About the Research

From a simple question about the Pythagorean tree to 3,158 formally verified theorems across 40+ mathematical domains.

The Origin

This project began with a simple question: can the Pythagorean tree — the ternary tree of all primitive Pythagorean triples generated by the Berggren matrices A, B, C — reveal new structure in integer factoring?

What emerged was a comprehensive investigation spanning number theory, algebra, complexity theory, and computational engineering. The Berggren tree, with its elegant group-theoretic structure in GL(3, ℤ), became a lens through which to examine the deepest questions in factoring and computational complexity.

What is Formal Verification?

Every theorem in this project is machine-verified using Lean 4 with the Mathlib library. This means:

✓

No Hidden Assumptions

Every proof is checked against the axioms. Only standard axioms (propext, Classical.choice, Quot.sound) are used.

✓

No Errors Possible

The computer verifies every logical step. A gap in reasoning would produce a compilation error.

✓

Reproducible

Anyone can download the code and verify independently. The proofs are permanent artifacts.

✓

One Sorry

Out of 3,158 theorems, exactly one uses sorry (the Sauer-Shelah lemma). Everything else is fully proved.
