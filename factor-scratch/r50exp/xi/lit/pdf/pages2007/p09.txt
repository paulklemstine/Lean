4.1 EXTENSION OF THE CLASS C
    In order to express conveniently our results on the asymptotic expansion of the function 𝜉, we introduce a
variant of the class C defined in Section 3.

Definition 15. Let 𝛼, 𝛽 ∈ R. The class of functions C [ 𝛼,𝛽 ] is the set of functions 𝑓 with values in R such that
𝜈 ↦→ 𝜈 −𝛼 (log 𝜈) −𝛽 𝑓 (𝜈) is in C.

    In particular, C [0,0] = C. If 𝑓 is in C [ 𝛼,𝛽 ] , then we denote by F ∈ R[𝑋, 𝑌 ] the series associated to 𝜈 ↦→
𝜈 −𝛼 (log 𝜈) −𝛽 𝑓 (𝜈) and call it, by extension, the series associated to 𝑓 . Note however that this extension deserves
some caution, as the association makes sense only relative to a given (𝛼, 𝛽).
    The introduction of these classes C [ 𝛼,𝛽 ] is motivated by the fact that in the context of NFS, the function
𝑢 ↦→ − log 𝜌(𝑢), which gives the relevant smoothness probabilities, is in C [1,1] (see Corollaries 13 and 14). The
following proposition establishes stability properties for elements of the classes C [ 𝛼,𝛽 ] .

Proposition 16. Let 𝑓 ∈ C [ 𝛼,𝛽] with associated series F ∈ R[[𝑋, 𝑌 ]] such that 𝛼 > 0 and F(0, 0) > 0. Then
  1. log 𝑓 ∈ C [0,1] and its associated series is 𝛼 + 𝛽𝑋/𝛼 + (𝑌 log F)/𝛼;
   2. Y ( 𝑓 ) = (log 𝑓 ) −1 ∈ C and its associated series is

                                                 𝑌 /(𝛼 + 𝛽𝑋/𝛼 + (𝑌 log F)/𝛼);

   3. if 𝛼 > 0, then X( 𝑓 ) = log2 𝑓 /log 𝑓 ∈ C and its associated series is

                            (𝑋 + 𝑌 log(𝛼 + 𝛽𝑋/𝛼 + (𝑌 log F)/𝛼))/(𝛼 + 𝛽𝑋/𝛼 + (𝑌 log F)/𝛼).

4.2 TWO NEW PROVEN TERMS FOR THE NFS COMPLEXITY
    In this section we develop the functions of interest 𝑎, 𝑏, 𝑑, defined in Section 2. The end result of this section is
an asymptotic expansion of the complexity of NFS with two new terms. We also introduce several reasonings that
will be intensively used and automatized in Section 4.3.

Theorem 17. The minimizers 𝑎, 𝑏, 𝑑 satisfy :

                          𝑎 = (8/9) 1/3 𝜈 1/3 (log 𝜈) 2/3 (1 + 𝑎 10 X(𝜈) + 𝑎 01 Y (𝜈) + 𝑜(Y (𝜈))),
                          𝑏 = (8/9) 1/3 𝜈 1/3 (log 𝜈) 2/3 (1 + 𝑎 10 X(𝜈) + 𝑎 01 Y (𝜈) + 𝑜(Y (𝜈))),
