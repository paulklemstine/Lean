    SCOPE WARNING — THIS IS NOT A QUADRATIC-SIEVE LATTICE PAPER. It is the
    binary-quadratic-form / CLASS GROUP algorithm. From the zbMATH review
    (English translation, verbatim):

      "The new factoring algorithm presented by the author performs the
       complete factorisation of a natural number N with probability >0
       in a running time of exp sqrt{(5/4) log N  log log N} steps, under
       the assumption that the Extended Riemann Hypothesis (ERH) holds. The
       new algorithm is based on the following ideas:
       1) It suffices to know the 2-part of the ideal class group of
          Q(sqrt(-N)), since the ambiguous binary quadratic forms of
          discriminant -N correspond one-to-one to the decompositions of N
          into two factors. The use of this idea goes back to Shanks and was
          already used by H. W. Lenstra and Schnorr to construct
          probabilistic algorithms.
       2) Selection of prime forms which, under ERH, generate the class group.
       3) Determination of sufficiently many relations between these
          generators by a probabilistic algorithm; on success this yields a
          matrix whose determinant is a nonzero multiple of the class number.
       4) Raising the prime forms to the odd part of this determinant yields
          a generating system for the 2-class group and hence the desired
          decomposition of N."

    Same review, verbatim, on Lenstra: "Seysens Verfahren ist inzwischen von
    A. K. Lenstra noch weiter bis zu einer Laufzeit von exp((1+o(1))sqrt(log N
    log log N)) verbessert worden, indem das Aufsuchen der Relationenmatrix
    unter Verwendung elliptischer Kurven beschleunigt wurde."

SCOPE CORRECTION THE QUESTION NEEDS:
  In the QUADRATIC SIEVE there is no such parity/character constraint on the
  relation lattice — a QS relation already forces x^2 = y exactly, so the
  square condition is built in and there is no "even sublattice of index 2^r"
  to find. The quadratic-character / index-2^m apparatus belongs to the
  NUMBER FIELD SIEVE, where F_i(a,b) is only required to be *almost* a square
  and the extra character rows are needed to force it. (Elkenbracht-Huizing's
  text makes this explicit: the requirement is that every exponent in the
  factorisation be even, and the extra rows are added to ENFORCE it.)

   Provenance: Buhler-Lenstra-Pomerance 1993 LNM 1554 sections 8 and 12.7,

   THREE CORRECTIONS THE QUESTION NEEDS:
     (a) It is NFS, not QS. In QS the square condition is built into the
         relation, so there is no parity constraint left to impose.
     (b) It is a GF(2) MATRIX-ROW / extra-bit construction, not a Z-lattice
         "mod-2 sublattice". Briggs: each relation vector is "augmented" and has
         "1 + k + l + m binary bits"; the extra bit is 0 if the Legendre symbol
         is 1, else 1.
     (c) It is NECESSARY BUT NOT SUFFICIENT (Briggs, verbatim), and the number
         of character-base primes is a CONFIDENCE/COST knob. Cavallar's footnote
         shows a record-setting implementation DROPPED the rows entirely. There
         is no rigorous index-2^r constant here.
   "index 2^r" / "2-adic" language: NOT-FOUND in eight full texts.
   The trivial-gcd failure mode IS real and observed (3 of 4 dependencies in
   RSA-512) but is named only "the trivial factorization". No 2-adic name.
