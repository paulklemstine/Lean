# Meta-Oracle Dreaming: Experimental Demos

Python demonstrations for hypotheses H13–H22 from the Oracle Bootstrap research.

## Quick Start

```bash
pip install numpy
python3 run_all_experiments.py    # Run H13-H17 experiments
python3 new_hypotheses_h18_h22.py # Run H18-H22 experiments
```

## Individual Demos

| Script | Hypothesis | Description |
|--------|-----------|-------------|
| `h13_julia_set.py` | H13 | Julia set Hausdorff dimension estimation |
| `h14_phase_transition.py` | H14 | Bootstrap family phase transition scan |
| `h15_bootstrap_factoring.py` | H15 | Bootstrap + lattice factoring benchmark |
| `h16_npotent_category.py` | H16 | N-potent categorical functor verification |
| `h17_npotent_filtration.py` | H17 | N-potent filtration (gen. Wedderburn) |
| `new_hypotheses_h18_h22.py` | H18–H22 | Next-generation hypotheses |
| `run_all_experiments.py` | All | Complete experimental suite |

## Requirements

- Python 3.8+
- NumPy
