The Map That Cannot Be Smoothed

Imagine you are a cartographer tasked with drawing a map of a strange landscape. The terrain has no gentle hills — only cliffs and plateaus. Every slope is infinitely steep or perfectly flat. There is no in-between.

This is the world of p-adic numbers — an alternative number system that has quietly powered some of the deepest advances in modern mathematics. And now, new research shows that this alien arithmetic can illuminate one of the most pressing practical problems in artificial intelligence: understanding when a neural network's decisions can be trusted.

Two Ways to Measure Distance

Our familiar number system has a simple concept of "closeness." The numbers 3.14 and 3.15 are close because their difference, 0.01, is small. But in the 1890s, Kurt Hensel proposed a radical alternative: measure closeness by divisibility. In his system, two numbers are "close" if their difference is divisible by a high power of a prime p.

This creates an ultrametric landscape unlike anything in ordinary geometry: every triangle is isosceles, every point inside a ball is its center, and space decomposes into nested, non-overlapping discs.

The Skeleton Beneath the Surface

The key insight: when a mathematical function is built from addition, multiplication, and division over p-adic numbers, its decision landscape breaks into a finite collection of well-behaved pieces — a skeleton. On each piece, the network's behavior follows a precise algebraic formula.

The theory proves that the number of skeleton pieces grows at most as $2^n$ where $n$ is the gate count of the circuit, and that each piece admits a tropical affine description: $\varphi(x) = \sum_i a_i \cdot \text{chart}_i(x) + b$.

Certified Robustness

The ultrametric inequality guarantees that small perturbations stay small: $v(x+y) \geq \min(v(x), v(y))$. Combined with Lipschitz bounds, this yields certified adversarial robustness — mathematical guarantees that no small perturbation can fool the classifier.

The Bigger Picture

Number theory, tropical combinatorics, machine learning theory, and computational complexity all meet in the structure of p-adic decision boundaries. The skeleton margin duality shows that certifying AI robustness is secretly a problem about integer arithmetic and combinatorial geometry — opening entirely new approaches to trustworthy AI.

Valuation-Skeleton Margin Duality for p-adic Rational Networks

Abstract. We establish a formally verified valuation-theoretic margin theory for rational arithmetic circuits over non-Archimedean valued fields. For any rational gate circuit of gate count $n$, the valuation margin function $v(f(x)-t)$ decomposes into at most $2^n$ cells on which the margin is piecewise integer-affine. We derive certified robustness certificates from the ultrametric inequality and prove mixed-label cells are bounded by skeleton complexity. 1. Introduction

Neural networks over non-Archimedean fields have attracted interest from p-adic ML, arithmetic circuit complexity, and tropical geometry. The central challenge is understanding decision boundary geometry.

Over the reals, ReLU networks produce piecewise-linear boundaries. Over non-Archimedean fields, the ultrametric topology provides additional structure enabling clean combinatorial decompositions.

2. Definitions

2.1 HasIntValuation

A typeclass for fields $K$ with valuation $v: K \to \mathbb{Z} \cup \{\infty\}$ satisfying:

  • $v(0) = \infty$, $v(1) = 0$
  • $v(xy) = v(x) + v(y)$ (multiplicativity)
  • $\min(v(x), v(y)) \leq v(x+y)$ (ultrametric)

2.2 RationalGate

Inductive circuit syntax: input | const | add | mul | inv

Key measures: depth (circuit depth), gateCount (total operations)

2.3 SkeletonCell & FiniteSkeletonCover

A cell carries a set, chart dimension, and valuation coordinates. Covers partition the input space into finitely many cells.

3. Main Results

Theorem 1 (Strict Dominance)

If $v(x) < v(y)$, then $v(x+y) = v(x)$.

Proof sketch: Lower bound from ultrametric. Upper bound: $v(x) = v((x+y)+(-y)) \geq \min(v(x+y), v(y))$. If $v(x+y) \geq v(y) > v(x)$, contradiction.

Theorem 2 (Exponential Complexity Bound)

$\text{gateComplexityBound}(g) \leq 2^{\text{gateCount}(g)}$

Proof: Structural induction. Add/mul: $b(l) \cdot b(r) \leq 2^{gc(l)} \cdot 2^{gc(r)} = 2^{gc(l)+gc(r)} \leq 2^{1+gc(l)+gc(r)}$. Inv: $b(g)+1 \leq 2^{gc(g)}+1 \leq 2 \cdot 2^{gc(g)} = 2^{gc(g)+1}$.

Theorem 3 (Mixed-Label Bound)

$\text{mixedLabelCellCount}(S, \text{lbl}) \leq \text{skeletonComplexity}(S)$

Theorem 4 (Pole-Free Finite Margin)

If margin is constant $m \in \mathbb{Z}$ on cell $C$, then $f(x) - t \neq 0$ for all $x \in C$.

Theorem 5 (Margin Monotonicity)

$\gamma_1 \leq \gamma_2 \implies \text{HighMarginRegion}(f, t, \gamma_2) \subseteq \text{HighMarginRegion}(f, t, \gamma_1)$

def compute_gate_complexity(gate):
    if isinstance(gate, (InputGate, ConstGate)):
        return 1
    elif isinstance(gate, (AddGate, MulGate)):
        return complexity(gate.left) * complexity(gate.right)
    elif isinstance(gate, InvGate):
        return complexity(gate.child) + 1

Python: p-adic Valuation

def padic_val(n: int, p: int = 5) -> float:
    """Compute v_p(n) = max{k : p^k | n}."""
    if n == 0:
        return float('inf')
    n = abs(n)
    v = 0
    while n % p == 0:
        n //= p
        v += 1
    return v

def gate_complexity_bound(g):
    """Skeleton complexity upper bound (verified: ≤ 2^gateCount)."""
    if isinstance(g, (Input, Const)):
        return 1
    elif isinstance(g, (Add, Mul)):
        return gate_complexity_bound(g.left) * gate_complexity_bound(g.right)
    elif isinstance(g, Inv):
        return gate_complexity_bound(g.child) + 1

Python: Certified Robustness

def certified_robustness_radius(f_val, threshold, lipschitz_const, p=5):
    """Certified robustness radius for p-adic classifier.
    
    Verified: for all y with v_p(y-x) ≥ radius,
    classification label(y) = label(x).
    """
    margin = padic_val(f_val - threshold, p)
    radius = margin - lipschitz_const
    return (margin, radius)
