The Hidden Mathematics of Neural Networks

How algebra reveals what AI can and cannot do — with mathematical certainty.

The Black Box Problem

Imagine building a self-driving car. Your neural network distinguishes stop signs from speed limit signs with 99.9% accuracy. But what happens when someone sticks a small piece of tape on the sign? In 2017, researchers showed that tiny, nearly invisible modifications could cause state-of-the-art networks to catastrophically misclassify road signs.

This vulnerability isn't a bug — it's a fundamental property of how neural networks process information. Until recently, we had no mathematical tools to predict when or how it would occur. We could test millions of examples, but we could never guarantee correct behavior on unseen inputs.

A Weight System Is a Dynamical System

The key insight begins with a change of perspective. A neural network isn't just a function — it's a dynamical system that iteratively transforms information through successive layers. Each layer multiplies data by a matrix of "weights." The collection of all possible weight matrices forms a weight system with precise algebraic structure.

The Joint Spectral Radius: A Universal Speed Limit

The most important number is the joint spectral radius $\rho$, measuring the maximum growth rate of products of weight matrices. For any network with JSR $\rho$ and depth $d$:

$$\|W_{i_1} \cdots W_{i_d}\| \leq \rho^d$$

If $\rho < 1$, signals decay exponentially — the network is stable. If $\rho > 1$, signals grow — amplifying both information and noise. The certified robustness radius is $\varepsilon = \text{margin} / \rho^d$.

Pruning by Radical

The Jacobson radical of the weight algebra — elements that become zero when raised to a power — corresponds precisely to redundant neurons. If $a^k = 0$, then $a$ contributes nothing after $k$ layers. This transforms pruning from art to science.

GK-Dimension: True Complexity

The Gelfand-Kirillov dimension measures how fast the algebra of weight products grows. It's additive under composition ($\text{GK-dim}(A \otimes B) \leq \text{GK-dim}(A) + \text{GK-dim}(B)$) and invariant under reparameterization — capturing intrinsic complexity, not parameter count.

Cross-Domain Bridges

The framework connects to post-quantum cryptography ($\rho^{-n} \geq 1$ gives exponential hardness), thermodynamics ($S = n \log \rho$ entropy rate), and residual networks ($(1+\varepsilon)^d \leq e^{\varepsilon d}$ Lipschitz bounds).

Algorithms

Algorithm 1: Certified Robustness Computation

def certify_robustness(weights, depth, margin):
    """
    Compute certified adversarial robustness radius.
    Complexity: O(|𝒜| · n²) + O(1)
    """
    rho = max(norm(W, ord=2) for W in weights)
    lipschitz = rho ** depth
    radius = margin / lipschitz
    return radius

Algorithm 2: GK-Dimension Estimation

def estimate_gk_dimension(weights, max_k=8):
    """
    Estimate GK-dimension from growth of product spans.
    Complexity: O(K · m^K · n²)
    """
    for k in range(1, max_k + 1):
        V_k = span of all products of length ≤ k
        dims[k] = rank(V_k)
    return lim_sup(log(dims[k]) / log(k))

Algorithm 3: Security Certificate

def security_certificate(weights, lattice_dim):
    """
    Compute post-quantum security parameter.
    Security = n · log₂(1/ρ) bits
    Quantum security = security / 2 (Grover)
    """
    rho = max_norm(weights)
    if rho < 1:
        return lattice_dim * log2(1/rho)  # bits
    return 0  # Not contractive → no security

structure WeightSystem (A : Type*) [NormedRing A] where
  weights : Finset A
  nonempty : weights.Nonempty

noncomputable def WeightSystem.maxNorm (ws : WeightSystem A) : ℝ :=
  ws.weights.sup' ws.nonempty (fun a => ‖a‖)

structure ContractiveWeightSystem (A : Type*) [NormedRing A]
    extends WeightSystem A where
  contractive : ∀ w ∈ weights, ‖w‖ < 1

def PolynomialGrowth (growth : ℕ → ℕ) (d : ℕ) : Prop :=
  ∃ C : ℕ, 0 < C ∧ ∀ k : ℕ, 0 < k → growth k ≤ C * k ^ d

def GrowthEquivalent (g1 g2 : ℕ → ℕ) : Prop :=
  ∃ (C : ℕ) (d : ℕ), 0 < C ∧
    (∀ k, 0 < k → g1 k ≤ C * k ^ d * g2 k) ∧
    (∀ k, 0 < k → g2 k ≤ C * k ^ d * g1 k)

Key Proof (Contractive Convergence)

theorem contractive_convergence_rate
    (cws : ContractiveWeightSystem A) :
    ∀ (ε : ℝ), 0 < ε →
    ∃ (D : ℕ), ∀ (d : ℕ), D ≤ d → ∀ (l : List A),
      l.length = d → (∀ a ∈ l, a ∈ cws.weights) →
      ‖l.prod‖ < ε := by
  intro ε hε
  have hρ := contractive_maxNorm_lt_one cws
  have hρ_nn := cws.toWeightSystem.maxNorm_nonneg
  obtain ⟨D, hD⟩ := exists_pow_lt_of_lt_one hε hρ
  exact ⟨D, fun d hd l hlen hl => calc
    ‖l.prod‖ ≤ cws.toWeightSystem.maxNorm ^ l.length :=
      depth_product_norm_bound _ l hl
    _ = cws.toWeightSystem.maxNorm ^ d := by rw [hlen]
    _ ≤ cws.toWeightSystem.maxNorm ^ D :=
      pow_le_pow_of_le_one hρ_nn (le_of_lt hρ) hd
    _ < ε := hD⟩
