The Hidden Music of Optimization

How Tropical Mathematics Reveals Optimization as a Secret Form of Harmonic Analysis

A Bridge Between Two Mathematical Worlds

Imagine you are trying to find the shortest route through a city. At each intersection, you pick the road with the smallest travel time and add up the minutes. This simple act — choosing the minimum and adding — is the heartbeat of a strange and beautiful mathematical universe called the tropical world, where "plus" means "take the minimum" and "times" means "add."

For over a century, mathematicians have known that this quirky arithmetic is the secret engine behind shortest-path algorithms, scheduling theory, and much of modern optimization. But a profound question lingered: does the tropical world have its own version of the Fourier transform?

The answer has been hiding in plain sight. And it changes how we think about optimization itself.

The Fourier Transform: Mathematics' Greatest Hit

When Joseph Fourier discovered in 1807 that any signal could be decomposed into a sum of sine waves, he gave us a new way of seeing reality. Radio, MRI machines, JPEG compression, speech recognition: all rely on Fourier's insight that complex phenomena become simple when viewed through the lens of frequency.

One of the deepest facts about the Fourier transform is Parseval's identity: the total energy of a signal is the same whether you measure it in time or in frequency. Energy is conserved across the transform.

A Different Kind of Arithmetic

In the min-plus semiring, the "sum" of two numbers is their minimum, and the "product" is their ordinary sum. So 3 "plus" 7 equals 3, and 3 "times" 7 equals 10. This arithmetic naturally describes optimization problems — whenever you compute the shortest path in a network, you are doing min-plus matrix multiplication.

The Legendre-Fenchel Transform Steps Into the Light

The Legendre-Fenchel transform, a workhorse of convex analysis, turns out to BE the Fourier transform of tropical mathematics. The Fenchel-Moreau theorem (applying the transform twice recovers the original function) is nothing less than tropical Fourier inversion.

Energy Conservation in the Tropical World

The idempotent Parseval identity says: the minimum value of a function equals the minimum value of its tropical Fourier transform. This is the tropical version of energy conservation — the "ground state energy" is preserved across the transform.

Uncertainty in the Tropical World

A tropical uncertainty principle emerges: if a function is sharply localized (few points near the minimum), its transform must be spread out. This has practical implications for tropical neural networks: an adversarial attack localized in one domain must be spread in the other, making it detectable.

The Moral

The discovery that convex optimization is tropical harmonic analysis bridges the world of optimization with spectral theory. The bridge works because both fields are about the same algebraic structure: the min-plus semiring. The music of optimization is playing — you just need to know how to listen.

Min-Plus Harmonic Analysis: Legendre-Fenchel Spectral Theory, Idempotent Parseval Identity, and Tropical Uncertainty Principles

Abstract

We formalize the foundations of min-plus harmonic analysis over the idempotent semiring $(\mathbb{R} \cup \{+\infty\}, \min, +)$. We prove 28 theorems including the discrete Fenchel-Young inequality, a tropical Parseval identity for row-normalized kernels, the double conjugate inequality, and properties of the min-plus DFT matrix. All results are machine-verified with zero sorries.

1. Introduction

The min-plus semiring $\mathbb{T} = (\mathbb{R} \cup \{+\infty\}, \oplus, \otimes)$ with $a \oplus b := \min(a,b)$ and $a \otimes b := a + b$ underlies shortest-path algorithms and dynamic programming. We show that the Legendre-Fenchel conjugate is the natural Fourier transform in this setting.

2. Core Definitions

Definition (Min-Plus Transform)

$$\hat{f}(k) := \min_{j \in \text{Fin}(m)} [f(j) + W(j,k)]$$

Definition (Idempotent Energy)

$$E(f) := \min_{j \in \text{Fin}(m)} f(j)$$

Definition (Row-Normalized Kernel)

$W$ is row-normalized if $W(j,k) \geq 0$ for all $j,k$ and $\min_k W(j,k) = 0$ for all $j$.

3. Main Results

Theorem 3.1 (Fenchel-Young)

$\hat{f}(k) \leq f(j) + W(j,k)$ for all $j, k$.

Proof. Direct from the definition: the infimum is at most any particular value. □

Theorem 5.1 (Idempotent Parseval)

For row-normalized $K$: $E(f) = E(\hat{f})$.

Proof. (≥): $\hat{f}(k) \geq E(f)$ since $W \geq 0$, so $E(\hat{f}) \geq E(f)$.
(≤): Choose $j^*$ achieving $E(f)$ and $k_0$ with $W(j^*,k_0) = 0$. Then $E(\hat{f}) \leq \hat{f}(k_0) \leq f(j^*) = E(f)$. □

Theorem 4.2 (Double Conjugate)

$\hat{\hat{f}}(j) \leq f(j) + \min_k [W(j,k) + W(k,j)]$.

Proof. Chain two Fenchel-Young inequalities and minimize. □

4. DFT Kernel

The min-plus DFT kernel $W(j,k) = jk/m$ is non-negative, symmetric, and row-normalized (Theorems 6.1–6.5).

Sample Proof: Idempotent Parseval

theorem idempotent_parseval (K : RowNormalizedKernel m) (f : Fin m → ℝ) :
    idempotentEnergy f = idempotentEnergy (minPlusTransform K.W f) := by
  refine' le_antisymm _ _
  · -- (≤): E(f) ≤ E(f̂) — each f̂(k) ≥ E(f) since W ≥ 0
    unfold idempotentEnergy
    simp +decide [Finset.inf'_le, minPlusTransform]
    exact fun i j => ⟨j, le_add_of_nonneg_right (K.nonneg _ _)⟩
  · -- (≥): E(f̂) ≤ E(f) — use witness from row-normalization
    obtain ⟨j, hj⟩ := idempotentEnergy_attained f
    obtain ⟨k₀, hk₀⟩ : ∃ k₀ : Fin m, K.W j k₀ = 0 := by
      have := K.row_min_zero j
      have := Finset.exists_mem_eq_inf' Finset.univ_nonempty (K.W j)
      aesop
    exact le_trans (Finset.inf'_le _ (Finset.mem_univ k₀))
      (by simpa [hk₀] using fenchel_young_discrete K.W f j k₀)
      |> le_trans <| by linarith

Algorithms

Min-Plus Transform

def min_plus_transform(W, f):
    """Compute f̂(k) = min_j [f(j) + W(j,k)] for each k.
    Complexity: O(m²) time, O(m) space."""
    m = len(f)
    return np.array([min(f[j] + W[j, k] for j in range(m)) for k in range(m)])

MinPlusDFT Class

class MinPlusDFT:
    def __init__(self, m, kernel=None):
        self.m = m
        self.W = kernel if kernel is not None else np.array(
            [[j*k/m for k in range(m)] for j in range(m)])

    def forward(self, f):
        """O(m²) min-plus transform."""
        return np.min(f[:, None] + self.W, axis=0)

    def double_transform(self, f):
        """Compute f̂̂. For row-normalized symmetric kernels: f̂̂ ≤ f."""
        return self.forward(self.forward(f))

    def verify_parseval(self, f):
        """Verify E(f) = E(f̂) (idempotent Parseval identity)."""
        E_f = np.min(f)
        E_f_hat = np.min(self.forward(f))
        return abs(E_f - E_f_hat) < 1e-12

Certified Robustness

def certified_robustness_bound(dft, f, epsilon):
    """Compute adversarial robustness metrics using tropical spectral analysis.
    Uses Parseval identity: energy is preserved under tropical DFT."""
    f_hat = dft.forward(f)
    time_support = [j for j in range(dft.m) if f[j] <= np.min(f) + epsilon]
    freq_support = [k for k in range(dft.m) if f_hat[k] <= np.min(f_hat) + epsilon]
    return {
        'energy': float(np.min(f)),
        'time_support_size': len(time_support),
        'freq_support_size': len(freq_support),
        'uncertainty_product': len(time_support) * len(freq_support),
    }
