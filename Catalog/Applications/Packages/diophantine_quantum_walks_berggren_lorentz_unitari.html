Domains Bridged

There is a tree that grows not in any forest, but in the realm of pure mathematics. Its root is the simplest right triangle—the one with sides 3, 4, and 5. From this root, three branches spring forth, each producing a new right triangle: (5, 12, 13), (21, 20, 29), and (15, 8, 17). Each of these branches again in three directions, forever. Every right triangle with whole-number sides appears exactly once.

The Einstein Connection

The Berggren tree's three generator matrices turn out to preserve the Lorentzian distance formula \(Q(a,b,c) = a^2 + b^2 - c^2\). For Pythagorean triples, \(Q = 0\)—these triples live on the "light cone" of a miniature Minkowski spacetime. The Berggren matrices are integer Lorentz transformations.

Theorem (Berggren-Lorentz). For each Berggren generator \(A_i\), \(A_i^\top \eta A_i = \eta\) where \(\eta = \text{diag}(1,1,-1)\).

Three Matrices, One Universe

The determinant signature is \((+1, -1, +1)\): \(A_1\) and \(A_3\) are "proper" Lorentz transformations; \(A_2\) is "improper" (orientation-reversing). All three share the same Frobenius norm \(\sqrt{35} \approx 5.92\).

\(A_1\) is unipotent: \((A_1 - I)^3 = 0\), with sole eigenvalue 1. But \(A_2\) has irrational eigenvalues \(2 \pm \sqrt{3}\), creating aperiodic dynamics—exactly what enables efficient quantum walks.

From Symmetry to Security

The generators do not commute: \(A_1 A_2 \neq A_2 A_1\). This non-commutativity enables hard word problems for post-quantum cryptography. Combined with Ω(5d) hypotenuse growth, the Berggren monoid offers a geometrically natural one-way function.

The Quantum Walk

Because the Berggren matrices preserve the quadratic form, a quantum walk on the tree has a certified invariant: \(Q = 0\) is maintained at every step, for every branch. This is proved by induction on word length—the key theorem enabling quantum Diophantine computation.

Core Definitions

-- Minkowski quadratic form Q(a,b,c) = a² + b² − c²
def minkowskiQ (a b c : ℤ) : ℤ := a ^ 2 + b ^ 2 - c ^ 2

-- Minkowski metric tensor η = diag(1,1,−1)
def eta : Matrix (Fin 3) (Fin 3) ℤ := !![1, 0, 0; 0, 1, 0; 0, 0, -1]

-- Integer Lorentz group O(2,1;ℤ)
def IntLorentzGroup : Set (Matrix (Fin 3) (Fin 3) ℤ) :=
  {M | M.transpose * eta * M = eta}

Key Theorems

-- Berggren-Lorentz preservation
theorem A₁_lorentz : A₁.transpose * eta * A₁ = eta := by native_decide

-- Quadratic form preservation
theorem A₁_preserves_Q (a b c : ℤ) :
    minkowskiQ (a - 2*b + 2*c) (2*a - b + 2*c) (2*a - 2*b + 3*c) = minkowskiQ a b c := by
  unfold minkowskiQ; ring

-- Inductive closure: every word preserves Lorentz form
theorem wordToMatrix_in_lorentz (w : BerggrenWord) :
    wordToMatrix w ∈ IntLorentzGroup := by
  induction w with
  | nil => exact one_in_lorentz
  | cons g gs ih => exact lorentz_mul_closed _ _ (gen_in_lorentz g) ih

-- Cayley-Hamilton for A₁: unipotent
theorem cayley_hamilton_A₁ :
    A₁ * A₁ * A₁ - 3 • (A₁ * A₁) + 3 • A₁ - 1 = 0 := by native_decide
