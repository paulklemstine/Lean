Key Results

Theorem (Cayley Faithfulness)

Every monoid admits a faithful representation via the left regular action. This guarantees that neural proof representations can perfectly encode tactic structure.

$\forall a, b \in M,\ (\forall x,\ a \cdot x = b \cdot x) \implies a = b$

Theorem (Lipschitz Certified Robustness)

A Lipschitz goal embedding with constant $L$ provides certified robustness radius $\delta/L$: adversarial perturbations of norm $< \delta$ can only affect goals within proof distance $\delta/L$.

$\|\varphi(g_1) - \varphi(g_2)\| / L \leq d_{\text{proof}}(g_1, g_2)$

For a tactic system with branching factor $b \geq 2$, the total search space at depth $\leq d$ is bounded by $b^{d+1}$.

$\sum_{i=0}^{d} b^i \leq b^{d+1}$

The Hidden Algebra of Thinking Machines

How Mathematicians Discovered That Every Proof Strategy Has a Secret Geometric Shape

Imagine you're trying to solve a maze. Not just any maze — a mathematical maze where each turn represents a different logical move: perhaps introducing a variable, applying a known theorem, or splitting a problem into cases. For decades, mathematicians and computer scientists have built automated reasoning systems that navigate these mazes, searching for paths from conjecture to proof. But they've faced a fundamental mystery: why do some strategies work brilliantly on certain problems and fail catastrophically on others?

A new mathematical framework called neural proof mining offers a surprising answer — one that bridges the gap between abstract algebra, geometry, and artificial intelligence. The key insight is almost poetic: every collection of proof strategies carries a hidden algebraic structure, and that structure determines exactly how hard it is to find proofs.

The Algebra of Proof Moves

Think of a chess player's repertoire. Each opening — the Sicilian Defense, the Queen's Gambit — is a sequence of moves. You can combine openings by playing one after another. There's an "empty strategy" (doing nothing), and combining three strategies in sequence always gives the same result regardless of grouping. Mathematicians call this a monoid.

The same structure appears in mathematical reasoning. When a mathematician proves a theorem, they use tactics: introducing assumptions, applying known results, rewriting expressions. These tactics compose naturally, forming the tactic shape monoid of the proof system.

This monoid has a rich theory of representations — ways of encoding its abstract elements as matrices. The Cayley Faithfulness Theorem establishes that every finite collection of proof strategies can be faithfully encoded as matrices, perfectly preserving algebraic relationships.

The Lipschitz Guarantee

Modern AI systems for mathematics work by embedding proof goals into high-dimensional vector spaces. But can an adversary craft a slightly modified statement that fools the AI? Neural proof mining answers this with Lipschitz continuity: a goal embedding is L-Lipschitz if nearby goals in proof distance always map to nearby points in space.

This provides a certified robustness guarantee: perturbations of norm $\delta$ can only affect goals within proof distance $\delta/L$. The Lipschitz constant becomes a quantitative security parameter.

The Stratification of Difficulty

Goals naturally stratify into layers based on proof complexity. The depth stratification theorem shows these layers partition all goals into disjoint levels. A pigeonhole argument reveals structural constraints: if $n$ goals are distributed across $D+1$ levels, some level has at most $\lfloor n/(D+1) \rfloor$ goals.

The geometric search bound makes this concrete: a tactic system with branching factor $b$ searching to depth $d$ must explore at most $b^{d+1}$ states — an exponential bound connecting to computational complexity and post-quantum cryptographic hardness.

Deep Networks and the Robustness Cascade

When neural networks compose multiple Lipschitz layers, robustness degrades multiplicatively: a 10-layer network with per-layer constant 2 has overall constant 1024. The trace factorization theorem offers a path forward: any depth-$d$ proof decomposes into $d$ unit-depth steps, enabling step-by-step robustness maintenance.

Part I: Tactic Monoid Structure

Theorem 2 (Depth Additivity)
$\text{depth}(t_1 \cdot t_2) = \text{depth}(t_1) + \text{depth}(t_2)$
Theorem 3 (Power Scaling)
$\text{depth}(t^n) = n \cdot \text{depth}(t)$
Theorem 5 (Arity-Depth Bound)
$\text{totalArity}(t) \leq \text{depth}(t) \cdot \max_s \text{arity}(s)$

Part II: Cayley Faithfulness

Theorem 6 (Cayley Faithfulness)
$\forall a, b \in M,\ (\forall x,\ a \cdot x = b \cdot x) \Rightarrow a = b$

Proof: Evaluate at $x = 1$: $a \cdot 1 = b \cdot 1$, hence $a = b$.

Part III: Lipschitz Certification

Theorem 13 (Distance Bound)
$\|\varphi(g_1) - \varphi(g_2)\| / L \leq d(g_1, g_2)$
Theorem 15 (Composition)

If $f$ is $L_1$-Lipschitz and $g$ is $L_2$-Lipschitz, then $g \circ f$ is $(L_1 \cdot L_2)$-Lipschitz.

Part IV: Depth Stratification

Theorem 23 (Geometric Search Bound)
$\sum_{i=0}^{d} b^i \leq b^{d+1} \quad \text{for } b \geq 2$
Theorem 24 (Pigeonhole Tradeoff)

For $n$ goals across $D+1$ depth levels: $\exists k: |S_k| \leq \lfloor n/(D+1) \rfloor$

theorem cayley_left_action_faithful (M : Type*) [Monoid M] :
    Function.Injective (fun (m : M) => fun (x : M) => m * x) := by
  exact fun a b h => by simpa using congr_fun h 1
Depth Additivity (TacticTrace.depth_mul)
theorem TacticTrace.depth_mul (t₁ t₂ : TacticTrace) :
    (t₁ * t₂).depth = t₁.depth + t₂.depth := by
  simp [TacticTrace.depth, TacticTrace.mul_steps, List.length_append]
Lipschitz Distance Bound (lipschitz_embedding_dist_bound)
theorem lipschitz_embedding_dist_bound {G E : Type*} [NormedAddCommGroup E]
    (φ : LipschitzGoalEmbedding G E) (g₁ g₂ : G) (hL : 0 < φ.lipConst) :
    ‖φ.embed g₁ - φ.embed g₂‖ / φ.lipConst ≤ φ.goalDist g₁ g₂ := by
  exact div_le_iff₀' hL |>.2 (by linarith [φ.lipschitz_certified g₁ g₂])
Geometric Search Bound (geometric_search_bound)
theorem geometric_search_bound (b d : ℕ) (hb : 2 ≤ b) :
    (∑ i ∈ Finset.range (d + 1), b ^ i) ≤ b ^ (d + 1) := by
  exact Nat.le_of_lt (Nat.geomSum_lt (by linarith) (by aesop))
Pigeonhole Tradeoff (depth_complexity_tradeoff)
theorem depth_complexity_tradeoff (n D : ℕ) (hD : 0 < D + 1)
    (goals_at_depth : Fin (D + 1) → ℕ)
    (h_total : (∑ i, goals_at_depth i) = n) :
    ∃ k : Fin (D + 1), goals_at_depth k ≤ n / (D + 1) := by
  contrapose! h_total
  exact ne_of_gt (lt_of_lt_of_le
    (by simp +arith +decide; nlinarith [Nat.div_add_mod n (D+1), Nat.mod_lt n hD])
    (Finset.sum_le_sum fun i _ => Nat.succ_le_of_lt (h_total i)))
Trivial Rep Not Faithful (trivial_rep_not_faithful)
theorem trivial_rep_not_faithful {M : Type*} [Monoid M] [Nontrivial M]
    (R : Type*) [Semiring R] (n : ℕ) :
    ¬ (trivialRep M R n).IsFaithful := by
  exact fun h => by
    obtain ⟨a, b, hab⟩ := exists_pair_ne M
    have := @h a b (Matrix.ext fun i j => by simp [trivialRep])
    contradiction
Representation Preserves Powers (rep_map_pow)
theorem rep_map_pow {M : Type*} [Monoid M] {R : Type*} [Semiring R]
    {n : ℕ} (ρ : MonoidRep M R n) (m : M) (k : ℕ) :
    ρ.toFun (m ^ k) = ρ.toFun m ^ k := by
  induction' k with k ih
  · simp [ρ.map_one]
  · simp [pow_succ, ρ.map_mul, ih]

Algorithms

Algorithm 1: Tactic Monoid Construction

Algorithm: ConstructTacticMonoid(tactics, max_depth)
Input:  Set of tactic shapes S, maximum depth D
Output: Tactic trace monoid T

1. T ← {ε}                    // identity element
2. current ← {ε}
3. For d = 1, ..., D:
4.   next ← ∅
5.   For each t ∈ current:
6.     For each s ∈ S:
7.       next ← next ∪ {t · [s]}
8.   T ← T ∪ next
9.   current ← next
10. Return T

Complexity: O(|S|^D) time and space

Algorithm 2: Lipschitz Goal Embedding

Algorithm: LipschitzEmbed(goals, dist, L)
Input:  Goal set G, distance matrix d, Lipschitz constant L
Output: Embedding φ: G → ℝ^|G|

1. For each goal g ∈ G:
2.   φ(g) ← L · (d(g, g₁), d(g, g₂), ..., d(g, gₙ))
3. Verify: ‖φ(g₁) - φ(g₂)‖ ≤ L · d(g₁, g₂) ∀ pairs
4. Return φ

Complexity: O(|G|² · |S|) for distances, O(|G|²) for embedding

Algorithm 3: Certified Robustness Check

Algorithm: CertifyRobustness(embedding, L, δ)
Input:  Embedding φ, Lipschitz constant L, perturbation budget δ
Output: Certified robustness radius

1. radius ← δ / L
2. For each pair (g₁, g₂):
3.   If ‖φ(g₁) - φ(g₂)‖ < δ:
4.     Assert d(g₁, g₂) < radius  // guaranteed by Theorem 14
5. Return radius

Complexity: O(|G|²)

Python — Demo Script

class TacticShape:
    def __init__(self, id: int, arity: int):
        self.id = id
        self.arity = arity

class TacticTrace:
    def __init__(self, steps=None):
        self.steps = list(steps) if steps else []

    @property
    def depth(self):
        return len(self.steps)

    def __mul__(self, other):
        return TacticTrace(self.steps + other.steps)

    def __pow__(self, n):
        result = TacticTrace()
        for _ in range(n):
            result = result * self
        return result

# Verify depth additivity
t1 = TacticTrace([TacticShape(0, 1), TacticShape(1, 2)])
t2 = TacticTrace([TacticShape(2, 1)])
composed = t1 * t2
assert composed.depth == t1.depth + t2.depth  # Theorem 2 ✓
