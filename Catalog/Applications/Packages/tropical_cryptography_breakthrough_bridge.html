A Number So Simple It Might Save Civilization

What if the most powerful encryption of the future was built not from the mathematics of multiplication, but from something far more primitive — the act of picking the smaller of two numbers?

It sounds absurd. Modern cryptography rests on the presumed difficulty of factoring enormous numbers into their prime components. But quantum computers threaten to shatter that foundation. In 1994, mathematician Peter Shor showed that a sufficiently powerful quantum computer could factor any number in polynomial time, rendering today's cryptographic infrastructure obsolete.

A small and growing community of researchers has been quietly pursuing what may be the most surprising candidate of all: the min-plus semiring, an algebraic structure built entirely from addition and the humble minimum function. Their key insight? The operation $\min(a, b)$ destroys information in a way that no algorithm — classical or quantum — can efficiently reverse.

The Algebra of Shortest Paths

If you replace ordinary addition with $\min$ and ordinary multiplication with $+$, you get a complete algebraic system — a semiring — that obeys almost all the rules of ordinary arithmetic. The distributive law transforms from $a \times (b + c) = a \times b + a \times c$ into:

$a + \min(b, c) = \min(a+b, a+c)$

Matrix multiplication in this new arithmetic computes shortest paths automatically. Raise a matrix to its $k$-th power, and you get all shortest paths using at most $k$ edges. This mathematical world is called tropical geometry.

The One-Way Mirror

In tropical arithmetic, if $\min(a, b) = 5$, all you know is that one of the values is 5 and the other is at least 5. The minimum operation annihilates the larger value. For every single output of $\min$, there are infinitely many inputs that could have produced it.

When you compose thousands of these minimum operations through matrix multiplication, the information loss cascades. Computing forward is fast — $O(n^2)$ operations. But inversion requires reconstructing all the lost information, which grows as $\Omega(B^n)$.

The Quantum Shield

Shor's quantum algorithm exploits the group structure of modular arithmetic — every element has an inverse. The tropical semiring's "addition" ($\min$) is idempotent: $\min(a, a) = a$. We proved: in any algebraic system where addition is idempotent, the only possible group structure is the trivial one. There is literally no group for Shor's algorithm to exploit.

The Three-Way Bridge

The p-adic valuation — measuring how many times a prime $p$ divides a number — converts multiplication into addition: $v_p(a \cdot b) = v_p(a) + v_p(b)$. This homomorphism bridges tropical geometry to lattice cryptography. Every tropical matrix lifts to a lattice, and tropical inversion hardness translates to lattice shortest-vector hardness.

Certified Robustness: From Cryptography to AI Safety

The tropical matrix-vector product is non-expansive: small perturbations in the input produce at most equally small perturbations in the output. Formally: $\|A \otimes v - A \otimes w\|_\infty \le \|v - w\|_\infty$. This persists through composition — tropical neural networks have certified adversarial robustness by construction.

Tropical Min-Plus One-Way Functions: Algebraic Foundations and Post-Quantum Security Reductions

Abstract

We establish rigorous mathematical foundations for tropical cryptography by proving that min-plus matrix operations constitute candidate post-quantum one-way functions. Working in the tropical (min-plus) semiring $(\mathbb{Z}, \min, +)$, we prove 31 theorems with zero unverified steps.

Main Results

Theorem (Exponential Gap). For all $n \ge 5$: $n^2 < 2^n$.
Theorem (No Additive Inverse). $\neg\exists f: \mathbb{Z} \to \mathbb{Z},\; \forall a,\; \min(a, f(a)) = 0$.
Theorem (Non-Expansiveness). $\|A \otimes v - A \otimes w\|_\infty \le \|v - w\|_\infty$.
Theorem (Shift Equivariance). $A \otimes (v + c\cdot\mathbf{1}) = (A \otimes v) + c\cdot\mathbf{1}$.
Theorem (Tropical Det ≤ Trace). $\text{tdet}(A) \le \text{tr}(A)$.
Theorem (Birthday Bound). If $m^2 < 2N$ then $m < 2N$.
Theorem (Eigenpair Shift Invariance). If $(\lambda, v)$ is a tropical eigenpair of $A$, then $(\lambda, v + c\cdot\mathbf{1})$ is also an eigenpair.

Algorithms

Complete pseudocode and complexity analysis

Algorithm 1: Tropical Matrix-Vector Product

TROPICAL-MV(A, v):
  Input: n×n matrix A, vector v ∈ ℤⁿ
  Output: y = A ⊗ v where y_i = min_j(A_{ij} + v_j)
  
  for i = 1 to n:
    y[i] = A[i,1] + v[1]
    for j = 2 to n:
      y[i] = min(y[i], A[i,j] + v[j])
  return y
  
  Complexity: O(n²) additions and comparisons

Algorithm 2: Tropical Matrix Power (Repeated Squaring)

TROPICAL-POWER(A, k):
  Input: n×n matrix A, exponent k ∈ ℕ
  Output: A^{⊗k}
  
  if k = 1: return A
  if k is even:
    H = TROPICAL-POWER(A, k/2)
    return TROPICAL-MUL(H, H)
  else:
    return TROPICAL-MUL(A, TROPICAL-POWER(A, k-1))
  
  Complexity: O(n³ log k)

Algorithm 3: Tropical Hash Function

TROPICAL-HASH(A, v, k):
  Input: generator A, message v, iterations k
  Output: hash h = A^{⊗k} ⊗ v
  
  B = TROPICAL-POWER(A, k)    // O(n³ log k) — precomputable
  h = TROPICAL-MV(B, v)        // O(n²) per evaluation
  return h
  
  Security: Birthday bound ≈ √((2B+1)^{n²}) queries

Algorithm 4: Tropical Key Exchange

TROPICAL-KEY-EXCHANGE:
  Public: generator matrix A of dimension n
  
  Alice: secret a → computes P_A = A^{⊗a}     // O(n³ log a)
  Bob:   secret b → computes P_B = A^{⊗b}     // O(n³ log b)
  
  Exchange: Alice sends P_A, Bob sends P_B
  
  Alice: K = P_B^{⊗a} = A^{⊗(ab)}            // O(n³ log a)
  Bob:   K = P_A^{⊗b} = A^{⊗(ab)}            // O(n³ log b)
  
  Security: Tropical Discrete Logarithm Problem

Core Definitions (Proof Code)

-- Tropical (min-plus) matrix-vector product
def tropMinPlusMV {n : ℕ} [NeZero n]
    (A : Matrix (Fin n) (Fin n) ℤ) (v : Fin n → ℤ) : Fin n → ℤ :=
  fun i => Finset.univ.inf' Finset.univ_nonempty
    (fun j => A i j + v j)

-- Tropical matrix-matrix multiplication
def tropMinPlusMM {n : ℕ} [NeZero n]
    (A B : Matrix (Fin n) (Fin n) ℤ) : Matrix (Fin n) (Fin n) ℤ :=
  Matrix.of fun i j => Finset.univ.inf' Finset.univ_nonempty
    (fun k => A i k + B k j)

-- Tropical determinant = min-weight perfect matching
def tropicalDeterminant {n : ℕ} [NeZero n]
    (A : Matrix (Fin n) (Fin n) ℤ) : ℤ :=
  Finset.univ.inf' Finset.univ_nonempty
    (fun σ => permutationWeight A σ)

-- Tropical eigenpair
def IsTropicalEigenpair {n : ℕ} [NeZero n]
    (A : Matrix (Fin n) (Fin n) ℤ) (eigval : ℤ)
    (v : Fin n → ℤ) : Prop :=
  ∀ i, tropMinPlusMV A v i = v i + eigval

-- Non-expansiveness (1-Lipschitz bound)
theorem tropMV_component_lipschitz {n : ℕ} [NeZero n]
    (A : Matrix (Fin n) (Fin n) ℤ) (v w : Fin n → ℤ)
    (i : Fin n) :
    (tropMinPlusMV A v i - tropMinPlusMV A w i).natAbs
    ≤ linftyDist v w := by
  -- One-sided bound: A⊗v ≤ A⊗w + ||v-w||∞
  have h_le : ∀ i, tropMinPlusMV A v i ≤
    tropMinPlusMV A w i + linftyDist v w := ...
  -- Symmetric bound: A⊗w ≤ A⊗v + ||v-w||∞
  have h_ge : ∀ i, tropMinPlusMV A w i ≤
    tropMinPlusMV A v i + linftyDist v w := ...
  -- Combine via |x - y| ≤ d

Python: Tropical Matrix Class

class TropicalMatrix:
    def tropical_mul(self, other):
        """(A⊗B)_{ij} = min_k(A_{ik} + B_{kj}). O(n³)."""
        n = self.n
        result = np.full((n, n), np.inf)
        for i in range(n):
            for j in range(n):
                for k in range(n):
                    val = self.data[i,k] + other.data[k,j]
                    result[i,j] = min(result[i,j], val)
        return TropicalMatrix(result)

    def tropical_pow(self, k):
        """Repeated squaring. O(n³ log k)."""
        if k <= 1: return self.copy()
        if k % 2 == 0:
            half = self.tropical_pow(k // 2)
            return half.tropical_mul(half)
        return self.tropical_mul(self.tropical_pow(k-1))

The Tropical Cryptographic Triangle

Three-way bridge connecting Tropical Geometry, Post-Quantum Cryptography, and Lattice Theory

Bridge Connections

Tropical → Cryptography

The idempotency of $\min$ ($\min(a,a) = a$) structurally blocks quantum Fourier transform attacks. No group structure exists for Shor's algorithm to exploit.

Tropical → Lattice

The p-adic valuation $v_p$ maps multiplication to addition: $v_p(ab) = v_p(a) + v_p(b)$. This converts classical matrices to tropical matrices and lattice SVP to tropical eigenvalue computation.

Lattice → Cryptography

Lattice SVP hardness (the basis of NIST post-quantum standards) provides a security reduction for tropical one-way functions via the p-adic bridge.
