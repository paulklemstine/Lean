When Geometry Gets Cheap

How "tropical" mathematics is reshaping cryptography and artificial intelligence

The Shortest Path to a Revolution

Imagine you're planning a road trip across the country. You don't care about the scenic route — you want the cheapest path. At every intersection, you pick whichever road costs less. You never multiply costs; you just pick the minimum and add tolls together.

Without knowing it, you've just done tropical mathematics.

For decades, a strange corner of pure mathematics has been quietly building an alternative universe of geometry — one where "addition" means "pick the smaller number" and "multiplication" means "add them together." Mathematicians call this the min-plus semiring, and the geometry built on top of it goes by the exotic name of tropical geometry.

The Language of Physics, Rewritten

Since the 1800s, physicists have known that the equations governing mechanical systems have a hidden geometric structure. This structure, the symplectic form, captures the relationship between position and momentum. Gromov's non-squeezing theorem (1985) says you can't squeeze a ball through a narrower cylinder, at least not with symplectic transformations.

The new work asks: what happens if you rebuild all of this in the tropical world?

Tropical Non-Squeezing

Define a tropical ball of radius $R$ as the $\ell^\infty$-ball $\{x : |x_i| \leq R\}$. Define a tropical cylinder of radius $r$ as $\{x : |x_0| \leq r\}$. The tropical symplectic capacity $c(B_\infty(R)) = R$ and $c(C(r)) \leq r$.

If $R > r$, no rearranging can fit the ball into the cylinder. The proof reduces to comparing two numbers — but the implication is deep: tropical phase space has genuine rigidity.

From Pure Math to Applications

The same structures that describe symplectic rigidity also appear in lattice-based post-quantum cryptography. The capacity provides a lower bound on lattice distortion, yielding security parameters. And since ReLU networks are tropical objects, the capacity gives certified Lipschitz bounds for neural network robustness.

Research Paper

Abstract

We develop the foundations of tropical symplectic geometry, establishing min-plus analogues of Hamilton's principle, Noether's theorem, and Gromov's non-squeezing theorem. Working over the min-plus semiring $(\mathbb{R}, \min, +)$, we define tropical symplectic forms, tropical symplectomorphisms, and tropical symplectic capacity. We prove $c(B_\infty(R)) = R$, $c(C(r)) \leq r$, and the tropical non-squeezing theorem. All results are machine-verified with zero sorry axioms.

Main Results

Theorem 1: Ball Capacity

For $n \geq 1$ and $R \geq 0$: $c(B_\infty^n(R)) = R$

Proof sketch: Upper bound: any $r$ with $B_\infty(r) \subseteq B_\infty(R)$ satisfies $r \leq R$ (test with $x = (r,...,r)$). Lower bound: $R$ is in the set since $B_\infty(R) \subseteq B_\infty(R)$.

Theorem 2: Tropical Non-Squeezing

For $n \geq 2$, $R > r \geq 0$: $B_\infty^n(R) \not\subseteq C^n(r)$

Proof: The point $x = (R,...,R) \in B_\infty(R)$ but $|x_0| = R > r$, so $x \notin C(r)$.

Theorem 3: Tropical Noether

If $(φ_t)$ preserves $H$, then $H(φ_t(q,p)) = H(q,p)$ for all $t$.

Algorithms

Algorithm 1: Tropical Symplectic Form

def compute_tropical_symplectic_form(q1, p1, q2, p2):
    """ω(q₁,p₁,q₂,p₂) = Σᵢ (p₁ᵢ·q₂ᵢ - q₁ᵢ·p₂ᵢ)
    Time: O(n)  Space: O(1)"""
    return sum(p1[i]*q2[i] - q1[i]*p2[i] for i in range(n))

Algorithm 2: Tropical Capacity via Binary Search

def compute_tropical_capacity(n, membership_test, max_R=1000, tol=1e-6):
    """c(S) = sup{R ≥ 0 : B∞(R) ⊆ S}
    Time: O(n · log(max_R/tol))  Space: O(n)"""
    lo, hi = 0, max_R
    while hi - lo > tol:
        mid = (lo + hi) / 2
        if all(membership_test(corner) for corner in test_corners(mid)):
            lo = mid
        else:
            hi = mid
    return (lo + hi) / 2

Algorithm 3: Non-Squeezing Witness

def find_witness(n, R, r):
    """Find x ∈ B∞(R) \ C(r). Time: O(n)"""
    if R > r and n >= 2:
        return [R] * n  # x = (R,...,R)
    return None

Algorithm 4: Tropical Bellman Iteration

def tropical_bellman(cost_matrix, terminal, max_iter=100):
    """V(q) = min_{q'} {c(q,q') + V(q')}
    Time: O(n² · max_iter)  Space: O(n)"""
    V = terminal.copy()
    for _ in range(max_iter):
        V_new = [min(cost[q][q'] + V[q'] for q') for q]
        if converged(V, V_new): break
        V = V_new
    return V

Applications

Post-Quantum Cryptography

The tropical non-squeezing theorem implies lattice distortion lower bounds. For a lattice scheme with dimension $n$ and ball radius $R$:

$$\text{security} \geq R - \log_2(n) \text{ bits}$$

For Kyber-1024: $n=512, R=512 \Rightarrow$ security $\geq 503$ bits.

Neural Network Robustness

Since ReLU = max(0,x) is a tropical operation, every ReLU network is a tropical polynomial. The tropical capacity gives certified Lipschitz bounds:

$$L \leq \frac{e^c}{d}$$

For capacity $c=5$ in dimension $d=100$: $L \leq 1.48$, guaranteeing input perturbation $\delta$ causes output change $\leq 1.48\delta$.

Reinforcement Learning

The Bellman equation $V(q) = \min_{q'}\{c(q,q') + V(q')\}$ IS the tropical Hamilton-Jacobi equation. Q-learning is tropical calculus.
