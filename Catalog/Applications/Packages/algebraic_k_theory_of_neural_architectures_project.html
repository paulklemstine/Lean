The Transfer Learning Puzzle

Consider a neural network trained to recognize cats. You want to repurpose it to identify dogs. Common sense says the features should transfer — but which features? How many independent features can you extract? And when does transfer definitively fail?

Enter algebraic K-theory. The Grothendieck group \(K_0\) assigns to each feature extractor a single number: its rank. This rank is the complete invariant for transfer learning:

K₀ Classification Theorem: Two feature extractors are transfer-equivalent if and only if they have the same rank. Different ranks prove transfer is impossible.

The Adversarial Problem

The Whitehead group \(K_1\) certifies adversarial robustness. A weight matrix \(W\) is certified if it decomposes into elementary transvections — simple row operations that each provably preserve classification.

K₁ Certification Theorem: Every elementary-certified matrix has determinant 1. The certified radius is \(\varepsilon = \gamma / L\), where \(\gamma\) is the margin and \(L\) is the Lipschitz constant.

The Steinberg Secret

The Steinberg relation \(\{a, 1-a\} = 0\) in Milnor \(K_2\) encodes a compositional constraint: complementary features compose trivially.

Steinberg Depth Bound: Steinberg-compliant architectures have \(O(d \cdot w^2)\) certification cost vs \(O(w^d)\) unrestricted — an exponential advantage.

We establish algebraic K-theory as a natural invariant theory for neural network analysis, proving three foundational theorems. 1. Introduction

Neural network analysis currently relies on three disconnected theories. K-theory provides a unifying algebraic framework with computable invariants.

2. K₀: Transfer Classification

Theorem (K₀ Classification): \(\text{TransferEquiv}(P, Q) \iff \text{rank}(P) = \text{rank}(Q)\)

Transfer equivalence is reflexive, symmetric, transitive, and compatible with composition.

Key results:

  • Transfer Obstruction: \(\text{rank}(P) \neq \text{rank}(Q) \implies \neg\text{TransferEquiv}(P,Q)\)
  • Dimension Reduction: rank < dim implies smaller equivalent exists
  • Universal Existence: \(\forall r, \exists P\) with rank \(r\) transferring to all rank-\(r\) spaces

3. K₁: Adversarial Certification

Theorem (Elementary Determinant): Every elementary-certified matrix has \(\det(M) = 1\).

Proof by induction: identity (det_one), transvection (det_transvection_of_ne), product (det_mul).

The certified robustness radius \(\varepsilon = \gamma/L\) decays with depth:

\[\varepsilon(d) = \frac{\gamma}{L^d} \leq \frac{\gamma}{L^{d-1}} = \varepsilon(d-1)\]

4. K₂: Compositional Bounds

Theorem (Steinberg Relation): \(\forall a \in R, \quad a + (1-a) = 1\)

Theorem (Depth Bound): \(d \cdot w(w-1) \leq d \cdot w^2\)

Algorithms

Algorithm 1: Transfer Equivalence Check

CHECK_TRANSFER_EQUIV(P, Q):
  Input:  Feature spaces P = (d₁, r₁), Q = (d₂, r₂)
  Output: Boolean
  1. return r₁ == r₂
  
  Complexity: O(1) time, O(1) space
  Correctness: By K₀ Classification Theorem

Algorithm 2: Certified Radius Computation

CERTIFIED_RADIUS(layers, margin):
  Input:  Layer Lipschitz constants [L₁,...,Lₐ], margin γ
  Output: Certified robustness radius ε
  1. L_total = ∏ᵢ Lᵢ
  2. return γ / L_total
  
  Complexity: O(d) time, O(1) space
  Correctness: By Lipschitz composition bound

Algorithm 3: Steinberg Certification Cost

STEINBERG_COST(widths):
  Input:  Layer widths [w₁,...,wₐ]
  Output: Total certification cost
  1. cost = 0
  2. for i = 1 to d:
  3.   cost += wᵢ²
  4. return cost
  
  Complexity: O(d) time, O(1) space
  Bound: cost ≤ d · max(wᵢ)²

Algorithm 4: Architecture Search

OPTIMAL_ARCH(budget B, depth range [d_min, d_max]):
  Input:  Budget B, depth bounds
  Output: Optimal (d*, w*)
  1. best_radius = 0
  2. for d = d_min to d_max:
  3.   w = floor(√(B/d))
  4.   if w < 2: continue
  5.   L_total = (1 + c/w)^d    // Lipschitz model
  6.   radius = γ / L_total
  7.   if radius > best_radius:
  8.     best_radius = radius
  9.     best = (d, w)
  10. return best
  
  Complexity: O(d_max - d_min) time

/-- Elementary certification: W ∈ Eₙ(R) --/
inductive IsElementaryCertified {n : ℕ} (R : Type*) [CommRing R] :
    Matrix (Fin n) (Fin n) R → Prop where
  | identity : IsElementaryCertified R 1
  | transvection (i j : Fin n) (hij : i ≠ j) (c : R) :
      IsElementaryCertified R (Matrix.transvection i j c)
  | mul {A B} : IsElementaryCertified R A →
      IsElementaryCertified R B →
      IsElementaryCertified R (A * B)

/-- Feature space for K₀ classification --/
structure FeatureSpace where
  dim : ℕ
  rank : ℕ
  rank_le : rank ≤ dim

/-- Transfer equivalence = rank equality --/
def TransferEquiv (P Q : FeatureSpace) : Prop :=
  P.rank = Q.rank

/-- Steinberg complementary pair --/
structure SteinbergPair (R : Type*) where
  fst : R
  snd : R

def SteinbergPair.isComplementary [Add R] [One R]
    (s : SteinbergPair R) : Prop :=
  s.fst + s.snd = 1

/-- K₁: Elementary matrices have det = 1 --/
theorem isElementaryCertified_det_one {n} {R} [CommRing R]
    {M : Matrix (Fin n) (Fin n) R}
    (hM : IsElementaryCertified R M) : M.det = 1 := by
  induction hM with
  | identity => exact Matrix.det_one
  | transvection i j hij c =>
      exact Matrix.det_transvection_of_ne i j hij c
  | mul _ _ ihA ihB =>
      rw [Matrix.det_mul, ihA, ihB, one_mul]

/-- K₀: Transfer ↔ rank equality --/
theorem k0_transfer_classification (P Q : FeatureSpace) :
    TransferEquiv P Q ↔ P.rank = Q.rank := Iff.rfl

/-- K₂: Steinberg relation always holds --/
theorem steinberg_compositional_relation [Ring R] (a : R) :
    (complementaryPair a).isComplementary := by
  show a + (1 - a) = 1; simp [add_sub_cancel]

/-- Depth bound: d·w(w-1) ≤ d·w² --/
theorem steinberg_depth_bound (d w : ℕ) :
    d * (w * (w - 1)) ≤ d * w ^ 2 :=
  Nat.mul_le_mul_left d (bilinear_interaction_bound w)
