A Different Kind of Distance

Imagine a family tree. Your relationship to your cousin isn't measured in miles — it's measured in how many branches you need to climb to find a common ancestor. Two siblings are "close" (one branch up). Two fourth cousins are "far" (four branches up). And here's the crucial thing: there's no in-between. You're either in someone's immediate family or you're not. The circles never half-overlap.

This is the essence of an ultrametric space — a world where distance satisfies the strong triangle inequality:

$$d(x,z) \leq \max(d(x,y), d(y,z))$$

Unlike ordinary distance where $d(x,z) \leq d(x,y) + d(y,z)$, the ultrametric replaces the sum with a maximum. This single change has profound consequences: in an ultrametric space, closed balls are either nested or completely disjoint. They never partially overlap.

The Problem with Proving AI is Safe

Modern AI systems are spectacularly good at pattern recognition, but we often can't guarantee they'll keep working when conditions change slightly. The mathematical framework for studying this — PAC-Bayes theory — bounds how badly a learning algorithm can fail on new data. The bound depends on a complexity term measuring how many distinct behaviors the model can exhibit.

Traditional complexity is measured using Euclidean covering numbers: how many balls of radius $r$ cover the hypothesis space? For a $d$-dimensional space, you need roughly $(1/r)^d$ balls — a number that explodes exponentially with dimension. Neural networks with billions of parameters make these bounds useless.

The Ultrametric Revolution

In ultrametric spaces, covering numbers equal packing numbers exactly. The greedy algorithm — simply pick separated points — gives an optimal cover. No dimensional blow-up. No exponential explosion. Just combinatorial perfection.

Main Theorem (Cover-Packing Duality): In any ultrametric space, a maximal $r$-separated subset is simultaneously an optimal $r$-cover. The minimum cover cardinality equals the maximum packing cardinality.

Combined with a Lipschitz condition on the loss function, this yields a PAC-Bayes bound where the complexity term is controlled by valuation depth rather than ambient dimension:

$$\text{Bound} = K \cdot r + \frac{\log(\text{cover number at radius } r)}{n}$$

The Tropical Bridge

Perhaps most surprisingly, these results connect to tropical geometry — the mathematics of min-plus algebra. Through a "valuation bridge," tropical margin bounds transport directly into ultrametric robustness certificates. This creates a pipeline:

Tropical confidence → Ultrametric distance → Cover complexity → Generalization guarantee

2. Main Results

▶ Theorem: Ball Center Swap

In an ultrametric space, if $x \in B(c, r)$ then $B(c, r) = B(x, r)$. Every point of a ball is a center.

Proof idea: For $y \in B(c,r)$: $d(y,x) \leq \max(d(y,c), d(c,x)) \leq \max(r,r) = r$. Reverse inclusion is symmetric.

▶ Theorem: Nested or Disjoint Balls

For any $c_1, c_2$ and radius $r$: either $B(c_1, r) = B(c_2, r)$ or $B(c_1, r) \cap B(c_2, r) = \emptyset$.

Proof idea: If intersection is nonempty, pick $x$ in it. Then $B(c_1,r) = B(x,r) = B(c_2,r)$ by the center swap theorem.

▶ Theorem: Cover-Packing Duality (Main)

Any maximal $r$-separated subset $S$ of target is an optimal $r$-cover, and $|S| \leq |C|$ for any cover $C$.

Part 1: If $x$ is not covered, $S \cup \{x\}$ is still separated, contradicting maximality.

Part 2: Map each $s \in S$ to its covering center $c \in C$. If $f(s_1) = f(s_2)$, then $d(s_1,s_2) \leq \max(d(s_1,c), d(s_2,c)) \leq r$, contradicting separation.

▶ Theorem: PAC-Bayes Lipschitz Certified Robustness

For $K$-Lipschitz loss and $r$-cover centers:

$$\forall h \in \text{supp}(\rho), \exists c \in \text{centers}: |\ell(h,z) - \ell(c,z)| \leq K \cdot r$$

Combined with the cover bound: complexity $= K \cdot r + \log(|\text{cover}|) / n$.

▶ Theorem: Tropical-Ultrametric Transfer

If the posterior image under the bridge has diameter $\leq R$:

$$\exists c \in H, \forall t \in \text{supp}(\rho), \forall z: |\ell(f(t),z) - \ell(c,z)| \leq K \cdot R$$

Algorithms

Greedy Ultrametric Cover (O(n²))

def greedy_ultra_cover(space, r, target):
    """
    Find maximal r-separated subset = optimal r-cover.
    
    In ultrametric spaces, this greedy algorithm is OPTIMAL
    (not just an approximation).
    
    Time: O(n²)  Space: O(n)
    """
    separated = []
    for x in target:
        if all(dist(x, s) > r for s in separated):
            separated.append(x)
    return separated

PAC-Bayes Bound Computation

def pac_bayes_bound(space, loss, K, r, n_samples, posterior):
    """
    Compute: K·r + log(cover_number) / n
    
    1. Find r-cover using greedy algorithm
    2. Perturbation term: K * r
    3. Complexity term: log(|cover|) / n  
    4. Total bound = sum
    """
    centers = greedy_ultra_cover(space, r, posterior.support)
    perturbation = K * r
    complexity = log(len(centers)) / n_samples
    return perturbation + complexity

Transport Posterior

def transport_posterior(f, source):
    """
    Push forward distribution along map f.
    Fiber aggregation: w'(b) = Σ_{a: f(a)=b} w(a)
    """
    new_weights = {}
    for a in source.support:
        b = f(a)
        new_weights[b] = new_weights.get(b, 0) + source.weight(a)
    return FiniteHypDist(new_weights)
