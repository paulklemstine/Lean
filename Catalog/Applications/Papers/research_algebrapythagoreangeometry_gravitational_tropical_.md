# Tropical Arithmetic Lensing on the Berggren Tree: Caustic Rigidity and Certified Factor Reconstruction

## Abstract

We develop a novel formal bridge between the Berggren tree of primitive Pythagorean triples, tropical (min-plus) path actions, and arithmetic reconstruction of prime factorization signatures. The central construction is the **prime interaction profile**, which records the primes appearing as common factors of an integer and hypotenuses of Berggren-tree triples. We prove three main results: (1) **functoriality and monotonicity** of tropical lens actions under Berggren child maps and height function domination; (2) **caustic rigidity**: equality of prime interaction profiles over sufficient probe sets forces equality of prime factor supports; and (3) a **certified reconstruction algorithm** that extracts prime factor candidates from the profile with formal soundness and exactness guarantees. All results are machine-verified in Lean 4 with Mathlib, constituting the first formalization of tropical arithmetic inverse problems on canonical number-theoretic trees.

**Keywords**: tropical arithmetic lensing, Berggren tree, primitive Pythagorean triples, min-plus geometry, caustic rigidity, arithmetic inverse problems, certified factor reconstruction, formal verification

## 1. Introduction

### 1.1 Motivation

The Berggren tree organizes all primitive Pythagorean triples into a ternary tree rooted at (3, 4, 5), with children generated by three integer-linear transformations [Berggren 1934, Barning 1963, Hall 1970]. The tree is exhaustive (every primitive triple appears exactly once) and structurally rich: hypotenuses grow strictly at every step, determinants of the generating matrices reveal a parity grading, and the generators belong to the integer Lorentz group O(2,1;ℤ).

Tropical (min-plus) geometry replaces ordinary addition with minimization and ordinary multiplication with addition. This framework arises naturally in optimization, shortest-path algorithms, and algebraic geometry over non-archimedean fields. The valuation map v_p: ℤ_p* → ℤ is a homomorphism from multiplicative to additive structure — a "tropical functor" that converts divisibility into order.

Our key observation is that these two structures can be combined: the Berggren tree provides a canonical weighted graph (weighted by hypotenuse height), and tropical path actions on this graph encode arithmetic information about integers through their prime interaction with tree nodes.

### 1.2 Contributions

1. **Formal definitions** of tropical lens actions, caustic profiles, and prime interaction profiles on the Berggren tree (§3–4).
2. **Structural theorems**: Berggren child maps preserve the Pythagorean property and strictly increase hypotenuses; tropical lens actions are monotone under height domination and functorial under child maps (§5).
3. **Caustic rigidity theorem**: equal prime interaction profiles over sufficient probe sets imply equal prime factor supports, with specialization to the squarefree regime (§6).
4. **Certified reconstruction**: a sound and exact algorithm for extracting prime factor candidates from interaction profiles (§7).
5. **Machine verification**: all definitions and proofs formalized in Lean 4 with Mathlib, using only standard axioms (propext, Classical.choice, Quot.sound) (§8).

### 1.3 Related Work

**Berggren tree**: The ternary tree structure was discovered independently by Berggren [1934] and Barning [1963]. Its connection to the Lorentz group was noted by several authors. Our formalization builds on catalog results establishing Pythagorean preservation, determinant structure, and hypotenuse growth bounds.

**Tropical geometry**: The min-plus semiring structure and its connections to valuation theory are well-established [Maclagan-Sturmfels 2015]. Our work uses the tropical semiring certificate infrastructure from the TropicalValuationFunctor module, which establishes commutativity, associativity, and distributivity of min-plus operations.

**Factorization algorithms**: Trial division, Pollard's rho, quadratic sieve, and number field sieve are standard. Our reconstruction algorithm is not competitive in complexity but provides formal soundness guarantees absent from traditional implementations.

## 2. Preliminaries

### 2.1 Pythagorean Triples and the Berggren Tree

A triple (a, b, c) ∈ ℤ³ is **Pythagorean** if a² + b² = c². It is **primitive** if gcd(a, b) = 1 (equivalently, gcd(a, b, c) = 1).

The **Berggren child maps** are:
- **A**: (a,b,c) ↦ (a−2b+2c, 2a−b+2c, 2a−2b+3c)
- **B**: (a,b,c) ↦ (a+2b+2c, 2a+b+2c, 2a+2b+3c)
- **C**: (a,b,c) ↦ (−a+2b+2c, −2a+b+2c, −2a+2b+3c)

**Theorem (Berggren)**: Starting from (3, 4, 5), repeated application of A, B, C generates every primitive Pythagorean triple with positive entries exactly once.

### 2.2 Tropical Semiring

The **tropical semiring** (ℕ, min, +) satisfies:
- min(a, b) = min(b, a) (commutativity)
- min(a, min(b, c)) = min(min(a, b), c) (associativity)
- a + min(b, c) = min(a+b, a+c) (distributivity)
- min(a, a) = a (idempotency)

### 2.3 Prime Factorization

For n ∈ ℕ with n ≠ 0, the **prime support** is primeFactors(n) = {p : p prime, p | n}. For squarefree n, the prime support completely determines the number up to permutation of factors.

## 3. Definitions

### 3.1 Height Potentials

**Definition 3.1** (Hypotenuse Height). For a triple t = (a, b, c), the hypotenuse height is H(t) = |c|.

**Definition 3.2** (Perimeter Height). H_per(t) = |a| + |b| + |c|.

### 3.2 Tropical Lens Action

**Definition 3.3** (Tropical Lens Action). For a height function H: α → ℕ and a path p = [t₁, ..., tₖ], the tropical lens action is:

$$\text{tropicalLensAction}(H, p) = \sum_{i=1}^{k} H(t_i)$$

### 3.3 Caustic Height Profile

**Definition 3.4** (Caustic Height Profile). For a finite set S and height function H, the caustic height profile is:

$$\text{causticHeightProfile}(H, S) = \{H(s) : s \in S\}$$

### 3.4 Profile Order

**Definition 3.5** (Profile Partial Order). P₁ ≤ P₂ if for every x ∈ P₁, there exists y ∈ P₂ with x ≤ y.

### 3.5 Prime Interaction Profile

**Definition 3.6** (Prime Interaction Profile). For n ∈ ℕ and a probe set S ⊆ ℕ:

$$\text{primeInteractionProfile}(n, S) = \bigcup_{s \in S} \text{primeFactors}(\gcd(n, s))$$

### 3.6 Sufficient Probe Set

**Definition 3.7** (Sufficient Probe Set). S is sufficient for n if for every prime p | n, there exists s ∈ S with p | s.

### 3.7 Reconstruction

**Definition 3.8** (Reconstruction). reconstructCandidates(prof) = {p ∈ prof : p prime}.

## 4. Main Results

### 4.1 Pythagorean Preservation

**Theorem 4.1** (Child Map Preservation). Each Berggren child map preserves the Pythagorean property: if a² + b² = c², then the child triple (a', b', c') satisfies a'² + b'² = c'².

*Proof sketch*: Direct algebraic verification. For child A: (a−2b+2c)² + (2a−b+2c)² = (2a−2b+3c)² expands to a² + b² + c² terms that cancel using the Pythagorean relation. Verified by nlinarith in Lean. □

### 4.2 Hypotenuse Growth

**Theorem 4.2** (Strict Hypotenuse Growth). For positive Pythagorean triples (a, b, c) with a, b, c > 0 and a² + b² = c², every Berggren child has strictly larger hypotenuse than the parent.

*Proof*: 
- Child A: c' = 2a − 2b + 3c. We need c' > c, i.e., 2(a − b + c) > 0. Since c² = a² + b² > b² and c, b > 0, we have c > b. Combined with a > 0, we get a − b + c > 0.
- Child B: c' = 2a + 2b + 3c > 3c > c. Immediate from positivity.
- Child C: c' = −2a + 2b + 3c. We need 2(b − a + c) > 0. Since c > a (analogous to above) and b > 0, this holds.

*Formal proof*: nlinarith with auxiliary inequality sq_nonneg(c − b) for A, sq_nonneg(c − a) for C. □

### 4.3 Tropical Action Properties

**Theorem 4.3** (Additivity). tropicalLensAction(H, p ++ q) = tropicalLensAction(H, p) + tropicalLensAction(H, q).

**Theorem 4.4** (Monotonicity). If H₁(x) ≤ H₂(x) for all x, then tropicalLensAction(H₁, path) ≤ tropicalLensAction(H₂, path).

**Theorem 4.5** (Functoriality). If H(x) ≤ H(f(x)) for all x, then tropicalLensAction(H, path) ≤ tropicalLensAction(H, path.map f).

*Proof of 4.4*: By induction on path length. The base case is trivial. For the inductive step, tropicalLensAction(H₁, x :: xs) = H₁(x) + tropicalLensAction(H₁, xs) ≤ H₂(x) + tropicalLensAction(H₂, xs) = tropicalLensAction(H₂, x :: xs). □

*Significance*: Theorem 4.5, applied to Berggren child maps (which increase hypotenuse by Theorem 4.2), gives: descending into the tree always increases the tropical cost. This is the discrete analogue of the gravitational lensing principle that a denser mass distribution produces stronger light deflection.

### 4.4 Profile Monotonicity

**Theorem 4.6** (Profile Monotonicity). If H₁ ≤ H₂ pointwise, then causticHeightProfile(H₁, S) ≤ causticHeightProfile(H₂, S) in the profile order.

*Proof*: For x ∈ causticHeightProfile(H₁, S), there exists s ∈ S with H₁(s) = x. Take y = H₂(s) ∈ causticHeightProfile(H₂, S). Then x = H₁(s) ≤ H₂(s) = y. □

### 4.5 Caustic Rigidity

**Theorem 4.7** (Visibility). If p is prime, p | n, n ≠ 0, s ∈ S, and p | s, then p ∈ primeInteractionProfile(n, S).

*Proof*: p | n and p | s imply p | gcd(n, s). Since gcd(n, s) ≠ 0 (as n ≠ 0) and p is prime, p ∈ primeFactors(gcd(n, s)) ⊆ primeInteractionProfile(n, S). □

**Theorem 4.8** (Faithfulness). If n ≠ 0, then primeInteractionProfile(n, S) ⊆ primeFactors(n).

*Proof*: If p ∈ primeInteractionProfile(n, S), then p ∈ primeFactors(gcd(n, s)) for some s, so p | gcd(n, s) | n, hence p ∈ primeFactors(n). □

**Theorem 4.9** (Profile Characterization). If S is sufficient for n and n ≠ 0, then primeInteractionProfile(n, S) = primeFactors(n).

*Proof*: Combines Theorems 4.7 and 4.8: sufficiency gives ⊇ via visibility, and faithfulness gives ⊆. □

**Theorem 4.10** (Caustic Rigidity). If n, m ≠ 0, S is sufficient for both n and m, all elements of S are nonzero, and primeInteractionProfile(n, S) = primeInteractionProfile(m, S), then primeFactors(n) = primeFactors(m).

*Proof*: By Theorem 4.9, primeInteractionProfile(n, S) = primeFactors(n) and primeInteractionProfile(m, S) = primeFactors(m). The hypothesis gives primeFactors(n) = primeFactors(m). □

**Corollary 4.11** (Squarefree Rigidity). Under the hypotheses of Theorem 4.10, if additionally n and m are squarefree, then primeFactors(n) = primeFactors(m).

*Note*: In the squarefree case, primeFactors determines the number up to reordering of factors. This is the strongest form of arithmetic reconstruction from tropical data.

### 4.6 Certified Reconstruction

**Theorem 4.12** (Soundness). If S is sufficient for n and n ≠ 0, then primeFactors(n) ⊆ reconstructCandidates(primeInteractionProfile(n, S)).

*Proof*: By Theorem 4.9, the profile equals primeFactors(n). Every element of primeFactors(n) is prime, so it passes the filter in reconstructCandidates. □

**Theorem 4.13** (Exactness). Under the same hypotheses, reconstructCandidates(primeInteractionProfile(n, S)) = primeFactors(n).

*Proof*: Soundness gives ⊇. For ⊆: elements of reconstructCandidates are elements of the profile that are prime. By faithfulness (Theorem 4.8), profile elements divide n. Being prime and dividing n, they are in primeFactors(n). □

**Theorem 4.14** (Boundedness). For any profile, the candidate set has a finite upper bound.

*Proof*: Finsets in Lean are inherently finite and bounded. □

## 5. Algorithms

### 5.1 Prime Interaction Profile Computation

```
Algorithm: ComputePrimeInteractionProfile(n, S)
Input:  n ∈ ℕ, probe set S ⊂ ℕ (finite)
Output: Finset of primes

profile ← ∅
for s ∈ S:
    g ← gcd(n, s)
    profile ← profile ∪ primeFactors(g)
return profile

Complexity: O(|S| · (log n + log(max S))) for gcd computations,
            plus O(|S| · √(max S)) for factoring gcd values.
```

### 5.2 Berggren Tree Probe Set Generation

```
Algorithm: GenerateProbeSet(depth)
Input:  depth D ∈ ℕ
Output: Finset of hypotenuses from Berggren tree up to depth D

queue ← [(3, 4, 5)]
probes ← {5}
for d = 1 to D:
    next ← []
    for (a, b, c) ∈ queue:
        for child ∈ {childA, childB, childC}:
            (a', b', c') ← child(a, b, c)
            next.append((a', b', c'))
            probes.add(c')
    queue ← next
return probes

Complexity: O(3^D) time and space.
```

### 5.3 Certified Factor Reconstruction

```
Algorithm: CertifiedReconstruction(n, depth)
Input:  n ∈ ℕ, depth D ∈ ℕ
Output: Finset of candidate prime factors (with soundness certificate)

S ← GenerateProbeSet(D)
profile ← ComputePrimeInteractionProfile(n, S)
candidates ← {p ∈ profile : isPrime(p)}
return candidates

Soundness: If IsSufficientProbeSet(n, S), then
           primeFactors(n) ⊆ candidates = primeFactors(n).
Complexity: O(3^D · log n) total.
```

## 7. Discussion

### 7.1 Significance

The caustic rigidity theorem establishes that prime factorization data is encoded in a tropical geometric invariant on a canonical arithmetic tree. This is, to our knowledge, the first formal result connecting tropical path actions on Pythagorean triple spaces to number-theoretic inverse problems.

### 7.2 Limitations

1. **Probe set sufficiency**: The theorem requires the probe set to be sufficient, meaning every prime factor of n must divide some hypotenuse in the tree. Not all primes appear as hypotenuse factors of primitive Pythagorean triples (only primes ≡ 1 mod 4, plus those dividing leg products). The sufficiency condition must be verified for each application.

2. **Computational complexity**: The probe set grows as O(3^D) with tree depth, making the algorithm impractical for large n compared to standard factoring methods.

3. **Support vs. multiplicity**: The current framework recovers only the prime support (which primes divide n), not the full factorization (how many times each prime divides n). Extension to multiplicity recovery is a natural next step (see Future Work).

### 7.3 Connections to Other Domains

**Tropical geometry**: The framework uses the min-plus semiring structure established in the TropicalValuationFunctor and TropicalOneWayFunctions modules. The monotonicity and distributivity of min-plus operations are essential for the profile comparison principle.

**Lorentz group**: The Berggren matrices belong to O(2,1;ℤ) and preserve the Lorentz form a² + b² − c² = 0. The Pythagorean preservation theorem follows from this symmetry. The connection to Lorentz geometry could enable extensions to higher-dimensional tropical lensing.

**Certified computation**: All results are machine-verified, providing a level of certainty absent from informal mathematical arguments. The reconstruction algorithm comes with formal soundness and exactness certificates.
