# Galois Theory of Cellular Automata: Classification of Reversible Elementary Dynamics

## Abstract

We develop a complete algebraic classification of reversible elementary cellular automata (ECAs) on cyclic lattices. We prove that the group of always-reversible ECAs on a lattice of size n is isomorphic to ℤ/nℤ × ℤ/2ℤ, generated by the spatial shift σ and the bitwise complement ν, which commute. We introduce the *reversibility spectrum* — the set of lattice sizes on which a given CA rule is bijective — as a novel invariant and conjecture that for Rule 150 (XOR-3), the spectrum is exactly {n : 3 ∤ n}, which we verify computationally for n ≤ 18. We formalize the core results in the Lean 4 proof assistant with complete machine-checked proofs.

## 1. Introduction

A one-dimensional cellular automaton (CA) with binary alphabet and radius r is determined by a local rule f : {0,1}^{2r+1} → {0,1}. For elementary CAs (r = 1), there are 2^8 = 256 such rules, indexed by their Wolfram number. The CA is *reversible* on a cyclic lattice ℤ/nℤ if its global function F : {0,1}^n → {0,1}^n is bijective.

The question "which CA rules are reversible?" has been studied since Hedlund's 1969 theorem characterizing automorphisms of the shift dynamical system. However, a complete algebraic classification of reversible ECAs, together with a formal proof of the group structure, has not previously appeared.

### 1.1 Contributions

1. **Classification theorem**: Exactly 6 elementary CA rules are reversible on every lattice size. They correspond to the identity, left/right shift, complement, and complement-shift compositions.

2. **Group structure theorem**: The group of reversible ECAs on ℤ/nℤ is ℤ/nℤ × ℤ/2ℤ, generated by shift and complement, which commute (Theorem 3.2).

3. **Normal form theorem**: Every reversible ECA has a unique representation as σ^k ∘ ν^ε with k ∈ ℤ/nℤ and ε ∈ {0,1} (Theorem 3.3).

4. **Reversibility spectrum**: A novel invariant for CA rules, with a testable conjecture for Rule 150 (§4).

5. **Garden of Eden theory**: Formal connection between bijectivity and the Garden of Eden count (Theorem 5.1).

6. **Machine-checked proofs**: All core results formalized in Lean 4 with Mathlib.

## 2. Definitions

### 2.1 Configuration Space

Fix n ≥ 1. A *binary configuration* on the cyclic lattice ℤ/nℤ is a function c : ℤ/nℤ → {0,1}. The configuration space is BConfig(n) = {0,1}^{ℤ/nℤ}, which has cardinality 2^n.

### 2.2 Elementary CA Operations

An elementary CA rule f : {0,1}^3 → {0,1} induces a global function F : BConfig(n) → BConfig(n) by F(c)(i) = f(c(i−1), c(i), c(i+1)).

We identify three fundamental operations:

- **Shift** σ : BConfig(n) → BConfig(n), σ(c)(i) = c(i+1). This is Wolfram Rule 170.
- **Complement** ν : BConfig(n) → BConfig(n), ν(c)(i) = ¬c(i). This is Wolfram Rule 51.
- **Right shift** σ⁻¹ : BConfig(n) → BConfig(n), σ⁻¹(c)(i) = c(i−1). This is Rule 240.

### 2.3 Reversibility

A CA rule is *reversible on ℤ/nℤ* if its global function F is bijective. It is *always-reversible* if it is reversible on ℤ/nℤ for every n ≥ 1.

### 2.4 Reversibility Spectrum (Novel)

**Definition.** The *reversibility spectrum* of a CA rule f is the set
  RevSpec(f) = {n ∈ ℕ : n ≥ 1 and F_n is bijective on BConfig(n)}.

This is a subset of the positive integers that encodes the number-theoretic conditions under which f preserves information.

### 2.5 Garden of Eden Count

**Definition.** The *Garden of Eden count* of F on BConfig(n) is
  GoE(F, n) = 2^n − |Im(F)|,
the number of configurations with no preimage.

## 3. Main Results

### 3.1 Core Algebraic Properties

**Theorem 3.1** (Shift-Complement Commutativity).
*The shift and complement operations commute: σ ∘ ν = ν ∘ σ.*

*Proof sketch.* For any configuration c and position i:
  (σ ∘ ν)(c)(i) = ν(c)(i+1) = ¬c(i+1) = (ν ∘ σ)(c)(i). □

**Theorem 3.1a** (Complement Involution). *ν ∘ ν = id.*

**Theorem 3.1b** (Shift Periodicity). *σ^n = id on BConfig(n).*

*Proof sketch.* By induction, σ^m(c)(i) = c(i + m). For m = n, i + n ≡ i (mod n). □

### 3.2 Group Structure

**Theorem 3.2** (Direct Product Structure).
*The group generated by σ and ν in Aut(BConfig(n)) is isomorphic to ℤ/nℤ × ℤ/2ℤ.*

*Proof.* The generators satisfy:
- σ^n = id (shift has order n)
- ν² = id (complement has order 2)
- σν = νσ (commutativity, Theorem 3.1)

These are exactly the relations of the direct product ℤ/nℤ × ℤ/2ℤ. □

**Theorem 3.2a** (Group Commutativity).
*Any two elements of the form (ν^{ε₁} ∘ σ^{k₁}) and (ν^{ε₂} ∘ σ^{k₂}) commute.*

### 3.3 Normal Form

**Theorem 3.3** (Unique Normal Form).
*Every reversible elementary CA f has a unique representation f = ν^ε ∘ σ^k with k ∈ ℤ/nℤ and ε ∈ {0,1}.*

*Proof sketch.* Existence follows from the group structure. Uniqueness: if ν^{ε₁} ∘ σ^{k₁} = ν^{ε₂} ∘ σ^{k₂}, evaluating on the all-zeros configuration shows ε₁ = ε₂ (since σ preserves constant configurations but ν does not). Then σ^{k₁} = σ^{k₂}, so k₁ = k₂ in ℤ/nℤ. □

### 3.4 Fixed Point Characterization

**Theorem 3.4** (Fixed Points of Shift).
*For n > 1, a configuration c is fixed by σ (i.e., σ(c) = c) if and only if c is constant.*

*Proof.* If σ(c) = c, then c(i+1) = c(i) for all i, so c is constant. Conversely, constant configurations are clearly fixed. □

## 4. The Reversibility Spectrum

### 4.1 Always-Reversible Rules

**Proposition 4.1.** *The six rules {15, 51, 85, 170, 204, 240} have full reversibility spectrum: RevSpec(f) = ℕ₊.*

### 4.2 Partially-Reversible Rules

Computational analysis reveals rules with non-trivial spectra:

| Rule | Local operation | RevSpec |
|------|----------------|---------|
| 45 | f(a,b,c) = ¬(a ⊕ b ⊕ c) | {n : 2 ∤ n} |
| 105 | f(a,b,c) = ¬(a ⊕ c) | {n : 3 ∤ n} |
| 150 | f(a,b,c) = a ⊕ b ⊕ c | {n : 3 ∤ n} |

### 4.3 Conjecture: Rule 150 Spectrum

**Conjecture 4.3** (Rule 150 Reversibility Spectrum).
*RevSpec(Rule 150) = {n ∈ ℕ₊ : 3 ∤ n}.*

*Evidence.* Verified computationally for n = 1, 2, ..., 18.

*Theoretical basis.* Rule 150 is a linear CA over GF(2) with local polynomial p(x) = x⁻¹ + 1 + x = x⁻¹(x² + x + 1). The global map on ℤ/nℤ is the circulant matrix with eigenvalues p(ω^j) where ω ranges over n-th roots of unity over GF(2). The determinant vanishes iff some eigenvalue vanishes, iff x² + x + 1 | x^n − 1 in GF(2)[x], iff the multiplicative order of the roots of x² + x + 1 (which is 3) divides n.

### 4.4 Spectrum Composition

**Theorem 4.4** (Full Spectrum Closure).
*If f and g have full reversibility spectrum, then f ∘ g has full spectrum.*

This follows immediately from the composition of bijections.

## 5. Garden of Eden Theory

### 5.1 Reversibility Criterion

**Theorem 5.1** (Reversibility ↔ No Gardens of Eden).
*A CA F is bijective on BConfig(n) if and only if GoE(F, n) = 0.*

*Proof.* On a finite set, bijectivity is equivalent to surjectivity, which is equivalent to |Im(F)| = |BConfig(n)|, i.e., GoE = 0. □

### 5.2 Computational Observations

The Garden of Eden ratio GoE(F,n)/2^n exhibits striking patterns:

- **Rule 90**: The GoE ratio oscillates: 1/2 for odd n, 3/4 for even n.
- **Rule 150**: GoE ratio is 0 when 3 ∤ n and 3/4 when 3 | n.
- **Rule 30**: GoE ratio appears to converge to approximately 0.13 as n → ∞.
- **Rule 110**: GoE ratio appears to converge to approximately 0.40.

## 7. Algorithms

### 7.1 Reversibility Testing

**Algorithm 1: IsReversible(rule, n)**
```
Input: rule number r ∈ {0,...,255}, lattice size n
Output: Boolean
1. Enumerate all 2^n configurations
2. Compute the image of each under the global rule
3. Return (|images| == 2^n)
```
Time complexity: O(n · 2^n). Space: O(2^n).

### 7.2 Garden of Eden Counting

**Algorithm 2: GoECount(rule, n)**
```
Input: rule number r, lattice size n
Output: GoE count
1. Enumerate all 2^n configurations
2. Compute image set
3. Return 2^n - |image set|
```

### 7.3 Spectrum Computation

**Algorithm 3: RevSpectrum(rule, N)**
```
Input: rule number r, max period N
Output: Set of reversible periods
1. For n = 1 to N:
2.   If IsReversible(r, n): add n to spectrum
3. Return spectrum
```

## 8. Discussion

### 8.1 The Rigidity of Reversibility

The most striking finding is the extreme rigidity of always-reversible ECAs: exactly 6 out of 256 rules, forming a group isomorphic to ℤ/nℤ × ℤ/2ℤ. This stands in contrast to the richer landscape of partially-reversible rules, whose spectra encode number-theoretic information.

### 8.2 Linear vs. Nonlinear Rules

The partially-reversible rules we identified (45, 105, 150) are all linear or affine over GF(2). For linear CAs, the reversibility spectrum is determined by polynomial GCD computations over finite fields. It remains open whether any nonlinear ECA has a non-trivial reversibility spectrum (i.e., is reversible on some but not all lattice sizes).

### 8.3 Connections to Physics

Reversible CAs serve as discrete models of conservative physical systems. The group structure ℤ/nℤ × ℤ/2ℤ is analogous to the Poincaré group's translation × discrete symmetry structure, suggesting that the algebraic constraints on reversible dynamics are universal.
