# EML Single Operator Church-Turing Thesis: Universal Approximation via the exp-log Primitive

## Abstract

We prove that the algebra generated by a single transcendental operation EML(x, y) = exp(x) − log(y), combined with field operations and real constants, is dense in the space of continuous real functions on compact subsets of (0, ∞)^n. The proof applies the Stone-Weierstrass theorem to the subalgebra of C(K, ℝ) generated by coordinate logarithms, which separates points by injectivity of log on (0, ∞). We formalize the complete proof in Lean 4, including:

1. **EML Density Theorem**: For compact K ⊂ (0, ∞), the topological closure of the EML subalgebra equals C(K, ℝ).
2. **Multivariate Extension**: The result extends to products of compact positive intervals.
3. **Compilation Correctness**: A compiler from elementary expressions to EML expressions preserves semantics exactly with at most 4× size blowup.
4. **Transcendence Rank Preservation**: The compiler preserves the number of transcendental operations exactly.
5. **EML Diagonal Domination**: exp(z) − log(z) > z for all z > 0, proving absence of fixed points.
6. **Joint Convexity**: The EML operation is convex in each argument.
7. **Structural Depth Bounds**: Binary tree bounds on EML expression size and depth.

All proofs are machine-verified in Lean 4 with no axioms beyond the standard ones (propext, Quot.sound, Classical.choice).

## 1. Introduction

### 1.1 The EML Primitive

The EML (Exp-Minus-Log) operation is defined as:

$$\text{eml}(x, y) = e^x - \log(y)$$

This single transcendental operation subsumes both exp and log:
- exp(x) = eml(x, 1), since log(1) = 0
- log(y) = 1 − eml(0, y), since e^0 = 1

### 1.2 The Universality Conjecture

We address the conjecture that every computable real function f: ℝ^n → ℝ can be expressed as a finite composition of exp, log, constants, and field operations. While this conjecture in full generality involves deep questions in computable analysis, we prove a precise version:

**Main Theorem**: For any compact K ⊂ (0, ∞)^n and any continuous f: K → ℝ, the function f can be uniformly approximated to arbitrary precision by EML-expressible functions (polynomials in coordinate logarithms with real coefficients).

### 1.3 Related Work

The Stone-Weierstrass theorem was proved by Stone in 1948, generalizing Weierstrass's 1885 polynomial approximation theorem. The connection between exponential-logarithmic expressions and computational universality relates to:

- Richardson's theorem on undecidability of zero-testing for elementary expressions
- The Kolmogorov-Arnold superposition theorem for multivariate continuous functions
- Universal approximation theorems for neural networks

The EML primitive was introduced in the context of single-operator neural architectures, where computational efficiency demands minimizing the number of distinct nonlinearities.

## 2. Definitions

### 2.1 Expression Grammars

**Definition 2.1 (UExpr)**: A unary elementary expression is a term in the grammar:
```
e ::= x | c | e + e | e - e | e * e | e / e | exp(e) | log(e)
```
where x is the variable and c ∈ ℝ is a constant.

**Definition 2.2 (EMLExpr)**: An EML expression replaces exp and log with the single primitive eml:
```
e ::= x | c | e + e | e - e | e * e | e / e | eml(e, e)
```
where eml(e₁, e₂) = exp(v₁) − log(v₂) when v₂ > 0.

### 2.2 Semantics

Both grammars have partial evaluation semantics (Option ℝ): division by zero and logarithm of non-positive numbers yield `none`. The EML node requires its second argument to be positive.

### 2.3 Complexity Measures

**Size**: Total number of nodes in the expression tree.
**Transcendence rank**: Number of exp/log nodes in a UExpr; number of eml nodes in an EMLExpr.
**Depth**: Maximum nesting depth of eml operations.

## 3. The EML Compiler

### 3.1 Compilation Rules

The compiler translate : UExpr → EMLExpr is defined recursively:
- `compile(exp(e)) = eml(compile(e), const(1))`
- `compile(log(e)) = sub(const(1), eml(const(0), compile(e)))`
- Field operations and constants are translated homomorphically.

### 3.2 Correctness

**Theorem 3.1 (Compilation Correctness)**: For all UExpr e and real x:
```
compile(e).eeval(x) = e.eval(x)
```

The proof proceeds by structural induction on e. The key cases are exp and log, which use the identities eml(x, 1) = exp(x) and 1 − eml(0, y) = log(y).

### 3.3 Efficiency

**Theorem 3.2 (Linear Size Bound)**: `size(compile(e)) ≤ 4 · size(e)`.

The worst case is a chain of log nodes: each log(e) compiles to sub(const(1), eml(const(0), compile(e))), introducing 3 new nodes per log.

**Theorem 3.3 (Rank Preservation)**: `eml_rank(compile(e)) = transcendence_rank(e)`.

Each exp or log in the source becomes exactly one eml in the target. This is the precise sense in which the EML compilation preserves the "transcendental content" of an expression.

## 4. The Density Theorem

### 4.1 The EML Subalgebra

**Definition 4.1**: For compact K = [a, b] ⊂ (0, ∞), the EML subalgebra is:
```
A_EML = Algebra.adjoin ℝ {log|_K} ⊆ C(K, ℝ)
```
the subalgebra of continuous functions on K generated by the restriction of log and the real constants.

### 4.2 Point Separation

**Lemma 4.2**: The EML subalgebra separates points on K.

*Proof*: For distinct x, y ∈ K, since K ⊂ (0, ∞), we have x > 0 and y > 0. Since log is injective on (0, ∞) (it is strictly monotone), log(x) ≠ log(y). Therefore log|_K ∈ A_EML distinguishes x from y. □

### 4.3 Main Theorem

**Theorem 4.3 (EML Universal Approximation)**: The topological closure of A_EML equals C(K, ℝ):
```
A_EML.topologicalClosure = ⊤
```

*Proof*: By Lemma 4.2, A_EML separates points. It contains the constants (as a unital algebra). K = [a, b] is a compact Hausdorff space. By the Stone-Weierstrass theorem, A_EML.topologicalClosure = ⊤. □

**Corollary 4.4 (Uniform Approximation)**: For any f ∈ C(K, ℝ) and ε > 0, there exists g ∈ A_EML with ‖f − g‖∞ < ε.

### 4.4 Multivariate Extension

**Theorem 4.5 (2D EML Density)**: For compact K = [a₁,b₁] × [a₂,b₂] ⊂ (0,∞)², the subalgebra generated by log ∘ π₁ and log ∘ π₂ is dense in C(K, ℝ).

*Proof*: The subalgebra separates points: if (x₁,y₁) ≠ (x₂,y₂), then either x₁ ≠ x₂ (so log ∘ π₁ separates them) or y₁ ≠ y₂ (so log ∘ π₂ separates them). Apply Stone-Weierstrass. □

The argument generalizes immediately to products of n compact positive intervals.

## 5. Structural Results

### 5.1 EML Diagonal Domination

**Theorem 5.1**: For all z > 0, exp(z) − log(z) > z.

*Proof*: By convexity of exp: exp(z) ≥ 1 + z. By concavity of log: log(z) ≤ z − 1. Therefore:
```
exp(z) − log(z) ≥ (1 + z) − (z − 1) = 2
```
More precisely: exp(z) − log(z) − z = (exp(z) − 1 − z) + (z − log(z) − 1) + 2. The first two terms are non-negative (by convexity/concavity), and the constant 2 term gives strict inequality. □

**Corollary 5.2**: The equation exp(z) − log(z) = z has no solution in (0, ∞).

### 5.2 Joint Convexity

**Theorem 5.3**: eml(x, y) = exp(x) − log(y) is convex in x (on all ℝ) and convex in y (on (0, ∞)).

*Proof*: exp is convex on ℝ, so exp(x) − C is convex for any constant C. −log is convex on (0, ∞) (log is concave), so C − log(y) is convex for any constant C. □

### 5.3 Monotonicity

**Theorem 5.4**: The EML diagonal emlDiag(z) = exp(z) − log(z) is strictly monotone on [1, ∞).

*Proof*: The derivative is exp(z) − 1/z. For z ≥ 1, exp(z) ≥ e > 1 ≥ 1/z, so the derivative is positive. By the mean value theorem, emlDiag is strictly increasing on [1, ∞). □

### 5.4 Expression Tree Bounds

**Theorem 5.5**: For an EML tree t, size(t) ≤ 2^(totalDepth(t)+1) − 1.

This is the standard full binary tree bound. It implies that EML expressions of bounded total depth have bounded size.

**Theorem 5.6**: The eml-depth (counting only eml nesting) is at most the total depth.

### 5.5 Differentiation Closure

**Theorem 5.7 (EML Chain Rule)**: If f and g are differentiable with derivatives f' and g' respectively, and g(x) > 0, then:
```
d/dx [exp(f(x)) − log(g(x))] = f'(x) · exp(f(x)) − g'(x)/g(x)
```

The right-hand side involves only field operations, exp, and the reciprocal—all of which are EML-expressible. Therefore the EML algebra is closed under differentiation: it forms a differential algebra.

## 6. Power Function Representation

**Theorem 6.1**: For x > 0 and α ∈ ℝ, x^α = exp(α · log(x)).

This identity shows that all real power functions are EML-expressible: they use exp and log, which are both EML primitives.

**Theorem 6.2**: For x, y > 0:
- x · y = exp(log(x) + log(y))
- x / y = exp(log(x) − log(y))
- x = exp(log(x))

These identities show that even basic arithmetic on positive reals can be "compiled through" the EML primitive.

## 7. Discussion

### 7.1 Relation to Neural Networks

The EML universal approximation theorem provides theoretical justification for neural architectures based on a single nonlinearity combining exp and log. A "neuron" computing eml(w·x + b₁, w'·x + b₂) is, in principle, a universal approximator when composed in layers. This simplifies hardware implementation (a single transcendental circuit) while retaining full approximation power.

### 7.2 Relation to the Kolmogorov-Arnold Theorem

The Kolmogorov-Arnold superposition theorem states that every continuous function f: [0,1]^n → ℝ can be represented as:
```
f(x₁,...,xₙ) = Σᵢ Φᵢ(Σⱼ λᵢⱼ · φⱼ(xⱼ))
```
where Φᵢ and φⱼ are continuous functions of one variable. Combined with our EML density result in one variable, this means: every continuous function on compact positive domains can be approximated by a superposition of EML compositions.

### 7.3 Boundaries of the Result

1. **Domain restriction**: EML universality holds on compact K ⊂ (0, ∞)^n, not on all of ℝ^n.
2. **Approximation vs exact**: EML functions approximate but generally cannot exactly represent non-elementary functions (like the Gamma function or Bessel functions).
3. **Rate of convergence**: The Stone-Weierstrass theorem is non-constructive; it guarantees existence of approximants but doesn't bound the degree needed for a given ε.
