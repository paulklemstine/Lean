# Computational Evidence — Berggren Tree Lifted to Euclid Parameters

This evidence supports `Catalog/Pythagorean/BerggrenEuclidLift.lean`, which proves that the
classical Berggren ternary tree on primitive Pythagorean triples is, underneath the Euclid
parametrisation `q(m,n) = (m²−n², 2mn, m²+n²)`, a tree on coprime opposite-parity pairs
`(m,n)` generated by three *linear* maps

* `A : (m,n) ↦ (2m−n, m)`
* `B : (m,n) ↦ (2m+n, m)`
* `C : (m,n) ↦ (m+2n, n)`

rooted at `(2,1)` (which parametrises `(3,4,5)`).

## 1. Small-case calculations (root + its descendants)

Root `(m,n) = (2,1)` ⇒ triple `(3,4,5)`.

Depth-1 children, verifying the linear maps reproduce the Berggren matrices:

| branch | param map result | Euclid triple | Berggren matrix on (3,4,5) |
|--------|------------------|---------------|----------------------------|
| A | (3,2) | (5,12,13)  | (3−8+10, 6−4+10, 6−8+15) = (5,12,13) ✓ |
| B | (5,2) | (21,20,29) | (3+8+10, 6+4+10, 6+8+15) = (21,20,29) ✓ |
| C | (4,1) | (15,8,17)  | (−3+8+10, −6+4+10, −6+8+15) = (15,8,17) ✓ |

Depth-2 (from B-child params `(5,2)`):

| branch | params | triple | gcd | opp. parity | hyp grows |
|--------|--------|--------|-----|-------------|-----------|
| A | (8,5)  | (39,80,89)   | 1 | yes | 29 < 89  ✓ |

All children are valid generator pairs (coprime, opposite parity, `m>n>0`) and the
hypotenuse `m²+n²` strictly increases at every step — matching the proved theorems
`forward_preserves_good` and `forward_hyp_increases`.

## 2. Parent classification (descent) — boundary checks

The proved split is: `n < m < 2n ⇒ A`, `2n < m < 3n ⇒ B`, `m > 3n ⇒ C`.

* `m = 2n` occurs **only** at the root `(2,1)`: `IsCoprime (2n) n ⇒ n=1`. Checked.
* `m = 3n` **never** occurs for a valid pair: it forces `n=1, m=3`, but `(3,1)` has the
  same parity, so it is not a valid generator pair. Checked.

Sample descents (each lands on a strictly smaller valid parent, terminating at `(2,1)`):

* `(8,5)`: `5 < 8 < 10` ⇒ A ⇒ parent `(5, 2·5−8)=(5,2)` ⇒ `2<5<6`... ⇒ root. ✓
* `(9,2)`: `9 > 6` and `9 < ...`, `2·2<9`? `4<9<6`? no; `9>3·2=6` ⇒ C ⇒ parent `(9−4,2)=(5,2)` ⇒ root. ✓
* `(12,5)`: `10<12<15` ⇒ B ⇒ parent `(5,12−10)=(5,2)` ⇒ root. ✓

## 3. Counterexample hunt

Tested all coprime opposite-parity pairs with `2 ≤ m ≤ 40`, `0 < n < m`:

* every such pair descends to `(2,1)` (supports `completeness`);
* every forward map preserves validity and strictly grows the hypotenuse;
* no pair admits two distinct parent branches (uniqueness of the split is exhaustive).

No counterexamples found.

## 4. OEIS

The hypotenuses produced along the all-`B` spine `(2,1)→(5,2)→(12,5)→(29,12)→…` are
`5, 29, 169, 985, …` (every other Pell/NSW-type value). The `m`-coordinates `2,5,12,29,70,…`
are the Pell numbers' half-companion sequence (OEIS A000129-adjacent / A001109 family).
This is consistent with `paramMap B` being the Pell recurrence `m ↦ 2m+n, n ↦ m`.
