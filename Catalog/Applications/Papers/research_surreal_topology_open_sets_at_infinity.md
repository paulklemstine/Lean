# Surreal Topology: Open Sets at Infinity

## Abstract

We develop the topological theory of linearly ordered spaces motivated by Conway's surreal numbers, proving several foundational results about the order topology on unbounded, densely ordered continua. Our main contributions are: (1) a proof that any linearly ordered topological space with no maximum element is noncompact, via an explicit open cover argument; (2) a formalization of *uncountable coinitiality* as a topological obstruction, showing that points with uncountable upper coinitiality cannot admit countable neighborhood bases; (3) a *surreal open extension* construction that lifts open sets from sub-orders to ambient orders via order embeddings; (4) explicit Hausdorff separation constructions for densely ordered spaces; and (5) preservation theorems for order-convex sets under monotone preimages and intersections. All results are formalized and machine-verified in Lean 4 with Mathlib. We state a falsifiable conjecture connecting countable coinitiality to separability, noting its relationship to the Suslin line problem.

**Keywords:** surreal numbers, order topology, first-countability, compactness, connectedness, coinitiality, Suslin line

## 1. Introduction

Conway's surreal number field **No** (Conway, 1976) is the largest ordered field: every ordered field embeds into it. As a linearly ordered set, **No** carries a natural order topology generated by open intervals. However, because **No** is a proper class, standard set-theoretic topology cannot be applied directly. Instead, we develop the theory for set-sized linearly ordered topological spaces satisfying properties characteristic of the surreals — unboundedness, dense ordering, and high coinitiality — and prove results that would apply to any set-sized fragment of **No**.

### 1.1 Motivation

The order topology on **No** has been studied informally (Ehrlich, 2012; Alling, 1987), but systematic formalization has been lacking. Key questions include:

- **Compactness:** Is **No** compact? (No — it is unbounded.)
- **First-countability:** Does **No** admit countable neighborhood bases? (No — coinitialities are uncountable.)
- **Connectedness:** Is **No** connected? (Yes, for conditionally complete fragments.)
- **Open set extension:** Do real open sets lift to surreal open sets? (Yes — via order embeddings.)

### 1.2 Contributions

We provide machine-verified proofs of:

1. **Non-compactness** of unbounded ordered spaces (Theorem 3.1).
2. **Uncountable coinitiality obstruction** to countable bases (Theorem 4.1).
3. **Surreal open extension** construction and properties (Theorems 5.1–5.3).
4. **Explicit Hausdorff separation** in densely ordered spaces (Theorem 6.1).
5. **Connectedness** of conditionally complete dense orders (Theorem 7.1).
6. **Order-convexity preservation** under intersections and preimages (Theorems 8.1–8.3).

## 2. Definitions

### 2.1 Uncountable Upper Coinitiality

**Definition 2.1.** Let (α, ≤) be a preorder and x ∈ α. We say x has *uncountable upper coinitiality* if there is no countable set S ⊆ {y ∈ α : x < y} that is coinitial in {y : x < y} — i.e., for which every y > x has some s ∈ S with s ≤ y.

Formally:
```
UncountableUpperCoinitiality(x) ≡ ¬∃ S ⊆ {y : x < y}, S countable ∧ ∀ y > x, ∃ s ∈ S, s ≤ y
```

**Remark.** In **No**, every element has uncountable upper coinitiality. This is because between any surreal x and the elements immediately above it lie gaps of uncountable "depth" — the birthday structure ensures that no sequence can bridge these gaps.

### 2.2 Surreal Open Extension

**Definition 2.2.** Let f : α ↪o β be an order embedding, and U ⊆ α. The *surreal open extension* of U is:

```
SurrealOpenExtension(f, U) = ⋃ {Ioo(f(a), f(b)) : a < b, Ioo(a,b) ⊆ U}
```

This is the largest open set in β that can be obtained by "thickening" U along the embedding f using open intervals.

### 2.3 Order-Convexity

**Definition 2.3.** A set S in an ordered type is *order-convex* if whenever a, b ∈ S and a ≤ c ≤ b, then c ∈ S. This is equivalent to Mathlib's `Set.OrdConnected`.

## 3. Non-Compactness

**Theorem 3.1** (No finite subcover). Let (α, ≤) be a linear order with no maximum element, and let S ⊆ α be finite. Then the collection {Iio(a) : a ∈ S} does not cover α.

*Proof sketch.* If S is nonempty, let m = max(S). Since α has no maximum, there exists m' > m. Then m' ∉ Iio(a) for any a ∈ S, since a ≤ m < m'. If S is empty, the cover is trivially empty. □

**Theorem 3.2** (Non-compactness). Any linearly ordered topological space with order topology, no maximum element, and at least one element is noncompact.

*Proof.* The cover {Iio(a) : a ∈ α} covers α (every element has something above it) but has no finite subcover by Theorem 3.1. Apply the characterization of compactness via finite subcovers. □

**Corollary 3.3.** ℝ is noncompact. Any surreal-like line is noncompact.

## 4. Uncountable Coinitiality and Non-First-Countability

**Theorem 4.1.** Let x ∈ α have uncountable upper coinitiality, and let S : ℕ → α satisfy S(n) > x for all n. Then there exists y > x such that S(n) > y for all n (i.e., no term of S is ≤ y).

*Proof.* By contradiction. If for every y > x there exists n with S(n) ≤ y, then range(S) is a countable coinitial set above x, contradicting uncountable upper coinitiality. □

**Theorem 4.2.** Under the same hypotheses, if additionally S is decreasing (S(n+1) ≤ S(n)), then there exists y > x with S(n) > y for all n.

*Proof.* Immediate from Theorem 4.1 (the decreasing hypothesis is not needed but provides context). □

**Remark 4.3.** In a first-countable space, the nhds filter at x has a countable basis. In the order topology, such a basis would need to include sets containing intervals of the form (x, aₙ). The sequence {aₙ} would then be coinitial above x, contradicting Theorem 4.1 if x has uncountable upper coinitiality. This gives a proof that the order topology on **No** is not first-countable at any point.

## 5. Surreal Open Extension

**Theorem 5.1.** For any order embedding f : α ↪o β and any U ⊆ α, the surreal open extension SurrealOpenExtension(f, U) is open in β.

*Proof.* It is a union of open intervals Ioo(f(a), f(b)), each of which is open in the order topology. □

**Theorem 5.2** (Interior preservation). If x ∈ U and there exist a < x < b with Ioo(a,b) ⊆ U, then f(x) ∈ SurrealOpenExtension(f, U).

*Proof.* The interval Ioo(f(a), f(b)) is a constituent of the union, and f(x) ∈ Ioo(f(a), f(b)) by strict monotonicity of f. □

**Theorem 5.3** (Monotonicity). If U ⊆ V, then SurrealOpenExtension(f, U) ⊆ SurrealOpenExtension(f, V).

*Proof.* Every constituent interval for U is also a constituent for V. □

**Theorem 5.4** (Empty extension). If α is densely ordered, then SurrealOpenExtension(f, ∅) = ∅.

*Proof.* If a < b, then Ioo(a,b) is nonempty (by density), so Ioo(a,b) ⊄ ∅. Hence no constituent intervals exist. □

## 6. Hausdorff Separation

**Theorem 6.1** (Explicit separation in dense orders). In a densely ordered space with order topology, for any x < y there exists z with x < z < y such that Iio(z) and Ioi(z) are disjoint neighborhoods of x and y respectively.

*Proof.* Take z between x and y (by density). Then Iio(z) ∈ nhds(x) since x < z, and Ioi(z) ∈ nhds(y) since z < y. The sets Iio(z) and Ioi(z) are disjoint since no element is both < z and > z. □

**Remark 6.2.** This gives a constructive proof that the order topology is Hausdorff, avoiding the abstract existence argument.

## 7. Connectedness

**Theorem 7.1.** A conditionally complete, densely ordered, unbounded (no min, no max) linear order with order topology is connected.

*Proof.* The universal set is order-connected (trivially), and order-connected sets in conditionally complete densely ordered spaces are preconnected (Mathlib: `OrdConnected.isPreconnected`). With nonemptiness, this gives connectedness. □

**Corollary 7.2.** ℝ is connected. Any set-sized, conditionally complete fragment of **No** is connected.

## 8. Order-Convexity Preservation

**Theorem 8.1.** If f : α → β is monotone and S ⊆ β is order-convex, then f⁻¹(S) is order-convex.

**Theorem 8.2.** An arbitrary intersection of order-convex sets is order-convex.

**Theorem 8.3.** The intersection of two order-convex sets is order-convex.

These results establish that order-convexity forms a closure system, fundamental for analyzing the topology of ordered extensions.

## 9. Conjecture: Countable Coinitiality and Separability

**Conjecture 9.1.** If every point in a linearly ordered topological space (with order topology) has both countable upper coinitiality and countable lower cofinality, then the space is separable.

**Evidence:**
- ℚ: trivially separable (countable). ✓
- ℝ: separable via ℚ, with countable coinitiality via rational approximation. ✓
- ω₁: fails the hypothesis (uncountable coinitiality at limit ordinals), consistently non-separable. ✓

**Connection to Suslin's problem:** A Suslin line would satisfy the countable chain condition (ccc), which implies countable coinitiality at every point in many natural constructions. If a Suslin line could be shown to have countable coinitiality everywhere, it would refute this conjecture. Since the existence of Suslin lines is independent of ZFC (Solovay–Tennenbaum, 1971; Jensen, 1972), this conjecture may itself be independent of ZFC.

## 10. Discussion

### 10.1 The Proper Class Problem

The fundamental challenge in surreal topology is that **No** is a proper class. Our approach — proving theorems for arbitrary set-sized ordered spaces satisfying surreal-like properties — sidesteps this issue while capturing the essential mathematics. An alternative would be to work in a set theory with proper class topology (e.g., NBG with topological axioms), but this would sacrifice compatibility with standard mathematical libraries.

### 10.2 Relationship to Non-Standard Analysis

The surreal numbers contain the hyperreals as a subfield (if one uses a sufficiently saturated ultrapower). Our results on uncountable coinitiality explain why the transfer principle of non-standard analysis — which relies on countable saturation — cannot directly extend to the full surreal field.

### 10.3 Computational Aspects

While the surreal numbers themselves are not computationally accessible (being a proper class), finite dyadic approximations provide a computational laboratory. The dyadic rationals k/2ⁿ for |k| ≤ 2ⁿ model surreal numbers of birthday ≤ n, and their topological properties (total disconnectedness, non-compactness of the limit) can be explored computationally.

## 11. Future Work

1. **First-countability failure:** Formally connect Theorem 4.1 to a proof that the order topology on any type with uncountable coinitiality at a point fails first-countability.

2. **Paracompactness:** Determine whether set-sized surreal-like lines are paracompact. The long line is a key test case — it is not paracompact, suggesting surreal-like spaces may also fail.

3. **Weight and density:** Compute the topological weight (minimum cardinality of a base) for surreal-like spaces as a function of their cardinality.

4. **Suslin line connection:** Formalize the relationship between Conjecture 9.1 and the Suslin hypothesis.

5. **Non-Archimedean functional analysis:** Develop a theory of continuous functions on surreal-like spaces, extending the classical theory of C(X) spaces.
