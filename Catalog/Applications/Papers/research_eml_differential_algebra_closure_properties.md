# The EML Derivation Calculus: A Verified Symbolic Differential Algebra

## Abstract

We introduce the **EML Derivation Calculus**, a symbolic expression algebra equipped with a verified differentiation operator. The calculus captures the smallest class of real-valued functions containing exp, log, constants, and the identity that is closed under addition, multiplication, negation, reciprocal, and function composition. We prove three main results: (1) this class forms a **differential algebra** — the symbolic differentiation operator `sdiff` correctly computes the actual derivative for all valid expressions; (2) the **derivation tower** of exp(x) is semantically constant — every iterated symbolic derivative of exp evaluates to exp, despite unbounded syntactic growth; (3) expression size grows at most **quadratically** under a single differentiation step, implying doubly-exponential worst-case growth under iteration. We also establish that the inv/log-free fragment is preserved under differentiation, providing unconditional validity for important expression classes. All results are formalized and machine-verified in Lean 4 with Mathlib.

## 1. Introduction

### 1.1 Motivation

The class of functions generated by exponential and logarithmic operations — the EML (Exponential-Multiplicative-Logarithmic) functions — appears throughout mathematical analysis, computer algebra, and machine learning theory. Understanding the algebraic and differential properties of this class is fundamental to:

- **Computer algebra**: Determining when symbolic operations stay within representable function classes
- **Differential Galois theory**: Characterizing solutions of linear differential equations
- **Neural network expressivity**: Understanding the closure properties of activation function compositions
- **Integration theory**: The Liouville-Risch algorithm for deciding elementary integrability

### 1.2 Key Discovery

The standard EML class, generated by {exp, log, constants, +, ×, composition}, is **not** closed under differentiation. The obstruction is precise: d/dx[log(x)] = 1/x, and the reciprocal function is not in the class. Adding the reciprocal operation is necessary and sufficient for differential closure.

### 1.3 Contributions

1. **The EML Derivation Calculus**: A novel symbolic expression type (`Expr`) with evaluation semantics, equipped with a verified symbolic differentiation operator (`sdiff`).

2. **Semantic Correctness** (`sdiff_eval_hasDerivAt`): Under validity conditions, symbolic differentiation correctly computes the actual derivative: `HasDerivAt e.eval (e.sdiff.eval x) x`.

3. **The Derivation Tower**: The sequence of iterated symbolic derivatives, with the proof that exp's tower is semantically constant (`exp_tower_eval_eq`).

4. **The Inv/Log-Free Fragment**: A structural invariant preserved by differentiation, enabling unconditional derivative computation for important expression subclasses.

5. **Size Growth Analysis** (`sdiff_size_le`): The quadratic bound `sdiff(e).size ≤ 3 · e.size²`, which is tight.

## 2. Definitions

### 2.1 The Expression Type

We define EML expressions inductively:

```
Expr ::= cnst(c)        -- constant c ∈ ℝ
       | var             -- the variable x
       | add(e₁, e₂)    -- pointwise sum
       | mul(e₁, e₂)    -- pointwise product
       | neg(e)          -- pointwise negation
       | inv(e)          -- pointwise reciprocal
       | eexp(e)         -- exp ∘ e
       | elog(e)         -- log ∘ e
```

### 2.2 Semantic Evaluation

The evaluation function `eval : Expr → ℝ → ℝ` interprets expressions as real-valued functions:

- `eval(cnst c, x) = c`
- `eval(var, x) = x`
- `eval(add(e₁, e₂), x) = eval(e₁, x) + eval(e₂, x)`
- `eval(eexp(e), x) = exp(eval(e, x))`
- etc.

### 2.3 Symbolic Differentiation

The operator `sdiff : Expr → Expr` implements the standard differentiation rules:

| Expression | `sdiff` |
|-----------|---------|
| cnst(c) | cnst(0) |
| var | cnst(1) |
| add(e₁, e₂) | add(sdiff(e₁), sdiff(e₂)) |
| mul(e₁, e₂) | add(mul(sdiff(e₁), e₂), mul(e₁, sdiff(e₂))) |
| neg(e) | neg(sdiff(e)) |
| inv(e) | neg(mul(sdiff(e), mul(inv(e), inv(e)))) |
| eexp(e) | mul(sdiff(e), eexp(e)) |
| elog(e) | mul(sdiff(e), inv(e)) |

### 2.4 Validity

The predicate `ValidAt : Expr → ℝ → Prop` requires that all `inv` and `elog` subexpressions evaluate to nonzero values. This is necessary for the derivative to exist.

### 2.5 The Inv/Log-Free Fragment

`NoInvLog : Expr → Prop` asserts that an expression contains no `inv` or `elog` constructors. This fragment has trivial validity (`NoInvLog e → ValidAt e x` for all x) and is preserved by differentiation.

## 3. Main Results

### 3.1 Theorem: Semantic Correctness of `sdiff`

**Theorem** (`sdiff_eval_hasDerivAt`). *For all expressions e and points x, if e.ValidAt x and (sdiff e).ValidAt x, then*

$$\text{HasDerivAt}(\text{eval}(e), \text{eval}(\text{sdiff}(e), x), x)$$

*Proof sketch.* By structural induction on e. Each constructor case applies the corresponding Mathlib derivative rule:

- **cnst**: `hasDerivAt_const`
- **var**: `hasDerivAt_id`
- **add**: `HasDerivAt.add`
- **mul**: `HasDerivAt.mul`
- **neg**: `HasDerivAt.neg`
- **inv**: `HasDerivAt.inv` with algebraic matching via `field_simp` and `ring`
- **eexp**: `HasDerivAt.exp` with commutativity adjustment
- **elog**: `HasDerivAt.log`

The algebraic matching between the symbolic formula and Mathlib's formula is nontrivial for `inv` (where we must show `-(f' · f⁻¹ · f⁻¹) = -f'/f²`) and `elog` (where `f' · f⁻¹ = f'/f`). □

### 3.2 Theorem: The Leibniz Rule

**Theorem** (`sdiff_leibniz`). *For all expressions e₁, e₂ and points x:*

$$\text{eval}(\text{sdiff}(\text{mul}(e_1, e_2)), x) = \text{eval}(\text{sdiff}(e_1), x) \cdot \text{eval}(e_2, x) + \text{eval}(e_1, x) \cdot \text{eval}(\text{sdiff}(e_2), x)$$

*Proof.* Immediate from the definition of sdiff and eval, verified by `simp`. □

### 3.3 Theorem: The Exponential Fixed Point

**Theorem** (`exp_tower_eval_eq`). *For all n ∈ ℕ and x ∈ ℝ:*

$$\text{eval}(\text{iterSdiff}(n, \text{eexp}(\text{var})), x) = \exp(x)$$

*Proof sketch.* By induction on n. The key insight is that `eexp var` is in the inv/log-free fragment (`NoInvLog`), which is preserved by `sdiff` (Theorem `sdiff_preserves_noInvLog`), hence by iterated sdiff (`iterSdiff_preserves_noInvLog`). This gives unconditional validity.

For the inductive step: by the IH, `(iterSdiff n (eexp var)).eval = exp` as functions (via `funext`). By `sdiff_eval_hasDerivAt` with the validity guarantee, the derivative of `(iterSdiff n (eexp var)).eval` at x equals `(iterSdiff (n+1) (eexp var)).eval x`. Since the function equals exp, and `HasDerivAt exp (exp x) x` (from Mathlib), uniqueness of derivatives gives the result. □

### 3.4 Theorem: Quadratic Size Growth

**Theorem** (`sdiff_size_le`). *For all expressions e:*

$$\text{size}(\text{sdiff}(e)) \leq 3 \cdot \text{size}(e)^2$$

*Proof sketch.* By structural induction. The worst case is `inv`, where `sdiff(inv e) = neg(mul(sdiff(e), mul(inv(e), inv(e))))` has size `5 + sdiff_size(e) + 2·size(e)`, bounded by `3·(1+size(e))²` using `size(e) ≥ 1`. □

### 3.5 Theorem: Iterated Differentiation Distributes

**Theorem** (`iterSdiff_add_eval`). *For all n, e₁, e₂, x:*

$$\text{eval}(\text{iterSdiff}(n, \text{add}(e_1, e_2)), x) = \text{eval}(\text{iterSdiff}(n, e_1), x) + \text{eval}(\text{iterSdiff}(n, e_2), x)$$

*Proof.* By induction on n, using the syntactic fact that `sdiff(add(a,b)) = add(sdiff(a), sdiff(b))`. □

### 3.6 Theorem: Polynomial Termination

**Theorem** (`x_squared_third_deriv_zero`). *For all x ∈ ℝ:*

$$\text{eval}(\text{iterSdiff}(3, \text{mul}(\text{var}, \text{var})), x) = 0$$

*Proof.* Direct computation by unfolding iterSdiff, sdiff, and eval three times. □

## 4. The Differential Complexity Classification

The derivation tower induces a classification of expressions:

### 4.1 Polynomial Class

Expressions built from `var`, constants, `add`, `mul`, `neg` (no `exp`, `log`, `inv`). The derivation tower terminates: after sufficiently many differentiations, all evaluations are zero.

**Example**: `mul(var, var)` (representing x²) has `iterSdiff 3 = 0`.

### 4.2 Exponential Class

Expressions involving `eexp` but no `elog` or `inv`. The derivation tower is semantically periodic (for `eexp var`, it is constant at exp(x)), but syntactically grows at each step.

**Example**: `eexp var` has constant semantic tower but syntactic size growing as Θ(3ⁿ).

### 4.3 Transcendental Class

Expressions involving `elog` or `inv`. The derivation tower grows both semantically and syntactically.

**Example**: `elog var` (log x) has derivatives 1/x, -1/x², 2/x³, -6/x⁴, ... — an infinite non-periodic sequence.

## 5. The Integration Obstruction

### 5.1 The Fundamental Asymmetry

The EML differential algebra is closed under differentiation but **not** under integration. The function `exp(x²)` is EML, but its antiderivative involves the error function erf(x), which is provably non-elementary by the Liouville-Risch theorem.

### 5.2 Formal Witness

We define `expXSquared = eexp(mul(var, var))` and prove:

$$\text{eval}(\text{sdiff}(\text{expXSquared}), x) = 2x \cdot \exp(x^2)$$

This derivative is EML, but the original function `exp(x²)` has no EML antiderivative. The proof that no antiderivative exists requires the full Liouville-Risch theory, which we state as a conjecture for future formalization.

### 5.3 Self-Integration

Not all integration is impossible: `exp(x)` IS its own antiderivative (up to constants). We prove `IsAntideriv (eexp var) (eexp var)`: the expression `eexp var` is an antiderivative of itself.

## 7. PEGB Analysis

### 7.1 Semantic Correctness (`sdiff_eval_hasDerivAt`)

- **Proof**: Complete, machine-verified induction over 8 expression constructors
- **Example**: `sdiff(mul(var, var)).eval x = 2x` (derivative of x²)
- **Generalization**: Extends to multivariate expressions via partial differentiation
- **Boundary**: Fails at singularities; `ValidAt` is necessary and tight

### 7.2 Exponential Fixed Point (`exp_tower_eval_eq`)

- **Proof**: Induction using inv/log-free fragment preservation and derivative uniqueness
- **Example**: `iterSdiff 5 (eexp var)` evaluates to exp(x)
- **Generalization**: Any function f with f' = f is a semantic tower fixed point
- **Boundary**: Does NOT hold syntactically — expression size grows exponentially

### 7.3 Size Growth Bound (`sdiff_size_le`)

- **Proof**: Structural induction with case analysis on all 8 constructors
- **Example**: `size(sdiff(eexp(eexp(eexp var)))) = 13`, bounded by `3 · 4² = 48`
- **Generalization**: Iterated size satisfies `size(iterSdiff n e) ≤ (3s²)^n` approximately
- **Boundary**: The bound is tight for nested `inv` expressions

## 8. Conjectures

### 8.1 Integration Non-Closure (Falsifiable)

**Conjecture**: There is no EML expression E such that `sdiff(E).eval x = exp(x²)` for all x > 0.

**Test**: Search computationally over EML expressions of increasing size for antiderivatives of exp(x²). If one is found, the conjecture is false.

### 8.2 Derivation Tower Growth Rate

**Conjecture**: For any EML expression e, `size(iterSdiff n e) = Θ(c^(2^n))` for some constant c depending on e.

**Test**: Compute tower sizes for specific expressions and fit the growth rate.

## 9. Discussion

The EML Derivation Calculus provides a rigorous foundation for studying the differential properties of elementary functions. The key innovation is treating differentiation as a **syntactic** operation on expression trees, then proving its **semantic** correctness via the formal derivative.

The inv/log-free fragment discovery is of independent interest: it identifies a natural subclass where all validity conditions are automatically satisfied, enabling unconditional derivative computation. This has practical implications for computer algebra systems, where tracking validity domains is a major source of complexity.
