# EML Stone–Weierstrass for Compact Hausdorff Codomains Presented as Inverse Limits of Compact Metrizable ANR Stages

## Abstract

We establish a codomain-universal approximation theorem for continuous maps
from compact Hausdorff spaces into compact Hausdorff spaces that are realized
as inverse limits of compact metrizable ANR (Absolute Neighborhood Retract)
stages. The key result is a *reduction theorem*: if a class of maps
(e.g., EML-realizable maps) is dense in continuous maps to each stage of an
inverse system, then, under appropriate compatibility and metric control
conditions, the same class is dense in continuous maps to the inverse limit.

All proofs are formalized in Lean 4 using Mathlib, with complete machine
verification and no `sorry` axioms beyond the standard foundational axioms
(`propext`, `Classical.choice`, `Quot.sound`).

## 1. Introduction

### 1.1 The Approximation Problem

The classical Stone–Weierstrass theorem asserts that continuous
real-valued functions on a compact Hausdorff space can be uniformly
approximated by elements of any subalgebra that separates points and
contains constants. The EML (Exponential-Minus-Log) function algebra
generated by exponential and logistic activation functions satisfies
these hypotheses, yielding a universal approximation theorem for
continuous maps into ℝ.

Extending this to vector-valued maps (codomains ℝⁿ) is straightforward
via coordinatewise approximation. The more challenging question is:
*what happens when the codomain is a general compact Hausdorff space?*

Previous work in this project has established EML density for:
- Compact convex subsets of ℝⁿ (direct Stone–Weierstrass)
- Compact metrizable ANR codomains (via Euclidean embedding and retraction)
- Finite products of compact metrizable spaces (coordinatewise assembly)

### 1.2 The Inverse-Limit Bridge

Many compact Hausdorff spaces of interest are not themselves ANRs, but
can be expressed as inverse limits of compact metrizable ANRs. Examples include:

- **The Cantor set**: inverse limit of finite discrete spaces
- **Solenoids**: inverse limits of circles with multiplication bonding maps
- **Pro-finite groups**: inverse limits of finite groups
- **Certain Julia sets and attractors**: inverse limits of manifolds

The inverse-limit construction provides a natural bridge between the
ANR-valued approximation theorem and a much broader class of codomains.

### 1.3 Main Result

Our main theorem states that if:
1. The codomain `L` is presented as an inverse limit of compact metrizable
   stages `(Y_n)` with bonding maps `p_n : Y_{n+1} → Y_n`,
2. The projections `π_n : L → Y_n` provide finite-coordinate metric control
   (finitely many coordinates suffice to approximate the metric on `L`),
3. For any finite truncation level `N` and any continuous map `f : X → L`,
   there exist compatible approximations in the given class at the first
   `N` stages that can be assembled into a map to `L`,

then every continuous map `f : X → L` can be uniformly approximated by
maps from the given class.

## 2. Mathematical Framework

### 2.1 Inverse Systems

An **inverse system** indexed by ℕ consists of:
- A family of compact metrizable spaces `(Y_n)_{n ∈ ℕ}`,
- Continuous surjective bonding maps `p_n : Y_{n+1} → Y_n`.

The **inverse limit** `L = lim←(Y_n, p_n)` is the subspace of the
product `∏_n Y_n` consisting of compatible sequences:

$$L = \{(y_n)_n \in \prod_n Y_n \mid p_n(y_{n+1}) = y_n \text{ for all } n\}$$

with the subspace topology. The projection maps `π_n : L → Y_n`
are the coordinate projections restricted to `L`.

### 2.2 Finite-Coordinate Metric Control

**Definition.** An inverse limit presentation `(L, π_n)` has
*finite-coordinate metric control* if for every `ε > 0` there exists
`N ∈ ℕ` such that for all `y, z ∈ L`:

$$\forall n \leq N,\; d_n(\pi_n(y), \pi_n(z)) < \varepsilon/2 \implies d_L(y, z) < \varepsilon$$

This is automatic when `L` carries the inverse-limit metric
`d_L(y,z) = \sum_n 2^{-n} d_n(\pi_n(y), \pi_n(z))`, since the tail
sum `\sum_{n>N} 2^{-n} \cdot \text{diam}(Y_n) \to 0` as `N \to \infty`.

### 2.3 The EML Map Class

For the purposes of the reduction theorem, we parameterize by a general
map predicate `P` on `C(X, L)` (the space of continuous maps from `X`
to `L` with the sup metric). The key structural requirement is:

**Compatible finite-stage assembly**: For any `f ∈ C(X, L)`, any `N ∈ ℕ`,
and any `δ > 0`, there exists `G ∈ C(X, L)` with `P(G)` such that
`d_∞(π_n ∘ f, π_n ∘ G) < δ` for all `n ≤ N`.

This hypothesis is where the ANR structure at each stage enters: the
finite limit stage `F_N = \{(y_0, ..., y_N) \mid p_n(y_{n+1}) = y_n\}`
is itself a compact metrizable ANR (as a closed subset of a product of
ANRs under suitable conditions), and the ANR-valued EML density theorem
applies.

## 3. Main Theorems

### 3.1 Finite-Coordinate Metric Control Lifting

**Theorem (inverseLimit_metric_control).** *Let `L` be a compact metric
space with projections `π_n : L → Y_n` into compact metric spaces.
If the projections satisfy finite-coordinate metric control at the
point level:*

$$\forall \varepsilon > 0,\; \exists N,\; \forall y,z \in L,\; (\forall n \leq N,\; d_n(\pi_n(y), \pi_n(z)) < \varepsilon/2) \implies d_L(y,z) < \varepsilon$$

*then the same control holds at the function-space level:*

$$\forall \varepsilon > 0,\; \exists N,\; \forall f,g \in C(X,L),\; (\forall n \leq N,\; d_\infty(\pi_n \circ f, \pi_n \circ g) < \varepsilon/2) \implies d_\infty(f,g) < \varepsilon$$

**Proof.** Given `ε > 0`, let `N` be the controlling index from the
point-level hypothesis. For `f, g ∈ C(X, L)`, if `d_∞(π_n ∘ f, π_n ∘ g) < ε/2`
for all `n ≤ N`, then for each `x ∈ X`:
- `d_n(π_n(f(x)), π_n(g(x))) ≤ d_∞(π_n ∘ f, π_n ∘ g) < ε/2`  for all `n ≤ N`,
- hence `d_L(f(x), g(x)) < ε` by the point-level control.

Since this holds for all `x`, `d_∞(f, g) < ε`. ∎

### 3.2 The Main Reduction Theorem

**Theorem (approx_inverseLimit_from_finite_coordinates).** *Let `L` be a
compact metric space with projections `π_n : L → Y_n` satisfying
finite-coordinate metric control. Let `P` be a predicate on `C(X, L)`.
If for every `f ∈ C(X, L)`, every `N ∈ ℕ`, and every `δ > 0`, there
exists `G ∈ C(X, L)` with `P(G)` and `d_∞(π_n ∘ f, π_n ∘ G) < δ` for
all `n ≤ N`, then `P` is dense in `C(X, L)`:*

$$\forall f \in C(X, L),\; \forall \varepsilon > 0,\; \exists G \in C(X, L),\; P(G) \wedge d_\infty(f, G) < \varepsilon$$

**Proof.** Given `f` and `ε > 0`:
1. Apply metric control to get `N` for tolerance `ε`.
2. Apply the compatible approximation hypothesis with `N` and `δ = ε/2`
   to get `G` with `P(G)` and coordinatewise control.
3. Apply the function-space metric control to conclude `d_∞(f, G) < ε`. ∎

### 3.3 Compatible Approximation via Sections

**Theorem (compatible_approx_from_section).** *Suppose for each `N` there exist:*
- *A compact metric space `Z_N` (the "finite limit stage"),*
- *An embedding `ι_N : L → Z_N` and a section `s_N : Z_N → L`,*
- *Such that `π_n ∘ s_N ∘ ι_N = π_n` for all `n ≤ N`,*
- *Both `π_n` and `s_N` are 1-Lipschitz,*
- *`P` is dense in `C(X, Z_N)` (via postcomposition with `s_N`).*

*Then the compatible approximation hypothesis holds.*

**Proof.** Given `f ∈ C(X, L)`, `N`, and `δ > 0`:
1. Set `f_N = ι_N ∘ f ∈ C(X, Z_N)`.
2. Approximate `f_N` by `g_N ∈ C(X, Z_N)` with `P(s_N ∘ g_N)` and
   `d_∞(f_N, g_N) < δ`.
3. Set `G = s_N ∘ g_N`.
4. For each `n ≤ N`:
   ```
   d_∞(π_n ∘ f, π_n ∘ G) = d_∞(π_n ∘ s_N ∘ f_N, π_n ∘ s_N ∘ g_N)
                            ≤ d_∞(f_N, g_N) < δ
   ```
   using the 1-Lipschitz property and the identity `π_n ∘ s_N ∘ ι_N = π_n`. ∎

### 3.4 Full Pipeline

**Theorem (dense_inverseLimit_full_pipeline).** *Combining the metric
control, section-based compatible approximation, and the main reduction:
if all hypotheses of §3.1 and §3.3 hold, then `P` is dense in `C(X, L)`.*

This is a direct composition of the three theorems above.

## 4. Formalization in Lean 4

The entire theorem chain is formalized in Lean 4 using Mathlib. The key
design decisions are:

1. **Parameterization by predicate**: We use a general predicate
   `P : C(X, L) → Prop` rather than a specific `IsEMLMap` definition.
   This makes the theorems modular and reusable.

2. **Mathlib metric on `C(X, Y)`**: For compact `X` and metric `Y`,
   Mathlib provides `ContinuousMap.instPseudoMetricSpace` with the
   sup-metric. We use `ContinuousMap.dist_lt_iff` and
   `ContinuousMap.dist_apply_le_dist` as the main interface lemmas.

3. **Structure for inverse limits**: We define
   `InverseLimitPresentation` capturing the projection maps, compatibility
   with bonding maps, and point separation.

All proofs compile without `sorry` and depend only on the standard axioms:
`propext`, `Classical.choice`, and `Quot.sound`.

## 5. Applications

### 5.1 Neural Network Approximation on Fractal Codomains

Many interesting dynamical systems have attractors that are inverse limits
of simpler spaces. Our theorem shows that EML neural networks can
approximate continuous maps into such attractors, provided the
approximation works at each finite stage.

**Example (Cantor set codomain)**: A continuous map `f : [0,1] → C`
into the Cantor set can be uniformly approximated by EML maps, because:
- The Cantor set is the inverse limit of `{0,1}^n` with projection bonding maps.
- Maps into `{0,1}^n` are trivially approximable (they are locally constant).
- The metric control is automatic from the product metric.

### 5.2 Signal Processing on Solenoids

The p-adic solenoid `Σ_p` is the inverse limit of circles
`S^1 →[×p] S^1 →[×p] S^1 →[×p] ...`
with the multiplication-by-p bonding map.

Continuous maps into solenoids arise in:
- Multi-scale signal analysis (each stage represents a frequency band)
- Time-frequency representations of signals
- Adelic harmonic analysis

Our theorem shows that EML maps can approximate such multi-scale
representations, with the error controlled by the number of frequency
bands considered.

### 5.3 Approximation on Profinite Groups

Every profinite group (e.g., the p-adic integers ℤ_p, absolute Galois
groups) is an inverse limit of finite groups. Our theorem shows that
continuous maps into profinite groups can be approximated by EML maps,
provided each finite quotient admits approximation.

### 5.4 Shape-Theoretic Universality

From the shape-theoretic perspective, our result shows that EML
approximation is not merely a smooth-manifold phenomenon but extends to
all compact Hausdorff spaces that are "pro-ANR" — i.e., that can be
expressed as inverse limits of ANRs. This covers a very large class of
spaces, including:
- All compact metrizable spaces (by the Freudenthal compactification theorem)
- All compact Hausdorff spaces that are shape-equivalent to a polyhedron

## 6. Discussion: Making the Abstract Concrete

### For the General Reader

Imagine you want to predict the weather, but your model needs to output
not just a single number (temperature) but an entire complex state —
perhaps a fractal-like pattern of cloud formations, or a multi-scale
description of atmospheric turbulence.

The classical universal approximation theorem says neural networks can
approximate any continuous function that outputs a single real number.
But what if the output space is something exotic — a fractal, a solenoid,
or some other complicated topological object?

Our result says: **if you can break the complicated output space into
a sequence of simpler approximations, then the neural network can handle
the full complex output**. It's like building a high-resolution image
from progressively finer layers — first the broad shapes, then the
medium details, then the fine textures. At each resolution level, the
neural network can do its job. And our theorem guarantees that these
layered approximations combine correctly into a faithful approximation
of the full complex output.

### Historical Context

This result sits at the intersection of three mathematical traditions:

1. **Approximation theory** (Weierstrass, Stone): functions can be
   uniformly approximated by "nice" functions (polynomials, subalgebra
   elements).

2. **Shape theory** (Borsuk, Mardešić): complicated spaces can be
   studied through their "shadows" in simpler spaces, using inverse limits.

3. **Neural network theory** (Cybenko, Hornik): neural networks are
   universal approximators for continuous functions.

Our contribution connects these traditions by showing that the neural
network approximation theorem extends from "nice" codomains (Euclidean
spaces, manifolds) to "complicated" codomains (inverse limits of ANRs),
using the shape-theoretic machinery of inverse limits as the bridge.

### Future Directions

1. **Quantitative bounds**: Our theorem is existential; it would be
   valuable to obtain explicit bounds on the number of neurons needed
   as a function of the number of stages and the stage-level complexity.

2. **Removing the ANR assumption**: The requirement that each stage be
   an ANR could potentially be weakened using more refined retraction
   arguments or alternative approximation methods.

3. **Codomain-universal theorem**: The ultimate goal is a theorem
   asserting EML density for *all* compact Hausdorff codomains, without
   requiring an explicit inverse-limit presentation. This would require
   showing that every compact Hausdorff space admits such a presentation
   with the right properties.

4. **Computational aspects**: Implementing the inverse-limit approximation
   algorithm in practice, using the stage-by-stage approach with
   compatibility corrections.

## 7. Conclusion

We have established a formally verified reduction theorem showing that
EML approximation in inverse-limit codomains reduces to EML approximation
at compact metrizable ANR stages. The key mathematical insight is that
the inverse-limit topology is controlled by finitely many coordinate
projections, and this control lifts cleanly from the point level to the
function-space level. The result extends the EML codomain-approximation
program from ANR targets to a broad class of compact Hausdorff spaces
obtained by inverse limits, demonstrating that EML approximation is stable
under inverse-limit constructions — a strong structural universality statement.
