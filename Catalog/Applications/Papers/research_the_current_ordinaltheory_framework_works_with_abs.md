# The Tight Depth Hierarchy for the Inverse-Free EML Fragment

## Abstract

We study **EML**, an expression language over the reals in which transcendence
enters through a single primitive, `eml(a,b) = a·exp(b)`, layered on top of the
field operations and multiplicative inverse. The *eml-depth* of an expression is
the maximal nesting of `eml` primitives. We prove a **tight depth hierarchy**
for the inverse-free fragment: an inverse-free EML expression of eml-depth `D`
can represent the `n`-fold iterated exponential `iterExp n` only when `n ≤ D`;
to represent a tower of height `n` requires depth *exactly* `n`. The
canonical construction shows depth `n` suffices; the lower bound is the
content. The proof introduces a sharpened growth invariant — the
**polynomial-argument tower majorant**, `|e(x)| ≤ iterExp k (C·x^N)` — together
with a structural **growth rank** satisfying `growthRank e ≤ emlDepth e`. The
polynomial argument is closed under the operations that combine subexpressions
(`add`, `mul`, `neg`), which lets the majorant absorb cross-terms without
spending a tower level, eliminating the spurious `+3` slack of the earlier
linear-argument bound and yielding the exact hierarchy. We also develop a
companion toolkit on idempotent oracles, fixed points, binary entropy, Möbius
composition, and inverse stereographic projection, all sharing the algebraic
theme of idempotence and projective/spherical structure.

**Keywords:** iterated exponential, exponential depth, growth hierarchy,
transcendental expressions, tower majorant, growth rank, idempotent oracles,
stereographic projection.

## 1. Introduction

The iterated exponential `iterExp n` — a tower of `n` exponentials — is among
the simplest constructions whose growth outpaces every elementary closed form of
bounded complexity. A natural complexity measure for transcendental expressions
is the depth of exponential nesting. The motivating problem is to determine the
*minimal* nesting depth required to express a given iterated exponential within a
fixed expression language.

We answer this for **EML**, a language whose only transcendental primitive is
`eml(a,b) = a·exp(b)`. Our main theorem states that, **in the inverse-free
fragment**, eml-depth is an *exact* ruler of iterated-exponential complexity:
depth `D` represents `iterExp n` if and only if `n ≤ D`. The "if" direction is a
direct construction; the "only if" — the lower bound — is proved by a growth
argument whose precision rests on a new majorant notion.

The restriction to the inverse-free fragment is genuine: multiplicative
inverses introduce singular behaviour that can imitate extra growth, so the
exact law is a feature of the honest, division-free world of polynomial-and-
exponential combinations.

### Contributions

1. A formal expression language EML with evaluation, eml-depth, and the
   inverse-free / eml-free fragments (Section 2).
2. The canonical tower construction `emlExprIterExp n` of depth exactly `n`

3. The **polynomial-argument tower majorant** `HasPolyTowerMajorant` and the

4. The tight depth hierarchy theorem and its proof architecture (Section 5).
5. A companion toolkit on idempotent oracles, binary entropy, Möbius

## 2. The EML expression language

**Definition 2.1 (EMLExpr).** The set of EML expressions is the inductive type
generated by:

- `var` (the indeterminate),
- `const c` for `c ∈ ℝ`,
- `add a b`, `mul a b`, `neg a`,
- `inv a`,
- `eml a b`.

**Definition 2.2 (Evaluation).** The evaluation `eval : EMLExpr → ℝ → ℝ` is

```
eval(var, x)        = x
eval(const c, x)    = c
eval(add a b, x)    = eval(a,x) + eval(b,x)
eval(mul a b, x)    = eval(a,x) · eval(b,x)
eval(neg a, x)      = -eval(a,x)
eval(inv a, x)      = (eval(a,x))⁻¹
eval(eml a b, x)    = eval(a,x) · exp(eval(b,x))
```

**Definition 2.3 (eml-depth).** `emlDepth : EMLExpr → ℕ` is

```
emlDepth(var)       = 0
emlDepth(const c)   = 0
emlDepth(add a b)   = max(emlDepth a, emlDepth b)
emlDepth(mul a b)   = max(emlDepth a, emlDepth b)
emlDepth(neg a)     = emlDepth a
emlDepth(inv a)     = emlDepth a
emlDepth(eml a b)   = 1 + max(emlDepth a, emlDepth b)
```

Thus eml-depth is the length of the longest root-to-leaf chain of `eml`
constructors; field operations contribute no depth.

**Definition 2.4 (Fragments).** The predicate `noInv e` holds iff `e` contains no
`inv` node (the *inverse-free fragment*); `noEml e` holds iff `e` contains no
`eml` node (the *pure field fragment*). Both are defined by the obvious structural
recursion, with `noInv(inv a) = False` and `noEml(eml a b) = False`.

**Definition 2.5 (Representation).** An expression `e` *represents* `f : ℝ → ℝ`
on the positive reals, written `RepresentsOnPos e f`, iff `eval(e,x) = f(x)` for
all `x > 0`.

We work on the positive reals to avoid trivial obstructions at `x ≤ 0` and to
align with the asymptotic nature of the growth argument.

## 3. The iterated exponential and the canonical tower

**Definition 3.1 (iterExp).** `iterExp : ℕ → ℝ → ℝ` is

```
iterExp 0 x       = x
iterExp (n+1) x   = exp(iterExp n x)
```

with the immediate rewrite lemmas `iterExp_zero : iterExp 0 x = x` and
`iterExp_succ : iterExp (n+1) x = exp(iterExp n x)`.

**Definition 3.2 (Canonical tower expression).**

```
emlExprIterExp 0       = var
emlExprIterExp (n+1)   = eml (const 1) (emlExprIterExp n)
```

**Proposition 3.3 (Upper bound: depth `n` suffices).** For every `n`,
`emlExprIterExp n` is inverse-free, has `emlDepth (emlExprIterExp n) = n`, and
represents `iterExp n` on the positive reals.

*Proof sketch.* By induction on `n`. For `n = 0` the expression is `var`, of
depth 0, evaluating to `x = iterExp 0 x`. For the step, `emlExprIterExp (n+1) =
eml (const 1) (emlExprIterExp n)` has depth `1 + max(0, emlDepth(emlExprIterExp
n)) = 1 + n` and evaluates to `1 · exp(eval(emlExprIterExp n, x)) =
exp(iterExp n x) = iterExp (n+1) x` by the induction hypothesis. Inverse-freeness
is preserved at each step since no `inv` is introduced. ∎

Proposition 3.3 establishes the easy half of the hierarchy: depth `n` is
*sufficient*. The remainder of the paper proves it is *necessary*.

## 4. Growth invariants: the polynomial-argument majorant

The lower bound is an asymptotic-growth argument. We need a uniform ceiling on
how fast any low-depth inverse-free expression can grow.

**Definition 4.1 (Linear-argument tower majorant).** For `k : ℕ`,
`HasTowerMajorant k e` holds iff there is `C > 0` with

> `eval(e,x) ≤ iterExp k (C·x)` for all `x > 1`.

This is the classical notion and is sufficient to prove *some* hierarchy, but it
loses a constant number of levels under composition, yielding only the weaker
statement that depth `D` cannot reach `iterExp n` for `n > D + 3`.

**Definition 4.2 (Polynomial-argument tower majorant — key innovation).** For
`k : ℕ`, `HasPolyTowerMajorant k e` holds iff there exist `C > 0`, `N : ℕ`, and a
threshold `X₀` such that

> `|eval(e,x)| ≤ iterExp k (C·x^N)` for all `x ≥ X₀`.

The crucial difference is the polynomial argument `C·x^N` in place of the linear
`C·x`. Polynomials in `x` form a class closed under the operations that combine
subexpressions, which lets cross-terms be absorbed without incrementing `k`.

**Definition 4.3 (Growth rank).** `growthRank : EMLExpr → ℕ` is

```
growthRank(var)       = 0
growthRank(const c)   = 0
growthRank(add a b)   = max(growthRank a, growthRank b)
growthRank(mul a b)   = max(growthRank a, growthRank b)
growthRank(neg a)     = growthRank a
growthRank(inv a)     = growthRank a
growthRank(eml a b)   = 1 + max(growthRank a, growthRank b)
```

The growth rank assigns to each inverse-free expression the tower level needed
to majorize it: rank 0 for the polynomial fragment, and one extra level per
genuine exponential.

**Lemma 4.4 (Rank is bounded by depth).** For every `e`,
`growthRank e ≤ emlDepth e`.

*Proof sketch.* Structural induction. The two recursions are syntactically
identical on every constructor (`var`, `const` give 0; `add`, `mul` take a max;
`neg`, `inv` pass through; `eml` adds one to a max), so in fact
`growthRank e = emlDepth e` on the inverse-free fragment, and `≤` holds in
general because `inv` is handled identically. The inequality form is the
robust statement used downstream. ∎

**Lemma 4.5 (Polynomial majorant closure).** On the inverse-free fragment:

1. `var`, `const c` have `HasPolyTowerMajorant 0` (bounded by `C·x^N`, e.g.
   `|x| ≤ x^1` and `|c| ≤ |c|·x^0` for `x ≥ 1`).
2. If `a, b` have polynomial majorants at levels `j, k`, then `add a b`,
   `mul a b`, `neg a` have polynomial majorants at level `max(j,k)`.
3. If `a, b` have polynomial majorants at levels `j, k`, then `eml a b` has a
   polynomial majorant at level `1 + max(j,k)`.

*Proof sketch.* (1) is immediate. For (2), put both summands/factors over a
common tower level `m = max(j,k)`; since `iterExp m` is monotone and the sum or
product of two quantities each `≤ iterExp m (C·x^N)` is `≤ iterExp m (C'·x^{N'})`
after enlarging the polynomial (a sum doubles, a product squares the bound, both
absorbed by increasing `C, N`), the level `m` is preserved — *this is exactly
where a polynomial argument is needed*: a linear argument cannot absorb the
product's exponent without an extra level. `neg` is trivial by `|−t| = |t|`.
For (3), `|eval(eml a b, x)| = |eval(a,x)|·exp(eval(b,x)) ≤ iterExp j(C·x^N) ·
exp(iterExp k(C·x^N))`. The leading polynomial-sized factor is absorbed into the
outer exponential (since `P(x)·exp(Q(x)) ≤ exp(Q(x) + log P(x)) ≤ exp(C'·x^{N'})`
for large `x`), giving a bound of the form `iterExp (1+max(j,k))(C'·x^{N'})`. ∎

**Corollary 4.6 (Uniform majorant by rank).** Every inverse-free `e` satisfies
`HasPolyTowerMajorant (growthRank e) e`, hence by Lemma 4.4
`HasPolyTowerMajorant (emlDepth e) e`.

*Proof.* Induction over `e` using Lemma 4.5 at each constructor, with the level
tracked exactly by `growthRank`; then weaken via `growthRank ≤ emlDepth`. ∎

## 5. The tight depth hierarchy

**Lemma 5.1 (Towers separate strictly).** For every `k < n`, every `C > 0`, and
every `N : ℕ`,

> `iterExp k (C·x^N) = o(iterExp n x)` as `x → ∞`;

in particular `iterExp n x` eventually exceeds `iterExp k (C·x^N)`.

*Proof sketch.* Apply the strictly increasing function `log` exactly `k` times to
both sides; this is legitimate for large `x` where all quantities exceed `1` and
`log ∘ iterExp (m+1) = iterExp m`. The left side reduces to `C·x^N` and the
right to `iterExp (n−k) x` with `n − k ≥ 1`, i.e. to at least one exponential
`exp(iterExp (n−k−1) x) ≥ exp(x)`. The schoolbook limit `exp(x)/(C·x^N) → ∞`
finishes the comparison; monotonicity of the `k` applied exponentials transports
the inequality back. ∎

**Theorem 5.2 (Tight depth hierarchy).** Let `e` be an inverse-free EML
expression with `emlDepth e = D`. If `e` represents `iterExp n` on the positive
reals, then `n ≤ D`. Equivalently, for every `n > D`, no inverse-free expression
of depth `D` represents `iterExp n`.

*Proof sketch.* Suppose `e` is inverse-free of depth `D` and represents
`iterExp n`, i.e. `eval(e,x) = iterExp n x` for all `x > 0`. By Corollary 4.6,
`|eval(e,x)| ≤ iterExp D (C·x^N)` for all `x ≥ X₀`. Hence
`iterExp n x = eval(e,x) ≤ |eval(e,x)| ≤ iterExp D (C·x^N)` for large `x`
(note `iterExp n x > 0`). If `n > D`, Lemma 5.1 (with `k = D`) gives the reverse
strict inequality `iterExp D (C·x^N) < iterExp n x` for all sufficiently large
`x`, a contradiction. Therefore `n ≤ D`. ∎

**Theorem 5.3 (Exact representability law).** For inverse-free EML, the minimal
eml-depth needed to represent `iterExp n` is exactly `n`: depth `n` suffices
(Proposition 3.3) and depth `n−1` does not (Theorem 5.2).

**Remark 5.4 (Why "tight").** The polynomial-argument majorant is what makes the
bound `n ≤ D` rather than `n ≤ D + 3`. With the linear majorant (Definition 4.1),
the product step of Lemma 4.5(2) forces an extra tower level, and the
accumulated loss over the recursion is a fixed additive constant (3 in the
earlier analysis). The polynomial class absorbs those cross-terms in the
*argument* of the same tower level, so no level is wasted and the hierarchy
closes with zero slack.

**Remark 5.5 (Necessity of inverse-freeness).** With `inv` available, singular
combinations such as `inv(...)` can blow up near isolated points and emulate
faster growth without adding eml-depth, breaking the clean separation of
Lemma 5.1. The exact law is therefore a theorem about the inverse-free fragment;
the general fragment requires the weaker, slacker bounds.

### 5.6 Worked examples

We trace the invariants on concrete expressions to illustrate the mechanism.

- `e₁ = x² + 3 = add(mul(var,var), const 3)`. Each leaf has rank 0; `mul` and
  `add` take maxima, so `growthRank e₁ = emlDepth e₁ = 0`. A polynomial-argument
  majorant at level 0 is immediate: `|e₁(x)| ≤ x² + 3 ≤ 4·x²` for `x ≥ 1`, i.e.
  `iterExp 0 (4·x²)`. Consistent with Theorem 5.2, `e₁` represents `iterExp n`
  only for `n = 0` (it does not, but the *depth budget* permits only `n ≤ 0`).
- `e₂ = x·eˣ + e^(x²)`. Here `eml(const 1, var)` and `eml(const 1, mul(var,var))`
  each have rank 1; the surrounding `mul` and `add` preserve the maximum, so
  `growthRank e₂ = emlDepth e₂ = 1`. The majorant computation of Lemma 4.5(3)
  gives `|e₂(x)| ≤ exp(2·x²) = iterExp 1 (2·x²)` for large `x`: the leading
  factor `x` in `x·eˣ` is absorbed into the exponent because `x·eˣ ≤ exp(2x)`
  for `x ≥ 1`. By Theorem 5.2, `e₂` cannot represent any tower of height `≥ 2`.
- `e₃ = emlExprIterExp 2 = eml(const 1, eml(const 1, var))`. Both invariants
  equal 2, the expression evaluates to `exp(exp(x)) = iterExp 2 x`, and depth 2
  is exactly the minimum by Theorem 5.3.

These examples show the recursion in Definition 4.3 tracking precisely the number
of genuine exponentials, and the polynomial argument absorbing the algebraic
cross-terms (`x·eˣ`) that a linear-argument majorant could not.

## 6. Companion toolkit: idempotent oracles and geometric maps

Alongside the hierarchy we develop a small reusable toolkit centered on
idempotence, fixed points, and projective/spherical geometry.

### 6.1 Oracle refinement

**Definition 6.1.** For `O₁, O₂ : X → X`, `O₁` *refines* `O₂`
(`OracleRefines O₁ O₂`) iff every fixed point of `O₁` is a fixed point of `O₂`:
`∀ x, O₁ x = x → O₂ x = x`.

**Proposition 6.2.** Refinement is a preorder: `OracleRefines O O` (reflexivity),
and `OracleRefines O₁ O₂` with `OracleRefines O₂ O₃` give `OracleRefines O₁ O₃`
(transitivity). *Proof.* Reflexivity is the identity implication; transitivity
chains the two implications on a common fixed point. ∎

**Proposition 6.3 (Idempotent oracles).** If `f : X → X` satisfies
`f(f(x)) = f(x)` for all `x`, then `f ∘ f = f` (by functional extensionality),
and `f` converges in one step: `f x = f(f x)`. A constant oracle `x ↦ c` has the
unique fixed point `c`. Moreover, for decidable `X`, each `x` either is fixed
(`f x = x`) or is mapped in one step to a fixed point (`f x ≠ x ∧ f(f x) = f x`).

These facts model "self-improving" procedures: an idempotent improvement
operator reaches a stable solution immediately upon a second application.

### 6.2 Meta-oracles

**Definition 6.4.** A `MetaGeodesicOracle` over an index type `α` bundles a
family `family : α → (ℝ → ℝ)`, a proof that each `family i` is idempotent, and a
selector `selectIdx : ℝ → α`. Its consultation is
`consult x = family (selectIdx x) x`.

**Proposition 6.5.** If the selector is constant (`selectIdx x = i` for all `x`),
the meta-oracle is itself idempotent: `consult (consult x) = consult x`. *Proof.*
Substituting the constant selector reduces `consult` to `family i`, which is
idempotent by hypothesis. ∎

### 6.3 Binary entropy

**Definition 6.6.** `binaryEntropy p = −p·log₂ p − (1−p)·log₂(1−p)` (with the
usual convention at the endpoints).

**Proposition 6.7.** For `0 < p < 1`, `binaryEntropy p ≥ 0`, and
`binaryEntropy(1/2) = 1`. *Proof sketch.* Non-negativity follows from
`log₂ p < 0` and `log₂(1−p) < 0` on `(0,1)`, making both terms non-negative; the
value at `1/2` is `−(1/2)log₂(1/2) − (1/2)log₂(1/2) = 1`. ∎

This is the information-theoretic statement that a fair binary source carries
exactly one bit.

### 6.4 Möbius composition

**Definition 6.8.** `mobiusTransform a b c d x = (a·x + b)/(c·x + d)`.

**Proposition 6.9.** Where denominators are non-zero,

> `mobius(a₁,b₁,c₁,d₁)(mobius(a₂,b₂,c₂,d₂)(x)) =
>  (a₁(a₂x+b₂)+b₁(c₂x+d₂)) / (c₁(a₂x+b₂)+d₁(c₂x+d₂))`,

i.e. composition of Möbius transforms is multiplication of their `2×2`
coefficient matrices. *Proof.* Substitute and clear denominators; the result is
the matrix product. ∎

### 6.5 Inverse stereographic projection

**Definition 6.10.** For `x ∈ ℝⁿ` with `s = Σ xᵢ²`, the inverse stereographic
projection `invStereoN n x ∈ ℝ^{n+1}` has coordinates `2xᵢ/(1+s)` for `i < n`
and `(s−1)/(1+s)` in the last slot.

**Proposition 6.11.** The image lies on the unit `n`-sphere:
`Σ_{i=0}^{n} (invStereoN n x)ᵢ² = 1` for all `x`. *Proof sketch.* The first `n`
squared coordinates sum to `4s/(1+s)²`; the last is `(s−1)²/(1+s)²`; their sum is
`(4s + (s−1)²)/(1+s)² = (s+1)²/(1+s)² = 1`. ∎

## 7. Algorithms

The constructive content yields three algorithms (see also the demonstration
code and the `algorithms` field of the package bundle).

- **`build_canonical_tower(n)`** constructs `emlExprIterExp n` by `n` wrappings
  in `eml(const 1, ·)`. Time and space `Θ(n)`; the result has eml-depth exactly
  `n` (Proposition 3.3).
- **`growth_rank(e)` / `eml_depth(e)`** compute the structural invariants by a
  single post-order traversal in `Θ(|e|)` time, and witness Lemma 4.4 pointwise.
- **`min_depth_for_iterexp(n) = n`** returns the exact minimal depth
  (Theorem 5.3); together with the separation check (Lemma 5.1) it certifies
  impossibility for any candidate of smaller depth.

## 8. Applications and discussion

**Lower bounds for symbolic computation.** Theorem 5.2 is an unconditional lower
bound: no rewriting within inverse-free EML can reduce the exponential nesting
below the target tower height. This certifies optimality of representations in
computer-algebra and verified-numerics settings.

**Syntax–semantics alignment.** The result is a clean coincidence of a syntactic
measure (eml-depth) and an analytic one (growth rate), bridged by the growth
rank. The polynomial-argument majorant is the technical device that makes the
correspondence exact rather than approximate.

**Idempotence as computational stability.** The companion toolkit packages the
recurring "fixed point reached in one step" pattern that underlies self-
improving oracles and provides verified building blocks (Möbius composition,
spherical projection) for geometric pipelines.

## 10. Conclusion

We proved an exact depth law: in the inverse-free EML fragment, representing the
height-`n` iterated exponential requires eml-depth *exactly* `n`. The upper bound
is a direct tower construction; the lower bound rests on the polynomial-argument
tower majorant and the growth-rank invariant `growthRank ≤ emlDepth`, which
together close the hierarchy with zero slack and remove the earlier additive
gap. The accompanying toolkit on idempotent oracles, binary entropy, Möbius
composition, and inverse stereographic projection supplies verified, reusable
infrastructure in the same algebraic spirit.
