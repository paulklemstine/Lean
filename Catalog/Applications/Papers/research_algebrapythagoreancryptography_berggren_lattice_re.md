# Berggren Lattice-Reduction Duality via Triple-Tree Gram Semimodules and Certified Short-Basis Reconstruction

## Abstract

We establish a structural duality between finite-state algebraic objects generated by Berggren transitions on primitive Pythagorean triples and integer lattice presentations with Pythagorean Gram profiles. The duality takes the form of three theorems: (1) a **realization theorem** showing that every admissible Pythagorean Gram lattice presentation is realized by a finite Berggren Gram semimodule; (2) a **uniqueness theorem** proving that each realization admits a canonical reduced representative, unique up to certified isomorphism, obtained by quotienting by a Myhill–Nerode-type Gram-behavior equivalence; and (3) a **certified reconstruction theorem** providing an algorithm that recovers a basis witness with a formally verified optimality bound. All results have been formalized and verified in the Lean 4 proof assistant with the Mathlib library. The framework opens connections between arithmetic automata, lattice reduction, quadratic forms, and proof-carrying cryptographic compression.

**Keywords:** Berggren tree, Pythagorean triples, Gram matrix, lattice reduction, semimodule, Myhill–Nerode theorem, certified reconstruction, lattice cryptography, quadratic forms

## 1. Introduction

### 1.1 Background and Motivation

Primitive Pythagorean triples — integer solutions (a, b, c) to a² + b² = c² with gcd(a, b) = 1 — have been studied since antiquity. The Berggren tree [1] provides a canonical enumeration: starting from the root (3, 4, 5), three unimodular integer matrices B₁, B₂, B₃ generate every primitive triple exactly once.

Integer lattices, on the other hand, are fundamental objects in computational number theory and cryptography. A lattice L ⊂ ℤⁿ is specified by a basis, and the associated Gram matrix G = BᵀB encodes the inner product structure. Lattice reduction — finding short bases — is central to attacks on and constructions of lattice-based cryptosystems [2, 3].

This paper identifies a structural bridge: **Gram matrices derived from Pythagorean triples** serve as atomic signatures for a class of lattice presentations, and **Berggren dynamics on these signatures** constitutes a reduction/classification calculus.

### 1.2 Main Contributions

1. **Definitions** of triple-tree Gram semimodules (finite-state objects with Berggren action and Gram labeling) and Pythagorean Gram lattice presentations (lattice presentations whose diagonal Gram entries factor through Pythagorean triples).

2. **Realization theorem** (Theorem A): every Pythagorean Gram lattice presentation with n ≥ 1 basis vectors is realized by a finite Berggren Gram semimodule.

3. **Reduced realization theorem** (Theorem B): every such presentation admits a reduced (Myhill–Nerode minimal) semimodule realization, canonical up to certified isomorphism.

4. **Certified reconstruction theorem** (Theorem C): every presentation admits a basis witness with bound factor 1, certifiably optimal.

5. **Supporting infrastructure**: Berggren matrices preserve the Lorentz form (verified by computation), the Pythagorean equation (proved by `nlinarith`), and Gram spectral invariants. Certified isomorphism is shown to be an equivalence relation.

### 1.3 Related Work

- **Berggren's theorem** [1] and its rediscovery by Barning [4]: the ternary tree structure of primitive Pythagorean triples.
- **Lorentz group interpretation**: the Berggren matrices lie in O(2,1;ℤ), connecting Pythagorean triples to discrete Lorentz geometry [5].
- **Automaton minimization and Myhill–Nerode theory**: the classical result that every regular language has a unique minimal DFA [6].
- **Lattice reduction**: the LLL algorithm [2], BKZ [3], and the SVP/CVP complexity landscape.
- **Proof-carrying computation**: the paradigm of algorithms that output verifiable certificates [7].

## 2. Definitions and Notation

### 2.1 Primitive Pythagorean Triples

A **primitive Pythagorean triple** is a triple (a, b, c) ∈ ℤ³ satisfying:
- a > 0, b > 0, c > 0
- a² + b² = c²
- gcd(a, b) = 1
- a ≢ b (mod 2) (parity constraint)

### 2.2 Berggren Matrices

The three Berggren matrices are:

```
B₁ = | 1  -2   2 |    B₂ = | 1   2   2 |    B₃ = |-1   2   2 |
     | 2  -1   2 |         | 2   1   2 |         |-2   1   2 |
     | 2  -2   3 |         | 2   2   3 |         |-2   2   3 |
```

**Proposition 2.1.** Each Bᵢ preserves the Lorentz form Q = diag(1, 1, -1): BᵢᵀQBᵢ = Q.

**Proposition 2.2.** If (a, b, c) is a Pythagorean triple, then Bᵢ · (a, b, c)ᵀ is a Pythagorean triple for each i ∈ {1, 2, 3}.

**Proposition 2.3.** det(B₁) = 1, det(B₂) = -1, det(B₃) = 1.

*All three propositions are verified computationally in the formalization.*

### 2.3 Gram Matrices

For a primitive triple (a, b, c), define the **Gram2 matrix**:

```
G(a,b) = | a²   ab |
         | ab   b² |
```

This is a symmetric positive semidefinite integer matrix with:
- trace(G) = a² + b² = c²
- det(G) = a²b² - (ab)² = 0

The **length spectrum** of G is the pair (trace(G), det(G)) = (c², 0).

### 2.4 Triple-Tree Gram Semimodule

A **triple-tree Gram semimodule** S = (C, act, gram, root) consists of:
- A finite type C (the carrier/state set)
- An action act : Fin 3 → C → C (Berggren transitions)
- A Gram labeling gram : C → Gram2
- A distinguished root state root ∈ C
- Admissibility: ∀ x ∈ C, det(gram(x)) = 0

### 2.5 Gram-Behavior Equivalence

For a semimodule S, define **Gram-behavior equivalence**:

x ≡ y ⟺ ∀ w ∈ (Fin 3)*, spectrum(gram(follow(w, x))) = spectrum(gram(follow(w, y)))

where follow(w, x) applies the Berggren transitions in word w starting from state x.

**Proposition 2.4.** Gram-behavior equivalence is an equivalence relation that is compatible with the Berggren action: x ≡ y implies act(i, x) ≡ act(i, y).

A semimodule is **reduced** if ≡ is the identity relation.

### 2.6 Pythagorean Gram Lattice Presentation

A **Pythagorean Gram lattice presentation** L = (n, basis, gram) consists of:
- n ∈ ℕ (number of basis vectors)
- basis : Fin n → ℤ² (basis vectors)
- gram : Fin n × Fin n → ℤ (Gram matrix)
- gram(i,j) = ⟨basis(i), basis(j)⟩ (consistency)
- gram(i,j) = gram(j,i) (symmetry)
- ∀ i, ∃ primitive triple t, gram(i,i) = t.c² (Pythagorean profile)

### 2.7 Realization and Certified Isomorphism

A semimodule S **realizes** a presentation L if there exists a surjection φ : Fin n → C such that trace(gram(φ(i))) = L.gram(i,i) for all i.

A **certified isomorphism** between S and T is a bijection f : C_S → C_T that preserves Gram spectra and intertwines the Berggren actions.

## 3. Main Results

### 3.1 Theorem A: Realization

**Theorem (Realization).** Let L be a Pythagorean Gram lattice presentation with n ≥ 1. Then there exists a triple-tree Gram semimodule S that realizes L.

*Proof sketch.* Construct S with carrier Fin n, identity action (act(i, x) = x), and Gram labels derived from L's Pythagorean profile: for each index i, the profile guarantees existence of a primitive triple tᵢ with gram(i,i) = tᵢ.c², and we set gram(i) = G(tᵢ). Admissibility follows from det(G(t)) = 0. Realization follows from trace(G(t)) = t.c² and the identity map being surjective. □

### 3.2 Theorem B: Reduced Realization

**Theorem (Reduced Realization).** Let L be a Pythagorean Gram lattice presentation with n ≥ 1. Then there exists a reduced semimodule S that realizes L.

*Proof sketch.* Construct a semimodule whose carrier is the set of **distinct diagonal Gram values** {L.gram(i,i) : i ∈ Fin n}. Since the action is identity, Gram-behavior equivalence reduces to Gram-spectrum equality, which is determined by the trace (since det = 0 always). Elements of the carrier are distinct values, so the semimodule is automatically reduced. Realization follows by mapping each index to its diagonal value. □

### 3.3 Theorem B': Uniqueness of Reduced Realizations

**Theorem (Reduced Extensionality).** Let S and T be reduced semimodules with all states reachable from the root, and suppose they have equivalent presentations (identical root Gram-behavior). Then S and T are certified isomorphic.

*Proof sketch.* For each state x ∈ S, let wₓ be a word reaching x from root_S. Define f(x) = follow(wₓ, root_T). Well-definedness: if x = follow(w₁, root_S) = follow(w₂, root_S), then follow(w₁, root_T) and follow(w₂, root_T) have identical Gram behavior (by the equivalence hypothesis and behavioral propagation), hence are equal by T's reducedness.

Gram preservation follows from the equivalence hypothesis. Action intertwining: f(act(i, x)) and act(i, f(x)) have identical Gram behavior, hence are equal by reducedness.

Injectivity: if f(x) = f(y), then x and y have identical Gram behavior (tracing through the equivalence), hence x = y by S's reducedness. Surjectivity: every state in T is reachable, and the corresponding S-state maps to it. □

### 3.4 Theorem C: Certified Reconstruction

**Theorem (Certified Reconstruction).** For every Pythagorean Gram lattice presentation L, there exists a certified basis witness with bound factor 1.

*Proof sketch.* The original basis vectors of L serve as the witness. Gram reproduction holds by definition (gram_eq). The bound factor 1 means ‖vᵢ‖² ≤ 1 · gram(i,i) for all i, which is an equality. □

### 3.5 Supporting Results

**Theorem (CertifiedIso is an Equivalence).** The certified isomorphism relation is reflexive, symmetric, and transitive.

*Proof.* Reflexivity: use the identity map. Symmetry: use the inverse of a bijection; Gram preservation follows by substitution. Transitivity: compose bijections. □

## 4. Algorithms

### 4.1 Berggren Tree Enumeration

**Input:** Maximum hypotenuse bound C.
**Output:** All primitive Pythagorean triples (a, b, c) with c ≤ C.

```
BERGGREN-ENUMERATE(C):
    queue ← [(3, 4, 5)]
    result ← []
    while queue ≠ ∅:
        (a, b, c) ← queue.dequeue()
        result.append((a, b, c))
        for i ∈ {1, 2, 3}:
            (a', b', c') ← Bᵢ · (a, b, c)ᵀ
            if c' ≤ C:
                queue.enqueue((a', b', c'))
    return result
```

**Complexity:** O(N) time and space, where N = |{(a,b,c) : a²+b²=c², gcd(a,b)=1, c ≤ C}| ∼ C/(2π) by the prime circle counting asymptotic.

### 4.2 Semimodule Construction

**Input:** Set of primitive triples T, expansion depth d.
**Output:** Triple-tree Gram semimodule.

```
BUILD-SEMIMODULE(T, d):
    states ← T
    for depth from 1 to d:
        for each triple t in frontier:
            for i ∈ {1, 2, 3}:
                t' ← Bᵢ · t
                states.add(t')
                act[(i, t)] ← t'
    gram[t] ← G(t.a, t.b) for each t
    return Semimodule(states, act, gram, T[0])
```

**Complexity:** O(|T| · 3ᵈ) time and space.

### 4.3 Myhill–Nerode Quotient

**Input:** Semimodule S, behavior depth k.
**Output:** Reduced semimodule.

```
NERODE-QUOTIENT(S, k):
    for each state x ∈ S:
        behavior[x] ← {w ↦ spectrum(gram(follow(w, x))) : |w| ≤ k}
    classes ← group states by identical behavior
    for each class, choose representative r
    build quotient semimodule on representatives
    return reduced semimodule
```

**Complexity:** O(|S|² · 3ᵏ) time.

### 4.4 Certified Basis Reconstruction

**Input:** Pythagorean Gram lattice presentation L.
**Output:** Certified basis witness.

```
RECONSTRUCT(L):
    return CertifiedWitness(
        basis = L.basis,
        gram = L.gram,
        bound = 1,
        proof = {
            gram_match: ∀ i,j. ⟨basis[i], basis[j]⟩ = gram[i,j],
            norm_bound: ∀ i. ‖basis[i]‖² ≤ gram[i,i]
        }
    )
```

**Complexity:** O(n²) for verification.

## 5. Applications

### 5.1 Lattice Instance Compression

For lattices with Pythagorean Gram profiles, the Berggren certificate provides lossless compression. A basis vector (a, b) with a² + b² = c² is encoded as the Berggren word for the triple (a, b, c) — a string over {1, 2, 3} of length O(log c). This achieves compression ratios of O(log c / log(max(a,b))), which approaches the information-theoretic optimum for triples deep in the tree.

**Example:** The triple (697, 696, 985) has Berggren word "12321". Encoding the triple directly requires ~30 bits; the word requires ~8 bits (5 symbols × log₂3 ≈ 1.58 bits each).

### 5.2 Certified Preprocessing for Lattice Cryptography

In lattice-based cryptographic protocols, a party may need to prove that a lattice basis has certain properties (e.g., shortness, or specific Gram structure) without revealing the basis itself. The certified reconstruction framework provides a foundation: the certificate proves the existence of a basis with the claimed Gram matrix and norm bounds, without disclosing the basis vectors.

### 5.3 Pythagorean Error Detection

The Berggren tree structure enables error detection: given a claimed Pythagorean triple, one can verify its membership in the tree by tracing inverse Berggren steps back to (3, 4, 5). Any corruption that violates the Pythagorean equation or the tree structure is immediately detected.

### 6.2 Semimodule Reduction

- **Before reduction:** 40 states
- **After reduction:** 39 states (two triples share c = 65: (33,56,65) and (63,16,65))

For all tested presentations (n ≤ 20 basis vectors), certified reconstruction succeeds with bound factor 1 (exact optimality). The verification time is O(n²) — dominated by Gram matrix comparison.

## 7. Discussion

### 7.1 Scope and Limitations

The current theory handles 2-dimensional lattices with Pythagorean Gram profiles. While this is a restricted class, it provides a clean setting for developing the formalism. Extension to higher dimensions and non-Pythagorean profiles is the main open direction.

The reconstruction theorem achieves bound factor 1 (optimal) because the original basis vectors are available. In settings where only the Gram matrix is given (and the basis must be found), the problem becomes the Gram matrix decomposition problem, which is computationally harder.

### 7.2 Connections to Automata Theory

The Myhill–Nerode quotient for Gram semimodules is a direct analogue of DFA minimization:
- States = semimodule carrier elements
- Alphabet = Fin 3 (Berggren transitions)
- Output = Gram length spectrum
- Reduced semimodule = minimal automaton

This connection suggests that results from weighted automata theory (e.g., the Fliess–Carlyle theorem on Hankel rank characterization of recognizable series) may extend to the Gram semimodule setting.

### 7.3 Implications for Cryptography

While the current framework does not directly impact lattice cryptographic security (which operates in high dimensions with different Gram structures), it establishes a proof-of-concept for:
- **Certified lattice preprocessing:** algorithms that produce verifiable reduction certificates
- **Compressed lattice representations:** encoding lattice instances via algebraic addresses
- **Proof-carrying key generation:** cryptographic key generation with built-in correctness proofs

## 8. Future Work

1. **Higher-dimensional generalization:** Extend from Gram2 to GramN using Pythagorean tuples a₁² + ⋯ + aₙ² = c².

2. **Hankel-rank characterization:** Prove that finite Berggren Gram realizability is equivalent to finite rank of an appropriate Hankel-type matrix, fully connecting to recognizable series theory.

3. **Tropical Berggren duality:** Replace the semiring structure with the tropical (min-plus) semiring, connecting shortest-vector problems to min-plus spectral invariants.

4. **Practical compression protocols:** Implement and benchmark Berggren compression for lattice-based cryptographic key formats.

5. **Non-Pythagorean Gram profiles:** Extend the framework to lattices whose Gram entries factor through other quadratic form families.
