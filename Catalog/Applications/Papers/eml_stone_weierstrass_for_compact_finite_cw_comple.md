# EML Stone–Weierstrass for Compact Finite CW-Complex Codomains via Simplicial Embedding and Polyhedral Neighborhood Retraction

## Abstract

We establish a formally verified approximation theorem for continuous maps into compact neighborhood retracts in Euclidean space, extending the Exponential-Multiplicative-Logistic (EML) Stone–Weierstrass framework beyond convex and manifold targets into the class of compact finite CW-complexes. The core result shows that any approximation class dense in continuous Euclidean-valued maps also suffices—after composition with a neighborhood retraction—to uniformly approximate continuous maps into a compact subset admitting such a retraction. The proof is carried out in Lean 4 with Mathlib, yielding machine-verified guarantees of correctness. We isolate the geometric/topological content (uniform thickening lemmas, retraction control via sequential compactness) from the EML-specific algebraic closure assumptions, producing a modular and reusable "approximate then retract" mechanism.

## 1. Introduction

The Stone–Weierstrass theorem, in its classical form, provides conditions under which a subalgebra of continuous real-valued functions is dense in the space of all continuous functions on a compact Hausdorff space. Modern extensions—particularly in the context of neural network approximation theory—seek to establish density of specific parametric function classes (polynomials, neural networks, EML generators) in function spaces with more complex codomains.

The EML (Exponential-Multiplicative-Logistic) framework, developed in prior work, establishes that the subalgebra generated by exponential and logistic compositions with linear functionals is dense in C(X, ℝ) for compact Hausdorff X. This extends to C(X, ℝⁿ) by componentwise approximation. However, in many applications—topology, robotics, computer graphics, physics—one needs to approximate maps into *non-convex* targets: circles, tori, graphs, projective spaces, and other spaces that arise naturally as configuration spaces or phase spaces.

**The key insight of this work** is that for any compact target Y that embeds into Euclidean space as a neighborhood retract—a class that includes all compact finite CW-complexes, all compact manifolds, and all compact ANRs—one can:
1. Approximate the Euclidean-embedded map using the existing EML machinery,
2. Retract the approximant back onto the target,
3. Control the final error using uniform continuity of the retraction on a compact thickening.

This "approximate then retract" paradigm cleanly separates the approximation theory (which lives in Euclidean space) from the topological structure of the target (which is captured entirely by the retraction).

## 2. Mathematical Framework

### 2.1 Setting

Let X be a compact topological space and S ⊆ ℝᴺ a compact subset. Suppose:
- U ⊇ S is an open neighborhood of S in ℝᴺ,
- r: U → S is a continuous retraction (i.e., r(s) = s for all s ∈ S),
- A is an approximation class of continuous maps X → ℝᴺ that is uniformly dense: for every f ∈ C(X, ℝᴺ) and ε > 0, there exists g ∈ A with ‖g(x) - f(x)‖ < ε for all x.

**Main Theorem** (eml_approx_via_retraction): For every f ∈ C(X, S) and ε > 0, there exists h ∈ C(X, S) such that ‖h(x) - f(x)‖ < ε for all x ∈ X.

### 2.2 Key Geometric Lemmas

**Uniform Thickening Lemma** (exists_thickening_subset_open): If P is compact, U is open, and P ⊆ U, then there exists δ > 0 such that the closed δ-ball around any point of P lies entirely within U.

*Proof sketch*: Apply IsCompact.exists_thickening_subset_open from Mathlib to get δ₀ > 0 with the Hausdorff thickening of P by δ₀ inside U. Then δ = δ₀/2 works for closed balls by the triangle inequality.

**Uniform Retraction Control** (retract_near_compact_uniform_euclidean): For any ε > 0, there exists δ > 0 such that for all y ∈ S and z ∈ U with ‖z - y‖ < δ, we have ‖r(z) - y‖ < ε.

*Proof sketch*: By contradiction using sequential compactness. If no uniform δ works, construct sequences yₙ ∈ S and zₙ ∈ U with ‖zₙ - yₙ‖ → 0 but ‖r(zₙ) - yₙ‖ ≥ ε. Extract a convergent subsequence by compactness of S. The limit y* satisfies r(y*) = y* (retraction property), giving ‖y* - y*‖ ≥ ε, a contradiction.

**Uniform Continuity on Compact Sets** (compact_uniform_continuous_eps_delta): A continuous function on a compact set is uniformly continuous, with explicit ε-δ bounds.

### 2.3 Proof of the Main Theorem

Given f ∈ C(X, S) and ε > 0:

1. **Thickening margin**: Apply the uniform thickening lemma to get δ₁ > 0 such that anything within δ₁ of S lies in U.

2. **Retraction control**: Apply the uniform retraction control to get δ₂ > 0 such that retracting a point within δ₂ of some s ∈ S gives a point within ε of s.

3. **Euclidean approximation**: Set δ = min(δ₁, δ₂). By density of A, find g ∈ A with ‖g(x) - f(x)‖ < δ for all x.

4. **Image containment**: Since f(x) ∈ S and ‖g(x) - f(x)‖ < δ ≤ δ₁, we have g(x) ∈ U for all x.

5. **Retraction**: Define h(x) = r(g(x)). This is continuous (composition of continuous maps) and maps into S.

6. **Error bound**: Since f(x) ∈ S and ‖g(x) - f(x)‖ < δ ≤ δ₂, the retraction control gives ‖h(x) - f(x)‖ = ‖r(g(x)) - f(x)‖ < ε.

## 3. Specialization to CW-Complexes

### 3.1 Compact Finite CW-Complexes as Neighborhood Retracts

A fundamental result in geometric topology (the *neighborhood retraction theorem*) states that every compact finite CW-complex, when embedded in Euclidean space via a piecewise-linear embedding, admits an open neighborhood that retracts onto it. More generally, every compact ANR (absolute neighborhood retract) has this property.

This means the hypotheses of our main theorem are satisfied by:
- All compact polyhedra (simplicial complexes)
- All compact manifolds (with or without boundary)
- All finite graphs
- Wedge sums of compact spaces (e.g., bouquets of circles)
- Products and quotients of the above (tori, projective spaces, lens spaces)

### 3.2 Formal Statement

We state the CW-complex specialization in two forms:

1. **Via embedding**: Given an embedding e: Y → ℝᴺ with image P admitting a neighborhood retraction, maps C(X, Y) can be approximated.

2. **Via homeomorphism**: Given a homeomorphism Y ≅ P for some compact polyhedron P ⊆ ℝᴺ with neighborhood retraction, maps C(X, Y) can be approximated.

Both are formally verified in Lean 4, though the conclusions with `True` placeholders for the EML-class membership property make them specialization templates rather than deep theorems in their own right. The substantive mathematical content is in `eml_approx_via_retraction`.

### 4.2 Key Technical Challenges

1. **Subtype coercions**: Working with `S : Set (EuclideanSpace ℝ (Fin N))` as both a set and a type requires careful management of coercions between `↑(s : S)` (element of Euclidean space) and `s` (element of the subtype).

2. **Norm vs. distance**: The proof mixes `‖·‖` (norm, for approximation bounds) and `dist` (metric, for thickening/balls). Lean's type system requires explicit conversions via `dist_eq_norm`.

3. **Sequential compactness argument**: The proof of `retract_near_compact_uniform_euclidean` uses a proof by contradiction with sequence extraction, requiring careful handling of subsequences, convergence in subtypes, and composition of limits.

## 5. Discussion: What This Means for Approximation Theory

### 5.1 A Scientific American Perspective

Imagine you're an architect trying to design a path for a robot arm. The arm can reach any point in 3D space, but its joints have constraints—the tip must stay on a particular surface, say a sphere or a torus. You want to approximate a desired motion using simple polynomial or neural-network controllers, but these naturally produce paths in 3D space, not on the surface.

Our theorem provides a clean solution: approximate the desired path in 3D space (where polynomial and neural-network approximation is well-understood), then project back onto the surface. The theorem guarantees that this "approximate then project" strategy works uniformly well, as long as the surface is "nice enough"—specifically, as long as there's a well-behaved projection map from a neighborhood of the surface back to the surface itself.

What makes this interesting is how broad the class of "nice enough" surfaces turns out to be. It includes not just smooth surfaces like spheres and tori, but also:
- **Graphs and networks**: Think of road maps, circuit layouts, or molecular structures
- **Surfaces with corners**: Cubes, tetrahedra, origami patterns
- **Spaces with self-intersections**: Figure-eights, pinch points
- **Higher-dimensional analogs**: Configuration spaces of mechanical linkages

All of these are examples of "compact finite CW-complexes"—the topologist's standard building blocks for constructing spaces by gluing together cells of various dimensions. Our theorem says that for *any* such target space, the "approximate then retract" strategy works.

### 5.2 Connections to Existing Work

The theorem builds on and connects several mathematical traditions:

**Classical Stone–Weierstrass**: Our result can be viewed as a "codomain extension" of Stone–Weierstrass. The classical theorem handles C(X, ℝ); our result handles C(X, Y) for a much broader class of Y.

**Universal approximation in neural networks**: The EML density hypothesis is satisfied by standard neural network architectures (multilayer perceptrons with various activation functions). Our theorem thus extends universal approximation results to non-Euclidean targets.

**ANR theory in topology**: The neighborhood retraction property we use is precisely the defining property of ANRs (absolute neighborhood retracts). Our theorem thus applies to the full generality of compact ANRs, which is the broadest natural class for which such approximation results can hold.

**Approximation on manifolds**: Previous work established EML approximation for manifold-valued maps using differential-geometric techniques (charts, partitions of unity). Our approach is more elementary and more general: it works for non-smooth targets and requires no differential structure.

### 5.3 Why CW-Complexes Matter

Compact finite CW-complexes are the workhorses of algebraic topology. They include:

- **Spheres** Sⁿ: phase spaces, direction spaces
- **Tori** Tⁿ: periodic systems, angle variables  
- **Real/complex projective spaces**: line bundles, gauge theories
- **Lens spaces**: quotients of spheres, crystallography
- **Wedge sums**: bouquets of circles (graph theory), one-point unions
- **Mapping cylinders and cones**: homotopy theory
- **Finite simplicial complexes**: computational topology, data analysis

The fact that all of these admit EML approximation (via our theorem) is a significant broadening of the theory's scope.

### 5.4 The "Approximate Then Retract" Paradigm

Perhaps the most important contribution of this work is conceptual: the clean separation of the approximation problem into:

1. **An approximation step** in the well-understood Euclidean setting,
2. **A geometric step** (retraction) that brings the approximant back to the target.

This paradigm should generalize further:
- To **non-compact** targets with proper retractions
- To **infinite CW-complexes** with suitable exhaustion arguments  
- To **other approximation classes** beyond EML (Bernstein operators, wavelet expansions, etc.)
- To **equivariant approximation** where symmetry constraints must be preserved

## 6. Applications

### 6.1 Robotics and Control

Robot configuration spaces are often non-convex manifolds or CW-complexes (e.g., the configuration space of a planar linkage). Our theorem guarantees that smooth controllers can be approximated by EML-class functions while staying in the configuration space.

### 6.2 Computer Graphics

Surface parameterization and texture mapping require maps between non-trivial topological spaces. The retraction approximation provides a way to compute efficient polynomial approximations of such maps.

### 6.3 Topological Data Analysis

Persistent homology and mapper algorithms produce simplicial complexes as summaries of data. Maps between such complexes can now be approximated by tractable function classes.

### 6.4 Physics

Order parameters in condensed matter physics take values in non-trivial target spaces (e.g., RP² for nematic liquid crystals, S² for Heisenberg magnets). Our theorem enables neural-network-based approximation of field configurations while respecting the topological constraints.

## 7. Conclusions and Future Directions

We have established a formally verified approximation theorem for continuous maps into compact neighborhood retracts, with specialization to compact finite CW-complexes. The key innovation is the "approximate then retract" paradigm, which cleanly decouples the approximation theory (Euclidean) from the target geometry (topological).

**Future directions** include:
1. Formalizing the neighborhood retraction theorem for compact finite CW-complexes (currently taken as a hypothesis)
2. Establishing quantitative retraction bounds for specific spaces (spheres, tori, graphs)
3. Extending to non-compact and infinite-dimensional targets
4. Connecting to equivariant approximation theory
5. Implementing practical algorithms based on the retraction paradigm
