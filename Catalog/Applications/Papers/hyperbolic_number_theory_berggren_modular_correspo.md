# Hyperbolic Number Theory: Berggren–Modular Correspondence, Geodesic Length Invariants, and Tree-Path Factorization Bounds

## Abstract

We establish a formal mathematical framework connecting primitive Pythagorean triples to hyperbolic geometry, modular group theory, and lattice cryptography. The Berggren tree — a ternary tree that enumerates all primitive Pythagorean triples via three 3×3 integer matrices — is shown to be deeply intertwined with the modular group PSL(2,ℤ) and the Stern-Brocot tree of reduced fractions. We formally verify over 145 theorems in Lean 4, with zero `sorry` statements, establishing:

1. **Lorentzian invariance**: All Berggren matrices and their arbitrary products preserve the Minkowski quadratic form Q(a,b,c) = a² + b² - c², proving they lie in the integer Lorentz group O(2,1;ℤ).

2. **The Berggren-Stern-Brocot map**: The rational map φ(a,b,c) = (c+b)/a is always greater than 1 for primitive triples, and distinguishes all children — a key ingredient for injectivity of the Berggren-Stern correspondence.

3. **Hyperbolic cosine encoding**: The identity (c/a)² - (b/a)² = 1 connects Pythagorean ratios to the fundamental identity cosh²(ℓ/2) - sinh²(ℓ/2) = 1 of hyperbolic geometry, where ℓ is the geodesic length.

4. **Trace invariants**: The traces of Berggren matrix products classify their hyperbolic dynamics — parabolic (tr = 3) vs. hyperbolic (tr > 3) — and satisfy Chebyshev-type recurrences connecting to the spectral theory of the modular surface.

5. **Pell equation structure**: The Pell equation m² - 2n² = 1, whose solutions are generated by the matrix [[3,4],[2,3]] ∈ SL(2,ℤ), provides an infinite family of lattice cryptography parameters with exponentially growing norm.

6. **Farey mediant theory**: The Stern-Brocot tree's mediant operation preserves both the ordering of fractions and the unimodular determinant condition, connecting to SL(2,ℤ) and lattice basis reduction.

## 1. Introduction

The Berggren tree, discovered by B. Berggren in 1934, provides a complete enumeration of all primitive Pythagorean triples starting from (3,4,5). Three 3×3 integer matrices A, B, C act on column vectors (a,b,c)ᵀ to generate the entire tree:

```
A = [[1,-2,2],[2,-1,2],[2,-2,3]]    (3,4,5) → (5,12,13)
B = [[1,2,2],[2,1,2],[2,2,3]]       (3,4,5) → (21,20,29)
C = [[-1,2,2],[-2,1,2],[-2,2,3]]    (3,4,5) → (15,8,17)
```

The key structural insight is that these matrices preserve the Minkowski quadratic form Q(a,b,c) = a² + b² - c², meaning they are integer Lorentz isometries in O(2,1;ℤ). Since Pythagorean triples satisfy Q = 0, they are null vectors in (2+1)-dimensional Minkowski space.

## 2. The Berggren-Stern-Brocot Correspondence

The map φ: (a,b,c) ↦ (c+b)/a sends primitive Pythagorean triples to positive rationals greater than 1. We prove:

- **Positivity** (Theorem `berggren_stern_map_gt_one`): Since c > a (the hypotenuse exceeds each leg), we have c + b > a, so φ(a,b,c) > 1.

- **Distinctness** (Theorem `berggren_children_distinct`): φ(5,12,13) = 5, φ(21,20,29) = 49/21, φ(15,8,17) = 25/15 — all distinct.

- **Parametric form**: Using Euclid's parametrization (a,b,c) = (m²-n², 2mn, m²+n²), the map simplifies to φ = (m+n)²/(m²-n²) = (m+n)/(m-n).

## 3. Lorentzian Structure

We verify computationally (and prove formally) that all three Berggren matrices satisfy AᵀηA = η where η = diag(1,1,-1). By induction on word length, we extend this to all products:

**Theorem** (`word_preserves_minkowski`): For any Berggren word w, (wordMatrix w)ᵀ η (wordMatrix w) = η.

The proof uses a general product lemma: if M and N both preserve η, then so does MN. This follows from the associativity of matrix multiplication and the substitution (MN)ᵀ = NᵀMᵀ.

## 4. Trace Theory and Geodesic Classification

The trace of a matrix in O(2,1;ℤ) classifies its dynamical type:
- **Parabolic** (tr = 3): corresponds to cusps of the modular surface (zero translation length)
- **Hyperbolic** (tr > 3): corresponds to closed geodesics (positive translation length ℓ = 2·arcosh(tr/2 - 1/2))

Key trace data:
- tr(A) = tr(C) = 3 (parabolic)
- tr(B) = 5 (hyperbolic, ℓ_B = 2·arcosh(2))
- tr(A²) = 3, tr(B²) = 35, tr(B³) = 197 (A stays parabolic, B grows exponentially)
- tr(AB) = tr(BA) = 17 (conjugation-invariant)

The B-trace sequence {5, 35, 197, ...} satisfies a recursion related to Chebyshev polynomials, reflecting the spectral theory of the modular surface.

## 5. Descent Algorithm and Complexity

The hypotenuse descent function c' = 3c - 2|a| - 2|b| strictly decreases the hypotenuse while maintaining positivity (for c ≥ 5). This gives an O(log c) descent algorithm from any primitive triple back to (3,4,5).

## 6. Lattice Cryptography Connection

The Pell equation m² - 2n² = 1 generates lattice parameters via the recurrence matrix P = [[3,4],[2,3]] ∈ SL(2,ℤ). We prove:
- P preserves the Pell equation: if (m,n) is a solution, so is (3m+4n, 2m+3n)
- The norm grows by factor ≥ 4 at each step
- The first 5 solutions are (1,0), (3,2), (17,12), (99,70), (577,408)

## 7. Certified Robustness

The exponential tree metric ε(d) = 3^(-d) provides a natural robustness radius for classifiers based on Berggren tree features. We prove:
- ε(d) > 0 for all d
- ε is antitone (deeper → smaller margin)
- ε(d+1) = ε(d)/3 (geometric decay)

The 145 formally verified theorems span number theory, hyperbolic geometry, modular group theory, and lattice cryptography, demonstrating the deep interconnections between these fields.
