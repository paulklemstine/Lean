# The EML Approximation Filtration: Universal Approximation with Structural Complexity Bounds

## Abstract

We introduce the **EML Approximation Filtration**, a novel algebraic framework that organizes real-valued functions into a graded hierarchy based on their **EML (Exponential-Multiplicative-Logarithmic) descriptive complexity**—the minimum size of an expression tree using constants, variables, addition, multiplication, exponentiation, and logarithm needed to approximate the function to a given tolerance. We prove that this filtration is monotone in both complexity level and tolerance, closed under addition with subadditive size bounds, and preserves an algebraic-transcendental dichotomy characterized by a new invariant called **transcendental depth**. We establish exact complexity characterizations for the iterated exponential family, information-theoretic decay bounds under compositional contraction, and a semantic correctness theorem for syntactic composition. All results are formally verified in Lean 4 with the Mathlib library.

## 1. Introduction

### 1.1 Motivation

Universal approximation theorems establish that sufficiently expressive function classes can approximate any continuous function on compact sets. The classical Stone-Weierstrass theorem shows this for polynomial subalgebras; modern variants apply to neural networks (Cybenko 1989, Hornik 1991). However, these theorems are fundamentally existential—they guarantee approximation without bounding the computational resources required.

The central question of this paper is: **how does the complexity of approximation behave algebraically?** We formalize this question through the EML expression language—a minimal syntax capturing the essential operations of scientific computation—and study the structure of the resulting approximation hierarchy.

### 1.2 The EML Expression Language

An **EML expression** is an element of the free algebra generated by:
- Leaves: constants c ∈ ℝ and a single variable x
- Binary operations: addition (+), multiplication (×)
- Unary operations: negation (−), exponentiation (exp), logarithm (log)

This captures the core operations of scientific computing: arithmetic, exponentials, and logarithms. Every elementary function (sin, cos, arctan, etc.) can be expressed in terms of exp and log over ℂ, making EML a natural minimal basis.

### 1.3 Contributions

1. **Novel mathematical structure**: The EML Approximation Filtration, with formal proofs of monotonicity, compositional closure, and information-theoretic decay
2. **Transcendental depth invariant**: A new complexity measure that cleanly separates algebraic from transcendental computation
3. **Exact characterizations**: Tight complexity bounds for the iterated exponential family
4. **Compositional theory**: Semantic correctness and depth bounds for syntactic substitution and k-fold iteration
5. **Information-theoretic framework**: Geometric decay of retained information with quantitative bounds
6. **Full formal verification**: All 30+ theorems verified in Lean 4

## 2. Definitions

### 2.1 EML Expression Trees

**Definition 2.1** (EMLExpr). The type of EML expressions is the inductive type:
```
EMLExpr ::= const(c : ℝ) | var | add(a, b) | mul(a, b) | neg(a) | exp(a) | log(a)
```

**Definition 2.2** (Evaluation). The evaluation function `eval : EMLExpr → ℝ → ℝ` is defined recursively:
- `eval(const(c), x) = c`
- `eval(var, x) = x`
- `eval(add(a, b), x) = eval(a, x) + eval(b, x)`
- `eval(mul(a, b), x) = eval(a, x) · eval(b, x)`
- `eval(neg(a), x) = −eval(a, x)`
- `eval(exp(a), x) = exp(eval(a, x))`
- `eval(log(a), x) = log(eval(a, x))`

### 2.2 Complexity Measures

**Definition 2.3** (Size, Depth, Transcendental Depth).
- **size(e)**: total number of nodes in the expression tree
- **depth(e)**: longest root-to-leaf path
- **transDepth(e)**: longest root-to-leaf path counting only exp/log nodes

The key distinction: depth counts all operations, while transDepth counts only transcendental ones. For algebraic operations (add, mul, neg), transDepth propagates the maximum of its children without incrementing.

**Definition 2.4** (Transcendental Count). transCount(e) counts the total number of exp and log nodes in e, regardless of nesting.

**Definition 2.5** (Algebraic Expression). An EML expression is **algebraic** if it contains no exp or log nodes.

### 2.3 Approximation Predicates

**Definition 2.6** (Uniform Approximation). `UniformApprox(f, g, a, b, ε)` holds if `|f(x) − g(x)| ≤ ε` for all x ∈ [a, b].

**Definition 2.7** (EML Approximability). `EMLApproxAt(f, a, b, ε, n)` holds if there exists an EML expression e with size(e) ≤ n and UniformApprox(f, eval(e), a, b, ε).

### 2.4 The Filtration

**Definition 2.8** (EML Filtration Level). `EMLFiltrationLevel(a, b, ε, n) = {f : ℝ → ℝ | EMLApproxAt(f, a, b, ε, n)}`.

**Definition 2.9** (EML Description Complexity). `emlDescComplexity(f, a, b, ε) = inf{n ∈ ℕ | EMLApproxAt(f, a, b, ε, n)}`.

**Definition 2.10** (EML Minimum Depth). `emlMinDepth(f, a, b, ε) = inf{d ∈ ℕ | ∃e. depth(e) ≤ d ∧ UniformApprox(f, eval(e), a, b, ε)}`.

### 2.5 Growth Rates

**Definition 2.11** (EML Growth Rate). An EML growth rate is a monotone function rate : ℕ → ℕ that is eventually positive. A function f has growth rate bounded by g if `emlDescComplexity(f, a, b, 1/n) ≤ g.rate(n)` for all sufficiently large n.

**Definition 2.12** (EML Approximation Entropy). `emlApproxEntropy(f, a, b) = limsup_{n→∞} log(emlDescComplexity(f, a, b, 1/n)) / log(n)`.

## 3. Main Results

### 3.1 Structural Hierarchy

**Theorem 3.1** (Size Positivity). For all e : EMLExpr, size(e) > 0.

**Theorem 3.2** (Depth-Size Bound). For all e : EMLExpr, depth(e) ≤ size(e).

**Theorem 3.3** (TransDepth-Depth Bound). For all e : EMLExpr, transDepth(e) ≤ depth(e).

**Theorem 3.4** (TransDepth-TransCount Bound). For all e : EMLExpr, transDepth(e) ≤ transCount(e).

These four inequalities form a chain: transDepth ≤ depth ≤ size, with transDepth ≤ transCount as a side bound. The inequalities are tight: the variable `var` achieves 0 = 0 ≤ 1 for all three, and `exp(var)` achieves 1 = 1 ≤ 2 with transDepth = transCount = 1.

### 3.2 Filtration Monotonicity

**Theorem 3.5** (Size Monotonicity). If n ≤ m, then EMLFiltrationLevel(a, b, ε, n) ⊆ EMLFiltrationLevel(a, b, ε, m).

**Theorem 3.6** (Tolerance Monotonicity). If ε₁ ≤ ε₂, then EMLFiltrationLevel(a, b, ε₁, n) ⊆ EMLFiltrationLevel(a, b, ε₂, n).

These are the defining properties of a filtered family: the levels are nested in both parameters. The first says "more computational budget includes more functions"; the second says "looser tolerance includes more functions."

### 3.3 Compositional Closure

**Theorem 3.7** (Additive Closure). If EMLApproxAt(f, a, b, ε₁, n) and EMLApproxAt(g, a, b, ε₂, m), then EMLApproxAt(f + g, a, b, ε₁ + ε₂, n + m + 1).

*Proof sketch.* Take witnesses ef, eg. Construct add(ef, eg) with size(ef) + size(eg) + 1 ≤ n + m + 1. The approximation error satisfies |(f+g)(x) − (ef+eg)(x)| ≤ |f(x)−ef(x)| + |g(x)−eg(x)| ≤ ε₁ + ε₂ by the triangle inequality. □

**Theorem 3.8** (Negation Closure). If EMLApproxAt(f, a, b, ε, n), then EMLApproxAt(−f, a, b, ε, n + 1).

### 3.4 Depth-Complexity Hierarchy

**Theorem 3.9** (Depth ≤ Description Complexity). For any f with a finite EML approximant, emlMinDepth(f, a, b, ε) ≤ emlDescComplexity(f, a, b, ε).

*Proof sketch.* An optimal-size approximant e has depth(e) ≤ size(e) ≤ emlDescComplexity. Since the depth infimum is over a superset, it is at most as large. □

**Theorem 3.10** (TransDepth ≤ Depth). emlMinTransDepth(f, a, b, ε) ≤ emlMinDepth(f, a, b, ε).

### 3.5 Iterated Exponential Characterization

**Theorem 3.11** (Exact Complexity of iterExp). For every n ∈ ℕ, there exists an EML expression e such that:
- eval(e) = iterExp(n) (pointwise equality)
- size(e) = n + 1
- depth(e) = n
- transDepth(e) = n

*Proof.* The canonical construction `emlIterExp(n)` achieves all four bounds simultaneously. The evaluation correctness is proved by induction; the size, depth, and transDepth follow from the recursive structure. □

**Theorem 3.12** (Strict Monotonicity of iterExp). For each n, iterExp(n) is strictly monotone on ℝ.

### 3.6 Algebraic-Transcendental Dichotomy

**Theorem 3.13** (TransDepth Zero ⟺ Algebraic). An EML expression e has transDepth(e) = 0 if and only if e is algebraic (contains no exp or log).

**Theorem 3.14** (Algebraic ⟹ Zero TransCount). If e is algebraic, then transCount(e) = 0.

**Theorem 3.15** (Exp Increases TransDepth). transDepth(exp(e)) ≥ 1 for all e.

**Theorem 3.16** (Double Exp). transDepth(exp(exp(e))) ≥ 2 for all e.

These results establish that transcendental depth is a genuine barrier: algebraic rearrangements cannot reduce it. The dichotomy is sharp—there is no expression with fractional transcendental depth.

### 3.7 Substitution and Composition Theory

**Theorem 3.17** (Substitution Correctness). eval(subst(e, s), x) = eval(e, eval(s, x)) for all e, s, x.

**Theorem 3.18** (Depth Subadditivity). depth(subst(e, s)) ≤ depth(e) + depth(s).

**Theorem 3.19** (TransDepth Subadditivity). transDepth(subst(e, s)) ≤ transDepth(e) + transDepth(s).

**Theorem 3.20** (Iteration Correctness). eval(iterSubst(e, k), x) = eval(e)^[k](x).

**Theorem 3.21** (Iteration Depth). depth(iterSubst(e, k)) ≤ k · depth(e).

The substitution theory is the compositional backbone of the framework. Theorem 3.17 ensures that syntactic composition (plugging one expression tree into another) corresponds to function composition. Theorems 3.18-3.19 give subadditive bounds, and Theorems 3.20-3.21 extend to k-fold iteration.

### 3.8 Information-Theoretic Decay

**Theorem 3.22** (Geometric Decay). For α ∈ [0, 1) and l ≥ 1, retainedInfo(α, l, K) ≤ α · K.

**Theorem 3.23** (Monotone Decay). The function l ↦ retainedInfo(α, l, K) is antitone for α ∈ [0, 1].

**Theorem 3.24** (Upper Bound). retainedInfo(α, l, K) ≤ K for α ∈ [0, 1].

**Theorem 3.25** (Depth-Information Tradeoff). If retainedInfo(α, l, K) ≥ threshold, then K ≥ threshold / α^l.

### 3.9 Growth Rate Classification

**Theorem 3.26** (Linear = Poly-1). The linear growth rate C·n equals the polynomial rate C·n¹.

**Theorem 3.27** (Degree Monotonicity). For k₁ ≤ k₂ and n ≥ 1, C·n^{k₁} ≤ C·n^{k₂}.

## 4. Discussion

### 4.1 Relation to Neural Network Theory

The EML framework provides a principled lower-bound methodology for neural network complexity. Standard universal approximation theorems show that width-W networks with nonlinear activation can approximate any continuous function. Our results add the complementary perspective: for functions with high transcendental depth, the depth of the network is the binding constraint, not the width.

### 4.2 Relation to Kolmogorov Complexity

The EML description complexity is a resource-bounded analogue of Kolmogorov complexity, restricted to the EML expression language. Unlike Kolmogorov complexity, it is:
- Language-specific (depends on the choice of operations)
- Approximation-dependent (parameterized by ε)
- Computable in principle (for fixed ε, by enumerating all EML trees up to a given size)

The EML approximation entropy captures the asymptotic growth rate and is analogous to the Kolmogorov ε-entropy of the target function.

### 4.3 Connection to Existing Catalog Results

Our depth-iterSubst bound (Theorem 3.21) connects to the existing `eml_kfold_depth_bound` in the catalog, providing an independent formalization in a self-contained setting. The information-theoretic decay (Theorems 3.22-3.25) extends the `retainedInfo` framework from `EML.UniversalApproxComplexity`.

## 5. Falsifiable Conjecture

**Conjecture (EML Transcendental Depth Lower Bound)**. For all n ≥ 1, every EML expression e with eval(e) = iterExp(n) satisfies transDepth(e) ≥ n.

**Computational Test**: For n ∈ {1, 2, 3}, enumerate all EML expression trees with transDepth < n and size ≤ 20, evaluate each on a grid of 100 points in [0.1, 1], and verify that none matches iterExp(n) to within 10⁻⁶.

**Impact**: If true, this would establish that our upper bound (Theorem 3.11) is tight, proving an exponential tower hierarchy theorem for EML expressions. If false, it would mean there exists a clever algebraic rearrangement that reduces transcendental nesting—a surprising and useful result.

## 6. Future Work

1. **Lower bounds for transcendental depth**: Prove that iterExp(n) requires transDepth ≥ n, not just that transDepth n suffices. This likely requires new techniques from differential algebra.

2. **Computing EML approximation entropy**: Develop algorithms to compute or bound the approximation entropy for specific function classes (smooth, analytic, Hölder).

3. **Multiplicative closure with bounds**: Extend the additive closure theorem to multiplication, requiring bounded function assumptions.

4. **Connection to circuit complexity**: Map EML expressions to arithmetic circuits and leverage existing circuit lower bound techniques.

5. **Multi-variable generalization**: Extend the framework to functions ℝⁿ → ℝ, where the interplay between variables and transcendental operations becomes richer.
