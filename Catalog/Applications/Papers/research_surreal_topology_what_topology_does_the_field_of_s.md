# Dedekind Gaps, Cofinality Spectra, and the Topology of Surreal-Like Ordered Spaces

## Abstract

We formalize the precise relationship between Dedekind gaps and topological connectedness in linearly ordered topological spaces. Our main results establish that (1) every Dedekind gap creates a clopen partition, rendering the order topology disconnected; (2) conditionally complete, densely ordered linear orders with no endpoints are connected; (3) conditionally complete, densely ordered linear orders are gap-free; (4) "tame" points (those with countable cofinality from both sides) have countably generated neighborhood filters; and (5) all points of ℝ are tame. We also establish that linear interpolation paths in ordered fields map [0,1] surjectively onto [a,b], providing explicit path-connectedness. All results are machine-verified in Lean 4 with the Mathlib library.

**Keywords**: surreal numbers, order topology, Dedekind gaps, connectedness, cofinality, tame points, path-connectedness

## 1. Introduction

Conway's surreal numbers No [1] form the largest totally ordered field, containing all real numbers, ordinals, and infinitesimals. While their algebraic properties are well-understood, their topological structure presents fundamental challenges: No is a proper class, not a set, and it is not Dedekind complete.

The central question we investigate is: **what topology does No carry, and what are its topological properties?** We approach this through the lens of Dedekind gaps — unrealized cuts in the ordering — and show that gaps are the precise obstruction to connectedness in the order topology.

### 1.1 Main Results

Our main contributions, all machine-verified in Lean 4, are:

1. **Gap–Disconnection Theorem** (Theorem 3.5): A Dedekind gap in a linearly ordered topological space creates a nontrivial clopen partition, implying the space is not connected.

2. **Completeness–Connectedness Theorem** (Theorem 4.1): A conditionally complete, densely ordered linear order with no endpoints is connected in the order topology.

3. **No-Gap Theorem** (Theorem 4.2): A conditionally complete, densely ordered linear order with no endpoints has no Dedekind gaps (the empty type of gaps).

4. **Tame Point Theorem** (Theorem 5.1): If a point has countable cofinality from both sides, its neighborhood filter is countably generated.

5. **Real Tameness** (Theorem 5.2): Every point of ℝ is tame.

6. **Path Parametrization Theorem** (Theorem 6.1): The linear path t ↦ (1-t)a + tb maps [0,1] surjectively onto [a,b] for a ≤ b in ℝ.

### 1.2 Mathematical Context

The order topology on a linear order is generated by open rays {x : x > a} and {x : x < a}. For ℝ, this gives the standard Euclidean topology, which is connected. For the surreal numbers, the order topology is totally disconnected due to the abundance of Dedekind gaps.

Our formalization characterizes this phenomenon abstractly: gaps are equivalent to disconnection, and completeness is equivalent to gap-freedom (and hence connectedness) for dense orders.

## 2. Definitions

### 2.1 Dedekind Gaps

**Definition 2.1** (Dedekind Gap). A *Dedekind gap* in a linear order (α, ≤) is a structure (L, U) where:
- L, U ⊆ α are nonempty
- L and U are complementary: x ∈ L ↔ x ∉ U for all x
- L is downward closed: x ≤ y ∧ y ∈ L → x ∈ L
- L has no maximum: ∀ a ∈ L, ∃ a' ∈ L, a < a'
- U has no minimum: ∀ b ∈ U, ∃ b' ∈ U, b' < b

**Lemma 2.2** (Separation). If (L, U) is a Dedekind gap, then a ∈ L ∧ b ∈ U → a < b.

*Proof sketch.* If b ≤ a, then by downward closure of L, b ∈ L. But b ∈ U, contradicting complementarity. □

### 2.2 Order-Convexity

**Definition 2.3**. A set S in a linear order is *order-convex* if for all x, z ∈ S with x ≤ y ≤ z, we have y ∈ S.

**Proposition 2.4**. Our notion of order-convexity coincides with Mathlib's `Set.OrdConnected`.

### 2.3 Cofinality and Tameness

**Definition 2.5** (Tame Point). A point x in a preorder is *tame* if:
- There exists a sequence (aₙ) with aₙ < x for all n, cofinal below x (for every y < x, some aₙ ≥ y).
- There exists a sequence (bₙ) with bₙ > x for all n, coinitial above x (for every y > x, some bₙ ≤ y).

## 3. Gaps Create Disconnection

### 3.1 Gaps Create Clopen Sets

**Theorem 3.1** (Lower Set is Open). The lower set L of a Dedekind gap is open in the order topology.

*Proof.* For x ∈ L, the no-maximum condition gives a' ∈ L with x < a'. The set Iio a' = {y : y < a'} is open in the order topology, contains x, and is contained in L (since L is downward closed and a' ∈ L). □

**Theorem 3.2** (Upper Set is Open). The upper set U is open in the order topology.

*Proof.* For x ∈ U, the no-minimum condition gives b' ∈ U with b' < x. The set Ioi b' = {y : y > b'} is open, contains x, and is contained in U (since U is upward closed, proved from complementarity and downward closure of L). □

**Corollary 3.3** (Clopen). L is clopen: it is both open (Theorem 3.1) and closed (its complement U is open by Theorem 3.2).

**Theorem 3.5** (Gap–Disconnection). If a linearly ordered topological space with the order topology has a Dedekind gap, it is not connected.

*Proof.* The lower set L is clopen, nonempty (by definition), and not all of α (since U is nonempty). A connected space has no nontrivial clopen sets, contradiction. □

### 3.2 Application to Surreal Numbers

The surreal numbers No have Dedekind gaps at every ordinal cofinality. For example, the gap between all finite surreal numbers and ω (and its approximations) creates a Dedekind gap. By Theorem 3.5, the order topology on No is disconnected. In fact, the abundance of gaps makes No totally disconnected in the order topology.

## 4. Completeness Implies Connectedness

**Theorem 4.1** (Completeness–Connectedness). Let α be a conditionally complete linear order with the order topology, densely ordered, with no minimum and no maximum. Then α is connected.

*Proof.* The whole space is trivially ord-connected, and in a conditionally complete, densely ordered space, ord-connected sets are preconnected (by the Mathlib result `isPreconnected_iff_ordConnected`). □

**Theorem 4.2** (No-Gap Theorem). Under the same hypotheses, α has no Dedekind gaps.

*Proof.* Suppose (L, U) is a gap. L is nonempty and bounded above (by any element of U). Let s = sup L. If s ∈ L, the no-maximum condition gives a' > s in L, contradicting s = sup L. If s ∈ U, the no-minimum condition gives b' < s in U. Since b' ∈ U, every element of L is below b', so sup L ≤ b' < s, contradiction. □

**Corollary 4.3**. ℝ has no Dedekind gaps and is connected in the order topology.

## 5. Cofinality Spectrum and First-Countability

**Theorem 5.1** (Tame ⇒ Countably Generated). If x is a tame point in a linearly ordered topological space with the order topology, then the neighborhood filter 𝓝(x) is countably generated.

*Proof.* Let (aₙ) be cofinal below x and (bₘ) coinitial above x. The family {Ioo(aₙ, bₘ) : n, m ∈ ℕ} is countable and forms a neighborhood basis at x: any open set containing x contains an interval (a', b') with a' < x < b', and by cofinality there exist n, m with aₙ ≥ a' and bₘ ≤ b', giving Ioo(aₙ, bₘ) ⊆ (a', b'). □

**Theorem 5.2** (Real Tameness). Every point of ℝ is tame.

*Proof.* For x ∈ ℝ, use the sequences aₙ = x - 1/(n+1) (cofinal below x by the Archimedean property) and bₙ = x + 1/(n+1) (coinitial above x, similarly). □

**Corollary 5.3**. The neighborhood filter at every point of ℝ is countably generated (first-countability of ℝ).

### 5.1 Wild Points in Surreal-Like Spaces

A point is *wild* if it is not tame — it lacks countable cofinality from at least one side. In the surreal numbers, the point ω (the first infinite ordinal) has uncountable "left cofinality" in a certain sense: while it can be approached from below by the countable sequence 0, 1, 2, …, there exist surreal numbers of uncountable birthday that create gaps requiring uncountable directed systems to analyze.

## 6. Path-Connectedness via Field Arithmetic

**Theorem 6.1** (Path Parametrization). For a ≤ b in ℝ, the linear path f(t) = (1-t)a + tb is continuous, monotone, and satisfies f([0,1]) = [a,b].

*Proof.* Continuity: f is a polynomial in t, hence continuous. Monotonicity: f(t) = a + t(b-a) with b-a ≥ 0. Image: forward direction by substitution and arithmetic; surjectivity by solving t = (y-a)/(b-a) for a < b, or t = 0 for a = b. □

**Corollary 6.2** (Path-Connectedness of ℝ). ℝ is path-connected: for any a, b ∈ ℝ, there exists a continuous function f : ℝ → ℝ with f(0) = a and f(1) = b.

## 7. Discussion

### 7.1 The Completeness–Universality Trade-off

Our results formalize a fundamental trade-off in the theory of ordered fields:
- **Completeness** (Dedekind completeness) ensures connectedness but limits size.
- **Universality** (containing all ordinals and infinitesimals) requires giving up completeness.

The surreal numbers optimize for universality at the cost of total disconnection. The real numbers optimize for completeness at the cost of excluding infinitesimals and transfinite quantities.

### 7.2 The Cofinality Spectrum

The partition of points into "tame" and "wild" based on cofinality captures a fundamental dichotomy in ordered spaces. Tame points behave like points of ℝ (first-countable neighborhoods), while wild points require genuinely uncountable apparatus for topological analysis.

### 7.3 Falsifiable Conjecture

**Conjecture 7.1**: For any dense linear order α without endpoints, equipped with the order topology, the following are equivalent:
1. α is connected
2. α has no Dedekind gaps
3. α is a continuous image of ℝ (if α is a set)

The equivalence (1) ⇔ (2) is established by our results for conditionally complete orders. The direction (3) ⇒ (1) holds because continuous images of connected spaces are connected. The direction (1) ⇒ (3) would require additional structure and may fail for non-separable spaces.

## 8. Future Work

1. **Total disconnection**: Prove that if every point has a Dedekind gap on each side, the space is totally disconnected.
2. **Alternative topologies**: Investigate topologies on surreal-like spaces that restore some connectedness while preserving useful algebraic properties.
3. **Cofinality spectrum classification**: Classify which combinations of left and right cofinalities can occur at points of ordered fields.
4. **Non-Archimedean analysis**: Develop a theory of continuity adapted to non-tame points using nets or filters instead of sequences.
