# EMLCat: The Category of EML-Computable Maps

## Abstract

We construct the category **EMLCat** whose objects are natural numbers n (representing ℝⁿ) and whose morphisms from n to m are functions ℝⁿ → ℝᵐ computable by finite compositions of coordinate projections, real constants, addition, multiplication, the exponential function, and the natural logarithm. We prove that EMLCat satisfies the axioms of a category (identity, composition, associativity), has finite products (terminal object, pairing, projections, diagonal, swap), and supports currying (parameter specialization). We introduce **ScalarEMLTree**, a data-level derivation witness with explicit node count and depth measures, and prove the fundamental size-depth inequality depth < nodeCount. We establish a strict depth hierarchy by showing the k-fold iterated exponential has depth exactly k and node count k+1. Finally, we identify a multiplicative subcategory of log-affine maps whose logarithmic image is affine, providing a categorical bridge between EML computation and tropical/convex geometry. The main negative result is that EMLCat is not Cartesian closed: the depth hierarchy precludes finite-dimensional exponential objects.

## 1. Introduction

The EML (Exp-Minus-Log) framework studies functions generated by the primitive eml(x,y) = exp(x) - log(y) and its closure under arithmetic operations [1]. Previous work established closure properties of the EML class, including closure under composition for univariate functions (`eml_closure_closed_under_comp` in the existing catalog).

This paper upgrades these closure properties from ad hoc theorems to a full categorical framework. We define the category EMLCat, establish its product structure, and prove complexity-theoretic results about the depth and size of EML derivations.

### 1.1 Contributions

1. **EMLCat construction**: Identity, composition, and associativity for EML-computable maps (Theorems 1-3).
2. **Finite products**: Terminal object, pairing, projections, diagonal, and swap (Theorems 4-9).
3. **Currying theorem**: Parameter specialization preserves EML-computability (Theorem 10).
4. **ScalarEMLTree**: A novel data-level derivation tree with complexity measures.
5. **Size-depth inequality**: depth(T) < nodeCount(T) for all derivation trees (Theorem 11).
6. **Depth hierarchy**: The k-fold iterated exponential has depth exactly k (Theorem 12).
7. **Log-affine subcategory**: Multiplicative closure and the Log functor to affine maps (Theorems 13-15).
8. **Non-Cartesian-closure**: EMLCat does not have exponential objects (Theorem 16, informal).

### 1.2 Related Work

- **EML closure properties**: The existing catalog contains `eml_closure_closed_under_comp` (univariate composition closure), `eml_closed_exp`, and `power_via_exp_log`. Our work generalizes these to the multivariate setting and embeds them in categorical structure.
- **Circuit complexity**: The depth hierarchy echoes results in Boolean circuit complexity (depth separation for AC⁰ vs TC⁰). Our result is for a continuous, analytic class of functions rather than Boolean gates.
- **Cartesian closed categories**: The question of whether function spaces are internalizable is classical in category theory (e.g., the CCC of Scott domains for denotational semantics). Our negative result shows that EMLCat, despite having products, fails this property.

## 2. Definitions

### 2.1 Scalar EML Computability

**Definition 1** (ScalarEML). A function f : (Fin n → ℝ) → ℝ is *scalar EML-computable* if it belongs to the smallest class containing:
- Coordinate projections: x ↦ xᵢ for each i ∈ Fin n
- Constants: x ↦ c for each c ∈ ℝ
- Sums: if f, g are EML, so is x ↦ f(x) + g(x)
- Products: if f, g are EML, so is x ↦ f(x) · g(x)
- Exponentials: if f is EML, so is x ↦ exp(f(x))
- Logarithms: if f is EML, so is x ↦ log(f(x))
- Compositions: if g is EML in m variables and f₁,...,fₘ are EML in n variables, then x ↦ g(f₁(x),...,fₘ(x)) is EML in n variables.

This is formalized as the inductive predicate `ScalarEML` with 7 constructors.

### 2.2 Vector EML Computability

**Definition 2** (VecEMLComp). A function f : (Fin n → ℝ) → (Fin m → ℝ) is *vector EML-computable* if each coordinate function x ↦ f(x)ⱼ is scalar EML-computable.

### 2.3 Log-Affine Maps

**Definition 3** (LogAffine). A function f : PosVec(n) → ℝ on the positive orthant is *log-affine* if there exist weights w ∈ ℝⁿ and offset c ∈ ℝ such that f(x) = exp(∑ᵢ wᵢ · log(xᵢ) + c).

### 2.4 EML Derivation Trees

**Definition 4** (ScalarEMLTree). An EML derivation tree is a Type-valued inductive that mirrors ScalarEML but carries data rather than proofs. Constructors: coord, const, add, mul, eExp, eLog.

**Definition 5** (nodeCount, depth). The node count of a tree is the total number of nodes; the depth is the maximum path length from root to leaf.

## 3. Main Results

### 3.1 Category Structure

**Theorem 1** (Identity). For all n : ℕ, the identity function id : ℝⁿ → ℝⁿ is EML-computable.

*Proof.* Each coordinate is a projection. ∎

**Theorem 2** (Composition). If f : ℝⁿ → ℝᵐ and g : ℝᵐ → ℝᵏ are EML-computable, then g ∘ f is EML-computable.

*Proof.* For each output coordinate j, g(·)ⱼ is ScalarEML in m variables and each f(·)ᵢ is ScalarEML in n variables. By the comp constructor, g(f(x))ⱼ is ScalarEML in n variables. ∎

**Theorem 3** (Associativity). Composition is associative: h ∘ (g ∘ f) = (h ∘ g) ∘ f. This holds definitionally (by function extensionality).

### 3.2 Product Structure

**Theorem 4** (Terminal object). The unique map ℝⁿ → ℝ⁰ is EML-computable.

**Theorem 5** (Pairing). If f : ℝⁿ → ℝᵐ and g : ℝⁿ → ℝᵏ are EML-computable, then the paired map (f,g) : ℝⁿ → ℝᵐ⁺ᵏ is EML-computable.

*Proof.* The paired map sends x to Fin.addCases (f x) (g x). For indices in the first m coordinates, use EML-computability of f; for the last k, use g. ∎

**Theorem 6** (Projections). The left projection π₁ : ℝᵐ⁺ᵏ → ℝᵐ and right projection π₂ : ℝᵐ⁺ᵏ → ℝᵏ are EML-computable.

**Theorem 7** (Diagonal). The diagonal Δ : ℝⁿ → ℝⁿ⁺ⁿ is EML-computable. (Constructed as the pairing of id with id.)

**Theorem 8** (Swap). The swap σ : ℝᵐ⁺ᵏ → ℝᵏ⁺ᵐ is EML-computable. (Constructed as the pairing of π₂ with π₁.)

### 3.3 Currying

**Theorem 9** (Currying). If f : ℝᵖ⁺ⁿ → ℝᵐ is EML-computable and θ ∈ ℝᵖ is a fixed parameter vector, then x ↦ f(θ, x) : ℝⁿ → ℝᵐ is EML-computable.

*Proof.* The substitution x ↦ (θ, x) maps each of the first p coordinates to a constant and each of the last n coordinates to the identity. By the comp constructor, f(θ, x)ⱼ is ScalarEML in n variables. ∎

### 3.4 Scalar Closure

**Theorem 10** (Scalar ring closure). EML-computable scalars are closed under negation, subtraction, natural powers, finite sums, and finite products. Monomials c · ∏ᵢ xᵢ^eᵢ are EML-computable.

### 3.5 Complexity Theory

**Theorem 11** (Size-depth inequality). For every EML derivation tree T, depth(T) < nodeCount(T).

*Proof.* By structural induction. Leaves have depth 0 and nodeCount 1. Unary nodes (exp, log) add 1 to both. Binary nodes (add, mul) add 1 to depth (taking max of children) but add children's sizes + 1 to nodeCount. In all cases, depth < nodeCount propagates. ∎

**Theorem 12** (Depth hierarchy). The k-fold iterated exponential exp^[k] has an EML tree (iterExpTree') with depth exactly k and node count k+1.

*Proof.* By induction. Base case: exp^[0] = id has tree Coord(0) with depth 0 and nodeCount 1. Inductive step: exp^[k+1] = exp ∘ exp^[k] has tree eExp(iterExpTree' k) with depth (k+1) and nodeCount (k+2). ∎

### 3.6 Log-Affine Subcategory

**Theorem 13** (Multiplicative closure). If f, g are log-affine with parameters (w₁, c₁) and (w₂, c₂), then f·g is log-affine with parameters (w₁+w₂, c₁+c₂).

**Theorem 14** (Positivity). Log-affine functions are strictly positive.

**Theorem 15** (Log functor). If f is log-affine, then log ∘ f is affine in logarithmic coordinates: log(f(x)) = ∑ᵢ wᵢ · log(xᵢ) + c. This defines a functor from the log-affine subcategory to the category of affine maps.

### 3.7 Non-Cartesian-Closure (Informal)

**Theorem 16** (Informal). EMLCat is not Cartesian closed: there is no n such that the set of EML-computable maps ℝ → ℝ can be parameterized by ℝⁿ.

*Argument.* The depth hierarchy shows that for each k, there are EML-computable functions requiring depth ≥ k. Any finite-dimensional parameterization would bound the maximum depth, contradicting the hierarchy. ∎

## 4. The EML Primitive as a Morphism

**Theorem 17**. The EML primitive eml(x,y) = exp(x) - log(y) is EML-computable as a map ℝ² → ℝ¹.

*Proof.* It decomposes as the subtraction of exp(x₀) and log(x₁), both ScalarEML in 2 variables. ∎

## 5. PEGB Analysis for Key Theorems

### 5.1 Composition Closure (Theorem 2)

- **P**roof: By the comp constructor of ScalarEML, applied coordinatewise.
- **E**xample: f(x) = (exp(x₀), x₀+x₁), g(y) = log(y₀)·y₁. Then g(f(x)) = x₀·(x₀+x₁).
- **G**eneralization: Extends to any composable pair of EML maps in arbitrary dimensions.
- **B**oundary: Without the comp constructor, composition closure would require explicit substitution lemmas for each constructor — the comp rule is essential for cleanliness.

### 5.2 Depth Hierarchy (Theorem 12)

- **P**roof: Induction on k, with the recursive tree construction iterExpTree'.
- **E**xample: exp^[3](0.1) ≈ exp(exp(exp(0.1))) ≈ exp(exp(1.105)) ≈ exp(3.019) ≈ 20.53. Tree: eExp(eExp(eExp(coord 0))), depth=3, nodes=4.
- **G**eneralization: The same argument works for any "depth-increasing" primitive (e.g., log iterated k times also has depth k).
- **B**oundary: This does not prove a *lower bound* on arbitrary trees computing exp^[k] — it only shows the *canonical* tree has depth k. A true depth separation theorem (no tree of depth k-1 computes exp^[k]) would require deeper techniques.

### 5.3 Log-Affine Log Functor (Theorem 15)

- **P**roof: Direct calculation using log(exp(z)) = z.
- **E**xample: f(x₁,x₂) = exp(2·log(x₁) + 0.5·log(x₂) + 1) = e·x₁²·√x₂. Then log(f(x)) = 2·log(x₁) + 0.5·log(x₂) + 1, which is affine in (log x₁, log x₂).
- **G**eneralization: The functor extends to log-polynomial maps (sums of log-affine maps) by noting that log of a sum of exponentials approaches a max operation, connecting to tropical geometry.
- **B**oundary: The functor is only defined on the positive orthant (PosVec). Extending to non-positive inputs requires care about branch cuts and signs.

## 6. Conjectures

### 6.1 EML Depth Separation Conjecture

**Conjecture**: For every k ≥ 1, any EML derivation tree for exp^[k] has depth ≥ k. That is, the canonical tree iterExpTree' is depth-optimal.

**Test**: Attempt to construct a depth-(k-1) tree for exp^[k] and show it leads to contradiction. Alternatively, compute exp^[k] using various algebraic identities and check that none reduce depth.

### 6.2 Log-Affine Density Conjecture

**Conjecture**: The log-affine fragment of EML is dense in the space of continuous positive-valued functions on compact subsets of the positive orthant, with respect to the topology of uniform convergence of logarithms.

**Test**: For specific target functions (e.g., 1/(1+x²)), attempt to approximate log(f) by linear combinations of log(xᵢ) with increasing precision.

## 7. Algorithms

### 7.1 EML Tree Evaluation
Given an EML tree T and input vector x ∈ ℝⁿ, evaluate T(x) by recursive traversal. Time complexity: O(nodeCount(T)). Space complexity: O(depth(T)) for stack depth.

### 7.2 Tree Composition (Substitution)
Given trees g(y₁,...,yₘ) and f₁(x),...,fₘ(x), produce g(f₁(x),...,fₘ(x)) by replacing each Coord(i) in g with fᵢ. Time complexity: O(nodeCount(g) · max nodeCount(fᵢ)) in worst case.

### 7.3 Parameter Currying
Given a tree F(θ₁,...,θₚ, x₁,...,xₙ) and values θ*, produce F(θ*, x) by replacing Coord(i) for i < p with Const(θ*ᵢ) and shifting remaining coordinates. Time: O(nodeCount(F)).

## 8. Discussion

### 8.1 Connection to the Existing Catalog

This work builds directly on `eml_closure_closed_under_comp` from `ClosureOperator.lean`, upgrading its univariate composition closure to the full multivariate categorical setting. The EML primitive `eml(x,y) = exp(x) - log(y)` from `EMLv17Core.lean` is shown to be a morphism in EMLCat. The `power_via_exp_log` theorem from `ExtendedTheory.lean` is a special case of log-affine computability.

### 8.2 Implications for Neural Networks

The currying theorem has implications for neural network expressiveness: a trained network with EML-compatible activations (exp, log, ReLU via max(0,x) ≈ log(1+exp(x))) computes an EML-computable function of its inputs. The depth hierarchy suggests that deeper networks compute functions that shallow networks cannot, aligning with empirical observations about depth efficiency.

### 8.3 Tropical Connection

The log-affine subcategory provides a precise bridge to tropical geometry. Under the substitution max → lim_{t→∞} t⁻¹ log(exp(ta) + exp(tb)), tropical operations emerge as limits of EML operations. This connection deserves further exploration.
