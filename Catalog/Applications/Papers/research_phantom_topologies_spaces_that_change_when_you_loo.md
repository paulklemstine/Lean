# Phantom Topologies: Observer-Dependent Topological Spaces and the Strict Phantom Number

## Abstract

We introduce **phantom topologies**, a framework in which a type X is equipped not with a single topology but with a family of topologies indexed by a set of observers. The **consensus topology** — the intersection of all observer topologies — represents the "objective" topological structure: a set is consensus-open if and only if every observer considers it open. We define the **strict phantom number** of a topology τ as the minimum number of strictly finer topologies whose intersection recovers τ, and develop the foundational theory of this invariant.

Our main results include: (1) a complete characterization of consensus-open sets via the lattice structure of `TopologicalSpace`; (2) a proof that the discrete topology admits no strict phantom representation; (3) a sufficient condition for strict phantom number ≤ 2 in terms of lattice decompositions; (4) a monotonicity theorem relating observer refinement to consensus coarsening; (5) the **phantom spectrum**, which localizes observer discrepancies at individual points, and a theorem that in strict representations every observer must deviate from consensus somewhere. All results have been formalized and verified in Lean 4 with Mathlib.

**Keywords**: topological lattices, observer-dependent structures, phantom number, topology decomposition, formal verification

## 1. Introduction

The lattice of topologies on a fixed set is a well-studied object in general topology (see Birkhoff [1], Larson–Andima [2]). Given a set X, the collection Top(X) of all topologies on X forms a complete lattice under the refinement ordering, where the infimum corresponds to the intersection of open-set families and the supremum to the topology generated by their union.

Despite this rich structure, the question of *decomposing* a given topology into simpler pieces via lattice operations has received relatively little systematic attention. We propose the framework of **phantom topologies** to study this question from an observer-theoretic perspective.

### 1.1 Motivation

The philosophical motivation comes from the observation that different mathematical or physical frameworks can impose different topological structures on the same underlying set. In analysis, one might use the norm topology; in functional analysis, the weak or weak-* topology; in algebraic geometry, the Zariski topology. The consensus of these perspectives — what all frameworks agree on — is a natural object of study.

### 1.2 Contributions

1. **Formal framework**: We define phantom topologies, consensus, agreement, and the phantom spectrum.
2. **Strict phantom number**: A new topological invariant measuring decomposability.
3. **Structural theorems**: Monotonicity, surjective reindexing invariance, merge formulas.
4. **Extremal results**: Phantom-irreducibility of the discrete topology.
5. **Falsifiable conjecture**: The Metrizable Phantom Conjecture.
6. **Full formalization**: All definitions and theorems verified in Lean 4.

## 2. Definitions

### 2.1 Phantom Topology

**Definition 2.1** (Phantom Topology). Let X be a type and O a type of observers. A *phantom topology* on X indexed by O is a function

$$T : O \to \mathrm{Top}(X)$$

assigning to each observer o ∈ O a topology T(o) on X.

### 2.2 Consensus Topology

**Definition 2.2** (Consensus). The *consensus topology* of a phantom topology T is

$$\tau_{\mathrm{cons}} = \bigcap_{o \in O} T(o)$$

where the intersection is taken in the lattice of topologies (i.e., as the intersection of open-set families). A set U ⊆ X is consensus-open if and only if U is T(o)-open for every o ∈ O.

In Lean 4 with Mathlib, where `≤` on `TopologicalSpace` means "finer" (more open sets) and `⊥ = discrete`, the consensus is represented as `⨆ o, T o` (the supremum in Mathlib's order, which corresponds to the infimum/intersection of open-set families).

### 2.3 Agreement and Discrepancy

**Definition 2.3** (Agreement). Two observers o₁, o₂ *agree* on a set U if U is open in both T(o₁) and T(o₂).

**Definition 2.4** (Discrepancy). The *discrepancy set* of observers o₁, o₂ is the collection of sets that are open in exactly one of the two topologies.

### 2.4 Strict Phantom Representation

**Definition 2.5** (Strict Phantom Representation). A phantom topology T : O → Top(X) is a *strict phantom representation* of τ if:
1. The consensus equals τ: ⋂_{o} T(o) = τ
2. Each observer sees strictly more: T(o) ⊋ τ for all o ∈ O (as open-set families)

**Definition 2.6** (Strict Phantom Number). The *strict phantom number* spn(τ) of a topology τ is the minimum cardinality |O| such that there exists a strict phantom representation of τ indexed by O. If no strict representation exists, spn(τ) = 0.

### 2.5 Phantom Spectrum

**Definition 2.7** (Phantom Spectrum). For a phantom topology T and a point x ∈ X, the *phantom spectrum* at x is

$$\mathrm{Spec}_T(x) = \{o \in O \mid \exists U \text{ open in } T(o),\; x \in U,\; U \notin \tau_{\mathrm{cons}}\}$$

This localizes the discrepancy: o ∈ Spec_T(x) means observer o sees extra structure near x.

## 3. Main Results

### 3.1 Consensus Characterization

**Theorem 3.1** (Consensus Open-Set Characterization). *A set s is open in the consensus topology if and only if s is open in T(o) for every observer o.*

*Proof.* Direct application of `isOpen_iSup_iff` in Mathlib's topology lattice. □

This theorem is the foundational bridge between the abstract lattice definition and the concrete interpretation of consensus.

### 3.2 Observer Ordering

**Theorem 3.2** (Consensus Coarseness). *For every observer o, T(o) is finer than (or equal to) the consensus topology. That is, every consensus-open set is T(o)-open.*

*Proof.* Follows from `le_iSup`. □

**Theorem 3.3** (Monotonicity). *If T₁(o) is finer than T₂(o) for every o, then the consensus of T₁ is finer than the consensus of T₂.*

*Proof.* Monotonicity of `iSup` (`iSup_mono`). □

**Corollary 3.4** (Consensus Map Monotonicity). *The consensus map, viewed as a function from the pointwise-ordered set of phantom topologies to the topology lattice, is monotone.*

### 3.3 Surjective Reindexing

**Theorem 3.5** (Reindexing Invariance). *If f : O' → O is surjective, then the consensus of T ∘ f equals the consensus of T.*

*Proof.* Uses `Function.Surjective.iSup_comp`. Relabeling observers through a surjection preserves what they collectively agree on. □

### 3.4 Merging Observer Families

**Theorem 3.6** (Merge Formula). *Let T₁ : O₁ → Top(X) and T₂ : O₂ → Top(X) be two phantom topologies. The consensus of their merge (indexed by O₁ ⊕ O₂) is the supremum of the individual consensuses:*

$$\tau_{\mathrm{cons}}(T_1 \sqcup T_2) = \tau_{\mathrm{cons}}(T_1) \vee \tau_{\mathrm{cons}}(T_2)$$

*Proof.* Direct from `iSup_sum`. □

**Interpretation.** Merging two observer groups takes the coarsest topology containing both consensuses. More observers generally means a coarser (more agreed-upon) consensus.

### 3.5 Unanimity

**Theorem 3.7** (Unanimous Agreement). *If all observers have the same topology, the consensus equals that topology.*

*Proof.* Reduces to `iSup_const`. □

**Theorem 3.8** (Single Observer). *A single-observer phantom topology has consensus equal to that observer's topology.*

### 3.6 Discrete Irreducibility

**Theorem 3.9** (Phantom Irreducibility of Discrete). *If O is nonempty, there is no phantom topology on X indexed by O that forms a strict phantom representation of the discrete topology.*

*Proof.* The discrete topology is ⊥ in Mathlib's order on TopologicalSpace. In a strict representation, every observer's topology would need to be strictly less than ⊥ (strictly finer than discrete), which is impossible since ⊥ is the minimum. □

**Interpretation.** The discrete topology is "phantom-irreducible" — it cannot be decomposed into complementary observations. A space where everything is visible cannot be reconstructed from observers who see "even more."

### 3.7 Pair Decomposition

**Theorem 3.10** (Strict 2-Observer Representation). *If τ₁ ⊔ τ₂ = τ (as topologies, with ⊔ = intersection of open-set families) and both τ₁ < τ and τ₂ < τ (strictly finer), then τ admits a strict phantom representation with 2 observers.*

*Proof.* Construct the phantom topology P with P(0) = τ₁, P(1) = τ₂. Verify consensus = τ₁ ⊔ τ₂ = τ via `Fin.iSup`, and strict finiteness from the hypotheses. □

### 3.8 Phantom Spectrum Theorems

**Theorem 3.11** (Spectrum Emptiness). *If an observer's topology equals the consensus, that observer is not in any point's phantom spectrum.*

**Theorem 3.12** (Spectrum Nonemptiness in Strict Representations). *In a strict phantom representation, every observer belongs to the phantom spectrum of at least one point.*

*Proof sketch.* Since each observer's topology is strictly finer than the consensus, there exists a set U open for the observer but not consensus-open. Since U ≠ ∅ (as ∅ is always open), pick any x ∈ U. Then o ∈ Spec(x). □

## 4. The Metrizable Phantom Conjecture

**Conjecture 4.1** (Metrizable Phantom Conjecture). *Every metrizable second-countable topological space has strict phantom number at most 2.*

### 4.1 Evidence

**Example 4.2** (The Real Line). The standard topology on ℝ equals the intersection of the Sorgenfrey (lower-limit) topology (basis: [a, b)) and the upper-limit topology (basis: (a, b]).

*Verification.* If U is open in both topologies, then for each x ∈ U:
- In the lower-limit topology: ∃ε > 0 with [x, x+ε) ⊆ U
- In the upper-limit topology: ∃δ > 0 with (x-δ, x] ⊆ U
- Therefore (x-δ, x+ε) ⊆ U, so U is standard-open.

Conversely, every standard-open set is open in both finer topologies. Both are strictly finer (e.g., [0,1) is lower-limit-open but not standard-open).

### 4.2 Strategy for General Proof

For a second-countable metrizable space with countable basis {B₁, B₂, ...}, consider splitting the basis into odd-indexed and even-indexed sub-bases. The topologies generated by these sub-bases may satisfy the decomposition property, though the proof that their intersection recovers the original topology requires careful analysis of how basis elements combine.

### 4.3 Falsification Protocol

To disprove the conjecture, one would need to find a second-countable metrizable space (X, τ) such that for *every* pair of topologies τ₁, τ₂ strictly finer than τ, we have τ₁ ⊔ τ₂ ≠ τ (in Mathlib's order). This is a strong condition: it means τ cannot be written as any non-trivial intersection of two finer topologies.

## 5. Algorithms

### 5.1 Consensus Computation

Given finite representations of observer topologies (e.g., as sets of generators), the consensus topology can be computed as the intersection of their open-set families.

**Algorithm: COMPUTE_CONSENSUS**
- Input: Observers O, for each o a generating set G(o) ⊆ P(X)
- Output: Generating set for the consensus topology
- Method: For finite X, compute all open sets for each observer, then intersect.

### 5.2 Phantom Number Search

Given a topology τ on a finite set X:
1. Enumerate all topologies on X finer than τ
2. For n = 2, 3, ..., check all n-tuples whose intersection equals τ
3. Return the first n that works

This is computationally expensive (the number of topologies grows super-exponentially) but is implementable for small |X|.

## 6. Discussion

### 6.1 Relationship to Existing Work

The lattice of topologies on a fixed set has been studied since Birkhoff (1936). The concept of "complementary topologies" (τ₁ ∧ τ₂ = indiscrete, τ₁ ∨ τ₂ = discrete) was investigated by Steiner (1966). Our strict phantom number can be viewed as measuring the "intersection complexity" of a topology within this lattice.

### 6.2 Connections to Other Fields

- **Quantum mechanics**: Observer-dependent measurement outcomes; the consensus is analogous to the common ground between measurement contexts.
- **Sheaf theory**: A phantom topology can be viewed as a presheaf of topological spaces over the observer set.
- **Data science**: Different similarity metrics on a dataset induce different topologies; the consensus captures robust structural features.

### 6.3 Open Problems

1. Compute spn(τ) for specific topologies: the cofinite topology, the Zariski topology on algebraic varieties, p-adic topologies.
2. Is spn(τ) always finite for T₁ spaces?
3. Characterize topologies with spn = 2 algebraically.
4. Extend the theory to locales or pointfree topology.
5. Develop a categorical framework: functors from observer categories to Top.

All definitions and theorems in this paper have been formalized in Lean 4 using the Mathlib library. The key technical insight is that Mathlib's ordering on `TopologicalSpace α` has `≤` meaning "finer" (more open sets), with `⊥ = discrete` and `⊤ = indiscrete`. Consequently, the consensus (intersection of open-set families) corresponds to `⨆` (supremum) rather than `⨅` (infimum) in the lattice.
