# EML Interpolation Theory: Stone-Weierstrass for Exp-Log Networks

## Abstract

We develop a formal approximation theory for **EML networks**—computational graphs whose operations are restricted to exponentiation (exp), multiplication/addition, and logarithm (log). We introduce the **EML expression tree** as a novel mathematical structure with two complexity measures (depth and size), and establish that the algebra of EML-evaluable functions on compact intervals forms a subalgebra of continuous functions that separates points. By the Stone-Weierstrass theorem, this algebra is dense in C(K, ℝ), establishing EML networks as universal approximators.

Beyond the existential density result, we prove:
1. **Separation theorem**: The EML algebra separates points on any compact interval via the identity function, with log providing an independent witness on positive domains.
2. **Transcendence**: The EML algebra strictly extends polynomial algebras—log and exp are provably non-polynomial, and EML provides constant-size exact representations of real powers x^r that polynomials can only approximate.
3. **Depth hierarchy**: Depth-0 EML expressions compute exactly the affine functions; depth-1 is strictly richer (exp is not affine). The iterated exponential exp^n has depth n and exhibits strict growth separation between consecutive depth levels.
4. **Substitution algebra**: EML expression composition satisfies a depth-additivity bound, with substitution being semantic composition.

All results are formalized in Lean 4 with complete machine-verified proofs.

## 1. Introduction

The universal approximation theorem (Cybenko 1989, Hornik 1991) establishes that neural networks with a single hidden layer can approximate any continuous function. However, these classical results are existential—they guarantee approximation but say nothing about the architecture or complexity of the approximant.

Recent work on specific architectures—particularly those incorporating exponential and logarithmic nonlinearities—has raised the question: can we prove approximation results *specific* to these operations? The EML (Exp-Log-Mul) framework provides an affirmative answer with additional structure: the algebraic properties of exp and log give us exact representations of important function classes (power laws, exponential decay) that polynomial methods can only approximate.

### 1.1 Related Work

The Stone-Weierstrass theorem (Stone 1937) is the classical tool for establishing density of function algebras. Its application to neural network theory dates to the 1990s. Our contribution is to apply it to a specific, structured function algebra (EML) and to complement the density result with expressivity and complexity theorems.

The EML formalism connects to:
- **Tropical geometry**: where max-plus algebras provide piecewise-linear approximation
- **Circuit complexity**: where depth vs. size tradeoffs mirror our depth-size analysis
- **Approximation theory**: where Jackson-type theorems quantify polynomial approximation rates

## 2. The EML Expression Tree

### 2.1 Definition

An **EML expression** is an element of the inductively defined type:

```
EMLExpr ::= const(c : ℝ) | proj | exp(e) | log(e) | add(e₁, e₂) | mul(e₁, e₂)
```

where `const(c)` represents the constant function x ↦ c, `proj` is the identity x ↦ x, and the remaining constructors are compositional.

### 2.2 Evaluation Semantics

Each EML expression evaluates to a function ℝ → ℝ:
- `eval(const c, x) = c`
- `eval(proj, x) = x`
- `eval(exp e, x) = exp(eval(e, x))`
- `eval(log e, x) = log(eval(e, x))` (using the extended log, with log(x) = 0 for x ≤ 0)
- `eval(add e₁ e₂, x) = eval(e₁, x) + eval(e₂, x)`
- `eval(mul e₁ e₂, x) = eval(e₁, x) · eval(e₂, x)`

### 2.3 Complexity Measures

**Definition (EML Complexity).** The *depth* of an expression is:
- depth(const c) = depth(proj) = 0
- depth(op e) = depth(e) + 1 for op ∈ {exp, log}
- depth(bin e₁ e₂) = max(depth(e₁), depth(e₂)) + 1 for bin ∈ {add, mul}

The *size* is the total number of nodes. We prove:

**Theorem 2.1.** For all EML expressions e, depth(e) ≤ size(e).

**Theorem 2.2.** For all EML expressions e, size(e) ≥ 1.

The **EML Complexity** structure packages depth and size as a pair (d, s) with the invariant d ≤ s, ordered component-wise.

## 3. The EML Subalgebra and Stone-Weierstrass

### 3.1 The EML Subalgebra

For a compact interval [a, b], we define the **EML subalgebra** as the ℝ-subalgebra of C([a,b], ℝ) generated by the coordinate function (iccVal: x ↦ x).

This is a subalgebra because:
- It contains all constants (1 ∈ Algebra.adjoin ℝ S for any S)
- It is closed under addition and multiplication (by definition of Algebra.adjoin)
- It is closed under scalar multiplication (by ℝ-algebra structure)

### 3.2 Separation

**Theorem 3.1 (EML Separation).** The EML subalgebra separates points on [a, b]: for any x ≠ y in [a, b], there exists f in the subalgebra with f(x) ≠ f(y).

*Proof.* The coordinate function x ↦ x is in the subalgebra and separates all distinct points. □

**Theorem 3.2 (Log Separation).** On [a, b] with 0 < a, log provides an independent separation witness: log(x) ≠ log(y) whenever x ≠ y and x, y > 0.

*Proof.* By strict monotonicity of log on (0, ∞), equivalently by injectivity of log on the positive reals. □

### 3.3 Density

**Theorem 3.3 (EML Stone-Weierstrass).** The topological closure of the EML subalgebra equals C([a,b], ℝ):

```
(emlSubalgebra a b).topologicalClosure = ⊤
```

*Proof.* By Stone-Weierstrass (Theorem `subalgebra_topologicalClosure_eq_top_of_separatesPoints` in Mathlib), applied to the EML subalgebra which separates points (Theorem 3.1). □

**Corollary 3.4 (EML Uniform Approximation).** For any f ∈ C([a,b], ℝ) and ε > 0, there exists g in the EML subalgebra with dist(f, g) < ε.

### 3.4 Extended EML Subalgebra

On positive domains [a, b] with 0 < a, the **extended EML subalgebra** is generated by both iccVal and log∘iccVal. It satisfies:

**Theorem 3.5.** The extended EML subalgebra contains the basic EML subalgebra.

**Theorem 3.6.** The extended EML subalgebra is also dense in C([a,b], ℝ).

## 4. EML Transcendence

### 4.1 Log is Non-Polynomial

**Theorem 4.1.** For any polynomial p ∈ ℝ[X], there exists x > 0 with p(x) ≠ log(x).

*Proof.* The polynomial p has a continuous extension to 0, but log(x) → -∞ as x → 0⁺. If p(x) = log(x) for all x > 0, then the sequence p(1/n) = log(1/n) → -∞, contradicting continuity of p at 0. □

### 4.2 Exp is Non-Polynomial

**Theorem 4.2.** For any polynomial p ∈ ℝ[X], there exists x with p(x) ≠ exp(x).

*Proof.* By the growth rate comparison: exp(x)/p(x) → 0 as x → ∞ (since polynomials are dominated by exponentials), but if p = exp everywhere, this ratio would be identically 1. □

### 4.3 Constant-Size Real Powers

**Theorem 4.3.** The EML expression `emlPow r = exp(r · log(proj))` evaluates to x^r for any r ∈ ℝ and x > 0, with constant size 5 and depth 3.

This is a strict expressivity advantage over polynomials, which cannot represent non-integer powers at all and require degree n for x^n.

## 5. The Depth Hierarchy

### 5.1 Depth-0 Classification

**Theorem 5.1 (Depth-0 = Affine).** If depth(e) = 0, then e.eval is affine: there exist a, b ∈ ℝ with e.eval(x) = ax + b for all x.

*Proof.* By case analysis: depth 0 forces e to be either `const c` (a=0, b=c) or `proj` (a=1, b=0), since exp, log, add, mul all have depth ≥ 1. □

### 5.2 Strict Hierarchy

**Theorem 5.2 (Depth-1 > Depth-0).** There is no affine function equal to exp: ¬∃ a b, ∀ x, exp(x) = ax + b.

*Proof.* If exp(x) = ax + b for all x, then exp(0) = b = 1, exp(1) = a+1, so a = e-1. Then exp(-1) should equal -(e-1)+1 = 2-e. But exp(-1) = 1/e, and 1/e = 2-e iff (e-1)² = 0 iff e = 1, contradicting e > 1. □

### 5.3 Iterated Exponentials

The iterated exponential `iterExp n` (n-fold exp) has:
- depth(iterExp n) = n (exact)
- size(iterExp n) = n + 1 (linear)
- Strict growth: iterExp(n+1)(x) > iterExp(n)(x) for all x

**Theorem 5.3 (Growth Separation).** For all n ∈ ℕ and x ∈ ℝ:
```
exp^n(x) < exp^{n+1}(x)
```

*Proof.* By the inequality e^t ≥ t + 1, we have exp(exp^n(x)) ≥ exp^n(x) + 1 > exp^n(x). □

## 6. The Substitution Algebra

### 6.1 Definition

The substitution operation `e₁.subst(e₂)` replaces every occurrence of `proj` in e₁ with e₂, computing the composition e₁ ∘ e₂.

### 6.2 Properties

**Theorem 6.1 (Semantic Correctness).** `(e₁.subst e₂).eval x = e₁.eval(e₂.eval x)`.

**Theorem 6.2 (Depth Bound).** `depth(e₁.subst e₂) ≤ depth(e₁) + depth(e₂)`.

**Theorem 6.3 (Unit Law).** `e.subst(proj) = e`.

### 6.3 Cancellation

**Theorem 6.4 (Exp-Log Cancellation).** For x > 0: `exp(log(x)) = x`.

**Theorem 6.5 (Log-Exp Cancellation).** For all x: `log(exp(x)) = x`.

**Theorem 6.6.** The expression `exp(log(proj))` has size 3 but evaluates to the identity on (0,∞), demonstrating that EML size is not a faithful complexity measure without simplification.

## 7. Algorithms

### 7.1 EML Evaluation Algorithm

```python
def eval_eml(expr, x):
    match expr:
        case Const(c):    return c
        case Proj():      return x
        case Exp(e):      return exp(eval_eml(e, x))
        case Log(e):      return log(eval_eml(e, x))
        case Add(e1, e2): return eval_eml(e1, x) + eval_eml(e2, x)
        case Mul(e1, e2): return eval_eml(e1, x) * eval_eml(e2, x)
```

Time complexity: O(size(expr)). Space complexity: O(depth(expr)) for the recursion stack.

### 7.2 EML Substitution Algorithm

```python
def subst(e1, e2):
    match e1:
        case Const(c):    return Const(c)
        case Proj():      return e2
        case Exp(e):      return Exp(subst(e, e2))
        case Log(e):      return Log(subst(e, e2))
        case Add(a, b):   return Add(subst(a, e2), subst(b, e2))
        case Mul(a, b):   return Mul(subst(a, e2), subst(b, e2))
```

## 8. Discussion and Future Work

### 8.1 Quantitative Rates

Our density result is existential—it guarantees approximation but does not quantify the rate. A natural conjecture:

**Conjecture 8.1 (EML Jackson Inequality).** For f ∈ Lip_α([a,b]), there exists an EML expression of size O(ε^{-1/α}) achieving uniform error ε.

### 8.2 Multi-variate Extension

The framework extends naturally to ℝ^n by using n projection functions. The EML subalgebra on K ⊂ ℝ^n generated by the coordinate projections separates points (by the projections themselves), giving Stone-Weierstrass density on compact subsets of ℝ^n.

### 8.3 Normal Forms

The cancellation paradox (exp(log(x)) = x but has size 3) motivates the study of EML normal forms—reduced expressions that cannot be simplified. This connects to questions in symbolic computation and term rewriting.

### 8.4 Connections to Neural Networks

An EML expression tree can be viewed as a neural network without training: the architecture *is* the function. EML approximation theory thus provides a framework for analyzing the expressive power of specific network architectures.
