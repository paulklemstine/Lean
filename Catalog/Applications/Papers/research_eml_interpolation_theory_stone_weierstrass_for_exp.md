# EML Interpolation Theory: Stone–Weierstrass Density and Jackson-Type Rates for Exponential–Logarithmic Networks

**Author:** Aristotle
**Date:** 2026-06-28
**Domain:** Applications (approximation theory, theoretical machine learning)

## Abstract

We develop a quantitative approximation theory for **EML functions** — functions
built by finite composition of the exponential, the logarithm, addition,
multiplication, and real scalars. Three results anchor the theory. First, a
*separation theorem*: the single EML primitive
$g(t) = e^{a}\log(b t + c)$ is strictly monotone whenever $b > 0$ and its argument
is positive, hence injective, hence point-separating; on any interval
$[\mathrm{lo},\mathrm{hi}]$ the normalization $g(t) = \log(t + 1 - \mathrm{lo})$
suffices. Second, via the Stone–Weierstrass theorem, the unital subalgebra
generated by this *single* primitive is uniformly dense in
$C([\mathrm{lo},\mathrm{hi}], \mathbb{R})$ — and, abstractly, any point-separating
EML subalgebra is dense in $C(X,\mathbb{R})$ for compact Hausdorff $X$, a property
that transfers along injective continuous maps by a pullback construction. Third,
two *Jackson-type rate theorems* convert this existential density into
constructive, rate-quantified approximation. The piecewise-linear EML interpolant
on a uniform $n$-cell grid approximates any $L$-Lipschitz $f$ on $[0,1]$ with
uniform error $\le L/n$, and any $\alpha$-Hölder $f$ with error $\le 2L/n^{\alpha}$;
to reach accuracy $\varepsilon$ the width scales as $\varepsilon^{-1/\alpha}$. For
the smooth target $x^2$, the single-exponential network
$\mathrm{Q}_h(x) = (2/h^2)(e^{hx} - 1 - hx)$ achieves error $\le \tfrac{4}{9}h$,
i.e. $\le 4/(9n)$ at $h = 1/n$, and this rate is shown to be tight ($\Theta(1/n)$).
All results are fully formalized and machine-checked.

## 1. Introduction

Universal approximation theorems assert that a function class is dense in a space of
continuous functions, but in their classical form they are *existential*: they
guarantee that an approximant exists without bounding its complexity or its error.
For practical function classes — particularly those underlying neural and
log-domain computation — what is wanted is a *constructive* theory with explicit
**Jackson-type rates** relating accuracy to network size.

This paper supplies such a theory for the **EML class**: functions assembled from
exponentials, logarithms, additions, multiplications, and scalars. These are
exactly the operations available to computational architectures mixing additive
combination with exponential/logarithmic nonlinearities, and they pervade
scientific computing (log-likelihoods, log-sum-exp, multiplicative gating).

Our contributions are organized around three pillars.

1. **Separation (Section 3).** A single EML primitive $g(t) = e^a\log(bt+c)$ is
   strictly monotone for $b>0$ on the region where $bt+c>0$, hence separates
   points. On an interval the explicit normalization $g(t)=\log(t+1-\mathrm{lo})$
   discharges all hypotheses.

2. **Density (Section 4).** Stone–Weierstrass upgrades separation to uniform
   density of the generated subalgebra, both for the concrete single-generator
   interval algebra and abstractly for any point-separating EML subalgebra of
   $C(X,\mathbb{R})$, with a pullback transfer principle along injective maps.

3. **Rates (Sections 5–6).** Two structurally different constructions deliver
   explicit Jackson rates: the piecewise-linear interpolant for the entire
   Lipschitz/Hölder class, and a single rescaled exponential for the smooth target
   $x^2$, whose $\Theta(1/n)$ rate is proved sharp.

Section 7 records the curse of dimensionality and structured-target escapes as
future directions.

## 2. Preliminaries and definitions

Throughout, $X$ denotes a compact Hausdorff topological space and
$C(X,\mathbb{R})$ the Banach algebra of continuous real functions with the uniform
norm $\|f\| = \sup_{x\in X}|f(x)|$.

**Definition 2.1 (EML primitive).** For real parameters $a,b,c$, the *EML
separating primitive* is
$$\mathrm{emlSep}(a,b,c;t) = e^{a}\,\log(b\,t + c).$$
It is an EML function: a scalar exponential $e^a$ times the logarithm of an affine
map.

**Definition 2.2 (Point separation).** A subalgebra
$A \subseteq C(X,\mathbb{R})$ *separates points* if for all $x \neq y$ in $X$ there
is $h \in A$ with $h(x) \neq h(y)$.

**Definition 2.3 (Lipschitz / Hölder).** A function $f:\mathbb{R}\to\mathbb{R}$ is
$L$-*Lipschitz* if $|f(x)-f(y)| \le L|x-y|$ for all $x,y$, and $\alpha$-*Hölder*
with constant $L$ (for $0<\alpha\le 1$) if $|f(x)-f(y)| \le L|x-y|^{\alpha}$.

**Definition 2.4 (Piecewise-linear EML interpolant).** For $f:\mathbb{R}\to
\mathbb{R}$, width $n \ge 1$, and $x \in \mathbb{R}$, set
$$k = \min(n-1,\ \lfloor n x\rfloor),\quad a = \tfrac{k}{n},\quad b=\tfrac{k+1}{n},$$
and define
$$\widehat{f}_n(x) = \mathrm{pwLinInterp}(f,n;x) = f(a) + \frac{f(b)-f(a)}{b-a}(x-a).$$
The clamp $k = \min(n-1, \lfloor nx\rfloor)$ places $x\in[0,1]$ in the grid cell
$[k/n,(k+1)/n]$, with the boundary value $x=1$ assigned to the final cell. Each
branch is affine, so $\widehat{f}_n$ is a width-$n$ EML network (a finite gluing of
affine pieces).

**Definition 2.5 (Single-exponential quadratic network).** For $h>0$,
$$\mathrm{Q}_h(x) = \mathrm{emlQuadApprox}(h;x) = \frac{2}{h^2}\bigl(e^{hx}-1-hx\bigr),$$
the rescaled second-order forward difference of $\exp$, built from $\exp$,
addition, multiplication, and scalars.

## 3. The separation theorem

**Theorem 3.1 (`emlSep_strictMonoOn`).** Let $b>0$. Then $t\mapsto
\mathrm{emlSep}(a,b,c;t)$ is strictly increasing on $\{t : b t + c > 0\}$.

*Proof sketch.* For $t_1 < t_2$ with $bt_i+c>0$, monotonicity of the affine map
($b>0$) gives $0 < bt_1+c < bt_2+c$; strict monotonicity of $\log$ on the positive
reals gives $\log(bt_1+c) < \log(bt_2+c)$; multiplying by $e^a>0$ preserves the
strict inequality. $\qquad\blacksquare$

**Theorem 3.2 (`emlSep_separates`).** Let $b>0$ and $x\neq y$ with $bx+c>0$ and
$by+c>0$. Then $\mathrm{emlSep}(a,b,c;x)\neq\mathrm{emlSep}(a,b,c;y)$.

*Proof sketch.* A strictly monotone function is injective on its domain; apply
Theorem 3.1 and injectivity. $\qquad\blacksquare$

**Corollary 3.3 (`emlSep_separates_Icc`).** On $[\mathrm{lo},\mathrm{hi}]$, the
normalization $a=0$, $b=1$, $c=1-\mathrm{lo}$ — i.e. $g(t)=\log(t+1-\mathrm{lo})$ —
separates points. Indeed for $t\in[\mathrm{lo},\mathrm{hi}]$ the argument
$t+1-\mathrm{lo}\ge 1>0$, so the positivity hypothesis of Theorem 3.2 holds
uniformly.

The positivity domain is **load-bearing**: outside $\{bt+c>0\}$ the logarithm is
undefined or non-monotone, and separation can fail. The shift $c=1-\mathrm{lo}$ is
the minimal device that discharges it uniformly on the interval.

## 4. Density via Stone–Weierstrass

We use the Stone–Weierstrass theorem in the following operator form.

**Theorem 4.1 (`eml_topologicalClosure_eq_top_of_separatesPoints`).** Let $X$ be
compact Hausdorff and $A\subseteq C(X,\mathbb{R})$ a (unital) subalgebra that
separates points. Then the topological closure of $A$ is all of $C(X,\mathbb{R})$.

Equivalent reformulations are recorded as
`eml_dense_range_of_subalgebra_separatesPoints` (the carrier of $A$ is dense) and
the following $\varepsilon$-form.

**Theorem 4.2 (`eml_exists_uniform_approx`).** Under the hypotheses of Theorem 4.1,
for every $f\in C(X,\mathbb{R})$ and $\varepsilon>0$ there is $g\in A$ with
$\|g-f\|<\varepsilon$.

The abstract EML universal approximation theorem is the direct instantiation.

**Theorem 4.3 (`eml_universalApproximation`).** Any point-separating EML-generated
subalgebra $A\subseteq C(X,\mathbb{R})$ is uniformly dense in $C(X,\mathbb{R})$.

Combining the separation results of Section 3 with Theorem 4.1 yields a fully
*concrete* density statement from a single generator.

**Theorem 4.4 (`eml_adjoin_dense_on_Icc`).** The unital subalgebra
$\mathrm{Algebra.adjoin}\,\mathbb{R}\,\{t\mapsto\log(t+1-\mathrm{lo})\}$ generated
by the single EML primitive $g(t)=\log(t+1-\mathrm{lo})$ is uniformly dense in
$C([\mathrm{lo},\mathrm{hi}],\mathbb{R})$.

*Proof sketch.* The generator is continuous on $[\mathrm{lo},\mathrm{hi}]$ (its
argument is $\ge 1$). By Corollary 3.3 the generated subalgebra separates points
(`emlSepCM_separatesPoints`). Apply Theorem 4.1. $\qquad\blacksquare$

### 4.1 Pullback transfer along injective maps

Density transfers through continuous maps by precomposition, a principle used to
move approximation guarantees between domains.

**Definition 4.5 (Pullback subalgebra).** For continuous $\varphi:X\to Y$ and a
subalgebra $A\subseteq C(Y,\mathbb{R})$, the *pullback* is
$\varphi^{*}A = \{g\circ\varphi : g\in A\}\subseteq C(X,\mathbb{R})$, realized as
the image of $A$ under the precomposition algebra homomorphism
$\mathrm{precompAlgHom}(\varphi):C(Y,\mathbb{R})\to C(X,\mathbb{R})$,
$g\mapsto g\circ\varphi$.

The precomposition map is norm-contractive, $\|g\circ\varphi - h\circ\varphi\|\le
\|g-h\|$ (`norm_comp_le`), hence continuous (`continuous_precomp`); this is the
estimate that carries closures across $\varphi$.

**Theorem 4.6 (`pullback_closure_eq_factorsThrough`).** If $X,Y$ are compact
Hausdorff and $A$ is dense in $C(Y,\mathbb{R})$, then the closure of $\varphi^*A$
equals the subalgebra of functions on $X$ that factor through $\varphi$.

**Theorem 4.7 (`pullback_dense_of_injective`,
`eml_pullback_universalApproximation`).** If in addition $\varphi$ is injective and
$A$ separates points, then $\varphi^*A$ is dense in *all* of $C(X,\mathbb{R})$;
equivalently, every $f\in C(X,\mathbb{R})$ is within $\varepsilon$ of some
$g\circ\varphi$ with $g\in A$ (`eml_pullback_exists_approx`).

*Proof sketch.* An injective continuous map from a compact space to a Hausdorff
space is a closed embedding; by the Tietze extension theorem every continuous
function on $X$ factors through $\varphi$ (`factorsThrough_eq_top_of_injective`), so
the factors-through subalgebra is everything. Combine with Theorem 4.6.
$\qquad\blacksquare$

## 5. Jackson-type rate for the Lipschitz and Hölder classes

The piecewise-linear EML interpolant (Definition 2.4) converts density into an
explicit rate. The engine is a sharp single-cell estimate.

**Lemma 5.1 (`linInterp_error`).** If $f$ is $L$-Lipschitz and $a<b$, the linear
interpolant $\ell(x)=f(a)+\frac{f(b)-f(a)}{b-a}(x-a)$ through the endpoints of
$[a,b]$ satisfies, for $x\in[a,b]$,
$$|f(x)-\ell(x)|\le 2L\cdot\min(x-a,\ b-x).$$

*Proof sketch.* Bound $|f(x)-\ell(x)|$ two ways. Writing $f(x)-\ell(x)=(f(x)-f(a))
-\mathrm{slope}\cdot(x-a)$, the triangle inequality with $|f(x)-f(a)|\le L(x-a)$
and $|\mathrm{slope}|\le L$ gives $\le 2L(x-a)$. Symmetrically, anchoring at $b$
gives $\le 2L(b-x)$. Take the smaller. The error vanishes at the nodes $x=a,b$.
$\qquad\blacksquare$

**Lemma 5.2 (`pwLinInterp_locate`).** For $n\ge 1$ and $x\in[0,1]$, the clamped
index $k=\min(n-1,\lfloor nx\rfloor)$ satisfies $k/n\le x\le (k+1)/n$, i.e. $x$
lies in cell $[k/n,(k+1)/n]$. The clamp handles $x=1$ (where $\lfloor nx\rfloor=n$
would index a non-existent cell).

**Theorem 5.3 (`pwLinInterp_error`).** For any $L$-Lipschitz $f$, $n\ge 1$, and
$x\in[0,1]$,
$$\bigl|f(x)-\widehat{f}_n(x)\bigr|\le \frac{L}{n}.$$

*Proof sketch.* By Lemma 5.2, $x$ lies in a cell $[a,b]$ of width $b-a=1/n$. Lemma
5.1 gives $|f(x)-\widehat f_n(x)|\le 2L\min(x-a,b-x)\le 2L\cdot\frac{b-a}{2}=L(b-a)
=L/n$. $\qquad\blacksquare$

**Corollary 5.4 (`pwLinInterp_tendsto`).** For each $x\in[0,1]$,
$\widehat{f}_n(x)\to f(x)$ as $n\to\infty$.

The identical construction attains the full Hölder scaling.

**Lemma 5.5 (`holderInterp_error`).** If $f$ is $\alpha$-Hölder with constant $L$
($0<\alpha\le1$) and $a<b$, then for $x\in[a,b]$,
$$|f(x)-\ell(x)|\le 2L\,(b-a)^{\alpha}.$$

**Theorem 5.6 (`pwLinInterp_holder_error`).** For $\alpha$-Hölder $f$, $n\ge 1$,
and $x\in[0,1]$,
$$\bigl|f(x)-\widehat{f}_n(x)\bigr|\le \frac{2L}{n^{\alpha}}.$$
Hence width $n = O(\varepsilon^{-1/\alpha})$ suffices for uniform accuracy
$\varepsilon$, with $\widehat f_n(x)\to f(x)$ (`pwLinInterp_holder_tendsto`). The
Lipschitz case $\alpha=1$ recovers the $O(1/n)$ rate of Theorem 5.3.

*Proof sketch.* As in Theorem 5.3 with Lemma 5.5 replacing Lemma 5.1: the cell
width $1/n$ enters as $(1/n)^{\alpha}=1/n^{\alpha}$. $\qquad\blacksquare$

## 6. A smooth rate for $x^2$ and its sharpness

A single smooth EML gadget can beat the piecewise-linear construction on smooth
targets. The square function is the canonical example.

**Lemma 6.1 (`exp_sub_quadratic_le`).** For $u\in[0,1]$,
$$\Bigl|e^{u}-\bigl(1+u+\tfrac{u^2}{2}\bigr)\Bigr|\le \tfrac{2}{9}\,u^{3}.$$

*Proof sketch.* Taylor's theorem for $\exp$ truncated at order $3$ (Mathlib's
`Real.exp_bound`) bounds the remainder by $\tfrac{|u|^3}{3!}\cdot\frac{1}{1-|u|/4}$;
on $[0,1]$ this is at most $\tfrac{2}{9}u^3$. $\qquad\blacksquare$

**Theorem 6.2 (`emlQuadApprox_error`).** For $0<h\le1$ and $x\in[0,1]$,
$$\bigl|\mathrm{Q}_h(x)-x^2\bigr|\le \frac{4}{9}\,h.$$

*Proof sketch.* With $u=hx$, the algebraic identity
$\mathrm{Q}_h(x)-x^2=\frac{2}{h^2}\bigl(e^{u}-(1+u+\tfrac{u^2}{2})\bigr)$ holds.
Apply Lemma 6.1: the bound becomes $\frac{2}{h^2}\cdot\frac{2}{9}u^3=\frac{4}{9}h
x^3\le\frac{4}{9}h$ since $x\in[0,1]$. $\qquad\blacksquare$

**Theorem 6.3 (`emlQuadApprox_rate`).** For $n\ge 1$ and $x\in[0,1]$,
$$\bigl|\mathrm{Q}_{1/n}(x)-x^2\bigr|\le \frac{4}{9n},$$
with $\mathrm{Q}_{1/n}(x)\to x^2$ as $n\to\infty$ (`emlQuadApprox_tendsto`).

### 6.1 Sharpness

The $O(1/n)$ rate of this construction is not improvable.

**Lemma 6.4 (`exp_ge_cubic`, `emlQuadApprox_lower`).** A matching lower bound holds:
$\mathrm{Q}_h(x)-x^2$ is bounded *below* by a positive multiple of $h$ (for fixed
$x>0$), because $e^{u}\ge 1+u+\tfrac{u^2}{2}+\tfrac{u^3}{6}$ for $u\ge0$.

**Theorem 6.5 (`emlQuadApprox_error_Theta`, `emlQuadApprox_rate_lower`,
`emlQuadApprox_not_o`).** The error of the single-exponential network is
$\Theta(h)$, equivalently $\Theta(1/n)$ at $h=1/n$: it is bounded above and below by
constant multiples of $h$, and is *not* $o(h)$. The construction therefore achieves
exactly the Jackson rate and no faster.

### 6.2 Two witnesses for $x^2$

**Theorem 6.6 (`pwLinInterp_sq_rate`, `eml_two_witnesses_sq`).** Since $x\mapsto x^2$
is $2$-Lipschitz on $[0,1]$, the piecewise-linear EML interpolant also attains
$$\bigl|x^2-\widehat{(x^2)}_n(x)\bigr|\le \frac{2}{n},$$
so for every width $n\ge 1$ there are *two structurally distinct* width-$n$ EML
networks approximating $x^2$ at rate $O(1/n)$: the smooth network $\mathrm{Q}_{1/n}$
(constant $4/9$) and the piecewise-linear interpolant (constant $2$). The smooth
network is the tighter witness, $4/9 < 2$.

## 7. Algorithms

Two algorithms summarize the constructive content.

**Algorithm A (Lipschitz/Hölder Jackson interpolant).** Given $f$, target accuracy
$\varepsilon$, modulus $(L,\alpha)$ on $[0,1]$: choose
$n=\lceil(2L/\varepsilon)^{1/\alpha}\rceil$ (or $n=\lceil L/\varepsilon\rceil$ when
$\alpha=1$), sample $f$ at the nodes $\{j/n\}_{j=0}^{n}$, and return the
piecewise-linear interpolant $\widehat f_n$. Certified uniform error
$\le 2L/n^{\alpha}$ (Theorem 5.6); cost $O(n)$ samples and $O(1)$ evaluation per
point via the cell index $k=\min(n-1,\lfloor nx\rfloor)$.

**Algorithm B (single-exponential quadratic network).** Given accuracy
$\varepsilon$, choose $h=\min(1,\ 9\varepsilon/4)$ and return
$\mathrm{Q}_h(x)=(2/h^2)(e^{hx}-1-hx)$. Certified uniform error $\le \tfrac49 h\le
\varepsilon$ on $[0,1]$ (Theorem 6.2); a single exponential evaluation per point.

## 8. Applications and discussion

**Constructive universal approximation.** The combination
"separation $\Rightarrow$ density $\Rightarrow$ explicit rate" turns the classical
existential universal-approximation guarantee into an engineering recipe with a
size–accuracy law. For EML architectures the law is $n=O(\varepsilon^{-1/\alpha})$
in one dimension.

**Minimality of separation.** Theorem 4.4 shows that *one* strictly monotone
log-function generates a dense algebra. Universality of EML functions thus reduces
to the single, verifiable property of telling points apart.

**Two complementary constructions.** The piecewise-linear interpolant is universal
across the Hölder scale; the single-exponential network exploits smoothness for a
better constant on $x^2$. Theorem 6.6 exhibits both as width-$n$ EML networks for
the same target, and Section 6.1 certifies the smooth rate as tight.

**Transfer of guarantees.** The pullback principle (Theorems 4.6–4.7) moves density
along injective continuous maps, allowing approximation results proved on a
convenient domain $Y$ to be imported to any embedded domain $X$.

## 9. Future directions

This cycle extended the EML approximation programme in two directions previously
available only in one dimension or two variables.

- **Multivariate Lipschitz rate.** The $d$-dimensional grid quantizer gives uniform
  error $L d/(2n)$ with an approximant taking $\le (n+1)^d$ values; accuracy
  $\varepsilon$ needs width $\le(n+1)^d$ with $n\le Ld/(2\varepsilon)+1$, i.e.
  width $O(\varepsilon^{-d})$ — the conjectured $\varepsilon^{-n/\alpha}$ exponent
  at $\alpha=1$, $n=d$. This is the curse of dimensionality made explicit.
- **LogSumExp surrogate for the maximum.** The $d$-variable LogSumExp
  $\mathrm{lse}_t(x)=(1/t)\log\sum_i e^{t x_i}$ is a one-sided EML
  over-approximation of $\max$ with explicit slack $(\log d)/t$, converging as
  $t\to\infty$; the two-variable case recovers the softmax error bound. The
  contrast — *logarithmic* dimension dependence for the smooth max surrogate vs.
  *exponential* dimension dependence for uniform Lipschitz approximation — seeds the
  conjectures below.

**Conjecture 1 — Matching lower bound (the exponent $d$ is necessary).** There is
$c_d>0$ such that for every $M$ and every $g:[0,1]^d\to\mathbb{R}$ taking at most
$M$ distinct values, some $1$-Lipschitz ($\ell^1$) $f$ has $\|f-g\|_\infty\ge
c_d M^{-1/d}$. Equivalently, width $\Omega(\varepsilon^{-d})$ is unavoidable, so the
grid rate is optimal. The key insight: a $\delta$-separated grid of
$(\lfloor 1/\delta\rfloor+1)^d$ points is a fooling set — a piecewise-constant $g$
with fewer pieces must collapse two grid points, and a Lipschitz $f$ separating
them forces error $\ge\delta/2$.

**Conjecture 2 — LogSumExp beats the curse for max-structured targets.** If $f$ is
the maximum of $d$ affine (ridge) functions on $[0,1]^d$, then the single EML
network $\mathrm{lse}_t$ of the $d$ ridge features approximates $f$ to accuracy
$\varepsilon$ with width $O(d)$ and temperature $t=(\log d)/\varepsilon$ —
polynomial, not exponential, in $d$. The slack $(\log d)/t$ decouples the cost from
the ambient dimension when the target is a max of few features.

**Conjecture 3 — A smooth ($C^\infty$) EML Jackson rate via LogSumExp gluing.**
Replacing the discontinuous grid quantizer by a LogSumExp-smoothed partition of
unity should yield a $C^\infty$ EML approximant retaining the Jackson rate, removing
the corners of the piecewise-linear interpolant while preserving explicit error
control.

## 10. Conclusion

We have given a self-contained, machine-checked quantitative approximation theory
for EML functions: a single strictly monotone log-primitive separates points
(Theorems 3.1–3.2, Corollary 3.3); separation forces uniform density via
Stone–Weierstrass, even from one generator (Theorems 4.1–4.4) and across injective
maps (Theorems 4.6–4.7); and two explicit constructions deliver Jackson-type rates
— $O(1/n)$ and $O(n^{-\alpha})$ for the Lipschitz/Hölder classes (Theorems 5.3,
5.6) and a tight $\Theta(1/n)$ rate for $x^2$ via a single exponential (Theorems
6.2–6.5). Together these results elevate EML universal approximation from an
existential statement to a constructive theory with explicit size–accuracy laws.
