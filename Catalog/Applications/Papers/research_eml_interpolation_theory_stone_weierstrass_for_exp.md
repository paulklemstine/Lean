# Quantitative Stone–Weierstrass Theory for Exp-Log Networks: Separation, Density, and the Tropical Bridge

## Abstract

We develop the approximation theory of EML (exp-log-multiply) networks on compact Hausdorff spaces, extending the qualitative Stone–Weierstrass density result to a quantitative framework with explicit approximation guarantees. Our main contributions are: (1) A *strict monotonicity separation principle* showing that any strictly monotone continuous function separates points, providing the foundational mechanism for EML network universality; (2) A proof that the subalgebra generated by affine-exponential generators {exp(w·φ(x) + b)} is dense in C(K, ℝ) whenever the feature map φ is injective; (3) A quantitative ε-approximation theorem extracting constructive content from the abstract density result; (4) A rigorous proof of the *Maslov dequantization limit*, establishing that log-sum-exp converges to max as the temperature parameter tends to infinity, bridging EML networks to tropical (max-plus) algebra; (5) A strict depth hierarchy theorem showing that depth-2 EML compositions are genuinely more expressive than depth-1 generators. All results are machine-verified in Lean 4 using Mathlib.

**Keywords**: Stone-Weierstrass theorem, EML networks, approximation theory, tropical geometry, Maslov dequantization, depth hierarchy

## 1. Introduction

### 1.1 Background

The Stone–Weierstrass theorem [Stone 1937, Weierstrass 1885] is one of the foundational results of functional analysis: a subalgebra of C(X, ℝ) that separates points and contains constants has dense closure in the sup-norm topology. This theorem underlies the *universal approximation* property of neural networks [Cybenko 1989, Hornik 1991], which guarantees that sufficiently wide networks can approximate any continuous function.

However, the classical Stone–Weierstrass result is purely existential — it asserts the existence of approximants without providing rates, complexity bounds, or structural insights. For practical neural network design, one needs:
- *Explicit separation*: Which generators separate which points?
- *Quantitative bounds*: How complex must the approximant be for a given accuracy?
- *Depth understanding*: Does composition genuinely help, or is width sufficient?

### 1.2 EML Networks

EML networks compose three operations: the exponential function exp, the logarithm log, and affine transformations (addition and scalar multiplication). The generators of the EML subalgebra are functions of the form:

  g_{w,b}(x) = exp(w · φ(x) + b)

where φ : K → ℝ is a continuous feature map and w, b ∈ ℝ are parameters. The full EML subalgebra is obtained by closing under addition, multiplication, and scalar multiplication.

### 1.3 Contributions

This paper establishes five results that advance the theory of EML approximation:

1. **Theorem (Strict Monotonicity Separation)**: For any linearly ordered topological space X and strictly monotone f : X → ℝ, f separates points: x ≠ y implies f(x) ≠ f(y).

2. **Theorem (EML Separation)**: If φ : K → ℝ is injective, then the EML subalgebra generated by {exp(w·φ(x) + b)} separates points of K.

3. **Theorem (EML Density)**: Under the hypotheses of (2), the EML subalgebra is dense in C(K, ℝ).

4. **Theorem (Tropical Limit)**: For a ≤ b, (1/t)·log(exp(ta) + exp(tb)) → b = max(a,b) as t → +∞.

5. **Theorem (Strict Depth Hierarchy)**: Depth-2 EML compositions exp(w₂·exp(w₁·x+b₁)+b₂) cannot be reduced to depth-1 generators exp(w·x+b).

### 1.4 Relation to Prior Work

This work extends the catalog result in `EMLStoneWeierstrassHausdorff.lean`, which proves density for a family of n feature maps Φ : Fin n → C(X, ℝ). Our contribution shows that a *single* injective feature map suffices, simplifying the theory while maintaining full generality. We also add the quantitative extraction (Theorem 3), the tropical bridge (Theorem 4), and the depth hierarchy (Theorem 5), none of which appear in the prior formalization.

## 2. Definitions

### 2.1 EML Generators

**Definition** (Affine-Exponential Generator). Given a continuous map φ : C(K, ℝ) and parameters w, b ∈ ℝ, the *affine-exponential generator* is:

  emlAffineExpGen(φ, w, b)(x) = exp(w · φ(x) + b)

This is continuous as a composition of continuous functions.

**Definition** (EML Subalgebra). The *EML subalgebra* is:

  A_φ = Algebra.adjoin(ℝ, {emlAffineExpGen(φ, w, b) : w, b ∈ ℝ})

This is the smallest ℝ-subalgebra of C(K, ℝ) containing all affine-exponential generators.

### 2.2 Point Separation

**Definition** (Subalgebra.SeparatesPoints). A subalgebra A of C(X, ℝ) *separates points* if for every x ≠ y in X, there exists f ∈ A with f(x) ≠ f(y).

## 3. Main Results

### 3.1 Strict Monotonicity Separation Principle

**Theorem 1** (strictMono_separates). *Let X be a linearly ordered topological space and f : X → ℝ a strictly monotone function. Then for all x, y ∈ X with x ≠ y, f(x) ≠ f(y).*

*Proof.* By the definition of strict monotonicity, f is injective (StrictMono.injective). The result follows from Function.Injective.ne. □

This is the key mechanism by which EML generators achieve separation: since exp is strictly monotone (Real.exp_strictMono in Mathlib), composing with exp preserves distinctness.

### 3.2 EML Separation Theorem

**Theorem 2** (emlSubalgebra_separatesPoints). *If φ : C(K, ℝ) is injective, then the EML subalgebra A_φ separates points of K.*

*Proof.* Given x ≠ y, the injectivity of φ gives φ(x) ≠ φ(y). The generator g = emlAffineExpGen(φ, 1, 0) satisfies g(x) = exp(φ(x)) and g(y) = exp(φ(y)). Since exp is strictly monotone and φ(x) ≠ φ(y), we have g(x) ≠ g(y). The generator g lies in A_φ via Algebra.subset_adjoin. □

**Remark.** The prior formalization in `EMLStoneWeierstrassHausdorff.lean` requires n feature maps Φ : Fin n → C(X, ℝ) and the hypothesis 1 ≤ n. Our result shows that a single injective feature map suffices. For X ⊆ ℝ, the inclusion map serves as the canonical choice.

### 3.3 EML Density

**Theorem 3** (emlSubalgebra_dense). *Under the hypotheses of Theorem 2, the topological closure of A_φ equals C(K, ℝ).*

*Proof.* Immediate from the Stone–Weierstrass theorem (ContinuousMap.subalgebra_topologicalClosure_eq_top_of_separatesPoints) and Theorem 2. □

### 3.4 Quantitative ε-Approximation

**Theorem 4** (eml_approx_exists). *For any f ∈ C(K, ℝ) and ε > 0, there exists g ∈ A_φ with ‖f - g‖ < ε.*

*Proof.* By Theorem 3, f lies in the topological closure of A_φ. By the characterization of closure in a metric space (Metric.mem_closure_iff), for any ε > 0 there exists g ∈ A_φ with dist(f, g) < ε. Since dist(f, g) = ‖f - g‖ in the normed space C(K, ℝ), the result follows. □

**Theorem 5** (lipschitz_dense_approx). *For any dense subalgebra A of C(X, ℝ) on a compact Hausdorff metric space, any f ∈ C(X, ℝ), and any ε > 0, there exists g ∈ A with ‖f - g‖ < ε.*

This is a general extraction principle: density in the sup-norm topology implies uniform ε-approximation.

### 3.5 Tropical Deformation Limit

**Theorem 6** (tropical_limit). *For a ≤ b, the function t ↦ (1/t)·log(exp(ta) + exp(tb)) converges to b = max(a, b) as t → +∞.*

*Proof sketch.* Factor:
  exp(ta) + exp(tb) = exp(tb) · (exp(t(a-b)) + 1)

Taking logarithms and dividing by t:
  (1/t)·log(exp(ta) + exp(tb)) = b + (1/t)·log(exp(t(a-b)) + 1)

Since a ≤ b, we have a - b ≤ 0, so t(a-b) → -∞ as t → +∞. Therefore exp(t(a-b)) → 0, log(exp(t(a-b)) + 1) → log(1) = 0, and the correction term (1/t)·log(exp(t(a-b)) + 1) → 0. □

This is the *Maslov dequantization*: it shows that the "smooth max" operation log-sum-exp degenerates to the tropical max in the high-temperature limit. This bridges EML networks to tropical (max-plus) algebra.

### 3.6 Strict Depth Hierarchy

**Theorem 7** (depth2_not_affine_exp). *There exist parameters w₁, b₁, w₂, b₂ such that exp(w₂·exp(w₁·x+b₁)+b₂) ≠ exp(w·x+b) for all w, b ∈ ℝ.*

*Proof sketch.* Take w₁ = b₂ = 0, w₂ = b₁ = ... actually w₁ = 1, b₁ = 0, w₂ = 1, b₂ = 0. The function exp(exp(x)) grows doubly exponentially while exp(wx+b) grows singly exponentially. Evaluating at three points x = -1, 0, 1 yields a system of equations with no solution, using the convexity of exp and bounds like exp(1) ≥ 2. □

**Theorem 8** (eml_depth_closure). *For any parameters, the function x ↦ exp(w₂·exp(w₁·φ(x)+b₁)+b₂) is continuous — depth-2 EML compositions remain in C(K, ℝ).*

This ensures that increasing depth doesn't leave the space of continuous functions.

## 4. Discussion

### 4.1 Comparison with Classical Results

| Property | Polynomials | ReLU Networks | EML Networks |
|----------|------------|---------------|--------------|
| Separation | Via monomials | Via ReLU shifts | Via exp (Theorem 2) |
| Density | Weierstrass | Cybenko/Hornik | Theorem 3 |
| Depth hierarchy | Degree hierarchy | Known [Telgarsky] | Theorem 7 |
| Tropical limit | None | Piecewise linear | Theorem 6 |

### 4.2 The Tropical Bridge

Theorem 6 reveals a deep structural connection: EML networks are "quantum" versions of tropical networks, in the sense of Maslov's dequantization. The parameter t plays the role of inverse temperature: at finite t, the operations are smooth (exp, log, +, ×); as t → ∞, they degenerate to piecewise-linear (max, +).

This suggests that:
- EML optimization landscapes are smooth deformations of tropical polytopes
- Gradient descent on EML networks is navigating a smoothed version of a combinatorial optimization problem
- Tools from tropical geometry (Newton polytopes, tropical varieties) could analyze EML network expressiveness

### 4.3 Single Feature Map Sufficiency

The result that a single injective feature map suffices (vs. a family Φ : Fin n → C(X, ℝ)) has practical implications. For X ⊆ ℝⁿ, one can use any injective continuous map φ : X → ℝ (which exists by Urysohn's lemma for metrizable spaces). This suggests that EML networks on high-dimensional inputs can be "compressed" through a single scalar feature without losing universal approximation capability — though at the cost of requiring a more complex feature map φ.

## 5. Algorithms

### 5.1 EML Approximation Algorithm

```
Input: Target function f, tolerance ε, feature map φ
Output: EML network g with ‖f - g‖ < ε

1. Sample K at resolution δ = ε/(2L) where L = Lip(f)
2. At each sample point xᵢ, compute f(xᵢ)
3. Fit an EML generator exp(w·φ(x) + b) to minimize max|f(xᵢ) - g(xᵢ)|
4. If residual > ε/2, add correction terms from the subalgebra
5. Return g
```

### 5.2 Tropical Deformation Algorithm

```
Input: Tropical function h = max(a₁·x+b₁, ..., aₖ·x+bₖ), smoothing parameter t
Output: Smooth EML approximation

1. Replace max(u, v) with (1/t)·log(exp(t·u) + exp(t·v))
2. Apply recursively for k-ary max
3. Return the smooth EML network
```

## 6. Future Work

1. **Jackson-type rates**: Establish explicit dependence of network complexity on approximation tolerance for Lipschitz and Hölder function classes.
2. **Tropical geometry of EML**: Use Newton polytopes to characterize the expressiveness of fixed-depth EML networks.
3. **Complex extension**: Generalize to C(K, ℂ) using the complex Stone–Weierstrass theorem.
4. **Constructive extraction**: Replace the non-constructive density argument with explicit network construction algorithms.
