# Stone-Weierstrass for EML Networks: Universal Approximation via Injective Generators

## Abstract

We establish that the algebra of EML (exponential-multiply-logarithm) functions is dense in the space of continuous functions on compact Hausdorff spaces, with proofs formalized in Lean 4. Our main contribution is a general **injective generator theorem**: on any compact Hausdorff space X, a single injective continuous function σ : X → ℝ generates a subalgebra whose closure equals C(X, ℝ). This unifies and generalizes classical results on polynomial density (Weierstrass), exponential density, and neural network universal approximation. We prove the separation property for subalgebras containing injective elements, apply Stone-Weierstrass to obtain density, demonstrate that exp is not a polynomial (establishing strict hierarchy), and show the exponential monomial system {e^{nx}}_{n≥0} forms a complete system. All results are machine-verified using the Lean 4 proof assistant with Mathlib.

**Keywords**: Stone-Weierstrass theorem, universal approximation, EML networks, subalgebra density, injective generators

## 1. Introduction

The Stone-Weierstrass theorem is one of the foundational results of functional analysis: if A is a subalgebra of C(X, ℝ) that separates points and contains constants, where X is compact Hausdorff, then the closure of A equals C(X, ℝ).

In the context of neural networks, the **universal approximation theorem** (Cybenko 1989, Hornik 1991) states that single-hidden-layer networks with suitable activation functions can approximate any continuous function on compact sets. The classical proofs use the Stone-Weierstrass theorem but typically require the activation function to be non-polynomial (Leshno et al. 1993) or satisfy certain moment conditions.

We observe that a simpler, more fundamental property suffices: **injectivity**. If the activation function σ is injective on the compact input domain, then σ alone generates a dense subalgebra. This is because injectivity immediately implies the separation property required by Stone-Weierstrass.

### 1.1 Main Results

Our principal contributions are:

1. **Subalgebra Separation via Injectivity** (Theorem 3.1): If a subalgebra A ⊆ C(X, ℝ) contains an injective element, then A separates points.

2. **Injective Generator Density** (Theorem 3.2): For any injective σ ∈ C(X, ℝ) on compact Hausdorff X, the subalgebra Algebra.adjoin ℝ {σ} has closure ⊤.

3. **EML Density on Intervals** (Theorem 4.1): The algebra generated by exp is dense in C([a,b], ℝ) for any interval [a,b].

4. **Strict Hierarchy** (Theorem 5.1): exp is not a polynomial function, so the EML algebra strictly extends the polynomial algebra.

5. **Exponential Monomial Completeness** (Theorem 5.2): The system {e^{nx}}_{n≥0} generates a dense subalgebra.

6. **Joint Exp-Log Density** (Theorem 6.1): On intervals where both are defined, the joint exp-log algebra is dense.

7. **Composition Depth** (Theorem 6.2): exp∘exp also generates a dense algebra; double composition preserves the density property.

## 2. Preliminaries

### 2.1 The Stone-Weierstrass Theorem

Let X be a compact Hausdorff topological space. A **subalgebra** A of C(X, ℝ) (the algebra of continuous real-valued functions on X with the supremum norm) is a subset closed under addition, scalar multiplication by reals, and pointwise multiplication, containing the constant function 1.

A subset S ⊆ C(X, ℝ) **separates points** if for every x ≠ y in X, there exists f ∈ S with f(x) ≠ f(y).

**Theorem (Stone-Weierstrass).** *If A is a subalgebra of C(X, ℝ) that separates points, then the topological closure of A equals C(X, ℝ).*

In Mathlib, this is formalized as `subalgebra_topologicalClosure_eq_top_of_separatesPoints`.

### 2.2 EML Functions

The **EML algebra** consists of functions built from:
- The exponential function exp : ℝ → ℝ
- The natural logarithm log : ℝ₊ → ℝ  
- Addition and multiplication of functions
- Scalar multiplication by real constants

On a compact domain K, the EML algebra restricted to K forms a subalgebra of C(K, ℝ).

## 3. The Injective Generator Theorem

### 3.1 Separation from Injectivity

**Theorem 3.1** (Subalgebra Separation). *Let A be a subalgebra of C(X, ℝ) for any topological space X. If A contains an element f such that f : X → ℝ is injective, then A separates points.*

*Proof.* Given x ≠ y in X, we need g ∈ A with g(x) ≠ g(y). Take g = f. Since f is injective and x ≠ y, we have f(x) ≠ f(y). □

The formalized proof is:
```
theorem Subalgebra.separatesPoints_of_injective
    (A : Subalgebra ℝ C(X, ℝ)) (f : A)
    (hf : Function.Injective (f : C(X, ℝ))) :
    A.SeparatesPoints := by
  intro x y hxy
  exact ⟨_, ⟨f, f.2, rfl⟩, hf.ne hxy⟩
```

**Remark.** This theorem requires no topological assumptions on X — neither compactness nor the Hausdorff property. The separation property is purely algebraic/set-theoretic.

### 3.2 Density of Injective Generators

**Theorem 3.2** (Injective Generator Density). *Let X be compact Hausdorff. If σ ∈ C(X, ℝ) is injective, then the subalgebra generated by σ has closure C(X, ℝ).*

*Proof.* By Theorem 3.1, the subalgebra Algebra.adjoin ℝ {σ} contains the injective function σ and hence separates points. By Stone-Weierstrass, its closure is ⊤. □

**PEGB Analysis:**
- **P**roof: Direct two-line application of Theorems 3.1 and Stone-Weierstrass
- **E**xample: σ = exp on [0,1] gives the EML density theorem (Section 4)
- **G**eneralization: Works for any topological ring, not just ℝ, if Stone-Weierstrass holds
- **B**oundary: Fails for non-injective σ (e.g., σ = const generates only constants; σ = x² on [-1,1] fails to separate ±x). Also requires compactness (counterexample: σ = id on ℝ generates polynomials, which are not dense in C(ℝ, ℝ) with compact-open topology).

## 4. EML Density on Compact Intervals

### 4.1 Density of the Exp-Generated Algebra

**Theorem 4.1.** *For any a, b ∈ ℝ, the subalgebra of C([a,b], ℝ) generated by exp is dense.*

*Proof.* The exponential function is injective on all of ℝ (it is strictly monotone), hence injective on any subinterval. Apply Theorem 3.2. □

**PEGB Analysis:**
- **P**roof: One-line from Theorem 3.2 + exp injectivity
- **E**xample: On [0,1], the polynomial a₀ + a₁e^x + a₂e^{2x} + ... + aₙe^{nx} can approximate any f ∈ C([0,1], ℝ)
- **G**eneralization: Works on any compact subset of ℝ (not just intervals), since exp is globally injective
- **B**oundary: On non-compact domains, the algebra generated by exp may fail to be dense (e.g., on [0,∞), exponential polynomials cannot approximate functions that decay at infinity)

### 4.2 Quantitative Form

**Theorem 4.2.** *For any f ∈ C([0,1], ℝ) and ε > 0, there exists g in the exp-generated subalgebra with ‖g - f‖_∞ < ε.*

This follows from density by the definition of topological closure in the normed space C([0,1], ℝ).

## 5. Structural Results

### 5.1 exp is Not a Polynomial

**Theorem 5.1.** *There is no polynomial p ∈ ℝ[X] such that exp(x) = p(x) for all x ∈ [0,1].*

*Proof.* By contradiction. If exp = p on [0,1], then their iterated derivatives agree on (0,1). The (deg(p)+1)-th derivative of exp at 1/2 is e^{1/2} ≠ 0, while the (deg(p)+1)-th derivative of p is 0. □

**PEGB Analysis:**
- **P**roof: Uses iterated derivative comparison
- **E**xample: exp(0) = 1, exp(0.5) ≈ 1.6487, exp(1) ≈ 2.7183 — these values lie on no polynomial of bounded degree
- **G**eneralization: exp is not even an algebraic function; it's transcendental over ℝ(x)
- **B**oundary: On finite discrete subsets, exp *is* interpolated by a polynomial (Lagrange interpolation)

### 5.2 Exponential Monomial Completeness

**Theorem 5.2.** *The system of exponential monomials {e^{nx}}_{n≥0} generates a dense subalgebra of C([0,1], ℝ).*

*Proof.* The monomial e^{1·x} = e^x is injective on [0,1]. It belongs to the generated subalgebra (it's in the generating set). By Theorem 3.1, the subalgebra separates points. By Stone-Weierstrass, it's dense. □

This result is related to the Müntz-Szász theorem, which characterizes which subsets of {x^λ} generate a dense subalgebra. Our exponential version shows the analogous result holds for exponential monomials unconditionally.

## 6. Composition and Joint Algebras

### 6.1 Composition Preserves Density-Generation

**Theorem 6.1.** *exp∘exp generates a dense subalgebra of C([0,1], ℝ).*

*Proof.* exp∘exp is injective (composition of injective functions). Apply Theorem 3.2. □

More generally, any finite composition of injective continuous functions is injective and continuous, hence generates a dense algebra on any compact domain.

### 6.2 Joint Exp-Log Algebra

**Theorem 6.2.** *On [1, e], the algebra generated jointly by exp and log is dense.*

*Proof.* The joint algebra contains exp, which is injective on [1, e]. By Theorem 3.1, it separates points. By Stone-Weierstrass, it's dense. □

The joint algebra is richer than either the exp-algebra or the log-algebra alone: it's closed under both exp and log composition (where defined), forming a structure closer to the full EML algebra.

## 7. Bridge to Neural Networks

### 7.1 Universal Approximation via Injectivity

Our Theorem 3.2 can be rephrased in neural network language:

**Corollary 7.1** (Activation Universality). *On any compact Hausdorff input space X, a single-hidden-layer neural network with any injective continuous activation function σ is a universal approximator.*

This is because the single-hidden-layer network computes functions of the form:
$$f(x) = \sum_{i=1}^{n} a_i \prod_{j \in S_i} \sigma(x)^{k_j}$$
which are elements of the algebra generated by σ. The universality follows from the density of this algebra.

### 7.2 Comparison with Classical Results

The classical Cybenko (1989) and Hornik (1991) results require the activation function to be non-constant and continuous (Cybenko requires sigmoidal; Hornik requires non-polynomial). Our result requires only injectivity, which is a strictly different condition:

- Every non-constant polynomial on a compact interval is either injective or non-injective
- cos(x) on [0, 2π] is continuous and non-polynomial but not injective
- x² on [-1,1] is continuous and non-polynomial but not injective
- Any strictly monotone continuous function is injective

The injective condition is both sufficient (by our theorem) and essentially necessary for the "single-generator" version: if σ is not injective, say σ(x) = σ(y) for x ≠ y, then no element of Algebra.adjoin ℝ {σ} can distinguish x from y, so the algebra fails to separate points.

## 8. Algorithms

### 8.1 EML Approximation Algorithm

Given target f ∈ C([a,b], ℝ) and tolerance ε > 0:

1. Choose N grid points x₁, ..., x_N in [a,b]
2. Form the design matrix M_{ij} = exp(j · x_i) for i = 1,...,N and j = 0,...,d
3. Solve the least-squares problem min_c ‖Mc - f‖₂ where f_i = f(x_i)
4. The approximation is g(x) = Σ c_j exp(j · x)
5. If ‖g - f‖_∞ > ε, increase d and/or N and repeat

This algorithm converges by the density theorem; the rate depends on the smoothness of f.

## 9. Discussion and Future Work

### 9.1 Quantitative Bounds

Our current results are qualitative (existence of ε-approximations) rather than quantitative (bounds on the degree/complexity needed). Jackson-type theorems for exponential polynomials — bounding the approximation error in terms of the modulus of continuity and the degree — remain open.

**Conjecture.** For f ∈ Lip_α([0,1]) with α ∈ (0,1], the best approximation by exponential polynomials of degree n satisfies:
$$E_n^{\exp}(f) = O(n^{-α})$$

This would parallel the classical Jackson theorem for algebraic polynomials.

### 9.2 Multi-dimensional Extensions

On compact K ⊂ ℝ^d, the separation property is more subtle. A single function σ : K → ℝ can separate points only if it's injective, which is a strong condition in higher dimensions (it requires K to be essentially one-dimensional, by invariance of domain). For genuine multi-dimensional universal approximation, one needs a family of functions {σ ∘ ℓ_w : w ∈ ℝ^d} where ℓ_w are linear functionals.

### 9.3 Rate-Optimal Activation Functions

Among all injective activations, which gives the fastest approximation rate? The exponential function has the special property that (d/dx)exp = exp, making it a fixed point of differentiation. This self-reproducing property might yield optimal approximation rates for analytic functions.
