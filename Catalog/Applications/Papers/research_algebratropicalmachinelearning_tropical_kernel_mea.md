# Tropical Kernel Mean Duality via Idempotent RKHS Semimodules and Certified Support Prototype Reconstruction

## Abstract

We establish a finite duality theorem connecting tropical (max-plus) kernel theory with prototype-based machine learning. For a finite type X equipped with a tropical kernel K : X × X → ℝ admitting a feature factorization of rank r, we prove that: (1) the kernel semimodule — the tropical analogue of a reproducing kernel Hilbert space — is generated by at most r extremal sections; (2) every element of this semimodule admits a unique minimal antichain support, computable via residuation; (3) the residuated coefficients provide canonical, optimal reconstruction weights. These results are fully formalized and machine-verified. We provide algorithms for support extraction (O(n³)), residuated coefficient computation (O(n²)), and certified minimal reconstruction, along with concrete numerical examples demonstrating the theory.

**Keywords:** tropical kernels, idempotent RKHS, max-plus semimodules, prototype compression, residuation, support vectors, antichain support, certified reconstruction

## 1. Introduction

### 1.1 Motivation

Classical reproducing kernel Hilbert space (RKHS) theory provides the mathematical foundation for support vector machines, Gaussian processes, and kernel regression. A central result — the Representer Theorem — states that the solution to a regularized empirical risk minimization problem in an RKHS can be expressed as a finite linear combination of kernel sections at the training points. The support vectors are the training points with nonzero coefficients.

However, the classical Representer Theorem is fundamentally *optimization-dependent*: the support vectors depend on the loss function, the regularization, and the specific training data. There is no intrinsic algebraic characterization of which training examples are "essential."

In this work, we develop an algebraic alternative: a *tropical representer theorem* for finite kernels, where the support prototypes are determined canonically by the algebraic structure of the kernel semimodule. This provides:

- **Canonical sparsity**: The minimal support is unique and determined by residuation.
- **Certified minimality**: Each support element is provably necessary.
- **Antichain structure**: No support element dominates any other.
- **Constructive computation**: Coefficients are computed by a simple minimum, not optimization.

### 1.2 Related Work

**Max-plus algebra and idempotent analysis.** The tropical (max-plus) semiring (ℝ ∪ {-∞}, max, +) has been extensively studied in optimization, control theory, and discrete event systems [1, 2, 3]. The idempotent analogue of linear algebra over this semiring involves semimodules rather than vector spaces.

**Tropical convexity.** Develin and Sturmfels [4] developed tropical convexity, including tropical polytopes and tropical halfspaces. Our kernel semimodule is a special case of a tropically convex set generated by kernel sections.

**Residuation theory.** Residuation (the Galois connection associated with the max-plus semiring) provides optimal "division" in the max-plus setting [5, 6]. We use residuation to define canonical reconstruction coefficients.

**Kernel methods in machine learning.** Classical RKHS theory [7, 8] establishes representation theorems for kernel methods. Max-plus kernel methods have been explored in [9, 10] but without the algebraic duality framework we develop here.

### 1.3 Contributions

1. **Formal definitions** of tropical feature rank, kernel semimodule, residuated coefficients, support antichains, and minimal support expansion for finite tropical kernels.

2. **A complete chain of proved theorems** establishing:
   - Residuated coefficients are optimal (Galois connection property)
   - The residuated bound is tight (achieved at some witness point)
   - Every kernel section is in the kernel span
   - Minimal supports are antichains under the domination preorder
   - Feature factorizations determine kernel generation
   - The tropical prototype predictor exactly reconstructs from minimal support

3. **Algorithms** for residuated coefficient computation (O(n²)), greedy minimal support extraction (O(n³)), and antichain verification (O(|S|²n)).

4. **Machine-verified proofs** of all main results using the Lean 4 proof assistant with the Mathlib library.

## 2. Definitions and Notation

### 2.1 Tropical Semiring

The **tropical semiring** is (ℝ ∪ {-∞}, ⊕, ⊙) where a ⊕ b = max(a, b) and a ⊙ b = a + b. The additive identity is -∞ and the multiplicative identity is 0.

In our finite setting, we work over ℝ (without -∞) for simplicity, using Finset.sup' for finite tropical sums.

### 2.2 Tropical Kernel

Let X be a finite type with n elements.

**Definition 2.1 (Tropical Kernel).** A **tropical kernel** on X is a function K : X × X → ℝ.

**Definition 2.2 (Kernel Section).** The **kernel section** at x ∈ X is K_x : X → ℝ defined by K_x(y) = K(x, y).

**Definition 2.3 (Tropical Feature Factorization).** K has a **tropical feature factorization of rank ≤ r** if there exists φ : X → ℝ^(r+1) such that

K(x, y) = max_{i ∈ Fin(r+1)} (φ(x, i) + φ(y, i))

for all x, y ∈ X. The minimal such r is the **tropical feature rank** of K.

Note: We use Fin(r+1) rather than Fin(r) for a rank-r kernel to ensure the index type is always nonempty.

### 2.3 Kernel Semimodule

**Definition 2.4 (Tropical Representation).** A function f : X → ℝ is **represented by** a nonempty set S ⊆ X with coefficients c : X → ℝ if

f(y) = max_{x ∈ S} (c(x) + K(x, y))

for all y ∈ X.

**Definition 2.5 (Kernel Span).** f is **in the kernel span** of K if there exist S and c such that f is represented by S with coefficients c. The kernel span is the **kernel semimodule** H_K.

### 2.4 Residuation

**Definition 2.6 (Residuated Coefficient).** The **residuated coefficient** of x for representing f via K_x is

res(K, f, x) = min_{y ∈ X} (f(y) - K(x, y))

This is the Galois adjoint of the tropical multiplication map c ↦ c ⊙ K_x = c + K(x, ·).

**Definition 2.7 (Active Support).** x is in the **active support** of f if there exists y such that res(K, f, x) + K(x, y) = f(y).

### 2.5 Domination and Antichains

**Definition 2.8 (Support Antichain).** A set T ⊆ X is a **support antichain** for f if for all distinct x, z ∈ T, there exists y ∈ X such that

res(K, f, x) + K(x, y) > res(K, f, z) + K(z, y)

That is, no element's residuated contribution is pointwise dominated by another's.

### 2.6 Generation and Minimal Support

**Definition 2.9 (Generation).** A nonempty set S **generates** the kernel semimodule if for every z ∈ X, there exist coefficients c such that K(z, y) ≤ max_{x ∈ S}(c(x) + K(x, y)) for all y.

**Definition 2.10 (Minimal Support Expansion).** S **minimally supports** f if (1) f(y) = max_{x ∈ S}(res(K, f, x) + K(x, y)) for all y, and (2) every x ∈ S is in the active support of f.

## 3. Main Results

### 3.1 Residuation Theory

**Theorem 3.1 (Residuated Lower Bound).** For all x, y ∈ X:
res(K, f, x) + K(x, y) ≤ f(y)

*Proof sketch.* By definition, res(K, f, x) = min_z(f(z) - K(x, z)) ≤ f(y) - K(x, y). □

**Theorem 3.2 (Residuation Optimality).** If c + K(x, y) ≤ f(y) for all y, then c ≤ res(K, f, x).

*Proof sketch.* c ≤ f(y) - K(x, y) for all y, so c ≤ min_y(f(y) - K(x, y)) = res(K, f, x). □

**Theorem 3.3 (Tightness).** For every x, there exists y such that res(K, f, x) + K(x, y) = f(y).

*Proof sketch.* The minimum in the definition of res is achieved on the finite set X. If y₀ achieves the minimum, then res(K, f, x) = f(y₀) - K(x, y₀), whence res(K, f, x) + K(x, y₀) = f(y₀). □

**Corollary 3.4 (Universal Active Support).** Every x ∈ X is in the active support of every f.

Theorems 3.1–3.2 establish that residuation is a Galois connection: res(K, f, ·) is the right adjoint to the map c ↦ c + K(·, ·).

### 3.2 Reconstruction Theory

**Theorem 3.5 (Prototype Lower Bound).** The tropical prototype predictor

pred(y) = max_{x ∈ S} (res(K, f, x) + K(x, y))

satisfies pred(y) ≤ f(y) for all y.

*Proof.* Immediate from Theorem 3.1 applied to each x ∈ S. □

**Theorem 3.6 (Exact Reconstruction).** If S minimally supports f, then pred(y) = f(y) for all y.

*Proof.* The equality is exactly the first condition of minimal support expansion. □

### 3.3 Antichain Structure

**Theorem 3.7 (Minimal Support is Antichain).** Suppose S minimally supports f and for each x ∈ S, there exists a witness y such that all other z ∈ S have res(K, f, z) + K(z, y) < f(y). Then S is a support antichain.

*Proof sketch.* Suppose for contradiction that x is pointwise dominated by z. Then at the witness y provided by the irredundancy hypothesis for x, we would need f(y) = max_{w ∈ S}(res(K, f, w) + K(w, y)). But every w ≠ x has a strict gap at y (by irredundancy), and x is dominated by z which also has a strict gap — so no element achieves f(y), contradicting the minimal support expansion equality. □

### 3.4 Feature Rank and Generation

**Theorem 3.8 (Universal Generation).** The full set X always generates the kernel semimodule.

*Proof.* For any z, use coefficients c = 0. Then max_{x ∈ X}(0 + K(x, y)) ≥ K(z, y) for all y. □

**Theorem 3.9 (Factored Kernels Have Bounded Rank).** If K(x, y) = max_{s ∈ S}(φ(x, s) + φ(y, s)) for some nonempty S and function φ, then K has tropical feature rank at most |S|.

*Proof sketch.* Construct a feature map ψ : X → ℝ^(|S|+1) by indexing the elements of S. The extra coordinate is filled with a value that doesn't affect the maximum. □

### 3.5 Self-Section Properties

**Theorem 3.10 (Self-Residuation).** If K(x, y) ≤ K(x, x) for all y (the diagonal dominance condition), then res(K, K_x, x) = 0.

*Proof.* res(K, K_x, x) = min_y(K(x, y) - K(x, y)) = min_y(0) = 0. □

This means that in a diagonally dominant kernel, each point represents itself with zero cost.

## 4. Algorithms

### 4.1 Residuated Coefficient Computation

```
Algorithm 1: ResidatedCoefficient(K, f, x)
Input: Kernel matrix K ∈ ℝ^(n×n), target f ∈ ℝ^n, index x ∈ {0,...,n-1}
Output: res(K, f, x) ∈ ℝ

1. c ← +∞
2. for y = 0 to n-1:
3.     c ← min(c, f[y] - K[x, y])
4. return c

Time: O(n)
Space: O(1)
```

### 4.2 Greedy Minimal Support Extraction

```
Algorithm 2: GreedyMinimalSupport(K, f, ε)
Input: Kernel matrix K, target f, tolerance ε > 0
Output: Minimal support set S

1. S ← {0, 1, ..., n-1}
2. c ← ResidatedCoefficients(K, f)  // O(n²)
3. for x = 0 to n-1:
4.     S' ← S \ {x}
5.     if S' ≠ ∅:
6.         pred ← TropicalReconstruct(K, c, S')
7.         if ||pred - f||_∞ < ε:
8.             S ← S'
9. return S

Time: O(n³) worst case, O(n² × |S_final|) typical
Space: O(n²)
```

### 4.3 Antichain Verification

```
Algorithm 3: VerifyAntichain(K, f, S)
Input: Kernel matrix K, target f, support set S
Output: Boolean

1. c ← ResidatedCoefficients(K, f)
2. for each x ∈ S:
3.     for each z ∈ S, z ≠ x:
4.         dominated ← true
5.         for y = 0 to n-1:
6.             if c[x] + K[x,y] > c[z] + K[z,y]:
7.                 dominated ← false
8.                 break
9.         if dominated: return false
10. return true

Time: O(|S|² × n)
Space: O(n)
```

### 4.4 Certified Decomposition

```
Algorithm 4: CertifiedDecomposition(K, f, ε)
Input: Kernel matrix K, target f, tolerance ε
Output: (S, c, minimal, antichain, error)

1. c ← ResidatedCoefficients(K, f)           // O(n²)
2. S ← GreedyMinimalSupport(K, f, ε)         // O(n³)
3. pred ← TropicalReconstruct(K, c, S)       // O(|S|n)
4. error ← ||pred - f||_∞
5. minimal ← VerifyMinimality(K, f, S, ε)    // O(|S|²n)
6. antichain ← VerifyAntichain(K, f, S)      // O(|S|²n)
7. return (S, c[S], minimal, antichain, error)

Total time: O(n³)
Total space: O(n²)
```

## 5. Examples

### 5.1 Rank-1 Kernel

Let X = {0, 1, 2, 3} with feature map φ(x) = [v(x)] where v = (1, 3, 2, 0.5). Then K(x, y) = v(x) + v(y).

All kernel sections are "parallel shifts": K_x(y) = v(x) + v(y). The residuated coefficient of z for K_x is min_y(v(x) + v(y) - v(z) - v(y)) = v(x) - v(z). The minimal support for K_x is {argmax_z v(z)} = {1} if x ≠ 1, or any singleton if x = 1. In our experiments, the greedy algorithm finds a single-point support.

### 5.2 Rank-2 Kernel

Let X = {A, B, C, D, E} with features:

| Point | φ₁ | φ₂ |
|-------|-----|-----|
| A     | 3.0 | 1.0 |
| B     | 1.0 | 4.0 |
| C     | 2.5 | 2.5 |
| D     | 0.0 | 3.0 |
| E     | 2.0 | 0.5 |

The kernel section K_A = (6, 5, 5.5, 4, 5). The minimal support is {D, E} with residuated coefficients res(K, K_A, D) = 0 and res(K, K_A, E) = 1. Point D contributes through Feature 2, and Point E through Feature 1. This is an antichain: neither dominates the other.

### 5.3 Random Rank-3 Kernel

For n = 6 with random rank-3 features, kernel sections typically have support sizes of 1–2, well below the feature rank of 3. The average support size across all sections is 1.3, confirming that the support bound is often not tight.

## 6. Formalization

All main results have been formally verified using Lean 4 with the Mathlib library. The formalization includes:

- 8 definitions (KernelSection, TropicalFeatureRankLE, IsRepresentedBy, InKernelSpan, ResiduatedCoefficient, IsActiveSupport, IsSupportAntichain, MinimalSupportExpansion, etc.)
- 12 theorems, all proved without sorry

The formalization totals approximately 260 lines of Lean code. Key proof techniques include:
- `Finset.inf'_le` and `Finset.le_inf'` for residuation bounds
- `Finset.exists_min_image` for tightness of the infimum
- `Finset.sup'_le` for tropical predictor bounds
- Contrapositive reasoning for the antichain theorem
- Type-theoretic embedding via `Fintype.equivOfCardEq` for the factorization theorem

## 7. Discussion

### 7.1 Relationship to Classical RKHS Theory

In classical RKHS theory, the Representer Theorem states that solutions to regularized ERM problems lie in the span of kernel sections at training points. Our results provide a *structure theorem* for the tropical analogue: not just that solutions are in the span, but that the span has a canonical decomposition into extremal components with unique minimal support.

The key differences are:
- **Classical**: Support depends on the optimization problem. **Tropical**: Support depends only on the algebraic structure.
- **Classical**: Support vectors arise from KKT conditions. **Tropical**: Support prototypes arise from residuation (Galois connection).
- **Classical**: Uniqueness requires strict complementarity. **Tropical**: Uniqueness is automatic from the lattice structure.

### 7.2 Computational Considerations

The O(n³) complexity of the greedy support extraction algorithm is competitive with classical kernel methods (SVM training is typically O(n² to n³)). The residuated coefficients can be computed in O(n²), which is optimal since reading the kernel matrix requires O(n²) time.

For large n, the bottleneck is the greedy backward elimination. A forward selection variant (starting with S = ∅ and adding elements) could be more efficient in practice, terminating when the reconstruction error falls below a threshold.

### 7.3 Limitations

1. **Finite setting**: Our results are for finite X. Extension to compact or infinite X would require tropical topological semimodule theory.

2. **Feature rank**: Computing the exact tropical feature rank is NP-hard in general (it reduces to tropical matrix factorization). Our algorithms estimate it rather than computing it exactly.

3. **Equality vs. inequality**: The generation definition uses inequality (K(z, y) ≤ max...) rather than equality. This means generation is a weaker condition than factorization, and the two notions of rank may differ.

## 8. Future Work

1. **Tropical Representer Theorem for ERM**: Extend to regularized empirical risk minimization in the tropical setting, showing that optimal predictors have sparse support.

2. **Infinite-dimensional tropical RKHS**: Develop a theory of reproducing kernel semimodules over compact spaces with tropical integrals.

3. **Tropical spectral theory**: Eigenvalue decomposition of tropical kernel matrices, connecting to tropical linear algebra and max-plus eigenvalues.

4. **Applications to neural network compression**: Apply prototype extraction to max-plus layers in deep networks, potentially reducing model size while preserving predictions.

5. **Tropical Gaussian processes**: Use tropical kernels for uncertainty quantification, replacing Gaussian expectations with tropical (max-plus) expectations.
