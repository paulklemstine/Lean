# Computational Evidence

## Small-case calculations

For a uniformly random one-bit memory, the two microstate probabilities are
`1/2, 1/2`. Its Shannon entropy is

| State distribution | Entropy |
|---|---:|
| `(1/2, 1/2)` | `log 2 ≈ 0.693147` |
| `(1, 0)` after erasure | `0` |
| Entropy lost | `log 2 ≈ 0.693147` |

Consequently the Landauer work scale is `k T log 2`, positive whenever `k > 0`
and `T > 0`. At normalized units `k = T = 1`, its value is approximately
`0.693147`, so the zero-work candidate is already excluded by the smallest case.

For the complexity transfer, finite toy classes exhibit the same closure pattern.
If every problem in a class reduces to a demon problem and the efficient class is
closed downward under those reductions, placing the demon in the efficient class
places every reduced problem there. This is structural rather than asymptotic, so
no larger numerical sample changes the conclusion.

## Sequence-database search

No integer sequence is generated by the conjectures. An OEIS search is therefore
not applicable. The numerical invariant used here is the single-bit entropy loss
`log 2`, not an integer sequence.

## Counterexample hunt

The unguarded claim “if P = NP, then a Maxwell demon violates the second law” fails
at the one-bit boundary. A complexity collapse can change whether a decision problem
has a polynomial-time algorithm, but it does not set the entropy loss of Boolean
erasure to zero. Under the finite Jarzynski condition, positive temperature forces
strictly positive mean work.

Boundary tests identify the needed guards:

| Boundary | Outcome |
|---|---|
| `k > 0`, `T > 0`, Jarzynski condition | Mean erasure work is strictly positive |
| `T = 0` | The strict `k T log 2` argument degenerates |
| Jarzynski condition omitted | No work lower bound follows from complexity alone |
| Reversible injective map | No logical erasure occurs; zero entropy loss is possible |

## Evidence-driven pivot

The original violation conjecture was replaced by a falsifiable separation theorem:
even if a collapse makes an NP demon polynomial-time, a finite implementation that
actually erases a bit and satisfies Jarzynski dynamics cannot have zero mean work.
The computational check motivates, but does not substitute for, the exact entropy
and work inequalities developed in the accompanying theory.
