# Computational evidence skipped

The core claims proved here are structural equivalences for arbitrary group actions, not a numerical conjecture or finite sequence. Small-case computation cannot validate the universal statements: the proofs reduce directly to invariance, injectivity, freeness, and nontriviality. A concrete finite instance using the regular action of the permutation group on five letters is included in Lean, so the representative example is kernel-checked rather than reported from an external calculation. No OEIS sequence, plot, or numerical table is relevant to these claims.
