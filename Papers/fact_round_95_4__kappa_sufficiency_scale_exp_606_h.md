# Computational Evidence — exp 606 KAPPA-SUFFICIENCY-SCALE formalisation

All numbers below were produced by `#eval` inside Lean 4 (exact `ℕ`/`ℚ` arithmetic, no
floating point except where marked), against the definitions that the theorems use.  They
are exploratory checks, not proofs; every claim they motivated is proved separately and
sorry-free in `Catalog/Novelty/Kappa*.lean`.

## 1. Small-case calculation: cell fibres over one period

Base `B = {2,3,5}`, period `M = ∏ p = 30`.  `cellFiber B S` is the set of `v < 30` whose
set of dividing base primes is exactly `S`.

| cell `S` | `|cellFiber|` | `∏_{p ∈ B∖S} (p−1)` |
|---|---|---|
| ∅ | 8 | 1·2·4 = 8 |
| {2} | 8 | 2·4 = 8 |
| {3} | 4 | 1·4 = 4 |
| {5} | 2 | 1·2 = 2 |
| {2,3} | 4 | 4 |
| {2,5} | 2 | 2 |
| {3,5} | 1 | 1 |
| {2,3,5} | 1 | 1 |
| **total** | **30 = M** | |

Exhaustive check for `B = {2,3,5,7}` (`M = 210`, all 16 cells):
`decide (∀ S ∈ B.powerset, (cellFiber B S).card = ∏ p ∈ B \ S, (p-1))` evaluates to `true`.

This is `KappaCellPeriod.card_cellFiber`, proved for arbitrary finite bases of distinct
primes, together with `sum_card_cellFiber` (the fibres partition the period) and
`cellFiber_density` (density = `∏_{p∈S} 1/p · ∏_{p∉S}(1−1/p)`, i.e. *exact* independence).

`∑_{v<30} κ(v) = 31 = 15 + 10 + 6 = 30/2 + 30/3 + 30/5`, so the mean is

## 3. The regression slope is exactly `−β` (scale stability)

Product cell measure on `B = {2,3,5}` with the arithmetic marginals `q p = 1/p`, weights
`w ≡ 0.35`, exact rationals:

| quantity | value |
|---|---|
| total mass `∑_S π(S)` | `1` |
| `E κ` | `31/30` |
| `Var κ` | `569/900` |
| `∑_p q p (1−q p)` | `569/900` (equal, as `variance_kappa` asserts) |
| OLS slope of `Λ` on `κ` | `−7/20 = −0.35` exactly |

No dependence on the base or on `D`: this is the model content of the reported
`C3_SCALE_CONFIRMED` verdict (`KappaSufficiencyScale.regression_slope_of_const`,
`arith_regression_slope`).

## 4. Counterexample hunt for the sufficiency claim

The empirical claim under test is "κ summarises everything rate-relevant".  In the additive
model this *fails as soon as two weights differ*, already at `κ = 1`:
`logRate D w {r} − logRate D w {p} = w p − w r` (`identity_gap_singletons`).  So no
counterexample search is needed for the qualitative direction — the dichotomy is proved
(`kappaSufficient_iff_constant_weights`).

For the *quantitative* side we searched for a formula for the increment.  With
`B = {2,3,5}`, `q p = 1/p`:

| weights `w` | residual variance | pairwise-energy formula |
|---|---|---|
| `(0.35, 0.35, 0.35)` | `0` | `0` |
| `(0.5, 0.35, 0.2)` | `1017/113800 ≈ 0.008937` | `1017/113800` |

The two columns agreed as exact rationals in every case tried, which is what the proved
identity `residualVariance_eq_pairEnergy` states:

```
residual = (½ ∑_{p,r} v p · v r · (w p − w r)²) / (∑_p v p),   v p = q p (1 − q p).
```

## 6. Is the "identity increment" really a residual variance?

Same configuration (`B = {2,3,5}`, `q p = 1/p`, `w = (0.5, 0.35, 0.2)`), fitting the line
`α + βκ` by least squares and forming `R = Λ − (α + βκ)`:

| quantity | value |
|---|---|
| `E R` | `0` |
| `Cov(R, κ)` | `0` |
| `Var R` | `1017/113800` |
| `Var Λ − Cov(Λ,κ)²/Var κ` | `1017/113800` |
| `Var Λ − (β² Var κ + Var R)` | `0` |

This is what `KappaOlsResidual.Emean_olsResidual`, `cov_olsResidual_kappa`,
`variance_olsResidual` and `variance_decomposition` prove in general.

## 7. Sequence check (OEIS)

The fibre-size table for a base of the first `k` primes is generated by
`∏_{p ∉ S}(p−1)`; summed over cells it reproduces the primorials `2, 6, 30, 210, …`
(OEIS A002110), and the `S = ∅` column reproduces `φ(primorial)` `= 1, 2, 8, 48, …`
(OEIS A005867).  Both are immediate corollaries of `card_cellFiber` / `sum_card_cellFiber`
rather than independent evidence.

## 8. What the evidence does *not* support

The reported slope value `β ≈ −0.35` itself is **not** derived here.  The theorems show
that *if* the per-prime penalty is a constant `β` then the measured slope is `−β` at every
scale — the observed cross-scale stability is exactly the signature of weight homogeneity —
but the numerical value of `β` (and any Dickman-type closed form for it) remains open; see
`FUTURE_DIRECTIONS.md`.
