# Computational evidence skipped

Computational evidence is unnecessary for the formal results delivered here. The main statements are symbolic identities and inequalities valid for every finite edge type and every finite family of candidate subgraphs: normalization, exact marginal probabilities, an exact overlap formula for the second moment, and a Cauchy–Schwarz/Paley–Zygmund bound. Exhaustive small-graph enumeration would only instantiate these already kernel-checked general theorems.

The phase-transition result is an analytic fixed-point theorem for the limiting Poisson exploration equation `ρ = 1 - exp(-λρ)`, rather than a finite numerical conjecture. Its subcritical uniqueness and supercritical existence are proved uniformly over real `λ`, so numerical plots would not strengthen or test the universal proof.
