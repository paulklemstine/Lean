# Computational Evidence

## Small-case calculations

The constructor tables give the following diagnostic sample.

| Expression | Result | Consequence |
|---|---:|---|
| `2 + 3` | `5` | finite addition is preserved |
| `2 · (-3)` | `-6` | finite multiplication is preserved |
| `+∞ + 4` | `+∞` | finite translation is absorbed at positive infinity |
| `+∞ + (-∞)` | `Φ` | incompatible additive directions create nullity |
| `0 · (+∞)` | `Φ` | the ring annihilation law fails |
| `(-2) · (+∞)` | `-∞` | multiplication records finite sign |
| `(+∞)⁻¹` | `0` | reciprocal totalizes infinity |
| `(-∞)⁻¹⁻¹` | `+∞` | a single unsigned zero loses the sign of infinity |

For finite values `x,y ∈ {-2,-1,0,1,2}`, table expansion agrees with real addition and multiplication in all 25 pairs for each operation.  Checking all exceptional constructor combinations identifies nullity products exactly when an input is already nullity or one input is finite zero and the other is a signed infinity.

## Sequence-database search

No integer sequence is generated by the structural claims, so an OEIS search is not applicable.  The relevant evidence is an exhaustive finite constructor table rather than asymptotic sequence data.  Likewise, no arithmetic variety or automorphic object arises, so an LMFDB search is not applicable.

## Counterexample hunt

Three ambitious global laws fail immediately:

1. Ring annihilation fails at `0 · (+∞) = Φ ≠ 0`.
2. Additive inverses fail at `+∞ + (-(+∞)) = Φ ≠ 0`.
3. Global reciprocal involution fails at `(-∞)⁻¹⁻¹ = +∞ ≠ -∞`.

Additive cancellation also fails without using nullity as an input: `+∞ + 0 = +∞ + 1`, although `0 ≠ 1`.

The evidence supports a guarded-transfer program: ordinary theorems survive while every intermediate value remains finite and every divisor remains nonzero.  It contradicts an unqualified claim that the four-constructor system is an involutive wheel.
