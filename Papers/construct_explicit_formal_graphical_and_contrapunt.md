# Computational Evidence

All computations below were run in Lean 4 (`#eval`, Mathlib v4.28.0) before the
corresponding statements were formalised in
`Catalog/Logic/GEBGradedLawvere.lean`.  Every claim they support is now a
`sorry`-free theorem in that file, so the numbers are corroboration, not the
final justification.

## 1. Size of the maximal representable family over `Fin n`

The obstruction spectrum theorem says a family `F ⊆ (B → B)` of semantic
endomorphisms is diagonally representable by one evaluation table iff every
`f ∈ F` has a fixed point.  Hence for `B = Fin n` the greatest representable
family has size `#{f : Fin n → Fin n | ∃ b, f b = b}`.

Brute-force enumeration over all `n^n` maps:

| `n` | brute force count | closed form `n^n - (n-1)^n` |
|-----|-------------------|------------------------------|
| 1   | 1                 | `1 - 0 = 1`                  |
| 2   | 3                 | `4 - 1 = 3`                  |
| 3   | 19                | `27 - 8 = 19`                |
| 4   | 175               | `256 - 81 = 175`             |
| 5   | (not enumerated)  | `3125 - 1024 = 2101`         |

The brute-force column was computed by filtering `Finset.univ : Finset (Fin n →
Fin n)` on `∃ b, f b = b`; it agrees with the closed form for all enumerated
`n`.  The closed form is proved in `card_maximal_representable_family` (the
fixed-point-free count `(n-1)^n` is `card_fixedPointFree`).

No OEIS lookup is claimed here; the closed form is proved directly.

## 2. Density of representable endomorphisms

Ratio `(n^n - (n-1)^n) / n^n` (floating point):

| `n` | 1 | 2 | 3 | 4 | 5 | 6 |
|-----|---|---|---|---|---|---|
| density | 1.000000 | 0.750000 | 0.703704 | 0.683594 | 0.672320 | 0.665102 |

Target value `1 - e⁻¹ = 0.632121...`.  The sequence decreases towards it
slowly, consistent with `((n-1)/n)^n ↑ e⁻¹`.  The limit is proved in
`representable_density_tendsto`.

## 3. Counterexample hunt: is representability monoid-controlled?

The previous cycle conjectured that maximal representable families are governed
by the transformation monoid generated by `F`.  Search over small permutation
families of `Fin 3`:

* `tA = (0 1)` acting as `0↦1, 1↦0, 2↦2` — fixed point `2` (`decide` = `true`).
* `tB = (1 2)` acting as `0↦0, 1↦2, 2↦1` — fixed point `0` (`decide` = `true`).
* `tA ∘ tB` acts as `0↦1, 1↦2, 2↦0` — a 3-cycle, no fixed point
  (`decide (∃ b, (tA ∘ tB) b = b)` = `false`).

Table of values (`b`, `tA b`, `tB b`, `(tA ∘ tB) b`):
`(0,1,0,1)`, `(1,0,2,2)`, `(2,2,1,0)`.

So `{tA, tB}` is representable while an element of the monoid it generates is
not: the conjecture is refuted.  Formalised as
`representability_not_closed_under_monoid`.

On `Bool` no such counterexample exists (the only fixed-point-free map is
negation, and it is not a composite of two maps with fixed points), which is
why the phenomenon is invisible at the Boolean level examined in cycle 0 —
three points are the minimum.

## 4. Vacuity check for full universality

For a domain `B` with `b₁ ≠ b₂`, the map `x ↦ if x = b₁ then b₂ else b₁` was
tested on `Fin 3`, `Fin 4`, `Bool`: always fixed-point-free.  This is the
uniform witness used to prove `universal_presentation_subsingleton`, which
shows that every earlier "universal presentation" hypothesis over a nontrivial
semantics is unsatisfiable.

## 5. Pitch-class model

With `Pitch = ZMod 12`: inversion `x ↦ -x` has fixed points `0` and `6`;
tritone inversion `x ↦ 6 - x` has fixed points `3` and `9`; transposition
`x ↦ x + 1` has none.  Diagonal values in the explicit formal/visual/musical
triad computed to `0` (inversion) and `3` (tritone inversion), confirming both
`geb_triad_common_value` and the code dependence exhibited by
`geb_triad_second_value`.
