# Why computational evidence was skipped

The central claim is a structural theorem quantified over arbitrary types, functions, complete lattices, and categories. Its proof is a symbolic diagonal argument: surjectivity supplies a code for the transformed diagonal, and evaluating that equality at its own code produces the fixed point. Finite numerical experiments cannot provide meaningful evidence for this universal implication.

Moreover, the Boolean consequence is an impossibility theorem valid for every state type, while the least-fixed-point result is inherited from complete-lattice structure. There is no naturally associated integer sequence, OEIS candidate, numerical plot, or representative finite sample that tests the actual hypotheses. Small finite examples would instead be systematically misleading: complete Boolean self-models cannot exist at any finite size (or any size), so no positive instances could be calculated.

For these reasons, direct kernel-checked formal proof is both more concise and more probative than an ad hoc computational stage for this mission.
