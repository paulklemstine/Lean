# Computational evidence

All numbers below were produced inside Lean 4 (Mathlib `v4.28.0`) with `#eval`, or checked by
`decide`; nothing was computed in an external scratch script.  The final statements themselves
are machine-checked theorems in `Physics/QuantumCayleyDeterminant.lean` and
`Physics/QuantumGroupDeterminant.lean` (no `sorry`, axioms `propext`, `Classical.choice`,
`Quot.sound` only).

## 1. Small cases of the objects

### `2 × 2` Cayley determinant

`cdet !![a, b; c, d] = a * d - c * b` (column-ordered products, order matters).  Formalised as
`QuantumDet.cdet_fin_two`.

For the `q`-version, `qcdet q !![a, b; c, d] = a * d - q⁻¹ • (c * b)`
(`QuantumDet.qcdet_fin_two`).  For a quantum matrix of `M_q(2)` (where `cb = bc`) this is
exactly the classical quantum determinant `det_q = ad - q⁻¹ bc`
(`QuantumGroup.qdet_eq_qCayley`).

### The crossing relation *is* `2 × 2` antisymmetry

Expanding both sides of `cdet !![b, a; d, c] = -cdet !![a, b; c, d]` gives

```
b*c - d*a = -(a*d - c*b)   ⟺   a*d - c*b = d*a - b*c,
```

which is literally the right-quantum crossing relation for `i<j`, `k<l` in the `2 × 2` case.
This observation is what suggested the general theorem `cdet_col_perm`, and the Lean proof is a
sign-reversing involution that reduces the `n × n` statement to exactly this identity.

## 2. Inversion statistics (`invCount`)

`#eval` of the distribution of `invCount` over `S_n` (number of permutations with `k`
inversions):

| `n` | distribution |
|-----|--------------|
| 2 | `[1, 1]` |
| 3 | `[1, 2, 2, 1]` |
| 4 | `[1, 3, 5, 6, 5, 3, 1]` |
| 5 | `[1, 4, 9, 15, 20, 22, 20, 15, 9, 4, 1]` |

These are the **Mahonian numbers**, OEIS **A008302** (triangle of numbers of permutations of
`n` letters with `k` inversions; rows `1`; `1,1`; `1,2,2,1`; `1,3,5,6,5,3,1`; ...).  Their
generating function is the `q`-factorial `[n]_q! = ∏_{i=1}^n (1 + q + ⋯ + q^{i-1})`, which is
precisely the total weight appearing in the `q`-Cayley determinant.

Brute-force check (closed by `decide`, i.e. kernel-verified):

```lean
example : ∀ σ : Equiv.Perm (Fin 4), (Equiv.Perm.sign σ : ℤ) = (-1) ^ invCount σ := by decide
```

The general statement is the theorem `QuantumDet.sign_eq_neg_one_pow_invCount`, proved by
strong induction on the number of inversions.

## 3. Counterexample hunt: is the right-quantum hypothesis needed?

Yes — and the counterexample is verified in Lean (end of
`Physics/QuantumCayleyDeterminant.lean`).  Work in the noncommutative ring
`R = M₂(ℚ)` and set

```
E = !![0,1;0,0],  F = !![0,0;1,0],   E*F = !![1,0;0,0] ≠ !![0,0;0,1] = F*E.
```

For `A = !![E, 0; 0, F]` (a matrix over `R`):

* `A` is **not** right-quantum: the crossing relation would say `E*F = F*E`;
* `cdet A = E*F`, while the column-swapped matrix `!![0, E; F, 0]` has Cayley determinant
  `-F*E`.  Since `E*F ≠ F*E`, the antisymmetry `cdet(A∘τ) = sgn τ • cdet A` **fails**.

So `cdet_col_perm` is not vacuous window dressing: dropping the quantum relations destroys the
conclusion.

Conversely, right-quantum matrices with genuinely noncommuting entries do exist: for any ring
and any `x, y`, the matrix `!![x, y; 1, 1]` is right-quantum
(`QuantumDet.isRightQuantum_of_row_ones`), with `cdet = x - y`, and the column swap indeed
gives `y - x`.  Taking `x = E`, `y = F` above makes the entries noncommuting.

## 4. `q`-deformation: determining the swap factor

Requiring that the pairing `{σ, σ·s}` cancel in
`qcdet(A with columns t, t+1 swapped) = λ • qcdet A` forces, for `i = σ(t)`, `j = σ(t+1)`,

```
A_{i,l} A_{j,k} - λ A_{i,k} A_{j,l} + λ A_{j,l} A_{i,k} - λ² A_{j,k} A_{i,l} = 0,
```

and the `q`-right-quantum relation
`A_{i,k}A_{j,l} - q⁻¹ A_{j,k}A_{i,l} = A_{j,l}A_{i,k} - q A_{i,l}A_{j,k}`
makes this vanish exactly when `λ = -q⁻¹`.  A hand check on `M_q(2)` confirms it:

```
qcdet !![b,a;d,c] = b*c - q⁻¹ d*a = q⁻² b*c - q⁻¹ a*d = -q⁻¹ (a*d - q⁻¹ b*c),
```

using `da = ad - (q⁻¹ - q) bc` and `cb = bc`.  The general theorem is
`QuantumDet.qcdet_swap_adjacent_cols`, and the `2 × 2` instance is
`QuantumDet.qcdet_swap_cols_fin_two`.

## 5. Centrality of the quantum determinant

The four commutation checks `det_q · x = x · det_q` for `x ∈ {a,b,c,d}` were first done by hand
(each is a three-line rewriting using the `M_q(2)` relations and `q⁻¹ q² = q`) and are now the
theorems `QuantumGroup.qdet_comm_a/b/c/d`, with the closure statement
`QuantumGroup.qdet_mem_centralizer` covering the whole subring generated by the entries.
