# Skip Evidence Justification

A separate exploratory computation stage was unnecessary for this result. The finite model admits an exact proof for every `n`: `surprise j` equals the ordinal coordinate of `j`, the terminal resolution is `Fin.last n`, and its surprise is exactly `n`. These statements, including the 100-resolution specialization, are checked directly in `Pythagorean/UniversalHumor.lean`.

There is no nontrivial integer sequence to identify in OEIS (the maximal values are simply `0, 1, 2, ...`), and finite sampling would provide weaker evidence than the general theorem. No empirical human-rating dataset was supplied, so inventing a correlation table would be inappropriate.
