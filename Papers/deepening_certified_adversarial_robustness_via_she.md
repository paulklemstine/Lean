# Computational Evidence

All computations below were run inside Lean 4 (mathlib4, `v4.28.0`) with exact
rational arithmetic (`ℚ`), against the definitions of
`Catalog/MachineLearning/SheafCohomologyRobustness/`.  They were used to *test*
the conjectures before formalising them; the theorems in the `.lean` files are
the verified statements, these numbers are only supporting evidence.

Reproduction script (run with the catalog modules on the Lean path):

```lean
import Mathlib
import MachineLearning.SheafCohomologyRobustness.CyclicHolonomy
import MachineLearning.SheafCohomologyRobustness.TorusNerve
open SheafCohomologyRobustness

def dcyc {n : ℕ} (f : Fin (n+1) → ℚ) : Fin (n+1) → ℚ := fun i => f (i+1) - f i

-- E1
#eval (List.range 6).map (fun k =>
  let f : Fin (k+1) → ℚ := fun i => (i.val : ℚ)^2 - 3*(i.val : ℚ)
  (Finset.univ.sum (fun i : Fin (k+1) => dcyc f i)))

-- E2
def g5 : Fin 5 → ℚ := ![2, -3, 4, 1, -4]
def P5 (k : ℕ) : ℚ := (Finset.univ.filter (fun j : Fin 5 => j.val < k)).sum g5
#eval Finset.univ.sum g5
#eval (List.finRange 5).map (fun i => (dcyc (fun k : Fin 5 => P5 k.val) i, g5 i))

-- E3
def h5 : Fin 5 → ℚ := ![2, -3, 4, 1, 1]
def hbar : Fin 5 → ℚ := fun i => h5 i - 1
def Q5 (k : ℕ) : ℚ := (Finset.univ.filter (fun j : Fin 5 => j.val < k)).sum hbar
#eval Finset.univ.sum h5
#eval (List.finRange 5).map (fun i => dcyc (fun k : Fin 5 => Q5 k.val) i - h5 i)

-- E4 (brute force over 13^4 = 28 561 integer potentials with f 0 = 0)
def sup5 (u : Fin 5 → ℚ) : ℚ := (List.finRange 5).foldl (fun acc i => max acc |u i|) 0
#eval
  let vals : List ℚ := (List.range 13).map (fun t => ((t : ℚ) - 6))
  let cands : List (Fin 5 → ℚ) :=
    (vals.flatMap (fun a => vals.flatMap (fun b => vals.flatMap (fun c => vals.map (fun d =>
      (![0, a, b, c, d] : Fin 5 → ℚ))))))
  cands.foldl (fun best f => min best (sup5 (fun i => dcyc f i - h5 i))) 100

-- E5 (3 × 3 torus nerve)
def hT : Fin 3 × Fin 3 → ℚ := fun _ => 1/3
def vT : Fin 3 × Fin 3 → ℚ := fun _ => 0
#eval (List.finRange 3).map (fun b => (Finset.univ.sum (fun a : Fin 3 => hT (a,b))))
#eval (List.finRange 3).map (fun a => (Finset.univ.sum (fun b : Fin 3 => vT (a,b))))
#eval (List.finRange 3).flatMap (fun a => (List.finRange 3).map (fun b =>
  hT (a,b) + vT (a+1,b) - vT (a,b) - hT (a,b+1)))
```

## E1 — Holonomy of a coboundary vanishes on the loop nerve

For `f i = i² − 3i` on loops of `n+1 = 1, …, 6` regions:

| n+1        | 1 | 2 | 3 | 4 | 5 | 6 |
|------------|---|---|---|---|---|---|
| `∑ᵢ (δf)ᵢ` | 0 | 0 | 0 | 0 | 0 | 0 |

Consistent with `deltaCyc_sum_zero` (proved).

## E2 — Zero holonomy ⟹ the discrete primitive is a genuine potential

`g = (2, −3, 4, 1, −4)` on a loop of 5 regions has `∑ g = 0`, and the primitive
`P(k) = ∑_{j<k} gⱼ` satisfies, at every overlap (computed `(δP)ᵢ`, target `gᵢ`):

| i | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| `(δP)ᵢ` | 2 | −3 | 4 | 1 | −4 |
| `gᵢ`    | 2 | −3 | 4 | 1 | −4 |

The wrap-around overlap `i = 4` is reproduced correctly — the case that consumes
the hypothesis `∑ g = 0`.  Formalised as `deltaCyc_of_sum_zero`.

## E3/E4 — The defect `|holonomy| / (n+1)` is exact

`h = (2, −3, 4, 1, 1)` has holonomy `∑ h = 5` on a loop of `5` regions, so the
predicted minimal uniform mismatch is `5/5 = 1`.

* E3: the mean-subtracted primitive achieves mismatch exactly `−1` at *every*
  overlap: `(−1, −1, −1, −1, −1)`.  Uniform error `1`.
* E4 (counterexample hunt): brute-force search over all `13⁴ = 28 561` potentials
  with integer entries in `[−6, 6]` and `f 0 = 0` returns minimum uniform error
  `1`.  **No potential beats `|holonomy|/(n+1)`** in this sample, matching the
  proved lower bound `cyclic_defect_lower_bound` and the attainment result
  `cyclic_defect_attained`.

## E5 — Torus nerve: a flat cochain with holonomy `(1, 0)`

On the `3 × 3` torus nerve, `h ≡ 1/3`, `v ≡ 0`:

* row holonomies `(1, 1, 1)` — constant in the row index, as predicted by
  `rowHol_const`;
* column holonomies `(0, 0, 0)` — `colHol_const`;
* all nine plaquette sums equal `0`, so the cochain is flat.

Since the row holonomy is nonzero, `torus_isCoboundary_iff` says it is not a
coboundary; together with the analogous cochain of holonomy `(0, 1)` this
exhibits the two independent classes counted by `finrank_torusH1 = 2`.
