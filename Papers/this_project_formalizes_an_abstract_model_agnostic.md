# Computational Evidence — Weighted min-plus multiverse quantifiers

We test the central claims of `WeightedBridge.lean` on the concrete
three-universe multiverse `{L, cohen, meas}` with Continuum-Hypothesis truth
`CHb = (L ↦ true, cohen ↦ false, meas ↦ true)` and forcing costs
`fcost = (L ↦ 0, cohen ↦ 1, meas ↦ 5)`.

## 1. Small-case calculations

Per-universe min-plus cost of CH, `wcost CH fcost`:

| universe | CH holds? | cost `c` | `wcost` value |
|----------|-----------|----------|---------------|
| L        | yes       | 0        | `0`           |
| cohen    | no        | 1        | `⊤`           |
| meas     | yes       | 5        | `5`           |

* **Cheapest witness (tropical sum = `inf`):** `min(0, ⊤, 5) = 0`, attained at
  `L`. Matches `ch_cheapest_cost`.
* **Aggregate cost (tropical product = `sum`):** `0 + ⊤ + 5 = ⊤`, i.e. infinite,
  so CH is *not* multiverse-true. Matches `necessary_iff_finite` /
  `ch_not_necessary`.

For the negation `¬CH` (holds only in `cohen`, cost 1): cheapest witness cost is
`min(⊤, 1, ⊤) = 1`. Both CH and ¬CH are possible, with distinct witness costs
`0` vs `1` — a quantitative refinement of plain independence.

## 2. Monotonicity spot-check

Lower `meas`'s cost from `5` to `-3`. New `wcost` values `(0, ⊤, -3)`, cheapest
`min(0, ⊤, -3) = -3 ≤ 0`. Consistent with `cheapest_mono` (lowering any cost can
only lower the cheapest witness cost).

## 3. Degenerate zero-cost slice

Setting all costs to `0`, `wcost` becomes `(0, ⊤, 0)` and the tropical value at
each universe equals `boolToTropR (CHb u)` (`1` for true, `0 = trop ⊤` for
false). The cheapest cost is `0` (finite) iff CH is possible, recovering the
purely Boolean bridge. Matches `wval_zero_cost` and `possible_iff_finite`.

## 4. Counterexample hunt

The attainment claim `cheapest_witness` was stress-tested against the empty-witness
case: if CH held nowhere, `min` over an all-`⊤` family is `⊤`, so no real witness
exists — which is exactly why the theorem is guarded by a possibility hypothesis
(`possible_iff_finite` characterises this boundary). No counterexample to the
guarded statements was found; all finite cases evaluate as the theorems predict.

## 5. Sequence note

No integer sequence is generated by this construction (values are real forcing
costs), so no OEIS entry applies.
