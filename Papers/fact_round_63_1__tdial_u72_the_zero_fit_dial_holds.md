## 2. Gram-feasibility budget `Σᵢ ρᵢ² ≤ 1`

For `k` mutually decorrelated statistics reading `ρ` against one response the budget is
`k·ρ² ≤ 1`:

```
2 * 0.605²  = 0.732050   ≤ 1   ← count parity at bitlen 72 is feasible
3 * 0.605²  = 1.098075   > 1   ← a third decorrelated baseline is impossible
2 * 0.78²   = 1.216800   > 1   ← parity at bitlen 44 is impossible
```

Thresholds: `1/√2 = 0.707107`, `1/√3 = 0.577350`.  So the recorded readings fall into
capacity classes: `0.78` → capacity 1, `0.605` → capacity 2 (since
`0.577350 < 0.605 ≤ 0.707107`).  These three inequalities are exactly the content of
`u72_capacity_two`, `dial44_capacity_one` and `capacity_window`.

## 3. Forcing hunt: `c ≥ ab − √((1−a²)(1−b²))`

Lower bound forced on the mutual correlation `c` of the two statistics by a pair of
readings `(a, b)`:

```
(0.78 , 0.71 )  ->  +0.113125     (bitlen 44 regime: correlation FORCED)
(0.705, 0.635)  ->  -0.100196     (bitlen 52: vacuous)
(0.605, 0.555)  ->  -0.326565     (bitlen 72 with count parity: vacuous)
(0.608, 0.535)  ->  -0.345479     (bitlen 76 report: vacuous)
```

This is a *counterexample hunt* against the naive hypothesis "a high dial reading plus a
high baseline reading is always possible": it fails only above the threshold.  The
transition happens exactly where `2ρ² = 1`.

## 4. Where does the dial cross the threshold?

Linear interpolation of the reported decline `0.78` (bitlen 44) → `0.605` (bitlen 72):

```
44 + 28*(0.78 - 1/√2)/(0.78 - 0.605) = 55.66
```

so the predicted crossing is near **bitlen 56**, i.e. between the bitlen-52 measurement
(advantage `+0.070`, reading `0.705 ≈ 1/√2`) and the bitlen-64 measurement
(`0.648 < 1/√2`).  This is a falsifiable prediction of the parity mechanism: the count
advantage should decay in exactly that window, which is where the reported advantage moves
from `+0.070` to below `+0.05`.

## 5. Tie geometry is not the binding constraint

The dyadic (2-adic) tie ceiling of the earlier catalog cycles is `6/7 = 0.857143`, i.e.
`ρ ≤ 0.925820`.  Both recorded readings are far below it, and the ceiling is essentially
constant in the bitlen (`Novelty.ZeroFitDialU76.dial_flat_72_76`).  The Gram/parity
threshold `0.707107` is *below* the tie ceiling and, unlike it, separates the recorded
readings.  This is why the new file works with three-variable geometry rather than tie
profiles.
