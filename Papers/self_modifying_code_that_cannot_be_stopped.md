# Computational Evidence Justification

Finite computation is not an informative test of the central claims. Undecidability, non-enumerability, and mutual reducibility quantify over all program codes or all execution lengths; every finite sample is compatible both with the theorem and with its negation outside the sample. The strict-hardness claim is instead settled structurally by an exact step-for-step simulation that stores mutable code in ordinary state. For these reasons, finite tables, plots, and sequence searches would add no probative evidence and were omitted.
