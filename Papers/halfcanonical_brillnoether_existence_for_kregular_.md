Computational evidence was not used because the current project develops adjacency-multiplicity divisor theory but does not yet provide an enumerator for divisor classes, reduced divisors, or Baker–Norine rank on arbitrary finite regular graphs. A small-case table produced by an unrelated external implementation would not directly validate the definitions used here. The investigation therefore concentrates on exact symbolic consequences: the regular-graph genus formula, the closed Brill–Noether expression, an explicit sufficient numerical threshold, and residual-rank symmetry. A future evidence cycle should first add a certified finite rank algorithm and then enumerate connected regular graphs and divisor classes with the same definitions.
