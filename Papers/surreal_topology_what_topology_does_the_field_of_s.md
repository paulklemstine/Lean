# Computational Evidence: Topology of the Surreal Numbers

## The question and the honest answer

The mission conjectures that the *interval topology* (= order topology, generated by the open
intervals `(a,b)`) makes the surreal field `No` **connected** and **contractible**.

Direct computation of the argument shows the opposite: the interval topology on `No` is
**disconnected**. The formal statement is `Surreal.not_preconnectedSpace` in
`SurrealTopology.lean`.

## 1. Small-case / structural calculation

The order topology of a linear order `X` is connected **iff** `X` is a *linear continuum*:
densely ordered **and** Dedekind complete (no gaps). We check the two standard reference orders and
then `No`:

| order | densely ordered? | Dedekind complete (as a whole)? | order topology connected? |
|-------|------------------|---------------------------------|---------------------------|
| `ℤ`   | no               | —                               | no (discrete)             |
| `ℚ`   | yes              | no (gap at √2)                  | **no** (totally disc.)    |
| `ℝ`   | yes              | yes                             | yes (connected)           |
| `No`  | yes              | **no** — has proper-class gaps  | **no** (this file)        |

`No` behaves like `ℚ`, not like `ℝ`: it is densely ordered but riddled with gaps, so its order
topology is disconnected.

## 2. The explicit gap used in the proof

The cleanest gap is the **Archimedean gap**. Consider

```
Finite surreals  F = { x | ∃ n : ℕ, x < n }        (everything below some integer)
Infinite surreals  Fᶜ = { x | ∀ n : ℕ, n ≤ x }     (everything above every integer)
```

* `F` is open: `F = ⋃ n, Iio n`, a union of open rays.
* `Fᶜ` is open: if `x` is infinite then the whole ray `(x-1, ∞)` is infinite, because
  `y > x-1 ≥ n` for every `n`.
* `F` is nonempty (`0 ∈ F`) and `F ≠ No` (any surreal `> ω` lies in `Fᶜ`).

So `F` is a nontrivial clopen set, and `No` is disconnected.

## 3. Why the gap exists: the non-Archimedean check

The single fact powering the split is that **`No` is non-Archimedean**: there is a surreal larger
than every natural number (e.g. `ω`). We obtain this *computationally* from the set-theoretic size
bound `Surreal.bddAbove_range_of_small`: the family `n ↦ (n : No)` is indexed by the small type `ℕ`,
hence has a surreal upper bound `M`, and `M + 1` exceeds every natural. First terms of the family:
`0, 1, 2, 3, …`; upper bound: any infinite surreal such as `ω`.

## 4. Counterexample hunt against the conjecture

* **"Connected"** — refuted: the clopen set `F` above.
* **"Contractible" / "path-connected"** — refuted a fortiori: a path-connected (in particular
  contractible) space is connected, and `No` is not. Formalized as
  `Surreal.not_pathConnectedSpace`.
* **"Hausdorff"** — *confirmed* (as a positive counterpoint): the order topology on a linear order
  is always `T2`. Formalized as `Surreal.instT2Space`.

## 5. OEIS

No integer sequence is central to the theorem, so no OEIS entry applies. (The birthday/sign-sequence
combinatorics of surreals are a separate matter not needed here.)

## Conclusion

The computational/structural evidence uniformly points to disconnectedness, matching the general
"linear continuum" criterion. The formal proof in `SurrealTopology.lean` confirms it and refutes the
connected/contractible conjecture, while keeping the true positive fact (Hausdorffness).
