# Computational evidence

## Small cases

The companion `ComputationalEvidence.lean` checks a parity-observing two-state machine on four histories:

| input history | output |
|---|---:|
| `[]` | `false` |
| `[true]` | `true` |
| `[true, true]` | `false` |
| `[true, false, true]` | `false` |

It also proves that a one-state silent machine and a physically different two-state machine with constant-false observations are behaviorally equivalent.

## OEIS search

No integer sequence is naturally generated by the theorem, so an OEIS search is not applicable.

## Counterexample hunt

The universal claim that the parity machine is equivalent to the silent machine is refuted by the explicit history `[true]`. The contradiction is kernel-checked in `parity_not_silent`.

The positive claim that the redundant silent machine is equivalent to the one-state silent machine was tested universally and proved for every finite input history in `redundant_silent_equiv`.
