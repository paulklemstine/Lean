# Vector-Valued EML Stone–Weierstrass: From Scalar Density to Multiclass Universality

## Abstract

We formalize in Lean 4 the canonical finite-dimensional upgrade of the scalar Stone–Weierstrass theorem for EML (Exponential-Max-Linear) function classes. Starting from the established fact that a point-separating subalgebra of C(X, ℝ) is dense in the uniform topology on compact Hausdorff spaces, we prove that the coordinatewise vector class VecClass(A, m) is dense in C(X, Fin m → ℝ). We further introduce a coupled-output class CoupledVecClass(A, m) — capturing shared-feature architectures with continuous readout — and prove it is also dense. The development includes a retraction-based theorem for constrained-target approximation and a softmax-based specialization for simplex-valued outputs. All proofs are machine-verified in Lean 4 with Mathlib, with no sorry statements or non-standard axioms. The formal development totals approximately 370 lines of Lean code, proving 15 theorems and establishing 7 key definitions.

## 1. Introduction

The Stone–Weierstrass theorem is one of the foundational results of functional analysis, guaranteeing that suitably rich function classes are dense in the space of continuous functions on compact spaces. In the context of machine learning, this theorem provides the mathematical foundation for *universal approximation*: the guarantee that neural network architectures can approximate arbitrary continuous functions to any desired accuracy.

The Exponential-Max-Linear (EML) program builds function classes from exponential generators exp(w·Φ(x) + b) and logistic generators σ(w·Φ(x) + b), where Φ : Fin n → C(X, ℝ) is a point-separating family of continuous features. The scalar Stone–Weierstrass theorem — that the subalgebra generated by these functions is dense in C(X, ℝ) — has been formalized in prior work.

However, real-world applications rarely involve scalar outputs:
- **Multiclass classification** requires probability vectors in the simplex Δ^(m-1)
- **Control systems** produce multi-dimensional action vectors
- **Generative models** output high-dimensional structured predictions

This paper addresses the natural question: *Does scalar density automatically propagate to vector-valued outputs?*

The answer is affirmative, and the proof is surprisingly clean. The key insight is that the sup norm on finite products Fin m → ℝ makes coordinatewise approximation optimal: if each coordinate can be approximated within ε, the vector approximation error is also at most ε.

## 2. Mathematical Framework

### 2.1 Setting

We work with a compact Hausdorff topological space X and the Banach space C(X, ℝ) of continuous real-valued functions equipped with the uniform norm ‖f‖ = sup_x |f(x)|. For vector-valued maps, C(X, Fin m → ℝ) carries the norm ‖F‖ = sup_x ‖F(x)‖ where ‖v‖ = sup_i |v_i| is the sup norm on Fin m → ℝ.

### 2.2 Core Definitions

**Definition 1** (Coordinate projection). For each i : Fin m, the coordinate projection is

    coordMap(m, i) : C(Fin m → ℝ, ℝ) := ⟨fun x ↦ x i, continuous_apply i⟩

**Definition 2** (Coordinatewise vector class). Given a set A ⊆ C(X, ℝ), the coordinatewise vector class is

    VecClass(A, m) := {F : C(X, Fin m → ℝ) | ∀ i, coordMap(m,i) ∘ F ∈ A}

**Definition 3** (Coupled vector class). The coupled-output class captures shared-feature architectures:

    CoupledVecClass(A, m) := {F | ∃ k, ∃ g : Fin k → C(X, ℝ),
        (∀ j, g j ∈ A) ∧ ∃ φ : C(Fin k → ℝ, Fin m → ℝ), F = φ ∘ assemble(g)}

where assemble(g)(x)(j) := g(j)(x).

**Definition 4** (Softmax map). For m > 0, the softmax map is

    softmaxMap(m)(y)(i) := exp(y_i) / Σ_j exp(y_j)

## 3. Main Results

### 3.1 Coordinatewise Density (First Main Theorem)

**Theorem 1** (closure_vecClass_eq_univ_of_scalar). *If every f ∈ C(X, ℝ) lies in the closure of A, then every F ∈ C(X, Fin m → ℝ) lies in the closure of VecClass(A, m).*

*Proof sketch.* Given F and ε > 0, for each coordinate i : Fin m, extract g_i ∈ A with ‖coordMap(i) ∘ F - g_i‖ < ε using scalar density. Assemble G = assembleVec(g) ∈ VecClass(A, m). Since the norm on Fin m → ℝ is the sup norm, ‖F - G‖ = sup_x sup_i |F(x)(i) - G(x)(i)| ≤ ε. □

The proof uses two key lemmas:

**Lemma** (norm_pi_le_of_coord_bound). *If |v_i| ≤ δ for all i, then ‖v‖ ≤ δ.*

**Lemma** (norm_sub_continuousMap_le_of_coord_bound). *If |F(x)(i) - G(x)(i)| ≤ δ for all x, i, then ‖F - G‖ ≤ δ.*

### 3.2 Coupled Class Density (Second Main Theorem)

**Theorem 2** (dense_coupledVecClass_of_dense_scalar). *Under the same scalar density hypothesis, every F ∈ C(X, Fin m → ℝ) lies in the closure of CoupledVecClass(A, m).*

The proof factors through an inclusion lemma:

**Lemma** (vecClass_subset_coupledVecClass). *VecClass(A, m) ⊆ CoupledVecClass(A, m).*

*Proof.* Given F ∈ VecClass(A, m), take k = m, let g_j = coordMap(j) ∘ F ∈ A for each j, and let φ = id. Then F = id ∘ assemble(g). □

Density then follows from monotonicity of closure: closure(VecClass) ⊆ closure(CoupledVecClass).

### 3.3 Closure Under Postcomposition

**Theorem 3** (comp_mem_coupledVecClass). *If F ∈ CoupledVecClass(A, m) and ψ : C(Fin m → ℝ, Fin p → ℝ), then ψ ∘ F ∈ CoupledVecClass(A, p).*

*Proof.* If F = φ ∘ assemble(g), then ψ ∘ F = (ψ ∘ φ) ∘ assemble(g). □

### 3.4 Retraction-Based Constrained Approximation (Third Main Theorem)

**Theorem 4** (dense_into_compactRange_of_retraction). *Let r : C(Fin m → ℝ, Fin m → ℝ) be a continuous retraction onto K (i.e., r|_K = id and range(r) ⊆ K). If F : C(X, Fin m → ℝ) maps into K, then for every ε > 0 there exists G ∈ CoupledVecClass(A, m) with G mapping into K and dist(F, G) < ε.*

*Proof.* Since r ∘ F = F, and the map H ↦ r ∘ H is continuous on C(X, Fin m → ℝ), for δ > 0 small enough: ‖H - F‖ < δ implies ‖r ∘ H - r ∘ F‖ < ε. Take H ∈ VecClass close to F, then G = r ∘ H ∈ CoupledVecClass maps into K and satisfies ‖G - F‖ < ε. □

### 3.5 Softmax and Simplex Outputs (Fourth Main Theorem)

**Theorem 5** (softmaxMap_mem_stdSimplex). *For m > 0, the softmax map sends any vector into the standard simplex.*

**Theorem 6** (approx_simplex_interior). *If F : C(X, Fin m → ℝ) maps into the interior of the simplex (all coordinates strictly positive), then F lies in the closure of {softmaxMap ∘ H | H ∈ CoupledVecClass(A, m)}.*

*Proof.* Define logit coordinates z(x)(i) = log(F(x)(i)). Since F maps into the simplex interior, z is well-defined and continuous. The key identity: softmax(log(F(x))) = F(x) when Σ_i F(x)(i) = 1 and F(x)(i) > 0. Approximate z by H ∈ CoupledVecClass using Theorem 2. Since softmax is continuous, softmax ∘ H converges to softmax ∘ z = F. □

### 3.6 EML Specialization

**Theorem 7** (eml_vec_stoneWeierstrass). *For X compact Hausdorff with a point-separating family Φ : Fin n → C(X, ℝ) with n ≥ 1, the closure of VecClass(EMLScalarClass(Φ), m) equals Set.univ.*

This follows immediately from the scalar EML Stone–Weierstrass theorem (which gives density of the EML subalgebra) and Theorem 1.

## 4. Formalization Details

The complete Lean 4 formalization resides in `EML/VectorStoneWeierstrass.lean` (approximately 370 lines). Key aspects:

- **No axioms beyond Lean's kernel**: all theorems depend only on `propext`, `Classical.choice`, and `Quot.sound`.
- **Clean type-theoretic structure**: the coordinatewise vector class is defined using `ContinuousMap.comp`, avoiding coercion pitfalls.
- **Sup norm**: The proof critically relies on the fact that `Fin m → ℝ` carries the sup norm (via `Pi.norm_def`), making coordinatewise ε-approximation sufficient for vector ε-approximation.
- **Metric characterization**: Closure membership is established via `Metric.mem_closure_iff`, converting to ε-approximation form.
- **Continuous postcomposition**: The retraction and softmax arguments use `continuous_postcomp` to show that H ↦ r ∘ H (or softmax ∘ H) is continuous on the space of continuous maps.

## 5. Applications

### 5.1 Multiclass Classification
The simplex-valued approximation theorem (Theorem 6) directly applies to multiclass prediction: any continuous class-probability function F : X → Δ^(m-1) with strictly positive class probabilities can be approximated by softmax ∘ (EML features). This is exactly the architecture used in practice: shared feature layers feeding into a softmax readout.

### 5.2 Constrained Control
The retraction theorem (Theorem 4) applies to control problems with compact action sets K ⊆ ℝ^m. If the action set admits a continuous retraction (e.g., convex compact sets always do, via metric projection), then EML controllers can approximate any continuous policy mapping into K.

### 5.3 Shared-Latent Architectures
The coupled class density (Theorem 2) formally validates the architectural choice of sharing latent features across output dimensions — the standard design in modern neural networks. The theorem shows no approximation power is lost by sharing, compared to independent coordinatewise networks.

### 5.4 Robustness Transfer
The coordinatewise error bound (Lemma norm_sub_continuousMap_le_of_coord_bound) shows that robustness guarantees transfer from scalar to vector: if each scalar coordinate has a certified perturbation bound, the vector output inherits the same bound.

## 6. Discussion: Making the Abstract Concrete

*For a broader audience.*

Imagine you have a weather forecasting model that needs to output not just temperature, but temperature, humidity, and wind speed simultaneously — a three-dimensional prediction at each point in space. The classical Stone–Weierstrass theorem guarantees that sufficiently expressive function classes can approximate any single-output prediction (like temperature alone). But can the same type of model handle all three outputs at once?

Our theorem answers: **yes, and automatically**. The key insight is almost surprisingly simple: if you can approximate each output separately, you can approximate all outputs together, with no loss in accuracy. This works because the "distance" between two multi-output predictions is measured by the worst-case error across all outputs — so controlling each output individually gives you control over the whole vector.

This might seem obvious, but the formal proof reveals subtle structure. The theorem doesn't just say "do each coordinate independently." It also shows that **shared-feature architectures** — where one set of internal computations feeds multiple outputs through a continuous readout — are equally powerful. This validates the standard neural network design of shared hidden layers with multiple output heads.

An important practical extension handles constrained outputs. In many applications, the output must satisfy constraints: probabilities must sum to 1, control actions must stay within safe bounds, and robot joint angles have physical limits. Our retraction theorem shows that any continuous "repair map" that projects outputs back into the valid region preserves approximation power. For probability outputs specifically, the softmax function serves as this repair map — and our theorem proves that softmax-composed EML networks can approximate any smooth probability distribution over classes.

The historical parallel is instructive. Stone's 1948 generalization of Weierstrass's 1885 approximation theorem was already a major conceptual leap from polynomials to abstract algebras. Our vector-valued extension is the natural next step, but one that had not been formally verified until now. With machine-checked proofs in Lean 4, we can be certain the argument is correct down to every logical step — important for results that will underpin safety-critical AI systems.

The practical import is immediate: the same EML architecture that achieves scalar universality automatically achieves vector universality for multiclass classifiers (via softmax), constrained controllers (via retraction), and coupled multi-output systems. No new approximation theory is needed — only these clean lifting theorems.

## 7. Related Work

The Stone–Weierstrass theorem has been formalized in several proof assistants, including Isabelle/HOL and Coq. The Mathlib library for Lean 4 contains the scalar version (`ContinuousMap.subalgebra_topologicalClosure_eq_top_of_separatesPoints`), which our development builds upon.

The vector-valued extension is well-known in functional analysis but has not, to our knowledge, been formally verified in a proof assistant. The coupled class formulation and retraction-based constrained approximation are more specific to the machine learning setting and appear to be novel in the formal verification literature.

The universal approximation theorem for neural networks, originally proved by Cybenko (1989) and Hornik (1991), is the machine learning analogue of Stone–Weierstrass. Our work extends this line by formalizing the multi-output case, which is implicitly used throughout deep learning but rarely stated precisely.

## 8. Conclusion

We have formalized a complete chain of density theorems lifting scalar EML Stone–Weierstrass to:
1. Unconstrained vector outputs (VecClass density)
2. Shared-feature architectures (CoupledVecClass density)
3. Constrained targets via retraction
4. Simplex-valued outputs via softmax

All proofs are machine-verified in Lean 4. The development demonstrates that once scalar universality is established, the vector-valued theory follows cleanly through finite-dimensional arguments, with the sup norm on Fin m → ℝ playing the crucial structural role.

### Future Directions

- **Quantitative bounds**: Upgrade density to explicit approximation rate bounds (Jackson-type theorems) for the vector-valued case.
- **Infinite-dimensional targets**: Extend beyond Fin m → ℝ to separable Banach space codomains.
- **Depth-width tradeoffs**: Formalize how the coupled class benefits from depth in the readout map φ.
- **Measure-valued outputs**: Generalize from simplex to the space of probability measures.
