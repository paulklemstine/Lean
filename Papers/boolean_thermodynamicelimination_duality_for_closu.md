# Boolean Thermodynamic–Elimination Duality for Closure-Generated Proof Semirings via Join-Irreducible Prime Coding

## Abstract

We establish a duality theorem for closure-generated proof systems modeled by
finite distributive lattices. The central result shows that derivability after
variable elimination is completely characterized by a finite Boolean code of
join-irreducible (sup-irreducible) prime witnesses, and that non-derivability
admits a thermodynamically extremal countermodel drawn from the same witness set.
All results are formally verified in Lean 4 using the Mathlib library.

**Keywords**: finite distributive lattice, Birkhoff representation, join-irreducible,
elimination, proof semiring, thermodynamic separation, formal verification

---

## 1. Introduction

A recurring challenge in proof theory and automated reasoning is the *elimination
problem*: given a collection of hypotheses Γ and a variable y to be eliminated,
determine which conclusions φ remain derivable from Γ \ {y}. When the underlying
proof system has the structure of a finite distributive lattice, we show that this
question admits a remarkably clean answer in terms of join-irreducible elements.

### 1.1 Main Contributions

We prove three interlocking results:

1. **Birkhoff Separation Lemma** (Theorem 1): In any finite sup-semilattice with ⊥,
   the order relation a ≤ b holds if and only if every sup-irreducible element below
   a is also below b.

2. **Elimination Prime Code Characterization** (Theorem 2): Derivability of φ from
   Γ \ {y} is equivalent to acceptance by all join-irreducible prime witnesses.

3. **Maximal Energy Separator** (Theorem 3): When derivability fails, there exists
   a join-irreducible witness that simultaneously rejects the derivation and has
   maximal "free energy" among all rejecting witnesses.

The combination of these three results constitutes the *Boolean Thermodynamic–
Elimination Duality*: the same finite set of prime codes controls both proof search
and countermodel search.

### 1.2 Formal Verification

All results are machine-verified in Lean 4 (v4.28.0) using the Mathlib library.
The formalization consists of approximately 350 lines and uses only standard axioms
(propext, Classical.choice, Quot.sound). The key Mathlib ingredients are:

- `exists_supIrred_decomposition`: every element in a well-founded sup-semilattice
  decomposes into a finite join of sup-irreducible elements
- `supPrime_iff_supIrred`: in a distributive lattice, sup-irreducible = sup-prime
- `Finset.exists_max_image`: finite maximization over nonempty finite sets

## 2. Mathematical Framework

### 2.1 Closure-Generated Proof Semirings

**Definition 1** (Closure Proof Semiring). A *closure-generated proof semiring* over
a type α of formulas consists of:
- A finite distributive lattice (L, ≤, ⊔, ⊓, ⊥) with decidable equality
- An embedding function `embed : α → L`

The *theory* of a finite context Γ ⊆ α is the lattice join:

    theory(Γ) = ⊔_{γ ∈ Γ} embed(γ)

**Definition 2** (Derivability). A formula φ is *derivable* from context Γ if:

    embed(φ) ≤ theory(Γ)

This captures the idea that the "content" of φ is contained in the theory
generated by Γ.

**Definition 3** (Variable Elimination). Eliminating variable y from context Γ
produces the reduced context:

    eliminateVar(Γ, y) = Γ \ {y}

### 2.2 Join-Irreducible Prime Witnesses

**Definition 4** (Sup-Irreducible). An element j ∈ L is *sup-irreducible* if j ≠ ⊥
and whenever j = a ⊔ b, either j = a or j = b.

In a distributive lattice, sup-irreducible is equivalent to sup-prime: j ≤ a ⊔ b
implies j ≤ a or j ≤ b. This equivalence (Mathlib's `supPrime_iff_supIrred`) is
the bridge from lattice theory to prime-spectrum semantics.

**Definition 5** (Prime Code Acceptance). A sup-irreducible witness j *accepts*
the derivation of φ from context Γₑ if:

    j ≤ embed(φ) → j ≤ theory(Γₑ)

Conversely, j *rejects* if j ≤ embed(φ) and j ≰ theory(Γₑ).

### 2.3 Free Energy and Thermodynamic Separation

**Definition 6** (Free Energy Data). A *free energy assignment* is a function
`energy : L → ℕ` assigning an energy score to each lattice element.

**Definition 7** (Maximal Free-Energy Countermodel). A sup-irreducible j is a
*maximal free-energy countermodel* for (Γₑ, φ) if:
1. j rejects the derivation of φ from Γₑ
2. For every other rejecting sup-irreducible j', energy(j') ≤ energy(j)

## 3. Main Results

### 3.1 Birkhoff Separation Lemma

**Theorem 1** (le_iff_forall_supIrred_le). *Let L be a finite sup-semilattice with ⊥.
For any a, b ∈ L:*

    a ≤ b  ⟺  ∀ j ∈ L, SupIrred(j) → j ≤ a → j ≤ b

*Proof.* The forward direction is immediate by transitivity. For the backward
direction, by `exists_supIrred_decomposition`, there exists a finite set S ⊆ L with
S.sup id = a and every element of S sup-irreducible. For each x ∈ S, we have
x ≤ S.sup id = a, so by hypothesis x ≤ b. Then S.sup id ≤ b by `Finset.sup_le`,
giving a ≤ b. ∎

**Corollary** (Separation Witness). *If a ≰ b, there exists a sup-irreducible j
with j ≤ a and j ≰ b.*

### 3.2 Elimination Prime Code Characterization

**Theorem 2** (elimination_prime_code_iff). *For any context Γ, variable y, and
formula φ:*

    Derivable(eliminateVar(Γ,y), φ)  ⟺
      ∀ j ∈ JoinIrreduciblePrimeWitnesses, primeCodeAccepts(j, eliminateVar(Γ,y), φ)

*Proof.* Soundness (→): If embed(φ) ≤ theory(Γₑ) and j ≤ embed(φ), then
j ≤ theory(Γₑ) by transitivity.

Completeness (←): The hypothesis says ∀ j, SupIrred(j) → j ≤ embed(φ) → j ≤ theory(Γₑ).
By Theorem 1 (backward direction), embed(φ) ≤ theory(Γₑ). ∎

### 3.3 Maximal Energy Separator

**Theorem 3** (exists_maximal_energy_separator). *If ¬Derivable(eliminateVar(Γ,y), φ),
then for any energy assignment E, there exists a sup-irreducible j that:*
1. *rejects the derivation, and*
2. *has maximal energy among all rejecting sup-irreducibles.*

*Proof.* By Theorem 1 (separation witness), non-derivability yields a sup-irreducible j₀
with j₀ ≤ embed(φ) and j₀ ≰ theory(Γₑ). The set of rejecting sup-irreducibles is
therefore nonempty. By `Finset.exists_max_image` on this finite nonempty set with
the energy function, we obtain a maximal element. ∎

### 3.4 Combined Duality

**Theorem 4** (boolean_thermodynamic_elimination_duality). *The conjunction of
Theorems 2 and 3: the same finite set of join-irreducible prime witnesses controls
both derivability (via the biconditional) and non-derivability (via the maximal-energy
separator).*

### 3.5 Decision Procedure

**Theorem 5** (eliminationDecider_spec). *The Boolean function*

    eliminationDecider(Γ, y, φ) = decide(∀ j ∈ J, primeCodeAccepts(j, Γₑ, φ))

*returns true if and only if φ is derivable from eliminateVar(Γ, y).*

### 3.6 Witness Extraction

**Theorem 6** (maximalEnergyWitness_spec). *When derivability fails, the function
`maximalEnergyWitness` returns a concrete sup-irreducible element that rejects the
derivation and has maximal energy among all rejectors.*

## 4. Examples

### 4.1 Boolean Lattice P({1,2,3})

Consider the power set lattice of {1,2,3} with formulas embedded as singleton sets.
The join-irreducibles are exactly the atoms: {1}, {2}, {3}.

**Example**: Context Γ = {x, y, z} with embed(x) = {1}, embed(y) = {2}, embed(z) = {3}.
Eliminating y gives Γₑ = {x, z} with theory(Γₑ) = {1,3}.

Query: Is "xy" (= {1,2}) derivable from Γₑ?
- Prime {1}: {1} ≤ {1,2}? Yes. {1} ≤ {1,3}? Yes. → ACCEPTS
- Prime {2}: {2} ≤ {1,2}? Yes. {2} ≤ {1,3}? No. → **REJECTS**
- Prime {3}: {3} ≤ {1,2}? No. → ACCEPTS (vacuously)

Since prime {2} rejects, the derivation fails. The witness {2} identifies exactly
which "aspect" of the conclusion is missing from the reduced context.

### 4.2 Divisor Lattice of 30

The divisors of 30 = 2 × 3 × 5, ordered by divisibility, form a distributive lattice
isomorphic to P({1,2,3}). The join-irreducibles are the primes: 2, 3, 5.

**Example**: Can we derive 15 (= 3 × 5) from {3} (after eliminating 2 from {2,3})?
- Prime 2: 2 | 15? No. → ACCEPTS
- Prime 3: 3 | 15? Yes. 3 | 3? Yes. → ACCEPTS
- Prime 5: 5 | 15? Yes. 5 | 3? No. → **REJECTS**

Prime 5 witnesses that "the factor 5 is needed but not available."

## 5. Discussion: Compressing Proof Search into Boolean Codes

### 5.1 A Scientific American Perspective

Imagine you're an architect trying to determine whether a building can stand without
one of its pillars. You could simulate the entire structure — a complex and expensive
computation. Or you could identify the *critical stress points* — a small number of
places where failure would first manifest — and check only those.

Our theorem says something analogous for logical reasoning. When you remove a
hypothesis from a mathematical argument and ask "does the conclusion still follow?",
you don't need to search through all possible proofs or counterexamples. Instead,
you can check a small, canonical set of "stress tests" — the join-irreducible prime
witnesses. These are the logical equivalent of critical stress points.

What makes this remarkable is the *duality*: the very same stress tests that certify
success (when all pass) also provide the most informative failure explanation (when
one fails). It's as if the same instrument that confirms structural integrity also
pinpoints the exact weakest point when the structure fails.

The "thermodynamic" aspect adds another layer: when the building does fail, you don't
just learn *that* it fails — you learn *where* it fails most dramatically. The
maximal-energy separator is the stress point where the failure is most pronounced,
giving the most informative diagnostic.

### 5.2 Historical Context

The mathematical foundation traces to Garrett Birkhoff's 1937 representation theorem
for finite distributive lattices. Birkhoff showed that every such lattice is isomorphic
to the lattice of downward-closed sets (lower sets) of its join-irreducible elements.
This means the join-irreducible elements form a complete "genetic code" for the lattice.

Our contribution is to interpret this coding in proof-theoretic terms: the
join-irreducible code becomes a decision procedure for variable elimination, and the
thermodynamic interpretation (choosing the highest-energy separator) gives an
optimization principle for countermodel extraction.

### 5.3 Connections to Existing Work

**Proof complexity**: The prime-code characterization compresses derivability checking
from a search over all proofs to a check of |J| prime witnesses, where |J| is the
number of join-irreducibles. In Boolean lattices, |J| equals the number of atoms,
which is logarithmic in the lattice size.

**SAT solving**: In propositional logic, the lattice of theories is a Boolean algebra,
and elimination corresponds to existential quantification / variable projection.
Our theorem shows that in the finite distributive regime, this projection is controlled
by join-irreducible "unit propagation" witnesses.

**Tropical geometry**: In tropical (min-plus) semirings, join-irreducible elements
correspond to vertices of Newton polytopes, and the energy function becomes a tropical
valuation. The duality then connects to min-max theorems in tropical optimization.

## 6. Applications

### 6.1 Certified Variable Elimination

The `eliminationDecider` provides a verified decision procedure:
1. Enumerate the (finite, precomputed) set of join-irreducible witnesses
2. For each witness j, check whether j ≤ embed(φ) → j ≤ theory(Γₑ)
3. Return true iff all witnesses accept

This is a model for certified elimination in any system whose proof states form
a finite distributive lattice.

### 6.2 Countermodel Extraction

When a derivation fails, `maximalEnergyWitness` provides:
- A specific join-irreducible witness j identifying the missing "aspect"
- An energy certificate showing j is the most informative failure explanation
- A concrete countermodel for debugging or explanation

### 6.3 Proof Compression

The prime-code representation compresses proof certificates: instead of storing
a full derivation tree, one stores the set of join-irreducible witnesses that
accept. This is particularly efficient when |J| ≪ |L|.

## 8. Conclusion

We have established that in finite distributive lattices, the join-irreducible elements
form a Boolean code that simultaneously decides variable elimination and provides
extremal countermodels. This duality — between proof search and countermodel search,
mediated by the same finite prime code — is a structural consequence of Birkhoff's
representation theorem, interpreted in the language of closure-generated proof semirings.

The formal verification in Lean 4 ensures that these results are mathematically
airtight. The companion Python demonstrations make the theorem tangible on concrete
lattices, showing how join-irreducible primes act as both validators and separators
in practice.
