# Computational evidence justification

A separate computational evidence stage was skipped because the model has exactly three truth values and every universal algebraic claim is proved by exhaustive case analysis inside Lean. The checked proofs cover all 3 cases for unary laws, all 9 cases for binary laws, and all 27 cases of Heyting residuation. Thus an external table or script would duplicate, and be weaker than, the kernel-checked exhaustive proofs.

No numerical sequence arises, so an OEIS search is inapplicable. The formal witness `present` is the counterexample to ordinary excluded middle; the universal temporal and residuation laws have no counterexample among the complete finite state space, as established by the proofs.
