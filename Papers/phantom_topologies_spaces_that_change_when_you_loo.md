# Computational Evidence — Phantom Possibility Topologies

This cycle studies the *possibility* (pooled-resolution) topology
`possibility T = ⨅ i, T i`, the order-dual of the catalog's *consensus* topology
`consensus T = ⨆ i, T i`. Reality-as-agreement (`⨆`, opens = intersection of the observer
open families) is contrasted with reality-as-pooling (`⨅`, opens = topology generated by
the union of the observer open families).

## 1. Small-case squeeze on ℝ

For the lower-limit (Sorgenfrey) observer (basic opens `[x, b)`) and the upper-limit
observer (basic opens `(a, x]`), we check the key intersection point-by-point:

| x    | `[x, x+1)`        | `(x-1, x]`        | intersection |
|------|-------------------|-------------------|--------------|
| 0    | `[0, 1)`          | `(-1, 0]`         | `{0}`        |
| 1.5  | `[1.5, 2.5)`      | `(0.5, 1.5]`      | `{1.5}`      |
| -3   | `[-3, -2)`        | `(-4, -3]`        | `{-3}`       |

In general `y ∈ [x, x+1) ∩ (x-1, x]` forces `x ≤ y ≤ x`, i.e. `y = x`. So every singleton
is possibility-open, hence the pooled topology is **discrete**. This is the opposite of the
consensus, which the catalog computed to be the **Euclidean** topology.

Consequence — a strict *three-level reality* from one observer pair:

```
discrete (pool)   <   Euclidean (agree)   <   indiscrete (ignore)
   ⊥                        std                      ⊤
```

Strictness witnesses: `{0}` is not Euclidean-open (no isolated points), so
`⊥ ≠ std`; `Ioo 0 1` is Euclidean-open but is neither `∅` nor `univ`, so `std ≠ ⊤`.

## 2. Two-point (Bool) duality

Enumerating the opens of the two Sierpiński observers:

- `sierpTrue` opens: `∅, {true}, univ`  (a set is open iff `false ∈ U → true ∈ U`).
- `sierpFalse` opens: `∅, {false}, univ` (a set is open iff `true ∈ U → false ∈ U`).

- **Agreement** (`⊔`): common opens are `∅, univ` → indiscrete `⊤`  (catalog result).
- **Pooling** (`⊓`): `{true}` (from `sierpTrue`) and `{false}` (from `sierpFalse`) are both
  in the pooled topology, so every subset is open → discrete `⊥`.

So one Sierpiński observer pair spans the *entire* four-element lattice of topologies on
`Bool`, mirroring the ℝ phenomenon.

## 3. Counterexample hunt against the *positive* conjecture

Claim tested: "every second-countable space admits a genuine phantom representation with
≤ 2 observers" (each observer strictly finer than the consensus).

Sample of nice spaces and whether they are *genuinely* representable:

| space                    | second-countable | metrizable | genuine finite phantom rep? |
|--------------------------|:----------------:|:----------:|:---------------------------:|
| ℝ, Euclidean             | yes              | yes        | yes (lower/upper limit)     |
| `Bool`, indiscrete `⊤`   | yes              | no         | yes (two Sierpiński)        |
| `Bool`, discrete `⊥`     | yes              | yes        | **NO** (join-irreducible)   |
| ℕ, discrete `⊥`          | yes              | yes        | **NO** (join-irreducible)   |

The discrete two-point space is a counterexample: nothing is strictly finer than `⊥`
(`not_lt_bot`), so a genuine representation is impossible even though the space is as nice
(second-countable, metrizable) as one could ask. Genuine representability is governed by
join-reducibility in the lattice of topologies, not by separation axioms.

## Summary of what was formalised

- `lowerTop ⊓ upperTop = ⊥` and `possibility observersℝ = ⊥` (ℝ pooled = discrete).
- `possibility observersℝ < consensus observersℝ < ⊤` (three strict levels).
- `sierpTrue ⊓ sierpFalse = ⊥` and the Bool `⊥`/`⊤` possibility/consensus duality.
- `discreteTopology_phantom_rigid` and a concrete second-countable + metrizable witness
  refuting the positive conjecture.
