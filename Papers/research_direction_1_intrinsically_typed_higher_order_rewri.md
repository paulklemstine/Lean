# Intrinsically Typed Higher-Order Rewriting with βη-Completion

## Abstract

We develop a formally verified theory of higher-order rewriting modulo βη-equivalence for intrinsically typed simply typed λ-terms. All terms are well-scoped and well-typed by construction using de Bruijn indices indexed by contexts and types. We prove three main theorems: (1) substitution composition is functorial, establishing that contexts and substitutions form a category; (2) η-contraction is stable under substitution, the crucial extensional lemma absent from prior untyped developments; and (3) higher-order equational generation descends to βη-equivalence classes, meaning that rewrite-generated equations are well-defined on the βη-quotient. These results are mechanically verified in Lean 4 with no axioms beyond `propext` and `Quot.sound`. We introduce the concept of a **βη-stable rewrite theory** and show that the minimal such theory generates exactly βη-equivalence. The development opens a path toward certified completion procedures for extensional functional programs and normalization-by-evaluation pipelines.

**Keywords**: higher-order rewriting, simply typed λ-calculus, βη-equivalence, intrinsic typing, de Bruijn indices, substitution calculus, extensional equality, completion procedures, categorical semantics, compiler correctness, proof normalization

## 1. Introduction

### 1.1 Motivation

Higher-order rewriting extends classical term rewriting to settings with variable binding and function types. While first-order rewriting benefits from mature completion procedures (Knuth-Bendix) and well-understood confluence theory, the higher-order case is complicated by:

1. **Variable binding**: α-equivalence, capture-avoiding substitution, and the interaction between binders and rewrite rules.
2. **β-reduction**: The computational rule of the λ-calculus must be incorporated into the rewrite system.
3. **η-equivalence**: Functions that produce identical outputs on all inputs should be identified — but this *extensional* principle interacts nontrivially with syntactic rewriting.

The first two challenges have been addressed in various settings (Nipkow 1991, Mayr & Nipkow 1998, Blanqui 2000). The third — extensional closure — remains largely informal in the rewriting literature.

### 1.2 The Extensional Gap

Prior work on higher-order completion, including the catalog developments in `HigherOrderCompletion.lean` and `ConcreteTermAlgebra.lean`, handles β-reduction but treats terms at the syntactic level without η. This means that the rewrite theory cannot distinguish between a function `f` and its η-expansion `λx. f x`, even though these should be identified in any extensional semantics.

The gap becomes critical when:
- **Optimizing functional programs**: a compiler that identifies `λx. map f x` with `map f` needs η-reduction to be sound with respect to the optimization rules.
- **Normalizing proofs**: in type theory, definitional equality includes η, so proof normalization must respect it.
- **Completing higher-order systems**: a Knuth-Bendix procedure modulo βη requires that critical pair analysis descends to the βη-quotient.

### 1.3 Contributions

We address the extensional gap by developing a fully intrinsically typed theory of higher-order rewriting modulo βη. Our contributions are:

1. **Intrinsically typed syntax**: Terms `Tm Γ A` are indexed by their context and type, so well-scopedness and well-typedness hold by construction.

2. **Substitution calculus**: We prove the full suite of renaming-substitution interaction lemmas, culminating in the composition theorem `subst τ (subst σ t) = subst (compSub τ σ) t`.

3. **η-stability theorem**: We prove that η-contraction commutes with substitution — the key extensional lemma that makes quotient descent possible.

4. **Quotient descent**: We prove that the equational theory generated by any βη-stable rule set descends to βη-equivalence classes.

5. **Categorical structure**: We establish that contexts and substitutions form a category (associativity, identity laws), connecting to Fiore-Plotkin-Turi style categorical semantics.

All results are mechanically verified in Lean 4 with no `sorry` and no non-standard axioms.

### 1.4 Relationship to Prior Work

Our development builds on and extends:

- **`ConcreteTermAlgebra.lean`** (catalog): `FOTerm.subst_comp` establishes substitution functoriality for first-order terms. Our `subst_comp` is the intrinsically typed higher-order analogue; the `lam` case requires genuinely new lemmas about lifted substitution composition.

- **`HigherOrderCompletion.lean`** (catalog): `hoRewrite_beta_stable_under_closed_subst` proves β-aware rewriting stability for untyped/less-indexed terms. Our development adds intrinsic typing and, crucially, η-closure.

- **Autosubst** (Schäfer et al. 2015): Our substitution calculus follows the Autosubst methodology but in an intrinsically typed setting, which strengthens the coherence conditions.

- **Fiore-Plotkin-Turi** (1999): Our categorical substitution laws provide the syntactic side of their abstract syntax framework.

## 2. Definitions and Notation

### 2.1 Types and Contexts

```
Ty ::= base(n)  |  arr(A, B)
Ctx = List Ty
```

Types are either base types (indexed by natural numbers) or function types. A context `Γ` is a list of types representing the types of free variables.

### 2.2 Variables and Terms

Variables are typed de Bruijn indices — proofs of membership in the context:

```
Var : Ctx → Ty → Type
  vz : Var (A :: Γ) A
  vs : Var Γ A → Var (B :: Γ) A
```

Terms are intrinsically typed:

```
Tm : Ctx → Ty → Type
  var : Var Γ A → Tm Γ A
  app : Tm Γ (arr A B) → Tm Γ A → Tm Γ B
  lam : Tm (A :: Γ) B → Tm Γ (arr A B)
```

### 2.3 Renamings and Substitutions

A **renaming** `ρ : Ren Γ Δ` is a type-preserving map from variables in `Γ` to variables in `Δ`:
```
Ren Γ Δ = (A : Ty) → Var Γ A → Var Δ A
```

A **substitution** `σ : Sub Γ Δ` maps variables to terms:
```
Sub Γ Δ = (A : Ty) → Var Γ A → Tm Δ A
```

**Lifting** extends a renaming/substitution under a binder:
```
liftRen ρ : Ren (B :: Γ) (B :: Δ)
  vz    ↦ vz
  vs v  ↦ vs (ρ v)

liftSub σ : Sub (B :: Γ) (B :: Δ)
  vz    ↦ var vz
  vs v  ↦ rename wk (σ v)
```

### 2.4 β-Reduction and η-Contraction

**β-step**: `app (lam body) arg →β subst (singleSub arg) body`

**η-step**: `lam (app (rename wk f) (var vz)) →η f`

The η-step is the intrinsic encoding of `λx. f x →η f` when `x ∉ FV(f)`. The condition is enforced structurally: `f : Tm Γ (arr A B)` does not mention variable 0 in `A :: Γ`.

### 2.5 βη-Equivalence and Equational Generation

**BetaEtaEq** is the smallest equivalence relation containing β and η steps, closed under congruence (app and lam).

**HOEqGen E** is the smallest congruence containing a given rule set `E`. Substitution closure is *not* built in — it is proved as a theorem.

## 3. Main Results

### 3.1 Theorem 1: Substitution Composition

**Statement.**
```
theorem subst_comp (σ : Sub Γ Δ) (τ : Sub Δ Ξ) (t : Tm Γ A) :
    subst τ (subst σ t) = subst (compSub τ σ) t
```

**Proof sketch.** By structural induction on `t`:
- **var v**: Both sides reduce to `subst τ (σ A v)`, which is `compSub τ σ A v` by definition.
- **app f a**: Follows from the induction hypotheses on `f` and `a`.
- **lam body** (the critical case): We need
  ```
  subst (liftSub τ) (subst (liftSub σ) body) = subst (liftSub (compSub τ σ)) body
  ```
  By the IH, the LHS equals `subst (compSub (liftSub τ) (liftSub σ)) body`. We then apply `subst_ext` to show that `compSub (liftSub τ) (liftSub σ)` agrees pointwise with `liftSub (compSub τ σ)`:
  - At `vz`: both give `var vz`.
  - At `vs v`: the LHS gives `subst (liftSub τ) (rename wk (σ A v))`, which by `rename_subst` and `subst_rename` equals `rename wk (subst τ (σ A v))`, which is `liftSub (compSub τ σ) A (vs v)`.

This is the key interaction between lifting and composition that distinguishes the higher-order case from the first-order `FOTerm.subst_comp`.

### 3.2 Theorem 2: η-Stability Under Substitution

**Statement.**
```
theorem eta_closed_under_subst
    {t u : Tm Γ A} (h : EtaStep t u) (σ : Sub Γ Δ) :
    EtaStep (subst σ t) (subst σ u)
```

**Proof sketch.** The only η-step is `EtaStep.eta f`, where the redex is `lam (app (rename wk f) (var vz))` and the reduct is `f`. After substitution:

```
subst σ (lam (app (rename wk f) (var vz)))
= lam (subst (liftSub σ) (app (rename wk f) (var vz)))
= lam (app (subst (liftSub σ) (rename wk f)) (liftSub σ _ vz))
= lam (app (subst (liftSub σ) (rename wk f)) (var vz))
```

The crucial step is showing `subst (liftSub σ) (rename wk f) = rename wk (subst σ f)`, which follows from `rename_subst` and `subst_rename`. The result is itself an η-redex that contracts to `subst σ f`.

**Why this is nontrivial**: The β-stability proof is analogous but well-known. The η case is genuinely new because it requires the commutation `subst ∘ liftSub ∘ rename wk = rename wk ∘ subst`, which is a deeper property of the substitution calculus.

### 3.3 Theorem 3: Quotient Descent

**Statement.**
```
theorem hoEqGen_respects_betaEta
    (hβ : ∀ {Γ A} {t u : Tm Γ A}, BetaStep t u → E t u)
    (hη : ∀ {Γ A} {t u : Tm Γ A}, EtaStep t u → E t u)
    {t t' u u' : Tm Γ A}
    (heq : HOEqGen E t u)
    (htt' : BetaEtaEq t t') (huu' : BetaEtaEq u u') :
    HOEqGen E t' u'
```

**Proof.** We first embed `BetaEtaEq` into `HOEqGen E` via `betaEtaEq_to_hoEqGen` (since E contains β and η steps). Then:
```
HOEqGen E t' u'
  = HOEqGen E t' t ∘ HOEqGen E t u ∘ HOEqGen E u u'
```
using symmetry and transitivity of `HOEqGen`.

**Significance**: This says that `HOEqGen E` is well-defined on the βη-quotient. If `t ≈βη t'` and `u ≈βη u'`, then `t` and `u` are E-equated iff `t'` and `u'` are. Rewriting cannot distinguish between βη-equivalent presentations.

### 3.4 Additional Results

**Substitution Category Laws:**
```
compSub σ idSub = σ          (right identity)
compSub idSub σ = σ          (left identity)
compSub υ (compSub τ σ) = compSub (compSub υ τ) σ  (associativity)
```

**βη-Equivalence stability:** `BetaEtaEq t u → BetaEtaEq (subst σ t) (subst σ u)`

**Minimal theory characterization:** `HOEqGen MinBetaEtaRule t u ↔ BetaEtaEq t u`

## 4. Algorithms

### 4.1 βη-Normalizer

**Input**: A simply typed λ-term `t` in de Bruijn notation.
**Output**: The βη-normal form of `t`.
**Strategy**: Leftmost-outermost reduction (always terminates for simply typed terms by strong normalization).

```
function normalize(t):
    repeat:
        r ← normalize_step(t)
        if r = None: return t
        t ← r

function normalize_step(t):
    if t = app(lam(body), arg):
        return body[arg/0]         -- β-reduction
    if t = lam(app(f, var(0))) and 0 ∉ FV(f):
        return shift_down(f)       -- η-contraction
    recurse into subterms (leftmost-outermost)
```

**Complexity**: O(n · 2^n) worst case, O(n²) typical for simply typed terms. Convergence is guaranteed by the strong normalization theorem.

### 4.2 η-Redex Detector

Traverses a term tree and identifies all positions where η-contraction applies.

**Complexity**: O(size(t)²) worst case.

### 4.3 Orthogonality Checker

Given a finite set of typed rewrite rules, checks whether their left-hand sides overlap. Two patterns overlap if there exists a unifying substitution. We use a simplified first-order-like check sufficient for Miller patterns.

**Complexity**: O(|rules|² · max_pattern_size).

## 5. Applications

### 5.1 Compiler Optimization

In functional language compilers, η-expansion frequently arises from partial application, CPS transformation, or defunctionalization. The η-stability theorem (Theorem 2) guarantees that optimization rules stated as rewrite equations remain valid after η-contraction. Combined with the quotient descent theorem (Theorem 3), this means that:

> *An optimization rule proved correct on η-expanded terms remains correct on η-contracted terms.*

**Example**: The rule `map f (cons x xs) → cons (f x) (map f xs)` remains valid whether `map f` appears as `map f` or as `λxs. map f xs`.

### 5.2 Proof Normalization

In type theory with the Curry-Howard correspondence, proofs are λ-terms and definitional equality includes βη. Our quotient descent theorem says that if two proofs are βη-equivalent, any equational consequence of one is also a consequence of the other. This is essential for:

- **Proof irrelevance**: Two proofs of the same proposition can be used interchangeably in further reasoning.
- **Normalization-by-evaluation**: The βη-quotient provides the correct semantic domain for NbE.

### 5.3 Categorical Semantics

Our substitution category laws provide the syntactic half of the equivalence between:
- The syntactic category (contexts as objects, substitutions as morphisms)
- Categories with families (CwFs) as models of dependent type theory

The associativity law `compSub_assoc` is the key algebraic identity needed to verify that the syntactic category is well-defined.

## 7. Discussion

### 7.1 What the Intrinsic Typing Buys

Compared to the untyped/extrinsic approach in `HigherOrderCompletion.lean`:

1. **No side conditions**: The η-step `lam (app (rename wk f) (var vz)) →η f` has no side condition "x ∉ FV(f)" — this is enforced by the typing.

2. **Stronger induction principles**: Pattern matching on `Var (A :: Γ) B` is exhaustive (either `vz` or `vs v`), eliminating impossible cases automatically.

3. **No ill-typed terms**: Every `Tm Γ A` is well-typed by construction, so substitution stability theorems don't need type-preservation lemmas.

4. **Cleaner composition**: The `liftSub_compSub` lemma is a clean case analysis on `vz/vs`, whereas the untyped version requires arithmetic on de Bruijn indices.

### 7.2 Limitations

1. **Simple types only**: We handle the simply typed λ-calculus. Extension to dependent types, polymorphism, or universe polymorphism would require substantially more infrastructure.

2. **No normalization proof**: We do not prove strong normalization within this development. This is a separate, deep theorem (Tait 1967, Girard 1972).

3. **No algorithmic completion**: While we establish the algebraic foundations, we do not implement a full Knuth-Bendix completion procedure modulo βη. This is a direction for future work.

### 7.3 The Deep Point

The mathematical insight is this:

- **β-stability** says rewriting respects computation.
- **η-stability** says rewriting respects extensionality.
- **Intrinsic typing** says these properties are structural facts of the syntax, not accidental side conditions.

Together, they make higher-order rewriting modulo βη a **semantics-level object** rather than merely a syntactic relation. In extensional settings, functions are determined by their action. A rewrite theory that fails to descend to βη-classes is semantically brittle. Our theorems remove that brittleness.

1. **Full completion modulo βη**: Implement a certified Knuth-Bendix procedure that generates rewrite rules from critical pairs modulo βη-equivalence.

2. **Normalization-by-evaluation**: Use the substitution category structure to build a certified NbE algorithm for simply typed λ-calculus.
