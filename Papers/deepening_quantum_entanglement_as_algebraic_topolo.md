# Computational Evidence

Exploratory numerics used to *select* the conjectures before formalisation.
Everything listed here was subsequently **proved in Lean** (see
`Catalog/Pythagorean/`); the numbers below are only the reconnaissance that
guided the choice of statements. Floating-point experiments are not proofs, and
nothing in this file is claimed as verified — the Lean files are the verification.

## 1. The Hopf gap identity

For `u = (α,β)`, `v = (γ,δ)` in `ℂ²`, with the Hopf map
`h(z,w) = (2 Re(z w̄), 2 Im(z w̄), |z|²−|w|²)`, five random Gaussian samples gave

| `‖u‖²‖v‖² − ⟨h(u),h(v)⟩` | `2·|αδ−βγ|²` | `‖h(u)‖² − (‖u‖²)²` |
|---|---|---|
| 7.5023312941 | 7.5023312941 | 0.0 |
| 39.5898265955 | 39.5898265955 | 0.0 |
| 10.0513994130 | 10.0513994130 | 0.0 |
| 6.4041905383 | 6.4041905383 | 0.0 |
| 6.2231235413 | 6.2231235413 | 0.0 |

Both columns agree to machine precision, and the Hopf image always lies on the
sphere of radius `‖u‖²`. This is the identity later proved as
`HopfEntanglement.hopf_dot_identity` and `HopfEntanglement.hopfVec_normSq`.

Sanity checks on distinguished states:

* Bell `Φ⁺` (`α = δ = 1/√2`): `p = q = 1/2`, `h(u) = (0,0,1/2)`, `h(v) = (0,0,−1/2)`
  — antipodal Hopf base points, gap `1/2`, concurrence `1`.
* `α = β = γ = δ = 1/2` (a product state): `h(u) = h(v) = (1/2,0,0)` — the two
  Hopf base points *coincide*, gap `0`, concurrence `0`.

This dichotomy (coincident vs. distinct base points) is exactly what the linking
number detects.

## 2. Winding number of the Hopf fibre

For `γ(θ) = e^{iθ}v` and the linking coordinate `x ↦ det(u,x)`, the integrand
`γ'/γ` is the constant `i`, so `(2πi)⁻¹∮ = 1` — no numerics needed, and this is
`HopfLink.winding_circle` (proved for general multiplicity `n`).

## 3. Hyperdeterminant: `SL(2)³` relative invariance

Three random `2×2×2` complex arrays `a` and random `2×2` matrices `M`, acting on
the first index. Reported: `|Det(M·a) − (det M)² Det(a)|`.

```
1.78e-15
9.65e-13
3.79e-15
```

Zero to floating-point precision. This convinced us the Cayley formula we wrote
down was the correct one, and the identity is now proved exactly by `ring` in
`ThreeTangle.hyperdet_act1/2/3` (and, since the same formula is invariant under
all three factors, the invariance test also validates the formula itself).

## 4. Tangles of the distinguished three-qubit states

```
tau GHZ = 1.0000000000000004
tau W   = 0.0
```

matching the proved theorems `ThreeTangle.threeTangle_ghz` and
`ThreeTangle.threeTangle_w`. The W state nevertheless has a nonzero `2×2` minor
across the `A|BC` cut (`−1/3`), which is the proved
`ThreeTangle.w_entangled_across_cutA`.

## 5. Counterexample hunt

* Searched for a two-qubit state with `0 < C(ψ) < ` any positive linking value
  other than `1`: **none exists** — and indeed we proved
  `HopfLink.linkingNumber_eq_ite`, the linking number of two Hopf fibres is
  exactly `0` or `1`. The invariant is a Boolean *for Hopf fibres*; the
  `(m,n)` torus loops (`HopfLink.torusLoop_linking_first/second`) show the
  underlying winding invariant is genuinely ℤ-valued.
* Searched for a normalised state with `C(ψ) = 1` and unbalanced halves
  (`p ≠ q`): none found, in agreement with the proved
  `HopfEntanglement.maximally_entangled_iff_antipodal`.

## 6. OEIS

The Hopf sphere identity restricted to Gaussian integers produces Pythagorean
quadruples `x²+y²+z² = n²` (`HopfEntanglement.pythagorean_quadruple_of_gaussian`);
the associated hypotenuse sequence is the classical set of numbers that are the
hypotenuse of a Pythagorean quadruple. No new integer sequence was generated by
this work, so no OEIS submission is warranted.

## 7. GHZ vs W reduced states (partial transpose)

Partial transpose on the second factor of the two-party reduced state, tested on
`|00⟩ − |11⟩`:

| state | `⟨v, ρ_AB^{T_B} v⟩` | conclusion |
|---|---|---|
| GHZ | `0` | consistent with separability (proved: `ghz_rhoAB_separable`) |
| W   | `−1/3` | negative, so not separable (proved: `w_rhoAB_not_separable`) |

Both entries are now theorems: `ThreeTangle.w_partialTranspose_negative` computes
the value `−1/3` exactly, and `ThreeTangle.separable_partialTransposeB_nonneg`
proves the Peres criterion used to draw the conclusion.
