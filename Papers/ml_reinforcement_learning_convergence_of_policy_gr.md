# Why computational evidence was skipped

The principal claims are symbolic finite-sum and differentiation identities valid for every finite action count and every real-valued policy family satisfying explicit hypotheses. Small-case numerical testing would exercise only arbitrary chosen inputs and would not materially validate the universal calculus argument. The sharpness theorem already supplies an exact, machine-checked two-action witness attaining the inverse-ε rate, which is more relevant than an external numerical table. No integer sequence arises, so an OEIS search is inapplicable.
