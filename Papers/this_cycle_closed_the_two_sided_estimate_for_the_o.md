# Computational evidence

The cycle targets an all-size analytic inequality rather than a conjecture
selected from numerical data. Small cases nevertheless agree with the proved
window. For `n = 2,3,4,5`, the exact path formula predicted by discrete cosine
diagonalization gives respectively

| `n` | predicted gap `(2-2 cos(π/n))/n` | proved interval `[2/n³,12/n³]` |
|---:|---:|---:|
| 2 | 1.000000 | [0.250000, 1.500000] |
| 3 | 0.333333 | [0.074074, 0.444444] |
| 4 | 0.146447 | [0.031250, 0.187500] |
| 5 | 0.076393 | [0.016000, 0.096000] |

No counterexample can occur within the stated domain because the delivered
Poincaré estimate proves the interval for every `n ≥ 2` and every nonconstant
real observable. No OEIS identification is pertinent: the exact values are
algebraic trigonometric quantities rather than an integer sequence. The sharper
cosine formula is retained as a future conjecture and is not used as a verified
result of this cycle.
