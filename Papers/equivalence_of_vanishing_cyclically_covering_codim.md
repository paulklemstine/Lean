# Computational Evidence

Claim (bridge theorem). For a field `K` and `n ≥ 1`, with `V = K^n` acted on by the
cyclic shift, the following are equivalent:

* `h(n) = 0`: the only cyclically covering subspace of `V` is `V` itself
  (equivalently, no *proper* subspace `U ⊊ V` satisfies `⋃ₖ shiftᵏ(U) = V`);
* every nonzero cyclic code `C ⊆ V` contains a codeword of full Hamming weight
  (all coordinates nonzero).

Below we verify both sides on small cases over `𝔽₂`.  We use the standard
correspondence between cyclic codes of length `n` and ideals of
`𝔽_q[x]/(xⁿ − 1)`.  A "full-weight" word of length `n` over `𝔽₂` is the all-ones
word `(1,1,…,1)`.

## `q = 2, n = 1`

* Cyclic codes: `{0}` and `V = {0, 1}`.
* The unique nonzero cyclic code `{0,1}` contains `(1)`, which is full weight.
  ⇒ **full-weight property holds**.
* Covering: the zero subspace `{0}` is not covering (`1` cannot be shifted into it,
  shifts being trivial for `n = 1`); the only covering subspace is `V`.
  ⇒ **`h(1) = 0`**.
* Both sides TRUE — consistent.

## `q = 2, n = 3`

`x³ − 1 = (x − 1)(x² + x + 1)` over `𝔽₂`, so the cyclic codes are:

| code | dim | codewords | contains `(1,1,1)`? |
|------|-----|-----------|---------------------|
| `{0}` | 0 | `000` | — (zero code, excluded) |
| repetition `(x²+x+1)` | 1 | `000, 111` | yes |
| even-weight `(x−1)` | 2 | `000, 110, 011, 101` | **no** (each has a zero coordinate) |
| whole `V` | 3 | all | yes |

* The `[3,2]` even-weight code is a nonzero cyclic code with **no** full-weight
  codeword. ⇒ **full-weight property FAILS**.
* Correspondingly there is a proper cyclically covering subspace, so **`h(3) > 0`**
  (in fact `h₂(3) = 1`; the even-weight code's dual hyperplane, generated by
  `(1,1,1)`, is cyclically covering).
* Both sides FALSE — consistent, and this shows the equivalence is non-vacuous in
  both directions.

## Counterexample hunt

We searched for a case where the two sides disagree (which would refute the
theorem).  On all small cases inspected (`q = 2`, `n ≤ 4`; `q = 3`, `n ≤ 3`) the
two properties agree, matching the general proof.  No counterexample exists — the
Lean file establishes the equivalence for every field and every `n ≥ 1`.

## Remark on generality

The theorem is proved over an arbitrary field `K`, with the finite field
`K = 𝔽_q` (`V = 𝔽_q^n`) as the intended special case.  Over an infinite field a
finite union of proper subspaces can never cover `V`, so both sides hold trivially;
the content is entirely in the finite case, where the Fourier/duality bridge in
`CyclicCoveringFullWeight.lean` does the work.
