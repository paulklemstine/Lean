# Computational evidence

The selected results are structural identities about arbitrary finite maps rather than a numerical conjecture. Small finite examples nevertheless clarify the claims.

## Small-case calculation

Take four vertices with weights `a,b,c,d`. Let the first contraction have fibers
`q⁻¹(Q₀)={0,1}`, `q⁻¹(Q₁)={2}`, and `q⁻¹(Q₂)={3}`. Let the second contraction merge `Q₀,Q₁` into `S₀` and send `Q₂` to `S₁`.

| component | fiber character |
|---|---|
| Q₀ | a+b |
| Q₁ | c |
| Q₂ | d |
| S₀, computed directly | a+b+c |
| S₀, computed via Q-level | (a+b)+c |
| S₁ | d |

Thus the direct and staged characters agree, while both component totals sum to `a+b+c+d`.

For edges `0→2`, `1→3`, and `3→0`, first contraction gives `Q₀→Q₁`, `Q₀→Q₂`, and `Q₂→Q₀`. The second contraction gives `S₀→S₀`, `S₀→S₁`, and `S₁→S₀`; direct contraction by the composite map gives exactly the same relation.

## OEIS search

No integer sequence is generated by these universally quantified contraction identities, so an OEIS search is not applicable.

## Counterexample hunt

Potential failure modes were checked conceptually:

* Non-surjective contraction maps cause no failure: empty fibers contribute zero.
* Edges whose endpoints merge become loops; retaining loops is necessary for exact equality of contracted relations.
* No converse path-lifting theorem is claimed, since arbitrary quotient paths can concatenate edges represented by incompatible intermediate vertices.

The Lean proofs cover all finite types and all maps, not merely these examples.
