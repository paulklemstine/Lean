# Aether Quality Upgrade Glossary

| Term | Definition |
|---|---|
| **Depth** | The structural complexity, non-obviousness, and generality of a result. Deep theorems connect concepts, require non-trivial proof strategy, or open new sub-questions. |
| **Impact** | The likelihood that a result advances a famous open problem, enables other theorems, or changes how mathematicians think about a domain. |
| **Correctness floor** | The invariant that all Aristotle-generated Lean files must compile and contain no `sorry`. Non-negotiable, but not sufficient for quality. |
| **Famous-problem subtask** | A decomposed chunk of a named hard problem (e.g., proving a special case, finding an equivalent formulation, tightening a bound). |
| **Cross-domain bridge** | A theorem, technique, or conjecture that transfers ideas between two distinct mathematical domains. |
| **Menu** | The set of direction categories from which Aristotle's selection algorithm may choose; here split 50/50 between famous-problem subtasks and cross-domain bridges. |
| **Aristotle decides** | The principle that the selection algorithm, not the human, picks the exact research target each cycle, within a constrained strategy menu. |
