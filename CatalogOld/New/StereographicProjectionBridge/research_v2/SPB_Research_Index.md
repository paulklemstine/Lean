## 5. Key Research Findings

### Answered Questions

1. **SPB Fourier Transform**: Yes — the SPB basis T_n(x) = tan(n·arctan(x)) under Cauchy measure gives a complete orthogonal system with O(N log N) fast transform via FFT on the circle.

2. **Neural Network Separation**: SPB networks need O(log(1/ε)) parameters for periodic functions, vs O(1/√ε) for ReLU MLPs — an exponential separation.

3. **Automorphism Group**: Klein four-group Z/2Z × Z/2Z, generated by negation (x ↦ −x) and composition with inversion (x ↦ −1/x).

4. **Cocycle Cohomology**: The cocycle c(x,y) = 1/(1−xy) is a coboundary with cobounding cochain f(x) = (1+x²)^{−1/2}. The cohomology class is trivial.

5. **Finite Field Order**: |SPB(𝔽_p)| = p+1 if p ≡ 3 mod 4, p−1 if p ≡ 1 mod 4 — confirmed for all primes p ≤ 97 and explained via norm-1 subgroup theory.
