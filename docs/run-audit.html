F1: "This research cycle established..." — Garbage Concept Titles
263 of 1,222 future directions (21%) have auto-generated titles that describe the CYCLE instead of the RESEARCH TOPIC.

These titles come from Aristotle's FUTURE_DIRECTIONS.md output. The titles describe what the PREVIOUS cycle did, not what the NEXT cycle should investigate. When dispatched, the concept title IS the research direction — so Aristotle receives "prove: This research cycle established a rigorous formal framework..." which is a meta-statement, not a mathematical direction.

The code already caps auto-titled directions at priority 0.60, but they're still being selected because 104 available directions with domain balancing still pushes them to the front. The priority cap isn't enough — the titles themselves are the problem.
F2: All Dispatches → Same Domain (Algebra)

EFFECT Research concentrates in one domain
The available directions span 14 domains, but only Algebra gets attention. The UCB bandit is supposed to balance exploration and exploitation, but with cold-start ∞ everywhere, it collapses to a fixed choice.
