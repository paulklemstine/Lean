## Overview

This project is a multi-disciplinary investigation into **strange loops** — self-referential hierarchical structures that Douglas Hofstadter proposes as the architectural substrate of consciousness. Through computational demonstrations, mathematical analysis, visual art, and scholarly writing, we explore the question: *Can a strange loop be conscious?*

## Three Necessary Conditions for Consciousness

Our research identifies three conditions a strange loop must satisfy:

1. **Self-Representation (SR)**: The system contains a model of itself
2. **Bidirectional Level-Crossing (BLC)**: The model influences the system AND vice versa
3. **Fixed-Point Identity (FPI)**: The loop converges to a stable "I"

## Key Insight

> *Consciousness is what incompleteness feels like from the inside.*

Gödel's theorem guarantees that any self-referential system powerful enough to model itself is necessarily *incomplete* — there are truths about itself it can never capture. This gap between self-model and self may be constitutive of subjective experience.
