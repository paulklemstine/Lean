# Finitely Generated Congruences on Polynomial Semirings: An Idempotent Hilbert Basis Theorem

## Abstract

We present a machine-verified formalization of the theory of finitely generated ring congruences on multivariate polynomial semirings, developed in Lean 4 with Mathlib. Our main results establish that (1) surjective variable elimination preserves finite presentation of ring congruences, and (2) the kernel of a surjective polynomial renaming is finitely generated by variable identification pairs. These results constitute the congruence-level analogue of classical elimination theory and the Hilbert basis theorem, adapted to the semiring setting relevant to tropical and idempotent algebra. All proofs are fully verified by the Lean 4 proof assistant, with no axioms beyond the standard foundations (propext, Classical.choice, Quot.sound).

## 1. Introduction

In classical commutative algebra, the Hilbert basis theorem states that polynomial rings over Noetherian rings are Noetherian, ensuring that every ideal is finitely generated. A fundamental consequence is that elimination ideals — obtained by projecting polynomial systems onto subsets of variables — are finitely generated. This underpins Gröbner basis theory and computational algebraic geometry.

Over semirings that lack subtraction, the notion of ideal becomes inadequate: one cannot form difference elements. Instead, the correct algebraic objects are *congruences* — equivalence relations compatible with ring operations. This shift is essential in tropical geometry, where the coordinate semiring is an idempotent semiring (where a + a = a), and geometric objects are defined by congruences rather than ideals.

We formalize the foundations of this theory:

- **Ring congruence generation** from finite sets of polynomial pairs, using Mathlib's `RingConGen.Rel` inductive type.
- **Variable elimination** via pullback of congruences along polynomial renaming maps.
- **The elimination theorem**: surjective variable maps preserve finite presentation of congruences.
- **Kernel finite generation**: the kernel of a surjective renaming is generated by variable identification pairs.

### 1.1 Relationship to Existing Work

The study of congruences on semirings has roots in lattice theory and universal algebra. In tropical geometry, Giansiracusa and Giansiracusa (2016) introduced the notion of tropical scheme via congruences on polynomial semirings. Lorscheid's blueprint geometry (2018) provides another framework where congruences play the role of ideals.

Our formalization provides machine-verified foundations for this theory. To our knowledge, this is the first formal verification of elimination-type results for semiring congruences.

## 2. Definitions and Setup

### 2.1 Ring Congruences

A **ring congruence** on a ring (or semiring) R is an equivalence relation that is compatible with both addition and multiplication:

- If a ≡ b and c ≡ d, then a + c ≡ b + d
- If a ≡ b and c ≡ d, then a · c ≡ b · d

In Mathlib, this is captured by the type `RingCon R`.

### 2.2 Congruence Generation

Given a binary relation r on R, the **ring congruence generated by r** is the smallest ring congruence containing r. Mathlib provides `RingConGen.Rel r`, an inductive type with six constructors:

```
.of    : r(a, b) → Rel r a b
.refl  : Rel r a a
.symm  : Rel r a b → Rel r b a
.trans : Rel r a b → Rel r b c → Rel r a c
.add   : Rel r w x → Rel r y z → Rel r (w+y) (x+z)
.mul   : Rel r w x → Rel r y z → Rel r (w·y) (x·z)
```

### 2.3 Finite Presentation

A ring congruence C on `MvPolynomial σ S` is **finitely presented** if there exists a finite set R of polynomial pairs such that C equals the congruence generated by R:

```lean
def FinitelyPresentedCongruence (C : RingCon (MvPolynomial σ S)) : Prop :=
  ∃ R : Finset (MvPolynomial σ S × MvPolynomial σ S),
    ∀ f g, C f g ↔ RingConGen.Rel (finsetPairsToRel R) f g
```

### 2.4 Elimination Congruence

For a variable map ι : τ → σ, the **elimination congruence** is the pullback of C along `rename ι`:

```lean
def eliminateCongruence (ι : τ → σ) (C : RingCon (MvPolynomial σ S)) :=
  C.comap (MvPolynomial.rename ι)
```

This means f ≡_elim g if and only if rename(ι)(f) ≡_C rename(ι)(g).

## 3. Main Results

### 3.1 Transport Under Ring Homomorphisms

**Theorem (map_RingConGen_rel).** Let φ : A →+* B be a ring homomorphism and r a relation on A. If RingConGen.Rel r a b, then RingConGen.Rel r' (φ a) (φ b), where r' is the image relation.

This is proved by straightforward induction on the derivation tree, using the ring homomorphism properties of φ (preserves + and ×).

### 3.2 Pullback Under Surjections

**Theorem (pullback_RingConGen_of_surjective).** Let φ : A →+* B be a surjective ring homomorphism and r a relation on B. If RingConGen.Rel r (φ a) (φ b), then RingConGen.Rel r' a b, where r'(x,y) holds when either r(φ x, φ y) or φ x = φ y.

The proof generalizes to arbitrary elements x, y ∈ B (not just images of a, b) and proceeds by induction on the derivation. The key insight for the add case: given a proof of (w+y) ≡ (x+z) with φ(a) = w+y and φ(b) = x+z, we choose preimages w', x', y', z' of w, x, y, z (using surjectivity), connect a to w'+y' and b to x'+z' via the kernel relation, and use the induction hypothesis for the sub-derivations.

Notably, this theorem requires no axioms beyond the logical framework — it is proved entirely constructively relative to the surjectivity hypothesis.

### 3.3 Kernel Finite Generation

**Theorem (kernel_rename_finitely_generated).** For a surjective ι : τ → σ (with τ and σ finite types), the kernel of rename(ι) — the relation "rename(ι)(f) = rename(ι)(g)" — is finitely generated as a ring congruence by the pairs {(X_t, X_collapse(t)) | t ∈ τ}, where collapse : τ → τ maps each variable to the canonical representative of its ι-fiber.

The proof introduces a key lemma:

**Lemma (poly_congr_collapsed).** For any polynomial f, f ≡_K rename(collapse)(f), where K is the kernel generator set.

This is proved by induction on f using `MvPolynomial.induction_on`:
- Constants are fixed by rename, so reflexivity applies.
- For f₁ + f₂: use the induction hypothesis and the .add constructor.
- For f₁ · X_t: use the IH for f₁, the generator (X_t, X_collapse(t)), and .mul.

The main theorem then follows: if rename(ι)(f) = rename(ι)(g), then rename(collapse)(f) = rename(collapse)(g) (since collapse = surjSection ∘ ι), and by the lemma, f ≡_K rename(collapse)(f) = rename(collapse)(g) ≡_K g.

### 3.4 The Elimination Theorem

**Theorem (elimination_fg).** For a surjective ι : τ → σ (with τ, σ finite), if C is a finitely presented congruence on MvPolynomial σ S, then eliminateCongruence(ι, C) is finitely presented on MvPolynomial τ S.

The proof constructs explicit generators for the elimination congruence:

1. **Preimage generators**: For each generating pair (p, q) ∈ R of C, choose preimages f_p, g_q under rename(ι) (using surjectivity) to form the pair (f_p, g_q).

2. **Kernel generators**: The pairs {(X_t, X_collapse(t)) | t ∈ τ} from the kernel theorem.

3. **Combined set**: eliminationGenerators = preimageGenerators ∪ kernelGenerators.

The backward direction (these generators are valid) follows by checking that each generator pair maps correctly under rename(ι): preimage pairs map to original generators, kernel pairs map to equal elements.

The forward direction (these generators suffice) uses the pullback theorem: any derivation of rename(ι)(f) ≡ rename(ι)(g) from R pulls back to a derivation of f ≡ g from the relation "r ∘ rename(ι) ∨ ker(rename(ι))". Each base case of this pulled-back relation can be resolved using the preimage and kernel generators.

## 4. Discussion: Making Tropical Algebra Computable

### For the General Reader

Imagine you have a system of equations, but instead of ordinary arithmetic, you're using a strange number system where "addition" means "take the maximum" and "multiplication" means "add." This is the *tropical semiring*, and it appears naturally in optimization, scheduling theory, and even machine learning (ReLU neural networks compute piecewise-linear functions that are tropical rational expressions).

In ordinary algebra, we can solve systems of polynomial equations using techniques like Gaussian elimination and Gröbner bases. These methods work because polynomial rings over fields are *Noetherian* — every ideal is finitely generated. This is Hilbert's basis theorem, one of the cornerstones of modern algebra.

But tropical algebra is fundamentally different. There's no subtraction (you can't "un-max" two numbers), so the usual notion of ideal doesn't work. Instead, we use *congruences* — equivalence relations that respect the algebraic operations. Two tropical polynomials are "congruent" if they can be identified through a chain of rewrites using some basic equivalences.

Our work proves that a key property of classical algebra carries over to this tropical world: **if you start with finitely many basic equivalences and project away some variables, you still get a finitely presented system**. This is the tropical analogue of the fact that eliminating variables from a finite system of equations gives another finite system.

Why does this matter? Because it means tropical polynomial systems are computationally tractable. Given a finite description of a tropical geometric object, we can algorithmically project it, intersect it, and reason about it — all while maintaining finite descriptions. This opens the door to verified algorithms for tropical optimization, scheduling, and neural network analysis.

### An Analogy

Think of congruences like the rules of a board game. The "generators" are the basic moves. The "congruence generated by the generators" is everything you can reach by combining basic moves. Our theorem says: if you have finitely many basic moves in a larger game, and you restrict attention to a subset of the game board (eliminating some variables), the restricted game also has finitely many effective basic moves. You don't lose computability by zooming in.

### Historical Context

David Hilbert proved his basis theorem in 1890, shocking the mathematical world with a non-constructive existence proof. His advisor, Paul Gordan, reportedly declared "This is not mathematics; this is theology!" The constructive content of Hilbert's theorem has been a subject of ongoing research ever since.

Our formalization is partially constructive: the pullback theorem and transport lemmas are proved without Classical.choice, while the elimination theorem uses it only for choosing preimages (surjectivity witnesses). This suggests that with additional computational structure on the semiring, fully constructive versions may be achievable.

## 5. Applications

### 5.1 Tropical Geometry
Tropical varieties are defined by congruences on tropical polynomial semirings. Our elimination theorem provides the algebraic backbone for computing images of tropical varieties under coordinate projections — a fundamental operation in tropical computational geometry.

### 5.2 Neural Network Verification
ReLU neural networks compute piecewise-linear functions that can be expressed as tropical rational functions. Verifying properties of neural networks (robustness, equivalence) can be cast as congruence membership problems in tropical polynomial semirings. Our certificate framework provides a basis for verified neural network analysis.

### 5.3 Optimization and Scheduling
The max-plus algebra (a specific idempotent semiring) is used in discrete event systems, scheduling, and operations research. Congruence-based reasoning provides a framework for certifying optimality and equivalence of scheduling policies.

## 7. Conclusion

We have formalized the core theory of finitely generated ring congruences on polynomial semirings, proving the elimination theorem for surjective variable maps. This establishes the algebraic infrastructure needed for computational tropical geometry and verified reasoning over idempotent semirings.

Key open problems for future formalization include:
1. The injective elimination case (the full Hilbert basis analogue for congruences)
2. Gröbner-style canonical bases for congruence generation
3. Decidability bounds for congruence membership
4. The tropical Nullstellensatz via finitely presented congruences
