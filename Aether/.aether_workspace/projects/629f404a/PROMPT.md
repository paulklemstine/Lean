## Research Task: Stone-Weierstrass universal approximation for EML activation algebras on compact spaces

Research Mode: PROVE

Work in a new file
`EML/StoneWeierstrass.lean`.

The goal is to turn the existing closure properties of the EML-generated function class into a genuine density theorem in the uniform norm. The cleanest route is to formalize a reusable Stone–Weierstrass statement for real-valued subalgebras of `C(X, ℝ)` and then instantiate it for the EML algebra once point-separation and constant containment have been established.

A strong deliverable is a two-stage development:

1. a general Stone–Weierstrass theorem for a subalgebra `A : Subalgebra ℝ C(X, ℝ)` on a compact Hausdorff space `X`;
2. an EML-specific corollary showing that the subalgebra generated by EML primitives is dense, first on `[0,1]` or `Fin n → Icc (0:ℝ) 1`, and then in a more abstract compact-space form if the hypotheses can be packaged cleanly.

### Proof strategy

1. **First locate and exploit Mathlib’s Stone–Weierstrass theorem rather than reproving it from scratch.**  
   There is typically already a theorem for subalgebras/subrings of `C(X, ℝ)` whose closure is top under the hypotheses “contains constants” and “separates points.” Your first task is to identify the exact API and adapt your theorem statement to match it. The main work should be in bridging your hypotheses into the theorem’s expected form, not rebuilding the full functional-analytic proof manually.

2. **Package point separation in the exact form Mathlib wants.**  
   Many Stone–Weierstrass lemmas use `Set.SeparatesPoints` or a variant over subalgebras. If your EML closure results naturally produce a statement
   ```lean
   ∀ x y, x ≠ y → ∃ f, f x ≠ f y
   ```
   then prove a helper lemma converting this to the library notion:
   ```lean
   lemma separatesPoints_of_explicit
       {X : Type*} [TopologicalSpace X]
       (A : Set C(X, ℝ))
       (h : ∀ x y, x ≠ y → ∃ f ∈ A, f x ≠ f y) :
       Set.SeparatesPoints A := ...
   ```
   This helper will make the EML instantiation much cleaner.

3. **Exploit that subalgebras contain constants automatically.**  
   If you work with `Subalgebra ℝ C(X, ℝ)`, the constant functions are already present via `algebraMap`; do not carry an unnecessary separate hypothesis unless the theorem you are instantiating is for a bare set of functions. A useful lemma is:
   ```lean
   lemma const_mem_subalgebra
       {X : Type*} [TopologicalSpace X]
       (A : Subalgebra ℝ C(X, ℝ)) (c : ℝ) :
       ContinuousMap.const X c ∈ A := ...
   ```
   This is likely just `show algebraMap ℝ C(X, ℝ) c ∈ A`.

4. **Pass from closure equality to explicit ε-approximation via density.**  
   Once you have `A.topologicalClosure = ⊤`, derive the constructive approximation statement using `mem_closure_iff` or the density API. In practice, the theorem
   ```lean
   f ∈ A.topologicalClosure
   ```
   should yield that every neighborhood of `f` meets `A`; choose the open ball of radius `ε`. If needed, first prove:
   ```lean
   lemma mem_closure_subalgebra_iff_uniform
       {X : Type*} [TopologicalSpace X] [CompactSpace X]
       (A : Subalgebra ℝ C(X, ℝ)) (f : C(X, ℝ)) :
       f ∈ A.topologicalClosure ↔ ∀ ε > 0, ∃ g : A, ‖f - g.1‖ < ε
   ```
   This lemma is the real bridge from abstract closure to universal approximation.

5. **For the concrete EML corollary, separate the algebraic and geometric inputs.**  
   Do not entangle the Stone–Weierstrass proof with the specifics of EML primitives. Instead prove:
   - `EMLSubalgebra X` is a `Subalgebra ℝ C(X, ℝ)`;
   - EML primitives and closure rules imply the relevant generators lie in `EMLSubalgebra X`;
   - a dedicated lemma `eml_separates_points_I01` or `eml_separates_points_cube` proving explicit point separation on the chosen compact domain.  
   Then the universal approximation theorem becomes a one-line application of the abstract result.

### How to connect this to the EML algebra

The research value is not merely in restating Stone–Weierstrass abstractly, but in showing that the verified EML operations generate a subalgebra rich enough to be dense. So aim for one of the following concrete instantiations:

- **Minimal viable theorem:** assume an abstract `Aeml : Subalgebra ℝ C(X, ℝ)` satisfying a point-separation hypothesis justified by prior EML closure results, and conclude density.
- **Stronger theorem:** define `EMLSubalgebra X` as the subalgebra generated by EML primitives and prove point separation on `I01` or cubes from explicit generators such as identity/coordinates, affine maps, or logistic/log-exp transforms already in the project.
- **Best theorem:** prove the cube version and then state that any continuous target on a compact cube can be uniformly approximated by EML functions, giving a genuine universal approximation theorem.

If exact realization of identity or coordinate maps by EML primitives is not yet available, isolate that as a clearly named lemma rather than leaving the density theorem vague:

```lean
axiom eml_contains_id_I01 : id_I01 ∈ EMLSubalgebra I01
```

or better, a proved theorem if possible. Then Stone–Weierstrass turns this single representability fact into a full approximation theorem.

### Significance

This result is the missing bridge from the project’s existing “EML functions are closed under a rich algebra of operations” to a classical and publishable approximation theorem. Closure alone says the function class is stable; Stone–Weierstrass says it is expressive enough to approximate every continuous target on compact domains. That is the mathematically decisive transition from algebraic structure to universality.

Formally, this theorem will also give a reusable infrastructure layer: any future activation family in the project can inherit universal approximation by proving only two facts—membership in a subalgebra of `C(X, ℝ)` and point separation. So the payoff is both conceptual and architectural: it upgrades the EML line from a collection of closure lemmas to a general approximation framework in Lean.
