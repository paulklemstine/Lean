## Core Vision

### Central Conjecture
Let `L` be a finite or image-finite labelled transition system, let `ExpAct(L)` denote the site/cover category of local observational neighborhoods generated by actions or traces, and let `Ω` be a presheaf of local bisimulation witnesses. Then:

> **Conjecture.** `H¹(ExpAct(L), Ω) = 0` if and only if `L` satisfies the image-finiteness condition that guarantees modal indistinguishability implies bisimilarity in the Hennessy–Milner theorem.  
> Moreover, when `H¹` is nontrivial, its classes classify obstructions to extending compatible local bisimulation equivalences to a global bisimulation relation.

This is ambitious. In this cycle, formalize and prove the strongest finite/combinatorial version you can, especially for explicit finite covers where Čech 1-cohomology is computable.

## Exact Theorem Targets

### Theorem 1: Presheaf Descent of Local Bisimulations
Build on:
- `Pythagorean/TemporalAdjunction/Defs.lean` — `TraceSieve`
- `Pythagorean/TemporalAdjunction/Theorems.lean` — `sieve_nonBoolean`
- `Catalog/Pythagorean/YonedaBisimulation/Properties.lean` — `bisimUnion_is_bisimulation`

**Mathematical statement.**
For a finite family of observational patches `U : ι → Patch L`, if on each `U i` we have a local bisimulation relation `R_i`, and these agree on overlaps `U i ∩ U j`, then the union relation glues to a bisimulation on the union patch.

This is the descent theorem that makes the entire cohomological viewpoint legitimate.

### Suggested Lean 4 type signature
```lean
theorem localBisim_family_glues
  {State Act ι : Type _}
  [Fintype ι]
  (L : LTS State Act)
  (U : ι → Patch L)
  (R : ∀ i, LocalBisimSection L (U i))
  (hcompat :
    ∀ i j, restrictLocalBisim (U i) (patchInter (U i) (U j)) (R i) =
           restrictLocalBisim (U j) (patchInter (U i) (U j)) (R j)) :
  ∃ G : LocalBisimSection L (patchSUnion U),
    ∀ i, restrictLocalBisim (patchSUnion U) (U i) G = R i
```

### Why it matters
This is the formal descent principle: local behavioral equivalences can be glued exactly when overlap data is coherent. It is the process-algebra analogue of gluing local sections of a sheaf.

### Theorem 2: Vanishing of Čech 1-Cohomology Implies Gluing
Define a finite Čech 1-cocycle object for your bisimulation obstruction presheaf. Then prove:

**Mathematical statement.**
If every Čech 1-cocycle for a cover is a coboundary, then every compatible local family of bisimulation witnesses extends to a global witness.

### Suggested Lean 4 type signature
```lean
theorem cechH1_vanishes_implies_gluing
  {State Act ι : Type _}
  [Fintype ι]
  (L : LTS State Act)
  (U : ι → Patch L)
  (Ω : BisimObstructionPresheaf L)
  (hH1 :
    ∀ z : CechOneCocycle L U Ω, ∃ c : CechZeroCochain L U Ω, cechδ0 L U Ω c = z) :
  ∀ s : CompatibleLocalFamily L U Ω, ∃ g : GlobalSection L Ω, realizesFamily L U Ω g s
```

### Why it matters
This theorem is the local-to-global principle in exact obstruction language. It turns cohomology from metaphor into mechanism.

### Theorem 3: Nontrivial 1-Cocycle Produces a Genuine Obstruction
You need a converse-style obstruction theorem: if a cocycle class is nontrivial, gluing fails.

**Mathematical statement.**
For a finite cover `U`, if a compatible transition family determines a 1-cocycle not cohomologous to zero, then there is no global bisimulation witness restricting to that family.

### Suggested Lean 4 type signature
```lean
theorem nontrivial_obstruction_prevents_globalization
  {State Act ι : Type _}
  [Fintype ι]
  (L : LTS State Act)
  (U : ι → Patch L)
  (Ω : BisimObstructionPresheaf L)
  (s : CompatibleLocalFamily L U Ω)
  (hz : ¬ ∃ c : CechZeroCochain L U Ω, cechδ0 L U Ω c = familyCocycle L U Ω s) :
  ¬ ∃ g : GlobalSection L Ω, realizesFamily L U Ω g s
```

### Why it matters
This is the first theorem that says **cohomology class = obstruction**, not just “cohomology is interesting.” It is the conceptual heart of the project.

## Proof Strategy Architecture

You must give Aristotle-level proof architecture, not vague hints.

### Strategy A: Direct finite Čech descent via explicit cocycles
**Most promising for this cycle.**
1. Define finite 0-cochains and 1-cocycles on a cover of patches.
2. Encode a compatible local family as a 1-cocycle measuring mismatch on overlaps.
3. Prove:
   - zero cocycle ⇒ exact agreement on overlaps,
   - coboundary adjustment ⇒ reparametrization of local witnesses,
   - vanishing class ⇒ existence of a glued global witness.

**Why this is best:** it avoids the technical overhead of general sheaf cohomology while preserving the obstruction-theoretic essence. It is formalizable in Lean 4 with finite types and explicit equalities.

### Strategy B: Sheaf-style descent using union-of-bisimulations
1. Use `bisimUnion_is_bisimulation` as the engine for gluing.
2. Define compatibility on overlaps as equality of restrictions.
3. Prove that exact compatibility implies union is a bisimulation on the union patch.
4. Then package failure of exact compatibility into a cochain complex.

**Why this is powerful:** it leverages existing catalog theorems directly and gives a clean route from known process algebra to new topology-inspired invariants.

### Strategy C: Nerve/simplicial approach
1. Construct the nerve of the observational cover.
2. Realize 0-, 1-, and 2-simplices as patches, overlaps, and triple overlaps.
3. Define cocycle equations simplicially.
4. Derive the obstruction theorem from the simplicial identity `δ¹ ∘ δ⁰ = 0`.

**Why this is conceptually elegant:** it aligns with algebraic topology and could later support persistent or higher-dimensional invariants.  
**Why it is less promising right now:** more category/simplicial overhead in Lean.

Recommendation: **Start with Strategy B, then package into Strategy A.** Use Strategy C only if the infrastructure becomes unexpectedly smooth.
