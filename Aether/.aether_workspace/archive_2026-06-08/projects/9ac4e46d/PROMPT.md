### Theorem 1: Strict descent / termination witness
Every one-step rewrite strictly decreases the new complexity measure.

```lean
theorem rewrite1_decreases_measure
    {t u : TensorExpr} :
    Rewrite1 t u → distPotential u < distPotential t
```

This theorem is the engine of termination. It must not be proved by brute-force case enumeration hidden behind automation; it should use structured case analysis on the rewrite derivation and multi-step arithmetic comparisons.

A stronger variant is welcome:

```lean
theorem rewriteStar_measure_monotone
    {t u : TensorExpr} :
    RewriteStar t u → distPotential u ≤ distPotential t
```

and then strictness for nontrivial steps.

### Theorem 2: Local confluence modulo AC
Any critical pair produced by one-step reductions is joinable up to AC-equivalence.

```lean
theorem local_confluence_mod_AC
    {t u v : TensorExpr} :
    Rewrite1 t u → Rewrite1 t v →
    ∃ w, RewriteStar u w ∧ RewriteStar v w
      ∨ ∃ w1 w2, RewriteStar u w1 ∧ RewriteStar v w2 ∧ ACEq w1 w2
```

If your formulation is cleaner using a dedicated `JoinableModAC` predicate, do that:

```lean
def JoinableModAC (u v : TensorExpr) : Prop :=
  ∃ u' v', RewriteStar u u' ∧ RewriteStar v v' ∧ ACEq u' v'

theorem local_confluence_mod_AC
    {t u v : TensorExpr} :
    Rewrite1 t u → Rewrite1 t v → JoinableModAC u v
```

This is the mathematically decisive step: explicitly analyze overlaps of the 8 distributivity rules and prove all critical peaks are joinable.

### Theorem 3: Confluence modulo AC / uniqueness of normal forms
Assuming the reduction is terminating and locally confluent modulo AC, conclude uniqueness of normal forms modulo AC.

```lean
theorem unique_normal_form_mod_AC
    {t n₁ n₂ : TensorExpr} :
    RewriteStar t n₁ →
    RewriteStar t n₂ →
    IsNormal n₁ →
    IsNormal n₂ →
    ACEq n₁ n₂
```

If needed, first prove a confluence theorem:

```lean
theorem confluent_mod_AC :
  ∀ {t u v : TensorExpr},
    RewriteStar t u → RewriteStar t v → JoinableModAC u v
```

and then derive unique normal forms.

This theorem is the conceptual summit. Once established, normalization is deterministic up to the intended scalar-addition symmetry, and therefore suitable as a certified canonicalization procedure.

## Proof architecture: 3 viable strategies

You should pursue one main route, but document at least two alternatives.

### Strategy A: Termination + critical pairs + Newman’s lemma modulo AC
**Most promising.**

1. **Define a strict well-founded measure** `distPotential`.
   - Count distributivity redexes with a weighted subtree measure.
   - Show each of the 8 rules strictly reduces this measure.
   - Derive strong normalization / absence of infinite rewrite chains.

2. **Prove local confluence modulo AC by critical pair analysis.**
   - Enumerate overlaps among the 8 rules.
   - Classify them into:
     - disjoint redexes,
     - nested redexes,
     - genuine critical overlaps.
   - For each genuine overlap, build explicit joining reductions, possibly after scalar-addition reassociation/permutation.

3. **Invoke Newman’s lemma** (or formalize the needed variant).
   - Termination + local confluence modulo AC yields confluence modulo AC.
   - Deduce uniqueness of irreducible forms modulo AC.

**Why this is most promising:** the fragment is finite, oriented, and syntactic. The critical-pair space should be manageable, and the measure argument is aligned with your conjectured redex-counting idea.

---

### Strategy B: Canonicalization-by-evaluation
1. Define a semantics-preserving map from tensor syntax into a **multiset-polynomial normal form**:
   - flatten scalar sums into multisets,
   - recursively distribute tensor constructors into a canonical combinatorial object.

2. Prove every rewrite step preserves this semantic normal object.

3. Show the algorithm `normalizeCanon` computes exactly that object reified back into syntax.
   - Then uniqueness follows because two normal forms computing the same canonical object must be AC-equivalent.

**Why it is powerful:** this bypasses some explicit critical-pair checking by proving canonicity through a semantic invariant.  
**Why it is harder:** reification and semantic adequacy may require more infrastructure than direct rewriting.

---

### Strategy C: Parallel reduction / diamond property
1. Define a **parallel one-step reduction** contracting all independent redexes at once.
2. Prove parallel reduction has the diamond property modulo AC.
3. Show ordinary multi-step reduction and parallel reduction generate the same congruence closure.
4. Deduce confluence modulo AC and unique normal forms.

**Why it is elegant:** parallel reduction often simplifies commuting-redex arguments.  
**Why it is less likely to finish first:** the modulo-AC bookkeeping may be more elaborate than direct critical-pair analysis.

## Concrete proof steps you should execute

### Step 1: Build the measure carefully
A naïve size measure may fail because distribution can increase raw syntax size. Instead define something like:

- `badness t`: number of additive nodes appearing beneath multiplicative/tensor constructors where a rewrite can fire,
- `exposure t`: weighted sum of depths of such bad additive nodes,
- `distPotential t := (badness t, exposure t, size t)` lexicographically.

Then prove:

```lean
theorem rewrite1_badness_drop_or_exposure_drop
    {t u : TensorExpr} :
    Rewrite1 t u →
    badness u < badness t ∨
      (badness u = badness t ∧ exposure u < exposure t)
```

From this derive strict lexicographic descent.

This is exactly the sort of deep proof that should use induction over term structure, `rcases` on rewrite derivations, and `calc` chains on inequalities.

---

### Step 2: Formal critical-pair analysis
For each pair of rules, determine whether overlaps are:
- impossible by sort discipline,
- trivial by disjointness,
- joinable by one or two further rewrite steps,
- joinable only modulo `ACEq`.

You should define a reusable theorem schema:

```lean
theorem joinable_of_disjoint_redexes
    ...
```

and then reserve explicit hand-crafted proofs for the genuinely overlapping cases.

If the rule family is encoded inductively, use inversion lemmas to reduce impossible combinations. This is an ideal place for `rcases`, `cases`, and contradiction arguments.
