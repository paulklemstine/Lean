# Future Directions

Derived from the analysis and adversarial review of this cycle.  What was
proved (all `sorry`-free, in `Catalog/NumberTheory/`):

* `VietaInjectiveFamilies.lean` — the six-element symmetry orbit of
  `vietaValue a b = −3ab(a+b)`, a residual collision inside the fundamental
  domain (`f(1,5) = f(2,3)`), the divisor bound for the multiplicity of a Vieta
  value, two injective subfamilies (the spine `a = 1`, and the two-parameter
  dyadic family `a = 2^i`, `b` odd, injective via the `2`-adic valuation), and
  the counting bounds `⌊√(N/6)⌋` (one-sided) and `2⌊√(N/6)⌋` (both signs), all
  with three nonzero cubes.
* `CubeDigitFamilies.lean` — the greedy cube-digit principle, an injective
  three-scale box, and the counting bound `≫ N^{19/27}` for sums of three
  positive cubes (`19/27 ≈ 0.7037`), including a real-analytic version valid
  for all `N` and the explicit comparison `100√N ≤ t¹⁹`.
* `VietaEscape.lean` — every Vieta value is divisible by `6`, hence the Vieta
  counting function is sandwiched `⌊√(N/6)⌋ ≤ #Vieta(N) ≤ ⌊N/6⌋`; and a
  residue-restricted cube-digit family producing `≥ 136 t¹⁹` integers below
  `10⁸ t²⁷` that are sums of three positive cubes and are *not* Vieta values.
* `GreedyCubeTower.lean` — the induction generalising the cube-digit principle
  to `s` cubes: exponent `1 − (2/3)^s` (proved both at the sample scales and, in
  real-analytic form `tower_count_rpow`, for every `N ≥ towerConst s`),
  converging to `1`; the cases `s = 2, 3, 4` give `5/9`, `19/27`, `65/81`.

Analysis of the gap: the truth for the Vieta value set is `≍ N^{2/3}`
(experiment: `≈ 0.53 N^{2/3}`), while the provable injective subfamilies only
reach `N^{1/2}`, because collisions are governed by divisors of the value, and
sparsifying the first parameter to make the value determine it (valuations,
smooth numbers) makes the sum `Σ_a (N/a)^{1/2}` converge.  This is a genuine
"needs a different definition" failure, not a false statement.

---

## Conjecture 1 — Divisor-Controlled Vieta Density

For every `ε > 0` there is `c(ε) > 0` such that the number of integers of
absolute value `≤ N` of the form `3ab(a+b)` is at least `c(ε) N^{2/3−ε}`.

**The key insight is** that the proved bound
`#{(a,b) : 3ab(a+b) = v} ≤ d(v)` converts the problem into a divisor-moment
estimate: the `N^{2/3}` lattice points in the region `3ab(a+b) ≤ N` collapse
only by the divisor function, so any sub-polynomial bound `d(v) ≪_ε v^ε`
immediately yields the conjecture.

**Why now?**  `vieta_multiplicity_le_card_divisors` is already formalised, and
`d(n) ≪_ε n^ε` is an elementary multiplicative-function argument that Mathlib
does not yet have but which is squarely within reach; nothing deeper (no
class-field theory, no Thue equations) is required for the `2/3 − ε` bound.

## Conjecture 2 — Exact Vieta Counting Asymptotic

`#{v : |v| ≤ N, v = 3ab(a+b) for some integers a,b}` is asymptotic to
`κ N^{2/3}` with `κ ≈ 1.05` (empirically `0.53` on the positive side, doubled by
sign symmetry), and the second-order term is `O(N^{1/2} log N)`.

**The key insight is** that the binary cubic form `3ab(a+b)` has an
automorphism group of order exactly `6` (the `S₃`-orbit proved in
`vietaValue_orbit`) and class number one in the relevant sense, so its value set
should behave like a generic lattice count divided by `6`.

**Why now?**  The orbit theorem and the divisor multiplicity bound are
formalised; the missing input is an average (not maximal) divisor bound, i.e. a
second-moment count `Σ_{v ≤ N} r(v)² ≪ N^{2/3} log^c N`, which is a
Cauchy–Schwarz computation over a two-dimensional region.

## Conjecture 3 — Greedy Barrier Is Sharp at `1 − (2/3)^s`

Any family of sums of `s` positive cubes whose injectivity is certified purely
by nested "remainder below the cube gap" conditions has counting exponent at
most `1 − (2/3)^s`, and this is attained (proved: `tower_count`).  Breaking it
for `s = 2` (i.e. beating `N^{5/9}` for sums of two positive cubes) is
equivalent to a quantitative taxicab-rarity statement:
`#{v ≤ N : r₂(v) ≥ 2} = o(N^{2/3})`.

**The key insight is** that the greedy scheme is exactly an optimisation of
`Σ_i (2/3)^i` over the nesting depth, so the only way to gain is to prove that
coincidences `x³+y³ = x'³+y'³` are rare, rather than to forbid them by size.

**Why now?**  The `s`-fold induction is formalised, so the extremal problem is
now a statement about a concrete formal object; and taxicab rarity is provable
in the weak form needed (`o(N^{2/3})`) by an elementary counting of solutions of
a genus-one curve in boxes.

## Conjecture 4 — Escape Density of Non-Vieta Cube Sums

For every residue `r ∉ 6ℤ` the number of integers `n ≤ N` with `n ≡ r (mod 6)`
which are sums of three positive cubes is `≫ N^{19/27}`, and in fact
`≫ N^{1−(2/3)^3}` uniformly in `r`; consequently the Vieta family, whose values
all lie in `6ℤ` (proved: `six_dvd_vietaValue`), misses a positive-density
portion of the three-cube values in every non-trivial class.

**The key insight is** that `n³ ≡ n (mod 6)` lets one prescribe the residue of a
cube sum by prescribing the residues of the roots, at the cost of an explicit
constant only, so the greedy box construction is compatible with arbitrary
congruence conditions.

**Why now?**  The case `r = 3` is already proved (`escape_count`); the general
case only needs the box to be re-centred at roots `≡ r_i (mod 6)`, which the
existing gap lemmas support verbatim.

## Conjecture 5 — Tower Exponents Meet the Wooley Regime

For `s = 3` the elementary tower gives `19/27 ≈ 0.7037`; the conjecture is that
a hybrid of the tower with one divisor-controlled Vieta layer gives
`N^{3/4}` for sums of three positive cubes, i.e. the first elementary bound
past `0.75` without circle-method input.

**The key insight is** that the bottom layer of the tower wastes the most:
it contributes only `y^{2/3}` choices where a divisor-controlled Vieta layer
would contribute `y^{1−ε}` values in the same range.

**Why now?**  Conjecture 1 supplies exactly the missing layer, and the tower
induction (`greedy_tower`) is already parameterised by "a family of values below
`B`", so a stronger bottom layer can be substituted without redoing the
induction.
