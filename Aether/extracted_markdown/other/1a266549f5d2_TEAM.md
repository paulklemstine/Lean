# Research Team: The Tetrabranch Pythagorean Spacetime Project

## Mission Statement

Investigate the hypothesis that the classical 3-branch Berggren Pythagorean triple tree
is naturally embedded in (3+1)-dimensional Minkowski spacetime, where a **4th branch** —
corresponding to the temporal/lightlike dimension — completes the structure. This 4th branch
represents photon worldlines: the start and end of light, where the spacetime interval is zero.
