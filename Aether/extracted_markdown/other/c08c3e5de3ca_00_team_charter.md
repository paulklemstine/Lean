# Project CHIMERA — Charter & Team Roster

## Mission
Identify mathematical structures that sound like science fiction but are
rigorously provable, then map each one to a technology prototype that could be
built **today** (TRL ≥ 4). For every claim we make, we produce:

1. A precise mathematical hypothesis.
2. A computational or physical experiment to test it.
3. A formal Lean 4 / Mathlib proof of the core theorem (where feasible).
4. An engineering sketch showing how to turn the result into hardware or software.

## Virtual Research Team

| Callsign | Role | Focus |
|-----------|------|-------|
| **GEOMETER** | Differential & algebraic geometry | Curved-space computing, metamaterials |
| **TOPOLOGIST** | Algebraic topology / TDA | Hidden-dimension detection in data |
| **ALGEBRAIST** | Abstract algebra / number theory | Quaternion & Clifford-algebra processors |
| **PHYSICIST** | Mathematical physics | Transformation optics, analogue gravity |
| **ENGINEER** | Signal processing & antenna design | Fractal antennas, hyperbolic embeddings |
| **FORMALIST** | Lean 4 / Mathlib | Machine-checked proofs of core claims |

## Ground Rules
- Every hypothesis gets an ID: `HYP-CHIMERA-###`.
- Every experiment gets an ID: `EXP-CHIMERA-###`.
- We iterate: propose → test → revise → re-test.
- "Validated" means either (a) formal proof, (b) reproducible numerical
  experiment, or (c) physical prototype measurement.
