# Certified Robustness for Instant-Runoff Classifiers via Tropical Lipschitz Bounds

## Abstract

We develop a formally verified robustness theory for deterministic, tie-free
instant-runoff voting (IRV) classifiers whose multiclass scores are generated by
Lipschitz maps — in particular, tropical (max-plus affine) and GL₃ Satake score
architectures. The core result shows that when every round of the IRV elimination
has a score gap of at least γ between the eliminated candidate and the runner-up,
any uniform perturbation of scores bounded by ε < γ/2 preserves the entire
elimination order and hence the winner. Composing with a K-Lipschitz bound on the
score map yields an explicit L∞ input robustness radius of r = γ/(2K). All results
are machine-verified in Lean 4 with Mathlib, with zero remaining `sorry` statements.

## 1. Introduction

Machine learning classifiers are increasingly deployed in high-stakes settings
where adversarial robustness is essential. A natural approach to certified
robustness is to combine:

1. **Score-level Lipschitz bounds** — typically derived from the architecture of
   the scoring function (e.g., tropical polynomial or max-plus affine maps) — with
2. **Decision-level stability theorems** — showing that the discrete prediction
   (class label) is invariant under bounded score perturbations.

For standard argmax classifiers, step (2) is trivial: the argmax is stable
whenever the margin between the top class and the runner-up exceeds 2ε. But for
more complex decision rules — such as instant-runoff voting (IRV), which
sequentially eliminates the weakest candidate — the decision depends on an entire
recursive chain of comparisons, and score-level robustness does not immediately
translate to decision-level robustness.

This paper bridges that gap. We formalize a **recursive gap certificate** that
tracks the minimum score separation at every elimination round, and prove that
when this certificate exceeds 2ε, the entire elimination sequence — not just the
final winner — is preserved. The proof proceeds by induction on the cardinality
of the active candidate set, with the key algebraic step being a one-round
perturbation lemma showing that a gap of γ shrinks by at most 2ε under uniform
ε-perturbation.

### 1.1 Contributions

- **One-round perturbation lemma** (Lemma 3.1): the algebraic heart of the

- **Elimination-order stability theorem** (Theorem 4.1): full inductive proof

## 2. Definitions

### 2.1 Sequential Elimination

Fix m candidates indexed by `Fin m`. Given a score vector `v : Fin m → ℝ` and
an active set `S ⊆ Fin m`, the **round loser** is the unique candidate in S
achieving the minimum score:

$$\text{roundLoser}(S, v) = \arg\min_{i \in S} v(i)$$

The **elimination order** is defined recursively: if |S| = 1, the single
remaining candidate is the winner; otherwise, eliminate the round loser and
recurse on `S \ {roundLoser(S, v)}`.

The **IRV winner** is the last candidate in the elimination order, equivalently
the output of the recursive process when started from the full candidate set
`S = \{0, 1, \ldots, m-1\}`.

### 2.2 Gap Certificates

**Definition (HasGapAtLeast).** We say candidate i has gap at least γ in S
under v if `i ∈ S` and `v(i) + γ ≤ v(j)` for all `j ∈ S \ {i}`.

**Definition (EliminationGapCertified).** The elimination of v on S is
gap-certified with parameter γ if:
- When |S| = 1: trivially true.
- When |S| > 1: the round loser has gap at least γ, and the recursive
  elimination on `S \ {loser}` is also gap-certified with parameter γ.

This recursive structure is designed to make inductive proofs straightforward.

### 2.3 Perturbation Model

We model perturbations as uniform coordinatewise bounds:

$$\forall i,\; |v'(i) - v(i)| \le \varepsilon$$

This is the natural model for L∞ score perturbations. For a K-Lipschitz score
map `s : ℝ^d → ℝ^m` with respect to the L∞ norm, an input perturbation
`‖x' - x‖_∞ ≤ r` yields score perturbation at most `ε = Kr`.

## 3. One-Round Perturbation Lemma

**Lemma 3.1 (Gap Preservation).** If `HasGapAtLeast S v i γ` and
`∀ k, |v'(k) - v(k)| ≤ ε`, then for all `j ∈ S` with `j ≠ i`:

$$v'(i) + (\gamma - 2\varepsilon) \le v'(j)$$

*Proof.* From `|v'(i) - v(i)| ≤ ε`, we get `v'(i) ≤ v(i) + ε`. From
`|v'(j) - v(j)| ≤ ε`, we get `v'(j) ≥ v(j) - ε`. From the gap certificate,
`v(j) ≥ v(i) + γ`. Combining:

$$v'(j) \ge v(j) - \varepsilon \ge v(i) + \gamma - \varepsilon \ge v'(i) - \varepsilon + \gamma - \varepsilon = v'(i) + \gamma - 2\varepsilon$$

This is the algebraic heart of the entire theory. □

**Corollary 3.2.** When `2ε < γ`, the preserved gap `γ - 2ε > 0`, so i remains
the strict minimizer of v' on S: `∀ j ∈ S, j ≠ i ⟹ v'(i) < v'(j)`.

## 4. Main Stability Theorem

**Theorem 4.1 (Elimination-Order Stability).** Let S be a nonempty finite set
of candidates. If `EliminationGapCertified S v γ`, `0 ≤ ε`, `2ε < γ`, and
`∀ i, |v'(i) - v(i)| ≤ ε`, then:

$$\text{eliminationOrderOn}(S, v') = \text{eliminationOrderOn}(S, v)$$

*Proof.* By strong induction on |S|.

**Base case** (|S| ≤ 1): Both sides return `[min' S]`. Immediate.

**Inductive step** (|S| > 1): Let `i = roundLoser(S, v)`. Unfolding the
gap certificate gives `HasGapAtLeast S v i γ` and
`EliminationGapCertified (S \ {i}) v γ`.

By Lemma 3.1, for all `j ∈ S` with `j ≠ i`, we have
`v'(i) + (γ - 2ε) ≤ v'(j)`. Since `γ - 2ε > 0`, candidate i is the strict
minimizer of v' on S, so `roundLoser(S, v') = i`.

Both elimination sequences therefore start with i and continue on
`S' = S \ {i}`. The perturbation bound `∀ k, |v'(k) - v(k)| ≤ ε` restricts
to S' automatically (it's universal over all coordinates). The recursive
certificate provides `EliminationGapCertified S' v γ`. Since |S'| < |S|, the
induction hypothesis gives `eliminationOrderOn(S', v') = eliminationOrderOn(S', v)`.

Concatenating i with the equal tails yields the result. □

**Corollary 4.2 (Winner Stability).** Under the same hypotheses:

$$\text{irvWinnerOn}(S, v') = \text{irvWinnerOn}(S, v)$$

This follows by the same induction (or directly from Theorem 4.1, since the
winner is determined by the elimination order).

## 5. Tropical / GL₃ Certified Robustness

**Theorem 5.1 (Certified Robustness).** Let `s : ℝ^d → ℝ^m` be a score map
satisfying the Lipschitz bound: for all inputs z, z' with
`∀ k, |z'(k) - z(k)| ≤ r`, we have `∀ i, |s(z')(i) - s(z)(i)| ≤ Kr`.

If `EliminationGapCertified` holds for the scores `s(x)` with gap parameter γ,
and `2Kr < γ`, then for any input `x'` with `∀ k, |x'(k) - x(k)| ≤ r`:

$$\text{irvWinner}(s(x')) = \text{irvWinner}(s(x))$$

*Proof.* Apply Corollary 4.2 with `ε = Kr`. The Lipschitz bound gives the
required score closeness `∀ i, |s(x')(i) - s(x)(i)| ≤ Kr`, and the margin
condition is `2Kr < γ`. □

The **certified robustness radius** in L∞ input space is therefore:

$$r^* = \frac{\gamma}{2K}$$

where γ is the minimum round gap of the IRV elimination at the base point x,
and K is the Lipschitz constant of the score map.

### 5.1 Instantiation: Tropical Max-Plus Affine Scores

For a tropical (max-plus affine) score map of the form:

$$s_i(x) = \max_j (W_{ij} + x_j)$$

the Lipschitz constant with respect to L∞ is K = 1, since:

$$|s_i(x') - s_i(x)| \le \max_j |x'_j - x_j| = \|x' - x\|_\infty$$

The certified radius then simplifies to `r* = γ/2`.

### 5.2 Instantiation: GL₃ Satake Score Maps

For GL₃ Satake-type score maps, the Lipschitz constant K depends on the
specific parameterization of the Hecke operators and the tropical polynomial
structure. Once a bound `K` is established from the GL₃ infrastructure, the
certified radius `r* = γ/(2K)` follows immediately from Theorem 5.1.

## 6. Discussion: Making Robustness Tangible

### A voting analogy

Imagine an election with four candidates. In each round, the candidate with
the fewest votes is eliminated. The certified robustness theorem says:
*if every elimination is decisive — the loser clearly trails the runner-up —
then small fluctuations in vote counts cannot change the outcome*.

More precisely, if the weakest candidate trails by at least γ votes in every
round, then recounting with errors of at most ε < γ/2 per candidate will
produce the exact same elimination sequence. Not just the same winner, but
the same order of elimination. The entire process is frozen.

### Why is this harder than argmax?

For a simple "highest score wins" classifier, robustness is a one-shot
comparison: the winner's margin is everything. But IRV is a *sequential*
process. Even if the final winner has a large margin, an early-round
near-tie could cause a different candidate to be eliminated first, cascading
into a completely different outcome. Our theorem shows that controlling the
gap at *every* round prevents this cascade.

### The 2ε budget

The factor of 2 in `2ε < γ` is tight and has a clean interpretation. In the
worst case, the loser's score goes up by ε (making it look stronger) while
the runner-up's score goes down by ε (making it look weaker). The gap shrinks
by ε from each side, for a total loss of 2ε. As long as the original gap γ
exceeds this total perturbation, the ordering is preserved.

### Connections to social choice theory

Our theorem connects to classical results on manipulation resistance in
voting theory. The Gibbard–Satterthwaite theorem shows that no
non-dictatorial voting rule is immune to strategic manipulation. Our result
is complementary: it shows that *non-strategic* noise (random perturbations)
cannot change the outcome of IRV when the gaps are sufficiently large. This
is a quantitative stability result, not a strategic immunity result.

## 7. Applications

### 7.1 Adversarial robustness certification for ML classifiers

The primary application is certifying that a multiclass ML classifier using
IRV-style aggregation is robust to adversarial input perturbations. Given a
trained model with known Lipschitz constant K:

1. Compute scores `s(x)` for each class at input x.
2. Run the IRV elimination and record the gap at each round.
3. The certified radius is `r* = min_gap / (2K)`.

Any adversarial perturbation within `‖δ‖_∞ < r*` is guaranteed to preserve
the prediction.

### 7.2 Election auditing

In the context of actual ranked-choice elections, the round gaps can be
computed from the tally. If the minimum round gap exceeds twice the maximum
possible tabulation error per candidate, the election result is certified
correct regardless of tabulation errors. This provides a formal basis for
risk-limiting audits of IRV elections.

### 7.3 Ensemble methods

When combining multiple classifiers by treating their scores as candidates in
an IRV-like elimination scheme, the certified radius provides a robustness
guarantee for the ensemble prediction. This extends the standard practice of
majority voting with a quantitative stability certificate.

## 9. Conclusion

We have formalized and machine-verified a robustness theory for instant-runoff
classifiers with Lipschitz score maps. The key insight is that the recursive
structure of IRV elimination admits a recursive gap certificate, and stability
follows by a clean induction once the one-round perturbation lemma provides the
algebraic base. The resulting certified radius `r* = γ/(2K)` is explicit,
computable, and composes cleanly with any Lipschitz score architecture —
including tropical max-plus affine maps and GL₃ Satake constructions.

All theorems, from basic finite set minimizer uniqueness through the full
tropical robustness corollary, are verified in Lean 4 with Mathlib, ensuring
the highest level of mathematical certainty.
