### 1. `SolovayKitaev.lean` — Gate Synthesis Theory
- Precision improvement under squaring (ε² < ε for 0 < ε < 1)

- Cayley ball monotonicity and identity membership

### 2. `QuantumErrorCorrection.lean` — Berggren-Pythagorean QEC
- Stabilizer code constraints and Singleton/Hamming bounds
- Pythagorean triples as codespace conditions
- **Lorentz form error detection**: single-coordinate errors produce syndrome 2aδ + δ²
- **Syndrome uniqueness**: errors are uniquely identifiable for |δ| < a

### 3. `QuantumTropicalFunctor.lean` — Maslov Dequantization
- **Tight LogSumExp bounds**: max(x,y) ≤ log(eˣ+eʸ) ≤ max(x,y) + log(2)
- Tropical semiring properties (idempotency, distributivity)
- **Dequantization threshold**: 2ⁿ > n² iff n ≥ 5
- **Superpolynomial advantage**: ∀d, ∃N, n ≥ N → 2ⁿ > nᵈ

### 4. `OctonionComputation.lean` — Non-Associative Computation
- Associator algebra and alternative law
- Catalan numbers C(0)=1, C(1)=1, ..., C(4)=14 (via Nat.choose)
- Moufang loop identity
- Hurwitz theorem dimensions {1, 2, 4, 8}

### 5. `QuantumNeuralArchitecture.lean` — MERA-Transformer Connection
- MERA logarithmic depth, softmax normalization
- **Barren plateau severity**: 2⁵⁰ > 10¹⁵
- **Local cost advantage**: 2ⁿ > n² for n ≥ 5
- **Bernoulli's inequality**: (1-p)ᵀ ≥ 1-Tp (decoherence bound)
- **Quantum advantage**: 2ⁿ > n³ for n ≥ 10

### 6. `QuantumBackpropagation.lean` — Parameter-Shift Rule
- **Exact parameter-shift rule**: [C(θ+π/2) - C(θ-π/2)]/2 = dC/dθ
- **HasDerivAt proof**: formal derivative verification

- **Net quantum advantage**: 2ⁿ > 2k for n ≥ 10, k ≤ n²
