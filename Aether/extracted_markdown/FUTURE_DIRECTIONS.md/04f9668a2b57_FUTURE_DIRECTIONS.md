# Future Directions: Certified Optimization via Quotient Algebras

## Synthesis

The formalization of commutative normalization as a quotient-section optimizer opens a systematic pathway from universal algebra to verified software infrastructure. The five directions below form a coherent research program:

- **Direction 1** generalizes from commutativity to arbitrary convergent equational theories, providing the foundational generalization.
- **Direction 2** bridges to the rapidly growing field of equality saturation and e-graphs, connecting our abstract framework to practical compiler technology.
- **Direction 3** extends the algebraic framework to multi-sorted signatures, enabling application to real programming languages.
- **Direction 4** addresses the optimization-of-optimization problem: among all correct normalizers, which minimizes cost?
- **Direction 5** proposes a grand challenge: compositional optimizer certification, where pipeline correctness follows from component correctness.

Each direction builds on the catalog theorems `commNorm_preserves_eval`, `QuotientOptimizer.preserves_eval`, and `endomorphism_preserves_semantics`, extending them in mathematically precise and computationally testable ways.

## Direction 1: Convergent Rewrite Systems as Quotient Optimizers

**Conjecture**: For any finitely presented equational theory `E` over a single-sorted signature `Σ`, if the oriented rewrite system `R` derived from `E` is convergent (terminating and confluent), then the normal-form function `nf_R : T(Σ, X) → T(Σ, X)` induces a semantics-preserving optimizer for every algebra satisfying `E`.

Formally: for every `Σ`-algebra `A` satisfying `E` and every interpretation `ι : X → A`,
```
eval_A(nf_R(t)) = eval_A(t)
```

**Test**: Implement 50 random convergent rewrite systems over small signatures (≤ 5 operations, ≤ 10 rules). For each, generate 10,000 random terms, compute normal forms, and evaluate in 100 random finite algebras satisfying the theory. Any mismatch disproves the conjecture.

**Impact**: This would be the master theorem of certified algebraic optimization, subsuming commutative normalization as a special case and covering associativity, distributivity, idempotency, and their combinations.

**Catalog References**: `Pythagorean/QuotientOptimizer.lean` — `commNorm_preserves_eval`, `QuotientOptimizer.preserves_eval`; `Pythagorean/VerifiedCompilerSynthesis.lean` — `endomorphism_preserves_semantics`.

**Proof Strategy**: Generalize `permRel` to the congruence generated by `E`. Show that the normal-form map is well-defined on quotient classes (by confluence) and factors through the quotient. Then apply the abstract `QuotientOptimizer.preserves_eval`.

**Domain Bridges**: Term rewriting → verified compilers → SMT solvers → algebraic geometry (Gröbner bases as convergent rewrite systems for polynomial rings).

**Lineage**: Direct generalization of `commNorm_preserves_eval` from commutativity to arbitrary equations.

**Ambition**: ★★★★★ — This would unify decades of work in term rewriting with formal verification.

## Direction 2: E-Graph Extraction as Approximate Quotient Section

**Conjecture**: In equality saturation over a finite equational theory with complete saturation and cost-optimal extraction, the extracted representative for each e-class is a canonical section of the semantic quotient, and extraction correctness reduces to congruence soundness of the e-graph.

More precisely: if an e-graph correctly tracks the congruence closure of a set of equational axioms, then for any extraction function `extract : EClass → Term`, the property
```
∀ eclass c, ∀ t₁ t₂ ∈ c, eval_A(extract(c)) = eval_A(t₁) = eval_A(t₂)
```
holds for every algebra `A` satisfying the axioms.

**Test**: Build random e-graphs from commutative + associative identities over 3-variable expressions of depth ≤ 5. Compare extracted terms against direct normalization on 10,000 random inputs in random finite algebras. Any semantic mismatch disproves extraction correctness. A mismatch where congruence is sound but extraction fails would disprove the reduction claim.

**Impact**: Would provide the first formal foundation for equality-saturation correctness at the algebraic level, connecting the practical engineering of e-graph tools to the mathematical theory of quotient algebras.

**Catalog References**: `Pythagorean/QuotientOptimizer.lean` — `commNorm_factors_through_quotient`, `QuotientOptimizer.preserves_eval`.

**Proof Strategy**: Model the e-graph as a quotient of the term algebra. Show that extraction is a section of the quotient map. Apply `QuotientOptimizer.preserves_eval`.

**Domain Bridges**: Equality saturation (egg, egglog) → compiler optimization (MLIR, Cranelift) → SMT solving (congruence closure) → universal algebra.

**Lineage**: Extends `commNorm_factors_through_quotient` from the commutative quotient to general congruence closures.

**Ambition**: ★★★★☆ — High practical impact, connecting to active research in program optimization.

## Direction 3: Multi-Sorted Quotient Optimizers

**Conjecture**: The `QuotientOptimizer` framework extends to multi-sorted algebras: for a multi-sorted signature `Σ` with sorts `S₁, ..., Sₖ`, a sort-respecting congruence, and a sort-preserving normalization function, the abstract correctness theorem `preserves_eval` holds for multi-sorted homomorphisms.

**Test**: Formalize a two-sorted example: a module over a ring, with sort `R` (ring elements) and sort `M` (module elements). Define commutativity normalization on the ring sort only. Verify that evaluation of mixed ring-module expressions is preserved under normalization of the ring components, on 5,000 random inputs.

**Impact**: Enables application to real programming languages where types (sorts) are fundamental.

**Catalog References**: `Pythagorean/QuotientOptimizer.lean` — `QuotientOptimizer` structure.

**Proof Strategy**: Generalize `QuotientOptimizer` to a family of types indexed by sorts, with sort-indexed relations and normalization functions. The abstract correctness theorem should follow by the same argument applied sort-by-sort.

**Domain Bridges**: Universal algebra → type theory → programming language semantics → categorical semantics (functorial semantics of multi-sorted theories).

**Lineage**: Generalizes the single-sorted `QuotientOptimizer` to the multi-sorted setting.

**Ambition**: ★★★☆☆ — Solid extension with clear applications.

## Direction 4: Complexity-Optimal Quotient Sections

**Conjecture**: For `FreeMonoid X` modulo a finitely presented commutative/idempotent theory, the lexicographically-first sorted canonical section minimizes the pair `(length, lexicographic rank)` among all representatives in each equivalence class.

More precisely: for the commutative quotient, among all words `w'` with `w'.Perm w`, the sorted representative minimizes `(|w'|, lex_rank(w'))`, where `lex_rank` is the position in lexicographic order among all permutations.

**Test**: Enumerate all words of length ≤ 12 over a 4-letter alphabet. For each equivalence class, compute all representatives and verify that the sorted one has minimal `(length, lex_rank)`. Note: the length is always the same for permutations, so the test reduces to: does the sorted permutation have minimal lexicographic rank? This should be true (it's the lexicographically smallest permutation).

For the idempotent quotient (where `xx ~ x`), enumerate representatives of classes for words of length ≤ 15 and check whether the sorted canonical form minimizes length. **This can fail**: the minimal-length representative under idempotency may not be sorted.

**Impact**: Characterizes the optimality of the sorting-based section, and identifies when different sections are needed for different cost functions.

**Catalog References**: `Pythagorean/QuotientOptimizer.lean` — `commNorm_canonical`, `commNorm_idempotent`.

**Proof Strategy**: For the pure commutative case, prove that sorted order = lexicographic minimum among permutations (straightforward by induction). For the idempotent case, construct a counterexample or prove the analogous theorem.

**Domain Bridges**: Combinatorial optimization → compiler cost models → computational complexity → invariant theory (optimal orbit representatives).

**Lineage**: Refines `commNorm_canonical` by adding an optimality property.

**Ambition**: ★★☆☆☆ — Concrete and testable, with clear resolution path.

## Direction 5: Compositional Optimizer Pipelines (Grand Challenge)

**Conjecture**: If `opt₁` is a `QuotientOptimizer` for congruence `R₁` and `opt₂` is a `QuotientOptimizer` for congruence `R₂`, and `R₂` is compatible with `R₁` (meaning `R₁`-related elements remain `R₁`-related after `opt₂.normalize`), then the composition `opt₂.normalize ∘ opt₁.normalize` is a `QuotientOptimizer` for the transitive closure of `R₁ ∪ R₂`, and it preserves semantics for any homomorphism compatible with both `R₁` and `R₂`.

**Test**: Implement two optimizers:
1. Commutative normalization (sorting) on `FreeMonoid X`.
2. Idempotent normalization (deduplication of adjacent equal elements) on sorted words.

Compose them and verify on 10,000 random words that:
- The composition is idempotent.
- Evaluation is preserved in any commutative idempotent monoid (a semilattice).
- The composition's equivalence classes are correct (words are related iff they have the same *set* of generators, ignoring both order and multiplicity).

A failure of idempotence or semantics preservation would disprove the conjecture.

**Impact**: This would be transformative for verified compiler pipelines: if each optimization pass is a quotient optimizer, the entire pipeline inherits correctness by composition. This is the algebraic foundation for multi-pass compiler verification.

**Catalog References**: `Pythagorean/QuotientOptimizer.lean` — `QuotientOptimizer`, `QuotientOptimizer.preserves_eval`; `Pythagorean/VerifiedCompilerSynthesis.lean` — `optimizer_semantics_preserved`.

**Proof Strategy**: Define compatibility of congruences. Prove that the composition of compatible quotient optimizers is again a quotient optimizer. The main challenge is showing idempotence of the composition; this may require that the normalizers commute or that one refines the other.

**Domain Bridges**: Compiler pipeline verification → categorical composition → monad composition → abstract interpretation → denotational semantics.

**Lineage**: Composes multiple instances of `QuotientOptimizer.preserves_eval` into a pipeline theorem, extending `optimizer_semantics_preserved` from single passes to multi-pass pipelines.

**Ambition**: ★★★★★ — Grand challenge. Success would provide the algebraic foundation for verified multi-pass compilers.
