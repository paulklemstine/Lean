# Future Directions: Tropical Canonical Forms and KW Protocols

## 1. Logarithmic Depth via Balanced Splitting

The current linear-scan protocol achieves depth equal to the number of affine pieces `n`. A balanced binary-splitting construction — at each node, split the index set in half and query whether any piece in the left half separates — should achieve depth `⌈log₂ n⌉`. The key insight is that the "does any piece in a subset separate?" query can be answered by comparing the sub-maxima of the two halves, reducing the problem to a single real-number comparison at each node. Why now? The linear-scan validity proof (`mkLinearTree_finds_separator`) already establishes the inductive pattern; lifting it to a balanced tree requires only changing the splitting strategy from "peel off one element" to "split in half," with the same correctness invariant. A falsifiable target: for any list of `n` pieces, the balanced protocol has depth exactly `⌈log₂ n⌉` and remains valid.

## 2. Equivalence-Class Invariance Under Canonical Reduction

Two different lists of affine pieces can define the same tropical polynomial (pointwise max). The canonical form removes dominated pieces. The conjecture is that the protocol constructed from the canonical form is "equivalent" to any protocol from a redundant representation, in the sense that they agree on all separating inputs and the canonical protocol's depth is at most the depth of any valid protocol for the same function. The key insight is that dominated pieces never achieve the maximum, so they can never serve as separating witnesses; removing them doesn't change the set of reachable leaves on valid inputs. Why now? The file `Tropical/Canonical/Basic.lean` already defines canonical tropical polynomials with uniqueness; connecting canonicalization to protocol minimality is the natural next step.

## 3. Multivariate Extension: Tropical Polynomials in ℝⁿ

The current theory handles univariate affine pieces `x ↦ ax + b`. For multivariate tropical polynomials `f(x₁,...,xₙ) = max_i (∑_j a_{ij} x_j + b_i)`, the separating witness theorem should still hold: if `f(x) < f(y)` then some affine piece separates. The key insight is that the proof of `separating_witness_exists` is dimension-agnostic — it only uses that each piece's evaluation is bounded by the max and that the max equals some piece's evaluation. Why now? The univariate proof structure is clean enough to serve as a template; the multivariate generalization requires replacing `ℝ → ℝ` affine maps with `ℝⁿ → ℝ` affine maps (inner product + constant), which is a straightforward Mathlib `EuclideanSpace` or `Fin n → ℝ` construction.

## 4. Communication Lower Bounds via Piece Counting

If the tropical polynomial has exactly `n` essential affine pieces (no two agree on any open interval), then any valid KW-style protocol must have at least `n` distinct leaves (one per possible separator). Combined with the tree structure, this forces depth ≥ `⌈log₂ n⌉`. The key insight is that for each pair of consecutive pieces in the canonical representation, there exists a specific pair of inputs `(x, y)` where *only* one piece separates, forcing that piece to appear as a distinct leaf. Why now? The existing `KWProtocol.card_leafLabels_le` in `Bridges/KarchmerWigderson.lean` already proves `|leaves| ≤ 2^depth`; the missing ingredient is the injection from essential pieces to leaves, which the hard-pair construction provides.

## 5. Bridge to Neural Network Verification

ReLU neural networks compute piecewise-affine functions that can be written as tropical rational expressions (difference of two tropical polynomials). For verification tasks — proving `f(x) > f(y)` for all x in region A and y in region B — the tropical KW protocol provides a certified decomposition into affine-piece comparisons, each of which reduces to a linear program. The key insight is that the protocol tree becomes a branch-and-bound certificate: each leaf corresponds to a single LP feasibility check, and the tree's validity theorem guarantees completeness. Why now? The `relu_network_has_canonical_tropical_rational` theorem (stated in `Tropical/Canonical/Basic.lean`) provides the representation theorem; combining it with `tropical_kw_bridge` yields an end-to-end pipeline from neural network weights to verified separation certificates.
