# Future Directions: Berggren Post-Quantum Lattices

## Research Roadmap

This document outlines 5 concrete breakthrough opportunities opened by the formally verified foundations established in this work.

### Direction 1: Higher-Dimensional Berggren Lattice Families

**Exact Theorem Target:**
```lean
theorem berggren_tensor_lattice_rank (n : ℕ) :
    ∃ (L : Submodule ℤ (Fin (3 * n) → ℤ)),
      IsBerggrenTensorGenerated L ∧
      Module.finrank ℤ L = 3 * n
```

**Why It Would Matter:**
Practical lattice cryptography operates in dimensions 256–1024. Our current results live in ℤ³. The natural extension is to form tensor products or direct sums of Berggren orbit lattices. If a rank-3n lattice family can be constructed from n independent Berggren orbits, each with certified norm bounds, the resulting family would have both high dimension and inherited geometric guarantees.

**Dependencies:**
- `berggren_three_orbit_vectors_independent` (current work)
- `berggren_hyp_increase` (current work)
- Mathlib's `Submodule.prod` or `DirectSum` API

**Estimated Difficulty:** Medium-hard. The tensor/direct-sum construction is straightforward; the challenge is proving that norm bounds and independence properties lift cleanly to the product lattice.

**Task Type:** formalize + prove

### Direction 2: Collision Resistance of the Berggren Orbit Map

**Exact Theorem Target:**
```lean
theorem berggren_orbit_injective :
    ∀ (w₁ w₂ : BerggrenWord),
      evalWord w₁ root = evalWord w₂ root → w₁ = w₂
```

**Why It Would Matter:**
If distinct Berggren words always produce distinct orbit vectors, then the map w ↦ evalWord w root is a provably injective function from the free monoid on 3 generators to ℤ³. This would establish collision resistance — a fundamental cryptographic primitive — directly from the algebraic structure of the Berggren semigroup. Combined with the word space cardinality theorem (3^m), it would give a formally verified one-way function candidate.

The key mathematical content is that the Berggren semigroup acts freely on the null cone. This is equivalent to showing that the group generated by A, B, C is free (which is known classically but has not been machine-verified).

**Dependencies:**
- `berggrenG_mul_inv` / `berggrenGinv_mul_G` (current work)
- `wordMatrix_det_unit` (current work)
- Freeness of the Berggren semigroup (new, requires Ping-Pong lemma or Bass-Serre theory)

**Estimated Difficulty:** Hard. The mathematical result (freeness) is known but the proof requires either the Ping-Pong lemma for O(2,1; ℤ) or a careful combinatorial argument about reduced words.

**Task Type:** prove

### Direction 3: Worst-Case SVP Reduction via Lorentz Geometry

**Exact Theorem Target:**
```lean
theorem svp_reduction_to_berggren
    (n : ℕ) (hn : 3 ≤ n) :
    ∃ (N : ℕ) (Φ : (Fin n → ℤ) →ₗ[ℤ] (Fin N → ℤ))
      (L : Submodule ℤ (Fin N → ℤ))
      (C : ℕ),
    0 < C ∧
    IsBerggrenGenerated L ∧
    Function.Injective Φ ∧
    (∀ v, Φ v ∈ L) ∧
    (∀ v, sqNorm (Φ v) ≤ C * sqNorm v)
```

**Why It Would Matter:**
This is the crown jewel: an explicit reduction showing that solving SVP on Berggren lattices is at least as hard as solving SVP on general lattices (up to an approximation factor). If established, it would be the first worst-case hardness result for a lattice family derived from a classical Diophantine dynamical system, opening an entirely new paradigm in lattice cryptography.

The approach would exploit the Lorentz form structure: the Berggren matrices preserve Q(v) = v₀² + v₁² − v₂², making Berggren lattices a structured subfamily of lattices adapted to a specific quadratic form. The challenge is showing that this structure is rich enough to embed arbitrary lattices.

**Dependencies:**
- All current theorems
- New theory connecting Berggren orbit lattices to general lattice geometry
- Potentially: results on integral representations of quadratic forms

**Estimated Difficulty:** Very hard (potential research breakthrough). The obstruction theorem (Theorem 5) shows full universality is impossible, so the reduction must work with an approximation factor or restricted lattice class.

**Task Type:** prove / discover

### Direction 4: Automorphic Forms and Hecke Operators on the Berggren Tree

**Exact Theorem Target:**
```lean
theorem berggren_hecke_eigenvalue :
    ∃ (f : BerggrenWord → ℂ),
      (∀ w, ‖f w‖ ≤ 1) ∧
      (∀ j w, f (j :: w) = eigenvalue j * f w + error_term j w) ∧
      (∀ j w, ‖error_term j w‖ ≤ C * ‖f w‖)
```

**Why It Would Matter:**
The Berggren tree is the quotient of the Bruhat-Tits tree of PGL(2) by an arithmetic congruence subgroup. Functions on this tree are automorphic forms, and the Berggren generators correspond to Hecke operators. Establishing eigenvalue bounds for these operators would yield:

1. **Spectral gap → expansion**: proving the orbit graph is an expander, giving strong mixing properties for random walks.
2. **Ramanujan-type bounds**: optimal spectral bounds would make Berggren lattices provably good for derandomization.
3. **L-function connections**: linking Berggren orbit statistics to analytic number theory.

This direction would create an unprecedented bridge between the Langlands program and post-quantum cryptography.

**Dependencies:**
- Berggren matrices as elements of O(2,1; ℤ) (current work)
- Mathlib's spectral theory and representation theory infrastructure
- Potentially: modular forms API in Mathlib

**Estimated Difficulty:** Very hard (requires deep mathematical machinery). This is more of a long-term research program than a single theorem, but even partial results (e.g., spectral gap for the depth-bounded orbit graph) would be significant.

**Task Type:** discover + formalize

### Direction 5: Practical Berggren Key Exchange Protocol

**Exact Theorem Target:**
```lean
structure BerggrenKeyExchange where
  wordLen : ℕ
  publicKey : BerggrenWord → Fin 3 → ℤ
  sharedSecret : BerggrenWord → BerggrenWord → Fin 3 → ℤ
  correctness : ∀ wA wB,
    sharedSecret wA wB = sharedSecret wB wA
  security : ∀ wA,
    2 * 128 ≤ wordLen →
    -- extracting wA from publicKey wA requires ≥ 128-bit quantum work
    True  -- placeholder for formal security statement

theorem berggren_key_exchange_exists :
    ∃ (ke : BerggrenKeyExchange), ke.wordLen ≤ 256
```

**Why It Would Matter:**
Moving from theoretical foundations to a concrete, implementable protocol with formally verified correctness and security bounds would be a first-of-its-kind achievement: a post-quantum key exchange whose security proof chain is entirely machine-checked.

The main challenge is designing a protocol where Alice and Bob can derive a shared secret from their respective public keys without revealing their secret words. This likely requires either:
- A commutative sub-semigroup of the Berggren semigroup (unlikely given non-commutativity)
- A hash-based extraction step (straightforward but needs formal hash model)
- A lattice-based construction using the Berggren lattice as a structured public key

**Dependencies:**
- All current theorems
- Direction 2 (collision resistance) for one-wayness
- Formal model of hash functions or random oracle
- Performance benchmarking (Python implementations from current work)

**Estimated Difficulty:** Medium (protocol design) to hard (formal security proof). The implementation is feasible; the challenge is the formal security reduction.

**Task Type:** formalize + prove

## Cross-Cutting Themes

### Formal Verification as Research Methodology
Every direction above should maintain the standard established in this work: all claimed theorems machine-verified. This discipline prevents the subtle errors that plague hand-written cryptographic proofs and creates a cumulative, reusable library of certified results.

### Connections to Pursue
- **Berggren ↔ Modular arithmetic**: The Berggren matrices reduce mod p to elements of GL(3, 𝔽_p). The orbit structure mod p may reveal algebraic structure relevant to discrete-log-style problems.
- **Berggren ↔ Continued fractions**: The B-path satisfies a Pell recurrence, connecting to continued fraction expansions and Diophantine approximation.
- **Berggren ↔ Hyperbolic geometry**: The Berggren tree is isomorphic to a subtree of the Farey graph / hyperbolic tessellation. This geometric perspective may yield shortest-vector bounds via hyperbolic geometry.

### Prioritization
1. **Direction 2** (collision resistance) — highest impact per effort, builds directly on current work
2. **Direction 1** (higher dimensions) — essential for practical relevance
3. **Direction 5** (protocol design) — highest applied impact
4. **Direction 3** (SVP reduction) — highest theoretical impact but hardest
5. **Direction 4** (automorphic forms) — deepest mathematical content, longest timeline
