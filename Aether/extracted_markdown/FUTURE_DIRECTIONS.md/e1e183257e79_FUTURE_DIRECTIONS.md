# Future Directions: Depth Hierarchy for Iterated Exponentials

## Overview

This document presents five falsifiable scientific hypotheses arising from
our formally verified depth hierarchy theory for iterated exponentials.
Each hypothesis is precise enough to be confirmed or refuted by concrete
computation or proof, and each would open significant new research directions
if confirmed.

---

## Hypothesis 1: Inverse-Linear Scaling of Best Approximation Error

**Conjecture.** For fixed `k ≥ 2`, the best uniform approximation error on `[0,1]` of
`iterExp(k)` by depth-`(k−1)` expressions of size `S` scales as `Θ(S⁻¹)`.

More precisely, there exist constants `c₁(k), c₂(k) > 0` such that:

  c₁(k) / S  ≤  inf_{E : depth ≤ k−1, size ≤ S}  sup_{x ∈ [0,1]} |E(x) − iterExp(k,x)|  ≤  c₂(k) / S

**Test.** Exhaustive/heuristic search over expressions up to size `S_max = 15` for
`k = 2, 3`. Fit the best error `ε*(S)` in log-log coordinates. If the slope is
consistently near `−1`, the hypothesis is supported. If it deviates significantly
(e.g., slope < −1.5 or > −0.5), the hypothesis is refuted.

**Impact.** If true, this establishes the exact approximation rate for the depth
hierarchy, proving that the conjectured `ε⁻¹` size lower bound is tight. This would
be a foundational result in analytic complexity theory.

---

## Hypothesis 2: Exponential-in-Depth Constant Growth

**Conjecture.** The constant `c₁(k)` in the lower bound grows at least exponentially in `k`:
there exists `α > 1` such that `c₁(k) ≥ α^k` for all `k ≥ 2`.

**Test.** Estimate `c₁(k)` for `k = 2, 3, 4, 5` by computing best approximation errors
at several sizes and fitting. Plot `log c₁(k)` vs `k`. If the plot is roughly linear
with positive slope, the hypothesis is supported.

**Impact.** This would prove that not only does each new depth level create an
approximation barrier, but the barrier grows exponentially with depth — a true
hierarchy, not just a sequence of diminishing separations.

---

## Hypothesis 3: Derivative Envelope Sharpness

**Conjecture.** The formal derivative envelope for depth-`d` expressions is
asymptotically sharp up to polynomial factors in the size. That is, for each
`d` and `S`, there exists a depth-`d`, size-`S` expression `E` such that

  max_{x ∈ [0,1]} |E'(x)|  ≥  Ω(envelope(d, S) / S^c)

for some universal constant `c`.

**Test.** For `d = 0, 1, 2` and `S = 3, 5, 7, 9`, enumerate all depth-`d`
size-≤`S` expressions, compute maximum derivatives on `[0,1]`, and compare
with the theoretical envelope bound. Compute the ratio. If the ratio remains
bounded by a polynomial in `S`, the envelope is sharp.

**Impact.** Sharp envelopes would make the derivative-obstruction proof strategy
optimal: the separation theorems would give best-possible lower bounds through
this route, closing the question of whether derivative arguments suffice.

---

## Hypothesis 4: Restricted-Fragment Exactness

**Conjecture.** For the restricted expression fragment generated by `{x, const, +, *, exp}`
(no negation or subtraction), the derivative-envelope lower bounds already force
qualitative depth separation. Specifically, for every `k ≥ 2`, there exists `ε₀(k) > 0`
such that no restricted depth-`(k−1)` expression of any size can approximate `iterExp(k)`
within `ε₀` on `[0,1]`.

**Test.** Search the restricted syntax exhaustively up to size 12 for `k = 2, 3`.
Check whether the best error converges to zero (refutation) or saturates at a
positive value (confirmation). Verify that the derivative envelope bounds are
sufficient to explain the saturation.

**Impact.** If true, this would be the cleanest depth separation theorem: no size
bound needed, just depth alone suffices for the restricted fragment. This is the
strongest form of the hierarchy and would have immediate implications for
symbolic regression algorithms that use this fragment.

---

## Hypothesis 5: Refutation Trigger — Anomalously Efficient Approximants

**Conjecture (Null Hypothesis).** There exists `k ≥ 3` and a depth-`(k−1)` expression `E`
of size `o(c^k · ε⁻¹)` that achieves uniform error `≤ ε` on `[0,1]` against `iterExp(k)`.

**Test.** Automated search for anomalously efficient approximants:
1. For each `k ∈ {3, 4}`, set target error `ε = 0.1, 0.01, 0.001`.
2. Search for depth-`(k−1)` expressions achieving error ≤ ε.
3. Record the minimum size found.
4. If size grows slower than `c^k / ε`, flag as potential counterexample.

**Impact.** Finding such an anomaly would falsify the full conjecture in its current
form, requiring either a weaker lower bound or a refined expression language definition.
This is the most important test: it directly probes the conjecture's validity.

## Methodology Notes

All hypotheses can be tested using the computational tools provided:

The formally verified theorems provide guaranteed lower bounds that serve as
baselines. Any computational finding that contradicts these theorems would
indicate a bug in the computation, not a counterexample to the theory.
