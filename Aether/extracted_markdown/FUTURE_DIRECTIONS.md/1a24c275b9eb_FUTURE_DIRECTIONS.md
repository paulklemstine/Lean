# Future Directions: Formal Hodge Theory

## Overview

This document identifies five falsifiable scientific hypotheses emerging from our formalization of rank-one Hodge theory. Each hypothesis is precise enough to be tested by formalization attempts and specific enough that failure would be informative.

---

## Hypothesis 1: Rank-k Orthogonal Lattice Classification

**Conjecture.** For a polarized weight-2 rational Hodge structure V with Picard rank ρ = k ≥ 2, the Hodge class submodule Hdg(V) is isomorphic (as a polarized ℚ-lattice) to a sublattice of the K3 lattice Λ = U³ ⊕ E₈(-1)² of rank k. Moreover, the isometry class of the pair (Hdg(V), Q|_{Hdg}) determines the embedding up to the action of O(Λ).

**Precise statement for formalization:**
```
theorem rank_k_hodge_lattice_classification
  (HS : PolarizedWeightTwoHodgeData V)
  (hρ : Module.finrank ℚ (HodgeClasses HS.toWeightTwoHodgeData) = k)
  (hk : k ≥ 2) :
  ∃ (W : Submodule ℚ V), W = HodgeClasses HS.toWeightTwoHodgeData ∧
    IsOrthogonalDirectSummand HS.Q W := by sorry
```

**Test.** Formalize the orthogonal decomposition V = Hdg(V) ⊕ T(V) for rank k ≥ 2 with the condition that Q|_{Hdg} is nondegenerate. If this fails for k ≥ 2 without additional hypotheses (e.g., the signature condition on Q|_{Hdg}), the conjecture needs refinement.

**What would count as refutation.** A construction of a weight-2 Hodge structure with ρ = 2 where Q|_{Hdg} is degenerate, preventing the orthogonal decomposition. This is actually possible (take Hdg(V) to contain an isotropic vector), which would show the nondegeneracy hypothesis is essential.

**Impact.** A positive result would extend our reconstruction theorem (C2) to arbitrary Picard rank, giving a complete formal classification of polarized Hodge structures by their transcendental lattice plus algebraic lattice isometry class. This is the linear-algebraic core of the Torelli theorem for K3 surfaces.

## Hypothesis 2: Tensor Product Hodge Class Generation

**Conjecture.** For weight-1 rational Hodge structures W₁ and W₂, the Hodge classes in W₁ ⊗ W₂ are generated by morphisms of Hodge structures:

$$\text{Hdg}(W_1 \otimes W_2) \cong \text{Hom}_{\text{HS}}(W_1^\vee, W_2)$$

where W₁ᵛ is the dual weight-1 structure.

**Precise statement for formalization:**
```
def HodgeStructureMorphisms (W₁ W₂ : WeightOneHodgeData) :
    Submodule ℚ (W₁.V →ₗ[ℚ] W₂.V) :=
  { carrier := {f | ∀ v ∈ W₁.H10, (complexifyMap f) v ∈ W₂.H10},
    ... }

theorem tensor_hodge_classes_eq_morphisms
  (W₁ W₂ : WeightOneHodgeData) :
  HodgeClasses (inducedWeightTwoOnTensor W₁ W₂) ≃ₗ[ℚ]
    HodgeStructureMorphisms W₁ W₂ := by sorry
```

**Test.** First verify the claim for specific examples:
- W₁ = W₂ = H¹(E) for an elliptic curve E without CM: expect dim Hom = 1
- W₁ = W₂ = H¹(E) for E with CM by ℚ(√(-d)): expect dim Hom = 2
- W₁ ≠ W₂ non-isogenous: expect dim Hom = 0

**What would count as refutation.** A weight-1 structure where the tensor Hodge classes strictly exceed the morphism space. This would indicate the definition of `HodgeStructureMorphisms` needs to include anti-linear morphisms (Hodge structures of type (0,0) from W₁ᵛ ⊗ W₂ can involve conjugation).

**Impact.** This would formalize the Hodge-theoretic content of the Tate conjecture for abelian varieties in the function field case, and provide a machine-checked version of Deligne's theorem on absolute Hodge classes for abelian varieties.

## Hypothesis 3: Torelli Reconstruction Beyond Rank One

**Conjecture.** The reconstruction theorem (C2) extends to arbitrary Picard rank: given two polarized weight-2 Hodge structures with isometric algebraic lattices and isometric transcendental lattices (compatible with the orthogonal decomposition), the full structures are isometric.

**Precise statement:**
```
theorem general_reconstruction
  (HS HS' : PolarizedWeightTwoHodgeData V)
  (hcompl : IsCompl (HodgeClasses HS) (TranscendentalLattice HS))
  (hcompl' : IsCompl (HodgeClasses HS') (TranscendentalLattice HS'))
  (f_alg : HodgeClasses HS ≃ₗ[ℚ] HodgeClasses HS')
  (f_tr : TranscendentalLattice HS ≃ₗ[ℚ] TranscendentalLattice HS')
  (hf_alg_iso : ∀ a b, HS.Q a b = HS'.Q (f_alg a) (f_alg b))
  (hf_tr_iso : ∀ a b, HS.Q a b = HS'.Q (f_tr a) (f_tr b)) :
  ∃ F : V ≃ₗ[ℚ] V, ∀ a ∈ HodgeClasses HS, F a = f_alg ⟨a, ‹_›⟩ := by sorry
```

**Test.** The proof should follow by direct sum gluing, generalizing our rank-one argument. The key technical challenge is constructing the linear equivalence on the product type and verifying bijectivity.

**What would count as refutation.** An example where the algebraic and transcendental isometries are individually well-defined but incompatible at the boundary — i.e., the glued map fails to be a global isometry. This would indicate the need for a compatibility condition between f_alg and f_tr.

**Impact.** This would give a complete formal version of the abstract Torelli principle for polarized Hodge structures, applicable to K3 surfaces, hyperkähler manifolds, and cubic fourfolds.

## Hypothesis 4: Exterior Power Hodge Class Computation

**Conjecture.** For a weight-1 Hodge structure W with H¹(W,ℂ) = H^{1,0} ⊕ H^{0,1} where dim H^{1,0} = g, the Hodge classes in the exterior power Λ^{2k}W form a space of dimension:

$$\dim_\mathbb{Q} \text{Hdg}(\Lambda^{2k} W) = \binom{g}{k}^2$$

when W is "generic" (i.e., its Mumford-Tate group is the full symplectic group Sp(2g)).

**Precise statement for testing:**
```
-- For g = 2, k = 1: Λ²W should have 4 = C(2,1)² Hodge classes
-- This is verifiable for concrete constructions
theorem exterior_power_hodge_dimension
  (W : WeightOneHodgeData)
  (hg : Module.finrank ℚ W.V = 2 * g)
  (hgeneric : MumfordTateGroup W = Sp(2g)) :
  Module.finrank ℚ (HodgeClasses (inducedOnExteriorPower 2 W)) = g^2 := by sorry
```

**Test.** Compute numerically for small g:
- g = 1: Λ²W is 1-dimensional, expect 1 Hodge class ✓
- g = 2: Λ²W is 6-dimensional, expect 4 Hodge classes
- g = 3: Λ²W is 15-dimensional, expect 9 Hodge classes

**What would count as refutation.** A generic weight-1 structure of dimension 2g = 4 where Λ² has more or fewer than 4 Hodge classes. This would indicate either the genericity hypothesis is wrong or the formula is wrong.

**Impact.** This would formalize classical results of Hodge theory for abelian varieties and provide the foundation for machine-checked computations of Hodge numbers for higher-dimensional varieties.

## Hypothesis 5: Formal Period Map Injectivity

**Conjecture.** The period map for weight-2 Hodge structures at rank one is injective on isomorphism classes. More precisely: define the period point of a rank-1 polarized structure as the pair (T(V), Q(ω,ω)) ∈ (isometry classes of polarized lattices) × ℚ>0. The map sending a rank-1 structure to its period point is injective up to isomorphism.

**Precise statement:**
```
theorem period_map_injective
  (HS HS' : PolarizedWeightTwoHodgeData V)
  (hρ : PicardRank HS = 1) (hρ' : PicardRank HS' = 1)
  (hperiod : TranscendentalLattice HS ≃ₗᵢ[ℚ] TranscendentalLattice HS')
  (hnorm : AlgebraicNorm HS = AlgebraicNorm HS') :
  ∃ F : V ≃ₗ[ℚ] V, IsHodgeIsometry HS HS' F := by sorry
```

**Test.** This is essentially our Theorem C2 with the additional requirement that F preserves the Hodge decomposition (not just the bilinear form). The test is whether our current C2 can be strengthened to include Hodge-compatibility.

**What would count as refutation.** Two rank-1 structures with isometric transcendental lattices and equal algebraic norms, but different Hodge decompositions on the transcendental part. This would show that the period point must also include the Hodge decomposition of T(V), not just its isometry class — which is of course the classical content of the period map.

**Impact.** A positive result, properly accounting for the Hodge decomposition, would give the first machine-verified version of the Torelli theorem in any nontrivial case. This would be a landmark in formal algebraic geometry.

## Priority Ranking

1. **Hypothesis 3** (General reconstruction): Most directly extends our existing infrastructure. Estimated effort: medium. The proof should generalize from rank 1 to rank k using the same direct-sum gluing technique.

2. **Hypothesis 1** (Rank-k classification): Requires extending the orthogonal decomposition. Estimated effort: medium-high. The key challenge is handling the nondegeneracy condition on arbitrary-rank sublattices.

3. **Hypothesis 2** (Tensor Hodge classes): Requires formalizing Hodge structure morphisms and the Hom-tensor adjunction. Estimated effort: high. The complexification of linear maps introduces significant technical overhead.

4. **Hypothesis 4** (Exterior power computation): Requires graded components of the exterior algebra. Estimated effort: high. Depends on Mathlib development of exterior algebra grading.

5. **Hypothesis 5** (Period map injectivity): Requires formalizing the Hodge decomposition on the transcendental part. Estimated effort: very high. This is the deepest direction and would constitute a major advance in formalized algebraic geometry.
