# Future Directions: Log-Linearization and Interaction Geometry

## Conjecture 1: Stability of Approximate Log-Separability

**Conjecture.** For every compact rectangle $K \subset (0,\infty)^2$, there exists a constant $C_K > 0$ such that if a positive continuous function $f$ has uniformly small interaction defect on $K$:

$$\sup_{x_1,x_2,y_1,y_2 \in K} |\log f(x_1,y_1) + \log f(x_2,y_2) - \log f(x_1,y_2) - \log f(x_2,y_1)| \le \varepsilon,$$

then $f$ is uniformly close on $K$ to a multiplicatively separable function $\phi(x)\psi(y)$:

$$\inf_{\phi,\psi} \sup_{(x,y) \in K} |\log f(x,y) - \log \phi(x) - \log \psi(y)| \le C_K \cdot \varepsilon.$$

**Test.** Sample smooth perturbations of separable functions (e.g., $f(x,y) = x^2 y^3 (1 + \varepsilon \sin(xy))$), compute both sides numerically for varying $\varepsilon$, and test whether a linear bound $C_K \cdot \varepsilon$ holds. Our computational demo already shows the defect scales linearly with $\varepsilon$. A formal proof would likely use a double-centering argument on $\log f$.

**Impact.** If true, this provides a quantitative version of the main theorem — an approximate cross-ratio identity implies approximate factorization. This is essential for practical applications where exact separability never holds due to noise.

## Conjecture 2: Smooth Mixed-Derivative Characterization

**Conjecture.** Let $f : (0,\infty)^2 \to (0,\infty)$ be $C^2$ and define $G(s,t) = \log f(e^s, e^t)$. Then $f$ is multiplicatively separable if and only if the mixed partial derivative $\frac{\partial^2 G}{\partial s \partial t} = 0$ everywhere.

**Test.** For $f(x,y) = x^a y^b$, compute $G(s,t) = as + bt$ and verify $\partial^2 G / \partial s \partial t = 0$. For $f(x,y) = (x+y)^2$, compute $G(s,t) = 2\log(e^s + e^t)$ and verify that $\partial^2 G / \partial s \partial t = e^{s+t}/(e^s + e^t)^2 \neq 0$. For the formal proof, integrate $\partial^2 G / \partial s \partial t = 0$ using the fundamental theorem of calculus to get $G(s,t) = u(s) + v(t)$.

**Impact.** This connects the algebraic characterization (cross-ratio identity) to an analytic one (PDE condition), bridging the discrete and continuous theories. It would formalize the physics intuition that "zero mixed free-energy curvature means no interaction."

## Conjecture 3: Multivariate Generalization (Tensor Rank One)

**Conjecture.** A positive continuous function $f : (0,\infty)^n \to (0,\infty)$ satisfies $f(x_1, \ldots, x_n) = \prod_{i=1}^n \phi_i(x_i)$ for continuous positive $\phi_i$ if and only if for every pair of coordinates $i \neq j$ and every fixing of the remaining coordinates, the resulting bivariate function satisfies the cross-ratio identity.

**Test.** Implement the trivariate case: test $f(x,y,z) = x^2 y^3 z$ (separable) and $f(x,y,z) = (x+y) z$ (non-separable in $x,y$ but separable in $(x,y)$ vs $z$). Verify that the pairwise cross-ratio test correctly detects which coordinate pairs interact.

**Impact.** This would extend the theory from bivariate to arbitrary dimension, enabling tensor decomposition tests for multivariate positive kernels. It connects to Tucker decomposition and CP-rank in tensor algebra.

## Conjecture 4: Information-Geometric Interpretation

**Conjecture.** The log interaction defect $D_f(x_1, x_2, y_1, y_2)$ is the exponential of a signed area in the Fisher information geometry of the exponential family generated by $f$. Specifically, if $f$ defines a bivariate exponential family $p_\theta(x,y) \propto f(x,y)^{\theta}$, then the interaction defect equals $\exp(\theta^2 \cdot A)$ where $A$ is the mixed Fisher curvature.

**Test.** Compute the Fisher information matrix for parametric families of the form $f_\theta(x,y) = (x^a y^b)^\theta$ and $(x+y)^{2\theta}$. Check whether the defect's dependence on $\theta$ matches the predicted quadratic scaling via Fisher curvature.

**Impact.** This would establish a deep connection between multiplicative separability and information geometry, showing that the interaction defect is not just an algebraic convenience but a geometric invariant of the statistical manifold.

## Conjecture 5: Categorical Characterization via Monoidal Functors

**Conjecture.** The log-linearization equivalence is an instance of a natural isomorphism between two monoidal functors: the "multiplicative" functor $(\mathbb{R}_{>0}, \times) \to (\text{Pos}, \times)$ and the "additive" functor $(\mathbb{R}, +) \to (\text{Pos}, +_{\log})$, where $\text{Pos}$ is the category of positive continuous functions on the positive quadrant and $+_{\log}$ denotes pointwise addition in log coordinates.

**Test.** Formalize the categories and functors in Lean 4 using Mathlib's category theory library. Verify that the main theorem corresponds to the existence of a natural isomorphism. Check functoriality: does composition of separable functions remain separable? (Yes: $f \cdot g$ separable if both $f, g$ are.)

**Impact.** A categorical formulation would make the theory composable and extensible, allowing systematic application to new domains without re-proving the core theorem. It would also connect to the theory of logarithmic structures in algebraic geometry.
