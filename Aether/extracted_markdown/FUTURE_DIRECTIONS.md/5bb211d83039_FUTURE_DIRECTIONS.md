# Future Directions: EML Interpolation Theory

## Synthesis

This research cycle established the foundational density theorem for EML networks — proving that the algebra generated by exp and the identity is dense in C(K, ℝ) for compact K ⊆ ℝ — and introduced EML complexity as a novel measure of transcendental operation cost. The most promising cross-domain connection emerged from the interplay between algebraic structure (the EML term grammar), approximation theory (Stone-Weierstrass density), and computational complexity (the width-depth tradeoff). The formal EMLTerm grammar connects to the Catalog's existing EML work (EMLv17Core's two-variable eml function, MaxPlusStoneWeierstrass's tropical approximation) and to the machine learning thread (ClosureNetworkUAP's universal approximation). The highest breakthrough potential lies in Direction 1, which would establish quantitative rates beyond the existential guarantee of Stone-Weierstrass, potentially connecting to the Jackson-Bernstein theory of classical approximation.

The key open problem is whether EML networks exhibit a strict depth hierarchy — whether depth-d networks can approximate functions that depth-(d-1) networks cannot efficiently approximate. This would parallel the celebrated results of Telgarsky (2016) for ReLU networks but in the richer algebraic setting of transcendental functions, where the iterated exponential provides natural candidates for hard functions.

### Direction 1: Jackson-Bernstein Theory for EML Networks

**Conjecture**: For f in Lip_α([0,1]) (α-Hölder continuous functions), the minimum width of an EML term achieving ε-approximation satisfies:
```
emlComplexity(f, 0, 1, ε) ≤ C · ε^{-1/α}
```
for a universal constant C depending only on the Lipschitz constant. Moreover, this rate is optimal: there exist Lip_α functions requiring width Ω(ε^{-1/α}).

**Test**: (1) Construct explicit EML approximations of |x - 1/2| (Lipschitz-1, not differentiable) on [0,1] and measure how width scales with ε. (2) Prove the lower bound by showing that width-w EML terms have bounded Vapnik-Chervonenkis dimension, limiting their approximation power.

**Impact**: If true, this gives the first explicit approximation rates for transcendental networks, bridging classical Jackson-Bernstein theory with modern neural network expressivity. If false, it reveals a qualitative difference between algebraic and transcendental approximation.

**Catalog References**: `Catalog/EML/ApproximationBounds.lean`, `Catalog/EML/UniversalApproximation.lean`, `Catalog/MachineLearning/ClosureNetworkUAP.lean`

**Proof Strategy**: (1) For the upper bound, discretize [0,1] into ε^{1/α}-width intervals and use the Taylor-based EML approximation (Theorem 4.2 from this cycle) locally on each interval, then patch using partition-of-unity techniques expressible in the EML algebra. (2) For the lower bound, bound the number of sign changes of width-w EML terms.

**Domain Bridges**: Approximation Theory <-> Machine Learning (neural network expressivity), Analysis <-> Algebra (algebraic structure of approximants)

**Lineage**: Builds on eml_stoneWeierstrass, emlApproxSquare_overestimates, emlComplexity_polynomial_zero from this cycle.

**Ambition**: grand_challenge

### Direction 2: Exponential Depth Hierarchy

**Conjecture**: The n-fold iterated exponential exp^[n](x) cannot be ε-approximated on [0,1] by any EML term of depth less than n and width less than 2^{n/2}, for ε = 1/4.

**Test**: (1) For n = 2, attempt to construct a depth-1 EML term that approximates exp(exp(x)) on [0,1] within 1/4, and show that all such terms require width ≥ 2. (2) Computationally verify for n = 3, 4, 5 using numerical optimization.

**Impact**: This would establish an exponential depth-width tradeoff for EML networks, showing that depth is exponentially valuable — each additional layer of nesting provides exponential savings in width. This parallels Telgarsky's result for ReLU networks but in a richer algebraic setting.

**Catalog References**: `Catalog/Bridges/ArrowDepthComplexity.lean` (contains `not_exists_uniform_exp_depth_bound`), `Catalog/EML/DepthEfficiency.lean`

**Proof Strategy**: (1) Show that depth-1 EML terms (sums and products of exp(a_i x + b_i) and log(c_i x + d_i)) have bounded oscillation on [0,1], growing at most exponentially in width. (2) Show that exp^[n](x) on [0,1] has super-exponential growth (tower function), requiring matching oscillation in any approximant.

**Domain Bridges**: Complexity Theory <-> Approximation Theory, EML <-> Computation (circuit complexity analogy)

**Lineage**: Builds on EMLTerm.iterExp, iterExp_strictMono, double_exp_gt, EMLTerm.depth_compose_le from this cycle.

**Ambition**: grand_challenge

### Direction 3: Multivariate EML Density on ℝⁿ

**Conjecture**: The subalgebra of C(K, ℝ) generated by coordinate projections πᵢ and exp(Σ aᵢπᵢ) for all (aᵢ) ∈ ℝⁿ is dense in C(K, ℝ) for any compact K ⊆ ℝⁿ, n ≥ 2.

**Test**: (1) Verify the separation condition: for x ≠ y in ℝⁿ, some coordinate projection separates them (trivial if the projections are included). (2) Prove the result formally using the multivariate Stone-Weierstrass theorem. (3) Test computationally on K = [0,1]² by approximating f(x,y) = sin(x+y) with multivariate EML terms.

**Impact**: Extends the density theorem from compact subsets of ℝ to ℝⁿ, which is the natural setting for neural networks (which process n-dimensional inputs). This is the necessary foundation for practical EML network design.

**Catalog References**: `Catalog/EML/VectorStoneWeierstrass.lean`, `Catalog/EML/VecEML.lean`

**Proof Strategy**: Use the multivariate Stone-Weierstrass theorem with the subalgebra generated by all coordinate projections. Since coordinate projections separate points of ℝⁿ, the algebra is dense. The key challenge is ensuring the formalization handles the product topology correctly.

**Domain Bridges**: Analysis (multivariate approximation) <-> Machine Learning (high-dimensional function approximation)

**Lineage**: Builds on eml_stoneWeierstrass, emlSubalgebra_separatesPoints from this cycle.

**Ambition**: extension

### Direction 4: EML Complexity of Specific Function Classes

**Conjecture**: The EML complexity of exp(exp(x)) on [0,1] is exactly 2 for sufficiently small ε > 0. More generally, emlComplexity(exp^[n], 0, 1, ε) = n for small enough ε.

**Test**: (1) Show that exp^[n] is not a finite sum/product of terms involving fewer than n nested exponentials (this requires understanding the algebraic independence of exp towers). (2) Show that exp^[n] IS achievable with n exponentials (trivially true by iterExp(n)). (3) Computationally search for width-(n-1) approximations and show they fail.

**Impact**: If true, this gives the first exact computation of EML complexity for a natural function class, establishing that the complexity measure is non-trivial and captures genuine mathematical structure.

**Catalog References**: `Catalog/EML/ComplexityTheorems.lean`, `Catalog/EML/DepthEfficiency.lean`, `Catalog/Computation/PadicValuationDepth.lean`

**Proof Strategy**: For the upper bound, use iterExp(n) directly. For the lower bound, use differential-algebraic arguments: the function exp^[n](x) satisfies a differential equation of order n that cannot be satisfied by compositions of fewer than n exponentials.

**Domain Bridges**: Complexity Theory <-> Differential Algebra (Liouville theory), EML <-> Computation

**Lineage**: Builds on emlComplexity, EMLTerm.iterExp, EMLTerm.width_iterExp from this cycle.

**Ambition**: extension

### Direction 5: EML-Tropical Bridge

**Conjecture**: The tropical limit (replacing + with min and × with +) of the EML algebra yields exactly the max-plus algebra used in tropical geometry. Specifically, for a family of EML terms t_λ parametrized by λ → ∞, the rescaled limit (1/λ)·log(eval(t_λ, exp(λx))) converges to a tropical polynomial.

**Test**: (1) Take t_λ = log(exp(λa₁x + λb₁) + exp(λa₂x + λb₂)) and verify (1/λ)·t_λ(x) → max(a₁x + b₁, a₂x + b₂) as λ → ∞. (2) Prove this convergence formally for general EML terms.

**Impact**: This would establish a precise bridge between the "smooth" EML world and the "piecewise-linear" tropical world, showing that tropical geometry is a degeneration of EML theory. This connects to the Maslov dequantization program and has implications for optimization (tropical methods are used in linear programming).

**Catalog References**: `Catalog/Bridges/TropicalStoneWeierstrass.lean` (contains `tropical_stone_weierstrass_eml_dense`), `Catalog/Tropical/Applications.lean`, `Catalog/EML/EMLTropicalSemiring.lean`

**Proof Strategy**: Use the log-sum-exp identity: log(Σ exp(λfᵢ)) / λ → max(fᵢ) as λ → ∞. Formalize this as a pointwise convergence result and extend to uniform convergence on compact sets.

**Domain Bridges**: EML <-> Tropical Geometry, Analysis <-> Combinatorial Optimization

**Lineage**: Builds on eml_stoneWeierstrass, the tropical_stone_weierstrass_eml_dense theorem in the Catalog.

**Ambition**: extension
