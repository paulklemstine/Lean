# Future Directions — Automatic Sequences and the Zero-in-Sequence Problem

This cycle formalized the automata-theoretic core of the "halting problem for
automatic sequences": the zero-in-sequence problem reduces to DFA language
emptiness, which a pumping/pigeonhole argument collapses to a *finite* search
(`accepts_nonempty_iff_short`, `zero_value_iff_short`), with the companion
infinitude dichotomy (`accepts_infinite_of_long`, `zero_value_infinite`).  We
also pinned the boundary with `P`-recursive sequences: automatic sequences are
finite-valued (`autoSeq_range_finite`), so `a_n = n` is *not* automatic
(`id_not_automatic`), and unary automatic sequences are eventually periodic
(`unary_autoSeq_eventually_periodic`, built on the catalog's
`pow_eventually_periodic`).

The conjectures below are derived directly from those findings.

## C1. Sharp pumping threshold for the zero set is exactly the state count
**Conjecture.** For a DFAO with `s` states and output map `out`, the set
`{w | out (M.eval w) = z}` is infinite **iff** it contains a word of length in the
window `[s, 2s)`; equivalently, finiteness is decided by inspecting words of
length `< s` only, and infinitude by exhibiting one in `[s, 2s)`.

**The key insight is** that `DFA.pumping_lemma` already localizes the loop `b`
inside the first `s` letters (`a.length + b.length ≤ s`), so the entire
finite/infinite dichotomy is witnessed within a bounded length window rather than
unboundedly far out.

**Why now?** We have machine-checked both halves of the dichotomy
(`accepts_finite_iff` and `accepts_infinite_of_long`); tightening the witness
length from "≥ s" to the explicit window `[s, 2s)` is a finite combinatorial
refinement that our existing pumping infrastructure should discharge.

## C2. Eventual periodicity generalizes from unary to ultimately-constant inputs
**Conjecture.** If the representation stream `repr n` is eventually constant in
its tail letter (reads a fixed letter `a` after a bounded prefix), then
`n ↦ out (M.eval (repr n))` is eventually periodic, with period dividing the
order of `s ↦ M.step s a` in `Function.End σ`.

**The key insight is** that `unary_autoSeq_eventually_periodic` already shows the
tail dynamics are governed by a single endofunction's orbit; a bounded prefix only
shifts the starting state, leaving the eventual period intact.

**Why now?** `End_pow_apply` + `evalFrom_replicate` give an exact bridge between
list evaluation and monoid powers, so the prefix-shift argument is within reach of
the same `pow_eventually_periodic` engine we already invoked.

## C3. Finite-valuedness is the decisive separator: automatic ⊊ P-recursive
**Conjecture.** Every `k`-automatic integer sequence is `P`-recursive, but the
converse fails on exactly the unbounded `P`-recursive sequences; a `P`-recursive
sequence is automatic only if it takes finitely many values.

**The key insight is** that `autoSeq_range_finite` makes finite range a *necessary*
condition for automaticity, and `id_not_automatic` shows the simplest unbounded
`P`-recursive sequence `a_n = n` already violates it — so the boundary is "bounded
range", not the degree of the recurrence as the original conjecture claimed.

**Why now?** We have a formal, axiom-clean obstruction (`autoSeq_range_finite`);
the remaining task is to formalize the `automatic ⟹ P-recursive` direction and the
finite-range converse, both of which are structural rather than analytic.

## C4. Decidability survives the morphic boundary for *length-uniform* morphisms
**Conjecture.** The zero-in-sequence problem stays decidable for morphic
sequences generated by morphisms whose iterated images have lengths obeying a
linear recurrence (a strict subclass of general morphic sequences), via a pumping
argument on the substitution graph rather than the DFA.

**The key insight is** that the DFA pumping argument we formalized only used
finiteness of the state set plus a loop; a length-uniform morphism induces a
finite "block automaton" whose loops admit the same down-pump/up-pump dichotomy.

**Why now?** The reusable lemmas `exists_shorter_of_long` and
`accepts_infinite_of_long` are stated abstractly over any DFA, so porting them to
the block automaton of a length-uniform morphism is a definitional, not
foundational, step — letting us probe precisely where decidability breaks toward
the general (open) morphic case.

## C5. The decidable instance is a certified bounded-search algorithm
**Conjecture.** `decidableExistsOutputValue` extracts (via `Decidable.decide`) a
total algorithm that, on any explicitly presented DFAO over a finite alphabet,
returns a witness word of length `< s` whenever the value `z` is attainable, and a
proof of non-attainability otherwise — and this is *optimal* in worst-case search
depth.

**The key insight is** that `zero_value_iff_short` certifies correctness of the
bounded search and `accepts_infinite_of_long` certifies that no shorter universal
bound than `s` exists, so the instance is not just decidable but length-optimal.

**Why now?** The `Decidable` instance is already machine-checked; turning it into a
benchmarked, extracted decision procedure (the mission's "verify on 100 test
sequences" test) is now purely an engineering exercise on top of verified math.
