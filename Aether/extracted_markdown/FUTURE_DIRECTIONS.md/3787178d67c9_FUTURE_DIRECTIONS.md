# Future Directions — Quantum Gravity as a Topological Quantum Field Theory

## Synthesis

The file `Catalog/Physics/QuantumGravityTQFT.lean` realizes, from a single
first-principles input — a finite set of anyon labels `A` — the three structural pillars
that any candidate `2+1`-dimensional topological quantum gravity must satisfy:

1. the surface Hilbert space `H(Σ_g) = ℂ^{A^g}` is **finite-dimensional**, with
   `dim_ℂ H(Σ_g) = GSD A g = |A|^g`, tying directly into the catalog result
   `Physics.TopologicalOrderGenus.GSD_eq_card_fun`;
2. the **mapping class group acts unitarily**, realized as permutation matrices that lie
   in `Matrix.unitaryGroup` and preserve the `L²` inner product;
3. the **partition function equals the Turaev–Viro state sum**: the operator trace
   `Z(M_σ) = Tr ρ(σ)` of the mapping torus `M_σ` equals the number of flat
   `A`-connections (`partitionFunction_eq_turaevViro`), with the corollaries
   `Z(Σ_g × S¹) = dim H(Σ_g) = GSD A g` and topological (conjugation) invariance.

The unifying mechanism is sharp: **a permutation operator is simultaneously unitary and
has trace equal to its number of fixed points.** Unitarity of the mapping class group and
the Turaev–Viro state-sum formula are therefore two faces of one elementary fact about
`Equiv.Perm.permMatrix`. This is the kind of "explanatory elegance" the engine targets:
the proof *is* the physical mechanism.

## Research Directions

### 1. Gluing / multiplicativity: the cobordism functor is monoidal
The present file computes `Z` on mapping tori. The next step is the *gluing axiom*: for a
disjoint union of surfaces `H(Σ ⊔ Σ') ≅ H(Σ) ⊗ H(Σ')` and `Z(M ⊔ M') = Z(M)·Z(M')`,
upgrading `partitionFunction` to a symmetric monoidal functor on a (combinatorial)
cobordism category. **The key insight is** that `Conf A (g+g') = Conf A g × Conf A g'`
turns `EuclideanSpace ℂ (Conf A (g+g'))` into a tensor product and the permutation
representation into an external tensor product, so multiplicativity of `Z` is the
multiplicativity of traces under `⊗` — provable with `Matrix.trace_kron` /
`LinearMap.trace_tensorProduct`. **Why now?** The catalog already proves
`GSD_connected_sum : GSD A (g+h) = GSD A g · GSD A h`; the same factorization that powers
that dimension count powers the partition-function gluing axiom, so the algebra is in hand.

### 2. Modular representation of `SL(2,ℤ)` on the torus Hilbert space
On the torus (`g = 1`) the mapping class group is `SL(2,ℤ)`, generated by `S` and `T`. The
catalog's modular `S`-matrix (`TopologicalOrderGenus.ModularBraiding`, proven unitary)
should be exactly the image of the `S` generator under the unitary mapping-class action of
this file. **The key insight is** that the unitary `S`-matrix `S_{a,b} = |A|^{-1/2}χ_a(b)`
and the permutation/`T` action together satisfy `(ST)³ = S²` and `S⁴ = 1`, giving an
honest unitary representation of `SL(2,ℤ)` on `H(T²) = ℂ^A`. **Why now?** Both halves —
the unitary `S` (catalog) and the unitary mapping-class operators (this file) — are already
formalized and unitary; only the braid/modular relations remain, and these are finite
character identities provable by `Finset` orthogonality.

### 3. Verlinde-type formula: state sum from the `S`-matrix spectrum
Conjecture: for the abelian theory, the Turaev–Viro/Dijkgraaf–Witten partition function of
any closed `3`-manifold built from these surfaces is a polynomial in the eigenvalues of the
modular data, e.g. `Z(M_σ) = ∑_a (S_{0a})^{χ} (…)` for an appropriate Euler-characteristic
exponent. **The key insight is** that fixed-point counts (the state sum proven here) are
discrete Fourier transforms of the braiding bicharacter, so `#Fix(σ) = ∑_a 𝟙[σ-invariant
character]` rewrites the trace as a character sum — a finite-abelian Verlinde formula.
**Why now?** `partitionFunction_eq_turaevViro` reduces every `Z` to a fixed-point count,
and the catalog's character-orthogonality lemmas convert fixed-point counts into `S`-matrix
sums; the bridge is one Fourier-inversion lemma away.

### 4. Positivity / reflection positivity of the gravitational path integral
Conjecture: the partition function pairing `⟨M_σ⟩` defines a positive semidefinite Gram
matrix indexed by mapping classes, i.e. the theory is *reflection positive* —
`∑_{i,j} c_i \overline{c_j} Z(M_{σ_i^{-1}σ_j}) ≥ 0`. **The key insight is** that
`Z(M_{σ^{-1}τ}) = Tr(ρ(σ)^† ρ(τ)) = ⟨ρ(σ), ρ(τ)⟩_{HS}`, so the Gram matrix is a genuine
Hilbert–Schmidt Gram matrix of unitaries and hence PSD by construction. **Why now?**
`mcg_acts_unitarily` already places `ρ(σ)` in the unitary group, so the Hilbert–Schmidt
inner-product structure needed for positivity is immediate; this links directly to the
catalog's reflection-positivity / mass-gap files (`ReflectionPositivityMassGap`).

### 5. Non-abelian generalization via fusion categories
Replace the finite *group* `A` by a finite *fusion category* and the configuration space by
admissible edge-colorings of a triangulation; conjecture that the resulting Turaev–Viro
state sum is still triangulation-independent and equals an operator trace on a
finite-dimensional Hilbert space. **The key insight is** that the abelian proof never uses
commutativity beyond the bijection "flat connections on `M_σ` ↔ fixed configurations";
recasting "fixed configuration" as "admissible coloring invariant under the gluing
homeomorphism" should preserve the trace = state-sum identity at the level of `6j`-symbol
weighted sums. **Why now?** Mathlib's growing monoidal/fusion-category library makes the
non-abelian weights expressible, and the abelian file isolates exactly which lemma
(fixed-point trace) must be generalized — turning a vague program into a single concrete
target.
