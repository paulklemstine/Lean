# Future Directions: Testable Hypotheses for Formal Class Field Theory

## Overview

The current cycle established the algebraic skeleton: quotient refinement, ray class group architecture, abelian transfer, and capitulation framework. The following hypotheses identify the next five precise, falsifiable targets for extending formal class field theory.

---

## Hypothesis 1: Concrete Ray Class Group Construction

**Conjecture.** For the number field K = ℚ(√-5) and modulus 𝔪 = (2), a concrete `RayClassGroupData` instance can be constructed in Lean 4 using Mathlib's fractional ideal API, yielding a ray class group of order 4.

**Precise statement.** Define the group of fractional ideals of ℤ[√-5] coprime to (2), the subgroup of principal ideals generated by elements ≡ 1 mod (2), and the quotient. Prove that this quotient has cardinality 4 and that the canonical surjection to Cl(ℤ[√-5]) ≅ ℤ/2ℤ has kernel of order 2.

**Test.** Construct a term of type `RayClassGroupData (𝓞 (QuadraticField (-5))) (Ideal.span {2})` and prove `Fintype.card (RayClassGroup ...) = 4`.

**Success criterion.** Sorry-free proof compiling against Mathlib v4.28+.

**Failure criterion.** A proof that Mathlib's `FractionalIdeal` API cannot express "coprime to 𝔪" without first extending the localization/coprimality infrastructure. This would identify the exact missing abstraction.

**Impact.** This would be the first concrete ray class group computation in any proof assistant, validating the axiomatic framework established in the current cycle.

## Hypothesis 2: General Transfer Map via Transversals

**Conjecture.** The general group-theoretic transfer Ver: G → U^ab can be formalized using Quotient.out as a transversal, with independence from transversal choice proved after descent to the abelianization.

**Precise statement.** Define:
```
def transfer (G : Type*) [Group G] [Fintype G]
    (U : Subgroup G) : G →* Abelianization U :=
  -- Ver(g) = ∏_{s ∈ G/U} Abelianization.of (t(g·s)⁻¹ · g · t(s))
  -- where t : G/U → G is Quotient.out
```
Prove that this is a well-defined group homomorphism independent of the transversal choice, and that it specializes to the [G:U]-th power map when G is abelian.

**Test.** Construct the transfer and prove:
```
theorem transfer_eq_abelianTransfer_of_comm [CommGroup G] :
    transfer G U = (Abelianization.equivOfComm U).symm.toMonoidHom.comp (abelianTransfer U)
```

**Success criterion.** Sorry-free proof.

**Failure criterion.** Demonstration that Lean's `Quotient.out` introduces universe issues or that `Abelianization` lacks the necessary API for product manipulations over finite sets.

**Impact.** Opens the door to non-abelian capitulation theorems and eventually Tate cohomology.

## Hypothesis 3: Ambiguous Class Number Formula

**Conjecture.** For a cyclic quadratic extension L/K of number fields, the number of ambiguous ideal classes equals 2^(t-1) · h_K, where t is the number of ramified primes and h_K is the class number of K.

**Precise statement.** Define an "ambiguous class" as an element of Cl(𝓞_L) fixed by the non-trivial element of Gal(L/K). Prove that the subgroup of ambiguous classes has order 2^(t-1) · h_K / [𝓞_K× : 𝓞_K× ∩ N_{L/K}(L×)].

**Test.** For L = ℚ(√5, √-5) / K = ℚ(√-5), compute t and verify the formula matches the known class number of L.

**Success criterion.** Sorry-free proof for the quadratic case, or at minimum for one explicit quadratic extension.

**Failure criterion.** Identification of which parts of ramification theory (e.g., decomposition groups, inertia subgroups) are missing from Mathlib.

**Impact.** First formal genus theory result, connecting ramification to class group structure.

## Hypothesis 4: Conductor-Discriminant Formula for Abelian Extensions

**Conjecture.** For a finite abelian extension L/K of number fields, the discriminant ideal 𝔡_{L/K} equals the product of conductors: 𝔡_{L/K} = ∏_χ 𝔣(χ), where χ ranges over characters of Gal(L/K).

**Precise statement.** Define the conductor of a character χ: Gal(L/K) → ℂ× as the smallest modulus 𝔪 such that χ factors through Cl_𝔪(K). Prove the product formula for the discriminant.

**Test.** For the cyclotomic extension ℚ(ζ_p)/ℚ, verify that the formula gives 𝔡 = (p^(p-2)), matching the known discriminant.

**Success criterion.** Sorry-free proof for at least one explicit cyclotomic case.

**Failure criterion.** Identification of missing conductor theory or Gauss sum infrastructure.

**Impact.** The conductor-discriminant formula is a cornerstone of explicit class field theory and would connect the formal framework to analytic number theory.

## Hypothesis 5: Transfer Kernel = Norm Index in Finite Abelian Setting

**Conjecture.** For a finite abelian group G with subgroup U of index n, the order of ker(Ver) equals n · |G|/|G^n| where G^n = {g^n : g ∈ G} is the image of the n-th power map.

**Precise statement.** Prove:
```
theorem transfer_ker_card_eq
    {G : Type*} [CommGroup G] [Fintype G] (U : Subgroup G) :
    Fintype.card (abelianTransfer U).ker =
      Fintype.card G / Fintype.card (abelianTransfer U).range
```

This is equivalent to the first isomorphism theorem applied to the power map.

**Test.** Verify computationally for G = ℤ/12ℤ, U of index 3: ker has order 3, range has order 4, and 3 × 4 = 12.

**Success criterion.** Sorry-free proof using `MonoidHom.range_restrict` and `Subgroup.card_eq_card_quotient_mul_card_subgroup`.

**Failure criterion.** API gap in connecting `Fintype.card` with `Nat.card` for subgroups of finite groups.

**Impact.** Provides the precise quantitative bridge between transfer kernels and norm indices, which is the finite-group shadow of the norm index computation in local class field theory.
