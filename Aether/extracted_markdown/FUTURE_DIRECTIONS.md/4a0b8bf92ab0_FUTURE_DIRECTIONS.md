# Future Directions — Tropical Geometry of ReLU Networks

This cycle added two fully-verified (0-sorry) Lean files extending the catalog's
tropical-ReLU line:

* `MachineLearning/TropicalRationalAlgebra.lean` — the **vector-lattice algebra**
  of tropical rational functions on `ℝ^d` (closure under `+`, `neg`, `sub`,
  arbitrary `smul`, `sup`/`max`, `inf`/`min`, `ReLU`, finite sums) plus the
  **difference-of-convex (DC) decomposition**.
* `MachineLearning/DeepReLUTropical.lean` — the inductive predicate
  `ReLUComputable` capturing *arbitrary-depth* feed-forward ReLU networks, and the
  **main theorem** `ReLUComputable.isTropRational` (every deep ReLU network output
  is a tropical rational function), with corollaries: closure under
  `sub`/`neg`/`max`/`min` (maxout units are free via `max f g = ReLU(f-g)+g`),
  affine-combination layers (`affineComb`), continuity, and the DC corollary.

The conjectures below are precise and testable: each is intended to become a Lean
`theorem ... := by sorry` skeleton in a follow-up cycle.

---

## Conjecture 1 (Converse / CPWL completeness)

**Statement.** A function `f : ℝ^d → ℝ` is `ReLUComputable` **iff** it is a
continuous piecewise-linear (CPWL) function with finitely many affine pieces.
The `→` direction follows from `ReLUComputable.continuous` + `ReLUComputable.isDC`
(a difference of convex PL functions is CPWL); the open `←` direction is the deep
fact (Arora–Basu–Mianjy–Mukherjee): every CPWL function is computable by a ReLU
network.

**Testable milestone.** Prove the `d = 1` case first: every continuous
`f : ℝ → ℝ` that is affine on each piece of a finite partition is `ReLUComputable`,
by writing `f` as a finite signed sum of shifted ReLU "hinge" functions
`x ↦ ReLU(x - tᵢ)` (a telescoping of slope increments). This is a self-contained,
fully formalizable lemma and the key inductive engine for general `d`.

## Conjecture 2 (Tropical/lattice characterization)

**Statement.** The set `{ f | ReLUComputable f }` is exactly the **sublattice
subring-without-mult** (the lattice-ordered ℝ-vector space) of `C(ℝ^d, ℝ)`
generated by the affine functionals `x ↦ ⟨a,x⟩ + b`. Equivalently, it is the
smallest set containing all affine functions and closed under `+`, real `smul`,
`max`, and `min`.

**Testable milestone.** We already have closure under `+`, `smul`, `max`, `min`.
Formalize the generation statement: define `LatticeGen` as the inductive closure
of affine functions under `+`/`smul`/`max`/`min`, and prove
`ReLUComputable f ↔ LatticeGen f`. The `←` direction is immediate from the
proved corollaries; `→` needs `ReLU t = max t 0` expressed inside `LatticeGen`.

## Conjecture 3 (Newton-polytope bound on linear regions)

**Statement.** For a tropical polynomial `p = sup' over S of affine pieces`, the
number of distinct *linear regions* (maximal domains of affineness) of `p` is at
most `|S|`, and for a tropical rational `f = p - q` it is at most `|S| · |T|`.
Hence a one-hidden-layer ReLU net with `n` units has at most `n + 1` linear
regions per direction, while depth-`k` width-`w` nets can realize `Ω(w^k)`,
giving a **depth-vs-width region-count separation**.

**Testable milestone.** Define `linearRegionsLE (f) (N) : Prop` and prove the
`|S|` upper bound for `IsTropPoly` by induction on `S` using `Finset.sup'`. Then
exhibit the sawtooth/tent map `Tₖ` (an explicit `ReLUComputable` function with
`2^k` regions) and prove it needs `≥ 2^k` affine pieces — a concrete depth
separation witness.

## Conjecture 4 (Quantitative DC / piece bounds)

**Statement.** If `f` is computed by a ReLU network with `L` layers and total
hidden width `W`, then in the DC decomposition `f = p - q` produced by
`IsTropRational.dc`, both `p` and `q` are tropical polynomials whose number of
affine pieces is bounded by an explicit function `B(L, W)` (conjecturally
`2^{O(L)} · poly(W)`).

**Testable milestone.** Make the existential `IsTropRational.dc` *quantitative*:
track `S.card`/`T.card` through every closure lemma in
`TropicalRationalAlgebra.lean` (e.g. `sup` multiplies cardinalities, `add` adds,
`smul` preserves), yielding a `IsTropRationalWithBudget f N` refinement and a
budget-propagating version of `ReLUComputable.isTropRational`.

## Conjecture 5 (Polyhedral decision boundaries)

**Statement.** The decision boundary `{ x | f x = 0 }` of any `ReLUComputable`
classifier `f` is a **finite polyhedral complex** (a finite union of polyhedra),
and equals the tropical hypersurface where the two DC parts `p`, `q` coincide —
extending `TropicalReLUBridge.decisionBoundary_on_tropHypersurface` from one
hidden layer to arbitrary depth.

**Testable milestone.** Using `f = p - q` with `p, q` tropical polynomials,
prove `{x | f x = 0} = {x | p x = q x}` (already available pattern) and that this
locus is a finite union of the affine sets `{x | affEval abp x = affEval abq x}`
over maximizing pieces `abp ∈ S`, `abq ∈ T`. Formalize "finite union of
hyperplanes/polyhedra" and connect to `ConvexOn`/polyhedral API in Mathlib.
