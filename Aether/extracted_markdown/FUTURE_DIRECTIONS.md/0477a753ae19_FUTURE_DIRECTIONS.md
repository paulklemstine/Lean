# Future Directions: Coalgebraic Final Semantics for Simply Typed λ-Calculus

## Synthesis

The coalgebraic final semantics framework established here — where each simple type *A* determines a polynomial functor *F_A* and the behavioral quotient of finite *F_A*-coalgebras is itself a canonical coalgebra — opens five precise research directions. The unifying theme is that **type structure controls behavioral complexity**: the arity, order, and recursive structure of a type predict the size, shape, and classification of its canonical behavior objects. The first two directions are grand challenges that could reshape the relationship between type theory and automata theory. The remaining three are concrete extensions that build directly on the verified theorems in the catalog and can be formalized within the existing Lean infrastructure.

---

## Direction 1: Hennessy–Milner Characterization for Type-Indexed Coalgebras

**Conjecture:** On finite *F_A*-coalgebras generated by closed STLC terms of type *A*, behavioral equivalence coincides with modal equivalence at finite depth. That is, two states are bisimilar if and only if they satisfy the same modal formulas of depth at most *|C|*, where *|C|* is the carrier size.

**Test:** For types of order ≤ 2 and coalgebras with ≤ 20 states, exhaustively check whether the partition refinement stabilization (which computes behavioral equivalence) produces the same partition as formula separation (checking agreement on all modal formulas up to the stabilization depth). Any discrepancy — two states that agree on all finite-depth formulas but are distinguished by bisimulation, or vice versa — would disprove the conjecture.

**Impact:** This would establish a logical characterization of the canonical behavior object: behavioral states correspond to complete modal theories. It would connect coalgebraic semantics to modal logic in a way that makes the Hennessy–Milner theorem a *type-indexed family* of characterization results, one per simple type.

**Catalog References:**
- `CoalgebraicSemantics/Theorems.lean`: `behavioral_implies_nstep` (one direction)
- `CoalgebraicSemantics/Theorems.lean`: `behavEquivN_descending` (chain property)
- `Catalog/FINAL/Pythagorean/HennessyMilner.lean`: existing Hennessy–Milner infrastructure

**Proof Strategy:** Prove the converse of `behavioral_implies_nstep` on finite coalgebras: if *x ≈_n y* for all *n*, then *x ≈ y*. The key step is showing that the intersection ∩_n ≈_n is itself a bisimulation, which follows from finiteness (the descending chain of partitions stabilizes).

**Domain Bridges:** Modal logic ↔ coalgebra ↔ automata (Hennessy–Milner is the coalgebraic analogue of the Myhill–Nerode syntactic characterization).

**Lineage:** Extends `behavioral_implies_nstep` to a biconditional.

**Ambition:** Grand challenge — would establish a complete logical characterization of type-indexed behavioral semantics.

## Direction 2: Canonical Behavior Size Bounds from Type Complexity

**Conjecture:** For a simple type *A* of order *k* and arity *n*, the canonical behavior object *Can_A* (the final generated coalgebra) has at most *f(n, k)* states, where *f* is an explicit computable function. Specifically, we conjecture *|Can_A| ≤ 2^{n · k}* for types of order ≤ 3.

**Test:** For all simple types with size ≤ 15 and order ≤ 3, enumerate all closed η-long β-normal forms up to a size bound, construct their coalgebra representations, minimize, and record the quotient size. Plot quotient size against arity and order. If the bound *2^{n·k}* is violated, the conjecture is disproved.

**Impact:** Would give the first explicit finite-model-theoretic bounds on the semantic complexity of simple types. This would enable a priori estimation of the cost of program equivalence checking purely from type signatures.

**Catalog References:**
- `CoalgebraicSemantics/Defs.lean`: `STLCType.arityOf`, `STLCType.order`, `STLCType.size`
- `CoalgebraicSemantics/Theorems.lean`: `transition_arity_bounded_by_type`
- `Catalog/FINAL/Pythagorean/TypeComplexityBounds.lean`: existing complexity infrastructure

**Proof Strategy:** Induction on type order. Base case (order 0, i.e., base type): canonical object has 1 state. Inductive step: for *A → B*, bound *|Can_{A→B}|* in terms of *|Can_B|* and the number of distinct normal forms of type *A*.

**Domain Bridges:** Combinatorics ↔ type theory ↔ finite model theory.

**Lineage:** Builds on `transition_arity_bounded_by_type`.

**Ambition:** Grand challenge — explicit complexity bounds are the quantitative core of the theory.

## Direction 3: Dependent Polynomial Functors for Heterogeneous Branching

**Conjecture:** For each simple type *A*, there exists a *dependent* polynomial functor *G_A* (where the successor types vary with the branch index) such that the behavioral quotient of *G_A*-coalgebras generated by STLC terms is strictly finer than the *F_A*-quotient, capturing type-heterogeneous observations.

**Test:** Construct coalgebras for the type *(o → o) → (o → o → o) → o* using both *F_A* (uniform branching) and *G_A* (dependent branching that remembers which argument type each successor has). Compare the quotient sizes. If *G_A* produces strictly more equivalence classes on some example, the conjecture is supported.

**Impact:** Would upgrade the framework from "uniform polynomial" to "dependent polynomial" functors, capturing the full type-theoretic structure of STLC observations. This is the natural next step toward a complete coalgebraic semantics.

**Catalog References:**
- `CoalgebraicSemantics/Defs.lean`: `TypePolynomialFunctor` (to be generalized)
- `CoalgebraicSemantics/Theorems.lean`: `str_respects_behavioral_equiv` (quotient descent to be extended)

**Proof Strategy:** Define *G_A* by recursion on *A*: *G_base(X) = 1*, *G_{A→B}(X) = 1 + (G_A(X) × G_B(X))*. Prove quotient descent for *G_A* by extending the bisimulation-respects-structure argument.

**Domain Bridges:** Dependent type theory ↔ polynomial functors ↔ species theory.

**Lineage:** Generalizes `TypePolynomialFunctor`.

**Ambition:** Solid extension — well-scoped and directly builds on existing infrastructure.

## Direction 4: Coalgebra Morphism Category and Functoriality

**Conjecture:** The assignment *A ↦ Can_A* (type to canonical coalgebra) extends to a functor from the category of simple types (with type embeddings as morphisms) to the category of finite coalgebras (with coalgebra morphisms).

**Test:** For the type embeddings *o ↪ (o → o)* (constant function embedding) and *(o → o) ↪ ((o → o) → o → o)* (Church numeral embedding), construct the induced coalgebra morphism *Can_o → Can_{o→o}* and *Can_{o→o} → Can_{(o→o)→o→o}*. Check functoriality: does the composite morphism equal the direct morphism?

**Impact:** Would establish a categorical structure on the family of canonical behaviors, enabling compositional reasoning about type-indexed semantics. This is the entry point to a full categorical semantics.

**Catalog References:**
- `CoalgebraicSemantics/Theorems.lean`: `CoalgebraHom.comp`, `CoalgebraHom.id`
- `CoalgebraicSemantics/Theorems.lean`: `final_coalgebra_unique`

**Proof Strategy:** Define type embeddings, construct induced coalgebra morphisms by universality, verify functoriality from uniqueness.

**Domain Bridges:** Category theory ↔ type theory ↔ semantics.

**Lineage:** Extends `final_coalgebra_unique` to a functorial statement.

**Ambition:** Solid extension — moderate difficulty, high conceptual payoff.

## Direction 5: Stabilization Depth Bounds and Decidability

**Conjecture:** For any finite *F_A*-coalgebra *C* with *n* states and arity *k*, the modal depth equivalence ≈_d stabilizes (equals ≈_{d+1}) at depth *d ≤ n - 1*. Moreover, the stabilization depth is tight: for each *n* and *k ≥ 1*, there exists a coalgebra achieving stabilization depth exactly *n - 1*.

**Test:** For arities 1, 2, 3 and state counts 2 through 15, exhaustively enumerate all possible coalgebra structures (up to isomorphism), compute stabilization depths, and record the maximum. If any coalgebra stabilizes later than *n - 1*, the upper bound is disproved. If no coalgebra achieves *n - 1* for some *(n, k)*, the tightness claim is disproved.

**Impact:** Would provide the exact complexity of bisimulation decidability for type-indexed coalgebras, enabling optimal algorithm design.

**Catalog References:**
- `CoalgebraicSemantics/Theorems.lean`: `behavEquivN_descending`
- `CoalgebraicSemantics/Theorems.lean`: `behavEquivN_equiv`
- `algorithms.py`: `find_stabilization_depth`

**Proof Strategy:** Upper bound: standard pigeonhole argument on the partition refinement sequence. Tightness: construct a "chain" coalgebra of length *n* where each refinement step splits exactly one class.

**Domain Bridges:** Computational complexity ↔ partition refinement ↔ automata theory.

**Lineage:** Directly extends `behavEquivN_descending`.

**Ambition:** Solid extension — concrete and computationally testable.
