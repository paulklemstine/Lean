# Future Directions: Frankl's Union-Closed Conjecture

## 1. Bounded-Width Lattice Hypothesis

**Conjecture:** Every finite union-closed family whose associated join-semilattice has width (maximum antichain size) at most 4 satisfies Frankl's conjecture.

**Test:** Exhaustively enumerate all union-closed families on ground sets of size n ≤ 8 whose Hasse diagram has antichain width ≤ 4. For each, verify that some element appears in ≥ half the sets. The enumeration can be performed by generating all sub-join-semilattices of the Boolean lattice 2^[n] with bounded antichain width.

**Refutation criterion:** Any single union-closed family with width ≤ 4 and no element appearing in at least half its members.

**Impact:** Width bounds connect directly to Dilworth's theorem and chain decompositions. A proof for bounded width would establish Frankl for all families whose lattice structure is "thin," covering a vast class of structured set systems. It would also connect to the Sauer–Shelah lemma and VC-dimension bounds.

## 2. Singleton-Extension Hypothesis

**Conjecture:** For every finite union-closed family F with ground set U and |F| ≥ 3, there exists an element x ∈ U such that the subfamily F_x = {A ∈ F : x ∈ A} is itself union-closed and satisfies |F_x| ≥ |F|/2.

**Test:** Enumerate all union-closed families on ground sets of size n ≤ 7. For each family with ≥ 3 members, check whether some element x yields a union-closed subfamily F_x of size ≥ |F|/2.

**Refutation criterion:** A union-closed family where for every element x, either F_x is not union-closed or |F_x| < |F|/2.

**Impact:** If true, this provides a structural recursion for attacking Frankl: one could apply the conjecture inductively to F_x. The union-closure of F_x is a strong structural constraint that, combined with the frequency bound, could yield the full conjecture via an inductive argument on |U|.

## 3. Average-Cardinality Lower Bound Hypothesis

**Conjecture:** For every finite union-closed family F containing the empty set, the average cardinality of members satisfies:

  (1/|F|) ∑_{A ∈ F} |A| ≥ (1/2) log₂(|F|)

**Test:** Enumerate all union-closed families containing ∅ on ground sets of size n ≤ 9. Compute the average cardinality and compare with (1/2) log₂(|F|). This bound is weaker than the ground-size bound but is already known (Reimer 2003) and could serve as a stepping stone.

**Refutation criterion:** Any family violating the inequality. (Note: this is expected to hold — Reimer proved it — so the real test is formalizing Reimer's proof.)

**Impact:** Formalizing Reimer's result would provide a certified lower bound on average set size. Combined with Theorem A (our average-size criterion), this would yield Frankl for all families where log₂(|F|) ≥ |ground(F)|, i.e., "dense" families.

## 4. Closure-Rank Duality Hypothesis

**Conjecture:** If F is a union-closed family on ground set U, then the dual intersection-closed family F* = {U \ A : A ∈ F} has closure rank (the minimum number of generators needed for the associated closure operator) at most |U| - 1. Moreover, if F violates Frankl's conjecture, then F* has closure rank exactly |U|.

**Test:** For each union-closed family on n ≤ 7, compute the dual family F* and determine the minimum number of generators for the closure system generated by F*. Check whether the closure rank is ≤ n-1, and whether the rank correlates with near-violations of Frankl.

**Refutation criterion:** A union-closed family satisfying Frankl whose dual has closure rank = |U|, or a family violating Frankl (if one exists) whose dual has rank < |U|.

**Impact:** This would establish that counterexamples to Frankl (if they exist) are precisely the families whose dual closure systems are "maximally complex." This transforms the combinatorial conjecture into a structural algebraic question about closure operators, opening attacks via matroid theory and formal concept analysis.

## 5. Entropy-Frequency Majorization Hypothesis

**Conjecture:** For every finite union-closed family F with ground set U, the frequency vector (freq(x₁)/|F|, ..., freq(xₙ)/|F|) majorizes the vector (1/2, ..., 1/2, r) for some r ∈ [0, 1/2], where the number of 1/2 entries is max(0, ⌊|U|/2⌋ - k) for some family-dependent parameter k ≤ |U|/2.

More precisely: sort the frequencies in decreasing order as f₁ ≥ f₂ ≥ ... ≥ fₙ. Then f₁ ≥ 1/2 (which is Frankl's conjecture) and the partial sums ∑_{i=1}^{k} fᵢ ≥ k/2 for all k ≤ n.

**Test:** Enumerate all union-closed families on n ≤ 7. Compute the sorted frequency vector. Check whether partial sums satisfy ∑_{i=1}^k freq(xᵢ)/|F| ≥ k/2 for all k.

**Refutation criterion:** Any family and index k where the partial sum of the top k frequencies falls below k|F|/2.

**Impact:** This "strengthened Frankl" would imply the original conjecture as the k=1 case. If true, it would reveal that union-closure imposes a global positive-correlation structure on element frequencies, connecting to the FKG inequality and ferromagnetic models in statistical physics. Even partial results (proving it for k ≤ 3) would be significant advances.
