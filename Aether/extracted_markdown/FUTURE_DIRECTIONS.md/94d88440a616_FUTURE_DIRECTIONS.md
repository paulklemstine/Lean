# Future Directions: EML-KA Depth Theory and Duality Bridges

## Synthesis

This research cycle established three interconnected results: (1) the **depth-independence phenomenon** for EML-KA decompositions of monomials, showing that exp(a·log(x) + b·log(y)) = x^a · y^b has constant decomposition depth regardless of exponents; (2) the **Fenchel-Young duality bridge**, proving that the gap exp(x) + s·log(s) - s - x·s is nonneg with equality iff s = exp(x), establishing exp and log as convex conjugates; and (3) a complete **Bregman divergence theory** including Gibbs' inequality for KL divergence with equality characterization.

The most promising cross-domain connection is between **depth-independence** and **neural architecture design**. The depth-independence theorem (formally: `monomial_ka_max_depth`) shows that the EML-KA decomposition depth for any monomial is exactly 1, regardless of exponent magnitude. Combined with the polynomial extension (`poly_ka_spec`, `poly_ka_max_depth_le`), this means M-monomial polynomials have M-term, depth-1 representations. Since polynomials are dense in C(K) by Stone-Weierstrass, this implies that EML-KA decompositions with exp/log building blocks can approximate any continuous function at constant depth — a result with potential implications for neural network architecture (replacing ReLU with exp/log activations).

The Fenchel-Young bridge connects to optimization and information theory through the catalog's existing EML convexity results (`EML/EMLv17Core.lean`: `eml_convexOn_fst`, `eml_jointly_convex`) and fixed-point theory (`emlGmap_fixed_point_exists`). The KL-Bregman divergence (`klBregman_eq_zero_iff`) bridges to information geometry and optimal transport. Direction 1 has the highest breakthrough potential because it would establish EML as a *universal* approximation scheme — not just for polynomials, but for all continuous functions.

### Direction 1: EML-KA Universality for Continuous Functions

**Conjecture**: For every continuous function f : K → ℝ where K ⊂ (0,∞)² is compact, and every ε > 0, there exists a finite EML-KA decomposition d with Q terms such that sup_{(x,y) ∈ K} |d.eval(x,y) - f(x,y)| < ε.

Formally: ∀ f continuous on compact K ⊂ (0,∞)², ∀ ε > 0, ∃ Q and d : EMLKADecomp Q, ∀ (x,y) ∈ K, |d.eval x y - f x y| < ε.

**Test**: Implement a numerical optimizer that fits EML-KA decompositions (varying Q, coefficients, and exponents) to target functions like sin(x·y), log(x² + y²), and exp(-x²-y²) on [1,2]². Track approximation error vs Q. If error fails to converge to 0 as Q → ∞ for any target, the conjecture is false.

**Impact**: If true, establishes exp and log as universal building blocks for function representation — a concrete, constructive version of the Kolmogorov-Arnold theorem. This would have immediate implications for neural network design (EML-KAN architectures) and symbolic regression (structured search space). If false, identifies specific function classes that escape EML representation, which would be equally interesting.

**Catalog References**: `EML/EMLKADepthTheory.lean` (this cycle: `monomial_ka_spec`, `poly_ka_spec`), `Catalog/EML/KolmogorovArnoldEML.lean` (prior: `mul_ka_decomp_spec`, `eml_ka_inner_separates`), `Catalog/EML/EMLv17Core.lean` (`eml_convexOn_fst`).

**Proof Strategy**:
1. Start with the density of monomial polynomials Σ cᵢ x^{aᵢ} y^{bᵢ} (with real exponents) in C(K) for K ⊂ (0,∞)². This requires a Stone-Weierstrass-type argument: the algebra of functions {x^a · y^b : a, b ∈ ℝ} separates points (since log is injective) and contains constants (take a=b=0).
2. Formalize that the closure of the EML-KA function space (finite sums of exp(a·log(x) + b·log(y))) contains all monomial polynomials (established in this cycle by `poly_ka_spec`).
3. Show that the closure is itself dense in C(K) using Stone-Weierstrass, combined with the fact that the subalgebra generated by {x^a : a ∈ ℝ} is dense.
4. Key lemma needed: `rpow_separatesPoints` — for distinct (x₁,y₁), (x₂,y₂) ∈ (0,∞)², there exist a, b such that x₁^a · y₁^b ≠ x₂^a · y₂^b.

**Domain Bridges**: ApproximationTheory <-> MachineLearning, FunctionalAnalysis <-> NeuralArchitecture

**Lineage**: Builds on this cycle's `monomial_ka_spec`, `poly_ka_spec`, `monomial_ka_max_depth`, and prior catalog work in `KolmogorovArnoldEML.lean`.

### Direction 2: Tropical Limit of EML-KA Decompositions

**Conjecture**: Under the tropical limit (replacing log-semiring with (max, +)-semiring), EML-KA decompositions converge to tropical polynomial representations. Specifically, for the monomial decomposition d(x,y) = exp(a·log(x) + b·log(y)), the tropical limit t→0 of t·log(d(e^{u/t}, e^{v/t})) equals max(a·u, b·v).

More precisely, define the "tropicalization" of an EML-KA decomposition with Q terms as: Trop(d)(u,v) = lim_{t→0⁺} t · log(Σ_q exp(chain₁_q(e^{u/t}) + chain₂_q(e^{v/t})) / t).

**Test**: Compute the tropical limit numerically for the polynomial decomposition of 3x²y + 2xy³ on the grid [0,1]² using t = 1, 0.1, 0.01, 0.001. Verify convergence to the tropical polynomial max(2u+v+log3, u+3v+log2).

**Impact**: Would establish a formal bridge between EML-KA representation theory and tropical geometry, connecting continuous optimization (via Fenchel-Young) to combinatorial optimization (via tropical semirings). The depth-independence result might yield a tropical analog.

**Catalog References**: `Tropical/` (tropical semiring infrastructure), `EML/EMLKADepthTheory.lean` (`polyKADecomp`), `EML/EMLv17Core.lean` (`eml_def`).

**Proof Strategy**:
1. Formalize the tropical limit: for f_t(u) = t·log(exp(a_t(u)/t)), show convergence.
2. Use Laplace's method / log-sum-exp identity: t·log(Σ exp(fᵢ/t)) → max(fᵢ) as t → 0⁺.
3. Apply to each term of the polynomial decomposition.
4. Key Mathlib tools needed: `Filter.Tendsto`, `Real.log_sum_exp_le`.

**Domain Bridges**: EML <-> Tropical, ConvexOptimization <-> CombinatorialOptimization

**Lineage**: Builds on `polyKADecomp` and the Fenchel-Young bridge from this cycle.

**Ambition**: extension

### Direction 3: EML-Bregman Information Geometry

**Conjecture**: The EML-Bregman divergence D_EML(p,q) = D_exp(p,q) + D_{-log}(p,q) defines a valid divergence on (0,∞) that induces a Riemannian metric via g(p) = D_EML''(p,p) = exp(p) + 1/p². This metric has non-constant curvature, and geodesics on the EML manifold ((0,∞), g) have explicit parametric solutions.

**Test**: Compute the Gaussian curvature K(p) of the metric g(p) = exp(p) + 1/p² at p = 0.5, 1, 2, 5 and verify it is non-constant. Compute numerical geodesics between pairs of points and compare with exp/log interpolation.

**Impact**: Would establish an information-geometric foundation for EML, connecting to optimal transport (Wasserstein distance), statistical manifolds (Fisher information), and mirror descent convergence rates. The EML metric combines exponential growth (from D_exp) with inverse-square decay (from D_{-log}), creating a geometry that "sees" both large and small scales.

**Catalog References**: `EML/FenchelYoungBridge.lean` (`bregmanExp_nonneg`, `bregmanNegLog_nonneg`, `emlBregman_nonneg`), `EML/EMLv17Core.lean` (`eml_second_deriv_pos`, `eml_second_deriv_snd_pos`).

**Proof Strategy**:
1. Formalize the Hessian of D_EML at p = q to obtain the metric tensor.
2. Compute the Christoffel symbols and curvature tensor in 1D (scalar case).
3. Show the geodesic equation reduces to an ODE involving exp and inverse powers.
4. For the multidimensional case, use the product structure of the EML-KA decomposition.

**Domain Bridges**: EML <-> InformationGeometry, BregmanDivergence <-> RiemannianGeometry

**Lineage**: Builds on `bregmanExp_nonneg`, `bregmanNegLog_nonneg`, `emlBregman_nonneg` from this cycle and `eml_convexOn_fst` from catalog.

**Ambition**: extension

### Direction 4: Depth-Optimal EML Circuits and Lower Bounds

**Conjecture**: The function f(x) = exp(exp(x)) requires EML expression depth ≥ 2. More generally, the k-fold iterated exponential exp^{(k)}(x) requires EML expression depth ≥ k.

Formally: For any EML expression e with naDepth(e) < k, the function e.eval does not agree with exp^{(k)} on any open interval.

**Test**: Attempt to prove the depth-2 lower bound for exp(exp(x)) by contradiction: if e has naDepth ≤ 1, show e.eval is piecewise of the form a·exp(b·x+c) + d or a·log(b·exp(c·x+d)+e) + f, neither of which can match exp(exp(x)) on an interval.

**Impact**: Would establish that the depth hierarchy for EML expressions is strict — each additional level of exp/log nesting genuinely increases computational power. Combined with the depth-independence result for monomials (depth 1 suffices), this would precisely delineate what can and cannot be computed at each depth level. This is the EML analog of circuit complexity lower bounds.

**Catalog References**: `EML/EMLKADepthTheory.lean` (`EMLExpr.depth_zero_is_affine`), `Catalog/EML/EMLv17Core.lean` (`eml_tower_two`, `eml_tower_three`), `FINAL/MachineLearning/Expressions.lean` (`depth_lower_bound_from_derivative`).

**Proof Strategy**:
1. Start with the depth-0 result: `EMLExpr.depth_zero_is_affine` shows depth-0 ⇒ affine.
2. For depth-1: classify all depth-1 EML expressions. They have the form a₁·exp(b₁·x+c₁) + a₂·log(b₂·x+c₂) + a₃·x + a₄ (finite sum of such terms).
3. Show that depth-1 expressions have at most single-exponential growth, while exp(exp(x)) has double-exponential growth. Use asymptotic analysis.
4. Generalize by induction: depth-k expressions have at most k-fold exponential growth.

**Domain Bridges**: ComputationalComplexity <-> FunctionApproximation, CircuitComplexity <-> EML

**Lineage**: Builds on `EMLExpr.depth_zero_is_affine` from this cycle and `depth_lower_bound_from_derivative` from catalog.

**Ambition**: grand_challenge

### Direction 5: EML-KA for Neural Architecture Search

**Conjecture**: An EML-KAN (Kolmogorov-Arnold Network with exp/log activations) with M neurons per layer achieves O(1/M) approximation error for Lipschitz functions on compact subsets of (0,∞)^n, compared to O(1/√M) for ReLU-KAN.

**Test**: Train EML-KAN and ReLU-KAN networks on benchmark regression tasks (polynomial fitting, exponential decay fitting, power-law fitting) with M = 4, 8, 16, 32, 64 neurons. Compare convergence rates. If EML-KAN shows 1/M decay and ReLU-KAN shows 1/√M, the conjecture is supported.

**Impact**: Would provide theoretical justification for a new neural network architecture with provably better approximation rates for functions on positive domains. Practical applications in scientific computing (where exp/log naturally appear) and financial modeling (where power laws and exponential growth are ubiquitous).

**Catalog References**: `EML/EMLKADepthTheory.lean` (`poly_ka_spec`, `poly_ka_max_depth_le`), `Catalog/EML/KolmogorovArnoldEML.lean` (`ka_add_eval`), `Catalog/MachineLearning/ClosureNetworkUAP.lean` (`compact_exists_finite_dense_subset`).

**Proof Strategy**:
1. Formalize the EML-KAN architecture: layers alternate between EML chain evaluation and summation.
2. Use the polynomial approximation theorem (Jackson's theorem) to bound how well M monomial terms approximate a Lipschitz function.
3. Apply the depth-independence result to show each monomial term has constant depth.
4. Compare with ReLU approximation theory (Yarotsky 2017-style bounds).

**Domain Bridges**: MachineLearning <-> ApproximationTheory, NeuralArchitecture <-> FunctionRepresentation

**Lineage**: Builds on depth-independence results and polynomial decomposition from this cycle.

**Ambition**: extension
