# Future Directions: Tropical Gravity and Min-Plus Spacetime

## 1. Tropical Causal Cones and Alexandrov Topology on Finite Idempotent Spacetimes

**Hypothesis**: On a finite weighted directed graph with min-plus distance, the "causal future" of a point x (the set of points reachable with finite tropical cost) defines an Alexandrov topology whose open sets are exactly the down-sets of the causal partial order.

**Proof Strategy**: Define causal precedence x ≤ y iff the min-plus distance d(x,y) < ∞. Show this is a partial order (using the triangle inequality from tropical matrix multiplication). Then prove the Alexandrov topology (generated by causal diamonds) coincides with the order topology. The key lemma is that tropical convolution preserves causal reachability.

**Cross-Domain Connections**: Causal set theory (Sorkin program), domain theory (Scott topology on information orders), directed algebraic topology.

**Lean Formalization Target**: Define `tropicalCausalOrder` as a partial order on `Fin n` from a weight matrix, prove it is a partial order, and show the Alexandrov topology is T₀.

## 2. Tropical Ricci Flow as Iterated Inf-Convolution Smoothing

**Hypothesis**: Repeated application of the tropical Einstein step to edge weights (not vertex values) defines a "tropical Ricci flow" that monotonically decreases curvature concentration. Formally, if we define tropical curvature at a vertex as the difference between outgoing and incoming min-plus costs, then the iterated tropical transfer smooths this curvature.

**Proof Strategy**: Define tropical sectional curvature as `κ(x) = max_y K(x,y) - min_y K(x,y)`. Show that one step of tropical matrix self-convolution `K' = tropMatMul K K` satisfies `max_x κ'(x) ≤ max_x κ(x)`. This is a contraction estimate in the sup-norm of curvature. Use the nonexpansiveness theorem (tropicalEinsteinStep is nonexpansive) as a model.

**Cross-Domain Connections**: Ollivier-Ricci curvature on graphs, optimal transport, Hamilton's Ricci flow program, Bakry-Émery theory.

**Lean Formalization Target**: Define tropical curvature, prove the monotone decrease under iteration, and characterize the fixed points (flat tropical geometries).

## 3. Idempotent Black Hole Entropy via Counting Tropical Geodesics

**Hypothesis**: The number of distinct tropical geodesics (min-cost paths) from the boundary to the horizon in a finite tropical spacetime provides a combinatorial entropy that scales like the horizon "area" (the number of horizon-adjacent vertices).

**Proof Strategy**: On a layered graph with n shells and k angular vertices per shell, define the horizon as the fixed-point shell of radialUpdate. Count the number of distinct min-cost paths from the outermost shell to the horizon. Show this count equals k^(n_horizon) where n_horizon is the number of horizon vertices, giving S = n_horizon · log k, analogous to Bekenstein-Hawking entropy S = A/(4G).

**Cross-Domain Connections**: Bekenstein-Hawking entropy, loop quantum gravity state counting, tropical enumerative geometry, polymer models of black hole microstates.

**Lean Formalization Target**: Define tropical geodesic count on layered `Fin n × Fin k` graphs, prove the counting formula, and show proportionality to horizon size.

## 4. Tropical Einstein Constraint Equations as Min-Plus Feasibility

**Hypothesis**: The initial data for the tropical Einstein evolution (a function u₀ : α → ℝ satisfying certain min-plus inequalities) can be characterized as solutions to a tropical linear programming problem. The constraint surface is a tropical polyhedron, and the moduli space of valid initial data is a tropical convex set.

**Proof Strategy**: Define tropical constraint equations as inequalities of the form `tropicalEinsteinStep K u₀ ≤ u₀` (sub-solution condition) or `tropicalEinsteinStep K u₀ = u₀` (fixed-point condition). Show the set of sub-solutions is closed under tropical (min) superposition and under addition of nonneg constants. This makes it a tropical convex cone. Use the tropicalEvolution_nonincreasing theorem to show that sub-solutions generate convergent evolutions.

**Cross-Domain Connections**: Tropical convexity, tropical linear programming, constraint satisfaction in GR (ADM formalism), idempotent functional analysis.

**Lean Formalization Target**: Prove that the set `{u | tropicalEinsteinStep K u ≤ u}` is closed under pointwise min and under addition of nonneg constants.

## 5. Quantum-to-Tropical Semiclassical Comparison Theorem

**Hypothesis**: For a finite quantum system with Hamiltonian H on ℂ^n, the tropical limit ℏ → 0 of the path integral kernel K(x,y;t) = ⟨x|e^{-iHt/ℏ}|y⟩ converges (in a Maslov dequantization sense) to the tropical propagator tropicalEvolution. Formally, -ℏ log |K_ℏ(x,y;t)| → tropicalEvolution W t δ_y (x) as ℏ → 0, where W is the classical action matrix.

**Proof Strategy**: For finite-dimensional matrices, use the explicit formula for matrix exponentials and the Laplace method for sums (finite analogue of the stationary phase approximation). The key estimate is that for a sum S = Σ_j exp(f_j/ℏ), we have -ℏ log S → max_j f_j as ℏ → 0. This is the Maslov dequantization theorem. Apply it entry-by-entry to the transfer matrix.

**Cross-Domain Connections**: Maslov dequantization, WKB approximation, semiclassical analysis, tropical geometry as ℏ → 0 limit, Viro's patchworking.

**Lean Formalization Target**: Prove the finite Maslov dequantization lemma: for a finite family of reals {a_1,...,a_n}, -ε · log(Σ exp(a_i/ε)) → max_i a_i as ε → 0⁺. Then connect to the tropical propagator via matrix exponentials on `Fin n`.
