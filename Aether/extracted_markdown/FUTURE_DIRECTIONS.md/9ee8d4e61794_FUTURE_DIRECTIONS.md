# Future Directions: Tropical Normalization and Beyond

## 1. Extending to Distributive Tropical Polynomial Normal Forms

**Hypothesis:** The ACI normalizer for the `min`/`+` fragment can be extended to handle the distributive law `a + min(b, c) = min(a + b, a + c)`, yielding a complete decision procedure for the full tropical semiring identity problem.

**Strategy:**
- Define a canonical *tropical polynomial normal form* as `min` of *tropical monomials* (sums of variables with natural number coefficients).
- Implement distributive expansion: push `+` inside `min` until all `min`-operands are monomial sums.
- After expansion, apply the existing ACI normalizer to the resulting min-of-monomials expression.
- Prove soundness via a sequence of rewriting steps, each justified by the distributive law.

**Key Lemma to Formalize:**
```
∀ e : TropExpr, ∃ nf : TropPolyNF, eval σ e = eval σ (embed nf)
```

**Cross-domain connection:** Tropical polynomial normal forms correspond directly to *tropical hypersurfaces* in tropical geometry. A complete normalizer would enable automated reasoning about tropical varieties, including checking equality of tropical polynomials that define the same geometric object.

**Impact:** This would be the first certified decision procedure for tropical semiring identities, analogous to `ring` for commutative rings. It would make routine tropical algebra fully automatable, dramatically reducing the proof burden for formalized tropical geometry.

## 2. Dualizing to Max-Plus Algebra

**Hypothesis:** The entire normalization-reflection pipeline can be mechanically dualized from min-plus to max-plus algebra by replacing `min` with `max` and `⊓` with `⊔`.

**Strategy:**
- Define `MaxPlusTropExpr` with `tmax` replacing `tmin`.
- Port all definitions (flatten, sort, dedup, normalize, eval) by substituting `max` for `min`.
- Port all proofs using a systematic substitution of `min_comm` → `max_comm`, `min_assoc` → `max_assoc`, `min_self` → `max_self`.
- Alternatively, define an abstract framework parameterized by a lattice operation (any idempotent commutative monoid) and instantiate for both min and max.

**Key Innovation:** A *generic idempotent-commutative normalizer* parameterized by a type class:
```
class TropicalLike (α : Type) where
  op : α → α → α
  op_comm : ∀ a b, op a b = op b a
  op_assoc : ∀ a b c, op (op a b) c = op a (op b c)
  op_idem : ∀ a, op a a = a
```

**Cross-domain connection:** Max-plus algebra is the algebra of *longest paths*, *critical path scheduling*, and *discrete event systems*. A max-plus tactic would enable certified reasoning about manufacturing schedules, processor pipeline timing, and network flow optimization.

**Impact:** Two tactics for the price of one proof effort. The generic framework would also extend to other idempotent commutative operations (e.g., GCD, LCM) opening automation for lattice-theoretic reasoning.

## 3. Certified Shortest-Path and Dynamic Programming Verification

**Hypothesis:** The tropical normalization tactic can serve as the algebraic backend for *certified shortest-path algorithms* and *dynamic programming correctness proofs*.

**Strategy:**
- Formalize min-plus matrix multiplication as a concrete instantiation of tropical algebra.
- Express the Floyd-Warshall/Bellman-Ford recurrences as tropical polynomial identities.
- Use the normalization tactic to verify algebraic steps in correctness proofs (e.g., that the Bellman operator is well-defined up to ACI equivalence).
- Connect to existing Mathlib formalization of graph theory and matrix algebra.

**Concrete Target Theorems:**
```
theorem bellman_step_ACI (W V : Matrix n n ℝ) :
    tropical_min_plus_mul W (tropical_min_plus_mul W V)
    = tropical_min_plus_mul (tropical_min_plus_mul W W) V
```

**Cross-domain connection:** This connects tropical algebra to *verified algorithms* — a major area of formal methods research. Shortest-path algorithms underpin routing protocols (OSPF, BGP), logistics optimization, and VLSI timing analysis.

**Impact:** Would provide the first path toward *verified implementations* of shortest-path algorithms with algebraic correctness guarantees, going beyond functional correctness to structural algebraic properties.

## 4. Tropical Gröbner Bases and Simplification Engine

**Hypothesis:** Tropical Gröbner basis computation can be formalized and used to create a more powerful simplification engine that handles not just identities but also implications and conditional rewrites in tropical algebra.

**Strategy:**
- Formalize tropical ideals and the notion of a tropical basis.
- Implement a tropical Buchberger algorithm (or its tropical analogue using *standard pairs*).
- Prove termination and correctness of the tropical Gröbner basis computation.
- Use the computed basis for membership testing: given a tropical identity `f = g`, check if `f - g` (in a suitable sense) belongs to the ideal generated by the semiring axioms.

**Key Challenge:** Tropical Gröbner bases require a fundamentally different treatment from classical Gröbner bases because the tropical semiring lacks additive inverses. The theory of *tropical preorders* and *bend relations* must be formalized.

**Cross-domain connection:** Tropical Gröbner bases connect to *combinatorial optimization* (they encode linear programming feasibility), *algebraic statistics* (tropical sufficient statistics), and *phylogenetics* (tree metrics as tropical linear spaces).

**Impact:** A certified tropical Gröbner basis engine would be a unique capability in any proof assistant, enabling automated reasoning about tropical varieties and their applications across mathematics and science.

## 5. Piecewise-Linear Neural Network Verification via Tropical Geometry

**Hypothesis:** ReLU neural networks are tropical rational maps, and the tropical normalization tactic can be extended to verify properties of piecewise-linear functions arising from neural network computation.

**Strategy:**
- Formalize the correspondence: a ReLU neuron `max(0, w·x + b)` is a tropical polynomial.
- A feedforward ReLU network is a composition of tropical polynomial maps.
- Develop a tactic that can normalize the tropical polynomial representation of a small network and verify input-output properties.
- Connect to existing work on *certified robustness* and *adversarial example detection*.

**Key Theorem Target:**
```
theorem relu_network_tropical_form (W : List (Matrix m n ℝ)) (b : List (Vector m ℝ)) :
    ∃ p : TropPoly, ∀ x : Vector n ℝ, network_eval W b x = trop_eval p x
```

**Cross-domain connection:** This bridges tropical geometry with *AI safety* and *neural network verification* — two of the most active areas in computer science. The tropical perspective provides a clean algebraic framework for reasoning about piecewise-linear decision boundaries.

**Impact:** Could enable a new class of *algebraically certified* neural network verifiers that leverage tropical normal forms to check properties like monotonicity, Lipschitz bounds, and robustness certificates. This would be a breakthrough connection between pure mathematics and practical AI safety.
