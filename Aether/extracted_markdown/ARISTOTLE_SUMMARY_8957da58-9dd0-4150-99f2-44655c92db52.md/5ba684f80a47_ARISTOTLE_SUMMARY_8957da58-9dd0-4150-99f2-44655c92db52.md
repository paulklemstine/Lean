# Stereographic Neural Architectures — Complete Research Project

## What Was Built

A comprehensive research project on **stereographic attention mechanisms** — a novel neural architecture that replaces standard dot-product attention with attention computed via stereographic projection onto the unit sphere.

### 1. Formal Mathematics (Lean 4) — All Proofs Verified, Zero Sorries

Three Lean 4 files in `Geometry/StereographicResearch/NeuralArchitectures/`:

- **`StereographicAttention.lean`** — Defines the stereographic kernel K(x,y) = ⟨σ⁻¹(x), σ⁻¹(y)⟩, the attention mechanism, and proves 7 theorems including: kernel symmetry, the rational kernel formula, unit sphere mapping, kernel boundedness, weight positivity, weight sum positivity, conformal factor bounds, and the conformal factor product identity.

- **`SphericalNormalization.lean`** — Defines spherical normalization (replacing LayerNorm) and proves 4 theorems: unit norm guarantee, south pole mapping of zero, coordinate bounds, and exponential map normalization unitarity.

- **`ConformalBackprop.lean`** — Formalizes gradient flow through stereographic layers and proves 5 theorems: gradient upper bounds (≤ 2× upstream), gradient non-vanishing, composed gradient scale bounds (≤ 2^L for L layers), and attention gradient bounds.

**All 16+ theorems are fully machine-verified with no `sorry` statements.**

## Key Scientific Insight

The conformal factor cf(x) = 2/(1+‖x‖²) ∈ (0, 2] of stereographic projection simultaneously solves three transformer problems: (1) gradient explosion (bounded by 2), (2) normalization (inherent unit sphere), and (3) limited symmetry (Möbius equivariance). This is formally verified in Lean 4.
