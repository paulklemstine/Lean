# SVG Visualizations

High-quality SVG diagrams illustrating the SPB framework and its 50 algorithms.

## Files

### 1. `berggren_tree.svg`
The Berggren ternary tree of primitive Pythagorean triples, showing three levels of the tree with the three Berggren matrices and their Lorentz invariance properties.

### 2. `spb_framework.svg`
Overview of the entire SPB framework, showing the central SPB/EML core and its connections to five mathematical domains: Number Theory, Machine Learning, Cryptography, Physics, and Tropical Geometry.

### 3. `eml_operations.svg`
The EML universal arithmetic primitive and its derived operations: exponentiation, logarithm, inversion, and identity — plus four application domains (neural compression, universal approximation, instruction set architecture, and irrationality proofs).

### 4. `tropical_neural.svg`
The deep connection between tropical geometry and neural networks. Shows how ReLU networks compute tropical rational functions, with LogSumExp as the smooth bridge between the two worlds.

### 5. `fifty_algorithms_map.svg`
Complete map of all 50 algorithms organized into 10 thematic clusters, with verification statistics and theorem counts per domain.

### 6. `verification_pipeline.svg`
The pipeline from mathematical theorem to working algorithm: Theorem → Lean 4 Proof → Algorithm Design → Implementation, with the formal verification feedback loop.

## Usage

SVG files can be viewed directly in any modern web browser, or embedded in documents, presentations, and web pages. They scale to any resolution without loss of quality.
