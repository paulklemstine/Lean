# Twilight Zone Applications — Python Implementations
## The P² = P Mirror Framework

Five science-fiction-inspired applications, each grounded in the
mathematics of projective geometry, elliptic curves, and quantum
computation — all flowing from the single axiom **P² = P**.

## Quick Start

```bash
# Run all five applications
cd /path/to/project
python -m twilight_zone.holographic_vault
python -m twilight_zone.mirror_debugger
python -m twilight_zone.gravity_blockchain
python -m twilight_zone.vampire_qec
python -m twilight_zone.infinite_compression

# Or run all at once
python -m twilight_zone.run_all
```

**Requirements:** Python 3.8+, NumPy
