# Meta-Oracle Theory

**A Mathematical Framework for Self-Improving Intelligent Systems**

## Overview

This project develops **Meta-Oracle Theory** — a rigorous mathematical framework for reasoning about systems that improve their own reasoning processes. The theory combines fixed-point theory, information theory, and dynamical systems to prove fundamental results about iterative self-improvement.

## Machine-Verified Theorems (Lean 4 + Mathlib)

All theorems compile without `sorry` and use only standard axioms (`propext`, `Classical.choice`, `Quot.sound`).

| Theorem | Description |
|---|---|
| `MetaOracle.quality_mono` | Quality is monotonically non-decreasing under iteration |
| `contraction_geometric_decrease` | Contractive meta-oracles converge geometrically: d(Mⁿf, f*) ≤ kⁿ·d(f, f*) |
| `oracleEntropy_pos` | Oracle entropy H = -log(k) > 0 for genuine contractions |
| `oracleEntropy_additive` | Composing meta-oracles adds their oracle entropies |
| `no_free_lunch_avg` | Average improvement over all permutations is exactly zero |
| `exists_fixed_quality_strict` | Strictly improving maps on finite sets must have fixed points |
| `comp_contraction_rate` | Composition of k₁ and k₂ contractions is a k₁k₂ contraction |
| `portfolio_quality_bounded` | Convex portfolio quality lies between min and max individual quality |
| `AdaptiveMetaOracle.quality_mono_adaptive` | Adaptive meta-oracles preserve quality monotonicity |

## Key Concepts

- **Oracle Entropy** (H = -log k): A new information-theoretic quantity measuring improvement rate per iteration
- **Contraction Meta-Oracle**: A self-improvement operator that brings strategies closer together
- **Reflective Stability**: Fixed points of meta-oracles — strategies stable under self-modification
- **Portfolio Meta-Oracles**: Weighted combinations of specialized oracles (provably bounded)
