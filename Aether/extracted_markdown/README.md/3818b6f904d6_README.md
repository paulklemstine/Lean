# Berggren Pythagorean Triple Trees & Prime Number Connections

## Research Project Overview

This project investigates the deep connections between the **Berggren ternary tree** of primitive Pythagorean triples and the distribution of **prime numbers**. It combines:

- 🔬 **Computational experiments** in Python
- 📊 **Visualizations** of tree structure, prime distribution, and Gaussian integer patterns
- 📝 **Research notes** from an Oracle Council investigation
- 📄 **Research paper** with formal results and conjectures
- 📰 **Scientific American article** for general audiences
- ✅ **Formally verified proofs** in Lean 4 + Mathlib (in `../Pythagorean/`)

## Key Results

### Algebraic (Formally Verified in Lean 4)
- ✅ All three Berggren matrices preserve the Pythagorean property a² + b² = c²
- ✅ All three matrices preserve the Lorentz form Q = diag(1,1,−1)
- ✅ det(A) = det(C) = 1, det(B) = −1
- ✅ Every node in the tree satisfies a² + b² = c² (inductive proof)
- ✅ M₃⁻¹ · M₁ = S (theta group identity)

### Computational
- Prime hypotenuse density decays as ~d^{−0.6}, slower than the PNT prediction of ~d^{−1}
- Longest prime chain found: length 9 (5 → 13 → 53 → 193 → 433 → 773 → 1213 → 1753 → 2393)
- **Prime repulsion confirmed**: children of prime-hypotenuse nodes are less likely to have prime hypotenuses (after depth 2)
- Every prime factor of every hypotenuse is ≡ 1 (mod 4) — verified for all triples through depth 6
- Fermat's two-square theorem verified: all primes ≡ 1 (mod 4) below 500 appear exactly once as hypotenuses

### Theoretical Insights
- The tree structure reflects unique factorization in the Gaussian integers ℤ[i]
- Tree depth relates to continued fraction length of Euclid parameters
- The theta group Γ_θ (index-3 subgroup of SL(2,ℤ)) underlies the tree
- Connections to Patterson-Sullivan theory and the Selberg zeta function

## The Berggren Matrices

```
     ┌ 1  −2   2 ┐       ┌ 1   2   2 ┐       ┌−1   2   2 ┐
A =  │ 2  −1   2 │  B =  │ 2   1   2 │  C =  │−2   1   2 │
     └ 2  −2   3 ┘       └ 2   2   3 ┘       └−2   2   3 ┘
```

Starting from (3, 4, 5), these generate ALL primitive Pythagorean triples:
```
                            (3, 4, 5)
                         /      |      \
                   (5,12,13) (21,20,29) (15,8,17)
                  /   |   \    / | \    / | \
            (7,24,25) ... ...  ...  ...  ... ...
```
