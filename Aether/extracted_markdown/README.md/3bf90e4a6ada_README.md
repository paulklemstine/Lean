# AETHER v0.1.0-alpha

**Automated Epic Theorem Hypothesis Engine & Research**

AETHER is an autonomous mathematical research system that:
1. **Mines** your Lean 4 theorem catalog for gaps and opportunities
2. **Generates** novel conjectures, algorithms, and sci-fi mathematics
3. **Dispatches** structured proof requests to Aristotle (Harmonic's verified reasoning agent)
4. **Integrates** successful proofs back into the Catalog
5. **Logs** everything with telemetry, benchmarking, and experiment registries

---

## Quick Start

```bash
cd Catalog/Aether/

# 1. Scan the catalog frontier
python3 -m aether.engine --mode landscape

# 2. Generate research proposals
python3 -m aether.engine --mode generate --arc "Quantum Pythagoras" --count 5

# 3. Dispatch to Aristotle for proving
python3 -m aether.engine --mode dispatch

# 4. View telemetry dashboard
python3 -m aether.engine --mode report

# 5. Run a complete single cycle
python3 -m aether.engine --mode single --arc "Quantum Pythagoras"
```

## Configuration

Edit `config.yaml`:

```yaml
aristotle:
  api_key: "${ARISTOTLE_API_KEY}"  # Or set env var
  timeout_seconds: 300

catalog:
  root_dir: "../"                  # Relative to Aether/ directory
  db_path: "../Tools/output/catalog.json"

research:
  generation_batch_size: 5
  max_proposals_per_arc: 3

telemetry:
  log_dir: "./logs"
```

## Integration Pipeline

```
AETHER writes → Catalog/{domain}/AutoGen/{file}.lean
                    ↓
            tools/rescan (rebuilds database)
                    ↓
            lake build (verifies correctness)
                    ↓
            Next cycle: ConceptMiner sees new theorems
```

This creates a **closed loop** of autonomous mathematical discovery.

---

## Safety

- **Dry-run by default**: Integration validates patches but doesn't apply them unless `--no-dry-run` is passed.
- **Human review gate**: Set `require_human_review: true` in config.
- **Rollback**: Every patched file is backed up before modification.
- **Validation checks**: syntax, semantic, deduplication, import graph integrity.
