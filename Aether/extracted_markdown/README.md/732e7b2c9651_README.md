# Pythagorean Quadruple Factoring Framework

A formally verified framework for integer factoring based on Pythagorean quadruples, with research papers, interactive Python demos, and SVG visualizations.

## Formal Verification

All 35+ theorems are verified in Lean 4 / Mathlib with **zero sorry statements**. Key results:

| Theorem | Lean Name | Description |
|---------|-----------|-------------|
| Peel channels | `peel_channel_a/b/c` | Three difference-of-squares factorisations |
| Energy conservation | `energy_conservation` | K(q) = Φ(q)² |
| Gravity-energy product | `gravity_energy_product` | Product duality identity |
| Collision factor | `quadruple_collision_factor` | Factor extraction from collisions |
| Euler identity | `euler_four_square_identity` | Product of sums of 4 squares |
| Lebesgue parametrisation | `lebesgue_is_quadruple` | Parametric quadruple generation |
| Channel counts | `channel_count_k2/k3/k4/k8` | 5, 9, 14, 44 channels |

Only standard axioms used: `propext`, `Classical.choice`, `Quot.sound`, `Lean.ofReduceBool`, `Lean.trustCompiler`.
