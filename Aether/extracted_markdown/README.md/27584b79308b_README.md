# Quantum Gate Simulation via Octonion Projection

## Overview

This project implements and investigates a novel framework for quantum gate simulation
using the octonion algebra 𝕆 — the largest normed division algebra (dimension 8 over ℝ).
The core idea is a **lift–rotate–project** architecture:

1. **LIFT:** Embed a qubit state |ψ⟩ ∈ ℂ² into octonion space 𝕆 ≅ ℝ⁸
2. **ROTATE:** Apply a rotation in 8-dimensional space (SO(8) or its subgroup G₂)
3. **PROJECT:** Extract the transformed quantum state from the octonion

This creates an extended family of quantum gates that access the 14-dimensional
exceptional Lie group G₂ = Aut(𝕆), with novel phenomena including **octonionic leakage**
(amplitude transfer to hidden dimensions) and **non-associative gate composition**.

## The Gate Library

- **Standard gates:** X, Z, H, Phase(φ) — all standard single-qubit gates, zero leakage
- **Fano gates:** 7 families from the Fano plane — couple quantum and hidden sectors
- **G₂ generators:** 14 one-parameter families — preserve octonionic structure
- **Cross-sector gates:** Maximum quantum↔hidden amplitude transfer
- **Multiplication gates:** Left-multiplication L_q(x) = q·x — exhibit non-associativity

## Mathematical Foundation

The octonions 𝕆 are the unique 8-dimensional normed division algebra over ℝ.
Their multiplication is governed by the Fano plane and satisfies:
- **Norm multiplicativity:** ||ab|| = ||a||·||b||
- **Alternativity:** a(ab) = (aa)b
- **Moufang identities:** Three weakened associativity laws
- **NON-associativity:** (ab)c ≠ a(bc) in general
