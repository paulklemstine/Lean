# SVG Visualizations

Visual illustrations of the CatalogBuild framework's mathematical structures.

## Files

### `project_overview.svg`
High-level overview of the entire framework: 28,797 declarations, 22,334 theorems, 1,446 files, 178,634 lines. Includes a domain bar chart and key results summary.

### `berggren_tree.svg`
The Berggren tree structure showing how three matrix operations (B₁, B₂, B₃) generate all primitive Pythagorean triples from the root (3, 4, 5). Shows two levels of the ternary tree with verified properties.

### `spb_connections.svg`
A hub-and-spoke diagram showing the SPB operation at the center, connected to all 13 mathematical domains (Pythagorean, Tropical, EML, Machine Learning, Cryptography, Physics, etc.) with theorem counts.

### `tropical_relu.svg`
Side-by-side comparison of a ReLU neural network (left) and its equivalent tropical polynomial (right), demonstrating the formally verified equivalence. Includes key theorems and piecewise-linear visualization.

### `ai_algorithms_map.svg`
A thematic map of all 50 AI algorithms organized into 10 clusters, each grounded in specific formally verified results. Shows theorem counts per cluster.

### `eml_density.svg`
The EML operation tree and closure density growth. Left: EML computation tree from seed {1}. Right: exponential growth of closure set size and number line density visualization.

### `pythagorean_circle.svg`
Generated by `demos/demo_berggren_visual.py`. Shows 364 primitive Pythagorean triples as points (a/c, b/c) on the unit circle, color-coded by depth in the Berggren tree.
