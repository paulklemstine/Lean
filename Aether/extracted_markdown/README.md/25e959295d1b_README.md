## Overview

This project explores the radical mathematical idea that the entire geometric structure of an *n*-dimensional closed universe can be unfolded from a single point — the number **1** — through iterated inverse stereographic projection. The "Big Bang" singularity corresponds to the north pole of the resulting sphere: the point at infinity added by Alexandroff one-point compactification.

### Key Insight

Inverse stereographic projection wraps flat Euclidean space ℝⁿ onto the sphere Sⁿ. Under this mapping:
- The **origin** becomes the south pole (the "observer")
- **Infinity** becomes the north pole (the "Big Bang")
- The entire infinite space has **finite volume** = Vol(Sⁿ)
- Local physics is **indistinguishable** from flat space (conformal invariance)
