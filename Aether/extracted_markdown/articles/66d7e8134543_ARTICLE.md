# The Algebra of Forgetting: How Mathematics Reveals the Hidden Structure of Memory

*Every time you remember something, you forget everything else. A new algebraic framework shows that this loss isn't chaos — it's geometry.*

---

## The Filing Cabinet That Forgets

Imagine a filing cabinet with exactly ten drawers. Every morning, you receive a stack of documents — news reports, memos, receipts — and you must file each one into a drawer. The catch: the cabinet doesn't care about the content. It assigns each document to a drawer based on a fixed rule — perhaps the first letter of the title, or the date modulo ten.

This cabinet is a *memory system*. It compresses an infinite stream of inputs into a finite number of states. And here's the deep insight: the way it compresses — the specific rule it uses — has a precise algebraic structure that mathematicians can now describe with the same rigor used for symmetry groups and geometric spaces.

A team of researchers has developed what they call *Memory Compression Algebra*, a framework that treats every finite-state memory system as an algebraic object living in a tropical geometric space. Their results reveal that information loss isn't random or chaotic. It follows strict mathematical laws — laws that connect automata theory, abstract algebra, and a strange variant of geometry where addition replaces multiplication.

## Compression as Homomorphism

The key idea is deceptively simple. Any finite-state system — a computer with limited RAM, a neuron with a fixed number of firing patterns, a bureaucracy with a finite number of filing categories — can be modeled as a *monoid homomorphism*. That's a mathematical function that preserves the structure of sequential composition: processing input A followed by input B gives the same result as processing the combined input AB.

The "free monoid" is just the set of all possible input sequences over some alphabet. The homomorphism maps these sequences to a finite set of states. The image of this map — the set of actually reachable states — is where the interesting mathematics lives.

Think of it this way: the English language has roughly 170,000 words in current use, but most people's active vocabulary is about 20,000–35,000 words. The compression from the full language to an individual's working vocabulary is a kind of memory homomorphism. The structure of what's preserved — and what's lost — tells you something deep about the system.

## The Stabilization Theorem

The first major result is the *Idempotent Stabilization Theorem*. In any finite memory system, if you keep feeding the same input repeatedly, the system eventually reaches a state that doesn't change anymore. Mathematically: for any element *a* in a finite monoid, there exists a positive integer *n* such that *a^n* is *idempotent* — meaning *a^n · a^n = a^n*.

This isn't just a curiosity. It's the algebraic foundation of habituation, the phenomenon where repeated stimulation produces a diminishing response. Your brain stops noticing the ticking clock. A market stops reacting to repeated news. A computer cache reaches a steady state. The theorem says this behavior is *inevitable* in any finite-state system — it's a mathematical law, not an empirical observation.

The proof uses a beautiful pigeonhole argument. In a finite monoid with *m* elements, the sequence *a, a², a³, ...* can have at most *m* distinct values. So some two powers must be equal: *aⁱ = aʲ* with *i < j*. The gap *d = j - i* creates a cycle, and from this cycle, one can extract an idempotent power. The construction is explicit and the bound is computable.

## The Product Bound: Joint Memory Can't Exceed the Sum of Its Parts

The second deep result concerns *joint memory systems*. Suppose you have two filing cabinets — one that categorizes documents by topic (10 categories) and one that categorizes by date (30 bins). If you build a combined system that tracks both topic *and* date, you might expect up to 300 categories. The *Tropical Capacity Subadditivity Theorem* makes this precise.

For any two compression functions *f₁* and *f₂* applied to the same input stream, the number of distinct pairs *(f₁(x), f₂(x))* is at most the product of their individual image sizes:

> |image(f₁, f₂)| ≤ |image(f₁)| · |image(f₂)|

Take logarithms, and this becomes an *additive* inequality:

> log|image(f₁, f₂)| ≤ log|image(f₁)| + log|image(f₂)|

This is the *tropical capacity bound*. The word "tropical" comes from a branch of geometry where the usual operations of addition and multiplication are replaced by maximum and addition. In this tropical world, the logarithm of image size — the *capacity* — behaves like a metric, and the subadditivity law is the triangle inequality of this tropical metric space.

The implications are profound. It means that *information is subadditive*: combining two memory systems can never produce more information than the sum of what each system captures individually. This is a fundamental constraint on any architecture that combines multiple finite-state components.

## The Compression Ordering

Perhaps the most elegant result is about the *factoring relationship* between memory systems. We say that one compression function *f* "factors through" another function *g* if you can recover *f* from *g* — that is, if there exists a decoder *h* such that *f = h ∘ g*. This means *g* carries at least as much information as *f*.

The theorem states: if *f* factors through *g*, then |image(f)| ≤ |image(g)|. Information content, measured by image cardinality, respects the factoring order. This creates a *lattice* of memory systems ordered by information content, where the top element is the identity function (perfect memory) and the bottom is any constant function (total amnesia).

This lattice structure connects directly to the *congruence lattice* of universal algebra. Every equivalence relation on the input space that is compatible with the memory system's operation corresponds to a quotient — a coarser view of the world. Finer equivalence relations distinguish more inputs, yielding larger quotients and higher capacity. The researchers proved that quotient cardinality is monotone with respect to refinement: if equivalence relation *r₁* is finer than *r₂*, then the quotient by *r₁* has at least as many classes as the quotient by *r₂*.

## The Tropical Connection

Why "tropical"? The name comes from Brazilian mathematician Imre Simon, who pioneered the study of algebraic structures where "addition" is replaced by "maximum." In classical algebra, you add and multiply numbers. In tropical algebra, you take maxima and add. This seemingly bizarre substitution turns out to be natural for optimization problems, phylogenetics, and — as this research shows — information theory.

The logarithm of image cardinality is a *tropical valuation*: it converts multiplicative relationships (products of image sizes) into additive ones (sums of capacities). The cascade product bound — that the total state space of a composed system is at most the product of individual state spaces — becomes, in tropical language, the statement that capacity is subadditive under composition.

This bridge between tropical geometry and memory theory opens unexpected doors. Tropical geometry has deep connections to algebraic geometry, combinatorics, and even string theory. By placing memory systems inside a tropical framework, the researchers have potentially opened a pipeline for importing results from all these fields into the study of finite-state computation.

## The Conjecture That Failed — and Why That Matters

Not every conjecture survived scrutiny. The team initially hypothesized that tropical capacity would be a *modular* function on the lattice of congruences — satisfying the identity *v(r₁ ∨ r₂) + v(r₁ ∧ r₂) = v(r₁) + v(r₂)* for any two equivalence relations. This would have been a beautiful structural result, connecting memory theory to modular lattice theory.

But the conjecture is false. A simple counterexample on six elements shows that capacity is neither modular nor even submodular in general on the full partition lattice. This failure is itself informative: it tells us that the tropical structure of memory is *genuinely more complex* than the lattice structure alone suggests. The interplay between the algebraic operation (the monoid structure) and the combinatorial structure (the partition lattice) creates phenomena that neither theory alone can explain.

## From Filing Cabinets to Brains

The practical implications extend far beyond pure mathematics. Any system that processes sequential inputs through a finite number of states — neural networks, communication protocols, biological signaling pathways, economic markets — is a memory system in this algebraic sense.

The stabilization theorem explains why neural circuits habituate. The product bound constrains how much information can be extracted by combining sensory modalities. The congruence-capacity duality suggests that the "resolution" of a memory system — how finely it distinguishes inputs — is determined by its algebraic structure, not its physical implementation.

Perhaps most intriguingly, the tropical framework suggests that the "space" of all memory systems has its own geometry — a non-Euclidean geometry where distances are measured by information loss. In this geometry, two memory systems are "close" if they retain similar information, and "far apart" if one forgets what the other remembers. Navigating this space — finding memory systems that are optimally adapted to their environment — becomes a problem in tropical optimization.

We are only beginning to explore this landscape. But the algebraic framework laid down in this research provides the first rigorous map of terrain that engineers, neuroscientists, and mathematicians will be exploring for decades to come.
