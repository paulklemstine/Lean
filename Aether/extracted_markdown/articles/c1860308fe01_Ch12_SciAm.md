## What Idempotent Means — And Why It Matters

A function f is **idempotent** if applying it twice gives the same result as applying it once:

```
f(f(x)) = f(x)  for all x
```

Press the "elevator call" button. The elevator comes. Press it again. The elevator is still there. The button press is idempotent.

```
    ╔══════════════════════════════════════════╗
    ║         IDEMPOTENT OPERATIONS            ║
    ║                                          ║
    ║   max(max(x,0), 0) = max(x,0)   (ReLU)  ║
    ║   floor(floor(x)) = floor(x)             ║
    ║   sort(sort(list)) = sort(list)           ║
    ║   σ(σ⁻¹(t)) = t         (stereographic) ║
    ║   O(O(x)) = O(x)        (oracle)         ║
    ║   Universe(Universe) = Universe           ║
    ╚══════════════════════════════════════════╝
```

The researchers proved the master theorem:

```lean
theorem stereo_round_trip_idempotent (t : ℝ) :
    stereoFwd₁ (invStereo₁ t) = t
```

The stereographic projection and its inverse compose to the identity. The encoding-decoding process is idempotent. The universe, viewed as the process of encoding and decoding itself, maps to itself.

## The Fixed Point Theorem

For any idempotent function f, the image equals the set of fixed points:

```
Image(f) = {x : f(x) = x}
```

**What an idempotent projects onto is exactly what it leaves unchanged.**

```
    Idempotent function f:
    
    ●───→ f(●) = ★         ★ is a fixed point
    ○───→ f(○) = ★         (f(★) = ★)
    △───→ f(△) = ◆         ◆ is a fixed point
    □───→ f(□) = ◆         (f(◆) = ◆)
    
    Image = {★, ◆} = Fixed points
```

In oracle terms: the questions the oracle can meaningfully answer are exactly the questions whose answers don't change when you ask again. The oracle's domain of expertise IS its set of fixed points.
