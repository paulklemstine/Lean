# The Mathematics of Forgetting: How Functions Lose Information

*Every computation destroys information. A new mathematical theory measures exactly how much.*

---

When you multiply 7 × 8 to get 56, you can reverse the process — if you know one factor, you can recover the other. But when a computer reduces a high-resolution photograph to a thumbnail, something irreversible happens. The millions of pixels in the original image are compressed into a few thousand, and no algorithm, no matter how clever, can reconstruct the original from the thumbnail alone. Information has been permanently lost.

This basic asymmetry between reversible and irreversible processes runs through all of mathematics, computer science, and physics. In 1961, the physicist Rolf Landauer made a startling connection: the loss of information is not merely an abstract mathematical phenomenon but a physical one. Every time a computer erases a bit of information, a tiny but measurable amount of heat must be released — a minimum of *kT* ln 2 joules, where *k* is Boltzmann's constant and *T* is the temperature. In a world increasingly concerned with the energy consumption of data centers and artificial intelligence, Landauer's principle has moved from a theoretical curiosity to a practical constraint.

But how do you measure exactly how much information a function destroys? Shannon's information theory, developed in the late 1940s, measures the information content of messages. A new mathematical framework, which we call **functorial entropy**, turns this lens on the functions themselves.

## Counting the Fibers

The key idea is beautifully simple. Consider any function *f* that maps elements from one finite set to another. For each output value *b*, count how many inputs map to it. This count — the size of the **fiber** over *b* — tells you how much merging *f* does at that point.

If every fiber has exactly one element, the function is injective (one-to-one), and no information is lost. If some fiber has 100 elements, then seeing that particular output tells you only that the input was one of those 100 possibilities — you've lost log(100) ≈ 6.6 bits of information about which specific input occurred.

The functorial entropy *H(f)* averages this loss across all possible inputs, weighted by how likely each output is when the input is uniformly distributed. The formula is:

*H(f) = Σ (nᵦ / |α|) · log(nᵦ)*

where *nᵦ* is the number of inputs that map to output *b*, and |α| is the total number of inputs. This elegant expression captures everything about the information-destroying character of *f*.

## Three Fundamental Theorems

The theory yields three results of genuine mathematical depth.

**The Zero-Entropy Characterization.** A function has zero entropy if and only if it is injective. This is the precise mathematical statement of the intuition that "no merging means no information loss." The proof requires showing that if any fiber has size greater than 1, it contributes a strictly positive amount to the total entropy — a statement that seems obvious but requires careful analysis of when logarithms vanish on natural numbers.

**The Data Processing Inequality.** If you apply a function *f* and then a second function *g*, the total information loss can only increase: *H(g ∘ f) ≥ H(f)*. In other words, further processing cannot recover lost information.

This theorem's proof reveals a deep connection to convex analysis. The function *t · log(t)* has a remarkable property called **superadditivity**: if you split a pile of *n* objects into groups and compute *t · log(t)* for each group, the sum is always less than or equal to *n · log(n)* for the whole pile. When *g* merges fibers of *f*, it creates larger fibers, and superadditivity guarantees that the entropy increases.

The data processing inequality is one of the pillars of information theory, and seeing it emerge from pure combinatorics — without any reference to probability distributions, channel capacities, or coding theorems — reveals it as a far more fundamental mathematical fact than its usual presentation suggests.

**Entropy Stabilization.** When a function maps a finite set to itself (an endomorphism), you can iterate it: apply *f*, then *f* again, then again. The entropy of the *n*-th iterate, *H(fⁿ)*, forms a non-decreasing sequence — each application can only lose more information. But since the set is finite, there are only finitely many possible fiber patterns. A monotone sequence in a finite set must eventually become constant. This means every endomorphism has a well-defined **entropy rate**: the value at which its information loss stabilizes.

This stabilization theorem connects to the theory of dynamical systems. The entropy rate of an endomorphism is an invariant that captures the "eventual information loss per step" — a concept reminiscent of the Kolmogorov-Sinai entropy in ergodic theory, but defined purely combinatorially without requiring any measure-theoretic machinery.

## The Entropy Spectrum

Perhaps the most intriguing new concept is the **entropy spectrum** of a finite set: the collection of all entropy rates achievable by endomorphisms on that set. This set is a numerical invariant that encodes deep structural information about the possible dynamics on the set.

For any finite set, zero is always in the spectrum (achieved by the identity function). But what other values appear? For a set with *n* elements, the maximum possible entropy (achieved by a constant function) is log(*n*). Between these extremes lies a rich landscape of achievable values, determined by which partitions of *n* can be realized as fiber structures of iterable functions.

Understanding the entropy spectrum connects to partition theory, a classical subject with deep roots in number theory and combinatorics. Each point in the spectrum corresponds to a particular way of organizing *n* objects into groups that is "dynamically achievable" — that is, realizable as the eventual fiber structure of some iterated function. This constraint is far more restrictive than merely being a partition of *n*, and characterizing exactly which partitions are dynamically achievable is an open problem.

## Landauer's Principle, Quantified

The connection to physics goes beyond metaphor. The functorial entropy of a function is precisely the **Landauer cost** of implementing that function irreversibly — the minimum number of bits that must be erased, and hence the minimum amount of heat that must be dissipated.

The data processing inequality then takes on physical meaning: composing functions can only increase the total thermodynamic cost. And the zero-entropy characterization becomes Landauer's principle itself: a computation has zero thermodynamic cost if and only if it is reversible.

As we enter an era where the energy consumption of computation is becoming a civilizational concern, having a rigorous mathematical theory of computational irreversibility is not merely an intellectual luxury. The functorial entropy framework provides the precise language needed to reason about the fundamental physical limits of computation.

## Looking Forward

The theory of functorial entropy opens several directions for future investigation. The most ambitious is the **composition superadditivity conjecture**: that pre-composing with a surjection also cannot decrease entropy. Together with the proven post-composition monotonicity, this would complete the picture of how entropy behaves under all compositions — a result that would connect to the log-sum inequality, one of the deepest inequalities in all of information theory.

Another frontier is the entropy theory of **functors between categories**, lifting the theory from mere functions to the richer world of structure-preserving maps. When a functor maps one category to another, it transforms not just objects but the morphisms (arrows) between them. The entropy of a functor would measure how much structural information about the source category is lost in the translation — a notion that could illuminate everything from database theory to theoretical physics.

Mathematics often progresses by taking familiar concepts and recognizing them as special cases of something deeper. Shannon entropy measures the information in a probability distribution. Functorial entropy measures the information destroyed by a function. The data processing inequality, long understood as a theorem about communication channels, turns out to be a theorem about the combinatorics of fibers — one of the oldest and most basic structures in mathematics. Sometimes the deepest truths are hiding in the simplest objects, waiting for the right lens to bring them into focus.
