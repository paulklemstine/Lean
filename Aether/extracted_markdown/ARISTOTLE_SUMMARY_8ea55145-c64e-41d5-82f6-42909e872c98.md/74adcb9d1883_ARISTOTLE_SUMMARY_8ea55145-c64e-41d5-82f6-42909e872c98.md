# Summary of changes
Created `rsa_factor.py` — a comprehensive Python integer factoring toolkit targeting the RSA Challenge numbers.

**Algorithms implemented (7):**
1. **Trial division** — small primes up to 10⁶
2. **Fermat's factorization** — best when factors are close to √n
3. **Pollard's rho** (Brent's improvement) — O(n^{1/4}), good for factors up to ~25 digits
4. **Pollard's p-1** — finds factors p where (p-1) is smooth
5. **Williams' p+1** — finds factors p where (p+1) is smooth, using Lucas sequences
6. **Lenstra's ECM** (Elliptic Curve Method) — Montgomery curves with Suyama parametrization, good for factors up to ~35 digits in Python
7. **Quadratic Sieve** — GF(2) linear algebra over smooth relations, for medium composites

**Features:**
- `--target RSA-100` — attempt a specific RSA target with full algorithm cascade
- `--number N` — factor any integer
- `--benchmark` — benchmark all algorithms on random semiprimes of increasing size
- `--all-targets` — attempt all RSA targets in order
- Default mode: verify known factorizations + show GNFS difficulty estimates
- Per-algorithm timeouts prevent hanging
- Known factorizations stored and verified for RSA-100, 110, 120, 129, 140, 155
- GNFS complexity estimates for all targets (RSA-2048: ~10^35 ops, ~10^19 years)

**Benchmark results (random semiprimes):**
- 10-digit: instant (trial division)
- 20-digit: <0.1s (Pollard's rho or ECM)
- 30-digit: <1s (ECM with B1=5000)
- 35-digit: ~4s (ECM with B1=50000)
- 40-digit: at the boundary of pure Python feasibility

**Honest about limitations:** The unfactored RSA numbers (RSA-260+) require the General Number Field Sieve running on large compute clusters. The script clearly documents this and recommends CADO-NFS, msieve, yafu, or GMP-ECM for serious factoring.
