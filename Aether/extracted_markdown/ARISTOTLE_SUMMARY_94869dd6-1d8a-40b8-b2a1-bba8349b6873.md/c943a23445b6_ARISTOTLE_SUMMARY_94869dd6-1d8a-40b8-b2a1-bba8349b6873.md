### Answer

The R₁₁₁₁ descent for Pythagorean quadruples is the quaternion Euclidean algorithm in disguise. The reflection through (1,1,1,1) in Minkowski space corresponds to division by σ = 1+i+j+k in the Lipschitz integer quaternions. The key dictionary:

| Quaternion concept | Descent tree concept |
|---|---|
| Integer quaternion α | Parametrizes quadruple (a,b,c,d) via Euler |
| Squared norm \|α\|² | Hypotenuse d |
| σ = 1+i+j+k, \|σ\|² = 4 | Reflection vector (1,1,1,1), η(s,s) = 2 |
| Euclidean division by σ | Application of R₁₁₁₁ |
| \|remainder\| < \|dividend\| | d' < d (strict descent) |
| Unit quaternions (\|α\|=1) | Root (0,0,1,1) |
| Euler's four-square identity | Descent preserves null cone |
