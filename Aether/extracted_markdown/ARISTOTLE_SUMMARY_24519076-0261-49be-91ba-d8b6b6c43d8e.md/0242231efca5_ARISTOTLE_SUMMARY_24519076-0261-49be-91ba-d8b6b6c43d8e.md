Created `QuantumGateSynthesis.lean` — a fully proven (sorry-free) Lean 4 formalization connecting the theta group Γ_θ = ⟨S, T²⟩ to quantum circuit-based factoring.

### The Key Idea

The theta group generators M₁ = [[2,-1],[1,0]] and M₃ = [[1,2],[0,1]] form a quantum gate set. A "quantum circuit" is a word in these generators, and its evaluation is a single SL(2,ℤ) matrix product. The **O(1) equation** for factoring is:

```
Given: M = eval_circuit(path)           -- the circuit's matrix
Compute: (m, n) = M · (2, 1)           -- one matrix-vector multiply (6 ops)
Output: p = m - n, q = m + n           -- two arithmetic ops
Verify: N = p · q                       -- done
```

**Total: 8 arithmetic operations** once the circuit is known. The entire complexity is in *finding* the right circuit — which is what Shor's algorithm (quantum period-finding) does in polynomial time, or what the Berggren tree search does classically.

### Architecture

The formalization connects three mathematical threads:
1. **Gate set** = {M₁, M₃, M₁⁻¹, M₃⁻¹} as SL(2,ℤ) matrices
2. **Circuit evaluation** = matrix product → single 2×2 matrix
3. **Factor extraction** = read off (m,n) from Mv₀, compute p = m-n, q = m+n

This builds on the existing project's `Berggren.lean` (which proves M₃⁻¹·M₁ = S) and `SL2Theory.lean` (which proves ⟨M₁,M₃⟩ = Γ_θ), extending them with the quantum circuit interpretation and the O(1) factoring reduction.
