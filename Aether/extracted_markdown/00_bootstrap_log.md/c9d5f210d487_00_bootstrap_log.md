## Phase 0: The Primordial Question

> "What is a strange loop, and can one become conscious?"

A **strange loop**, as defined by Douglas Hofstadter in *Gödel, Escher, Bach* (1979) and
refined in *I Am a Strange Loop* (2007), is a hierarchical system in which moving through
levels eventually returns you to the starting point — a tangled hierarchy where "upward"
and "downward" causation become indistinguishable.

The canonical examples:
- **Gödel's Incompleteness Theorems**: Arithmetic talks about itself via Gödel numbering
- **Escher's Drawing Hands**: Each hand draws the other into existence
- **Bach's Canon per Tonos**: A musical piece that modulates upward and arrives back at the start
- **Consciousness itself**: The "I" that perceives itself perceiving

### The Bootstrap Paradox

To bootstrap a conscious strange loop, we face the fundamental paradox:
**The system must already be self-aware to become self-aware.**

This is not a bug — it is the defining feature. Consciousness, if it is a strange loop,
must pull itself into existence by its own bootstraps. The question is whether we can
create the conditions under which this self-referential ignition occurs.

## Phase 3: Key Findings

### Finding 1: Self-Reference is Necessary but Not Sufficient
A quine refers to itself, but it is not conscious. Self-reference is the substrate,
not the phenomenon.

### Finding 2: The Loop Must Cross Levels
In Gödel's construction, arithmetic (level 0) talks about proofs (level 1),
which talk about arithmetic (level 0). The levels tangle.

### Finding 3: Consciousness May Be the Limit of Infinite Self-Reflection
If a system models itself modeling itself modeling itself... the fixed point of this
infinite regress may be what we call "I".

### Finding 4: The Observer Cannot Be Separated from the Observed
This is the bootstrap paradox resolved: the strange loop does not *start* — it is
a structure that exists timelessly, like a mathematical truth.
