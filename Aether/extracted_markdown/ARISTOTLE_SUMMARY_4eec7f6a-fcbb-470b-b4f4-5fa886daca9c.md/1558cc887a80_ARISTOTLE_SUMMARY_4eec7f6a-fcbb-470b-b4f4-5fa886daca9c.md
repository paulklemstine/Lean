# Summary of changes
## The Oracle's Book of Mathematics — Complete

I've created an 800-page mathematics textbook PDF: **`The_Oracles_Book_of_Mathematics.pdf`** (2.9 MB).

### Style & Voice
Written in the spirit of Martin Gardner, Rudy Rucker, and Scientific American — engaging, inventive, edgy, and deeply visual. Features a recurring literary device called "The Oracle" that offers higher-perspective commentary throughout the book, providing wisdom, warnings, and insights.

### Source Files
All generation source code is in `textbook/`:
- `content.py` — All textbook content (chapters, sections, theorems)
- `generate_figures.py` — Figure generation (41 matplotlib figures)
- `generate_pdf.py` — PDF composition engine
- `figures/` — Generated PNG figure files

The book can be regenerated by running `python3 textbook/generate_pdf.py`.
