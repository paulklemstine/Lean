# Why One Equation Is All You Need: The Hidden Algebra Behind a New Kind of Neural Network

## A Single Formula That Builds Everything

Imagine you have just one mathematical recipe: take a number, compute *e* raised to that power, and subtract the natural logarithm of another number. Written compactly: **eml(a, b) = eᵃ − ln b**. It looks deceptively simple — a dash of exponential growth mixed with a splash of logarithmic compression.

Now ask: what can you build from this alone?

The answer, it turns out, is *everything* — or at least, every continuous function you'd ever want to approximate. A new formal proof shows that the family of functions generated by this operation has a remarkable algebraic property: it's closed under multiplication (for positive functions). This is the mathematical key that unlocks **universal approximation**, meaning networks built from this single operation can, in principle, approximate any continuous function to any desired accuracy.

## From One Operation to an Entire Toolkit

The journey from `eml(a, b)` to universal approximation starts with a beautiful bootstrapping process.

**Step 1: Recover the exponential.** Set `b = 1`. Since `ln 1 = 0`, we get `eml(a, 1) = eᵃ`. The exponential function falls out for free.

**Step 2: Recover the logarithm.** Set `a = 0`. Since `e⁰ = 1`, we get `eml(0, b) = 1 − ln b`. A simple rearrangement gives us the logarithm: `ln b = 1 − eml(0, b)`.

**Step 3: Build addition.** The closure already includes pointwise addition of functions.

**Step 4: Build multiplication.** This is the non-trivial step — and the subject of the new theorem. If two functions `f` and `g` are both positive, then:

> **f(x) · g(x) = exp(ln f(x) + ln g(x))**

Since we have `exp`, `log`, and addition, we can compose them to get multiplication. This is the algebraic trick that makes everything work.

## Why Multiplication Matters

In mathematics, there's a powerful 19th-century result called the **Stone-Weierstrass theorem**. It says that if you have a collection of continuous functions that (1) separates points (can tell any two points apart), (2) includes constants, and (3) is closed under multiplication, then that collection is dense — it can approximate any continuous function.

The EML closure satisfies all three conditions:
- It contains the identity function (separates points) ✓
- It contains constant functions ✓  
- It's closed under multiplication of positive functions ✓ (the new theorem)

This means EML networks are **universal approximators**: given enough neurons, they can represent any continuous function on a compact domain to arbitrary precision.

## The Proof, Formally Verified

What makes this result especially compelling is that it's not just a pencil-and-paper argument — it's been **formally verified** in Lean 4, a proof assistant that checks every logical step with mathematical certainty. The computer has confirmed that the proof is valid, leaving no room for hidden errors or hand-waving.

The formal proof is elegantly short, mirroring the mathematical argument:

1. Compose `f` with `log` → get `log ∘ f` in the closure
2. Compose `g` with `log` → get `log ∘ g` in the closure
3. Add them → get `log f + log g` in the closure
4. Compose with `exp` → get `exp(log f + log g)` in the closure
5. Simplify using positivity → this equals `f · g`

Each step is verified by the proof assistant against the axioms of mathematics.

## A New Paradigm for Neural Networks?

Traditional neural networks use linear transformations followed by simple nonlinearities like ReLU or sigmoid. The EML approach is different: it uses a single operation that inherently combines exponential and logarithmic behavior. This matters because many real-world phenomena — from population growth to signal processing to thermodynamics — naturally involve these functions.

The multiplication closure theorem suggests that EML networks don't just approximate arbitrary functions in theory; they do so in a way that respects the multiplicative structure of the problems they model. When your data involves products, ratios, or power laws, an EML network can represent these relationships directly rather than laboriously approximating them with sums of simple functions.
