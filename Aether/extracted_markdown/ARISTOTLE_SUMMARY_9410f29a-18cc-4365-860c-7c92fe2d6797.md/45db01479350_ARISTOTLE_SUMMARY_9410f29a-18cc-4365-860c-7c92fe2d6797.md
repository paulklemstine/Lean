**Factoring as Tropical Optimization (Part I):**
- `factoring_action_zero_iff` — The tropical action |N - a·b| is zero ↔ a·b = N

- `factor_symmetry` — Factorizations are symmetric
- `nontrivial_factor_bound` — Nontrivial factors satisfy a < N

- `sat_cost_zero_iff` — SAT cost = 0 ↔ all clauses satisfied
- `satisfying_assignment_zero_cost` — Satisfying assignments have zero cost
- `sat_cost_le_num_clauses` — Cost bounded by number of clauses

- `oracle_idempotent_range_eq_fixedPoints` — Range = fixed points for idempotent oracles
- `oracle_range_are_fixedPoints` — Range elements are fixed points
- `compose_commuting_oracles` — Commuting idempotent oracles compose idempotently
- `compose_oracle_fixedPoints` — Composed fixed points = intersection (the consensus theorem)
- `id_is_oracle`, `const_is_oracle` — Basic oracle examples

**Simulated Annealing (Part IV):**
- `metropolis_always_accepts_improvement` — Improvements always accepted
- `metropolis_zero_temp_greedy` — At T=0, only improvements accepted
- `metropolis_monotone_acceptance` — Acceptance probability is monotone in cost

**Bit-Vector Search Space (Part V):**
- `bitsToNat_lt_pow` — n-bit values < 2ⁿ
- `search_space_size` — Search space has size 2^(2n)

**Number Theory & Complexity (Part VI–VII):**
- `composite_has_nontrivial_factors` — Composites have nontrivial factorizations
- `prime_or_composite` — Every N ≥ 2 is prime or composite
- `geometric_cooling_converges` — Geometric cooling T₀·αᵏ → 0
- `geometric_temp_pos` — Temperature stays positive

All proofs use only standard axioms (propext, Classical.choice, Quot.sound).
