It develops the canonical ultrametric on the *path space* of the ternary Berggren tree, with complete proofs and a module docstring.

Contents (all proved, no sorries):
- `Triple := ℤ × ℤ × ℤ`, `applyGen : Fin 3 → Triple → Triple` dispatching to the core child maps `childA`/`childB`/`childC`, and `applyPath : List (Fin 3) → Triple → Triple` iterating along a path.
- `depth := List.length` with the extension law `depth_cons : depth (i :: p) = depth p + 1`, and `applyPath_append : applyPath (u ++ v) t = applyPath v (applyPath u t)`.
- `lcpLen` (longest common prefix length) with supporting simp lemmas, `lcpLen_comm` (symmetry), and the key combinatorial inequality `lcpLen_min_le : min (lcpLen p q) (lcpLen q r) ≤ lcpLen p r`.
- The ℚ-valued ultrametric `treeDist p q = if p = q then 0 else 1 / 2 ^ lcpLen p q` with `treeDist_self`, `treeDist_symm`, `treeDist_nonneg`, `treeDist_pos_of_ne`, `treeDist_eq_zero_iff`, and the strong triangle inequality `treeDist_strong_triangle : treeDist p r ≤ max (treeDist p q) (treeDist q r)`.
- Invariant preservation reusing the core: `applyGen_preserves_pythag`, `applyPath_preserves_pythag`, plus `applyGen_preserves_Q` / `applyPath_preserves_Q` for the Lorentz form, and a corollary `applyPath_root_pythag` that every vertex reached from the root `(3,4,5)` is Pythagorean.
- A lightweight bridge lemma `common_prefix_ancestor` showing a common prefix `u` factors both path evaluations through the shared ancestor `applyPath u t`. (Per the constraints, no metric is forced on triples and no path-injectivity is attempted; the metric package lives on finite paths.)
