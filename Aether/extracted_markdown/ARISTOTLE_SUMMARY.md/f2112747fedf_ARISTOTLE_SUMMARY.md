# Summary of changes for run fab5a6b0-3fc3-4300-93a1-12de88743ad3
Created a self-contained, fully proved Lean 4 file `Catalog/Applications/SpeciesTropicalProfile.lean` developing a tropical extremal-support theory for finitely supported rational sequences `f : ℕ →₀ ℚ`. Every declaration is proved with no `sorry` and no nonstandard axioms (only `propext`, `Classical.choice`, `Quot.sound`); the file builds cleanly with no errors or linter warnings.

Contents (all proved):
- Definitions: `ord : (ℕ →₀ ℚ) → WithTop ℕ` (least support index, `ord 0 = ⊤`) and `deg : (ℕ →₀ ℚ) → WithBot ℕ` (greatest support index, `deg 0 = ⊥`), defined directly via `Finset.min`/`Finset.max` of the support.
- Basic support API: `ord_zero`, `deg_zero`; existence of extremal indices for nonzero `f` (`exists_ord_eq`, `exists_deg_eq`); vanishing outside the extremal window (`coeff_eq_zero_of_lt_ord`, `coeff_eq_zero_of_deg_lt`); nonvanishing at the extremes (`coeff_ne_zero_of_ord_eq`, `coeff_ne_zero_of_deg_eq`); converse containment lemmas (`ord_le_of_ne_zero`, `le_deg_of_ne_zero`); and the workhorse extremal-characterisation lemmas `ord_eq_of`, `deg_eq_of`.
- Convolution: `cconv (f g : ℕ →₀ ℚ) : ℕ →₀ ℚ` built via `Finsupp.onFinset` with the coefficientwise formula `cconv f g n = ∑ i ∈ range (n+1), f i * g (n - i)` (`cconv_apply`), plus `cconv_zero_left`/`cconv_zero_right`.
- Tropical addition laws: `ord_add_ge : min (ord f) (ord g) ≤ ord (f + g)` and `deg_add_le : deg (f + g) ≤ max (deg f) (deg g)`, proved by support containment.
- Exact convolution laws: `ord_cconv : ord (cconv f g) = ord f + ord g` and `deg_cconv : deg (cconv f g) = deg f + deg g`. The proofs follow the requested unique-extremal-contributing-pair strategy: zero cases handled first, then below/above the sum index all summands vanish (`cconv_eq_zero_below`, `cconv_eq_zero_above`), and at the sum index only the pair `(ord f, ord g)` (resp. degrees) contributes, giving a nonzero product since `ℚ` is a domain (`cconv_apply_ord_add`, `cconv_apply_deg_add`).
- Examples: `ord`/`deg` of `Finsupp.single 2 3`, the zero cases, and a nontrivial convolution value computed coefficientwise.
- Downstream species/EGF corollary `binConv_extremal_profile`: the extremal contributing-pair phenomenon transfers to the catalog's binomial/exponential convolution `CombinatorialSpecies.binConv` (bottom coefficient nonzero exactly at `ord f + ord g`, vanishing strictly below), since the binomial weights are positive. This is the only species-facing result and introduces no new species abstractions. The file header states explicitly that the core is about finitely supported sequences and the species/EGF interpretation is a downstream corollary.
