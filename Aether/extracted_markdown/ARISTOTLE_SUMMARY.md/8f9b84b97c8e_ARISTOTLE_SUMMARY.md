Created `Catalog/MachineLearning/AutomaticSequences/Core.lean`, a complete, sorry-free formalization of core structural theorems about automatic sequences generated by deterministic finite automata with output (DFAOs).

What the file contains:
- `DFAO` structure (finite state type `σ`, `step : σ → α → σ`, `start`, `out : σ → β`), with word evaluation (`run`, `eval`), a `Reachable` predicate, and the base-`k` sequence `autoSeq` built from little-endian `Nat.digits k n`.
- Finite-valuedness: `DFAO.eval_range_subset_out`, `DFAO.eval_range_finite`, and `DFAO.autoSeq_range_finite` (the value set is contained in `Set.range out`, hence finite when `σ` is finite).
- `IsKAutomatic` and `id_not_automatic`: the sequence `n ↦ n` is not `k`-automatic for any base `k` (proved via infinite range vs. finite range; the statement is strengthened to all `k`, which covers the requested `k ≥ 2`).
- Reachability/decidability: `DFAO.output_occurs_iff_reachable` (an output `z` occurs iff some reachable state outputs `z`), and a `Decidable` instance `DFAO.decEval` reducing occurrence to a finite search over bounded-length words.
- Pumping/shortest-path bound, stated correctly on state reachability (not on representations of naturals): `DFAO.exists_shorter_of_long`, `DFAO.run_short_witness`, `DFAO.reachable_bounded_witness`, and `DFAO.output_occurs_bounded` (witness word length strictly below the number of states).
- Unary eventual periodicity: `DFAO.unary_state_eventually_periodic` and `DFAO.unary_out_eventually_periodic`, reusing the catalog theorem `eventually_periodic_of_finite` from `MachineLearning/AdelicSync/Core.lean` on iterates of a self-map of a finite type.

The module docstring documents the conventions (little-endian digits, no reliance on representation uniqueness or leading-zero normalization) and explains the rigorous boundary these results give.
