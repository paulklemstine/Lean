# Dreamtime Algebra: Aboriginal Kinship Systems as Group Theory

## Summary

This research cycle formalizes Australian Aboriginal kinship systems as finite groups generated by commuting involutions, introduces the **DreamtimeAlgebra** as a novel algebraic structure, and establishes a surprising cross-connection to error-correcting codes.

## Lean 4 Formalization (26 theorems, 0 sorries)

**File**: `Catalog/Algebra/KinshipAlgebra/Basic.lean`

All 26 theorems are fully machine-verified with no sorries and only standard axioms (propext, Classical.choice, Quot.sound).

### Novel Structures Defined
1. **KinshipSystem** — Axiomatizes kinship section systems via marriage/descent permutations with involution, exogamy (fixed-point-freeness), and descent constraints.
2. **DreamtimeAlgebra** — Novel structure: k commuting involutions on a finite set with faithful action. Abstracts the group-theoretic content of kinship systems to arbitrary dimension.
3. **Dreamtime Operator** — The composition T = marriage ∘ descent, capturing the fundamental generational-marital cycle.

### Key Theorems Proved
- **4-Section System (Kariera)**: Marriage and descent are involutions, commute, and generate a group isomorphic to Z₂ × Z₂ (proved via injective group map `fourSectionGroupMap_injective`).
- **8-Subsection System (Aranda)**: Three generators (marriage, patrilineal descent, matrilineal descent) are involutions, commute pairwise, and generate Z₂ × Z₂ × Z₂ (`eightSectionGroupMap_injective`).
- **Dreamtime Operator Involution**: In any commutative kinship system, T = m·d is itself an involution (`kinship_dreamtime_invol`, `DreamtimeAlgebra.dreamtimeOp_invol`).
- **Regularity**: Every non-identity kinship group element is fixed-point-free (`fourSection_regular`).
- **Marriage = Coset**: Marriage partners lie in a specific coset of the descent subgroup (`marriage_coset_property`).
- **Binary Code Connection**: Sections encode as binary strings; marriage flips bit 0, descent flips bit 1, Hamming distance to marriage partner = 1 (`marriage_hamming_distance_one`).
- **Abstract algebraic core**: Product of commuting involutions is an involution (`comm_invol_product_invol`).
