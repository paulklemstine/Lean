# Summary of changes for run c4ac1717-b88a-4933-bc0d-534688b9d0ca
Added a single, self-contained, fully-proved Lean file `Catalog/Applications/SpeciesTropicalProfile.lean` (337 lines) that builds a tropical (min-plus / max-plus) coefficient profile on top of the catalog's existing combinatorial-species EGF algebra. It builds cleanly with no `sorry`, no warnings, and only the standard axioms (`propext`, `Classical.choice`, `Quot.sound`); it adds no `axiom` or `@[implemented_by]` declarations.

What it contains, matching each requested item:

1. `ord (f : ℕ →₀ ℚ) : WithTop ℕ` — least nonzero index (order of vanishing), with the conventional value `⊤` for the zero sequence (the min-plus unit).
2. `deg (f : ℕ →₀ ℚ) : WithBot ℕ` — greatest nonzero index, with `⊥` for the zero sequence (the max-plus unit). Finitely supported data is modeled with mathlib's `ℕ →₀ ℚ`, so everything is computable.
3. The convolution profile reuses the catalog's binomial convolution `CombinatorialSpecies.binConv` directly, packaged as `bconv : (ℕ →₀ ℚ) → (ℕ →₀ ℚ) → (ℕ →₀ ℚ)` with `bconv_apply` showing it agrees coefficientwise with `binConv`.
4. Tropical subadditivity: `ord_add_ge : min (ord f) (ord g) ≤ ord (f + g)` and `deg_add_le : deg (f + g) ≤ max (deg f) (deg g)`.
5. Multiplicative laws: `ord_bconv : ord (bconv f g) = ord f + ord g` and `deg_bconv : deg (bconv f g) = deg f + deg g`. These are proved as the strongest clean reusable statements: because the catalog works over the integral domain `ℚ`, the trailing/leading coefficients (nonzero by the very definition of `ord`/`deg`) cannot cancel, and the zero sequence is absorbed by the `⊤`/`⊥` conventions of `WithTop`/`WithBot` addition, so no extra non-cancellation hypotheses are required. The non-cancellation content is isolated in reusable core lemmas (`binConv_ord_collapse`, `binConv_zero_below_ord`, `binConv_deg_collapse`, `binConv_zero_above_deg`) and the characterizations `ord_eq`/`deg_eq`.
6. Bridge to the existing EGF/species API: `egf_bconv : egf (bconv f g) = egf f * egf g` (via `egf_mul`) and `egf_add_finsupp : egf (f + g) = egf f + egf g` (via `egf_add`), connecting the profile to the catalog's `egf` transform; plus species wrappers `Species.ordProfile` / `Species.degProfile` over finite truncations.
7. Worked species examples on truncations, with concrete computed profiles: for the species of sets `E` and linear orders `L` truncated at bound 4 (`ord = 0`, `deg = 4`), and an end-to-end convolution example (`deg = 5`, `ord = 0`) illustrating max-plus/min-plus multiplicativity (`degProfile_setSpecies`, `degProfile_linearOrderSpecies`, `ordProfile_setSpecies`, `ordProfile_linearOrderSpecies`, `degProfile_bconv_setSpecies`, `ordProfile_bconv_setSpecies`).
