**2. `DeepReLUTropical.lean` — deep ReLU networks compute tropical rational functions.**

The **main theorem** `ReLUComputable.isTropRational` proves every deep ReLU network output is a tropical rational function — the full-depth correspondence — by a short structural induction discharged by the closure lemmas from file 1. Includes worked examples (a two-hidden-layer network; a maxout unit).
