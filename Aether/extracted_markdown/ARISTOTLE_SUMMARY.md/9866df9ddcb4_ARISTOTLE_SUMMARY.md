This complements the existing catalog file `Bridges/ClosureMatroidSecretSharing.lean`, which treats secret sharing abstractly (which *sets* of parties can reconstruct, via matroid/closure access structures). The new file is the concrete arithmetic counterpart: it works with the actual *shares* over an arbitrary abelian group `G` and proves how they behave under computation.

Theorems proved (all `proved`, no sorry):
1. `reconstruct_map` — any group homomorphism is applied locally, share-by-share: `∑ L(fᵢ) = L(∑ fᵢ)`. This is the GMW principle that linear gates are "free" (require no interaction). Corollaries: `reconstruct_add`, `reconstruct_neg`, `reconstruct_zero`, and `reconstruct_smul` (scalar/module gates).
2. `share_privacy_existence` + `share_privacy_uniqueness` — for any view of `n−1` parties and any candidate secret there is a unique full sharing consistent with that view (perfect-privacy equivocation: existence and uniqueness halves).
3. `privacyEquiv` — the explicit bijection `G ≃ {sharings extending a fixed partial view}`, the strongest statement: an `n−1`-party view is information-theoretically independent of the secret. This combines results 2 into a single `Equiv`.
4. `rerandomize_equiv` — adding a sharing of `0` is a bijection on the sharings of a fixed secret (re-randomization acts simply transitively), the formal mechanism for refreshing shares between gates.
5. `mul_not_local` (boundary/counterexample for the best theorem) — there is *no* share-local product rule, the precise obstruction that forces MPC multiplication gates to use interaction (Beaver triples).
