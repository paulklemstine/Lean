### Novel Mathematical Structure: Generator Algebra

I developed the **Generator Algebra** framework — a novel algebraic structure that captures how a single continuous function generates approximating subalgebras, unifying classical Weierstrass approximation and exponential approximation under one principle.

### Key Lean 4 Theorems (all machine-verified, zero sorries)

The file `Bridges/EMLDensityTheory.lean` contains 47 declarations including:

1. **Generator Algebra Density Theorem** (`generatorAlgebra_dense_of_injective`): If φ : C(X, ℝ) is injective on a compact space, then Gen(φ) is dense in C(X, ℝ). This unifies Weierstrass (φ=id), exponential approximation (φ=exp), and all injective generators.

2. **Separation–Injectivity Equivalence** (`separatesPoints_iff_injective`): On T₂ spaces, Gen(φ) separates points **if and only if** φ is injective — a precise, bidirectional characterization.

3. **Kernel Determination Lemma** (`aeval_eq_of_generator_eq`): If φ(x) = φ(y), then p(φ)(x) = p(φ)(y) for every polynomial p. This is the technical heart proving the converse direction.

4. **Depth Collapse Theorem** (`depth_collapse_of_zero_separates` / `no_qualitative_depth_separation`): If any depth level contains an injective generator, ALL depth levels are dense. Depth adds no qualitative approximation power.

5. **Joint Density Theorem** (`jointAlgebra_dense_of_jointly_separating`): Two generators that jointly separate points produce a dense algebra.

6. **Iterated Exponential Properties** (`iteratedExp_injective`, `iteratedExp_continuous`): exp^n is injective and continuous for all n.

### Novel Structures Defined
- **GeneratorAlgebra**: The ℝ-subalgebra generated by a single function
- **ApproximationFiltration**: Increasing chain of subalgebras from a sequence of generators
- **ApproximationKernel**: The equivalence relation x ~ y iff φ(x) = φ(y)
- **DepthFilteredAlgebra**: Algebras with depth grading
- **ApproximationSpectrum**: The "fingerprint" of a generator (fibers, simplicity, defect)
- **KernelRefines**: Preorder on generators by kernel inclusion
- **JointGeneratorAlgebra**: Subalgebra from multiple generators
