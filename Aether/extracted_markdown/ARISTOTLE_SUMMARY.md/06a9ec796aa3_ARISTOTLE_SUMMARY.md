# EML Stone-Weierstrass Theory: Density and Complexity of Exp-Log Networks

## Research Summary

This research cycle introduces the **EML algebra** — the algebra generated by exponential, logarithm, addition, and multiplication — and proves fundamental approximation-theoretic and complexity-theoretic results about it. All theorems are machine-verified in Lean 4 with no `sorry` statements and only standard axioms.

## Novel Mathematical Structure: EML Expressions

Defined `EMLExpr`, an inductive type representing exp-log network computations, together with evaluation, depth, and size measures. Built `EMLComplexity` — a complexity measure for continuous functions based on optimal EML representation size at a given approximation scale.

## Key Proven Theorems (15 total, all sorry-free)

### Main Density Theorem (PEGB: Proof + Example + Generalization + Boundary)
- **`eml_dense_in_continuous_functions`**: The EML algebra is dense in C([a,b], ℝ) for 0 < a < b, via Stone-Weierstrass. The identity function x = exp(log(x)) provides point separation.
- **`eml_uniform_approximation`**: For any continuous f and ε > 0, there exists an EML function within ε in the sup-norm.

### Depth Hierarchy (PEGB)
- **`exp_exp_not_depth_one`**: exp(exp(x)) cannot be computed by any depth-1 EML expression. Proved by exhaustive case analysis over all depth-≤1 forms with numerical contradictions.
- **`depth_zero_classification`**: Depth-0 expressions compute only constants or the identity.
- **`depth_one_structure`**: Complete structural classification of depth-1 expressions.

### Polynomial Compression (PEGB)
- **`polynomial_eml_linear_size`**: Degree-d polynomials have EML size O(d) with constant C = 11.
- **`emlPower_eval`**: x^n = exp(n · log(x)) for x > 0 — constant-size power computation.
- **`emlPower_size`**: The power expression has size exactly 5, independent of the exponent.

### Structural Theorems
- **`eml_size_ge_depth_succ`**: Size ≥ depth + 1 for all EML expressions (depth-size tradeoff).
- **`eml_lipschitz_transfer`**: EML approximations of K-Lipschitz functions satisfy |g(x)-g(y)| ≤ K|x-y| + 2ε.
- **`exp_comp_log_strictMono_pos`**: exp ∘ log is strictly monotone on (0,∞).
- **`const_eml_complexity`**, **`id_eml_complexity_pos`**: Constants have complexity 1, identity has complexity 3.
