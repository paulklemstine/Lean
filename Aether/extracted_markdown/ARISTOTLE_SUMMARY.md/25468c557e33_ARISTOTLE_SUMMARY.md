Definitions:
- `DFAO k α`: a structure with a finite state type `Q` ([Fintype Q], [DecidableEq Q] as instance fields), initial state `q0`, transition `δ : Q → Fin k → Q`, and output `out : Q → α` (α arbitrary; finiteness of the value range is derived, which is what lets Theorem B apply to `id : ℕ → ℕ`).
- `DFAO.evalFrom` / `DFAO.eval`: evaluation on a list of digits (`List (Fin k)`).
- `DFAO.evalNat`: evaluation on `n : ℕ` via the canonical base-k expansion `(Nat.digits k n).reverse` (most-significant-digit first; 0 is the empty word, and every nonzero n has a nonzero leading digit). Out-of-range digits leave the state unchanged (never occurs for genuine digits).
- `IsKAutomatic`: a sequence `a : ℕ → α` is k-automatic iff some DFAO computes it.

Main theorems:
- A. `IsKAutomatic.range_finite`: the range of any k-automatic sequence is finite (it is contained in `Set.range out`, finite since `Q` is a Fintype).
- B. `not_isKAutomatic_id`: for every base `k ≥ 2`, `id : ℕ → ℕ` is not k-automatic (combines A with the infiniteness of `Set.range id = Set.univ`). The `2 ≤ k` hypothesis is kept as requested though the argument does not need it (noted in the docstring; this is the only, benign, unused-variable warning).
- C. `DFAO.decidableOccurs`: for a fixed DFAO over base `k ≥ 2` and a value `z`, the proposition `∃ n, M.evalNat n = z` is decidable. This rests on `DFAO.occurs_iff`, a finite-reachability characterization: `z` occurs iff some state in a computable finite reachable set `M.reachSet` outputs `z`. The reachable set is built via a `δ`-closure (`closureFrom`) computed by iterating an `expand` step `card Q + 1` times to a fixpoint; correctness is `DFAO.mem_closureFrom_iff`. The link to genuine base-k expansions uses Mathlib's digit round-trip lemmas (`Nat.digits_ofDigits`, `Nat.getLast_digit_ne_zero`, etc.).
- D. `UDFAO.seq_eventually_periodic`: for the unary case (`UDFAO`, a single step `next : Q → Q` with output `out`), the generated sequence `seq n = out (next^[n] q0)` is eventually periodic — there exist a threshold `i` and a period `p > 0` with `seq (n + p) = seq n` for all `n ≥ i`. The proof uses the finite-orbit pigeonhole (`Finite.exists_ne_map_eq_of_infinite`) and `Function.iterate_add_apply`.

Supporting lemmas (all proven) include closure monotonicity/fixpoint stabilization, the `stepNat`/`δ` fold-compatibility lemma, and a digit-conversion lemma between ℕ-words with all entries `< k` and `Fin k`-words.
