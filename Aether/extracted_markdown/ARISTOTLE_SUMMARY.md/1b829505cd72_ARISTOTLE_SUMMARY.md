### Lean 4 Proofs (8 theorems, 0 sorries)

All theorems are in `Applications/EMLStoneWeierstrass.lean`, fully proved with only standard axioms (propext, Classical.choice, Quot.sound):

1. **`strictMono_separates`** — Strict monotonicity separation principle: any strictly monotone function separates points. This is the foundational mechanism for EML universality.

2. **`emlSubalgebra_separatesPoints`** — The EML subalgebra generated by {exp(w·φ(x)+b)} separates points of K whenever the feature map φ is injective. *Key insight*: a single injective feature map suffices, simplifying the prior formalization which required a family Φ : Fin n → C(X,ℝ).

3. **`emlSubalgebra_dense`** — The EML subalgebra's topological closure equals C(K,ℝ) — the main Stone-Weierstrass density result.

4. **`eml_approx_exists`** — Quantitative ε-approximation: for any continuous f and ε > 0, there exists g in the EML subalgebra with ‖f - g‖ < ε.

5. **`tropical_limit`** — The Maslov dequantization: (1/t)·log(exp(ta) + exp(tb)) → max(a,b) as t → ∞. This bridges EML networks to tropical (max-plus) algebra.

6. **`lipschitz_dense_approx`** — General dense subalgebra approximation: any dense subalgebra of C(X,ℝ) provides ε-approximation.

7. **`eml_depth_closure`** — Depth-2 EML compositions remain continuous, showing the algebra is closed under composition with exp.

8. **`depth2_not_affine_exp`** — Strict depth hierarchy: exp(exp(x)) cannot be written as exp(wx+b), proving depth-2 is genuinely more expressive than depth-1.
