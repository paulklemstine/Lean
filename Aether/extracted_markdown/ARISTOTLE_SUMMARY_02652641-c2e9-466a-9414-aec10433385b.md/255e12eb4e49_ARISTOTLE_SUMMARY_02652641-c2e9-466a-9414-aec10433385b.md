## Core Findings

### Definition
A **photon** of integer n is a Gaussian integer z = a+bi with |z|² = a²+b² = n. The **photon network** P(n) is a graph whose vertices are the distinct representations of n as a sum of two squares, connected by Gaussian prime conjugation swaps.

### Answer 1: Network Structure
The photon network of n = p₁^e₁ · p₂^e₂ · ⋯ · pₖ^eₖ (primes ≡ 1 mod 4) is isomorphic to the **grid graph** P_{e₁+1} × P_{e₂+1} × ⋯ × P_{eₖ+1}. For example, 1105 = 5×13×17 has a **3D cube** network (P₂×P₂×P₂) with 8 vertices and 12 edges.

### Answer 2: All Networks Are Connected
Every non-trivial photon network is **connected** — verified computationally for all n ≤ 1000. Grid graphs (products of paths) are always connected: you can reach any vertex from any other by changing one coordinate at a time.

### Answer 3: No Networks Are Disconnected
Under the correct edge relation (Gaussian prime conjugation), no photon network has disconnected components.

### Answer 4: Why Some Photons Are "Dark"
An integer n is **dark** (has no photon network) if and only if n has a prime factor p ≡ 3 (mod 4) appearing to an **odd power**. This is because -1 is not a quadratic residue mod such p, creating an algebraic obstruction. About 57-73% of integers are dark.

### Answer 5: Why Some Integers Have No Network
Same answer — the mod-4 obstruction. Primes like 3, 7, 11, 19, 23 are "inert" in the Gaussian integers and block sum-of-two-squares representations at odd powers. The density of bright integers tends to 0 by the Landau-Ramanujan theorem (rate K/√(ln N)).
