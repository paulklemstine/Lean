## Assignment: 3. Weighted Automata Minimization (Myhill–Nerode Bridge)

**Mode:** `prove`

Prove a genuinely new bridge theorem connecting tropical polynomial canonicalization to state minimization for single-letter tropical weighted automata. This should not be a metaphorical analogy: make it an exact equivalence theorem with a Lean-ready interface.

### Research Direction

Build a formal equivalence between two compression procedures:

1. **Algebraic compression:** remove dominated monomials from a single-variable tropical polynomial.
2. **Automata-theoretic compression:** quotient residual weighted languages by tropical Myhill–Nerode equivalence.

The breakthrough claim is that, in the one-letter setting, these are the same operation seen through two different lenses. If established cleanly, this opens a new algebra–automata dictionary: tropical convex hull / lower-envelope simplification becomes automata minimization, and automata residuals become semantic witnesses for tropical normal forms.

This is not just an incremental theorem about weighted automata. It would create a certified bridge between:
- tropical geometry,
- weighted formal language theory,
- idempotent semiring algebra,
- algorithmic minimization,
- and eventually categorical semantics for explainable compressed models.

### Precise Target Theorem

Work in the min-plus tropical semantics on coefficients in `ℝ`. Restrict first to **single-variable** tropical polynomials represented by finitely supported exponent-weight pairs.

A mathematically precise target is:

> For every finitely supported tropical polynomial `p(x) = min_{i ∈ S} (a_i + i*x)` in one variable, there exists a weighted language `L_p : ℕ → ℝ` recognized by a finite tropical automaton such that:
>
> 1. the residual languages of `L_p` are in bijection with the non-dominated monomials of `p`,
> 2. dominated monomials induce residuals equivalent in the tropical Myhill–Nerode sense to smaller representatives,
> 3. therefore the cardinality of the minimal recognizing automaton for `L_p` is exactly the number of non-dominated monomials of `p`.

A sharpened exact statement to aim for:

> **Canonicalization–Minimization Theorem.**
> Let `p` be a single-variable tropical polynomial with finite support. Let `canon p` be the sub-support of non-dominated monomials. Construct the associated weighted language `L_p`. Then the tropical Myhill–Nerode quotient of `L_p` has exactly `|canon p|` classes, and the minimal tropical automaton for `L_p` has one state per canonical monomial.

  exp : ℕ
  coeff : ℝ

def monoEval (m : TropMono) (x : ℝ) : ℝ :=
  m.coeff + (m.exp : ℝ) * x

def tropEval (p : TropPoly1) (x : ℝ) : ℝ :=
  p.inf' (by
    -- nonempty side condition if needed, or use `WithTop ℝ`
    sorry) (fun m => monoEval m x)

def Dominates (m₁ m₂ : TropMono) : Prop :=
  ∀ x : ℝ, monoEval m₁ x ≤ monoEval m₂ x

def Canonical (p : TropPoly1) : Finset TropMono :=
  p.filter (fun m => ¬ ∃ m' ∈ p, m' ≠ m ∧ Dominates m' m)

def polyLanguage (p : TropPoly1) : ℕ → ℝ :=
  fun n => tropEval p n

def residual (L : ℕ → ℝ) (k : ℕ) : ℕ → ℝ :=
  fun n => L (k + n)

def NerodeEq (L : ℕ → ℝ) (i j : ℕ) : Prop :=
  residual L i = residual L j

### Required Intermediate Definitions and Lemmas

You will almost certainly need these bridge components:

1. **Dominated monomial semantic redundancy**
   ```lean
   theorem dominated_monomial_removal_preserves_eval
     (p : TropPoly1) (m : TropMono)
     (hm : m ∈ p)
     (hdom : ∃ m' ∈ p, m' ≠ m ∧ Dominates m' m) :
     tropEval (p.erase m) = tropEval p
   ```

2. **Canonicalization preserves language**
   ```lean
   theorem canonical_preserves_language
     (p : TropPoly1) :
     polyLanguage (Canonical p) = polyLanguage p
   ```

3. **Distinct canonical monomials yield distinct residuals**
   This is the real mathematical heart. You need a separation lemma:
   if `m₁, m₂` are distinct non-dominated monomials, then there exists some suffix length `n`
   at which their contributions differ in a way that produces different residual behavior.

   A candidate formulation:
   ```lean
   theorem distinct_canonical_monomials_separate_residuals
     (p : TropPoly1) {m₁ m₂ : TropMono}
     (h₁ : m₁ ∈ Canonical p) (h₂ : m₂ ∈ Canonical p) (hne : m₁ ≠ m₂) :
     ∃ k : ℕ, residual (polyLanguage p) m₁.exp k ≠ residual (polyLanguage p) m₂.exp k
   ```

   You may need to revise the indexing map from monomials to residuals; perhaps use a state parameter built from monomials directly rather than exponents.

4. **Finite quotient cardinality equals canonical support size**
   Use the above injection plus a converse surjection from residual classes to canonical monomials.

### Why This Would Be a Breakthrough

If successful, this theorem says that tropical polynomial normal forms are not just syntactic simplifications: they are **exact automata minimizers**. That turns canonicalization into a certified minimization algorithm and turns Myhill–Nerode theory into a semantic explanation tool for tropical algebra.

This opens several fields at once:

- **Tropical compiler theory:** simplify tropical expressions by automata minimization.
- **Weighted verification:** certify that no smaller finite-state tropical model exists.
- **Geometric automata theory:** interpret residual classes as lower-envelope faces / active linear forms.
- **Explainable AI over semirings:** minimal states correspond to essential decision templates.
- **Categorical semantics:** functor from tropical polynomial presentations to residual-language coalgebras.

### Proof Strategy Paths

#### Strategy A: Direct lower-envelope analysis of monomials
Most promising for the first theorem.

1. Prove that a dominated monomial never attains the minimum in `tropEval`.
2. Show that removing all such monomials preserves evaluation on every `x : ℝ`, hence on `ℕ`.
3. For non-dominated monomials, prove each is active somewhere; use these activation points to distinguish residual behaviors.

Why this is promising:
- It is concrete and computational.
- It matches finite `Finset` representations well.
- It avoids heavy category theory until the core theorem is certified.

#### Strategy B: Residual-language construction via transition semigroup
Build a one-letter weighted automaton whose states are candidate monomials.

1. Define states as monomials, transition by incrementing input length, and output by affine update.
2. Show state semantics equals residual weighted language.
3. Prove that quotienting by Nerode equivalence identifies exactly dominated states, leaving canonical monomials.

Why this is strong:
- It aligns directly with `tropical_recognizable_iff_finite_nerode`.
- It gives an actual extracted minimal automaton, not just a counting theorem.

Potential difficulty:
- You must choose the automaton semantics carefully so the state-to-monomial correspondence is exact.

#### Strategy C: Convex-geometric duality / Newton polygon route
Most conceptually ambitious.

1. Identify canonical monomials with exposed lower hull points of the Newton polygon.
2. Interpret residuals as translations of the lower envelope.
3. Show Nerode equivalence collapses exactly those monomials not contributing distinct lower-hull behavior.

Why this matters:
- It connects automata minimization to tropical convex geometry.
- It could generalize later to multivariate polynomials via normal fans and polyhedral cell complexes.

Why not start here:
- Harder to formalize first in Lean than the direct finite-support proof.

### Concrete Formalization Advice

Use concrete finite structures first. Avoid abstract semiring-general statements until the one-variable `ℝ` case is complete.

Good initial choices:
- `Finset (ℕ × ℝ)` or a custom `TropMono`
- semantics `ℕ → ℝ`
- residuals by translation `k ↦ fun n => L (k+n)`

If `Finset.inf'` creates avoidable nonempty obligations, either:
- restrict to nonempty polynomials, or
- work with `WithTop ℝ` and define empty polynomial as `⊤`.

If extensional equality of functions becomes annoying, use pointwise lemmas first:
```lean

  polyLanguage (Canonical p) n = polyLanguage p n
```
then package with `funext`.
