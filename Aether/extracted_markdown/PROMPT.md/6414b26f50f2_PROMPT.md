## Proof strategy

### Strategy A: Finite pointwise tropical Nullstellensatz in the full function semiring
This is the most promising route.

1. **Prove the zero-sup lemma.**  
   Establish the finite idempotent analogue of positivity:
   ```lean
   lemma finset_sup_eq_bot_iff
     (g : X → S) :
     Finset.sup Finset.univ g = ⊥ ↔ ∀ x, g x = ⊥ := by
     ...
   ```
   or, more realistically,
   ```lean
   lemma finset_sup_ne_bot_iff
     (g : X → S) :
     Finset.sup Finset.univ g ≠ ⊥ ↔ ∃ x, g x ≠ ⊥ := by
     ...
   ```
   Then instantiate `g x = w x * f x`.

2. **Use no-zero-divisor/nondegeneracy on support.**  
   You need the implication
   `w x * f x = ⊥` and `w x ≠ ⊥` imply `f x = ⊥`.
   If the coefficient semiring is `WithBot` over an ordered cancellative monoid, this is immediate from multiplication-by-nonbot. Prove a dedicated lemma once and reuse it:
   ```lean
   lemma mul_eq_bot_of_nonbot_left_iff {a b : S} (ha : a ≠ ⊥) :
     a * b = ⊥ ↔ b = ⊥ := ...
   ```

3. **Derive `ker_kme_eq_vanishing_support`.**  
   Combine the previous two lemmas:
   `μ_w(f)=⊥` iff every term `w x * f x = ⊥` iff `f x = ⊥` on `supportOfMeasure w`.

4. **Classify ideals by supports.**  
   For any ideal `I`, define `supportOfIdeal I := {x | ∀ f ∈ I, f x = ⊥}`.  
   Prove `I ⊆ vanishingIdeal (supportOfIdeal I)` always.  
   Then characterize the ideals satisfying equality as exactly the support-stable ones.

5. **Recover subsets from ideals using point-separating functions.**  
   To show `supportOfIdeal (vanishingIdeal F) = F`, the nontrivial inclusion is:
   if `x ∉ F`, construct `f ∈ vanishingIdeal F` with `f x ≠ ⊥`.
   In the full function semiring, use the indicator:
   ```lean
   def ptSep (F : Set X) (x : X) : X → S :=
     fun y => if y = x then some_nonbot else ⊥
   ```
   In the kernel-generated subsemiring, derive such a separator from the singleton-separating kernel theorem in the catalog.

This route gives the algebraic heart of the duality with minimal topological friction.

## Significance

This theorem is not a routine finite classification result. It is the first algebraic-geometric reconstruction principle for idempotent kernel mean embeddings in the finite setting:

- `ker_kme_eq_vanishing_support` is the idempotent/tropical analogue of the classical measure-theoretic fact that a positive linear functional vanishes exactly on functions vanishing on the support. Formalizing this in Lean turns support identifiability into an algebraic invariant, not merely an analytic one.

- `closedSet_equiv_supportStableRadicalIdeals` is a finite tropical Gelfand reconstruction theorem: the space is recoverable from the algebra of kernel sections via support-stable radical ideals. This is the correct bridge between the completed KME support-duality results and tropical algebraic geometry.

- The theorem creates an algorithmic shadow immediately: on a finite space, closed subsets can be enumerated and converted into ideals, and conversely ideals can be reduced to supports. This gives a computable spectrum for idempotent learning models, tropical observables, and finite-state max-plus systems.

- Conceptually, this opens a new research line: tropical Tannaka/Gelfand reconstruction for idempotent statistics. Once this finite anti-isomorphism exists, the next steps are prime-ideal spectra, functoriality under kernel morphisms, and tropical Wasserstein/Kantorovich duality expressed through algebraic supports.

This is exactly the missing bridge between the “support determines KME” side and the “algebra of observables determines space” side of the program.
