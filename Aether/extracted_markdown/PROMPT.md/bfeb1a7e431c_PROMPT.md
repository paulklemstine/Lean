## Assignment: Circuit universality

Mode: **prove**

Prove a genuinely new universality theorem that turns simple finite gate libraries into a formally verified theory of exact circuit synthesis in Lean 4. Do not settle for ad hoc gadget lemmas. The target is a classification theorem: identify minimal algebraic conditions under which a gate set generates **all** boolean functions on `n` bits, and formalize the synthesis mechanism.

This is high-impact because it creates a bridge between:
- finite universal algebra / Post-style clone theory,
- constructive circuit synthesis,
- additive/combinatorial gadget engineering,
- and eventually categorical or Hopf-style semantics of composition.

The existing catalog theorems are not about circuits directly, but they suggest a strategy: formalize structural lower bounds and “properness requires size” constraints, then use them to force nontrivial generators. In particular:
- `proper_requires_ge_three` and `proper_requires_ge_two` suggest a reusable pattern: if a decomposition is genuinely nontrivial, then the arity/structure must exceed a threshold. Analogously, a nontrivial universal gate basis should require enough expressive asymmetry to escape affine/monotone/self-dual traps.
- `bounded_autocorr_bounded_energy` hints at a combinatorial-energy viewpoint: non-universal classes are “structured” and can often be detected by preserved invariants.
- `twamm_reduces_price_impact` is from a distant domain, but conceptually useful: composition in small increments can smooth complexity spikes. That suggests proving universality via staged synthesis rather than one-shot normal forms.
- `portfolio_quality_bounded` suggests formal boundedness arguments over finite search spaces, useful if you build decidable predicates for closure properties of gate sets.

## Precise breakthrough target

Formalize finite boolean circuits over a gate library `G`, and prove an exact universality criterion for a concrete high-value basis first, then push toward a general invariant-based classification.

### Primary theorem target
Prove that the NAND gate alone generates every boolean function on `n` bits.

Mathematically:

> For every `n : ℕ` and every boolean function `f : (Fin n → Bool) → Bool`, there exists a finite circuit built only from projections, constants, and binary NAND gates whose evaluation equals `f`.

This is classical mathematically, but the **breakthrough here is formal**: do it in Lean 4 with a reusable circuit semantics and synthesis pipeline, so future universality theorems become one-line corollaries. The real value is the architecture.

### Lean 4 type signature sketch
You should define a concrete inductive circuit type; for example:

```lean
inductive Circuit (n : ℕ) : Type
| input : Fin n → Circuit n
| const : Bool → Circuit n
| nand  : Circuit n → Circuit n → Circuit n

def Circuit.eval {n : ℕ} : Circuit n → (Fin n → Bool) → Bool
```

Then target:

```lean
theorem nand_universal :
  ∀ {n : ℕ} (f : (Fin n → Bool) → Bool),
    ∃ c : Circuit n, Circuit.eval c = f
```

Equality of functions may be easier as:
```lean
theorem nand_universal :
  ∀ {n : ℕ} (f : (Fin n → Bool) → Bool),
    ∃ c : Circuit n, ∀ σ : Fin n → Bool, Circuit.eval c σ = f σ
```

This avoids extensionality friction at first.

## Stronger theorem target: invariant-breaking universality

Once the circuit semantics is in place, prove a nontrivial clone-separation theorem for finite gate sets.

Define closure predicates on a gate family `G`:
- preserves constants (`0`-preserving, `1`-preserving),
- monotone,
- affine over `Bool` as `Xor`-linear/affine,
- self-dual.

Then prove a finite-gate universality criterion of the following shape:

> If a finite gate library `G` contains definable operations that violate each of the standard obstruction classes (constant-preserving, monotone, affine, self-dual), then the clone generated by `G` contains NAND, hence is universal.

### Lean-facing theorem shape
This can be staged as a theorem schema:

```lean
theorem generates_nand_of_breaking_invariants
  (G : Finset (Σ k : ℕ, ((Fin k → Bool) → Bool))) :
  breaks_zero_preserving G →
  breaks_one_preserving G →
  breaks_monotone G →
  breaks_affine G →
  breaks_selfDual G →
  Generates G nand_op
```

and then

```lean
theorem universal_of_generates_nand
  (G : Finset (Σ k : ℕ, ((Fin k → Bool) → Bool))) :
  Generates G nand_op →
  ∀ {n : ℕ} (f : (Fin n → Bool) → Bool),
    ∃ c : GCircuit G n, eval c = f
```

If full Post completeness is too large for one cycle, at minimum prove:

1. NAND universal.
2. NOR universal.
3. If a library generates negation and conjunction, then it is universal.
4. If a library generates negation and disjunction, then it is universal.

These are already nontrivial and reusable.

## Proof strategy architecture

### Strategy A: Truth-table synthesis via disjunctive normal form
This is the most promising first proof because it is constructive, finite, and Lean-friendly.

Steps:
1. For a given `f : (Fin n → Bool) → Bool`, define the finite set of satisfying assignments:
   ```lean
   {σ : Fin n → Bool | f σ = true}
   ```
   Since `Fin n → Bool` is finite, use `Fintype` enumeration.
2. For each satisfying assignment `σ`, build a “minterm circuit” `mσ` that outputs true exactly on `σ`. This uses conjunctions of literals:
   - input `i` if `σ i = true`,
   - negated input `i` if `σ i = false`.
3. OR all minterms together to obtain a circuit computing `f`.
4. Finally, express `NOT`, `AND`, and `OR` using NAND alone:
   - `¬a = nand a a`
   - `a ∧ b = ¬(nand a b)`
   - `a ∨ b = nand (¬a) (¬b)`

Why this is best:
- Finite truth-table arguments are robust in Lean.
- The only hard part is managing finite products and assignment equality.
- It yields an explicit synthesis algorithm, not merely existence.

### Strategy B: Functional completeness via generated connectives
This is elegant and modular.

Steps:
1. Define semantic expressibility:
   ```lean
   DefinableByNand (f : BFun n) : Prop := ∃ c, eval c = f
   ```
2. Prove closure of definable functions under substitution/composition.
3. Show constants, negation, conjunction, and disjunction are definable by NAND.
4. Prove by induction on DNF formulas that every boolean formula is NAND-definable.
5. Use the finite completeness theorem: every boolean function has a DNF formula.

Why it is good:
- Cleaner algebraic story.
- Sets up later generalizations to arbitrary gate libraries and clone closure.

Potential weakness:
- You still need a formal DNF completeness theorem, which may be more work than direct circuit construction.

### Strategy C: Finite universal algebra / clone route
This is the most visionary, but likely second-cycle unless you move very efficiently.

Steps:
1. Define the clone generated by a gate library as the smallest family of boolean operations closed under projections and composition.
2. Define obstruction classes: monotone, affine, self-dual, etc.
3. Prove each obstruction class is clone-closed.
4. Show NAND lies outside each obstruction class and can be synthesized once all obstructions are broken.
5. Deduce universality from NAND generation.

Why it matters:
- This is the route to a formal Post-style completeness theorem.
- It would be a field-opening contribution inside Lean’s ecosystem.

Why it may be harder:
- Considerable infrastructure for variable arity and composition.

## Concrete intermediate lemmas to prove

These should be explicit theorem targets, not just ideas.

```lean
def notC {n : ℕ} (c : Circuit n) : Circuit n := Circuit.nand c c
def andC {n : ℕ} (a b : Circuit n) : Circuit n := notC (Circuit.nand a b)
def orC  {n : ℕ} (a b : Circuit n) : Circuit n := Circuit.nand (notC a) (notC b)
```

Then:

```lean
theorem eval_notC {n} (c : Circuit n) (σ) :
  Circuit.eval (notC c) σ = ! Circuit.eval c σ

theorem eval_andC {n} (a b : Circuit n) (σ) :
  Circuit.eval (andC a b) σ = (Circuit.eval a σ && Circuit.eval b σ)

theorem eval_orC {n} (a b : Circuit n) (σ) :
  Circuit.eval (orC a b) σ = (Circuit.eval a σ || Circuit.eval b σ)
```

Minterm exactness:

```lean
def literalCircuit {n : ℕ} (i : Fin n) (b : Bool) : Circuit n := ...
def mintermCircuit {n : ℕ} (τ : Fin n → Bool) : Circuit n := ...
```

Target:

```lean
theorem eval_mintermCircuit_eq_true_iff {n : ℕ} (τ σ : Fin n → Bool) :
  Circuit.eval (mintermCircuit τ) σ = true ↔ σ = τ
```

This theorem is the heart of exact synthesis.

Then define the DNF circuit from the finite list of satisfying assignments and prove:

```lean
theorem eval_dnfCircuit {n : ℕ} (f : BFun n) (σ : Fin n → Bool) :
  Circuit.eval (dnfCircuit f) σ = f σ
```

From this, `nand_universal` follows immediately.

## Cross-domain connections you should explicitly exploit

### 1. Universal algebra and finite model theory
This theorem is really about definability and closure. Once formalized, it opens the door to:
- mechanized Post lattice fragments,
- exact expressivity classifications for finite logical languages,
- automated discovery of minimal universal gate sets.

### 2. Complexity theory
A verified universality theorem is the semantic bedrock for:
- circuit-size upper bounds,
- depth-vs-size tradeoffs,
- verified reductions between computational models.

Even if you do not prove complexity bounds this cycle, structure definitions so that size/depth measures can be added later:
```lean

def Circuit.depth : Circuit n → ℕ
```

### 3. Category theory / compositional algebra
Circuits form a compositional syntax with semantics by evaluation. This is fertile ground for:
- operads of gates,
- symmetric monoidal categories of circuits,
- Hopf/renormalization-inspired decomposition principles.

This is where the catalog’s coproduct/splitting theorems may become philosophically relevant: universality can be framed as the ability of a compositional algebra to generate every observable operation from a tiny basis.

### 4. Additive combinatorics and invariant obstructions
Non-universal gate classes are characterized by preserved structure. This mirrors additive combinatorics, where low-complexity structure is detected by invariants and energy bounds. Long-term, one could search for quantitative universality certificates using invariant decay under composition.
