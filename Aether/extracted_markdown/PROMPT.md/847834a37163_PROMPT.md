## Core Mathematical Framing

The Euler–Mascheroni constant is
\[
\gamma = \lim_{n\to\infty}\left(\sum_{k=1}^n \frac1k - \log n\right).
\]
Its irrationality is open. Therefore, the correct research target is:

- formalize the strongest approximation statements available from elementary analysis and continued fractions,
- derive conditional irrationality criteria from explicit approximation growth bounds,
- connect γ to zeta/L-function expansions so that future work can import transcendence machinery.

The revolutionary significance is this: if Aristotle builds the **formal approximation theory of γ** in Lean, then future cycles can test irrationality heuristics computationally, compare continued-fraction growth against random models, and connect analytic number theory to formal Diophantine approximation. This opens a new subfield: **machine-assisted irrationality research in Lean for constants defined by renormalized divergent sums**.

## Precise Theorem Targets

### Target A: Formal existence and identification of γ via harmonic renormalization

Prove the convergence of the classical sequence
\[
a_n := \sum_{k=1}^n \frac1k - \log n
\]
and package the limit as a canonical real constant.

A Lean-facing target could look like:

```lean
def harmonic (n : ℕ) : ℝ := ∑ k in Finset.Icc 1 n, (1 : ℝ) / k

def eulerMascheroniSeq (n : ℕ) : ℝ :=
  harmonic n - Real.log n

def eulerMascheroni : ℝ :=
  sSup {x : ℝ | ∃ N : ℕ, ∀ n ≥ N, x ≤ eulerMascheroniSeq n} -- or via `limUnder`
```

More realistically, use Mathlib’s existing limit framework rather than defining by `sSup`. The theorem target is:

```lean
theorem tendsto_eulerMascheroniSeq :
  ∃ γ : ℝ, Filter.Tendsto eulerMascheroniSeq Filter.atTop (nhds γ)
```

and then uniqueness/definition:

```lean
noncomputable def eulerMascheroni : ℝ := Classical.choose tendsto_eulerMascheroniSeq

theorem tendsto_eulerMascheroni :
  Filter.Tendsto eulerMascheroniSeq Filter.atTop (nhds eulerMascheroni)
```

A stronger theorem, and more useful for downstream irrationality criteria:

```lean
theorem eulerMascheroniSeq_bounds (n : ℕ) (hn : 1 ≤ n) :
  0 < (harmonic n - Real.log (n + 1)) ∧
  harmonic n - Real.log n < 1 / n
```

or some equivalent explicit two-sided estimate. This gives a certified rate of convergence.

**Why this matters:** It converts γ from a folklore analytic constant into a formally manipulable object with explicit error control. That error control is the raw material for all subsequent rational approximation theorems.

### Target B: Continued-fraction irrationality criterion specialized to γ-approximants

You likely cannot prove γ irrational directly, but you can prove a sharp meta-theorem:

> If a real number admits infinitely many rational approximants with error strictly smaller than \(1/(2q^2)\), then it is irrational.

Specialize this to any explicit approximation scheme for γ that you can verify.

Lean-style theorem:

```lean
theorem irrational_of_exists_good_rat_approx
    {x : ℝ}
    (h : ∀ N : ℕ, ∃ p q : ℤ, (q : ℝ) > N ∧
      |x - p / q| < 1 / (2 * (q : ℝ)^2)) :
    Irrational x
```

A more natural version uses `ℕ` denominators and coerces into `ℝ`:

```lean
theorem irrational_of_infinitely_many_approx
    {x : ℝ}
    (h : ∀ N : ℕ, ∃ p : ℤ, ∃ q : ℕ, q ≥ N ∧
      |x - (p : ℝ) / q| < 1 / (2 * (q : ℝ)^2)) :
    Irrational x
```

Then define a sequence of rational approximants to γ, for example
\[
r_n := H_n - \log n,
\]
not rational because of \(\log n\), so this is not directly Diophantine. Therefore you need a better object: construct **auxiliary rational approximants** coming from truncations/Padé-like expansions for \(\log(1+x)\), or continued fractions for harmonic-log combinations if available.

A productive theorem here is conditional:

```lean
theorem irrational_eulerMascheroni_of_auxiliary_approx
    (h : ∀ N : ℕ, ∃ p : ℤ, ∃ q : ℕ, q ≥ N ∧
      |eulerMascheroni - (p : ℝ) / q| < 1 / (2 * (q : ℝ)^2)) :
    Irrational eulerMascheroni
```

This is not vacuous: it isolates the exact Diophantine threshold future work must hit.

**Why this matters:** This is the formal “port” through which any future computational or analytic approximation scheme can discharge irrationality. It transforms an open question into a sequence of finite certification tasks.

### Target C: Counterexample theorem to naïve rationality attacks

You should explicitly kill a weak strategy. For example, prove that merely having convergence by rationals does **not** imply irrationality, or that \(O(1/q)\)-quality approximations are too weak.

A clean theorem:

```lean
theorem exists_rat_seq_tendsto_of_rat (x : ℝ) (hx : x ∈ Set.range (fun q : ℚ => (q : ℝ))) :
  ∃ a : ℕ → ℚ, Filter.Tendsto (fun n => ((a n : ℚ) : ℝ)) Filter.atTop (nhds x)
```

More importantly, prove the insufficiency threshold:

```lean
theorem not_irrationality_certificate_of_c_over_q
    (C : ℝ) (hC : 0 < C) :
    ∃ x : ℝ, ¬ Irrational x ∧
      ∀ N : ℕ, ∃ p : ℤ, ∃ q : ℕ, q ≥ N ∧
        |x - (p : ℝ) / q| < C / q
```

Take \(x = 0\) or any rational. This sounds trivial, but it is scientifically important: it tells future cycles that approximation quality must cross the \(1/q^2\) barrier, not merely \(1/q\).

Even sharper:

```lean
theorem rational_has_eventually_no_too_good_approx
    {x : ℝ} (hx : x ∈ Set.range (fun q : ℚ => (q : ℝ))) :
    ∃ C > 0, ∀ p : ℤ, ∀ q : ℕ, q ≠ 0 →
      |x - (p : ℝ) / q| ≥ C / (q : ℝ)
```

or an equivalent denominator-gap lower bound for rationals.

**Why this matters:** It prevents wasted effort. It formally separates “good approximation” from “irrationality-certifying approximation,” which is exactly the conceptual bottleneck in γ research.

### Target D: Zeta/L-function bridge through Laurent expansion at s = 1

The deepest bridge theorem is to formalize that γ is the constant term in the Laurent expansion of \(\zeta(s)\) at \(s=1\), at least in a weak asymptotic sense if full meromorphic expansion is too heavy.

An ambitious but field-opening target:

\[
\lim_{s\to 1^+} \left(\zeta(s) - \frac{1}{s-1}\right) = \gamma.
\]

If Mathlib already has enough zeta infrastructure, aim for:

```lean
theorem tendsto_zeta_sub_pole :
  Filter.Tendsto
    (fun s : ℝ => riemannZeta s - 1 / (s - 1))
    (nhdsWithin 1 (Set.Ioi 1))
    (nhds eulerMascheroni)
```

If `riemannZeta` on `ℝ` is not available or not developed enough, prove a discrete Abel-summation bridge instead, e.g. a theorem expressing
\[
\sum_{n\le N}\frac1n - \log N
\]
as the renormalized constant term of a Dirichlet-series truncation.

A more accessible intermediate theorem:

```lean
theorem tendsto_dirichlet_renorm :
  Filter.Tendsto
    (fun s : ℝ =>
      (∑' n : ℕ, if n = 0 then 0 else (n : ℝ)⁻¹^s) - 1 / (s - 1))
    (nhdsWithin 1 (Set.Ioi 1))
    (nhds eulerMascheroni)
```

This may require substantial infrastructure; if too ambitious, formulate it as a conjectural interface theorem and prove weaker summation-by-parts lemmas that would support it.

**Why this matters:** This is the genuine cross-domain bridge. It connects asymptotic harmonic analysis, analytic number theory, and special values of L-functions. Once formalized, the same framework can be extended to Stieltjes constants, Dirichlet L-values, and regulators.

## Proof Strategy Architecture

### Strategy A: Elementary analysis + monotonicity + integral comparison
Most promising for Target A.

1. Define \(H_n = \sum_{k=1}^n 1/k\) and \(a_n = H_n - \log n\).
2. Use integral comparison:
   \[
   \log(n+1) \le H_n \le 1 + \log n
   \]
   or sharper telescoping inequalities from
   \[
   \int_k^{k+1} \frac{dx}{x}.
   \]
3. Show \(a_n\) is bounded and monotone (or Cauchy via explicit difference bounds), then conclude convergence.
4. Extract explicit error estimates such as
   \[
   \frac{1}{2(n+1)} \lesssim a_n - \gamma \lesssim \frac{1}{2n}
   \]
   if you can prove them.

**Why best:** It is robust, elementary, and likely already close to what Mathlib supports: integrals of \(1/x\), `Real.log`, finite sums, monotone convergence.

---

### Strategy B: Diophantine approximation criterion via denominator separation
Best for Target B and C.

1. First prove a general lemma: if \(x = a/b \in \mathbb{Q}\), then for any distinct rational \(p/q\),
   \[
   \left|x - \frac pq\right| \ge \frac{1}{|b|q}
   \]
   up to normalization.
2. Deduce that infinitely many approximants with error \(< c/q^2\) force irrationality.
3. Package this as a reusable theorem independent of γ.
4. Then define the γ-specific conditional theorem: any explicit approximation family meeting that bound implies `Irrational eulerMascheroni`.

**Why best:** Even if γ remains open, this yields genuine reusable infrastructure in formal irrationality theory.

---

### Strategy C: Summation by parts / Mellin-transform heuristic formalization
Most visionary for Target D.

1. Express harmonic sums as partial sums of a Dirichlet series derivative or an Abel transform.
2. Show that the subtraction of the pole term \(1/(s-1)\) corresponds to logarithmic renormalization.
3. Prove a limit theorem connecting the renormalized zeta expression to `eulerMascheroni`.
4. If full analytic continuation is out of reach, prove discrete approximants that mirror the Laurent expansion.

**Why promising:** This is the route that opens the L-function field. It is harder than Strategy A/B but has the highest long-term payoff.

## Cross-Domain Connections You Must Exploit

### 1. Analytic number theory × formal asymptotics
γ is not just a constant; it is the renormalized defect between a divergent arithmetic sum and a logarithmic integral. This places it at the boundary between discrete arithmetic and continuous analysis.

### 2. Diophantine approximation × continued fractions
Even if a full continued fraction for γ is intractable, formalize the **criterion layer**: convergents, best approximants, and irrationality thresholds. This creates infrastructure for later computational experiments on γ’s partial quotients.

### 3. Special values of L-functions × renormalization
γ is the constant term of a pole subtraction process. This is conceptually parallel to renormalization in mathematical physics: remove a divergent principal part, retain a canonical finite constant. Formalizing this bridge could later connect Stieltjes constants, spectral determinants, and entropy-like quantities.

### 4. Experimental mathematics × theorem proving
Because irrationality is open, your formal theorems should support computation:
- certified rational approximation searches,
- continued-fraction statistics,
- tests for growth of partial quotients,
- comparison with random irrational models.

This is how the project becomes scientific rather than aspirational.
