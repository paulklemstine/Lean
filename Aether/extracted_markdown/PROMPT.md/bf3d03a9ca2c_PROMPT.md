Title: Tropical Height Monotonicity on the Berggren Tree

Goal: produce a fully proved Lean file (no `sorry`) defining one explicit tropical/max-plus height on primitive Pythagorean triples and proving exact recursion and monotonicity results for the three Berggren children.

Scope constraints:
1. Stay tightly aligned with the existing Berggren/Lorentz formalization in the catalog.
2. Do not introduce vague notions like automorphic forms, harmonicity, or general tropical representation theory.
3. Prefer the strongest already-verified catalog foundations, especially FINAL files if available.
4. The deliverable should be a compact, self-contained formalization with several genuinely proved lemmas/theorems, not a scaffold of declarations.

Concrete mathematical target:
- Work with primitive Pythagorean triples generated by the three standard Berggren transformations.
- Define a tropical height function on triples, ideally
  `tropHeight (a,b,c) : ℤ := max a (max b c)`
  or the natural variant matching the types in the existing files.
- Then specialize to Pythagorean triples to prove that this height is just the hypotenuse coordinate `c` (or the corresponding ordered-coordinate statement available in the infrastructure).
- For each of the three Berggren children, prove an explicit formula for the child height by computing the child `c`-coordinate from the matrix action.
- Deduce strict monotonicity: each Berggren child has strictly larger tropical height than its parent.
- Prove a rooted-path theorem: along any finite path in the Berggren tree, tropical height is strictly increasing. If a convenient recursive tree datatype/path API is absent, formulate this as repeated child application or list-fold over child choices.
- Derive at least one computable separation bound, e.g. after `n` steps height is at least the initial height plus `n`, or a stronger bound following from the exact child formulas.

Recommended proof strategy:
- Reuse the existing definitions of Berggren matrices/child maps and primitive Pythagorean triples from the catalog.
- First prove low-level coordinate lemmas for each child transformation, especially the formula for the `c` coordinate.
- Then define `tropHeight` and prove simplification lemmas on valid triples.
- Use the explicit formulas to show `parent.c < child.c` for each branch.
- Lift one-step monotonicity to iterated paths by induction on a list/path length.

What to avoid:
- Do not spend time on unrelated divisibility or residue-obstruction lemmas.
- Do not create a large new API for tropical algebra unless it is directly necessary for these proofs.
- Do not leave theorem statements without proof terms.

Expected output:
- One Lean file in the BerggrenTree/TropicalHeight area with complete proofs.
- Theorems should be named clearly, with at least:
  * definition of tropical height,
  * exact child-height recursion lemmas for the three Berggren children,
  * strict child monotonicity,
  * path monotonicity / separation theorem.

If the current infrastructure makes `max a b c` awkward, simplify further: define height directly as the hypotenuse coordinate on primitive Pythagorean triples and explain in comments that this is the tropical height because `c` dominates `a,b` on such triples. The priority is a complete, nontrivial, checked formalization.
