## Precise Theorem Targets

You should formalize at least the following theorem family.

### 1. Full Newton–Girard recurrence

Let `μ : Fin m → R` be a finite family over a commutative ring or field of characteristic zero, and define:
- `p k = ∑ i, (μ i)^k`
- `e k =` the `k`th elementary symmetric polynomial in the `μ i`.

Then for every `k ≥ 1`,
\[
p_k = \sum_{j=0}^{k-2} (-1)^j e_{j+1}\, p_{k-1-j} + (-1)^{k-1} k\, e_k,
\]
equivalently
\[
p_k - e_1 p_{k-1} + e_2 p_{k-2} - \cdots + (-1)^{k-1} e_{k-1} p_1 + (-1)^k k e_k = 0.
\]

A Lean-oriented signature target could look like:

```lean
theorem newton_girard_general
    {R : Type*} [LinearOrderedField R]
    {m k : ℕ} (μ : Fin m → R) (hk : 1 ≤ k) :
    powerSum μ k
      =
    ∑ j in Finset.range (k - 1),
      (-1 : R) ^ j * esymm μ (j + 1) * powerSum μ (k - 1 - j)
      + (-1 : R) ^ (k - 1) * (k : R) * esymm μ k
```

If your existing definitions use a different indexing convention, adapt accordingly, but preserve the mathematical content exactly.

A second equivalent formulation is also worth proving, because it is often easier to use in downstream rewriting:

```lean
theorem newton_girard_general_zero
    {R : Type*} [LinearOrderedField R]
    {m k : ℕ} (μ : Fin m → R) (hk : 1 ≤ k) :
    ∑ j in Finset.range k,
      (-1 : R) ^ j * esymm μ j * powerSum μ (k - j)
    =
    0
```

with the convention `powerSum μ 0 = m` and suitable normalization of `esymm μ 0 = 1`. If this formulation is cleaner in your setup, make it the main theorem and derive the recurrence form as a corollary.

### 2. Vanishing above the number of variables and finite closure

For `k > m`, the elementary symmetric polynomial `e_k` vanishes. Combined with Newton–Girard, this yields a **finite linear recurrence** for all higher power sums.

Target theorem:

```lean
theorem powerSum_linear_recurrence_of_gt_card
    {R : Type*} [LinearOrderedField R]
    {m k : ℕ} (μ : Fin m → R) (hk : m < k) :
    powerSum μ k
      =
    ∑ j in Finset.range m,
      (-1 : R) ^ j * esymm μ (j + 1) * powerSum μ (k - 1 - j)
```

This theorem is conceptually decisive: it says that **all high-order moments are generated by finitely many low-order invariants**. This is the algebraic engine that makes entropy approximation possible.

\[

Then prove that this depends only on the elementary symmetric data of `μ`, via Newton–Girard reduction of monomials.

### 4. Higher-order entropy surrogate theorem on a gapped interval

Let
\[
h_\alpha(x) =
\begin{cases}
-x \log x & \alpha = 1 \\
\frac{x^\alpha - x}{1-\alpha} & \alpha \neq 1
\end{cases}
\]
or any one-parameter entropy kernel already present in your development.

Fix `0 < δ < 1/2`. On the compact interval `[δ, 1 - δ]`, approximate `h_α` by a degree-`N` polynomial `q_N` with uniform error `ε_N`, ideally with geometric decay `ε_N ≤ C δ^N` if your approximation theorem supports it, or at minimum `ε_N → 0`.

Then for spectra `μ_i ∈ [δ, 1 - δ]`,
\[
\left|\sum_i h_\alpha(\mu_i) - \sum_i q_N(\mu_i)\right|
\le m \, \|h_\alpha - q_N\|_{\infty,[\delta,1-\delta]}.
\]

And since `∑_i q_N(μ_i)` is computable from elementary symmetric data, this gives an entropy surrogate.

Lean target skeleton:

```lean
theorem entropy_surrogate_uniform_error
    {m N : ℕ} {δ : ℝ} (hδ : 0 < δ) (hδ' : δ < 1 / 2)
    (μ : Fin m → ℝ)
    (hμlo : ∀ i, δ ≤ μ i) (hμhi : ∀ i, μ i ≤ 1 - δ)
    (qN : Polynomial ℝ)
    (happrox :
      ∀ x ∈ Set.Icc δ (1 - δ),
        |entropyKernel α x - qN.eval x| ≤ εN) :
    |(∑ i, entropyKernel α (μ i)) - spectralPolyEval qN μ|
      ≤ m * εN
```

A stronger asymptotic version is highly desirable:

```lean
theorem entropy_surrogate_converges
    ...
    (hq : ∀ N, ∃ qN : Polynomial ℝ, ∀ x ∈ Set.Icc δ (1 - δ),
      |entropyKernel α x - qN.eval x| ≤ err N)
    (herr : Tendsto err atTop (nhds 0)) :
    Tendsto
      (fun N => surrogateEntropyFromEsymm α N μ)
      atTop
      (nhds (∑ i, entropyKernel α (μ i)))
```

If proving geometric `O(ρ^N)` rigorously in full generality is too heavy, isolate a theorem with an explicit assumption:

```lean
(hgeo : ∀ N, err N ≤ C * ρ^N) (hρ : 0 ≤ ρ ∧ ρ < 1)
```

and then derive the surrogate error estimate.

## Deep Proof Strategy Options

You must give the development real mathematical depth. At least 3 theorems should use induction, `rcases`, `by_contra`, `field_simp`, or substantial `calc` chains.

### Strategy A: Generating function / coefficient extraction
Most visionary and conceptually clean.

1. Define
   \[
   E(t) = \prod_{i=1}^m (1 + \mu_i t) = \sum_{r=0}^m e_r t^r.
   \]
2. Compute logarithmic derivative:
   \[
   \frac{E'(t)}{E(t)} = \sum_i \frac{\mu_i}{1+\mu_i t}.
   \]
   Multiply by `t` or substitute `-t` to align signs with your indexing convention.
3. Expand the right-hand side as a formal power series:
   \[
   \sum_i \frac{\mu_i t}{1+\mu_i t}
   = \sum_{k\ge1} (-1)^{k-1} p_k t^k.
   \]
4. Compare coefficients with
   \[
   tE'(t)=\left(\sum_{r\ge1} r e_r t^r\right),
   \quad
   E(t)\left(\sum_{k\ge1} (-1)^{k-1} p_k t^k\right),
   \]
   and extract the coefficient of `t^k`.

**Why promising:** It gives the universal theorem in one stroke and explains the recurrence structurally, not combinatorially. It also naturally suggests the finite linear recurrence and links to analytic approximation.

Lean tools likely needed:
- `Polynomial.coeff`
- product coefficient lemmas
- derivative coefficient identities
- formal power series if available and convenient; otherwise stay in polynomials truncated to relevant degree.

### Strategy B: Induction on `k` using the ESP recurrence
Likely more robust if coefficient extraction becomes technically expensive.

1. Use `esymmCoeff_succ_eq` or the characteristic-polynomial recurrence to express `e_{r+1}` recursively.
2. Prove the Newton–Girard formula by induction on `k`.
3. For the inductive step, isolate the alternating convolution term and reorganize with `Finset` algebra.
4. Use vanishing of `e_k` for `k > m` to derive the finite recurrence.

**Why promising:** This probably integrates most directly with the existing catalog, especially if the low-order `k = 1,2,3` proofs already establish notation and helper lemmas. It may require more painful summation manipulations but fewer imported abstractions.

### Strategy C: Characteristic polynomial / companion recurrence
Best for the closure theorem and algorithm.

1. Define the monic polynomial
   \[
   \chi_\mu(X)=\prod_i (X-\mu_i)
   = X^m - e_1 X^{m-1} + \cdots + (-1)^m e_m.
   \]
2. Since each `μ_i` is a root, multiply by `μ_i^{k-m}` and sum over `i`.
3. Obtain
   \[
   p_k - e_1 p_{k-1} + \cdots + (-1)^m e_m p_{k-m}=0
   \quad (k>m).
   \]
4. Then back-solve the full Newton–Girard identities or at least the recurrence closure and algorithmic reconstruction.

**Why promising:** This is ideal for the computational engine: once you have the characteristic recurrence, you can implement a verified dynamic-programming algorithm for power sums and surrogate entropy. It also connects directly to linear recurrences, control theory, and signal processing.

**Recommended plan:** Use **Strategy A** for the flagship theorem if feasible, then derive the algorithmic recurrence with **Strategy C**, and keep **Strategy B** as fallback for difficult coefficient lemmas.
