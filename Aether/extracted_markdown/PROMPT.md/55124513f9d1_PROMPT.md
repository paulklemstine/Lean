## Assignment: Define tropical factor rank

**Mode:** prove

You are not being asked for a cosmetic definition. You are being asked to formalize a genuinely structural invariant at the boundary of tropical linear algebra, complexity, and expressive efficiency in modern architectures: **tropical factor rank** as the minimum number of tropical rank-1 summands needed to build a matrix. This is the tropical analogue of nonnegative rank, Boolean rank, and tensor factorization complexity — and if done correctly, it becomes a bridge theorem generator across tropical geometry, matrix complexity, attention mechanisms, and compressed representations.

The core ambition is to make `tropFactorRank` into a mathematically usable invariant in Lean 4, then prove the first nontrivial structural theorems that connect it to the catalog’s existing rank bounds from deep networks, attention, and tensor compilation.

## Primary Formalization Target

Work over tropical matrices with entries in `WithTop ℤ`, using tropical addition = `inf`/`min`-style aggregation and tropical multiplication = ordinary addition. Since the catalog already uses `WithTop ℤ`, stay there unless a stronger API exists in the local codebase.

A rank-1 tropical matrix should be formalized as one representable in separable form
\[
M_{ij} = u_i + v_j
\]
for vectors `u : Fin m → WithTop ℤ` and `v : Fin n → WithTop ℤ`.

Then define tropical factor rank as the least `r` such that
\[
M = \bigoplus_{t < r} (u^{(t)} \odot (v^{(t)})^\top),
\]
i.e. entrywise infimum/minimum of `r` tropical rank-1 matrices.

### Suggested Lean 4 definitions

You should choose a definition that is easiest to prove things about. A good route is to define the decomposition predicate first, then define the rank as the minimal witness.

```lean
open scoped BigOperators

def TropRankOne {m n : ℕ} (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) : Prop :=
  ∃ u : Fin m → WithTop ℤ, ∃ v : Fin n → WithTop ℤ,
    ∀ i j, M i j = u i + v j

def TropDecompOfRank {m n : ℕ} (r : ℕ)
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) : Prop :=
  ∃ U : Fin r → Fin m → WithTop ℤ,
    ∃ V : Fin r → Fin n → WithTop ℤ,
      ∀ i j, M i j = ⨅ k : Fin r, (U k i + V k j)

def tropFactorRank {m n : ℕ}
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) : ℕ :=
  Nat.findGreatest (fun r => False) 0 -- placeholder, replace by a genuine minimal-witness definition
```

That placeholder is intentionally wrong: you should replace it by a robust minimal definition. Since factor rank is an **infimum over natural witnesses**, the cleanest practical Lean definition is often:

```lean
def tropFactorRank {m n : ℕ}
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) : ℕ :=
  sInf {r : ℕ | TropDecompOfRank r M}
```

but only if you can conveniently prove the set is nonempty. If `sInf` over `ℕ` becomes awkward, define it via `Nat.find` using an existence theorem for some decomposition, e.g. the trivial decomposition by one summand per column or per row.

A very useful existential theorem to prove early is:

```lean
theorem tropDecomp_exists_of_finite {m n : ℕ}
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) :
    ∃ r : ℕ, TropDecompOfRank r M
```

A canonical upper bound is `r ≤ n` by decomposing columnwise:
\[
M_{ij} = \min_{k<n} (\delta_{jk} + M_{ik}),
\]
where `δ_{jk}` is `0` if `j=k` and `⊤` otherwise. This is exactly the kind of finite constructive witness Lean likes.

## Breakthrough Theorem Targets

### Theorem 1: Existence and minimality of tropical factor rank
This is the foundational theorem that makes the invariant real.

#### Precise statement
For every finite tropical matrix, there exists a tropical rank-`r` decomposition for some `r`, and `tropFactorRank M` is the least such `r`.

#### Lean target
```lean
theorem tropFactorRank_spec {m n : ℕ}
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) :
    TropDecompOfRank (tropFactorRank M) M ∧
    ∀ r : ℕ, TropDecompOfRank r M → tropFactorRank M ≤ r
```

#### Why this matters
Without this theorem, `tropFactorRank` is just a definition. With it, it becomes a usable complexity invariant. This is the tropical analogue of saying tensor rank or nonnegative rank is a true optimization quantity, not just syntax.

### Theorem 2: Finite-dimensional upper bound
This should be your first nontrivial structural theorem.

#### Precise statement
For any `m × n` tropical matrix,
\[
\operatorname{tropFactorRank}(M) \le \min(m,n).
\]
At minimum, prove one-sided bounds
\[
\operatorname{tropFactorRank}(M) \le n
\quad\text{and}\quad
\operatorname{tropFactorRank}(M) \le m.
\]

#### Lean target
```lean
theorem tropFactorRank_le_numCols {m n : ℕ}
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) :
    tropFactorRank M ≤ n

theorem tropFactorRank_le_numRows {m n : ℕ}
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) :
    tropFactorRank M ≤ m

theorem tropFactorRank_le_min {m n : ℕ}
    (M : Matrix (Fin m) (Fin n) (WithTop ℤ)) :
    tropFactorRank M ≤ min m n
```

#### Why this is a breakthrough
This is the first theorem showing tropical factor rank is not an arbitrary finite witness count but a dimension-controlled complexity measure. It puts tropical factor rank into the same conceptual family as classical rank bounds, but with different geometry and decomposition semantics.

#### Connection to catalog
Use `tropical_rank_le_dim` as a conceptual and possibly technical precursor. Even if it concerns tropical rank rather than factor rank, the philosophical move is the same: finite dimension controls tropical complexity. Your theorem should sharpen the ecosystem by introducing a second rank notion with explicit comparison opportunities later.

## Proof Strategy Architecture

You must not rely on one route. Here are three strategies; pursue at least two in parallel.

### Strategy A: Constructive finite decomposition via columns or rows
This is the most promising route for foundational theorems.

1. For each column `j`, define a rank-1 matrix
   \[
   R^{(j)}_{i\ell} = M_{ij} + \delta_{j\ell},
   \]
   where `δ_{jℓ} = 0` if `j=ℓ` and `⊤` otherwise.
2. Show that
   \[
   M_{i\ell} = \min_{j<n} R^{(j)}_{i\ell}.
   \]
3. Conclude `TropDecompOfRank n M`, hence `tropFactorRank M ≤ n`.

**Why best:** It is fully constructive, finite, and Lean-friendly. No abstract order theory is needed beyond finite infima.

### Strategy B: Minimal witness via `Nat.find`
This is the best route for the specification theorem.

1. First prove existence of some decomposition using Strategy A.
2. Define
   ```lean
   def tropFactorRank (M) := Nat.find (exists_decomp M)
   ```
   where `exists_decomp M : ∃ r, TropDecompOfRank r M`.
3. Prove the spec theorem from `Nat.find_spec` and `Nat.find_min'`.

**Why strong:** Avoids subtle `sInf` obligations over `ℕ`, especially if the complete lattice machinery for natural-number infima becomes annoying.

### Strategy C: Comparison with existing tropical rank notions
This is the most conceptually ambitious route.

1. Examine `tropical_rank_le_dim` and identify whether its notion of rank is minor-based, Barvinok-style, or combinatorial.
2. Prove a comparison theorem:
   \[
   \text{tropical rank}(M) \le \text{tropFactorRank}(M)
   \]
   or the reverse, depending on the exact library notion.
3. Use this to inherit dimension bounds or to create new lower-bound tools for factor rank.

**Why powerful:** This opens a new rank-comparison program, analogous to the ecosystem of classical rank, nonnegative rank, psd rank, and tensor rank.

This invariant is a min-plus circuit size proxy for matrix synthesis. Rank-1 tropical summands are “atomic templates,” and the factor rank is the minimal number of such templates. This is directly analogous to nonnegative rank in communication complexity and extension complexity.
