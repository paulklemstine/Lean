## Research Task: EML Stone–Weierstrass for vector lattices via lattice closure + affine closure

Research Mode: PROVE

Work in `C(X, ℝ) := ContinuousMap X ℝ` with the sup norm topology. The goal is to formalize a genuine lattice-version Stone–Weierstrass theorem: multiplicative closure is not needed if one has vector-space closure plus pointwise `sup`/`inf`. This is the right theorem for the EML program because EML classes are naturally stable under affine operations and max/min, and this result upgrades those closure properties directly to universal approximation on compact spaces.

A good formal target is not merely “dense” in an abstract topological sense, but the concrete ε-approximation statement in sup norm. If Mathlib’s `Subalgebra` Stone–Weierstrass theorem is not directly reusable, prove the finite-patching approximation theorem directly.

## Essential intermediate lemmas

First build the vector-lattice API from the raw hypotheses. These lemmas are mathematically indispensable and should be stated explicitly.

### 1. Negation and subtraction closure

```lean
lemma eml_mem_neg
    {X : Type*} [TopologicalSpace X]
    (A : Set C(X, ℝ))
    (hsmul : ∀ {a : ℝ} {f : C(X, ℝ)}, f ∈ A → a • f ∈ A)
    {f : C(X, ℝ)} (hf : f ∈ A) :
    -f ∈ A := by
  simpa using hsmul (a := (-1 : ℝ)) hf
```

```lean
lemma eml_mem_sub
    {X : Type*} [TopologicalSpace X]
    (A : Set C(X, ℝ))
    (hadd : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → f + g ∈ A)
    (hsmul : ∀ {a : ℝ} {f : C(X, ℝ)}, f ∈ A → a • f ∈ A)
    {f g : C(X, ℝ)} (hf : f ∈ A) (hg : g ∈ A) :
    f - g ∈ A := by
  exact hadd hf (eml_mem_neg A hsmul hg)
```

### 3. Two-point interpolation lemma

This is the key constructive ingredient. From separation of points, build an element of `A` with prescribed values at two points.

A very useful statement is:

```lean
lemma eml_exists_eq_at_two_points
    {X : Type*} [TopologicalSpace X]
    (A : Set C(X, ℝ))
    (hconst : ∀ c : ℝ, ContinuousMap.const X c ∈ A)
    (hadd : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → f + g ∈ A)
    (hsmul : ∀ {a : ℝ} {f : C(X, ℝ)}, f ∈ A → a • f ∈ A)
    (hsep : ∀ x y : X, x ≠ y →
      ∃ f : C(X, ℝ), f ∈ A ∧ f x ≠ f y)
    {x y : X} (hxy : x ≠ y) (a b : ℝ) :
    ∃ f : C(X, ℝ), f ∈ A ∧ f x = a ∧ f y = b
```

Proof idea: choose `u ∈ A` with `u x ≠ u y`; define
`f := ((b - a) / (u y - u x)) • (u - const (u x)) + const a`,
or an equivalent affine normalization. Then verify `f x = a`, `f y = b`.
This is where closure under constants, addition, and real scalar multiplication is crucial. If division is awkward in Lean, define the scalar carefully and use `field_simp` only on the real scalar side after proving the denominator is nonzero.

### 4. One-sided local barrier lemma

For the compactness patching argument, prove a local interpolation/barrier statement around each point `x`.

A strong and useful formulation is:

```lean
lemma eml_exists_local_lower_bound
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
    (A : Set C(X, ℝ))
    (hconst : ∀ c : ℝ, ContinuousMap.const X c ∈ A)
    (hadd : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → f + g ∈ A)
    (hsmul : ∀ {a : ℝ} {f : C(X, ℝ)}, f ∈ A → a • f ∈ A)
    (hsup : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → sup f g ∈ A)
    (hinf : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → inf f g ∈ A)
    (hsep : ∀ x y : X, x ≠ y →
      ∃ f : C(X, ℝ), f ∈ A ∧ f x ≠ f y) :
    ∀ (g : C(X, ℝ)) (x : X) (ε : ℝ), 0 < ε →
      ∃ f : C(X, ℝ), f ∈ A ∧
        g x - ε < f x ∧
        ∃ U : Set X, IsOpen U ∧ x ∈ U ∧
          ∀ y ∈ U, f y < g y + ε
```

But an even more classical route is pairwise interpolation for each `y`, then use continuity to get an open neighborhood around `y`, then compactness to extract finitely many neighborhoods, then patch them by finite `inf`, and finally patch in `x` by finite `sup`.

Concretely, for fixed `x` and each `y`, use the previous lemma to get `f_xy ∈ A` such that
`f_xy x = g x` and `f_xy y = g y`.
By continuity of `f_xy - g`, there is a neighborhood `U_y` of `y` with
`f_xy z < g z + ε` on `U_y`.
Since also `f_xy x = g x`, one has `g x - ε < f_xy x`.
Compactness gives finitely many `U_y` covering `X`; take the finite infimum of the corresponding `f_xy`. This produces `F_x ∈ A` with
`F_x x > g x - ε`
and
`∀ z, F_x z < g z + ε`.

This finite-inf construction is the heart of the lattice proof.

## Suggested proof architecture for the main theorem

### Step 1: Build affine and lattice closure API
From `hconst`, `hadd`, `hsmul`, derive closure under negation, subtraction, translates, absolute value, positive part, and negative part. This confirms that `A` behaves as a vector sublattice of `C(X, ℝ)`.

Key formulas:
- `-f = (-1 : ℝ) • f`
- `f - g = f + (-g)`
- `|f| = sup f (-f)`
- `f⁺ = sup f 0`
- `f⁻ = sup (-f) 0`
- `f = f⁺ - f⁻`

These are worth proving cleanly because they will also be reusable in later EML approximation results.

### Step 2: Two-point affine interpolation
For distinct `x ≠ y` and target values `a b : ℝ`, choose `u ∈ A` separating `x,y`. Affinely rescale `u` so that it takes values exactly `a,b` at `x,y`.

This is the main use of point separation. It upgrades “there exists a distinguisher” into “there exists a function matching arbitrary prescribed values at two points.” Without this lemma, the later local patching is much harder.

### Step 3: For each fixed `x`, construct a global lower approximant `F_x ∈ A`
Fix `g : C(X, ℝ)` and `ε > 0`. For each `y : X`, let `u_y ∈ A` satisfy
`u_y x = g x` and `u_y y = g y`
by the two-point interpolation lemma (if `y = x`, use the constant function `g x`).

By continuity of `u_y - g` and the fact `(u_y - g) y = 0`, there exists an open neighborhood `U_y` of `y` such that
`∀ z ∈ U_y, u_y z < g z + ε`.
The sets `U_y` cover `X`; compactness yields a finite subcover `U_{y₁}, …, U_{y_n}`.
Define
`F_x := inf (u_{y₁}) (inf (u_{y₂}) ... )`.
Then:
- `F_x ∈ A` by finite `inf` closure;
- `F_x x = g x`, hence `g x - ε < F_x x`;
- for every `z`, since some `z ∈ U_{y_i}`, we get `F_x z ≤ u_{y_i} z < g z + ε`.

Thus each `F_x` lies globally below `g + ε`, but is almost equal to `g` at the chosen point `x`.

### Step 4: Compactness again, then finite supremum
For each `x`, continuity of `F_x - g` and the inequality `g x - ε < F_x x` give an open neighborhood `V_x` of `x` such that
`∀ z ∈ V_x, g z - ε < F_x z`.
These `V_x` cover `X`; compactness gives a finite subcover `V_{x₁}, …, V_{x_m}`.
Define
`F := sup (F_{x₁}) (sup (F_{x₂}) ... )`.
Then:
- `F ∈ A` by finite `sup` closure;
- for every `z`, choose `i` with `z ∈ V_{x_i}`; then `g z - ε < F_{x_i} z ≤ F z`;
- also each `F_{x_i} z < g z + ε`, so `F z < g z + ε`.

Hence for all `z`,
`|F z - g z| < ε`,
and therefore `‖F - g‖ < ε`.

The final norm estimate may use a standard lemma equating the sup norm with the pointwise supremum on compact spaces, or you can prove
`∀ z, ‖(F - g) z‖ < ε` and then invoke a `ContinuousMap.norm_lt_iff`-style result if available.

### Step 5: Package as density if desired
Once the ε-approximation theorem is established, derive `Dense A` using the metric-space characterization of density:
`Dense A ↔ ∀ x ε > 0, ∃ y ∈ A, dist y x < ε`.
For `ContinuousMap X ℝ`, `dist f g = ‖f - g‖`.

## Lean-specific technical guidance

1. **Constants**  
   Use `ContinuousMap.const X c`.  
   Evaluate by `simp`.

2. **Pointwise lattice operations**  
   `sup` and `inf` on `C(X, ℝ)` should be pointwise.  
   Extensionality proof pattern:
   ```lean
   ext x
   simp [sup_eq_max, inf_eq_min]
   ```
   depending on available simp lemmas.

3. **Absolute value identity**  
   The cleanest proof of `|f| = sup f (-f)` is:
   ```lean
   ext x
   simp [abs_eq_max_neg]
   ```

4. **Two-point interpolation scalar**
   Given `u x ≠ u y`, define
   ```lean
   let α : ℝ := (b - a) / (u y - u x)
   let β : C(X, ℝ) := u - ContinuousMap.const X (u x)
   let f : C(X, ℝ) := α • β + ContinuousMap.const X a
   ```
   Then check values with `field_simp` after deriving `u y - u x ≠ 0`.

5. **Neighborhood extraction from continuity**
   For a continuous real-valued map `h` with `h y < ε`, use continuity to obtain a neighborhood where `h < ε`. It may be easiest to phrase this via preimages of open intervals:
   ```lean
   have hopen : IsOpen {z | h z < ε} := isOpen_lt h.continuous continuous_const
   have hy : y ∈ {z | h z < ε} := by ...
   ```
   Then set `U := {z | h z < ε}`.

6. **Finite subcover**
   Use compactness in the form:
   ```lean
   obtain ⟨t, htfin, hsub⟩ := isCompact_univ.elim_finite_subcover ...
   ```
   or an equivalent `CompactSpace` lemma already in Mathlib. If the general open-cover API becomes cumbersome, you can work with `Set.range U` and finite subsets of indices.

7. **Norm estimate**
   To conclude `‖F - g‖ < ε`, one likely needs a lemma of the form
   ```lean
   show ‖F - g‖ < ε
   ```
   from
   `∀ z, ‖(F - g) z‖ < ε`.
   Search for lemmas on `ContinuousMap.norm_lt_iff`, `nnnorm_lt_iff`, or the characterization of the sup norm by pointwise bounds on compact spaces. If unavailable, isolate this as a final helper lemma; it is standard and should be provable from the definition of the norm on `ContinuousMap`.

## Stronger corollaries worth attempting

After the main theorem, the following are natural and useful:

### Corollary 1: Rational-scalar closure suffices if upgraded to real-scalar closure in the closure
If direct `ℝ`-scalar closure is too strong for the intended EML class, prove a variant where `A` is closed under `ℚ`-scalars and conclude density of `A` after passing to its uniform closure. A possible theorem:

```lean
theorem eml_uniformDense_of_separatesPoints_vectorLattice_rat
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
    (A : Set C(X, ℝ))
    (hconst_rat : ∀ q : ℚ, ContinuousMap.const X (q : ℝ) ∈ A)
    (hadd : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → f + g ∈ A)
    (hsmul : ∀ {q : ℚ} {f : C(X, ℝ)}, f ∈ A → ((q : ℝ) • f) ∈ A)
    (hsup : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → sup f g ∈ A)
    (hinf : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A → inf f g ∈ A)
    (hsep : ∀ x y : X, x ≠ y →
      ∃ f : C(X, ℝ), f ∈ A ∧ f x ≠ f y) :
    Dense A
```

This may require an extra lemma approximating real constants and real scalars by rationals in sup norm. If this becomes too long, keep it as a second-stage theorem.

### Corollary 2: Closure under `max` and affine maps implies universal approximation for EML-generated classes
Once the theorem is in place, instantiate it for the EML function class generated by constants and coordinate maps under affine combinations and pointwise `max/min`. This is the conceptual payoff: it gives a clean universal approximation theorem without any multiplication hypothesis.

## Why this matters

This theorem is the correct ordered-functional-analytic upgrade of the current EML approximation program. It removes the algebra/product closure assumption from Stone–Weierstrass and replaces it with the closure operations that EML architectures actually possess: affine combination and lattice operations. Formally, it turns “EML classes are max-plus/affine stable” into a genuine universal approximation theorem on compact spaces.

Mathematically, this is the Kakutani–Stone / vector-lattice Stone–Weierstrass principle specialized to `C(X, ℝ)` and reconstructed in a form suitable for Lean. Once proved, it should serve as the main abstract approximation engine behind later concrete EML density results, tropical-network approximation statements, and robustness/optimization corollaries built from lattice closure rather than multiplication.
