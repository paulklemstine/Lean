Develop a complete, type-checking Lean 4 file formalizing a finite information-theoretic model of proof search, with no placeholders and no malformed declarations. The goal is not to prove the original asymptotic conjecture about typical proof information, but to establish rigorous finite counting and incompressibility theorems that capture the search-space bottleneck.

Work in a fully elementary finite setting. Let `a : ℕ` be an alphabet size, preferably under assumptions strong enough to avoid degenerate cases when needed (for example `0 < a`, and use `1 < a` only where a strict geometric bound truly requires it). Define `ProofStr a n := Fin n → Fin a`. Define `BoundedProof a L` as the sigma-type of all proof strings of length at most `L`; one convenient choice is `Σ n : Fin (L+1), ProofStr a n`, since `n.val ≤ L` is built in. Introduce an arbitrary statement type `S` with `[Fintype S]`, and a verifier `check : BoundedProof a L → S`. Interpret `Set.range check` as the set of statements provable within budget `L`.

Your main task is to produce a clean sequence of fully proved theorems:

1. Exact cardinality of fixed-length proof strings: `Fintype.card (ProofStr a n) = a ^ n`.
2. Exact cardinality of the bounded proof space, preferably in a form such as
   `Fintype.card (BoundedProof a L) = ∑ n : Fin (L+1), a ^ n.val`.
   If useful, also derive a Nat-interval version with `Finset.range (L+1)`.
3. A verifier-range bound: `Fintype.card (Set.range check) ≤ Fintype.card (BoundedProof a L)` via the general fact that the cardinality of a range is at most the cardinality of the domain.
4. An incompressibility / unprovability theorem: if `Fintype.card S > Fintype.card (BoundedProof a L)`, then there exists `s : S` with `s ∉ Set.range check`.
5. If practical, a corollary specialized to surjective verifiers: if every `s : S` is in `Set.range check`, then `Fintype.card S ≤ Fintype.card (BoundedProof a L)`.

Only after these core results are complete should you attempt any sharper numerical estimate. If you do, keep it explicit and finite. For example, under `1 < a`, prove a simple upper bound on the geometric sum such as `∑ n in Finset.range (L+1), a^n < a^(L+1) * C` for some easy constant, or another inequality that yields a usable lower bound on `L` from the requirement of covering all statements. Do not state or pursue `Θ(n log n)` asymptotics unless you can reduce them to already formalized finite inequalities and finish the proof completely.
