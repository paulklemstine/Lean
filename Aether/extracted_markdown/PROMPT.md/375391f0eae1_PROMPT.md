Research Brief: Structure-Preserving Berggren–Photonic Bridge

Prove that the Berggren tree action on primitive Pythagorean triples descends via the Stereographic Pythagorean Bridge to a Möbius action on the photonic frontier, and that the cross-ratio is a shared invariant of this algebraic-physical correspondence.

**Theorem Statement.** Let `PT` denote the type of primitive Pythagorean triples `(a, b, c : ℤ)` with `a² + b² = c²`, `a > 0`, `b > 0`, `gcd(a, b) = 1`. Let `spb : PT → ℙ¹ ℝ` be the stereographic Pythagorean bridge `spb(a, b, c) = [a : c − b]`. Let `𝒢` be the free monoid on `Fin 3` generated by the Berggren matrices `U, A, D` with the action `berggren_action : 𝒢 → PT → PT` defined in `BerggrenFactoring`. Then there exists a canonical monoid homomorphism `Φ : 𝒢 →* SL(2, ℤ)` such that for every word `w : 𝒢` and all primitive triples `p₁ p₂ p₃ p₄ : PT` with photonic images `z₁ z₂ z₃ z₄ : ℙ¹ ℝ` satisfying `∀ i, spb p_i = z_i`, we have:

**Proof Strategy.**

1. **Construct the monoid homomorphism Φ.** Map each Berggren generator `g ∈ Fin 3` to an explicit 2×2 integer matrix with determinant 1 derived from the Lorentz-form representation of the Berggren matrices catalogued in `BerggrenFactoring`. Verify `det = 1` for each generator using `Matrix.det_fin_two_of` together with `norm_num`. Then extend to the full free monoid using `FreeMonoid.lift`, and prove uniqueness via `FreeMonoid.hom_ext`. This embeds the Berggren tree into `SL(2, ℤ)` as a discrete subgroup.

2. **Establish SPB equivariance for generators.** Fix a generator `g` and a primitive triple `p = (a, b, c)`. Compute `berggren_action g p = (a', b', c')` using the matrix multiplication from `BerggrenFactoring`. By the Lorentz form preservation `a'² + b'² = c'²` (already proved in the catalog), rewrite the transformed slope `a'/(c' − b')`. Cancel the common scaling factor using field simplification (`field_simp` and `ring`) and apply `cross_ratio_dilation_invariant` to recognize that the projective coordinates match the linear fractional transformation defined by `Φ(g)`. This proves `spb(B·p) = Φ(B)(spb p)` for generators.

3. **Lift invariance to arbitrary words.** Proceed by induction on the free monoid structure using `FreeMonoid.recOn`. The base case (`w = 1`) is trivial because `Φ 1 = 1` and the identity Möbius transformation fixes cross-ratios. For the inductive step, use `MonoidHom.map_mul` to decompose `Φ(w·g) = Φ w * Φ g`, then apply `moebius_mul` (composition of Möbius transformations corresponds to matrix multiplication in `SL(2, ℤ)`) together with the equivariance from Step 2. Finally, invoke the general projective invariance of cross-ratio under `SL(2, ℝ)` action—realized in Mathlib via `Matrix.SpecialLinearGroup.mul_apply` followed by `cross_ratio_moebius_invariant`—to conclude that the equality holds for all `w : 𝒢`.

**Why This Matters.** This theorem establishes a canonical structure-preserving map between the discrete algebraic dynamical system generating all primitive Pythagorean triples (the Berggren tree) and the projective geometry of the photonic frontier. The cross-ratio is a foundational invariant in twistor theory and scattering amplitudes; by proving it is preserved under the full Berggren monoid action, you demonstrate that the algebra of Pythagorean triples and the physics of massless states share a common symmetry subgroup of `PSL(2, ℤ)`. This directly bridges `BerggrenFactoring` to `cross_ratio_dilation_invariant` in `PhotonicFrontier`, and provides the necessary algebraic-topological footing for the tropical Feynman integral and tropical Hecke algebra directions in the open problems list. In short, it rigorously identifies the Berggren tree as a discrete Fuchsian symmetry of the photonic frontier, upgrading a single-scale invariance to a complete group-theoretic correspondence.
