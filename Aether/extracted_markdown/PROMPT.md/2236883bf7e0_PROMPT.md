### Strategy C: Rational-function local bounds and verified computation

3. Implement a verified search algorithm producing the extremizing torus type and certified value.

**Why this is promising:** It creates the computational backbone needed for falsifiable exceptional conjectures and makes `demo.py` scientifically meaningful.

**Most promising overall:** Combine A + B first, then add C if time permits. A gives structural depth, B gives direct relevance to the catalog theorem, and C turns the theory into a research instrument.
