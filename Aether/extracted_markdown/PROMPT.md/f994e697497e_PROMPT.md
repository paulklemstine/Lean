## Precise Theorem Target

You should introduce whatever minimal definitions are necessary, but aim for a theorem of the following shape.

### Suggested definitions
Work with finite firing patterns as vectors `ι → ℝ`, with `Fintype ι`. Let:
- `X : Finset (ι → ℝ)` be the observed codewords,
- `label : (ι → ℝ) → κ` assign a stimulus identity, with `Fintype κ`,
- `classSet k : Finset (ι → ℝ) := X.filter (fun x => label x = k)`.

Define a tropical hull predicate or structure for each class:
- `InTropicalHull : Finset (ι → ℝ) → (ι → ℝ) → Prop`

and define a class margin:
- `tropicalClassMargin : Finset (ι → ℝ) → Finset (ι → ℝ) → ℝ`

measuring certified separation between two class hulls.

Then target a theorem of this form.

### Lean 4 theorem shape
```lean
theorem tropical_neural_code_capacity_from_class_hulls
    {ι κ : Type*} [Fintype ι] [DecidableEq ι] [Fintype κ] [DecidableEq κ]
    (X : Finset (ι → ℝ))
    (label : (ι → ℝ) → κ)
    (hcover : ∀ x, x ∈ X → x ∈ (X.filter fun y => label y = label x))
    (hsep : ∀ k₁ k₂, k₁ ≠ k₂ →
      0 < tropicalClassMargin
            (X.filter fun x => label x = k₁)
            (X.filter fun x => label x = k₂))
    :
    ∃ Q : Finset κ × ℝ,
      (∀ k₁ k₂, k₁ ≠ k₂ →
        0 < tropicalClassMargin
              (X.filter fun x => label x = k₁)
              (X.filter fun x => label x = k₂)) ∧
      Finite (Quot (fun x y : X => label x = label y)) ∧
      Q.2 ≤
        (Finset.univ.sup fun k =>
          (X.filter fun x => label x = k).card)
```

This exact signature may need adjustment because `Quot` over a finite subtype may be awkward; if so, replace the quotient statement with a finite cardinal bound on the image of `label` restricted to `X`, or with a theorem using `Set.Finite` / `Finite` over the induced classifier state space.

A cleaner, more Lean-realistic target is:

```lean
theorem tropical_neural_code_capacity_bound
    {ι κ : Type*} [Fintype ι] [DecidableEq ι] [Fintype κ] [DecidableEq κ]
    (X : Finset (ι → ℝ))
    (label : (ι → ℝ) → κ)
    (hsep : ∀ k₁ k₂, k₁ ≠ k₂ →
      0 < tropicalClassMargin
            (X.filter fun x => label x = k₁)
            (X.filter fun x => label x = k₂))
    :
    Fintype.card {k // ∃ x ∈ X, label x = k} ≤ X.card
```

and then strengthen it by showing the witness classes are exactly those with nonempty tropical hulls.

But the genuinely visionary theorem is the following conceptual statement:

### Breakthrough theorem
```lean
theorem tropical_hull_determines_classification_capacity
    {ι κ : Type*} [Fintype ι] [DecidableEq ι] [Fintype κ] [DecidableEq κ]
    (X : Finset (ι → ℝ))
    (label : (ι → ℝ) → κ)
    (hmargin : ∀ k₁ k₂, k₁ ≠ k₂ →
      0 < tropicalClassMargin
            (X.filter fun x => label x = k₁)
            (X.filter fun x => label x = k₂))
    :
    ∃ capacity : ℕ,
      capacity = Fintype.card {k // ∃ x ∈ X, label x = k} ∧
      capacity ≤ X.card ∧
      ∀ k, (∃ x ∈ X, label x = k) →
        Nonempty (TropicalHull (X.filter fun x => label x = k))
```

Here `TropicalHull` can be a structure you define, or a predicate packaged as a subtype. The point is to formally connect:
- positive pairwise hull margins,
- realizable class representatives,
- finite capacity.

## Proof Strategy A: Pairwise-to-Global Finite Capacity
This is likely the most Lean-feasible path.

1. **Define class hulls and pairwise margins.**
   For each `k : κ`, form the class code `X_k := X.filter (fun x => label x = k)`.
   Use existing margin theorems to show that if `k₁ ≠ k₂` then positive tropical margin between `X_k₁` and `X_k₂` certifies distinct classification behavior.

2. **Package distinct realizable classes into a finite subtype.**
   Consider `{k // ∃ x ∈ X, label x = k}`. This is canonically finite.
   Prove its cardinal is bounded by `X.card` by sending each realizable class to a witness codeword.

3. **Interpret this cardinal as classification capacity.**
   Show that pairwise positive margins imply classes are genuinely distinguishable under the certified classifier, hence the number of realizable classes is a lower/upper bound for a natural notion of capacity.

Why promising: it minimizes new infrastructure, uses `Finset.filter`, finite subtypes, and cardinal inequalities that Lean handles well.

## Proof Strategy B: Coboundary-to-Margin-to-Capacity
This is more original and mathematically deeper.

1. **Extract combinatorial separation from receptive field incidence.**
   Define a neural code coboundary/incompatibility invariant between classes based on disagreement of receptive field support patterns.

2. **Apply `tropical_margin_lower_bound_of_coboundary`.**
   This gives a certified positive lower bound on tropical class margin from the combinatorial invariant.

3. **Push positive margin into multiclass classification and finite quotient.**
   Use the multiclass certification theorem and then `finite_neural_quotient_implies_finite_classification_quotient`.

Why promising: this makes the theorem truly about neural coding, not just finite labels. It says combinatorial neural structure enforces geometric separation.

## Proof Strategy C: Quotient-Theoretic Tropical Classifier
This is the most conceptually ambitious path.

1. **Define an equivalence relation on codewords**
   where `x ~ y` iff they lie in the same certified tropical decision region / same class hull sector.

2. **Show tropical margins force distinct labels to lie in distinct equivalence classes.**
   Thus the quotient refines label classes.

3. **Use finiteness of the neural quotient to conclude finite classification capacity.**
   Then prove the quotient cardinal is controlled by class hull geometry.

Why promising: this could become the foundation for a whole program on tropical decision complexes.  
Why risky: quotient constructions can be cumbersome in Lean unless carefully staged.
