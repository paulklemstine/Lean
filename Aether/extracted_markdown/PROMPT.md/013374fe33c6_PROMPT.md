# Forbidden Minor Characterization of Hard Formulas: Resolution Complexity Meets Robertson-Seymour Theory

## The Vision

Proof complexity and structural graph theory have developed in parallel for decades, but a deep connection remains unexplored: the configuration graphs of hard formulas carry specific minor obstructions, just as graphs of large treewidth carry grid minors (Robertson-Seymour). This would mean that computational hardness—specifically, large clause space in resolution—has a purely combinatorial certificate: a forbidden minor. This bridges proof complexity, graph minor theory, and information theory, opening an entirely new field: **structural proof theory via minors**.

### Definitions (Novel Structures)

```lean
/-- A literal over n boolean variables -/
inductive Literal (n : ℕ) where
  | pos : Fin n → Literal n
  | neg : Fin n → Literal n
  deriving DecidableEq

/-- A clause is a finite set of literals -/
def Clause (n : ℕ) := Finset (Literal n)

/-- A CNF formula is a finite set of clauses -/
def CNFFormula (n : ℕ) := Finset (Clause n)

/-- A configuration at space bound s: a set of ≤ s clauses -/
structure Config (n s : ℕ) where
  clauses : Finset (Clause n)
  hsize : clauses.card ≤ s
  deriving DecidableEq

/-- Resolution step: add axiom, resolve two clauses, or remove a clause -/
inductive ResStep (F : CNFFormula n) (s : ℕ) : Config n s → Config n s → Prop where
  | axiom (C ∈ F) (cfg : Config n s) (h : cfg.clauses.card < s) :
      ResStep F s cfg ⟨cfg.clauses ∪ {C}, by omega⟩
  | resolve (C₁ C₂ : Clause n) (l : Literal n) (cfg : Config n s)
      (h₁ : C₁ ∈ cfg.clauses) (h₂ : C₂ ∈ cfg.clauses)
      (hres : resolveOn l C₁ C₂ ≠ none) :
      ResStep F s cfg ⟨(cfg.clauses \ {C₁, C₂}) ∪ {(resolveOn l C₁ C₂).get hres}, ...⟩
  | erase (C : Clause n) (cfg : Config n s) (h : C ∈ cfg.clauses) :
      ResStep F s cfg ⟨cfg.clauses \ {C}, by omega⟩

/-- The configuration graph: vertices are configurations, edges are resolution steps -/
def bConfGraph (F : CNFFormula n) (s : ℕ) : SimpleGraph (Config n s) :=
  SimpleGraph.fromRel (ResStep F s)

/-- Clause space: minimum s such that empty clause is reachable from empty config -/
def clauseSpace (F : CNFFormula n) : ℕ :=
  sInf {s | ∃ cfg, Reachable (bConfGraph F s) (emptyConfig F s) cfg ∧ emptyClause ∈ cfg.clauses}

/-- Path minor of width w: a minor of G that is a path P₁-...-Pₘ
    where each supernode contracts from ≥ w vertices of G -/
structure PathMinorOfWidth {α : Type*} [DecidableEq α] (G : SimpleGraph α) (w : ℕ) where
  length : ℕ
  supernodes : Fin length → Finset α
  h_disjoint : Pairwise (Disjoint on supernodes)
  h_cover : ∀ v, v ∈ ⋃ i, supernodes i
  h_connected : ∀ i, IsConnected (G.induce (supernodes i))
  h_adjacent : ∀ i < length - 1, ∃ u ∈ supernodes i, ∃ v ∈ supernodes (i+1), G.Adj u v
  h_width : ∀ i, (supernodes i).card ≥ w
```

### Theorem 1: Minor Lower Bound on Clause Space

*If the configuration graph contains a path minor of width w, then the formula requires clause space at least w.*

```lean
theorem minor_lower_bound_clause_space
    (F : CNFFormula n) (s w : ℕ) (hunsat : IsUnsat F)
    (hminor : PathMinorOfWidth (bConfGraph F s) w)
    : clauseSpace F ≥ w := by
  sorry
```

**Proof Strategy A (Bottleneck Argument — Most Promising):**
1. Each supernode in the path minor contracts from ≥ w configurations. By the minor structure, any resolution refutation must pass through every supernode.
2. At each supernode boundary, the proof must "carry" at least w distinct clauses: the path minor ensures no configuration in supernode Pᵢ can be reached from the initial configuration without maintaining all w clause-sets present in earlier supernodes.
3. By induction on the path minor length, show that the clause space lower bound is exactly the width w. This mirrors Ben-Sasson–Wigderson's width lower bound but lifts it to the minor structure.
4. The key lemma: `pathMinorForcesBottleneck`: if G has a path minor of width w from u to v, then any path from u to v must pass through ≥ w intermediate vertices, each contributing an essential clause.

**Proof Strategy B (Width-Minor Duality):**
1. First establish `width_minor_duality`: if `resolutionWidth F ≥ w`, then `bConfGraph F (2*w)` has a path minor of width ≥ w/2.
2. Then invoke the known result `clauseSpace_ge_resolutionWidth_div_2` (which can be built from catalog theorem `formula_for_recMaj_uses_all_vars` by extending it to general CNF formulas).
3. Compose: `clauseSpace F ≥ resolutionWidth F / 2 ≥ w / 2`. This factorizes the problem but requires the intermediate duality theorem.

**Proof Strategy:**
1. Define `phpFormula n` encoding n+1 pigeons into n holes.
2. Use the known fact that `clauseSpace (phpFormula n) ≥ n` (building on `formula_for_recMaj_uses_all_vars` which establishes variable-usage lower bounds).
3. Construct the path minor explicitly: each supernode Pᵢ corresponds to the set of configurations where pigeon i has been assigned. The path structure follows the pigeon ordering.
4. Show each supernode has ≥ √n configurations by a counting argument: there are ≥ √n distinct partial assignments for each pigeon, and the minor structure preserves all of them.
5. The adjacency between consecutive supernodes follows from the resolution derivation structure: resolving on pigeon i's variables creates edges between supernodes Pᵢ and Pᵢ₊₁.

### Theorem 3: Resolution Data Processing Inequality (Cross-Domain: Information Theory ↔ Proof Complexity)

*Resolution mutual information satisfies the data processing inequality along any path in the configuration graph, importing Shannon's DPI into proof complexity.*

```lean
/-- Resolution entropy of a configuration -/
def resEntropy (cfg : Config n s) : ℝ := Real.log cfg.clauses.card

/-- Resolution mutual information between two configurations -/
def resMutualInfo (C₁ C₂ : Config n s) : ℝ :=
  resEntropy ⟨C₁.clauses ∪ C₂.clauses, ...⟩
    - resEntropy C₁ - resEntropy C₂
    + resEntropy ⟨C₁.clauses ∩ C₂.clauses, ...⟩

theorem resolution_data_processing_inequality
    (F : CNFFormula n) (s : ℕ)
    (C₁ C₂ C₃ : Config n s)
    (h₁₂ : Adj (bConfGraph F s) C₁ C₂)
    (h₂₃ : Adj (bConfGraph F s) C₂ C₃)
    : resMutualInfo C₁ C₃ ≤ resMutualInfo C₁ C₂ := by
  sorry
```

**Proof Strategy (Information Bottleneck):**
1. Case-analyze on `ResStep`: axiom introduction, resolution, or erasure.
2. For axiom introduction: `C₂ = C₁ ∪ {C}` for some axiom clause C. Show `I(C₁; C₃) ≤ I(C₁; C₂)` because adding a clause can only increase mutual information with C₁ (subadditivity of entropy).
3. For erasure: `C₂ = C₁ \ {C}`. Show that removing a clause is a "lossy channel" — information about C₁ that was carried by C is lost, so `I(C₁; C₃) ≤ I(C₁; C₂)`.
4. For resolution: `C₂` results from resolving two clauses in `C₁`. This is the critical step: resolution is a "deterministic channel" (the output is determined by the inputs), so by the classical DPI argument, `I(C₁; C₃) ≤ I(C₁; C₂)`.
5. The key lemma: `resolution_step_is_channel`: every resolution step defines a Markov chain C₁ → C₂ → C₃, and the DPI for Markov chains applies.

## Cross-Domain Connections

1. **Robertson-Seymour → Proof Complexity**: The Grid Minor Theorem (large treewidth forces grid minors) finds its proof-theoretic analogue: large clause space forces path minors in configuration graphs. This is the first application of RS theory to proof complexity, creating a "structural proof theory" parallel to structural graph theory.

2. **Information Theory → Proof Complexity**: The Resolution DPI (Theorem 3) shows that proof complexity has its own information theory. Clause space is information capacity; resolution steps are channels; path minors are information bottlenecks. This creates "resolution information theory" — a measure-theoretic foundation for proof complexity where the DPI governs information flow through proofs.

3. **Parameterized Complexity → Minor Hierarchy**: If hard formulas have minor obstructions, then the W-hierarchy maps to the minor hierarchy of configuration graphs. W[1]-hardness would correspond to containing a specific minor family, creating a "minor-based parameterized proof complexity."

4. **Tropical Geometry → Configuration Spaces**: Configuration graphs live in tropical space: each configuration is a point in the min-plus semiring of clause-sets, and derivation steps are tropical line segments. Clause space is tropical dimension. This connects to tropical hypersurface arrangements and their vanishing ideals.

## Falsifiable Conjecture

**Conjecture (Minor-Space Correspondence)**: There exist absolute constants c, d such that for all unsatisfiable CNF formulas F:

`(1/d) · clauseSpace(F) ≤ maxPathMinorWidth(bConfGraph(F, clauseSpace(F))) ≤ c · clauseSpace(F)`

**Computational Test**: For all non-isomorphic unsatisfiable CNF formulas over n = 3, 4, 5 variables:
1. Compute `clauseSpace(F)` by exhaustive resolution refutation search.
2. Compute `maxPathMinorWidth(bConfGraph(F, clauseSpace(F)))` by minor detection.
3. Plot `clauseSpace` vs. `maxPathMinorWidth` and fit the linear relationship.
4. If the ratio `maxPathMinorWidth / clauseSpace` grows with n, the conjecture fails.

**Disproof condition**: Find a family Fₙ where `clauseSpace(Fₙ) = Ω(n)` but `maxPathMinorWidth(bConfGraph(Fₙ, n)) = o(n)`, or vice versa.
