## Research Task: Tropical certified robustness for attention-style max-affine gating networks via pathwise logit-gap margins

### Research Mode: PROVE

Develop a Lean 4 formalization of attention-style tropical gating blocks as finitely many affine experts together with a finite-valued selector, and prove robustness certificates extending the existing tropical ReLU / DAG / residual theory from static compositions to dynamically routed piecewise-affine networks.

The central target is a theorem of the following form: if a multiclass piecewise-affine network `f : ℝ^d → ℝ^C` has global `L∞` Lipschitz constant `K`, and at an input `x` the predicted class `c` has pairwise logit-gap margin
`m = inf_{j ≠ c} (f x c - f x j) > 0`,
then every perturbation `δ` with `‖δ‖∞ < m / (2*K)` preserves the argmax class. The nontrivial part is to prove that this remains valid when intermediate blocks are attention-style gated expert modules whose routing depends on the input but is finite-valued cellwise.

---

### 1. Formal model of gated affine blocks

Use a finite expert index type and finite selector type. A clean concrete starting point is:

```lean
import Mathlib.Data.Matrix.Basic
import Mathlib.Data.Real.Basic
import Mathlib.Analysis.NormedSpace.PiLp
import Mathlib.LinearAlgebra.Matrix.ToLinearEquiv
import Mathlib.LinearAlgebra.AffineSpace.AffineMap
import Mathlib.Data.Finset.Basic

open scoped BigOperators
open Matrix

def AffineMapVec (d o : ℕ) := Matrix (Fin o) (Fin d) ℝ × (Fin o → ℝ)

def evalAffine {d o : ℕ} (E : AffineMapVec d o) (x : Fin d → ℝ) : Fin o → ℝ :=
  fun i => ∑ j, E.1 i j * x j + E.2 i
```

Model a gated block by a finite family of affine maps indexed by `ι` and a selector map into a finite set `σ` of sparse convex coefficients:

```lean
def SelectorVec (ι : Type) [Fintype ι] := ι → ℝ

def selectorOutput {d o : ℕ} {ι σ : Type} [Fintype ι]
    (experts : ι → AffineMapVec d o) (sel : σ → SelectorVec ι) (s : σ) (x : Fin d → ℝ) :
    Fin o → ℝ :=
  fun k => ∑ i, (sel s i) * evalAffine (experts i) x k
```

Then the actual gating block is determined by a finite-valued routing function:

```lean
def GatedBlock (d o : ℕ) (ι σ : Type) [Fintype ι] [Fintype σ] where
  experts : ι → AffineMapVec d o
  selector : σ → SelectorVec ι
  route : (Fin d → ℝ) → σ

def GatedBlock.eval {d o : ℕ} {ι σ : Type} [Fintype ι] [Fintype σ]
    (B : GatedBlock d o ι σ) (x : Fin d → ℝ) : Fin o → ℝ :=
  selectorOutput B.experts B.selector (B.route x) x
```

You should also define the affine map attached to a fixed selector:

```lean
def combinedAffine {d o : ℕ} {ι σ : Type} [Fintype ι]
    (experts : ι → AffineMapVec d o) (sel : σ → SelectorVec ι) (s : σ) :
    AffineMapVec d o := ...
```

and prove:

```lean
theorem eval_combinedAffine {d o : ℕ} {ι σ : Type} [Fintype ι]
    (experts : ι → AffineMapVec d o) (sel : σ → SelectorVec ι) (s : σ) (x : Fin d → ℝ) :
    evalAffine (combinedAffine experts sel s) x = selectorOutput experts sel s x := ...
```

This is the structural lemma that lets you reduce each gated block, on a fixed routing cell, to a single affine map.

### 2. Cellwise affine theorem

Do not attempt a full polyhedral-complex formalization at first. Instead, isolate the finite-valued routing mechanism and prove a precise cellwise-affine theorem on fibers of the route map.

A minimal exact statement is:

```lean

    ∀ x, B.route x = s → B.eval x = evalAffine (combinedAffine B.experts B.selector s) x := ...
```

Then for a network given by a finite composition of such blocks, define recursively:

```lean
def BlockSeq : ℕ → ℕ → Type := ...

```

and prove a compositional cellwise theorem: once a route value is fixed for each layer, the whole network equals a single affine map on the common route fiber. A useful type signature is:

```lean
theorem network_eq_affine_on_route_pattern
    {d C L : ℕ}
    (net : ...) (pattern : Fin L → Σ n, Fin n) :
```

If dependent route types become cumbersome, specialize to a homogeneous architecture where each layer has a fixed finite selector type `σ`.

This theorem matters because it gives the exact tropical-support-function replacement for dynamic routing: although the gate depends on the input, once the route pattern is fixed the network is still affine, so all margin and Lipschitz arguments reduce to affine inequalities on cells.

### 3. Global `L∞` Lipschitz bound for gated blocks

Define the row-sum operator norm corresponding to `‖·‖∞ → ‖·‖∞`:

```lean
def linfMatrixNorm {d o : ℕ} (A : Matrix (Fin o) (Fin d) ℝ) : ℝ :=
  Finset.univ.sup (fun i : Fin o => ∑ j, |A i j|)
```

First prove the standard affine difference estimate:

```lean
theorem evalAffine_lipschitz
    {d o : ℕ} (E : AffineMapVec d o) (x y : Fin d → ℝ) :
    ‖evalAffine E x - evalAffine E y‖∞ ≤ linfMatrixNorm E.1 * ‖x - y‖∞ := ...
```

You may need to instantiate the `L∞` norm on finite functions as `‖·‖ = iSup ...`; if the exact `‖·‖∞` notation is awkward in Lean, formulate coordinatewise first:

```lean
theorem evalAffine_coord_bound
    {d o : ℕ} (E : AffineMapVec d o) (x y : Fin d → ℝ) (i : Fin o) :
    |evalAffine E x i - evalAffine E y i| ≤ linfMatrixNorm E.1 * ‖x - y‖ := ...
```

Then derive the norm bound.

For gated blocks, assume the selector coefficients are nonnegative and sum to `1`:

```lean
def IsConvexSelector {ι σ : Type} [Fintype ι] (sel : σ → SelectorVec ι) : Prop :=
  ∀ s, (∀ i, 0 ≤ sel s i) ∧ (∑ i, sel s i = 1)
```

Prove the key bound:

```lean
theorem combinedAffine_linfMatrixNorm_le
    {d o : ℕ} {ι σ : Type} [Fintype ι]
    (experts : ι → AffineMapVec d o) (sel : σ → SelectorVec ι)
    (hsel : IsConvexSelector sel) (s : σ) :
    linfMatrixNorm (combinedAffine experts sel s).1 ≤
      Finset.univ.sup (fun i : ι => linfMatrixNorm (experts i).1) := ...
```

The proof should use:
1. Expand the combined matrix rowwise as a convex combination of expert rows.
2. Apply `|∑ a_i| ≤ ∑ |a_i|`.
3. Use nonnegativity of selector weights.
4. Bound each expert row-sum by the supremum over experts.
5. Sum the selector weights to `1`.

Then deduce:

```lean
theorem GatedBlock_lipschitz_of_convex_selector
    {d o : ℕ} {ι σ : Type} [Fintype ι] [Fintype σ]
    (B : GatedBlock d o ι σ) (hsel : IsConvexSelector B.selector) :
    ∀ x y,
      B.route x = B.route y →
      ‖B.eval x - B.eval y‖∞ ≤
        (Finset.univ.sup (fun i : ι => linfMatrixNorm (B.experts i).1)) * ‖x - y‖∞ := ...
```

This is the clean same-cell estimate.

For a genuinely global theorem, either:
- assume route fibers cover the segment in a way allowing piecewise chaining, or
- define a network semantics already known to be globally `K`-Lipschitz and prove that each gated block contributes at most the supremum expert norm.

A practical compositional theorem is:

```lean
theorem gated_network_lipschitz
    {dims : ℕ → ℕ} {L : ℕ}
    (net : ...)
    (Ks : Fin L → ℝ)
    (hK : ∀ l, blockLipschitzConst (net.blocks l) ≤ Ks l) :
    ∀ x y, ‖net.eval x - net.eval y‖∞ ≤ (∏ l, Ks l) * ‖x - y‖∞ := ...
```

If full products over dependent dimensions are awkward, prove first for two blocks:
`K(g ∘ f) ≤ K(g) * K(f)`,
then iterate by induction on layers.

### 4. Margin-to-robustness theorem for multiclass outputs

Represent classifier outputs as `Fin C → ℝ` with predicted class `c`. Define the pairwise margin:

```lean
def logitGap {C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ) (x : Fin d → ℝ) (c j : Fin C) : ℝ :=
  f x c - f x j

def classMargin {C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ) (x : Fin d → ℝ) (c : Fin C) : ℝ :=
  Finset.inf' (Finset.univ.erase c) (by ...) (fun j => logitGap f x c j)
```

It may be technically easier to avoid `inf'` at first and assume the stronger hypothesis:

```lean
(hmargin : ∀ j, j ≠ c → m ≤ f x c - f x j)
```

Then prove the robust argmax theorem:

```lean
theorem robust_of_pairwise_margin_lipschitz
    {d C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ)
    (K : ℝ) (hK : ∀ x y, ‖f x - f y‖∞ ≤ K * ‖x - y‖∞)
    (x : Fin d → ℝ) (c : Fin C) (m : ℝ)
    (hm : 0 < m)
    (hmargin : ∀ j, j ≠ c → m ≤ f x c - f x j) :
    ∀ δ : Fin d → ℝ, ‖δ‖∞ < m / (2 * K) →
      ∀ j, j ≠ c → f (x + δ) j < f (x + δ) c := ...
```

A sharper and often easier equivalent version is to work directly with pairwise difference maps
`g_j(z) = f z c - f z j`. Since each coordinate of `f` is `K`-Lipschitz in `L∞`, each gap is `2K`-Lipschitz:

```lean
theorem gap_lipschitz
    {d C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ)
    (K : ℝ)
    (hK : ∀ x y, ‖f x - f y‖∞ ≤ K * ‖x - y‖∞)
    (c j : Fin C) :
    ∀ x y, |(f x c - f x j) - (f y c - f y j)| ≤ 2 * K * ‖x - y‖∞ := ...
```

Then the robustness theorem becomes a one-line consequence:
if `f x c - f x j ≥ m` and `2*K*‖δ‖∞ < m`, then
`f (x+δ) c - f (x+δ) j > 0`.

A final classification-preservation statement:

```lean
theorem argmax_stable_of_margin
    {d C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ)
    (K : ℝ)
    (hK : ∀ x y, ‖f x - f y‖∞ ≤ K * ‖x - y‖∞)
    (x : Fin d → ℝ) (c : Fin C) (m : ℝ)
    (hm : 0 < m)
    (hmargin : ∀ j, j ≠ c → m ≤ f x c - f x j) :
    ∀ δ, ‖δ‖∞ < m / (2 * K) →
      IsGreatest {i | True} c := ...
```

But if formalizing `argmax` is too cumbersome, stop at the pairwise strict inequalities
`f(x+δ)_j < f(x+δ)_c` for all `j ≠ c`, which is the mathematically essential content.

### 5. Stronger local same-cell theorem

Prove a stronger local certificate under the hypothesis that the perturbation does not change the route pattern. This theorem should improve the conceptual bridge with tropical cells.

A good exact statement is:

```lean
theorem same_route_local_robustness
    {d C : ℕ} {ι σ : Type} [Fintype ι] [Fintype σ]
    (net : GatedBlock d C ι σ)
    (hsel : IsConvexSelector net.selector)
    (x δ : Fin d → ℝ) (c : Fin C) (m : ℝ)
    (hr : net.route (x + δ) = net.route x)
    (hm : 0 < m)
    (hmargin : ∀ j, j ≠ c → m ≤ net.eval x c - net.eval x j)
    (hδ : ‖δ‖∞ <
      m / (2 * Finset.univ.sup (fun i : ι => linfMatrixNorm (net.experts i).1))) :
    ∀ j, j ≠ c → net.eval (x + δ) j < net.eval (x + δ) c := ...
```

Here the proof should explicitly rewrite both `net.eval x` and `net.eval (x+δ)` using the same `combinedAffine`, then apply the affine Lipschitz estimate to the gap map. This is the precise local theorem showing that the refined tropical cell decomposition really carries the robustness certificate.

### 6. Proof strategy: concrete steps

1. **Collapse a fixed selector to one affine map.**  
   Define `combinedAffine` by summing expert matrices and biases against selector coefficients. Prove `eval_combinedAffine` by extensionality on output coordinates and rearranging finite sums with `Finset.sum_add_distrib`, `Finset.mul_sum`, and `ring`.

2. **Bound the operator norm of the combined affine map.**  
   Work rowwise. For each output coordinate `k`,
   show
   `∑ j |∑ i sel s i * A_i k j| ≤ ∑ i sel s i * (∑ j |A_i k j|)`.
   Use triangle inequality for finite sums, then convexity of the selector and the definition of `sup`. This is the key structural estimate passing from experts to the routed block.

3. **Prove Lipschitzness of affine and gated blocks.**  
   For affine maps, the bias cancels in differences. Expand coordinatewise and bound by the row-sum norm times `‖x-y‖∞`. For gated blocks on a common route fiber, rewrite both evaluations using the same `combinedAffine` and apply the affine estimate.

4. **Compose Lipschitz constants through the network.**  
   Prove a two-layer composition lemma first, then iterate by induction. If some layers are residual or concatenative from earlier developments, phrase the theorem so gated blocks can be inserted as one more constructor in the existing architecture datatype, with the same style of `K_out ≤ K₁ * K₂` or additive residual bound.

5. **Convert margin to robustness via gap functions.**  
   For each competing class `j`, define `g_j(z) = f z c - f z j`. Show `g_j` is `2K`-Lipschitz. Then
   `g_j(x+δ) ≥ g_j(x) - 2K‖δ‖∞ > m - m = 0`,
   giving strict class preservation. This is the cleanest way to avoid delicate global argmax formalization.

### 7. Why this matters

This result extends tropical certified robustness from static max-affine / residual architectures to input-dependent routing modules, which are the natural piecewise-linear analogue of attention and mixture-of-experts mechanisms. The key mathematical gain is the cellwise support-function description: dynamic routing does not destroy the tropical affine structure, it only refines the cell decomposition. Once formalized, this gives a reusable theorem schema for certified robustness of modern gated architectures and opens the door to later results on:
- sparse top-`k` selectors instead of one-hot gates,
- local certificates using route stability rather than global Lipschitz constants,
- tighter class-specific constants obtained from the active expert pattern,
- eventual extension from simple gated blocks to tropical attention layers with score-based finite routing.

A strong deliverable is a Lean file proving at least:
1. `eval_combinedAffine`,
2. `combinedAffine_linfMatrixNorm_le`,
3. `GatedBlock_lipschitz_of_convex_selector` on same-route fibers,
4. `gap_lipschitz`,
5. `robust_of_pairwise_margin_lipschitz`,
6. one composed network theorem showing the certificate passes through a sequence of gated blocks.
