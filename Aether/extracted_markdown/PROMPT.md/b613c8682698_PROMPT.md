**Mode:** `prove`

Build a new bridge between **algebraic complexity theory**, **combinatorial commutative algebra**, and **discrete geometry of supports**. The central mission is to turn the exact support–derivative correspondence from the catalog into a genuine lower-bound framework for algebraic circuits.

This is not an invitation to formalize folklore. It is a call to create a new invariant of circuit complexity — a **shadow decay profile** — and prove that it is rigid under circuit constructions but large for explicit hard polynomials.

## Core Breakthrough Target

Define a support-geometric complexity invariant for multivariate polynomials and prove nontrivial upper bounds for all polynomials produced by restricted algebraic circuits. Then exhibit explicit families whose shadow decay profile violates the qualitative behavior forced by small circuits.

The revolutionary idea is:

> **Derivative complexity is controlled exactly by support shadow geometry, so if circuit operations constrain shadow geometry, then support combinatorics becomes a route to circuit lower bounds.**

This would open a new program: **circuit lower bounds via monotone support geometry**, potentially complementary to partial derivatives, shifted partials, rank methods, and Newton polytope arguments.

## Theorem 2: Structural shadow bound for support-compressed circuit leaves

This is the first real lower-bound architecture theorem.

### Mathematical statement
For every support-compressed circuit output of formal degree `d` in `n` variables with leaf count at most `s`, the `k`-th shadow cardinality is bounded above by a linear-in-`s` combinatorial envelope:
\[
|\mathrm{Sh}_k(\mathrm{supp}(f))| \le s \binom{n+d-k}{n}.
\]

You should prove this first for the support-compressed model available in the catalog, then isolate the exact hypotheses needed for extension to richer circuit classes.

### Lean 4 target shape
A plausible theorem statement:

```lean

  {S : Finset (Fin n → ℕ)}
  (hS : SupportCompressed n d S)
  (hs : hS.leafCount ≤ s) :
  shadowProfile S k ≤ s * Nat.choose (n + d - k) n := by
  ...
```

Or, if the catalog theorem is already close:

```lean
theorem circuitShadowEnvelope_bound
  {n d k : ℕ}
  {C : SupportCompressedCircuit n d}
  (hk : k ≤ d) :
  shadowProfile C.support k ≤ circuitShadowEnvelope n d C.leafCount k := by
  ...
```

### Catalog theorem to build on
Use:
- `Pythagorean/IteratedShadowGeometry.lean`
- `Bridges/Catalog/Pythagorean/SupportCompression.lean`
- specifically `supportCompressedLeafCount_le_active_choose`

Do not merely cite it; explain and exploit its content:
- it gives a certified combinatorial upper bound on active support growth,
- you must transport that bound from “active” combinatorics to `k`-th shadows,
- then package it as a circuit complexity invariant.

### Suggested proof strategy A: Direct transport from catalog combinatorics
1. Use the support compression theorem to bound the number of active monomials/leaves contributing after `k` derivative steps.
2. Show that every element of the `k`-th shadow arises from one such active contribution.
3. Apply finite-set cardinality bounds and simplify with `Nat.choose` identities.

**Why promising:** It aligns directly with existing certified infrastructure.

### Suggested proof strategy B: Structural induction on circuit formation
1. Define a restricted circuit syntax with constructors `input`, `add`, `mul`.
2. Prove by induction that the shadow profile of each constructor obeys a subadditive envelope.
3. Use degree bookkeeping plus combinatorial bounds for Minkowski sums of supports under multiplication.

**Why promising:** More ambitious, but this is the path toward a genuine lower-bound theory for circuits rather than just compressed supports.

### Suggested proof strategy C: Hypergraph shadow interpretation
1. View support monomials of degree `≤ d` as integer points in a simplex.
2. Interpret `k`-th shadows as downward slices under coordinate subtraction.
3. Use a generalized Kruskal–Katona style argument or simplex lattice counting.

**Why promising:** This could produce sharper bounds and may reveal the true extremizers.

### Most promising route
Start with **Strategy A** to secure a certified theorem quickly. Then, if time permits, pursue **Strategy B** to create a new formal model of support circuits. Strategy C is the conceptual north star.

## Theorem 3: Cross-domain theorem — Newton polytope / simplex volume control of shadow decay

You are required to include a cross-domain connection. The strongest candidate here is between **algebraic complexity** and **discrete convex geometry**.

### Mathematical statement
If the support of a polynomial is contained in the degree-`d` simplex, then every `k`-th shadow is contained in the degree-`(d-k)` simplex, hence its cardinality is bounded by a simplex lattice-point count. This sounds elementary, but you must sharpen it into a geometric statement relating support complexity to Newton polytope contraction under derivative shadowing.

A possible theorem:
\[
\mathrm{supp}(f)\subseteq \Delta_{n,d}\quad\Longrightarrow\quad
|\mathrm{Sh}_k(\mathrm{supp}(f))|\le |\Delta_{n,d-k}\cap \mathbb{Z}_{\ge0}^n|
= \binom{n+d-k}{n}.
\]

Then connect this to the Newton polytope of `f`: iterated derivative shadows stay inside a translated/downward closure of the Newton polytope.

### Lean 4 target shape
```lean

  (hdeg : ∀ m ∈ S, m.sum (fun i a => a) ≤ d) :
  shadowProfile S k ≤ Nat.choose (n + d - k) n := by
  ...
```

And a geometric bridge theorem, perhaps:

```lean

  {n d k : ℕ} {S : Finset (Fin n → ℕ)}
  (hdeg : ∀ m ∈ S, m.sum (fun i a => a) ≤ d) :
```

### Cross-domain significance
This connects:

It suggests a future bridge to:

### Suggested proof strategy

## Ambitious Theorem 4: Explicit separation for elementary symmetric families or determinant/permanent supports

You may not yet be able to prove a genuine superpolynomial lower bound. But you can and should prove rigorous separation statements for explicit support families.

### Candidate theorem
For the support of the degree-`r` elementary symmetric polynomial in `n` variables, the `k`-th shadow has exact size
\[
|\mathrm{Sh}_k(\mathrm{supp}(e_r))| = \binom{n}{r-k}.
\]

This is exact, elegant, and nontrivial. It provides a benchmark family whose shadow decay is fully computable.

### Lean 4 target shape
```lean
theorem shadowProfile_elemSymm_exact
  {n r k : ℕ} (hk : k ≤ r) :
  shadowProfile (elemSymmSupport n r) k = Nat.choose n (r - k) := by
  ...
```

Then compare this with determinant/permanent supports, which share the same support pattern in the multilinear square-matrix encoding.

### Why it matters
This gives a computable calibration family and a rigorous testing ground for the broader conjecture. It also creates a bridge to extremal set theory: shadows of uniform set families.

### Proof strategy
1. Identify multilinear monomials of degree `r` with `r`-subsets.
2. Show that taking one shadow step corresponds to deleting one element.
3. Iterate and identify the result with all `(r-k)`-subsets.

This theorem is a beautiful cross-domain bridge between polynomial supports and classical combinatorics.
