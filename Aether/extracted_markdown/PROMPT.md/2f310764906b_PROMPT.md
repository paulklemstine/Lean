## PROOF STRATEGY BLUEPRINT

### Strategy A: direct word induction + extensionality
This is the most promising route for the foundational lemmas.

1. **Define `rightCost` by recursion on `List α`**.
   - Base case `[]`: output cost.
   - Step case `a :: w`: aggregate next-state costs via finite sum.
   - Use `[Fintype σ] [DecidableEq σ]` when sums over states are needed.

2. **Prove `rightCost_append` early**:
   ```lean
   theorem rightCost_append ...
   ```
   This is the structural engine behind prefix/suffix invariance.
   Prove by induction on the prefix word `u`.

3. **Show `TropicalNerodeRel` is exactly extensional equality of right-languages**.
   - Use `funext` to move between
     `∀ w, rightCost A w p = rightCost A w q`
     and
     `tropicalRightLanguage A p = tropicalRightLanguage A q`.

4. **Prove the separation theorem by classical logic**.
   - Unfold the definition.
   - Convert `¬ ∀ w, ...` into `∃ w, ...` using `by_contra`.
   - This is a good place to use `Classical`.

5. **Construct quotient semantics**.
   - Define the `Setoid`.
   - Show observables descend to quotient by proving well-definedness under Nerode equivalence.

### Strategy B: semiring-congruence transport
This is conceptually deeper and should be used for at least one bridge theorem.

1. View each state as determining an observable in a function semiring:
   ```lean
   σ → (List α → W)
   ```
   or simply `List α → W`.

2. Define the induced relation as kernel equality of the map:
   ```lean
   q ↦ tropicalRightLanguage A q
   ```
   Then many equivalence facts become kernel facts.

3. Use existing `SemiringCong` / elimination infrastructure where possible:
   - treat observables modulo extensional equality
   - derive compatibility of algebraic combinations
   - connect quotient semantics to elimination or collapse principles

4. This route is especially suitable for theorem names involving
   `..._induces_semiring_congruence_...`.

### Strategy C: finite witness extraction by pigeonhole / state compression
Use this for the bounded witness theorem if possible.

1. Consider residual observables after prefixes.
2. In a finite state space, repeated residual classes force eventual looping.
3. Compress long separating words to shorter ones by eliminating repeated quotient classes.
4. If the general theorem is difficult, do it under determinism or finite-image hypotheses.
5. State the exact complexity bound you can prove:
   - `w.length ≤ Fintype.card σ`
   - or `≤ Fintype.card σ ^ 2`
   - or another explicit formula

This theorem matters more for **utility** than elegance, so prioritize an actual proved bound over an ambitious unproved one.
