## Assignment: 4. Tropical Spectral Causality: Eigenpairs as Invariant Causal Directions

**Mode:** prove

Prove a genuinely new bridge theorem linking tropical spectral theory, order/causality structures on state space, and min-plus linear dynamics. The core vision is this:

> A tropical eigenvector is not merely a fixed projective direction; it is a **causal geodesic ray** for min-plus dynamics.  
> The eigenvalue controls the exact displacement budget of that ray under matrix action.

This is the right level of ambition because it reframes tropical Perron–Frobenius theory as a dynamical causality theory. If formalized cleanly, this opens a new interface between tropical linear algebra, control, discrete event systems, max-plus/min-plus semigroup theory, and even Lorentzian-style order structures in idempotent settings.

Then prove the displacement formula:

If `tropicalSupDisplacement (v) (v+t)` simplifies to `|t|`, then the abstract causal theorem should likely use `|t|` rather than `t * |d|`. So before committing to the supplied statement, **check the semantics**. There are two plausible causal laws:

1. **shift covariance law**: matrix action preserves displacement exactly along the eigen-ray;
2. **spectral growth law**: iterated action scales/accumulates displacement by the eigenvalue.

The supplied statement
```lean

```
suggests a growth law, but a single matrix application to an eigenvector usually produces an additive shift by `d`, not a multiplicative scaling by `|d|`. So the most likely correct theorem is one of the following.

## Why this is a breakthrough

Tropical eigenvectors are usually treated as static algebraic objects: fixed points up to additive scalar in projective tropical space. That is not enough. The real conceptual leap is:

- interpret an eigenvector as a **distinguished causal direction**,
- interpret the eigenvalue as **temporal drift / propagation speed**,
- show matrix dynamics preserve a preorder on the ray generated by that eigenvector.

This would create a new formal language for:
- discrete event systems,
- min-plus control,
- scheduling and network timing,
- tropical Hamilton–Jacobi dynamics,
- idempotent analogues of causal cones.

In ordinary spectral theory, eigenvectors define invariant lines.  
In tropical spectral causality, eigenvectors define **invariant futures**.

That is a new idea with real mathematical legs.

## Proof strategy architecture

### Strategy A: translation-equivariance + eigenpair unfolding
This is the most promising route.

**Step 1. Prove scalar-shift equivariance of tropical matrix multiplication.**  
Show:
```lean
tropMatVecMul A (x + t·1) = tropMatVecMul A x + t·1
```
In coordinates, min-plus multiplication is typically:
```lean
(tropMatVecMul A x) i = ⨅ j, (A i j + x j)
```
so
```lean
⨅ j, (A i j + (x j + t)) = (⨅ j, (A i j + x j)) + t
```
This is the key algebraic lemma. It is the tropical analogue of linearity along the all-ones direction.

**Step 2. Unfold the eigenpair condition.**  
From `heig`, obtain:
```lean
tropMatVecMul A v = v + d·1
```
Then combine with Step 1:
```lean
tropMatVecMul A (v + t·1) = v + (d+t)·1
```

**Step 3. Compute the displacement exactly.**  
Now both images differ by the same constant shift `t`, so any sup-displacement / one-sided displacement should collapse to a closed form, usually `t` for `t ≥ 0`. Then discharge `TropicalCausal` and `TropicalFuture`.

**Why this is best:** it reduces the theorem to a structural property of min-plus linear maps, not a case-by-case argument about causal predicates.

---

### Strategy B: nonexpansive dynamics in tropical Hilbert/projective metric
This is more conceptual and may yield stronger theorems.

**Step 1. Prove or import a nonexpansiveness lemma** for `tropMatVecMul A` with respect to your displacement functional.

**Step 2. Specialize to an eigen-ray.**  
Because `v` is an eigenvector, the image of the whole ray `v+t` is again the same ray, shifted by `d`.

**Step 3. Upgrade nonexpansiveness to exact invariance** by comparing lower and upper bounds and exploiting constant-shift structure.

**Why this matters:** if successful, you may get a general theorem:
> every tropical linear map is causal/nonexpansive, and eigenvectors identify exact geodesics of equality.
That would be much bigger than the immediate target.

---

### Strategy C: iterate-first approach via tropical semigroups
This is the bold route if you want a theorem with more long-term value.

**Step 1. Define / use tropical powers** `tropMatPowMul A k`.

**Step 2. Prove by induction**
```lean
A^k ⊗ v = v + k*d
```

**Step 3. Deduce a family of causal invariance statements** for all times `k`, turning the eigen-ray into a globally invariant temporal orbit.

**Why this is powerful:** it reframes the theorem as a semigroup law and positions the result for applications in control and asymptotic cycle-time theory.

## Mathematical refinement you should check carefully

There is a serious semantic issue in the supplied theorem statement:
```lean
(t * |d|)
```
may be mathematically incorrect for a one-step action unless your definitions encode something unusual.

In standard min-plus algebra:
- eigenvalue `d` is an additive drift under matrix action,
- ray parameter `t` is a shift along the all-ones direction,
- one application of `A` maps `v+t` to `(v+d)+t`.

So the displacement between images is typically controlled by `t`, not `t*|d|`.

Therefore:

- either **repair the theorem statement** to the causally correct form,
- or prove a stronger exact identity from which the intended inequality follows if definitions justify it.

Do not formalize a false theorem out of loyalty to the prose.  
If necessary, switch into a **counterexample-with-repair** submode:
construct a tiny `2 × 2` matrix and eigenpair showing why `t*|d|` is wrong, then formalize the corrected theorem. That would itself be mathematically valuable and would save the project from building on a broken premise.

This project becomes revolutionary only if you make the right analogies explicit in comments, theorem names, and FUTURE_DIRECTIONS.

### 1. Discrete event systems / scheduling
In max-plus/min-plus systems, eigenvalues encode asymptotic cycle time and eigenvectors encode stationary timing profiles. Your theorem says these timing profiles determine invariant causal directions. That is a new formal bridge between algebraic spectral data and temporal order.

### 2. Control theory / viability
`TropicalFuture` should be read as a viability or forward-invariance predicate. An eigenpair then gives a controlled invariant cone/ray. This suggests tropical analogues of reachable sets and monotone dynamical systems.

### 3. Lorentzian geometry / causality
The phrase “causal ray” is not metaphorical. In Lorentzian geometry, null directions determine invariant causal structure. Here, tropical eigenvectors may play the role of idempotent null/geodesic directions. This is a striking conceptual analogy worth making precise in future work.

### 4. Hamilton–Jacobi / weak KAM
Min-plus linearity appears in Lax–Oleinik semigroups and idempotent analysis. Tropical eigenfunctions often correspond to additive eigenfunctions of dynamic programming operators. Your theorem could become the finite-dimensional seed of a tropical weak-KAM causality theory.

### 5. Tropical information flow / network science
If a matrix encodes transmission delays or costs on a network, an eigen-ray describes a coherent propagation mode. Causal invariance then says the network preserves an intrinsic direction of information flow.

These are not decorative analogies. They tell you what the next theorems should be.
