## Precise theorem targets

You should define at least one new concept absent from the catalog. A strong candidate is:

```lean
/-- A finitely additive probability valued in an ordered field `K`. -/
structure NAProbability (α : Type _) (K : Type _)
    [LinearOrderedField K] where
  mass : Finset α → K
  empty_mass : mass ∅ = 0
  add_mass :
    ∀ s t : Finset α, Disjoint s t →
      mass (s ∪ t) = mass s + mass t
  total_mass : mass Finset.univ = 1
  nonneg_mass : ∀ s : Finset α, 0 ≤ mass s
```

If `Finset.univ` is inconvenient, restrict first to `[Fintype α]`.

Then define expectation:

```lean
def NAExpectation {α K : Type _} [Fintype α] [LinearOrderedField K]
    (P : NAProbability α K) (X : α → K) : K :=
  ∑ a : α, X a * P.mass ({a} : Finset α)
```

### Theorem 1: Uniform infinitesimal-like atomic probability on finite grids

For each `n ≥ 1`, let `Grid n := Fin (n+1)`. Define the singleton mass to be `1/(n+1)` and extend by finite additivity. Prove:

```lean
theorem grid_uniform_exists
    (n : ℕ) :
    ∃ P : NAProbability (Fin (n+1)) ℚ,
      ∀ i : Fin (n+1),
        P.mass ({i} : Finset (Fin (n+1))) = 1 / (n+1 : ℚ)
```

This is the seed theorem: every point has a nonzero “small” probability, and as `n → ∞` these masses asymptotically behave as infinitesimals. The theorem is elementary in statement but nontrivial in formal architecture because you must construct `mass` on arbitrary finite sets and verify finite additivity cleanly.

### Theorem 2: Exact expectation of affine observables on the grid

Let `x_n(i) = i / n` on `Fin (n+1)` viewed in `ℚ`. For affine functions `f(x)=a*x+b`, prove the discrete expectation equals the trapezoidal average with exact finite-sum formula:

```lean
theorem grid_expectation_affine
    (n : ℕ) (hn : 0 < n) (a b : ℚ) :
    let X : Fin (n+1) → ℚ := fun i => a * (i : ℚ) / n + b
    let P := gridUniformProb n
    NAExpectation P X = a / 2 + b
```

This is a genuine theorem, not a computation stunt: it exhibits a proto-continuum law and shows your non-Archimedean finite model already recovers exact classical expectation for affine observables.

### Theorem 3: Refinement invariance / coherence under grid subdivision

Define the refinement map from `Fin (n+1)` into `Fin (k*(n+1))` by block embedding or averaging over fibers. Prove that expectation of observables pulled back from the coarse grid is preserved by the refined uniform probability.

A possible Lean signature:

```lean
theorem refinement_expectation_invariant
    (n k : ℕ) (hk : 0 < k) :
    let coarse := gridUniformProb n
    let fine := gridUniformProb (k * (n+1) - 1)
    ∀ X : Fin (n+1) → ℚ,
      NAExpectation coarse X
        =
      NAExpectation fine (refineObservable k X)
```

You may adjust the indexing to a cleaner grid model if needed; the mathematical point is essential:
**probability is coherent under refinement.**

This is the theorem that begins to justify a continuum interpretation.

### Theorem 4: Standard-part shadow for bounded observables on refining grids

If a full standard-part operator is too ambitious in Lean for now, prove a surrogate convergence theorem over `ℚ`/`ℝ`:

```lean
theorem grid_average_converges_interval_integral_affine
    (a b : ℚ) :
    Tendsto
      (fun n : ℕ => NAExpectation (gridUniformProb (n+1))
        (fun i => a * ((i : ℚ) / (n+1)) + b))
      atTop
      (𝓝 (a / 2 + b))
```

Or stronger for polynomials of degree ≤ 2 if manageable. This theorem is the “shadow principle”: infinitesimal atomic probabilities approximate classical continuum probability.

### Theorem 5: Impossibility boundary (counterweight theorem)

To avoid overclaiming, prove a rigorous obstruction theorem: there is no countably additive classical real-valued probability on a finite or countable partition of equal positive singleton mass summing to `1`. This clarifies why the surreal/finitely additive route is genuinely new.

For example:

```lean
theorem no_countably_additive_equal_positive_atoms_on_nat
    ¬ ∃ μ : Set ℕ → ℝ,
        (μ ∅ = 0) ∧
        (∀ A B, Disjoint A B → μ (A ∪ B) = μ A + μ B) ∧
        (∀ n, 0 < μ {n}) ∧
        μ Set.univ = 1
```

If countable additivity is too heavy in the available library, prove a finite partial-sum contradiction formulation.

This theorem is cross-domain important: it marks the exact frontier where non-Archimedean/finitely additive probability departs from Kolmogorov.

## Proof strategy architecture

### Strategy A: Finset-additive construction from cardinality
Most promising for the first three theorems.

1. Define `mass s := (s.card : K) / Fintype.card α`.
2. Prove finite additivity using `Finset.card_union_eq` under `Disjoint`.
3. Derive singleton mass and expectation formulas via `Finset.sum` and known formulas for `∑ i`.

Why this is promising:
- Lean’s `Finset` API is robust.
- It yields deep proofs with `rcases`, `calc`, `field_simp`, cardinality lemmas, and sum identities.
- It creates reusable infrastructure for later non-Archimedean extensions.

### Strategy B: Pushforward/coherence under refinement
Best for the refinement theorem.

1. Define a map `π : Fine → Coarse`.
2. Show each fiber has constant cardinality.
3. Rewrite fine expectation as a double sum over fibers; collapse using equal fiber sizes.

Key tactics:
- `classical`
- `rw [Finset.sum_sigma' ...]` or equivalent fiber decomposition
- `field_simp`
- `ring` / `linarith` only at the final arithmetic stage, not as the entire proof.

Why it matters:
This is the formal analogue of measure-preserving factor maps and is the first step toward Loeb-style constructions.

### Strategy C: Obstruction theorem via partial sums and Archimedean contradiction
Best for the impossibility theorem.

1. Assume every singleton has the same positive mass `ε`.
2. Show finite sets of size `N` have mass `N*ε`.
3. Choose `N > 1/ε` by Archimedean property.
4. Contradict total mass `≤ 1`.

This introduces a profound conceptual divide:
classical Archimedean probability forbids equal positive mass on infinitely many atoms; non-Archimedean probability escapes via infinitesimals or by abandoning countable additivity.
