### New Definition 1: Rayleigh Quotient for Self-Adjoint Operators

Define the Rayleigh quotient of a bounded operator \(T\) on a Hilbert space:

\[
R_T(x) = \frac{\langle T x, x \rangle}{\langle x, x \rangle}
\quad \text{for } x \neq 0.
\]

In Lean, one natural form is to avoid division by zero by restricting to nonzero vectors.

**Lean 4 type signature sketch**
```lean
def rayleighQuotient
  {𝕜 E : Type*} [IsROrC 𝕜]
  [NormedAddCommGroup E] [InnerProductSpace 𝕜 E]
  (T : E →L[𝕜] E) (x : E) : 𝕜 :=
  ⟪T x, x⟫ / ⟪x, x⟫
```

For self-adjoint operators over `𝕜 = ℂ`, prove that the quotient is real-valued in the sense that it equals its own conjugate when `x ≠ 0`, or package it as an `ℝ`-valued definition:

```lean
def selfAdjointRayleigh
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  (T : E →L[ℂ] E) (hT : IsSelfAdjoint T) (x : E) : ℝ := ...
```

### Theorem 1: Reality of Expectation / Rayleigh Quotient

For a self-adjoint bounded operator \(T\), the expectation value \(\langle T x, x\rangle\) is real.

**Precise statement**
\[
\forall x,\ \overline{\langle T x, x\rangle} = \langle T x, x\rangle.
\]

Equivalent formulation:
\[
\exists r \in \mathbb R,\ \langle T x, x\rangle = r.
\]

**Lean 4 type signature sketch**
```lean
theorem inner_selfAdjoint_apply_real
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  (T : E →L[ℂ] E) (hT : IsSelfAdjoint T) (x : E) :
  conj ⟪T x, x⟫ = ⟪T x, x⟫
```

or

```lean
theorem rayleighQuotient_mem_reals
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  (T : E →L[ℂ] E) (hT : IsSelfAdjoint T) {x : E} (hx : x ≠ 0) :
  ∃ r : ℝ, rayleighQuotient T x = (r : ℂ)
```

**Why this matters:** this is the formal gateway from abstract operators to physical observables.

### New Definition 2: Spectral Bounds / Variational Envelope

Define a new structure capturing lower and upper spectral bounds through quadratic forms:

```lean
structure SpectralInterval
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  (T : E →L[ℂ] E) : Type* where
  lower upper : ℝ
  lower_le_expectation :
    ∀ x : E, x ≠ 0 →
      lower ≤ selfAdjointRayleigh T ?hT x
  expectation_le_upper :
    ∀ x : E, x ≠ 0 →
      selfAdjointRayleigh T ?hT x ≤ upper
```

If dependent packaging around `hT` is awkward, parameterize the structure by both `T` and `hT`.

This is not just bureaucracy: it creates a reusable abstraction for later numerical spectral enclosures and quantum energy bounds.

### Theorem 2: Order Preservation of Polynomial Functional Calculus

Construct at least a **polynomial functional calculus** for self-adjoint operators:
\[
p \mapsto p(T),
\]
for real polynomials \(p\), and prove an order property on commuting/self-adjoint contexts or at minimum the spectral mapping identity for eigenvectors.

A realistically formalizable core theorem is:

If \(T v = \lambda v\), then
\[
p(T)v = p(\lambda) v.
\]

**Lean 4 type signature sketch**
```lean
def polynomialFunctionalCalculus
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  (T : E →L[ℂ] E) :
  Polynomial ℂ →ₐ[ℂ] (E →L[ℂ] E) := ...

theorem polynomial_apply_eigenvector
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  (T : E →L[ℂ] E) (p : Polynomial ℂ) {v : E} {μ : ℂ}
  (hv : v ≠ 0) (hTv : T v = μ • v) :
  polynomialFunctionalCalculus T p v = (p.eval μ) • v
```

Then specialize to self-adjoint \(T\) and real \(\mu\), giving a **spectral mapping theorem for point spectrum**:

```lean
theorem eigenvalue_spectral_mapping_polynomial
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  (T : E →L[ℂ] E) (hT : IsSelfAdjoint T)
  (p : Polynomial ℂ) {μ : ℂ}
  (hμ : μ ∈ pointSpectrum T) :
  p.eval μ ∈ pointSpectrum (polynomialFunctionalCalculus T p)
```

**Why this matters:** this is the first nontrivial spectral mapping mechanism and the seed of continuous/Borel functional calculus.

### Theorem 3: Min-Max / Rayleigh Extremal Principle in Finite Dimension

In finite-dimensional Hilbert space, prove that a self-adjoint operator attains maximal and minimal Rayleigh quotient values on the unit sphere, and these are eigenvalues.

A clean theorem:

\[
\exists v,\ \|v\|=1 \land T v = \lambda_{\max} v \land
\forall x,\ \|x\|=1 \to \langle T x,x\rangle_{\mathbb R} \le \lambda_{\max}.
\]

Likewise for \(\lambda_{\min}\).

**Lean 4 type signature sketch**
```lean
theorem exists_eigenvector_maximizing_rayleigh
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  [FiniteDimensional ℂ E]
  (T : E →L[ℂ] E) (hT : IsSelfAdjoint T) :
  ∃ (λ : ℝ) (v : E),
    ‖v‖ = 1 ∧
    T v = (λ : ℂ) • v ∧
    ∀ x : E, ‖x‖ = 1 →
      selfAdjointRayleigh T hT x ≤ λ
```

A stronger second theorem in the same direction:

```lean
theorem exists_eigenvector_minimizing_rayleigh
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  [FiniteDimensional ℂ E]
  (T : E →L[ℂ] E) (hT : IsSelfAdjoint T) :
  ∃ (λ : ℝ) (v : E),
    ‖v‖ = 1 ∧
    T v = (λ : ℂ) • v ∧
    ∀ x : E, ‖x‖ = 1 →
      λ ≤ selfAdjointRayleigh T hT x
```

If full Courant–Fischer is too heavy, this extremal version is already deep and nontrivial.

### Theorem 4: Quantum Observable Positivity Criterion

For self-adjoint \(T\), if all expectation values are nonnegative, then the Rayleigh quotient is nonnegative; in finite dimension, connect this to positivity of all eigenvalues.

A strong bridge theorem:

\[
\left(\forall x,\ \langle T x,x\rangle \in \mathbb R_{\ge 0}\right)
\implies
\forall \lambda \in \sigma_p(T),\ \lambda \in \mathbb R_{\ge 0}.
\]

**Lean 4 type signature sketch**
```lean
theorem eigenvalues_nonneg_of_expectation_nonneg
  {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
  [FiniteDimensional ℂ E]
  (T : E →L[ℂ] E) (hT : IsSelfAdjoint T)
  (hpos : ∀ x : E, 0 ≤ selfAdjointRayleigh T hT x) :
  ∀ μ : ℂ, μ ∈ pointSpectrum T → 0 ≤ μ.re
```

Or stronger, after proving eigenvalues are real:
```lean
theorem eigenvalue_nonneg_of_quadraticForm_nonneg
  ...
  : ∀ λ : ℝ, (∃ v ≠ 0, T v = (λ : ℂ) • v) → 0 ≤ λ
```

**Why this matters:** this theorem makes the formalism usable for Hamiltonians, density operators, covariance operators, and stability analysis.

## Proof Strategy Architecture

You must include **2–3 genuine proof strategies**, and choose one as primary.

### Strategy A: Finite-dimensional compactness + variational calculus
Most promising for min-max and extremal eigenvalue theorems.

1. Restrict the Rayleigh quotient to the unit sphere.
2. Use finite-dimensional compactness to obtain maximizers/minimizers.
3. Prove by perturbation/orthogonality argument that a maximizer is an eigenvector:
   - consider \(v + t w\),
   - differentiate or use algebraic comparison of quadratic forms,
   - derive orthogonality of \(T v - \lambda v\) against all \(w\),
   - conclude \(T v = \lambda v\).

**Why promising:** avoids requiring the full spectral theorem first; instead derives extremal eigenpairs directly from compactness and inner-product identities.

### Strategy B: Build polynomial functional calculus first, then derive spectral mapping and positivity
Best for operator-algebraic coherence.

1. Define `polynomialFunctionalCalculus T` by polynomial evaluation in the algebra of continuous linear maps.
2. Prove algebraic functoriality:
   - constants,
   - `X`,
   - addition,
   - multiplication.
3. Use induction on polynomials and eigenvector hypotheses to prove:
   \[
   p(T)v = p(\lambda)v.
   \]
4. Specialize to self-adjoint \(T\) to infer reality/order/positivity properties.

**Why promising:** Mathlib already supports algebraic polynomial evaluation machinery better than measure-theoretic functional calculus.

### Strategy C: Matrix reduction in finite dimension
Good fallback if operator-level lemmas are missing.

1. Choose an orthonormal basis in finite dimension.
2. represent \(T\) as a Hermitian matrix,
3. import or prove matrix Hermitian spectral facts,
4. transfer back to operators.

**Why less ideal but viable:** technically heavier in basis management, but can leverage linear algebra theorems if continuous-linear-operator infrastructure is thin.

**Recommended primary route:** combine **A + B**. Use B to build a reusable functional calculus, then A to establish variational extremal eigenvalue theorems without needing the full infinite-dimensional spectral theorem.
