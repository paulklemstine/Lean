## Precise Theorem Targets

You should introduce a small inductive syntax of tropical proof terms over `Nat` costs. Keep the core language minimal enough to prove deep metatheorems.

A promising concrete syntax:

```lean
inductive TropTerm where
  | atom : Nat → TropTerm
  | cut  : TropTerm → TropTerm → TropTerm
  | plus : TropTerm → TropTerm → TropTerm
  | min  : TropTerm → TropTerm → TropTerm
deriving DecidableEq, Repr
```

with tropical evaluation:

```lean
def eval : TropTerm → Nat
  | TropTerm.atom n   => n
  | TropTerm.cut t s  => eval t + eval s
  | TropTerm.plus t s => eval t + eval s
  | TropTerm.min t s  => Nat.min (eval t) (eval s)
```

and a one-step normalization relation generated by tropical proof equalities such as:

- duplicate branch collapse: `min t t ↦ t`
- cut distributes through choice:
  - `cut (min t u) s ↦ min (cut t s) (cut u s)`
  - `cut s (min t u) ↦ min (cut s t) (cut s u)`
- optional reassociation/orientation rules for `plus` and `min` if needed for canonicalization.

### Theorem 1: Soundness of Tropical Cut Elimination

Prove that every normalization step preserves tropical semantics.

**Lean target:**
```lean
theorem step_preserves_eval {t u : TropTerm} :
  Step t u → eval t = eval u
```

and therefore

```lean
theorem rtc_step_preserves_eval {t u : TropTerm} :
  Relation.ReflTransGen Step t u → eval t = eval u
```

### Theorem 2: Strict Decrease of a Syntactic Potential

Define a potential/complexity measure that strictly decreases under the oriented normalization rules.

A good target is a lexicographic measure combining:
1. number of `cut` nodes above a `min`,
2. total size,
3. number of duplicate `min t t` redexes.

For example:

```lean
def cutMinCount : TropTerm → Nat := ...
def dupMinCount : TropTerm → Nat := ...
def termSize : TropTerm → Nat := ...

def potential (t : TropTerm) : Nat × Nat × Nat :=
  (cutMinCount t, dupMinCount t, termSize t)
```

Then prove:

```lean
theorem step_decreases_potential {t u : TropTerm} :
  Step t u → Prod.Lex (· < ·) (Prod.Lex (· < ·) (· < ·)) (potential u) (potential t)
```

or an equivalent well-founded formulation.

This is the engine for strong normalization.

### Theorem 3: Strong Normalization

Prove there is no infinite reduction sequence.

**Lean target:**
```lean
theorem strongly_normalizing : WellFounded Step
```

or, if the direct `WellFounded` statement is too heavy, prove every term admits an accessible proof:

```lean
theorem acc_step (t : TropTerm) : Acc Step t
```

This is not merely a rewriting result: it formalizes the claim that **tropical cut elimination is an optimization process with a terminating canonical descent**.

### Theorem 4: Local Confluence / Diamond for the Core Critical Pairs

For the minimal rewrite system, prove local confluence on one-step overlaps, then conclude confluence by Newman’s lemma using strong normalization.

**Lean target:**
```lean
theorem local_confluence :
  Relation.LocalConfluent Step
```

and then

```lean
theorem confluent :
  Relation.Confluent Step
```

If full local confluence is too ambitious initially, prove a **diamond theorem for the critical fragment** generated by `cut` over `min` and idempotence of `min`, then lift to the full system.

### Theorem 5: Uniqueness and Semantic Optimality of Normal Forms

Define normal forms and prove that every term normalizes to a unique normal form whose evaluation is the least cost represented by the proof term.

**Lean target:**
```lean
def Normal (t : TropTerm) : Prop := ¬ ∃ u, Step t u

theorem normal_form_exists (t : TropTerm) :
  ∃ u, Relation.ReflTransGen Step t u ∧ Normal u

theorem normal_form_unique {t u v : TropTerm} :
  Relation.ReflTransGen Step t u → Normal u →
  Relation.ReflTransGen Step t v → Normal v →
  u = v

theorem normalization_is_semantics {t u : TropTerm} :
  Relation.ReflTransGen Step t u → Normal u → eval u = eval t
```

The revolutionary interpretation: **proof normalization computes optimal proof cost**.

## Proof Strategy Architecture

### Strategy A: Rewriting-Theoretic Core via a Well-Founded Potential
This is the most promising path.

1. **Define a minimal rewrite system** with only semantically justified rules:
   - duplicate collapse,
   - distribution of `cut` across `min`.
2. **Engineer a lexicographic potential** that strictly decreases under each rule.
   - `cutMinCount` should drop on distribution rules.
   - `dupMinCount` should drop on idempotence rules.
   - `termSize` breaks ties.
3. **Apply well-founded induction** on the potential to prove accessibility of every term, hence strong normalization.
4. **Prove local critical-pair joinability** by finite case analysis on the small rule set.
5. **Invoke Newman’s lemma**: strong normalization + local confluence ⇒ confluence.
6. Conclude **existence and uniqueness of normal forms**.

Why this is strongest: it is fully syntactic, Lean-friendly, and yields machine-verified proof theory rather than only denotational semantics.

### Strategy B: Canonical Normal Form by Compilation to Tropical DAG Semantics
This is conceptually deeper and may produce a stronger theorem if it works.

1. Define a **canonical extractor** `normalize : TropTerm → TropTerm` by recursion:
   - recursively normalize subterms,
   - flatten nested mins,
   - remove duplicates using idempotence,
   - push cuts through mins to obtain a “min of cut-free branches” normal form.
2. Prove:
   - `eval (normalize t) = eval t`,
   - `Normal (normalize t)`,
   - `Relation.ReflTransGen Step t (normalize t)`.
3. Prove **uniqueness by canonicity**, not just by confluence.

Why this matters: it turns the theory into an executable normalizer and reveals the computational content of tropical Curry–Howard as certified dynamic programming.

### Strategy C: Ordered-Algebraic Semantics and Abstract Reduction
This is more abstract and suitable for a second pass.

1. Regard `eval` as a morphism into an idempotent semiring/order-enriched algebra.
2. Show rewrite steps are instances of order-preserving equalities in this algebra.
3. Use the algebraic normal form theorem for free idempotent semiring expressions, specialized to your syntax.
4. Pull back semantic uniqueness to syntactic confluence via a completeness argument.

Why this is ambitious: it could generalize immediately from `Nat` to `ℝ`, `WithTop ℕ`, matrices over tropical semirings, and weighted proof nets. But it may require more library infrastructure.

**Recommendation:** Start with Strategy A, implement enough of Strategy B to produce a certified normalizer, then formulate Strategy C as the conceptual bridge theorem.

## Cross-Domain Connections You Must Make Explicit

This project is powerful because it is not just proof theory.

### 1. Rewriting Theory and Automated Reasoning
Tropical normalization turns cut elimination into **cost-aware proof search**. This suggests proof assistants where normalization computes shortest or cheapest derivations. The idempotent law formalizes proof memoization.

### 2. Dynamic Programming and Shortest Paths
`min` + `+` is the algebra of shortest paths. Your normal forms should be interpreted as **compiled shortest-proof certificates**. This creates a bridge between Curry–Howard and Bellman–Ford / Viterbi / weighted automata semantics.

### 3. Semiring Semantics in Programming Languages
The syntax is a tiny typed programming language with:
- sequencing = `cut` / `plus`,
- nondeterministic choice = `min`,
- normalization = optimization.
This is a tropical analogue of normalization-by-evaluation and opens a route to **resource-sensitive semantics**.

### 4. Tropical Geometry
The expression `min_i (a_i + x_i)` is the local grammar of tropical geometry. Normal forms in your proof calculus resemble tropical polynomials in canonical presentation. This suggests a future theorem connecting proof equivalence classes to tropical hypersurfaces.

### 5. Verification and Control
A proof term as a min-plus program is also a controller or plan with cost. Cut elimination then becomes **certified policy simplification**. This could connect to verified planning, scheduling, and robust verification.
