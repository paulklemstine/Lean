## Precise Mathematical Targets

Let `S` be a totally ordered idempotent semifield, `X` a type of inputs, and `F` a finitely generated `S`-semimodule of feature maps `X → S`. Let ridge atoms be the tropical affine generators
\[
r_{w,\phi}(x) := w \otimes \phi(x),
\]
and let the tropical Barron class `Barron(F)` be the closure under finite tropical sums:
\[
f = \bigoplus_{i=1}^n w_i \otimes \phi_i.
\]

A tropical Choquet functional on `Barron(F)` is a map
\[
L : Barron(F) \to S
\]
which is:

1. monotone,
2. sup-preserving on finite tropical sums,
3. shift-equivariant:
   \[
   L(a \otimes f) = a \otimes L(f).
   \]

Assume a **finite extremality / separating hypothesis**: there is a finite family of extremal evaluation functionals `ev_{x_i}` that separates the relevant extremal rays of `F`.

### Theorem 1: Finite Tropical Barron–Choquet Representation
Prove that every such `L` admits a canonical finite decomposition
\[
L(f) = \bigoplus_{i \in I} w_i \otimes ev_{x_i}(f),
\]
where `I` is finite, each `x_i` lies in the extremal support, and the support can be chosen irredundant. Moreover, under an antichain/non-domination hypothesis on the extremal evaluations, this support is unique up to permutation.

### Theorem 2: Certified Sparse Reconstruction
Given values of `L` on a finite separating family of extremal atoms/evaluations, prove that one can recover the unique irredundant support set and weights of the representation. The recovered support has **minimum cardinality** among all tropical neural realizations of `L`.

This is the theorem that converts duality into a certified compression algorithm.

## Mathematical overview

In max-plus (tropical) algebra, addition is `max` and multiplication is `+`.
A max-plus linear functional Λ on continuous functions satisfies:
- `Λ(f ⊔ g) = Λ(f) ⊔ Λ(g)` (preserves tropical addition = max)
- `Λ(f + c) = Λ(f) + c` (equivariant under tropical scalar action = real translation)

The Choquet–Radon representation expresses such a functional as a "max-plus integral":
  `Λ(f) = ⊔_K (μ(K) + inf_K f)`
where `μ` is a maxitive capacity on compact sets.

/-- An upper-continuous tropical (max-plus linear) functional on `C(X, ℝ)`,
taking values in `EReal` (extended reals with ±∞).

The axioms encode:
- `monotone'`: monotonicity with respect to pointwise order
- `sup_preserving'`: max-plus additivity `Λ(f ⊔ g) = max(Λ(f), Λ(g))`
- `shift_equivariant'`: tropical scalar action `Λ(f + c) = Λ(f) + c`
- `normalized'`: normalization `Λ(0) = 0`

structure UCTropicalFunctional (X : Type*) [TopologicalSpace X]
    [CompactSpace X] [T2Space X] where
  /-- The underlying function from continuous maps to extended reals. -/
  toFun : C(X, ℝ) → EReal
  /-- The functional is monotone. -/
  monotone' : Monotone toFun
  /-- The functional preserves binary suprema (max-plus additivity). -/
  sup_preserving' : ∀ f g : C(X, ℝ), toFun (f ⊔ g) = toFun f ⊔ toFun g
  /-- The functional is equivariant under translation by real constants. -/
  shift_equivariant' : ∀ (c : ℝ) (f : C(X, ℝ)),
    toFun (f + ContinuousMap.const X c) = toFun f + (c : EReal)
  /-- Upper continuity: Λ commutes with monotone suprema of continuous functions,
      provided the supremum is itself continuous. -/
  top_continuous' : ∀ {ι : Type*} [Nonempty ι] [Preorder ι] (s : ι → C(X, ℝ))
    (f : C(X, ℝ)),
    (∀ x, f x = ⨆ i, (s i x : EReal)) →
    Monotone s →
    toFun f = ⨆ i, toFun (s i)
  /-- Normalization: the zero function maps to zero. -/
  normalized' : toFun 0 = 0
