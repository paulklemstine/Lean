### Theorem B: Classical finite computation admits reversible tropical simulation with polynomial overhead

Do **not** overreach immediately to full Turing machines on infinite tapes. First prove a finite-window simulation theorem strong enough to encode bounded-time classical computation. This is already nontrivial and mathematically clean.

Define a bounded machine model:
- state space `σ`
- tape alphabet `Γ`
- bounded tape length `n`
- configuration type `Cfg σ Γ n := σ × Fin n → Γ × Fin n` or a cleaner structure
- deterministic step function `step : Cfg σ Γ n → Cfg σ Γ n`

Then define a reversible extension:
- enlarge configuration by adding history or ancilla bits,
- show the extension is bijective,
- show each reversible step can be realized by a tropical isomorphism.

A target theorem:

```lean
structure ClassicalMachine (σ Γ : Type*) [Fintype σ] [Fintype Γ] where
  step : σ × (Γ → Γ) → σ × (Γ → Γ)

structure RevTropicalMachine (α : Type*) [Fintype α] where
  stepIso : TropicalIso α

def SimulatesWithOverhead
  {α β : Type*} (encode : α → β) (decode : β → α) (f : α → α) (g : β → β)
  (poly : ℕ → ℕ) : Prop := sorry

theorem classical_to_reversible_tropical_poly_overhead
  {σ Γ : Type*} [Fintype σ] [Fintype Γ]
  (M : ClassicalMachine σ Γ) :
  ∃ (α : Type) (_ : Fintype α) (R : RevTropicalMachine α) (encode : (σ × (Γ → Γ)) → α)
    (decode : α → (σ × (Γ → Γ))) (poly : ℕ → ℕ),
    SimulatesWithOverhead encode decode M.step R.stepIso.toFun poly
    ∧ ∃ k c : ℕ, ∀ n, poly n ≤ k * n + c := by
  sorry
```

This signature is schematic; you should probably replace `(Γ → Γ)` with a finite tape representation like `Fin n → Γ`, because Lean can reason about finite arrays more directly:

```lean
def Tape (Γ : Type*) (n : ℕ) := Fin n → Γ
def Cfg (σ Γ : Type*) (n : ℕ) := σ × Tape Γ n × Fin n
```

Then prove:

```lean
theorem bounded_classical_cfg_to_rev_tropical_linear_overhead
  {σ Γ : Type*} [Fintype σ] [Fintype Γ]
  (n : ℕ) (step : Cfg σ Γ n → Cfg σ Γ n) :
  ∃ (α : Type) (_ : Fintype α) (T : TropicalIso α)
    (encode : Cfg σ Γ n → α) (decode : α → Cfg σ Γ n),
    Function.LeftInverse decode encode
    ∧ ∀ cfg, decode (T.toFun (encode cfg)) = step cfg
    ∧ ∃ c : ℕ, True := by
  sorry
```

Then strengthen to a **t-step simulation overhead theorem**:

```lean
theorem bounded_classical_iterate_simulated_by_rev_tropical
  {σ Γ : Type*} [Fintype σ] [Fintype Γ]
  (n t : ℕ) (step : Cfg σ Γ n → Cfg σ Γ n) :
  ∃ (α : Type) (_ : Fintype α) (T : TropicalIso α)
    (encode : Cfg σ Γ n → α) (decode : α → Cfg σ Γ n) (C : ℕ),
    Function.LeftInverse decode encode
    ∧ ∀ cfg,
        decode ((T.toFun^[C * t + C]) (encode cfg)) = (step^[t]) cfg := by
  sorry
```

Why this is a breakthrough: it gives a formal theorem that **reversible tropical dynamics are computationally universal up to polynomial overhead**. This reframes Bennett-style reversibility as a theorem in min-plus algebra rather than only in classical complexity theory.

### Theorem C: Exact Landauer cost for uniform one-bit erasure

The assignment says “exactly `kT ln(2)` per bit.” Formalize this first in the cleanest finite probabilistic setting: uniform bit erasure from `{0,1}` to a fixed state. Then generalize to `n` bits.

Precise theorem target:

```lean
def bitDist : Bool → ℝ := fun b => (1 : ℝ) / 2

def eraseBit : Bool → Unit := fun _ => ()

def landauerWork (T k : ℝ) (ΔH : ℝ) : ℝ := k * T * Real.log 2 * ΔH

theorem landauer_bit_erasure_exact
  (k T : ℝ) (hT : 0 ≤ T) (hk : 0 ≤ k) :
  landauerWork T k 1 = k * T * Real.log 2 := by
  ring
```

But that is only an arithmetic identity. The actual theorem must connect entropy drop to work:

```lean
def EntropyBits {α : Type*} [Fintype α] (p : α → ℝ) : ℝ := sorry

theorem uniform_bit_entropy :
  EntropyBits bitDist = 1 := by
  sorry

theorem erased_unit_entropy :
  EntropyBits (fun _ : Unit => 1) = 0 := by
  sorry

theorem landauer_cost_uniform_bit_erasure_exact
  (k T : ℝ) (hT : 0 ≤ T) (hk : 0 ≤ k) :
  let ΔH := EntropyBits bitDist - EntropyBits (fun _ : Unit => 1)
  in k * T * Real.log 2 * ΔH = k * T * Real.log 2 := by
  sorry
```

Then generalize to `Fin (2^n)` or `Vector Bool n`:

```lean
def uniformBits (n : ℕ) : (Fin (2^n) → ℝ) := fun _ => (2 : ℝ) ^ (-n : ℤ) -- schematic

theorem landauer_cost_uniform_n_bit_erasure_exact
  (n : ℕ) (k T : ℝ) (hT : 0 ≤ T) (hk : 0 ≤ k) :
  ∃ ΔH : ℝ, ΔH = n ∧ k * T * Real.log 2 * ΔH = n * k * T * Real.log 2 := by
  sorry
```

A cleaner finite-set version may be easier:

```lean
theorem landauer_cost_fintype_uniform_erasure_exact
  (α : Type*) [Fintype α] [Nonempty α]
  (k T : ℝ) :
  let ΔH := Real.log (Fintype.card α)
  in k * T * ΔH = k * T * Real.log (Fintype.card α) := by
  simp
```

Then instantiate with `α = Fin (2^n)` and use `Real.log ((2:ℝ)^n) = n * Real.log 2`.

Why this matters: if formalized correctly, this becomes one of the first machine-checked bridges between **finite information theory, thermodynamics, and tropical cost semantics**.

Build on:
- `landauer_cost_uniform_erasure`
- finite cardinality lemmas
- `Real.log_rpow`, `pow_nat`, positivity lemmas
- if needed, define entropy only for uniform distributions first, where proofs are much cleaner

## Proof Strategy Paths

### Strategy A: Bennett history tape construction
Most promising for the simulation theorem.

1. Given a deterministic bounded step `step : Cfg → Cfg`, define reversible lift
   ```lean
   revStep : Cfg × Cfg → Cfg × Cfg
   revStep (x, h) = (step x, x)
   ```
   or a slightly richer version accumulating history.
2. Prove `revStep` is injective/surjective by explicit inverse.
3. Package `revStep` as a `TropicalIso`.
4. Show decoding of the first component recovers the original computation.
5. Bound overhead by counting one reversible step per classical step, or a linear factor if cleanup is included.

Why promising: it avoids hard semantic arguments and turns reversibility into explicit algebra.

### Strategy B: Embed configurations into weighted tropical matrices
Best for the “tropical isomorphism” interpretation.

1. Represent each reversible step as a permutation matrix over the tropical semiring.
2. Prove permutation tropical matrices are invertible and compose tropically.
3. Use matrix multiplication to model computation over time.
4. Show the simulation map is faithful and overhead remains polynomial.

Why promising: this makes the tropical structure intrinsic rather than decorative. It also opens the door to spectral and geometric analysis of reversible computation.

### Strategy C: Category-theoretic transport of reversibility to thermodynamics
Best for the entropy theorem layer.

1. Define a category of finite state spaces with bijections.
2. Define a functor to tropical cost objects and a functor to entropy-preserving stochastic actions.
3. Prove reversibility implies functorial entropy invariance.
4. Model erasure as a non-isomorphism/quotient and show exact entropy drop.

Why promising: this gives conceptual clarity and future extensibility, but it is heavier in Lean. Use only if Layers I and II are already stable.

**Recommendation:** Start with A for simulation, use B to tropicalize it, and use a lightweight version of C only for the entropy interpretation.

## Important Caution

Do not claim “every transition corresponds to a tropical semiring isomorphism” unless you have defined what that means on the chosen state space. The safest mathematically honest interpretation is:

- the configuration basis vectors form a tropical semimodule,
- a reversible machine step acts by a permutation of basis vectors,
- permutation maps are tropical linear automorphisms.

This is elegant, true, and Lean-friendly.

A precise theorem for that bridge:

```lean
theorem equiv_induces_tropical_linear_automorphism
  {α : Type*} [Fintype α] (e : α ≃ α) :
  ∃ F : (α → ℝ) → (α → ℝ),
    (∀ x y, F (fun a => min (x a) (y a)) = fun a => min (F x a) (F y a))
    ∧ (∀ c x, F (fun a => c + x a) = fun a => c + F x a)
    ∧ Function.Bijective F := by
  sorry
```

This is one of the most beautiful statements available here: a reversible computation step induces a tropical linear automorphism on cost landscapes.
