## Research Task: EML Stone–Weierstrass for compact manifold codomains via closed embeddings and neighborhood retractions

Research Mode: PROVE

Work in the existing EML approximation framework on a compact Hausdorff domain `X`, and push the already-established finite-dimensional codomain theorem to compact manifold targets by factoring through a Euclidean embedding and a continuous retraction from a neighborhood of the embedded image.

The clean formal target should be phrased first in a topological/retract form, with the manifold statement as a corollary. This avoids overcommitting to whatever smooth-manifold API is currently most convenient in Mathlib, while still delivering the intended manifold-valued universal approximation theorem.

### Main theorem to formalize first: retract-valued approximation

Let `X` be compact Hausdorff, let `S : Set (Fin n → ℝ)` be a compact subset of Euclidean space, and suppose `S` is a neighborhood retract: there exist an open set `U` with `S ⊆ U` and a continuous map `r : U → S` such that `r s = ⟨s, hs⟩` for all `s ∈ S`. If the existing EML class approximates arbitrary continuous maps `X → (Fin n → ℝ)` uniformly, then it also approximates arbitrary continuous maps `X → S` uniformly.

A useful Lean-style theorem signature is:

```lean
theorem eml_uniform_approx_subtype_of_neighborhoodRetract
    {X : Type*} [TopologicalSpace X] [CompactSpace X]
    [T2Space X]
    {n : ℕ}
    (S : Set (Fin n → ℝ))
    (hS_compact : IsCompact S)
    (U : Set (Fin n → ℝ))
    (hU_open : IsOpen U)
    (hSU : S ⊆ U)
    (r : U → S)
    (hr_cont : Continuous r)
    (hr_fix : ∀ s : S, r ⟨s.1, hSU s.2⟩ = s)
    (A : Set (C(X, Fin n → ℝ)))
    (hA_dense :
      ∀ f : C(X, Fin n → ℝ), ∀ ε > 0,
        ∃ g ∈ A, ∀ x, ‖g x - f x‖ < ε) :
    ∀ f : C(X, S), ∀ ε > 0,
      ∃ g : C(X, S),
        (∃ g0 ∈ A, ∀ x, g x = r ⟨g0 x, by sorry⟩) ∧
        ∀ x, ‖(g x : Fin n → ℝ) - (f x : Fin n → ℝ)‖ < ε
```

The only delicate placeholder above is the proof that the approximant `g0 x` lands in `U`; that should be discharged by choosing a uniform tubular radius around `f(X)` inside `U`.

A sharper and more reusable intermediate lemma is the “stability under retraction” estimate:

```lean
theorem exists_uniform_radius_into_open
    {X : Type*} [TopologicalSpace X] [CompactSpace X]
    [T2Space X]
    {n : ℕ}
    {S U : Set (Fin n → ℝ)}
    (hS_compact : IsCompact S)
    (hU_open : IsOpen U)
    (hSU : S ⊆ U) :
    ∃ δ > 0, ∀ y, (∃ s ∈ S, ‖y - s‖ < δ) → y ∈ U
```

and then, for the retract itself,

```lean
theorem retract_uniform_close_on_compact
    {K : Set (Fin n → ℝ)}
    (hK_compact : IsCompact K)
    (hKU : K ⊆ U)
    (hr_cont : Continuous r) :
    ∀ ε > 0, ∃ δ > 0, ∀ y z : U,
      ((y : Fin n → ℝ) ∈ K) →
      ‖(z : Fin n → ℝ) - y‖ < δ →
      ‖(r z : Fin n → ℝ) - (r y : Fin n → ℝ)‖ < ε
```

with the key specialization `r y = y` on `S`.

### Manifold corollary

Once the retract-valued theorem is in place, derive the intended manifold-valued result by instantiating `S` with the image of a compact smooth manifold under a Euclidean embedding.

A realistic Lean-facing statement, depending on available manifold API, is:

```lean
theorem eml_uniform_approx_compact_manifold
    {X M : Type*}
    [TopologicalSpace X] [CompactSpace X] [T2Space X]
    [TopologicalSpace M] [CompactSpace M] [T2Space M]
    {n : ℕ}
    (e : M ↪ (Fin n → ℝ))
    (he_cont : Continuous e)
    (he_homeo :
      Continuous (fun y : e '' (Set.univ : Set M) =>
        Classical.choose (by sorry) )) -- replace by an actual embedding/homeomorph API
    (U : Set (Fin n → ℝ))
    (hU_open : IsOpen U)
    (himageU : Set.range e ⊆ U)
    (r : U → Set.range e)
    (hr_cont : Continuous r)
    (hr_fix : ∀ m : M, r ⟨e m, himageU ⟨m, rfl⟩⟩ = ⟨e m, ⟨m, rfl⟩⟩)
    (A : Set (C(X, Fin n → ℝ)))
    (hA_dense :
      ∀ F : C(X, Fin n → ℝ), ∀ ε > 0,
        ∃ G ∈ A, ∀ x, ‖G x - F x‖ < ε) :
    ∀ f : C(X, M), ∀ ε > 0,
      ∃ h : C(X, M), ∀ x, dist (h x) (f x) < ε
```

But in practice, the subtype/retract theorem is the robust formal core; the manifold corollary can be specialized later once the exact Mathlib statements for embedding and tubular neighborhood are confirmed.

### Recommended proof strategy

1. **Reduce to the embedded compact image.**  
   For `f : C(X, S)`, the range `K := Set.range (fun x => (f x : Fin n → ℝ))` is compact because `X` is compact and `f` is continuous. Since `K ⊆ S ⊆ U` and `U` is open, compactness gives a positive uniform margin:
   ```lean
   ∃ δ₀ > 0, ∀ x y, y ∈ K → ‖x - y‖ < δ₀ → x ∈ U.
   ```
   This is the key “stay inside the tubular neighborhood” lemma. Prove it either by a finite subcover argument using balls inside `U`, or via compact/open-set distance separation if the needed lemmas are already available.

2. **Use continuity of the retraction uniformly on a compact set.**  
   Restrict attention to the compact thickening of `K` inside `U`. Since `r` is continuous and `K` is compact, `r` is uniformly continuous near `K`. Concretely, for any `ε > 0`, choose `δ₁ > 0` such that whenever `y ∈ K`, `z ∈ U`, and `‖z - y‖ < δ₁`, then
   ```lean
   ‖(r ⟨z, _⟩ : Fin n → ℝ) - y‖ < ε,
   ```
   because `r ⟨y, _⟩ = y` for `y ∈ S`, hence for `y ∈ K ⊆ S`. This is where the retract identity converts continuity of `r` into closeness to the original point.

3. **Approximate the embedded map in Euclidean space.**  
   Apply the existing finite-dimensional EML Stone–Weierstrass theorem to the composed map
   ```lean
   F : C(X, Fin n → ℝ) := fun x => (f x : Fin n → ℝ).
   ```
   With `δ := min δ₀ δ₁`, obtain `g0 ∈ A` such that
   ```lean
   ∀ x, ‖g0 x - F x‖ < δ.
   ```
   The `δ₀` bound guarantees `g0 x ∈ U` for every `x`, so the retraction is defined pointwise.

4. **Retract back to the target and estimate the final error.**  
   Define
   ```lean
   g x := r ⟨g0 x, hg0U x⟩.
   ```
   Then `g : C(X, S)` by continuity of `g0` and `r`. For each `x`, set `y := F x ∈ K`; since `‖g0 x - y‖ < δ ≤ δ₁`, the uniform continuity estimate yields
   ```lean
   ‖(g x : Fin n → ℝ) - y‖ < ε.
   ```
   Since `y = (f x : Fin n → ℝ)`, this is the desired uniform approximation in the subtype codomain.

5. **Pass from embedded image back to the manifold.**  
   If `e : M ↪ Fin n → ℝ` identifies `M` homeomorphically with `S := Set.range e`, then compose the subtype-valued approximant with the inverse homeomorphism `S ≃ₜ M`. Error transfer is immediate if the metric on `M` is taken as the pullback metric from the embedding; otherwise use uniform continuity of the inverse on compact `S`.

### Important implementation choices

- Use `Fin n → ℝ` rather than arbitrary finite-dimensional normed spaces; this matches the existing EML vector-valued API most directly.
- Prefer codomain `S` as a subtype `↥S` of Euclidean space. This makes the retraction codomain precise and avoids carrying a separate equivalence until the final manifold corollary.
- State approximation in pointwise sup-norm form
  ```lean
  ∀ x, ‖g x - f x‖ < ε
  ```
  unless the existing EML theorem is already packaged with `dist` or `‖f - g‖`. Match the library theorem exactly when invoking it.
- If the manifold API is awkward, prove first the theorem for any compact Euclidean neighborhood retract. The compact smooth manifold result should then be a short corollary from Whitney embedding plus tubular neighborhood retraction, and this intermediate theorem is mathematically stronger in the direction of compact ENR/ANR codomains.

### Why this matters

This theorem is the natural next step in the EML approximation program: it upgrades approximation from linear/affine codomains to genuinely nonlinear state spaces while still using the verified finite-dimensional Euclidean approximation theorem as the engine. Once established, it immediately yields manifold-valued approximation results for spheres, tori, projective spaces after embedding, compact matrix groups realized as closed submanifolds of Euclidean space, and many configuration/state spaces used in geometry and physics. Formally, it also builds the exact bridge needed for later ANR-codomain and geometric-constraint approximation results: the essential new ingredient is not manifold smoothness per se, but the retract mechanism that converts Euclidean approximation into target-preserving approximation.
