## Core Vision

The breakthrough is to replace the graph-theoretic “merge/cycle-birth” tropical Morse spectrum by a **critical-simplex event spectrum** for weighted simplicial complexes, where events are indexed by simplex dimension and interpreted through homological changes in a filtration. If this is done correctly, the spectrum should become a topological-combinatorial invariant that sees higher-dimensional structure invisible to Weisfeiler–Leman-type local refinement.

This is not a routine extension of 1-dimensional persistent topology. The real target is a new interface:

- **tropical geometry** supplies min-plus ordering and spectral viewpoint,
- **discrete Morse theory** supplies critical events,
- **persistent homology** supplies barcode semantics,
- **combinatorics of simplicial complexes** supplies computable structure,
- **logic / graph isomorphism complexity** supplies comparison with `k`-WL.

If successful, this opens a field: **tropical Morse signatures for higher-order data**—useful in mesh analysis, topological materials science, geometric learning on cell complexes, and the algorithmic study of topological distinguishability beyond WL.

### Theorem 1: Euler characteristic from weighted simplex filtration in all finite dimensions

This is the first indispensable extension of the graph result.

**Mathematical statement.**  
Let `K` be a finite weighted simplicial complex with distinct simplex weights. For each filtration threshold `t`, let `K≤t` be the subcomplex of simplices with weight at most `t`. Then the alternating sum of the number of simplices added up to time `t` equals the Euler characteristic of `K≤t`. Consequently, the total alternating count of critical simplex events over the whole filtration equals `χ(K)`.

A Lean-shaped target:

```lean
theorem euler_char_from_weighted_filtration
  {V : Type*} [Fintype V] [DecidableEq V]
  (K : SimplicialComplexOn V)
  (w : {σ : Finset V} → σ ∈ K.faces → ℝ)
  (hw_inj :
    ∀ {σ τ : Finset V} (hσ : σ ∈ K.faces) (hτ : τ ∈ K.faces),
      w hσ = w hτ → σ = τ)
  (t : ℝ) :
  eulerChar (filtrationSubcomplex K w t)
    =
  ∑ σ in (K.faces.filter (fun σ =>
      by
        classical
        exact if h : σ ∈ K.faces then w h ≤ t else False)),
      ((-1 : ℤ) ^ simplexDim σ)
```

You may need a cleaner formalization with a face-weight function `weight : Finset V → ℝ` together with a proof that it is only used on faces. That is fine.

**Why this matters.**  
This is the universal conservation law of the theory. In graphs, merge and cycle events suffice. In higher dimensions, the alternating event count becomes the backbone tying tropical spectral data to topology.

### Theorem 2: Single-simplex update theorem for Euler characteristic and homological event type

**Mathematical statement.**  
Assume generic weights so simplices enter one at a time. If a `d`-simplex `σ` is added at a filtration step, then the Euler characteristic changes by `(-1)^d`. Moreover, under an acyclic pairing / discrete Morse admissibility hypothesis, the addition is either homologically null (paired simplex) or changes exactly one Betti number in dimensions `d` or `d-1`.

Lean-shaped target:

```lean
theorem add_simplex_euler_step
  {V : Type*} [Fintype V] [DecidableEq V]
  (K : SimplicialComplexOn V)
  (σ : Finset V)
  (hσ : σ ∉ K.faces)
  (hfaces : ∀ ⦃τ : Finset V⦄, τ ⊂ σ → τ.Nonempty → τ ∈ K.faces) :
  eulerChar (K.adjoinSimplex σ hσ hfaces)
    =
  eulerChar K + (-1 : ℤ) ^ simplexDim σ
```

and a refined event theorem such as:

```lean
theorem critical_simplex_changes_at_most_one_betti
  {V : Type*} [Fintype V] [DecidableEq V]
  (K : SimplicialComplexOn V)
  (σ : Finset V)
  (hattach : AttachesAlongBoundary K σ)
  (hcritical : IsCriticalSimplex K σ) :
  ∃ k ≤ simplexDim σ,
    Nat.Abs (bettiNumber k (K.attach σ) - bettiNumber k K) = 1 ∧
    (∀ j, j ≠ k → bettiNumber j (K.attach σ) = bettiNumber j K)
```

If full Betti-number formalization is too expensive, prove a weaker but still deep theorem in terms of Euler characteristic plus a combinatorial criticality dichotomy. But push hard for at least one theorem with genuine homological semantics.

**Why this matters.**  
This is the local law of higher tropical Morse theory: every spectral event corresponds to one simplex insertion, and criticality controls whether topology actually changes.

### Theorem 3: Surface classification via tropical Morse signatures

Specialize to finite triangulated closed surfaces. Prove that the tropical Morse spectrum determines Euler characteristic, and hence distinguishes standard surfaces with different Euler characteristic under generic weights.

**Mathematical statement.**  
For triangulations of the torus `T²`, Klein bottle `Klein`, and projective plane `RP²`, any generic weighted filtration has total signed event count equal to `0`, `0`, and `1` respectively. Hence projective plane is always distinguished from torus and Klein bottle by the spectrum. Further, with an orientability-sensitive refinement (for example parity/profile of 2-simplex critical events, or a first-homology coefficient choice), torus and Klein bottle become distinguishable.

Lean-shaped target:

```lean
theorem tropical_morse_spectrum_detects_euler_char_surface
  (S : WeightedTriangulatedSurface)
  (hw_generic : GenericWeights S) :
  signedEventSum (tropicalMorseSpectrum S.toComplex S.weight) = eulerChar S.toComplex
```

and concrete corollaries:

```lean
theorem projectivePlane_not_torus_by_TMS
  (P T : WeightedTriangulatedSurface)
  (hP : P.IsTriangulationOfProjectivePlane)
  (hT : T.IsTriangulationOfTorus)
  (hPg : GenericWeights P)
  (hTg : GenericWeights T) :
  tropicalMorseSpectrum P.toComplex P.weight ≠
  tropicalMorseSpectrum T.toComplex T.weight
```


A stronger theorem, if you can support mod-2 or coefficient-dependent homology:

**Why this matters.**  
This is the first serious evidence that higher-dimensional tropical Morse data is a shape invariant, not merely a bookkeeping device. Distinguishing surfaces is the right “minimal nontrivial world” where geometry, topology, and combinatorics all meet.

## Proof Architecture: 3 Viable Strategies

### Strategy A: Filtration-by-single-simplex insertion + Euler/Poincaré bookkeeping
1. Order simplices by generic weight and realize the filtration as successive simplex insertions.
2. Prove a local update theorem: adding a `d`-simplex changes simplex counts by exactly one in dimension `d`, so Euler characteristic changes by `(-1)^d`.
3. Sum over filtration steps to recover the global theorem; then connect critical insertions to topological changes.

**Why promising:** This is the cleanest Lean route. It leverages finite combinatorics and extends `euler_char_from_filtration` naturally.

### Strategy B: Discrete Morse pairing viewpoint
1. Define a gradient-like pairing on simplices compatible with the filtration.
2. Show non-critical paired simplices contribute cancelling `(+1,-1)` Euler increments.
3. Conclude that only critical simplices contribute to the tropical Morse spectrum, and their dimensions control homological events.

**Why promising:** Conceptually strongest. This gives the true higher-dimensional Morse interpretation and opens the path to barcode-level theorems.

### Strategy C: Chain-complex / boundary-rank approach
1. Encode each filtration step via chain groups and boundary maps.
2. Use rank-nullity to express Betti changes under simplex insertion.
3. Derive that a simplex insertion changes at most one Betti number and shifts Euler characteristic by `(-1)^d`.

**Why promising:** Best for a theorem explicitly relating the spectrum to persistent homology.  
**Why harder:** Requires more algebraic infrastructure. Use if Mathlib support is sufficient or if you can isolate a low-dimensional combinatorial version.

**Recommendation:** Start with Strategy A for guaranteed theorem production, then use Strategy B to define criticality and Strategy C for at least one nontrivial homological theorem.
