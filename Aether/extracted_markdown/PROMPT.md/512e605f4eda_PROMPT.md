### Definition 1: `WeightSystem` — A Set of Weight Matrices as a Dynamical System

```lean
/-- A weight system is a finite collection of linear maps over a normed ring,
representing the weight matrices of a neural network layer. The joint spectral
radius captures the maximal asymptotic growth rate of products of these maps.

Bridge: connects operator theory to certified_robustness in deep learning. -/
structure WeightSystem (n : ℕ) (R : Type*) [NormedCommRing R] where
  maps : Finset (Matrix (Fin n) (Fin n) R)
  nonempty : maps.Nonempty
  deriving DecidableEq
```

### Definition 2: `JointSpectralRadius` — The Asymptotic Growth Rate

```lean
/-- The joint spectral radius ρ(𝒜) of a weight system is defined as
ρ(𝒜) = lim_{k→∞} max_{A_{i₁}...A_{iₖ} ∈ 𝒜^k} ||A_{i₁}...A_{iₖ}||^{1/k}

This provides a certified expressivity bound: any depth-d network using weights
from 𝒜 has operator norm bounded by ρ(𝒜)^d.

Bridge: connects multiplicative ergodic theory to lipschitz_certified_robustness. -/
noncomputable def jointSpectralRadius {n : ℕ} {R : Type*} [NormedCommRing R]
    (ws : WeightSystem n R) : ℝ :=
  (Filter.liminf (fun k : ℕ => (maxProductNorm ws k : ℝ)^(1/k : ℚ))
    Filter.atTop)
```

### Definition 3: `BarabanovNorm` — The Extremal Norm Certifying the JSR

```lean
/-- A Barabanov norm for a weight system 𝒜 with JSR ρ is a norm ||·||_B such that
∀ A ∈ 𝒜, ∀ x, ||Ax||_B ≤ ρ · ||x||_B

Existence of this norm certifies the JSR bound and provides
lipschitz_certified_robustness for the network.

Bridge: connects convex geometry to certified_robustness bounds in ML. -/
structure BarabanovNorm (n : ℕ) (R : Type*) [NormedCommRing R]
    (ws : WeightSystem n R) (ρ : ℝ) extends Norm (Fin n → R) where
  dominates : ∀ A ∈ ws.maps, ∀ x, norm (A.mulVec x) ≤ ρ * norm x
  tight : ∃ A ∈ ws.maps, ∃ x, norm (A.mulVec x) = ρ * norm x
  homogeneous_certified : ∀ (r : R) (x : Fin n → R),
    norm (r • x) = ‖r‖ * norm x
```

### Definition 4: `NeuralWeightAlgebra` — The Associative Algebra of Weights

```lean
/-- The neural weight algebra is the subalgebra of (n×n)-matrices generated by
```
