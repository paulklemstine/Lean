### Theorem B: Berggren hypotenuse Dirichlet series has exact prime-support Euler factorization

Define the primitive-triple counting coefficient
\[
A(n) := \#\{(a,b,c)\in \mathcal P : c=n\}.
\]
Then define the arithmetic generating series
\[
Z(s) := \sum_{n\ge 1} A(n)\, n^{-s}.
\]
In Lean, use a finite truncation or a formal arithmetic function version if full analytic convergence is too expensive.

The exact theorem should say that the support of \(A\) is multiplicatively generated by \(2\) and primes \(p\equiv 1 \pmod 4\), and therefore the formal Euler product of the support indicator matches the tropical zeta support.

#### Lean target: support-level factorization
```lean

  ((Finset.range (n+1)).biUnion fun a =>
    (Finset.range (n+1)).filter fun b =>
      Nat.Coprime a b ∧ a^2 + b^2 = n^2).card

def hypotenuseSupport (n : ℕ) : Prop := hypotenuseCount n > 0

theorem hypotenuse_support_iff_sum_two_squares
    {n : ℕ} :
    hypotenuseSupport n ↔ ∃ x y : ℕ, x^2 + y^2 = n
```

A more realistic theorem, if the above exact equivalence is easier through classical sum-of-two-squares theory, is:
```lean
theorem primitive_hypotenuse_iff_sum_two_squares
    {n : ℕ} :
    (∃ a b : ℕ, Nat.Coprime a b ∧ a^2 + b^2 = n^2) ↔
    ∃ x y : ℕ, x^2 + y^2 = n
```

Then prove the prime-support corollary:
```lean
theorem hypotenuse_support_prime_factorization
    {n : ℕ} :
    hypotenuseSupport n ↔
      ∀ p : ℕ, Nat.Prime p → p ∣ n → p = 2 ∨ p % 4 = 1
```

This theorem is the true Euler-product theorem in formal disguise. Once this is proved, the tropical Euler product is not hand-waving: it is the **support factorization law**.

## Proof Strategy Architecture

### Strategy A: Euclid parametrization + sum-of-two-squares arithmetic
This is the most promising route for Theorems A and B.

1. Prove or import the standard classification of primitive triples:
   \[
   a=2mn,\quad b=m^2-n^2,\quad c=m^2+n^2,
   \]
   with \(\gcd(m,n)=1\) and opposite parity.
2. Use classical sum-of-two-squares theory to prove:
   - if \(p\mid c\) and \(c=m^2+n^2\) with \(\gcd(m,n)=1\), then \(p=2\) or \(p\equiv1\pmod4\),
   - conversely if \(p\equiv1\pmod4\), then \(p=x^2+y^2\), hence \(p\) is a primitive hypotenuse.
3. Convert the prime-divisor characterization into the support-level Euler factorization.

Why this is best: Mathlib already has strong modular arithmetic, primality, divisibility, finite sums, and coprimality infrastructure. This path yields exact arithmetic theorems rather than heuristic analytic statements.

### Strategy B: Berggren tree induction + matrix invariants
Use the Berggren tree as the primary engine.

1. Start from the root primitive triple \((3,4,5)\).
2. Use `berggren_preserves_pythagorean` and `berggren_map_pythagorean` to show every Berggren descendant remains primitive/Pythagorean.
3. Define a hypotenuse-support predicate on tree nodes and prove inductively that every node hypotenuse has only admissible prime factors.
4. If possible, prove surjectivity from primitive triples to Berggren nodes, then obtain the global support theorem.

Why this matters: this turns the theorem from classical number theory into a theorem about **arithmetic dynamics on a tree**, which is much more original. It is also the right route for tropical statistics and levelwise zeta truncations.

### Strategy C: Finite tropical zeta truncations + combinatorial functional equation
This is the right route for Theorem C.

1. Define finite-level Berggren node sets and a min-plus or max-plus weight functional.
2. Prove invariance or monotonicity under one or more Berggren generators using explicit matrix inequalities and `berggren_BA_product`.
3. Derive a levelwise symmetry/duality between leg and hypotenuse statistics, e.g. lower/upper bounds relating
   \[
   c-\max(a,b),\quad \min(a,b),\quad c-(a+b)/2.
   \]
4. Package this as a tropical “functional equation shadow” for the truncated zeta.

Why this is promising: it avoids unsupported complex analysis while still delivering something genuinely new and structurally deep.
