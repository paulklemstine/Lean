## Assignment: Direction 2: E-Graph Extraction as Approximate Quotient Section

**Mode:** `prove`

Prove genuinely new, non-trivial theorems that turn equality saturation from an engineering heuristic into a theorem of universal algebra. The central vision is this:

> An e-graph is not merely a data structure for rewriting; it is a finite presentation of a semantic quotient of the term algebra. Extraction is therefore not an arbitrary search procedure, but a candidate **section** of the quotient map. The breakthrough is to identify the exact hypotheses under which this section is semantically canonical, and to prove that extraction correctness is a corollary of congruence soundness.

This is not an incremental extension of optimizer correctness. It is a conceptual re-foundation of equality saturation, with consequences for compiler optimization, SMT congruence closure, universal algebra, and even categorical semantics of approximation.

The key point is to sharpen the vague slogan “extraction is correct” into a theorem with quantifiers, quotient maps, and section properties.

## Main Theorem Statements

You must prove at least 3 substantial theorems. Here are the exact targets you should aim for, with Lean-style signatures that Aristotle can refine to match the actual imported catalog interfaces.

### Theorem 1: Extraction invariance on congruence classes
**Mathematical statement.**  
Let `≈` be a congruence on terms sound for all models of an equational theory `R`. Let `extract : Quotient (≈) → Term` satisfy the section property. Then for every algebra `A` satisfying `R`, evaluation of the extracted representative agrees with evaluation of every term in the class.

**Lean-style target**
```lean
theorem extraction_eval_invariant
  {Σ : Type u} {Term : Type v} {α : Type w}
  (s : Setoid Term)
  (eval : Term → α)
  (h_sound : ∀ {t₁ t₂ : Term}, s.r t₁ t₂ → eval t₁ = eval t₂)
  (extract : Quotient s → Term)
  (h_sec : ∀ q : Quotient s, Quotient.mk _ (extract q) = q) :
  ∀ (q : Quotient s) (t : Term), Quotient.mk _ t = q → eval (extract q) = eval t
```

**Why this matters.**  
This is the formal heart of equality saturation: extraction correctness is no longer a property of a particular search heuristic, but a theorem about sections of semantic quotients.

### Theorem 2: Reduction of extraction correctness to congruence soundness
**Mathematical statement.**  
Suppose an e-graph relation `≈eg` contains the axiomatic equivalence generated by `R` and is sound under evaluation in every `R`-algebra. Then any extraction function selecting a representative from each e-class is semantically correct. Thus extraction correctness reduces to congruence soundness.

**Lean-style target**
```lean
theorem extraction_correct_of_congruence_sound
  {Term : Type u} {α : Type v}
  (s : Setoid Term)
  (eval : Term → α)
  (extract : Quotient s → Term)
  (h_repr : ∀ q : Quotient s, s.r (extract q) (Quotient.out q))
  (h_sound : ∀ {t₁ t₂ : Term}, s.r t₁ t₂ → eval t₁ = eval t₂) :
  ∀ q : Quotient s, eval (extract q) = eval (Quotient.out q)
```

You may need to replace `Quotient.out` by a custom representative lemma depending on available Mathlib interfaces. The important content is the reduction theorem.

**Why this matters.**  
This theorem isolates the sole mathematically essential obligation of e-graphs: **sound congruence closure**. Once that is certified, extraction inherits semantic correctness. This would be a foundational theorem for `egg`, `egglog`, MLIR equality saturation, and compiler superoptimization.

### Theorem 3: Cost-optimal extraction is semantically constant on each class
**Mathematical statement.**  
If `cost : Term → ℕ` and `extract` returns a cost-minimizing representative of each e-class, then the semantic value of the minimum-cost term is independent of which minimum-cost representative is chosen, provided congruence soundness holds.

**Lean-style target**
```lean
theorem optimal_extract_semantics_unique
  {Term : Type u} {α : Type v}
  (s : Setoid Term)
  (eval : Term → α)
  (cost : Term → ℕ)
  (t₁ t₂ : Term)
  (hrel : s.r t₁ t₂)
  (hmin₁ : ∀ t, s.r t t₁ → cost t₁ ≤ cost t)
  (hmin₂ : ∀ t, s.r t t₂ → cost t₂ ≤ cost t)
  (h_sound : ∀ {a b : Term}, s.r a b → eval a = eval b) :
  eval t₁ = eval t₂
```

**Why this matters.**  
This proves that cost optimization is semantically harmless inside a sound e-class. It bridges quotient semantics with algorithmic optimization and explains why “best term extraction” is mathematically meaningful, not just operationally useful.

## Stronger Conjectural Frontier

Go beyond exact sections. Introduce a notion of **approximate quotient section** for incomplete saturation or heuristic extraction.

### New concept
Define something like:
```lean
def ApproximateSection
  (err : α → α → Prop)
  (eval : Term → α)
  (extract : Quotient s → Term) : Prop :=
  ∀ q t, Quotient.mk _ t = q → err (eval (extract q)) (eval t)
```

Then formulate a falsifiable conjecture:

> **Conjecture (Approximate Section Stability).**  
> For finite equational theories over finite signatures, if an e-graph is partially saturated to depth `k` and extraction is locally cost-optimal, then the extracted term is an approximate section of the semantic quotient, with approximation error monotonically decreasing as `k` increases.

This is scientifically valuable because it predicts a measurable convergence phenomenon for incomplete equality saturation.

### Testable prediction
Implement the computational test:

- Generate random expressions over 3 variables of depth `≤ 5`.
- Use associative and commutative axioms.
- Build random partially saturated e-graphs.
- Extract minimal-cost representatives.
- Compare:
  1. extracted evaluation,
  2. direct normalization evaluation,
  3. original term evaluation,
  over 10,000 random inputs in random finite commutative semigroups or semirings.

**Disproof criterion:** any semantic mismatch in a model satisfying the axioms refutes correctness; any monotonicity failure refutes the approximation conjecture.

This is excellent because it is not vague exploration; it is a crisp falsifiable scientific hypothesis.

## Proof Strategy Architecture

You must include 2–3 serious proof routes and choose the most promising.

### Strategy A: Quotient-universal property route
1. Define the e-graph relation as a setoid/congruence on terms.
2. Prove evaluation respects the relation using congruence soundness.
3. Apply quotient factorization (`commNorm_factors_through_quotient` as model).
4. Show any section-like extraction preserves the factored semantic value.

**Why promising:** This is the cleanest and most reusable route. It aligns directly with the catalog theorem `commNorm_factors_through_quotient` and converts extraction correctness into a universal property argument.

---

### Strategy B: Representative-chasing route
1. For each quotient class `q`, choose a witness term `t`.
2. Use the section property or representative-membership lemma to show `extract q ~ t`.
3. Apply congruence soundness to derive semantic equality.
4. Use transitivity to compare extracted term with any class member.

**Why promising:** More elementary and likely easier to formalize if quotient APIs are awkward. This route will likely require `rcases`, `induction_on`, and explicit congruence reasoning.

---

### Strategy C: Cost-optimal dynamic programming route
1. Define recursive cost over term DAGs/e-classes.
2. Prove extraction returns a minimal representative by induction over e-class dependency order.
3. Use soundness to prove all minima have equal semantics.
4. Derive correctness of cost-optimal extraction.

**Why promising:** Best for the algorithmic theorem. This is the route that makes the result useful for compiler extraction and not merely for abstract quotients.

**Recommended priority:** A first, B as fallback, C for the algorithmic capstone.
