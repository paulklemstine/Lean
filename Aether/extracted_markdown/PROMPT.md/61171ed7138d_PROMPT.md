## Assignment: Tropical Sudoku: Min-Plus Constraint Satisfaction and Phase Transitions

**Mode:** `prove`

You are not being asked for a toy encoding of Sudoku into a cost function. You are being asked to carve out a mathematically sharp theory in which Sudoku becomes a genuine min-plus constraint system, with a rigorously defined propagation operator, a monotonicity/termination theorem, and a threshold theorem for random partially revealed grids. The target is a new bridge between tropical algebra, finite CSP theory, random combinatorial structures, and algorithmic phase transitions.

The original vision is bold but too informal. Your task is to replace slogans with exact formal statements that can live in Lean 4 and survive contact with Mathlib.

## Core Program

Formalize a finite `n^2 × n^2` Sudoku universe, define a tropical violation functional on candidate assignments, prove that zero tropical cost is equivalent to satisfiability, define a propagation operator on cell-candidate sets, prove soundness and polynomial-time convergence of propagation, and isolate a mathematically provable monotone phase-transition surrogate for random clue density.

Do **not** overclaim “the hardest Sudokus are exactly those at the threshold” in full empirical complexity-theory generality unless you can define and prove a precise finite theorem. Instead, prove a rigorous theorem of the form:

- there is a monotone family of random Sudoku-instance models,
- satisfiability probability is monotone in clue density,
- the expected propagation closure size / contradiction probability exhibits a sharp transition window in a finite surrogate model,
- maximal ambiguity or maximal propagation depth occurs in a boundary regime.

That is already a field-opening bridge if formalized cleanly.

## Precise Mathematical Targets

### 1. Tropical encoding of Sudoku satisfiability

Define a finite Sudoku board of order `n` as assignments
`x : Fin (n^4) → Fin (n^2)` after choosing a standard encoding of cells into row/column coordinates.

Define the set of Sudoku constraints:
- row uniqueness,
- column uniqueness,
- box uniqueness,
- compatibility with givens.

Define a min-plus tropical cost:
- each violated atomic constraint contributes cost `1`,
- each satisfied atomic constraint contributes cost `0`,
- total cost is the tropical sum realized here as ordinary addition on `ℕ`,
- conjunction of constraints is represented by additive aggregation, compatible with tropical semiring intuition.

Then prove:

**Theorem A (zero cost iff valid Sudoku).**
For every Sudoku instance `I` and assignment `x`, the tropical violation cost is `0` if and only if `x` is a valid solution of `I`.

A plausible Lean shape:

```lean
structure SudokuInstance (n : ℕ) where
  givens : Fin (n^4) → Option (Fin (n^2))

def SudokuAssignment (n : ℕ) := Fin (n^4) → Fin (n^2)

def sudokuViolationCost (n : ℕ) (I : SudokuInstance n) (x : SudokuAssignment n) : ℕ := ...

def ValidSudoku (n : ℕ) (I : SudokuInstance n) (x : SudokuAssignment n) : Prop := ...

theorem sudoku_violationCost_eq_zero_iff
    (n : ℕ) (I : SudokuInstance n) (x : SudokuAssignment n) :
    sudokuViolationCost n I x = 0 ↔ ValidSudoku n I x
```

This is the indispensable foundation. It turns Sudoku from a recreational object into a certified tropical feasibility problem.

### 2. Tropical propagation as a monotone closure operator

Instead of assigning a single digit to each cell, consider candidate sets:

```lean
def CandidateState (n : ℕ) := Fin (n^4) → Finset (Fin (n^2))
```

Define a one-step propagation operator `propagateOnce` removing candidates forbidden by:
- givens,
- row singleton exclusions,
- column singleton exclusions,
- box singleton exclusions.

Then prove:

**Theorem B1 (soundness).**
Every genuine solution remains inside every propagated candidate set.

```lean
def RespectsState (n : ℕ) (x : SudokuAssignment n) (S : CandidateState n) : Prop :=
  ∀ c, x c ∈ S c

def propagateOnce (n : ℕ) (I : SudokuInstance n) (S : CandidateState n) : CandidateState n := ...

theorem propagateOnce_sound
    (n : ℕ) (I : SudokuInstance n) (S : CandidateState n) (x : SudokuAssignment n)
    (hx : ValidSudoku n I x) (hS : RespectsState n x S) :
    RespectsState n x (propagateOnce n I S)
```

**Theorem B2 (monotonicity).**
Propagation is antitone with respect to candidate inclusion and inflationary in information order.

```lean
def StateLe (n : ℕ) (S T : CandidateState n) : Prop :=
  ∀ c, S c ⊆ T c

theorem propagateOnce_mono
    (n : ℕ) (I : SudokuInstance n) :
    Monotone (propagateOnce n I)
```

You may need the opposite order convention depending on whether “more informative” means smaller sets.

**Theorem B3 (termination by finite descent).**
Iterated propagation reaches a fixed point in at most `n^6` candidate deletions, hence in polynomial time.

```lean
def candidateVolume (n : ℕ) (S : CandidateState n) : ℕ :=
  ∑ c, (S c).card

theorem propagate_terminates_poly
    (n : ℕ) (I : SudokuInstance n) (S : CandidateState n) :
    ∃ k ≤ n^6, Function.IsFixedPt (Nat.iterate (propagateOnce n I) k S)
```

The exact exponent may vary with your implementation. What matters is a formally proved polynomial bound from finiteness plus strict decrease of a volume potential whenever the state changes.

This is a genuine algorithmic theorem, not a metaphor.

### 3. Tropical contradiction detection

Define the tropical inconsistency of a candidate state by assigning infinite/positive penalty when a cell loses all candidates. In Lean, remain in `ℕ` first and simply define contradiction as emptiness.

Prove:

**Theorem C (propagation completeness for forced contradiction).**
If propagation reaches a state with an empty candidate set, then the Sudoku instance is unsatisfiable.

```lean
def Contradictory (n : ℕ) (S : CandidateState n) : Prop :=
  ∃ c, (S c).card = 0

theorem contradiction_of_propagation
    (n : ℕ) (I : SudokuInstance n) (S : CandidateState n)
    (h : Contradictory n (propagateOnce n I S)) :
    ¬ ∃ x, ValidSudoku n I x
```

This follows from soundness: any true solution would have to survive propagation.

### 4. A rigorous phase-transition surrogate theorem

A full sharp-threshold theorem for genuine random Sudoku is likely too ambitious for a first Lean formalization. Replace it by a mathematically precise monotone random model and prove threshold behavior for a surrogate observable.

Define a random instance model abstractly by selecting a set of givens of cardinality `k` from a fixed valid completed Sudoku solution `σ`, then asking about candidate propagation on the induced puzzle.

Let:
- `μ_k` be the uniform distribution on `k` revealed cells from `σ`,
- `P_k` be the probability that propagation solves the entire puzzle,
- or `Q_k` the probability that propagation derives contradiction for a random inconsistent clue pattern,
- or `A_k` the expected number of undecided cells after closure.

Prove monotonicity:

**Theorem D1 (monotonicity in clue density).**
More givens cannot hurt propagation.

```lean
theorem propagation_monotone_in_givens
    (n : ℕ) (σ : SudokuAssignment n) :
    Monotone (fun k => solvedByPropagationProbability n σ k)
```

If full probability formalization is too heavy, prove the combinatorial monotonicity statement pointwise for clue sets `G ⊆ H`.

```lean
theorem closure_monotone_under_more_givens
    (n : ℕ) (I J : SudokuInstance n)
    (hsub : ∀ c v, I.givens c = some v → J.givens c = some v) :
    StateLe n (closureState n J) (closureState n I)
```

Then derive a threshold surrogate using finite monotone Boolean function machinery if available, or prove existence of a crossing index by monotonicity on the finite chain `k = 0, …, n^4`:

**Theorem D2 (finite threshold index).**
For every target level `α`, there exists a clue density index where the propagation-solved proportion crosses `α`.

```lean
theorem exists_threshold_index
    (n : ℕ) (σ : SudokuAssignment n) (α : ℚ)
    (hα0 : 0 < α) (hα1 : α < 1) :
    ∃ k : ℕ, k ≤ n^4 ∧
      solvedByPropagationProbability n σ k ≤ α ∧
      α ≤ solvedByPropagationProbability n σ (k+1)
```

If probability formalization is infeasible, replace this with a finite counting ratio over all `k`-subsets of cells. This is still mathematically meaningful and Lean-friendly.

### 5. Boundary hardness as maximal residual ambiguity

The slogan “hardest Sudokus are exactly those at the tropical phase boundary” should be formalized as a theorem about a measurable surrogate of hardness. A good surrogate is the residual search space after propagation.

Define:
- `residualVolume(I)` = total number of remaining candidates after closure,
- or `branchingComplexity(I)` = product / log-product of candidate counts over unsolved cells,
- or `propagationDepth(I)` = least number of propagation rounds to reach closure.

Then prove a finite extremal theorem:

**Theorem E (boundary maximizes residual ambiguity in a monotone family).**
In a nested clue family extracted from a fixed solution, the residual ambiguity is maximized at an index adjacent to the satisfiability/uniqueness transition.

A realistic Lean statement:

```lean
def residualVolumeAfterClosure (n : ℕ) (I : SudokuInstance n) : ℕ := ...

theorem maximal_ambiguity_near_threshold
    (n : ℕ) (σ : SudokuAssignment n) :
    ∃ k ≤ n^4,
      IsLocalMax (fun t => averageResidualVolume n σ t) k ∧
      NearThresholdIndex n σ k
```

If this exact statement is too heavy, prove a weaker but clean version:
- residual ambiguity is nonincreasing in the number of givens,
- therefore the largest search space among satisfiable instances occurs at minimal clue density within the satisfiable regime.

That weaker theorem is still a rigorous version of “hardness concentrates near the boundary.”

The catalog theorems are abstract and possibly not directly about Sudoku, but they can still guide algebraic organization.

1. **`tropical_min_associative`**
   Use this as a semantic justification that aggregation of local tropical penalties is well behaved under regrouping. Even if your final cost uses `Nat` addition more than `min`, build a lemma that local elimination order does not affect closure or violation aggregation structure.

   This is highly relevant if you define candidate elimination costs or dynamic programming over candidate states via tropical Bellman-style recurrences. A strong angle is to express propagation as repeated local min-plus relaxation over hyperedges of the Sudoku constraint graph.

## Proof Strategy Architecture

### Strategy A: Finite CSP + tropical penalty exactness
Most promising for Theorem A.

1. Define all atomic Sudoku constraints as decidable predicates on assignments.
2. Define `sudokuViolationCost` as a finite sum of `0/1` penalties over all atomic constraints.
3. Prove each summand is nonnegative and equals `0` iff the corresponding atomic constraint holds.
4. Conclude the total sum is `0` iff every atomic constraint holds.

Why promising: this is robust, elementary, and ideal for Lean. It avoids forcing a heavy tropical-semiring abstraction too early while still delivering the conceptual bridge.

---

### Strategy B: Constraint hypergraph + monotone closure operator
Most promising for Theorems B and C.

1. Encode Sudoku as a finite hypergraph where each row/column/box-digit incidence gives a local exclusion rule.
2. Define propagation as intersection of candidate sets with the fixed-point image of all local exclusion maps.
3. Prove monotonicity by pointwise set inclusion.
4. Prove termination by a strictly decreasing potential `candidateVolume`.
5. Prove soundness by showing each local rule preserves all genuine solutions.

Why promising: this is the cleanest route to a polynomial-time theorem and naturally connects to arc consistency, abstract interpretation, and lattice fixed-point theory.

---

### Strategy C: Monotone family threshold theorem via finite counting
Most promising for Theorem D.

1. Fix a completed solution `σ`.
2. For each `k`, enumerate all `k`-subsets of revealed cells and define a finite counting ratio of those puzzles solved by propagation.
3. Prove monotonicity under adding givens.
4. Use finiteness of the chain `0,1,...,n^4` to obtain a threshold index by discrete intermediate-value logic for monotone sequences.
5. If possible, strengthen to concentration or local maximal ambiguity near the crossing.

Why promising: this avoids full measure-theoretic probability while preserving the exact combinatorial essence of phase transition.

## Cross-Domain Connections You Must Exploit

### 1. Statistical mechanics
Interpret `sudokuViolationCost` as a Hamiltonian on a finite spin system:
- cells are spins,
- digits are spin states,
- constraints are interaction terms,
- zero-energy states are valid solutions.

This reframes Sudoku phase transition as a zero-temperature glass transition / constraint satisfaction threshold. Formalizing even the finite energy landscape language would open a route to certified complexity barriers and metastability-style theorems.

### 2. Tropical geometry and min-plus linearity
Treat candidate elimination as tropical message passing on a constraint hypergraph. This connects Sudoku to:
- min-plus dynamic programming,
- shortest-path semirings,
- tropical convexity,
- belief propagation in idempotent semirings.

A strong theorem here would suggest a general framework for “tropical CSP solvers” far beyond Sudoku.

### 3. Error-correcting codes / information theory
A completed Sudoku grid behaves like a highly structured codeword subject to local parity-like constraints. Givens are partial observations; propagation is a decoding procedure. This suggests a bridge to:
- peeling decoders,
- LDPC threshold phenomena,
- density evolution surrogates,
- data-processing style monotonicity of information under propagation.

If you can prove that more givens monotonically reduce residual entropy/candidate volume, that is already an information-theoretic statement in disguise.

### 4. Abstract interpretation / program analysis
Propagation closure is a monotone operator on a finite lattice of candidate states. Knaster–Tarski style fixed-point logic is nearby. A clean formalization could become a reusable framework for certified CSP propagation in Lean.
