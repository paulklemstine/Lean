### Theorem 1: Closure-generated universal approximation for positive continuous functions

A realistic theorem in Lean is to target a class generated from positive affine functions under multiplication, inversion/log, and exponentiation, then show it approximates positive continuous functions on a compact interval. If full generality is too heavy, prove a **constructive polynomial-to-EML reduction** and combine with polynomial density.

#### Mathematical statement
For every continuous `f : [a,b] → ℝ` with `δ ≤ f(x)` for all `x` and every `ε > 0`, there exists an EML expression `e` such that
\[
\sup_{x \in [a,b]} |f(x) - \llbracket e \rrbracket(x)| < \varepsilon.
\]
The positivity assumption is essential because `log` is only directly meaningful on positive functions; it also creates a natural multiplicative geometry.

A sharper multiplicative version:
\[
\sup_{x\in[a,b]} |\log f(x) - \log \llbracket e \rrbracket(x)| < \varepsilon,
\]
hence relative approximation:
\[
e^{-\varepsilon} f(x) \le \llbracket e \rrbracket(x) \le e^\varepsilon f(x).
\]

#### Suggested Lean 4 type signature
```lean
theorem eml_universal_approx_positive_interval
  (f : ℝ → ℝ) (a b δ eps : ℝ)
  (hab : a < b) (hδ : 0 < δ) (heps : 0 < eps)
  (hcont : Continuous f)
  (hpos : ∀ x, a ≤ x → x ≤ b → δ ≤ f x) :
  ∃ e : EMLExpr,
    UniformApproxOn f
      (fun x => e.eval (fun i => if i = 0 then x else 0))
      a b eps
```

#### Why this is a breakthrough
This upgrades universal approximation from “neural nets with activation σ are dense” to “a symbolic-transcendental closure system is dense with explicit multiplicative structure.” That opens a new route to **interpretable universal approximation** and to **closed-form scientific law discovery**.

### Theorem 2: Constructive compositional complexity bound

This theorem should formalize that if `f` and `g` have EML approximants of complexity `m` and `n`, then `f+g`, `f*g`, and under positivity assumptions `log ∘ f`, `exp ∘ f` have approximants with controlled complexity. Build explicitly on subadditivity.

#### Mathematical statement
If `f` and `g` admit `ε/2` approximants with EML description complexity at most `m` and `n`, then `f+g` admits an `ε` approximant with complexity `O(m+n)`. Likewise for products on bounded domains, with quantitative error propagation. For positive bounded-away-from-zero `f`, `log∘f` preserves approximability with controlled complexity.

#### Suggested Lean 4 type signature
```lean
theorem eml_description_complexity_add
  (f g : ℝ → ℝ) (a b eps : ℝ) (m n : ℕ)
  (heps : 0 < eps)
  (hm : eml_description_complexity f a b (eps / 2) ≤ m)
  (hn : eml_description_complexity g a b (eps / 2) ≤ n) :
  eml_description_complexity (fun x => f x + g x) a b eps ≤ m + n + 1
```

And multiplicative variant:
```lean
theorem eml_description_complexity_mul
  (f g : ℝ → ℝ) (a b eps B : ℝ) (m n : ℕ)
  (heps : 0 < eps) (hB : 0 ≤ B)
  (hfB : ∀ x, a ≤ x → x ≤ b → |f x| ≤ B)
  (hgB : ∀ x, a ≤ x → x ≤ b → |g x| ≤ B)
  (hm : eml_description_complexity f a b (eps / (2 * (B + 1))) ≤ m)
  (hn : eml_description_complexity g a b (eps / (2 * (B + 1))) ≤ n) :
  eml_description_complexity (fun x => f x * g x) a b eps ≤ m + n + 1
```

### Theorem 3: Depth upper bound from symbolic description complexity

This is the flagship complexity theorem. Do not promise exact Kolmogorov complexity unless formalized carefully; instead prove a theorem for the surrogate `eml_description_complexity`.

#### Mathematical statement
There exists a universal constant `C` such that for every function `f` in the EML-approximable class and every `ε > 0`,
\[
\mathrm{MinDepth}_{EML}(f,\varepsilon) \le C \cdot \frac{K_{EML}(f,\varepsilon)}{\varepsilon},
\]
where `K_EML` is the shortest EML symbolic description length, or a formally defined surrogate thereof.

In Lean, define:
```lean
def eml_min_depth (f : ℝ → ℝ) (a b eps : ℝ) : ℕ := ...
```

Then target:
```lean
theorem eml_min_depth_le_desc_complexity_over_eps
  (f : ℝ → ℝ) (a b eps : ℝ)
  (heps : 0 < eps) :
  ∃ C : ℝ,
    0 < C ∧
    (eml_min_depth f a b eps : ℝ) ≤ C * (eml_description_complexity f a b eps : ℝ) / eps
```

If constants are hard to identify canonically, prove a cleaner natural-number version:
```lean
theorem eml_min_depth_bigO
  (f : ℝ → ℝ) (a b : ℝ) :
  ∃ C : ℕ, ∀ eps : ℝ, 0 < eps →
    eml_min_depth f a b eps ≤ C * eml_description_complexity f a b eps.natCeil
```
But the real-valued bound is more scientifically meaningful.

#### Why this matters
This is the point where approximation theory meets algorithmic information. It suggests that “functions with short symbolic-transcendental descriptions” are exactly those that deep EML models learn efficiently. This would be a formal bridge between:
- symbolic regression,
- minimum description length,
- architecture design,
- and complexity-aware learning theory.

### Theorem 4: Information-theoretic cross-domain theorem

You are required to include a cross-domain theorem. Here is the most compelling one.

#### Mathematical statement
If an EML architecture of depth `d` approximates a target function to error `ε`, then under a suitable encoding/representation model, the retained information about the target’s symbolic description decays at most exponentially in depth, yielding a lower bound on required depth for high-description-complexity targets.

This can be formalized abstractly using the catalog theorem `info_decays_with_depth`.

#### Suggested Lean 4 type signature
```lean
theorem eml_depth_information_tradeoff
  (alpha : ℝ) (l : ℕ) (K : ℕ)
  (halpha0 : 0 ≤ alpha) (halpha1 : alpha ≤ 1) :
  alpha ^ l * K ≤ K
```

That bare theorem is too weak alone; you should wrap it in a domain-specific definition such as:
```lean
def retained_symbolic_information (alpha : ℝ) (l K : ℕ) : ℝ :=
  alpha ^ l * K
```

Then prove a meaningful monotonicity/decay statement and connect it to depth lower/upper bounds using:
- `info_decays_with_depth`
- `eml_depth_cheaper_than_width`

A more domain-specific theorem:
```lean
theorem retained_symbolic_information_monotone
  (alpha : ℝ) (l1 l2 K : ℕ)
  (halpha0 : 0 ≤ alpha) (halpha1 : alpha ≤ 1)
  (hle : l1 ≤ l2) :
  retained_symbolic_information alpha l2 K ≤ retained_symbolic_information alpha l1 K
```

Then interpret this as: deeper architectures compress symbolic information, so only functions with low effective EML description can be approximated at small depth without loss.

#### Cross-domain significance
This theorem ties **approximation theory** to **information theory**, making the project much bigger than universal approximation. It points toward a rigorous theory of **representation compression in transcendental networks**.

## Proof Strategy Options

You asked for 2–3 proof strategy steps; here are three viable routes.

### Strategy A: Stone–Weierstrass via polynomial embedding into EML
Most promising for a clean formal breakthrough.

1. Prove that every polynomial can be represented exactly, or arbitrarily well, by EML expressions using constants, variables, addition, and multiplication.
2. Invoke a density theorem for polynomials on compact intervals for continuous functions; for positive functions, optionally approximate `log f` polynomially and exponentiate back.
3. Use explicit error propagation through `exp`/`log` and structural complexity induction to extract complexity bounds.

Why this is promising:
- Polynomials are already the canonical dense subalgebra.
- EML contains polynomial operations for free.
- The positivity route via `log f` gives multiplicative approximation and a natural role for `exp` and `log`, making the theorem genuinely EML-specific rather than “polynomials in disguise.”

### Strategy B: Constructive partition-and-gate approximation
Potentially more algorithmic.

1. Approximate a continuous function by piecewise affine or piecewise polynomial functions on `[a,b]`.
2. Construct smooth EML “soft gates” using combinations of `exp` and `log` to localize regions.
3. Sum localized approximants and prove explicit size/depth bounds.

Why it matters:
- This yields an actual verified approximation algorithm.
- It makes the architecture look more like a neural computation graph.
- It may produce sharper depth-width tradeoffs than a pure density proof.

### Strategy C: Symbolic complexity induction
Best for the complexity theorems.

1. Define `EMLExpr`, `size`, `depth`, and the approximation predicate.
2. Prove closure lemmas: if `e₁` approximates `f` and `e₂` approximates `g`, then constructors approximate `f+g`, `fg`, `exp∘f`, and `log∘f` with quantitative error.
3. Use induction on symbolic descriptions and the catalog subadditivity theorem to obtain the depth/description upper bound.

Why this is essential:
- This is the route to the `O(K(f)/ε)`-type theorem.
- It gives a reusable formal language for future EML research.

Recommended combination:
- Use **Strategy A** for the universality theorem.
- Use **Strategy C** for the complexity theorem.
- Add a small component of **Strategy B** if you want a stronger demo/algorithm.

### Conjecture: EML description complexity predicts approximation depth better than width
For positive analytic targets on `[0,1]`, the empirically minimal EML depth needed for `ε`-approximation scales like
\[
\Theta(K_{EML}(f,\varepsilon)\log(1/\varepsilon)),
\]
while minimal width scales asymptotically worse.

Suggested formal statement in markdown, not necessarily Lean:
- For target family `f_n(x) = exp(p_n(x))` with `p_n` a degree-`n` polynomial of bounded coefficients,
  the minimal EML depth for sup-norm `ε`-approximation grows polynomially in `n` and logarithmically in `1/ε`,
  whereas width-only approximants require superlinear growth in `n`.

**Computational disproof test**:
1. Generate targets `f_n(x) = exp(p_n(x))`, `log(1+x+x^2)`, multiplicative compositions, etc.
2. Search over bounded-depth EML expression trees.
3. Measure smallest depth achieving uniform error ≤ `ε`.
4. Compare to width-limited baselines.

If the predicted scaling fails systematically on these target families, the conjecture is false.
