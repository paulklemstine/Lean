## Assignment: 2. Integrate Distributivity via Knuth–Bendix Completion

**Mode:** prove

Prove a genuinely new theorem package: a **canonical normalization theorem for the equational theory of tropical expressions generated by constants, variables, `min`, and `+`**, where `+` distributes over `min`. Do not stop at the scalar identity
`a + min(b,c) = min(a+b,a+c)`—that theorem already exists in the catalog. The breakthrough is to formalize the **completion-to-normal-form pipeline** and show that tropical terms admit a canonical “minimum of affine forms” representation.

This is not an incremental algebra lemma. It is the tropical analogue of passing from arbitrary ring expressions to canonical polynomial normal forms, or from Boolean formulas to DNF/CNF. If you can make this precise in Lean, you open a new formal bridge between **rewriting theory, tropical geometry, semiring normalization, optimization, and symbolic neural verification**.

### Precise Theorem Target

Define an inductive syntax of tropical expressions over variables indexed by `Fin n`:

- constants `c : ℝ`
- variables `x_i`
- binary `min`
- binary `+`

Interpretation is into functions `(Fin n → ℝ) → ℝ`.

Then define a normal-form datatype representing finite minima of affine forms:
- an affine form is a constant plus a finite sum of variable coefficients times variables,
- in the first version, it is acceptable to restrict to the **idempotent semilinear fragment generated syntactically**, where coefficients are natural multiplicities arising from repeated addition of variables.

A strong and realistic first breakthrough theorem is:

```lean
/-- Tropical expressions in variables `Fin n`. -/
inductive TropExpr (n : ℕ) where
  | const : ℝ → TropExpr n
  | var   : Fin n → TropExpr n
  | tmin  : TropExpr n → TropExpr n → TropExpr n
  | add   : TropExpr n → TropExpr n → TropExpr n

/-- Semantics of tropical expressions. -/
def TropExpr.eval {n : ℕ} : TropExpr n → (Fin n → ℝ) → ℝ
```

Define a normal form:

```lean
/-- An affine tropical monomial: constant plus multiplicities of variables. -/
structure AffineForm (n : ℕ) where
  constant : ℝ
  coeff    : Fin n → ℕ

/-- Evaluate an affine form. -/
def AffineForm.eval {n : ℕ} (a : AffineForm n) (x : Fin n → ℝ) : ℝ :=
  a.constant + ∑ i, (a.coeff i : ℝ) * x i

/-- A tropical normal form is a finite minimum of affine forms. -/
abbrev TropNF (n : ℕ) := List (AffineForm n)

/-- Evaluate a normal form as the minimum of its affine forms. -/
def TropNF.eval {n : ℕ} : TropNF n → (Fin n → ℝ) → ℝ
```

Then prove:

```lean
theorem exists_tropical_nf {n : ℕ} :
  ∀ e : TropExpr n, ∃ N : TropNF n, TropExpr.eval e = TropNF.eval N
```

The more revolutionary theorem, if you can reach it, is a canonicity theorem modulo permutation and dominated-term elimination:

```lean
/-- `normalize e` computes a canonical tropical normal form. -/
def normalize {n : ℕ} : TropExpr n → TropNF n

theorem normalize_sound {n : ℕ} (e : TropExpr n) :
  TropExpr.eval e = TropNF.eval (normalize e)

theorem normalize_complete {n : ℕ} (e₁ e₂ : TropExpr n) :
  normalize e₁ = normalize e₂ ↔ TropExpr.eval e₁ = TropExpr.eval e₂
```

If full completeness is too ambitious at first, prove the one-way canonicality theorem:

```lean
theorem normalize_eq_of_semantic_eq
  {n : ℕ} {e₁ e₂ : TropExpr n}
  (h : TropExpr.eval e₁ = TropExpr.eval e₂) :
  normalize e₁ = normalize e₂
```

under a suitably strengthened canonicalization invariant, such as sorted lists with duplicate and domination elimination.

### Core theorem architecture

The deepest mathematically meaningful formalization target is the following equivalence:

> Every tropical term built from constants, variables, `min`, and `+` denotes a piecewise-linear concave function equal to the minimum of finitely many affine forms with natural slope multiplicities, and this representation is computable by structural normalization.

This is a tropical analogue of:
- disjunctive normal form in logic,
- multivariate polynomial expansion in commutative algebra,
- support-function decomposition in convex analysis.

### Proof Strategy A: Structural normalization by semantics-preserving compilation
**Most promising for Lean.**

Instead of formalizing a full abstract Knuth–Bendix completion engine first, define normalization recursively and prove it computes the completed form.

1. **Define normal forms and their operations.**
   - `const` becomes singleton affine form.
   - `var i` becomes singleton affine form with coefficient 1 on `i`.
   - `tmin` becomes list concatenation followed by canonicalization.
   - `add` becomes tropical convolution / Minkowski sum of affine forms:
     every affine form in `N₁` added to every affine form in `N₂`.

2. **Prove semantic soundness of NF operations.**
   - `eval (mergeMin N₁ N₂) = min (eval N₁) (eval N₂)` via `inf`/list-min semantics.
   - `eval (addNF N₁ N₂) = eval N₁ + eval N₂`, using distributivity:
     `a + min_j b_j = min_j (a + b_j)` and then iterating on both sides.

3. **Define `normalize` by recursion and prove soundness.**
   - This bypasses explicit termination/confluence of a rewrite relation while still delivering the canonical completed form.
   - After soundness, add sorting/dedup/dominance elimination to move toward uniqueness.

Why this is best: Lean handles recursive compilation plus semantic invariants much more smoothly than a first-principles critical-pair development. You still realize the Knuth–Bendix vision, but as a certified compiler to completed normal forms.

### Proof Strategy B: Explicit rewrite system with termination + local confluence
**Conceptually purer, more rewriting-theoretic, but heavier.**

Orient the equations:
- associativity/commutativity/idempotence of `min` handled by quotienting or AC-normalized syntax,
- associativity/commutativity of `+` handled similarly,
- distributivity oriented as pushing `+` below `min`:
  `add a (tmin b c) → tmin (add a b) (add a c)`
  and symmetrically in the left argument if desired.

Then:

1. **Termination.**
   Define a measure such as the total number of `add` nodes lying above some `min` node, or a multiset path ordering. Show each distributive rewrite strictly decreases this measure once AC reassociation is normalized.

2. **Local confluence.**
   Analyze critical pairs between:
   - two distributivity redexes,
   - distributivity and AC-normalization,
   - nested `min` idempotence/associativity interactions.
   The key joinability lemma will mirror the fact that distributing in different orders yields the same finite family of affine sums.

3. **Newman’s lemma.**
   Termination + local confluence gives confluence, hence unique normal forms.

This route is more “completion proper” and would be a landmark formalization if done cleanly. But it likely requires a robust AC rewriting infrastructure, so it may be better as phase two after Strategy A establishes the target normal forms.

### Proof Strategy C: Convex-analytic / support-set semantics
**Most visionary, potentially field-opening.**

Interpret each term not merely as a function but as a finite set of affine forms:
- `const c` ↦ `{c}`
- `var i` ↦ `{x_i}`
- `min` ↦ union
- `+` ↦ Minkowski sum of support sets

Then prove:
- evaluation of a support set is the minimum of evaluations of its members,
- syntactic `+` corresponds to setwise addition of affine forms,
- syntactic `min` corresponds to union,
- canonicalization corresponds to removing dominated affine forms.

This reframes normalization as a theorem about **finite tropical support sets**, connecting directly to Newton polytopes, Legendre–Fenchel style duality, and idempotent analysis. In Lean, this may simplify the semantics by making distributivity tautological at the support-set level.

### Critical design choices

- **Do not model full real coefficients on variables at first.** Natural multiplicities from repeated addition are enough for a strong theorem and avoid introducing general linear algebra too early.
- **Represent minima as finite lists**, but quickly impose a canonical ordering if you want equality of normal forms rather than permutation equivalence.
- **Prefer semantic evaluation into functions** `(Fin n → ℝ) → ℝ`; function extensionality will likely be needed.
- **Treat `min` as idempotent but `+` as non-cancellative**—the theorem `tropical_add_not_cancellative` should shape your proof philosophy.

### Cross-domain connections to emphasize in the development

1. **Gröbner / Buchberger analogy**
   Completion here plays the role of deriving canonical representatives in a quotient theory. The tropical normal form is a semiring-theoretic cousin of reduced Gröbner normal form.

2. **Boolean logic analogy**
   `min` behaves like conjunction/disjunction under idempotent semantics depending on convention; distributive expansion produces a tropical DNF/CNF-like representation.

3. **Convex geometry / tropical geometry**
   A minimum of affine forms is exactly a piecewise-linear concave function. Normal forms therefore encode tropical hypersurfaces, polyhedral complexes, and lower hull combinatorics.

4. **Optimization and control**
   Min-plus algebra underlies shortest paths, dynamic programming, and deterministic control. A certified normalizer becomes a symbolic optimizer.

5. **Neural networks**
   Tropicalized ReLU/max-affine/min-affine models can be symbolically normalized, enabling certified equivalence and robustness transformations.

6. **Type theory / proof automation**
   A canonical normalizer for idempotent semirings can become a `norm_tropical` tactic, potentially a new automation layer in Lean for tropical mathematics.
