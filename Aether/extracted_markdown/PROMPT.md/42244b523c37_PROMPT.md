# Schanuel's Conjecture: Formalization and Conditional Results

This file formalizes Schanuel's Conjecture — one of the central open problems in
transcendental number theory — and proves that it implies several classical
transcendence results, including the Hermite-Lindemann theorem (single case)
and the transcendence of e.

## Main definitions

* `SchanuelProperty` : The formal statement of Schanuel's Conjecture: if z₁,...,zₙ
  are ℚ-linearly independent complex numbers, then
  trdeg_ℚ ℚ(z₁,...,zₙ,e^z₁,...,e^zₙ) ≥ n.

## Main results

* `schanuel_implies_hermite_lindemann_single` : Schanuel's Conjecture implies that
  for any nonzero algebraic number α, exp(α) is transcendental over ℚ.
* `schanuel_implies_e_transcendental` : Schanuel's Conjecture implies e is
  transcendental over ℚ.
* `algebraic_set_adjoin_trdeg_zero` : If every element of a set S is algebraic
  over ℚ, then Algebra.trdeg ℚ (Algebra.adjoin ℚ S) = 0.

## References

* S. Lang, "Introduction to Transcendental Numbers", 1966
* M. Waldschmidt, "Diophantine Approximation on Linear Algebraic Groups", 2000
-/

import Mathlib

open Complex Cardinal

noncomputable section

/-!
## Schanuel's Conjecture

The conjecture states: if z₁,...,zₙ are complex numbers that are ℚ-linearly
independent, then the transcendence degree of ℚ(z₁,...,zₙ,e^z₁,...,e^zₙ)
over ℚ is at least n.
-/

/-- **Schanuel's Conjecture**: For any n complex numbers z₁,...,zₙ that are
linearly independent over ℚ, the transcendence degree of the field generated
by z₁,...,zₙ,exp(z₁),...,exp(zₙ) over ℚ is at least n.

This is stated for an arbitrary finite indexing type `Fin n`. The set of
generators is `{z i | i} ∪ {exp (z i) | i}`, and we require that the
transcendence degree of their ℚ-adjoin is at least n. -/
def SchanuelProperty : Prop :=
  ∀ (n : ℕ) (z : Fin n → ℂ),
    LinearIndependent ℚ z →
    (n : Cardinal) ≤
      Algebra.trdeg ℚ
        (Algebra.adjoin ℚ (Set.range z ∪ Set.range (fun i => exp (z i))))

/-!
## Structural lemma: algebraic generators yield trdeg 0

This is the key algebraic ingredient: if every generator of a ℚ-subalgebra
of ℂ is algebraic over ℚ, then the whole subalgebra is algebraic, hence
has transcendence degree 0.
-/

/-
If every element of S ⊆ ℂ is algebraic over ℚ, then the ℚ-subalgebra
generated by S has transcendence degree 0 over ℚ.
-/
theorem algebraic_set_adjoin_trdeg_zero (S : Set ℂ) (hS : ∀ x ∈ S, IsAlgebraic ℚ x) :
    Algebra.trdeg ℚ (Algebra.adjoin ℚ S) = 0 := by
  convert trdeg_eq_zero_iff.mpr _;
  refine' ⟨ fun x => _ ⟩;
  -- Since every element of $S$ is algebraic over $\mathbb{Q}$, the subalgebra generated by $S$ is also algebraic over $\mathbb{Q}$.
  have h_alg : ∀ x ∈ Algebra.adjoin ℚ S, IsAlgebraic ℚ x := by
    intro x hx; induction hx using Algebra.adjoin_induction ; aesop;
    · exact isAlgebraic_algebraMap _;
    · exact IsAlgebraic.add ‹_› ‹_›;
    · exact IsAlgebraic.mul ‹_› ‹_›;
  convert h_alg x x.2;
  constructor <;> rintro ⟨ p, hp, hp' ⟩ <;> use p <;> aesop

/-!
## SC implies Hermite-Lindemann (single element case)

If Schanuel's Conjecture holds and α is a nonzero algebraic complex number,
then exp(α) is transcendental over ℚ.

The proof: since α ≠ 0, the singleton {α} is ℚ-linearly independent.
Applying SC with n = 1 gives trdeg ℚ(α, exp(α)) ≥ 1. If exp(α) were
algebraic, then since α is also algebraic, every generator of ℚ(α, exp(α))
would be algebraic, giving trdeg = 0 — a contradiction.
-/

/-
!-- The proof uses SC with n=1 and z(0) = α. Linear independence of {α}
follows from α ≠ 0 and torsion-freeness. The contradiction comes from
algebraic_set_adjoin_trdeg_zero applied to {α, exp(α)}. -- !--

**Schanuel implies Hermite-Lindemann (single case)**: If Schanuel's Conjecture
holds and α is a nonzero complex number algebraic over ℚ, then exp(α) is
transcendental over ℚ.
-/
theorem schanuel_implies_hermite_lindemann_single
    (hSC : SchanuelProperty)
    (α : ℂ) (hα_ne : α ≠ 0) (hα_alg : IsAlgebraic ℚ α) :
    Transcendental ℚ (exp α) := by
  contrapose! hSC with h;
  unfold SchanuelProperty; push_neg; use 1; use ![α]; simp_all +decide [ Transcendental ] ;
  convert algebraic_set_adjoin_trdeg_zero _ _;
  aesop

/-
!-- Corollary: SC implies e is transcendental. Take α = 1, which is
nonzero and algebraic (it's rational), so exp(1) = e is transcendental. -- !--

**Schanuel implies e is transcendental**: If Schanuel's Conjecture holds,
then e = exp(1) is transcendental over ℚ.
-/
theorem schanuel_implies_e_transcendental (hSC : SchanuelProperty) :
    Transcendental ℚ (exp 1 : ℂ) := by
  -- Apply the schanuel_implies_hermite_lindemann_single theorem with α = 1.
  apply schanuel_implies_hermite_lindemann_single hSC 1 (by norm_num) (by exact isAlgebraic_one)

/-!
## Examples and boundary analysis
-/

/-
Example: 1 is algebraic over ℚ (it is rational).
-/
example : IsAlgebraic ℚ (1 : ℂ) := by
  exact isAlgebraic_one

/-
Example: the singleton {α} is ℚ-linearly independent when α ≠ 0,
since ℂ is torsion-free over ℚ.
-/
example (α : ℂ) (hα : α ≠ 0) :
    LinearIndependent ℚ (fun (_ : Fin 1) => α) := by
  rw [ linearIndependent_unique_iff ] ; aesop

/-!
## Generalizations (stated, not fully proved)

These are natural extensions of the above results.
-/

/-- **Generalization**: SC implies the full Lindemann-Weierstrass theorem
for n algebraic numbers: if α₁,...,αₙ are ℚ-linearly independent algebraic
numbers, then exp(α₁),...,exp(αₙ) are algebraically independent over ℚ. -/

    (n : ℕ) (α : Fin n → ℂ)
    (hα_li : LinearIndependent ℚ α)
    (hα_alg : ∀ i, IsAlgebraic ℚ (α i)) :
    AlgebraicIndependent ℚ (fun i => exp (α i)) := by
  sorry

/-
**Boundary**: Schanuel's Conjecture is tight — the bound n cannot be
improved to n+1 in general. For example, with z = (1), the set {1, e} generates
a field of trdeg exactly 1 (assuming e is transcendental), not 2.
-/
theorem schanuel_bound_tight_example
    (h_e_trans : Transcendental ℚ (exp 1 : ℂ)) :
    Algebra.trdeg ℚ (Algebra.adjoin ℚ ({1, exp 1} : Set ℂ)) ≤ 1 := by
  rw [ show Algebra.adjoin ℚ { 1, cexp 1 } = Algebra.adjoin ℚ { cexp 1 } from ?_ ];
  · -- The range of the polynomial evaluation at $e$ is isomorphic to the polynomial ring $\mathbb{Q}[x]$.
    have h_iso : Nonempty (↥(Algebra.adjoin ℚ {Complex.exp 1}) ≃ₐ[ℚ] Polynomial ℚ) := by
      refine' ⟨ _ ⟩;
      symm;
      refine' ( AlgEquiv.ofBijective _ ⟨ _, _ ⟩ );
      refine' ( Polynomial.aeval _ );
      exact ⟨ Complex.exp 1, Algebra.subset_adjoin rfl ⟩;
      · intro p q h_eq;
        exact Classical.not_not.1 fun h => h_e_trans <| by exact ⟨ p - q, sub_ne_zero_of_ne h, by simpa [ sub_eq_zero ] using congr_arg Subtype.val h_eq ⟩ ;
      · intro x;
        rcases x with ⟨ x, hx ⟩;
        rw [ Algebra.adjoin_singleton_eq_range_aeval ] at hx;
        obtain ⟨ p, rfl ⟩ := hx; use p; aesop;
    have := h_iso.some;
    rw [ this.trdeg_eq ];
    simp +zetaDelta at *;
  · refine' le_antisymm _ _ <;> simp +decide

end

# Future Directions: Schanuel's Conjecture Formalization

## 1. Full Lindemann-Weierstrass from Schanuel

The natural next step is proving `schanuel_implies_lindemann_weierstrass_full` — that Schanuel's Conjecture implies the full Lindemann-Weierstrass theorem: if α₁,...,αₙ are ℚ-linearly independent algebraic numbers, then exp(α₁),...,exp(αₙ) are algebraically independent over ℚ. The key insight is that this requires a "trdeg tower" lemma: if S ⊆ T generates an algebra where every element of S is algebraic, then trdeg(adjoin T) = trdeg(adjoin (T \ S)). This should follow from `Algebra.IsAlgebraic` transitivity properties already in Mathlib but requires careful subalgebra manipulation. Why now? The infrastructure for `AlgebraicIndependent` and `trdeg` in Mathlib is mature enough to support this argument, and the single-element case proved here validates the approach.

## 2. Schanuel implies algebraic independence of e and π

Conjecture: Under `SchanuelProperty`, the pair (e, π) is algebraically independent over ℚ. The proof would use SC with z = (1, iπ), observing that these are ℚ-linearly independent and exp gives (e, -1). Since -1 and 1 are rational, the trdeg ≥ 2 must come from e and iπ. The key insight is that algebraic independence of {e, iπ} over ℚ implies algebraic independence of {e, π} because i is algebraic over ℚ, so ℚ(e, iπ) is algebraic over ℚ(e, π) and vice versa. Why now? This would connect the formalization to one of the most famous open problems in number theory (whether e + π is irrational), demonstrating the power of SC as a unifying principle.

## 3. Conditional transcendence of iterated exponentials

Conjecture: Under `SchanuelProperty`, for any nonzero algebraic α, the tower e, eᵉ, eᵉᵉ, ... consists of algebraically independent elements. The key insight is that SC can be applied iteratively: at each stage, the previous tower elements are transcendental (by the Hermite-Lindemann consequence), and the new element exp(previous) adds a fresh transcendence degree because the previous elements, while transcendental, are "independent" from the exponential of the new input. Why now? The Hermite-Lindemann single case is now proved, providing the base case for the induction. The main challenge is formalizing the "cumulative independence" argument.

## 4. Unconditional results: direct proof of e transcendence

Rather than assuming SC, prove the transcendence of e directly in Lean using Hermite's classical argument (1873). The key insight is that Hermite's proof uses only integer polynomial evaluations and factorial divisibility — no advanced algebra. Specifically, for any polynomial f(x) with integer coefficients, the integral ∫₀^∞ f(t)e⁻ᵗ dt can be evaluated in terms of f and its derivatives at 0, leading to a contradiction if e = p/q. Why now? Mathlib has the necessary integration theory (`MeasureTheory.integral`) and polynomial infrastructure. This would complement the conditional results by providing an unconditional anchor point.
