### Research Direction

Formalize and prove a precise local functoriality theorem for **symmetric square transfer** from 2-dimensional Satake parameters to 3-dimensional Euler factors. Do this first in a purely algebraic setting over `ℂ` (or a Lean-friendly algebraically closed field if needed), using diagonal/semisimple matrices as unramified local parameters.

### Precise Theorem Targets

#### Target A: Local symmetric-square Euler factor identity

Define a local rank-2 parameter by a pair `(α β : ℂ)`. Define
\[
L_p(X;\alpha,\beta) := \frac{1}{(1-\alpha X)(1-\beta X)}
\]
and
\[
L_p^{\mathrm{sym2}}(X;\alpha,\beta) := \frac{1}{(1-\alpha^2 X)(1-\alpha\beta X)(1-\beta^2 X)}.
\]

Prove the exact denominator identity
\[
(1-\alpha^2 X)(1-\alpha\beta X)(1-\beta^2 X)
=
1-(\alpha^2+\alpha\beta+\beta^2)X+\alpha\beta(\alpha^2+\alpha\beta+\beta^2)X^2-(\alpha\beta)^3X^3.
\]

This gives a canonical Lean definition of the symmetric-square local factor as a cubic polynomial determined by the elementary symmetric data of the original parameter.

A Lean 4 signature target:

```lean
theorem symmSquare_local_denominator
    (α β X : ℂ) :
    (1 - α^2 * X) * (1 - (α * β) * X) * (1 - β^2 * X)
      =
    1 - (α^2 + α*β + β^2) * X
      + (α*β) * (α^2 + α*β + β^2) * X^2
      - (α*β)^3 * X^3 := by
```

Also prove the matrix/eigenvalue formulation if feasible:

```lean
theorem symmSquare_charpoly_diag
    (α β T : ℂ) :
    (T - α^2) * (T - α*β) * (T - β^2)
      =
    T^3 - (α^2 + α*β + β^2) * T^2
        + (α*β) * (α^2 + α*β + β^2) * T
        - (α*β)^3 := by
```

This is the exact cubic Hecke polynomial of the symmetric square lift.

#### Target B: Compatibility with determinant-one normalization

For the classical `GL(2)` / modular-form normalization, the central character often imposes \(\alpha\beta = 1\) after suitable scaling. In that case prove the simplified identity
\[
(1-\alpha^2 X)(1-X)(1-\beta^2 X)
=
1-(\alpha^2+1+\beta^2)X+(\alpha^2+1+\beta^2)X^2-X^3.
\]

Lean target:

```lean
theorem symmSquare_local_denominator_det_one
    (α β X : ℂ) (h : α * β = 1) :
    (1 - α^2 * X) * (1 - X) * (1 - β^2 * X)
      =
    1 - (α^2 + 1 + β^2) * X
      + (α^2 + 1 + β^2) * X^2
      - X^3 := by
```

This is the first genuinely automorphic-looking identity: the cubic local factor is palindromic under determinant-one normalization, echoing self-duality phenomena.

#### Target C: Finite Euler-product functoriality shadow

Define for a finite index set `S : Finset ι` with maps `α β : ι → ℂ`:
\[
L_S(X) = \prod_{v\in S}\frac{1}{(1-\alpha_v X)(1-\beta_v X)},
\qquad
L_S^{\mathrm{sym2}}(X)=\prod_{v\in S}\frac{1}{(1-\alpha_v^2 X)(1-\alpha_v\beta_v X)(1-\beta_v^2 X)}.
\]

Prove that the denominator of the finite symmetric-square Euler product factors pointwise through the local transfer map. At minimum:

```lean
theorem finite_symmSquare_eulerFactorization
    {ι : Type} (S : Finset ι) (α β : ι → ℂ) (X : ℂ) :
    (∏ v in S, ((1 - α v ^ 2 * X) * (1 - (α v * β v) * X) * (1 - β v ^ 2 * X)))
      =
    ∏ v in S,
      (1 - (α v ^ 2 + α v * β v + β v ^ 2) * X
         + (α v * β v) * (α v ^ 2 + α v * β v + β v ^ 2) * X^2
         - (α v * β v)^3 * X^3) := by
```

This theorem matters because it turns local functoriality into a finite global statement, the exact shape Lean can support before analytic convergence enters.

#### Target D: Representation-theoretic trace identity for Sym²

For a diagonal matrix \(g=\mathrm{diag}(\alpha,\beta)\), the trace of \(\mathrm{Sym}^2(g)\) is
\[
\operatorname{tr}(\mathrm{Sym}^2 g)=\alpha^2+\alpha\beta+\beta^2.
\]
Formalize `Sym²` first on diagonal data if full representation theory is too heavy.

Lean target:

```lean
def symmSquareTrace (α β : ℂ) : ℂ := α^2 + α*β + β^2

theorem symmSquareTrace_eq_trace_sq_minus_det
    (α β : ℂ) :
    symmSquareTrace α β = (α + β)^2 - α*β := by
```

and ideally

```lean
theorem symmSquareTrace_in_terms_of_trace_det
    (α β : ℂ) :
    α^2 + α*β + β^2 = (α + β)^2 - α*β := by
```

This is the bridge to Hecke eigenvalues: if \(a_p = \alpha+\beta\) and \(\omega_p=\alpha\beta\), then
\[
a_p^{(\mathrm{Sym}^2)} = a_p^2 - \omega_p.
\]
That is exactly the first coefficient relation of symmetric-square lifting.

### Mathematical Framing

The core idea is to avoid impossible analytic overhead at first and instead formalize the **unramified semisimple local packet** as algebraic spectral data. In the unramified local Langlands dictionary for `GL(n)`, a representation is encoded by a semisimple conjugacy class in the dual group. For `GL(2)`, this is represented by eigenvalues \(\alpha,\beta\). The symmetric-square transfer simply sends these eigenvalues to \(\alpha^2,\alpha\beta,\beta^2\), which defines a `GL(3)` parameter. The local \(L\)-factor is then the inverse characteristic polynomial at \(X=p^{-s}\).

Your task is to make this exact dictionary Lean-native.

### Proof Strategy Architecture

#### Strategy A: Direct polynomial expansion in `ring_nf`
Most promising for Targets A, B, D.

1. State identities over a commutative semiring/ring first if possible, then specialize to `ℂ`.
2. Use `ring_nf` / `ring` after normalizing powers and parenthesization.
3. Package the expanded cubic coefficients into reusable lemmas: coefficient of `X`, coefficient of `X^2`, constant term, cubic term.

Why promising: these theorems are exact algebraic identities, and Lean’s polynomial/ring normalization is strongest here. This minimizes sorry and creates robust reusable lemmas.

#### Strategy B: Characteristic-polynomial route via matrices
Most promising for a more conceptual theorem and future extensibility.

1. Define diagonal `2×2` matrix `diag α β`.
2. Define a diagonal `3×3` matrix with entries `α^2, αβ, β^2` as the symmetric-square shadow.
3. Compute the characteristic polynomial and show its coefficients equal the trace/determinant formulas from Target A/D.

Why promising: this aligns with the actual Langlands philosophy — semisimple conjugacy classes and characteristic polynomials. It prepares the ground for later replacing diagonal matrices by semisimple matrices up to conjugacy.

#### Strategy C: Symmetric-polynomial / invariant-theoretic route
Most visionary, best for follow-up generalization.

1. Express the symmetric-square coefficients in terms of \(e_1=\alpha+\beta\), \(e_2=\alpha\beta\).
2. Prove
   \[
   \alpha^2+\alpha\beta+\beta^2 = e_1^2 - e_2,
   \]
   and rewrite the full cubic denominator solely in terms of `trace` and `det`.
3. State a theorem showing the transfer depends only on the conjugacy-invariant data `(trace, det)`.

For example:
```lean
theorem symmSquare_denominator_in_trace_det
    (α β X : ℂ) :
    (1 - α^2 * X) * (1 - (α * β) * X) * (1 - β^2 * X)
      =
    1 - (((α + β)^2 - α*β) * X)
      + (α*β) * (((α + β)^2 - α*β)) * X^2
      - (α*β)^3 * X^3 := by
```

Why promising: this is the true conceptual content — functoriality respects invariant data. It is also the bridge to Hecke eigenvalues \(a_p\) and nebentypus \(\omega_p\).
