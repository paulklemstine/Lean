## Core Vision

Let `f_n : ZMod n → ZMod n` be the squaring map `x ↦ x^2`. Consider the functional graph of `f_n`, and especially the undirected graph obtained by forgetting orientation. The arithmetic structure of `n` should force spectral signatures:

- primes: few idempotents, highly centralized basin structure;
- composites with multiple prime factors: many idempotents, fragmented attractor structure;
- this fragmentation should force smaller expansion and smaller spectral gap.

The breakthrough theorem is not merely “composites have more fixed points.” It is that **arithmetic factorization creates graph bottlenecks**, and bottlenecks control the first nonzero Laplacian eigenvalue.

That is the field-opening claim.

   ```lean
   def idempotentSet (n : ℕ) : Set (ZMod n) := {x | x^2 = x}
   ```

3. **Undirected squaring adjacency**
   A symmetric adjacency relation on `ZMod n`:
   ```lean
   def SqAdj (n : ℕ) (x y : ZMod n) : Prop :=
     sqMap n x = y ∨ sqMap n y = x
   ```

4. **Basin of an idempotent**
   ```lean
   def basin (n : ℕ) (e : ZMod n) : Set (ZMod n) :=
     {x | ∃ k : ℕ, (sqMap n^[k]) x = e}
   ```
   If iteration notation is awkward, define recursively or via `Nat.iterate`.

5. **Idempotent separation property**
   A new structural notion expressing that distinct idempotents induce distinct forward basins:
   ```lean
   def IdempotentSeparated (n : ℕ) : Prop :=
     ∀ ⦃e₁ e₂ : ZMod n⦄, e₁ ≠ e₂ →
       e₁ ∈ idempotentSet n → e₂ ∈ idempotentSet n →
       Disjoint (basin n e₁) (basin n e₂)
   ```

6. **Combinatorial spectral proxy**
   Since full linear-algebraic Laplacian formalization may be too heavy for the first pass, define a graph bottleneck invariant or Cheeger-style ratio:
   ```lean
   def edgeBoundaryCard (n : ℕ) (S : Finset (ZMod n)) : ℕ := ...
   ```

   This is acceptable and scientifically valuable if you prove it detects compositeness structurally.

This is important: even if the full analytic eigenvalue formalization is deferred, you should prove theorems about a **certified combinatorial proxy** that is known in spectral graph theory to control the gap.

## Proof strategy architecture

You must include multi-step proofs. Here are the recommended routes.

### Strategy A: Arithmetic decomposition → idempotents → disjoint basins → sparse cut
**Most promising.** It uses the catalog directly and yields the strongest structural theorem with the least analytic overhead.

1. Use `nontrivial_idempotent_iff_multiple_prime_factors` and related catalog results to obtain distinct idempotents for composite `n` with at least two prime factors.
2. Prove that idempotents are fixed points of `sqMap`, and analyze forward orbits under iteration to show basin separation or at least basin distinguishability.
3. Construct a subset `S` as a basin or union of basins; show its edge boundary is small because edges mostly remain inside a basin.
4. Deduce an upper bound on your conductance proxy; interpret this as spectral-gap suppression.

Why this is strongest: it converts arithmetic factorization into an explicit graph cut, which is exactly the mechanism spectral theory needs.

---

### Strategy B: Chinese remainder theorem factorization of dynamics
This is conceptually beautiful and may produce the cleanest theorem.

1. Use the CRT decomposition
   \[
   \mathbb{Z}/n\mathbb{Z} \cong \prod_i \mathbb{Z}/p_i^{k_i}\mathbb{Z}
   \]
   and show the squaring map factors coordinatewise.
2. Prove that idempotents correspond to coordinate choices of `0` and `1` in squarefree directions, yielding a product attractor structure.
3. Show that the functional graph of `n` inherits a product-like decomposition from the coordinate dynamics.
4. Extract cuts from coordinate projections; argue that multiple prime factors induce product bottlenecks.

Why this is exciting: it reveals the spectral phenomenon as an arithmetic product-geometry effect, not an accident of numerics.

---

### Strategy C: Fixed-point subgraph and zero-eigenvalue multiplicity
This is the cleanest spectral foothold if full Cheeger formalization becomes unwieldy.

1. Define the induced subgraph on idempotents.
2. Prove distinct idempotents are isolated there, hence each contributes a separate connected component.
3. Use standard Laplacian folklore: connected component count equals zero-eigenvalue multiplicity for the induced subgraph.
4. Argue in paper/demo that increasing low-frequency mass in this subgraph predicts reduced ambient spectral gap.

Why this is useful: even if it falls short of a full spectral-gap theorem, it establishes a certified low-frequency obstruction created by compositeness.
