## Theorem 1: Symmetry, regularity, and connectivity of certified Cayley graphs

Formalize the Cayley graph from a certificate pair and prove basic but nontrivial structure theorems that will be used later.

### Suggested mathematical statement

For a finite group `G` and symmetric generating set `S` with `1 ∉ S`, the Cayley graph `Cayley(G,S)` is a connected `|S|`-regular undirected graph. Specialize to `G = GL_n(F_q)` and `S = {g, g⁻¹, h, h⁻¹}` coming from a certified generating pair.

### Lean-style signature target

```lean
theorem cayley_connected_of_certified_pair
    {q n : ℕ} [Fact q.Prime] (hn : 2 ≤ n)
    {g h : Matrix (Fin n) (Fin n) (ZMod q)}
    (hcert : CertifiedGeneratingPair q n g h)
    (hneq1g : g ≠ 1) (hneq1h : h ≠ 1) :
    Graph.Connected (certifiedCayleyGraph q n g h)
```

Also prove regularity:

```lean
theorem degree_certifiedCayleyGraph
    {q n : ℕ} [Fact q.Prime] (hn : 2 ≤ n)
    {g h : Matrix (Fin n) (Fin n) (ZMod q)}
    (hsym : SymmetricGeneratorSet q n g h)
    (hsep : PairwiseDistinctGenerators q n g h) :
    ∀ v, Graph.degree (certifiedCayleyGraph q n g h) v = 4
```

### Why this matters

This theorem is the algebraic entry point: it converts certificate data into a canonical sparse network. It is not enough by itself, but it creates the exact combinatorial object on which spectral theory acts.

### Proof strategy options

**Strategy A: closure-to-path induction**
1. Show every word in the generators corresponds to a path in the Cayley graph.
2. Use subgroup closure equality `closure S = ⊤` to represent every vertex as a word.
3. Deduce connectivity by explicit path construction from `1` to arbitrary `x`.

**Strategy B: graph-theoretic orbit argument**
1. Show the connected component of identity is stable under left multiplication by generators.
2. Prove it forms a subgroup containing `S`.
3. Since `S` generates `G`, the component must be all of `G`.

**Most promising:** Strategy B. It is conceptually clean, uses subgroup closure elegantly, and should formalize well in Lean via `Subgroup.closure_induction`.

## Theorem 2: Spectral gap criterion from representation-theoretic operator norm bounds

This is the conceptual heart. You may not be able to prove the full `ε ≤ C/q` conjecture immediately, but you should prove a theorem that reduces expansion to a concrete representation-theoretic inequality.

### Precise theorem statement

Let `G` be finite, `S` a symmetric generating multiset, and let `A_S` be the normalized adjacency / Markov operator on functions `G → ℂ`. If for every nontrivial irreducible representation `ρ` of `G`,
\[
\left\|\frac{1}{|S|}\sum_{s \in S} \rho(s)\right\| \le \alpha < 1,
\]
then the second-largest eigenvalue in absolute value of the Cayley graph is at most `α`, hence the spectral gap is at least `1 - α`.

### Lean-style signature target

```lean
theorem spectral_gap_of_irrep_norm_bound
    {G : Type*} [Finite G] [Group G] [Fintype G]
    (S : Finset G)
    (hsym : ∀ g ∈ S, g⁻¹ ∈ S)
    (hgen : Subgroup.closure ((↑S : Set G)) = ⊤)
    {α : ℝ} (hα0 : 0 ≤ α) (hα1 : α < 1)
    (hbound :
      ∀ (ρ : IrreducibleUnitaryRep ℂ G),
        ¬ IsTrivialRep ρ →
        operatorNorm (averageRepOperator S ρ) ≤ α) :
    spectralGap (cayleyGraph S) ≥ 1 - α
```

If the exact objects `IrreducibleUnitaryRep`, `operatorNorm`, or `spectralGap` do not yet exist in the needed form, define a finite-dimensional substitute. The theorem itself is the point.

### Why this is a breakthrough

This theorem isolates the exact interface between **certificate algebra** and **expansion**. Once formalized, any future algebraic criterion that bounds nontrivial representation averages will instantly yield new expanders. It is a reusable theorem schema, not a one-off result.

### Proof strategy options

**Strategy A: regular representation decomposition**
1. Decompose the left regular representation into irreducibles.
2. Show the averaging operator is block diagonal under this decomposition.
3. Bound the spectrum on the orthogonal complement of constants by the maximal nontrivial operator norm.

**Strategy B: Fourier transform on finite groups**
1. Define the convolution operator associated to the generator measure.
2. Use finite-group Fourier inversion to identify eigenvalues with representation Fourier coefficients.
3. Deduce the spectral radius bound from the operator norm assumption.

**Strategy C: variational characterization**
1. Use Rayleigh quotient for the normalized adjacency operator.
2. Expand arbitrary mean-zero functions in irreducible matrix coefficients.
3. Bound the quotient term-by-term using the nontrivial representation hypothesis.

**Most promising:** Strategy A if enough representation theory infrastructure is available; otherwise Strategy C may be easier to engineer directly with finite-dimensional linear algebra.

## Theorem 3: Certified pairs imply a nontrivial expansion bound in low-rank cases

You need at least one theorem that is not merely a reduction theorem. Prove an actual expansion estimate for a concrete family, even if weak. The most realistic target is `GL₂(F_q)` under explicit hypotheses.

### Candidate theorem statement

For `q` prime, `q ≥ 5`, and `g,h ∈ GL₂(F_q)` such that:
- `g` is Singer-like (irreducible characteristic polynomial over `F_q`, order dividing `q^2 - 1` and not dividing `q - 1`),
- `det h` is primitive in `F_qˣ`,
- `⟨g,h⟩ = GL₂(F_q)`,

then the normalized adjacency operator of the Cayley graph with generators `{g,g⁻¹,h,h⁻¹}` has second eigenvalue strictly less than `1`. Even a formal explicit bound like
\[
\lambda_2 \le 1 - \frac{1}{|GL_2(F_q)|^2}
\]
is nontrivial if proved structurally rather than by enumeration.

### Lean-style signature target

```lean
theorem weak_expansion_GL_two_of_certified_pair
    {q : ℕ} [Fact q.Prime] (hq : 5 ≤ q)
    {g h : Matrix (Fin 2) (Fin 2) (ZMod q)}
    (hcert : CertifiedGeneratingPair q 2 g h) :
    ∃ ε : ℝ, 0 < ε ∧ spectralGap (certifiedCayleyGraph q 2 g h) ≥ ε
```

This theorem is weaker than the grand conjecture, but it is already field-opening because it converts generation certificates into a **positive expansion constant**.

### Why this matters

A positive spectral gap for an explicit deterministic 4-regular family is already a major object. Once established, the next cycle can improve the quantitative bound to `Ω(1/q)` or even uniform-in-rank statements.

### Proof strategy options

**Strategy A: finite compactness / spectral exclusion**
1. Prove connected non-bipartite regular finite graphs satisfy `λ₂ < 1`.
2. Show the certified Cayley graph is connected and contains an odd cycle or otherwise excludes the `-1/1` obstruction.
3. Convert strict inequality into existence of some positive `ε`.

**Strategy B: representation-theoretic strict contraction**
1. Use Theorem 2 with a crude bound `α < 1`.
2. Show equality `‖Aρ‖ = 1` would imply a nonzero invariant vector for the generator set.
3. Use generation plus irreducibility to derive contradiction for nontrivial reps.

**Most promising:** Strategy B. It is exactly the bridge theorem in action and demonstrates the philosophical core of the project.

## Theorem 4: Cross-domain bridge — mixing time / derandomization theorem

You are required to connect to another domain. The best bridge here is **theoretical computer science** via random walks and pseudorandomness.

### Precise theorem statement

If the spectral gap of the certified Cayley graph is at least `ε > 0`, then the lazy random walk on `GL_n(F_q)` driven by the certificate generators mixes to uniform in time
\[
O\!\left(\frac{\log |GL_n(F_q)| + \log(1/\delta)}{\varepsilon}\right).
\]

### Lean-style signature target

```lean
theorem mixing_time_bound_of_spectral_gap
    {G : Type*} [Finite G] [Group G] [Fintype G]
    (S : Finset G) (hSym : ∀ g ∈ S, g⁻¹ ∈ S)
    {ε δ : ℝ} (hε : 0 < ε) (hδ : 0 < δ) :
    spectralGap (cayleyGraph S) ≥ ε →
    ∃ t : ℕ, totalVariationDist (lazyWalkLaw S t) uniform ≤ δ ∧
      t ≤ Nat.ceil ((Real.log (Fintype.card G) + Real.log (1 / δ)) / ε)
```

Specialize it to certificate pairs in `GL_n(F_q)`.

### Why this is revolutionary

This turns a pure algebraic theorem into an algorithmic guarantee:
- fast mixing,
- pseudorandom sampling of group elements,
- explicit sparse networks with provable diffusion,
- foundations for derandomized algorithms using certified matrix pairs.

This is the required cross-domain theorem: **group theory + spectral graph theory + theoretical computer science**.

### Proof strategy options

**Strategy A: standard spectral decomposition of Markov chains**
1. Express the lazy walk operator as `P = (I + A)/2`.
2. Bound the mean-zero component by `(1 - ε/2)^t`.
3. Convert `L²` decay to total variation using Cauchy–Schwarz.

**Strategy B: conductance/Cheeger route**
1. Derive edge expansion from spectral gap.
2. Use a standard mixing-time inequality from conductance.
3. Specialize to the Cayley graph.

**Most promising:** Strategy A. It is more direct, cleaner in Lean, and uses the spectral operator already developed.

## Grand Conjecture to State and Test

You must include a falsifiable conjecture with explicit computational test.

### Conjecture
For every prime `q ≥ 5`, there exists an absolute constant `C > 0` such that for every certified pair `(g,h)` in `GL₂(F_q)` of Singer/primitive-determinant type,
\[
\operatorname{gap}(g,h) \ge \frac{1}{Cq}.
\]

Equivalently, with `S = {g,g⁻¹,h,h⁻¹}`,
\[
\lambda_2(\mathrm{Cay}(GL_2(F_q),S)) \le 1 - \frac{1}{Cq}.
\]

### Testable prediction
Compute the exact normalized spectral gap for all certified pairs in:
- `GL₂(F₃)`,
- `GL₂(F₅)`,

and compare the minimum observed gap against:
- `0.01`,
- `1/q`,
- `1/(2q)`.

If some certified pair has gap `< 0.01`, the strong form is false. If all tested pairs satisfy gap `≫ 1/q`, the conjecture gains credibility.

### Stronger speculative extension
For fixed `n ≥ 2`, certified pairs in `GL_n(F_q)` satisfy
\[
\operatorname{gap} \ge \frac{c_n}{q}
\]
for some constant `c_n > 0` depending only on `n`.

This is a real conjecture because it can fail computationally in low-rank examples.

## Mathematical Insight You Should Exploit

The central mechanism is:

1. **Singer certificate** gives an element acting with no nontrivial invariant subspace over the base field, hence forces high algebraic irreducibility.
2. **Primitive determinant element** breaks containment in determinant-restricted or semilinear obstructions.
3. Together, these exclude many low-complexity subgroups and push generation to the full group.
4. In the representation category, “no invariant subspace / no proper obstruction subgroup” should imply that averaging over the generator set has no almost-fixed vectors in nontrivial irreducible representations.
5. That absence of almost-fixed vectors is exactly the source of a spectral gap.

The decisive new idea is to formalize this as a reusable theorem schema:
**certificate obstruction elimination ⇒ representation contraction ⇒ expander.**
