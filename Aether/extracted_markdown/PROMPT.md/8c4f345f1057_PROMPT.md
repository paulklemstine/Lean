## Precise Theorem Statements

### Theorem A: Reflection soundness for tropical matrix expressions

Define a syntactic type of tropical matrix expressions over `Fin n → Fin n → ℝ∞`-valued semantics (or `ℝ` if you choose a finite-weight-only phase first), with constructors for variables, entrywise tropical addition, tropical matrix multiplication, and powers.

A core theorem should be:

```lean
theorem TropMatExpr.normalize_sound
  {n m : ℕ} (e₁ e₂ : TropMatExpr n m) :
  normalize_mat e₁ = normalize_mat e₂ →
  eval_mat e₁ = eval_mat e₂
```

If square matrices are easier for the multiplication fragment, specialize first:

```lean
theorem TropSquareExpr.normalize_sound
  {n : ℕ} (e₁ e₂ : TropSquareExpr n) :
  normalize_sq e₁ = normalize_sq e₂ →
  eval_sq e₁ = eval_sq e₂
```

A stronger and more automation-ready extensional form is even better:

```lean
theorem TropMatExpr.normalize_sound_ext
  {n m : ℕ} (e₁ e₂ : TropMatExpr n m) :
  normalize_mat e₁ = normalize_mat e₂ →
  ∀ i j, eval_mat e₁ i j = eval_mat e₂ i j
```

This theorem should explicitly build on the scalar canonicalization engine behind `CTropExpr` / `normalize_ca` by reducing matrix equality to entrywise scalar equality after normalization.

### Theorem B: Semantic correctness of tropical matrix multiplication

Formalize tropical matrix multiplication as min-plus convolution:

```lean
def tropMul {n k m : ℕ}
  (A : Fin n → Fin k → ℝ)
  (B : Fin k → Fin m → ℝ) :
  Fin n → Fin m → ℝ :=
fun i j => Finset.inf' Finset.univ (by simp) (fun t => A i t + B t j)
```

Then prove the semantics theorem for the expression-level multiplication constructor:

```lean
theorem eval_mat_mul
  {n k m : ℕ} (e₁ : TropMatExpr n k) (e₂ : TropMatExpr k m) :
  eval_mat (TropMatExpr.mul e₁ e₂) = tropMul (eval_mat e₁) (eval_mat e₂)
```

If `ℝ` causes issues with finite infimum APIs, use `ℝ∞ := WithTop ℝ` or a dedicated min-plus carrier and prove a clean finite-index version first.

### Theorem C: Tropical trace-power lower/upper spectral bridge

For a square tropical matrix `A : Fin n → Fin n → ℝ`, define tropical powers and tropical trace:
- `(A^[t]) i j` by repeated tropical multiplication
- `tropTrace A := inf_i A i i` in min-plus convention, or the corresponding diagonal optimum according to your existing library convention

Then prove a cycle-mean comparison theorem of the following shape:

```lean
theorem tropical_trace_pow_cycle_mean_bound
  {n : ℕ} [NeZero n] (A : Fin n → Fin n → ℝ) :
  ∀ k : ℕ, 1 ≤ k →
    tropicalEigenvalue A ≤ tropTrace (tropPow A k) / k
```

and, if the existing spectral infrastructure is strong enough, push to the asymptotic statement:

```lean
theorem tropical_trace_pow_inf_eq_eigenvalue
  {n : ℕ} [NeZero n] (A : Fin n → Fin n → ℝ) :
  sInf {x : ℝ | ∃ k : ℕ, 1 ≤ k ∧ x = tropTrace (tropPow A k) / k}
    = tropicalEigenvalue A
```

If sequence limits are too heavy for the first cycle, prove the **infimum characterization** instead of a full convergence theorem. That is already mathematically substantial and far more likely to compose with the current catalog.

A more graph-theoretic formulation is also acceptable:

```lean
theorem tropical_eigenvalue_eq_inf_trace_pow_div
  {n : ℕ} [NeZero n] (A : Fin n → Fin n → ℝ) :
  tropicalEigenvalue A =
    sInf (Set.range (fun k : {k : ℕ // 1 ≤ k} =>
      tropTrace (tropPow A k.1) / k.1))
```

This is the theorem that would truly matter: it identifies the tropical eigenvalue with a certified asymptotic invariant of matrix powers.

## Proof Strategy: 3 Viable Routes

### Strategy A: Entrywise reflection via scalar normalization
**Most promising for the first breakthrough theorem.**

1. Define matrix semantics as functions `Fin n → Fin m → α`.
2. For each matrix expression and each index pair `(i,j)`, compile `eval_mat e i j` to a scalar tropical expression in the existing canonical form.
3. Define `normalize_mat` by normalizing each compiled scalar entry.
4. Prove:
   - normalized entry equality implies scalar semantic equality,
   - extensional matrix equality follows by `funext`.

Why this is promising:
- It reuses the strongest certified asset you already have: scalar normalization.
- It minimizes new algebraic burden.
- It yields an actual automation tactic early.

This should deliver Theorem A quickly.

---

### Strategy B: Path-expansion normal form for matrix products
**Most elegant mathematically; likely best for spectral follow-up.**

1. Show that each entry of a tropical matrix product is the minimum over weighted paths of fixed length.
2. Represent a matrix expression in canonical path-sum form.
3. Prove normalization soundness by uniqueness of path-expansion semantics.
4. Use the same path machinery to connect diagonal entries of `A^k` with cycle weights of length `k`.

Why this is deeper:
- It makes the combinatorics of powers and trace transparent.
- It naturally interfaces with graph-theoretic minimum cycle mean arguments.
- It is the right architecture if you want Karp-style algorithms later.

This is the route to Theorem C.

---

### Strategy C: Graph-theoretic spectral formalization first, reflection second
**Best if `MinPlusSpectral` is already strong.**

1. Interpret `A : Fin n → Fin n → ℝ` as a weighted digraph.
2. Define the tropical eigenvalue as minimum cycle mean.
3. Prove `tropTrace (A^k)` is the optimal weight of a closed walk of length `k`.
4. Derive the infimum characterization of the eigenvalue from cycle decomposition.
5. Only then build matrix reflection to automate the finite algebraic identities needed in the graph proof.

Why this may win:
- The spectral theorem is the mathematically strongest deliverable.
- It opens the door to algorithm certification immediately.
- Reflection can then be justified as the proof automation layer for the graph algebra.
