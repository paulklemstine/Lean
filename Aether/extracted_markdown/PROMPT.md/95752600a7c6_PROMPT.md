## Vision: Differential Closure as the First Certified Transseries Fragment

The target is not a small closure lemma. The target is a **formal differential closure principle for positive EML expressions** that behaves like the first rigorous, machine-checked fragment of transseries. If successful, this opens a route from Hardy hierarchies to:

### Theorem 1: symbolic differentiation respects semantic differentiation
This theorem is foundational and should use induction, `calc`, and nontrivial rewriting.

```lean
theorem eval_deriv_eq_deriv_eval
  (e : PosEMLExpr) :
  HasDerivAt (fun x => e.eval x) ((e.deriv).eval x) x
```

or, if global differentiability is easier to encode:

```lean
theorem differentiable_eval
  (e : PosEMLExpr) :
  Differentiable ℝ (fun x => e.eval x)
```

plus

```lean
theorem deriv_eval_eq_eval_deriv
  (e : PosEMLExpr) :
  deriv (fun x => e.eval x) = fun x => (e.deriv).eval x
```

if the analytic prerequisites are manageable.

**Why this matters:** it turns syntax into certified differential semantics, the indispensable first step toward formal transseries.

### Theorem 4: logarithmic derivative stays within the same transseries fragment
This is the cross-domain theorem candidate: it links Hardy growth to differential algebra and physics-style observables.

For eventually positive `e`, define the logarithmic derivative:
```lean
def logDeriv (f : ℝ → ℝ) := fun x => deriv f x / f x
```

Then aim for a theorem like:

```lean
theorem hardyLevel_logDeriv_le
  (e : PosEMLExpr)
  (hpos : EventuallyPositive (fun x => e.eval x))
  (hne : ∀ᶠ x in Filter.atTop, e.eval x ≠ 0) :
  HardyLevelLE (e.depth + 1) (logDeriv (fun x => e.eval x))
```

or a fragment theorem for expressions of the form `a * exp b`:
```lean
theorem logDeriv_mul_exp
  (a b : PosEMLExpr) :
  logDeriv (fun x => a.eval x * Real.exp (b.eval x))
  =ᶠ[Filter.atTop]
  fun x => logDeriv (fun x => a.eval x) x + deriv (fun x => b.eval x) x
```

This is powerful because logarithmic derivatives are the native language of:
- WKB approximation,
- saddle-point asymptotics,
- multiplicative renormalization,
- Riccati transforms of ODEs.

## Proof architecture: 3 viable strategies

### Strategy A: Syntactic derivative → semantic transfer → catalog closure
**Most promising.**

1. **Define symbolic differentiation on EML syntax** and prove
   `eval_deriv_eq_deriv_eval` by induction on expressions.
   - base cases: constant, variable,
   - inductive cases: add, mul, exp via chain rule.
2. **Prove complexity control**
   `depth_deriv_le_succ_depth`.
   This is a structural induction with arithmetic inequalities on `Nat`.
3. **Apply catalog theorem**
   `hardyLevel_closed_under_eml` to `e.deriv`, using the depth bound to conclude the derivative lies in Hardy level `depth e + 1`.

**Why best:** it modularizes syntax, analysis, and growth. It is also the cleanest route to future transseries formalization.

---

### Strategy B: Direct semantic induction on EML evaluation formulas
1. Prove directly that every constructor preserves the “derivative raises level by at most one” property.
2. In the `exp` case, use
   \[
   \frac{d}{dx}(a \cdot e^b) = (a' + a b')e^b
   \]
   and bound each term’s Hardy level semantically.
3. Avoid explicit symbolic derivative normalization; instead prove existence of some witness expression at bounded depth.

**Why useful:** may avoid painful expression-size bookkeeping.  
**Risk:** existential witnesses can become awkward in Lean unless the catalog already has a representation theorem.

---

### Strategy C: Eventual domination / asymptotic comparison approach
1. Define a relation `f ≼[n] g` meaning “`f` is eventually dominated by a canonical level-`n` Hardy witness.”
2. Prove derivative closure for the canonical witnesses.
3. Show EML expressions of depth `d` embed into this domination hierarchy by catalog closure.
4. Conclude the derivative remains in level `d+1`.

**Why exciting:** this is closest to classical asymptotic analysis and may generalize beyond EML.  
**Risk:** likely heavier setup, but if successful it opens a broader asymptotic-comparison framework.

### Conjecture A: sharpness of the +1 bound
> There exists an infinite family of eventually positive EML expressions `e_n` such that the derivative genuinely has minimal Hardy level exactly `depth e_n + 1`.

**Test:** enumerate expressions up to depth 4 or 5, compute symbolic derivatives, compare inferred minimal level to `depth + 1`. A single family with exact attainment supports sharpness; a counterexample with lower uniform bound disproves it.

### Conjecture B: logarithmic derivative does not increase level for pure exponentials
> If `e = exp b` with `EventuallyPositive (eval e)`, then `logDeriv (eval e)` has Hardy level at most `depth b`, not `depth b + 1`.

**Test:** generate `b` up to depth 4, compute `logDeriv(exp b) = b'`, and compare empirical level.

### Conjecture C: differential closure under eventual quotients
> If `a,b` are eventually positive EML expressions with `HardyLevelLE d`, then `deriv (a/b)` has Hardy level at most `d+1`.

**Test:** enumerate pairs `(a,b)` with eventual nonvanishing denominator; use symbolic quotient differentiation and search for violations.

### Conjecture D: normalization lowers derivative depth
> After a suitable symbolic simplifier, `depth (normalize (deriv e)) ≤ depth e` for all eventually positive `e` in a restricted fragment.

**Test:** implement a normalizer; compare raw derivative depth vs normalized derivative depth on exhaustive search.

These are scientifically valuable because they can fail.
