## Vision

The target is a **finite proof-theoretic tropical duality theorem**:

- a finite weighted consequence system induces a canonical min-plus semimodule of proof valuations;
- the least fixed point of the tropical consequence operator computes exact minimal derivation cost;
- extremal / join-irreducible valuation profiles encode prime cut-free derivation templates;
- from those extremals one can reconstruct a **certified minimal derivation DAG** for each derivable sequent;
- conversely, every finite idempotent consequence semimodule with the right elimination/residuation axioms comes from a finite weighted proof system.

If formalized cleanly, this opens a field: **tropical proof semantics**, where proof normalization, shortest derivation, spectral reconstruction, and idempotent linear duality become one object.

This is not a variant of closure duality or ultrametric semantics. The breakthrough is that **proof cost and proof shape become recoverable from tropical linear structure**.

## Precise theorem package to target

You should introduce finite structures for:

A good first formal model is:

- each rule has a finite list of premises and one conclusion;
- applying a rule costs `w`;
- valuation of conclusion is bounded by `w + aggregate premises`;
- for proof-cost semantics, the premise aggregate should initially be `Finset.sup` or `Finset.sum` depending on whether rules require all premises in parallel or additive composition; the mathematically intended tropical aggregate is min-plus, so the safest first target is:
  - proof cost of a rule instance = `w + sum of premise costs`,
  - global consequence operator = infimum/min over rules concluding `q`.

This gives shortest hyperpath semantics and is formalizable without fragile abstract tropical infrastructure. Once the theorem is established there, abstract it to an idempotent semiring/semimodule formulation.

## Core theorem statements

### 1. Least fixed point = minimal derivation cost

Define:

- `derivCost : P → Cost` as the infimum/minimum cost among all finite derivation DAGs proving `q`;
- `T : (P → Cost) → (P → Cost)` by
  `T f q = min over rules r concluding q of (w r + aggregatePremiseCosts f r)`.

Then prove:

```lean
theorem least_fixedPoint_eq_minDerivCost
  [Fintype P] [DecidableEq P] :
  leastFixedPoint T = derivCost
```

A more Lean-realistic signature may be:

```lean
theorem lfp_consequence_eq_minimal_cost
  [Fintype P] [DecidableEq P] :
  ∀ q : P, lfpValuation rules q = minimalDerivationCost rules q
```

where `lfpValuation` is constructed by finite iteration from `⊤` or from axioms, depending on your order convention.

## Proof architecture: 3 strategy paths

### Strategy A: Finite Bellman–Knaster–Tarski route
**Most promising for the first complete formal breakthrough.**

1. Define derivation DAGs and minimal derivation cost independently.
2. Show `consequenceOp` is monotone and stabilizes after finitely many iterations on finite `P`.
3. Prove by induction on derivation DAGs that every derivation gives an upper bound on the lfp valuation.
4. Prove conversely that every stabilized lfp witness selects a rule predecessor, recursively yielding a minimal derivation DAG.
5. Package realizable valuation profiles into a finite idempotent semimodule and identify extremals by nondecomposability.

Why this is strongest:
- It aligns with shortest-path / hypergraph dynamic programming.
- It should reuse finite closure and reconstruction ideas from the catalog.
- It gives the algorithmic corollary almost for free.

### Strategy B: Tropical convex/spectral decomposition route
**Best for the extremal classification theorem.**

1. Define the set of realizable valuations as the closure of rule-profile generators under pointwise `min` and tropical scaling/translation.
2. Use a finite tropical decomposition theorem to show every valuation has a finite decomposition into extremals.
3. Prove that cut-elimination/normality implies decomposable valuations correspond to non-prime derivation templates, while join-irreducibles correspond to prime cut-free templates.
4. Recover minimal derivation DAGs from a selected extremal decomposition.

Why this matters:
- This is where the bridge becomes conceptually new, not merely algorithmic.
- It directly leverages `certified_finite_tropical_decomposition`.

### Strategy C: Closure/reconstruction duality transfer
**Best for the converse realization theorem.**

1. Translate the consequence operator into a closure-like operator on valuation profiles.
2. Apply or adapt spectral reconstruction machinery from the closure bridge.
3. Show the separating tropical linear functionals determine a finite family of weighted rules.
4. Construct the proof system and prove order/semimodule equivalence.

Why this is promising:
- The converse theorem is difficult if attacked from raw syntax.
- Existing reconstruction bridges likely already encode the right finite spectral philosophy.

Recommended order:
- First complete Strategy A for lfp = minimal cost + certified reconstruction.
- Then use Strategy B for extremals.
- Finally Strategy C for realization.

## Nontrivial mathematical insights to encode

### 1. Proof search as shortest hyperpath
A weighted inference rule with multiple premises is a directed hyperedge. The least fixed point theorem is a shortest-hyperpath theorem in disguise. But the breakthrough is not that shortest hyperpaths exist; it is that the **entire proof semantics forms an idempotent semimodule whose extremals classify proof templates**.

### 2. Cut-elimination as tropical extremality purification
The tropical cut-elimination axiom should be framed so that any valuation profile admitting a cut decomposition is tropically reducible. Then cut-free prime templates are exactly irreducible/extremal valuation rays. This is a novel algebraic semantics of normalization.

### 3. Realization theorem as proof-syntax reconstruction from valuation geometry
The converse says syntax is not primitive: under finite separation and normality, it can be reconstructed from tropical geometry. This is the genuinely field-opening part.
