### 1. Oracle traces and prefix geometry

```lean
abbrev OracleTrace (α : Type u) := List α
```

Define longest-common-valued-prefix depth:

```lean
def lcvpDepth [DecidableEq α] : OracleTrace α → OracleTrace α → ℕ
```

Intended semantics: largest `n` such that the first `n` symbols agree.

Define a natural-number distance and a rationalized ultrametric surrogate:

```lean
def lcvpDistNat [DecidableEq α] (x y : OracleTrace α) : ℕ := ...
def lcvpDist [DecidableEq α] (x y : OracleTrace α) : ℚ := ...
```

A good concrete choice is:
- `lcvpDistNat x y = x.length + y.length - 2 * lcvpDepth x y`
- or prefix penalty based on first disagreement;
- for `lcvpDist`, use `0` on equality and `1 / (lcvpDepth x y + 1)` otherwise.

Also define trace balls:

```lean
def traceBall [DecidableEq α] (center : OracleTrace α) (r : ℕ) : Set (OracleTrace α)
```

with the intended meaning “all traces sharing at least `r` prefix symbols with `center`”.

## Proof strategy architecture

You must not rely on a single proof pattern. Use induction, `rcases`, `by_contra`, arithmetic tactics, extensionality, and set-theoretic reasoning.

### Phase I: list-prefix combinatorics
1. Define `lcvpDepth` recursively on lists, likely by simultaneous pattern matching:
   - `[], _ => 0`
   - `_, [] => 0`
   - `a::as, b::bs => if a = b then lcvpDepth as bs + 1 else 0`
2. Prove `lcvpDepth_self`, `symm`, and boundedness by induction on the pair of lists.
3. Prove the ultrametric depth inequality by induction on a common leading symbol analysis:
   - `rcases x with _ | a::xs <;> rcases y with _ | b::ys <;> rcases z with _ | c::zs`
   - split on equalities `a = b`, `b = c`, `a = c`.
   - `omega` or `linarith` can finish the arithmetic after reductions.

Most promising route: prove a helper lemma
```lean
lemma prefix_agree_of_min_depth ...
```
then derive the min-depth inequality from prefix agreement.

### Phase II: balls and rigidity
4. Define `traceBall c r := {x | r ≤ lcvpDepth c x}`.
5. Ball monotonicity is immediate via transitivity of `≤`.
6. Ball intersection rigidity follows from `lcvpDepth_ultra`: if centers agree to depth `r`, then any point agreeing with one center to depth `r` agrees with the other.

This is the key geometric lemma; it drives entropy comparison.

### Phase III: admissible simulations as coarse Lipschitz maps
7. Package the prefix-loss property in `AdmissibleSimulation`.
8. Show image-ball control by directly unfolding `traceBall` and applying `monotone_prefix`.
9. For composition, define the composite transducer and prove depth losses add:
   - this should use `calc` chains and `omega`.
10. Derive `PrefixLipschitz` and `CertifiedPrefixRobust` as corollaries.

### Phase IV: counting/growth
11. Keep `traceComplexity` simple enough to avoid difficult finiteness obligations.
   A good option is to count traces of length exactly/at most `n` over a finite alphabet using `Finset.univ.pi`-style encodings or cardinality bounds rather than exact counts.
12. Prove monotonicity under set inclusion.
13. For transduced-image complexity, use:
   - any output trace of length `≤ n` comes from an input trace whose useful prefix length is `≤ n + depth_loss`,
   - so image complexity is bounded by source complexity with shifted radius.
14. Use rational coercions carefully; if necessary prove integer inequalities first, then coerce.

Most promising route: formulate `traceComplexity` as cardinality of a finite subtype over traces with bounded length. This lets you use `Nat.card_mono` or explicit embeddings. If direct cardinality embeddings are messy, prove existence of an injection from outputs of bounded size into inputs of shifted bounded size in concrete transducer cases.

### Phase V: invariance
15. The main theorem should be derived by applying the forward comparison to `E.forward` and the reverse comparison to `E.backward`.
16. Package the final result as a bounded-shift equivalence of growth profiles.
17. Include one theorem with quantifier alternation `∀ n, ∃ C` and one with `∀ x, ∃ y` if possible, e.g. a simulation witness theorem.

This file establishes the algebraic core of **proof-spectrum semantics**: the reconstruction
of semiprime theories/kernels as intersections of prime theories in commutative semirings.

## Main results

* `semiprime_eq_iInter_prime_theories` — A semiprime kernel in a commutative semiring equals the
  intersection of all prime theories containing it. This is the algebraic heart of the
  proof-spectrum correspondence.

* `exists_prime_theory_avoiding` — Prime separation: if `a` is not in a semiprime kernel `K`,

* `zeroLocus_anti_mono`, `theoryOf_zeroLocus_extensive`, `theoryOf_zeroLocus_galois` — The
  antitone Galois correspondence between sets of proof terms and sets of congruences.

* `zeroClass_of_prime_congruence_isPrimeTheory` — The zero-class of a prime proof congruence
  is a prime theory.

## Mathematical overview

The key insight is that a proof system can be given the structure of an idempotent commutative
semiring, where `a + b` represents "either derivation resource," `a * b` represents "composite
derivation," and the induced order captures logical entailment. The prime congruence spectrum
then provides a geometric semantics: theories correspond to vanishing loci, and derivability
is captured by vanishing on all points of the associated spectral set.

The decisive theorem is that **semiprime** theories (those closed under square roots:
`a * a ∈ T → a ∈ T`) are exactly the intersections of prime theories. This is the
semiring-theoretic analogue of the radical ideal theorem from algebraic geometry.

## References

The algebraic content is a semiring generalization of the classical commutative algebra result
that semiprime ideals are intersections of prime ideals (a consequence of Krull's theorem).
The proof uses Zorn's lemma applied to the family of ideals disjoint from a multiplicative set.

/-- A semiring congruence interpreted as proof indistinguishability. -/
structure ProofCongruence (α : Type u) [CommSemiring α] where
  r : α → α → Prop

  add_compat : ∀ {a b c d}, r a b → r c d → r (a + c) (b + d)

def zeroLocus {α : Type u} [CommSemiring α]

  {P | ∀ a ∈ S, vanishesAt P a}

/-- The theory reconstructed from a family of proof congruences. -/
def theoryOf {α : Type u} [CommSemiring α]
    (X : Set (ProofCongruence α)) : Set α :=
  {a | ∀ P ∈ X, vanishesAt P a}

/-- A proof congruence is prime if `ab ~ 0` forces `a ~ 0` or `b ~ 0`. -/
def ProofCongruence.IsPrime {α : Type u} [CommSemiring α]
    (P : ProofCongruence α) : Prop :=
  ∀ {a b : α}, P.r (a * b) 0 → P.r a 0 ∨ P.r b 0

/-- The prime spectrum: the set of all prime proof congruences. -/
def primeSpectrum {α : Type u} [CommSemiring α] : Set (ProofCongruence α) :=
  {P | ProofCongruence.IsPrime P}

## Mathematical overview

/-- A semiring congruence interpreted as proof indistinguishability. -/
structure ProofCongruence (α : Type u) [CommSemiring α] where
  r : α → α → Prop
  iseqv : Equivalence r
  add_compat : ∀ {a b c d}, r a b → r c d → r (a + c) (b + d)

def vanishesAt {α : Type u} [CommSemiring α] (P : ProofCongruence α) (a : α) : Prop :=
  P.r a 0

/-- Zariski closed set defined by a family of proof terms. -/
def zeroLocus {α : Type u} [CommSemiring α]
    (S : Set α) : Set (ProofCongruence α) :=
  {P | ∀ a ∈ S, vanishesAt P a}

/-- The theory reconstructed from a family of proof congruences. -/
def theoryOf {α : Type u} [CommSemiring α]
    (X : Set (ProofCongruence α)) : Set α :=
  {a | ∀ P ∈ X, vanishesAt P a}

/-- A proof congruence is prime if `ab ~ 0` forces `a ~ 0` or `b ~ 0`. -/
def ProofCongruence.IsPrime {α : Type u} [CommSemiring α]
    (P : ProofCongruence α) : Prop :=
  ∀ {a b : α}, P.r (a * b) 0 → P.r a 0 ∨ P.r b 0

/-- The prime spectrum: the set of all prime proof congruences. -/
def primeSpectrum {α : Type u} [CommSemiring α] : Set (ProofCongruence α) :=
  {P | ProofCongruence.IsPrime P}
