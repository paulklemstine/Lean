def closurePartitionFunction {α : Type*} [Fintype α] (β : ℝ) (φ : α → ℝ) : ℝ :=

def closurePressure {α : Type*} [Fintype α] (β : ℝ) (φ : α → ℝ) : ℝ :=

def closureGibbsWeight {α : Type*} [Fintype α] (β : ℝ) (φ : α → ℝ) (a : α) : ℝ :=
  closureWeight β φ a / closurePartitionFunction β φ

/-- Gibbs state as a normalized finite probability mass function encoded as a function. -/
def closureGibbsState {α : Type*} [Fintype α] (β : ℝ) (φ : α → ℝ) : α → ℝ :=
  closureGibbsWeight β φ

/-- Transfer operator associated to a closure kernel and potential. -/
def closureTransfer {α : Type*} [Fintype α]
    (K : ClosureKernel α) (β : ℝ) (φ f : α → ℝ) : α → ℝ :=
  fun a => ∑ b, K.step a b * Real.exp (β * φ b) * f b

/-- Invariance of a state under a finite kernel. -/
def IsClosureInvariant {α : Type*} [Fintype α]

## PROOF STRATEGY DETAILS

### Strategy A: finite partition-function calculus (most promising)
This should be the backbone.

1. Expand every object into finite sums over `Fintype`.
2. Prove positivity using:
   - `Real.exp_pos`
   - `Finset.sum_pos` or `Finset.sum_nonneg`
3. Prove normalization by direct algebra:
   - unfold `closureGibbsWeight`, `closurePartitionFunction`
   - rewrite the numerator sum as the partition function
   - finish with field division using positivity
4. Prove pressure lower bounds by:
   - comparing one summand to the whole sum,
   - applying `Real.log_le_log` with partition positivity.
5. Prove Lipschitz stability by deriving:
   - `β * φ a ≤ β * ψ a + |β| * ρ`
   - and its symmetric form via `abs_sub_le_iff` / `abs_mul` / `linarith`,
   - then exponentiate and sum,
   - then apply monotonicity of `log`.

This route should use diverse tactics: `simp`, `rw`, `calc`, `have`, `linarith`, `nlinarith`, `field_simp`, `by_cases hβ : 0 ≤ β`, `rcases`, `constructor`.

### Strategy B: closure-system lifting through `Finset α`
For the algebraic layer.

1. Define energies on `Finset α` through `C.cl`.
2. Use `C.idempotent` to prove collapse identities.
3. Use `C.monotone` and a monotone `ψ` to prove energy monotonicity.
4. Lift partition-function positivity and pressure definitions to closed-set semantics.
5. Relate closure-collapse to thermodynamic coarse-graining.

This gives the “algebraic” content and is important for the bridge.

### Strategy C: doubly stochastic fixed-point theorem
For the invariant Gibbs state theorem.

1. Show the zero-potential Gibbs state is uniform:
   - `exp (0 * 0) = 1`,
   - partition function is `card α`,
   - normalized weight is reciprocal cardinality.
2. Expand `IsClosureInvariant`.
3. Rewrite the RHS:
   - `∑ b, (card α)⁻¹ * K.step b a = (card α)⁻¹ * ∑ b, K.step b a`
   - use `Finset.mul_sum` / `Finset.sum_mul`
   - apply column-stochasticity.
4. Compare with the LHS uniform value.
5. If needed, prove helper lemmas about finite sums of constants:
   - `∑ x, (c : ℝ) = Fintype.card α * c`.

This theorem is mathematically elegant and easy enough to formalize fully.
