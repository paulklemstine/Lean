## Research Task: Vector-valued EML Stone–Weierstrass via affine partition-of-unity coding

Research Mode: PROVE

Push the scalar-postcomposition EML Stone–Weierstrass theorem into a genuinely geometric vector-valued density theorem. The goal is not the coordinatewise argument “approximate each component and reassemble”, but a finite-dimensional barycentric coding theorem: approximate a continuous map `F : X → ℝ^m` by convex/affine combinations of finitely many constant output vectors, with scalar weights coming from the scalar EML closure.

This is the right next theorem because it upgrades scalar EML universality to a robust vector-output approximation mechanism that is native to multiclass/simplex-valued outputs, embeddings, and affine decoders. It also gives a reusable formal pattern: scalar approximation + partition of unity + finite-dimensional affine decoding.

### Precise target objects

Work with a compact Hausdorff space `X`, using the standard typeclass assumptions already present in the scalar Stone–Weierstrass development. Let `C(X, ℝ)` denote continuous real-valued maps and `C(X, Fin m → ℝ)` denote continuous `ℝ^m`-valued maps, represented in Lean as `ContinuousMap X (Fin m → ℝ)`.

Use the scalar closure theorem already established: if `A : Set (ContinuousMap X ℝ)` is a pullback-stable lattice-subalgebra containing constants and separating points, then its EML closure is uniformly dense in `C(X, ℝ)`.

You should define a concrete vector class that is intentionally tailored to the affine coding proof.

### Suggested Lean definitions

A minimal and usable definition is the class of finite barycentric/linear combinations with scalar EML coefficients:

```lean
def VecEML
    {X : Type*} [TopologicalSpace X]
    (S : Set (ContinuousMap X ℝ)) (m : ℕ) :
    Set (ContinuousMap X (Fin m → ℝ)) :=
  {F | ∃ n : ℕ, ∃ φ : Fin n → ContinuousMap X ℝ, ∃ v : Fin n → (Fin m → ℝ),
      (∀ i, φ i ∈ S) ∧
      F = ∑ i, (φ i).smulRight (v i)}
```

Here `(φ i).smulRight (v i)` is the continuous map `x ↦ (φ i x) • v i`. If `smulRight` is inconvenient, define explicitly:

```lean
def scalarVec
    {X : Type*} [TopologicalSpace X]
    (f : ContinuousMap X ℝ) (v : Fin m → ℝ) :
    ContinuousMap X (Fin m → ℝ) :=
  { toFun := fun x j => f x * v j
    continuous_toFun := by
      continuity }
```

and then use finite sums of `scalarVec (φ i) (v i)`.

You may also want a simplex-coded subclass:

```lean
def AffinePOUVec
```

but the main theorem can be stated for the linear span-style class `VecEML`; the affine partition-of-unity proof then lands inside it automatically.

### Main theorem: density by affine coding

A strong theorem with a clean Lean shape is:

```lean
theorem vecEML_dense_of_scalar_dense
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
    (S : Set (ContinuousMap X ℝ))
    (h_dense :
      ∀ f : ContinuousMap X ℝ, ∀ ε > 0,
        ∃ g ∈ S, ‖f - g‖ < ε)
    {m : ℕ} (hm : 0 < m)
    (F : ContinuousMap X (Fin m → ℝ))
    (ε : ℝ) (hε : 0 < ε) :
    ∃ G ∈ VecEML S m, ‖F - G‖ < ε
```

where `‖·‖` is the sup norm on continuous maps. If your existing scalar density theorem is packaged as closure density rather than epsilon approximation, adapt the hypothesis to:

```lean

```

```lean

```

and derive the epsilon version when needed.

### Intermediate theorem: partition-of-unity affine approximation

The real geometric content should be isolated as a standalone theorem independent of EML:

```lean
theorem exists_affine_partition_approx
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
    {m : ℕ}
    (F : ContinuousMap X (Fin m → ℝ))
    (ε : ℝ) (hε : 0 < ε) :
    ∃ n : ℕ,
    ∃ ψ : Fin n → ContinuousMap X ℝ,
    ∃ y : Fin n → (Fin m → ℝ),
      (∀ x, ∀ i, 0 ≤ ψ i x) ∧
      (∀ x, (∑ i, ψ i x) = 1) ∧
      ‖F - ∑ i, (ψ i).smulRight (y i)‖ < ε
```

This theorem should be proved using compactness plus a finite partition of unity subordinate to an oscillation cover of `F`. It is a valuable theorem in its own right: it says every continuous map into a finite-dimensional normed space is uniformly approximable by barycentric coding over finitely many sampled output values.

Then the EML theorem follows by approximating the scalar partition functions `ψ i` by scalar EML functions.

### Stronger theorem: stability under approximate partition coding

To bridge exact partitions of unity to approximate scalar EML coefficients, prove a quantitative perturbation lemma. This is likely the key technical tool.

Let `ψ_i` be an exact partition of unity, `φ_i` approximations, and `y_i` bounded output vectors. Then the resulting affine decoders are close. A good formal statement is:

```lean
theorem affine_coding_error_bound
    {X : Type*} [TopologicalSpace X]
    {m n : ℕ}
    (ψ φ : Fin n → ContinuousMap X ℝ)
    (y : Fin n → (Fin m → ℝ))
    (B : ℝ)
    (hy : ∀ i, ‖y i‖ ≤ B) :
    ‖(∑ i, (ψ i).smulRight (y i)) - (∑ i, (φ i).smulRight (y i))‖
      ≤ (∑ i, ‖ψ i - φ i‖) * B
```

A pointwise version may be easier first:

```lean
theorem affine_coding_error_bound_pointwise
    {X : Type*} [TopologicalSpace X]
    {m n : ℕ}
    (ψ φ : Fin n → ContinuousMap X ℝ)
    (y : Fin n → (Fin m → ℝ))
    (x : X) :
    ‖∑ i, (ψ i x - φ i x) • y i‖
      ≤ ∑ i, ‖ψ i x - φ i x‖ * ‖y i‖
```

and then take suprema. This is the lemma that lets you approximate partition weights independently and still control the final vector error.

### Proof strategy

1. **Oscillation cover from uniform continuity of `F`.**  
   Since `X` is compact Hausdorff and `F` is continuous into finite-dimensional Euclidean space, `F` is uniformly continuous. For each `x : X`, choose an open neighborhood `U_x` such that
   ```lean
   ∀ x' ∈ U_x, ‖F x' - F x‖ < ε / 3
   ```
   Extract a finite subcover `U₁, ..., Uₙ` by compactness, and choose sample points `x_i ∈ U_i`, setting `y_i := F x_i`.

2. **Continuous partition of unity subordinate to the finite cover.**  
   Use the normality/paracompactness machinery available for compact Hausdorff spaces to obtain continuous functions
   ```lean
   ψ_i : ContinuousMap X ℝ
   ```
   with `ψ_i ≥ 0`, `∑ i ψ_i = 1`, and `support ψ_i ⊆ U_i` (or at least `ψ_i x ≠ 0 → x ∈ U_i`). Then define
   ```lean
   G₀ := ∑ i, (ψ_i).smulRight (y_i).
   ```
   Pointwise, because only indices with `x ∈ U_i` contribute and each such `y_i` is within `ε/3` of `F x`, the convexity estimate gives
   ```lean
   ‖F x - G₀ x‖ ≤ ∑ i ψ_i x * ‖F x - y_i‖ < ε / 3.
   ```
   Therefore `‖F - G₀‖ < ε/3`.

3. **Approximate each scalar partition function by scalar EML functions.**  
   By scalar EML density, for each `i` choose `φ_i ∈ EMLClosure A` with
   ```lean
   ‖ψ_i - φ_i‖ < δ
   ```
   for a carefully chosen
   ```lean
   δ := ε / (3 * n * (max 1 B))
   ```
   where `B` bounds `‖y_i‖`. Compactness of `F(X)` gives boundedness, so you can set
   ```lean
   B := max_i ‖y_i‖
   ```
   over the finite index set. Then define
   ```lean
   G := ∑ i, (φ_i).smulRight (y_i).
   ```
   By construction `G ∈ VecEML (EMLClosure A) m`.

4. **Control the perturbation error by a finite-dimensional norm estimate.**  
   Use the error bound lemma:
   ```lean
   ‖G₀ - G‖ ≤ (∑ i ‖ψ_i - φ_i‖) * B < ε / 3.
   ```
   Combine with the partition approximation:
   ```lean
   ‖F - G‖ ≤ ‖F - G₀‖ + ‖G₀ - G‖ < 2ε/3 < ε
   ```
   after tightening constants at the start if needed.

5. **Package the result as density of `VecEML`.**  
   Since `F` and `ε` were arbitrary, conclude the epsilon-density statement. If your scalar theorem is expressed via topological closure, deduce
   ```lean
   Dense (VecEML (EMLClosure A) m)
   ```
   in `C(X, Fin m → ℝ)`.

### Important technical choices in Lean

- Prefer `Fin m → ℝ` over a custom `ℝ^m`; it has ready-made `NormedAddCommGroup` and `NormedSpace ℝ`.
- Keep sums finite via `Fin n`; this avoids `Finset` bookkeeping in the main definitions.
- If `∑ i, ...` over `Fin n` causes coercion trouble for continuous maps, first prove pointwise formulas and then extensionality:
  ```lean
  ext x j <;> simp [scalarVec]
  ```
- The sup norm on `ContinuousMap` is often available under compactness assumptions. If direct norm lemmas are awkward, prove pointwise bounds
  ```lean
  ∀ x, ‖(F - G) x‖ < ε
  ```
  and then pass to the continuous-map norm using the characterization of the sup norm.
- If exact subordinate partition-of-unity lemmas are difficult to access in current Mathlib, isolate that step as a theorem using the existing compact Hausdorff partition-of-unity API. This is still mathematically substantial and likely reusable elsewhere.

### Why this matters

This theorem is the first genuinely vector-valued EML universality result that is not a disguised coordinatewise argument. It shows scalar EML primitives already suffice to synthesize finite-dimensional output geometry through barycentric coding. That has three concrete payoffs:

1. **Geometric universality.**  
   It proves density for maps into arbitrary finite-dimensional real output spaces by affine decoding from scalar gates.

2. **Simplex/multiclass readiness.**  
   Partition-of-unity coefficients are naturally simplex-valued, exactly the structure used in multiclass classification, mixture models, and certified robustness pipelines.

3. **Reusable formal architecture.**  
   The proof decomposes into independent reusable components: oscillation covers, partition of unity, scalar approximation, and affine stability. These pieces should support later results on simplex-valued outputs, probabilistic decoders, and embedding-valued approximation.

A particularly elegant endpoint would be to expose the theorem both as a density statement for `ContinuousMap X (Fin m → ℝ)` and as a constructive approximation lemma producing explicit finite affine codings from scalar EML approximants.
