## Precise Theorem Targets

Work with a finite type `α` of observables/states and a finite totally ordered type `σ` of scales.

### 1. Filtered closure reconstruction from irreducible defects

Define a finite filtered closure system:
- `c : Set α → Set α` a closure operator,
- `cr : σ → Set α → Set α` a monotone scale family,
such that for all `r ≤ s`,
- `cr r A ⊆ cr s A`,
- `cr s (cr r A) = cr s A`,
- each `cr r` is extensive, monotone, idempotent.

Define the **defect** of `A` across scales as the scale-indexed growth profile, or concretely the family of jump witnesses
\[
D(A)(r,s) := cr\,s(A) \setminus cr\,r(A), \qquad r \le s.
\]
Let irreducible defects be those nonzero defects not expressible as idempotent joins of strictly smaller defects in the induced defect semimodule.

### Main theorem A: exact reconstruction
If the filtered closure system is finite, scale-separable, and interaction-generated, then the entire coarse-graining flow is determined by the semimodule generated by irreducible closure defects. Moreover, the minimal number of semimodule generators equals the number of renormalization-relevant interaction classes.

A Lean-oriented theorem shape:

```lean
theorem filtered_closure_reconstruction
  {α σ : Type*} [Fintype α] [DecidableEq α]
  [LinearOrder σ] [Fintype σ] [DecidableEq σ]
  (F : FilteredClosureSystem α σ)
  (hsep : ScaleSeparable F)
  (hgen : InteractionGenerated F) :
  ∃ M : ScaleSemimodule σ α,
    IsMinimalRealization F M ∧
    ReconstructsFlow F M ∧
    generatorRank M = relevantClassCount F
```

A more concrete extensional form should also be proved:

```lean

  {α σ : Type*} [Fintype α] [DecidableEq α]
  [LinearOrder σ] [Fintype σ] [DecidableEq σ]
```

### 2. Semimodule-to-closure realization

Conversely, define a finitely generated idempotent `σ`-scale semimodule `M` with:
- idempotent addition = join/superposition of effective modes,
- scale action monotone in `σ`,
- residuated action encoding “how much scale is needed to activate a mode,”
- distinguished finite basis of irreducible interaction modes.

### Main theorem B: realization / duality half
Every finite separated idempotent scale semimodule determines a filtered closure system whose scale flow is reconstructed exactly from semimodule generators.


### 3. Minimality / uniqueness up to isomorphism

The reconstruction should not merely exist; it should be **canonical up to isomorphism** among finite realizations.

```lean
theorem minimal_realization_unique
  {α σ : Type*} [Fintype α] [DecidableEq α]

  (h₁ : IsMinimalRealization F M₁)
```

## Separation and Generation Hypotheses

Make the key hypotheses mathematically sharp.

### Scale-separable
A good formal condition is:
for any two distinct irreducible interaction classes, there exists some scale and test set on which their induced closure jumps differ.

```lean
def ScaleSeparable (F : FilteredClosureSystem α σ) : Prop :=
  ∀ d₁ d₂ ∈ irreducibleDefects F, d₁ ≠ d₂ →
    ∃ A r, defectEval d₁ A r ≠ defectEval d₂ A r
```

### Interaction-generated
Every scale closure is the join of contributions from irreducible defects active up to that scale.

```lean
def InteractionGenerated (F : FilteredClosureSystem α σ) : Prop :=
  ∀ A r, ∃ S ⊆ irreducibleDefects F,
    F.scaleClosure r A = reconstructFromDefectSet S A r
```

### Relevant interaction classes
Define an equivalence relation on irreducible defects by observational indistinguishability across all scales/test sets, then take quotient cardinality.

```lean

```

The theorem `generatorRank M = relevantClassCount F` is then the exact finite renormalization-count statement.

## Proof Strategy Architecture

You must pursue at least two proof routes in parallel and decide early which formalization is most robust.

### Strategy A: Finite lattice / join-irreducible route
1. Show that for each scale `r`, the family of `r`-closed sets forms a finite Moore family / complete finite lattice.
2. Package the full filtered system as a monotone diagram of finite lattices over `σ`.
3. Define defects as join-irreducible increments in the diagram, and prove that every closure profile decomposes as the join of irreducible increments.
4. Construct the semimodule from the finite join-semilattice of defect profiles; prove minimality via uniqueness of join-irreducible support modulo observational equivalence.

**Why promising:** finite lattice theory is well adapted to Lean, especially if you reduce everything to finite sets and order embeddings. This route is likely the most formalization-friendly.

### Strategy B: Residuated action / Galois reconstruction route
1. Define from each irreducible mode a “threshold scale” at which it becomes active.
2. Use residuation to characterize reconstruction as the left Kan extension / minimal activation envelope of observed defects.
3. Prove that the semimodule action recovers closures exactly by taking joins of all modes with threshold below `r`.
4. Derive minimality from residuated uniqueness: any smaller generating family fails to separate some observational jump class.

**Why promising:** this captures the physics meaning of “relevant couplings activated by scale.” It may produce the conceptually strongest theorem, though it is more abstract.

### Strategy C: Incidence/DAG extraction route
1. Encode observed closure jumps as a finite dependency hypergraph.
2. Quotient hyperedges by indistinguishability to obtain relevant interaction classes.
3. Show that transitive reduction yields the minimal renormalization DAG.
4. Identify DAG nodes with irreducible semimodule generators and prove exactness of flow reconstruction.

**Why promising:** best route for the certified algorithm theorem and executable extraction. It is also the route most likely to produce computational artifacts useful beyond pure formalization.

**Recommended plan:** Use **Strategy A** for the foundational existence/minimality theorem, then derive **Strategy C** for the reconstruction algorithm, while importing selected conceptual language from **Strategy B** to define thresholds/residuation cleanly.
