   Strategy: Use the identity F(m+n) = F(m+1)*F(n) + F(m)*F(n-1). Then gcd(F m, F(m+n)) = gcd(F m, F(m+1)*F(n) + F(m)*F(n-1)) = gcd(F m, F(m+1)*F(n)). Since gcd(F m, F(m+1)) = 1 (consecutive Fibonacci numbers are coprime), this equals gcd(F m, F n).

   Strategy: Follow the Euclidean algorithm. The pair (m, n) reduces to (gcd m n, 0) via the same steps that (F m, F n) reduces via fib_gcd_recurrence.
