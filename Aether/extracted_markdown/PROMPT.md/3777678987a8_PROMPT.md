## Precise Theorem Target

Let \(G\) be a finite connected graph, let \(q\) be a distinguished root vertex, and let
\[
S \subseteq V(G)\setminus\{q\}.
\]
Write \(D_S\) for the rooted subset divisor attached to \(S\), and \(L_S\) for the family of Laplacian columns indexed by \(S\) in the tropical bridge setup.

### Primary Conjectural Theorem
For connected \(G\), root \(q\), and \(S \subseteq V(G)\setminus\{q\}\),
\[
r(D_S)=\operatorname{tropRank}(L_S)-1
\]
if and only if both of the following hold:

1. all vertices of \(S\) lie in a single connected component of \(G-\{q\}\), and  
2. the induced subgraph \(G[S]\) is a tree.

This is the theorem to attack first.

## Proof Architecture: 3 Possible Strategies

You should not commit blindly to one route. Try these in parallel.

### Strategy A: Decomposition + obstruction by cycles
**Most promising for necessity.**

1. Use `rootedSubsetDivisor_decomposition` to express \(D_S\) as a sum over rooted/nested cut pieces.
2. Show that if \(G[S]\) contains a cycle, then one can construct a nontrivial firing relation supported inside \(S\) that does not increase divisor rank correspondingly.
3. Derive strict inequality by contradiction: assume equality, produce an “extra” tropical dependence not matched by actual chip-firing flexibility.

Why promising: the catalog already contains decomposition technology and positivity lemmas; cycles are exactly where Laplacian columns develop redundant combinatorics.

### Strategy B: Induction on \(|S|\) using leaf removal in the induced tree
**Most promising for sufficiency.**

1. Assume \(G[S]\) is a tree in one component of \(G-q\).
2. Induct on `S.card`. In the inductive step, choose a leaf \(v\in S\).
3. Compare \(D_S\) and \(D_{S \setminus \{v\}}\) using a one-vertex extension lemma; prove tropical rank and divisor rank each increase by exactly one.
4. Conclude equality for all rooted induced trees.

Why promising: trees have canonical leaves, and both chip-firing and Laplacian-column behavior should admit recursive control.

### Strategy C: Contrapositive via tropical dependence certificates
**Most promising for the converse if direct combinatorics gets messy.**

1. Define a certificate of tropical non-tightness: a dependence among columns of \(L_S\) that is not realizable by a compatible firing schedule.
2. Show that either
   - \(S\) spans multiple components of \(G-q\), or
   - \(G[S]\) contains a cycle,
   gives such a certificate.
3. Use `firingIndependentOn` to transfer this mismatch into strict inequality.

Why promising: this packages the argument in the native language of the bridge theorem and opens a route to future valuated matroid formulations.

**Recommendation:** Start with Strategy B for the positive direction and Strategy A for the negative direction. Strategy C is the conceptual unifier and may become the cleanest paper narrative even if it is not the first formal proof completed.

## Deeper Mathematical Insight

The conjecture is really asserting that the equality locus is the place where the **graphic matroid** on \(S\) behaves like a **free tropical basis** relative to the rooted Laplacian embedding. Trees are exactly the subsets with no internal cycle relations, and single-component support is exactly the condition preventing external splitting across the root cut.

This suggests the following interpretation:

- **Cycles** create internal syzygies in the Laplacian column configuration.
- **Multiple root-separated components** create external direct-sum decompositions.
- **A rooted induced tree in one component** is the unique regime with neither internal nor external slack.

In other words, equality should characterize the subsets for which the tropical linear space of Laplacian columns is combinatorially simplicial.

That is a major conceptual statement. It links the chip-firing rank function to the local face structure of a tropical linear space.
