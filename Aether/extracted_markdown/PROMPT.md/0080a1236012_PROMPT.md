### Proof Strategy Architecture

#### Strategy A: Presentation-to-polyhedron via generator coordinates
This is the most promising first route.

1. **Define the generator evaluation map**
   - Send a normalized tropical character `χ` to its coordinate vector `(χ(T₁), …, χ(Tₙ))`.
   - Quotient by tropical scaling using a chosen normalization hyperplane or base generator.

2. **Tropicalize the presentation relations**
   - Every semiring relation `p(S) = q(S)` becomes a min-plus equality on coordinate vectors.
   - Prove soundness: every character satisfies all tropicalized relations.
   - Prove completeness: every normalized solution to the tropicalized relation system extends to a character.

3. **Extract the polyhedral complex**
   - Use the finite relation set to build a rational polyhedral decomposition.
   - Show the image is exactly this complex.
   - Define Hecke multiplication by generators as a relation on coordinate vectors and prove it is piecewise-linear by finite case analysis on minima.

**Why this is best:** it is closest to what Lean can certify cleanly: finite presentations, finite relations, explicit coordinate maps, finite polyhedral decompositions.
