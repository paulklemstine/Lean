## Core Mathematical Program

Let `ι` be a finite type. Let `L : Matrix ι ι ℝ` be a symmetric positive semidefinite kernel defining a finite DPP. For an external field `h : ι → ℝ`, define the tilted partition function
\[
Z_L(h) := \det\!\big(I + \mathrm{diag}(e^{h}) \, L\big),
\]
or, if technically cleaner in Lean,
\[
Z_{β,L}(h) := \det\!\big(I + \beta \,\mathrm{diag}(e^{h})\, L\big)
\]
for `β : ℝ`.

Define the pressure
\[
\Phi_{β,L}(h) := \log Z_{β,L}(h).
\]

Define the mean occupancy vector
\[
m_i(h) := \frac{\partial \Phi_{β,L}}{\partial h_i}(h),
\]
and the susceptibility matrix
\[
\chi_{ij}(h) := \frac{\partial^2 \Phi_{β,L}}{\partial h_i \partial h_j}(h).
\]

At `h = 0`, this is the static linear response matrix of the DPP.

Your task is to formalize and prove deep theorems around the following precise target.

## Primary Breakthrough Theorem

### Theorem A (Exact susceptibility = covariance Hessian)
For any finite DPP with kernel `βL`, the Hessian of the log-partition function at zero equals the covariance matrix of occupation variables:
\[
\chi_{ij}(0)
=
\mathrm{Cov}(n_i,n_j).
\]
Equivalently,
\[
\chi(0)=K-K\circ K
\quad\text{on the diagonal/off-diagonal in the appropriate DPP form,}
\]
where
\[
K := \beta L (I+\beta L)^{-1}
\]
is the marginal kernel.

This is the exact fluctuation side of the fluctuation–dissipation principle.

## Resistance-Theoretic Target

### Theorem B (Laplacian factorization of susceptibility)
Define a conductance matrix from the marginal kernel by
\[
c_{ij} := K_{ij}^2 \quad (i\neq j),
\]
or with the temperature scaling emphasized,
\[
c_{ij}^{(\beta)} := \beta^2 L_{ij}^2
\]
when working in the weak-coupling approximation.

Let `Lap(c)` be the weighted graph Laplacian:
\[
\mathrm{Lap}(c)_{ii} = \sum_{j\neq i} c_{ij},
\qquad
\mathrm{Lap}(c)_{ij} = -c_{ij}\ \ (i\neq j).
\]

Prove that the susceptibility matrix has Laplacian structure:
- off-diagonal entries are nonpositive,
- row sums vanish after suitable augmentation / gauge-fixing,
- the associated quadratic form matches the pairwise repulsion Dirichlet form.

A strong exact theorem would be:
\[
v^\top \chi(0) v
=
\frac12 \sum_{i,j} c_{ij}(v_i-v_j)^2
\]
for an explicitly defined conductance `c_{ij}` extracted from the DPP.

If exact equality is too strong globally, prove it in one of the following forms:
1. exact on the codimension-one subspace of zero-sum vectors,
2. exact after subtracting a diagonal gauge term,
3. exact to second order in `β`,
4. exact for projection DPPs,
5. exact for kernels arising from graph incidence/Laplacian models.

A realistic formal target:

```lean

  {ι : Type*} [Fintype ι] [DecidableEq ι]
  (L : Matrix ι ι ℝ) (β : ℝ)

```

This theorem is the dissipation side: it says response is controlled by an electrical energy.

## Green Function / Effective Resistance Theorem

### Theorem C (Susceptibility controls resistance distance)
For the Laplacian built from the DPP conductances, define the effective resistance Green kernel `G` as the Moore–Penrose pseudoinverse on the zero-sum subspace. Prove a comparison theorem of the form:
\[
\chi \simeq G^{-1}
\quad\text{or}\quad
G \simeq \chi^{+},
\]
with exact equality in a natural regime (projection kernels, graph-induced kernels, or infinitesimal field response), and otherwise derive sharp inequalities.

At minimum, prove:
\[
R_{\mathrm{eff}}(i,j)
\le C \big(\chi_{ii}+\chi_{jj}-2\chi_{ij}\big)
\]
or the reverse inequality, with explicit `C`.

A more ambitious exact version:
\[
\chi_{ij}
=
\beta \, G_{ij}
\]
on the gauge-fixed subspace for a canonically associated conductance network.

### Lean 4 target signature
A feasible comparison statement:

```lean
theorem effectiveResistance_le_susceptibility_distance
  {ι : Type*} [Fintype ι] [DecidableEq ι]
  (L : Matrix ι ι ℝ) (β : ℝ)
  (i j : ι)
  (hLsymm : L.IsSymm)
  (hLpsd : PositiveSemidefinite L) :
  effectiveResistance (susceptibilityConductance β L) i j
    ≤
  susceptibilityDistance β L i j
```

where `susceptibilityDistance β L i j := (χ i i + χ j j - 2 * χ i j)`.

This is the true bridge theorem: it converts DPP response coefficients into a geometric metric.

## 2–3 Proof Strategy Paths

### Strategy 1: Log-det differential calculus → covariance identity → Dirichlet form
**Most promising.**
1. Use the determinant/log-det identities already latent in `dpp_partitionFunction_eval_ones` to define `dppPartitionFun β L h = det (I + β * D(h) ⬝ L)`.
2. Differentiate once to identify the gradient with the marginal vector, using matrix derivative identities and the resolvent
   \[
   (I+\beta D(h)L)^{-1}.
   \]
3. Differentiate again and simplify to obtain covariance entries; then use catalog Dirichlet-form identities such as `laplacianEnergy_eq_pairwise` to rewrite the quadratic form as a graph energy.

Why this is promising: it stays closest to the existing catalog and directly exposes the statistical-physics meaning of the Hessian.

### Strategy 2: Generating function of occupation indicators → combinatorial DPP identities
1. Express
   \[
   Z_L(h)=\sum_{S\subseteq ι} \det(L_S)\exp\!\Big(\sum_{i\in S} h_i\Big).
   \]
2. Show that first and second partial derivatives of `log Z_L` recover expectations and covariances of indicator variables by pure finite combinatorics.
3. Only after obtaining covariance, identify the resulting matrix with a Laplacian/Green object using algebraic identities from the repulsive information geometry file.

Why this is powerful: it avoids heavy Fréchet derivative machinery and may be more robust in Lean. It also makes the theorem conceptually transparent.

### Strategy 3: Information geometry route via Fisher metric
1. Treat `h ↦ Φ(h)` as a cumulant generating function for the DPP exponential family.
2. Invoke the general fact that the Hessian of the log-partition function is the Fisher information metric.
3. Then prove that for DPPs this metric equals a repulsive Dirichlet form induced by squared kernel entries, connecting to electrical resistance.

Why this matters: it gives the strongest cross-domain interpretation. Even if some general information-geometric theorem is not in Mathlib, formalizing a finite-dimensional special case may be elegant and reusable.

**Recommendation:** pursue Strategy 2 first for the exact covariance theorem, then Strategy 1 for the matrix-energy identity, then Strategy 3 to package the result conceptually.
