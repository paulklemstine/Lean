### Proof Strategies

**Strategy A: Structural Induction on PosEMLExpr (Most Promising)**

This is the most direct approach. Proceed by induction on the structure of `b`:

1. **Atomic cases** (variables, constants): `deriv(const c) = 0` has depth 0 ≤ 0. `deriv(var x) = 1` has depth 0 ≤ 1. ✓
2. **Exponential case** `b = exp(f)`: `deriv(exp(f)) = exp(f) · deriv(f)`. Since `depth(exp(f)) = depth(f) + 1` and `depth(deriv(f)) ≤ depth(f)` by IH, we need `depth(exp(f) · deriv(f)) ≤ depth(f) + 1 = depth(b)`. The key sub-lemma: `depth(e₁ · e₂) ≤ max(depth(e₁), depth(e₂))`, which should hold for PosEMLExpr since multiplication doesn't create new transcendence levels in the positive fragment.
3. **Logarithmic case** `b = log(f)`: `deriv(log(f)) = deriv(f) / f`. Need `depth(deriv(f)/f) ≤ depth(f) - 1 + 1 = depth(b)`. Since `depth(log(f)) = depth(f) - 1` and division by `f` reduces depth, this should go through.
4. **Multiplication case** `b = f · g`: `deriv(f · g) = f' · g + f · g'`. This is the CRITICAL case. Need `depth(f'·g + f·g') ≤ max(depth(f), depth(g))`. By IH, `depth(f') ≤ depth(f)` and `depth(g') ≤ depth(g)`. The sub-expression depths are bounded, and addition preserves the maximum depth in the positive fragment.

**Strategy B: Via Logarithmic Derivative Algebra**

Instead of proving depth stability for differentiation directly, prove it for the logarithmic derivative operator, which has better algebraic properties:

1. Prove `logDeriv(eval b) ≤ depth(b)` by induction, using the key identity `logDeriv(exp(b)) = deriv(b)`.
2. Prove the chain rule for `logDeriv`: `logDeriv(f · g) = logDeriv(f) + logDeriv(g)`, which shows that `logDeriv` is a *homomorphism* from the multiplicative group to the additive group.
3. Use this homomorphism property to show that `logDeriv` maps depth-d expressions to depth-d expressions, since addition of depth-d expressions stays at depth d.

This is elegant because it exploits the algebraic structure: `logDeriv` is a derivation in the Lie algebra sense, and derivations preserve the filtration by Hardy depth.

**Strategy C: WKB Reduction via Riccati Equation**

1. Formulate the Riccati equation `z' + z² = q(x)` where `z = y'/y = logDeriv(y)` and `y` solves `y'' = q(x)y`.
2. Prove that if `q` has Hardy level `d`, then `z` has Hardy level at most `d`. This follows because the Riccati equation is *contractive*: the quadratic term `z²` forces `z` to stay within the level set by `q`.
3. Lift this to the general PosEMLExpr case by showing every such expression arises as a solution to a Riccati equation with appropriate `q`.

This strategy connects differential equation theory to the Hardy hierarchy and would be the most conceptually deep result, but requires substantial infrastructure.

**Recommendation:** Strategy A is most promising for the Lean formalization because it directly uses the inductive structure already present in PosEMLExpr. Strategy B is the most mathematically illuminating and should be developed in parallel. Strategy C opens the door to Riccati theory but requires more foundational work.

### Cross-Domain Connections

**1. WKB Approximation ↔ Hardy Hierarchy:** The WKB ansatz writes solutions to `y'' = q(x)y` as `y = exp(∫√q dx)` times lower-order corrections. The key property that makes WKB work is that taking `log(y)` reduces the problem to first order without increasing complexity. This is *exactly* the statement that `logDeriv` preserves Hardy level. Our theorem gives a *rigorous, quantitative* foundation for what physicists have used heuristically for a century.

**2. Riccati Equation ↔ Depth Filtration:** The Riccati substitution `z = y'/y` transforms a second-order linear ODE into `z' + z² = q`. This is a *filtration-preserving* map: if `q` is at depth `d`, then `z` is at depth at most `d`. This connects the algebraic theory of differential equations (Riccati theory, Lie-Vessiot groups) to the computability-theoretic Hardy hierarchy.

**3. Tropical Geometry ↔ Logarithmic Derivatives:** In the min-plus (tropical) semiring, the tropicalization `trop(f) = log(f)` sends multiplication to addition and exponentiation to multiplication. The statement `depth(deriv(b)) ≤ depth(b)` tropicalizes to `tropicalDepth(tropicalDeriv(trop(b))) ≤ tropicalDepth(trop(b))`, which is a statement about tropical polynomial complexity. This bridges real analytic depth to tropical algebraic complexity.

**4. Information Theory ↔ Hardy Levels:** The Hardy hierarchy classifies functions by growth rate, which is the continuous analog of Kolmogorov complexity. The statement that differentiation is "free" in Hardy levels is analogous to the statement that the derivative of a computable function is computable — a continuous analog of the Kreisel-Lacombe-Shoenfield theorem.
