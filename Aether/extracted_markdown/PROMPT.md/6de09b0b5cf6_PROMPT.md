### Theorem 1: Observable lower bound becomes a distinguisher lower bound

This is the conceptual hinge.

#### Mathematical statement
Let `μ_T` be the output distribution of a `T`-round alternating hybrid walk on `S_n`, where each round uses generators from the adjacent-swap/cyclic-shift family. Assume the catalog theorem gives a lower bound showing that for `T ≤ c * n^2 * log n / k`, some observable `Φ` remains biased away from its uniform expectation by at least `δ(n,T,k) > 0`. Then there exists a Boolean distinguisher `D_Φ` such that
\[
\operatorname{TV}(\mu_T, U_{S_n}) \ge c' \, \delta(n,T,k).
\]

This is the bridge from mixing theory to cryptographic security.

#### Lean 4 target signature
```lean
theorem tv_lower_bound_of_observable_bias
    {α : Type} [Fintype α] [DecidableEq α]
    (μ ν : PMF α) (f : α → ℝ)
    (hf_nonneg : ∀ a, 0 ≤ f a)
    (hf_bdd : ∀ a, f a ≤ 1)
    (hgap : |∑ a, f a * μ a - ∑ a, f a * ν a| ≥ δ) :
    δ ≤ Real.totalVariationDist μ ν := ...
```

If `Real.totalVariationDist` is not available in the needed form, define finite-space TV distance directly:
```lean
def tvDist {α : Type} [Fintype α] (μ ν : PMF α) : ℝ :=
  (1/2) * ∑ a, |μ a - ν a|
```
and prove the theorem for that notion.

#### Why this matters
This theorem is not about one cipher. It establishes a **general reduction principle**:
> any certified observable bias is automatically a cryptographic distinguisher.

That turns spectral and combinatorial lower bounds into security lower bounds.

### Theorem 2: Alternating networks preserve detectable displacement bias below the mixing threshold

This is the actual lower bound for the architecture class.

#### Mathematical statement
For constants `c, C > 0`, for all sufficiently large `n`, if an alternating permutation network on `n` wires uses `T` rounds with at most `k` adjacent-swap operations per adjacent layer, and
\[
T \le c \frac{n^2 \log n}{k},
\]
then the output distribution `μ_T` satisfies
\[
\operatorname{TV}(\mu_T, U_{S_n}) \ge C \cdot \beta(n,T,k),
\]
for some explicit positive bias function `β` inherited from the catalog observable lower bound.

This theorem should explicitly cite and repurpose the exact lower-bound theorem from `AdjCycleMixing.lean` / `HybridWalk.lean`.

#### Lean 4 target signature
Something of the form:
```lean
theorem alternating_network_tv_lower_bound
    {n T k : ℕ}
    (hn : 2 ≤ n)
    (hk : 1 ≤ k)
    (hT : T ≤ c * (n^2 * Nat.log n) / k)
    (μT : PMF (Equiv.Perm (Fin n)))
    (hμT : μT = alternatingHybridOutputDist n T k) :
    β n T k ≤ tvDist μT (PMF.uniformOfFintype _) := ...
```

You may need to formalize with natural-number approximations to `log`, or replace `Nat.log n` with a monotone proxy if the exact asymptotic shape is awkward in Lean. The crucial thing is that the theorem still states an explicit nontrivial lower bound in terms of `n`, `T`, and `k`.

#### Why this matters
This would be, in effect, a **provable round-complexity lower bound for a cipher architecture family**. That is far stronger than “our experiments suggest more rounds are needed.”

### Theorem 3: Min-entropy deficiency lower bound from total variation

This is the information-theoretic bridge.

#### Mathematical statement
If a distribution on `S_n` has total variation distance at least `ε` from uniform, then its min-entropy is at most
\[
\log |S_n| - c(\varepsilon,n),
\]
for an explicit deficiency term. Even a coarse but formal theorem is valuable:
non-negligible TV distance implies non-maximal min-entropy.

#### Lean 4 target signature
```lean
def minEntropy {α : Type} [Fintype α] (μ : PMF α) : ℝ :=
  -Real.log (sSup {p | ∃ a, p = μ a})

theorem minEntropy_le_of_tvDist_ge
    {α : Type} [Fintype α] [DecidableEq α]
    (μ : PMF α) (ε : ℝ)
    (hε : 0 ≤ ε)
    (htv : ε ≤ tvDist μ (PMF.uniformOfFintype _)) :
    minEntropy μ ≤ Real.log (Fintype.card α) - entropyGap ε (Fintype.card α) := ...
```

If exact min-entropy is cumbersome, prove a simpler theorem on maximum point mass:
```lean
theorem exists_heavy_point_of_tvDist_ge
    {α : Type} [Fintype α] [DecidableEq α]
    (μ : PMF α) (ε : ℝ)
    (htv : ε ≤ tvDist μ (PMF.uniformOfFintype _)) :
    ∃ a : α, (1 : ℝ) / Fintype.card α + ε / Fintype.card α ≤ μ a := ...
```
and derive min-entropy deficiency from it.

#### Why this matters
Now the result speaks the language of cryptography and information theory:
**too few rounds imply entropy deficiency**, hence exploitable structure.

### Theorem 4: Deterministic networks cannot simulate the random walk too quickly

This theorem is optional but potentially the most striking.

#### Mathematical statement
Let `F_K` be the permutation induced by a keyed alternating network with key space `K`. If the induced distribution on permutations is supported on at most `|K|` outputs, then
\[
\operatorname{TV}(\mu_{F_K}, U_{S_n}) \ge 1 - \frac{|K|}{n!}.
\]
This is elementary but conceptually important when combined with architecture restrictions: **small key schedule/image size itself obstructs pseudorandomness**.

#### Lean 4 target signature
```lean
theorem tvDist_uniform_support_bound
    {α K : Type} [Fintype α] [Fintype K] [DecidableEq α]
    (f : K → α)
    (μ : PMF α)
    (hμ : μ = PMF.map f (PMF.uniformOfFintype K)) :
    1 - (Fintype.card K : ℝ) / Fintype.card α ≤ tvDist μ (PMF.uniformOfFintype _) := ...
```

This theorem bridges architecture, key schedule cardinality, and statistical security.

## Proof Strategy Architecture

You asked for 2–3 proof strategy steps. Here are three routes. You should likely pursue A + C, with B as a strengthening route.

### Strategy A: Observable-to-TV reduction, then import the catalog lower bound
1. **Abstract finite-space lemma:** prove that any bounded observable bias lower-bounds total variation distance.
   - This is a robust theorem independent of the permutation network.
   - It should require multi-step `calc` reasoning and finite expectation manipulations.
2. **Instantiate the observable with the catalog statistic** from `AdjCycleMixing` / `HybridWalk`.
   - Whatever theorem currently says “the walk has not mixed because statistic `Φ` remains biased,” reinterpret that as a statement about expectation under `μ_T` vs uniform.
3. **Conclude a cryptographic distinguisher theorem.**
   - Define a threshold distinguisher from `Φ`.
   - Deduce the TV lower bound, then phrase it as a failure of statistical security.

**Why this is most promising:** it minimizes new hard combinatorics and maximally leverages vetted catalog machinery. It is the fastest path to a theorem that feels genuinely new.

---

### Strategy B: Direct combinatorial invariant for shallow alternating networks
1. Define a displacement, inversion, or locality statistic that changes by at most `O(k)` under one adjacent-swap layer and predictably under a cyclic shift.
2. Prove by induction on the number of rounds that shallow networks cannot spread this statistic to the uniform scale.
3. Show uniform permutations have substantially different expectation or concentration for that statistic, yielding a TV lower bound.

**Why this is powerful:** it may produce a cleaner and more architecture-specific lower bound than the imported walk theorem. It would also be more interpretable for cryptographers and hardware designers.

**Why it is harder:** you must prove concentration/expectation bounds for the statistic under the uniform distribution on `S_n`, which may require more combinatorial development.

---

### Strategy C: Entropy/compression route
1. Prove a support-size or image-complexity bound for restricted alternating networks or restricted key schedules.
2. Convert support-size deficiency into TV distance from uniform.
3. Derive min-entropy deficiency and phrase this as a cryptographic weakness.

**Why this matters:** this route connects the architecture to information theory and may yield stronger practical statements about key schedules and distinguishers.

**Best use:** as a companion theorem even if the main lower bound comes from Strategy A.

## Concrete Conjecture with Falsifiable Prediction

You must include a conjecture that can be computationally attacked.

### Conjecture
For some absolute constants `c₁,c₂ > 0`, if `μ_{n,T,k}` is the output distribution of the keyed alternating permutation network on `Fin n` with `T` rounds and at most `k` adjacent swaps per swap layer, then
\[
\operatorname{TV}(\mu_{n,T,k}, U_{S_n})
\ge c₁ \exp\!\left(-c₂ \frac{Tk}{n^2}\right)
\]
for all `n ≥ 4`.

Equivalently, to achieve TV distance `< 2^{-λ}`, one needs
\[
T \ge \frac{n^2}{c₂ k}(\lambda \log 2 + \log c₁^{-1}).
\]

### Computational test

3. Estimate:
   - TV distance from uniform,

   - min-entropy,

A counterexample would be scientifically valuable: it would reveal an unexpectedly efficient diffusion mechanism.
