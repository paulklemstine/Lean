## Research Task: Berggren-tree matrix embedding of SPB Diffie–Hellman

Work with a single explicit Berggren-type generator `g : Matrix (Fin 2) (Fin 2) ℤ` satisfying
`g.det = 1` and `1 < Int.trace g` (hyperbolic case), and then optionally extend to a finite generating set `S`.
The key point is to separate two layers cleanly:

1. an **integral faithfulness / injectivity** statement for powers or normal-form words in `SL₂(ℤ)`;
2. a **finite-field reduction** statement showing that reduction mod `p` places the image in a cyclic subgroup of `SL₂(𝔽_p)` where exponent recovery is exactly DLP.

The most promising first theorem is the one-generator case, because it already gives a rigorous SPB-DH reduction and avoids hard formal-language machinery. After that, package a restricted normal-form semigroup statement for Berggren words.

### Precise theorem targets

Start with the one-generator hyperbolic embedding.

```lean
theorem berggren_pow_injective
    (g : Matrix (Fin 2) (Fin 2) ℤ)
    (hdet : g.det = 1)
    (htr : 2 < Matrix.trace g) :
    Function.Injective (fun n : ℕ => g ^ n)
```

A stronger and more usable variant is:

```lean
theorem berggren_pow_eq_iff
    (g : Matrix (Fin 2) (Fin 2) ℤ)
    (hdet : g.det = 1)
    (htr : 2 < Matrix.trace g) :
    ∀ {m n : ℕ}, g ^ m = g ^ n ↔ m = n
```

This is the faithfulness statement needed for “normalization to powers of a single hyperbolic generator”.

Then formalize reduction modulo a prime. It is likely easiest to define entrywise reduction using `ZMod p`:

```lean
def matRed (p : ℕ) : Matrix (Fin 2) (Fin 2) ℤ →*
    Matrix (Fin 2) (Fin 2) (ZMod p)
```

or at least an explicit function
`Matrix (Fin 2) (Fin 2) ℤ → Matrix (Fin 2) (Fin 2) (ZMod p)` with lemmas for multiplication and powers.

The basic determinant-preservation theorem should be:

```lean
theorem det_matRed
    {p : ℕ} [Fact p.Prime]
    (g : Matrix (Fin 2) (Fin 2) ℤ)
    (hdet : g.det = 1) :
    (matRed p g).det = 1
```

so `matRed p g` lies in `SL₂(ZMod p)`.

For the cyclic-subgroup reduction, a robust theorem is:

```lean
theorem orderOf_dvd_split_or_nonsplit
    {p : ℕ} [Fact p.Prime]
    (hpodd : p ≠ 2)
    (g : Matrix (Fin 2) (Fin 2) ℤ)
    (hdet : g.det = 1) :
    let tr : ZMod p := Matrix.trace (matRed p g)
    let Δ : ZMod p := tr^2 - 4
    (IsSquare Δ → orderOf (matRed p g) ∣ (p - 1)) ∧
    (¬ IsSquare Δ → orderOf (matRed p g) ∣ (p + 1))
```

This is the exact finite-field structure statement you want: split semisimple elements have order dividing `p-1`, non-split semisimple elements have order dividing `p+1`. If the full dichotomy is too heavy in one pass, first prove the split case:

```lean
theorem orderOf_dvd_p_sub_one_of_split
    {p : ℕ} [Fact p.Prime]

    (hdet : g.det = 1)
```

and separately a non-split version with `p + 1`.

Next state the exact DLP equivalence on the cyclic subgroup generated by the reduced Berggren element:

```lean
theorem berggren_dlp_equiv
    {α : Type*} [Group α]
    (g : α) :
    ∀ {x : Subgroup.zpowers g} {n : ℤ},
      x = ⟨g^n, by
        exact Subgroup.mem_zpowers_iff.mpr ⟨n, rfl⟩⟩ →
      ∃! k : ℤ, g^k = x
```

For finite order, the modular version is cleaner:

```lean
theorem dlp_uniqueness_mod_order
    {α : Type*} [Group α] [Finite α]
    (g : α) :
    ∀ {m n : ℕ}, m < orderOf g → n < orderOf g →
      g^m = g^n ↔ m = n
```

Applied to `α := Subgroup.closure ({matRed p g} : Set (Matrix (Fin 2) (Fin 2) (ZMod p)))` or directly to the cyclic subgroup generated by `matRed p g`, this gives the exact uniqueness of the secret exponent modulo `q := orderOf (matRed p g)`.

Then package the cryptographic reduction in theorem form:

```lean
theorem recoverExponent_eq_discreteLog
    {p : ℕ} [Fact p.Prime]
    (g : Matrix (Fin 2) (Fin 2) ℤ)
    (hdet : g.det = 1)
    (q : ℕ)
    (hq : q = orderOf (matRed p g)) :
    ∀ (n : ℕ), n < q →
      ∃! k : ℕ, k < q ∧ (matRed p g)^k = (matRed p g)^n
```

This theorem is mathematically the reduction statement: recovering `n` from `(matRed p g, (matRed p g)^n)` is exactly discrete logarithm in the cyclic subgroup generated by `matRed p g`.

Finally, for Diffie–Hellman:

```lean
theorem berggren_dh_correct
    {p : ℕ} [Fact p.Prime]
    (g : Matrix (Fin 2) (Fin 2) ℤ)
    (a b : ℕ) :
    (matRed p g)^a ^ b = (matRed p g)^b ^ a
```

and, more concretely,

```lean
theorem berggren_dh_shared
    {p : ℕ} [Fact p.Prime]
    (g : Matrix (Fin 2) (Fin 2) ℤ)
    (a b : ℕ) :
    ((matRed p g)^a)^b = (matRed p g)^(a*b) ∧
    ((matRed p g)^b)^a = (matRed p g)^(b*a)
```


This is the exact bridge from “Berggren-word public parameter” to a standard cyclic-group DH instance.

### Restricted normal-form semigroup target

If you want a genuinely semigroup-level theorem beyond powers, do not aim first for full freeness of all positive Berggren words. Instead, define a restricted language where each word corresponds to a unique matrix by monotonicity/positivity of entries.

A realistic target is a two-generator positive monoid theorem:

The right hypotheses should express that left multiplication by `A` and `B` send a chosen positive cone to disjoint sub-cones; this is the classical ping-pong mechanism in a semigroup setting. ### Proof strategy

1. **Hyperbolic powers are distinct in `SL₂(ℤ)`**  
   For `g ∈ SL₂(ℤ)` with `trace g > 2`, show `g ≠ 1` and `g` has infinite order.  
   The clean route is via the characteristic polynomial
   `X^2 - (trace g) X + 1`, whose discriminant is positive:
   `Δ = (trace g)^2 - 4 > 0`. Hence over `ℝ`, `g` has two distinct real eigenvalues
   `λ, λ⁻¹` with `λ > 1`. Then `g^m = g^n` implies `λ^m = λ^n`, hence `m = n`.
   If diagonalization over `ℝ` is awkward in Lean, use a recurrence for traces:
   `trace (g^(n+2)) = trace g * trace (g^(n+1)) - trace (g^n)`.
   Under `trace g > 2`, this sequence is strictly increasing for `n ≥ 1`, so equal powers have unequal traces unless exponents coincide.

2. **Entrywise reduction mod `p` preserves multiplication, powers, determinant, and trace**  
   Define `matRed p` entrywise and prove:
   - `matRed p (M * N) = matRed p M * matRed p N`
   - `matRed p (M^n) = (matRed p M)^n`
   - `(matRed p M).det = ((M.det : ℤ) : ZMod p)`
   - `Matrix.trace (matRed p M) = ((Matrix.trace M : ℤ) : ZMod p)`  
   These lemmas are foundational and should be isolated early; they will be reused throughout the SPB-DH development.

3. **Classify the reduced element by discriminant**  
   Let `ĝ := matRed p g`, `t := trace ĝ`, `Δ := t^2 - 4`.  
   Since `det ĝ = 1`, the characteristic polynomial is `X^2 - tX + 1`.
   - If `Δ` is a square in `𝔽_p`, the polynomial splits over `𝔽_p`, so `ĝ` is semisimple split with eigenvalues in `𝔽_pˣ`; therefore `ĝ` is conjugate into a split torus and `orderOf ĝ ∣ p-1`.
   - If `Δ` is a non-square, then the eigenvalues live in `𝔽_{p^2}` with norm `1`, so `ĝ` lies in a non-split torus of order `p+1`; therefore `orderOf ĝ ∣ p+1`.  
   In Lean, you may first prove this under an added hypothesis that `ĝ` is diagonalizable or has distinct eigenvalues, since for odd `p`, `Δ ≠ 0` handles the semisimple case cleanly. The repeated-root/unipotent case is part of the finite bad set and can be excluded.

4. **Extract the exact DLP statement from cyclicity**  
   Let `q := orderOf ĝ`. In the cyclic subgroup generated by `ĝ`, the map
   `n ↦ ĝ^n` factors through `ZMod q` and is bijective. The key lemmas are:
   - `ĝ^m = ĝ^n ↔ m ≡ n [MOD q]`
   - if `m,n < q`, then `ĝ^m = ĝ^n ↔ m = n`  
   This gives the precise mathematical reduction: any algorithm that recovers the exponent from `(ĝ, ĝ^n)` solves discrete logarithm in `⟨ĝ⟩`.

5. **Bridge normalized Berggren words to the cyclic DH instance**  
   If the SPB public parameter is a Berggren word `w` with a proven normalization theorem
   `w = g^n`, then after reduction mod `p` one has
   `matRed p w = ĝ^n`. This transports CDH/DDH statements for the SPB protocol to ordinary CDH/DDH in the cyclic subgroup `⟨ĝ⟩`.  
   The crucial formal lemma is functoriality of reduction with respect to word evaluation or powers.

### Significance

This line of work matters because it gives the SPB Diffie–Hellman program its first clean algebraic security theorem: the “geometric” Berggren/Pythagorean side is not merely suggestive, but actually embeds into a standard cyclic discrete-log setting after reduction modulo suitable primes. Formally, this accomplishes three things:

1. **Faithfulness over `ℤ`**: the Berggren-side exponent or normalized word parameter is not collapsing accidentally in the ambient matrix semigroup.
2. **Finite-field control**: after reduction mod `p`, the image lands in a subgroup whose order is explicitly constrained by the split/non-split torus dichotomy (`p-1` or `p+1`), making parameter selection mathematically transparent.
3. **Security reduction**: SPB-DH instances based on normalized Berggren generators become honest DH instances in a cyclic subgroup of `SL₂(𝔽_p)`, so exponent recovery is exactly DLP and CDH/DDH reduce to standard assumptions in that subgroup.

This theorem is the missing bridge between the existing Berggren-matrix/Pythagorean infrastructure and a cryptographically interpretable hardness assumption. Even a fully formal one-generator version would be a substantial and nontrivial advance, and the restricted normal-form semigroup extension would then push the program from “cyclicized SPB” toward genuinely noncommutative Berggren-key material with rigorous control.

```lean
## Conclusion: The Conjecture Is False

The central claim — that `tropicalRank(T_p(N)) = ω(N)` — is **false**, for multiple
independent reasons:

### 1. Dimensional Obstruction (Fatal)
The "path matrix" B(N) has dimensions (path_length × 3), since each Pythagorean triple
is a vector in ℤ³. Therefore its tropical rank is at most min(path_length, 3) ≤ 3.
But ω(N) can be arbitrarily large, so the equality fails for any N with ω(N) > 3.

### 2. Concrete Counterexample: N = 169 = 13²
- Path: (3,4,5) → (21,20,29) → (119,120,169), using B₂ twice.
- For p = 13: T₁₃(169) = [[0,0,0],[0,0,0],[0,0,2]]

  outer sum a[i] + b[j], since all entries are 0 except the (2,2) entry which is 2).
- But ω(169) = ω(13²) = 1.
- So tropical rank ≥ 2 > 1 = ω(N). **Equality fails.**

### 3. Concrete Counterexample: N = 25 = 5²
- Path: (3,4,5) → (5,12,13) → (7,24,25), using B₁ twice.
- For p = 5: T₅(25) = [[0,0,1],[1,0,0],[0,0,2]]

Not every N > 1 appears as a hypotenuse of a primitive Pythagorean triple.
For a primitive triple (a,b,c), every prime factor of c must be ≡ 1 (mod 4).
```
