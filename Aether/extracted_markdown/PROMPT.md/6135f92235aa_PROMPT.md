## Core Breakthrough Goal

Prove that there exist filtered torsion profiles with identical global birth sets but different primewise birth sets. In other words, the map
\[
F \mapsto \mathrm{TorsionBirthSet}(F)
\]
forgets information that is retained by the family
\[
F \mapsto \big(\mathrm{PTorsionBirthSet}(p,F)\big)_p.
\]

This is the first nontrivial separation theorem for the theory: it shows that the primewise invariant is not cosmetic bookkeeping, but a **strict refinement**. That is the conceptual breakthrough.

## Precise Theorem Targets

You should introduce a minimal, explicit finite model of a filtration by assigning to each filtration level a finite list or finset of cyclic torsion orders born at that level. The global birth set remembers only whether *some* torsion is born at level `n`; the primewise birth set remembers whether some torsion order born at `n` is divisible by `p`.

### New definition requirement

Define at least one genuinely new structure, for example:

```lean

  levels : ℕ → Finset ℕ

```

or a simpler finitely-supported variant already convenient for computation, such as a finite list of levels with attached torsion orders. If `Nat.supp` is inconvenient, use a concrete finite encoding:

```lean
structure FiniteBirthProfile where
  maxLevel : ℕ
  ordersAt : Fin maxLevel.succ → Finset ℕ
```

Then define:

```lean
def globalTorsionBirthSet (F : FiniteBirthProfile) : Finset ℕ := ...
def pTorsionBirthSet (p : ℕ) (F : FiniteBirthProfile) : Finset ℕ := ...
```

with the intended semantics:
- `n ∈ globalTorsionBirthSet F` iff some torsion order `m > 1` is born at level `n`,
- `n ∈ pTorsionBirthSet p F` iff some torsion order `m` born at level `n` satisfies `p ∣ m`.

You should also define a **primewise birth spectrum** as a function of `p`:

```lean
def primewiseBirthSpectrum (F : FiniteBirthProfile) : ℕ → Finset ℕ :=
  fun p => pTorsionBirthSet p F
```

This is your new mathematical object. It should be presented as the filtration-level analogue of primary decomposition.

## Main theorem statement

A fully explicit existence theorem should be the centerpiece.

### Mathematical statement

There exist filtrations `F` and `G` such that:
1. `globalTorsionBirthSet F = globalTorsionBirthSet G`,
2. there exists a prime `p` with `pTorsionBirthSet p F ≠ pTorsionBirthSet p G`.

A sharper explicit version is preferable:

- `globalTorsionBirthSet F = {1,3}`,
- `pTorsionBirthSet 2 F = {1,3}`,
- `pTorsionBirthSet 3 F = {3}`,
- `globalTorsionBirthSet G = {1,3}`,
- `pTorsionBirthSet 2 G = {3}`,
- `pTorsionBirthSet 3 G = {1,3}`.

This can be realized by taking:
- `F`: torsion orders `2` at level `1`, `6` at level `3`,
- `G`: torsion orders `3` at level `1`, `6` at level `3`.

### Suggested Lean 4 theorem signature

Adapt to your concrete encoding, but aim for something this precise:

```lean
theorem exists_same_global_different_primewise :
  ∃ F G : FiniteBirthProfile,
    globalTorsionBirthSet F = globalTorsionBirthSet G ∧
    ∃ p : ℕ, Nat.Prime p ∧ pTorsionBirthSet p F ≠ pTorsionBirthSet p G
```

and ideally the sharpened explicit witness theorem:

```lean
theorem explicit_primewise_separation :
  ∃ F G : FiniteBirthProfile,
    globalTorsionBirthSet F = ({1, 3} : Finset ℕ) ∧
    globalTorsionBirthSet G = ({1, 3} : Finset ℕ) ∧
    pTorsionBirthSet 2 F = ({1, 3} : Finset ℕ) ∧
    pTorsionBirthSet 3 F = ({3} : Finset ℕ) ∧
    pTorsionBirthSet 2 G = ({3} : Finset ℕ) ∧
```

## Proof architecture: multiple strategies

You must not proceed with a single brittle route. Here are three viable proof pathways.

### Strategy A: Explicit finite witness computation
**Best for the main separation theorem.**

1. Define explicit witness profiles `F` and `G` with nonempty births only at levels `1` and `3`.
2. Compute `globalTorsionBirthSet F`, `globalTorsionBirthSet G`, `pTorsionBirthSet 2 F`, `pTorsionBirthSet 3 F`, `pTorsionBirthSet 2 G`, `pTorsionBirthSet 3 G`.
3. Use extensionality of finsets and divisibility facts (`2 ∣ 2`, `2 ∣ 6`, `¬ 2 ∣ 3`, `3 ∣ 3`, `3 ∣ 6`, `¬ 3 ∣ 2`) to separate the invariants.

Why promising: it gives a crystal-clear witness theorem and can be mirrored in `demo.py`.

### Strategy B: Structural theorem first, explicit witness second
**Best for the conceptual result.**

1. Prove `mem_global_iff_exists_prime_mem_pTorsion`.
2. Deduce `global_eq_of_primewise_eq`.
3. Exhibit explicit `F,G` violating converse implication “same global implies same primewise,” thereby proving strictness of refinement.

Why promising: this frames the example as the negation of a tempting false converse and makes the mathematics feel inevitable, not ad hoc.

### Strategy C: Support-decomposition via prime factorization
**Most ambitious and conceptually strongest.**

1. For each level `n`, define the set of primes dividing some torsion order born at `n`.
2. Show `n ∈ globalTorsionBirthSet F` iff this prime-support set is nonempty.
3. Build `F,G` with identical support-nonemptiness at each level but different prime-support sets.

Why promising: this turns the theorem into a statement about **lossy projection from prime-support data to support-nonemptiness**, a clean information-theoretic viewpoint. This is likely the most revolutionary framing.

**Recommendation:** Use **Strategy B** as the spine, with **Strategy A** for the explicit witness and computational validation. Strategy C can become the conceptual discussion in `RESEARCH_PAPER.md` and possibly a fourth theorem.
