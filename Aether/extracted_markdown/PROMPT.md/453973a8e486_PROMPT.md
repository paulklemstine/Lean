## Assignment: Batch Certification as a Tropical-Computational Geometry Breakthrough

**Mode:** prove

Prove a genuinely new theorem that turns robustness certification from a per-point optimization problem into a **dataset-scale geometric data structure theorem**. The central vision is this:

> For a fixed tropical / max-affine classifier, the expensive geometric information should be compiled once into a certified arrangement, after which certification of an entire dataset becomes an amortized nearest-facet query problem with parallel complexity essentially linear in the batch size and highly amenable to SIMD/GPU execution.

This is not an implementation exercise disguised as mathematics. The goal is to formalize the theorem that makes such implementations inevitable.

## Core Mathematical Target

Let a classifier be represented by finitely many affine score differences
\[
\Delta_j(x)=\langle n_j,x\rangle + c_j,\qquad j \in J,
\]
where each \(n_j\in \mathbb{R}^d\) is a precomputed normal vector corresponding to either a class-separating tropical facet or a ReLU-region-local decision boundary. For a point \(x\), define the certified radius
\[
r(x)=\min_{j\in J_x} \frac{\Delta_j(x)}{\|n_j\|_*},
\]
where \(J_x\) is the active set of valid separating inequalities for the predicted class and \(\|\cdot\|_*\) is the dual norm to the perturbation norm.

The theorem to prove is that when the normals are precomputed, **batch certification decomposes into a reusable geometric preprocessing phase plus parallel dot-product evaluation**, and that under mild incremental assumptions one gets an amortized update bound strictly better than recomputing all certificates from scratch.

### Precise Theorem Statement

Work first in Euclidean norm for formal simplicity.

Let \(d,m,N : \mathbb{N}\). Let \(n : \mathrm{Fin}\; m \to \mathbb{R}^d\), \(c : \mathrm{Fin}\; m \to \mathbb{R}\), and dataset \(X : \mathrm{Fin}\; N \to \mathbb{R}^d\). Define
\[
\mathrm{dist}_j(x) = \frac{\langle n_j,x\rangle + c_j}{\|n_j\|},
\qquad
\mathrm{cert}(x)=\min_j \mathrm{dist}_j(x),
\]
assuming all \(n_j\neq 0\).

Then prove a theorem of the following flavor:

1. **Exact batch decomposition:** certification of all \(X_i\) is exactly the matrix computation of all dot products \(\langle n_j, X_i\rangle\) followed by rowwise affine shifts, norm normalization, and pointwise minima.
2. **Incremental amortization theorem:** if a new point \(x'\) is inserted into a dataset while the normals \(n_j\) and offsets \(c_j\) are unchanged, then the update cost is \(O(md)\) arithmetic operations for exact certification of \(x'\), versus \(O(Nmd)\) to recompute all certificates from scratch; equivalently, the amortized per-insertion recomputation overhead is constant relative to the existing dataset size.
3. **Region-local globalization theorem for piecewise-ReLU/tropical networks:** if each linear region \(R\) of a ReLU network admits a local tropical certificate
\[
r_R(x)=\min_{j\in J_R} \frac{\langle n_{R,j},x\rangle+c_{R,j}}{\|n_{R,j}\|},
\]
then the global certificate at \(x\in R\) is
\[
r_{\mathrm{global}}(x)=\min\big(r_R(x),\, \mathrm{dist}(x,\partial R)\big),
\]
provided the predicted class is constant on \(R\).

This third statement is the real breakthrough: it connects tropical certification, polyhedral geometry of ReLU regions, and dynamic nearest-boundary data structures.

## The Breakthrough Theorem to Aim For

### Theorem A: Exact Batch Certification by Reusable Facet Evaluation
For any finite family of nonzero normals \(n_j\) and offsets \(c_j\), batch certification over a dataset is exactly equivalent to a single precomputed facet table followed by independent pointwise reductions:
\[
\forall i,\quad \mathrm{cert}(X_i)=\min_j \frac{\langle n_j,X_i\rangle+c_j}{\|n_j\|}.
\]
This sounds obvious, but formalizing it in a way that supports incremental and region-local extensions is the foundation.

### Theorem B: Incremental Certification is Strictly Better than Recompute-All
Suppose the classifier geometry is fixed and only dataset points are inserted. Then certification of the enlarged dataset can be updated without changing any precomputed normals or offsets, and only the new point requires fresh facet evaluation. Formally, old certificates are preserved and the new certificate is computed by one facet-min reduction.

This is a theorem of **persistence under dataset extension**.

### Theorem C: Global Piecewise-Tropical ReLU Certificate
Let \(f\) be a ReLU network, \(R\) a linear region containing \(x\), and assume the predicted class is constant on \(R\). If \(r_R(x)\) is the local tropical/affine certificate within \(R\), then
\[
r_{\mathrm{global}}(x)=\min\big(r_R(x), \operatorname{dist}(x,\partial R)\big).
\]
This is the mathematically decisive statement. It says: local robustness survives until either the local classifier fails or the point exits the region where that classifier is valid.

That is the exact theorem that turns piecewise-linear deep networks into certifiable polyhedral dynamical systems.

## Proof Strategy Architecture

### Strategy A: Direct finite-dimensional convex geometry
Most promising for Lean.

1. Define each local decision boundary and region boundary as affine hyperplanes / halfspaces.
2. Prove that inside a fixed region \(R\), the network reduces to an affine score map using `deep_relu_tropical_terms`.
3. Show that the largest safe perturbation radius within \(R\) is the minimum of:
   - distance to class-switching hyperplanes,
   - distance to region-boundary hyperplanes.
4. Conclude the global formula by intersecting these constraints.

**Why this is promising:** finite sets, Euclidean distance to hyperplanes, and minima over finite families are Lean-friendly and align with Mathlib’s geometry APIs.

### Strategy B: Arrangement-theoretic proof via polyhedral complexes
More ambitious, potentially more revolutionary.

1. Construct the hyperplane arrangement induced by ReLU boundaries and class-difference equalities.
2. Show the arrangement partitions space into cells on which the classifier is affine and class-constant.
3. Prove the certificate equals the distance to the complement of the current safe cell.
4. Identify this as a nearest-facet problem in a polyhedral complex.

**Why this matters:** this elevates certification from an ad hoc formula to a theorem about cell complexes. It opens the door to topological and combinatorial invariants of robustness.

### Strategy C: Tropical algebraic proof
Most visionary, perhaps hardest to complete fully in one cycle.

1. Express score functions as tropical polynomials / max-affine forms.
2. Characterize decision boundaries as tropical hypersurface comparisons.
3. Show local linearization on each chamber and identify the certificate with chamber-exit distance.
4. Reinterpret batch certification as tropical evaluation followed by a min-reduction.

**Why this is powerful:** it connects certified robustness to tropical geometry proper, not just polyhedral numerics. This could seed a new “tropical safety” subfield.

**Recommendation:** complete Strategy A formally, document Strategy B as the geometric reinterpretation, and frame Strategy C in `FUTURE_DIRECTIONS.md`.

## Cross-Domain Connections

### Computational Geometry
This is a dynamic nearest-facet / nearest-hyperplane problem in a polyhedral arrangement. If formalized well, it creates a bridge between certified ML and kinetic geometry.

### Database Algorithms
Batch certification is a column-store query:
- precompute facet normals,
- stream points,
- perform fused multiply-add reductions,
- maintain minima.
This invites formal analogies with priority queues, incremental views, and kinetic indexing.

### Real-Time ML
The theorem implies **online robustness monitoring**: when data points stream in but the model is fixed, one does not re-solve the geometric problem from scratch.

### Representation Theory / Boundary Reconstruction
The analogy with `gl3_value_determined_by_boundary_and_levi` is profound: global behavior reconstructed from boundary data plus local structure. Robustness certification may admit a general “Levi + boundary” principle for piecewise-linear systems.

### Complexity Theory
A certified radius becomes a finite minimization over precompiled affine forms. This suggests a complexity stratification:
- preprocessing complexity,
- query complexity,
- update complexity.
Formalizing this could connect robustness to static-vs-dynamic complexity separations.
