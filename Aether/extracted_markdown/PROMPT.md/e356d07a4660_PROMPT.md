Build a standalone Lean 4 development for a reduced and precise version of the 'EML Special Functions' direction, focusing only on statements that can be completed with current Mathlib APIs and without placeholders.

Primary objective:
Create one coherent file (or two tightly related files) formalizing the following two packages.

Package A: Gamma as a meromorphic special function
1. Prove that Complex.Gamma is meromorphic on ℂ, using existing Mathlib theorems rather than reproving analytic facts from first principles.
2. Prove that z ↦ 1 / Complex.Gamma z is differentiable everywhere (hence entire).
3. Prove that for each n : ℕ, (1 / Complex.Gamma (-n)) = 0, and package the pole set as the nonpositive integers.
4. Prove the factorial interpolation theorem Complex.Gamma (n + 1) = n! (with the correct coercions/types required by Mathlib).
5. If available from existing lemmas, prove a clean no-zeros statement for Gamma away from the pole set; otherwise omit this rather than leaving gaps.
6. State a final theorem summarizing the package in precise Mathlib language, e.g. a theorem that Gamma is meromorphic and that its reciprocal is entire with zeros at the nonpositive integers.

Package B: Hypergeometric formal power series
1. Define the coefficient sequence for the Gauss hypergeometric series 2F1(a,b;c;z) at the level of ℂ-valued sequences or formal power series.
2. Prove the standard coefficient recurrence
   (n+1)(n+c) a_{n+1} = (n+a)(n+b) a_n
   in whatever normalized form is most convenient in Lean.
3. Use that recurrence to prove the corresponding formal power series satisfies Gauss's hypergeometric differential equation in formal-power-series form. It is acceptable to work entirely formally and not prove analytic convergence.
4. Keep the statement sharply scoped: the goal is a formal differential-equation identity for the series, not global analytic continuation.
