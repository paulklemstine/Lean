## Precise Theorem Statements to Target

You may need to prove these in stages, with weaker versions first. But these are the right north stars.

### Theorem 1: Canonical finite Berggren multiresolution decomposition

For each `n : ℕ`, let `Layer n` be the depth-`n` Berggren nodes, identified with words of length `n` in a 3-letter alphabet. Let
`V n := Layer n → ℂ`.
Define `Scaling n k ⊆ V n` to be the subspace of functions constant on depth-`k` cylinders, and define `Detail n k` as an orthogonal complement of `Scaling n k` inside `Scaling n (k+1)`.

**Target statement:**
For every `n`, there exists a canonical internal direct sum
\[
V_n \cong \mathrm{Scaling}(n,0)\ \oplus\ \bigoplus_{k=0}^{n-1} \mathrm{Detail}(n,k),
\]
with each `Detail n k` generated by local mean-zero branch wavelets.

A Lean-oriented type signature could be:

```lean
theorem berggren_multiresolution_exists
  (n : ℕ) :
  ∃ (Scaling : ℕ → Submodule ℂ (LayerFun n))
    (Detail : ℕ → Submodule ℂ (LayerFun n)),
    Scaling 0 = ⊤ ∧
    (∀ k, k < n → Detail k ≤ Scaling (k+1)) ∧
    (∀ k, k < n → IsCompl (Scaling k) (Detail k)) ∧
    ⨆ k : Fin n, Detail k ⊔ Scaling 0 = ⊤
```

A more realistic first formalization may replace the final supremum statement by an explicit basis theorem:

```lean
theorem berggren_wavelet_basis_exists
  (n : ℕ) :
  ∃ (ι : Type) [Fintype ι] (ψ : ι → Layer n → ℂ),
    LinearIndependent ℂ ψ ∧
    Submodule.span ℂ (Set.range ψ) = ⊤
```

Then strengthen to an orthogonal basis once the inner-product space setup is in place.

### Theorem 2: Block diagonalization of natural commuting transport algebra

Let `Avg n`, `ShiftA n`, `ShiftB n`, `ShiftC n`, or suitable depth-preserving descendants/rewriting operators act on `V n`. Define the commutative algebra `𝒜 n` generated by those operators that preserve depth and commute.

**Target statement:**
In the Berggren wavelet basis, every `T ∈ 𝒜 n` preserves the scaling/detail decomposition and acts blockwise on each detail level.

Lean-style target:

```lean
theorem berggren_transport_preserves_multiresolution
  (n : ℕ) (T : Module.End ℂ (LayerFun n))
  (hT : T ∈ berggrenCommutingAlgebra n) :
  ∀ k, T '' (DetailSpace n k) ≤ DetailSpace n k ∧
       T '' (ScalingSpace n) ≤ ScalingSpace n
```

```lean
theorem berggren_transport_block_diagonalizable
```

If “block diagonal” is too ambitious initially, prove invariant-subspace preservation and triangularization over finite-dimensional spaces.

### Theorem 3: Periodic observables have sparse spectral support

Let `obs : Layer n → α` where `α` is finite, e.g. `ZMod q`, induced by hypotenuse modulo `q`, height modulo `q`, or a valuation surrogate. Let `f = φ ∘ obs` for some class function `φ : α → ℂ`.

**Target statement:**
If `f` factors through a coarse quotient determined by prefixes or arithmetic classes compatible with the Berggren action, then its wavelet coefficients vanish off a structured subset of scales/locations. In particular, functions constant on depth-`k` cylinders have no detail coefficients below scale `k`; and arithmetic observables periodic modulo `q` admit bounded spectral support with respect to the induced quotient partition.

Lean-style theorem:

```lean
theorem wavelet_coefficients_vanish_of_prefix_constant
  (n k : ℕ) (hk : k ≤ n) (f : Layer n → ℂ)
  (hf : IsPrefixConstant n k f) :
  ∀ j, k ≤ j → ∀ ψ ∈ detailWavelets n j, inner ℂ f ψ = 0
```

And an arithmetic version:

```lean
theorem sparse_spectrum_of_modular_observable
  (n q : ℕ) (f : Layer n → ℂ)
  (hf : ∃ g : ZMod q → ℂ, f = fun x => g (hypotenuseMod q x)) :
  ∃ S : Finset (WaveletIndex n),
    ∀ i, i ∉ S → waveletCoeff n f i = 0
```

Even if exact modular sparsity is too strong globally, prove a weaker but still substantial theorem:
- coefficient support is controlled by the partition induced by the observable,
- or support cardinality is bounded by the number of observable classes.

### Theorem 4: Certified reconstruction / period finding on bounded layers

Define a finite transform `F_n` from functions on `Layer n` to spectral coefficients. Show exact inversion on the image, and stable reconstruction under bounded perturbation.

**Target statement:**
If `f` has structured sparse support in the Berggren spectral basis, then from its retained coefficients one can reconstruct `f` exactly; under perturbation bounded in a suitable norm, the recovered period/class signal is certified correct when the noise lies below an explicit threshold.

Lean-style target:

```lean
theorem berggren_wavelet_reconstruction
  (n : ℕ) (f : Layer n → ℂ) :
  reconstruct n (forwardTransform n f) = f
```

Sparse version:

```lean
theorem exact_recovery_of_sparse_signal
  (n : ℕ) (f : Layer n → ℂ) (S : Finset (WaveletIndex n))
  (hf : ∀ i, i ∉ S → waveletCoeff n f i = 0) :
  reconstructFromSupport n S (restrictedCoeffs n f S) = f
```

Certified robustness version, using the existing theorem as a stability engine:

```lean
theorem certified_period_recovery_of_bounded_height
  (n : ℕ) (f g : Layer n → ℂ)
  (hclose : berggrenSignalDist f g ≤ ε)
  (hper : HasHiddenPeriodOnObservable n f)
  (hbound : BoundedHeightSignal n f) :
  CertifiedRecoveredPeriod n g = True
```

This theorem should explicitly exploit
`quantum_lipschitz_certified_robustness_of_bounded_height`
to transfer recovery guarantees from ideal arithmetic signals to perturbed signals.

## Proof Strategy Architecture

### Strategy A: Combinatorial word-tree MRA
This is likely the most promising initial route.

1. **Identify depth-`n` Berggren nodes with ternary words.**
   The arithmetic triple data is then a labeling on a regular rooted tree. The multiresolution structure depends only on the tree, not yet on deep arithmetic facts. This makes the decomposition canonical and easy to formalize.

2. **Construct local Haar-type wavelets on each branching event.**
   For each prefix `u` of length `k`, define:
   - one scaling vector constant on the cylinder over `u`,
   - two independent mean-zero detail vectors distinguishing the three children.
   Then tensor/extend these to depth `n`.

3. **Prove spanning and linear independence by dimension count.**
   Since `|Layer n| = 3^n`, explicit basis cardinality arguments should close the decomposition theorem. Orthogonality follows from disjoint support and mean-zero cancellation.

Why this is promising: it avoids representation theory at first while already delivering a real wavelet theorem. It also produces explicit executable objects in Lean.

---

### Strategy B: Finite representation theory of the Berggren transition monoid
This is the visionary route for the “Fourier duality” language.

1. **Define the finite transition monoid acting on bounded layers.**
   On `Layer n`, the generators induce endomorphisms or partial transport operators. Package the algebra they generate.

2. **Study its module structure on `V n`.**
   Show the scaling/detail decomposition refines the isotypic decomposition or at least yields invariant submodules.

3. **Interpret wavelet coefficients as matrix coefficients against irreducible blocks.**
   This gives the true nonabelian Fourier flavor: not just a basis change, but a spectral decomposition with algebraic meaning.

Why this matters: it upgrades the project from “tree wavelets” to “Berggren Fourier analysis.” Even a partial theorem here would be field-opening. If full irreducible classification is too difficult, prove semisimplicity/invariant decomposition for a commuting subalgebra.

---

### Strategy C: Certified arithmetic recovery via quotient observables and robustness
This should be built after Strategy A gives the transform.

1. **Define observable partitions** such as hypotenuse mod `q`, height bands, or prefix classes.
2. **Prove coefficient vanishing/concentration** for functions constant on these partition cells or for observables Lipschitz with respect to tree distance.
3. **Invoke robustness machinery** from
   `quantum_lipschitz_certified_robustness_of_bounded_height`
   to show perturbations preserve recoverable class/period information below a threshold.

Why this is powerful: it turns the spectral theory into an algorithmic theorem, not merely a structural one. This is where the “quantum period-finding” analogy becomes mathematically operational.

## Cross-Domain Connections You Should Explicitly Exploit

### 1. Wavelets on trees ↔ arithmetic of primitive triples
The Berggren tree is not just a graph; it is a Diophantine generative system. A wavelet decomposition on this tree is therefore an arithmetic microscope. This links harmonic analysis on hierarchical structures with classical number theory.

### 2. Noncommutative Fourier analysis ↔ quantum algorithms
Quantum period-finding succeeds because hidden arithmetic structure becomes visible in a spectral basis. Here, bounded Berggren layers provide a finite nonabelian analog: arithmetic observables on primitive triples become signals whose hidden classes are detectable from transform coefficients.

### 3. Automata / symbolic dynamics ↔ Diophantine geometry
Words in `{A,B,C}` encode both symbolic dynamics and primitive triples. This lets you import finite-state, language-theoretic, and transfer-operator ideas into the geometry of Pythagorean generation.

### 4. Certified numerics / robustness ↔ exact arithmetic signal recovery
The existing theorem
`quantum_lipschitz_certified_robustness_of_bounded_height`
should not remain isolated. Use it as the bridge from exact decomposition theorems to certified reconstruction guarantees under perturbation. This is the computational credibility layer.

### 5. Expander-style transport ↔ spectral compression
Even if previous Berggren work emphasized hashing or expansion, your theorem should reinterpret transport as a spectral object. This opens a path from combinatorial expansion to arithmetic compression and detection.
