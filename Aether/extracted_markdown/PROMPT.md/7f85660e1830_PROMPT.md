## Assignment: 4. General Linear Map Kernel Density Theorem

**Mode**: `prove`

Prove a genuinely general finite-field representation theorem, not a matrix-coordinate corollary. The point is to extract a structural law of finite-dimensional linear maps over `ZMod q` that survives every change of basis and every representation model. This should become the canonical theorem from which matrix bounds, coding-theoretic rank estimates, and finite-model counting lemmas all descend.

### Core Breakthrough Target

For a nonzero linear map between finite-dimensional vector spaces over the prime field `ZMod q`, the kernel occupies at most a `1/q` fraction of the domain. In cardinal form:

```lean
theorem nonzero_linear_map_kernel_density
    {q : ℕ} [Fact q.Prime]
    {V W : Type*} [AddCommGroup V] [Module (ZMod q) V]
    [AddCommGroup W] [Module (ZMod q) W]
    [FiniteDimensional (ZMod q) V] [FiniteDimensional (ZMod q) W]
    [Fintype V] [Fintype W]
    (f : V →ₗ[ZMod q] W) (hf : f ≠ 0) :
    Fintype.card f.ker * q ≤ Fintype.card V
```

But do not stop there. The truly clean structural theorem is stronger and should be proved first if feasible:

```lean
theorem card_kernel_mul_card_range
    {q : ℕ} [Fact q.Prime]
    {V W : Type*} [AddCommGroup V] [Module (ZMod q) V]
    [AddCommGroup W] [Module (ZMod q) W]
    [FiniteDimensional (ZMod q) V] [FiniteDimensional (ZMod q) W]
    [Fintype V] [Fintype W]
    (f : V →ₗ[ZMod q] W) :
    Fintype.card f.ker * Fintype.card f.range = Fintype.card V
```

and then derive the target theorem from the fact that `f ≠ 0` forces `q ≤ Fintype.card f.range`.

An even more conceptual strengthening, if Mathlib support cooperates, is the dimension/cardinality interface:

```lean
theorem nonzero_linear_map_kernel_codim_pos
    {q : ℕ} [Fact q.Prime]
    {V W : Type*} [AddCommGroup V] [Module (ZMod q) V]
    [AddCommGroup W] [Module (ZMod q) W]
    [FiniteDimensional (ZMod q) V] [FiniteDimensional (ZMod q) W]
    (f : V →ₗ[ZMod q] W) (hf : f ≠ 0) :
    FiniteDimensional.finrank (ZMod q) f.ker < FiniteDimensional.finrank (ZMod q) V
```

from which the cardinal inequality follows via `|X| = q^(finrank X)` for finite-dimensional `ZMod q`-spaces.

### Why this is a breakthrough

This is not “just rank-nullity again.” In formal mathematics, the leap from `Matrix (Fin m) (Fin n) (ZMod q)` to arbitrary finite-dimensional modules is the difference between a coordinate lemma and a reusable theorem schema. Once established, this theorem becomes a universal counting principle for:

- linear codes and parity-check kernels,
- finite-field representation theory,
- randomized linear hashing,
- additive combinatorics over `𝔽_q`,
- finite-state verification of algebraic systems,
- probabilistic soundness arguments where a nonzero linear constraint is violated on at most `1/q` of inputs.

This is the exact formal bridge from “a matrix has many non-solutions” to “every nontrivial linear observable has density gap.” That bridge opens a field of formalized finite-field probability and coding theory.

### Proof architecture: three viable strategies

#### Strategy A: Quotient / first isomorphism theorem route
This is the most conceptual and likely the most reusable.

1. Use the linear equivalence induced by the first isomorphism theorem:
   `V ⧸ f.ker ≃ₗ[ZMod q] f.range`.
2. Convert linear equivalence into equality of `Fintype.card`.
3. Use the additive-group cardinality formula for quotients:
   `Fintype.card (V ⧸ f.ker) * Fintype.card f.ker = Fintype.card V`.
4. Deduce
   `card ker * card range = card V`.
5. Show `hf : f ≠ 0` implies `f.range` is nontrivial, hence has dimension at least `1`, hence cardinal at least `q`.

Why this is promising: it bypasses delicate dimension arithmetic and gives the exact multiplicative structure immediately. It is also the theorem form that future work in coding theory and finite abelian groups will want.

#### Strategy B: finrank-first route
This is closest to the mathematical intuition in the assignment.

1. Use rank-nullity:
   `finrank ker + finrank range = finrank V`.
2. Prove `hf` implies `finrank range ≠ 0`, hence `1 ≤ finrank range`.
3. Deduce
   `finrank ker ≤ finrank V - 1`.
4. Use the finite-field cardinality theorem:
   `Fintype.card X = q ^ finrank X`
   for every finite-dimensional `ZMod q`-space `X`.
5. Reduce the theorem to monotonicity of powers of `q`, using primality to ensure `1 < q`.

Why this is promising: it produces a theorem in dimension language, which is often easier to reuse in later representation-theoretic arguments. It also reveals the exact codimension phenomenon.

#### Strategy C: Basis transport to matrices
This is less elegant but often robust in Lean when abstract linear algebra APIs are awkward.

1. Choose finite bases of `V` and `W`.
2. Transport `f` to a matrix over `ZMod q`.
3. Apply or derive the corresponding matrix kernel-cardinality theorem.
4. Pull the result back through linear equivalences preserving kernel size and ambient cardinality.

Why this is promising: if there is already matrix infrastructure in the local development, this may be the shortest path. Why it is less ideal: it proves the right theorem for the wrong reason and leaves less reusable abstract infrastructure.

**Recommendation**: Start with Strategy A. If quotient cardinality lemmas are painful, pivot to Strategy B. Keep Strategy C as a tactical fallback, not the conceptual center.

### Cross-domain connections to foreground

This theorem is a formal nucleus for several domains that normally remain disconnected in theorem libraries:

- **Coding theory**: the kernel of a parity-check map is a linear code; this theorem bounds code density exactly by codimension.
- **Probabilistic verification**: a nonzero linear test accepts at most a `1/q` fraction of random inputs; this is the linear ancestor of Schwartz–Zippel phenomena.
- **Additive combinatorics**: kernels are maximal structured sets with one linear constraint; density `1/q` is the atomic hyperplane density law.
- **Cryptography / hashing**: universal linear hash families over `𝔽_q` rely on collision sets that are affine kernels of nonzero linear maps.
- **Representation theory**: any nontrivial linear functional on a finite-dimensional representation cuts out a codimension-1-or-more subrepresentation-like constraint set.
- **Finite model theory / complexity**: counting solutions to linear predicates over finite fields is foundational for AC0[p], PCP-style algebraization, and formalized counting arguments.

This is how you make the theorem feel inevitable and revolutionary: it is the exact algebraic primitive behind “one nontrivial linear condition costs one factor of `q`.”
