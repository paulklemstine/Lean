## YOUR ASSIGNMENT: Berggren Tree Completeness — Unique Descent, Exhaustiveness, and Cryptographic Hash via Inverse Matrix Well-Founded Induction

**DOMAIN**: Pythagorean × Cryptography × Quantum Walks

**CONCEPT**: Prove that every primitive Pythagorean triple (a,b,c) with a² + b² = c², gcd(a,b)=1, and a,b,c > 0 appears **exactly once** in the Berggren tree generated by matrices A, B, C from root (3,4,5). The proof proceeds by:

1. **Inverse Matrix Construction**: Define the three inverse Berggren matrices A⁻¹, B⁻¹, C⁻¹ explicitly and prove they are indeed inverses.
2. **Unique Parent Theorem**: Every primitive triple with c > 5 has exactly one valid parent among A⁻¹(t), B⁻¹(t), C⁻¹(t) that yields a triple of positive integers.
3. **Hypotenuse Descent**: The unique parent has strictly smaller hypotenuse (c_parent < c_child), enabling well-founded induction.
4. **Exhaustiveness**: By well-founded induction on hypotenuse, every primitive triple descends to (3,4,5).
5. **Uniqueness**: The descent path is unique, so each triple appears exactly once.

This completes the algebraic characterization and opens two breakthrough directions:
- **Post-quantum hash**: The unique descent path gives an injective map `PrimTriple → List (Fin 3)`, yielding a collision-resistant hash function with O(log c) output length and security reducible to the unique factorization of primitive triples.
- **Quantum walk completeness**: The Berggren tree is a 3-regular tree, and exhaustiveness ensures a quantum walk on it is ergodic over all primitive triples with mixing time O(√(c/ln c)).

### PROOF STRATEGY DETAILS

**For berggren_parent_exists** (Theorem 2 — the hardest part):
1. **Parity Classification**: For a primitive triple (a,b,c), exactly one of a,b is even (by coprime). Case split:
   - If a is odd, b is even: Show A⁻¹·(a,b,c)ᵀ has all positive entries.
   - If a is even, b is odd: Show B⁻¹·(a,b,c)ᵀ has all positive entries.
   - C⁻¹ is never the parent for primitive triples with c > 5 (or only for a specific subcase).
2. **Direct Computation**: Compute A⁻¹·(a,b,c)ᵀ = (a+2b-2c, 2a+b-2c, 2a+2b-3c). Show positivity using a² + b² = c².
3. **Fallback**: Use omega/larith after establishing a + b > c (from the triangle inequality for acute angles).

**For berggren_descent_hypotenuse_decreases** (Theorem 4):
1. Compute c_parent = |2a + 2b - 3c| or similar for each inverse.
2. Show c_parent < c using c² = a² + b² and the constraint a + b > c (for c > 5).
3. Key inequality: 2(a + b) - 3c < c ⟺ a + b < 2c, which follows from (a+b)² < 4c² (since a < c and b < c).

**For berggren_tree_exhaustive** (Theorem 6 — the crown jewel):
1. Define `descentSequence : PrimTriple → List (Fin 3 × PrimTriple)` that repeatedly applies the unique inverse.
2. Prove it terminates using `hypotenuseMeasure` and well-founded induction on ℕ.
3. Prove the last element is (3,4,5) by showing no other triple with c = 5 is primitive.
4. Extract the path and prove it reconstructs the original triple via forward matrices.
