## Central Vision

The Breuillard–Green–Tao philosophy says that failure of growth is never accidental: it signals hidden algebraic structure. In finite matrix groups, the first genuinely formalizable incarnation of this idea should be:

> a definable set with bounded product growth is controlled by a definable subgroup-like object, while a set not so controlled must exhibit strict product growth.

This is not just a restatement of a growth theorem. It is a **model-theoretic recoding** of product expansion into definable structure. If you can make this work even for a robust fragment of `GL(2, 𝔽_q)`, you open a path toward formal approximate group theory, pseudofinite asymptotics, and eventually a verified Hrushovski/BGT-style structural interface.

## Precise Formalization Target

You should avoid full first-order model theory at the outset. Instead, introduce a mathematically sharp, Lean-friendly proxy for definability:

### New definition to introduce
A subset of `GL(2, 𝔽_q)` is **polynomially definable** if it is the image of a polynomial map from a finite affine space over `𝔽_q` into matrices, together with an invertibility witness.

This is the correct finite-field shadow of definability: concrete enough for Lean, rich enough to capture algebraic families, and flexible enough to support algorithmic enumeration.

You should define at least one genuinely new structure, for example:

```lean
structure PolyDefinableSubset (F : Type*) [Field F] (n : ℕ) where
  arity : ℕ
  carrier : Set (Matrix (Fin n) (Fin n) F)
  witness :
    ∃ p : (Fin arity → F) → Matrix (Fin n) (Fin n) F,
      (∀ x, p x ∈ carrier ↔ IsUnit (Matrix.det (p x))) ∧
      (∀ g ∈ carrier, ∃ x, p x = g)
```

If this exact formulation is too rigid, refine it. But the object must be mathematically meaningful and genuinely new.

Also define a subgroup-control notion, e.g. a **definably controlled set**:

```lean
def DefinablyControlledBy
  {G : Type*} [Group G] (A H : Set G) : Prop :=
  ∃ g : G, A ⊆ Set.mul {g} H ∨ A ⊆ Set.mul H {g}
```

or a stronger variant involving boundedly many cosets if needed.

Finally define a growth profile:

```lean
def prodSet {G : Type*} [Group G] (A B : Set G) : Set G :=
  {g | ∃ a ∈ A, ∃ b ∈ B, a * b = g}

def setPow {G : Type*} [Group G] : ℕ → Set G → Set G
| 0, A => {1}
| n+1, A => prodSet (setPow n A) A

def StrictGrowthProfile {G : Type*} [Group G] (A : Set G) (k : ℕ) : Prop :=
  Fintype.card ↥(setPow k A) < Fintype.card ↥(setPow (k+1) A)
```

You may need finite-set versions (`Finset`, `Fintype`, `Subtype`) for cardinality. That is encouraged.

## Exact Theorem Targets

You must prove at least **3 substantial theorems**, all nontrivial, all with multi-step proofs. At least one should connect to another domain.

### Theorem 1: Definable growth-or-control dichotomy in finite groups
A first abstract theorem should isolate the combinatorial core.

**Mathematical statement**

Let `G` be a finite group and `A ⊆ G` a finite symmetric subset with `1 ∈ A`. If `|A^2| ≤ |A|`, then `A` is a subgroup. Hence if `A` is not contained in a coset of any proper subgroup and is not itself a subgroup, then `|A^2| > |A|`.

This is classical in spirit, but the formal target should be sharpened into a reusable dichotomy.

**Lean-style signature sketch**
```lean
theorem subgroup_of_small_doubling_eq
  {G : Type*} [Group G] [Fintype G]
  (A : Finset G)
  (h1 : (1 : G) ∈ A)
  (hsym : ∀ a, a ∈ A → a⁻¹ ∈ A)
  (hmul : card (A * A) ≤ card A) :
  ∃ H : Subgroup G, ↑A = (H : Set G)
```

A stronger and more usable corollary:

```lean
theorem strict_growth_of_not_subgroup
  {G : Type*} [Group G] [Fintype G]
  (A : Finset G)
  (h1 : (1 : G) ∈ A)
  (hsym : ∀ a, a ∈ A → a⁻¹ ∈ A)
  (hproper_control : ∀ H : Subgroup G, ↑A ⊆ (H : Set G) → H = ⊤)
  (hA_not_subgroup : ¬ ∃ H : Subgroup G, ↑A = (H : Set G)) :
  card A < card (A * A)
```

**Why this matters**
This theorem is the seed crystal: it converts “absence of algebraic structure” into certified expansion. It is the finite-group prototype of the BGT/Hrushovski philosophy.

### Theorem 2: Dichotomy for polynomially definable subsets of `GL(2, 𝔽_q)`
Now specialize to matrix groups and inject definability.

**Mathematical statement**

Let `F = 𝔽_q` be a finite field and let `A ⊆ GL(2,F)` be polynomially definable, symmetric, and contain the identity. Then either:

1. `A` is contained in a left coset of a proper polynomially definable subgroup-like set, or
2. `|A^2| > |A|`.

A more ambitious version replaces `A^2` by strict growth along all initial powers up to stabilization:
if `A` is not subgroup-controlled, then for every `k` below the stabilization index,
`|A^(k+1)| > |A^k|`.

**Lean-style signature sketch**
```lean
theorem polydef_gl2_growth_or_control
  (F : Type*) [Field F] [Fintype F]
  (A : PolyDefinableSubset F 2)
  (hsym : SymmetricSet A.carrier)
  (h1 : (1 : Matrix (Fin 2) (Fin 2) F) ∈ A.carrier)
  (hfin : Finite A.carrier) :
  (∃ H : Subgroup (GL (Fin 2) F), H ≠ ⊤ ∧ DefinablyControlledBy A.carrier (H : Set _))
  ∨
  Fintype.card ↥(prodSet A.carrier A.carrier) > Fintype.card ↥A.carrier
```

If `GL (Fin 2) F` is awkward in your local setup, formulate over invertible `2×2` matrices as a subtype.

**Why this is a breakthrough**
This is the first genuine bridge between **definability** and **growth** in a formal proof assistant context. It reframes product expansion not as brute-force counting, but as a structural theorem about algebraic descriptions of sets.

## Proof Strategy Architecture

You must present and pursue at least 2–3 proof strategies. Do not give only one route.

### Strategy A: Pure finite-combinatorial route via translation-injection
**Most promising for the core theorem.**

1. For any `a ∈ A`, left multiplication gives an injection `A → A*A`.
2. If `|A*A| ≤ |A|`, that injection is bijective, so `a*A = A` for every `a ∈ A`.
3. Deduce closure under multiplication and inverse using `1 ∈ A` and symmetry; conclude `A` is a subgroup.

This route is ideal for Theorem 1 because it is elementary, exact, and Lean-friendly. It uses cardinality comparison, `Finite`, `Fintype.card`, and subgroup extensionality.

### Strategy B: Definability via polynomial parameter spaces
**Most promising for the `GL(2, 𝔽_q)` theorem.**

1. Define polynomially definable subsets as images of finite affine spaces under polynomial matrix maps.
2. Show closure properties: product of polynomially definable sets is polynomially definable; inversion on `GL(2,F)` is rational/polynomial after determinant inversion witness on finite fields.
3. Transfer the abstract growth-or-control theorem to this definable class by proving that failure of growth yields a subgroup-valued image or subgroup-controlled image.

This route makes definability operational rather than metaphysical.

### Strategy C: Orbit/action route using matrix group generation certificates
**Best for connecting to the catalog and strengthening significance.**

1. Use results in `Catalog/Algebra/MatrixGroupGeneration.lean` to certify when a subset generates an irreducible or large subgroup.
2. Show that if a polynomially definable `A` is not trapped in a proper definable subgroup/coset, the generated subgroup is large enough to force nontrivial product expansion.
3. Convert generation certificates into explicit exclusions of subgroup-control.

This is the path that turns your theorem from a self-contained combinatorial fact into a reusable tool for finite linear groups.

## Deeper Mathematical Insight to Capture

The real theorem you are after is not “sets grow unless they do not.” It is:

> **Definability compresses combinatorics into algebraic structure.**

In arbitrary finite groups, bounded doubling only implies approximate subgroup behavior. But in algebraic families over finite fields, bounded doubling should often force containment in a low-complexity algebraic object. Even your `GL(2, 𝔽_q)` result is a prototype of the following future principle:

- **Low product growth + definability ⇒ algebraic control**
- **No algebraic control ⇒ strict product growth**
- **Strict product growth ⇒ dynamical spreading under convolution/random walk**

This is a triangle between **model theory**, **group growth**, and **probabilistic expansion**.

You must state at least one falsifiable conjecture with a clear computational test.

### Conjecture A: Uniform bounded-complexity control in `GL(2, 𝔽_q)`
For every fixed polynomial complexity bound `C`, there exists `K = K(C)` such that for every finite field `𝔽_q` and every symmetric polynomially definable subset `A ⊆ GL(2, 𝔽_q)` of complexity at most `C` with `1 ∈ A`, if

**Computational test:** enumerate low-complexity polynomial images in small fields `𝔽_q` (`q = 3,5,7,9`) and compute doubling constants and coset-cover numbers. A single family with uniformly small doubling but no bounded coset control would refute the conjecture.

If `A ⊆ GL(2, 𝔽_q)` is symmetric, polynomially definable, contains `1`, and is not controlled by a proper definable subgroup, then
`|A^k| < |A^(k+1)|` for every `k` with `A^k ≠ ⟨A⟩`.

**Computational test:** for small fields, compute all power sets of sample definable families until stabilization; search for plateaus before subgroup closure.
