This should not be an incremental closure-capacity variant. The breakthrough is to show that **finite closure dependency geometry**, when enriched by an idempotent semimodule of derivation certificates, supports a duality between:

1. **closed dependency structure** on a finite feature universe, and  
2. **canonical sparse predictor semimodule data** extracted from minimal derivations.

The conceptual target is a new mathematical object: an **exchange-closure dependency system**. It should sit strictly between arbitrary finite closure systems and matroids/antimatroids, with enough exchange control to make sparse predictor extraction canonical.

This would open a new lane connecting:
- closure operators / implicational systems,

It also avoids the already-failed exact closure–matroid/secret-sharing route by aiming at a weaker and more ML-native notion of reconstructible dependency.

## Core theorem package to formalize and prove

Work over:
- a finite type `α` of features,
- a closure operator `cl : Set α → Set α`,
- an idempotent semiring `S`,
- a weight/certificate semantics on implications `(A,b)`.

You should define a finite dependency profile from closure data and then prove a realization/minimality duality.

### Precise mathematical target

Let `X` be finite and let `cl : 𝒫(X) → 𝒫(X)` be a closure operator. For each implication `(A,b)` with `A ⊆ X`, `b ∈ X`, assign a weight in an idempotent semiring `S`. Construct a semimodule of dependency certificates `M(cl)` generated by formal implication certificates `e_(A,b)` modulo closure-consistency relations identifying certificates that derive the same closed consequence with no greater cost. Define the **prediction cost**
\[
\mathrm{pcost}_{cl}(A,b)
\]
to be the infimum/idempotent sum of weights of certificates deriving `b` from `A`.

Define an **exchange-closure dependency system** by requiring that whenever
\[
b \in cl(A \cup \{c\}) \setminus cl(A),
\]
there exists some
\[
c' \in cl(A \cup \{b\}) \setminus cl(A)
\]
such that derivability of `c'` from `A ∪ {b}` is bounded in cost by a uniform function of the derivation cost of `b` from `A ∪ {c}`. This is a cost-controlled weak exchange axiom, not full matroid exchange.

Then prove:

### Theorem A: Canonical sparse basis existence
For every finite exchange-closure dependency system of bounded generator rank, there exists a canonical finite set of irredundant predictor supports whose induced minimal certificate semimodule generates all finite derivations, and these supports are exactly the join-irreducible/extreme closed dependencies.

### Theorem B: Minimality/extremality correspondence
In such systems, irredundant predictor supports correspond bijectively to extreme generators of the minimal dependency semimodule. Equivalently, a support is indispensable in every sparse predictor basis iff its associated closed dependency is join-irreducible among nontrivial closed dependencies.

### Theorem C: Reconstruction duality
Two finite exchange-closure dependency systems are equivalent as closure dependency models iff their certified sparse predictor semimodules are isomorphic in a way preserving minimal support cost. Thus the canonical sparse predictor object determines the closure dependency structure, and conversely.

This should be formulated first at the level of finite closure systems and finite-support semimodule certificates, not in full generality.

## Proof architecture: 3 viable strategies

### Strategy 1: Finite lattice of closed sets + join-irreducibles
This is likely the most Lean-robust first route.

1. **Build the finite lattice**
   - Show the closed subsets of `cl` form a finite lattice under inclusion.
   - Define nontrivial closed dependencies as proper closed sets generated by finite supports.

2. **Extract canonical generators**
   - Use finite lattice theory: every element is a join of join-irreducibles.
   - Prove that under the exchange-closure axiom, each join-irreducible closed set admits an irredundant support whose prediction profile is minimal.

3. **Prove uniqueness/minimality**
   - Show irredundant supports correspond exactly to join-irreducibles.
   - Deduce canonical basis existence and reconstruction from equality/isomorphism of these generating profiles.

**Why promising:** finite lattice arguments are already close to Mathlib’s strengths, and join-irreducibility is a crisp formal target. This route minimizes bespoke semimodule formalization in the first pass.

---

### Strategy 2: Idempotent semimodule extremality + normal forms
This is conceptually deepest and may produce the strongest theorem.

1. **Define a semimodule of minimal certificates**
   - Present certificates as finite weighted derivation objects.
   - Quotient by cost-preserving equivalence / closure-consistency.

2. **Develop a normal form theorem**
   - Show every certificate admits a minimal support normal form.
   - Use the weak exchange axiom to prove elimination of redundant support elements.

3. **Characterize extreme generators**
   - Define extremality in the idempotent semimodule.
   - Prove extreme generators are exactly irredundant supports / join-irreducible dependencies.
   - Conclude semimodule isomorphism determines the closure model.

**Why promising:** this is the theorem that would most strongly connect tropical/idempotent algebra to interpretable learning. It is more ambitious but also more paradigm-shifting.

---

### Strategy 3: Galois-style reconstruction from cost profiles
This is the cleanest route to the duality theorem if semimodule formalization gets heavy.

1. **Define the cost profile functor**
   - Send `D` to the function `(A,b) ↦ predCost D A b`.
   - Show closure can be recovered from zero/finite/minimal-cost derivability thresholds.

2. **Recover closed sets**
   - Prove `cl(A)` is determined by the set of `b` with minimal derivation cost from `A`.
   - Then show all closed dependencies are reconstructible from the cost profile.

3. **Recover canonical sparse basis**
   - Define irredundant supports as supports minimal for their recovered closed dependency.
   - Show these are invariant under cost-profile equivalence.

**Why promising:** this route gives a reconstruction theorem earlier, even before a full semimodule API is built. It may be the best first milestone.

## Key definitions to get right

You need a mathematically sharp and Lean-tractable notion of weak exchange. One good version:

For finite `A`, if `b ∈ cl(A ∪ {c}) \ cl(A)`, then there exists `c' ∈ cl(A ∪ {b}) \ cl(A)` such that
\[
\mathrm{pcost}(A \cup \{b\}, c') \le K \otimes \mathrm{pcost}(A \cup \{c\}, b)
\]
for some global bound `K` depending only on `D`.

A weaker order-only version may be easier first:
- replace cost inequality by mere existence of `c'`,
- prove structural theorems,
- then enrich with weights as a refinement theorem.

Similarly, define irredundancy as:
- `A` predicts its closed dependency,
- no proper subset `A' ⊂ A` has the same closure or same minimal prediction profile.

This lets you prove a strong correspondence with join-irreducibility of `cl(A)`.

/-! ## §1. Exchange Closure Systems -/

/-- A finite exchange closure system: a closure operator satisfying
extensivity, monotonicity, idempotence, and Steinitz–Mac Lane exchange. -/
structure ExchangeClosureSystem (X : Type u) [Fintype X] where
  cl : Set X → Set X
  extensive : ∀ A, A ⊆ cl A
  mono : ∀ ⦃A B : Set X⦄, A ⊆ B → cl A ⊆ cl B
  idempotent : ∀ A, cl (cl A) = cl A
  exchange : ∀ ⦃A : Set X⦄ ⦃x y : X⦄,
    y ∈ cl (A ∪ {x}) → y ∉ cl A → x ∈ cl (A ∪ {y})

    C.IsClosed (C.cl A) := C.idempotent A

  mono {A B} hAB := M.closure_subset_closure hAB

/-- A finitely generated dependency presentation on a finite type X.
Each dependency has a support set and a designated target element.
The target is determined by the rest of the support. -/
structure DepPresentation (X : Type u) [Fintype X] [DecidableEq X] where
  Dep : Type u
  [instFinDep : Fintype Dep]
  support : Dep → Finset X
  tgt : Dep → X
  tgt_mem : ∀ d, tgt d ∈ support d
  support_nonempty : ∀ d, (support d).Nonempty

attribute [instance] DepPresentation.instFinDep

variable {X : Type u} [Fintype X] [DecidableEq X]

namespace DepPresentation

/-- Induced closure: x ∈ cl(A) iff x ∈ A or there is a dependency targeting x
with all other support elements in A (i.e., support \ {x} ⊆ A). -/
def cl (S : DepPresentation X) (A : Set X) : Set X :=
  {x | x ∈ A ∨ ∃ d, S.tgt d = x ∧ ∀ y ∈ S.support d, y ≠ x → y ∈ A}

/-- Qualified: target t is in cl(Q) -/
def Qualified (S : DepPresentation X) (t : X) (Q : Finset X) : Prop :=
  t ∈ S.cl (↑Q)

/-- Minimally qualified -/
def MinQualified (S : DepPresentation X) (t : X) (Q : Finset X) : Prop :=
  S.Qualified t Q ∧ ∀ Q' : Finset X, Q' ⊂ Q → ¬S.Qualified t Q'

/-- Extractor witness -/
def ExtractorWit (S : DepPresentation X) (A : Finset X) (x : X) : Prop :=
  x ∈ S.cl (↑A)

end DepPresentation

/-! ## §4. Rank Structure -/

/-- Matroid-style rank axioms. -/
structure MatroidRankFn (X : Type u) [Fintype X] [DecidableEq X] where
  r : Finset X → ℕ
  rank_bounded : ∀ A, r A ≤ A.card
  rank_mono : ∀ ⦃A B⦄, A ⊆ B → r A ≤ r B
  rank_submod : ∀ A B, r (A ∪ B) + r (A ∩ B) ≤ r A + r B
  rank_unit : ∀ A x, r A ≤ r (insert x A) ∧ r (insert x A) ≤ r A + 1

namespace MatroidRankFn

def RankIndep (R : MatroidRankFn X) (A : Finset X) : Prop := R.r A = A.card

def RankBasis (R : MatroidRankFn X) (I B : Finset X) : Prop :=
  I ⊆ B ∧ R.RankIndep I ∧ R.r I = R.r B

def RankCircuit (R : MatroidRankFn X) (C : Finset X) : Prop :=
  R.r C < C.card ∧ ∀ D : Finset X, D ⊂ C → R.r D = D.card

end MatroidRankFn
