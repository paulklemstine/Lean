**Domain**: Bridges
**Mathematical framing**: Work with a finite type of states α and a closure operator `cl : Set α → Set α` already packaged through `SetClosureOperator` / `FiniteClosureSystem`. Choose a finite probe family `P` from the Bridges closure files and define for each state `a : α` an evaluation vector `ev a : P → ℤ` (or another canonically available ordered idempotent semiring) by recording probe responses. For a subset `S`, define its tropical envelope as the pointwise max-plus hull of `{ev s | s ∈ S}`. The main conjectural theorem is a representation equivalence: `a ∈ cl S ↔ ev a` lies in the tropical halfspace intersection determined by all closure-stable probes that are valid on `S`. A stronger finite-separation theorem should assert that if `a ∉ cl S`, then there exists a tropical halfspace `H` from a bounded generating family with `ev[S] ⊆ H` but `ev a ∉ H`; ideally one proves a Helly-number bound in the finite setting. Falsifiable milestones include (1) proving the envelope is closure-monotone, extensive, and idempotent on evaluation images, (2) proving every closed set equals the preimage of a tropical convex set under `ev`, and (3) extracting explicit finite certificates of non-membership. /-! ## Part 1: Tropical Convexity Foundations -/

/-- **Tropical convexity in the max-plus semiring.**
    A set S ⊆ ℝⁿ is tropically convex if for all x, y ∈ S and
    all coefficients s, t with max(s, t) = 0, the tropical combination
    i ↦ max(s + xᵢ, t + yᵢ) lies in S.

    The condition max(s, t) = 0 normalizes the tropical coefficients,
    analogous to requiring s + t = 1 in classical convex combinations. -/
def IsTropConvex {n : ℕ} (S : Set (Fin n → ℝ)) : Prop :=
  ∀ ⦃x y : Fin n → ℝ⦄, x ∈ S → y ∈ S →
    ∀ s t : ℝ, max s t = 0 → (fun i => max (s + x i) (t + y i)) ∈ S

def tropConvexHull {n : ℕ} (T : Set (Fin n → ℝ)) : Set (Fin n → ℝ) :=
  ⋂₀ {S : Set (Fin n → ℝ) | IsTropConvex S ∧ T ⊆ S}
