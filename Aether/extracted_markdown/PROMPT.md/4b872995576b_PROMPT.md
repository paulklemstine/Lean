## Main Theorem A: Finite Reconstruction / Representation

The first theorem should be a rigorous finite representation theorem from weighted closure data to canonical idempotent channels.

### Mathematical statement

Let `C` be a finite weighted closure system on `α`. Construct a canonical finite observation type `β(C)` from extremal closed-set observables of `C`, and define a channel
`K_C : α → β(C) → Cost`
by evaluation of generator-to-observable cost.

Prove:

1. `K_C` is determined canonically by the weighted closure semimodule.
2. If two weighted closure systems are isomorphic, then their canonical channels are Blackwell-equivalent.
3. Conversely, if their canonical channels are Blackwell-equivalent and both are minimal/extremal, then the weighted closure systems are isomorphic.
4. Every finite weighted closure system admits a minimal realization obtained by quotienting redundant observables and retaining extremal generators.

This is the theorem that makes the bridge real: **closure semantics are completely reconstructible from a Blackwell class of tropical channels**.

### Lean-oriented theorem signature

A realistic first formal target:

```lean
theorem weightedClosure_iso_iff_blackwell_equiv_minimal
    {α β : Type _} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (C : WeightedClosureSystem α) (D : WeightedClosureSystem β)
    (hCmin : C.IsMinimalRealization) (hDmin : D.IsMinimalRealization) :
    Nonempty (C ≃w D) ↔
      BlackwellEquiv (canonicalChannel C) (canonicalChannel D)
```

where `≃w` is a weighted closure-system isomorphism you define.

A decomposition theorem that may be easier to prove first:

```lean

    {α : Type _} [Fintype α] [DecidableEq α]
```

and then the fullness/uniqueness statement:

```lean
    IsCanonicalRealization C K →
    IsCanonicalRealization C L →
    IsMinimalChannelRealization C K →
    IsMinimalChannelRealization C L →
```

This pair is likely the most Lean-feasible route to the advertised duality.

## Main Theorem B: Blackwell Monotonicity = Thermodynamic Free-Energy Monotonicity

Now prove that garbling is exactly thermodynamic dissipation in the closure-semimodule model.

### Mathematical statement

Define a free-energy functional `F_C` on channels/observables induced by the closure weight `w`, for example as a tropical partition profile, minimum expected work proxy, or extremal observable envelope. Then show:

- If `L` is a garbling of `K`, then `F_C K ≤ F_C L`.
- If `K` and `L` are Blackwell-equivalent minimal realizations, then `F_C K = F_C L`.
- The resulting free-energy profile is a certified invariant of Blackwell equivalence.
- For canonical minimal realizations, equality of free-energy profiles implies equivalence of channels.

This is the key conceptual breakthrough: **the Blackwell preorder becomes a thermodynamic second-law preorder**.

### Lean-oriented theorem signature

```lean
theorem freeEnergy_monotone_of_blackwellLE
    {α β γ : Type _}
    [Fintype α] [DecidableEq α]
    [Fintype β] [DecidableEq β]
    [Fintype γ] [DecidableEq γ]
    (C : WeightedClosureSystem α)
    (K : IdemChannel α β) (L : IdemChannel α γ) :
    BlackwellLE K L →
    freeEnergy C K ≤ freeEnergy C L
```

and the certified invariant statement:

```lean
theorem blackwellEquiv_iff_same_freeEnergyProfile_of_minimal
    {α β γ : Type _}
    [Fintype α] [DecidableEq α]
    [Fintype β] [DecidableEq β]
    [Fintype γ] [DecidableEq γ]
    (C : WeightedClosureSystem α)
    (K : IdemChannel α β) (L : IdemChannel α γ) :
    IsMinimalChannelRealization C K →
    IsMinimalChannelRealization C L →
```

If the biconditional is too ambitious in one pass, prove first:

## Main Theorem C: Certified Reconstruction Algorithm

Formalize a finite algorithm extracting a minimal channel from closure-semimodule data and certify correctness.

### Mathematical statement

For finite `C`, there is a polynomially-bounded reconstruction procedure that:
1. computes extremal observables,
2. builds the canonical channel matrix,
3. removes redundant columns via tropical factorization,
4. outputs a minimal channel Blackwell-equivalent to any realization of `C`.

At Lean level, you likely cannot prove asymptotic polynomial time cleanly without a dedicated complexity framework, but you can absolutely formalize:

- minimality,

## Proof Architecture: 3 Strategies

You must pursue at least two in parallel and choose one as the backbone.

### Strategy A: Extremal-generator reconstruction via tropical convexity
This is likely the most promising.

1. Define the observable semimodule of closed-set cost profiles.
2. Show every observable is a tropical combination of extremal ones.
3. Use extremal observables as canonical channel outputs.
4. Prove garblings correspond exactly to tropical postcomposition maps.
5. Show minimality by irredundancy of extremals.
6. Prove uniqueness up to Blackwell equivalence from equality of generated semimodules.

**Why promising:** finite tropical convexity and extremal generation are combinatorial, constructive, and Lean-friendly. This route avoids heavy categorical machinery.

### Strategy B: Galois/closure duality route
1. Build a correspondence between closed sets and decision regions/observable fibers.
2. Show the closure operator induces a Galois connection between generators and channel observables.
3. Identify Blackwell morphisms with maps preserving the induced closure preorder.
4. Derive reconstruction from the lattice of closed observables.

**Why promising:** if your closure systems already align with catalog EML results, this may reuse existing closure-algebra lemmas and order-theoretic machinery.

**Risk:** proving full uniqueness may become abstract and harder to compute.

### Strategy C: Thermodynamic monotone first, reconstruction second
1. Define free-energy profile directly from weighted closure data.
2. Show channel garbling is exactly monotonicity of this profile.
3. Define minimal channels as profile-extremal realizations.
4. Reconstruct channels from the set of profile extremals.

**Why promising:** best for the conceptual bridge to physics.

**Risk:** if the free-energy profile is defined too implicitly, the reconstruction theorem may become difficult.

**Recommendation:** Use **Strategy A** for the main existence/uniqueness theorem, and then layer **Strategy C** on top to prove the thermodynamic interpretation. Strategy B can supply order-theoretic lemmas when needed.
