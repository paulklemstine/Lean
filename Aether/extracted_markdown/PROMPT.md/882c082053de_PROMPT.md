## Assignment: 4. Khovanov Homology as a Categorification

**Mode:** prove

Build the first serious Lean 4 bridge from polynomial knot invariants to categorified topology. Do not stop at definitions. The target is a machine-checked theorem saying that a chain-level construction recovers the Jones polynomial by graded Euler characteristic, and that the resulting homology is invariant under Reidemeister moves. This is not merely “formalizing Khovanov homology”; it is the moment where Mathlib-level algebra, combinatorics on cube-of-resolutions, and low-dimensional topology fuse into a certified categorification engine.

The decisive breakthrough is to isolate a Lean-friendly finite, combinatorial core:
1. the cube of smoothings of a link diagram,
2. a Frobenius algebra package generating the merge/split maps,
3. a bigraded chain complex,
4. an Euler characteristic theorem recovering the bracket/Jones polynomial,
5. local chain homotopy equivalences for Reidemeister moves.

If you can get even the Euler characteristic theorem plus one nontrivial Reidemeister invariance theorem into Lean cleanly, you will have opened an entirely new formal frontier: certified categorification in topology.

## Precise theorem targets

You should formulate the theory over a commutative semiring or ring `R`, but for the first full theorem it is completely reasonable to specialize to `R := ℤ` or `R := ℚ`. The key is to make the cube finite and computable.

### Core objects to define

Let `D` be a finite planar link diagram with:
- a finite type of crossings `D.Crossing`,
- for each smoothing state `s : D.Crossing → Bool`, a finite number `loops D s : ℕ` of resulting circles,
- a crossing count decomposition `n₀(s), n₁(s)` or simply `zeroCount`, `oneCount`.

Define the standard rank-2 Frobenius algebra
\[
A = R[X]/(X^2)
\]
or equivalently the free `R`-module on basis `{1, x}` with multiplication/comultiplication
\[
m(1\otimes 1)=1,\quad m(1\otimes x)=m(x\otimes 1)=x,\quad m(x\otimes x)=0,
\]
\[
\Delta(1)=1\otimes x + x\otimes 1,\quad \Delta(x)=x\otimes x.
\]

For each state `s`, assign
\[
C(D,s) := A^{\otimes \, \mathrm{loops}(D,s)}
\]
with homological degree given by the number of `1`-smoothings and quantum grading shifted by the usual Khovanov convention.

Then define
\[
C^i(D)=\bigoplus_{\substack{s\\ |s|=i}} C(D,s),
\]
with differential given by signed sums over edges in the cube of resolutions.

### 1. Differential squares to zero
```lean
theorem khovanov_d_squared
  {R : Type*} [CommRing R]
  (D : LinkDiagram) :
  let C := khovanovChainComplex R D
  ∀ i, (C.d (i+1) i) ∘ₗ (C.d (i+2) (i+1)) = 0
```

If you package as `HomologicalComplex`, the statement may become:
```lean
theorem khovanov_d_comp_d
  {R : Type*} [CommRing R]
  (D : LinkDiagram) :
  (khovanovChainComplex R D).d_comp_d = by
  ...
```

This is the first nontrivial categorification theorem: the cube differential really is a chain differential.

### 2. Graded Euler characteristic recovers the Jones/Kauffman bracket
A precise decategorification statement:
```lean
theorem gradedEulerCharacteristic_khovanov
  (D : LinkDiagram) :
  gradedEulerCharacteristic (khovanovChainComplex ℤ D)
    = jonesPolynomial D
```

If Jones polynomial is not yet defined, first prove the bracket version:
```lean
theorem gradedEulerCharacteristic_kauffmanBracket
  (D : LinkDiagram) :
  gradedEulerCharacteristic (unnormalizedKhovanovComplex ℤ D)
    = kauffmanBracket D
```

This is the exact theorem that turns “chain complex attached to a knot diagram” into “categorification of a classical invariant.”

### 3. Reidemeister invariance up to chain homotopy equivalence
For each local move:
```lean
theorem khovanov_reidemeister_I
  {R : Type*} [CommRing R]
  (D₁ D₂ : LinkDiagram)
  (h : ReidemeisterI D₁ D₂) :
  ChainHomotopyEquiv
    (khovanovChainComplex R D₁)
    (gradingShiftRI (khovanovChainComplex R D₂))
```

Similarly for II and III:
```lean
theorem khovanov_reidemeister_II ...
theorem khovanov_reidemeister_III ...
```

Then derive the diagram-independent invariant:
```lean
theorem khovanov_homology_link_invariant
  {R : Type*} [CommRing R]
  {D₁ D₂ : LinkDiagram}
  (h : DiagramEquivalent D₁ D₂) :
  Nonempty (BigradedEquiv
    (khovanovHomology R D₁)
    (khovanovHomology R D₂))
```

### 4. Explicit computations for benchmark knots
```lean
theorem khovanov_trefoil_computation :
  khovanovPoincarePolynomial ℤ trefoilDiagram
    = trefoilExpectedPolynomial
```

```lean

  khovanovPoincarePolynomial ℤ figureEightDiagram
    = figureEightExpectedPolynomial
```

These are not ornamental examples. They are calibration tests for the whole theory.

## Why this would be a breakthrough

Formal topology has many invariants, but very few genuinely categorical ones built from chain complexes whose homology survives local diagram moves. Khovanov homology is the canonical test case for whether theorem provers can certify a categorification pipeline rather than merely verify static algebraic identities.

If you succeed, you open:

- **Certified knot recognition infrastructure:** chain-level invariants with verified computation.
- **Formal categorification:** a reusable pattern for lifting polynomial invariants to homological theories.
- **Topological quantum computation links:** Khovanov-type state sums interface naturally with TQFT and anyonic models.
- **Algorithmic low-dimensional topology:** exact, trustworthy unknot obstruction computations.
- **Future bridges to Floer/gauge theory:** the Kronheimer–Mrowka unknot detection theorem becomes a conceivable long-range formal target.

This is the first step from “formalized knot polynomials” to “formalized homological topology.”

## Proof architecture: 3 viable strategies

### Strategy A: Cube-of-resolutions + Frobenius algebra identities
This is the most canonical and likely the best first route.

**Step 1.** Define the cube category of smoothing states.
- States are functions `D.Crossing → Bool`.
- Edges correspond to changing exactly one crossing.
- Build the chain groups by summing over states of fixed Hamming weight.

**Step 2.** Define edge maps using local merge/split cobordism algebra.
- If changing a smoothing merges two circles, use multiplication `m`.
- If it splits one circle into two, use comultiplication `Δ`.
- Introduce the standard cube sign convention using the ordering of crossings.

**Step 3.** Prove anti-commutativity of every square face in the cube.
- Reduce `d² = 0` to checking each 2-face.
- Each face corresponds to one of finitely many local topological configurations.
- The proof becomes a finite verification of Frobenius identities:
  associativity, coassociativity, and Frobenius compatibility.

**Why this is promising:** It matches the classical proof exactly, keeps everything finite/combinatorial, and Lean handles finite case splits well once the local algebra is encoded properly.

---

### Strategy B: Abstract rank-2 commutative Frobenius algebra formalization
This is more ambitious and more reusable.

**Step 1.** Define a Lean structure:
```lean
structure CommutativeFrobeniusAlgebra (R A : Type*) ...
```
including multiplication, unit, comultiplication, counit, and Frobenius compatibility.

**Step 2.** Construct a generic “cube TQFT complex” from any diagram and any Frobenius algebra.
- The Khovanov complex becomes one instance of a more general machine.
- `d² = 0` follows abstractly from Frobenius axioms and cube sign conventions.

**Step 3.** Specialize to `A = R[X]/(X²)` and derive Khovanov homology.
- Then the Euler characteristic theorem becomes an abstract decategorification result plus a specialization computation.

**Why this is revolutionary:** It does not merely formalize Khovanov homology; it formalizes the *mechanism of categorification by 2D TQFT*. This would support Lee homology, Bar-Natan deformation, and possibly odd Khovanov variants later.

**Risk:** More setup. If you want one flagship theorem quickly, begin with Strategy A and refactor toward B afterward.

---

### Strategy C: Skein-theoretic decategorification first, then chain lift
This is the best route if Jones/Kauffman bracket infrastructure is already partially available.

**Step 1.** Prove a state-sum formula for the Kauffman bracket in Lean:
\[
\langle D\rangle = \sum_s A^{\alpha(s)-\beta(s)}(-A^2-A^{-2})^{\mathrm{loops}(D,s)-1}.
\]

**Step 2.** Define the chain groups so that their graded dimensions realize exactly the state-sum weights.
- This gives the Euler characteristic theorem almost by construction.

**Step 3.** Add the differential later and prove that homology preserves the same Euler characteristic.
- Then Reidemeister invariance can be split into chain-level local equivalences.

**Why this is useful:** It gives an early decisive win: categorification at the level of graded Euler characteristic. Even before full homological invariance, you will have a genuine theorem.

**Best use:** If local move chain homotopies become too heavy initially, land the Euler characteristic theorem first.

## Cross-domain connections to exploit aggressively

### 1. Topological quantum field theory
Khovanov’s construction is a discrete 2D TQFT attached to a Frobenius algebra. Formalizing it creates a certified TQFT fragment in Lean. This is the real conceptual payload.

### 2. Homological algebra
Once the chain complex is in place, Mathlib’s homological machinery becomes available: homology, chain maps, homotopies, mapping cones. Reidemeister invariance should be expressed in this language, not ad hoc.

### 3. Statistical mechanics
The Kauffman bracket is a state sum, structurally akin to a partition function. Khovanov homology is then a categorified partition function. This analogy may guide finite state indexing, weight normalization, and decategorification proofs.

### 4. Quantum computation and anyon models
Jones-type invariants sit near braid group representations and topological quantum computing. A formal Khovanov engine would support verified calculations of categorified braid closures.

### 5. Certified algorithms
This work would enable trustworthy knot invariant computation kernels. Long term, this points toward verified unknot detection heuristics and certified obstruction tools.

## Technical design choices that will matter

- Represent states as `Crossing → Bool` if `Crossing` is finite.
- Use an explicit linear order on crossings to define cube signs.
- Keep the Frobenius algebra concrete at first: basis `{vPlus, vMinus}` or `{1, x}`.
- Encode gradings as integer shifts on modules early; do not postpone all grading data.
- Separate:
  1. ungraded chain complex,
  2. bigraded object,
  3. decategorification theorem.
- Build small local lemmas for merge/split maps before assembling the global differential.

A common failure mode is to define everything globally and only later discover the local algebra is awkward to rewrite. Invert that: prove the local algebra identities first.
