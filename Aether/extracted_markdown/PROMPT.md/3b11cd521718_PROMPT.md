## Assignment: Direction 1: Kruskal–Katona Optimal Shadow Bounds for Circuit Supports

**Mode:** `prove`

Prove genuinely new theorems at the interface of **extremal combinatorics, algebraic complexity, discrete convex geometry, and symbolic differentiation**. The target is not a routine extension of classical Kruskal–Katona, but a new mechanism for **algebraic circuit lower bounds via support-shadow expansion**.

The central vision is this: the support of a polynomial computed by a small algebraic circuit is not an arbitrary finite subset of `ℕ^n`; it is generated by repeated **union** and **Minkowski addition**. Those operations should force hidden combinatorial regularity. If one can show that small circuits cannot realize support families with “too extremal” shadow behavior—or conversely that explicit hard polynomials have systematically inflated shadows relative to Kruskal–Katona minimizers—then we obtain a new lower-bound invariant that is neither rank-based nor partial-derivative-based in the usual sense, but **extremal-set-theoretic**.

This would open a field: **extremal support complexity**.

## Core mathematical program

Let `α = Fin n → ℕ` denote exponent vectors (multi-indices). For a finite family `S : Finset α`, define its one-step shadow
\[
\mathrm{Sh}_1(S) := \{\beta : \exists i,\ \beta(i)+1 \in S(i)\ \text{and}\ \forall j\neq i,\ \beta(j)=S(j)\},
\]
i.e. the set of exponent vectors obtained by decrementing one positive coordinate by one. This is the support-level analogue of taking all first partial derivatives.

Your conjectural direction should be sharpened into formal theorems that isolate what can already be proved in Lean and what remains conjectural.

### Theorem 1: Shadow–derivative equivalence for monomial supports
This upgrades the catalog derivative-shadow correspondence into a direct support identity for first derivatives.

**Mathematical statement.**  
For a polynomial `f` over a semiring of characteristic zero (or over `ℕ`/`ℤ` if simpler), an exponent vector `β` lies in the one-shadow of the support of `f` iff there exists a variable `i` such that `X_i * monomial β` occurs in the support of `f`. Equivalently, `β` lies in the support of some first partial derivative of `f`.

Suggested Lean signature:
```lean
theorem mem_oneShadow_iff_exists_partialDerivative_support
    {n : ℕ} {R : Type*} [Semiring R]
    (f : MvPolynomial (Fin n) R) (β : Fin n → ℕ) :
    β ∈ oneShadow (f.support) ↔
      ∃ i : Fin n, β ∈ (MvPolynomial.pderiv i f).support
```

If `pderiv` support lemmas are awkward over general semirings, specialize to:
```lean
{R : Type*} [CommSemiring R] [NoZeroSMulDivisors ...]
```
or even `R = ℕ`.

**Why this matters.**  
This theorem identifies shadow growth with derivative complexity, linking extremal combinatorics directly to one of the central tools of algebraic complexity.

**Catalog build.**  
Use:
- `Pythagorean/IteratedShadowGeometry.lean`: `mem_kthShadow_iff_exists_iteratedDerivative`

### Theorem 2: Shadow subadditivity under support union
This is the first circuit gate theorem: addition of polynomials corresponds to union of supports (up to cancellation), and the shadow should be subadditive.

**Mathematical statement.**  
For finite support families `A, B ⊆ ℕ^n`,
\[
|\mathrm{Sh}_1(A \cup B)| \le |\mathrm{Sh}_1(A)| + |\mathrm{Sh}_1(B)|.
\]
Hence if `supp(f+g) ⊆ supp(f) ∪ supp(g)`, then
\[
|\mathrm{Sh}_1(\mathrm{supp}(f+g))|
\le |\mathrm{Sh}_1(\mathrm{supp}(f))| + |\mathrm{Sh}_1(\mathrm{supp}(g))|.
\]

Suggested Lean signatures:
```lean
theorem card_oneShadow_union_le
    {n : ℕ} (A B : Finset (Fin n → ℕ)) :
    (oneShadow (A ∪ B)).card ≤ (oneShadow A).card + (oneShadow B).card
```

```lean
theorem support_add_shadow_bound
    {n : ℕ} {R : Type*} [Semiring R]
    (f g : MvPolynomial (Fin n) R) :
    (oneShadow ((f + g).support)).card
      ≤ (oneShadow f.support).card + (oneShadow g.support).card
```

**Why this matters.**  
This gives the additive half of a structural induction on circuits. It says the shadow invariant behaves like a complexity measure under `+`-gates.

**Proof texture.**  
This should not be trivialized by cardinality automation; prove set inclusion
\[
\mathrm{Sh}_1(A\cup B)\subseteq \mathrm{Sh}_1(A)\cup \mathrm{Sh}_1(B)
\]
then conclude via `Finset.card_le_card` after constructing the embedding/inclusion.

### Theorem 3: Shadow of Minkowski product contains shifted factors
This is the multiplicative gate theorem. It is weaker than the full conjecture, but powerful and provable.

**Mathematical statement.**  
Suppose `0 ∈ B`. Then for every `α ∈ oneShadow(A)`, we have `α + 0 ∈ oneShadow(A ⊞ B)` where `⊞` is pointwise exponent addition. More generally, if `b ∈ B`, then for every `α ∈ oneShadow(A)` and every coordinate decrement in a witness for `α`, one gets `α + b ∈ oneShadow(A ⊞ B)`.

In particular,
\[
0 \in B \implies |\mathrm{Sh}_1(A)| \le |\mathrm{Sh}_1(A ⊞ B)|.
\]

Suggested Lean signatures:
```lean
def supportMul {n : ℕ} (A B : Finset (Fin n → ℕ)) : Finset (Fin n → ℕ) := ...
```

```lean
theorem add_mem_oneShadow_supportMul
    {n : ℕ} (A B : Finset (Fin n → ℕ))
    (h0 : (0 : Fin n → ℕ) ∈ B) :
    ∀ ⦃α⦄, α ∈ oneShadow A → α ∈ oneShadow (supportMul A B)
```

```lean
theorem card_oneShadow_le_card_oneShadow_supportMul
    {n : ℕ} (A B : Finset (Fin n → ℕ))
    (h0 : (0 : Fin n → ℕ) ∈ B) :
    (oneShadow A).card ≤ (oneShadow (supportMul A B)).card
```

A stronger translation form is even better:
```lean
theorem map_add_mem_oneShadow_supportMul
    {n : ℕ} (A B : Finset (Fin n → ℕ)) :
    ∀ ⦃α b⦄, α ∈ oneShadow A → b ∈ B → α + b ∈ oneShadow (supportMul A B)
```
provided your `oneShadow` witness bookkeeping supports it.

**Why this matters.**  
Multiplication is the source of complexity in algebraic circuits. Any monotonicity or controlled growth theorem for shadows under support multiplication is the seed of a true lower-bound method.

**Cross-domain significance.**  
This is simultaneously:
- a statement in **algebraic complexity**,
- a theorem in **additive combinatorics** about lower shadows of Minkowski sums,
- and a geometric fact about lattice points in Newton polytopes.

### Theorem 4: Degree-slice lower bound via classical set shadows
This is the key cross-domain bridge to extremal combinatorics proper.

Restrict to **squarefree supports** of homogeneous degree `d`, identified with `d`-subsets of `Fin n`. Then the multi-index shadow agrees with the classical lower shadow, so the classical Kruskal–Katona theorem can be imported directly.

**Mathematical statement.**  
If every exponent vector in `S` is squarefree and has total degree `d`, then
\[
|\mathrm{Sh}_1(S)| \ge \mathrm{KK}(n,d,|S|),
\]
where `KK(n,d,m)` is the classical lower-shadow minimum for `m` many `d`-subsets.

Suggested Lean signature:
```lean
def SquarefreeFamily {n d : ℕ} (S : Finset (Fin n → ℕ)) : Prop := ...
```

```lean
theorem squarefree_homogeneous_shadow_ge_kk
    {n d : ℕ} (S : Finset (Fin n → ℕ))
    (hsq : SquarefreeFamily (n := n) (d := d) S) :
    kkMinShadow n d S.card ≤ (oneShadow S).card
```

If exact `kkMinShadow` is too abstract, prove a transport theorem from set families:
```lean
theorem squarefree_shadow_card_eq_set_lowerShadow_card ...
```
and then invoke an existing classical KK theorem if available, or prove a weaker binomial lower bound.

**Why this matters.**  
This theorem is the formal hinge between **multi-index polynomial support geometry** and **classical extremal set theory**. It says the circuit-support problem already contains the classical Kruskal–Katona world as a slice.

### Theorem 5: Circuit-level induction theorem for monotone circuits
If full general circuits are too ambitious due to cancellation, prove a monotone version now.

Define a simple inductive type of monotone support circuits whose semantics is a finite support family built from singleton monomials using union and supportMul.

Suggested Lean:
```lean
inductive SupportCircuit (n : ℕ)
| atom : (Fin n → ℕ) → SupportCircuit n
| add  : SupportCircuit n → SupportCircuit n → SupportCircuit n
| mul  : SupportCircuit n → SupportCircuit n → SupportCircuit n
```

Then prove a structural theorem such as:

```lean
theorem shadow_bound_of_supportCircuit

    ∀ C : SupportCircuit n,
```

**Why this matters.**  
This is the first genuine formal model of support complexity for circuits. It creates an object on which one can run induction, algorithms, and experiments.

## Most promising proof strategies

You asked for 2–3 proof strategy steps; here are the ones worth pursuing.

### Strategy A: Derivative-first route via catalog shadow theorems
**Best for Theorem 1 and for motivating all others.**

1. Use `mem_kthShadow_iff_exists_iteratedDerivative` from `Pythagorean/IteratedShadowGeometry.lean` and specialize to `k = 1`.
2. Convert the iterated-derivative witness into a first partial derivative witness, carefully handling support membership and coefficient nonvanishing.
3. Package the result as a support identity for `oneShadow`, then use it to interpret shadow cardinality as “number of monomials reachable by one differentiation.”

**Why promising:** the hard conceptual work is already in the catalog; you are extracting the exact complexity-theoretic corollary we need.

---

### Strategy B: Finset inclusion and injective transport under Minkowski addition
**Best for Theorems 2 and 3.**

1. Define `oneShadow` by an existential witness `(i, α+e_i ∈ S)`.
2. For union: prove inclusion by `rcases` on the witness and dispatch by cases on whether the lifted monomial came from `A` or `B`.
3. For multiplication: given `α ∈ oneShadow A` with witness `i` and `a+e_i ∈ A`, and given `b ∈ B`, show `(a+b)+e_i ∈ supportMul A B`; hence `α+b ∈ oneShadow (supportMul A B)`.
4. Deduce cardinality inequalities from explicit injections; avoid relying on extensional simplification alone.

**Why promising:** this route is concrete, combinatorial, and Lean-friendly. It turns the main ideas into witness manipulations on exponent vectors.

---

### Strategy C: Squarefree transport to subset families
**Best for Theorem 4 and the KK bridge.**

1. Define a map from squarefree degree-`d` exponent vectors to `Finset (Fin n)` by support-of-exponent, and its inverse by indicator vectors.
2. Prove these maps are inverse on the squarefree homogeneous slice.
3. Show `oneShadow` corresponds exactly to the classical lower shadow on `d`-uniform set families.
4. Import or rebuild the KK lower bound on the set side, then transport it back.

**Why promising:** this avoids formalizing general colex on `ℕ^n` immediately, while still capturing a mathematically rich and nontrivial regime with direct complexity applications (e.g. determinant/permanent-type squarefree supports).

## Cross-domain connections you must explicitly develop

You are required to include at least one theorem connecting to another domain. Here are the right bridges.

### 1. Algebraic complexity ↔ extremal combinatorics
The support of a polynomial becomes a finite family in `ℕ^n`; partial derivatives become lower shadows. This reframes lower bounds as a problem about extremizers of shadow minimization.

### 2. Algebraic complexity ↔ additive combinatorics
Polynomial multiplication corresponds to Minkowski addition of exponent sets. Therefore support growth and shadow growth can be studied using sumset technology, compressed-set heuristics, and Brunn–Minkowski-type lattice analogues.

### 3. Algebraic complexity ↔ convex geometry
The convex hull of the support is the Newton polytope. The one-shadow is a discrete inward normal erosion of the exponent set. Prove or state a theorem/conjecture relating shadow size to the number of lattice points on degree slices of the Newton polytope.

### 4. Algebraic complexity ↔ statistical physics / entropy
A support family defines a microcanonical ensemble on monomials. Small shadow means low one-step accessible state count under particle removal. This suggests an entropy production viewpoint: hard polynomials may exhibit anomalously large derivative-accessible phase space.

You do not need to fully formalize the physics analogy, but mention it in `FUTURE_DIRECTIONS.md` and `ARTICLE.md`.
