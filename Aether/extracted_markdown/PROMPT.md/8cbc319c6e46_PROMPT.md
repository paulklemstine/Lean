## Research Direction A: Boundary rigidity for series-parallel networks

### Vision
Prove that for a large, formalizable class of weighted series-parallel networks, the weighted boundary response completely determines the internal network up to the natural equivalence generated by series/parallel reductions. This would be a combinatorial-tropical analogue of boundary rigidity and inverse problems on manifolds, but in a class where Lean can actually certify the reconstruction.

This is not “graph theory with weights.” This is an inverse-problem theorem with implications for:
- network tomography,
- electrical reconstruction,
- tropical metric recovery,
- explainable architectures for piecewise-linear systems.

### Precise theorem target
Work with finite weighted graphs with a designated boundary set. You may need to define a response invariant first — e.g. boundary distance, effective resistance, or min-plus path metric — but the theorem should be exact.

A promising formal target is:

```lean
/-- A finite weighted network with boundary vertices. -/
structure BoundaryNetwork where
  V        : Type
  [fintypeV : Fintype V]
  [decEqV   : DecidableEq V]
  boundary : Finset V
  weight   : V → V → ℝ
  symmetric : ∀ u v, weight u v = weight v u
  nonneg    : ∀ u v, 0 ≤ weight u v

attribute [instance] BoundaryNetwork.fintypeV BoundaryNetwork.decEqV

/-- Boundary distance induced by the network (to be defined via shortest paths). -/
def boundaryDist (G : BoundaryNetwork) : G.boundary → G.boundary → ℝ := sorry

/-- Series-parallel networks modulo reduction equivalence. -/
def SP_equiv (G H : BoundaryNetwork) : Prop := sorry

/-- Boundary rigidity for series-parallel networks. -/
theorem series_parallel_boundary_rigid
  (G H : BoundaryNetwork)
  (hG : IsSeriesParallel G)
  (hH : IsSeriesParallel H)
  (hbd : Nonempty (G.boundary ≃ H.boundary))
  (hdist :
    ∃ e : G.boundary ≃ H.boundary,
      ∀ a b, boundaryDist G a b = boundaryDist H (e a) (e b)) :
  SP_equiv G H := by
  sorry
```

If exact graph isomorphism is too strong initially, prove a two-stage result:

1. **uniqueness up to SP-equivalence**,  
2. **canonical reduced form exists and is unique**, hence exact equality of reduced normal forms.

That is already a field-opening theorem in a formally verified inverse-problem setting.

### Strong intermediate theorem
A more reachable but still nontrivial theorem:

```lean
theorem series_parallel_boundaryDist_invariant
  (G H : BoundaryNetwork)
  (h : SP_equiv G H) :
  ∃ e : G.boundary ≃ H.boundary,
    ∀ a b, boundaryDist G a b = boundaryDist H (e a) (e b) := by
  sorry
```

followed by the converse reconstruction theorem.

### Proof strategies

#### Strategy A: Canonical decomposition tree
Most promising.

1. Define a syntax tree of series and parallel composition for two-terminal networks.
2. Prove that boundary response transforms functorially:
   - series composition corresponds to addition of boundary distances,
   - parallel composition corresponds to tropical/min-plus or harmonic combination, depending on the response notion chosen.
3. Construct a canonical reduced decomposition tree and prove injectivity of the response map on reduced trees.

Why this is promising: series-parallel graphs are inductively generated, so Lean induction aligns perfectly with the mathematics. This turns a hard inverse problem into a normal-form theorem.

#### Strategy B: Matroid / cut-space characterization
1. Encode SP networks by excluded minors or by decomposition of graphic matroids.
2. Show the boundary response determines enough cut/path data to recover the decomposition.
3. Deduce rigidity from equality of cut signatures.

Why useful: this may scale beyond SP networks.  
Why less promising initially: matroid formalization overhead may dominate.

#### Strategy C: Tropical Schur complement / elimination
1. Build a weighted adjacency or Laplacian-like matrix.
2. Define a tropical or classical boundary response via elimination of interior vertices.
3. Prove that for SP networks, elimination order is confluent and yields a complete invariant.

Why exciting: directly connects to the tropical linear algebra library below.  
Why medium risk: elimination theory in Lean will require matrix infrastructure first.

- **Tropical geometry**: shortest-path boundary metrics are tropical objects.
- **Electrical networks**: if effective resistance is used, compare classical and tropical responses.
- **Program semantics / explainability**: SP decomposition resembles compositional certification for piecewise-linear systems.

## Research Direction B: Formalize Gromov hyperbolicity in the tropical framework

### Vision
The big idea is to show that tropical path metrics on suitable combinatorial objects exhibit hyperbolicity, and that this hyperbolicity can be certified by finite inequalities. This would create a verified bridge between tropical geometry and coarse geometry.

Do not settle for merely defining δ-hyperbolicity. Prove a theorem that identifies a broad tropical class where hyperbolicity is automatic or sharply controlled.

### Precise theorem target
A natural first theorem is that tree metrics are 0-hyperbolic, then lift this to tropical metrics arising from min-plus path geometry on series-parallel or cactus-like structures.

```lean
/-- Four-point definition of Gromov hyperbolicity. -/
def IsDeltaHyperbolic {X : Type} [PseudoMetricSpace X] (δ : ℝ) : Prop :=
  ∀ w x y z : X,
    dist w x + dist y z ≤
      max (dist w y + dist x z) (dist w z + dist x y) + 2 * δ

theorem tree_metric_zero_hyperbolic
  (T : Type) [Fintype T] [DecidableEq T]
  [PseudoMetricSpace T]
  (hT : IsTreeMetric T) :
  IsDeltaHyperbolic 0 := by
  sorry
```

Then the genuinely new tropical bridge theorem:

```lean
/-- Tropical path metrics coming from two-terminal series-parallel networks are hyperbolic. -/
theorem series_parallel_tropical_hyperbolic
  (G : BoundaryNetwork)
  (hG : IsSeriesParallel G)
  (hmetric : TropicalPathMetric G) :
  ∃ δ : ℝ, 0 ≤ δ ∧ IsDeltaHyperbolic δ := by
  sorry
```

An even stronger theorem, if feasible:

```lean
theorem series_parallel_tropical_hyperbolic_uniform
  ∃ δ : ℝ, 0 ≤ δ ∧
    ∀ G : BoundaryNetwork, IsSeriesParallel G → TropicalPathMetric G → IsDeltaHyperbolic δ := by
  sorry
```

If the uniform statement is false, produce a counterexample family and prove instead a bound in terms of decomposition depth:

```lean
theorem series_parallel_tropical_hyperbolic_depth_bound
  (G : BoundaryNetwork)
  (hG : IsSeriesParallel G)
  (hmetric : TropicalPathMetric G) :
  IsDeltaHyperbolic (spDepth G * maxEdgeWeight G) := by
  sorry
```

### Proof strategies

#### Strategy A: Four-point inequality by SP induction
Most promising.

1. Define tropical path metric as min over weighted path lengths.
2. Prove the four-point inequality for the base edge/tree case.
3. Show series and parallel compositions preserve hyperbolicity with explicit δ-update formulas.

This is ideal because the proof mirrors the inductive generation of SP networks.

#### Strategy B: Embed tropical metric into a tree-like object
1. Construct a decomposition tree or Buneman-style representation.
2. Show the tropical metric is an additive perturbation of a tree metric.
3. Deduce δ-hyperbolicity from perturbation bounds.

Why powerful: gives geometric intuition and possibly sharper constants.

#### Strategy C: Tropical convexity / injective hull approach
1. Define tropical geodesics and intervals.
2. Show intervals satisfy a slim-triangle condition.
3. Convert slim triangles to four-point hyperbolicity.

Why visionary: connects tropical convexity to coarse negative curvature.  
Why harder: more definitions and more geometry to formalize.

### Cross-domain connections
- **Geometric group theory**: hyperbolicity as a coarse curvature notion.
- **Phylogenetics**: tree metrics and tropical moduli.
- **Optimization**: shortest path geometry and metric embeddings.
- **Machine learning robustness**: tropical decision regions often inherit polyhedral tree-like geometry; hyperbolicity may control adversarial path complexity.

### Application keywords
`Gromov hyperbolicity`, `tropical geometry`, `coarse geometry`, `tree metrics`, `shortest paths`, `metric embeddings`, `phylogenetics`

## Research Direction C: Certified tropical linear algebra library

### Vision
Do not build a bag of lemmas. Build the certified substrate needed for the two theorems above and for future tropical analysis. The goal is a reusable Lean 4 library for max-plus/min-plus matrix algebra with semiring-style statements, spectral invariants, monotonicity, and certified inequalities.

The library should support matrix products, powers, closure/Kleene-star style constructions if feasible, and metric extraction from weighted adjacency matrices.

### Core formalization targets
Introduce a tropical matrix layer on concrete types such as `Matrix (Fin n) (Fin n) ℝ`, with definitions specialized enough to prove theorems now, and abstract enough to generalize later.

Suggested definitions:

```lean
open Matrix

def tropicalAdd (a b : ℝ) : ℝ := min a b
def tropicalMul (a b : ℝ) : ℝ := a + b

def tropicalMatMul {n : ℕ} (A B : Matrix (Fin n) (Fin n) ℝ) :
    Matrix (Fin n) (Fin n) ℝ :=
  fun i k => sInf (Set.range fun j : Fin n => A i j + B j k)

def tropicalMatPow {n : ℕ} (A : Matrix (Fin n) (Fin n) ℝ) : ℕ → Matrix (Fin n) (Fin n) ℝ
  | 0 => fun i j => if i = j then 0 else Real.instTopologicalSpace -- replace with a proper ∞ model if needed
  | m+1 => tropicalMatMul (tropicalMatPow A m) A
```

In practice, you may want to avoid raw `ℝ` and instead use `ℝ∞ := WithTop ℝ` or `ENNReal`-style constructions, because shortest-path tropical algebra needs an additive infinity.

A better signature may be:

```lean
def Trop := WithTop ℝ
```

and then formulate all operations there.

### Precise theorem targets
At minimum prove monotonicity, associativity, and path semantics.

```lean
theorem tropical_matmul_assoc
  {n : ℕ} (A B C : Matrix (Fin n) (Fin n) Trop) :
  tropicalMatMul (tropicalMatMul A B) C = tropicalMatMul A (tropicalMatMul B C) := by
  sorry

theorem tropical_matmul_mono
  {n : ℕ} {A A' B B' : Matrix (Fin n) (Fin n) Trop}
  (hA : A ≤ A') (hB : B ≤ B') :
  tropicalMatMul A B ≤ tropicalMatMul A' B' := by
  sorry

/-- The (i,j)-entry of A^k is the minimum weight of a length-k path. -/
theorem tropical_pow_path_semantics
  {n k : ℕ} (A : Matrix (Fin n) (Fin n) Trop) :
  ∀ i j, tropicalMatPow A k i j = minPathWeightExactLength A k i j := by
  sorry
```

Then connect to metric closure:

```lean
theorem tropical_distance_is_inf_over_powers
  {n : ℕ} (A : Matrix (Fin n) (Fin n) Trop) :
  ∀ i j, tropicalDistance A i j = ⨅ k : ℕ, tropicalMatPow A k i j := by
  sorry
```

This theorem would be transformative because it turns shortest-path geometry into a certified linear-algebraic object.

### Build explicitly on catalog theorems
The existing theorems are not directly about matrices, but they certify a pattern: tropical operations interact well with Lipschitz/robustness control.

Use them conceptually as follows:

1. `tropical_monomial_linear`  
   Treat this as a seed instance that tropical “multiplication” linearizes to ordinary addition on monomials. Generalize from scalars to path weights and then to matrix products.

2. `tropical_affine_lipschitz_certified_robustness` and `tropical_certified_robustness`  
   Reinterpret tropical matrix multiplication as a compositional Lipschitz map on weighted path profiles. This can provide monotonicity and stability lemmas for matrix powers.

3. `multi_class_tropical_certified_robustness`  
   Use the multi-output pattern to motivate matrix row/column-wise certified inequalities.

4. `tropical_mirror_theorem`  
   Though elementary, it is a reminder that idempotence (`max a a = a`, dually `min a a = a`) is foundational. Build an idempotent linear algebra interface around such lemmas.

Most promising for Lean execution.

```lean
theorem sp_boundary_response_tropical_schur_hyperbolic
  (G : BoundaryNetwork)
  (hG : IsSeriesParallel G) :
  ∃ A : Matrix (Fin (numVertices G)) (Fin (numVertices G)) Trop,
    EncodesNetwork G A ∧
    BoundaryResponseFromNetwork G = TropicalSchurComplement A (boundaryIndices G) ∧
    ∃ δ : ℝ, 0 ≤ δ ∧ IsDeltaHyperbolic δ := by
  sorry
```

If you can prove even a weakened version of this, you have created a new certified interface between inverse problems, tropical algebra, and coarse geometry.
