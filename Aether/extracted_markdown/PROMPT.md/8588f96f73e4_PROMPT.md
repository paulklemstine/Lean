## Research Task: GL3 tropical Satake robustness for abstaining top-2 margin Hecke score classifiers

Research Mode: PROVE

Work in a concrete metric setting already compatible with the robustness library, e.g. score maps on `EuclideanSpace ℝ (Fin d)` or on `Fin d → ℝ` equipped with the standard norm metric. The key point is not the ambient type but that the same pairwise-difference Lipschitz hypothesis used in the existing certified-margin theorems is available.

The goal is to formalize a selective multiclass classifier with reject option for three tropical Satake/Hecke scores and prove two stability theorems:

1. **robust preservation of a non-abstaining class decision**, and  
2. **robust preservation of abstention**,  

both from a strict top-2 margin bound.

This is the right next theorem after ordinary multiclass margin robustness: selective classification is genuinely different because one must control not only the argmax class but also the threshold crossing event relative to `τ`. In GL3 tropical Satake language, this says that the tropical representation-theoretic score geometry certifies stability of the reject region and the acceptance regions simultaneously.

### Concrete definitions to introduce

Use three real-valued score coordinates:
```lean
def ScoreVec (X : Type _) := Fin 3 → X → ℝ
```

Define the competing-score maximum:
```lean
def otherMax {X : Type _} (s : Fin 3 → X → ℝ) (i : Fin 3) (x : X) : ℝ :=
  ((Finset.univ.erase i).sup' (by
      simpa using Finset.card_erase_pos.mpr (Finset.mem_univ i))
    (fun j => s j x))
```

Define the margin of class `i`:
```lean
def classMargin {X : Type _} (s : Fin 3 → X → ℝ) (i : Fin 3) (x : X) : ℝ :=
  s i x - otherMax s i x
```

Define a selective classifier with abstention as `Option (Fin 3)`:
```lean
def abstainClassifier {X : Type _} [DecidableEq (Fin 3)]
    (s : Fin 3 → X → ℝ) (τ : ℝ) (x : X) : Option (Fin 3) :=
  if h : ∃ i : Fin 3, τ < classMargin s i x then
    some (Classical.choose h)
  else
    none
```

However, for the main theorems it is cleaner to avoid uniqueness issues in the definition and instead prove preservation statements under an explicit hypothesis
```lean
abstainClassifier s τ x = some i
```
or under the more structural hypothesis
```lean
τ < classMargin s i x
```
together with a lemma that strict margin `> τ` forces all competitors to be below `i`, hence uniqueness. In GL3 this uniqueness proof is easy and worth isolating.

A useful explicit uniqueness lemma:

### Precise theorem statements to target

Assume:
- `X` is a pseudo-metric or normed additive commutative group;
- every pairwise score difference is `Kd`-Lipschitz.

A practical formulation is:
```lean
def PairwiseDiffLipschitz {X : Type _} [PseudoMetricSpace X]
    (s : Fin 3 → X → ℝ) (Kd : ℝ) : Prop :=
  ∀ i j : Fin 3, ∀ x y : X,
    |(s i x - s j x) - (s i y - s j y)| ≤ Kd * dist x y
```

Then prove the max-margin map is also Lipschitz:
```lean
lemma classMargin_lipschitz
    {X : Type _} [PseudoMetricSpace X]
    {s : Fin 3 → X → ℝ} {Kd : ℝ}
    (hLip : PairwiseDiffLipschitz s Kd) :
    ∀ i : Fin 3, ∀ x y : X,
      |classMargin s i x - classMargin s i y| ≤ Kd * dist x y := by
  ...
```

This lemma is the real bridge. Since
`classMargin s i x = min_{j ≠ i} (s i x - s j x)` in the 3-class setting,
you can prove it by rewriting `s i - max_{j ≠ i} s j` as the infimum/minimum of pairwise differences over the two competitors and then controlling the change by the maximum of the two pairwise changes. In `Fin 3`, this can be done concretely by enumerating the two elements of `Finset.univ.erase i`, avoiding any abstract order-theory overhead.


### Proof strategy

1. **Reduce selective robustness to scalar threshold robustness.**  
   The classifier changes from `some i` to something else only if the scalar quantity `classMargin s i` crosses downward through `τ`. Likewise abstention changes to acceptance only if `topMargin` crosses upward through `τ`. This turns the problem into a pair of one-dimensional certified-threshold lemmas.

2. **Prove `classMargin` is Lipschitz from pairwise-difference Lipschitzness.**  
   The key identity is
   ```lean
   classMargin s i x = min' ((Finset.univ.erase i)) (by ...) (fun j => s i x - s j x)
   ```
   because subtracting the maximum competitor is the same as taking the minimum pairwise difference. For a finite min of two terms, use:
   - each term changes by at most `Kd * dist x y`,
   - the min of finitely many `Kd`-Lipschitz functions is still `Kd`-Lipschitz.
   
   In Lean, for `Fin 3`, brute-force finite-set arguments are acceptable and likely easier than proving a general theorem about finite infima.

3. **Derive a Lipschitz bound for `topMargin`.**  
   Since `topMargin` is the supremum over the three class margins, and each class margin is `Kd`-Lipschitz, `topMargin` is also `Kd`-Lipschitz. Again, because the index type is `Fin 3`, this can be proved by finite-case analysis or by a generic lemma on `Finset.sup'` over reals. The needed estimate is
   ```lean
   |topMargin s x - topMargin s y| ≤ Kd * dist x y.
   ```

4. **Apply the certified threshold lemma.**  
   From
   ```lean
   |f x - f y| ≤ Kd * dist x y
   ```
   and
   ```lean
   dist x y < (f x - τ) / Kd
   ```
   with `τ < f x`, deduce `τ < f y`. Similarly, from
   ```lean
   f x < τ
   ```
   and
   ```lean
   dist x y < (τ - f x) / Kd
   ```
   deduce `f y < τ`. This is just arithmetic after the Lipschitz estimate. If the existing robustness library already has a theorem of this shape, instantiate it directly rather than reproving the scalar analysis.

5. **Upgrade scalar threshold preservation to classifier preservation.**  
   For the `some i` theorem, combine `τ < classMargin s i y` with uniqueness of the winning class above threshold. For the `none` theorem, show every class margin stays below `τ`, hence the existential in `abstainClassifier` is false.

### Significance

This theorem is not just a routine variant of top-1 robustness. It adds a **reject option**, so the geometry of the decision rule has two coupled components:
- which class has the top tropical Satake score gap,
- whether that gap clears the acceptance threshold `τ`.

Formally verifying this for GL3 tropical Hecke/Satake scores is valuable for three reasons:

1. **It extends the certified robustness program from classification to selective classification.**  
   That is a real strengthening: preserving the label alone is weaker than preserving both the label and the accept/reject status.

2. **It isolates the exact robust quantity as the top-2 margin.**  
   The theorem shows that the same pairwise tropical Lipschitz control used in ordinary margin theorems is enough to certify selective decisions. This clarifies the mathematical role of the Satake score geometry.

3. **It creates a reusable abstraction for future GLn and tropical Hecke developments.**  
   Once `classMargin` and `topMargin` are handled cleanly, the same pattern should scale to larger finite label sets, top-`k`-with-abstention, hierarchical reject rules, and eventually more representation-theoretic score systems.
