The goal is not merely to repackage standard rewriting folklore, but to turn **normalization by convergent presentations** into a reusable optimization principle inside Lean 4, with explicit bridges to compiler correctness, automated reasoning, and algebraic geometry.

The conceptual leap is this:

## Core Breakthrough Target

### Master Theorem
For any finitely presented single-sorted equational theory `E` over a signature `Σ`, let `R` be an oriented rewrite system on terms such that:

1. every rewrite step of `R` is sound modulo `E`,
2. `R` is terminating,
3. `R` is confluent.

Then the normal-form map `nf_R` is a semantics-preserving optimizer in every `Σ`-algebra satisfying `E`.

Mathematically:

For every `Σ`-algebra `A` satisfying `E`, every variable assignment `ι : X → A`, and every term `t`,
\[
\mathrm{eval}_A(\mathrm{nf}_R(t), \iota) = \mathrm{eval}_A(t, \iota).
\]

This should be formalized as a theorem that factors normalization through the quotient by the congruence generated by `E`, then invokes the abstract quotient optimizer architecture from the catalog.

## Precise Formalization Targets

You will likely need to introduce a new reusable structure encoding convergent optimization systems.

### New Definition 1: RewritePresentation
Define a structure expressing a rewrite system together with the equational theory it presents.

Suggested shape:
```lean
structure RewritePresentation
    (Sig : Type u)
    (Var : Type v)
    (Term : Type w) where
  Red : Term → Term → Prop
  Eqv : Term → Term → Prop
  nf : Term → Term
  sound : ∀ {s t}, Red s t → Eqv s t
  nf_irreducible : ∀ t, ¬ ∃ u, Red (nf t) u
  nf_reachable : ∀ t, Eqv t (nf t)
  nf_unique : ∀ {s t}, Eqv s t → nf s = nf t
```

You may need a more refined version, e.g. replacing `nf_reachable` by reflexive-transitive closure of `Red`, or separating:
- `joinable`,
- `normal`,
- `confluent`,
- `terminating`,
- `nf_spec`.

But define at least one genuinely new concept not already in the catalog. A stronger alternative is:

```lean
structure ConvergentOptimizer (Term : Type u) where
  Red : Term → Term → Prop
  Eqv : Term → Term → Prop
  nf : Term → Term
  sound : ∀ {s t}, Red s t → Eqv s t
  complete : ∀ t, Eqv t (nf t)
  canonical : ∀ {s t}, Eqv s t ↔ nf s = nf t
```

This is stronger and more optimizer-oriented.

### New Definition 2: ModelSound
Formalize what it means for an evaluator to respect the equational theory:
```lean
def ModelSound
    {Term A : Type _}
    (Eqv : Term → Term → Prop)
    (eval : Term → A)
    : Prop :=
  ∀ ⦃s t⦄, Eqv s t → eval s = eval t
```

This will be the exact semantic bridge needed for quotient optimization.

## Stronger Theorem You Should Aim For

If possible, do not stop at `eval (nf t) = eval t`. Prove the **universal property**:

```lean
theorem nf_factors_through_quotient
    {Term A : Type _}
    (P : ConvergentOptimizer Term)
    (eval : Term → A)
    (hmodel : ModelSound P.Eqv eval) :
    ∃ g : Quot (fun s t => P.Eqv s t) → A,
      ∀ t, g ⟦t⟧ = eval (P.nf t)
```

and ideally also
```lean
∀ t, g ⟦t⟧ = eval t
```

This is the true categorical content: normalization gives a section of the quotient semantics by selecting canonical representatives.

This is the theorem that transforms rewriting from “syntax simplification” into **quotient compilation**.

## 2–3 Proof Strategy Architectures

### Strategy A: Abstract quotient-first proof
**Most promising** if the catalog quotient optimizer API is mature.

1. Define the equivalence/congruence `Eqv` generated by the equational theory or by the rewrite relation.
2. Prove that `nf` is constant on `Eqv`-classes:
   \[
   s \sim t \Rightarrow nf(s)=nf(t).
   \]
   This is where confluence and termination do the heavy lifting.
3. Factor `nf` through the quotient and invoke `QuotientOptimizer.preserves_eval` using model soundness of evaluation.

Why this is best:
- maximally reusable,
- aligns directly with catalog lineage,
- reveals the universal mathematical mechanism rather than a one-off rewriting proof.

---

### Strategy B: Closure-of-rewrite-soundness proof
Best if quotient APIs become cumbersome.

1. Show single-step rewrite preserves evaluation:
   ```lean
   Red s t → eval s = eval t
   ```
   by combining rewrite soundness with model soundness.
2. Extend this to reflexive-transitive closure:
   if `s →* t`, then `eval s = eval t`, using induction on the closure proof.
3. Use normalization reachability `t →* nf t` to conclude `eval t = eval (nf t)`.

Why it works:
- technically simpler,
- avoids early quotient engineering,
- still nontrivial if closure and confluence are formalized properly.

Limitation:
- does not by itself expose the quotient optimizer structure as cleanly as Strategy A.

---

### Strategy C: Canonical representative / unique normal forms proof
Best if you formalize confluence and normality directly.

1. Define `Normal t := ¬ ∃ u, Red t u`.
2. Prove every term reduces to a normal form `nf t`.
3. Prove uniqueness of normal forms:
   if `s` and `t` are equivalent, then `nf s = nf t`,
   by joining reduction chains and using irreducibility.
4. Deduce semantic preservation by replacing `t` with its unique canonical representative.

Why it matters:
- captures the classical rewriting theorem in a computationally meaningful form,
- provides a basis for equality checking and optimizer correctness.

This is probably the most mathematically satisfying route if you want the file to feel like a genuine rewriting theory contribution.

## Concrete Lean Engineering Suggestions

You may want lightweight infrastructure for terms rather than full universal algebra at first. A practical route:

- define a first-order term language:
  ```lean
  inductive Term (σ : Type u) (α : Type v)
  | var : α → Term σ α
  | node : σ → List (Term σ α) → Term σ α
  ```

- define evaluation by an algebra structure assigning an interpretation to each symbol:
  ```lean
  structure Algebra (σ : Type u) (A : Type v) where
    interp : σ → List A → A
  ```

- define rewrite relation abstractly on `Term σ α`,
- define reflexive-transitive closure,
- define normal forms and normalization function abstractly.

This lets you prove the universal theorem without getting trapped in full-blown many-sorted algebra.

If the catalog already has term syntax/algebra syntax, use it instead and adapt the theorem statements accordingly.
