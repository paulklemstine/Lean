## Core Mathematical Setup

Let `α` be an input alphabet, and let outputs live in a tropical semimodule such as `Fin m → Tropical ℝ` or a suitable min-plus codomain. For a function
\[
f : \alpha^\* \to Y
\]
with `Y` a tropical semimodule, define the tropical Hankel kernel by
\[
H_f(u,v) := f(uv).
\]

The central idea is to treat the row family
\[
v \mapsto H_f(u,v)
\]
as a tropical semimodule of contexts, and define finite tropical rank by finite generation of this row semimodule (or equivalently column semimodule, if you can prove a duality theorem under your hypotheses).

The cryptographic insight is:

- finite Hankel rank = finite-state recognizability / finite transducer realization,
- finite effective spectral decomposition + bounded ambiguity = algorithmic control of fibers,
- therefore bounded rank families cannot sustain one-wayness or collision resistance.

### 1. Tropical Hankel finite-rank recognizability theorem

Informal statement:

> Let `f : List α → Y` be a tropical-valued word function. If the tropical Hankel row semimodule generated by `u ↦ (v ↦ f (u ++ v))` is finitely generated, then `f` is recognized by a finite min-plus weighted automaton/transducer. Conversely, every finite min-plus weighted automaton induces a function of finite tropical Hankel rank.

This is the structural theorem. It is the weighted/tropical recognizability criterion you will use as the cryptanalytic backbone.

### 2. Effective tropical spectral decomposition implies fiber reconstruction

Informal statement:

> Suppose `f` has finite tropical Hankel rank and admits an effective finite spectral decomposition through a finite tropical semimodule. This is the cryptanalytic theorem. It should not remain existential if avoidable; formulate a computable certification statement.

## Proof Architecture: 3 Viable Strategies

### Strategy A: Tropical Myhill–Nerode → Hankel finite generation → finite recognizability
**Most promising for the first main theorem.**

1. Define the right congruence / residual profile:
   \[
   u \sim_f u' \iff \forall v,\ f(uv)=f(u'v)
   \]
   or a weighted/tropical variant where equality is replaced by equality of residual rows.

2. Use the existing Tropical Myhill–Nerode theorem as the finite-index engine:
   - finite number of residual profiles,
   - each row lies in the semimodule generated by representatives,
   - build a finite weighted automaton from residual states.

3. Prove converse by extracting residual row vectors from any finite transducer realization:
   - each state induces a row profile,
   - all rows factor through the finite state space,
   - hence finite rank.

**Why promising:** this aligns with already-developed automata infrastructure and avoids inventing spectral theory from scratch. It gives a canonical route from language-theoretic finite-state structure to Hankel factorization.

---

### Strategy B: Matrix factorization via tropical linear algebra
**Most promising for the spectral decomposition and collision algorithm.**

1. Model the transducer/hash as a tropical matrix product:
   \[
   f(w) = \lambda \otimes M_{a_1}\otimes \cdots \otimes M_{a_k}\otimes \rho
   \]
   using existing `tropMul` lemmas.

2. Show that if only finitely many residual vectors arise up to tropical span, then the infinite Hankel matrix factors as
   \[
   H_f = P \otimes Q
   \]
   through a finite tropical semimodule.

3. Use this factorization to derive an explicit finite search space for collisions/fibers:
   - outputs are determined by finite state summaries,
   - bounded ambiguity ensures finitely many minimal witnesses per summary,
   - certified search over the summary graph yields witnesses.

**Why promising:** this strategy naturally exploits `tropMul`, transpose identities, and boundedness lemmas. It is especially suited to code extraction and executable reconstruction algorithms.

---

### Strategy C: Syntactic semimodule / semiring representation theory
**Most conceptually ambitious; likely strongest long-term payoff.**

1. Define the syntactic tropical semimodule of `f` generated by left derivatives/residuals.
2. Show finite generation of the syntactic semimodule is equivalent to finite Hankel rank.
3. Interpret cryptographic invertibility failure as finite presentability of this semimodule, from which collision reconstruction follows by enumerating semimodule normal forms.

**Why promising:** if successful, this turns tropical cryptanalysis into a representation-theoretic discipline.  
**Why riskier now:** requires more infrastructure and may exceed what is currently easiest to formalize.
