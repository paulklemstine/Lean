## Assignment: Certified Novelty Detection for Theorem Provers

Prove new, non-trivial theorems. Build on catalog theorems. Minimize sorry.

### Research Direction
Construct a **formal novelty certification layer** for theorem proving outputs: a mathematically certified mechanism that assigns to each theorem statement a computable embedding into a metric space and proves that sufficiently large distance from a certified archive implies non-identity, non-redundancy, and structural novelty. The breakthrough is not “better search heuristics”; it is a **foundational theorem of mathematical originality detection** inside Lean.

This should not be treated as vague ML-style embedding rhetoric. The target is a rigorous finite-dimensional theorem encoding with a provable separation theorem.

### Core Breakthrough Target

Define a concrete feature embedding of theorem statements into a finite-dimensional normed space, beginning with a syntactic/semantic abstraction over a restricted theorem language, and prove a **distance-based novelty certification theorem**.

A strong first target is to formalize theorem descriptors as finite feature vectors extracted from concrete mathematical statements over `Nat`, `Fin`, `Bool`, finite sums/products, bounded quantifier depth, and a finite vocabulary of symbols. Then prove that if two theorem descriptors are equal in the induced embedding, their certified feature summaries coincide; if the distance exceeds an explicit archive radius, then the theorem lies outside the archive novelty ball.

This is already mathematically meaningful if done correctly: it yields a certified outer approximation to “known mathematics,” analogous to certified robustness in verification, but now for theorem-space.

## Precise Theorem Statement

### Primary theorem
Let `Descriptor` be a concrete structure encoding bounded theorem features, and let `embed : Descriptor → EuclideanSpace ℝ (Fin n)` be a feature map. Let `archive : Finset Descriptor`. Define the archive radius of a candidate `d` by
`archiveDist d archive = inf' archive (fun a => ‖embed d - embed a‖) ...`.

Prove:

> **Novelty Certificate Theorem.**  
> For every descriptor `d` and finite archive `A`, if `ε ≥ 0` and every archived descriptor lies at Euclidean distance at least `ε` from `d`, then `d` is certified `ε`-novel relative to `A`. Moreover, if the embedding is injective on the descriptor class, then any `ε > 0` certificate implies `d ∉ A`.

In Lean-oriented form, target something close to:

```lean
structure Descriptor where
  quantDepth : ℕ
  symbolCount : ℕ
  binderCount : ℕ
  hasEq : Bool
  hasForall : Bool
  hasExists : Bool
  natArity : ℕ
  finArity : ℕ
  boolArity : ℕ
  deriving DecidableEq

def embed (d : Descriptor) : EuclideanSpace ℝ (Fin 9) :=
  fun i =>
    match i.1 with
    | 0 => d.quantDepth
    | 1 => d.symbolCount
    | 2 => d.binderCount
    | 3 => if d.hasEq then 1 else 0
    | 4 => if d.hasForall then 1 else 0
    | 5 => if d.hasExists then 1 else 0
    | 6 => d.natArity
    | 7 => d.finArity
    | _ => d.boolArity

def archiveDist (A : Finset Descriptor) (d : Descriptor) : ℝ :=
  if h : A.Nonempty then
    Finset.inf' A h (fun a => ‖embed d - embed a‖)
  else 0

def Novel (ε : ℝ) (A : Finset Descriptor) (d : Descriptor) : Prop :=
  ε ≤ archiveDist A d

theorem novelty_of_pointwise_lower_bound
    (A : Finset Descriptor) (d : Descriptor) (ε : ℝ)
    (hA : A.Nonempty)
    (hε : 0 ≤ ε)
    (hsep : ∀ a ∈ A, ε ≤ ‖embed d - embed a‖) :
    Novel ε A d := by
  ...

theorem not_mem_of_positive_novelty
    (hinj : Function.Injective embed)
    (A : Finset Descriptor) (d : Descriptor) (ε : ℝ)
    (hA : A.Nonempty)
    (hε : 0 < ε)
    (hnov : Novel ε A d) :
    d ∉ A := by
  ...
```

Use the catalog theorem `inf'_eq_of_bounds_and_witness` to prove not just a lower bound but **exact nearest-neighbor distance realization** for a finite archive.

Target:

## Proof Strategy Paths

### Strategy A: Finite-infimum certification via catalog bridge
Most promising.

1. Define `archiveDist` using `Finset.inf'`.
2. Apply `inf'_eq_of_bounds_and_witness` from `Bridges/BottleneckUpgrade.lean` to show exact realization of the nearest archived descriptor.
3. Use the witness theorem to derive the equivalence:
   - lower bounds on all archive points imply lower bound on the infimum;
   - if the infimum is at least `ε`, then every point is at least `ε`.
4. For `not_mem_of_positive_novelty`, argue by contradiction:
   if `d ∈ A`, then the witness distance can be `0`, hence `archiveDist A d = 0`, contradicting `ε > 0`.

Why best: it directly exploits the strongest relevant catalog theorem and turns your novelty predicate into a computable certified quantity.

### Strategy B: Dimension-reduction and oracle viewpoint
More visionary, potentially field-opening.

1. Interpret `embed` as an oracle-accessible theorem feature extractor.
2. Use `query_strategy_output_bound` and `oracle_dimension_bounds` to formalize that any bounded-query novelty checker only sees a compressed descriptor.
3. Prove a theorem of the form: finite-dimensional embeddings induce a certified novelty lower bound but also a collision upper bound unless injectivity assumptions hold.
4. This yields a **tradeoff theorem**: certification strength versus descriptor dimension.

This is conceptually powerful because it connects novelty detection to oracle complexity and information bottlenecks.

### Strategy C: Boolean circuit semantics for theorem fingerprints
A cross-domain route.

1. Encode basic theorem features as Boolean circuits or finite predicates.
2. Use `litCircuit_correct` to validate correctness of feature extraction from theorem descriptors.
3. Lift Boolean correctness to metric correctness by summing indicator coordinates into a real vector embedding.
4. Prove Hamming-distance or Euclidean-distance novelty lower bounds.

Why interesting: this ties theorem novelty to verified hardware/circuit semantics, suggesting formally verified theorem-fingerprint compilers.
