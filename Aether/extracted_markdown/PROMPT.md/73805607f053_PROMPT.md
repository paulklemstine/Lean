## Theorem 1: Exceptional parameters are controlled by local obstructions

### Mathematical statement
Prove a theorem of the following shape:

\[
\forall c \in \mathbb Z,\quad \text{ExceptionalParameter}(c) \implies \text{LocalObstruction}(c).
\]

Interpretation: if Benford universality fails, there must be some modular or periodic degeneracy already visible modulo a prime. This is a decisive reduction from an analytic/digital phenomenon to an arithmetic one.

### Lean 4 type signature
```lean
theorem exceptional_implies_localObstruction
    (T : ℤ → ℕ → ℤ)
    (hcompat : ∀ c n, T c (n+1) = quadraticStep c (T c n))
    (hBenfordCriterion :
      ∀ c, (¬ ∃ p : ℕ, Nat.Prime p ∧ DegenerateModPrime (T c) p) →
        BenfordUniversal (T c)) :
    ∀ c : ℤ, ExceptionalParameter T c → LocalObstruction T c
```

This is not trivial: it is a contrapositive structural theorem. The proof should use `by_contra`, unfold the new definitions, and drive the contradiction through the Benford criterion.

### Why this matters
This theorem is the hinge. It says exceptional parameters cannot be “mysterious”; they must advertise themselves through a finite-level obstruction. That is exactly the kind of theorem that makes finiteness plausible and algorithmically testable.

### Proof strategy options
**Strategy A: Contrapositive reduction**  
1. Assume `¬ LocalObstruction T c`.  
2. Apply the abstract Benford criterion hypothesis to deduce `BenfordUniversal (T c)`.  
3. Contradict `ExceptionalParameter T c`.  
Most promising if the catalog already contains a criterion converting modular nondegeneracy into Benford behavior.

**Strategy B: Minimal bad prime argument**  
1. Suppose `ExceptionalParameter T c`.  
2. Assume no local obstruction and derive uniform non-periodicity modulo all primes.  
3. Use a preexisting periodicity/exponential-growth theorem to force Benford universality.  
Best if the existing theorem `periodic...` in the catalog gives a bridge from periodicity failure to statistical spread.

**Strategy C: Orbit closure formulation**  
1. Rephrase local obstruction as finite orbit collapse modulo some prime.  
2. Show that absence of such collapse yields sufficiently rich logarithmic mantissa dynamics.  
3. Deduce Benford universality.  
Most ambitious; best if you can connect to equidistribution already formalized.

## Theorem 2: Finite obstruction sets yield finite exceptional sets

### Mathematical statement
Prove an abstract finiteness transfer theorem:

\[
\left(\forall p,\ \text{only finitely many } c \text{ are degenerate mod } p\right)
\;\wedge\;
\left(\text{only finitely many } p \text{ can witness degeneracy}\right)
\;\Longrightarrow\;
E \text{ is finite}.
\]

This is the theorem that turns local arithmetic classification into global exceptional-set finiteness.

### Lean 4 type signature
A finite-set version is likely easiest:

```lean
theorem finite_exceptional_of_finite_obstruction_support
    (T : ℤ → ℕ → ℤ)
    (S : Finset ℕ)
    (hprime : ∀ p ∈ S, Nat.Prime p)
    (hcontrol :
      ∀ c : ℤ, ExceptionalParameter T c →
        ∃ p ∈ S, DegenerateModPrime (T c) p)
    (hfinite :
      ∀ p ∈ S, {c : ℤ | DegenerateModPrime (T c) p}.Finite) :
    {c : ℤ | ExceptionalParameter T c}.Finite
```

If `Set.Finite` over `ℤ` is awkward in your local setup, use an equivalent boundedness statement:

```lean
theorem bounded_exceptional_of_bounded_local_obstructions
    (T : ℤ → ℕ → ℤ) :
    ...
```

### Why this matters
This theorem is the formal skeleton of the entire conjecture. Once proven, any future local classification instantly yields global finiteness. It transforms brute-force search into a mathematically principled pipeline.

### Proof strategy options
**Strategy A: Finite union of finite sets**  
1. Show each exceptional parameter belongs to a union over `p ∈ S` of degenerate parameter sets.  
2. Prove this union is finite.  
3. Conclude exceptional set finite.  
Most promising and cleanest in Lean, using `Set.Finite.subset` and finite unions.

**Strategy B: Explicit enumeration map**  
1. Construct a function sending each exceptional `c` to a witness prime `p ∈ S`.  
2. Partition the exceptional set by witness prime.  
3. Use finite fibers and finite index set.  
Useful if direct set-union lemmas become cumbersome.

**Strategy C: Boundedness instead of finiteness**  
1. Replace finite sets by explicit bounds on `|c|`.  
2. Prove exceptional parameters lie in a bounded interval.  
3. Convert bounded integer sets to finite sets.  
Good if your obstruction classification naturally produces inequalities.

## Theorem 3: Cross-domain theorem — periodicity forces digital non-universality

You are required to include a cross-domain connection. Here the strongest one is:

**arithmetic dynamics + digital statistics / information theory**

### Mathematical statement
If the orbit of \(T_c\) is eventually periodic, then its leading-digit distribution cannot be Benford-universal unless the orbit is trivial in a very special sense. In particular, eventual periodicity creates a positive lower bound on divergence from the Benford law.

A theorem of the following shape is ideal:

\[
\forall c,\ \text{EventualPeriodic}(T_c) \to \neg \text{BenfordUniversal}(T_c).
\]

Or, in a stronger information-theoretic form:

\[
\text{EventualPeriodic}(T_c) \to D_{\mathrm{KL}}(\mu_c \,\|\, \mu_{\mathrm{Benford}}) > 0.
\]

### Lean 4 type signature
A qualitative version is more realistic:

```lean
theorem eventualPeriodic_not_benford
    (T : ℤ → ℕ → ℤ)
    (c : ℤ)
    (hper : EventualPeriodic (T c)) :
    ¬ BenfordUniversal (T c)
```

If KL divergence is already formalized, go stronger:

```lean
theorem eventualPeriodic_kl_pos
    (T : ℤ → ℕ → ℤ)
    (c : ℤ)
    (hper : EventualPeriodic (T c)) :
    0 < KLDivergence (digitDist (T c)) benfordDist
```

### Why this matters
This is the cross-domain bridge: a dynamical rigidity property implies an information-theoretic anomaly. That is exactly the kind of result that makes mathematicians say, “I never thought of connecting those two things.” It reframes Benford failure as a **low-entropy signature of dynamical collapse**.

### Proof strategy options
**Strategy A: Finite support argument**  
1. Show eventual periodicity implies only finitely many values recur in the orbit tail.  
2. Deduce only finitely many leading-digit frequencies appear in the tail.  
3. Contradict Benford universality, which requires asymptotic logarithmic digit frequencies.  
Most promising if `EventualPeriodic` is already available.

**Strategy B: Empirical measure rigidity**  
1. Construct the empirical digit distribution of the periodic tail.  
2. Show it is rational with denominator equal to the period length.  
3. Prove it cannot equal the Benford distribution, whose probabilities involve irrational logarithms.  
This is especially beautiful and genuinely deep.

**Strategy C: KL lower bound from support mismatch**  
1. Show periodic tails induce atomic distributions on a finite digit cycle.  
2. Compare with Benford’s strictly nonuniform logarithmic law.  
3. Produce a positive divergence bound.  
Best if probability mass functions are formalized enough.
