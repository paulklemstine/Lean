## Core Mathematical Setup

Work first in the finite-state setting, which is already deep enough to be publishable and formalizable.

Let:
- `α` be a finite type of observable classes / closure states,
- `A : Matrix α α (WithBot ℤ)` or `Matrix α α (WithBot ℚ)` be the tropical transition matrix,
- `A i j = ⊥` mean transition `i → j` is forbidden,
- finite path weight be the tropical sum of edge weights, i.e. ordinary sum in `ℤ`/`ℚ`,
- path score be the maximum over admissible paths,
- asymptotic pressure be the normalized maximal path weight.

You may choose `WithBot ℤ` first for ease of finite combinatorics, then generalize to `WithBot ℚ` if feasible. If max-plus infrastructure is easier over `ℝ`, state the finite rational/integer version as a corollary after embedding.

Define the **maximum cycle mean**
\[
\lambda_{\mathrm{trop}}(A)
:= \max_{\gamma \text{ directed cycle}} \frac{w(\gamma)}{\ell(\gamma)}.
\]

Define the **closure pressure**
\[
P_{\mathrm{cl}}(A)
:= \sup_{n \ge 1} \frac{1}{n}\max\{w(p) : p \text{ admissible path of length } n\}.
\]
For finite graphs, one expects this to equal the maximum cycle mean.

The EML content enters by proving that a finitary closure correspondence operator `T` canonically induces such a weighted graph up to closure-congruence quotient, and that the invariant is independent of representatives.

### Theorem 1: Quotient Invariance of Tropical Transition Semantics

Let `T` be a finitary closure correspondence operator on a finite observable quotient, with transition weight depending only on closure-congruence classes. Then the induced tropical transition matrix is well-defined on the quotient.

Suggested Lean shape:
```lean
theorem tropical_transition_wellDefined_quotient
  {α β : Type*} [Fintype α]
  (q : α → β)
  [Fintype β]
  (T : α → Finset α)
  (w : α → α → WithBot ℤ)
  (hq_surj : Function.Surjective q)
  (hT_compat :
    ∀ {x x' y y'}, q x = q x' → q y = q y' →
      (y ∈ T x ↔ y' ∈ T x'))
  (hw_compat :
    ∀ {x x' y y'}, q x = q x' → q y = q y' → w x y = w x' y')
  :
  ∃ M : Matrix β β (WithBot ℤ),
    ∀ b c, M b c =
      sSup {t | ∃ x y, q x = b ∧ q y = c ∧ y ∈ T x ∧ w x y = t}
```

You may want to replace `sSup` by an explicit finite maximum over representatives to avoid order-theoretic overhead. If so, define the quotient matrix using `Finset.sup`.

**Breakthrough significance:** this theorem makes tropical semantics intrinsic to closure dynamics, not an artifact of presentation.

### Theorem 4: Periodic Orbit Growth Bound and Equality in the Primitive Case

Let `Per_n(T)` denote the set of periodic closure trajectories of period `n`, with suitable weight normalization. Then:
\[
\limsup_{n\to\infty}\frac{1}{n}\log^+(\mathrm{Per}_n(T)) \le \lambda_{\mathrm{trop}}(T)
\]
or, in a purely tropical-weighted form,
\[
\sup_n \frac{1}{n}\max_{\gamma:\,\ell(\gamma)=n,\ \gamma \text{ periodic}} w(\gamma)
\le \lambda_{\mathrm{trop}}(T),
\]
with equality under strong connectivity / primitivity assumptions.

## Proof Strategy Architecture

You must pursue at least 2 serious proof routes and choose the one that formalizes best.

### Strategy A: Finite weighted graph combinatorics via cycle decomposition
**Most promising for Lean.**

1. Define path weights and maximal length-`n` path score.
2. Prove subadditivity / quasi-superadditivity properties for maximal path weights.
3. Show every long path decomposes into a simple prefix plus cycles; deduce asymptotic normalized maximal weight is bounded by the maximal cycle mean.
4. Construct arbitrarily long paths by repeating a maximizing cycle; deduce the reverse inequality.
5. Conclude `closurePressure = maxCycleMean`.

Why this is promising:
- Finite combinatorics, no heavy order theory
- Clear bridge to algorithmics
- Avoids needing a mature tropical semiring eigenvector library

### Strategy B: Tropical Collatz–Wielandt through subeigenvectors and potentials
1. Define a tropical subeigenvector condition:
   \[
   A_{ij} + u_j \le \mu + u_i.
   \]
2. Show any such `μ` upper-bounds every cycle mean by telescoping around a cycle.
3. Construct a potential `u` from longest-path data below a candidate threshold `μ > maxCycleMean`.
4. Infer
   \[
   \maxCycleMean = \inf\{\mu : \exists u,\ A \otimes u \le \mu \otimes u\}.
   \]
5. Identify this infimum as the tropical eigenvalue / pressure.

Why this matters:
- Gives the true variational flavor
- Connects to optimization, Bellman inequalities, and control theory
- Stronger conceptual theorem, though probably harder in Lean

### Strategy C: Dynamic programming / Karp formula
1. Define `dp k i` as maximal weight of a path of length `k` ending at `i`.
2. Prove Karp’s formula for maximum cycle mean:
   \[
   \lambda = \max_i \min_{0 \le k < n}\frac{dp(n,i)-dp(k,i)}{n-k}.
   \]
3. Use this to derive computability and asymptotic pressure equality.
4. Package as a certified algorithm.

Why this is powerful:
- Strongest computational endpoint
- Opens extraction to verified algorithms
- But may be technically heavier than Strategy A for the first pass

**Recommended order:** A first, then B, then C.  
A gives the main theorem quickly and robustly. B upgrades it to a true variational principle. C turns the theory into a certified computational engine.

## Cross-Domain Connections You Should Exploit Explicitly

### 1. Thermodynamic formalism ↔ idempotent analysis
Classical pressure sums over trajectories; tropical pressure takes the maximal weighted trajectory. This is the zero-temperature / large-deviation shadow of classical thermodynamics. Make this analogy explicit in theorem naming and comments.

### 2. EML closure dynamics ↔ automata / weighted graph semantics
A finitary closure correspondence operator is effectively a weighted automaton on observable classes. This lets you import finite graph methods and reinterpret closure complexity as path optimization.

### 3. Tropical spectral radius ↔ Bellman optimality / control
The subeigenvector inequality
\[
A_{ij}+u_j \le \mu+u_i
\]
is a Bellman-type certificate. This gives a direct route to verified complexity bounds and compression certificates.

### 4. Periodic orbit growth ↔ symbolic dynamics
The equality between pressure and cycle mean under primitivity is a tropical analogue of spectral control of periodic orbit growth in subshifts and transfer-operator theory.

### 5. Compression ↔ information theory
If closure trajectories are encoded by finite admissible paths, then tropical pressure measures asymptotic “dominant orbit cost,” which can be interpreted as a code-rate obstruction or compression certificate. Even one formal corollary here would be highly original.

### 6. Tropicalization of classical transfer semantics
Use the existing Ruelle/Artin–Mazur theorem as a conceptual predecessor: the classical zeta/rationality side tracks counting; the tropical side tracks extremal growth. These are complementary thermodynamic regimes.
