## Theorem 1: Spectral gap positivity from nontrivial representation exclusion

This is the foundational theorem that upgrades connectivity to quantitative expansion.

### Mathematical statement

For any finite group `G` and symmetric generating set `S`, if every nontrivial irreducible representation `ρ` of `G` has normalized averaging operator
\[
A_{S,\rho} := \frac{1}{|S|}\sum_{s\in S}\rho(s)
\]
with operator norm at most `β < 1`, then the normalized second eigenvalue of the Cayley graph adjacency operator is at most `β`, hence the spectral gap is at least `1 - β`.

This theorem is the formal portal from representation theory to combinatorial expansion.

### Lean 4 type signature target

You may need to adapt names to the existing API, but the target shape should be as close as possible to:

```lean
theorem cayley_secondEigenvalue_le_of_irrep_bound
    {G : Type*} [Group G] [Fintype G] [DecidableEq G]
    (S : Finset G)
    (hSsymm : ∀ g ∈ S, g⁻¹ ∈ S)
    (hSgen : Subgroup.closure ((↑S : Set G)) = ⊤)
    (β : ℝ)
    (hβ : β < 1)
    (hirr :
      ∀ (ρ : Representation ℂ G V),
        IsIrreducible ρ →
        ¬ Subsingleton V →
        operatorNorm (cayleyAverageOperator S ρ) ≤ β) :
    cayleySecondEigenvalue G S ≤ β
```

If full irreducible representation infrastructure is too heavy, prove a certified finite-dimensional surrogate theorem using the regular representation and invariant subspace decomposition already available or constructible.

### Why this is a breakthrough

This theorem isolates the exact mechanism by which arithmetic information enters expander theory. Once formalized, every future arithmetic expansion result becomes a matter of feeding in representation bounds. This is the correct abstraction layer for Bourgain–Gamburd, Deligne-style estimates, and quasirandomness arguments.

### Proof strategy options

#### Strategy A: Regular representation decomposition
1. Express the Cayley averaging operator on `ℓ²(G)` and identify constants as the trivial subrepresentation.
2. Decompose the orthogonal complement into irreducible components.
3. Bound the operator norm on each component and conclude the second eigenvalue bound by a supremum argument.

This is the most conceptually powerful route and the right long-term architecture.

#### Strategy B: Direct invariant-subspace argument
1. Define the mean-zero subspace of functions on `G`.
2. Show the averaging operator preserves this subspace.
3. Prove the operator norm bound on this subspace from a decomposition theorem or an abstract spectral lemma.

This may be easier if the representation API is incomplete.

#### Strategy C: Character-theoretic finite formula
1. Use the class function / Fourier transform on finite groups.
2. Express the trace or spectral radius in terms of irreducible characters.
3. Deduce the eigenvalue bound from the irreducible estimates.

This is elegant but likely more infrastructure-heavy.

Most promising: **Strategy A**, because it scales directly to all future arithmetic groups.

## Theorem 2: A certified spectral gap theorem for explicit generators in `SL₂(𝔽_p)`

Do not attempt full Bourgain–Gamburd in one jump. Instead, prove a nontrivial explicit theorem for a concrete generator family and then test it computationally.

### Candidate explicit generators

Take
\[
u = \begin{pmatrix}1&1\\0&1\end{pmatrix}, \qquad
v = \begin{pmatrix}1&0\\1&1\end{pmatrix}
\]
in `SL₂(𝔽_p)`.

These are canonical unipotent generators. For odd prime `p`, they generate `SL₂(𝔽_p)`.

### Mathematical statement

For odd prime `p`, the symmetric generating set
\[
S_p = \{u, u^{-1}, v, v^{-1}\}
\]
generates `SL₂(𝔽_p)`, and the associated normalized adjacency operator has strictly positive spectral gap:
\[
\lambda_2(\mathrm{Cay}(SL_2(\mathbb F_p), S_p)) < 1.
\]

This is weaker than a uniform lower bound, but it is already a genuinely spectral theorem: positivity of gap is equivalent to connectedness only because the operator is symmetric and the graph is regular, and the proof should proceed through spectral reasoning rather than merely graph traversal.

### Lean 4 type signature target

```lean
theorem sl2_unipotent_pair_spectral_gap_pos
    (p : ℕ) [Fact p.Prime] (hpodd : p ≠ 2) :
    let G := SL(2, ZMod p)
    let u : Matrix (Fin 2) (Fin 2) (ZMod p) := !![1,1;0,1]
    let v : Matrix (Fin 2) (Fin 2) (ZMod p) := !![1,0;1,1]
    let S : Finset G := {⟨u, by simp [u]⟩, ⟨u⁻¹, by simp⟩,
                         ⟨v, by simp [v]⟩, ⟨v⁻¹, by simp⟩}
    0 < cayleySpectralGap G S
```

If `SL(2, ZMod p)` notation is unavailable, define the subtype:
```lean
def SL2 (p : ℕ) := { A : Matrix (Fin 2) (Fin 2) (ZMod p) // A.det = 1 }
```

### Why this matters

This is the first arithmetic instantiation of the abstract expander framework. It takes the framework from permutation groups to algebraic groups over finite fields. Once this theorem exists, uniformity in `p`, random generation, and comparison with Ramanujan bounds become meaningful next steps instead of slogans.

### Proof strategy options

#### Strategy A: Generation + symmetric operator + Perron-Frobenius style spectral separation
1. Prove `u, v` generate `SL₂(𝔽_p)` using elementary row operation factorization.
2. Use existing connectivity theorems for the Cayley graph.
3. Deduce spectral gap positivity for the symmetric normalized adjacency operator by ruling out eigenvalue `1` on the orthogonal complement of constants.

This is likely the most feasible formal route.

#### Strategy B: Explicit action on functions
1. Define averaging by left multiplication with `u, v`.
2. Show any eigenfunction with eigenvalue `1` is invariant under `u` and `v`.
3. Since `u, v` generate, the eigenfunction is constant; therefore the second eigenvalue is `< 1`.

This is a beautiful direct proof and may be easier than importing heavy spectral graph machinery.

#### Strategy C: Representation-theoretic exclusion of trivial summands
1. View the averaging operator in the regular representation.
2. Show eigenvalue `1` occurs only on the trivial representation.
3. Conclude positivity of the spectral gap.

Most promising: **Strategy B**, because it is deep, concrete, and avoids unnecessary abstraction while still being spectral.

## Theorem 3: Elementary generation theorem for `SL₂(𝔽_p)` via unipotents

This is the algebraic backbone needed for Theorem 2 and future arithmetic expansion.

### Mathematical statement

For every prime `p`, `p ≠ 2`, the subgroup of `SL₂(𝔽_p)` generated by the upper and lower unipotents
\[
u = \begin{pmatrix}1&1\\0&1\end{pmatrix}, \qquad
v = \begin{pmatrix}1&0\\1&1\end{pmatrix}
\]
is all of `SL₂(𝔽_p)`.

Equivalently, every determinant-1 matrix over `𝔽_p` can be written as a product of these elementary matrices.

### Lean 4 type signature target

```lean
theorem closure_unipotent_generators_eq_top_SL2
    (p : ℕ) [Fact p.Prime] (hpodd : p ≠ 2) :
    let G := SL2 p
    let u : G := ...
    let v : G := ...
    Subgroup.closure ({u, v} : Set G) = ⊤
```

A stronger constructive factorization theorem would be even better:

```lean
theorem exists_word_unipotent_generators_of_mem_SL2
    (p : ℕ) [Fact p.Prime] (hpodd : p ≠ 2)
    (g : SL2 p) :
    ∃ w : List (SL2 p), (∀ x ∈ w, x = u ∨ x = u⁻¹ ∨ x = v ∨ x = v⁻¹) ∧
      w.prod = g
```

### Why this matters

This theorem is the arithmetic analogue of “adjacent transpositions generate `S_n`.” But unlike the symmetric-group case, the proof uses algebraic geometry in miniature: Bruhat-style elimination, elementary matrices, and the structure of reductive groups over finite fields. It is the correct entrance ramp to higher-rank groups and arithmetic quotients.

### Proof strategy options

#### Strategy A: Gaussian elimination in `SL₂`
1. For `g = [[a,b],[c,d]]`, split into cases `c = 0` and `c ≠ 0`.
2. If `c ≠ 0`, use products of elementary unipotents to reduce `g` to diagonal form.
3. Show determinant-1 diagonal matrices are also products of unipotents.

This is the most explicit and Lean-friendly approach.

#### Strategy B: Bruhat decomposition
1. Prove `SL₂(𝔽_p) = B ∪ BwB`.
2. Show both the Borel subgroup `B` and the Weyl element `w` lie in the subgroup generated by `u` and `v`.
3. Conclude generation.

This is conceptually superior and aligns with future generalization to `SL_n`.

#### Strategy C: Reduction from elementary linear group results
If Mathlib already contains enough facts about `ElementaryMatrix`, reduce generation to those certified theorems.

Most promising: **Strategy A** for immediate formalization, with **Strategy B** worth documenting in `FUTURE_DIRECTIONS.md`.

## Theorem 4: Cross-domain bridge — expansion implies rapid mixing for the random walk on `SL₂(𝔽_p)`

You are required to include a theorem connecting this domain to another. The cleanest bridge is to probability / statistical mechanics / quantum information.

### Mathematical statement

Let `μ_p` be the simple random walk measure on the symmetric generating set `S_p`. If the normalized second eigenvalue is `≤ β < 1`, then for every mean-zero function `f` on `SL₂(𝔽_p)`,
\[
\|A_{S_p}^n f\|_2 \le β^n \|f\|_2.
\]
Consequently, the total variation distance to uniform decays exponentially.

This ties arithmetic expansion to mixing of Markov chains and to unitary design heuristics in quantum computing.

### Lean 4 type signature target

```lean
theorem sl2_random_walk_L2_decay
    (p : ℕ) [Fact p.Prime] (hpodd : p ≠ 2)
    (β : ℝ)
    (hβ : cayleySecondEigenvalue (SL2 p) (unipotentSymmSet p) ≤ β)
    (n : ℕ)
    (f : (SL2 p) → ℂ)
    (hfmean : mean_zero f) :
    ‖(cayleyAveragingOperator (unipotentSymmSet p))^[n] f‖ ≤ β^n * ‖f‖
```

If the exact normed-space API is difficult, prove a finite-dimensional version using sums over `Fintype`.

### Why this is revolutionary

This is where arithmetic expansion exits pure group theory and becomes a transport principle. Rapid mixing on `SL₂(𝔽_p)` is relevant to:

- pseudorandom generation,
- Monte Carlo on algebraic groups,
- quantum compiling via gate sets related to `SL₂`,
- and statistical-mechanical interpretations of spectral relaxation.

This is the theorem that makes the project legible outside pure number theory.

### Proof strategy options

#### Strategy A: Spectral theorem for self-adjoint averaging operator
1. Show symmetry of `S_p` makes the operator self-adjoint.
2. Restrict to the orthogonal complement of constants.
3. Apply operator norm submultiplicativity and iterate.

#### Strategy B: Finite-dimensional diagonalization
1. Represent the operator by a Hermitian matrix.
2. Diagonalize over `ℂ`.
3. Bound powers by eigenvalue powers.

Most promising: **Strategy A**, because it matches the abstract framework.

\[

### Conjecture B: Random pair expansion for `SL₂(𝔽_p)`
For uniformly random generating pairs `(σ, τ)` of `SL₂(𝔽_p)`, the Cayley graph on `{σ^{±1}, τ^{±1}}` has spectral gap bounded below by an absolute constant with probability tending to `1` as `p → ∞`.

This is the explicit formal version of the assignment conjecture.

### Computational falsification protocol

For `p = 5, 7, 11, 13`:

1. Enumerate elements of `SL₂(𝔽_p)`.
2. Build the Cayley graph for:
   - canonical pair `(u,v)`,
   - several random generating pairs `(σ,τ)`.
3. Compute normalized adjacency matrices.
4. Extract the second largest eigenvalue modulus.
5. Compare:
   - empirical spectral gap,
   - Alon–Boppana / Ramanujan heuristic threshold `2√(q-1)/q` for `q = 4`,
   - and pair-to-pair variance.

A clear disproof would be a systematic decay of the gap toward `0` already in small primes or a pathological family among canonical generators.
