## Theorem 1: Log-Hessian induces a positive definite metric on zero-sum directions

### Mathematical statement

Let `L` be the resolvent matrix of a DPP on a finite ground set `α`, and let `H` be the Hessian of `log p` at the all-ones point, where `p` is the generating polynomial. Suppose catalog results identify off-diagonal entries by
\[
H_{ij} = - L_{ij}^2 \quad (i \neq j),
\]
and row sums vanish after the canonical diagonal correction, so that `H` annihilates constant vectors. Then the restriction of `-H` to the zero-sum subspace is positive definite.

This is the first theorem that turns conditional negative dependence into a genuine Riemannian metric statement.

### Suggested Lean 4 type signature

Adjust names/types to actual catalog conventions, but target something of this form:

```lean
theorem repulsionMetric_posDef_on_zeroSum
    {n : ℕ}
    (H : Matrix (Fin n) (Fin n) ℝ)
    (hsym : H.IsSymm)
    (hker_const : ∀ c : ℝ, H.mulVec (fun _ => c) = 0)
    (hcnd : ∀ x : Fin n → ℝ, (∑ i, x i = 0) →
      0 ≤ - dotProduct x (H.mulVec x)) :
    ∀ x : zeroSumSubmodule n,
      x.1 ≠ 0 →
      0 < - dotProduct x.1 (H.mulVec x.1)
```

A more DPP-specific version is even better:

```lean
theorem dpp_repulsionMetric_posDef
    {n : ℕ}
    (L : Matrix (Fin n) (Fin n) ℝ)
    (hLsymm : L.IsSymm)
    (hH : ∀ i j, i ≠ j → dppLogHessian L i j = - (L i j)^2)
    (hrowsum : ∀ i, ∑ j, dppLogHessian L i j = 0) :
    ∀ x : zeroSumSubmodule n,
      x.1 ≠ 0 →
      0 < repulsionEnergy (dppLogHessian L) x
```

### Why this is a breakthrough

This theorem says repulsion is not merely “curvature-like”; it defines an actual inner geometry on admissible perturbations. That is the gateway to importing the full toolkit of information geometry: natural gradients, geodesics, Cramér–Rao-type inequalities, and convexity of entropy-like functionals.

## Theorem 2: Energy representation as a pairwise resistance-form sum

### Mathematical statement

For any symmetric matrix `H` with zero row sums, the quadratic form on zero-sum vectors admits the canonical pairwise representation
\[
-x^\top H x = \frac12 \sum_{i,j} w_{ij}(x_i-x_j)^2,
\quad\text{where } w_{ij} = -H_{ij} \text{ for } i\neq j.
\]
In the DPP resolvent case, using `H_{ij} = -L_{ij}^2`, this becomes
\[
-x^\top H x = \frac12 \sum_{i,j} L_{ij}^2 (x_i-x_j)^2.
\]
This identifies the repulsion metric with a weighted graph Dirichlet form.

### Suggested Lean 4 type signature

```lean
theorem repulsionEnergy_eq_pairwise
    {n : ℕ}
    (H : Matrix (Fin n) (Fin n) ℝ)
    (hsym : H.IsSymm)
    (hrowsum : ∀ i, ∑ j, H i j = 0) :
    ∀ x : Fin n → ℝ,
      - dotProduct x (H.mulVec x)
        = (1 / 2 : ℝ) * ∑ i, ∑ j, (-H i j) * (x i - x j)^2
```

DPP-specialized:

```lean
theorem dpp_repulsionEnergy_eq_resolventDirichlet
    {n : ℕ}
    (L : Matrix (Fin n) (Fin n) ℝ)
    (hLsymm : L.IsSymm)
    (hHoff : ∀ i j, i ≠ j → dppLogHessian L i j = - (L i j)^2)
    (hrowsum : ∀ i, ∑ j, dppLogHessian L i j = 0) :
    ∀ x : Fin n → ℝ,
      - dotProduct x ((dppLogHessian L).mulVec x)
        = (1 / 2 : ℝ) * ∑ i, ∑ j, (L i j)^2 * (x i - x j)^2
```

### Why this matters

This theorem is the dictionary entry. It rewrites an information-theoretic Hessian as an electrical-network energy. Once formalized, it becomes possible to compare repulsive measures via spectral sparsification, resistance bounds, and graph embedding techniques.

## Theorem 3: Resistance distance equals the dual metric on point-mass differences

### Mathematical statement

Let `Q = -H`, where `H` is as above, so `Q` is PSD with kernel equal to the constants. Let `Q⁺` be its Moore–Penrose pseudoinverse. Define the repulsion distance between coordinates by
\[
d_H(i,j)^2 := (e_i-e_j)^\top Q^+ (e_i-e_j).
\]
Then in the DPP case with weights `w_{ij}=L_{ij}^2`, this equals the effective resistance distance of the weighted graph with conductances `L_{ij}^2`.

This is the precise form of the “isometry to effective resistance” conjecture.

### Suggested Lean 4 type signature

If pseudoinverse infrastructure is too heavy, formulate first as an equality between two identically defined quantities attached to the same operator.

```lean
def coordDiff (n : ℕ) (i j : Fin n) : Fin n → ℝ :=
  fun k => if k = i then 1 else if k = j then -1 else 0

theorem repulsionDistance_eq_effectiveResistance
    {n : ℕ}
    (Q : Matrix (Fin n) (Fin n) ℝ)
    (hQsymm : Q.IsSymm)
    (hQpsd : 0 ≤ᵐ Q)
    (hker : ∀ x, Q.mulVec x = 0 ↔ ∃ c : ℝ, x = fun _ => c)
    (i j : Fin n) :
    repulsionDistanceSq Q i j
      = effectiveResistanceSq Q i j
```

A DPP-resolvent version:

```lean
theorem dpp_repulsionDistance_eq_resistance
    {n : ℕ}
    (L : Matrix (Fin n) (Fin n) ℝ)
    (hLsymm : L.IsSymm)
    (hvalid : IsDPPResolvent L) :
    ∀ i j : Fin n,
      repulsionDistanceSq (dppConductanceMatrix L) i j
        = effectiveResistanceSq (dppConductanceLaplacian L) i j
```

If a full pseudoinverse formalization is too ambitious, prove the variational characterization:
\[
d_H(i,j)^2
=
\sup_{x:\, x_i-x_j=1} \frac{1}{x^\top Q x},
\]
or the minimization dual
\[
d_H(i,j)^2
=
\inf\{ x^\top Q x : x_i-x_j=1\}^{-1},
\]
which is often easier to formalize and already enough to identify the metric with effective resistance.

### Why this is revolutionary

This theorem would convert a second derivative of a probability generating function into a metric invariant already central in graph theory, random walks, and network science. It would let one transport known resistance inequalities directly into repulsive probability.

### Mathematical statement

For a generating polynomial that factors as a product of positive linear forms

p(x)=\prod_{k=1}^m \ell_k(x),

This would connect Lorentzian/strongly log-concave combinatorics to classical statistical models.

## Proof architecture: 3 viable strategies

You must attempt multiple proof pathways and choose the strongest one.

### Strategy A: Dirichlet-form expansion from row-sum-zero Hessians
1. Start from the catalog Hessian formula for DPPs, especially off-diagonal identification `H_{ij} = -L_{ij}^2`.
2. Prove the diagonal is forced by the zero-row-sum identity, turning `Q = -H` into a weighted Laplacian.
3. Expand `xᵀQx` into the pairwise sum `1/2 ∑_{i,j} w_{ij}(x_i-x_j)^2` by multi-step `calc`, symmetry, and row-sum cancellation.
4. Deduce positive definiteness on zero-sum vectors using connectivity/nondegeneracy hypotheses.

**Why promising:** This uses only finite-dimensional linear algebra and should be closest to existing catalog lemmas.

### Strategy B: Spectral decomposition on constants ⊕ zero-sum
1. Decompose `Fin n → ℝ` into the direct sum of constants and zero-sum vectors.
2. Show `H` annihilates constants and is negative semidefinite by catalog conditional negative semidefiniteness.
3. Restrict to the orthogonal complement and use eigenvalue positivity of `-H` there.
4. Define the metric and, if possible, the pseudoinverse using the inverse on the restricted operator.

**Why promising:** Best route for the resistance-isometry theorem and conceptual clarity. It matches the geometry exactly.

### Strategy C: Variational/electrical characterization
1. Define the repulsion energy as the infimum of `xᵀQx` among vectors with prescribed coordinate difference `x i - x j = 1`.
2. Prove this equals the effective resistance characterization from electrical network theory.
3. Use the DPP Hessian formula to identify the conductances as `L_{ij}^2`.

**Why promising:** Avoids needing a fully developed Moore–Penrose pseudoinverse API. Most robust if matrix inverse machinery becomes painful in Lean.

**Recommendation:** Start with Strategy A to establish the Dirichlet form theorem, then move to Strategy C for the distance theorem. Strategy B is ideal if the spectral decomposition APIs are comfortable enough.
