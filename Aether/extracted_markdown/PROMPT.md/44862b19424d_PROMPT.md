### Theorem 1: Prime sensitivity of arithmetic phase probes

**Mathematical statement.**  
Let `M` be a finitely generated abelian group. If `M` has nonzero `p`-torsion and no nonzero `q`-torsion for a distinct prime `q`, then the prime profiles at `p` and `q` differ. In particular, any phase classifier built from all primes up to a bound containing `p,q` distinguishes `M` from a module whose torsion is supported only at `q`.

This theorem is the formal arithmetic analogue of “wrong characteristic misses the phase.”

#### Lean 4 type signature target
```lean
theorem torsionProfile_distinguishes_primes
  {M : Type} [AddCommGroup M] [Module ℤ M]
  [Module.Finite ℤ M]
  {p q P : ℕ}
  (hp : Nat.Prime p) (hq : Nat.Prime q) (hpq : p ≠ q)
  (hMp : ∃ x : M, x ≠ 0 ∧ (p : ℤ) • x = 0)
  (hMq : ∀ y : M, (q : ℤ) • y = 0 → y = 0)
  (hp_le : p ≤ P) (hq_le : q ≤ P) :
  torsionProfileUpTo M P ≠
    (Finset.range (P+1)).filter (fun r => Nat.Prime r ∧ r = q) := by
  ...
```

You may replace the right-hand side with a more natural comparison object, e.g. the profile of another module `N`. The key theorem is:

> if two modules differ in prime torsion support inside the observation window `≤ P`, then their arithmetic torsion profiles differ.

A better and cleaner formal statement may be:

```lean
theorem torsionProfileUpTo_ne_of_prime_witness
  {M N : Type} [AddCommGroup M] [Module ℤ M] [Module.Finite ℤ M]
               [AddCommGroup N] [Module ℤ N] [Module.Finite ℤ N]
  {p P : ℕ}
  (hp : Nat.Prime p) (hp_le : p ≤ P)
  (hM : ∃ x : M, x ≠ 0 ∧ (p : ℤ) • x = 0)
  (hN : ∀ y : N, (p : ℤ) • y = 0 → y = 0) :
  torsionProfileUpTo M P ≠ torsionProfileUpTo N P := by
  ...
```

#### Why this matters
This is the first **soundness theorem** for arithmetic phase distinction: a prime-local torsion event is enough to force phase separation under the arithmetic classifier.

### Theorem 4: Finite-prime phase separation from bounded arithmetic support

**Mathematical statement.**  
Let `M` and `N` be finitely generated abelian groups. Suppose all torsion primes of `M` and `N` are at most `P`. Then equality of `torsionProfileUpTo M P` and `torsionProfileUpTo N P` is equivalent to equality of the prime support of the torsion subgroups.

#### Lean 4 type signature target
```lean
theorem torsionProfileUpTo_complete_for_bounded_support
  {M N : Type}
  [AddCommGroup M] [Module ℤ M] [Module.Finite ℤ M]
  [AddCommGroup N] [Module ℤ N] [Module.Finite ℤ N]
  {P : ℕ}
  (hMbound : ∀ p, Nat.Prime p → HasPTorsion M p → p ≤ P)
  (hNbound : ∀ p, Nat.Prime p → HasPTorsion N p → p ≤ P) :
  torsionProfileUpTo M P = torsionProfileUpTo N P ↔
    ∀ p, Nat.Prime p → (HasPTorsion M p ↔ HasPTorsion N p) := by
  ...
```

This is a clean formal version of the “all primes up to a size-dependent bound suffice” philosophy.

#### Why this would be revolutionary
It would be the first theorem that makes the conjectural physics slogan mathematically testable: **bounded prime scanning is complete for bounded systems**.

## Proof Strategy Architecture

You must include 2–3 real proof pathways and choose the most promising.

### Strategy A: Finitely generated abelian group decomposition
Use the structure theory of finitely generated abelian groups, or as much of it as Mathlib exposes, to reduce statements to free parts and cyclic torsion summands.

1. Decompose modules into free part plus torsion summands.
2. Show free summands contribute no `p`-torsion via `pTorPersistence_vanishes_of_free`.
3. Show cyclic summands `ZMod n` contribute exactly at primes dividing `n`.
4. Reassemble prime support through products/direct sums.

**Why promising:** This is the mathematically canonical route and aligns directly with arithmetic phase interpretation. If decomposition lemmas are available enough in Mathlib, this gives the cleanest theorem statements.

---

### Strategy B: Direct prime-action analysis on cyclic models
Avoid full classification and prove theorems for explicit physical toy models built from products of `ZMod n`.

1. Define arithmetic phase profiles for products like `ZMod n × ZMod m`.
2. Prove detectability at primes dividing one factor using witness elements.
3. Prove invisibility at wrong primes using coprimality and scalar invertibility arguments.
4. Extend by induction over finite products.

**Why promising:** This is likely the most Lean-tractable route. It still yields a genuine breakthrough if you package the results as a phase classifier for finite cyclic gauge models.

---

### Strategy C: Persistent filtration theorem via monotonicity
Model energy filtration levels as a nested family of modules or quotients and prove monotonicity/stability of prime support.

1. Define `persistentPrimeSupportUpTo`.
2. Prove monotonicity under filtration inclusion.
3. Show phase transitions force support change, and support changes imply a detectable arithmetic event.
4. Connect to catalog persistence lemmas.

**Why promising:** This best captures the physics of phase transitions. It may be harder technically, but even a partial theorem here would significantly deepen the project.

---

### Recommended path
Start with **Strategy B**, because it is most likely to yield robust Lean proofs without overreliance on unavailable decomposition APIs. Then import the conceptual strength of **Strategy A** where possible, and finally formulate at least one **Strategy C** theorem for filtered systems. The file should read as the beginning of a new theory, not as a bag of examples.
