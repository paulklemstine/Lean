## Assignment: Direction 1 — Deletion–Contraction Duality for Polynomial Supports

**Mode:** prove

You should not treat this as a routine extension. The real target is to **create a support-level minor theory** for discrete convex polynomial supports, with a deletion–contraction formalism strong enough to support inductive classification theorems and invariant recurrences. The contraction theorem already gives one half of the matroidal machine. The breakthrough is to show that polynomial supports themselves admit a **minor calculus** analogous to matroids, and that this calculus is rich enough to carry a Tutte-type universal invariant.

The immediate conjecture below is only the entry point. The real objective is a formal framework where support deletion, support contraction, exchange, and recursive invariants interact exactly as they do in matroid theory — but now at the level of exponent sets of polynomials, opening a new algebraic-combinatorial interface.

---

## Core Vision

Let \( \alpha \) be a finite index type and let \( S \subseteq \mathbb{N}^\alpha \) be a support. Define deletion in coordinate \( i \in \alpha \) by
\[
D_i(S) := \{ m \in S \mid m(i)=0 \}.
\]
This is the support-level analogue of setting \(x_i=0\) in a polynomial and retaining only monomials that survive. Contraction, already developed in the catalog, is the support-level analogue of dividing out a common \(x_i\)-power and projecting.

The theorem you should prove is not merely “deletion preserves exchange.” It should establish that **exchange-stable supports admit minors**, and that these minors satisfy a **deletion–contraction recurrence** for a support-Tutte invariant. This would make M-convex supports behave like a genuine combinatorial species with recursive structure.

This is a breakthrough because it would enable:
- inductive proofs on supports via minors,
- classification programs for Lorentzian / M-convex polynomial supports,
- transfer of Tutte-style universality into algebraic combinatorics,
- bridges to graph polynomials, reliability, Potts models, and knot invariants through Jones/Tutte correspondences.

## Precise Theorem Targets

You must formalize at least the following three theorem-level milestones.

### Theorem 1: Deletion preserves the exchange property

Let `exchange` be the support exchange axiom already used in
`Catalog/Pythagorean/LorentzianRecognitionComplete.lean`.

If \(S\) satisfies exchange, then for every coordinate \(i\), the deletion \(D_i(S)\) also satisfies exchange.

### Lean 4 target signature (adapt as needed to actual catalog names)
```lean
theorem exchange_of_deletion
  {ι : Type*} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι →₀ ℕ)) (i : ι)
  (hS : SupportExchange S) :
  SupportExchange (supportDelete S i)
```

If the catalog uses a set-valued rather than `Finset` formulation, prove the set version first and derive the finitary corollary:
```lean
theorem exchange_of_deletion_set

  (S : Set (ι →₀ ℕ)) (i : ι)
  (hS : SupportExchangeSet S) :

```

### Theorem 2: Deletion and contraction define a support-level minor system

You should define a new notion of support minor generated by deletion and contraction, and prove closure of exchange under both operations.

A possible new definition:
```lean
inductive SupportMinorStep {ι : Type*} [DecidableEq ι] :
    Finset (ι →₀ ℕ) → Finset (ι →₀ ℕ) → Prop
| delete (S : Finset (ι →₀ ℕ)) (i : ι) :
    SupportMinorStep S (supportDelete S i)
| contract (S : Finset (ι →₀ ℕ)) (i : ι) :
    SupportMinorStep S (supportContract S i)

def SupportMinor {ι : Type*} [DecidableEq ι] :
    Finset (ι →₀ ℕ) → Finset (ι →₀ ℕ) → Prop :=
Relation.TransGen SupportMinorStep
```

Then prove:
```lean
theorem exchange_of_minor
  {ι : Type*} [Fintype ι] [DecidableEq ι]
  {S T : Finset (ι →₀ ℕ)}
  (hS : SupportExchange S)
  (hST : SupportMinor S T) :
  SupportExchange T
```

This is the theorem that turns the current isolated contraction result into a genuine minor theory.

### Theorem 3: A deletion–contraction recurrence for a support-Tutte polynomial

You need a new invariant. Do **not** just state a recurrence abstractly. Define a support-level polynomial-valued invariant recursively on minors, at least for a class where the recursion is well-founded and computable.

A promising route is to define a rank-like quantity from the affine span / coordinate support / jump complexity of the exponent set, and then define activities through deletion–contraction. If full universality is too ambitious in one cycle, prove a rigorous prototype recurrence on a certified class of supports induced by matroids.

For a matroid-induced support \(S_M\), prove that your support-Tutte invariant agrees with the ordinary Tutte polynomial of \(M\), or at minimum satisfies the same deletion–contraction recurrence on non-loop/non-coloop coordinates.

A prototype Lean target:
```lean
theorem supportTutte_delete_contract
  {ι : Type*} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι →₀ ℕ)) (i : ι)
  (hS : SupportExchange S)
  (hregular : SupportRecursiveRegular S i) :
  supportTutte S =
    supportTutte (supportDelete S i) +
      supportTutte (supportContract S i)
```

If the correct formula requires coefficients \(x\), \(y\), or special loop/coloop cases, formalize the full trichotomy:
```lean
theorem supportTutte_recursion
  ...
  : supportTutte S =
      if hloop : IsSupportLoop S i then
        Y * supportTutte (supportDelete S i)
      else if hcoloop : IsSupportColoop S i then
        X * supportTutte (supportContract S i)
      else
        supportTutte (supportDelete S i) +
        supportTutte (supportContract S i)
```

This is the theorem that changes the direction from “one more closure property” to “a universal recursive invariant exists on support minors.”

## Why this is mathematically revolutionary

Deletion corresponds to setting a variable to zero; contraction corresponds to removing a forced power and renormalizing. These are the two fundamental local operations on polynomial supports. If both preserve exchange/M-convexity, then support geometry acquires a **minor theory**. Once a minor theory exists, universal recursive invariants become possible. That is exactly the historical route by which matroid theory became a central hub connecting graph theory, statistical physics, coding theory, and knot theory.

The support-level viewpoint is more flexible than matroids because it is native to:
- multivariate generating functions,
- Lorentzian and strongly log-concave polynomials,
- tropical geometry,
- Newton polytopes and discrete convex analysis.

A deletion–contraction theorem at the support level would therefore open a new field: **minor theory for algebraic supports**.

## Proof strategy architecture

You must present and pursue multiple proof routes, not just one.

### Strategy A: Direct witness preservation under filtering
Most promising for Theorem 1.

1. Unfold `supportDelete`.
2. Take `x, y ∈ D_i(S)` and a coordinate pair witnessing exchange tension.
3. Apply exchange in `S` to obtain an exchanged vector `x - e_a + e_b`.
4. Prove the exchanged vector still has \(i\)-coordinate zero.

The key difficulty is when one of the exchange coordinates equals `i`. You must isolate the cases:
- if `a = i`, then `x i > y i`, impossible because both deleted vectors satisfy `x i = y i = 0`;
- if `b = i`, then the exchange output would increase coordinate `i`, so you need to show this case cannot be required or can be replaced by another witness using the exchange hypotheses.

This case split is exactly where the theorem becomes nontrivial. Do not handwave it.

### Strategy B: Interpret deletion as face restriction of the support polytope
More conceptual and potentially stronger.

1. Regard \(D_i(S)\) as the intersection of the support with the coordinate hyperplane \(m_i=0\).
2. Show exchange/M-convexity is stable under taking such coordinate faces.
3. Derive deletion preservation from a general face theorem.

This could produce a stronger theorem:
> any coordinate face of an exchange support is exchange.

Lean target:
```lean
theorem exchange_of_coordinate_face
  ...
  (A : Finset ι) :
  SupportExchange S → SupportExchange (supportFace S A)
```
with deletion as the special case `A = {i}`.

This is more ambitious, but if achieved it is the better theorem because it exposes the true convex-geometric mechanism.

### Strategy C: Reduce to known matroid basis exchange on special supports
Best for validating the Tutte recurrence.

1. Construct support families induced by matroid bases.
2. Show support deletion/contraction coincide with matroid deletion/contraction on those families.
3. Transfer the classical Tutte recurrence.

This is the strongest route for Theorem 3 because it anchors your new invariant in an already universal object. Even a partial theorem of the form
\[
\mathrm{supportTutte}(S_M)=T_M
\]
for basis supports would be substantial.

**Recommendation:**  
Use Strategy A to secure the foundational closure theorem quickly.  
Use Strategy B if the direct proof gets tangled — it may produce the cleanest general theorem.  
Use Strategy C for the recursive invariant, because universality is easiest to justify through matroid-induced supports.
