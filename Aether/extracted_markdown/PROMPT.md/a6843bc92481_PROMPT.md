### Theorem 1: Conformal transport of the spherical Laplacian
This is the foundational geometric theorem.

#### Mathematical statement
Let `σ : ℝ² → S² \ {N}` be the inverse stereographic projection and let `u : S² → ℝ` be smooth. If `v = u ∘ σ`, then
\[
\Delta_{S^2} u (\sigma(x))
=
\frac{(1+\|x\|^2)^2}{4}\,\Delta_{\mathbb R^2} v(x).
\]
Equivalently,
\[
\Delta_{\mathbb R^2} v(x)
=
\frac{4}{(1+\|x\|^2)^2}\,(\Delta_{S^2}u)(\sigma(x)).
\]

This is the exact analytic dictionary. Once formalized, every spherical eigenfunction becomes a weighted planar PDE solution.

#### Lean 4 type signature sketch
You will likely need to adapt to available manifold/Laplacian APIs, but the target should look like:
```lean
theorem laplacian_inverseStereographic_pullback
  (u : Sphere (0 : EuclideanSpace ℝ (Fin 3)) 1 → ℝ)
  (hu : ContDiff ℝ 2 u)
  (x : EuclideanSpace ℝ (Fin 2)) :
  laplacianEuclidean (fun y => u (inverseStereographic y)) x
    =
  (4 / (1 + ‖x‖^2)^2) *
    laplacianSphere u (inverseStereographic x)
```

If full manifold Laplacian infrastructure is too heavy, prove a formally weaker but still meaningful version in coordinates:
- define the inverse stereographic map explicitly,
- define the pulled-back differential operator,
- prove equality between the transported operator and the weighted Euclidean Laplacian.

#### Why this is a breakthrough
This theorem creates the **formal conformal transport engine** for neural field equations. It is the reusable core from which weighted PDEs, bifurcation theory, and mode classification on cortical-like geometries can be derived.

#### Proof strategies
**Strategy A: Coordinate computation (most promising).**
1. Define inverse stereographic projection explicitly:
   \[
   \sigma(x,y)=\left(\frac{2x}{1+r^2},\frac{2y}{1+r^2},\frac{r^2-1}{1+r^2}\right), \quad r^2=x^2+y^2.
   \]
2. Compute the pullback metric and show it equals
   \[
   \left(\frac{2}{1+r^2}\right)^2 g_{\mathrm{Euc}}.
   \]
3. Use the formula for the Laplace–Beltrami operator under a conformal metric in dimension 2.

**Strategy B: Differential geometric transport.**
1. Prove the stereographic chart is conformal.
2. Invoke the 2D conformal covariance of the Laplacian.
3. Specialize to `S²`.

**Strategy C: Direct operator comparison.**
1. Define the transported operator on `ℝ²` from the spherical metric.
2. Expand the operator using `field_simp`, `ring`, and derivative identities.
3. Match coefficients with the weighted Euclidean Laplacian.

Strategy A is best because it is explicit, Lean-friendly, and minimizes reliance on the most delicate manifold APIs.

### Theorem 2: Spherical eigenmodes induce weighted planar eigen-solutions
This is the first real neural-field consequence.

#### Mathematical statement
If `u : S² → ℝ` satisfies
\[
\Delta_{S^2}u = -l(l+1)u,
\]
then its pullback `v = u ∘ σ` satisfies
\[
\Delta_{\mathbb R^2} v
=
-\frac{4\,l(l+1)}{(1+\|x\|^2)^2}v.
\]
Thus spherical harmonic modes become solutions of a weighted Schrödinger-type equation on the plane.

#### Lean 4 type signature sketch
```lean
theorem spherical_eigenmode_to_weighted_planar_mode
  (u : Sphere (0 : EuclideanSpace ℝ (Fin 3)) 1 → ℝ)
  (l : ℕ)
  (hu : IsSphereEigenfunction u l)
  (x : EuclideanSpace ℝ (Fin 2)) :
  laplacianEuclidean (fun y => u (inverseStereographic y)) x
    =
  -((4 : ℝ) * l * (l + 1) / (1 + ‖x‖^2)^2) *
    (fun y => u (inverseStereographic y)) x
```

You may define:
```lean
def IsSphereEigenfunction
  (u : Sphere (0 : EuclideanSpace ℝ (Fin 3)) 1 → ℝ) (l : ℕ) : Prop :=
  ∀ p, laplacianSphere u p = -((l : ℝ) * (l + 1)) * u p
```

#### Why this matters
This theorem converts abstract harmonic analysis into a **pattern-generating algorithm**. It says every degree-`l` spherical mode yields a weighted planar stationary state. This is the formal seed of the hallucination-pattern prediction program.

#### Proof strategies
**Strategy A: Immediate corollary of Theorem 1.**
1. Pull back the spherical eigenvalue equation.
2. Substitute using the conformal transport identity.
3. simplify with `field_simp` and `ring_nf`.

**Strategy B: Define weighted planar operator first.**
1. Define
   ```lean
   def weightedSphericalOperator (v : ℝ² → ℝ) (x : ℝ²) :=
     ((1 + ‖x‖^2)^2 / 4) * laplacianEuclidean v x
   ```
2. Prove the pullback intertwines `laplacianSphere` and `weightedSphericalOperator`.
3. Transfer eigenfunction status.

### Theorem 3: Degree-`l` pattern multiplicity equals `2l+1`
This theorem makes the pattern count precise at the linearized level.

#### Mathematical statement
The real vector space of spherical harmonics of degree `l` on `S²` has dimension `2l+1`.

A formalized version can be weakened if necessary: prove that a concrete explicitly defined family of degree-`l` modes is linearly independent and spans a `(2l+1)`-dimensional subspace. Even this would already be a major formal achievement if connected to pattern counting.

#### Lean 4 type signature sketch
Depending on Mathlib’s finite-dimensional APIs:
```lean
theorem finrank_degree_l_spherical_modes (l : ℕ) :
  FiniteDimensional.finrank ℝ (SphericalModeSpace l) = 2 * l + 1
```

If the full abstract space is too ambitious, target:
```lean
theorem exists_linearly_independent_family_of_spherical_modes
  (l : ℕ) :
  ∃ (ι : Type) (_ : Fintype ι) (f : ι → Sphere (0 : EuclideanSpace ℝ (Fin 3)) 1 → ℝ),
    Fintype.card ι = 2 * l + 1 ∧
    LinearIndependent ℝ f ∧
    ∀ i, IsSphereEigenfunction (f i) l
```

#### Why this is revolutionary
This theorem ties the neuroscience claim to representation theory. It says pattern multiplicity is not arbitrary or numerological: it emerges from the irreducible `SO(3)` module of degree `l`. This is the first rigorous bridge from cortical geometry to symmetry-forced pattern counts.

#### Proof strategies
**Strategy A: Polynomial harmonic construction.**
1. Define homogeneous harmonic polynomials in `ℝ³`.
2. Restrict degree-`l` harmonic polynomials to `S²`.
3. Use the classical dimension count.

**Strategy B: Inductive representation-theoretic construction.**
1. Build ladder operators or recurrence relations.
2. Prove linear independence by evaluating on carefully chosen points.
3. Count the family.

**Strategy C: Use associated Legendre-style concrete basis.**
1. Define a concrete family indexed by `m ∈ {-l,...,l}`.
2. Show each satisfies the eigenvalue equation.
3. Prove linear independence via parity/Fourier decomposition in spherical coordinates.

Strategy C is likely the most Lean-realistic if you avoid full Lie theory and focus on explicit functions.

### Theorem 4: Decay of planar pullbacks at infinity for mean-zero modes
This gives the planar neural interpretation.

#### Mathematical statement
If `u : S² → ℝ` is continuous and vanishes at the north pole, then its inverse stereographic pullback `v = u ∘ σ` satisfies
\[
\lim_{\|x\|\to\infty} v(x)=0.
\]
In particular, any spherical harmonic of positive degree whose value at the north pole is zero induces a decaying planar pattern.

A stronger version: after suitable rotation, every nonconstant degree-`l` mode has a pullback decaying along some chosen chart.

#### Lean 4 type signature sketch
```lean
theorem tendsto_pullback_at_infty_of_vanish_north
  (u : Sphere (0 : EuclideanSpace ℝ (Fin 3)) 1 → ℝ)
  (hu : Continuous u)
  (hN : u northPole = 0) :
  Tendsto (fun x : EuclideanSpace ℝ (Fin 2) => u (inverseStereographic x))
    (cocompact (EuclideanSpace ℝ (Fin 2)))
    (𝓝 0)
```

#### Why this matters
This theorem explains why planar patterns arising from spherical modes look localized or decaying. It is the analytic justification behind interpreting the pullback as a physically meaningful cortical pattern in Euclidean coordinates.

#### Proof strategies
**Strategy A: Topological compactification.**
1. Show inverse stereographic projection sends `‖x‖ → ∞` to the north pole.
2. Use continuity of `u`.
3. Transfer the limit.

**Strategy B: Sequential characterization.**
1. Take any sequence `x_n` with `‖x_n‖ → ∞`.
2. Show `σ(x_n) → N`.
3. Conclude `u(σ(x_n)) → u(N)=0`.

This should use nontrivial `rcases`, limit reasoning, and geometric inequalities.

### Theorem 5: Radius-to-mode selection inequality (formal linear surrogate for the Mexican-hat conjecture)
Do not overpromise full nonlinear stability unless the library supports it. Instead, prove a precise linear selection theorem.

#### Mathematical statement
Let `K_r` be a rotationally symmetric interaction kernel on `S²` whose spherical harmonic eigenvalues are `λ_l(r)`. Suppose:
1. `λ_N(r) > 0`,
2. `∀ l ≠ N, λ_l(r) < λ_N(r)`.

Then the top eigenspace of the linearized neural field operator has dimension `2N+1`, and under inverse stereographic projection this yields a `(2N+1)`-dimensional family of dominant weighted planar modes.

#### Lean 4 type signature sketch
```lean
theorem top_mode_multiplicity_of_radial_kernel
  (r : ℝ) (N : ℕ) (K : RadialSphereKernel)
  (hmax : IsUniqueMaxMode K r N) :
  FiniteDimensional.finrank ℝ (TopModeSpace K r) = 2 * N + 1
```

You will need to define `RadialSphereKernel`, its mode eigenvalues, and `TopModeSpace`.

#### Why this is the right theorem
This is the mathematically honest version of the `2N+1` pattern-count principle. It captures the symmetry mechanism exactly, even before nonlinear stability is formalized.

#### Proof strategies
**Strategy A: Spectral decomposition by harmonic modes.**
1. Define the operator induced by a radial kernel.
2. Prove each degree-`l` harmonic subspace is invariant.
3. Use uniqueness of the top eigenvalue to identify the top eigenspace.

**Strategy B: Funk–Hecke style finite-mode abstraction.**
1. Postulate mode eigenvalues as data attached to a radial kernel.
2. Build the theorem abstractly from eigenspace decomposition.
3. Later instantiate for explicit kernels.

Strategy B is likely best for this cycle because it avoids heavy harmonic integral analysis while preserving the scientific content.
