Title: Tropical Hypergraph Counterpoint for SATB: zero-locus legality, shortest-path realization, and pairwise tensor factorization

You should attack the SATB problem as a genuine new mathematical object: a tropical constrained dynamical system whose legal trajectories are exactly geodesics in a hypergraph with multi-voice penalties. The breakthrough is not “formalizing music theory.” It is proving that a high-arity symbolic constraint system can be converted into tropical optimization with exact legality detection and nontrivial state-space compression. If successful, this opens a field: certified tropical symbolic dynamics for structured combinatorial art, program synthesis, and constraint-governed sequential design.

## Core theorem package

Work with a finite pitch universe `P : Finset ℤ` or, if Lean convenience demands, `P : Finset Int`. A chord is an SATB assignment `v : Fin 4 → ℤ`. A progression is `σ : Fin (n+1) → (Fin 4 → ℤ)`.

Define for each unordered voice pair `(i,j)` with `i < j` a pairwise penalty
- `parallelFifthPenalty_pair i j v w : ℝ`
- `crossingPenalty_pair i j w : ℝ`
- `spacingPenalty_pair i j w : ℝ`

and aggregate
- `pairPenalty i j v w := max (parallelFifthPenalty_pair i j v w) (max (crossingPenalty_pair i j w) (spacingPenalty_pair i j w))`
- `totalPenalty6 v w := ∑ (ij in unordVoicePairs), pairPenalty ij.1 ij.2 v w`

where `unordVoicePairs : Finset (Fin 4 × Fin 4)` is the 6 unordered pairs.

Also define legality of a transition:
- `LegalSATBStep v w : Prop`
meaning no forbidden parallel fifths between any pair, no voice crossing in `w`, and all spacing constraints hold.

Your first target is an exact zero-locus theorem.

### Theorem 1: SATB zero-locus characterization
Precise statement:
For all chords `v w`, the transition is legal iff every pairwise penalty vanishes, equivalently iff the total tropical penalty vanishes.

Suggested Lean shape:
```lean
def Voice := Fin 4
def Chord := Voice → Int

def LegalSATBStep (v w : Chord) : Prop := ...
def pairPenalty (i j : Voice) (v w : Chord) : ℝ := ...
def totalPenalty6 (v w : Chord) : ℝ := ∑ ij in unordVoicePairs, pairPenalty ij.1 ij.2 v w

theorem legal_iff_pairPenalty_zero
    (v w : Chord) :
    LegalSATBStep v w ↔
      ∀ ij ∈ unordVoicePairs, pairPenalty ij.1 ij.2 v w = 0 := ...

theorem legal_iff_totalPenalty6_zero
    (v w : Chord) :
    LegalSATBStep v w ↔ totalPenalty6 v w = 0 := ...
```

A stronger and more tropical variant is worth proving if your definitions make penalties nonnegative:
```lean
theorem totalPenalty6_eq_zero_iff
    (hnonneg : ∀ v w ij, 0 ≤ pairPenalty ij.1 ij.2 v w)
    (v w : Chord) :
    totalPenalty6 v w = 0 ↔
      ∀ ij ∈ unordVoicePairs, pairPenalty ij.1 ij.2 v w = 0 := ...
```

This is the exact formal version of H1.2. It is nontrivial because the six pairwise constraints are not independent: crossing and spacing interact globally, and proving equivalence requires showing that the chosen six-component penalty basis is complete for SATB legality.

## Hypergraph shortest-path theorem

Now define a tropical hypergraph:
- vertices = legal SATB chords over finite pitch set `P`
- hyperedges from `v` to `w` weighted by `totalPenalty6 v w`
- path cost = tropical sum / ordinary sum of edge costs, depending on your semiring presentation

The breakthrough theorem is that legal harmonizations are exactly zero-cost paths, and among all paths connecting fixed endpoints, legal ones are shortest whenever they exist.

### Theorem 2: legal progressions are exactly zero-cost paths
```lean
def ProgressionCost {n : ℕ} (σ : Fin (n+1) → Chord) : ℝ :=
  ∑ k : Fin n, totalPenalty6 (σ k.castSucc) (σ k.succ)

def LegalProgression {n : ℕ} (σ : Fin (n+1) → Chord) : Prop :=
  ∀ k : Fin n, LegalSATBStep (σ k.castSucc) (σ k.succ)

theorem legalProgression_iff_zero_cost
    {n : ℕ} (σ : Fin (n+1) → Chord)
    (hnonneg : ∀ v w, 0 ≤ totalPenalty6 v w) :
    LegalProgression σ ↔ ProgressionCost σ = 0 := ...
```

If you can make the graph finite by restricting to `P`, then prove the shortest-path form:

```lean
theorem zero_cost_path_is_shortest
    {n : ℕ} (σ : Fin (n+1) → Chord)
    (hlegal : LegalProgression σ)
    (hnonneg : ∀ v w, 0 ≤ totalPenalty6 v w) :
    ∀ τ : Fin (n+1) → Chord, σ 0 = τ 0 → σ (Fin.last n) = τ (Fin.last n) →
      ProgressionCost σ ≤ ProgressionCost τ := ...
```

This realizes H1.1 in a precise form. If the fixed-length endpoint-constrained statement is awkward, weaken to “every legal progression has cost zero and every progression has cost ≥ 0,” which already implies optimality.

## Tensor-factorization / complexity-collapse theorem

H1.3 should not be stated vaguely. Prove an exact decomposition statement showing the 4-voice penalty is controlled by, or equal to, a tropical combination of pairwise penalties, and use `tropical_factoring_decomposition` as the algebraic engine.

### Theorem 3: pairwise tropical factorization of SATB cost
```lean
theorem totalPenalty6_pairwise_factorization
    (v w : Chord) :
    totalPenalty6 v w =
      ∑ ij in unordVoicePairs, pairPenalty ij.1 ij.2 v w := rfl
```
This alone is too trivial. The real target is a dynamic-programming or tensor decomposition theorem. For instance:

```lean

theorem satb_cost_le_pairwise_tropical_convolution
    (v w : Chord) :
    totalPenalty6 v w ≤
      ∑ ij in unordVoicePairs, pairPenalty ij.1 ij.2 v w := by
  -- should sharpen to equality if definitions match
```

But the true breakthrough would be a sequence-level factorization:
```lean
theorem progression_cost_factorizes_over_pairs
    {n : ℕ} (σ : Fin (n+1) → Chord) :
    ProgressionCost σ =
      ∑ ij in unordVoicePairs,
        ∑ k : Fin n,
          pairPenalty ij.1 ij.2 (σ k.castSucc) (σ k.succ) := ...
```

Then push further: if legality constraints are pairwise complete, search over SATB progressions reduces to coupled search over six 2-voice projections.

A formal theorem in that direction could be:
```lean
theorem legal_progression_determined_by_pair_projections
    {n : ℕ} (σ : Fin (n+1) → Chord) :
    LegalProgression σ ↔
      ∀ ij ∈ unordVoicePairs,
        ∀ k : Fin n,
          pairPenalty ij.1 ij.2 (σ k.castSucc) (σ k.succ) = 0 := ...
```

This is the mathematically honest version of “factoring the 4-voice problem into coupled 2-voice subproblems.” It does not yet prove algorithmic complexity reduction, but it gives the exact structural decomposition that any later algorithm can exploit.

## Proof strategies

### Strategy A: direct zero-locus equivalence via nonnegativity and finite case analysis
Most promising for Theorems 1 and 2.
1. Define each pairwise penalty so that it is manifestly nonnegative and equals zero exactly on legality for that pair.
2. Prove a lemma for each rule family:
   - `parallelFifthPenalty_pair i j v w = 0 ↔ noParallelFifthsPair i j v w`
   - `crossingPenalty_pair i j w = 0 ↔ noCrossingPair i j w`
   - `spacingPenalty_pair i j w = 0 ↔ spacingOKPair i j w`
3. Combine them using `max_eq_zero_iff`-style lemmas and finite summation nonnegativity to get
   pairwise zero iff pairwise legal, and total zero iff all six pairwise legal.
4. Lift edgewise zero-cost equivalence to pathwise zero-cost equivalence by summing over transitions.

Why promising: Lean likes finite sums, `Fin 4`, and explicit equivalence lemmas. This route minimizes abstraction overhead and gives robust reusable infrastructure.

### Strategy B: Boolean-to-tropical encoding of legality
Most promising for conceptual novelty.
1. Define a Boolean legality oracle for each pair and show it equals a tropical expression using `bool_and_as_tropical_max`.
2. Show conjunction over all six pairs corresponds to a tropical aggregate whose zero locus is exactly legality.
3. Deduce path legality as the vanishing of a tropical path functional.

Why promising: this gives the strongest “tropical logic” interpretation and could lead to later theorems about SATB legality as a tropical circuit.

### Strategy C: tensor decomposition / pairwise projection route
Most promising for H1.3.
1. Represent the 4-voice transition cost as a 4-index tensor over pitch assignments.
2. Prove it decomposes into a tropical sum of six pairwise tensors.
3. Invoke or adapt `tropical_factoring_decomposition` to show the induced optimization over progressions factorizes over pair projections, at least at the level of objective evaluation and legality certification.

Why promising: this is where the real scalability and cross-domain significance lives. Harder than A, but potentially the field-opening contribution.
