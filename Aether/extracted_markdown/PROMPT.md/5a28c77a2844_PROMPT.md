## Assignment: Conjecture 4: Multi-Pole Chains Generate Lattice RG Maps

You are to turn the informal “multi-pole chain” renormalization picture into a rigorous Lean 4 theory with genuinely nontrivial mathematics, not a toy formalization. The core vision is this:

A chain of transfer maps indexed by poles behaves trivially at the fully microscopic level because the cocycle/composition law collapses the entire periodic cycle to the identity. But once one passes to a coarse-grained observable — block compression, block averaging, or induced action on a lower-dimensional statistic — nontrivial scale dependence can emerge. This is exactly the renormalization-group phenomenon in algebraic disguise: microscopic reversibility with macroscopic flow.

Your goal is to formalize and prove the first mathematically sharp version of that principle.

---

## Central mathematical object

Introduce a new structure encoding a compositional pole-transfer system together with a coarse-graining observable.

### New definition to introduce
Define a structure along the following lines:

```lean
structure PoleRGSystem (α β : Type*) where
  F : α → α → β → β
  comp : ∀ a b c, Function.comp (F b c) (F a b) = F a c
  id   : ∀ a, F a a = id
```

Then define a coarse-graining functional on maps or on states. One promising choice is to let the maps act on a linear or affine space and introduce a block observable:

```lean
structure BlockObservable (β γ : Type*) where
  obs : β → γ
```

and define the effective block map by transport through the observable when possible, or more concretely in the affine case by extracting a scalar statistic (fixed point, derivative, translation part, rotation parameter, energy density surrogate, etc.).

If necessary, specialize to:
- `β = ℝ`
- `F a b x = ((x - a) / (x - b))`-type Möbius-inspired maps, or
- affine transport maps `F a b x = x + φ b - φ a`,
- or a matrix model `F a b ∈ SL(2, ℝ)` / `PSL(2, ℝ)` with exact cocycle law.

The crucial novelty is not the raw cocycle law — that is easy — but the theorem that **a derived coarse-grained quantity defines a nontrivial semigroup in block scale**.

## Precise theorem targets

You must prove at least 3 substantial theorems. At least one should be abstract, at least one concrete, and at least one cross-domain.

### Theorem 1: Telescoping chain identity for periodic pole systems
Formalize the exact cocycle collapse over a periodic chain.

#### Lean target
```lean
theorem periodic_chain_collapse
  {α β : Type*} [Inhabited β]
  (S : PoleRGSystem α β) :
  ∀ (n : ℕ) (a : Fin (n+1) → α),
    (a 0 = a (Fin.last n)) →
    (List.foldl
      (fun g i => Function.comp (S.F (a ⟨i, by omega⟩) (a ⟨i+1, by omega⟩)) g)
      id
      (List.range n))
    = id
```

You may need to adjust the indexing/type signature to something cleaner using lists instead of `Fin`; that is fine. But the mathematical theorem should be:

> For any compositional pole system satisfying `F_{b,c} ∘ F_{a,b} = F_{a,c}` and `F_{a,a} = id`, the transfer around a periodic pole chain is the identity.

This theorem is not the endpoint; it is the microscopic conservation law from which all RG phenomena emerge.

### Theorem 2: Block compression theorem
Define a block map for a chain segment and prove exact reduction to an endpoint transfer.

For a list `a₀, a₁, ..., a_m`, define:
```lean
def blockTransfer (S : PoleRGSystem α β) : List α → (β → β)
```
as the composition of consecutive transfer maps along the list.

Then prove:

```lean
theorem blockTransfer_eq_endpoint
  {α β : Type*} (S : PoleRGSystem α β) :
  ∀ (l : List α) (h : l ≠ []),
    blockTransfer S l = S.F l.head! l.getLast
```

or a safer nonempty-list version.

Mathematically:

> Any finite block of consecutive poles compresses exactly to a single endpoint map.

This is the exact analog of integrating out internal degrees of freedom in a one-dimensional transfer chain.

### Theorem 3: Coarse-grained observable yields scale semigroup
This is the breakthrough theorem. You need a derived quantity that is **not** invariant under block size, even though the underlying transfer is endpoint-exact.

One clean route: specialize to a concrete family where each endpoint map has a scalar invariant depending on pole separation, then show block concatenation induces an additive or multiplicative law on that scalar.

For example, in an affine model:
```lean
def affineF (φ : α → ℝ) (a b : α) : ℝ → ℝ := fun x => x + (φ b - φ a)

def blockEnergy (φ : α → ℝ) (l : List α) : ℝ :=
  φ l.getLast - φ l.head!
```

Then prove:

```lean
theorem blockEnergy_concat
  (φ : α → ℝ) :
  ∀ {l₁ l₂ : List α}, -- suitable nonempty compatibility hypotheses
    blockEnergy φ (l₁ ++ l₂.tail) = blockEnergy φ l₁ + blockEnergy φ l₂
```

This gives a genuine semigroup law in scale under concatenation of blocks.

A stronger Möbius version would be even better:

- Define endpoint map in `PSL(2, ℝ)`.
- Extract a coarse observable such as trace, translation length, or derivative at a distinguished point.
- Prove concatenation induces a nontrivial recursion/inequality for that observable.

A possible Lean-style theorem in a concrete differentiable setting:

```lean
theorem endpoint_deriv_mul
  (φ : α → ℝ)
  (a b c : α) :
  deriv (affineF φ a c) x
    = deriv (affineF φ b c) ((affineF φ a b) x) *
      deriv (affineF φ a b) x
```

This is trivial for affine maps, so better is a fractional linear model where derivatives actually encode geometry. If full differentiability formalization is too heavy, use matrix norms/traces instead.

### Theorem 4: Cross-domain theorem connecting RG blocking to 1D statistical mechanics
You must include one theorem connecting the pole-chain formalism to another domain. The most natural is transfer matrices for the 1D Ising model.

Define a parameterized transfer matrix family `T(J,h)` and show that block concatenation corresponds to matrix multiplication, while the effective endpoint/block observable corresponds to a renormalized coupling statistic.

A realistic theorem:

```lean
theorem ising_block_partition_factorization
  (Ts : List (Matrix (Fin 2) (Fin 2) ℝ)) :
  partitionFunctionOfBlockProduct Ts =
  endpointObservable (Ts.foldl (· * ·) 1)
```

Or, more concretely:

> For nearest-neighbor 1D chains, the partition function of a concatenated block factors through the product transfer matrix, and the logarithm of the spectral radius is additive under periodic repetition.

This is the bridge:
- pole chains ↔ cocycles,
- coarse-graining ↔ transfer-matrix compression,
- RG flow ↔ semigroup law on effective couplings/free energy density.

Even a weaker formally proved theorem is acceptable if it is mathematically real and nontrivial.

## Proof strategy architecture

### Strategy A: Abstract cocycle induction on nonempty lists
Most promising for the foundational theorems.

1. Define `chainTransfer` recursively on lists.
2. Prove a recursion lemma for `a :: b :: t`.
3. Use induction on the tail to show `chainTransfer S l = S.F a₀ a_m` for any nonempty list.
4. Deduce periodic identity by substituting `a₀ = a_m`.

Why this is promising:
- It gives a robust formal backbone.
- It naturally uses induction, `rcases`, and multi-step `calc`.
- It cleanly separates abstract algebra from concrete physics interpretations.

### Strategy B: Category/groupoid viewpoint
Elegant and conceptually deeper.

1. View poles as objects of a thin groupoid and `F a b` as transport morphisms.
2. Interpret the cocycle law as functoriality of transport.
3. Show a chain collapses to the unique composite from first to last object.
4. Define coarse observables as functorial images into an additive or ordered monoid.

Why it matters:
- This reframes RG as functorial compression.
- It opens future links to holonomy, parallel transport, and gauge theory.
- Formalization may be slightly heavier, but the conceptual payoff is enormous.

### Strategy C: Concrete matrix/Möbius model with spectral observable
Most revolutionary if feasible.

1. Represent `F a b` by explicit `SL(2, ℝ)` or affine matrices satisfying exact cocycle law.
2. Define block effective coupling from matrix trace, spectral radius, or projective derivative.
3. Prove exact endpoint reduction at matrix level.
4. Prove nontrivial scale law or monotonicity/convexity for the derived observable.

Why this could be breakthrough:
- It connects renormalization, projective geometry, and dynamical systems.
- It produces a computational object suitable for `demo.py`.
- It gives a direct bridge to transfer matrices in statistical mechanics.

Recommended order:
- First complete Strategy A abstractly.
- Then instantiate Strategy C or an affine/matrix simplification.
- Finally add the Ising/transfer-matrix cross-domain theorem.

## Cross-domain connections you should explicitly develop

### 1. Renormalization group in statistical mechanics
A chain of exact transfer maps can be microscopically trivial over a closed loop yet induce nontrivial effective couplings on coarse observables. This mirrors:
- decimation,
- block-spin RG,
- transfer-matrix compression,
- free-energy density flow.

### 2. Groupoids and parallel transport
The law `F_{b,c} ∘ F_{a,b} = F_{a,c}` is a discrete flat connection. Periodic collapse is zero holonomy. Coarse-graining then asks:
- which observables remain flat?
- which induced observables develop effective flow after projection?
This is a discrete analog of gauge reduction and emergent curvature after quotienting.

### 3. Dynamical systems
Endpoint maps may be trivial on full state space but nontrivial on derived observables:
- derivative cocycles,
- Lyapunov exponents,
- rotation numbers,
- projective actions.
This gives a formal path from exact algebraic cocycles to emergent scale-dependent dynamics.

### 4. Information theory / computation
Block compression of exact compositional systems resembles:
- finite-state transducer minimization,
- hidden Markov coarse-graining,
- sufficient statistics under composition.
A future theorem could characterize which observables preserve semigroup structure under blocking.
