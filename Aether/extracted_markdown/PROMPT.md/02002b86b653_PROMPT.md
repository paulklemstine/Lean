# Research Direction: Tropical Carathéodory Compression

## Core theorem target

The conjecture as written with the binary operation
`fun i => min (a + x i) (b + y i)`
is really pointing toward the min-plus tropical convex hull generated by arbitrary finite tropical combinations. The right theorem to formalize is the finite-support compression principle:

> **Theorem (Tropical Carathéodory Compression, min-plus form).**  
> Let `S : Finset (Fin n → ℝ)` and let `z : Fin n → ℝ`. Assume `z` lies in the tropical convex hull of `S`, meaning there exists a finite family of tropical weights on points of `S` such that for every coordinate `i`,
> \[
> z(i)=\inf_{x\in S}(w_x+x(i)),
> \]
> with only finitely many relevant `w_x`. Then there exists a subset `T ⊆ S` with `T.card ≤ n+1` such that `z` already lies in the tropical convex hull of `T`.

This is the theorem that would genuinely matter: it says tropical convex generation admits **dimension-bounded witnesses**, exactly the phenomenon needed for tropical Helly, tropical LP basis theory, and compact infeasibility certificates.

If the existing catalog already defines a binary tropical segment closure rather than arbitrary finite tropical combinations, prove first the equivalence between:
1. closure under binary tropical convex combinations, and
2. finite tropical inf-combinations with additive shifts.

That equivalence is itself a valuable formal theorem and should be built as a reusable API lemma.

## Precise Lean 4 target

You may need to define a tropical convex hull operator for finite subsets first. A good formal target is:

```lean
def TropComb {n : ℕ} (w : α → ℝ) (v : α → (Fin n → ℝ)) : Fin n → ℝ :=
  fun i => sInf (Set.range fun a => w a + v a i)

def IsTropConvexCombinationOf {n : ℕ} (S : Finset (Fin n → ℝ)) (z : Fin n → ℝ) : Prop :=
  ∃ (α : Type) [Fintype α] (v : α → (Fin n → ℝ)) (w : α → ℝ),
    (∀ a, v a ∈ S) ∧
    z = fun i => Finset.inf' (Finset.univ.image fun a => w a + v a i) ?h

def tropConvHull {n : ℕ} (S : Finset (Fin n → ℝ)) : Set (Fin n → ℝ) :=
  {z | IsTropConvexCombinationOf S z}
```

Then the theorem statement should look like:

```lean
theorem tropical_carathéodory_compression
    {n : ℕ} (S : Finset (Fin n → ℝ)) {z : Fin n → ℝ}
    (hz : z ∈ tropConvHull S) :
    ∃ T : Finset (Fin n → ℝ),
      T ⊆ S ∧
      T.card ≤ n + 1 ∧
      z ∈ tropConvHull T
```

## Suggested supporting definitions and lemmas

You should aim to build a robust API around these facts:

1. **Finite-support tropical combination lemma**  
   Every element of `tropConvHull S` can be represented by a weight function on `S` itself, not on an auxiliary finite type.

2. **Normalization lemma**  
   Tropical combinations are invariant under adding a common constant to all weights and subtracting it from the output, or under fixing one active coordinate/weight normalization. This often removes one degree of freedom.

3. **Active set lemma**  
   For a representation
   \[
   z(i)=\min_{x\in S}(w_x+x(i)),
   \]
   for each coordinate `i` there exists at least one active generator `x_i ∈ S` attaining the minimum.

4. **Coordinate witness compression lemma**  
   If one selects one active generator per coordinate, then the union of these generators plus possibly one normalization anchor has size at most `n+1`, and already generates `z`.

5. **Binary closure vs finite combination equivalence**  
   If your current hull notion is inductively generated by binary combinations, prove it agrees with the finite min-plus combination hull on finite sets.

This supporting API will likely be more valuable long-term than the main theorem alone.

## Proof strategies

### Strategy A: active-coordinate compression via support selection
This is the most promising route for Lean.

**Idea:** Start from a finite tropical representation
\[
z(i)=\min_{x\in S}(w_x+x(i)).
\]
For each coordinate `i : Fin n`, choose one generator `x_i` attaining the minimum. Let `T₀` be the set of chosen generators. Then `|T₀| ≤ n`. Show that using only `T₀` may already recover all coordinates of `z`; if a normalization or global offset witness is needed, adjoin one more point to obtain `|T| ≤ n+1`.

**Steps:**
1. Prove attainment of minima because `S` is finite.
2. Choose active witnesses coordinatewise using `Finset.exists_min_image`.
3. Show that for each coordinate `i`, the restricted infimum over the selected witnesses still equals `z(i)`.
4. Package the selected witnesses into a sub-`Finset` and conclude.

**Why promising:** It is combinatorial, finitary, and aligns with Lean’s strengths on `Finset`, `card`, `image`, and pointwise equality of functions on `Fin n`. It avoids heavy topological or polyhedral machinery.

---

### Strategy B: reduction to classical Carathéodory through logarithmic/epigraph lifting
This is conceptually deeper and may produce stronger downstream theorems.

**Idea:** Tropical convexity can often be encoded as ordinary convexity after lifting to an epigraph/polyhedral complex or via valuation-like transforms. Embed each tropical point into a higher-dimensional classical convex object so that tropical combinations correspond to projections of ordinary convex combinations. Then classical Carathéodory in dimension `n` or `n+1` yields the support bound.

**Steps:**
1. Construct an auxiliary polyhedral/lifted representation of tropical combinations.
2. Prove the image of a tropical hull point lies in a classical convex hull in controlled dimension.
3. Apply classical Carathéodory.
4. Pull the support set back to the tropical side.

**Why interesting:** If successful, this creates a bridge to the existing convex geometry library and sets up future formal proofs of tropical Radon and Helly via classical machinery.  
**Why less immediate:** It may require infrastructure in Mathlib for convex hulls over `ℝ` and a nontrivial equivalence theorem.

---

### Strategy C: induction on dimension using projection and lower-envelope structure
This is attractive if you want a theorem chain toward Helly.

**Idea:** Project along one coordinate, compress in dimension `n-1`, then restore the missing coordinate by tracking which generators are active on the lower envelope.

**Steps:**
1. Project `S` and `z` from `Fin (n+1)` to `Fin n`.
2. Apply the induction hypothesis to obtain a compressed witness family in lower dimension.
3. Analyze whether one additional generator is enough to recover the omitted coordinate.
4. Reassemble a witness set of size at most `(n) + 1 + 1`, then sharpen to `n+2` or better by eliminating redundancy.

**Why useful:** It mirrors geometric intuition and may naturally connect to tropical hyperplane arrangements.  
**Why risky:** The bookkeeping is harder, and obtaining the sharp `n+1` bound may require a secondary pruning argument.

**Recommendation:** Pursue **Strategy A** first. It is the most Lean-native and likely gives the sharp theorem with the least infrastructure.

## Cross-domain connections you should exploit

### 1. Idempotent analysis / semiring linear algebra
Tropical convex hulls are the idempotent analog of linear span. A Carathéodory theorem here says finite-dimensional idempotent linearity has sparse generators. This is the semiring counterpart of basis sparsity.

### 2. Graph algorithms and shortest paths
The expression
\[
z(i)=\min_x(w_x+x(i))
\]
is a lower-envelope / shortest-path style formula. Compression to `n+1` witnesses suggests a finite certificate phenomenon analogous to:
- shortest paths using simple paths,
- negative cycle infeasibility certificates,
- Bellman-Ford witness extraction.

This directly links your second future direction on minimal infeasible tropical systems.

### 3. Optimization and LP basis theory
Classical LP vertices are determined by active constraints. Tropical Carathéodory would imply tropical optima admit small active witness sets. This is the exact structural theorem needed to define a **tropical basic feasible solution**.

### 4. Helly/Radon/Tverberg program
Once compression is formalized, you can attack:
- tropical Radon partitions from support compression,
- tropical Helly numbers for halfspaces,
- sparse infeasibility certificates,
- eventually tropical Tverberg-type partition phenomena.

### 5. Formal verification / certified optimization
A small witness set is exactly what proof-producing solvers need. In Lean, this means optimization certificates can be checked from tiny subsets rather than the whole instance.
