## EXACT PROOF STRATEGY TO PURSUE

Use multiple proof pathways; do not rely on a single brittle route.

### Strategy A: Compact simplex + continuity + extreme value theorem
Most promising if the imported thermodynamic files already expose continuity or lower semicontinuity of `thermodynamicRate`.

1. Show `simplexCarrier` coincides with `IsProbabilityMeasure`.
2. Prove it is closed and bounded in the finite product space `SpectralPoint S → ℝ`; then infer compactness using finite-dimensional Heine–Borel facts already in Mathlib.
3. Show `thermodynamicRate ...` is continuous (or at least lower semicontinuous) on that compact set.
4. Extract a minimizer `ν`.
5. Convert the minimizing inequality into equality with `sInf (rateSet ...)` using:
   - `csInf_le` / `le_csInf` style lemmas,
   - nonemptiness and bounded-below lemmas for `rateSet`,
   - extensional rewriting between image/range formulations of the set.

Lean tactics likely useful: `classical`, `simpa`, `refine`, `constructor`, `rcases`, `obtain`, `have`, `exact`, `aesop?` only as a helper, not the whole proof.

### Strategy B: Finite enumeration and direct minimization over `Fin n`
Best if topological compactness becomes annoying.

1. Use `Fintype.equivFin` to transport `SpectralPoint S` to `Fin n`.
2. Rewrite probability measures as vectors in a closed simplex in `EuclideanSpace ℝ (Fin n)` or as functions `Fin n → ℝ`.
3. Use a finite-dimensional minimization theorem already available in Mathlib or prove a bespoke one for closed bounded subsets of `Fin n → ℝ`.
4. Pull the minimizer back along the equivalence.
5. Prove support-cardinality bounds using `Finset.univ.card`.

This route should give especially clean sparse-support estimates.

### Strategy C: Reuse catalog minimizer existence and sharpen it to extraction
Best if the catalog already contains a theorem named like `minimizer_existence` in a more general form.

1. Instantiate the general theorem to the finite-spectrum setting.
2. Prove the additional sparse support theorem using finiteness.
3. Prove the positive evidence extraction by combining:
   - prime-spectral separation from non-derivability,
   - positivity of `countermodelEvidence`,
   - minimizer existence on the restricted feasible set if necessary.
4. Package the witness into `FiniteRateMinimizer` or `SparseCountermodelCertificate`.

This route is ideal if the thermodynamic infrastructure is already formalized and you mainly need a stronger extraction layer.

/-- A **coherent closure proof semiring** is a bounded distributive lattice `S`
equipped with a closure operator `cl : S → S` satisfying extensiveness,
idempotency, and monotonicity. -/
class CoherentClosureProofSemiring (S : Type*) extends DistribLattice S, BoundedOrder S where
  cl : S → S
  cl_extensive : ∀ x : S, x ≤ cl x
  cl_idempotent : ∀ x : S, cl (cl x) = cl x
  cl_monotone : ∀ x y : S, x ≤ y → cl x ≤ cl y

namespace ThermodynamicSanov

variable {S : Type*} [CoherentClosureProofSemiring S]

abbrev cl : S → S := CoherentClosureProofSemiring.cl

def derivable (x y : S) : Prop := cl x ≤ cl y

theorem derivable_refl (x : S) : derivable x x := le_refl _

theorem derivable_trans {x y z : S} (hxy : derivable x y) (hyz : derivable y z) :
    derivable x z := le_trans hxy hyz

/-! ## Part 2: Spectral Points -/

/-- A **spectral point** of a coherent closure proof semiring is a prime filter
compatible with the closure operator. -/
structure SpectralPoint (S : Type*) [CoherentClosureProofSemiring S] where
  val : S → Prop
  val_mono : ∀ {a b : S}, a ≤ b → val a → val b
  val_top : val ⊤
  val_inf : ∀ a b : S, val (a ⊓ b) ↔ val a ∧ val b
  val_prime : ∀ a b : S, val (a ⊔ b) → val a ∨ val b
  val_cl : ∀ x : S, val (cl x) ↔ val x

/-! ## Part 3: Countermodel Defect Observable -/

/-- The **countermodel defect** observable. Returns `1` when the spectral point
separates `x` from `y`, and `0` otherwise. -/
def countermodelDefect (x y : S) (p : SpectralPoint S) : ℝ :=
  if p.val (cl x) ∧ ¬p.val (cl y) then 1 else 0

theorem countermodelDefect_nonneg (x y : S) (p : SpectralPoint S) :
    0 ≤ countermodelDefect x y p := by
  unfold countermodelDefect; split_ifs <;> norm_num

theorem countermodelDefect_le_one (x y : S) (p : SpectralPoint S) :
    countermodelDefect x y p ≤ 1 := by
  unfold countermodelDefect; split_ifs <;> norm_num

theorem derivable_implies_zero_defect (x y : S) (h : derivable x y)
    (p : SpectralPoint S) : countermodelDefect x y p = 0 := by
  unfold countermodelDefect
  rw [if_neg]
  push_neg
  exact fun hval => p.val_mono h hval

theorem countermodelDefect_eq_zero_iff (x y : S) (p : SpectralPoint S) :
    countermodelDefect x y p = 0 ↔ (p.val (cl x) → p.val (cl y)) := by
  unfold countermodelDefect
  constructor
  · intro h
    split_ifs at h with hc
    · exact absurd h one_ne_zero
    · push_neg at hc; exact hc
  · intro h
    rw [if_neg]
    push_neg; exact h

/-- The prime spectral completeness hypothesis. -/

  separation : ∀ x y : S, ¬derivable x y →
