### Definition 1: PolynomialNeuralNet (Novel Structure)
A polynomial neural network is a composition of polynomial layer maps over a field, with each layer having specified input/output dimensions.

```lean
/-- A polynomial neural network layer: a polynomial map k^d_in → k^d_out
    Bridge: connects Algebra.Polynomial to MachineLearning.NeuralNetwork -/
structure PolyLayer (k : Type*) [Field k] (d_in d_out : ℕ) where
  /-- The component polynomial functions, one per output neuron -/
  components : Fin d_out → (Fin d_in → k) → k
  /-- Each component is a polynomial in the input variables -/
  is_poly : ∀ i : Fin d_out, ∃ p : MvPolynomial (Fin d_in) k,
    ∀ x : Fin d_in → k, components i x = MvPolynomial.eval x p

/-- A deep polynomial neural network: composition of layers
    The architecture is determined by the list of layer widths -/
structure PolyNeuralNet (k : Type*) [Field k] (dims : List ℕ) where
  /-- Individual layers -/
  layers : ∀ i : Fin (dims.length - 1),
    PolyLayer k (dims.get i) (dims.get (i + 1))
  /-- Width constraint: each layer's output dimension matches the next layer's input -/
  width_chain : dims.length ≥ 2
```

### Definition 2: FeatureField (Novel Structure)
The function field generated by the outputs of a polynomial neural network, representing the "features learned" by that network.

```lean
/-- The function field of features learned by a polynomial neural network f.
    This is the field k(f(X₁,...,Xₙ)) ⊆ k(X₁,...,Xₙ).
    Bridge: connects Algebra.FieldTheory to MachineLearning.FeatureLearning -/
def featureField {k : Type*} [Field k] {n m : ℕ}
    (f : (Fin n → k) → (Fin m → k))
    (hf : ∀ i : Fin m, ∃ p : MvPolynomial (Fin n) k,
      ∀ x : Fin n → k, f x i = MvPolynomial.eval x p) :
    Subfield (FractionRing (MvPolynomial (Fin n) k)) :=
  Subfield.closure (Set.range (fun i : Fin m ↦
    (MvPolynomial.eval (fun j ↦ MvPolynomial.X j)) (Classical.choose (hf i))))
```

## PROOF STRATEGY DETAILS

### Strategy for composition_symmetry_decomposition (RECOMMENDED: Wreath Product Action)

**Step 1: Define the restriction homomorphism**
Construct `restrict : Gal(k(X)/k(f(X))) →* Gal(k(X)/k(h(X)))` by restricting automorphisms to the intermediate field k(h(X)). Prove this is a well-defined group homomorphism using `MonoidHom.mk'` and the fundamental theorem of Galois theory.

**Key Lemma**: `restrict_surjective` — The restriction map is surjective because every automorphism of k(X)/k(h(X)) extends to an automorphism of k(X)/k(f(X)) by acting trivially on k(h(X))/k(f(X)). Use `IsSplitField` and the extension theorem for automorphisms.

**Step 2: Identify the kernel**
Show `ker(restrict) = Gal(k(X)/k(h(X)))` as a subgroup of `Gal(k(X)/k(f(X)))`. This follows because an automorphism fixes k(h(X)) pointwise iff it lies in `Gal(k(X)/k(h(X)))`.

**Step 3: Construct the semidirect product action**
Define the action of `Gal(k(X)/k(h(X)))` on `Gal(k(h(X))/k(f(X)))` by conjugation within `Gal(k(X)/k(f(X)))`. Prove this satisfies the semidirect product axioms using `SemidirectProduct.mk` and `MonoidHom.ext`.

**Step 4: Embed via the recognition theorem**
Apply the group recognition theorem: if `N ⊴ G` with complement `H` and `N ∩ H = {1}`, then `G ≅ N ⋊ H`. Here `N = Gal(k(X)/k(h(X)))` and `H = Gal(k(h(X))/k(f(X)))` (embedded via the section of `restrict`).

**Step 5: Verify the embedding preserves the composition structure**
