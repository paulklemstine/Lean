# Effect Algebras: Axiomatic Foundation for Quantum Probability

Effect algebras (Foulis–Bennett, 1994) provide the minimal algebraic
structure for quantum probability theory. They generalize Boolean algebras
by replacing total addition with *partial* addition, capturing complementarity
of quantum observables. This formalization addresses Hilbert's 6th problem
by providing a rigorous axiomatic foundation that subsumes Kolmogorov's
classical probability framework as a special case.

## Main definitions

* `EffectAlgebra` — A set with partial addition, zero, one, and orthocomplement
* `EffectAlgebra.ele` — The natural partial order: a ≤ b iff ∃ c, a ⊕ c = b

## Main results

* `EffectAlgebra.ortho_involutive` — Orthocomplement is an involution
* `EffectAlgebra.cancel_left` — Left cancellation law for partial addition
* `EffectAlgebra.ele_antisymm` — The natural order is antisymmetric
* `EffectAlgebra.bot_le'` — 0 is the bottom element
* `EffectAlgebra.le_top'` — 1 is the top element

## References

* D.J. Foulis, M.K. Bennett, "Effect algebras and unsharp quantum logics",
  Found. Phys. 24 (1994), 1331–1352.
-/

import Mathlib

/-! ## Effect Algebra: Definition

An effect algebra is a set E with a distinguished zero `ezero`, unit `eone`,
partial binary operation `oplus` (defined when elements are "orthogonal"),
and orthocomplement `ortho`. The partial addition is commutative, associative
(when defined), has `ezero` as identity, and every element has a unique
orthocomplement summing to `eone`.
-/

/-- An effect algebra: the algebraic foundation of quantum probability.
The partial operation `oplus a b` returns `some c` when `a` and `b` are
orthogonal (can be jointly measured), and `none` otherwise. -/
class EffectAlgebra (E : Type*) where
  /-- Partial addition of effects. -/
  oplus : E → E → Option E
  /-- The zero effect (impossible event). -/
  ezero : E
  /-- The unit effect (certain event). -/
  eone : E
  /-- Orthocomplement: the unique element such that a ⊕ a⊥ = 1. -/
  ortho : E → E
  /-- Commutativity of partial addition. -/
  oplus_comm : ∀ a b : E, oplus a b = oplus b a
  /-- Associativity: if a ⊕ b and (a ⊕ b) ⊕ c are defined,
      then b ⊕ c is defined and a ⊕ (b ⊕ c) = (a ⊕ b) ⊕ c. -/
  oplus_assoc : ∀ a b c d e : E,
    oplus a b = some d → oplus d c = some e →
    ∃ f, oplus b c = some f ∧ oplus a f = some e
  /-- Zero is a right identity for ⊕. -/
  oplus_ezero : ∀ a : E, oplus a ezero = some a
  /-- Orthocomplement law: a ⊕ a⊥ = 1. -/
  oplus_ortho : ∀ a : E, oplus a (ortho a) = some eone
  /-- Zero-one law: if a ⊕ 1 is defined, then a = 0. -/
  oplus_eone_eq_ezero : ∀ a b : E, oplus a eone = some b → a = ezero
  /-- Uniqueness of orthocomplement: if a ⊕ b = 1 then b = ortho(a). -/
  ortho_unique : ∀ a b : E, oplus a b = some eone → b = ortho a

namespace EffectAlgebra

variable {E : Type*} [EffectAlgebra E]

scoped infixl:65 " ⊕ₑ " => EffectAlgebra.oplus

/-! ### Basic lemmas -/

lemma ezero_oplus (a : E) : ezero ⊕ₑ a = some a := by
  rw [oplus_comm]; exact oplus_ezero a

lemma ortho_oplus (a : E) : (ortho a) ⊕ₑ a = some eone := by
  rw [oplus_comm]; exact oplus_ortho a

/-! ## Theorem 1: Left cancellation law

**PEGB**:
- **P**roof: Use associativity with ortho(d) and uniqueness of orthocomplement.
- **E**xample: In [0,1] ⊂ ℝ, if a + b = a + c ≤ 1, then b = c.
- **G**eneralization: Cancellation in any effect monoid.
- **B**oundary: Fails in partial semigroups without unique orthocomplement.
-/

/-
Left cancellation: if a ⊕ b and a ⊕ c are both defined and equal, then b = c.
-/
theorem cancel_left (a b c d : E)
    (h1 : a ⊕ₑ b = some d) (h2 : a ⊕ₑ c = some d) : b = c := by
  obtain ⟨ f, hf1, hf2 ⟩ := ( ‹EffectAlgebra E›.oplus_assoc a b ( ‹EffectAlgebra E›.ortho d ) d ( ‹EffectAlgebra E›.eone ) ) h1 ( ‹EffectAlgebra E›.oplus_ortho d );
  obtain ⟨ g, hg1, hg2 ⟩ := ( ‹EffectAlgebra E›.oplus_assoc a c ( ‹EffectAlgebra E›.ortho d ) d ( ‹EffectAlgebra E›.eone ) ) h2 ( ‹EffectAlgebra E›.oplus_ortho d );
  obtain ⟨ h_val, hh1, hh2 ⟩ := ( ‹EffectAlgebra E›.oplus_assoc b ( ‹EffectAlgebra E›.ortho d ) a f ( ‹EffectAlgebra E›.eone ) ) hf1 ( by
    have := ‹EffectAlgebra E›.oplus_comm a f; aesop; )
  obtain ⟨ k_val, hk1, hk2 ⟩ := ( ‹EffectAlgebra E›.oplus_assoc c ( ‹EffectAlgebra E›.ortho d ) a g ( ‹EffectAlgebra E›.eone ) ) hg1 ( by
    exact ‹EffectAlgebra E›.oplus_comm _ _ ▸ hg2 )
  generalize_proofs at *;
  have h_eq : h_val = k_val := by
    grind;
  have h_eq : ‹EffectAlgebra E›.ortho b = h_val ∧ ‹EffectAlgebra E›.ortho c = h_val := by
    exact ⟨ by simpa [ h_eq ] using ( ‹EffectAlgebra E›.ortho_unique b h_val hh2 ).symm, by simpa [ h_eq ] using ( ‹EffectAlgebra E›.ortho_unique c h_val ( by simpa [ h_eq ] using hk2 ) ).symm ⟩;
  have h_eq : ‹EffectAlgebra E›.ortho (‹EffectAlgebra E›.ortho b) = b ∧ ‹EffectAlgebra E›.ortho (‹EffectAlgebra E›.ortho c) = c := by
    grind +suggestions;
  grind

**PEGB**:
- **P**roof: From a ⊕ ortho(a) = eone by commutativity ortho(a) ⊕ a = eone,
  and by uniqueness of orthocomplement a = ortho(ortho(a)).
- **E**xample: In Bool, not (not b) = b.
- **G**eneralization: In any algebra with unique complements, the complement
  operation is an involution.
- **B**oundary: Fails without uniqueness — multiple complements break involutivity.
-/

/-
The orthocomplement is an involution: ortho(ortho(a)) = a.
-/
theorem ortho_involutive (a : E) : ortho (ortho a) = a := by
  rename_i h;
  cases h;
  grind

/-! ## Theorem 3: ortho(eone) = ezero and ortho(ezero) = eone -/

/-
ortho(eone) = ezero.
-/

ortho(ezero) = eone.
-/
theorem ortho_ezero : ortho (ezero : E) = eone := by

  cases h;
  grind +ring

/-! ## Theorem 4: Natural partial order

**PEGB**:
- **P**roof: Define a ≤ b iff ∃ c, a ⊕ c = some b. Show reflexivity,
  antisymmetry, transitivity, with ezero as bottom and eone as top.
- **E**xample: In [0,1], a ≤ b iff b - a ≥ 0 and b ≤ 1.
- **G**eneralization: Any cancellative partial commutative monoid admits such an order.
- **B**oundary: Without cancellation, antisymmetry fails.
-/

/-- Natural partial order: a ≤ b iff ∃ c, a ⊕ c = some b. -/
def ele (a b : E) : Prop := ∃ c, a ⊕ₑ c = some b

/-- 0 is the bottom element. -/
theorem bot_le' (a : E) : ele ezero a :=
  ⟨a, ezero_oplus a⟩

/-- Every element is ≤ 1. -/
theorem le_top' (a : E) : ele a eone :=
  ⟨ortho a, oplus_ortho a⟩

/-- Reflexivity of the natural order. -/
theorem ele_refl (a : E) : ele a a :=
  ⟨ezero, oplus_ezero a⟩

/-
If a ⊕ b = ezero, then a = ezero.
-/
theorem oplus_eq_ezero (a b : E)
    (h : a ⊕ₑ b = some ezero) : a = ezero := by
  have := ‹EffectAlgebra E›.oplus_assoc a b ( ‹EffectAlgebra E›.ortho ( ‹EffectAlgebra E›.ezero ) ) ( ‹EffectAlgebra E›.ezero ) ( ‹EffectAlgebra E›.eone ) ; simp_all +decide;
  grind +suggestions

/-
Antisymmetry of the natural order.
-/
theorem ele_antisymm (a b : E)
    (h1 : ele a b) (h2 : ele b a) : a = b := by
  cases' h1 with c1 hc1
  cases' h2 with c2 hc2;
  rename_i h;
  obtain ⟨ f, hf1, hf2 ⟩ := h.oplus_assoc a c1 c2 b a hc1 hc2;
  -- By oplus_eq_ezero: c1 ⊕ c2 = some ezero. So c1 = ezero.
  have hc1_zero : c1 = h.ezero := by
    have hc1_zero : f = h.ezero := by
      have := h.cancel_left a f h.ezero a hf2 ( by simp +decide [ h.oplus_ezero ] ) ; aesop;
    exact h.oplus_eq_ezero c1 c2 ( by aesop );
  have := h.oplus_ezero a; aesop;

/-
Transitivity of the natural order.
-/
theorem ele_trans (a b c : E)
    (h1 : ele a b) (h2 : ele b c) : ele a c := by
  obtain ⟨ c₁, hc₁ ⟩ := h1
  obtain ⟨ c₂, hc₂ ⟩ := h2
  obtain ⟨ f, hf₁, hf₂ ⟩ := (‹EffectAlgebra E›.oplus_assoc a c₁ c₂ b c hc₁ hc₂)
  use f
