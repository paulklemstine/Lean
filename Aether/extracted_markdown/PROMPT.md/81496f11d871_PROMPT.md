**Mode:** `prove`

Do **not** spend the cycle merely enumerating irreducible characters of `S_3`, `S_4`, `S_5`. That is useful infrastructure, but it is not the breakthrough. The real target is to formalize **character-theoretic rigidity phenomena** for symmetric groups and use them to bridge finite-group representation theory with combinatorics, spectral graph theory, and computational mathematics.

Your mission is to build a Lean 4 development where explicit character tables for small symmetric groups are only the **base cases** for deeper theorems about orthogonality, class functions, and permutation representations. If Burnside’s `p^a q^b` theorem is too distant from current Mathlib infrastructure, do not die on that hill first. ## Core Breakthrough Goal

Formalize and prove that for small symmetric groups, the character table is not just computed but **uniquely certified** by general structural principles:

1. **Row orthogonality** and **column orthogonality** of irreducible characters.
2. **Permutation-character decomposition** for natural actions of `S_n`.
3. **Character-theoretic reconstruction**: a class function satisfying integrality, degree constraints, and orthogonality relations must coincide with a genuine irreducible character.
4. **Spectral cross-domain theorem**: the character of the permutation representation controls eigenvalue multiplicities of the conjugacy-class averaging operator / Cayley graph adjacency operator.

This opens a path toward machine-verified finite representation theory where tables are consequences of structure, not ad hoc lookup.

### Theorem 1: Character of the natural permutation representation of `S_n`

For `n ≥ 1`, the trace of the permutation representation of `Equiv.Perm (Fin n)` on `Fin n → K` equals the number of fixed points.

A Lean-shape target:

```lean
theorem char_perm_rep_eq_fixedPoints
  (K : Type*) [Field K] [CharZero K]
  (n : ℕ) :
  ∀ σ : Equiv.Perm (Fin n),
    LinearMap.trace K (Fin n → K) (permLinearRep K σ) =
      (Fintype.card {i : Fin n // σ i = i} : K)
```

You may need to define:

```lean
def permLinearRep (K : Type*) [Field K] {n : ℕ} (σ : Equiv.Perm (Fin n)) :
    Module.End K (Fin n → K) := ...
```

This is not trivial: the theorem turns combinatorial fixed-point counting into a representation-theoretic trace identity. It is the gateway to every permutation-character computation for `S_n`.

### Theorem 2: Decomposition of the natural permutation character into trivial + standard

For `n ≥ 2`, the permutation representation of `S_n` on `K^n` splits as the direct sum of the trivial representation and the standard subrepresentation of codimension 1. On characters:

```lean
theorem permutation_character_decomposes
  (K : Type*) [Field K] [CharZero K]
  (n : ℕ) (hn : 2 ≤ n) :
  ∃ χtriv χstd χperm : ClassFunction (Equiv.Perm (Fin n)) K,
    IsTrivialCharacter χtriv ∧
    IsStandardCharacter n χstd ∧
    χperm = χtriv + χstd ∧
    ∀ σ, χperm σ =
      (Fintype.card {i : Fin n // σ i = i} : K)
```

You will likely define `ClassFunction`, `IsTrivialCharacter`, and `IsStandardCharacter` if Mathlib lacks the exact notions. This theorem is the conceptual source of the partition `(n-1,1)` representation and should be used concretely for `n = 3,4,5`.

### Theorem 3: Orthogonality-certified irreducibility of the standard character

For `n ≥ 3`, the standard character has inner product 1 with itself, hence is irreducible:

```lean
theorem standard_character_irreducible
  (K : Type*) [IsROrC K]
  (n : ℕ) (hn : 3 ≤ n) :
  characterInner
      (standardCharacter K n)
      (standardCharacter K n) = 1
```

and consequently

```lean
theorem standard_character_is_irreducible
  (K : Type*) [IsROrC K]
  (n : ℕ) (hn : 3 ≤ n) :
  IsIrreducibleCharacter (standardCharacter K n)
```

This should be proved by a nontrivial calculation over conjugacy classes / cycle types, not by brute-force enumeration. For `n = 3,4,5`, this theorem should instantiate to explicit certified irreducibles in the table.

### Theorem 4: Character-theoretic reconstruction for `S_3` or `S_4`

Pick at least one small symmetric group and prove a uniqueness theorem:

```lean
theorem s3_character_rigidity
  (χ : ClassFunction (Equiv.Perm (Fin 3)) ℂ) :
  satisfiesOrthogonality χ ∧
  integralValuesOnClasses χ ∧
  degreeConstraintS3 χ
  → χ = trivialCharacter ∨ χ = signCharacter ∨ χ = standardCharacter ℂ 3
```

Or analogously for `S_4`, where you characterize one specific irreducible by degree and orthogonality data. This is a genuinely new formal statement: it says the table is **forced** by structure.

### Theorem 5: Cross-domain spectral theorem

Connect character theory to graph spectra. For a conjugacy-invariant generating multiset `C ⊆ S_n`, define the averaging operator on the permutation representation and prove its trace/eigenvalue formula.

A Lean-shape target:

```lean
theorem trace_class_sum_operator_eq_character_sum
  (K : Type*) [Field K] [CharZero K]
  (n : ℕ) (C : Finset (Equiv.Perm (Fin n))) :
  LinearMap.trace K (Fin n → K) (classSumOperator K C) =
    ∑ σ in C, (Fintype.card {i : Fin n // σ i = i} : K)
```

Then strengthen toward decomposition into trivial and standard pieces. This is the bridge to spectral graph theory: for transposition-generated Cayley graphs, the standard representation gives nontrivial eigenvalues.

**Application keywords:** spectral graph theory, random walks on groups, quantum symmetry, certified computation, class functions, Fourier analysis on finite groups.

## Proof strategy architecture

You must present and pursue at least 2–3 proof routes. Do not rely on a single brittle implementation.

### Strategy A: Direct linear representation + trace calculation
1. Define the permutation representation `permLinearRep`.
2. Prove that basis vectors are permuted by `σ`.
3. Compute the trace by identifying diagonal entries with fixed points.
4. Deduce the permutation character formula.
5. Extract the standard representation as the kernel of the summation map.

**Why promising:** This route is close to Mathlib’s linear algebra strengths and avoids requiring full semisimplicity infrastructure at the outset.

### Strategy B: Class-function inner product and orthogonality
1. Define class functions and the Hermitian inner product on them.
2. For `S_3`, `S_4`, `S_5`, encode conjugacy classes by cycle type.
3. Compute inner products using class sizes and fixed-point formulas.
4. Show that candidate rows are orthonormal and dimension-squared sums match `|G|`.
5. Conclude completeness / irreducibility / rigidity.

**Why promising:** This is the mathematically deepest route. It turns explicit tables into theorems from general principles and sets up future Burnside and Frobenius work.

### Strategy C: Combinatorial-spectral route
1. Define class-sum / averaging operators associated to conjugacy classes.
2. Show traces are character sums.
3. Use decomposition of permutation modules to derive spectral multiplicities.
4. Verify on transposition and 3-cycle classes for `S_4` or `S_5`.

**Why promising:** This creates the cross-domain theorem required by the assignment and opens a bridge to expander theory, random walks, and quantum computation.

**Recommended order:** A → B → C.  
A builds infrastructure. B gives the conceptual breakthrough. C delivers the “I never thought of that connection” payoff.
