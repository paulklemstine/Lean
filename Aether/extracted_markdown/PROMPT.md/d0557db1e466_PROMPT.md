## Precise theorem target

Work in a finitely generated idempotent semiring-semimodule setting with an order induced by idempotent addition. You may need to define a typeclass expressing the order-theoretic and finite-generation hypotheses needed for the proofs.

### Core mathematical statement

Let:
- `S` be an idempotent semiring,
- `M` be a finitely generated `S`-semimodule equipped with its natural canonical order,
- `c : M → M` be a closure operator, i.e. monotone, extensive, idempotent,
- `E : M → S` be a monotone linear observable,
- `defect : M → S` measure the closure gap from `x` to `c x`, with `defect x = 0` iff `c x = x`,
- `β : S`.

Define the tropical free-energy functional
\[
F_{c,E,\beta}(x) := defect(x) \oplus (\beta \otimes E(x)).
\]

Then prove a theorem package of the following form:

1. **Variational fixed-point characterization**  
   For every `x : M`, `x` is closed iff it minimizes `F` on its closure fiber / closure class in the precise sense:
   \[
   c(x)=x \iff \forall y,\; c(y)=c(x)\to F(x)\le F(y),
   \]
   under admissibility hypotheses on `E` and `β`.

2. **Closure–equilibrium correspondence**  
   The poset of closed states is order anti-/iso-equivalent (choose the mathematically correct direction after formal development) to a poset of tropical equilibrium spectra defined by minimizing free-energy levels.

3. **Minimal equilibrium presentation**  
   Under finite generation, each closed state admits a certified minimal equilibrium presentation, and the support size of a minimal presentation equals or is sharply bounded by a tropical rank-like invariant of the entropy semimodule generated by closure defects.

4. **Certified finite descent**  
   Define an iterative descent operator `step : M → M` driven by free-energy improvement. Prove finite termination to `c x`, and extract an explicit bound in terms of a finite height / rank / support complexity invariant.

### Main theorem candidate

```lean
theorem isClosed_iff_fiberwise_freeEnergy_min
    {S M : Type _}
    [Preorder M]
    [CanonicallyOrderedCommSemiring S]
    [OrderBot S]
    [Preorder M]
    (c : M → M)
    (defect E : M → S)
    (β : S)
    (hc : IsClosureOperator c)
    (hdef : ∀ x, defect x = ⊥ ↔ c x = x)
    (hmin : ∀ x y, c y = c x → defect (c x) ≤ defect y)
    :
    ∀ x, c x = x ↔ ∀ y, c y = c x → freeEnergy defect E β x ≤ freeEnergy defect E β y
```

A more realistic and probably easier theorem is the **forward implication first**, then strengthen to iff under an admissibility condition on `E` such as closure-fiber monotonicity or constancy:

```lean
theorem closed_minimizes_freeEnergy_on_fiber
    ...
    (hE : ∀ x y, c y = c x → E (c x) ≤ E y) :
    ∀ x, c x = x → ∀ y, c y = c x → freeEnergy defect E β x ≤ freeEnergy defect E β y
```

Then derive:

```lean
theorem minimizes_freeEnergy_on_fiber_of_not_closed_contra
    ...
    (hstrict : ∀ x, c x ≠ x → defect (c x) < defect x) :
    ∀ x, (∀ y, c y = c x → freeEnergy defect E β x ≤ freeEnergy defect E β y) → c x = x
```

### Descent and termination theorem candidate

```lean
def closureDescent (c : M → M) : M → M := c

theorem closureDescent_terminates_in_one_step
    {M : Type _} [Preorder M]
    (c : M → M) (hc : IsClosureOperator c) :
    ∀ x, closureDescent c (closureDescent c x) = closureDescent c x
```

This is too trivial if `step = c`. The real opportunity is to define a **local free-energy descent** operator that only partially applies generators / basis moves and show it reaches `c x` in finitely many steps. That theorem is much more interesting:

```lean
theorem exists_finite_freeEnergy_descent_to_closure
    {M : Type _} [Fintype ι] [Preorder M]
    (gens : ι → M → M)
    (step : M → M)
    (c : M → M)
    ...
    :
    ∀ x, ∃ n ≤ bound x, Nat.iterate step n x = c x
```

The bound should ideally depend on a finite height or support complexity:
- height of the interval `[x, c x]`,
- cardinality of an antichain basis,
- tropical rank / basis size,
- threshold-gap minimality invariant.

## Proof architecture: 3 viable strategies

### Strategy A: Fiberwise order-theoretic minimization
**Most promising for the first Lean milestone.**

1. **Define the closure fiber**
   \[
   \mathrm{Fib}(z) = \{x \mid c(x)=z\}.
   \]
   Show `c x` is the unique closed point in the fiber of `x`.

2. **Choose defect so closed points are exactly zero-defect**
   Prove `defect (c x) = 0` and `defect y ≥ 0` for all `y` in the fiber. If `E` is closure-fiber monotone or constant on fibers, then:
   \[
   F(c x) \le F(y)
   \]
   for every `y` in the fiber.

3. **Converse via strict positivity of defect**
   If `x` minimizes free energy in its own fiber but is not closed, compare `x` with `c x`; strict defect decrease yields contradiction.

Why this is promising:
- It uses only closure axioms plus a carefully designed defect.
- It should formalize cleanly with existing order-theoretic infrastructure.
- It gives the core theorem fast, after which the spectral and complexity layers can be built.

---

### Strategy B: Galois/Stone duality route through fixpoint lattices
**Most visionary for the anti-equivalence theorem.**

1. Show the closed states of `c` form a complete or finite distributive sublattice under suitable hypotheses.

2. Define equilibrium spectra as principal minimizer filters / lower sets of `F`, or as characters on the idempotent entropy semimodule.

3. Construct an order-(anti)-equivalence between:
   - closed-state lattice,
   - equilibrium spectrum lattice.

This can leverage ideas from temporal Stone duality and fixpoint semantics:
- closed states as semantic theories,
- equilibrium spectra as thermodynamic models / valuations.

Why it matters:
- This is the conceptual leap from “a minimization theorem” to “a new duality theory.”
- It opens semantic applications in learning and logic.

Risk:
- heavier categorical/lattice formalization,
- likely needs finite distributivity assumptions.

---

### Strategy C: Generator-level descent and certified complexity
**Best for the algorithmic breakthrough.**

1. Present `M` by a finite generating family and define local update operators corresponding to closure generators or transfer actions.

2. Show each update weakly decreases free energy and strictly decreases a well-founded complexity measure whenever not closed.

3. Use finite generation to extract:
   - a termination bound,
   - a support-size bound for minimal equilibria,
   - a certified realization complexity theorem.

This is the strategy that best connects to:
- `certified_generalization_from_closure_nerve_descent`,
- `basis_with_threshold_gap_is_minimal_authorized`.

Why it matters:
- It turns the theorem into an executable certified algorithm.
- It provides the “thermodynamic descent computes closure” slogan with proof.

Risk:
- requires more setup around presentations, supports, and complexity measures.

## Concrete definitions likely to work

### 1. Closure defect
Do not overcommit early to a metric-like “distance.” In idempotent settings, the right defect may simply be an order residual or gap witness.

Good first formal options:
- `defect x = 0` if `c x = x`, else a positive witness from a finite height measure;
- `defect x = rankGap x (c x)`;
- `defect x = supportCost (c x) - supportCost x` in a tropicalized ordered codomain;
- a residual `ρ x` with `ρ x = ⊥ ↔ x = c x`.

The key is not geometric elegance but:
- zero iff closed,
- monotone decrease under descent,
- compatibility with finite generation.

### 2. Free energy
In tropical algebra, “energy plus entropy” often means `⊕` of two costs, but depending on convention this may correspond to `inf`, `sup`, `min`, or addition in the ambient ordered semiring. Pick the abstraction that matches Mathlib best.

You may need two variants:
- **order-theoretic free energy** for theorem proving,
- **semiring free energy** for applications.

### 3. Equilibrium spectrum
A workable first definition:
- an equilibrium spectrum point is a closed state together with a minimizing certificate,
or
- a prime lower set / character of the entropy semimodule determined by a closed state.

Start concrete, then abstract.

## Cross-domain connections you should make explicit in the file and theorem comments

1. **Thermodynamics ↔ closure semantics**  
   Closed states become zero-entropy equilibria; closure descent becomes free-energy descent.

2. **Tropical geometry ↔ learning theory**  
   Closure classes define tropical cells/fibers; minimizers select canonical representatives analogous to tropical barycenters.

3. **Order theory ↔ statistical mechanics**  
   Entropy defect is not Shannon entropy but an order-theoretic irreversibility measure. This is precisely what makes the theory non-Archimedean.

4. **Transfer operators ↔ semantic propagation**  
   Linear observables induced by idempotent transfer operators act like energy landscapes over semantic states.

5. **Stone/Galois duality ↔ equilibrium spectra**  
   Closed theories/states correspond to equilibrium spectra, suggesting a semantic statistical mechanics of logical closure.

6. **Complexity theory ↔ minimal realization**  
   Minimal equilibrium support is a thermodynamic notion of model compression; tropical rank becomes a realization complexity invariant.

These are not decorative. They determine how you define the objects so the theorem becomes reusable by later projects in EML, semantics, and tropical algorithms.
