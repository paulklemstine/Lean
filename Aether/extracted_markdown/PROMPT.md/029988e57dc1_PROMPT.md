# Central Breakthrough Target

## Theorem (Tropical Radon over `ℚ`)

For every natural number `n` and every family of `n+2` points in tropical affine space `ℚ^n ≅ (Fin n → ℚ)`, there exist two disjoint nonempty index sets whose tropical convex hulls intersect.

A precise finite-index formulation that should be Lean-friendly is:

> Let `m := n + 2`. For every map `p : Fin m → (Fin n → ℚ)`, there exist subsets `A B : Finset (Fin m)` such that
> 1. `A.Nonempty`
> 2. `B.Nonempty`
> 3. `Disjoint A B`
> 4. `∃ z : Fin n → ℚ, z ∈ tropConvHull (p '' A) ∧ z ∈ tropConvHull (p '' B)`.

This is the right theorem because it avoids encoding a partition of all points if that becomes technically awkward; disjoint nonempty subfamilies suffice for Radon. If a stronger “covering partition” theorem is reachable, prove that too:

> `A ∪ B = Finset.univ`.

But do not let the stronger partition formulation block the core theorem.

# Why this would be a breakthrough

Classical convexity is organized by a deep chain:
**Carathéodory ⇒ Radon ⇒ Helly ⇒ Tverberg**.

Tropical convexity has many isolated analogues, but a fully formalized and structurally coherent chain in Lean is still missing. Proving tropical Radon in a reusable theorem-engineering style would do three revolutionary things:

1. **Create the missing middle link** between tropical Carathéodory compression and tropical Helly-type intersection theorems.
2. **Turn tropical convexity into a formal combinatorial platform** rather than a collection of examples.
3. **Open the road to tropical Tverberg, colorful tropical Helly, and algorithmic certificates** for infeasibility/intersection in tropical optimization.

If done cleanly, this theorem becomes the seed crystal for a new library: tropical combinatorial convexity in Mathlib style.

# Three proof architectures

## Strategy A: Derive Radon from tropical Carathéodory via “remove-one-point” compression
**Most promising if the catalog already has a strong finite tropical Carathéodory theorem.**

### Step 1
Let `S = {p 0, ..., p (n+1)}`. Form a tropical hull point `z` built from all points in a symmetric way, ideally a canonical one such as a coordinatewise minimum of suitable shifts, or a point in the tropical hull of the full family with a minimal support certificate.

### Step 2
Use tropical Carathéodory to show `z` can be represented by a strict subfamily of size at most `n+1`. Since the original family has `n+2` points, at least one point is removable without changing hull membership.

### Step 3
Compare two representations of the same `z`: one using a larger family and one using a smaller family. Extract disjoint active supports `A` and `B` whose tropical combinations coincide, yielding
`z ∈ tropConvHull(A) ∩ tropConvHull(B)`.

**Why promising:** this mirrors the classical linear-dependence proof of Radon, but replaces affine dependence by support compression. It uses your strongest existing theorem directly, so it is the shortest route to a formal breakthrough.

---

## Strategy B: Tropical linear dependence via min-plus matrix singularity
**Most promising if you can import known equivalences between tropical dependence, singular matrices, and convexity intersection.**

Encode the `n+2` points as columns of a tropical matrix `M : Matrix (Fin n) (Fin (n+2)) ℚ`. Then seek a tropical dependence among columns in the sense that a tropical linear combination attains the minimum at least twice in each row, or equivalently that an augmented matrix is tropically singular.

### Step 1
Augment points if needed to homogeneous coordinates in `ℚ^(n+1)` by appending `0`, moving from affine tropical convexity to projective tropical geometry.

### Step 2
Use a tropical dependence theorem: any `n+2` vectors in tropical projective dimension `n` are tropically dependent.

### Step 3
Convert tropical dependence into a Radon partition by splitting indices according to which coefficients realize the common tropical combination.

**Why this is deep:** this route connects convexity to tropical linear algebra, valuated matroids, and Kapranov-rank phenomena. It is mathematically richer and may generalize further to tropical Tverberg.  
**Why it may be harder:** formalizing tropical singularity and dependence in Lean could be substantial unless the catalog already has matrix infrastructure in this direction.

---

## Strategy C: Polyhedral/cell-complex proof via types and sectors
**Most promising for future Helly/Tverberg extensions.**

Tropical convex hulls admit cell decompositions governed by types: for a candidate point `z`, each coordinate records which generators are active in the minima defining `z`.

### Step 1
Study the type decomposition of `tropConvHull(S)` for `|S| = n+2`. Show that by pigeonhole/covering arguments, some type pattern forces two disjoint active supports.

### Step 2
Construct a witness point `z` where at least two disjoint support classes are simultaneously active across all coordinates.

### Step 3
Conclude `z` belongs to both hulls.

**Why this matters:** this proof is more geometric and would likely produce combinatorial data structures useful for Helly numbers, tropical halfspaces, and certified algorithms.  
**Why secondary:** likely longer to formalize than Strategy A unless the catalog already contains “types” or tropical polyhedral cell decomposition lemmas.

# Strong auxiliary lemmas to target

These are likely the true formal bottlenecks, and proving them cleanly will matter more than the headline theorem.

## Lemma 1: Finite-support tropical representation
For finite `S : Finset (Fin n → ℚ)`, every `z ∈ tropConvHull(S)` admits explicit tropical coefficients on a finite support.

Possible type shape:
```lean
theorem mem_tropConvHull_iff_exists_weights
    {n : ℕ} {S : Finset (Fin n → ℚ)} {z : Fin n → ℚ} :
    z ∈ tropConvHull (↑S : Set (Fin n → ℚ)) ↔
      ∃ w : (Fin n → ℚ) → ℚ,
        (∀ x ∉ (↑S : Set (Fin n → ℚ)), w x = 0) ∧
        ...
```
If this exact formulation is awkward, use a support-indexed version over `s : Finset α`.

## Lemma 2: Minimal-support witness exists
Among all representations of a given `z` from a finite family, there exists one with minimal support cardinality.

This may require a finite search argument on `Finset` subsets.

## Lemma 3: Non-uniqueness from oversampling
For a family of size `n+2`, some hull point has two distinct support witnesses of size `≤ n+1`.

This is the real Radon engine if derived from Carathéodory.

## Lemma 4: Support-splitting implies hull intersection
If
\[
z = \bigoplus_{i \in I} (\lambda_i \odot p_i)
  = \bigoplus_{j \in J} (\mu_j \odot p_j)
\]
with `I ∩ J = ∅`, then
`z ∈ tropConvHull({p_i | i ∈ I}) ∩ tropConvHull({p_j | j ∈ J})`.

This should be straightforward once the representation theorem is in place.
