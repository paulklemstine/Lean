Formalize a single complete Lean 4 theorem file proving an axis-parallel escape result on the infinite board `ℤ × ℤ`, with no unfinished declarations and no chess-specific move definitions.

Create a self-contained file, e.g. `Catalog/Geometry/InfiniteChess/AxisParallelEscape.lean`, that does the following:

1. Define the board as `ℤ × ℤ`.
2. Define an axis-parallel attack configuration by two finite sets `V H : Finset ℤ`, where `V` is the set of attacked vertical columns and `H` is the set of attacked horizontal rows.
3. Define the attacked set as the set of board positions `(x,y)` such that `x ∈ V ∨ y ∈ H`.
4. Prove a precise slice lemma: if `x ∉ V`, then the set of `y : ℤ` such that `(x,y)` is attacked is exactly `{y | y ∈ H}`. You may express this either as set equality or as an iff characterization, whichever is easier to maintain in Lean.
5. Deduce from the slice lemma that for `x ∉ V`, the attacked vertical slice is finite.
6. Prove an existence lemma that every finite set of integers misses some integer. Use this to obtain `x : ℤ` with `x ∉ V` and `y : ℤ` with `y ∉ H`.
7. Conclude the main theorem: for any finite axis-parallel attack configuration `V H`, there exists `(x,y) : ℤ × ℤ` that is not attacked.

Important constraints:
- Do not define `kingStep`, queens, bishops, diagonals, or any general chess attack type.
- Do not leave theorem statements without proofs.
- Prefer simple constructive proofs over abstraction-heavy ones.
- If a supporting lemma about finite subsets of `ℤ` is needed, prove it locally in the file unless there is an obvious Mathlib lemma.
- Keep the namespace and theorem names clear and stable, such as `attacked`, `attacked_iff`, `slice_eq`, `exists_not_mem_finset_int`, and `exists_unattacked`.

The target is a fully compiling, sorry-free file whose main mathematical contribution is the explicit theorem that a finite union of horizontal and vertical lines cannot cover `ℤ × ℤ`.
