# Theorem Cluster A: Exact Minimum Hypotenuse Formula

## Target theorem A1
For every depth `d ≥ 0`, the minimum hypotenuse among all Berggren words of length `d` is exactly
\[
c_{\min}(d)=2d^2+6d+5,

and it is attained by the all-`A` branch.

## Structural lemma B2: One-step strict child optimality on the extremal branch
For the all-`A` triple
\[
(a_n,b_n,c_n)=(2n+3,\; 2n^2+6n+4,\; 2n^2+6n+5),

prove that the `A`-child has strictly smaller hypotenuse than the `B`-child and `C`-child.

### Lean target

```lean
theorem A_child_strictly_best_on_A_branch
    (n : ℕ) :
    let t := iterateA n baseTriple
    hypotenuse (childA t) < hypotenuse (childB t) ∧
    hypotenuse (childA t) < hypotenuse (childC t)
```

This is likely the key local rigidity statement.

## Structural theorem B3: Prefix-optimality
Any global minimizer at depth `d+1` must have a global minimizer prefix at depth `d`.

```lean
theorem minimizer_has_minimizer_prefix
    {d : ℕ} {w : BerggrenWord}
    (hw : w.length = d+1)
    (hmin : hypotenuse (evalWord w) = berggrenMinHypotenuse (d+1)) :
    hypotenuse (evalWord w.prefix) = berggrenMinHypotenuse d
```

Combined with strict optimality of `A` from the unique minimizer state, this gives an induction proving uniqueness.

## Why this is a breakthrough
This identifies a canonical **extremal geodesic** in the Berggren semigroup. In modern language: among all words of fixed length in the positive Berggren generators, one distinguished ray minimizes a natural height function. That is the kind of rigidity phenomenon that usually signals deeper geometry, akin to greedy geodesics in Coxeter groups, Lyapunov-minimizing orbits in matrix semigroups, and calibrated trajectories in discrete weak KAM theory.

# Theorem Cluster C: Exact Enumeration Depth for Hypotenuse Cutoff

Once A1/B1 are proved, derive the exact search-depth law.

## Target theorem C1
Let `D(N)` be the largest depth that can contain a primitive triple with `c ≤ N`. Then
\[
D(N)=\left\lfloor \frac{-3+\sqrt{2N+1}}{2}\right\rfloor.
\]

More precisely:
\[
\exists \text{ a triple at depth } d \text{ with } c \le N
\iff 2d^2+6d+5 \le N.
\]

### Lean 4 type signature target
```lean
theorem exists_depth_d_triple_with_hyp_le_iff
    (N d : ℕ) :
    (∃ t ∈ depthTriples d, hypotenuse t ≤ N) ↔ 2*d^2 + 6*d + 5 ≤ N
```

Then define:

```lean
def maxDepthUnderHypotenuse (N : ℕ) : ℕ := ...

theorem maxDepthUnderHypotenuse_eq
    (N : ℕ) :
    maxDepthUnderHypotenuse N =
      Nat.floor ((Real.sqrt (2*N + 1) - 3) / 2)
```

If avoiding `Real.floor` is cleaner in Lean, prove the equivalent pair of inequalities:
```lean
theorem maxDepthUnderHypotenuse_spec
    (N : ℕ) :
    2*(maxDepthUnderHypotenuse N)^2 + 6*(maxDepthUnderHypotenuse N) + 5 ≤ N ∧
    N < 2*(maxDepthUnderHypotenuse N + 1)^2 + 6*(maxDepthUnderHypotenuse N + 1) + 5
```

## Why this matters
This turns Berggren generation into an **exact-output-sensitive enumeration theorem**. It gives a certified stopping rule for exhaustive primitive-triple search under hypotenuse bound `N`. In algorithmic number theory and formal verification, exact stopping rules are far more valuable than asymptotic bounds.

# Proof Strategy Architecture

## Strategy 1: Direct algebraic dominance via explicit recurrences
This is the most promising route for Conjectures 1 and 2.

### Step 1
Derive exact recurrences for `a,b,c` under each generator, and especially for the hypotenuse:
\[
c(A(t)),\; c(B(t)),\; c(C(t))
\]
as explicit linear forms in `(a,b,c)`.

For the standard Berggren matrices, these are linear combinations with positive coefficients. You should isolate formulas of the shape
\[
c(G(t)) = \alpha_G a + \beta_G b + \gamma_G c
\]
for `G ∈ {A,B,C}`.

### Step 2
Characterize the region of state space occupied by the all-`A` branch and prove that inside this region, `A` is strictly hypotenuse-minimizing among the three children.

This likely reduces to inequalities among linear forms after substituting the explicit closed form for the `A^n` branch.

### Step 3
Prove prefix-optimality: if a depth-`d+1` word is globally minimizing, then its prefix at depth `d` must also minimize. Since the child map depends only on the parent, this converts the global problem into a one-step dynamic programming principle.

Then induction gives uniqueness of `A^d`.

### Why this is best
It aligns perfectly with Lean: explicit formulas, inequalities in `ℕ`/`ℤ`, and induction on depth. It avoids heavy spectral or geometric machinery and should formalize robustly.

## Strategy 2: Height monotonicity and a Bellman-optimality principle
This is conceptually deeper and may yield reusable machinery.

### Step 1
Define a height functional `H` on primitive triples, initially `H = c`, and prove that each generator strictly increases height.

### Step 2
Show that the minimal next-step growth
\[
\Delta_G(t) := c(G(t)) - c(t)
\]
is uniquely attained by `A` on a forward-invariant region containing the all-`A` branch.

### Step 3
Package this as a deterministic shortest-path / Bellman principle on the rooted Berggren tree:
\[
V(d,t)=\min_{|w|=d} c(w\cdot t).
\]
Then prove
\[
V(d+1,t)=\min_G V(d,G(t)).
\]
Establish that the optimizer remains in the `A`-invariant cone.

### Why it matters
This opens a new formal perspective: the Berggren tree becomes a discrete optimal control system. That viewpoint could generalize to other arithmetic trees and matrix semigroups.

---

## Strategy 3: Matrix-semigroup / cone geometry approach
This is bolder and potentially field-opening, especially for D-type results.

### Step 1
View each generator as a positive integer matrix in `GL₃(ℤ)` preserving the Pythagorean cone
\[
a^2+b^2=c^2.
\]

### Step 2
Interpret hypotenuse minimization at fixed word length as minimization of a linear functional on a semigroup orbit:
\[
c(w\cdot v_0)=\ell(M_w v_0)
\]
with `\ell(a,b,c)=c`.

### Step 3
Attempt to prove that among all products of length `d`, the product `A^d` minimizes `\ell(M_w v_0)`. This resembles a noncommutative rearrangement/greedy theorem and may connect to lower spectral radii or Barabanov-norm phenomena.

### Why this is exciting
If formalized even partially, this would link the Berggren problem to **joint spectral radius theory**, **Lyapunov-minimizing words**, and **semigroup extremal dynamics**—a genuinely unexpected bridge.

# Cross-Domain Connections You Should Explicitly Exploit

## 1. Joint spectral radius / lower spectral radius
The all-`A` branch as unique minimizer suggests a “lower spectral geodesic” phenomenon: among all products of length `d`, one repeated generator minimizes a chosen linear observable. This is analogous to extremal products in matrix semigroups, but here the observable is arithmetic and the semigroup is structured by a Diophantine invariant.

## 2. Discrete optimal control / Bellman dynamics
The recurrence “global minimizer at depth `d+1` has minimizing prefix at depth `d`” is exactly a dynamic programming principle. Formalizing this in Lean could create reusable machinery for optimization over finitely branching algebraic trees.

## 3. Expander heuristics and arithmetic random walks
The modular residue graph problem is a finite-state shadow of the infinite Berggren semigroup. Strong connectivity + spectral gap would place Berggren dynamics near the territory of random walks on arithmetic groups, affine sieve, and equidistribution of arithmetic invariants.

## 4. Formal algorithmics
Exact depth cutoff theorems are certification results: they transform brute-force generation into a verified algorithm with correctness and stopping guarantees. This is valuable for theorem provers, exact enumeration libraries, and certified number theory.

## 5. Hyperbolic / geometric group analogies
The unique all-`A` branch behaves like a preferred geodesic ray minimizing a height/Busemann function. Even if only metaphorical, this viewpoint may suggest monotonicity or convexity lemmas.
