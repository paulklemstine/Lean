## Precise Theorem Targets

You must prove **at least 3 deep theorems**. The following are the target theorems; prove as many as possible, but at minimum prove three of them with nontrivial arguments.

### Theorem 1: Substitution Functoriality for Simply-Typed λ-Terms

This is the higher-order analogue of `subst_comp` / `subst_comp3`.

**Mathematical statement.**  
For all typed substitutions `σ` and `τ`, and every term `t`, substituting by `σ` and then by `τ` is equal to substituting once by the composed substitution `τ ∘ σ` (with the correct lifting under binders).

**Lean 4 type signature sketch:**
```lean
theorem subst_comp
  {Ty : Type} [DecidableEq Ty]
  {Γ Δ Θ : Ctx Ty} {α : Ty}
  (t : Term Γ α)
  (σ : Subst Γ Δ)
  (τ : Subst Δ Θ) :
  subst (subst t σ) τ = subst t (Subst.comp σ τ)
```

If you use de Bruijn syntax:
```lean
theorem subst_comp
  {α : Ty} (t : Term n α)
  (σ : Subst n m) (τ : Subst m k) :
  subst (subst t σ) τ = subst t (compSubst σ τ)
```

**Why this matters.**  
This is the categorical backbone: substitutions form a category, and λ-terms become presheaf-like objects over contexts. Without this, higher-order completion has no stable algebraic substrate.

---

### Theorem 2: β-Compatible Rewrite Closure Under Substitution

This is the higher-order lift of `rewrites_closed_under_subst_and_context`.

**Mathematical statement.**  
If `t` rewrites to `u` in one β-aware rewrite step generated by equations `E`, then for every typed substitution `σ`, the substituted term `t[σ]` rewrites to `u[σ]` in the same generated relation.

**Lean 4 type signature sketch:**
```lean
theorem hoRewrites_closed_under_subst
  {Γ Δ : Ctx Ty} {α : Ty}
  {E : Set (Sigma fun Γ => Sigma fun α => Term Γ α × Term Γ α)}
  {t u : Term Γ α}
  (h : HoRewrite E t u)
  (σ : Subst Γ Δ) :
  HoRewrite E (subst t σ) (subst u σ)
```

If your generated relation is indexed differently, preserve the quantifier structure:
```lean
theorem betaRw_closed_under_subst
  {t u : Term Γ α}
  (h : BetaRwStep E t u) (σ : Subst Γ Δ) :
  BetaRwStep E (subst t σ) (subst u σ)
```

**Why this matters.**  
This is the theorem that makes rewriting a semantic operation on programs rather than a syntactic accident on open expressions.

---

### Theorem 3: β-Compatible Rewrite Closure Under Higher-Order Contexts

**Mathematical statement.**  
If `t → u`, then replacing an occurrence of `t` by `u` inside any typed λ/application context yields another valid rewrite step.

**Lean 4 type signature sketch:**
```lean
theorem hoRewrites_closed_under_context
  {Γ : Ctx Ty} {α β : Ty}
  (C : HOCtx Γ α β)
  {t u : Term Γ α}
  (h : HoRewrite E t u) :
  HoRewrite E (HOCtx.fill C t) (HOCtx.fill C u)
```

**Why this matters.**  
In first-order rewriting, contexts are tree contexts. In λ-calculus, contexts include abstraction and application structure, so this theorem is the gateway to reasoning about rewriting inside programs, not just on top-level terms.

---

### Theorem 4: β-Step is Stable Under Substitution

This theorem isolates the non-first-order phenomenon.

**Mathematical statement.**  
A β-redex remains a β-redex after substitution, with the result commuting appropriately with substitution.

**Lean 4 type signature sketch:**
```lean
theorem beta_closed_under_subst
  {Γ Δ : Ctx Ty} {α β : Ty}
  (t : Term (Γ ▻ α) β) (s : Term Γ α) (σ : Subst Γ Δ) :
  subst (betaContract t s) σ =
    betaContract (subst t (liftSubst σ)) (subst s σ)
```

or as a relational version:
```lean
theorem betaStep_subst
  (h : BetaStep t u) (σ : Subst Γ Δ) :
  BetaStep (subst t σ) (subst u σ)
```

**Why this matters.**  
This is where binding enters the theory for real. Proving this cleanly is the litmus test that your syntax and substitution design are mathematically correct.

---

### Theorem 5: Generated Higher-Order Equational Theory Respects β-Equivalence

This is the conceptual payoff theorem.

**Mathematical statement.**  
If `t ≡ u` is generated by equations plus higher-order closure, and `t ~β t'`, `u ~β u'`, then `t' ≡ u'` in the β-quotiented generated theory.

**Lean 4 type signature sketch:**
```lean
theorem EqvGen_respects_beta
  {t t' u u' : Term Γ α}
  (htt' : BetaEq t t')
  (huu' : BetaEq u u')
  (h : HOEqGen E t u) :
  HOEqGenModBeta E t' u'
```

A weaker but still meaningful version is acceptable:
```lean
theorem EqvGen_beta_congr
  (h : HOEqGen E t u) :
  HOEqGen E (betaNormalize t) (betaNormalize u)
```
provided you define and verify enough normalization infrastructure.

**Why this matters.**  
This theorem says the generated theory lives at the right semantic level: not raw syntax with binders, but computational content modulo β.

## Proof Strategy Architecture

You must include multi-step proofs. Do not hide the mathematics behind automation. Use induction, `rcases`, `cases`, `simp` only where structurally justified, and explicit `calc` chains where the categorical structure matters.

### Strategy A: De Bruijn + Structural Induction + Lifted Substitution
**Most promising.**

1. Represent variables with de Bruijn indices to make α-equivalence judgmental or irrelevant.
2. Define `rename`, `subst`, `liftSubst`, and prove the renaming/substitution interaction lemmas first.
3. Prove `subst_comp` by induction on term structure:
   - variable case reduces to substitution composition,
   - application case is immediate from IH,
   - abstraction case requires the lifted composition lemma under binders.
4. Define β-step by explicit contraction of `app (lam t) s`.
5. Prove closure under substitution and contexts by induction on derivations of the rewrite relation.

**Why this is best.**  
It minimizes the α-equivalence burden and turns the hard part into a manageable family of binder-lifting lemmas. This is the cleanest route to certified higher-order rewriting in Lean.

---

### Strategy B: Locally Nameless + Opening/Closing Lemmas
**Viable if you want stronger readability, but proof-heavy.**

1. Use free variables + bound indices.
2. Define opening/closing and capture-avoiding substitution.
3. Prove substitution composition using freshness lemmas.
4. Show β-closure under substitution by careful handling of abstraction cases.

**Why it may be worth it.**  
This representation aligns more naturally with paper mathematics and may help if you later want βη or polymorphism. But the freshness bureaucracy is substantial.

---

### Strategy C: Quotient by α-Equivalence + Contextual Rewriting
**Conceptually elegant, formally risky.**

1. Define raw syntax and α-equivalence.
2. Quotient terms by α-equivalence.
3. Define substitution and β-step on quotient terms.
4. Prove context/substitution closure at the quotient level.

**Why this is visionary but difficult.**  
If successful, it gives the cleanest mathematical object. But quotient transport in Lean may consume the project. Use only if the dynamic context indicates strong support libraries.

### Conjecture: Local Confluence for Small Orthogonal Higher-Order Systems Modulo β
For every finite, left-linear, simply-typed higher-order rewrite system with no critical pairs up to β-normalized matching on terms of size ≤ `N`, the generated β-aware one-step relation is locally confluent on all closed terms of size ≤ `N`.

This is falsifiable.

**Computational test protocol:**
1. Enumerate closed simply-typed λ-terms up to size bound `N`.
2. Enumerate one-step β-aware reducts.
3. Detect local peaks `u ← t → v`.
4. Search bounded joinability of `u` and `v`.
5. Report counterexamples.

If a counterexample appears at small sizes, the conjecture fails. If not, you have evidence for a higher-order critical-pair criterion.
