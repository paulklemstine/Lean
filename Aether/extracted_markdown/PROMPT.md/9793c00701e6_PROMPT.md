## Core Vision

A tropical/ReLU classifier is piecewise affine; each linearity region is cut out by dominance inequalities and is therefore polyhedral. The breakthrough is to stop treating robustness certificates as ad hoc analytic estimates and instead identify them with **exact distances to polyhedral cell boundaries**. This upgrades certified robustness from a Lipschitz lower bound to a geometric theorem about tropical cells. Then, in a second leap, use this geometric certificate as a control parameter for **entropy contraction** under perturbation, connecting tropical geometry to information theory.

This is not just “apply Polyhedron to neural nets.” It is the beginning of a **tropical-geometric semantics of robustness**:
- decision regions become tropical cells,
- margins become support-function gaps,
- certified radii become inradii or boundary distances,
- robustness implies information loss under adversarially constrained channels.

If formalized cleanly, this opens a field: **formal tropical learning theory in Lean**.

## Primary Theorem Target A: Polyhedral Cell Distance = Tropical Margin Radius

### Precise mathematical statement

Fix finitely many affine forms on `ℝ^n`,
\[
\ell_i(x) = a_i \cdot x + b_i \quad (i \in ι),
\]
and define the tropical score
\[
f(x) = \max_{i \in ι} \ell_i(x).
\]
For a distinguished index `k`, define the tropical cell
\[
C_k = \{x : \forall j,\ \ell_j(x) \le \ell_k(x)\}.
\]
If `x ∈ int(C_k)`, define the margin
\[
\operatorname{margin}_k(x) = \inf_{j \ne k} (\ell_k(x)-\ell_j(x)).
\]
Then the Euclidean distance from `x` to the boundary of `C_k` is bounded below by the normalized margin:
\[
\operatorname{dist}(x,\partial C_k)
\;\ge\;
\inf_{j \ne k}\frac{\ell_k(x)-\ell_j(x)}{\|a_k-a_j\|}.
\]
In the one-constraint-active case, or more generally when the nearest boundary facet is realized by a single competitor, this lower bound is exact.

This theorem converts tropical margin into a genuine polyhedral boundary distance certificate.

## Secondary Theorem Target B: Polyhedral Realization of Tropical Cells

### Precise mathematical statement

For finite affine forms `ℓ_i(x)=a_i·x+b_i`, each tropical cell
\[
C_k = \{x : \forall j,\ \ell_j(x)\le \ell_k(x)\}
\]
is a convex polyhedron, indeed a finite intersection of closed halfspaces. Therefore:
1. `C_k` is convex,
2. `C_k` is closed,
3. membership in `C_k` is equivalent to a finite halfspace system determined by the normals `a_j-a_k`,
4. the boundary of `C_k` is contained in the union of tie hyperplanes `ℓ_j = ℓ_k`.

### Lean 4 type signature target

Again, exact names may vary with Mathlib’s current `Polyhedron` API, but aim for a theorem of this form:

```lean

  {ι : Type*} [Fintype ι]
  {n : Type*} [NormedAddCommGroup n] [InnerProductSpace ℝ n]
  [FiniteDimensional ℝ n]
  (a : ι → n) (b : ι → ℝ) (k : ι) :
  ∃ P : Set n, IsPolyhedron ℝ P ∧
    P = {x : n | ∀ j, inner ℝ (a j) x + b j ≤ inner ℝ (a k) x + b k} := by
  ...
```

If `IsPolyhedron` is not the exact predicate in your imported API, prove the equivalent finite-intersection-of-halfspaces statement first and derive the polyhedral corollaries.

### Why this matters

This theorem is the infrastructure theorem. Without it, tropical cells are just sets cut out by inequalities. With it, they become first-class polyhedral objects in Lean, making available:
- convexity lemmas,
- closure/interior tools,
- distance-to-set machinery,
- eventual face lattice / combinatorial arguments.

This is the formal gateway to tropical stratification of neural networks.

## Tertiary Theorem Target C: Robustness from Polyhedral Interior

### Precise mathematical statement

Let `f(x)=max_i ℓ_i(x)` and suppose class `k` uniquely wins at `x`, i.e.
\[
\forall j\ne k,\ \ell_j(x) < \ell_k(x).
\]
If
\[
r < \operatorname{dist}(x,\partial C_k),
\]
then for every `y` with `dist(x,y) < r`, index `k` still wins:
\[
\forall j,\ \ell_j(y)\le \ell_k(y).
\]
Equivalently, the open ball centered at `x` of radius strictly below the boundary distance lies inside the same tropical cell.

## Ambitious Cross-Domain Theorem Target D: Entropy Contraction via Certified Radius

The prompt fragment suggests an information-theoretic theorem, but it needs sharpening to become mathematically defensible and formalizable.

### Recommended reformulation

Let `X` be a finite random variable on `α`, and let `W` be a stochastic channel from `α` to distributions on `β`. Suppose the classifier induced by a tropical score map has certified radius `r(x)` at each input `x`, and let `A_r` be the event that an admissible perturbation of size at most `r(x)` does not change the winning cell. Then under a perturbation channel `P` supported inside the certified cell,
\[
I(\mathrm{label}(X); \mathrm{label}(P(X))) = H(\mathrm{label}(X)).
\]
Conversely, when perturbations cross a cell boundary with probability `p`, one expects a Fano-style lower or upper bound:
\[
I(\mathrm{label}(X); \mathrm{label}(P(X))) \ge H(\mathrm{label}(X)) - h(p) - p\log(|\mathcal Y|-1).
\]

This is the right conceptual bridge: robustness radius controls boundary-crossing probability, and boundary-crossing probability controls information contraction.

### Lean target, phase 1

Do not start with full Shannon mutual information unless the probability API is ready. First formalize a deterministic surrogate:

```lean
theorem label_invariant_under_certified_perturbation
  {α n ι : Type*} ...
  (label : n → ι)
  (x y : n)
  (hxy : dist x y < certifiedRadius x)
  :
  label y = label x := by
  ...
```

Then package a finite-probability corollary later.

### Why this is revolutionary

This would create a rigorous pipeline:
**polyhedral geometry → robustness certificate → perturbation stability → information preservation/contraction**.

That is a new language for explainability. Decision boundaries become tropical hypersurfaces; interpretability becomes geometry of cells; robustness becomes a statement about how much information survives constrained channels.

## Proof Strategy Architecture

### Strategy A: Hyperplane-distance first, then polyhedral intersection
**Most promising.**

1. Prove the exact distance formula to a single affine hyperplane:
   \[
   \operatorname{dist}(x,\{y:\langle u,y\rangle=c\}) = |\langle u,x\rangle-c|/\|u\|.
   \]
   This is the atomic geometric lemma.

2. Rewrite each tropical cell inequality
   \[
   \ell_j(y)\le \ell_k(y)
   \]
   as a halfspace inequality with normal `a j - a k`, so `C_k` is a finite intersection of halfspaces.

3. Show the boundary is contained in the union of tie hyperplanes, and conclude the lower bound on distance to the boundary by taking the infimum over competitors `j ≠ k`.

Why best: it isolates all difficulty into a standard geometric fact plus finite-set order reasoning. It is modular and likely aligns best with Mathlib’s existing metric/convex APIs.

---

### Strategy B: Convex analysis via support functions and separating hyperplanes

1. Treat each competitor inequality as defining a support functional on the active cell.

2. Use convexity/closedness of finite halfspace intersections to show nearest-point projection onto the complement or frontier exists in finite-dimensional Euclidean space.

3. Characterize the first violated inequality along the segment from `x` to a nearest boundary point, yielding the active-facet formula.

Why useful: this gives a stronger convex-analytic theorem and may scale to exact inradius/facet-combinatorics later. But it is heavier and more dependent on available projection theorems.

---

### Strategy C: Piecewise-affine network route

1. Start from `relu_boundary` and the existing tropical/ReLU theorems to derive that a one-layer or tropical-affine classifier has cells defined by score comparisons.

2. Prove the polyhedral theorem specifically for the score regions arising from the network architecture.

3. Generalize from network-specific cells to arbitrary finite tropical max-affine cells.

Why useful: easiest path to immediate applications, especially if the generic polyhedron API is awkward. But less elegant as a foundational result. Use this if generic convex geometry stalls.

## Cross-Domain Connections

### Neural network interpretability
ReLU networks are tropical rational or piecewise tropical-affine maps. Their decision regions are polyhedral cells, and your theorem interprets saliency/robustness in geometric terms:
- margin = score gap,
- explanation region = active tropical cell,
- decision boundary = tropical hypersurface,
- robustness radius = distance to hypersurface.

This makes interpretability certifiable and geometric rather than heuristic.

### Tropical algebraic geometry
The union of tie hyperplanes is the tropical hypersurface where the max is non-smooth. Your theorem says that classification stability is exactly distance from the tropical hypersurface. This is a formal bridge between learning theory and tropical varieties.

### Information theory
Certified radius controls whether a perturbation channel can cross decision boundaries. This yields a route to formal bounds on label-information preservation and eventually tropical forms of data processing.

### Formal methods / verification
A polyhedral certificate is machine-checkable, local, and compositional. This is ideal for theorem-proved safety certificates for neural systems.

### Convex optimization
Nearest-boundary computation for polyhedral cells links to support functions, active-set methods, and exact certification algorithms.
