## Exact Target Theorems

### Theorem A: Obstruction to naive tropical twin-prime implication
Formalize a finite obstruction theorem showing that any purely order-theoretic/min-plus inequality on weighted residue data is insufficient to force infinitely many twin pairs.

A precise formal target:

```lean
def TwinPairIn (s : Finset ℕ) (n : ℕ) : Prop :=
  n ∈ s ∧ n + 2 ∈ s

def HasNoTwinPairs (s : Finset ℕ) : Prop :=
  ∀ n, ¬ TwinPairIn s n

def tropicalResidueScore (w : ℕ → ℝ) (N : ℕ) : ℝ :=
  ((Finset.range N).inf' (by
    have h : (0 : ℕ) ∈ Finset.range (N+1) := by simp
    exact Finset.Nonempty.mono (by simpa) ⟨0, h⟩)
    (fun n => w n))

theorem tropical_residue_does_not_force_twin_pairs :
  ∀ N : ℕ, ∃ s : Finset ℕ,
    s ⊆ Finset.range N ∧
    HasNoTwinPairs s
```

This theorem is intentionally modest but conceptually crucial: it shows that **without arithmetic structure**, tropical minima alone cannot create twin primes.

A stronger variant, if feasible:

```lean
def gapWeight (w : ℕ → ℝ) (s : Finset ℕ) : ℝ :=
```

This is a **counterexample theorem schema**: arbitrary tropical weights do not enforce arithmetic twin structure.

### Theorem B: Tropical gap-energy inequality on finite sets
Now prove a real theorem. Define a tropical energy measuring how efficiently a finite set supports gap `2`.

```lean
def pairIndicator (s : Finset ℕ) (n : ℕ) : ℕ :=
  if n ∈ s ∧ n + 2 ∈ s then 1 else 0

def twinCount (s : Finset ℕ) : ℕ :=
  ∑ n in s, pairIndicator s n

def tropicalGapEnergy (w : ℕ → ℝ) (s : Finset ℕ) : ℝ :=
  s.inf' (by
    rcases Finset.nonempty_iff_ne_empty.mpr ?h with hne
    exact hne)
    (fun n => max (w n) (w (n+2)))
```

Then target a theorem of the form:

```lean
theorem twinCount_le_card :
  ∀ s : Finset ℕ, twinCount s ≤ s.card
```

and then a structurally richer theorem:

```lean
theorem twinCount_zero_of_parity_layer
    (s : Finset ℕ)
    (h : ∀ n ∈ s, Even n) :
    twinCount s = 0
```

This gives a first exact classification phenomenon: a dense set in one parity layer has **zero** twin pairs. Tropical gap statistics must therefore detect **interaction between arithmetic layers**, not just density.

Now push this to a min-plus inequality:

```lean
theorem tropical_gap_energy_monotone
    (w₁ w₂ : ℕ → ℝ) (s : Finset ℕ)
    (h : ∀ n, w₁ n ≤ w₂ n) :
    tropicalGapEnergy w₂ s ≥ tropicalGapEnergy w₁ s
```

This theorem is simple but foundational: it establishes the order-theoretic backbone needed for a future tropical sieve calculus.

### Theorem C: Min-plus convolution identity for finite gap profiles
This is the genuine “tropical Hardy–Littlewood shadow” you can formalize now.

Define the finite correlation profile:

```lean
def gapProfile (s : Finset ℕ) (h N : ℕ) : ℕ :=
  (((Finset.range N).filter (fun n => n ∈ s ∧ n + h ∈ s)).card)

def tropicalConv (f g : ℕ → ℝ) (n : ℕ) : ℝ :=
  ((Finset.range (n+1)).inf' ⟨0, by simp⟩ (fun k => f k + g (n-k)))
```

Target a theorem asserting a min-plus convolution lower bound for gap profiles encoded by costs:

```lean
def supportCost (s : Finset ℕ) (n : ℕ) : ℝ :=
  if n ∈ s then 0 else 1

theorem tropical_conv_support_detects_overlap
    (s : Finset ℕ) (n : ℕ) :
    tropicalConv (supportCost s) (fun m => supportCost s (m+2)) n = 0 →
    ∃ k ≤ n, k ∈ s ∧ (n - k) + 2 ∈ s
```

This is the correct finite analogue of “Hardy–Littlewood as convolution”: if the min-plus convolution vanishes, there is a witness pair realizing the target gap pattern.

A stronger and more elegant exact identity may be reachable:

```lean
theorem tropical_conv_zero_iff_gap_witness
    (s : Finset ℕ) (n : ℕ) :
    tropicalConv (supportCost s) (fun m => supportCost s (m+2)) n = 0 ↔
    ∃ k ≤ n, k ∈ s ∧ (n - k) + 2 ∈ s
```

This is a true theorem, formally meaningful, and it opens a program.

## Proof strategy architecture

### Strategy A: Finset-combinatorial foundation
Most promising for immediate Lean success.

1. Define all objects on `Finset ℕ` first, not on infinite sets or asymptotic densities.
2. Prove witness lemmas converting `inf' = 0` or min-plus bounds into explicit existential statements.
3. Derive gap-profile theorems by finite decomposition and membership rewriting.

Why this is best: Mathlib is strong on `Finset`, sums, cardinals, order, and basic real inequalities. This gives a clean formal core with minimal analytic overhead.

---

### Strategy B: Tropical/order-theoretic abstraction
After the finite combinatorics works, abstract to idempotent semiring language.

1. Recast `supportCost` as a cost-valued indicator into `ℝ`.
2. Show min-plus convolution is monotone in each variable.
3. Prove detection lemmas as a Galois-style correspondence between zero-cost witnesses and overlap patterns.

Why it matters: this turns a one-off twin-gap construction into a general theorem about tropical pattern detection, potentially applicable to `k`-tuple constellations, coding theory, and shortest-path geometry.

---

### Strategy C: Arithmetic layer decomposition
This is the bridge back toward number theory.

1. Partition finite sets by residue classes mod `2`, then mod `p`.
2. Show some residue-layer configurations force zero twin count, while others permit it.
3. Formalize that tropical data must be enriched by congruence constraints to retain arithmetic meaning.

Why this matters: it explains exactly why a naive tropical sieve cannot prove twin primes. Arithmetic lives in the interaction between tropical cost and residue structure.
