**Mode:** prove

## Precise Theorem Targets

Work with one-dimensional nearest-neighbor cellular automata over a finite alphabet `α`, with local rule
`f : α → α → α → α`. Let `CA α := (α × α × α → α)` if that is easier in Lean. Define the induced global map on bi-infinite configurations when possible, or, if full two-sided shift infrastructure is too heavy, begin with the **finite ring approximation** on `Fin n → α`, where the update is taken modulo `n`. This already captures periodic point counts and zeta approximants.

### Theorem A: Rationality for additive/permutative finite-ring approximants
For a finite alphabet carrying a finite abelian group structure, and for any nearest-neighbor additive cellular automaton on the cyclic ring `Fin n`, the periodic point counting sequence of the induced global map satisfies a linear recurrence, hence its Artin–Mazur zeta series is rational.

A concrete formal target:

```lean
def LocalRule (α : Type _) := α → α → α → α

def additive_local_rule
    {α : Type _} [Finite α] [AddCommGroup α]
    (f : LocalRule α) : Prop :=
  ∃ a b c : End α, ∀ x y z, f x y z = a x + b y + c z

def ringCA
    {α : Type _} [Fintype α]
    (f : LocalRule α) (n : ℕ) :
    (Fin n → α) → (Fin n → α) := sorry

def periodicPoints
    {X : Type _} [Fintype X]
    (T : X → X) (m : ℕ) : Finset X :=
  Finset.univ.filter (fun x => (T^[m]) x = x)

def zetaCoeff
    {X : Type _} [Fintype X]
    (T : X → X) (m : ℕ) : ℚ :=
  (periodicPoints T m).card

theorem additive_ca_periodic_points_linear_recurrence
    {α : Type _} [Fintype α] [DecidableEq α] [AddCommGroup α]
    (f : LocalRule α) (hf : additive_local_rule f) :
    ∃ k : ℕ, ∃ c : Fin k → ℤ,
      ∀ᶠ m : ℕ in Filter.atTop,
        zetaCoeff (ringCA f (m+1)) (m+1) =
          ∑ i : Fin k, (c i : ℚ) * zetaCoeff (ringCA f (m+1)) (m - i.1) := sorry
```

This signature can be adjusted, but the mathematical content must be: **periodic point counts are recurrence-controlled**.

A more realistic first theorem, and likely the right one to actually prove:

```lean
theorem additive_ca_zeta_rational_finite
    {α : Type _} [Fintype α] [DecidableEq α] [AddCommGroup α]
    (f : LocalRule α) (n : ℕ) :
    ∃ P Q : Polynomial ℚ,
      Q ≠ 0 ∧
      PowerSeries.mk (fun m => (periodicPoints (ringCA f n) m).card : ℚ) = P / Q := sorry
```

If the power series API is inconvenient, formulate rationality as eventual linear recurrence of coefficients.

### Theorem B: Finite-state spacetime language for left/right permutative automata
Define the finite window spacetime language `ST_f(w,h)` of all `w × h` spacetime rectangles realizable by the CA. Prove that for left-permutative or right-permutative CA, this language is regular in the horizontal direction via a finite transducer/state compression. This is the formal bridge to “short proofs”: regularity gives bounded-description certificates.

Target statement:

```lean
def SpaceTimeBlock
    (α : Type _) (w h : ℕ) := Fin h → Fin w → α

def realizesBlock
    {α : Type _} (f : LocalRule α) {w h : ℕ} :
    SpaceTimeBlock α w h → Prop := sorry

def blockLanguage
    {α : Type _} (f : LocalRule α) (h : ℕ) :
    Language (Fin h → α) := sorry

theorem permutative_block_language_regular
    {α : Type _} [Fintype α] [DecidableEq α]
    (f : LocalRule α)
    (h : ℕ)
    (hf : left_permutative f ∨ right_permutative f) :
    ∃ M : Type _, ∃ _ : Fintype M,
      language_recognized_by_finite_automaton (blockLanguage f h) := sorry
```

If `Language` and automata infrastructure are too cumbersome, replace by a finiteness theorem on Myhill–Nerode equivalence classes of width extensions.

### Theorem C: Compression upper bound from regular spacetime language
Formalize a surrogate for “subquadratic proof complexity” that Lean can handle cleanly: **certificate complexity of block realizability**. For example, define the certificate length of a width-`w`, height-`h` block to be the minimum size of a boundary witness or automaton run certifying realizability. Then prove linear or quasilinear upper bounds for the classes in Theorem B.

Target:

```lean
def certComplexity
    {α : Type _} (f : LocalRule α) {w h : ℕ}
    (B : SpaceTimeBlock α w h) : ℕ := sorry

theorem permutative_cert_complexity_linear
    {α : Type _} [Fintype α] [DecidableEq α]
    (f : LocalRule α)
    (hf : left_permutative f ∨ right_permutative f) :
    ∃ C : ℕ, ∀ w h (B : SpaceTimeBlock α w h),
      realizesBlock f B →
      certComplexity f B ≤ C * (w + h) := sorry
```

This theorem is the right formal proxy for the proof-complexity side. It transforms the original conjecture from a philosophical slogan into a theorem schema:
**rational/regular dynamics imply compressible certificates**.

If you prove even one robust implication
`zeta rationality -> finite-state spacetime recognizability -> short certificates`,
you create a new invariant pipeline:

**dynamical spectrum → language complexity → proof complexity**

That would open:
- symbolic dynamics informed by bounded arithmetic,
- automata-theoretic proof certificates for dynamical systems,

- a route to classifying “explainable” versus “irreducible” discrete physics.

This also creates a formal-methods payoff: one could certify nontrivial dynamical properties by checking finite-state compression rather than brute-force simulation.

## Proof Strategy Paths

### Strategy A: Linear algebra over finite abelian groups
Most promising for Theorem A.

1. For additive `f`, show `ringCA f n` is an endomorphism of the finite abelian group `(Fin n → α)`.
2. Express periodic points of period `m` as `ker ((ringCA f n)^[m] - 1)`.
3. Use structure theory of finite modules / matrices over finite rings or direct finiteness arguments to derive recurrence/rationality of the sequence `#Fix(T^m)`.

Why this is promising:
- It converts dynamics into certified algebra.
- Lean handles finite endomorphisms and cardinality arguments better than analytic zeta manipulations.
- It naturally connects to matrix traces and determinant formulas.

A sharpened target in this strategy:
for linear CA over `ZMod p`, identify `ringCA f n` with a circulant matrix and prove
`#Fix(T^m)` is governed by gcd data of characteristic polynomials.

### Strategy B: Transfer-matrix / automaton counting
Best for Theorems B and C.

1. Encode height-`h` spacetime strips as paths in a finite graph of admissible adjacent columns.
2. Show the number of realizable width-`w` blocks is given by powers of a finite adjacency matrix.
3. Conclude rational generating functions and finite-state recognizability.

Why this matters:
- This is the cleanest route from symbolic dynamics to certificate compression.
- It makes the zeta-regularity analogy literal: both periodic point counts and block counts become transfer-matrix traces.

This is also the best bridge to proof complexity: a path in a finite graph is a short certificate.

### Strategy C: Reversibility/permutativity as bounded-information propagation
Best for a structurally deep theorem.

1. Use left/right permutativity to show each new column is determined by bounded boundary data.
2. Construct an explicit boundary witness whose size is `O(h)` or `O(w+h)`.
3. Deduce certificate upper bounds and regularity of the spacetime language.

Why this is powerful:
- It turns a dynamical property into a proof-compression theorem.
- It should interact beautifully with the catalog theorem
  `finite_function_one_step_reversible_extension`, which suggests an existing reversible-extension mechanism you can exploit to build finite-state witnesses or inverses.
