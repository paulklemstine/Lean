## Core objects to define

Work with a finite boundary type `B` and a finite internal state type `S` over an idempotent commutative semiring `K`. The intended model is min-plus, but the first layer should be semiring-generic wherever Mathlib permits.

Define:

1. **Boundary response vectors**
   - functions `B → K`, interpreted as source-to-sink transfer profiles.

2. **Transfer semimodule**
   - a finitely generated subsemimodule of `B → K`, together with a filtered composition structure encoding finite-step propagation.

3. **Weighted acyclic transport graph**
   - a finite DAG with distinguished boundary vertices and edge weights in `K`.
   - its transfer matrix sends each source boundary vertex to the tropical aggregate over all directed paths to each sink boundary vertex.

4. **Path-response semimodule**
   - the semimodule generated by the boundary transfer profiles arising from vertices/layers/elementary propagation channels of the graph.

5. **Minimal realization**
   - a graph realization with no redundant internal vertices relative to the transfer semimodule, unique up to boundary-preserving weighted graph isomorphism.

You should isolate a finite axiom package for an abstract transfer semimodule:
- **boundary monotonicity**
- **tropical superposition**
- **path factorization**
- **acyclic causal filtration**

The filtration is the decisive ingredient: it should force realizations to be DAG-like and make inductive reconstruction possible.

## Precise theorem targets

### Theorem 1: Realization of finite filtered tropical transfer semimodules

Informal statement:

> Let `K` be an idempotent commutative semiring, `B` a finite boundary type, and `T ⊆ (B → K)` a finitely generated transfer semimodule equipped with a finite causal filtration and satisfying boundary monotonicity, tropical superposition, and path factorization. Then there exists a finite weighted acyclic directed graph `G` with boundary `B` such that `T` is isomorphic, as a filtered idempotent semimodule, to the path-response semimodule of `G`.

A Lean-oriented signature skeleton:

```lean
theorem exists_weightedAcyclicGraph_of_filteredTransfer
  {K B : Type*} [CanonicallyOrderedCommSemiring K]
  [OrderBot K] [Fintype B] [DecidableEq B]
  (T : Submodule K (B → K))
  (hfg : T.FG)
  (hmono : BoundaryMonotone T)
  (hsuper : TropicalSuperposition T)
  (hfactor : PathFactorization T)
  (hfil : AcyclicCausalFiltration T) :
  ∃ G : WeightedAcyclicBoundaryGraph K B,
    Nonempty (FilteredTransferIso T G.pathResponseSubmodule)
```

If `Submodule` over a semiring of functions is awkward in your chosen semiring class, use a bespoke `IdempotentSubsemimodule` structure. Precision of the mathematical content matters more than reusing a typeclass that does not quite fit.

### Theorem 2: Canonical minimal realization and uniqueness

Informal statement:

> Every realizable finite filtered transfer semimodule admits a minimal acyclic graph realization `G_min`, and if `G₁`, `G₂` are minimal realizations of the same transfer semimodule, then they are isomorphic by a boundary-preserving weight-preserving graph isomorphism.

Lean-oriented signature skeleton:

```lean
theorem exists_unique_minimal_realization
  {K B : Type*} [CanonicallyOrderedCommSemiring K]
  [OrderBot K] [Fintype B] [DecidableEq B]
  (T : Submodule K (B → K))
  (hfg : T.FG)
  (hmono : BoundaryMonotone T)
  (hsuper : TropicalSuperposition T)
  (hfactor : PathFactorization T)
  (hfil : AcyclicCausalFiltration T) :
  ∃ Gmin : WeightedAcyclicBoundaryGraph K B,
    IsMinimalRealization T Gmin ∧
    ∀ G : WeightedAcyclicBoundaryGraph K B,
      IsMinimalRealization T G →
      Nonempty (BoundaryWeightedGraphIso Gmin G)
```

### Theorem 3: Realizability criterion via transfer matrix closure/rank

Informal statement:

> A finite tropical transfer matrix `H : B → B → K` is realizable by a finite weighted acyclic boundary graph iff it satisfies a finite extremal-generation/closure criterion. Equivalently, the associated transfer semimodule is finitely generated by extremal responses compatible with the causal filtration.

Lean-oriented signature skeleton:

```lean
theorem realizable_iff_extremalClosure
  {K B : Type*} [CanonicallyOrderedCommSemiring K]
  [OrderBot K] [Fintype B] [DecidableEq B]
  (H : B → B → K) :
  TransferMatrixRealizable H ↔
    HasFiniteExtremalGeneratorFamily H ∧
    SatisfiesCausalClosureCriterion H
```

If a rank notion is easier to formalize than a closure operator, define a tropical factor rank or extremal rank surrogate and prove one direction first:
- realizable ⇒ finite extremal closure
- finite extremal closure + filtration ⇒ realizable

### Theorem 4: Certified reconstruction of the minimal graph

Informal statement:

> There is a constructive elimination procedure which, from a realizable transfer matrix `H`, recovers a minimal weighted acyclic boundary graph `G_min`, together with a correctness certificate and minimality certificate.

def reconstructMinimalGraph

## Proof strategy options

### Strategy A: Layered filtration induction from abstract semimodule data
This is the most promising route.

**Step 1.** Define the causal filtration so that each graded piece captures exactly the “new” extremal transfer profiles appearing at a propagation depth. Prove finite generation gives a finite extremal basis layer-by-layer.

**Step 2.** Realize each graded layer by a set of internal vertices whose outgoing responses equal those extremal generators. Use path factorization to show inter-layer composition corresponds to weighted edges from earlier to later layers.

**Step 3.** Glue the layers into a finite DAG and prove the induced path-response semimodule is isomorphic to the original `T`. Then prune redundant vertices to obtain minimality and prove uniqueness from extremal-layer invariants.

Why this is strongest:
- It uses the filtration exactly where acyclicity matters.
- It is constructive enough to feed the reconstruction theorem.
- It mirrors state-minimization ideas without importing automata machinery wholesale.

### Strategy B: Tropical factorization of the transfer matrix
A more matrix-centric route.

**Step 1.** Associate to `T` or `H_T` a tropical transfer matrix and prove the axioms imply a finite factorization through layered matrices:
`H = L₁ ⊗ L₂ ⊗ ... ⊗ L_n`
with each factor encoding one causal layer.

**Step 2.** Convert each factor into a bipartite weighted layer of a DAG. The product of layers computes path propagation, so the full layered graph realizes `H`.

**Step 3.** Characterize minimality by irredundancy of the factorization, perhaps via extremal columns/rows or tropical rank surrogates.

Why this is attractive:
- It gives a clean realizability criterion.
- It connects naturally to tropical linear algebra and decomposition theorems.
- It may reuse existing finite decomposition results directly.

Risk:
- Tropical rank notions can be subtle and may become a formalization sinkhole if overgeneralized too early.

### Strategy C: Galois/closure duality via generator-response correspondence
This is conceptually deep and could produce the strongest “bridge theorem.”

**Step 1.** Define a closure operator on boundary responses generated by admissible path-compositions. Show realizable transfer semimodules are exactly the finitely generated fixed points of this closure.

**Step 2.** Use extremal generators as “indecomposable scattering channels” and construct a graph whose vertices are closure-irreducibles. Prove path factorization gives the edge relation.

**Step 3.** Identify minimal realizations with the poset of irreducibles under causal precedence; uniqueness then follows from the canonical closure structure.

Why this matters:
- It makes the theorem look like a true duality, not just an existence statement.
- It interfaces naturally with prior closure and reconstruction bridges.

Risk:
- Best pursued after Strategy A has delivered the core theorem.

Recommendation: **Lead with Strategy A**, borrow matrix lemmas from Strategy B, and package the conceptual duality language from Strategy C in the final theorem statements and documentation.

## Formalization guidance

Keep the first pass finite and rigid.

- Use finite types throughout: `Fintype`, `DecidableEq`.
- Build a concrete `WeightedAcyclicBoundaryGraph K B` structure rather than over-abstracting graph theory.
- Encode acyclicity via a layer function `ℓ : V → ℕ` with every internal edge strictly increasing layer. This is far easier in Lean than arbitrary DAG acyclicity.
- Define path responses recursively by dynamic programming over layers instead of summing over arbitrary path sets.
- This recursion will likely make `pathResponse_finitelyGenerated` and reconstruction correctness much easier.

A good graph structure may be:

```lean
structure WeightedAcyclicBoundaryGraph (K B : Type*) [Zero K] where
  V : Type*
  instFintypeV : Fintype V
  instDecidableEqV : DecidableEq V
  boundaryVertex : B → V
  layer : V → ℕ
  weight : V → V → K
  edge_respects_layer :
    ∀ {u v}, weight u v ≠ 0 → layer u < layer v
```

Then define transfer recursively from terminal layers backward. If min-plus is the concrete model, replace `0`/`1` conventions carefully with the semiring’s additive/multiplicative identities.
