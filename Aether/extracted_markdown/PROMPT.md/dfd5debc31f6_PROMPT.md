Prove the generalized EML Stone–Weierstrass theorem for arbitrary compact Hausdorff spaces. In `EMLClosure.lean` we established density of the EML-generated subalgebra on compact subsets of `Fin n → ℝ`. The next milestone is to remove the ambient Euclidean space entirely and work with any compact Hausdorff topological space equipped with a continuous point-separating family.

**Theorem to prove.** Let $X$ be a nonempty compact Hausdorff space, let $n \geq 1$, and let $\Phi : \mathrm{Fin}\,n \to C(X,\mathbb{R})$ be a family of continuous real-valued functions that separates points. Define the logistic activation $\sigma(x) = 1/(1+e^{-x})$, the EML exponential generators $e_{w,b}(x) = \exp(\sum_i w_i \Phi_i(x) + b)$, and the EML logistic generators $\ell_{w,b}(x) = \sigma(\sum_i w_i \Phi_i(x) + b)$. Let $\mathcal{A}(\Phi)$ be the $\mathbb{R}$-subalgebra of $C(X,\mathbb{R})$ generated by $\{e_{w,b}\}_{w,b} \cup \{\ell_{w,b}\}_{w,b}$.

```lean
import Mathlib

noncomputable section

open Real

variable {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
variable {n : ℕ} (Φ : Fin n → C(X, ℝ))

def logistic (x : ℝ) : ℝ := 1 / (1 + exp (-x))

def emlExpGen (w : Fin n → ℝ) (b : ℝ) : C(X, ℝ) :=
  ⟨fun x => exp (∑ i : Fin n, w i * Φ i x + b), by continuity⟩

def emlLogisticGen (w : Fin n → ℝ) (b : ℝ) : C(X, ℝ) :=
  ⟨fun x => logistic (∑ i : Fin n, w i * Φ i x + b), by continuity⟩

def emlGeneratorsHausdorff : Set C(X, ℝ) :=
  {f | ∃ w b, f = emlExpGen Φ w b} ∪ {f | ∃ w b, f = emlLogisticGen Φ w b}

def emlSubalgebraHausdorff : Subalgebra ℝ C(X, ℝ) :=
  Algebra.adjoin ℝ (emlGeneratorsHausdorff Φ)

theorem eml_stoneWeierstrass_hausdorff
    (hn : 1 ≤ n)
    (hΦ : ∀ x y : X, x ≠ y → ∃ i : Fin n, Φ i x ≠ Φ i y) :
    (emlSubalgebraHausdorff Φ).SeparatesPoints ∧
    (emlSubalgebraHausdorff Φ).topologicalClosure = ⊤ := by
  sorry
```

**Proof strategy.**  
1. **Constants and multiplicative closure.** The constant function $1$ belongs to the algebra because `emlExpGen Φ 0 0 = ⟨fun _ => 1, _⟩` by `exp_zero`. Multiplicative closure of the exponential generators follows from `EMLStoneWeierstrassBridge.EML_closed_under_mul` (alias `exp_add`): the product of two generators with parameters $(w,b)$ and $(w',b')$ is exactly the generator with parameters $(w+w',b+b')$. This functional equation is the core of the algebraic bridge recorded in `AlgebraEMLBridge.eml_add_exp_bridge`, which itself reduces via `EMLApproximation.eml_exp` to the identity $\exp(a+a') = \exp a \cdot \exp a'$.

2. **Point separation.** For distinct $x, y \in X$, hypothesis `hΦ` yields an index $j$ with $\Phi_j(x) \neq \Phi_j(y)$. Choose weights $w_i := \Phi_i(x) - \Phi_i(y)$ and bias $b := 0$. Then the affine combination evaluates with difference exactly $\sum_i (\Phi_i(x) - \Phi_i(y))^2 > 0$, where strict positivity follows by applying `Finset.sum_pos` to the witness term $(\Phi_j(x) - \Phi_j(y))^2$ using `sq_pos_of_ne`. Because `exp` is strictly monotone (`Real.exp_lt_exp`), the generator `emlExpGen Φ w b` takes distinct values at $x$ and $y$. Hence `emlSubalgebraHausdorff Φ` separates points.

3. **Density via Stone–Weierstrass.** Continuity of the exponential generators is immediate from `ContinuousFunctionBridge.exp_continuous` composed with the continuous affine functional; continuity of the logistic generators follows from the definition of $\sigma$ as a rational expression in $\exp$ and the `continuity` tactic. Since `emlSubalgebraHausdorff Φ` is an $\mathbb{R}$-subalgebra containing constants and separating points on the compact Hausdorff space $X$, apply `ContinuousMap.subalgebra_topologicalClosure_eq_top_of_separatesPoints` from Mathlib (`Topology.StoneWeierstrass`). This gives `topologicalClosure = ⊤`, i.e. uniform density in $C(X,\mathbb{R})$.

**Why this matters.** The catalog already contains the Euclidean special case (`EMLClosure.lean.eml_stoneWeierstrass`) and the algebraic bridge verifying that exp-log compositions satisfy a homomorphism (`AlgebraEMLBridge.eml_add_exp_bridge`, `EMLStoneWeierstrassBridge.EML_closed_under_mul`). By proving density for *any* compact Hausdorff space equipped with *any* continuous point-separating family, this theorem shows that EML networks are universal approximators not merely on $\mathbb{R}^n$, but on arbitrary configuration spaces arising in tropical geometry, dynamical systems, and quantum field theory. It resolves the "EML universal approximation theorem" open problem in its proper topological generality and provides the rigorous foundation for applying certified EML approximation to non-Euclidean state spaces.
