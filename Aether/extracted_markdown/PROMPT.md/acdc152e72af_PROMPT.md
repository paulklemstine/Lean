## Core Mathematical Vision

Work in the max-plus tropical semiring over `ℝ` (or better, `WithBot ℝ` if you want a true additive zero later). A tropical convex combination of points `v₁, …, v_k` is an expression
\[
x = \bigoplus_{i=1}^k \lambda_i \odot v_i
\]
with normalization
\[
\bigoplus_{i=1}^k \lambda_i = 0,
\]
which in max-plus means
\[
x_j = \max_i (\lambda_i + (v_i)_j), \qquad \max_i \lambda_i = 0.
\]

The field-opening theorem is a **finite-generator = finite-inequality** correspondence for a Lean-friendly class of tropical convex sets, followed by an **algorithmic solvability theorem** reducing a tropical feasibility problem to shortest-path / Bellman–Ford style closure. That already creates a rigorous bridge to combinatorial optimization, static analysis, discrete event systems, and game semantics.

## Precise Theorem Targets

You should not try to formalize the full generality of tropical polyhedra on day one. Instead, prove a sharp finite-dimensional theorem for a tractable fragment that still deserves the name “tropical Minkowski–Weyl.”

### Target 1: Tropical segment convexity and finite generation

Define tropical scaling and tropical addition on vectors `Fin n → ℝ` by
- scalar action: `(a •ₜ x) i = a + x i`
- tropical sum: `(x ⊕ₜ y) i = max (x i) (y i)`

Then define the tropical convex hull of a finite set `S`.

**Theorem statement**
For every finite family `V : Fin m → (Fin n → ℝ)`, the tropical convex hull generated by `V` is tropically convex and every element admits a normalized finite tropical barycentric representation.

A Lean-style target:
```lean
def tscale {n : ℕ} (a : ℝ) (x : Fin n → ℝ) : Fin n → ℝ := fun i => a + x i
def tadd   {n : ℕ} (x y : Fin n → ℝ) : Fin n → ℝ := fun i => max (x i) (y i)

def IsTropConvex {n : ℕ} (C : Set (Fin n → ℝ)) : Prop :=
  ∀ ⦃x y : Fin n → ℝ⦄, x ∈ C → y ∈ C →
    ∀ a b : ℝ, max a b = 0 →
      tadd (tscale a x) (tscale b y) ∈ C

def TropConvHull {n m : ℕ} (V : Fin m → Fin n → ℝ) : Set (Fin n → ℝ) :=
  {x | ∃ λ : Fin m → ℝ,
      (∀ i, x i = Finset.univ.sup fun j : Fin m => λ j + V j i) ∧
      Finset.univ.sup λ = 0}

theorem tropConvHull_isTropConvex
    {n m : ℕ} (V : Fin m → Fin n → ℝ) :
    IsTropConvex (TropConvHull V) := by
  sorry
```

This is foundational, but not yet revolutionary. The revolution begins when you prove a **Carathéodory-type compression** or finite support normalization lemma in a reusable form.

### Target 2: Tropical Minkowski–Weyl for alcoved / difference-constraint polyhedra

The strongest Lean-feasible theorem here is not the full arbitrary tropical halfspace theorem, but the important special case of **alcoved tropical polyhedra**: sets cut out by coordinate difference constraints
\[
x_i - x_j \le c_{ij}.
\]
These are simultaneously:
- tropical convex,
- classically convex,
- graph-theoretic,
- algorithmically tractable.

Define:
```lean
def DiffConstraintPolyhedron {n : ℕ} (c : Fin n → Fin n → ℝ) : Set (Fin n → ℝ) :=
  {x | ∀ i j, x i - x j ≤ c i j}
```

Then target:

```lean
theorem diffConstraint_tropConvex
    {n : ℕ} (c : Fin n → Fin n → ℝ) :
    IsTropConvex (DiffConstraintPolyhedron c) := by
  sorry
```

Now the genuine Minkowski–Weyl-style theorem:

```lean
theorem diffConstraint_finitelyGenerated
    {n : ℕ} (c : Fin n → Fin n → ℝ)
    (hclosed : ∀ i, c i i = 0)
    (htri : ∀ i j k, c i k ≤ c i j + c j k) :
    ∃ m (V : Fin m → Fin n → ℝ),
      DiffConstraintPolyhedron c = TropConvHull V := by
  sorry
```

Interpretation: every closed system of tropical difference inequalities is the tropical convex hull of finitely many generators. This is the right first formal tropical Minkowski–Weyl theorem because:
1. it is mathematically nontrivial,
2. it has a graph closure interpretation,
3. it is algorithmic,
4. it is a gateway to full tropical polyhedra.

If equality is too hard, prove two inclusions first:
- every generator satisfies the inequalities,
- every feasible point is a tropical combination of canonical extremal columns derived from `c`.

A canonical candidate generator family is given by the columns of the Kleene star / closure matrix of `c`.

### Target 3: Polynomial-time solvability of tropical feasibility

Avoid making unverifiable complexity-theoretic claims in Lean unless you define a concrete executable algorithm and prove correctness plus a step-bound for a natural cost model. The right formal theorem is:

- define a finite system of inequalities `x_i ≤ a + x_j`,
- define graph relaxation / Bellman–Ford closure,
- prove feasibility iff no negative cycle in the associated weighted digraph,
- derive a computable witness assignment.

```lean
    {n : ℕ} (E : Finset (Fin n × Fin n × ℝ)) :

```

### Target 4: Reduction bridge to mean payoff games

Do not overclaim “tropical linear programming is solvable in polynomial time” in full generality unless you mean the difference-constraint fragment. For general tropical linear feasibility, the celebrated connection is to mean payoff games, and polynomial-time solvability is open in full generality. The breakthrough is to formalize the reduction itself.

A realistic theorem target:
```lean
theorem tropical_affine_feasibility_reduces_to_mean_payoff
    {m n : ℕ} (A B : Matrix (Fin m) (Fin n) ℝ) :
    ∃ G : MeanPayoffGame,
      (∃ x : Fin n → ℝ, ∀ i, (Finset.univ.sup fun j => A i j + x j)
                           ≤ (Finset.univ.sup fun j => B i j + x j))
      ↔ PlayerMaxHasNonnegativeValue G := by
  sorry
```

This theorem is ambitious. If too large, first formalize the operator
\[
(Tx)_i = \min_j(-A_{ji} + \max_k(B_{jk}+x_k))
\]
or its max-plus dual and prove monotonicity / additively homogeneous structure. That is already the nonlinear Perron–Frobenius doorway to mean payoff games.

## Proof Strategy Architecture

### Strategy A: Graph-theoretic closure via difference bounds matrices
Most promising for the Minkowski–Weyl fragment.

1. Represent a tropical inequality system as a weighted directed graph with edge `j → i` of weight `a` encoding `x_i ≤ a + x_j`.
2. Use transitive closure / shortest-path inequalities to replace the raw system by its canonical closure `c`.
3. Show the feasible set equals the tropical convex hull of the columns of `c` (or a normalized variant).

Why this is strongest:
- It gives both geometry and algorithmics at once.
- It aligns with Bellman–Ford/Floyd–Warshall style proofs already natural in finite combinatorics.
- It opens a direct path to certified optimization software.

### Strategy B: Residuation and max-plus linear algebra
Most conceptually elegant for the bridge to mean payoff games.

1. Formalize tropical matrix-vector action:
   \[
   (A \otimes x)_i = \max_j (A_{ij} + x_j).
   \]
2. Recast feasibility as a residuated inequality `A ⊗ x ≤ B ⊗ x`.
3. Use monotone homogeneous operators, fixed points, and Collatz–Wielandt-type arguments to connect to game value.

Why this matters:
- It unifies tropical LP, dynamic programming, and spectral theory.
- It positions the development for later work on tropical eigenvectors and control.

### Strategy C: Polyhedral decomposition / normalized representatives
Best for finite-generation proofs if direct equality is difficult.

1. Normalize points modulo additive constants, e.g. impose `x 0 = 0` or `sup_i x_i = 0`.
2. Show the feasible set in normalized coordinates is classically compact and cut out by finitely many linear inequalities.
3. Identify extremal normalized points and prove every feasible point is their tropical convex combination.

Why this is useful:
- It avoids some semiring abstraction overhead.
- It may let you exploit existing `Convex` infrastructure in Mathlib where appropriate, even though the end theorem is tropical.

## Cross-Domain Connections You Must Exploit

### 1. Graph algorithms / shortest paths
Difference constraints are shortest-path dual objects. This is the cleanest algorithmic interpretation of tropical convex feasibility.

### 2. Static analysis and verification
Difference bound matrices are central in timed automata and abstract interpretation. A certified tropical polyhedron library would immediately support machine-checked invariant generation.

### 3. Mean payoff games and dynamic programming
Tropical affine inequalities are Bellman operators in disguise. This is the major conceptual bridge. It opens contact with algorithmic game theory and complexity theory.

### 4. Discrete event systems
Max-plus linear systems model synchronization networks, manufacturing systems, and train timetabling. Tropical convex sets are reachable-region objects there.

### 5. Nonlinear Perron–Frobenius theory
The operator-theoretic viewpoint links tropical optimization to eigenproblems, ergodic control, and asymptotic growth rates.
