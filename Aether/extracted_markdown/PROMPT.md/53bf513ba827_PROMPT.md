## Research Task: Finite-ball subgroup avoidance and generic-group lower-bound transfer for the Berggren/SPB embedding in `SL₂(ℤ)`

Research Mode: PROVE

Work with the positive Berggren semigroup `S ⊂ SL(2, ℤ)` generated by the three already formalized SPB/Berggren matrices. The goal is to strengthen finite-quotient injectivity into a usable *finite-ball rigidity theorem* and then derive a clean algebraic consequence for generic-group style discrete-log attacks on reduced Berggren images.

You should aim to prove one main algebraic theorem and one transfer theorem, together with the supporting lemmas needed to make the proof modular.

### Concrete theorem layer 1: finite-ball injectivity on quotient-differences

A good first target is a theorem of the following shape.

```lean
theorem berggren_ball_mod_injective_on_pairwise_differences
    (R : ℕ) :
    ∃ N : ℕ, 2 ≤ N ∧
      ∀ {x y z w : SL(2, ℤ)},
        x ∈ berggrenBall R →
        y ∈ berggrenBall R →
        z ∈ berggrenBall R →
        w ∈ berggrenBall R →
        ((x : Matrix (Fin 2) (Fin 2) ℤ) * y⁻¹ =
         (z : Matrix (Fin 2) (Fin 2) ℤ) * w⁻¹) ↔
        (Matrix.map (Int.castRingHom (ZMod N)) ((x : Matrix (Fin 2) (Fin 2) ℤ)) *
           (Matrix.map (Int.castRingHom (ZMod N)) ((y : Matrix (Fin 2) (Fin 2) ℤ)))⁻¹ =
         Matrix.map (Int.castRingHom (ZMod N)) ((z : Matrix (Fin 2) (Fin 2) ℤ)) *
           (Matrix.map (Int.castRingHom (ZMod N)) ((w : Matrix (Fin 2) (Fin 2) ℤ)))⁻¹)
```

If the exact coercions for `SL(2, ℤ)` into matrices are awkward, it is completely acceptable to formulate this first for the underlying matrix representatives of determinant `1`, e.g. with a finite set
```lean
pairwiseQuotientSet R :
  Finset (Matrix (Fin 2) (Fin 2) ℤ)
```
defined from the ball by
```lean
{x * y⁻¹ | x,y ∈ berggrenBall R}.
```

Then prove a more combinatorial version:

```lean
theorem exists_modulus_injective_on_pairwiseQuotientSet
    (R : ℕ) :
    ∃ N : ℕ, 2 ≤ N ∧
      Set.InjOn
        (fun M : Matrix (Fin 2) (Fin 2) ℤ =>
          Matrix.map (Int.castRingHom (ZMod N)) M)
        (↑(pairwiseQuotientSet R) : Set (Matrix (Fin 2) (Fin 2) ℤ))
```

This is the right finite-ball strengthening: equality of reduced quotients already forces equality of the original quotients, which is exactly what later lets one lift generic-group collisions back to honest semigroup relations.

### Concrete theorem layer 1b: subgroup-witness avoidance via injectivity on powers

The “proper cyclic subgroup witness” should be made mathematically precise in a way that is Lean-friendly and still strong enough for the transfer argument. A robust formulation is to forbid accidental *short power collisions* among quotient elements.

Define a bounded witness predicate such as:

```lean
def HasShortPowerCollisionMod (N K : ℕ)
    (g : Matrix (Fin 2) (Fin 2) (ZMod N)) : Prop :=
  ∃ a b : ℕ, a < b ∧ b ≤ K ∧ g ^ a = g ^ b
```

and then prove:

```lean
theorem berggren_ball_quotient_no_short_power_collision
    (R K : ℕ) :
    ∃ N : ℕ, 2 ≤ N ∧
      ∀ {x y : SL(2, ℤ)},
        x ∈ berggrenBall R →
        y ∈ berggrenBall R →
        x ≠ y →
        ¬ HasShortPowerCollisionMod N K
          ((Matrix.map (Int.castRingHom (ZMod N))
             (((x : Matrix (Fin 2) (Fin 2) ℤ) * y⁻¹))) )
```

A slightly weaker but easier-to-prove alternative is enough if exponentiation of arbitrary quotient matrices is cumbersome:

```lean
theorem berggren_ball_quotient_powers_injective_up_to
    (R K : ℕ) :
    ∃ N : ℕ, 2 ≤ N ∧
      ∀ {x y : SL(2, ℤ)} {a b : ℕ},
        x ∈ berggrenBall R →
        y ∈ berggrenBall R →
        x ≠ y →
        a ≤ K →
        b ≤ K →
        (Matrix.map (Int.castRingHom (ZMod N))
          ((((x : Matrix (Fin 2) (Fin 2) ℤ) * y⁻¹)) ^ a)) =
        (Matrix.map (Int.castRingHom (ZMod N))
          ((((x : Matrix (Fin 2) (Fin 2) ℤ) * y⁻¹)) ^ b)) →
        a = b
```

This realizes the “subgroup avoidance” request in a precise finite-ball sense: no reduced quotient element coming from two distinct radius-`R` Berggren elements can masquerade as an element of unexpectedly small cyclic order up to the chosen cutoff `K`.

### Key proof strategy for layer 1

1. **Finiteness of the relevant witness set.**  
   Show that `berggrenBall R` is finite, hence the set
   ```lean
   Q(R,K) = { ((x * y⁻¹)^a, (x * y⁻¹)^b) | x,y ∈ berggrenBall R, x ≠ y, a,b ≤ K, a ≠ b }
   ```
   is finite. The theorem then reduces to separating finitely many unequal integer matrices modulo a single modulus.

2. **Single modulus separating finitely many matrix inequalities.**  
   For any finite set `T` of pairwise distinct integer matrices, there exists `N ≥ 2` such that reduction mod `N` is injective on `T`. The standard proof is: for each distinct pair `M ≠ M'`, choose an entry where they differ; let `d(M,M') ≠ 0` be that integer difference; pick `N` avoiding all prime divisors of all such nonzero differences, for example any prime larger than the maximum absolute value of all entries appearing in all pairwise differences.  
   In Lean, it is often easier to prove a lemma:
   ```lean
   theorem exists_modulus_injective_on_finite_int_matrix_set
       (T : Finset (Matrix (Fin 2) (Fin 2) ℤ)) :
       ∃ N : ℕ, 2 ≤ N ∧
         Set.InjOn (fun M => Matrix.map (Int.castRingHom (ZMod N)) M) (↑T : Set _)
   ```
   using a large prime `p` with `p > maxEntryBound`.

3. **Power-collision avoidance is just injectivity on a larger finite set.**  
   To prove the “no short power collision” theorem, enlarge the finite set from pairwise quotients to all powers
   ```lean
   ((x * y⁻¹)^n)   with x,y ∈ berggrenBall R, x ≠ y, n ≤ K.
   ```
   Then injectivity of reduction on this finite set immediately forbids `a ≠ b` with equal reductions. This avoids needing any structure theory of finite cyclic subgroups.

4. **Use equality in the ambient group, not semigroup normal forms, at this stage.**  
   The algebraic heart is finite-set residual separation in `SL₂(ℤ)`, not growth estimates. Do not overcomplicate layer 1 by trying to classify subgroups of `SL₂(ZMod N)`. Bounded-order subgroup witnesses can be replaced by bounded power collisions, which are enough for the later generic-relation contradiction.

5. **If needed, derive matrix equality from group equality entrywise.**  
   You may need a small extensionality lemma saying that if two `2×2` integer matrices differ, then some entry differs, and reduction modulo a prime larger than the absolute value of that entry difference preserves non-equality.

### Concrete theorem layer 2: generic-relation lifting from finite quotient to semigroup rigidity

The cryptographic transfer should be stated algebraically, avoiding full probabilistic oracle formalization unless it is already available. The right abstraction is: any purported “short discrete-log solver” that uniformly outputs exponent relations on reduced Berggren-ball instances yields a forbidden short relation upstairs.

A precise and realistic theorem target is:

```lean
theorem reduced_relation_lifts_to_semigroup_relation
    (R K : ℕ) :
    ∃ N : ℕ, 2 ≤ N ∧
      ∀ {x y u v : SL(2, ℤ)} {a b : ℕ},
        x ∈ berggrenBall R →
        y ∈ berggrenBall R →
        u ∈ berggrenBall R →
        v ∈ berggrenBall R →
        a ≤ K →
        b ≤ K →
        (Matrix.map (Int.castRingHom (ZMod N))
          ((((x : Matrix (Fin 2) (Fin 2) ℤ) * y⁻¹)) ^ a)) =
        (Matrix.map (Int.castRingHom (ZMod N))
          ((((u : Matrix (Fin 2) (Fin 2) ℤ) * v⁻¹)) ^ b)) →
        (((x : Matrix (Fin 2) (Fin 2) ℤ) * y⁻¹) ^ a) =
        (((u : Matrix (Fin 2) (Fin 2) ℤ) * v⁻¹) ^ b)
```

This is the exact lifting statement needed in a generic-group lower-bound argument: any equality discovered in the reduced quotient among bounded-complexity expressions already held over the integers.

From this, derive a semigroup-specialized contradiction principle. For example:

```lean
theorem no_uniform_short_dlog_relation_on_reduced_ball
    (R K : ℕ) :
    ∃ N : ℕ, 2 ≤ N ∧
      ∀ (f : SL(2, ZMod N) → ℕ),
      (∀ {x y : SL(2, ℤ)},
          x ∈ berggrenBall R →
          y ∈ berggrenBall R →
          ∃ k ≤ K,
            Matrix.map (Int.castRingHom (ZMod N)) (y : Matrix (Fin 2) (Fin 2) ℤ) =
              (Matrix.map (Int.castRingHom (ZMod N)) (x : Matrix (Fin 2) (Fin 2) ℤ)) ^ k) →
      False
```

That exact formulation may be too strong globally; if so, weaken it to a contradiction principle saying that any such `f` would force two distinct bounded words or bounded quotient-powers to reduce to the same element, contradicting layer 1. The essential point is not to model a realistic algorithm, but to prove the *structural impossibility of universally valid short exponent extraction on the radius-`R` image*.

A more implementable alternative is to formalize a bounded-expression language and prove injective evaluation modulo `N` on that language up to complexity `K`. For example:

```lean
inductive WordExpr
| genA | genB | genC
| mul : WordExpr → WordExpr → WordExpr
| inv : WordExpr → WordExpr
| pow : WordExpr → ℕ → WordExpr
```

with a complexity measure `exprSize : WordExpr → ℕ`, and then prove:

```lean
theorem exists_modulus_injective_on_bounded_wordExprs
    (K : ℕ) :
    ∃ N : ℕ, 2 ≤ N ∧
      Set.InjOn
        (evalMod N)
        {e | exprSize e ≤ K ∧ e ∈ berggrenExprClosure}
```

This is a very clean generic-group surrogate: bounded symbolic manipulations in the reduced group cannot create new equalities not already present in `SL₂(ℤ)`.

### Key proof strategy for layer 2

1. **Reduce “algorithmic success” to a bounded equality of expressions.**  
   In generic-group arguments, every successful computation ultimately certifies an equality between two bounded symbolic expressions in the group operations. You do not need probabilistic oracle semantics to get a strong theorem: define a bounded class of quotient/power expressions and prove that any equality mod `N` among them lifts.

2. **Choose the modulus using the entire bounded expression set.**  
   For fixed `R` and `K`, the set of all expressions built from elements of `berggrenBall R` using at most `K` multiplications/inversions/powers is finite. Apply the same finite-set residual separation lemma as in layer 1. This gives a uniform modulus for *all* bounded relations simultaneously.

3. **Use quotient normalization to connect with semigroup equations.**  
   Once a reduced equality lifts to
   ```lean
   (x * y⁻¹)^a = (u * v⁻¹)^b
   ```
   multiply by suitable right factors and invoke the already established right-cancellation/common-right-multiple machinery to normalize it into a relation among positive Berggren words. This is where the SPB semigroup structure matters: equalities in the ambient group can often be converted into semigroup equalities after clearing denominators on the right.

4. **Contradict finite-ball injectivity or distinctness of normal forms.**  
   The endgame should be: a hypothetical short DLP relation gives a nontrivial equality between two distinct bounded semigroup words, or between two distinct bounded quotient-powers, but layer 1 chose `N` precisely to forbid such collapses modulo `N`.

5. **Keep the cryptographic theorem deterministic and structural.**  
   Avoid introducing randomness, probability monads, or complexity classes unless already present. The core mathematical content is a *lower-bound transfer by relation lifting*: no bounded generic manipulation in the finite quotient can succeed uniformly unless a bounded algebraic relation already existed in the Berggren semigroup.

### Why this matters

This theorem family would create a genuine bridge between the algebraic rigidity of the Berggren/SPB semigroup and finite-quotient cryptographic hardness heuristics. The existing finite-quotient injectivity results show only that distinct bounded words can survive reduction. What is needed for a meaningful DLP/DH interpretation is much stronger: *all bounded algebraic relations* seen in the reduced group should already be visible upstairs. That is exactly what the quotient-difference injectivity and bounded-expression lifting theorems provide.

Mathematically, this upgrades residual finiteness into a finite-ball model-theoretic rigidity statement for the Berggren semigroup inside `SL₂(ℤ)`. Cryptographically, it gives a rigorous generic-group style obstruction: any uniformly successful short discrete-log extraction on reduced Berggren instances would manufacture a forbidden short relation in the semigroup. This is the right formal stepping stone toward a serious SPB-based hardness framework, and it uses the project’s semigroup-specific cancellation/common-multiple theory in a nontrivial way rather than only ambient group facts.
