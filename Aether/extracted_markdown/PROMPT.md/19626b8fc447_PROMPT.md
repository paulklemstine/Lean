## Assignment: Direction 2 — Tropical Differential Entropy via Newton Shadows

**Mode:** `prove`

## Vision

Build a genuine theory of **discrete tropical entropy flow** for finite lattice supports under iterated shadow operators. The central ambition is not merely to count lattice points after repeated differentiation-like operations, but to show that Newton support erosion obeys an **information law** analogous to entropy dissipation in analysis and Brunn–Minkowski concavity in convex geometry.

This would open a new bridge between:

- **tropical geometry**: supports, Newton polytopes, shadow semigroups,
- **information theory**: entropy, entropy production, dissipation rates,
- **convex / discrete geometry**: lattice-point monotonicity, section growth, erosions,
- **algorithmic sparse algebra**: predicting symbolic complexity under repeated differentiation.

The conjectural picture is that iterated tropical shadowing behaves like a discrete geometric flow, and the logarithm of support cardinality behaves like a combinatorial entropy. If this can be formalized even in a sharp finite-set model, it creates a platform for future tropical analogues of entropy power inequalities, data processing inequalities, and discrete curvature bounds.

## Core objects to define

You should introduce at least one genuinely new definition beyond the catalog material in `Pythagorean/IteratedShadowGeometry.lean`.

### New definition 1: tropical shadow entropy
For a finite support set `S : Finset (Fin n → ℕ)` and `k : ℕ`, define
\[
H_S(k) := \log \bigl| \operatorname{Sh}_k(S) \bigr|,
\]
with the convention that if the `k`-th shadow is empty then the entropy is `0` or is handled via an `Option`/truncated definition. In Lean, it is probably cleaner to define the raw cardinal profile first and then define the logarithmic entropy only on nonempty shadows.

Suggested Lean skeleton:
```lean
def shadowCard (S : Finset (Fin n → ℕ)) (k : ℕ) : ℕ :=
  ((kthShadow S k).card)

def shadowEntropy (S : Finset (Fin n → ℕ)) (k : ℕ) : ℝ :=
  Real.log (shadowCard S k)
```
You may want a protected variant ensuring positivity:
```lean
def shadowEntropyPos (S : Finset (Fin n → ℕ)) (k : ℕ) : ℝ :=
  Real.log ((shadowCard S k : ℝ) + 1)
```
The `+1` version is often the right formal object for unconditional theorems.

### New definition 2: tropical entropy drop
\[
\Delta H_S(k) := H_S(k+1) - H_S(k).
\]
Lean:
```lean
def shadowEntropyDrop (S : Finset (Fin n → ℕ)) (k : ℕ) : ℝ :=
  shadowEntropyPos S (k+1) - shadowEntropyPos S k
```

### New definition 3: compressed / downward-closed support class
To obtain nontrivial theorems, define a class of finite supports where shadow behavior is rigid enough to prove concavity-type statements. A promising notion is:

- `DownwardClosed S`: whenever `a ∈ S` and `b ≤ a` coordinatewise, then `b ∈ S`.

This is the discrete monomial-ideal / order-ideal setting and is likely the right proving ground.

Lean:
```lean
def DownwardClosed (S : Finset (Fin n → ℕ)) : Prop :=
  ∀ ⦃a b : Fin n → ℕ⦄, a ∈ S → (∀ i, b i ≤ a i) → b ∈ S
```

This is a major conceptual move: for downward-closed supports, iterated shadowing should coincide with “degree truncation from above” or erosion by total degree, making the entropy theory tractable.

## Precise theorem targets

You should prove at least 3 substantial theorems. The first theorem should be a structural exact formula or inclusion theorem; the second should establish monotonicity / finite dissipation; the third should be a genuine concavity theorem under a meaningful hypothesis.

### Theorem 1: semigroup-driven monotonicity of entropy
Using the catalog semigroup law for shadows, prove that shadow cardinality is nonincreasing in the shadow time parameter, hence entropy is nonincreasing.

Mathematical statement:
\[
\forall S,\ \forall a,b \in \mathbb{N},\quad \operatorname{Sh}_{a+b}(S)\subseteq \operatorname{Sh}_a(S),
\]
and therefore
\[
H_S(a+b)\le H_S(a)
\]
for the `log(card+1)` entropy.

Suggested Lean theorem:
```lean
theorem shadowCard_mono_add
    (S : Finset (Fin n → ℕ)) (a b : ℕ) :
    shadowCard S (a + b) ≤ shadowCard S a
```

and then
```lean
theorem shadowEntropyPos_antitone
    (S : Finset (Fin n → ℕ)) :
    Antitone (shadowEntropyPos S)
```

Why this matters: this theorem upgrades the existing semigroup law from a combinatorial identity to a **thermodynamic arrow of time**. It is the minimum viable entropy law for tropical differentiation.

### Theorem 2: finite extinction and total entropy dissipation
Define the maximal total degree of a support:
\[
D(S) := \max_{u\in S} \sum_i u_i.
\]
Prove that after more than `D(S)` shadow steps, the support vanishes (or stabilizes to the empty set / singleton base layer depending on the exact shadow definition). Hence the entropy flow has finite lifetime.

Suggested Lean definitions:
```lean
def totalDegree (u : Fin n → ℕ) : ℕ := ∑ i, u i

def supportMaxDegree (S : Finset (Fin n → ℕ)) : ℕ :=
  S.sup totalDegree
```

Target theorem:
```lean
theorem kthShadow_eq_empty_of_supportMaxDegree_lt
    (S : Finset (Fin n → ℕ)) {k : ℕ}
    (hk : supportMaxDegree S < k) :
    kthShadow S k = ∅
```

Entropy corollary:
```lean
theorem shadowEntropyPos_eventually_zero
    (S : Finset (Fin n → ℕ)) :
    ∃ D, ∀ k ≥ D, shadowEntropyPos S k = 0
```
or with the `+1` convention, eventually `Real.log 1 = 0`.

Why this matters: this identifies tropical entropy dissipation as a **finite-time extinction phenomenon**, analogous to extinction in geometric flows and nonlinear PDE.

### Theorem 3: discrete concavity for downward-closed supports
This is the breakthrough theorem to aim for.

For a downward-closed finite support `S`, prove that the shadow cardinality profile is log-concave:
\[
|\operatorname{Sh}_{k+1}(S)|^2 \ge |\operatorname{Sh}_k(S)|\,|\operatorname{Sh}_{k+2}(S)|
\]
for all admissible `k`. Consequently,
\[
H_S(k+1)-H_S(k)\ \ge\ H_S(k+2)-H_S(k+1),
\]
so the entropy drop is nonincreasing and `H_S` is discrete concave.

Lean target:
```lean
theorem shadowCard_logConcave_of_downwardClosed
    (S : Finset (Fin n → ℕ))
    (hS : DownwardClosed S) :
    ∀ k : ℕ,
      (shadowCard S (k+1) : ℤ)^2 ≥
        (shadowCard S k : ℤ) * (shadowCard S (k+2) : ℤ)
```

Entropy version:
```lean
theorem shadowEntropyDrop_antitone_of_downwardClosed
    (S : Finset (Fin n → ℕ))
    (hS : DownwardClosed S) :
    Antitone (shadowEntropyDrop S)
```

If the full theorem is too difficult at first, prove it for one of these high-value subclasses:

1. supports of the form `{u | totalDegree u ≤ d}` inside `Fin n → ℕ`,
2. box supports `{u | ∀ i, u i ≤ a i}`,
3. Cartesian products of intervals,
4. simplicial supports.

Any of these would already be mathematically meaningful and nontrivial.

Why this is a breakthrough: it would be the first rigorous statement that **iterated tropical differentiation obeys a discrete second law with diminishing marginal information loss**, making the Brunn–Minkowski analogy precise in a finite combinatorial setting.

### Cross-domain theorem A: order ideals and Hilbert functions
For downward-closed `S`, define the degree layer count
\[
L_S(t) := |\{u\in S : \deg(u)=t\}|.
\]
Show that `shadowCard S k` equals the cumulative Hilbert function tail:
\[
|\operatorname{Sh}_k(S)| = \sum_{t\ge k} L_S(t)
\]
or an equivalent exact formula depending on the shadow definition in the catalog.

Lean target:
```lean
def degreeLayerCard (S : Finset (Fin n → ℕ)) (t : ℕ) : ℕ :=
  ((S.filter (fun u => totalDegree u = t)).card)

theorem shadowCard_eq_degreeTail_of_downwardClosed
    (S : Finset (Fin n → ℕ))
    (hS : DownwardClosed S) :
    ∀ k : ℕ,
      shadowCard S k = ∑ t in Finset.range (supportMaxDegree S + 1), 
        if k ≤ t then degreeLayerCard S t else 0
```

This is a bridge from tropical geometry to commutative algebra: the entropy profile becomes an integrated Hilbert function. That is field-opening.

### Cross-domain theorem B: isoperimetric interpretation

with the magnitude controlled by the size of a boundary layer. This connects to discrete isoperimetry / surface-to-volume heuristics.

## Proof architecture: 3 possible strategies

You must not rely on trivial automation. Use induction, `rcases`, `by_contra`, multi-step `calc`, and where needed `field_simp` for logarithmic inequalities after positivity reductions.

### Strategy A — Degree-layer decomposition via downward-closed supports
**Most promising.**

1. Define total degree and prove that one shadow step lowers maximal degree by at least one.
2. For downward-closed supports, identify `kthShadow S k` with the subset of elements of degree at least `k`, shifted/eroded appropriately depending on the catalog shadow definition.
3. Rewrite `shadowCard S k` as a tail sum of degree-layer counts.
4. Prove discrete concavity from tail-sum structure, ideally using known log-concavity / unimodality of degree layers for boxes or simplices, or by direct combinatorial injection.

Why promising: it converts a geometric-flow problem into a sequence problem. Once the shadow profile is a tail of layer counts, entropy inequalities become one-dimensional.

### Strategy B — Semigroup + cardinal submultiplicativity / injection argument
1. Use `kthShadow_add` from the catalog to express deeper shadows as iterated applications.
2. Construct explicit injections or surjections between boundary layers of `Sh_k(S)`, `Sh_{k+1}(S)`, and `Sh_{k+2}(S)`.
3. Derive a cardinal inequality resembling Newton/Maclaurin inequalities for the profile.

Why promising: this stays closest to the catalog and may generalize beyond downward-closed sets. It is harder but more revolutionary if it works.

### Strategy C — Exact formulas for model polytopes, then abstract closure
1. Start with canonical supports:
   - simplex supports `deg(u) ≤ d`,
   - box supports `u i ≤ a i`.
2. Derive explicit formulas:
   - simplex: binomial coefficients,
   - box: products of truncated linear terms or coefficient extractions.
3. Prove log-concavity of these formulas using binomial coefficient inequalities and `calc` chains.
4. Then abstract to products / images / compressed supports.

Why promising: gives concrete breakthrough theorems quickly and supports the computational conjecture. Best fallback if the full downward-closed theorem is too ambitious in one cycle.
