### Core objects to define

- `P`: prompt feature states
- `Q`: output quality states

Interpret:
- `p ∈ P` as a structured prompt specification

- `eval : P →o Q`  — prompt-to-quality evaluation
- `back : Q →o P`  — quality-to-required-prompt reconstruction

The decisive condition is a **Galois connection**
\[
\forall p : P,\ \forall q : Q,\quad eval(p) \le q \iff p \le back(q).
\]

From this derive:
- the closure operator on prompts `clP = back ∘ eval`
- the interior operator on qualities `intQ = eval ∘ back`

The mathematical thesis is that **optimal prompts are exactly the fixed points of `clP`**, equivalently the objects satisfying the universal property induced by the adjunction.

## Exact Theorem Statements

### Theorem A: Prompt optimization as a closure system
Let `P, Q` be finite complete lattices, and let `eval : P →o Q`, `back : Q →o P` form a Galois connection. Then:

1. `clP := back ∘ eval` is monotone, inflationary, and idempotent.
2. The subtype of closed prompts
   \[
   \mathrm{Closed}(clP) := \{p : P \mid clP(p)=p\}
   \]
   is itself a complete lattice.
3. For every `p : P`, `clP p` is the **least optimal prompt above** `p`.

This is the universal property you should emphasize:
\[
clP(p) \text{ is closed},\quad p \le clP(p),\quad
\forall p',\ p \le p' \land clP(p')=p' \Rightarrow clP(p) \le p'.
\]

### Theorem B: Adjunction computes optimal prompts
Under the same hypotheses, prove:
\[
p \text{ is optimal } \iff \exists q,\ p = back(q)\ \land\ eval(back(q)) = q
\]
or, more robustly,
\[
p \text{ is optimal } \iff clP(p)=p.
\]

This identifies “optimal prompt” not with a heuristic score maximum, but with a **reflective object** under the adjunction.

### Theorem C: Finite convergence of iterative adjunction
Assume `P` is finite. Define
\[
p_{n+1} := clP(p_n).
\]
Then for every initial `p₀ : P`, there exists `N ≤ Fintype.card P` such that
\[
p_N = p_{N+1},
\]
hence the sequence stabilizes at an optimal prompt.

A stronger theorem is available if you formulate iteration on a finite lattice height:
\[
\exists N \le \mathrm{height}(P),\quad clP^{[N]}(p)=clP^{[N+1]}(p).
\]

### Theorem D: Alternating prompt-quality optimization reaches the same fixed point
Define the alternating process:
- `q_n := eval(p_n)`
- `p_{n+1} := back(q_n)`

Then `p_{n+1} = clP(p_n)`, so the alternating optimization converges to the same closed prompt as Theorem C.

This theorem is conceptually important: it upgrades “iterative prompt engineering” into a provably terminating adjoint dynamics.
