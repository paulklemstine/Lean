## Core Definitions to Introduce

Work on `ℕ` with values in `WithTop ℕ` or `ℕ∞`-style costs. Define the tropical indicator of a set `A : Set ℕ` by
- cost `0` on `A`,
- cost `⊤` off `A`.

Then define min-plus convolution:
- `(f ⋆ₜ g) n = inf_{a+b=n} (f a + g b)`.

For subsets, this should collapse to the exact additive-combinatorial statement:
- the convolution is `0` iff `n ∈ A + B`,
- otherwise `⊤`.

This is the right formal skeleton.

A good Lean 4 setup is:

```lean
def tropInd (A : Set ℕ) : ℕ → WithTop ℕ
| n => if n ∈ A then 0 else ⊤

def tropConv (f g : ℕ → WithTop ℕ) : ℕ → WithTop ℕ
| n => sInf {c | ∃ a b : ℕ, a + b = n ∧ c = f a + g b}
```

You may prefer a finite infimum over `Finset.range (n+1)` to avoid set-theoretic pain:

```lean
def tropConvNat (f g : ℕ → WithTop ℕ) (n : ℕ) : WithTop ℕ :=
  ((Finset.range (n+1)).image (fun a => f a + g (n - a))).inf'
    (by
      refine ⟨0, ?_⟩
      simp)
```

Or, more robustly:

```lean
def tropConvNat (f g : ℕ → WithTop ℕ) (n : ℕ) : WithTop ℕ :=
  Finset.inf (Finset.range (n+1)) (fun a => f a + g (n - a))
```

depending on available `Finset.inf` lemmas for `WithTop ℕ`.

For primes, define:

```lean
def primeCost : ℕ → WithTop ℕ
| n => if Nat.Prime n then 0 else ⊤
```

and the tropical Goldbach function:

```lean
def goldbachTrop (n : ℕ) : WithTop ℕ :=
  tropConvNat primeCost primeCost n
```

## Precise Theorem Targets

### Theorem 1: Exact tropical-additive equivalence
This is the foundational theorem. It is genuinely formalizable and important.

**Mathematical statement.**  
For any `A B : Set ℕ` and any `n : ℕ`,
\[
(\tropInd(A) ⋆ₜ \tropInd(B))(n) = 0 \iff \exists a\in A,\ \exists b\in B,\ a+b=n.
\]
Moreover,
\[
(\tropInd(A) ⋆ₜ \tropInd(B))(n) = \top \iff \neg \exists a\in A,\ \exists b\in B,\ a+b=n.
\]

**Lean 4 type signature sketch.**
```lean
theorem tropInd_tropConv_eq_zero_iff
    (A B : Set ℕ) (n : ℕ) :
    tropConvNat (tropInd A) (tropInd B) n = 0 ↔
      ∃ a b : ℕ, a ∈ A ∧ b ∈ B ∧ a + b = n

theorem tropInd_tropConv_eq_top_iff
    (A B : Set ℕ) (n : ℕ) :
    tropConvNat (tropInd A) (tropInd B) n = ⊤ ↔
      ¬ ∃ a b : ℕ, a ∈ A ∧ b ∈ B ∧ a + b = n
```

**Why this is a breakthrough.**  
This theorem turns additive representation theory of subsets of `ℕ` into tropical linear algebra. It gives a certified translation layer between classical additive combinatorics and idempotent analysis. Once this exists in Lean, every theorem about sumsets can be reinterpreted as a theorem about tropical convolution minima. This opens a formal bridge to optimization, tropical geometry, automata, and semiring methods.

### Theorem 2: Goldbach is exactly the vanishing of a tropical prime convolution
Do not claim to prove Goldbach; prove the exact equivalence.

**Mathematical statement.**  
For every even `n > 2`,
\[
\text{Goldbach}(n) \iff goldbachTrop(n)=0.
\]
Equivalently,
\[
(\forall n>2,\ Even(n)\to goldbachTrop(n)=0)
\iff
(\forall n>2,\ Even(n)\to \exists p q,\ Nat.Prime\,p \land Nat.Prime\,q \land p+q=n).
\]

**Lean 4 type signature sketch.**
```lean
theorem goldbach_tropical_equiv_pointwise (n : ℕ) :
    goldbachTrop n = 0 ↔
      ∃ p q : ℕ, Nat.Prime p ∧ Nat.Prime q ∧ p + q = n

theorem goldbach_conjecture_iff_tropical :
    (∀ n : ℕ, 2 < n → Even n → goldbachTrop n = 0) ↔
    (∀ n : ℕ, 2 < n → Even n →
      ∃ p q : ℕ, Nat.Prime p ∧ Nat.Prime q ∧ p + q = n)
```

**Why this matters.**  
This is the correct formal statement behind the user’s vision. It isolates exactly what a tropical reformulation can and cannot do. It also gives a reusable specification theorem: future prime-distribution hypotheses can now be imported as statements about tropical costs.

### Theorem 3: Counterexample to naive “bounded tropical Goldbach function”
If the tropical Goldbach function takes values in `{0, ⊤}`, then “bounded” is false unless Goldbach is true. Prove this explicitly.

**Mathematical statement.**  
If there exists an even `n > 2` not representable as a sum of two primes, then `goldbachTrop n = ⊤`; hence `goldbachTrop` is not bounded above by any finite natural-valued cost function on all even `n > 2`.

**Lean 4 type signature sketch.**
```lean
theorem not_bounded_of_goldbach_counterexample
    (n : ℕ) (hgt : 2 < n) (he : Even n)
    (h : ¬ ∃ p q : ℕ, Nat.Prime p ∧ Nat.Prime q ∧ p + q = n) :
    goldbachTrop n = ⊤
```

and perhaps

```lean
theorem no_finite_bound_if_counterexample_exists
    (h : ∃ n : ℕ, 2 < n ∧ Even n ∧
      ¬ ∃ p q : ℕ, Nat.Prime p ∧ Nat.Prime q ∧ p + q = n) :
    ¬ ∃ C : ℕ, ∀ n : ℕ, 2 < n → Even n → goldbachTrop n ≤ C
```

after embedding `ℕ` into `WithTop ℕ`.

**Why this matters.**  
This theorem prevents a false research direction from contaminating the formal development. It also sharpens the meaning of “boundedness”: with `0/⊤` costs, boundedness is equivalent to universal representability. That is a conceptual correction with real scientific value.

### Theorem 4: Unconditional replacement — cofinite sets have eventually zero tropical self-convolution
This is where the real additive combinatorics begins.

**Mathematical statement.**  
If `A ⊆ ℕ` is cofinite, then there exists `N` such that for all `n ≥ N`,
\[
(\tropInd(A) ⋆ₜ \tropInd(A))(n)=0.
\]
A sharp explicit bound should be extracted from the finite exceptional set.

**Lean 4 type signature sketch.**
```lean
theorem tropConv_self_eventually_zero_of_finite_compl
    (A : Set ℕ)
    (hA : (Aᶜ).Finite) :
    ∃ N : ℕ, ∀ n : ℕ, N ≤ n → tropConvNat (tropInd A) (tropInd A) n = 0
```

A stronger finite-exception quantitative version:
```lean
theorem tropConv_self_eventually_zero_of_bounded_compl
    (A : Set ℕ) (M : ℕ)
    (hA : ∀ n : ℕ, M ≤ n → n ∈ A) :
    ∀ n : ℕ, 2*M ≤ n → tropConvNat (tropInd A) (tropInd A) n = 0
```

**Why this is a breakthrough.**  
This theorem is the first unconditional tropical additive theorem of real content. It says eventual additive completeness is equivalent to eventual tropical vanishing. This opens a path to formalizing classical additive-combinatorial notions—basis of order 2, asymptotic basis, Schnirelmann-type phenomena—inside tropical semiring language.

### Theorem 5: Finite interval Cauchy–Davenport-style tropical lower bound
Since primes are hard, prove a finite combinatorial theorem that showcases the machinery.

For finite sets `A B ⊆ {0,…,N}`, define truncated tropical indicators and prove a support-size lower bound on where the tropical convolution vanishes, using sumset cardinality estimates.

**Mathematical statement.**  
For finite nonempty `A, B ⊆ ℕ`, the zero set of `tropInd(A) ⋆ₜ tropInd(B)` has cardinality at least `|A+B|`; in interval-mod-`p` settings, recover Cauchy–Davenport:
\[
| \{n : (\tropInd(A)⋆ₜ\tropInd(B))(n)=0\} | \ge \min(p, |A|+|B|-1).
\]

This may be easier first over `ZMod p`.

**Lean 4 type signature sketch.**
```lean
theorem zero_locus_tropConv_card_eq_sumset_card
    (A B : Finset ℕ) :
    ((A +ᶠ B).card) =
      (((Finset.range (A.sup id + B.sup id + 2)).filter
        (fun n => tropConvNat (tropInd (↑A : Set ℕ)) (tropInd (↑B : Set ℕ)) n = 0)).card)
```

This exact signature will likely need adjustment, but the target is clear: identify the zero locus with the sumset.

**Why this matters.**  
It connects tropical convolution directly to additive combinatorics on finite sets and finite groups. This is where `tropical_sum_right_inv` may become useful if you port to finite groups and define tropical convolution there.

## Proof Strategy Architecture

### Strategy A: Direct finite decomposition on `n` via `Finset.range (n+1)`  
**Best first route.** It is elementary, Lean-friendly, and gives exact equivalence theorems.

1. Define tropical convolution at `n` by taking the infimum over all `a ≤ n` of `f a + g (n-a)`.
2. For `tropInd`, show each summand is either `0` or `⊤`.
3. Conclude the infimum is `0` iff at least one witness `a` yields both membership conditions; otherwise all summands are `⊤`, so the infimum is `⊤`.

Why this is most promising: it avoids abstract order-theoretic `sInf` machinery and stays inside finite combinatorics over `Nat`.

---

### Strategy B: Semiring/idempotent algebra abstraction  
After Theorem 1 is done concretely, generalize.

1. Abstract from `WithTop ℕ` to an idempotent ordered semiring-like structure where `inf` is tropical addition and ordinary addition is tropical multiplication.
2. Reinterpret subset indicators as characteristic vectors in a semimodule over the tropical semiring.
3. Show support of convolution equals Minkowski sum / additive support.

Why this matters: it upgrades the result from a one-off arithmetic lemma into a reusable bridge theorem for tropical representation theory and combinatorial optimization.

This is where catalog theorems like `tropical_min_comm` are conceptually aligned: commutativity of tropical minimum helps normalize convolution expressions.

---

### Strategy C: Finite-group model first, then specialize to `ℕ`  
Potentially powerful if Lean lemmas are easier over finite types.

1. Define tropical convolution on a finite abelian group `G`.
2. Use `tropical_sum_right_inv` and group inversion to prove support/convolution identities.
3. Transfer the philosophy back to truncated intervals in `ℕ`, or to `ZMod p` for Cauchy–Davenport-style statements.

Why this is promising: finite groups are where additive combinatorics and representation theory naturally meet, and the catalog already contains a tropical representation-theoretic theorem. This could become the true “bridge paper.”
