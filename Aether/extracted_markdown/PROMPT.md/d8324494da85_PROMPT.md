Formalize the following four theorems about the Laplacian matrix and Dirichlet energy of a finite simple graph in Lean 4, building on Mathlib.

## Setup
Given a finite type V with decidable equality and a simple graph G : SimpleGraph V with decidable edge relation, define:
- The degree of a vertex v : V as the number of neighbors of v
- The Laplacian matrix L : Matrix V V ℝ where L i i = degree G i and L i j = -1 if G.Adj i j, else 0
- The Dirichlet energy of f : V → ℝ as ∑_{(i,j) in edge set} (f i - f j)^2

## Theorems to prove (in order of dependency)

1. **laplacian_quadratic_form_eq_dirichlet_energy**: For all f : V → ℝ,
   (∑ i, ∑ j, f i * (L i j) * f j) = ∑_{(i,j) ∈ G.edgeSet} (f i - f j)^2
   This is the fundamental identity linking the algebraic and combinatorial views.

2. **laplacian_nonneg**: For all f : V → ℝ, ∑ i, ∑ j, f i * (L i j) * f j ≥ 0
   Prove this using theorem 1 plus the fact that each (f i - f j)^2 ≥ 0.

3. **laplacian_monotone_edge_add**: If G' is obtained from G by adding one edge {u,v}, then for all f, fᵀL'f ≥ fᵀLf. The difference is exactly (f u - f v)^2 ≥ 0.

4. **laplacian_null_iff_constant_on_components**: fᵀLf = 0 ↔ ∀ c ∈ connectedComponents, ∀ i j ∈ c, f i = f j. The forward direction uses that each squared difference must be 0, so f is constant along every edge, hence on each component. The reverse direction is immediate.

## Approach
- Use Mathlib's SimpleGraph, Matrix, and Finset APIs
- Start by proving the quadratic form expansion algebraically
- All proofs should be complete tactic proofs, not `sorry` or truncated
- Do NOT introduce tropical algebra, probability, social choice, or any unrelated mathematics
- Keep the file focused: one file, four theorems, complete proofs
