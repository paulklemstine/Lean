## Assignment: Alternative — Tropical Matrix Factorization is NP-Complete

**Mode:** `prove`

Prove a genuinely new complexity-theoretic bridge theorem formalizing that a natural tropical algebra decision problem is NP-complete via an explicit Karp reduction from a classical NP-hard problem with path/precedence structure. This should not be framed as a minor encoding exercise: the goal is to create the first Lean-certified gateway from tropical linear algebra into structural complexity and cryptographic hardness.

## Precise Breakthrough Target

Formalize a decision problem of **bounded tropical matrix factorization** and prove:

> **Theorem (informal).**  
> There exists a polynomial-time computable reduction from **Shortest Path with Forbidden Pairs** (or, if cleaner in Lean, Assignment with Precedence Constraints) to **tropical matrix factorization of fixed inner dimension**, such that an instance is satisfiable iff the constructed tropical matrix admits a factorization of the prescribed rank/shape. Consequently, bounded tropical factorization is NP-hard. If combined with a polynomial-time verifier for certificates `(A,B)`, it follows that bounded tropical factorization is NP-complete.

This is the right scale: not “tropical algebra is expressive,” but a certified theorem saying **tropical factorization is algorithmically universal enough to encode NP-hard combinatorial constraints**.

## Stronger Mathematical Statement to Aim For

The truly visionary version is:

> There exists a fixed integer `r ≥ 3` such that deciding whether an integer tropical matrix `M` has tropical factorization rank at most `r` is NP-complete.

In Lean-friendly form:

```lean
theorem trop_rank_le_fixed_r_NP_complete :
  ∃ r : ℕ, 3 ≤ r ∧
    NP_Complete
      (fun M : Σ n m, Matrix (Fin n) (Fin m) (WithTop ℤ) =>
        ∃ A B, tropMul A B = M.2 ∧
          A.ncols = r ∧ B.nrows = r)
```

Even a first version with variable `r` encoded in the instance would already be important; but if the reduction can be made with fixed inner dimension, that is a field-opening result.

## 2–3 Proof Strategy Paths

### Strategy A: Gadget matrix encoding of forbidden pairs via tropical minima
**Most promising.**

Build a matrix `M_I` whose entries encode path compatibility constraints so that any factorization `M_I = A ⊗ B` forces a decomposition into “choice columns” corresponding to admissible path segments. Forbidden pair violations are represented by tropical penalties (`⊤` or sufficiently large weights) that cannot participate in a minimum if the factorization is valid.

Core steps:
1. Encode vertices/edges/path states as rows and columns of `M_I`, with tropical products representing concatenation cost.
2. Use large-separation weights so admissible combinations uniquely realize minima, while forbidden pairs force impossible equalities.
3. Prove bidirectional correctness:
   - from a valid path, construct factors `A, B`;
   - from any factorization, extract a consistent path avoiding forbidden pairs.

Why promising: tropical multiplication is already a min-plus combinatorial optimizer; forbidden-pair constraints naturally become “certain minima must never be achieved.” This is conceptually aligned with the semiring.

### Strategy B: Reduce through tropical rank / biclique-cover style intermediate problem
Instead of reducing directly from forbidden pairs to factorization, pass through an intermediate combinatorial covering problem whose incidence matrix has known factorization semantics.

Core steps:
1. Formalize a Boolean or weighted covering problem equivalent to tropical factorization rank.
2. Show forbidden-pairs instances map to structured incidence matrices.
3. Lift Boolean cover solutions to tropical factorizations by embedding `{0,∞}` into `WithTop ℤ`.

Why promising: easier extraction lemmas; many hardness proofs for matrix factorization pass through rank/cover interpretations. This may be Lean-friendlier if direct path extraction becomes messy.

### Strategy C: Assignment-with-precedence reduction using schedule matrices
Use the assignment problem with precedence constraints directly. Jobs, agents, and precedence relations become row/column blocks; tropical factors encode feasible schedule layers and matching choices.

Core steps:
1. Define a block tropical matrix where finite entries represent compatible assignment-precedence pairs.
2. Show that rank-`r` factorization corresponds to selecting precedence-respecting assignment strata.
3. Use precedence violations to force contradiction in one block of the product.

Why promising: stronger optimization-to-algebra narrative, especially for cryptographic applications. Harder than Strategy A but potentially more elegant and more aligned with your original framing.

**Recommendation:** Start with Strategy A for a first theorem, then elevate to Strategy C in `FUTURE_DIRECTIONS.md`.

## Cross-Domain Connections You Should Make Explicit

### Computational Complexity → Tropical Geometry
Tropical factorization is a geometric decomposition problem over the min-plus semiring. Proving NP-hardness says tropical geometry carries the same algorithmic complexity as classical discrete optimization. This opens a formal theory of **tropical complexity geometry**.

### Computational Complexity → Cryptography
Once tropical factorization is NP-hard and tropical maps are noninvertible in the sense of `no_matrix_inverts_noninj_function`, one can formulate candidate **tropical one-way primitives** whose security is complexity-backed rather than heuristic.

### Optimization → Idempotent Linear Algebra
Assignment, precedence, and forbidden-pair constraints are optimization-native. Encoding them into tropical factorization demonstrates that idempotent linear algebra is a universal language for constrained combinatorics.

### Semiring Algebra → Proof Complexity / SAT Encodings
The reduction will likely create conjunction gadgets and exclusivity gadgets. This hints at a future formal correspondence between **CNF satisfiability gadgets** and **tropical rank constraints**.

### Tropical Mathematics → Network Science / Scheduling
Assignment with precedence is scheduling-theoretic; shortest path with forbidden pairs is network-theoretic. A tropical hardness theorem implies natural barriers for exact algorithms in max-plus/min-plus models of logistics, control, and dynamic programming.
