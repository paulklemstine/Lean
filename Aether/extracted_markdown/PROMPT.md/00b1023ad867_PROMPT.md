## Research Direction 1: Super-linear tropical lower bounds for bounded-width branching programs

### Vision

Formalize and prove that bounded-width min-plus branching programs cannot compute global combinatorial properties cheaply. The breakthrough is to turn tropical cost into a **certified complexity measure** that behaves like an obstruction invariant across layers. If this lands cleanly, it opens a new formal lower-bound technology for restricted computation models inside Lean: not just Boolean circuits, but weighted dynamic programs, shortest-path style algorithms, streaming sketches, and VLSI routing abstractions.

The conceptual leap is this: **min-plus cost accumulation is not just an algebraic gadget; it is a geometry of information bottlenecks**. Width bounds force a tropical “coarse state compression,” and global predicates like connectivity or distinctness should incur super-linear cost because the layered min-plus geometry cannot shortcut too many combinatorial possibilities.

### Precise theorem target

You likely need an abstract theorem first, then instantiate it to candidate functions.

#### Theorem A: Generic tropical lower bound from layered obstruction growth
Prove a theorem of the following shape:

```lean
theorem bounded_width_bp_tropical_lower_bound
  {α β : Type} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
  (f : α → β)
  (width layers B : ℕ)
  (hwidth : 2 ≤ width)
  (hobs : obstruction_measure f ≥ B)
  (hrealize : tropical_bp_realizes width layers f)
  (hlayer : layered_system width layers)
  (hblock : ∀ i < layers, block_cost_at_least f i)
  (hnoshortcut : layered_no_shortcut width layers) :
  B ≤ tropical_cost_of_realization width layers f
```

This is the master statement: if a function carries a certified obstruction, every bounded-width layered tropical branching-program realization pays at least that much cost.

Then sharpen to a super-linear corollary:

```lean
theorem bounded_width_bp_superlinear_cost
  {α β : Type} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
  (f : α → β)
  (n width : ℕ)
  (hwidth : width ≤ n)
  (hrealize : tropical_bp_realizes width n f)
  (hobs : c * n * Nat.log n ≤ obstruction_measure f)
  (hlayer : layered_system width n)
  (hblock : ∀ i < n, block_cost_at_least f i)
  (hnoshortcut : layered_no_shortcut width n) :
  c * n * Nat.log n ≤ tropical_cost_of_realization width n f
```

You may need to replace `Nat.log` by a simpler super-linear witness first, e.g. `n + n`, `n + n/2`, or a parameterized lower bound `g n` with hypothesis `n < g n`.

### Proof strategy

Most promising.

3. Invoke `layered_no_shortcut` to show width-bounded paths cannot bypass obstructed layers.
4. Sum the contributions and conclude via `circuit_lower_bound_from_obstruction`.

Why promising: it aligns exactly with the given infrastructure and converts existing lemmas into a compositional lower-bound machine.

#### Strategy B: Reduction to certified circuit obstruction

3. Show element distinctness or connectivity requires rapid growth, hence many costly layers.

Why exciting: this could evolve into a tropical analogue of communication rank or branching-program width complexity.  
Risk: more conceptual overhead, but potentially the most field-opening if you can formalize it.

## Research Direction 2: Tropical communication complexity via min-plus protocol cost

### Vision

Define a communication model where transcript cost is aggregated in the min-plus semiring, then prove direct-sum lower bounds using cycle-gap or obstruction machinery. This would create a genuinely new branch: **tropical communication complexity**. If branching-program lower bounds capture state bottlenecks over time, tropical communication complexity captures **distributed bottlenecks over cuts**.

This is a bold direction because communication complexity is the universal lower-bound hub of theoretical CS. A successful min-plus variant could become a transfer principle into:
- distributed shortest-path computation,
- semiring optimization protocols,
- network routing lower bounds,
- and tropical/algebraic formulations of information flow.

### Precise theorem target

Start with an abstract protocol model.

```lean
structure TropicalProtocol (X Y Z : Type) where
  cost : X → Y → ℕ
  output : X → Y → Z
```

Define tropical communication cost:

```lean
def tropicalCommCost (P : TropicalProtocol X Y Z) : ℕ := ...
def computes (P : TropicalProtocol X Y Z) (f : X → Y → Z) : Prop := ...
def directSumFn (f : X → Y → Z) (k : ℕ) : (Fin k → X) → (Fin k → Y) → (Fin k → Z) := ...
```

Then prove a direct-sum theorem of the shape:

```lean
theorem tropical_comm_direct_sum
  (f : X → Y → Z)
  (k : ℕ)
  (hgap : cycle_gap_obstruction f ≥ B) :
  k * B ≤ tropical_comm_complexity (directSumFn f k)
```

A more structurally realistic version may first prove:

```lean
theorem tropical_comm_cost_subadditive_lower_bound
  (f : X → Y → Z)
  (k : ℕ) :
  k * tropical_comm_complexity f ≤ tropical_comm_complexity (directSumFn f k)
```

or with a constant-loss factor.

### Why this is a breakthrough

Classical communication complexity is additive because independent instances force independent information revelation. In the tropical world, min-plus aggregation means transcript composition behaves like optimization over additive costs. Proving a direct-sum theorem says: **even under semiring optimization, independent instances do not collapse for free**.

That would seed a tropical analogue of:
- fooling sets,
- discrepancy/rank methods,
- information complexity,
- direct-sum/direct-product theorems.

### Proof strategy

#### Strategy A: Cycle-gap obstruction lifting
Most aligned with your prompt.

1. Define a cycle-gap invariant for a single protocol instance measuring unavoidable transcript separation.
2. Show this invariant tensorizes/adds across direct sums.
3. Prove any protocol computing the direct sum induces a protocol for each coordinate, so total tropical cost must absorb all coordinate gaps.

This is the best route if the cycle-gap framework already exists in nearby files.

#### Strategy B: Reduction from branching-program lower bounds
1. Encode a communication protocol as a width-bounded layered tropical system across alternating Alice/Bob layers.
2. Apply the generic lower bound from Research Direction 1.
3. Deduce direct-sum lower bounds as a communication corollary.

This would be stunning because it would unify time-layer and communication-cut lower bounds in one formal framework.

#### Strategy C: Tropical rectangle/barrier method
1. Define tropical rectangles as protocol regions with constant local cost structure.
2. Show low-cost protocols induce sparse tropical rectangle covers.
3. Exhibit functions whose direct sums require many such rectangles.

This is conceptually powerful and could become the tropical replacement for rectangle lower bounds.

- **Distributed computing**: min-plus protocols model shortest-path and routing style negotiations across network cuts.
- **Information theory**: tropical cost behaves like an optimization-valued information measure; direct-sum hints at a tropical data-processing principle.
- **Fine-grained complexity**: direct-sum lower bounds can imply batch hardness and no-amortization theorems.
- **Network coding / routing**: tropical algebra is native to path metrics; communication lower bounds become congestion lower bounds.
