Formalize narcissistic (Armstrong) numbers in Lean 4 and prove their finiteness.

## Definition

A natural number n is narcissistic if n equals the sum of its decimal digits each raised to the power of the number of digits. Formally:

```
def IsNarcissistic (n : ℕ) : Prop :=
  n = (Nat.digits 10 n).sum fun d => d ^ (Nat.digits 10 n).length
```

## Key Lemma: Exponential Inequality

Prove that for all d ≥ 61: d * 9^d < 10^(d-1).

Proof strategy: Show that the ratio (d+1)*9^(d+1) / (d*9^d) = 9*(1+1/d) < 10 = 10^d/10^(d-1) for d ≥ 1, so once d*9^d < 10^(d-1) holds at d=61 (verifiable by computation), it holds for all larger d by induction.

## Main Theorem: Finiteness

Prove narcissistic_lt: every narcissistic number n satisfies n < 10^60.

Proof sketch: If n has d digits, then n ≥ 10^(d-1). But if n is narcissistic, n ≤ d·9^d (since each digit ≤ 9 and there are d digits). When d ≥ 61, d·9^d < 10^(d-1) ≤ n, contradiction. So d ≤ 60, hence n < 10^60.
