## Precise Mathematical Target

Let `S` be a commutative idempotent semiring. Let `X` be a finite `S`-semimodule of bulk states. Let `c : X →ₗ[S] X` or, if linearity is too strong, a closure operator on `X` satisfying:

- extensive: `x ≤ c x`
- monotone: `x ≤ y → c x ≤ c y`
- idempotent: `c (c x) = c x`

Let `Σ` be a finite alphabet of actions, and let `T : Σ → X →ₛₗ[S] X` be the bulk transition action. Let `B` be a boundary semimodule. Let `K : B →ₗ[S] X →ₗ[S] S` or curried bilinear pairing `K : B → X → S` be a boundary kernel satisfying closure-compatibility, e.g.

- `K b (c x) = K b x` for closure-stable observables, or
- more generally `K` factors through the closed quotient/nucleus.

Assume `K` separates closed states:
`∀ x y, IsClosed c x → IsClosed c y → (∀ b, K b x = K b y) → x = y`.

For each boundary probe `b : B`, choose a canonical closed bulk representative `x_b : X` induced by the kernel/boundary embedding. For a word `w : List Σ`, define `T_w` by composition and the boundary response series
`H_T : B → List Σ → B → S`
via
`H_T b w b' = K b' (T_w (x_b))`.

Define the boundary Hankel object by identifying two histories when they induce the same boundary response against all future tests and boundary outputs, modulo closure.

**Mathematical statement.**

1. `S` is a finitely generated commutative idempotent semiring,

This is the precise bulk–boundary duality theorem.

## Proof Architecture: 3 Viable Strategies

### Strategy A: Closure-Refined Myhill–Nerode Quotient
This is likely the most Lean-robust and conceptually clean.

1. **Define observational equivalence on histories.**
   Two histories are equivalent iff all closed future boundary responses agree.
   Prove this is a congruence under word extension / action composition.

2. **Construct `X_min` as quotient of finitely many reachable boundary histories.**
   Use finite Hankel rank to show only finitely many equivalence classes are needed.
   Define the induced action `Tmin` by concatenation and prove well-definedness.

3. **Prove universality/minimality/uniqueness.**
   Every realization factors through the quotient because observational equivalence identifies exactly the states indistinguishable by `K` on closed states. Separation of closed states upgrades factorization to injectivity for minimal realizations. Then prove uniqueness of the induced isomorphism.

Why this is promising:
- It mirrors the strongest constructive ideas in automata theory.
- It makes the “boundary-only reconstruction” explicit.
- It is compatible with finite data and algorithmic certification.

### Strategy B: Tropical/Idempotent Hankel Semimodule Factorization
This is more visionary and more algebraic.

1. **Package `H_T` as a Hankel semimodule object.**
   Treat rows indexed by boundary-history pairs and columns indexed by continuation-output pairs.

2. **Show finite closure rank gives a finite generating set of rows.**
   Define `X_min` as the row semimodule or image semimodule of the Hankel operator.
   The action is induced by row shift; closure descends because kernel and transitions are closure-compatible.

3. **Prove representation theorem.**
   Show any realization yields a factorization of the Hankel operator through the bulk semimodule, and minimality corresponds to generated row semimodule equality. Uniqueness follows by identifying both minimal realizations with the same Hankel image.

Why this is revolutionary:
- It is the semiring/tropical analogue of classical linear systems Hankel realization.
- It connects directly to tropical linear algebra and rank notions.
- It turns holography into an operator-image theorem.

This may be harder in Lean because “rank” over semirings is subtle. If exact rank infrastructure is unavailable, define a finite-generation replacement.

### Strategy C: Closure Nucleus / Karoubi Envelope Approach
This is the most conceptually sophisticated.

1. **View closure as a nucleus/idempotent reflector.**
   Closed states form a reflective sub-semimodule-like structure or quotient-by-nucleus object.

2. **Restrict the system to the reflective image.**
   Show the boundary kernel factors through this closed image, and only the reflective image matters observationally.

3. **Apply a quotient-minimality theorem inside the reflective world.**
   Reconstruct the minimal object there, then transport back to the original system.

Why it matters:
- This is the right categorical language for “bulk information surviving on the boundary.”
- It will make future generalizations to sheaves, enriched categories, and idempotent topoi possible.

Most promising overall:
- **Start with Strategy A** for a certified theorem in Lean.
- Build enough infrastructure so that the final statement can be reinterpreted in the **Strategy B** Hankel language.
- If time permits, add a theorem or remark showing equivalence of the quotient and row-semimodule constructions.
