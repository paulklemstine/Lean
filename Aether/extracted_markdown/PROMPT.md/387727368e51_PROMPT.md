## Primary Theorem Target

Work with finite sets indexed by `Fin n`, and define the distance matrix
`D i j = d(i,j)` for a finite ultrametric space. The central theorem should be a precise spectral statement about a canonical transform of `D`.

A highly promising target is:

### Theorem A: Negative Type of Finite Ultrametrics
For every finite ultrametric space `(Fin n, d)`, the squared-distance-free centered quadratic form is negative semidefinite on the codimension-1 subspace of zero-sum vectors.

In concrete terms:

\[
\forall x \in \mathbb R^n,\quad \Big(\sum_i x_i = 0\Big)\ \Longrightarrow\ \sum_{i,j} x_i x_j\, d(i,j) \le 0.
\]

This is a real theorem with strong consequences: it implies that the distance matrix behaves spectrally like a hierarchical Laplacian kernel on the zero-mean subspace.

### Lean 4 type signature target
You will likely need to define a finite ultrametric structure first. A plausible theorem statement is:

```lean
theorem ultrametric_distance_matrix_condNeg
    {n : ℕ} (hn : 0 < n)
    (d : Fin n → Fin n → ℝ)
    (h_nonneg : ∀ i j, 0 ≤ d i j)
    (h_refl : ∀ i, d i i = 0)
    (h_symm : ∀ i j, d i j = d j i)
    (h_ultra : ∀ i j k, d i k ≤ max (d i j) (d j k)) :
    ∀ x : Fin n → ℝ,
      (∑ i, x i) = 0 →
      ∑ i, ∑ j, x i * x j * d i j ≤ 0
```

This statement is strong, concrete, and feasible in Lean using finite sums over `Fin n`.

## Stronger Breakthrough Variant

If Theorem A goes through cleanly, push to the sharper decomposition theorem:

### Theorem B: Hierarchical Cut Decomposition of Finite Ultrametrics
Every finite ultrametric distance on `Fin n` can be written as a nonnegative linear combination of cut metrics induced by a laminar family of partitions.

Schematically:

\[
d(i,j) = \sum_{t \in T} w_t \cdot \mathbf 1_{\text{$i,j$ separated at scale }t},
\qquad w_t \ge 0,
\]

with `T` indexing hierarchical levels.

This is revolutionary because it converts ultrametric novelty into a **compressed codebook of scales**. Once formalized, Theorem A follows by proving each cut metric is conditionally negative semidefinite on zero-sum vectors.

### Lean 4 type signature target
A first formal version can avoid full trees and use a finite family of Boolean cuts:

```lean
theorem ultrametric_as_laminar_cut_sum
    {n : ℕ}
    (d : Fin n → Fin n → ℝ) :
    IsUltrametric d →
    ∃ (m : ℕ) (w : Fin m → ℝ) (S : Fin m → Finset (Fin n)),
      (∀ t, 0 ≤ w t) ∧
      (∀ i j, d i j =
        ∑ t, w t * if ((i ∈ S t) ∧ (j ∈ S t)) ∨ ((i ∉ S t) ∧ (j ∉ S t)) then 0 else 1)
```

You may want to replace the raw formula with a cleaner definition of a cut metric. The key point is explicit finite decomposition.

## Spectral Corollary Target

Once Theorem A is proved, derive a true spectral statement.

### Theorem C: One-Dimensional Positive Spectrum After Centering
Let `J = I - (1/n)11ᵀ` be the centering operator. Then for an ultrametric distance matrix `D`, the matrix `-J D J` is positive semidefinite.

Equivalently, the nontrivial spectrum of the centered distance matrix is controlled by hierarchy.

A Lean-level theorem may be expressed first through quadratic forms rather than full eigenvalue API, which is often the right formal route:

```lean
theorem centered_ultrametric_psd
    {n : ℕ} (hn : 0 < n)
    (d : Fin n → Fin n → ℝ)
    (hU : IsUltrametric d) :
    ∀ x : Fin n → ℝ,
      0 ≤
        ∑ i, ∑ j,
          x i * x j *
            (-((d i j) - (∑ k, d i k) / n - (∑ k, d k j) / n
                + (∑ k, ∑ l, d k l) / (n * n)))
```

You can define centering more elegantly using matrices if the matrix API cooperates.

This theorem is the precise mathematical bridge to “spectral novelty”: after removing the trivial mean mode, the hierarchy becomes a positive energy form.

## Proof Strategy Architecture

You must pursue at least 2–3 approaches in parallel and identify the most promising one.

### Strategy 1: Laminar Cut Decomposition → Quadratic Form Factorization
Most promising.

Step 1. Define a cut metric associated to a subset `S ⊆ Fin n`:
\[
\delta_S(i,j)=
\begin{cases}
1 & \text{if exactly one of } i,j \text{ lies in } S,\\
0 & \text{otherwise.}
\end{cases}
\]

Step 2. Prove the quadratic identity for zero-sum `x`:
\[
\sum_{i,j} x_i x_j \delta_S(i,j) = -2\Big(\sum_{i\in S} x_i\Big)^2 \le 0.
\]

This is the key formal lemma. It is concrete and should be very Lean-friendly with `Finset` algebra.

Step 3. Show any finite ultrametric is a nonnegative sum of laminar cut metrics. Then summing the identity yields conditional negative semidefiniteness.

Why this is promising: it reduces spectral geometry to finite combinatorial algebra. It also directly expresses compression: a hierarchy is a sparse code of cuts.

### Strategy 2: Tree Representation of Ultrametrics
Conceptually elegant.

Step 1. Formalize a rooted weighted tree representation of finite ultrametrics: leaves are points, and distance equals the height of the least common ancestor, or twice a height difference depending on normalization.

Step 2. Express the distance matrix as a sum over internal nodes of separation indicators.

Step 3. Derive the negative-type inequality by telescoping node contributions.

Why this is promising: it reveals the genuine hidden structure and gives a pathway to future theorems about eigenvalue multiplicities and scale separation. It is heavier in Lean because tree formalization is nontrivial.

### Strategy 3: Direct Matrix Centering and PSD Verification
Most spectral, but API-risky.

Step 1. Define the centered matrix `B = -J D J`.

Step 2. Show directly that for any vector `x`, one has
\[
x^\top B x = -y^\top D y
\]
where `y = Jx` has zero sum.

Step 3. Apply Theorem A to conclude `xᵀBx ≥ 0`.

Why this is promising: if the matrix API and finite-dimensional linear algebra cooperate, this yields immediate spectral corollaries. Why it is risky: full matrix spectral formalization can be technically expensive.

**Recommendation:** Prove Strategy 1 first, then package Strategy 3 as the corollary layer.
