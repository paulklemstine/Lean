### Core formal target

#### 3. Well-foundedness of support reduction

For your reduction relation, prove a strict descent theorem:

```lean

    {σ S : Type*} [CommSemiring S] [DecidableEq σ] [Fintype σ]
    (G : Finset (MvPolynomial σ S × MvPolynomial σ S))
```

Then derive termination:

```lean

    {σ S : Type*} [CommSemiring S] [DecidableEq σ] [Fintype σ]

    WellFounded (ReducibleBy G)
```

If strict measure decrease is too coarse, use `InvImage` of a well-founded relation on finite support signatures.

#### 4. Existence of normal forms

```lean

    {σ S : Type*} [CommSemiring S] [DecidableEq σ] [Fintype σ]
    (G : Finset (MvPolynomial σ S × MvPolynomial σ S))
    (p : MvPolynomial σ S × MvPolynomial σ S) :
    ∃ q, ReflTransGen (ReducibleBy G) p q ∧ NormalForm G q
```

This theorem is already a major algorithmic milestone: it turns finite generating data into a terminating rewrite system candidate.

#### 5. Buchberger-style completion for congruence pairs

Define an `SPair` or critical-pair constructor on polynomial pairs, at least support-theoretically:

```lean
def SPair
    {σ S : Type*} [CommSemiring S] [DecidableEq σ]
    (p q : MvPolynomial σ S × MvPolynomial σ S) :
    MvPolynomial σ S × MvPolynomial σ S := ...
```

Then prove a finite completion theorem in the weakest viable form:

```lean
theorem exists_finite_completed_basis
    {S σ : Type*} [CommSemiring S] [IsIdempotentElem S (+)]
    [Fintype σ] [DecidableEq σ]
    (C : Con (MvPolynomial σ S)) :
    C.FinitelyGenerated →
    ∃ G : Finset (MvPolynomial σ S × MvPolynomial σ S),
      GeneratesCongruence G C ∧
      CompletedBasis G
```

Here `GeneratesCongruence G C` and `CompletedBasis G` are new definitions you should introduce. `CompletedBasis G` should assert enough closure of critical pairs to imply that reduction to normal form decides congruence membership, but it need not initially be the strongest possible analogue of classical Buchberger.

Finally extract the algorithmic corollary:

```lean
theorem congruence_mem_iff_normalForm_eq
    {S σ : Type*} [CommSemiring S] [IsIdempotentElem S (+)]
    [Fintype σ] [DecidableEq σ]
    {C : Con (MvPolynomial σ S)}
    {G : Finset (MvPolynomial σ S × MvPolynomial σ S)} :
    GeneratesCongruence G C →
    CompletedBasis G →
    ∀ p q : MvPolynomial σ S,
      C p q ↔
      normalForm G (p, q) = normalForm G (q, q)
```

If equality to a canonical representative is awkward, use “their reduced pair normalizes to a diagonal pair” or another equivalent criterion.

### Proof strategy: concrete architecture

#### Strategy A: Reduce injective elimination to the known elimination theorem through a subtype/range equivalence
This is the most promising route.

1. Construct the variable-image subsemiring inside `MvPolynomial σ S` generated by variables `X (ι i)`.
2. Show `MvPolynomial.rename ι : MvPolynomial τ S →+* MvPolynomial σ S` lands in this subsemiring and induces a semiring equivalence onto it.
3. Transport the congruence `C` to a congruence on that subsemiring; identify its finite generation with finite generation of the comap along `rename ι`.
4. Apply the existing `elimination_fg` theorem to the subsemiring/range formulation already in the catalog.
5. Push finite generation back across the equivalence.

Key lemmas likely needed:
- injectivity of `MvPolynomial.rename ι` for embeddings;
- characterization of the support of renamed polynomials;
- extensionality on image variables;
- transport of `FinitelyGenerated` across semiring equivalences.

#### Strategy B: Prove finite generation directly by pulling back a finite generating family
Use only if Strategy A hits API obstacles.

1. Start from a finite generating set `T` for `C`.
2. For each generator pair `(f,g)` in `T`, eliminate variables outside `range ι` using the existing elimination infrastructure.
3. Show every relation in the comap congruence is generated by finitely many such eliminated pairs.
4. Use finite support of polynomials and finiteness of the variable types to close the construction.

This is conceptually direct, but likely much more painful in Lean because it requires explicit manipulation of generated congruences.

#### Strategy C: For completion, prove a Dickson-style termination theorem on support signatures
Most promising for the normalization side.

1. Define support signatures in `(σ →₀ ℕ)` and order them by divisibility / componentwise ≤.
2. Invoke Dickson’s lemma on finitely many variables to obtain a well-quasi-order on monomials.
3. Lift this to finite unions/signatures for polynomial pairs.
4. Show every nontrivial reduction strictly decreases the chosen signature.
5. Deduce that every completion sequence terminates once injective elimination prevents new independent variables from proliferating.

If a full WQO on finite sets is awkward, use a simpler natural-number measure first to establish existence of normal forms, then state the stronger WQO-based completion theorem as a conjecture with precise type.

### Recommended concrete proof steps

1. **Build the range model of embedded variables.**
   Prove that the image of `MvPolynomial.rename ι` is exactly the subsemiring of polynomials whose monomial support is contained in exponents on `range ι`. This is the hidden structural lemma behind injective elimination.

2. **Transport finite generation across equivalence.**
   Introduce a general lemma:
   ```lean
   theorem finitelyGenerated_congruence_map_iff
       {R A B : Type*} [Semiring A] [Semiring B]
       (e : A ≃+* B) (C : Con A) :
       C.FinitelyGenerated ↔ (C.map e.toMonoidHom).FinitelyGenerated
   ```
   or the variant compatible with your congruence API. This lemma will pay for itself repeatedly.

3. **Define reduction in a support-monotone way.**
   Don’t overcommit to a coefficient-sensitive notion. In idempotent semirings, support containment is already a natural reduction invariant. Define reduction so that replacing a pair by a generator-translated pair strictly shrinks support.

4. **Prove well-foundedness via a measure.**
   If `Finset (σ →₀ ℕ)` is too hard to order directly, use:
   - cardinality of support union;
   - then sum of total degrees;
   - then lexicographic combination.
   This often suffices for a first formal Buchberger theorem.

5. **Package completion abstractly.**
   Define `CompletedBasis G` by the property that every critical pair reduces to a normal form lying on the diagonal congruence. Then prove that from finite generation and termination one can enlarge any finite generating set to such a `G`.

### Why this matters

This is the idempotent-semiring analogue of the passage from Hilbert basis to elimination theory to Gröbner bases. The injective elimination theorem is the Noetherian spine: it says variable restriction preserves finite describability, exactly what is needed to make local rewrite data global and algorithmic. The normalization/completion layer then turns finite generation from a static existence theorem into a computational engine.

If formalized cleanly, this opens at least three new directions immediately:

1. **Tropical computational algebra.** Congruences over idempotent semirings are the algebraic core of tropical varieties; a canonical finite basis gives an actual decision procedure for tropical polynomial equivalence modulo finitely generated relations.

2. **Automated reasoning in max-plus/min-plus systems.** Normal forms for congruence pairs become symbolic simplifiers for optimization, control, and discrete event systems.

3. **A new Gröbner theory beyond rings.** Classical Buchberger relies on subtraction; this program replaces it by support geometry and congruence pairs. That is not an incremental variant — it is a different algebraic civilization.
