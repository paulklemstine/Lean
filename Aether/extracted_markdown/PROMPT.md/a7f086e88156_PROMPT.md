## Precise formalization targets

You should define the minimum viable infrastructure needed to state and prove the theorem in a form Lean can exploit immediately. Do not wait for the “perfect” category-theoretic generality; first prove the theorem in an order-enriched setting with explicit ω-chain suprema, then abstract.

### 1. Guarded order-theoretic fixed-point structure

A productive first layer is a complete semilattice-style fixed-point semantics on endomaps.

Use a class along the following lines:

```lean
class GuardedOrder (α : Type u) extends PartialOrder α, OrderBot α, SupSet α where
  omegaSup : (ℕ → α) → α
  le_omegaSup : ∀ s n, s n ≤ omegaSup s
  omegaSup_le : ∀ s a, (∀ n, s n ≤ a) → omegaSup s ≤ a
```

If `ConditionallyCompleteLattice` or a suitable existing Mathlib class is already available, use that instead of inventing `omegaSup`.

Define a delay/guard operator:

```lean
class DelayOperator (α : Type u) [PartialOrder α] where
  delay : α → α
  monotone_delay : Monotone delay
  bot_le_delay : ∀ x, ⊥ ≤ delay x
```

For the contractive/productive condition, introduce:

```lean
def GuardedMap {α : Type u} [PartialOrder α] [DelayOperator α] (F : α → α) : Prop :=
  ∀ x, F x ≤ DelayOperator.delay x ⊔ F ⊥
```

If this shape is awkward relative to existing infrastructure, replace it by the stronger and easier-to-use hypothesis:

```lean
def DelayMonotone {α : Type u} [PartialOrder α] [DelayOperator α] (F : α → α) : Prop :=
  Monotone F ∧ ∀ x, F x ≤ DelayOperator.delay x ⊔ F ⊥
```

Then define guarded iteration:

```lean
def guardedIterate {α : Type u} [OrderBot α] (F : α → α) : ℕ → α
  | 0 => ⊥
  | n + 1 => F (guardedIterate F n)
```

and the candidate fixed point:

```lean
def guardedLfp {α : Type u} [GuardedOrder α] [OrderBot α] (F : α → α) : α :=
  GuardedOrder.omegaSup (guardedIterate F)
```

### 2. Main fixed-point theorem

The first theorem should be an explicit least fixed-point theorem for guarded maps.

A good Lean signature is:

```lean
theorem guardedIterate_mono
    {α : Type u} [GuardedOrder α] [DelayOperator α] [OrderBot α]
    {F : α → α} (hF : Monotone F) :
    Monotone (guardedIterate F)
```

Then:

```lean
theorem guardedLfp_is_fixed
    {α : Type u} [GuardedOrder α] [DelayOperator α] [OrderBot α]
    {F : α → α} (hmono : Monotone F)
    (hcont : F (guardedLfp F) ≤ guardedLfp F)
    (hstep : ∀ n, guardedIterate F (n+1) ≤ F (guardedLfp F)) :
    F (guardedLfp F) = guardedLfp F
```

But the more meaningful target is a direct theorem under ω-continuity:

```lean
def OmegaContinuous {α : Type u} [GuardedOrder α] (F : α → α) : Prop :=
  ∀ s : ℕ → α, Monotone s → F (GuardedOrder.omegaSup s) ≤ GuardedOrder.omegaSup (fun n => F (s n))
```

Then prove:

```lean
theorem guardedLfp_fixed
    {α : Type u} [GuardedOrder α] [DelayOperator α] [OrderBot α]
    {F : α → α}
    (hmono : Monotone F)
    (hω : OmegaContinuous F) :
    F (guardedLfp F) = guardedLfp F
```

and uniqueness among prefixed points / fixed points:

```lean
theorem guardedLfp_least_fixed
    {α : Type u} [GuardedOrder α] [DelayOperator α] [OrderBot α]
    {F : α → α}
    (hmono : Monotone F)
    (hω : OmegaContinuous F) :
    ∀ {x : α}, F x = x → guardedLfp F ≤ x
```

```lean
theorem guarded_fixedpoint_unique
    {α : Type u} [GuardedOrder α] [DelayOperator α] [OrderBot α]
    {F : α → α}
    (hmono : Monotone F)
    (hω : OmegaContinuous F)
    {x y : α}
    (hx : F x = x) (hy : F y = y)
    (hleastx : ∀ z, F z = z → x ≤ z)
    (hleasty : ∀ z, F z = z → y ≤ z) :
    x = y
```

This uniqueness statement is slightly redundant but often easier to use than trying to prove antisymmetry from scratch in later modules.

### 3. Trace from guarded fixed points

Now define a simple traced operator at the semantic level. Avoid full traced monoidal category bureaucracy until the core works.

For a morphism semantic type `X → A → X × B` or curried equivalent, define the feedback functional on `X → B`-style semantics. One workable order-enriched encoding is:

```lean
def guardedTrace
    {σ α β : Type u}
    [GuardedOrder (σ → β)] [DelayOperator (σ → α)]
    [OrderBot (σ → α)] [OrderBot (σ → β)]
    (f : (σ → α) → (σ → β)) : (σ → β) :=
  guardedLfp f
```

But this is too degenerate if you want a real feedback operator. Better:

```lean
def feedbackFunc
    {x a b : Type u}
    (f : x × a → x × b) (u : a → x) : a → x :=
  fun a => (f (u a, a)).1

def guardedTrace
    {x a b : Type u}
    [GuardedOrder (a → x)] [DelayOperator (a → x)] [OrderBot (a → x)]
    (f : x × a → x × b) : a → b :=
  fun a =>
    let u := guardedLfp (feedbackFunc f)
    (f (u a, a)).2
```

Then prove the unfolding law:

```lean
theorem guardedTrace_unfold
    {x a b : Type u}
    [GuardedOrder (a → x)] [DelayOperator (a → x)] [OrderBot (a → x)]
    {f : x × a → x × b}
    (hmono : Monotone (feedbackFunc f))
    (hω : OmegaContinuous (feedbackFunc f)) :
    let u := guardedLfp (feedbackFunc f)
    guardedTrace f = fun a => (f (u a, a)).2
```

and the uniqueness theorem for the internal state solution:

```lean
theorem guardedTrace_unique
    {x a b : Type u}
    [GuardedOrder (a → x)] [DelayOperator (a → x)] [OrderBot (a → x)]
    {f : x × a → x × b}
    (hmono : Monotone (feedbackFunc f))
    (hω : OmegaContinuous (feedbackFunc f))
    {u : a → x}
    (hu : feedbackFunc f u = u)
    (hleast : ∀ v, feedbackFunc f v = v → u ≤ v) :
    u = guardedLfp (feedbackFunc f)
```

### 4. Bekič decomposition

This is where the result becomes structurally nontrivial. Even a specialized Bekič law is a major advance.

Define product-level feedback:

```lean
def feedbackFunc₂
    {x y a : Type u}
    (f : (x × y) × a → (x × y)) :
    (a → x × y) → (a → x × y) :=
  fun u a => f (u a, a)
```

Then a specialized Bekič statement:

```lean
theorem guardedTrace_bekic
    {x y a : Type u}
    [GuardedOrder (a → x)] [DelayOperator (a → x)] [OrderBot (a → x)]
    [GuardedOrder (a → y)] [DelayOperator (a → y)] [OrderBot (a → y)]
    [GuardedOrder (a → x × y)] [DelayOperator (a → x × y)] [OrderBot (a → x × y)]
    {f : (x × y) × a → x × y}
    (hmono : Monotone (feedbackFunc₂ f))
    (hω : OmegaContinuous (feedbackFunc₂ f)) :
    ∃ ux : a → x, ∃ uy : a → y,
      guardedLfp (feedbackFunc₂ f) = fun a => (ux a, uy a)
```

If full Bekič equality is too costly, prove this decomposition existence theorem first, then strengthen later to an equation identifying nested guarded fixed points with the product guarded fixed point.

A stronger target, if feasible:

```lean
theorem guarded_bekic_nested
    ...
    : guardedLfp (feedbackFunc₂ f) =
      fun a => (guardedLfp Fx a, guardedLfp Fy a)
```

for explicitly derived `Fx`, `Fy`.

### 5. Reversible temporal circuits and finite unrolling

Now specialize to reversible circuits. Use a lightweight structure first:

```lean
structure RevCircuit (α β : Type u) where
  step : α → β
  inv  : β → α
  left_inv  : Function.LeftInverse inv step
  right_inv : Function.RightInverse inv step
```

For temporal guarded loops:

```lean
structure GuardedRevCircuit (σ α β : Type u) where
  body : σ × α → σ × β
  body_rev : RevCircuit (σ × α) (σ × β)
  guarded : True
```

You may later refine `guarded : True` into an actual delay-respecting property once the semantic theorem is in place.

Define finite unrolling:

```lean
def unfoldn
    {σ α β : Type u}
    (f : σ × α → σ × β) : ℕ → σ → α → σ × β
  | 0 => fun s a => (s, (f (s,a)).2)
  | n+1 => fun s a =>
      let r := unfoldn f n s a
      f (r.1, a)
```

Then define semantic equivalence by all finite unfoldings:

```lean
def FiniteUnfoldingEq
    {σ α β : Type u}
    (f g : σ × α → σ × β) : Prop :=
  ∀ n s a, unfoldn f n s a = unfoldn g n s a
```

The crucial theorem:

```lean
theorem reversible_circuit_equiv_iff_finite_unfoldings
    {σ α β : Type u}
    [GuardedOrder (α → σ)] [DelayOperator (α → σ)] [OrderBot (α → σ)]
    {f g : σ × α → σ × β}
    (hf_mono : Monotone (feedbackFunc f))
    (hf_ω : OmegaContinuous (feedbackFunc f))
    (hg_mono : Monotone (feedbackFunc g))
    (hg_ω : OmegaContinuous (feedbackFunc g)) :
    guardedTrace f = guardedTrace g ↔ FiniteUnfoldingEq f g
```

This exact biconditional may require an extensionality or observability hypothesis. If so, strengthen hypotheses explicitly:

```lean
    (hobs :
      ∀ u v : α → σ,
        (∀ n a, guardedIterate (feedbackFunc f) n a = guardedIterate (feedbackFunc g) n a) →
        u = v)
```

or replace the reverse implication with a more realistic theorem:

```lean
theorem finite_unfoldings_imp_trace_equiv ...
```

and separately state the converse as a conjecture if it needs stronger separation assumptions.

## Proof strategy

### Strategy A: ω-chain semantics first, trace second, reversibility last
This is the most promising route because it isolates the hard order-theoretic argument from the still-fluid categorical interface.

1. **Build the iteration chain and prove monotonicity.**  
   Prove:
   - `guardedIterate F n ≤ guardedIterate F (n+1)` under `Monotone F` and `⊥ ≤ F ⊥` or an equivalent starter lemma.
   - `Monotone (guardedIterate F)` as a map `ℕ → α`.
   Key lemmas:
   - induction on `n`
   - `hmono : Monotone F`
   - `GuardedOrder.le_omegaSup`

2. **Show the ω-sup is a fixed point.**  
   This is the central semantic move. Use ω-continuity to compare
   `F (sup_n F^n ⊥)` with `sup_n F^(n+1) ⊥`, then identify the shifted chain with the original sup.
   Key intermediate lemma:
   ```lean
   theorem omegaSup_shift
       {s : ℕ → α} (hs : Monotone s) :
       GuardedOrder.omegaSup (fun n => s (n+1)) = GuardedOrder.omegaSup s
   ```
   This lemma will likely be reused everywhere.

3. **Prove leastness and uniqueness.**  
   For any fixed point `x`, show by induction that `guardedIterate F n ≤ x`, hence `guardedLfp F ≤ x`.
   This gives canonical uniqueness whenever later constructions produce another least solution.

4. **Define guarded trace through the fixed point of the state component.**  
   For `f : x × a → x × b`, extract the state-update functional `feedbackFunc f : (a → x) → (a → x)`. Apply the fixed-point theorem to obtain `u`. Define output as `(f (u a, a)).2`.  
   Prove unfolding by `simp [guardedTrace, feedbackFunc, guardedLfp_fixed]`.

5. **Specialize to reversible circuits and finite unrolling.**  
   Show finite unfoldings compute the `n`th approximant:
   ```lean
   theorem unfoldn_eq_iterate ...
   ```
   Then equality of all finite unfoldings implies equality of all approximants, hence equality of ω-sups, hence equality of traces.

Why this is best: it uses standard Lean-friendly induction and order reasoning, minimizes category theory overhead, and yields executable semantics immediately.

### Strategy B: Conway-style axiomatization first, then derive trace
If the codebase already contains `guardedTrace_unfold`, `guardedTrace_unique`, or Conway identities as placeholders, prove the abstract identities and instantiate later.

1. Introduce a class:
   ```lean
   class GuardedFixpointOperator ... where
     gfix : ...
     unfold : ...
     unique : ...
   ```
2. Define `guardedTrace` from `gfix`.
3. Prove trace identities:
   - unfolding
   - naturality/dinaturality if available
   - Bekič
4. Instantiate the class using the ω-chain construction.
5. Transfer all abstract theorems to reversible circuits.

Why this is good: if surrounding files already expect abstract trace laws, this reduces refactoring.  
Why it is less promising: uniqueness and Bekič often become harder to prove abstractly than concretely.

---

### Strategy C: Semiring-enriched relational semantics
Use the idempotent semiring layer explicitly: morphisms are weighted relations, composition is semiring matrix multiplication, and guarded trace is a closure/star-like construction.

1. Represent temporal processes as kernels:
   ```lean
   X → Y → S
   ```
   with `S` an idempotent semiring.
2. Interpret feedback as a monotone endomap on kernels.
3. Show guarded iteration computes the Kleene chain.
4. Prove trace is the semiring supremum of finite loop traversals.
5. For reversible circuits, use partial isomorphism hypotheses to show no information is lost under unfolding.

Why this matters: it ties the theorem directly to the EML/idempotent algebra stack.  
Why it is harder: kernel composition and reversibility constraints may require more infrastructure than the immediate theorem needs.

Use this as the second phase after Strategy A lands.

## Concrete proof steps and key lemmas to target

1. **Shifted-supremum invariance**
   ```lean
   theorem omegaSup_iterate_succ
       {α : Type u} [GuardedOrder α] {F : α → α}
       (hmono : Monotone F) :
       GuardedOrder.omegaSup (fun n => guardedIterate F (n+1)) =
       GuardedOrder.omegaSup (guardedIterate F)
   ```
   This is the engine behind `guardedLfp_fixed`.

2. **Approximants below every fixed point**
   ```lean
   theorem guardedIterate_le_fixed
       {α : Type u} [GuardedOrder α] [OrderBot α]
       {F : α → α} (hmono : Monotone F) {x : α} (hx : F x = x) :
       ∀ n, guardedIterate F n ≤ x
   ```

3. **Finite unrolling equals approximant semantics**
   For the state component:
   ```lean
   theorem unfoldn_state_eq_iterate
       {σ α β : Type u}
       (f : σ × α → σ × β) :
       ∀ n a, (unfoldn f n ⊥ a).1 = guardedIterate (feedbackFunc f) n a
   ```
   Adjust `⊥` if the state space is function-valued or ordered differently.

4. **Trace equality from approximant equality**
   ```lean
   theorem guardedTrace_eq_of_iterates_eq
       {σ α β : Type u}
       [GuardedOrder (α → σ)] [DelayOperator (α → σ)] [OrderBot (α → σ)]
       {f g : σ × α → σ × β}
       (hfg : ∀ n, guardedIterate (feedbackFunc f) n = guardedIterate (feedbackFunc g) n) :
       guardedTrace f = guardedTrace g
   ```

5. **Bekič splitting via product order extensionality**
   You will likely need:
   ```lean
   theorem guardedLfp_prod_fst_le ...
   theorem guardedLfp_prod_snd_le ...
   ```
   then combine by `Prod.ext`.

## Lean implementation advice

- If `SupSet`/`sSup` becomes painful, define a bespoke `omegaSup` first. The theorem is about ω-chain semantics, not arbitrary complete lattices.
- For function spaces, instantiate order pointwise:
  ```lean
  instance : PartialOrder (α → β) := Pi.partialOrder
  instance [OrderBot β] : OrderBot (α → β) := Pi.instOrderBot
  ```
- If `OmegaContinuous` as an equality is too strong, use the one-sided inequality needed for the fixed-point proof, then derive equality from the iterate chain.
- Reversibility should not block the core theorem. Treat it as a semantic side condition for the circuit layer, not as part of the foundational fixed-point proof.
- If categorical tensor `⊗` is not yet available in the relevant files, use products `×` for the first formalization and leave a theorem/comment explaining this is the cartesian traced instance.

## Why this matters

This theorem is not just another fixed-point lemma. It creates a semantic bridge between:
- guarded recursion in logic,
- traced feedback in categorical semantics,
- reversible circuit equivalence in computation,
- and idempotent semiring/Kleene-style approximation in algebra.

The breakthrough is the **finite approximation principle for reversible temporal loops**: loop denotations become computable by monotone guarded unrolling, and circuit equivalence reduces to a trace-unfolding criterion. That is the algorithmic shadow. It opens a path to:
- certified normalization procedures for feedback circuits,
- semiring-weighted reversible program analysis,
- tropical/idempotent models of causal reversible computation,
- and ultimately a unified semantics where guarded trace behaves like a productive Kleene star.

This is exactly the kind of infrastructure that can later support a temporal Langlands of computation: feedback, reversibility, and idempotent algebra all talking to each other in one formal language.
