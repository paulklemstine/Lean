## Precise Theorem Targets

You should define a finite structure of “parity-realizable closure-capacity objects” and prove an existence–uniqueness–reconstruction package.

### Core mathematical statement

Let \(X\) be a finite type, let \(\operatorname{cl} : \mathcal P(X)\to \mathcal P(X)\) be a closure operator, and let
\[
\operatorname{cap} : \mathcal P_{\mathrm{fin}}(X)\to \mathbb N
\]
be a finite capacity profile. Define a class of objects \((X,\operatorname{cl},\operatorname{cap})\) satisfying:

1. **Atomic finite generation**: every closed set is generated by finitely many atoms/minimal generators.
2. **Parity-submodularity**:
   \[
   \operatorname{cap}(A\cup B)+\operatorname{cap}(A\cap B)\le \operatorname{cap}(A)+\operatorname{cap}(B).
   \]
3. **Exchange-free syndrome monotonicity**:
   if \(A\subseteq B\), then \(\operatorname{cap}(A)\le \operatorname{cap}(B)\), and equality forces closure-shadow stability of syndrome generators.
4. **Finite separation**: distinct closure classes are separated by some finite capacity witness.
5. **Support realizability axiom**: the minimal generators over each closed set form a finite support hypergraph compatible with the capacity increments.

Then prove:

### Theorem 1: Realization / Canonical Minimality
For every finite parity-realizable closure-capacity object \((X,\operatorname{cl},\operatorname{cap})\), there exists a finite field \(\mathbb F_q\), a finite linear code \(C\subseteq \mathbb F_q^X\), and a parity-check matrix \(H\) for \(C\), such that the closure-shadow of the associated idempotent parity semimodule \(P(H)\) is isomorphic to \((X,\operatorname{cl},\operatorname{cap})\). Moreover there exists a canonical minimal parity-check matrix \(H_{\min}\) such that:
- \(H_{\min}\) realizes \((X,\operatorname{cl},\operatorname{cap})\),
- any other realizing parity-check matrix has row rank at least \(\operatorname{rank}(H_{\min})\),
- \(H_{\min}\) is unique up to column permutation and code equivalence.

### Theorem 2: Functorial Reconstruction
From the closure data \((X,\operatorname{cl},\operatorname{cap})\) alone, one can functorially reconstruct:
- the support hypergraph of minimal parity constraints,
- the minimal parity-check rank,
- a canonical representative \(H_{\min}\),
and this reconstruction is certified correct: reapplying the closure-shadow construction to \(H_{\min}\) returns an object isomorphic to the original one.

### Theorem 3: Equivalence on a finite category
Define a category of finite parity-realizable closure-capacity objects and a category of canonical minimal parity-check presentations modulo code equivalence. Prove these categories are equivalent, or at minimum prove a bijection on isomorphism classes with functorial reconstruction maps inverse to each other.

This is the right scale: not one isolated theorem, but a new formalized bridge.

## Proof strategy architecture

## Strategy A: Hypergraph-first reconstruction from minimal generators
**Most promising for Lean.**

1. **Extract the support hypergraph from closure-capacity increments.**
   Define minimal witnesses for strict capacity jumps:
   \[
   \Delta_x(A) := \operatorname{cap}(A\cup\{x\}) - \operatorname{cap}(A).
   \]
   Use atomic finite generation and separation to show the family of minimal \(A\) with \(\Delta_x(A)=0\) or prescribed threshold forms a finite irredundant support hypergraph.

2. **Construct a canonical parity-check incidence object from the hypergraph.**
   First realize the hypergraph as a Boolean or finite-field incidence matrix; then refine coefficients so capacity equals minimal syndrome cost/rank contribution. This yields a parity-check matrix \(H_{\min}\).

3. **Prove correctness and minimality.**
   Show the closure-shadow of \(H_{\min}\) reproduces \((\operatorname{cl},\operatorname{cap})\). Then prove any realizing \(H\) must contain at least the same irredundant support constraints, forcing rank/support-profile minimality.

Why this is most promising:
- finite combinatorics are Lean-friendly;
- hypergraph irredundancy is easier to certify than direct linear-code uniqueness;
- canonicalization can be defined lexicographically on finite support families.

## Strategy B: Rank-function representation via polymatroid-to-code lift
Potentially more conceptual, but riskier.

1. Show `cap` behaves like a constrained rank function or syndrome complexity polymatroid.
2. Prove every object in your class admits a representation by a parity-rank model.
3. Convert parity-rank model into a concrete parity-check matrix, then derive closure-shadow equivalence.

This is elegant and closer to information theory, but the representability step may collapse into difficult finite-field realization issues unless your axioms are tuned carefully.

## Strategy C: Category-theoretic reconstruction via adjunction
Best as a second-phase theorem after the core existence theorem.

1. Define a functor from parity-check presentations to closure-capacity objects via closure-shadow.
2. Define a reconstruction functor back using canonical minimal supports.
3. Prove unit/counit isomorphisms on the parity-realizable subcategory.

This is the cleanest “bridge theorem” philosophically, but should come after the combinatorial realization is established.

**Recommendation:** Start with Strategy A, borrow certification architecture from the existing reconstruction theorem, then elevate to Strategy C if the core data structures stabilize.

## Deeper mathematical insight: what the theorem is really saying

This project should be framed as a new representability doctrine:

- A closure system says which coordinates are semantically forced by which others.
- A parity-check matrix says which coordinate patterns are syndrome-constrained.
- An idempotent semimodule records not just yes/no dependence, but **minimal cost of forcing/separating a syndrome**.
- The capacity profile is the observable shadow of that cost geometry.

So the theorem says: **certain finite semantic closure structures are exactly parity-syndrome geometries in disguise**.

That is much stronger than matroid language. Matroids forget cost and often impose exchange. Your target class is explicitly **exchange-free**, meaning this could model cryptographic extraction phenomena and coding constraints not visible to classical linear dependence alone.

This is why “idempotent parity semimodule” matters: it captures optimization over parity explanations, not merely existence of dependence.

structure ExchangeClosureSystem (X : Type u) [Fintype X] where
  cl : Set X → Set X
  extensive : ∀ A, A ⊆ cl A
  mono : ∀ ⦃A B : Set X⦄, A ⊆ B → cl A ⊆ cl B
  idempotent : ∀ A, cl (cl A) = cl A
  exchange : ∀ ⦃A : Set X⦄ ⦃x y : X⦄,
    y ∈ cl (A ∪ {x}) → y ∉ cl A → x ∈ cl (A ∪ {y})

namespace ExchangeClosureSystem
variable {X : Type u} [Fintype X]

def IsClosed (C : ExchangeClosureSystem X) (S : Set X) : Prop := C.cl S = S

theorem cl_isClosed (C : ExchangeClosureSystem X) (A : Set X) :

/-- A closure operator on `Set α`: monotone, extensive, idempotent. -/
structure IsClosureOperator {α : Type*} (cl : Set α → Set α) : Prop where
  idempotent : ∀ s, cl (cl s) = cl s
  monotone : ∀ ⦃s t : Set α⦄, s ⊆ t → cl s ⊆ cl t

/-! ## §2. Closure Capacity

A normalized, monotone, closure-invariant function from sets to the tropical
valuation scale `WithTop ℕ`, satisfying the ultrametric join inequality. -/

structure ClosureCapacity
    (α : Type*) [Fintype α] [DecidableEq α]
    (cl : Set α → Set α) : Type _ where
  toFun : Set α → WithTop ℕ
  closed_invariant : ∀ s : Set α, toFun (cl s) = toFun s
  monotone : ∀ ⦃s t : Set α⦄, s ⊆ t → toFun s ≤ toFun t
  normalized_bot : toFun ∅ = 0
  ultrametric_join :
    ∀ s t : Set α, toFun (cl (s ∪ t)) ≤ max (toFun s) (toFun t)

@[ext]
theorem ClosureCapacity.ext' {α : Type*} [Fintype α] [DecidableEq α]
