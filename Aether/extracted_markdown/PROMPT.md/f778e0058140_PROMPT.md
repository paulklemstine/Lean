## Core Vision

The bounded-augmentation principle in the catalog says: adding finitely many global generators to a local generating set does not destroy the local spectral scaling. Your task is to discover and formalize the **breaking point** of that principle when the number of added generators grows with \(n\).

The conjectural critical scale for \(G_n = (\mathbb Z/n\mathbb Z)^2\) is

\[
f(n) = \Theta(n^{2/3}).
\]

The revolutionary claim is that this is not merely a quantitative threshold but a **new universality class** for random walks on augmented lattices: below \(n^{2/3}\), locality dominates and the spectral gap ratio remains bounded; above it, random long-range geometry overwhelms local transport and universality fails.

This would be a breakthrough because it identifies a precise interface between:
- **local transport geometry**,
- **random shortcut effects**,
- **spectral perturbation theory**,
- and **random graph phase transitions**.

It would create a blueprint for analogous thresholds in higher-dimensional tori, nilpotent groups, arithmetic expanders, and even long-range interacting statistical mechanics.

## Exact Theorem Program

You must prove at least **3 substantial theorems**, with multi-step reasoning. The following are the target theorems.

### Theorem 1: Monotonicity / comparison under augmentation
A foundational theorem showing that adding generators can only improve the spectral gap in the abelian Fourier model.

**Mathematical statement**
For every finite abelian group \(G\), every symmetric generating sets \(S \subseteq T\), the nontrivial Fourier eigenvalue modulus for the simple symmetric walk on \(T\) is bounded above by that for \(S\), hence the spectral gap for \(T\) is at least that for \(S\).

A Lean-style target:

```lean
theorem spectralGap_mono_of_subset
    {n : ℕ}
    (hn : 0 < n)
    {S T : Finset ((ZMod n) × (ZMod n))}
    (hST : S ⊆ T)
    (hSsym : SymmetricFinset S)
    (hTsym : SymmetricFinset T) :
    spectralGapZN2 n S ≤ spectralGapZN2 n T := ...
```

This theorem is the algebraic backbone: augmentation is a perturbation that can only help mixing, so the entire problem becomes one of quantifying *how much* help appears as the augmentation grows.

### Theorem 2: Subcritical bounded-ratio theorem
A theorem extending the catalog’s bounded augmentation principle from constant-size augmentation to a quantitatively growing regime.

**Mathematical statement**
There exists a universal constant \(C>0\) such that if \(S_n\) is the local generating set on \((\mathbb Z/n\mathbb Z)^2\), and \(A_n\) is a symmetric augmentation with cardinality \(k_n\) satisfying a subcritical growth inequality
\[
k_n^3 \le C n^2,
\]
then the spectral gap ratio
\[
\frac{\lambda(S_n \cup A_n)}{\lambda(S_n)}
\]
remains uniformly bounded above.

Lean-style target:

```lean
theorem subcritical_ratio_bounded
    (C : ℕ)
    (hC : 0 < C) :
    ∃ K : ℝ, 0 < K ∧
      ∀ n : ℕ, ∀ A : Finset ((ZMod n) × (ZMod n)),
        IsAdmissibleAugmentationZN2 n A →
        (A.card ^ 3 ≤ C * n ^ 2) →
        spectralGapRatio n localGeneratorsZN2 (localGeneratorsZN2 ∪ A) ≤ K := ...
```

This is the first serious breakthrough theorem. It formalizes that locality is robust not just to finitely many shortcuts, but to **a mesoscopic cloud of shortcuts** up to a precise scale.

### Theorem 3: Explicit supercritical acceleration witness
A theorem proving that beyond a larger scale, there exist augmentations that force a large increase in spectral gap.

**Mathematical statement**
There exists \(c>0\) and an explicit family \(A_n\) with \(|A_n| \ge c n\) such that
\[
\frac{\lambda(S_n \cup A_n)}{\lambda(S_n)} \to \infty
\]
or at least grows at a specified polynomial rate.

Lean-style target:

```lean
theorem explicit_dense_augmentation_diverges :
    ∃ c : ℝ, 0 < c ∧
    ∃ Aseq : ∀ n : ℕ, Finset ((ZMod n) × (ZMod n)),
      (∀ n, IsAdmissibleAugmentationZN2 n (Aseq n)) ∧
      (∀ n, c * n ≤ (Aseq n).card) ∧
      Filter.Tendsto
        (fun n : ℕ => spectralGapRatio n localGeneratorsZN2 (localGeneratorsZN2 ∪ Aseq n))
        Filter.atTop
        Filter.atTop := ...
```

If the full divergence statement is too ambitious for the first pass, prove a quantitative lower bound such as
\[
\texttt{spectralGapRatio} \ge c' \, n^\alpha
\]
for infinitely many \(n\), using an explicit structured augmentation.

This theorem matters because it proves that universality genuinely breaks: the bounded-ratio phenomenon is not immortal.

### Theorem 4: Cross-domain theorem via Fourier-energy or random-matrix surrogate
You must include at least one theorem bridging to another domain. The strongest option is a bridge to **harmonic analysis / additive combinatorics**:

**Mathematical statement**
If the augmentation set \(A\) has small Fourier bias, then the augmented walk has improved spectral gap controlled by the maximal nontrivial Fourier coefficient of \(1_A\). This turns spectral acceleration into a theorem about pseudorandomness of subsets of \((\mathbb Z/n\mathbb Z)^2\).

Lean-style target:

```lean
theorem spectralGap_lower_bound_of_small_fourier_bias

    (A : Finset ((ZMod n) × (ZMod n)))
    (hA : IsAdmissibleAugmentationZN2 n A)

    spectralGapZN2 n (localGeneratorsZN2 ∪ A) ≥
      spectralGapZN2 n localGeneratorsZN2 + biasGainTerm n A ε := ...
```

This is a major cross-domain bridge:
- **Markov chains** ↔ **Fourier analysis on finite groups**
- **spectral graph theory** ↔ **additive combinatorics**

Even a weaker, rigorously formalized version would be a strong contribution.

## Proof Architecture: 3 Serious Strategy Paths

You must not rely on trivial automation. Use induction, `rcases`, `by_contra`, `field_simp`, `calc`, and layered reductions.

### Strategy A: Fourier-analytic exact diagonalization on \((\mathbb Z/n\mathbb Z)^2\) — most promising
This is the strongest route because the group is finite abelian, so every Cayley walk diagonalizes in the character basis.

1. **Diagonalize the walk explicitly.**
   Show that for each character \(\chi_{a,b}\),
   \[
   \mu_S(\chi_{a,b}) = \frac1{|S|}\sum_{s \in S} \chi_{a,b}(s).
   \]
   Then identify the spectral gap as
   \[
   1 - \max_{(a,b)\neq(0,0)} \Re \mu_S(\chi_{a,b})
   \]
   or the symmetric equivalent using real character averages.

2. **Separate local and augmentation contributions.**
   For \(S = L \cup A\),
   write the eigenvalue as a convex combination of the local average and augmentation average. Use this to compare the nontrivial spectrum of \(L\cup A\) against that of \(L\).

3. **Subcritical regime via bias averaging.**
   Show that if \(|A|^3 \ll n^2\), then augmentation cannot simultaneously suppress all low-frequency obstructions strongly enough to change the scaling by more than a constant factor. This is where you import telescoping/congestion intuition from the catalog but translate it into Fourier language.

Why this is most promising: the spectral quantity is exactly computable in principle, and the abelian model avoids heavy representation theory. It gives the cleanest Lean formalization path.

### Strategy B: Canonical paths / congestion perturbation
This strategy builds most directly on `CanonicalPaths.lean`.

1. Start from the local walk’s canonical path system and congestion bound.
2. Add augmentation edges and analyze how much the canonical path congestion can improve when only \(k\) extra edges are present.
3. Prove a quantitative upper bound on improvement in the subcritical regime by averaging overlap contributions and applying Cauchy–Schwarz to the rerouted flow.

This strategy is especially attractive for proving the **bounded-ratio theorem**, because the catalog likely already has lemmas controlling congestion under bounded augmentation. Your new insight is to make those constants depend on \(k\) and identify the threshold where the argument breaks.

### Strategy C: Explicit eigenfunction / Rayleigh quotient witness for the supercritical regime
This is the natural route for the lower-bound/divergence theorem.

1. Construct an explicit family of augmentations \(A_n\), perhaps line-like, arithmetic-progression-like, or pseudorandom, for which certain low-frequency Fourier modes are dramatically damped.
2. Evaluate the Rayleigh quotient or exact Fourier eigenvalue for these modes.
3. Show that the gap improves polynomially relative to the local \(n^{-2}\)-scale baseline.

This strategy is likely best for the **supercritical witness theorem** because it gives a constructive family and an explicit algorithmic demo.

For \(G_n = (\mathbb Z/n\mathbb Z)^2\), there exist constants \(0<c<C\) such that:

- if \(k_n^3 \le c n^2\), then
  \[

  \[
  \frac{\lambda(L_n \cup A_n)}{\lambda(L_n)} \to \infty.

A single convincing countertrend would falsify the conjecture.
