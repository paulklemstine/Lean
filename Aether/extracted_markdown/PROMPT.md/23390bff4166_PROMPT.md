### Visionary Context

Knuth-Bendix completion is not merely an algorithm — it is a **computational resolution of algebraic singularities**. Each critical pair is a "point where the algebraic variety fails to be smooth," and adding a rule resolves it. When completion terminates, we have constructed a **decision procedure for the word problem** bundled as a `ConvergentQuotientOptimizer`. This bridges rewriting theory, decidability theory, and computational algebra in one stroke: the same machinery that decides `x * 1 = x` in a group also optimizes neural network layers by identifying equivalent computational graphs.

### Proof Strategies

**Strategy A (Direct Inductive Construction):** Define `KBTerminates` as an inductive predicate tracking the finite sequence of completion steps. Prove soundness by induction on the step count, then apply Newman's Lemma (from catalog) for the confluent conclusion. *Most promising* because the induction mirrors the algorithm's execution.

**Strategy B (Homotopical — Critical Pairs as 2-Cells):** Model critical pairs as 2-dimensional cells in a rewriting 2-category. Completion adds 3-cell fillers. Termination = every 2-cell has a filler. Confluence becomes a computation of homotopies. *Elegant but harder to formalize.*

**Strategy C (Order-Theoretic — via Decreasing Diagrams):** Use van Oostrom's decreasing diagrams technique: prove that the union of the original system and all completion rules satisfies the decreasing diagram condition, which implies confluence without requiring separate termination + local confluence arguments. *Most efficient path to Theorem 2.*

**Recommendation:** Strategy A for Theorem 1, Strategy C for Theorem 2, then Strategy A again for Theorem 3 via the existing `ConvergentQuotientOptimizer` structure.

### Novel Definitions Required

```lean
/-- A critical pair: two terms arising from overlapping rule applications -/
structure CriticalPair (α : Type) [Signature α] where
  term₁ : Term α
  term₂ : Term α
  overlap : Term α  -- common ancestor
  rule₁ rule₂ : RewriteRule α
  position : Position  -- where the overlap occurs

/-- One step of Knuth-Bendix completion -/
inductive KBStep (α : Type) [Signature α] where
  | addRule (new_rule : RewriteRule α) (cp : CriticalPair α)
      (proof : cp.term₁ ≃ cp.term₂)
  | simplify (rule : RewriteRule α) (simplified : RewriteRule α)
      (proof : simplified.lhs reduces_to rule.lhs)

/-- The Knuth-Bendix completion procedure terminates when all critical pairs are joinable -/
def KBTerminates (α : Type) [Signature α] [DecidableEq α]
    (eqs : List (Equation α)) : Prop :=
  ∃ (rs : RewriteSystem α) (steps : List (KBStep α)),
    WellFounded rs ∧
    (∀ cp, IsCriticalPair cp rs → Joinable cp.term₁ cp.term₂ rs) ∧
    steps_derive_system steps rs eqs
```

### Cross-Domain Connections

1. **Rewriting ↔ Homological Algebra:** Critical pairs are 2-cells; completion adds 3-cell fillers. This is the computational analog of resolving syzygies in a free resolution. The "completion = convergence" theorem mirrors "acyclicity = exactness."

2. **Rewriting ↔ Decidability Theory:** A convergent system gives a decision procedure for the word problem. This connects to the **Novikov-Boone theorem** (word problem is undecidable in general) — KB completion *fails exactly when* the word problem is undecidable for the presentation. Formalize: `¬(KBTerminates eqs) → ¬(Decidable (WordProblem eqs))` for suitably pathological `eqs`.

3. **Rewriting ↔ Optimization Theory:** The `ConvergentQuotientOptimizer` normalizes expressions to canonical forms. This is identical in structure to **tropical normalization** in EML — normal forms are tropical idempotent representatives. The catalog's `certified_radius_inequality` uses normal forms for robustness; KB completion *generates* the normal form algorithm from axioms.

4. **Rewriting ↔ Category Theory:** A convergent system is a **coequalizer** in the category of terms modulo equations. The `ConvergentQuotientOptimizer` is a computational witness to this universal property.
