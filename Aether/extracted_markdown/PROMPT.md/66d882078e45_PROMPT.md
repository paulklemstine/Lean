The breakthrough is to show that **trapdoor decoding regions are the exposed faces of a canonical tropical rate–distortion object**, so that cryptographic asymmetry becomes a theorem of idempotent convex duality rather than an ad hoc hardness heuristic.

This must not be treated as a variant of existing tropical cryptography around prime congruence spectra, semiring hardness quotients, or non-Archimedean information duality. The new axis is:

## Core Mathematical Program

### Objects to define

You should formalize finite versions first.

1. **Finite closure-capacity system**
   - A finite type `α`
   - A closure operator `cl : Set α → Set α`
   - A capacity `cap : Set α → ℝ∞` or `ℝ≥0∞`
   - Conditions:
     - monotonicity,
     - normalization,
     - closure invariance `cap (cl S) = cap S`,
     - max-plus/modular behavior on closed finitely generated sets.

2. **Finite tropical code system**
   - A finite generator type `ι`
   - A tropical distortion gauge `δ : ι → ℝ∞`
   - A cost/weight function `w : ι → ℝ∞`
   - A family of sublevel decoding regions stable under residuation / tropical convex generation.

3. **Rate/support functionals**
   - Tropical rate:
     \[
     R(\lambda) := \inf_{i : \iota} \big(\delta(i) + \lambda\, w(i)\big)
     \]
     in min-plus notation.
   - Closure pressure/support:
     \[
     P(\lambda) := \inf\{ \operatorname{cap}(K) + \lambda\,\operatorname{cost}(K) : K \text{ closed generator object}\}
     \]
     or an equivalent support functional over extremal closed generators.

4. **Threshold spectrum**
   - The set of slopes / breakpoints / exposed faces where minimizers change.
   - This is the certified decoding phase diagram.

The finite case is enough for the first paradigm-shifting theorem. If the catalog already contains finite tropical convexity lemmas, residuation lemmas, support-function lemmas, or closure monotonicity infrastructure, build directly on those.

## Exact Theorem Targets

### Theorem 1: Canonical distortion gauge from closure capacities

Prove that every finite finitely generated idempotent closure-capacity system determines a canonical tropical distortion gauge on extremal closed generators, unique up to tropical additive normalization.

A mathematically sharp statement:

> Let `α` be finite, let `cl` be a finitary closure operator on `α`, and let `cap` be closure-invariant and modular on closed generators. Then there exists a function `δ : Extremal cl → ℝ∞` such that for every closed finitely generated object `K`,
> \[
> \operatorname{cap}(K) = \min_{e \in \mathrm{Ext}(K)} \delta(e)
> \]
> or the max-plus dual variant, depending on your chosen convention, and `δ` is unique up to addition of a global constant after canonical normalization `inf δ = 0`.

This is the theorem that turns capacities into distortion data.

#### Lean 4 target signature sketch
```lean
structure FiniteClosureCapacity (α : Type _) where
  cl        : Set α → Set α
  isClosed  : Set α → Prop := fun s => cl s = s
  cap       : Set α → ℝ≥0∞
  cl_mono   : Monotone cl
  cl_ext    : ∀ s, s ⊆ cl s
  cl_idem   : ∀ s, cl (cl s) = cl s
  cap_cl    : ∀ s, cap (cl s) = cap s
  cap_mono  : Monotone cap
  finite_univ : Finite α

-- Extremal generators can initially be implemented as a subtype of α
-- satisfying a minimality/extremality predicate relative to cl.

theorem exists_unique_canonicalDistortion
  {α : Type _} [Fintype α] [DecidableEq α]
  (C : FiniteClosureCapacity α) :
  ∃ δ : α → ℝ≥0∞,
    (Infᵢ δ = 0) ∧
    (∀ s : Set α, C.isClosed s →
      ∃ t ⊆ s, IsExtremalFamily C.cl t ∧
        C.cap s = iInf (fun a : t => δ a)) ∧
    (∀ δ' : α → ℝ≥0∞,
      (Infᵢ δ' = 0) →
      (∀ s : Set α, C.isClosed s →
        ∃ t ⊆ s, IsExtremalFamily C.cl t ∧
          C.cap s = iInf (fun a : t => δ' a)) →
      δ' = δ)
```

If exact uniqueness is too strong at first pass, prove uniqueness modulo additive tropical translation:
```lean
∃ c : ℝ≥0∞, ∀ a, δ' a = δ a + c
```
with normalization removing `c`.

### Theorem 3: Tropical rate–pressure duality and threshold spectrum theorem

This is the flagship theorem.

> For a finite tropical code / closure-capacity pair in canonical correspondence, the tropical rate functional equals the closure pressure/support functional under normalization, and the exposed faces / breakpoints of this piecewise-linear tropical convex object classify the certified decoding thresholds.

Concretely, define
\[
R(\lambda)=\inf_i (\delta(i)+\lambda w(i)).
\]
Then prove:
1. `R = P` under the correspondence.
2. Minimizer changes occur exactly at threshold values.
3. Exposed minimizer sets correspond to trapdoor decoding regions.
4. Monotone perturbations below threshold preserve the selected decoding region.

#### Lean 4 target signature sketch
```lean
def tropicalRate
  {α : Type _} (δ w : α → ℝ≥0∞) (λ : ℝ≥0∞) : ℝ≥0∞ :=
  iInf (fun a => δ a + λ * w a)

def closurePressure
  {α : Type _} (C : FiniteClosureCapacity α) (cost : Set α → ℝ≥0∞) (λ : ℝ≥0∞) :
  ℝ≥0∞ :=
  iInf (fun s : {s : Set α // C.isClosed s} => C.cap s.1 + λ * cost s.1)

theorem tropicalRate_eq_closurePressure
  {α : Type _} [Fintype α] [DecidableEq α]
  (C : FiniteClosureCapacity α)
  (δ : α → ℝ≥0∞)
  (w : α → ℝ≥0∞)
  (hδ : IsCanonicalDistortion C δ)
  (hw : CompatibleCost C w) :
  ∀ λ, tropicalRate δ w λ = closurePressure C (closedSetCostFromWeight w) λ
```

```lean
def IsThreshold (δ w : α → ℝ≥0∞) (λ : ℝ≥0∞) : Prop :=
  ¬ ∃! a, δ a + λ * w a = tropicalRate δ w λ

theorem threshold_iff_multiple_exposed_minimizers

  ∀ λ, IsThreshold δ w λ ↔
    ∃ a ≠ b, bothMinimizeAt δ w λ a b
```

### Theorem 4: Certified asymmetry theorem

This is the cryptographic theorem. It must be stated abstractly but sharply enough to be meaningful.

> In the abstract semiring model, if a code family admits a trapdoor witness selecting a unique exposed minimizer below a certified threshold, then decoding with the witness is monotone and stable under bounded tropical perturbations; conversely, inversion without any threshold certificate cannot distinguish among multiple exposed minimizers across threshold walls. Therefore the geometry itself certifies one-way compression/decompression asymmetry.

This is not computational complexity in the Turing sense yet; it is a **formal asymmetry theorem in the idempotent geometric model**. That is already a breakthrough if done cleanly.

#### Lean 4 target signature sketch
```lean
structure TrapdoorWitness (α : Type _) where
  certifies : ℝ≥0∞ → α → Prop
  sound     : ∀ λ a, certifies λ a → IsUniqueMinimizerAt λ a
  stable    : ∀ λ a, certifies λ a → PerturbationStableAt λ a

theorem certified_asymmetry
  {α : Type _} [Fintype α] [DecidableEq α]
  (δ w : α → ℝ≥0∞)
  (W : TrapdoorWitness α) :
  ∀ λ,
    (∃ a, W.certifies λ a) →
      EasyDecodeWithWitness δ w W λ ∧
      StableUnderBoundedPerturbation δ w λ ∧
      (AboveThreshold λ →
        NoCertificateOfUniqueInverse δ w λ)
```

If “easy” is too computationally loaded, formalize:
- unique certified minimizer exists,
- can be recovered from witness,
- remains minimizer under perturbations bounded by margin,
- non-witness inversion lacks uniqueness certificate.

## Suggested proof architecture

### Strategy A: Finite extremal decomposition via closure lattice
Most promising for Lean.

1. Define the lattice of closed sets for a finite closure operator.
2. Prove every closed set is generated by a finite extremal family.
3. Construct `δ` on extremals by Möbius-style minimal capacity extraction or direct inf-characterization.
4. Show closure pressure reduces to an infimum over extremals.
5. Deduce rate–pressure equality by rewriting both sides as the same lower envelope.

**Why promising:** finite lattice arguments, monotonicity, and infimum rewrites are Lean-friendly. This strategy minimizes dependence on heavy tropical convex machinery while still delivering the conceptual theorem.

### Strategy B: Tropical convex hull / support-function proof
Most conceptually elegant.

1. Associate to each generator `a` the point `(w(a), δ(a))`.
2. Show `R(λ)` is the lower tropical support function of the resulting point set.
3. Identify closed-generator capacities with the same support object under canonical normalization.
4. Use exposed-face theory to classify thresholds and decoding regions.

**Why powerful:** this makes the geometry transparent and directly ties thresholds to exposed faces. If the catalog already contains tropical polytope/support lemmas, use them aggressively.

### Strategy C: Fenchel duality / residuation proof
Potentially deepest, but maybe second-phase.

1. Define a tropical conjugate of the distortion/capacity functional.
2. Show residuation-stable sublevel sets are exactly those arising from closure systems.
3. Derive the threshold algorithm as a conjugacy computation.
4. Extract robustness from dual margin inequalities.

**Why important:** this could become the gateway to infinite-dimensional or categorical generalizations later. But unless the current catalog already has tropical conjugation infrastructure, use it as the conceptual capstone after Strategy A or B.

**Recommendation:** Execute **Strategy A** for the foundational theorem package, then package **Strategy B** as the geometric interpretation theorem. Use **Strategy C** only if catalog infrastructure makes it cheap.

1. **Finite closure lattice API**

2. **Canonical distortion extraction**

   - rewrite pressure over extremals,
   - identify both sides as the same finite infimum,
   - derive piecewise-linearity / lower-envelope behavior.

4. **Threshold characterization**
   - prove threshold iff minimizer non-uniqueness,
   - define exposed minimizer sets,
   - map them to decoding regions.

5. **Robustness margin**
   - define margin as gap between best and second-best minimizers,
   - prove perturbations bounded by half the margin preserve the minimizer,
   - use this as the certified decoding theorem.

6. **Functoriality**
   - quotient maps induce contraction of spectra / monotonicity of rate,
   - closure refinements induce order relations on pressure.
