### Join-irreducible closed sets
This is central. The skeleton vertices should be these objects, or a distinguished subset corresponding to principal futures.

```lean
def IsJoinIrreducibleClosed (C : FiniteCausalClosure X) (A : Finset X) : Prop :=
  IsClosed C A ∧ A.Nonempty ∧

    A = B ∪ D → A = B ∨ A = D
```

In finite closure lattices, join-irreducibles are the right algebraic atoms for reconstruction.

### Skeleton relation
Define a cover-style causal edge:
```lean
def SkeletonEdge (C : FiniteCausalClosure X) (A B : Finset X) : Prop :=
  IsJoinIrreducibleClosed C A ∧
```

This gives a Hasse-style DAG on irreducible closed sets. It is likely the most canonical minimal skeleton.

## Strategy A: Lattice-theoretic reconstruction via join-irreducibles
**Most promising.**

1. Prove the closed sets of `C` form a finite join-semilattice under union followed by closure:
   ```lean

   ```
   Show finite generation and identify join-irreducibles.

2. Prove every closed set is the join of join-irreducible closed sets, using finiteness.
   This is the algebraic heart: finite closure lattices are controlled by their irreducibles.

3. Define the skeleton as the cover relation on join-irreducibles and show:
   - the skeleton is acyclic,
   - its Alexandrov closure yields exactly the original closure operator,
   - minimality follows because any skeleton realizing the same closure must contain all irreducible generators.

Why this is best: it aligns perfectly with finite duality technology, keeps the proof combinatorial, and turns horizon structure into rank/filtration in a finite lattice.
