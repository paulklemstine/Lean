### Theorem A: Existence and Closure-Compatibility of Canonical RG

Formalize a canonical renormalized transfer operator and prove it preserves closure saturation.

Suggested Lean-level theorem:

```lean
theorem canonical_rg_closure_compatible
  {X T : Type*} [Finite X] [DecidableEq X]
  [CanonicallyOrderedCommSemiring T]
  (K Cl : (X → T) → (X → T))
  (hCl_ext : ∀ f, f ≤ Cl f)
  (hCl_mono : Monotone Cl)
  (hCl_idem : ∀ f, Cl (Cl f) = Cl f)
  (hK_mono : Monotone K)
  (hcompat : ∀ f, Cl (K (Cl f)) = Cl (K f)) :
  let Krg := fun f => Cl (K (Cl f))
  ∀ f, Cl (Krg f) = Krg f
```

This theorem is the minimal formal seed: the RG step lands in the closure-saturated sector.

A stronger variant worth pursuing:

```lean
theorem canonical_rg_iterates_closed
  {X T : Type*} [Finite X] [DecidableEq X]
```

This gives a genuine renormalization semidynamics on the closed sector.

### Theorem B: Monotonicity of Closure-Corrected Tropical c-Function

Define a c-function on observables first, then derive a system-level statement.

Suggested observable-level setup:
- `energy : (X → T) → α`
- `cap : (X → T) → α`
- `cfun f := energy f + cap f`
for an ordered additive codomain `α`, e.g. `ℕ`, `ℤ`, or `WithTop ℕ`.

Assume:
- `energy (Cl (K (Cl f))) ≤ energy f`
- `cap (Cl (K (Cl f))) ≤ cap f`

Then prove:

```lean
theorem cfun_monotone_along_rg
  {X T α : Type*} [Finite X] [DecidableEq X]
  [Preorder α]
  (K Cl : (X → T) → (X → T))
  (energy cap : (X → T) → α)
  (henergy : ∀ f, energy (Cl (K (Cl f))) ≤ energy f)
  (hcap : ∀ f, cap (Cl (K (Cl f))) ≤ cap f) :
  let Krg := fun f => Cl (K (Cl f))
  ∀ n f,
    let cfun := fun g => Prod.lex (energy g) (cap g)
    cfun ((Krg^[n+1]) f) ≤ cfun ((Krg^[n]) f)
```

If lexicographic codomain is awkward, prove coordinatewise monotonicity first:

```lean
theorem rg_monotone_energy_and_capacity
  ...
  :
  let Krg := fun f => Cl (K (Cl f))
  ∀ n f,
    energy ((Krg^[n+1]) f) ≤ energy ((Krg^[n]) f) ∧
    cap ((Krg^[n+1]) f) ≤ cap ((Krg^[n]) f)
```

Then package a corollary for `cfun`.

This is the formal c-theorem: a coarse-graining trajectory cannot increase the closure-corrected tropical free energy.

### Theorem C: Fixed-Point Rigidity / Equality iff Equilibrium

This is the conceptual heart. Prove that equality in the c-theorem characterizes idempotent transfer equilibrium with closure-saturated horizons.

Suggested notion:

```lean
def IsTransferEquilibrium
  (K Cl : (X → T) → (X → T)) (f : X → T) : Prop :=
  Cl f = f ∧ Cl (K f) = f
```

Then prove a rigidity theorem of the form:

```lean
theorem cfun_equality_iff_equilibrium
  {X T α : Type*} [Finite X] [DecidableEq X]
  [Preorder α]
  (K Cl : (X → T) → (X → T))
  (cfun : (X → T) → α)
  (hstrict :
    ∀ f, cfun (Cl (K (Cl f))) = cfun f →
      (Cl f = f ∧ Cl (K f) = f)) :
  let Krg := fun f => Cl (K (Cl f))
  ∀ f, cfun (Krg f) = cfun f ↔ IsTransferEquilibrium K Cl f
```

A more realistic two-stage route:
1. prove `equilibrium → equality`,
2. prove `equality → closed fixed point` under strict decrease assumptions.

If exact iff is too ambitious initially, prove:
- `cfun (Krg f) = cfun f → Krg f = Cl f`
- and then derive equilibrium from closure saturation.

This theorem is what elevates the result beyond monotonicity folklore: it identifies the exact endpoint structure of irreversible tropical RG.

1. Define `Krg f := Cl (K (Cl f))`.
2. Prove every iterate is closed: `Cl ((Krg^[n]) f) = (Krg^[n]) f`.
