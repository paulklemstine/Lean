## Assignment: Phase Transition in Certificate Complexity

**Mode:** `discover` with a `prove` core

You are not being asked to numerically rediscover the random 3-SAT threshold. You are being asked to create a new mathematical language for **certificate phase transitions** in structured SAT encodings arising from circuit lower bound questions, beginning with triangle detection. The target is a field-opening bridge between:

- monotone circuit complexity,
- hypergraph transversals and certificate systems,

The immediate object is not “triangle detection circuits” in full generality, but a mathematically clean formal proxy: SAT instances generated from **certificate-refutation constraints** attached to triangle witnesses and certificate subsets. The breakthrough is to prove rigorous monotonicity, threshold-window, and obstruction theorems for this proxy, then back them with a verified generator and computational experiment.

Build on catalog material around `Pythagorean/Hypergraph/Defs.lean`, especially any definitions/theorems around monotone satisfiability, hitting sets, and equivalences of the form `hitting_set_iff_...`. ## Core Mathematical Vision

The decisive insight is this:

> A circuit-refutation SAT instance for triangle detection can be modeled as a monotone constraint system induced by a hypergraph of local triangle certificates. Satisfiability under random certificate deletion should then behave like a monotone property on a finite probability space, hence exhibit a threshold phenomenon. The nontrivial work is to define a structurally meaningful threshold parameter and prove rigorous finite theorems that make the “4.2 ± 0.3” conjecture mathematically legible.

You should formalize a **certificate hypergraph** whose vertices are candidate certificate atoms and whose hyperedges are minimal local obstructions to a valid triangle-refuting explanation. The associated SAT instance is satisfiable exactly when a suitable transversal/avoidance condition holds. This recasts circuit-refutation complexity as a hypergraph threshold problem.

This is already a conceptual advance: it turns lower-bound heuristics into a measurable phase diagram.

## New Definitions You Must Introduce

You must define at least one genuinely new concept; ideally define all of the following.

### 1. Certificate obstruction hypergraph
A finite hypergraph whose vertices are certificate atoms and whose edges are minimal jointly incompatible certificate sets.

Suggested Lean-facing shape:
```lean
structure CertificateObstructionSystem (α : Type _) [Fintype α] where
  Obstruction : Finset α → Prop
  obstruction_nonempty :
    ∀ s : Finset α, Obstruction s → s.Nonempty
```

or more concretely via a family of finite obstructions:
```lean
structure CertificateObstructionSystem (α : Type _) [DecidableEq α] where
  obstructions : Finset (Finset α)
  nonempty_mem : ∀ s ∈ obstructions, s.Nonempty
```

### 2. Certificate satisfiability under deletion
For a set `S` of retained certificate atoms, define satisfiability as “every obstruction is avoided” or dually “there exists no obstruction fully contained in `S`”, depending on encoding.

```lean
def CertificateSatisfiable
    {α : Type _} [DecidableEq α]
    (C : CertificateObstructionSystem α) (S : Finset α) : Prop :=
  ∀ o ∈ C.obstructions, ¬ o ⊆ S
```

This monotone/antitone choice should be made carefully and used consistently.

### 3. Critical certificate ratio / transversal density
A finite combinatorial proxy for clause-to-variable ratio or obstruction density.

For example:
```lean
def obstructionDensity
    {α : Type _} [Fintype α] [DecidableEq α]
    (C : CertificateObstructionSystem α) : Rat :=
  (C.obstructions.card : Rat) / (Fintype.card α : Rat)
```

and/or a more structural parameter:
```lean
def averageObstructionSize
    {α : Type _} [DecidableEq α]
    (C : CertificateObstructionSystem α) : Rat := ...
```

### 4. Sharpness window / threshold interval
A finite definition that can be proved without asymptotic probability theory.

```lean
def hasThresholdWindow
    {α : Type _} [Fintype α] [DecidableEq α]
    (C : CertificateObstructionSystem α) (k₁ k₂ : ℕ) : Prop := ...
```

You may define this in terms of cardinality slices:
- all subsets of size `≤ k₁` are satisfiable,
- all subsets of size `≥ k₂` are unsatisfiable,
- the interval `[k₁, k₂]` is the finite transition window.

This gives a rigorous notion of “phase transition” in finite instances.

### Theorem 2: Hitting-set equivalence for satisfiability
Translate certificate satisfiability into a transversal statement in the obstruction hypergraph.

If `R` is the removed set and `U` is the universe of certificate atoms, then retained satisfiability is equivalent to `R` being a hitting set for the obstruction family.

**Mathematical statement**
Let `S` be the retained set and `R = U \ S`. Then
`CertificateSatisfiable C S ↔ ∀ o ∈ C.obstructions, (o ∩ R).Nonempty`.

This should explicitly build on catalog hypergraph/hitting-set lemmas.

**Lean 4 type signature**
```lean
theorem certificateSatisfiable_iff_compl_hittingSet
    {α : Type _} [Fintype α] [DecidableEq α]
    (C : CertificateObstructionSystem α)
    (S : Finset α) :
    CertificateSatisfiable C S ↔
      ∀ o ∈ C.obstructions,
        ((o.filter fun a => a ∉ S)).Nonempty := by
  ...
```

If the catalog already has a stronger hitting-set equivalence, adapt your definitions to reuse it rather than reproving everything from scratch.

**Why this matters**
This is the bridge from SAT/certificate complexity to hypergraph transversal theory. It converts computational experiments into combinatorial geometry.

### Theorem 3: Existence of a finite transition window
For every finite obstruction system, there exist cardinality thresholds `k_sat ≤ k_unsat + 1` separating guaranteed satisfiability from guaranteed unsatisfiability.

One robust formulation:
- define
  - `kSatMax := max {k | every subset of size ≤ k is satisfiable}`
  - `kUnsatMin := min {k | every subset of size ≥ k is unsatisfiable}`
- prove these are well-defined under a mild nondegeneracy hypothesis, and satisfy `kSatMax < kUnsatMin` or a closely related order relation depending on your convention.

A more Lean-friendly theorem:
```lean
theorem exists_transition_index
    {α : Type _} [Fintype α] [DecidableEq α]
    (C : CertificateObstructionSystem α)
    (h_nontriv_sat : CertificateSatisfiable C ∅)
    (h_nontriv_unsat : ¬ CertificateSatisfiable C Finset.univ) :
    ∃ k : ℕ,
      (∀ S : Finset α, S.card ≤ k → CertificateSatisfiable C S) ∧
      (∀ S : Finset α, k < S.card → ¬ CertificateSatisfiable C S) := by
  ...
```

This exact formulation may need adjustment if the threshold is not perfectly sharp for arbitrary systems. If so, prove a **window theorem** with two indices:

```lean
theorem exists_transition_window
    {α : Type _} [Fintype α] [DecidableEq α]
    (C : CertificateObstructionSystem α)
    (h_nontriv_sat : CertificateSatisfiable C ∅)
    (h_nontriv_unsat : ¬ CertificateSatisfiable C Finset.univ) :
    ∃ k₁ k₂ : ℕ,
      k₁ ≤ k₂ ∧
      (∀ S : Finset α, S.card ≤ k₁ → CertificateSatisfiable C S) ∧
      (∀ S : Finset α, k₂ ≤ S.card → ¬ CertificateSatisfiable C S) := by
  ...
```

**Why this matters**
This is the first rigorous finite theorem deserving the phrase “phase transition” in this setting.

## Proof Strategy Architecture

You must not merely state theorems; you must pursue them with multi-step arguments.

### Strategy A: Hypergraph-transversal route
Most promising.

1. Define certificate satisfiability so that unsatisfiability means “some obstruction is fully present.”
2. Use catalog hypergraph lemmas to translate complement sets into hitting sets/transversals.
3. Prove monotonicity and threshold-window theorems by cardinality arguments on finite subsets.

**Why promising:** It directly leverages existing catalog infrastructure and converts SAT language into a mature combinatorial framework.

### Strategy B: Boolean lattice / order-theoretic route
1. View subsets of certificate atoms as points in the Boolean lattice.
2. Prove satisfiable sets form a downward-closed family and unsatisfiable sets an upward-closed family.
3. Define the transition indices via extremal ranks in this lattice and prove existence by finite well-ordering.

**Why promising:** Very Lean-friendly. Finite cardinality and subset monotonicity interact well with `Finset` and induction on cardinality.

### Strategy C: Simplicial-complex route
1. Show satisfiable sets form an abstract simplicial complex.
2. Use minimal nonfaces = obstructions to characterize the system.
3. Derive threshold bounds from minimal nonface size and packing arguments.

**Why promising:** This is the most conceptually novel and creates a topology-complexity bridge. It may be heavier to formalize, but even partial success would be field-opening.

**Recommended order:** A → B → C.
