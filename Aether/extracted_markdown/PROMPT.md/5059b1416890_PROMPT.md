## PROOF STRATEGY REQUIREMENTS

For each main theorem, pursue 3–5 explicit proof steps, not one-line `simp` proofs. Use diverse tactics across the file:
- `induction` on finite cardinality or lists/multisets where appropriate
- `rcases` to unpack witnesses from nonzero counts or subtype elements
- `by_contra` for rigidity and separation statements
- `omega` for finite-cardinality arithmetic over `Nat`
- `linarith` for real/rational inequality steps
- `field_simp` when normalizing rational densities
- `have`, `calc`, `nlinarith`, `simp_rw`, `Finset.card_bind`, `Finset.mem_product`

Suggested proof pathways:

### Path A: Finset counting
Most promising for the core algebra/combinatorics theorems.
- Encode energies/collisions as `Finset` cardinalities of subtypes or filtered products.
- Use explicit witnesses to show positivity.
- Compare two counts via maps into `differenceSpectrum`.
- Derive cardinality inequalities by bounding fiber sizes.

### Path B: Orbit/fiber decomposition
Best for symmetry and Galois-inspired theorems.
- Decompose collisions by orbits under a finite group action.
- Use `Function.Injective` on quotient-like observations where possible.
- Relate orbit collisions to ordinary additive collisions by forgetting symmetry.

### Path C: Metric certification
Best for the ML/physics impact theorems.
- Define a finite minimum pairwise distance over a `Finset.image`.
- Show positivity under injectivity/separation.
- Take radius `r = gap / 2` or a normalized variant `gap / (2 * L)`.
- Use triangle inequality plus action Lipschitz control to prove uniqueness/certification.

### Path D: Rational normalization / entropy density
- Define densities by dividing natural counts by `(Fintype.card α)^2` or `(Fintype.card α)^4`.
- Convert bounds from naturals to rationals/reals.
- Use `field_simp` and positivity lemmas on finite cardinals.

When a theorem is too ambitious in maximal generality, **weaken hypotheses minimally but explicitly**:
- replace `[AddCommGroup G]` by `[AddGroup G] [DecidableEq G]` only if subtraction notation remains manageable;
- assume `Nonempty α` if denominators need positivity;
- assume `Finite α` + `[Fintype α]` when constructing minima over finite images;
- use finite group actions instead of full automorphism groups if direct Galois formalization becomes too heavy.
