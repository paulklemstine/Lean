## Central Vision

The core insight is that for a group isomorphic to `GL_n(𝔽_q)`, the characteristic polynomial of a random element is not arbitrary noise: it encodes two orthogonal global parameters.

- Its **degree** rigidly determines `n`.
- Its **factorization statistics** are asymptotically governed by `q` in ways that can be made quantitative.

This suggests a new paradigm:

> **Recognize a black-box matrix group by certified statistical laws of its characteristic polynomials.**

That is a field-opening direction because it replaces ad hoc recognition by a mathematically analyzable “spectral fingerprint.” It has immediate implications for:
- black-box recognition in GAP/Magma,
- certified finite-group cryptanalytic preprocessing,
- probabilistic model selection for algebraic data,
- and potentially “representation learning” over finite groups, where the observable is not the group law itself but spectral summaries of sampled actions.

### Theorem 3: Distinct field sizes are separated by polynomial statistics

This is the conceptual heart. You need a theorem showing that a statistic of monic degree-`n` polynomials over finite fields distinguishes field sizes. One clean route is to work first in the polynomial universe, then transfer heuristically/algorithmically to characteristic polynomials of random matrices.

A candidate theorem:

```lean
theorem irreducible_rate_strict_mono_in_q
    {n q₁ q₂ : ℕ}
    (hn : 2 ≤ n) (hq : 2 ≤ q₁) (hqq : q₁ < q₂) :
    ((num_irreducible_monic q₁ n : ℚ) / q₁^n) <
    ((num_irreducible_monic q₂ n : ℚ) / q₂^n) := by
```

where `num_irreducible_monic q n` is the number of monic irreducible degree-`n` polynomials over `𝔽_q`. If strict monotonicity is too strong globally, prove a separated quantitative inequality for tested values or under stronger hypotheses:

```lean
theorem irreducible_rate_lower_upper_bounds
    {q n : ℕ} (hq : 2 ≤ q) (hn : 1 ≤ n) :
    |((num_irreducible_monic q n : ℚ) / q^n) - (1 / n)| ≤ (C n) / q := by
```

using Möbius inversion / the prime polynomial theorem.

Then derive a recognizer-separation theorem:

```lean
theorem field_size_identifiable_from_irreducible_rate
    {n q₁ q₂ : ℕ}
    (hneq : q₁ ≠ q₂) :
    ∃ δ > 0, ∀ r₁ r₂,
      |r₁ - irreducibleRate n q₁| < δ →
      |r₂ - irreducibleRate n q₂| < δ →
      False := by
```

**Why this matters:** this is the first rigorous statement that the “spectral statistics” contain enough information to recover the field size.

## Suggested Proof Architecture

You must include **2–3 proof strategy paths** in your work and pursue the most promising one. Here are the recommended routes.

### Strategy A: Polynomial-first recognition (most promising)

1. Prove exact counting or asymptotic theorems for monic irreducible polynomials over `𝔽_q` using Möbius inversion and standard finite-field polynomial counting.
2. Define a theoretical fingerprint `irreducibleRate n q`, `splitRate n q`, etc.
3. Show these rates separate different `q`.
4. Use concentration inequalities to derive sample complexity for recovering `q` from empirical rates.
5. Transfer this to random matrices by showing that characteristic polynomial degree always gives `n`, and irreducible charpolys feed certificate infrastructure.

**Why most promising:** Mathlib is strongest on algebraic identities and finite combinatorics. You can prove robust theorems about polynomial distributions even if full random-matrix measure theory is cumbersome. This still yields a major result because the algorithm can compare observed matrix data to certified polynomial-side predictions.

---

### Strategy B: Singer-cycle / cyclic-matrix route

1. Show that matrices with irreducible characteristic polynomial are cyclic and generate a field extension.
2. Connect such matrices to Singer-type elements and existing generation certificates.
3. Prove that the probability of seeing such elements depends detectably on `q` and `n`, perhaps through lower bounds rather than exact formulas.
4. Build a recognizer using the presence/frequency of these certified elements.

**Why powerful:** this directly exploits `Algebra/MatrixGroupGeneration.lean` and yields a structurally rich theorem. It may be less analytically sharp than Strategy A, but it gives a deeper bridge between recognition and generation theory.

---

### Strategy C: Factorization-profile recognition

1. For each sampled characteristic polynomial, record its factorization partition of `n`.
2. Compare the empirical partition distribution with the partition statistics predicted over `𝔽_q[x]`.
3. Prove injectivity (or finite ambiguity with explicit resolution) of the map
   \[
   q \mapsto \text{factorization profile distribution at degree } n.
   \]
4. Resolve ambiguous pairs using a second statistic such as squarefreeness or linear-factor frequency.

**Why exciting:** this resembles statistical mechanics and machine learning feature extraction: a high-dimensional observable compresses structural information about the underlying field. This is the most “science-fiction” route and should at least appear in `FUTURE_DIRECTIONS.md`.
