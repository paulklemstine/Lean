# Research Direction
# Future Directions: Certified Generation Probability and Dixon's Theorem

The decisive breakthrough is to replace the slogan “two random permutations generate `S_n` or `A_n` with high probability” by a **certified obstruction expansion**:
\[
P(\langle \sigma,\tau\rangle \neq S_n,A_n)
=
P(\text{intransitive})
+
P(\text{transitive imprimitive})
+
P(\text{primitive exceptional}),
\]
with the first term made explicit to second order and the remaining terms shown to be lower-order. This is not just a tidy estimate: it is a formal probabilistic anatomy of subgroup structure in `SymmetricGroup α`, and it opens a path from asymptotic finite group theory to machine-checked quantitative generation theorems.

The first theorem should be completely elementary, sharp enough to matter, and formalizable now.

## Target Theorem 1: Tight elementary intransitive obstruction bound

### Precise statement
For every integer `n ≥ 6`,
\[
\sum_{k=1}^{\lfloor n/2\rfloor}\frac{1}{\binom{n}{k}}
\le \frac{1}{n}+\frac{3}{n^2}.
\]
Equivalently, the probability that two independent uniformly random permutations of `n` letters both stabilize some common proper subset is at most `1/n + 3/n^2`, after the standard union bound over subset stabilizers of size `k ≤ n/2`.

This is the right first battlefield because it converts the vague “intransitive part is about `1/n`” into a theorem with explicit constants, and that explicitness is exactly what formal mathematics can do better than classical asymptotics.

### Lean 4 target signature
A clean arithmetic formulation:
```lean
theorem sum_inv_choose_le_one_div_add_three_div_sq
    (n : ℕ) (hn : 6 ≤ n) :
    ∑ k in Finset.Icc 1 (n / 2),
      (1 : ℚ) / (Nat.choose n k)
      ≤ (1 : ℚ) / n + (3 : ℚ) / (n^2)
```

A more probability-flavored corollary, if you build the uniform measure on pairs of permutations:
```lean
theorem intransitive_obstruction_prob_le
    (n : ℕ) (hn : 6 ≤ n) :
    obstructionProbIntransitiveTwoGens n
      ≤ (1 : ℚ) / n + (3 : ℚ) / (n^2)
```
where `obstructionProbIntransitiveTwoGens n` is defined via the union bound over subset stabilizers, not yet the exact probability.

### Why this is a breakthrough
This theorem is elementary but strategically transformative. It gives a **certified first-order obstruction term** for Dixon’s theorem with a machine-checkable constant. Once formalized, it becomes a reusable kernel for:
- explicit lower bounds on generation probability,
- comparison between `S_n` and `A_n`,
- multi-generator extensions,
- certified asymptotics for random subgroup algorithms.

The conceptual gain is that subgroup geometry is converted into a summation problem over reciprocal binomial coefficients, and that summation is fully formalizable.

## Proof strategy architecture for Target Theorem 1

### Strategy A: ratio-domination + finite tail compression
Most promising.

1. Isolate the first two terms:
   \[
   \sum_{k=1}^{\lfloor n/2\rfloor}\frac1{\binom nk}
   =
   \frac1n + \frac{2}{n(n-1)} + \sum_{k=3}^{\lfloor n/2\rfloor}\frac1{\binom nk}.
   \]

2. Prove monotone growth of binomial coefficients up to `n/2`, and stronger ratio growth on the early range:
   \[
   \frac{\binom n{k+1}}{\binom nk}=\frac{n-k}{k+1}.
   \]
   Show this is at least `2` whenever `k ≤ (n-2)/3`. This gives geometric decay of reciprocals in the initial segment.

3. For the remaining tail near `n/2`, use a crude but strong uniform lower bound such as
   \[
   \binom nk \ge \binom n3 \quad \text{for } 3 \le k \le \lfloor n/2\rfloor,
   \]
   hence
   \[
   \sum_{k=3}^{\lfloor n/2\rfloor}\frac1{\binom nk}
   \le \frac{n/2}{\binom n3}
   = O(n^{-2}),
   \]
   with enough room to fit into the constant `3`.

Why promising: it avoids analytic machinery and uses only identities and inequalities on `Nat.choose`, which are already close to Mathlib’s comfort zone.

---

### Strategy B: convexity / unimodality compression
1. Use symmetry and log-concavity of binomial coefficients to show the reciprocal sequence is decreasing on `1 ≤ k ≤ n/2`.
2. Bound the tail by comparing it to an integral or by a simple “first term times number of terms” estimate:
   \[
   \sum_{k=3}^{\lfloor n/2\rfloor}\frac1{\binom nk}
   \le \frac{\lfloor n/2\rfloor-2}{\binom n3}.
   \]
3. Verify the resulting rational inequality
   \[
   \frac{2}{n(n-1)} + \frac{\lfloor n/2\rfloor-2}{\binom n3} \le \frac{3}{n^2}
   \]
   for all `n ≥ 6`.

Why useful: less delicate than ratio splitting; perhaps easier if the library already has monotonicity of `Nat.choose` on the left half.

---

### Strategy C: exact finite verification after symbolic reduction
1. Prove a universal symbolic bound reducing the theorem to a simpler rational inequality valid for all `n ≥ N`.
2. Check the finitely many remaining cases `6 ≤ n < N` by exact computation in `ℚ`.
3. Package the theorem as “asymptotic argument + certified finite base cases.”

Why useful: a practical Lean strategy if some inequalities are annoying. Formal mathematics often benefits from hybrid symbolic/computational closure.

## Target Theorem 2: exact common-fixed-subset obstruction formula

This theorem upgrades the union-bound ingredients into exact counting data.

### Precise statement
For fixed `r ≥ 1`, the probability that `r` independent uniform permutations in `S_n` all fix every point of some common `j`-element subset is
\[
\left(\frac{(n-j)!}{n!}\right)^r.
\]
By inclusion-exclusion, the probability that they have a common fixed point is exactly
\[
\sum_{j=1}^n (-1)^{j+1}\binom{n}{j}\left(\frac{(n-j)!}{n!}\right)^r.
\]

For `r = 2`, this becomes
\[
\sum_{j=1}^n (-1)^{j+1}\binom{n}{j}\left(\frac{(n-j)!}{n!}\right)^2.
\]

This is not merely combinatorics; it gives an exact probabilistic observable attached to the point-stabilizer obstruction, and it is the prototype for all higher obstruction classes.

### Lean 4 target signature
```lean
theorem prob_common_fixed_point_r_generators
    (n r : ℕ) :
    commonFixedPointProb n r
      =
    ∑ j in Finset.Icc 1 n,
      ((-1 : ℚ) ^ (j + 1)) *
      (Nat.choose n j) *
      (((Nat.factorial (n - j) : ℚ) / (Nat.factorial n)) ^ r)
```

A counting version may be easier first:
```lean
theorem card_tuples_fixing_given_jset
    (n r j : ℕ) (hj : j ≤ n) :
    cardTuplesFixingGivenJSet n r j
      = (Nat.factorial (n - j)) ^ r
```

### Why this matters
This theorem makes the first obstruction class exact, not asymptotic. It creates a formal bridge between:
- random generation in finite groups,
- inclusion-exclusion on permutation actions,
- Poisson-style rare-event heuristics.

It also gives the correct template for `r`-generator random generation, where the obstruction profile changes dramatically.

## Proof strategy architecture for Target Theorem 2

### Strategy A: direct counting on tuples of permutations
Most promising.

1. For a fixed subset `J : Finset (Fin n)` of size `j`, count permutations fixing every element of `J`; there are `(n-j)!`.
2. Independence gives `(n-j)!^r` tuples of `r` permutations.
3. Apply inclusion-exclusion over all `j`-element subsets.

This is the cleanest finite combinatorics route.

---

### Strategy B: subgroup-index probability
1. Identify the pointwise stabilizer of a fixed `j`-set as a subgroup of `S_n` of cardinality `(n-j)!`.
2. Uniform probability that one random permutation lands in that subgroup is
   \[
   \frac{(n-j)!}{n!}.
   \]
3. Raise to the `r`th power and perform inclusion-exclusion.

Why useful: better aligned with the later subgroup-obstruction formalism.

---

### Strategy C: action-theoretic Möbius inversion on the Boolean lattice
1. View “common fixed point” as nonemptiness of the common fixed set.
2. Use the Boolean lattice of subsets of `{1,…,n}` and Möbius inversion.
3. Derive the same formula conceptually from orbit-counting principles.

Why exciting: opens the door to formal incidence-algebra methods in finite group generation.

## Target Theorem 3: obstruction decomposition for non-generation

### Precise statement
Let `P_fail(n)` be the probability that two random permutations in `S_n` do not generate a subgroup containing `A_n`. Then
\[
P_{\mathrm{fail}}(n)
\le
P_{\mathrm{intrans}}(n)
+
P_{\mathrm{imprim}}(n)
+
P_{\mathrm{prim\_exc}}(n),
\]
where:
- `P_intrans(n)` is bounded by the sum of reciprocal binomial coefficients,
- `P_imprim(n)` is bounded by a sum over block systems,
- `P_prim_exc(n)` is bounded by a sum over primitive maximal subgroups not containing `A_n`.

The fully formal theorem may first be an inequality over a finite union of subgroup classes, before any asymptotic classification input.

### Lean 4 target signature
A structural theorem:
```lean
theorem fail_to_generate_le_obstruction_sum
    (n : ℕ) :
    failGenerateProb n
      ≤ intransitiveProbBound n
      + imprimitiveProbBound n
      + primitiveExceptionalProbBound n
```

A stronger theorem if you define the three events directly:
```lean
theorem fail_event_subset_union_obstructions
    (n : ℕ) :
    failGenerateEvent n ⊆
      intransitiveEvent n ∪ imprimitiveEvent n ∪ primitiveExceptionalEvent n
```

### Why this is revolutionary
This is the machine-checkable version of the subgroup-structure skeleton behind Dixon’s theorem. It turns an asymptotic group-theoretic narrative into a modular formal object. Once built, any future classification input improves the probability bound automatically. This is how one should formalize deep asymptotic theorems: separate the exact combinatorial scaffold from the difficult classification-dependent estimates.

1. Show failure to generate `A_n` or `S_n` means the generated subgroup lies in some maximal subgroup not containing `A_n`.

Why exciting: it reframes finite permutation group theory in order-theoretic language, useful for later formalization of O’Nan–Scott fragments.

## Hypothesis B: Transitive non-alternating obstruction is `O(1/n^2)`

**Conjecture:** The probability that two random permutations in `S_n` generate a transitive subgroup that is neither `A_n` nor `S_n` is `O(1/n^2)` for `n ≥ 5`.

More precisely,
\[
P(\mathrm{fail})
=
P(\mathrm{intransitive})
+
P(\mathrm{transitive,\ imprimitive})
+
P(\mathrm{primitive,\ not}\ A_n,S_n),
\]
with:
- imprimitive contribution `O(1/n^2)` via wreath-product type stabilizers,
- primitive exceptional contribution exponentially small or at worst much smaller than `1/n^2`.

### Lean 4 target signature
A weak-but-formalizable version first:
```lean
theorem transitive_nonalt_prob_le
    (n : ℕ) :
    transitiveNonAltProb n
      ≤ imprimitiveProbBound n + primitiveExceptionalProbBound n
```

An aspirational asymptotic wrapper:
```lean
theorem transitive_nonalt_prob_bigO_inv_sq :
    IsBigO atTop
      (fun n : ℕ => transitiveNonAltProb n)
      (fun n : ℕ => (1 : ℚ) / (n^2))
```

### Test
For `n = 5, 6, 7`, compute exact contributions of obstruction classes by exhaustive enumeration if practical, or by subgroup-index summation over known maximal subgroups.

### Impact
This would isolate the structural sources of non-generation and show that asymptotically only point stabilizers matter at first order. Combined with Hypothesis A, it yields a formal Dixon-style theorem with explicit constants.

### Refutation criterion
Find a family of transitive maximal subgroups with contribution `Ω(1/n)`.

## Hypothesis C: Multi-generator point-stabilizer formula

**Conjecture:** For fixed `r ≥ 2`, the probability that `r` random permutations in `S_n` have a common fixed point is exactly
\[
\sum_{j=1}^{n} (-1)^{j+1} \binom{n}{j} \left(\frac{(n-j)!}{n!}\right)^r.
\]

This should be the exact inclusion-exclusion formula for the point-stabilizer obstruction.

### Lean 4 target signature
```lean
theorem common_fixed_point_prob_eq_inclusion_exclusion
    (n r : ℕ) :
    commonFixedPointProb n r
      =
    ∑ j in Finset.Icc 1 n,
      ((-1 : ℚ) ^ (j + 1))
        * (Nat.choose n j)
        * (((Nat.factorial (n - j) : ℚ) / Nat.factorial n) ^ r)
```

### Key asymptotic corollary to seek
For fixed `r`,
\[
P(\text{common fixed point})
=
\frac{1}{n^{r-1}} + O\!\left(\frac{1}{n^r}\right).
\]
For `r=2`, this recovers the first-order `1/n` obstruction. For larger `r`, it predicts much faster generic generation.

### Impact
This opens a full **multi-generator random generation theory** in Lean, with exact formulas rather than soft heuristics.
