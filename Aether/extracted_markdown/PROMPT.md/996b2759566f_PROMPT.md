### Theorem 1: Positivity and gauge invariance of GFF energy
This is the entry point from catalog Laplacian theory to Gaussian mechanics.

**Mathematical statement**

For any finite weighted graph with symmetric nonnegative edge weights and weighted Laplacian `L`, the quadratic form
\[
E_L(x) = x^\top L x
\]
is nonnegative, and is invariant under adding constants:
\[
E_L(x + c\mathbf{1}) = E_L(x).
\]

This identifies the physical state space with potentials modulo constants.

**Lean 4 type signature sketch**
```lean
theorem graphGFFEnergy_nonneg
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (L : Matrix ι ι ℝ)
    (hL_psd : ∀ x : ι → ℝ, 0 ≤ GraphGFFEnergy L x) :
    ∀ x : ι → ℝ, 0 ≤ GraphGFFEnergy L x
```

A stronger targeted statement, if you can express Laplacian row-sum zero:
```lean
theorem graphGFFEnergy_add_const
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (L : Matrix ι ι ℝ)
    (h_rowsum : ∀ i, ∑ j, L i j = 0)
    (h_symm : IsSymm L) :
    ∀ (x : ι → ℝ) (c : ℝ),
      GraphGFFEnergy L (fun i => x i + c) = GraphGFFEnergy L x
```

**Why this matters**
This theorem is the rigorous gateway from the graph Laplacian to the GFF measure on the quotient by constants. It turns a spectral statement into a physical gauge symmetry statement.

### Theorem 2: Reduced determinant partition function formula
This is the central statistical mechanics theorem.

**Mathematical statement**

Let `Γ` be a connected finite weighted graph with weighted Laplacian `L`. Fix a vertex `v₀`, and let `L_red` be the reduced Laplacian obtained by deleting the `v₀` row and column. Then the pinned Gaussian free field partition function satisfies
\[
Z_{\mathrm{pin}}(\Gamma,v_0)
=
(2\pi)^{(n-1)/2}\, (\det L_{\mathrm{red}})^{-1/2}.
\]

If you also define a genus-normalized periodic quantity in your metric-graph framework, explain carefully whether the exponent should be `g/2` or `(n-1)/2`; do **not** blur these. One of the most important contributions of this project may be to identify the exact hypothesis under which a genus-based formula is valid and when the correct quantity is instead rank of the Laplacian. If the original conjecture as stated is too optimistic, isolate the correct theorem and state the stronger genus-form only as a conjecture.

**Lean 4 type signature sketch**
```lean
theorem pinnedGFF_partition_function_formula
    {n : ℕ}
    (Lred : Matrix (Fin n) (Fin n) ℝ)
    (hpd : PositiveDefinite Lred) :
    gaussianIntegral
      (fun x : (Fin n → ℝ) => Real.exp (-(GraphGFFEnergy Lred x) / 2))
    =
    (2 * Real.pi) ^ (n / 2 : ℝ) * Real.sqrt (1 / Lred.det)
```

More realistically, if full measure-theoretic Gaussian integration is too expensive in Lean for this cycle, prove an **algebraic-normalization theorem**:

```lean
def GFFPartitionPrefactor (Lred : Matrix (Fin n) (Fin n) ℝ) : ℝ :=
  (2 * Real.pi) ^ ((n : ℝ) / 2) / Real.sqrt Lred.det

theorem pinnedGFF_partition_prefactor_well_defined
    {n : ℕ}
    (Lred : Matrix (Fin n) (Fin n) ℝ)
    (hpd : PositiveDefinite Lred) :
    0 < Lred.det ∧ 0 < GFFPartitionPrefactor Lred
```

and then specialize to explicit graph families where the determinant can be computed exactly.

**Why this matters**
This theorem is the exact bridge from combinatorial Laplacian geometry to thermodynamic normalization. It opens a formal route toward spanning tree/GFF duality, zeta regularization on metric graphs, and tropical statistical mechanics.

### Theorem 3: Covariance equals effective resistance observable
This is the cross-domain theorem and should be treated as a flagship result.

**Mathematical statement**

Let `L⁺` denote the Moore–Penrose pseudoinverse of the Laplacian of a connected weighted graph. Then for the pinned or zero-mean GFF,
\[
\mathrm{Var}(\phi_i - \phi_j) = R_{\mathrm{eff}}(i,j),
\]
and equivalently
\[
R_{\mathrm{eff}}(i,j)
= L^+_{ii} + L^+_{jj} - 2L^+_{ij}.
\]

If the catalog already contains an effective resistance theorem in quadratic-form language, your job is to derive the covariance interpretation from it.

**Lean 4 type signature sketch**
```lean
theorem effectiveResistance_eq_pseudoinverse_quadratic
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (Lplus : Matrix ι ι ℝ)
    (R : ι → ι → ℝ) :
    CovarianceCompatible Lplus R →
    ∀ i j, R i j = Lplus i i + Lplus j j - 2 * Lplus i j
```

A pinned-basepoint covariance theorem is also acceptable:
```lean
theorem pinned_covariance_from_resistance
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (R : ι → ι → ℝ) (base : ι) :
    ∀ i j,
      ((R i base) + (R j base) - R i j) / 2
      =
      ((R j base) + (R i base) - R j i) / 2
```

and then connect it to a covariance matrix definition.

**Why this matters**
This is where statistical mechanics meets electrical network theory in a theorem that can be computed, visualized, and generalized. It gives physical meaning to effective resistance as a fluctuation observable, not just a network invariant.

### Theorem 4: Explicit cycle graph formula
This should be your computational anchor theorem and support the demo.

**Mathematical statement**

For the cycle graph `C_n` with unit weights,
\[
\det(L_{\mathrm{red}})=n,
\qquad
Z_{\mathrm{pin}}(C_n)
=
(2\pi)^{(n-1)/2} n^{-1/2}.
\]
Moreover, the effective resistance satisfies
\[
R_{\mathrm{eff}}(i,j)=\frac{d(i,j)(n-d(i,j))}{n},
\]
where `d(i,j)` is cyclic graph distance.

**Lean 4 type signature sketch**
```lean

```

**Why this matters**
This theorem gives an exactly solvable family where every quantity can be compared against numerical experiments. It is the ideal proving ground for the conjectural metric-graph periodicity picture.

## Clarification of the genus issue

The original conjecture states:
\[
Z(\Gamma)=(2\pi)^{g/2}(\det L_{\mathrm{red}})^{-1/2},
\]
where `g` is the genus.

You must treat this carefully. For a finite connected graph with `|V| = n`, the pinned Gaussian integral naturally lives in dimension `n-1`, not generally `g`. Thus one of the most mathematically valuable outcomes would be:

1. prove the correct finite-graph theorem with exponent `(n-1)/2`, and

This is not a retreat; it is a sharpening. If successful, this turns a vague physical slogan into a precise decomposition between:
- vertex-potential fluctuations (`n-1` degrees of freedom), and

### Strategy A: Quadratic-form first, then algebraic partition theory
1. Use `weightedLaplacian_psd` to prove `GraphGFFEnergy_nonneg`.
2. Prove gauge invariance via row-sum-zero and symmetry of Laplacian, expanding
   \[
   (x+c\mathbf{1})^\top L (x+c\mathbf{1})
   \]
   and showing the linear and constant terms vanish.
3. Define the reduced Laplacian and prove positivity/positivity of determinant for connected graphs.
4. Package the partition function first as a prefactor theorem, then derive exact formulas on cycle graphs.

**Why promising:** This is the cleanest route in Lean because it reduces analysis to linear algebra and finite sums, and it directly leverages catalog PSD results.

### Strategy B: Effective-resistance first, then interpret covariance
1. Start from catalog effective resistance identities.
2. Define a covariance candidate from resistance:
   \[
   K(i,j)=\frac{R(i,b)+R(j,b)-R(i,j)}{2}.
   \]
3. Prove symmetry and positivity properties of `K`.
4. Show `Var(φ_i-φ_j)=R(i,j)` formally at the matrix/algebraic level.

**Why promising:** This route produces the strongest cross-domain theorem early, and it avoids needing full Gaussian integration machinery before obtaining physically meaningful observables.

### Strategy C: Explicit family first, then abstract generalization
1. Define `cycleReducedLaplacian`.
2. Prove determinant and resistance formulas by induction on `n`, with nontrivial `calc`, `field_simp`, and recurrence arguments.
3. Use the cycle family to motivate and test the general partition/covariance theorems.

**Why promising:** This is the best route for guaranteed executable output and for the demo, though less conceptually general than Strategy A.

**Recommended order:** Start with **A**, use **B** for the flagship bridge theorem, and use **C** to produce exact formulas and computational evidence.
