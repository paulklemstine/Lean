## MATHEMATICAL TARGET

Formalize a finite-observer semantics where a family of congruences on a semiring separates terms, and use this to define a compressed code map into a finite product of quotients. Then prove that diagonal avoidance gives injectivity on a chosen finite subset, together with explicit cardinality bounds and certified robustness style stability lemmas.

The guiding idea is:

- A “proof semiring” `S` carries symbolic proof traces / neural proof tokens.
- A congruence `c` on `S` is an observational compression channel.
- A family `F : Fin n → Con S` yields a code
  \[
  x \mapsto ([x]_{F 0}, [x]_{F 1}, \dots, [x]_{F (n-1)})
  \]
  into the product of quotients.
- If for every distinct `x,y` in a target finite set `T`, there exists `i` such that `¬ c_i x y`, then the code is injective on `T`.
- If each quotient has cardinality at most `K`, then `|T| ≤ K^n`.
- If a score map into `ℕ` or `ℤ` is congruence-stable, then the compressed code preserves certified decision margins.
- A diagonal-avoidance predicate packages the “for all distinct x,y, there exists i” alternation.

This is the theorem family you should build toward.

## PROOF STRATEGY: CONCRETE STEPS

### Strategy A: Quotient-product coding (preferred)
This is the most conceptually elegant and gives the cleanest “spectrum to code” theorem.

1. **Build the code map coordinatewise**  
   Define `encodeByObservers F x i := Quotient.mk _ x`.  
   Prove extensionality:
   ```lean
   funext; apply Quot.sound; exact ...
   ```
   for respect lemmas.

2. **Prove code equality iff all observers identify the pair**  
   Use:
   - `funext` for function equality,
   - quotient equality characterization (`Quotient.exact` / `Quotient.sound` depending on representation),
   - `constructor`, `intro`, `specialize`.
   This lemma is the gateway to every later theorem.

3. **Convert diagonal avoidance into injectivity**  
   For `x,y ∈ T`, assume equal codes.  
   By `observerCode_eq_iff`, every observer identifies `x,y`.  
   If `x ≠ y`, diagonal avoidance gives an observer separating them — contradiction.  
   This proof should use `by_contra`, `push_neg`, and `rcases`.

4. **Derive cardinality bound**  
   Show `T.image (encodeByObservers F)` has card `T.card` by injectivity on support.  
   Then bound image cardinality by codomain cardinality.  
   Bound the codomain cardinality by `K ^ F.n` using:
   - cardinality of finite function types,
   - product/cardinal arithmetic,
   - induction on `n` if direct theorem lookup fails.
   This is where induction is essential.

5. **Add score stability / certified robustness theorem**  
   If equal codes imply observer-wise congruence, and observer-wise congruence implies equal score, then `CertifiedMargin = 0`.  
   Use `sub_eq_zero.mpr` or integer absolute value lemmas.

### Strategy B: Relation-coded compression without quotients
If quotient cardinality APIs are too heavy, define:
```lean
def rawCode (F : FiniteProofObserverFamily S) (x : S) : S → Prop := ...
```
or a finite boolean code using selected witnesses from the support. Then:
- prove pair-separation on `T`,
- derive finite-image cardinality bound by embedding into `Fin F.n → Bool`,
- conclude `|T| ≤ 2 ^ F.n` in the booleanized case.

This route is especially promising if you want an explicit cryptographic collision bound.

### Strategy C: Finset spectral family extraction
For `P : Finset (Con S)`, convert to `Fin n → Con S` via `Finset.attach` or enumeration of a deduplicated list.
- First prove a helper enumerating a finite set by `Fin`.
- Then transfer `SpectralSeparator P T` into `DiagonalAvoidsOn`.
This gives the “prime spectrum” theorem even if the rest of the development uses finite families.

**Most promising route**: combine A + C. Use quotient-product coding for the clean semantics, and finite-family extraction from a prime-congruence finset for the spectral narrative.

# Prime Congruence Spectra of Closure-Generated Proof Semirings

This file establishes the algebraic core of **proof-spectrum semantics**: the reconstruction
of semiprime theories/kernels as intersections of prime theories in commutative semirings.

## Main results

* `semiprime_eq_iInter_prime_theories` — A semiprime kernel in a commutative semiring equals the
  intersection of all prime theories containing it. This is the algebraic heart of the
  proof-spectrum correspondence.

* `exists_prime_theory_avoiding` — Prime separation: if `a` is not in a semiprime kernel `K`,
  there exists a prime theory containing `K` but not `a` (via Zorn's lemma).

* `zeroLocus_anti_mono`, `theoryOf_zeroLocus_extensive`, `theoryOf_zeroLocus_galois` — The
  antitone Galois correspondence between sets of proof terms and sets of congruences.

* `zeroClass_of_prime_congruence_isPrimeTheory` — The zero-class of a prime proof congruence
  is a prime theory.

## Mathematical overview

The key insight is that a proof system can be given the structure of an idempotent commutative
semiring, where `a + b` represents "either derivation resource," `a * b` represents "composite
derivation," and the induced order captures logical entailment. The prime congruence spectrum
then provides a geometric semantics: theories correspond to vanishing loci, and derivability
is captured by vanishing on all points of the associated spectral set.

The decisive theorem is that **semiprime** theories (those closed under square roots:
`a * a ∈ T → a ∈ T`) are exactly the intersections of prime theories. This is the
semiring-theoretic analogue of the radical ideal theorem from algebraic geometry.

## References

The algebraic content is a semiring generalization of the classical commutative algebra result
that semiprime ideals are intersections of prime ideals (a consequence of Krull's theorem).
The proof uses Zorn's lemma applied to the family of ideals disjoint from a multiplicative set.

def theoryOf {α : Type u} [CommSemiring α]

  {a | ∀ P ∈ X, vanishesAt P a}

  ∀ {a b : α}, P.r (a * b) 0 → P.r a 0 ∨ P.r b 0

def primeSpectrum {α : Type u} [CommSemiring α] : Set (ProofCongruence α) :=
  {P | ProofCongruence.IsPrime P}

  trans' : ∀ {a b c}, r a b → r b c → r a c
  add' : ∀ {a b c d}, r a b → r c d → r (a + c) (b + d)

theorem mul_left (C : SemiringCong A) (f : A) {a b : A} (h : C.r a b) :
