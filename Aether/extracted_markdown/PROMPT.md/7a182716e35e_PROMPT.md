### Novel Definitions (REQUIRED — not in Catalog)

**Definition 1: Semantic Threshold Graph.** Given a finite type `V` with a decidable distance function `dist : V → V → ℕ` and a threshold `ε : ℕ`, define:

```lean
structure SemanticThresholdGraph (V : Type*) [Fintype V] [DecidableEq V] where
  dist : V → V → ℕ
  dist_sym : ∀ x y, dist x y = dist y x
  dist_self : ∀ x, dist x x = 0
  ε : ℕ
  graph : SimpleGraph V
  adj_def : ∀ x y, graph.Adj x y ↔ (x ≠ y ∧ dist x y ≤ ε)
```

**Definition 2: Cyclomatic Number (Betti Number).** For a finite simple graph, `cyclomaticNumber G = |E| - |V| + |CC|` where `CC` is the set of connected components. This already exists in spirit in the catalog (`graphCycleRank_pos_of_connected_many_edges`) but needs a clean, composable formalization:

```lean
noncomputable def cyclomaticNumber {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] : ℤ :=
  (G.edgeFinset.card : ℤ) - (Fintype.card V : ℤ) + (G.connectedComponentSet.card : ℤ)
```

**Definition 3: Proof-Theoretic Locality (NOVEL).** For a connected graph `G` with positive cyclomatic number and a vertex `x`, the locality `L_G(x)` measures the fraction of the graph's cyclic structure concentrated in the closed neighborhood of `x`:

```lean
noncomputable def proofTheoreticLocality {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] [Connected G]
    (x : V) : ℝ :=
  let G_nbhd := G.induce (insert x (G.neighborFinset x))
  let r_local := (cyclomaticNumber G_nbhd : ℝ)
  let r_global := (cyclomaticNumber G : ℝ)
  r_local / r_global
```

**Definition 4: Critical Threshold (NOVEL).** For a semantic threshold graph family `{G_{S,ε}}_ε`, the critical threshold `ε*` maximizes the *normalized* cyclomatic number `φ(ε) = cyclomaticNumber(G_{S,ε}) / |E(G_{S,ε})|`, which measures cyclic information density per edge:

```lean
noncomputable def normalizedCyclomaticDensity {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] : ℝ :=
  (cyclomaticNumber G : ℝ) / (G.edgeFinset.card : ℝ)
```

### Theorem 1: Neighborhood Cyclomatic Bound (Structural)

**Statement:** For any finite simple graph `G` and vertex `x` with degree `d ≥ 2`, the cyclomatic number of the induced subgraph on the closed neighborhood `N[x]` is at most `(d choose 2)`. Equality holds if and only if `N[x]` induces a complete graph on `d + 1` vertices.

```lean
theorem cyclomaticNumber_closedNeighborhood_bound {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] (x : V)
    (hd : 2 ≤ G.degree x) :
    cyclomaticNumber (G.induce (insert x (G.neighborFinset x))) ≤ (G.degree x * (G.degree x - 1)) / 2 := by
  sorry

theorem cyclomaticNumber_closedNeighborhood_eq_iff_complete {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] (x : V)
    (hd : 2 ≤ G.degree x) :
    cyclomaticNumber (G.induce (insert x (G.neighborFinset x))) = (G.degree x * (G.degree x - 1)) / 2 ↔
    ∀ y z ∈ G.neighborFinset x, y ≠ z → G.Adj y z := by
  sorry
```

**Proof Strategy A (Combinatorial — RECOMMENDED):** The closed neighborhood `N[x]` has `d + 1` vertices. The maximum number of edges in any graph on `d + 1` vertices is `(d + 1 choose 2)`. The cyclomatic number is `|E| - (d + 1) + c` where `c` is the number of connected components of `G[N[x]]`. Since `x` is adjacent to all `d` neighbors, the induced subgraph is connected (`c = 1`). Therefore `cyclomaticNumber = |E| - d`. Since `|E| ≤ (d + 1 choose 2) = d(d+1)/2`, we get `cyclomaticNumber ≤ d(d+1)/2 - d = d(d-1)/2 = (d choose 2)`. For equality, we need `|E| = (d + 1 choose 2)`, i.e., the induced subgraph is complete.

**Proof Strategy B (Inductive on degree):** Base case `d = 2`: the closed neighborhood has 3 vertices, at most 3 edges, cyclomatic number ≤ 1 = (2 choose 2). Inductive step: adding a neighbor increases the bound by exactly the right amount. Less elegant but verifies the base carefully.

### Theorem 2: Locality-Cycle Participation Duality (Cross-Domain: Graph Theory ↔ Proof Complexity)

**Statement:** For a connected finite simple graph `G` with cyclomatic number `r ≥ 1` and any vertex `x` with locality `L_G(x) = k/r` (where `k` is the cyclomatic number of `G[N[x]]`), the vertex `x` lies on at least `k` edge-disjoint simple cycles of `G`. This establishes a **duality**: local cyclic concentration forces global cycle participation.

```lean
theorem locality_cycle_participation_duality {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] [Connected G]
    (x : V)
    (hr : 1 ≤ cyclomaticNumber G)
    (hk : cyclomaticNumber (G.induce (insert x (G.neighborFinset x))) = k) :
    ∃ (cycles : Finset (Sym2 V)), cycles.card = k ∧
      ∀ c ∈ cycles, c ∈ G.edgeSet ∧
      ∀ c₁ ∈ cycles, ∀ c₂ ∈ cycles, c₁ ≠ c₂ → Disjoint (edgeSetOfCycle c₁) (edgeSetOfCycle c₂) ∧
      ∀ c ∈ cycles, x ∈ verticesOfCycle c := by
  sorry
```

**Proof Strategy A (Algebraic Topology — RECOMMENDED):** The cyclomatic number `k` of `G[N[x]]` equals the dimension of the cycle space of `G[N[x]]` over `ℤ/2ℤ`. Each basis cycle in the cycle space of `G[N[x]]` passes through `x` (since `x` is connected to all neighbors and the subgraph is connected). These `k` basis cycles can be extended to edge-disjoint simple cycles in `G` using the ear decomposition of `G` (since `G` is connected with cyclomatic number `r ≥ k`). The key lemma: any cycle through `x` in `G[N[x]]` is also a cycle through `x` in `G`.

**Proof Strategy B (Constructive via ear decomposition):** Use the fact that any connected graph with cyclomatic number `r` has an ear decomposition with exactly `r` ears. The ears originating from `N[x]` are edge-disjoint by construction. Count them: there are at least `k` such ears.

**Cross-Domain Significance:** This theorem bridges algebraic topology (cycle spaces over `ℤ/2ℤ`) and proof complexity. In proof theory, a "cycle" in the dependency graph corresponds to a mutual dependency (A uses B, B uses C, C uses A). A theorem lying on `k` edge-disjoint cycles must resolve `k` independent mutual dependency chains. This gives a *structural lower bound* on proof search: any prover must explore at least `k` distinct dependency resolutions.

### Theorem 3: Critical Threshold Phase Transition (Cross-Domain: Graph Theory ↔ Statistical Mechanics)

**Statement:** For a finite metric space `(S, d)` with `|S| ≥ 3` and at least two distinct nonzero pairwise distances, the normalized cyclomatic density `φ(ε) = cyclomaticNumber(G_{S,ε}) / |E(G_{S,ε})|` achieves its maximum at a threshold `ε*` strictly between the minimum and maximum nonzero distances. At `ε*`, the graph `G_{S,ε*}` is neither a forest (which would give `φ = 0`) nor complete (which would give `φ = 0` for `|S| ≥ 4`), establishing a **phase transition** between tree-like and saturated dependency structures.

```lean
theorem critical_threshold_exists {V : Type*} [Fintype V] [DecidableEq V]
    (STG : SemanticThresholdGraph V)
    (h_card : 3 ≤ Fintype.card V)
    (h_distinct : ∃ x y z : V, x ≠ y ∧ y ≠ z ∧ x ≠ z ∧
      STG.dist x y ≠ STG.dist y z ∧ 0 < STG.dist x y ∧ 0 < STG.dist y z) :
    ∃ ε* : ℕ, ε* > 0 ∧
      let G_star := STG.withThreshold ε*;
      0 < normalizedCyclomaticDensity G_star ∧
      ∀ ε : ℕ, ε > 0 → ε ≠ ε* →
        normalizedCyclomaticDensity G_star ≥ normalizedCyclomaticDensity (STG.withThreshold ε) := by
  sorry
```

**Proof Strategy A (Piecewise Analysis — RECOMMENDED):** The function `φ(ε)` is piecewise constant on intervals between consecutive distinct distances. At each threshold `ε = d_i` (a distinct distance), a new edge appears. When the new edge connects two previously separate components, `cyclomaticNumber` increases by 0 (it reduces components by 1 and adds 1 edge, net change 0 to cyclomatic number) but wait — `m - n + c`: adding an edge within a component increases `m` by 1, `c` unchanged, so cyclomatic number increases by 1. Adding an edge between components increases `m` by 1 and decreases `c` by 1, so cyclomatic number increases by 2. The normalized density `φ = (m - n + c) / m`. Compute `φ` at each threshold and find the maximum by finite enumeration.

**Proof Strategy B (Convexity argument):** Show that `φ(ε)` is unimodal (increasing then decreasing) by analyzing the marginal contribution of each new edge. Early edges tend to connect components (high marginal contribution to cyclomatic number, `φ` increases). Late edges tend to be within already-dense components (low marginal contribution, `φ` decreases). The maximum occurs at the crossover point.

**Statistical Mechanics Connection:** This is precisely the **percolation phase transition** in the semantic graph. Below `ε*`, the graph is "subcritical" — locally tree-like, proofs are modular and easy. Above `ε*`, the graph is "supercritical" — globally interconnected, proofs require navigating complex dependency webs. The critical threshold `ε*` is the **percolation threshold** of the theorem dependency network, and it governs the transition from "locally decidable" to "globally entangled" proof structures.

### Theorem 4 (Key Consequence): Locality Lower-Bounds Proof Depth

**Statement:** Let `G` be a connected dependency graph with cyclomatic number `r ≥ 1`. For any vertex `x` with `proofTheoreticLocality G x = α > 0`, any proof of `x` that uses only direct dependencies (edges of `G`) must traverse at least `⌈α · r⌉` distinct intermediate results. This is the formal theorem that makes the empirical hardness-locality correlation *structurally inevitable*.

```lean
theorem locality_lower_bounds_proof_depth {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj] [Connected G]
    (x : V) (α : ℝ)
    (hα : proofTheoreticLocality G x = α)
    (hr : 0 < cyclomaticNumber G) :
    ∀ (path : List V) (h_path : path.head? = some x) (h_deps : ∀ i, i + 1 < path.length → G.Adj (path.get i) (path.get (i+1))),
      (path.toFinset.card : ℝ) ≥ α * (cyclomaticNumber G : ℝ) := by
  sorry
```

**Proof Strategy:** By Theorem 2, vertex `x` lies on `k = ⌈α · r⌉` edge-disjoint cycles. Any dependency path proving `x` must "break" each of these cycles — it must include at least one vertex from each cycle (since the cycle represents a mutual dependency that must be resolved). By edge-disjointness, these vertices are distinct. Therefore the path visits at least `k` distinct vertices.
