Mode: **prove** / **formalize** / **discover**

Aristotle, this is not a request for a cosmetic formalization of Euclid-tree folklore. This is a call to turn the Berggren generation of primitive Pythagorean triples into a certified algebraic-combinatorial cryptographic machine. The breakthrough is to identify a rigorously formalizable **groupoid-orbit structure** behind primitive triple generation, extract a **lattice-valued hardness interface** from orbit data, and then prove a **security reduction skeleton** connecting orbit inversion to shortest-vector style problems and entropy-based post-quantum key security already present in the catalog.

The deepest opportunity is not “Pythagorean triples in cryptography.” It is the creation of a new bridge:

## Core Vision

Formalize the three Berggren matrices acting on primitive Pythagorean triples, prove that they preserve primitivity and the quadratic cone
\[
a^2 + b^2 = c^2,
\]
then package reachable triples as an orbit/groupoid object. From there, define a lattice generated by orbit differences or bounded orbit samples, and prove a reduction theorem of the following shape:

> If orbit recovery is easy for Berggren words/matrices from their output triples, then one can algorithmically recover short nonzero relations in a naturally associated integer lattice.

This need not immediately yield a production-grade cryptosystem. The true breakthrough is the **first fully formalized theorem schema connecting arithmetic tree actions to lattice-style post-quantum hardness**.

## Precise Theorem Targets

### 1. Berggren matrices preserve the Pythagorean cone and primitivity

Define the standard Berggren matrices
\[
A=\begin{pmatrix}
1 & -2 & 2\\
2 & -1 & 2\\
2 & -2 & 3
\end{pmatrix},\quad
B=\begin{pmatrix}
1 & 2 & 2\\
2 & 1 & 2\\
2 & 2 & 3
\end{pmatrix},\quad
C=\begin{pmatrix}
-1 & 2 & 2\\
-2 & 1 & 2\\
-2 & 2 & 3
\end{pmatrix}.
\]

Define a predicate on integer vectors \(v=(a,b,c)\in \mathbb Z^3\):
\[
\mathrm{PrimitivePythTriple}(v) :\!\iff a^2+b^2=c^2 \;\wedge\; \gcd(a,b)=1 \;\wedge\; \gcd(a,c)=1 \;\wedge\; \gcd(b,c)=1 \;\wedge\; 0<a \wedge 0<b \wedge 0<c.
\]

#### Lean target signature
```lean

  v 0 ^ 2 + v 1 ^ 2 = v 2 ^ 2 ∧
  Int.gcd (v 0) (v 1) = 1 ∧
  Int.gcd (v 0) (v 2) = 1 ∧
  Int.gcd (v 1) (v 2) = 1 ∧
  0 < v 0 ∧ 0 < v 1 ∧ 0 < v 2

def berggrenA : Matrix (Fin 3) (Fin 3) ℤ := ...
def berggrenB : Matrix (Fin 3) (Fin 3) ℤ := ...
def berggrenC : Matrix (Fin 3) (Fin 3) ℤ := ...

theorem berggrenA_preserves_primitive :
  ∀ v : Fin 3 → ℤ, PrimitivePythTriple v →
    PrimitivePythTriple (berggrenA.mulVec v)

theorem berggrenB_preserves_primitive :
  ∀ v : Fin 3 → ℤ, PrimitivePythTriple v →
    PrimitivePythTriple (berggrenB.mulVec v)

theorem berggrenC_preserves_primitive :
  ∀ v : Fin 3 → ℤ, PrimitivePythTriple v →
    PrimitivePythTriple (berggrenC.mulVec v)
```

This is the indispensable arithmetic foundation. It is nontrivial but realistic in Lean.

### 2. Orbit closure and injective word action on the Berggren tree

Define words over the alphabet `{A,B,C}` and their evaluation as products in `Matrix (Fin 3) (Fin 3) ℤ`. Let the root be the classical primitive triple \((3,4,5)\). Prove that every evaluated word sends the root to a primitive triple. Then target a **faithfulness / injectivity theorem** at least on a bounded or syntactically reduced class of words.

#### Lean target signature
```lean
inductive BerggrenGen | A | B | C
deriving DecidableEq, Repr

def BerggrenWord := List BerggrenGen

def evalBerggrenWord : BerggrenWord → Matrix (Fin 3) (Fin 3) ℤ
| [] => 1
| g :: w => (match g with
    | BerggrenGen.A => berggrenA
    | BerggrenGen.B => berggrenB
    | BerggrenGen.C => berggrenC) * evalBerggrenWord w

def rootTriple : Fin 3 → ℤ
| 0 => 3
| 1 => 4
| 2 => 5

theorem eval_word_preserves_primitive :
  ∀ w : BerggrenWord,
    PrimitivePythTriple ((evalBerggrenWord w).mulVec rootTriple)
```

Then the breakthrough target:

```lean
def boundedWord (N : ℕ) (w : BerggrenWord) : Prop := w.length ≤ N

theorem berggren_word_action_faithful_bounded :
  ∀ N : ℕ, ∀ w₁ w₂ : BerggrenWord,
    boundedWord N w₁ →
    boundedWord N w₂ →
    ((evalBerggrenWord w₁).mulVec rootTriple =
     (evalBerggrenWord w₂).mulVec rootTriple) →
    w₁ = w₂
```

A fully global faithfulness theorem may be hard in one cycle. A bounded-depth version is already significant and cryptographically useful. It interfaces directly with the catalog theorem `post_quantum_security_from_faithfulness`.

Why this matters: bounded faithfulness turns orbit points into unique public keys for bounded secret words.

### 3. Lattice extracted from orbit differences and nontrivial short-vector witness

Construct an integer lattice from orbit samples. A tractable formal version is:

Given a finite set `S : Finset (Fin 3 → ℤ)` of orbit points, define the subgroup/lattice generated by pairwise differences \(u-v\). Prove it is nontrivial when `S` contains at least two distinct orbit points, and exhibit a concrete bounded nonzero vector in it.

This is the first step toward an SVP-style reduction: orbit collisions or near-collisions induce short lattice vectors.

#### Lean target signature
```lean
def orbitPoint (w : BerggrenWord) : Fin 3 → ℤ :=
  (evalBerggrenWord w).mulVec rootTriple

def orbitDiff (w₁ w₂ : BerggrenWord) : Fin 3 → ℤ :=
  orbitPoint w₁ - orbitPoint w₂

def orbitSpan (W : Finset BerggrenWord) : AddSubgroup (Fin 3 → ℤ) := ...
```

Then prove something concrete:

```lean
theorem orbitSpan_nontrivial_of_distinct :
  ∀ {w₁ w₂ : BerggrenWord},
    orbitPoint w₁ ≠ orbitPoint w₂ →
    ∃ z ∈ orbitSpan ({w₁, w₂} : Finset BerggrenWord), z ≠ 0
```

A stronger theorem, if feasible:

```lean
def l1Norm (v : Fin 3 → ℤ) : ℤ := |v 0| + |v 1| + |v 2|

theorem short_vector_from_orbit_pair :
  ∀ w₁ w₂ : BerggrenWord,
    orbitPoint w₁ ≠ orbitPoint w₂ →
    ∃ z ∈ orbitSpan ({w₁, w₂} : Finset BerggrenWord),
      z ≠ 0 ∧ l1Norm z ≤ l1Norm (orbitDiff w₁ w₂)
```

This theorem is elementary enough to formalize, yet conceptually it says: **orbit geometry canonically produces lattice vectors**.

## Proof Strategy Architecture

You asked for 2–3 proof strategy steps; here are multiple routes.

### Strategy A: Direct arithmetic matrix proof on the quadratic form
Most promising for the preservation theorems.

1. **Cone preservation by explicit polynomial expansion**  
   For each Berggren matrix \(M\), compute coordinates of `M.mulVec v` as linear forms in `a,b,c`. Expand:
   \[
   a'^2 + b'^2 - c'^2
   \]
   and show it equals
   \[
   a^2 + b^2 - c^2.
   \]
   In Lean, this may require `ring`/`nlinarith` after unfolding matrix multiplication.

2. **Positivity from primitive-root cone geometry**  
   Show each output coordinate is positive whenever \(0<a,b<c\) and \(a^2+b^2=c^2\). You may need standard inequalities such as \(c>b\), \(c>a\), and in some branches \(c > |a-b|\).

3. **Primitivity via gcd invariance / divisibility contradiction**  
   If a prime divides all transformed coordinates, use the invertibility of Berggren matrices over `ℤ` or determinant ±1 to deduce it divides the original coordinates. This is the elegant path: unimodularity transfers gcd-1 information.

Why most promising: it reduces everything to explicit algebra plus standard gcd lemmas.

---

### Strategy B: Quadratic-form automorphism viewpoint
Most conceptually powerful.

1. Define the Lorentzian quadratic form
   \[
   Q(a,b,c)=a^2+b^2-c^2.
   \]
   Prove each Berggren matrix preserves `Q`, i.e. lies in the integral orthogonal group of `diag(1,1,-1)`.

2. Deduce that the cone `Q(v)=0` is invariant.  
   This packages the core arithmetic fact as a representation-theoretic statement.

3. Use determinant ±1 to obtain lattice automorphisms of `ℤ^3`, hence preservation of primitivity follows from invertibility over integers.

Why this matters: this creates a bridge to **hyperbolic geometry**, **integral automorphic forms**, and **Lorentzian lattices**. It is also the right language if later cycles push toward higher-dimensional Diophantine cryptography.

---

### Strategy C: Tree-theoretic / combinatorial faithfulness
Most promising for bounded injectivity.

1. Prove each Berggren image of a positive primitive triple strictly increases the hypotenuse `c`.  
   This gives a monotonicity invariant.

2. Show the three child maps have disjoint image regions, e.g. via inequalities comparing `a`, `b`, and linear combinations.  
   Then two distinct first letters cannot land at the same child.

3. Induct on word length to prove bounded-depth or full faithfulness on the root orbit.

Why promising: avoids difficult matrix semigroup theory. It converts algebra into order-theoretic uniqueness.

## Cross-Domain Connections You Must Exploit

Do not present this as an isolated number-theory curiosity. Explicitly connect it to at least one of the following domains in the Lean development and writeup.

### 1. Category theory / faithful representations
The catalog theorem `post_quantum_security_from_faithfulness` is a giant hint. The cryptographic message is:

> A public-key map arising from a faithful action of a combinatorial algebraic system on structured states is secure against collision-style inversion insofar as distinct secrets cannot produce the same public state.

This is a categorical security principle. Berggren words become morphisms; primitive triples become objects/states.

### 2. Lattice cryptography
Orbit differences form integer vectors in `ℤ^3`; bounded orbit sets generate lattices/subgroups. This is the arithmetic-dynamical analogue of module-lattice cryptography. Your reduction theorem can be modest, but the conceptual leap is huge:
- public keys are orbit points,
- secret keys are words,
- attacks induce short relations in orbit-generated lattices.

### 3. Hyperbolic geometry / Lorentzian dynamics
The cone \(a^2+b^2-c^2=0\) sits inside a Lorentzian quadratic space. Berggren matrices belong to an integral isometry semigroup. This links:
- primitive Pythagorean triples,
- geodesic-like tree dynamics,
- arithmetic on light cones.

This could become a future bridge to automorphic cryptography or expander constructions.

### 4. Information theory / entropy extraction
If secret words are sampled with enough min-entropy and the orbit map is injective on the support, then the resulting public-key derivation can be piped into the existing entropy-extraction theorems. This is how to connect arithmetic structure to the catalog’s certified post-quantum key theorems.
