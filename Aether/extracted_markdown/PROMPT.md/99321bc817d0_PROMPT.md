**Mode:** `prove`

The goal is not merely to restate classical convex facts, but to formalize a **tropical duality principle** that turns existing catalog lemmas into a reusable bridge between tropical algebra and convex conjugation.

## Core Theorem Target

Define the Legendre transform of a function `f : ℝ → ℝ` by
\[
f^\star(y) := \sup_{x \in \mathbb{R}} (x y - f(x)).
\]
In Lean, because unrestricted `sSup` over `ℝ` is delicate unless boundedness is supplied, begin with the **quadratic seed case** where the supremum is attained explicitly.

### Primary breakthrough theorem
Formalize and prove that the quadratic function is a fixed point of double conjugation up to the classical coefficient normalization:

\[
f(x) = \frac{x^2}{2}
\quad\Longrightarrow\quad
f^\star(y) = \frac{y^2}{2}
\quad\text{and}\quad
f^{\star\star}(x)=f(x).
\]

This is the correct first nontrivial Legendre duality theorem because:
- it is fully exact, not asymptotic,
- it can be proved in Lean without importing the whole abstract convex conjugate machinery,
- it creates the reusable pattern for later tropical convexity theorems,
- it links directly to min-plus algebra through negation and min/max duality.

### Lean 4 type signature target
You should introduce a concrete definition such as:

```lean
def legendreTransform (f : ℝ → ℝ) (y : ℝ) : ℝ :=
  sSup (Set.range fun x : ℝ => x * y - f x)
```

Then prove a theorem of the form:

```lean
theorem legendre_half_sq (y : ℝ) :
    legendreTransform (fun x : ℝ => x^2 / 2) y = y^2 / 2 := by
```

and, if feasible from that definition,

```lean
theorem legendre_biconjugate_half_sq (x : ℝ) :
    legendreTransform (legendreTransform (fun x : ℝ => x^2 / 2)) x = x^2 / 2 := by
```

If the second theorem is too hard with the raw `sSup` definition, define an intermediate explicit formula theorem first:

```lean
theorem legendre_half_sq_explicit (y : ℝ) :
    (sSup (Set.range fun x : ℝ => x * y - x^2 / 2)) = y^2 / 2 := by
```

and then derive the biconjugate theorem by rewriting.

## Stronger Tropicalized Duality Target

Once the quadratic theorem is in place, prove a min-plus/tropical reformulation. The key observation is that conjugation converts additive quadratic penalties into extremal algebra. A useful target is:

\[
\sup_x \left(xy - \frac{x^2}{2}\right)=\frac{y^2}{2}
\quad\Longleftrightarrow\quad
\inf_x \left(\frac{x^2}{2}-xy\right) = -\frac{y^2}{2}.
\]

This should be expressed as an exact duality identity using your existing catalog theorem `min_max_duality`.

### Lean target
```lean
theorem legendre_inf_quad (y : ℝ) :
    sInf (Set.range fun x : ℝ => x^2 / 2 - x * y) = -(y^2 / 2) := by
```

or equivalently, if `sInf` is awkward, prove the existential optimizer form:

```lean
theorem quad_penalty_minimizer (y : ℝ) :
    ∀ x : ℝ, x^2 / 2 - x * y ≥ -(y^2 / 2) := by
```

together with equality at `x = y`:

```lean
theorem quad_penalty_minimizer_eq (y : ℝ) :
    y^2 / 2 - y * y = -(y^2 / 2) := by
```

This pair already encodes the duality in a way that is robust in Lean.

## Precise Theorem Package to Aim For

### Theorem A: Quadratic Legendre identity
```lean
theorem legendre_half_sq (y : ℝ) :
    legendreTransform (fun x : ℝ => x^2 / 2) y = y^2 / 2 := by
```

### Theorem B: Fenchel–Young inequality, specialized quadratic form
For all `x y : ℝ`,
\[
xy \le \frac{x^2}{2} + \frac{y^2}{2}.
\]

This is foundational because it is the inequality form of conjugate duality.

```lean
theorem fenchel_young_quadratic (x y : ℝ) :
    x * y ≤ x^2 / 2 + y^2 / 2 := by
```

This theorem is extremely Lean-friendly and should probably be proved first. It can then feed the Legendre proof.

### Theorem C: Equality characterization at the optimizer
\[
xy = \frac{x^2}{2} + \frac{y^2}{2} \iff x = y.
\]

```lean
theorem fenchel_young_quadratic_eq_iff (x y : ℝ) :
    x * y = x^2 / 2 + y^2 / 2 ↔ x = y := by
```

This theorem gives the exact attainment witness needed for the supremum proof.

### Theorem D: Biconjugation for the quadratic
```lean
theorem legendre_biconjugate_half_sq (x : ℝ) :
    legendreTransform (legendreTransform (fun x : ℝ => x^2 / 2)) x = x^2 / 2 := by
```

### Theorem E: Tropical reformulation
```lean
theorem tropical_legendre_quadratic (y : ℝ) :
    sInf (Set.range fun x : ℝ => x^2 / 2 - x * y) = -(y^2 / 2) := by
```

If `sInf` is too costly, replace with a pair of lower-bound/attainment theorems.

## Proof Strategy Paths

### Strategy A: Direct optimizer + complete-the-square
**Most promising.**  
This is likely the best route in Lean because it avoids high-level convex analysis and reduces everything to polynomial identities.

1. Prove the algebraic identity
   \[
   xy - \frac{x^2}{2} = \frac{y^2}{2} - \frac{(x-y)^2}{2}.
   \]
   In Lean:
   ```lean
   have hsq : x * y - x^2 / 2 = y^2 / 2 - (x - y)^2 / 2 := by ring
   ```
2. Deduce the upper bound
   \[
   xy - \frac{x^2}{2} \le \frac{y^2}{2}
   \]
   from nonnegativity of squares.
3. Show equality at `x = y`, so the supremum over all `x` is exactly `y^2 / 2`.

Why this is best:
- relies only on `ring`, `nlinarith`, and order facts,
- gives both inequality and optimizer witness,
- naturally yields Fenchel–Young and tropical infimum statements.

### Strategy B: Fenchel–Young first, then identify the conjugate
1. Prove
   \[
   2xy \le x^2 + y^2
   \]
   via
   \[
   0 \le (x-y)^2.
   \]
2. Rearrange to get
   \[
   xy - x^2/2 \le y^2/2.
   \]
3. Use `x = y` for equality and conclude the `sSup` formula.

Why useful:
- modular theorem structure,
- makes the duality package reusable for later non-quadratic generalizations,
- aligns with classical convex-analysis narratives.

### Strategy C: Tropical duality via negation and min/max translation
1. Rewrite the supremum theorem as an infimum theorem using negation:
   \[
   \sup g = -\inf(-g).
   \]
2. Use `min_max_duality` and `tropical_mirror_duality` to formalize the passage between max-plus and min-plus.
3. Present the Legendre identity as a tropical optimization theorem.

Why important:
- this is the conceptual bridge theorem,
- turns a convex-analytic result into a tropical algebra result,
- opens the door to tropical dynamic programming and idempotent analysis.

This strategy is likely secondary for the core proof, but crucial for the “why this matters” theorem packaging.

## Cross-Domain Connections You Must Exploit

### 1. Optimal transport / Kantorovich duality
`kantorovich_weak_duality` is not accidental context. The expression
\[
xy - f(x)
\]
is a single-site dual potential. The Legendre transform is the atomized prototype of transport duality. A successful formalization here opens a path to:
- tropical transport costs,
- idempotent duality,
- Hamilton–Jacobi and Lax–Oleinik semigroups.

Try to state at least one corollary or remark theorem showing that quadratic Legendre duality is a one-dimensional weak duality equality case.

### 2. Tropical geometry / min-plus algebra
The tropical world replaces sums/products with min-plus or max-plus operations. Legendre transform acts like a nonlinear Fourier transform for convex functions and is deeply compatible with tropicalization. Your theorem should be framed as:
- a tropical support-function computation,
- a min-plus convolution primitive,
- a duality engine for tropical polynomials with quadratic weights.

### 3. Analysis / PDE
The quadratic conjugate is the kernel behind Hopf–Lax formulas. Formalizing it in Lean opens:
- viscosity solution bounds,
- convex Hamiltonians,
- certified optimization semigroups.

### 4. Information geometry / large deviations
Legendre transforms underlie cumulant generating functions and rate functions. A tropicalized formal version suggests future work on:
- tropical entropy,
- tropical large deviations,
- max-plus statistical mechanics.

These are not decorative connections. They should shape how you package definitions and theorem names.
