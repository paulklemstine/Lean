## Assignment: Tropical One-Wayness as Additive Rank Rigidity

Mode: **prove**

You should not merely “define a one-way function” in a complexity-theoretic black-box sense. In Lean, with concrete algebraic objects, the right breakthrough is to isolate a **mathematically checkable obstruction to inversion** for tropical powers and then prove sharp structure theorems around it. The central insight is this:

> In the tropical semiring, iterated tropical multiplication is additive on valuations/weights and therefore compresses structure into min-plus convolution data. The genuine formal opportunity is to prove that this compression preserves a forward invariant while destroying enough inverse information to create many-to-one fibers. That is the seed of a rigorous tropical one-wayness theory.

Your target is to build the first formal skeleton of that theory.

## Core Definitions to Introduce

Work with concrete tropical objects first, preferably matrices over `ℝ` with tropical multiplication interpreted as min-plus matrix multiplication. If needed, begin with functions `Fin n → ℝ` under tropical convolution on a finite index set.

A promising concrete starting point is:

- tropical scalar multiplication: addition in `ℝ`
- tropical addition: minimum
- tropical matrix product:
  \[
  (A \otimes B)_{ij} = \inf_k (A_{ik} + B_{kj})
  \]
  and for finite `k`, this is `Finset.inf'` / `Finset.min'` over `Fin n`.

Define tropical powers `A^[⊗ T]` recursively.

Then define a **fiber of the T-th tropical power map**:
\[
\mathrm{Fiber}_T(B) := \{ A \mid A^{\otimes T} = B \}.
\]

The first nontrivial notion of one-wayness should not be computational hardness yet, but **non-injective compressiveness**:
- there exist distinct `A ≠ A'` with `A^[⊗ T] = A'^[⊗ T]`;
- and more strongly, some fibers are infinite up to tropical gauge symmetries.

This is formalizable now and mathematically meaningful.

## Precise Theorem Targets

### Theorem 1: Tropical power map is noninjective on diagonal-shifted matrices

For diagonal or rank-one tropical matrices, prove that the tropical power map collapses affine families.

A concrete theorem statement:

> For any `n ≥ 1` and any tropical diagonal matrix `D`, adding a scalar `c` to all diagonal entries scales the `T`-th tropical power by `T*c`; hence after normalization modulo additive constants, the tropical power map is not injective.

This should be made precise via a normalization quotient or an explicit equality criterion.

### Lean 4 type signature sketch
```lean
theorem tropical_pow_shift
  {n T : ℕ} (hT : 1 ≤ T) (A : Matrix (Fin n) (Fin n) ℝ) (c : ℝ) :
  tropicalPow T (A + constMatrix c) =
    tropicalPow T A + constMatrix (T * c)
```
If `constMatrix` is too aggressive globally, restrict to a class where the statement is true, e.g. diagonal matrices or matrices with every minimizing path using exactly `T` edges. A safer diagonal version is:

```lean
theorem tropicalPow_diagonal_shift
  {n T : ℕ} (D : Fin n → ℝ) (c : ℝ) :
  tropicalPowDiag T (fun i => D i + c) =
    fun i => tropicalPowDiag T D i + T * c
```

Then derive noninjectivity modulo normalization:

```lean
theorem tropicalPow_not_injective_mod_center
  {n T : ℕ} (hT : 2 ≤ T) :
  ∃ A B : Matrix (Fin n) (Fin n) ℝ,
    A ≠ B ∧ normalize (tropicalPow T A) = normalize (tropicalPow T B)
```

This is the first rigorous “one-wayness-like” statement: forward map easy, inversion non-unique even after natural normalization.

### Theorem 2: Additive lower bound on tropical gap under powering

Build on `one_step_tropical_gap`. The conceptual move is to show that a spectral/gap-like quantity evolves monotonically or linearly under tropical powers. If you can define a gap functional `gap : Matrix ... → ℝ`, prove:

\[
\mathrm{gap}(A^{\otimes T}) \ge T \cdot \mathrm{gap}(A)
\quad\text{or at least}\quad
\mathrm{gap}(A^{\otimes (T+1)}) \ge \mathrm{gap}(A^{\otimes T}).
\]

### Lean 4 type signature sketch
```lean
theorem tropical_gap_monotone_pow
  {n T : ℕ} (A : Matrix (Fin n) (Fin n) ℝ) :
  tropicalGap (tropicalPow (T + 1) A) ≥ tropicalGap (tropicalPow T A)
```

or stronger:

```lean
theorem tropical_gap_linear_lower_bound
  {n T : ℕ} (A : Matrix (Fin n) (Fin n) ℝ) :
  (T : ℝ) * tropicalGap A ≤ tropicalGap (tropicalPow T A)
```

Why this matters: if powering amplifies a certified forward invariant while collapsing preimages, then tropical powering behaves like a mathematically clean analog of a one-way compression operator.

Use `one_step_tropical_gap` as the seed case and bootstrap by induction on `T`.

### Theorem 3: Tropical root obstruction via residue constraints / divisibility of path weights

This is the most visionary target.

For certain classes of tropical matrices/functions, prove that a necessary condition for `B` to admit a tropical `T`-th root is divisibility of a linear weight invariant. For diagonal data this is immediate and already powerful:

\[
B = A^{\otimes T} \implies \forall i,\; B_{ii} = T A_{ii}.
\]

Hence if some diagonal entry is not divisible by `T` inside a discrete subsemiring such as `ℤ`, no root exists.

### Lean 4 type signature sketch
```lean
theorem tropical_root_obstruction_int
  {n T : ℕ} (hT : 1 ≤ T) (B : Matrix (Fin n) (Fin n) ℤ) :
  (∃ A, tropicalPow T A = B) →
  ∀ i, T ∣ B i i
```

A diagonal specialization may be easiest:

```lean
theorem tropicalDiag_has_root_implies_divisible
  {n T : ℕ} (hT : 1 ≤ T) (d : Fin n → ℤ) :
  (∃ a : Fin n → ℤ, tropicalPowDiag T a = d) →
  ∀ i, T ∣ d i
```

Then prove a converse for diagonal data:

```lean
theorem tropicalDiag_root_iff_divisible
  {n T : ℕ} (hT : 1 ≤ T) (d : Fin n → ℤ) :
  (∃ a : Fin n → ℤ, tropicalPowDiag T a = d) ↔
  ∀ i, T ∣ d i
```

This is a genuine theorem, not a definition. It creates the first exact root-existence criterion for a tropical power map on a natural class.

## Proof Strategy Architecture

### Strategy A: Diagonal-first exact classification
Most promising for immediate theorem production.

1. Define tropical powers for diagonal data `Fin n → α`.
   - Show `tropicalPowDiag T d i = T * d i` over `ℝ` or `ℤ`.
2. Prove root existence iff coordinatewise divisibility (over `ℤ`) or trivial solvability (over `ℝ`).
3. Derive noninjectivity after normalization by additive constants.

Why this is best: it yields exact theorems, low `sorry` risk, and a clean algebraic prototype of one-wayness.

### Strategy B: Matrix semigroup with gap invariant
Higher risk, higher conceptual payoff.

1. Define tropical matrix multiplication and powers on `Matrix (Fin n) (Fin n) ℝ`.
2. Import or adapt the gap notion from the Markov bridge files.
3. Prove `one_step_tropical_gap` implies monotonicity/amplification under iteration.

Why promising: it turns one-wayness into a dynamical phenomenon, not just noninjectivity.

### Strategy C: Quotient by gauge symmetry / projective tropicalization
Most visionary, but likely technically heavier.

1. Define an equivalence relation `A ~ B` if `B = A + c` in the appropriate global tropical sense.
2. Show tropical powers descend to a quotient or interact predictably with it.
3. Prove induced map still has nontrivial fibers or root obstructions.

Why important: cryptographic hardness in tropical settings should live on normalized/projective classes, not raw affine representatives.

Recommended order: **A → B → C**.
