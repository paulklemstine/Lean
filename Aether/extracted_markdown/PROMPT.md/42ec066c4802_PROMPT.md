## Assignment: Formalization Steps — Product Noise, Low-Degree Structure, and Spectral Bias on Berggren Word Cubes

**Mode:** prove / formalize

You are not being asked for a routine extension. You are being asked to build a reusable spectral calculus for functions on the finite product space
\[
\Omega_L := (\mathrm{Fin}\ 3)^L \cong \mathrm{Fin}\ L \to \mathrm{Fin}\ 3,
\]
and then to turn that calculus into a certified low-degree bias principle. This is the discrete harmonic-analysis engine behind future work in symbolic dynamics, thermodynamic formalism, additive combinatorics on tree-indexed words, and complexity bounds for Berggren-generated arithmetic structures.

The decisive move is to formalize the **product noise operator** on Berggren words, identify its eigenspaces by tensor structure, define the **degree-\(k\)** submodule as the low-order Walsh/Fourier sector, and then **instantiate a general spectral-decay-to-bias theorem**. This creates a bridge from finite probability on ternary cubes to the spectral ideas already appearing in the catalog under eigenvalue-product and thermodynamic formalism themes.

## Core Objects to Define

Work over `ℝ` unless a more general scalar field is clearly easier and still useful.

### 1. Berggren word space
Define
```lean
abbrev BerggrenWordSpace (L : ℕ) := Fin L → Fin 3
```

This is the finite state space of length-`L` words in a 3-symbol alphabet. It is canonically a finite type.

### 2. Function space
Use the real-valued function space
```lean
abbrev BerggrenFn (L : ℕ) := BerggrenWordSpace L → ℝ
```

This should inherit the usual `NormedAddCommGroup`, `Module ℝ`, and finite-dimensional structure from function spaces on finite types.

### 3. Single-site averaging/noise kernel
Define a one-coordinate Markov operator on `Fin 3 → ℝ`. The cleanest version is the convex combination
\[
T_\rho f(x) = \rho f(x) + (1-\rho)\frac{1}{3}\sum_{y \in \mathrm{Fin}\ 3} f(y),
\qquad 0 \le \rho \le 1.
\]
This is the ternary analogue of the standard noise operator on the Boolean cube.

A likely Lean type signature:
```lean
def singleSiteNoise (ρ : ℝ) : LinearMap ℝ (Fin 3 → ℝ) (Fin 3 → ℝ) := ...
```

Then define the product operator acting independently on each coordinate:
```lean
def productNoise (L : ℕ) (ρ : ℝ) : LinearMap ℝ (BerggrenFn L) (BerggrenFn L) := ...
```

You may define it either:
- recursively on `L`,
- by averaging over random coordinate resampling,
- or via an explicit tensor/product basis action.

The tensor route is most powerful for later eigenvalue decomposition.

This is the local spectral theorem. It is the seed from which everything else grows.

### Theorem B: Degree-`k` submodule
Define the submodule spanned by functions depending on at most `k` coordinates.

A natural notion: `f` depends on `S : Finset (Fin L)` if changing coordinates outside `S` does not change `f`. Then define the degree-`k` submodule as the span of all such functions with `S.card ≤ k`.

Possible Lean-facing definitions:
```lean

def degreeLeSubmodule (L k : ℕ) : Submodule ℝ (BerggrenFn L) := ...
```

Then prove:
```lean
theorem degreeLeSubmodule_mono {L k₁ k₂ : ℕ}
    (h : k₁ ≤ k₂) :
    degreeLeSubmodule L k₁ ≤ degreeLeSubmodule L k₂ := by
  ...

theorem productNoise_preserves_degreeLe
    (L k : ℕ) (ρ : ℝ) :
    Submodule.map (degreeLeSubmodule L k) (productNoise L ρ) ≤ degreeLeSubmodule L k := by
  ...
```

More concretely, if `f ∈ degreeLeSubmodule L k`, then `productNoise L ρ f ∈ degreeLeSubmodule L k`.

### Theorem C: Tensor-product eigenvalue decomposition
This is the breakthrough theorem. You want the exact spectral structure: each homogeneous degree sector is an eigenspace with eigenvalue `ρ^d`.

To make this formalizable, first choose a basis of `Fin 3 → ℝ` adapted to the decomposition
\[
\mathbb{R}^{\mathrm{Fin}\ 3} = \langle \mathbf{1} \rangle \oplus V_0,
\]
where `V_0` is the 2-dimensional mean-zero subspace. Then basis tensors with exactly `d` coordinates in `V_0` are eigenvectors with eigenvalue `ρ^d`.

A formal theorem can be phrased without building a complete orthonormal basis if you define the homogeneous degree-`d` submodule as the span of pure tensors with exactly `d` mean-zero coordinates and constants elsewhere.

Suggested target:
```lean
def homogeneousDegreeSubmodule (L d : ℕ) : Submodule ℝ (BerggrenFn L) := ...

theorem productNoise_eigen_on_homogeneousDegree
    (L d : ℕ) (ρ : ℝ) :
    ∀ f ∈ homogeneousDegreeSubmodule L d,
      productNoise L ρ f = (ρ ^ d) • f := by
  ...
```

Then derive:
```lean
theorem productNoise_eigenvalue_decomposition
    (L : ℕ) :
    ∀ f : BerggrenFn L, ∃ pieces : Fin (L+1) → BerggrenFn L,
      (∀ d, pieces d ∈ homogeneousDegreeSubmodule L d.1) ∧
      f = ∑ d, pieces d ∧
      ∀ ρ, productNoise L ρ f = ∑ d, (ρ ^ d.1) • pieces d := by
  ...
```

If the full decomposition theorem is too heavy in one pass, prove the homogeneous eigen-action theorem first and package the decomposition as a `FUTURE_DIRECTIONS` target. But push hard: this theorem is the real field-opener.

## 2–3 Proof Strategy Paths

### Strategy A: Direct finite harmonic analysis on the ternary cube
1. Prove the one-site decomposition:
   \[
   \mathbb R^{\mathrm{Fin}\ 3} = \langle 1 \rangle \oplus \{f : \sum_x f(x)=0\}.
   \]
   Show `singleSiteNoise` acts by `1` on the first summand and `ρ` on the second.
2. Build product basis functions on `Fin L → Fin 3` by coordinatewise multiplication of basis vectors from the one-site decomposition.
3. Show the product operator acts diagonally with eigenvalue `ρ^d`, where `d` counts mean-zero coordinates.

**Why promising:** It is elementary, explicit, and should align best with finite function-space lemmas already in Mathlib. It also gives the cleanest route to `bias_bound_of_spectral_decay`.

### Strategy B: Recursive decomposition in the length parameter `L`
1. Identify
   \[
   \mathrm{BerggrenFn}(L+1) \cong \mathrm{Fin}\ 3 \to \mathrm{BerggrenFn}(L).
   \]
2. Define `productNoise (L+1) ρ` recursively as `singleSiteNoise ρ` tensored with `productNoise L ρ`.
3. Prove the homogeneous-degree eigenspace theorem by induction on `L`, splitting on whether the new coordinate contributes degree `0` or `1`.

**Why promising:** This avoids a heavy upfront tensor-product formalization. It may be the most practical if Mathlib tensor APIs are cumbersome for the desired schedule.

### Strategy C: Abstract operator-algebra / finite-dimensional spectral theorem
1. Define commuting coordinate-noise operators `T_i`.
2. Show each `T_i` is diagonalizable with eigenvalues `{1, ρ}` and that the `T_i` commute.
3. Conclude simultaneous diagonalizability; identify joint eigenspaces by subsets of coordinates, then aggregate by Hamming weight to get homogeneous degree.

**Why promising:** Conceptually strongest and closest to theorems in analysis and representation theory.  
**Why risky:** Simultaneous diagonalization in Lean may require more infrastructure than the direct basis method.

**Recommendation:** Start with **Strategy A**, use **Strategy B** as fallback if tensor notation becomes painful, and preserve the operator-algebra perspective in comments and `FUTURE_DIRECTIONS.md`.
