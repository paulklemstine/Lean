## Assignment: Dragon Curve Fractals as Tropical Curve Generators

Mode: **prove / counterexample / discover**

This direction is ambitious, but as stated it conflates several mathematically distinct notions: polygonal substitution curves, tropical hypersurfaces, Hausdorff dimension in Euclidean metric, and “all space-filling curves.” Your task is to **separate the true revolutionary core from the false overreach**, formalize the correct tropical objects in Lean 4, and then prove a package of theorems that opens a genuine bridge between **iterated function systems, lattice substitutions, and tropical polyhedral geometry**.

The likely breakthrough is **not** the literal statement “the Heighway dragon is a tropical curve” in the standard algebraic-geometric sense, because tropical plane curves are piecewise-linear balanced 1-complexes, while the Heighway dragon is classically the attractor/boundary of a self-affine tile and its Euclidean fractal geometry is subtler. The real opportunity is to prove that:

1. a dragon-iteration system admits a **min-plus encoding of its combinatorics** on the lattice,
2. its stagewise approximants are **tropically generated polyhedral sets**,
3. its limit set has a **tropical self-similarity law**,
4. and the Euclidean/Hausdorff claims must be formulated carefully — some versions are true and deep, some are false and should be refuted cleanly.

Your job is to produce a mathematically honest, field-opening formalization that could seed a new subject: **tropical substitution fractals**.

## Core Theorem Package to Target

### Theorem A: Min-plus generation of dragon approximants
Define a discrete dragon iteration on lattice-coded states, and prove that every finite-stage approximant is generated by iterating a min-plus affine update rule.

A precise formal target:

- Let a lattice state be `(ℤ × ℤ × Fin 4)` encoding position and quarter-turn orientation.
- Define two affine successor maps corresponding to the two folds of the dragon substitution.
- Define a min-plus “support potential” whose sublevel set encodes reachable states after `n` steps.

Prove:

> For every `n : ℕ`, there exists a finitely supported tropical polynomial / min-plus potential `Φ_n` on the lattice state space such that the set of states reachable in `n` dragon steps is exactly the argmin set (or zero-sublevel set) of `Φ_n`, and `Φ_{n+1}` is obtained from `Φ_n` by a min-plus convolution of the two successor maps.

This is the cleanest theorem that makes “dragon curve generated by iterated min-plus maps” precise.

### Suggested Lean 4 type signature
You will need to define the objects, but the theorem should look structurally like:

```lean
def DragonState := ℤ × ℤ × Fin 4

def stepL : DragonState → DragonState := ...
def stepR : DragonState → DragonState := ...

def reachable : ℕ → Set DragonState
| 0 => {s | s = (0,0,0)}
| n+1 => {s | ∃ t, t ∈ reachable n ∧ (s = stepL t ∨ s = stepR t)}

def tropPot : ℕ → DragonState → ℤ := ...

theorem reachable_iff_tropPot_min
    (n : ℕ) :
    reachable n = {s | tropPot n s = 0} := ...
```

```lean
    (n : ℕ) :

```

This theorem is a genuine bridge between symbolic substitution dynamics and tropical optimization.

### Theorem B: Tropical self-similarity of dragon approximants
Formalize the substitution law as a tropical scaling/decomposition identity.

A mathematically meaningful statement:

> There exists a lattice scaling/rotation operator `S` and two tropical affine maps `A, B` such that the stage-`n+1` dragon approximant is the union of two transformed copies of the stage-`n` approximant, and the corresponding tropical potential satisfies
> `Φ_{n+1}(x) = min (Φ_n(A⁻¹ x) + c₁, Φ_n(B⁻¹ x) + c₂)`.

This is the exact tropical analogue of self-similarity.

### Suggested Lean 4 type signature

```lean
theorem dragon_selfsimilar_union

theorem tropPot_recursion
    (n : ℕ) (x : DragonState) :
    tropPot (n+1) x = min (tropPot n (stepL⁻¹? x) + c₁) (tropPot n (stepR⁻¹? x) + c₂) := ...
```

If inverses are awkward, formulate using image/min-convolution instead of literal inverses.

### Theorem C: Dimension growth and planar saturation of lattice approximants
Do **not** rush to the false blanket statement “Hausdorff dimension of tropical dragon curves equals 2 exactly” without clarifying the object and metric.

A more robust and formalizable theorem is:

> The number of occupied lattice cells in the stage-`n` dragon approximant grows on the order of `2^n`, while its diameter grows on the order of `2^(n/2)`. Hence its box-counting/Minkowski scaling exponent in the plane is `2`.

This is the dimension statement that matches the area-filling nature of the dragon tile phenomenon.

### Suggested Lean 4 type signature
```lean

    (n : ℕ) :
    (occupiedCells n).card = 2^n := ...

theorem dragon_diameter_quadratic_scale
    (n : ℕ) :
    ∃ C > 0, diameterBound n ≤ C * Real.sqrt (2^n) := ...

theorem dragon_minkowski_dimension_two
    :
    ∀ ε > 0, ∃ N, ∀ n ≥ N,
      (2 - ε) ≤
        Real.log ((occupiedCells n).card : ℝ) /
        Real.log (diameterBound n)
      ∧
      Real.log ((occupiedCells n).card : ℝ) /
        Real.log (diameterBound n)
        ≤ (2 + ε) := ...
```

If full Minkowski dimension is too heavy for first pass, prove the asymptotic logarithmic ratio theorem for the discrete approximants. Then document clearly what remains to pass from discrete scaling exponent to classical Hausdorff/Minkowski dimension of a limit set.

## Counterexample Mandate: Refute the overreach cleanly

You should explicitly test and, if necessary, **disprove** the strongest claims in the assignment.

### Counterexample 1: “All space-filling curves are tropical limits of dragon curve iterations”
This is almost certainly false as stated. A single substitution system cannot approximate every space-filling curve in any natural strong topology without a universality theorem far beyond known structure.

Target a formal negative result of the form:

> There exists a continuous surjective space-filling curve `γ : [0,1] → [0,1]^2` whose finite combinatorial turn language is not contained in the dragon substitution language; therefore it cannot arise as a uniform limit of rescaled dragon substitution iterates.

In Lean, you may need a weaker discrete version:

```lean

  ∃ w : List Bool, w ∉ dragonLanguage := ...
```

Then derive a non-universality theorem for any curve family encoded by dragon turn words.

This is valuable science: it clears a false conjectural path and sharpens the correct universality question.

### Counterexample 2: “Heighway dragon is a tropical curve” in the strict balanced-fan sense
If your formal definition of tropical curve means a finite balanced polyhedral 1-complex, then the dragon limit set is not one. Prove instead:

> Every finite dragon approximant is a polyhedral lattice path and admits tropical generation, but the infinite limit is not a finite tropical plane curve in the standard algebraic-geometric sense.

A Lean skeleton:

```lean

    (n : ℕ) :
    IsPolygonalLatticePath (dragonApprox n) := ...

theorem dragon_limit_not_finite_tropical_curve
    :

```

If the full negative theorem is too large, state and prove a simpler obstruction: cardinality of vertices, non-local finiteness, or failure of finite balancing data.

This is not retreat. It is the crucial conceptual clarification that could found the subject properly.

## Most Promising Proof Strategies

### Strategy A: Substitution-dynamics first, tropicalization second
1. Define the dragon approximants combinatorially via turn words / rewrite rules.
2. Show the reachable-state recursion is equivalent to a two-branch affine recursion on lattice states.
3. Encode reachability as a min-plus potential via dynamic programming.
4. Derive self-similarity and scaling laws from the recursion.

Why promising:
- Lean handles inductive definitions and recursive reachability well.
- `tropical_min_assoc` directly supports the dynamic-programming recursion.
- This avoids prematurely formalizing heavy fractal/Hausdorff machinery.

### Strategy B: Signed-digit / Gaussian integer model
1. Represent dragon vertices using Gaussian-integer-like lattice algebra `(a,b) : ℤ × ℤ`.
2. Express the substitution as multiplication by quarter-turn matrices plus translation.
3. Use `lattice_scaling` to prove exact decomposition identities.
4. Push this matrix recursion into tropical potentials.

Why promising:
- This gives the cleanest mathematics.
- The Heighway dragon is naturally tied to `1 + i` scaling; the diameter-growth exponent `1/2` becomes transparent.
- It opens a bridge to algebraic number theory and cyclotomic lattices; `cyclotomic_lattice_bound` may become relevant through 4th roots of unity / quarter-turn symmetries.

### Strategy C: Cell-complex / occupancy model for dimension
1. Replace the curve by its occupied unit cells or thickened neighborhoods.
2. Prove exact recursion for cell counts.
3. Prove diameter bounds via matrix norm growth.
4. Deduce discrete Minkowski dimension `2`.

Why promising:
- Much easier than direct Hausdorff dimension of a fractal boundary.
- Better aligned with the true area-filling behavior of dragon-like substitution tilings.
- Gives a theorem strong enough to matter and formalize.

**Recommended path:** Combine **B + C**. Use the Gaussian-integer/lattice transform picture to get exact self-similarity, then prove the discrete dimension theorem via occupied cells. Use Strategy A only as the Lean-engineering layer for reachability and min-plus recursion.

## Cross-Domain Connections You Must Exploit

### 1. Tropical geometry × symbolic dynamics
The dragon is fundamentally a substitution dynamical system. Tropicalization turns branching substitution into min-plus recursion. This suggests a new framework: **tropical automata for self-similar curves**.

### 2. Fractal geometry × optimization
The min-plus potential is a shortest-path/value-function object. This connects dragon generation to:
- dynamic programming,
- Bellman equations,
- control-theoretic semirings,
- idempotent analysis.

A theorem here could launch “optimal-control fractal generation.”

### 3. Cyclotomic / lattice algebra × self-affine tilings
Quarter-turn symmetries are 4th-root-of-unity symmetries. The dragon’s scaling is naturally encoded by the lattice action of `1 + i`. This is where `cyclotomic_lattice_bound` may become structurally relevant: not as decoration, but as a lattice-norm estimate governing substitution growth.

### 4. Computational complexity × formal geometry
If finite-stage dragon approximants admit tropical dynamic programming descriptions, membership and generation may have low-complexity certificates. That opens:
- certified fractal generation,
- verified rendering,
- exact symbolic compression of self-similar sets.

### 5. Tropical algebraic geometry × self-affine tiles
The bold conceptual leap is to define a new class:
> **tropical substitution curves/tiles** = limit objects generated by iterated min-plus affine recursions on lattices.

This would be a new field, not a variant.
