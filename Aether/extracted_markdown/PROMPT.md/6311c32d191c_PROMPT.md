## Exact theorem statement candidates

### Theorem 1: Finite upper bound from bounded obstruction size
This is the most promising rigorous theorem if full Friedgut–Kalai machinery is too heavy in the first pass.

**Mathematical statement.**  
Let `F_n` be a monotone triangle obstruction family on `K_n`. Suppose every minimal unsatisfiable certificate contains at most `s(n)` edges, where `s(n) = o(n^2)`. Then the transition window width is at most `s(n)`; hence the normalized width is at most `s(n) / (n choose 2)`, and therefore tends to `0` whenever `s(n) / (n choose 2) → 0`.

This is powerful because it converts **local witness complexity** into **global threshold concentration**.

### Theorem 2: Lower/upper sandwich via packing and minimal obstruction size
Use the catalog’s existing lower satisfiable and upper unsatisfiable criteria to squeeze the window.

**Mathematical statement.**  
If every obstruction has size at least `m(n)` and there exists a disjoint packing of `p(n)` obstructions forcing unsatisfiability by size `u(n)`, then
\[
w(n) \le \frac{u(n)-m(n)}{\binom{n}{2}}.
\]
This theorem is the exact finite-size scaling inequality you need.

Suggested Lean shape:

```lean

  (hunsat : ∀ G, kUnsat ≤ G.card → ¬ Satisfiable sys G) :
  normalizedTransitionWidth n (kUnsat - kSat) ≤
    ((kUnsat - kSat : ℝ) / (Nat.choose n 2)) := by

```

## Proof strategy architecture

### Strategy A: Minimal-obstruction compression argument
**Most promising.**

1. Define the transition indices:
   - largest guaranteed satisfiable size,
   - smallest guaranteed unsatisfiable size.
2. Show any first unsatisfiable configuration contains a **minimal unsatisfiable certificate**.
3. Use the size bound on such certificates to show that removing at most `s` edges returns to satisfiable territory, hence the window width is at most `s`.

Why this is promising:
- It is purely finite and combinatorial.
- It leverages existing catalog monotonicity.
- It avoids needing the full formalization of product-measure threshold theorems immediately.
- It yields a theorem that is already scientifically meaningful.

Key tactics likely needed:
- `rcases` to extract minimal counterexamples,
- induction on cardinality,
- `by_contra` for first-unsatisfiable arguments,
- multi-step `calc`,
- subset/cardinality lemmas for `Finset`.

### Strategy B: Sandwich the transition using existing catalog theorems
1. Use `satisfiable_of_card_lt_minObstructionSize` to get a lower satisfiable threshold.
2. Use `unsat_of_disjoint_packing` to get an upper unsatisfiable threshold.
3. Subtract and normalize to derive explicit finite-size bounds.

Why this matters:
- It directly extends existing certified results.
- It gives an immediate theorem even before asymptotics.
- It may reveal the right scaling quantity empirically.

This should be one of the required three deep theorems, not just a corollary by simplification.

### Strategy C: Finite influence/susceptibility bridge
1. Define an edge-pivotality count or boundary count for size-`k` edge sets.
2. Prove that every pivotal configuration contains a small minimal witness.
3. Bound the number of pivotal configurations by counting witness placements.

Why this is visionary:
- It is the combinatorial shadow of Friedgut–Kalai.
- It opens the door to future formalization of threshold sharpness under random graph sampling.
- It connects your obstruction system to statistical mechanics observables.

This is the strongest cross-domain theorem in the brief.

## Suggested conjectures with computational tests

### Conjecture A: Polynomial window decay
For the canonical triangle obstruction system on `K_n`, there exists `β > 0` and `C > 0` such that
\[
w(n) \le C n^{-\beta}
\]
for all sufficiently large `n`.

**Test:** Compute exact or sampled `w(n)` for `n = 4,\dots,15`; fit `log w(n)` vs `log n`; reject if slope is statistically indistinguishable from `0` or positive.

### Conjecture B: Witness-size governs concentration
If the maximum cardinality of a minimal unsatisfiable certificate is `O(n)`, then
\[
w(n) = O(1/n).
\]

**Test:** For each `n`, enumerate/sample minimal unsatisfiable certificates, estimate maximal minimal witness size `s(n)`, and compare `w(n)` against `s(n)/binom(n,2)`.

### Conjecture C: Susceptibility peak aligns with transition center
The size `k` maximizing `edgeBoundaryCount sys k` lies inside or adjacent to the transition window.

**Test:** Compute `edgeBoundaryCount` numerically and compare argmax with `(k_sat, k_unsat)`.

These are falsifiable and scientifically useful.
