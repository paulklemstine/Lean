Complete the Dung argumentation framework formalization in Lean 4. The file Logic/Dung.lean already has ConflictFree defined and ConflictFree.subset proven. You must now:

1. Define the remaining core notions:
   - Defends S a := ∀ b, attacks b a → ∃ c ∈ S, attacks c b
   - Admissible S := ConflictFree attacks S ∧ ∀ a ∈ S, Defends attacks S a
   - Preferred S := Admissible attacks S ∧ ∀ T, Admissible attacks T → S ⊆ T → T = S

2. Prove preferred_not_downward_closed: Use the explicit framework with α = Fin 2, attacks 0 1 := True, attacks 1 0 := True, attacks 0 0 := False, attacks 1 1 := False. Show:
   - {0,1} is admissible (conflict-free since attacks within are only 0→1 and 1→0, but wait — these ARE attacks within the set, so {0,1} is NOT conflict-free). CORRECTION: Use α = Fin 3 with attacks 0 2 := True, attacks 2 0 := True, attacks 1 2 := True, attacks 2 1 := True. Then {0,1} is conflict-free (0 and 1 don't attack each other), and both 0 and 1 defend against all attackers. But {0} alone is not admissible because 0 doesn't defend against attacker 2 (no defender in {0} attacks 2). Similarly {1} alone is not admissible. So {0,1} is preferred but {0} and {1} are not admissible, proving preferred extensions aren't downward closed.

   ALTERNATIVE SIMPLER COUNTEREXAMPLE: Use α = Fin 2 with attacks 0 1 := True only (no other attacks). Then {0} is admissible (conflict-free, and 0 has no attackers so vacuously defended). {1} is NOT admissible (1 is attacked by 0, and no argument in {1} defends 1). {0,1} is conflict-free (only attack is 0→1, but wait, ConflictFree requires ¬attacks a b for all a,b ∈ S, so ¬attacks 0 1 must hold, but it's True, contradiction). So this doesn't work either.

   CORRECT COUNTEREXAMPLE: Let α = Fin 2, attacks 0 0 := True (self-attack on 0), all other attacks False. Then {1} is conflict-free and admissible (1 has no attackers). {0,1} is NOT conflict-free (0 attacks 0 within the set). So this doesn't give a preferred extension that fails downward closure.

   WORKING COUNTEREXAMPLE: Let α = Fin 3, attacks: 0↔2 and 1↔2 (four directed attacks). No self-attacks, no 0↔1 attacks. Then {0,1} is conflict-free. Attacker of 0 is 2, and 1 attacks 2, so 1 defends 0. Attacker of 1 is 2, and 0 attacks 2, so 0 defends 1. So {0,1} is admissible. It's also maximal (adding 2 creates conflict). But {0} alone: 0 is attacked by 2, and no argument in {0} attacks 2, so 0 is undefended. So {0} is not admissible. Similarly {1} is not admissible. Thus {0,1} is preferred but {0} and {1} are not admissible — preferred extensions are not downward closed.
