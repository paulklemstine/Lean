Your goal is to formalize a typed higher-order term language rich enough to express a fragment of stream fusion, define a finite rewrite theory encoding the core stream/unstream/fold/build/map/filter interactions, and prove that **fusion corresponds to normalization**.

### Theorem 1: Closure and soundness of fusion rewrites on the typed fragment

**Mathematical statement.**  
Let `T` be the finite higher-order rewrite system encoding the core stream fusion equations. For any well-typed substitution instance of any fusion rule, and any well-typed context `C`, the induced rewrite remains inside the well-typed fusion fragment and preserves denotational meaning. In other words, fusion is a sound contextual higher-order rewrite theory.

**Lean 4 type signature sketch**
```lean
theorem fusion_rewrites_sound_under_subst_and_context
  (FT : FusionTheory)
  {Γ τ : Ty}
  {l r : Term Γ τ}
  (hrule : FT.IsFusionRule l r)
  (hwt_l : WellTyped Γ l τ)
  (hwt_r : WellTyped Γ r τ)
  (σ : Subst Γ Δ)
  (C : Context Δ τ τ')
  :
  Denote (C.fill (subst σ l)) = Denote (C.fill (subst σ r)) ∧
  WellTyped Δ (C.fill (subst σ l)) τ' ∧
  WellTyped Δ (C.fill (subst σ r)) τ'
```

**Why it matters.**  
This upgrades catalog closure lemmas such as `rewrites_closed_under_subst_and_context` from a generic rewriting fact into a **certified compiler-pass theorem**: every local fusion rule is globally valid under arbitrary program placement and substitution.

**Catalog building blocks.**
- `Pythagorean/HigherOrderCompletion.lean`
- `Pythagorean/ConcreteTermAlgebra.lean`
- especially the closure result analogous to `rewrites_closed_under_subst_and_context`
- use substitution composition facts analogous to `subst_comp`

### Theorem 2: Elimination of administrative stream structure by normalization

**Mathematical statement.**  
Every well-typed term in the stream-fusion fragment normalizes, under β plus the fusion theory, to a term in fused normal form with no eliminable intermediate stream structure. This is the algebraic heart of “deforestation.”

**Lean 4 type signature sketch**
```lean
theorem exists_fused_normal_form
  (FT : FusionTheory)
  {Γ τ : Ty}
  (t : Term Γ τ)
  (hfrag : InFusionFragment FT t)
  (hwt : WellTyped Γ t τ) :
  ∃ n : Term Γ τ,
    RewritesStarBeta FT t n ∧
    IsFusedNormalForm FT n
```

A stronger uniqueness statement is even better if you can obtain confluence modulo β:

```lean
theorem fused_normal_form_unique
  (FT : FusionTheory)
  (hconf : ConfluentModuloBeta FT)
  {Γ τ : Ty}
  {n₁ n₂ : Term Γ τ}
  (hn₁ : IsFusedNormalForm FT n₁)
  (hn₂ : IsFusedNormalForm FT n₂)
  (h₁ : RewritesStarBeta FT t n₁)
  (h₂ : RewritesStarBeta FT t n₂) :
  BetaEq n₁ n₂
```

**Why it matters.**  
This is the theorem that turns optimization into canonicalization. It says the fused program is not merely “a possible optimized version” but **the normal form determined by the theory**.

### Theorem 3: Fusion correctness for composed producers/consumers

**Mathematical statement.**  
For the core producer/consumer fragment generated by `stream`, `unstream`, `map`, `filter`, `foldr`, and `build`, the normalized fused term computes the same denotation as the original composition and removes at least one layer of intermediate stream/list structure whenever a producer meets a consumer.

A prototypical statement:
```lean
theorem map_filter_foldr_fusion_correct
  (FT : FusionTheory)
  {α β : Ty}
  (f : Term Γ (α ⇒ β))
  (p : Term Γ (α ⇒ boolTy))
  (c : Term Γ (β ⇒ δ ⇒ δ))
  (z : Term Γ δ)
  (xs : Term Γ (listTy α))
  :
  Denote
    (foldr c z (map f (filter p xs))) =
  Denote
    (normalize FT (foldr c z (map f (filter p xs))))
```

A more structural theorem is preferable:
```lean
theorem producer_consumer_pair_eliminates_administrative_layer
  (FT : FusionTheory)
  {Γ τ : Ty}
  {t : Term Γ τ}
  (hpc : HasProducerConsumerRedex FT t)
  (hwt : WellTyped Γ t τ) :
  ∃ t',
    OneStepFusion FT t t' ∧
    adminComplexity t' < adminComplexity t
```

**Why it matters.**  
This theorem connects semantics to optimization quality. Not only is normalization correct, it is provably reducing the compiler-generated administrative burden.

### Theorem 4: Local confluence modulo β from joinability of critical pairs in the bounded fragment

If the full confluence theorem is too large, prove the bounded but still deep theorem:

**Mathematical statement.**  
For the finite set of stream fusion rules, if every well-typed higher-order critical pair generated up to the chosen pattern-order bound is joinable modulo β, then one-step overlaps in the bounded fragment are locally confluent modulo β.

**Lean 4 type signature sketch**
```lean
theorem bounded_local_confluence_mod_beta_of_joinable_critical_pairs
  (FT : FusionTheory)
  (B : Nat)
  (hjoin : ∀ cp ∈ criticalPairsUpTo FT B, JoinableModuloBeta FT cp.left cp.right) :
  LocallyConfluentModuloBetaOn (boundedFusionFragment FT B)
```

**Why it matters.**  
This is the bridge between completion experiments and theorem proving. It gives a mathematically clean explanation of how bounded completion evidence certifies a real optimization fragment.

## Proof Strategy Architecture

You must present and pursue **2–3 proof paths**, not just one.

### Strategy A: Rewrite-theoretic completion path
1. Define the fusion rule set as a finite higher-order theory.
2. Use catalog lemmas on substitution/context closure to prove every rule is sound under instantiation and embedding.
3. Generate critical pairs in the bounded typed fragment and prove local confluence modulo β from joinability.
4. Combine local confluence with a normalization argument on a structurally decreasing administrative-complexity measure.

**Why promising:** this most directly realizes the vision “compiler optimization = convergent presentation.”

### Strategy B: Semantic preservation + syntactic descent path
1. Give a denotational semantics for the fusion fragment.
2. Prove each fusion rule preserves denotation.
3. Define `adminComplexity : Term Γ τ → Nat` counting intermediate stream/build/unstream structure.
4. Show each oriented fusion rule weakly preserves semantics and strictly decreases `adminComplexity` on designated redexes.
5. Derive existence of fused normal forms by well-founded descent.

**Why promising:** even if full confluence modulo β is difficult, this yields a powerful certified optimizer with semantic correctness and guaranteed progress toward fusion.

### Strategy C: Coalgebraic bridge
1. Interpret streams as coalgebras and list consumers as catamorphisms.
2. Show producer/consumer interaction laws correspond to bialgebra-style distributive laws.
3. Prove the rewrite rules are syntactic shadows of these categorical equalities.
4. Use this to justify orientation choices and derive semantic uniqueness of fused forms.

**Why promising:** this creates the deepest cross-domain payoff and could transform the result from “verified optimization” into “coalgebraic compilation theory.”

**Most promising route:** combine **A + B**. Use B to secure a robust normalization/correctness theorem even if full completion stalls; use A to prove local confluence and bounded canonicality where possible.
