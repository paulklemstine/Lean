### Realization / reconstruction theorem

Define compatibility conditions explicitly as a finite list of inequalities and boundary identities. At minimum, the package should satisfy:

1. **Boundary consistency**: the edge restrictions of `c1` and `c2` agree with one-step tropical shifts of `e1`, `e2`.
2. **Horn-type subadditivity / concavity**: the fundamental convolution profiles satisfy tropical rhombus inequalities on every elementary diamond in the dominant chamber.
3. **Levi compatibility**: along each simple-coroot edge, the `GL₂`-type restrictions extracted from `c1`, `c2` coincide with the edge data and with each other where both are defined.
4. **Mixed commutation**: if `cmix` is included, it should agree with the two possible parenthesizations expected from associativity of tropical convolution by the fundamental generators.

A concrete definition could be:
```lean
structure Compatible (N : ℕ) (O : ObservablePackage N) : Prop where
  boundary1 : ∀ n, O.c1 (n,0) = O.e1 (n+1)
  boundary2 : ∀ n, O.c2 (0,n) = O.e2 (n+1)
  rhombus1 : ∀ a b, a + b ≤ N →
    O.c1 (a+1,b+1) + O.c1 (a,b) ≤ O.c1 (a+1,b) + O.c1 (a,b+1)
  rhombus2 : ∀ a b, a + b ≤ N →
    O.c2 (a+1,b+1) + O.c2 (a,b) ≤ O.c2 (a+1,b) + O.c2 (a,b+1)
  edge_agree : ∀ n, n ≤ N → O.c1 (0,n) = O.c2 (n,0)
```
The exact inequalities may need adjustment to the tropical normalization in your library, but they should be finite, local, and sufficient for recursive reconstruction.

### Proof strategy

1. **Triangular recovery on antidiagonals.**  
   Order dominant weights by height `h(a,b) = a + b`. Show that convolution with `Tω1` and `Tω2` gives recursive formulas in which the value of `f (a,b)` is the unique unknown in a tropical linear relation involving:
   - `obsFund1 f (a,b)` and/or `obsFund2 f (a,b)`,
   - previously determined values `f (a',b')` with `a' + b' < a + b`,
   - boundary values from `edge1 f`, `edge2 f`.
   
   The key theorem should look like:
   ```lean
   theorem recover_interior_from_fundamental_convolutions
       (hrec : ∀ ab, ab.1 + ab.2 < a + b → f ab = g ab)
       (h1 : obsFund1 conv f (a,b) = obsFund1 conv g (a,b))
       (h2 : obsFund2 conv f (a,b) = obsFund2 conv g (a,b))
       (ha : 0 < a) (hb : 0 < b) :
       f (a,b) = g (a,b) := by
     ...
   ```
   This is the heart of injectivity: the observable map should be triangular with respect to height.

2. **Edge initialization and chamber propagation.**  
   The induction base is exactly the simple-coroot edge data:
   ```lean
   hobs.1 : edge1 f = edge1 g
   hobs.2.1 : edge2 f = edge2 g
   ```
   Use these to seed the antidiagonal induction. The interior should then propagate uniquely from the two edges via the fundamental convolutions. This makes precise the slogan that the full chamber is generated from its simple-coroot rays plus the two fundamental Hecke steps.

3. **Local compatibility implies global realizability.**  
   For the realization theorem, construct `f` by induction on height. At stage `k`, define all `(a,b)` with `a+b=k` using the compatibility identities for `c1`, `c2`. Then prove:
   - the definition is independent of whether one uses the `ω₁`- or `ω₂`-recovery formula;
   - the local rhombus/Horn inequalities are exactly what guarantees this consistency;
   - support boundedness is preserved because all observables vanish outside the finite box.
   
   This is a tropical analogue of solving a discrete boundary-value problem with local integrability conditions.

4. **Use associativity to minimize generators.**  
   If a mixed observable `cmix` is needed initially, try to prove it is actually determined by `c1` and `c2` using associativity of convolution and the already-established injectivity:
   ```lean
   theorem mixed_determined_by_fundamental_data
       (hf : HasBoxSupport N f) :
       obsMixed conv f = explicitMixedFromC1C2 conv (obsFund1 conv f) (obsFund2 conv f) := by
     ...
   ```
   This would strengthen the result to a genuinely minimal presentation by just edge data plus the two fundamental generators.

5. **Finite presentation as exact image = relations.**  
   After injectivity and realization, the finite-presentation statement should be deduced by extensionality:
   - injectivity gives uniqueness of the preimage,
   - realization gives surjectivity onto the compatibility locus,
   - therefore the image is exactly the set of solutions to finitely many explicit relations.
   
   In Lean, the cleanest route is often equality of sets plus `Subtype.ext` / `funext`.

### Why this matters

This theorem would be the first genuine **finite presentation** result for the `GL₃` tropical Satake image, not merely a collection of partial reconstruction principles. Its significance is threefold:

1. It identifies a **minimal observable boundary** for the rank-2 tropical Hecke algebra: two simple-coroot edge rays plus the two fundamental double-coset convolutions.
2. It replaces bulky rank-2 Levi profile data by a **small generator set**, making the tropical Satake transform computationally and structurally closer to a finitely presented combinatorial algebra.
3. It creates the exact rank-2 prototype needed for extension to higher rank: once `GL₃` is controlled by edge data and fundamental generators with local Horn-type relations, one has a realistic blueprint for `GLₙ` presentations by simple-root boundary observables and fundamental Hecke operators.

A successful formalization here would therefore be a decisive step from “reconstruction from many observables” to “presentation by few generators and explicit relations,” which is the right structural statement for the tropical Hecke/Satake research program.
