### Exact Research Target

Work in a finite theorem universe `σ` with decidable equality and a finite family of inference rules. Represent a theory as a finite set `S : Finset σ`. Define a one-step consequence operator
`step : Finset σ → Finset σ`
which adjoins all conclusions of rules whose premises are already contained in `S`.

Then define the iterative closure from axioms `A` by
- `T 0 = A`
- `T (n+1) = step (T n)`

and define the discovered theory as the union / eventual fixed point of this iteration.

Your first theorem should be a precise finite Knaster–Tarski style stabilization theorem:

```lean
theorem finite_monotone_closure_stabilizes
  {σ : Type} [DecidableEq σ] [Fintype σ]
  (step : Finset σ → Finset σ)
  (h_mono : ∀ {S T : Finset σ}, S ⊆ T → step S ⊆ step T)
  (h_extensive : ∀ S : Finset σ, S ⊆ step S) :
  ∀ A : Finset σ, ∃ N : ℕ, step^[N] A = step^[N+1] A
```

This is the first anchor: theorem discovery stabilizes on finite idempotent state spaces.

Then strengthen it to identify the stabilized object as the least fixed point above the axioms:

```lean
theorem closure_is_least_fixed_point
  {σ : Type} [DecidableEq σ] [Fintype σ]
  (step : Finset σ → Finset σ)
  (h_mono : ∀ {S T : Finset σ}, S ⊆ T → step S ⊆ step T)
  (h_extensive : ∀ S : Finset σ, S ⊆ step S)
  (A : Finset σ) :
  ∃ C : Finset σ,
    A ⊆ C ∧
    step C = C ∧
    ∀ D : Finset σ, A ⊆ D → step D = D → C ⊆ D
```

This theorem is the precise formal version of “the idempotent closure automatically generates a lattice of consequences that converges to a fixed-point theory.”

### Provability Completeness Target

Now define a derivability predicate from the rule system. You may encode rules as a finite type:

```lean
structure Rule (σ : Type) where
  premises : Finset σ
  conclusion : σ
```

A rule fires in `S` if `premises ⊆ S`. Define:

```lean
def stepRules {σ : Type} [DecidableEq σ]
    (rules : Finset (Rule σ)) (S : Finset σ) : Finset σ :=
  S ∪ rules.biUnion (fun r =>
    if h : r.premises ⊆ S then {r.conclusion} else ∅)
```

Then define inductive derivability `Derivable rules A φ` in the usual proof-theoretic way: either `φ ∈ A`, or `φ` is the conclusion of a rule whose premises are all derivable.

The key completeness theorem is:

```lean
theorem derivable_iff_mem_closure
  {σ : Type} [DecidableEq σ] [Fintype σ]
  (rules : Finset (Rule σ)) (A : Finset σ) (φ : σ) :
  Derivable rules A φ ↔
    φ ∈ Classical.choose
      (closure_is_least_fixed_point
        (stepRules rules)
        (by
          intro S T hST
          -- monotonicity proof
          sorry)
        (by
          intro S
          -- extensivity proof
          sorry)
        A)
```

You do not need to force this exact implementation, but the theorem must state clearly:

> For every formula `φ`, `φ` belongs to the stabilized idempotent closure of `A` iff `φ` is derivable from `A` using the rules.

This is the formal heart of the project. It turns emergent closure into actual theorem discovery, not just closure under an arbitrary operator.

### Depth Bound / Spectral Complexity Target

The original prompt invokes “the tropical spectral radius of the closure operator bounds the depth of the deepest discoverable theorem.” This is too vague unless you make the operator finite and weighted.

So introduce a **weighted inference hypergraph** on a finite theorem set `σ`, where each rule has a cost/depth increment. The simplest robust formalization is via a min-plus dynamic program on theorem depths:
- each theorem gets value `∞` if not yet discovered,
- axioms get depth `0`,
- a rule with premises `p₁,...,p_k` and conclusion `c` updates
  `depth(c) ≤ max(depth(p_i)) + w(r)`.

This is a Bellman-style operator in the tropical / min-plus setting.

A realistic finite theorem statement is:

```lean
theorem least_depth_fixed_point_exists
  {σ : Type} [DecidableEq σ] [Fintype σ]
  (rules : Finset (Rule σ))
  (weight : Rule σ → ℕ)
  (A : Finset σ) :
  ∃ d : σ → WithTop ℕ,
    (∀ a, a ∈ A → d a = 0) ∧
    IsLeast
      {d' : σ → WithTop ℕ |
        DepthClosed rules weight A d'}
      d
```

where `DepthClosed` expresses closure under the min-plus update inequalities.

Then prove a finite-depth bound theorem of the following kind:

```lean
theorem derivable_depth_le_card
  {σ : Type} [DecidableEq σ] [Fintype σ]
  (rules : Finset (Rule σ))
  (A : Finset σ) :
  ∀ φ, Derivable rules A φ →
    ∃ n ≤ Fintype.card σ, φ ∈ (stepRules rules)^[n] A
```

This is already a nontrivial and formalizable spectral surrogate: the depth of discovery is bounded by the size of the state space.

Then, if possible, upgrade to a genuinely tropical matrix statement. Encode a dependency graph on single-premise rules or on SCC condensation, build a min-plus adjacency matrix `M : Matrix ι ι (WithTop ℕ)`, and prove:

```lean
theorem closure_depth_bounded_by_graph_diameter
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (M : Matrix ι ι (WithTop ℕ))
  (h_idem : ∀ i, M i i = 0) :
  ∀ i j, shortestPathDist M i j ≤ Fintype.card ι - 1
```

Use this as the rigorous replacement or precursor to the spectral-radius slogan. If you can connect to `spectral_radius_B2_equation`, do so by proving that in an idempotent finite nilpotent/acyclic propagation regime, tropical spectral radius `≤ 1` or `= 0` forces bounded proof depth.

A bold but plausible bridge theorem would be:

```lean
theorem tropical_spectral_radius_bounds_stabilization_steps
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (M : Matrix ι ι (WithTop ℕ)) :
  ∃ N ≤ Fintype.card ι,
    kleeneStarTrunc N M = kleeneStar M
```

Even if the full theorem is too ambitious, prove a finite truncation stabilization theorem for acyclic or upper-triangular min-plus matrices. That would already be a real bridge between theorem discovery and tropical linear algebra.

## 2–3 Proof Strategy Paths

### Strategy A: Finite lattice / monotone dynamics
1. Show `Finset σ` with inclusion is a finite poset; every ascending chain stabilizes within `Fintype.card σ` strict growth steps.
2. Prove `A ⊆ step A ⊆ step^[2] A ⊆ ...` using extensivity and monotonicity.
3. Conclude existence of `N` with `step^[N] A = step^[N+1] A`; then prove least-fixed-point minimality by induction on iterates.

Why this is promising: it is the cleanest route to the stabilization and least-fixed-point theorems, and it is extremely Lean-friendly.

### Strategy B: Inductive proof theory ↔ closure semantics
1. Define `Derivable rules A φ` inductively.
2. Prove soundness: if `Derivable rules A φ`, then `φ` lies in some iterate `step^[n] A`.
3. Prove completeness: if `φ ∈ step^[n] A`, then `Derivable rules A φ` by induction on `n`.

Why this matters: this theorem is the conceptual breakthrough. It identifies emergent closure with actual provability and gives theorem discovery semantics independent of syntax.

### Strategy C: Tropical dynamic programming / weighted dependency graph
1. Replace boolean membership by depth values in `WithTop ℕ`; define the Bellman operator associated to weighted rules.
2. Prove monotonicity and existence of the least fixed point by finite iteration.
3. For graph-like rule systems, identify the fixed point with shortest-path distances and derive explicit depth bounds from graph size, acyclicity, or tropical spectral constraints.

Why this is revolutionary: it recasts proof search as tropical optimization. This is the route that opens a new field rather than merely proving a closure lemma.
