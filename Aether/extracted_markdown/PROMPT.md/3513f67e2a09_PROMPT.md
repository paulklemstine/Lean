## Assignment: Galaxy-Scale Computation: Tropical Distributed Systems Across Light-Years

**Mode:** prove

Prove a genuinely new bridge theorem turning “galactic distributed computation” into a precise min-plus geometry statement in Lean 4. The goal is not metaphor. The goal is a formal theorem that says: when communication latency dominates, the right complexity object is the tropical shortest-path metric, and the global synchronization cost is controlled exactly by a tropical diameter/radius invariant. Then push one step further: prove that for monotone-idempotent aggregation tasks, repeated communication stabilizes without any consensus round complexity.

This is a cold start, but do not drift into vague definitions. Build concrete finite network models on `Fin n`, weighted by `ℝ≥0∞` or `ℝ`, and prove sharp statements.

### Core Breakthrough Vision

Classical parallel complexity assumes negligible synchronization relative to local compute. At galactic scale this is false: communication delay is the geometry. The revolutionary statement is that **distributed execution time becomes a tropical metric invariant**, and for a broad class of aggregation problems, **idempotence replaces consensus**. If formalized, this opens a new field:

- tropical distributed complexity,
- min-plus scheduling under relativistic latency,
- algebraic consensus-free computation,
- idempotent semantics for fault-tolerant aggregation,
- network geometry as computational complexity.

This is not “distributed systems with weights.” The breakthrough is to show that the *same min-plus algebra* underlying tropical geometry governs execution depth, synchronization barriers, and fixed-point stabilization of replicated state.

### Precise Formalization Targets

Work with a finite set of nodes `Fin n`. A communication network is given by edge delays
`w : Fin n → Fin n → ℝ≥0∞`, where `w i i = 0`, and absent links may be `⊤`.
Define the tropical path cost from `i` to `j` as the infimum/minimum over all path sums. On a finite graph with nonnegative weights, this should be realized by shortest paths, so you can avoid measure-theoretic complications.

You should define, or reuse if available:

- a path-cost function,
- a shortest-path distance `dist`,
- tropical diameter `diam := ⨆ i, ⨆ j, dist i j` or finite `Finset.sup`,
- tropical eccentricity/radius if helpful,
- a synchronous round model with latency-aware completion time.

### Primary Theorem A: Tropical Diameter Controls Global Completion Time

Formalize a finite dissemination model where one initial datum at source `s` must become available at every node, and a node can forward only after receipt. Prove that the optimal completion time equals the maximum shortest-path latency from `s`.

A Lean-shape target:

```lean
theorem optimal_broadcast_time_eq_max_dist
  {n : ℕ} (hn : 0 < n)
  (w : Fin n → Fin n → ℝ≥0∞)
  (hdiag : ∀ i, w i i = 0) :
  optimalBroadcastTime w
    = ⨆ j : Fin n, shortestDist w 0 j
```

More invariantly, for arbitrary source:

```lean
theorem optimal_broadcast_time_eq_eccentricity
  {n : ℕ} (hn : 0 < n)
  (w : Fin n → Fin n → ℝ≥0∞)
  (hdiag : ∀ i, w i i = 0)
  (s : Fin n) :
  optimalBroadcastTimeFrom w s = eccentricity w s
```

Then derive the network-level bound:

```lean
theorem optimal_all_source_broadcast_time_eq_diameter
  {n : ℕ} (hn : 0 < n)
  (w : Fin n → Fin n → ℝ≥0∞)
  (hdiag : ∀ i, w i i = 0) :
  ⨆ s : Fin n, optimalBroadcastTimeFrom w s = tropicalDiameter w
```

This theorem is the formal core of the “galaxy-scale network determines parallel speedup” claim. If every global barrier requires information propagation across the network, then the barrier cost is diameter-scale.

### Primary Theorem B: Parallel Speedup is Diameter-Limited

Now model a computation with total local work `W : ℝ≥0∞` and `k : ℕ` workers, where each barrier incurs communication cost at least the tropical diameter. You do not need a full PRAM theory; prove a mathematically clean upper bound that captures the principle.

For example, define a simple latency-aware runtime
`T(k) := W / k + B * tropicalDiameter w`
for `B` synchronization phases, and prove speedup is bounded by a rational function of diameter.

A Lean-shape theorem:

```lean
theorem speedup_le_latency_bound
  (W D : ℝ) (k B : ℕ)
  (hW : 0 ≤ W) (hD : 0 ≤ D) :
  W / (W / k + B * D) ≤ k
```

This is too weak alone, so strengthen it to show strict degradation when `D > 0` and `B > 0`:

```lean
theorem speedup_lt_workers_of_positive_diameter
  (W D : ℝ) (k B : ℕ)
  (hk : 0 < k) (hW : 0 < W) (hD : 0 < D) (hB : 0 < B) :
  W / (W / k + B * D) < k
```

Then connect this analytic bound to the graph invariant by substituting `D = tropicalDiameter w`.

If division on `ℕ` becomes annoying, move to `ℝ` with `(k : ℝ)`.

### Primary Theorem C: Idempotent Aggregation Stabilizes Without Consensus

This is the most original part. Model each node state as a value in a linearly ordered idempotent semiring-like structure, but for a first theorem just use `α` with `min` or `max`. Let the global update operator be

- each node receives neighbor states plus transmission delays,
- it updates by tropical aggregation (`min` or `max`) over received values.

For pure aggregation, prove that repeated application of an idempotent monotone update reaches the same global aggregate independent of message duplication/order, and that once all source values have reached a node, further rounds do not change the result.

Concrete first target on finite sets:

```lean
theorem min_aggregate_duplicate_invariant
  [LinearOrder α] (s : Finset α) (a : α) :
  min (s.inf' ?h) a = (insert a s).inf' ?h'
```

But do not stop at a Finset identity. Lift it to network execution:

```lean
theorem idempotent_aggregation_eventual_stability
  {n : ℕ} (hn : 0 < n)
  (w : Fin n → Fin n → ℝ≥0∞)
  (x : Fin n → ℝ)
  (t : ℝ≥0∞) :
  tropicalStateAtTime w x t = tropicalStateAtTime w x (t + tropicalDiameter w)
```

or a round-based version:

```lean
theorem idempotent_round_update_stabilizes
  {n : ℕ} (f : (Fin n → ℝ) → (Fin n → ℝ))
  (hmono : Monotone f)
  (hidem : Function.Idempotent f) :
  ∀ x, ∃ N, ∀ m ≥ N, (f^[m]) x = (f^[N]) x
```

Then specialize `f` to a tropical aggregation operator built from `min`/`max`. This is where the catalog lemmas matter:

- `tropical_idempotent`
- `tropical_min_comm`
- `tropical_add_idempotent`
- `min_self_idempotent`

Use them explicitly to discharge the algebraic identities behind duplicate-insensitivity and order-independence.

The philosophical claim “eliminates the need for consensus protocols” should be rendered mathematically as:

> for tasks whose specification is an idempotent commutative aggregation, all fair delivery schedules converge to the same fixed point, so agreement is a theorem of the algebra rather than a protocol-level achievement.

That is a real theorem shape.

### Proof Strategy Architecture

#### Strategy A: Graph-Theoretic Dynamic Programming via Shortest Paths
Most promising for Theorem A.

1. Define admissible broadcast schedules and prove any schedule inducing delivery to node `j` yields time at least `shortestDist w s j`.
2. Construct an optimal schedule by forwarding along shortest paths / shortest-path tree.
3. Take supremum over `j` to identify completion time with eccentricity, then over `s` for diameter.

Why this is promising: shortest-path realizability on finite nonnegative weighted graphs is concrete, constructive, and close to existing Mathlib graph/path machinery if available; otherwise it is still manageable with custom path definitions.

#### Strategy B: Tropical Linear Algebra / Min-Plus Closure
Most promising for Theorem C and elegant for A if you can make matrix powers work.

1. Represent network latency by a min-plus matrix `W`.
2. Show `W^⊗k` computes best `k`-hop propagation times.
3. Show Kleene star / finite closure computes all-pairs shortest paths on `Fin n`.
4. Interpret dissemination and aggregation as tropical matrix-vector multiplication; idempotence of tropical addition gives duplicate-insensitivity automatically.

Why this is powerful: it unifies routing, synchronization, and aggregation in one algebraic language. If you can get even a lightweight min-plus matrix API in Lean, it becomes a platform for future theorems.

#### Strategy C: Order-Theoretic Fixed Points for Consensus-Free Aggregation
Best for the “no consensus needed” theorem.

1. Define the state-update map as a monotone operator on `(Fin n → α)` with pointwise order.
2. Prove it is inflationary/deflationary and idempotent after closure over reachable messages.
3. Use finiteness or explicit bounded stabilization to show eventual fixed-point convergence.
4. Prove the fixed point depends only on the multiset/set of delivered source values, not on order or duplication.

Why this matters: it upgrades a systems slogan into a theorem in lattice/fixed-point theory. It also cross-connects with CRDT semantics and distributed databases.

### How to Use the Catalog Theorems

Do not merely cite them. Build with them.

- `tropical_idempotent`  
  Use to prove that aggregating the same message twice does not change node state. This is the algebraic basis of duplicate-insensitivity.

- `tropical_min_comm`  
  Use to prove schedule/order independence of pairwise message aggregation. Extend from binary commutativity to list/Finset fold invariance.

- `tropical_add_idempotent`  
  If you work in max-plus instead of min-plus for utility/arrival front semantics, this gives the corresponding duplicate-collapse theorem.

- `tropical_idempotent_quantum_obstruction`  
  Use as a conceptual contrast: idempotent tropical aggregation behaves classically and collapses duplicates, unlike genuinely non-idempotent quantum accumulation. This is a cross-domain bridge, not necessarily a dependency.

- `min_self_idempotent`  
  Useful for concrete `Nat`-based toy models and to discharge simplification goals in finite examples before generalizing to `ℝ`/`ℝ≥0∞`.
