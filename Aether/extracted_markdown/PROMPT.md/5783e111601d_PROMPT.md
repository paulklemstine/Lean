# McDiarmid Concentration for Tropical Nerve Observables: A Formal Foundation for Stochastic Topology

## The Central Theorem

**Theorem (Tropical McDiarmid Inequality):** Let $(\Omega_i)_{i=1}^m$ be finite sets with uniform probability, $\Omega = \prod_{i=1}^m \Omega_i$. For any function $f : \Omega \to \mathbb{R}$ satisfying the bounded-difference condition with constants $c_i$:

$$\forall i, \forall x \in \Omega, \forall x_i' \in \Omega_i: |f(x) - f(x[i \mapsto x_i'])| \leq c_i$$

the following concentration holds:

$$\Pr\!\left(\left|f(X) - \mathbb{E}[f(X)]\right| \geq t\right) \leq 2\exp\!\left(\frac{-2t^2}{\sum_{i=1}^m c_i^2}\right)$$

### Lean 4 Type Signatures

```lean
-- Core structure: bounded-difference functions on product spaces
structure BoundedDiffFun (m : ℕ) (Ω : Fin m → Type*) [Π i, Fintype (Ω i)] where
  toFun : (Π i, Ω i) → ℝ
  diffs : Fin m → ℝ
  diffs_pos : ∀ i, 0 ≤ diffs i
  bounded_diff : ∀ i (x : Π i, Ω i) (x_i : Ω i),
    |toFun (Function.update x i x_i) - toFun x| ≤ diffs i

-- The uniform expectation on a finite product space
def uniformExpect {m : ℕ} {Ω : Fin m → Type*} [Π i, Fintype (Ω i)]
    (f : (Π i, Ω i) → ℝ) : ℝ :=
  (∑' x, f x) / ∏ i, (Fintype.card (Ω i) : ℝ)

-- The main theorem
theorem mcdiarmid_concentration {m : ℕ} {Ω : Fin m → Type*} 
    [Π i, Fintype (Ω i)] (f : BoundedDiffFun m Ω) (t : ℝ) (ht : 0 ≤ t) :
    uniformProb (fun x => |f.toFun x - uniformExpect f.toFun| ≥ t) 
      ≤ 2 * Real.exp (-2 * t^2 / ∑ i, f.diffs i^2)

-- Corollary: nerve vertex count concentration
theorem nerveVertex_concentration {m : ℕ} {Ω : Fin m → Type*} 
    [Π i, Fintype (Ω i)] (t : ℝ) (ht : 0 ≤ t) :
    uniformProb (fun x => |nerveVertexCount x - uniformExpect nerveVertexCount| ≥ t) 
      ≤ 2 * Real.exp (-2 * t^2 / m)
```

## Proof Strategies

### Strategy A: Iterated Conditional Expectation (Most Promising)

This is the most direct formalization path, avoiding full martingale theory.

**Step 1.** Define the iterated conditional expectation on finite product spaces:
$$E_k(x_1, \ldots, x_k) = \frac{1}{\prod_{j=k+1}^m |\Omega_j|} \sum_{(x_{k+1}, \ldots, x_m)} f(x_1, \ldots, x_k, x_{k+1}, \ldots, x_m)$$

This is purely combinatorial — no measure-theoretic conditional expectation needed. Prove $E_0 = \mathbb{E}[f]$ and $E_m = f$.

**Step 2.** Establish the key bounded-increment lemma: for each $k$ and any partial assignment $(x_1, \ldots, x_{k-1})$:
$$|E_k(x_1, \ldots, x_{k-1}, x_k) - E_k(x_1, \ldots, x_{k-1}, x_k')| \leq c_k$$

This follows from the bounded-difference condition by triangle inequality over the sum, yielding exactly $\frac{|\Omega_k| \cdot c_k}{|\Omega_k|} = c_k$.

**Step 3.** Apply the exponential moment method iteratively. Show:
$$\mathbb{E}[e^{s(f - \mathbb{E}[f])}] = \mathbb{E}_{x_1}\left[\mathbb{E}_{x_2}\left[\cdots \mathbb{E}_{x_m}[e^{s(f - \mathbb{E}[f])}]\right]\right]$$

At each conditioning step, use Hoeffding's lemma (a convexity argument): if $Y$ is supported on an interval of width $c$, then $\mathbb{E}[e^{sY}] \leq e^{s^2 c^2/8}$. Chain these to get $\prod e^{s^2 c_i^2/8}$. Optimize over $s$ and apply Markov's inequality.

**Why most promising:** Each step is a finite computation over finite types. No `MeasureTheory.ConditionalExpectation` needed — just sums over `Fintype` instances. The Hoeffding lemma for finite uniform distributions is itself a finite calculation using convexity of $\exp$.

### Strategy B: Azuma-Hoeffding via Doob Martingale

**Step 1.** Define the Doob martingale $M_k = E_k(X_1, \ldots, X_k)$ and prove it is a martingale with respect to the natural filtration.

**Step 2.** Prove bounded increments: $|M_k - M_{k-1}| \leq c_k$ almost surely, using Step 2 from Strategy A.

**Step 3.** Apply the Azuma-Hoeffding inequality for martingales with bounded differences.

**Drawback:** Requires formalizing filtrations and martingale properties in Mathlib's `ProbabilityTheory` framework. The infrastructure exists but composing it is heavy.

### Strategy C: Tensorization via Subgaussian Certification

**Step 1.** Define: a function $f$ is $(v, L)$-subgaussian if $\mathbb{E}[\exp(sf)] \leq \exp(s^2 v/2 + sL)$ for all $s$.

**Step 2.** Prove a tensorization lemma: if $f(x_1, \ldots, x_m)$ is $(v_i, c_i)$-subgaussian in each coordinate, then $f - \mathbb{E}[f]$ is $(\sum v_i, \sum c_i)$-subgaussian.

**Step 3.** Show bounded-difference implies subgaussian, then optimize.

**Advantage:** This yields a more general framework (subgaussian calculus) that applies beyond McDiarmid. It connects to information-theoretic concentration via the Herbst argument.

**Cross-domain bridge:** The tensorization step is structurally identical to the data-processing inequality in information theory: $\mathbb{I}(X;Y) = \sum_i \mathbb{I}(X_i;Y)$ for independent $X_i$. This suggests a *tropical mutual information* satisfying analogous tensorization.

## Cross-Domain Connections

### 1. Statistical Learning Theory → PAC-Bayes Generalization Bounds

McDiarmid's inequality is the workhorse behind generalization bounds for learning algorithms. The bounded-difference constant $c_i$ measures *sensitivity* of the algorithm to a single training point. For `nerveVertexCount`, $c_i = 1$ means: changing one coefficient can change the nerve by at most one vertex. This yields:

**Theorem (Topological Generalization):** A learning algorithm that selects a tropical nerve based on training data has generalization gap $\epsilon$ with probability $\geq 1 - \delta$ provided $m \geq \frac{2\log(2/\delta)}{\epsilon^2}$ samples suffice.

### 2. Topological Data Analysis → Stability of Persistent Homology

The Gromov-Hausdorff stability of persistent homology (a foundational result in TDA) can be *quantified* via McDiarmid: if the bottleneck distance between persistence diagrams is a bounded-difference function of the sample points, then concentration follows. This is the first step toward *probabilistic* stability theorems.

### 3. Information Theory → Tropical Mutual Information

The subgaussian framework (Strategy C) connects to entropy via the Herbst argument: subgaussian concentration implies entropy bounds. Define:
$$I_{\text{trop}}(X; Y) = H_{\min}^{\text{trop}}(X) - H_{\min}^{\text{trop}}(X | Y)$$
where $H_{\min}^{\text{trop}}$ is the min-entropy of the tropical nerve observable. The McDiarmid bound then becomes: *tropical mutual information satisfies the data processing inequality*.

## Testable Conjecture

**Conjecture (Sharp McDiarmid for Nerve Observables):** For `nerveVertexCount` on $m$ coefficients uniformly drawn from $\{0, 1, \ldots, n-1\}$:

$$\Pr\!\left(\left|\text{nerveVertexCount}(X) - \frac{1}{n^m}\sum_x \text{nerveVertexCount}(x)\right| \geq t\right) = 2\Phi\!\left(\frac{-t}{\sqrt{m/3}}\right) \cdot (1 + o(1))$$

as $m \to \infty$, where $\Phi$ is the standard normal CDF.

**Computational test:** For $m = 10$, $n = 5$, enumerate all $5^{10} = 9765625$ coefficient vectors. Compute the exact distribution of `nerveVertexCount`. Compare the tail probabilities to the McDiarmid bound $2\exp(-2t^2/10)$ and to the Gaussian approximation $2\Phi(-t/\sqrt{10/3})$. The ratio of actual tail to McDiarmid bound should approach 1 for moderate $t$ and the Gaussian approximation should be tighter for large $m$.

**Falsification criterion:** If for any $m \leq 20$ and $n \leq 10$, the actual tail probability exceeds $2\exp(-2t^2/m)$ for any $t > 0$, the conjecture is false.
