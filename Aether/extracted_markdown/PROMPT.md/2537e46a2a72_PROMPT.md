## 3. Finite trace syntax as a free chronometric semiring with involution

Define a syntax of finite traces over an alphabet `α`, with sum, product, zero, one, and reverse:

```lean
inductive TraceExpr (α : Type u)
| zero : TraceExpr α
| one : TraceExpr α
| atom : α → TraceExpr α
| add : TraceExpr α → TraceExpr α → TraceExpr α
| mul : TraceExpr α → TraceExpr α → TraceExpr α
| rev : TraceExpr α → TraceExpr α
deriving DecidableEq, Repr
```

Define a semantic interpretation into any `ChronometricSemiring R`:

```lean
def TraceExpr.eval {α R} [ChronometricSemiring R]
    (σ : α → R) : TraceExpr α → R
```

with the equations:

- `zero ↦ 0`
- `one ↦ 1`
- `atom a ↦ σ a`
- `add e f ↦ eval e + eval f`
- `mul e f ↦ eval e * eval f`
- `rev e ↦ timeRev (eval e)`

Prove the evaluation respects reverse/multiplication anti-homomorphism:

```lean
theorem TraceExpr.eval_rev {α R} [ChronometricSemiring R]
    (σ : α → R) :
    ∀ e, TraceExpr.eval σ (TraceExpr.rev e) =
      ChronometricSemiring.timeRev (TraceExpr.eval σ e)

theorem TraceExpr.eval_mul_rev {α R} [ChronometricSemiring R]
    (σ : α → R) :
    ∀ e f,
      TraceExpr.eval σ (TraceExpr.rev (TraceExpr.mul e f)) =
      TraceExpr.eval σ (TraceExpr.mul (TraceExpr.rev f) (TraceExpr.rev e))
```

The second should be proved by direct simplification after the first.

## 4. Decidable normal form and algorithmic semantics

### 4.1 Normal forms

Define a syntactic normal form for finite traces. A practical choice is a finitely supported sum of words, where `rev` has been pushed to atoms and products reassociated.

You may define words over signed atoms:

```lean
inductive SignedAtom (α : Type u)
| fwd : α → SignedAtom α
| bwd : α → SignedAtom α
deriving DecidableEq, Repr

abbrev TraceWord (α : Type u) := List (SignedAtom α)
abbrev TraceNormalForm (α : Type u) := List TraceWord
```

Interpret `TraceNormalForm α` in any chronometric semiring by folding products over words and sums over lists.

Define normalization:

```lean
def TraceExpr.normalize : TraceExpr α → TraceNormalForm α
```

The intended behavior:
- `zero` ↦ `[]`
- `one` ↦ `[[]]`
- `atom a` ↦ `[[SignedAtom.fwd a]]`
- `add e f` ↦ concatenate normal forms
- `mul e f` ↦ language product of lists of words
- `rev e` ↦ reverse each word and swap `fwd ↔ bwd`

Prove semantic correctness:

```lean

    (σ : α → R) :
    ∀ e, evalNormalForm σ (TraceExpr.normalize e) = TraceExpr.eval σ e
```

## 10. Concrete proof hints for difficult points

### 10.1 `chronoLE_trans`
Use idempotent-add semiring algebra:
- from `a + b = b` and `b + c = c`
- compute `a + c = a + (b + c) = (a + b) + c = b + c = c`
- use associativity repeatedly

### 10.2 `chronoZeroLocus_union`
Use extensionality on sets:
- `ext P`
- split both directions
- for `→`, apply the universal condition to each side of the union
- for `←`, use `rcases` on membership in `S ∪ T`

### 10.3 `TraceExpr.normalize_sound`
Proceed by induction on `e`.
- `zero`, `one`, `atom`: trivial by unfolding
- `add`: evaluation over concatenation should correspond to semiring addition
- `mul`: prove an auxiliary lemma `evalNormalForm_append_mul`
- `rev`: prove a lemma that evaluating reversed words equals `timeRev` of the original evaluation, then lift to lists

### 10.4 Size bound
Define `TraceNormalForm.size` as total symbol count plus list overhead.
Then prove:
- additive case bounded by sum of bounds
- multiplicative case may double/combine, hence exponential
- use `omega` for arithmetic inequalities on `Nat`
A recurrence of the form
`T(add e f) ≤ T(e)+T(f)+1`, `T(mul e f) ≤ T(e)*T(f)+1`, `T(rev e) ≤ T(e)+1`
is enough to derive a coarse `2 ^ size` bound.

### 10.5 Causal separation
If full prime existence is hard, isolate it as a typeclass assumption and prove all consequences cleanly.
For reconstruction:
- prove inclusion `⊆` by direct application
- for `⊇`, use `by_contra hx`
- obtain a separating `P` from `HasChronoPrimeSeparation.sep`
- derive contradiction with the universal spectral condition

```lean
theorem mul_left (C : SemiringCong A) (f : A) {a b : A} (h : C.r a b) :
```

```lean
# Prime Congruence Spectra of Closure-Generated Proof Semirings

This file establishes the algebraic core of **proof-spectrum semantics**: the reconstruction
of semiprime theories/kernels as intersections of prime theories in commutative semirings.

## Main results

* `semiprime_eq_iInter_prime_theories` — A semiprime kernel in a commutative semiring equals the
  intersection of all prime theories containing it. This is the algebraic heart of the
  proof-spectrum correspondence.

* `exists_prime_theory_avoiding` — Prime separation: if `a` is not in a semiprime kernel `K`,
  there exists a prime theory containing `K` but not `a` (via Zorn's lemma).

* `zeroLocus_anti_mono`, `theoryOf_zeroLocus_extensive`, `theoryOf_zeroLocus_galois` — The
  antitone Galois correspondence between sets of proof terms and sets of congruences.

* `zeroClass_of_prime_congruence_isPrimeTheory` — The zero-class of a prime proof congruence
  is a prime theory.

## Mathematical overview

The key insight is that a proof system can be given the structure of an idempotent commutative
semiring, where `a + b` represents "either derivation resource," `a * b` represents "composite
derivation," and the induced order captures logical entailment. The prime congruence spectrum
then provides a geometric semantics: theories correspond to vanishing loci, and derivability
is captured by vanishing on all points of the associated spectral set.

The decisive theorem is that **semiprime** theories (those closed under square roots:
`a * a ∈ T → a ∈ T`) are exactly the intersections of prime theories. This is the
semiring-theoretic analogue of the radical ideal theorem from algebraic geometry.

## References

The algebraic content is a semiring generalization of the classical commutative algebra result
that semiprime ideals are intersections of prime ideals (a consequence of Krull's theorem).
The proof uses Zorn's lemma applied to the family of ideals disjoint from a multiplicative set.
-/
```
