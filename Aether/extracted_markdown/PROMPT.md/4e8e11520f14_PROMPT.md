## Core Mathematical Program

### New definitions you should introduce

You must define at least one genuinely new concept. The following package is the right abstraction level.

1. **Kernel-invariant noise law**
   A predicate saying that a distribution or weight function on ciphertext randomness is constant on cosets of `LinearMap.ker f`.

2. **FO consistency predicate**
   An abstract predicate saying that a ciphertext `c` is FO-consistent with respect to a public key, a hash/re-encryption rule, and a comparison relation.

3. **FO-factorable morphism**
   A module morphism through which FO consistency descends to the quotient.

Suggested Lean-level abstractions:

```lean
def KernelInvariant
    {R M N : Type*} [Semiring R] [AddCommMonoid M] [AddCommMonoid N]
    [Module R M] [Module R N]
    (f : M →ₗ[R] N) (μ : M → ℚ) : Prop :=
  ∀ x y, y - x ∈ f.ker → μ x = μ y
```

If subtraction forces additive groups, use the stronger assumptions `[AddCommGroup M] [AddCommGroup N]`.

```lean
def FOConsistentCiphertext
    {R M C K : Type*}
    [Semiring R] [AddCommMonoid M] [Module R M]
    (reencrypt : K → M → C)
    (recover   : C → K × M)
    (cmp       : C → C → Prop)
    (c : C) : Prop :=
  let km := recover c
  cmp (reencrypt km.1 km.2) c
```

And the factorization notion:

```lean
def FactorsThrough
    {α β γ : Type*} (g : α → β) (π : α → γ) : Prop :=
  ∃ h : γ → β, g = h ∘ π
```

For a predicate-valued map:

```lean
def PredicateFactorsThrough
    {α γ : Type*} (P : α → Prop) (π : α → γ) : Prop :=
  ∃ Q : γ → Prop, ∀ a, P a ↔ Q (π a)
```

These are not cosmetic definitions. They are the right language to state theorems that are stronger than implementation-specific equalities.

## Precise theorem targets

You should aim to prove at least the following three substantial theorems.

### Theorem 1: FO consistency factors through the kernel quotient

**Mathematical statement.**  
Let `f : M →ₗ[R] N` be a linear map. Assume:
- the reencryption/comparison behavior is invariant under perturbation by elements of `ker f`,
- the recovery procedure depends only on the image under `f`,
- the comparison relation is extensional under the quotient.

Then `FOConsistentCiphertext` factors through `f`.

This is the structural theorem: the FO check is really a predicate on compressed ciphertexts.

**Suggested Lean 4 type signature** (adapt to exact ambient structures available in Mathlib/catalog):

```lean
theorem foConsistent_factors_through_quotient
    {R M N C K : Type*}
    [CommSemiring R]
    [AddCommGroup M] [AddCommGroup N]
    [Module R M] [Module R N]
    (f : M →ₗ[R] N)
    (embed : M → C)
    (compress : C → N)
    (reencrypt : K → M → C)
    (recover : C → K × M)
    (cmp : C → C → Prop)
    (hcomp : ∀ m, compress (embed m) = f m)
    (hrecover :
      ∀ c₁ c₂, compress c₁ = compress c₂ → recover c₁ = recover c₂)
    (hcmp :
      ∀ c₁ c₂ c₁' c₂',
        compress c₁ = compress c₁' →
        compress c₂ = compress c₂' →
        (cmp c₁ c₂ ↔ cmp c₁' c₂'))
    : PredicateFactorsThrough
        (FOConsistentCiphertext reencrypt recover cmp)
        compress
```

A more quotient-native version using `Submodule.Quotient` is even better:

```lean
theorem foConsistent_factors_through_linear_quotient
    {R M C K : Type*}
    [CommSemiring R]
    [AddCommGroup M] [Module R M]
    (S : Submodule R M)
    (reencrypt : K → M → C)
    (recover : C → K × M)
    (cmp : C → C → Prop)
    ...
    : ∃ Q : M ⧸ S → Prop, ∀ m,
        FOConsistentCiphertext reencrypt recover cmp (reencrypt (recover (reencrypt default m)).1 m)
        ↔ Q (Submodule.Quotient.mk m)
```

You may need to refine the exact packaging, but the theorem must say unambiguously that the FO consistency predicate is a quotient predicate.

### Theorem 2: Kernel-invariant noise preserves FO rejection probability under compression

**Mathematical statement.**  
Suppose the ciphertext/noise law is invariant on cosets of `ker f`. Then the probability of FO rejection is equal before and after applying the compression map induced by `f`.

This is the probability-level theorem connecting the structural predicate to security experiments.

**Suggested Lean 4 type signature**:

```lean
theorem foRejectProb_map_eq
    {R M N C K : Type*}
    [CommSemiring R]
    [AddCommGroup M] [AddCommGroup N]
    [Module R M] [Module R N]
    [Fintype C] [DecidableEq C]
    (f : M →ₗ[R] N)
    (μ : C → ℚ)
    (compress : C → N)
    (reencrypt : K → M → C)
    (recover : C → K × M)
    (cmp : C → C → Prop)
    (hμ : KernelInvariant f (fun m => ∑ c : C, if compress c = f m then μ c else 0))
    (hfact : PredicateFactorsThrough (FOConsistentCiphertext reencrypt recover cmp) compress)
    :
    (∑ c : C, if FOConsistentCiphertext reencrypt recover cmp c then 0 else μ c)
      =
    (∑ y : N, if (Classical.choose hfact) y then 0 else
        ∑ c : C, if compress c = y then μ c else 0)
```

This signature is schematic; the exact probability formalization can be adapted to whatever finite-distribution API the catalog uses. The theorem must explicitly identify **FO rejection probability** as preserved by compression/quotienting.

If the catalog already provides a finite acceptance probability lemma like `acceptProb_map_eq`, use it as the engine and instantiate acceptance with the FO consistency predicate.

### Theorem 3: Hybrid CCA bound via quotient-preserved FO consistency

**Mathematical statement.**  
For an FO-style KEM game built over a CPA-secure PKE, if the FO consistency predicate factors through compression and the rejection probability is compression-invariant, then the CCA advantage after compression is bounded by the CPA advantage plus the FO rejection probability term.

This is the cryptographic payoff theorem.

**Suggested Lean 4 type signature**:

```lean
theorem ccaAdv_le_cpaAdv_add_foReject
    {Adv : Type*}
    [LinearOrderedRing Adv]
    (CCAAdv CPAAdv FOReject : Adv)
    (hhybrid : CCAAdv ≤ CPAAdv + FOReject)
    : CCAAdv ≤ CPAAdv + FOReject := hhybrid
```

The above is too weak by itself; you must prove a **nontrivial instantiated theorem** where `hhybrid` is derived from a game hop argument, not assumed. A more meaningful target is:

```lean
theorem fo_cca_advantage_bound_of_factorization
    {Game Ciphertext Plaintext Key : Type*}
    (CCAAdv CPAAdv FOReject : ℚ)
    (h₁ : -- game hop 1: replace decapsulation oracle by consistency oracle
      CCAAdv ≤ CPAAdv + FOReject)
    (h₂ : -- FO rejection probability unchanged by compression
      True)
    : CCAAdv ≤ CPAAdv + FOReject
```

But you should go further: define an abstract **decapsulation game transformation** and prove a lemma whose hypotheses are actual game-equivalence conditions. The theorem should not collapse to arithmetic tautology.

A stronger and more desirable statement is:

```lean
theorem fo_game_hop_bound
    {C S : Type*}
    [Fintype C] [DecidableEq C]
    (RealGame HybridGame : Set C → ℚ)
    (P : C → Prop)
    (μ : C → ℚ)
    (hagree : ∀ c, P c → RealGame {c} = HybridGame {c})
    :
    |(∑ c, μ c * RealGame {c}) - (∑ c, μ c * HybridGame {c})|
      ≤
    ∑ c, if P c then 0 else μ c
```

Then instantiate `P := FOConsistentCiphertext ...`. This is where the proof must use serious finite-sum reasoning, case splits, and multi-step `calc`.

## Proof strategy architecture

You must include at least 2–3 proof pathways and pursue the strongest one.

### Strategy A: Quotient-first structural proof
1. Define `FOConsistentCiphertext` abstractly and prove extensionality under equality of compressed images.
2. Use `Submodule.Quotient` or a `PredicateFactorsThrough` wrapper to build the descended predicate.
3. Push the descended predicate through the finite probability theorem from `KernelQuotient.lean`.

**Why promising:** This aligns perfectly with the catalog’s quotient/compression infrastructure and gives the cleanest theorem statement.

### Strategy B: Game-semantic proof via bad-event decomposition
1. Define the FO decapsulation game and the “bad event” that re-encryption mismatch occurs.
2. Prove game equality on the complement of the bad event.
3. Bound the distinguishing gap by the bad-event probability, then identify that probability with FO rejection and invoke compression invariance.

**Why promising:** This is the right path to the CCA theorem. It turns quotient invariance into a security statement rather than just a predicate statement.

### Strategy C: Coset-analytic proof via sufficient statistics
1. Show that compression `f` partitions ciphertext space into cosets/fibers.
2. Prove that both the noise law and the FO consistency predicate are fiber-constant.
3. Rewrite the rejection probability as a sum over fibers, obtaining exact equality before/after compression.

**Why promising:** This is conceptually elegant and makes the information-theoretic meaning explicit: compression is a sufficient statistic for FO consistency.

**Recommended order:** A → C → B.  
A gives the predicate theorem, C gives the probability theorem, B gives the security consequence.
