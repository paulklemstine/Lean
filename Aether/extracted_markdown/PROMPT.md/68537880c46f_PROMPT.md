
This is novel enough to matter: it interpolates between interval geometry and weighted digraph potentials.

## Theorem 1: Two-sided closure criterion for tropical band feasibility

### Mathematical statement
For a finite index type `ι`, a tropical band system is feasible if and only if its lower bounds satisfy all upper and difference constraints after closure under shortest-path inequalities.

A precise theorem schema:

> Let `B` be a tropical band system on a finite set `ι`. Define the path pseudodistance
> `dist_B i j` as the infimum/finite minimum of path weights induced by `B.slack`.
> Then `B` is feasible if and only if:
>
> 1. for all `i`, `lower i ≤ upper i`,
> 2. for all `i j`, `lower i ≤ lower j + dist_B i j`,
> 3. for all `i j`, `lower i ≤ upper j + dist_B i j`,
> 4. no negative cycle occurs in the weighted digraph determined by `slack`.

This is the tropical analogue of Bellman-Ford feasibility, but phrased as a Helly-style certificate theorem.

### Lean 4 type signature sketch

```lean
theorem tropBand_feasible_iff_closedBounds
  {ι : Type _} [Fintype ι] [DecidableEq ι]
  (B : TropBand ι) :
  B.Feasible ↔
    NoNegativeCycle B.slack ∧
    (∀ i, B.lower i ≤ B.upper i) ∧
    (∀ i j, B.lower i ≤ B.lower j + closureDist B.slack i j) ∧
    (∀ i j, B.lower i ≤ B.upper j + closureDist B.slack i j)
```

If `closureDist` and `NoNegativeCycle` do not already exist, define them carefully for finite weighted digraphs.

### Why this is a breakthrough
This theorem upgrades tropical box feasibility into a **residuated tropical convexity theorem**. It says tropical feasibility is governed by metric closure, not raw constraints. That is the bridge from tropical geometry to shortest-path duality.

### Proof strategy options

**Strategy A: Potential construction via shortest-path closure**  
Most promising.
1. Define `x i := inf_j (B.upper j + closureDist B.slack i j)` or a finite-min version.
2. Prove by multi-step `calc` that this `x` satisfies all difference constraints using triangle inequalities for `closureDist`.
3. Show lower-bound admissibility from the closure hypotheses.

Why promising: it yields the constructive witness directly, which is essential for the algorithmic deliverable.

**Strategy B: Induction on constraint saturation**
1. Start from the raw lower bound assignment.
2. Iteratively tighten coordinates using violated constraints.
3. Prove termination on finite types via monotone closure and derive the least feasible potential.

Why promising: closer to algorithm extraction, though more technically involved in Lean.

**Strategy C: Reduction to finite weighted graph feasibility**
1. Encode the system as a graph with source/sink nodes.
2. Invoke or rebuild shortest-path / no-negative-cycle machinery.
3. Translate graph potentials back into tropical feasibility.

Why promising: ideal if catalog graph lemmas are strong; less elegant tropically, but robust.

## Theorem 2: Helly number 2 for laminar tropical bands

Boxes have Helly number 2. General tropical convexity may have larger Helly number. The right next breakthrough is to identify a nontrivial intermediate class where Helly number 2 survives.

### New concept
Define a finite family of tropical bands to be **laminar** if their active difference-constraint graphs are nested or pairwise compatible in a precise sense, e.g. every pair of supports is nested or the union contains no alternating directed cycle.

Possible formal skeleton:

```lean
def LaminarSupportFamily {ι α : Type _}
    (S : α → Finset (ι × ι)) : Prop :=
  ∀ a b, S a ⊆ S b ∨ S b ⊆ S a
```

Then attach each support to a `TropBand ι`.

### Mathematical statement
> For any finite laminar family of tropical band systems on `ι`, if every pair of systems has a common feasible point, then the whole family has a common feasible point.

### Lean 4 type signature sketch

```lean
theorem helly_two_laminar_tropBands
  {ι α : Type _} [Fintype ι] [DecidableEq ι] [Fintype α]
  (B : α → TropBand ι)
  (hLam : LaminarTropBandFamily B)
  (hPair : ∀ a b, ∃ x : ι → ℝ, FeasibleFor x (B a) ∧ FeasibleFor x (B b)) :
  ∃ x : ι → ℝ, ∀ a, FeasibleFor x (B a)
```

### Why this is a breakthrough
This would identify the first non-box tropical family with a verified Helly number 2. It would show that Helly-2 is not an accident of intervals but a consequence of **hierarchical constraint geometry**. That opens a classification program: which tropical convex families admit constant-size certificates?

### Proof strategy options

**Strategy A: Extremal feasible point gluing**
1. For each band, define canonical least/greatest feasible potentials from closure.
2. Use laminarity to prove pairwise compatibility forces monotone nesting of feasible regions.
3. Intersect these canonical bounds to construct a global witness.

Why promising: reduces geometry to order structure; ideal if theorem 1 is already established.

**Strategy B: Induction on the laminar family tree**
1. Organize the family by inclusion into a rooted tree.
2. Prove the result for leaves and combine upward using pairwise feasibility at each merge.
3. Use `rcases` on the laminar dichotomy and a careful induction on finite cardinality.

Why promising: naturally deep and Lean-friendly for finite families.

**Strategy C: Contradiction via minimal counterexample**
1. Assume a minimal family with pairwise but not global intersection.
2. Use laminarity to find a maximal support and remove/reinsert it.
3. Derive a contradiction by comparing closure distances.

Why promising: conceptually sharp, but likely harder to mechanize than induction.

## Theorem 3: Tropical feasibility certificates are equivalent to graph-potential certificates

This is the mandatory cross-domain theorem.

### Mathematical statement
> For a tropical band system on a finite index set, feasible points are in bijective correspondence with graph potentials satisfying a weighted digraph inequality system. In particular, infeasibility is certified by a negative directed cycle, while feasibility is certified by a potential function.

This is a precise bridge between tropical geometry and combinatorial optimization.

### Lean 4 type signature sketch

```lean
theorem tropBand_feasible_iff_graphPotential
  {ι : Type _} [Fintype ι] [DecidableEq ι]
  (B : TropBand ι) :
  B.Feasible ↔ ∃ p : ι → ℝ, GraphPotentialCert B.slack B.lower B.upper p
```

and an explicit infeasibility witness theorem:

```lean
theorem tropBand_infeasible_of_negativeCycle
  {ι : Type _} [Fintype ι] [DecidableEq ι]
  (B : TropBand ι) :
  HasNegativeCycle B.slack → ¬ B.Feasible
```

Optionally, strengthen to an iff if you can formalize finite negative-cycle detection cleanly.

### Why this is a breakthrough
This theorem means tropical Helly geometry is not just geometry. It is a geometric language for **difference constraints, shortest paths, temporal consistency, and control invariants**. It creates a verified bridge between tropical convexity and optimization theory.

### Proof strategy options

**Strategy A: Direct translation**
1. Show every feasible `x` is a graph potential by rearranging inequalities.
2. Conversely, a graph potential satisfying lower/upper side conditions gives a feasible tropical point.
3. Prove negative cycles contradict telescoping sums using `calc` over cycle edges.

Why promising: simple, powerful, and exposes the exact bridge.

**Strategy B: Matrix/residuation formulation**
1. Encode constraints as a min-plus linear operator.
2. Use a fixed-point or residuation lemma to derive potential existence.
3. Recover graph certificates from the operator form.

Why promising: more conceptual and opens future spectral directions.
