## Research Task: Berggren semigroup finite-prefix unique factorization and logarithmic word-metric rigidity for the SL₂(ℤ) SPB embedding

Research Mode: PROVE

Prove a concrete normal-form theorem for the positive Berggren semigroup generated by the three standard SL₂(ℤ) matrices already present in the SPB development. The central objective is to upgrade the existing cancellation and common-multiple facts to a full free-monoid model: every semigroup element should admit a unique word in the three generators, left/right divisibility should coincide with prefix/suffix order on that word, and the induced word-length should be a genuine additive grading.

### Precise theorem targets

Work with the existing type of Berggren generators and their embedding into `SL(2, ℤ)` / `Matrix (Fin 2) (Fin 2) ℤ` already defined in the SPB files. Introduce, if not already present, the finite alphabet type of generators and its evaluation into matrices.

A good concrete setup is:

```lean
inductive BergGen
| A | B | C
deriving DecidableEq, Fintype

abbrev BergWord := List BergGen

def evalBergWord : BergWord → Matrix (Fin 2) (Fin 2) ℤ
```

with `evalBergWord [] = 1` and `evalBergWord (g :: w) = evalGen g * evalBergWord w`, where `evalGen : BergGen → Matrix (Fin 2) (Fin 2) ℤ` is the existing embedding of the three Berggren generators.

Then target the following theorem package.

#### 1. Injectivity / freeness of the evaluation map

The primary theorem should be stated as:

```lean
theorem evalBergWord_injective :
  Function.Injective evalBergWord
```

Equivalently, if a subsemigroup `bergSemigroup` is already defined and the evaluation lands in it, prove:

```lean
theorem evalBergWord_eq_iff {u v : BergWord} :
  evalBergWord u = evalBergWord v ↔ u = v
```

This is the decisive “no hidden relations” theorem.

A stronger and often more useful formulation is the left-factor version:

```lean
theorem evalBergWord_mul_eq_evalBergWord_mul_iff
    {u v s t : BergWord} :
  evalBergWord (u ++ s) = evalBergWord (v ++ t) ↔ u = v ∧ s = t
```

when specialized appropriately after extracting the maximal common prefix. You likely will first prove the simpler injectivity theorem and then derive overlap rigidity.

#### 2. Unique coding of semigroup elements

Define the image semigroup predicate, e.g.

```lean
def InBergSemigroup (M : Matrix (Fin 2) (Fin 2) ℤ) : Prop :=
  ∃ w, evalBergWord w = M
```

Then define a canonical code by classical choice:

```lean
noncomputable def bergWordOf
    (M : Matrix (Fin 2) (Fin 2) ℤ)
    (hM : InBergSemigroup M) : BergWord := ...
```

and prove:

```lean
theorem eval_bergWordOf
    {M : Matrix (Fin 2) (Fin 2) ℤ} (hM : InBergSemigroup M) :
  evalBergWord (bergWordOf M hM) = M

theorem bergWordOf_unique
    {M : Matrix (Fin 2) (Fin 2) ℤ} (hM : InBergSemigroup M) {w : BergWord} :
  evalBergWord w = M → w = bergWordOf M hM
```

This isolates the normal form needed for downstream cryptographic use.

#### 3. Left-divisibility = prefix, right-divisibility = suffix

Define divisibility relations internally to the semigroup:

```lean
def LeftDivides (X Y : Matrix (Fin 2) (Fin 2) ℤ) : Prop :=
  ∃ Z, InBergSemigroup Z ∧ Y = X * Z

def RightDivides (X Y : Matrix (Fin 2) (Fin 2) ℤ) : Prop :=
  ∃ Z, InBergSemigroup Z ∧ Y = Z * X
```

Then prove the exact prefix/suffix correspondence:

```lean
theorem leftDivides_iff_prefix
    {u v : BergWord} :
  LeftDivides (evalBergWord u) (evalBergWord v) ↔ ∃ t, v = u ++ t

theorem rightDivides_iff_suffix
    {u v : BergWord} :
  RightDivides (evalBergWord u) (evalBergWord v) ↔ ∃ t, v = t ++ u
```

The uniqueness of the residual factor should be explicit:

```lean
theorem left_factor_unique
    {u v s t : BergWord}
    (hs : evalBergWord v = evalBergWord u * evalBergWord s)
    (ht : evalBergWord v = evalBergWord u * evalBergWord t) :
  s = t
```

and similarly on the right. In prefix language:

```lean
theorem prefix_residual_unique
    {u v s t : BergWord}
    (hs : v = u ++ s) (ht : v = u ++ t) :
  s = t
```

but the matrix-level uniqueness is the substantive one, derived using cancellation plus injectivity.

#### 4. Additive word length and rigidity under truncation

Define:

```lean
noncomputable def bergLength
    (M : Matrix (Fin 2) (Fin 2) ℤ) (hM : InBergSemigroup M) : ℕ :=
  (bergWordOf M hM).length
```

Then prove well-defined additivity:

```lean
theorem bergLength_eval (w : BergWord) :
  bergLength (evalBergWord w) ⟨w, rfl⟩ = w.length

theorem bergLength_mul
    {X Y : Matrix (Fin 2) (Fin 2) ℤ}
    (hX : InBergSemigroup X) (hY : InBergSemigroup Y) :
  bergLength (X * Y) (by
    rcases hX with ⟨u, rfl⟩
    rcases hY with ⟨v, rfl⟩
    exact ⟨u ++ v, by simp [evalBergWord]⟩)
  = bergLength X hX + bergLength Y hY
```

Also prove finite-prefix truncation rigidity: if two products agree up to a fixed initial segment, that segment is forced.

A clean statement is:

```lean
theorem eval_prefix_rigidity
    {u v s t : BergWord}
    (h : evalBergWord (u ++ s) = evalBergWord (v ++ t))
    (huv : u.length = v.length) :
  u = v
```

and more generally:

```lean
theorem eval_common_prefix_decomposition
    (u v : BergWord) :
  ∃ p s t,
    u = p ++ s ∧
    v = p ++ t ∧
    (s = [] ∨ t = [] ∨ s.head? ≠ t.head?)
```

followed by the matrix consequence that any equality of products factors through the longest common prefix.

#### 5. Overlap decomposition for equations `x*u = y*v`

The semigroup-theoretic payoff is a free-monoid overlap theorem. A robust statement is:

```lean
theorem berg_overlap_decomposition
    {u v s t : BergWord}
    (h : evalBergWord u * evalBergWord s = evalBergWord v * evalBergWord t) :
  ∃ p u' v',
    u = p ++ u' ∧
    v = p ++ v' ∧
    (u' = [] ∨ v' = []) ∧
    evalBergWord u' * evalBergWord s = evalBergWord v' * evalBergWord t
```

Using injectivity, this should sharpen to the free-monoid dichotomy:

```lean
theorem berg_overlap_free_monoid
    {u v s t : BergWord}
    (h : evalBergWord (u ++ s) = evalBergWord (v ++ t)) :
  ∃ p a b,
    u = p ++ a ∧
    v = p ++ b ∧
    (a = [] ∨ b = []) ∧
    a ++ s = b ++ t
```

From this derive the standard comparability corollary:

```lean
theorem equal_products_prefix_comparable
    {u v s t : BergWord}
    (h : evalBergWord u * evalBergWord s = evalBergWord v * evalBergWord t) :
  u <+: v ∨ v <+: u
```

where `<+:` is `List.IsPrefix`.

### Proof strategy

A successful route is to prove a “first-letter rigidity” lemma and then bootstrap to full injectivity by induction on word length.

1. **Construct a generator-recognition invariant.**  
   Use a concrete monotone invariant extracted from the matrix entries or from the action on primitive Pythagorean triples. The key lemma should distinguish the three left cones:
   ```lean
   theorem berg_generator_left_disjoint
       {g h : BergGen} {u v : BergWord}
       (hne : g ≠ h) :
     evalGen g * evalBergWord u ≠ evalGen h * evalBergWord v
   ```
   The content is that the images of the principal left ideals `gS` are pairwise disjoint. This is the real freeness input. A likely proof is by analyzing one or two matrix entries mod small integers, or by showing each generator sends a suitable invariant region/congruence class to a disjoint subset. Since the Berggren matrices are explicit, parity/congruence fingerprints of the first column or of the associated primitive triple are promising.

2. **Upgrade disjointness to first-letter cancellation.**  
   Prove:
   ```lean
   theorem berg_head_eq_of_cons_eq_cons
       {g h : BergGen} {u v : BergWord}
       (hEq : evalBergWord (g :: u) = evalBergWord (h :: v)) :
     g = h
   ```
   using the previous disjointness lemma. Then use the already verified left-cancellation theorem for the semigroup embedding to deduce:
   ```lean
   theorem berg_tail_eq_of_cons_eq_cons
       {g : BergGen} {u v : BergWord}
       (hEq : evalBergWord (g :: u) = evalBergWord (g :: v)) :
     u = v
   ```

3. **Induct on total length to prove injectivity.**  
   For `u` and `v`, split on emptiness. If both are nonempty, apply head rigidity to show the first letters agree, cancel, and recurse on tails. This yields `evalBergWord_injective`. Keep the induction measure simple:
   ```lean
   Nat.recAux? / induction on u generalizing v
   ```
   or induction on `u.length + v.length`.

4. **Derive prefix/suffix characterization from injectivity plus semigroup multiplication.**  
   For left divisibility, if `evalBergWord v = evalBergWord u * Z` and `Z = evalBergWord t`, then:
   ```lean
   evalBergWord v = evalBergWord (u ++ t)
   ```
   hence injectivity gives `v = u ++ t`. The converse is immediate by taking `Z = evalBergWord t`. Right divisibility is analogous, using `evalBergWord (t ++ u) = evalBergWord t * evalBergWord u`.

5. **Define length through the unique code and prove additivity.**  
   Once `bergWordOf` is unique, `bergLength` is independent of witnesses. For multiplication, choose words `u`, `v` for `X`, `Y`; then `X * Y = evalBergWord (u ++ v)`, and injectivity identifies the canonical code with `u ++ v`. Therefore the length is additive.

6. **Longest common prefix / overlap theorem.**  
   Use the standard list decomposition lemma: for any words `u`, `v`, there exists a maximal common prefix `p` with `u = p ++ a`, `v = p ++ b`, and either `a = []`, `b = []`, or the heads of `a`, `b` differ. Apply this to an equality
   ```lean
   evalBergWord (u ++ s) = evalBergWord (v ++ t)
   ```
   If both `a` and `b` are nonempty with distinct heads, then after rewriting the equality becomes an equality of words with different first letters, contradicting first-letter rigidity. Hence one of `a`, `b` is empty, i.e. one prefix is contained in the other. This is the exact free-monoid overlap structure.

### Why this matters

This theorem package is the structural backbone needed to treat the Berggren/SPB semigroup as a genuine free semigroup inside `SL₂(ℤ)`, rather than merely a cancellative one. That distinction is crucial for at least three reasons.

1. **Cryptographic normal forms.**  
   Protocol elements can be encoded canonically by generator words, so equality testing, transcript parsing, and reduction arguments become exact rather than quotient-dependent.

2. **Divisibility and extraction.**  
   Prefix/suffix recovery turns semigroup equations into combinatorics on words. This is the right framework for proving uniqueness of decomposition, analyzing collision resistance, and formalizing extraction from equalities appearing in SPB Diffie–Hellman style protocols.

3. **Metric rigidity.**  
   The additive length function gives a computable grading on the semigroup, providing a word metric that is rigid under multiplication and truncation. This opens the door to growth estimates, finite-prefix security arguments, and eventually to algorithmic membership and shortest-factorization results.

The decisive nontrivial step is not the list combinatorics; it is proving the principal left/right ideals generated by the three Berggren matrices are disjoint in the positive semigroup image. Once that is formalized cleanly, the rest should fall into place via cancellation and induction, yielding a substantial upgrade of the current SPB algebraic infrastructure.
