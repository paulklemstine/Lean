### Target Theorem 1: Tropical Choquet Representation for Closure Functionals

Mathematical statement:

Let `K` be a compact tropical convex object and let `F : K → ℝ` be a functional satisfying:
- monotonicity,
- preservation of tropical suprema,
- shift-equivariance: `F (x ⊕ c) = F x + c`,
- suitable upper semicontinuity / compact compatibility assumptions already encoded in the Choquet-Radon infrastructure.

Then there exists a tropical capacity `μ` supported on the extremal spectrum `Ext K` such that for all `x ∈ K`,
\[
F(x) = \sup_{e \in \mathrm{Ext}(K)} \big(\operatorname{ev}_e(x) + \mu(e)\big).
\]
Moreover, under an anti-chain separation hypothesis on `Ext K`, this representing capacity is unique up to tropical scalar normalization.

A Lean-oriented signature skeleton:

```lean
theorem tropical_choquet_representation
  {K : Type*} [TopologicalSpace K]
  [Preorder K] [SemilatticeSup K]
  [CompactSpace K]
  (Ext : Set K)
  (F : K → ℝ)
  (hmon : Monotone F)
  (hsup : ∀ x y, F (sup x y) = max (F x) (F y))
  (hshift : ∀ (x : K) (c : ℝ), F (tropShift x c) = F x + c)
  (husc : UpperSemicontinuous F)
  (hChoquet : TropicalChoquetData K Ext F) :
  ∃ μ : K → ℝ,
    (∀ e ∉ Ext, μ e = ⊥ₜ) ∧
    ∀ x : K, F x = sSup {r : ℝ | ∃ e ∈ Ext, r = tropEval e x + μ e}
```

If `⊥ₜ` is not available in your tropical codomain abstraction, replace by a chosen “inactive weight” convention or finite-support formulation.

A more finite/computable variant, likely easier to formalize first:

```lean
theorem finite_tropical_choquet_representation
  {K : Type*} [Fintype K] [Preorder K] [SemilatticeSup K]
  (Ext : Finset K)
  (F : K → ℝ)
  (hmon : Monotone F)
  (hsup : ∀ x y, F (sup x y) = max (F x) (F y))
  (hshift : ∀ (x : K) (c : ℝ), F (tropShift x c) = F x + c)
  (hgen : ∀ x, ∃ S ⊆ Ext, x = tropSupHull S) :
  ∃ μ : K → ℝ,
    ∀ x : K, F x = Ext.sup (fun e => tropEval e x + μ e)
```

This finite theorem may be the right first milestone, with the compact theorem obtained by approximation/compactness.

Then the closure-fixed equilibrium observables correspond exactly to extremal generators in the tropical capacity representation.

Formally, if `Eq(F)` denotes equilibrium observables and `ExtCap(F)` denotes extremal points of the representing capacity polytope, then

x \in Eq(F) \cap \mathrm{Fix}(\operatorname{cl})

x \text{ corresponds to an extremal atom of } \mu_F.

### Target Theorem 3: Uniqueness via Tropical Anti-Chain Separation

Mathematical statement:

Assume the extremal spectrum satisfies a tropical anti-chain separation property: distinct extremals can be separated by a closure-preserving tropical affine observable. Then the capacity representation is unique.

\[
\mu_1,\mu_2 \text{ represent } F \implies \mu_1 = \mu_2.
\]

Lean skeleton:

```lean
theorem tropical_capacity_representation_unique
  {K : Type*} [TopologicalSpace K] [Preorder K] [SemilatticeSup K]
  (Ext : Set K) (F : K → ℝ)
  (hsep : TropicalAntichainSeparation Ext)
  {μ₁ μ₂ : K → ℝ}
  (h₁ : RepresentsTropically Ext F μ₁)
  (h₂ : RepresentsTropically Ext F μ₂) :
  μ₁ = μ₂
```

This theorem matters because without uniqueness, “representation” is merely existential. With uniqueness, you have a canonical equilibrium decomposition.

### Target Theorem 4: Certified Finite Decomposition with Stability Bounds

Mathematical statement:

For computable finitely generated closure functionals, one can compute a finite extremal support
\[
F(x) = \max_{e \in S} (\operatorname{ev}_e(x) + w_e)
\]
with `S` consisting of closure-extremal atoms. Moreover, if `‖F-G‖ ≤ ε` in tropical sup norm / ultrametric norm, then the resulting weights and support are stable up to an explicit bound.

Lean skeleton:

```lean
theorem certified_extremal_decomposition
  {C : Type*} [Fintype C] [Preorder C] [SemilatticeSup C]
  (cl : C → C) (F : C → ℝ)
  (hcl : ClosureOperator cl)
  (hfin : FinitelyGeneratedClosureFunctional cl F)
  (hax : TropicalClosureAxioms F) :
  ∃ S : Finset C, ∃ w : C → ℝ,
    (∀ s ∈ S, IsExtremalGenerator cl F s) ∧
    ∀ x : C, F x = S.sup (fun s => tropEval s x + w s)
```

and stability:

```lean
theorem certified_extremal_decomposition_stable
  {C : Type*} [Fintype C] [PseudoMetricSpace (C → ℝ)]

  (hF : HasCertifiedExtremalDecomposition cl F)
  (hG : HasCertifiedExtremalDecomposition cl G)
  (hclose : dist F G ≤ ε) :
  ∃ δ ≤ K * ε,
    ExtremalSupportDistance hF hG ≤ δ
```

## Proof Architecture: 3 Viable Strategies

### Strategy A: Finite-generation first, then compact completion
This is the most promising route.

1. **Finite extremal hull theorem**  
   Work first in a finitely generated closure/tropical convex setting. Show every admissible `F` is determined by its values on closure-extremal generators. Then define weights
   \[
   w_e := \inf_x (F(x) - \operatorname{ev}_e(x))
   \]
   in tropical form and prove
   \[
   F(x)=\max_e(\operatorname{ev}_e(x)+w_e).
   \]

2. **Identify equilibrium observables with extremal support**  
   Show an observable is equilibrium/fixed iff removing its atom changes the represented functional. This gives extremality as semantic indispensability.

3. **Pass to compact Choquet-Radon form**  
   Use compactness and upper semicontinuity to upgrade finite max representations to support on `Ext K`. This is where `CompactTropicalChoquetRadon` should enter decisively.

Why this is strongest: it gives a computational theorem first, which is more Lean-friendly and aligns with the requested decomposition pipeline.

---

### Strategy B: Abstract idempotent Hahn–Banach / separation route
This is more conceptual and may yield the cleanest theorem statement.

1. Define the cone of admissible closure functionals and the tropical convex hull of evaluation maps.
2. Use an idempotent separation theorem to show any monotone sup-preserving shift-equivariant functional lies in the closure of that hull.
3. Characterize extremal points by non-separable equilibrium states, then prove uniqueness via anti-chain separation.

Why useful: this could produce the most elegant “representation iff axioms” theorem.  
Why risky: Lean formalization of abstract separation may be heavier unless Mathlib/your infrastructure already contains enough order-topological convexity lemmas.

---

### Strategy C: Pressure semantics as the representation engine
This is the most original EML-facing route.

1. Start from the certified pressure semantics of closure functionals using
   `certified_closure_pressure_O_n_bound`.
2. Show the pressure of a closure functional can be rewritten as a tropical envelope of extremal trace/equilibrium observables.
3. Use `closure_thermodynamic_trace_not_vacuum` to eliminate degenerate representations and prove the support consists of nontrivial extremal equilibrium atoms.

Why this is exciting: it directly binds thermodynamic semantics to tropical representation theory.  
Why secondary: it likely depends on having enough representation lemmas already in place, so it may be better as the second theorem after Strategy A.
