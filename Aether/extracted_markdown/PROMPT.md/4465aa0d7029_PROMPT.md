The goal is to formalize a Schulze/beatpath aggregation layer on top of pairwise tropical Hecke margins for `Fin 3`, and prove a certified robustness theorem whose radius is governed by the minimum decisive beatpath gap. This should not be treated as a mere voting-theory exercise: the key mathematical content is that tropical Hecke score geometry induces a weighted tournament, the Schulze winner is extracted by a max-min path closure, and the closure is 1-Lipschitz with respect to uniform perturbations of edge weights. That gives a new certified multiclass decision rule distinct from top-2, Condorcet-by-raw-margins, and score-gap rules.

### Core definitions to introduce

Use concrete finite types throughout. A good starting point is to define weighted directed graphs on `Fin n` by a margin matrix.

Suggested definitions:

```lean
def PairMargin (n : ℕ) := Fin n → Fin n → ℝ

def beatpathStrength {n : ℕ} (m : PairMargin n) (i j : Fin n) : ℝ := ...
```

For formalization, avoid arbitrary path types at first. Since the target is `Fin 3`, define beatpath strength by explicit closure over paths of length at most `n`, or use a finite dynamic-programming closure:

```lean
def widemaxStep {n : ℕ} (m p : PairMargin n) : PairMargin n :=
  fun i j => max (p i j) (Finset.univ.sup fun k => min (p i k) (m k j))

def beatpathIter {n : ℕ} (m : PairMargin n) : ℕ → PairMargin n
| 0 => m
| t+1 => widemaxStep m (beatpathIter m t)

def beatpathStrengthN {n : ℕ} (m : PairMargin n) : PairMargin n :=
  beatpathIter m n
```

If `Finset.sup` over `ℝ` becomes awkward because `ℝ` is not order-top by default, switch to explicit `Finset.fold max` with seed `m i j`, or define for `Fin 3` by enumerating intermediates. For this project, a robust and Lean-friendly route is preferable to maximal generality.

Define the winner predicate:

```lean
def IsBeatpathWinner {n : ℕ} (m : PairMargin n) (c : Fin n) : Prop :=
  ∀ d, d ≠ c → beatpathStrengthN m c d > beatpathStrengthN m d c

def UniqueBeatpathWinner {n : ℕ} (m : PairMargin n) (c : Fin n) : Prop :=
  IsBeatpathWinner m c ∧ ∀ d, IsBeatpathWinner m d → d = c
```

For GL3 tropical Satake scores, define margins from scores:

```lean
def scoreMargin (H : Fin 3 → ℝ) : PairMargin 3 :=
  fun i j => H i - H j
```

and, if needed, a perturbation relation:

```lean
def MarginPerturbBound {n : ℕ} (m m' : PairMargin n) (ε : ℝ) : Prop :=
  ∀ i j, |m' i j - m i j| ≤ ε
```

Finally define the decisive beatpath gap of a candidate:

```lean
def beatpathGap (m : PairMargin 3) (c : Fin 3) : ℝ :=
  Finset.inf' (Finset.univ.erase c)
    (by
      simp)
    (fun d => beatpathStrengthN m c d - beatpathStrengthN m d c)
```

If `Finset.inf'` over `ℝ` is cumbersome, define instead:

```lean
def beatpathGapLB (m : PairMargin 3) (c : Fin 3) (γ : ℝ) : Prop :=
  ∀ d, d ≠ c → γ ≤ beatpathStrengthN m c d - beatpathStrengthN m d c
```

This lower-bound formulation is often much easier for the robustness theorem and avoids order-theoretic boilerplate.

### Precise theorem targets

The central theorem should be split into a graph-theoretic layer and a Hecke-score layer.

#### 1. Beatpath winner uniqueness from strict pairwise beatpath dominance

```lean
theorem unique_beatpath_winner_of_strict_domination
    (m : PairMargin 3) (c : Fin 3)
    (hdom : ∀ d, d ≠ c → beatpathStrengthN m c d > beatpathStrengthN m d c) :
    UniqueBeatpathWinner m c
```

A useful intermediate theorem:

```lean
theorem beatpath_winner_irrefl_asym
    (m : PairMargin 3) {a b : Fin 3}
    (ha : beatpathStrengthN m a b > beatpathStrengthN m b a) :
    ¬ IsBeatpathWinner m b
```

The uniqueness proof should be direct: if `c` strictly dominates every rival in beatpath strength, no rival can itself dominate `c`, so no rival satisfies the winner predicate.

#### 2. 1-Lipschitz stability of beatpath strengths under uniform edge perturbations

This is the crucial max-min closure theorem.

```lean
theorem beatpathStrengthN_lipschitz
    (m m' : PairMargin 3) (ε : ℝ)
    (hε : 0 ≤ ε)
    (hpert : MarginPerturbBound m m' ε) :
    ∀ i j, |beatpathStrengthN m' i j - beatpathStrengthN m i j| ≤ ε
```

This theorem is the real engine of the program. It says the beatpath closure over the bottleneck semiring does not amplify uniform additive uncertainty on edges.

To make this tractable, prove first the scalar inequalities for `min` and `max`:

```lean
theorem min_abs_le_of_abs_le_abs_le
    {a a' b b' ε : ℝ}
    (ha : |a' - a| ≤ ε) (hb : |b' - b| ≤ ε) :
    |min a' b' - min a b| ≤ ε
```

```lean
theorem max_abs_le_of_abs_le_abs_le
    {a a' b b' ε : ℝ}
    (ha : |a' - a| ≤ ε) (hb : |b' - b| ≤ ε) :
    |max a' b' - max a b| ≤ ε
```

Then prove a finite-sup/fold stability lemma specialized to `Fin 3`:

```lean
theorem fold_max_abs_le_of_pointwise_abs_le
    (f g : Fin 3 → ℝ) (ε : ℝ) (hε : 0 ≤ ε)
    (hfg : ∀ k, |f k - g k| ≤ ε) :
    |(Finset.univ.sup f) - (Finset.univ.sup g)| ≤ ε
```

If `Finset.univ.sup` is awkward, replace with explicit `max (f 0) (max (f 1) (f 2))` using `Fin 3` enumeration.

Then prove by induction on the iteration parameter:

```lean
theorem beatpathIter_lipschitz
    (m m' : PairMargin 3) (ε : ℝ)
    (hε : 0 ≤ ε)
    (hpert : MarginPerturbBound m m' ε) :
    ∀ t i j, |beatpathIter m' t i j - beatpathIter m t i j| ≤ ε
```

and derive `beatpathStrengthN_lipschitz` by taking `t = 3`.

#### 3. Winner preservation under a half-gap condition

Formulate in lower-bound form first:

```lean
theorem beatpath_winner_stable_of_half_gap
    (m m' : PairMargin 3) (c : Fin 3) (ε γ : ℝ)
    (hε : 0 ≤ ε)
    (hpert : MarginPerturbBound m m' ε)
    (hgap : ∀ d, d ≠ c → γ ≤ beatpathStrengthN m c d - beatpathStrengthN m d c)
    (hdec : 2 * ε < γ) :
    IsBeatpathWinner m' c
```

Proof idea: for each rival `d`,
- `beatpathStrengthN m' c d ≥ beatpathStrengthN m c d - ε`,
- `beatpathStrengthN m' d c ≤ beatpathStrengthN m d c + ε`,
so
- `beatpathStrengthN m' c d - beatpathStrengthN m' d c ≥ (beatpathStrengthN m c d - beatpathStrengthN m d c) - 2ε ≥ γ - 2ε > 0`.

Then derive uniqueness:

```lean
theorem unique_beatpath_winner_stable_of_half_gap
    (m m' : PairMargin 3) (c : Fin 3) (ε γ : ℝ)
    (hε : 0 ≤ ε)
    (hpert : MarginPerturbBound m m' ε)
    (hgap : ∀ d, d ≠ c → γ ≤ beatpathStrengthN m c d - beatpathStrengthN m d c)
    (hdec : 2 * ε < γ) :
    UniqueBeatpathWinner m' c
```

using `unique_beatpath_winner_of_strict_domination`.

### Proof strategy

#### Strategy A: Dynamic-programming closure on `Fin 3` via max-min iteration
This is the most promising route in Lean.

1. Define `beatpathIter` using one-step closure
   \[
   p_{t+1}(i,j) = \max\big(p_t(i,j), \max_k \min(p_t(i,k), m(k,j))\big).
   \]
   On `Fin 3`, this computes the strongest path of length at most `t+1`.

2. Prove the one-step Lipschitz lemma:
   if `p` and `p'` are pointwise `ε`-close and `m,m'` are pointwise `ε`-close, then
   `widemaxStep m p` and `widemaxStep m' p'` are pointwise `ε`-close.
   This uses:
   - `abs_sub_le_iff` manipulations,
   - monotonicity/Lipschitzness of `min`,
   - monotonicity/Lipschitzness of finite `max`.

3. Induct on `t` to obtain `beatpathIter_lipschitz`.
   Since the same `ε` persists through max-min closure, there is no accumulation with path length; this is the conceptual heart of the theorem.

4. Use two-sided estimates from the absolute-value bound to compare decisive beatpath gaps before and after perturbation, losing at most `2ε`.

5. Deduce strict positivity under `2ε < γ`, hence preservation of beatpath winner status and uniqueness.

This route is attractive because it turns the social-choice statement into a clean semiring-stability theorem.

#### Strategy B: Pathwise definition over finite lists with simple-path reduction
This is mathematically elegant but more combinatorial.

1. Define path strength of a nonempty directed path as the minimum edge margin along the path.
2. Define beatpath strength as the maximum over all simple paths from `i` to `j`.
3. Prove every path strength changes by at most `ε` under edge perturbation, because minima are 1-Lipschitz.
4. Since the set of simple paths on `Fin 3` is finite, maxima are also 1-Lipschitz.
5. Conclude winner stability from the gap argument.

This route may become cumbersome because encoding paths and simple-path finiteness in Lean costs more than the mathematics itself.

#### Strategy C: Explicit closed form for `Fin 3`
For `Fin 3`, one can derive a formula:
\[
p(i,j)=\max\big(m(i,j), \max_{k\neq i,j}\min(m(i,k),m(k,j))\big),
\]
since any simple path has length at most 2. This is extremely efficient.

1. Prove on `Fin 3` that every nontrivial simple path from `i` to `j` is either direct or passes through the unique third vertex.
2. Obtain an explicit formula for beatpath strength.
3. Prove Lipschitzness directly from the formula using `min`/`max` stability.
4. Derive winner uniqueness and robustness immediately.

This route is especially compelling if the goal is a polished theorem for `GL3` only. It sacrifices generality but may be the shortest path to a complete, clean formalization.

Recommended plan: use Strategy C if you want the strongest chance of a fully finished file with minimal infrastructure, and Strategy A if you want reusable beatpath closure machinery for future `Fin n` generalizations.

### Why this matters

This theorem creates a new certified decision architecture for tropical Satake classifiers. Existing robustness certificates in the project mostly certify raw score gaps, top-2 separations, or direct pairwise dominance. Beatpath aggregation is qualitatively different: it extracts a winner from the global geometry of pairwise comparisons via bottleneck path closure. That means:

- **It connects tropical representation theory to bottleneck semiring dynamics.**
  The closure operator behind Schulze aggregation is a tropical/max-min analogue of transitive completion. Showing it is 1-Lipschitz under score perturbation is a structural theorem, not just a classifier fact.

- **It produces an algorithmic certificate.**
  The winner and its robustness radius can be computed by max-min Floyd–Warshall style closure on the pairwise Hecke margin matrix. This gives a certifiable multiclass rule with a concrete computational shadow.

- **It opens a new bridge to Condorcet-consistent aggregation inside formalized ML/representation pipelines.**
  Rather than collapsing everything to one-vs-rest or direct argmax, you formalize a graph-mediated decision rule that can exploit indirect evidence through strong comparison chains.

- **It sets up future generalization beyond `Fin 3`.**
  Once the 1-Lipschitz max-min closure theorem is in place, the path is open to `GL_n`, tropical attention/graph networks, and robust decision rules based on idempotent semiring closures more generally.

This is exactly the kind of theorem that turns a collection of isolated certified inequalities into a new mathematical language for robust multiclass inference.
