## Research Task: EML Stone–Weierstrass for compact convex codomains via affine coordinates and a uniform retraction

### Research Mode: PROVE

Prove a codomain-constrained universal approximation theorem extending the finished finite-dimensional vector-valued EML Stone–Weierstrass result. The new content is that approximants must land in a prescribed compact convex subset `C` of a finite-dimensional real normed space, not merely in the ambient affine hull.

The cleanest route is to formalize the theorem first for a **convex compact subset of Euclidean space** `Fin m → ℝ`, where a canonical nearest-point projection/retraction is available, and then derive the affine-space version by transporting along an affine equivalence between `affineHull ℝ C` and `EuclideanSpace ℝ (Fin m)`.

---

## Main theorem to target first: Euclidean codomain version

Let `K` be a compact Hausdorff space, `m : ℕ`, and `C : Set (EuclideanSpace ℝ (Fin m))` be nonempty, compact, and convex. Let `A : Subalgebra ℝ C(K, ℝ)` be a scalar approximation class satisfying:
- constants are in `A`,
- lattice closure (`sup`, `inf`, hence `max`, `min`) is available on the uniform closure of `A`,
- `A` separates points of `K`,
- the existing scalar/vector EML Stone–Weierstrass theorem gives uniform density of the induced coordinatewise class in `C(K, EuclideanSpace ℝ (Fin m))`.

Define the codomain-constrained class
```lean
def EMLConvexMaps
    (A : Subalgebra ℝ C(K, ℝ))
    (C : Set (EuclideanSpace ℝ (Fin m))) : Set (C(K, C)) := ...
```
as the set of continuous maps into `C` obtained by composing a coordinatewise `A`-approximant `g : C(K, EuclideanSpace ℝ (Fin m))` with a continuous retraction `r : EuclideanSpace ℝ (Fin m) → C` that is the identity on `C`.

A strong target statement is:


This schematic type should be replaced by an explicit density statement in the uniform topology on `C(K, C)`. If it is technically easier, prove the epsilon-form version first:


The key point is that the output `g` lands in `C` by construction.

## Core geometric lemma: continuous retraction onto compact convex sets in Euclidean space

This is the pivotal new theorem. Use metric projection onto a nonempty compact convex subset of finite-dimensional Euclidean space.

A precise target:

```lean
theorem exists_continuous_retraction_compact_convex_euclidean
    {m : ℕ}
    (C : Set (EuclideanSpace ℝ (Fin m)))
    (hC_nonempty : C.Nonempty)
    (hC_compact : IsCompact C)
    (hC_convex : Convex ℝ C) :
    ∃ r : EuclideanSpace ℝ (Fin m) → C,
      Continuous r ∧
      ∀ x : C, r x = x
```

Since `r` has codomain `C`, the identity-on-`C` condition should be interpreted via coercions:
```lean
∀ x : C, ((r x : C) : EuclideanSpace ℝ (Fin m)) = x
```
or, if `r : EuclideanSpace ℝ (Fin m) → EuclideanSpace ℝ (Fin m)` with range in `C`,
```lean
MapsTo r Set.univ C ∧ Continuous r ∧ ∀ x ∈ C, r x = x.
```

This second formulation is often easier to compose with `ContinuousMap`.

A very usable version is:

```lean
theorem exists_continuous_selfmap_into_compact_convex_fixing
    {m : ℕ}
    (C : Set (EuclideanSpace ℝ (Fin m)))
    (hC_nonempty : C.Nonempty)
    (hC_compact : IsCompact C)
    (hC_convex : Convex ℝ C) :
    ∃ r : EuclideanSpace ℝ (Fin m) → EuclideanSpace ℝ (Fin m),
      Continuous r ∧
      Set.MapsTo r Set.univ C ∧
      ∀ x ∈ C, r x = x
```

If nearest-point projection already exists in Mathlib for complete convex subsets of an inner product space, use it directly. Otherwise isolate the needed existence/continuity facts in lemmas.

## Proof strategy: concrete steps

### Step 1: Build or import the metric projection/retraction
For compact convex `C ⊆ EuclideanSpace ℝ (Fin m)`, define `r x` as a minimizer of `y ↦ ‖x - y‖` on `C`.

Useful sublemmas to prove:

```lean
theorem exists_norm_isMinOn_compact
    {m : ℕ} (C : Set (EuclideanSpace ℝ (Fin m)))
    (hC_nonempty : C.Nonempty) (hC_compact : IsCompact C) (x : EuclideanSpace ℝ (Fin m)) :
    ∃ y ∈ C, IsLeast ((fun z : C => ‖x - (z : EuclideanSpace ℝ (Fin m))‖) '' Set.univ) ‖x - y‖
```

and uniqueness from strict convexity of the squared norm plus convexity of `C`:
```lean
theorem nearest_point_unique_of_convex
    {m : ℕ} {C : Set (EuclideanSpace ℝ (Fin m))}
    (hC_convex : Convex ℝ C) :
    ...
```

Then package the unique minimizer as `projC x`. For continuity, in finite dimensions it is enough to prove the projection is 1-Lipschitz or at least continuous. If nonexpansiveness is available, prove:

```lean
theorem dist_proj_le_dist
    ...
theorem lipschitz_proj_compact_convex :
    LipschitzWith 1 projC
```

If the full 1-Lipschitz proof is too heavy, continuity by compactness/uniqueness plus closed-graph is acceptable:
- show `x_n → x` implies every cluster point of `projC x_n` is a nearest point to `x`,
- uniqueness forces convergence.

### Step 2: Lift the retraction to continuous maps
Given `r : E → E` continuous with `MapsTo r univ C`, define:
```lean
def retractContinuousMap (r : E → E) (hrc : Set.MapsTo r Set.univ C) :
    C(K, E) → C(K, C)
```
by pointwise composition. Also prove:
```lean
theorem retractContinuousMap_coe
    (F : C(K, C)) :
    retractContinuousMap r hrc (F.comp <| ContinuousMap.id ?_) = F
```
or the corresponding extensional identity after coercion to `C(K, E)`.

This lets you convert ambient approximants into codomain-constrained approximants.

### Step 3: Quantitative control via uniform continuity of the retraction
To conclude approximation, you need a modulus of continuity for `r` on a compact neighborhood containing the image of approximants. The easiest route is to prove `r` is Lipschitz (ideally `1`-Lipschitz), yielding:
```lean
‖r ∘ G - r ∘ F‖ ≤ ‖G - F‖.
```
Then for `f : C(K, C)`, since `r ∘ f = f`, any ambient approximant `G` to `(f : C(K, E))` immediately gives a codomain-constrained approximant `r ∘ G`.

If only continuity is available, use uniform continuity on the compact set
```lean
(range ((f : C(K, E)))) ∪ closure (range G)
```
or, more simply, first approximate so closely that `G(K)` lies in a fixed compact neighborhood `N` of `C`, then use uniform continuity of `r` on `N`.

A clean epsilon proof pattern:
1. choose `δ > 0` from continuity/Lipschitz of `r`,
2. approximate `f` by `G` in the ambient vector-valued EML class with `‖f - G‖ < δ`,
3. define `g := r ∘ G`,
4. use `r ∘ f = f` and the modulus of continuity to get `‖f - g‖ < ε`.

### Step 4: Preserve the EML-generated nature of the approximants
You need a formal class of admissible codomain-constrained approximants. The most robust definition is existential:

```lean
def EMLConvexMaps
    {K : Type*} [TopologicalSpace K]
    {m : ℕ}
    (A : Subalgebra ℝ C(K, ℝ))
    (C : Set (EuclideanSpace ℝ (Fin m))) :
    Set (C(K, C)) :=
  {f | ∃ G : C(K, EuclideanSpace ℝ (Fin m)),
      G ∈ vectorEMLClass A ∧
      ∀ x, G x ∈ Set.univ ∧
      f = retractContinuousMap projC (by intro x hx; exact projC_mem x)}
```

But because equality into subtype-valued maps can be awkward, it may be cleaner to define:
```lean
def IsRetractEMLApprox
    (f : C(K, C)) : Prop :=
  ∃ G ∈ vectorEMLClass A, f = ContinuousMap.codRestrict _ (fun x => projC_mem _) (projC ∘ G)
```

Then the theorem becomes:
```lean
∀ f : C(K, C), ∀ ε > 0, ∃ g, IsRetractEMLApprox A C g ∧ ‖(f : C(K, E)) - (g : C(K, E))‖ < ε
```

### Step 5: Affine reduction from general finite-dimensional `V`
For general `V`, work inside the affine hull of `C`. Since `C` is compact convex and `V` is finite-dimensional, `affineSpan ℝ C` is finite-dimensional and affinely equivalent to `EuclideanSpace ℝ (Fin m)` for some `m`. Transport:
- the target map `f : C(K, C)` to Euclidean coordinates,
- the ambient approximation class coordinatewise,
- the retraction theorem back through the affine equivalence.

A useful intermediate lemma is:
```lean
theorem compact_convex_has_affine_euclidean_model
    {V : Type*} [NormedAddCommGroup V] [NormedSpace ℝ V] [FiniteDimensional ℝ V]
    (C : Set V) :
    ∃ (m : ℕ) (e : affineHull ℝ C ≃A[ℝ] EuclideanSpace ℝ (Fin m)), True
```
Even if the exact affine-hull subtype is awkward, any linear isomorphism after choosing a basepoint is enough:
- choose `c₀ ∈ C`,
- identify the direction space of `affineSpan ℝ C` with a finite-dimensional subspace,
- choose a basis and a linear isomorphism to `Fin m → ℝ`,
- encode points by coordinates relative to `c₀`.

## Why this matters

This theorem is the correct codomain-sensitive extension of the vector-valued EML Stone–Weierstrass program. The already established finite-dimensional theorem only gives approximants in an ambient vector space. For many applications—probability simplices, bounded control sets, state constraints, color spaces, portfolios, stochastic kernels, and normalized outputs in machine learning—the codomain itself is semantically essential. Approximating a map `K → C` by maps `K → V` is not enough if the approximants violate positivity, normalization, or geometric constraints.

Formalizing the compact-convex retraction principle upgrades the entire approximation theory from “ambient approximation” to “intrinsic approximation inside the target set.” Once this is in place, several downstream results become accessible:
- EML universal approximation into simplices and boxes,
- approximation of probability-vector-valued maps with codomain preserved,
- constrained neural approximation theorems where outputs remain feasible,
- future extensions to tropical/idempotent constrained codomains via similar retract arguments.

So the central deliverable is not just another density theorem: it is the mechanism that makes approximation compatible with convex geometric constraints.

## Recommended implementation order

1. Prove the Euclidean retraction theorem for compact convex `C`.
2. Package composition with the retraction as a map `C(K, E) → C(K, C)`.
3. Prove the epsilon-form codomain-constrained density theorem in Euclidean space.
4. Only then transport to general finite-dimensional affine codomains.

If a full nearest-point projection is too ambitious initially, start with special codomains where the retraction is explicit:
- closed intervals in `ℝ`,
- products of intervals (`Icc` boxes) via coordinatewise clipping,
- standard simplex via positive-part normalization or Euclidean projection if available.

Even a theorem for `C = Set.Icc a b` in `Fin m → ℝ` would already be a meaningful constrained approximation result and a strong stepping stone to the general compact convex case.
