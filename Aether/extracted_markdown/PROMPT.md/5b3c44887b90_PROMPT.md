## Research Task: Tropical certified robustness for multiclass residual piecewise-linear networks under one-vs-all argmax via the global second-logit gap

Research Mode: PROVE

Develop a clean formal robustness theory for multiclass residual tropical / piecewise-linear networks in the `L∞` metric. The central goal is to prove that the predicted class is stable on an `L∞` ball whose radius is controlled by the global one-vs-all logit gap and an explicit residual-network Lipschitz constant. The mathematically nontrivial part is to build a compositional Lipschitz calculus for residual blocks `x ↦ x + g x`, then transfer that to pairwise margins and finally to argmax invariance.

This should be done at the level of concrete finite-dimensional real vectors, e.g. `Fin n → ℝ` for inputs and `Fin C → ℝ` for logits, with norms expressed as
`‖x - y‖∞ := Finset.sup (Finset.univ.image fun i => |x i - y i|)`
or via an existing `dist`/`norm` API if convenient. Keep the statements independent of differentiability: piecewise-linearity/tropicality matters mainly because it supplies Lipschitz constants and local affine regions.

### Core definitions to introduce

Use a fixed finite class count `C : ℕ` with `[Fact (2 ≤ C)]`, input dimension `d : ℕ`, and functions
`f : (Fin d → ℝ) → Fin C → ℝ`.

A useful concrete setup is:

```lean
def LinfDist {d : ℕ} (x y : Fin d → ℝ) : ℝ :=
  Finset.sup Finset.univ (fun i : Fin d => |x i - y i|)

def IsLinfLipschitz {d : ℕ} (K : ℝ) (g : (Fin d → ℝ) → α) : Prop :=
  0 ≤ K ∧ ∀ x y, ‖g x - g y‖ ≤ K * LinfDist x y
```

If codomain norms on functions `Fin C → ℝ` are inconvenient, work coordinatewise:

```lean
def LogitLipschitz {d C : ℕ} (K : ℝ) (f : (Fin d → ℝ) → Fin C → ℝ) : Prop :=
  0 ≤ K ∧ ∀ i x y, |f x i - f y i| ≤ K * LinfDist x y
```

Define predicted class and gap relative to a chosen winner `y : Fin C`:

```lean
def IsArgmaxAt {d C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ) (x : Fin d → ℝ) (y : Fin C) : Prop :=
  ∀ j, f x j ≤ f x y

def Margin {d C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ) (y j : Fin C) (x : Fin d → ℝ) : ℝ :=
  f x y - f x j

def GapAt {d C : ℕ} (f : (Fin d → ℝ) → Fin C → ℝ) (x : Fin d → ℝ) (y : Fin C) : ℝ :=
  sInf {r : ℝ | ∃ j : Fin C, j ≠ y ∧ r = Margin f y j x}
```

For finite `Fin C`, it may be easier and cleaner to define the gap using `Finset.inf'` over
`Finset.univ.erase y`:

```lean
def GapAtFinset {d C : ℕ} [Fact (2 ≤ C)]
    (f : (Fin d → ℝ) → Fin C → ℝ) (x : Fin d → ℝ) (y : Fin C) : ℝ :=
  Finset.inf' (Finset.univ.erase y) (by
    simpa using Finset.card_erase_pos.2 (Fin.is_lt y))
    (fun j => Margin f y j x)
```

Also define robustness on radius `r`:

```lean
def ArgmaxStableOnBall {d C : ℕ}
    (f : (Fin d → ℝ) → Fin C → ℝ) (x : Fin d → ℝ) (y : Fin C) (r : ℝ) : Prop :=
  ∀ x', LinfDist x x' ≤ r → ∀ j, f x' j ≤ f x' y
```

For residual blocks, define:

```lean
def ResidualBlock {d : ℕ} := (Fin d → ℝ) → (Fin d → ℝ)

def ResidualForm {d : ℕ} (T : ResidualBlock) : Prop :=
  ∃ g, T = fun x => x + g x
```

and a compositional Lipschitz constant for a list of blocks with constants `Ks : List ℝ`:
`Kres = (Ks.map (fun K => 1 + K)).prod`.

### Main theorem statements to target

#### 1. Residual block Lipschitz calculus

First prove the basic skip-addition estimate.

```lean
theorem residual_block_lipschitz
    {d : ℕ} {g : (Fin d → ℝ) → Fin d → ℝ} {Kg : ℝ}
    (hKg : 0 ≤ Kg)
    (hg : ∀ x y i, |g x i - g y i| ≤ Kg * LinfDist x y) :
    ∀ x y i,
      |((fun z i => z i + g z i) x i) - ((fun z i => z i + g z i) y i)|
        ≤ (1 + Kg) * LinfDist x y
```

A stronger vector-valued corollary should package the coordinatewise bound into a network Lipschitz statement:

```lean
theorem residual_block_LogitLipschitz_self
    {d : ℕ} {g : (Fin d → ℝ) → Fin d → ℝ} {Kg : ℝ}
    (hKg : 0 ≤ Kg)
    (hg : ∀ x y i, |g x i - g y i| ≤ Kg * LinfDist x y) :
    ∀ x y i,
      |(x i + g x i) - (y i + g y i)| ≤ (1 + Kg) * LinfDist x y
```

Then prove composition:

```lean
theorem comp_coordinate_lipschitz
    {α β γ : Type*} {K₁ K₂ : ℝ}
    {f : α → β} {g : β → γ}
    (hK₁ : 0 ≤ K₁) (hK₂ : 0 ≤ K₂)
    (hf : ∀ x y, distβ (f x) (f y) ≤ K₁ * distα x y)
    (hg : ∀ u v, distγ (g u) (g v) ≤ K₂ * distβ u v) :
    ∀ x y, distγ (g (f x)) (g (f y)) ≤ (K₂ * K₁) * distα x y
```

Specialize this to a list of residual blocks to obtain an explicit product bound:

```lean
theorem residual_network_lipschitz_of_blocks
    {d : ℕ} (Ts : List ((Fin d → ℝ) → (Fin d → ℝ))) (Ks : List ℝ)
    (hlen : Ts.length = Ks.length)
    (hblock :
      ∀ n hn, ∃ g,
        Ts.get ⟨n, by simpa [hlen] using hn⟩ = (fun x => x + g x) ∧
        ∀ x y i, |g x i - g y i| ≤ Ks.get ⟨n, by simpa [hlen] using hn⟩ * LinfDist x y)
    (hKs : ∀ n hn, 0 ≤ Ks.get ⟨n, by simpa [hlen] using hn⟩) :
    ∃ Kres,
      Kres = (Ks.map (fun K => 1 + K)).prod ∧
      ∀ x y i,
        |(List.foldl (fun Tacc T => T ∘ Tacc) id Ts x i) -
         (List.foldl (fun Tacc T => T ∘ Tacc) id Ts y i)| ≤ Kres * LinfDist x y
```

If the full list-indexing theorem is cumbersome, it is acceptable to first prove the two-block and finite-induction versions, then derive the list-product theorem.

#### 2. Pairwise margin Lipschitz bound

This is the key bridge from network Lipschitz control to multiclass robustness.

```lean
theorem margin_lipschitz
    {d C : ℕ} {f : (Fin d → ℝ) → Fin C → ℝ} {K : ℝ}
    (hK : 0 ≤ K)
    (hf : ∀ i x y, |f x i - f y i| ≤ K * LinfDist x y) :
    ∀ y j x x',
      |Margin f y j x - Margin f y j x'| ≤ (2 * K) * LinfDist x x'
```

A sharper one-sided form is especially useful for robustness:

```lean
theorem margin_lower_bound_under_perturbation
    {d C : ℕ} {f : (Fin d → ℝ) → Fin C → ℝ} {K : ℝ}
    (hK : 0 ≤ K)
    (hf : ∀ i x y, |f x i - f y i| ≤ K * LinfDist x y) :
    ∀ y j x x',
      Margin f y j x' ≥ Margin f y j x - (2 * K) * LinfDist x x'
```

This should follow from the elementary inequality
`|(a-b) - (c-d)| ≤ |a-c| + |b-d|`.

#### 3. Global second-logit gap certificate

Now prove the central robustness theorem.

```lean
theorem argmax_stable_of_gap_gt
    {d C : ℕ} [Fact (2 ≤ C)]
    {f : (Fin d → ℝ) → Fin C → ℝ} {K r : ℝ}
    {x : Fin d → ℝ} {y : Fin C}
    (hK : 0 ≤ K)
    (hf : ∀ i x x', |f x i - f x' i| ≤ K * LinfDist x x')
    (hy : IsArgmaxAt f x y)
    (hgap : 0 < GapAtFinset f x y)
    (hr : r < GapAtFinset f x y / (2 * K)) :
    ArgmaxStableOnBall f x y r
```

Also prove a weak-inequality variant that avoids strictness issues by giving `≤` with a strict gap hypothesis on every competitor:

```lean
theorem argmax_stable_of_pairwise_margin_bound
    {d C : ℕ}
    {f : (Fin d → ℝ) → Fin C → ℝ} {K r : ℝ}
    {x : Fin d → ℝ} {y : Fin C}
    (hK : 0 ≤ K)
    (hf : ∀ i x x', |f x i - f x' i| ≤ K * LinfDist x x')
    (hmargin : ∀ j, j ≠ y → 2 * K * r < Margin f y j x) :
    ArgmaxStableOnBall f x y r
```

Then derive the concise corollary:

```lean
theorem certified_radius_lower_bound
    {d C : ℕ} [Fact (2 ≤ C)]
    {f : (Fin d → ℝ) → Fin C → ℝ} {K : ℝ}
    {x : Fin d → ℝ} {y : Fin C}
    (hK : 0 ≤ K)
    (hf : ∀ i x x', |f x i - f x' i| ≤ K * LinfDist x x')
    (hy : IsArgmaxAt f x y) :
    ∀ r, r < GapAtFinset f x y / (2 * K) → ArgmaxStableOnBall f x y r
```

This is the formal version of the certificate
`r*(x) ≥ gamma(x) / (2 K)`.

Package the previous theorem for residual architectures.

theorem residual_multiclass_certified_radius

### Sharp local theorem

A stronger local result is worth proving if feasible: on a fixed linear region, the exact certificate is governed by the local Lipschitz constant, and equality holds when a worst-case competitor and perturbation direction are realized.

A tractable formal version is:

```lean
theorem local_certified_radius_lower_bound
    {d C : ℕ} [Fact (2 ≤ C)]
    {f : (Fin d → ℝ) → Fin C → ℝ} {Kloc : ℝ}
    {x : Fin d → ℝ} {y : Fin C} {ρ : ℝ}
    (hKloc : 0 ≤ Kloc)
    (hlocal : ∀ i x', LinfDist x x' ≤ ρ → |f x i - f x' i| ≤ Kloc * LinfDist x x')
    (hy : IsArgmaxAt f x y)
    (hρ : 0 < ρ) :
    ∀ r, r < min ρ (GapAtFinset f x y / (2 * Kloc)) → ArgmaxStableOnBall f x y r
```

If exact equality is too ambitious to formalize abstractly, isolate it as a theorem under explicit realizability assumptions:

```lean
theorem local_certified_radius_eq_under_attainment
    {d C : ℕ} [Fact (2 ≤ C)]
    ...
    (hattain_class : ∃ j, j ≠ y ∧ GapAtFinset f x y = Margin f y j x)
    (hattain_slope : ∃ x', LinfDist x x' = GapAtFinset f x y / (2 * Kloc) ∧
       Margin f y j x' = 0)
    :
    exact_certified_radius f x y = GapAtFinset f x y / (2 * Kloc)
```

It is acceptable to define `exact_certified_radius` as a supremum of radii on which `ArgmaxStableOnBall` holds, if that API is manageable; otherwise proving the lower bound plus a matching upper bound under attainment assumptions is enough.

### Concrete proof strategy

1. **Build the residual Lipschitz calculus from the triangle inequality.**  
   For a block `T x = x + g x`, fix coordinate `i` and write
   `|(x_i + g(x)_i) - (y_i + g(y)_i)| ≤ |x_i - y_i| + |g(x)_i - g(y)_i|`.
   Bound the first term by `LinfDist x y` and the second by `Kg * LinfDist x y`, then factor. This is the only genuinely new algebraic feature introduced by skip connections; it is what distinguishes the residual theorem from the already-understood pure feedforward/aggregation setting.

2. **Propagate constants through composition multiplicatively.**  
   Prove a general composition lemma once, then induct over the list of residual blocks. The resulting constant should be exactly
   `Kbody = ∏_ℓ (1 + Kℓ)`.
   If there is a final logit head with constant `Kh`, then logits have constant `Kres = Kh * Kbody`. Keep all nonnegativity hypotheses explicit, since Lean will need them for ring inequalities and monotonicity of multiplication.

3. **Pass from logit Lipschitz bounds to pairwise margin Lipschitz bounds.**  
   For `m_j(x) = f_y(x) - f_j(x)`, use
   `|m_j(x) - m_j(x')| ≤ |f_y(x)-f_y(x')| + |f_j(x)-f_j(x')| ≤ 2K d∞(x,x')`.
   Then derive the one-sided estimate
   `m_j(x') ≥ m_j(x) - 2K d∞(x,x')`.
   This is the critical lemma: multiclass argmax robustness reduces to preserving positivity of all pairwise margins.

4. **Convert the global gap into simultaneous positivity of all margins.**  
   Show that if `GapAtFinset f x y = γ`, then for every `j ≠ y`,
   `γ ≤ Margin f y j x`. Hence if `d∞(x,x') ≤ r` and `2Kr < γ`, then
   `Margin f y j x' > 0` for all `j ≠ y`. Conclude `f x' j < f x' y`, hence `y` remains an argmax. A useful intermediate lemma is:
   ```lean
   theorem gap_le_margin
       (j : Fin C) (hj : j ≠ y) :
       GapAtFinset f x y ≤ Margin f y j x
   ```

5. **For the local theorem, localize all previous arguments to a ball.**  
   Replace global Lipschitz hypotheses by local ones valid for `LinfDist x x' ≤ ρ`; the same proof yields stability for radii
   `r < min ρ (γ / (2Kloc))`.
   If pursuing equality, add explicit assumptions that a competitor attains the gap and that a perturbation in the active linear region drives that margin to zero exactly at radius `γ/(2Kloc)`.

### Technical Lean notes that should help

- Prefer `Finset.inf' (Finset.univ.erase y)` over `sInf` unless you specifically want order-theoretic generality; finite combinatorics is easier to control.
- You will likely need lemmas about `Finset.univ.erase y` being nonempty when `C ≥ 2`.
- It may be simpler to define `IsArgmaxAt` with weak inequalities and derive strict inequalities for competitors from positive margins.
- Keep separate lemmas for:
  - `abs_sub_le_of_le_linf`
  - `margin_eq_sub`
  - `gap_pos_iff_all_margins_pos`
  - `argmax_of_all_pairwise_margins_nonneg`
- If the exact vector `L∞` norm is cumbersome, a coordinatewise formulation is fully acceptable and likely the smoothest route in Lean.

### Why this matters

This theorem would give the first clean certified-robustness result for multiclass **residual** tropical/piecewise-linear architectures in the current development. The novelty is not just the final inequality `r ≥ γ/(2Kres)`, but the formal blockwise Lipschitz calculus for skip connections, which changes the algebra from pure composition to `id + g`. That calculus is the missing ingredient needed to extend tropical certified robustness from feedforward/aggregation models to residual networks, one of the explicitly prioritized directions. Once formalized, it should become reusable infrastructure for sharper local certificates, architecture-aware bounds, and eventually certified robustness theorems for more realistic network families.
