## Core Vision

Let `G` be a connected simple graph, `q` a distinguished root vertex, and `S ⊆ V(G)` a rooted subset invariant whose defect is governed by a balance between cycle rank and root-separation complexity. Suppose `S = S₁ ∪ S₂` with `S₁` and `S₂` lying in **distinct connected components of `G - {q}`**. Then the defect should decompose additively, with a universal correction term reflecting the gluing through the root.

This is the graph-theoretic analogue of:

- **Mayer–Vietoris** in algebraic topology,
- **Künneth-type additivity** for split complexes,
- **direct-sum decomposition of energies/obstructions** in statistical mechanics,
- **separability of tropical divisors** across disconnected regions.

If you prove the right formula, you open the door to a full decomposition calculus for defect invariants.

## Primary Breakthrough Theorem

First aim for the structurally strongest theorem, not merely the conjectural numerical identity.

### Theorem A: cycle-rank additivity on root-separated induced pieces
If `S₁` and `S₂` are root-separated, then the induced subgraph on `S₁ ∪ S₂` splits as a disjoint union of the induced subgraphs on `S₁` and `S₂`, so the first Betti number / cycle rank is additive:

```lean
theorem betaOne_union_of_rootSeparated
  {V : Type*} [Fintype V] [DecidableEq V]
  (G : SimpleGraph V) (q : V) (S₁ S₂ : Finset V)
  (hsep : RootSeparatedPieces G q S₁ S₂) :
  betaOne (G.induce ((↑(S₁ ∪ S₂)) : Set V)) =
    betaOne (G.induce ((↑S₁) : Set V)) +
    betaOne (G.induce ((↑S₂) : Set V))
```

If `betaOne` is not yet defined in the catalog, define the appropriate cycle-rank invariant via
`|E| - |V| + c`, or use the existing graph invariant underlying defect.

### Theorem B: root-component count additivity
Prove the root-separation complexity term is additive on root-separated unions:

## Proof Strategy Architecture

### Strategy A — Structural decomposition through induced subgraphs
**Most promising.**

1. Define `RootSeparatedPieces` so that it implies **no cross-edges** between `S₁` and `S₂`.
2. Prove the induced subgraph on `S₁ ∪ S₂` is isomorphic to the graph-theoretic disjoint sum of the induced graphs on `S₁` and `S₂`.
3. Deduce additivity of cycle rank / Betti number and then unfold defect.

Why this is strongest:
- It reveals the real mechanism, not just the numerical identity.
- It gives reusable lemmas for future decomposition theorems.
- It naturally generalizes to `n` pieces.

Expected tactics:
- `rcases` on separation hypotheses,
- extensionality on edges/adjacency,
- `calc` chains for cardinality identities,
- induction for the finite-family extension.

### Strategy B — Direct algebra on the defect formula
1. Expand `defect G q S` using its catalog definition.
2. Prove separately:
   - additive behavior of the cycle term,
   - additive behavior of `rootComponentCount`,
   - disjointness/cardinality lemmas for unions.
3. Reassemble with `ring`-style arithmetic if the target is in `ℤ`/`ℕ`.

Why this may work:
- Fastest path if the catalog already contains decomposition lemmas.
- Good for obtaining the first certified theorem.

Risk:
- Can obscure the conceptual reason and make generalization harder.

### Strategy C — Root deletion and component-indexing
1. Work in the graph `G' := deleteVerts G {q}` or the catalog’s equivalent.
2. Represent `S₁`, `S₂` by membership in distinct connected components of `G'`.
3. Use component-index uniqueness to force path/edge separation, then derive additivity.

Why this matters:
- Best route if Mathlib’s connectivity/component APIs are strong enough.
- Most canonical for later homological interpretation.

Risk:
- Component machinery may be technically heavy in Lean.

Recommendation:
Start with **Strategy B** to get a theorem quickly if the defect formula is already explicit, but develop **Strategy A** in the same file because it is the true breakthrough and the right foundation for generalization.
