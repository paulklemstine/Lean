### Step 1: Define the Berggren-induced lattice and Gram object

Use a rank-2 lattice first, since it is easiest to certify.

For a primitive triple `t = (a,b,c)` with `a^2 + b^2 = c^2`, define the basis vectors
- `v₁ = (a,b)`
- `v₂ = (b,c)`

and the Gram matrix
\[
\operatorname{Gram}(t) =
\begin{pmatrix}
a^2+b^2 & ab+bc \\
ab+bc & b^2+c^2
\end{pmatrix}.
\]

This is positive definite for primitive nondegenerate triples. Then define reduction-equivalence by equality up to `GL(2,ℤ)`-change of basis.

A stronger finite-path version should assign to a Berggren path `p` a cumulative invariant package:
- terminal triple,
- path matrix in the Berggren semigroup,
- Gram matrix,
- norm profile along the path,
- primitive congruence profile mod small integers.

## Primary Theorem A: Functorial Gram Transport

Formalize the Berggren generators as integer matrices acting on triples. If `M` is a Berggren generator and `t` a primitive triple, then the induced lattice basis transforms by an explicit integer matrix on the chosen lattice coordinates, and the Gram object transforms covariantly.

### Mathematical statement
There exists an induced map `Φ(M)` on lattice bases such that
\[
\operatorname{Gram}(M \cdot t) = \Phi(M)^{\mathsf T}\,\operatorname{Gram}(t)\,\Phi(M),
\]
for every Berggren generator `M`, and hence for every finite Berggren path by semigroup composition.

This is the first bridge theorem: Berggren composition acts as a **structured transport law for Gram data**.

```lean
theorem gram_functorial_of_berggren
  (M : BerggrenMatrix) (t : PrimitiveTriple) :
  tripleGram (M • t) = (basisTransport M)ᵀ * tripleGram t * (basisTransport M)
```

If matrix transposition notation becomes awkward in Mathlib, use the explicit `Matrix.mul_apply` form or package as matrix congruence:

## Primary Theorem B: Monotonicity of Norm / Successive-Minima Proxy Along Branches

Since full successive minima may be heavy to formalize initially, define a certified proxy:
- first basis norm,
- second basis norm,
- determinant,
- shortest basis-vector length in the chosen Berggren basis,
- optionally the minimum of norms over all vectors with coefficients in a bounded search box.

Prove monotonicity or eventual monotonicity along every nontrivial branch.

### Mathematical statement
For any Berggren child `t'` of a primitive triple `t`, the trace and determinant of the Gram matrix weakly increase:
\[
\operatorname{tr}(\operatorname{Gram}(t)) \le \operatorname{tr}(\operatorname{Gram}(t')), \qquad
\det(\operatorname{Gram}(t)) \le \det(\operatorname{Gram}(t')).
\]
Moreover, the squared norm of the shortest vector among the distinguished basis vectors is monotone:
\[
\min(\|v_1(t)\|^2,\|v_2(t)\|^2) \le \min(\|v_1(t')\|^2,\|v_2(t')\|^2).
\]

A stronger version would show branchwise convexity or submultiplicative growth for these invariants along paths.

### Lean 4 target signature
```lean
theorem gram_trace_mono_child
  (t : PrimitiveTriple) (g : BerggrenGenerator) :
  Matrix.trace (tripleGram t) ≤ Matrix.trace (tripleGram (g • t))

theorem gram_det_mono_child
  (t : PrimitiveTriple) (g : BerggrenGenerator) :
  (tripleGram t).det ≤ (tripleGram (g • t)).det

theorem distinguished_short_norm_mono_child
  (t : PrimitiveTriple) (g : BerggrenGenerator) :
  shortNormSq t ≤ shortNormSq (g • t)
```

If full monotonicity fails for your chosen basis, pivot immediately to a corrected invariant:
- sorted diagonal of Lagrange-reduced Gram form,
- trace plus off-diagonal absolute value,
- spectral radius,
- tropicalized valuation profile.

A counterexample-guided refinement is acceptable, but the final theorem must be exact.

## Primary Theorem C: Finite Recognition / Reduction-Equivalence Criterion

This is the heart of the program.

Define a finite invariant package for a Berggren path `p`:
- terminal Gram matrix,
- determinant,
- trace,
- primitive congruence data,
- path length,
- optional normalized path matrix modulo sign/permutation symmetries.

Then prove a recognition theorem: if two finite Berggren path segments have identical certified invariant package, then the associated lattices are reduction-equivalent; ideally, their reduced Gram normal forms coincide.

### Mathematical statement
There exists a finite invariant `I(p)` such that for Berggren paths `p,q`,
\[
I(p)=I(q) \implies \mathrm{RedEq}(L_p,L_q).
\]
A stronger version:
\[
I(p)=I(q) \implies \mathrm{ReducedGram}(L_p)=\mathrm{ReducedGram}(L_q).
\]

This is the formal finite-recognition theorem that turns Berggren dynamics into a reduction theory.

```lean
theorem invariant_complete_for_reduction_equiv
```

## Primary Theorem D: Certified Short-Basis Reconstruction

This is the flagship theorem. From finite transfer invariants, reconstruct a reduced basis up to a controlled equivalence.

### Mathematical statement
There exists an effectively computable reconstruction map `R` from finite invariant packages such that for every Berggren path `p`,
\[
R(I(p)) = B_p
\]
where `B_p` is a reduced basis for the associated lattice, unique up to sign changes and basis permutation, and satisfying a certified correctness theorem:
\[
\operatorname{Gram}(B_p) \sim \operatorname{Gram}(L_p).
\]

Even a rank-2 theorem would be field-opening if formalized cleanly.

## Proof Strategy Paths

### Strategy 1: Direct matrix-congruence route
**Most promising for Lean.**

1. Define the basis vectors explicitly and compute `tripleGram` by unfolding.
2. For each Berggren generator, derive the transformed basis and verify Gram congruence by matrix multiplication.
3. Build path-level results by induction on `BerggrenPath`.
4. Define a simple rank-2 reduced normal form, likely a Lagrange/Minkowski-style canonical Gram representative.
5. Show the invariant package determines this normal form, then define reconstruction from the normal form.

**Why this is promising:** it avoids deep geometry-of-numbers infrastructure and reduces the entire program to certified integer matrix identities plus a manageable canonical-form argument.

---

### Strategy 2: Binary quadratic form / `GL(2,ℤ)` classification route
1. Interpret each Gram matrix as a positive definite binary quadratic form.
2. Use reduction theory of binary forms: reduced forms are canonical representatives modulo `GL(2,ℤ)`.
3. Prove Berggren-induced forms remain in a controlled arithmetic family.
4. Show your path invariant determines the reduced quadratic form.
5. Extract the reduced basis from the reduced form.

**Why this is powerful:** it connects the theorem to classical Gauss reduction, making the result mathematically deeper and more canonical.  
**Why it may be harder in Lean:** unless the relevant quadratic form infrastructure already exists in the catalog, you may need to define too much from scratch.

---

### Strategy 3: Tropical / ordered semimodule compression route
1. Define a semimodule-valued Gram summary using ordered or tropicalized invariants: trace, determinant valuation, min-plus norm profile.
2. Prove Berggren composition acts monotonically on these summaries.
3. Show the summary is complete for reduced-basis reconstruction within the Berggren-generated family.
4. Recover reduced basis through a finite search bounded by these tropical certificates.

**Why this is visionary:** it upgrades ordinary Gram theory to a semimodule/tropical control mechanism, potentially connecting reduction to idempotent linear algebra.  
**Why it is riskier:** completeness of tropical summaries may require delicate family-specific arguments.

**Recommendation:** Start with Strategy 1, then layer Strategy 2 if canonical form is needed, and reserve Strategy 3 as the conceptual upgrade if the direct approach lands.
