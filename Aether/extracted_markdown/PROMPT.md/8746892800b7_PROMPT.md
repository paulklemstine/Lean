### Theorem 1: Monotonicity and eventual connectivity of the first-meeting filtration

Define for a finite path `x : Fin (T+1) → α` on a decidable finite type `α` the visited-set graph filtration:
- vertices = states appearing in the path,
- edge `{a,b}` appears by time `t` iff both `a` and `b` have appeared by time `t`.

This is a coarse but robust surrogate for the true first-meeting/transition filtration, and it already captures a connectivity phase transition.

#### Mathematical statement
For every path `x`, the filtration is monotone in `t`. If every visited vertex appears by time `t`, then the graph at level `t` is complete on the visited set, hence connected whenever at least two vertices have been visited.

A stronger version: if the trajectory is generated by a walk on a finite group and the support generates the subgroup `H`, then once all vertices in the trajectory-generated orbit segment have been seen, the associated flag complex is a simplex and all reduced homology vanishes.

#### Lean 4 type signature sketch
```lean
def visitedSet {α : Type*} [DecidableEq α] {T : ℕ} (x : Fin (T+1) → α) (t : Fin (T+1)) : Finset α := ...

def appearsBy {α : Type*} [DecidableEq α] {T : ℕ}
    (x : Fin (T+1) → α) (a : α) (t : Fin (T+1)) : Prop := a ∈ visitedSet x t

def meetEdge {α : Type*} [DecidableEq α] {T : ℕ}
    (x : Fin (T+1) → α) (t : Fin (T+1)) (a b : α) : Prop :=
  a ≠ b ∧ appearsBy x a t ∧ appearsBy x b t

theorem meetEdge_mono
    {α : Type*} [DecidableEq α] {T : ℕ}
    (x : Fin (T+1) → α) {s t : Fin (T+1)} (hst : s ≤ t) :
    ∀ {a b : α}, meetEdge x s a b → meetEdge x t a b := ...

theorem complete_graph_after_full_visit
    {α : Type*} [Fintype α] [DecidableEq α] {T : ℕ}
    (x : Fin (T+1) → α) (t : Fin (T+1))
    (hfull : ∀ a ∈ visitedSet x ⟨T, Nat.lt_succ_self T⟩, appearsBy x a t) :
    ∀ {a b : α}, a ∈ visitedSet x ⟨T, Nat.lt_succ_self T⟩ →
                 b ∈ visitedSet x ⟨T, Nat.lt_succ_self T⟩ →
                 a ≠ b → meetEdge x t a b := ...
```

#### Why this matters
This theorem isolates the deterministic mechanism behind barcode collapse: once the walk has “covered enough” of its effective state space, the filtration loses local memory and topological complexity rapidly dies. This is the skeleton of universality.

### Theorem 2: Diameter/cover-time control implies persistent-collapse bound

Introduce a new invariant:

```lean
def collapseTime {α : Type*} [DecidableEq α] {T : ℕ}
    (x : Fin (T+1) → α) : ℕ := ...
```

where `collapseTime x` is the least time by which every state ever visited by the trajectory has already appeared. Then prove deterministic bounds linking this to vanishing of 1-dimensional cycle proxies in the filtration.

#### Mathematical statement
Let `x` be a finite trajectory. For all `t ≥ collapseTime x`, the graph filtration on visited vertices is complete, hence every cycle is filled in the flag complex. In particular, any persistence interval corresponding to 1-dimensional homology must die by `collapseTime x`.

This gives a theorem of the form “cover-time controls barcode death time.”

#### Lean 4 type signature sketch
```lean
def collapseTime {α : Type*} [DecidableEq α] {T : ℕ}
    (x : Fin (T+1) → α) : ℕ := Nat.sInf {t | ∀ a ∈ visitedSet x ⟨T, Nat.lt_succ_self T⟩,
      ∃ ht : t ≤ T, appearsBy x a ⟨t, Nat.lt_of_lt_of_le (Nat.lt_succ_self _) ht⟩ }

theorem edge_complete_after_collapseTime
    {α : Type*} [Fintype α] [DecidableEq α] {T : ℕ}
    (x : Fin (T+1) → α) :
    ∀ {t : ℕ}, collapseTime x ≤ t → t ≤ T →
    ∀ {a b : α},
      a ∈ visitedSet x ⟨T, Nat.lt_succ_self T⟩ →
      b ∈ visitedSet x ⟨T, Nat.lt_succ_self T⟩ →
      a ≠ b →
      meetEdge x ⟨t, Nat.lt_of_lt_of_le (Nat.lt_succ_self _) ‹t ≤ T›⟩ a b := ...
```

You may also define a combinatorial surrogate of `H₁` such as “triangle-filled cycle rank defect” if full persistent homology is too heavy in Lean. The point is to prove a rigorous collapse theorem, not to handwave.

#### Why this matters
This theorem translates a probabilistic/mixing question into a topological one: prove cover-time concentration, and topological collapse follows. It is the formal bridge between random walk theory and persistence.

### Theorem 3: Group-equivariance and quotient invariance for modular walks

Now connect to arithmetic groups. Formalize a finite-group walk driven by a symmetric generating multiset, and prove that the filtration construction is equivariant under left multiplication. Thus persistence summaries depend only on the trajectory modulo relabeling of vertices.

#### Mathematical statement
Let `G` be a finite group, `x : Fin (T+1) → G` a trajectory, and `g ∈ G`. Define `g • x` by left multiplication. Then the meeting-time filtration of `g • x` is canonically isomorphic to that of `x`. Consequently, all isomorphism-invariant graph statistics and all persistence summaries of the associated flag filtration are unchanged.

This is the first rigorous indication that the observable is genuinely about the walk law on the group, not arbitrary labels.

#### Lean 4 type signature sketch
```lean
def leftTranslatePath {G : Type*} [Group G] {T : ℕ}
    (g : G) (x : Fin (T+1) → G) : Fin (T+1) → G := fun i => g * x i

theorem visitedSet_leftTranslate
    {G : Type*} [Group G] [DecidableEq G] {T : ℕ}
    (g : G) (x : Fin (T+1) → G) (t : Fin (T+1)) :
    visitedSet (leftTranslatePath g x) t = (visitedSet x t).image fun a => g * a := ...

theorem meetEdge_leftTranslate_iff
    {G : Type*} [Group G] [DecidableEq G] {T : ℕ}
    (g : G) (x : Fin (T+1) → G) (t : Fin (T+1)) (a b : G) :
    meetEdge (leftTranslatePath g x) t (g * a) (g * b) ↔ meetEdge x t a b := ...
```

#### Why this matters
Universality should be a class-function phenomenon. Equivariance is the minimal arithmetic symmetry theorem any serious theory must satisfy. It also prepares the route to reduction mod `p`, where one compares walks across different primes via ambient group structure rather than labels.

### Theorem 4: Spectral/combinatorial bridge — expansion forces rapid topological collapse

This is the bold cross-domain theorem. You may need to formulate and prove a deterministic finite-graph version rather than the full random walk statement.

#### Mathematical statement
Let `Γ` be a finite connected `d`-regular graph with spectral gap `1 - λ₂ > 0`. For a trajectory `x` of simple random walk on `Γ`, if the visited set at time `t` has cardinality at least `m`, then the meeting-time graph on visited vertices has edge density bounded below by a monotone function of `m`. Under a cover-time hypothesis derived from expansion, the filtration collapses by time `O(log |V|)`.

In Lean, you can formalize the deterministic implication:
- if a walk trajectory visits all vertices by time `t`,
- then the filtration is complete by time `t`,
and in `RESEARCH_PAPER.md` explain how standard expander cover-time bounds imply `t = O(log |G|)` for the conjectural arithmetic families.

A more ambitious formal theorem would relate a lower bound on visited-set growth to lower bounds on filtration edge density.

```lean
def edgeDensityLowerBound (n m : ℕ) : Rat := ((m : Rat) - 1) / (n : Rat)

theorem complete_after_full_cover_finite_group
    {G : Type*} [Fintype G] [Group G] [DecidableEq G] {T : ℕ}
    (x : Fin (T+1) → G)
    (hcover : ∀ g : G, g ∈ visitedSet x ⟨T, Nat.lt_succ_self T⟩) :
    ∀ {a b : G}, a ≠ b → meetEdge x ⟨T, Nat.lt_succ_self T⟩ a b := ...
```

#### Cross-domain significance

## Full Conjecture to State Clearly

### Universality Conjecture for modular matrix-product persistence
Let `μ` be a finitely supported probability measure on `SL₂(ℤ)` whose support generates a non-elementary subgroup. For each prime `p`, let `μ_p` be the reduction of `μ` to `SL₂(𝔽_p)`, and let `X₀, X₁, ..., X_T` be the corresponding random walk. Construct a filtered graph `G_p(T)` on visited vertices using first-appearance or transition-frequency weights, and let `K_p(T)` be its flag complex. Then there exists a constant `C = C(μ-support type)` and persistence summary statistics `S_p(T)` such that, for `T = c log p`:
1. if `c < C`, the law of `S_p(T)` depends on `μ`,
2. if `c > C`, the law of `S_p(T)` converges as `p → ∞` to a limit depending only on the family `SL₂(𝔽_p)` and not on `μ`.

A sharper version predicts `C` is governed by the spectral radius / entropy / Lyapunov data of the walk, and that normalized barcode landscapes converge to a universal profile.

### Testable prediction
For several finitely supported measures on `SL₂(ℤ)` with the same Zariski-dense support type but different weights:
- compute persistence summaries of the modular reduction walks,
- plot them against `T / log p`,
- observe collapse to a common curve near a critical constant.

Refutation:
- no collapse after normalization,
- limiting summaries remain measure-specific,
- or transition scale is not logarithmic in `p`.

## Proof Strategy Architecture

You must not give a one-line proof plan. Build multiple routes.

### Strategy A: Deterministic filtration theory first, probability second
1. Define visited-set, first-appearance, and meeting-time filtrations for arbitrary finite trajectories.
2. Prove monotonicity, equivariance, and collapse-after-cover theorems.
3. In the paper, import known cover-time / mixing heuristics for expanders and modular groups to argue why the collapse window should be logarithmic.

**Why promising:** Lean handles deterministic finite combinatorics very well; this creates a reusable library for future probabilistic theorems.

### Strategy B: Cayley-graph growth and product-set expansion
1. Model trajectories in finite groups generated by a finite symmetric set.
2. Relate early-time visited-set geometry to word balls / product growth.
3. Show that once product growth saturates, the filtration becomes dense and the clique complex loses low-dimensional homology.

**Why promising:** This connects directly to Helfgott/Breuillard-Green-Tao style growth in `SL₂(𝔽_p)` and explains why universality should emerge from arithmetic expansion, not from ad hoc TDA features.

### Strategy C: Spectral route via expander mixing
1. Formalize coarse graph-statistical invariants of the filtration.
2. Show these invariants become close to those of an Erdős–Rényi-like dense graph once the walk mixes.
3. Use this to motivate universality of persistence summaries above the mixing window.

**Why promising:** Most conceptually aligned with the conjecture.  
**Why less Lean-friendly initially:** full spectral random-walk machinery may exceed current formal convenience. Use this primarily in the paper and demo unless the catalog already contains the needed spectral graph infrastructure.

Most promising overall: **Strategy A first, then B in theorem statements, and C in computational/interpretive layers**.
