This is the most conceptually powerful route and likely the best if the catalog already contains a thermodynamic Gödel–Lawvere theorem.

1. **Assume** `h : ExactInternallyTruthfulKMSModel M beta`.
2. Use exact internal truthfulness to obtain a self-evaluation map that correctly reflects all internally expressible truth predicates.
3. Apply the existing **thermodynamic Gödel–Lawvere incompleteness theorem** to produce a diagonal sentence/observable whose self-evaluation forces a modular free-energy fixed point.
4. Show that the resulting fixed point is exact, not merely approximate, because the hypothesis is exact truthfulness.
5. Invoke the **free-energy no-self-compression theorem** (or its modular dual form) to contradict existence of such an exact fixed point at `0 < beta`.
