## Core Vision

The breakthrough is not “another primality fact.” The breakthrough is to **recast Miller–Rabin derandomization as a formal hitting-set theory**:

- each odd composite `n` induces a large witness set `W n ⊆ {2, …, B}`,
- a deterministic primality test up to bound `B` is equivalent to choosing a small set `H` intersecting every `W n`,
- the classical “at least 3/4 of bases are witnesses” becomes a **dense set-system theorem**,
- from that density one should derive small universal hitting sets, first existentially and then algorithmically.

This opens a new formal direction: **certified derandomization inside Lean**, where probabilistic algorithms are transformed into explicit finite combinatorial objects with correctness proofs and executable search procedures.

## Theorem 1: Dense Witness Sets Imply Small Hitting Sets

This is the conceptual center. Prove a finite-set-system theorem specialized to Miller–Rabin.

### Precise theorem statement
Let `U = {2, …, B}` and let `𝒲_B = { witnessSet B n | n odd composite, n ≤ B }`.  
Assume every member of `𝒲_B` has size at least `δ |U|` with fixed `0 < δ ≤ 1`. Then there exists a finite hitting set `H ⊆ U` with
`|H| ≤ ⌈(log |𝒲_B| + c)/(-log (1-δ))⌉`
for a suitable constant `c`, and in particular for Miller–Rabin with `δ = 3/4`,
`|H| = O(log B)` because `|𝒲_B| ≤ B`.

### Lean-oriented type signature
A clean finite-combinatorics formulation you can actually prove:

```lean
theorem exists_hittingSet_card_le_of_dense_subsets
  (U : Finset α) (F : Finset (Finset α)) (δ : ℚ)
  (hU : U.Nonempty)
  (hδ₀ : 0 < δ) (hδ₁ : δ ≤ 1)
  (hsub : ∀ S ∈ F, S ⊆ U)
  (hdense : ∀ S ∈ F, δ * U.card ≤ S.card)
  :
  ∃ H ⊆ U, (∀ S ∈ F, S ∈ F → (H ∩ S).Nonempty) ∧
    H.card ≤ Nat.ceil ((Rat.log (F.card + 1)) / (-Rat.log (1 - δ)))
```

If `Rat.log` is unavailable or awkward, replace the explicit analytic bound by a combinatorial recursive bound with powers:
there exists `k` such that `(1 - δ)^k * F.card < 1`, hence a hitting set of size `k`. This is often more Lean-friendly.

A more formalizable version:

```lean
theorem exists_hittingSet_of_dense_subsets
  (U : Finset α) (F : Finset (Finset α)) (k : ℕ)
  (hsub : ∀ S ∈ F, S ⊆ U)
  (hdense : ∀ S ∈ F, 4 * (U.card - S.card) ≤ U.card) -- density ≥ 3/4
  (hk : F.card * 4^k < 4^k.succ) :
  ∃ H ⊆ U, H.card ≤ k ∧ ∀ S ∈ F, S ∈ F → (H ∩ S).Nonempty
```

The exact inequality can be adjusted. What matters is a nontrivial finite theorem deriving small hitting sets from density.

### Why this is a breakthrough
This turns a folklore probabilistic argument into a certified **derandomization meta-theorem** in Lean. Once proved, it can be reused far beyond primality testing: any dense family of “good tests” admits a small deterministic test suite.

## Theorem 2: Miller–Rabin Witness Family Up To `B` Has a Small Hitting Set

Use the catalog liar bound to instantiate Theorem 1.

### Precise theorem statement
For every natural number `B ≥ 3`, there exists a finite set `H ⊆ {2, …, B}` such that
for every odd composite `n ≤ B`, some `a ∈ H` is a Miller–Rabin witness for `n`.
Moreover `|H| ≤ C log B` for an explicit constant `C` obtained from the witness-density bound.

### Lean 4 type signature
```lean
theorem exists_small_MR_hittingSet_up_to
  (B : ℕ) (hB : 3 ≤ B) :
  ∃ H : Finset ℕ,
    H ⊆ MRCandidateBases B ∧
    hitsAllOddCompositesUpTo B H ∧
    H.card ≤ C * Nat.ceil (Nat.log2 (B + 1))
```

If explicit constants are too painful, prove first:

```lean
theorem exists_MR_hittingSet_up_to
  (B : ℕ) (hB : 3 ≤ B) :
  ∃ H : Finset ℕ,
    H ⊆ MRCandidateBases B ∧
    hitsAllOddCompositesUpTo B H
```

Then strengthen to a cardinality bound using your dense-family theorem and the catalog witness lower bound. The strengthening is the real target.

### How to build on the catalog
If `liarTupleSet_card_le_pow'` gives an upper bound on liar tuples or liar-set cardinality, extract the contrapositive form:
for odd composite `n`, the number of non-witnesses among candidate bases is at most `|U| / 4`, hence the witness set has density at least `3/4`.
This is exactly the input needed for Theorem 1.

## Theorem 3: Greedy Set-Cover Bound for Witness Families

This theorem is the algorithmic engine and the cross-domain bridge to approximation algorithms.

### Precise theorem statement
Let `F` be a finite family of subsets of a finite universe `U`. Suppose every set in `F` has size at least `δ|U|`. Then the greedy algorithm that repeatedly chooses the element covering the largest number of remaining sets terminates after at most `O((log |F|)/δ)` steps with a hitting set.

Specialize to the Miller–Rabin witness family to obtain a certified deterministic search algorithm for witness bases up to `B`.

### Lean 4 type signature
You may formalize a one-step potential drop theorem rather than the full asymptotic statement:

```lean
def uncoveredBy (H : Finset α) (F : Finset (Finset α)) : Finset (Finset α) :=
  F.filter (fun S => Disjoint H S)

theorem exists_base_covering_fraction_of_uncovered
  (U : Finset α) (F : Finset (Finset α))
  (hsub : ∀ S ∈ F, S ⊆ U)
  (hdense : ∀ S ∈ F, δ * U.card ≤ S.card) :
  ∃ a ∈ U, 
    ((uncoveredBy {a} F).card : ℚ) ≤ (1 - δ) * F.card
```

Then iterate this theorem:

```lean
theorem greedy_hittingSet_card_bound
  (U : Finset α) (F : Finset (Finset α)) :
  ∃ H ⊆ U, H.card ≤ k ∧
    uncoveredBy H F = ∅
```

with `k` satisfying the appropriate shrinkage inequality.

### Why this matters
This is no longer merely existential. It yields a **verified algorithm** extracting deterministic Miller–Rabin bases by a principled finite optimization method. That is a publishable formal-methods contribution in its own right.

## Proof Strategy Architecture

### Strategy A: Probabilistic method → finite derandomization theorem
1. Define the family `F_B` of witness sets `witnessSet B n` for odd composite `n ≤ B`.
2. Use `liarTupleSet_card_le_pow'` to prove each `witnessSet B n` has density at least `3/4` inside `MRCandidateBases B`.
3. Sample `k` bases independently in the classical argument: the probability a fixed witness set is missed is at most `(1/4)^k`.
4. Union bound over all odd composite `n ≤ B`; choose `k` with `|F_B| * (1/4)^k < 1`.
5. Convert “positive probability” into existence of a finite hitting set.

**Why promising:** mathematically clean, closest to the conjectural philosophy, and directly exploits the catalog theorem.

### Strategy B: Averaging / greedy cover without probability
1. For the uncovered family `F`, count incidences `(a, S)` with `a ∈ S`.
2. Since every `S` has size at least `3|U|/4`, total incidences are at least `(3/4)|U||F|`.
3. Hence some `a ∈ U` lies in at least `(3/4)|F|` sets.
4. Add such an `a` to the hitting set; uncovered sets shrink by factor at most `1/4`.
5. Iterate to obtain a hitting set of size `O(log |F|)`.

**Why promising:** this is likely the most Lean-friendly path. It avoids real logarithms and measure-theoretic probability entirely, replacing them with double counting and induction on the number of uncovered sets.

### Strategy C: Hypergraph transversal framework
1. Package witness families as dense hypergraphs.
2. Prove a transversal-number bound for dense hypergraphs.
3. Instantiate with Miller–Rabin.

**Why promising:** most conceptual and best for future reuse, though heavier formal overhead. Good if you want a foundational result beyond primality.

**Recommendation:** pursue **Strategy B first**, then recover the probabilistic interpretation in `RESEARCH_PAPER.md`. In Lean, a finite averaging + induction proof will be more robust than analytic logarithm machinery.
