## Max-Plus Hecke Algebras and the Idempotent Satake Isomorphism: Formalizing Tropical Langlands Foundations

### I. FOUNDATIONAL DEFINITIONS — The Idempotent Spectral Universe

**Definition 1: PrimeCongruence.** A congruence `P : Con R` on a commutative idempotent semiring `R` is *prime* when the quotient `R ⧸ P` is a cancellative idempotent semifield — equivalently, `∀ a b : R, (a * b, 0) ∈ P → (a, 0) ∈ P ∨ (b, 0) ∈ P`. This is the idempotent analogue of a prime ideal; the zero element replaces one because `0` is the "top" of the idempotent order.

```lean
structure PrimeCongruence (R : Type*) [CommSemiring R] extends Con R where
  prime : ∀ a b : R, (a * b, 0) ∈ toCon → (a, 0) ∈ toCon ∨ (b, 0) ∈ toCon
  cancel : ∀ a b c : R, (a + c, b + c) ∈ toCon → (a, b) ∈ toCon
```

**Definition 2: SpecIdempotent.** The prime congruence spectrum, the idempotent Zariski site:

```lean
def SpecIdempotent (R : Type*) [CommSemiring R] : Type* :=
  PrimeCongruence R
```

Equip `SpecIdempotent R` with the specialization preorder: `P ≤ Q ↔ Q ⊆ P` (reverse inclusion, mirroring the classical Zariski topology where smaller primes are "generic points").

**Definition 3: MaxPlusHeckeOperator.** For a prime congruence `P` on `R`, define the sup-convolution on bounded functions `f : SpecIdempotent R → Tropical ℝ≥0`:

```lean
noncomputable def maxPlusHeckeOperator {R : Type*} [CommSemiring R] 
    (P : PrimeCongruence R) 
    (f : SpecIdempotent R → Tropical ℝ≥0) 
    (Q : SpecIdempotent R) : Tropical ℝ≥0 :=
  sSup <| Set.range fun R_val : {R : SpecIdempotent R // (R.1 ⊔ Q.1 : Con R) ⊇ P.1} => 
    f R_val.1
```

This is a *max-plus convolution*: supremum replaces summation, congruence join `⊔` replaces multiplication. The operator `T_P` averages `f` over all primes `R` whose join with `Q` dominates `P` — the tropical shadow of averaging over double cosets.

**Definition 4: CoprimeCongruences.** Two prime congruences `P, Q` are *coprime* when their join `P ⊔ Q` is again prime. This is the idempotent analogue of coprime ideals:


**Definition 5: MaxPlusHeckeAlgebra.** The Hecke algebra `H(R)` is the subalgebra of `End` (bounded functions on `SpecIdempotent R`) generated by all `T_P`:

```lean

  carrier : Set (SpecIdempotent R → Tropical ℝ≥0 →ₛ[Tropical.addMonoidAlgebra] SpecIdempotent R → Tropical ℝ≥0)
```

**Definition 6: SphericalFunction.** A bounded function `f : SpecIdempotent R → Tropical ℝ≥0` is *spherical* when it is invariant under the action of the tropical Weyl group — the automorphism group of the congruence lattice:
