## Theorem 1: Covariance decay along an expander walk

This is the mathematical heart. You want a theorem saying that for a mean-zero observable, correlations along the walk decay exponentially at a rate governed by the contraction constant.

### Mathematical statement

Let `T` be the averaging operator of a regular expander on a finite state space `V`, preserving the uniform measure. Let `g : V → ℝ` satisfy `E[g] = 0`. If for all mean-zero `h`,
\[
\|Th\|_2 \le \rho \|h\|_2 \qquad \text{with } 0 \le \rho < 1,
\]
then for a stationary walk `(X_t)` driven by `T`,
\[
\left| \mathbb{E}[g(X_0)g(X_t)] \right| \le \rho^t \, \|g\|_2^2.
\]

This converts spectral contraction into a quantitative correlation bound.

### Lean 4 target signature sketch

```lean
theorem covariance_decay_of_L2_contraction
  {V : Type*} [Fintype V] [DecidableEq V]
  (T : (V → ℝ) → (V → ℝ))
  (ρ : ℝ)
  (hT_preserve_mean : ∀ f, IsUniformMeanPreserving T f)
  (hT_contract :
    ∀ g, UniformMean g = 0 → l2Norm (T g) ≤ ρ * l2Norm g)
  (hρ : 0 ≤ ρ ∧ ρ < 1)
  (g : V → ℝ)
  (hg0 : UniformMean g = 0) :
  ∀ t : ℕ,
    |uniformCovariance g (iterateLinear T t g)| ≤ (ρ ^ t) * (l2Norm g)^2
```

You may need to adapt names (`UniformMean`, `l2Norm`, `uniformCovariance`, `iterateLinear`) to the catalog’s actual API. If the existing infrastructure is phrased using inner products, an even better statement is:

```lean
theorem inner_le_pow_smul_norm_sq
  ...
  : ∀ t : ℕ, |⟪g, (T^[t]) g⟫| ≤ (ρ ^ t) * ‖g‖^2
```

### Why this is a breakthrough

This theorem is the formal hinge between spectral graph theory and derandomization. Once certified, it becomes a reusable engine for every “expander walk replaces independence” argument in complexity theory.

### Proof strategies

**Strategy A: Hilbert-space iteration via mean-zero contraction**  
1. Show by induction that `‖(T^[t]) g‖₂ ≤ ρ^t ‖g‖₂` for mean-zero `g`.  
2. Express covariance as an inner product `⟪g, (T^[t]) g⟫`.  
3. Apply Cauchy–Schwarz and the iterative contraction bound.  
**Most promising** if `SpectralGap.lean` already has linear-operator style lemmas.

**Strategy B: Orthogonal decomposition into constants + mean-zero space**  
1. Decompose any observable into mean plus fluctuation.  
2. Use preservation of constants and contraction on the orthogonal complement.  
3. Derive the correlation estimate from the fluctuation part.  
Best if the catalog already exposes `mean_zero` subspaces or projection lemmas.

**Strategy C: Spectral theorem / eigenbasis for symmetric averaging operators**  
1. Diagonalize `T` on `ℝ^V`.  
2. Expand `g` in an eigenbasis.  
3. Bound each eigencomponent by `ρ^t`.  
Conceptually beautiful, but likely heavier in Lean unless the finite-dimensional spectral theorem is already convenient.

## Theorem 2: Variance bound for the empirical mean of walk samples

Once covariance decay is available, prove that the empirical average of correlated samples still concentrates enough for amplification.

### Mathematical statement

Let `f : V → {0,1}` or `f : V → ℝ` with `0 ≤ f ≤ 1`, and define
\[
\bar f_k := \frac1k \sum_{i=0}^{k-1} f(X_i),
\qquad \mu := \mathbb E[f].
\]
Then under stationarity and the covariance decay bound,
\[
\mathrm{Var}(\bar f_k)
\le \frac{C(\rho)}{k}\,\mathrm{Var}(f),
\]
where one may take
\[
C(\rho) = 1 + 2\sum_{t\ge 1}\rho^t = \frac{1+\rho}{1-\rho}.
\]
A finite-sum version is even better:
\[
\mathrm{Var}(\bar f_k)
\le \frac{\mathrm{Var}(f)}{k^2}
\left(k + 2\sum_{t=1}^{k-1}(k-t)\rho^t\right).
\]

This theorem is stronger and cleaner than jumping directly to majority error. It is the exact bridge from operator theory to algorithmic amplification.

### Lean 4 target signature sketch

```lean
theorem variance_empiricalMean_le_geometric
  {V : Type*} [Fintype V] [DecidableEq V]
  (W : ExpanderAmplifier V)
  (f : V → ℝ)
  (hf01 : ∀ v, 0 ≤ f v ∧ f v ≤ 1) :
  ∀ k : ℕ, 1 ≤ k →
    empiricalVariance W f k ≤
      ((uniformVariance f) / (k : ℝ)^2) *
        ((k : ℝ) + 2 * ∑ t in Finset.Icc 1 (k - 1), ((k - t : ℕ) : ℝ) * (W.ρ ^ t))
```

And then derive the closed form:

```lean
theorem variance_empiricalMean_le_closedForm
  ...
  : ∀ k : ℕ, 1 ≤ k →
      empiricalVariance W f k ≤
        uniformVariance f * ((1 + W.ρ) / (1 - W.ρ)) / k
```

Again, adapt exact names.

### Why this is a breakthrough

This is the certified finite-sample theorem complexity theorists actually need. It says correlated samples generated with tiny randomness overhead still achieve `1/k` variance decay up to a spectral constant. That is a formalized derandomization primitive.

### Proof strategies

**Strategy A: Expand the variance as a double sum**  
1. Write `Var(Σ_i Y_i)` as `Σ_i Var(Y_i) + 2 Σ_{i<j} Cov(Y_i,Y_j)`.  
2. Use stationarity to rewrite `Cov(Y_i,Y_j)` as a function of lag `j-i`.  
3. Plug in Theorem 1 and sum the geometric series.  
This is the cleanest and should use `calc` chains heavily.

**Strategy B: Operator-theoretic proof using the Green kernel / resolvent flavor**  
1. Regard the empirical average as applying a polynomial in `T` to `f`.  
2. Bound the resulting `L²` norm by controlling the polynomial on `[−ρ,ρ]`.  
3. Extract variance from `L²`.  
More conceptual, and potentially useful later for weighted samplers.

**Strategy C: Martingale decomposition**  
1. Decompose the walk observable into a predictable part plus innovation.  
2. Bound variance by orthogonality plus contraction.  
3. Recover the same asymptotic constant.  
Potentially elegant, but likely too infrastructure-heavy for this cycle.

## Theorem 3: Majority vote error bound for biased Boolean functions

This is the algorithmic headline theorem.

### Mathematical statement

Let `f : V → Bool` or `f : V → ℝ` with values in `{0,1}`, and suppose
\[
\mu := \mathbb E[f] \ge \frac12 + \delta
\qquad (\delta > 0).
\]
Let `X_0,\dots,X_{k-1}` be a stationary expander walk, and let
\[
M_k := \mathbf{1}\left[\sum_{i=0}^{k-1} f(X_i) > k/2\right].
\]
Then
\[
\Pr[M_k = 0]
\le \frac{\mathrm{Var}(\bar f_k)}{\delta^2}
\le \frac{1}{4\delta^2}\cdot \frac{1+\rho}{1-\rho}\cdot \frac1k,
\]
and therefore for
\[
k \ge \frac{1+\rho}{1-\rho}\cdot \frac{1}{4\delta^2\varepsilon},
\]
the majority vote error is at most `ε`.

This gives a polynomial-in-`1/δ` and linear-in-`1/ε` amplification theorem from second-moment methods alone. If you can strengthen to an exponential tail under stronger assumptions, excellent — but the variance/Chebyshev theorem is already substantial and directly supported by current machinery.

### Lean 4 target signature sketch

```lean
theorem majority_error_le_of_bias
  {V : Type*} [Fintype V] [DecidableEq V]
  (W : ExpanderAmplifier V)
  (f : V → ℝ)
  (hf01 : ∀ v, f v = 0 ∨ f v = 1)
  (δ ε : ℝ)
  (hδ : 0 < δ)
  (hμ : (1/2 : ℝ) + δ ≤ UniformMean f)
  (hε : 0 < ε)
  (k : ℕ)
  (hk :
    ((1 + W.ρ) / (1 - W.ρ)) / (4 * δ^2 * ε) ≤ k) :
  majorityError W f k ≤ ε
```

A more implementable version may phrase the threshold condition after coercing `k` to `ℝ`.

### Why this is a breakthrough

This theorem turns an abstract spectral gap into a **certified error-amplification protocol**. It is a machine-checked analogue of a core derandomization principle in complexity theory: one can recycle randomness without losing the ability to amplify correctness.

### Proof strategies

**Strategy A: Bias gap + Chebyshev**  
1. Observe that majority failure implies `\bar f_k ≤ 1/2`, hence `|\bar f_k - μ| ≥ δ`.  
2. Apply Chebyshev using Theorem 2.  
3. Rearrange to obtain the `k` sufficient condition.  
This is the most realistic path for a complete Lean formalization this cycle.

**Strategy B: One-sided Cantelli inequality**  
1. Replace Chebyshev with Cantelli for a sharper one-sided bound.  
2. Use the same variance estimate.  
3. Derive a slightly stronger sample complexity constant.  
Good if probability inequalities are already available in Mathlib.

**Strategy C: Exponential moments via bounded observables**  
1. Bound the mgf of the walk average using spectral methods.  
2. Derive a Chernoff-style tail.  
3. Obtain `k = O(log(1/ε)/(1-ρ))`.  
This would be field-opening, but only attempt if the operator and measure infrastructure cooperates. Otherwise state it as the next conjectural frontier.

## Theorem 4: Random-bit complexity of the expander-walk amplifier

This is your cross-domain theorem connecting algebraic expansion to computational complexity.

### Mathematical statement

For a `d`-regular Cayley expander on `S_n`, a walk of length `k` can be sampled using:
- `O(log |S_n|) = O(n log n)` random bits to choose the initial state uniformly,
- plus `k · O(log d)` random bits to choose one of the `d` generators at each step.

Therefore the majority amplifier uses
\[
O(n\log n + k\log d)
\]
random bits.

For the concrete generating set on `S_5`, this should be made exact.

### Lean 4 target signature sketch

```lean
theorem randomBits_expanderWalkSampler
  (n d k : ℕ) :
  randomBitCostExpanderWalk n d k ≤ C * (n * Nat.log2 (n + 1) + k * Nat.log2 (d + 1))
```

or, if you want a cleaner exact theorem for the finite concrete sampler:

```lean
theorem randomBits_cayleySampler_S5
  (k : ℕ) :
  randomBitCostS5 k ≤ initBitsS5 + k * stepBitsS5
```

You may need to define `randomBitCost...` as a verified accounting function rather than a probabilistic object. That is perfectly acceptable and mathematically meaningful.

### Why this matters

This is where the mathematics touches complexity theory directly. The point is not merely concentration; it is **concentration under randomness constraints**. That is the essence of derandomization.

### Proof strategies

**Strategy A: Counting-based encoding argument**  
1. Count the number of possible initial states and transitions.  
2. Use binary encoding lengths.  
3. Prove the total bit bound by arithmetic inequalities.

**Strategy B: Explicit sampler semantics**  
1. Define a sampler that consumes a bitstream.  
2. Prove soundness of decoding into initial state and generator choices.  
3. Bound consumed bits structurally by recursion on walk length.
