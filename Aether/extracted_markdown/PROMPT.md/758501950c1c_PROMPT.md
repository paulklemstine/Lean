### Theorem 1: Positive local cycle pressure from global cycle surplus

This theorem turns global graph density into a local hardness signal.

**Mathematical statement.**  
Let `G` be a finite connected simple graph. If the cycle rank of `G` is positive, then there exists a vertex whose local cycle pressure is positive. If the cycle rank is at least `k > 0`, then some connected region carries cycle surplus at least `1`, and in a suitable localized definition this yields a witness vertex of nonzero pressure.

A Lean-friendly version:

```lean
theorem exists_vertex_positive_lcp
    {α : Type _} [Fintype α] [DecidableEq α]
    (G : SimpleGraph α)
    (hconn : G.Connected)
    (hcyc : 0 < graphCycleRank G) :
    ∃ x : α, 0 < localCyclePressure G x
```

If your `localCyclePressure` is defined as component cycle rank, this theorem should be strengthened to a nontrivial localization statement rather than becoming tautological. For example, define `localCyclePressure G x` using an induced neighborhood subgraph of radius `r = 1` or `2`.

**Why this matters.**  
This is the first bridge from catalog-level cycle-rank theorems to theorem-wise difficulty predictors.

### Theorem 2: Monotone pressure implies nonnegative Spearman-type rank correlation

This is the conceptual heart. You do not need to formalize asymptotic statistics in full generality; a finite deterministic rank theorem is enough.

**Mathematical statement.**  
For a finite type `α`, if `h` is monotone in `L`, then the rank covariance between `L` and `h` is nonnegative. If the monotonicity is strict on at least two distinct pressure levels, then the rank covariance is strictly positive unless one function is constant on all but one rank class.

A Lean-friendly finite-order version:

```lean
theorem spearman_nonneg_of_monotone
    {α : Type _} [Fintype α] [DecidableEq α] [LinearOrder α]
    (L h : α → ℕ)
    (hmono : ∀ ⦃x y : α⦄, L x ≤ L y → h x ≤ h y) :
    0 ≤ spearmanScore L h
```

If `spearmanScore` is too heavy to formalize directly, define a mathematically equivalent finite statistic via pairwise concordance:

```lean
def pairwiseOrderScore {α : Type _} [Fintype α] [DecidableEq α]
    (L h : α → ℕ) : ℤ := ...
```

and prove

```lean
theorem pairwiseOrderScore_nonneg_of_monotone
    {α : Type _} [Fintype α] [DecidableEq α]
    (L h : α → ℕ)
    (hmono : ∀ ⦃x y : α⦄, L x ≤ L y → h x ≤ h y) :
    0 ≤ pairwiseOrderScore L h
```

Then explain in `RESEARCH_PAPER.md` that this is a finite Spearman/Kendall surrogate sufficient for the scientific claim.

**Why this is a breakthrough.**  
This theorem isolates the exact mathematical mechanism by which topological pressure can force positive rank correlation with proof difficulty. It transforms an empirical conjecture into a theorem schema.

**Cross-domain connection.**

### Theorem 3: Cluster separation creates a hardness barrier

Use graph separation to prove a theorem about impossibility of uniformly high pressure.

**Mathematical statement.**  
If a semantic threshold graph splits into well-separated clusters, then any theorem in a tree-like or acyclic cluster has zero local cycle pressure, hence any pressure-monotone hardness model predicts a hardness gap between cyclic and acyclic regions.

Lean-friendly theorem:

```lean
theorem zero_lcp_on_acyclic_component
    {α : Type _} [Fintype α] [DecidableEq α]
    (G : SimpleGraph α) (x : α)
    (hacyc : graphCycleRank (inducedComponentSubgraph G x) = 0) :
    localCyclePressure G x = 0
```

and then a consequence:

```lean
theorem hardness_gap_of_pressure_gap
    {α : Type _} [Fintype α] [DecidableEq α]
    (M : HardnessModel α)
    {x y : α}
    (hx : M.pressure x = 0)
    (hy : 0 < M.pressure y) :
    M.hardness x ≤ M.hardness y
```

**Why this matters.**  
This turns topological separation into a concrete hardness stratification theorem. It suggests a practical theorem-library decomposition into easy and hard zones.

**Catalog build blocks.**
- `disconnected_of_cluster_separation`

Use it to justify graph decomposition at threshold choices where semantic clusters become disconnected.

## Proof Strategy Architecture

You must include 2–3 serious proof pathways and choose the most promising.

### Strategy A: Graph-theoretic localization via cycle-rank decomposition
1. Define `localCyclePressure G x` using induced radius-1 or component-local subgraphs.
2. Use catalog cycle-rank positivity theorems to obtain global cycle witnesses.
3. Push witness cycles into local neighborhoods/components via `rcases` on a cycle certificate and conclude positivity of local pressure.

**Why promising:**  
This directly leverages existing catalog graph-topology results and should produce nontrivial Lean proofs using `rcases`, induction on finite subgraphs, and multi-step `calc`.

---

### Strategy B: Pairwise concordance theorem instead of full Spearman formalization
1. Define a finite pairwise order score counting concordant minus discordant pairs.
2. Prove nonnegativity under monotonicity by partitioning pairs according to pressure order.
3. Show this score is a Spearman/Kendall surrogate sufficient for the scientific interpretation.

**Why most promising:**  
Formalizing exact Spearman correlation with tie corrections may be unnecessarily heavy. A pairwise order score is mathematically cleaner in Lean, still deep, and captures the rank-monotonicity phenomenon sharply.

Expect to use:
- finite sums over `Finset.univ.product`,
- `by_contra`,
- sign decomposition,
- antisymmetry and order case splits,
- careful integer/rational coercion.

---

### Strategy C: Separation-to-hardness via cluster decomposition
1. Use `disconnected_of_cluster_separation` to create graph components.
2. Prove acyclic components have zero local pressure.
3. Combine with a monotone hardness model to derive hardness inequalities between components.

**Why valuable:**  
This gives the first theorem explaining *where* hard theorems live: near cyclic semantic cores rather than separated tree-like peripheries.
