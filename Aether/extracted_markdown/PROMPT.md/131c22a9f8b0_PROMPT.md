**Title**: Closure capacities as submodular energies on finite closure systems
**Domain**: Bridges
**Mathematical framing**: Work in a finite type `α` with a closure operator `cl : Set α → Set α` formalized via `SetClosureOperator` or `FiniteClosureSystem`. Define `IsClosed s := cl s = s`. Introduce a capacity `μ : Set α → ℝ` (or `ℚ`) satisfying monotonicity `A ⊆ B → μ A ≤ μ B`, normalization `μ ∅ = 0`, and closure invariance `μ (cl A) = μ A`. Main target 1: prove that the induced functional `E` on closed sets given by `E(C) = μ C` is monotone on the lattice of closed sets. Main target 2: under a submodularity assumption on `μ` over arbitrary sets, prove `E(C) + E(D) ≥ E(cl (C ∩ D)) + E(cl (C ∪ D))`; since `C,D` are closed this simplifies to a submodular law on the closed-set lattice. Main target 3: using `ProbeFamily` and `ClosureStableProbe`, prove a reconstruction theorem: if every closed set is the intersection of probe-detected supersets and `μ` is generated by probe weights, then `E` is uniquely determined by finitely many probe values. Main target 4: package the result as an optimization pipeline on finite closure systems, showing minimizers exist and are stable under intersection when the closed-set family is closed under finite meets. These statements are precise, falsifiable, and should lean on finite-set lattice reasoning rather than speculative semantics.
**Concept description**: The key insight is that the existing closure-system infrastructure can be pushed one step further to produce a genuine bridge theorem: every finite closure system equipped with a monotone closure capacity should induce a submodular energy on closed sets, with explicit inequalities that make optimization and reconstruction possible. Why now: the catalog already contains the exact primitives needed on the EML/closure side — `FiniteClosureSystem`, `ClosurePotential`, `ClosureKernel`, `SetClosureOperator`, and `ClosureSemimoduleSystem` — while a closely adjacent speculative target about closure capacities remains open, indicating both tractability and unmet demand. Concretely, define from a closure operator `cl` on a finite type and a monotone capacity `μ` on subsets a restricted functional on closed sets, then prove order-monotonicity and a diminishing-returns inequality of the form `μ(A) + μ(B) ≥ μ(cl (A ∩ B)) + μ(cl (A ∪ B))` under a natural closure-compatibility hypothesis. A second theorem should show that if `μ` is determined by values on a probe family stable under closure, then the energy on all closed sets is reconstructible from those probe values. This would create a new bridge from algebraic/EML closure formalisms to computation-ready optimization principles, without repeating the in-flight tropical closure-capacity project because the ambient objects here are general finite closure systems rather than tropical semimodules.
