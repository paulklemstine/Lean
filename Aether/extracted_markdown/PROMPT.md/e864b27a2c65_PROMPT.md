## Precise theorem statements with Lean 4 target signatures

### Theorem 1: β-soundness of denotational semantics
```lean
theorem denote_beta
  {Γ : Ctx} {σ τ : HOType}
  (body : HOTerm (Γ ▻ σ) τ) (arg : HOTerm Γ σ) :
  denote (app (lam body) arg) =
    denote (subst0 arg body)
```

**Meaning:** β-reduction preserves denotation in the standard set-theoretic model.

This theorem is foundational: it lets β live inside `EqvGen` without breaking semantic soundness.

## Proof architecture: 3 viable strategies

## Strategy A: Intrinsically typed de Bruijn syntax + direct denotational induction
**Most promising.**

### Step 1
Define intrinsically typed terms:
- variables indexed by context membership,
- `lam`, `app`,
- renaming and substitution operations.

This avoids α-equivalence headaches entirely by construction.

### Step 2
Define denotational semantics into standard set-theoretic types:
- base types interpreted as Lean types,
- arrow types as functions,
- contexts as dependent products / environments.

Prove renaming/substitution lemmas:
- weakening preserves denotation,
- substitution commutes with denotation.

### Step 3
Define `HOEqvGen R` inductively with constructors for:
- refl/symm/trans,
- congruence under `app` and `lam`,
- β,
- η,
- user axioms `R`.

Then prove semantic preservation by induction on the derivation.

**Why this is strongest:** it localizes all binder complexity into renaming/substitution lemmas and gives a structurally clean induction principle. It is the best route for a robust Lean formalization.

---

## Strategy B: Quotient by α-equivalence + named variables + semantic invariance
### Step 1
Use a named-variable syntax and define α-equivalence explicitly.

### Step 2
Show semantics respects α-equivalence, then define β/η modulo α.

### Step 3
Build the higher-order e-graph semantics on α-classes.

**Why it is less promising:** mathematically elegant, but in Lean this often explodes into transport and quotient-management overhead. Use only if the catalog already contains strong α-equivalence infrastructure.

---

## Strategy C: Categorical semantics first, extraction theorem second
### Step 1
Formalize simply-typed λ-calculus semantics in a cartesian closed category fragment or as the free CCC semantics into `Type`.

### Step 2
Interpret β and η as coherence equalities of the CCC structure.

### Step 3
Derive extraction soundness as functorial invariance of e-graph quotienting.

**Why this is scientifically exciting:** it reveals equality saturation as a semantic quotient construction in categorical logic.  
**Why it is risky:** much heavier formal overhead. This is ideal for the `RESEARCH_PAPER.md`, but probably not the fastest route to the core Lean theorem.
