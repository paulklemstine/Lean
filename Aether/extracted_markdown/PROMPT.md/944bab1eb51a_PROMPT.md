## Precise Theorem Target

Let `X`, `Y`, and `Seed` be finite types. Let `cl : Set X → Set X` be a finitary closure operator. Let `M_cl` be a finitely generated idempotent semimodule over an idempotent semiring `S`, generated by indicators of principal dependency sets `cl {x}` and pairwise dependency sets `cl {x,y}`. Define, for finite `A ⊆ X`,

- deficiency: `δ(A) = card (cl A) - card A`,
- entropy surrogate: `h(A) = card X - δ(A)`.

For a family `F = (f_s : X → Y)_{s ∈ Seed}`, define **closure-separation at threshold `k`** to mean:

> for every `A ⊆ X` with `h(A) ≥ k`, and for every distinct `y₁ ≠ y₂` in `Y`, there exists `s : Seed` and a closure-stable semimodule functional `φ : M_cl →ₛₗ[S] B` (for a finite idempotent target semimodule `B`, or concretely an ordered idempotent scalar target if this is easier to formalize first) such that the induced evaluations on the pullback fibers of `f_s` distinguish `y₁` and `y₂` over `A`.

The main equivalence should be formalized in a finite/computable form:

### Main Bridge Theorem
A finite seed-indexed family of maps with entropy loss at most `e` exists **iff** there exists a finite basis of closure-stable dependency functionals whose evaluation matrix has closure-rank defect at most `e` and separates all `k`-large closed sets.

You should formalize this in a Lean-friendly version where “closure-rank defect” is defined combinatorially via finite matrices over a decidable codomain, or via a cardinal defect between the number of basis functionals and the maximal number of closure-independent columns they separate.

A strong formal target is:

```lean
theorem closureExtractor_duality
  {X Y Seed S : Type*}
  [Fintype X] [DecidableEq X]
  [Fintype Y] [DecidableEq Y]
  [Fintype Seed] [DecidableEq Seed]
  [CanonicallyOrderedCommSemiring S] [IdempotentSemiring S]
  (cl : Set X → Set X)
  (hcl_ext : ∀ A, A ⊆ cl A)
  (hcl_mono : ∀ {A B : Set X}, A ⊆ B → cl A ⊆ cl B)
  (hcl_idem : ∀ A, cl (cl A) ⊆ cl A)
  (k e : ℕ) :
  (∃ (f : Seed → X → Y),
      ClosureSeparating cl f k ∧
      EntropyLossBound cl f e) ↔
  (∃ (ι : Type*) (_ : Fintype ι) (_ : DecidableEq ι)
      (Φ : ι → ClosureStableFunctional cl S X),
      SeparatesLargeClosedSets cl Φ k ∧
      ClosureRankDefect cl Φ ≤ e)
```

You will almost certainly want a computable finite variant first, where `ι = Fin n` and `ClosureStableFunctional` is encoded concretely as a function on a finite generating family satisfying invariance under closure equivalence.

Then prove a **certified reconstruction theorem**:

```lean

  {X Y S : Type*}
  [Fintype X] [DecidableEq X]
  [Fintype Y] [DecidableEq Y]
  [CanonicallyOrderedCommSemiring S] [IdempotentSemiring S]
```

If the full biconditional is too large for one pass, prove it in three layers:

1. `functionals → extractor`,
2. `extractor → functionals`,

## Lean 4 Type Signature Guidance

You should introduce explicit finite structures rather than overly abstract category-level interfaces. The most robust route is to define:

```lean
structure IsClosureOperator {X : Type*} (cl : Set X → Set X) : Prop :=
  (extensive : ∀ A, A ⊆ cl A)
  (monotone : ∀ ⦃A B⦄, A ⊆ B → cl A ⊆ cl B)
  (idempotent : ∀ A, cl (cl A) = cl A)
```

Then define:

```lean
def deficiency {X : Type*} [Fintype X] [DecidableEq X]
  (cl : Set X → Set X) (A : Finset X) : ℕ :=
  (cl (A : Set X)).toFinite.toFinset.card - A.card

def entropySurrogate {X : Type*} [Fintype X] [DecidableEq X]
  (cl : Set X → Set X) (A : Finset X) : ℕ :=
  Fintype.card X - deficiency cl A
```

For closure-stable functionals, start with a finite encoding:

```lean
structure ClosureStableFunctional
  (X S : Type*) [Fintype X] [DecidableEq X] [CanonicallyOrderedCommSemiring S]
  (cl : Set X → Set X) where
  toFun : Finset X → S
  stable : ∀ A B : Finset X, cl (A : Set X) = cl (B : Set X) → toFun A = toFun B
  monotone_closed :
    ∀ A B : Finset X, cl (A : Set X) ⊆ cl (B : Set X) → toFun A ≤ toFun B
```

Then define separation:

```lean
def ClosureSeparating
  {X Y Seed S : Type*}
  [Fintype X] [DecidableEq X]
  [Fintype Y] [DecidableEq Y]
  [Fintype Seed] [DecidableEq Seed]
  [CanonicallyOrderedCommSemiring S]
  (cl : Set X → Set X)
  (f : Seed → X → Y) (k : ℕ) : Prop := ...
```

A practical Lean theorem may use **closed sets only** instead of all subsets, since the statement is morally closure-invariant anyway:

## 2–3 Proof Strategy Paths

### Strategy A: Finite separation duality via closure-normal forms
**Most promising.**

1. **Pass to closure-normal representatives.** Replace arbitrary subsets by closed subsets `C` with `cl C = C`. Show all relevant notions (`deficiency`, entropy surrogate, separation) factor through closure equivalence.
2. **Construct the evaluation matrix.** From a seed family `f : Seed → X → Y`, define columns indexed by large closed sets and rows indexed by seed/fiber tests or derived closure-stable functionals. Prove that failure of separation is exactly column collision modulo closure.
3. **Prove equivalence by finite compactness.** In the forward direction, extract a finite separating family of functionals from the seed family. In the reverse direction, use the finite evaluation matrix to define output coordinates and seeds by coding row-patterns, then prove entropy-loss/rank-defect correspondence.

Why this is promising: it reduces the theorem to finite combinatorics and decidable extensionality over `Fintype`, which Lean handles well. It also avoids deep semimodule infrastructure at the start; the idempotent-semimodule interpretation can then be layered on top as meaning, not burden.

### Strategy B: Idempotent semimodule representation theorem
1. **Build `M_cl` from generators** corresponding to principal and pairwise closure dependencies.
2. **Define closure-stable functionals as semimodule morphisms** out of `M_cl` that coequalize closure-equivalent generators.
3. **Use a finite presentation / quotient universal property** to prove that separating families of functionals correspond to matrix factorizations through the presented semimodule, and reconstruct seeds from basis coordinates.

Why it matters: this gives the theorem its true algebraic soul. If successful, it turns extractor reconstruction into a representation theorem in idempotent linear algebra. Harder in Lean, but more revolutionary.

### Strategy C: Greedy reconstruction and certificate extraction
1. **Define a greedy rank-defect minimization algorithm** over finite candidate functionals derived from closure generators.
2. **Show greedy-selected rows preserve separation** of `k`-large closed sets whenever a separating matrix of defect `≤ e` exists.
3. **Compile the selected rows into explicit seeds** and prove the certified reconstruction theorem.

Why this is valuable: it converts existence into synthesis. Even if the full algebraic biconditional is difficult, a formalized reconstruction theorem with correctness guarantees would already be a major contribution and create a practical certified extractor-search pipeline.

Recommended order: **A → C → B**. First establish the finite duality in closure-normal combinatorial form, then prove algorithmic reconstruction, then lift/interpret via semimodule presentations.

- Keep everything finite and computable.

- Start with a combinatorial notion of “functional” if full semimodule morphisms are too heavy initially.
- Introduce the semimodule presentation after the finite theorem is stable.

  - number of rows minus maximal separating subfamily,

  - or a cardinality defect of image patterns.
