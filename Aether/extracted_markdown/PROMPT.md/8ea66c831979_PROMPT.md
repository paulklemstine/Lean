## Core Formal Target

Define a concrete model of a layered tropical circuit by a square matrix `M : Matrix (Fin n) (Fin n) ℕ`, where `M i j` is the cost of propagating information from gate `i` to gate `j` across one layer. The tropical path cost of length `k` is encoded by min-plus powers of `M`. The key invariant is the least cycle mean / tropical spectral value together with a gap condition.

You should formalize at least one theorem of the following form.

### Theorem A: Tropical path-cost lower bound on circuit depth

For a circuit matrix `M`, if every path from an input set `S` to an output node `t` of length `< d` has tropical cost strictly larger than `B`, while there exists a path of length `d` with cost `≤ B`, then every circuit realizing the corresponding propagation relation has depth at least `d`.

This is the combinatorial anchor theorem. It converts tropical path geometry into a genuine lower bound.

A Lean-oriented statement could be:

```lean
theorem depth_lower_bound_of_tropical_path_cost
  {n d B : ℕ}
  (M : Matrix (Fin n) (Fin n) ℕ)
  (S : Finset (Fin n)) (t : Fin n)
  (hshort :
    ∀ k < d, ∀ s ∈ S,
      B < tropicalPathCost M k s t)
  (hexists :
    ∃ s ∈ S, tropicalPathCost M d s t ≤ B) :
  circuitDepthLB M S t d
```

Here `tropicalPathCost M k s t` and `circuitDepthLB M S t d` will need definitions. This is worth doing: it creates the formal language in which all later theorems live.

### Theorem B: Min-plus permanent lower-bounds layered depth

The most credible formal breakthrough from your prompt is not an immediate super-polynomial lower bound in unrestricted circuit complexity, but a theorem showing that the min-plus permanent of a circuit interaction matrix gives an obstruction to shallow realizations.

A robust theorem statement is:

> If `permₜ(M)` is large relative to the maximal edge weight budget per layer, then any layered realization of `M` must have depth at least `⌈permₜ(M) / W⌉`.

Here `permₜ(M)` is the min over permutations `σ` of `∑ i, M i (σ i)`.

A Lean type signature:

```lean
def tropicalPerm {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ) : ℕ := ...

def layerWeightCap {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ) : ℕ := ...

def layeredCircuitDepth {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ) : ℕ := ...

theorem tropicalPerm_le_depth_mul_cap
  {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ) :
  tropicalPerm M ≤ layeredCircuitDepth M * layerWeightCap M
```

and hence the corollary

```lean
theorem depth_ge_of_tropicalPerm
  {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ)
  (hcap : 0 < layerWeightCap M) :
  (tropicalPerm M + layerWeightCap M - 1) / layerWeightCap M ≤ layeredCircuitDepth M
```

This is a true lower-bound theorem with quantitative content.

### Theorem C: Spectral-gap amplification forces depth growth

To bring in “tropical spectral theory” honestly, define a notion of tropical spectral value `λₜ(M)` and a gap witness saying that all non-optimal cycles have average weight at least `λₜ(M) + g`. Then prove that the gap stabilizes path optimization and forces a linear-in-length cost growth away from the optimal cycle structure. This yields lower bounds on how quickly a shallow circuit can realize low-cost propagation patterns.

A possible formal statement:

```lean
def tropicalSpectralValue {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ) : ℚ := ...
def tropicalSpectralGap {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ) : ℚ := ...

theorem path_cost_growth_of_spectral_gap
  {n : ℕ} (M : Matrix (Fin n) (Fin n) ℕ)
  (hg : 0 < tropicalSpectralGap M) :
  ∃ C : ℚ, ∀ k : ℕ, C + k * tropicalSpectralValue M ≤ minEntry (tropicalPow M k)
```

Then derive a depth lower bound by comparing this with a target matrix family whose required propagation cost grows slower than shallow depth permits.

This theorem is deeper and may require more setup, but it is the theorem that makes the entire program intellectually distinctive.

## Proof strategy architecture

### Strategy 1: Direct combinatorial path semantics
Most promising for the first formal breakthrough.

Step 1:
Define tropical matrix multiplication and prove by induction on `k` that `(tropicalPow M k) i j` equals the minimum cost of a length-`k` path from `i` to `j`. This is where `tropical_bridge_path_cost` should enter decisively.

Step 2:
Define layered circuit depth semantically: depth `≤ d` means every required input-output dependency is realizable by a path of length at most `d`. Then prove the contrapositive: if all paths of length `< d` exceed the budget but some path of length `d` meets it, depth cannot be `< d`.

Step 3:
Define `tropicalPerm` and show each layer can decrease the assignment obstruction by at most `layerWeightCap M`. Summing over layers yields `tropicalPerm M ≤ depth * cap`.

Why this is promising:
It uses only finite combinatorics, matrices over `ℕ`, and induction. It is realistic in Lean and already nontrivial.

### Strategy 2: Subadditive / Fekete-style spectral route
Most conceptually powerful, likely harder.

Step 1:
Define `a_k = minEntry (tropicalPow M k)` and prove subadditivity:
`a_(k + ℓ) ≤ a_k + a_ℓ`.

Step 2:
Use a finite-model substitute for Fekete’s lemma or an explicit cycle decomposition argument to define the asymptotic mean `λₜ(M)` and identify it with a minimum cycle mean.

Step 3:
Prove that a positive spectral gap implies quantitative stabilization of optimal paths, then convert this into lower bounds on the depth required to reach certain target costs.

Why this matters:
This is the theorem family that makes the work look like genuine “tropical spectral complexity” rather than only graph combinatorics.

### Strategy 3: Assignment-duality / permanent obstruction
Best for quantitative lower bounds.

Step 1:
Define tropical permanent via `Finset.univ.permutations` or a permutation subtype. Prove basic bounds: monotonicity, invariance under relabeling, and lower bounds from diagonal witnesses.

Step 2:
Show that one layer contributes at most `layerWeightCap M` to the assignment cost accumulated across any realization. This is an amortized invariant argument.

Step 3:
Conclude the depth lower bound by telescoping over layers. Then instantiate on explicit matrix families whose tropical permanent grows as `Ω(n log n)` or `Ω(n^2)`.

Why this is exciting:
It resembles communication/circuit lower bounds via rank, except in the tropical world. That analogy alone is field-opening.
