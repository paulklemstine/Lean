## Precise Theorem Targets

You will likely need to introduce new types and intermediate definitions. Use concrete combinatorial structures whenever possible: finite crossing sets, smoothing states as `Finset`-indexed assignments, Laurent polynomials represented either through Mathlib support or a custom finitely supported exponent map into `ℤ`.

### 1. Kauffman bracket state sum

Define a type of unoriented link diagrams `LinkDiagram`. For a diagram `D`, let `crossings D : Finset ι` for some finite crossing index type, and let a state be a map assigning an `A`- or `B`-smoothing to each crossing.

Define:
- `numA : State D → ℕ`
- `numB : State D → ℕ`
- `loops : State D → ℕ`

Then define the bracket:
\[
\langle D\rangle = \sum_{s} A^{\#A(s)-\#B(s)}(-A^2-A^{-2})^{\ell(s)-1}.
\]

A Lean-oriented target signature could be:

```lean
def LinkDiagram : Type

def State (D : LinkDiagram) : Type

def bracket : LinkDiagram → LaurentPolynomial ℤ
```

or, if Laurent polynomials are implemented via finitely supported integer exponents:

```lean
def LaurentPoly := AddMonoidAlgebra ℤ ℤ

def bracket : LinkDiagram → LaurentPoly
```

Key theorem:

```lean
theorem bracket_reidemeister_II_invariant :
  ∀ {D₁ D₂ : LinkDiagram}, ReidemeisterII D₁ D₂ → bracket D₁ = bracket D₂

theorem bracket_reidemeister_III_invariant :
  ∀ {D₁ D₂ : LinkDiagram}, ReidemeisterIII D₁ D₂ → bracket D₁ = bracket D₂
```

### 2. Normalization by writhe and Jones invariance

For oriented diagrams define writhe `writhe : OrientedLinkDiagram → ℤ`, and normalized Jones polynomial
\[
V_D(t) = (-A)^{-3w(D)} \langle D \rangle,\qquad t = A^{-4}.
\]

Lean target:

```lean
def OrientedLinkDiagram : Type
def forgetOrientation : OrientedLinkDiagram → LinkDiagram
def writhe : OrientedLinkDiagram → ℤ
def jones : OrientedLinkDiagram → LaurentPolynomial ℤ

theorem jones_reidemeister_invariant :
  ∀ {D₁ D₂ : OrientedLinkDiagram},
    ReidemeisterEquivalent D₁ D₂ → jones D₁ = jones D₂
```

A stronger decomposition is preferable:

```lean
theorem jones_RI_invariant :
  ∀ {D₁ D₂ : OrientedLinkDiagram}, ReidemeisterI D₁ D₂ → jones D₁ = jones D₂

theorem jones_RII_invariant :
  ∀ {D₁ D₂ : OrientedLinkDiagram}, ReidemeisterII D₁ D₂ → jones D₁ = jones D₂

theorem jones_RIII_invariant :
  ∀ {D₁ D₂ : OrientedLinkDiagram}, ReidemeisterIII D₁ D₂ → jones D₁ = jones D₂
```

### 4. Detection of the unknot for alternating knots

This is the deepest theorem in the brief. You may formalize a tractable version first using reduced alternating diagrams and span/adequacy arguments.

Mathematical target:
> If `K` is an alternating knot and `V_K = 1`, then `K` is the unknot.

A formal statement may require a diagram-level theorem first:

```lean
def Alternating : OrientedLinkDiagram → Prop
def Reduced : OrientedLinkDiagram → Prop
def RepresentsUnknot : OrientedLinkDiagram → Prop

theorem alternating_reduced_jones_span_positive :
  ∀ {D : OrientedLinkDiagram},
    Alternating D → Reduced D → crossingNumber D > 0 →
    jonesSpan D > 0
```

and then derive:

```lean
theorem jones_detects_unknot_for_alternating :
  ∀ {D : OrientedLinkDiagram},
    Alternating D →
    jones D = 1 →
    RepresentsUnknot D
```

A more realistic route is:
1. prove nontrivial span for reduced alternating nontrivial diagrams,
2. prove unknot admits Jones polynomial `1`,
3. conclude detection inside the alternating class.

## Proof Architecture: 3 Viable Strategies

### Strategy A: Pure state-sum local rewrite proof
Most direct and probably best for the foundational invariance theorems.

1. **Define diagrams combinatorially with explicit local replacement operations.**
   Encode Reidemeister moves as local transformations on a finite planar crossing graph or a more combinatorial tangle interface type.
2. **Prove bracket identities by partitioning states.**
   For Reidemeister II and III, classify states by smoothing choices on the local patch and show exact termwise cancellation/matching.
3. **Add writhe correction for RI.**
   Show bracket changes by a monomial factor under Reidemeister I, then prove normalization cancels this exactly.

Why promising: it mirrors textbook proofs and minimizes dependence on deep topology. It is algebraic, local, and Lean-friendly.

### Strategy B: Skein-characterization uniqueness
Conceptually stronger and better for extensibility to other invariants.

1. Define the bracket/Jones polynomial abstractly as the unique invariant satisfying:
   - skein relation,
   - value on unknot,
   - multiplicativity under disjoint union / normalization under writhe.
2. Prove existence from the state sum.
3. Prove invariance by showing Reidemeister moves preserve the defining relations.

Why promising: once formalized, this gives a reusable universal property. It sets up future work on HOMFLY-PT, Alexander, and categorified invariants.

### Strategy C: Temperley–Lieb / braid closure route
Most visionary; potentially harder, but opens quantum algebra.

1. Encode braids and their closure.
2. Define the Jones polynomial via the Temperley–Lieb representation and Markov trace.
3. Prove agreement with the Kauffman bracket on braid closures and use this to compute torus knots efficiently.

Why promising: this is the route toward quantum groups and topological quantum computation. Best as a second phase after Strategy A secures the state-sum base.

**Recommendation:** Start with **Strategy A** for core correctness, then layer **Strategy B** for abstraction. Reserve **Strategy C** for the torus knot family and future expansion.

## Cross-Domain Connections You Must Exploit

### 1. Statistical mechanics / partition functions
The Kauffman bracket is a state sum. Treat it as a rigorously certified partition function over smoothing configurations. This suggests:
- using finite-state summation machinery,
- importing ideas from spin models,
- proving positivity/support/span bounds by combinatorial energy arguments.

This is where the catalog theorem `recognizable_and` may inspire a finite-state encoding of local constraints on smoothing states. Even if not directly used, the conceptual bridge is strong: knot diagrams as finite combinatorial systems with local admissibility and global evaluation.

### 2. Automata and MSO definability
A link diagram or braid word can be viewed as a finite word/graph with local rewrite semantics. There is a tantalizing bridge between:
- regular/recognizable combinatorial encodings,
- state-sum evaluation,
- certified invariants as automaton-weighted sums.

This could eventually connect Jones computation on bounded-width families to automata-theoretic algorithms.

### 3. Quantum algebra / topological quantum computation
The Jones polynomial is the shadow of braid group representations and modular tensor categories. Formalizing it through the Kauffman bracket lays the groundwork for:
- Temperley–Lieb category,
- Markov traces,
- unitary braid representations,
- certified anyonic gate semantics.

### 4. Complexity theory
Exact Jones evaluation is computationally deep. A formal combinatorial implementation creates a platform for proving:
- tractable subclasses,
- #P-hardness reductions externally mirrored by certified computations internally,
- parameterized algorithms for bounded crossing number or bounded braid index.
