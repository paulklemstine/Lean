## Proof architecture

### Strategy A: finite matrix Perron theory via cycle means and subadditivity
This is the most promising route.

1. **Define tropical matrix powers and path semantics.**  
   Prove that `(tropicalMatPow M k) i j` equals the maximum weight of a directed path of length `k` from `j` to `i`.  
   Target lemmas:
   ```lean
   theorem tropicalMatPow_one ...
   theorem tropicalMatPow_succ ...
   theorem tropicalMatPow_eq_max_path_weight ...
   ```
   This is the bridge from algebra to combinatorics.

2. **Prove upper and lower bounds from cycle decomposition.**  
   Any long path decomposes into a simple path plus cycles. This yields:
   - upper bound: no path can beat `k * maxCycleMean M + C`
   - lower bound: irreducibility gives access to a critical cycle, hence some entries achieve `k * maxCycleMean M - C`
   
   The key finite combinatorial lemma is:
   ```lean
   theorem path_weight_le_length_mul_maxCycleMean_add_const ...
   ```
   together with a realization lemma using a critical cycle:
   ```lean
   theorem exists_paths_achieving_asymptotic_slope ...
   ```

3. **Extract the eigenvector from normalized powers.**  
   Fix a base node `j₀`. Consider
   ```lean
   v_k i := (tropicalMatPow M k) i j₀ - k * maxCycleMean M
   ```
   Use the bounded-defect estimate to show this family is bounded modulo additive normalization; then choose a maximizing subsequence on the finite-dimensional coordinate space. In Lean, avoid full compactness if painful: derive the eigenvector from critical graph potentials instead.

4. **Critical graph potential method.**  
   Define `v i` as the maximal weight of a path from a chosen critical node to `i`, after subtracting `λ` per edge. Show:
   ```lean
   ∀ i, maxPlusMul' M v i ≤ λ + v i
   ```
   and use irreducibility plus criticality to upgrade to equality. This is often easier to formalize than a topological limit argument.

5. **Transfer from matrix eigenvector to EML eigencharacter.**  
   If `T (gens i)` is encoded by coefficients `P.coeff i j`, define the character on the tropical span by sending a tropical linear combination to the corresponding max over `v j + coefficient_j`. Then verify:
   ```lean
   χ (T a) = λ + χ a
   ```
   first on generators, then extend by tropical linearity.

### Strategy C: Karp dynamic programming as the central engine
Define path DP values
```lean
dp k i := max weight of a path of length k ending at i
```
Prove Karp’s formula:
```lean
maxCycleMean M = max_i min_{0 ≤ k < n} ((dp n i - dp k i) / (n - k))
```
This route gives the executable theorem almost for free and then yields asymptotic growth. It is algorithmically powerful and highly aligned with the computational side of the project. If you can make one theorem both spectral and executable, this is it.
