## Assignment: Direction 3 — Compression Obstruction Predicts Formula Depth Better Than Raw KW Size

**Mode:** prove

You are to turn the current compression-to-KW-depth pipeline into a genuinely sharper theory: not merely “large witness sets imply depth,” but “structured incompressibility predicts formula depth more faithfully than raw witness count.” The scientific goal is to isolate a new invariant of monotone Boolean functions — a **compression obstruction** — and prove that it lower-bounds monotone formula depth in a way that tracks true depth substantially better than naive Karchmer–Wigderson witness cardinality.

This should not be a lightweight empirical note. It should be a mathematically serious bridge between **compression theory, communication complexity, entropy/information, and monotone formula complexity**.

The conjectural picture is that for natural monotone functions, the hard part of computing the function is not just the number of KW witnesses, but the **failure of those witnesses to admit short uniquely decodable descriptions compatible with the monotone protocol structure**. If this is right, then compression/entropy methods become a primary lower-bound technology for formula depth.

Your task is to formalize and prove nontrivial theorems that make this precise.

## New Mathematical Object You Must Introduce

Define at least one genuinely new concept. The recommended choice is:

### `WitnessCompressionProfile`
A structure assigning to each code-length budget `ℓ : ℕ` the proportion or count of KW witnesses that can be encoded by a monotone-compatible compressor of length at most `ℓ`.

Suggested Lean-facing shape:

```lean
structure WitnessCompressionProfile (α β : Type _) where
  witnessSet : Finset α
  codeSet    : ℕ → Finset β
  enc        : α → β
  dec        : β → Option α
  sound      : ∀ a, dec (enc a) = some a
  bounded    : ∀ ℓ, {a ∈ witnessSet | enc a ∈ codeSet ℓ}.Finite
```

If this exact structure is awkward, define a more Lean-natural variant using finite types / `Fintype` / `Finset`. What matters is the mathematics: a profile measuring **how many witnesses survive under short encodings**.

From this define a scalar invariant, e.g.

### `compressionObstruction`
For a finite witness family `W`, define the least `k` such that there exists an injective encoding of all witnesses into bitstrings of length `k` satisfying whatever monotone/KW compatibility constraints are formalizable. If no such map exists below `k`, that gap is the obstruction.

Possible Lean signature skeleton:

```lean
def compressionObstruction
  {W C : Type _} [Fintype W] [Fintype C] : ℕ := ...
```

or, if you work directly with finite witness sets,

```lean
def compressionObstructionFinset
  (W : Finset α) : ℕ := ...
```

A more ambitious and better version is a **relative obstruction**:

```lean
def admissibleCodeLength
  (W : Finset α) (P : (α → Bool) → Prop) : ℕ := ...
```

where `P` encodes monotone/KW admissibility of the decoder.

This is the novel mathematical heart of the project.

## Proof Strategy Architecture

You must not provide a one-line proof path. Develop at least 2–3 approaches and choose the most promising.

### Strategy A: Counting + injectivity + admissibility refinement
1. Define admissible codes and the compression obstruction as a minimum feasible code length.
2. Use `no_injective_compression` and `incompressible_strings_lower_bound` to derive the base counting obstruction.
3. Lift the existing theorem `kw_compression_implies_depth_lower_bound` by showing any monotone formula of depth `d` induces an admissible code of length `d`.
4. Conclude `compressionObstruction ≤ depth`, hence the lower bound.

**Why promising:** This reuses the current catalog most directly and is the best route to a fully verified theorem with minimal new infrastructure.

---

### Strategy B: Prefix-free / uniquely decodable codes via Kraft-type obstruction
1. Restrict admissible witness encodings to a prefix-free or uniquely decodable family.
2. Prove a finite Kraft inequality in Lean for codeword lengths.
3. Show that balanced witness families force larger minimal maximum length than raw cardinality predicts.
4. Transport this obstruction through the KW correspondence to formula depth.

**Why promising:** This is the cleanest route to a strict-gap theorem. It gives a mathematically classical reason the new obstruction exceeds `log₂ |W|`.

**Why deeper than Strategy A:** It produces genuinely richer structure, not just a repackaged counting argument.

---

### Strategy C: Entropy / average-case protocol depth
1. Define a finite distribution on KW witnesses.
2. Show any admissible code/protocol has expected length bounded below by witness entropy or a combinatorial entropy surrogate.
3. Relate expected protocol length to worst-case formula depth.
4. Deduce that “spread-out” witness geometry implies depth lower bounds stronger than witness cardinality alone.

**Why revolutionary:** This opens a path from **Shannon-style lower bounds** to **monotone formula complexity**, potentially enabling average-case-to-worst-case transfers.

**Risk:** More infrastructure may be needed than is currently in Mathlib/catalog.
