## Theorem 1: Spectral-gap-to-total-variation certified mixing bound

Formalize a theorem that turns the catalog L² contraction theorem into an explicit total variation upper bound for a finite reversible walk.

### Mathematical statement

Let `P` be a reversible Markov kernel on a finite state space `α`, with stationary distribution `π`, and spectral gap `gap > 0`. Then for every starting state `x` and time `t`,
\[
\|P^t(x,\cdot)-\pi\|_{\mathrm{TV}}
\;\le\;
\frac12 \sqrt{\frac{1-\pi(x)}{\pi(x)}}\,(1-\mathrm{gap})^t.
\]
In the uniform case `π(x)=1/|α|`, this gives
\[
\|P^t(x,\cdot)-\pi\|_{\mathrm{TV}}
\;\le\;
\frac12 \sqrt{|α|-1}\,(1-\mathrm{gap})^t,
\]
hence
\[
t_{\mathrm{mix}}(\varepsilon)
\;\le\;
\left\lceil \frac{\log\!\big(\sqrt{|α|-1}/(2\varepsilon)\big)}{-\log(1-\mathrm{gap})} \right\rceil.
\]

### Lean 4 target signature

A plausible target, adapted to available infrastructure, is:

```lean
theorem tv_le_half_sqrt_card_mul_gap_decay
  {α : Type*} [Fintype α] [DecidableEq α]
  (P : α → α → ℝ)
  (hrev : IsReversibleUniform P)
  (hmarkov : IsMarkovKernel P)
  (hgap : 0 < spectralGap P) :
  ∀ x t,
    totalVariationDist (stepDist P t x) (uniformDist α)
      ≤ (1 / 2 : ℝ) * Real.sqrt (Fintype.card α - 1) *
          (1 - spectralGap P) ^ t
```

and then

```lean
theorem mixingTime_le_spectral_gap_bound
  {α : Type*} [Fintype α] [DecidableEq α]
  (P : α → α → ℝ)
  (hrev : IsReversibleUniform P)
  (hmarkov : IsMarkovKernel P)
  (hgap : 0 < spectralGap P) :
  ∀ ε > 0,
    mixingTimeTV P ε ≤
      Nat.ceil
        (Real.log (Real.sqrt (Fintype.card α - 1) / (2 * ε)) /
          (-Real.log (1 - spectralGap P)))
```

### Why this is a breakthrough

This theorem is the **certified translation layer** from algebraic expansion to probabilistic mixing guarantees. It upgrades spectral-gap infrastructure from a static property into an **algorithmically actionable theorem**: given a certified gap, one obtains a certified mixing-time bound. This is exactly the sort of theorem that makes formal spectral theory scientifically useful.

### Proof strategy options

**Strategy A: L² contraction + Cauchy–Schwarz + density comparison**  
Most promising.
1. Express `P^t(x, ·) - π` as a mean-zero function relative to `π`.
2. Apply the catalog L² contraction theorem to obtain exponential decay in L².
3. Convert L² distance to total variation by Cauchy–Schwarz:
   \[
   \|μ-π\|_{TV} \le \frac12 \|dμ/dπ - 1\|_{L²(π)}.
   \]
4. Compute the initial L² norm for a point mass at `x` under uniform `π`.

**Strategy B: Variance decomposition route**  
1. Encode the density of the time-`t` law relative to stationarity.
2. Use variance decay from the catalog rather than direct operator norm contraction.
3. Rewrite total variation via the centered density and finish with `sqrt(Var)` bounds.

**Strategy C: Spectral expansion over eigenfunctions**  
1. Decompose the delta mass in an orthogonal eigenbasis.
2. Bound each mode by `(1-gap)^t`.
3. Sum in L² and convert to TV.  
This is elegant but likely heavier in Lean unless the spectral decomposition is already available.

## Theorem 2: Certified mixing bound for the Cayley walk on `S_n`

Now specialize Theorem 1 to the concrete generating set from the catalog:
- adjacent transpositions,
- plus a long cycle.

The exact random walk should be the lazy or symmetric walk supported on this generating set, depending on what the catalog already defines. Be explicit.

### Mathematical statement

Let `P_n` be the symmetric random walk on `S_n` generated by the set
\[
S_n = \{(1\,2),(2\,3),\dots,(n-1\,n), (1\,2\,\dots\,n), (1\,2\,\dots\,n)^{-1}\}
\]
or the catalog’s equivalent symmetrized generating set. Then for every `n ≥ 2`, every `ε ∈ (0,1)`,
\[
t_{\mathrm{mix}}^{(n)}(\varepsilon)
\le
\left\lceil
\frac{\log\!\big(\sqrt{n!-1}/(2\varepsilon)\big)}{-\log(1-\mathrm{gap}(P_n))}
\right\rceil.
\]
If the catalog contains a lower bound `gap(P_n) ≥ c / n²`, derive
\[
t_{\mathrm{mix}}^{(n)}(\varepsilon)
\le
C\, n^2 \big(\log(n!) + \log(1/\varepsilon)\big),
\]
and hence
\[
t_{\mathrm{mix}}^{(n)}(\varepsilon) = O(n^3 \log n)
\]
unconditionally from that gap lower bound, with the possibility of sharpening to `O(n² log n)` if the stronger gap estimate is available.

### Lean 4 target signature

```lean
theorem symmetricGroup_mixTime_le_from_gap
  (n : ℕ) (hn : 2 ≤ n) :
  ∀ ε > 0,
    mixingTimeTV (adjTranspositionLongCycleWalk n) ε ≤
      Nat.ceil
        (Real.log (Real.sqrt (Nat.factorial n - 1) / (2 * ε)) /
          (-Real.log (1 - spectralGap (adjTranspositionLongCycleWalk n))))
```

and, if available:

```lean
theorem symmetricGroup_mixTime_le_cn2_log_factorial
  (n : ℕ) (hn : 2 ≤ n)
  (hgap : c / (n^2 : ℝ) ≤ spectralGap (adjTranspositionLongCycleWalk n)) :
  ∀ ε > 0,
    mixingTimeTV (adjTranspositionLongCycleWalk n) ε ≤
      Nat.ceil (C * (n^2 : ℝ) * (Real.log (Nat.factorial n) + Real.log (1 / ε)))
```

### Why this matters

This is the first nontrivial certified mixing theorem for a concrete nonabelian family in your environment. It transforms `S_n` from a combinatorial object with a gap theorem into a **verified sampler with explicit runtime guarantees**.

### Proof strategy options

**Strategy A: direct specialization of Theorem 1**  
Most efficient.
1. Show the walk is reversible with respect to uniform measure on `S_n`.
2. Show the state space cardinality is `n!`.
3. Plug into Theorem 1.

**Strategy B: Cayley-graph regularity + catalog expander theorem**
1. Use that symmetric generating sets induce regular reversible kernels.
2. Pull the gap lower bound from `Pythagorean/CayleyExpander/SpectralGap.lean`.
3. Combine with the TV theorem.

**Strategy C: path comparison / conductance-inspired estimate**
1. If direct gap infrastructure is awkward, derive a weaker but explicit bound using conductance or canonical paths.
2. Then upgrade to mixing via standard inequalities.  
Less likely to be shortest in Lean, but scientifically valuable if the spectral path stalls.

## Theorem 3: Observable-based lower bound on total variation

You need at least one theorem going in the opposite direction: a **certified obstruction to early mixing**.

### Mathematical statement

Let `f : α → ℝ` be a bounded observable with `π(f)=0`. Suppose
\[
\left| \mathbb E_x[f(X_t)] \right| \ge a_t
\quad\text{and}\quad
\mathrm{Var}_\pi(f)\le \sigma^2.
\]
Then
\[
\| \mathcal L_x(X_t) - \pi \|_{\mathrm{TV}}
\ge
\frac{a_t^2}{2(\sigma^2 + a_t^2)}
\]
or another explicit lower bound of Paley–Zygmund / Chebyshev type that you can prove cleanly.

For the symmetric-group walk, instantiate `f` using a concrete statistic:
- number of fixed points,
- indicator that `1` lies in a short cycle,
- displacement of a distinguished element,
- or a cycle-count statistic.

This theorem gives a **Wilson-style lower-bound framework** even if the full asymptotic cutoff theorem remains out of reach.

### Lean 4 target signature

```lean
theorem tv_lower_bound_from_observable
  {α : Type*} [Fintype α] [DecidableEq α]
  (π μ : Finset α → ℝ) -- replace by your actual distribution type
  (f : α → ℝ)
  (hmean : expectation π f = 0)
  (hvar : variance π f ≤ σ^2)
  (hsep : a ≤ |expectation μ f|) :
  a^2 / (2 * (σ^2 + a^2)) ≤ totalVariationDist μ π
```

and then a specialization:

```lean
theorem symmetricGroup_tv_lower_bound_from_fixedPoints
  (n t : ℕ) :
  explicitLowerBound n t ≤
    totalVariationDist
      (stepDist (adjTranspositionLongCycleWalk n) t 1)
      (uniformDist (Equiv.Perm (Fin n)))
```

### Why this is a breakthrough

Upper bounds alone never reveal cutoff. Observable lower bounds create the first formal language for **pre-cutoff detection**. This is the seed of a formal theory of abrupt mixing transitions.

### Proof strategy options

**Strategy A: test-function event extraction**
1. Convert large expectation discrepancy into a separating event using thresholding.
2. Use Chebyshev under stationarity and Markov/Chebyshev under the time-`t` law.
3. Deduce a TV lower bound from the difference of event probabilities.

**Strategy B: dual characterization of total variation**
1. Use
   \[
   \|μ-π\|_{TV} = \frac12 \sup_{\|g\|_\infty \le 1} |\mathbb E_μ g - \mathbb E_π g|.
   \]
2. Normalize/clamp the observable `f` to a bounded test function.
3. Optimize the resulting bound in terms of `‖f‖∞` or variance.

**Strategy C: Paley–Zygmund on positive part**
1. Apply the inequality to `(f-c)_+`.
2. Extract a separating set `{f ≥ c}`.
3. Compare probabilities under `μ` and `π`.  
This can give sharper lower bounds but may be more delicate formally.

## Theorem 4: Relaxation time as a statistical-physics bridge

You are required to include a cross-domain theorem. The strongest bridge here is to **statistical physics**, where the inverse spectral gap is the **relaxation time**.

### Mathematical statement

For a finite reversible Markov chain,
\[
\tau_{\mathrm{rel}} := \frac{1}{\mathrm{gap}}
\]
governs exponential decay of equilibrium fluctuations:
\[
\mathrm{Var}_\pi(P^t f) \le e^{-2t/\tau_{\mathrm{rel}}}\,\mathrm{Var}_\pi(f)
\]
whenever `1 - gap ≤ e^{-1/τ_rel}` or directly
\[
\mathrm{Var}_\pi(P^t f) \le (1-\mathrm{gap})^{2t}\mathrm{Var}_\pi(f).
\]
Interpret this as a discrete analog of thermal relaxation toward equilibrium.

### Lean 4 target signature

```lean
theorem variance_decay_via_relaxation_time
  {α : Type*} [Fintype α] [DecidableEq α]
  (P : α → α → ℝ)
  (hrev : IsReversibleUniform P)
  (hmarkov : IsMarkovKernel P)
  (hgap : 0 < spectralGap P)
  (f : α → ℝ) :
  variance (uniformDist α) (iterateKernel P t f)
    ≤ (1 - spectralGap P)^(2*t) * variance (uniformDist α) f
```

or with a defined relaxation time:

```lean
def relaxationTime (P : α → α → ℝ) : ℝ := 1 / spectralGap P
```

```lean
theorem variance_decay_exp_form
  ...
  : variance (uniformDist α) (iterateKernel P t f)
      ≤ Real.exp (- (2 : ℝ) * t / relaxationTime P) *
          variance (uniformDist α) f
```

### Cross-domain significance

This theorem connects finite-group random walks to:
- **statistical physics**: equilibration and relaxation,
- **MCMC theory**: autocorrelation decay,
- **information theory**: contraction of distinguishability,
- **theoretical computer science**: randomized generation and approximate counting.

This is not decorative. It says the same spectral object controlling expansion also controls physical relaxation rates.

### Conjecture A: pre-cutoff / cutoff profile for the `S_n` walk

For the walk `P_n` on `S_n` generated by adjacent transpositions and a long cycle, there exist constants `c, C > 0` such that for every fixed `ε ∈ (0,1/2)`,
\[
c\, n^2 \log n \;\le\; t_{\mathrm{mix}}^{(n)}(\varepsilon)
\;\le\; C\, n^2 \log n,
\]
and moreover the family exhibits cutoff with window `O(n²)`:
\[
t_{\mathrm{mix}}^{(n)}(\varepsilon) - t_{\mathrm{mix}}^{(n)}(1-\varepsilon) = O(n^2).
\]

### Computational test

For `n = 5,6,7`:
1. build the exact transition matrix,
2. compute `P^t(e,·)` exactly or numerically to high precision,
3. compute
   \[
   d_n(t) = \|P^t(e,\cdot)-\pi\|_{TV},
   \]
4. locate the times when `d_n(t)` crosses `0.9, 0.5, 0.1`,
5. compare the transition width to `n²`,
6. compare the location to `n² log n`.

This is falsifiable: if the transition width scales more like `n³`, or the center like `n log n`, the conjecture fails.

### Conjecture B: fixed-point witness lower bound

There exists an observable `f_n` built from fixed points or short-cycle counts such that
\[
|\mathbb E[f_n(X_t)] - \mathbb E_\pi[f_n]| \ge c
\]
for all `t ≤ c' n² log n`, yielding a matching lower bound on mixing up to constants.

This gives a concrete target for Wilson-style lower bounds.
