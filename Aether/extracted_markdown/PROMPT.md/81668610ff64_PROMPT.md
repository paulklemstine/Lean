## Precise formalization target

Define a tropical predator-prey map on `ℝ × ℝ` by
- prey update: `x_{n+1} = min (a + x_n) (b + y_n)`
- predator update: `y_{n+1} = min (c + x_n) (d + y_n)`

for parameters `a b c d : ℝ`.

This is the min-plus analogue of a linear interaction system. Its equilibria are tropical fixed points, its iterates encode ecological trajectories, and its asymptotic growth/cycle rate is controlled by the min-plus spectral quantity
`μ = min a d ((b + c) / 2)`.

The central theorem package should be:

### Theorem 1: Ecological equilibria are tropical fixed points
For any `F : ℝ × ℝ → ℝ × ℝ`, if `F p = p`, then all iterates preserve `p`. This should explicitly instantiate the catalog theorem `fixed_points_are_iterative_invariants` or `closure_fixed_points_are_iterative_invariants` in the concrete predator-prey setting.

A concrete Lean target:
```lean
def TropPredPrey (a b c d : ℝ) : ℝ × ℝ → ℝ × ℝ
| (x, y) => (min (a + x) (b + y), min (c + x) (d + y))

theorem trop_pred_prey_fixed_point_invariant
  (a b c d : ℝ) (p : ℝ × ℝ)
  (hp : TropPredPrey a b c d p = p) :
  ∀ n : ℕ, (Function.iterate (TropPredPrey a b c d) n) p = p
```

This theorem is not deep by itself, but it is the certified anchor for all subsequent dynamics.

### Theorem 2: Tropical eigenvalue formula for the 2-species interaction matrix
Let
`A = !![a, b; c, d]`
be the min-plus interaction matrix. Define the tropical eigenvalue
`μ = min a d ((b + c) / 2)`.
Prove that this is the cycle mean of the two-node weighted digraph, i.e. the minimum over:
- loop at prey: `a`
- loop at predator: `d`
- 2-cycle prey→predator→prey: `(b + c)/2`

A Lean-friendly target is:
```lean
def tropEigenValue2 (a b c d : ℝ) : ℝ :=
  min a (min d ((b + c) / 2))

theorem trop_eigenvalue_2x2_formula
  (a b c d : ℝ) :
  tropEigenValue2 a b c d = min a (min d ((b + c) / 2))
```

That statement is tautological if defined this way, so do not stop there. The nontrivial theorem should identify this quantity as the minimum cycle mean of the associated graph. Formalize the graph-cycle side concretely, not abstractly, if necessary:

```lean
def twoCycleMean (b c : ℝ) : ℝ := (b + c) / 2

theorem trop_eigenvalue_2x2_is_min_cycle_mean
  (a b c d : ℝ) :
  tropEigenValue2 a b c d = min a (min d (twoCycleMean b c))
```

Then strengthen it with an iterate-growth inequality or exact eigenvector criterion.

### Theorem 3: Canonical period/growth rate is determined by the tropical eigenvalue
The scientifically interesting statement is not literal periodicity in `ℝ × ℝ` for arbitrary parameters, because that is often false without normalization. Instead, prove a projective/cycle-rate theorem: if there exists `v : ℝ × ℝ` such that
`TropPredPrey a b c d v = (μ + v.1, μ + v.2)`,
then iterates satisfy
`F^[n] v = (n*μ + v.1, n*μ + v.2)`.
This is the correct tropical analogue of a periodic orbit/eigenmode.

Lean target:
```lean
theorem trop_eigenvector_iterates
  (a b c d μ : ℝ) (v : ℝ × ℝ)
  (hμ : μ = tropEigenValue2 a b c d)
  (hv :
    TropPredPrey a b c d v = (μ + v.1, μ + v.2)) :
  ∀ n : ℕ,
    (Function.iterate (TropPredPrey a b c d) n v)
      = (n * μ + v.1, n * μ + v.2)
```

Because `n * μ` needs coercions, you may prefer:
```lean
((n : ℝ) * μ + v.1, (n : ℝ) * μ + v.2)
```

This is a genuine theorem: it identifies the ecological “canonical period” as a tropical linear drift rate. If you can additionally quotient by additive translation and prove projective periodicity, that would be a major advance.

### Theorem 4: Stability from tropical spectral radius bound
Interpret stability as non-expansion or bounded drift under spectral radius ≤ 1. Since the catalog already contains
`tropical_spectral_stability (rho : ℝ) (hrho_nn : 0 ≤ rho) (hrho : rho ≤ 1)`,
you should build a concrete bridge theorem from your predator-prey eigenvalue to that abstract stability result.

A Lean target:
```lean
theorem trop_pred_prey_stable_of_eigenvalue_le_one
  (a b c d : ℝ)
  (hnonneg : 0 ≤ tropEigenValue2 a b c d)
  (hbound : tropEigenValue2 a b c d ≤ 1) :
  True
```

But this is too weak. Replace `True` by a concrete stability statement, for example monotone bounded growth of the eigenmode, or non-expansion in sup norm if you can prove it:

```lean
theorem trop_pred_prey_nonexpansive
  (a b c d : ℝ) :
  ∀ p q : ℝ × ℝ,
    max (abs ((TropPredPrey a b c d p).1 - (TropPredPrey a b c d q).1))
        (abs ((TropPredPrey a b c d p).2 - (TropPredPrey a b c d q).2))
    ≤
    max (abs (p.1 - q.1)) (abs (p.2 - q.2))
```

This nonexpansiveness theorem is in many ways more powerful than a vague “spectral radius < 1 implies stability” statement, because it is certifiable and compositional. Then use `tropical_spectral_stability` as a conceptual bridge theorem rather than the sole content.

## Proof strategy architecture

### Strategy A: Direct min-plus dynamical proof on pairs
Most promising for immediate formal success.

1. Define `TropPredPrey` directly on `ℝ × ℝ`.
2. Prove fixed-point invariance by instantiating the catalog theorem.
3. For eigenvector iterates, use induction on `n`, with the inductive step powered by
   `tropical_plus_distributes_over_min`:
   - if `F(v) = μ + v`,
   - then `F(μ + v) = μ + F(v) = 2μ + v`,
   - and by induction `F^[n](v) = nμ + v`.
4. Prove nonexpansiveness coordinatewise from the elementary inequality
   `|min u v - min u' v'| ≤ max (|u-u'|) (|v-v'|)`.

Why this is promising:
- avoids heavy matrix infrastructure,
- uses exactly the cataloged tropical distributivity lemma,
- yields strong formal theorems quickly.

### Strategy B: Tropical matrix semantics and cycle-mean spectral theory
Most visionary, but technically heavier.

1. Define a min-plus matrix action of `A = !![a,b;c,d]` on vectors.
2. Show your pair-based `TropPredPrey` equals tropical matrix multiplication.
3. Define the weighted digraph of `A` and its cycle means.
4. Prove the 2×2 spectral formula by explicit case analysis on all simple cycles.
5. Deduce the eigenvector iterate theorem from tropical linearity.

Why this matters:
- it generalizes immediately to `n`-species ecosystems,
- it transforms ecology into tropical Perron-Frobenius theory,
- it opens the path to certified food-web spectral analysis.

Why it is less immediate:
- matrix and graph infrastructure may require substantial setup.

### Strategy C: Order-theoretic / closure-theoretic stability
Most conceptually surprising.

1. Show `TropPredPrey` is monotone with respect to the product order on `ℝ × ℝ`.
2. Investigate whether parameter constraints make it a closure, kernel, or nonexpansive semiring operator.
3. Use `closure_fixed_points_are_iterative_invariants` to reinterpret ecological equilibrium as closure saturation.
4. Connect stability to lattice-theoretic convergence or order intervals.

Why this is exciting:
- it reframes ecology as order dynamics,
- it may connect to abstract interpretation and program semantics,
- it could yield robust convergence theorems stronger than metric stability.

Most promising overall: **Strategy A first, Strategy B second**. A gives certifiable, nontrivial results quickly; B upgrades them into a field-opening tropical spectral ecology framework.
