## Research Task: Algebraic tropicalization of EML function algebras — an idempotent Stone–Weierstrass theorem via max-plus separation

Research Mode: PROVE

Build a genuinely new approximation theorem at the interface of EML semantics, tropical convexity, and constructive function algebra. The central objective is to formalize a max-plus analogue of Stone–Weierstrass for compact tropical codomains, not as a loose analogy but as a precise, coordinatewise-uniform density theorem with an explicit finite-expression extraction mechanism.

The key breakthrough is to replace ordinary linear combinations by idempotent sup-plus combinations and show that the resulting tropical EML algebra is still dense in the continuous EML maps into a compact tropical polytope. This is not a routine extension of scalar Stone–Weierstrass: the codomain geometry is now max-plus convex, the algebraic closure is semiring-valued rather than ring-valued, and separation must be tropical rather than linear.

### Core Formal Objects

Work with a concrete finite-coordinate model first. The most Lean-realistic starting point is to avoid the full `ℝ ∪ {-∞}` formalization and use `Fin n → ℝ` with max-plus operations, then define a tropical polytope as a compact subset generated by finitely many tropical convex combinations. The conceptual role of `-∞` can be postponed to a second file.

Use the following infrastructure-level definitions.

```lean
open Set Metric TopologicalSpace
open scoped BigOperators

def Trop (n : ℕ) := Fin n → ℝ

def tropAdd {n : ℕ} (x y : Trop n) : Trop n := fun i => max (x i) (y i)
def tropSMul {n : ℕ} (a : ℝ) (x : Trop n) : Trop n := fun i => a + x i

def IsTropConvex {n : ℕ} (K : Set (Trop n)) : Prop :=
  ∀ ⦃x y : Trop n⦄, x ∈ K → y ∈ K → ∀ a b : ℝ, (fun i => max (a + x i) (b + y i)) ∈ K

def TropAffineMap (X : Type*) [TopologicalSpace X] (n : ℕ) :=
  X → Trop n
```

For the approximation space, use a concrete “generated tropical algebra” rather than an abstract closure operator at first. A robust initial formalization is: the approximants are finite coordinatewise suprema of shifted generators.

```lean
def TropGeneratorFamily (X : Type*) [TopologicalSpace X] (ι : Type*) (n : ℕ) :=
  ι → X → ℝ

def TropExpr {X : Type*} [TopologicalSpace X] {ι : Type*} {n : ℕ}
    (φ : TropGeneratorFamily X ι n) :=
  Finset (ι × ℝ × Fin n)

def evalTropExpr {X : Type*} [TopologicalSpace X] {ι : Type*} {n : ℕ}
    (φ : TropGeneratorFamily X ι n) (E : TropExpr φ) : X → Trop n :=
  fun x i => E.sup (fun t => let ⟨j, c, k⟩ := t; if h : k = i then c + φ j x else -1e100)
```

You may want a cleaner expression language with constants, coordinate tags, and `max`; if so, define an inductive syntax and an evaluation function. What matters is that the approximating class is visibly finite and constructive.

For codomain-constrained maps into a compact tropical polytope `K`, define:

```lean
def ContinuousInto {X Y : Type*} [TopologicalSpace X] [TopologicalSpace Y]
    (K : Set Y) :=
  {f : X → Y // Continuous f ∧ MapsTo f univ K}

def supDist {X : Type*} {n : ℕ} [TopologicalSpace X] (f g : X → Trop n) : ℝ :=
  sSup ((fun x => ‖f x - g x‖) '' (Set.univ : Set X))
```

If `X` is compact and the maps are continuous, use `HasAntitoneBasis`, `Bornology`, or existing compactness lemmas to prove boundedness and existence of the supremum. If the full `sSup` setup becomes heavy, first state approximation pointwise with a uniform bound:
```lean
∀ x, ‖f x - g x‖ ≤ ε
```
which is stronger and often easier to use than introducing a separate metric object.

### Main Theorem 1: Coordinatewise tropical Stone–Weierstrass density

The first theorem should be stated in a form Lean can support directly: compact domain, finite-dimensional tropical codomain, coordinatewise generator family, and a coordinate separation hypothesis strong enough to invoke scalar Stone–Weierstrass on each coordinate.

A precise Lean target:

```lean
theorem tropical_stone_weierstrass_fin
    {X : Type*} [TopologicalSpace X] [CompactSpace X]
    [T2Space X]
    {n ι : ℕ}
    (K : Set (Trop n))
    (hK_closed : IsClosed K)
    (hK_nonempty : K.Nonempty)
    (hK_compact : IsCompact K)
    (F : Fin ι → X → ℝ)
    (hF_cont : ∀ j, Continuous (F j))
    (h_sep : ∀ x y : X, x ≠ y →
      ∃ j : Fin ι, F j x ≠ F j y)
    (f : X → Trop n)
    (hf_cont : Continuous f)
    (hf_maps : MapsTo f univ K) :
    ∀ ε > 0, ∃ E, ∀ x : X, ‖f x - evalTropExpr (fun j x => F j x) E x‖ ≤ ε
```

This is the finite-generator version. It is already a major theorem if the expression class is built only from tropical constants and coordinatewise max-plus combinations of the `F j`.

The mathematically stronger codomain-respecting version should then project the approximant back into `K` using a retraction or nearest tropical projector:

```lean
theorem tropical_stone_weierstrass_into_polytope
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
    {n ι : ℕ}
    (K : Set (Trop n))
    (r : Trop n → Trop n)
    (hr_cont : Continuous r)
    (hr_retract : ∀ x ∈ K, r x = x)
    (hr_maps : MapsTo r univ K)
    (F : Fin ι → X → ℝ)
    (hF_cont : ∀ j, Continuous (F j))
    (h_sep : ∀ x y : X, x ≠ y → ∃ j : Fin ι, F j x ≠ F j y)
    (f : X → Trop n)
    (hf_cont : Continuous f)
    (hf_maps : MapsTo f univ K) :
    ∀ ε > 0, ∃ E, ∀ x : X, ‖f x - r (evalTropExpr (fun j x => F j x) E x)‖ ≤ ε
```

This theorem is the formal bridge to the “EML codomain semantics” viewpoint: approximation happens in ambient tropical affine space, then a continuous retraction preserves codomain correctness.

### Main Theorem 2: Tropical functoriality of density under retraction

The second theorem should isolate the functorial mechanism rather than burying it inside the first proof. This is the theorem that makes the whole framework reusable.

```lean
theorem dense_under_continuous_retraction
    {X Y Z : Type*}
    [TopologicalSpace X] [CompactSpace X] [T2Space X]
    [PseudoMetricSpace Y] [PseudoMetricSpace Z]
    (A : Set (X → Y))
    (r : Y → Z)
    (hr_cont : Continuous r)
    (S : Set (X → Z))
    (hS : S = (fun g => r ∘ g) '' A)
    (f : X → Z)
    (g0 : X → Y)
    (hg0_cont : Continuous g0)
    (hf : f = r ∘ g0)
    (hdense :
      ∀ ε > 0, ∃ g ∈ A, ∀ x, dist (g x) (g0 x) ≤ ε) :
    ∀ ε > 0, ∃ h ∈ S, ∀ x, dist (h x) (f x) ≤ ε
```

The proof should use uniform continuity of `r` on the compact image of approximants. If a general statement is too abstract for the first pass, specialize to `Y = Trop n`, `Z = K` with subspace metric, and use continuity on compact sets to derive a modulus.

### Main Theorem 3: Constructive error bound from coordinate moduli of continuity

Do not stop at existential density. Extract an explicit approximation pipeline. The algorithmic theorem should say: if each coordinate of `f` has a modulus of continuity and the generator family induces a finite partition/refinement scheme, then one can build a tropical expression with certified error.

A workable first theorem statement is:

```lean
def ModulusOfContinuity {X : Type*} [PseudoMetricSpace X] (u : X → ℝ) :=
  ℝ → ℝ

def IsModulus {X : Type*} [PseudoMetricSpace X] (u : X → ℝ)
    (ω : ModulusOfContinuity u) : Prop :=
  (∀ δ > 0, 0 ≤ ω δ) ∧
  (∀ ε > 0, ∃ δ > 0, ω δ ≤ ε) ∧
  (∀ x y, |u x - u y| ≤ ω (dist x y))

theorem tropical_expression_approximation_with_modulus
    {X : Type*} [PseudoMetricSpace X] [CompactSpace X]
    {n ι : ℕ}
    (F : Fin ι → X → ℝ)
    (f : X → Trop n)
    (hf_cont : Continuous f)
    (ω : Fin n → ModulusOfContinuity (fun x => f x))
    (hω : ∀ i, IsModulus (fun x => f x i) (ω i)) :
    ∀ ε > 0, ∃ E, ∀ x : X, ‖f x - evalTropExpr (fun j x => F j x) E x‖ ≤ ε
```

If the full compiler theorem is too ambitious initially, state and prove a weaker but explicit quantitative lemma: given a finite `δ`-net of `X`, build an approximant by taking tropical suprema of shifted “bump” generators and derive an error bounded by `max_i ω i δ`.

### Proof Strategy

#### Strategy A: Coordinatewise reduction to scalar Stone–Weierstrass, then reassemble
This is the most promising route for a first complete Lean proof.

1. **Define the scalar tropical algebra generated by constants and generators.**  
   For each coordinate `i : Fin n`, consider the scalar class of functions `X → ℝ` obtained from the generators by tropical addition (`max`) and tropical scalar shift (`c + _`). Prove closure under these operations and continuity preservation.

2. **Show scalar separation from max-plus separation.**  
   Your separation hypothesis should imply ordinary point separation for the scalar generated algebra:
   ```lean
   ∀ x y, x ≠ y → ∃ u ∈ A, u x ≠ u y
   ```
   If needed, strengthen the hypothesis so the generator family itself separates points.

3. **Invoke existing scalar Stone–Weierstrass machinery coordinatewise.**  
   Approximate each coordinate function `fun x => f x i` uniformly by some scalar tropical expression `g_i`. This is where you should explicitly reuse prior EML/Stone–Weierstrass lemmas if they already show density of a point-separating semiring/lattice of continuous scalar functions.

4. **Assemble the coordinate approximants into a vector-valued approximant.**  
   Define
   ```lean
   g x i := g_i x
   ```
   and prove
   ```lean
   ∀ x, ‖f x - g x‖ ≤ ε
   ```
   by choosing coordinatewise error `ε / C`, where `C` depends on the norm (`Real.sqrt n`, `n`, or `1` for sup norm). If Euclidean norm introduces overhead, define and use the sup norm on `Fin n → ℝ`.

5. **Project back to `K` via retraction.**  
   If `g` does not automatically land in `K`, compose with a continuous retraction `r`. Use uniform continuity of `r` on the compact image set to preserve approximation. If `K` is itself tropically convex and generated by the same coordinate maps, try to show directly that the approximant lands in `K`; otherwise the retraction theorem is the correct abstraction.

Key lemmas to establish:
```lean

lemma continuous_evalTropExpr ...
lemma coord_uniform_error_implies_vector_uniform_error ...

```

#### Strategy B: Tropical separation via finite upper envelopes
This route is more original and may yield a cleaner constructive compiler theorem.

1. For each `x ∈ X` and coordinate `i`, build a tropical affine minorant/majorant touching `f_i` at `x` and staying within `ε` on a neighborhood.
2. Use compactness of `X` to extract a finite subcover.
3. Take the tropical supremum of the finitely many local pieces.
4. Prove the resulting upper envelope approximates `f_i` uniformly.
5. Assemble coordinates and retract to `K`.

This is the tropical analogue of the classical upper-envelope proof of Stone–Weierstrass, but now the envelope operation is not an auxiliary trick — it is the algebraic operation of the semiring itself. This strategy is conceptually deeper and more constructive, but it requires a local separation lemma strong enough to produce those touching tropical affine pieces.

#### Strategy C: Tropical convex duality / Hahn–Banach style separation
This is the most ambitious and the least likely to close quickly in Lean, but it is the right conceptual endpoint.

1. Define tropical halfspaces or residuated affine functionals.
2. Prove a separation theorem for points and compact tropical convex sets.
3. Use the separation theorem to produce coordinatewise approximants as suprema of tropical affine functionals.
4. Deduce density by compactness and finite generation of `K`.

This route is mathematically revolutionary because it identifies the approximation theorem as a manifestation of tropical duality, not just coordinatewise scalar approximation. Even if a full proof is out of reach, isolate the separation lemma as a conjectural or partial formal target.

### Supporting Definitions and Lemmas Worth Formalizing

Introduce a concrete “point-separating tropical subsemiring” predicate:

```lean
def TropSeparatesPoints {X : Type*} (A : Set (X → ℝ)) : Prop :=
  ∀ x y : X, x ≠ y → ∃ f ∈ A, f x ≠ f y
```

Define closure under tropical operations:

```lean
def IsTropSubsemiring {X : Type*} (A : Set (X → ℝ)) : Prop :=
  (∀ c : ℝ, (fun _ : X => c) ∈ A) ∧
  (∀ f g, f ∈ A → g ∈ A → (fun x => max (f x) (g x)) ∈ A) ∧
  (∀ a : ℝ, ∀ f, f ∈ A → (fun x => a + f x) ∈ A)
```

Then prove a scalar theorem of independent interest:

```lean
theorem scalar_tropical_stone_weierstrass
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]

    (hA_cont : ∀ f ∈ A, Continuous f)
    (hA_semiring : IsTropSubsemiring A)

    ∀ f : X → ℝ, Continuous f →
    ∀ ε > 0, ∃ g ∈ A, ∀ x, |f x - g x| ≤ ε
```

If you can prove this scalar theorem first, the vector-valued theorems become largely formal corollaries. This is likely the cleanest architecture for the file.

### Why this matters

This theorem would create a new algebraic semantics for approximation: EML expressions would no longer be viewed merely as compositional programs or codomain-retracted approximants, but as elements of an idempotent function algebra whose closure recovers all continuous tropical-semantic behaviors on compact spaces. That changes the research program in three ways:

1. **It unifies universal approximation with tropical convexity.**  
   Approximation is no longer an analytic accident; it becomes a structural consequence of max-plus algebra.

2. **It produces a certified compiler.**  
   The proof itself yields a finite tropical expression approximant, with an explicit error bound from coordinatewise moduli of continuity. This is the algorithmic shadow of the theorem and is essential for semantics-to-network compilation.

3. **It opens tropical representation theory for EML.**  
   Once density is expressed through tropical generators and retractions, one can ask about minimal generating families, approximation ranks, tropical Barron-type norms, and categorical tropicalization functors for semantic models.

4. **It is distinct from existing codomain-retraction results.**  
   The novelty is not merely “approximate in ambient space then retract,” but the identification of a specific idempotent semiring of approximants whose intrinsic closure is the full continuous tropical semantic space.
