## Primary Breakthrough Targets

### 1. Reed–Solomon as an MDS evaluation code with explicit decoding radius

Formalize Reed–Solomon codes over a finite field `K` as evaluation vectors of low-degree polynomials on a finite set of pairwise distinct evaluation points.

A precise theorem target:

```lean
theorem reed_solomon_distance_eq
  {K : Type*} [Field K] [Fintype K] [DecidableEq K]
  {n k : ℕ}
  (α : Fin n → K)
  (hα : Function.Injective α)
  (hk : k ≤ n) :
  minimumDistance
    {c : Fin n → K |
      ∃ p : K[X], p.natDegree < k ∧ ∀ i, c i = p.eval (α i)}
    = n - k + 1
```

If `minimumDistance` is too heavy to instantiate immediately, first prove the lower bound and then exhibit a witness pair to obtain equality:

```lean
theorem reed_solomon_distance_ge
  {K : Type*} [Field K] [Fintype K] [DecidableEq K]
  {n k : ℕ}
  (α : Fin n → K)
  (hα : Function.Injective α)
  (hk : k ≤ n) :
  codeMinDistance
    {c : Fin n → K |
      ∃ p : K[X], p.natDegree < k ∧ ∀ i, c i = p.eval (α i)}
    ≥ n - k + 1
```

Then derive the unique-decoding radius:

```lean
theorem reed_solomon_unique_decode_radius
  {K : Type*} [Field K] [Fintype K] [DecidableEq K]
  {n k : ℕ}
  (α : Fin n → K)
  (hα : Function.Injective α)
  (hk : k ≤ n) :
  uniqueDecodingRadius
    {c : Fin n → K |
      ∃ p : K[X], p.natDegree < k ∧ ∀ i, c i = p.eval (α i)}
    = (n - k) / 2
```

This theorem is not revolutionary by itself; its significance is that it gives the metric side needed to state Berlekamp–Massey correctness as a true decoder theorem.

### 2. BCH bound via consecutive roots in an extension field

This is the central algebraic theorem. Formalize a BCH code as a cyclic code generated by a polynomial whose roots include a consecutive block of powers of a primitive `n`th root of unity in an extension field. Then prove the BCH lower bound on minimum distance.

A precise theorem target, in a formulation likely more Lean-friendly than full cyclic-code abstraction at first pass:

```lean
theorem bch_distance_bound
  {K L : Type*} [Field K] [Field L] [Algebra K L]
  {n δ b : ℕ}
  (α : L)
  (hα_primitive : IsPrimitiveRoot α n)
  (g : K[X])
  (hg_monic : g.Monic)
  (hroots : ∀ j : ℕ, j < δ - 1 → aeval α^[b+j] g = 0) :
  bchMinDistance K n g ≥ δ
```

If the above is too abstract because `aeval α^[b+j] g` and extension-field roots require substantial infrastructure, split the theorem into two layers.

First, a polynomial root-pattern theorem:

```lean
theorem cyclic_codeword_weight_ge_of_consecutive_roots
  {K L : Type*} [Field K] [Field L] [Algebra K L]
  {n δ b : ℕ}
  (α : L)
  (hα_primitive : IsPrimitiveRoot α n)
  (c : K[X])
  (hc_mod : c.natDegree < n)
  (hroots : ∀ j : ℕ, j < δ - 1 → aeval α^[b+j] c = 0) :
  hammingWeight (polyToWord n c) ≥ δ
```

Then deduce the BCH code distance bound from divisibility by the generator polynomial.

This theorem is a breakthrough because it imports the heart of algebraic coding theory into Lean in a reusable way: **distance from spectral vanishing constraints**. That principle can later be repurposed for additive combinatorics, finite-field harmonic analysis, and pseudorandomness.

### 3. Berlekamp–Massey as certified minimal recurrence synthesis

This is where the project becomes field-opening. Formalize Berlekamp–Massey not merely as a decoder subroutine, but as a theorem about finite streams over a field: it computes the shortest linear recurrence generating the stream.

A precise theorem target:

```lean
theorem berlekamp_massey_correct
  {K : Type*} [Field K] [DecidableEq K]
  (s : ℕ → K) (N : ℕ) :
  let C := berlekampMassey (fun i : Fin N => s i)
  in isLinearRecurrencePrefix C (fun i : Fin N => s i)
   ∧ ∀ C', isLinearRecurrencePrefix C' (fun i : Fin N => s i) →
       recurrenceLength C ≤ recurrenceLength C'
```

For coding-theoretic use, connect it to syndrome sequences:

```lean
theorem berlekamp_massey_syndrome_locator
  {K L : Type*} [Field K] [Field L] [Algebra K L] [DecidableEq L]
  {n t : ℕ}
  (α : L)
  (hα_primitive : IsPrimitiveRoot α n)
  (e : Fin n → K)
  (hewt : hammingWeight e ≤ t) :
  let s := syndromeStream α e
  let σ := berlekampMassey (prefix (2*t) s)
  in isErrorLocator α e σ
```

And then the decoding theorem:

```lean
theorem bch_decode_correct_of_weight_le
  {K L : Type*} [Field K] [Field L] [Algebra K L] [DecidableEq L]
  {n δ : ℕ}
  (C : BCHCode K L n δ)
  (r c e : Fin n → K)
  (hr : r = c + e)
  (hc : c ∈ C.codewords)
  (he : hammingWeight e ≤ (δ - 1) / 2) :
  decodeBM C r = some c
```

This is the theorem that matters. Once proved, Lean becomes capable of certifying actual bounded-distance algebraic decoding.

## Proof Strategy Architecture

### Strategy A: Root-counting → distance → unique decoding
Most promising for the Reed–Solomon and BCH distance layer.

1. **Reed–Solomon lower bound from polynomial root counting**  
   For two distinct codewords `ev(p)` and `ev(q)`, the difference is `ev(p-q)`. If they agree on too many coordinates, then `p-q` has too many roots relative to its degree. This is exactly where `reed_solomon_min_distance` should be exploited: identify your codeword difference with the polynomial whose roots correspond to matching coordinates.

2. **BCH bound from Vandermonde/non-singularity argument**  
   For a codeword of weight `< δ`, write the parity-check equations coming from consecutive roots `α^b, α^(b+1), ..., α^(b+δ-2)`. Restrict to support positions of the codeword. This yields a rectangular Vandermonde system. Choose a square subsystem and prove its determinant is nonzero using distinctness of powers of a primitive root. Therefore the support coefficients must vanish, contradiction.

3. **Transfer to code minimum distance**  
   Once every nonzero codeword has weight at least `δ`, the minimum distance bound follows immediately.

Why this is most promising: it is algebraically clean, close to textbook proofs, and formalizes well in Lean using existing polynomial/root infrastructure.

---

### Strategy B: Linear-algebraic parity-check formalization
Most promising for BCH if polynomial modulo cyclic structure becomes cumbersome.

1. Define the code by a parity-check matrix over an extension field whose rows are indexed by consecutive exponents and columns by powers `α^(ij)`.
2. Show any set of `< δ` columns is linearly independent by a Vandermonde determinant argument.
3. Deduce no nonzero codeword can have support size `< δ`.

Why this may be better: Lean often handles finite matrices and determinant lemmas more smoothly than quotient rings modulo `X^n - 1`. This route also exposes direct bridges to compressed sensing and sparse recovery.

---

### Strategy C: Berlekamp–Massey via loop invariant on discrepancy
Most promising for algorithm correctness.

1. Define discrepancy and candidate connection polynomial.
2. Prove the loop invariant: after processing `m` syndromes, the current polynomial annihilates the known prefix with the smallest possible length among candidates satisfying the current constraints.
3. Show that for a syndrome stream arising from `t` errors, the true error-locator polynomial is a valid annihilator of length `≤ t`; minimality then forces the algorithm’s output to be the error-locator polynomial up to scaling.
4. Normalize to monic and conclude decoder correctness.

Why this is most promising: Berlekamp–Massey is fundamentally a minimality theorem for recurrences. Formalizing it at that level makes the result reusable far beyond coding theory.
