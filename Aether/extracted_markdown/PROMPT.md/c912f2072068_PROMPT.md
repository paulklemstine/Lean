## Assignment: Tropical Neural Code Classification with Provable Margins

**Mode:** prove

Build a new formal bridge between tropical convexity, neural coding, and certified classification. The target is not an incremental robustness lemma: it is a foundational theorem saying that **the tropical convex hull of a finite neural code controls both its label realizability and an explicit classification margin**, so that combinatorial neural codes become certifiable geometric classifiers inside Lean.

This should read as the beginning of a formal **tropical coding theory for neuroscience**.

---

## Core Breakthrough Target

Let a neural firing pattern be a vector in `Fin n → ℝ`, interpreted tropically with max-plus operations. Let each stimulus class be represented by a finite family of codewords/receptive-field response vectors. Define the tropical convex hull of each class, and define the tropical margin between classes as the infimum coordinatewise slack needed to dominate one hull by another.

The central theorem should show:

1. **Separation by tropical hulls implies correct class assignment**, and  
2. **A positive lower bound on tropical hull separation yields a provable classification margin**, and  
3. **The combinatorial classification capacity depends only on the finite quotient / combinatorial structure of the code**, not on arbitrary Euclidean embeddings.

This would establish tropical geometry as a formal language for neural code classification, analogous to how linear separators structure classical statistical learning theory.

## Main Theorem A: Positive Tropical Separation Gives Certified Classification

### Informal statement
For two finite neural codebooks `A B : Finset (Fin n → ℝ)`, if every tropical convex combination of class `A` is separated from every tropical convex combination of class `B` by margin `γ > 0`, then every observation lying within a certified perturbation radius below `γ/2` of the `A`-hull is correctly classified as class `A` against class `B`.

### Lean-style target
```lean
theorem tropical_hull_margin_certifies_binary_classification
  {n : ℕ} [NeZero n]
  (A B : Finset (Fin n → ℝ))
  (γ : ℝ)
  (hγ : 0 < γ)
  (hsep :
    ∀ a ∈ tropConvHull A, ∀ b ∈ tropConvHull B,
      ∃ i : Fin n, γ ≤ a i - b i)
  :
  ∀ x : Fin n → ℝ,
    (∃ a ∈ tropConvHull A, ∀ i, |x i - a i| < γ / 2) →
    ¬ (∃ b ∈ tropConvHull B, ∀ i, |x i - b i| < γ / 2)
```

This is a robust non-overlap theorem: no point can lie simultaneously in `γ/2`-tubes around tropically separated class hulls.

A stronger classifier version can define:
```lean
def tropicalScore (S : Finset (Fin n → ℝ)) (x : Fin n → ℝ) : ℝ := ...
```
and prove argmax correctness.

## Main Theorem B: Tropical Hull Determines Finite Classification Quotient

This is the conceptual theorem. Connect it to the catalog theorem
`finite_neural_quotient_implies_finite_classification_quotient`.

### Informal statement
If a finite neural code induces only finitely many tropical hull cells / dominance regions, then the resulting stimulus classification quotient is finite. In particular, combinatorial capacity is controlled by the tropical hull decomposition.

### Lean-style target
```lean
theorem finite_tropical_hull_cells_imply_finite_classification_capacity
  {n : ℕ} [NeZero n]
  (C : Finset (Fin n → ℝ))
  (Label : Type)
  [Fintype Label]
  (assign : (Fin n → ℝ) → Label)
  (hcompat :
    ∀ x y,
      tropicalCell C x = tropicalCell C y → assign x = assign y)
  :
  Finite (Set.range assign)
```

If `tropicalCell` is too ambitious, define a simpler finite invariant first:
```lean
def dominancePattern (C : Finset (Fin n → ℝ)) (x : Fin n → ℝ) : Finset (Finset (Fin n))
```
or even
```lean
def argmaxPattern (C : Finset (Fin n → ℝ)) (x : Fin n → Finset α)
```
for a finite index type of generators. Then prove classification factors through this pattern. This directly interfaces with finite quotient ideas.

Exploit the catalog theorem

### Informal statement
If a neural code sheaf carries a coboundary lower bound that certifies consistency gap `δ`, then the induced tropical classifier has adjusted margin at least `δ` (or a monotone function of `δ`) on realizable codewords.

theorem tropical_margin_lower_bound_of_coboundary
  {n : ℕ} [NeZero n]
  (C₀ C₁ : Finset (Fin n → ℝ))
  (δ : ℝ)

**Most promising for first formal breakthrough.**

2. Use `tropical_row_norm_bound_coord` to show perturbations of size `< γ/2` preserve strict score ordering / impossibility of simultaneous membership in both separated hull neighborhoods.

- Avoids deep tropical convexity machinery at first.
- Produces an actual certified-margin theorem quickly.

1. Define for each `x` the finite combinatorial object recording which generators attain the tropical maximum in each coordinate, or which inequalities are active.
2. Prove that if two points have the same dominance pattern, then they induce the same class decision.
3. Apply `finite_neural_quotient_implies_finite_classification_quotient` to conclude finite classification capacity.

Why this is promising:
- Gives the conceptual theorem that classification capacity is combinatorial.
- Uses only finite types, `Finset`, and equality of patterns.
- Can be developed independently of full tropical hull formalization.

1. Formalize a compatibility statement between receptive field consistency and tropical dominance slack.

Why this is revolutionary:
- It connects local-to-global consistency obstructions in sheaf theory with geometric margin in tropical classification.
- This is exactly the kind of theorem that makes researchers say “I never thought of that connection.”

This is probably harder, but if achieved even in a restricted finite setting, it is field-opening.

## Concrete Lean 4 Formalization Suggestions

Prefer simple concrete aliases:
```lean
abbrev TropPoint (n : ℕ) := Fin n → ℝ
```

Potential definitions:
```lean
def coordGap {n : ℕ} (x y : TropPoint n) : ℝ :=
  ⨅ i : Fin n, (x i - y i)

def separatedBy {n : ℕ} (γ : ℝ) (x y : TropPoint n) : Prop :=
  ∃ i : Fin n, γ ≤ x i - y i

def tropGeneratorScore {n : ℕ} (S : Finset (TropPoint n)) (x : TropPoint n) : ℝ :=
  S.sup (fun s => coordGap x s)

def classifiesAs {n : ℕ} (A B : Finset (TropPoint n)) (x : TropPoint n) : Prop :=
  tropGeneratorScore A x ≥ tropGeneratorScore B x
```

Then prove a margin theorem of the shape:
```lean
theorem tropical_score_stability_under_coord_perturbation
  {n : ℕ} [NeZero n]
  (A B : Finset (TropPoint n))
  (x x' : TropPoint n)
  (γ ε : ℝ)
  (hε : 0 ≤ ε)
  (hpert : ∀ i, |x i - x' i| ≤ ε)
  (hgap : tropGeneratorScore A x ≥ tropGeneratorScore B x + γ)
  (hγε : 2 * ε < γ)
  :
  tropGeneratorScore A x' > tropGeneratorScore B x'
```

This theorem is exceptionally useful: it is a certified tropical classifier stability theorem, and it likely admits a manageable proof.
