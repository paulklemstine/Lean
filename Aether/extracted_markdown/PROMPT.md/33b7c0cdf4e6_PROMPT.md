## Research Direction

### Core theorem target A: divisor-level Hodge = algebraic in a formal finite-dimensional model

The first decisive theorem should mirror the Lefschetz (1,1)-theorem in a finite-dimensional formal setting. You may not yet have the full analytic/algebraic apparatus of singular cohomology of complex projective varieties in Mathlib, but you can formalize the **structural theorem** that makes the classical statement possible.

Define a rational Hodge structure of weight `2` on a finite-dimensional `ℚ`-vector space `V`, together with a complexification decomposition
\[
V_\mathbb{C} = H^{2,0} \oplus H^{1,1} \oplus H^{0,2}
\]
satisfying conjugation symmetry. Then define the Hodge classes as
\[
\mathrm{Hdg}(V) := V \cap H^{1,1}.
\]

Introduce an abstract “algebraic cycle class subspace”
\[
\mathrm{Alg}(V) \subseteq \mathrm{Hdg}(V)
\]
and prove exact equivalence under a span hypothesis.

This sounds tautological if phrased poorly; make it nontrivial by formulating it as a basis/realization theorem over `ℚ`, reducing algebraicity of Hodge classes to rational spanning of the `(1,1)`-part.

### Precise theorem statement
If a finite family of rational classes lands in the `(1,1)`-part and spans all rational Hodge classes, then every Hodge class is a rational linear combination of these classes.

### Lean 4 type signature sketch
```lean
theorem hodgeClass_mem_span_of_generators
  {V : Type*} [AddCommGroup V] [Module ℚ V] [FiniteDimensional ℚ V]
  (HC : HodgeStructureWeightTwo V)
  (Z : Finset V)
  (h11 : ∀ z ∈ Z, HC.IsHodge11 z)
  (hspan : Submodule.span ℚ ((↑Z : Set V)) = HC.hodgeClasses) :
  ∀ x : V, x ∈ HC.hodgeClasses → x ∈ Submodule.span ℚ ((↑Z : Set V)) := by
```

This is the minimal certified theorem, but it is only the beginning. The actual breakthrough comes from constructing situations where `hspan` is itself provable from geometry or lattice theory.

## Core theorem target B: rank-one and rank-two polarized Hodge structures force algebraicity

You should prove a theorem showing that in low Picard-rank models, every rational `(1,1)`-class is generated by an explicit polarization class, or by at most two classes. This is where the result becomes mathematically substantive.

### Theorem B1: rank-one case
For a polarized rational Hodge structure of weight `2`, if the rational Hodge class space has dimension `1`, then every Hodge class is a rational multiple of any nonzero algebraic class.

### Lean 4 type signature sketch
```lean
theorem hodgeClasses_eq_span_singleton_of_finrank_one
  {V : Type*} [AddCommGroup V] [Module ℚ V] [FiniteDimensional ℚ V]
  (HC : HodgeStructureWeightTwo V)
  (η : V)
  (hη : η ∈ HC.hodgeClasses)
  (hηne : η ≠ 0)
  (hfin : FiniteDimensional.finrank ℚ HC.hodgeClasses = 1) :
  HC.hodgeClasses = Submodule.span ℚ ({η} : Set V) := by
```

This is a formal analogue of the phenomenon behind Picard rank one: all divisor classes are generated by the polarization.

### Theorem B2: rank-two case
If the Hodge class subspace has rational dimension `2`, then any two linearly independent algebraic Hodge classes generate all Hodge classes.

```lean
theorem hodgeClasses_eq_span_pair_of_finrank_two
  {V : Type*} [AddCommGroup V] [Module ℚ V] [FiniteDimensional ℚ V]
  (HC : HodgeStructureWeightTwo V)
  (η₁ η₂ : V)
  (hη₁ : η₁ ∈ HC.hodgeClasses)
  (hη₂ : η₂ ∈ HC.hodgeClasses)
  (hindep : LinearIndependent ℚ ![η₁, η₂])
  (hfin : FiniteDimensional.finrank ℚ HC.hodgeClasses = 2) :
  HC.hodgeClasses = Submodule.span ℚ ({η₁, η₂} : Set V) := by
```

This gives a formal theorem with immediate K3/abelian-surface flavor: once the Néron–Severi rank is controlled, algebraicity reduces to linear algebra.

## Core theorem target C: orthogonal decomposition and transcendental/algebraic splitting

A field-opening theorem is to formalize the decomposition of a polarized weight-2 Hodge structure into algebraic and transcendental parts.

Let `Q` be a nondegenerate symmetric bilinear form polarizing the structure. Define:
- `Alg := HC.hodgeClasses`
- `Tr := Algᗮ` (orthogonal complement with respect to `Q`)

Then prove:
1. `V = Alg ⊔ Tr` as a direct sum under nondegeneracy hypotheses,
2. `Tr ∩ Alg = ⊥`,
3. every Hodge class projects trivially to the transcendental part.

### Lean 4 type signature sketch
```lean
theorem hodgeClasses_orthogonal_directSum
  {V : Type*} [AddCommGroup V] [Module ℚ V] [FiniteDimensional ℚ V]
  (Q : BilinForm ℚ V)
  (hQnd : Q.Nondegenerate)
  (HC : PolarizedHodgeStructureWeightTwo V Q) :
  IsCompl HC.hodgeClasses (HC.hodgeClasses.orthogonal Q) := by
```

and

```lean
theorem hodgeClass_proj_transcendental_eq_zero
  {V : Type*} [AddCommGroup V] [Module ℚ V] [FiniteDimensional ℚ V]
  (Q : BilinForm ℚ V)
  (hQnd : Q.Nondegenerate)
  (HC : PolarizedHodgeStructureWeightTwo V Q)
  (x : V) (hx : x ∈ HC.hodgeClasses) :
  LinearMap.proj HC.hodgeClasses (HC.hodgeClasses.orthogonal Q) x = 0 := by
```

This is not yet the Hodge conjecture, but it formalizes the exact architecture in which the conjecture lives: algebraic classes versus transcendental classes.

## Core theorem target D: certified instances for products / block decompositions

A genuinely useful theorem is that algebraicity of Hodge classes is stable under direct sums/products in the formal category. This creates an inductive machine.

### Theorem D
If two weight-2 rational Hodge structures satisfy “every Hodge class is generated by algebraic classes,” then their direct sum does too.

```lean
theorem hodgeConjecture_like_closed_under_directSum
  {V W : Type*}
  [AddCommGroup V] [Module ℚ V] [FiniteDimensional ℚ V]
  [AddCommGroup W] [Module ℚ W] [FiniteDimensional ℚ W]
  (HV : HodgeStructureWeightTwo V)
  (HW : HodgeStructureWeightTwo W)
  (algV : Submodule ℚ V) (algW : Submodule ℚ W)
  (hV : algV = HV.hodgeClasses)
  (hW : algW = HW.hodgeClasses) :
  (directSumHodgeStructure HV HW).hodgeClasses =
    Submodule.map (LinearMap.inl ℚ V W) algV ⊔
    Submodule.map (LinearMap.inr ℚ V W) algW := by
```

This theorem matters because products of abelian varieties and decomposed motives are central testing grounds for Hodge-type statements.

## Mathematical Framing

The full Hodge conjecture says:

> For every smooth projective complex variety `X` and every `p`, every rational Hodge class in  
> \[
> H^{2p}(X,\mathbb{Q}) \cap H^{p,p}(X)
> \]
> is a `ℚ`-linear combination of classes of codimension-`p` algebraic cycles.

Inside Lean 4 today, the correct revolutionary program is to formalize the **linear-algebraic skeleton** of this statement and prove nontrivial exact theorems in special regimes:
- divisor classes (`p = 1`) in abstract polarized Hodge structures,
- rank-one/rank-two Hodge class spaces,
- orthogonal decompositions into algebraic/transcendental parts,
- direct-sum/product stability,
- concrete finite-dimensional models suggestive of abelian varieties and K3 surfaces.

This is how one builds a theorem prover bridge from abstract Hodge theory to arithmetic geometry.

## 2–3 Proof Strategy Paths

### Strategy A: Linear algebra first, then geometric interpretation
**Most promising.**

1. Define `HodgeStructureWeightTwo V` as a rational vector space `V` together with complexified subspaces `H20`, `H11`, `H02` whose internal direct sum is all of `V ⊗[ℚ] ℂ`, and with conjugation symmetry.
2. Define `hodgeClasses : Submodule ℚ V` as the preimage/intersection of `V` with the `(1,1)`-subspace after scalar extension.
3. Prove basis/rank lemmas using `FiniteDimensional.finrank`, submodule spans, and standard linear algebra.
4. Add polarization and orthogonal complement theorems using `BilinForm`, `Submodule.orthogonal`, and direct sum results.
5. Only then connect these abstract theorems to “algebraic cycles” via a chosen generating family.

Why this is strongest: Mathlib already supports finite-dimensional linear algebra far better than full cohomology of complex varieties. This path yields certified nontrivial theorems now.

---

### Strategy B: Lattice-theoretic attack inspired by K3 surfaces
1. Model the degree-2 cohomology as a rational quadratic space with distinguished Hodge line(s) and integral/rational lattice data.
2. Define the algebraic part as the orthogonal complement of the transcendental plane or as the rational `(1,1)` part.
3. Prove that when the algebraic lattice has rank `1` or `2`, explicit generators control all Hodge classes.
4. Extract signatures and discriminant constraints.

Why this is exciting: this imports K3-surface logic into Lean through quadratic forms and lattices rather than full scheme theory. It opens a path toward Torelli-style formalization later.

---

### Strategy C: Product/representation-theoretic route via abelian varieties
1. Formalize Hodge structures carried by exterior powers of a weight-1 structure.
2. Show that Hodge classes in low-degree tensor constructions are preserved under direct sums and symmetries.
3. Prove generatedness results for special low-dimensional cases using invariant subspaces.

Why this matters: abelian varieties are the natural first arena for nontrivial Hodge classes beyond divisors. Even partial results on formal tensor-Hodge structures would be important.

Most promising ranking:
1. **Strategy A**
2. Strategy B
3. Strategy C

Begin with A, but design definitions so B and C become plug-ins rather than rewrites.
