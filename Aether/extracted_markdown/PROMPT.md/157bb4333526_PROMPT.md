## Precise Theorem Target

Work in a finite alphabet `Σ`, a type of configurations `X`, and a closure operator on predicates or sets over `X`. The mathematically cleanest first formalization is to represent closure on `Set X`, with language semantics valued in closure-stable predicates.

### Core definitions to formalize

A **closure transition system** should include:

- `cl : Set X → Set X`
- closure axioms:
  - extensive: `A ⊆ cl A`
  - monotone: `A ⊆ B → cl A ⊆ cl B`
  - idempotent: `cl (cl A) = cl A`
- letter actions `step : X → α → X` or relational actions `δ : α → Set X → Set X`
- closure compatibility, e.g.
  - direct image preserves closure-stable semantics up to closure
  - or `δ a (cl A) ⊆ cl (δ a A)` / equality if available

Let `Acc : Set X` be the accepting region. For a word `w : List α`, define its **residual closure profile**
\[
R_w := cl\{x \mid \text{the continuation from }x\text{ after }w\text{ is accepting}\},
\]
or equivalently the closure-stable continuation semantics induced by `w`.

Then define residual equivalence:
\[
u \sim_R v \iff R_u = R_v.
\]

The key algebraic object is the finite family of reachable residuals, ordered by inclusion, with join given by closure of union:
\[
P \vee Q := cl(P \cup Q).
\]

## Main theorem statement

You should aim for a theorem of the following form, possibly split into 4–6 lemmas plus a final structure theorem.

### Mathematical statement

Let `(X, cl, Σ, δ, Acc)` be a deterministic closure-compatible transition system. Assume:

1. `cl` is extensive, monotone, idempotent.
2. Each letter action is closure-compatible.
3. The set of reachable residual closure profiles
   \[
   \mathcal R := \{R_w \mid w \in Σ^\*\}
   \]
   is finite.
4. `\mathcal R` is generated under finite join by a finite set of closure-stable residual generators.

Then:

1. residual equality `~R` is a right congruence on words;
2. acceptance factors through residual classes;
3. `\mathcal R`, with join `P ⊔ Q := cl(P ∪ Q)` and word action `P ↦ P·a`, is a finite idempotent semimodule / join-semilattice with action;
4. the join-irreducible elements `JI(\mathcal R)` determine a canonical deterministic closure automaton `A_min`;
5. `A_min` recognizes the same closure behavior and is minimal among deterministic closure-compatible recognizers;
6. every deterministic closure-compatible recognizer of the same behavior admits a unique surjective morphism onto `A_min`;
7. from any finite generating family of residual closure predicates, one can algorithmically reconstruct the state set, transition function, and acceptance map of `A_min`.

This is the closure-semantic analogue of Myhill–Nerode, but with the crucial refinement that **minimal states are extracted from the algebra of residual closures, not postulated externally**.

## Proof strategy paths

## Strategy 1: Classical Myhill–Nerode lifted through closure residuals
**Most promising for Lean and for theorem architecture.**

1. Define residual profiles `R_w` and prove suffix invariance:
   equality of residuals is preserved by appending words.
2. Build the canonical automaton on residual classes / reachable residual sets.
3. Prove language equivalence and universal quotient exactly as in Myhill–Nerode, but every step is mediated by closure compatibility and closure idempotence.

**Why this is strongest:** it leverages the classical recognizer-minimization pattern while replacing ordinary right languages by closure-stable residual predicates. This will likely let you reuse ideas from `closure_myhill_quantum_minimality` and `myhill_nerode_chronometric_minimality`.

---

## Strategy 2: Order-theoretic algebra via finite idempotent semimodules
1. Show reachable residuals form a finite join-semilattice with action of words/letters by endomorphisms.
2. Characterize states by principal residuals or join-irreducibles.
3. Use finite semilattice representation theory: every element is the join of irreducibles; transitions preserve joins; minimality follows from algebraic generation.

**Why this matters:** this is the route that makes the theorem feel new, because it identifies automata states with algebraic atoms of semantic closure. It also creates the bridge to idempotent semimodule theory and tropical algebra.

**Risk:** join-irreducibles in finite semilattices can be more technically awkward in Lean than quotient-based residual classes. Best used after the quotient automaton is built.

---

## Strategy 3: Certified reconstruction by finite saturation / abstract interpretation
1. Start from a finite generating family `G` of closure predicates.
2. Saturate under join and letter action until a fixed point is reached.
3. Prove the resulting finite table equals the reachable residual family and therefore yields the canonical automaton.

**Why this is powerful:** this gives an executable minimization pipeline, not just an existence theorem. It opens the door to code extraction and certified symbolic minimization.

**Best use:** after Strategy 1 establishes canonicity; then Strategy 3 becomes the computational corollary.
