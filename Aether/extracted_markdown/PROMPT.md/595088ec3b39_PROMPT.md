### III. PROOF STRATEGY — Three Paths

**Strategy A (Cauchy-Schwarz via Fourier Duality)** — MOST PROMISING

The proof mirrors the standard proof of the Heisenberg uncertainty principle:

1. **Lemma `cutDepth_normalWidth_fourier_duality`**: Establish that `cutDepthProfile` and `normalWidthProfile` are related by a discrete Fourier-like transform: `normalWidthProfile k = ∑ᵢ, cutDepthProfile i * ω^(i*k)` where `ω` is a root of unity. This follows from the cut-elimination dynamics: normalization width at step `k` depends on the interference pattern of all cuts at various depths.

2. **Lemma `variance_product_lower_bound`**: For any two sequences `f, g : ℕ → ℚ` related by Fourier duality, `Var(f) · Var(g) ≥ 1/4`. This is the discrete Donoho-Stark uncertainty principle. Prove it via:
   - Apply Cauchy-Schwarz to `∑ x · f(x)` and `∑ f'(x)` where `f'` is the Fourier dual
   - Key identity: `∑ x · |f(x)|² = ∑ k · |f̂(k)|²` (Parseval)
   - Integration by parts analog: `∑ x · f(x) · f'(x) = (1/2) · ∑ |f(x)|²`

3. **Lemma `proof_fourier_pair_certified`**: For a proof `π` with `π.cuts ≠ 0`, the pair `(cutDepthProfile π, normalWidthProfile π)` satisfies the Fourier duality conditions of Step 1. Prove by induction on proof structure, using the `ProofEnergyConservation` catalog theorem.

4. **Compose**: `cut_interference_uncertainty` follows from Steps 1-3.

**Strategy B (Information-Theoretic via Mutual Information)**

1. Define mutual information `I(cutDepth; normalWidth)` between cut depth and normalization width random variables.
2. Prove `I(cutDepth; normalWidth) ≥ log(2)` using `SequentVariationalPrinciple`.
3. Use the inequality `Var(X) · Var(Y) ≥ (1/4) · exp(2·I(X;Y) - 2·h(X) - 2·h(Y))`.
4. Bound differential entropies using `CutEliminationEntropy`.

**Strategy C (Contrapositive via Normalization Failure)**

1. Assume `cutDepthVariance · normalWidthVariance < 1/4`.
2. Show this implies a proof can be normalized with zero variance — a "classical" proof.
3. But `h : π.cuts ≠ 0` means the proof has genuine quantum-like interference.
4. Contradiction via `ProofEnergyConservation`: any proof with cuts requires positive variance in both measurements.
