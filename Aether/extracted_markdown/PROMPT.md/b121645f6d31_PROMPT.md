## Research Task: GL3 tropical Satake majority-vote robustness theorem for pairwise Hecke score tournaments

Research Mode: PROVE

Define and study a 3-class decision rule built from pairwise score comparisons rather than top-1/top-k aggregation. The central object is a score map
`S : α → Fin 3 → ℝ`
coming from the GL3 tropical Satake / Hecke classifier, together with the induced pairwise gaps
`gap S x i j := S x i - S x j`.

A natural robust tournament classifier on 3 labels is obtained by orienting the edge `i → j` whenever `gap S x i j > 0`, and then choosing the unique vertex with two outgoing edges when such a vertex exists. For three labels, this is exactly the strict Condorcet / Copeland winner in the transitive case. The key theorem should show that if all relevant pairwise margins are bounded away from zero by more than the perturbation budget coming from the tropical Lipschitz estimate, then the tournament winner is certified invariant under all `L∞` perturbations of radius `r`.

### Suggested Lean definitions

Work with a general input type `α` carrying a perturbation relation `Perturb : α → α → ℝ → Prop`, or, if the existing GL3 robustness files already use a concrete normed domain, specialize immediately to that domain. If possible, align with the already established certified robustness API for score functions.

A clean finite-label setup is:

```lean
def gap (S : α → Fin 3 → ℝ) (x : α) (i j : Fin 3) : ℝ :=
  S x i - S x j

def pairwiseWins (S : α → Fin 3 → ℝ) (x : α) (i : Fin 3) : ℕ :=
  ((Finset.univ.filter fun j => j ≠ i ∧ 0 < gap S x i j).card)

def isCondorcetWinner (S : α → Fin 3 → ℝ) (x : α) (i : Fin 3) : Prop :=
  ∀ j, j ≠ i → 0 < gap S x i j

def strictTournament (S : α → Fin 3 → ℝ) (x : α) : Prop :=
  ∀ i j, i ≠ j → gap S x i j ≠ 0
```

If useful, also define the minimum pairwise margin:

```lean
def minPairMargin (S : α → Fin 3 → ℝ) (x : α) : ℝ :=

      -- nonemptiness of ordered distinct pairs on `Fin 3`
```

### Precise theorem targets

The first theorem should be the sign-preservation lemma for pairwise gaps under perturbation.

```lean
theorem gap_sign_stable_of_margin
    {α : Type*}
    (S : α → Fin 3 → ℝ)
    (x x' : α) (K d r : ℝ)
    (hKd : 0 ≤ K) (hd : 0 ≤ d) (hr : 0 ≤ r)
    (hgap :
      ∀ i j : Fin 3, |gap S x' i j - gap S x i j| ≤ 2 * K * d * r)
    (hmargin :
      ∀ i j : Fin 3, i ≠ j → 2 * K * d * r < |gap S x i j|) :
    ∀ i j : Fin 3, i ≠ j → (0 < gap S x i j ↔ 0 < gap S x' i j)
```

This is the core analytic step: if a real number is perturbed by less than its absolute value, its sign cannot change.

Then prove the purely combinatorial tournament lemma specialized to `Fin 3`.

```lean
theorem condorcet_winner_unique_on_Fin3
    (S : α → Fin 3 → ℝ) (x : α)
    (hstrict : strictTournament S x) :
    ∃! i : Fin 3, isCondorcetWinner S x i
```

This theorem is only true if the tournament is transitive, not for an arbitrary strict tournament on three vertices. So the right formulation is probably not the one above. Instead, prove a more accurate structural lemma:

```lean
theorem exists_condorcet_winner_iff_no_cycle_Fin3
    (S : α → Fin 3 → ℝ) (x : α) :
    (∃ i : Fin 3, isCondorcetWinner S x i) ↔
      ¬ ((0 < gap S x 0 1 ∧ 0 < gap S x 1 2 ∧ 0 < gap S x 2 0) ∨
         (0 < gap S x 1 0 ∧ 0 < gap S x 0 2 ∧ 0 < gap S x 2 1))
```

However, an even cleaner route avoids tournament-existence issues entirely: assume a designated class `c` beats both rivals, and prove this property is preserved. Then derive Copeland-score maximality from those two inequalities.

```lean
theorem condorcet_stable_of_pairwise_margins
    {α : Type*}
    (S : α → Fin 3 → ℝ)
    (x x' : α) (c : Fin 3) (K d r : ℝ)
    (hgap :
      ∀ i j : Fin 3, |gap S x' i j - gap S x i j| ≤ 2 * K * d * r)
    (hmargin :
      ∀ j : Fin 3, j ≠ c → 2 * K * d * r < gap S x c j) :
    isCondorcetWinner S x' c
```

A useful strengthening is to show not just that `c` remains a Condorcet winner, but that its Copeland score remains exactly `2`.

```lean
theorem pairwiseWins_eq_two_of_condorcet
    (S : α → Fin 3 → ℝ) (x : α) (c : Fin 3)
    (hcond : isCondorcetWinner S x c) :
    pairwiseWins S x c = 2
```

and then

```lean
theorem copeland_stable_of_pairwise_margins
    {α : Type*}
    (S : α → Fin 3 → ℝ)
    (x x' : α) (c : Fin 3) (K d r : ℝ)
    (hgap :
      ∀ i j : Fin 3, |gap S x' i j - gap S x i j| ≤ 2 * K * d * r)
    (hmargin :
      ∀ j : Fin 3, j ≠ c → 2 * K * d * r < gap S x c j) :
    pairwiseWins S x' c = 2
```

Finally, package this into the robustness theorem matching the existing tropical certification style. If the existing GL3 file already provides a theorem of the shape
`|S x' i - S x i| ≤ K * d * r`,
then derive the gap bound internally by subtraction.

A likely final statement is:

```lean
theorem robust_tournament_winner_of_GL3_margin
    {α : Type*}
    (S : α → Fin 3 → ℝ)
    (x x' : α) (c : Fin 3) (K d r : ℝ)
    (hscore :
      ∀ i : Fin 3, |S x' i - S x i| ≤ K * d * r)
    (hmargin :
      ∀ j : Fin 3, j ≠ c → 2 * K * d * r < S x c - S x j) :
    isCondorcetWinner S x' c
```

where the notation in `hmargin` should be adjusted to `S x c` / `S x j` if `S x` is viewed as a vector, or `S x c` and `S x j` if curried as above.

A stronger “all edges preserved” version is also worth proving:

```lean
theorem strict_tournament_orientation_stable
    {α : Type*}
    (S : α → Fin 3 → ℝ)
    (x x' : α) (K d r : ℝ)
    (hgap :
      ∀ i j : Fin 3, |gap S x' i j - gap S x i j| ≤ 2 * K * d * r)
    (hmargin :
      ∀ i j : Fin 3, i ≠ j → 2 * K * d * r < |gap S x i j|) :
    ∀ i j : Fin 3, i ≠ j →
      (0 < gap S x i j ↔ 0 < gap S x' i j)
```

From this, any tournament functional depending only on the orientation of the three edges is invariant under perturbation.

### Concrete proof strategy

1. **Derive pairwise gap perturbation from coordinatewise score perturbation.**  
   Starting from
   `|S x' i - S x i| ≤ K * d * r` and `|S x' j - S x j| ≤ K * d * r`,
   prove
   ```lean
   |gap S x' i j - gap S x i j| ≤ 2 * K * d * r
   ```
   by rewriting
   ```lean
   gap S x' i j - gap S x i j = (S x' i - S x i) - (S x' j - S x j)
   ```
   and applying `abs_sub_le` / triangle inequality. This is the exact place where the factor `2` enters.

2. **Use the real-analysis sign stability lemma.**  
   Prove a standalone lemma:
   ```lean
   theorem sign_preserved_of_abs_diff_lt_abs
       {a b ε : ℝ}
       (h1 : |b - a| ≤ ε)
       (h2 : ε < |a|) :
       (0 < a ↔ 0 < b)
   ```
   The proof should split on `0 < a` versus `a < 0` using `lt_trichotomy a 0`, then show `b` cannot cross zero because that would force `|b-a| ≥ |a|`. Variants using
   `abs_lt`, `neg_lt_iff_pos_add`, or `linarith` after suitable inequalities may be effective.

3. **Preserve designated winning edges from a class `c`.**  
   Given `∀ j ≠ c, 2 * K * d * r < gap S x c j`, combine Step 1 and Step 2 to show
   `0 < gap S x' c j` for all `j ≠ c`. This directly yields `isCondorcetWinner S x' c`. This route avoids any difficult global tournament classification.

4. **Connect Condorcet winner to Copeland score on `Fin 3`.**  
   Show that if `c` beats both other vertices, then `pairwiseWins S x c = 2`, while every other vertex has at most one win. Since `Fin 3` has exactly two opponents per class, cardinality arguments are straightforward with `Finset.univ`. You may need small helper lemmas about `Fin 3`, e.g. that
   `((Finset.univ.filter fun j => j ≠ c).card) = 2`.

5. **Optional global orientation theorem.**  
   If you prove the stronger all-pairs sign-preservation theorem, then derive invariance of any edge-based tournament winner functional by extensionality: if all three pairwise signs are unchanged, then the output of any deterministic decision rule built from those signs is unchanged. This provides a reusable API for future multiclass aggregation rules beyond Copeland.

### Lean-specific implementation advice

- Prefer `Fin 3` over ad hoc label types; it makes exhaustive finite arguments manageable.
- For pairwise comparisons, it may be cleaner to use `DecidableEq (Fin 3)` and `Finset.univ.filter`.
- Helpful lemmas likely include:
  - `abs_sub_le`
  - `abs_nonneg`
  - `sub_eq_add_neg`
  - `by nlinarith` / `linarith` once absolute values are eliminated
  - finite-cardinality lemmas for `Finset.filter` on `Finset.univ`
- For `Fin 3`, direct case splits via `fin_cases i` can simplify awkward combinatorial arguments.
- If uniqueness of winner is needed, derive it from the strict inequalities `gap S x c j > 0` for both rivals `j ≠ c`; another class cannot also beat `c`.

### Why this matters

This theorem gives a genuinely new robust multiclass certification principle for GL3 tropical Satake / Hecke score maps: robustness is transferred not merely to top-1 or top-k selectors, but to a nontrivial pairwise social-choice aggregation functional. The key novelty is that the classifier depends on the sign pattern of score differences, so the right certified quantity is the minimum pairwise margin, not just a single top-vs-runner-up gap. Formally establishing this bridge matters for the broader program because it isolates a reusable mechanism:

- tropical Lipschitz control on scores  
  ⇒ Lipschitz control on pairwise gaps  
  ⇒ sign stability of all decisive comparisons  
  ⇒ invariance of tournament-based multiclass decisions.

This is an attractive intermediate theorem toward richer tropical Hecke decision architectures, and it should integrate well with future work on higher-rank tropical Satake classifiers, robust voting/committee schemes, and combinatorial decision layers built from pairwise margin data.
