## Precise Target Theorem Statements

### Theorem A: Tropical Sheaf Sampling Injectivity

Formal mathematical statement:

Let `X` be finite, `F` a finite cellular sheaf of finitely generated idempotent `K`-semimodules, and let `Δ₀ : C⁰(X;F) → C⁰(X;F)` be the tropical sheaf Laplacian. Suppose `PW_λ(F)` is the subsemimodule of global sections whose tropical spectral value is at most `λ`. If `S` is a `λ`-dominating set and every section `s` vanishing on `S` satisfies the certified tropical Poincaré inequality
\[
\mathsf{Rayleigh}_\Delta(s) > \lambda,
\]
then the restriction map
\[
\Gamma(X,F) \to F(S)
\]
is injective on `PW_λ(F)`.

This is the tropical sheaf analogue of a spectral uniqueness/sampling theorem.

### Suggested Lean 4 signature

Use this as the architectural target, adjusting names to local conventions:

```lean
theorem tropical_sheaf_sampling_injective
  {K X : Type _} [TotallyOrderedIdempotentSemifield K]
  [FiniteCellComplex X]
  (F : CellularSheaf X K)
  [FiniteSheafStalks F] [FGIdempotentStalks F]
  (λ : K)
  (S : Finset X)
  (hdom : IsLambdaDominating F λ S)
  (hpoincare :
    ∀ s : GlobalSection F,
      restrictCells F S s = 0 →
      TropicalBandlimited F λ s →
      False) :
  Function.Injective
    (fun s : {s : GlobalSection F // TropicalBandlimited F λ s} =>
      restrictCells F S s)
```

A more conceptual version, if you define a kernel-exclusion hypothesis:

```lean
theorem tropical_sheaf_sampling_injective'
  {K X : Type _} [TotallyOrderedIdempotentSemifield K]
  [FiniteCellComplex X]

```

The theorem is conceptually simple: **no nonzero λ-bandlimited section can vanish on the sampling set**.

### Theorem B: Certified Reconstruction by Tropical Resolvent Iteration

Formal mathematical statement:

Assume the hypotheses of Theorem A. Then for every sample vector `y` in the image of restriction on `PW_λ(F)`, there exists a canonical reconstruction sequence
\[
s_{n+1} = \mathcal{R}_{\lambda,S,y}(s_n)
\]
defined by a monotone tropical resolvent/update operator, such that:
1. `s_n` stabilizes after finitely many antichain steps,
2. the stable value is the unique bandlimited global section restricting to `y`,
3. reconstruction is order-minimal/canonical among all feasible extensions.

### Suggested Lean 4 signature

```lean
theorem tropical_sheaf_bandlimited_reconstruction
  {K X : Type _} [TotallyOrderedIdempotentSemifield K]
  [FiniteCellComplex X]
  (F : CellularSheaf X K)
  [FiniteSheafStalks F] [FGIdempotentStalks F]
  (λ : K)
  (S : Finset X)
  (hcert : CertifiedSamplingData F λ S)
  (y : SampleAssignment F S)
  (hy : IsBandlimitedSample F λ S y) :
  ∃ s : GlobalSection F,
    TropicalBandlimited F λ s ∧
    restrictCells F S s = y ∧
    IsCanonicalReconstruction F λ S y s ∧
    ∃ N : ℕ, ∀ n ≥ N, resolventIterate F λ S y n = s
```

If finite stabilization is hard at first, first prove eventual periodicity or monotone stationarity in finite height, then strengthen to finite stabilization using finite generation / ACC on antichains.

### Theorem C: Stability Under Valuation-Bounded Perturbations

Formal mathematical statement:

Let `F` and `F'` be cellular sheaves on the same finite cell complex with the same stalk semimodule types, and suppose their restriction maps differ by a uniformly bounded congruence/valuation perturbation of size at most `ε`. Then the canonical reconstructions `Rec_F(y)` and `Rec_F'(y')` of corresponding bandlimited samples satisfy a tropical Lipschitz/condition-radius bound
\[
d_{\mathrm{trop}}(\mathrm{Rec}_F(y), \mathrm{Rec}_{F'}(y')) \le \Phi(\epsilon,\lambda,\kappa),
\]
where `κ` is the certified tropical condition radius (or equivalent modulus extracted from the Poincaré/spectral gap certificate).

## Definitions You Should Introduce Carefully

### 1. Tropical Laplacian
You need a workable finite combinatorial notion, not a philosophically perfect one. A pragmatic route:

- define `Cochain₀ F := Π cell₀, F.stalk cell₀` with compatibility for global sections
- define `d₀` using sheaf restriction maps across incidences
- define `d₀†` using residuation / greatest preimage bound
- define `Δ₀ := d₀† ∘ d₀` if the full Hodge-style sum is too heavy initially

Then later generalize to
```lean
def tropicalLaplacian (k : ℕ) : Cochain F k → Cochain F k := ...
```

A degree-0 theorem is already a substantial breakthrough.

### 2. Bandlimitedness
Because eigenspaces over idempotent semirings are subtle, define bandlimitedness via one of:

- **Rayleigh sublevel condition**:
  `TropicalRayleigh F s ≤ λ`
- **finite spectral filtration generated by Δ-iterates**
- **annihilation by a tropical polynomial filter**
- **membership in a certified low-complexity decomposition class**

The Rayleigh/sublevel route is likely easiest to formalize.

### 3. Sampling set
A set `S` should be “sampling” if every nonzero section vanishing on `S` has tropical energy above `λ`. This avoids needing a full density theorem.

### 4. Reconstruction operator
A good candidate is the least fixed point of a monotone operator enforcing:
- sample consistency on `S`
- Laplacian-energy cutoff / bandlimit certificate off `S`

Then prove finite convergence using:
- finite generation of stalk semimodules
- monotonicity
- finite height / ACC / antichain stabilization

## Proof Strategy Architecture

You must pursue at least two proof paths and choose the strongest.

### Strategy A: Kernel-exclusion via tropical Poincaré gap
This is likely the most promising for Theorem A.

1. Define the subsemimodule
   \[
   \ker(\mathrm{res}_S) = \{ s : \Gamma(X,F) \mid s|_S = 0 \}.
   \]
2. Show that if a nonzero bandlimited section lies in `ker(res_S)`, then its tropical Rayleigh value is `≤ λ`.
3. Use the certified Poincaré hypothesis saying every nonzero element of `ker(res_S)` has value `> λ`.
4. Contradiction. Hence no nonzero bandlimited section vanishes on `S`, giving injectivity.

Why promising: it avoids delicate spectral decomposition and only needs a robust “energy gap on the unsampled kernel.”

### Strategy B: Finite tropical decomposition + support separation
This is likely strongest for reconstruction and finite convergence.

1. Use `certified_finite_tropical_decomposition` to express any bandlimited section as a finite tropical sum of low-frequency atoms.
2. Prove that restriction to `S` separates these atoms under the `λ`-dominating hypothesis.
3. Reconstruct by selecting the unique minimal coefficient vector compatible with samples.
4. Translate this coefficient selection into a monotone min-plus iteration and prove termination by finite antichain descent/stabilization.

Why promising: it gives an explicit algorithm, not just an existential uniqueness theorem.

### Strategy C: Order-theoretic fixed point / residuated inverse
This is the best path for stability.

1. Model reconstruction as the least fixed point of a monotone operator `T`.
2. Show `T` is inflationary/deflationary in the appropriate order and preserves certified bandlimitedness.
3. Prove finite stabilization using finite generation of stalks or a noetherian order on feasible states.
4. Under perturbation, compare the two operators `T` and `T'` and propagate the difference through monotone iteration using a condition-radius estimate.

Why promising: this is the natural idempotent analogue of resolvent inversion and yields stability almost automatically once operator monotonicity is established.

**Recommendation:** Use Strategy A to get injectivity fast, Strategy B to produce canonical reconstruction, and Strategy C to prove perturbation stability.
