## Assignment: Tropical Language Evolution: Min-Plus Phylogenetics and Glottochronology

Mode: `prove`

This project should not merely imitate biological phylogenetics in tropical notation. The breakthrough target is to show that a rigorously defined min-plus geometry on lexical data simultaneously supports:

1. an intrinsic pairwise language divergence metric,
2. an additive tree reconstruction principle,
3. a glottochronological time estimator as a tropical path length,
4. and a uniqueness theorem for the induced phylogenetic object as a min-plus Steiner tree under suitable exactness hypotheses.

If successful, this opens a new formal bridge between tropical geometry, metric phylogenetics, historical linguistics, and algorithmic reconstruction. The point is not “apply tropical math to language”; it is to show that the combinatorial rigidity of min-plus algebra naturally explains why tree-like language evolution is recoverable from lexical loss/innovation data.

### Core Definitions to Introduce in Lean

Work with a finite index type of lexical items `ι` and represent a language as a weight vector `ι → ℝ`, where `L i` is the “cost” or divergence score of lexical item `i`. Define tropical distance by coordinatewise absolute difference aggregated via `Finset.sup` or via additive path metrics depending on which theorem is targeted.

A promising concrete setup:

```lean
def TropLang (ι : Type) := ι → ℝ

def tropicalSegmentCost {ι : Type} [Fintype ι] [DecidableEq ι]
    (L₁ L₂ : TropLang ι) : ℝ :=
  Finset.sup Finset.univ (fun i => |L₁ i - L₂ i|)

def tropicalLexCost {ι : Type} [Fintype ι] [DecidableEq ι]
    (L₁ L₂ : TropLang ι) : ℝ :=
  ∑ i in Finset.univ, min (L₁ i) (L₂ i)

def tropicalDivergence {ι : Type} [Fintype ι] [DecidableEq ι]
    (L₁ L₂ : TropLang ι) : ℝ :=
  ∑ i in Finset.univ, |L₁ i - L₂ i|
```

You may need two notions:
- `tropicalSegmentCost` for max-plus / tropical convexity arguments,
- `tropicalDivergence` for additive phylogenetic reconstruction and dating.

That is not redundancy; it reflects two geometric layers:
- tropical convex geometry controls medians/Steiner points,
- additive `L¹`-type costs control recoverable divergence times.

### Primary Breakthrough Theorem A: Tropical divergence is an optimal phylogenetic distance

Formalize a finite rooted tree with edge lengths and leaf-labeling by languages. Define the path metric on leaves. Then prove that if lexical evolution is coordinatewise min-plus additive along edges, the induced pairwise tropical divergence equals the tree path metric on leaves.

A precise target:

```lean
theorem tropical_divergence_eq_tree_distance
  {ι V : Type}
  [Fintype ι] [DecidableEq ι]
  [Fintype V] [DecidableEq V]
  (T : SimpleGraph V)
  (root : V)
  (w : Sym2 V → ℝ)
  (lang : V → TropLang ι)
  (isTree : T.IsTree)
  (hw_nonneg : ∀ e, 0 ≤ w e)
  (h_evolution :
    ∀ {u v : V}, T.Adj u v →
      ∃ δ : TropLang ι, (∀ i, 0 ≤ δ i) ∧
        (∀ i, lang v i = lang u i + δ i ∨ lang u i = lang v i + δ i))
  (hleaf_exact :
    ∀ a b : V, ¬ T.Adj a b → True) :
  ∀ a b : V,
    tropicalDivergence (lang a) (lang b) = treePathDist T w a b
```

This exact signature will likely need refinement depending on your chosen tree/path infrastructure in Mathlib. If `SimpleGraph` path metric machinery is inconvenient, define a bespoke finite tree structure with unique path and path-length sum. The theorem’s real content is:

> For languages evolving by coordinatewise nonnegative additive lexical innovations/losses on a tree, the sum of coordinatewise absolute differences between leaf lexical profiles equals the additive path length between those leaves.

This is the formal phylogenetic reconstruction theorem. It says tropical divergence is not merely heuristic similarity; it is the exact intrinsic distance of the historical tree model.

### Primary Breakthrough Theorem B: Glottochronology is recovered as tropical distance estimation

Once Theorem A is in place, define a clock hypothesis: each edge contributes uniform expected lexical drift rate `ρ : ℝ`. Then prove that divergence time is recovered by normalized tropical divergence.

Precise target:

```lean
def glottoTimeEstimate {ι : Type} [Fintype ι] [DecidableEq ι]
    (ρ : ℝ) (L₁ L₂ : TropLang ι) : ℝ :=
  tropicalDivergence L₁ L₂ / ρ

theorem glottochronology_from_tropical_divergence
  {ι V : Type}
  [Fintype ι] [DecidableEq ι]
  [Fintype V] [DecidableEq V]
  (T : SimpleGraph V)
  (w : Sym2 V → ℝ)
  (lang : V → TropLang ι)
  (ρ : ℝ)
  (hw_nonneg : ∀ e, 0 ≤ w e)
  (hρ : 0 < ρ)
  (h_clock : ∀ a b : V, tropicalDivergence (lang a) (lang b) = ρ * treePathDist T w a b) :
  ∀ a b : V,
    glottoTimeEstimate ρ (lang a) (lang b) = treePathDist T w a b
```

This theorem is conceptually sharp: glottochronology is not introduced as an external statistical formula, but emerges as a normalization of tropical path length. This is the right level of ambition.

### Primary Breakthrough Theorem C: Tropical phylogenetic tree as unique min-plus Steiner tree

This is the deepest theorem and likely the most field-opening one. Restrict to a realizable exact-data regime: a finite family of languages whose pairwise tropical divergences satisfy the four-point condition and whose internal ancestral states are tropical medians. Then prove uniqueness of the minimizing Steiner tree.

A formal target, perhaps in stages:

```lean
def steinerCost {ι V : Type} [Fintype ι] [DecidableEq ι]
    (T : SimpleGraph V) (lang : V → TropLang ι) : ℝ :=
  ∑ e in T.edgeFinset, tropicalDivergence (lang (Sym2.Mem.left e)) (lang (Sym2.Mem.right e))

def realizesLeafData {ι V α : Type} [Fintype ι] [DecidableEq ι]
    (leaves : Finset α) (embed : α → V) (obs : α → TropLang ι) (lang : V → TropLang ι) : Prop :=
  ∀ x ∈ leaves, lang (embed x) = obs x

theorem unique_tropical_steiner_tree_of_four_point
  {ι α V : Type}
  [Fintype ι] [DecidableEq ι]
  [Fintype α] [DecidableEq α]
  [Fintype V] [DecidableEq V]
  (obs : α → TropLang ι)
  (hleafMetric :
    ∀ a b c d : α,
      tropicalDivergence (obs a) (obs b) + tropicalDivergence (obs c) (obs d)
        ≤ max
            (tropicalDivergence (obs a) (obs c) + tropicalDivergence (obs b) (obs d))
            (tropicalDivergence (obs a) (obs d) + tropicalDivergence (obs b) (obs c)))
  :
  ∃! (T : PhyloTree α),
    T.realizes obs ∧
    ∀ T', T'.realizes obs → steinerCost T.graph T.lang ≤ steinerCost T'.graph T'.lang
```

You will probably need to define `PhyloTree α` yourself. That is acceptable and likely necessary. The true theorem should likely be staged:

1. four-point condition implies existence of an additive tree,
2. additive tree implies Steiner minimality,
3. exact tropical median condition implies uniqueness of Steiner realization.

This decomposition is mathematically cleaner and much more Lean-friendly.

### Recommended Intermediate Theorems

These should be proved first and used as scaffolding.

#### 1. Tropical divergence is a metric
```lean
theorem tropicalDivergence_nonneg
  {ι : Type} [Fintype ι] [DecidableEq ι] (L₁ L₂ : TropLang ι) :
  0 ≤ tropicalDivergence L₁ L₂

theorem tropicalDivergence_symm
  {ι : Type} [Fintype ι] [DecidableEq ι] (L₁ L₂ : TropLang ι) :
  tropicalDivergence L₁ L₂ = tropicalDivergence L₂ L₁

theorem tropicalDivergence_triangle
  {ι : Type} [Fintype ι] [DecidableEq ι] (L₁ L₂ L₃ : TropLang ι) :
  tropicalDivergence L₁ L₃ ≤ tropicalDivergence L₁ L₂ + tropicalDivergence L₂ L₃
```

These are not glamorous, but they are the load-bearing beams. They also make the phylogenetic distance statement mathematically serious.

#### 2. Coordinatewise tropical median minimizes total divergence
For three languages, define the coordinatewise median and show it minimizes sum of distances. This is the right finite-dimensional tropical analogue of an ancestral reconstruction principle.

```lean
def coordMedian3 {ι : Type} [LinearOrder ℝ]
    (A B C : TropLang ι) : TropLang ι :=
  fun i => max (min (A i) (B i)) (min (max (A i) (B i)) (C i))

theorem coordMedian3_minimizes
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (A B C X : TropLang ι) :
  tropicalDivergence A (coordMedian3 A B C) +
    tropicalDivergence B (coordMedian3 A B C) +
    tropicalDivergence C (coordMedian3 A B C)
  ≤ tropicalDivergence A X + tropicalDivergence B X + tropicalDivergence C X
```

This theorem is a gateway to Steiner-tree arguments and ancestral state reconstruction.

#### 3. Four-point condition from tree-realizable tropical divergence
```lean
theorem tropical_four_point_of_tree_model
  {ι V : Type}
  [Fintype ι] [DecidableEq ι]
  [Fintype V] [DecidableEq V]
  (T : PhyloTree V ι) :
  ∀ a b c d : V,
    tropicalDivergence (T.lang a) (T.lang b) +
      tropicalDivergence (T.lang c) (T.lang d)
    ≤ max
        (tropicalDivergence (T.lang a) (T.lang c) + tropicalDivergence (T.lang b) (T.lang d))
        (tropicalDivergence (T.lang a) (T.lang d) + tropicalDivergence (T.lang b) (T.lang c))
```

This is the certification theorem that your tropical model genuinely lands inside phylogenetic metric geometry.

### Proof Strategy Paths

#### Strategy A: Additive metric first, Steiner second
Most promising.

1. Define `tropicalDivergence` as finite `L¹` distance on lexical profiles and prove it is a metric.
2. Formalize a tree-evolution model where each edge contributes a nonnegative lexical drift vector, and prove path additivity of divergence.
3. Derive the four-point condition and then prove the realized tree is Steiner-minimal; add a median exactness hypothesis to get uniqueness.

Why this is most promising: Lean handles finite sums and absolute-value inequalities much more robustly than abstract tropical convexity at first pass. This route gets you a certified theorem with substantial content quickly.

#### Strategy B: Tropical convexity and median geometry
More conceptually elegant, harder technically.

1. Define tropical convex combinations / coordinatewise minima structure on lexical profiles.
2. Show ancestral nodes are tropical medians minimizing total divergence to descendants.
3. Reconstruct the entire phylogenetic tree as the unique tropical median closure of the leaf set, then identify this closure with the Steiner tree.

Why this matters: if it works, it gives a genuinely new geometric language for historical linguistics. But expect more custom definitions and more proof engineering.

#### Strategy C: Four-point characterization as the central theorem
Best if tree infrastructure is already available.

1. Prove directly that tropical divergence matrices arising from your model satisfy Buneman’s four-point condition.
2. Invoke or formalize additive tree reconstruction from four-point metrics.
3. Conclude uniqueness/minimality of the phylogenetic tree and derive glottochronology as a corollary.

Why useful: this aligns with classical phylogenetics and maximizes cross-domain credibility. The challenge is whether Mathlib has enough finite metric-tree reconstruction machinery; if not, you must build it.

1. **Metric phylogenetics**: The four-point condition and additive tree metrics are the exact classical bridge. This is what prevents the project from becoming metaphorical.
2. **Tropical geometry**: Coordinatewise `min` and tropical distributivity encode ancestral reconstruction and lexical inheritance.

4. **Optimization / network design**: The Steiner-tree uniqueness theorem places language evolution into exact combinatorial optimization, not just descriptive modeling.
5. **Computational historical linguistics**: Once formalized, this yields certified reconstruction algorithms and correctness theorems for dating and tree inference.
