## Primary theorem target: tropical composition is 1-Lipschitz in sup norm

Define a tropical proof-combinator on finite families as max-aggregation after additive weighting. Then prove that changing the input scores by at most `ε` changes the aggregate by at most `ε`. This is the right first breakthrough because it turns tropical proof interpretation into a **stable semantics**, not merely an algebraic curiosity.

### Precise mathematical statement
For `n : ℕ`, weights `w : Fin n → ℝ`, and score functions `x y : Fin n → ℝ`, define
\[
T_w(x) := \max_{i : \mathrm{Fin}\ n} (w_i + x_i).
\]
Then:
\[
\forall n,\ \forall w\,x\,y,\quad
|T_w(x) - T_w(y)| \le \max_i |x_i - y_i|.
\]

This theorem says tropical proof aggregation is non-expansive under perturbation. In Curry–Howard language: **proof interpretation is stable under bounded perturbation of premises**. In neural language: **max-plus routing is robust**. In optimization language: **support functions are 1-Lipschitz in the sup norm**.

### Lean 4 type signature target
A very plausible formal target is:


## Proof strategy architecture

### Strategy A: direct order-theoretic proof via maximizing indices
Most promising.

1. Define `tropicalAgg` using `Finset.univ.sup'`.
2. Show pointwise:
   \[
   w_i + x_i \le (w_i + y_i) + ε
   \]
   whenever `|x i - y i| ≤ ε`.
3. Take suprema over `i` to derive
   \[
   tropicalAgg\ w\ x \le tropicalAgg\ w\ y + ε.
   \]
4. Swap `x` and `y` to get the reverse inequality.
5. Conclude the absolute value bound using `abs_sub_le_iff`.

Why this is best: it is elementary, robust in Lean, and scales immediately to `tropicalSelect` and `tropicalReluAgg`.

### Strategy B: factor through generic finite sup non-expansiveness
More abstract, potentially more reusable.

1. Prove a generic lemma:
   ```lean
   theorem sup'_le_sup'_of_pointwise
   ```
   for functions on `Fin n`.
2. Instantiate it with `fun i => w i + x i`.
3. Derive a reusable “sup of ε-close families is ε-close” theorem.
4. Use that theorem throughout `TropicalCurryHoward`.

Why it matters: this turns the current project into an extensible library of tropical stability lemmas. It is slightly more setup-heavy but much more revolutionary for future work.

### Strategy C: encode as support functions / convexity
Most conceptually beautiful, but least likely to be fastest.

1. Interpret `tropicalAgg w x` as a support-function-like max of affine functionals.
2. Use the fact that support functions are 1-Lipschitz in the sup norm.
3. Formalize the finite-dimensional special case directly in Lean.

Why to consider it: this creates a bridge to convex analysis and idempotent functional analysis. Even if not fully completed this cycle, document it in `FUTURE_DIRECTIONS.md`.
