## What Was Created

### 1. Lean 4 Formalization (`Pythagorean/TreeFactoring/Core.lean`)
**17 theorems, all machine-verified with zero `sorry` statements.** Key results:

- **`trivial_triple_is_pyth`**: For any odd N, (N, (N²−1)/2, (N²+1)/2) is a valid Pythagorean triple
- **`diff_of_squares`**: The core identity N² + b² = c² ⟹ (c−b)(c+b) = N²
- **`divisor_pair_to_triple`**: Same-parity divisor pairs biject with Pythagorean triples
- **`inv_B1/B2/B3_preserves`**: All three inverse Berggren matrices preserve the Pythagorean property
- **`parent_hyp_decrease`**: Descent terminates — parent hypotenuse satisfies 0 < c' < c
- **`inv_B1/B2/B3_comp_B1/B2/B3`**: Forward-inverse round-trip is identity (component-wise)
- **`factor_from_gcd`**: Non-trivial GCD extraction yields factors of N
- **`semiprime_gcd`**: For N = p·q, gcd(p, N) = p
- **`inv_B1_B2_exclusive`**: At most one inverse map gives positive components (parent uniqueness)
- **`inv_B1/B2/B3_lorentz`**: All inverses preserve the Lorentz form a² + b² − c²

The file also includes a working `factorDescent` algorithm verified via `#eval` on examples: 15→(3,5), 77→(7,11), 143→(11,13), 323→(17,19), 10403→(101,103).

Only standard axioms used: `propext`, `Classical.choice`, `Quot.sound`.
