### Generation Scripts
All Python source files are in `Textbook/`:
- `generate_final.py` — Main generator (run to regenerate the PDF)
- `expand_content.py` — Extended chapter content
- `deep_content.py` — Deep mathematical explorations
- `extra_content.py` — Exercises, historical notes, connections, worked examples
