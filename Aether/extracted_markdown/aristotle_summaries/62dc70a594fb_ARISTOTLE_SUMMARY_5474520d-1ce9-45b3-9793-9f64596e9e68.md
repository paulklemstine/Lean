## Berggren Generalization to Pythagorean Quadruples — Complete Research Package

### The Answer

**No, the Berggren tree does not generalize to Pythagorean quadruples.** The obstruction is group-theoretic and fundamental:

- For **triples** (a² + b² = c²): The symmetry group O(2,1;ℤ) is **virtually free** — by Bass-Serre theory, it acts on a tree, which IS the Berggren tree. Three matrices from a single root (3,4,5) generate everything.

- For **quadruples** (a² + b² + c² = d²): The symmetry group O(3,1;ℤ) is **NOT virtually free** — it contains ℤ² as a subgroup (two independent commuting parabolic elements). By Stallings' theorem, no tree action exists. No finite set of matrices from any single root can generate all primitive quadruples.

**What does generalize**: The Lorentz form, the null cone interpretation, integer Lorentz transformations, and the **quaternionic parametrization** (m,n,p,q) → (m²+n²-p²-q², 2(mq+np), 2(nq-mp), m²+n²+p²+q²), which always produces valid quadruples. But this parametrization is many-to-one and does not yield a tree.

**Computational evidence**: 13 candidate matrices from (1,2,2,3) reach only 82.6% of primitive quadruples with d ≤ 50 — 15 are permanently unreachable, confirming the theoretical obstruction.
