### Novel Mathematical Structure
Introduced the **EML Approximation Filtration** — a depth-indexed algebraic filtration of the function space generated by EML (Exponential-Multiplicative-Logarithmic) expressions. The EML language uses a single transcendental primitive `eml(a, b) = a · exp(b)` combined with field operations. The filtration stratifies computable functions by their transcendental complexity.

1. **Filtration Monotonicity & Field Closure** — Each level is closed under +, ×, negation; higher levels contain lower ones.
2. **Strict Depth Hierarchy** — The `expRank` invariant proves `expRank(e) ≤ emlDepth(e)`, and the canonical `iterExp(n)` has `expRank = n`, so depth n is necessary and sufficient.

4. **Size Decomposition** — `size = leafCount + fieldCount + emlCount` (exact structural decomposition).

7. **Canonical Construction** — `emlExprIterExp(n)` has size `2n+1`, depth `n`, expRank `n`, `n+1` leaves, `n` eml nodes, 0 field ops.
8. **Composition Bound** — `f ∈ Level(d₁), g ∈ Level(d₂) ⟹ f∘g ∈ Level(d₁+d₂)`.
