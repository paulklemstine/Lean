### Consolidation

Each category includes a **`_Consolidated.lean`** file that merges all individual files into a single organized file with section headers. This provides a one-file overview of each entire domain — 20 consolidated files total.

### Files Created/Updated
- **`Theorems/`** — New organized directory with 674 files (654 source + 20 consolidated)
- **`Theorems/CATALOG.md`** — Full catalog with stats, directory mapping, and organization details
- **`README.md`** — Updated with new structure and category table
- **`lakefile.toml`** — Updated with `Theorems` library target

### What was merged
73 original directories were consolidated into 18 categories. For example:
- 10 physics-related dirs → `Theorems/Physics/`
- 20+ exploration/speculative dirs → `Theorems/Exploration/`
- 5 factoring dirs → `Theorems/Factoring/`
- Oracle + OracleCouncil + OracleResearchLab → `Theorems/OracleTheory/`

Original source directories are preserved for reference.
