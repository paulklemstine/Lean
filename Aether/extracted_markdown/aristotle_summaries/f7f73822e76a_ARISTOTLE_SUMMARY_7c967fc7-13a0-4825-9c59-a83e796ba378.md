### What the script does
The Python script replaces standard linear layers in a 32B-parameter transformer with a "TriResonant Linear" reparameterization that decomposes each weight matrix column into:
1. **Direction** — a unit vector on a learned 2-sphere within a 3D subspace of ℝᴺ
2. **Magnitude** — a per-column scale factor

The direction is constructed by composing four classical mathematical operations: stereographic projection, Gram–Schmidt orthogonalization, and spherical coordinate interpolation.
