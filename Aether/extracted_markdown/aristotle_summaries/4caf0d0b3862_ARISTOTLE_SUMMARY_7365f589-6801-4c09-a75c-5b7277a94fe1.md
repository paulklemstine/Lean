**Core impossibility results:**
1. **`no_injective_compression`** — No injection exists from `{0,1}^n → {0,1}^m` when `m < n` (pigeonhole principle). This is the mathematical death of universal compression.
2. **`no_universal_compression`** — Corollary: no `n`-bit string can be universally compressed to `(n-1)` bits.
3. **`incompressible_strings_lower_bound`** — At least fraction `1 - 2^{-k}` of all `n`-bit strings cannot be compressed by `k` bits (99%+ for k ≥ 7).
4. **`incompressible_fraction_bound`** — Complementary bound: `2^(n-k+1) ≤ 2^n`.
5. **`card_shorter_strings`** — Geometric series: `∑_{i=0}^{n-1} 2^i = 2^n - 1`.

**Achievable compression (codebooks):**
6. **`Codebook` structure** — Formal definition of lossless encode/decode pairs.
7. **`Codebook.encode_injective`** — Every codebook has injective encoding.
8. **`codebook_exists_of_card_le`** — If `|Source| ≤ |Code|`, a lossless codebook exists. This proves source-specific O(1) compression is always achievable.

**Information theory foundations:**
9. **`kraft_inequality_nat`** — Kraft's inequality for prefix-free codes.
10. **`shannonEntropy_nonneg`** — Shannon entropy is nonnegative for all valid distributions.
