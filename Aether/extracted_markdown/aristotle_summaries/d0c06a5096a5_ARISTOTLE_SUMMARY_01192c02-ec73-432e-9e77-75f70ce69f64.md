# Formal Complexity Theory: Complete Research Package

I created a comprehensive complexity theory research package with machine-verified Lean 4 formalizations and supporting materials.

## Lean 4 Formalizations (sorry-free, fully verified)

### `New/ComplexityTheory/BooleanFunctions.lean` — 20+ verified theorems:
- **Boolean function definitions**: BoolFn, Hamming weight/distance, bit flipping
- **Sensitivity theory**: sensitivityAt, sensitivity, with bounds (s ≤ n)
- **Certificate complexity**: IsCertificate, with key bound s(f) ≤ |certificate|
- **Influence theory**: individual and total influence, with 0 ≤ Inf ≤ 1
- **Monotone functions**: definition and constant function examples
- **Parity function**: parity_flipBit (flipping any bit changes parity), sensitivity_parity_allfalse (parity achieves maximum sensitivity = n)
- **Sunflower basics**: IsSunflower definition, disjoint sunflower theorem

### `New/ComplexityTheory/CombinatorialBounds.lean` — 15+ verified theorems:
- **Decision tree bounds**: depth ≥ log₂(outcomes)
- **Binomial coefficient bounds**: partial sums, monotonicity, exact values
- **Sauer-Shelah weak bound**: ∑_{i≤d} C(m,i) ≤ (m+1)^d for m ≥ d ≥ 1
- **Counting**: card_subsets_size_k = C(n,k), card_powerset_fin = 2^n
- **Probabilistic method**: exists_ge_average and exists_le_average (averaging argument)
- **Polynomial method**: poly_roots_bound (degree-d polynomial has ≤ d roots)
- **Dimension arguments**: fin_fun_finrank

All proofs use only standard axioms (propext, Classical.choice, Quot.sound).
