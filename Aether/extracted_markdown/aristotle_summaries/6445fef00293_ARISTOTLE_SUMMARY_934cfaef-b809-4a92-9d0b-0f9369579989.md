### Key Research Discovery

The attempted "boost" theorems for O(3,1;ℤ) — mapping (a,b,c,d) → (a, b, 3c+2d, 2c+3d) — were **refuted by computation** (1²+2²+12² = 149 ≠ 169 = 13²). The algebraic root cause was identified: single-plane boosts require the Pell equation λ²−μ²=1, which has no nontrivial integer solutions. This was then formally proved in Lean 4. The correct approach uses the full parametric/SL(2,ℤ) generation instead.
