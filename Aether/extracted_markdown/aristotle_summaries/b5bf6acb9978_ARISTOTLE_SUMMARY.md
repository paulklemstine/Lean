### 1. Formally Verified Mathematics (`Algebra/IdempotentHilbertBasis.lean`)

All theorems are **fully proved with zero sorry's** and verified by the Lean 4 proof assistant. The file contains 470+ lines of Lean 4 code with 11 definitions and 17 theorems/lemmas. Only standard axioms are used (propext, Classical.choice, Quot.sound).

**Core Definitions:**
- `FinitelyPresentedCongruence` — a ring congruence equal to one generated by a finite set of pairs
- `eliminateCongruence` — pullback of a congruence along `MvPolynomial.rename ι`, implemented via `RingCon.comap`
- `congruenceMembershipCertificate` — membership in a finitely generated congruence via `RingConGen.Rel`

**Core Theorems (all fully proved):**
- `finite_syzygy_basis_of_fg` — finite presentation yields a finite syzygy basis for membership certificates
- `RingConGen_mono` — monotonicity of congruence generation in the generating relation
- `map_RingConGen_rel` — ring homomorphisms transport congruence derivations forward
- `rename_preserves_congruence_generation` — renaming maps transport derivations
- `pullback_RingConGen_of_surjective` — **surjective ring homomorphisms pull back congruence derivations** (proved without Classical.choice!)
- `kernel_rename_finitely_generated` — **the kernel of `rename ι` for surjective ι is finitely generated** by variable identification pairs `(X_t, X_collapse(t))`
- `elimination_fg` — **the main elimination theorem**: for surjective variable maps, elimination preserves finite presentation of congruences

**Key Helper Infrastructure:**
- `surjSection` / `fiberCollapse` — canonical fiber representative construction
- `kernelGenerators` / `preimageGenerators` / `eliminationGenerators` — explicit generator sets
- `poly_congr_collapsed` — any polynomial is congruent to its collapsed version (key lemma for kernel theorem)
- `elimination_forward` / `elimination_backward` — both directions of the elimination theorem

**Note on scope:** The elimination theorem is proved for **surjective** variable maps ι : τ → σ. The injective case (embedding fewer variables into more, corresponding to classical variable elimination) is a deeper result requiring Noetherian-type properties and is left as a future direction.
