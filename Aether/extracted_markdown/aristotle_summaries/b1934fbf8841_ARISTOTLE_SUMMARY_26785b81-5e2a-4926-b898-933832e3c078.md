### Key Theoretical Contributions

- **Maslov Training Protocol**: Train classically, then anneal temperature T→0 to crystallize into tropical form — preserves accuracy while gaining tropical structure
- **GELU Gap Analysis**: Bounded per-layer error for compiling GELU networks (GPT-2) via ReLU approximation
- **Tropical Straight-Through Estimator**: Forward pass uses hard max, backward pass uses softmax gradients
- **Tropical Continual Learning**: max(old, new) ≥ old — knowledge addition without catastrophic forgetting

The project builds on the existing Lean 4 formalizations in `Tropical/` (semiring axioms, ReLU identity, LogSumExp bounds, layer composition — all machine-verified with zero sorries).
