### Python Demos (`research/demos/`)
Five self-contained experiments, each runnable independently:

1. **`hypothesis1_constellation_rigidity.py`** — Tests G(n) ~ α·C₂(n)·n·ρ(n)² up to n=10,000. **Result: CONFIRMED** — recovers Hardy-Littlewood Conjecture B with α ≈ 0.651, matching the twin prime constant prediction.

2. **`hypothesis2_spectral_mass_gap.py`** — Analyzes first 100 Riemann zeta zeros, tests GUE statistics, studies minimum spacing vs height. **Result: PARTIALLY SUPPORTED** — soft spectral gap (GUE level repulsion) but no hard mass gap; proposes de Bruijn-Newman constant as bridge.

3. **`hypothesis3_fluid_prediction.py`** — Simulates Burgers' equation, lattice gas automata, and blow-up prediction complexity. **Result: PARTIALLY SUPPORTED** — forward direction (blow-up → hardness) supported; reverse refuted by 2D counterexample; refined to decidability-complexity link.

4. **`hypothesis4_approximation_universality.py`** — Verifies Lonely Runner (n≤6), tests Littlewood conjecture numerically, measures orbit coverage on tori. **Result: SUPPORTED** — both conjectures are dual aspects of equidistribution in compact groups.

5. **`hypothesis5_erdos_straus.py`** — Counts Egyptian fraction decompositions of 4/n for n≤300. **Result: REFINED** — growth is D(n) ~ n^0.59 (not log), with r=0.93 correlation to d(n)², governed by factorization structure.

Run all: `python research/demos/run_all.py`
