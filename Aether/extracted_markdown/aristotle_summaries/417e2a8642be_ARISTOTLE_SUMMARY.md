# Summary of changes for run 08228967-8e0e-4250-b310-1e0a065f9660
Created `Catalog/Applications/SpeciesTropicalProfile.lean`, a self-contained formalization of a tropical-style coefficient-profile theory for finitely supported rational sequences `f : ℕ →₀ ℚ`. The file builds cleanly with no `sorry`, no added axioms, and no `@[implemented_by]`; the key theorems were verified to depend only on the standard axioms `propext`, `Classical.choice`, `Quot.sound`.

Contents:
- **Definitions.** `ord f : WithTop ℕ` and `deg f : WithBot ℕ` realized directly as `f.support.min` / `f.support.max` (so `ord 0 = ⊤`, `deg 0 = ⊥`), and `bconv f g : ℕ →₀ ℚ`, the finitely supported packaging of the catalog's `CombinatorialSpecies.binConv` via `Finsupp.onFinset` over the support sumset.
- **Section 1 (support/extremal lemmas).** `ord_eq_top_iff`, `deg_eq_bot_iff`, `ord_ne_top_iff`, `deg_ne_bot_iff`, the vanishing/nonvanishing lemmas `coeff_ord_ne_zero`, `coeff_lt_ord_eq_zero`, `coeff_deg_ne_zero`, `coeff_gt_deg_eq_zero`, the full characterizations `ord_eq_coe_iff` / `deg_eq_coe_iff`, existence lemmas `exists_ord_eq` / `exists_deg_eq`, and monomial values `ord_single` / `deg_single`.
- **Section 2 (additive tropical laws, inequalities only).** `ord_add_ge : min (ord f) (ord g) ≤ ord (f + g)` and `deg_add_le : deg (f + g) ≤ max (deg f) (deg g)`, proved via `Finsupp.support_add` and `Finset.min_union` / `Finset.max_union`.
- **Section 3 (exact convolution laws).** `bconv_apply`, the zero cases, the away-from-extremum vanishing lemmas (`bconv_apply_eq_zero_of_lt` / `_of_gt`) and the unique-extremal-pair value lemmas (`bconv_apply_extremal_lo` / `_hi`), culminating in `ord_bconv : ord (bconv f g) = ord f + ord g` and `deg_bconv : deg (bconv f g) = deg f + deg g`. The proofs handle the zero cases first, then isolate the unique contributing index pair and use that over `ℚ` the binomial coefficient times the product of extremal coefficients is nonzero.
- **Section 4 (EGF compatibility).** `egf_add_finsupp` and `egf_bconv`, reusing the catalog's `CombinatorialSpecies.egf_add` and `egf_mul` rather than reproving the EGF algebra.
- **Section 5.** Minimal explicit examples (monomials, a monomial convolution, a two-term sequence) computing their `ord`, `deg`, and convolution profiles.

Infrastructure note: the project's `lakefile.toml` had no library covering the `Catalog.*` modules (the default build was already failing), so no `Catalog` module could be compiled. I added a single `Catalog` `lean_lib` entry (globbing `Catalog.+`) so that `Catalog.Applications.CombinatorialSpecies` and the new file resolve and build; `defaultTargets` was left unchanged.
