### 🎵 `index.html` — The App (1,214 lines, zero dependencies)
A complete single-page algorithmic music machine. Open in any modern browser and press **PLAY**.

**Features:**
- **25 electronic music genres:** House, Techno, Dubstep, Phonk, Wave, EBM, EDM, Trance, DnB, Ambient, Synthwave, Industrial, Trap, Garage, Lo-fi, Jazz, Rock, Alternative, Breaks, Psytrance, Downtempo, Disco, Reggaeton, Afrobeat, Hardstyle
- **Real-time synthesis** from pure Web Audio API oscillators and noise — no samples, no loading, zero dependencies
- **Music theory engine:** 14 scale modes, 12 chord types, 9 progression templates, constrained Brownian melody generation
- **7 concurrent synth voices:** FM kick, noise snare/hat/clap, dual-detuned sawtooth bass with sub-oscillator, variable-waveform lead, detuned pad, square arp
- **Arrangement engine:** Automatic intro→build→drop→breakdown→outro phase cycling with filter sweeps, voice allocation, and pattern regeneration
- **∞ Auto-Mix mode:** Infinite jukebox — automatically transitions between genres every ~90 seconds
- **Neuroacoustic layer:** Binaural beat entrainment (1-40 Hz, targeting Delta through Gamma brainwave bands), sub-bass psychoacoustics, tension-release dopamine optimization
- **Controls:** BPM, Intensity, Chaos, Hypnosis, Scale Root, Filter Cutoff, Reverb, Swing, Binaural Δ, Sub-Bass
- **Visualizer:** Audio-reactive radial frequency spectrum + hypnotic spiral + real-time waveform oscilloscope
- **Neurochemistry display:** Real-time estimated Dopamine, Serotonin, Adrenaline, Flow State, and Ecstasy Index meters
- **Live sequencer view, chord/scale display, event log**

**Usage:** Open `index.html` in Chrome/Firefox/Safari. Use headphones for binaural beat effects. Press PLAY, select a genre, enable ∞ AUTO-MIX for the infinite jukebox experience.
