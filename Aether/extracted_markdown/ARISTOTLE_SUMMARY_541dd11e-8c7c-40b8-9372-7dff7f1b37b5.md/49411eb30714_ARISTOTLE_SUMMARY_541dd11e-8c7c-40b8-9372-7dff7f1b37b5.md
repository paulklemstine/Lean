### Progress on Open Problems

1. **Tropical Langlands**: Formalized the free monoid structure of Berggren paths (BerggrenMove, applyPath), proved path composition, quadratic form preservation along arbitrary paths, perimeter parity, and computed grandchildren.

2. **Idempotent Neural Architectures**: Proved 1-step convergence (f^[n+1] = f), complementary projection ((id-f)² = id-f), ker(f) = range(id-f) duality, commuting idempotent composition, and that full-range idempotent = identity.

3. **Quantum Berggren Gates**: Verified all three matrices preserve the (2,1)-signature form (Mᵀ·Σ·M = Σ via native_decide), computed determinants (M₁=+1, M₂=-1, M₃=+1), proved composition closure, verified distinctness, traces, and root vector children. Key finding: integrality prevents SU(2) universality.

4. **Formal Sauer–Shelah**: Proved the restriction operator is idempotent (the key connection to idempotent collapse), restriction has ≤ 2^|S| elements, shattering monotonicity, binomial sum bounds Σ C(n,i) ≤ 2^n.
