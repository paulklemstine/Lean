# Summary of changes
## Sauer–Shelah Lemma — Fully Formalized

Created `SauerShelah.lean` containing a complete, sorry-free formalization of the Sauer–Shelah lemma (also known as the Sauer–Shelah–Perles lemma).

### Theorems proved

1. **`sauer_shelah`** (upper bound form): If a family `𝒜` of subsets of a finite type with `n` elements shatters no set of size `d + 1`, then `|𝒜| ≤ ∑_{i=0}^{d} C(n, i)`.

2. **`sauer_shelah_exists_shattered`** (contrapositive / existence form): If `|𝒜| > ∑_{i=0}^{d} C(n, i)`, then `𝒜` shatters some set of size `d + 1`.

3. **`sauer_shelah_fin`** / **`sauer_shelah_fin_exists`**: Specializations to `Fin n` for convenience.

### Helper lemmas

- **`Finset.Shatters.card_le_of_no_shatter`**: If no set of size `d + 1` is shattered, every shattered set has size ≤ `d`.
- **`Finset.vcDim_le_of_no_shatter`**: If no set of size `d + 1` is shattered, the VC-dimension is at most `d`.

### Proof strategy

The proof combines two results already in Mathlib:
1. **Pajor's inequality** (`Finset.card_le_card_shatterer`): `|𝒜| ≤ |shatterer(𝒜)|`
2. **Shatterer bound** (`Finset.card_shatterer_le_sum_vcDim`): `|shatterer(𝒜)| ≤ ∑_{k=0}^{vcDim} C(n, k)`

with the new observation that if no set of size `d + 1` is shattered then `vcDim ≤ d`, yielding the classical Sauer–Shelah bound. All proofs compile cleanly with only standard axioms (`propext`, `Classical.choice`, `Quot.sound`).
