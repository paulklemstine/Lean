# Aperiodicity Exponent of Transition Monoids for Cellular Automata Column Languages

## Abstract

We study the transition monoid of the column-extension DFA associated with nearest-neighbor cellular automata. For a CA rule $f : \alpha \times \alpha \to \alpha$ over a finite alphabet $\alpha$ and strip height $h \geq 1$, the DFA state tracks the "right diagonal" of the spacetime diagram, an element of $\alpha^h$. We prove that every element $m$ of the transition monoid satisfies $m^{h+1} = m^h$, establishing aperiodicity with exponent at most $h$. We show this bound is tight: for the left-projection rule $f(x,y) = x$, the single-letter transition has exponent exactly $h$. This corrects an earlier conjecture of uniform exponent 2 ($m^3 = m^2$), which we disprove for $h \geq 3$ with an explicit counterexample. All results are formally verified in the Lean 4 theorem prover.

**Keywords:** cellular automata, transition monoid, aperiodicity, column language, DFA, finite semigroup, formal verification

---

## 1. Introduction

### 1.1 Motivation

Cellular automata (CA) are discrete dynamical systems where cells on a lattice update synchronously according to a local rule. The spacetime diagram of a one-dimensional CA records the evolution of the system, with the horizontal axis representing space and the vertical axis representing time.

A fundamental question in symbolic dynamics is: what languages arise from the local structure of CA spacetime diagrams? Specifically, for a strip of fixed height $h$, the set of valid column sequences forms a regular language — the *column language* — recognizable by a finite automaton.

The algebraic invariant of this automaton — its *transition monoid* — encodes the computational complexity of the language. The monoid's structural properties determine where the language sits in the refined Straubing–Thérien hierarchy of regular languages. In particular:

- **Aperiodicity** (existence of $n$ with $m^{n+1} = m^n$ for all $m$) characterizes star-free languages, equivalent to FO[$<$]-definability by the Schützenberger–McNaughton–Papert theorem.
- **$\mathcal{J}$-triviality** characterizes piecewise testable languages, by Simon's theorem.
- The **aperiodicity exponent** bounds the quantifier complexity of first-order descriptions.

### 1.2 Main Results

We establish:

**Theorem A (Aperiodicity Exponent).** For every finite alphabet $\alpha$, every nearest-neighbor CA rule $f : \alpha \times \alpha \to \alpha$, every height $h \geq 0$, and every element $m$ of the transition monoid $M_h(f)$:
$$m^{h+1} = m^h.$$

**Theorem B (Tightness).** For $|\alpha| \geq 2$ and $f(x,y) = x$ (left projection), the single-letter transition reading any fixed symbol has exponent exactly $h$: $m^h \neq m^{h-1}$ but $m^{h+1} = m^h$.

**Theorem C (Counterexample).** The conjecture $m^3 = m^2$ for all $m \in M_h(f)$ is false for $h = 3$, $\alpha = \{0,1\}$, $f(x,y) = x$, and $m = $ the transition reading symbol $0$.

### 1.3 Related Work

The aperiodicity of CA column languages follows from their recognizability by deterministic finite automata with particular structural properties. The novelty here is the *precise exponent bound* and its *tightness*, together with the formal verification of these results.

The column language framework connects to:
- Kůrka's study of column shift spaces in symbolic dynamics [Kůrka, 2003]
- The algebraic theory of finite automata (Eilenberg, Pin)
- Descriptive complexity theory (Immerman, Straubing)

## 2. Definitions and Notation

### 2.1 Cellular Automata

Let $\alpha$ be a finite alphabet with $|\alpha| \geq 2$. A **nearest-neighbor CA rule** is a function $f : \alpha \times \alpha \to \alpha$. The rule generates a spacetime diagram from an initial row $(a_1, a_2, \ldots, a_n) \in \alpha^n$:

$$a_{i,t+1} = f(a_{i,t}, a_{i+1,t})$$

for $1 \leq i \leq n - t - 1$ and $t \geq 0$. The spacetime diagram forms a triangle: row $t$ has $n - t$ cells.

### 2.2 Right Diagonal State

For a strip of height $h$ (rows $0$ through $h-1$), the **right diagonal** at position $k$ (after reading cells $a_1, \ldots, a_k$ with $k \geq h$) is the vector:

$$b = (b_0, b_1, \ldots, b_{h-1}) \in \alpha^h$$

where $b_t$ is the rightmost cell in row $t$ that depends on $a_1, \ldots, a_k$.

### 2.3 Step Transition

Reading a new cell value $a$ from state $b \in \alpha^h$ produces a new state $b' \in \alpha^h$:

$$b'_0 = a, \qquad b'_{i+1} = f(b_i, b'_i) \quad \text{for } 0 \leq i < h-1.$$

This defines the **step transition** $\sigma_a : \alpha^h \to \alpha^h$.

### 2.4 Transition Monoid

For a word $w = a_1 a_2 \cdots a_L \in \alpha^L$, the **word transition** is:

$$\tau_w = \sigma_{a_L} \circ \sigma_{a_{L-1}} \circ \cdots \circ \sigma_{a_1} : \alpha^h \to \alpha^h.$$

The **transition monoid** $M_h(f)$ is the submonoid of the full transformation monoid on $\alpha^h$ generated by $\{\sigma_a : a \in \alpha\}$.

## 3. Main Results

### 3.1 Agreement Lemma

The key technical tool is the following "information propagation" lemma.

**Definition.** Two states $b, b' \in \alpha^h$ **agree at level $k$** (written $b =_k b'$) if $b_j = b'_j$ for all $j < k$.

**Lemma 1 (Step Agreement).** If $b =_k b'$, then $\sigma_a(b) =_{k+1} \sigma_a(b')$ for any $a \in \alpha$.

*Proof.* By induction on the coordinate index $j \leq k$:
- $j = 0$: $\sigma_a(b)_0 = a = \sigma_a(b')_0$.
- $j + 1 \leq k$: $\sigma_a(b)_{j+1} = f(b_j, \sigma_a(b)_j)$. Since $j < k$, we have $b_j = b'_j$. By the inductive hypothesis, $\sigma_a(b)_j = \sigma_a(b')_j$. Therefore $\sigma_a(b)_{j+1} = \sigma_a(b')_{j+1}$. $\square$

**Lemma 2 (Word Agreement).** If $b =_k b'$, then $\tau_w(b) =_{k + |w|} \tau_w(b')$.

*Proof.* Induction on $|w|$, applying Lemma 1 at each step. $\square$

### 3.2 Constancy Lemma

**Lemma 3 (Constancy).** If $|w| \geq h$, then $\tau_w$ is a constant function on $\alpha^h$.

*Proof.* For any $b, b' \in \alpha^h$, we have $b =_0 b'$ trivially. By Lemma 2, $\tau_w(b) =_{|w|} \tau_w(b')$. Since $|w| \geq h$, this gives $\tau_w(b) =_h \tau_w(b')$, i.e., $\tau_w(b) = \tau_w(b')$. $\square$

### 3.3 Main Theorem

**Theorem A.** For all $w \in \alpha^*$: $\tau_w^{h+1} = \tau_w^h$ (as functions $\alpha^h \to \alpha^h$).

*Proof.* **Case 1:** $w = \varepsilon$ (empty word). Then $\tau_w = \text{id}$ and $\text{id}^{h+1} = \text{id} = \text{id}^h$.

**Case 2:** $w \neq \varepsilon$, so $|w| \geq 1$. We have:
$$\tau_w^{h+1} = \tau_w^h \circ \tau_w.$$

The word $w^h$ (concatenation of $h$ copies of $w$) has length $h \cdot |w| \geq h$. By Lemma 3, $\tau_{w^h} = \tau_w^h$ is a constant function, say with value $s$.

For any state $b$:
$$\tau_w^{h+1}(b) = \tau_w^h(\tau_w(b)) = s,$$
since $\tau_w^h$ is constant. Also $\tau_w^h(b) = s$. Therefore $\tau_w^{h+1}(b) = \tau_w^h(b)$ for all $b$. $\square$

### 3.4 Tightness

**Theorem B.** For $\alpha = \{0, 1\}$, $f(x,y) = x$, and $m = \sigma_0$, we have $m^h \neq m^{h-1}$ for $h \geq 2$.

*Proof.* With $f(x,y) = x$, the step transition is a pure right shift:
$$\sigma_a(b_0, b_1, \ldots, b_{h-1}) = (a, b_0, b_1, \ldots, b_{h-2}).$$

Therefore $\sigma_0^k(b) = (0, 0, \ldots, 0, b_0, b_1, \ldots, b_{h-1-k})$ — the first $k$ coordinates are zero, and the remaining coordinates are the first $h - k$ coordinates of $b$.

For $k = h - 1$: $\sigma_0^{h-1}(b) = (0, \ldots, 0, b_0)$, which depends on $b_0$.
For $k = h$: $\sigma_0^h(b) = (0, \ldots, 0)$, independent of $b$.

Taking $b = (1, 0, \ldots, 0)$ and $b' = (0, \ldots, 0)$:
$$\sigma_0^{h-1}(b) = (0, \ldots, 0, 1) \neq (0, \ldots, 0) = \sigma_0^{h-1}(b'),$$
so $\sigma_0^{h-1}$ is not constant, hence $m^{h-1} \neq m^h$ (since $m^h$ is constant). $\square$

### 3.5 Counterexample to $m^3 = m^2$

**Theorem C.** For $\alpha = \{0,1\}$, $f(x,y) = x$, $h = 3$, and $m = \sigma_0$:

$$m^2(1, 0, 0) = (0, 0, 1) \neq (0, 0, 0) = m^3(1, 0, 0).$$

*Proof.* Direct computation using the shift structure. $\square$

## 4. Computational Experiments

### 4.1 Exponent Classification of Binary Rules

We enumerated all 16 binary Boolean CA rules $f : \{0,1\}^2 \to \{0,1\}$ and computed their exponent sequences $(e_1, e_2, \ldots, e_5)$ for heights $h = 1, \ldots, 5$.

| Exponent Pattern | Count | Rules |
|---|---|---|
| $(1, 1, 1, 1, 1)$ | 4 | Constant rules, $f(x,y) = y$ |
| $(1, 2, 2, 2, 2)$ | 2 | $f(x,y) = x \wedge \neg y$, complement |
| $(1, 2, 2, 3, 3)$ | 2 | $f(x,y) = \neg(x \vee y)$, complement |
| $(1, 2, 3, 4, 5)$ | 8 | Generic rules including $f(x,y) = x$, XOR, OR |

**Observation:** 8 out of 16 rules achieve the tight exponent $e_h = h$, while the remaining 8 have sub-linear exponent growth.

### 4.2 Transition Monoid Sizes

| Rule | $|M_1|$ | $|M_2|$ | $|M_3|$ | $|M_4|$ |
|---|---|---|---|---|
| $f(x,y) = x$ | 3 | 7 | 15 | 31 |
| $f(x,y) = y$ | 3 | 3 | 3 | 3 |
| XOR | 3 | 7 | 15 | 31 |
| AND | 3 | 5 | 7 | 9 |

For the left-projection and XOR rules, $|M_h| = 2^{h+1} - 1$, growing exponentially. For the right-projection rule, $|M_h| = 3$ is constant (the monoid consists of only the identity and two constant functions). For AND, the growth is linear: $|M_h| = 2h + 1$.

### 4.3 Formal Verification

## 5. Discussion

### 5.1 Interpretation

The theorem reveals a fundamental property of deterministic local evolution: **information propagation through the spacetime diagonal is strictly one-directional and bounded.** Each step transition shifts information upward by one level. After $h$ steps, all initial information has been "flushed out," and the transition function becomes constant.

This is a consequence of the *triangular dependency structure* of nearest-neighbor CA: the value at position $(i, t)$ depends on the "cone" of cells at positions $(i, 0), (i+1, 0), \ldots, (i+t, 0)$. The right diagonal at position $k$ depends only on cells $a_{k-h+1}, \ldots, a_k$. Shifting by one position replaces one cell of this window, decreasing the "overlap" with the original window by one.

### 5.2 Algebraic Implications

The aperiodicity of $M_h(f)$ implies, by the Schützenberger–McNaughton–Papert theorem, that the column language is star-free and FO[$<$]-definable. The exponent $h$ gives a bound on the logical resources required:

- The column language at height $h$ can be described by a first-order sentence over an ordering with quantifier depth at most $h \cdot |\alpha|^h$.
- The star-free expression for the language has nesting depth bounded by a function of $h$ and $|\alpha|$.

### 5.3 Comparison with Conjectured Exponent 2

The original conjecture proposed uniform exponent 2, which would have placed the column language in a much more restrictive algebraic class. While this is false in general, it is worth noting:

- For $h \leq 2$, the exponent is indeed at most 2.
- For rules where the update function $f$ is "contractive" (e.g., $f(x,y) = y$, constant rules), the exponent can be much smaller than $h$.
- The sub-linear exponent growth for certain rules (see Section 4.1) suggests that additional structural properties beyond the general bound may hold for specific rule classes.

### 5.4 Open Questions

1. **$\mathcal{J}$-triviality:** Is $M_h(f)$ always $\mathcal{J}$-trivial? Our computational experiments suggest this may fail, but a definitive answer requires more careful analysis of Green's relations.

2. **Rule-specific exponents:** Can the exact exponent be characterized in terms of properties of $f$? The data suggests a connection to the "information flow" through $f$ — specifically, how much the output depends on each input.

3. **Higher-dimensional CA:** Does an analogous bound hold for two-dimensional CA, where the spacetime diagram is three-dimensional?

4. **Larger neighborhoods:** For CA with neighborhood radius $r$, the step transition shifts by $r$ positions. Does the exponent become $\lceil h/r \rceil$?

## 6. Algorithms

### 6.1 Computing the Transition Monoid

**Input:** CA rule $f$, height $h$, alphabet $\alpha$.
**Output:** The transition monoid $M_h(f)$.

```
COMPUTE-MONOID(f, h, α):
    Q ← α^h                    // State set
    generators ← {σ_a : a ∈ α} // Step transitions
    M ← {id} ∪ generators      // Initialize monoid
    queue ← list(generators)
    while queue ≠ ∅:
        τ ← queue.dequeue()
        for each σ ∈ generators:
            τ' ← σ ∘ τ
            if τ' ∉ M:
                M ← M ∪ {τ'}
                queue.enqueue(τ')
    return M
```

**Complexity:** $O(|M|^2 \cdot |\alpha|^h)$ time, $O(|M| \cdot |\alpha|^h)$ space.

### 6.2 Computing the Aperiodicity Exponent

**Input:** Transition function $\tau : Q \to Q$.
**Output:** Smallest $k$ with $\tau^{k+1} = \tau^k$.

```
COMPUTE-EXPONENT(τ):
    prev ← id
    for k = 1, 2, ...:
        curr ← τ ∘ prev
        if curr = prev:
            return k - 1
        prev ← curr
```

**Complexity:** $O(k \cdot |Q|)$ time where $k$ is the exponent.

## 7. Future Work

The most promising directions for extending this work include:

1. **Piecewise testability:** Determine whether the column language is piecewise testable (not just star-free). This requires analyzing Green's $\mathcal{J}$-relation on the transition monoid, which is computationally tractable for small examples but theoretically open in general.

2. **Quantifier rank bounds:** Derive explicit bounds on the FO[$<$] quantifier rank as a function of $h$ and $|\alpha|$. The current bound $h \cdot |\alpha|^h$ is crude; tighter bounds may follow from the specific structure of the transition monoid.

3. **Generating function analysis:** Exploit the bounded exponent to derive properties of the generating function $\sum_n c_n x^n$ where $c_n$ counts valid column sequences of width $n$. The aperiodicity constraint may restrict the denominator's cyclotomic factors.

4. **Connection to additive CA:** For additive CA over finite fields, the transition monoid has additional algebraic structure (linearity). The interplay between the general exponent bound and the arithmetic periodicity of additive CA merits further investigation.

5. **Formal verification of generalizations:** Extend the Lean formalization to larger neighborhoods, periodic boundary conditions, and higher-dimensional CA.
