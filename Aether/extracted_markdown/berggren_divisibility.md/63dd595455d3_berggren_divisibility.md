# Cancellation, Divisibility, and Prefix Order in the Berggren Semigroup:
# A Formally Verified Cryptographic Foundation

## Abstract

We develop a formally verified divisibility and cancellation theory for the Berggren semigroup — the subsemigroup of GL₃(ℤ) generated by the three classical Berggren matrices that parametrize the Pythagorean triple tree. Building on a machine-checked proof that the generating map is injective (freeness), we transport the prefix calculus of the free semigroup to an intrinsic partial order on the matrix semigroup. The main results, all verified in Lean 4 with Mathlib, are:

1. **Left and right cancellation** in the Berggren semigroup, transported from free semigroup cancellation via the faithful embedding.
2. **Left-divisibility forms a partial order**, with antisymmetry following from the impossibility of `a · x = a` in a free semigroup (a length argument).
3. **Exact correspondence**: left-divisibility on matrices ↔ prefix order on normal forms, with a matching characterization for right-divisibility and suffixes.
4. **Greatest lower bounds via longest common prefix**: the LCP operation on normal forms computes the meet in the divisibility order.
5. **Oracle reduction theorem**: an oracle recovering the prefix of an element in a homomorphic image uniquely determines the hidden suffix (secret word), providing a clean algebraic foundation for analyzing prefix-recovery attacks on semigroup-based cryptographic protocols.

All proofs compile without `sorry` against Lean 4.28.0 with Mathlib, using only standard axioms.

## 1. Introduction

The Berggren tree, discovered independently by Berggren (1934) and Barning (1963), organizes all primitive Pythagorean triples into a ternary tree rooted at (3, 4, 5). Each node generates three children via the matrices:

```
B₁ = | 1  -2   2 |    B₂ = | 1   2   2 |    B₃ = |-1   2   2 |
     | 2  -1   2 |         | 2   1   2 |         |-2   1   2 |
     | 2  -2   3 |         | 2   2   3 |         |-2   2   3 |
```

The semigroup S = ⟨B₁, B₂, B₃⟩ generated by these matrices inside GL₃(ℤ) is known to be a free semigroup of rank 3. This freeness property — the statement that distinct words in the generators produce distinct matrices — is the algebraic backbone for the SPB (Semigroup-based Protocol using Berggren matrices) family of cryptographic protocols.

However, freeness alone tells us only that the encoding is injective. It does not expose the internal structure of the matrix semigroup: its divisibility theory, its order-theoretic properties, or the algorithmic consequences of unique factorization. This paper fills that gap.

## 2. Formal Framework

### 2.1 Definitions

We work with the type `BGen` with three constructors A, B, C, and the free semigroup `FreeSemigroup BGen`. The semigroup homomorphism

```
φ : FreeSemigroup(BGen) →ₙ* Mat₃ₓ₃(ℤ)
```

is defined via `FreeSemigroup.lift` applied to the generator map. We define the *Berggren semigroup* as the image:

```
BerggrenSg := { M : Matrix (Fin 3) (Fin 3) ℤ // ∃ w : FreeSemigroup BGen, φ w = M }
```

Each element has a unique **normal form** — the preimage under φ — extracted via `Exists.choose`:

```
noncomputable def nf (A : BerggrenSg) : FreeSemigroup BGen := A.2.choose
```

The key properties `nf_spec : φ (nf A) = A.1` and `nf_unique : φ w = A.1 → w = nf A` follow immediately from injectivity.

### 2.2 Freeness Proof Strategy

Our proof of `evalWord_injective` (injectivity of the evaluation map from words to triples) uses a **discriminant classifier**. We define two linear forms:

```
δₓ(a, b, c) = a + 2b - 2c
δᵧ(a, b, c) = 2a + b - 2c
```

and prove algebraic identities showing that applying generator g to a "good triple" (positive Pythagorean triple) produces predictable signs for δₓ and δᵧ. The sign pattern uniquely identifies the generator, giving unique parenthood in the tree and hence freeness by induction on word length.

## 3. Main Results

### 3.1 Cancellation

**Theorem (Left Cancellation).** For all A, B, C in BerggrenSg, if A · B = A · C then B = C.

*Proof.* Transport to normal forms: nf(A) · nf(B) = nf(A) · nf(C) in the free semigroup, then apply free semigroup cancellation (which is a direct consequence of list append cancellation).

### 3.2 Divisibility as Partial Order

We define left-divisibility as:
```
def LeftDivides (A B : BerggrenSg) : Prop := A = B ∨ ∃ C, B = A * C
```

The disjunction with equality handles reflexivity in the absence of an identity element.

**Theorem.** `LeftDivides` is a partial order on `BerggrenSg`.

*Antisymmetry* is the nontrivial case: if B = A · C and A = B · D, then A = A · (C · D), which in normal forms gives nf(A) = nf(A) · (nf(C) · nf(D)). But in a free semigroup, x · y ≠ x for any y (since |x · y| > |x|), contradiction.

### 3.3 Divisibility ↔ Prefix

**Theorem.** LeftDivides(A, B) ⟺ IsPrefixFS(nf(A), nf(B))

This is the key bridge between the matrix world and combinatorics on words.

### 3.4 Greatest Lower Bounds

**Theorem.** When the LCP of nf(A) and nf(B) is nonempty, the corresponding semigroup element is the greatest lower bound for left-divisibility.

### 3.5 Oracle Reduction

**Theorem (Secret Suffix Uniqueness).** For all A, T in BerggrenSg:
```
∃! U ∈ FreeSemigroup(BGen), nf(A · T) = nf(A) · U
```
and the unique U is nf(T).

**Corollary.** Any oracle recovering nf(A) from ψ(A) and ψ(A · T) uniquely determines the secret suffix nf(T).

## 4. Applications

### 4.1 Cryptographic Protocol Analysis

Our results show that in any semigroup-based protocol using Berggren generators:

1. **Unique factorization is exact**: every matrix product admits a unique decomposition.
2. **Prefix information is maximally dangerous**: recovering even a prefix of the secret word from a public key is equivalent to recovering the entire suffix.
3. **The divisibility order is decidable**: one can algorithmically determine structural relationships between secret keys.

### 4.2 Algorithmic Number Theory

The LCP operation provides a computable "greatest common divisor" for the matrix semigroup, useful for common ancestor detection in the Pythagorean triple tree.

## 5. Discussion: Making Algebra Visible

### For the General Reader

Imagine a tree where every node is a different Pythagorean triple — those special right triangles with whole-number sides like 3-4-5. The Berggren tree is exactly this: starting from (3, 4, 5), each triple spawns three children via matrix operations, and *every* primitive Pythagorean triple appears exactly once.

Now imagine using this tree as a cryptographic system. Your secret key is a path through the tree — a sequence of left, middle, and right turns. Your public key is the matrix product along your path. Because the tree is "free" (no two paths give the same matrix), your secret is well-hidden.

But here's the subtle point our paper proves: if an attacker can figure out even the *beginning* of your path — say, the first three turns — they can uniquely reconstruct the rest. In most algebraic settings, knowing part of a factorization doesn't determine the remainder. But in the Berggren semigroup, it does, because of unique normal forms and cancellation.

This is like a combination lock where knowing the first few digits uniquely determines all the rest. Protocol designers need to be aware of this property.

### Connections to Existing Work

The Berggren tree has been studied extensively in number theory and more recently in connection with non-commutative cryptography. Our contribution is to formally verify the algebraic-order-theoretic properties that underpin the security analysis, bridging the gap between the tree's combinatorial structure and its use as a cryptographic primitive.

### Future Directions

1. **Finite-field reductions**: specialize the oracle reduction to concrete finite-field images used in SPB protocol implementations.
2. **Complexity-theoretic reductions**: strengthen the logical reduction to a computational reduction.
3. **Automated decomposition**: implement and verify the discriminant-based parsing algorithm as a certified program.
