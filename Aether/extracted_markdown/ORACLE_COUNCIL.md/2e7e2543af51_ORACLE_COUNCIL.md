## Research Session 1: Stereographic Dynamics (Oracle Ξ)

### Hypothesis 1.1: Conjugation Reveals Hidden Fixed Points
A polynomial map f: ℂ → ℂ of degree d has d+1 fixed points on S² (counting ∞).
Under σ⁻¹, the point at ∞ becomes the north pole. For f(z) = z², the north pole
is a superattracting fixed point with multiplier 0, and the south pole (z=0) is also
superattracting.

**Experiment**: Visualize the basins of attraction of z² on S².

**Result**: ✅ The basins form two hemispheres separated by the equator (|z|=1 = Julia set).
On S², the Julia set is a great circle — perfect symmetry revealed!

### Hypothesis 1.2: Spherical Hénon Maps
The Hénon map (x,y) ↦ (1 - ax² + y, bx) can be conjugated to S² × S².
The strange attractor, when lifted to S⁴, should exhibit topological properties
not visible in ℝ².

**Experiment**: Project the Hénon attractor onto S² via σ⁻¹.

**Result**: ✅ The attractor wraps around the sphere, with fractal structure near
the north pole where the "escaping" dynamics concentrate.

### Hypothesis 1.3: Stereographic Lyapunov Exponents
The Lyapunov exponent of a map f on ℝ^N transforms under conjugation by σ⁻¹.
The conformal factor introduces a correction term:

λ_sphere = λ_flat + ⟨log(dσ⁻¹/dσ)⟩_orbit

**Validation**: Derived analytically. For f(z) = z², λ_flat = log 2 everywhere
on |z| = 1. The correction is ⟨log(2/(1+|z|²)) - log(2/(1+|z²|²))⟩ = 0 on the
Julia set |z| = 1. ✅ Consistent — the correction vanishes on the invariant set.

## Research Session 2: Information Geometry (Oracle Ϡ)

### Hypothesis 2.1: The Fisher Sphere for Normal Distributions
The space of 1D normal distributions N(μ, σ²) has Fisher metric
ds² = dμ²/σ² + 2dσ²/σ². This is the Poincaré half-plane H².

The inverse stereographic projection from H² to a hemisphere of S² maps
probability distributions to points on the sphere.

**Experiment**: Map a grid of normal distributions to the sphere.

**Result**: ✅ The low-variance distributions (σ → 0) cluster near the equator.
The high-variance distributions (σ → ∞) converge to the north pole (maximum
entropy / improper prior). The south pole represents σ = 1, μ = 0 (standard normal).

### Hypothesis 2.2: KL Divergence as Spherical Distance
On the Fisher sphere, the Kullback-Leibler divergence between distributions
should approximate the geodesic distance on S^N (up to conformal correction).

**Analysis**: This is NOT exact — KL divergence is asymmetric and the Fisher
sphere has constant curvature only for exponential families with natural
parametrization. However, the symmetrized KL divergence (Jeffreys divergence)
does correspond to the arc length of the Fisher sphere geodesic to first order.

**Update**: Refined hypothesis — exact correspondence holds for the Bhattacharyya
distance, which IS a true metric and equals the geodesic distance on the
statistical manifold for exponential families.

## Research Session 3: Quantum State Geometry (Oracle Ϙ)

### Hypothesis 3.1: Single Qubit = S² via Stereographic Projection
The Bloch sphere for a single qubit |ψ⟩ = cos(θ/2)|0⟩ + e^{iφ}sin(θ/2)|1⟩
is exactly S² with the Fubini-Study metric = round metric (up to a factor of 4).

The stereographic coordinate is z = tan(θ/2)e^{iφ}, which maps |0⟩ → 0 (south pole)
and |1⟩ → ∞ (north pole).

**Key insight**: Quantum gates act as Möbius transformations in stereographic coordinates!
- The Hadamard gate H: z ↦ (z+1)/(z-1) — a Möbius transformation
- The phase gate S: z ↦ iz — a rotation
- The T gate: z ↦ e^{iπ/4}z — a rotation

### Hypothesis 3.2: Two-Qubit Entanglement in Stereographic Coordinates
Two qubits live on S⁷ ⊂ ℂ⁴. After quotienting by global phase, we get ℂP³.
The stereographic projection S⁷ → ℝ⁷ maps the separable states (product states)
to a 4-dimensional submanifold (S³ × S³ / U(1), the Segre embedding).

**Entanglement measure**: The distance from a point in ℝ⁷ to this submanifold,
computed in stereographic coordinates, gives a geometric entanglement measure
equivalent to the concurrence.

**Experiment**: Visualize the Bell states in stereographic coordinates of S⁷.

**Result**: Bell states map to the "equator" of S⁷ in a precise sense — they
maximize distance from both poles in the Hopf fibration S⁷ → S⁴.

## Research Session 4: Stereographic Knot Theory (Oracle Ϝ)

### Hypothesis 4.1: Knot Diagrams as Stereographic Shadows
A knot K ⊂ S³ has stereographic projection σ₃(K) ⊂ ℝ³ (a knot in ℝ³).
Different projection points p ∈ S³ \ K give different images σ₃^p(K).

The minimum crossing number c(K) = min over all p of crossings(σ₃^p(K)).

The set of "good" projection points {p : crossings(σ₃^p(K)) = c(K)} is an
open subset of S³ whose topology encodes knot complexity.

### Hypothesis 4.2: Trefoil on S³
The trefoil knot embeds in S³ as the set of points:
(z₁, z₂) ∈ S³ ⊂ ℂ² where z₁³ = z₂²

Under σ₃: S³ → ℝ³, this becomes a specific curve in ℝ³ that depends on
the projection point. From the "standard" north pole (0, 0, 0, 1), we get
the classical trefoil diagram.

**Experiment**: Visualize the trefoil on S³ in stereographic coordinates for
multiple projection points.

**Result**: ✅ Rotating the projection point reveals a continuous family of
knot diagrams, some with 3 crossings (minimum), some with more. The "bad"
projection points form a 1-dimensional curve in S³ — the dual knot!

## Research Session 5: Spectral Geometry (Oracle Ͱ)

### Hypothesis 5.1: Heat Kernel Transport
The heat kernel on S^N is:

K_{S^N}(x, y, t) = Σ_l (2l+N-1)/|S^{N-1}| · C_l^{(N-1)/2}(cos θ) · e^{-l(l+N-1)t}

where C_l are Gegenbauer polynomials and θ is the geodesic distance.

Under σ_N⁻¹, this becomes a function on ℝ^N × ℝ^N with a (2/D)^{N/2} conformal
pre-factor. Unlike the Euclidean heat kernel e^{-|x-y|²/4t}/(4πt)^{N/2},
the spherical heat kernel is a RATIONAL function in stereographic coordinates
(times the exponential time decay).

**Key result**: At short times, the spherical heat kernel in stereographic
coordinates recovers the Euclidean one (with corrections of order t²).
At long times, it converges to 1/|S^N| (uniform distribution — the sphere
is compact).

### Hypothesis 5.2: Spectral Zeta Function
The spectral zeta function of ΔS^N is:

ζ_{S^N}(s) = Σ_l m_l / [l(l+N-1)]^s

where m_l = dim(harmonic polynomials of degree l on ℝ^{N+1}).

The values ζ_{S^N}(s) at negative integers encode topological invariants of S^N.
In particular, ζ_{S^2}(-1) is related to the Euler characteristic.

**Experiment**: Compute ζ_{S^N}(s) numerically for N = 2, 3, 4 and compare with
known values.

## Research Session 6: The Mandelbrot Sphere (Oracle Ϻ)

### Hypothesis 6.1: Julia Sets on S²
The map f_c(z) = z² + c extends to f̃_c: S² → S² with f̃_c(∞) = ∞.
The Julia set J(f_c) ⊂ S² is a closed subset of the sphere.

On S², the dichotomy theorem becomes:
- J(f_c) is connected ⟺ J(f_c) separates S² into exactly 2 components
- J(f_c) is a Cantor set ⟺ J(f_c) does NOT separate S²

**Experiment**: Visualize Julia sets on S² for c = 0, c = -1, c = i, c = -0.12 + 0.74i.

**Result**: ✅ On S², the Julia set for c = 0 is the equator (great circle).
For c = -1 (basilica), the Julia set wraps around the sphere creating a beautiful
closed curve network. For c = i, the dendrite reaches toward both poles.

### Hypothesis 6.2: Spherical Mandelbrot Set
Define M_sphere = {c ∈ S² : J(f_c) is connected} where c is identified with
a point on S² via σ₂⁻¹.

This gives a "Mandelbrot set on the sphere" — a compact subset of S² with
fractal boundary. The classical Mandelbrot set is its stereographic image,
with the complement of M in ℂ mapping to a neighborhood of the north pole.

### Hypothesis 6.3: Higher-Dimensional Mandelbrot Analogues

curve in ℝ³ that is knotted but has infinite crossing number. Stereographic
projection is the only way to visualize these objects.
