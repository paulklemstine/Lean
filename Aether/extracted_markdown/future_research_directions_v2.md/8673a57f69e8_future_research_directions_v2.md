## 1. Universal Approximation: Completing the Proof

### 1.1 Stone-Weierstrass Completion
**Status: Prerequisites PROVED ✅ | Full theorem: OPEN**

We have formally proved all three prerequisites:
- Separation: `eml_separates_points` ✅
- Nonvanishing: `eml_nonvanishing` ✅  
- Continuity: `eml_exp_neuron_continuous` ✅

**Remaining work:** Complete the Stone-Weierstrass application by showing that the algebra generated by EML neurons is self-adjoint (closed under complex conjugation in the complex case, automatic in the real case).

### 1.2 Rate of Approximation
**Open Question:** What is the approximation rate? For polynomials, the Jackson-Bernstein theory gives `O(1/n^k)` for k-smooth functions with n-term approximation. For EML:
- Conjecture: EML approximation rate is `O(exp(-c·n))` for analytic functions (exponentially fast)
- This would be much better than polynomial approximation
- The exp component enables "exponential search" through function space

### 1.3 Width vs Depth for EML
**New discovery from formal verification:**

- Width-1, depth-D: 6D parameters → each layer adds 6 parameters
- Width-W, depth-1: 5W+1 parameters → each neuron adds 5 parameters
- A depth-d EML chain can represent `exp^d(x)` (tower of exponentials)

**Conjecture:** Depth is more efficient than width for EML networks — the opposite of standard ReLU networks. A depth-5 EML network can represent functions requiring width-10^6 ReLU networks.

## 2. Dual-Gradient Training Dynamics (NEW)

### 2.1 Formalizing the Phase Transition
**Status: Gradient decomposition PROVED ✅ | Phase transition: OPEN**

We proved that the gradient decomposes into exp and log components. The next challenge: formally characterize the crossover point where the dominant component switches.

**Conjecture:** The crossover epoch scales as `O(1/lr)` where lr is the learning rate.

### 2.2 EML-Specific Optimizers
Design optimizers that exploit the dual-gradient structure:
- **DualAdam:** Use different momentum parameters for exp and log gradient components
- **PhaseAware SGD:** Detect the current phase and adjust learning rate accordingly
- **LogDecay:** Use the log gradient's natural decay as the primary annealing mechanism

### 2.3 Gradient Clipping Theory
**Proved:** Exp gradient can explode to `exp(|w₁|·M + |b₁|)` ✅
**Open:** Optimal gradient clipping threshold as a function of network depth and data range.

### 2.4 Critical Depth Theorem
**Proved:** Chain gradient explodes when avg gradient > 1 ✅
**Proved:** Chain gradient vanishes when avg gradient < 1 ✅
**Recommended:** Maximum depth 5 ✅

**Open:** Is there a "critical depth" d* where training transitions from feasible to infeasible? Preliminary evidence suggests d* ≈ 5 for standard configurations.

## 3. Statistical Learning Theory (NEW)

### 3.1 VC Dimension Refinement
**Proved:** VC dim ≤ 2k for k-leaf EML trees ✅
**Proved:** EML VC dim < NN VC dim for same width ✅

**Open:** What is the *exact* VC dimension? The upper bound 2k may not be tight. The exp-log structure could constrain the function class more than generic parametric families.

### 3.2 PAC-Bayes Bounds for EML
The MDL framework we formalized (MDL = 2k + k·b) suggests natural PAC-Bayes bounds:
- Prior: uniform over topologies, Gaussian over parameters
- Posterior: concentrated on the found tree
- The PAC-Bayes bound should be much tighter than generic NN bounds

### 3.3 Minimax Rates
**Open:** What is the minimax optimal rate for learning k-leaf EML trees from n samples? 
- Conjecture: `O(k·log(n)/n)` (standard parametric rate)
- The Catalan number structure of tree topologies adds a `log(C_k)` ≈ `2k` term

### 3.4 Model Selection via MDL
**Proved:** MDL = 2k + k·b for EML trees ✅
**Proved:** Optimal complexity ≈ 32 for 10^6 samples ✅

**Open:** Derive the exact optimal complexity formula. The heuristic k* = n^(1/4) appears to work well empirically but lacks a formal proof.

**Open improvements:**

### 4.2 Neural-Guided Search

- Input: target function values at a grid of points
- Output: probability distribution over next tree construction action
- Train on a database of (function, optimal tree) pairs

### 4.3 Multi-Variable EML
**Critical open problem:** Extend EML regression to f(x₁, ..., x_d).
- How do tree topologies scale with dimension?
- Feature selection: which variables appear?
- Interaction detection: which variables share EML nodes?

### 4.4 Dimensional Analysis Integration
Incorporate physical units into EML regression:
- Reject trees that violate dimensional consistency
- Dramatically prunes the search space
- Compatible with SI, CGS, or natural unit systems

## 5. Formula Compression and Distillation

### 5.1 Distillation Guarantees
**Proved:** 250× compression for specific examples ✅
**Open:** When does distillation *provably succeed*?

**Conjecture:** Distillation succeeds with error ε when the target function has K_EML complexity ≤ k, given n ≥ O(k·log(1/ε)/ε²) teacher samples.

### 5.2 Iterative Distillation
Start with a small tree, grow as needed:
1. Fit a 2-leaf tree
2. If residual > threshold, add an EML node
3. Re-optimize all parameters
4. Repeat until convergence

This avoids the combinatorial explosion of searching all topologies at once.

### 5.3 Multi-Output Distillation
For networks with multiple outputs:
- Distill each output independently? (simple but misses shared structure)
- Shared EML subtrees with output-specific tops? (captures common features)
- Joint optimization over all outputs?

## 6. Hardware Acceleration

### 6.1 Analog EML Gates
**Key insight:** Transistors in subthreshold mode naturally compute I ∝ exp(V/V_T). Log amplifiers using op-amps compute V_out ∝ ln(V_in). Combining these gives a single analog EML gate.

**Research questions:**
- What precision can be achieved?
- How do analog errors propagate through deep EML trees?
- Can we build a programmable analog EML array?

### 6.2 FPGA Implementation
- Fixed-point vs floating-point EML computation
- Parallel evaluation of multiple EML trees
- Reconfigurable tree topology programming
- Expected: 100× throughput over GPU for small trees

### 6.3 Custom Silicon (Long-term)
- Minimal ISA: PUSH_1, PUSH_X, EML (3 instructions!)
- Stack-based evaluation
- Estimated die area: < 1 mm² in 7nm process
- Power: < 100 mW

## 8. EML for Explainable AI (XAI)

### 8.1 Post-Hoc Explanation
Given any trained black-box model:
1. Generate predictions on a grid of inputs
2. Distill to an EML tree
3. Read the formula as an explanation

**Advantage over LIME/SHAP:** EML gives a *global* explanation (a formula), not just local feature importances.

### 8.2 Concept-Level Explanations
EML tree structure reveals conceptual organization:
- Each EML node represents a "concept" (a sub-computation)
- The tree hierarchy shows how concepts compose
- Pruning a subtree removes a specific concept

### 8.3 Counterfactual Analysis
With a symbolic formula, counterfactual questions become algebra:
- "What input change would change the output by δ?"
- "Which variable has the most impact?"
- "Is there a threshold effect?"

## 9. EML for AI Safety

### 9.1 Formal Verification of Learned Policies
If a robot's policy is an EML tree, we can formally verify:
- "The robot never exceeds speed limit X"
- "The drug dose formula never produces negative values"
- "The financial model never recommends infinite leverage"

### 9.2 Spurious Correlation Detection
In a formula, spurious correlations are visible:
- "Why does the model depend on patient ZIP code?"
- "This variable should appear additively, not multiplicatively"
- "The formula reduces to a constant when this variable is removed"

### 9.3 Certified Robustness
Symbolic analysis of EML formulas can provide:
- Lipschitz bounds (how much the output changes per unit input change)
- Domain validity (where the formula is well-defined)
- Sensitivity analysis (which parameters are critical)

## 10. Open Mathematical Questions

### 10.1 K_EML Complexity Theory
- Is computing K_EML decidable? (Likely undecidable, by analogy with Kolmogorov complexity)
- Are there natural "hard" functions with high K_EML?
- Is K_EML subadditive under composition?

### 10.2 The EML Search Space Topology
- Define a metric on EML trees (tree edit distance + parameter Euclidean distance)
- Is the resulting space connected? Compact? Simply connected?
- Can we define gradient flow on tree space?

### 10.3 EML and Number Theory
- Is π EML-computable with K_EML ≤ 40? (Conjectured yes)
- What is K_EML(ζ(3))? K_EML(γ)?
- Do algebraic numbers have bounded K_EML?

### 10.4 EML and Differential Equations
- Can EML trees represent solutions to generic ODEs?
- What about PDEs? (e.g., heat equation, wave equation)
- Connection to Ritt's theorem on integration in finite terms
