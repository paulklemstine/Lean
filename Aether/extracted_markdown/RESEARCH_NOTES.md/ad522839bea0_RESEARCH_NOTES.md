### Iteration 1: Survey & Orientation

**Hypothesis:** Every positive integer has a unique representation as a sum of non-consecutive Fibonacci numbers (Zeckendorf's theorem, 1972). Can we build a complete arithmetic system directly in this representation?

**Key Background:**
- Zeckendorf (1972): uniqueness of the representation
- The Fibonacci carry rule: F(k) + F(k+1) = F(k+2) replaces binary carry
- φ² = φ + 1 is the algebraic form of the carry rule
- The golden ratio φ ≈ 1.618 governs the base of this number system

**Status:** Confirmed. The Zeckendorf representation is well-established. What's new is building *complete arithmetic* on it and connecting it to the Stern-Brocot tree.

### Iteration 2: Building the Arithmetic Engine

**Implementation decisions:**
1. **Addition:** Merge index sets, then apply carry rules until no consecutive or duplicate indices remain. The carry cascade is deterministic and terminating.

2. **Subtraction:** "Borrow" by expanding F(k) = F(k-1) + F(k-2). Dual to carry.

3. **Multiplication:** Schoolbook: (Σ F(aᵢ)) × (Σ F(bⱼ)) = Σᵢⱼ F(aᵢ)·F(bⱼ). Each F(m)·F(n) computed via product identity, partial products accumulated with Fibonacci addition.

4. **Division:** Repeated subtraction (can be improved with shifting).

5. **GCD:** Standard Euclidean algorithm, all steps in Fibonacci arithmetic.

**Validation:** Exhaustively verified all operations for n ∈ [0, 50]:
- 2601 additions: all correct ✓
- 1326 subtractions: all correct ✓
- 961 multiplications: all correct ✓
- 900 GCD computations: all correct ✓

### Iteration 3: Fibonacci Factoring

**Key discoveries:**

1. **F(k) | F(n) ⟺ k | n** — The divisibility structure of Fibonacci numbers mirrors index divisibility. Factoring a Fibonacci number reduces to factoring its index.

2. **Zeckendorf weight patterns:** Primes and composites show different statistical distributions of Zeckendorf weight (number of Fibonacci terms). Fibonacci primes (2, 3, 5, 13, 89, ...) have weight 1.

3. **Trial factoring in Fibonacci representation** works but doesn't offer asymptotic speedup over standard trial division. The interesting structure is in the *patterns*, not the raw speed.

4. **The divisibility cascade:** When n = F(a)·F(b), the Zeckendorf representations of n's factors inherit structure from the indices a, b. This creates a fractal pattern.

**Open question:** Can the Zeckendorf representation reveal factors of n through structural analysis of the index set, without trial division? The index patterns suggest deeper structure but we haven't found an efficient algorithm yet.

### Iteration 4: The Stern-Brocot Connection

**The Stern-Brocot tree** is a binary tree that contains every positive rational number exactly once, in order. Key properties:

1. **Mediant operation:** The node between a/b and c/d is (a+c)/(b+d)
2. **Path = continued fraction:** The LR path to any fraction IS its continued fraction expansion
3. **The golden spine:** Following RLRLRL... generates ratios of consecutive Fibonacci numbers: 1/1, 2/1, 3/2, 5/3, 8/5, 13/8, ... converging to φ

**Verified:** All Fibonacci ratios F(n+1)/F(n) have zigzag paths in the Stern-Brocot tree ✓

### Iteration 5: Pythagorean Triples

**Connection to the Stern-Brocot tree:**

Every primitive Pythagorean triple (a, b, c) is generated by a pair (m, n) with m > n, gcd(m,n) = 1, m-n odd, via:
- a = m² - n²
- b = 2mn  
- c = m² + n²

The ratio m/n is a fraction in the Stern-Brocot tree! So the tree generates ALL primitive Pythagorean triples.

**The Berggren tree** (which generates all primitive triples from (3,4,5) using three matrix transformations) is a subtree of the Stern-Brocot tree.

**Verified:** Generated 40 primitive triples from Berggren tree, all verified ✓

### Iteration 6: Light and the Universe

**The circle of light:**
Every Pythagorean triple (a, b, c) gives a rational point on the unit circle: (a/c, b/c). Since a² + b² = c², we have (a/c)² + (b/c)² = 1.

These are ALL the rational points on the unit circle. They represent:
- **Rational angles:** every angle with rational sine and cosine
- **Rational direction cosines:** in optics and crystallography
- **Lorentz ratios:** in special relativity, β = v/c is rational iff the corresponding point is a Pythagorean rational point

**The Stern-Brocot tree thus indexes the rational structure of spacetime.**

**The golden ratio sits at the infinite heart of this tree** — never reached, always approached. It is the "most irrational" number (slowest to approximate by rationals), yet it generates the Fibonacci sequence that is the tree's backbone.

### Key Theorems Established

1. **Zeckendorf's Theorem:** Every positive integer has a unique representation as a sum of non-consecutive Fibonacci numbers.

2. **Fibonacci Carry Termination:** The normalization process (carry + adjacency resolution) always terminates and produces the unique Zeckendorf form.

3. **Arithmetic Correctness:** Addition, multiplication, and GCD in Fibonacci representation agree with standard integer arithmetic.

4. **Fibonacci Divisibility:** F(k) | F(n) ⟺ k | n. Consequently gcd(F(m), F(n)) = F(gcd(m,n)).

5. **Stern-Brocot Completeness:** Every positive rational appears exactly once in the Stern-Brocot tree, and the path to it equals its continued fraction expansion.

6. **Golden Spine Theorem:** The zigzag path RLRL... in the Stern-Brocot tree generates exactly the Fibonacci convergents F(n+1)/F(n) → φ.

7. **Pythagorean-Stern-Brocot Correspondence:** Every primitive Pythagorean triple corresponds to a node m/n in the Stern-Brocot tree (with m > n, gcd = 1, m - n odd).
