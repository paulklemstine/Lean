## Overview

This repository contains a unified research framework and **10 fully functional Python demos** exploring the intersection of chaos theory, high-dimensional computing, topology, and evolutionary algorithms. Each demo is a self-contained, runnable application implementing a genuinely novel algorithmic paradigm.

## 🧪 The 10 Demos

All demos require only **Python 3 + NumPy**. No GPU, no deep learning frameworks, no cloud APIs.

```bash
pip install numpy
python demos/01_adversarial_swarm.py
```
