## Key Insight

> The tropical semiring, where every element is idempotent, may be the natural habitat of computation itself.

The idempotent density ρ parametrized by q interpolates:
- **q → 0** (tropical): ρ = 1, every element is idempotent
- **q = 1** (classical): ρ = 2^ω(n)/n, sparse idempotents
- **q → ∞** (quantum): ρ → 0, projections become rare
