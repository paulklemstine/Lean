# 🌻 Fibonacci Factoring: The Secret Arithmetic of the Golden Ratio

## Overview

Can we factor integers by exploiting the Fibonacci base (Zeckendorf) representation? This project investigates that question through three lenses: **Fibonacci entry points**, **tropical semirings**, and **long-form Fibonacci multiplication** — and discovers that while the factoring shortcut doesn't exist, the journey reveals a magnificent unification through the Stern-Brocot tree.

## Key Findings

### ✓ The Entry Point Method Works
Every integer n has a **Fibonacci entry point** α(n) — the smallest k where F_k ≡ 0 (mod n). If N = p×q, then α(N) = lcm(α(p), α(q)), and probing divisors of α(N) via gcd(F_d, N) reveals factors. **100% success rate** on all tested composites.

### ✗ But It's O(N), Not O(√N)
Computing α(N) takes up to 6N steps — worse than trial division at O(√N). The Fibonacci sequence *remembers* factorizations through its periodicity, but accessing that memory isn't faster than brute force.

### ✓ The Five Faces of One Tree
The Stern-Brocot tree simultaneously generates:
1. **All positive fractions** (in order, each exactly once)
2. **All continued fractions** (tree path = CF expansion)
3. **The Fibonacci sequence** (golden spine RLRL... → φ)
4. **All Pythagorean triples** (via Euclid's parametrization)
5. **All rational angles** (points on the unit circle)

### ✓ Tropical Structure of Carries
Fibonacci carries form a **tropical optimization** — each normalization step reduces a potential function, and the Zeckendorf form is the tropical minimum.

## Formal Proofs (Lean 4)

Ten theorems formally verified in `FibonacciArithmetic.lean`:

| Theorem | Statement |
|---------|-----------|
| `fibonacci_carry_rule` | F(n) + F(n+1) = F(n+2) |
| `fibonacci_double_carry` | 2·F(n+2) = F(n+3) + F(n) |
| `fibonacci_gcd_identity` | gcd(F_m, F_n) = F_{gcd(m,n)} |
| `fib_dvd_of_dvd` | m ∣ n → F_m ∣ F_n |
| `euclid_pythagorean` | (m²-n²)² + (2mn)² = (m²+n²)² |
| `fib_mod_periodic` | ∃ π ≥ 1, ∀ k, F(k+π) ≡ F(k) (mod m) |
| `mediant_between` | a/b < (a+c)/(b+d) < c/d |
| `mediant_coprime` | Stern-Brocot mediants preserve coprimality |
| `fib_sum` | Σ F(k) for k=0..n-1 = F(n+1) - 1 |
| `fib_coprime` | gcd(F_n, F_{n+1}) = 1 |

All proofs are complete — **zero sorries remain**. Only standard axioms used (propext, Classical.choice, Quot.sound).
