## Key Theorems

1. **Consciousness Fixed Point** — Contractive self-loops have a unique conscious (fixed-point) state
2. **Exponential Error Decay** — Self-correction reduces error at rate c^n
3. **Ambiguity Decomposition** — Ensemble error = avg individual error - disagreement
4. **Wisdom of Crowds** — Ensemble prediction ≤ average individual prediction error
5. **No Perfect Introspection** — Gödelian limit: no system can perfectly predict itself
6. **Team Monotonicity** — Adding team members never hurts performance
7. **Calibration Convergence** — Self-assessed calibration converges to true calibration
8. **Conscious Bayesian Update** — Calibration-aware Bayesian updating
