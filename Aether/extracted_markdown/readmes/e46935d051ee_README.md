## 🚀 Quick Start

1. Open `app/index.html` in a modern web browser (Chrome or Firefox recommended)
2. Click **▶ ENTER THE VOID**
3. Put on headphones (required for binaural beats / hypnosis features)
4. Adjust controls to taste

**No installation, no server, no dependencies.** Just a browser.

## 🎵 Features

### Music Engine
- **12 Electronic Genres:** Techno, House, Dubstep, Phonk, Wave, EBM, EDM, Trance, Acid House, Ambient, Industrial, Drum & Bass
- **Algorithmic Composition:** Markov chain melodies, Euclidean rhythms, cellular automata patterns, L-system structural evolution
- **Full Synthesis:** Kick, snare, hi-hat, bass, lead, and pad voices via Web Audio API
- **Effects Chain:** Delay (BPM-synced), convolution reverb, waveshaper distortion, dynamics compression
- **Infinite Variation:** Patterns evolve every N bars — never repeats

### Visual Engine
- **10 Psychedelic Modes:** Fractal Tunnel, Plasma Ocean, Sacred Geometry, Waveform Matrix, Particle Storm, Hypno Spiral, DMT Gateway, Void Meditation, Kaleidoscope, Neural Network
- **Audio-Reactive:** Real-time FFT analysis drives all visual parameters
- **WebGL Shaders:** GPU-accelerated fragment shaders at 60fps
- **Based on neuroscience:** Implements Klüver's form constants (tunnel, spiral, lattice, cobweb)

### Consciousness Engineering
- **Binaural Beats:** Theta (4–8 Hz), Alpha (8–14 Hz), or Beta (14–22 Hz) targeting
- **Rhythmic Entrainment:** Motor cortex synchronization through steady pulse
- **Photic Driving:** Visual flicker at entrainment frequencies
- **Tension-Release Dynamics:** Dopaminergic reward cycle manipulation

## 🎛️ Controls

| Control | Function |
|---------|----------|
| **Genre tags** | Switch between 12 EDM genres |
| **Intensity** | Musical density, volume, filter openness |
| **Chaos** | Pattern mutation rate, algorithmic complexity |
| **Depth** | Reverb/delay effect level |
| **Visual Intensity** | Shader brightness and saturation |
| **Hypnosis** | Binaural beat depth and entrainment targeting |
| **MUTATE** | Force immediate pattern evolution |
| **VISION** | Cycle through 10 visual modes |

### Keyboard Shortcuts
- `Space` — Play/Pause
- `M` — Mutate
- `V` — Cycle visual mode
- `F` — Toggle fullscreen
- `1-9` — Select genre directly
