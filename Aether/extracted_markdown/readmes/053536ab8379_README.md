# A* Factoring via the Pythagorean Triple Tree

> *"The integers are the work of God; all else is the work of man." — Leopold Kronecker*

An experimental framework for integer factorization using **A\* search** with an **energy heuristic** to navigate the **Berggren ternary tree** of Pythagorean triples.

## Overview

Every primitive Pythagorean triple (a, b, c) with a² + b² = c² lives in an infinite ternary tree rooted at (3, 4, 5). Each triple encodes a difference of squares: a² = (c−b)(c+b). This project uses A* search to find triples whose components share factors with a target composite number N.

## How It Works

1. **Tree:** The Berggren tree generates ALL primitive Pythagorean triples via three matrix transformations from (3,4,5).
2. **Energy:** A multi-channel heuristic (GCD, residue, modular) measures how close each triple is to revealing a factor.
3. **A\* Search:** Explores the tree prioritizing low-energy (promising) nodes.
4. **Scaling:** Also checks non-primitive triples k·(a,b,c) at each node.

## Key Results

- A* consistently outperforms BFS on the same tree structure
- The energy landscape shows genuine structure (not random)
- The algorithm factors semiprimes up to ~10⁸ within reasonable node budgets
- Not competitive with quadratic sieve for large numbers (as expected)
