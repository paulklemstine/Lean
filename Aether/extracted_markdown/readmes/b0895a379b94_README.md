## Key Discoveries

### 1. The Lorentz Group Theorem (New)
The Berggren matrices A, B, C are elements of O(2,1;ℤ), the integer Lorentz group:
M^T · diag(1,1,−1) · M = diag(1,1,−1). Pythagorean triples are "light rays" in Minkowski space. **Formally verified in Lean 4.**

### 2. The Gaussian Square Correspondence (New)
Every primitive Pythagorean triple (a,b,c) = z² for z = m + ni ∈ ℤ[i]. The Berggren tree is a tree of Gaussian integer squares.

### 3. The Path–CF Correspondence (New)
Berggren tree paths encode continued fraction expansions of m/n through a ternary alphabet {A,B,C}, extending the binary Stern–Brocot encoding.

### 4. The Pythagorean Entropy (New)
H_P(n) = log₂|T(n)| measures factoring information with optimal efficiency. For semiprimes, exactly 2 bits.

### 5. The Ternary Tree Zoo (New)
Unified framework connecting Berggren, Markov, Apollonian, and Eisenstein trees via Vieta jumping over quadratic forms.

### 6. Depth-Factor Theorem (Confirmed)
For n = p × q: depth of factor-p triple = (q−3)/2. Verified for all semiprimes up to 200.
