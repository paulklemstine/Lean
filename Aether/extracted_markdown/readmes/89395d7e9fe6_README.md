# Demo Scripts

Python visualization scripts for the 8 research problems.

## Scripts

| Script | Output | Description |
|--------|--------|-------------|
| `demo_berggren_tree.py` | `berggren_tree.png`, `lorentz_cone.png` | Berggren tree structure, descent efficiency, light cone |
| `demo_sauer_shelah.py` | `sauer_shelah.png` | VC dimension bounds, shattering examples, bound tightness |
| `demo_hyperbolic_nn.py` | `hyperbolic_nn.png` | Poincaré disk embedding, Lorentz attention, invariance |
| `demo_hopf_robustness.py` | `hopf_robustness.png` | Hopf fibers, topological robustness, Pythagorean weights |
| `demo_crystalline_brain.py` | `crystalline_brain.png` | Unified 9-panel architecture overview |

## Running

```bash
pip install matplotlib numpy
python3 demo_berggren_tree.py
python3 demo_sauer_shelah.py
python3 demo_hyperbolic_nn.py
python3 demo_hopf_robustness.py
python3 demo_crystalline_brain.py
```

## Dependencies

- Python 3.8+
- NumPy
- Matplotlib
