## 🧮 The Seven Algorithms

| # | Algorithm | Input | Output | Complexity | Novel? |
|---|-----------|-------|--------|------------|--------|
| 1 | **Stern-Brocot Navigator** | Real number (stream) | Best rational approximations | O(1) amortized | Streaming variant ✨ |
| 2 | **Euclidean Rhythm** | k pulses, n slots | Maximally uniform rhythm | O(k + n) | Weighted + hierarchical ✨ |
| 3 | **Golden Hash** | Integer key | Hash bucket | O(1) | Optimality proof ✨ |
| 4 | **Calkin-Wilf Bijection** | Positive rational p/q | Index n ∈ ℕ | O(log(p+q)) | Inverse function ✨ |
| 5 | **Mediant Sort** | List of rationals | Sorted list + SB encodings | O(n log D) | Adaptive sort ✨ |
| 6 | **Zeckendorf Arithmetic** | Fibonacci representations | Sum/product in Fibonacci | O(n) add, O(n²) mul | Complete arithmetic ✨ |
| 7 | **Balanced Ternary Multiplier** | Balanced ternary numbers | Product | O(n^1.585) Karatsuba | Ternary Karatsuba ✨ |

## 🌟 The Grand Unification

All seven algorithms connect through the **golden ratio** φ = (1+√5)/2:

> The golden ratio is the **most irrational** number — its continued fraction
> [1; 1, 1, 1, ...] has the smallest possible partial quotients. This extremal
> property makes it the optimal choice for any algorithm depending on the
> uniform distribution of {nα mod 1}.

This manifests as:
- **Best hash multiplier** (minimizes worst-case gap ratio)
- **Most complex rhythm** (maximally aperiodic Euclidean pattern)  
- **Hardest to approximate** (Hurwitz's theorem is tight for φ)
- **Densest Fibonacci encoding** (digit density = 1/φ²)
- **Deepest Stern-Brocot paths** (slowest-growing convergent denominators)
