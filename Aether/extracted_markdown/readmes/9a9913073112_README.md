# Dickian Mathematics: The Formal Mathematics of Philip K. Dick

> *"Reality is that which, when you stop believing in it, doesn't go away."* — Philip K. Dick

## Overview

This project develops **five new mathematical frameworks** inspired by the ontological architecture of Philip K. Dick's science fiction. Each framework yields genuine theorems, computable invariants, and practical applications — all formally verified in Lean 4 with Mathlib.

## Formally Verified Theorems (Lean 4)

All 11 core theorems have been **machine-verified** in Lean 4 with Mathlib. No sorry remains. Only standard axioms (propext, Classical.choice, Quot.sound) are used.

### Reality Layer Algebras
- `dickian_fixed_point_exists` — Knaster-Tarski: stable realities always exist
- `black_iron_prison_unique` — Contractive perception has a unique (worst) fixed point

### Entropic Decay (Ubik)
- `ubik_collapse_time_formula` — Finite-time collapse under super-linear decay
- `ubik_stabilizer_formula` — The Ubik stabilizer: -α·C^β + α·C^β = 0

### Identity Topology (A Scanner Darkly)
- `connected_image_connected` — Continuous image of connected space is connected
- `no_retraction_to_disconnected` — Connected space cannot retract to disconnected (irreversibility)

### Pre-cognitive Game Theory (Minority Report)
- `perfect_precog_no_free_will` — Perfect prediction determines action
- `minority_report_paradox` — Prediction + prevention → all predictions false

### Empathy Networks (Mercerism)
- `mercerism_instability_condition` — Above w_c: collective consciousness emerges
- `below_critical_stable` — Below w_c: individual isolation

### Dickian Information Principle
- `self_reference_bound` — Non-identity functions have strictly fewer fixed points
