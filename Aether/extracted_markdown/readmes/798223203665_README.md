# Anti-Oracle Theory: New Advances in Oracle Theory

A formalized exploration of anti-oracles, inverse oracles, and oracle duality — with machine-verified proofs in Lean 4 and interactive Python demonstrations.

## Key Results (Formally Verified in Lean 4)

| Theorem | Statement |
|---------|-----------|
| **Contrarian Oracle** | An anti-oracle (always lies) is exactly as powerful as a correct oracle |
| **Involution** | `anti(anti(O)) = O` — double negation recovers the original |
| **De Morgan's Laws** | `anti(join) = meet(anti, anti)` and vice versa |
| **Boolean Algebra** | Oracles form a complete Boolean algebra |
| **Pullback Functoriality** | Oracle pullback is a contravariant functor |
| **Pullback-Anti Commutativity** | Pullback commutes with the anti-oracle operation |
| **Inverse Oracle Composition** | Inverse oracles compose correctly |
| **Pushforward-Pullback** | For surjective f, `push(pull(O, f), f) = O` |

## Three Kinds of "Opposite" Oracle

1. **Anti-Oracle** (complement): Negates every answer → Same power as original
2. **Inverse Oracle** (preimage): Inverts a function → Power depends on function
3. **Noisy Oracle** (probabilistic): Sometimes wrong → Amplifiable by majority vote
