# Meta-Oracle: Exotic Algebras for Self-Referential AI Reasoning

A formally verified framework combining tropical semirings, oracle algebras, and Knaster–Tarski fixed-point theory to build a convergent meta-reasoning AI agent.

## Project Structure

```
├── RequestProject/
│   └── ExoticAlgebras.lean     # Lean 4 formalization (all proofs verified)
├── meta_oracle_agent.py         # Python CLI meta-oracle agent
├── research_paper.md            # Full research paper
├── scientific_american_article.md  # Popular science article
└── README.md                    # This file
```

## Quick Start

### Run the Meta-Oracle Agent

```bash
python3 meta_oracle_agent.py
```

Then type natural-language queries:
```
🔮 meta-oracle> What is a tropical semiring?
🔮 meta-oracle> Explain the meta oracle fixed point theorem
🔮 meta-oracle> Tell me about exotic algebras
🔮 meta-oracle> help
🔮 meta-oracle> quit
```

### Verify the Lean Proofs

```bash
lake build RequestProject.ExoticAlgebras
```

## Verified Theorems

| Theorem | Description |
|---------|-------------|
| `TropicalSemiring.add_idempotent` | min(a, a) = a |
| `TropicalSemiring.left_distrib'` | a + min(b, c) = min(a+b, a+c) |
| `TropicalSemiring.right_distrib'` | min(a, b) + c = min(a+c, b+c) |
| `oracle_iter_monotone` | Ωⁿ is monotone when Ω is |
| `oracle_iter_ascending` | Inflationary Ω produces ascending chains |
| `meta_oracle_fixed_point` | **∃ x, Ω(x) = x** (Knaster–Tarski) |
| `reflection_principle` | Pre-fixed points are oracle-closed |
| `oracle_idempotent_at_fixedpoint` | Ω(Ω(x)) = Ω(x) at fixed points |
| `oracle_composition_monotone` | Ω₁ ∘ Ω₂ is monotone |
