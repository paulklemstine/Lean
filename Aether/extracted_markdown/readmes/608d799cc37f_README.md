# ShefferAI: Formally Verified Sheffer Algebra Theory

## Overview

This project provides a **complete, machine-verified formalization** of the Sheffer algebra — the algebra of functions generated by the softplus function σ(x) = log(1 + eˣ) under affine pre-composition and affine combination.

**70 declarations, 0 sorry statements, standard axioms only.**

## Quick Start

lake build ShefferAI

# Run numerical experiments  
cd python_demos && python3 sheffer_numerical_explorer.py

cd python_demos && python3 sheffer_visualizations.py

## Key Theorems

### Membership Results
- `softplus_mem_sheffer` — σ ∈ ShefferAlg
- `id_mem_sheffer` — identity ∈ ShefferAlg (x = σ(x) − σ(−x))
- `affine_mem_sheffer` — ax + b ∈ ShefferAlg
- `log_sigmoid_mem_sheffer` — log(S(x)) = x − σ(x) ∈ ShefferAlg
- `bounded_sheffer_exists` — bounded non-constant functions exist

### Exclusion Results
- `exp_not_mem_sheffer` — eˣ ∉ ShefferAlg (Lipschitz barrier)
- `pow_not_mem_sheffer` — xⁿ ∉ ShefferAlg for n ≥ 2
- `sin_not_mem_sheffer` — sin ∉ ShefferAlg (limit trichotomy)
- `cos_not_mem_sheffer` — cos ∉ ShefferAlg (limit trichotomy)

### Structural Results
- `sheffer_expr_lipschitz` — every Sheffer expression is Lipschitz
- `sheffer_expr_tendsto_both` — limit trichotomy at ±∞
- `derivative_limit_pairs_surjective` — Q39 resolved

### Orbit Dynamics
- `softplus_iter_eq` — σⁿ(x) = log(n + eˣ)
- `softplus_iter_hasDerivAt` — (σⁿ)'(x) = eˣ/(n + eˣ)
- `softplus_iter_log_nat` — σⁿ(log k) = log(n + k)
- `softplus_iter_growth_decomp` — σⁿ(x) = log(n) + log(1 + eˣ/n)
