## The Core Insight

The stereographic projection σ⁻¹: ℝⁿ → Sⁿ \ {N} is a conformal diffeomorphism.
Adding the point at infinity gives the one-point compactification:

**ℝⁿ ∪ {∞} ≅ Sⁿ**

The flat, infinite universe and the curved, finite sphere are **the same mathematical object** — two descriptions of identical structure related by the conformal factor λ = 2/(1 + |x|²).
