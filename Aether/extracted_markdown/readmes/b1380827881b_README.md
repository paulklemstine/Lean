# Formalizing the Unformalizable

**Machine-verified proofs of the limits of machine verification.**

*A strange loop: using a computer to prove that computers have limits.*

---

## Overview

This project formalizes the fundamental impossibility theorems of mathematical logic in Lean 4:

- **Cantor's Diagonal Argument** — No set surjects onto its power set
- **Gödel's Incompleteness Theorems** — Sound formal systems are incomplete
- **Turing's Halting Problem** — No universal decision procedure exists
- **Tarski's Undefinability of Truth** — Truth cannot define itself
- **Lawvere's Fixed Point Theorem** — The category-theoretic unification
- **Russell's Paradox, Curry's Paradox, the Liar** — Self-reference and its limits

**Every theorem is machine-verified with zero sorries and only standard axioms.**

## The Central Irony

We used Lean 4 (a formal proof assistant) to prove that formal proof assistants
have inherent limits. This is not a contradiction — it is the deepest demonstration
of the theorems' content:

- **What IS formalized**: The meta-theorems proving limits exist (Gödel, Cantor, Turing)
- **What CANNOT be formalized**: The specific sentences witnessing those limits within the system

The proof that blind spots exist is not itself a blind spot.
