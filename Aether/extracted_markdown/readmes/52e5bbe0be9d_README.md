# Pythagorean Harmonic Number Theory
## A Grand Unification of Mathematics Through Machine-Verified Proofs

---

### Overview

This project formalizes and machine-verifies **5,052 theorems** across **50+ branches of mathematics**, all connected through the ancient Pythagorean equation $a^2 + b^2 = c^2$ and its modern generalizations.

**Scale**: 265 Lean files · 54,758 lines of verified code · 830 definitions · 92 structures  
**Technology**: Lean 4.28.0 · Mathlib v4.28.0  
**Organization**: 19 thematic divisions in `GrandUnification/`

---

### Quick Start

```bash
lake build Basic            # Build core Pythagorean triple theory
lake build BerggrenTree     # Build Berggren tree formalization
lake build                  # Build all 62 default targets
```

```
Numbers ←—Gaussian—→ Algebra ←—SL₂ℤ—→ Geometry ←—Stereo—→ Topology ←—Tropical—→ Computation
```
