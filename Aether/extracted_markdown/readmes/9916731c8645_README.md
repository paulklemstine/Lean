# Forced Idempotent Collapse

**Can we collapse everything? Yes.**

This project formalizes and proves the **Universal Idempotent Collapse Theorem**: for any type α and any nonempty subset S ⊆ α, there exists an idempotent endomorphism f : α → α whose image is exactly S. All proofs are machine-verified in Lean 4 with Mathlib — zero sorries, zero non-standard axioms.

## Key Theorems (all proved in Lean 4)

| Theorem | Statement |
|---------|-----------|
| `universal_forced_collapse` | ∀ S ⊆ α, S ≠ ∅ → ∃ f, f∘f=f ∧ range(f)=S ∧ ∀n≥1, f^n=f |
| `idempotent_image_eq_fixed` | f∘f=f → Image(f) = Fix(f) |
| `idempotent_iterate_eq` | f∘f=f → f^n = f for all n ≥ 1 |
| `collapse_inj_on_image` | f∘f=f → f is injective on its image |
| `identity_unique_total_preserving` | f∘f=f ∧ f surjective → f = id |
| `collapse_spectrum` | ∀ 0<m≤n, ∃ f:Fin n→Fin n, f∘f=f ∧ |Image(f)|=m |

## The Four Pillars

1. 🌴 **Tropical**: Valuation maps polynomials to piecewise-linear shadows (v∘v = v)
2. 🔮 **Oracle**: Truth functions collapse queries in one step (O∘O = O)
3. 🌀 **Holographic**: RG flow converges to conformal fixed points (RG^∞∘RG^∞ = RG^∞)
4. 🔷 **Cayley-Dickson**: Norm projects any algebra back to ℝ (‖‖x‖‖ = ‖x‖)
