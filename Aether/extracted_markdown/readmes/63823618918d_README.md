# Oracle Theory — Formalized

A machine-verified formalization of oracle theory in Lean 4, with Python demonstrations and a Scientific American–style research paper.

## Overview

This project formalizes the algebra of oracles, anti-oracles, inverse oracles, and the "inverse stereographic projection" encoding that converts any oracle over a countable domain into an integer-indexed truth lookup. All Lean proofs compile with **zero `sorry`s** and use only standard axioms.

## Key Theorems (Formally Verified)

| Theorem | Statement | File |
|---------|-----------|------|
| Contrarian Oracle | `x ∈ O ↔ x ∉ anti(O)` | Basic.lean |
| Involution | `anti(anti(O)) = O` | Basic.lean |
| XOR Universality | `O ⊕ anti(O) = ⊤` | Basic.lean |
| De Morgan (join) | `anti(O₁ ∪ O₂) = anti(O₁) ∩ anti(O₂)` | Basic.lean |
| De Morgan (meet) | `anti(O₁ ∩ O₂) = anti(O₁) ∪ anti(O₂)` | Basic.lean |
| Pullback Functoriality | `pullback(O, g∘f) = pullback(pullback(O, g), f)` | InverseOracle.lean |
| Pullback–Anti Commute | `anti(pullback(O, f)) = pullback(anti(O), f)` | InverseOracle.lean |
| Pushforward–Pullback | `push(pull(O, f), f) = O` (f surjective) | InverseOracle.lean |
| Inverse Oracle Compose | `(g∘f)⁻¹(z) = ⋃_{y ∈ g⁻¹(z)} f⁻¹(y)` | InverseOracle.lean |
| Integer Lookup | `encode(x) ∈ S ↔ x ∈ O` | InverseOracle.lean |
| Cardinality Sum | `|O| + |anti(O)| = |α|` | NoisyOracle.lean |

## Building

```bash
# Build the Lean formalization
lake build

# Run Python demos
python3 demos/oracle_demo.py
python3 demos/oracle_visualization.py
```

## Requirements

- **Lean**: v4.28.0
- **Mathlib**: v4.28.0
- **Python**: 3.8+ (no external dependencies for demos)

## Axioms Used

All proofs use only the standard foundational axioms:
- `propext` (propositional extensionality)
- `Classical.choice` (axiom of choice)
- `Quot.sound` (quotient soundness)

Verified via `#print axioms` for all theorems.
