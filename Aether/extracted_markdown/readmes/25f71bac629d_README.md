## 🎵 What Is This?

Ecstasis 4 is an **infinite jukebox** — a browser-based application that generates electronic dance music and psychedelic visuals in real time, forever, without repeating. It synthesizes all sounds from scratch using the Web Audio API, emulating legendary instruments:

- **Roland TR-808** — The drum machine that defined hip-hop, electro, and trap
- **Roland TR-909** — The drum machine that powered house and techno
- **Roland TB-303** — The bass synthesizer that birthed acid house
- **MC-505/707/909** — Groove box sequencing and synthesis paradigms

## 🚀 Quick Start

1. Open `app/index.html` in a modern browser (Chrome/Firefox/Edge recommended)
2. Click the play button or press **Space**
3. Select a genre or let it auto-transition
4. Put on headphones for full binaural effect
5. Go fullscreen with **F**
6. Hide the UI with **H**
7. Let go
