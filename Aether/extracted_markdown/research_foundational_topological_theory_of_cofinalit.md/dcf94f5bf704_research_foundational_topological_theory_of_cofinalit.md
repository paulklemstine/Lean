# Cofinality Spectra and the P-Filter Property in Ordered Topological Spaces

## Abstract

We develop the foundational theory of cofinality spectra for linearly ordered topological spaces equipped with the order topology. We introduce the concepts of **tame** and **wild** points based on the countability of left and right cofinalities, and prove three main results: (1) the **Bound Lemma**, showing that countable subsets below a wild point admit strict upper bounds; (2) the **P-Filter Theorem**, proving that fully wild points (uncountable cofinality from both sides) satisfy the P-filter property — countable intersections of neighborhoods remain neighborhoods; and (3) the **Tame–First-Countable Equivalence**, establishing that a point is tame if and only if its neighborhood filter is countably generated. As an application, we show that all real numbers are tame. We introduce the **cofinality profile** as a novel four-way classification (tame, left-wild, right-wild, fully wild) and formulate a conjecture on the openness of the tame locus. All results are formalized in Lean 4 with proofs verified by the Lean kernel.

## 1. Introduction

The interplay between order-theoretic and topological properties in linearly ordered spaces is a classical subject. The order topology, generated by open rays, provides a natural topology on any linearly ordered set, and the resulting topological properties encode information about the order's combinatorial structure.

A fundamental question is: **when does a point in an ordered topological space have a countable neighborhood basis?** This property — first-countability at a point — determines whether sequential methods suffice for analyzing convergence. In metrizable spaces, every point is first-countable, but linearly ordered spaces with the order topology can exhibit non-first-countable behavior when the underlying order has uncountable cofinality.

We systematize this phenomenon through the **cofinality spectrum**, which assigns to each point a classification based on the countability of its left and right cofinalities. Our main results are:

1. **Tame ↔ Countably Generated** (Theorem 3.3): A point is tame (countable cofinality from both sides) if and only if its neighborhood filter is countably generated.

2. **P-Filter Theorem** (Theorem 3.2): Points with uncountable cofinality from both sides have the P-filter property — countable intersections of neighborhoods are neighborhoods.

3. **Bound Lemma** (Theorem 3.1): Any countable subset below a point with uncountable left cofinality admits a strict upper bound below the point.

## 2. Definitions

### 2.1 Core Cofinality Concepts

Let $(L, \leq)$ be a linearly ordered set with the order topology.

**Definition 2.1** (Cofinal Below). A set $S \subseteq \{y : y < x\}$ is *cofinal below* $x$ if for every $y < x$, there exists $z \in S$ with $y \leq z$.

**Definition 2.2** (Coinitial Above). A set $S \subseteq \{y : y > x\}$ is *coinitial above* $x$ if for every $y > x$, there exists $z \in S$ with $z \leq y$.

**Definition 2.3** (Countable Left/Right Cofinality).
- $x$ has *countable left cofinality* if $x$ is a minimum element (nothing below it) or there exists a countable set cofinal below $x$.
- $x$ has *countable right cofinality* if $x$ is a maximum element or there exists a countable set coinitial above $x$.

**Definition 2.4** (Tame and Wild Points).
- $x$ is *tame* if it has countable left and right cofinality.
- $x$ is *wild* if it is not tame.

**Definition 2.5** (Tame and Wild Loci).
- The *tame locus* $\mathcal{T}(L) = \{x \in L : x \text{ is tame}\}$.
- The *wild locus* $\mathcal{W}(L) = \{x \in L : x \text{ is wild}\}$.

These clearly partition $L$: $\mathcal{T}(L) \cup \mathcal{W}(L) = L$ and $\mathcal{T}(L) \cap \mathcal{W}(L) = \emptyset$.

### 2.2 The Cofinality Profile

**Definition 2.6** (Cofinality Type). The *cofinality type* of $x$ is one of:
- **Tame**: countable cofinality from both sides.
- **Left-wild**: uncountable left cofinality, countable right cofinality.
- **Right-wild**: countable left cofinality, uncountable right cofinality.
- **Fully wild**: uncountable cofinality from both sides.

This four-way classification is a novel invariant that refines the tame/wild dichotomy.

### 2.3 The P-Filter Property

**Definition 2.7** (P-Filter Property). A point $x$ has the *P-filter property* if for every sequence $(U_n)_{n \in \mathbb{N}}$ of neighborhoods of $x$, the intersection $\bigcap_n U_n$ is again a neighborhood of $x$.

This is strictly stronger than the filter axiom (closure under finite intersections).

## 3. Main Results

### 3.1 The Bound Lemma

**Theorem 3.1** (Bound Lemma). Let $x$ have uncountable left cofinality. If $S \subseteq \{y : y < x\}$ is countable, then there exists $y < x$ with $z < y$ for all $z \in S$.

*Proof sketch.* By contraposition: if no such $y$ exists, then $S$ is cofinal below $x$ (for every $y < x$, some $z \in S$ satisfies $y \leq z$), contradicting uncountable left cofinality. □

The symmetric statement holds for right cofinality.

### 3.2 The P-Filter Theorem

**Theorem 3.2** (P-Filter Theorem). If $x$ has uncountable cofinality from both sides (fully wild), then $x$ has the P-filter property.

*Proof.* Let $(U_n)_{n \in \mathbb{N}}$ be neighborhoods of $x$. Since $x$ has uncountable left cofinality, $x$ is not a minimum, so elements exist below $x$. Similarly for above. By the order topology basis (open intervals), each $U_n$ contains an interval $(a_n, b_n)$ with $a_n < x < b_n$.

The set $\{a_n : n \in \mathbb{N}\}$ is countable and contained in $\{y : y < x\}$. By the Bound Lemma, there exists $a$ with $a_n < a < x$ for all $n$. Similarly, there exists $b$ with $x < b < b_n$ for all $n$.

The interval $(a, b)$ satisfies:
- $(a, b) \in \mathcal{N}(x)$ since $a < x < b$.
- $(a, b) \subseteq \bigcap_n U_n$: for any $z \in (a, b)$ and any $n$, we have $a_n < a < z < b < b_n$, so $z \in (a_n, b_n) \subseteq U_n$.

Therefore $\bigcap_n U_n \in \mathcal{N}(x)$. □

### 3.3 The Tame–First-Countable Equivalence

**Theorem 3.3.** A point $x$ in a linearly ordered topological space is tame if and only if its neighborhood filter $\mathcal{N}(x)$ is countably generated.

*Proof sketch (forward direction).* If $x$ is tame, let $S_l$ be a countable cofinal set below $x$ (or $x$ is a minimum) and $S_r$ a countable coinitial set above $x$ (or $x$ is a maximum). The neighborhood filter decomposes as $\mathcal{N}(x) = L \sqcap R$ where $L = \bigsqcap_{a < x} \mathcal{P}(\{y : y > a\})$ and $R = \bigsqcap_{b > x} \mathcal{P}(\{y : y < b\})$. By cofinality, $L$ is generated by $\{(a, \infty) : a \in S_l\}$, which is countable. Similarly for $R$. The infimum of two countably generated filters is countably generated.

*Proof sketch (backward direction).* Given a countable antitone basis $(V_n)$ for $\mathcal{N}(x)$: if $x$ is a minimum, left cofinality is trivially countable. Otherwise, by `exists_Ioc_subset_of_mem_nhds`, each $V_n$ contains an interval $(l_n, x]$ with $l_n < x$. The set $\{l_n : n \in \mathbb{N}\}$ is countable and cofinal below $x$: for any $y < x$, the set $(y, \infty) \in \mathcal{N}(x)$, so some $V_m \subseteq (y, \infty)$, giving $l_m \geq y$ (otherwise $y \in (l_m, x] \subseteq V_m \subseteq (y, \infty)$ would give $y > y$, a contradiction). □

### 3.4 Application: All Real Numbers are Tame

**Theorem 3.4.** Every $x \in \mathbb{R}$ is tame.

*Proof.* The set $\{x - 1/(n+1) : n \in \mathbb{N}\}$ is countable and cofinal below $x$ (by the Archimedean property). Similarly, $\{x + 1/(n+1) : n \in \mathbb{N}\}$ is countable and coinitial above $x$. □

## 4. The Cofinality Profile as a Topological Invariant

The four-way cofinality classification provides finer information than the tame/wild dichotomy. Each type has distinct analytical signatures:

| Type | Left Cof. | Right Cof. | Sequential from left | Sequential from right | P-filter |
|------|-----------|------------|---------------------|----------------------|----------|
| Tame | Countable | Countable | ✓ | ✓ | Sometimes |
| Left-wild | Uncountable | Countable | ✗ | ✓ | Unknown |
| Right-wild | Countable | Uncountable | ✓ | ✗ | Unknown |
| Fully wild | Uncountable | Uncountable | ✗ | ✗ | ✓ (Thm 3.2) |

The P-filter column for left-wild and right-wild points remains open. We conjecture that it fails in general.

## 5. Conjectures and Future Work

### 5.1 Tame Locus Openness Conjecture

**Conjecture 5.1.** In any linearly ordered topological space with the order topology, the tame locus $\mathcal{T}(L)$ is an open set.

*Evidence.* If $x$ is tame, witnessed by cofinal $S_l$ and coinitial $S_r$, then nearby points (in an interval determined by $S_l$ and $S_r$) can potentially reuse the same witnesses. A disproof would require constructing a tame point as a limit of wild points.

### 5.2 Partial P-Filter for Half-Wild Points

**Conjecture 5.2.** If $x$ is left-wild but right-tame, then countable intersections of neighborhoods from the left (sets containing $x$ and an interval to its left) remain neighborhoods from the left.

### 5.3 Surreal Calculus

The P-filter theorem suggests that analysis on the surreal numbers (and similar spaces with uncountable cofinality) should use filter-based rather than sequence-based methods. The P-filter property at wild points provides a "countable stability" that could serve as the foundation for a surreal calculus.

## 6. Related Work

The cofinality spectrum connects to several established areas:

- **Descriptive set theory**: The tame/wild partition mirrors the Borel/non-Borel distinction, where countable processes determine accessibility.
- **Cardinal invariants**: The cofinality of Iio $x$ as a directed set is a cardinal invariant studied in set theory.
- **P-points in ultrafilters**: The P-filter property at wild points is analogous to the P-point property in ultrafilter theory, where similar countable-intersection closure holds.
