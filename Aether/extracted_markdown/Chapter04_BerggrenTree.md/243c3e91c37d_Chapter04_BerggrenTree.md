### A 4,000-Year-Old Discovery

The Babylonians knew it. The Egyptians used it to build pyramids. Pythagoras
(or his school) proved it: **a² + b² = c².** The most famous equation in
mathematics.

But here's what most people don't know: **every** primitive Pythagorean triple
(one where a, b, c share no common factor) can be generated from the single
triple (3, 4, 5) using exactly three matrix multiplications. The structure is
a **tree** — an infinite, perfectly organized family tree where (3, 4, 5) is
the ancestor of every right triangle with integer sides.

This tree was discovered by Berggren in 1934, and our project contains the most
comprehensive machine-verified formalization of it ever created: **25 files,
452+ theorems**, covering everything from the basic tree structure to quaternary

### The Three Magical Matrices

The three Berggren matrices B₁, B₂, B₃ have a beautiful property: they
preserve the Pythagorean equation. If (a, b, c) satisfies a² + b² = c²,
then so does Bᵢ·(a, b, c) for each i ∈ {1, 2, 3}.

But even more remarkably, **the inverse matrices also preserve the equation**,
and they always produce *smaller* triples (with smaller hypotenuse). This means
every primitive triple has a unique *parent* in the tree, found by applying the
correct inverse matrix.

The file `Pythagorean/BerggrenTree.lean` formalizes this:

```lean
def applyInvBG1 (v : Fin 3 → ℤ) : Fin 3 → ℤ :=
  fun i => match i with
  | 0 => v 0 + 2 * v 1 - 2 * v 2
  | 1 => -2 * v 0 - v 1 + 2 * v 2
  | 2 => -2 * v 0 - 2 * v 1 + 3 * v 2
```

The parent-finding algorithm `findBerggrenParent` tries each inverse matrix
and picks the one that produces positive components.

### Descent: The Highway Back to (3,4,5)

Given ANY primitive Pythagorean triple, we can repeatedly apply the parent-finding
algorithm to descend back to (3,4,5). This descent is:
- **Guaranteed to terminate** (the hypotenuse strictly decreases)
- **Unique** (each triple has exactly one parent)
- **Fast** (O(log c) steps to reach the root)

### The Factoring Connection: Inside-Out Factoring

Here is where the Berggren tree becomes truly surprising. The file
`InsideOutFactor.lean` shows how the tree can be used to **factor integers**.

The idea:
1. Given an odd composite N = p·q
2. Construct a Pythagorean triple with N as a leg: (N, 2mn, m²+n²)
   where m = (N+1)/2, n = (N-1)/2
3. Descend through the Berggren tree using inverse matrices
4. At each step, compute gcd(leg, N)
5. **A nontrivial GCD reveals a factor!**

Why does this work? As you descend, the legs trace arithmetic-like
progressions modulo p. By the pigeonhole principle, some leg must be
≡ 0 (mod p) within O(p) steps.

### The Lorentz Connection

Perhaps the most unexpected connection is to **special relativity**. The file
`Pythagorean/LorentzBerggren.lean` shows that the Berggren matrices are
related to **Lorentz transformations** — the symmetries of spacetime.

The Pythagorean equation a² + b² = c² can be rewritten as:
c² − a² − b² = 0, or equivalently, x² − y² − z² = 0 (null cone).

The Berggren matrices, when viewed in this signature, are discrete Lorentz
transformations! They preserve the light cone. Pythagorean triples are
**integer points on the light cone of (2+1)-dimensional Minkowski spacetime.**
