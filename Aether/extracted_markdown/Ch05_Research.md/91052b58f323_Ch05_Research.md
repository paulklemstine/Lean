## 1. The Berggren Matrices

### Definition 1.1
The three Berggren matrices generate children of a Pythagorean triple (a, b, c):

- **M₁**: (a, b, c) ↦ (a - 2b + 2c, 2a - b + 2c, 2a - 2b + 3c)
- **M₂**: (a, b, c) ↦ (a + 2b + 2c, 2a + b + 2c, 2a + 2b + 3c)
- **M₃**: (a, b, c) ↦ (-a + 2b + 2c, -2a + b + 2c, -2a + 2b + 3c)

### Theorem 1.2 (Pythagorean Preservation)

```lean
theorem berggren_A_pyth_eq (a b c : ℤ) (h : a^2 + b^2 = c^2) :
    (a - 2*b + 2*c)^2 + (2*a - b + 2*c)^2 = (2*a - 2*b + 3*c)^2 := by nlinarith

theorem berggren_B_pyth_eq (a b c : ℤ) (h : a^2 + b^2 = c^2) :
    (a + 2*b + 2*c)^2 + (2*a + b + 2*c)^2 = (2*a + 2*b + 3*c)^2 := by nlinarith

theorem berggren_C_pyth_eq (a b c : ℤ) (h : a^2 + b^2 = c^2) :
    (-a + 2*b + 2*c)^2 + (-2*a + b + 2*c)^2 = (-2*a + 2*b + 3*c)^2 := by nlinarith
```

## 2. Tree Structure

### Definition 2.1 (Tree Path)

```lean
inductive TreePath where
  | root : TreePath
  | left  : TreePath → TreePath   -- apply M₁
  | mid   : TreePath → TreePath   -- apply M₂
  | right : TreePath → TreePath   -- apply M₃
```

### Definition 2.2 (Path Evaluation)

```lean
def berggrenTripleAux : TreePath → ℤ × ℤ × ℤ
  | .root    => (3, 4, 5)
  | .left p  => let (a, b, c) := berggrenTripleAux p
                 (a - 2*b + 2*c, 2*a - b + 2*c, 2*a - 2*b + 3*c)
  | .mid p   => let (a, b, c) := berggrenTripleAux p
                 (a + 2*b + 2*c, 2*a + b + 2*c, 2*a + 2*b + 3*c)
  | .right p => let (a, b, c) := berggrenTripleAux p
                 (-a + 2*b + 2*c, -2*a + b + 2*c, -2*a + 2*b + 3*c)
```

### Theorem 2.3 (Universal Pythagorean Property)
Every triple in the tree satisfies the Pythagorean equation:

```lean
theorem berggrenTripleAux_pyth (path : TreePath) :
    let (a, b, c) := berggrenTripleAux path
    a^2 + b^2 = c^2
```

**Proof.** By structural induction on the path. The base case (3² + 4² = 5²) is by computation. Each inductive step follows from the Pythagorean preservation theorems. ∎

## 3. Inverse Berggren Descent

### Definition 3.1 (Parent Finding)

```lean
def findBerggrenParent (a b c : ℤ) : ℕ × ℤ × ℤ × ℤ :=
  let a1 := a + 2*b - 2*c; let b1 := -2*a - b + 2*c; let c1 := -2*a - 2*b + 3*c
  let a2 := a + 2*b - 2*c; let b2 := 2*a + b - 2*c
  if 0 < a1 && 0 < b1 then (1, a1, b1, c1)
  else if 0 < a2 && 0 < b2 then (2, a2, b2, c1)
  else let a3 := -a - 2*b + 2*c; let b3 := 2*a + b - 2*c; (3, a3, b3, c1)
```

### Theorem 3.2 (Descent Termination)
The inverse descent from any primitive Pythagorean triple terminates at (3, 4, 5) in a finite number of steps. This follows from the fact that the hypotenuse strictly decreases: c' < c for the parent triple.

## 4. Inside-Out Factoring

### Algorithm 4.1 (IOF — Inside-Out Factoring)

**Input:** Odd composite N
**Output:** A nontrivial factor of N

1. Construct triple: (N, (N²-1)/2, (N²+1)/2)
2. While current triple ≠ (3, 4, 5):
   a. Compute parent via inverse Berggren
   b. Let (a', b', c') be the parent
   c. If gcd(a', N) ∉ {1, N}: return gcd(a', N)
   d. If gcd(b', N) ∉ {1, N}: return gcd(b', N)
3. Return "failed" (should not happen for composite N)

### Theorem 4.2 (Correctness)
If N is composite, the algorithm produces a nontrivial factor.

**Proof sketch.** The leg values trace a deterministic sequence mod p for each prime factor p of N. By pigeonhole, within O(p) steps, some leg must be ≡ 0 (mod p), giving gcd > 1. ∎
