# Phase 1: Literature Review & Mathematical Foundations

## 1. Pythagorean Triplets — Core Mathematics

### Definition
A **Pythagorean triplet** (a, b, c) consists of positive integers satisfying:
```
a² + b² = c²
```

### Complete Parametrization (Euclid's Formula)
Every **primitive** Pythagorean triplet (gcd(a,b,c) = 1) is generated by:
```
a = m² - n²
b = 2mn
c = m² + n²
```
where m > n > 0, gcd(m,n) = 1, and m-n is odd.

### Key Properties
- There are **infinitely many** primitive triplets
- They become **sparser** as numbers grow: ~N/(2π) triplets with hypotenuse ≤ N  
- The "Pythagorean angle" θ = arctan(a/b) is always a **rational multiple of π** only for trivial cases
- Triplets tile a 2D integer lattice with integer-length diagonals

### Connection to Gaussian Integers
A Pythagorean triplet corresponds to |z|² being a perfect square, where z = a + bi is a Gaussian integer. The norm N(z) = a² + b² = c² means c = |z|.

## 2. Light and Geometry — The Standard Picture

### Special Relativity
- Light travels along **null geodesics**: ds² = -c²dt² + dx² + dy² + dz² = 0
- The Minkowski metric is **continuous** and has **no preferred frame**
- Lorentz symmetry: all inertial frames are equivalent

### The Pythagorean Connection
The spatial part of the null condition gives:
```
c²dt² = dx² + dy² + dz²
```
In 2D: `(c·dt)² = dx² + dy²` — this IS the Pythagorean theorem!

**Key insight**: Light's spatial displacement and its temporal displacement are related by the Pythagorean theorem. If these displacements are quantized (integer multiples of some fundamental unit), they must form Pythagorean triplets.

## 3. Discrete Spacetime — Prior Work

### Causal Set Theory (Bombelli, Lee, Meyer, Sorkin, 1987)
- Spacetime is a discrete set of events with a partial ordering (causality)
- Lorentz invariance is maintained **statistically** through random sprinkling
- Key tension: exact Lorentz invariance vs discrete structure

### Loop Quantum Gravity (Rovelli, Smolin, 1990s)
- Space is quantized: area and volume have discrete spectra
- Minimum length ~ Planck length: ℓ_P ≈ 1.6 × 10⁻³⁵ m
- Does NOT require absolute coordinates

### Lattice Field Theory (Wilson, 1974)
- Discretize spacetime on a regular lattice for calculations
- Known problem: regular lattices **break** continuous rotational symmetry
- Fermion doubling problem on lattices

### Digital Physics (Zuse, Fredkin, Wolfram)
- Universe as a cellular automaton
- Requires a fixed lattice → absolute frame
- Controversial; conflicts with relativity

## 4. The Core Tension: Discreteness vs Lorentz Invariance

### The Problem
A **regular lattice** has preferred directions. If I place a cubic lattice in space:
- Light traveling along an axis covers distance `a` in steps of 1
- Light traveling at 45° covers distance `a√2` — but √2 is **irrational**
- On a discrete lattice, you can't represent √2 exactly
- Pythagorean triplets are the **only** exact solutions for diagonal distances

### Implications
1. If light must travel integer lattice distances → only certain angles are allowed
2. Different directions would have slightly different effective speeds of light
3. This **violates Lorentz invariance** (isotropy of space)
4. Current experimental bounds: anisotropy of light speed < 10⁻¹⁸

### Possible Resolutions
- Lattice spacing is so small (Planck scale) that anisotropy is undetectable
- The lattice is not regular but **random** (causal set approach)
- Lorentz invariance is emergent/approximate at large scales
- The lattice structure is more subtle than a simple cubic grid

## 5. Density of Pythagorean Triplets on a Lattice

### In 2D
- Points (a, b) on the integer lattice where a² + b² is a perfect square
- These are lattice points that can be "seen" from the origin via integer-length rays
- Density: the number of such points with a² + b² ≤ R² grows as ~ R / √(log R)
- Most lattice directions are NOT Pythagorean — this is a severe constraint

### In 3D (Pythagorean Quadruples)
- a² + b² + c² = d²
- More solutions exist; every positive integer > 0 participates in some quadruple
- Parametrization exists but is more complex
- Better coverage of directions on a 3D lattice

### Implication for the Hypothesis
If light can ONLY travel along Pythagorean directions on a lattice, the set of allowed propagation directions is **measure zero** in the continuous limit. This seems catastrophically restrictive — unless the lattice spacing is infinitesimal or the model is more nuanced.
