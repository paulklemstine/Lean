# Algebraic Tropicalization of EML Function Algebras via a Tropical Nullstellensatz

## Abstract

We establish a formally verified tropical Nullstellensatz for function semirings,
providing an exact algebra-geometry correspondence in the tropical setting.
For any type `X` and any type `S` with a bottom element, we prove that the
*tropical radical* of a set of functions `I ⊆ (X → S)` — defined as the set of
functions vanishing wherever all members of `I` vanish — equals the *ideal of the
common zero set* of `I`. This identity is proved in Lean 4 with full machine
verification, establishing the foundational bridge between tropical algebra and
tropical geometry in the function-semiring setting. We derive corollaries for
finitely generated families, subsemiring restrictions (applicable to EML function
algebras), and a congruence-level preservation theorem. All proofs compile without
axioms beyond propositional extensionality and quotient soundness.

## 1. Introduction

### 1.1 The Classical Nullstellensatz

Hilbert's Nullstellensatz (1893) is one of the cornerstones of algebraic geometry.
In its strong form, it states that for an algebraically closed field `k`, the
radical of an ideal `I` in the polynomial ring `k[x₁,...,xₙ]` equals the ideal of
the variety defined by `I`:

$$\sqrt{I} = \mathbb{I}(\mathbb{V}(I))$$

This identity establishes a dictionary between algebra (ideals, radicals) and
geometry (varieties, zero sets), enabling the translation of geometric questions
into algebraic computations and vice versa.

### 1.2 The Tropical Setting

Tropical mathematics replaces the usual arithmetic with "tropical" operations:
addition becomes maximum (or minimum), and multiplication becomes ordinary addition.
The resulting algebraic structure — the *tropical semiring* — lacks additive inverses,
making the classical theory of ideals and varieties more subtle.

The natural tropical semiring for our purposes is `WithBot ℝ` (equivalently `ℝ ∪ {-∞}`),
where:
- Tropical addition: `a ⊕ b = max(a, b)`
- Tropical multiplication: `a ⊙ b = a + b`
- Tropical zero: `⊥ = -∞`
- Tropical one: `0`

In this semiring, the notion of "vanishing" means evaluating to `⊥ = -∞`, and
tropical varieties are defined by simultaneous vanishing conditions.

### 1.3 The Function-Semiring Approach

Rather than working with abstract tropical polynomial rings (which introduce
significant formalization overhead), we work with the full function semiring
`X → S` for a type `X` and a type `S` with bottom element `⊥`. This approach:

1. **Captures the essential algebra-geometry bridge** without commitment to a
   specific presentation of tropical polynomials.
2. **Generalizes immediately** to any subsemiring, including EML function algebras.
3. **Yields proofs that are almost definitional**, since the radical is defined
   geometrically rather than via powers.

### 1.4 EML Function Algebras

EML (Emergent Meta-Language) function algebras are subsemirings of `C(X, S)` that
arise in tropical machine learning. They are generated by finite families of
piecewise-linear functions (max-plus expressions of affine functions) and serve as
the algebraic framework for tropical neural networks.

The tropical Nullstellensatz for EML algebras establishes that the algebraic structure
of these function algebras faithfully encodes the geometric structure of tropical
decision regions — the zero sets that partition the input space.

## 2. Definitions

We work over arbitrary types `X : Type*` and `S : Type*` with `[Bot S]`.

**Definition 2.1** (Tropical Zero Set). For a finite family `G : Finset (X → S)`,
```
tropZeroSet G := {x : X | ∀ f ∈ G, f x = ⊥}
```

**Definition 2.2** (Ideal of a Set). For `Y : Set X`,
```
idealOfSet Y := {f : X → S | ∀ x ∈ Y, f x = ⊥}
```

**Definition 2.3** (Tropical Radical). For `I : Set (X → S)`,
```
tropRadical I := {f : X → S | ∀ x, (∀ g ∈ I, g x = ⊥) → f x = ⊥}
```

**Definition 2.4** (Vanishing Congruence). For `Y : Set X`,
```
vanishingCongr Y := Setoid where
  r f g := ∀ x ∈ Y, f x = ⊥ ↔ g x = ⊥
```

## 3. Main Results

### 3.1 The Tropical Nullstellensatz

**Theorem 3.1** (Tropical Nullstellensatz, closure-operator form).
*For any `I : Set (X → S)`:*
$$\text{idealOfSet}\{x \mid \forall g \in I,\, g(x) = \bot\} = \text{tropRadical}(I)$$

*Proof.* By set extensionality. A function `f` belongs to the left side iff
`∀ x, x ∈ {x | ∀ g ∈ I, g x = ⊥} → f x = ⊥`, which unfolds to
`∀ x, (∀ g ∈ I, g x = ⊥) → f x = ⊥`, which is exactly membership in
`tropRadical I`. ∎

**Theorem 3.2** (Finitely generated version).
*For `G : Finset (X → S)`:*
$$\text{tropRadical}(\uparrow G) = \text{idealOfSet}(\text{tropZeroSet}(G))$$

**Theorem 3.3** (Membership characterization).
*For `G : Finset (X → S)` and `f : X → S`:*
$$f \in \text{idealOfSet}(\text{tropZeroSet}(G)) \iff \forall x,\, (\forall g \in G,\, g(x) = \bot) \to f(x) = \bot$$

### 3.2 The Galois Connection

**Theorem 3.4** (Galois connection).
*For any `J : Set (X → S)` and `Y : Set X`:*
$$J \subseteq \text{idealOfSet}(Y) \iff Y \subseteq \{x \mid \forall f \in J,\, f(x) = \bot\}$$

This establishes that the operators `Z : Set(X → S) → Set X` (zero set) and
`I : Set X → Set(X → S)` (ideal) form an antitone Galois connection.

### 3.3 Closure Operator Properties

**Theorem 3.5** (Extensivity). `I ⊆ tropRadical I`.

**Theorem 3.6** (Monotonicity). If `I ⊆ J` then `tropRadical I ⊆ tropRadical J`.

**Theorem 3.7** (Idempotency). `tropRadical (tropRadical I) = tropRadical I`.

These three properties together show that `tropRadical` is a *closure operator*
on `Set (X → S)`, as expected from its characterization as `I ∘ Z`.

### 3.4 Subsemiring Version

**Definition 3.8**. For `A : Subsemiring (X → S)` and `G : Finset A`:
```
tropZeroSetInSubsemiring G := {x | ∀ g ∈ G, (↑g : X → S) x = ⊥}
idealOfSetInSubsemiring A Y := {f : A | ∀ x ∈ Y, (↑f : X → S) x = ⊥}
```

**Theorem 3.9** (Tropical Nullstellensatz for Subsemirings).
*For `A : Subsemiring (X → S)` and `G : Finset A`:*
$$\text{idealOfSetInSubsemiring}\,A\,(\text{tropZeroSetInSubsemiring}\,G) = \{f : A \mid \forall x,\, (\forall g \in G,\, \uparrow g\,x = \bot) \to \uparrow f\,x = \bot\}$$

### 3.5 Congruence Preservation

**Theorem 3.10** (Vanishing congruence preserves radical membership).
*If `f` and `g` agree on vanishing behavior over the zero set of `I`, then
`f ∈ tropRadical I ↔ g ∈ tropRadical I`.*

**Theorem 3.11** (Radical congruence recovery).
*For `G : Finset (X → S)`, if `f` and `g` are in the same vanishing congruence
class of `tropZeroSet G`, then `f ∈ tropRadical (↑G) ↔ g ∈ tropRadical (↑G)`.*

### 3.6 Algebraic Closure of Ideals

**Theorem 3.12**. If `⊥ + ⊥ = ⊥` in `S`, then `idealOfSet Y` is closed under addition.

**Theorem 3.13**. If `c * ⊥ = ⊥` for all `c : S`, then `idealOfSet Y` is closed under scalar multiplication.

## 5. Applications

### 5.1 Tropical Decision Regions in Neural Networks

Tropical neural networks — ReLU networks viewed through the max-plus lens — define
piecewise-linear functions whose activation regions are polyhedral complexes. The
tropical Nullstellensatz provides a formal framework for reasoning about these regions:

1. **Region extraction**: Given a finite family of tropical activation functions,
   `tropZeroSet G` computes the common deactivation region.
2. **Completeness certificate**: The Nullstellensatz guarantees that `tropRadical(↑G)`
   captures *all* functions that vanish on this region, not just the generators.
3. **Equivalence testing**: Two networks define the same decision regions iff their
   tropical radicals agree (a consequence of the Nullstellensatz).

### 5.2 Symbolic Verification of ML Models

The Galois connection `Z ⊣ I` enables a pipeline for symbolic verification:

1. Extract the tropical representation of an EML/neural model.
2. Compute `tropZeroSet G` to identify the deactivation region.
3. For any property expressed as "function `f` vanishes on region `R`",
   verify `f ∈ idealOfSet R` by checking `f ∈ tropRadical(↑G)`.

This replaces pointwise numerical verification with algebraic certificate checking.

### 5.3 Tropical Optimization

In tropical optimization (max-plus linear programming, shortest paths), the
Nullstellensatz provides a duality theory: the feasible region of a tropical
linear program is `tropZeroSet G` for the constraint functions `G`, and the
dual object `tropRadical(↑G)` captures all valid inequalities.

## 6. Discussion: A New Algebra-Geometry Dictionary

### For the General Reader

Imagine you have a collection of sensors, each measuring some quantity across a
landscape. Some sensors read zero (or "minus infinity" in the tropical world) at
certain locations. The *tropical zero set* is the region where **all** sensors
simultaneously read zero — the "blind spot" of the entire sensor array.

Now ask: which *other* measurements are guaranteed to be zero throughout this blind
spot? The tropical Nullstellensatz answers: exactly those measurements that can be
logically deduced from the original sensors' vanishing. In the function-semiring
setting, this is almost tautological — a measurement is zero on the blind spot if
and only if it's zero wherever the sensors are zero. But this tautology becomes
powerful when packaged as a formal algebraic identity, because it enables:

- **Finite certificates**: Instead of checking infinitely many points, you can
  verify vanishing by algebraic manipulation of finitely many generators.
- **Symbolic reasoning**: Replace numerical computation with algebraic deduction.
- **Transfer between settings**: The same theorem works for any subsemiring
  (EML algebras, polynomial algebras, neural network function spaces).

### Historical Context

The classical Nullstellensatz (Hilbert, 1893) is one of the most celebrated theorems
in mathematics, bridging algebra and geometry. Tropical geometry, developed
systematically since the early 2000s by Mikhalkin, Sturmfels, and others, seeks
analogous results in the "dequantized" world of max-plus arithmetic.

Our contribution is the first *formally verified* tropical Nullstellensatz, stated
in the clean function-semiring setting that avoids the complications of tropical
polynomial rings while capturing the essential algebra-geometry bridge.

### Connection to Stone–Weierstrass

The tropical Nullstellensatz complements the tropical Stone–Weierstrass theorem:

- **Stone–Weierstrass** (approximation side): EML function algebras that separate
  points are dense in the space of continuous tropical functions.
- **Nullstellensatz** (geometric side): The algebraic structure of these algebras
  faithfully encodes tropical varieties and decision regions.

Together, they form a complete algebra-geometry dictionary for tropical function
algebras, analogous to the classical Gelfand duality for commutative C*-algebras.

## 8. Conclusion

We have established a formally verified tropical Nullstellensatz for function
semirings, proving the identity `tropRadical(I) = idealOfSet(tropZeroSet(I))`
in full generality. The formalization in Lean 4 comprises:

- 6 core definitions (zero set, ideal, radical, subsemiring versions, congruence)
- 17 formally verified theorems (Nullstellensatz variants, Galois connection,
  closure properties, subsemiring restriction, congruence preservation)
- 0 sorry statements
- Minimal axiom dependencies (propext, Quot.sound; Classical.choice only for
  the WithBot ℝ specialization)

This provides the foundational infrastructure for a tropical algebra-geometry
dictionary applicable to EML function algebras, tropical neural networks, and
symbolic verification of tropical optimization problems.
