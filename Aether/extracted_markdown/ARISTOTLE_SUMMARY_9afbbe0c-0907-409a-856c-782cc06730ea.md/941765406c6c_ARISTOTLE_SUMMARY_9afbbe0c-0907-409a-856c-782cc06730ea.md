# Summary of changes
## AutoHeal — Self-Healing Software Library

Created a complete self-healing program library with research documentation, demos, visuals, and publications. The system embeds a tail-watching AI into any Python application that monitors log output, detects errors, generates patches, recompiles, and hot-swaps live fixes — all without restarting.

### Core Library (`autoheal/core/`)

Six modular components forming the heal pipeline:

| Component | File | Purpose |
|-----------|------|---------|
| **TailWatcher** | `tail_watcher.py` | Daemon-thread log file tail with rotation detection, bounded queue, back-pressure |
| **Diagnostician** | `diagnostician.py` | Cascaded error classifier (regex → heuristic → AI fallback) |
| **CodeSurgeon** | `code_surgeon.py` | Patch generation with heuristic rules + Oracle AI, AST validation gate, backup-before-write |
| **Compiler** | `compiler.py` | `py_compile` + `importlib.reload()` with fallback for dynamically loaded modules |
| **HotSwapper** | `hot_swapper.py` | In-place `__code__` replacement so existing references see new behavior instantly |
| **Oracle / OracleTeam** | `oracle.py` | Single AI unit + 6-oracle council (Researcher → Hypothesizer → Experimenter → Validator → Updater → Iterator) |
| **AutoHealer** | `auto_healer.py` | Top-level façade wiring everything together |
