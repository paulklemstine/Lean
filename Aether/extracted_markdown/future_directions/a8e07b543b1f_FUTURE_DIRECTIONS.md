# Future Directions — Species Growth → Tropical Generating-Function Valuations

This cycle established (in `Catalog/Bridges/SpeciesTropicalValuation.lean`) that the `X`-adic
order of the exponential generating function is a **tropical valuation functor** on combinatorial
species:

* product (Day-convolution) ↦ tropical multiplication (`+` in `ℕ∞`): `egf_order_mul`,
  `tropOrder_prodCard`, `tropVal_mul`;
* sum (disjoint union) ↦ tropical addition (`min`), **exactly** for non-negative sequences:
  `egf_order_add_of_nonneg`, `tropOrder_sum`, `tropVal_add_of_nonneg`;
* the valuation = size of the smallest non-empty structure ("growth onset"): `egf_order_eq_nat`,
  `Species.tropOrder_eq_nat`.

The conjectures below are concrete next targets, each phrased so it can be stated and attacked
directly in Lean.

## Conjecture 1 — Composition law: order of a composite = product of orders

For the substitution (composition) of species `F ∘ G` with `G` having **no empty structure**
(`G.coeffSeq 0 = 0`, i.e. `tropOrder G ≥ 1`), the EGF satisfies `EGF (F ∘ G) = (EGF F) ∘ (EGF G)`
(formal substitution). Conjecture:
```
tropOrder (F ∘ G) = tropOrder F * tropOrder G      (ordinary product in ℕ∞)
```
This is the tropical shadow of the chain rule / Newton-polygon multiplicativity under
substitution, and would upgrade `tropVal` from a `(+,·)`-rig homomorphism to a structure that also
tracks composition. **Test:** verify on `E ∘ (X·E)` (the species of set partitions) and on
`L ∘ L⁺`. Likely needs `PowerSeries.order` behaviour under `PowerSeries.subst`/`rescale`.

## Conjecture 2 — Differential calculus shifts the valuation predictably

With the catalog's derivative species `F′` (`F′[n] = F[n+1]`) and pointed species `F•`:
```
tropOrder F ≥ 1  →  tropOrder (F′) = tropOrder F - 1
tropOrder (F•)  =  the least n ≥ 1 with F.coeffSeq n ≠ 0
```
i.e. differentiation lowers the growth onset by one, and pointing deletes the empty structure
(raising the onset past `0`). **Test:** `tropOrder (E′) = 0` while `tropOrder (E•) = 1`. Provable
from `EGF_derivativeSpecies`, `EGF_pointedSpecies`, and `PowerSeries.order` of `X · _` and the
formal derivative.

## Conjecture 3 — The valuation is independent of the exponential normalization

For **any** weighting `w : ℕ → ℚ` with `w n ≠ 0` for all `n` (the EGF uses `w n = 1/n!`, the OGF
uses `w n = 1`), the order of `PowerSeries.mk (fun n => w n * a n)` is the same:
```
(PowerSeries.mk (fun n => w n * a n)).order = (PowerSeries.mk a).order .
```
Hence the tropical valuation is an invariant of the **bare counting sequence**, not of the chosen
generating-function model (EGF vs OGF vs Dirichlet-type). **Test:** `order (egf a) = order
(PowerSeries.mk a)` as the special case `w n = 1/n!`. This pins down exactly *what information* the
tropical functor sees.

## Conjecture 4 — Newton-polygon refinement: product ↦ inf-convolution

The order only records the *first* exponent. The full tropicalization should record the whole
**support**. Define the support indicator `supp F : ℕ → ℕ∞`, `supp F n = 0` if `F.coeffSeq n ≠ 0`
else `⊤`. Conjecture: for the structural product,
```
supp (F · G) = supp F ⋆min supp G        (min-plus / inf-convolution)
```
i.e. `n ∈ supp(F·G) ↔ ∃ i+j=n, i ∈ supp F ∧ j ∈ supp G`. This is the categorified
Cauchy/Minkowski sum of supports and the genuine "Newton polygon of a species". `tropOrder` is then
the recovered as the minimum of the support. **Test:** `supp (X^k as species)` is the singleton
`{k}`, and the product law reduces to `{k} ⋆ {l} = {k+l}`.

## Conjecture 5 — `tropVal` is a (strong) monoidal functor / decategorified homotopy cardinality

Assemble the species into a rig and show `tropVal : (Species, ⊔, ·) → Tropical (ℕ∞)` is a
homomorphism of commutative semirings, factoring as
```
Species --EGF--> ℚ⟦X⟧ --order--> ℕ∞ --trop--> Tropical (ℕ∞),
```
and that it is the decategorification of the homotopy-cardinality / Euler-characteristic valuation
already studied in `Catalog/Applications/SpeciesHomotopyCardinality.lean`. Conjecture: the diagram
of functors commutes and `tropVal` is the unique semiring map sending the singleton species `X` to
the tropical generator `trop 1`. **Test:** check `tropVal X = trop 1`, `tropVal 1 = trop 0`,
`tropVal E = trop 0`, and the two homomorphism laws already proved combine to give the universal
property on the polynomial sub-rig generated by `X`.
