# OISCC: Future Research Directions

## A Roadmap for the One Instruction Set Continuous Computer

---

## I. Theoretical Foundations

### 1. Optimal Instruction Counts
**Problem**: What is the minimum number of PUSH+EML instructions needed to compute each elementary operation?

We have upper bounds (exp: 3, ln: 7, sub: 11, add: 11, mul: ~19) but no lower bounds. A lower bound proof would establish the fundamental "circuit complexity" of EML computation.

**Approach**: Model OISCC programs as binary trees (each EML node has two children), and use information-theoretic arguments. Each leaf contributes one degree of freedom (the PUSH value), and each EML node contributes the fixed structure $e^a - \ln(b)$. Lower bounds may follow from counting degrees of freedom.

**Key Question**: Is there a shorter program for multiplication than the 19-instruction one we found?

### 2. Stack Depth vs. Program Length Tradeoffs
**Problem**: What is the minimum stack depth required to compute a given function?

For sequential composition without recomputation, deeper functions need deeper stacks. But allowing recomputation (computing the same subexpression twice) can reduce stack depth at the cost of more instructions.

**Conjecture**: Computing $n$-ary symmetric functions requires stack depth $\Omega(\log n)$.

### 3. EML Complexity Classes
**Problem**: Define and study complexity classes based on EML tree depth and size.

- **EML-DEPTH(d)**: Functions computable by EML trees of depth ≤ d
- **EML-SIZE(s)**: Functions computable by EML trees with ≤ s nodes
- **EML-STACK(k)**: Functions computable by OISCC programs with stack depth ≤ k

**Question**: Is there a hierarchy theorem? Is EML-DEPTH(d) ⊊ EML-DEPTH(d+1)?

### 4. The EML Complexity of Specific Constants
**Problem**: What is the minimum EML tree size needed to compute π, √2, γ (Euler-Mascheroni), or other fundamental constants?

We can compute e = EML(1,1) with a depth-1 tree. What about π? The best known approach uses π = 4·arctan(1), but arctan requires inverse trigonometric decomposition. A direct EML representation of π would be remarkable.

**Conjecture**: K_EML(π) ≤ 40 (the EML tree complexity of π is at most 40 nodes).

### 5. Algebraic Properties of the EML Monoid
**Problem**: Study the algebraic structure of functions generated by EML.

The set of functions obtainable by composing EML forms a monoid under composition. What are its automorphisms? Is it finitely presented? What is its growth rate?

## II. Hardware Implementation

### 6. Analog EML Circuit Design
**Problem**: Design and fabricate an analog circuit implementing $f(a,b) = e^a - \ln(b)$.

**Approach**:
- Use a BJT's exponential I-V characteristic for $e^a$
- Use a translinear logarithmic circuit for $\ln(b)$
- Combine with a differential amplifier for subtraction
- Target < 100 transistors total

**Deliverable**: A fabricated chip with measured accuracy, power consumption, and speed.

### 7. Digital CORDIC-Based EML Unit
**Problem**: Implement EML in digital logic using a modified CORDIC algorithm.

CORDIC (COordinate Rotation DIgital Computer) can compute exp and ln via shift-and-add operations. A unified CORDIC unit computing both simultaneously would be the digital version of the EML circuit.

**Target**: 32-bit precision, < 1000 gates, < 20 clock cycles per EML operation.

### 8. FPGA Prototype
**Problem**: Implement a complete OISCC on an FPGA with instruction memory, stack, and EML unit.

**Milestones**:
1. EML unit (exp-minus-log computation)
2. Stack memory controller
3. Instruction fetch and decode (1-bit opcode!)
4. Simple I/O interface
5. Demonstration running arithmetic programs

### 9. Power Measurement and Comparison
**Problem**: Measure the actual power consumption of an OISCC vs. equivalent microcontrollers.

**Benchmark workloads**:
- Temperature sensor conversion: $T = (V - 0.5) \times 100$
- Moving average filter: $y_n = \alpha x_n + (1-\alpha) y_{n-1}$
- Softmax computation: $\sigma(x_i) = e^{x_i} / \sum e^{x_j}$
- Kalman filter update step

### 10. Logarithmic Number System Integration
**Problem**: In a logarithmic number system (LNS), numbers are stored as their logarithms. Multiplication becomes addition, and addition requires a lookup table. The EML naturally operates in a hybrid log/linear domain.

**Question**: Is there a number representation that makes EML operations exact (no rounding)?

## III. Programming and Compilation

### 11. OISCC Compiler
**Problem**: Build a compiler from a high-level language to OISCC assembly (PUSH/EML sequences).

**Input**: Arithmetic expressions involving +, −, ×, ÷, exp, ln, pow
**Output**: Optimal or near-optimal PUSH/EML sequences
**Challenge**: Register allocation is replaced by stack scheduling — minimizing stack depth while minimizing instruction count.

### 12. Peephole Optimization
**Problem**: Identify and catalog common EML subexpression patterns that can be simplified.

For example: EML(0, EML(x, 1)) = 1 − ln(exp(x)) = 1 − x. Can this pattern be detected and shortened?

### 13. Common Subexpression Elimination
**Problem**: When computing multiple operations, shared subexpressions (like ln(a) used in both multiplication and division) should be computed once.

**Question**: What is the amortized cost of computing $n$ arithmetic operations on the same operands?

### 14. Macro Library
**Problem**: Define a standard library of OISCC "macros" — named sequences of PUSH/EML that compute common operations.

```
MACRO EXP(x):    PUSH x, PUSH 1, EML
MACRO LN(x):     PUSH 0, PUSH 0, PUSH x, EML, PUSH 1, EML, EML
MACRO SUB(a,b):  LN(a), EXP(b), EML
MACRO ADD(a,b):  LN(a), EXP(-b), EML
MACRO MUL(a,b):  EXP(LN(a) + LN(b))
MACRO DIV(a,b):  EXP(LN(a) - LN(b))
```

## IV. Numerical Analysis

### 15. Error Propagation in EML Chains
**Problem**: How do floating-point errors propagate through long chains of EML operations?

The exponential amplifies errors (condition number = x for exp at x), while ln dampens them. EML combines both — does the overall error grow, shrink, or stay bounded?

**Approach**: Analyze the condition number of the composite function $f_n = \text{EML}(\text{EML}(\ldots), \text{EML}(\ldots))$ as a function of depth $n$.

### 16. Interval Arithmetic for OISCC
**Problem**: Develop interval arithmetic variants of EML for guaranteed bounds on results.

$$\text{EML}([a_l, a_u], [b_l, b_u]) = [e^{a_l} - \ln(b_u), e^{a_u} - \ln(b_l)]$$

This could enable verified computing on the OISCC.

### 17. Mixed-Precision EML
**Problem**: Can the exp and ln sub-operations use different precisions to save power?

For example, if the result is dominated by the exp term, the ln computation might need fewer bits. Adaptive precision EML could save 30-50% power.

### 18. Catastrophic Cancellation
**Problem**: When $e^a \approx \ln(b)$, the subtraction in EML suffers catastrophic cancellation.

**Question**: Can we identify and avoid operand combinations that trigger cancellation? Is there a reformulation like $\text{expm1}(a) - \text{log1p}(b-1)$ that improves numerical behavior?

## V. Applications

### 19. TinyML on OISCC
**Problem**: Implement small neural networks (1-10 layers, 100-1000 parameters) on OISCC for edge AI.

**Target**: Image classification of 8×8 grayscale images (handwritten digits) with < 100 μW power budget.

**Advantage**: Softmax, sigmoid, and tanh are native EML operations.

### 20. EML-Based PID Controller
**Problem**: Implement a PID controller using only OISCC instructions.

The PID equation $u(t) = K_p e(t) + K_i \int e(\tau) d\tau + K_d \frac{de}{dt}$ requires multiplication and addition — both computable via EML.

### 21. Software-Defined Radio
**Problem**: Use the OISCC for baseband signal processing in ultra-low-power radios.

FM demodulation involves computing $\arctan(Q/I)$ and differentiation — both expressible through EML compositions. An OISCC-based SDR could operate on harvested RF energy.

### 22. Implantable Medical Computing
**Problem**: Design an OISCC-based processor for implantable glucose monitors.

**Requirements**: < 10 μW, continuous operation for 5+ years, compute glucose concentration from sensor voltage using a nonlinear calibration curve (typically exponential or logarithmic).

### 23. Blockchain/Cryptocurrency Mining
**Problem**: Explore whether EML-based hash function evaluation could be more energy-efficient than SHA-256 on conventional hardware for proof-of-work variants that naturally involve exp/ln.

### 24. EML-Based Random Number Generation
**Problem**: The chaotic dynamics of iterated EML (especially the diagonal map $x \mapsto e^x - \ln(x)$) could serve as a hardware random number generator.

**Study**: Analyze the statistical properties of EML-iterated sequences. Do they pass NIST randomness tests?

## VI. Mathematical Extensions

### 25. Complex EML and Trigonometry
**Problem**: Extend the OISCC to complex numbers. Since $e^{ix} = \cos(x) + i\sin(x)$, the complex EML naturally computes trigonometric functions.

**Question**: Does the complex OISCC compute all Liouvillian functions (solutions of differential equations solvable by quadratures)?

### 26. p-adic EML
**Problem**: Define and study the EML operator over p-adic numbers, where exp and log have different convergence properties.

The p-adic exponential converges only for $|x|_p < p^{-1/(p-1)}$, giving the p-adic EML a restricted but well-defined domain.

### 27. Tropical EML
**Problem**: In tropical mathematics, addition becomes min and multiplication becomes addition. What is the "tropical EML"?

$$\text{EML}_{\text{trop}}(a, b) = \min(a, -b) \quad ?$$

### 28. EML in Differential Algebra
**Problem**: Study the differential-algebraic closure of EML. The Risch algorithm decides integrability of elementary functions — can it be expressed as a finite EML program?

### 29. Category Theory of EML
**Problem**: View EML as a morphism in a suitable category. The closure of constants under EML forms a subobject — what categorical properties does this subobject have?

### 30. Quantum EML
**Problem**: Define a quantum version of EML operating on quantum states. Can a quantum OISCC (QOISCC) gain speedup for certain EML tree evaluations through superposition?

---

## VII. Biological and Chemical Computing

### 31. Biochemical EML Circuits
**Problem**: Implement EML using biochemical reaction networks.

Enzyme kinetics naturally involve exponentials (Arrhenius equation: $k = Ae^{-E_a/RT}$). Gene regulatory networks implement logarithmic responses (Weber-Fechner law). A biochemical EML circuit could enable molecular computing.

### 32. DNA Computing with EML
**Problem**: Encode EML computations in DNA strand displacement reactions.

**Approach**: Use DNA concentration ratios as real numbers, enzyme-catalyzed reactions for exponential amplification, and competitive binding for subtraction.

### 33. Neural EML
**Problem**: Can biological neurons implement EML? Synaptic transmission involves exponential calcium dynamics, and neural firing rates follow logarithmic stimulus-response curves.

**Hypothesis**: Pairs of excitatory (exp-like) and inhibitory (log-like) neurons might naturally implement EML-like operations.

**Interface**: Users connect EML blocks like LEGO bricks, building computation trees visually. The system shows real-time stack state and intermediate results.

With 35 concrete research directions, collaborations across mathematics, CS, EE, and biology could yield decades of productive work — all flowing from the single identity $e^a - \ln(b)$.
