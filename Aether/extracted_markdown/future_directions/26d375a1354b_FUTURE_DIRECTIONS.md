# Future Directions — Memory Editing: When Forgetting Is a Mathematical Operation

## Synthesis

This cycle recast *memory* as a monoid homomorphism `m : FreeMonoid A →* M` from
experience streams (free monoid on an alphabet of atomic experiences) to a
representation monoid, and established the algebraic skeleton of *bounded* memory.
Three facts crystallized. First, a finite-memory bound over a nonempty alphabet
makes memory **provably lossy**: `forgetting_is_lossy` is pigeonhole over the
infinite free monoid. Second, the loss is not arbitrary deletion — it is an
**equalizer submonoid** `lossSubmonoid m` on pairs of streams, equivalently the
kernel **congruence** `Con.ker m` (`mem_lossSubmonoid`, `loss_iff_congruence`), and
under the bound it is genuinely off-diagonal (`loss_genuine`). Third, **targeted
forgetting is a quotient**: the monoid first isomorphism theorem identifies the
compressed memory with `(Con.ker m).Quotient` (`targeted_forgetting_is_quotient`),
which is finite (`compressed_memory_finite`).

The sharpest conceptual yield is that *forgetting has two inequivalent faces*: the
**erasure kernel** `m.mker` (streams remembered as nothing) can be trivial, while the
**indistinguishability congruence** is always nontrivial under a bound. The correct
invariant of bounded memory is therefore the congruence (a quotient), not the kernel
(a subobject). This is what makes "memory editing" categorical: it is a quotient in
the category of memory algebras, not a subtraction.

## Results Summary

- `forgetting_is_lossy` — finite `M`, nonempty `A` ⇒ `m` not injective.
- `exists_indistinguishable` — explicit colliding pair of distinct streams.
- `lossSubmonoid` / `mem_lossSubmonoid` / `loss_iff_congruence` — the loss object as a
  submonoid of `Stream A × Stream A`, equal to `Con.ker m`.
- `loss_genuine` — the loss submonoid strictly contains the diagonal.
- `targeted_forgetting_is_quotient` — `(Con.ker m).Quotient ≃* mrange m`.
- `compressed_memory_finite` — the indistinguishability quotient is finite.

## Research Directions

### 1. A quantitative forgetting rate: the collision-growth law
Define `D(n)` as the number of distinguishable memory states reachable from streams of
length `≤ n`, i.e. the image of length-bounded streams under `m`. Conjecture: for a
finite-memory bound `|M| = k` over an alphabet of size `a ≥ 2`, `D(n)` saturates at a
value `≤ k` after at most `k` steps, while the number of streams grows like `a^n`, so
the *forgetting rate* `1 - D(n)/a^n → 1` and in fact the first collision occurs at
length `≤ ⌈log_a k⌉ + 1`. **The key insight is** that the submonoid `mrange m` is
generated by the `a` images of single experiences, so its reachable set is governed by
a finite automaton on `≤ k` states, forcing logarithmic time-to-first-collision.
**Why now?** We already have `exists_indistinguishable`; promoting it to a *quantitative*
length bound is the natural next theorem and is fully constructive (a search over `≤ k+1`
lengths), so it is both provable and immediately falsifiable by exhibiting a memory whose
first collision is later than the bound.

### 2. Erasure kernel triviality is generic, congruence triviality is impossible
Conjecture: over any finite nontrivial `M` and nonempty `A`, there exists a memory whose
erasure kernel `m.mker` is trivial (`= ⊥`), yet *no* memory into a finite `M` has trivial
indistinguishability congruence. **The key insight is** the idempotent witness from the
Lab Notebook: mapping the generator to a non-unit idempotent kills the kernel while the
finite codomain still forces a congruence collision. **Why now?** The two faces of
forgetting are already separated qualitatively in this file; turning the separation into a
pair of formal theorems (`∃ m, m.mker = ⊥` and `∀ m, Con.ker m ≠ ⊥`) cements the claim
that memory editing must be modelled by congruences, and each statement is a crisp
falsifiable proposition.

### 3. Universality of targeted forgetting (the deletion functor)
Fix a "forbidden" set of experiences `S ⊆ A` to be deleted. Define the *targeted-forgetting
congruence* as the smallest monoid congruence collapsing every `s ∈ S` to the unit, and
conjecture it is the kernel of the canonical projection `FreeMonoid A →* FreeMonoid (A \ S)`,
giving a universal property: every memory that ignores `S` factors uniquely through it.
**The key insight is** that "deleting an experience" is the quotient by the congruence
generated by `{(s, 1) : s ∈ S}`, so `loss_iff_congruence` upgrades to a *universal* quotient
exactly as in the first isomorphism theorem already proved here. **Why now?** We have the
quotient machinery (`Con`, `Con.Quotient`) wired up and the first-isomorphism theorem in
hand; the deletion functor is the cross-domain bridge to `Cryptography/Core.lean`'s
compositional product, letting forgetting compose functorially.

### 4. An entropy bound on lossy memory (bridge to the entropy catalog)
Conjecture: if experiences are drawn i.i.d. with Shannon entropy `H` per symbol, then any
finite memory with `|M| = k` satisfies a coding-style inequality — the asymptotic fraction
of length-`n` streams in any single indistinguishability class is at least `2^{-log_2 k}`
per `n`-block, so the per-symbol "remembered information" is bounded by `(log_2 k)/n → 0`.
**The key insight is** that `loss_genuine` is the algebraic shadow of the pigeonhole used in
source coding: collisions in `mrange m` are exactly decoding ambiguities. **Why now?** The
`Shared/EntropyLatticeCrypto.lean` and `Shared/MutualInformation.lean` modules already
supply entropy infrastructure; combining them with `compressed_memory_finite` yields the
first information-theoretic theorem about algebraic memory and is falsifiable by any memory
that beats the bound (which would contradict counting).

### 5. Memory editing as a topology: the indistinguishability metric and its completion
Equip streams with the ultrametric `d(x, y) = 2^{-ℓ}` where `ℓ` is the length of the longest
common prefix on which `m` agrees. Conjecture: `m` factors continuously through the metric
completion, and bounded memory is exactly the statement that this completion is *compact*
(totally bounded by `|M|`). **The key insight is** that the kernel congruence `Con.ker m`
induces a uniformity whose separated quotient is finite precisely when `M` is finite — the
topological reflection of `compressed_memory_finite`. **Why now?** With the quotient already
identified as finite, the leap to "finite = compact reflection" connects memory editing to
the profinite/topological-monoid catalog entries and opens an entirely new (topological)
proof route for the forgetting theorems, testable by checking total boundedness fails the
moment `M` is infinite.
