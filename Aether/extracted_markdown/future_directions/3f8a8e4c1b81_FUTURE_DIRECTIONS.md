### 1. Fermat Two-Square Bridge via Berggren Orbits

- **Theorem Statement**: For every prime p ≡ 1 (mod 4), there exist a, b ∈ ℕ with a² + b² = p, and the triple (2ab, a²−b², p) is reachable from (3,4,5) via a Berggren word of length O(log p).
- **Proof Strategy**:
  - (A) Use Fermat's two-square theorem (available in Mathlib as `Nat.Prime.sq_add_sq`) to obtain a, b.
  - (B) Prove that (2ab, a²−b², p) is a primitive Pythagorean triple by Euclid's parametrization.
  - (C) Apply the descent algorithm (Theorem 3.12) to trace back to (3,4,5) in O(log p) steps.
  - Key lemma: `descent_length_bound (a b c : ℤ) (h : IsPythagoreanTriple a b c) : ∃ w : BerggrenWord, wordToMatrix w *ᵥ seed = ![a, b, c] ∧ w.length ≤ 2 * Nat.log 2 c.toNat`
- **Why This Is Revolutionary**: Establishes a constructive bridge from prime factorization to Berggren tree geometry, potentially enabling number-theoretic algorithms via tree search.
- **Catalog Leverage**: `descent_decrease_bound`, `prime_unique_triple`, `berggren_first_letter_unique`
- **Research Mode**: prove
- **Estimated Depth**: 3

### 2. Higher-Dimensional Berggren Walks on O(n,1;ℤ)

- **Theorem Statement**: For each n ≥ 2, there exist generators of a subgroup of O(n,1;ℤ) that produce all primitive Pythagorean n-tuples (a₁,...,aₙ,c) with a₁² + ⋯ + aₙ² = c² from a single seed.
- **Proof Strategy**:
  - (A) Construct generators using the "extended Berggren" approach: for n=3, use 7 generators of O(3,1;ℤ).
  - (B) Prove Lorentz preservation Q(Mv) = Q(v) for the generalized quadratic form.
  - (C) Prove completeness: every primitive solution is reachable.
- **Why This Is Revolutionary**: Opens a systematic theory of integral Lorentz groups acting on higher Pythagorean varieties, connecting to the theory of integral quadratic forms.
- **Catalog Leverage**: `lorentz_mul_closed`, `wordToMatrix_in_lorentz`, `A₁_preserves_Q`
- **Research Mode**: discover
- **Estimated Depth**: 4

### 4. Tropical Berggren Theory

- **Theorem Statement**: The "tropical Berggren matrices" obtained by replacing (+, ×) with (min, +) define a tropical Lorentz group O_trop(2,1;ℤ) that acts on tropical Pythagorean triples (a,b,c) satisfying min(a,b) = c in the tropical sense.
- **Proof Strategy**:
  - (A) Define tropical matrix operations in the min-plus semiring.
  - (B) Define the tropical Minkowski form Q_trop(a,b,c) = min(a,b) − c.
  - (C) Prove tropical Berggren matrices preserve Q_trop.
- **Why This Is Revolutionary**: Creates a new field of tropical Lorentzian geometry with potential applications to optimization and tropical cryptography.
- **Catalog Leverage**: Tropical semiring definitions from the Tropical catalog.
- **Research Mode**: discover
- **Estimated Depth**: 3

### 5. Berggren Zeta Function and Functional Equation

- **Theorem Statement**: Define ζ_B(s) = Σ_{n≥0} c_n^{−s} where c_n ranges over hypotenuses in the B-branch (5, 29, 169, 985, ...). Then ζ_B has meromorphic continuation and satisfies a functional equation.
- **Proof Strategy**:
  - (A) Express c_n via the recurrence c_{n+1} = 6c_n − c_{n-1} with c_0 = 5, c_1 = 29.
  - (B) The closed form is c_n = α(3+2√2)^n + β(3−2√2)^n for suitable α, β.
  - (C) The Dirichlet series ζ_B(s) = Σ c_n^{−s} converges for Re(s) > 0 and has analytic continuation via Mellin transform techniques.
- **Why This Is Revolutionary**: Creates a spectral zeta function for the Berggren tree, potentially revealing deep connections to L-functions.
- **Catalog Leverage**: `B_recurrence_verify`, `hypotenuse_sequence`
- **Research Mode**: discover
- **Estimated Depth**: 5

## Under-explored Territory

### Berggren Monoid Representation Theory
The Berggren monoid is generated by three matrices with known Cayley-Hamilton relations. Its representation theory—irreducible representations, character theory, and Hecke algebra structure—is completely unexplored.

### Pythagorean Triple Counting Functions
The function r(N) counting primitive Pythagorean triples with hypotenuse N has deep connections to class numbers of imaginary quadratic fields. The Berggren tree structure should give new bounds on r(N).

### Ergodic Theory of Berggren Walks
The random walk on the Berggren tree (choosing A₁, A₂, or A₃ uniformly) defines a Markov chain whose stationary distribution and mixing time are unknown. The Lorentz invariant constrains the dynamics.

## Cross-Domain Bridges

1. **Number Theory ↔ Lorentzian Geometry**: Pythagorean triples are null vectors; Berggren descent is Lorentz boosting.
2. **Lorentz Groups ↔ Quantum Walks**: O(2,1;ℤ) membership certifies unitarity of walk operators.
3. **Non-Commutativity ↔ Post-Quantum Cryptography**: The Berggren word problem is a candidate one-way function.
4. **Frobenius Norm Uniformity ↔ Balanced Random Walks**: ||Aᵢ||_F = √35 for all i enables isotropic walks.
5. **Cayley-Hamilton ↔ Recurrence Relations**: The minimal polynomial of A₂ gives the B-branch hypotenuse recurrence.

## Open Problems Encountered

1. **Berggren Completeness**: The claim that every primitive Pythagorean triple appears exactly once in the tree is not yet formalized in our framework (requires GCD theory).
2. **Sharp Spectral Gap**: The exact spectral gap of the Berggren random walk on ℤ/Nℤ is unknown.
3. **Quantum Query Complexity**: Formal bounds on quantum query complexity for Berggren tree search require a formalized quantum computation model.
4. **Spectral Factorization Certificate**: Whether the Berggren walk amplitude can distinguish prime from composite hypotenuses remains open.
