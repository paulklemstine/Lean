# Future Directions: Set-Local Distortion of Hausdorff Dimension

## Synthesis

The file `Catalog/Geometry/FractalDimension.lean` closes a genuine gap in the Mathlib
theory of Hausdorff dimension. Mathlib provides `LipschitzOnWith.dimH_image_le` (a
*set-local* upper bound) but only `AntilipschitzWith.le_dimH_image` (a *global* lower
bound). There was no `AntilipschitzOnWith` predicate at all, so there was no way to state
— let alone prove — that a map which is antilipschitz **only on a set `s`** cannot
collapse the dimension of `s`. We introduced `AntilipschitzOnWith` and proved the missing
lower bound `dimH s ≤ dimH (f '' s)`, then combined it with the existing upper bound to
obtain set-local *bilipschitz* and *isometry* invariance of Hausdorff dimension.

The decisive technical move is a **subtype reduction**: on the subtype `s`, the ambient
`edist` is definitionally the induced one, so "antilipschitz on `s`" becomes "globally
antilipschitz on the metric space `s`". One then transports the conclusion back along the
isometric inclusion `Subtype.val`. This pattern is reusable for *every* set-local
distortion statement, which is what makes the directions below tractable today.

## Results Summary (all proved, `sorry`-free, only standard axioms)

- `AntilipschitzOnWith` — the new set-local antilipschitz predicate, the companion of
  Mathlib's `AntilipschitzWith` and `LipschitzOnWith`.
- `AntilipschitzOnWith.le_dimH_image` — **headline**: `dimH s ≤ dimH (f '' s)` whenever
  `f` is antilipschitz on `s`. Strictly stronger than `AntilipschitzWith.le_dimH_image`.
- `dimH_image_eq_of_bilipschitzOn` — bilipschitz-on-a-set maps preserve Hausdorff
  dimension exactly.
- `dimH_image_eq_of_isometryOn` — isometry-on-a-set maps preserve Hausdorff dimension
  (set-local form of `Isometry.dimH_image`).
- Supporting API: `AntilipschitzWith.antilipschitzOnWith`, `AntilipschitzOnWith.mono`,
  `AntilipschitzOnWith.injOn`, `AntilipschitzOnWith.subtype_antilipschitzWith`,
  `isometryOn_bilipschitz`.

## Direction 1 — Set-local Hölder lower bound (`AntiholderOnWith`)

Mathlib's `HolderOnWith.dimH_image_le` gives `dimH (f '' s) ≤ dimH s / r` for a
Hölder-on map with exponent `r`. The matching lower bound should read: if `f` satisfies a
*reverse* Hölder estimate on `s`, namely `edist x y ≤ C * edist (f x) (f y) ^ r` for all
`x, y ∈ s`, then `dimH s ≤ dimH (f '' s) / r`, equivalently `r · dimH s ≤ dimH (f '' s)`.
The key insight is that the same subtype reduction used for `AntilipschitzOnWith` applies
verbatim once `AntiholderOnWith` is defined, reducing the set-local statement to a global
reverse-Hölder dimension bound that can be obtained from
`HolderWith.hausdorffMeasure_image_le` run "in reverse". **Why now?** We already have the
isometric-inclusion transport lemma `isometry_subtype_coe` wired up and verified in this
cycle; the only new ingredient is the reverse-Hölder measure estimate, making this the
lowest-hanging generalization.

## Direction 2 — Exact dimension formula for self-similar attractors

Conjecture: for a finite iterated function system of contracting similarities
`{S_i}` on `ℝ^n` satisfying the open set condition, the attractor `A` has
`dimH A = d`, where `d` is the unique solution of `∑ r_i^d = 1` (the Moran/Hutchinson
equation), and each `S_i` is bilipschitz-on `A` so that `dimH (S_i '' A) = dimH A` by
`dimH_image_eq_of_bilipschitzOn`. The key insight is that our set-local bilipschitz
invariance lets one prove the *self-consistency* half (`dimH A = max_i dimH (S_i '' A)`)
purely formally from `dimH_bUnion` plus `dimH_image_eq_of_bilipschitzOn`, isolating the
genuinely hard content into the single Moran-equation lower bound. **Why now?** The union
side (`dimH_bUnion`, `dimH_iUnion`) is already in Mathlib and the per-map invariance is
exactly what this cycle delivered; the conjecture is falsifiable by computing
`dimH` of the standard Cantor set (`d = log 2 / log 3`) as a first test case.

## Direction 3 — Decidable rational dimension certificates for finite-state fractals

For attractors generated by similarities with a common contraction ratio `1/b`
(`b ∈ ℕ`, `b ≥ 2`) and `m` maps, the Moran equation collapses to `m · b^{-d} = 1`, i.e.
`d = log m / log b`, a *computable* real. Conjecture: the predicate "the box-counting /
Hausdorff dimension of the digit-restricted set `{x ∈ [0,1] : digits of x in base b avoid
a fixed forbidden set}` equals `log m / log b`" is **decidable** as a function of the
finite forbidden set, with an explicit witness extracted from the cardinality `m` of
allowed digits. The key insight is that `dimH_image_eq_of_isometryOn` makes the
base-`b` shift map a dimension-preserving isometry-on the attractor, turning the dimension
into a finite-automaton invariant (count allowed transitions). **Why now?** This engine is
configured for constructive/algorithmic output, and the dimension here is literally an
`#eval`-able rational-logarithm from a finite count — a perfect computational target built
directly on the isometry-on invariance proved this cycle.

## Direction 4 — Failure of invariance under merely-continuous distortion

Falsifiable sharpness claim: the antilipschitz-on hypothesis in
`AntilipschitzOnWith.le_dimH_image` cannot be weakened to "injective and continuous on
`s`". The key insight is that a space-filling-type or Hölder-deficient homeomorphism can
strictly *raise* dimension (`dimH (f '' s) > dimH s`) while a non-antilipschitz injection
can strictly *lower* it, so neither inequality survives. **Why now?** With the clean
`AntilipschitzOnWith` interface in place, one can state both potential counterexamples as
precise Lean propositions and discharge them against concrete maps (e.g. `x ↦ x^3` near
`0`, or a Cantor-staircase restriction), turning a folklore "the hypothesis is necessary"
remark into a machine-checked sharpness theorem.

## Direction 5 — Set-local product and graph dimension bounds

Conjecture: if `f` is antilipschitz-on `s` and `g` is antilipschitz-on `t`, then the
graph/product map is antilipschitz-on `s ×ˢ t` for the sup metric, giving
`dimH s + dimH t ≤ dimH ((f × g) '' (s ×ˢ t))` whenever the Mathlib product-dimension
lemmas (`dimH_prod`-style results) apply. The key insight is that `AntilipschitzOnWith` is
closed under products with the *max* of the two constants, so the subtype reduction lifts
to `s ×ˢ t` and the lower bound combines additively with the (currently partial) Mathlib
product theory. **Why now?** The set-local predicate composes cleanly under products by
construction, and stating the conjecture exposes exactly which product-of-dimensions lemma
Mathlib still lacks, steering the next cycle toward a concrete, high-value Mathlib
contribution.
