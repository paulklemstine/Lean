# Future Directions — Eastin–Knill Obstructions and Fault-Tolerance Thresholds

This cycle extended the catalog file `EastinKnillThreshold.lean` with
`EastinKnillUniversality.lean`, which sharpens both pillars of fault-tolerant
quantum computation. On the algebraic side we upgraded the Eastin–Knill no-go
statement from *exact* non-universality (a finite transversal gate group cannot
be the whole unitary group) to *approximate* non-universality (a finite
transversal gate group is not even **dense**), the analytically correct form of
the theorem, via the general topological lemma `finite_not_dense`. On the
analytic side we moved past the qualitative limit `errorRate → 0` to a
**quantitative** theory: strict per-level error suppression
(`errorRate_strictAnti_subthreshold`), a finite-overhead resource guarantee
(`errorRate_reaches_target`), the explicit surface-code instance
(`surface_code_subthreshold_collapse`), and a sharpness/boundary result showing
suppression fails exactly at threshold
(`errorRate_at_threshold_not_tendsto_zero`). The following directions are
falsifiable extensions, each prove-or-disprove in Lean.

## 1. Explicit doubly-logarithmic level overhead

Strengthen `errorRate_reaches_target` from mere existence to an explicit closed
form: below threshold the number of concatenation levels needed to reach target
logical error `ε` is `L(ε) = ⌈log₂( log(cε) / log(cp) )⌉`, and one should prove
`errorRate c p (L(ε)) ≤ ε` with `L` of order `log log (1/ε)`. **The key insight
is** that the rescaled recursion linearizes to `q_n = q₀^(2^n)`, so the level
count is a *double* logarithm of the target — exponentially cheaper than the
naive iteration count, which is precisely why concatenation is practical. **Why
now?** We already have the closed form `errorRate_closed_form` and the
sub-threshold limit in hand; the only missing piece is a clean `Nat.log`/`Real.logb`
manipulation, which is well supported in current Mathlib.

## 2. Lie-group form: finite ⇒ nowhere dense ⇒ measure zero

Replace the `T1` hypothesis of `finite_not_dense` with the structure of a
connected, positive-dimensional Lie group `G` (e.g. `SU(2)`) and prove the
quantitatively stronger statement that a finite transversal subgroup is
**nowhere dense** and has **Haar measure zero**, so the reachable set has measure
zero in the full unitary group. **The key insight is** that the obstruction is
not merely cardinality but dimension: a finite set is a 0-dimensional submanifold
inside a positive-dimensional group, so it is null for the Haar measure. **Why
now?** Mathlib now has Haar measure on locally compact groups and the
`MeasureTheory` API for null sets; combining it with `Set.Finite.measure_zero`
turns the topological no-go into a measure-theoretic one.

## 3. Quantitative gap-to-universality (Solovay–Kitaev companion)

Formalize the converse pressure: define the covering radius `δ(S)` of a gate set
`S` (the worst-case distance from a target unitary to the group it generates) and
prove that for any *finite* `S` in an infinite metric group, `δ(S) > 0`,
exhibiting an explicit unitary at distance `≥ δ(S)`. **The key insight is** that
the complement of a finite (hence closed) set in a perfect metric space contains
an open ball, giving a *uniform* lower bound on approximation error rather than
just non-density. **Why now?** With `finite_not_dense` proven, the metric
refinement is a short step using `Metric.isOpen_compl` and the fact that
`U(n)`/`SU(2)` has no isolated points; this is the exact dual to the
Solovay–Kitaev theorem and a natural next catalog entry.

## 4. Multi-constant and biased-noise thresholds

Generalize the single suppression constant `c` to a level-dependent sequence
`cₙ` (modeling improving gadgets, or biased noise where `X` and `Z` errors have
different rates) and prove a generalized threshold criterion: the product law
`∏ cₖ^(2^{n-k})` collapses to `0` iff `limsup (cₙ pₙ) < 1`. **The key insight is**
that the doubly-exponential weighting makes the *late* levels dominate, so the
threshold is governed by the asymptotic, not initial, gadget quality. **Why
now?** The induction skeleton of `errorRate_closed_form` generalizes directly to
a telescoping product; this captures realistic hardware where physical error
rates drift, a regime the constant-`c` model cannot address.

## 5. Code-switching circumvents Eastin–Knill (constructive complement)

Prove the positive companion to the no-go theorem: if two codes `A` and `B` have
transversal gate groups `T_A`, `T_B` whose *union* generates a dense subgroup,
then alternating (code-switching) reaches a dense set even though each `T_A`,
`T_B` is finite. Formalize this as: there exist finite subgroups `H₁, H₂` of an
infinite group `G` with `Dense (Subgroup.closure (H₁ ∪ H₂) : Set G)`. **The key
insight is** that `finite_not_dense` forbids density *within a single subgroup*,
but the subgroup *generated by two finite sets* need not be finite — this is
exactly the loophole real fault-tolerant architectures exploit (e.g. transversal
Clifford on the surface code plus a magic-state/lattice-surgery T gate). **Why
now?** A concrete witness exists already in Mathlib reach: two finite rotation
subgroups of `SO(3)`/`SU(2)` by incommensurate angles generate a free, dense
group, so the statement is constructively provable and cleanly closes the
narrative opened by the no-go theorem.
