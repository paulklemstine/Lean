# Future Directions: Berggren Dynamics as Thin-Semigroup Laboratory

## Hypothesis 1: C-Ray Universal Second-Extremality

**Conjecture**: For every n ≥ 1, the all-C word Cⁿ is the unique word of length n with second-smallest hypotenuse among all 3ⁿ words. That is:
- For all w with |w| = n and w ≠ Aⁿ: c(Cⁿ) ≤ c(w)
- Equality holds if and only if w = Cⁿ

**Test**: Verified computationally for n = 1, ..., 6 (3⁶ = 729 words at depth 6). Extend to n = 10 (59,049 words) using branch-and-bound pruning. For a formal proof, the approach would require showing:
1. Among {A,C}-only words, Cⁿ has second-smallest hyp after Aⁿ (requires monotonicity of the leg-swap along pure branches).
2. Any word containing B has hypotenuse exceeding 4n² + 8n + 5 (requires a refined lower bound for B-containing words).

**Expected failure mode**: The conjecture is almost certainly true based on extensive computation. A proof failure would indicate that the monotonicity structure of the Berggren action is more complex than the "greedy choice" intuition suggests.

**Impact**: Establishing this formally would give the first complete spectral characterization of the Berggren tree at the "ground state + first excited state" level, directly analogous to spectral theory on hyperbolic surfaces.

## Hypothesis 2: Third-Extremal Classification

**Conjecture**: For every n ≥ 2, the word A^{n-1}C (n-1 copies of A followed by one C) is the unique third-extremal word. Its hypotenuse is:
```
c(A^{n-1}C) = 6n² + 6n - 3
```
More precisely, among all words w of length n with w ∉ {Aⁿ, Cⁿ}, A^{n-1}C minimizes c(w).

**Test**: Verify the closed form c(A^{n-1}C) = 6n² + 6n - 3 for n = 1, ..., 10. Verify third-extremality computationally for n = 2, ..., 8. The closed form can be derived by applying C to the A-ray closed form at depth n-1:
```
C(2(n-1)+3, 2n(n+1), 2(n-1)² + 6(n-1) + 5)
= C(2n+1, 2n(n+1), 2n² + 2n + 1)
```
and simplifying.

**Expected failure mode**: The closed form might be incorrect for the third component, requiring correction. The third-extremality might fail at large n if there exist "mixing" words (using both A and C in non-trivial patterns) that achieve smaller hypotenuse.

**Impact**: A full extremal hierarchy (1st, 2nd, 3rd, ...) would reveal the fine structure of the "density of states" in the Berggren dynamics, directly relevant to counting triples by hypotenuse.

## Hypothesis 3: Strong Connectivity of Modular Orbits for All Coprime Odd Primes

**Conjecture**: For every odd prime p ≥ 7, the directed multigraph G_p — whose vertices are the orbit of (3,4,5) mod p under {A, B, C} and edges are generator applications — is strongly connected.

**Test**: 
- Already verified computationally for p = 7, 11, 13, 17, 19, 23, 29, 31.
- Extend to all primes up to 200 using the BFS orbit computation algorithm.
- For a formal proof, the approach would be:
  1. Show each generator is invertible mod p (det(A) = det(C) = 1, det(B) = -1, so all are invertible when gcd(p, det) = 1).
  2. Use the Euclid parametrization (m²-n², 2mn, m²+n²) mod p to translate the Berggren action to an action on parameter pairs (m, n) ∈ (ℤ/pℤ)².
  3. Show the induced action on parameter pairs is transitive using group-theoretic arguments.

**Expected failure mode**: The conjecture might fail for p = 2, 3, or 5 (which divide 30, the product of the Berggren matrix denominators). It should hold for p ∤ 30.

**Impact**: Strong connectivity is the minimal requirement for the modular Berggren system to behave as a "thin orbit laboratory." It is the foundation for all mixing, equidistribution, and spectral gap results.

## Hypothesis 4: Uniform Spectral Gap in Modular Quotients

**Conjecture**: There exists δ > 0 such that for all squarefree odd m with gcd(m, 30) = 1, the transition operator P_m on the modular Berggren orbit has second eigenvalue |λ₂(P_m)| ≤ 1 - δ.

**Test**:
- Compute exact spectral gaps for m = 7, 11, 13, ..., 101 using exact rational arithmetic on the transition matrix.
- Plot 1 - |λ₂| vs m to check for convergence to a positive limit.
- The Bourgain-Gamburd theory predicts δ > 0 for thin groups with the "expansion property," which requires: (a) the group generated by A, B, C mod p is large (ideally all of SL₃(ℤ/pℤ) or a large subgroup), and (b) the generators are "non-degenerate" in a spectral sense.

**Expected failure mode**: The spectral gap might shrink as O(1/log m), indicating polynomial (rather than exponential) mixing. This would mean the Berggren semigroup does NOT satisfy uniform expansion, which would be interesting in its own right as it would distinguish it from known expander families.

**Impact**: A uniform spectral gap would immediately yield: (a) exponential mixing of random walks, (b) equidistribution of Berggren orbits in residue classes, (c) a quantitative sieve for counting triples with prescribed modular properties. This would be a major theorem connecting elementary number theory to expander graph theory.

## Hypothesis 5: Geodesic Coding and Symbolic Dynamics Classification

**Conjecture**: Define the "defect sequence" of a word w = g₁g₂...gₙ as the sequence of positions where gᵢ ≠ A. The hypotenuse c(w) is determined (up to O(1)) by:
```
c(w) ≈ 2n² + 6n + 5 + Σᵢ f(gᵢ, posᵢ)
```
where f(C, k) = 4(n-k)(n-k+1) and f(B, k) ≈ 18(n-k)² (rough asymptotics).

In other words, each defect from the geodesic contributes an additive penalty that depends on the defect position and type, and these penalties are approximately independent.

**Test**: Compute c(w) for all words of length n = 8 (6561 words) and fit the residual c(w) - (2n²+6n+5) as a function of defect positions. Check whether the fit is additive (no interaction terms between defects at different positions).

**Expected failure mode**: The penalties might not be additive for adjacent defects (e.g., a C followed by a B might interact differently than their individual contributions suggest). The interaction terms would reveal the "curvature" of the Berggren dynamics.

**Impact**: An additive defect model would give an explicit formula for the hypotenuse of any word as a function of its symbolic itinerary, enabling: (a) exact counting of triples by hypotenuse, (b) a partition function / free energy for the Berggren symbolic dynamics, (c) entropy computation for the tree. This is the bridge from extremal path theory to full thermodynamic formalism.
