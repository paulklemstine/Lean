# Future Directions

## 1. Full Distributional Rigidity for Word Measures

**Status:** Defined but not yet proved.

Extend the fingerprint rigidity theorem from individual words to finitely supported distributions (`WordDist`). The target theorem:

> If two finitely supported distributions μ, ν over Berggren words produce the same aggregated fingerprint, then their abelianized profiles `distAbelianProfile μ = distAbelianProfile ν` agree.

This requires proving that the linear map from word distributions to fingerprint statistics has a trivial kernel when restricted to the abelianization subspace. The key ingredient would be showing that the fingerprint statistics of words within each abelian class are linearly independent over ℤ.

## 2. Partial Ordered-Word Recovery from Fingerprints

**Status:** Open.

The current theorem shows that the full-triple fingerprint determines the word entirely (via freeness), which is much stronger than abelianized-profile recovery. Can we recover partial ordering information from weaker statistics? For instance:

- Using only hypotenuse values (not full triples), can we still determine the abelian count?
- Can we recover the first k generators from the fingerprint restricted to triples of height ≤ R?

The hypotenuse-only version is subtle because two distinct Pythagorean triples can share a hypotenuse (e.g., 65 = 63² + 16² = 33² + 56²), though they would correspond to different words.

## 3. Tropicalization of the Fingerprint

**Status:** Conceptual.

Replace the integer triple action with its tropical (min-plus) shadow. The Berggren generators become tropical 3×3 matrices, and word evaluation becomes tropical matrix multiplication. The tropical fingerprint is the min-plus analogue of the matrix-vector product.

Key questions:
- Does the tropical fingerprint still separate abelian classes?
- What is the tropical analogue of freeness?
- Can tropical data-processing inequalities bound information loss?

This connects to the existing tropical analysis infrastructure in the project.

## 4. Analogues for Other Arithmetic Semigroups

**Status:** Exploratory.

The Berggren tree is just one instance of a ternary tree acting on lattice points. Similar structures exist for:

- **Markov triples** (generated by Vieta involutions)
- **Apollonian gasket** (generated by four Descartes circle inversions)
- **Thin matrix groups** (integer points in algebraic groups)

For each, one can define word evaluation, abelianized profiles, and fingerprint statistics. The freeness theorem likely generalizes to any free semigroup acting faithfully on ℤⁿ, but the generator separation theorem (distinct generators → distinct statistics) requires case-specific analysis.

## 5. Quantum Query Lower Bounds from Collision Obstructions

**Status:** Theoretical.

The collision-resistance theorem can be interpreted as a computational hardness statement: given a fingerprint, recovering the word (or even its abelian count) from just the hypotenuse data requires solving a discrete logarithm-like problem in the Berggren semigroup.

In the quantum setting, this suggests:
- A hidden-shift problem where the shift is the abelianized generator count
- Query lower bounds for distinguishing words with different abelian counts
- Connections to the quantum money and quantum cryptography literature

The formally verified collision bound (C = 71 from the existing `BerggrenSpectralHash`) provides an explicit security parameter for such protocols.
