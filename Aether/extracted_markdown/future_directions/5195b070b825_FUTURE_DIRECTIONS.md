# Future Directions: Arithmetic-Orbit Cryptography

## Overview

The Berggren groupoid orbit formalization establishes the first certified bridge between arithmetic tree dynamics and post-quantum cryptographic hardness. This document outlines five concrete breakthrough research directions, each with specific theorem targets, candidate proof strategies, and estimated difficulty.

---

## Direction 1: Higher-Dimensional Integral Orthogonal Semigroups

### Vision
Extend the Berggren construction from the Pythagorean cone $a^2 + b^2 = c^2$ in $\mathbb{Z}^3$ to higher-dimensional quadratic surfaces:
$$x_1^2 + x_2^2 + \cdots + x_n^2 = x_{n+1}^2$$
in $\mathbb{Z}^{n+1}$. The integral orthogonal group $O(n,1;\mathbb{Z})$ contains finitely generated subgroups analogous to the Berggren matrices, and their orbits on the integer light cone produce higher-dimensional "primitive tuples."

```

  -- orbit faithfulness
  ...
```

### Proof Strategy
1. Identify the generators of an appropriate subgroup of $O(n,1;\mathbb{Z})$ for small $n$ (e.g., $n=3$ gives Pythagorean quadruples).
2. Verify the cross-generator diagonal sign property computationally for specific generator sets.
3. Generalize the hypotenuse monotonicity argument to the $(n+1)$-th coordinate.
4. The main challenge is finding generator sets with the right separation properties.

### Cryptographic Impact
Higher dimensions provide exponentially larger key spaces (more generators per dimension) and connect to well-studied high-dimensional lattice problems (LWE, NTRU) where concrete hardness results are available.

### Estimated Difficulty: ★★★★☆

## Direction 2: Average-Case Hardness from Orbit Growth Rates

### Vision
Prove that the orbit inversion problem — recovering a Berggren word from its orbit point — is hard on average for uniformly random words, not just existentially hard. This requires analyzing the growth rate of orbit points and showing that "most" orbit points are exponentially far from root in a metric that resists efficient traversal.

### Theorem Targets

```
-- Candidate Lean signature
theorem orbit_point_growth_lower_bound (w : BerggrenWord) :
    (orbitPoint w) 2 ≥ (3 : ℤ) ^ (w.length / 2) := by sorry

theorem average_case_orbit_search_bound (d : ℕ) :
    -- For a random word w of length d, the expected number of
    -- oracle queries to find w from orbit(w) is Ω(3^(d/2))
    ...
```

### Proof Strategy
1. **Spectral analysis**: Compute the spectral radii of the three Berggren matrices. The matrix $B$ has spectral radius $\approx 5.83$, giving the fastest growth. The minimum growth over all generators determines the worst-case lower bound.
2. **Lyapunov exponent**: Show that the top Lyapunov exponent of the random matrix product (uniform over {A,B,C}) is positive, implying exponential growth of orbit norms almost surely.
3. **Reduction to lattice distinguishing**: Show that an efficient orbit inverter can be used to distinguish between orbit-generated lattice distributions and uniform distributions, connecting to the LWE assumption.

### Key Auxiliary Lemma
```
-- The hypotenuse grows by a multiplicative factor at each step
theorem hypotenuse_multiplicative_growth (v : Fin 3 → ℤ) (hv : PrimitivePythTriple v) (g : BerggrenGen) :
    (genMatrix g).mulVec v 2 ≥ v 2 + 2 * min (v 0) (v 1) := by sorry
```

### Estimated Difficulty: ★★★★★

## Direction 3: Markov Surface Extension

### Vision
Apply the faithful orbit framework to the **Markov surface** $x^2 + y^2 + z^2 = 3xyz$. Markov triples have their own ternary tree structure, generated by Vieta involutions, and the associated dynamics exhibit properties (uniqueness conjecture, hyperbolic geometry connections) that may provide even richer cryptographic structures.

### Theorem Targets

```
def IsMarkovTriple (v : Fin 3 → ℤ) : Prop :=
  v 0 ^ 2 + v 1 ^ 2 + v 2 ^ 2 = 3 * v 0 * v 1 * v 2 ∧
  ∀ i, 0 < v i

-- Vieta involution: replace x with 3yz - x
def vietaInv (i : Fin 3) (v : Fin 3 → ℤ) : Fin 3 → ℤ := ...

theorem vieta_preserves_markov (i : Fin 3) (v : Fin 3 → ℤ) (hv : IsMarkovTriple v) :
    IsMarkovTriple (vietaInv i v) := by sorry

-- The Markov uniqueness conjecture (open problem!)
-- Every positive integer appears at most once as the maximum element of a Markov triple
conjecture markov_uniqueness :
    ∀ v w : Fin 3 → ℤ, IsMarkovTriple v → IsMarkovTriple w →
    Finset.max' ... = Finset.max' ... → ... := by sorry
```

### Cryptographic Impact
The Markov uniqueness conjecture (still unproven after 100+ years) would, if true, provide a perfect one-way function: each maximum element uniquely determines its Markov triple, but computing the triple from the maximum appears hard. Even without the conjecture, the tree structure provides a faithful orbit action.

### Estimated Difficulty: ★★★★★ (due to the open conjecture)

## Direction 4: Certified Toy Key Exchange Implementation

### Vision
Build a complete, formally verified key exchange protocol based on Berggren orbits. This includes:
- Concrete parameter selection with provable security bounds
- Serialization/deserialization of public keys

## Direction 5: Entropy Extraction from Structured Algebraic Sources

### Vision
Prove that uniformly random Berggren words of sufficient depth produce orbit points with high min-entropy, suitable for cryptographic key derivation via the leftover hash lemma. This connects the algebraic structure of the Berggren tree to information-theoretic security guarantees.

### Theorem Targets

```
-- Min-entropy of the orbit distribution
def berggrenMinEntropy (depth : ℕ) : ℝ :=
  Real.log 3 / Real.log 2 * depth

theorem berggren_orbit_entropy_bound (depth : ℕ) :
    -- The orbit map preserves most of the entropy of the word distribution
    berggrenMinEntropy depth ≥ depth := by sorry

-- Connection to leftover hash lemma
theorem berggren_key_extraction (depth keyLen : ℕ)
    (h_depth : 2 * keyLen + 128 ≤ berggrenMinEntropy depth) :
    -- A universal hash of the orbit point yields a keyLen-bit key
    -- with statistical distance ≤ 2^{-64} from uniform
    ... := by sorry
```

### Proof Strategy
1. **Injectivity implies full entropy**: By Theorem 4.5, the orbit map is injective, so the orbit distribution on depth-$d$ words has exactly $3^d$ elements, giving min-entropy $\log_2(3^d) = d \cdot \log_2 3$.
2. **Leftover hash lemma application**: Use the existing formalized leftover hash lemma (in `Catalog/Cryptography/EntropyExtraction/LeftoverHash.lean`) to extract a nearly-uniform key.
3. **Concrete parameters**: For 128-bit security with 64-bit statistical distance, depth $\geq \lceil (2 \times 128 + 128) / \log_2 3 \rceil = 243$.

### Estimated Difficulty: ★★☆☆☆

## Cross-Domain Connections to Explore

- **Expander graphs**: The Berggren matrices may generate an expander family on the set of primitive triples, providing rapid mixing guarantees for random orbit walks.
- **Automorphic forms**: The connection to $O(2,1;\mathbb{Z})$ links to the theory of automorphic forms and L-functions, potentially providing analytic tools for hardness proofs.
- **Tropical geometry**: The "tropical" version of the Pythagorean cone (using min-plus algebra) may connect to tropical cryptography and certified robustness.
- **Algebraic complexity**: The word problem in the Berggren semigroup relates to circuit complexity lower bounds for matrix multiplication.
