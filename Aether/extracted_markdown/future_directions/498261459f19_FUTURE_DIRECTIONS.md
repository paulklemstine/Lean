# Future Directions: Sheaf Compression on Finite Sites

## Synthesis

The topology-transparent compression principle — that Grothendieck topologies constrain which probes are admissible without changing how many are needed — opens a rich landscape of testable hypotheses. The verified results establish sandwich bounds and equality criteria for finite sites, but the full invariance conjecture remains open. The five directions below form a coherent research program: Direction 1 (the central conjecture) drives the theoretical core; Directions 2-3 build computational and cross-domain extensions; Directions 4-5 represent paradigm-shifting grand challenges connecting sheaf compression to quantum information and higher category theory. Each direction builds on the verified Lean theorems (Catalog references below) and is falsifiable through explicit computation or construction.

---

## Direction 1: Sheafification Invariance Conjecture

**Conjecture**: For any finite site $(C, J)$ with $|\mathrm{Ob}(C)| \leq 10$ and any $J$-sheaf $F$, the sheaf and presheaf probe complexities are exactly equal:
$$\mathrm{SheafProbeComplexity}_J(F) = \mathrm{PresheafProbeComplexity}(F)$$

**Test**: Implement exhaustive enumeration of:
1. All small categories with $\leq 5$ objects (up to equivalence, ~100 categories).
2. All Grothendieck topologies on each category (finitely many for each finite category).
3. All sheaves on each site (finitely many for finite sites with finite fiber sets).
4. Compute both complexities and verify equality.

Any counterexample would identify a "topology-compression gap" — a site where the topology genuinely increases the probe count. This is expected to be empty for $\leq 5$ objects but could emerge for larger sites.

**Impact**: A proof would establish that topology is universally transparent to compression on finite sites, with implications for all downstream applications. A counterexample would identify the precise structural feature of a topology that creates compression overhead.

**Catalog References**: `Pythagorean/ProbeComplexity/SheafCompression.lean` (Theorems `presheafProbeComplexity_le_sheafProbeComplexity`, `sheafProbeComplexity_eq_presheafProbeComplexity_top`, `complexity_eq_of_optimal_respects`, `complexity_eq_of_all_optimal_respect`)

**Proof Strategy**: Show that for any finite site $(C, J)$ and $J$-sheaf $F$, every minimal presheaf-separating family automatically generates covering sieves. Key lemma: if $P$ separates a sheaf $F$ and $\mathrm{ProbeFamilySieve}(P, c) \notin J(c)$ for some $c$, then there exist distinct sections in $F(c)$ that agree on all probes but differ on the covering sieve — contradicting the sheaf axiom.

**Domain Bridges**: Algebraic geometry (étale sites), topos theory (dense generators), information theory (side-constraint coding).

**Lineage**: Extends `sheafProbeComplexity_eq_presheafProbeComplexity_top` (the maximal topology case) to arbitrary topologies.

**Ambition**: ★★★★☆ (Solid extension — expected to be true and provable with moderate effort)

## Direction 2: Compression Gap Bound via Covering Sieve Count

**Conjecture**: The gap between sheaf and presheaf probe complexities is bounded by the number of non-trivial covering sieves:
$$\mathrm{SheafProbeComplexity}_J(F) - \mathrm{PresheafProbeComplexity}(F) \leq \sum_{c \in \mathrm{Ob}(C)} |J(c) \setminus \{\top_c\}|$$

**Test**: For random finite sites with $3$–$7$ objects and random topologies (generated by choosing random presieve families and closing under the Grothendieck axioms), compute both complexities and the covering sieve count. Verify the bound holds in $\geq 10{,}000$ random instances.

**Impact**: Would quantify the "topological overhead" of sheaf compression. If the conjecture holds, it provides a computable a priori bound on the complexity gap, useful for algorithmic applications.

**Catalog References**: `Pythagorean/ProbeComplexity/SheafCompression.lean` (Theorem `complexity_gap_bounded`)

**Proof Strategy**: Refine the crude gap bound $\leq |\mathrm{Ob}(C)|$ by analyzing how each non-trivial covering sieve constrains the set of admissible probe families. Each covering sieve at $c$ potentially eliminates one candidate family, bounding the gap by the total number of constraints.

**Domain Bridges**: Combinatorics (set cover problems), optimization (constrained minimization).

**Lineage**: Refines `complexity_gap_bounded` from the linear bound to a covering-sieve-count bound.

**Ambition**: ★★★☆☆ (Solid extension, likely provable)

## Direction 3: Étale Probe Complexity and Arithmetic Invariants

**Conjecture**: For the étale site of a number field $K$ restricted to a finite subcategory (e.g., étale covers of $\mathrm{Spec}(\mathcal{O}_K)$ up to degree $d$), the sheaf probe complexity of the structure sheaf equals the class number $h_K$.

**Test**: 
1. Compute étale probe complexity for $K = \mathbb{Q}(\sqrt{d})$ with $d \in \{-163, -67, -43, -19, -11, -7, -3, -2, -1, 2, 3, 5, 6, 7\}$.
2. Compare with known class numbers.
3. Check correlation and exact equality for class number 1 fields.

**Impact**: Would establish a new connection between probe complexity and classical arithmetic invariants, potentially providing a novel algorithm for class number computation.

**Catalog References**: `Pythagorean/ProbeComplexity/SheafCompression.lean` (framework), `Pythagorean/ProbeComplexity/RepresentableDimension.lean` (measurement invariants)

**Proof Strategy**: Use the fact that the étale fundamental group $\pi_1^{\mathrm{ét}}(\mathrm{Spec}(\mathcal{O}_K))$ classifies connected étale covers, and the class group controls the abelian covers. Probe complexity should measure the minimum number of étale neighborhoods needed to separate all local sections, which is controlled by the class group structure.

**Domain Bridges**: Algebraic number theory (class field theory), algebraic geometry (étale cohomology).

**Lineage**: New direction building on the sheaf compression framework.

**Ambition**: ★★★★★ (Grand challenge — connects probe complexity to deep arithmetic)

## Direction 4: Quantum Measurement Complexity via Topology-Respecting Probes

**Conjecture**: For the site of Boolean algebras (with the canonical topology encoding commutativity), topology-respecting probe complexity of the spectral presheaf of a quantum system equals the minimum number of mutually unbiased bases needed to reconstruct the quantum state.

**Test**:
1. Formalize the site of Boolean subalgebras of $\mathcal{B}(\mathbb{C}^n)$ for $n = 2, 3, 4$.
2. Compute the spectral presheaf and its probe complexity with the canonical topology.
3. Compare with known MUB counts (3 for $n = 2$, 4 for $n = 3$, 5 for $n = 4$).

**Impact**: Would establish the first rigorous connection between categorical probe complexity and quantum state tomography, bridging abstract category theory with quantum information science.

**Catalog References**: `Pythagorean/ProbeComplexity/SheafCompression.lean` (topology-respecting probes), `Pythagorean/ProbeComplexity/Defs.lean` (separation)

**Proof Strategy**: The spectral presheaf assigns to each Boolean subalgebra $B$ the set of ultrafilters on $B$ (classical snapshots of the quantum state). Probes are Boolean subalgebras; topology-respecting means the probes generate a covering family of commutative contexts. Show that the minimum covering family corresponds to a complete set of MUBs.

**Domain Bridges**: Quantum foundations (Kochen-Specker), quantum information (state tomography, MUBs), topos quantum theory (Döring-Isham).

**Lineage**: New grand challenge direction.

**Ambition**: ★★★★★ (Paradigm-shifting — unifies categorical probe theory with quantum measurement theory)

## Direction 5: ∞-Categorical Probe Complexity and Persistent Homology

**Conjecture**: For the ∞-site of simplicial complexes filtered by inclusion (the persistence site), the sheaf probe complexity of the persistent homology sheaf equals the number of distinct persistence intervals (bars in the barcode).

**Test**:
1. Compute persistent homology for standard TDA datasets (e.g., Vietoris-Rips complexes of point clouds in $\mathbb{R}^2$ and $\mathbb{R}^3$).
2. Compute probe complexity of the associated persistence sheaf (as a sheaf on the poset of filtration values).
3. Compare with the number of bars in the persistence barcode.

**Impact**: Would provide a categorical foundation for persistent homology via probe complexity, potentially leading to new stability results and a deeper understanding of TDA invariants.

**Catalog References**: `Pythagorean/ProbeComplexity/RepresentableDimension.lean` (representable dimension for discrete presheaves), `Pythagorean/ProbeComplexity/SheafCompression.lean` (sheaf probe complexity)

**Proof Strategy**: On a finite poset, sheaves are functors satisfying a descent condition for covering families. The probe complexity of the persistent homology sheaf counts how many "reference filtration values" are needed to reconstruct all homology groups. Each persistence interval contributes one independent piece of information, suggesting equality with the barcode count.

**Domain Bridges**: Topological data analysis (persistent homology, barcodes), applied algebraic topology (Čech and Vietoris-Rips complexes), computational geometry.

**Lineage**: Extends finite-category probe complexity to the persistent/filtered setting.

**Ambition**: ★★★★☆ (Grand challenge direction with concrete testability)
