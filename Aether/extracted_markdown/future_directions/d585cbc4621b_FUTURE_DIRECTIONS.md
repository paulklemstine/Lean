# Future Directions: Tropical Scaling Exponents for Computation DAGs

## Overview

The tropical scaling exponent framework established in this work provides the first formally verified invariant for neural scaling laws. Below we identify five falsifiable scientific hypotheses that arise naturally from this framework, each with precise conjectures, experimental or formal tests, and criteria for refutation.

---

## Hypothesis 1: Exponent Completeness

**Conjecture**: For admissible symbolic architectures (transformer variants, MLPs, convnets with standard activation functions), tropical equivalence completely determines the leading empirical scaling exponent. That is, if two architectures $G$ and $H$ satisfy $G \approx_T H$ and are trained on the same data distribution with matched hyperparameters, then their empirical scaling exponents $\hat{\alpha}_G$ and $\hat{\alpha}_H$ converge to the same value as training data and compute increase.

**Test**: Construct families of 10+ architectures within each of 3-5 tropical equivalence classes. Train each architecture across 5 scales (e.g., $N \in \{10^6, 10^7, 10^8, 10^9, 10^{10}\}$) on a fixed text corpus. Fit power-law exponents $\hat{\alpha}$ and compute 95% confidence intervals.

**Refutation criterion**: If within any tropical class, two architectures show exponent estimates $\hat{\alpha}_1, \hat{\alpha}_2$ whose 95% confidence intervals are disjoint and the separation persists as scale increases, the hypothesis is refuted.

**Impact if true**: Tropical equivalence becomes a practical design tool — engineers can freely rearrange computation graphs within an equivalence class without affecting scaling.

---

## Hypothesis 2: Polylogarithmic Correction Universality

**Conjecture**: Tropical equivalence determines not only the leading power-law exponent $\alpha$ but also constrains the degree range of logarithmic corrections. Specifically, if $G \approx_T H$, then the sub-leading behavior satisfies $L_G(N) = \Theta(N^{-\alpha} (\log N)^{\beta_G})$ and $L_H(N) = \Theta(N^{-\alpha} (\log N)^{\beta_H})$ with $\beta_G$ and $\beta_H$ in the same bounded range determined by the tropical profile.

**Test**: Fit the model $L(N) = c \cdot N^{-\alpha} (\log N)^\beta$ on matched architecture families using nonlinear regression. Compare the fitted $\beta$ values across tropically equivalent architectures.

**Refutation criterion**: Stable $\beta$-values that differ by more than a factor of 2 within one tropical class across repeated experiments with different random seeds and data shuffles.

**Impact if true**: The tropical profile captures not just the first-order scaling but also meaningful second-order structure, suggesting the framework has deeper predictive power than the leading exponent alone.

---

## Hypothesis 3: Motivic Refinement

**Conjecture**: There exists a finer invariant than the tropical scaling exponent — analogous to a Grothendieck-class valuation on computation graphs — that distinguishes architectures with the same $\alpha$ but different lower-order asymptotic structure. Formally, define a "tropical Grothendieck ring" $K_0(\mathbf{DAG}_T)$ generated by tropical equivalence classes under disjoint union and composition. The class $[G]$ in this ring determines more information than $\alpha(G)$ alone.

**Test**: Construct pairs of DAGs with equal $\alpha$ but different intercept distributions. Check whether these pairs systematically show different sub-leading scaling behavior. Formalize the ring structure and prove it is non-trivial (has more than one generator in each dimension).

**Refutation criterion**: If the Grothendieck ring is trivially generated (every class is determined by $\alpha$), or if DAGs with the same ring class but different intercepts show identical sub-leading behavior in all experiments, the refinement adds no information.

**Impact if true**: Opens a connection to motivic integration and algebraic K-theory, potentially yielding a complete invariant theory for computation graph scaling.

---

## Hypothesis 4: Complexity-Transfer Invariance

**Conjecture**: For symbolic task families with equal Kolmogorov complexity growth rate $K(n) = \Theta(n^{\gamma})$, any fixed tropical architecture class yields the same scaling exponent $\alpha$ regardless of the specific task family. That is, the exponent depends on the architecture's tropical class and the complexity growth rate, but not on the specific task within a complexity class.

**Test**: Compare three task families with matched complexity growth:
- Arithmetic sequences with $K(n) \sim n$ (e.g., addition of $n$-digit numbers)
- Formal language recognition with $K(n) \sim n$ (e.g., balanced parentheses of depth $n$)
- Algorithmic sequences with $K(n) \sim n$ (e.g., sorting $n$ elements)

Train a fixed architecture class on each task family and compare scaling exponents.

**Refutation criterion**: Persistent exponent divergence (confidence intervals non-overlapping) across matched-growth task families on the same architecture class.

**Impact if true**: Establishes that scaling exponents factor into an architecture component and a task-complexity component, enabling transfer of scaling predictions across domains.

---

## Hypothesis 5: Tropical Minor Monotonicity

**Conjecture**: If the tropical normal form of architecture $H$ contains the tropical profile of architecture $G$ as a "dominant minor" (i.e., the minimum-slope forms of $G$ appear in $H$'s profile), then $\alpha(H) \leq \alpha(G)$. Furthermore, if $G$'s profile is a subset of $H$'s profile, then $\alpha(H) \leq \alpha(G)$ with equality iff $G$'s minimum-slope form is also $H$'s minimum-slope form.

**Test**:
1. Formally prove the subset-monotonicity result: if $S(G) \subseteq S(H)$, then $\alpha(H) \leq \alpha(G)$.
2. Construct DAG families where adding paths (edges) to a graph either preserves or reduces the exponent.
3. Verify empirically that architectures with richer path structure (more tropical paths) tend to have smaller (better) exponents.

**Refutation criterion**: Finding a pair $G, H$ where $S(G) \subsetneq S(H)$ but $\alpha(H) > \alpha(G)$. (This should be formally impossible by the subset property of $\min$, so the real test is whether the *empirical* exponents respect this ordering.)

**Impact if true**: Provides a monotonicity principle for architecture design — adding computational pathways can only improve or preserve the scaling exponent, giving a formal basis for the "wider/deeper is better" heuristic.

---

## Priority Ordering

1. **Hypothesis 1** (Exponent Completeness) — most fundamental, directly tests the framework's empirical relevance
2. **Hypothesis 5** (Minor Monotonicity) — most formally tractable, can be partially resolved by pure mathematics
3. **Hypothesis 4** (Complexity-Transfer) — most practically impactful for cross-domain prediction
4. **Hypothesis 2** (Polylog Corrections) — requires careful experimental methodology
5. **Hypothesis 3** (Motivic Refinement) — most mathematically ambitious, longest time horizon

---

## Connection to Current Work

The theorems proved in this cycle — rationality of $\alpha$, tropical invariance, and the asymptotic sandwich — are precisely what makes Hypotheses 1–5 scientifically meaningful rather than speculative. Without the invariance theorem, "tropical equivalence preserves exponents" would be a tautology or an undefined claim. With it, each hypothesis makes a precise prediction that can be tested against the mathematical framework.

The formal verification ensures that any experimental refutation points to a modeling gap (between real neural networks and tropical DAGs) rather than a mathematical error, focusing future investigation on the right questions.
