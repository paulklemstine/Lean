# Future Directions: Certified Tropical Hodge Theory

## Overview

The tropical Hodge–cycle correspondence established in this work opens several concrete research directions. Each direction below is specific enough to drive a focused research cycle, with clear hypotheses, proof strategies, and cross-domain connections.

---

## Direction 1: Graded Ring Structure and Divisor-Generation Bootstrap

### Goal
Formalize the graded ring structure on tropical cohomology and prove that if cohomology is generated in degree 1 by divisor classes (the "Hard Lefschetz" condition), then the Hodge–cycle correspondence holds in all degrees by multiplicative bootstrap.

### Hypothesis
If `G : GradedTropicalModel` has divisor generators $d_1, \ldots, d_k \in \text{Coh}^1$ that are cycle classes, and if cohomology is generated by products of divisor classes, and if products of cycle classes are cycle classes (tropical intersection product), then every Hodge class in every degree is a cycle class.

### Strategy
1. Define a bilinear multiplication map `cohMul : Coh p → Coh q → Coh (p+q)`.
2. Define the divisor power submodule: $D^p = \text{span}_\mathbb{Z}\{d_{i_1} \cdot \ldots \cdot d_{i_p}\}$.
3. Prove by induction on $p$: if each $d_i$ is a cycle class and products of cycle classes are cycle classes, then every element of $D^p$ is a cycle class.
4. If $H_p = D^p$ (generation hypothesis), conclude $H_p = C_p$.

### Cross-Domain Connections
- **Matroid Chow rings:** The Chow ring $A^*(M)$ of a matroid is generated in degree 1. This direction would directly apply to matroid Hodge theory.
- **Algebraic K-theory:** The divisor-generation condition is related to the Chern character being surjective.

### Estimated Difficulty
Medium. The main challenge is handling the `cast` in `Coh (1 + (n+1)) = Coh (n+2)` cleanly in Lean.

## Direction 2: Tropical Poincaré Duality and Hard Lefschetz

### Goal
Formalize Poincaré duality for finite balanced polyhedral complexes and derive a Hard Lefschetz criterion for cycle representability.

### Hypothesis
For a "nice" polyhedral complex $\Sigma$ of dimension $d$ with a Lefschetz element $L \in \text{Coh}^1$, the map $L^{d-2p} : H^p \to H^{d-p}$ is an isomorphism. Combined with the Hodge–cycle correspondence, this implies every Hodge class in degree $\leq d/2$ is determined by its Lefschetz images.

### Strategy
1. Define a pairing $\langle \cdot, \cdot \rangle : \text{Coh}^p \times \text{Coh}^{d-p} \to \mathbb{Z}$ via cell counting.
2. Formalize Poincaré duality: the pairing is non-degenerate on balanced classes.
3. Define the Lefschetz operator $L : \text{Coh}^p \to \text{Coh}^{p+1}$ (multiplication by a chosen divisor class).
4. Prove Hard Lefschetz under explicit combinatorial conditions on $\Sigma$.
5. Derive: if $x \in H^p$ with $p \leq d/2$, then $x$ is a cycle class iff $L^{d-2p} \cdot x$ is.

### Cross-Domain Connections
- **Hodge index theorem:** Sign conditions on the intersection form.
- **Algebraic topology:** Poincaré duality for cell complexes.
- **Convex geometry:** The Lefschetz property is related to the $g$-theorem for simplicial polytopes.

### Estimated Difficulty
Hard. Poincaré duality requires careful handling of orientations and boundary maps.

## Direction 3: Certified Algorithm for Tropical Algebraic Class Detection

### Goal
Build a verified algorithm (inside Lean or as a certified external procedure) that, given a tropical complex and a cohomology class, decides whether the class is in the cycle image and produces a balanced weight representative if so.

### Hypothesis
The finite generation theorem (Theorem B) guarantees that cycle class membership is decidable. An explicit algorithm using Hermite normal form over $\mathbb{Z}$ can decide membership in polynomial time.

### Strategy
1. Implement Hermite normal form for integer matrices in Lean (or verify an external implementation).
2. Given balanced generators $g_1, \ldots, g_k$ and cycle map $\phi$, compute the Hermite normal form of the image matrix $[\phi(g_1), \ldots, \phi(g_k)]$.
3. Test membership of the given class in the lattice generated by the columns.
4. If membership holds, extract the coefficient vector and reconstruct the balanced weight.
5. Prove correctness of each step formally.

### Cross-Domain Connections
- **Computational number theory:** Smith and Hermite normal forms.
- **Lattice algorithms:** Connection to LLL reduction and closest vector problems.
- **Verified computation:** Extends Lean's computational capabilities.

### Estimated Difficulty
Medium-High. The algorithm itself is well-known; the challenge is formal verification.

## Direction 4: Functorial Transfer for Degenerating Families

### Goal
Extend the transfer principle from a single comparison map to a *functorial* comparison for families of varieties degenerating to a tropical limit.

### Hypothesis
Given a family $\mathcal{X} \to \text{Spec}(R)$ of algebraic varieties with tropical limit $\Sigma$, the specialization map $\text{sp} : H^*(\mathcal{X}_\eta) \to H^*(\Sigma)$ is compatible with cycle classes. The tropical Hodge theorem on $\Sigma$ then constrains the algebraic classes on every smooth fiber $\mathcal{X}_t$.

### Strategy
1. Define a `FamilyTransferData` structure extending `TransferData` with a base parameter.
2. Prove compatibility of the transfer with specialization maps.
3. Show: if a class is in the cycle image of $\Sigma$, its pullback to any smooth fiber is algebraic.
4. Derive: the transferred cycle image gives a *uniform* lower bound on algebraic classes across all fibers.

### Cross-Domain Connections
- **Non-Archimedean geometry:** Berkovich analytification and tropicalization.
- **Mirror symmetry:** SYZ fibrations and their tropical shadows.
- **Moduli theory:** Compactification of moduli spaces via tropical geometry.

### Estimated Difficulty
Very Hard. Requires significant mathematical infrastructure beyond what is currently available in Mathlib.

## Direction 5: Bergman Fan Cohomology and Matroid Chow Rings

### Goal
Connect the tropical Hodge framework to Bergman fan cohomology and matroid Chow rings, establishing the Hodge–cycle correspondence for the Bergman fan of a matroid.

### Hypothesis
For a matroid $M$ with Bergman fan $\Sigma_M$, the Chow ring $A^*(M)$ is isomorphic to the tropical cohomology of $\Sigma_M$, and the Hodge–cycle correspondence holds by the Adiprasito–Huh–Katz theory.

### Strategy
1. Define the Bergman fan of a matroid as a `PolyhedralData` structure.
2. Compute balanced submodules for small matroids (uniform matroids $U_{k,n}$ for small $k, n$).
3. Verify the Hodge–cycle correspondence computationally.
4. Prove the correspondence for specific matroid families (e.g., uniform matroids, graphic matroids).
5. Connect to the log-concavity results of Adiprasito–Huh–Katz.

### Cross-Domain Connections
- **Combinatorics:** Chromatic polynomials, characteristic polynomials of matroids.
- **Optimization:** Matroid intersection and polyhedral combinatorics.
- **Representation theory:** Kazhdan–Lusztig theory for matroids.

### Estimated Difficulty
Hard. Requires formalization of matroid theory and Bergman fan construction.

## Team Research Directive

Each direction should be pursued by a team that:
1. **Formulates precise hypotheses** as Lean theorem statements with `sorry`.
2. **Tests hypotheses computationally** using the Python algorithms on small examples.
3. **Builds infrastructure incrementally** — prove helper lemmas bottom-up.
4. **Cross-validates** with the mathematical literature.
5. **Iterates** — update hypotheses based on failed proof attempts.

The overarching goal is to build the first **certified tropical Hodge machine**: a framework where tropical algebraic geometry is machine-verified, algorithmically tractable, and connected to classical algebraic geometry by proven transfer principles.
