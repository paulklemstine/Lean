# Future Directions: Automatic Sequences and Decidability

## Synthesis

This research cycle established a formal foundation for automatic sequences by formalizing DFAOs (Deterministic Finite Automata with Output), proving the decidability of value occurrence via finite-state reachability, and establishing structural results including the pumping lemma and eventual periodicity of unary sequences. The most significant finding is the clean separation between the decidable world of automatic sequences and the potentially undecidable world of morphic sequences — a boundary that hinges entirely on whether the generating morphism is uniform.

The cycle introduced **automatic complexity** as a novel measure of finite-state sequence complexity, analogous to Kolmogorov complexity but computable and well-defined for all automatic sequences. This opens connections to the Catalog's information-theoretic and complexity-theoretic results, particularly the `PadicValuationDepth` work which measures sequence complexity via p-adic valuations, and the `InfoEfficientAlgorithms` framework which characterizes computational efficiency in terms of potential functions.

The most promising cross-domain connection is between automatic complexity and the EML (Ensemble Machine Learning) complexity measures in the Catalog. Both measure the "inherent complexity" of structured objects using different frameworks — automatic complexity via minimal finite automata, EML complexity via ensemble decomposition. A bridge theorem connecting these measures could unify discrete automata theory with continuous optimization frameworks. The direction with the highest breakthrough potential is formalizing Christol's theorem, which would create a verified bridge between algebra (algebraic power series) and automata theory (DFAOs), touching number theory, formal language theory, and algebraic geometry simultaneously.

### Direction 1: Christol's Theorem Formalization

**Conjecture**: A formal power series f(x) = Σ aₙ xⁿ over the finite field F_q is algebraic over F_q(x) (i.e., satisfies P(x, f(x)) = 0 for some nonzero polynomial P ∈ F_q[x, y]) if and only if the coefficient sequence (aₙ)ₙ≥₀ is q-automatic (generated by a DFAO with base q and output in F_q).

**Test**: (1) Formalize the forward direction for q = 2: given a 2-automatic sequence (aₙ) over F₂, construct the polynomial P(x, y) ∈ F₂[x, y] such that P(x, Σ aₙ xⁿ) = 0 in F₂[[x]]. (2) Verify computationally for the Thue-Morse sequence mod 2: the generating function t(x) = Σ t(n) xⁿ satisfies t(x)³ + t(x) + x = 0 over F₂. (3) Attempt the reverse direction: given an algebraic power series, construct the generating DFAO.

**Impact**: A verified Christol's theorem would be a landmark formalization, connecting three major areas of mathematics (automata theory, algebra, number theory) in a single machine-checked proof. It would enable automated reasoning about algebraicity of power series by reducing to automata-theoretic computations.

**Catalog References**: `Computation/PadicValuationDepth.lean` (p-adic structure of sequences), `Computation/AutomaticSequences.lean` (DFAO framework from this cycle)

**Proof Strategy**: The forward direction (automatic → algebraic) proceeds via the Cartier operator: define the operator C_i(f) = Σ a_{qn+i} xⁿ for 0 ≤ i < q. Show that f is q-automatic iff the vector space spanned by iterated Cartier operators is finite-dimensional. Then construct the minimal polynomial from the linear dependence relations. The key lemma is that the Cartier operators correspond to the transition function of the DFAO. The reverse direction uses the fact that an algebraic power series satisfies a finite system of q-Mahler equations, from which the DFAO can be extracted.

**Domain Bridges**: Automata theory ↔ Commutative algebra ↔ Number theory (p-adic analysis)

**Lineage**: Builds on the DFAO formalization from this cycle (processFrom_append, eval_eq_of_process_eq, generatedSeq_values_finite). Requires new Mathlib infrastructure for formal power series over finite fields and the Cartier operator.

**Ambition**: grand_challenge

### Direction 2: Morphic Zero-in-Sequence Decidability

**Conjecture**: The zero-in-sequence problem for morphic sequences is decidable. Precisely: given a morphism σ : Σ → Σ* on a finite alphabet Σ, a letter a ∈ Σ with σ(a) starting with a (so that the fixed point σ^ω(a) exists), a coding c : Σ → Γ, and a target value v ∈ Γ, it is decidable whether v appears in c(σ^ω(a)).

**Test**: (1) Implement a candidate decision algorithm for morphic sequences over alphabets of size ≤ 5 and morphisms with maximum image length ≤ 10. (2) Test on 1000 random morphisms: verify that the algorithm terminates and gives correct answers (checked against brute-force computation of the first 10⁶ terms). (3) Attempt to formalize the algorithm's correctness for the special case of "growing" morphisms (where |σ(a)| ≥ 2 for all a).

**Impact**: If true, this would close an open problem in combinatorics on words. If false (i.e., morphic zero-in-sequence is undecidable), it would establish a sharp decidability boundary: uniform morphisms = decidable, general morphisms = undecidable. Either answer would be a significant result.

**Catalog References**: `Computation/AutomaticSequences.lean` (DFAO decidability proof provides the template), `Catalog/Logic/Advanced.lean` (decidability framework)

**Proof Strategy**: The most promising approach uses the fact that morphic sequences have at most polynomial factor complexity (Pansiot's theorem). This limits the growth of the "generalized kernel" — the set of distinct subsequences obtained by iterating the morphism. If this generalized kernel is always finite (or can be effectively bounded), decidability follows by the same reachability argument used for DFAOs. The key challenge is formalizing the relationship between morphism iteration and the growth of the generalized kernel for non-uniform morphisms.

**Domain Bridges**: Automata theory ↔ Combinatorics on words ↔ Computability theory

**Lineage**: Directly extends the DFAO decidability results from this cycle. The morphic conjecture was formally stated as `morphicZeroDecidabilityConjecture` in `Computation/AutomaticSequences.lean`.

**Ambition**: grand_challenge

### Direction 3: Automatic Complexity Bounds and Structure

**Conjecture**: For any k-automatic sequence a with automatic complexity AC_k(a) = s, and any pointwise function f : α → β, the composed sequence f ∘ a has automatic complexity AC_k(f ∘ a) ≤ s. More strongly, AC_k(f ∘ a) equals the number of equivalence classes of the relation q₁ ~ q₂ iff f(τ(q₁)) = f(τ(q₂)) on the reachable states of the minimal DFAO for a.

**Test**: (1) Compute AC_2 for the first 100 2-automatic sequences in the OEIS. (2) Verify the upper bound AC_k(a ⊕ b) ≤ AC_k(a) · AC_k(b) for ⊕ = XOR on 50 pairs of 2-automatic sequences. (3) Characterize which values of s are achievable as AC_2(a) for sequences over {0, 1} — is every positive integer achievable?

**Impact**: Understanding automatic complexity bounds would provide a practical measure of sequence complexity computable in polynomial time (given the sequence's generating DFAO). Connections to factor complexity and subword complexity could yield new characterizations of automatic sequences.

**Catalog References**: `Computation/AutomaticSequences.lean` (automatic complexity definition), `Computation/InfoEfficientAlgorithms.lean` (complexity measures for algorithms), `EML/AdvancedTheory.lean` (ensemble complexity — potential analogue)

**Proof Strategy**: For the composition bound, use the fact that composing the output function τ with f yields a new DFAO with the same states but possibly more state equivalences. The quotient by the new equivalence gives the minimal DFAO for f ∘ a. Formalize state equivalence quotients using the stateEquiv_equiv theorem from this cycle. For the product bound, use the productDFAO construction and show that unreachable states can be removed.

**Domain Bridges**: Automata theory ↔ Information theory (complexity measures) ↔ EML (ensemble decomposition)

**Lineage**: Builds on automaticComplexity definition and stateEquiv_equiv from this cycle.

**Ambition**: extension

### Direction 4: Automatic Sequences and p-adic Analysis

**Conjecture**: For a prime p, the p-automatic complexity of a sequence (aₙ) over F_p equals the dimension of the F_p-vector space spanned by the p-kernel of (aₙ). Furthermore, this dimension equals the degree of the minimal polynomial of the generating function Σ aₙ xⁿ over F_p(x) (connecting to Christol's theorem).

**Test**: (1) Compute the p-kernel vector space dimension for all 2-automatic sequences with AC_2 ≤ 5. (2) Verify the equality with AC_2 in each case. (3) For the Thue-Morse sequence, verify that the 2-kernel has exactly 2 elements and the generating function has minimal polynomial degree 2 (it satisfies t² + t + x/(1+x)² = 0 over F₂... actually t³ + t + x = 0).

**Impact**: A verified connection between kernel dimension, automatic complexity, and algebraic degree would unify three independent characterizations of "how complex" an automatic sequence is. This triple equivalence would be a powerful tool for computing any one measure from any other.

**Catalog References**: `Computation/PadicValuationDepth.lean` (p-adic depth measures), `Computation/AutomaticSequences.lean` (kernel and complexity definitions)

**Proof Strategy**: The kernel-dimension ≤ AC_k direction follows from the fact that each kernel element corresponds to a reachable state in the DFAO (formalized via processFrom_append). The reverse direction constructs a DFAO from a finite kernel basis. The algebraic-degree equality requires Christol's theorem (Direction 1) as a prerequisite.

**Domain Bridges**: Automata theory ↔ p-adic analysis ↔ Algebraic geometry (function fields)

**Lineage**: Builds on both the DFAO framework and the k-kernel definition from this cycle, and would naturally follow from progress on Direction 1 (Christol's theorem).

**Ambition**: extension

### Direction 5: Decidability Hierarchy for Sequence Classes

**Conjecture**: There exists a strict hierarchy of sequence classes, ordered by the decidability of the zero-in-sequence problem:

1. **Eventually periodic** (decidable, trivially — finite check)
2. **k-automatic** (decidable — finite-state reachability, proved this cycle)
3. **Morphic** (conjectured decidable — open, Direction 2)
4. **Polynomial recursive** (P-recursive / D-finite) (unknown)
5. **Computable** (Σ₁⁰-complete — r.e. but not decidable)
6. **General** (not even r.e.)

Furthermore, the boundary between decidable and undecidable zero-in-sequence lies strictly between morphic and computable.

**Test**: (1) Formalize the hierarchy as a chain of set inclusions: EventuallyPeriodic ⊂ Automatic ⊂ Morphic ⊂ PRecursive ⊂ Computable. (2) Prove that each inclusion is strict by exhibiting a separating example. (3) For P-recursive sequences, investigate whether decidability depends on the order of the recurrence — is zero-in-sequence decidable for sequences satisfying a first-order linear recurrence with polynomial coefficients?

**Impact**: A verified decidability hierarchy would provide a complete map of the "computational landscape" of infinite sequences. Understanding exactly where decidability breaks down would have implications for automated reasoning about combinatorial identities, formal verification of number-theoretic algorithms, and the foundations of enumerative combinatorics.

**Catalog References**: `Computation/AutomaticSequences.lean` (automatic level), `Catalog/Logic/Advanced.lean` (decidability and computability), `Computation/GravityOracle.lean` (oracle hierarchies)

**Proof Strategy**: The inclusions EventuallyPeriodic ⊂ Automatic ⊂ Morphic are well-known. Automatic ⊂ Morphic follows from the characterization of k-automatic sequences as codings of fixed points of k-uniform morphisms. Separating examples: the Fibonacci word (morphic but not automatic), the sequence of prime indicators (computable but not P-recursive by a result of Flajolet). The decidability of zero-in-sequence for P-recursive sequences is a major open question that could be approached via effective bounds on zero-free intervals.

**Domain Bridges**: Automata theory ↔ Computability theory ↔ Analytic combinatorics ↔ Oracle computation

**Lineage**: Extends the decidability results from this cycle into a broader hierarchy. The unary_dfao_eventually_periodic theorem establishes the connection between levels 1 and 2.

**Ambition**: grand_challenge
