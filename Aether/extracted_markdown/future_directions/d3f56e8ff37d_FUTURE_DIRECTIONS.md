# Future Directions: Pythagorean Lattice Cryptography and Tropical Geometry

## Breakthrough Opportunities (ranked by impact)

### 1. Berggren Completeness Theorem (Impact: ★★★★★)

**Theorem Statement**: Every primitive Pythagorean triple (a,b,c) with a odd, b even, gcd(a,b)=1, a,b,c > 0, appears exactly once in the Berggren tree rooted at (3,4,5).

**Proof Strategy**:
- **Descent approach**: Show that each inverse Berggren matrix maps a valid triple to a triple with strictly smaller hypotenuse, until reaching (3,4,5). Key lemma: for c > 5, exactly one of A⁻¹, B⁻¹, C⁻¹ produces a valid triple with smaller c.
- **Structural approach**: Use the bijection between primitive triples and pairs (m,n) with m > n > 0, gcd(m,n) = 1, m-n odd (Euclid parametrization), and show the Berggren matrices act by specific transformations on (m,n) that partition the parameter space.

**Why Revolutionary**: Establishes the Berggren tree as a complete computational framework for Pythagorean triples, enabling O(log c) algorithms for any operation that reduces to tree traversal.

**Catalog Leverage**: `berggrenTree_all_pythagorean`, `berggren_A_pyth`, `berggren_B_pyth`, `berggren_C_pyth`

**Research Mode**: prove | **Estimated Depth**: 4

### 2. Exact SVP Hardness for Pythagorean Lattices (Impact: ★★★★★)

**Theorem Statement**: For the 3-dimensional lattice L_p generated by Berggren matrix columns applied to a primitive triple p, the shortest non-zero vector has Euclidean length exactly equal to the minimum leg of p.

**Proof Strategy**:
- Compute the Gram matrix G = B^T B for each Berggren matrix B
- Use Minkowski's theorem to bound the shortest vector
- Show the explicit vector (a, b, c) achieves the bound with length = min(a,b)

**Why Revolutionary**: Would connect Pythagorean structure to the Shortest Vector Problem, establishing the first concrete family of lattices with known SVP solutions and characterizable hardness.

**Catalog Leverage**: `berggren_lorentz_all`, `berggren_det_unit`, `pythLatticeDim_mono`

**Research Mode**: prove | **Estimated Depth**: 5

### 3. Tropical Pythagorean Data Processing Inequality (Impact: ★★★★)

**Theorem Statement**: For any Lipschitz-1 map f on tropical Pythagorean triples, the "tropical entropy" H_trop(f(X)) ≤ H_trop(X) where H_trop is the sup-norm entropy H_trop(p) = max(|p.a|, |p.b|).

**Proof Strategy**:
- Define tropical entropy as H_trop(p) = tropPythDist(p, tropPythZero)
- Use `tropical_certified_robustness` to show f contracts distances from zero
- The inequality follows from f being nonexpansive

**Why Revolutionary**: Establishes an information-theoretic constraint on tropical computation, connecting tropical geometry to information theory.

**Catalog Leverage**: `tropical_certified_robustness`, `tropPythDist_triangle`, `tropPythMul_isometry_right`

**Research Mode**: prove | **Estimated Depth**: 2

### 4. Deep Min-Pooling Network Robustness (Impact: ★★★★)

**Theorem Statement**: For a depth-L min-pooling network with Lipschitz-1 layers f₁,...,f_L, the composition f_L ∘ ... ∘ f₁ is Lipschitz-1 with respect to tropPythDist.

**Why Revolutionary**: Would provide formally verified certified robustness bounds for arbitrary-depth tropical neural networks.

**Catalog Leverage**: `tropical_depth_2_robustness`, `tropical_lipschitz_composition`

### 5. Berggren–Stern–Brocot Correspondence (Impact: ★★★★)

**Theorem Statement**: There exists an order-preserving bijection between the Berggren tree of primitive Pythagorean triples (ordered by a/b ratio) and the Stern-Brocot tree of positive rationals.

**Proof Strategy**:
- Map (a, b, c) → a/b (or b/a) to get a rational number
- Show the three Berggren transforms on a/b correspond to the left/right moves in the Stern-Brocot tree
- The key algebraic identity: the Berggren matrices act on a/b by Möbius transformations

**Why Revolutionary**: Would unify two fundamental tree structures in number theory, showing they are different views of the same underlying object.

**Catalog Leverage**: `berggren_AC_conj`, `berggren_exponential_growth`, `berggren_tree_total`

**Research Mode**: discover | **Estimated Depth**: 4

## Under-explored Territory

1. **Pythagorean quadruples** (a² + b² + c² = d²): The existing catalog has basic quadruple definitions but few deep theorems. The Berggren-like tree structure for quadruples would be a major result.

2. **Tropical Pythagorean optimization**: The convexity of `tropPythCone` suggests efficient optimization algorithms. Formalizing tropical linear programming on the Pythagorean cone could yield new algorithmic results.

3. **Galois-theoretic obstructions**: The ℤ/4ℤ rotation symmetry (galois_4fold) suggests deeper Galois structure. Which number fields admit Pythagorean triples? The answer involves the ramification of 2 and relates to class field theory.

4. **p-adic Pythagorean triples**: For each prime p, the set of p-adic Pythagorean triples forms a p-adic analytic manifold. The interaction between the Berggren tree (which is Archimedean) and p-adic structure is unexplored.

## Cross-Domain Bridges

1. **Pythagorean ↔ Quantum**: The Lorentz form Q = diag(1,1,-1) is the metric of (2+1)-dimensional Minkowski spacetime. Pythagorean triples on the null cone correspond to light-like directions. A formal bridge to the quantum Pythagorean theorem (‖x+y‖² = ‖x‖² + ‖y‖² for orthogonal x,y in Hilbert space) would connect classical number theory to quantum mechanics.

2. **Tropical ↔ Neural Networks**: The composition of min and addition operations in tropical arithmetic is exactly the computation performed by min-pooling layers in neural networks. Formalizing the equivalence between tropical Pythagorean triples and min-pooling network states would give a new mathematical foundation for neural network analysis.

3. **Berggren ↔ Lattice Cryptography**: The Berggren matrices generate a finitely-generated subgroup of GL(3,ℤ) acting on the Pythagorean lattice. The word problem in this group (given a triple, find the Berggren path) is the Pythagorean analogue of the lattice shortest vector problem.

## Open Problems Encountered

1. **Ring tactic limitation**: The `ring` tactic in Lean 4 cannot handle ℤ subtraction in certain normal forms. The Lorentz multiplicativity theorem Q(p·q) = Q(p)·Q(q) is FALSE in general (only true on the null cone), which we discovered and corrected during formalization.

2. **Nat.div opacity**: Proving strict inequalities involving `N*(N+1)/2` requires explicitly establishing that N*(N+1) is even (via `Nat.even_mul_succ_self`). The omega tactic cannot see through integer division.

3. **List induction for network composition**: Proving certified robustness for arbitrary-depth networks via `List.foldl` is technically challenging in Lean due to the interaction between function composition and list induction.
