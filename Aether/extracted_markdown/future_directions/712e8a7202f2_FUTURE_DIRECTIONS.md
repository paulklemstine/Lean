# Future Directions: Substitution Complex Theory

## 1. Shortest Path Enumeration and Factorial Structure

The number of shortest substitution chains between two configurations at Hamming distance k is exactly k!, corresponding to the k! permutations of which differing coordinates to "fix" first. The key insight is that shortest paths biject with linear extensions of an antichain in the poset of coordinate-corrections, and an antichain of size k has exactly k! linear extensions. Why now? The connectivity theorem (`substitution_connected`) already constructs one canonical path by iterating over differing coordinates; extending this to a full enumeration requires formalizing the bijection between shortest paths and permutations of `(Finset.univ.filter fun i => f i ≠ g i).toList.permutations`. This would yield a formal proof that the substitution graph has non-trivial higher path structure.

## 2. PseudoMetricSpace Instance and Lipschitz Analysis

The Hamming distance satisfies all metric space axioms (symmetry, identity of indiscernibles, triangle inequality), which we have proved individually. The natural next step is to package these into an actual `MetricSpace` or `PseudoMetricSpace` instance on `Fin n → α` and study Lipschitz maps between substitution complexes of different dimensions. The key insight is that any function `φ : (Fin n → α) → (Fin m → β)` that is "coordinate-wise" (depends on each output coordinate on at most one input coordinate) is automatically 1-Lipschitz with respect to the Hamming metrics. Why now? Mathlib's `MetricSpace` typeclass infrastructure is mature, and our three core lemmas (`hammingDist_symm`, `hammingDist_eq_zero`, `hammingDist_triangle`) are exactly the axioms needed. This would connect substitution complexes to the broader Mathlib analysis library.

## 3. Chromatic Number and Clique Structure

The substitution graph on `Fin n → Fin q` (q-ary codes of length n) has chromatic number q^(n-1) when q ≥ 2. More precisely, the maximum clique size equals q (configurations differing only in one fixed coordinate from a base configuration), and the graph is vertex-transitive, so the fractional chromatic number equals q^n / (max independent set size). The key insight is that maximum independent sets are exactly the Hamming balls of radius 0, i.e., singletons — wait, that's wrong. Actually the independent sets correspond to codes with minimum distance ≥ 2, connecting this to classical coding theory bounds (Singleton, Plotkin). Why now? The adjacency relation `Adjacent` is already formalized, and Mathlib has growing support for graph coloring. This would bridge substitution complexes to combinatorial coding theory.

## 4. Fundamental Group of the Substitution Complex

When we attach higher simplices (k-simplices for each set of k+1 mutually adjacent configurations), the resulting simplicial complex has interesting homotopy groups. For `Fin n → Fin 2` (binary codes), the substitution complex is the 1-skeleton of the n-dimensional hypercube, whose fundamental group is trivial (the hypercube is simply connected when n ≥ 2). The key insight is that every cycle in the substitution graph bounds a 2-cell corresponding to two substitutions that commute (changing coordinate i then j equals changing j then i), so π₁ = 0. Why now? The path connectivity theorem provides the foundation — we can already construct paths; the next step is showing that all loops are contractible by formalizing the commutation of independent substitutions as 2-cells.

## 5. Equivalence with Cayley Graphs of Symmetric Groups

The substitution graph on `Fin n → Fin q` is isomorphic to the Cayley graph of (ℤ/qℤ)^n with the standard generating set of unit vectors. This identification reveals that the graph's spectral gap equals 2(1 - cos(2π/q))/q for the normalized Laplacian, giving explicit mixing time bounds for random walks on the configuration space. The key insight is that the substitution adjacency relation is translation-invariant on the abelian group (ℤ/qℤ)^n, so standard Fourier analysis on finite abelian groups gives exact eigenvalues. Why now? Mathlib has `ZMod` and character theory for finite abelian groups, and our formalization provides the graph-theoretic foundation. This would connect the discrete "recipe substitution" model to spectral graph theory and random walks.
