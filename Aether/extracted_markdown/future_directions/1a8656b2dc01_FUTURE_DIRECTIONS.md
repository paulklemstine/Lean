# Future Directions: Tropical Hecke Trapdoor Duality

## Overview

This document outlines five concrete next steps opened by the formalization of tropical Hecke trapdoor duality — a framework connecting min-plus convolution algebras, spectral filtration theory, and cryptographic trapdoor design over finite monoids.

---

## 1. Double-Coset Basis Theorem for Finite Coxeter Groups

**Goal:** Show that tropical Hecke envelopes for finite Coxeter groups admit canonical triangular bases indexed by double-coset classes `H \ G / H`, and that these bases yield explicit trapdoor flags via tropical triangularity.

**Precise Statement (sketch):**
```
theorem double_coset_triangular_basis
  (G : Type*) [Group G] [Fintype G] [DecidableEq G]
  (H : Subgroup G) [DecidableEq (Subgroup.quotient H)]
  (𝒯 : TropicalHeckeFamily G) :
  ∃ basis : Finset (TropicalHeckeOperator G),
    IsTriangularBasis basis (doubleCosetClasses H G) ∧
    ∃ F : TrapdoorFlag (compositeOperator basis),
      True -- F is constructively derived from triangularity
```

**Proof Strategy:**
- Define double-coset decomposition `H \ G / H` using `Subgroup.quotient`.
- Show operators constant on double cosets form a commutative sub-envelope.
- Prove triangularity by induction on Bruhat order, using that double-coset kernels have support localized to specific strata.
- Construct the trapdoor flag as the sequence of partial triangular factorizations.

**Cross-domain connections:**
- Classical Hecke algebra theory (Iwahori–Hecke algebras, Kazhdan–Lusztig theory)
- Tropical Bruhat order and tropical flag varieties
- Explicit post-quantum key generation from Coxeter combinatorics

## 2. Residual Decoding via Galois Connections

**Goal:** Prove that decoding fibers in the tropical Hecke framework are residual preimages in complete idempotent semimodules, giving a general abstract inversion theory via Galois connections.

**Precise Statement (sketch):**
```
theorem residual_decoding
  (G : Type*) [Fintype G] [DecidableEq G] [Monoid G]
  (T : TropicalHeckeOperator G) :
  ∃ res : (G → WithTop ℤ) → (G → WithTop ℤ),
    GaloisConnection T.apply res ∧
    ∀ y, (∀ f, T.apply f = y → f ≤ res y) ∧ T.apply (res y) ≥ y
```

**Proof Strategy:**
- Extend the weight type from `ℤ` to `WithTop ℤ` (complete idempotent semimodule).
- Define the residual as the greatest preimage: `res(y)(g) = inf_{h} (y(g*h) - T.kernel(h))`.
- Prove the Galois connection property using order completeness.
- Show the unique minimal witness from the trapdoor flag equals the residual image when the flag is adapted.

**Cross-domain connections:**
- Residuated lattice theory and abstract interpretation
- Max-plus linear algebra (Gaubert, Litvinov)
- Tropical convex geometry: decoding fibers as tropical polyhedra

## 3. Tropical Satake-Style Correspondence

**Goal:** Identify commutative tropical Hecke envelopes with invariant tropical polynomial semirings in low-rank examples (GL₂, GL₃), giving a tropical analogue of the Satake isomorphism.

**Precise Statement (sketch):**
```
theorem tropical_satake_GL2 :
  TropicalHeckeEnvelope (GL₂ 𝔽_q) ≃+* TropicalPolynomialSemiring 1
```

**Proof Strategy:**
- For GL₂ over a finite field, the double-coset decomposition by the upper-triangular Borel subgroup gives operators indexed by a single parameter.
- Show the tropical Hecke envelope is generated by a single operator, hence is commutative.
- Construct the isomorphism explicitly: the generator maps to the tropical polynomial variable.
- Verify the isomorphism preserves tropical multiplication (convolution → polynomial multiplication).

**Cross-domain connections:**
- Classical Satake isomorphism and spherical functions
- Tropical geometry of Grassmannians
- Number-theoretic applications: tropicalized L-functions

## 4. Average-Case Hardness Surrogate via Min-Plus Circuit Complexity

**Goal:** Relate generic extremal witness search (decoding without trapdoor) to established complexity-theoretic hardness assumptions, specifically min-plus circuit lower bounds or weighted automata ambiguity.

**Precise Statement (sketch):**
```
theorem extremal_witness_reduces_to_min_plus_circuit
  (n : ℕ) (hn : n ≥ 10) :
  ∃ (C : MinPlusCircuit n),
    SolvesExtremalWitness C →
    C.size ≥ 2^(n/3)
```

**Proof Strategy:**
- Define min-plus circuits: circuits with `min` and `+` gates over ℤ.
- Encode the extremal witness problem for a random Hecke operator as a min-plus circuit evaluation problem.
- Apply known min-plus circuit lower bounds (or prove new ones) to show super-polynomial circuit size is necessary.
- Connect to weighted automata: the number of accepting runs of minimal weight equals the number of minimal witnesses, and counting runs is #P-hard in general.

**Cross-domain connections:**
- Computational complexity: min-plus circuit lower bounds (Jukna, Vassilevska-Williams)
- Weighted automata theory: ambiguity and counting problems
- Post-quantum security reductions: formal hardness of tropical decoding

## 5. Noise Stability and Certified Radius Theorem

**Goal:** Define a tropical spectral gap radius under which certified decoding is stable to perturbations, giving a quantitative robustness guarantee analogous to error-correcting code distance.

**Precise Statement (sketch):**
```
theorem certified_decoding_radius
  (G : Type*) [Fintype G] [DecidableEq G] [Monoid G]
  (T : TropicalHeckeOperator G) (F : TrapdoorFlag T)
  (y : Codeword G) (ε : Codeword G) :
  (∀ g, |ε g| ≤ spectralGap T F / (2 * Fintype.card G)) →
  trapdoorDecode T F (y + ε) = trapdoorDecode T F y
```

**Proof Strategy:**
- Define the spectral gap as the minimum difference between the weight of the unique minimal witness and the next-best witness in any fiber.
- Show that perturbations smaller than `gap / (2|G|)` cannot change which witness is minimal, because the total weight perturbation is bounded by `|G| * ε_max`.
- Prove stability of the decoding function under this perturbation bound.
- Connect to the existing `spectralSupportRadius` and `spectralLevel` infrastructure.

**Cross-domain connections:**
- Error-correcting codes: minimum distance and decoding radius
- Certified robustness in machine learning: Lipschitz certificate paradigm
- Tropical perturbation theory: stability of min-plus eigenvalues under perturbation
