# Future Directions: Braid Group Invariants

## 1. The Burau Representation and Faithfulness

The permutation representation B_n → S_n we formalized loses information: it cannot distinguish σ_i from σ_i⁻¹. The reduced Burau representation ρ : B_n → GL_{n-1}(ℤ[t, t⁻¹]) is a strictly stronger invariant that assigns to each generator a matrix over the Laurent polynomial ring. The key insight is that the Burau representation is faithful for n ≤ 3 (proved by Magnus and Peluso) but unfaithful for n ≥ 5 (proved by Moody, Long–Paton, and Bigelow). The case n = 4 remains open. Why now? Our `BraidInvariant` structure provides the exact framework needed: one would define the Burau matrices, verify the three axiom types (cancellation, braid relation, far commutativity) for the matrix assignment, and obtain a `BraidInvariant n (Matrix ...)` instance. The matrix computations are mechanical and well-suited for formal verification. A falsifiable prediction: formalizing the n = 3 faithfulness proof would require showing that the kernel of the Burau representation is trivial, which reduces to a decidable problem about matrices over ℤ[t, t⁻¹].

## 2. The Lawrence–Krammer–Bigelow Representation and Linearity of Braid Groups

Bigelow (2001) and Krammer (2002) independently proved that braid groups are linear — they admit faithful representations into GL_m(ℤ[q±1, t±1]) for appropriate m. The key insight is that this representation arises from the action of B_n on the second homology of a configuration space, giving it a natural topological interpretation that our braid word formalism can capture algebraically. Why now? Our framework already handles the permutation representation; the LKB representation is structurally identical (verify three axiom types on matrix generators) but over a more complex coefficient ring. The non-trivial mathematical content is the faithfulness proof, which could be attacked for small n (n = 3, 4) by computational methods within Lean's `#eval` capabilities. A falsifiable prediction: for n = 3, the LKB representation should separate all pairs of 3-strand braids up to word length 10, which is computationally verifiable.

## 3. Braid Group Orderability and the Dehornoy Order

Dehornoy proved that braid groups carry a left-invariant total order, making them left-orderable. The key insight is that this order can be defined purely combinatorially on braid words: a braid word w is σ-positive if, in every word equivalent to w, the generator σ_i with smallest index i appears only positively (never as σ_i⁻¹). A braid is positive in the Dehornoy order if it is σ-positive. Why now? Our `BraidWord` type with its signed generators is precisely the right data structure for formalizing σ-positivity, and the invariance proof (σ-positivity is preserved by braid moves) follows the exact same pattern as our `BraidInvariant` axioms. A falsifiable prediction: the Dehornoy order should be computable on braid words of bounded length, and for 3-strand braids up to length 8, every non-trivial braid should be either σ-positive or σ-negative (never both), which is computationally testable.

## 4. Connection to Knot Invariants via Braid Closure

Alexander's theorem states that every knot/link can be represented as the closure of some braid, and Markov's theorem characterizes when two braid closures give the same link. The key insight is that our `BraidInvariant` structure captures exactly the first half of this story: a function on braids that is constant on braid equivalence classes is a necessary (but not sufficient) condition for a knot invariant — one additionally needs invariance under Markov moves (conjugation and stabilization). Why now? Extending our `BraidInvariant` structure to a `KnotInvariant` structure that additionally requires Markov invariance would create a formal framework for constructing and verifying knot invariants from braid representations. The Jones polynomial and HOMFLYPT polynomial both arise this way. A falsifiable prediction: defining a `MarkovInvariant` extending `BraidInvariant` with conjugation invariance (`val (g :: w ++ [g.inv]) = val w`) and stabilization invariance should suffice to characterize functions that descend to knot invariants.

## 5. Garside Normal Forms and the Word Problem

Garside (1969) solved the word problem for braid groups by introducing a normal form. Every braid can be written uniquely as Δ^k · P where Δ is the half-twist (Garside element) and P is a "positive permutation braid." The key insight is that the Garside normal form provides a canonical representative for each braid equivalence class, transforming our quotient-based `BraidInvariant` approach into a direct computational one: two braids are equivalent if and only if they have the same normal form. Why now? Our `BraidWord` type already supports the algorithmic manipulations needed (concatenation, inversion), and the Garside algorithm is a sequence of well-defined rewriting steps on braid words. Formalizing this would give a `DecidableEq` instance on the braid group (as a quotient), which is a strong result. A falsifiable prediction: implementing Garside normalization as a function `BraidWord n → BraidWord n` and proving it is a braid invariant (in the sense of our `BraidInvariant` structure) with the additional property that it is idempotent would solve the word problem for braid groups in Lean.
