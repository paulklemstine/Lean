# Future Directions: Berggren-Tree Lattice Reduction

## 1. Exponential Height Growth and Spectral Gap Constants

The current formalization proves *linear* height growth: `tripleHeight(evalAtRoot w) ≥ 5 + |w|`. 
However, computational evidence shows *exponential* growth: the minimum hypotenuse 
at depth `d` grows roughly as `2^d`. Formalizing this would require:

- **Spectral analysis**: The smallest singular value of each Berggren generator 
  matrix is > 1 (approximately 2.618, the golden ratio squared). Proving this 
  gives `height ≥ λ^d` for some explicit `λ > 1`.
- **Impact**: Exponential growth would give logarithmic-depth pruning — the 
  branch-and-bound search would run in time polynomial in `log(height)` instead 
  of linear.
- **Concrete target**:
  ```lean
  theorem height_exp_lower_bound (w : BerggrenWord) :
    2 ^ w.length ≤ tripleHeight (evalAtRoot w) + C
  ```

## 2. Quantitative Prefix Rigidity with Explicit Constants

The current `prefix_rigidity_exact` theorem states that `geoDist = 0 ↔ same word`. 
The natural quantitative strengthening would bound the common prefix length from 
below in terms of height and distance:

```lean
theorem quantitative_prefix_rigidity :
  ∃ c C : ℕ, c > 0 ∧
  ∀ u v : BerggrenWord,
    c * min (tripleHeight (evalAtRoot u)) (tripleHeight (evalAtRoot v))
    ≤ C * geoDist (evalAtRoot u) (evalAtRoot v) + lcpLength u v + C
```

This requires:
- A **first-letter divergence bound**: when two words start with different 
  generators applied to the same good triple, the L∞ distance is proportional 
  to the triple's height. Proving this needs careful analysis of the 3×3 
  Berggren matrices and their cone-separation properties.
- **Matrix norm estimates** for the difference between generator outputs.

## 3. Recovery from Partial / Noisy Invariants

The current formalization assumes exact triple observation. In cryptographic 
applications, the adversary may only observe:
- The hypotenuse modulo some prime `q`
- A lossy hash of the triple
- The triple with bounded additive noise

**Concrete extensions**:
- `(c mod q, height window)` as public invariant
- Noisy recovery with `geoDist ≤ ε` tolerance
- Tropical coordinates `(v_p(a), v_p(b), v_p(c))` for various primes `p`

```lean
def noisyInvariant (t : Triple) (q : ℕ) : ℤ × ℕ := (t.2.2 % q, tripleHeight t)
```

## 5. Generalization to Other Thin Semigroups

The entire framework should generalize beyond the Berggren tree to:

- **Markov triple tree**: The Markov equation `x² + y² + z² = 3xyz` has a 
  similar ternary tree structure. The analogous freeness and rigidity theorems 
  would connect to Markov number theory and Teichmüller space.
  
- **Continued fraction monoids**: The Stern-Brocot tree and its matrix 
  representation `SL₂(ℤ)` provide another instance where word-length rigidity 
  has number-theoretic significance.
  
- **General thin matrix semigroups**: Any semigroup generated by matrices with 
  entries in ℤ₊ and determinant ±1 where the generators produce disjoint cones 
  should admit analogous prefix rigidity.

```lean
class ThinSemigroup (G : Type) where
  generators : Finset G
  eval : List G → M  -- for some metric space M
  freeness : Function.Injective eval
  height_growth : ∀ w, height (eval w) ≥ |w|
  cone_separation : ∀ g h, g ≠ h → separated (cone g) (cone h)
```

## 6. Certified Lattice Reduction for Berggren-Based Cryptosystems

Extend the pruning theorem to a full lattice-reduction certificate:
- Define the "Berggren lattice" as the image of the evaluation map in ℤ³
- Prove that closest-vector problems in this lattice reduce to shortest-word 
  recovery
- Formalize the complexity of the branch-and-bound search as a function of 
  the noise level ε and target height H

This would provide the first formally verified cryptanalysis of a semigroup-based 
cryptographic construction.
