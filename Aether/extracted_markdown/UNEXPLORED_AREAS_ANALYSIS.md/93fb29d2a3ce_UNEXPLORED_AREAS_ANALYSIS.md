## 1. Generative Audio & Music Synthesis

**Sources:** Ecstasis 1–5, Synesthesia

### 1.1 Synthesis & Timbral Fidelity
- **Wavetable synthesis**: Replacing basic Web Audio API oscillators with wavetable synthesis for studio-quality timbres (identified in Ecstasis 2, 5)
- **Sample-based production**: No sample playback of real instruments; current oscillators produce functional but not studio-quality output (all Ecstasis papers)
- **Analog synthesizer emulation**: Web Audio API cannot match the richness of analog synthesizers (Ecstasis 1, 3)
- **Measured impulse responses**: Algorithmically generated reverb lacks the spatial realism of measured impulse responses (Ecstasis 3)

### 1.2 Compositional Intelligence
- **Long-range structural planning**: No 8-bar build-ups or multi-section arrangement; lacks hierarchical compositional arcs (Ecstasis 2)
- **Hierarchical planning via transformers/RNNs**: Using deep learning for arrangement-level musical structure (Ecstasis 2)
- **Hidden Markov models for melody**: Current Brownian motion melody generation is simplistic (Ecstasis 5)
- **Transformer-based melodic generation**: More sophisticated neural approaches for compelling melodic content (Ecstasis 5)
- **Vocal synthesis**: No vocal or vocal-like content generation across any version; limits genre coverage for vocal trance, future bass, etc. (all Ecstasis papers)
- **Text-to-speech / vocoder integration**: For genre-appropriate vocal elements (Ecstasis 1, 3)

### 1.3 Machine Learning Integration
- **Genre-specific neural networks**: Training on professional productions to improve timbral fidelity (Ecstasis 1, 3, 4, 5)
- **Spectral feature extraction**: Training genre models on spectral features from commercial tracks (Ecstasis 2)
- **MIDI corpus training**: Genre-specific melody and rhythm models (Ecstasis 5)
- **Reinforcement learning from user feedback**: System does not learn or adapt from listener responses (Ecstasis 4)

### 1.4 Spatial & Immersive Audio
- **Ambisonics / 3D spatial audio**: Immersive sound field rendering not implemented (Ecstasis 1, 2, 3, 4, 5)
- **WebXR integration**: Full 3D sound positioning in VR/AR contexts (Ecstasis 2, 4)

### 1.5 Multi-User & Social Systems
- **Collaborative generation**: Multiple users influencing parameters simultaneously (Ecstasis 1, 2, 3, 4, 5)
- **Synchronized collective experiences**: Network-synchronized instances for shared ecstatic states (Ecstasis 3, 4)

### 1.6 Cultural & Genre Authenticity
- **Cultural nuance**: Genre authenticity is parametrically approximated; subtle cultural knowledge embedded in human production is not captured (Ecstasis 1)
- **Genre boundaries**: System covers 17–25 genres but many sub-genres and emerging genres are unaddressed

## 2. Psychedelic Visual Systems & Consciousness Technology

**Sources:** Ecstasis Visual, Ecstasis 3–4, Synesthesia

### 2.1 Hardware & Display
- **VR/HMD integration**: Head-mounted displays for full visual field coverage (Ecstasis Visual, Ecstasis 2)
- **Display dynamic range**: Current displays cannot match natural vision's dynamic range, field-of-view, or resolution (Ecstasis Visual)
- **GPU dependency**: Visual system requires WebGL-capable browser and reasonable GPU (Ecstasis 4)

### 2.2 Biometric Feedback Loops
- **EEG-driven adaptation**: Real-time brainwave monitoring for closed-loop neural state adaptation (Ecstasis Visual, Ecstasis 3, 4, 5)
- **Heart rate / GSR sensors**: Physiological feedback to close the entrainment loop (Ecstasis 1, 4, 5)
- **HRV-driven adaptive parameters**: Neuro-responsive visuals driven by heart rate variability (Ecstasis Visual)
- **Eye tracking**: Foveated rendering and gaze-contingent effects (Ecstasis Visual)

### 2.3 Haptic & Multi-Sensory
- **Haptic integration**: Synchronizing wearable devices for vibrotactile feedback with audio-visual events (Ecstasis 1, Ecstasis Visual)
- **Multi-sensory stimulation**: Beyond audio-visual to include tactile, olfactory dimensions (unexplored)

### 2.4 Advanced Visual Generation
- **GAN-generated textures**: Neural network-generated visual content (Ecstasis Visual)
- **Neural Radiance Fields (NeRFs)**: Photorealistic impossible scenes (Ecstasis Visual)
- **Physical simulation visuals**: Fluid dynamics, particle systems, reaction-diffusion systems for organic textures (Ecstasis 3)

### 2.5 Therapeutic & Clinical
- **Psychedelic-assisted therapy**: Use in therapeutic settings for preparation, integration, or adjunct to sub-threshold dosing (Ecstasis Visual)
- **Clinical validation**: No large-scale perceptual studies validating ecstasis induction claims (Ecstasis 3)
- **Photosensitive epilepsy safety**: Warning systems exist but comprehensive safety protocols are underdeveloped
- **Psychological vulnerability assessment**: Screening for individuals with psychotic disorders or PTSD

### 2.6 Neuroacoustic Limitations
- **Binaural beat efficacy**: Literature shows mixed results; effectiveness varies across individuals and requires headphones (Ecstasis 2, 4, 5)
- **Individual variation**: Hypnotic susceptibility, visual sensitivity, and musical preference vary enormously (Ecstasis Visual)
- **Entrainment ceiling**: Without pharmacological assistance, entrainment effects are subtler and more variable (Ecstasis Visual)
- **No pharmacological equivalence**: System cannot replicate full multi-system neurological effects of psychedelic compounds (Ecstasis Visual)

### 2.7 Engagement & Complexity
- **Adaptive difficulty/complexity**: Real-time complexity adjustment based on detected engagement level (Ecstasis 4)
- **Addiction potential**: Pleasure-optimizing design could create dependency; unexplored mitigation strategies (Ecstasis 3)
- **Autonomous consent**: As altered states deepen, user capacity for ongoing consent diminishes — ethical framework needed (Ecstasis 3)

## 5. Oracle Theory & Idempotent Collapse

**Sources:** IdempotentCollapse 1–2, Cross-Examination, Oracle papers (old), Thinking Machines

### 5.1 Theoretical Foundations
- **P vs NP via idempotent collapse**: Is there an efficient idempotent collapse from problem instances to solutions? (IdempotentCollapse 1)
- **Riemann Hypothesis via fixed points**: Can zeta function non-trivial zeros be characterized as fixed points of an idempotent operator? (IdempotentCollapse 1)
- **Yang-Mills mass gap via RG flow**: Does the RG flow converge to a conformal fixed point with a mass gap? (IdempotentCollapse 1)
- **Idempotent collapse as computational primitive**: Not yet shown whether idempotent collapse can provide computational advantages

### 5.2 Oracle Hierarchies
- **N-potent hierarchy**: Bootstrap dynamics and the n-potent hierarchy explored computationally but not comprehensively formalized
- **Meta-oracle convergence**: Emergent algorithmic paradigms at the intersection of chaos, topology, and hyperdimensional computing — largely speculative
- **Self-learning oracle**: Integer encodings, tropical compression, and idempotent intelligence — no empirical validation
- **Oracle as strange attractor**: Connection between self-reference, compression, and mathematical truth — conceptual framework without rigorous proofs
- **Universal Oracle SAT solver**: Fixed-point theory meets stochastic search — no competitive benchmark results

### 5.3 Applied Oracle Systems
- **Oracle-guided problem solving**: Practical applications of oracle theory to real-world problem solving remain unexplored
- **Oracle team optimization**: Multi-oracle ensemble methods lack formal optimality guarantees
- **Diminishing returns theorem**: Is there a formal bound on when adding more oracles stops helping? (Prediction paper)
