# Polarity Spaces: A Unified Framework for Galois Connections, Topology, and Fixed-Point Theory

## Abstract

We introduce **PolaritySpace**, a mathematical structure consisting of a binary relation R : α → β → Prop between two types. From this single datum, we derive a Galois connection between powersets, closure operators on both sides, a complete lattice of fixed points, and a canonical topology on each type. We prove that the polarity maps become continuous with respect to these induced topologies, that the topology is T₀ when the relation separates points, and that polarity morphisms induce continuous maps. We establish the Knaster-Tarski fixed-point theorem in the setting of polarity-closed sets. All results are formalized in Lean 4 with complete machine-verified proofs.

## 1. Introduction

Galois connections are among the most pervasive structures in mathematics. They appear in:

- **Algebraic geometry**: the correspondence between ideals and algebraic varieties (Zariski topology)
- **Field theory**: the Galois correspondence between subgroups and intermediate fields
- **Formal concept analysis**: the correspondence between objects and attributes
- **Domain theory**: the correspondence between programs and specifications

Despite their ubiquity, the common structure underlying these examples is rarely made explicit at the level of formal verification. In this paper, we introduce the notion of a **polarity space** — a pair of types connected by a binary relation — and systematically develop the theory that flows from this simple definition.

### 1.1 Contributions

1. **Novel structure**: The `PolaritySpace` structure and its systematic theory
2. **Closure operator**: Proof that the composition V ∘ I is a closure operator (extensive, monotone, idempotent)
3. **Moore family**: Polarity-closed sets are closed under arbitrary intersections
4. **Polarity topology**: Construction of a canonical topology from any polarity
5. **Continuity**: Polarity morphisms induce continuous maps
6. **T₀ separation**: The topology is T₀ when the relation separates points
7. **Knaster-Tarski**: Fixed-point theorems for monotone maps on complete lattices and polarity-closed sets
8. **Zariski connection**: The Zariski topology arises as a polarity topology

## 2. Definitions

### 2.1 PolaritySpace

**Definition 2.1.** A *polarity space* is a triple (α, β, R) where α and β are types and R : α → β → Prop is a binary relation.

```
structure PolaritySpace (α : Type u) (β : Type v) where
  rel : α → β → Prop
```

### 2.2 Vanishing and Annihilator Maps

**Definition 2.2.** Given a polarity space P = (α, β, R), the *vanishing map* V : Set β → Set α and *annihilator map* I : Set α → Set β are:

- V(S) = { a ∈ α | ∀ b ∈ S, R(a, b) }
- I(T) = { b ∈ β | ∀ a ∈ T, R(a, b) }

### 2.3 Polarity Closure

**Definition 2.3.** The *polarity closure* cl : Set α → Set α is cl(T) = V(I(T)).

A set T is *polarity-closed* if cl(T) = T.

### 2.4 Polarity Topology

**Definition 2.4.** The *polarity topology* on α is the topology generated by the subbasis { V({b})ᶜ | b ∈ β } of open sets.

### 2.5 Dual Polarity

**Definition 2.5.** The *dual* of a polarity P = (α, β, R) is P* = (β, α, R*) where R*(b, a) = R(a, b).

### 2.6 Polarity Morphism

**Definition 2.6.** A *polarity morphism* from P = (α, β, R) to Q = (α', β', R') is a pair (f : α → α', g : β' → β) such that R(a, g(b')) ↔ R'(f(a), b') for all a, b'.

### 2.7 Spectrum

**Definition 2.7.** The *spectrum* of a polarity P is the set of elements a ∈ α whose annihilator I({a}) is irreducible: it cannot be written as S₁ ∪ S₂ with I({a}) ⊄ Sᵢ for i = 1, 2.

## 3. Main Results

### 3.1 Antitone Galois Connection

**Theorem 3.1** (Galois Connection). *For any polarity space P, the maps V and I satisfy:*
$$T \subseteq V(S) \iff S \subseteq I(T)$$

*Proof.* Both directions are immediate from unfolding the definitions: T ⊆ V(S) means ∀ a ∈ T, ∀ b ∈ S, R(a,b), which is the same as ∀ b ∈ S, ∀ a ∈ T, R(a,b), i.e., S ⊆ I(T). □

**Corollary.** V and I are both antitone: S₁ ⊆ S₂ implies V(S₂) ⊆ V(S₁), and similarly for I.

### 3.2 Closure Operator

**Theorem 3.2** (Closure Operator). *The polarity closure cl = V ∘ I satisfies:*
1. *(Extensiveness)* T ⊆ cl(T)
2. *(Monotonicity)* T₁ ⊆ T₂ implies cl(T₁) ⊆ cl(T₂)
3. *(Idempotence)* cl(cl(T)) = cl(T)

*Proof sketch.*
1. If a ∈ T and b ∈ I(T), then R(a,b) by definition.
2. Composition of two antitone maps.
3. For ⊆: since S ⊆ I(V(S)) for any S (by extensiveness on the β side), taking S = I(T) gives I(T) ⊆ I(V(I(T))), so V(I(V(I(T)))) ⊆ V(I(T)) by antitonicity of V. For ⊇: by extensiveness. □

### PEGB Analysis for Theorem 3.2

**P (Proof):** Complete formal proof in Lean 4, using `Subset.antisymm`, `vanishing_antitone`, and `subset_polarityClosure`.

**E (Example):** Consider the polarity between {1,2,3} and {a,b,c} with R defined by:
- R(1,a), R(1,b), R(2,b), R(2,c), R(3,a), R(3,c)

Then V({a}) = {1,3}, I({1,3}) = {a}, V(I({1,3})) = V({a}) = {1,3}. So {1,3} is polarity-closed. But V(I({1,2})) = V({b}) = {1,2}, showing {1,2} is also polarity-closed with closure {1,2}.

**G (Generalization):** The closure operator works for any relation between any types, not just finite sets. The three properties hold in complete generality.

**B (Boundary):** The polarity closure is NOT a topological closure in general: polarity-closed sets are closed under arbitrary intersections but NOT necessarily under finite unions. This is why we must generate the topology from a subbasis rather than taking polarity-closed sets as the closed sets directly.

### 3.3 Moore Family

**Theorem 3.3** (Moore Family). *Polarity-closed sets are closed under arbitrary intersections. Specifically, if {Tᵢ} is a family of polarity-closed sets, then ⋂ᵢ Tᵢ is polarity-closed.*

*Proof.* If Tᵢ = V(Sᵢ), then ⋂ᵢ V(Sᵢ) = V(⋃ᵢ Sᵢ), which is polarity-closed. □

### 3.4 Topology and Separation

**Theorem 3.4** (Polarity Topology). *For any polarity P, the polarity topology makes every vanishing set V(S) closed.*

*Proof.* V(S) = ⋂_{b∈S} V({b}). Each V({b}) is closed since V({b})ᶜ is in the generating set of open sets. Arbitrary intersections of closed sets are closed. □

**Theorem 3.5** (T₀ Separation). *If the polarity separates points (∀ a₁ a₂, (∀ b, R(a₁,b) ↔ R(a₂,b)) → a₁ = a₂), then the polarity topology is T₀.*

### PEGB Analysis for Theorem 3.5

**P (Proof):** Formal proof using `T0Space.mk`. If a₁ ≠ a₂, find b distinguishing them. V({b}) is a closed set containing one but not the other.

**E (Example):** For the Zariski polarity on ℤ, ideals (n) and (m) with n ≠ m are separated by any element in one but not the other.

**G (Generalization):** The result generalizes to any notion of "separation by probes" — whenever a family of functions separates points, the generated topology is T₀.

**B (Boundary):** T₀ is sharp: the topology is generally NOT T₁ (points are not closed unless they are polarity-closed singletons). In the Zariski topology, the generic point η of an irreducible variety is not closed — its closure is the entire variety.

### 3.5 Knaster-Tarski Fixed-Point Theorems

**Theorem 3.6** (Knaster-Tarski LFP). *Let L be a complete lattice and f : L → L monotone. Then μ = ⨅{x | f(x) ≤ x} satisfies f(μ) = μ, and μ ≤ y for all y with f(y) ≤ y.*

**Theorem 3.7** (Knaster-Tarski GFP). *Let L be a complete lattice and f : L → L monotone. Then ν = ⨆{x | x ≤ f(x)} satisfies f(ν) = ν, and y ≤ ν for all y with y ≤ f(y).*

### PEGB Analysis for Knaster-Tarski

**P (Proof):** Explicit construction. For LFP: f(μ) ≤ μ because f(μ) is a lower bound for {x | f(x) ≤ x}; μ ≤ f(μ) because f(μ) is in {x | f(x) ≤ x}.

**E (Example):** f(x) = x² on [0,1]. The pre-fixed points are {x | x² ≤ x} = [0,1]. The least fixed point is 0 (since f(0) = 0). The greatest fixed point is 1 (since f(1) = 1).

**G (Generalization):** The theorem works on any complete lattice, including the lattice of polarity-closed sets, the lattice of subsets of a set, and the lattice of closed subsets of a topological space.

**B (Boundary):** Monotonicity is essential. The function f(x) = 1-x on [0,1] has the unique fixed point x = 1/2 which is neither ⨅{x | f(x) ≤ x} = 0 nor ⨆{x | x ≤ f(x)} = 1/2. Without monotonicity, the formula fails.

### 3.6 Continuity of Morphisms

**Theorem 3.8** (Morphism Continuity). *A polarity morphism (f,g) from P to Q induces a continuous map f : α → α' between polarity topologies.*

*Proof.* By `continuous_generateFrom`, it suffices to show each generating open set pulls back to an open set. f⁻¹(V_Q({b'})ᶜ) = (f⁻¹(V_Q({b'})))ᶜ = V_P({g(b')})ᶜ by the pullback lemma, which is in the generating set. □

### PEGB Analysis for Theorem 3.8

**P (Proof):** Uses `continuous_generateFrom_iff`, `morphism_pullback_vanishing`, and `GenerateOpen.basic`.

**E (Example):** Ring homomorphisms φ : R → S induce polarity morphisms from the Zariski polarity on S to that on R (via pullback of ideals and pushforward of elements), giving the classical result that Spec is a contravariant functor.

**G (Generalization):** The result extends to morphisms between different types of polarities (not just within the same category), enabling cross-domain transfer.

**B (Boundary):** The morphism condition R_P(a, g(b')) ↔ R_Q(f(a), b') is strict. Weakening to ⇒ gives only continuity of f with respect to finer topologies.

### 3.7 Zariski Connection

**Theorem 3.9** (Zariski as Polarity). *For a commutative ring R, the Zariski polarity (Ideal R, R, ∈) satisfies:*
- V(S) = {I | S ⊆ I} (ideals containing S)
- I(T) = ⋂_{J ∈ T} J (intersection of ideals in T)

### 3.8 Duality

**Theorem 3.10** (Duality Involution). *Duality is an involution: (P*)* = P. Moreover, V for P equals I for P*, and vice versa.*

## 4. Algorithms

### 4.1 Computing Polarity Closure

Given a finite relation R ⊆ α × β represented as a bipartite graph:

```
function PolarityClosure(T, R):
    I_T = {b ∈ β | ∀ a ∈ T, (a,b) ∈ R}    // Annihilator
    V_I_T = {a ∈ α | ∀ b ∈ I_T, (a,b) ∈ R}  // Vanishing
    return V_I_T
```

Time complexity: O(|α| · |β|).

### 4.2 Enumerating All Polarity-Closed Sets

The polarity-closed sets form a complete lattice, enumerable via the "next closure" algorithm (Ganter 1984). Starting from the empty closure cl(∅), each successor is computed by a lexicographic search.

## 5. Conjecture

**Conjecture 5.1** (Spectral Polarity Conjecture). *If P = (α, β, R) is a polarity space such that:*
1. *The polarity separates points of α*
2. *For every finite F ⊆ β, V(F) is compact in the polarity topology*
3. *The polarity-closed sets are closed under finite unions*

*then the polarity topology on α is a spectral space.*

## 6. Discussion

The PolaritySpace framework demonstrates that a remarkable amount of mathematical structure flows from a single binary relation. The key insight is that the interaction between the vanishing and annihilator maps creates self-reinforcing patterns: closures generate lattices, lattices generate topologies, and topologies enable continuity.

The framework also reveals why certain constructions in different areas of mathematics "feel similar": they are literally the same construction applied to different polarities. The Zariski topology, the Galois correspondence, and the hull-kernel topology are all instances of the polarity topology.
