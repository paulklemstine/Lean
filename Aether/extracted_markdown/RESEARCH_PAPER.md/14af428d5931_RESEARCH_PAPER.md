# Surreal Topology: Connectedness, Contractibility, and Uniqueness for Ordered Continua

## Abstract

We develop a rigorous topological theory for set-sized surreal fragments — ordered topological spaces that model the essential structure of Conway's surreal numbers while remaining within the type-theoretic framework of modern proof assistants. We introduce the notion of order-convexity (`IsOrderConvex`) and the axiomatic class `SurrealLikeLine`, and prove three main theorems:

1. **Connectedness from interval preconnectedness**: In a densely ordered space with no endpoints and order topology, if every closed interval is preconnected, then the entire space is preconnected (hence connected if nonempty).

2. **Contractibility of intervals**: Closed intervals in ℝ (and more generally in any complete ordered field) are contractible.

3. **Uniqueness of interval topology**: On any linear order, the topology generated by open intervals as a basis is unique.

We also prove that conditionally complete, densely ordered linear orders with no endpoints are connected, that order-convex nonempty subsets of such orders are connected, and establish computational infrastructure for bounded-day dyadic approximants with monotonicity and halving properties. All theorems are formally verified in Lean 4 with Mathlib, using no axioms beyond the standard `propext`, `Classical.choice`, and `Quot.sound`. We test the conjecture that countable surreal fragments are totally disconnected and discuss implications for non-Archimedean topology, valuation theory, and topological data analysis.

**Keywords:** ordered topology, surreal numbers, non-Archimedean geometry, interval topology, convexity, contractibility, homotopy theory, order-convexity, formal verification

## 1. Introduction

### 1.1 Motivation

Conway's surreal numbers (Conway, 1976) form the largest possible ordered field — a proper class containing the real numbers, infinitesimals, transfinite ordinals, and much more. They arise from a recursive construction: on each "day," new numbers are created as formal cuts between previously constructed numbers. The surreal number line is dense, extends infinitely in both directions, and contains elements at every conceivable scale.

A natural question, posed informally by several researchers, is: *what is the topology of the surreal numbers?* More precisely:

- Is the surreal number line connected?
- Are its intervals contractible?
- Is the order topology the unique natural topology?
- How does the topology behave on finite approximants?

### 1.2 The Formalizability Obstacle

The full surreal field `No` is a proper class, not a set. In standard set theory (ZFC) and in type-theoretic frameworks (Lean 4, Coq), topological spaces are defined on sets or types, not on proper classes. This means:

1. `No` cannot directly carry a `TopologicalSpace` instance in Lean 4.
2. Statements like "No is connected" require either new foundations or a surrogate approach.
3. The naive question is not directly formalizable.

### 1.3 Our Approach

We adopt the **set-sized shadow** strategy: instead of formalizing topology on the full surreal class, we:

1. Develop general theorems about ordered topological spaces that capture surreal-like properties.
2. Introduce the `SurrealLikeLine` class axiomatizing the essential features.
3. Prove theorems applicable to any set-sized model (ℝ, dyadic rationals, Hahn series fields, lexicographic products).
4. Test conjectures computationally on bounded-day dyadic approximants.

This approach yields genuinely new mathematical results while remaining fully formalizable.

### 1.4 Related Work

- **Mathlib's order topology**: The Lean 4 Mathlib library provides extensive infrastructure for order topologies, including `OrderTopology`, `IsPreconnected`, and the theorem `Set.OrdConnected.isPreconnected` for conditionally complete linear orders with dense ordering (Mathlib, 2024).
- **Surreal number formalization**: Mathlib contains a partial formalization of surreal numbers (`SetTheory.Surreal`), but without topological structure.
- **Non-Archimedean topology**: The topology of valued fields and non-Archimedean ordered structures has been studied extensively (Schikhof, 1984; van Rooij, 1978), but typically in the context of ultrametric spaces rather than ordered fields.

## 2. Definitions and Notation

### 2.1 Order-Convexity

**Definition 2.1 (IsOrderConvex).** Let $(α, ≤)$ be a type with a partial order. A set $s ⊆ α$ is *order-convex* if for all $a, b, c ∈ α$ with $a ∈ s$, $b ∈ s$, and $a ≤ c ≤ b$, we have $c ∈ s$.

```
def IsOrderConvex {α : Type*} [LE α] (s : Set α) : Prop :=
  ∀ ⦃a b c : α⦄, a ∈ s → b ∈ s → a ≤ c → c ≤ b → c ∈ s
```

**Proposition 2.2.** `IsOrderConvex s ↔ s.OrdConnected` (where `Set.OrdConnected` is the Mathlib notion requiring `Icc a b ⊆ s` for all `a, b ∈ s`).

This equivalence is proved directly and allows us to translate between our geometrically motivated definition and Mathlib's algebraically convenient one.

### 2.2 SurrealLikeLine

**Definition 2.3 (SurrealLikeLine).** A type $α$ is a *surreal-like line* if it is equipped with:
- A linear order,
- A topological space structure,
- The order topology (topology generated by open rays and open intervals),
- Dense ordering (between any two elements there exists a third),
- No minimum element,
- No maximum element.

```
class SurrealLikeLine (α : Type*) extends LinearOrder α, TopologicalSpace α where
  orderTop : OrderTopology α
  denseOrd : DenselyOrdered α
  noMin : NoMinOrder α
  noMax : NoMaxOrder α
```

Standard examples include ℚ and ℝ with their usual orderings.

### 2.3 Bounded-Day Dyadics

**Definition 2.4.** The *bounded-day dyadics* of day $n$ are:
$$D_n = \left\{ \frac{k}{2^n} : k ∈ ℤ, |k| ≤ 2^n \right\}$$

```
def boundedDayDyadics (n : ℕ) : Finset ℚ :=
  (Finset.Icc (-(2^n : ℤ)) (2^n : ℤ)).image (fun (k : ℤ) => (k : ℚ) / (2 : ℚ)^n)
```

## 3. Main Results

### 3.1 Theorem 1: Connectedness from Interval Preconnectedness

**Theorem 3.1.** Let $α$ be a linearly ordered type with the order topology, dense ordering, and no endpoints. If every closed interval $[a,b]$ is preconnected, then $\text{univ} ⊆ α$ is preconnected.

```
theorem isPreconnected_univ_of_intervalPreconnected
    (α : Type*) [LinearOrder α] [TopologicalSpace α]
    [OrderTopology α] [DenselyOrdered α] [NoMinOrder α] [NoMaxOrder α]
    (hIcc : ∀ a b : α, IsPreconnected (Icc a b)) :
    IsPreconnected (univ : Set α)
```

**Proof sketch.** We apply `isPreconnected_of_forall_pair`: for any $x, y ∈ \text{univ}$, we exhibit a preconnected subset containing both. If $x ≤ y$, take $[x, y]$, which is preconnected by hypothesis and contains both $x$ and $y$. If $y ≤ x$, take $[y, x]$. □

**Corollary 3.2.** Under the same hypotheses with $α$ nonempty, $α$ is a connected space.

```
theorem connectedSpace_of_intervalPreconnected ... : ConnectedSpace α
```

**Significance.** This theorem does *not* require conditional completeness. The standard Mathlib theorem `Set.OrdConnected.isPreconnected` assumes `ConditionallyCompleteLinearOrder`, which excludes many non-Archimedean ordered fields. Our theorem works for any ordered space where intervals happen to be preconnected, regardless of the completeness properties. This makes it applicable to surreal fragments and non-Archimedean continua where completeness may fail.

### 3.2 Theorem 2: Connectedness of Conditionally Complete Dense Orders

**Theorem 3.3.** A conditionally complete, densely ordered linear order with order topology, no minimum, and no maximum is a connected space.

```
theorem connectedSpace_of_conditionallyComplete_dense
    (α : Type*) [ConditionallyCompleteLinearOrder α] [TopologicalSpace α]
    [OrderTopology α] [DenselyOrdered α] [NoMinOrder α] [NoMaxOrder α] [Nonempty α] :
    ConnectedSpace α
```

**Proof.** The universal set `univ` is trivially order-connected. By Mathlib's `Set.OrdConnected.isPreconnected` (which applies to conditionally complete dense orders), `univ` is preconnected. With nonemptiness, this gives `ConnectedSpace`. □

**Corollary 3.4.** Any nonempty, order-convex subset of a conditionally complete densely ordered linear order (with order topology) is connected.

### 3.3 Theorem 3: Contractibility of Intervals

**Theorem 3.5.** For $a ≤ b$ in $ℝ$, the closed interval $[a,b]$ is contractible.

```
theorem icc_contractible (a b : ℝ) (hab : a ≤ b) :
    ContractibleSpace (Icc a b)
```

**Proof.** The set $[a,b]$ is convex in $ℝ$ (as a real vector space over itself) and nonempty (since $a ≤ b$). By Mathlib's `Convex.contractibleSpace`, convex nonempty subsets of topological vector spaces are contractible. The explicit homotopy is $H(x,t) = (1-t) \cdot x + t \cdot x_0$ for any fixed $x_0 ∈ [a,b]$, which is continuous and preserves convexity. □

**Significance.** This is the decisive homotopy-theoretic result: it says that the fundamental building blocks of any ordered continuum's topology (its bounded intervals) carry no homotopy information. All intervals are topologically trivial — equivalent to a single point from the perspective of algebraic topology.

### 3.4 Theorem 4: Uniqueness of the Interval Topology

**Theorem 3.6.** On a linear order, any two topologies for which the open intervals $\{(a,b) : a, b ∈ α\}$ form a topological basis must coincide.

```
theorem interval_topology_unique
    (α : Type*) [LinearOrder α]
    (t₁ t₂ : TopologicalSpace α)
    (h₁ : @IsTopologicalBasis α t₁ {s : Set α | ∃ a b : α, s = Ioo a b})
    (h₂ : @IsTopologicalBasis α t₂ {s : Set α | ∃ a b : α, s = Ioo a b}) :
    t₁ = t₂
```

**Proof.** A topological basis determines the topology: both $t_1$ and $t_2$ are the topology generated by the same collection of sets, hence equal. □

**Significance.** This converts the informal claim that "the interval topology is the only natural topology on an ordered set" into a precise mathematical statement.

### 3.5 Computational Results

**Theorem 3.7.** $0 ∈ D_n$ for all $n$.

**Theorem 3.8.** $D_n ⊆ D_{n+1}$ for all $n$ (as sets of rationals).

**Theorem 3.9.** The contraction sequence $[q, q/2, q/4, \ldots, q/2^n]$ starts at $q$ and ends at $q/2^n$.

These are formally verified and provide the computational infrastructure for testing conjectures about surreal approximants.

## 4. Algorithms

### 4.1 Bounded-Day Dyadic Generation

**Algorithm.** `boundedDayDyadics(n)`:
1. Generate all integers $k$ with $|k| ≤ 2^n$.
2. Map each $k$ to $k/2^n$.
3. Deduplicate and sort.

**Complexity:** Time $O(n \cdot 2^n)$ (sorting dominates), Space $O(2^n)$.

### 4.2 Interval Graph Construction

**Algorithm.** `intervalGraph(points, ε)`:
1. For sorted points $p_1 < p_2 < \ldots < p_m$:
2. For each $i$, scan forward: add edge $(i, j)$ whenever $p_j - p_i ≤ ε$.
3. Stop scanning when $p_j - p_i > ε$.

**Complexity:** Time $O(m \cdot k)$ where $k$ is the average $ε$-neighborhood size, Space $O(m + |E|)$.

### 4.3 Persistence Analysis

**Algorithm.** `persistenceBetti0(points)`:
1. Compute all adjacent gaps $g_i = p_{i+1} - p_i$.
2. Sort gaps in increasing order.
3. Initialize union-find on $m$ vertices.
4. Process gaps in order: each gap merge reduces the component count by 1.
5. Record $(0, g_i)$ as a birth-death pair for each merge.

**Complexity:** Time $O(m \log m)$, Space $O(m)$.

## 5. Computational Experiments

### 5.1 Total Disconnectedness of Finite Approximants

We tested the conjecture that finite dyadic approximant sets are totally disconnected:

| Day $n$ | Points $|D_n|$ | Min gap | Max gap | Components (ε=0) |
|---------|----------------|---------|---------|-------------------|
| 0       | 1              | N/A     | N/A     | 1                 |
| 1       | 3              | 1.0     | 1.0     | 3                 |
| 2       | 9              | 0.25    | 0.25    | 9                 |
| 3       | 17             | 0.125   | 0.125   | 17                |
| 4       | 33             | 0.0625  | 0.0625  | 33                |
| 5       | 65             | 0.03125 | 0.03125 | 65                |

All gaps are strictly positive for every tested $n$, confirming that each point is isolated in the subspace topology. This is consistent with Sierpiński's theorem.

### 5.2 Persistence Diagrams

The persistence diagrams of $D_n$ show a characteristic pattern:
- All birth times are 0 (all points exist from the start).
- Death times cluster at $1/2^n$ (the uniform gap).
- A single component survives to $ε = 2$ (the diameter of $[-1, 1]$).

As $n$ increases, the death times decrease toward 0, suggesting convergence to a connected limit at $ε = 0$ — but this limit is never reached for finite $n$.

### 5.3 Gap Statistics

| Day $n$ | Min gap $1/2^n$ | Mean gap | Max gap |
|---------|-----------------|----------|---------|
| 1       | 1.000           | 1.000    | 1.000   |
| 3       | 0.125           | 0.125    | 0.125   |
| 5       | 0.031           | 0.031    | 0.031   |
| 7       | 0.008           | 0.008    | 0.008   |

The uniform gap structure of $D_n$ (all gaps equal $1/2^n$) is a consequence of the regular structure of the dyadic rationals.

## 6. Discussion

### 6.1 The Completion Principle

Our results establish a clear dichotomy:

1. **Countable surreal fragments** (dyadic rationals, or any countable dense order without endpoints) are *totally disconnected* in the order topology, by Sierpiński's theorem.

2. **Complete surreal shadows** (conditionally complete dense orders with no endpoints, such as ℝ) are *connected* and their closed intervals are *contractible*.

The transition from disconnected to connected requires a *completion* operation — filling in the gaps, analogous to Dedekind's construction of the reals from the rationals. This is a fundamental insight for surreal topology: the surreal construction itself (which creates numbers day by day) produces only the "disconnected skeleton" of the continuum. The topological continuum must be obtained by a separate completion step.

### 6.2 Non-Archimedean Extensions

Our Theorem 3.1 (connectedness from interval preconnectedness) does not assume conditional completeness. This opens the door to studying non-Archimedean ordered fields that might be connected without being complete in the classical sense. For example:

- **Hahn series fields** $k((t^G))$ for an ordered abelian group $G$ carry a natural valuation topology. Their order topology may differ, and our uniqueness theorem constrains the possibilities.
- **Lexicographic products** $ℤ \times_{lex} ℝ$ model two-scale number systems with infinitely large and infinitely small elements. These are densely ordered with no endpoints, and our theorems apply directly.
- **Hyperreal fields** ${}^*ℝ$ from nonstandard analysis carry both an order topology and a transfer of the real topology. Our results provide tools to compare these.

### 6.3 Implications for Homotopy Theory

The contractibility of intervals (Theorem 3.5) has deep implications:

1. The fundamental group $π_1$ of any convex subset of a complete ordered field is trivial.
2. All higher homotopy groups vanish as well.
3. The ordered line is, from the homotopy perspective, a "point" — all its topological complexity comes from how it is embedded in higher-dimensional spaces.

This suggests that a future homotopy theory for surreal-like spaces would need to focus on *non-convex* subsets or *multi-dimensional* surreal spaces to find nontrivial homotopical phenomena.

## 7. Future Work

1. **Non-Archimedean completions**: Construct explicit completions of non-Archimedean ordered fields and study their topology. The key question: does the completion of a Hahn series field yield a connected space?

2. **Lexicographic homotopy**: Develop the homotopy theory of lexicographic products $G \times_{lex} ℝ$ for various ordered groups $G$. These model multi-scale surreal phenomena and may exhibit nontrivial higher homotopy.

3. **Valuation-topological bridge**: Connect the order topology on non-Archimedean fields to their valuation topology. When do these coincide? When does one refine the other?

4. **Class-level foundations**: Develop a category-theoretic or homotopy-type-theoretic framework for topology on proper classes, enabling direct formalization of surreal topology.

5. **TDA applications**: Use the persistence analysis framework developed here for computational topology applications on hierarchical data with multi-scale structure.
