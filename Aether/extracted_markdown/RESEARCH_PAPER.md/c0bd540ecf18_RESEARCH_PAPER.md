# EML Interpolation Theory: Stone-Weierstrass for Exp-Log Networks

## Abstract

We develop the mathematical foundations of **EML (Exponential-Logarithm-Multiply) networks** as function approximators. We introduce the formal grammar `EMLTerm` — an inductive type representing finite compositions of exp, log, addition, and multiplication — equipped with structural complexity measures (width, depth, size). Our main result is the **EML Stone-Weierstrass Theorem**: the subalgebra of continuous functions generated by the identity and exponential is dense in `C(K, ℝ)` for any compact `K ⊆ ℝ`. We prove this by verifying the separation-of-points condition via the injectivity of exp.

Beyond the density theorem, we establish:
- Explicit error bounds for EML approximation of `x²` using a single exponential
- Composition laws for EML terms with depth and width bounds
- A novel complexity measure (`EMLComplexity`) quantifying the transcendental operations needed to approximate a given function
- The result that polynomials have EML complexity zero

All results are formally verified in Lean 4 with Mathlib.

## 1. Introduction

The classical Weierstrass approximation theorem (1885) establishes that polynomials are dense in `C([a,b], ℝ)` under the uniform norm. The Stone-Weierstrass generalization (1937, 1948) characterizes when a subalgebra of continuous functions is dense: it suffices for the algebra to separate points and contain constants.

Modern machine learning relies on **universal approximation theorems** showing that neural networks can approximate any continuous function. These typically use ReLU, sigmoid, or other fixed activation functions. We propose studying networks built from the transcendental operations `exp` and `log` — the fundamental functions of calculus — and prove that these **EML networks** are universal approximators with richer algebraic structure than standard neural networks.

### 1.1 Contributions

1. **EMLTerm**: A formal inductive grammar for EML networks with evaluation semantics, width (transcendental operation count), depth (nesting level), and size measures.

2. **EML Stone-Weierstrass Theorem**: The subalgebra generated by `{id, exp}` in `C(K, ℝ)` is dense for any compact `K ⊆ ℝ`.

3. **Quantitative bounds**: The EML term `2(exp(x) - 1 - x)` approximates `x²` on `[0,1]` with:
   - Non-negative error (overestimate) for `x ≥ 0`
   - Error bounded by `e - 2 ≈ 0.718`
   - Width = 1 (single transcendental operation)

4. **Composition theory**: We prove that composition of EML terms satisfies:
   - `depth(s ∘ t) ≤ depth(s) + depth(t)`
   - `width(s ∘ t) ≤ width(s) + size(s) · width(t)`

5. **EML Complexity**: A novel measure where `emlComplexity(f, ε)` is the minimum width of an EML term achieving uniform `ε`-approximation. We prove polynomials have complexity 0 and the measure is antitone in `ε`.

## 2. The EML Grammar

### Definition 2.1 (EMLTerm)

An EML term is defined inductively:

```
EMLTerm ::= Const(c)    -- constant c ∈ ℝ
           | Proj         -- identity x ↦ x
           | Exp(t)       -- x ↦ exp(t(x))
           | Log(t)       -- x ↦ log(t(x))
           | Add(t₁, t₂)  -- x ↦ t₁(x) + t₂(x)
           | Mul(t₁, t₂)  -- x ↦ t₁(x) · t₂(x)
```

The evaluation semantics `eval : EMLTerm → ℝ → ℝ` is defined by structural recursion. We use Lean's total `Real.log` (returning 0 for non-positive inputs), making evaluation well-defined on all of `ℝ`.

### Definition 2.2 (Complexity Measures)

- **Width** counts transcendental operations (Exp and Log nodes)
- **Depth** measures the longest root-to-leaf path
- **Size** counts total nodes

**Theorem 2.3**: `width(t) ≤ size(t)` and `depth(t) ≤ size(t)` for all `t`.

### Definition 2.4 (Log-free terms)

A term is **log-free** if it contains no `Log` nodes. Log-free terms evaluate to continuous functions on all of `ℝ` (since `exp` is continuous everywhere, unlike `log`).

**Theorem 2.5**: If `t` is log-free, then `eval(t)` is continuous.

## 3. Separation of Points and Density

### 3.1 The EML Subalgebra

**Definition 3.1**: For compact `K ⊆ ℝ`, the EML subalgebra is:

```
emlSubalgebra(K) := Algebra.adjoin ℝ {id_K, exp_K}
```

where `id_K : C(K, ℝ)` is the inclusion and `exp_K : C(K, ℝ)` is `exp` restricted to `K`.

### 3.2 Separation

**Theorem 3.2** (Separation of Points): The EML subalgebra separates points of `K`.

*Proof*: The identity function `id_K` is in the algebra and is injective on `K` (since `K ⊆ ℝ`). For `x ≠ y` in `K`, `id_K(x) = x ≠ y = id_K(y)`. □

**Remark**: We could also use `exp` for separation (since it's injective), but the identity suffices and yields a cleaner proof.

### 3.3 The EML Stone-Weierstrass Theorem

**Theorem 3.3** (EML Stone-Weierstrass): For any compact `K ⊆ ℝ`:

```
(emlSubalgebra K).topologicalClosure = ⊤
```

*Proof*: The EML subalgebra is a unital subalgebra (contains constants via the algebra structure), and separates points by Theorem 3.2. By the Stone-Weierstrass theorem (Mathlib: `ContinuousMap.subalgebra_topologicalClosure_eq_top_of_separatesPoints`), it is dense. □

**Corollary 3.4** (Uniform Approximation): For any `f ∈ C(K, ℝ)` and `ε > 0`, there exists `g` in the EML subalgebra with `‖g - f‖ < ε`.

## 4. Quantitative Approximation

### 4.1 EML Approximation of x²

**Definition 4.1**: The EML term `E_sq := 2 · (Exp(Proj) + (-1) · (1 + Proj))` has:
- `eval(E_sq, x) = 2(exp(x) - 1 - x)`
- Width = 1 (one exponential)
- Depth = 3

**Theorem 4.2** (Non-negativity): For `x ≥ 0`:
```
2(exp(x) - 1 - x) ≥ x²
```

*Proof*: From `exp(x) ≥ 1 + x + x²/2` (Taylor bound, proved via `Real.sum_le_exp_of_nonneg`). □

**Theorem 4.3** (Error bound on [0,1]): For `x ∈ [0, 1]`:
```
0 ≤ 2(exp(x) - 1 - x) - x² ≤ e - 2
```

The overestimate is bounded above by `e - 2 ≈ 0.718`.

### 4.2 PEGB Analysis for Theorem 4.3

- **Proof**: Verified in Lean 4 using `Real.sum_le_exp_of_nonneg` and monotonicity of exp.
- **Example**: At `x = 0.5`: `2(e^0.5 - 1.5) ≈ 0.297`, `0.5² = 0.25`, error ≈ 0.047.
- **Generalization**: For `x ∈ [0, R]`, error ≤ `R² · (e^R - 1 - R - R²/2)/(R²)`.
- **Boundary**: At `x = 0` the error is 0 (exact). At `x = 1`, error = `2(e - 2) - 1 = 2e - 5 ≈ 0.436`.

## 5. Composition Theory

### 5.1 Term Composition

**Definition 5.1**: Composition `s.compose(t)` substitutes `t` for every `Proj` in `s`.

**Theorem 5.2**: `eval(s.compose(t), x) = eval(s, eval(t, x))`.

**Theorem 5.3** (Depth bound): `depth(s.compose(t)) ≤ depth(s) + depth(t)`.

**Theorem 5.4** (Width bound): `width(s.compose(t)) ≤ width(s) + size(s) · width(t)`.

The width bound reflects that each `Proj` node in `s` is replaced by a copy of `t`, each contributing `width(t)` operations.

### 5.2 Iterated Exponentials

**Definition 5.5**: The iterated exponential `iterExp(n)` = `Exp(Exp(...Exp(Proj)...))` (n times).

**Theorem 5.6**: Properties of `iterExp(n)`:
- `eval(iterExp(n), x) = exp^[n](x)` (the n-fold iterate of exp)
- `width(iterExp(n)) = n`
- `depth(iterExp(n)) = n`
- `iterExp(n)` is log-free

**Theorem 5.7**: The iterated exponential is strictly monotone.

**Theorem 5.8**: `exp(exp(x)) > x` for all `x ∈ ℝ`.

**Theorem 5.9**: The sequence `exp^[n](0)` is strictly increasing: `0 < 1 < e < e^e < e^{e^e} < ...`

## 6. EML Complexity

### Definition 6.1 (EML Complexity)

For `f : ℝ → ℝ`, the **EML complexity** at tolerance `ε` on `[a, b]` is:

```
emlComplexity(f, a, b, ε) := inf { width(t) : |eval(t, x) - f(x)| ≤ ε ∀x ∈ [a,b] }
```

### Theorem 6.2 (Polynomial Complexity)

For any polynomial `p` and `ε > 0`: `emlComplexity(p, a, b, ε) = 0`.

*Proof*: Polynomials are finite sums of monomials `c · x^n`. Each monomial `x^n` is an EML term `Mul(Mul(...(Mul(Proj, Proj), Proj)...), Proj)` with width 0. By induction on the polynomial structure. □

### Theorem 6.3 (Antitone property)

If the feasible set at `ε₁` is nonempty and `ε₁ ≤ ε₂`, then:
```
emlComplexity(f, a, b, ε₂) ≤ emlComplexity(f, a, b, ε₁)
```

## 7. Conjectures and Open Problems

### Conjecture 7.1 (Jackson-type rate)

For `f ∈ Lip_α([0,1])`:
```
emlComplexity(f, 0, 1, ε) = O(ε^{-1/α})
```

**Testable prediction**: Compute the optimal EML approximation of `|x - 1/2|` (Lipschitz-1) on `[0,1]` and check whether width grows as `1/ε`.

### Conjecture 7.2 (Depth hierarchy)

There exists a function family `{f_n}` where:
- `emlComplexity(f_n, 0, 1, 1/n) = Ω(n)` at depth 1
- `emlComplexity(f_n, 0, 1, 1/n) = O(log n)` at depth `n`

This would show an exponential depth-width tradeoff.

## 8. Related Work

- **Stone-Weierstrass theorem**: Marshall Stone (1937, 1948). Our contribution applies it to the specific algebra generated by `{id, exp}`.
- **Universal approximation**: Cybenko (1989), Hornik (1991) for neural networks. Our EML framework gives a more algebraically structured alternative.
- **Neural network complexity**: Telgarsky (2016) proved depth-width tradeoffs for ReLU networks. Our EML framework may exhibit analogous tradeoffs.
- **EML functions in the Catalog**: The Catalog contains extensive prior work on EML functions (EMLv17Core, etc.), focusing on the two-variable function `eml(x,y) = exp(x) - log(y)`. Our work extends this to the approximation-theoretic setting.

## 9. Conclusion

We have established that EML networks — compositions of exp, log, +, × — are universal approximators on compact sets, with a formal algebraic and complexity-theoretic framework. The key results are:

1. The EML subalgebra is dense in `C(K, ℝ)` (Stone-Weierstrass)
2. Explicit error bounds for Taylor-based EML approximations
3. Composition bounds linking depth and width to approximation cost
4. A novel complexity measure with proven properties

All results are machine-verified, providing a rigorous foundation for the study of EML networks in approximation theory and machine learning.
