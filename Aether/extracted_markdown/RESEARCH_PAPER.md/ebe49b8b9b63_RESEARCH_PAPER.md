# EML Transcendence Theory: Algebraic Independence and the Schanuel Conjecture

## Abstract

We develop a formal theory of transcendence for numbers generated by the EML function `eml(x, y) = exp(x) - log(y)`, connecting the algebraic structure of EML expressions to deep results in transcendental number theory. We establish the Algebraic Displacement Theorem (transcendental ± algebraic = transcendental), prove that the class of EML numbers forms a ring closed under exp and log, and derive conditional results under Schanuel's conjecture showing that EML values at algebraic inputs are transcendental. Our main results include: (1) a conditional proof that exp(α) is transcendental for any nonzero algebraic α (recovering Hermite-Lindemann from Schanuel), (2) algebraic independence of exp(α) and exp(β) for Q-linearly independent algebraic α, β under Schanuel, (3) a composition theorem showing the EML function acts as a "transcendence pump" under Schanuel, and (4) unconditional lower bounds on the EML diagonal. All results are formalized in Lean 4 with complete machine-verified proofs, extending the existing catalog of EML and Schanuel results.

**Keywords**: Transcendental numbers, Schanuel's conjecture, algebraic independence, EML function, formal verification

## 1. Introduction

### 1.1 Background

The EML (Exponential-Minus-Logarithm) function, defined as `eml(x, y) = exp(x) - log(y)`, was introduced in the EML research program as a fundamental operation combining the exponential and logarithmic functions. Previous work established basic identities, differential properties, and monotonicity results for the EML function (see `EML/EMLv17Core.lean` in the catalog).

Schanuel's conjecture, formulated by Stephen Schanuel in the 1960s, asserts that if z₁, ..., zₙ are Q-linearly independent complex numbers, then the transcendence degree of Q(z₁, ..., zₙ, e^{z₁}, ..., e^{zₙ}) over Q is at least n. This conjecture, if true, would resolve virtually all known open problems in transcendental number theory, including the algebraic independence of e and π.

### 1.2 Our Contributions

We bridge the EML functional theory with transcendental number theory through the following contributions:

1. **Algebraic Displacement Theorem** (unconditional): We prove that transcendental numbers are preserved under algebraic displacement: if α is transcendental and β is algebraic, then α ± β and α · β (for β ≠ 0) are transcendental. This provides the mechanism by which EML inherits transcendence.

2. **EML Number Ring** (unconditional): We prove that the class of EML numbers — real numbers expressible as evaluations of EML expression trees over Q — forms a ring closed under exp and log.

3. **Schanuel Transcendence Transfer** (conditional on Schanuel): Under Schanuel's conjecture, exp(α) is transcendental for any nonzero algebraic α, and pairs (exp(α), exp(β)) are algebraically independent for Q-linearly independent algebraic α, β.

4. **EML Composition Theorem** (conditional on Schanuel): The EML function acts as a "transcendence pump": under Schanuel, if eml(x, y) is algebraic and nonzero, then eml(eml(x, y), z) is transcendental.

5. **EML Diagonal Bounds** (unconditional): emlDiag(z) = exp(z) - log(z) > 0 for all z > 0, with the lower bound exp(z) - z ≤ emlDiag(z).

## 2. Definitions

### 2.1 The EML Function

**Definition 2.1** (EML Function). For x, y ∈ ℝ, `eml(x, y) := exp(x) - log(y)`.

**Definition 2.2** (EML Diagonal). For z ∈ ℝ, `emlDiag(z) := exp(z) - log(z)`.

### 2.2 Schanuel's Conjecture

**Definition 2.3** (Schanuel's Conjecture). For every n ∈ ℕ and every Q-linearly independent tuple z = (z₁, ..., zₙ) ∈ ℂⁿ, there exists an embedding e : Fin n ↪ Fin n ⊕ Fin n such that the composition

  i ↦ Sum.elim z (j ↦ exp(zⱼ)) (e(i))

is algebraically independent over Q.

This formulation is equivalent to the standard "transcendence degree ≥ n" formulation: the embedding selects n algebraically independent elements from the combined tuple (z₁, ..., zₙ, e^{z₁}, ..., e^{zₙ}).

### 2.3 EML Expressions

**Definition 2.4** (EML Expression). An EML expression is an element of the inductive type:
```
inductive EMLExpr : Type where
  | rat : ℚ → EMLExpr
  | add : EMLExpr → EMLExpr → EMLExpr
  | mul : EMLExpr → EMLExpr → EMLExpr
  | neg : EMLExpr → EMLExpr
  | rexp : EMLExpr → EMLExpr
  | rlog : EMLExpr → EMLExpr
```

**Definition 2.5** (EML Number). A real number x is an EML number if there exists an EML expression e with e.eval = x.

**Definition 2.6** (Depth). The depth of an EML expression counts the maximum nesting of transcendental operations:
- depth(rat q) = 0
- depth(add e₁ e₂) = max(depth(e₁), depth(e₂))
- depth(rexp e) = depth(e) + 1
- depth(rlog e) = depth(e) + 1

## 3. Main Results

### 3.1 Algebraic Displacement Theorem

**Theorem 3.1** (Algebraic Displacement). Let α ∈ ℝ be transcendental over Q and β ∈ ℝ be algebraic over Q. Then:
1. α + β is transcendental over Q
2. α - β is transcendental over Q
3. β - α is transcendental over Q
4. If β ≠ 0, then αβ is transcendental over Q

*Proof sketch*. For (1): If α + β were algebraic, then (α + β) - β = α would be algebraic (since algebraic numbers are closed under subtraction), contradicting the transcendence of α. Cases (2)-(4) are similar, using closure of algebraic numbers under addition, subtraction, and multiplication by nonzero algebraic numbers. □

**PEGB Analysis:**
- **P**roof: Complete Lean 4 proof using `IsAlgebraic.sub` and contraposition.
- **E**xample: π + 1 is transcendental (π is transcendental, 1 is algebraic).
- **G**eneralization: Extends to any field extension K/F where the algebraic closure forms a subfield. The proof only uses that algebraic elements form a ring.
- **B**oundary: Breaks down for transcendental + transcendental: e + (-e) = 0 is algebraic.

### 3.2 EML Transcendence Propagation

**Theorem 3.2** (EML Transcendence). If exp(x) is transcendental over Q and log(y) is algebraic over Q, then eml(x, y) is transcendental over Q.

*Proof*. eml(x, y) = exp(x) - log(y) is the difference of a transcendental and an algebraic number. By Theorem 3.1(2), this is transcendental. □

**Corollary 3.3**. If exp(x) is transcendental, then eml(x, 1) is transcendental.

*Proof*. log(1) = 0, which is algebraic. □

### 3.3 EML Number Ring Structure

**Theorem 3.4** (EML Ring). The class of EML numbers satisfies:
1. Every rational number is an EML number
2. EML numbers are closed under +, -, ·, and negation
3. 0 and 1 are EML numbers
4. EML numbers are closed under exp and log
5. The EML function of two EML numbers is an EML number

*Proof*. Each closure property follows from the corresponding constructor of the EMLExpr type:
- rat(q) for rationals
- add(e₁, e₂) for addition
- mul(e₁, e₂) for multiplication
- neg(e) for negation
- rexp(e) for exp
- rlog(e) for log
The EML function eml(x,y) = exp(x) - log(y) combines rexp, rlog, and subtraction. □

**PEGB Analysis:**
- **P**roof: Constructive — each closure property witnesses the EML expression.
- **E**xample: e - log(2) = eml(1, 2) is an EML number.
- **G**eneralization: Could extend to include inverse (1/x) for a field structure, or power (x^y) for a richer class.
- **B**oundary: The ring structure alone does not determine transcendence; algebraic numbers also form a ring.

### 3.4 Depth-Algebraicity Correspondence

**Theorem 3.5** (Depth Zero Algebraicity). Every EML expression of depth 0 evaluates to an algebraic number.

*Proof*. By induction on the expression. Depth 0 means no exp or log operations, so the expression is purely algebraic (built from rationals via +, ·, -). Algebraic numbers are closed under these operations. □

**Theorem 3.6** (Depth One Transcendence, conditional on Schanuel). Under Schanuel's conjecture, if e is a purely algebraic EML expression with e.eval ≠ 0, then exp(e.eval) is transcendental.

*Proof*. e.eval is algebraic by Theorem 3.5. By Schanuel (transferred from ℂ to ℝ), exp at a nonzero algebraic input is transcendental. □

### 3.5 Schanuel Transcendence Transfer

**Theorem 3.7** (Schanuel → Hermite-Lindemann). Under Schanuel's conjecture, for any nonzero algebraic α ∈ ℂ, exp(α) is transcendental.

*Proof*. Take n = 1, z = ![α]. Since α ≠ 0, {α} is Q-linearly independent. Schanuel gives an embedding e : Fin 1 ↪ Fin 1 ⊕ Fin 1 with AlgebraicIndependent Q (i ↦ combined(e(i))). The image e(0) is either Sum.inl 0 (giving α, which is algebraic, contradicting algebraic independence) or Sum.inr 0 (giving exp(α), which must then be transcendental). □

**Theorem 3.8** (Real Schanuel Transfer). Under Schanuel's conjecture, for any nonzero algebraic α ∈ ℝ, exp(α) is transcendental over Q.

*Proof*. Embed α into ℂ via the canonical inclusion ℝ ↪ ℂ. Apply Theorem 3.7 to (α : ℂ). Transfer back via the injective ring homomorphism, preserving algebraicity and transcendence. □

**PEGB Analysis:**
- **P**roof: The proof involves a case analysis on the Schanuel embedding.
- **E**xample: Under Schanuel, exp(1) = e is transcendental (already known unconditionally by Hermite's theorem).
- **G**eneralization: The same technique gives transcendence of exp(α) for α in any algebraically closed subfield.
- **B**oundary: Requires α ≠ 0 (exp(0) = 1 is algebraic). Cannot handle irrational algebraic α without Schanuel.

### 3.6 Algebraic Independence

**Theorem 3.9** (Exponential Pair Independence). Under Schanuel's conjecture, if α, β ∈ ℂ are algebraic and Q-linearly independent, then exp(α) and exp(β) are algebraically independent over Q.

*Proof*. Apply Schanuel with n = 2, z = ![α, β]. Since α, β are Q-linearly independent (by hlin), we get an embedding e : Fin 2 ↪ Fin 2 ⊕ Fin 2 with algebraic independence. Since α, β are algebraic, the embedding must map both elements to the exponential side (Sum.inr), otherwise algebraic independence fails. The injectivity of e ensures the two images are distinct, giving algebraic independence of a permutation of (exp(α), exp(β)). □

**PEGB Analysis:**
- **P**roof: Detailed case analysis on the embedding, using injectivity.
- **E**xample: Under Schanuel, exp(1) and exp(√2) are algebraically independent.
- **G**eneralization: Extends to n-tuples: n Q-linearly independent algebraic numbers have algebraically independent exponentials.
- **B**oundary: The requirement of Q-linear independence is essential: exp(1) and exp(2) = exp(1)² are algebraically dependent (the latter is the square of the former if we allowed 2 = 1+1, but they are Q-linearly independent as exponents, so they ARE independent).

### 3.7 EML Composition Theorem

**Theorem 3.10** (Schanuel EML Composition). Under Schanuel's conjecture, if eml(x, y) is algebraic and nonzero, and log(z) is algebraic, then eml(eml(x, y), z) is transcendental.

*Proof*. Let t = eml(x, y). Since t is algebraic and nonzero, by Theorem 3.8, exp(t) is transcendental. Then eml(t, z) = exp(t) - log(z) is transcendental by Theorem 3.2. □

This theorem reveals the EML function as a "transcendence pump": even starting from an algebraic value, one application of EML produces a transcendental output (assuming Schanuel and log(z) algebraic).

### 3.8 EML Diagonal Bounds

**Theorem 3.11** (Diagonal Positivity). For z > 0, emlDiag(z) > 0.

*Proof*. Using the fundamental inequalities exp(z) ≥ 1 + z and log(z) ≤ z - 1 for z > 0:
emlDiag(z) = exp(z) - log(z) ≥ (1 + z) - (z - 1) = 2 > 0. □

**Theorem 3.12** (Diagonal Lower Bound). For z > 0, exp(z) - z ≤ emlDiag(z).

*Proof*. Equivalently, log(z) ≤ z, which follows from log(z) ≤ z - 1 < z. □

**PEGB Analysis:**
- **P**roof: Direct computation using classical exp/log inequalities.
- **E**xample: emlDiag(1) = e - 0 = e ≈ 2.718 > 0. emlDiag(0.01) ≈ 1.01 - (-4.61) ≈ 5.62.
- **G**eneralization: The bound emlDiag(z) ≥ 2 can likely be sharpened to emlDiag(z) ≥ e - 1 (the minimum, achieved at z = 1).
- **B**oundary: The positivity requires z > 0 strictly. At z = 0, log is undefined; for z < 0, log is undefined in ℝ.

## 4. Cross-Domain Bridge: EML and Information Theory

The EML function has a natural interpretation in information theory. The expression eml(x, y) = exp(x) - log(y) arises in several contexts:

1. **KL Divergence Components**: The KL divergence involves terms of the form p · log(p/q), which can be decomposed into exp and log operations.

2. **Softmax Gradients**: The gradient of the softmax function involves exp(x) - log(Σ exp(xᵢ)), an EML-type expression.

3. **Entropy Bounds**: Shannon entropy H = -Σ pᵢ log(pᵢ) involves logarithmic terms whose exponentials are the original probabilities.

The transcendence results established here imply that, under Schanuel's conjecture, the "natural constants" appearing in information-theoretic computations at rational parameters are transcendental and algebraically independent. This provides a rigorous foundation for the observation that information-theoretic quantities resist exact rational computation.

## 5. Discussion

### 5.1 Relationship to Prior Work

Our formalization of Schanuel's conjecture follows the embedding approach of the catalog's `Algebra/Schanuel/Theorems.lean`, which uses `AlgebraicIndependent` and function embeddings rather than the traditional transcendence degree formulation. This approach has the advantage of being directly usable in inductive proofs.

The key innovation is the transfer from ℂ to ℝ (Theorem 3.8), which allows Schanuel-conditional results to be stated for the real EML function. This transfer requires careful handling of the ring homomorphism ofReal : ℝ → ℂ and the preservation of algebraicity through this map.

### 5.2 Limitations

1. All Schanuel-conditional results depend on an unproven conjecture. If Schanuel's conjecture is false, these results may not hold.

2. The EML expression framework does not include division or arbitrary powers. Extending to a field structure would require handling division by zero.

3. The depth-transcendence correspondence (Theorems 3.5-3.6) does not extend cleanly to depth > 1 without additional hypotheses.

## 6. Algorithms

### 6.1 EML Expression Evaluation

```
function eval(e: EMLExpr) → ℝ:
    match e with
    | rat(q)      → q
    | add(e₁, e₂) → eval(e₁) + eval(e₂)
    | mul(e₁, e₂) → eval(e₁) · eval(e₂)
    | neg(e)      → -eval(e)
    | rexp(e)     → exp(eval(e))
    | rlog(e)     → log(eval(e))
```

### 6.2 Schanuel Embedding Verification

Given z₁, ..., zₙ ∈ ℂ (Q-linearly independent algebraic numbers):

```
function verify_schanuel_embedding(z: Vector(ℂ, n)) → Option(Embedding):
    for each injective e: Fin n → Fin n ⊕ Fin n:
        values := [Sum.elim z (exp ∘ z) (e(i)) for i in Fin n]
        if test_algebraic_independence(values):
            return Some(e)
    return None
```

## 7. Future Work

1. **Unconditional results**: Proving EML transcendence without Schanuel would require either proving Schanuel's conjecture or finding alternative techniques (Baker's method, Gel'fond-Schneider).

2. **Higher-order algebraic independence**: Under Schanuel, proving algebraic independence of n-tuples of EML values for arbitrary n.

3. **EML field structure**: Extending the ring structure to a field by adding inverse operations.

4. **Computational algebraic independence testing**: Implementing efficient algorithms (PSLQ, LLL) for numerical detection of polynomial relations among EML values.
