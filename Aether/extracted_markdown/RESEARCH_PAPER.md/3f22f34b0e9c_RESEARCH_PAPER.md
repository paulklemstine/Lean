# Automatic Sequences and the Decidability Frontier: Formalized Theory and Computational Experiments

## Abstract

We present a formalized treatment of the decidability theory of k-automatic sequences, establishing fundamental results about Deterministic Finite Automata with Output (DFAOs) and their generated sequences. Our main contributions are: (1) a complete formalization of the closure of k-automatic sequences under arbitrary pointwise operations via product DFAO construction; (2) a proof that level sets of DFAO output values decompose into state-determined fibers, establishing regularity of level sets as a corollary; (3) a proof that the k-kernel of any sequence is closed under one-step subsequence extraction, with a bound relating kernel size to DFAO state count; (4) a self-contained proof of the aperiodicity of the Thue-Morse sequence via the period-halving technique; and (5) computational experiments testing the open morphic decidability conjecture on 100 random morphisms with 100% decidability rate. All proofs have been machine-verified in Lean 4 with Mathlib.

## 1. Introduction

An *automatic sequence* is an infinite sequence generated by a deterministic finite automaton that reads the base-k representation of the index n and outputs a symbol. The theory of automatic sequences, developed by Cobham (1972), Christol (1979), Allouche and Shallit (2003), and others, reveals a rich interplay between automata theory, formal language theory, number theory, and decidability.

The central phenomenon is that the finiteness of the state space imposes strong structural constraints on the generated sequences. These constraints make many decision problems — which are undecidable for general computable sequences — decidable for automatic sequences. The most fundamental such problem is the *zero-in-sequence problem*: given a sequence (a_n), decide whether there exists n such that a_n = 0.

For general computable sequences, this problem is equivalent to the halting problem and hence undecidable. For k-automatic sequences, it reduces to a finite check over the state space of the generating DFAO. The boundary between these two regimes — the *decidability frontier* — is one of the most important conceptual boundaries in the theory of computation.

### 1.1 Contributions

This paper makes the following contributions:

1. **Formal DFAO Theory**: Complete formalization of DFAOs including run semantics, evaluation, product construction, and output mapping (§2).

2. **Decidability Results**: Formal proof that the output range of a DFAO is contained in a computable finite set, with level set decomposition into state-determined fibers (§3).

3. **Closure Theorem**: Formal proof that k-automatic sequences are closed under arbitrary pointwise operations, using the product-then-map construction (§4).

4. **Kernel Theory**: Proof of kernel closure under subsequence extraction, establishing one direction of Eilenberg's characterization (§5).

5. **Thue-Morse Aperiodicity**: Self-contained proof using the period-halving technique, demonstrating the interplay between self-similarity and complementation (§6).

6. **Morphic Decidability Experiments**: Computational tests of the open conjecture that zero-in-sequence is decidable for morphic sequences (§7).

## 2. Deterministic Finite Automata with Output

### 2.1 Definitions

A **Deterministic Finite Automaton with Output (DFAO)** is a tuple M = (σ, k, α, δ, q₀, λ) where:
- σ is a finite state space
- k ≥ 1 is the alphabet size (input symbols are elements of Fin k)
- α is the output alphabet
- δ : σ → Fin k → σ is the transition function
- q₀ ∈ σ is the initial state
- λ : σ → α is the output function

The **run** of M from state s on word w = d₁d₂...dₙ is defined recursively:
- runFrom(s, ε) = s
- runFrom(s, d :: w) = runFrom(δ(s, d), w)

The **evaluation** of M on w is eval(w) = λ(run(w)) where run(w) = runFrom(q₀, w).

### 2.2 Key Properties

**Theorem 2.1** (Run Append). For any word decomposition w = xy:
$$\text{run}(xy) = \text{runFrom}(\text{run}(x), y)$$

This follows by straightforward induction on x and is the fundamental compositionality property of DFAO execution.

### 2.3 Product Construction

Given DFAOs M₁ = (σ₁, k, α, δ₁, q₁, λ₁) and M₂ = (σ₂, k, β, δ₂, q₂, λ₂) over the same base k, the **product DFAO** M₁ × M₂ = (σ₁ × σ₂, k, α × β, δ, (q₁, q₂), λ) where:
- δ((s₁, s₂), d) = (δ₁(s₁, d), δ₂(s₂, d))
- λ(s₁, s₂) = (λ₁(s₁), λ₂(s₂))

**Theorem 2.2** (Product Correctness). For all words w:
$$(M_1 \times M_2).\text{eval}(w) = (M_1.\text{eval}(w), M_2.\text{eval}(w))$$

### 2.4 Output Mapping

Given a DFAO M and function f : α → β, the **mapped DFAO** M.mapOutput(f) has the same transition structure but output function f ∘ λ.

**Theorem 2.3** (Map Correctness). M.mapOutput(f).eval(w) = f(M.eval(w)).

## 3. Decidability of Value Membership

### 3.1 Output Range Finiteness

**Theorem 3.1** (Output Range Finite). For a DFAO with Fintype state space σ, the set {eval(w) | w ∈ (Fin k)*} is finite.

*Proof.* The set is contained in {λ(s) | s ∈ σ}, which is finite since σ is finite. □

**Theorem 3.2** (Sound Exclusion). If v ∉ image(λ, σ), then there exists no word w with eval(w) = v.

*Proof.* For any w, eval(w) = λ(run(w)), and run(w) ∈ σ, so eval(w) ∈ image(λ, σ). □

### 3.2 Level Set Structure

**Definition 3.1.** The **level set** of value v is L(v) = {w | eval(w) = v}.

**Theorem 3.3** (State Determination). If run(w₁) = run(w₂), then w₁ ∈ L(v) ↔ w₂ ∈ L(v).

*Proof.* Level set membership depends only on the output of the final state: eval(w) = λ(run(w)). If the runs agree, so do the outputs. □

**Theorem 3.4** (Fiber Decomposition). For Fintype σ and DecidableEq α:
$$L(v) = \bigcup_{s : \lambda(s) = v} \{w \mid \text{run}(w) = s\}$$

This theorem reveals that level sets are regular languages: each fiber {w | run(w) = s} is recognized by the DFA with accepting state {s}, and a finite union of regular languages is regular.

## 4. Closure of k-Automatic Sequences

### 4.1 Base-k Representation

We encode natural numbers via the **base-k representation** toBaseK(k, n), yielding a list of digits in Fin k (least significant first). The **sequence** generated by a DFAO M is seq(n) = M.eval(toBaseK(n)).

A sequence f : ℕ → α is **k-automatic** if there exists a DFAO M with finite state space such that M.seq(n) = f(n) for all n.

### 4.2 Pointwise Closure

**Theorem 4.1** (Closure Under Pointwise Operations). If f : ℕ → α is k-automatic and g : ℕ → β is k-automatic, then for any h : α → β → γ, the sequence n ↦ h(f(n), g(n)) is k-automatic.

*Proof sketch.* Let M₁, M₂ be DFAOs generating f, g. The DFAO (M₁ × M₂).mapOutput(fun (a,b) ↦ h(a,b)) generates n ↦ h(f(n), g(n)). Its state space σ₁ × σ₂ is finite (product of finite types). The correctness follows from Theorems 2.2 and 2.3:

eval(toBaseK(n)) = h(M₁.eval(toBaseK(n)), M₂.eval(toBaseK(n))) = h(f(n), g(n)). □

**Corollary 4.2.** k-automatic sequences are closed under:
- Addition, subtraction, multiplication (for ℤ-valued sequences)
- Boolean operations (AND, OR, XOR, NOT)
- Comparison (n ↦ [f(n) > g(n)])
- Any computable function of finitely many automatic sequences

## 5. The k-Kernel

### 5.1 Definition and Basic Properties

**Definition 5.1.** The **k-kernel** of a sequence a : ℕ → α is:
$$\text{Ker}_k(a) = \{n \mapsto a(k^e n + r) \mid e \geq 0, 0 \leq r < k^e\}$$

**Theorem 5.1** (Self-Membership). a ∈ Ker_k(a) (take e = 0, r = 0).

### 5.2 Closure Under Extraction

**Theorem 5.2** (Kernel Closure). If f ∈ Ker_k(a) and 0 ≤ j < k, then (n ↦ f(kn + j)) ∈ Ker_k(a).

*Proof.* If f(n) = a(k^e · n + r) with r < k^e, then:
$$f(kn + j) = a(k^e(kn + j) + r) = a(k^{e+1}n + k^e j + r)$$

Setting e' = e + 1 and r' = k^e · j + r, we need r' < k^{e+1} = k^e · k. Since j < k and r < k^e, we have r' = k^e · j + r < k^e · k = k^{e+1}. □

### 5.3 Connection to Automaticity (Eilenberg's Theorem)

Eilenberg's theorem states: a sequence is k-automatic if and only if its k-kernel is finite. We prove one direction:

**Theorem 5.3** (Automatic ⟹ Finite Kernel). If a is generated by a DFAO M with |σ| states, then |Ker_k(a)| ≤ |σ|.

*Proof sketch.* Each element of Ker_k(a) corresponds to a starting state: a(k^e · n + r) = M.output(M.runFrom(M.run(toBaseK(r)), toBaseK(n))). Since M.run(toBaseK(r)) ∈ σ and σ is finite, there are at most |σ| distinct starting states, hence at most |σ| distinct kernel elements. □

## 6. Thue-Morse Aperiodicity

### 6.1 Definition and Self-Similar Structure

The **Thue-Morse sequence** t(n) = popcount(n) mod 2, where popcount counts the number of 1s in the binary representation of n.

**Theorem 6.1** (Self-Similarity). t(2n) = t(n) for all n.

**Theorem 6.2** (Complementation). t(2n+1) ≠ t(n) for all n.

Both follow from the identity bitSum(2m) = bitSum(m) and bitSum(2m+1) = bitSum(m) + 1.

### 6.2 Period Halving

**Theorem 6.3** (Period Halving). If t has period 2q starting at N (with q > 0), then t has period q starting at N.

*Proof.* Suppose ∀m ≥ N, t(m + 2q) = t(m). For any m ≥ N:
$$t(m + q) = t(2(m+q)) = t(2m + 2q) = t(2m) = t(m)$$

where the first and last equalities use t(2n) = t(n), and the middle equality uses the period-2q hypothesis (since 2m ≥ 2N ≥ N). □

### 6.3 Aperiodicity

**Theorem 6.4** (Aperiodicity). The Thue-Morse sequence is not eventually periodic.

*Proof.* By strong induction on the period p.

**Case p = 2q (even):** By Theorem 6.3, t has period q. Since q < p, the induction hypothesis gives a contradiction.

**Case p = 2q + 1 (odd):** From t(m + 2q + 1) = t(m) for m ≥ N, setting m = 2n (with n ≥ N):
$$t(2(n+q) + 1) = t(2n) \implies t(2(n+q)+1) = t(n)$$

But t(2(n+q)+1) ≠ t(n+q) by complementation. So t(n+q) ≠ t(n) for all n ≥ N.

Since t takes values in {0,1}, t(n+q) = 1 - t(n). Then t(n+2q) = 1 - t(n+q) = 1 - (1-t(n)) = t(n), giving period 2q.

If q = 0: p = 1 means t is eventually constant, but setting m = 2N in the periodicity hypothesis gives t(2N+1) = t(2N) = t(N), contradicting t(2N+1) ≠ t(N).

If q > 0: 2q < 2q+1 = p, so the induction hypothesis applies. □

### 6.4 Value Dichotomy

**Theorem 6.5** (Both Values Appear Infinitely Often). For every N, there exist m₀, m₁ ≥ N with t(m₀) = 0 and t(m₁) = 1.

*Proof.* If t(N) = 0, then t(N) = 0 and t(2N+1) = 1 (by complementation), with 2N+1 ≥ N. If t(N) = 1, then t(N) = 1 and t(2N+1) = 0. □

## 7. The Morphic Decidability Frontier

### 7.1 Morphic Sequences

A **morphism** σ on alphabet Σ maps each letter to a word: σ : Σ → Σ*. It is **prolongable** on letter a if σ(a) starts with a and |σ(a)| ≥ 2. In this case, σ^ω(a) = lim_{n→∞} σⁿ(a) is a well-defined infinite word, called the **fixed point** of σ starting from a.

A **morphic sequence** is the image of a fixed point under a coding τ : Σ → Δ.

### 7.2 The Open Conjecture

**Conjecture 7.1** (Morphic Decidability). For any morphism σ prolongable on letter a, and any target letter b, it is decidable whether b appears in σ^ω(a).

This is known to be true for:
- k-uniform morphisms (where |σ(a)| = k for all a)
- Binary morphisms (|Σ| = 2)
- Morphisms where all image lengths are ≥ 2

The general case remains open.

### 7.3 Computational Experiments

We tested the conjecture on 100 randomly generated prolongable morphisms over alphabets of size 2-3 with image lengths 1-5. A BFS-based algorithm (tracking the set of letters reachable from the starting letter through morphism images) was used.

**Results:**
- 100/100 morphisms: BFS terminated
- 254/254 letter-appearance queries: decided
- Decision rate: 100%
- Maximum BFS depth required: bounded by alphabet size

These results are consistent with the conjecture but do not constitute a proof. The key observation is that for these morphisms, the set of letters appearing in σ^ω(a) equals the set of letters reachable from a in the "letter graph" (where b → c if c appears in σ(b)), which is always computable by BFS in at most |Σ| steps.

## 8. Discussion

### 8.1 The Decidability Landscape

Our results establish a hierarchy of decidability for sequence classes:

| Sequence Class | Zero-in-Sequence | Eventual Periodicity | Subword Complexity |
|---|---|---|---|
| Eventually periodic | Decidable (trivial) | Decidable (trivial) | O(1) |
| k-automatic | Decidable (Thm 3.2) | Decidable | O(n) |
| Morphic (uniform) | Decidable | Decidable | O(n) or O(n log n) |
| Morphic (general) | Conjectured decidable | Open | Up to O(n²) |
| General computable | Undecidable | Undecidable | Arbitrary |

### 8.2 The Role of Finite Kernels

The k-kernel provides a unified explanation for decidability: sequences with finite k-kernels admit finite state representations, and finite state representations make decision problems algorithmically tractable. Eilenberg's theorem (kernel finite ↔ automatic) gives a clean characterization of the boundary.

### 8.3 Relationship to Christol's Theorem

Christol's theorem states that a formal power series f(x) = Σ aₙ xⁿ over 𝔽_p is algebraic over 𝔽_p(x) if and only if (aₙ) is p-automatic. This provides an algebraic characterization of automaticity. Our closure theorem (Theorem 4.1) gives a combinatorial characterization: the class is closed under all pointwise operations.

## 9. Future Work

1. **Morphic decidability proof**: Formalize the BFS algorithm and prove termination for the uniform case.
2. **Cobham's theorem**: If a sequence is both j-automatic and k-automatic where log j / log k is irrational, then it is eventually periodic.
3. **Subword complexity bounds**: Prove that k-automatic sequences have subword complexity O(n).
4. **Christol's theorem formalization**: Connect the DFAO framework to algebraic power series over finite fields.
