## Lean 4 Formalizations (All Machine-Verified, Zero Sorry)

### New Theorems Proved

**1. LYM Inequality & Sperner's Theorem** (`New/New__LYMInequality.lean`)
- **LYM inequality**: For any antichain 𝒜 in 2^[n], ∑_{A∈𝒜} 1/C(n,|A|) ≤ 1
- **Sperner's theorem**: The largest antichain has size C(n, ⌊n/2⌋)
- Proof uses permutation counting (Lubell's argument), fully formalized

**2. Stern-Brocot Tree** (`New/New__SternBrocot.lean`)
- Tree construction via mediants with path-based navigation
- **Adjacency invariant**: bc - ad = 1 preserved through all paths (by induction)
- Mediant adjacency for both left and right children
- Denominator positivity for all nodes

**3. Kolmogorov Complexity** (`New/New__KolmogorovComplexity.lean`)
- Description methods, complexity measures, universality
- **Invariance theorem**: Universal description methods are optimal (K independent of UTM up to constant)
- **Trivial upper bound**: K(x) ≤ |x| + c
- **Incompressibility**: For every n, incompressible strings of length n exist (counting argument)

All proofs use only standard axioms (propext, Classical.choice, Quot.sound) — verified via `#print axioms`.
