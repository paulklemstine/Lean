# Gravitational Factoring on Pythagorean k-Tuple Trees: A Geometric Framework for Integer Factoring

---

**Abstract.** We introduce *gravitational factoring*, a framework that reinterprets the integer factoring problem as navigation on the tree of Pythagorean k-tuples. A Pythagorean k-tuple $(x_1, x_2, \ldots, x_k, d)$ satisfies $\sum_{i=1}^k x_i^2 = d^2$, and the set of all primitive k-tuples forms a tree under natural descent operators. We define an *energy functional* whose minima correspond to factorizations of a target semiprime $N = p \cdot q$, and study *gravitational descent*—tree traversal guided by this energy—as a factoring strategy. We prove that each k-tuple yields $k$ independent *peel channels* and $\binom{k}{2}$ *cross-collision channels*, giving $k(k+1)/2$ independent GCD-based factor extraction opportunities. At the Cayley–Dickson dimensions $k = 2, 4, 8$ (corresponding to the complex numbers, quaternions, and octonions), the sum-of-squares function is multiplicative, enabling *norm-algebraic factoring* that directly connects quaternion/octonion decomposition to integer factoring. We formalize these results in the Lean 4 proof assistant and provide computational demonstrations.

**Keywords:** integer factoring, Pythagorean quadruples, k-tuples, quaternion norm, octonion, sum of squares, GCD cascade, tree traversal, Lean formalization

---

## 1. Introduction

The integer factoring problem—given a composite $N$, find nontrivial factors—remains one of the most important open problems in computational number theory. Its presumed hardness underpins RSA and related cryptosystems. Modern factoring algorithms (the general number field sieve, elliptic curve method, quadratic sieve) operate on algebraic-analytic principles. We propose a geometric alternative.

### 1.1 The Core Idea

Every positive integer $d$ has representations as a sum of $k$ squares for $k \geq 4$ (by Lagrange's theorem for $k = 4$). These representations are integer points on the $(k-1)$-sphere $S^{k-1}(d)$ of radius $d$. The key observation is:

> **Peel Identity.** If $x_1^2 + x_2^2 + \cdots + x_k^2 = d^2$, then for each $j$:
> $$(d - x_j)(d + x_j) = \sum_{i \neq j} x_i^2$$
> This gives a factorization of $\sum_{i \neq j} x_i^2$ as a product of two integers whose GCD with $N$ may reveal factors.

When the hypotenuse $d$ is chosen as the target $N$ itself (or a multiple/power of $N$), the peel channels produce candidate factors via:
$$\gcd(d - x_j, N) \quad \text{and} \quad \gcd(d + x_j, N)$$

If any of these GCDs is nontrivial (strictly between 1 and $N$), we have factored $N$.

### 1.2 The Tree Structure

Pythagorean triples ($k = 2$: $a^2 + b^2 = c^2$) are generated by the Berggren tree, a ternary tree rooted at $(3, 4, 5)$. For $k = 3$ (quadruples: $a^2 + b^2 + c^2 = d^2$), the tree structure is richer—generated by matrix actions on roots like $(0, 0, 1, 1)$ and $(1, 2, 2, 3)$.

We define *gravitational descent* as the process of moving from a node toward the root (decreasing the hypotenuse $d$), and *energy ascent* as moving away from the root. The *factoring energy* $E(x_1, \ldots, x_k, d, N)$ measures how close a k-tuple is to revealing a factor of $N$:

$$E = \min_j \left\{ \min\left( (d - x_j) \bmod N, \, (d + x_j) \bmod N \right) \right\}$$

Factoring corresponds to finding a state with $E = 0$.

### 1.3 Contributions

1. **The Dimensional Advantage Theorem** (§3): k-tuples yield $k(k+1)/2$ factoring channels, growing quadratically with dimension.

2. **The Cayley–Dickson Multiplicativity Theorem** (§4): At dimensions $k = 2, 4, 8$, the norm function is multiplicative, enabling direct algebraic factoring.

3. **The Euler Four-Square Identity and Factoring** (§5): Explicit connection between quaternion algebra and integer factoring.

4. **The Cross-Collision Theorem** (§6): Two k-tuples sharing a hypotenuse generate difference-of-sums equations that yield additional factoring channels.

5. **Gravitational Descent Algorithm** (§7): A tree-traversal factoring algorithm with modular navigation heuristics.

6. **Lean 4 Formalization** (§8): Machine-verified proofs of the core theorems.

7. **Computational Demonstrations** (§9): Python implementations demonstrating all methods.

## 2. Preliminaries

### 2.1 Pythagorean k-Tuples

**Definition 2.1.** A *Pythagorean k-tuple* is a tuple $(x_1, x_2, \ldots, x_k, d) \in \mathbb{Z}^{k+1}$ satisfying:
$$x_1^2 + x_2^2 + \cdots + x_k^2 = d^2$$

It is *primitive* if $\gcd(x_1, x_2, \ldots, x_k, d) = 1$.

**Special cases:**
- $k = 2$: Pythagorean triples ($a^2 + b^2 = c^2$)
- $k = 3$: Pythagorean quadruples ($a^2 + b^2 + c^2 = d^2$)
- $k = 4$: Pythagorean quintuples, connected to quaternion norms
- $k = 8$: Pythagorean 9-tuples, connected to octonion norms

### 2.2 The Root Nodes

For $k = 3$, the fundamental root nodes are:
- $(0, 0, 1, 1)$: the degenerate root
- $(1, 2, 2, 3)$: the smallest primitive quadruple
- $(2, 3, 6, 7)$: the second primitive quadruple

### 2.3 The Energy Functional

**Definition 2.2.** The *Pythagorean energy* of a tuple $(x_1, \ldots, x_k, d)$ is:
$$E_{\text{pyth}}(x_1, \ldots, x_k, d) = \sum_{i=1}^k x_i^2 - d^2$$

A tuple is Pythagorean if and only if $E_{\text{pyth}} = 0$.

**Definition 2.3.** The *factoring energy* with respect to target $N$ is:
$$E_{\text{fact}}(x_1, \ldots, x_k, d, N) = \min_j \left\{ \min(\gcd(d - x_j, N), \gcd(d + x_j, N)) - 1 \right\}$$

Values $\leq 0$ indicate a nontrivial GCD has been found.

## 3. The Dimensional Advantage Theorem

### 3.1 Peel Channels

**Theorem 3.1** (Peel Channel Identity). *For any Pythagorean k-tuple $(x_1, \ldots, x_k, d)$ and any index $j \in \{1, \ldots, k\}$:*
$$(d - x_j)(d + x_j) = \sum_{i \neq j} x_i^2$$

*Proof.* $(d - x_j)(d + x_j) = d^2 - x_j^2 = \sum_i x_i^2 - x_j^2 = \sum_{i \neq j} x_i^2$. ∎

Each peel channel yields two GCD computations: $\gcd(d - x_j, N)$ and $\gcd(d + x_j, N)$.

### 3.2 Cross-Collision Channels

**Theorem 3.2** (Cross-Collision). *If two k-tuples $(a_1, \ldots, a_k, d)$ and $(b_1, \ldots, b_k, d)$ share the same hypotenuse $d$, then for any index $i$:*
$$a_i^2 - b_i^2 = \sum_{j \neq i} (b_j^2 - a_j^2)$$

*and each difference $a_i^2 - b_i^2 = (a_i - b_i)(a_i + b_i)$ yields two more GCD channels.*

### 3.3 Total Channel Count

**Theorem 3.3** (Dimensional Advantage). *A k-tuple provides $k$ peel channels. Two k-tuples with shared hypotenuse provide $\binom{k}{2}$ cross-collision channels. The total factoring channel count is:*
$$\mathcal{C}(k) = k + \binom{k}{2} = \frac{k(k+1)}{2}$$

| k | Name | Peel | Cross | Total | Algebra |
|---|------|------|-------|-------|---------|
| 2 | Triple | 2 | 1 | 3 | ℂ (Gaussian) |
| 3 | Quadruple | 3 | 3 | 6 | — |
| 4 | Quintuple | 4 | 6 | 10 | ℍ (Quaternion) |
| 5 | Sextuple | 5 | 10 | 15 | — |
| 8 | 9-tuple | 8 | 28 | 36 | 𝕆 (Octonion) |

*Proof.* The peel channel count is $|\{1, \ldots, k\}| = k$. The cross-collision count is $\binom{k}{2}$ (choosing 2 indices from $k$). Their sum is $k + k(k-1)/2 = k(k+1)/2$. ∎

## 4. The Cayley–Dickson Multiplicativity Theorem

### 4.1 Sum-of-Squares Multiplicativity

The crucial distinction between "general" dimensions and the *Cayley–Dickson dimensions* $k \in \{1, 2, 4, 8\}$ is:

**Theorem 4.1** (Pfister/Hurwitz). *The function $S_k(x) = \sum_{i=1}^k x_i^2$ satisfies the identity:*
$$S_k(x) \cdot S_k(y) = S_k(z)$$
*where $z$ is a bilinear function of $x$ and $y$, if and only if $k \in \{1, 2, 4, 8\}$.*

These correspond to the four normed division algebras: $\mathbb{R}$ ($k=1$), $\mathbb{C}$ ($k=2$), $\mathbb{H}$ ($k=4$), $\mathbb{O}$ ($k=8$).

### 4.2 Consequences for Factoring

At Cayley–Dickson dimensions, if $N = p \cdot q$ and we have:
- $p = \sum_{i=1}^k a_i^2$ (decomposition of $p$)
- $q = \sum_{i=1}^k b_i^2$ (decomposition of $q$)

Then the multiplicative identity gives $N = \sum_{i=1}^k c_i^2$ where each $c_i$ is a bilinear combination of the $a_i$ and $b_i$. The *factoring reverse problem* is: given the $c_i$ (a decomposition of $N$), recover the $a_i$ and $b_i$ (decompositions of $p$ and $q$).

**Theorem 4.2** (Norm Algebraic Factoring). *At Cayley–Dickson dimensions, the factoring problem is equivalent to factoring in the corresponding integer algebra (Gaussian integers, Hurwitz quaternions, or Cayley integers). GCD computations on the bilinear combinations $c_i$ yield candidate factors of $N$.*

## 5. The Euler Four-Square Identity and Quaternion Factoring

### 5.1 The Identity

**Theorem 5.1** (Euler, 1748). *For any integers $a_1, b_1, c_1, d_1, a_2, b_2, c_2, d_2$:*

$$(a_1^2 + b_1^2 + c_1^2 + d_1^2)(a_2^2 + b_2^2 + c_2^2 + d_2^2) = A^2 + B^2 + C^2 + D^2$$

*where:*
$$A = a_1 a_2 + b_1 b_2 + c_1 c_2 + d_1 d_2$$
$$B = a_1 b_2 - b_1 a_2 + c_1 d_2 - d_1 c_2$$
$$C = a_1 c_2 - c_1 a_2 + d_1 b_2 - b_1 d_2$$
$$D = a_1 d_2 - d_1 a_2 + b_1 c_2 - c_1 b_2$$

### 5.2 Factoring Application

Given $N = p \cdot q$ and $N = A^2 + B^2 + C^2 + D^2$ (by Lagrange's four-square theorem):

1. Compute $\gcd(A, N)$, $\gcd(B, N)$, $\gcd(C, N)$, $\gcd(D, N)$
2. Compute $\gcd(A \pm B, N)$, $\gcd(A \pm C, N)$, etc.
3. If any GCD is nontrivial, we have factored $N$.

The key insight: different decompositions of $N$ as a sum of 4 squares correspond to different quaternion factorizations, and their GCD provides a "fingerprint" of the prime factors.

### 5.3 Multiple Representations

**Theorem 5.3** (Jacobi). *The number of representations of $n$ as a sum of 4 squares is:*
$$r_4(n) = 8 \sum_{\substack{d \mid n \\ 4 \nmid d}} d$$

For a semiprime $N = pq$ with odd primes $p, q$:
$$r_4(N) = 8(1 + p + q + pq) = 8(1+p)(1+q)$$

This gives $\Theta(N)$ representations, providing a rich search space for factoring-revealing decompositions.

## 6. The Cross-Collision Theorem

### 6.1 Shared Hypotenuse Collisions

**Theorem 6.1.** *If $a_1^2 + b_1^2 + c_1^2 = d^2$ and $a_2^2 + b_2^2 + c_2^2 = d^2$, then:*
$$(a_1 - a_2)(a_1 + a_2) = (b_2^2 - b_1^2) + (c_2^2 - c_1^2)$$

*If $d$ is related to $N$ (e.g., $d = N$ or $N \mid d$), then $\gcd(a_1 \pm a_2, N)$ are candidate factors.*

### 6.2 The Information-Theoretic Advantage

Each shared-hypotenuse collision produces a new system of equations in the legs. For $m$ representations with the same hypotenuse, we get $\binom{m}{2}$ collision pairs, each producing $k$ difference equations. The total information grows as $O(m^2 k)$.

**Corollary 6.2.** *For primes $p \equiv 1 \pmod{4}$, we have $r_2(p) = 8$, giving 4 essentially different Pythagorean representations. These produce $\binom{4}{2} = 6$ collision pairs, each with 2 difference equations, for 12 GCD computations.*

## 7. Gravitational Descent Algorithm

### 7.1 Algorithm Overview

```
GRAVITATIONAL-FACTOR(N):
  1. Choose dimension k (recommend k = 4 for quaternion multiplicativity)
  2. Generate k-tuples with hypotenuse d = N or d dividing a power of N
  3. For each k-tuple, compute all peel channel GCDs
  4. If nontrivial GCD found, return factor
  5. Find pairs with shared hypotenuse, compute cross-collision GCDs
  6. If no factor found, use modular navigation to refine search
```

### 7.2 Modular Navigation

The key heuristic: we want $x_j \equiv d \pmod{p}$ for unknown prime $p \mid N$. Since we don't know $p$, we search for tuples where $d - x_j$ has large GCD with $N$.

**Modular Sieve.** Precompute the set of quadratic residues mod $N$:
$$\text{QR}(N) = \{x^2 \bmod N : 0 \leq x < N\}$$

Then filter k-tuples to those where $\sum x_i^2 \equiv 0 \pmod{N}$, since these give $N \mid d^2$.

### 7.3 Complexity Discussion

The gravitational factoring framework does not (as yet) improve the asymptotic complexity of factoring beyond known methods. The quadruple tree has $O(d^2)$ nodes up to hypotenuse $d$, and brute-force traversal is no faster than trial division. The potential advantage lies in:

1. **Structured search**: The tree structure enables pruning via modular constraints.
2. **Multiple channels**: The $k(k+1)/2$ independent GCD computations per tuple increase the probability of finding a factor.
3. **Algebraic structure**: At Cayley–Dickson dimensions, the norm multiplicativity provides algebraic shortcuts.
4. **Parallel exploration**: Different branches of the tree can be explored independently.

Whether these advantages can be exploited to achieve subexponential complexity remains an open question.

## 10. Conclusions and Open Questions

### 10.1 Conclusions

We have established that:

1. The Pythagorean k-tuple tree provides a structured geometric search space for integer factoring.
2. The number of independent factoring channels grows quadratically with dimension.
3. At Cayley–Dickson dimensions, norm multiplicativity provides additional algebraic structure.
4. The Euler four-square identity directly connects quaternion decomposition to factoring.
5. Cross-collision (shared hypotenuse) amplifies factoring information quadratically in the number of representations.

### 10.2 Open Questions

1. **Complexity**: Can gravitational descent achieve subexponential factoring complexity?
2. **Optimal dimension**: What is the optimal $k$ for factoring $N$? Is $k \sim \log_2 N$?
3. **Quantum advantage**: Can quantum superposition over tree branches provide speedup?
4. **Lattice connection**: How does the quadruple tree relate to LLL lattice reduction?
5. **Norm factoring in 𝕆**: Can octonionic norm factoring be made practical?
6. **Neural tree navigation**: Can reinforcement learning discover effective navigation policies?
7. **Density of factoring-tuples**: What fraction of k-tuples with hypotenuse $N$ reveal factors?
