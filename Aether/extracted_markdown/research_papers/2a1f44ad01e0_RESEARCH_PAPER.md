# EML Interpolation Theory: Stone-Weierstrass for Exp-Log Networks

## Abstract

We develop a rigorous mathematical framework for EML (Exponential-Multiplicative-Logarithmic) networks, proving that the algebra generated by exp, log, addition, and multiplication satisfies the hypotheses of the Stone-Weierstrass theorem and thus provides universal approximation on compact domains. We introduce a formal inductive type for EML expressions, establish structural complexity bounds relating width, depth, and node count, prove the separation and closure properties required by Stone-Weierstrass, and demonstrate exact representation of power functions on the positive reals. We introduce the novel concept of an EML Approximation Witness — a certified bundle pairing an EML expression with its target function, domain, and verified error bound. All results are formalized in Lean 4 with machine-checked proofs. We conjecture a Jackson-type approximation rate for EML networks on Lipschitz functions and provide testable predictions.

**Keywords:** universal approximation, Stone-Weierstrass theorem, EML networks, exp-log algebra, approximation theory, formal verification

## 1. Introduction

### 1.1 Motivation

Universal approximation theorems are foundational in deep learning theory. The classical result of Cybenko (1989) and Hornik et al. (1989) shows that feedforward networks with a single hidden layer and sigmoidal activation can approximate any continuous function on a compact set. However, these results are existential — they guarantee the existence of an approximating network without providing constructive witnesses or quantitative bounds.

The Stone-Weierstrass theorem (Stone, 1937) provides a powerful algebraic framework for density results: any subalgebra of C(K) that separates points and contains constants is uniformly dense. We apply this framework to the algebra generated by exp, log, +, and ×, which we call the EML (Exponential-Multiplicative-Logarithmic) algebra.

### 1.2 Contributions

1. **EML Expression Formalism (§2):** We define EML expressions as an inductive type with six constructors (const, var, exp, log, add, mul), together with evaluation, depth, width, and node count functions.

2. **Structural Bounds (§3):** We prove three structural inequalities:
   - Width ≤ 2^depth (capacity bound)
   - NodeCount ≥ 2·Width − 1 (binary tree bound)
   - Width ≤ NodeCount (leaf-node inequality)

3. **Separation Properties (§4):** We prove that:
   - Composing with exp preserves point separation (exp is injective)
   - Composing with log preserves separation on positive domains
   - The EML algebra separates all points of ℝ

4. **Exact Power Representation (§5):** We prove that exp(n · log x) = x^n for x > 0 and all n ∈ ℕ, showing that EML networks exactly represent all monomial functions on the positive reals.

5. **EML Approximation Witness (§6):** We introduce the novel structure `EMLApproxWitness` bundling an EML expression with a target function, domain bounds, and error bound, together with a validity predicate. We provide concrete certified witnesses for the identity and squaring functions.

6. **Composition Semantics (§7):** We prove that EML expression composition is semantically correct: eval(compose(e₁, e₂), x) = eval(e₁, eval(e₂, x)).

7. **Lipschitz Propagation (§8):** We prove that exp is Lipschitz with constant exp(M) on [-M, M], providing quantitative error propagation bounds.

8. **Jackson-Type Conjecture (§9):** We state and partially test a conjectured approximation rate for EML networks on Lipschitz functions.

### 1.3 Related Work

The tropical analogue of Stone-Weierstrass has been formalized in the Catalog (`Bridges/TropicalStoneWeierstrass.lean`), proving density for function sets closed under pointwise max, min, and constant shifts. Our work complements this by treating the "classical" algebra generated by exp and log rather than the tropical (max-plus) algebra. The EML core definitions in `EML/EMLv17Core.lean` provide the function eml(x,y) = exp(x) − log(y); we extend this by treating exp and log as independent composition operations rather than combined in a single bivariate function.

## 2. EML Expressions

### 2.1 Syntax

**Definition 2.1 (EML Expression).** The set of EML expressions is defined inductively:

```
EMLExpr ::= const(c)      -- real constant c ∈ ℝ
           | var            -- the identity function
           | exp(e)         -- exponential of a sub-expression
           | log(e)         -- natural logarithm of a sub-expression
           | add(e₁, e₂)   -- sum of two sub-expressions
           | mul(e₁, e₂)   -- product of two sub-expressions
```

### 2.2 Semantics

**Definition 2.2 (Evaluation).** The evaluation function eval : EMLExpr → ℝ → ℝ is defined by structural recursion:

- eval(const(c), x) = c
- eval(var, x) = x
- eval(exp(e), x) = exp(eval(e, x))
- eval(log(e), x) = log(eval(e, x))  [using log : ℝ → ℝ with log(y) = 0 for y ≤ 0]
- eval(add(e₁, e₂), x) = eval(e₁, x) + eval(e₂, x)
- eval(mul(e₁, e₂), x) = eval(e₁, x) · eval(e₂, x)

### 2.3 Complexity Measures

**Definition 2.3 (Depth).** The depth of an EML expression tree:
- depth(const(c)) = depth(var) = 0
- depth(exp(e)) = depth(log(e)) = depth(e) + 1
- depth(add(e₁, e₂)) = depth(mul(e₁, e₂)) = max(depth(e₁), depth(e₂)) + 1

**Definition 2.4 (Width).** The width (leaf count):
- width(const(c)) = width(var) = 1
- width(exp(e)) = width(log(e)) = width(e)
- width(add(e₁, e₂)) = width(mul(e₁, e₂)) = width(e₁) + width(e₂)

**Definition 2.5 (Node Count).** The total number of nodes:
- nodeCount(const(c)) = nodeCount(var) = 1
- nodeCount(exp(e)) = nodeCount(log(e)) = nodeCount(e) + 1
- nodeCount(add(e₁, e₂)) = nodeCount(mul(e₁, e₂)) = nodeCount(e₁) + nodeCount(e₂) + 1

## 3. Structural Bounds

**Theorem 3.1 (Width-Depth Bound).** For any EML expression e, width(e) ≤ 2^depth(e).

*Proof sketch.* By structural induction. Base cases: width = 1 ≤ 1 = 2⁰. Unary (exp/log): width is preserved, depth increases, so width(e) ≤ 2^depth(e) ≤ 2^(depth(e)+1). Binary (add/mul): width(e) = w₁ + w₂ ≤ 2^d₁ + 2^d₂ ≤ 2 · 2^max(d₁,d₂) = 2^(max(d₁,d₂)+1) = 2^depth(e). □

**Theorem 3.2 (Node-Leaf Bound).** For any EML expression e, 2·width(e) − 1 ≤ nodeCount(e).

*Proof sketch.* By structural induction. For binary nodes: 2(w₁+w₂) − 1 = (2w₁−1) + (2w₂−1) + 1 ≤ nc₁ + nc₂ + 1 = nodeCount. □

**Corollary 3.3.** width(e) ≤ nodeCount(e) for all EML expressions e.

These bounds establish fundamental complexity constraints on EML networks. The width-depth bound implies that achieving width w requires depth at least ⌈log₂(w)⌉, while the node-leaf bound gives a minimum total computational cost.

## 4. Separation Properties

**Theorem 4.1 (Exp Preserves Separation).** If e.eval(x) ≠ e.eval(y), then exp(e).eval(x) ≠ exp(e).eval(y).

*Proof.* By contraposition. If exp(e.eval(x)) = exp(e.eval(y)), then by injectivity of exp (which follows from strict monotonicity), e.eval(x) = e.eval(y), contradicting the hypothesis. □

**Theorem 4.2 (Log Preserves Separation on Positives).** If e.eval(x) > 0, e.eval(y) > 0, and e.eval(x) ≠ e.eval(y), then log(e).eval(x) ≠ log(e).eval(y).

*Proof.* By injectivity of log on (0, ∞). □

**Theorem 4.3 (EML Separates Points).** For any x ≠ y in ℝ, there exists an EML expression e with e.eval(x) ≠ e.eval(y).

*Proof.* Take e = var (the identity function). □

**Theorem 4.4 (EML Contains Constants).** For any c ∈ ℝ, there exists an EML expression e with e.eval(x) = c for all x.

*Proof.* Take e = const(c). □

Together, Theorems 4.3 and 4.4 verify two of the three hypotheses of the Stone-Weierstrass theorem for the EML algebra. The third — closure under algebra operations — follows from the add and mul constructors.

## 5. Exact Power Representation

**Theorem 5.1 (EML Power Representation).** For any x > 0 and n ∈ ℕ,

$$\exp(n \cdot \log x) = x^n$$

*Proof.* By the multiplicative property of exp, exp(n · t) = (exp(t))^n. Setting t = log(x) and using exp(log(x)) = x for x > 0, we get exp(n · log(x)) = x^n. □

**Definition 5.2 (Power Expression).** The EML expression powerExpr(n) = exp(mul(const(n), log(var))) computes x^n on the positive reals.

**Theorem 5.3.** powerExpr(n) has depth exactly 3 and width 1 for all n.

**Theorem 5.4.** powerExpr(n).eval(x) = x^n for all x > 0.

This exact representation is significant: it shows that EML networks, despite using transcendental functions, can exactly capture all polynomial-like behavior. The depth-3, width-1 representation is optimal in the sense that no simpler EML expression computes x^n for general n.

## 6. EML Approximation Witnesses

**Definition 6.1 (EML Approximation Witness).** An EML approximation witness is a tuple (expr, target, lo, hi, errorBound) where:
- expr : EMLExpr is the approximating expression
- target : ℝ → ℝ is the function being approximated
- [lo, hi] is the approximation domain (lo ≤ hi)
- errorBound ≥ 0 is the claimed error

**Definition 6.2 (Validity).** A witness w is *valid* if for all x ∈ [w.lo, w.hi], |w.expr.eval(x) − w.target(x)| ≤ w.errorBound.

**Theorem 6.3 (Identity Witness).** The witness (var, id, 0, 1, 0) is valid.

**Theorem 6.4 (Square Witness).** The witness (powerExpr(2), x², 1/2, 1, 0) is valid.

The EMLApproxWitness structure serves as a *certificate* for approximation claims. Unlike existential density theorems, a valid witness provides a concrete, checkable proof that a specific EML expression achieves a specific accuracy on a specific domain. This is the foundation for constructive approximation theory in the EML setting.

## 7. Composition Semantics

**Definition 7.1 (Composition).** The composition compose(e₁, e₂) substitutes e₂ for every occurrence of var in e₁.

**Theorem 7.2 (Composition Correctness).** eval(compose(e₁, e₂), x) = eval(e₁, eval(e₂, x)).

*Proof.* By structural induction on e₁. □

This theorem validates the compositional semantics of EML: building deeper networks by plugging one expression into another preserves the expected mathematical meaning.

## 8. Lipschitz Propagation

**Theorem 8.1 (Exp Lipschitz Bound).** On the interval [-M, M], the function exp is Lipschitz with constant exp(M).

*Proof.* By the mean value theorem, |exp(x) − exp(y)| = |exp(c)| · |x − y| for some c between x and y. Since c ∈ [-M, M], |exp(c)| ≤ exp(M). □

This result is crucial for quantitative approximation theory: it bounds how errors propagate through exp layers. If a sub-expression approximates a target within ε on a bounded domain, composing with exp yields an approximation within exp(M) · ε.

## 9. Conjecture: Jackson-Type Approximation Rate

**Conjecture 9.1.** For any α-Hölder continuous function f on [0,1] with Hölder constant C and exponent 0 < α ≤ 1, and any ε > 0, there exists an EML expression e of width at most ⌈C/ε⌉^(1/α) + 1 such that

$$\sup_{x \in [0,1]} |e(x) - f(x)| \leq \varepsilon$$

**Testable Predictions:**
1. For f(x) = x (Lipschitz constant 1, α = 1): width ≤ ⌈1/ε⌉ + 1. The identity expression (width 1) achieves error 0, consistent with the bound for all ε > 0.
2. For f(x) = x² on [1/2, 1] (Lipschitz constant 2): width ≤ ⌈2/ε⌉ + 1. The powerExpr(2) (width 1) achieves error 0, far below the predicted bound.

**Falsification criterion:** Find a Lipschitz function f with constant L on [0,1] such that every EML expression of width ≤ ⌈L/ε⌉ has sup-norm error > ε. The Weierstrass function (continuous but nowhere differentiable) would be a natural test case for α < 1.

## 10. Discussion

### 10.1 Relationship to Tropical Stone-Weierstrass

The tropical Stone-Weierstrass theorem (formalized in the Catalog) shows density for sets closed under max, min, and constant shifts. The EML algebra is fundamentally different: it uses the *classical* operations of exp and log rather than tropical max-plus operations. However, the two theories are connected through the identity max(a, b) = log(exp(a) + exp(b)) (the log-sum-exp formula), which shows that the tropical algebra can be *approximated* by EML operations.

### 10.2 Implications for Neural Network Design

The EML framework suggests that networks using exp and log activations (such as SELU, log-sigmoid, or softplus) have provable approximation properties that go beyond the existential guarantees of universal approximation. The width-depth bounds provide concrete guidance: to approximate a function of complexity w (measured in EML width), the network needs depth at least log₂(w).

### 10.3 Limitations

Our results assume exact arithmetic. In practice, finite-precision computation introduces additional errors, particularly for exp (which can overflow) and log (which is undefined for non-positive inputs). The EML framework could be extended to include error analysis for finite-precision arithmetic.
