# Gap-Connectedness Theory for Linearly Ordered Topological Spaces

## Abstract

We develop a formal theory connecting order-theoretic gaps to topological connectedness in linearly ordered topological spaces (LOTS). We introduce the `OrderGap` structure — a pair (a, b) with a < b and no element strictly between — and prove that connected LOTS are necessarily gap-free (`connected_implies_gapFree`). We establish that gap-freeness is equivalent to Mathlib's `DenselyOrdered` class, bridging our framework to existing formalized order theory. We introduce the `GapIndex`, a novel cardinality-based measure of disconnectedness, and prove it is an order-isomorphism invariant. We demonstrate that gap successors and predecessors are unique in linear orders, providing algebraic structure to the gap framework. All results are fully formalized in Lean 4 with Mathlib, with no unproven assumptions.

**Keywords:** order topology, connectedness, densely ordered, gap-free, order gap, linearly ordered topological space

---

## 1. Introduction

The relationship between order-theoretic properties and topological connectedness in linearly ordered topological spaces (LOTS) is a classical topic in general topology. A LOTS is a linearly ordered set equipped with the order topology — the topology generated by open rays {x : x < a} and {x : a < x}. The foundational result in this area states that a LOTS is connected if and only if it is both order-dense (gap-free) and conditionally complete (Dedekind complete).

While the individual components of this characterization are well-known, the formalization of the gap-theoretic perspective — treating gaps as first-class mathematical objects rather than merely the negation of density — reveals additional structure. In this paper, we develop this perspective systematically, introducing:

1. The `OrderGap` structure as a concrete witness of non-density
2. The `GapFree` predicate and its equivalence to `DenselyOrdered`
3. The proof that gaps induce clopen partitions in LOTS
4. The `GapIndex` as a quantitative measure of disconnectedness
5. Uniqueness theorems for gap successors and predecessors
6. Order-isomorphism invariance of the gap index

### 1.1 Related Work

The order-topological characterization of connectedness dates to the early 20th century work of Hausdorff and is treated in standard references (Munkres, *Topology*; Engelking, *General Topology*). In the formalization community, Mathlib contains the `DenselyOrdered` class and connectedness results for specific ordered spaces (ℝ, intervals), but does not explicitly formalize the gap structure or the general gap-connectedness correspondence.

## 2. Definitions

### 2.1 Order Gap

**Definition 2.1** (OrderGap). Let (α, ≤) be a preorder. An *order gap* is a triple (lo, hi, h) where:
- lo, hi ∈ α
- lo < hi  (witnessed by h)
- ∀ c ∈ α, ¬(lo < c ∧ c < hi)

Equivalently, the open interval (lo, hi) is empty.

In Lean 4, this is formalized as:
```lean
structure OrderGap (α : Type*) [Preorder α] where
  lo : α
  hi : α
  lo_lt_hi : lo < hi
  empty_between : ∀ c, ¬(lo < c ∧ c < hi)
```

### 2.2 Gap-Free

**Definition 2.2** (GapFree). A preordered type α is *gap-free* if no OrderGap exists:
```lean
def GapFree (α : Type*) [Preorder α] : Prop := ∀ (g : OrderGap α), False
```

### 2.3 Gap Successor

**Definition 2.3** (IsGapSuccessor). For elements a, b in a preorder, b is the *gap-successor* of a if a < b and ∀ c, ¬(a < c ∧ c < b).

### 2.4 Gap Set and Gap Index

**Definition 2.4** (GapSet). The *gap set* of a preordered type α is:
```
gapSet(α) = { (a, b) ∈ α × α : a < b ∧ ∀ c, ¬(a < c ∧ c < b) }
```

**Definition 2.5** (GapIndex). The *gap index* of α is the extended natural number cardinality of the gap set:
```
GapIndex(α) = |gapSet(α)| ∈ ℕ∞
```

## 3. Main Results

### 3.1 Equivalence with Dense Ordering

**Theorem 3.1** (gapFree_iff_denselyOrdered). For a linear order α:
$$\text{GapFree}(\alpha) \iff \text{DenselyOrdered}(\alpha)$$

*Proof sketch.* (→) If GapFree holds, then for any a < b, by contradiction: if no c satisfies a < c < b, then (a, b, _) forms an OrderGap, contradicting GapFree. (←) If DenselyOrdered and there exists an OrderGap g, then by density there exists c with g.lo < c < g.hi, contradicting g.empty_between. □

This theorem bridges our framework to Mathlib's existing order theory. Any result about `DenselyOrdered` types immediately applies to gap-free types and vice versa.

### 3.2 Gaps Induce Clopen Partitions

**Lemma 3.2** (gap_Iic_eq_Iio). If g is a gap in a linear order, then Iic(g.lo) = Iio(g.hi).

*Proof sketch.* For the forward inclusion: x ≤ g.lo implies x < g.hi since g.lo < g.hi. For the reverse: if x < g.hi but g.lo < x, then g.lo < x < g.hi, contradicting g.empty_between. So x ≤ g.lo. □

**Theorem 3.3** (gap_induces_clopen). In a LOTS, if g is a gap, then Iic(g.lo) is clopen.

*Proof sketch.* The set Iic(g.lo) is closed (standard fact about order topology). By Lemma 3.2, Iic(g.lo) = Iio(g.hi), which is open. Hence clopen. □

This is the key geometric insight: a gap creates a "clean break" in the order topology, where the closed half-line below the gap coincides with an open half-line.

### 3.3 Connected Implies Gap-Free

**Theorem 3.4** (connected_implies_gapFree). A connected LOTS is gap-free.

*Proof.* Suppose g is a gap. By Theorem 3.3, Iic(g.lo) is clopen. It is nonempty (contains g.lo). By connectedness, any nonempty clopen set equals the whole space. But g.hi ∉ Iic(g.lo) since g.lo < g.hi. Contradiction. □

### 3.4 Gap Index Properties

**Theorem 3.5** (gapIndex_zero_iff_gapFree). GapIndex(α) = 0 if and only if GapFree(α).

*Proof sketch.* GapIndex = 0 iff gapSet is empty iff no gap exists iff GapFree. □

**Theorem 3.6** (gapIndex_int_infinite). GapIndex(ℤ) = ⊤ (infinity).

*Proof sketch.* The map n ↦ (n, n+1) is an injection from ℤ into gapSet(ℤ). Since ℤ is infinite, gapSet(ℤ) is infinite, hence has infinite extended natural number cardinality. □

**Theorem 3.7** (gapIndex_orderIso_eq). If f : α ≃o β is an order isomorphism, then GapIndex(α) = GapIndex(β).

*Proof sketch.* The map (a, b) ↦ (f(a), f(b)) restricts to a bijection between gapSet(α) and gapSet(β). □

### 3.5 Uniqueness of Gap Successors

**Theorem 3.8** (gapSuccessor_unique). In a linear order, gap successors are unique: if both b and b' are gap-successors of a, then b = b'.

*Proof sketch.* WLOG b ≤ b'. If b < b', then a < b < b', so b witnesses a < b ∧ b < b', contradicting the gap-successor property of b'. Hence b = b'. □

**Theorem 3.9** (gapPredecessor_unique). In a linear order, gap predecessors are unique: if both a and a' are gap-predecessors of b, then a = a'.

*Proof sketch.* Symmetric to Theorem 3.8. □

### 3.6 Gap Transfer

**Theorem 3.10** (OrderGap.map). Order isomorphisms preserve gaps: if g is a gap in α and f : α ≃o β, then (f(g.lo), f(g.hi)) is a gap in β.

*Proof sketch.* f preserves strict ordering (lo_lt_hi). For empty_between: if f(g.lo) < c < f(g.hi), then g.lo < f⁻¹(c) < g.hi by applying f⁻¹, contradicting g.empty_between. □

## 4. Algorithms

### 4.1 Gap Detection Algorithm

Given a finite linearly ordered set represented as a sorted array, detect all gaps:

```
Algorithm GapDetect(A[1..n]):
  gaps ← []
  for i from 1 to n-1:
    if A[i+1] is the order-successor of A[i]:
      # (depends on the order structure)
      gaps.append((A[i], A[i+1]))
  return gaps
```

For integer-valued arrays, this simplifies to checking A[i+1] - A[i] > 1 to detect non-gaps (elements between) or A[i+1] - A[i] = 1 for gaps.

### 4.2 Gap Index Computation

For finite ordered sets, the gap index equals the number of consecutive pairs with no element between them, which is computable in O(n) time.

## 5. Applications and Examples

### 5.1 The Integers

The integers ℤ have infinite gap index. Every consecutive pair (n, n+1) is a gap. This is formalized by `intGap` and `gapIndex_int_infinite`.

### 5.2 The Real Numbers

The reals ℝ are gap-free (and connected), having gap index 0. This follows from `connected_implies_gapFree` and the fact that ℝ is connected.

### 5.3 The Rational Numbers

The rationals ℚ are gap-free (densely ordered) but not connected (not conditionally complete). This shows that gap-freeness is necessary but not sufficient for connectedness — conditional completeness provides the other half of the characterization.

## 6. Discussion

### 6.1 The Gap-Completeness Duality

Our results establish the forward direction of the gap-completeness duality: connected LOTS → gap-free. The full characterization states:

**Conjecture (Gap-Completeness Duality).** A LOTS α (with the order topology) is connected if and only if it is gap-free and conditionally complete.

The reverse direction (gap-free + conditionally complete → connected) follows from the classical intermediate value theorem for ordered spaces, which shows that every Icc interval is connected, and the space can be expressed as a directed union of connected sets.

### 6.2 The Gap Index as Invariant

The gap index provides a more refined invariant than the binary connected/disconnected distinction. Two ordered spaces with different gap indices cannot be order-isomorphic, giving a new tool for distinguishing ordered structures.

Open questions include:
- What values can the gap index take? (Answer: any cardinal, by constructing appropriate ordinal sums)
- How does the gap index interact with products?
- Is there a relationship between gap index and the number of connected components?

### 6.3 Connections to Set Theory

For uncountable linearly ordered spaces, the gap structure interacts with set-theoretic independence phenomena. Suslin's hypothesis (SH) asserts that every LOTS satisfying the countable chain condition is order-isomorphic to ℝ. The gap-theoretic perspective suggests that SH can be reformulated in terms of gap structure: does a gap-free, conditionally complete LOTS with the countable chain condition necessarily have trivial gap index?

## 7. Future Work

1. **Reverse duality**: Formalize that gap-free + conditionally complete → connected for LOTS.
2. **Gap index and components**: Prove that for discrete LOTS, the gap index equals |components| - 1.
3. **Paracompactness**: Investigate whether every LOTS is paracompact (known to be true in ZFC for all linearly ordered spaces).
4. **Surreal number topology**: Apply gap theory to the surreal numbers, which have no gaps but are "too large" to be a set.
5. **Computational applications**: Develop efficient algorithms for gap detection in infinite but computably presented ordered structures.
