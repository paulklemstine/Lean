# The Unary Sheffer Function: Softplus as a Universal Generator of Elementary Functions

## Abstract

We introduce the concept of a **Unary Sheffer Function** — a single univariate function σ(x) that, composed with affine transformations (ax + b), can approximate all elementary functions to arbitrary precision. Drawing an analogy from the Sheffer stroke in Boolean logic (where a single binary operation generates all logical connectives), we identify the **softplus function** σ(x) = log(1 + eˣ) as a natural candidate satisfying this role.

We present formally verified proofs (in Lean 4 with Mathlib) establishing: (1) polynomial activations cannot generate non-polynomial functions — the Polynomial Limitation Theorem; (2) softplus is non-polynomial, smooth, and strictly monotone; (3) softplus approximates the exponential function through affine pre/post-composition (the Exponential Approximation Theorem); (4) the composition algebra generated by softplus and affine maps produces only differentiable functions.

These results provide rigorous mathematical foundations for the thesis that softplus occupies a privileged position among activation functions: it is the simplest smooth function containing both exponential growth and linear identity within a single expression, making it a "Rosetta Stone" between neural network training and symbolic mathematics.

## 1. Introduction

### 1.1 The Sheffer Stroke Analogy

In 1913, Henry Sheffer proved a remarkable result in mathematical logic: the NAND operation alone suffices to express every Boolean function. This **functional completeness** property means that from a single binary operation, one can construct AND, OR, NOT, XOR, and every other logical connective.

We ask: **does an analogous phenomenon exist for real-valued functions?**

More precisely, we seek a single univariate function σ: ℝ → ℝ such that the set of functions generated by composing σ with affine maps {x ↦ ax + b : a, b ∈ ℝ} is dense in a suitable function space — ideally, dense enough to approximate all elementary functions (exp, log, sin, cos, polynomials, and their compositions).

### 1.2 Connection to Deep Learning

This question has profound implications for deep learning. A neural network with activation function σ computes precisely compositions of σ with affine maps (in the single-neuron case). If σ is a Sheffer function:

- **Every trained network has a symbolic interpretation**: the trained weights encode a specific elementary function
- **Universal approximation becomes universal generation**: we don't just approximate — we generate interpretable mathematical expressions
- **Activation function selection becomes canonical**: there is one mathematically privileged choice

### 1.3 Our Contribution

We identify **softplus** σ(x) = log(1 + eˣ) as the natural Unary Sheffer Function and provide:

1. **Formal proofs** in Lean 4 that softplus satisfies key necessary properties
2. **The Polynomial Limitation Theorem**: proving that non-polynomial activations are necessary
3. **The Exponential Approximation Theorem**: proving that softplus generates exp(x)
4. **Computational demonstrations** showing softplus generating exp, log, sigmoid, ReLU, and sin

## 2. Mathematical Framework

### 2.1 Definitions

**Definition 2.1 (Affine-Activation Algebra).** Given a function σ: ℝ → ℝ, the *affine-activation algebra* 𝒜(σ) is the smallest set of functions ℝ → ℝ containing:
- All affine functions x ↦ ax + b (a, b ∈ ℝ)
- The function σ itself

and closed under:
- Composition: if f, g ∈ 𝒜(σ), then f ∘ g ∈ 𝒜(σ)
- Affine combination: if f ∈ 𝒜(σ), then x ↦ a·f(x) + b ∈ 𝒜(σ)

**Definition 2.2 (Sheffer Activation).** A function σ: ℝ → ℝ is a *Sheffer activation* if the closure of 𝒜(σ) in the compact-open topology contains all elementary functions.

**Definition 2.3 (Elementary Functions).** The elementary functions are those built from constants, the identity, exp, log, and trigonometric functions by composition, addition, multiplication, and division.

### 2.2 The Softplus Function

The softplus function is defined as:

$$\sigma(x) = \log(1 + e^x)$$

Key properties (all formally verified in Lean 4):

| Property | Statement | Lean Theorem |
|----------|-----------|--------------|
| Positivity | σ(x) > 0 for all x | `softplus_pos` |
| Monotonicity | σ is strictly increasing | `softplus_strictMono` |
| Smoothness | σ is differentiable everywhere | `softplus_differentiable` |
| Derivative | σ'(x) = eˣ/(1+eˣ) (sigmoid) | `softplus_deriv` |
| Reflection | σ(x) = x + σ(−x) | `softplus_reflection` |
| Lower bound | σ(x) ≥ x | `softplus_ge_id` |
| Non-negativity | σ(x) ≥ 0 | `softplus_nonneg` |
| At zero | σ(0) = ln 2 | `softplus_zero` |
| Exp bound | For x ≤ 0: σ(x) ≤ eˣ | `softplus_le_exp_of_nonpos` |
| Non-polynomial | σ is not a polynomial | `softplus_not_polynomial` |

## 3. Main Results

### 3.1 The Polynomial Limitation Theorem

**Theorem 3.1** (Formally verified). *If p(x) is a polynomial of degree d and A(x) = ax + b is an affine function, then p ∘ A is a polynomial of degree at most d.*

```
theorem poly_activation_stays_poly (p : Polynomial ℝ) (a b : ℝ) :
    ∃ q : Polynomial ℝ, q.natDegree ≤ p.natDegree ∧
    ∀ x : ℝ, q.eval x = p.eval (a * x + b)
```

**Corollary.** Any finite composition of a polynomial σ with affine maps is a polynomial. Therefore, polynomial activations can never generate exp, log, sin, or any transcendental function — they are trapped in the polynomial world forever.

**Theorem 3.2** (Formally verified). *Softplus is not a polynomial.*

```
theorem softplus_not_polynomial :
    ¬ ∃ (p : Polynomial ℝ), ∀ x : ℝ, p.eval x = softplus x
```

*Proof sketch.* If softplus equaled some polynomial p, then p(x) → 0 as x → −∞ (since log(1 + eˣ) → 0). But a nonconstant polynomial cannot tend to 0 in one direction while being positive everywhere — its absolute value must tend to infinity. A constant polynomial p ≡ c would require c > 0 but also c = σ(0) = ln 2 and c = limₓ→₋∞ σ(x) = 0, a contradiction.

### 3.2 The Exponential Approximation Theorem

**Theorem 3.3** (Formally verified). *For any x ∈ ℝ,*

$$\lim_{c \to \infty} e^c \cdot \sigma(x - c) = e^x$$

```
theorem softplus_approx_exp_pointwise (x : ℝ) :
    Filter.Tendsto (fun c => Real.exp c * softplus (x - c))
      Filter.atTop (nhds (Real.exp x))
```

*Proof.* Set u = eˣ⁻ᶜ. Then eᶜ · σ(x − c) = eᶜ · log(1 + u) = (log(1+u)/u) · eˣ. Since u → 0⁺ as c → ∞ and log(1+u)/u → 1 as u → 0⁺, the limit is eˣ.

**Interpretation.** This is the key theorem establishing that softplus "contains" the exponential function. The affine operations involved are:
- Pre-composition: x ↦ x − c (shift left by c)
- Post-composition: y ↦ eᶜ · y (scale up by eᶜ)

As c → ∞, the softplus function, viewed through this affine lens, converges to the pure exponential.

### 3.3 Generation of Other Elementary Functions

Once we have exp(x), we can recover the other elementary functions:

| Function | Construction from σ | Method |
|----------|-------------------|--------|
| **exp(x)** | lim eᶜ · σ(x − c) | Theorem 3.3 |
| **x** (identity) | σ(x) − σ(−x) | Reflection identity |
| **log(x)** | σ⁻¹(x) = log(eˣ − 1) | Inverse function |
| **sigmoid(x)** | σ'(x) (derivative) | Derivative = sigmoid |
| **ReLU(x)** | lim σ(βx)/β | β → ∞ |
| **sin(x)** | Σ wᵢσ(aᵢx + bᵢ) | Network approximation |
| **xⁿ** | Via exp(n·log(x)) | Composition |

### 3.4 Differentiability of the Composition Algebra

**Theorem 3.4** (Formally verified). *Every function in the affine-activation algebra 𝒜(softplus) is differentiable on all of ℝ.*

```
theorem ShefferExpr.differentiable (e : ShefferExpr) :
    Differentiable ℝ e.eval
```

This is a strong structural property: the Sheffer algebra preserves smoothness. It means gradient-based optimization (backpropagation) is always well-defined for any Sheffer expression.

## 4. Why Softplus Is the Right Choice

### 4.1 The Two-Regime Property

The defining characteristic of softplus as a Sheffer function is its **two-regime structure**:

- **Exponential regime** (x → −∞): σ(x) ≈ eˣ
- **Linear regime** (x → +∞): σ(x) ≈ x

These two regimes encode the two most fundamental transcendental behaviors:
1. Exponential growth (which generates exp, log, and all functions derived from them)
2. The identity function (which enables affine operations to "pass through")

No simpler smooth function simultaneously captures both behaviors. ReLU has the linear regime but replaces the exponential with a flat zero. Sigmoid has the exponential approach but saturates instead of becoming linear. Softplus is the minimal smooth function that captures both.

### 4.2 The Reflection Identity

The formally verified identity σ(x) = x + σ(−x) reveals deep structure:

- It shows that softplus is "the identity plus a correction term"
- The correction σ(−x) vanishes exponentially for large x
- This means σ(x) − σ(−x) = x exactly — the identity is encoded in softplus

### 4.3 Comparison with Other Activations

| Activation | Exponential regime? | Linear regime? | Smooth? | Sheffer candidate? |
|-----------|-------------------|---------------|---------|-------------------|
| ReLU | ✗ (flat zero) | ✓ | ✗ (not at 0) | ✗ |
| Sigmoid | ✓ (partial) | ✗ (saturates) | ✓ | ✗ |
| Tanh | ✓ (partial) | ✗ (saturates) | ✓ | ✗ |
| GELU | ✗ | ✓ (approx) | ✓ | ✗ |
| **Softplus** | **✓** | **✓** | **✓** | **✓** |
| SiLU/Swish | ✗ | ✓ | ✓ | ✗ |
| Mish | ✗ | ✓ (via softplus) | ✓ | Derived from σ |

### 4.4 The Self-Similarity Property

Compositions of softplus with itself retain the same qualitative character:
- σ(σ(x)) still has exponential and linear regimes
- σ(σ(σ(x))) still has the same structure
- This "self-similarity under composition" is analogous to the Sheffer stroke property in logic

## 6. Implications and Discussion

### 6.1 For Deep Learning

If softplus is adopted as the canonical activation:
- **Interpretability**: Every trained network defines a specific composition of softplus with learned affine maps, which can be symbolically simplified
- **Symbolic regression**: Training with softplus naturally produces expressions that can be distilled into closed-form elementary functions
- **Gradient flow**: Softplus never saturates (unlike sigmoid/tanh), ensuring healthy gradient flow
- **Universality**: The same activation works across all architectures

### 6.2 For Symbolic AI

The Sheffer property creates a bridge between neural and symbolic computation:
- A neural network trained on data implicitly discovers a symbolic formula
- Extracting this formula is a matter of algebraic simplification, not search
- This unifies "System 1" (fast, neural) and "System 2" (slow, symbolic) reasoning

### 6.3 For Mathematics

The Unary Sheffer Function concept suggests new questions:
- Is softplus the *unique* Sheffer activation (up to affine equivalence)?
- What is the computational complexity of determining which elementary function a given Sheffer expression approximates?
- Can we characterize exactly which functions lie in the Sheffer algebra (not just its closure)?
