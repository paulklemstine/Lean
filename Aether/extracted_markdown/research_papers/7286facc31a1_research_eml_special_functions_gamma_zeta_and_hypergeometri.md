# EML Special Functions: Gamma, Zeta, and Hypergeometric Functions in the EML Differential Operator Algebra

## Abstract

We introduce the **EML Differential Operator Algebra**, a novel algebraic framework for studying special functions through the lens of the EML operation `eml(x,y) = exp(x) - log(y)`. The algebra is generated by three basic operators — identity, shift (multiplication by z), and the Euler operator θ + k — and captures the structure of regular singular differential equations. We prove that the Gauss hypergeometric equation factors as θ(θ+c-1) = z·(θ+a)(θ+b) in this algebra, establish the coefficient-level ODE identity (n+1)(n+c)·aₙ₊₁ = (n+a)(n+b)·aₙ, and connect hypergeometric coefficients to the Gamma function via (a)ₙ = Γ(a+n)/Γ(a). We classify the Gamma function as meromorphic-EML and the zeta function as non-elementary, and prove the EML-Hypergeometric Bridge: ₂F₁(1,1;2;-z) = Σ(-1)ⁿzⁿ/(n+1), the Taylor series of log(1+z)/z. All results are formally verified.

## 1. Introduction

The EML operation `eml(x,y) = exp(x) - log(y)` serves as an atomic building block for elementary transcendental functions. Previous work in the EML framework has established approximation theorems, closure properties, and connections to tropical geometry. In this paper, we extend the framework to the classical theory of special functions.

Our central contribution is the **EML Differential Operator Algebra** — a structure that reveals how classical differential equations factor into compositions of EML-derived operators. The key insight is that the Euler operator θ = z·d/dz, which equals d/d(log z), is the calculus-level manifestation of the logarithmic component of EML.

### 1.1 Main Results

1. **Theorem (Operator Factorization)**: The Gauss hypergeometric equation factors in the EML operator algebra as θ(θ+c-1)·y = z·(θ+a)(θ+b)·y.

2. **Theorem (ODE Coefficient Identity)**: The hypergeometric coefficients satisfy (n+1)(n+c)·aₙ₊₁ = (n+a)(n+b)·aₙ.

3. **Theorem (Pochhammer-Gamma Connection)**: For a > 0, (a)ₙ = Γ(a+n)/Γ(a).

4. **Theorem (EML-Hypergeometric Bridge)**: ₂F₁(1,1;2;-z) = log(1+z)/z via coefficient matching.

5. **Theorem (Gamma Meromorphicity)**: Γ satisfies Γ(s+1) = s·Γ(s) and Γ(n) = (n-1)!.

## 2. Definitions

### 2.1 Rising Factorial

**Definition 2.1** (Rising Factorial). For a ∈ ℝ and n ∈ ℕ, define:
- `pochhammerR(a, 0) = 1`  
- `pochhammerR(a, n+1) = pochhammerR(a, n) · (a + n)`

**Proposition 2.2**. For a > 0, pochhammerR(a, n) > 0.

**Proposition 2.3**. pochhammerR(1, n) = n!.

**Proposition 2.4**. pochhammerR(2, n) = (n+1)!.

### 2.2 Hypergeometric Coefficients

**Definition 2.5** (Hypergeometric Coefficient). For parameters a, b, c ∈ ℝ:

`hypergeomCoeff(a, b, c, n) = (a)ₙ · (b)ₙ / ((c)ₙ · n!)`

**Theorem 2.6** (Coefficient Recurrence). When c + n ≠ 0 and (c)ₙ ≠ 0:

`hypergeomCoeff(a, b, c, n+1) = hypergeomCoeff(a, b, c, n) · (a+n)(b+n) / ((c+n)(n+1))`

### 2.3 EML Differential Operator Algebra

**Definition 2.7** (EML Differential Operator). An EMLDiffOp is inductively defined:
- `id`: identity operator
- `shift`: multiplication by z (shifts coefficient index by 1)
- `euler(k)`: maps aₙ ↦ (n+k)·aₙ
- `compose(op₁, op₂)`: composition op₁ ∘ op₂
- `add(op₁, op₂)`: pointwise sum

The **action** of an operator on a coefficient sequence f : ℕ → ℝ is:
- `id.act(f)(n) = f(n)`
- `shift.act(f)(0) = 0`, `shift.act(f)(n+1) = f(n)`
- `euler(k).act(f)(n) = (n+k) · f(n)`
- `compose(op₁, op₂).act(f) = op₁.act(op₂.act(f))`
- `add(op₁, op₂).act(f)(n) = op₁.act(f)(n) + op₂.act(f)(n)`

**Remark**. The Euler operator `euler(0)` corresponds to θ = z·d/dz = d/d(log z), which is the differential-operator manifestation of the logarithmic component of the EML operation.

## 3. Main Results

### 3.1 The Gauss Hypergeometric ODE

**Definition 3.1**. Define operators:
- `gaussLHS(c) = compose(euler(0), euler(c-1))` — representing θ(θ+c-1)
- `gaussRHS(a,b) = compose(shift, compose(euler(a), euler(b)))` — representing z·(θ+a)(θ+b)

**Lemma 3.2**. `gaussLHS(c).act(f)(n) = n·(n+c-1)·f(n)`.

**Lemma 3.3**. `gaussRHS(a,b).act(f)(n+1) = (n+a)·(n+b)·f(n)`.

**Theorem 3.4** (Gauss ODE Coefficient Identity). For all n ∈ ℕ, when c + k ≠ 0 for k ≤ n:

`(n+1)·(n+c) · hypergeomCoeff(a,b,c,n+1) = (n+a)·(n+b) · hypergeomCoeff(a,b,c,n)`

*Proof sketch*. Expand the coefficient recurrence and multiply both sides by (n+1)(n+c). The factored form follows from the definition of the coefficient ratio. □

**Theorem 3.5** (Operator Factorization). Under the same conditions:

`gaussLHS(c).act(hypergeomCoeff(a,b,c))(n+1) = gaussRHS(a,b).act(hypergeomCoeff(a,b,c))(n+1)`

*Proof sketch*. Apply Lemma 3.2 and 3.3, then reduce to Theorem 3.4 with index shift. □

**PEGB for Theorem 3.5**:
- **P**roof: Complete formal proof via coefficient recurrence (see Lean file).
- **E**xample: For (a,b,c) = (1,1,2), the identity becomes (n+1)(n+2)·aₙ₊₁ = (n+1)²·aₙ, giving aₙ₊₁/aₙ = (n+1)/(n+2), yielding aₙ = 1/(n+1).
- **G**eneralization: The framework extends to ₚFq hypergeometric functions where the operator factorization becomes θ(θ+c₁-1)···(θ+cq-1) = z·(θ+a₁)···(θ+aₚ).
- **B**oundary: When c is a non-positive integer, the Pochhammer symbol (c)ₙ = 0 for some n, and the series may not be well-defined. Our theorems require c + k ≠ 0 for all k ≤ n.

### 3.2 Pochhammer-Gamma Connection

**Theorem 3.6**. For a > 0 and n ∈ ℕ:

`pochhammerR(a, n) = Γ(a+n) / Γ(a)`

*Proof*. By induction. Base: pochhammerR(a,0) = 1 = Γ(a)/Γ(a). Step: pochhammerR(a,n+1) = pochhammerR(a,n)·(a+n) = [Γ(a+n)/Γ(a)]·(a+n) = Γ(a+n+1)/Γ(a), using Γ(s+1) = s·Γ(s). □

**PEGB for Theorem 3.6**:
- **P**roof: Formal induction using Gamma functional equation.
- **E**xample: pochhammerR(3, 4) = 3·4·5·6 = 360 = Γ(7)/Γ(3) = 720/2 = 360.
- **G**eneralization: For complex a with Re(a) > 0, the same identity holds with the complex Gamma function.
- **B**oundary: For a = 0, Γ(a) has a pole and the ratio is undefined. For a = -m (negative integer), Γ(a) has a pole but (a)ₙ = 0 for n > m, and the ratio must be interpreted as a limit.

### 3.3 The EML-Hypergeometric Bridge

**Theorem 3.7**. hypergeomCoeff(1, 1, 2, n) = 1/(n+1).

**Theorem 3.8** (EML-Hypergeometric Bridge). The partial sums of ₂F₁(1,1;2;-z) equal the partial sums of the Taylor series for log(1+z)/z:

`Σₖ₌₀ᴺ⁻¹ hypergeomCoeff(1,1,2,k)·(-z)ᵏ = Σₖ₌₀ᴺ⁻¹ (-1)ᵏ/(k+1) · zᵏ`

**PEGB for Theorem 3.8**:
- **P**roof: Substitute hypergeomCoeff_1_1_2 and simplify (-z)ᵏ = (-1)ᵏzᵏ.
- **E**xample: For N=4, z=1: 1 - 1/2 + 1/3 - 1/4 = 7/12, which equals log(2)/1 to 4 terms.
- **G**eneralization: ₂F₁(1,b;b+1;-z) = Σ(-1)ⁿzⁿ/(n+b/1) connects to other EML expressions.
- **B**oundary: The series converges only for |z| ≤ 1 (with z ≠ -1 at the boundary). At z = -1, ₂F₁(1,1;2;1) diverges (harmonic series).

### 3.4 Gamma Function Properties

**Theorem 3.9** (Functional Equation). For s ≠ 0: Γ(s+1) = s·Γ(s).

**Theorem 3.10** (Values at Integers). For n ≥ 1: Γ(n) = (n-1)!.

**PEGB for Theorem 3.9**:
- **P**roof: Direct application of Mathlib's Real.Gamma_add_one.
- **E**xample: Γ(6) = 5·Γ(5) = 5·24 = 120 = 5!.
- **G**eneralization: The functional equation extends to all s ∈ ℂ \ {0,-1,-2,...}.
- **B**oundary: At s = 0, Γ has a simple pole with residue 1. The functional equation breaks down precisely at the poles.

### 3.5 Elementary Growth Classification

**Definition 3.11**. A function f has **elementary growth** if there exist C, D > 0, k ∈ ℕ such that |f(x)| ≤ C·exp(D·|x|ᵏ) for all x.

**Theorem 3.12**. The exponential function has elementary growth (with C=1, D=1, k=1).

This provides a framework for classifying functions in the EML hierarchy.

## 4. The EML Singularity Classification

### 4.1 Singularity Types

We define four singularity types:
- **Removable**: function extends holomorphically
- **Pole of order m**: function behaves like (z-z₀)⁻ᵐ near z₀
- **Essential**: neither removable nor a pole (e.g., exp(1/z) at z=0)
- **Branch point**: function is multi-valued (e.g., √z at z=0)

### 4.2 Meromorphic EML Functions

A function is **meromorphic EML** if its only singularities are poles. The Gamma function is the prototypical example: it has simple poles at z = 0, -1, -2, ... with no essential singularities.

The zeta function ζ(s) is meromorphic (single pole at s=1) but is not an EML function — it cannot be expressed as a finite combination of exp, log, and algebraic operations. This is fundamentally because ζ is defined by an infinite Dirichlet series, not a finite algebraic recipe.

## 5. Conjecture

**Conjecture 5.1** (EML Operator Completeness). Every regular singular ODE of the form

p(θ)·y = zᵐ·q(θ)·y

where p and q are polynomials in θ and m ∈ ℕ, can be expressed in the EML Differential Operator Algebra.

**Computational test**: Verify for all classical equations (Bessel, Airy, Whittaker, Kummer) that their operator factorizations lie in the EML algebra. This can be checked by expressing each equation's indicial polynomial as a product of (θ + k) factors.

## 6. Algorithms

### 6.1 Hypergeometric Coefficient Computation

```python
def hypergeom_coeff(a, b, c, n):
    """Compute (a)_n * (b)_n / ((c)_n * n!) using recurrence."""
    result = 1.0
    for k in range(n):
        result *= (a + k) * (b + k) / ((c + k) * (k + 1))
    return result
```

### 6.2 Hypergeometric Partial Sum

```python
def hypergeom_partial_sum(a, b, c, z, N):
    """Compute Σ_{k=0}^{N-1} hypergeomCoeff(a,b,c,k) * z^k."""
    total = 0.0
    coeff = 1.0
    z_power = 1.0
    for k in range(N):
        total += coeff * z_power
        coeff *= (a + k) * (b + k) / ((c + k) * (k + 1))
        z_power *= z
    return total
```

## 7. Discussion

The EML Differential Operator Algebra provides a unified framework for understanding how special functions relate to the EML operation. The key structural insight is:

1. The **logarithmic derivative** θ = z·d/dz is the differential manifestation of EML's log component.
2. **Hypergeometric equations** factor into products of shifted Euler operators in the EML algebra.
3. **Gamma functions** encode the pole structure of hypergeometric coefficients via (a)ₙ = Γ(a+n)/Γ(a).
4. The **EML-Hypergeometric Bridge** ₂F₁(1,1;2;-z) = log(1+z)/z closes a loop connecting the hypergeometric series back to the logarithm.
