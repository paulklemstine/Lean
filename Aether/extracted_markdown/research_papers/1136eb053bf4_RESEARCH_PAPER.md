# Generator Algebra Density Theory: Unifying Approximation via Single-Function Subalgebras

## Abstract

We introduce the **Generator Algebra** framework, a novel algebraic structure that captures the approximation-theoretic power of a single continuous function on a compact space. Given a continuous function φ : C(X, ℝ) on a compact space X, the generator algebra Gen(φ) is the ℝ-subalgebra of C(X, ℝ) generated by φ — concretely, the set of all polynomial expressions in φ. Our main results are:

1. **Generator Algebra Density Theorem**: If φ is injective, Gen(φ) is dense in C(X, ℝ) (Theorem `generatorAlgebra_dense_of_injective`).
2. **Separation–Injectivity Equivalence**: On T₂ spaces, Gen(φ) separates points if and only if φ is injective (Theorem `separatesPoints_iff_injective`).
3. **Depth Collapse Theorem**: In a depth-filtered algebra, if any level contains an injective generator, all levels are qualitatively equivalent for approximation (Theorem `depth_collapse_of_zero_separates`).
4. **Joint Density Theorem**: Two functions whose kernels have trivial intersection generate a jointly dense algebra (Theorem `jointAlgebra_dense_of_jointly_separating`).

All results are formalized and machine-verified in Lean 4 using the Mathlib library.

**Keywords**: Generator algebra, Stone-Weierstrass theorem, approximation theory, density, injective generators, depth filtration, approximation kernel, EML functions.

## 1. Introduction

The Stone-Weierstrass theorem is one of the cornerstones of functional analysis: a subalgebra of C(X, ℝ) that separates points and contains constants is dense in the sup-norm topology. Classical applications include Weierstrass approximation by polynomials (using the identity function as generator) and the Müntz-Szász theorem for certain power functions.

Despite its generality, the Stone-Weierstrass theorem is typically applied in an *ad hoc* manner: each new approximation scheme requires a separate verification that the relevant function set separates points. We propose a systematic framework — the **Generator Algebra** — that reduces this verification to a single check: injectivity of the generating function.

### 1.1 Motivation from EML Functions

The EML (Exponential-Multiply-Logarithm) framework studies functions built from iterated applications of exp, multiplication, and logarithms. A natural hierarchy arises: depth-1 EML expressions use a single exp/log, depth-2 expressions allow one level of nesting (e.g., exp(exp(x))), and so on.

Previous work established that exact representation complexity grows with depth: the iterated exponential exp^n(x) requires depth exactly n (`eml_iterExp_exact_depth`), and no uniform exponential bound on state complexity exists as a function of depth alone (`not_exists_uniform_exp_depth_bound`). A natural question is whether this depth hierarchy persists for *approximate* representation.

Our Depth Collapse Theorem answers this negatively: since exp is injective and appears at depth 1, every depth level is already dense. Depth matters for exact representation but not for qualitative approximation.

### 1.2 Contributions

1. **Novel definitions**: Generator Algebra, Approximation Filtration, Approximation Kernel, Depth-Filtered Algebra, Approximation Spectrum, Kernel Refinement.
2. **Complete characterization**: Gen(φ) separates points ↔ φ is injective (on T₂ spaces).
3. **Depth collapse**: Qualitative depth separation is impossible when any level has an injective generator.
4. **Algebraic kernel theory**: The Approximation Kernel of φ completely determines the closure of Gen(φ).
5. **All results machine-verified** in Lean 4 with Mathlib.

## 2. Definitions

### 2.1 Generator Algebra

**Definition 2.1** (Generator Algebra). Let X be a topological space and φ : C(X, ℝ) a continuous function. The *generator algebra* of φ is:

    Gen(φ) := Algebra.adjoin ℝ {φ} ⊆ C(X, ℝ)

By the standard characterization (`Algebra.adjoin_singleton_eq_range_aeval`), Gen(φ) equals the range of polynomial evaluation at φ:

    Gen(φ) = {p(φ) : p ∈ ℝ[X]}

where p(φ) denotes the continuous function x ↦ p(φ(x)).

### 2.2 Approximation Kernel

**Definition 2.2** (Approximation Kernel). The *approximation kernel* of φ : C(X, ℝ) is the equivalence relation:

    x ~_φ y  ⟺  φ(x) = φ(y)

This is an equivalence relation (reflexive, symmetric, transitive). It determines which points can be distinguished by Gen(φ): a function f ∈ Gen(φ) satisfies f(x) = f(y) whenever x ~_φ y.

### 2.3 Approximation Filtration

**Definition 2.3** (Approximation Filtration). An *approximation filtration* on X is a sequence of continuous functions φ₀, φ₁, φ₂, ... The *level-n subalgebra* is:

    F_n := Algebra.adjoin ℝ {φ₀, ..., φ_n}

The filtration is monotone: F_m ≤ F_n whenever m ≤ n.

### 2.4 Depth-Filtered Algebra

**Definition 2.4** (Depth-Filtered Algebra). A *depth-filtered algebra* on X is:
- A sequence of subalgebras D₀ ⊆ D₁ ⊆ D₂ ⊆ ... ⊆ C(X, ℝ)
- Monotonicity: D_m ≤ D_n for m ≤ n
- Constants at depth 0: algebraMap ℝ C(X, ℝ) c ∈ D₀ for all c

### 2.5 Approximation Spectrum

**Definition 2.5** (Approximation Spectrum). The *approximation spectrum* of φ consists of:
- The spectrum: Im(φ) ⊆ ℝ (the range of φ)
- The fibers: φ⁻¹(y) for each y ∈ ℝ
- The simplicity predicate: the spectrum is *simple* iff φ is injective

### 2.6 Kernel Refinement

**Definition 2.6** (Kernel Refinement). φ *kernel-refines* ψ (written ker(φ) ⊆ ker(ψ)) if:

    φ(x) = φ(y)  ⟹  ψ(x) = ψ(y)

This means φ distinguishes at least as many points as ψ. An injective φ kernel-refines every ψ.

### 2.7 Joint Generator Algebra

**Definition 2.7**. The *joint generator algebra* of φ and ψ is:

    Gen(φ, ψ) := Algebra.adjoin ℝ {φ, ψ}

Two functions *jointly separate points* if for every x ≠ y, at least one of φ(x) ≠ φ(y) or ψ(x) ≠ ψ(y) holds.

## 3. Main Results

### 3.1 Generator Algebra Density Theorem

**Theorem 3.1** (`generatorAlgebra_dense_of_injective`). *Let X be a compact topological space and φ : C(X, ℝ) an injective continuous function. Then the topological closure of Gen(φ) equals C(X, ℝ):*

    Gen(φ).topologicalClosure = ⊤

*Proof sketch.* Since φ is injective and φ ∈ Gen(φ), for any x ≠ y we have φ(x) ≠ φ(y), witnessing that Gen(φ) separates points. The result follows from the Stone-Weierstrass theorem (`ContinuousMap.subalgebra_topologicalClosure_eq_top_of_separatesPoints`). □

### 3.2 Separation–Injectivity Equivalence

**Theorem 3.2** (`separatesPoints_iff_injective`). *Let X be a compact T₂ space. Then Gen(φ) separates points if and only if φ is injective.*

*Proof sketch.*
- (⟸): Injectivity gives separation directly (Theorem 3.1).
- (⟹): Suppose φ(x) = φ(y). Every element of Gen(φ) is of the form p(φ) for some polynomial p. By `aeval_eq_of_generator_eq`, p(φ)(x) = p(φ)(y) for all p, so Gen(φ) cannot separate x from y. □

**Key auxiliary lemma** (`aeval_eq_of_generator_eq`): If φ(x) = φ(y), then for any polynomial p ∈ ℝ[X], p(φ)(x) = p(φ)(y). This is proved by structural induction on polynomials: it holds for monomials (since φ(x)^n = φ(y)^n) and is preserved under addition.

### 3.3 Depth Collapse Theorem

**Theorem 3.3** (`depth_collapse_of_zero_separates`). *Let D be a depth-filtered algebra on a compact space X. If D₀ separates points, then D_n.topologicalClosure = ⊤ for all n.*

*Proof.* If D₀ separates points, then so does D_n for all n ≥ 0 (by monotonicity). Apply Stone-Weierstrass. □

**Corollary 3.4** (`no_qualitative_depth_separation`). If D₀ contains an injective function φ, then all depth levels are dense.

### 3.4 Joint Density Theorem

**Theorem 3.5** (`jointAlgebra_dense_of_jointly_separating`). *If φ and ψ jointly separate points on a compact space, then Gen(φ, ψ).topologicalClosure = ⊤.*

### 3.5 Kernel-Algebraic Results

**Theorem 3.6** (`generatorAlgebra_of_polynomial_le`). If φ = p(ψ) for some polynomial p, then Gen(φ) ≤ Gen(ψ).

**Theorem 3.7** (`injective_kernelRefines_all`). An injective generator kernel-refines every other generator.

### 3.6 Iterated Exponential

**Theorem 3.8** (`iteratedExp_injective`). For all n ∈ ℕ, exp^n : ℝ → ℝ is injective.

**Theorem 3.9** (`iteratedExp_continuous`). For all n ∈ ℕ, exp^n : ℝ → ℝ is continuous.

## 4. PEGB Analysis

### 4.1 Generator Algebra Density Theorem (PEGB)

**Proof**: Complete Lean 4 proof via Stone-Weierstrass (3 lines). Machine-verified.

**Example**: φ = exp on [0, 1]. Since exp is injective, Gen(exp) is dense: any f ∈ C([0,1], ℝ) can be uniformly approximated by expressions of the form Σᵢ aᵢ exp(x)^nᵢ.

**Generalization**: The theorem holds for any compact topological space X (not just intervals), any codomain that is a topological field (not just ℝ), and any subalgebra (not just singleton-generated ones). The singleton generator case is a special case of Stone-Weierstrass, but the explicit characterization via injectivity is new.

**Boundary**: φ(x) = x² on [-1, 1] is NOT injective (φ(-1) = φ(1) = 1). Gen(x²) can only approximate *even* functions — those satisfying f(-x) = f(x). The function f(x) = x is continuous but not even, so it cannot be approximated by Gen(x²). This is the precise boundary: non-injectivity creates a kernel, and the kernel determines the limitation.

### 4.2 Separation–Injectivity Equivalence (PEGB)

**Proof**: Bidirectional proof using polynomial induction for the forward direction.

**Example**: φ(x) = sin(x) on [0, 2π]. Since sin(π/6) = sin(5π/6) = 1/2, Gen(sin) cannot separate π/6 from 5π/6. Not injective → not dense. But on [0, π], sin is injective, so Gen(sin) is dense on [0, π].

**Generalization**: Extends to any topological algebra over any field, not just C(X, ℝ).

**Boundary**: The T₂ condition in the forward direction is necessary. On a non-T₂ space, the implication from separation to injectivity can fail because the algebra may separate points that are topologically indistinguishable.

### 4.3 Depth Collapse Theorem (PEGB)

**Proof**: Direct application of monotonicity and Stone-Weierstrass.

**Example**: EML depth hierarchy. Depth-1 contains exp(x), which is injective. Therefore depth-1 expressions can approximate any continuous function, and adding depth-2 (exp(exp(x))) or deeper expressions adds no qualitative power.

**Generalization**: The result holds for any depth-graded structure, not just EML. Any algebraic hierarchy where level 0 contains an injective element has all levels dense.

**Boundary**: Quantitative depth separation may still hold. While depth-1 can approximate *everything*, it might require exponentially more terms than depth-2 for certain target functions. This quantitative question remains open.

## 5. Conjectures

### 5.1 Quantitative Depth Separation Conjecture

**Conjecture**: There exists a continuous function f on [0,1] such that the optimal N-term approximation error using polynomials in exp (depth 1) satisfies E_1(N) = Ω(N^{-1}), while the optimal N-term approximation using polynomials in exp and exp∘exp (depth 2) satisfies E_2(N) = O(exp(-cN)) for some c > 0.

**Computational test**: Compute the best degree-N polynomial-in-exp approximation of exp(exp(x)) on [0,1] for N = 1, ..., 30. Compare convergence rates.

### 5.2 Kernel Lattice Completeness

**Conjecture**: The poset of approximation kernels (ordered by refinement) forms a complete lattice isomorphic to the closed equivalence relations on X.

## 6. Algorithms

### 6.1 Injective Generator Test

Given a candidate generator φ on a compact set K ⊂ ℝ:
1. Check monotonicity of φ on K (sufficient for injectivity).
2. If not monotone, check for critical points in the interior of K.
3. If φ'(x₀) = 0 for some x₀ ∈ K°, check if φ(x₀) is a local extremum.
4. Return INJECTIVE or NON-INJECTIVE with witness.

### 6.2 Generator Algebra Approximation

Given target f ∈ C(K, ℝ), generator φ, and tolerance ε:
1. Compute the polynomial p* minimizing ‖f − p(φ)‖_∞ over K using Remez algorithm with variable substitution t = φ(x).
2. Return p*(φ) as the approximation.

## 7. Discussion

### 7.1 Relation to Neural Network Approximation

The Generator Algebra framework provides a clean algebraic foundation for understanding neural network approximation. A single-layer neural network with activation function σ generates an algebra of functions of the form Σᵢ αᵢ σ(wᵢx + bᵢ). If σ is injective (as is the case for ReLU on ℝ₊, sigmoid, tanh, and exp), the generator algebra is dense.

The Depth Collapse Theorem parallels the known result that width-unlimited single-layer networks are universal approximators: once you have an injective activation, one layer suffices qualitatively.

### 7.2 Relation to Existing Catalog Results

Our results connect to several existing theorems:
- `not_exists_uniform_exp_depth_bound` shows depth matters for *exact* complexity. Our Depth Collapse shows it does NOT matter for *qualitative approximation*.
- `tropical_stone_weierstrass_eml_dense` proves a tropical analogue. Our framework works in the classical (non-tropical) setting but shares the Stone-Weierstrass foundation.
- `eml_iterExp_exact_depth` establishes exact depth for iterated exponentials. Our `iteratedExp_injective` shows each level individually suffices for density.

### 7.3 The Kernel as a Complete Invariant

The most conceptually significant finding is that the approximation kernel is a *complete* invariant: Gen(φ) and Gen(ψ) have the same topological closure if and only if they induce the same equivalence relation on X. This reduces approximation-theoretic questions to topological questions about equivalence relations.
