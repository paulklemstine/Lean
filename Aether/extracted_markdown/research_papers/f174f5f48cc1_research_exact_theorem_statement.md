# Closure–Kernel Duality for Expressive Model Logics: Galois Connections, Moore Families, and Canonical Generators

## Abstract

We establish that the EML (Expressive Model Logic) closure operator on real-valued function classes satisfies the axioms of a closure operator on the complete lattice of subsets of ℝ → ℝ, and we derive the resulting order-theoretic consequences. Our main results are: (1) a Galois insertion between the lattice of generator sets and the lattice of EML-closed classes; (2) a Galois connection that provides an exact biconditional `EMLClosure(A) ⊆ C ↔ A ⊆ C` for closed C; (3) a proof that EML-closed sets form a Moore family (closed under arbitrary intersections); (4) characterization of the EML core operator and its relationship to minimal generators. All results are machine-verified in Lean 4 with the Mathlib library, using only the standard axioms (propext, Classical.choice, Quot.sound).

**Keywords:** closure operator, Galois connection, Galois insertion, Moore family, expressive model logic, function classes, formal verification

## 1. Introduction

### 1.1 Motivation

Expressive Model Logic (EML) provides a framework for studying the expressive power of function classes generated by combining basic functions through algebraic operations and composition. Given a set S of real-valued functions, the EML closure of S consists of all functions obtainable from S by finitely many applications of:
- Constant functions (for any c ∈ ℝ, the function x ↦ c)
- Pointwise addition (f, g ↦ x ↦ f(x) + g(x))
- Pointwise multiplication (f, g ↦ x ↦ f(x) · g(x))
- Function composition (f, g ↦ x ↦ f(g(x)))

This framework captures the expressivity of wide classes of models, including polynomial networks, rational approximators, and compositions of activation functions.

### 1.2 Prior Work

The closure-theoretic properties of EML were previously established in the EML catalog:
- Extensivity: A ⊆ EMLClosure(A)
- Monotonicity: A ⊆ B → EMLClosure(A) ⊆ EMLClosure(B)
- Idempotence: EMLClosure(EMLClosure(A)) = EMLClosure(A)
- Self-stability under operations: the closure is closed under add, mul, comp

However, the order-theoretic consequences—Galois connections, the lattice structure of closed classes, and the relationship between generators and closed worlds—had not been formalized.

### 1.3 Contributions

This paper makes the following contributions:

1. **Galois insertion** (Theorem 3.1): We construct a Galois insertion between Set(ℝ → ℝ) and the subtype of EML-closed sets, using the Mathlib `ClosureOperator` infrastructure.

2. **Explicit Galois connection** (Theorem 3.2): We prove that for any A and closed C, `EMLClosure(A) ⊆ C ↔ A ⊆ C`.

3. **Moore family** (Theorem 4.1): We prove that EML-closed sets are closed under arbitrary intersections.

4. **Core operator** (Section 5): We define and study the EML core, proving monotonicity, containment in the original set, and its relationship to exact generators.

5. **Analysis of naive adjoint** (Section 6): We analyze the proposed `emlCore(C) = ⋂{A | C ⊆ cl(A)}` and show that while it is not the correct right adjoint to EMLClosure on all sets, it satisfies useful containment properties.

## 2. Definitions and Notation

### 2.1 EML Closure

**Definition 2.1** (EMLGenerated). The predicate `EMLGenerated(S, f)` is defined inductively:
- (base) If f ∈ S, then EMLGenerated(S, f).
- (const) For any c ∈ ℝ, EMLGenerated(S, x ↦ c).
- (add) If EMLGenerated(S, f) and EMLGenerated(S, g), then EMLGenerated(S, x ↦ f(x) + g(x)).
- (mul) If EMLGenerated(S, f) and EMLGenerated(S, g), then EMLGenerated(S, x ↦ f(x) · g(x)).
- (comp) If EMLGenerated(S, f) and EMLGenerated(S, g), then EMLGenerated(S, x ↦ f(g(x))).

**Definition 2.2** (EMLClosure). `EMLClosure(S) = {f : ℝ → ℝ | EMLGenerated(S, f)}`.

### 2.2 Closure Operator Properties

**Theorem 2.3** (Closure axioms).
- (Extensivity) A ⊆ EMLClosure(A)
- (Monotonicity) A ⊆ B → EMLClosure(A) ⊆ EMLClosure(B)
- (Idempotence) EMLClosure(EMLClosure(A)) = EMLClosure(A)

*Proof.* Extensivity follows from the (base) constructor. Monotonicity and idempotence are proved by structural induction on EMLGenerated derivations. □

### 2.3 Packaging as a ClosureOperator

**Definition 2.4**. We define `emlClosureOp : ClosureOperator (Set (ℝ → ℝ))` using the Mathlib `ClosureOperator` structure, which packages the three axioms into a single algebraic object.

### 2.4 EML Core

**Definition 2.5** (EML Core). `emlCore(C) = ⋂{A : Set(ℝ → ℝ) | C ⊆ EMLClosure(A)}`

**Definition 2.6** (Minimal generators). `minimalGeneratorsEq(C) = ⋂{A : Set(ℝ → ℝ) | EMLClosure(A) = C}`

## 3. Main Results: Galois Connection and Insertion

### 3.1 The Correct Adjoint

A key insight of this work is identifying the **correct right adjoint** for the EML closure. The naive proposal `emlCore(C) = ⋂{A | C ⊆ cl(A)}` does NOT yield a Galois connection on all of Set(ℝ → ℝ), because the implication

> cl(A) ⊆ C → A ⊆ emlCore(C)

fails in general: cl(A) ⊆ C ⊆ cl(B) does not imply A ⊆ B.

The correct right adjoint is the **inclusion** `Subtype.val : {C // EMLClosure(C) = C} → Set(ℝ → ℝ)`, which maps a closed set to itself.

**Theorem 3.1** (Galois Insertion). The pair (EMLClosure, inclusion) forms a Galois insertion:
```
GaloisInsertion emlClosureOp.toCloseds Subtype.val
```

This is an instance of a general fact: any closure operator on a partially ordered set induces a Galois insertion between the ambient poset and the fixed-point subposet.

*Proof.* This is `ClosureOperator.gi` from Mathlib, instantiated at `emlClosureOp`. □

**Theorem 3.2** (Galois Connection). The underlying Galois connection satisfies:
```
GaloisConnection emlClosureOp.toCloseds Subtype.val
```

*Proof.* Extracted from the Galois insertion via `GaloisInsertion.gc`. □

**Theorem 3.3** (Explicit biconditional). For any A : Set(ℝ → ℝ) and closed C (i.e., EMLClosure(C) = C):

> EMLClosure(A) ⊆ C ↔ A ⊆ C

*Proof.* Forward: A ⊆ EMLClosure(A) ⊆ C by extensivity and hypothesis. Backward: A ⊆ C implies EMLClosure(A) ⊆ EMLClosure(C) = C by monotonicity and closedness. □

### 3.2 Mathematical Significance

Theorem 3.3 is the fundamental duality of EML. It reduces questions about closure containment to direct set inclusion, eliminating the need to reason about the infinite generative process of EMLClosure. This is the EML analogue of:
- The Galois correspondence in field theory: intermediate fields ↔ subgroups
- The adjunction in topology: closure ↔ interior
- The soundness–completeness duality in logic: semantic entailment ↔ syntactic derivability

## 4. Moore Family Structure

**Theorem 4.1** (Closure under intersection). If every C ∈ S satisfies EMLClosure(C) = C, then EMLClosure(⋂S) = ⋂S.

*Proof.* The inclusion ⋂S ⊆ EMLClosure(⋂S) is extensivity. For the reverse, fix C ∈ S. Then ⋂S ⊆ C, so by monotonicity EMLClosure(⋂S) ⊆ EMLClosure(C) = C. Since this holds for all C ∈ S, we have EMLClosure(⋂S) ⊆ ⋂S. □

**Theorem 4.2** (Moore family). There exists a family F of subsets of (ℝ → ℝ) such that:
1. Every C ∈ F satisfies EMLClosure(C) = C.
2. For every T ⊆ F, ⋂T ∈ F.

*Proof.* Take F = {C | EMLClosure(C) = C} and apply Theorem 4.1. □

**Corollary 4.3**. The EML-closed sets form a complete lattice under set inclusion, with meet = intersection and join = closure of union.

## 5. The EML Core Operator

### 5.1 Basic Properties

**Theorem 5.1** (Containment). emlCore(C) ⊆ C for all C.

*Proof.* C ∈ {A | C ⊆ EMLClosure(A)} by extensivity, so ⋂{A | C ⊆ cl(A)} ⊆ C. □

**Theorem 5.2** (Monotonicity). If C ⊆ D then emlCore(C) ⊆ emlCore(D).

*Proof.* C ⊆ D implies {A | D ⊆ cl(A)} ⊆ {A | C ⊆ cl(A)}. By contravariance of ⋂, emlCore(C) = ⋂(larger family) ⊆ ⋂(smaller family) = emlCore(D). □

**Theorem 5.3** (Relationship to minimal generators). emlCore(C) ⊆ minimalGeneratorsEq(C) for all C.

*Proof.* {A | cl(A) = C} ⊆ {A | C ⊆ cl(A)} since equality implies containment. By contravariance of ⋂, intersecting over the larger family gives a smaller result. □

### 5.2 Why emlCore Is Not the Right Adjoint

The following counterexample shows that `GaloisConnection EMLClosure emlCore` fails on Set(ℝ → ℝ).

Consider C = EMLClosure({id}), where id : x ↦ x. Then:
- cl({id}) ⊆ C (trivially), so cl({id}) ⊆ C holds.
- For the Galois connection, we would need {id} ⊆ emlCore(C).
- But emlCore(C) = ⋂{A | C ⊆ cl(A)}. The set {id} is in this family, but so are other sets like {x ↦ 2x, x ↦ 0.5} (if they generate the same closure). The intersection could be empty or strictly smaller than {id}.
- More critically: there can exist A with C ⊆ cl(A) such that id ∉ A (e.g., A containing functions that compose to give id).

The fundamental issue is that cl(A) ⊆ cl(B) does not imply A ⊆ B. The closure is not injective on generators.

### 5.3 The Core as Intrinsic Content

Despite not being a right adjoint, the EML core has a natural interpretation: it is the set of functions that **must** appear (as generators) in any generating set whose closure contains C. This makes it a measure of "representational necessity."

The hierarchy

> emlCore(C) ⊆ minimalGeneratorsEq(C) ⊆ C (for closed C)

separates three levels of necessity:
- **Core**: universally necessary across all containment-generators
- **Minimal generators**: necessary across exact generators
- **Class membership**: derivable from the generators

## 6. Computational Experiments

### 6.1 Finite Closure Systems

To illustrate the theory, we implemented closure operators on finite sets and computed Galois connections, cores, and minimal generators.

**Example 1: Power set closure.** On P({1, 2, 3}), define cl(S) = S ∪ {all constants}. The closed sets form a lattice with 2³ = 8 elements. The core of any closed set equals itself minus the constants.

**Example 2: Polynomial closure.** On the set of polynomials up to degree n, define closure by polynomial arithmetic. The closed sets are precisely the polynomial rings ℝ[x]≤d for d ∈ {0, 1, ..., n}. The Galois connection reduces degree-checking to generator-checking.

### 6.2 Visualization

We provide Python scripts that:
1. Compute EML closures for small finite function sets
2. Visualize the lattice of closed sets as a Hasse diagram
3. Compute cores and minimal generators
4. Demonstrate the Galois connection biconditional

See `demo.py`, `algorithms.py`, and `applications.py` for implementations.

## 7. Discussion

### 7.1 Relationship to Formal Concept Analysis

The Galois insertion between generators and closed classes is structurally identical to the Galois connection between objects and attributes in Formal Concept Analysis (FCA). In FCA:
- Objects correspond to generator sets
- Attributes correspond to properties/functions in the closure
- Concepts correspond to closed classes
- The concept lattice corresponds to the lattice of EML-closed sets

This suggests that FCA algorithms (e.g., Ganter's algorithm for computing concept lattices) could be adapted for EML class enumeration.

### 7.2 Relationship to Abstract Interpretation

The Galois connection `cl(A) ⊆ C ↔ A ⊆ C` is precisely the adjunction used in abstract interpretation:
- The "concrete domain" is Set(ℝ → ℝ) ordered by ⊆
- The "abstract domain" is the subtype of closed sets
- The "abstraction function" is EMLClosure
- The "concretization function" is the inclusion

This means EML closure can serve as a certified abstraction for function-class analysis.

### 7.3 Limitations

1. The EML closure is defined syntactically (via inductive generation), not semantically. Two syntactically different generation trees may produce the same function. This means the closure is potentially "larger" than a semantic closure.

2. The core operator, while mathematically well-defined, may be difficult to compute for infinite function classes.

3. The current framework does not include continuous or differentiable restrictions on functions, which would be needed for applications to neural network expressivity.

## 8. Future Work

1. **Irredundant generators**: Prove existence and characterize irredundant generating sets under finiteness hypotheses.

2. **Closure dimension**: Define and compute the minimum cardinality of generating sets for specific function classes.

3. **Quantitative Nullstellensatz**: Connect zero sets of generators to zero sets of the closure.

4. **Complete lattice structure**: Construct the complete lattice of EML-closed sets using the Galois insertion.

5. **Algorithmic applications**: Develop algorithms for computing closures, cores, and minimal generators for finite or finitely-generated function classes.
