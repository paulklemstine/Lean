# Automatic Sequences and the Halting Problem: Decidability at the Finite-State Boundary

## Abstract

We formalize the theory of k-automatic sequences generated by Deterministic Finite Automata with Output (DFAOs) and establish key decidability results within a constructive proof framework. Our main contributions are: (1) a complete formalization of DFAO structure including the compositional processing lemma and the Myhill-Nerode principle for output equivalence; (2) a proof that the zero-in-sequence problem — "does a given value appear in a given automatic sequence?" — is decidable via reduction to finite graph reachability; (3) a pigeonhole-based pumping lemma showing that state repetition in DFA computations enables infinite value recurrence; (4) a proof that unary automatic sequences are exactly the eventually periodic sequences; (5) the introduction of *automatic complexity* as a novel measure of finite-state sequence complexity; and (6) the formulation of the morphic zero-in-sequence decidability conjecture as a precise mathematical statement. All key results are machine-verified in Lean 4 with Mathlib.

**Keywords:** automatic sequences, DFAO, decidability, k-kernel, pumping lemma, morphic sequences, automatic complexity

## 1. Introduction

Automatic sequences form a class of infinite sequences that can be generated by finite-state machines reading the base-k representation of the index. First studied systematically by Cobham (1972) and later developed by Allouche, Shallit, and others, these sequences occupy a privileged position at the intersection of automata theory, number theory, and combinatorics.

The fundamental appeal of automatic sequences lies in their dual nature: they are complex enough to exhibit rich mathematical structure (fractal self-similarity, algebraic properties of generating functions, connections to number theory via Christol's theorem) yet simple enough to admit decidable logical theories. This paper makes this decidability precise through formal proof.

### 1.1 Prior Work

The theory of automatic sequences is surveyed comprehensively in Allouche and Shallit (2003). Christol's theorem (1979) establishes that a formal power series over a finite field F_q is algebraic over F_q(x) if and only if its coefficient sequence is q-automatic. The Eilenberg theorem characterizes k-automaticity via finiteness of the k-kernel. Decidability results for first-order properties of automatic sequences were established by Büchi (1960) and extended by Bruyère et al.

Our contribution is a self-contained formalization of the core theory, emphasizing the decidability of value occurrence and the structural properties that make it possible.

## 2. Definitions

### 2.1 DFAO (Deterministic Finite Automaton with Output)

**Definition 2.1.** A *DFAO* over base k with output type α consists of:
- A finite state set Q = {0, 1, ..., s-1} with s ≥ 1
- A transition function δ : Q × {0,...,k-1} → Q
- An initial state q₀ ∈ Q
- An output function τ : Q → α

**Definition 2.2.** The *processing function* processFrom(q, w) processes a word w = d₁d₂...dₘ from state q:
- processFrom(q, ε) = q
- processFrom(q, dw') = processFrom(δ(q, d), w')

**Definition 2.3.** The *generated sequence* of a DFAO M with base k > 1 is:
a(n) = τ(processFrom(q₀, rep_k(n)))
where rep_k(n) is the base-k representation of n (MSB first), with rep_k(0) = ε.

### 2.2 k-Kernel

**Definition 2.4.** The *k-kernel* of a sequence a : ℕ → α is the set of subsequences:
ker_k(a) = {(n ↦ a(k^j · n + r)) : j ≥ 0, 0 ≤ r < k^j}

### 2.3 Automatic Complexity (Novel)

**Definition 2.5.** The *k-automatic complexity* AC_k(a) of a k-automatic sequence a is:
AC_k(a) = min{|Q| : M is a DFAO with state set Q generating a}

This is a finite-state analogue of Kolmogorov complexity restricted to the class of DFAO-computable sequences. Unlike Kolmogorov complexity, AC_k is always well-defined and finite for automatic sequences, and equals the size of the minimal DFAO (which is unique up to isomorphism by the Myhill-Nerode theorem).

### 2.4 State Equivalence

**Definition 2.6.** Two states q₁, q₂ in a DFAO M are *equivalent* (q₁ ≈ q₂) if:
∀ w ∈ {0,...,k-1}*, τ(processFrom(q₁, w)) = τ(processFrom(q₂, w))

## 3. Main Results

### 3.1 Compositionality of Processing (Theorem 1)

**Theorem 3.1** (processFrom_append). *For any DFAO M, state q, and words w₁, w₂:*
processFrom(q, w₁w₂) = processFrom(processFrom(q, w₁), w₂)

*Proof.* By induction on w₁. The base case w₁ = ε is immediate. For w₁ = dw₁', we have:
processFrom(q, dw₁'w₂) = processFrom(δ(q,d), w₁'w₂) = processFrom(processFrom(δ(q,d), w₁'), w₂) = processFrom(processFrom(q, dw₁'), w₂)
where the second equality uses the induction hypothesis. □

This seemingly simple lemma is the foundation of all compositional reasoning about DFAOs. It enables us to decompose long computations into shorter segments, which is essential for the pumping lemma and decidability results.

### 3.2 Myhill-Nerode Principle for DFAOs (Theorem 2)

**Theorem 3.2** (eval_eq_of_process_eq). *If two words w₁, w₂ lead to the same state in a DFAO M (i.e., process(w₁) = process(w₂)), then for all suffixes s:*
eval(w₁s) = eval(w₂s)

*Proof.* By compositionality (Theorem 3.1), eval(w₁s) = τ(processFrom(q₀, w₁s)) = τ(processFrom(processFrom(q₀, w₁), s)). Since processFrom(q₀, w₁) = processFrom(q₀, w₂) by hypothesis, the result follows. □

This is the DFAO analogue of the Myhill-Nerode theorem: the state captures all information about the past input that is relevant to future output. The number of equivalence classes of this relation gives the minimal DFAO size.

### 3.3 Decidability of Value Occurrence (Theorems 3-4)

**Theorem 3.3** (generatedSeq_values_finite). *For any DFAO M with base k > 1, the output values of the generated sequence are contained in the range of τ:*
∀ n, a(n) ∈ range(τ)

**Theorem 3.4** (generatedSeq_range_finite). *If value v appears in the generated sequence, then some state maps to v:*
(∃ n, a(n) = v) → (∃ q ∈ Q, τ(q) = v)

*Corollary.* The zero-in-sequence problem for automatic sequences is decidable: given a DFAO M and target value v, check whether any state q in the reachable set has τ(q) = v. The reachable set is computable by BFS in O(|Q| · k) time.

### 3.4 Pigeonhole on State Sequences (Theorem 5)

**Theorem 3.5** (dfao_state_repeat). *If a DFAO with s states processes a word of length ≥ s, then some state is visited twice:*
∃ i < j ≤ |w|, processFrom(q₀, w[0..i)) = processFrom(q₀, w[0..j))

*Proof.* The function i ↦ processFrom(q₀, w[0..i)) maps {0, 1, ..., |w|} (a set of size |w| + 1 > s) into Q (a set of size s). By the pigeonhole principle, two distinct indices must map to the same state. □

This theorem is the foundation of all pumping arguments. The repeated state creates a "loop" of length j - i that can be iterated, inserted, or removed without changing the final state, and hence without changing the output for any suffix.

### 3.5 Eventually Periodic Unary Sequences (Theorem 6)

**Theorem 3.6** (unary_dfao_eventually_periodic). *Every unary DFAO (k = 1) generates an eventually periodic output sequence:*
∃ p > 0, ∃ N, ∀ n ≥ N, τ(δⁿ(q₀, 0)) = τ(δⁿ⁺ᵖ(q₀, 0))

*Proof.* In base 1, the n-th term corresponds to processing n copies of the digit 0. The state after n steps is δ^n(q₀, 0), which is a sequence in the finite set Q. By the pigeonhole principle, there exist i < j with δ^i(q₀, 0) = δ^j(q₀, 0). Setting N = i and p = j - i, we have δ^{n+p}(q₀, 0) = δ^n(q₀, 0) for all n ≥ N, since the state after n steps determines all subsequent states.

The key inductive step: for n ≥ N, if δ^n(q₀, 0) = δ^{n+p}(q₀, 0), then applying δ(·, 0) to both sides gives δ^{n+1}(q₀, 0) = δ^{n+1+p}(q₀, 0). □

This result shows that the richness of automatic sequences requires base k ≥ 2. In unary, the tree structure of digit representations degenerates to a line, and the sequence collapses to eventual periodicity.

### 3.6 State Equivalence is an Equivalence Relation (Theorem 7)

**Theorem 3.7** (stateEquiv_equiv). *State equivalence ≈ is an equivalence relation on Q.*

*Proof.* Reflexivity, symmetry, and transitivity follow immediately from the corresponding properties of equality on α. □

While the proof is straightforward, the result is essential: it guarantees that the quotient Q/≈ is well-defined, which underlies the existence and uniqueness of the minimal DFAO (the Myhill-Nerode theorem for DFAOs).

## 4. Algorithms

### 4.1 Zero-in-Sequence Decision Algorithm

```
Algorithm: ZERO-IN-SEQUENCE(M, v)
Input: DFAO M = (Q, k, δ, q₀, τ), target value v
Output: (exists, witness)

1. Initialize visited = {q₀}, queue = [q₀], path[q₀] = []
2. While queue not empty:
   a. q ← dequeue(queue)
   b. If τ(q) = v: return (true, digits_to_number(path[q]))
   c. For each digit d ∈ {0,...,k-1}:
      q' ← δ(q, d)
      If q' ∉ visited:
        visited ← visited ∪ {q'}
        path[q'] ← path[q] ++ [d]
        enqueue(queue, q')
3. Return (false, ⊥)

Complexity: O(|Q| · k) time, O(|Q|) space
```

### 4.2 k-Kernel Computation Algorithm

```
Algorithm: K-KERNEL(a, k, max_depth, check_length)
Input: Sequence a, base k, maximum depth, check length
Output: Estimated kernel as set of distinct subsequences

1. kernel ← {}
2. For j = 0, 1, ..., max_depth:
   For r = 0, 1, ..., k^j - 1:
     subseq ← [a(k^j · n + r) for n = 0,...,check_length-1]
     Add subseq to kernel (as set element)
3. Return kernel

Complexity: O(max_depth · k^max_depth · check_length)
```

### 4.3 Product DFAO Construction

```
Algorithm: PRODUCT-DFAO(M₁, M₂)
Input: DFAOs M₁ = (Q₁, k, δ₁, q₀¹, τ₁), M₂ = (Q₂, k, δ₂, q₀², τ₂)
Output: Product DFAO simulating both in parallel

1. Q ← Q₁ × Q₂ (encoded as {0,...,|Q₁|·|Q₂|-1})
2. For each (q₁, q₂) and digit d:
   δ((q₁,q₂), d) ← (δ₁(q₁,d), δ₂(q₂,d))
3. q₀ ← (q₀¹, q₀²)
4. τ(q₁, q₂) ← (τ₁(q₁), τ₂(q₂))
5. Return (Q, k, δ, q₀, τ)

Complexity: O(|Q₁| · |Q₂| · k) construction time
```

## 5. Discussion

### 5.1 The Decidability Frontier

Our results confirm that automatic sequences have a decidable zero-in-sequence problem, and more generally, that any property reducible to state reachability is decidable for DFAOs. This aligns with the broader result (Büchi's theorem) that the first-order theory of (ℕ, +, V_k) is decidable, where V_k(n) is the largest power of k dividing n.

The open question is whether decidability extends to morphic sequences. Our formalization of the morphic zero-in-sequence conjecture provides a precise mathematical statement:

> For any morphism σ on a finite alphabet, any coding c, and any target value v, it is decidable whether v appears in the coded fixed point of σ.

The key difficulty is that non-uniform morphisms can produce words of varying lengths, breaking the clean correspondence between digit positions and automaton transitions that enables the DFAO decidability proof.

### 5.2 Automatic Complexity

The automatic complexity measure AC_k(a) introduced here has several attractive properties:
- **Computability**: Unlike Kolmogorov complexity, AC_k is computable (by exhaustive search over DFAOs of increasing size)
- **Uniqueness**: The minimal DFAO is unique up to isomorphism (by the Myhill-Nerode theorem)
- **Structure**: AC_k captures the "finite-state essence" of a sequence

Open questions include:
- Is AC_k(a ⊕ b) ≤ AC_k(a) · AC_k(b) for pointwise operations ⊕? (True for the product construction, which gives an upper bound.)
- What is the relationship between AC_k and factor complexity?
- For which sequences does AC_k = AC_{k'} for different bases k, k'?

### 5.3 Connections to Christol's Theorem

Christol's theorem states that a power series Σ aₙ xⁿ over F_q is algebraic over F_q(x) if and only if (aₙ) is q-automatic. Our DFAO formalization provides the automata-theoretic side of this correspondence. A full formalization of Christol's theorem would require connecting our DFAO framework to the algebraic theory of formal power series over finite fields — a substantial project that would bridge algebra and automata theory within a single formal framework.
