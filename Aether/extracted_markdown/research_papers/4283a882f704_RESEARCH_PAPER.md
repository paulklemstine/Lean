# Constructive Foundations from Homotopy Type Theory: A Self-Contained Identity-Type Fragment

## Abstract

We present a self-contained fragment of Homotopy Type Theory (HoTT) developed
without recourse to any ambient equality possessing definitional proof
irrelevance. The central design decision is to replace the native propositional
equality — which validates Uniqueness of Identity Proofs (UIP / Axiom K) and
therefore collapses every type to a set — with a *synthetic Martin-Löf identity
type* `Path`, declared as an indexed inductive family valued in the universe of
**data** rather than the universe of **propositions**. For such a type UIP is not
derivable, so `Path` genuinely models the homotopical identity type, and every
groupoid and coherence law must be established by honest path induction. On this
foundation we prove four load-bearing results: (1) the coincidence of the naive
and the structural notions of equivalence (a map admits a quasi-inverse iff all
its fibers are contractible); (2) the *full biconditional* Fundamental Theorem of
Identity Types (a fibrewise family is a fibrewise equivalence iff its total space
is contractible); (3) equivalence induction as the computational consequence of a
univalence hypothesis; and (4) propositional truncation as a genuine higher
inductive type, realized as a quotient, together with its recursion principle and
a uniqueness theorem certifying its universal property. We describe the proof
architecture — in particular the *adjointification* of quasi-inverses to
half-adjoint equivalences and the *retract-based* total-to-fibrewise transfer —
and the recurring "contractibility juggling" method that organizes the
development. We close with applications (encode–decode, the Structure Identity
Principle) and a program of falsifiable extensions.

**Keywords:** homotopy type theory, identity types, univalence, equivalence,
contractibility, higher inductive types, propositional truncation, adjoint
equivalence, encode–decode.

## 1. Introduction

### 1.1 The problem of equality

Martin-Löf intensional type theory equips every type `A` with an identity type
former that, for `a b : A`, produces a type of *identifications* of `a` with `b`.
The radical observation of Homotopy Type Theory is that this identity type is not,
in general, a mere truth value: it can carry nontrivial structure, behaving like
the path space of a topological space. Types become ∞-groupoids; equalities
become paths; equalities between equalities become homotopies; and so on without
end.

This perspective is incompatible with **Uniqueness of Identity Proofs** (UIP),
equivalently **Axiom K**, which asserts that any two inhabitants of an identity
type are themselves equal. UIP forces every type to be a *set* (0-truncated) and
annihilates all higher structure. Many proof environments make UIP *definitionally
true* for their native equality by giving it proof irrelevance. Consequently, one
cannot do genuine HoTT with such an equality: every homotopical statement becomes
either trivial or vacuous.

### 1.2 The synthetic remedy

Our development sidesteps this trap entirely. We do **not** use any ambient
equality. Instead we introduce a synthetic identity type `Path`, an indexed
inductive family valued in `Type` (the universe of data), generated by a single
constructor `refl`. Because `Path` is a `Type`-valued inductive, the eliminator
`Path.rec` is exactly the J-rule (path induction); crucially, **K is not
derivable** for it. All structure is therefore honest: every coherence law is a
theorem proved by path induction, not an artifact of proof irrelevance.

The development is deliberately library-free. No external mathematical library is
imported; every result is derived from the synthetic path calculus alone.

### 1.3 Contributions

1. A complete, self-contained synthetic groupoid calculus (Section 3), including a
   second-level (2-cell) calculus sufficient for coherence proofs.
2. `equiv_iff_contr_fibers`: the coincidence of quasi-invertibility and fiberwise
   contractibility (Section 5), via adjointification.
3. `fundamental_theorem_id`: the *biconditional* Fundamental Theorem of Identity
   Types (Section 6).
4. `equivalence_induction`: the elimination principle unlocked by a `Univalence`
   hypothesis (Section 7).
5. `PTrunc`, `PTrunc.rec`, `PTrunc.rec_unique`: propositional truncation as a
   genuine higher inductive type with a verified universal property (Section 8).

All non-truncation results are axiom-free; the truncation results use only
`Quot.sound`, which is unavoidable for a quotient-as-HIT realization.

## 2. The synthetic identity type

**Definition 2.1 (Identity type).** For a type `A : Type u`, the identity type is
the indexed inductive family
```
inductive Path {A : Type u} : A → A → Type u where
  | refl (a : A) : Path a a
```
We write `Path a b` for the type of paths from `a` to `b`. Its eliminator
`Path.rec` is *path induction*: to construct, for all `b` and all `p : Path a b`,
an element of a family `D b p`, it suffices to supply an element of `D a (refl a)`.

Because `Path` lands in `Type`, no proof-irrelevance principle applies, and Axiom
K is not available. Throughout, equalities denoted by an ordinary `=` between two
*paths* are themselves inhabitants of higher `Path` types (2-cells); we say two
paths are *connected* when such a witness exists.

## 3. Groupoid and coherence structure

We define the basic operations by the recursion pattern (i.e. by matching on
`refl`):

**Definition 3.1.**
- *Reversal:* `symm : Path a b → Path b a`, with `symm (refl a) = refl a`.
- *Concatenation:* `trans : Path a b → Path b c → Path a c`, with
  `trans (refl a) q = q`.
- *Action on paths:* for `f : A → B`, `ap f : Path a b → Path (f a) (f b)`, with
  `ap f (refl a) = refl (f a)`.
- *Transport:* for `P : A → Type v`, `transport P : Path a b → P a → P b`, with
  `transport P (refl a) x = x`.

**Proposition 3.2 (Groupoid laws).** The following hold:
1. `trans (refl a) p = p` — *definitionally*.
2. `Path (trans p (refl b)) p` — right unit (a 2-cell).
3. `Path (trans p (symm p)) (refl a)` — right inverse law.
4. `Path (trans (symm p) p) (refl b)` — left inverse law.
5. `Path (trans (trans p q) r) (trans p (trans q r))` — associativity.

*Proof sketch.* Each is proved by path induction: `cases` on the relevant path
reduces both sides to `refl`, after which the witness is `refl`. The left unit law
holds definitionally because it is the defining clause of `trans`. ∎

**Proposition 3.3 (Functoriality).**
1. `Path (ap g (ap f p)) (ap (g ∘ f) p)` — `ap` respects composition.
2. `Path (ap (id) p) p` — `ap` of the identity.

*Proof sketch.* Path induction on `p`. ∎

For the coherence proofs in Section 5 we require a small **2-cell calculus**:

**Proposition 3.4 (Naturality of homotopies).** For `f g : A → B`, a homotopy
`H : ∀ x, Path (f x) (g x)`, and `p : Path a b`, the naturality square commutes:
```
Path (trans (H a) (ap g p)) (trans (ap f p) (H b)).
```
*Proof sketch.* Path induction on `p`; the square degenerates to the right unit
law applied to `H a`. ∎

**Proposition 3.5 (Right cancellation).** If `Path (trans p r) (trans q r)` then
`Path p q`. *Proof sketch.* Path induction on `r`, then compose with the right
unit laws. ∎

**Proposition 3.6 (Retraction naturality, `eta_natural`).** For `f : A → B`,
`g : B → A`, and a homotopy `eta : ∀ a, Path (g (f a)) a`, one has, for every `a`,
```
Path (eta (g (f a))) (ap (g ∘ f) (eta a)).
```
*Proof sketch.* Instantiate naturality (3.4) with the homotopy `eta` at the path
`eta a`, simplify the `ap (id)` term via 3.3(2), and cancel `eta a` on the right
using 3.5. This is the load-bearing identity for adjointification. ∎

## 4. Contractibility, fibers, and equivalence

**Definition 4.1 (Contractibility).** A type `A` is *contractible*, `IsContr A`,
if there is a center `c : A` together with a contraction
`∀ x, Path c x`. Contractible types are the homotopical "points."

**Definition 4.2 (Fiber).** For `f : A → B` and `b : B`, the fiber is
`fib f b := Σ (a : A), Path (f a) b`.

**Definition 4.3 (Quasi-inverse / naive equivalence).** A *quasi-inverse* of
`f : A → B` is `g : B → A` with homotopies `∀ a, Path (g (f a)) a` and
`∀ b, Path (f (g b)) b`. We write `QInv f` for this data and `A ≃ₕ B` for the type
of maps equipped with a quasi-inverse.

**Definition 4.4 (Good equivalence).** `f` *is an equivalence*, `IsEquiv f`, if
every fiber `fib f b` is contractible.

**Definition 4.5 (Half-adjoint equivalence).** `f` is a *half-adjoint equivalence*
(`IsHAE f`) if it has `g`, homotopies `eta : ∀ a, Path (g (f a)) a` and
`eps : ∀ b, Path (f (g b)) b`, and a coherence
`tau : ∀ a, Path (eps (f a)) (ap f (eta a))` linking them. The role of `IsHAE` is
to interpolate between `QInv` (too little coherence) and `IsEquiv` (a property).

A central foundational fact is:

**Proposition 4.6 (`singleton_contr`).** For fixed `a : A`, the *based path space*
`Σ (x : A), Path a x` is contractible, with center `(a, refl a)`.
*Proof sketch.* The contraction `∀ (y : Σ x, Path a x), Path (a, refl a) y` is
constructed by path induction on the path component of `y`. ∎

**Proposition 4.7 (Transfer lemmas).**
1. `isContr_of_qinv`: contractibility transports along a quasi-inverse.
2. `isContr_of_retract`: if `A` is a retract of a contractible type, `A` is
   contractible.
*Proof sketches.* (1) Map the center across and build the contraction by composing
the given homotopies. (2) Take the image of the center; the retraction homotopy
supplies the contraction. ∎

## 5. Coincidence of the two notions of equivalence

The first headline theorem identifies the naive and structural definitions.

**Theorem 5.1 (`equiv_iff_contr_fibers`).** For `f : A → B`,
```
QInv f  ⇔  IsEquiv f,
```
i.e. `f` has a quasi-inverse if and only if every fiber of `f` is contractible.

The easy direction is:

**Lemma 5.2 (`qinv_of_isEquiv`).** If every fiber of `f` is contractible, then `f`
has a quasi-inverse. *Proof sketch.* The center of `fib f b` provides, for each
`b`, a preimage `g b` and a path `f (g b) = b`; contractibility of the fiber over
`f a` containing `(a, refl)` yields `g (f a) = a`. ∎

The hard direction must pass through adjointification, because an arbitrary
quasi-inverse lacks the coherence needed to prove fibers contractible directly.

**Lemma 5.3 (Adjointification, `qinv_to_ishae`).** A quasi-inverse upgrades to a
half-adjoint equivalence: `QInv f → IsHAE f`.

*Proof sketch.* Given `g, eta, eps`, keep `g` and `eta` but **correct** the right
homotopy to
```
eps' b := (eps (f (g b)))⁻¹ ⬝ ap f (eta (g b)) ⬝ eps b.
```
One then proves the triangle identity `eps' (f a) = ap f (eta a)` (`adjoint_triangle`).
The proof is a 2-cell computation: rewrite `ap f (eta (g (f a)))` using
`eta_natural` (3.6) and the functoriality laws (3.3), reassociate using 3.2(5),
apply naturality of `eps` (3.4) at `ap f (eta a)`, and cancel. This is the HoTT
Theorem 4.2.3 path algebra, carried out explicitly in the 2-cell calculus of
Section 3. ∎

**Lemma 5.4 (`qequiv_contr_fiber`).** A half-adjoint equivalence has contractible
fibers. *Proof sketch.* Fix `b`; the center is `(g b, eps b)`. Given any
`(a, p) : fib f b`, the triangle coherence `tau` is exactly what is needed to
build a path `(g b, eps b) = (a, p)` in the total space of the fiber by path
induction on `p`. Without `tau` this step is unprovable, which is precisely why
`IsHAE` (not `QInv`) is the correct intermediary. ∎

*Proof of Theorem 5.1.* Compose 5.3 and 5.4 for `QInv f → IsEquiv f`; use 5.2 for
the converse. ∎

**Remark 5.5.** Theorem 5.1 shows `≃ₕ` (quasi-invertible maps) and the
property-level `IsEquiv` pick out the same maps. The practical payoff is that
"being an equivalence" may henceforth be treated as a *proposition*, enabling the
property-level reasoning used in closure laws (2-out-of-3, 2-out-of-6).

## 6. The Fundamental Theorem of Identity Types

**Definition 6.1 (Fibrewise equivalence).** A family
`f : ∀ x, Path a x → C x` is a *fibrewise equivalence* if each
`f x : Path a x → C x` is an equivalence (has contractible fibers, equivalently a
quasi-inverse).

**Theorem 6.2 (`fundamental_theorem_id`).** For a type family `C : A → Type` with
a point `c₀ : C a` inducing `f x := transport` of the canonical map, the following
are equivalent:
```
(f is a fibrewise equivalence)   ⇔   IsContr (Σ (x : A), C x).
```

*Proof sketch.*
- **(⇒)** If every `f x` is an equivalence, then `f` induces an equivalence of
  total spaces `(Σ x, Path a x) ≃ (Σ x, C x)`. The domain is contractible by
  `singleton_contr` (4.6), and contractibility transports across the equivalence
  by `isContr_of_qinv` (4.7).
- **(⇐)** This is the *manufacturing* direction. Suppose `Σ x, C x` is
  contractible. The total map `total f : (Σ x, Path a x) → (Σ x, C x)` goes
  between two contractible types, hence is an equivalence. The key technical step,
  `fibrewise_of_total`, transfers the total-space equivalence back to each fiber.
  We discovered that a *retract* — requiring only a single homotopy that collapses
  to `refl` under path induction — suffices for this transfer, avoiding the full
  fiber-equivalence machinery (this is the constructive content of HoTT 4.7.7). ∎

**Significance.** The backward direction is a *tool*: from a single contractibility
witness it *produces* the equivalences `Path a x ≃ C x`. This is the formal engine
of the encode–decode method (Section 9.1). The one-directional version available
in many treatments is insufficient for this purpose; the full biconditional is
required.

## 7. Univalence and equivalence induction

We do not assume univalence globally; we package it as a hypothesis and extract
its computational consequence.

**Definition 7.1 (`Univalence`).** A `Univalence` structure for a universe
provides, for all `A B`, an inverse to the canonical map
`idToEquiv : Path A B → (A ≃ₕ B)`, exhibiting it as an equivalence. Concretely it
supplies `toId : (A ≃ₕ B) → Path A B` with the relevant homotopies.

**Theorem 7.2 (`equivalence_induction`).** Assume a `Univalence` structure. Let
`A` be fixed and `P : ∀ B, (A ≃ₕ B) → Type` a motive. To prove `P B e` for every
`B` and every equivalence `e : A ≃ₕ B`, it suffices to prove the base case
`P A (idEquiv A)`.

*Proof sketch.* By univalence, `e = idToEquiv (toId e)` and `toId e : Path A B`.
Path induction on `toId e` reduces `B` to `A` and the equivalence to
`idToEquiv (refl A)`, which the homotopies of the `Univalence` structure connect
to `idEquiv A`. Transport the assumed base case along this connection. ∎

**Remark 7.3 (β-rule).** Applied to the identity equivalence, the eliminator
returns the base case up to a path; under a strengthened *coherent* `Univalence`
carrying `idToEquiv (toId (refl A)) = refl A` as a left-inverse law, this can be
made to hold definitionally (a stated future direction).

Equivalence induction is the principle that justifies "without loss of generality,
assume the equivalence is the identity," and is the engine of the Structure
Identity Principle (Section 9.2).

## 8. Propositional truncation as a higher inductive type

**Definition 8.1 (Proposition / h-prop).** A type `P` *is a proposition*,
`IsProp P`, if `∀ (x y : P), Path x y`: any two inhabitants are connected.

**Definition 8.2 (Propositional truncation, `PTrunc`).** For a type `A`, define
`‖A‖ := PTrunc A` as the quotient of `A` by the total relation `fun _ _ => True`,
which forcibly identifies all points. The constructor `|·| : A → ‖A‖` is the
quotient map.

**Proposition 8.3.** `‖A‖` is a proposition: any two points are connected (using
the quotient's `Quot.sound` on the total relation).

**Theorem 8.4 (Recursion, `PTrunc.rec`).** Let `P` be a proposition and
`f : A → P`. Then there is a map `PTrunc.rec : ‖A‖ → P` with
`PTrunc.rec |a| = f a`. *Proof sketch.* Since `P` is a proposition, `f` respects
the total relation (any two outputs are connected), so it factors through the
quotient by its universal property. ∎

**Theorem 8.5 (Uniqueness, `PTrunc.rec_unique`).** Any two maps `‖A‖ → P` into a
proposition that agree on the image of `|·|` are connected pointwise; hence
`PTrunc.rec` is the unique extension of `f`. *Proof sketch.* For `x : ‖A‖`, both
maps land in `P`, where any two points are connected; uniqueness is then immediate
and the recursor is pinned down by its computation rule. ∎

Together 8.4 and 8.5 establish the **universal property** of propositional
truncation: `‖·‖` is left adjoint to the inclusion of propositions into types.
This certifies `PTrunc` as the genuine `(-1)`-truncation, not an accidental
quotient.

## 9. Applications

### 9.1 Encode–decode

Theorem 6.2(⇐) turns identity-type computation into a recipe:

1. **Guess** a family `C : A → Type` (the "codes") with a base code `c₀ : C a`.
2. **Verify** that `Σ x, C x` is contractible (one witness).
3. **Conclude**, for free, `Path a x ≃ C x` for all `x`.

For example, for the booleans the codes are `C true = Unit`, `C false = Empty`
(relative to base point `true`), whose total space is contractible, yielding the
expected description of `Path true x`. The method scales to coproducts and to
finite types `Fin n`, where it produces closed-form codes for identity types with
direct enumerative consequences. The demonstration code accompanying this paper
realizes these codes in a decidable (set-level) model.

### 9.2 The Structure Identity Principle

For a one-sorted algebraic signature (e.g. monoids), an isomorphism of structures
is precisely an equivalence of carriers commuting with the operations. Under
`Univalence`, such an isomorphism induces a `Path` of structures, and
`equivalence_induction` (7.2) reduces "prove property `P` of an isomorphic
structure" to "prove `P` of the identity isomorphism." Transport of structure thus
collapses to a single base case, connecting this foundational fragment directly to
algebraic developments.

### 9.3 Function extensionality from univalence

The biconditional Fundamental Theorem (6.2) is the precise engine of Voevodsky's
theorem that univalence implies function extensionality: the map relating a
function type to a based-path total space is a fibrewise equivalence over a
contractible base, so `funext` for maps into the universe follows. The
one-directional theorem is insufficient here; the manufacturing direction is
essential.

## 10. Proof architecture and methodology

Two structural observations organize the development.

**Contractibility juggling.** Nearly every hard theorem reduces to transporting
`IsContr` along a quasi-inverse (`isContr_of_qinv`) or a retract
(`isContr_of_retract`), seeded by the single workhorse `singleton_contr` (4.6).
The art is recognizing when a complicated space is secretly contractible.

**Where the difficulty concentrates.** The genuinely delicate content lives in two
places. First, **adjointification** (5.3), the HoTT 4.2.3 path algebra, which
forced construction of the 2-cell calculus (`trans_assoc`, `symm_trans`,
`cancel_right`, `homotopy_natural`, `eta_natural`). Second, the
**total-to-fibrewise transfer** (`fibrewise_of_total`, 6.2⇐), where a *retract*
turned out to suffice, sidestepping a full fiber equivalence.

**Principal failure mode.** Attempting `QInv → IsEquiv` *directly* cannot be closed
without the adjoint coherence `tau`. This is not a stylistic preference: the
half-adjoint structure `IsHAE` is a *necessary* intermediary, which is why
adjointification is unavoidable.

**Axiom hygiene.** The equivalence and identity-type theorems are axiom-free; the
truncation results use only `Quot.sound`, which is intrinsic to any
quotient-as-HIT realization and is permitted.

## 11. Discussion and future work

The fragment demonstrates that the central theorems of HoTT's identity-type layer
can be erected on a single primitive — path induction over a `Type`-valued
identity type — with nothing borrowed. Several extensions are immediate and
falsifiable:

1. **A computation rule for equivalence induction.** Prove the β-rule for the
   eliminator propositionally, and definitionally under a coherent `Univalence`;
   derive the 2-out-of-3 and 2-out-of-6 closure laws for `≃ₕ` directly from
   `equiv_iff_contr_fibers`, exploiting that "being an equivalence" is now a
   proposition.
2. **The n-truncation hierarchy.** Define the 0-truncation (set truncation) by the
   mere-equality relation and prove its universal property; build general
   `n`-truncation by hub-and-spoke and prove recursion into `n`-types. `rec_unique`
   is the `n = -1` instance of a uniform lifting property.
3. **The Structure Identity Principle.** Formalize, for one-sorted signatures,
   that isomorphic structures are equal, transporting all properties by
   `equivalence_induction` — a bridge to algebra.
4. **Voevodsky's theorem.** Derive function extensionality from a synthetic
   `Univalence` without ambient `funext`, via `fundamental_theorem_id`.
5. **Encode–decode for concrete types.** Use the manufacturing direction of
   `fundamental_theorem_id` to read off identity types of `Bool`, `Nat`, and
   `Fin n` with enumerative consequences.

Each direction reuses an already-validated schema and varies a single parameter,
testing the robustness of the contractibility-juggling method.

## 12. Conclusion

We have assembled a compact, self-contained foundation in which equality is
genuinely homotopical: paths form an ∞-groupoid; the naive and structural notions
of equivalence coincide; identity types are computed by a biconditional
Fundamental Theorem; univalence yields equivalence induction; and a genuine higher
inductive type — propositional truncation — is constructed with a verified
universal property. The architecture is uniform, the difficulties are localized
and understood, and the axiom footprint is minimal. The development stands as a
miniature but complete witness that the homotopical conception of equality can be
founded from a single primitive.
