# Causal Integration Lattices: A Formal Framework for Integrated Information Theory

## Abstract

We introduce the **Integration Complex**, a novel mathematical object that captures the structure of integrated information in causal networks. Given a weighted directed graph (causal network), the Integration Complex is the collection of subsets with positive integrated information Φ > 0. We establish several fundamental properties: (1) the cut symmetry theorem, showing Φ is invariant under partition complementation; (2) the composition collapse theorem, proving that causally independent systems have zero integrated information; (3) the weight monotonicity theorem, establishing that Φ is monotone in edge weights; and (4) the non-hereditary theorem, demonstrating that the Integration Complex fails the subset-closure property of simplicial complexes. All results are formalized and machine-verified in Lean 4 with the Mathlib library. These results provide the first rigorous mathematical foundation for the structural postulates of Integrated Information Theory (IIT).

## 1. Introduction

Integrated Information Theory (IIT), introduced by Tononi [1], proposes that consciousness corresponds to integrated information — the amount of information generated by a system above and beyond its parts. The theory's central quantity, Φ (phi), measures the minimum information lost across any bipartition of the system, capturing the irreducibility of the system's causal structure.

While IIT has been extensively studied computationally [2, 3], its mathematical foundations have received less rigorous treatment. Key structural claims — such as the exclusion postulate (consciousness corresponds to the partition achieving minimum Φ) and the composition postulate (only irreducible mechanisms contribute) — have been stated informally but not proven from first principles.

This paper addresses this gap by introducing a formal mathematical framework based on weighted directed graphs. Our main contributions are:

1. **The Integration Complex**: A novel mathematical object that encodes which subsets of a causal system are "integrated" (have Φ > 0). Unlike simplicial complexes, it is not hereditary.

2. **Composition Collapse Theorem**: A formal proof that causally independent systems have zero integrated information, establishing the composition postulate as a mathematical theorem.

3. **Weight Monotonicity**: A proof that Φ is monotone in edge weights, giving the space of causal networks a natural partial order structure.

4. **Non-Hereditary Theorem**: A constructive proof that the Integration Complex fails the hereditary property, via an explicit counterexample (the "bridge node" construction).

## 2. Definitions

### 2.1 Causal Networks

**Definition 2.1** (Causal Network). A *causal network* on n nodes is a pair C = (V, w) where V = Fin n and w : V × V → ℕ is a weight function satisfying w(i, i) = 0 for all i ∈ V (no self-loops).

The weight w(i, j) represents the strength of causal influence from node i to node j. The no-self-loop condition reflects the principle that a system element's causal influence on itself is not part of the integration structure.

### 2.2 Cut Values and Integrated Information

**Definition 2.2** (Cut Value). For a causal network C and a subset A ⊆ V, the *cut value* is:

    cutValue(C, A) = Σ_{a ∈ A} Σ_{b ∈ Aᶜ} [w(a,b) + w(b,a)]

This counts the total bidirectional causal influence crossing the partition (A, Aᶜ).

**Definition 2.3** (Integrated Information). The *integrated information* of C is:

    Φ(C) = min { cutValue(C, A) : A ≠ ∅, A ≠ V }

When n ≤ 1, Φ(C) = 0 by convention (no non-trivial partitions exist).

**Definition 2.4** (Subsystem Integration). For S ⊆ V with |S| ≥ 2, the *subsystem integrated information* is:

    Φ_S(C) = min { subCutValue(C, S, A) : ∅ ⊂ A ⊂ S }

where subCutValue(C, S, A) = Σ_{a ∈ A} Σ_{b ∈ S\A} [w(a,b) + w(b,a)].

### 2.3 The Integration Complex

**Definition 2.5** (Integration Complex). The *Integration Complex* of a causal network C is:

    IC(C) = { S ⊆ V : |S| ≥ 2 and Φ_S(C) > 0 }

This is the collection of subsets that exhibit genuine causal integration.

### 2.4 Block Diagonal Networks

**Definition 2.6** (Block Diagonal). Given causal networks C₁ on n₁ nodes and C₂ on n₂ nodes, the *block diagonal* network C₁ ⊕ C₂ on n₁ + n₂ nodes is defined by:

    w(i, j) = C₁.weight(i, j)     if i, j < n₁
    w(i, j) = C₂.weight(i-n₁, j-n₁)  if i, j ≥ n₁
    w(i, j) = 0                    otherwise

## 3. Main Results

### 3.1 Cut Symmetry (Theorem 1)

**Theorem 3.1** (Cut Symmetry). *For any causal network C and subset A ⊆ V:*
    
    cutValue(C, A) = cutValue(C, Aᶜ)

*Proof sketch.* By expanding both sides, cutValue(C, A) = Σ_{a∈A} Σ_{b∈Aᶜ} [w(a,b) + w(b,a)] and cutValue(C, Aᶜ) = Σ_{a∈Aᶜ} Σ_{b∈A} [w(a,b) + w(b,a)]. These are equal by commutativity of the double sum (Fubini) and commutativity of addition. □

**PEGB Analysis:**
- **P (Proof)**: Formally verified in Lean 4, using `Finset.sum_comm` and `add_comm`.
- **E (Example)**: For the complete graph K₃ with all weights 1, cutValue({0}, {1,2}) = 4 = cutValue({1,2}, {0}).
- **G (Generalization)**: The result generalizes to any commutative semiring-valued weight function, not just ℕ.
- **B (Boundary)**: For directed (asymmetric) weights, the symmetry still holds because the definition sums *both* directions. If we used only outgoing edges, symmetry would fail.

### 3.2 Weight Monotonicity (Theorem 2)

**Theorem 3.2** (Weight Monotonicity). *If C₁.weight(i,j) ≤ C₂.weight(i,j) for all i, j, then Φ(C₁) ≤ Φ(C₂).*

*Proof sketch.* For any partition A, cutValue(C₁, A) ≤ cutValue(C₂, A) by summing the pointwise bounds. Therefore Φ(C₁) = min_A cutValue(C₁, A) ≤ cutValue(C₁, A*) ≤ cutValue(C₂, A*), where A* is any partition. Taking A* to minimize cutValue(C₂, ·), we get Φ(C₁) ≤ Φ(C₂). □

**PEGB Analysis:**
- **P (Proof)**: Formal proof uses `Finset.sum_le_sum` twice and `Nat.add_le_add`.
- **E (Example)**: Adding edge (0,2) with weight 1 to the path 0→1→2 increases Φ from 1 to 2.
- **G (Generalization)**: Extends to real-valued weights with the same proof structure.
- **B (Boundary)**: The inequality is NOT strict in general: adding an edge parallel to the minimum cut doesn't change Φ.

### 3.3 Composition Collapse (Theorem 3)

**Theorem 3.3** (Composition Collapse). *For causal networks C₁ (n₁ ≥ 1 nodes) and C₂ (n₂ ≥ 1 nodes), the block diagonal satisfies Φ(C₁ ⊕ C₂) = 0.*

*Proof sketch.* The partition A = {i : i < n₁} is non-trivial (since both blocks are non-empty). For any a ∈ A and b ∈ Aᶜ, a is in the first block and b is in the second, so both w(a,b) = 0 and w(b,a) = 0 by the block diagonal construction. Hence cutValue(C₁ ⊕ C₂, A) = 0, and since Φ is the minimum over non-trivial partitions, Φ = 0. □

**PEGB Analysis:**
- **P (Proof)**: Formal proof constructs the partition explicitly and applies the disconnection theorem.
- **E (Example)**: Two triangles K₃ ⊕ K₃ each have Φ = 4, but their disjoint union has Φ = 0.
- **G (Generalization)**: More generally, if ANY non-trivial partition has zero cut, then Φ = 0. The composition collapse is a special case.
- **B (Boundary)**: Adding even a single edge between the blocks can make Φ > 0, showing the collapse is fragile.

### 3.4 Non-Hereditary Theorem (Theorem 4)

**Theorem 3.4** (Integration Complex is Not Hereditary). *There exist a causal network C and subsets T ⊆ S such that S ∈ IC(C) but T ∉ IC(C).*

*Proof sketch.* Take the "bridge" network on 3 nodes: w(0,1) = w(1,0) = w(1,2) = w(2,1) = 1, all other weights 0. The full set S = {0,1,2} satisfies Φ_S > 0 (every bipartition cuts at least one edge). But T = {0,2} satisfies Φ_T = 0 (no edges between 0 and 2). Hence S ∈ IC(C) and T ⊆ S but T ∉ IC(C). □

**PEGB Analysis:**
- **P (Proof)**: Formally verified by explicit construction and computation.
- **E (Example)**: The bridge network 0↔1↔2 with no 0↔2 edge. Full system has Φ = 1, but {0,2} has Φ = 0.
- **G (Generalization)**: For any n ≥ 3, the path graph provides a non-hereditary example. More generally, any graph with a cut vertex yields non-heredity.
- **B (Boundary)**: For the complete graph, IC *is* hereditary (all subsets of size ≥ 2 are integrated). Heredity fails precisely when the graph has cut vertices or bridges.

### 3.5 Disconnection and the Subsystem-Global Identity (Theorems 5-6)

**Theorem 3.5** (Disconnection). *If there exists a non-trivial partition A with cutValue(C, A) = 0, then Φ(C) = 0.*

**Theorem 3.6** (Subsystem-Global Identity). *Φ_univ(C) = Φ(C).* The subsystem Φ for the full vertex set equals the global Φ.

## 4. Algorithms

### 4.1 Computing Φ

Computing Φ requires minimizing cutValue over all 2^n - 2 non-trivial partitions. This is equivalent to the minimum cut problem, which for undirected graphs can be solved in polynomial time using the Stoer-Wagner algorithm (O(n³)). For directed graphs, computing the minimum s-t cut for all pairs (s,t) via max-flow yields O(n² · n³) = O(n⁵).

However, the subsystem version — computing Φ_S for all S — requires solving minimum cut on each of the 2^n induced subgraphs. This has exponential complexity in the worst case, consistent with the known computational hardness of IIT [4].

### 4.2 Computing the Integration Complex

The Integration Complex IC(C) can be computed by enumerating all subsets S with |S| ≥ 2 and computing Φ_S for each. For n nodes, this requires O(2^n) minimum cut computations, each on at most n nodes. Total complexity: O(2^n · n³).

## 5. Connection to Existing Work

### 5.1 Relation to Graph Connectivity

Φ(C) > 0 if and only if the underlying undirected graph of C is 2-edge-connected (no bridge edges). More precisely, Φ equals the minimum edge cut of the symmetrized graph.

### 5.2 Relation to Algebraic Graph Theory

The Fiedler value (algebraic connectivity) λ₂ of the Laplacian provides a spectral analogue of Φ. The Cheeger inequality relates the two: λ₂/2 ≤ h(G) ≤ √(2λ₂), where h(G) is the Cheeger constant (normalized minimum cut).

## 7. Discussion

The Integration Complex provides a natural mathematical framework for the structural claims of IIT. Its non-hereditary nature is perhaps the most striking result: it means that consciousness (in the IIT formulation) is a genuinely holistic property that cannot be reconstructed from knowledge of subsystem integration alone.

The block diagonal theorem formalize's IIT's exclusion postulate in its strongest form: independent systems contribute exactly zero to integrated information. This has implications for the "combination problem" in panpsychism — if elementary particles are conscious, what makes their combined consciousness different from the sum? The block diagonal theorem says: nothing, unless they causally interact.

The monotonicity result provides a natural ordering on causal architectures and suggests that evolution, by increasing neural connectivity, moves systems up the integration hierarchy. This could be tested empirically by comparing Φ across species with varying neural density.
