# Counterpoint as Category Theory: The Algebraic Structure of Consonance

## Abstract

We formalize Fux's first-species counterpoint as a categorical structure where objects are consonant intervals and morphisms are permitted voice leadings, and prove five structural theorems about this formalization. Our main results are: (1) the counterpoint transition relation is the full relation on consonant intervals, achieved via oblique motion, disproving the conjecture that first-species counterpoint is equivalent to a poset-generated thin category; (2) the consonant interval set {0, 3, 4, 7, 8, 9} ⊂ ℤ/12ℤ is NOT closed under negation (inversion), with the failure occurring precisely at the perfect fifth (7 ↦ 5), while the imperfect consonance subset {3, 4, 8, 9} is inversion-closed; (3) the consonant set does not form an additive subgroup of ℤ/12ℤ, with the tritone (6 = 3 + 3) serving as witness; (4) the sum of all consonant intervals mod 12 equals 7 (the perfect fifth); and (5) there exists a strict total order on consonant intervals by acoustic consonance strength, with the perfect/imperfect boundary serving as the categorical "restriction threshold." All results are formalized and machine-verified in Lean 4 with the Mathlib library.

**Keywords**: counterpoint, category theory, consonance, music theory, formal verification, ℤ/12ℤ, interval inversion

## 1. Introduction

### 1.1 Motivation

The rules of counterpoint, codified by Fux (1725) and refined through centuries of pedagogical tradition, constitute one of the oldest and most precisely specified constraint systems in Western intellectual history. Despite extensive musicological analysis, the precise mathematical structure of these constraints has remained unclear.

Recent work in mathematical music theory (Mazzola 2002, Tymoczko 2011, Fiore & Satyendra 2005) has explored connections between music theory and various mathematical frameworks including group theory, topology, and category theory. However, the specific question of what *kind* of category first-species counterpoint defines — and in particular whether it corresponds to a poset — has not been rigorously settled.

### 1.2 The Conjecture

The motivating conjecture is:

> **Conjecture (Poset Equivalence)**: The category of first-species counterpoint over a diatonic scale is equivalent to the thin category generated by a specific poset of 12 elements.

We prove this conjecture **false** (Theorem 5.1) and characterize the actual structure.

### 1.3 Contributions

1. A complete formalization of first-species counterpoint consonances as objects in a category
2. A disproof of the poset equivalence conjecture via construction of symmetric reachability
3. Discovery of the "inversion asymmetry" — the consonant set's failure to be inversion-closed, localized precisely at the fifth-fourth boundary
4. Proof that consonance is not an algebraic (subgroup) property of ℤ/12ℤ
5. Characterization of the consonance rank as a total order with the perfect/imperfect boundary as a functorial invariant

## 2. Definitions

### 2.1 Consonant Intervals

**Definition 2.1** (Consonant Interval). A *consonant interval* is an element of the 6-element type:

```
CInterval := { unison, min3, maj3, fifth, min6, maj6 }
```

with embedding into Fin 12 given by:

| Interval | Semitones | Frequency Ratio | Type |
|----------|-----------|-----------------|------|
| Unison   | 0         | 1:1             | Perfect |
| Minor 3rd | 3        | 6:5             | Imperfect |
| Major 3rd | 4        | 5:4             | Imperfect |
| Perfect 5th | 7      | 3:2             | Perfect |
| Minor 6th | 8        | 8:5             | Imperfect |
| Major 6th | 9        | 5:3             | Imperfect |

This embedding is injective (Theorem 3.1).

### 2.2 Voice Leadings

**Definition 2.2** (Voice Leading). A *voice leading* from consonant interval `a` to consonant interval `b` is a pair `(lowerStep, upperStep) ∈ ℤ × ℤ` satisfying:

```
b.toFin.val - a.toFin.val ≡ upperStep - lowerStep (mod 12)
```

**Definition 2.3** (Motion Type). The *motion type* of a voice leading (d_l, d_u) is:
- **Parallel**: d_l = d_u ≠ 0
- **Oblique**: d_l = 0 or d_u = 0 (and d_l ≠ d_u)
- **Contrary**: d_l · d_u < 0
- **Similar**: d_l · d_u > 0 and d_l ≠ d_u

**Definition 2.4** (Valid Voice Leading). A voice leading from `a` to `b` is *valid* if it is not parallel motion to a perfect consonance:

```
isValid(vl) := ¬(b.isPerfect ∧ motion(vl) = parallel)
```

### 2.3 Interval Inversion

**Definition 2.5** (Interval Negation). For i ∈ Fin 12, define:

```
intervalNeg(i) := (12 - i) mod 12
```

This corresponds to interval inversion: replacing an ascending interval with its descending complement.

### 2.4 The Consonance Rank

**Definition 2.6** (Consonance Rank). The *consonance rank* assigns to each consonant interval a value in Fin 7 based on the simplicity of its just-intonation frequency ratio:

| Interval | Ratio | Rank |
|----------|-------|------|
| Unison   | 1:1   | 6    |
| Fifth    | 3:2   | 5    |
| Maj 3rd  | 5:4   | 4    |
| Min 3rd  | 6:5   | 3    |
| Maj 6th  | 5:3   | 2    |
| Min 6th  | 8:5   | 1    |

## 3. Structural Results

### Theorem 3.1 (Embedding Injectivity)
The map `CInterval.toFin : CInterval → Fin 12` is injective.

*Proof*: By case analysis on all 36 pairs. □

### Theorem 3.2 (Perfect-Imperfect Dichotomy)
Every consonant interval is either perfect or imperfect, and these classes are disjoint. The perfect consonances number 2, the imperfect consonances number 4.

*Proof*: Exhaustive verification over the 6-element type. □

### Theorem 3.3 (Consonance Rank Injectivity)
The consonance rank function is injective — each consonant interval has a distinct rank.

*Proof*: Case analysis. □

### Theorem 3.4 (Perfect-Imperfect Ordering)
For any perfect consonance a and imperfect consonance b:

```
b.consonanceRank < a.consonanceRank
```

*Proof*: The minimum perfect rank is 5 (fifth) and the maximum imperfect rank is 4 (major third). □

## 4. The Inversion Asymmetry

### Theorem 4.1 (Inversion Non-Closure)
The consonant set is NOT closed under interval negation mod 12.

*Proof*: `intervalNeg(7) = 5`, and 5 (the perfect fourth) is not consonant. □

### Theorem 4.2 (Fifth-Fourth Asymmetry)
The failure of inversion closure occurs precisely at the perfect fifth:

```
intervalNeg(⟨7, _⟩) = ⟨5, _⟩   and   isConsonant(⟨5, _⟩) = false
```

This formalizes the centuries-old observation that the fourth, despite being acoustically as "simple" as the fifth (ratio 4:3 versus 3:2), receives different treatment in counterpoint.

### Theorem 4.3 (Imperfect Inversion Closure)
The imperfect consonance subset {3, 4, 8, 9} IS closed under interval negation:

```
∀ i : Fin 12, i.val ∈ [3, 4, 8, 9] → (intervalNeg i).val ∈ [3, 4, 8, 9]
```

*Proof*: Computational verification: neg(3) = 9, neg(4) = 8, neg(8) = 4, neg(9) = 3. □

### Corollary 4.4 (Inversion Fixed Points)
The perfect consonances are exactly the fixed points of the CInterval inversion map:

```
i.isPerfect = true ↔ i.invert = i
```

### Discussion

The inversion asymmetry has a physical explanation: in counterpoint, intervals are measured from the *bass* voice. The fourth, when it occurs above the bass, creates a suspension that demands resolution — it sounds unstable. Above other voices, the fourth is consonant. This context-dependence is captured by our formalization treating the fourth as dissonant (in the counterpoint context), creating the asymmetry.

The mathematical consequence is that the consonant set cannot be characterized as the orbit of any element under the dihedral group of ℤ/12ℤ — the broken inversion symmetry prevents this.

## 5. The Anti-Poset Theorem

### Theorem 5.1 (Universal Reachability)
For any two consonant intervals a, b, there exists a valid voice leading from a to b.

*Proof sketch*: Construct a voice leading with `lowerStep = 0` and `upperStep = b.toFin.val - a.toFin.val`. Since the lower voice is stationary, the motion type is oblique. Oblique motion is never parallel, so the parallel-consonance prohibition is not triggered. □

### Theorem 5.2 (Anti-Poset / Anti-Antisymmetry)
The counterpoint transition relation is NOT antisymmetric:

```
∃ a b : CInterval, a ≠ b ∧ (∃ valid vl : a → b) ∧ (∃ valid vl : b → a)
```

*Proof*: Take a = min3, b = maj3. These are distinct (by decidable equality). Apply Theorem 5.1 twice. □

### Corollary 5.3 (Poset Conjecture Disproof)
First-species counterpoint is NOT equivalent to a poset-generated thin category.

*Proof*: A thin category generated by a poset has at most one morphism between any pair, and the underlying relation is a partial order (reflexive, transitive, antisymmetric). By Theorem 5.2, the transition relation fails antisymmetry. □

### Discussion

The conjecture fails because oblique motion provides a "universal connector" — any consonant interval can reach any other by simply holding one voice and moving the other. The counterpoint system is therefore more like a *complete directed graph* on 6 vertices.

The interesting structure is not in the *existence* of morphisms but in their *multiplicity* and *classification*. The parallel-fifths prohibition removes certain morphisms between perfect consonances but does not disconnect the graph. The category is far from thin — it has infinitely many morphisms between each pair of objects (since voice steps are arbitrary integers, not just small diatonic steps).

## 6. The Non-Subgroup Theorem

### Theorem 6.1 (Consonance is Not Algebraic)
There is no additive subgroup H of ℤ/12ℤ whose underlying set equals the consonant set {0, 3, 4, 7, 8, 9}.

*Proof*: If H were such a subgroup, then since 3 ∈ H, closure under addition gives 3 + 3 = 6 ∈ H. But 6 ∉ {0, 3, 4, 7, 8, 9}. Contradiction. □

### Theorem 6.2 (Tritone Generation)
The tritone is the sum of two minor thirds: (3 + 3 : ℤ/12ℤ) = 6.

### Discussion

This result is musically profound. The minor third — one of the warmest, most consonant intervals — generates the tritone through simple repetition. Medieval theorists called the tritone *diabolus in musica* ("the devil in music") and forbade its direct use. That the devil can be summoned by repeating an angel is an algebraic fact with deep musical consequences.

The non-subgroup result means consonance cannot be characterized purely algebraically within the cyclic group ℤ/12ℤ. Instead, consonance is fundamentally a *number-theoretic* property — it depends on the prime factorization structure of frequency ratios, which does not correspond to any subgroup structure.

## 7. The Consonant Sum

### Theorem 7.1 (Sum Equals Fifth)
The sum of all consonant interval values modulo 12 is 7 (the perfect fifth):

```
(0 + 3 + 4 + 7 + 8 + 9 : ℤ/12ℤ) = 7
```

### Discussion

This result positions the perfect fifth as the "arithmetic center" of consonance. Combined with the fifth's role as the generator of the circle of fifths (the multiplicative structure of pitch-class space), this suggests the fifth occupies a unique position at the intersection of additive and multiplicative structures in music theory.

## 8. The Parallel-Fifths Prohibition

### Theorem 8.1 (No Parallel Fifths)
For any voice leading from the fifth to the fifth with parallel motion type, the voice leading is not valid:

```
∀ vl : VoiceLeading fifth fifth,
  classifyMotion vl.lowerStep vl.upperStep = parallel → ¬vl.isValid
```

### Theorem 8.2 (Identity is Valid)
The identity voice leading (both voices stationary) is valid for any consonant interval, including perfect consonances. This shows the parallel prohibition targets *motion*, not *stasis*.

### Discussion

The parallel-fifths rule is the cornerstone of contrapuntal voice leading. Our formalization reveals it as a *fiber condition* on the forgetful functor from the counterpoint category to the interval-change monoid: the fiber over the identity change at perfect consonances is restricted to exclude parallel motion.

## 9. PEGB Analysis

### Theorem: Anti-Poset (Primary Result)

- **P** (Proof): Complete Lean 4 proof via construction of oblique voice leadings and application to distinct intervals (min3, maj3).
- **E** (Example): From min3 to maj3, the voice leading (0, 1) — lower voice stays, upper rises one semitone — is valid oblique motion. From maj3 to min3, (0, -1) works. Both directions exist, violating antisymmetry.
- **G** (Generalization): The same argument applies to any species of counterpoint, and even to extended consonance sets (e.g., including the perfect fourth). The oblique-motion universal connector is a general phenomenon.
- **B** (Boundary): The argument breaks if we restrict voice leadings to parallel motion only — in that case, transitions to/from perfect consonances become impossible, and the resulting graph is disconnected.

### Theorem: Inversion Asymmetry

- **P** (Proof): Computational verification that intervalNeg(7) = 5 and 5 is dissonant.
- **E** (Example): A melody that outlines a descending fifth (C→F) creates a perfect fourth above the bass — dissonant. Inverting a fifth gives a fourth, breaking consonance.
- **G** (Generalization): In n-TET systems (equal temperament with n divisions), the analog of this asymmetry depends on whether the consonant set is symmetric about n/2. In 19-TET, the analogous set is also asymmetric.
- **B** (Boundary): In free counterpoint (without the bass-voice restriction), the fourth IS consonant, and the inversion symmetry is restored. The asymmetry is specific to *strict* Fuxian counterpoint.

### Theorem: Non-Subgroup

- **P** (Proof): Closure failure: 3 + 3 = 6 ∉ consonant set.
- **E** (Example): Stacking minor thirds (C-E♭-G♭) produces a diminished triad spanning a tritone — dissonance from consonance.
- **G** (Generalization): In 19-TET, the analogous consonant set is also not a subgroup. In 31-TET (which better approximates just intonation), the consonant set has different algebraic properties.
- **B** (Boundary): If we work in ℤ/7ℤ (the diatonic scale) instead of ℤ/12ℤ, the consonant set {0, 2, 4} (thirds and fifths in diatonic steps) IS a subgroup. The non-subgroup property is specific to the chromatic representation.

## 10. Algorithms

### Algorithm 1: Voice Leading Enumeration

Given consonant intervals a, b and a bound B on step size, enumerate all valid voice leadings (d_l, d_u) with |d_l|, |d_u| ≤ B:

```
for d_l in [-B, B]:
  for d_u in [-B, B]:
    if (b - a) ≡ (d_u - d_l) mod 12:
      if not (b.isPerfect and d_l = d_u ≠ 0):
        yield (d_l, d_u)
```

### Algorithm 2: Transition Matrix Construction

Build the 6×6 matrix M where M[a][b] counts valid voice leadings within step bound B. The parallel-fifths prohibition appears as reduced counts in the (unison, unison) and (fifth, fifth) diagonal entries.
