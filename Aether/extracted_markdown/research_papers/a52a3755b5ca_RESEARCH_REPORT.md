# Research Report: EML Positive Multiplication Closure

## Summary

We formally prove that the function space generated by the EML (Exp-Minus-Log) operation is closed under pointwise multiplication of strictly positive functions. This is the key algebraic property required to apply the Stone-Weierstrass theorem for establishing universal approximation by EML networks.

## Main Result

**Theorem** (`eml_pos_mul_mem_closure`): If `f` and `g` are in the EML closure and both are strictly positive everywhere, then their pointwise product `fun x ↦ f x * g x` is also in the EML closure.

## Mathematical Context

### The EML Operation

The EML operation is defined as:

$$\text{eml}(a, b) = e^a - \ln b$$

This single operation bridges exponential growth and logarithmic compression, serving as a fundamental building block for a class of neural network architectures.

### The EML Closure

We define the **EML closure** as the smallest set of functions `ℝ → ℝ` that:

1. Contains all partial applications of the EML operation (fixing either argument)
2. Contains the identity function and all constant functions
3. Is closed under function composition
4. Is closed under pointwise addition
5. Is closed under pointwise negation

### Derived Members

From the EML generators, we derive key functions:

- **Exponential**: `exp = eml(·, 1)` since `eml(x, 1) = exp(x) - log(1) = exp(x)`
- **Shifted log**: `1 - log = eml(0, ·)` since `eml(0, x) = exp(0) - log(x) = 1 - log(x)`
- **Logarithm**: `log = 1 + neg(1 - log)` using constants, negation, and addition

### Proof of Multiplication Closure

The proof proceeds in four steps:

1. `log ∘ f ∈ EMLClosure` — by composition closure with `log`
2. `log ∘ g ∈ EMLClosure` — by composition closure with `log`
3. `(log ∘ f) + (log ∘ g) ∈ EMLClosure` — by addition closure
4. `exp ∘ ((log ∘ f) + (log ∘ g)) ∈ EMLClosure` — by composition closure with `exp`

The final step uses the identity:

$$e^{\ln f(x) + \ln g(x)} = e^{\ln f(x)} \cdot e^{\ln g(x)} = f(x) \cdot g(x)$$

which holds when `f(x) > 0` and `g(x) > 0`.

## Significance for Universal Approximation

The Stone-Weierstrass theorem states that a subalgebra of `C(K)` (continuous functions on a compact space) is dense if it:

1. Separates points ✓ (the closure contains the identity)
2. Contains constants ✓ (by construction)
3. Is closed under multiplication ✓ (**this theorem**, for positive functions)

Our result provides condition (3), the most technically demanding of the three. Combined with conditions (1) and (2), this establishes that the EML closure is dense in `C(K)` for the appropriate function space, proving universal approximation.

## Additional Results

- `exp_mem_EMLClosure`: The exponential function is in the EML closure
- `log_mem_EMLClosure`: The logarithm function is in the EML closure
- `eml_sub_closure`: The closure is closed under subtraction
- `eml_sq_mem_closure`: Squaring positive functions preserves closure membership
