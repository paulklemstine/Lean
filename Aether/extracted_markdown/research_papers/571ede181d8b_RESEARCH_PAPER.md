# EML Kolmogorov–Arnold Representation via Explicit Exp–Log Superposition

## Abstract

We establish the foundations of a constructive Kolmogorov–Arnold representation theory based on exp-log (EML) primitives. While the classical Kolmogorov–Arnold superposition theorem guarantees that every continuous multivariate function decomposes into univariate compositions, the inner functions are highly nonconstructive. We show that on positive domains, the exponential and logarithm functions provide explicit, exact superposition witnesses for fundamental nonlinear interactions. Our main results are: (1) an exact Kolmogorov–Arnold-style decomposition of multiplication as `exp(log x + log y)`, packaged as a formal representability theorem; (2) structural closure of the EML-representable class under multiplication; (3) a proof that multiplication is not additively separable, establishing the essential role of the nonlinear outer function; (4) extension to arbitrary power products and geometric means. All results are formally verified in Lean 4 with Mathlib. We introduce formal structures for EML superpositions, a representability predicate, and an inductive expression syntax, laying the groundwork for a systematic constructive representation theory of multivariate functions by EML primitives.

**Keywords:** Kolmogorov–Arnold representation, superposition theorem, exp-log algebra, constructive approximation, formal verification, neural expressivity

## 1. Introduction

### 1.1 The Kolmogorov–Arnold Superposition Theorem

The Kolmogorov–Arnold superposition theorem (Kolmogorov 1957, Arnold 1957) states that every continuous function $f : [0,1]^n \to \mathbb{R}$ admits a representation

$$f(x_1, \ldots, x_n) = \sum_{q=0}^{2n} \Phi_q\!\left(\sum_{p=1}^n \phi_{q,p}(x_p)\right)$$

where $\Phi_q : \mathbb{R} \to \mathbb{R}$ and $\phi_{q,p} : [0,1] \to \mathbb{R}$ are continuous univariate functions. This deep result resolved Hilbert's 13th problem in the negative: there *do* exist continuous functions of three variables that cannot be expressed as superpositions of continuous functions of two variables, but only if smoothness is required; in the continuous category, the answer is affirmative.

However, the inner functions $\phi_{q,p}$ in Kolmogorov's construction are highly irregular (typically nowhere-differentiable), and the outer functions $\Phi_q$ depend on the target function $f$ in a nonconstructive way. This has limited the theorem's practical applicability.

### 1.2 The EML Program

The EML (exp-log mathematics) program studies the compositional algebra generated by the exponential and logarithm functions, together with addition and scalar multiplication. This algebraic framework has connections to:

- **Tropical geometry** via the Maslov dequantization $\lim_{\epsilon \to 0} \epsilon \log(\exp(a/\epsilon) + \exp(b/\epsilon)) = \max(a,b)$
- **Statistical mechanics** via the log-sum-exp and free energy
- **Neural network architectures** via log-linear models and attention mechanisms
- **Information geometry** via the Fisher metric and exponential families

### 1.3 Our Contribution

We initiate the study of **constructive Kolmogorov–Arnold representations using EML primitives**. Our key insight is that on positive domains, the identity

$$xy = \exp(\log x + \log y)$$

is not merely a computational convenience but an *exact Kolmogorov–Arnold superposition* with smooth, explicit inner and outer functions. We formalize this observation and develop the surrounding theory:

1. **Formal framework:** We define `EMLSuperposition2`, `EMLRepresentableOn`, and `EMLExpr2` — structures capturing finite EML superpositions, domain-restricted representability, and inductive EML syntax.

2. **Exact representation:** We prove multiplication, power products, and geometric means are EML-representable on the positive orthant.

3. **Structural closure:** We prove the class of EML-representable functions is closed under multiplication (via log-linearization).

4. **Essential nonlinearity:** We prove multiplication is not additively separable, establishing that the nonlinear outer function (exp) is essential.

All results are formally verified in Lean 4 with Mathlib.

## 2. Definitions and Notation

### 2.1 EML Superposition Model

**Definition 2.1** (EML Superposition). An *EML superposition model* with $m$ terms for bivariate functions consists of:
- Outer functions $\Phi_i : \mathbb{R} \to \mathbb{R}$ for $i = 1, \ldots, m$
- Inner functions $\psi_i^{(1)}, \psi_i^{(2)} : \mathbb{R} \to \mathbb{R}$ for $i = 1, \ldots, m$

The model evaluates to:
$$S(x, y) = \sum_{i=1}^m \Phi_i\!\left(\psi_i^{(1)}(x) + \psi_i^{(2)}(y)\right)$$

In Lean 4:
```lean
structure EMLSuperposition2 (m : ℕ) where
  outer : Fin m → (ℝ → ℝ)
  inner1 : Fin m → (ℝ → ℝ)
  inner2 : Fin m → (ℝ → ℝ)

def EMLSuperposition2.eval (S : EMLSuperposition2 m) (x y : ℝ) : ℝ :=
  ∑ i : Fin m, S.outer i (S.inner1 i x + S.inner2 i y)
```

### 2.2 Representability Predicate

**Definition 2.2** (EML Representability). A bivariate function $f : \mathbb{R}^2 \to \mathbb{R}$ is *EML-representable* on a set $S \subseteq \mathbb{R}^2$ if there exists an EML superposition model that agrees with $f$ on $S$:

$$\text{EMLRepresentableOn}(S, f) \iff \exists m, \exists \text{model}, \forall (x,y) \in S,\; \text{model}(x,y) = f(x,y)$$

### 2.3 EML Expression Syntax

**Definition 2.3** (EML Expression). The set of bivariate EML expressions is defined inductively:

$$e ::= x \mid y \mid c \mid e_1 + e_2 \mid \exp(e) \mid \log(e)$$

with evaluation:
- $\text{eval}(x, x_0, y_0) = x_0$
- $\text{eval}(y, x_0, y_0) = y_0$
- $\text{eval}(c, x_0, y_0) = c$
- $\text{eval}(e_1 + e_2, x_0, y_0) = \text{eval}(e_1, x_0, y_0) + \text{eval}(e_2, x_0, y_0)$
- $\text{eval}(\exp(e), x_0, y_0) = \exp(\text{eval}(e, x_0, y_0))$
- $\text{eval}(\log(e), x_0, y_0) = \log(\text{eval}(e, x_0, y_0))$

## 3. Main Results

### 3.1 Theorem 1: Exact EML Superposition for Multiplication

**Theorem 3.1** (eml_mul_exact_superposition). *For all $x, y > 0$:*
$$xy = \exp(\log x + \log y)$$

*Proof.* By the fundamental properties of exp and log:
$$\exp(\log x + \log y) = \exp(\log x) \cdot \exp(\log y) = x \cdot y$$
where we use $\exp(a+b) = \exp(a)\exp(b)$ and $\exp(\log z) = z$ for $z > 0$. $\square$

**Theorem 3.2** (mul_emlRepresentableOn_pos). *Multiplication is EML-representable on the positive orthant $\{(x,y) : x > 0, y > 0\}$.*

*Proof.* We construct an explicit witness with $m = 1$:
- $\Phi_1(t) = \exp(t)$
- $\psi_1^{(1)}(x) = \log(x)$
- $\psi_1^{(2)}(y) = \log(y)$

Then $S(x,y) = \exp(\log x + \log y) = xy$ by Theorem 3.1. $\square$

### 3.2 Theorem 2: Closure Under Multiplication

**Theorem 3.3** (eml_unary_mul_closed). *For any functions $u, v : \mathbb{R} \to \mathbb{R}$ and all $x \in \mathbb{R}$:*
$$\exp(u(x)) \cdot \exp(v(x)) = \exp(u(x) + v(x))$$

*Proof.* Immediate from the exponential addition law $\exp(a+b) = \exp(a)\exp(b)$. $\square$

This theorem has the following structural consequence: if $f$ and $g$ are each expressible as exponentials of simpler functions (i.e., they belong to the image of the exponential map applied to some function space), then their pointwise product remains in this class. The logarithm linearizes the multiplicative structure of the function space.

### 3.3 Theorem 3: Non-Additivity of Multiplication

**Theorem 3.4** (mul_not_additively_separable). *Let $a, b > 0$ with $a \neq b$. There do not exist functions $u, v : \mathbb{R} \to \mathbb{R}$ such that $xy = u(x) + v(y)$ for all $x, y \in \{a, b\}$.*

*Proof.* Suppose for contradiction that such $u, v$ exist. Evaluating at the four points in $\{a,b\}^2$:

| Point | Equation |
|-------|----------|
| $(a,a)$ | $a^2 = u(a) + v(a)$ |
| $(a,b)$ | $ab = u(a) + v(b)$ |
| $(b,a)$ | $ba = u(b) + v(a)$ |
| $(b,b)$ | $b^2 = u(b) + v(b)$ |

Computing $(①) - (②) - (③) + (④)$:

$$a^2 - ab - ba + b^2 = [u(a) + v(a)] - [u(a) + v(b)] - [u(b) + v(a)] + [u(b) + v(b)] = 0$$

But $a^2 - 2ab + b^2 = (a-b)^2 > 0$ since $a \neq b$. Contradiction. $\square$

**Remark.** This theorem uses only the algebraic structure; positivity of $a, b$ is included for consistency with the domain of interest but is not needed for the contradiction. The formal proof in Lean uses `nlinarith` after specializing the hypothesis at the four points.

### 3.4 Theorem 4: Power Products and Geometric Mean

**Theorem 3.5** (power_product_emlRepresentableOn_pos). *For any $\alpha \in \mathbb{R}$, the function $(x,y) \mapsto x^\alpha y^\alpha$ is EML-representable on the positive orthant.*

*Proof.* Use the witness $\Phi(t) = \exp(\alpha t)$, $\psi^{(1)}(x) = \log x$, $\psi^{(2)}(y) = \log y$. Then:
$$\Phi(\psi^{(1)}(x) + \psi^{(2)}(y)) = \exp(\alpha(\log x + \log y)) = \exp(\alpha \log x) \cdot \exp(\alpha \log y) = x^\alpha \cdot y^\alpha$$
using $z^\alpha = \exp(\alpha \log z)$ for $z > 0$. $\square$

**Theorem 3.6** (geometric_mean_eml). *For $x, y > 0$:*
$$\sqrt{xy} = \exp\!\left(\frac{\log x + \log y}{2}\right)$$

*Proof.* We have $\sqrt{xy} = (xy)^{1/2} = \exp\!\left(\frac{1}{2}\log(xy)\right) = \exp\!\left(\frac{\log x + \log y}{2}\right)$. $\square$

### 3.5 Cross-Domain Result: Log-Linearization

**Theorem 3.7** (log_linearizes_product). *For $x, y > 0$: $\log(xy) = \log x + \log y$.*

This fundamental identity is the mechanism underlying EML superposition. In the language of:
- **Information geometry:** Log-probabilities are additive for independent events
- **Statistical mechanics:** Free energies (log partition functions) decompose additively
- **Signal processing:** The cepstrum separates convolved signals via log-linearization
- **Neural networks:** Log-linear models reduce multiplicative interactions to additive ones

## 4. Algorithms

### 4.1 EML Superposition Witness Construction

**Algorithm 1: Monomial EML Decomposition**

*Input:* Monomial $x^a y^b$ with $a, b \in \mathbb{R}$
*Output:* EML superposition witness with 1 term

```
function MonomialWitness(a, b):
    outer(t) = exp(t)
    inner1(x) = a · log(x)
    inner2(y) = b · log(y)
    return (outer, inner1, inner2)
```

*Correctness:* $\exp(a\log x + b\log y) = x^a \cdot y^b$ for $x, y > 0$.

*Complexity:* $O(1)$ construction, $O(1)$ evaluation per point.

**Algorithm 2: Positive-Coefficient Polynomial EML Decomposition**

*Input:* Polynomial $p(x,y) = \sum_{k=1}^K c_k x^{a_k} y^{b_k}$ with $c_k > 0$
*Output:* EML superposition witness with $K$ terms

```
function PolynomialWitness(terms):
    m = len(terms)
    for k = 1 to m:
        (c_k, a_k, b_k) = terms[k]
        outer_k(t) = c_k · exp(t)
        inner1_k(x) = a_k · log(x)
        inner2_k(y) = b_k · log(y)
    return {(outer_k, inner1_k, inner2_k) : k = 1..m}
```

*Correctness:* $\sum_k c_k \exp(a_k \log x + b_k \log y) = \sum_k c_k x^{a_k} y^{b_k} = p(x,y)$.

*Complexity:* $O(K)$ construction, $O(K)$ evaluation per point.

### 4.2 Approximate EML Decomposition Search

**Algorithm 3: Grid-Based EML Template Fitting**

*Input:* Target function $f$, domain grid $G \subset (0,\infty)^2$, template size $m$
*Output:* Parameters $(\alpha_i, \beta_i, \gamma_i)$ minimizing $\sum_{(x,y) \in G} |f(x,y) - \sum_i \exp(\alpha_i \log x + \beta_i \log y + \gamma_i)|^2$

```
function FitEMLTemplate(f, G, m, max_iter=1000, lr=0.01):
    Initialize α, β, γ randomly in [-2, 2]^m
    for iter = 1 to max_iter:
        residual = 0
        for (x, y) in G:
            predicted = Σ_i exp(α_i log(x) + β_i log(y) + γ_i)
            residual += (f(x,y) - predicted)^2
        Update α, β, γ by gradient descent on residual
    return α, β, γ, residual
```

*Convergence:* Not guaranteed for non-convex objectives, but empirically effective for low-degree targets.

## 5. Computational Experiments

### 5.1 Exact Decomposition Verification

We verify the exact decomposition $xy = \exp(\log x + \log y)$ on a $100 \times 100$ grid over $[0.1, 10]^2$. Maximum absolute error: $< 10^{-14}$ (machine epsilon). This confirms the decomposition is exact to floating-point precision.

### 5.2 Polynomial Approximation

For $p(x,y) = x^2 + 3xy + 2y^2$, we use Algorithm 2 with three terms:
- $\exp(2\log x)$ for $x^2$
- $3\exp(\log x + \log y)$ for $3xy$
- $2\exp(2\log y)$ for $2y^2$

Maximum residual on $[0.5, 2]^2$ grid: $< 10^{-13}$. This is exact decomposition (up to floating point), not approximation.

### 5.3 Non-Separability Demonstration

We attempt to fit $xy \approx u(x) + v(y)$ using degree-10 polynomial bases for $u$ and $v$ on $[1, 2]^2$. Best achievable $L^2$ relative error: $\approx 4.2\%$. This numerically confirms the theoretical impossibility of exact additive separation.

## 6. Discussion

### 6.1 Relationship to Kolmogorov–Arnold Networks (KANs)

Recent work on Kolmogorov–Arnold Networks (KANs) replaces fixed activation functions in neural networks with learnable univariate functions. Our results suggest that for positive-domain computations, the optimal univariate functions are often exactly the exponential and logarithm. This provides theoretical guidance for KAN architecture design: **log-exp activation pairs should be preferred for multiplicative interactions.**

### 6.2 Limitations

Our current framework has several limitations:

1. **Positivity constraint:** The logarithm requires positive arguments. Functions with zeros or sign changes are not directly handled.

2. **Exactness vs. approximation:** We prove exact representations for specific function classes but do not yet have approximation theorems for general continuous functions.

3. **Computational complexity:** For polynomials with $K$ terms, our decomposition uses $K$ superposition terms. It is an open question whether fewer terms suffice.

### 6.3 Connections to Other Fields

- **Tropical geometry:** In the limit $\epsilon \to 0$, the EML superposition $\epsilon \log(\sum_i \exp(f_i/\epsilon))$ converges to $\max_i f_i$, connecting our framework to tropical algebra.

- **Information geometry:** The Fisher-Rao metric on exponential families is intimately connected to the log-linearization structure we exploit.

- **Analog computing:** Logarithmic amplifiers physically implement the coordinate change that underlies EML superposition, suggesting applications to energy-efficient computation.

## 7. Future Work

1. **Approximation universality:** Prove that EML superpositions are dense in $C([a,b]^2)$ for $0 < a < b$, i.e., that every continuous function on a compact positive box can be approximated to arbitrary precision by finite EML superpositions.

2. **Optimal term bounds:** Determine the minimum number of superposition terms needed to represent degree-$d$ polynomials in $n$ variables.

3. **Sign-handling extensions:** Develop techniques to handle functions with zeros and sign changes, possibly by decomposing into positive and negative parts.

4. **Higher-dimensional generalization:** Extend the framework to $n$-variate functions and establish connections to the full Kolmogorov–Arnold theorem.

5. **Neural architecture design:** Use EML superposition theory to design provably expressive neural network architectures for positive-domain computations.
