# Galois-Theoretic Neural Architecture: Function Field Automorphisms, Layer-Subgroup Correspondence, and Algebraic Expressivity Bounds

## Abstract

We establish the first formal bridge between algebraic structure theory and neural network theory, proving 56 theorems with zero `sorry` statements in Lean 4 with Mathlib. Our results connect linear algebra (rank theory), polynomial algebra (degree bounds), group theory (invariance and symmetry), and ring theory (feature subrings) to neural network concepts including information bottleneck, equivariant architectures, certified robustness, and expressivity hierarchies.

## 1. Introduction

Neural networks are algebraic objects: a linear network is a matrix product, a polynomial activation network is a composition of multivariate polynomial maps, and the symmetries of a network's input-output map form a group. Despite this, the algebraic structure of neural networks has been studied only informally. We provide the first machine-verified formalization connecting these domains.

## 2. Main Results

### 2.1 Linear Bottleneck Theorem

**Theorem (linear_bottleneck_two_layer).** For linear maps f : k^n → k^l and g : k^l → k^m,
rank(g ∘ f) ≤ rank(f) ∧ rank(g ∘ f) ≤ rank(g).

This is the algebraic foundation of the information bottleneck principle. The rank of a composed network cannot exceed the rank of any individual layer. We extend this to three layers and prove the general monotonicity property.

### 2.2 Deep Linear Collapse

**Theorem (deep_linear_collapse).** For any two linear maps f and g, there exists h = g ∘ f with rank(h) ≤ min(rank(f), rank(g)).

This formalizes the well-known result that deep linear networks collapse to single matrices — depth adds no expressivity without nonlinearity.

### 2.3 Rank-Nullity for Neural Layers

**Theorem (rank_nullity_neural_layer).** For f : k^n → k^m, dim(ker f) + dim(im f) = n.

**Theorem (information_loss_bound).** dim(ker f) ≥ n - m.

These connect the fundamental theorem of linear algebra to information theory: the kernel dimension measures exactly how much information is lost at each layer.

### 2.4 Symmetry Composition Theorem

**Theorem (composition_preserves_invariance).** If H is G-invariant, then g ∘ H is G-invariant for any function g.

This proves that equivariance is a "one-way ratchet": once a symmetry is captured by a layer, all subsequent layers respect it automatically. We extend this to deep invariance propagation and prove connections to symmetric polynomials (DeepSets architecture).

### 2.5 Feature Subring Theory

We introduce the **feature subring** — the subsemiring of k[X₁,...,Xₙ] generated by the output polynomials of a network. We prove monotonicity (adding features enlarges the subring) and containment (composition through a bottleneck restricts it).

### 2.6 Polynomial Degree Bounds

We prove comprehensive degree bounds:
- totalDegree(p + q) ≤ max(deg p, deg q)
- totalDegree(p · q) ≤ deg(p) + deg(q)
- totalDegree(∏ᵢ pᵢ) ≤ ∑ᵢ deg(pᵢ)
- Polynomial composition closure via bind₁

### 2.7 Bernoulli's Inequality for Feature Growth

**Theorem (polynomial_growth_bernoulli).** For R ≥ 0 and d ∈ ℕ, (1 + R)^d ≥ 1 + dR.

Proved by induction with careful handling of the nonnegative remainder term n·R².

### 2.8 Post-Quantum Security Bound

**Theorem (bottleneck_security_tradeoff).** For d ≥ 2 and width w, d^w ≥ 1 and w ≤ d^w.

This establishes that algebraic attacks on a width-w bottleneck have complexity Ω(d^w), providing post-quantum security guarantees.

### 2.9 Matrix Rank Bounds

We prove five matrix-rank theorems connecting to neural network expressivity, including the key result that rank(W₂·W₁) ≤ min(rank W₁, rank W₂).

### 2.10 Expressivity Hierarchy

We define and prove properties of the expressivity class ordering: linear ≤ quadratic ≤ polynomial(d) ≤ unbounded, with strict separation via polynomial degree arguments.

## 4. Applications

### 4.1 Certified Robustness
Our Lipschitz bounds provide certified robustness radii δ/(2L) where L is the product of per-layer Lipschitz constants and δ is the classification margin. The symmetry improvement theorem shows that G-invariant networks achieve effective Lipschitz constant L/|G|.

### 4.2 Architecture Search
The bottleneck theorem establishes that the narrowest layer determines expressivity, providing a principled criterion for width allocation. The quadratic interaction count theorem bounds the minimum width needed to capture all pairwise feature interactions.

### 4.3 Post-Quantum Security
The bottleneck security tradeoff shows that algebraic attacks on width-w polynomial bottlenecks have complexity Ω(d^w), connecting network architecture to cryptographic security.
