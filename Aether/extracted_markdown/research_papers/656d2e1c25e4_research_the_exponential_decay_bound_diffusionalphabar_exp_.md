# Closure–Gauge Realization Duality via Idempotent Holonomy

## Abstract

We establish a complete characterization of gauge-realizable closure operators on finite sets. A closure operator on a finite set α is *gauge-realizable* if it equals the valuation closure cl_v(S) = {x ∈ α : v(x) ≤ sup_{s ∈ S} v(s)} for some gauge valuation v : α → ℕ. Our main result, the **Closure–Gauge Realization Duality**, states that a closure operator is gauge-realizable if and only if its closed sets form a chain under inclusion. We prove several supporting results: that valuation closures are indeed closure operators, that their closed sets are automatically totally ordered, that equal closures imply order-equivalent valuations (gauge uniqueness), and that capacity profiles holographically determine closures. We also establish existence and essential uniqueness of minimal realizations, give a certified reconstruction algorithm, and characterize separation in terms of valuation injectivity. All results are formalized and machine-verified.

**Keywords**: closure operator, gauge valuation, realization theory, holographic duality, tropical algebra, chain condition, finite combinatorics

## 1. Introduction

Closure operators are a unifying abstraction across mathematics: they appear in topology (topological closure), algebra (algebraic closure of fields, radical of ideals), logic (deductive closure), and combinatorics (matroid closure). A fundamental question in any closure-theoretic setting is *realization*: when can an abstractly specified closure operator be represented concretely by a simpler mathematical object?

In this work, we study *gauge realization* — the question of when a closure operator on a finite set can be generated by a numerical valuation. The construction is elementary: given a function v : α → ℕ (the "gauge valuation"), define

$$\text{cl}_v(S) = \{x \in \alpha \mid v(x) \leq \sup_{s \in S} v(s)\}$$

This captures the intuition that an element belongs to the closure of S if its "level" does not exceed the maximum level present in S. Despite the simplicity of this construction, the resulting theory exhibits surprising depth, connecting to tropical linear algebra (where the supremum operation replaces addition), lattice gauge theory (where the gauge uniqueness theorem formalizes gauge equivalence), and automata-theoretic realization (where the chain condition plays the role of the Myhill-Nerode theorem).

### 1.1 Main Contributions

1. **Valuation Closure Theorem** (Section 3): For any v : α → ℕ, the map cl_v is a closure operator.
2. **Chain Theorem** (Section 4): Closed sets of any valuation closure form a chain.
3. **Realization Duality** (Section 5): A closure operator is gauge-realizable ⟺ its closed sets form a chain.
4. **Gauge Uniqueness** (Section 6): Equal closures ⟹ order-equivalent valuations.
5. **Holographic Duality** (Section 7): Equal capacity profiles ⟹ equal closures.
6. **Minimal Realization** (Section 8): Existence and gauge-uniqueness of minimal realizations.
7. **Separation Characterization** (Section 9): Separation ⟺ injectivity.

## 2. Definitions

Throughout, let α be a finite type with decidable equality. We write Finset α for the type of finite subsets of α.

**Definition 2.1 (Closure Operator).** A *closure operator* on Finset α is a triple C = (cl, extensive, monotone, idempotent) where cl : Finset α → Finset α satisfies:
- *Extensiveness*: S ⊆ cl(S) for all S.
- *Monotonicity*: S ⊆ T implies cl(S) ⊆ cl(T).
- *Idempotence*: cl(cl(S)) = cl(S) for all S.

**Definition 2.2 (Closed Set).** A set S is *closed* under C if cl(S) = S.

**Definition 2.3 (Gauge Valuation and Induced Closure).** A *gauge valuation* is a function v : α → ℕ. The *valuation closure* induced by v is:

$$\text{cl}_v(S) = \{x \in \alpha \mid v(x) \leq \sup_{s \in S} v(s)\}$$

where the supremum is taken in ℕ with the convention that sup(∅) = 0 (i.e., the bot element of ℕ under the natural order).

**Definition 2.4 (Gauge Realizability).** A closure operator C is *gauge-realizable* if there exists v : α → ℕ such that cl_C = cl_v.

**Definition 2.5 (Order Equivalence / Gauge Equivalence).** Two valuations v₁, v₂ : α → ℕ are *order-equivalent* (or *gauge-equivalent*) if for all x, y ∈ α:

$$v_1(x) \leq v_1(y) \iff v_2(x) \leq v_2(y)$$

**Definition 2.6 (Capacity).** The *capacity* of a set S under closure operator C is cap_C(S) = |cl_C(S)|.

**Definition 2.7 (Chain Condition).** A closure operator C satisfies the *chain condition* if for all closed sets S, T: either S ⊆ T or T ⊆ S.

**Definition 2.8 (Separation).** A closure operator C is *separated* if for all distinct a, b ∈ α: cl({a}) ≠ cl({b}).

**Definition 2.9 (Realization Rank).** The *rank* of a valuation v is the cardinality of its image: rank(v) = |{v(x) : x ∈ α}|.

**Definition 2.10 (Minimal Realization).** A valuation v is a *minimal realization* if for all w with cl_v = cl_w, we have rank(v) ≤ rank(w).

**Definition 2.11 (Normalized Valuation).** The *normalized valuation* of v is defined by:

$$\hat{v}(x) = |\{y \in \alpha \mid v(y) < v(x)\}|$$

This maps each element to the count of elements with strictly smaller v-value.

## 3. Valuation Closure is a Closure Operator

**Theorem 3.1 (Extensiveness).** *For any v : α → ℕ and S ⊆ α, we have S ⊆ cl_v(S).*

*Proof sketch.* If x ∈ S, then v(x) ≤ sup_{s ∈ S} v(s) by the definition of supremum, so x ∈ cl_v(S). □

**Theorem 3.2 (Monotonicity).** *For any v : α → ℕ, if S ⊆ T then cl_v(S) ⊆ cl_v(T).*

*Proof sketch.* If x ∈ cl_v(S), then v(x) ≤ sup_S v ≤ sup_T v (since S ⊆ T implies the supremum over S is at most the supremum over T), so x ∈ cl_v(T). □

**Lemma 3.3 (Supremum Preservation).** *The supremum of the valuation over a closure equals the supremum over the original set: sup_{x ∈ cl_v(S)} v(x) = sup_{s ∈ S} v(s).*

*Proof sketch.* The ≤ direction holds because every element of cl_v(S) has v-value at most sup_S v. The ≥ direction holds because S ⊆ cl_v(S) by extensiveness. □

**Theorem 3.4 (Idempotence).** *For any v : α → ℕ and S ⊆ α, we have cl_v(cl_v(S)) = cl_v(S).*

*Proof sketch.* By Lemma 3.3, sup_{cl_v(S)} v = sup_S v. Therefore x ∈ cl_v(cl_v(S)) iff v(x) ≤ sup_{cl_v(S)} v = sup_S v iff x ∈ cl_v(S). □

**Corollary 3.5.** *For any v : α → ℕ, the valuation closure cl_v is a closure operator.*

## 4. Closed Sets Form a Chain

**Theorem 4.1 (Closed Set Characterization).** *A set S is closed under cl_v if and only if S = {x ∈ α : v(x) ≤ sup_S v}.*

*Proof sketch.* By definition, cl_v(S) = {x : v(x) ≤ sup_S v}. So S is closed iff S = cl_v(S) iff S equals this level set. □

**Theorem 4.2 (Chain Theorem).** *Any two closed sets of a valuation closure are comparable under inclusion.*

*Proof sketch.* Let S, T be closed under cl_v. By Theorem 4.1, S = {x : v(x) ≤ k_S} and T = {x : v(x) ≤ k_T} where k_S = sup_S v and k_T = sup_T v. Since k_S and k_T are natural numbers, either k_S ≤ k_T or k_T ≤ k_S. In the first case S ⊆ T; in the second, T ⊆ S. □

## 5. The Realization Duality

**Theorem 5.1 (Forward: Realizable ⟹ Chain).** *If a closure operator C is gauge-realizable, then its closed sets form a chain.*

*Proof sketch.* Immediate from Theorem 4.2. □

**Theorem 5.2 (Backward: Chain ⟹ Realizable).** *If a closure operator C has the chain condition, then C is gauge-realizable.*

*Proof sketch.* Define v(x) = |cl_C({x})| − |cl_C(∅)|. We show cl_C = cl_v by proving mutual membership. For the forward direction: if x ∈ cl_C(S), we use the chain condition to find s₀ ∈ S such that cl_C(S) = cl_C({s₀}), and then cl_C({x}) ⊆ cl_C({s₀}) implies v(x) ≤ v(s₀) ≤ sup_S v. For the backward direction: if v(x) ≤ sup_S v, there exists s₀ ∈ S with v(x) ≤ v(s₀), and by the chain condition this implies cl_C({x}) ⊆ cl_C({s₀}) ⊆ cl_C(S), so x ∈ cl_C(S).

A key auxiliary result used is:

**Lemma (Chain Closure Equals Singleton Closure).** *In a closure operator with the chain property, for every nonempty S there exists s₀ ∈ S such that cl(S) = cl({s₀}).* □

**Lemma (Chain Subset iff Card).** *In a closure operator with the chain property, for closed sets S, T: S ⊆ T iff |S| ≤ |T|.* □

**Theorem 5.3 (Closure–Gauge Realization Duality).** *A closure operator C on a finite set is gauge-realizable if and only if its closed sets form a chain.*

*Proof.* Combine Theorems 5.1 and 5.2. □

## 6. Gauge Uniqueness

**Theorem 6.1 (Gauge Uniqueness).** *If cl_{v₁} = cl_{v₂}, then v₁ and v₂ are order-equivalent.*

*Proof sketch.* We have v₁(x) ≤ v₁(y) iff x ∈ cl_{v₁}({y}) (by definition of cl_v and the fact that sup of a singleton is the value itself) iff x ∈ cl_{v₂}({y}) (by hypothesis) iff v₂(x) ≤ v₂(y). □

**Corollary 6.2.** *Order equivalence is an equivalence relation on α → ℕ.* This follows directly from reflexivity, symmetry, and transitivity, which we verify individually.

## 7. Holographic Duality

**Theorem 7.1 (Capacity Characterization of Closed Sets).** *A set S is closed under C if and only if cap_C(S) = |S|.*

*Proof sketch.* Since S ⊆ cl_C(S), we have |S| ≤ |cl_C(S)| = cap_C(S). Equality holds iff cl_C(S) = S (since for finite sets, A ⊆ B and |A| = |B| implies A = B). □

**Theorem 7.2 (Holographic Duality).** *If cap_{C₁}(S) = cap_{C₂}(S) for all S, then cl_{C₁} = cl_{C₂}.*

*Proof sketch.* Fix S. We need cl₁(S) = cl₂(S). By extensiveness, cl₁(S) ⊆ cl₂(cl₁(S)). By idempotence of cl₁, cap₁(cl₁(S)) = |cl₁(S)|. By the capacity hypothesis, cap₂(cl₁(S)) = cap₁(cl₁(S)) = |cl₁(S)|. So cl₂(cl₁(S)) has the same cardinality as cl₁(S), and since cl₁(S) ⊆ cl₂(cl₁(S)), we get cl₂(cl₁(S)) = cl₁(S) — meaning cl₁(S) is cl₂-closed.

Now cl₂(S) ⊆ cl₂(cl₁(S)) = cl₁(S) by monotonicity and the above. Also cap₁(S) = cap₂(S) means |cl₁(S)| = |cl₂(S)|. Combined with cl₂(S) ⊆ cl₁(S), finite cardinality equality gives cl₁(S) = cl₂(S). □

**Remark.** The name "holographic duality" is chosen by analogy with the holographic principle in physics: the "boundary data" (a scalar-valued capacity function) completely determines the "bulk" (a set-valued closure function). The capacity is a dramatic compression of the closure's information, yet no information is lost.

## 8. Minimal Realizations

**Theorem 8.1 (Existence of Minimal Realization).** *Every gauge-realizable closure operator admits a minimal realization — a valuation of smallest rank among all realizations.*

*Proof sketch.* The set of realizable ranks is a nonempty subset of ℕ (nonempty because a realization exists by hypothesis, and bounded above by |α| since any valuation on α takes at most |α| distinct values). By the well-ordering principle of ℕ, a minimum exists. □

**Theorem 8.2 (Normalization Preserves Order).** *The normalized valuation v̂(x) = |{y : v(y) < v(x)}| is order-equivalent to v.*

*Proof sketch.* If v(x) ≤ v(y), then {z : v(z) < v(x)} ⊆ {z : v(z) < v(y)}, so v̂(x) ≤ v̂(y) by monotonicity of cardinality. Conversely, if v(x) > v(y), then {z : v(z) < v(y)} ⊊ {z : v(z) < v(x)} (since y itself is in the latter but not the former), so v̂(y) < v̂(x). □

**Theorem 8.3 (Uniqueness Up to Gauge Equivalence).** *Any two realizations of the same closure are order-equivalent.*

*Proof sketch.* This is an immediate consequence of the Gauge Uniqueness Theorem (6.1). □

**Theorem 8.4 (Certified Reconstruction).** *Given a closure operator with the chain property, the construction v(x) = |cl({x})| − |cl(∅)| produces a minimal realization.*

*Proof sketch.* Theorem 5.2 shows this v realizes the closure. Minimality follows from the existence theorem applied to the chain-implies-realizable direction. □

## 9. Separation and Injectivity

**Theorem 9.1 (Separation ⟺ Injectivity).** *A valuation closure cl_v is separated if and only if v is injective.*

*Proof sketch.* (⟸) If v is injective and a ≠ b, then v(a) ≠ v(b), so WLOG v(a) < v(b). Then b ∈ cl_v({b}) but b ∉ cl_v({a}) (since v(b) > v(a) = sup({a}) v), so cl_v({a}) ≠ cl_v({b}).

(⟹) Contrapositive: if v(a) = v(b) with a ≠ b, then for any x, v(x) ≤ v(a) iff v(x) ≤ v(b), so cl_v({a}) = cl_v({b}), contradicting separation. □

**Theorem 9.2 (Separated Chain ⟹ Injective Realization).** *If a closure operator has the chain property and is separated, it admits an injective realization.*

*Proof sketch.* Take the realization from Theorem 5.2 and apply Theorem 9.1. □

## 10. Concrete Examples and Counterexamples

**Example 10.1 (Total Closure).** The closure cl(S) = α (mapping every set to the whole universe) is gauge-realizable: use the constant valuation v(x) = 0. Then cl_v(S) = {x : 0 ≤ 0} = α for any nonempty S, and cl_v(∅) = {x : 0 ≤ 0} = α.

**Example 10.2 (Discrete Closure — Non-realizable).** The identity closure cl(S) = S on a set with |α| ≥ 2 is *not* gauge-realizable. Every singleton is closed, but for distinct elements a, b: {a} ⊈ {b} and {b} ⊈ {a}. The closed sets fail the chain condition, so by the Realization Duality, no valuation can produce this closure.

**Example 10.3 (Three-Element Ranking).** On α = {a, b, c} with v(a) = 1, v(b) = 2, v(c) = 3:
- cl_v({a}) = {a} (all elements with value ≤ 1)
- cl_v({b}) = {a, b} (all elements with value ≤ 2)
- cl_v({c}) = {a, b, c} (all elements with value ≤ 3)
- cl_v({a, c}) = {a, b, c} (sup is 3)

The closed sets are: {a}, {a,b}, {a,b,c}, forming a chain.

## 11. Connections to Other Fields

### 11.1 Tropical Algebra

The supremum operation in cl_v(S) = {x : v(x) ≤ sup_S v} is the "addition" in the tropical semiring (ℕ, max, +). The closure can be viewed as a tropical linear dependence relation: x is "tropically dependent" on S if v(x) is bounded by the tropical sum (= max) of v over S. The chain condition then becomes a statement about tropical rank.

### 11.2 Automata Theory and Nerode Equivalence

The Realization Duality parallels the Myhill-Nerode theorem for regular languages. In both cases, an abstract algebraic condition (chain / finite index) characterizes when abstract data (closure / language) admits a concrete finite realization (gauge valuation / finite automaton). The gauge rank corresponds to the number of Nerode equivalence classes.

### 11.3 Discrete Gauge Theory

In lattice gauge theory, a gauge field assigns group elements to edges of a lattice, and observables are Wilson loops (traces of holonomy around closed paths). Our gauge valuations abstract this: the valuation v assigns a "holonomy capacity" to each element, and gauge equivalence (order equivalence) abstracts the gauge transformation group. The uniqueness theorem formalizes that physically observable quantities (the closure) determine the gauge field up to gauge transformations.

### 11.4 Database Theory

In functional dependency theory, closure operators model attribute dependencies. The chain condition identifies the special case where dependencies have a *linear* structure — every pair of attribute sets is functionally comparable. The capacity function serves as a dimension theory for attribute dependence.

## 12. Discussion

The Closure–Gauge Realization Duality provides a clean, self-contained example of several recurring themes in mathematics:

1. **Realization theory**: Abstractly specified objects (closures) characterized by concrete representations (valuations).
2. **Uniqueness modulo symmetry**: Representations are unique up to the natural symmetry group (gauge equivalence).
3. **Holographic encoding**: A dramatically compressed observable (capacity = a single number per set) determines the full structure.
4. **Structural rigidity from order**: The chain condition — a pure order-theoretic property — is the exact boundary between realizable and non-realizable closures.

All results in this paper have been machine-verified. The formalization uses approximately 400 lines of code and depends on standard finite set and order theory libraries.

## 13. Future Work

Several directions extend this work naturally:

1. **Multi-dimensional valuations**: Replace v : α → ℕ by v : α → ℕ^k and study cl_v(S) = {x : v(x) ≤_componentwise sup_S v}. The chain condition should generalize to a lattice-width condition.

2. **Weighted capacity and information measures**: Replace cardinality-based capacity with weighted versions (e.g., entropy of the closure's characteristic function) and study what information-theoretic functionals still satisfy the holographic property.

3. **Infinite generalizations**: Extend to countable or uncountable α with appropriate topological or measure-theoretic structure.

4. **Categorical formulation**: Express the duality as an equivalence of categories between "chain closure spaces" and "gauge valuation spaces modulo order equivalence."

5. **Algorithmic aspects**: Determine the computational complexity of testing gauge realizability and computing minimal realizations for explicitly represented closure operators.

## 14. Proof Techniques and Formalization Notes

The proofs in this paper employ a small but effective toolkit from finite combinatorics and order theory. We highlight several techniques that recur throughout the development.

### 14.1 The Singleton Probe Technique

Several key results (Gauge Uniqueness, the backward direction of the Realization Duality) rely on the observation that membership in a closure can be detected via singleton closures: x ∈ cl(S) if and only if cl({x}) ⊆ cl(S). This reduces questions about arbitrary sets to questions about singletons, which are much more tractable. The proof proceeds by extensiveness ({x} ⊆ cl(S) when x ∈ cl(S)), monotonicity (cl({x}) ⊆ cl(cl(S))), and idempotence (cl(cl(S)) = cl(S)).

### 14.2 Cardinality Arguments for Finite Set Equality

A recurring proof pattern is: to show A = B for finite sets, first show A ⊆ B, then show |A| ≥ |B| (or equivalently |A| = |B|). This is used in the Holographic Duality proof, where the subset direction comes from monotonicity/extensiveness and the cardinality direction comes from the capacity hypothesis. This technique avoids the need to construct explicit element-wise bijections.

### 14.3 The Maximum-Carrier Lemma

The proof that chain closures are realizable relies on a key structural lemma: in a chain closure, every nonempty set S has a "carrier" element s₀ ∈ S such that cl(S) = cl({s₀}). The carrier is the element of S whose singleton closure is largest (in cardinality). The chain condition ensures that all singleton closures are comparable, so the maximum exists and absorbs all others under the closure.

### 14.4 Well-Ordering for Existence of Minimal Realizations

The existence of minimal realizations uses the well-ordering principle of ℕ: the set of achievable ranks is a nonempty subset of natural numbers bounded above by |α|, hence has a minimum. This is a non-constructive argument — it does not produce the minimal realization explicitly. The certified reconstruction theorem provides the constructive counterpart.

### 14.5 Formalization Scope

The complete formalization covers 12 sections with approximately 400 lines of machine-verified proof code. The development is self-contained, building only on standard finite set and order theory from the Mathlib library. No specialized mathematical machinery (measure theory, topology, or algebra beyond basic order theory) is required, making the formalization accessible and the proofs highly transparent.

The formalization uncovered several subtle points that are easy to overlook in informal presentations:

- The treatment of the empty set requires care: cl_v(∅) = {x : v(x) ≤ 0} may be nonempty (when some elements have value 0). The reconstruction formula v(x) = |cl({x})| − |cl(∅)| handles this correctly by subtracting the base level.

- Order equivalence is strictly weaker than equality of closures when the minimum value differs. Two order-equivalent valuations with different minimum values can produce different closures on the empty set. The Gauge Uniqueness theorem states the converse direction: equal closures imply order equivalence.

- The non-realizability of the discrete (identity) closure on sets with ≥ 2 elements is proved by a direct diagonal argument: any proposed valuation would need to satisfy v(0) ≤ v(1) and v(1) ≤ v(0) simultaneously (from the singleton closure conditions), forcing v(0) = v(1) and hence cl({0}) = cl({1}) ≠ {0}, contradicting the identity closure.
