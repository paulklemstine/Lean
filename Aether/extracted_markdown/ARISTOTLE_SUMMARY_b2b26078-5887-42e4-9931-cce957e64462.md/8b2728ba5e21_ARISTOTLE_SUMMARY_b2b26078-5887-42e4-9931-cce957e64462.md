## P = NP Cannot Be Proven

**P vs NP is an open Millennium Prize Problem.** No valid proof exists in either direction, and the overwhelming consensus among complexity theorists is that P ≠ NP. I cannot produce a machine-verified Lean proof of a statement for which no mathematical proof is known to exist.

### Why the Berggren Tree Argument Fails

The claim that the Berggren tree provides a polynomial-time mapping for Subset Sum contains fundamental errors, which the existing `Factor/PvsNP.lean` file already formalizes rigorously:

1. **Exponential branching:** The Berggren tree has 3^d nodes at depth d — exponential, not polynomial. Formally proven in `berggren_superpolynomial`.

2. **Exponential search space:** Subset Sum over n elements has 2^n candidate subsets, and no polynomial bound covers this. Formally proven in `no_poly_covering`.

3. **Structural mismatch:** Enumerating Pythagorean triples (a² + b² = c²) is unrelated to deciding whether a subset of integers sums to a target. No reduction between these problems is provided or known.

4. **NP-completeness is robust:** Even if one could solve Subset Sum efficiently via some structure, proving P=NP requires showing *all* NP problems reduce to it in polynomial time — the Berggren tree provides no mechanism for this.

### What IS Proven in the Repository

The existing `Factor/PvsNP.lean` contains machine-verified proofs of:
- ✅ The Subset Sum problem definition and decidability
- ✅ Subset Sum ∈ NP (efficient verification)
- ✅ The search space is exponential (2^n subsets)
- ✅ The Berggren tree is exponential (3^d nodes dominate any polynomial)
- ✅ No polynomial covering of exponential space exists

These are the strongest honest statements that can be made. Introducing a `theorem P_eq_NP` would require `sorry` (unproven) or logical inconsistency (invalid), neither of which constitutes a proof.
