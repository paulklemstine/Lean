## Precise Theorem Statement

Work with a finite class of weighted acyclic directed graphs with:

- finitely many designated input nodes,
- finitely many designated output nodes,
- edge weights in `ℝ`,
- min-plus path evaluation,
- a reducedness condition excluding boundary-invisible or generator-redundant internal vertices.

Let `T_G : Fin m → Fin n → ℝ` denote the tropical transfer matrix:
\[
T_G(i,j)=\inf\{\text{weight}(p)\mid p:\text{path from input }i\text{ to output }j\}.
\]

Let `TransferSemimodule T` be the idempotent semimodule generated by the boundary response vectors of `T` under tropical linear combination. Let `IsTransferIrredundant T` mean that the generating family consists exactly of extremal generators, with no generator obtainable as a tropical combination of the others. Let `IsMinimalTransferRealization G` mean that `G` is reduced and no strictly smaller boundary-preserving weighted acyclic network realizes the same transfer matrix.

### Main duality theorem
For the chosen finite reduced class, prove:

\[
\forall G,\;
\mathrm{ReducedScatteringNetwork}(G)
\to
\Big(
\mathrm{IsMinimalTransferRealization}(G)
\leftrightarrow
\mathrm{IsTransferIrredundant}(T_G)
\Big).
\]

### Existence-and-uniqueness theorem
For every finitely generated irredundant transfer semimodule `M`, there exists a reduced weighted acyclic network `G_M` such that:

1. `TransferSemimodule (T_{G_M}) = M`,
2. `G_M` is minimal,
3. if `G` and `G'` are minimal reduced realizations of the same transfer semimodule, then they are isomorphic by a weighted boundary-preserving graph isomorphism.

Formally, the uniqueness should be stated as:
\[
\forall G\,G',\;
\mathrm{ReducedScatteringNetwork}(G)\to
\mathrm{ReducedScatteringNetwork}(G')\to
\mathrm{IsMinimalTransferRealization}(G)\to
\mathrm{IsMinimalTransferRealization}(G')\to
T_G = T_{G'}
\to
G \cong_{\partial,w} G'.
\]

### Certified reconstruction theorem
Define a reconstruction procedure from `T` using extremal generators and path-separation certificates. Prove:

- if the certificate predicate holds, the procedure returns a minimal realization,
- the returned realization is correct and unique up to boundary-preserving weighted isomorphism.

This theorem is the mathematical heart of the cryptographic interpretation: forward transfer evaluation is easy; inversion is not arbitrary factorization but **certificate-governed realization recovery**.

## Proof Strategy A: Extremal-generator reconstruction from transfer columns/rows

This is the most promising route.

### Step 1
Show that the boundary response data extracted from a reduced network defines a finitely generated idempotent semimodule, and that every internal vertex contributes a generator whose response vector is extremal exactly when the vertex is indispensable.

This is where you should use min-plus linearity aggressively. The existing theorem

- `tropical_plus_distributes_over_min`

from `Bridges/MinPlusVerificationCore.lean`

should be used to normalize tropical combinations and prove closure properties of the response set under tropical addition/scaling.

### Step 2
Prove that reduced minimality of the network is equivalent to irredundancy of these generators. One direction should be direct: if a generator is tropically dependent, contract/delete the corresponding internal node without changing transfer behavior. The converse should use path witness arguments: if a node is indispensable, there exists a pair of boundary conditions whose optimal path necessarily separates through that node.

### Step 3
Construct a canonical realization from the extremal generators of the semimodule. Then prove:
- it realizes the given transfer matrix,
- it is reduced,
- any other minimal realization has the same extremal generator poset and hence is boundary-preserving isomorphic.

Why this route is strongest: it directly converts semimodule extremality into graph-theoretic indispensability, which is exactly the conceptual bridge needed for the cryptographic story.

### Step 3

Why it matters: this reframes the theorem as a tropical analogue of minimal automata / Hankel-state realization. It opens a route to a full tropical systems theory, not just one theorem.

## Proof Strategy C: Poset/antichain encoding via acyclicity

This may simplify the acyclic case and make formalization more robust.

### Step 1
Use acyclicity to topologically order internal vertices and define for each vertex its forward and backward boundary profiles.

### Step 2
Show that the transfer matrix is recovered as a min-plus convolution over these profiles, and that irredundancy corresponds to an antichain/extremality condition in the profile poset.

### Step 3
Prove minimality by induction on the topological order: removable vertices correspond exactly to non-extremal profile elements.

Why this route is useful: acyclicity is a powerful finiteness hypothesis, and Lean often likes induction on a DAG order better than abstract semimodule arguments.

/-- A weighted acyclic graph with source and sink boundary embeddings.

structure WeightedAcyclicGraph (K : Type u) (B : Type u) [Zero K] where
  /-- The vertex type -/

  /-- Vertices form a finite type -/

  /-- Layer assignment enforcing acyclicity -/
  layer : V → ℕ

  weight : V → V → K
  /-- Acyclicity: edges only go from lower to higher layers -/
  edge_respects_layer : ∀ u v, weight u v ≠ 0 → layer u < layer v

/-! ## Section 2: Transfer Matrix via Path Aggregation -/

/-- Matrix power: `matPow G n i j` sums over all length-n paths from i to j. -/
noncomputable def matPow (G : WeightedAcyclicGraph K B) :
    ℕ → (G.V → G.V → K)
  | 0 => fun i j => if i = j then 1 else 0
  | n + 1 => fun i j => ∑ k : G.V, G.weight i k * G.matPow n k j

/-- All-paths transfer: sum of path weights up to given length bound. -/
noncomputable def allPathsTransfer (G : WeightedAcyclicGraph K B)
    (bound : ℕ) (i j : G.V) : K :=
  ∑ k ∈ Finset.range (bound + 1), G.matPow k i j

/-- The boundary-to-boundary transfer matrix: source b₁ to sink b₂. -/
noncomputable def transferMatrix (G : WeightedAcyclicGraph K B)
    (b₁ b₂ : B) : K :=
  G.allPathsTransfer (Fintype.card G.V) (G.sourceEmb b₁) (G.sinkEmb b₂)

/-- Number of internal vertices (total minus boundary). -/
noncomputable def internalVertexCount (G : WeightedAcyclicGraph K B) : ℕ :=
  Fintype.card G.V - 2 * Fintype.card B

def RealizesTransferMatrix {K : Type u} {B : Type u}

    (G : WeightedAcyclicGraph K B) (H : B → B → K) : Prop :=
  G.transferMatrix = H

def IsMinimalTransferMatrixRealization {K : Type u} {B : Type u}
    [CommSemiring K] [Fintype B] [DecidableEq B]
    (H : B → B → K) (G : WeightedAcyclicGraph K B) : Prop :=
  RealizesTransferMatrix G H ∧
    ∀ G' : WeightedAcyclicGraph K B,
      RealizesTransferMatrix G' H →
      G.internalVertexCount ≤ G'.internalVertexCount

/-- An idempotent subsemimodule of `B → K`. -/
structure IdempotentSubsemimodule (K : Type u) (B : Type u) [CommSemiring K] where
  carrier : Set (B → K)
  zero_mem : (fun _ => (0 : K)) ∈ carrier
  add_mem : ∀ {f g}, f ∈ carrier → g ∈ carrier → (fun b => f b + g b) ∈ carrier
  smul_mem : ∀ (c : K) {f}, f ∈ carrier → (fun b => c * f b) ∈ carrier

def BoundaryMonotone {K B : Type u} [CommSemiring K] [Preorder K]
