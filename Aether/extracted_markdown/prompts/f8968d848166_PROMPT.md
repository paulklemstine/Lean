**Mode:** `prove` + `discover`

## Core Mathematical Vision

The identity
\[
a^3+b^3+(-a-b)^3 = -3ab(a+b)
\]
does more than produce examples. It exhibits a rational curve on each fiber \(X_k\), and the image set
\[
\mathcal V := \{-3ab(a+b): a,b\in\mathbb Z\}
\]
is the arithmetic shadow of that curve family. The breakthrough is to define and study the **constructively representable locus**
\[
\mathcal C := \{k\in\mathbb Z : \exists \text{ a certified integer-parametric rational curve on } X_k\},
\]
beginning with the binary cubic family above, and prove nontrivial structure theorems about \(\mathcal V\).

This is not just a local-global curiosity. It is the first step toward a formal correspondence:

> **parametric identities for three cubes  \(\leftrightarrow\)  rational curves on cubic surfaces  \(\leftrightarrow\)  explicit arithmetic subsets of integers.**

If done well, this opens a new formalized interface between algebraic geometry and additive number theory.

### Theorem 1: Certified parametric representation theorem
This upgrades the catalog identity into a reusable family statement.

**Mathematical statement**
\[
\forall a,b\in\mathbb Z,\quad a^3+b^3+(-a-b)^3 = -3ab(a+b).
\]
Hence every integer of the form \(-3ab(a+b)\) is representable as a sum of three cubes.

**Lean 4 target signature**
```lean
theorem diagonalCollapseFamily_spec (a b : ℤ) :
    a^3 + b^3 + (-a - b)^3 = -3 * a * b * (a + b)
```

and derived existence theorem
```lean
theorem mem_valueSet_diagonalCollapse_iff (k : ℤ) :
    k ∈ valueSet diagonalCollapseFamily ↔
      ∃ a b : ℤ, k = -3 * a * b * (a + b)
```

and representation theorem
```lean
theorem diagonalCollapse_represents (k : ℤ) :
    k ∈ valueSet diagonalCollapseFamily →
      ∃ x y z : ℤ, x^3 + y^3 + z^3 = k
```

**Why this matters**
This theorem is the certified basepoint of the whole program: it transforms one identity into an object in a theory of parametric families.

### Theorem 2: Symmetry and orbit-collapse theorem for the binary cubic form
The form
\[
F(a,b)= -3ab(a+b)
\]
has nontrivial symmetry under the \(S_3\)-action generated by
\[
(a,b),\quad (b,a),\quad (-a-b,a),\quad (a,-a-b),\quad (b,-a-b),\quad (-a-b,b).
\]
You should prove that all these give the same value.

**Mathematical statement**
For all \(a,b\in\mathbb Z\),
\[
F(a,b)=F(b,a)=F(-a-b,a)=F(a,-a-b)=F(b,-a-b)=F(-a-b,b).
\]

**Lean 4 target signature**
```lean
def diagonalCubic (a b : ℤ) : ℤ := -3 * a * b * (a + b)

theorem diagonalCubic_symm_swap (a b : ℤ) :
    diagonalCubic a b = diagonalCubic b a

theorem diagonalCubic_symm_cyclic₁ (a b : ℤ) :
    diagonalCubic a b = diagonalCubic (-a - b) a

theorem diagonalCubic_symm_cyclic₂ (a b : ℤ) :
    diagonalCubic a b = diagonalCubic b (-a - b)
```

Stronger optional packaged theorem:
```lean
theorem diagonalCubic_S3_invariant (a b : ℤ) :
    diagonalCubic a b = diagonalCubic b a ∧
    diagonalCubic a b = diagonalCubic (-a - b) a ∧
    diagonalCubic a b = diagonalCubic a (-a - b)
```

**Why this matters**
This is the arithmetic shadow of the line-permutation symmetry on the cubic relation \(x+y+z=0\). It is the first genuinely geometric structural theorem in the file: the parameter space has nontrivial orbit structure, and counting the value set requires quotienting by symmetry.

### Theorem 3: Primitive factorization obstruction / divisibility theorem
Exploit gcd structure of the factors \(a\), \(b\), and \(a+b\). This is where the project becomes number theory rather than symbolic algebra.

A robust theorem you can likely prove:

**Mathematical statement**
If \(\gcd(a,b)=1\), then
\[
\gcd(a,a+b)=1,\qquad \gcd(b,a+b)=1,
\]
so the three factors \(a,b,a+b\) are pairwise coprime up to sign. Consequently, any prime \(p\nmid 3\) dividing two of them divides the third only trivially.

Then derive a squarefree-support or divisibility consequence for values of \(F(a,b)\).

**Lean 4 target signatures**
```lean
theorem coprime_add_right_of_coprime {a b : ℤ} (h : IsCoprime a b) :
    IsCoprime a (a + b)

theorem coprime_add_left_of_coprime {a b : ℤ} (h : IsCoprime a b) :
    IsCoprime b (a + b)

theorem pairwise_coprime_factors_of_isCoprime {a b : ℤ} (h : IsCoprime a b) :
    IsCoprime a b ∧ IsCoprime a (a + b) ∧ IsCoprime b (a + b)
```

Then a value-form theorem such as:
```lean
theorem dvd_diagonalCubic_of_dvd_factor {p a b : ℤ} :
    p ∣ a → p ∣ diagonalCubic a b
```

and ideally a converse under coprimality hypotheses for primes \(p \nmid 3\):
```lean
theorem prime_dvd_diagonalCubic_of_coprime
    {p a b : ℤ} (hp : Nat.Prime p.natAbs) (h3 : ¬ (p : ℤ) ∣ 3)
    (hcop : IsCoprime a b) :
    p ∣ diagonalCubic a b → p ∣ a ∨ p ∣ b ∨ p ∣ (a + b)
```

**Why this matters**
This begins a sieve-theoretic analysis of the value set. The geometry gives the family; gcd decomposition gives the arithmetic control.

### Theorem 4: Growth lower bound on the number of produced values in a box
A full \(N^{2/3}\) lower bound may be too ambitious immediately in Lean, but you should still prove a genuine nontrivial counting theorem, not a toy bound.

A realistic first theorem is to construct a large injective subfamily. For example, restrict to positive pairs with \(1 \le a \le A\), \(1 \le b \le B\), and prove monotonicity in one variable when the other is fixed:
\[
b \mapsto 3ab(a+b)
\]
is strictly increasing for \(a>0\), \(b>0\). Then extract many distinct values.

**Mathematical statement**
For fixed \(a>0\), the map \(b \mapsto 3ab(a+b)\) is strictly increasing on positive integers. Hence for each fixed \(a\), the family produces at least \(B\) distinct positive values from \(1\le b\le B\).

**Lean 4 target signature**
```lean
theorem diagonalCubic_strictMono_right {a : ℤ} (ha : 0 < a) :
    StrictMono fun b : ℤ => 3 * a * b * (a + b)
```

If `StrictMono` on all integers is awkward, localize:
```lean
theorem diagonalCubic_lt_of_lt_of_pos {a b₁ b₂ : ℤ}
    (ha : 0 < a) (hb : 0 < b₁) (hlt : b₁ < b₂) :
    3 * a * b₁ * (a + b₁) < 3 * a * b₂ * (a + b₂)
```

Then derive a distinctness theorem:
```lean
theorem diagonalCubic_injective_right_on_pos {a b₁ b₂ : ℤ}
    (ha : 0 < a) (hb₁ : 0 < b₁) (hb₂ : 0 < b₂)
    (hEq : 3 * a * b₁ * (a + b₁) = 3 * a * b₂ * (a + b₂)) :
    b₁ = b₂
```

**Why this matters**
This is the first step toward a formal density theorem: before asymptotics, certify a mechanism that forces many distinct represented integers. This is the arithmetic analogue of proving that the rational curve map is not degenerate.

### Theorem 5: Cross-domain bridge theorem — algebraic geometry encoded arithmetically
You are required to include at least one theorem linking this domain to another. The cleanest bridge is to algebraic geometry via the linear section \(x+y+z=0\).

**Mathematical statement**
The polynomial identity
\[
x^3+y^3+z^3-3xyz = (x+y+z)(x^2+y^2+z^2-xy-yz-zx)
\]
implies that on the hyperplane \(x+y+z=0\),
\[
x^3+y^3+z^3 = 3xyz.
\]
Substituting \(z=-x-y\) yields the diagonal family. This is the factorization theorem connecting the cubic surface to a reducible geometric slice.

**Lean 4 target signature**
```lean
theorem sum_cubes_sub_three_mul_factor (x y z : ℤ) :
    x^3 + y^3 + z^3 - 3*x*y*z =
      (x + y + z) * (x^2 + y^2 + z^2 - x*y - y*z - z*x)

theorem sum_cubes_eq_three_xyz_of_sum_zero {x y z : ℤ}
    (h : x + y + z = 0) :
    x^3 + y^3 + z^3 = 3*x*y*z
```

Then connect it to the family:
```lean
theorem diagonalCollapse_from_hyperplane_section (a b : ℤ) :
    a^3 + b^3 + (-a - b)^3 = 3 * a * b * (-a - b)
```

**Why this matters**
This is the bridge theorem. It translates a classical factorization identity into the geometry of hyperplane sections of cubic surfaces. That is exactly the kind of cross-domain connection this project should formalize.

## Proof Strategy Architecture

You must not rely on one-line simplification. Use genuine proof structure.

### Strategy A: Algebraic-factorization route
Most promising for the geometric bridge theorems.

1. Prove the factorization
   \[
   x^3+y^3+z^3-3xyz=(x+y+z)(x^2+y^2+z^2-xy-yz-zx)
   \]
   by `ring_nf` only as a substep, not as the whole theorem narrative.
2. Specialize to \(z=-x-y\) or to the hypothesis \(x+y+z=0\).
3. Derive the diagonal family identity and package it as an instance of `ThreeCubeParamFamily`.

**Why promising:** it reveals the geometry and immediately generalizes to future line/plane sections.

---

### Strategy B: Arithmetic-structure route
Best for divisibility and sieve-flavored results.

1. Establish coprimality transfer lemmas: from `IsCoprime a b` derive `IsCoprime a (a+b)` and `IsCoprime b (a+b)`.
2. Use prime divisibility arguments and `rcases` on divisibility of products.
3. Derive structural constraints on represented values \(k=-3ab(a+b)\), especially away from the prime \(3\).

**Why promising:** it creates the machinery needed for density heuristics and computational filtering.

---

### Strategy C: Monotonicity/counting route
Best for proving distinct-value lower bounds without asymptotic machinery.

1. For fixed positive \(a\), compare
   \[
   3ab_1(a+b_1)\quad\text{and}\quad 3ab_2(a+b_2)
   \]
   for \(b_1<b_2\).
2. Expand the difference and prove positivity using `linarith`, `nlinarith`, `calc`, or explicit factorization.
3. Deduce injectivity on a box and extract a finite distinctness theorem.

**Why promising:** it gives an honest lower-bound theorem now, and can later be upgraded to asymptotics.

Start with **Strategy A**, then immediately combine with **Strategy B**. Add one **Strategy C** theorem so the file contains a concrete counting mechanism rather than pure structure.

That combination yields a coherent mini-theory:

### Main conjecture
Let
\[
V(N)=\#\{k\in [1,N] : \exists a,b\in\mathbb Z,\ k=3ab(a+b)\}.
\]
Then there exists \(c>0\) such that
\[
V(N)\ge cN^{2/3}
\]
for all sufficiently large \(N\).

A stronger heuristic version:
\[
V(N)\sim C N^{2/3}
\]
for some explicit constant \(C>0\) after quotienting by symmetry and local obstructions.

### Computational falsification protocol
Enumerate
\[
\{\,|3ab(a+b)| : |a|,|b|\le B\,\}
\]
for \(B=100,200,\dots,1000\), compute \(V(N)\) for \(N\le 10^6\), and fit the ratio
\[
V(N)/N^{2/3}.
\]
The conjecture is threatened if this ratio drifts convincingly toward \(0\) across scales.
