## Core breakthrough target

Define a general notion of an **equivariant task** associated to a group action, and prove that nontrivial orbit structure obstructs canonical solvability.

The correct unifying idea is not merely “free action,” but:

- **No canonical representative exists on a nontrivial torsor**.
- **No equivariant selector exists from an orbit to its points when symmetry is nontrivial**.
- **No invariant deterministic decoder can break symmetry uniformly across all inputs**.

This touches algebra, topology, social choice, and physics.

## Precise formal target

Introduce a new concept not already standard in Mathlib:

```lean
structure EquivariantTask (G X Y : Type*) [Group G] [MulAction G X] [MulAction G Y] where
  admissible : X → Set Y
  equiv_admissible :
    ∀ g x y, y ∈ admissible x ↔ g • y ∈ admissible (g • x)
```

Then define solvability:

```lean
def TaskSolvable (G X Y : Type*) [Group G] [MulAction G X] [MulAction G Y]
    (T : EquivariantTask G X Y) : Prop :=
  ∃ f : X → Y, (∀ x, f x ∈ T.admissible x) ∧
    ∀ g x, f (g • x) = g • f x
```

Also define the canonical “orbit-point selection task” for a `G`-set `X`, where the output space is `X` itself and admissible outputs at `x` are exactly the orbit of `x`:

```lean
def OrbitSelectionTask (G X : Type*) [Group G] [MulAction G X] :
    EquivariantTask G X X
```

The central theorem should be a sharp impossibility statement of the following flavor.

### Theorem A: no equivariant selector on a nontrivial free orbit
For a group acting freely and nontrivially on a type, there is no equivariant map selecting a canonical point of each orbit.

A Lean-shape target:

```lean
theorem no_equivariant_orbit_selector_of_free_nontrivial
    (G X : Type*) [Group G] [MulAction G X]
    (hfree : ∀ g : G, g ≠ 1 → ∀ x : X, g • x ≠ x)
    (hne : ∃ g : G, g ≠ 1)
    (htrans : ∀ x y : X, ∃ g : G, g • x = y) :
    ¬ TaskSolvable G X X (OrbitSelectionTask G X)
```

This theorem captures the essence of “you cannot make a symmetry-respecting canonical choice on a homogeneous free space.”

But do not stop there.

### Theorem B: converse existence of an impossible task from a free action
The user explicitly asked for a converse. The correct version is:

> If a group acts freely and has a nontrivial orbit, then there exists a natural equivariant task on that `G`-set which is impossible.

Formal target:

```lean
theorem exists_impossible_equivariant_task_of_free_action
    (G X : Type*) [Group G] [MulAction G X]
    (hfree : ∀ g : G, g ≠ 1 → ∀ x : X, g • x ≠ x)
    (horbit : ∃ x g, g ≠ 1) :
    ∃ T : EquivariantTask G X X, ¬ TaskSolvable G X X T
```

The proof should instantiate `T := OrbitSelectionTask G X` under suitable nontriviality hypotheses.

### Theorem C: fixed-point obstruction implies impossibility of invariant decoding
A second, deeper theorem should move beyond freeness and capture the real phenomenon: impossibility occurs when the task asks for an invariant or equivariant output but the source has “too much symmetry.”

For example, define an invariant-decoding task into a trivial action target:

```lean
def InvariantTask (G X Y : Type*) [Group G] [MulAction G X] [MulAction G Y]
    (S : X → Set Y) : EquivariantTask G X Y := ...
```

Then prove a theorem like:

```lean
theorem no_invariant_decoder_on_single_free_orbit
    (G X Y : Type*) [Group G] [MulAction G X] [MulAction G Y]
    [Subsingleton Y]
    (htrans : ∀ x y : X, ∃ g : G, g • x = y)
    (hnot_subsingleton : ¬ Subsingleton X) :
    ¬ ∃ f : X → Y, ∀ g x, f (g • x) = g • f x
```

or a more refined theorem where `Y` has trivial action and admissibility distinguishes orbit points in a way incompatible with equivariance.

### Theorem D: finite-group counting obstruction
For finite `G`-sets, prove a Burnside-flavored impossibility criterion: if all stabilizers are trivial and `X` is finite with `|G| > 1`, then no `G`-equivariant retraction from `X` onto a singleton orbit representative exists.

Possible Lean statement:

```lean
theorem no_equivariant_retraction_of_free_finite_action
    (G X : Type*) [Finite G] [Fintype G] [Group G]
    [Finite X] [Fintype X] [MulAction G X]
    (hfree : ∀ g : G, g ≠ 1 → ∀ x : X, g • x ≠ x)
    (hne : Fintype.card G > 1) :
    ¬ ∃ r : X → X, (∀ g x, r (g • x) = g • r x) ∧
      ∀ x y, r x = r y
```

This theorem gives a concrete combinatorial impossibility engine.

## 2–3 proof strategy paths

### Strategy A: torsor contradiction via transitivity and freeness
Most promising for Theorem A.

1. Assume an equivariant selector `f : X → X` exists.
2. Use transitivity to show `f` is determined by its value at one basepoint.
3. Use equivariance to derive `f (g • x) = g • f x`.
4. Since admissibility forces `f x` to lie in the orbit of `x`, identify `f` with translation by a fixed group element.
5. Show “constant orbit representative” or selector property contradicts freeness/nontriviality.

Why promising: it is conceptual, avoids heavy finite combinatorics, and matches the torsor intuition exactly.

### Strategy B: quotient/section obstruction
Best for a cleaner categorical statement.

1. Pass from `X` to orbit quotient `X ⧸ G`.
2. Show a solvable orbit-selection task yields a section of the quotient map.
3. Prove that if the action is free and transitive nontrivial, such a `G`-equivariant section would force a fixed point or trivialize the torsor.
4. Derive contradiction.

Why promising: this makes the theorem reusable and positions future work toward principal bundles, descent, and topological obstruction theory.

### Strategy C: finite counting / Burnside-style obstruction
Best for Theorem D and computational demos.

1. In a finite free action, every orbit has cardinality `|G|`.
2. Any equivariant retraction collapsing all points to a canonical representative would define an orbit of size `1`.
3. This contradicts orbit-size divisibility unless `|G| = 1`.

Why promising: extremely explicit, computable, and ideal for `demo.py`.

Recommended priority: **A first, then D, then E, then B/C abstractions**.
