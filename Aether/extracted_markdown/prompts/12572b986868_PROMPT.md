## Research Task: EML Stone–Weierstrass for compact Hausdorff codomains presented as inverse limits of compact metrizable ANR stages

Research Mode: PROVE

Establish a codomain-universal approximation theorem along the following inverse-limit bridge:

- input space `X` is compact Hausdorff,
- codomain `Y` is compact Hausdorff and realized as an inverse limit of compact metrizable ANRs with surjective bonding maps,
- every continuous `f : X → Y` can be uniformly approximated by EML-realizable maps.

The key point is that the already-completed ANR-valued approximation theorem should be used only at the metrizable stage level; the genuinely new content is to control compatibility across the inverse system well enough to reconstruct a global approximation in the limit codomain.

### Recommended intermediate lemmas

You should isolate the genuinely geometric content into 3–5 reusable lemmas.

1. **Projection reduction / finite-coordinate control**

```lean
theorem inverseLimit_metric_control
    {L : Type*} [MetricSpace L]
    {Y : ℕ → Type*} [∀ n, MetricSpace (Y n)]
    (π : ∀ n, L → Y n)
    (h_embed :
      ∀ ε > 0, ∃ N : ℕ, ∀ ⦃y z : L⦄,
        (∀ n ≤ N, dist (π n y) (π n z) < ε / 2) → dist y z < ε) :
    ∀ ε > 0, ∃ N : ℕ, ∀ ⦃f g : C(X, L)⦄,
      (∀ n ≤ N, distC ((ContinuousMap.comp (show C(L, Y n) from ⟨π n, ?_⟩) f))
                        ((ContinuousMap.comp (show C(L, Y n) from ⟨π n, ?_⟩) g)) < ε / 2) →
      distC f g < ε
```

The topological idea is standard: because `L` is compact Hausdorff and the inverse-limit projections separate points, the uniformity on `L` is generated by finitely many coordinate entourages. In metric form, this is exactly the statement above.

2. **Finite-stage compatible approximation**

For each `N`, approximate the truncated family `(π n ∘ f)_{n ≤ N}` by a *compatible* family of EML maps. A workable induction statement is:

```lean
theorem compatible_stagewise_eml_approx
    {X : Type*} [TopologicalSpace X] [CompactSpace X]
    {Y : ℕ → Type*}
    [∀ n, TopologicalSpace (Y n)]
    [∀ n, CompactSpace (Y n)]
    [∀ n, T2Space (Y n)]
    [∀ n, MetricSpace (Y n)]
    (p : ∀ n, C(Y (n+1), Y n))
    (h_surj : ∀ n, Function.Surjective (p n))
    (h_anr : ∀ n, CompactMetrizableANR (Y n))
    (h_eml_stage :
      ∀ n (f : C(X, Y n)) (δ : ℝ), 0 < δ →
        ∃ g : C(X, Y n), IsEMLMap g ∧ distC f g < δ) :
    ∀ N : ℕ, ∀ f : ∀ n ≤ N, C(X, Y n),
      (∀ ⦃m n⦄ (hm : m ≤ N) (hn : n ≤ N), m ≤ n →
        (p^[n-m]) ∘ f n hn = f m hm) →
      ∀ η > 0,
      ∃ g : ∀ n ≤ N, C(X, Y n),
        (∀ n hn, IsEMLMap (g n hn)) ∧
        (∀ n hn, distC (f n hn) (g n hn) < η) ∧
        (∀ ⦃m n⦄ (hm : m ≤ N) (hn : n ≤ N), m ≤ n →
          (p^[n-m]) ∘ g n hn = g m hm)
```

This exact statement may be too strong if exact compatibility is hard to impose directly. Then first prove an approximate compatibility version and only afterward rectify it using an ANR neighborhood retraction argument.

3. **Compatibility rectification via ANR neighborhoods**

This is likely the real new lemma. Let
\[
F_N := \{(y_0,\dots,y_N) \in \prod_{n \le N} Y_n \mid p_{n+1}(y_{n+1}) = y_n \text{ for all } n < N\}.
\]
Since finite products of compact metrizable ANRs are compact metrizable ANRs, and `F_N` is the equalizer of continuous maps between such spaces, you should show or assume as needed that `F_N` is itself a compact metrizable ANR. Then the map
\[
x \mapsto (\pi_0 f(x),\dots,\pi_N f(x))
\]
lands in `F_N`, and the already-proved ANR-valued EML Stone–Weierstrass theorem applies directly to `F_N`.

This gives a much cleaner theorem than trying to rectify coordinates after independent approximations:

```lean
theorem eml_dense_on_finite_limit_stage
    {X : Type*} [TopologicalSpace X] [CompactSpace X]
    {Y : ℕ → Type*}
    [∀ n, TopologicalSpace (Y n)]
    [∀ n, CompactSpace (Y n)]
    [∀ n, T2Space (Y n)]
    [∀ n, MetricSpace (Y n)]
    (p : ∀ n, C(Y (n+1), Y n))
    (h_anr : ∀ n, CompactMetrizableANR (Y n))
    (h_finite_limit_anr :
      ∀ N : ℕ, CompactMetrizableANR
        {y : ∀ n ≤ N, Y n // ∀ n (hn : n+1 ≤ N), p n (y (n+1) hn) = y n (Nat.le_trans (Nat.le_succ n) hn)})
    (h_eml_anr :
      ∀ {Z : Type*} [TopologicalSpace Z] [CompactSpace Z] [T2Space Z] [MetricSpace Z],
        CompactMetrizableANR Z →
        ∀ (f : C(X, Z)) (ε : ℝ), 0 < ε →
          ∃ g : C(X, Z), IsEMLMap g ∧ distC f g < ε) :
    ∀ N : ℕ,
      ∀ f : C(X,
        {y : ∀ n ≤ N, Y n // ∀ n (hn : n+1 ≤ N), p n (y (n+1) hn) = y n (Nat.le_trans (Nat.le_succ n) hn)}),
      ∀ ε > 0,
        ∃ g : C(X,
          {y : ∀ n ≤ N, Y n // ∀ n (hn : n+1 ≤ N), p n (y (n+1) hn) = y n (Nat.le_trans (Nat.le_succ n) hn)}),
          IsEMLMap g ∧ distC f g < ε
```

This route is conceptually strongest: instead of approximating coordinates and repairing them, package the finite compatibility constraints into a single ANR codomain and invoke the finished theorem once.

4. **Assembly from finite compatible truncations**

Once you have an EML approximation into the finite limit stage `F_N`, compose with the canonical map `F_N → L` coming from the universal property / chosen finite-stage lifting. This is where you use the inverse-limit presentation of `L`.

```lean
theorem assemble_from_finite_limit_stage
    {X : Type*} [TopologicalSpace X]
    {L : Type*} [TopologicalSpace L]
    {Y : ℕ → Type*} [∀ n, TopologicalSpace (Y n)]
    (π : ∀ n, C(L, Y n))
    (sN : ∀ N, C(
      {y : ∀ n ≤ N, Y n // CompatTrunc p N y},
      L))
    (h_section :
      ∀ N n (hn : n ≤ N), π n ∘ sN N = truncProj p N n hn) :
    ∀ {fN : C(X, {y : ∀ n ≤ N, Y n // CompatTrunc p N y})},
      IsEMLMap fN → IsEMLMap (sN N ∘ fN)
```

This theorem should be easy once `IsEMLMap` is known to be stable under postcomposition by continuous maps.

### Concrete proof strategy

A robust route is:

1. **Replace the full inverse limit by finite compatible truncations.**
   For fixed `ε > 0`, use compactness/uniformity of the inverse-limit codomain `L` to find `N` such that control of the first `N` coordinates within `ε/2` implies control in `L` within `ε`. This is the finite-coordinate control lemma and is the place where compact Hausdorff inverse-limit topology enters.

2. **Package the first `N` coordinates as a single ANR codomain.**
   Define the finite limit stage
   ```lean
   FN := { y : ∀ n ≤ N, Y n // CompatTrunc p N y }.
   ```
   The map
   ```lean
   fN : C(X, FN)
   ```
   is obtained from `f : C(X, L)` by taking the first `N` projections. Do not approximate each coordinate separately unless necessary; the best proof is to view `FN` as one compact metrizable ANR and apply the existing EML Stone–Weierstrass theorem directly to `fN`.

3. **Use the ANR-valued EML approximation theorem on `FN`.**
   Given `δ > 0`, obtain `gN : C(X, FN)` with `IsEMLMap gN` and `distC fN gN < δ`. Choose `δ` small enough so that every coordinate projection differs by `< ε/2`.

4. **Lift / assemble back to the inverse limit codomain.**
   Compose `gN` with a continuous section or reconstruction map `sN : FN → L` coming from the chosen inverse-limit presentation. Set
   ```lean
   G := sN N ∘ gN.
   ```
   By closure of EML maps under continuous postcomposition, `G` is EML-realizable.

5. **Estimate the final error in `L`.**
   For each `x : X`, the first `N` coordinates of `G x` and `f x` are close because the projections of `sN N (gN x)` agree with the coordinates of `gN x`. Then apply finite-coordinate control to conclude
   ```lean
   distC f G < ε.
   ```

If exact finite-stage sections `sN` are unavailable globally, a weaker but still viable route is to use that `L` embeds as a closed subset of the full product and that finite compatible truncations admit approximate extension/retraction data. Then prove an approximate assembly lemma sufficient for density. But if at all possible, the exact finite-stage compatible-subspace route is much cleaner.

### Important Lean design choices

- Work sequentially over `ℕ`. General directed inverse systems are mathematically natural but are much harder to encode and are unnecessary for a first theorem.
- Use `ContinuousMap` explicitly everywhere; avoid abstract `C(X,Y)` notation unless already present.
- Define the finite compatible stage as a subtype of a dependent finite product indexed by `{n // n ≤ N}` if this is easier than `∀ n ≤ N, Y n`.
- If a custom `distC` is needed, define it only for compact-domain metric-codomain maps:
  ```lean
  def distC (f g : C(X, Z)) : ℝ := ‖f - g‖
  ```
  or a direct `sSup` formula. You only need the lemmas:
  - nonnegativity,
  - triangle inequality,
  - coordinate projection is 1-Lipschitz,
  - `distC f g < ε` implies pointwise `dist (f x) (g x) < ε`.

### Significance for the research program

This theorem is the correct next extension of the EML codomain-approximation program because it passes from “nice codomains” (convex sets, manifolds, metrizable ANRs, finite products) to a broad class of compact Hausdorff spaces obtained by inverse limits of such objects. That is a genuine shape-theoretic leap: many compacta of interest are not themselves obviously ANRs, but are pro-ANR or ANR-like through inverse systems. Proving density at this level would show that EML approximation is not merely a metric-manifold phenomenon but is stable under inverse-limit constructions, which is a strong structural universality statement. It also sets up the right formal infrastructure for an eventual codomain-universal approximation theorem, where codomains are handled via approximation by finite ANR shadows rather than ad hoc coordinate scalarization.
