## Primary Breakthrough Target

### Theorem Cluster A: Finite-dimensional spectral theorem for self-adjoint operators

Work over a finite-dimensional inner product space, preferably first in matrix form where Mathlib is strongest.

A precise target theorem:

```lean
theorem exists_orthonormalBasis_eigenvectors_of_isHermitian
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ)
    (hA : A.IsHermitian) :
    ∃ (U : Matrix n n ℂ) (d : n → ℝ),
      U ∈ Matrix.unitaryGroup n ∧
      A = U ⬝ (Matrix.diagonal fun i => (d i : ℂ)) ⬝ Uᴴ
```

Real variant:

```lean
theorem exists_orthogonal_diagonalization_of_isSymmetric
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℝ)
    (hA : A.IsSymmetric) :
    ∃ (Q : Matrix n n ℝ) (d : n → ℝ),
      Q ⬝ Qᵀ = 1 ∧
      A = Q ⬝ Matrix.diagonal d ⬝ Qᵀ
```

Equivalent operator-form statement, if infrastructure allows:

```lean
theorem exists_orthonormalBasis_of_selfAdjoint
    {E : Type*} [NormedAddCommGroup E] [InnerProductSpace ℂ E]
    [FiniteDimensional ℂ E]
    (T : E →ₗᵢ[ℂ] E)
    (hT : IsSelfAdjoint T) :
    ∃ (b : OrthonormalBasis ι ℂ E),
      ∀ i, ∃ μ : ℝ, T (b i) = (μ : ℂ) • b i
```

If the exact typeclasses differ in Mathlib, adapt to the existing self-adjoint matrix/operator API, but keep the theorem mathematically this strong.

## Theorem Cluster B: Courant–Fischer / min-max theorem

Do **not** stop at “eigenvalues exist.” Prove a variational characterization.

For a Hermitian matrix `A`, with eigenvalues arranged increasingly, target something like:

```lean
theorem courants_fischer_minmax
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.IsHermitian) :
    ∃ (λ : Fin (Fintype.card n) → ℝ),
      (StrictMono λ) ∧
      (∀ k,
        λ k =
          sInf { r : ℝ |
            ∃ (S : Submodule ℂ (n → ℂ)),
              FiniteDimensional.finrank ℂ S = k.1 + 1 ∧
              r = sSup { re ⟪x, A.mulVec x⟫ |
                         x : S, ‖(x : n → ℂ)‖ = 1 } }) 
```

That exact set-theoretic formulation may be too heavy for first pass. A more Lean-realistic matrix Rayleigh quotient version is acceptable:

```lean
def rayleighQuotient
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (x : n → ℂ) : ℝ :=
  RealPart (dotProduct (star x) (A.mulVec x)) / ‖x‖^2

theorem max_rayleigh_eq_top_eigenvalue
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.IsHermitian) :
    ∃ λ : ℝ,
      IsGreatest (Set.range (rayleighQuotient A)) λ ∧
      λ ∈ Matrix.spectrum ℂ A
```

Then strengthen to min-max over codimension-`k` subspaces.

### Why this is a breakthrough
This theorem connects algebraic spectral theory to optimization and mechanics. It is the formal bridge between:

- eigenvalues and constrained extrema,
- quantum energy levels and variational principles,
- graph partitioning and Laplacian eigenvalues,
- PCA and covariance operators,
- semidefinite relaxations.

It transforms the spectral theorem from a structural result into a computational one.

## Theorem Cluster C: Functional calculus and spectral mapping

Start with **polynomial functional calculus**, then push to continuous functional calculus in finite dimension.

Precise initial target:

```lean
theorem polynomial_functional_calculus_commutes_with_diagonalization
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.IsHermitian) (p : Polynomial ℂ) :
    ∃ (U : Matrix n n ℂ) (d : n → ℝ),
      U ∈ Matrix.unitaryGroup n ∧
      A = U ⬝ Matrix.diagonal (fun i => ((d i : ℝ) : ℂ)) ⬝ Uᴴ ∧
      p.evalMatrix A =
        U ⬝ Matrix.diagonal (fun i => p.eval ((d i : ℝ) : ℂ)) ⬝ Uᴴ
```

Spectral mapping theorem target:

```lean
theorem spectrum_evalMatrix
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (p : Polynomial ℂ) :
    Matrix.spectrum ℂ (p.evalMatrix A) = p '' Matrix.spectrum ℂ A
```

Self-adjoint preservation for real-valued functions on the spectrum:

```lean
theorem polynomial_real_on_spectrum_gives_isHermitian
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.IsHermitian) (p : Polynomial ℂ)
    (hp : ∀ x : ℝ, p.eval (x : ℂ) ∈ Set.range (fun r : ℝ => (r : ℂ))) :
    (p.evalMatrix A).IsHermitian
```

If continuous functional calculus is feasible in finite dimension via diagonalization:

```lean
noncomputable def continuousFunctionalCalculus
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.IsHermitian)
    (f : ℝ → ℂ) : Matrix n n ℂ := ...
```

with theorem:

```lean
theorem spectrum_continuousFunctionalCalculus
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.IsHermitian)
    (f : ℝ → ℂ) :
    Matrix.spectrum ℂ (continuousFunctionalCalculus A hA f)
      = f '' Matrix.spectrum ℂ A
```

### Why this is a breakthrough
Functional calculus is where spectral theory becomes a machine. It lets you define:

- matrix exponential `exp(A)`,
- square root `A^(1/2)` for positive operators,
- spectral projections,
- quantum time evolution `exp(-itH)`,
- heat semigroups and diffusion operators.

This is the precise formal infrastructure needed for rigorous quantum and analytic computation in Lean.

## Theorem Cluster D: Quantum observables and expectation bounds

Formalize the core statement: measurement values lie in the convex hull of the spectrum, and expectation of a positive observable is nonnegative.

Targets:

```lean
theorem expectation_mem_convexHull_spectrum
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.IsHermitian) (ψ : n → ℂ)
    (hψ : ‖ψ‖ = 1) :
    RealPart (dotProduct (star ψ) (A.mulVec ψ))
      ∈ convexHull ℝ (Matrix.spectrum ℂ A)
```

```lean
theorem expectation_nonneg_of_posSemidef
    {n : Type*} [Fintype n] [DecidableEq n]
    (A : Matrix n n ℂ) (hA : A.PosSemidef) (ψ : n → ℂ) :
    0 ≤ RealPart (dotProduct (star ψ) (A.mulVec ψ))
```

```lean
theorem unitary_time_evolution_of_selfAdjoint_hamiltonian
    {n : Type*} [Fintype n] [DecidableEq n]
    (H : Matrix n n ℂ) (hH : H.IsHermitian) (t : ℝ) :
    let U := Matrix.exp ((-Complex.I * t) • H)
    U ⬝ Uᴴ = 1
```

Even if the full matrix exponential API is inconvenient, proving the polynomial-approximation or diagonalization version is already substantial.

### Why this is a breakthrough
This imports a mathematically serious fragment of finite-dimensional quantum mechanics into Lean:

- observables = self-adjoint operators,
- energies via min-max,
- evolution via functional calculus,
- positivity and Born-rule-compatible expectations.

This is the beginning of certified quantum linear algebra.

## Proof Strategy Architecture

## Strategy A: Diagonalize first, then derive everything
**Most promising.**

1. Prove or locate unitary/orthogonal diagonalization for Hermitian/symmetric matrices.
2. Define eigenvalue list/function from the diagonal form.
3. Reduce:
   - Rayleigh quotient statements to weighted averages of diagonal entries,
   - spectral mapping to pointwise polynomial evaluation on diagonal entries,
   - positivity and expectation statements to scalar inequalities.

**Why this is strongest:** once `A = U D Uᴴ` is in place, nearly every theorem becomes a transport argument through conjugation invariance. This is the cleanest architecture and minimizes later proof duplication.

---

## Strategy B: Variational-first via compactness on the unit sphere
1. Show the Rayleigh quotient attains a maximum/minimum on the unit sphere in finite dimension.
2. Use critical-point/equality arguments to prove maximizing vectors are eigenvectors.
3. Induct on dimension using orthogonal complements to obtain a full orthonormal eigenbasis.

**Why it matters:** this route gives the min-max theorem almost for free and mirrors analytic proofs used in quantum mechanics and PDE. It is conceptually deeper and creates infrastructure for later infinite-dimensional compact-operator generalizations.

**Risk:** more topological and compactness machinery may be needed than matrix diagonalization requires.

---

## Strategy C: Polynomial/characteristic-polynomial route
1. Use existence of roots of the characteristic polynomial over `ℂ` to get one eigenvalue.
2. Show Hermitian eigenvalues are real and eigenspaces for distinct eigenvalues are orthogonal.
3. Induct on dimension using invariant orthogonal complements.

**Why this is attractive:** it uses classical algebra and linear algebra rather than heavy topology.
**Risk:** more manual work than Strategy A, and less immediately reusable for functional calculus than direct diagonalization.

---

## Recommended execution order

1. **Hermitian diagonalization**
2. **Reality of eigenvalues + orthogonality of eigenspaces**

5. **Polynomial functional calculus**

Self-adjoint operators are observables; min-max gives ground-state and excited-state energies; functional calculus gives time evolution and measurement functions of observables.
