This is not an incremental automata theorem. This is a canonical-state-space theorem for closure-based computation. The objective is to make EML semantics *identifiable*: to prove that closure-weighted input/output behavior admits a finite and minimal realization exactly when its idempotent Hankel semimodule is finitely generated and stable under residual actions, and that this realization can be reconstructed algorithmically from finite Hankel data. If established cleanly in Lean, this becomes a new foundation for **closure automata**, **EML system identification**, and **idempotent behavioral realization theory**.

The decisive conceptual leap is this: instead of viewing closure semantics as static algebra or proof-theoretic structure, reinterpret it as a *recognizable transduction behavior* whose internal state is the orbit of its Hankel rows under residual input/output actions. This is the right analogue of Schützenberger/Myhill–Nerode for idempotent closure-valued processes.

### Theorem 2: Minimality = generator rank

Prove a minimality theorem, ideally in rank language if you define a suitable notion of semimodule basis/cardinality, or at least in universal minimal-state form.

A strong target:

```lean
theorem minimal_states_eq_hankel_generator_rank
  {Σ Γ S : Type _}
  [DecidableEq Σ] [DecidableEq Γ]
  [IdempotentSemiring S]
  (f : List Σ → List Γ → S)
  (hfg : FiniteGeneratedRowSemimodule f)
  (hstable : ClosureStableResidualActions f) :
  let r := rowGeneratorRank f
  ∃ T : ClosureTransducer Σ Γ S,
    behavior T = f ∧
    Fintype.card T.State = r ∧
    ∀ T' : ClosureTransducer Σ Γ S,
      behavior T' = f →
      r ≤ Fintype.card T'.State
```

If exact equality to a cardinal rank is too ambitious in the first pass because basis minimality for idempotent semimodules is subtle, prove the categorically stronger and more robust version:

```lean
theorem minimal_realization_unique_up_to_iso
  ...
  : ∃ T : ClosureTransducer Σ Γ S,
      behavior T = f ∧ MinimalReachableObservable T ∧
      ∀ T' : ClosureTransducer Σ Γ S,
        behavior T' = f →
        MinimalReachableObservable T' →
        Nonempty (T ≅ T')
```

Then derive cardinal equality as a corollary when `State` is finite.

**Breakthrough significance:** this gives EML semantics a *canonical internal dimension*. Not just realizability, but an intrinsic complexity invariant analogous to Hankel rank, now in closure/idempotent computation.

Prove an explicit algorithmic reconstruction theorem from a finite basis plus residual action tables.

```lean
theorem reconstruction_correct
  ...
```

The algorithm should build:
- states = basis indices
- initial/output weights from the empty row / empty continuation
- transition/residual structure from left actions on basis rows
- proof that all rows are represented
- proof that behavior agrees with the original series by induction on word lengths or by semimodule factorization.

This is where the theorem becomes computationally meaningful: not only existence, but *certified synthesis* from finite data.

## Proof Architecture: 3 Viable Strategies

### Strategy A: Direct Hankel factorization into residual-state transducer
**Most promising.**

1. **Construct states as basis rows.**
   Let the finite generating family of `Row(H_f)` be `b₁, ..., bₙ`. Show every row `row_f(u,v)` is an `S`-linear combination of basis rows. Use residual closure-stability to define action of input/output extensions on basis coordinates.

2. **Define transitions by residual action tables.**
   Prefixing by a symbol in `Σ` or `Γ` maps a row to another row in the row semimodule. Since the basis generates and is stable, this induces finite action matrices. These matrices become the transducer dynamics.

3. **Prove behavior equality via induction / factorization identity.**
   Show that the row corresponding to a word pair is exactly the state reached by iterated residual action from the empty row. Evaluating at the empty continuation recovers `f(u,v)`. This is the key semantic equation:
   \[
   f(u,v) = \mathrm{eval}_{(\epsilon,\epsilon)}(\mathrm{row}_f(u,v)).
   \]

Why this is best: it is closest to classical recognizable-series realization while still respecting idempotent semimodule algebra. It should formalize well because it reduces the theorem to finite combinatorial data plus semiring-linear closure lemmas.

---

### Strategy B: Myhill–Nerode style quotient by row equivalence
1. Define an equivalence relation on prefixes `(u,v)` by equality of bi-Hankel rows.
2. Use finite generation plus closure-stability to prove only finitely many “essential” equivalence classes are needed, or at least a finite generating quotient.
3. Build the transducer on equivalence classes / normal forms and prove minimality by universality.

Why it matters: this yields a conceptually sharp minimality theorem.  
Risk: quotient constructions and finite cardinal control may be more delicate in Lean than basis-indexed constructions.

---

### Strategy C: Categorical realization via representable functors / coalgebra
1. Package `f` as a morphism from the free bimonoid on `Σ, Γ` into an idempotent semimodule object.
2. Interpret closure-stable finite generation as finite presentability of a residual action object.
3. Extract a finite automaton/transducer as a finite carrier for this representable behavior and prove duality via functorial reconstruction.

Why pursue it: this is the route to the final equivalence theorem.  
Risk: highest abstraction overhead. Best done after Strategy A has established the concrete core.

**Recommendation:** Prove Theorems 1–3 via Strategy A, then lift to Strategy C for the category equivalence.

## Deeper Mathematical Insight to Emphasize

### 1. The right invariant is not ordinary rank, but closure-stable residual span
In classical weighted automata, Hankel rank controls recognizability. In closure/EML semantics, the decisive invariant is finer: finite generation of the row semimodule *together with residual stability under closure actions*. This is what turns a static algebraic object into a dynamical state-space.

### 2. Closure acts like a nucleus, not just an operator
If your `S` supports a closure/nucleus interpretation, exploit it. The row semimodule should not merely be finitely generated; it should be stable under the closure-compatible residual action. This suggests the “correct” states are closed residual profiles, not arbitrary coordinates.

### 3. Minimality is an identifiability theorem
The minimal transducer is not just smaller. It is the unique canonical model recoverable from black-box behavior. This shifts EML from semantics to **system identification**.

### 4. The bi-Hankel kernel is a two-sided observable
Because `f` is a transduction series, rows depend on both input and output extensions. This is richer than language recognition and closer to operator theory / system realization. You are building a finite-dimensional realization theory for idempotent two-sided kernels.
