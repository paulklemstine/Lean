## Precise Theorem Target

You should formalize a theorem of the following shape.

### Mathematical statement

Let `X` be a finite type and `cl : Set X → Set X` satisfy:

1. `A ⊆ cl A` for all `A`,
2. `A ⊆ B → cl A ⊆ cl B`,
3. `cl (cl A) = cl A`,
4. finitary/algebraic generation on finite `X`,
5. a separation axiom ensuring distinct closed sets are separated by meet-prime closed theories.

Define:
- `Closed_cl := {A : Set X // cl A = A}`,
- `C_cl` to be the idempotent semimodule of closure profiles generated by principal closures `cl ({x})`,
- `Basis_cl` the canonical implicational basis obtained from minimal non-closed witnesses,
- `Spec_cl` the finite space of meet-prime closed theories with topology generated by basic opens `U_x := {P | x ∉ P}` or order by reverse inclusion.

Then prove:

1. `C_cl` is finitely generated;
2. `C_cl` is projective iff `cl` admits a finite canonical implicational presentation `Basis_cl` with no redundant rule;
3. the closure table of `cl` determines `Basis_cl` uniquely;
4. `Spec_cl` is functorially reconstructible from the join-irreducible generators of `C_cl`;
5. the pair `(Basis_cl, Spec_cl)` is unique up to canonical isomorphism;
6. two finite closure operators with isomorphic closure tables have isomorphic canonical bases and homeomorphic spectral spaces.

The strongest clean theorem would be an equivalence:
> finite separated consequence closures  
> `≃` finite projective idempotent consequence semimodules with distinguished generators  
> `≃` finite canonical implicational theories with prime spectral realization.

### Theorem A: Certified finite basis reconstruction from closure table

**Statement idea:** for finite `X`, the full closure table determines a canonical implication basis `B_cl`, and this basis reconstructs exactly `cl`.

## Proof Strategy Architecture

## Strategy A: Finite closure lattice → canonical basis → prime spectrum
**Most promising first route.**

1. **Closure lattice extraction.**
   Show closed sets form a finite lattice under intersection and closure of unions. On a finite universe, every closed set can be enumerated from the closure table.

2. **Canonical basis from minimal counterexamples.**
   For each `x ∉ A` with `x ∈ cl A`, select minimal `A` witnessing the entailment of `x`. Turn these into implications `A → x`. Prove:
   - soundness,
   - completeness,
   - minimality/nonredundancy,
   - uniqueness up to syntactic equivalence.

3. **Prime spectrum from finite distributive-style separation.**
   Use meet-prime closed sets in the finite lattice. Prove they separate closed sets under the separation axiom. Then identify the spectrum with prime filters/ideals or with dual points of the lattice. Finally show reconstruction from join-irreducibles using finite Birkhoff/Priestley technology.

**Why this is best:** it uses finite combinatorics, closure systems, and lattice duality already close to Mathlib’s strengths. It also postpones semimodule abstraction until the combinatorial heart is established.

---

## Strategy B: Idempotent semimodule presentation first, then derive basis and spectrum
**Best if the semiring/semimodule API is already usable or can be localized.**

1. **Define closure profiles as idempotent vectors.**
   Encode a closure profile as a `0/1`-valued function on generators or closed sets, with join as idempotent addition and combination as scalar action over `Bool`/`Finset`-style idempotent semiring.

2. **Projective presentation.**
   Present `C_cl` as a retract of a finite free idempotent semimodule on proposition generators or join-irreducibles. Relations encode exactly the closure entailments.

3. **Translate algebraic splitting into canonical theory.**
   Show projectivity yields a normalized relation system, and this relation system is equivalent to a canonical implicational basis. Prime points then arise as semimodule homomorphisms to the two-element idempotent semiring, giving a Stone-like spectrum.

**Why it matters:** this route makes the theorem feel categorically inevitable and links logic directly to idempotent linear algebra. It is more revolutionary, but likely heavier in Lean.

---

## Strategy C: Formal concept analysis / Horn logic route, then upgrade to semimodule duality
**A robust fallback and good for certification.**

1. **Use Horn closure semantics.**
   Treat implications as Horn clauses on finite sets; define semantic closure by forward chaining. Prove every finite closure operator is representable by a finite implicational theory.

2. **Canonicalize via pseudo-intents or minimal generators.**
   If pseudo-intents are too heavy, use minimal witness premises. Prove canonicity and exact reconstruction.

3. **Upgrade to algebra and topology.**
   Identify closed sets with models of the Horn theory, then define prime theories as irreducible models. Show join-irreducibles correspond to essential generators and package this as a finite semimodule/spectral duality theorem.

**Why useful:** if direct semimodule formalization stalls, this still produces a major theorem and leaves a clean path to the full algebraic statement.
