## YOUR ASSIGNMENT: Quantitative Leftover Hash Lemma with Rényi-2 Entropy for Universal Hash Extraction

Create `Cryptography/EntropyExtraction/LeftoverHash.lean` as a self-contained formal development of a quantitative leftover hash lemma for finite sources and finite outputs, expressed in a way that interoperates with entropy-gap, post-quantum security, and quantum/classical comparison infrastructure.

Work over concrete finite types first, then abstract where harmless. Favor statements over `Fintype`, `DecidableEq`, finite sums in `ℝ`, and probability masses represented as functions `α → ℝ` with normalization/nonnegativity proofs. Avoid measure-theoretic overhead unless already present in the catalog.

### Core mathematical narrative

Formalize the following principle:

For a finite source `X` on `α`, a finite 2-universal hash family `H : ι → α → β`, and a uniformly random seed `s : ι`, the joint distribution of `(s, H s X)` is statistically close to `(s, Uβ)` whenever the Rényi-2 entropy of `X` exceeds `log₂ |β|` by a positive margin. Quantitatively, the distance is controlled by the collision probability gap:
\[
\Delta \le \frac12 \sqrt{|β| \cdot \mathrm{CP}(X) - 1},
\]
and therefore
\[
\Delta \le \frac12 \sqrt{2^{\log_2 |β| - H_2(X)}}.
\]
This is the cryptographic extractor statement, but it should be presented as a bridge theorem connecting:
- **cryptography**: post-quantum key derivation and universal hashing,
- **information theory**: Rényi-2 entropy / collision entropy,
- **quantum information**: classical shadows of Holevo-style distinguishability bounds,
- **analysis / finite-dimensional functional inequalities**: `ℓ¹`–`ℓ²` comparison.

Use these application keywords explicitly in theorem names or doc comments:
`post_quantum_security`, `entropy`, `quantum`, `certified`, `lattice_crypto`, `collision`, `key_derivation`.

## Proof strategy architecture

Do not attack the main theorem head-on. Build a chain of reusable lemmas.

### Strategy A: collision-first derivation (most promising)

1. **Normalize the seeded distribution**  
   Prove `seededHashedJointDist H X` is a probability distribution:
   - nonnegativity by `mul_nonneg`, `sum_nonneg`, and split on the `if`;
   - total mass one by swapping finite sums and using that for each fixed `(s,a)` exactly one `b` satisfies `H.hash s a = b`.
   Useful tactics: `rw [Finset.sum_sigma']`, `classical`, `by_cases h : ...`, `nlinarith`.

2. **Expand seeded collision probability**  
   Compute
   \[
   \sum_{s,b} P(s,b)^2
   \]
   into a quadruple sum over `s, a, a'`, then separate diagonal `a=a'` and off-diagonal `a≠a'` terms.  
   This is where `rcases eq_or_ne a a' with rfl | hne` should appear.

3. **Use universality exactly once**  
   For off-diagonal terms, replace the seed-average collision indicator by `≤ 1/|β|`.  
   For diagonal terms, use equality `if H.hash s a = H.hash s a then ... = 1`.  
   This yields:
   \[
   \mathrm{CP}(S,H_S(X))
   \le \frac{1}{|ι|}\mathrm{CP}(X)
      + \frac{1}{|ι||β|}(1-\mathrm{CP}(X)).
   \]

4. **Subtract the seeded-uniform collision baseline**  
   Apply the finite identity for `collisionGapToUniform` on `ι × β`, where the ideal uniform collision is `1/(|ι||β|)`.  
   The factor `|ι|` should cancel, leaving the classical leftover hash expression depending only on `|β|`.

5. **Apply the `ℓ¹`–`ℓ²` inequality**  
   Invoke `statDist_le_half_sqrt_collision_gap` on `ι × β`.  
   Use `field_simp` and `ring_nf` to simplify the resulting algebraic expression to
   \[
   \frac12 \sqrt{|β| \mathrm{CP}(X) - 1}.
   \]

This route is the canonical proof and should be your primary implementation.

### Strategy B: output-first derivation

For `hashedOutputDist`, directly prove
\[
\sum_b P_H(b)^2 \le \mathrm{CP}(X) + \frac{1-\mathrm{CP}(X)}{|β|},
\]
then lift to seeded distributions by tensoring with the uniform seed. This may lead to less bookkeeping on product types, but the seeded theorem is cryptographically stronger. Use this route if the product-type sum manipulations become cumbersome.

### Strategy C: matrix / Gram-form proof

Interpret the family `H` as a `0-1` incidence matrix from `α` to `ι × β`. Then the extracted distribution is a linear image of `X`, and the collision bound is a quadratic form estimate. This is aesthetically excellent because it bridges:
- finite analysis,
- linear algebra,
- cryptographic extraction,
- quantum distinguishability heuristics.

If you can make this clean in Lean using `Matrix`, add a supplementary theorem or doc comment, but do not let it block the core proof.
