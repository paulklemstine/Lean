# Quantum Topological Phase Computation: The Fibonacci Anyon Model

This file gives a concrete, computational formalization of the *Fibonacci anyon*
model of topological quantum computation, the smallest non-abelian anyon theory
that is universal for quantum computation. Each computational step is a braid
group operation acting on the fusion space of anyonic worldlines; the gates are
generated by two pieces of data:

* the **F-matrix** (`fibF`), the associator / change-of-fusion-basis matrix, and
* the **R-matrix** (`fibR`), the exchange (braiding) phase matrix.

We work in the two-dimensional fusion space of three `τ` anyons with total
charge `τ`, which is exactly the single logical qubit of the Fibonacci scheme.

## Main results

* `fibF_involutive`  — the Fibonacci F-matrix is an involution: `F * F = 1`.
  This is the matrix incarnation of the golden-ratio identity `τ(τ+1) = 1`,
  i.e. of the pentagon equation for Fibonacci fusion.
* `fibF_symmetric`   — `F` is symmetric, hence (being an involution) orthogonal.
* `fibF_det`         — `det F = -1`; `F` is an orientation-reversing reflection.
* `fibF_trace`       — `F` is traceless.
* `fibR_unitary`     — the R-matrix is unitary (`Rᴴ * R = 1`): braiding is
  norm-preserving, the algebraic content of topological protection.
* `total_quantum_dim_sq` — the total quantum dimension squared is `2 + φ`,
  recovering the catalog identity `goldenRatio^2 = goldenRatio + 1`.
* `fib_braid_relation` — the **Artin braid relation** `B₁B₂B₁ = B₂B₁B₂` holds
  for the two single-qubit Fibonacci generators `B₁ = R` and `B₂ = F·R·F`,
  proving they assemble into an honest representation of the braid group `B₃`.

import Mathlib

set_option maxHeartbeats 1600000

noncomputable section

open Matrix Real Complex

namespace FibonacciAnyon

/-! ## The golden ratio and the quantum dimension `τ` -/

/-- The golden ratio `φ = (1 + √5)/2`, the quantum dimension of the `τ` anyon. -/
def gold : ℝ := (1 + Real.sqrt 5) / 2

/-
`φ` is positive.
-/
theorem gold_pos : 0 < gold := by
  exact div_pos ( by positivity ) ( by positivity )

/-
The defining quadratic: `φ² = φ + 1`.
-/
theorem gold_sq : gold ^ 2 = gold + 1 := by
  unfold gold; nlinarith [ Real.sq_sqrt ( show 0 ≤ 5 by norm_num ) ] ;

/-- The inverse quantum dimension `τ = 1/φ = φ - 1`. -/
def tau : ℝ := 1 / gold

/-
`τ` is positive.
-/
theorem tau_pos : 0 < tau := by
  unfold tau; exact one_div_pos.mpr gold_pos;

/-
The key golden-ratio identity behind the pentagon equation: `τ(τ+1) = 1`.
-/
theorem tau_mul_succ : tau * (tau + 1) = 1 := by
  unfold tau;
  rw [ div_add_one, div_mul_div_comm, div_eq_iff ] <;> nlinarith [ gold_pos, gold_sq ]

/-
`√τ` squares back to `τ` since `τ ≥ 0`.
-/
theorem sqrtTau_sq : Real.sqrt tau ^ 2 = tau := by
  exact Real.sq_sqrt <| le_of_lt <| tau_pos

/-! ## The Fibonacci F-matrix -/

/-- The Fibonacci F-matrix (associator), a real symmetric `2×2` matrix
`!![τ, √τ; √τ, -τ]`. -/
def fibF : Matrix (Fin 2) (Fin 2) ℝ :=
  !![tau, Real.sqrt tau; Real.sqrt tau, -tau]

/-
**F-matrix is an involution**: `F * F = 1`.
Diagonal entries are `τ² + τ = τ(τ+1) = 1`; off-diagonal entries cancel.

!-- Expand the 2×2 product; the (0,0)/(1,1) entries are τ²+(√τ)² = τ(τ+1) = 1
by `tau_mul_succ`, off-diagonals are `τ√τ - √τ τ = 0`. -- !--
-/
theorem fibF_involutive : fibF * fibF = 1 := by
  ext i j; fin_cases i <;> fin_cases j <;> norm_num [ Matrix.mul_apply, fibF ];
  · grind +suggestions;
  · ring;
  · ring;
  · grind +suggestions

/-
The F-matrix is symmetric.
-/
theorem fibF_symmetric : fibF.transpose = fibF := by
  ext i j; fin_cases i <;> fin_cases j <;> rfl;

/-
Being symmetric and involutive, `F` is orthogonal: `Fᵀ * F = 1`.
-/
theorem fibF_orthogonal : fibF.transpose * fibF = 1 := by
  rw [ fibF_symmetric, fibF_involutive ]

/-
The determinant of the F-matrix is `-1`: it is a reflection.
`det = τ·(-τ) - √τ·√τ = -(τ² + τ) = -1`.
-/
theorem fibF_det : fibF.det = -1 := by
  norm_num [ fibF, Matrix.det_fin_two ];
  rw [ Real.mul_self_sqrt ( by exact le_of_lt ( tau_pos ) ) ] ; linarith [ tau_mul_succ ]

/-
The F-matrix is traceless.
-/
theorem fibF_trace : Matrix.trace fibF = 0 := by
  unfold fibF; norm_num;

/-! ## The Fibonacci R-matrix (braiding phases) -/

/-- First braiding phase, `R_τ^{ττ} = e^{-4πi/5}`. -/
def rPhase1 : ℝ := -4 * Real.pi / 5

/-- Second braiding phase, `R_1^{ττ} = e^{3πi/5}`. -/
def rPhase2 : ℝ := 3 * Real.pi / 5

/-- The Fibonacci R-matrix: a diagonal matrix of unit-modulus braiding phases. -/
def fibR : Matrix (Fin 2) (Fin 2) ℂ :=
  !![Complex.exp (rPhase1 * Complex.I), 0; 0, Complex.exp (rPhase2 * Complex.I)]

/-
**The R-matrix is unitary**: `Rᴴ * R = 1`. Exchanging anyons preserves the
inner product on the fusion space — the algebraic core of unitary evolution.

!-- Diagonal: conj(exp(θi))·exp(θi) = exp(-θi)·exp(θi) = exp 0 = 1 for real θ. -- !--
-/
theorem fibR_unitary : fibR.conjTranspose * fibR = 1 := by
  ext i j ; fin_cases i <;> fin_cases j <;> simp +decide [ *, Matrix.mul_apply ];
  · unfold fibR; norm_num [ Complex.ext_iff, Complex.exp_re, Complex.exp_im ] ;
    exact ⟨ by rw [ ← sq, ← sq, Real.cos_sq_add_sin_sq ], by ring ⟩;
  · simp +decide [ fibR ];
  · unfold fibR; norm_num;
  · unfold fibR; norm_num [ Complex.ext_iff, Complex.exp_re, Complex.exp_im ] ; ring_nf ; norm_num;

/-
The R-matrix has determinant of modulus one (it lies in `U(2)`):
`|det R| = 1`.
-/
theorem fibR_det_abs : ‖fibR.det‖ = 1 := by
  norm_num [ fibR ]

/-! ## Quantum dimension -/

/-
The total quantum dimension squared of the Fibonacci theory,
`D² = d_1² + d_τ² = 1 + φ²`, equals `2 + φ`.
-/
theorem total_quantum_dim_sq : 1 + gold ^ 2 = 2 + gold := by

/-! ## The braid relation

The two single-qubit braid generators on three `τ` anyons are
`B₁ = R` and `B₂ = F · R · F` (here `F = F⁻¹` since `F` is an involution).
Universality of Fibonacci anyons rests on these satisfying the braid relation

`SU(2)`. We prove the Artin relation outright below; combined with the density
results stated in `BraidingUniversality`, it yields universality. -/

equality of 2×2 complex matrices, each entry is a polynomial in the braiding
phases and in `τ`, `√τ`; the phase identities collapse via
`Real.cos_pi_div_five` and the golden-ratio relation `gold_sq`. -- !--
