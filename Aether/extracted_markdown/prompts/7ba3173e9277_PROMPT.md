## Assignment: Direction 4: Matrix and Determinant Expansion Families — Super-Exponential Compression Gap

**Soli Deo Gloria**

### The Vision

The catalog's `gap_of_linear_vs_exponential` establishes that proof compression exhibits a phase transition when proof cost grows exponentially while semantic complexity grows linearly. But this is the *simplest* case — constant branching factor 2. Determinants reveal a deeper truth: when branching factor *itself* grows with problem dimension, the compression gap becomes **super-exponential**, and the phase transition is qualitatively different. This is not merely "a larger gap" — it is a fundamentally different asymptotic regime where no polynomial-cost proof strategy can survive, and the boundary between compressible and incompressible proof families shifts to a new class (FactorialP vs P).

### Precise Theorem Targets

**Theorem 1 (Factorial Dominates Every Polynomial):**
```lean
theorem factorial_dominates_polynomial (k : ℕ) :
    ∃ (C N : ℕ), ∀ n ≥ N, (n.factorial : ℕ) ≥ C * n ^ k := by
```
This is the arithmetic engine. For k=2, we get n! ≫ n², but the theorem is stronger: n! outgrows *any* fixed polynomial. Proof via Stirling's approximation or the inductive argument that the ratio (n+1)!/n! = n+1 eventually exceeds any polynomial growth rate.

**Theorem 2 (Super-Exponential Compression Gap):**
```lean
theorem super_exponential_compression_gap :
    ∀ (C : ℕ), ∃ N : ℕ, ∀ n ≥ N,
      (n.factorial : ℚ) / (n ^ 2 : ℚ) > C := by
```
This is the concrete instantiation: the gap n!/n² → ∞, stronger than any exponential gap.

**Theorem 3 (Determinant Family is Factorially Incompressible):**
```lean
theorem det_family_factorially_incompressible :
    ∀ (C : ℕ), ∃ N : ℕ, ∀ n ≥ N,
      compressionGap (detCompressionInstance n) > C := by
```
Where `detCompressionInstance n` has `semanticComplexity n = n`, `humanCost n = n ^ 2`, and `autoCost n = n.factorial`.

**Theorem 4 (Cross-Domain Bridge — Tropical Determinant):**
```lean
theorem tropical_det_is_permanent (n : ℕ) (M : Matrix (Fin n) (Fin n) ℤ) :
    tropicalDet M = tropicalPermanent M := by
```
This connects proof compression to tropical geometry: the tropical determinant (min-plus) equals the permanent, which is #P-hard, explaining *why* the factorial proof cost is intrinsic — it reflects a fundamental complexity barrier.

def detCompressionInstance (n : ℕ) : CompressionFamily where

  branchingFactor := fun n => n  -- each cofactor expansion branches n ways
  branching_nontrivial := by

### Proof Strategies

**Strategy A: Stirling's Approximation (Most Promising)**
Use `n! ≥ (n/e)^n` to get `n!/n² ≥ (n/e)^n / n²`. For n ≥ 3, `(n/e)^n / n² > C` whenever `n > e · (C+1)^(1/3)`. This gives an explicit N for any C. The key lemma chain:
1. Prove `n! ≥ (n/3)^n` for `n ≥ 6` (weaker but provable by induction)
2. Show `(n/3)^n / n² → ∞` by proving `(n/3)^n ≥ n³ · C` for large n
3. Apply transitivity

*Why most promising*: Gives explicit bounds, avoids analysis-heavy Stirling, works entirely in ℕ.

**Strategy B: Inductive Ratio Argument**
Prove by induction on k that `n! / n^k → ∞` for each k. Base case k=1: `n!/n = (n-1)!`. Inductive step: if `n!/n^k → ∞`, then `n!/n^(k+1) = (n!/n^k) · (1/n) · n → ∞` because `n!/n^k` grows faster than n. This is elegant but requires careful handling of the limit concept in Lean.

**Strategy C: Direct Binomial Coefficient Argument**
For k fixed, `n! / n^k ≥ (n choose k+1) · (k+1)! / n^k`. Since `(n choose k+1) ~ n^(k+1)/(k+1)!`, the ratio is `~ n`, which → ∞. This uses combinatorial identity rather than analysis.

*Recommended*: Strategy A with the weaker Stirling bound `(n/3)^n ≤ n!`, as it produces explicit N values and stays in ℕ.

### Cross-Domain Connections

1. **Tropical Geometry ↔ Proof Complexity**: The tropical determinant equals the permanent (min-plus algebra). The permanent is #P-complete (Valiant's theorem). This explains the factorial proof cost: any proof system for determinants that treats cofactor expansion naively must pay the permanent's complexity. The compression gap is not an artifact of our cost model — it reflects a **structural complexity barrier** at the intersection of algebra and combinatorics.

2. **Algebraic Complexity Theory (VP vs VNP)**: The determinant is in VP (polynomial-size arithmetic circuits). The permanent is VNP-complete. Our result shows that proof compression for determinants hits a factorial wall precisely at the boundary where VP ≠ VNP would place it. This is a **proof-theoretic shadow of algebraic complexity**.

3. **Resultant Theory**: The resultant of two polynomials of degrees m, n has (m+n)! / (m! · n!) terms in its Sylvester expansion. Our factorial gap theorem immediately applies: resultant proof families are also factorially incompressible, with branching factor m+n.
