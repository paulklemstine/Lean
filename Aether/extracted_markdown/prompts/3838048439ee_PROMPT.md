## Research Task: GL3 tropical Satake certified robustness for Condorcet Hecke-score tournaments

Research Mode: PROVE

Work in a new file
`Bridges/GL3/TropicalSatakeCondorcetRobustness.lean`.

The goal is to formalize a robust multiclass certification theorem for Condorcet-style aggregation of pairwise tropical Satake score gaps. The central point is that robustness of each pairwise gap should lift to robustness of the entire tournament winner relation, provided one class has a strictly positive margin against every opponent.

You should make the setup completely concrete over a finite class type `C` with `[Fintype C] [DecidableEq C]`, an input space `ι → ℝ` with finite dimension `[Fintype ι]`, and score functions `s : C → (ι → ℝ) → ℝ`. Define the pairwise gap
`g c j x := s c x - s j x`.
Assume a certified pairwise perturbation bound of the form
`|g c j x' - g c j x| ≤ δ`
whenever `‖x' - x‖∞ ≤ ε`, where in the intended GL3 tropical Satake application one has `δ = 2 * K * d * ε`.

The theorem should be stated in two layers:

1. a purely tournament-theoretic / score-gap stability lemma, independent of GL3 details;
2. a corollary instantiating `δ = 2 * K * d * ε` from the tropical Satake score-gap robustness theorem.

### Core definitions to introduce

Use simple definitions that are easy to reason about in Lean.

A good concrete starting point is:

```lean
def PairwiseGap {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ) (c j : C) (x : ι → ℝ) : ℝ :=
  s c x - s j x

def CondorcetWinner {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ) (c : C) (x : ι → ℝ) : Prop :=
  ∀ j, j ≠ c → 0 < PairwiseGap s c j x

def UniqueCondorcetWinner {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ) (c : C) (x : ι → ℝ) : Prop :=
  CondorcetWinner s c x ∧ ∀ j, CondorcetWinner s j x → j = c
```

It is also useful to define the minimum outgoing margin from `c` as a `Finset.inf'` over
`(Finset.univ.erase c)`:

```lean
def minPairwiseMargin {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ) (c : C) (x : ι → ℝ) : ℝ :=
  ((Finset.univ.erase c).inf' (by
      simpa using Finset.nonempty_erase (Finset.mem_univ c))
      (fun j => PairwiseGap s c j x))
```

If `inf'` over `ℝ` becomes awkward because of order-theoretic instances, it is completely acceptable to avoid introducing `minPairwiseMargin` as a definition and instead state the theorem with the hypothesis
`∀ j, j ≠ c → m ≤ PairwiseGap s c j x`
for some `m > 0`. This is often the cleaner Lean route.

### Main theorem 1: abstract Condorcet robustness under uniform pairwise gap perturbation

A precise and Lean-friendly statement is:

```lean
theorem condorcet_winner_of_pairwise_margin
    {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ)
    (c : C) (x x' : ι → ℝ) (m δ : ℝ)
    (hmargin : ∀ j, j ≠ c → m ≤ PairwiseGap s c j x)
    (hm : 0 < m)
    (hgap : ∀ i j, i ≠ j → |(PairwiseGap s i j x') - (PairwiseGap s i j x)| ≤ δ)
    (hδ : δ < m) :
    UniqueCondorcetWinner s c x'
```

A slightly weaker but often easier intermediate theorem is:

```lean
theorem condorcet_winner_stable
    {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ)
    (c : C) (x x' : ι → ℝ) (m δ : ℝ)
    (hmargin : ∀ j, j ≠ c → m ≤ PairwiseGap s c j x)
    (hm : 0 < m)
    (hgap_c : ∀ j, j ≠ c → |(PairwiseGap s c j x') - (PairwiseGap s c j x)| ≤ δ)
    (hδ : δ < m) :
    CondorcetWinner s c x'
```

and then prove uniqueness separately:

```lean
theorem unique_of_condorcet_winner
    {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ)
    (c : C) (x : ι → ℝ)
    (hc : CondorcetWinner s c x) :
    ∀ j, CondorcetWinner s j x → j = c
```

This uniqueness lemma is genuinely structural and should use antisymmetry of strict comparisons:
if `j ≠ c`, then `hc j h` gives `0 < g c j x`, while `hj c (Ne.symm h)` gives `0 < g j c x`; but
`g j c x = - g c j x`, contradiction.

You should prove the algebraic identity once:

```lean
lemma pairwiseGap_swap
    {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ) (i j : C) (x : ι → ℝ) :
    PairwiseGap s j i x = - PairwiseGap s i j x := by
  unfold PairwiseGap
  ring
```

This lemma is the key to uniqueness.

### Sharpness / converse theorem at abstract tournament level

A strong extension is to prove that the margin threshold is optimal relative to the pairwise-gap perturbation model. This should be done at the abstract score level, not necessarily by constructing an actual perturbed GL3 input.

A clean theorem is:

```lean
theorem not_condorcetStable_of_small_margin
    {C ι : Type*} [Fintype C] [DecidableEq C]
    (s : C → (ι → ℝ) → ℝ)
    (c j : C) (x x' : ι → ℝ) (δ : ℝ)
    (hcj : j ≠ c)
    (hsmall : PairwiseGap s c j x ≤ δ)
    (hflip : PairwiseGap s c j x' ≤ 0)
    (hgap : ∀ i k, i ≠ k →
      |(PairwiseGap s i k x') - (PairwiseGap s i k x)| ≤ δ) :
    ¬ UniqueCondorcetWinner s c x'
```

This is a minimal formal converse: if one outgoing margin can be pushed to nonpositive, then `c` is no longer a Condorcet winner, so uniqueness fails.

If you want a sharper purely synthetic perturbation statement, define an abstract perturbed gap family
`g' : C → C → ℝ` with skew-symmetry `g' i j = - g' j i`, and show that whenever
`PairwiseGap s c j x ≤ δ`, one can choose `g' c j ≤ 0` while keeping
`|g' i j - PairwiseGap s i j x| ≤ δ` for all pairs. This demonstrates optimality of the `margin > δ` criterion in the category of all admissible pairwise perturbations.

### Proof strategy

1. **Lower-bound each perturbed outgoing edge from `c`.**
   For fixed `j ≠ c`, combine
   `m ≤ PairwiseGap s c j x`
   with
   `|(PairwiseGap s c j x') - (PairwiseGap s c j x)| ≤ δ`.
   Use `abs_le.mp` or the standard inequality
   `a - b ≤ |a - b|` in the form
   `PairwiseGap s c j x - δ ≤ PairwiseGap s c j x'`.
   Then conclude
   `0 < PairwiseGap s c j x'`
   from `δ < m ≤ PairwiseGap s c j x`.

2. **Package the previous step into `CondorcetWinner s c x'`.**
   This gives the existence half of the robust winner statement. It is important to phrase this as a reusable lemma, because it isolates the metric/Lipschitz part from the social-choice uniqueness part.

3. **Prove uniqueness by contradiction using skew-symmetry of pairwise gaps.**
   Suppose `j ≠ c` and `CondorcetWinner s j x'`. Then
   `0 < PairwiseGap s c j x'`
   and
   `0 < PairwiseGap s j c x'`.
   By `pairwiseGap_swap`, the second is `0 < - PairwiseGap s c j x'`, impossible. In Lean, `linarith` should dispatch this once the swap lemma is rewritten.

4. **Derive the explicit GL3 radius certificate.**
   Instantiate the abstract theorem with
   `m :=` any lower bound on all outgoing margins from `c`,
   `δ := 2 * K * d * ε`.
   If your hypotheses are of the form
   `2 * K * d * ε < PairwiseGap s c j x`,
   simply set up `hmargin` with the same quantity and use the abstract theorem directly.

5. **For the converse/sharpness statement, use only one obstructing opponent.**
   If after perturbation one has `PairwiseGap s c j x' ≤ 0` for some `j ≠ c`, then `c` fails the definition of `CondorcetWinner`. Therefore `UniqueCondorcetWinner s c x'` is false. This is mathematically simple but conceptually important: the sufficient condition is sharp with respect to the pairwise-gap perturbation budget.

### Significance

This theorem is the correct multiclass analogue of binary tropical margin certification when the decision rule is not `argmax`, plurality, top-`k`, ECOC decoding, or hierarchical composition, but rather a Condorcet tournament built from pairwise GL3 tropical Satake score gaps. The result shows that the geometric stability of tropical Satake score functions propagates through a genuinely nontrivial aggregation rule from social choice theory. Formally, it turns pairwise Lipschitz control into a certified winner-preservation theorem for a strict tournament structure.

This matters for the broader program because it isolates a reusable principle:

- **representation-theoretic tropical score stability**
  `⇒`
- **uniform pairwise comparison stability**
  `⇒`
- **robustness of a non-argmax multiclass decision rule**.

That bridge is new and should be reusable for other Hecke/tropical score systems and other tournament-based aggregation schemes. The sharpness statement is especially valuable: it shows the certificate is not an artifact of a loose proof, but is optimal at the level of the abstract pairwise-gap perturbation model.
