### 1. Stabilization / bounded Kleene theorem

**Mathematical statement.**  
Let `M` be a finitely generated idempotent iteration semimodule equipped with a closure operator `cl` and a monotone inflationary closure-stable endomorphism `F`. Assume the closure image has finite join-height bounded by `N`. Then for every `x : M`, the Kleene chain stabilizes after at most `N` steps:
\[
F^{N}(cl\,x)=F^{N+1}(cl\,x).
\]
Moreover, the least fixed point above `cl x` is `F^[N] (cl x)`.

A Lean-facing signature could be organized as:

```lean
theorem kleene_chain_stabilizes_of_finite
  {R M : Type*}
  [Semiring R]
  [AddCommMonoid M]
  [Module R M]
  (S : IdempotentIterationSemimodule R M)
  (hfg : S.FiniteGeneration)
  (hcap : ∃ N : ℕ, S.closureHeight ≤ N) :
  ∃ N : ℕ, ∀ x : M,
    S.F^[N] (S.cl x) = S.F^[N+1] (S.cl x)
```

A stronger version, if your definitions support least fixed points:

```lean
theorem kleene_iterate_eq_lfp_of_capacity_bound
  {R M : Type*}
  ...
  (S : IdempotentIterationSemimodule R M)
  (N : ℕ)
  (hN : S.closureHeight ≤ N) :
  ∀ x : M,
    IsLeast {y | S.cl x ≤ y ∧ S.F y = y} (S.F^[N] (S.cl x))
```

This is the foundational theorem: finite closure capacity forces bounded-time fixed-point computation.

### 3. Minimality theorem: quotient by iteration indistinguishability

**Mathematical statement.**  
Define an equivalence relation on circuit states or semimodule elements:
\[
x \sim y \iff \forall n,\; cl(F^n x)=cl(F^n y)
\]
or the appropriate observational variant on generators/outputs. Then the quotient yields a canonical reduced realization, and every realization factors through it. This gives uniqueness up to isomorphism of the minimal feedback circuit.

Lean-facing signature:

```lean
def IterationIndistinguishable
  {R M : Type*} (S : IdempotentIterationSemimodule R M) : M → M → Prop :=
fun x y => ∀ n : ℕ, S.cl (S.F^[n] x) = S.cl (S.F^[n] y)
```

Then target:

```lean
theorem minimal_feedbackCircuit_exists
  {R M : Type*}
  ...
  (S : IdempotentIterationSemimodule R M)
  (hfg : S.FiniteGeneration) :
  ∃ Cmin : FeedbackCircuit R,
    Cmin.Realizes S ∧ Cmin.IsMinimal
```

and

```lean
theorem minimal_feedbackCircuit_unique
  {R M : Type*}
  ...
  (S : IdempotentIterationSemimodule R M)
  {C₁ C₂ : FeedbackCircuit R}
  (h₁ : C₁.Realizes S ∧ C₁.IsMinimal)
  (h₂ : C₂.Realizes S ∧ C₂.IsMinimal) :
  Nonempty (C₁ ≃c C₂)
```

where `≃c` is your notion of circuit isomorphism.

This is the theorem that makes the project revolutionary: algebraic dynamics determine architecture canonically.

Assume the closure lattice is finite and generated by join-irreducibles. Then the transition graph and feedback edges of the minimal realization are recoverable from the join-irreducible closure profile. Furthermore, the closure capacity equals worst-case convergence depth:
\[
\mathrm{capacity}(S)=\max_x \min\{n : F^n(cl\,x)=F^{n+1}(cl\,x)\}.

## 2–3 proof strategy paths

### Strategy A: finite-height order-theoretic route
1. Equip the closure-stable part of the semimodule with the order induced by idempotent addition or an externally supplied semilattice order.
2. Prove monotone inflationary maps stabilize on finite-height posets using a strict-increase counting argument.
3. Define the feedback circuit by choosing a finite generating set and letting each register track the coefficient/profile of a generator under one application of `F`; then prove stabilization depth is bounded by closure height.

**Why promising:** this is the most Lean-friendly route. Mathlib already handles monotone maps, finite types, iteration, and order-theoretic stabilization more easily than highly abstract semimodule quotients.

---

### Strategy B: join-irreducible / lattice representation route
1. Show the finite closure image is a finite join-semilattice.
2. Represent elements by supports on join-irreducibles; interpret `F` as a monotone transition relation on these irreducibles.
3. Build the minimal circuit directly from the Hasse diagram / dependency graph of join-irreducible propagation; identify iteration indistinguishability with equality in the reduced profile semantics.

**Why promising:** this route is best for the reconstruction theorem and minimality uniqueness. It turns algebra into graph combinatorics and yields canonical architecture almost automatically.

---

### Strategy C: coalgebra / automata minimization analogue
1. Treat the iterative system as a deterministic monotone transition system with observations given by closure profiles.
2. Define behavioral equivalence = iteration indistinguishability.
3. Apply a Myhill–Nerode-style quotient argument to produce the unique minimal realization.

**Why promising:** conceptually deepest, and likely the right route for uniqueness up to isomorphism.  
**Why secondary:** more setup in Lean; probably best pursued after Strategy A establishes existence and bounded convergence.

## Recommended proof architecture

The strongest route is likely:

- **First** prove stabilization by **Strategy A**.
- **Then** derive a concrete finite-register realization from generators.
- **Then** prove minimality and uniqueness using **Strategy C**.
- **Finally** prove reconstruction from join-irreducibles using **Strategy B**.

This layered approach gives early theorems quickly while preserving the path to the canonical reconstruction result.
