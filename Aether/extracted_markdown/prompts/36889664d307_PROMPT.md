## Assignment: Direction 3 — Tropical Shadow Duality and Newton Polytope Preservation

**Mode:** `prove`

You are not being asked for an incremental lemma. You are being asked to isolate and formalize a genuinely new duality principle: that a combinatorial “shadow” extracted from support data controls the full second-derivative Newton geometry, and that under a non-cancellation certificate this control is exact. If completed cleanly, this would turn tropical/polyhedral computation into a certified proxy for algebraic Hessian complexity.

Build on the catalog theorems, but do not stop at their corollaries. The support identity is only the entry point. The breakthrough is to prove that the **polyhedral shadow functor** preserves the Hessian Newton data and exposes a tropical-algebraic duality with computational consequences.

## Core Vision

Let \(p\) be a multivariate polynomial with finite support \(S \subset \mathbb{N}^n\). For indices \(i,j\), define the **quadratic leaf shadow**
\[
\mathrm{quadLeafSet}(S,i,j)
\]
to be the exponent set obtained by selecting support exponents that survive two differentiations in directions \(i,j\), with the expected exponent decrement. The catalog already suggests that under a non-cancellation certificate, the support of the Hessian entry \(\partial_i\partial_j p\) is exactly this set.

The decisive next theorem is:

> **Shadow Duality Principle.** Under the non-cancellation certificate, the Newton polytope of \(\partial_i\partial_j p\) is exactly the convex hull of the quadratic leaf shadow. Equivalently, the polyhedral geometry of the Hessian is determined purely from support combinatorics.

This should then be strengthened to a tropical statement: the shadow operation is the support-level avatar of tropical differentiation, so the Newton polytope equality is the polyhedral manifestation of a tropical-algebraic duality.

This is not just a statement about Hessians. It is a candidate new bridge between:
- tropical geometry,
- Newton polytope methods,
- algebraic complexity,
- and certified symbolic computation.

If true in a strong form, it opens a route to lower bounds and structural invariants of arithmetic circuits via polyhedral shadows rather than coefficient explosion.

## Theorem 1 — Newton polytope preservation from exact support

This is the foundational theorem and should be stated with full quantifiers.

### Mathematical statement
Let \(R\) be a semiring/commutative semiring with suitable polynomial differentiation and support theory. Suppose \(p \in R[x_1,\dots,x_n]\), and let \(i,j\) be coordinate indices. If the non-cancellation certificate for \((p,i,j)\) holds and
\[
\operatorname{supp}(\partial_i\partial_j p)=\mathrm{quadLeafSet}(\operatorname{supp}(p),i,j),
\]
then
\[
\operatorname{Newt}(\partial_i\partial_j p)
=
\operatorname{conv}(\mathrm{quadLeafSet}(\operatorname{supp}(p),i,j)).
\]

### Lean 4 target signature
A plausible target is:

```lean
theorem newtonPolytope_hessianEntry_eq_shadowPolytope
    {n : ℕ} {R : Type*} [CommSemiring R]
    (p : MvPolynomial (Fin n) R)
    (i j : Fin n)
    (hcert : NonCancellationCertificate p i j) :
    newtonPolytope (hessianEntry p i j) = ShadowPolytope p.support i j := by
```

If `ShadowPolytope` is defined from `p : MvPolynomial`, then use:

```lean
def ShadowPolytope
    {n : ℕ} {R : Type*} [CommSemiring R]
    (p : MvPolynomial (Fin n) R) (i j : Fin n) : Set (Fin n → ℝ) := ...
```

Then:

```lean
theorem newtonPolytope_hessianEntry_eq_shadowPolytope
    {n : ℕ} {R : Type*} [CommSemiring R]
    (p : MvPolynomial (Fin n) R) (i j : Fin n)
    (hcert : NonCancellationCertificate p i j) :
    newtonPolytope (hessianEntry p i j) = ShadowPolytope p i j := by
```

### Why this matters
This theorem upgrades a support-level identity into a **convex-geometric invariant theorem**. That is the point where tropical geometry enters in earnest. Once the Newton polytope is controlled exactly, one can begin extracting:
- face structure,
- mixed volumes,
- sparse complexity measures,
- and degeneration invariants
from purely combinatorial shadow data.

### Expected proof ingredients
Use the catalog theorem:
- `Pythagorean/NonCancellationCertificate.lean`: `hessian_support_eq_quadLeafSet`

Then combine it with a lemma of the form:
- `newtonPolytope_eq_convexHull_support`
or prove it if absent.

### Proof strategy options
**Strategy A: direct support-to-convex-hull transport**  
1. Rewrite `newtonPolytope (hessianEntry p i j)` as convex hull of the embedded support.  
2. Rewrite support using `hessian_support_eq_quadLeafSet hcert`.  
3. Identify the resulting convex hull with `ShadowPolytope`.  
This is the cleanest and most promising path.

**Strategy B: extensional proof via point membership in convex hulls**  
1. Prove both inclusions of sets.  
2. For each inclusion, unfold `ShadowPolytope`, use support equality, and transport through embedding.  
3. Use `Subset.antisymm`.  
This is more verbose but may be necessary if set coercions become difficult.

**Strategy C: functoriality of Newton polytope under support-preserving transformations**  
1. Prove a general lemma: equal supports imply equal Newton polytopes.  
2. Instantiate with the Hessian support theorem.  
This is strategically valuable because it yields reusable infrastructure.

**Most promising:** Strategy C + A. First isolate the reusable lemma `support_eq → newtonPolytope_eq`, then the main theorem becomes conceptually transparent.

## Theorem 2 — Vertex realization / extremal shadow theorem

Do not stop at polytope equality. Prove an extremal version: every exposed vertex of the Hessian Newton polytope comes from an actual shadow exponent, and conversely every shadow exponent that is uniquely extremal for some weight is a Newton vertex.

### Mathematical statement
Assume the non-cancellation certificate. Then for every weight vector \(w\),
\[
\arg\max_{a \in \operatorname{supp}(\partial_i\partial_j p)} \langle w,a\rangle
=
\arg\max_{a \in \mathrm{quadLeafSet}(\operatorname{supp}(p),i,j)} \langle w,a\rangle.
\]
Consequently, the exposed faces, and in particular the vertices, of the Newton polytope of \(\partial_i\partial_j p\) are exactly those of the shadow polytope.

### Lean 4 target signature
A plausible formulation:

```lean
theorem exposedFace_hessianEntry_eq_exposedFace_shadow
    {n : ℕ} {R : Type*} [CommSemiring R]
    (p : MvPolynomial (Fin n) R) (i j : Fin n)
    (w : Fin n → ℝ)
    (hcert : NonCancellationCertificate p i j) :
    exposedFace w (newtonPolytope (hessianEntry p i j))
      = exposedFace w (ShadowPolytope p i j) := by
```

Or a support-level maximizer theorem:

```lean
theorem shadow_argmax_eq_hessian_argmax
    {n : ℕ} {R : Type*} [CommSemiring R]
    (p : MvPolynomial (Fin n) R) (i j : Fin n)
    (w : Fin n → ℝ)
    (hcert : NonCancellationCertificate p i j) :
    argmaxExponents w (supportExponents (hessianEntry p i j))
      = argmaxExponents w (quadLeafSet p.support i j) := by
```

### Why this matters
Polytope equality is already powerful, but vertex realization is what complexity theory and tropical geometry actually use. Extremal exponents govern:
- leading tropical terms,
- initial forms,
- regular subdivisions,
- and sparse elimination complexity.

If you prove this, then the shadow is not merely shape-preserving; it is **face-structure preserving**.

### Proof strategy options
**Strategy A: derive from support equality and linear-functional maximization**  
1. Rewrite both finite argmax sets using the support equality.  
2. Use a finite-set maximization lemma.  
3. Lift from maximizers to exposed faces of convex hulls.

**Strategy B: use the theorem that exposed faces of a convex hull come from exposed subsets of generators**  
1. Prove a general convex lemma for finite generator sets.  
2. Instantiate with support and shadow generator sets.  
This is more geometric and more reusable.

**Strategy C: by contradiction on a putative missing vertex**  
1. Assume a vertex exists on one side not present on the other.  
2. Separate by a supporting hyperplane.  
3. Contradict the support equality / polytope equality.  
This is elegant but may be heavier in Lean.

**Most promising:** Strategy B if Mathlib convex APIs are usable; otherwise A.

## Theorem 3 — Mixed-volume monotonicity or exactness under shadow duality

You need one theorem that pushes beyond equality of a single polytope and hints at intersection theory or complexity. A realistic formal target is a monotonicity or exactness theorem for finite families of shadow polytopes.

### Mathematical statement
For a family of polynomials \(p_1,\dots,p_m\) satisfying non-cancellation certificates at fixed \((i,j)\), the mixed volume of the Hessian Newton polytopes equals the mixed volume of the corresponding shadow polytopes:
\[
V(\operatorname{Newt}(\partial_i\partial_j p_1),\dots,\operatorname{Newt}(\partial_i\partial_j p_m))
=
V(\operatorname{Shad}_{i,j}(p_1),\dots,\operatorname{Shad}_{i,j}(p_m)).
\]

If mixed volume is too heavy for the current library, prove a weaker but still meaningful theorem:

\[
\operatorname{Newt}(\partial_i\partial_j(p+q))
\subseteq
\operatorname{conv}(\operatorname{Shad}_{i,j}(p)\cup \operatorname{Shad}_{i,j}(q)),
\]
with equality under a pairwise compatibility certificate.

### Lean 4 target signature
Strong form, if infrastructure exists:

```lean
theorem mixedVolume_hessian_eq_mixedVolume_shadow
    {n m : ℕ} {R : Type*} [CommSemiring R]
    (ps : Fin m → MvPolynomial (Fin n) R) (i j : Fin n)
    (hcert : ∀ k, NonCancellationCertificate (ps k) i j) :
    mixedVolume (fun k => newtonPolytope (hessianEntry (ps k) i j))
      = mixedVolume (fun k => ShadowPolytope (ps k) i j) := by
```

Fallback theorem:

```lean
theorem newtonPolytope_hessian_add_subset_shadow_union
    {n : ℕ} {R : Type*} [CommSemiring R]
    (p q : MvPolynomial (Fin n) R) (i j : Fin n) :
    newtonPolytope (hessianEntry (p + q) i j)
      ⊆ convexHull ℝ (ShadowPolytopeGenerators p i j ∪ ShadowPolytopeGenerators q i j) := by
```

### Why this matters
This is where tropical shadow duality starts speaking to **enumerative geometry** and **algebraic complexity**. Mixed volume controls root counts in sparse systems and is central to Bernstein–Kushnirenko–Khovanskii theory. Even a monotonicity theorem would say: shadow geometry predicts second-derivative interaction complexity.

### Proof strategy options
**Strategy A: transport equality through a functorial invariant**  
1. Prove equality of each individual Newton polytope with each shadow polytope.  
2. Apply congruence of mixed volume / monotonicity of convex-hull invariant.  
This is best if mixed volume is available.

**Strategy B: Minkowski-sum containment route**  
1. Prove a support containment theorem for sums.  
2. Pass to convex hulls.  
3. Deduce geometric containment and a volume/mixed-volume bound.  
This is more likely to formalize smoothly.

**Strategy C: induction on family size**  
1. Base case is Theorem 1.  
2. Step uses multilinearity/monotonicity of the chosen invariant.  
This is elegant if the invariant API supports it.

**Most promising:** B unless mixed volume is already formalized enough to support A.
