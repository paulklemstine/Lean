## Definitions to formalize

1. **Chain connectivity distance**: For a pseudometric space (X, d) and points x y : X, define
   `ripsUltraDist (x y : X) : ℝ := sInf {r : ℝ | r > 0 ∧ ChainConn d r x y}`
   where `ChainConn d r x y` means x and y are in the same connected component of the graph with vertex set X and edge set {(a,b) | d a b ≤ r}.

2. **Rips ultrametric space**: The structure bundling (X, ripsUltraDist) with proofs that ripsUltraDist satisfies the ultrametric axioms.

## Theorems to prove

1. **Ultrametric triangle inequality**: `ripsUltraDist x z ≤ max (ripsUltraDist x y) (ripsUltraDist y z)`
   Proof sketch: If x-y is connected at scale r₁ and y-z at scale r₂, then x-z is connected at scale max r₁ r₂ by concatenating chains.

2. **Subdominance**: `ripsUltraDist x y ≤ d x y`
   Proof sketch: Any two points at distance d x y are chain-connected at scale d x y (single-edge chain).

3. **Greatest subdominant ultrametric**: If d' is any ultrametric with d' ≤ d, then d' ≤ ripsUltraDist.
   Proof sketch: If d' x y < r, then x and y are chain-connected at scale r (since d' ≤ d and the ultrametric property lets us bound chain distances by max).

4. **Functoriality**: For an isometry f : X → Y between pseudometric spaces, `ripsUltraDist (f x) (f y) ≤ ripsUltraDist x y` (in fact equality holds). This makes the construction a functor.

5. **Tropical connection**: Show that the ultrametric inequality `d x z ≤ max (d x y) (d y z)` is equivalent to the tropical semiring statement that the distance is a tropical metric, i.e., the tropical addition (max) plays the role of addition in the triangle inequality.
