## Theorem Target 1: Exact KW Witness Counting for Symmetric Functions

### Mathematical statement

Let `f : (Fin n → Bool) → Bool` be symmetric, meaning `f x` depends only on the Hamming weight of `x`. Define the true and false layers
- `T_k = {x : (Fin n → Bool) | weight x = k ∧ f x = true}`
- `F_l = {y : (Fin n → Bool) | weight y = l ∧ f y = false}`.

For any `x ∈ T_k`, `y ∈ F_l`, a KW witness is an index `i` such that `x i ≠ y i`. If `k > l`, every such pair has exactly `k - l` valid witness coordinates; if `l > k`, exactly `l - k`; and if `k = l`, symmetry forces `f x = f y`, impossible. Hence:

\[
|KWWitness(f)| = \sum_{\substack{0 \le k,l \le n \\ f(k)=\mathrm{true},\, f(l)=\mathrm{false}}}
\binom{n}{k}\binom{n}{l}\, |k-l|.
\]

This is stronger than the original constant-factor conjecture: it gives an **exact closed formula**.

### Lean 4 target

You will likely need a weight-indexed presentation of symmetric functions. A good formal target is:

```lean
def hammingWeight {n : ℕ} (x : Fin n → Bool) : ℕ := Finset.card (Finset.univ.filter fun i => x i)

def SymmetricBoolFn (n : ℕ) := { f : (Fin n → Bool) → Bool // ∀ x y, hammingWeight x = hammingWeight y → f x = f y }

def layer (n k : ℕ) : Finset (Fin n → Bool) :=
  Finset.univ.filter (fun x => hammingWeight x = k)

def trueLayer (f : (Fin n → Bool) → Bool) (k : ℕ) : Finset (Fin n → Bool) :=
  (layer n k).filter (fun x => f x = true)

def falseLayer (f : (Fin n → Bool) → Bool) (k : ℕ) : Finset (Fin n → Bool) :=
  (layer n k).filter (fun x => f x = false)

theorem card_KWWitness_symmetric_exact
  {n : ℕ} (f : SymmetricBoolFn n) :
  Fintype.card (KWWitness f.1) =
    ∑ k in Finset.range (n+1),
      ∑ l in Finset.range (n+1),
        if f.1 (Classical.choose (exists_vector_of_weight n k)) = true ∧
           f.1 (Classical.choose (exists_vector_of_weight n l)) = false
        then Nat.choose n k * Nat.choose n l * Nat.dist k l
        else 0 := by
  sorry
```

A more elegant version is to first define the induced predicate on weights:

### Why this is a breakthrough

This would convert a qualitative barrier into an **exact enumerative invariant** for an entire class of functions. Not “KW witnesses are large”; rather: **here is the exact entropy budget of every symmetric Boolean function**. Once formalized, parity, majority, exact-threshold, tribes-style symmetric surrogates, and gap-thresholds become instant corollaries.

This is a mechanized analog of having the character table of a representation class: once known, many lower bounds become bookkeeping.

### Proof strategy options

#### Strategy A: Fiber decomposition by Hamming layers
1. Partition `KWWitness(f)` by triples `(k,l,i)` where `x` has weight `k`, `y` has weight `l`, and `i` is a witness.
2. For fixed `k,l`, count pairs `(x,y)` with `f(x)=true`, `f(y)=false`; symmetry makes this depend only on `k,l`.
3. Show each such pair contributes exactly `|k-l|` witness indices.

This is the cleanest and most promising route. It reduces everything to finite counting and combinatorics of subsets.

#### Strategy B: Transport to subset language
1. Identify `{x : Fin n → Bool}` with `Finset (Fin n)`.
2. Rewrite witness condition as membership in set difference: if `|X|=k`, `|Y|=l`, then witness coordinates are exactly `X \ Y` or `Y \ X` depending on orientation.
3. Use standard cardinality identities for finite sets to show `|(X \ Y) ∪ (Y \ X)| = |k-l|` under the true/false orientation relevant to KW.

This may mesh better with Mathlib’s existing `Finset.card_sdiff` lemmas.

#### Strategy C: Double counting incidence relation
1. Define an incidence set of triples `(x,y,i)` where `i` is a witness.
2. Count by `(x,y)` fibers to get the `|k-l|` factor.
3. Count by `(k,l)` fibers to get the binomial coefficients.

This is more abstract and may produce reusable infrastructure for later entropy arguments.

### Cross-domain connections

- **Statistical mechanics:** the Hamming layers are energy shells; the formula is a partition function weighted by shell separation `|k-l|`.
- **Information theory:** `log |KWWitness(f)|` becomes a microcanonical entropy of disagreement.
- **Geometric complexity:** symmetric functions collapse the hypercube to a 1D quotient by the `S_n` action; the theorem computes the lifted witness volume from this quotient.

## Theorem Target 2: Constant-Loss Entropy–Witness Equivalence for Symmetric Functions

### Mathematical statement

Using the exact formula above, prove asymptotic comparability between witness entropy and the naive product `n · |T(f)| · |F(f)|` for nondegenerate symmetric functions whose true and false layers are separated by at least one Hamming level.

A robust formal version is:

\[
|KWWitness(f)| \le n \cdot |T(f)| \cdot |F(f)|
\]

for all Boolean functions, and for symmetric `f` satisfying a layer-separation hypothesis,

\[
|KWWitness(f)| \ge \delta \cdot n \cdot |T(f)| \cdot |F(f)|
\]

for an explicit `\delta` determined by the average normalized layer gap:
\[
\delta = \frac{1}{n} \cdot
\frac{\sum_{k,l:\,f(k)=1,f(l)=0} \binom{n}{k}\binom{n}{l}|k-l|}
{\sum_{k,l:\,f(k)=1,f(l)=0} \binom{n}{k}\binom{n}{l}}.
\]

This refines the original conjecture: the right invariant is not an absolute constant in full generality, but an explicit structural parameter. That is scientifically stronger because it is true for the right reason.

### Lean 4 target

```lean
theorem card_KWWitness_le_card_product
  {n : ℕ} (f : (Fin n → Bool) → Bool) :
  Fintype.card (KWWitness f) ≤
    n * (Fintype.card {x // f x = true}) * (Fintype.card {y // f y = false}) := by
  sorry
```

For symmetric functions:

```lean

  {n : ℕ} (f : SymmetricBoolFn n) :
  (avgLayerGap f) * ((Fintype.card {x // f.1 x = true}) * (Fintype.card {y // f.1 y = false}))
    ≤ Fintype.card (KWWitness f.1) := by
  sorry
```

Or a natural-number-cleared denominator version.

### Why this is a breakthrough

The original “bounded by constants” claim is likely too crude. Replacing it with an **exact structural correction term** is not retreat — it is conceptual progress. It says witness entropy is governed by a geometric statistic of the true/false shell arrangement. That gives a refined taxonomy of function hardness inside the symmetric world.

### Proof strategy steps

1. Prove the universal upper bound by observing each true/false pair contributes at most `n` witness indices.
2. Use Theorem Target 1 to rewrite the exact cardinality for symmetric functions.
3. Factor the expression into `(number of true/false pairs) × (average witness multiplicity)` and identify the average multiplicity with the weighted layer-gap parameter.

### Cross-domain connections

- **Optimal transport:** the weighted average `|k-l|` is a 1D transport cost between the true and false layer distributions.
- **Entropy inequalities:** witness entropy becomes product entropy plus a transport correction.
- **Learning theory:** this measures average sensitivity of class separation under Hamming perturbation.

## Theorem Target 3: Exact Compression-to-KW Complexity Transfer up to Logarithmic Loss

### Mathematical statement

Formalize a quantitative relation between witness cardinality and optimal KW protocol complexity. The right general shape is:

\[
\mathrm{KWComplexityExact}(f) \le \lceil \log_2 |KWWitness(f)| \rceil
\]

because a protocol can identify a witness by indexing a finite witness set, and under suitable formal assumptions already present in the catalog, prove a lower bound of the form

\[
\mathrm{KWComplexityExact}(f) \ge \lfloor \log_2 |KWWitness(f)| \rfloor - c \log n
\]

for monotone `f`, where the `c log n` term captures protocol-description overhead / relation-vs-function encoding slack.

Then transfer this to formula depth via KW:

\[
\mathrm{MonoFormula.depth}(f) \ge \lfloor \log_2 |KWWitness(f)| \rfloor - c \log n.
\]

### Lean 4 target

Assuming there is or can be defined an exact protocol complexity notion:

```lean
  {n : ℕ} (f : (Fin n → Bool) → Bool) :
  KWComplexityExact f ≤ Nat.ceilLog2 (Fintype.card (KWWitness f)) := by
  sorry
```

```lean
    KWComplexityExact f.1 + C * Nat.log2 (n+1) := by
```

```lean
  φ.Realizes f.1 →

    φ.depth + C * Nat.log2 (n+1) := by
  sorry
```

### Why this is a breakthrough

This would turn the barrier framework into a **usable theorem schema for lower bounds**. Instead of proving protocol lower bounds directly, one can count witnesses and invoke a certified transfer theorem. This is exactly the kind of theorem that changes workflow in complexity theory.

### Proof strategy options

#### Strategy A: Coding-theoretic upper/lower sandwich
1. Upper bound: encode each witness by its rank in a finite enumeration of `KWWitness(f)`.
2. Lower bound: invoke catalog compression impossibility results to show any protocol of cost `d` induces a code of size `≤ 2^{d + O(log n)}` for witnesses.
3. Rearrange to obtain the logarithmic-loss inequality.

This is the most direct route if the catalog already contains `cardinality_forces_long_code` or similar.

#### Strategy B: Decision-tree extraction from protocols
1. Show every protocol partitions the witness relation into at most `2^d` monochromatic rectangles.
2. Bound the number of witnesses per rectangle using monotonicity/structure.
3. Deduce cardinality lower bounds on `d`.

This may yield sharper constants but will require more communication-complexity infrastructure.

#### Strategy C: Entropy formalization
1. Put the uniform distribution on `KWWitness(f)`.
2. Show protocol transcripts compress witness entropy into at most `d + O(log n)` bits.
3. Use Shannon-style finite entropy lemmas in a purely combinatorial finite-set form.

This is the most conceptually powerful and may unify with future information-theoretic results.

### Cross-domain connections

- **Source coding:** protocol complexity is witness compression length.
- **Proof complexity:** formula depth lower bounds emerge as coding lower bounds.
- **Algorithmic information theory:** witnesses act like descriptions whose incompressibility certifies hardness.

## Theorem Target 4: Monotone Threshold Functions Have Explicit KW Entropy and Depth Lower Bounds

### Mathematical statement

For the monotone threshold function
\[
\mathrm{Thresh}_{n,t}(x) = 1 \iff |x| \ge t,
\]
the exact witness count is

\[
|KWWitness(\mathrm{Thresh}_{n,t})|
=
\sum_{k=t}^{n}\sum_{l=0}^{t-1}\binom{n}{k}\binom{n}{l}(k-l).
\]

A particularly elegant sharpened theorem should isolate the dominant boundary term:
\[
|KWWitness(\mathrm{Thresh}_{n,t})| \ge \binom{n}{t}\binom{n}{t-1},
\]
since every pair of adjacent boundary layers contributes exactly one witness on average gap `1`, and in fact exactly `1` witness multiplicity only when `k=t,l=t-1` for monotone orientation.

Then combine with Theorem Target 3 to derive a formal lower bound on monotone formula depth.

### Why this matters

Threshold functions are the canonical meeting point of circuit complexity, learning theory, and statistical physics. Formal exact witness counts here would provide a benchmark family where the entire pipeline
`counting → entropy → protocol complexity → formula depth`

### Proof strategy steps

1. Specialize the symmetric exact-count theorem to the threshold profile.
2. Simplify the profile predicate `f(k)=true ↔ t ≤ k`.
3. Extract a clean lower bound by keeping only selected summands, especially the boundary pair `(t,t-1)`.

### Cross-domain connections

- **Statistical learning:** thresholds are halfspaces over the Boolean cube.
- **Phase transitions:** the boundary layer around `t` is a discrete critical surface.
- **Social choice / voting:** majority is the threshold `t = ⌈n/2⌉`.

## Theorem Target 5: Majority Witness Entropy is Quadratic-Exponential up to Polynomial Loss

### Mathematical statement

Let `Maj_n(x) = 1` iff `|x| ≥ ⌈n/2⌉`. Prove explicit asymptotic lower bounds on `|KWWitness(Maj_n)|` by extracting central binomial contributions:

\[
|KWWitness(Maj_n)|
\ge
\binom{n}{\lceil n/2 \rceil}\binom{n}{\lfloor n/2 \rfloor}.
\]

Hence
\[
\log_2 |KWWitness(Maj_n)|
\ge
\log_2 \binom{n}{\lceil n/2 \rceil}
+
\log_2 \binom{n}{\lfloor n/2 \rfloor},
\]
and via standard central binomial estimates,
\[
\log_2 |KWWitness(Maj_n)| \ge 2n - O(\log n).
\]

This gives a formally certified near-maximal witness entropy family.

### Lean 4 target

```lean

  thresholdFn n ((n+1)/2)

theorem card_KWWitness_majority_lower_bound
  {n : ℕ} :

    Fintype.card (KWWitness (majorityFn n)) := by
  sorry
```

```lean
    Nat.floorLog2 (Fintype.card (KWWitness (majorityFn n))) := by
  sorry
```

### Why this is a breakthrough

Majority is the paradigmatic “structured hard function.” A formal proof that its witness entropy is essentially `2n` bits would provide one of the first machine-checked lower-bound style results with genuinely asymptotic content and nontrivial combinatorics.

### Proof strategy steps

1. Instantiate the threshold theorem at `t = ⌈n/2⌉`.
2. Keep only the central boundary contribution `(k,l) = (⌈n/2⌉, ⌊n/2⌋)`.
3. Use binomial coefficient lemmas to derive logarithmic consequences.

### Cross-domain connections

- **Discrete Gaussian heuristics:** central binomial coefficients encode concentration.
- **Information geometry:** majority maximizes boundary mass among monotone symmetric rules.
- **Noise stability:** majority’s large witness entropy reflects a large balanced decision boundary.
