## Concept

**Title**: Tropical closure semimodules as algorithmic fixed-point systems
**Domain**: Bridges
**Mathematical framing**: Define a finite family `P` of tropical affine pieces `a_i` (building on `AffinePiece`/`TropicalPoly`) on a finite ambient type. For a set `S`, define an evaluation profile map `prof_P(S)` and a closure operator `cl_P` by intersecting all probe-stable sets determined by inequalities/equalities of affine-piece evaluations that hold on `S`. Main target theorem: `cl_P` is a closure operator and, under a finite separation hypothesis on `P`, `cl_P S` coincides with the tropical convex hull generated by `S` relative to `P`. Secondary theorem: the closure potential associated to `cl_P` is monotone along the reconstruction algorithm, giving a termination/correctness certificate via the info-efficient or thermodynamic formalism. Lean work should likely proceed by first repairing `Tropical/Canonical/Basic.lean` enough to obtain evaluable affine pieces and tropical polynomials, then instantiating `SetClosureOperator`, `ProbeFamily`, `ClosureStableProbe`, `ClosurePotential`, and `FiniteClosureSystem` with tropical data. The project bridges Tropical and Bridges and can fail in mathematically interesting ways if the proposed finite separation condition is insufficient.
**Concept description**: The key insight is that the existing closure-operator reconstruction framework can be lifted from order-theoretic finite closure systems to idempotent semiring-valued tropical semimodules, yielding a new bridge theorem: tropical convex generation behaves like a closure-stable probe system once affine tropical pieces are organized as closure kernels. Why now: the catalog already contains strong reconstruction and thermodynamic closure infrastructure in `Bridges/AlgebraEMLReconstruction.lean`, `Bridges/AlgebraEMLClosureComputation.lean`, and `Bridges/AlgebraicEMLThermodynamicFormalism.lean`, while Tropical has an explicit unfinished canonical layer in `Tropical/Canonical/Basic.lean`; combining them can both unlock a genuine cross-domain theorem and help discharge meaningful tropical sorries rather than proving isolated lemmas. Concretely, formalize a finite tropical affine-piece family as a closure-generating probe family, define the induced tropical hull operator as the intersection of probe-stable tropical halfspaces/affine pieces, and prove extensivity, monotonicity, idempotence, and a finite reconstruction theorem: every point in the tropical hull of a finite set is fixed by the closure induced from the affine-piece evaluation profile, and conversely any fixed point satisfies all probe inequalities coming from the generating family. The intended payoff is algorithmic: derive a certified pipeline turning finite evaluation data of tropical affine pieces into a closure computation with correctness guarantees and monotone potential bounds. This is not a restatement of tropical convexity; it proposes a new equivalence between tropical canonical representations and closure-stable reconstruction systems, with falsifiable failure points if the tropical evaluation layer cannot satisfy the closure axioms or if fixed points are strictly weaker than tropical hull membership.
