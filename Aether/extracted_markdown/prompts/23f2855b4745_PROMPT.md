## Precise Research Target

Let `A : Matrix (Fin n) (Fin n) ℝ` be a finite payoff matrix over the tropical min-plus semiring viewpoint, and define the tropical Bellman/Shapley operator
\[
T_A(x)_i := \min_{j : \mathrm{Fin}\ n} (A i j + x_j).
\]
This is the min-plus linear map associated to `A`.

We want to formalize and prove the following theorem cluster.

### Theorem 1: Tropical fixed points are tropical equilibria
Define a tropical equilibrium value `v : Fin n → ℝ` by the condition
\[
T_A(v) = v.
\]
Interpret this as an idempotent zero-sum game value condition. Then prove:

> **Theorem (fixed point = tropical equilibrium).**  
> For every finite matrix `A : Matrix (Fin n) (Fin n) ℝ`, if `v` is a fixed point of `T_A`, then each coordinate `v i` realizes a tropical best-response balance:
> \[
> v_i = \min_j (A_{ij} + v_j).
> \]
> Conversely, any vector satisfying these coordinatewise tropical Bellman optimality equations is a fixed point of `T_A`.

This sounds tautological, but the real content is to package it as a game-theoretic equilibrium notion and then build the minimax/value theory around it.

### Theorem 2: Finite-step stabilization under tropical idempotence
The nontrivial theorem should use an idempotence hypothesis on the matrix/operator. A natural condition is:
\[
A \otimes A = A
\]
in min-plus matrix multiplication, i.e.
\[
A i k = \min_j (A i j + A j k).
\]
Under this hypothesis, the Bellman operator is idempotent:
\[
T_A(T_A(x)) = T_A(x).
\]

Then prove:

> **Theorem (one-step or finite-step stabilization).**  
> If `A` is min-plus idempotent, then for every `x`,  
> \[
> T_A(T_A(x)) = T_A(x),
> \]
> hence value iteration stabilizes after at most `2` evaluations, and the limit is a fixed point.  
> More generally, for a monotone inflationary tropical operator on a finite-height lattice of height `n`, iteration stabilizes in at most `n` steps.

This is stronger and cleaner than the original “at most n steps for n-player games”; the right parameter is **lattice height / state count**, not number of players.

### Theorem 3: Tropical minimax inequality and equality under idempotence
Define for a matrix `A`:
\[
\underline v(A) := \max_i \min_j A_{ij}, \qquad \overline v(A) := \min_j \max_i A_{ij}.
\]
Then prove the tropical analogue of minimax inequality:
\[
\underline v(A) \le \overline v(A).
\]
Then seek equality under a tropical convexity / idempotent regularity hypothesis.

> **Theorem (tropical minimax).**  
> For every finite real matrix `A`,  
> \[
> \max_i \min_j A_{ij} \le \min_j \max_i A_{ij}.
> \]
> If `A` satisfies a tropical saddle-point condition
> \[
> \exists (i_0,j_0),\quad
> \forall i,j,\ \min(A_{i_0 j}, A_{i j_0}) \le A_{i_0 j_0} \le \max(A_{i_0 j}, A_{i j_0}),
> \]
> or a stronger formally convenient condition implying existence of a tropical saddle, then equality holds and the common value is the tropical game value.

If the saddle-point formulation becomes awkward in Lean, use the simpler and more formalizable statement: equality holds if there exists `i₀, j₀` with
\[
A i₀ j \ge A i₀ j₀ \quad\text{for all }j,\qquad
A i j₀ \le A i₀ j₀ \quad\text{for all }i.
\]

### Theorem 4: Existence and uniqueness of value under closure hypothesis
For arbitrary `A`, uniqueness of fixed point is false. The right theorem is:

> **Theorem (existence/uniqueness of tropical value projection).**  
> If `T_A` is monotone and idempotent, then `Fix(T_A)` is nonempty and forms an inf-semilattice; for every `x`, `T_A x` is the least fixed point above `T_A x` and the image of `T_A` equals `Fix(T_A)`.  
> If additionally `T_A` is constant on its image or contractive in a suitable order-theoretic sense, then the fixed point is unique.

This is a genuine structural theorem: the operator is a **nucleus/closure operator** in tropical disguise.

## Proof Strategy Architecture

### Strategy A: Direct finite matrix/order proof
Most promising for Lean.

1. **Define the Bellman operator explicitly** on `Fin n → ℝ` using `Finset.univ.inf'`.
2. **Prove monotonicity and idempotence**:
   - monotonicity by pointwise comparison under `+`
   - idempotence from min-plus matrix idempotence by expanding nested infima and reassociating
3. **Derive fixed-point and minimax theorems**:
   - image = fixed-point set for idempotent maps
   - minimax inequality via finite witness comparison
   - equality from saddle witnesses

Why this is most promising: it stays entirely within finite combinatorics, order, and matrix algebra available in Mathlib.

### Strategy B: Closure operator / Galois-theoretic route
More conceptual, potentially more revolutionary.

1. Show `tropBellman A` is a **kernel/closure-type operator** under suitable hypotheses.
2. Use abstract fixed-point theory: idempotent monotone maps have image equal to fixed points.
3. Reinterpret tropical equilibrium space as a **Moore family** or inf-closed subspace.

Why it matters: this elevates the theorem from a one-off matrix fact to a new paradigm: **tropical games are fixed-point geometries**.

### Strategy C: Duality and zero-temperature limit
Most visionary, but likely harder to formalize fully in one cycle.

1. Start from a soft operator
   \[
   T^\beta_A(x)_i = -\beta^{-1}\log \sum_j e^{-\beta(A_{ij}+x_j)}
   \]
   and identify the tropical operator as `β → ∞` limit.
2. Show the minimax theorem is the zero-temperature shadow of convex duality.
3. Connect fixed points to ergodic/control limits and policy iteration.

Why it matters: this connects tropical game theory to **reinforcement learning, large deviations, and statistical physics**.
