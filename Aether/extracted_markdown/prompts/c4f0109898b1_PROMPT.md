### Research Direction: Full EML Depth Hierarchy Persists Under Inversions

**Core Conjecture.** Allowing inversions (the full EML) does not reduce the minimum depth required for `iterExp(n)`. That is, even with `inv` nodes, depth `n` is necessary for `iterExp(n)`.

**Key Definitions to Formalize:**

```lean
-- Full EML with inversions
inductive EMLFull where
  | var : EMLFull
  | const (c : ℝ) : EMLFull
  | add (e₁ e₂ : EMLFull) : EMLFull
  | mul (e₁ e₂ : EMLFull) : EMLFull
  | inv (e : EMLFull) : EMLFull
  | exp (e : EMLFull) : EMLFull

-- Depth: exp increments, inv does NOT (this is the crux!)
def EMLFull.depth : EMLFull → ℕ
  | var | const _ => 0
  | add e₁ e₂ | mul e₁ e₂ => max e₁.depth e₂.depth
  | inv e => e.depth           -- inversions are "free" for depth
  | exp e => e.depth + 1       -- only exp increases depth

-- Growth order: ordinal-like stratification of growth rates
-- Maps EMLFull expressions to their "exponential rank" at +∞
def growthOrder (e : EMLFull) : ℕ :=
  match e with
  | var | const _ => 0
  | add e₁ e₂ | mul e₁ e₂ => max e₁.growthOrder e₂.growthOrder
  | inv e => e.growthOrder    -- inversions preserve growth order
  | exp e => e.growthOrder + 1

-- The crucial invariant: growth order ≤ depth
theorem growth_order_le_depth (e : EMLFull) : e.growthOrder ≤ e.depth := by
  induction e with
  | inv e ih => exact ih
  | exp e ih => omega
  | _ => simp [EMLFull.depth, growthOrder]; omega
```

### Proof Strategy Architecture

**Strategy A: Growth Rate Stratification (Most Promising ★★★★★)**

This directly extends the catalog's `HasPolyTowerMajorant` framework. The key insight is that inversions can only *decrease* growth rates, never increase them past what the exponential depth permits.

1. **Define `growthOrder`** as above: a function `EMLFull → ℕ` measuring the "exponential rank" of the asymptotic growth at +∞. Prove `growthOrder e ≤ e.depth` by induction on `e`.

2. **Prove the Growth Order Lemma**: For any `e : EMLFull`, if `e.growthOrder = k`, then `eval e x` grows at most like `iterExp(k)` as `x → +∞`. Formally:
   ```lean
   theorem growth_order_bound (e : EMLFull) (hk : e.growthOrder = k) :
     ∃ C : ℝ⁺, ∀ x ≥ C, |eval e x| ≤ C.val * iterExp k x := by sorry
   ```
   The proof proceeds by induction on `e`. The `inv e` case is the delicate one: if `|eval e x| ≤ C * iterExp k x`, then `|1/eval e x| ≤ 1` for large `x` (since `iterExp k x → +∞`), which is dominated by `iterExp 0 x = x`.

3. **Conclude by contradiction**: If `e` has `depth < n`, then `growthOrder e < n`, so `eval e x` grows at most like `iterExp(n-1)`, which is eventually dominated by `iterExp(n)`. Hence `e` cannot equal `iterExp(n)` on any unbounded set.

**Why Strategy A is most promising**: It reduces the problem to a clean induction on the `EMLFull` structure, with the `inv` case handled by the observation that `1/f` shrinks when `f` grows — inversions are self-defeating for representing fast-growing functions.

**Strategy B: Hardy Field Comparison (Alternative)**

Hardy fields provide a total order on germs at +∞. EMLFull expressions are Hardy field elements. Use the Hardy field rank to stratify: if `f ∈ H_k` (functions comparable to `iterExp(k)`), then `inv(f) ∈ H_{-k}` but this negative rank still satisfies the depth bound. The problem: Hardy field theory is not in Mathlib, requiring substantial development.

**Strategy C: Differential Algebra / Liouvillian Closure (High-Risk, High-Reward)**

EMLFull expressions are Liouvillian functions. The differential transcendence degree of `iterExp(n)` over `ℝ(x)` is `n` (each iteration adds one independent exponential). Inversions don't change differential transcendence degree. This would connect to differential Galois theory — but formalizing differential algebra in Lean is a major undertaking.

### Cross-Domain Connections

**1. Transseries Theory (van der Hoeven, Écalle)**

The transseries framework assigns every EMLFull expression a "transserial depth" — the number of nested exponential levels in its transseries expansion. This is exactly our `growthOrder`. The theorem we're proving is essentially: *the transserial depth of an EMLFull expression equals its exponential depth*. This connects EML complexity to the rich theory of asymptotic expansions.

**2. Differential Algebra**

`iterExp(n)` satisfies `y^{(n)} = y^{(n-1)} · y^{(n-2)} · ... · y · y'` — an order-n differential algebraic equation. Inversions preserve differential algebraic order. This bridges to differential Galois theory: the differential Galois group of `iterExp(n)` has "exponential depth" `n`.

**3. Renormalization Group (Mathematical Physics)**

In quantum field theory, the renormalization group flow involves iterated exponentials: coupling constants at scale Λ go as `g(Λ) ∼ iterExp(n)(log Λ/μ)`. Our theorem implies that n RG iterations require n levels of exponential nesting — a *computational lower bound on renormalization*.

**4. Computable Analysis**

`iterExp(n)` has Grzegorczyk hierarchy rank `n+2`. Our depth hierarchy mirrors this: EML depth `n` captures exactly the functions at Grzegorczyk level `n+2`. Inversions correspond to primitive recursive closure, which doesn't increase Grzegorczyk level.

### Testable Conjecture

**Conjecture (Rational Cancellation Barrier).** For any EMLFull expression `e` of depth `d < n`, there exists `x₀ > 0` such that `eval e x₀ ≠ iterExp n x₀`. Moreover, the first point of divergence can be bounded: if `e` has `m` inversions, then `|eval e x - iterExp n x| ≥ 1` for all `x ≥ max(m, 2^d)`.

**Computational Test.** Enumerate all EMLFull expressions with depth < n and ≤ k inversion nodes (for small n ∈ {2, 3, 4} and k ∈ {0, 1, 2, 3}). **Why this test is meaningful**: For n=3, depth-2 expressions with inversions can produce functions like `exp(x/(1+x))` or `exp(1 + 1/x)` — these have rich local behavior but fundamentally cannot match `exp(exp(exp(x)))` asymptotically. The test checks both local and global agreement.
