### Precise mathematical statement

Let `X` be finite. Let `(Cl, κ)` be a finite reduced closure-capacity presentation, where:

- `Cl ⊆ Set X` is a finite family of closed sets generating all closed sets under intersection and closure,
- `κ : Cl → α` takes values in an idempotent linearly ordered commutative semifield / tropical semiring-like structure,
- `κ` is monotone:
  `A ⊆ B → κ A ≤ κ B`,
- `κ` is normalized:
  `κ ⊥ = 0`,
- `κ` is submodular on closed sets:
  `κ(A ∩ B) + κ(cl (A ∪ B)) ≤ κ(A) + κ(B)`,
  interpreted in the ordered additive presentation appropriate to the chosen tropicalization.

Define `I(Cl, κ)` as the idempotent semimodule generated by basis symbols `e_A` for `A ∈ Cl`, modulo the capacity-envelope relations identifying a generator with the tropical supremum of strictly smaller generators whenever `κ` forces redundancy.

Define a sparse tropical attention realization on `X` with `h` heads to be a factorization
`T_X → α^h → V`
whose support sets are closed and whose score on principal singleton/token queries recovers `κ`.

Then the target theorem is:

> **Finite Closure-Capacity–Attention Duality Theorem.**  
> Every finite reduced closure-capacity object `(Cl, κ)` admits a canonical minimal sparse tropical attention realization whose heads are in bijection with the extreme generators of `I(Cl, κ)`. Conversely, every finitely generated closure-consistent sparse tropical attention realization determines a unique reduced closure-capacity object up to semimodule isomorphism and gauge equivalence. Moreover, the minimal number of attention heads equals the number of extreme generators, hence is an invariant of the closure-capacity object.

This should be decomposed into Lean-manageable theorems.

## Suggested theorem decomposition

Do not attempt the final equivalence first. Build the bridge in four layers.

### Layer 1: Representation of capacity by extremal generators
Prove that `κ` is the support functional of the extreme generators of the information semimodule.

Possible theorem:

```lean
theorem kappa_eq_sup_over_extremes
  (O : ClosureCapacityObj X α) :
  ∃ I : InfoSemimodule X α,
    ∀ A, O.κ A =
      iSup (fun g => if I.isExtreme g ∧ Supports g A then weight g else 0)
```

In finite form, replace `iSup` by `Finset.sup`.

This is the heart: it turns closure-capacity data into a finite tropical convex object.

### Layer 2: Minimality = extremal generator count
Show that any closure-consistent realization must use at least one head per extreme generator, and the canonical realization uses exactly that many.

Possible theorem:

```lean
theorem minimal_head_count_lower_bound
  (O : ClosureCapacityObj X α)
  (M : SparseAttentionModel X α)
  (hreal : RealizesClosureCapacity O M) :
  extremeRank O ≤ Fintype.card M.Head
```

```lean

  (O : ClosureCapacityObj X α) :
  ∃ M : SparseAttentionModel X α,
    RealizesClosureCapacity O M ∧
    Fintype.card M.Head = extremeRank O
```

Together these certify optimality.

### Layer 3: Reconstruction algorithm
Extract the canonical support hypergraph and score/value matrices from closure incidences and extreme generators.


This theorem should compute supports from the reduced closed generators and weights from `κ`.

### Layer 4: Uniqueness up to gauge/isomorphism

## Proof strategy options

### Strategy A: Finite tropical convexity / support-function route
1. Construct `I(C, κ)` as a finitely generated idempotent semimodule whose generators are closed sets modulo redundancy.
2. Prove every `κ(A)` is the tropical supremum of contributions from extreme generators supporting `A`.
3. Show each extreme generator induces exactly one irreducible head, and any head decomposition refines the extremal decomposition.

**Why promising:** this aligns best with the target theorem and gives a clean path to certified minimality. It also naturally explains uniqueness via extremal decomposition.

### Strategy B: Closure hypergraph factorization route
1. Encode the closure system as a support hypergraph on tokens.
2. Define sparse attention heads as hyperedges weighted by `κ`.
3. Prove minimal realizations correspond to irredundant hyperedge covers compatible with closure and submodularity.
4. Identify irredundant hyperedges with extreme semimodule generators.

**Why useful:** more combinatorial and may be easier to formalize first, especially if Mathlib support for finite hypergraphs/Finsets is more convenient than abstract semimodules.

### Strategy C: Galois duality / finite dual equivalence route
1. Build a category of reduced closure-capacity objects and a category of minimal closure-consistent sparse attention models.
2. Define functors `F` and `G` by semimodule generation and closure extraction.
3. Prove unit/counit are isomorphisms on reduced/minimal objects.

**Why powerful but harder:** conceptually strongest and closest to the stated duality, but likely best pursued after Strategy A establishes the core representation and uniqueness lemmas.

**Recommendation:** Start with **Strategy A**, use **Strategy B** as a finite combinatorial implementation device, and only then package the result in **Strategy C** if the infrastructure cooperates.

## Key definitions to make formalization tractable

To minimize sorry, prefer finite combinatorial definitions over abstract order-theoretic ones.

1. **Closed sets as `Finset X`**
   - Use extensional lemmas between `Finset` and `Set` carefully.
   - Keep closure operator on `Finset X` if possible.

2. **Capacity values**
   - If a fully tropical semifield is too heavy, first instantiate with `WithBot ℕ`, `ℕ`, or `OrderBot`-like finite weights and max-plus style operations.
   - You can generalize later.

3. **Extreme generators**
   - Define an element as extreme if it cannot be written as a tropical sum of strictly smaller-support generators with the same value.
   - Use a finite predicate first; abstract extremality later.

4. **Minimal attention model**
   - Define by cardinal minimality among all closure-consistent realizations:
     ```lean
     minimal := ∀ M', closure_consistent M' → realizes_same_data M' →
       Fintype.card Head ≤ Fintype.card M'.Head
     ```
   - This is easier than an abstract indecomposability notion.

5. **Gauge equivalence**
   - Start with head permutation equivalence only.
   - Add tropical scaling if straightforward.
   - If quotient types are painful, use a binary relation and prove uniqueness modulo that relation.
