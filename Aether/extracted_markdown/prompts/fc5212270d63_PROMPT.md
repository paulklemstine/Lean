## Assignment: Linear algebra over finite fields

Mode: **prove**

Prove a genuinely new finite-field polynomial method theorem in Lean 4, centered on the linear-algebraic mechanism behind “small sets admit nonzero low-degree vanishing polynomials,” and push it far enough that it becomes a reusable engine for combinatorics, coding theory, and algebraic complexity.

This is not just a dimension-count exercise. The breakthrough is to formalize a **finite-field interpolation obstruction principle**: whenever a finite set is too small to support all low-degree polynomial evaluations, there exists a nonzero polynomial of controlled degree vanishing on that set. Once formalized cleanly, this becomes a launchpad for finite-field Kakeya-style arguments, Reed–Muller code distance bounds, polynomial method lower bounds, and certificate extraction in algebraic complexity.

## Core theorem target

Work over a finite field `𝔽q` and the `n`-variable polynomial ring. Let `M(n,d)` denote the subspace of multivariate polynomials in `n` variables with total degree `< d`. For a finite set `E ⊆ 𝔽q^n`, define the evaluation map
\[
\mathrm{ev}_E : M(n,d) \to (E \to \mathbb{F}_q), \qquad f \mapsto (x \mapsto f(x)).
\]
If `|E| < dim M(n,d)`, then `ev_E` has nontrivial kernel, hence there exists a nonzero polynomial of degree `< d` vanishing on all of `E`.

This should be formalized in a concrete, Lean-friendly way first for:
1. **univariate polynomials**, then
2. **multivariate polynomials with a finitely supported monomial basis**, and ideally
3. the finite-field-specialized bound `dim M(n,q) = #{α : Fin n → ℕ // ∑ i, α i < q}` or a usable lower bound.

### Precise theorem statement

A first theorem that is both nontrivial and realistically formalizable:

```lean
theorem exists_nonzero_poly_vanishing_on_finite_set_of_card_lt
    (K : Type*) [Field K] [Fintype K]
    (E : Finset K) (d : ℕ)
    (hE : E.card < d) :
    ∃ p : K[X], p ≠ 0 ∧ p.natDegree < d ∧ ∀ x ∈ E, Polynomial.eval x p = 0
```

This univariate statement is already powerful: it packages the polynomial method in a degree-controlled existence theorem, and it should be provable either by rank-nullity or by explicit construction
\[
p(X)=\prod_{a\in E}(X-a),
\]
with degree `|E| < d`.

But do not stop there. The real target is the linear-algebraic multivariate upgrade:

```lean
theorem exists_nonzero_mvPolynomial_vanishing_on_finite_set_of_card_lt
    (K : Type*) [Field K] [Fintype K]
    (n d : ℕ)
    (E : Finset (Fin n → K))
    (hE : E.card < Fintype.card {m : Fin n →₀ ℕ // m.sum (fun _ e => e) < d}) :
    ∃ p : MvPolynomial (Fin n) K,
      p ≠ 0 ∧
      (∀ m : Fin n →₀ ℕ, m ∈ p.support → m.sum (fun _ e => e) < d) ∧
      ∀ x ∈ E, MvPolynomial.eval x p = 0
```

This is the real theorem. It says: the vector space of total-degree-`< d` polynomials has larger dimension than the target evaluation space `K^E`, so some nonzero low-degree polynomial vanishes on all of `E`.

If the exact subtype cardinality is too cumbersome initially, prove a structurally equivalent version using a defined submodule of low-degree polynomials and `FiniteDimensional.finrank K`:

```lean
theorem exists_nonzero_in_lowTotalDegree_vanishing
    (K : Type*) [Field K]
    (n : ℕ) (d : ℕ)
    (E : Finset (Fin n → K))
    (L : Submodule K (MvPolynomial (Fin n) K))
    (hLdeg : ∀ p ∈ L, ∀ m ∈ p.support, m.sum (fun _ e => e) < d)
    (hdim : E.card < FiniteDimensional.finrank K L) :
    ∃ p : L, p.1 ≠ 0 ∧ ∀ x ∈ E, MvPolynomial.eval x p.1 = 0
```

This version is often the best Lean architecture: isolate finite-dimensional linear algebra first, then instantiate `L` later.

## Why this is a breakthrough

Formalizing rank-nullity for evaluation maps over finite fields is not merely an exercise. It creates a **universal polynomial witness extractor**. In one stroke, Aristotle would enable formal proofs of:
- existence of low-degree separators and annihilators,
- Reed–Muller code minimum-distance lower bounds,
- polynomial certificates for finite-set avoidance,
- dimension-based lower bounds in algebraic circuit complexity,
- finite geometry incidence obstructions.

This is the exact kind of theorem that turns Mathlib from a library into an engine for the finite-field polynomial method.

## Proof strategies

### Strategy A: Abstract rank-nullity via evaluation linear map
Most promising.

1. Define the evaluation map from the chosen polynomial subspace `V` to `(E → K)`.
2. Show `FiniteDimensional.finrank K (E → K) = E.card`.
3. Use `LinearMap.finrank_range_add_finrank_ker`, plus `finrank_range ≤ E.card`, to deduce
   \[
   \dim \ker(\phi) \ge \dim V - |E| > 0.
   \]
4. Conclude existence of `v ≠ 0` in the kernel using `finrank_pos_iff`.

Why this is best: it isolates the theorem from polynomial-specific combinatorics and produces a general-purpose linear-algebra lemma that will power many later results.

### Strategy B: Constructive monomial-basis proof
Useful for multivariate explicitness.

1. Define the finite set of monomials of total degree `< d`.
2. Identify low-degree polynomials with finitely supported coefficient functions on that monomial set.
3. Represent evaluation on `E` as a matrix:
   \[
   A_{x,m} = m(x).
   \]
4. Since number of columns `> ` number of rows, the homogeneous system `Ac = 0` has a nontrivial solution.
5. Reassemble the coefficient vector into a polynomial.

Why this matters: it connects directly to coding theory and algebraic complexity, where explicit evaluation matrices are central.

### Strategy C: Univariate constructive factorization, then bootstrap
Best for minimizing sorry and securing an early theorem.

1. For finite `E`, define
   \[
   p_E(X)=\prod_{a\in E}(X-C(a)).
   \]
2. Prove `p_E ≠ 0`, `natDegree p_E = E.card`, and `p_E(a)=0` for `a∈E`.
3. If `E.card < d`, conclude `natDegree p_E < d`.
4. Use this as a warmup theorem and then generalize to linear-algebraic multivariate form.

Why this is good: fast, concrete, and highly likely to be fully formalized with minimal friction. But it is less revolutionary than Strategy A unless you explicitly package it as the first layer of a broader evaluation-kernel framework.

## Recommended execution order

1. Prove the abstract finite-dimensional kernel theorem `ker_nontrivial_of_finrank_gt_card`.
2. Instantiate it to a polynomial subspace whenever finite-dimensionality is already available.
3. In parallel, prove the univariate constructive theorem by product over roots.
4. If full multivariate low-total-degree submodule finiteness is difficult, first formalize a **bounded-exponent box degree** variant:
   monomials `m : Fin n →₀ ℕ` with `∀ i, m i < d`.
   This has dimension exactly `d^n`, often easier to count and already highly useful.

A very strong intermediate theorem would be:

```lean
theorem exists_nonzero_mvPolynomial_vanishing_on_finite_set_of_card_lt_pow
    (K : Type*) [Field K]
    (n d : ℕ)
    (E : Finset (Fin n → K))
    (hE : E.card < d ^ n) :
    ∃ p : MvPolynomial (Fin n) K,
      p ≠ 0 ∧
      (∀ m ∈ p.support, ∀ i, m i < d) ∧
      ∀ x ∈ E, MvPolynomial.eval x p = 0
```

This box-degree theorem is mathematically substantial and often easier than total-degree counting.

## Cross-domain connections

### Coding theory
The low-degree evaluation map is exactly the encoding map for Reed–Muller-type codes. Nontrivial kernel statements correspond to non-injectivity thresholds, while injectivity on large enough domains connects to distance and list-decoding phenomena. Formalizing this theorem opens a path to certified coding-theoretic bounds.

### Algebraic complexity
The catalog already contains:
- `bounded_circuit_degree_bound`
- `mulGates_lower_bound_from_degree`

Use the vanishing-polynomial theorem as a bridge: finite sets of evaluation constraints can be annihilated by low-degree polynomials, while circuit degree bounds limit what algebraic circuits can represent. This suggests future lower bounds of the form: if a circuit family agrees with a target on too many points but has too low degree, then a nonzero annihilator forces structural rigidity.

### Finite geometry / combinatorics
This is the polynomial method in embryo. Once formalized, it supports cap-set-style dimension arguments, Nikodym/Kakeya set obstructions, and incidence bounds over finite fields.

### Commutative algebra
`field_has_krull_dim_zero` is conceptually relevant: over a field, point-evaluation ideals are maximal, and finite sets correspond to intersections of maximal ideals. The vanishing polynomial theorem is a finite-dimensional shadow of the geometry of functions on zero-dimensional schemes.

### Probabilistic inference / information
Even `bayes_theorem` can be cross-linked philosophically: evaluation maps compress a hypothesis space of low-degree functions into observed data on `E`. Nontrivial kernel means observational indistinguishability. This suggests a future formal theory of algebraic identifiability over finite fields.

## Concrete build-on-catalog guidance

The circuit-complexity theorems are not direct prerequisites, but they give a downstream purpose:
- Use `bounded_circuit_degree_bound` to compare degree-bounded circuit outputs with low-degree vanishing certificates.
- Use `mulGates_lower_bound_from_degree` as motivation for constructing explicit polynomials of large algebraic complexity that nevertheless vanish on prescribed small sets.
- `field_has_krull_dim_zero` can be cited when framing point evaluations as maximal-ideal quotients and finite sets as zero-dimensional algebraic data.

The right move is to create a bridge theorem now, not to force those catalog theorems into the proof artificially.
