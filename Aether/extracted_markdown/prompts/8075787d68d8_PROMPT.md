## Primary Target Theorem: Exact Finite-Height Collapse

The current upper bound `2^(n+1)` strongly suggests slack. You should try to close the theory completely by proving the exact extremal law for finite-branching objects.

### Precise theorem statement

Let `maxNatDepthAtHeight n` denote the supremum of `natDepth` among research objects of height at most `n`. Prove that this extremal value is exactly `2^n` (or identify the exact corrected formula if the base case normalization differs in the existing definitions).

A mathematically precise target is:

> **Exact Height–Depth Law.**  
> For every `n : ℕ`,
> 1. every research object `R` with `height R ≤ n` satisfies `natDepth R ≤ 2^n`, and  
> 2. there exists `Rₙ` with `height Rₙ = n` and `natDepth Rₙ = 2^n`.

Via `natDepth_eq_researchDepth`, this yields the exact ordinal collapse statement for finite height:
\[
\forall R,\ \mathrm{height}(R)\le n \implies \mathrm{researchDepth}(R) < \omega
\]
with the exact natural code bounded by `2^n`.

### Lean 4 target signatures

You may need to adapt names to the actual file, but the formal target should look as close as possible to:

```lean

    (R : ResearchObject) :
    natDepth R ≤ 2 ^ height R

theorem exists_researchObject_natDepth_eq_two_pow
    (n : ℕ) :
    ∃ R : ResearchObject, height R = n ∧ natDepth R = 2 ^ n

theorem natDepth_sup_eq_two_pow
    (n : ℕ) :
    (∃ R : ResearchObject, height R = n ∧ natDepth R = 2 ^ n) ∧
    (∀ R : ResearchObject, height R ≤ n → natDepth R ≤ 2 ^ n)

    (R : ResearchObject) :
    researchDepth R ≤ (2 ^ height R : Ordinal)
```

If the current normalization gives `1` at height `0`, then `2^0 = 1` is perfect. If some constructor conventions force `2^(n+1)` or `2^n - 1`, do not force the conjecture; instead determine the exact closed form and prove it sharply.

### Why this would be a breakthrough

This would complete the finite regime of the theory with an *exact extremal law*, not a rough upper bound. That transforms the subject from “ordinal-flavored recursion folklore” into a genuine structural complexity theory, analogous to exact depth-size tradeoffs in circuits, derivation height in proof theory, and extremal rank formulas in well-founded trees.

It would also identify balanced binary composition as the canonical maximizer, revealing a universality principle: among all finite-height constructors, the deepest objects are the most symmetric ones. That is a highly reusable theorem schema.

## Secondary Target Theorem: Ordinal Multiplication from Layered Countable Branching

The truly field-opening move is to show that the jump from `ω` to `ω^2` is not mystical: it is generated by *stacking countable branching layers*. This would be the first genuine ordinal arithmetic theorem in your formal collapse theory.

- `omegaPowTree 0` has rank `1` or `0` depending on normalization,
- `omegaPowTree 1` has rank `ω` (recovering `omegaTree_rank_eq_omega`),
- `omegaPowTree (n+1)` is built by countably many branches whose `i`-th branch approximates the previous layer at height/index `i`.

> **Ordinal Tower Realization.**  
> For every `n : ℕ`, there exists a canonical object `Tₙ` with
> \[
> \mathrm{rank}(T_n)=\omega^n

## Proof Strategy Architecture

You should pursue at least two routes in parallel.

### Strategy A: Extremal recursion on height (most promising for the exact `2^n` theorem)

1. **Define a canonical balanced family** `B n` recursively with `B 0` a leaf/base object and `B (n+1)` a binary composition of `B n` with itself.
2. **Prove exact recurrences**:
   - `height (B (n+1)) = height (B n) + 1`
   - `natDepth (B (n+1)) = 2 * natDepth (B n)`
3. **Upgrade the current upper bound** by strengthening induction:
   prove directly that every constructor at height `n+1` contributes at most the sum/max of subdepths in a way bounded by `2^(n+1)`, and show balanced binary composition saturates the inequality.

Why this is most promising: it directly attacks the slack in `natDepth_height_bound` and uses your already verified affine/monotonicity machinery as recurrence-control lemmas.

### Strategy B: Algebra of constructors via a semiring-style depth calculus

1. Identify the exact algebraic laws for `natDepth` under each constructor:
   leaf/base, unary bootstrap, binary compose, countable/oracle branching.
2. Package these as inequalities/equalities resembling:
   - unary constructors preserve or add a constant,
   - binary composition corresponds to addition or doubling,
   - branching corresponds to suprema.
3. Prove the finite-height theorem by interpreting each object as an expression tree and applying a universal extremal principle: among all expressions of height `n`, the maximal value is achieved by repeated binary duplication.

Why this matters: if successful, it gives a reusable “depth semantics” framework that will also support the `ω^n` realization theorem by replacing finite sums with ordinal suprema.

### Strategy C: Ordinal approximation scheme for `ω^n` trees

1. Define `omegaPowTree (n+1)` so that its `i`-th branch approximates larger and larger finite truncations of `omegaPowTree n`.
2. Prove lower bounds `ω^n ≤ rank (omegaPowTree n)` by explicit embedding/monotone approximation.
3. Prove upper bounds `rank (omegaPowTree n) ≤ ω^n` by a structural induction using ordinal supremum identities such as
   \[
   \sup_i (\alpha_i + 1) = \omega^n
   \]
   when the approximants are cofinal below `ω^n`.

This is the key route for transfinite results. The hard part will be cofinality bookkeeping; if Mathlib’s ordinal API is strong enough, this becomes realistic.
