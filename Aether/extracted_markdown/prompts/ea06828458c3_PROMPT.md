**Definition 1: MeasurementScenario** — The basic structure of a compatibility scenario.
```lean
structure MeasurementScenario where
  X : Type*
  [Fintype X]
```

**Definition 2: LocalSection** — An assignment of outcomes to measurements within a single context.
```lean

  c → ℤ₂
```

**Definition 3: CompatibleFamily** — A family of local sections that agree on pairwise overlaps.
```lean

  sections : ∀ c ∈ S.contexts, LocalSection S c
  compatibility : ∀ c₁ ∈ S.contexts, ∀ c₂ ∈ S.contexts,
    ∀ x ∈ c₁ ∩ c₂, sections c₁ ‹_› x = sections c₂ ‹_› x
```

**Definition 4: CechOneCocycle** — The obstruction data on pairwise intersections.
```lean
structure CechOneCocycle (S : MeasurementScenario) where
  obstruction : ∀ c₁ c₂ ∈ S.contexts, (c₁ ∩ c₂ → ℤ₂)
  cocycle_condition : ∀ c₁ ∈ S.contexts, ∀ c₂ ∈ S.contexts, ∀ c₃ ∈ S.contexts,
    ∀ x ∈ c₁ ∩ c₂ ∩ c₃,
    obstruction c₁ ‹_› c₂ ‹_› x + obstruction c₂ ‹_› c₃ ‹_› x =
    obstruction c₁ ‹_› c₃ ‹_› x
```

**Definition 5: CechOneCoboundary** — Trivial obstructions arising from local section differences.
```lean
structure CechOneCoboundary (S : MeasurementScenario) extends CechOneCocycle S where
  witness : ∀ c ∈ S.contexts, LocalSection S c
  coboundary_derivation : ∀ c₁ ∈ S.contexts, ∀ c₂ ∈ S.contexts,
    ∀ x ∈ c₁ ∩ c₂,
```

### III. PROOF STRATEGIES (Three Paths)

**Strategy A: Direct Combinatorial Computation (Most Promising for Peres-Mermin)**
1. Enumerate all 2⁹ = 512 possible global sections g : Fin 9 → ℤ₂
2. For each global section, verify it violates at least one of the 6 parity constraints
3. Construct the Čech cocycle explicitly: for each pair of overlapping contexts (c₁, c₂), define the obstruction on c₁ ∩ c₂ as the difference between the quantum-predicted local sections
4. Verify the cocycle condition by checking all triples of overlapping contexts (O(6³) = O(216) checks)
5. Show this cocycle is not a coboundary by contradiction: assume a local section witness s exists, then derive a parity contradiction
6. **Why most promising**: The Peres-Mermin square is small enough for complete enumeration, and the ℤ₂ coefficients make all computations exact. The parity constraint argument is the classic route to Kochen-Specker.

**Strategy B: Functorial/Categorical Approach (Most Elegant)**
1. Define the assignment presheaf as a functor F : (Cover S)^op → Type
2. Show that compatible families are exactly sections of the sheafification F⁺
3. Use the Čech-to-derived-functor spectral sequence to identify H¹_Čech with H¹_derived
4. Apply the long exact sequence in cohomology for the presheaf → sheafification adjunction
5. **Why secondary**: Requires substantial category-theoretic infrastructure that may not yet exist in Mathlib for this level of generality. Better as a follow-up.

**Strategy C: Reduction via Symmetry (Most Scalable)**
1. Observe that the Peres-Mermin scenario has an S₃ symmetry (permuting rows/columns)
2. Use the S₃-action on H¹ to decompose it into irreducible representations
3. Show that the 2-dimensional representation corresponds to the Klein four-group structure
4. **Why tertiary**: Elegant but requires representation-theoretic machinery. Better for proving structure theorems about H¹ in general.

**Recommended approach**: Start with Strategy A for the concrete Peres-Mermin results (Theorems 2, 3, 6, 10, 11), then use the insights to prove the general structural results (Theorems 1, 4, 5, 7, 8, 9).

### IV. KEY LEMMAS (Building Blocks)

**Lemma: parity_product_anticommutativity**
The product of outcomes around the Peres-Mermin square satisfies: row products = +1, column products = -1, giving a total product of (+1)³ × (-1)³ = -1, which contradicts the classical requirement that the product must be +1.

**Lemma: cech_cocycle_from_local_sections**
Given a compatible family cf, the map δ(cf)(c₁, c₂)(x) = cf(c₁)(x) - cf(c₂)(x) for x ∈ c₁ ∩ c₂ defines a Čech 1-cocycle. Proof: the cocycle condition follows from the transitivity of differences.

**Lemma: coboundary_iff_globally_extendable**
A compatible family extends to a global section if and only if its Čech obstruction cocycle is a coboundary. This is the key bridge between the topological and logical viewpoints.

**Lemma: klein_four_from_parity_constraints**
The group of Čech 1-cocycles modulo coboundaries for the Peres-Mermin scenario has exactly 4 elements, corresponding to the 4 possible parity assignments (++, +-, -+, --) to the two independent constraint directions.

**Lemma: simulation_cost_lower_bound_torsion**

            ### Precise Mathematical Framing
            Define a measurement scenario as a triple (X, O, M) where X is a finite measurement set, O is a finite outcome set, and M ⊆ P(X) is an antichain cover by maximal measurement contexts.
