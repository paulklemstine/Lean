### Research Direction

**Central Conjecture (Universal Defect Formula):** For every finite connected graph $G$, root $q \in V(G)$, and nonempty $S \subseteq V \setminus \{q\}$:

$$\underbrace{\text{tropRank}(L_S) - 1 - r(D_S)}_{\text{equality defect } \delta_{\text{eq}}(G,q,S)} = \underbrace{\beta_1(G[S]) + \kappa(G,q,S) - 1}_{\text{structural defect } \delta_{\text{str}}(G,q,S)}$$

where:
- $\text{tropRank}(L_S)$ is the tropical rank (maximum size of a tropically nonsingular square submatrix) of the restricted tropical Laplacian $L_S$,
- $r(D_S)$ is the Baker–Norine divisor rank of $D_S = \deg_{G[S]} - \deg_G$ on $G[S]$,
- $\beta_1(G[S]) = |E(G[S])| - |V(G[S])| + c(G[S])$ is the cyclomatic number (first Betti number) of the subgraph induced by $S$,
- $\kappa(G,q,S)$ counts the connected components of $G[S]$ that have at least one edge to $q$ in $G$ (the "q-visible" components).

**Precise Lean 4 Type Signature:**

### Proof Strategies

**Strategy A: Component-Wise Rank Decomposition (Most Promising)**

This proceeds in three stages, leveraging the existing `rootedSubsetDivisor_decomposition` from the catalog:

1. **Decompose the Laplacian.** Show that when $G[S]$ has connected components $C_1, \ldots, C_k$, the tropical Laplacian $L_S$ decomposes as a block matrix (after permutation) with blocks $L_{C_i}$ on the diagonal and off-diagonal entries encoding inter-component edges. Use the existing `tropicalLaplacian` definition and prove a block structure lemma via `SimpleGraph.induce` properties.

2. **Compute tropical rank block-by-block.** Prove that $\text{tropRank}(L_S) = \sum_i \text{tropRank}(L_{C_i}) + \epsilon$ where $\epsilon$ is a correction from off-diagonal entries. Show this correction equals $\kappa(G,q,S) - c(G[S])$ by analyzing how q-visible components contribute extra rank through their connection to $q$. This is the key technical step — use tropical Cramer's rule (tropical determinant characterizes nonsingularity) and the fact that q-visible components introduce tropically independent rows.

3. **Reassemble via Baker–Norine subadditivity.** Using `divisor_rank_subadditivity` (or proving it if absent): $r(D_S) \leq \sum_i r(D_{C_i})$. Combined with the known zero-defect result (catalog: `zero_defect_case`), which gives $\text{tropRank}(L_{C_i}) = r(D_{C_i}) + 1$ for each connected component, derive $\text{tropRank}(L_S) - 1 - r(D_S) = \sum_i \beta_1(C_i) + \kappa - 1 = \beta_1(G[S]) + \kappa - 1$.

**Strategy B: Tropical Kernel-Cokernel Exact Sequence**

1. Define the tropical kernel of $L_S$ as the set of vectors $v$ with $L_S \otimes v = \mathbf{0}$ (tropical matrix-vector multiplication in the min-plus semiring).

2. Prove a tropical analogue of the rank-nullity theorem: $\text{tropRank}(L_S) + \text{dim}(\text{tropKer}(L_S)) = |S|$, where dimension is tropical dimension (tropically independent generators).

3. Show that $\text{tropKer}(L_S)$ is generated by the characteristic vectors of cycles in $G[S]$ plus indicator vectors of q-visible components, yielding $\text{dim}(\text{tropKer}(L_S)) = \beta_1(G[S]) + \kappa(G,q,S)$. This connects tropical linear algebra directly to homology.

**Strategy C: Matroid Rank Difference (Most Elegant if It Works)**

1. Observe that $\text{tropRank}(L_S)$ defines a matroid $\mathcal{M}_{\text{trop}}$ on the rows of $L_S$ (tropical row matroid), while $r(D_S) + 1$ defines a matroid $\mathcal{M}_{\text{div}}$ (divisor matroid via effective rank).

2. Prove that $\mathcal{M}_{\text{trop}}$ is a strengthening of $\mathcal{M}_{\text{div}}$ — i.e., every independent set in $\mathcal{M}_{\text{div}}$ is independent in $\mathcal{M}_{\text{trop}}$, but not conversely.

3. By matroid theory, the rank difference $r(\mathcal{M}_{\text{trop}}) - r(\mathcal{M}_{\text{div}})$ equals the rank of the restriction to the set of "loops" of $\mathcal{M}_{\text{div}}$ in $\mathcal{M}_{\text{trop}}$. Show these loops correspond exactly to cycles and q-visible components, giving $\beta_1 + \kappa - 1$.

**Recommendation:** Strategy A is most promising because it directly leverages the existing `rootedSubsetDivisor_decomposition` and the zero-defect case already in the catalog. Strategy C is the most elegant but requires developing matroid theory that may not yet be in Mathlib.

### Cross-Domain Connections

1. **Tropical Linear Algebra ↔ Algebraic Topology:** The defect $\beta_1 + \kappa - 1$ is precisely the Euler characteristic deficit of the pair $(G[S], G[S] \cup \{q\text{-edges}\})$. This mirrors the Atiyah–Singer index theorem: analytical index (rank gap) = topological index (Betti correction). Formalize: `defect = χ(G[S] ∪ q-edges) - χ(G[S]) + κ - 1`.

2. **Chip-Firing ↔ Sandpile Models ↔ Self-Organized Criticality (Physics):** The Baker–Norine rank $r(D_S)$ is the graph-theoretic analogue of the sandpile group's recurrent configuration count. The defect formula predicts that the "distance from criticality" in the sandpile model equals $\beta_1 + \kappa - 1$. This opens a bridge to statistical mechanics: the defect is an order parameter for a phase transition in the sandpile model on $G[S]$.

3. **Tropical Rank ↔ Min-Plus Optimization ↔ Operations Research:** Tropical rank via optimal assignment (Hungarian algorithm in the tropical semiring) connects to combinatorial optimization. The defect formula says: the gap between the "natural" optimization rank and the divisor-theoretic rank is purely topological. This has implications for tropical principal component analysis and tropical neural network theory (see catalog: `TropicalDegreeRobustness.lean`).

4. **Baker–Norine ↔ Riemann–Roch (Algebraic Geometry):** The full defect formula is a "Riemann–Roch with defects" — when the defect is zero, we recover the Baker–Norine Riemann–Roch theorem. When nonzero, the defect measures the failure of the graph to be "divisor-theoretically smooth," analogous to how singularities create discrepancies in the classical Riemann–Roch theorem.

### Falsifiable Conjecture with Computational Test

**Conjecture (Defect Quantization):** For any connected graph $G$ with root $q$ and $S \subseteq V \setminus \{q\}$:

$$\delta_{\text{eq}}(G,q,S) \in \{0, 1, \ldots, \beta_1(G) - 1\}$$

That is, the equality defect is always an integer between 0 and $\beta_1(G) - 1$ (inclusive), and every value in this range is achieved for some choice of $S$.

**Computational Test:** Enumerate all connected graphs on $n \leq 6$ vertices. For each graph and each valid $(q, S)$ pair, compute $\delta_{\text{eq}}$. Verify: (a) the defect is always in the claimed range, (b) every value in $\{0, \ldots, \beta_1(G)-1\}$ is realized. A single violation of (a) disproves the conjecture; failure of (b) weakens it significantly.
