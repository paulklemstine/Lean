## Primary Breakthrough Target

### Theorem Cluster A: Abstract path structure implies function extensionality

Define an interval/path abstraction and prove that pointwise paths induce paths between functions.

A precise target is:

```lean
class CubicalInterval (I : Type u) where
  i0 : I
  i1 : I

def PathOver {I : Type u} [CubicalInterval I] (A : Type v) (a₀ a₁ : A) : Type (max u v) :=
  { p : I → A // p (CubicalInterval.i0) = a₀ ∧ p (CubicalInterval.i1) = a₁ }

theorem funext_of_path
  {I : Type u} [CubicalInterval I]
  {α : Type v} {β : α → Type w}
  {f g : (x : α) → β x}
  (h : ∀ x, PathOver (β x) (f x) (g x)) :
  PathOver ((x : α) → β x) f g
```

This is the minimal nontrivial cubical theorem: a path object with endpoint data should support **dependent function extensionality at the path level**. If you can prove this cleanly, you have built the first real bridge from cubical semantics to Lean functions.

A stronger nondependent version should also be proved:

```lean
theorem funext_of_path_nondep
  {I : Type u} [CubicalInterval I]
  {α : Type v} {β : Type w}
  {f g : α → β}
  (h : ∀ x, PathOver β (f x) (g x)) :
  PathOver (α → β) f g
```

Why this matters: it demonstrates that “path = interval-indexed map with boundary conditions” is not just notation; it has enough coherence to recover one of the central principles of extensional type theory.

## Secondary Breakthrough Target

### Theorem Cluster B: Weak univalence for a concrete universe fragment of structured finite types

Full kernel-level univalence is not realistically derivable in Lean 4. But a **formal weak univalence theorem** for a concrete universe fragment is both meaningful and achievable.

Construct a small universe of codes for finite types, for example:

```lean
inductive UCode
| zero
| one
| bool
| sum   : UCode → UCode → UCode
| prod  : UCode → UCode → UCode
```

with interpretation:

```lean
def El : UCode → Type
```

Define code equivalence and equality of codes, then prove that equivalences of codes induce paths/equalities in the universe of codes. Precise target:

```lean
def CodeEquiv : UCode → UCode → Type := ...

theorem weak_univalence_code
  {a b : UCode} :
  CodeEquiv a b → PathOver UCode a b
```

Stronger target, if your path formalism is equality-compatible:

```lean
theorem weak_univalence_code_eq
  {a b : UCode} :
  Nonempty (El a ≃ El b) → a = b
```

This may require restricting to a canonical normal form universe where isomorphic codes are definitionally normalized before comparison. If so, say so explicitly and prove the normalization theorem.

Why this is a breakthrough: it gives a **computable, internalized univalence principle** for a genuine universe fragment. This is much more interesting than postulating univalence as an axiom, because it exhibits where univalence becomes constructive and algorithmic.

Application keywords: **univalent foundations, finite semantics, certified equivalence transport, normalization by evaluation, proof assistant kernel design**.

## Tertiary Breakthrough Target

### Theorem Cluster C: Higher inductive surrogates with correct recursion principles

Lean 4 does not natively support higher inductive types, so the right move is to implement **HIT surrogates** via quotient/gluing encodings and prove their universal properties.

#### 1. Circle surrogate
A mathematically clean starting point is to define a pointed connected 1-type surrogate of `S¹`. One candidate is integers modulo a chosen relation, but that trivializes topology. A more meaningful surrogate is the type of loops generated by one constructor modulo path algebra laws. Even if this is syntactic, the recursion principle is the theorem that matters.

Target interface:

```lean
constant S1 : Type
constant base : S1
constant loop : PathOver S1 base base

theorem S1_rec
  {X : Type u}
  (x0 : X)
  (ℓ : PathOver X x0 x0) :
  S1 → X
```

with computation lemmas as far as your encoding allows. If a direct HIT encoding is impossible, formalize instead a **signature + eliminator package** and prove uniqueness of recursors.

#### 2. Suspension
For any type `A`, define a suspension surrogate `Susp A` with north/south points and meridians:

```lean
constant Susp : Type u → Type u
constant north : {A : Type u} → Susp A
constant south : {A : Type u} → Susp A
constant merid : {A : Type u} → A → PathOver (Susp A) north south
```

Then prove its universal property:

```lean
theorem Susp_rec
  {A : Type u} {X : Type v}
  (n s : X)
  (m : A → PathOver X n s) :
  Susp A → X
```

#### 3. Torus as iterated suspension/product/gluing surrogate
A realistic target is not a full topological torus HIT, but a type equipped with:
- a base point,
- two commuting loops,
- and a square filler witness expressing commutation.

```lean
structure TorusData (X : Type u) where
  base : X
  p : PathOver X base base
  q : PathOver X base base
  commute : Type u
```

Then define a torus surrogate as an initial object for such data, or a syntactic free object modulo commuting relations, and prove its recursion principle.

Why this matters: universal properties of HIT surrogates are the real algebraic content behind synthetic homotopy theory. If you formalize these recursors and their uniqueness principles, you create a platform for later homotopy calculations.

Application keywords: **higher inductive types, recursion principles, free ∞-groupoid fragments, synthetic homotopy theory, algebraic topology in proof assistants**.

## 2–3 Proof Strategy Architectures

### Strategy A: Semantic interval model via `Bool` or a two-point type
Most promising for immediate theorem production.

1. Instantiate `CubicalInterval` with `Bool` or `Fin 2`.
   Then `PathOver A a₀ a₁` becomes a function on two endpoints with boundary proofs.
2. Prove `funext_of_path` by defining the path pointwise:
   ```lean
   p.val i x := (h x).1 i
   ```
   and discharge endpoint equalities by `funext`.
3. Develop `ap`, symmetry, and recursor packages for HIT surrogates in this simple model.

Why promising: it is implementable now, gives concrete Lean terms, and yields a nontrivial extensional path calculus. It will not capture genuine cubical composition, but it will establish the formal backbone.

### Strategy B: Axiomatized cubical structure with composition/filling operations
Most conceptually powerful.

1. Define a class extending `CubicalInterval` with abstract operations corresponding to composition/filling:
   coercion maps, boundary restriction, perhaps a composition operator for partial cubes.
2. Prove generic theorems from these axioms: path congruence, path induction surrogates, function extensionality, transport coherence.
3. Instantiate later with a concrete model or leave as an interface for future semantic models.

Why promising: this separates syntax from semantics and makes the theory extensible toward actual cubical semantics. It is the best route if your goal is a reusable Lean cubical library.

### Strategy C: Universe-code normalization and weak univalence by canonical forms
Best route for univalence-like results.

1. Define `UCode`, interpretation `El`, and a normalization function to canonical representatives.
2. Prove soundness/completeness:
   - normalized-equal codes interpret as equivalent types,
   - equivalences induce equality of normal forms.
3. Use the path/equality bridge to derive `weak_univalence_code`.

Why promising: full univalence is out of reach, but canonical finite universes are computationally tractable and mathematically clean. This could become a certified normalization-based univalence engine.

Recommended order: **A → C → B**, with HIT surrogates developed in parallel after A.

### Path algebra
```lean
theorem path_eta
  {I : Type u} [CubicalInterval I]
  {A : Type v} {a₀ a₁ : A}
  (p : PathOver A a₀ a₁) :

theorem path_ext
  {I : Type u} [CubicalInterval I]
  {A : Type v} {a₀ a₁ : A}
  {p q : PathOver A a₀ a₁}
  (h : ∀ i, p.1 i = q.1 i) :

```

### Function extensionality
```lean
theorem funext_path_eq
  {I : Type u} [CubicalInterval I]
  {α : Type v} {β : α → Type w}
  {f g : (x : α) → β x}
  (h : ∀ x, PathOver (β x) (f x) (g x)) :
  ∀ x, (PathOver.mk (fun i => (funext_of_path h).1 i) ((funext_of_path h).2)).1 x =
       (h x).1
```

### Universe code normalization
```lean
def normalize : UCode → UCode := ...

theorem normalize_idempotent (c : UCode) :
  normalize (normalize c) = normalize c

theorem El_normalize_equiv (c : UCode) :
  El c ≃ El (normalize c)
```

### Weak univalence
```lean
theorem weak_univalence_normalized
  {a b : UCode}
  (h : Nonempty (El a ≃ El b))
  (ha : normalize a = a)
  (hb : normalize b = b) :
  a = b
```

### Suspension recursor uniqueness
```lean
theorem Susp_rec_unique
  {A : Type u} {X : Type v}
  (n s : X) (m : A → PathOver X n s)
  (f g : Susp A → X)
  (hf : f = Susp_rec n s m)
  (hg : g = Susp_rec n s m) :
  f = g
```

Even if your HIT encodings are abstract, proving **uniqueness of recursors** is mathematically substantial.
