## Core Vision

Let `S` be an M-convex subset of integer lattice points of a fixed simplex layer, and let `c : ι → ℤ` be a linear objective. Define a steepest exchange-descent algorithm that, from a feasible point `x ∈ S`, repeatedly chooses indices `i, j` with `x i > 0` such that the exchange move
\[
x' = x - e_i + e_j
\]
remains in `S` and strictly decreases the objective
\[
\sum_k c_k x_k.
\]
The central claim is that M-convexity forces any local minimum under these elementary exchanges to be a global minimum, and that descent length is controlled by an exchange-distance potential.

This is the discrete convex analogue of the deepest paradigm in continuous optimization:

- convexity turns local optimality into global optimality,
- gradient-like descent becomes certifying,
- geometry yields complexity bounds.

Your task is to make that principle fully explicit in Lean 4.

## New Definitions You Should Introduce

At least one genuinely new concept must appear. The following package is promising and mathematically meaningful.

### 1. Exchange descent relation
Define the one-step descent relation on feasible points:
```lean
def ExchangeDescends
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ)) (c : ι → ℤ) (x y : ι → ℤ) : Prop :=
  y ∈ S ∧ x ∈ S ∧
  (∃ i j, i ≠ j ∧ 0 < x i ∧
    y = Function.update (Function.update x i (x i - 1)) j (x j + 1)) ∧
  (∑ k, c k * y k) < (∑ k, c k * x k)
```

If `Function.update` becomes awkward, define an additive exchange operator:
```lean
def exchangeVec {ι : Type} [DecidableEq ι] (x : ι → ℤ) (i j : ι) : ι → ℤ :=
  fun k => x k + (if k = j then 1 else 0) - (if k = i then 1 else 0)
```
and use `y = exchangeVec x i j`.

### 2. Exchange-local optimality
```lean
def IsExchangeLocalMin
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ)) (c : ι → ℤ) (x : ι → ℤ) : Prop :=
  x ∈ S ∧
  ∀ y, ExchangeDescends S c x y → False
```

Define a graph-distance-like potential from a point to the optimal set, or more concretely a distance between feasible points counted by elementary exchanges. Even a non-metric “minimum number of valid exchanges along feasible points” is enough if you can prove the needed monotonicity.
```lean
def exchangeReachableIn
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ)) : ℕ → (ι → ℤ) → (ι → ℤ) → Prop := ...
```

Then define:
```lean
def exchangeDist
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ)) (x y : ι → ℤ) : ℕ := ...
```
Possibly as an `sInf` over path lengths if convenient, or as a recursively defined graph distance on the finite exchange graph.

### 4. Certified optimizer
Define the output as a point together with proof of feasibility and optimality.

### Theorem 1: Local exchange optimality implies global optimality

#### Mathematical statement
Let `S` be M-convex. If `x ∈ S` admits no improving feasible exchange move, then `x` minimizes every linear objective over `S`.

Formally:
\[
\forall x \in S,\;
\Big(\forall i,j,\ x_i>0 \land x-e_i+e_j\in S \implies
c\cdot x \le c\cdot(x-e_i+e_j)\Big)
\Rightarrow
\forall y\in S,\ c\cdot x \le c\cdot y.
\]

#### Suggested Lean 4 signature
```lean
theorem exchange_local_min_implies_global_min
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ))
  (hM : IsMConvexSet S)
  (c : ι → ℤ)
  (x : ι → ℤ)
  (hx : x ∈ S)
  (hlocal :
    ∀ i j, i ≠ j → 0 < x i →
      exchangeVec x i j ∈ S →
      (∑ k, c k * x k) ≤ (∑ k, c k * exchangeVec x i j k)) :
  ∀ y, y ∈ S → (∑ k, c k * x k) ≤ (∑ k, c k * y k)
```

#### Why this is a breakthrough
This is the discrete convex analogue of “first-order optimality for convex functions.” Once formalized, it becomes a reusable engine for certifying correctness of combinatorial optimization procedures on M-convex domains. It opens a route to verified algorithms for allocation, balancing, flows, inventory, and polymatroid-type optimization.

#### Proof strategies
**Strategy A: Exchange-chain contradiction via M-convexity**  
Most promising.
1. Assume there exists `y ∈ S` with smaller objective than `x`.
2. Compare coordinates where `x` exceeds `y`; use M-convex exchange axiom to construct a feasible exchange from `x` toward `y`.
3. Show one such exchange strictly improves the linear objective, contradicting local minimality.

This is the cleanest because linear objectives interact perfectly with one-coordinate exchanges:
\[
c\cdot(x-e_i+e_j)=c\cdot x - c_i + c_j.
\]
So any profitable direction is visible at the coefficient level.

**Strategy B: Induction on ℓ1-distance between feasible points**  
1. Define
   \[
   \delta(x,y)=\sum_i \max(x_i-y_i,0).
   \]
2. If `δ(x,y)=0`, then `x=y`.
3. Otherwise use M-convexity to produce a feasible exchange decreasing `δ`, and propagate the objective comparison inductively.

This is robust and likely formalizes well because the induction measure is explicit.

**Strategy C: Exchange graph + monotone path argument**  
1. Use exchange connectivity from the catalog.
2. Refine connectivity to show there is a path from `x` to `y` whose first step can be chosen objective-improving whenever `c·y < c·x`.
3. Contradict local minimality.

This is conceptually elegant but may require more graph machinery.

### Theorem 2: Termination of steepest exchange descent by a well-founded potential

#### Mathematical statement
For finite M-convex `S`, repeated strict objective descent by feasible exchanges terminates from any starting point.

#### Suggested Lean 4 signature
A computable steepest-step selector may be nontrivial, so first prove an abstract termination theorem for any descent sequence:
```lean
theorem no_infinite_strict_descent_on_finite_mconvex
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ))
  (c : ι → ℤ) :
  WellFounded (fun x y =>
    x ∈ S ∧ y ∈ S ∧ (∑ k, c k * x k) < (∑ k, c k * y k))
```
Then instantiate it for the algorithm.

Or define a recursive optimizer:
```lean
def steepestDescent
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ)) (c : ι → ℤ) :
  {x // x ∈ S} → {x // x ∈ S}
```
and prove:
```lean
theorem steepestDescent_terminates
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ))
  (hM : IsMConvexSet S)
  (c : ι → ℤ)
  (x0 : ι → ℤ)
  (hx0 : x0 ∈ S) :
  ∃ x*, x* ∈ S ∧ IsExchangeLocalMin S c x*
```

#### Why this matters
This turns M-convexity into an **algorithmic invariant**. The point is not only existence of minimizers, but that a local rule produces one with a proof-carrying certificate. This is the discrete optimization analogue of Lyapunov-certified descent in dynamical systems.

#### Proof strategies
**Strategy A: Finite strictly decreasing objective values**  
Most direct.
1. Since `S` is finite, the set of objective values on `S` is finite.
2. Every descent step strictly lowers the objective.
3. Therefore no infinite descent chain exists; recursion on a measure is valid.

This gives the cleanest executable recursion principle.

**Strategy B: Lexicographic potential = objective value + exchange distance to optimum set**  
1. Let `Opt = {x ∈ S | x is globally optimal}`.
2. Show every non-optimal state admits a feasible exchange reducing either objective or distance-to-optimum.
3. Conclude well-foundedness by lexicographic order on `ℤ × ℕ`.

This is stronger and sets up the complexity theorem.

**Strategy C: Path-shortening induction in the exchange graph**  
1. Use exchange connectedness.
2. For any non-optimal `x`, choose an optimal `x*` and derive a path.
3. Show steepest descent cannot cycle and must advance toward lower objective strata.

Good conceptually, but more technical.

### Theorem 3: Complexity bound via exchange diameter

#### Mathematical statement
Let `D` be the exchange diameter of `S`, i.e. the maximum over feasible pairs of the shortest exchange-path length. Then steepest descent terminates in at most `D` strict improving exchanges; alternatively prove a more conservative bound `n * D` if the stronger theorem is harder.

A strong version:
\[
\forall x_0\in S,\quad \text{steps}(x_0)\le \min_{x^\star \in \operatorname{Argmin}(c)} d_{\mathrm{ex}}(x_0,x^\star)\le D.
\]

A weaker but still publishable version:
\[
\text{steps}(x_0)\le nD.
\]

#### Suggested Lean 4 signature
```lean
theorem steepestDescent_steps_le_exchangeDist_to_opt
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ))
  (hM : IsMConvexSet S)
  (c : ι → ℤ)
  (x0 xopt : ι → ℤ)
  (hx0 : x0 ∈ S)
  (hxopt : xopt ∈ S)
  (hopt : ∀ y, y ∈ S → (∑ k, c k * xopt k) ≤ (∑ k, c k * y k)) :
  stepCount S c x0 ≤ exchangeDist S x0 xopt
```
and then:
```lean
theorem steepestDescent_steps_le_exchangeDiameter
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (S : Finset (ι → ℤ))
  (hM : IsMConvexSet S)
  (c : ι → ℤ)
  (x0 : ι → ℤ)
  (hx0 : x0 ∈ S) :
  stepCount S c x0 ≤ exchangeDiameter S
```

If exact graph distance is too heavy, define a simpler diameter upper bound from coordinate discrepancy and prove:
```lean
theorem steepestDescent_steps_le_l1_half
  ...
  stepCount S c x0 ≤ ((∑ i, |x0 i - xopt i|) / 2)
```
This is mathematically natural because each exchange changes two coordinates by one.

#### Why this is genuinely new
This theorem upgrades correctness to **certified complexity**. In formal mathematics, verified optimization often stops at “returns an optimum.” Here the output comes with a structural iteration bound tied to the intrinsic geometry of the feasible set. That is the kind of theorem that can seed a field of verified discrete convex optimization.

#### Proof strategies
**Strategy A: Each improving exchange can be aligned with a shortest path to an optimum**  
Ambitious and high-value.
1. Fix an optimal `xopt`.
2. Show every non-optimal iterate admits an improving exchange that also decreases exchange distance to `xopt`.
3. Conclude by induction on `exchangeDist S x xopt`.

If you can prove this, it is the crown jewel.

**Strategy B: Objective layers + bounded path compression**  
1. Show every shortest exchange path from `x` to `xopt` contains at least one improving move.
2. Steepest descent does at least as well as any improving move.
3. Bound the number of strict objective layers by path length or by `n * D`.

This may be easier than full monotone geodesicity.

**Strategy C: Coordinate imbalance potential**  
1. Define
   \[
   \Phi(x;x^\star)=\sum_i \max(x_i-x^\star_i,0).
   \]
2. Show some steepest improving exchange decreases `\Phi`.
3. Since `\Phi ≤ nD` or directly `\Phi = d_ex` in good cases, derive the complexity bound.

This is probably the best compromise between strength and formal tractability.

## Cross-Domain Connection Theorem

### Recommended bridge: M-convex optimization ↔ majorization / inequality theory

On simplex layers, exchange operations are precisely “Robin Hood transfers” in reverse. This ties M-convexity to discrete Schur-convexity, fairness, and entropy-like balancing principles.

A theorem candidate:

#### Theorem 5: Exchange descent minimizes linear costs on fixed-mass allocations and encodes a majorization monotonicity principle
If `S = {x : ι → ℤ | ∀ i, 0 ≤ x i ∧ ∑ i, x i = d}` or an M-convex subset thereof, then an exchange from a higher-cost coordinate to a lower-cost coordinate decreases the linear energy. This connects discrete convex optimization with inequality theory and statistical mechanics of particle redistribution.

Lean-flavored statement:
```lean
theorem exchange_linear_drop_eq_coeff_gap
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (c x : ι → ℤ) (i j : ι)
  (hij : i ≠ j) :
  (∑ k, c k * exchangeVec x i j k)
    = (∑ k, c k * x k) - c i + c j
```

Then derive:
```lean
theorem exchange_improves_of_cost_gap
  {ι : Type} [Fintype ι] [DecidableEq ι]
  (c x : ι → ℤ) (i j : ι)
  (hij : i ≠ j) (hgap : c j < c i) :
  (∑ k, c k * exchangeVec x i j k) < (∑ k, c k * x k)
```

This theorem is elementary in formula but not trivial in proof if done through a careful `Finset` decomposition and multi-step `calc`. More importantly, it creates a bridge to:

- **economics**: discrete resource reallocation,
- **statistical physics**: particle transport lowering energy,
- **operations research**: load balancing and assignment costs,
- **majorization theory**: exchange-generated partial orders.

This is the right kind of cross-domain theorem because it identifies M-convex exchange descent as a **discrete energy dissipation law**.
