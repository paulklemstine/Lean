## Primary theorem A: polynomial orbit-count bound from spectral bound

State and prove a theorem of the following form:

### Mathematical statement
For every `n ≥ 1`, every tropical matrix `G : Matrix (Fin n) (Fin n) ℝ`, if there exists `ρ : ℝ` such that every entry of every tropical power grows at most linearly with slope `ρ`, i.e.
\[
\forall k \ge 1,\ \forall i,j,\ (G^{\otimes k})_{ij} \le k\rho + C,
\]
and similarly below by
\[
k\rho - C \le (G^{\otimes k})_{ij},
\]
then the number of distinct normalized powers up to time `N` is polynomially bounded in `N`.

The normalization is crucial: quotient out the trivial linear drift by considering
\[
\widetilde G^{(k)}_{ij} := (G^{\otimes k})_{ij} - k\rho.
\]
Then if all normalized entries lie in an interval of length `2C`, and if they are integer-valued or belong to a finite discretized set, one gets a genuine orbit-count bound.

Because the real-valued version cannot imply finiteness without a discreteness hypothesis, formulate the formal theorem on `ℤ`-valued or `ℕ`-valued tropical matrices first, or impose an explicit finite image hypothesis.

### Lean 4 type signature candidate
A robust formal target is:

```lean
theorem orbit_card_bound_of_entry_bounds
  {n : ℕ} [NeZero n]
  (G : Matrix (Fin n) (Fin n) ℤ)
  (ρ C : ℤ)
  (hupper : ∀ k : ℕ, 1 ≤ k →
    ∀ i j : Fin n, tropPow G k i j ≤ (k : ℤ) * ρ + C)
  (hlower : ∀ k : ℕ, 1 ≤ k →
    ∀ i j : Fin n, (k : ℤ) * ρ - C ≤ tropPow G k i j) :
  ∃ K : ℕ, ∀ N : ℕ,
    (orbitSetNormalized G ρ N).card ≤ K
```

This is already nontrivial and powerful: bounded normalized entries force eventual repetition in a finite state space.

A more quantitative refinement:

```lean
theorem orbit_card_bound_of_box_bound
  {n : ℕ} [NeZero n]
  (G : Matrix (Fin n) (Fin n) ℤ)
  (ρ C : ℤ)
  (hbound : ∀ k : ℕ, 1 ≤ k →
    ∀ i j : Fin n, |tropPow G k i j - (k : ℤ) * ρ| ≤ C) :
  ∀ N : ℕ,
    (orbitSetNormalized G ρ N).card ≤ (2 * Int.natAbs C + 1)^(n*n)
```

This theorem is field-opening because it converts spectral linear growth into a finite-state dynamical system statement. It is a tropical analogue of “subtract the Lyapunov drift and the residual dynamics lives in a compact symbolic state space.”

## Primary theorem B: spectral radius induces bounded normalized orbit

Now connect this to the catalog.

### Mathematical statement
Assume `ρ` is a tropical spectral bound for `G`, derived from `tropical_spectral_bound` or `tropical_spectral_radius_le_eigenvalue`. Prove that if `G` admits a tropical eigenvector/eigenvalue pair realizing `ρ`, then every entry of `G^k` differs from `kρ` by a constant depending only on the eigenvector gauge. Hence the normalized orbit is finite in the integer/discrete setting.

A clean statement:

\[
\exists v,\ \forall i,\ \max_j (G_{ij}+v_j)=\rho+v_i
\quad\Longrightarrow\quad
\forall k,i,j,\ (G^{\otimes k})_{ij} \le k\rho + (v_i-v_j),
\]
and similarly a lower bound under suitable irreducibility/critical graph hypotheses.

### Lean 4 type signature candidate
```lean
theorem trop_power_entry_upper_bound_of_eigenvector
  {n : ℕ} [NeZero n]
  (G : Matrix (Fin n) (Fin n) ℤ)
  (v : Fin n → ℤ) (ρ : ℤ)
  (heig : ∀ i : Fin n, (tropMatVecMul G v) i = ρ + v i) :
  ∀ k : ℕ, ∀ i j : Fin n,
    tropPow G k i j ≤ (k : ℤ) * ρ + v i - v j
```

A companion lower bound may require stronger assumptions. If full equality is too ambitious, prove the upper bound first; it is already enough to derive bounded normalized orbit after suitable dual hypotheses.

This theorem is the real bridge: it converts a tropical eigen-equation into a dynamical orbit constraint.

## Primary theorem C: entropy-collapse theorem

Once A and B are in place, prove that bounded normalized orbit implies zero asymptotic orbit entropy.

### Mathematical statement
Define
\[
h_{\mathrm{orb}}(G) := \limsup_{N\to\infty}\frac{1}{N}\log \#\{\widetilde G^{(1)},\dots,\widetilde G^{(N)}\}.
\]
Then under the bounded normalized orbit hypothesis,
\[
h_{\mathrm{orb}}(G)=0.
\]

### Lean 4 type signature candidate
```lean
def orbitEntropy
  {n : ℕ} (G : Matrix (Fin n) (Fin n) ℤ) (ρ : ℤ) : ℝ :=
  Filter.limsup (fun N : ℕ =>
    Real.log ((orbitSetNormalized G ρ N).card) / N) Filter.atTop

theorem orbit_entropy_eq_zero_of_bounded_normalized_orbit
  {n : ℕ} [NeZero n]
  (G : Matrix (Fin n) (Fin n) ℤ)
  (ρ : ℤ)
  (K : ℕ)
  (hK : ∀ N : ℕ, (orbitSetNormalized G ρ N).card ≤ K) :
  orbitEntropy G ρ = 0
```

If `limsup` is too heavy, prove the simpler asymptotic estimate
```lean
theorem orbit_entropy_upper_bound_zero_of_bounded_normalized_orbit
  ...
  : ∃ C : ℝ, ∀ N ≥ 1,
      Real.log ((orbitSetNormalized G ρ N).card) / N ≤ C / N
```
and derive the entropy conclusion later.

This is where the connection to `tropical_entropy_search_bound` should become explicit: the existing theorem already says tropicalized complexity measures admit entropy-type bounds. You are extending this from probability/search objects to semigroup orbits of tropical linear operators.

## Proof strategy architecture

## Strategy A: Finite-state pigeonhole after spectral normalization
Most promising for immediate Lean success.

1. Define normalized powers entrywise:
   \[
   \widetilde G^{(k)}_{ij} = (G^{\otimes k})_{ij} - k\rho.
   \]
2. Use entrywise bounds to show every normalized matrix belongs to a finite box:
   each entry lies in `[-C, C]`.
3. Since an `n × n` integer matrix with entries in `[-C,C]` has at most
   \[
   (2C+1)^{n^2}
   \]
   possibilities, conclude
   \[
   \#\{\widetilde G^{(1)},\dots,\widetilde G^{(N)}\}\le (2C+1)^{n^2}.
   \]
4. Deduce eventual repetition and zero orbit entropy.

Why this is strongest: it is purely combinatorial, needs minimal algebraic infrastructure, and directly produces a quantitative theorem.

## Strategy B: Tropical eigenvector sandwich
Best for conceptual depth and future expansion.

1. Assume or derive a tropical eigenvector `v` with eigenvalue `ρ`.
2. Prove by induction on `k` that
   \[
   (G^{\otimes k})_{ij} \le k\rho + v_i - v_j.
   \]
   The induction should use tropical matrix multiplication and the eigenvector identity.
3. If a dual subeigenvector or critical graph condition is available, derive a matching lower bound.
4. Feed the resulting uniform bounds into Strategy A.

Why this matters: it reveals the mechanism behind bounded orbit complexity. The residual dynamics is a cocycle controlled by the eigenvector gauge.
