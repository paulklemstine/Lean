### 3. Disjoint image theorem on primitive triples

The cleanest route is likely through the Berggren tree on primitive Pythagorean triples. Define the normalized positive primitive triples, for example:

```lean
def IsNormalizedTriple (t : ℤ × ℤ × ℤ) : Prop := ...
def IsPrimitivePythTriple (t : ℤ × ℤ × ℤ) : Prop := ...
def GoodTriple (t : ℤ × ℤ × ℤ) : Prop :=
  IsNormalizedTriple t ∧ IsPrimitivePythTriple t
```

Then prove that each generator preserves `GoodTriple`:

```lean
theorem A_preserves_goodTriple : ∀ {t}, GoodTriple t → GoodTriple (A • t)
theorem B_preserves_goodTriple : ∀ {t}, GoodTriple t → GoodTriple (B • t)
theorem C_preserves_goodTriple : ∀ {t}, GoodTriple t → GoodTriple (C • t)
```

The key nontrivial theorem is pairwise disjointness of images:

```lean
theorem berggren_images_disjoint :
  Set.Pairwise (fun s₁ s₂ : Set (ℤ × ℤ × ℤ) =>
    s₁ ≠ s₂ →
    Disjoint s₁ s₂)
  ({A '' {t | GoodTriple t}}, {B '' {t | GoodTriple t}}, {C '' {t | GoodTriple t}})
```

In a more Lean-friendly explicit form, prove the three statements:

```lean
theorem A_image_ne_B_image :
  Disjoint (A '' {t | GoodTriple t}) (B '' {t | GoodTriple t})

theorem A_image_ne_C_image :
  Disjoint (A '' {t | GoodTriple t}) (C '' {t | GoodTriple t})

theorem B_image_ne_C_image :
  Disjoint (B '' {t | GoodTriple t}) (C '' {t | GoodTriple t})
```

or even better, prove a classifier theorem giving a unique parent generator from inequalities on the output triple:

```lean
theorem berggren_generator_classifier
    {t : ℤ × ℤ × ℤ} (ht : GoodTriple t) (hroot : t ≠ rootTriple) :
    ((∃! p, GoodTriple p ∧ A • p = t) ∨
     (∃! p, GoodTriple p ∧ B • p = t) ∨
     (∃! p, GoodTriple p ∧ C • p = t))
```

This is the real combinatorial engine behind unique normal forms.

### Recommended proof strategy

#### Strategy A: unique parenthood in the Berggren tree
This is likely the most robust formal route.

1. **Formalize the state space of normalized primitive triples.**  
   Use the existing Berggren/Pythagorean results to define a predicate `GoodTriple t` encapsulating:
   - positivity,
   - Pythagorean relation `a^2 + b^2 = c^2`,
   - primitiveness `gcd a b = 1` or the stronger triplewise primitive condition,
   - normalization such as `0 < a ∧ a < b ∧ b < c` and parity convention.  
   You want enough normalization so that the Berggren tree is rooted and nonredundant.

2. **Prove each generator lands in a distinct region cut out by linear inequalities.**  
   The key lemma should be that if
   ```lean
   t = A • p
   ```
   with `GoodTriple p`, then `t` satisfies one characteristic system of inequalities, while `B • p` and `C • p` satisfy different incompatible systems.  
   Concretely, look for linear comparisons among coordinates such as:
   - sign of `2*a - b`,
   - ordering of `2*a`, `b`, `c - 2*a`,
   - or inequalities on Euclidean parameters / slopes if the action is transported there.  
   The exact separator is less important than proving three pairwise incompatible image conditions.

3. **Construct an explicit inverse branch on each image region.**  
   Since the Berggren matrices are invertible over `ℤ`, define candidate parents by applying `A⁻¹`, `B⁻¹`, `C⁻¹` as integer matrices and prove:
   - on the correct image region, the inverse branch returns a `GoodTriple`,
   - on the other regions it violates positivity/normalization.  
   This gives a partial inverse:
   ```lean
   parentGen? : Triple → Option (BergGen × Triple)
   ```
   together with correctness and uniqueness.

4. **Prove every non-root good triple has a unique parent.**  
   This is the decisive theorem. Then proceed by well-founded recursion on the hypotenuse `c : ℤ` or its natural-number coercion. Show each parent strictly decreases `c`, so recursive decoding terminates:
   ```lean
   parent_c_lt_child : parentGen? t = some (g,p) → p.3 < t.3
   ```
   Convert to naturals if needed to avoid order issues on `ℤ`.

5. **Deduce unique word decomposition by induction on `c`.**  
   For existence, recursively peel off the unique parent until reaching the root.  
   For uniqueness, if two words evaluate to the same triple, compare the first parent step using parent uniqueness, strip the common leading generator, and iterate.  
   Then lift from triples to matrices by evaluating both words on the root triple.

#### Strategy B: ping-pong on slopes / projective line
If the current library already contains the Lorentz form or Möbius-style action facts, a cleaner semigroup proof may be possible.

1. Transport the Berggren action to an action on a slope parameter, e.g. positive rationals or a projective interval.
2. Compute the image intervals of the three generators explicitly:
   ```lean
   A • I ⊆ IA,   B • I ⊆ IB,   C • I ⊆ IC
   ```
   with `IA`, `IB`, `IC` pairwise disjoint.
3. Apply a semigroup ping-pong argument: if two positive words differ in the first letter, their actions send the base interval/basepoint into disjoint sets.
4. Conclude injectivity of `evalWord` as transformations, then as matrices.

This route is elegant but depends on how much interval/rational-action infrastructure is already available. The tree/parent approach is probably easier to make airtight in Lean.

### Why this matters

This theorem is the missing algebraic backbone for the Berggren/SPB cryptographic program. A mere action-faithfulness result says distinct semigroup elements act differently somewhere; freeness and unique normal forms say much more:

- every public matrix/triple generated by the system carries a canonical decomposition into Berggren generators;
- left and right cancellation become available automatically;
- word length and generator sequence become well-defined invariants, enabling precise discrete-log-style formulations;
- reductions can target recovery of the unique Berggren normal form rather than an arbitrary preimage;
- the semigroup ceases to be a heuristic combinatorial object and becomes a rigorously controlled free monoid embedded in `SL₂(ℤ)` or the corresponding matrix group acting on triples.

This would substantially strengthen the formal foundations of SPB Diffie–Hellman: it upgrades “generation by Berggren moves” into a canonical encoding theorem, exactly the structure needed for hardness reductions and for later analysis of collision resistance, key recovery, and quantum search over normal forms.

# Tropical Berggren Rank Factorization: Analysis and Counterexamples

## Summary

This file formalizes the Berggren tree infrastructure and provides a rigorous analysis
of the conjecture that the tropical rank of p-adic valuation matrices derived from
Berggren tree paths equals the number of distinct prime factors of the hypotenuse.

## Conclusion: The Conjecture Is False

The central claim — that `tropicalRank(T_p(N)) = ω(N)` — is **false**, for multiple
independent reasons:

### 1. Dimensional Obstruction (Fatal)
The "path matrix" B(N) has dimensions (path_length × 3), since each Pythagorean triple
is a vector in ℤ³. Therefore its tropical rank is at most min(path_length, 3) ≤ 3.
But ω(N) can be arbitrarily large, so the equality fails for any N with ω(N) > 3.

### 2. Concrete Counterexample: N = 169 = 13²
- Path: (3,4,5) → (21,20,29) → (119,120,169), using B₂ twice.
- For p = 13: T₁₃(169) = [[0,0,0],[0,0,0],[0,0,2]]
- Tropical rank of this matrix is ≥ 2 (proof below: it cannot be written as an
  outer sum a[i] + b[j], since all entries are 0 except the (2,2) entry which is 2).
- But ω(169) = ω(13²) = 1.
- So tropical rank ≥ 2 > 1 = ω(N). **Equality fails.**

### 3. Concrete Counterexample: N = 25 = 5²
- Path: (3,4,5) → (5,12,13) → (7,24,25), using B₁ twice.
- For p = 5: T₅(25) = [[0,0,1],[1,0,0],[0,0,2]]
- Tropical rank ≥ 2 (the Monge condition fails: T[0,0]+T[1,1]=0 ≠ 1=T[0,1]+T[1,0]),
  so the matrix cannot be tropically rank 1.
- But ω(25) = 1. **Equality fails again.**

### 4. Domain Restriction (Fundamental)
Not every N > 1 appears as a hypotenuse of a primitive Pythagorean triple.
For a primitive triple (a,b,c), every prime factor of c must be ≡ 1 (mod 4).
So N = 6, 10, 14, 15, 21, ... have no Berggren path at all, making B(N) undefined.

### 5. Non-Uniqueness
When N is the hypotenuse of multiple primitive triples (e.g., N = 65 = 5 × 13
is the hypotenuse of both (33,56,65) and (63,16,65)), the "path matrix" B(N)
is ambiguous without choosing a specific triple.

### 6. Newton Polygon Claim Is Ill-Formed
The tropical determinant of T_p(N) is a single element of ℝ ∪ {∞} (a scalar in the
min-plus semiring), not a polynomial. A single scalar does not have a Newton polygon.
The claim that "Newton polygon breakpoints occur at the exponents eᵢ" is therefore
mathematically meaningless as stated.

- B₁ and B₃ have determinant 1, B₂ has determinant -1
- All three preserve the Pythagorean property: if a²+b²=c², then the transformed
  triple also satisfies this equation
- The Berggren tree path computation is well-defined for any tree path
- Verified counterexamples with machine-checked p-adic valuations
