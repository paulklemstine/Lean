## New Definitions You Should Introduce

At least one genuinely new concept is mandatory. I recommend introducing all of the following.

### 1. Tagged-card increment observable
For a permutation walk \(X_t \in S_n\) and fixed card \(j\), define the card position
\[
\mathrm{pos}_j(X_t) \in \mathbb Z/n\mathbb Z.
\]
Then define the one-step increment
\[
\Delta_j(X_t,X_{t+1}) := \mathrm{liftSigned}\big(\mathrm{pos}_j(X_{t+1}) - \mathrm{pos}_j(X_t)\big),
\]
where `liftSigned` chooses the canonical representative in `{-1,0,1}` when the step is local.

This is the first bridge to current observables.

### 2. Drift-corrected tagged current
Define
\[
J_j(t) := \sum_{s < t} \big(\Delta_j(X_s,X_{s+1}) - \mathbf E[\Delta_j]\big).
\]
This should be the finite-\(n\) analog of a centered current process.

### 3. Exclusion-compatible local environment
Define a predicate/structure expressing that, relative to card \(j\), the local neighborhood configuration evolves by nearest-neighbor exchange plus deterministic cyclic advection. This can be a finite combinatorial abstraction rather than a full IPS.

For example, a structure like:

```lean
structure TaggedCardEnvironment (n : ℕ) where
  card : Fin n
  pos : Equiv.Perm (Fin n) → Fin n
  localIncrement : Equiv.Perm (Fin n) → Equiv.Perm (Fin n) → ℤ
  drift : ℚ
  admissible : Prop
```

or a more specialized record tailored to your actual catalog APIs.

### 4. Optional but visionary: finite-ring TASEP surrogate
Define a **combinatorial surrogate process** on `Fin n` whose transitions match the tagged-card marginal drift and local jump asymmetry. You do not need full convergence to TASEP to prove something important; it is enough to define a process whose current/variance identities mirror TASEP heuristics.

### Theorem 1: Drift decomposition for a tagged card

**Mathematical statement.**  
Let \(n \ge 2\). In the adjacent-transposition-plus-cycle walk on `Equiv.Perm (Fin n)`, the expected one-step displacement of a fixed card \(j\) decomposes as
\[
\mathbf E[\Delta_j] = \frac{1}{n} + \varepsilon_{n,j},
\]
where the `1/n` term is the deterministic contribution of the long cycle and \(\varepsilon_{n,j}\) is the correction coming from local adjacent swaps. Moreover, the correction is explicitly expressible through the probability that card \(j\) lies on an edge selected for adjacent transposition.

A stronger finite combinatorial version you should aim to formalize is:
\[
\mathbf E[\Delta_j \mid X_t = \sigma]
= \frac{1}{n} + \frac{1}{n-1}\Big(\mathbf 1_{\text{swap moves }j\text{ right}} - \mathbf 1_{\text{swap moves }j\text{ left}}\Big),
\]
or the exact analog dictated by the walk definition in the catalog.

**Lean 4 target signature sketch**
```lean
theorem taggedCard_expected_increment_decomposition
    {n : ℕ} (hn : 2 ≤ n) (j : Fin n) :
    ∃ driftLocal driftCycle : ℚ,
      taggedCardExpectedIncrement n j = driftLocal + driftCycle ∧
      driftCycle = (1 : ℚ) / n := by
```

If expectation is already encoded over `ℝ`, use `ℝ` instead of `ℚ`. If the exact expected increment depends on a state `σ`, prove the conditional version first and derive the averaged version second.

**Why this matters.**  
This is the first exact finite-\(n\) current identity. Without it, all TASEP/KPZ analogies are poetry. With it, the walk acquires a bona fide hydrodynamic observable.

### Theorem 2: Martingale or compensated-current structure

**Mathematical statement.**  
Let
\[
M_j(t) := \sum_{s < t}\big(\Delta_j(X_s,X_{s+1}) - \mathbf E[\Delta_j \mid X_s]\big).
\]
Then \(M_j(t)\) is a martingale with respect to the natural filtration. In a finite deterministic Lean setting, if a full probability-space martingale formalization is too heavy, prove the exact finite-step telescoping identity that implies the compensated current has zero conditional drift.

A workable theorem is:
\[
\mathbf E[M_j(t+1)-M_j(t)\mid X_t] = 0.
\]

**Lean 4 target signature sketch**
```lean
theorem taggedCard_compensated_increment_zero_drift
    {n t : ℕ} (hn : 2 ≤ n) (j : Fin n) :
    conditionalExpectedTaggedIncrement n j t
      - taggedCardConditionalDrift n j t = 0 := by
```

Or, if filtration/martingale notions are available in Mathlib and practical:

```lean
theorem taggedCard_current_is_martingale
    {n : ℕ} (hn : 2 ≤ n) (j : Fin n) :
    IsMartingale (taggedCardFiltration n) (taggedCardCurrentProcess n j) := by
```

**Why this matters.**  
TASEP current fluctuations are organized around martingale/corrector decompositions. This theorem is the structural hinge between permutation dynamics and nonequilibrium transport.

### Theorem 4: Cross-domain theorem via order structure / Young diagram / inversion current

You are required to include at least one theorem that connects this domain to another domain. The strongest available bridge is to **algebraic combinatorics**.

Define an inversion or descent observable relative to the tagged card, e.g.
\[
I_j(\sigma) := \#\{k \neq j : \sigma^{-1}(k) < \sigma^{-1}(j)\},
\]
or a local inversion current. Prove that one-step evolution changes this quantity by a controlled amount determined by the tagged-card increment. This links permutation transport to growth processes and, ultimately, RSK/last-passage heuristics.

**Mathematical statement.**  
For the hybrid walk step \(\sigma \mapsto \sigma'\),
\[
|I_j(\sigma') - I_j(\sigma)| \le 1,
\]
and, more sharply, under adjacent transposition this change equals the signed local crossing number of card \(j\).

**Lean 4 target signature sketch**
```lean
theorem taggedInversion_change_controlled
    {n : ℕ} (hn : 2 ≤ n) (j : Fin n) (σ τ : Equiv.Perm (Fin n)) :
    IsHybridStep n σ τ →
    |taggedInversionCount j τ - taggedInversionCount j σ| ≤ 1 := by
```

Possible stronger bridge:
```lean
theorem taggedIncrement_eq_inversionCurrent
    {n : ℕ} (hn : 2 ≤ n) (j : Fin n) (σ τ : Equiv.Perm (Fin n)) :
    IsAdjacentSwapStep n σ τ →
    taggedSignedIncrement j σ τ =
      taggedInversionCount j τ - taggedInversionCount j σ := by
```

**Why this matters.**  
This is the algebraic-combinatorial portal. It turns displacement into an order statistic and invites RSK, growth models, and random-matrix asymptotics into the story.

### Strategy A — Direct finite-state current calculus
**Most promising for Lean.**

1. Express tagged-card displacement explicitly from the hybrid step definition in the catalog.

**Why promising:**

### Strategy B — Observable contraction + Poisson equation viewpoint
1. Use catalog contraction theorems for observables from `AdjCycleMixing.lean`.
2. Define the tagged current as an additive functional of the Markov chain.
3. Solve or partially solve the discrete Poisson equation
   \[
   (I-P)f = g - \pi(g)
   \]
   for the tagged observable \(g\).
4. Deduce compensated-current bounds and variance growth estimates.

**Why promising:**  
This gives a principled route to martingale decomposition and is conceptually closest to nonequilibrium statistical mechanics.

**Why harder:**  
Requires enough Markov operator infrastructure in Lean to manipulate additive functionals cleanly.

---

### Strategy C — Order-statistic / inversion-process reduction
1. Replace raw position by tagged inversion count or local crossing count.
2. Show adjacent swaps alter this count by exactly `±1` or `0`.
3. Show the long cycle contributes a deterministic transport term.
4. Translate displacement statements into inversion-current statements, then into combinatorial growth bounds.

**Why promising:**  
This is the best route for the cross-domain theorem and for eventual RSK/KPZ connections.

**Why revolutionary:**  
If this works, you are not merely studying a shuffle; you are constructing a discrete growth model hidden inside a Cayley walk.
