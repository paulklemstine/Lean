## Precise Theorem Targets

You must prove at least **3 deep theorems**. The following are the target statements. If some continuous formulation is too hard in Lean immediately, prove the discrete finite-type version first, but preserve the exact conceptual architecture.

### Theorem 1: Interleaving distance is a pseudometric
This is the foundational theorem that upgrades the notion from “relation” to “geometry.”

**Mathematical statement.**
For tropical persistence modules of finite type, the tropical interleaving distance is nonnegative, symmetric, and satisfies the triangle inequality.

A Lean 4 target signature could be:

```lean
theorem tropicalInterleavingDist_triangle
    (M N P : TropicalPersistenceModule) :
    tropicalInterleavingDist M P ≤
      tropicalInterleavingDist M N + tropicalInterleavingDist N P := ...

theorem tropicalInterleavingDist_symm
    (M N : TropicalPersistenceModule) :
    tropicalInterleavingDist M N = tropicalInterleavingDist N M := ...

theorem tropicalInterleavingDist_self
    (M : TropicalPersistenceModule) :
    tropicalInterleavingDist M M = 0 := ...
```

If your distance lands in `ℝ≥0∞`, adapt the codomain accordingly.

**Why this is nontrivial.**
The triangle inequality requires composing interleavings and verifying coherence after shift-addition. This is where the category structure matters. Do not trivialize this into a pointwise metric.

### Theorem 2: Barcode domination / algebraic stability
This is the first major bridge from the catalog to the new theory.

**Mathematical statement.**
For every pair of finite-type tropical persistence modules `M, N`, the tropical barcode distance is bounded above by the tropical interleaving distance.

```lean
theorem tropicalBarcodeDist_le_interleavingDist
    (M N : TropicalPersistenceModule) :
    tropicalBarcodeDist (barcodeOf M) (barcodeOf N) ≤ tropicalInterleavingDist M N := ...
```

If `barcodeOf` is not yet formalized, define a finite event-profile/barcode extraction from your modules and prove the inequality for that extraction. You may need a theorem in the style:

```lean
theorem tropicalEventProfile_stable_of_interleaving
    {δ : ℤ} (h : IsDeltaInterleaved δ M N) :

```

**Why this is a breakthrough.**
This theorem says the categorical metric controls the combinatorial invariant. It is the tropical analogue of algebraic stability in classical persistence.

### Theorem 3: Bi-Lipschitz equivalence on finite type
This is where the theory becomes complete rather than one-sided.

**Mathematical statement.**
There exist constants `C₁, C₂ > 0` such that for finite-type modules,
\[
C₁ \cdot d_I(M,N) \le d_B(M,N) \le C₂ \cdot d_I(M,N).
\]
In the most optimistic version, `C₁ = 1` and `C₂ = 1` fail, but finite-type modules admit explicit constants depending only on local variation bounds or rank bounds.

A Lean target could be:

```lean
theorem interleaving_barcode_biLipschitz
    (K : ℕ)
    (M N : TropicalPersistenceModule)
    (hM : BoundedLocalVariation K M)
    (hN : BoundedLocalVariation K N)
    (hMf : FiniteType M)
    (hNf : FiniteType N) :
    ∃ C : ℕ, 0 < C ∧
      tropicalInterleavingDist M N ≤ C * tropicalBarcodeDist (barcodeOf M) (barcodeOf N) ∧
      tropicalBarcodeDist (barcodeOf M) (barcodeOf N) ≤ C * tropicalInterleavingDist M N := ...
```

You may prefer `ℝ`-valued constants; that is fine.

**Why this is nontrivial.**
This is exactly where tropical behavior can differ from classical persistence. The theorem should expose the role of bounded local variation. If equality fails, prove explicit quantitative equivalence.

### Theorem 4: Strict gap example
You are explicitly asked not just to prove comparison, but to show the two distances are **not equal** in general.

**Mathematical statement.**
There exist finite-type tropical persistence modules `M, N` such that
\[
d_B(M,N) < d_I(M,N).
\]

Lean target:

```lean
theorem exists_strict_gap_barcode_interleaving :
  ∃ M N : TropicalPersistenceModule,
    FiniteType M ∧ FiniteType N ∧
    tropicalBarcodeDist (barcodeOf M) (barcodeOf N) <
    tropicalInterleavingDist M N := ...
```

If strict `<` is awkward in an `ℕ∞` codomain, formulate via explicit numerals:
```lean
∃ M N, tropicalBarcodeDist ... = 1 ∧ tropicalInterleavingDist M N = 2
```

**Why this matters.**
This prevents the theory from collapsing into a tautological rephrasing of barcode distance. It identifies genuinely tropical obstructions invisible to the barcode.

### Theorem 5: Universal property for stable tropical observables
This is the field-opening theorem.

**Mathematical statement.**
If `F` is any tropical observable from finite-type tropical persistence modules to a metric space that is stable under δ-interleavings, then `F` is 1-Lipschitz (or `C`-Lipschitz) with respect to tropical interleaving distance.

A Lean-friendly formulation:

```lean
structure StableTropicalObservable (α : Type*) [PseudoMetricSpace α] where
  toFun : TropicalPersistenceModule → α
  stable :
    ∀ {M N : TropicalPersistenceModule} {δ : ℕ},
      IsDeltaInterleaved δ M N →
      dist (toFun M) (toFun N) ≤ δ

theorem interleaving_universal
    {α : Type*} [PseudoMetricSpace α]
    (F : StableTropicalObservable α)
    (M N : TropicalPersistenceModule) :
    dist (F.toFun M) (F.toFun N) ≤ tropicalInterleavingDist M N := ...
```

**Why this is revolutionary.**
This is the tropical Bubenik–Scott principle: interleaving distance is not one stable metric among many, but the *initial* or *universal* one controlling all stable observables. This is the theorem that would make experts say: “Tropical persistence is now a complete abstract theory.”

## Proof Strategy Architecture

You must not give one proof idea. You must pursue at least 2–3 serious routes and decide which is best.

### Strategy A: Concrete discrete category + explicit coherence
1. Define tropical persistence modules over `ℤ` with explicit shift and interleaving data.
2. Prove composition of interleavings by constructing maps at shift `δ + ε`.
3. Derive pseudometric properties and stability of event profiles/barcodes by induction on support / finite-type decomposition.

**Why promising:** This is the most Lean-robust path. It minimizes category-theory overhead while preserving the core mathematics.

### Strategy B: Functor-category formulation
1. Formalize modules as functors from the thin category `(ℤ, ≤)` into a category of tropical semimodules or ordered additive structures.
2. Define shift as precomposition by translation and interleavings as natural transformations.
3. Use abstract naturality squares to prove triangle inequality and universal property cleanly.

**Why promising:** This gives the most conceptually satisfying theorem and aligns with Bubenik–Scott style universality.  
**Risk:** too much categorical infrastructure unless Mathlib support is already sufficient.

### Strategy C: Barcode/event-profile first, then lift to modules
1. Start from catalog theorems on tropical event profiles and barcode distance.
2. Define a module realization functor from event profiles.
3. Show interleavings induce profile inequalities and then reconstruct finite-type control.

**Why promising:** Directly leverages the catalog.  
**Risk:** reconstruction may be delicate; could accidentally bake in too much combinatorics and weaken the universal property.

**Recommended order:** A → C → B.  
First establish a concrete theorem-rich discrete theory. Then import the catalog stability machinery. Finally, if time permits, repackage the strongest results in abstract categorical language.
