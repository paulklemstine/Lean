## Assignment: Bourgain–Gamburd machine in the orthogonal/integral regime

Mode: **prove**

You are not being asked for an incremental adaptation of an expander argument. You are being asked to architect the first formal Bourgain–Gamburd-style machine in a setting where the ambient algebraic group is orthogonal, the arithmetic origin is integral, and the formal endpoint is a reusable Lean framework for spectral expansion via product growth + escape from algebraic constraints.

The decisive breakthrough is to isolate a **Lean-formalizable orthogonal expansion criterion** that does not require the full strength of finite simple group classification in the statement, but still captures the Bourgain–Gamburd logic:

1. non-concentration in proper algebraic substructures,
2. product growth / flattening,
3. spectral gap for the averaging operator.

The right target is not “the full theorem for all `SO_n(F_p)` immediately.” The right target is a theorem schema that can already certify spectral gap from combinatorial hypotheses in finite orthogonal quotients, and then a concrete instantiation for low rank.

## Core theorem target

Formalize a finite-group Bourgain–Gamburd machine specialized to orthogonal matrix groups over `ZMod p`, then instantiate it for a concrete orthogonal subgroup generated by symmetric reflections or signed permutation matrices preserving a quadratic form.

### Precise mathematical theorem

Let `p` be an odd prime, let `n ≥ 3`, let `Q : (Fin n → ZMod p) →ₗ[ZMod p] (Fin n → ZMod p) →ₗ[ZMod p] ZMod p` be a nondegenerate symmetric bilinear/quadratic form, and let `G ≤ Matrix (Fin n) (Fin n) (ZMod p)` be the finite subgroup of matrices preserving `Q`. Let `S ⊆ G` be finite, symmetric, and generating. Suppose:

- (**escape**) for every proper “structured” subgroup `H < G` from a designated family `𝓗` (e.g. stabilizers of isotropic lines, coordinate subspaces, or more generally proper subgroups detected by the orthogonal geometry), the random walk measure `μ_S^{(k)}` assigns mass at most `|G|^{-κ}` to every left coset `gH` once `k` is in a specified range;
- (**product growth**) every finite subset `A ⊆ G` with `|A| ≤ |G|^(1-ε)` and not highly concentrated in any `gH` satisfies `|A*A*A| ≥ |A|^(1+δ)`.

Then the normalized averaging operator
\[
T_S f(x) = \frac1{|S|}\sum_{s\in S} f(sx)
\]
on functions `G → ℝ` has second eigenvalue bounded by `1 - c`, for some `c = c(ε,δ,κ) > 0`. Equivalently, the Cayley graph `Cay(G,S)` is a two-sided expander.

This is the theorem that matters. It is the formal skeleton of the Bourgain–Gamburd machine in a new family.

This is not just another theorem about a finite group. It is a framework theorem: once formalized, it can be re-instantiated for `SL₂`, `SO_n`, unitary groups, arithmetic monodromy groups, and random walks on quotient graphs. It creates a machine.

## Recommended proof architecture

## Strategy A: Abstract finite-group flattening machine, then orthogonal specialization
**Most promising.**

### Step 1: Define the analytic combinatorics layer
Create definitions for:

- finite probability measures `μ : G → ℝ` with finite support,
- convolution `μ ⋆ ν`,
- `L²` norm and `L∞` norm on finite groups,
- concentration on cosets/subgroups,
- averaging operator associated to a finite symmetric generating set,
- spectral gap as `1 - λ₂` or an equivalent Rayleigh quotient formulation.

Prove basic lemmas:
- convolution preserves total mass,
- symmetry gives self-adjointness of averaging operator,
- `L²` flattening implies decay of nontrivial Fourier/Rayleigh modes.

### Step 2: Formalize a Bourgain–Gamburd-style flattening implication
Prove a theorem of the shape:

```lean
theorem flattening_or_structure
  {G : Type*} [Fintype G] [Group G] [DecidableEq G]
  (μ : G → ℝ) :
  probabilityMeasure μ →
  symmetricMeasure μ →
  ¬ concentratedOnStructuredSubgroups μ →
  largeMultiplicativeEnergy μ →
  ∃ A : Finset G, approximateSubgroupWitness μ A
```

Then combine with the product theorem hypothesis to derive a contradiction unless `μ ⋆ μ` has smaller `L²` norm.

### Step 3: Iterate flattening to spectral gap
Show repeated convolution drives the walk toward uniformity at an exponential rate, yielding a positive spectral gap. Then instantiate for orthogonal groups by supplying:
- a structured subgroup family,
- escape hypothesis,
- product theorem hypothesis.

**Why this is best:** it separates the difficult group-specific input from the general machine. Once done, future cycles can swap in different groups.

**Ambitious and conceptually beautiful.**

**Why this is powerful:** escape from subvarieties is the conceptual heart of Bourgain–Gamburd. A formal version in orthogonal geometry would be a major conceptual artifact even before the final spectral theorem.

## Concrete definitions you likely need

You should introduce explicit Lean definitions, probably in a new file family like:

- `GroupTheory/Expanders/Convolution.lean`
- `GroupTheory/Expanders/SpectralGap.lean`
- `GroupTheory/Orthogonal/FiniteOrthogonalGroup.lean`
- `GroupTheory/Expanders/BourgainGamburdOrthogonal.lean`

Candidate definitions:

```lean
def IsProbabilityMeasure {G : Type*} [Fintype G] (μ : G → ℝ) : Prop :=
  (∀ g, 0 ≤ μ g) ∧ (∑ g, μ g = 1)

def convolution {G : Type*} [Fintype G] [Group G] (μ ν : G → ℝ) : G → ℝ :=
  fun x => ∑ g, μ g * ν (g⁻¹ * x)

def uniformMeasure {G : Type*} [Fintype G] : G → ℝ :=
  fun _ => (Fintype.card G : ℝ)⁻¹

def averagingOperator
  {G : Type*} [Fintype G] [Group G]
  (S : Finset G) (f : G → ℝ) : G → ℝ :=
  fun x => (S.card : ℝ)⁻¹ * ∑ s in S, f (s * x)
```

For spectral gap, if full finite-dimensional spectral theory is cumbersome, use a Rayleigh quotient formulation:

```lean
def spectralGapLowerBound
  {G : Type*} [Fintype G] [Group G]
  (S : Finset G) (gap : ℝ) : Prop :=
  ∀ f : G → ℝ,
    meanZero f →
    dirichletForm S f ≥ gap * l2normSq f
```

This is often easier to prove and still mathematically decisive.

## Tactical advice for Lean

- For orthogonal groups, concrete matrices preserving a Gram matrix are often easier than abstract quadratic form automorphisms.
- If eigenvalue formalization is too costly, prove a **Dirichlet form / contraction theorem** and define spectral gap via that inequality.
- Separate reusable algebraic lemmas from the orthogonal application.
