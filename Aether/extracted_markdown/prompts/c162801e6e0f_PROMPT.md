## Precise theorem statements

You need at least 3 substantial theorems. Here is a coherent theorem suite.

### Theorem 1: Finite-type detection theorem
This is the central breakthrough statement in the finite model.

**Mathematical statement.**
Let `D` be a divergence profile whose primitive superficially divergent graph types generate a loop-filtered divergence complex `C(D)`. Assume:
1. every primitive superficially divergent type gives rise to a nonbounding 1-cycle born at its loop order,
2. every essential 1-cycle is generated by a primitive superficially divergent type,
3. the filtration is monotone and exhaustive on the bounded truncation.

Then the number of persistent essential 1-bars equals the number of primitive superficially divergent graph types.

**Lean-style signature.**
```lean
theorem persistent_bar_count_eq_primitive_divergence_count
  (D : DivergenceProfile)
  (C : LoopFilteredComplex D.GraphType)
  (hgen : GeneratesFromProfile D C)
  (hbirth : ∀ g, g ∈ primitiveDivergentFinset D →
      ∃ z, BornFromPrimitive C g z ∧ EssentialCycle C z)
  (hcomplete : ∀ z, EssentialCycle C z →
      ∃ g, g ∈ primitiveDivergentFinset D ∧ BornFromPrimitive C g z)
  : persistentOneBarCount C = primitiveDivergenceCount D
```

This theorem is the formal nucleus of the program.

---

### Theorem 2: Renormalizable iff bounded persistent count
This theorem translates physics into topology.

**Mathematical statement.**
Suppose `Dₙ` is the loop-truncation at loop order `n` of a scalar theory profile, and `Cₙ` its associated filtered divergence complex. If Theorem 1 holds uniformly in `n`, then:
- if the theory is renormalizable, there exists `B` such that for all `n`, `persistentOneBarCount Cₙ ≤ B`;
- if the theory has infinitely many superficially divergent primitive types appearing with increasing loop order, then for every `B` there exists `n` such that `persistentOneBarCount Cₙ > B`.

**Lean-style signature.**
```lean
theorem renormalizable_iff_eventually_bounded_persistent_count
  (D : ℕ → DivergenceProfile)
  (C : ∀ n, LoopFilteredComplex (D n).GraphType)
  (hcompat : ProfileSystemCompatible D C)
  (hcount :
    ∀ n, persistentOneBarCount (C n) = primitiveDivergenceCount (D n))
  : TheoryRenormalizable D ↔
      ∃ B : ℕ, ∀ n : ℕ, persistentOneBarCount (C n) ≤ B
```

This is the theorem that turns the barcode heuristic into a criterion.

This is the cross-domain bridge to algebraic topology and combinatorics.

**Mathematical statement.**
For a finite divergence complex `C` satisfying acyclicity above degree 1 in the bounded model, the persistent 1-bar count equals

|E_{\mathrm{ess}}| - |V| + \beta_0,

## Proof strategy architecture

You asked for 2–3 proof strategy steps. Here are three serious approaches.

### Strategy A: Finite combinatorial homology via cycle-space rank
**Most promising for Lean.**

1. Model the 1-skeleton of the filtered bar complex as a finite graph-like object.
2. Identify essential 1-cycles with a basis of the cycle space modulo boundaries generated by insertion relations.
3. Use finitary rank-counting arguments to show equality between persistent 1-bar count and primitive divergence count.

Why this is promising:
- avoids heavy chain-complex infrastructure if necessary;
- Lean handles `Finset`, counting, induction on loop truncation, and graph combinatorics well;
- gives algorithmic content directly for `demo.py`.

Key proof moves:
- induction on loop order;
- `rcases` on whether a new primitive divergence appears at level `n+1`;
- `calc` chains for count identities;
- `by_contra` to show essential cycles cannot disappear under the completeness hypothesis.

---

### Strategy B: Genuine filtered chain complexes and persistent homology stability
**More ambitious, more beautiful, but heavier.**

1. Construct a filtered chain complex from the bounded bar complex of the toy Connes–Kreimer structure.
2. Define birth/death of 1-homology classes via inclusion maps between filtration levels.
3. Prove that primitive divergent generators correspond exactly to persistent classes by showing they survive all later differentials.

Why this is revolutionary:
- closer to the true conjecture;
- opens the door to importing stability results from topological data analysis into renormalization.

Why it is harder:
- Mathlib support for full persistent homology is partial and may require substantial infrastructure;
- best used if the catalog context already contains chain complex and homology machinery you can leverage.

---

### Strategy C: Möbius inversion / incidence algebra reformulation
**Cross-pollinating and conceptually striking.**

1. Regard superficially divergent subgraph nesting as a finite poset.
2. Build the order complex or nerve of this poset and study its first homology.
3. Show that primitive divergent types correspond to indecomposable intervals or atoms whose incidence relations create essential 1-cycles.

Why this matters:
- links renormalization combinatorics to poset topology and incidence Hopf algebras;
- may produce stronger statements than the graph-complex model;
- naturally connects to combinatorial species and Hall-type structures.

This is especially strong if the catalog already contains results on order complexes, Möbius functions, or simplicial complexes.

**Recommendation:** Start with Strategy A, then, if the machinery cooperates, reinterpret the result through Strategy C in `RESEARCH_PAPER.md` as the conceptual extension.

## Suggested proof skeletons

### For `persistent_bar_count_eq_primitive_divergence_count`
- Define a map from primitive divergent types to essential cycles.
- Prove injectivity:
  distinct primitive types produce non-homologous cycles; use `by_contra` and the completeness/nonboundary hypotheses.
- Prove surjectivity:
  every essential cycle comes from some primitive divergent type by `hcomplete`.
- Convert bijection to equality of counts via finite set cardinality.

### For `renormalizable_iff_eventually_bounded_persistent_count`
- Forward direction:
  choose a finite witness set of primitive divergent types;
  use Theorem 1 at each truncation;
  show counts are uniformly bounded by the cardinality of the witness set.
- Reverse direction:
  argue by contrapositive;
  if not renormalizable, there are infinitely many new primitive divergent types;
  by Theorem 1 the counts exceed any fixed bound at some truncation.

### For `nonrenormalizable_implies_unbounded_persistent_growth`
- Fix `B`.
- Use `hinf` to obtain `B+1` distinct primitive divergent types appearing by some truncation `n`.
- Apply the count equality to deduce
  `B + 1 ≤ persistentOneBarCount (C n)`.
- Finish by arithmetic contradiction if necessary.

These are not one-line proofs; they should use induction, `rcases`, `by_contra`, and multi-step `calc`.
