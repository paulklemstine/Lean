### Vision

The key move is to replace an abstract quotient by a canonical section: the **sorted representative** of a chord class. If this representative preserves the voice-leading cost, then the quotient metric stops being merely existential and becomes algorithmic. This is not just a convenience lemma: it is the finite-dimensional shadow of a much larger principle —

> **optimal transport on an orbit space is realized by monotone coupling.**

In music theory this gives a rigorous computational foundation for Tymoczko-style chord-class geometry. In combinatorics it is a discrete rearrangement theorem. ## Primary Theorem Targets

Work with chords as functions `Fin n → ℤ`, with permutation-invariant voice-leading cost
\[
\mathrm{vlCostN}(x,y) := \inf_{\sigma \in S_n} \sum_{i=0}^{n-1} |x_i - y_{\sigma(i)}|.
\]
Since the domain is finite, this infimum is a minimum.

Define a canonical representative by sorting entries in weakly increasing order.

### Target 1: Sorted representative preserves quotient cost

Precise mathematical statement:

> For every `n : ℕ` and chords `x y : Fin n → ℤ`, if `sortChord x` and `sortChord y` are the canonical weakly increasing representatives of the permutation orbits of `x` and `y`, then
> \[
> \mathrm{vlCostN}(x,y)
> =
> \sum_{i : \mathrm{Fin}\ n} \big|\,\mathrm{sortChord}(x)(i)-\mathrm{sortChord}(y)(i)\,\big|.
> \]
> Equivalently, the optimal permutation matching is achieved by matching sorted coordinates to sorted coordinates.

This is the discrete **rearrangement/Monge optimality theorem** for one-dimensional integer data.

A Lean 4 target signature should look like:

```lean
theorem vlCostN_eq_sorted_pairing
    {n : ℕ} (x y : Fin n → ℤ) :
    vlCostN x y =
      ∑ i : Fin n, Int.natAbs (sortChord x i - sortChord y i)
```

If your current `vlCostN` is defined as a minimum over permutations in `Equiv.Perm (Fin n)`, you may also want the intermediate theorem:

```lean
theorem vlCostN_eq_min_perm
    {n : ℕ} (x y : Fin n → ℤ) :
    vlCostN x y =
      Finset.inf' (Finset.univ.image fun σ : Equiv.Perm (Fin n) =>
        ∑ i : Fin n, Int.natAbs (x i - y (σ i))) ?hne
```

and then identify the minimizing permutation after sorting.

### Target 2: Permutation invariance on both arguments

You will likely need the exact symmetry theorem as a reusable building block:

```lean
theorem vlCostN_perm_left
    {n : ℕ} (x y : Fin n → ℤ) (σ : Equiv.Perm (Fin n)) :
    vlCostN (fun i => x (σ i)) y = vlCostN x y

theorem vlCostN_perm_right
    {n : ℕ} (x y : Fin n → ℤ) (σ : Equiv.Perm (Fin n)) :
    vlCostN x (fun i => y (σ i)) = vlCostN x y
```

From these, derive canonical-representative invariance:

```lean
theorem vlCostN_sorted_left_right
    {n : ℕ} (x y : Fin n → ℤ) :
    vlCostN (sortChord x) (sortChord y) = vlCostN x y
```

### Target 3: Sorted matching is optimal among all permutations

This is the structural theorem behind computation:

```lean
theorem sorted_pairing_optimal
    {n : ℕ} (x y : Fin n → ℤ)
    (hx : Monotone (sortChord x))
    (hy : Monotone (sortChord y)) :
    ∀ σ : Equiv.Perm (Fin n),
      (∑ i : Fin n, Int.natAbs (sortChord x i - sortChord y i))
      ≤
      ∑ i : Fin n, Int.natAbs (sortChord x i - sortChord y (σ i))
```

You may need a more list-based statement first, then transfer to `Fin n → ℤ`.

### Target 4: Certified computable algorithm

Define a computable function that sorts and then sums coordinatewise distances:

```lean
def vlCostN_compute {n : ℕ} (x y : Fin n → ℤ) : ℕ :=
  ∑ i : Fin n, Int.natAbs (sortChord x i - sortChord y i)
```

Then prove correctness:

```lean
theorem vlCostN_compute_correct
    {n : ℕ} (x y : Fin n → ℤ) :
    vlCostN_compute x y = vlCostN x y
```

This theorem is the certificate that the quotient metric has an explicit evaluator.

## Recommended proof architecture

### Strategy A: Adjacent-transposition uncrossing argument
**Most promising.**

Prove that for sorted sequences, any permutation with an inversion is not better than the permutation obtained by swapping the inverted pair. Concretely, show for integers `a ≤ b` and `c ≤ d`:
\[
|a-d| + |b-c| \ge |a-c| + |b-d|.
\]
This is the Monge inequality for absolute value on the line.

Then:
1. Show every non-identity permutation has an inversion.
2. Swapping an inversion does not increase cost.
3. Bubble-sort any permutation to the identity, concluding identity is optimal for sorted inputs.

Lean-friendly decomposition:
- prove a 4-point inequality on `ℤ`;
- prove a local “uncrossing decreases cost” lemma for adjacent transpositions;
- induct on permutation length / inversion count.

Suggested lemma:

```lean
lemma abs_uncross
    {a b c d : ℤ} (hab : a ≤ b) (hcd : c ≤ d) :
    Int.natAbs (a - d) + Int.natAbs (b - c) ≥
    Int.natAbs (a - c) + Int.natAbs (b - d)
```

Then a finite-sum version for swapping two crossed assignments.

Why this is strongest: it is elementary, discrete, and avoids importing heavy convexity or transport machinery. It also yields a reusable theorem schema for other quotient metrics.

### Strategy B: Reduce to list sorting + rearrangement inequality
Represent `Fin n → ℤ` as a list/vector, sort it, and use a list-level theorem:

> For sorted lists `xs ys`, the sum of pairwise absolute differences is minimal among all permutations of `ys`.

Then transport the result back to `Fin n → ℤ`.

Steps:
1. Define conversion between `Fin n → ℤ` and `Vector ℤ n` or list with length proof.
2. use `List.sorted` and permutation lemmas;
3. prove or import a list-based rearrangement theorem;
4. transfer back to `vlCostN`.

Why useful: if your codebase already has strong list sorting/permutation lemmas, this may drastically reduce friction. It also gives a natural executable implementation.

### Strategy C: Interpret as discrete 1D optimal transport
View each chord as a multiset / empirical measure on `ℤ`. Then `vlCostN` is the minimal matching cost between equal-cardinality atomic measures. In one dimension, the monotone transport plan is optimal. Formalize the finite atomic case directly.

Steps:
1. define empirical measure semantics informally or via multisets;
2. prove that sorted pairing realizes monotone coupling;
3. identify `vlCostN` with the transport cost.

Why this matters: it opens a bridge to Wasserstein geometry and future generalizations. But as a first theorem in Lean, it is likely heavier than Strategy A.

**Recommendation:** use **Strategy A** for the core theorem, then expose Strategy C in `FUTURE_DIRECTIONS.md` as the conceptual upgrade path.

## Cross-domain connections to make explicit in the development

### 1. Geometric music theory and orbifolds
The quotient of ordered pitch tuples by `S_n` is the local model of a singular quotient space, i.e. an orbifold-like object. By proving the metric is realized on sorted representatives, you provide a concrete chart:
- interior points correspond to strictly increasing tuples;
- singular strata correspond to repeated notes;
- the quotient metric becomes explicit on the Weyl chamber `x₁ ≤ x₂ ≤ ... ≤ xₙ`.

This is exactly the kind of structure one sees in reflection-group quotients and Coxeter chamber geometry.

### 2. Optimal transport
Your theorem is the finite atomic 1D statement:
- matching sorted atoms minimizes `L¹` transport cost;
- `vlCostN` is a discrete Wasserstein-1 cost on equal-mass atomic measures.

This opens a bridge from music-theoretic voice leading to transport geometry.

### 3. Combinatorial group theory
The quotient by `Equiv.Perm (Fin n)` is an orbit-space construction. The proof via adjacent transpositions exploits the Coxeter generators of `S_n`. This is a beautiful formalization point:
- geometry of the quotient
- generated by local braid/adjacent swap moves
- metric optimality via inversion elimination.

### 4. Metric geometry / polyhedral geometry
The sorted chamber is a fundamental domain for the symmetric-group action on `ℤ^n`. Your theorem says the quotient metric is represented by `L¹` on this chamber. This is a discrete analogue of passing from Euclidean space to a Weyl chamber under a finite reflection group.

### 5. Algorithmic certification
Once `vlCostN_compute_correct` is proved, you get a certified algorithm with asymptotic improvement from factorial search to sorting plus linear scan. This matters for extraction, testing, and future verified music-analysis tooling.
