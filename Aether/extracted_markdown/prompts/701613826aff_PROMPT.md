## Required Theorems (with complete proofs)

A. `cliqueComplex_isFlag (G : SimpleGraph α) : IsFlag (cliqueComplex G)`
   Proof sketch: Given a Finset s whose distinct pairs are adjacent in oneSkel (cliqueComplex G), show each distinct pair is G-adjacent (by unfolding the 1-skeleton definition), hence s is a G-clique, hence s is a face.

B. `clique_pair_iff (G : SimpleGraph α) (a b : α) (h : a ≠ b) :
   ({a,b} : Finset α) ∈ (cliqueComplex G).faces ↔ G.Adj a b`
   Proof: Unfold the clique definition; the only distinct pair is (a,b).

C. `IsFlag.singleton_mem (K : ASC α) (hK : IsFlag K) (a : α) (ha : ({a} : Finset α) ∈ K.faces) : True`
   (This is trivially true since singletons are already faces by the ASC axioms.)

D. `IsFlag.eq_cliqueComplex (K : ASC α) (hK : IsFlag K) :
   K.faces = (cliqueComplex (oneSkel K)).faces`
   Direction ⊆: If s ∈ K.faces, then distinct pairs of s are edges of oneSkel K (by definition of oneSkel), so s is a clique of oneSkel K.
   Direction ⊇: If s is a clique of oneSkel K, then distinct pairs are adjacent in oneSkel K, so by IsFlag, s ∈ K.faces.

   IsFlag K ↔ K.faces = (cliqueComplex (oneSkel K)).faces`
   Forward: Theorem D. Backward: If K = cliqueComplex(oneSkel K), then K is flag by Theorem A.
