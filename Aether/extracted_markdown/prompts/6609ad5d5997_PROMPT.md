## Assignment: Certified Space Certificates for SAT Solvers

Prove a genuinely new finite-combinatorial theory of **clause-space certificates** for propositional refutations, with executable search and machine-checkable correctness guarantees. The goal is not merely to formalize a SAT procedure, but to create a new mathematical interface between **proof complexity**, **finite state reachability**, and **resource-bounded dynamical systems**.

You should treat clause-space as a first-class invariant, analogous to width, proof length, or energy in statistical mechanics. The breakthrough is to show that bounded-space refutations admit a **certificate semantics**: a finite witness object whose local transitions are checkable, whose global existence is equivalent to refutability within a prescribed memory budget, and whose search space can be explicitly bounded.

This would open a new field of **certified proof-complexity engineering**: not only “is a formula unsatisfiable?”, but “is it unsatisfiable within memory budget `s`, and can that fact itself be certified and checked independently?” That is a new kind of SAT certificate, orthogonal to DRAT-style proof-length certificates.

## Core formalization target

Define a finite transition system of bounded-memory clause configurations for a CNF formula `F`, where states are finite sets/lists of clauses currently held in memory, with `card ≤ s`, and transitions model admissible proof actions:
- clause download / axiom introduction from `F`,
- inference (e.g. resolution),
- erasure.

Then define a **space certificate** to be a finite path in this transition system from the empty configuration to one containing the empty clause, all while respecting the space bound.

The central theorem should be an equivalence between:
1. existence of a clause-space-`s` refutation, and
2. existence of a valid bounded-space certificate.

## Precise theorem statements to target

You must prove at least 3 substantial theorems. The following are the right scale.

### Theorem 1: Soundness of space certificates
A checked certificate really yields unsatisfiability.

**Mathematical statement.**
For every finite variable type `Var`, CNF `F`, and bound `s`, if there exists a valid space certificate from the empty memory state to a configuration containing the empty clause, then `F` is unsatisfiable.

**Lean-style target signature:**
```lean
theorem spaceCertificate_sound
  {Var : Type} [Fintype Var] [DecidableEq Var]
  (F : CNF Var) (s : ℕ) :
  (∃ C : SpaceCertificate F s, certificateChecks F s C = true) →
  ¬ satisfiable F
```

This is not trivial: it requires an invariant saying every clause present in every reachable configuration is semantically entailed by `F`, then applying that invariant to the empty clause.

### Theorem 2: Completeness of bounded-space certificates
Any bounded-space refutation can be normalized into a certificate accepted by the checker.

**Mathematical statement.**
If `F` has a clause-space-`s` refutation in the abstract proof system, then there exists a finite certificate whose every step respects the memory bound and whose checker accepts it.

**Lean-style target signature:**
```lean
theorem spaceCertificate_complete
  {Var : Type} [Fintype Var] [DecidableEq Var]
  (F : CNF Var) (s : ℕ) :
  clauseSpaceRefutable F s →
  ∃ C : SpaceCertificate F s, certificateChecks F s C = true
```

This is the theorem that turns the abstract notion of bounded-space refutation into an executable certification framework.

### Theorem 3: Finite-state bounded search termination
The bounded-space search procedure terminates because the search universe is finite.

**Mathematical statement.**
For finite `Var`, the set of all configurations of clauses over `Var` of memory size at most `s` is finite; hence exhaustive search over certificates/configurations terminates.

**Lean-style target signature:**
```lean
theorem boundedSpaceSearch_terminates
  {Var : Type} [Fintype Var] [DecidableEq Var]
  (F : CNF Var) (s : ℕ) :
  ∃ n : ℕ, searchWithinBound F s = some n ∨ searchWithinBound F s = none
```

Better, if you define a fuel-bounded search:
```lean
theorem boundedSpaceSearch_complete_with_fuel
  {Var : Type} [Fintype Var] [DecidableEq Var]
  (F : CNF Var) (s : ℕ) :
  ∃ fuel : ℕ,
    clauseSpaceRefutable F s →
    ∃ C : SpaceCertificate F s, searchWithFuel F s fuel = some C
```

But do not stop at bare decidability. The important theorem is an explicit combinatorial state bound.

### Theorem 4: Explicit configuration counting bound
This is where the mathematics becomes interesting rather than merely executable.

Let `N = Fintype.card Var`. The total number of syntactically valid clauses over `Var` is at most `3^N` (each variable is positive, negative, or absent). Therefore the number of memory configurations of size at most `s` is at most
\[
\sum_{k=0}^s \binom{3^N}{k}.
\]

Prove a formal upper bound of this form, or a clean polynomial/exponential relaxation.

**Lean-style target signature:**
```lean
theorem count_bounded_configs_le
  {Var : Type} [Fintype Var] [DecidableEq Var]
  (s : ℕ) :
  cardSpaceConfigs Var s ≤ ∑ k in Finset.range (s+1), Nat.choose (numClauses Var) k
```

and ideally
```lean
theorem numClauses_le_three_pow
  {Var : Type} [Fintype Var] [DecidableEq Var] :
  numClauses Var ≤ 3 ^ (Fintype.card Var)
```

This theorem is the bridge from proof complexity to explicit complexity analysis.

### Theorem 5: Reachability/certificate equivalence
Define a graph of bounded configurations. Then prove that certificate existence is equivalent to graph reachability of a goal node.

**Lean-style target signature:**
```lean
theorem certificate_iff_reachable_goal
  {Var : Type} [Fintype Var] [DecidableEq Var]
  (F : CNF Var) (s : ℕ) :
  (∃ C : SpaceCertificate F s, certificateChecks F s C = true) ↔
  Reachable (spaceGraph F s) emptyConfig goalConfig
```

This is the conceptual heart: clause-space certificates become finite-state reachability certificates.

## Stronger conjectural target

Your conjecture should be stated in a mathematically sharpened form, with a test that can fail.

### Conjecture: Polynomial-over-state-space search bound
There exists a polynomial `p : ℕ → ℕ` such that for every finite variable set `Var`, every CNF `F`, and every `s`,
if `F` is clause-space refutable in space `s`, then the bounded-space search finds a valid certificate in at most
\[
p(|\mathcal S(F,s)|)
\]
transition examinations, where `\mathcal S(F,s)` is the finite set of bounded configurations.

A more explicit falsifiable version:
> For all CNFs on at most 5 variables and all `s ≤ 4`, BFS over the bounded configuration graph finds a certificate, whenever one exists, within time at most quadratic in the number of reachable configurations.

This is computationally testable and can be refuted by a single counterexample instance.

## Proof strategy architecture

You must include 2–3 serious proof routes and pursue the most promising one.

### Strategy A: Semantic invariant + finite graph reachability
1. Define clause semantics and CNF satisfiability.
2. Prove by induction on `SpaceStep` that every clause in every reachable configuration is semantically entailed by `F`.
3. Conclude soundness when the empty clause appears.
4. Build the finite graph of bounded configurations and identify certificates with paths.

**Why promising:** this aligns perfectly with Lean’s strengths: inductive relations, finite types, and path/reachability arguments. It also cleanly separates semantic soundness from combinatorial search.

### Strategy B: Normalize abstract refutations into certified traces
1. Define an abstract bounded-space refutation system.
2. Show every derivation can be converted into a stepwise memory trace with explicit downloads/resolutions/erasures.
3. Prove the checker accepts the normalized trace.

**Why promising:** this gives the completeness theorem in a canonical form and yields an actual certificate format, not just existence. It is slightly more delicate because of trace normalization and memory bookkeeping.

### Strategy C: Counting argument via clause universe + combinatorics
1. Enumerate all possible clauses over `Var`.
2. Show each bounded-memory configuration is a subset of this universe of size `≤ s`.
3. Deduce the configuration-count upper bound.
4. Combine with BFS finiteness to obtain explicit search bounds.

**Why promising:** this is the route to the complexity theorem and cross-domain significance. It uses finite combinatorics rather than proof-theoretic semantics.

**Recommended order:** A first, then B, then C.  
A gives soundness and a robust invariant framework.  
B upgrades the framework to certification completeness.  
C transforms the theory into explicit algorithmics and complexity bounds.

## Deep proof tactics to use

Your proofs must not collapse to brute-force decision procedures. At minimum:
- use **induction** on derivations/traces/reachability,
- use **rcases** to unpack certificate structure and transition cases,
- use **by_contra** for contradiction from satisfiability versus empty-clause entailment,
- use **calc** blocks for counting inequalities and semantic entailment chains,
- use `field_simp` only if you introduce rational asymptotic bounds; otherwise prefer combinatorial arguments.

In particular, the soundness proof should be an actual semantic induction, and the counting theorem should be a genuine combinatorial inequality.

Clause space behaves like a memory resource in computation. Formalize a monotonicity theorem:
If `s ≤ t`, then every space-`s` certificate is also a space-`t` certificate.

```lean

  {Var : Type} [Fintype Var] [DecidableEq Var]
```

```lean
theorem findSpaceCertificate_correct
```
