2. **Tropical circle energy**


   or, if you want a more geometric version on nonnegative radii,

3. **Tropical duality transform on charges**
   ```lean
   def tDualCharge (n w : ℝ) : ℝ × ℝ := (w, n)
   ```

4. **Tropical Legendre transform**
   For a function `f : ℝ → ℝ`,
   ```lean
   def tropLegendre (f : ℝ → ℝ) (p : ℝ) : ℝ := sInf {y : ℝ | ∃ x, y = f x + p * x}
   ```
   If `sInf` becomes technically heavy, restrict to finite sets first:
   ```lean
   def tropLegendreFinset (A : Finset ℝ) (f : ℝ → ℝ) (p : ℝ) : ℝ :=
     A.inf' (by ...) (fun x => f x + p * x)
   ```

5. **Corner locus for piecewise-linear tropical potentials**
   For a finite family of affine functions:
   ```lean
   def tropPotential (A : Finset ι) (c m : ι → ℝ) (x : ℝ) : ℝ :=
     A.inf' (by ...) (fun i => c i + m i * x)
   ```

   Define a point to lie in the corner locus if the minimum is attained by at least two distinct indices:
   ```lean
   def InCornerLocus (A : Finset ι) (c m : ι → ℝ) (x : ℝ) : Prop :=
     ∃ i ∈ A, ∃ j ∈ A, i ≠ j ∧

       c j + m j * x = tropPotential A c m x
   ```

This is the right level of abstraction: enough to capture “mirror potentials” and “conifold = singular corner formation”, but still tractable in Lean.

## Precise Theorem Targets

### Theorem 1: Tropical T-duality is an involutive symmetry of the radius/charge package

Formalize and prove a theorem of the following shape:

```lean
theorem tDualRadius_involutive {R : ℝ} (hR : R ≠ 0) :
    tDualRadius (tDualRadius R) = R
```

and the charge involution
```lean
theorem tDualCharge_involutive (n w : ℝ) :
    tDualCharge (tDualCharge n w).1 (tDualCharge n w).2 = (n, w)
```

More importantly, prove an energy invariance theorem. For the simplest model:
```lean
theorem circleEnergy_tdual_invariant {R : ℝ} (hR : R ≠ 0) (n w : ℝ) :
    circleEnergy R n w = circleEnergy (tDualRadius R) w n
```

If you use the log-radius model, the theorem should become even cleaner:
```lean
def logRadiusEnergy (r n w : ℝ) : ℝ := min (n + r) (w - r)

theorem logRadiusEnergy_tdual (r n w : ℝ) :
    logRadiusEnergy r n w = logRadiusEnergy (-r) w n
```

This is the mathematically strongest first target: it is exact, nontrivial, and captures the T-duality involution without analytic baggage.

**Why this is a breakthrough:** it upgrades the usual physics heuristic “exchange momentum and winding while inverting radius” into a certified min-plus symmetry principle. Once formalized, this becomes a reusable algebraic interface for tropicalized sigma models, scattering amplitudes, and compactification functors.

### Theorem 2: Tropical mirror symmetry as involutivity of tropical Legendre transform on finite convex piecewise-linear potentials

Restrict first to finite tropical potentials:
```lean
def tropPotential (A : Finset ι) (c m : ι → ℝ) (x : ℝ) : ℝ :=
  A.inf' (by ...) (fun i => c i + m i * x)
```

Then define a finite-slope dual:
```lean
def dualPotential (A : Finset ι) (c m : ι → ℝ) (p : ℝ) : ℝ :=
  A.inf' (by ...) (fun i => c i - p * m i)
```

Prove a theorem identifying this with a finite tropical Legendre transform under an appropriate realization hypothesis.

Target theorem:
```lean
theorem tropLegendre_tropPotential_eq_dual
    (A : Finset ι) [DecidableEq ι]
    (hA : A.Nonempty)
    (c m : ι → ℝ) :
    tropLegendreFinset (A.image m) (tropPotential A c m) =
      dualPotential A c m
```
You may need to weaken or restate this theorem depending on the exact definition of `tropLegendreFinset`; that is acceptable, but the mathematical content must remain:

> the tropical mirror of a finite min-of-affines potential is the dual min-of-affines potential obtained by exchanging base variable and slope data.

Then prove an involutivity theorem under injectivity/convexity hypotheses:
```lean
theorem tropLegendreFinset_involutive
    (A : Finset ι) [DecidableEq ι]
    (hA : A.Nonempty)
    (c m : ι → ℝ)
    (hconv : ...) :
    tropLegendreFinset (A.image m)
      (tropLegendreFinset A (tropPotential A c m)) =
      tropPotential A c m
```

Even if full involutivity is too ambitious in the first pass, prove a **Galois-type inequality**:
```lean
theorem tropLegendre_biconjugate_le
    ... :
    tropLegendre (tropLegendre f) x ≤ f x
```
or the reversed inequality depending on your convention.

**Why this is a breakthrough:** this would make “mirror symmetry = tropical Legendre duality” precise on a certifiable class of potentials. That is not just a slogan from SYZ folklore; it becomes a formal bridge between tropical convexity, piecewise-linear geometry, and the duality architecture already emerging in the catalog.

### Theorem 3: Conifold transition as emergence of a corner locus

For finite tropical potentials, prove that singularity formation corresponds to coincidence of minimizing affine branches.

A precise theorem target:
```lean
theorem inCornerLocus_iff_two_minimizers
    (A : Finset ι) [DecidableEq ι]
    (hA : A.Nonempty)
    (c m : ι → ℝ) (x : ℝ) :
    InCornerLocus A c m x ↔
      ∃ i ∈ A, ∃ j ∈ A, i ≠ j ∧
        c i + m i * x = c j + m j * x ∧
        c i + m i * x = tropPotential A c m x
```

Then prove a parameterized transition theorem. For example, for a 3-branch family:
```lean
def conifoldFamily (t x : ℝ) : ℝ := min (x) (min (-x) t)
```

Prove that `t = 0` is the singular transition value:
```lean
theorem conifoldFamily_corner_at_zero :
    InCornerLocus (A := ({0,1,2} : Finset ℕ)) ... 0
```
and more structurally,
```lean
theorem conifoldFamily_nonsmooth_iff (x t : ℝ) :
    InCornerLocus ... x ↔ (x = 0 ∧ t = 0) ∨ ...
```

You may choose a cleaner finite-index encoding, but the content should be:

> a conifold-type transition is detected exactly by the creation or merger of tropical corners.

**Why this is a breakthrough:** this turns singular transitions in mirror geometry into combinatorial events in tropical convexity. Once formalized, it opens the door to certified singularity tracking, wall-crossing combinatorics, and eventually machine-verifiable birational transition data.

## Proof Strategy Architecture

### Strategy A: Algebraic involution first, geometry second
Most promising.

1. Prove radius inversion and charge swap involutivity directly by field simplification and pair extensionality.
2. Use `min_comm`, `min_left_comm`, arithmetic normalization, and the existing min-plus distribution lemmas to prove energy invariance.
3. Only after the involution package is solid, define tropical potentials and corner loci as finite minima of affine functions.

**Why best:** it gets a certifiable nontrivial theorem quickly and establishes reusable infrastructure for the more geometric mirror/conifold statements.

---

### Strategy B: Work in log-radius coordinates
Potentially the cleanest mathematically.

1. Replace `R > 0` by `r = log R`, so T-duality becomes `r ↦ -r`.
2. Define `logRadiusEnergy r n w = min (n + r) (w - r)`.
3. Prove symmetry by pure ring/min algebra, avoiding division side conditions.

**Why powerful:** this tropicalizes the physics correctly: multiplicative inversion becomes additive negation, which is native to min-plus geometry. This is conceptually the strongest formulation and likely the easiest to formalize.

---

### Strategy C: Finite convex duality via explicit slope-index calculations
Best for mirror symmetry.

1. Define potentials as finite minima of affine functions indexed by a `Finset`.
2. Compute the tropical Legendre transform explicitly on each branch.
3. Show the dual is again a finite min of affine expressions, with corner locus corresponding to non-unique minimizers.

**Why useful:** avoids hard analytic convex analysis and makes everything combinatorial. This is the right route for Lean and for future generalization to polyhedral complexes.
