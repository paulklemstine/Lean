## The Core Insight: Evaluation IS Normalization

The Eilenberg-Moore comparison theorem for the free-forgetful adjunction of monoids is not merely an abstract equivalence — it is a **verified normalization algorithm in disguise**. A `T`-algebra structure `α : List A → A` (where `T = List` is the free-monoid monad) simultaneously encodes:
1. A monoid structure on `A` (via `e = α []`, `m * n = α [m, n]`)
2. A normalization map (via `α` itself — it reduces formal expressions to values)
3. A correctness proof (the monad algebra laws ARE the coherence conditions for normalization)

The second monad algebra law `α ∘ μ = α ∘ Tα` translates to: *"normalizing a flattened expression equals normalizing each subexpression first, then normalizing the results"*. This is exactly the statement that normalization is **compositional** — the foundational requirement for any correct simplification engine.

## Precise Theorem Targets

### Theorem 1: T-Algebras Are Monoids (The Comparison)

```lean
/-- A T-algebra for the list monad carries the same structure as a monoid.
    The algebra structure map `α : List A → A` encodes:
    - unit: `α [] = 1`
    - multiplication: `α [a, b] = a * b`
    - general evaluation: `α [a₁, ..., aₙ] = a₁ * ... * aₙ` -/
theorem list_monad_algebra_equiv_monoid (A : Type*) :
    (∃ (α : List A → A), ∀ (a : A), α [a] = a ∧ 
     ∀ (l₁ l₂ : List (List A)), α (l₁ ++ l₂).join = α (List.map α (l₁ ++ l₂))) ↔
    ∃ (_ : Monoid A), True := sorry
```

This is the **comparison theorem** made explicit. Prove both directions:
- **Forward**: From a `T`-algebra `(A, α)`, construct `Monoid A` with `1 = α []`, `a * b = α [a, b]`. Prove monoid axioms from the algebra laws.
- **Reverse**: From `Monoid A`, define `α = List.prod'` (the monoid product of a list). Prove the algebra laws from monoid axioms.

### Theorem 2: Normalization Correctness (Compositionality)

```lean
/-- The normalization map α for a T-algebra is compositional:
    normalizing subexpressions first, then combining, equals normalizing the whole expression.
    This is the second monad algebra law restated as a computational guarantee. -/
theorem normalization_compositional {A : Type*} [Monoid A] 
    (α : List A → A) (h_alg : ∀ a, α [a] = a) 
    (h_compat : ∀ l, α l = l.foldl (· * ·) 1) :
    ∀ (l : List (List A)), α (l.join) = α (List.map α l) := sorry
```

**Proof strategy**: Induction on `l` with careful manipulation of `List.foldl` and the monoid associativity law. The key step is showing `α (l₁ ++ l₂) = α l₁ * α l₂`, which follows from `h_compat` and the definition of `foldl`.

### Theorem 3: Cross-Domain — Normalization and String Rewriting

```lean
/-- Confluence connection: In a free monoid, two words have the same normal form
    under α iff they are related by the congruence generated by the monoid laws.
    This connects T-algebra normalization to the rewriting-theoretic notion of confluence. -/
theorem normal_form_congruence {α : Type*} [Monoid α] (w₁ w₂ : List α) :
    List.foldl (· * ·) 1 w₁ = List.foldl (· * ·) 1 w₂ ↔
    ∀ (f : α → FreeMonoid α), 
      FreeMonoid.lift f (FreeMonoid.ofList w₁) = 
      FreeMonoid.lift f (FreeMonoid.ofList w₂) := sorry
```

This connects **categorical algebra** (T-algebras) to **string rewriting** (congruence on words), establishing that normalization in the Eilenberg-Moore sense captures exactly the equational theory.

## Proof Strategies (Three Paths)

### Strategy A: Direct Comparison Functor Construction (RECOMMENDED)
Most constructive — builds the equivalence explicitly, yielding a computable normalization map.

1. **Forward direction**: Given `(A, α)` with `α [a] = a` and `α ∘ join = α ∘ map α`, define:
   - `1 := α []`
   - `a * b := α [a, b]`
   - Prove `1 * a = a` using `α [α [], a] = α [a]` (from second law with `l₁ = [[]]`, `l₂ = [[a]]`)
   - Prove `(a * b) * c = a * (b * c)` using `α [α [a,b], c] = α [a, α [b,c]]` (from second law with appropriate nesting)
   
2. **Reverse direction**: Given `[Monoid A]`, define `α l = l.foldl (· * ·) 1`. Verify:
   - `α [a] = a` (foldl over singleton)
   - `α (l.join) = α (map α l)` (induction on `l`, using associativity)

3. **Equivalence**: Show these constructions are mutually inverse up to definitional equality.

### Strategy B: Via Beck Monadicity Theorem
More general but less constructive. Uses the fact that `MonoidCat` has coequalizers of `G`-split pairs. This approach would establish the result for *any* algebraic theory at once, but doesn't yield a concrete normalization algorithm. Use only if Strategy A encounters unexpected obstacles.

### Strategy C: Operadic Interpretation
View the list monad as the operad for associative algebras. The `n`-ary operation `αₙ : Aⁿ → A` is `α` applied to an `n`-element list. The monad algebra laws become operadic composition laws. This connects to the theory of **PROPs** and **Lawvere theories**, opening a path to generalizing beyond monoids. Most speculative but most fertile for future work.

**Recommendation**: Pursue Strategy A as the primary path. It is constructive, yields the normalization algorithm directly, and the proof obligations (monoid axioms from algebra laws) are the deep content.

## Cross-Domain Connections

### 1. Term Rewriting ↔ Category Theory
The T-algebra law `α ∘ μ = α ∘ Tα` is exactly the **confluence** condition from rewriting theory. A term rewriting system is locally confluent iff its evaluation map satisfies this compatibility law. This connects the Knuth-Bendix completion algorithm to Beck's monadicity theorem.

### 2. Denotational Semantics ↔ Algebra
The normalization map `α : List A → A` is an **evaluator** in the sense of programming language semantics. The monad algebra laws are the correctness conditions for an interpreter: evaluating subterms first and combining equals evaluating the whole term. This is precisely the **compositional semantics** property.

### 3. Homological Algebra
The bar resolution `B_n(M) = T^{n+1}(M)` for a monad `T` and `T`-algebra `(M, α)` yields a chain complex whose augmentation is `α`. The normalization map being a T-algebra morphism means it induces a chain map, connecting monad theory to **homological algebra** and **cohomology of algebraic structures**.

### 4. Information Theory
The compositionality law `α(join lss) = α(map α lss)` is a **data processing inequality**: processing information in stages (normalize subexpressions, then combine) loses no more information than processing it all at once. This opens a connection between monad algebras and **information conservation laws**.
