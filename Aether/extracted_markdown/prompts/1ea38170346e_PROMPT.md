## YOUR ASSIGNMENT: Boolean Congruence Elimination via Join-Irreducible Witness Lattices

Work in the Boolean idempotent semiring, and make the finite/computable content completely explicit. The core objective is to replace resultant-style elimination by a finite distributive-lattice extraction theorem.

### 1. Formalization target: concrete Boolean polynomial support model

Do **not** begin with an abstract polynomial semiring if that obscures finiteness. First build a concrete support model in which Boolean polynomials are finite sets of monomials, addition is union, and multiplication is Minkowski sum on exponent vectors. This is the right normal form because over `Bool` with idempotent addition, coefficients collapse and only support matters.

A robust Lean skeleton is:

```lean
abbrev Exp (n : ℕ) := Fin n → ℕ

structure BPoly (n : ℕ) where
  support : Finset (Exp n)
deriving DecidableEq

namespace BPoly

def zero (n : ℕ) : BPoly n := ⟨∅⟩
def one (n : ℕ) : BPoly n := ⟨{0}⟩

def add {n : ℕ} (f g : BPoly n) : BPoly n :=
  ⟨f.support ∪ g.support⟩

def mul {n : ℕ} (f g : BPoly n) : BPoly n :=
  ⟨(f.support.biUnion fun a =>
      g.support.image fun b => fun i => a i + b i)⟩
```

If a semiring instance is too expensive, it is acceptable to work at the level of support combinatorics plus a realization map into `MvPolynomial (Fin n) Bool` later. But the theorem must be stated on a concrete finite type.

Define projection dropping the last variable:

```lean

def projBPoly {n : ℕ} : BPoly (n+1) → BPoly n := ...
```

Define a support normal form map; in the concrete support model this should be the identity, but if you connect to `MvPolynomial`, then `support_nf` should assert that every Boolean polynomial is congruent/equal to the finite support form with duplicate monomials removed.

A good exact target is:

### 3. Join-irreducible witness lattice infrastructure

The conceptual engine is finite distributive lattice theory: a finitely generated Boolean congruence quotient should induce a finite distributive lattice of normal forms/support-classes on the bounded search region determined by the generators. Elimination then becomes extraction of finitely many join-irreducible witness implications.

Do not overreach to arbitrary infinite quotients. Restrict to the **finite support universe generated by the input relation**. This is the breakthrough restricted-class theorem.

Define a finite universe of supports closed under the combinatorics needed for one-step congruence propagation. For example, from a finite generating relation `R`, let `baseMonomials` be all monomials appearing in supports of endpoints of pairs in `R`; then work inside the finite powerset lattice on these monomials, or a finite truncation if multiplication introduces growth. If necessary, first prove the theorem for **support-hypergraph congruences** where multiplication by variables is not yet included; then extend to the closure regime already present in the existing elimination file.

Define a finite lattice of candidate support classes/witnesses:

```lean
def supportUniverse {n : ℕ} (R : Finset (BPoly n × BPoly n)) : Finset (Exp n) := ...

def supportPowersetLattice {n : ℕ} (R : Finset (BPoly n × BPoly n)) := Finset (Finset (Exp n))
```

Define join-irreducibility on a finite sup-semilattice concretely:

```lean
def IsJoinIrredFinset {α : Type _} [DecidableEq α]
    (U : Finset α) (le : α → α → Prop) (sup : α → α → α) (j : α) : Prop := ...
```

But for implementation, the most practical notion is on finite subsets ordered by inclusion:

```lean
def Finset.IsJoinIrred {α : Type _} [DecidableEq α] (s : Finset α) : Prop :=
  s.Nonempty ∧ ∀ a b : Finset α, a ⊂ s → b ⊂ s → a ∪ b ≠ s
```

or use the equivalent witness form “covers exactly one predecessor” if easier to prove algorithmically.

Then define the witness family extracted from the quotient/lattice presentation:

```lean

    Finset (BPoly (n+1) × BPoly (n+1)) := ...
```

The target finite/computable theorem should be something like:

```lean

    (R : Finset (BPoly (n+1) × BPoly (n+1))) :
    ∃ W : Finset (BPoly (n+1) × BPoly (n+1)),
      (∀ p ∈ W, IsJoinIrredWitness R p) ∧
      ∀ p, IsJoinIrredWitness R p → p ∈ W
```

If a canonical `W` is directly definable by filtering a finite ambient set, strengthen to:

```lean

    (R : Finset (BPoly (n+1) × BPoly (n+1))) :

```

but the stronger extensional characterization is preferable.

### 4. Main elimination theorem: finite generation by projected join-irreducible witnesses

This is the central statement. State it with exact quantifiers and computable generators.

A precise Lean target:

```lean
theorem elim_eq_generate_projected_witnesses {n : ℕ}
    (R : Finset (BPoly (n+1) × BPoly (n+1))) :
    eliminationCong (GeneratedCong R) =
      GeneratedCong ((joinIrredWitnesses R).image projectedPair)
```

If extensional equality of binary relations is awkward, write:

```lean
theorem elim_eq_generate_projected_witnesses {n : ℕ}
    (R : Finset (BPoly (n+1) × BPoly (n+1))) :
    ∀ f g : BPoly n,
      eliminationCong (GeneratedCong R) f g ↔
      GeneratedCong ((joinIrredWitnesses R).image projectedPair) f g
```

This is the theorem that matters: elimination is not merely finitely generated; it is generated by a canonically computable witness set derived from join-irreducibles.

A valuable intermediate theorem, likely easier and essential, is:

```lean
theorem elim_finitely_generated {n : ℕ}
    (R : Finset (BPoly (n+1) × BPoly (n+1))) :
    ∃ S : Finset (BPoly n × BPoly n),
      ∀ f g : BPoly n,
        eliminationCong (GeneratedCong R) f g ↔ GeneratedCong S f g
```

Then prove that `S` can be chosen as the projected join-irreducible witnesses.

### 5. Proof strategy: concrete steps and key lemmas

#### Strategy A: finite distributive lattice + Birkhoff extraction (most promising)

This is the right conceptual route. The theorem is really a finite Birkhoff representation theorem for elimination congruence.

1. **Normalize to supports.**
   Prove `support_nf` so every Boolean polynomial is determined by a finite support set.
   Key lemma:
   ```lean
   theorem eq_iff_support_eq {n : ℕ} (f g : BPoly n) :
     f = g ↔ f.support = g.support
   ```
   If connecting to `MvPolynomial`, prove support realization respects `+` and `*`.

2. **Construct a finite ambient lattice from the generators.**
   From `R`, build a finite universe `U` of support atoms relevant to elimination. The exact choice may be:
   - monomials occurring in generators and their projections, or
   - support subsets appearing in closure under one-step rules,
   - a bounded closure already encoded in the existing elimination file.
   
   Then define the finite lattice of `U`-supported polynomials modulo generated congruence. Show it is distributive because it is a quotient of a finite powerset lattice by a congruence compatible with union/intersection-like closure, or because normal forms are lower sets in an implication preorder.

3. **Identify elimination classes with a finite closure system.**
   Show the eliminated relation on `BPoly n` corresponds to a closure operator on projected supports:
   ```lean
   def witnessClosure : Finset (Exp n) → Finset (Exp n) := ...
   theorem witnessClosure_extensive ...
   theorem witnessClosure_mono ...
   theorem witnessClosure_idem ...
   ```
   Then the closed sets form a finite distributive lattice. This is where congruence elimination becomes algorithmic.

4. **Use join-irreducibles to generate all implications.**
   Apply finite Birkhoff logic: every element of a finite distributive lattice is the join of join-irreducibles; therefore every congruence consequence in the elimination lattice is generated by implications attached to join-irreducible failures/minimal witnesses.
   Key shape:
   ```lean
   theorem closure_eq_sup_joinIrreds ...
   theorem implication_generated_by_joinIrreds ...
   ```
   In Lean, you may avoid abstract lattice machinery by proving directly that any nontrivial closed-set inclusion admits a minimal counterexample, and that minimal counterexamples are join-irreducible witnesses.

5. **Project witnesses and prove equality of generated congruences.**
   Show every eliminated equality has a derivation from projected join-irreducible witnesses by induction on finite derivation height or lattice rank.
   Reverse inclusion is easier: every projected witness is valid in the elimination congruence by construction.

Why this is most promising: it converts elimination from an unbounded algebraic cancellation problem into a finite combinatorial closure theorem. It matches the Boolean/idempotent setting exactly and exploits the strongest available structure.

---

#### Strategy B: hypergraph implication closure

If quotient-lattice formalization becomes cumbersome, recast everything as Horn implication closure on finite supports.

1. Associate to each generator pair `(f,g)` the pair of support hyperedges.
2. Define the least closure system on projected supports stable under these implications.
3. Prove elimination congruence coincides with equality in this closure system.
4. Define minimal implications; prove these are finite and correspond to join-irreducibles of the closure lattice.
5. Recover the main theorem as equality of generated closure relations.

This is computationally attractive because `Finset` algorithms for closure systems are straightforward. It may be the fastest route to executable code.

---

#### Strategy C: quotient normal forms via canonical representatives

If there is already infrastructure for Buchberger-like normalization in the idempotent semiring congruence files, leverage it.

1. Define canonical Boolean support normal forms in the quotient by repeated reduction.
2. Prove reduction terminates because the support universe is finite.
3. Show elimination on `x`-variables only is equality of reduced projected normal forms.
4. Extract the finite set of critical minimal reductions; identify these with join-irreducible witnesses.
5. Prove these critical reductions generate the whole eliminated congruence.

This path is best if the existing file already contains reduction/normalization APIs.

### 8. Why this matters

This result is not a minor Boolean special case. It is the first credible positive elimination theorem in a regime where generic idempotent-semiring elimination is obstructed. The significance is threefold:

1. **Sharp boundary theorem.** It separates the impossible general elimination story from a computable finite distributive-lattice theory in the Boolean case. That is a structural discovery, not an implementation detail.

2. **New bridge between congruence geometry and finite lattice theory.** The quotient congruence data becomes a closure system / distributive lattice, and elimination becomes join-irreducible extraction. This is exactly the kind of cross-domain recoding that opens a field.

3. **Algorithmic foundation for idempotent symbolic methods.** Once elimination is recast as finite witness extraction, one can attack:
   - Boolean tropical prevarieties,
   - symbolic reachability and Horn closure systems,
   - congruence compression and minimal explanation sets,
   - certified elimination procedures for restricted semiring geometries.

In other words: this theorem turns congruence elimination from a fragile algebraic manipulation into a finite combinatorial engine.

```lean
# Functorial Resultant and Projection Reconstruction for Idempotent Semiring Congruences

This file builds an elimination mechanism for semiring congruences on multivariate
polynomials, parallel to classical resultant elimination but adapted to semiring
congruences rather than ideals.

## Overview

We work in a commutative semiring `S` with polynomial variables split as `Option σ`,
where `none` is the eliminated variable and `some i` are the retained variables.

Using the Mathlib equivalence `MvPolynomial.optionEquivLeft`, we view
`MvPolynomial (Option σ) S` as `Polynomial (MvPolynomial σ S)` — a univariate polynomial
in the distinguished variable `none` with coefficients in the retained-variable ring.

## Main definitions

* `SemiringCong` — a semiring congruence (equivalence compatible with `+` and `*`)
* `coeffNone` — extracts the n-th coefficient in the `none` variable
* `noneDegree` — maximum exponent of `none` in the support
* `PolyPair` — a pair of polynomials representing a congruence generator
* `liftSome` — the embedding `MvPolynomial σ S →ₐ[S] MvPolynomial (Option σ) S`
* `eliminationCong` — pullback of a semiring congruence along `liftSome`
* `linResultantPair` — cross-multiplied coefficient pair for linear generators

## Main results

* `coeffNone_add` — coefficient extraction is additive
* `coeffNone_X_none_pow_mul_liftSome` — key computation for `X none ^ k * liftSome a`
* `linear_expand_of_noneDegree_le_one` — decomposition of linear polynomials
* `mem_eliminationCong_iff` — characterization of elimination congruence
* `cross_mul_mem` — cross-multiplication theorem for congruence pairs
* `eliminationCong_mono` — monotonicity of elimination

import Mathlib

open MvPolynomial Polynomial

/-! ## Semiring Congruence -/

/-- A semiring congruence: an equivalence relation compatible with `+` and `*`. -/
structure SemiringCong (A : Type*) [Semiring A] where
  r : A → A → Prop
  refl' : ∀ a, r a a
  symm' : ∀ {a b}, r a b → r b a
  trans' : ∀ {a b c}, r a b → r b c → r a c
  add' : ∀ {a b c d}, r a b → r c d → r (a + c) (b + d)
  mul' : ∀ {a b c d}, r a b → r c d → r (a * c) (b * d)

namespace SemiringCong

variable {A : Type*} [Semiring A]

instance : LE (SemiringCong A) where
  le C D := ∀ ⦃a b⦄, C.r a b → D.r a b

end SemiringCong

/-! ## Type Abbreviations -/

/-- The "full" polynomial ring with the distinguished variable. -/
abbrev PolyFull (S : Type*) (σ : Type*) [CommSemiring S] := MvPolynomial (Option σ) S

/-- The "retained" polynomial ring without the distinguished variable. -/
abbrev PolyRet (S : Type*) (σ : Type*) [CommSemiring S] := MvPolynomial σ S

/-! ## Additive Idempotency -/

/-- A type with addition is additively idempotent if `a + a = a` for all elements. -/
class AddIdempotent (S : Type*) [Add S] : Prop where
  add_self : ∀ a : S, a + a = a

theorem add_self_eq {S : Type*} [Add S] [AddIdempotent S] (a : S) : a + a = a :=
  AddIdempotent.add_self a

/-! ## Coefficient Extraction -/

/-- Extract the n-th coefficient of the distinguished variable `none`. -/
noncomputable def coeffNone {S : Type*} [CommSemiring S] {σ : Type*}
    (n : ℕ) (f : PolyFull S σ) : PolyRet S σ :=
  Polynomial.coeff (optionEquivLeft S σ f) n

/-- `coeffNone` as an additive group homomorphism. -/
noncomputable def coeffNoneHom {S : Type*} [CommSemiring S] {σ : Type*}
    (n : ℕ) : PolyFull S σ →+ PolyRet S σ where
  toFun := coeffNone n
  map_zero' := by simp [coeffNone, map_zero]
  map_add' f g := by simp [coeffNone, map_add]

/-! ## Degree in the Distinguished Variable -/

/-- Maximum exponent of `none` in the support of `f`. -/
noncomputable def noneDegree {S : Type*} [CommSemiring S] {σ : Type*}
    (f : PolyFull S σ) : ℕ :=
  (optionEquivLeft S σ f).natDegree

/-! ## Polynomial Pairs -/

/-- A pair of polynomials representing a congruence generator. -/
structure PolyPair (S : Type*) (σ : Type*) [CommSemiring S] where
  lhs : PolyFull S σ
  rhs : PolyFull S σ

/-! ## Embedding and Elimination -/

/-- The canonical embedding `MvPolynomial σ S →ₐ[S] MvPolynomial (Option σ) S`. -/
noncomputable def liftSome {S : Type*} [CommSemiring S] {σ : Type*} :
    PolyRet S σ →ₐ[S] PolyFull S σ :=
  MvPolynomial.rename Option.some

/-- Elimination congruence: pullback of `C` along `liftSome`. -/
def eliminationCong {S : Type*} [CommSemiring S] {σ : Type*}
    (C : SemiringCong (PolyFull S σ)) : SemiringCong (PolyRet S σ) where
  r f g := C.r (liftSome f) (liftSome g)
  refl' a := C.refl' (liftSome a)
  symm' h := C.symm' h
  trans' h1 h2 := C.trans' h1 h2
  add' h1 h2 := by
    show C.r (liftSome (_ + _)) (liftSome (_ + _))
    simp only [map_add]; exact C.add' h1 h2
  mul' h1 h2 := by
    show C.r (liftSome (_ * _)) (liftSome (_ * _))
    simp only [map_mul]; exact C.mul' h1 h2
```
