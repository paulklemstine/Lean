Formalize the ultrametric structure on the Berggren tree of primitive Pythagorean triples. This is a focused development building on the existing catalog file Algebra/BerggrenLorentz/Core.lean which provides lorentzForm and lorentzQ.

## Definitions Required

1. **Berggren generators**: Define the three 3×3 matrices:
   A₁ = [[1,-2,2],[2,-1,2],[2,-2,3]],
   A₂ = [[1,2,2],[2,1,2],[2,2,3]],
   A₃ = [[-1,2,2],[-2,1,2],[-2,2,3]]
   These map a primitive Pythagorean triple (a,b,c) to three new primitive Pythagorean triples.

2. **Berggren tree path**: A BerggrenPath is a list of indices in Fin 3. The function `applyPath : BerggrenPath → Triple → Triple` applies the corresponding sequence of generators.

3. **Depth valuation**: `depth : BerggrenPath → ℕ` returns the length of the path. Prove `depth (i :: p) = depth p + 1`.

4. **Ultrametric distance**: For two triples reachable by paths p₁, p₂, define `d p₁ p₂ = (2 : ℚ)^(-(lcaDepth p₁ p₂))` where `lcaDepth` is the length of the longest common prefix of p₁ and p₂.

## Theorems to Prove

1. **Generator preservation of Pythagorean property**: If Q(a,b,c) = 0, then Q(Aᵢ(a,b,c)) = 0 for each i ∈ {1,2,3}. This means the Berggren generators map Pythagorean triples to Pythagorean triples.

2. **Strong ultrametric inequality**: For any three paths p, q, r, prove `d p r ≤ max (d p q) (d q r)`. This follows because the LCA depth satisfies: lcaDepth(p,r) ≥ min(lcaDepth(p,q))(lcaDepth(q,r)), which is a standard tree property.

3. **Depth is a valuation**: `v(applyPath (i :: p) root) = v(applyPath p root) + 1`, showing depth behaves as a discrete valuation (tropical-style: v(Aᵢ(T)) = v(T) + 1).

4. **Positivity and separation**: If p ≠ q, then d p q > 0. If p = q, then d p q = 0.
