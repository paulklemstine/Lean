## Core Mathematical Objective

Let `T` be a finite rooted weighted tree with distinguished boundary leaves. For boundary vertices `i, j`, define the tropical lens kernel
\[
L_T(i,j) := \text{directed path weight from } i \text{ to } j,
\]
or in the undirected tree case simply the unique path length. Enrich this by incidence/separation data indicating which internal edges lie on the geodesic between leaves. From this data, define an idempotent tropical semimodule `G(T)` generated by:
1. boundary distance vectors,
2. split/edge-separation functionals,
3. optionally rooted depth or ancestor profile vectors if needed for a canonical minimal realization.

The breakthrough theorem should show that for a rigidity class `C` of finite weighted trees:

1. **Full faithfulness / rigidity:** if `G(T₁) ≅ G(T₂)` as minimal separated tropical semimodules, then `T₁ ≅ T₂` as weighted rooted trees.
2. **Realization / essential surjectivity:** every finitely generated minimal separated geodesic semimodule satisfying the tropical tree axioms arises as `G(T)` for a unique `T ∈ C`.
3. **Certified reconstruction:** there is a canonical algorithm extracting the combinatorial tree type and edge weights from a finite generating set of `G(T)`, with proof of correctness.

This is not just “tree metrics in Lean.” The ambition is to prove that the *correct tropical linearization of geodesic data* is equivalent to finite tree geometry.

## Minimal Mathematical Definitions You Should Introduce

You need a mathematically sharp class, not a vague graph universe. Restrict early to make the theorem true and formalizable.

### Suggested rigidity class `C`
Use finite rooted trees with:
- positive edge weights,
- no unary internal vertices in the minimal realization,
- every internal edge inducing a nontrivial boundary split,
- boundary leaves separating all internal edges,
- unique geodesics between leaves.

This avoids non-identifiability from zero-length edges and suppressed degree-2 vertices.

### Suggested semimodule generators
For boundary set `B`, define generators in `α^B` or `α^(B×B)` by:
- leaf distance profiles `d_b : B → α`, `d_b(x)=dist(b,x)`,
- split functionals `σ_e : B → α` or cut pseudometrics associated to internal edges,
- pairwise kernel rows `L(i, ·)`.

A decisive move would be to prove that in trees, the semimodule generated by pairwise distance rows coincides with the semimodule generated by split metrics, and that the minimal generating set is exactly the internal edge split basis plus rooted offsets. That is the algebraic heart of the duality.

## Proof Architecture: Three Viable Strategies

### Strategy A: Split-Decomposition First, Semimodule Second
**Most promising for formalization.**

1. **Recover split pseudometrics from semimodule extremals.**
   Show that under minimality + separation, extremal generators correspond to indecomposable edge-separation functionals.
2. **Prove compatibility of extremals using the tropical four-point axiom.**
   Translate the classical Buneman compatibility criterion into inequalities among generators.
3. **Reconstruct the tree from compatible weighted splits.**
   Use a finite split system realization theorem, then prove the reconstructed tree has semimodule isomorphic to the original one.

Why this is strongest: Buneman-style split recovery is combinatorial and finite, making it easier to formalize than a direct category-theoretic equivalence. It also naturally exposes uniqueness.

### Strategy B: Full-Faithfulness via Morphism Reconstruction
1. Define a functor `geodesicSemimodule : TreeCat ⥤ TropSemiModCat`.
2. Show any semimodule isomorphism preserves extremal split generators and hence preserves boundary partitions.
3. Reconstruct a unique tree isomorphism from the preserved split system and verify weighted compatibility.

Why useful: this yields a cleaner “duality” theorem and may leverage existing categorical infrastructure if available. It is conceptually elegant but likely heavier in Lean.

### Strategy C: Metric Injective Hull / Tropical Convexity Route
1. Embed boundary distance data into a tropical polyhedral object or injective hull.
2. Show that for tree metrics this hull has 1-dimensional cell structure exactly matching the original tree.
3. Identify the geodesic semimodule with the semimodule of tropical affine functionals on that hull, giving reconstruction.

Why visionary: this connects tropical convexity, tight spans, and inverse geometry. It may be the deepest route conceptually, but likely too ambitious for the first theorem unless Mathlib already has strong convexity infrastructure.

**Recommendation:** Execute Strategy A for the formal core, borrow the language of Strategy B for the theorem statement, and record Strategy C in `FUTURE_DIRECTIONS.md` as the path to a tropical injective-hull theory of inverse problems.

/-- A weighted acyclic graph with source and sink boundary embeddings.

    internal vertices, and are measured at sinks. -/
structure WeightedAcyclicGraph (K : Type u) (B : Type u) [Zero K] where
  /-- The vertex type -/
  V : Type u
  /-- Vertices form a finite type -/
  [instFintypeV : Fintype V]
  /-- Decidable equality on vertices -/
  [instDecidableEqV : DecidableEq V]
  /-- Source boundary embedding (where signals enter) -/
  sourceEmb : B ↪ V
  /-- Sink boundary embedding (where signals are measured) -/
  sinkEmb : B ↪ V
  /-- Layer assignment enforcing acyclicity -/
  layer : V → ℕ
  /-- Edge weight function (0 = no edge) -/
  weight : V → V → K
  /-- Acyclicity: edges only go from lower to higher layers -/
  edge_respects_layer : ∀ u v, weight u v ≠ 0 → layer u < layer v

attribute [instance] WeightedAcyclicGraph.instFintypeV
  WeightedAcyclicGraph.instDecidableEqV

/-! ## Section 2: Transfer Matrix via Path Aggregation -/

/-- Matrix power: `matPow G n i j` sums over all length-n paths from i to j. -/
noncomputable def matPow (G : WeightedAcyclicGraph K B) :
    ℕ → (G.V → G.V → K)
  | 0 => fun i j => if i = j then 1 else 0
  | n + 1 => fun i j => ∑ k : G.V, G.weight i k * G.matPow n k j

/-- All-paths transfer: sum of path weights up to given length bound. -/
noncomputable def allPathsTransfer (G : WeightedAcyclicGraph K B)
    (bound : ℕ) (i j : G.V) : K :=
  ∑ k ∈ Finset.range (bound + 1), G.matPow k i j

/-- The boundary-to-boundary transfer matrix: source b₁ to sink b₂. -/
noncomputable def transferMatrix (G : WeightedAcyclicGraph K B)
    (b₁ b₂ : B) : K :=
  G.allPathsTransfer (Fintype.card G.V) (G.sourceEmb b₁) (G.sinkEmb b₂)

/-- Number of internal vertices (total minus boundary). -/
noncomputable def internalVertexCount (G : WeightedAcyclicGraph K B) : ℕ :=
  Fintype.card G.V - 2 * Fintype.card B

structure IdempotentSubsemimodule (K : Type u) (B : Type u) [CommSemiring K] where
  carrier : Set (B → K)
