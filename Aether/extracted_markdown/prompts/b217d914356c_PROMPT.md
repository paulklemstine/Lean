# Research Direction 1: Residue-Class Covering for Primitive Beal Triples

## Vision

Do **not** merely run computations. Formalize the *metatheorem* that if a finite family of moduli annihilates all primitive residue patterns, then Beal for a fixed exponent triple reduces to a finite contradiction. This creates a new object: a **covering certificate for exponential Diophantine equations**.

The breakthrough is not “checked many moduli.” The breakthrough is:

> a certified finite obstruction calculus for primitive generalized Fermat-type equations.

If successful, this opens a path to machine-checkable “modular unsatisfiability certificates” for entire families of Diophantine equations, analogous in spirit to SAT certificates, but in arithmetic geometry.

## Precise theorem target

For fixed exponents `x y z : ℕ`, define the primitive residue solution set modulo `m` by
\[
\mathrm{Sol}(m;x,y,z)
=
\{(a,b,c)\in (\mathbb Z/m\mathbb Z)^3 :
a^x+b^y=c^z,\ \gcd(a,b)=\gcd(b,c)=\gcd(a,c)=1 \text{ mod } m\}.
\]

The key theorem should say:

> If there exists a finite set of moduli \(M\) such that no integer triple \((A,B,C)\) can simultaneously realize residue classes lying in all corresponding local primitive solution sets, then there is no pairwise coprime integer solution to \(A^x+B^y=C^z\).

But go further: formulate this using the single modulus \(N = \prod_{m\in M} m\) when the moduli are pairwise coprime, via CRT. Then “finite covering” becomes **emptiness of a primitive solution set modulo one certified modulus**.

### Lean 4 type signature target

A robust formal target is:

```lean
theorem no_primitive_beal_of_empty_zmod_pattern
  (x y z N : ℕ)
  (hx : 2 < x) (hy : 2 < y) (hz : 2 < z)
  (hN : 0 < N)
  (hempty :
    ¬ ∃ a b c : ZMod N,
      IsCoprime (a.val) (b.val) ∧
      IsCoprime (b.val) (c.val) ∧
      IsCoprime (a.val) (c.val) ∧
      a ^ x + b ^ y = c ^ z) :
  ¬ ∃ A B C : ℕ,
      Nat.Coprime A B ∧ Nat.Coprime B C ∧ Nat.Coprime A C ∧
      A ^ x + B ^ y = C ^ z
```

This signature may need adaptation because `a.val` in `ZMod N` is not canonical enough for gcd reasoning. A better architecture is to define a predicate on natural representatives:

```lean
def PrimitiveResidueSolution (N x y z : ℕ) : Prop :=
  ∃ a b c : ℕ,
    a < N ∧ b < N ∧ c < N ∧
    Nat.Coprime a b ∧ Nat.Coprime b c ∧ Nat.Coprime a c ∧
    (a ^ x + b ^ y) % N = (c ^ z) % N
```

Then target:

```lean
theorem no_primitive_beal_of_no_primitive_residue_solution
  (N x y z : ℕ)
  (hx : 2 < x) (hy : 2 < y) (hz : 2 < z)
  (hN : 0 < N)
  (hres : ¬ PrimitiveResidueSolution N x y z) :
  ¬ ∃ A B C : ℕ,
      Nat.Coprime A B ∧ Nat.Coprime B C ∧ Nat.Coprime A C ∧
      A ^ x + B ^ y = C ^ z
```

This theorem is elementary but conceptually decisive: it turns any computational emptiness certificate modulo `N` into a fully formal obstruction theorem.

### Stronger CRT compression theorem

If you can define local solution predicates, prove the compression statement:

```lean
theorem primitive_residue_solution_crt
  {S : Finset ℕ} (hpairwise : S.Pairwise Coprime)
  (hpos : ∀ m ∈ S, 0 < m) :
  let N := ∏ m in S, m
  PrimitiveResidueSolution N x y z ↔
  ∀ m ∈ S, PrimitiveResidueSolution m x y z
```

This exact statement may require weakening to one direction first. Even the forward implication is useful. The reverse implication is the breakthrough: a finite family of local obstructions can be compressed into one modulus.

## Why this would be revolutionary

A theorem of this form creates a new formal language for attacking open Diophantine problems:

- **finite obstruction certificates**
- **CRT-compressed arithmetic unsatisfiability**
- **formal local-global refutation workflows**

This is not a tiny Beal lemma. It is a framework that could later be applied to:

- generalized Fermat equations
- Catalan/Mihăilescu-style residue exclusions
- signature-based S-unit equations
- formal verification of arithmetic impossibility claims

## Proof strategy options

### Strategy A: Direct residue descent from a hypothetical integer solution
1. Assume a primitive integer solution `A^x + B^y = C^z`.
2. Reduce `A, B, C` modulo `N` using least nonnegative residues.
3. Show pairwise coprimality descends: from `Nat.Coprime A B`, derive `Nat.Coprime (A % N) (B % N)` only in the sense needed for the chosen residue predicate; if this exact descent is false, redefine the residue predicate to require compatibility with global coprimality rather than literal residue gcd.
4. Conclude a contradiction with `hres`.

**Most promising**, but only if you choose the predicate correctly. The crucial design decision is to avoid a false lemma about gcd of residues. Use “primitive modulo `N`” in the stronger sense `Nat.Coprime a N`, `Nat.Coprime b N`, `Nat.Coprime c N`, together with pairwise coprimality of representatives if needed.

### Strategy B: Prime-divisor support formulation
Redefine the local primitive condition not by pairwise gcd of residues, but by *avoidance of prime divisors of the modulus*:
\[
\gcd(A B C, N)=1.
\]
Then prove:
1. A pairwise coprime integer solution gives residues modulo `N` satisfying the congruence.
2. If additionally one restricts to primitive solutions with `Nat.Coprime (A*B*C) N`, then emptiness of this local set forbids such solutions.
3. Build covering certificates from moduli whose prime supports are chosen to force this coprimality condition.

This is formally cleaner and better aligned with CRT.

### Strategy C: Chinese remainder theorem as a finite-state machine
1. Define the local state space of allowable residues modulo `m`.
2. Prove compatibility of states under pairwise coprime moduli.
3. Show global states modulo `N = ∏ m` correspond exactly to tuples of local states.
4. Conclude emptiness globally from local-cover incompatibility.

This is the deepest and most reusable strategy. It transforms the problem into a finite automaton on residue states. If possible, prioritize this architecture.

- **Complexity theory:** the local state space for exponent signatures behaves like a constraint satisfaction problem over finite rings.
- **Programming language semantics:** CRT compression is a compositional semantics for modular constraints.
- **Cryptography:** power-residue compatibility tables are cousins of discrete-log image sets and subgroup-membership filters.

# Research Direction 2: Quantitative ABC Threshold Sufficient for Beal

## Vision

The existing theorem `abc_int_implies_no_primitive_beal_K2` is not the endpoint. It is the first point on a **threshold curve**. Your job is to formalize that curve.

The right breakthrough statement is not “ABC implies Beal in one case.” It is:

> an explicit formula converting any integer-ABC exponent \(K\) into a forbidden region in Beal exponent space.

That creates a *phase diagram* for conditional Diophantine impossibility.

## Precise theorem target

Suppose one has an integer-ABC statement of the form
\[
c \le \operatorname{rad}(abc)^K
\]
for coprime positive integers \(a+b=c\). For a primitive Beal solution
\[
A^x+B^y=C^z,\qquad \gcd(A,B)=\gcd(B,C)=\gcd(A,C)=1,
\]
one expects
\[
C^z \le \operatorname{rad}(ABC)^K \le (ABC)^K \le C^{K(\frac1x+\frac1y+\frac1z)z}
\]
or a nearby inequality depending on the exact formal setup. Thus contradiction follows whenever
\[
1 > K\Big(\frac1x+\frac1y+\frac1z\Big).
\]
A clean sufficient criterion is obtained from the lower bound \(x,y,z \ge n\), yielding contradiction if
\[
1 > \frac{3K}{n},
\quad\text{i.e.}\quad n > 3K.
\]

This is more conceptual than the currently stated threshold \(2 + 2/\varepsilon_0\), and it may expose where the existing “7th power trick” is losing sharpness.

### Lean 4 theorem signature target

First define the abstract ABC hypothesis you actually use:

```lean
def IntAbcBound (K : ℕ) : Prop :=
  ∀ a b c : ℕ,
    0 < a → 0 < b → a + b = c →
    Nat.Coprime a b →
    c ≤ (rad (a * b * c)) ^ K
```

Then target a theorem like:

```lean
theorem abc_int_implies_no_primitive_beal_of_reciprocal_bound
  (K x y z : ℕ)
  (hABC : IntAbcBound K)
  (hx : 0 < x) (hy : 0 < y) (hz : 0 < z)
  (hrec : (K : ℚ) * ((1 : ℚ) / x + (1 : ℚ) / y + (1 : ℚ) / z) < 1) :
  ¬ ∃ A B C : ℕ,
      0 < A ∧ 0 < B ∧ 0 < C ∧
      Nat.Coprime A B ∧ Nat.Coprime B C ∧ Nat.Coprime A C ∧
      A ^ x + B ^ y = C ^ z
```

If rationals are too painful initially, prove the coarser but easier corollary:

```lean
theorem abc_int_implies_no_primitive_beal_of_uniform_exponent_bound
  (K n : ℕ)
  (hABC : IntAbcBound K)
  (hn : 3 * K < n) :
  ¬ ∃ A B C x y z : ℕ,
      0 < A ∧ 0 < B ∧ 0 < C ∧
      n ≤ x ∧ n ≤ y ∧ n ≤ z ∧
      Nat.Coprime A B ∧ Nat.Coprime B C ∧ Nat.Coprime A C ∧
      A ^ x + B ^ y = C ^ z
```

This theorem would be major: it gives a formal, explicit map from `K` to a no-solution region.

## Build directly on the catalog theorem

Use `abc_int_implies_no_primitive_beal_K2` as the base case and abstract its proof skeleton:

1. isolate the lemma converting primitive Beal to an ABC instance on
   \[
   a=A^x,\quad b=B^y,\quad c=C^z;
   \]
2. isolate the radical estimate
   \[
   \operatorname{rad}(A^x B^y C^z)=\operatorname{rad}(ABC);
   \]
3. isolate the growth comparison from
   \[
   C^z \le \operatorname{rad}(ABC)^K
   \]
   to contradiction using lower bounds on exponents.

If these are packaged cleanly, then `K = 2`, `K = 3`, and general `K` become one theorem with corollaries, not separate proofs.

## Proof strategy options

### Strategy A: Generalize the existing proof parametrically in `K`
1. Refactor `abc_int_implies_no_primitive_beal_K2` into reusable lemmas:
   - primitive power sum gives coprime ABC triple,
   - radical of powers collapses to radical of bases,
   - upper bound `rad (A*B*C) ≤ A*B*C`,
   - growth contradiction from exponent inequalities.
2. Replace every hard-coded `2` by a variable `K`.
3. Prove a coarse threshold first, e.g. `3*K < n`.

**Most promising** because it converts an existing successful proof into a theorem schema.

### Strategy B: Rational reciprocal inequality
1. Work in `ℚ` or `ℝ` with inequalities involving `1/x + 1/y + 1/z`.
2. Derive
   \[
   A B C \le C^{z(1/x+1/y+1/z)}
   \]
   from `A^x ≤ C^z`, `B^y ≤ C^z`, `C^z = C^z`.
3. Combine with ABC to contradict `K(1/x+1/y+1/z) < 1`.

This is mathematically cleaner and sharper, but formalizing reciprocal inequalities in Lean may be heavier.

### Strategy C: Integer-only exponent clearing
1. Avoid rationals entirely by raising inequalities to a common exponent.
2. Encode the reciprocal condition as an integer inequality after multiplying by `x*y*z`.
3. Derive contradiction using monotonicity of powers.

Less elegant, but perhaps more Lean-friendly and better for minimizing sorry.

## Sharpening target: beyond the “7th power trick”

You should explicitly investigate whether the current argument is lossy because of an unnecessarily high power amplification. The theorem to seek is:

> the minimal integer function `Threshold(K)` such that `IntAbcBound K` implies no primitive Beal solution whenever `x,y,z ≥ Threshold(K)`.

Even proving bounds
\[
3K+1 \le \mathrm{Threshold}(K) \le 7K
\]
would already create a new quantitative theory.

A particularly compelling formal corollary would be:

```lean
corollary abc_K3_implies_no_primitive_beal_exp_gt_9
  (hABC : IntAbcBound 3) :
  ¬ ∃ A B C x y z : ℕ,
      0 < A ∧ 0 < B ∧ 0 < C ∧
      10 ≤ x ∧ 10 ≤ y ∧ 10 ≤ z ∧
      Nat.Coprime A B ∧ Nat.Coprime B C ∧ Nat.Coprime A C ∧
      A ^ x + B ^ y = C ^ z
```

Then try to beat `10` by sharper inequalities.

## Why this would be revolutionary

This turns a qualitative conditional implication into a **quantitative phase transition theorem**. It would:

- calibrate the exact strength of ABC needed for Beal,
- separate what is genuinely “ABC-hard” from what is merely proof-loss,
- create a formal bridge between radical bounds and exponent geometry,
- suggest analogous threshold diagrams for other generalized Fermat equations.

This is the beginning of a new program: **conditional Diophantine threshold theory**.
