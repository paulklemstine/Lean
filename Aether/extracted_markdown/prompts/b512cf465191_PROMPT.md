theorem berggren_matrixOfWord_injective

#### 3. Matrix-entry separation for distinct bounded words

To turn freeness into modular collision resistance, prove an explicit integer separation bound. A very usable form is:

```lean
def matrixSupNorm (M : Matrix (Fin 3) (Fin 3) ℤ) : ℤ :=
  Finset.sup Finset.univ (fun i =>
    Finset.sup Finset.univ (fun j => Int.natAbs (M i j))) 

theorem berggren_distinct_words_entry_separated
  {w₁ w₂ : List (Fin 3)}
  (hneq : w₁ ≠ w₂) :
  ∃ i j : Fin 3,
    (berggrenMatrixOfWord w₁) i j ≠ (berggrenMatrixOfWord w₂) i j
```

Then strengthen to a quantitative bound on the difference size for bounded words:

```lean
theorem berggren_distinct_words_diff_norm_pos
  {w₁ w₂ : List (Fin 3)}
  (hneq : w₁ ≠ w₂) :
  1 ≤ matrixSupNorm (berggrenMatrixOfWord w₁ - berggrenMatrixOfWord w₂)
```

The real cryptographic payoff comes from an upper bound on norms of length-`L` words:

```lean
theorem berggren_matrix_norm_upper_bound
  ∃ C > (1 : ℤ), ∀ w : List (Fin 3),
    matrixSupNorm (berggrenMatrixOfWord w) ≤ C ^ w.length
```

Combined with the positivity/growth structure, this lets you say that if two distinct bounded words coincide modulo `N`, then a nonzero integer difference of size `< N` would have to be divisible by `N`, impossible.

#### 4. Bounded-length modular collision-separation

This is the central theorem. State it with an explicit threshold in terms of a growth constant. One Lean-feasible form is:

```lean
def badPrimes : Finset ℕ := {2, 3, 5} -- enlarge if needed

def hashState (N : ℕ) (w : List (Fin 3)) : Fin 3 → ZMod N :=
  fun i => ((tripleOfWord w) i : ZMod N)

theorem berggren_hash_injective_up_to_log
  ∃ K : ℕ, ∀ N : ℕ, 2 ≤ N →
    ∀ w₁ w₂ : List (Fin 3),
      w₁.length ≤ Nat.floor (Real.log N / K) →
      w₂.length ≤ Nat.floor (Real.log N / K) →
      hashState N w₁ = hashState N w₂ →
      w₁ = w₂
```

If the `Real.log` interface becomes annoying, replace it with a cleaner exponential criterion:

```lean
theorem berggren_hash_injective_below_exp_threshold
  ∃ C : ℕ, 1 < C ∧
    ∀ N w₁ w₂,
      C ^ w₁.length < N →
      C ^ w₂.length < N →
      hashState N w₁ = hashState N w₂ →
      w₁ = w₂
```

This theorem is mathematically strong and cryptographically interpretable: the quotient map is injective on the radius-`L` ball whenever `N` dominates the maximal coefficient growth at depth `L`.

A sharper matrix-action version is excellent if manageable:

#### 5. Injectivity radius / tree-likeness of the quotient action graph

Define the finite directed graph whose vertices are reduced modulo-`N` states and whose outgoing edges apply the three Berggren generators. Then prove that bounded balls around the root are tree-like up to logarithmic radius.

A concise graph-theoretic statement:

```lean
theorem berggren_quotient_ball_injective
  ∃ C : ℕ, 1 < C ∧
    ∀ N L,
      C ^ L < N →
      Set.InjOn (hashState N) {w | w.length ≤ L}
```

From this derive a combinatorial growth lower bound for reachable states:

```lean
theorem berggren_quotient_ball_card_ge
  ∃ c : ℕ, 1 < c ∧
    ∀ N L,
      c ^ L < N →
      c ^ L ≤ Fintype.card {x // ∃ w : List (Fin 3), w.length ≤ L ∧ hashState N w = x}
```

Even more concretely, if you define the image finite set explicitly, prove:

```lean
theorem berggren_ball_cardinality_eq_word_count
  ∀ N L, sufficientlyLarge N L →
    Fintype.card (Set.range (fun w : {w : List (Fin 3) // w.length ≤ L} => hashState N w))
      = ∑ k in Finset.range (L+1), 3^k
```

This is a bona fide injectivity-radius theorem: the finite quotient graph looks like the 3-ary Berggren tree up to depth `L`.

### Proof strategy architecture

#### Strategy A: Free semigroup via Berggren tree uniqueness, then modular injectivity via size bounds
This is the most promising route.

1. **Formalize the root action and positivity.**
   Show each generator sends primitive positive triples to primitive positive triples, and strictly increases the hypotenuse on the root orbit.
   Key lemmas to establish:
   ```lean
   theorem berggren_gen_preserves_positive_primitive : ...
   theorem berggren_gen_hypotenuse_increases : ...
   theorem berggren_word_preserves_positive_primitive : ...
   ```

2. **Establish parent uniqueness / reverse reduction.**
   The classical Berggren tree has a unique parent map on non-root primitive triples. Define an inverse-selection function on the orbit and prove:
   ```lean
   theorem berggren_parent_unique :
     ∀ t, inRootOrbit t → t ≠ rootTriple → ∃! g : Fin 3, ∃ t', generator g ⬝ t' = t
   ```
   This yields injectivity of `tripleOfWord` by induction on word length. This is the deepest structural step, but it converts freeness into a canonical normal form.

3. **Prove coefficient growth bounds.**
   Show every generator has nonnegative large entries in the relevant cone, so applying a word forces exponential growth of the hypotenuse and gives an upper bound on matrix coefficients by repeated norm submultiplicativity.
   Useful forms:
   ```lean
   theorem matrixSupNorm_mul_le :
     matrixSupNorm (M ⬝ N) ≤ 3 * matrixSupNorm M * matrixSupNorm N
   theorem berggren_norm_submultiplicative : ...
   theorem berggren_word_norm_exp_bound : ...
   ```

4. **Convert modular equality into integer equality.**
   If two bounded words have equal hash mod `N`, then every coordinate difference is divisible by `N`. If you also prove these differences have absolute value `< N`, they must be zero. Then invoke freeness.
   Core arithmetic lemma:
   ```lean
   theorem int_eq_zero_of_dvd_and_abs_lt
     {z : ℤ} (hdiv : (N : ℤ) ∣ z) (hz : Int.natAbs z < N) : z = 0
   ```

5. **Derive injectivity radius and graph growth.**
   Since the positive semigroup is free on three generators, the number of words of length `≤ L` is exactly `∑_{k=0}^L 3^k`. Injectivity of the quotient map on that ball implies the same lower bound on reachable states modulo `N`.

Why this route is best: it uses arithmetic and combinatorics already natural in Lean—induction on lists, matrix inequalities, divisibility, finite counting—rather than demanding a fully developed spectral graph package at the outset.

#### Strategy B: Matrix-level freeness from entry recurrences
Alternative if parent uniqueness is cumbersome.

1. Compute the action of each generator on a carefully chosen statistic, e.g. the third row, hypotenuse, or a pair of monotone linear forms.
2. Prove each generator has a signature detectable from the resulting matrix/triple: for example, disjoint inequalities characterizing the first letter.
3. Recover the first letter from the image, then peel it off inductively.
4. This yields direct injectivity of `berggrenMatrixOfWord` or `tripleOfWord` without building the full inverse-tree machinery.

This can be extremely effective if you can identify a partition of the positive cone into three disjoint regions corresponding to the three generators.

#### Strategy C: Congruence-first separation
Useful if exact freeness is already in the catalog.

1. Import existing freeness / orbit uniqueness theorems.
2. Focus on proving that bounded matrix entries are `< N`.
3. Show reduction modulo `N` is injective on the finite set of matrices/triples in the radius-`L` ball.
4. Package this as a collision-resistance theorem for `hashState`.

This is the fastest path if the catalog already contains strong Berggren uniqueness results.

### Why this matters

This program is not merely about one semigroup acting on triples. It creates a rigorous prototype for **algebraic-dynamical hash functions**: noncommutative word growth in an integer semigroup, reduced modulo `N`, with collision resistance certified by an injectivity radius theorem. Berggren’s tree is ideal because it is classical, explicit, arithmetic, and rigid. If you can prove that bounded words remain distinguishable modulo `N` up to logarithmic depth, you have formalized a new cryptographic paradigm in which security comes from Diophantine growth and free-semigroup geometry rather than from lattices or coding theory alone.

Mathematically, this opens at least three new directions:
1. **Arithmetic expansion from Diophantine semigroups:** Berggren dynamics become a testbed for proving expansion or quasi-expansion in thin semigroup quotients.
2. **Certified parameter selection for hashing:** the theorem gives explicit no-collision regimes `L < c log N`, exactly the kind of formally verified asymptotic guidance cryptography needs.
3. **General semigroup-hash infrastructure in Lean:** once built here, the same framework can be transferred to other free matrix semigroups, Apollonian packings, Markoff moves, thin groups, and hyperbolic monoids.

If a full spectral gap emerges, that is a breakthrough. If instead you prove the injectivity radius and exponential support growth theorem cleanly, that is already a mathematically serious and cryptographically meaningful result.

## Summary

This file formalizes the Berggren tree infrastructure and provides a rigorous analysis
of the conjecture that the tropical rank of p-adic valuation matrices derived from
Berggren tree paths equals the number of distinct prime factors of the hypotenuse.

## Conclusion: The Conjecture Is False

The central claim — that `tropicalRank(T_p(N)) = ω(N)` — is **false**, for multiple
independent reasons:

### 1. Dimensional Obstruction (Fatal)
The "path matrix" B(N) has dimensions (path_length × 3), since each Pythagorean triple
is a vector in ℤ³. Therefore its tropical rank is at most min(path_length, 3) ≤ 3.
But ω(N) can be arbitrarily large, so the equality fails for any N with ω(N) > 3.

### 2. Concrete Counterexample: N = 169 = 13²
- Path: (3,4,5) → (21,20,29) → (119,120,169), using B₂ twice.
- For p = 13: T₁₃(169) = [[0,0,0],[0,0,0],[0,0,2]]
- Tropical rank of this matrix is ≥ 2 (proof below: it cannot be written as an
  outer sum a[i] + b[j], since all entries are 0 except the (2,2) entry which is 2).
- But ω(169) = ω(13²) = 1.
- So tropical rank ≥ 2 > 1 = ω(N). **Equality fails.**

### 3. Concrete Counterexample: N = 25 = 5²
- Path: (3,4,5) → (5,12,13) → (7,24,25), using B₁ twice.
- For p = 5: T₅(25) = [[0,0,1],[1,0,0],[0,0,2]]
- Tropical rank ≥ 2 (the Monge condition fails: T[0,0]+T[1,1]=0 ≠ 1=T[0,1]+T[1,0]),
  so the matrix cannot be tropically rank 1.
- But ω(25) = 1. **Equality fails again.**

### 4. Domain Restriction (Fundamental)
Not every N > 1 appears as a hypotenuse of a primitive Pythagorean triple.
For a primitive triple (a,b,c), every prime factor of c must be ≡ 1 (mod 4).
So N = 6, 10, 14, 15, 21, ... have no Berggren path at all, making B(N) undefined.

is ambiguous without choosing a specific triple.

The tropical determinant of T_p(N) is a single element of ℝ ∪ {∞} (a scalar in the
min-plus semiring), not a polynomial. A single scalar does not have a Newton polygon.
The claim that "Newton polygon breakpoints occur at the exponents eᵢ" is therefore
mathematically meaningless as stated.
