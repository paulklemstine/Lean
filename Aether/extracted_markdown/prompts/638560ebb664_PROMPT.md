## Core Definitions You Should Introduce

Work with finite index sets `Fin n`, `Fin d`, matrices over `ℝ`, and row-wise attention.

Let:
- `Q K : Matrix (Fin n) (Fin d) ℝ`
- score matrix `S : Matrix (Fin n) (Fin n) ℝ := fun i j => ∑ k, Q i k * K j k`
- temperature parameter `τ : ℝ`, usually `0 < τ`

Define rowwise log-sum-exp normalization:
- `lse_row τ S i := τ * Real.log (∑ j, Real.exp (S i j / τ))`

Define the finite-temperature log-attention kernel:
- `Lτ i j := S i j - lse_row τ S i`

This is the logarithm of standard softmax attention weights. As `τ → 0+`, one expects
`lse_row τ S i → max_j S i j`,
so
`Lτ i j → S i j - max_k S i k`.

That limit is the tropical projector onto row maxima.

You should also define a tropical matrix product. Since the brief says min-plus but softmax asymptotics are usually max-plus in log coordinates, be explicit and honest: formalize one convention and derive the other by negation. The cleanest route is:

- max-plus product:
  `tropMulMax (A B) i k = sup_j (A i j + B j k)`
- min-plus product via negation:
  `tropMulMin A B = - tropMulMax (-A) (-B)`

For multi-head attention, define product-semiring structure componentwise on `Fin h → Matrix ... ℝ`, or simply use tuples of matrices and prove all operations distribute componentwise.

## Breakthrough Theorem Targets

### Theorem 1: Zero-temperature softmax is tropical row normalization

This is the foundational theorem. State it precisely, with finite-dimensional quantifiers and no handwaving.

**Mathematical statement**

For every finite score matrix `S : Matrix (Fin n) (Fin n) ℝ` with `n ≠ 0`, define
`Lτ i j = S i j - τ * log (∑ k, exp (S i k / τ))` for `τ > 0`.
Then for every `i j`,
\[
\lim_{\tau \to 0^+} L_\tau(i,j) = S(i,j) - \max_k S(i,k).
\]
Equivalently, the logarithm of softmax attention converges pointwise to tropical row normalization.

This is the rigorous content behind “softmax attention is tropical in the log-semiring.”

### Theorem 2: Tropicalization of attention composition

One layer of log-attention acts by a finite-temperature deformation of tropical matrix multiplication. The asymptotic composition law should be tropical.

Let `Aτ, Bτ` be families of log-kernels converging pointwise to tropical matrices `A, B`. Then the finite-temperature composition
\[
C_\tau(i,k) := \tau \log \sum_j \exp((A_\tau(i,j)+B_\tau(j,k))/\tau)
\]
converges to
\[
C(i,k) = \max_j (A(i,j)+B(j,k)).
\]

**Lean 4 target signature**

### Theorem 3: Multi-head attention is computation in a product tropical semiring

Do not settle for a vague statement. Prove a componentwise equivalence.

Let `h : ℕ` be the number of heads. For headwise tropical kernels `A_r`, `B_r`, define product-head composition componentwise:
\[
(A \odot B)_r := A_r \otimes_{\max,+} B_r.
\]
Then the tropicalization of multi-head attention commutes with product decomposition.

### Theorem 4: Attention sinks are tropical fixed points

This is the conceptual heart. Formalize a sink token as an index `s : Fin n` such that one row/column dominates tropical transitions. Then prove existence of a fixed point concentrated at `s` under a suitable tropical attention operator.

One possible formulation:

Define a tropical attention update on score vectors `x : Fin n → ℝ` by
\[
(T_A x)(i) = \max_j (A(i,j) + x(j)) - c_i
\]
for some row normalization `c_i`, e.g. `c_i = max_j A(i,j)`.

A sink condition at `s` could be:
\[
\forall i, \forall j,\quad A(i,s) \ge A(i,j).
\]
Then the indicator potential supported at `s` should be a fixed point, or at least a post-fixed point:
\[
T_A(\delta_s)=\delta_s
\quad\text{or}\quad
T_A(\delta_s)\le \delta_s
\]
depending on normalization.

**Lean 4 target signature**
```lean

  fun i =>
    Finset.univ.sup' Finset.univ_nonempty (fun j : Fin n => A i j + x j) -
    Finset.univ.sup' Finset.univ_nonempty (fun j : Fin n => A i j)

  fun j => if j = s then 0 else (-1)

    (s : Fin n)
    (hdom : ∀ i j : Fin n, A i j ≤ A i s) :

  sorry
```

You may need a cleaner codomain than `(-1)`; perhaps use `⊥`-style values via `WithBot ℝ`, or instead formulate fixed points modulo additive constants:
\[
T_A x = x + c.
\]
That is actually more natural in tropical spectral theory.

Use `tropical_ctc_fixed_point_exists` as a template or abstraction source. If there is already a fixed-point framework in the codebase, refactor attention into that framework rather than proving this ad hoc.

**Why this is a breakthrough**

The “attention sink” phenomenon is widely observed empirically and poorly understood mathematically. A tropical fixed-point theorem would be the first mechanistic theorem that predicts sink formation from dominance inequalities, not from black-box training lore.

### Theorem 5: Deep transformer convergence is controlled by tropical spectral radius / maximum cycle mean

This is the most ambitious theorem and the one with the highest payoff.

For a square tropical matrix `A`, define its max-plus spectral radius `ρₜ(A)` as the maximum cycle mean:
\[
\rho_t(A) = \max_{\gamma \text{ cycle}} \frac{w(\gamma)}{|\gamma|}.
\]

Then prove a growth law for iterates:
\[
(A^{\otimes k} x)(i) = k \rho_t(A) + O(1)
\]
uniformly in `i` under irreducibility / strong connectivity assumptions.

A weaker but still significant formal target is a two-sided bound:
\[
\max_i (A^{\otimes k}x)(i) \le k\rho_t(A) + C,
\qquad
\max_i (A^{\otimes k}x)(i) \ge k\rho_t(A) - C.
\]

If a full cycle-mean formalization is too large for one cycle, prove a spectral upper bound using the existing theorem `spectral_weight_product_bound` as a bridge theorem.

## Proof Strategy Architecture

### Strategy A: Finite-temperature asymptotics via log-sum-exp inequalities
Most promising for Theorems 1 and 2.

1. Prove the elementary finite-set inequality for any finite family `a_j`:
   \[
   \max_j a_j \le \tau \log \sum_j e^{a_j/\tau}
   \le \max_j a_j + \tau \log N.
   \]
   Here `N = card` of the finite index set.

2. Deduce convergence as `τ → 0+` by squeeze:
   \[
   \tau \log \sum_j e^{a_j/\tau} \to \max_j a_j.
   \]

3. Apply pointwise with `a_j = S i j` or `a_j = A i j + B j k`.

This is the cleanest route and should be fully Leanable using finite sums, `Real.log`, `Real.exp`, positivity lemmas, and basic limit machinery.

Why this is best: it avoids measure theory, avoids general large deviation theory, and gives exact finite-dimensional statements sufficient for transformer applications.

---

### Strategy B: Abstract idempotent dequantization / Maslov limit
Best for conceptual organization and future generalization.

1. Define the deformed addition
   \[
   a \oplus_\tau b := \tau \log(e^{a/\tau} + e^{b/\tau}),
   \]
   then prove `a ⊕_τ b → max(a,b)` as `τ → 0+`.

2. Extend inductively from binary sums to finite sums over `Fin n`.

3. Show matrix composition with `⊕_τ` and `+` converges to max-plus matrix multiplication.

This strategy is more elegant and semiring-theoretic. It is likely the best route if you want a reusable library for “dequantization to tropical algebra” that can later power HMMs, CTC, dynamic programming, and energy-based models.

---

### Strategy C: Fixed-point and spectral route through monotone operators
Best for Theorems 4 and 5.

1. Prove `tropAttentionOp A` is monotone and commutes with additive constants:
   \[
   x \le y \Rightarrow T_A x \le T_A y,\qquad T_A(x+c)=T_A(x)+c.
   \]

2. Under a sink dominance assumption, show a distinguished vector is a fixed point or projective fixed point.

3. For iterates, prove subadditive or growth bounds and invoke a tropical/nonlinear Perron–Frobenius pattern. If a full theorem is too hard, prove bounded projective diameter or eventual dominance under a unique maximizing cycle.

This strategy should exploit `tropical_ctc_fixed_point_exists` and `spectral_weight_product_bound`. Even if the exact tropical spectral radius is not fully formalized this cycle, a robust upper-bound theorem will already be publishable-grade infrastructure.
