## Assignment: 2. Eventual Periodicity Transfer via Semiconjugacy

**Mode:** `prove`

Prove a genuinely reusable bridge theorem in discrete dynamics that should become a canonical lemma for transporting orbit structure across models. This is not merely a one-line iterate manipulation: formalize the exact transfer principle cleanly enough that it can serve as infrastructure for future work in symbolic dynamics, automata, coding theory, finite-state compression, and any setting where one system is a deterministic image of another.

The immediate target is the basic semiconjugacy transfer theorem below. But the real objective is to package it in a way that unlocks a whole ecosystem of orbit-transport results.

### Core Breakthrough Target

A semiconjugacy is the formal language of “observation” or “encoding” of one dynamical system by another. If eventual periodicity survives under semiconjugacy, then every certified recurrence theorem on the source side can be pushed forward to a recurrence theorem on the observed side. This is the seed of a **general transfer calculus for dynamics under morphisms**.

The theorem is elementary mathematically, but strategically profound in Lean: once certified, it becomes the glue between existing orbit-existence theorems and downstream applications in finite dynamical systems, coding, and symbolic computation.

### Precise Theorem Statement

```lean
/-- If `f` has an eventually periodic orbit at `x`, and `h` semiconjugates `f` to `g`,
then `g` has an eventually periodic orbit at `h x`. -/
theorem semiconj_eventually_periodic
    {α β : Type*} {f : α → α} {g : β → β} {h : α → β}
    (hsemi : Function.Semiconj h f g)
    {x : α} {m n : ℕ}
    (hn : 0 < n)
    (hev : f^[m + n] x = f^[m] x) :
    g^[m + n] (h x) = g^[m] (h x)
```

### Stronger Theorem You Should Also Try to Prove

The statement above does not actually use `hn : 0 < n`. That is a signal: the true theorem is stronger and cleaner.

```lean
/-- Semiconjugacy transports iterate equalities exactly. -/
theorem semiconj_iterate_eq
    {α β : Type*} {f : α → α} {g : β → β} {h : α → β}
    (hsemi : Function.Semiconj h f g)
    {x : α} {i j : ℕ}
    (hij : f^[i] x = f^[j] x) :
    g^[i] (h x) = g^[j] (h x)
```

Then derive `semiconj_eventually_periodic` as a corollary by instantiating `i := m + n`, `j := m`.

This stronger theorem is the right abstraction: it says **every orbit collision pushes forward through semiconjugacy**. Eventual periodicity is just the first nontrivial special case.

## Proof Strategy Architecture

### Strategy A: Direct iterate transport via `Function.Semiconj`
This is the cleanest and most promising route.

1. Use the semiconjugacy iterate lemma, likely something like:
   - `hsemi.iterate_right`
   - or a theorem equivalent to `hsemi.iterate_eq`
   - or prove by induction that `h (f^[n] x) = g^[n] (h x)`.

2. Apply `congrArg h` to the source equality:
   ```lean
   have h1 : h (f^[i] x) = h (f^[j] x) := congrArg h hij
   ```

3. Rewrite both sides using semiconjugacy on iterates:
   ```lean
   simpa [hsemi.iterate_right] using h1
   ```
   or the exact rewrite form available in Mathlib.

**Why most promising:** minimal dependencies, no extensionality tricks, and directly exposes the categorical meaning of semiconjugacy.

### Strategy B: Induction on iterates to build a reusable transport lemma
If the library theorem names are inconvenient, prove your own intermediate lemma first.

1. Prove:
   ```lean
   have hiter : ∀ n x, h (f^[n] x) = g^[n] (h x)
   ```
   by induction on `n`.

2. Rewrite both sides of `congrArg h hij` using `hiter`.

3. Package `hiter` as a helper theorem for later orbit-transfer work.

**Why valuable:** even if Mathlib already contains the result, a local helper may make later corollaries dramatically easier to state and reuse.

### Strategy C: Orbit-relation viewpoint
This is more conceptual and may pay off if you want a family of corollaries.

1. Define the orbit-collision relation
   ```lean
   R_f x i j :↔ f^[i] x = f^[j] x
   ```
   and similarly for `g`.

2. Show semiconjugacy induces
   ```lean
   R_f x i j → R_g (h x) i j
   ```

3. Deduce eventual periodicity, periodicity, fixed-point transfer, and finite-state recurrence as corollaries.

**Why this matters:** it reframes the theorem as a transport law on orbit relations, opening the door to future abstractions about quotients and factor systems.

theorem semiconj_iterate_eq

    (hsemi : Function.Semiconj h f g)
