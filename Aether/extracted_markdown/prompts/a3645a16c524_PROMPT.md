## Theorem 1: Termination from Strict Lyapunov Descent

### Mathematical statement

For every proof refinement system with strictly decreasing natural-valued energy, every refinement sequence starting from any proof sketch is finite; equivalently, the step relation is well-founded.

### Lean 4 type signature target

```lean
theorem wellFounded_of_energy
    (S : ProofRefinementSystem α σ) :
    WellFounded S.step
```

A more concrete equivalent target, if easier with the catalog:

```lean
theorem no_infinite_descent_of_energy
    (S : ProofRefinementSystem α σ) :
    WellFounded S.step
```

or

```lean
theorem accessible_all_states
    (S : ProofRefinementSystem α σ) (p : α) :
    Acc S.step p
```

### Why this matters

This theorem upgrades the framework from an executable simplifier to a **certified abstract rewrite system**. It is the portal theorem that lets you import techniques from rewriting theory, ordinal descent, and complexity analysis.

### Proof strategy options

**Strategy A: Pull back well-foundedness from `<` on `ℕ`**  
1. Define the measure map `S.energy : α → ℕ`.  
2. Use `measure` / `invImage` style well-foundedness from Mathlib.  
3. Show each `step` is included in the inverse image of `<` under `energy`.  
This is likely the cleanest Lean route.

**Strategy B: Direct accessibility induction on energy**  
1. Prove by induction on `n = S.energy p` that every state of energy `n` is accessible.  
2. For a successor step `p ⟶ q`, use strict decrease to invoke the induction hypothesis.  
3. Conclude `Acc S.step p` for all `p`.  
This is more explicit and may better expose the dynamics interpretation.

**Strategy C: Contradiction via infinite descending chain**  
1. Assume non-well-foundedness to obtain an infinite sequence.  
2. Push forward through `energy` to get an infinite strictly descending chain in `ℕ`.  
3. Contradict well-foundedness of `<` on naturals.  
This is conceptually elegant, though often slightly more cumbersome in Lean.

**Most promising:** Strategy A, because Mathlib’s well-founded machinery around `measure` and `InvImage` should make the proof concise but still mathematically substantial.

## Theorem 2: Semantic Invariance Along Multi-Step Normalization

### Mathematical statement

If a proof sketch `p` refines to `q` through any finite sequence of refinement steps, then `p` and `q` have identical semantics.

### Lean 4 type signature target

Assuming reflexive-transitive closure `Relation.TransGen` or `ReflTransGen`:

```lean
theorem sem_invariant_rtc
    (S : ProofRefinementSystem α σ)
    {p q : α} :
    Relation.ReflTransGen S.step p q → S.sem p = S.sem q
```

If your local framework uses a custom closure, adapt accordingly.

### Why this matters

Single-step semantic preservation is local. This theorem globalizes it: **normalization is not merely terminating, but meaning-preserving end-to-end**. It is the analogue of subject reduction / sound normalization in programming languages and proof theory.

### Proof strategy options

**Strategy A: Induction on reflexive-transitive closure**  
1. Base case: reflexivity gives immediate semantic equality.  
2. Step case: combine `S.sem_invariant` with the induction hypothesis via transitivity.  
3. Use a `calc` chain to make the proof mathematically legible.  
This is the canonical route.

**Strategy B: Factor through list/path encoding of derivations**  
1. Represent a derivation as a finite list of intermediate proof sketches.  
2. Prove semantic invariance along adjacent edges.  
3. Fold equality along the path.  
This may be useful if the existing framework already encodes traces explicitly.

**Strategy C: Quotient-theoretic perspective**  
1. Define the equivalence relation generated by `step` under semantics.  
2. Show every step lies in a semantic kernel relation.  
3. Deduce closure inclusion.  
This is more abstract and may be useful later when defining proof redundancy classes.

**Most promising:** Strategy A, because it is direct, robust, and naturally extends to later canonical-normal-form theorems.

## Theorem 3: Quantitative Normalization Bound

### Mathematical statement

If `p` reduces to a normal form `q`, then the length of any strictly descending refinement chain from `p` is bounded above by `energy p`. In particular, normalization takes at most `energy p` steps.

A precise formulation may depend on whether the catalog already contains a notion of derivation length. You may need to define one.

### Lean 4 type signature target

One acceptable formal target is:

```lean
theorem derivation_length_le_energy
    (S : ProofRefinementSystem α σ)
    (trace : List α)
    (hchain : ∀ i, i + 1 < trace.length →
      S.step (trace.get ⟨i, by omega⟩) (trace.get ⟨i+1, by omega⟩))
    (hstart : trace.head? = some p) :
    trace.length - 1 ≤ S.energy p
```

If you define a custom `Derivation S p q n`, an even better target is:

```lean
theorem normalization_steps_le_energy
    (S : ProofRefinementSystem α σ)
    {p q : α} {n : ℕ}
    (h : Derivation S.step p q n) :
    n ≤ S.energy p
```

### Why this matters

Termination alone is qualitative. This theorem is **complexity theory for proof dynamics**: the Lyapunov function is not just decreasing, it certifies a runtime bound. This turns proof normalization into a controlled algorithm with predictable complexity.

### Proof strategy options

**Strategy A: Induction on derivation length**  
1. Base case `n = 0` is trivial.  
2. In the step case `p ⟶ r` followed by `n` steps, use strict energy decrease `energy r < energy p`.  
3. Combine induction hypothesis and arithmetic to show `n+1 ≤ energy p`.  
This is likely the best route.

**Strategy B: Strictly descending energy list**  
1. Push the derivation to a strictly descending list of naturals.  
2. Prove any strictly descending list starting at `m` has length at most `m+1`.  
3. Transfer the bound back to the proof chain.  
This is elegant and exposes the combinatorial heart.

**Strategy C: Ranking-function theorem**  
1. State and prove a general theorem: any relation admitting a ranking function into `ℕ` has chain length bounded by the rank of the source.  
2. Instantiate it for proof dynamics.  
This is the most reusable and conceptually strongest option.

**Most promising:** Strategy C if you can package it cleanly; otherwise Strategy A for immediate progress.

## Theorem 4: Canonical Normal Form from Local Confluence + Termination

This is the most ambitious theorem and the one most likely to become a flagship result.

### Mathematical statement

For a restricted subsystem generated by operations such as `dropRedundant`, `dropDuplicate`, and `simplifyLemmaLeaf`, assume:
1. termination holds,
2. local confluence holds on one-step critical forks.

Then every proof sketch has a unique normal form.

### Lean 4 type signature target

If using an abstract relation `r`:

```lean
theorem unique_normal_form_of_wellFounded_of_localConfluent
    {r : α → α → Prop}
    (hWF : WellFounded r)
    (hLC : LocalConfluent r) :
    UniqueNormalForm r
```

Or more explicitly:

```lean
theorem normal_form_unique
    {r : α → α → Prop}
    (hWF : WellFounded r)
    (hLC : LocalConfluent r)
    {a n₁ n₂ : α}
    (h1 : Relation.ReflTransGen r a n₁)
    (h2 : Relation.ReflTransGen r a n₂)
    (hn1 : NormalFormRel r n₁)
    (hn2 : NormalFormRel r n₂) :
    n₁ = n₂
```

You may need to define:

```lean
def NormalFormRel (r : α → α → Prop) (a : α) : Prop := ¬ ∃ b, r a b
```

and perhaps:

```lean
def LocalConfluent (r : α → α → Prop) : Prop := ...
def UniqueNormalForm (r : α → α → Prop) : Prop := ...
```

### Why this is a breakthrough

This would transform the framework from “a terminating simplifier” into a **canonical semantics-preserving compression procedure**. Canonical forms are where mathematics becomes classification. If successful, this theorem opens a route to:
- proof deduplication,
- semantic compression metrics,
- canonical representatives of proof equivalence classes,
- algorithmic search in quotient spaces of proofs.

### Proof strategy options

**Strategy A: Formalize Newman’s Lemma**  
1. Define local confluence and global confluence.  
2. Prove Newman’s lemma: well-founded + local confluent ⇒ confluent.  
3. Deduce uniqueness of normal forms from confluence.  
This is the most powerful and reusable route.

**Strategy B: Direct induction on accessibility**  
1. For each accessible state, prove all normalization outcomes join.  
2. Specialize to normal forms and conclude equality.  
3. Use local confluence at the first branching step.  
This may avoid some overhead if Newman is not already in the catalog.

**Strategy C: Critical-pair finite analysis for the restricted subsystem**  
1. Enumerate the finitely many interaction patterns between `dropRedundant`, `dropDuplicate`, `simplifyLemmaLeaf`.  
2. Prove each one-step fork is joinable.  
3. Combine with termination to obtain uniqueness.  
This is the best path if the restricted subsystem is syntactic and concrete.

**Most promising:** Strategy C for the concrete subsystem, possibly feeding into Strategy A as a general theorem. If Mathlib already has enough rewriting infrastructure, Strategy A becomes especially attractive.

## Cross-Domain Theorem Target: Proof Dynamics Meets Information/Compression

You are required to include at least one theorem connecting proof dynamics to a different domain. The strongest candidate here is **information/compression**.

### New concept

Define a redundancy index:

```lean
def redundancyIndex (S : ProofRefinementSystem α σ) (p : α) : ℕ :=
  S.energy p - S.energy (nf p)
```

where `nf` is a chosen normal form operator on a subsystem where uniqueness is proven.

### Theorem statement

If `nf` is semantics-preserving and idempotent, then redundancy index is zero exactly on normal forms.

### Lean 4 type signature target

```lean
theorem redundancyIndex_eq_zero_iff_normalForm
    (S : ProofRefinementSystem α σ)
    (nf : α → α)
    (hnf_fix : ∀ p, NormalForm S (nf p))
    (hnf_sem : ∀ p, S.sem (nf p) = S.sem p)
    (hnf_idem : ∀ p, nf (nf p) = nf p)
    (henergy_nf_le : ∀ p, S.energy (nf p) ≤ S.energy p)
    (hstrict_if_not_nf : ∀ p, ¬ NormalForm S p → S.energy (nf p) < S.energy p)
    {p : α} :
    redundancyIndex S p = 0 ↔ NormalForm S p
```

You may need to tune the assumptions, but the mathematical point is crucial: **normalization measures compressible proof redundancy**.

### Why this matters

This is the bridge theorem. It recasts proof simplification as a form of lossless compression, connecting proof theory to information theory and algorithmic compression. That is exactly the sort of cross-domain leap that can open a new field.
