**Title**: A finite Galois correspondence between closure systems and tropical halfspace hulls
**Domain**: Bridges
**Mathematical framing**: Define a finite closure system `(α, cl)` using `SetClosureOperator` and a finite probe/capacity semantics using `ClosureSemimoduleSystem` or `FiniteClosureSystem`. Construct a map `φ : α → β := Fin n → ℤ` or `ℕ` by assigning to each `x` the vector of probe capacities/closure potentials. For each closed set `C`, define a tropical halfspace `H_C` by coordinate inequalities derived from membership tests or capacity increments. Main target theorem: for finite `S ⊆ α`, `φ '' (cl S) = tropConvexHull (φ '' S) ∩ ⋂_{C closed, S ⊆ C} H_C`, with both inclusions proved constructively. Secondary theorem: if a point lies outside `φ '' (cl S)`, there exists a closed set separating it, yielding a tropical halfspace separator; this is a finite separation theorem analogous to Helly-style tropical convexity and directly leverages/fills the tropical halfspace infrastructure. Algorithmic corollary: compute closure membership by evaluating tropical inequalities instead of iterating closure. A stronger optional direction is to prove a Galois connection between families of probes and families of tropical halfspaces, with fixed points corresponding to irredundant hull descriptions.
**Concept description**: The key insight is that finite closure operators already present in the Algebra↔EML bridge can be turned into an algorithmic tropical convexity engine by representing each closed set as an intersection of finitely many tropical halfspaces, and conversely recovering a closure operator from a separating family of tropical halfspaces. /-! ## Part 1: Tropical Convexity Foundations -/

/-- **Tropical convexity in the max-plus semiring.**
    A set S ⊆ ℝⁿ is tropically convex if for all x, y ∈ S and
    all coefficients s, t with max(s, t) = 0, the tropical combination
    i ↦ max(s + xᵢ, t + yᵢ) lies in S.

    The condition max(s, t) = 0 normalizes the tropical coefficients,
    analogous to requiring s + t = 1 in classical convex combinations. -/
def IsTropConvex {n : ℕ} (S : Set (Fin n → ℝ)) : Prop :=
  ∀ ⦃x y : Fin n → ℝ⦄, x ∈ S → y ∈ S →
    ∀ s t : ℝ, max s t = 0 → (fun i => max (s + x i) (t + y i)) ∈ S

def tropConvexHull {n : ℕ} (T : Set (Fin n → ℝ)) : Set (Fin n → ℝ) :=
  ⋂₀ {S : Set (Fin n → ℝ) | IsTropConvex S ∧ T ⊆ S}
