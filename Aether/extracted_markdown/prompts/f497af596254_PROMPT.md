## Assignment: Post-Quantum Lattices from Pythagorean Triple Groupoids

Mode: **prove**

This direction is only worthwhile if we avoid hand-wavy cryptographic rhetoric and isolate a formally attackable mathematical core. The revolutionary target is **not** to claim a full Regev-style worst-case/average-case reduction for an ad hoc lattice family without the necessary Gaussian machinery already formalized. Instead, you should carve out a sequence of precise bridge theorems showing that:

1. Berggren orbit constructions canonically generate integer lattices from primitive Pythagorean data.
2. These lattices admit nontrivial norm lower bounds and orbit-invariance properties.
3. Primitive-triple search in bounded Berggren orbits can be converted into a shortest-vector style search problem on explicitly constructed lattices.
4. Existing entropy-extraction theorems can then be used to derive a **formal post-quantum security statement** for a toy key exchange built from that search hardness.

If you can certify these steps in Lean, you open a new field: **arithmetically structured post-quantum cryptography from Diophantine groupoid dynamics**. This would connect number theory, lattice cryptography, automata/groupoids, and formalized security reductions.

## Primary Theorem Targets

### Theorem 1: Orbit vectors remain primitive Pythagorean triples

This is the foundational arithmetic rigidity theorem.

**Lean target signature:**
```lean
theorem berggren_orbit_preserves_primitive
  (M : Matrix (Fin 3) (Fin 3) ℤ)
  (hM : M ∈ berggrenMonoid)
  : primitiveTriple (fun i => (M.mulVec rootTriple) i)
```

Here `rootTriple : Fin 3 → ℤ := ![3,4,5]` or equivalent.

A more realistic bounded-depth variant is acceptable:

```lean
theorem berggren_word_preserves_primitive
  (w : List BerggrenGen) :
  primitiveTriple (evalBerggrenWord w rootTriple)
```

This is already a major formalization result if done cleanly, because it certifies an infinite arithmetic source of structured lattice vectors.

### Theorem 2: Nonzero vectors in Berggren-generated lattices have explicit Euclidean lower bound

Do not aim immediately for “SVP as hard as general SVP”; that is likely mathematically false in this form for a highly structured family. Instead prove a rigorous hardness-bridge statement via embedding.

**Lean target signature:**
```lean
theorem berggren_lattice_norm_lower_bound
  (S : Finset (Fin 3 → ℤ))
  (hS : ∀ v ∈ S, primitiveTriple v)
  (x : Fin 3 → ℤ)
  (hx : x ∈ Submodule.span ℤ (↑S : Set (Fin 3 → ℤ)))
  (hne : x ≠ 0) :
  1 ≤ ‖x‖^2
```

If the norm on `Fin 3 → ℤ` is awkward, switch to a concrete quadratic form:

```lean
def sqNorm (v : Fin 3 → ℤ) : ℤ := ∑ i, (v i)^2

theorem berggren_lattice_sqNorm_pos
  ...
  (hne : x ≠ 0) :
  0 < sqNorm x
```

This theorem should build directly on the existing
`berggren_lattice_svp_trivial` from `Cryptography/BerggrenSymplecticCodes.lean`,
but strengthen it from mere nonzeroness/SVP triviality to an explicit quantitative lower bound.

### Theorem 3: Primitive-triple search reduces to bounded shortest-vector search on an explicitly constructed lattice

This is the real bridge theorem. State it as a **search reduction**, not a slogan.

Define a bounded search problem:
- Input: depth bound `d`, norm bound `R`
- Goal: find a primitive Berggren-orbit vector within bound

Construct a lattice whose short vectors encode valid triples.

**Lean target signature sketch:**
```lean
theorem primitive_triple_search_to_bounded_SVP
  (d R : ℕ) :
  ∃ (n : ℕ) (L : Submodule ℤ (Fin n → ℤ)) (β : ℕ),
    ∀ oracle : BoundedSVPSolver n,
      (solvesSVP oracle L β →
        ∃ v : Fin 3 → ℤ,
          primitiveTriple v ∧
          v ∈ boundedBerggrenOrbit d ∧
          sqNorm v ≤ R)
```

If an oracle-based reduction is too elaborate for Lean, prove the constructive encoding theorem that underlies it:

```lean
theorem bounded_berggren_orbit_encodes_as_lattice_vector
  (d : ℕ) :
  ∃ (n : ℕ) (L : Submodule ℤ (Fin n → ℤ)) (encode : Fin 3 → ℤ → Fin n → ℤ),
    ∀ v, v ∈ boundedBerggrenOrbit d → primitiveTriple v →
      encode v ∈ L ∧ shortWitness (encode v)
```

This is the right level of formal cryptographic mathematics: explicit encoding, explicit lattice, explicit norm control.

Use the catalog theorems here rather than making unsupported cryptographic claims.

Let sampled public data be derived from Berggren orbit words, and let the shared secret be hashed. Then combine:

**Berggren orbit unpredictability → min-entropy bound → leftover hash security → post-quantum key security**.

## Why This Would Be a Breakthrough

If successful, this would establish the first fully formalized bridge from:
- classical Diophantine generation of primitive Pythagorean triples,
- to explicit structured lattices,
- to short-vector search encodings,
- to cryptographic security reductions.

That is not an incremental variant of lattice crypto. It proposes a new arithmetic source of hardness with a machine-checked reduction skeleton. Even if the final hardness statement is weaker than “as hard as general SVP,” the formal bridge itself would open a new program:
**Diophantine cryptography with certified reductions.**

## Proof Strategy Architecture

### Strategy A: Arithmetic invariants first, then lattice span, then reduction
Most promising.

1. Formalize Berggren generators and prove each preserves the quadratic form
   `a^2 + b^2 = c^2` and primitivity.
2. Show finite orbit sets generate submodules with explicit nonzero norm positivity.
3. Encode bounded orbit search as a finite combinatorial search over lattice witnesses, then connect to extraction/security theorems.

Why this is best: it matches the available catalog theorems and minimizes dependence on heavy probability or Gaussian lattice machinery not yet certified.

### Strategy B: Parametrization-first via Euclid’s formula
Alternative if Berggren matrix algebra becomes cumbersome.

1. Prove every primitive triple in the orbit has Euclidean parameters `(m,n)` with
   `a = m^2 - n^2`, `b = 2mn`, `c = m^2 + n^2`.
2. Build lattices from parameter pairs rather than directly from triples.
3. Transfer search hardness from parameter recovery to short-vector recovery.

Why useful: this may simplify proofs of primitivity and norm growth. It also gives a direct bridge to algebraic number theory via norms in `ℤ[i]`.

### Strategy C: Automata/groupoid bridge through residual collision bounds
High-risk, high-reward.

1. Treat Berggren words as accepted paths in a residual automaton.
2. Use `post_quantum_security_residual_collision_bound` to bound collisions in public transcripts.
3. Derive entropy lower bounds on word-induced secrets, then invoke leftover hash security.

Why interesting: it creates a deep bridge between symbolic dynamics/groupoids and cryptographic entropy. This could be the truly field-opening angle if the automata formalization is tractable.

## Recommended Order of Attack

1. Define Berggren generators and root triple.
2. Prove preservation of Pythagorean and primitive predicates under each generator.
3. Prove bounded orbit finiteness and extract finite generating sets.
4. Strengthen `berggren_lattice_svp_trivial` to explicit norm positivity/lower bounds.
5. Build an encoding theorem from bounded orbit witnesses to lattice vectors.
6. Only then formulate the cryptographic protocol and security theorem using the catalog entropy results.
