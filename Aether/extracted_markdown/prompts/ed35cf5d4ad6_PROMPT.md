## Breakthrough Target

Classical Schützenberger-type realization says a series is recognizable iff its Hankel matrix has finite rank over a field. The idempotent/tropical world does **not** admit a naive linear-rank transplant: additive idempotency destroys ordinary linear duality, and the correct replacement is **semimodule generation + residuation-stable shift structure**.

Your target is to prove a theorem of the following form:

> For an idempotent residuated semiring `S` and a weighted language `f : List α → S`, finite-state recognizability by a deterministic `S`-weighted automaton is equivalent to finite generation of the tropical Hankel row semimodule together with closure under letter-shift operators and existence of residual actions. Moreover, the minimal deterministic realization is canonically recovered from a finite generating basis of the Hankel semimodule, and its state number is the generator rank of that semimodule.

If formalized cleanly, this opens a new field direction: **tropical system identification via certified semimodule extraction**. It would provide a mathematically sharp and mechanized analogue of classical Hankel realization for max-plus/min-plus computation, symbolic dynamics, shortest-path transducers, and tropical control.

### Main theorem A: Recognizability from finitely generated residuation-stable Hankel semimodule

Mathematical statement:

Let `S` be an idempotent semiring equipped with its natural order and a suitable residual operation on finitely generated subsemimodules. Let `α` be a finite alphabet and `f : List α → S`. Define the Hankel row associated to `u` by
`row_f(u)(v) = f (u ++ v)`.

If the row semimodule generated by `{row_f(u) | u ∈ α*}` is finitely generated by rows `row_f(b_i)` and for every generator `b_i` and letter `a`, the shifted row `row_f(b_i ++ [a])` admits a residual decomposition in the same generated semimodule, then `f` is recognized by a finite deterministic weighted automaton whose states are the basis indices.

Conversely, every finite deterministic weighted automaton recognizing `f` induces a finitely generated shift-stable row semimodule.

### Suggested Lean 4 type signature

You will likely need to adapt class names to available Mathlib infrastructure, but aim for something close to:

```lean
theorem recognizable_iff_fg_residuation_stable_rows
  {S α : Type _}
  [CanonicallyOrderedCommSemiring S]
  [IsIdempotentAdd S]
  [Fintype α] [DecidableEq α]
  (f : List α → S) :
  RecognizableSeries S α f ↔
    ∃ (B : Finset (List α)),
      GeneratesRowSemimodule S α f B ∧
      ResiduationStableRowBasis S α f B
```

If `CanonicallyOrderedCommSemiring` is too restrictive or semiring commutativity is unnecessary, weaken assumptions. If residuals require a custom typeclass, define one explicitly.

### Main theorem B: Minimality and generator rank

Mathematical statement:

Under the hypotheses above, if `B` is a minimal residuation-stable generating family of rows, then the reconstructed automaton has exactly `|B|` states and any deterministic weighted automaton recognizing `f` has at least `|B|` states. Hence `|B|` is the minimal state complexity, i.e. the tropical generator rank of the row semimodule.

### Suggested Lean 4 type signature

```lean
theorem minimal_state_count_eq_row_generator_rank
  {S α : Type _}
  [CanonicallyOrderedCommSemiring S]
  [IsIdempotentAdd S]
  [Fintype α] [DecidableEq α]
  (f : List α → S) :
  ∀ {B : Finset (List α)},
    MinimalResiduationStableRowBasis S α f B →
      stateCount (reconstructAutomaton S α f B) = B.card ∧
      ∀ A : WeightedDeterministicAutomaton S α,
        RecognizesSeries S α A f →
        B.card ≤ stateCount A
```

and prove:

### Main theorem C: Certified finite-block reconstruction

Mathematical statement:

Suppose a finite Hankel block indexed by prefix set `P` and suffix set `T` contains a basis certificate: every row in `P` is generated by basis rows in `B ⊆ P`, and every one-letter extension of a basis row is also representable over `T` with certified residual coefficients. Then one can reconstruct a finite weighted automaton whose behavior agrees with `f` on all words whose relevant factorizations lie inside the certified block; if the block is saturation-complete, the reconstruction is globally correct.

This is the computational theorem. It converts infinite algebra into a finite certificate.

### Suggested Lean 4 type signature

```lean
theorem certified_block_reconstruction
  {S α : Type _}
  [CanonicallyOrderedCommSemiring S]
  [IsIdempotentAdd S]
  [Fintype α] [DecidableEq α]
  (f : List α → S)
  (P T B : Finset (List α)) :
  CertifiedHankelBasisData S α f P T B →
    ∃ A : WeightedDeterministicAutomaton S α,
      CertifiedReconstructionCorrect S α f P T B A
```

A stronger final form would be:

```lean
theorem certified_block_reconstruction_global
  ...
  (hcomplete : SaturatedHankelCertificate S α f P T B) :
  ∃ A : WeightedDeterministicAutomaton S α,
    RecognizesSeries S α A f ∧
    stateCount A = B.card
```

### Secondary theorem D: Uniqueness up to semimodule congruence / automaton isomorphism

Mathematical statement:

If `B₁` and `B₂` are two minimal residuation-stable generating bases for the same row semimodule, then the corresponding reconstructed automata are isomorphic, with the isomorphism induced by the unique semimodule equivalence between the two basis coordinatizations.

### Suggested Lean 4 type signature

```lean
theorem minimal_reconstructions_isomorphic
  {S α : Type _}
  [CanonicallyOrderedCommSemiring S]
  [IsIdempotentAdd S]
  [Fintype α] [DecidableEq α]
  (f : List α → S) :
  ∀ {B₁ B₂ : Finset (List α)},
    MinimalResiduationStableRowBasis S α f B₁ →
    MinimalResiduationStableRowBasis S α f B₂ →
      AutomatonIsomorphic
        (reconstructAutomaton S α f B₁)
        (reconstructAutomaton S α f B₂)
```

## Proof Strategy Architecture

### Strategy A: Direct semimodule realization via basis coordinates
Most promising.

1. Define the row semimodule generated by basis `B`.
2. For each basis row `b` and letter `a`, use residuation-stability to obtain coefficients expressing `row_f (b ++ [a])` in basis coordinates.
3. Use those coefficients as transition weights; define initial/final weights from decomposition of `row_f []` and evaluation at `[]`.
4. Prove by induction on words that the automaton state semantics reproduces the Hankel row of each prefix.
5. Conclude that the automaton recognizes `f`.

Why this is strongest: it is constructive, algorithmically meaningful, and aligns perfectly with the finite-block certification theorem.

---

### Strategy B: Myhill–Nerode for idempotent semimodules
Conceptually deep; likely best for the minimality theorem.

1. Define an equivalence/congruence on prefixes by equality of Hankel rows or equality in the generated semimodule coordinates.
2. Show every deterministic weighted automaton factors through this congruence.
3. Prove minimal basis states correspond to semimodule-distinct row classes.
4. Deduce lower bounds on state count and uniqueness up to isomorphism.

Why this matters: it gives the right analogue of classical syntactic minimization, but in tropical semimodule language.

---

### Strategy C: Finite-block completion and certified reconstruction
Best for the algorithmic corollary.

1. Define finite prefix/suffix restrictions of the Hankel matrix.
2. State a saturation criterion ensuring that basis decomposition data on the block extends to all one-step shifts.
3. Use `certified_finite_tropical_decomposition` to extract basis coordinates.
4. Prove local correctness on the block first, then global correctness under saturation.

Why this is field-opening: it turns the abstract realization theorem into a practical, certifiable inference pipeline.
