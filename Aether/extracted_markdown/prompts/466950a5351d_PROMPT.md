## Assignment: Circuit Lower Bounds from Tropical Spectral Theory

**Mode:** `prove`

Build a genuinely new bridge between **idempotent linear algebra** and **structural complexity theory**. Do not settle for cosmetic “tropicalized” reformulations of known depth inequalities. The goal is to isolate a formally tractable tropical invariant of layered circuits and prove that it forces nontrivial lower bounds on computational resources. If the strongest complexity-class separation statement is out of reach in one cycle, prove the sharpest certified theorem that makes the separation program *constructive*.

The breakthrough vision is this:

> Encode a layered monotone circuit by a weighted min-plus transition matrix.  
> Show that **tropical spectral obstruction** — expressed either as an eigenvalue gap, min-plus cycle mean separation, or min-plus permanent growth — forces large depth or size.  
> This would open a new program: **complexity lower bounds by tropical operator theory**.

This is not an incremental variant of existing tropical-depth results. It proposes a new *mechanism* for lower bounds: spectral rigidity in semiring-linear models.

## Precise Theorem Targets

### Theorem A: Tropical spectral gap forces depth lower bounds

Define a tropical spectral quantity for a weighted square matrix `A`, for example via the gap between the smallest and second-smallest cycle means, or via a certified lower bound already available in the catalog. Then prove a depth lower bound from this gap.

A Lean-oriented target:

```lean
theorem circuit_depth_ge_of_tropical_spectral_gap
  {n d : ℕ} (hn : 2 ≤ n)
  (A : Matrix (Fin n) (Fin n) ℕ)
  (hgap : 1 ≤ tropicalSpectralGap A)
  (hrealizes : CircuitRealizesInDepth A d) :
  tropicalSpectralGap A ≤ d
```

A stronger asymptotic version, if you can define a circuit family:

```lean
theorem superpoly_depth_of_gap_family
  (L : ℕ → Set (List Bool))
  (A : ∀ n, Matrix (Fin (width n)) (Fin (width n)) ℕ)
  (d : ℕ → ℕ)
  (hrealizes : ∀ n, CircuitRealizesLanguage (A n) (L n) (d n))
  (hgap : ∀ n, n ≤ tropicalSpectralGap (A n))
  (hpoly : ¬ EventualPolynomialBound d) :
  True
```

The second theorem is deliberately schematic: if class-separation formalization is too large, replace it by a concrete statement such as `¬ ∃ k, ∀ n, d n ≤ n^k`.

The immediate mathematically meaningful theorem is the first one: a spectral invariant lower-bounds circuit depth.

Build explicitly on:

- `tropical_depth_lower_bound`
- `spectral_gap_lower_bound`

The desired synthesis is: **spectral gap certificate ⇒ tropical depth certificate**.

### Theorem B: Min-plus permanent bounds depth from below

Define a min-plus permanent of a square matrix `A : Matrix (Fin n) (Fin n) ℕ` by

\[
\operatorname{tperm}(A) := \min_{\sigma \in S_n} \sum_i A_{i,\sigma(i)}.
\]

Then prove that sufficiently large min-plus permanent obstructs shallow computation.

Lean target:

```lean
def tropicalPermanent {n : ℕ} (A : Matrix (Fin n) (Fin n) ℕ) : ℕ := ...

theorem tropical_permanent_depth_lower_bound
  {n d : ℕ} (hn : 2 ≤ n)
  (A : Matrix (Fin n) (Fin n) ℕ)
  (hrealizes : CircuitRealizesInDepth A d) :
  tropicalPermanent A ≤ n * d
```

A sharpened version would derive:

```lean
theorem depth_ge_tropicalPermanent_div
  {n d : ℕ} (hn : 1 ≤ n)
  (A : Matrix (Fin n) (Fin n) ℕ)
  (hrealizes : CircuitRealizesInDepth A d) :
  tropicalPermanent A / n ≤ d
```

This is a powerful theorem because it converts a global combinatorial invariant into a computational lower bound. Even if the exact normalization changes during formalization, the principle should survive:

> each layer can only reduce tropical assignment cost by a bounded amount, hence a large tropical permanent forces many layers.

This would be a real contribution: a tropical analogue of rank/rigidity style lower bounds, but semiring-native.

### Theorem C: Tropical matrix powers certify hard language families

For a family of circuit matrices `A_n`, prove that if tropical propagation to acceptance requires at least `f(n)` powers, then any represented language family has depth at least `f(n)`.

Lean target:

```lean
theorem matrix_power_hitting_time_lower_bound
  {n t : ℕ}
  (A : Matrix (Fin n) (Fin n) ℕ)
  (i j : Fin n)
  (hhit : FirstHitTime A i j = t) :
  ∀ d < t, ¬ ReachableInDepth A i j d
```

Then connect `FirstHitTime` to spectral or permanent data. This theorem is strategically excellent because it reduces lower bounds to a **first-passage problem in tropical dynamics**.

## Proof Strategy Paths

### Strategy 1: Layer-by-layer amortization via tropical path growth
**Most promising for Lean.**

1. Prove that one circuit layer changes the relevant tropical potential by at most a bounded amount.
   - For depth: show each matrix multiplication step increases minimal path cost by at most `1` or by a controlled additive constant.
   - For permanent: show one layer contributes at most `n` to tropical assignment cost.

2. Prove by induction on depth `d` that any depth-`d` circuit satisfies:
   - `tropicalSpectralGap A ≤ d`, or
   - `tropicalPermanent A ≤ n * d`.

3. Conclude by contraposition:
   - if gap or permanent exceeds the shallow bound, no depth-`d` realization exists.

Why this is promising:
- uses only finite combinatorics and induction
- fits naturally with `Nat`, `Matrix`, `Finset`
- aligns with existing theorem `tropical_depth_lower_bound`

---

### Strategy 2: Tropical powers and first-hitting-time dynamics
1. Define tropical matrix powers and a notion of first time `t` when an entry achieves the target witness.
2. Prove monotonicity / subadditivity of first-hitting times under layer composition.
3. Relate hitting time to spectral gap or cycle-mean separation:
   - larger gap implies delayed convergence to acceptance
   - delayed convergence yields depth lower bound

Why this is deep:
- turns circuit complexity into discrete dynamical systems
- gives a path toward asymptotic language-family statements
- may connect directly to `spectral_gap_lower_bound`

This strategy is conceptually revolutionary, but may require more infrastructure.

---

### Strategy 3: Assignment/transport duality for tropical permanent
1. Define tropical permanent as minimum assignment cost.
2. Interpret each shallow circuit layer as a bounded-capacity transport operation.
3. Show that any depth-`d` realization induces an assignment of total cost at most `n*d`.
4. Therefore large permanent implies large depth.

Why this matters:
- connects lower bounds to combinatorial optimization
- opens links to Hungarian-algorithm-style dual certificates
- gives an optimization-theoretic lower-bound witness

This is likely the best route for Theorem B.

## How to Build on the Catalog Theorems

### `tropical_depth_lower_bound`
Use this as the anchor theorem translating a tropical complexity measure into a depth lower bound. Do not merely cite it; **factor your new invariant through it**. The ideal structure is:

1. prove `tropicalSpectralGap A ≤ tropicalDepthMeasure A`
2. apply `tropical_depth_lower_bound`

This creates a reusable theorem pipeline.

### `spectral_gap_lower_bound`
Use it to certify nontriviality of your tropical gap definition on explicit matrix families. If it is stated over primes or arithmetic objects, use those constructions as a source of hard instances. The strategic move is:

- instantiate arithmetic matrices with certified positive spectral gap
- transport that gap into circuit-depth hardness

This would create an unexpected bridge from arithmetic spectral data to complexity lower bounds.

### `tropical_and_bound`
Use it in monotone-composition lemmas. If AND-like gate composition has tropical cost lower bounds, this can control how local gate composition accumulates into global depth/permanent constraints.

### `tropical_plus_distributes_over_min`
This should be a core algebraic simplifier for tropical matrix multiplication and path-composition lemmas. Use it aggressively to normalize expressions of the form
`a + min b c = min (a+b) (a+c)`.

## Minimal Viable Breakthrough

If the full spectral-gap theorem is too ambitious in one pass, the minimum acceptable result is:

1. define `tropicalPermanent`
2. prove `tropical_permanent_depth_lower_bound`
3. produce an explicit family `A_n` with `tropicalPermanent (A_n) ≥ c * n^2` or stronger
4. conclude nontrivial depth lower bounds for the corresponding circuit family

That already establishes a new lower-bound mechanism.

The next level is to prove:

- `tropicalSpectralGap A ≤ tropicalPermanent A`
  or
- `tropicalSpectralGap A ≤ C * depth`

which would unify the spectral and permanent approaches.
