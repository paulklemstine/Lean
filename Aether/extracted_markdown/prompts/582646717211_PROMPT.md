## Vision

Take the classical Berggren generators of primitive Pythagorean triples and turn them into a **certified finite-state expander hashing mechanism**. The revolutionary point is this:

- **Arithmetic dynamics upstairs**: Berggren words rigidly grow triple height and encode canonical tree structure.
- **Finite quotients downstairs**: reducing primitive triples modulo squarefree moduli produces finite state systems with nontrivial semigroup dynamics.
- **Spectral cryptography**: if the induced Cayley/Schreier graphs mix rapidly and short-word collisions are arithmetically thin, then the resulting hash family has provable diffusion, avalanche, and structured collision-resistance certificates.

This would open a new direction: **Pythagorean spectral cryptography**. It cross-pollinates:
- thin semigroups / orbit growth,
- expander graph theory,
- modular arithmetic of conics,
- formal verification of cryptographic diffusion,
- and algorithmic number theory.

This is not “Pythagorean triples meet crypto” in a superficial sense. The objective is to prove that **the same semigroup responsible for unique generation of primitive triples also yields finite quotients with certifiable pseudorandom walk behavior and collision rigidity**.

## Core Objects to Formalize

Let `B₁ B₂ B₃ : Matrix (Fin 3) (Fin 3) ℤ` be the classical Berggren matrices. Let `ΓB` be the multiplicative semigroup they generate. Let primitive triples be
\[
\mathcal P = \{(a,b,c)\in \mathbb Z^3 : a^2+b^2=c^2,\ \gcd(a,b,c)=1,\ c>0\}.
\]
For a modulus `N`, define a residue-state space `X_N` of normalized primitive Pythagorean classes modulo `N`, e.g. triples in `(ZMod N)^3` satisfying the Pythagorean relation and a chosen normalization rule modulo units / sign conventions / coordinate ordering, together with a nondegeneracy condition excluding singular local fibers.

The hash family should arise by:
1. encoding a message as a Berggren word `w`,
2. acting by the corresponding matrix on a fixed base primitive triple,
3. reducing modulo `N`,
4. normalizing to a canonical state in `X_N`.

The first breakthrough theorem should certify that for suitable `N`, short words almost never collide except through an explicitly bounded exceptional congruence set.

## Precise Theorem Targets

### Theorem A: Canonical modular action of Berggren semigroup

For squarefree `N` satisfying local admissibility conditions, the Berggren generators induce a well-defined endomorphism action on normalized primitive residue classes.

A mathematically precise target:

\[
\forall N,\ \mathrm{Squarefree}(N)\to \mathrm{Admissible}(N)\to
\forall g\in \Gamma_B,\ \forall x\in X_N,\ g\cdot x \in X_N,
\]
and this action is independent of representative choice used in normalization.

This is the formal gateway: the semigroup action must descend cleanly.

```lean
def PrimitiveResidue (N : ℕ) :=

def berggrenMatrix : BerggrenGen → Matrix (Fin 3) (Fin 3) ℤ

def berggrenActionMod (N : ℕ) (g : BerggrenGen) :

    ∀ g : BerggrenGen, Function.WellDefined (berggrenActionMod N g)
```

If `Function.WellDefined` is awkward, replace with an explicit representative-independence theorem for your chosen quotient construction.

### Theorem B: Short-word collision separation on a large good set

Fix a base state `x₀ ∈ X_N`. For words `w₁, w₂` in the Berggren generators of length at most `L`, if
\[
w_1 \cdot x_0 = w_2 \cdot x_0 \quad \text{in } X_N,
\]
then either `w₁ = w₂` as words / induced matrices, or `x₀` lies in an explicitly defined exceptional set `Exc(N,L)` whose density is bounded above by \(C_L/N^\delta\) or by a multiplicative local product forcing thinness.

A concrete finite-form theorem:
\[
\forall L,\ \exists C,\delta>0,\ \forall N\ \text{squarefree admissible},\ 
\#\mathrm{Exc}(N,L)\le C\,|X_N|\,N^{-\delta},
\]
and for `x ∉ Exc(N,L)`, the action map
\[
\{w:\ell(w)\le L\}\to X_N,\quad w\mapsto w\cdot x
\]
is injective.

This is the collision-resistance nucleus.

### Lean 4 type signature target
```lean
def Word := List BerggrenGen

def wordMatrix : Word → Matrix (Fin 3) (Fin 3) ℤ
def wordLength : Word → ℕ := List.length

def exceptionalSet (N L : ℕ) : Finset (PrimitiveResidue N)

theorem short_word_injective_off_exceptional
    (N L : ℕ)
    (hSq : Squarefree N)
    (hAdm : AdmissibleModulus N) :
    ∀ x : PrimitiveResidue N,
      x ∉ exceptionalSet N L →
      ∀ w₁ w₂ : Word,
        wordLength w₁ ≤ L →
        wordLength w₂ ≤ L →
        actWordMod N w₁ x = actWordMod N w₂ x →
        wordMatrix w₁ = wordMatrix w₂

theorem exceptionalSet_card_bound
    (N L : ℕ)
    (hSq : Squarefree N)
    (hAdm : AdmissibleModulus N) :
    ∃ C δ : ℝ, 0 < δ ∧
      (exceptionalSet N L).card ≤ Nat.ceil (C * (Fintype.card (PrimitiveResidue N)) / N^δ)
```

If a real-exponent bound is too heavy initially, first prove a weaker but formalizable statement:
- `card (exceptionalSet N L) ≤ C_L * N^2`
while `|X_N| ≍ N^3` on admissible squarefree moduli,
yielding density `O_L(1/N)`.

### Theorem C: Symmetrized Berggren quotient graphs are regular and spectrally separated

Let `S = {B₁, B₂, B₃}` and define a symmetrized graph on `X_N` using edges from action by `S` and reverse edges when available, or else pass to the undirected graph associated to the Markov operator
\[
M_N f(x)=\frac1{3}\sum_{s\in S} f(s\cdot x).
\]
Prove regularity and a nontrivial spectral gap:
\[
\|M_N|_{L^2_0(X_N)}\| \le 1-\varepsilon
\]
for all admissible squarefree `N` in a provable family, with `ε > 0` independent of `N` or at least bounded below on infinitely many `N`.

This is the expander theorem. Even a weaker theorem with explicit combinatorial expansion on a large subset would be major.

### Theorem D: Avalanche / diffusion lower bound

Define the Berggren expander hash
\[
H_N(w)=\mathrm{normalize}\bigl(\overline{M_w v_0}\bigr)\in X_N.
\]
Prove a certified diffusion statement: changing one generator in a word of length `L` changes the output on a positive proportion of admissible residue states, or after averaging over random suffixes/prefixes yields total variation separation bounded below by a constant depending on the spectral gap.

A practical theorem:
\[
\forall i<L,\ \forall w,w' \text{ differing at position } i,\ 
\Pr_{x\in X_N}[w\cdot x \ne w'\cdot x] \ge \eta
\]
outside an exceptional set of density `o(1)`.

### Lean 4 type signature target
```lean
def H_N (N : ℕ) (w : Word) (x0 : PrimitiveResidue N) : PrimitiveResidue N :=
  actWordMod N w x0

def differAt (i : ℕ) (w₁ w₂ : Word) : Prop := ...

theorem avalanche_lower_bound
    (N L : ℕ)
    (hSq : Squarefree N)
    (hAdm : AdmissibleModulus N) :
    ∃ η : ℝ, 0 < η ∧
      ∀ i < L, ∀ w₁ w₂ : Word,
        wordLength w₁ = L →
        wordLength w₂ = L →
        differAt i w₁ w₂ →
        η * Fintype.card (PrimitiveResidue N) ≤
          Fintype.card {x : PrimitiveResidue N // actWordMod N w₁ x ≠ actWordMod N w₂ x}
```

This theorem would formalize “avalanche” in purely finite arithmetic terms, avoiding heuristic crypto language.

## Proof Architecture: 3 Viable Strategies

### Strategy A: Thin-semigroup rigidity + modular orbit counting
**Most promising for the first major theorem.**

1. **Upstairs rigidity.** Use the uniqueness/canonicality of Berggren generation and height-growth monotonicity to show distinct short words produce distinct integer matrices and typically distinct integer triples from a basepoint.
2. **Downstairs collision equation.** If two words collide mod `N`, then `(M_{w₁} - M_{w₂})v ≡ 0 mod N` for the residue state `v`. This defines a proper congruence subvariety / kernel condition unless the matrices coincide.
3. **Count exceptional fibers.** For each pair `(w₁,w₂)`, bound the number of `v ∈ X_N` satisfying the congruence; union bound over all short pairs. Use squarefree factorization and CRT to reduce to local counts over `p | N`.

Why this is strong:
- It only needs semigroup rigidity and modular counting.
- It naturally produces an explicit exceptional set.
- It gives a formal collision certificate before full expander theory is complete.

This should be your **first attack**.

---

### Strategy B: Schreier graph expansion via local generation and product structure
1. **Construct local action modulo primes.** Show Berggren generators act nontrivially on `X_p`, preserve admissibility, and generate a sufficiently mixing local semigroup/graph.
2. **Lift to squarefree `N` by CRT.** Identify `X_N` with a product of local state spaces up to normalization subtleties.
3. **Tensor-product mixing.** Prove spectral or combinatorial expansion of the global Markov operator from local expansion plus product decomposition.

Why this matters:
- It can yield a genuine expander theorem.
- It gives mixing and avalanche from operator inequalities.
- It formalizes modular arithmetic in a way Lean can manage with finite products and CRT.

Risk:
- Local generation may be delicate.
- You may need to symmetrize the graph or restrict to a large strongly connected component.

---

### Strategy C: Matrix-coefficient separation + additive combinatorics on conic residue varieties
1. **Linearize collisions.** Treat the collision condition as vanishing of matrix coefficients on the Pythagorean cone modulo `N`.
2. **Use non-concentration.** Show primitive residue states do not concentrate in kernels of nonzero linear forms induced by `M_{w₁} - M_{w₂}` except on thin local degeneracy sets.
3. **Derive expansion surrogate.** Even without full spectral gap, prove flattening / discrepancy bounds for short random walks.

Why this is powerful:
- It may bypass difficult exact graph spectral calculations.
- It connects directly to formal discrepancy bounds and hash diffusion.
- It aligns with certified finite-state cryptographic claims.

This is an excellent fallback if full expander machinery proves too expensive initially.

## Cross-Domain Connections to Exploit

### 1. Thin groups / semigroups and affine sieve philosophy
The Berggren semigroup is a canonical thin arithmetic dynamical system. Your collision theorem is a finite-quotient analogue of the principle that thin orbits retain arithmetic structure while avoiding excessive congruence collapse.

### 2. Expander-based cryptography
Most expander cryptography is group-based or code-based. Here the novelty is a **semigroup on a Diophantine variety**. This could become a formally verified arithmetic expander hash primitive.

### 3. Conic dynamics and automorphic shadows
Primitive Pythagorean triples live on a rational cone. Modular reduction of their dynamics suggests connections to Hecke-type operators on conic residue spaces. Even a weak spectral theorem here would be conceptually profound.

### 4. Quantum / operator viewpoints
The averaging operator on `X_N → ℝ` is a finite transfer operator. If you can formalize norm contraction or spectral decomposition, this interfaces naturally with “quantum” operator semantics already hinted at in prior Pythagorean arcs.

### 5. Certified cryptography in Lean
A theorem saying “all short collisions lie in an explicitly checkable exceptional set of bounded density” is stronger, in some ways, than a heuristic cryptographic claim. It turns collision analysis into a decidable arithmetic certification problem.
