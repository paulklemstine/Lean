## Research Task: Algebraic tropicalization of EML function algebras via a tropical Stone–Weierstrass theorem for min-plus semiring-valued EML maps

Research Mode: PROVE

Work in the finite-valued setting first: continuous functions `X → ℝ` on a compact Hausdorff space, with min-plus operations
- tropical addition: `(f ⊕ g) x = min (f x) (g x)`
- tropical multiplication: `(f ⊗ g) x = f x + g x`
- tropical scalar constants: `x ↦ c`

The decisive bridge is the order-reversing involution `f ↦ -f`, which converts min-plus structure into max-plus structure:
- `-(min (f x) (g x)) = max (-f x) (-g x)`
- `-(f x + g x) = (-f x) + (-g x)`

The theorem to target is not merely a reformulation of classical Stone–Weierstrass: it is the algebraic certification that “cost-style” observables (shortest-path, value functions, energy landscapes, morphological erosions) can be uniformly approximated by finitely assembled min-plus primitives whenever those primitives separate states. This is the min-plus half of a tropical approximation theory for EML, and it should be formalized as a genuine dual companion to the max-plus program rather than as an ad hoc corollary.

### Primary theorem: min-plus Stone–Weierstrass via negation duality

The cleanest formal target is a transport theorem: if `A` is closed under min-plus operations and constants, then `neg '' A` is a max-plus class; if the corresponding max-plus Stone–Weierstrass theorem is available or can be proved on the interval, transfer density back to `A`.

A more computational theorem, likely easier to prove first, is a one-sided approximation theorem for Lipschitz functions:

```lean
theorem lipschitz_inf_of_distance_templates
    (f : C(Set.Icc (0 : ℝ) 1, ℝ))
    (hfLip : LipschitzWith K f)
    (ε : ℝ) (hε : 0 < ε) :
    ∃ N : ℕ, ∃ xs : Fin N → Set.Icc (0 : ℝ) 1, ∃ ws : Fin N → ℝ,
      let g : C(Set.Icc (0 : ℝ) 1, ℝ) :=

          (fun x => Finset.univ.inf' Finset.univ_nonempty
            (fun i => ws i + K * |x.1 - (xs i).1|))

  sorry
```

This theorem is revolutionary because it identifies value-function approximation with a finite tropical envelope of distance templates — exactly the language of dynamic programming, control, and shortest-path geometry.

### Proof strategy: 5 concrete steps

#### Strategy A: transport through max-plus Stone–Weierstrass via `f ↦ -f` (most promising)
This is the cleanest route if any max-plus density theorem exists or can be proved in parallel.

1. **Define the negation transport of a class**
   ```lean
   def NegImage (A : Set (C(I, ℝ))) : Set (C(I, ℝ)) := tropNeg '' A
   ```
   Prove that `A` closed under min-plus `min` and `+` implies `NegImage A` is closed under max-plus `max` and `+`, with constants preserved.

2. **Prove point separation is preserved**
   Show:
   ```lean
   theorem TropSeparatesPoints.neg_image_iff
   ```
   since `f x ≠ f y` iff `(-f) x ≠ (-f) y`.

3. **Prove uniform norm invariance under negation**
   This is the exact technical bridge:
   ```lean
   ‖tropNeg f - tropNeg g‖ = ‖f - g‖
   ```
   likely by extensionality and pointwise simplification, then using `norm_neg`.

4. **Apply max-plus density to `tropNeg f`**
   Obtain `h ∈ tropNeg '' A` with `‖tropNeg f - h‖ < ε`. Write `h = tropNeg g` with `g ∈ A`.

5. **Transport back**
   Use norm invariance to conclude `‖f - g‖ < ε`.

This strategy is best because it isolates the entire min/max duality into a reusable formal package. Once done, every max-plus theorem becomes a min-plus theorem “for free.”

#### Strategy B: direct finite-envelope construction from separation
If the max-plus theorem is not yet available in formalized form, build a direct approximation argument on `I = [0,1]`.

1. For each `x`, use separation to construct a function `h_x ∈ A` that lies below `f + ε` globally but nearly matches `f(x)`.
2. Use compactness to extract finitely many neighborhoods where these local lower-support functions are accurate.
3. Take the tropical supremum on the max-plus side after negation, or equivalently assemble a lower envelope in min-plus form after adding suitable constants.
4. Prove the resulting finite assembly remains in `A` by closure under constants, addition, and `min`.
5. Show the assembled function approximates `f` uniformly.

This is the true tropical analog of the classical Stone patching argument. It is more self-contained but technically harder.

#### Strategy C: explicit approximation by distance templates / McShane-Whitney style
This is especially suited to value-function applications.

1. For a Lipschitz `f`, define support templates
   ```lean
   φ_a(x) = f(a) - K * d(x,a)
   ```
   or the min-plus dual version appropriate for lower-envelope approximation.
2. Prove `φ_a ≤ f` and `f = sup_a φ_a` on the max-plus side, then dualize to min-plus.
3. Approximate the continuum of support points by a finite `ε`-net using compactness.
4. Show the finite infimum/supremum approximates uniformly.
5. Encode the finite approximation as a tropical polynomial in distance generators.

This path gives algorithmic approximants immediately and may be the strongest route for the second theorem.

### Significance for the research program

This theorem is the algebraic tropicalization of EML approximation on the “cost” side. Max-plus models naturally encode reward and utility; min-plus models encode cost, action, energy, travel time, dissipation, and dynamic programming value functions. Formalizing the min-plus Stone–Weierstrass principle means:

1. **EML acquires a certified approximation theory for optimization observables.**  
   Not just expressive power, but density with explicit error control in the uniform norm.

2. **Tropical algebra becomes computational infrastructure, not just analogy.**  
   Finite lower-envelope assemblies are exactly the data structures used in shortest-path, control, morphology, and Hamilton–Jacobi numerics.

3. **The max/min duality becomes a theorem factory.**  
   Once `f ↦ -f` is formalized at the algebraic and metric levels, future max-plus theorems can be mirrored systematically to min-plus settings.

4. **This opens a route to tropical Gelfand-type reconstruction on the cost side.**  
   Dense min-plus subalgebras suggest a duality between spaces and their tropical function algebras, with direct implications for idempotent analysis and EML semantics.

5. **Algorithmic shadow:** finite tropical polynomials become certified surrogates for value functions.  
   This is exactly the approximation language needed for formalized control, planning, shortest-path certificates, and morphological signal processing.
