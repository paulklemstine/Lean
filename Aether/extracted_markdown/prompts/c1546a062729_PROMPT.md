## Assignment: Algebra–EML–Computation Idempotent Kalman Realization via Closure Hankel Semimodules and Certified Minimal State Reconstruction

**Mode:** prove

Prove a genuinely new realization theorem that should become the idempotent/EML analogue of classical Kalman realization, but in a form strong enough to subsume weighted automata minimization and to launch a new theory of **closure-linear systems** over idempotent semirings.

The breakthrough target is this: show that **finite closure-Hankel rank is exactly the right invariant for finite-state recognizability of closure-regular behaviors**, and that the minimal state space is not an arbitrary quotient but a **canonical closure-stable semimodule extracted from Hankel geometry**. This would unify three worlds that are usually separate: tropical/idempotent algebra, EML-style closure semantics, and certified system identification from finite data.

You should define the closure-Hankel kernel by
\[
H_B(u,v) := cl(B_{uv}) \quad\text{or more concretely}\quad H_B(u,v)= (cl B)(u ++ v),
\]

### Theorem 1: Closure-Hankel realization equivalence

**Mathematical statement.**

Let `S` be an idempotent semiring, `Σ` a type, and `B : List Σ → S` a behavior. Assume `cl` is extensive, monotone, idempotent, and compatible with left shifts and finite `S`-linear combinations of rows. Then the following are equivalent:

1. The closure-Hankel row semimodule of `B` is closure-generated by `n` rows for some finite `n`.
2. There exists a finite-dimensional linear representation over `S`, i.e. vectors `α β : Fin n → S` and transition maps
   \[
   A_a : (Fin n → S) \toₛₗ[S] (Fin n → S)
   \]
   for each `a : Σ`, such that for every word `w`,
   \[
   cl(B)(w) = α^\top A_w β,
   \]
   equivalently
   \[
   B(w) = cl(\lambda w => α^\top A_w β)(w)
   \]
   if closure is only imposed at the behavior level.

This is the exact idempotent-Kalman analogue: **finite closure-Hankel rank iff finite closure-linear realizability**.

### Suggested Lean 4 theorem signature

A realistic theorem signature, possibly after introducing a bundled structure `ClosureCompatibleBehavior`, is:

If `→ₗ[S]` is unavailable for semimodules over your semiring assumptions, replace with whatever bundled endomorphism notion Mathlib supports in the semiring/semimodule setting, or define a lightweight structure of `S`-linear endomorphisms.

A possible evaluation function:

```lean

  (α β : Fin n → S)
  (A : Σ → ((Fin n → S) →ₗ[S] (Fin n → S))) :
  List Σ → S
```

with `A_w` defined by composition along the word.

### Theorem 2: Canonical minimality and uniqueness

**Mathematical statement.**

Assume `B` has finite closure-Hankel rank. Define:
- the **reachable semimodule** generated by the states `A_w β`,
- the **closure-observational equivalence** relation
  \[
  x \sim_{\mathrm{cl}} y \iff \forall u,\; cl(\lambda w, \mathrm{obs}(x,w))(u)=cl(\lambda w, \mathrm{obs}(y,w))(u),
  \]
  or more concretely equality of induced closed future behaviors,
- the **observable Hankel row semimodule** generated by rows `v ↦ cl(B(uv))`.

Then the quotient of the reachable semimodule by closure-indistinguishability is canonically isomorphic to the closure-Hankel row semimodule. In particular, the minimal realization exists and is unique up to closure-preserving semimodule isomorphism.

This is the idempotent/closure analogue of the reachable-observable minimal Kalman realization theorem and of Myhill–Nerode uniqueness, but now for general weighted signal behaviors.

### Theorem 3: Certified finite-window reconstruction

**Mathematical statement.**

Suppose finite prefix/suffix sets `P,Q ⊆ Σ*` are closed under the one-step extensions needed to read transitions, and suppose the closure-Hankel submatrix on `P × Q` has stabilized in rank: extending `P,Q` by one-letter shifts does not increase closure-rank. Then one can compute:
- a finite state semimodule of dimension equal to the stabilized rank,
- transition maps induced by row-shifts,
- initial/final vectors,
and prove that the resulting realization is correct and minimal for the closed behavior.

This is the algorithmic heart: a certified Ho–Kalman theorem for idempotent closure systems.

### Suggested Lean theorem signature

```lean
theorem reconstructMinimalClosureRealization_correct
  {Σ S : Type*}
  [Fintype Σ] [DecidableEq Σ]
  [Semiring S] [IdempotentSemiring S]
  (cl : (List Σ → S) → (List Σ → S))
  (hcl : IsEMLClosure cl)
  (B : List Σ → S)
  (P Q : Finset (List Σ))
  (hstab : ClosureHankelRankStableOn cl B P Q) :
  let R := reconstructMinimalClosureRealization cl B P Q hstab
  RealizesClosedBehavior cl R B ∧ IsMinimalClosureRealization cl B R
```

If extraction to concrete matrices is easier than abstract semimodules, start there:
- represent states by basis rows indexed by `Fin n`,
- define transitions by expressing shifted generators in the stabilized row basis,
- prove correctness from Hankel factorization.

## Proof architecture: 3 serious strategies

### Strategy A: Hankel row semimodule → shift representation
This is likely the most promising.

1. **Construct the state semimodule from rows.**  
   Let the state space be the closure-row semimodule generated by `u ↦ hankelRow cl B u`. Finite closure-rank gives finite generation by `n` rows.

2. **Define transitions by left-shift.**  
   For each letter `a`, define `T_a(row_u) = row_(a::u)` or `row_(u ++ [a])` depending on your chosen convention. Prove this is well-defined on the closure-span using closure compatibility.

3. **Extract initial/output maps.**  
   The initial state is the row at the empty word; the output is evaluation at `[]`. Then
   \[
   cl(B)(w)=\mathrm{output}(T_w(\mathrm{init})).
   \]
   Finally choose a finite generating family and transport to `Fin n → S`.

Why this is promising: it avoids difficult quotienting until the uniqueness stage and mirrors the automata/Myhill–Nerode proof pattern, which is likely already partially present in the catalog.

---

### Strategy B: Factorization of the closure-Hankel operator
This is the conceptual Kalman route.

1. **View Hankel as an operator.**  
   Regard
   \[
   H_B : \text{prefix semimodule} \to \text{behavior semimodule}
   \]
   via `u ↦ row_u`.

2. **Finite rank implies factorization through `S^n`.**  
   Prove finite closure-rank iff `H_B` factors through a free finitely generated semimodule:
   \[
   H_B = O \circ R
   \]
   with `R : Σ^* → S^n` and `O : S^n → (Σ^* → S)`.
   Then use shift invariance of Hankel rows to induce `A_a` on `S^n`.

3. **Recover realization formula.**  
   Show `R(aw) = A_a(R(w))` and output is evaluation via `O`. This yields the exact linear realization.

Why this matters: it is the cleanest analogue of classical Ho–Kalman/Hankel factorization and will make the final theorem look like a true new chapter in realization theory, not just an automata corollary.

---

### Strategy C: Reachable/observable quotient and closure-Myhill–Nerode synthesis
This is best for uniqueness/minimality.

1. **Define future behavior of a state.**  
   Associate to each reachable state its closed future-output behavior.

2. **Quotient by closure-indistinguishability.**  
   States are equivalent when they induce the same closed future behavior. Show this is a congruence for transitions.

3. **Identify quotient with observable Hankel rows.**  
   Construct a canonical map from reachable states to rows; prove surjective and kernel exactly closure-indistinguishability. Then the first isomorphism theorem gives minimality and uniqueness.

Why this is essential: this is the theorem that turns the realization from “some finite model exists” into “the minimal one is canonical.” That is the field-opening part.

## Cross-domain connections you should make explicit in the development

This project is powerful because it fuses several theories that usually do not talk to one another.

### 1. Classical systems theory / Ho–Kalman
The theorem is a semiring-and-closure version of:
- finite Hankel rank,
- reachable/observable decomposition,
- minimal realization,
- subspace identification from finite windows.

This opens a path to **nonlinear-by-closure system identification** in settings where addition is idempotent and closure captures semantic saturation.

### 2. Weighted automata / formal language theory
The state semimodule extracted from Hankel rows is the weighted analogue of the Nerode quotient. Your theorem should clarify that **weighted automata minimization is a special case of closure-linear realization theory**.

This is not just a connection; it is a conceptual merger of automata learning and linear systems.

### 3. Tropical geometry and max-plus control
Over `max-plus` or `min-plus`, realizations describe discrete event systems, shortest path propagation, scheduling, and synchronization. Closure semantics can encode saturation, observability under uncertainty, or semantic abstraction. A certified minimal realization theorem here becomes a foundation for **tropical control, robust scheduling, and explainable discrete-event inference**.

### 4. EML / semantic closure / abstract interpretation
If `cl` models an EML-style semantic closure or abstraction nucleus, then your theorem says:
- finite closure-Hankel complexity implies finite latent semantic state,
- the latent state is reconstructible from finite observations,
- the reconstruction is certified minimal.

That is a remarkable bridge from algebraic semantics to learnable state-space models.

### 5. Computation and formal verification
The finite-window reconstruction theorem is a formally verified identification algorithm. This suggests downstream extraction to trustworthy learning pipelines for weighted systems and tropical signal models.
