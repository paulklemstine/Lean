## Assignment: Direction 1: Finite Probe Representability Conjecture

**Mode:** prove / discover

Prove genuinely new, non-trivial theorems in Lean 4, building directly on the catalog results around finite probe families and Yoneda-style reconstruction. Minimize `sorry`. The target is not a routine extension: it is to determine whether **finite detectability by probes forces finite representable generation** in presheaf categories over finite bases.

This is a potential bridge between **categorical density**, **compressed sensing**, **property testing**, and **finite model reconstruction**.

---

## Central Vision

The density theorem says every presheaf is a colimit of representables. That is existential and often infinite. Your task is to attack a far sharper finite analogue:

> when a presheaf on a finite category is already determined by finitely many probes, can one compress it to a **finite representable cover**?

If true, this would create a rigorous theory of **compressed categorical sensing**: finite observation schemes recovering functors from bounded geometric data. If false, a counterexample would identify the precise obstruction, opening a new obstruction theory for finite approximation in presheaf categories.

The result would be conceptually new because it upgrades **extensional determination** (`natTrans_ext_of_finite_probes`) into **constructive representability bounds**.

## Precise Mathematical Target

Let `C` be a finite category. Let `P` be a finite family of probes in `C`. Let `F : Cᵒᵖ ⥤ Type` be a presheaf.

You should formalize a notion stronger than mere extensional detection, expressing that elements of `F.obj (op X)` are recoverable from finitely many probe restrictions. Then prove one of the following breakthrough statements, or else refute the strongest one by explicit counterexample and salvage an optimal corrected theorem.

### Core conjectural theorem
For a finite category `C`, a finite separating probe family `P`, and a presheaf `F : Cᵒᵖ ⥤ Type`, if `F` is finitely detected by `P`, then there exists a finite family of objects `(X_i) : Fin n → C` and a surjective natural transformation
\[
\left(\coprod_{i : \mathrm{Fin}\, n} \mathrm{yoneda.obj}(X_i)\right) \twoheadrightarrow F.
\]

Since finite coproducts in `Type`-valued presheaves are pointwise sums, you should likely formalize the source as an explicit finite representable sum presheaf.

## Required New Definitions

You must introduce at least one genuinely new structure not already present in the catalog. Recommended definitions:

### 1. Finite representable sum presheaf
Define an explicit finite coproduct of representables:
```lean
def finiteRepresentableSum (C : Type u) [Category C] (ι : Type v) [Fintype ι]
    (X : ι → C) : Cᵒᵖ ⥤ Type (max u v)
```
with objectwise values
```lean
(finiteRepresentableSum C ι X).obj (op Y) ≃ Σ i : ι, (Y ⟶ X i)
```
or equivalent.

### 2. Representably finitely generated presheaf
```lean
def RepresentablyFinitelyGenerated
    {C : Type u} [Category C] (F : Cᵒᵖ ⥤ Type v) : Prop :=
  ∃ (ι : Type w) (_ : Fintype ι) (X : ι → C),
    ∃ η : finiteRepresentableSum C ι X ⟶ F,
      Function.Surjective (fun x => η.app _ x)
```
You may need to strengthen “surjective” to pointwise surjective:
```lean
def NatTrans.PointwiseSurjective {F G : Cᵒᵖ ⥤ Type v} (η : F ⟶ G) : Prop :=
  ∀ Y, Function.Surjective (η.app Y)
```

### 3. Finite probe generation / elementwise detectability
A stronger notion than `P.Detects F G`, designed to control **elements** rather than just equality of natural transformations:
```lean
def FiniteProbeGenerates
    {C : Type u} [Category C]
    (P : FiniteProbeFamily C) (F : Cᵒᵖ ⥤ Type v) : Prop := ...
```
A good formulation is: each element of `F.obj (op Y)` is uniquely determined by its restrictions along maps from probes in `P`. If this is too strong globally, define a weaker “separates elements” predicate and prove implications.

This new definition is likely the key conceptual contribution.

## Proof Strategy Architecture

You must not pursue only one route. Develop at least 2–3 proof avenues and indicate which one is most promising.

### Strategy A: Explicit Yoneda-generator construction from element supports
1. For each object `Y` and each element `x : F.obj (op Y)`, use Yoneda to build a natural transformation
   \[
   \mathrm{yoneda.obj}(Y) \to F
   \]
   corresponding to `x`.
2. Show that if a finite set of such elements suffices to generate all fibers under restriction, then the induced map from a finite sum of representables is pointwise surjective.
3. Derive finite generation from a finite probe-detection hypothesis plus a compactness/finiteness lemma on possible measurement signatures.

**Why promising:** this is the most constructive path and aligns perfectly with the density theorem. It also naturally yields an algorithm.

---

### Strategy B: Measurement-space embedding and finite image argument
1. Define the probe measurement map sending an element of `F(Y)` to all its probe restrictions.
2. Use your strengthened probe-generation axiom to prove injectivity of this map.
3. Since the measurement space is finite (finite category, finite probes, finite values), conclude that only finitely many elements of each `F(Y)` exist up to probe data.
4. Convert each realized measurement signature into a generator, then package them as a finite sum of representables.

**Why promising:** this route transforms the problem into finite combinatorics and is closest to compressed sensing / coding theory. It should be especially effective for the finite-values theorem.

---

### Strategy C: Refutation / obstruction route
1. Search for a presheaf where probe data separates natural transformations but fails to separate elements.
2. Show that the catalog theorem `natTrans_ext_of_finite_probes` is extensional, not generative.
3. Build a finite counterexample where all representable tests pass but no finite representable cover exists.
4. Extract a corrected theorem by adding the minimal missing hypothesis (likely pointwise finite values, elementwise probe separation, or bounded support).

**Why promising:** if the full conjecture is too optimistic, this route still produces a major contribution by isolating the exact obstruction.

**Most promising overall:** Strategy B, then Strategy A. Strategy C should run in parallel computationally as a falsification engine.

## Falsifiable Conjectures and Testable Predictions

You must include at least one conjecture with a clear computational disproof criterion. Ideally include 3–5 in `FUTURE_DIRECTIONS.md`. Recommended hypotheses:

### Conjecture A: Finite-values positive theorem
For every finite category `C`, every finite separating probe family `P`, and every finite-valued presheaf `F`, if `FiniteProbeGenerates P F`, then `RepresentablyFinitelyGenerated F`.

**Test:** exhaustive enumeration on small categories and finite presheaves. A single finite-valued counterexample refutes it.

### Conjecture B: Uniform generator bound
There exists a bound depending only on `P` and `C` such that every `F` satisfying `FiniteProbeGenerates P F` admits a representable cover with at most that many summands.

**Test:** compute minimal cover sizes over enumerated presheaves; look for unbounded growth.

### Conjecture C: Measurement-cardinality bound is sharp
For every finite category and probe family, there exists a presheaf whose minimal representable generator number equals the maximal number of realized probe signatures.

**Test:** brute-force optimization over small categories.

### Conjecture D: Naive detectability is insufficient
The original extensional hypothesis `P.Detects F G` for representable `G` does **not** imply representable finite generation without an elementwise separation axiom.

**Test:** search for a finite counterexample where natural transformations are determined by probes, but some fiber contains indistinguishable non-generated elements.

### Conjecture E: Probe Helly principle
If every restriction of `F` to a full subcategory on at most `k` objects is representably finitely generated from `P`, then `F` is globally representably finitely generated.

**Test:** search small finite categories for minimal obstructions.
