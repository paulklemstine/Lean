### Theorem A: Tropical recursive generation of dragon prefixes
Define a finite lattice path recursion whose state is a word over quarter-turn instructions or a pair of endpoint maps, and prove it is representable by iterated min-plus piecewise-linear maps.

A good formal target is:

```lean
def DragonState := ℤ × ℤ × Fin 4

def tropicalDragonStep : DragonState → DragonState := ...

def dragonWord : ℕ → List (Fin 4) := ...

def dragonPath : ℕ → List (ℤ × ℤ) := ...

theorem dragonPath_generated_by_tropical_recursion :
  ∃ F : DragonState → DragonState,
    (∀ s, F s = tropicalDragonStep s) ∧
    ∀ n, ∃ S : List DragonState,
      S.length = n + 1 ∧
      dragonPath n = (S.map fun s => (s.1, s.2))
```

This theorem is too weak by itself, so sharpen it: define `tropicalDragonStep` explicitly using min-plus affine pieces and prove every prefix is generated by iterating this map from an initial lattice state.

A stronger version:

```lean
def MinPlusAffineMap (α : Type) := α → α

theorem dragon_recursion_minplus_realizable :
  ∃ F₁ F₂ : (ℤ × ℤ × Fin 4) → (ℤ × ℤ × Fin 4),
    (∀ s, tropical_on_regions F₁) ∧
    (∀ s, tropical_on_regions F₂) ∧
    ∀ n, dragonState n = (Nat.rec initialState (fun k st => if turnBit k = 0 then F₁ st else F₂ st) n)
```

Here `tropical_on_regions` should mean piecewise min-plus affine on finitely many lattice regions. If no catalog definition exists, define it cleanly.

### Theorem B: Exact self-similarity as tropical scaling
Formalize the decomposition of the order `n+1` dragon into two transformed copies of the order `n` dragon.

A target theorem:

```lean
def scaleRotateTranslate : ℝ → Matrix (Fin 2) (Fin 2) ℝ → (ℝ × ℝ) → Set (ℝ × ℝ) → Set (ℝ × ℝ) := ...

def dragonApprox : ℕ → Set (ℝ × ℝ) := ...

theorem dragon_self_similarity :
  ∀ n,
    dragonApprox (n + 1) =
      scaleRotateTranslate (Real.sqrt 2 / 2) R₊ t₁ (dragonApprox n) ∪
      scaleRotateTranslate (Real.sqrt 2 / 2) R₋ t₂ (dragonApprox n)
```

Then connect this to tropical scaling by proving that the address recursion for these two branches is encoded by min-plus combinatorics. If “tropical scaling” is not standard in your files, define it as logarithmic affine scaling in a min-plus semimodule or as a scaling law on support functions.

## Proof Strategy Options

You must pursue at least two strategies in parallel and decide quickly which one is formalization-feasible.

### Strategy 1: Symbolic dynamics → tropical recursion → self-similar attractor
This is the most promising route.

1. **Encode dragon words by binary address recursion.**
   The dragon is naturally generated by a binary symbolic system with reversal/complement. Prove recursive decomposition of words and paths.

2. **Realize the update maps as piecewise min-plus affine on lattice states.**
   Use explicit case splits on orientation `Fin 4` and sign patterns. This is where `tropical_min_assoc` and `lattice_scaling` can support algebraic simplification and scaling consistency.

3. **Pass from combinatorial recursion to geometric self-similarity.**
   Show order `n+1` approximants are unions of two transformed order `n` approximants. Then derive covering-number recurrences.

Why this is promising: it keeps everything discrete and constructive before taking limits, which is ideal for Lean.

### Strategy 2: Complex-base / matrix recursion → positive-area theorem
This is mathematically elegant and may be stronger if manageable.

1. Model the dragon attractor via the classical IFS in the complex plane:
   `z ↦ (1+i)z/2` and `z ↦ 1 - (1-i)z/2`, or an equivalent normalized pair.

2. Translate complex multiplication into `2 × 2` real matrices and formalize the attractor recursion.

3. Prove nonempty interior or positive Lebesgue measure, then invoke a general dimension lemma to conclude Hausdorff dimension `2`.

Why this is powerful: positive area gives dimension `2` immediately and reveals the dragon as a genuine planar tile-like object.  
Why it is risky: measure-theoretic attractor arguments may be heavy in Lean.

### Strategy 3: Covering growth and lattice occupancy
This is the most Lean-robust for dimension if Hausdorff machinery is too hard.

1. Define the `n`th polygonal approximation and count occupied dyadic or lattice boxes at scale `2^{-n/2}`.
2. Prove lower and upper bounds of order `C · 2^n` on occupied boxes.
3. Deduce box dimension `2` from asymptotic occupancy.

Why this is feasible: it uses combinatorics, finite sets, and asymptotic inequalities rather than advanced measure theory.  
Why it matters: a precise box-dimension theorem is already a major formal result and can later be upgraded.
