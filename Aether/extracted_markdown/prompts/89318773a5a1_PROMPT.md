## Precise Theorem Targets

### Target A: Formal statement of Schanuel’s conjecture

For a finite family `z : Fin n → ℂ`, if the coordinates are linearly independent over `ℚ`, then the transcendence degree over `ℚ` of the field generated by the `z i` and `Complex.exp (z i)` is at least `n`.

A realistic Lean-facing declaration may look like:

```lean
open Complex
open scoped BigOperators

/-- A finite-family formulation of Schanuel's conjecture over ℂ. -/
def SchanuelConjecture (n : ℕ) : Prop :=
  ∀ z : Fin n → ℂ,
    LinearIndependent ℚ z →
      n ≤
        Module.finrank ℚ
          (AlgebraicClosure ℚ) -- placeholder: replace by a correct tdg interface
```

This signature is **not yet mathematically correct**, because transcendence degree is not `finrank`. Your first job is to define the right interface. A more honest target is:

```lean
/-- Placeholder interface: transcendence degree lower bound for adjoining
`z i` and `exp z i` to `ℚ`. -/
def SchanuelFamily (n : ℕ) : Prop :=
  ∀ z : Fin n → ℂ,
    LinearIndependent ℚ z →
      n ≤ transcendenceDegreePair ℚ (fun i => z i) (fun i => Complex.exp (z i))
```

where you define or formalize an object such as:

```lean
noncomputable def transcendenceDegreePair
    (K : Type*) [Field K]
    (x y : Fin n → ℂ) : Cardinal := ...
```

If Mathlib already has `transcendenceBasis` / `transcendenceDegree`, use it directly. If not, define a finite-family surrogate:
- algebraic independence of a finite set,
- maximal cardinality of an algebraically independent subfamily,
- lower-bound statement sufficient for Lindemann–Weierstrass.

### Target B: Schanuel ⇒ Lindemann–Weierstrass

This is the first major theorem you should aim to formalize conditionally.

**Mathematical statement.**
If Schanuel’s conjecture holds, then for any algebraic numbers `α₁, …, αₙ ∈ ℂ` that are linearly independent over `ℚ`, the numbers `exp(α₁), …, exp(αₙ)` are algebraically independent enough in particular to imply they are linearly independent over `𝔸`, and hence exponentials of distinct algebraic numbers are linearly independent over the algebraic numbers. A standard consequence is the Lindemann–Weierstrass theorem:
if `α₁, …, αₙ` are distinct algebraic numbers, then `exp(α₁), …, exp(αₙ)` are linearly independent over `\overline{ℚ}`.

A Lean-facing conditional theorem could be split into manageable lemmas:

```lean
theorem schanuel_implies_exp_transcendental_of_nonzero_algebraic
    (SC : ∀ n, SchanuelFamily n)
    {z : ℂ}
    (hz_alg : IsAlgebraic ℚ z)
    (hz_ne : z ≠ 0) :
    Transcendental ℚ (Complex.exp z) := ...
```

```lean
theorem schanuel_implies_lindemann_weierstrass_fin
    (SC : ∀ n, SchanuelFamily n)
    {n : ℕ} (a : Fin n → ℂ)
    (ha_alg : ∀ i, IsAlgebraic ℚ (a i))
    (ha_lin : LinearIndependent ℚ a) :
    LinearIndependent (AlgebraicClosure ℚ) (fun i => (Complex.exp (a i) : ℂ)) := ...
```

If linear independence over `AlgebraicClosure ℚ` is too ambitious for current libraries, prove the weaker but still meaningful formal theorem:

```lean
theorem schanuel_implies_exp_not_algebraic_of_qLinIndep_algebraic
    (SC : ∀ n, SchanuelFamily n)
    {n : ℕ} (a : Fin n → ℂ)
    (ha_alg : ∀ i, IsAlgebraic ℚ (a i))
    (ha_lin : LinearIndependent ℚ a) :

```

### Target C: Provable finite-dimensional shadow theorems

Since the full conjecture is open, prove rigorous “shadow theorems” that mimic the logic of Schanuel in settings where the argument collapses to linear algebra or algebraicity.

Examples:

1. **One-dimensional Schanuel shadow**
   ```lean
   theorem schanuel_shadow_n1
       (z : ℂ)
       (hz_ne : z ≠ 0)
       (hz_alg : IsAlgebraic ℚ z) :
       ¬ IsAlgebraic ℚ (Complex.exp z) → 1 ≤ transcendenceDegreePair ℚ (fun _ : Fin 1 => z) (fun _ => Complex.exp z)
   ```

2. **Algebraic-dependence obstruction theorem**
   Formalize: if all `z i` and `exp(z i)` are algebraic, then `z i` cannot be Q-linearly independent under Schanuel.

3. **Rank-vs-transcendence interface theorem**
   Build a theorem comparing `finrank` of the `ℚ`-span of a family with any formal lower-bound notion you define for transcendence degree.

These are not trivial. They are the scaffolding that turns a famous conjecture into formal mathematics.

## Proof Strategy Architecture

### Strategy A: Axiomatic transcendence-degree interface
**Most promising.**

1. Define a clean finite-family notion of adjoining coordinates `z i` and `exp(z i)` to `ℚ`.
2. Introduce either:
   - a direct `transcendenceDegree` wrapper from Mathlib if available, or
   - a surrogate notion based on algebraic independence of finite subsets.
3. State Schanuel using that interface and prove conditional consequences by abstract field-theoretic arguments.

**Why best:** this separates the foundational burden from the conjectural content. It creates reusable infrastructure for many future transcendence problems.

### Strategy B: Minimal conditional route to Lindemann–Weierstrass
1. Avoid full transcendence-degree formalization initially.
2. Postulate a finite-family Schanuel lower-bound axiom only in the exact form needed.
3. Derive:
   - nonzero algebraic `z` implies `exp z` transcendental,
   - finite algebraic Q-linearly independent families yield transcendence/linear independence consequences.

**Why useful:** fastest route to a substantial theorem. This can produce a clean conditional paper-grade Lean development even if transcendence-degree APIs are incomplete.

### Strategy C: Counterexample-guided refinement of false formulations
1. Test naive formulations involving `Finset`, duplicated coordinates, or wrong scalar fields.
2. Produce Lean counterexamples showing why distinctness, Q-linear independence, and finite-family indexing matter.
3. Refine the statement into the mathematically canonical one.

**Why necessary:** transcendence conjectures are delicate. Formalization will expose bad formulations immediately. Treat counterexamples as progress, not failure.


and transport lemmas between:

- `Finset ℂ` plus embeddings.

### 2. Algebraicity / transcendence API over `ℚ ⟶ ℂ`
Expect to need wrappers for:
- `IsAlgebraic ℚ z`,
- `Transcendental ℚ z`,
- closure under sums/products,
- “if `z` algebraic and `exp z` algebraic then contradiction under Schanuel”.

### 3. Distinct algebraic numbers imply Q-linear independence after normalization
For Lindemann–Weierstrass, the standard reduction passes from distinct algebraic numbers to a Q-linearly independent basis of their span. Formalize that reduction explicitly.

Possible theorem:

```lean
theorem exists_q_basis_of_span_algebraic
    {n : ℕ} (a : Fin n → ℂ)
    (ha_alg : ∀ i, IsAlgebraic ℚ (a i)) :
    ∃ m (b : Fin m → ℂ),
      LinearIndependent ℚ b ∧
      (∀ j, IsAlgebraic ℚ (b j)) ∧
      ∀ i, a i ∈ Submodule.span ℚ (Set.range b) := ...
```

This is the linear-algebra bridge between the analytic statement and the algebraic conclusion.

## Cross-domain connections you must exploit

### 1. Model theory / Ax–Schanuel
Schanuel is the informal ancestor of Ax–Schanuel-type inequalities. Even if you do not formalize model theory, shape your definitions so they could generalize from `exp : ℂ → ℂ` to abstract exponential fields. This is the bridge to:
- o-minimality,
- differential fields,
- functional transcendence.

### 2. Differential algebra
The map `z ↦ exp z` is characterized by `f' = f`. Formal transcendence-degree inequalities resemble dimension inequalities in differential algebra. This suggests a future path toward:
- formalized differential Galois theory,
- conditional proofs of algebraic independence using derivations.

### 3. Information theory / dimension theory
Schanuel is a dimension inequality. Treat transcendence degree as an algebraic analogue of entropy/rank. This perspective may help define finite-family APIs:
- “rank of additive data” = Q-linear dimension of `z_i`,
- “rank of multiplicative-exponential data” = transcendence degree of `(z_i, exp z_i)`.

### 4. Computer algebra / proof certificates
A formal Lindemann–Weierstrass consequence would enable certified transcendence claims for constants like `e`, `exp(α)` for nonzero algebraic `α`, and eventually symbolic proof certificates in CAS.
