## Research Task: Tropical Satake certified robustness for GL3 Hecke score classifiers under top-k decision rules

**Research Mode: PROVE**

Work in a new file
`Bridges/TropicalSatake/TropicalTopKRobustnessGL3.lean`.

The goal is to upgrade the existing tropical Satake / margin robustness story from **top-1 argmax stability** to **top-k ranking stability** for finitely many GL3 Hecke-score classes. The core new theorem should be an order-statistics stability result under uniform score perturbation, then a specialization to tropical Hecke scores using the already-developed Lipschitz/margin machinery.

This matters because the top-1 theorem only certifies invariance of a single winning label, while many representation-theoretic and ML-facing applications naturally use **set-valued decisions**: shortlist decoding, beam-search truncation, multiclass retrieval, and ranking-based certified robustness. A clean top-k theorem is the missing bridge between tropical score separation and certified robustness of ranking outputs. In particular, it should subsume the old argmax theorem as the case `k = 1`.

## Precise objects and suggested definitions

Use a finite label type rather than bare indices when possible:

```lean
open scoped BigOperators

variable {ι : Type*} [Fintype ι] [DecidableEq ι]
```

A good concrete definition of the top-k label set is by cardinal comparison against the strict upper level set:

```lean
def topKSet (score : ι → ℝ) (k : ℕ) : Finset ι :=
  Finset.univ.filter (fun i => (Finset.univ.filter fun j => score i < score j).card < k)
```

This definition is tie-tolerant in the right way for robustness statements phrased via a strict gap between selected and unselected labels. It avoids needing to choose an ordering of all labels.

Also define the score-gap predicate:

```lean
def topKGapAt (score : ι → ℝ) (k : ℕ) (Δ : ℝ) : Prop :=
  0 < Δ ∧
  ∀ ⦃i j : ι⦄, i ∈ topKSet score k → j ∉ topKSet score k → Δ ≤ score i - score j
```

And a uniform perturbation bound:

```lean
def UniformScoreClose (score score' : ι → ℝ) (η : ℝ) : Prop :=
  ∀ i, |score' i - score i| ≤ η
```

For the tropical specialization, it is useful to isolate the score family and its Lipschitz estimate abstractly first:

```lean
def IsKLipschitzFamily {α : Type*} (d : α → α → ℝ) (score : α → ι → ℝ) (K : ℝ) : Prop :=
  ∀ x y i, |score x i - score y i| ≤ K * d x y
```

Then the GL3 tropical theorem can simply assume such a bound coming from the previously verified tropical Satake reconstruction/robustness development.

## Main theorem 1: abstract top-k invariance under uniform perturbation

Prove the finite-dimensional order-stability theorem first.

A precise target statement:

```lean
theorem topKSet_eq_of_uniform_score_close
    (score score' : ι → ℝ) (k : ℕ) (Δ η : ℝ)
    (hk : k ≤ Fintype.card ι)
    (hgap : topKGapAt score k Δ)
    (hclose : UniformScoreClose score score' η)
    (hη : 2 * η < Δ) :
    topKSet score' k = topKSet score k
```

A slightly weaker pair of inclusions may be easier to prove first:

```lean
theorem topKSet_subset_of_uniform_score_close
    (score score' : ι → ℝ) (k : ℕ) (Δ η : ℝ)
    (hgap : topKGapAt score k Δ)
    (hclose : UniformScoreClose score score' η)
    (hη : 2 * η < Δ) :
    topKSet score k ⊆ topKSet score' k
```

and its symmetric converse by swapping `score` and `score'`, after proving that the same gap structure excludes boundary crossing.

A more elementary and likely easier formulation is to prove first the pairwise separation lemma:

```lean
lemma separated_order_preserved_of_uniform_score_close
    (score score' : ι → ℝ) (i j : ι) (Δ η : ℝ)
    (hsep : Δ ≤ score i - score j)
    (hclose : UniformScoreClose score score' η)
    (hη : 2 * η < Δ) :
    score' j < score' i
```

This lemma is the engine of the whole argument.

### Suggested proof strategy
1. Expand `UniformScoreClose` at `i` and `j`, and derive
   `score i - η ≤ score' i` and `score' j ≤ score j + η`
   using `abs_le.mp`.
2. From `Δ ≤ score i - score j` and `2 * η < Δ`, obtain
   `score j + η < score i - η`.
3. Combine the two inequalities to conclude `score' j < score' i`.
4. For `i ∈ topKSet score k`, show every `j ∉ topKSet score k` still satisfies `score' j < score' i`; thus no outside label can overtake any inside label.
5. Convert this pairwise “inside beats outside” statement into equality of `topKSet`s by cardinal/ranking reasoning on `Finset.univ.filter`.

A useful intermediate characterization to prove is:

```lean
lemma mem_topKSet_iff_card_lt
    (score : ι → ℝ) (k : ℕ) (i : ι) :
    i ∈ topKSet score k ↔
      (Finset.univ.filter fun j => score i < score j).card < k := by
  rfl
```

You may also want a “boundary-separation implies exact cardinality” lemma when `k ≤ Fintype.card ι` and every inside score is strictly larger than every outside score:

```lean
lemma card_topKSet_of_strict_boundary
    (score : ι → ℝ) (k : ℕ)
    (hcard : k ≤ Fintype.card ι)
    (hboundary : ∀ ⦃i j⦄, i ∈ topKSet score k → j ∉ topKSet score k → score j < score i) :
    (topKSet score k).card = k
```

This is not completely trivial, but once established it makes the final equality proof much cleaner.

## Main theorem 2: metric/Lipschitz version

After the abstract perturbation theorem, package the metric form.

A target statement:

```lean
theorem topKSet_eq_of_lipschitz_gap
    {α : Type*} (d : α → α → ℝ) (score : α → ι → ℝ)
    (K : ℝ) (x x' : α) (k : ℕ) (Δ ε : ℝ)
    (hk : k ≤ Fintype.card ι)
    (hlip : IsKLipschitzFamily d score K)
    (hgap : topKGapAt (score x) k Δ)
    (hdist : d x x' ≤ ε)
    (hKnonneg : 0 ≤ K)
    (hεnonneg : 0 ≤ ε)
    (hmargin : 2 * K * ε < Δ) :
    topKSet (score x') k = topKSet (score x) k
```

This should be a short corollary of Main theorem 1 with `η := K * ε`.

### Suggested proof strategy
1. Use `hlip x x' i` and `hdist` to get
   `|score x' i - score x i| ≤ K * ε` for all `i`.
2. Package this as `UniformScoreClose (score x) (score x') (K * ε)`.
3. Rewrite `2 * (K * ε)` as `2 * K * ε` (or use `ring_nf`) to match the margin assumption.
4. Apply `topKSet_eq_of_uniform_score_close`.

## Main theorem 4: explicit tropical certificate form

Now connect the abstract top-k theorem back to GL3 tropical Satake score reconstruction. Keep this theorem flexible enough to match the exact names of the existing GL3 separation/reconstruction lemmas.

A schematic but precise target shape is:

```lean
theorem tropical_GL3_topK_certified_robust
    {α : Type*} (d : α → α → ℝ) (score : α → ι → ℝ)
    (K : ℝ) (x x' : α) (k : ℕ)
    (Δ edgeCert leviCert ε : ℝ)
    (hk : k ≤ Fintype.card ι)
    (hΔdef : Δ = edgeCert + leviCert)
    (hΔpos : 0 < Δ)
    (hsep :
      ∀ ⦃i j : ι⦄, i ∈ topKSet (score x) k → j ∉ topKSet (score x) k →
        Δ ≤ score x i - score x j)
    (hlip : IsKLipschitzFamily d score K)
    (hdist : d x x' ≤ ε)
    (hKnonneg : 0 ≤ K)
    (hεnonneg : 0 ≤ ε)
    (hmargin : 2 * K * ε < Δ) :
    topKSet (score x') k = topKSet (score x) k
```

Here `edgeCert` and `leviCert` are placeholders for the explicit separation quantities obtained from the GL3 finite test-family theorem: simple-coroot edge valuations plus rank-2 Levi marginal contributions. If the existing GL3 theorems give a more structured certificate, refine the theorem so `Δ` is literally that expression instead of an existentially introduced real.

### Suggested proof strategy
1. Use the tropical reconstruction/separation theorem to instantiate `hsep` from the explicit GL3 certificate.
2. Convert that into `topKGapAt (score x) k Δ` using `hΔpos`.
3. Apply `topKSet_eq_of_lipschitz_gap`.
4. If the existing theorem gives score variation directly rather than a metric Lipschitz estimate, bypass `IsKLipschitzFamily` and apply Main theorem 1 directly.

The key mathematical point is that **only the boundary gap between the k-th and (k+1)-st score levels matters**. The GL3 tropical Satake machinery should be used to compute or lower-bound that gap from representation-theoretic data, not to redo the ranking argument.

## Stronger weighted/boundary form

If feasible, prove a sharper theorem where the certificate is only needed on the top-k boundary, not for all inside/outside pairs. For example, define:

```lean
def topKBoundaryGapAt (score : ι → ℝ) (k : ℕ) (Δ : ℝ) : Prop :=
  0 < Δ ∧
  ∀ ⦃i j : ι⦄,
    i ∈ topKSet score k →
    j ∉ topKSet score k →
    score j ≤ score i - Δ
```

and show this is equivalent to the previous formulation. Then investigate whether the GL3 separation theorem naturally gives such a boundary-gap statement more directly than a full pairwise one.

A useful stronger conclusion is a no-new/no-lost-label decomposition:

```lean
theorem topKSet_preserved_of_lipschitz_gap_iff
    {α : Type*} (d : α → α → ℝ) (score : α → ι → ℝ)
    (K : ℝ) (x x' : α) (k : ℕ) (Δ ε : ℝ)
    ... :
    (∀ i, i ∈ topKSet (score x') k ↔ i ∈ topKSet (score x) k)
```

This pointwise membership form is often easier to reuse downstream than equality of finsets.

## Concrete proof steps to prioritize

1. **Pairwise perturbation lemma**: from `|δ_i|, |δ_j| ≤ η` and `score i - score j ≥ Δ > 2η`, deduce `score' i > score' j`.
2. **Boundary preservation lemma**: every old top-k label still beats every old non-top-k label after perturbation.
3. **Cardinality control**: show strict boundary separation forces exactly `k` labels on the winning side, hence the preserved boundary relation implies equality of the top-k sets.
4. **Lipschitz corollary**: specialize the abstract theorem with `η = K * ε`.
5. **GL3 certificate corollary**: instantiate `Δ` from the tropical Satake finite test-family separation theorem.

## Why this is a meaningful extension

This theorem creates the correct formal bridge between tropical representation-theoretic score separation and **certified robustness of ranking outputs**, not just winner-take-all decisions. It should become the canonical robustness statement for tropical Hecke classifiers with shortlist outputs. It also provides a reusable abstract lemma on finite score families that is independent of GL3 and likely useful elsewhere in the robustness development. Most importantly, the explicit GL3 certificate version turns representation-theoretic separation data into a verifiable multiclass robustness guarantee, which is exactly the kind of theorem needed to push the tropical Satake program from structural identities toward certified inference.
