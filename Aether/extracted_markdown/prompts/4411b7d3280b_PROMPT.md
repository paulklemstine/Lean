**Mode:** `prove`

Prove genuinely new theorems that elevate probe complexity into a bona fide **categorical dimension theory**. The target is not a small extension of existing cardinality bounds, but a structural theorem explaining when a family of probes controls the minimal representable complexity of all observable presheaves on a finite category.

Build directly on:

  - especially `card_presheaf_le_card_restrictions`
  - and `probeRestrictionMap_injective`
- `Catalog/Pythagorean/ProbeComplexity/Defs.lean`
  - especially `probeComplexity`

Your mission is to define a new invariant — **representable dimension relative to probes** — and prove comparison theorems showing that probe observability bounds, and in favorable regimes exactly determines, the minimal number of representable generators needed to recover a presheaf.

This is potentially a breakthrough because it turns “what probes can distinguish” into a **dimension theory of categorical observability**, analogous to VC dimension, metric dimension, and information dimension, but living in presheaf geometry. If successful, this opens a new field: **categorical complexity via measurement**.

## Core Vision

A probe family should not merely separate points; it should quantify how many **representable coordinates** are needed to encode every observable presheaf. The conjectural principle is:

> **Observable complexity = representable dimension = measurement-space size.**

That is a radical claim. It says that the complexity of all finite-valued presheaves visible to a probe family is governed by a computable invariant extracted solely from probe measurements.

The deep idea is to recast presheaves as **hidden states** and probes as **measurement channels**. Then representable generators play the role of latent basis states, and the measurement-space invariant becomes an information budget. This links:
- category theory ↔ information theory
- presheaf representation ↔ learning theory
- probe separation ↔ metric/VC dimension
- finite categorical geometry ↔ experimental design

## New Definitions to Introduce

You must define at least one genuinely new concept not already present in the catalog. The following are strong candidates and should be formalized cleanly.

### 1. Representable cover size
For a presheaf `F`, define the minimal cardinality of a family of representables whose coproduct admits a surjection onto `F`.

Informally:
- a **representable cover** of `F` is a finite indexed family `Σ i, yoneda.obj (op (Y i))` together with an epimorphism / pointwise-surjective natural transformation onto `F`;
- the **representable dimension** is the minimum size of such a family.

### 2. Measurement space at an object
For a probe family `P`, define `MeasurementSpace(P, Y)` as the image of the restriction/signature map recording how elements of `F.obj (op Y)` are seen by probes in `P`.

If the catalog already contains a restriction map, package its image as a finite type or `Finset`-cardinality invariant.

### 3. Probe-measurement invariant
Define
\[
\mathrm{measInv}(C,P) := \sum_{Y \in \mathrm{Ob}(C)} |\mathrm{MeasurementSpace}(P,Y)|.
\]

This should be computable for finite categories.

## Precise Theorem Targets

You need at least 3 substantial theorems. The following are the right targets.

### Theorem 1: Upper bound by measurement complexity
For finite categories and finite-valued presheaves separated by `P`, representable dimension is bounded by the total measurement-space size.

#### Mathematical statement
Let `C` be a finite category, `P` a probe family, and `F : Cᵒᵖ ⥤ Type` a finite-valued presheaf. Assume `P` separates `F` in the sense that probe signatures distinguish elements objectwise. Then
\[
\operatorname{repDim}_P(F) \le \sum_{Y \in \mathrm{Ob}(C)} |\mathrm{MeasurementSpace}(P,Y)|.
\]

This should be derived by combining injectivity of probe restriction maps with finite representability bounds.

#### Suggested Lean 4 type signature
You may need to adapt names to the actual catalog API, but aim for a theorem of this shape:

```lean
theorem representableDimension_le_measurementInvariant
  {C : Type u} [SmallCategory C] [Fintype C]
  (P : ProbeFamily C)
  (F : Cᵒᵖ ⥤ Type v)
  [FiniteValuedPresheaf F]
  (hsep : ProbeSeparates P F) :
  representableDimension P F ≤ measurementInvariant P
```

If `representableDimension` is defined independently of `P`, then use:

```lean
theorem representableDimension_le_measurementInvariant
  {C : Type u} [SmallCategory C] [Fintype C]
  (P : ProbeFamily C)
  (F : Cᵒᵖ ⥤ Type v)
  [FiniteValuedPresheaf F]
  (hsep : ProbeSeparates P F) :
  representableDimension F ≤ measurementInvariant P
```

### Theorem 2: Objectwise bound from probe signatures
At each object `Y`, the number of elements of `F.obj (op Y)` is bounded by the cardinality of the measurement space, hence any generator set at `Y` is bounded likewise.

#### Mathematical statement
For each object `Y`,
\[
|F(Y)| \le |\mathrm{MeasurementSpace}(P,Y)|
\]
whenever probe restrictions at `Y` are injective.

This is the local engine behind Theorem 1 and should use the catalog theorem `probeRestrictionMap_injective`.

#### Suggested Lean 4 type signature
```lean
theorem card_obj_le_measurementSpace
  {C : Type u} [SmallCategory C]
  [Fintype C]
  (P : ProbeFamily C)
  (F : Cᵒᵖ ⥤ Type v)
  [FiniteValuedPresheaf F]
  {Y : C}
  (hinj : Function.Injective (probeRestrictionMap P F Y)) :
  Fintype.card (F.obj (Opposite.op Y)) ≤ measurementSpaceCard P Y
```

### Theorem 3: Realization / lower bound theorem
Construct a finite-valued presheaf whose representable dimension is at least the number of distinct measurement signatures realized by `P`, or prove this for a broad class of categories (e.g. discrete finite categories, thin categories, or categories with enough terminal probes).

#### Mathematical statement
For a suitable class of finite categories `C` and probe families `P`,
\[
\mathrm{measurementInvariant}(C,P) \le \sup_F \operatorname{repDim}_P(F),
\]
where the supremum ranges over finite-valued `P`-separated presheaves.

Even a theorem for **discrete categories** would already be meaningful and nontrivial:
for discrete finite `C`, the supremum equals the sum of objectwise measurement-space cardinalities.

#### Suggested Lean 4 type signature
A practical first target is the discrete case:

```lean
theorem measurementInvariant_le_sup_representableDimension_discrete
  {C : Type u} [SmallCategory C] [Fintype C] [IsDiscrete C]
  (P : ProbeFamily C) :
  measurementInvariant P ≤
    sSup {n : ℕ | ∃ F : Cᵒᵖ ⥤ Type v, FiniteValuedPresheaf F ∧
      ProbeSeparates P F ∧ representableDimension F = n}
```

If `sSup` over naturals is awkward, define an explicit `maxRepresentableDimension` over a finite search space for finite-valued presheaves of bounded size, or formulate an existential lower bound theorem by constructing a witness presheaf.

### Theorem 4: Equality theorem in a tractable regime
You should aim for a regime where the grand challenge is actually proved, not merely bounded.

#### Strong target
For finite discrete categories:
\[
\sup_F \operatorname{repDim}(F) = \sum_{Y} |\mathrm{MeasurementSpace}(P,Y)|.
\]

This is the cleanest proving ground. In a discrete category, presheaves are just families of finite sets, representables are object-indicators, and the theory reduces to a combinatorial dimension statement. If you prove the equality there, you establish the first rigorous instance of the conjectural dimension principle.

#### Suggested Lean 4 type signature
```lean
theorem sup_representableDimension_eq_measurementInvariant_discrete
  {C : Type u} [SmallCategory C] [Fintype C] [IsDiscrete C]
  (P : ProbeFamily C) :
  supRepresentableDimension P = measurementInvariant P
```

You may define `supRepresentableDimension` however is most formalization-friendly.

## Proof Architecture: 3 Viable Strategies

You must include multi-step proofs, not one-line automation. Use induction, `rcases`, `by_contra`, `field_simp` where appropriate, and long `calc` chains.

### Strategy A — Compression via injective measurement coding
**Most promising for the upper bound.**

1. For each object `Y`, use `probeRestrictionMap_injective` to show that each element of `F.obj (op Y)` has a unique probe signature.
2. Conclude
   \[
   |F(Y)| \le |\mathrm{MeasurementSpace}(P,Y)|.
   \]
3. Sum objectwise cardinality bounds over all `Y`.
4. Invoke `card_presheaf_le_card_restrictions` or an adapted finite representability theorem to convert total objectwise cardinality bounds into a bound on representable cover size.
5. Package the result as `representableDimension_le_measurementInvariant`.

Why this is promising: it directly exploits the catalog’s strongest certified ingredients and upgrades cardinality control into dimension control.

### Strategy B — Constructive representable synthesis
**Best for obtaining an explicit algorithm and a verified construction.**

1. For each realized measurement signature, choose a canonical representable generator.
2. Build a coproduct of representables indexed by all measurement signatures.
3. Define a natural transformation from this coproduct onto `F`.
4. Prove pointwise surjectivity by decoding each element of `F(Y)` from its signature.
5. Conclude a concrete upper bound on representable dimension.

Why this matters: it does not just prove existence; it yields the required **verified algorithm** that constructs a representable cover from probe data.

### Strategy C — Extremal witness presheaves for the lower bound
**Best for the discrete or thin-category equality theorem.**

1. Construct a presheaf `F_P` whose elements at each object are exactly the measurement signatures.
2. Define restriction maps by pullback/reindexing of signatures.
3. Prove `F_P` is separated by `P`.
4. Show distinct signatures require distinct representable generators, giving
   \[
   \operatorname{repDim}(F_P) \ge \sum_Y |\mathrm{MeasurementSpace}(P,Y)|.
   \]
5. Combine with Strategy A to deduce equality.

Why this is revolutionary: it turns probe signatures from a passive invariant into an active universal object encoding the whole observable geometry.

## Lean Formalization Guidance

You should be explicit and careful about what “representable dimension” means in Lean. A robust route is:

- Define a structure expressing a finite representable cover:
```lean
structure RepresentableCover
  {C : Type u} [SmallCategory C] (F : Cᵒᵖ ⥤ Type v) where
  ι : Type w
  [fintype_ι : Fintype ι]
  Y : ι → C
  π : (∐ fun i : ι => yoneda.obj (Opposite.op (Y i))) ⟶ F
  surj : ∀ X, Function.Surjective (π.app X)
```

- Then define:
```lean
noncomputable def representableDimension
  {C : Type u} [SmallCategory C] (F : Cᵒᵖ ⥤ Type v) : ℕ :=
  sInf {n : ℕ | ∃ cov : RepresentableCover F, Fintype.card cov.ι = n}
```

If coproducts of representables in `Type` become cumbersome, use an equivalent combinatorial surrogate:
- a finite family of object-elements generating all sections via Yoneda;
- or an objectwise encoding theorem equivalent to representable cover size in your finite setting.

A more formalization-friendly intermediate notion may be:

```lean
def generatorFamily
  (F : Cᵒᵖ ⥤ Type v) :=
  Σ (ι : Type w) (_ : Fintype ι), (ι → Σ Y : C, F.obj (Opposite.op Y))
```

Then define a closure predicate saying every section of `F` is induced from some chosen generator via functoriality. The exact notion can be tuned to the available library support, but it must be mathematically meaningful and nontrivial.

## Required Cross-Domain Theorems and Interpretations

You must include at least one theorem that explicitly bridges this theory to another domain.

### Cross-domain theorem candidate A — Metric dimension analogy
For a discrete category coming from a finite graph viewed as a thin category or object-indexed measurement system, show that probe separation implies a bound analogous to metric dimension:
\[
\operatorname{repDim}(F) \le \text{number of distinct distance-signatures}.
\]

This connects probe complexity to graph resolvability.

### Cross-domain theorem candidate B — Learning theory / VC-style interpretation
Formalize the idea that measurement signatures define a hypothesis class on objectwise sections, and prove:
- if probe signatures shatter a family of sections, then representable dimension is at least the shattering number;
- or at minimum, prove a finite bound showing representable dimension controls the number of observable labelings.

This would be the first step toward a categorical analogue of VC dimension.

### Cross-domain theorem candidate C — Information-theoretic compression
Interpret `measurementInvariant P` as an information budget. Prove a counting theorem:
\[
\#\{\text{observable sections}\} \le \prod_Y |\mathrm{MeasurementSpace}(P,Y)|.
\]
Then deduce
\[
\log \#\{\text{observable sections}\} \le \sum_Y \log |\mathrm{MeasurementSpace}(P,Y)|.
\]
Even if the logarithmic form stays informal in Lean, the multiplicative counting theorem can be formalized exactly. This is a genuine bridge to information theory.
