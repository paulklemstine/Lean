## Research Task: Algebraic tropicalization of EML function algebras via a tropical Gelfand–Kolmogorov duality for max-plus character spaces

Research Mode: PROVE

Work in a concrete formalization where the “tropical algebra” is implemented on a function subsemiring of `X → ℝ` using pointwise `sup` as tropical addition and real addition by constants as tropical scalar action. If a full semiring-valued target into `ℝ∞` or `WithBot ℝ` becomes too heavy, first prove the duality for a concrete `ℝ`-valued max-plus function algebra with finite suprema and constant shifts, then isolate the extension to a genuine tropical semifield target as a second theorem.

The core breakthrough is to show that an EML-generated idempotent function algebra does not merely approximate observables on a compact space: it *remembers the space itself*. This is the tropical analogue of the classical Gelfand–Kolmogorov reconstruction principle, but in an idempotent/max-plus regime adapted to EML semantics. If successful, this turns EML approximation theory into spectral semantics: models become recoverable from their tropical observable algebra.

### Precise Formalization Target

You should define a structure of tropical characters on a function algebra `A ⊆ C(X, ℝ)` that preserves constants and finite suprema. Avoid over-abstracting at first; use a bundled sublattice/subalgebra of functions if convenient.

A practical first layer is:

```lean
structure TropChar (A : Set (C(X, ℝ))) where
  toFun : C(X, ℝ) → ℝ
  mem_respects : ∀ {f}, f ∈ A → True
  map_const : ∀ c : ℝ, toFun (ContinuousMap.const X c) = c
  map_sup : ∀ {f g : C(X, ℝ)}, f ∈ A → g ∈ A →
    toFun (f ⊔ g) = max (toFun f) (toFun g)
  map_add_const : ∀ {f : C(X, ℝ)} (hf : f ∈ A) (c : ℝ),
    toFun (f + ContinuousMap.const X c) = toFun f + c
```

If bundling as a map on all of `C(X, ℝ)` is awkward, replace this with a bundled subtype version:

```lean
def TropSubalg (X : Type*) [TopologicalSpace X] :=
  Set (C(X, ℝ))

structure TropCharSub (A : TropSubalg X) where
  toFun : {f // f ∈ A} → ℝ
  map_const : ∀ c : ℝ, toFun ⟨ContinuousMap.const X c, by sorry⟩ = c
  map_sup : ∀ (f g : {f // f ∈ A}),
    toFun ⟨f.1 ⊔ g.1, by sorry⟩ = max (toFun f) (toFun g)
  map_add_const : ∀ (f : {f // f ∈ A}) (c : ℝ),
    toFun ⟨f.1 + ContinuousMap.const X c, by sorry⟩ = toFun f + c
```

### Proof Strategy: Three Viable Routes

#### Strategy A: Order-theoretic classification via peak functions
This is the most promising route.

1. **Show monotonicity of characters from sup-preservation.**  
   Prove that if `f ≤ g` pointwise and both lie in `A`, then
   `φ f ≤ φ g`. The key identity is `g = f ⊔ g`, so
   `φ g = max (φ f) (φ g)`. This gives an order-theoretic handle on `φ`.

   Useful lemma target:
   ```lean
   theorem TropCharSub.monotone
       (φ : TropCharSub A) :
       Monotone φ.toFun
   ```

2. **Show 1-Lipschitz behavior for the sup norm once constant shifts are preserved.**  
   If `‖f - g‖∞ ≤ c`, then `f ≤ g + c` and `g ≤ f + c`, hence by monotonicity and `map_add_const`,
   `φ f ≤ φ g + c` and `φ g ≤ φ f + c`. Therefore
   `|φ f - φ g| ≤ c`. This continuity is what lets density determine a character uniquely.

   Precise lemma:
   ```lean
   theorem TropCharSub.lipschitz_supNorm
       (φ : TropCharSub A) :
       ∀ ⦃f g : {f // f ∈ A}⦄, |φ.toFun f - φ.toFun g| ≤ ‖f.1 - g.1‖∞
   ```

3. **Classify characters on the full algebra using compactness and Urysohn-style peak functions.**  
   For each character `φ` on `C(X, ℝ)`, define the closed family
   of sets on which functions “nearly attain” `φ(f)`. Use compactness plus finite suprema to show there is a point `x` compatible with all these constraints. Then prove `φ(f) = f(x)` for all `f`.  
   The tropical analogue of the classical kernel/maximal ideal argument is: the character picks a coherent “maximizing state,” and compact Hausdorff separation prevents multiple such states.

4. **Transfer from the full algebra to a dense subalgebra.**  
   Use the Lipschitz/continuity lemma to extend equality from a dense subset. If `A` is uniformly dense and `φ` is uniformly continuous, then `φ` is uniquely determined by its values on approximants, hence must coincide with evaluation at the same `x`.

This route is strongest because it turns tropical algebraic axioms directly into analytic rigidity.

#### Strategy B: Embed into product space and identify extremal points
1. Define the spectrum as a subset of the product `ℝ^A`.
2. Show evaluation points satisfy the character axioms and form a compact subset.
3. Use separation to show `evalMap A` is an embedding.
4. Use density to show every character is determined by coordinatewise limits of evaluations on approximating peak functions.
5. Deduce surjectivity by compactness plus uniqueness of coordinate functionals.

This route is good if topology on products and compactness lemmas are already easy to access in Mathlib.

#### Strategy C: Finite-observable reconstruction first, then compact limit
1. First prove a finite-coordinate theorem: for any finite family `F ⊆ A`, any character is determined by a point maximizing all observables in a compatible way.
2. Build a closed-set intersection system over finite families.
3. Use compactness to extract a global point.
4. Prove uniqueness via separation.

This route is technically robust if full extension arguments become difficult.

### Concrete Proof Steps and Key Lemmas

You should aim to establish the following lemmas in order:

1. **Evaluation is a tropical character.**
   ```lean
   theorem evalTropChar_apply
       (A : TropSubalg X) (x : X) (f : {f // f ∈ A}) :
       (evalTropChar A x).toFun f = f.1 x
   ```

2. **Sup-preserving implies monotone.**
   ```lean
   theorem tropChar_monotone
       (φ : TropCharSub A)
       {f g : {f // f ∈ A}}
       (hfg : f.1 ≤ g.1) :
       φ.toFun f ≤ φ.toFun g
   ```

3. **Constant-shift preservation gives translation equivariance.**
   ```lean
   theorem tropChar_add_const
       (φ : TropCharSub A)
       (f : {f // f ∈ A}) (c : ℝ) :
       φ.toFun ⟨f.1 + ContinuousMap.const X c, by sorry⟩ = φ.toFun f + c
   ```

4. **Uniform continuity/Lipschitz property.**
   ```lean
   theorem tropChar_uniform_continuous
       (φ : TropCharSub A) :
       UniformContinuous φ.toFun
   ```
   or a more manageable metric inequality as above.

5. **Separation gives injectivity.**
   Use `hsep` to pick `f ∈ A` with `f x ≠ f y`, then show the two evaluation characters differ on `⟨f, hf⟩`.

6. **Character on full algebra is evaluation at a unique point.**
   The crucial compactness step may need an auxiliary definition of the support/argmax closed sets:
   ```lean
   def charCarrier (φ : TropCharSub (Set.univ : TropSubalg X)) (f : C(X, ℝ)) : Set X :=
     {x | φ.toFun ⟨f, by trivial⟩ = f x}
   ```
   Then prove `charCarrier φ f` is closed and nonempty, and the finite intersection property is preserved under sup:
   ```lean
   theorem charCarrier_inter_sup ...
   ```
   Compactness then gives `x` in the intersection of all carriers, yielding `φ(f)=f(x)` for every `f`.

7. **Dense-subalgebra transfer.**
   If `fₙ ∈ A` converge uniformly to `g ∈ C(X,ℝ)`, then the Lipschitz property shows `φ(fₙ)` is Cauchy and agrees with `g(x)` if `φ = eval_x` on approximants. Use uniqueness to conclude.

### Why This Matters

This theorem changes the role of EML in the research program. Existing approximation results say EML observables can *approximate* continuous tropical data. Your new result says the observable algebra can *reconstruct the latent space itself*. That is a categorical jump: from approximation theory to spectral semantics.

This opens at least three major directions:

1. **Spectral semantics for EML models.**  
   A finitely generated EML tropical algebra yields an intrinsic state space via its characters. This creates a mathematically canonical notion of semantic compression.

2. **Idempotent nonclassical duality.**  
   Classical Gelfand theory relies on linear/multiplicative structure over rings or C*-algebras. Your theorem would show that max-plus/idempotent structure alone already supports a reconstruction principle.

3. **Algorithmic reconstruction.**  
   Once characters are evaluations, one can search for states by optimizing generators. This gives an algorithmic shadow: recover points from finite tropical observables, with potential applications to model identification and latent-state extraction.

4. **Bridge to tropical probability and decision theory.**  
   Characters are “deterministic extremal states” in an idempotent world. This suggests a future Choquet/Krein–Milman theory for tropical EML semantics.
