## Research Task: GL₃ tropical Satake finite-generation of dominant support from simple-coroot edge data and rank-2 Levi convolution profiles

Research Mode: PROVE

Work in the concrete GL₃ dominant chamber model already used in the tropical Satake files: represent a dominant coweight by a pair `(a,b) : ℕ × ℕ`, corresponding to the nonnegative simple-coroot coordinates. A finitely supported dominant support function is then a function
`f : (ℕ × ℕ) → ℤ` or `f : (ℕ × ℕ) → ℝ`
with finite support. The theorem should be stated for whichever coefficient type is already used for tropical convolution in the GL₃ files; if both are available, prove the integer-valued version first and derive the real-valued version by coercion.

The goal is to prove a genuine coordinate theorem: interior values of `f` are determined by the two boundary rays and the two rank-2 Levi convolution observables, and conversely compatible such data extend uniquely.

### Precise theorem targets

First define the two edge restrictions:
```lean
def edge01 (f : ℕ × ℕ → R) : ℕ → R := fun a => f (a, 0)
def edge10 (f : ℕ × ℕ → R) : ℕ → R := fun b => f (0, b)
```
where `R` is the coefficient type used in the existing convolution theory.

Assume the GL₃ tropical files already contain the two standard rank-2 Levi generators, or enough infrastructure to define them as finitely supported kernels:
```lean
def leviLeftGen  : (ℕ × ℕ) → R := ...
def leviRightGen : (ℕ × ℕ) → R := ...
```
and a tropical/Hecke convolution operation on finitely supported functions:
```lean
def tconv (f g : (ℕ × ℕ) → R) : (ℕ × ℕ) → R := ...
```
If the existing API uses `Finsupp`, formulate theorems there and derive pointwise corollaries.

A strong injective finite-generation statement should have a shape close to:
```lean
theorem edge_levi_data_injective
  (f g : (ℕ × ℕ) → R)
  (hf : Finite {p | f p ≠ 0})
  (hg : Finite {p | g p ≠ 0})
  (hedge1 : edge01 f = edge01 g)
  (hedge2 : edge10 f = edge10 g)
  (hleviL : tconv f leviLeftGen = tconv g leviLeftGen)
  (hleviR : tconv f leviRightGen = tconv g leviRightGen) :
  f = g
```
or, in finitely supported form:
```lean
theorem edge_levi_data_injective_finsupp
  (f g : ((ℕ × ℕ) →₀ R))
  (hedge1 : ∀ a, f (a,0) = g (a,0))
  (hedge2 : ∀ b, f (0,b) = g (0,b))
  (hleviL : tconv f leviLeftGen = tconv g leviLeftGen)
  (hleviR : tconv f leviRightGen = tconv g leviRightGen) :
  f = g
```

Then formulate the reconstruction/extension theorem. A useful way to package the data is:
```lean
structure EdgeLeviData (R : Type _) where
  leftEdge  : ℕ → R
  rightEdge : ℕ → R
  leftProf  : (ℕ × ℕ) → R
  rightProf : (ℕ × ℕ) → R
```
and a compatibility predicate expressing the local difference identities that hold for any actual support function:
```lean
def EdgeLeviCompatible (D : EdgeLeviData R) : Prop := ...
```
Then prove:
```lean
theorem exists_unique_of_compatible_edge_levi_data
  (D : EdgeLeviData R)
  (hcomp : EdgeLeviCompatible D)
  (hfin_edges :
    (Finite {a | D.leftEdge a ≠ 0}) ∧
    (Finite {b | D.rightEdge b ≠ 0}))
  (hfin_prof :
    (Finite {p | D.leftProf p ≠ 0}) ∧
    (Finite {p | D.rightProf p ≠ 0})) :
  ∃! f : (ℕ × ℕ) → R,
    (Finite {p | f p ≠ 0}) ∧
    (edge01 f = D.leftEdge) ∧
    (edge10 f = D.rightEdge) ∧
    (tconv f leviLeftGen = D.leftProf) ∧
    (tconv f leviRightGen = D.rightProf)
```
If the compatibility predicate is too ambitious to characterize in one step, it is acceptable to prove a two-stage theorem:

1. a **canonical reconstruction formula**
```lean
def reconstructFromEdgeLevi (D : EdgeLeviData R) : (ℕ × ℕ) → R := ...
```
2. a theorem saying that if `D` satisfies explicit local identities, then this reconstructed function has the required edges and Levi profiles:
```lean
theorem reconstructFromEdgeLevi_spec ...
```
3. uniqueness from `edge_levi_data_injective`.

A very concrete interior recovery lemma should also be isolated, since it is the engine of the induction:
```lean
theorem interior_value_determined_by_edge_and_levi
  (f g : (ℕ × ℕ) → R)
  (hf : Finite {p | f p ≠ 0}) (hg : Finite {p | g p ≠ 0})
  (hboundary :
    (∀ a, f (a,0) = g (a,0)) ∧
    (∀ b, f (0,b) = g (0,b)))
  (hleviL : tconv f leviLeftGen = tconv g leviLeftGen)
  (hleviR : tconv f leviRightGen = tconv g leviRightGen) :
  ∀ a b, f (a,b) = g (a,b)
```
The proof should proceed by induction on chamber depth `a + b`. This theorem may be easier to establish before packaging the global equality.

### Proof strategy

1. **Pass to the difference function**  
   Set `h := f - g`. Reduce injectivity to proving `h = 0` under vanishing edge data and vanishing Levi convolution profiles:
   ```lean
   edge01 h = 0, edge10 h = 0,
   tconv h leviLeftGen = 0, tconv h leviRightGen = 0.
   ```
   This is the cleanest algebraic form. If the convolution API is additive, use linearity to derive these immediately. If the tropical operation is only monotone/max-plus flavored, isolate the exact cancellation/difference lemma already available in the GL₃ reconstruction files and reuse it.

2. **Derive a local recurrence for interior coefficients**  
   The key mathematical step is that convolving with each rank-2 Levi generator should produce a relation involving a point `(a,b)` and its adjacent predecessors, typically of one of the forms
   ```lean
   h (a+1,b) = ΦL( (tconv h leviLeftGen) (a,b), h (a,b), h (a,b+1), ... )
   ```
   or
   ```lean
   h (a,b+1) = ΦR( (tconv h leviRightGen) (a,b), h (a,b), h (a+1,b), ... )
   ```
   for explicit `ΦL`, `ΦR`. Since the Levi kernels are rank-2, the relation should only involve a small stencil near `(a,b)`. Prove these as named lemmas. They are the actual “propagation identities” that move information from boundary/facet data into the chamber interior.

3. **Induct on depth `a + b`**  
   Use strong induction on `n = a + b`.  
   - Base case `n = 0`: the value at `(0,0)` is fixed by both edges.  
   - Boundary cases `a = 0` or `b = 0`: given directly by edge equality.  
   - Interior case `a,b > 0`: apply one of the local Levi recurrences to express `h (a,b)` in terms of values of strictly smaller depth and a vanishing convolution observable.  
   This gives `h (a,b) = 0`.  
   The crucial well-founded measure is the chamber depth; if the local recurrence preserves depth in one coordinate, switch to lexicographic induction on `(a+b, a)`.

4. **Construct the extension from compatible data**  
   Define `reconstructFromEdgeLevi D` recursively on depth.  
   - On the two edges, set values to `D.leftEdge` and `D.rightEdge`.  
   - For interior `(a,b)`, solve for the unknown coefficient using the local Levi identity and already-known lower-depth values.  
   Compatibility must guarantee that the value recovered from the left-Levi recurrence agrees with the value recovered from the right-Levi recurrence.  
   This is exactly the nontrivial consistency condition; formulate it as a local square/diamond identity on `D.leftProf` and `D.rightProf`.

5. **Prove finite support of the reconstruction**  
   Since the input edge and Levi profiles are finitely supported, show there is an explicit depth bound beyond which the recursive formula forces all coefficients to vanish. If needed, first prove a weaker theorem:
   ```lean
   ∃ N, ∀ a b, N < a + b → reconstructFromEdgeLevi D (a,b) = 0
   ```
   and then deduce finite support. This is important: the theorem is not merely uniqueness on an infinite grid, but finite generation of finitely supported dominant support functions.

### Concrete intermediate lemmas worth proving

These are likely the right stepping stones and should be stated explicitly in Lean.

A depth induction principle:
```lean
theorem nat_pair_depth_induction
  {P : ℕ → ℕ → Prop}
  (hstep :
    ∀ a b, (∀ a' b', a' + b' < a + b → P a' b') → P a b) :
  ∀ a b, P a b
```
This will simplify all chamber-recursive proofs.

A support bound lemma:
```lean
theorem finite_support_of_depth_bounded
  (f : (ℕ × ℕ) → R)
  (h : ∃ N, ∀ a b, N < a + b → f (a,b) = 0) :
  Finite {p | f p ≠ 0}
```
or the `Finsupp` analogue.

A boundary-zero plus recurrence-zero vanishing lemma:
```lean
theorem zero_of_zero_edges_and_zero_levi
  (h : (ℕ × ℕ) → R)
  (hfin : Finite {p | h p ≠ 0})
  (hedge1 : ∀ a, h (a,0) = 0)
  (hedge2 : ∀ b, h (0,b) = 0)
  (hleviL : tconv h leviLeftGen = 0)
  (hleviR : tconv h leviRightGen = 0) :
  ∀ a b, h (a,b) = 0
```
This should be the main injectivity engine.

A local compatibility lemma for reconstruction:
```lean
theorem compatibility_forces_left_right_reconstruction_agree
  (D : EdgeLeviData R)
  (hcomp : EdgeLeviCompatible D)
  (a b : ℕ) :
  leftReconstructStep D a b = rightReconstructStep D a b
```
Even if the final compatibility predicate is somewhat ad hoc, this lemma makes the extension theorem mathematically clean.

### Significance

This is not just another injectivity result. The theorem identifies a **finite and geometrically natural coordinate system** for finitely supported tropical Satake data in rank 2 for GL₃: two codimension-1 edge restrictions plus two rank-2 Levi convolution profiles. Proving that these data are both sufficient and unique means the interior of the dominant chamber is no longer primitive information; it is generated by boundary geometry and Levi harmonic analysis.

That matters for the broader program because:

- it upgrades reconstruction/uniqueness statements into a true **finite-generation theorem**;
- it isolates the minimal local propagation mechanism needed for higher-rank tropical Satake theory;
- it gives a reusable blueprint for GLₙ: boundary strata plus lower-rank Levi observables should control interior coefficients;
- it should make later algebraic constructions easier, since one can parameterize objects by edge/Levi coordinates rather than arbitrary chamber-supported functions.

So the proof should emphasize the structural mechanism: **adjacent-facet propagation + rank-2 Levi recurrences + depth induction**. Even a first theorem with a slightly stronger compatibility hypothesis is valuable if the reconstruction is explicit and the uniqueness theorem is complete.
