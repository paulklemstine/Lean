## Research Task: Tropical Satake top-2 margin theorem for GL3 Hecke score classifiers

Research Mode: PROVE

Work in a new file

The target is a sharp `n = 3`, `k = 2` robustness theorem for tropical score vectors, formulated so it can be instantiated for GL3 tropical Satake classifiers reconstructed from a finite test family. The core mathematical content should be separated into a purely order-theoretic/topological layer on triples of real scores, and then a representation layer saying that Satake perturbations induce bounded score drift.

The important point is that for three classes, “top-2 invariance” is exactly equivalent to saying that the excluded class remains strictly below both members of the selected pair. This gives a sharp theorem with a converse, unlike a generic top-`k` bound.

### Precise theorem package to implement

Use concrete score triples `x : Fin 3 → ℝ`. Define the top-2 label set as the set of indices whose score is at least the second-largest score. Since `Fin 3` is finite, it is reasonable to define this via `Finset.univ.filter`.

A convenient concrete definition is:

```lean
def top2Set (x : Fin 3 → ℝ) : Finset (Fin 3) :=
  let vals : Finset ℝ := Finset.univ.image x
  let t : ℝ := vals.sup id
  let u : ℝ := (vals.erase t).sup id
  Finset.univ.filter (fun i => u ≤ x i)
```

However, if `Finset.sup` over `ℝ` is annoying, it is better to avoid abstract order-statistics definitions and instead define top-2 sets by explicit pairwise inequalities, using the fact that there are only three indices. In practice, the cleanest route is probably to define:

```lean
def IsTop2Set (x : Fin 3 → ℝ) (A : Finset (Fin 3)) : Prop :=
  A.card = 2 ∧ ∀ i ∈ A, ∀ j ∉ A, x j < x i
```

This is the right notion for the uniqueness theorem, and it avoids heavy order-statistics infrastructure.


This theorem is the exact formal version of “the top-2 set is uniquely determined iff the second and third ordered scores are separated by a positive gap.” For `Fin 3`, uniqueness of the excluded class is the cleanest invariant.

### 2. Top-2 invariance under coordinatewise score perturbations

Define perturbation invariance at radius `ε` directly on score vectors:

```lean
def Top2StableUnderScorePerturbation
    (x : Fin 3 → ℝ) (ε : ℝ) : Prop :=
  ∃ A : Finset (Fin 3), IsTop2Set x A ∧
    ∀ y : Fin 3 → ℝ,
      (∀ i, |y i - x i| ≤ ε) →
      IsTop2Set y A
```

```lean

    (∃ c : Fin 3, ∀ i : Fin 3, i ≠ c → 2 * ε < x i - x c) →
```

This is the exact top-2 analogue of the usual argmax margin theorem, but note that the right margin is the minimum separation between the excluded class and each included class.

### 3. Lipschitz transfer from test-family valuation perturbations to score perturbations

Now introduce an abstract interface for finite-test-family score reconstruction. Keep it elementary and avoid committing to a complicated Satake implementation if the exact objects are not yet in the library.

A minimal concrete setup is:

```lean
structure FiniteTestScoreModel where
  T : Finset ℕ
  score : (Fin 3) → (ℕ → ℝ) → ℝ
  K : ℝ
  K_nonneg : 0 ≤ K
  lipschitz :
    ∀ v w : ℕ → ℝ, ∀ i : Fin 3,
      |score i v - score i w| ≤
        K * (Finset.sup T (fun t => |v t - w t|))
```

### 4. Max-plus linear realization theorem

Because the intended application is tropical Satake score maps represented by max-plus linear forms on a finite test family, it is worth isolating a theorem for that special case. A concrete simple model is:

```lean
def MaxPlusScore
    (T : Finset ℕ) (W : Fin 3 → Finset (ℕ × ℝ)) (v : ℕ → ℝ) :
    Fin 3 → ℝ :=
  fun i => (W i).sup (fun p => v p.1 + p.2)
```

If `Finset.sup` on `ℝ` again causes friction, assume each `W i` is nonempty and use `sSup` on the coerced finite set, or work with `max'` requiring nonemptiness. The theorem to prove is that if every test valuation changes by at most `η`, then every max-plus score changes by at most `η`:

### Proof strategy

For the core order-statistics/top-2 lemmas, the proof should be explicit and finite.

1. **Reduce top-2 uniqueness to a unique bottom class.**
   For `Fin 3`, a `Finset` of cardinality `2` has complement of cardinality `1`. Show that `IsTop2Set x A` is equivalent to: there exists a unique `c ∉ A` such that `∀ i ∈ A, x c < x i`. This removes all dependence on sorting machinery.

2. **Exploit finite case analysis on `Fin 3`.**
   Use `fin_cases` on indices or the explicit enumeration of `Fin 3`. If needed, prove a helper lemma that any two-element subset of `Fin 3` is the complement of a unique singleton. This will make uniqueness arguments elementary.

3. **For the stability theorem, compare perturbed score differences directly.**
   If `A` excludes `c`, and `a ∈ A`, then
   `y a - y c = (x a - x c) + ((y a - x a) - (y c - x c))`.
   Use
   `| (y a - x a) - (y c - x c) | ≤ |y a - x a| + |y c - x c| ≤ 2ε`
   to conclude `0 < y a - y c` whenever `2ε < x a - x c`.
   This is the key inequality; isolate it as a lemma.

4. **For the converse, construct the extremal perturbation explicitly.**
   If `x a - x c ≤ 2ε`, define
   ```lean
   y a := x a - ε
   y c := x c + ε
   y i := x i   -- for the remaining index
   ```
   Then `|y i - x i| ≤ ε` for all `i`, and
   `y a - y c = (x a - x c) - 2ε ≤ 0`,
   so `A` is no longer a valid top-2 set. This gives the sharpness direction with no compactness or existence arguments.

5. **For max-plus/test-family transfer, use monotonicity of sup/max under uniform coordinate perturbation.**
   If every active test coordinate changes by at most `η`, then every affine term `v t + c` changes by at most `η`, hence the max over finitely many such terms changes by at most `η`. This is the tropical analogue of a 1-Lipschitz property for support functions. Prove this coordinatewise and then invoke the score-perturbation top-2 theorem.

### Significance

This theorem is the correct sharp robustness certificate for the first genuinely nontrivial multiclass tropical Satake case. The argmax (`k = 1`) theory only controls the winner; the `k = 2` theorem captures stability of the entire “plausible label pair” and is strictly subtler because it is governed by separation from the third class, not by the top-vs-second gap. For GL3 this is the exact place where finite Satake reconstruction, tropical max-plus geometry, and certified robustness interact in a mathematically rigid way.

A successful formalization here does three things for the broader program:

1. It isolates the `Fin 3` order-statistics mechanism that should later generalize to tropical Hecke classifiers with structured top-`k` outputs.
2. It provides a clean theorem schema that can be instantiated by any finite-determinacy Satake reconstruction theorem giving score drift bounds from test-family valuation drift.
3. It yields a sharp converse, showing the certification threshold is not merely sufficient but exact in the GL3 top-2 setting.

The end product should therefore be a reusable theorem stack:
- pure top-2 combinatorics on score triples,
- robustness under coordinatewise perturbation,
- transfer from finite test-family perturbations,
- max-plus corollary matching tropical Satake reconstruction.
