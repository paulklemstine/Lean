## Research Task: Lifting-the-exponent for Fibonacci entry points and composite-index primitive divisors

### Research Mode: FORMALIZE

Formalize a valuation-theoretic backbone for the Fibonacci primitive-divisor program. The central goal is to isolate an LTE-style theorem for the Fibonacci sequence at odd primes, then use it to derive exact entry-point divisibility, valuation control on gcds, and finally the composite-index primitive divisor theorem outside a finite exceptional set.

Work in a new file such as `Shared/FibonacciLTE.lean`, and then import it into `Shared/CarmichaelProof.lean`.

### Precise theorem package to target

Use `fib : ℕ → ℕ` for Fibonacci numbers. Introduce, if needed, the Fibonacci entry point of a prime as the least positive index where divisibility occurs:

```lean
def fibEntry (p : ℕ) : ℕ := Nat.find <|
  by
    -- existence of some positive multiple with p ∣ fib n
    -- may initially be postulated if not yet available
```

At minimum, the file should expose the following statements, possibly first under explicit auxiliary hypotheses and later in stronger forms.

#### 1. Entry-point positivity and minimality
You will likely need a bundled specification:

```lean
def IsFibEntry (p z : ℕ) : Prop :=
  0 < z ∧ p ∣ fib z ∧ ∀ m, 0 < m → m < z → ¬ p ∣ fib m
```

Then prove:

```lean
theorem fibEntry_pos {p : ℕ} (hp : Nat.Prime p) : 0 < fibEntry p
theorem fibEntry_dvd_fib {p : ℕ} (hp : Nat.Prime p) : p ∣ fib (fibEntry p)
theorem fibEntry_minimal {p m : ℕ} (hp : Nat.Prime p) :
    0 < m → m < fibEntry p → ¬ p ∣ fib m
```

If existence of `fibEntry` is not already available, it is acceptable to define the later theorems relative to an arbitrary `z` with `IsFibEntry p z`.

#### 2. Divisibility criterion from the entry point
The crucial structural statement is:

```lean
theorem prime_dvd_fib_iff_entry_dvd
    {p n z : ℕ} (hp : Nat.Prime p) (hp2 : p ≠ 2)
    (hz : IsFibEntry p z) :
    p ∣ fib n ↔ z ∣ n
```

A variant specialized to `fibEntry p` should then read:

```lean
theorem prime_dvd_fib_iff_fibEntry_dvd
    {p n : ℕ} (hp : Nat.Prime p) (hp2 : p ≠ 2) :
    p ∣ fib n ↔ fibEntry p ∣ n
```

This is one of the key bridges from divisibility to index arithmetic.

#### 3. LTE-style valuation theorem along entry-point multiples
The main theorem should be stated as an exact `padicValNat` identity. A robust target is:

```lean
theorem padicValNat_fib_entry_mult
    {p z k : ℕ} (hp : Nat.Prime p) (hp2 : p ≠ 2)
    (hz : IsFibEntry p z) :
    padicValNat p (fib (k * z)) = padicValNat p (fib z) + padicValNat p k
```

You may also want the commuted multiplication variant:

```lean
theorem padicValNat_fib_entry_mult'
    {p z k : ℕ} (hp : Nat.Prime p) (hp2 : p ≠ 2)
    (hz : IsFibEntry p z) :
    padicValNat p (fib (z * k)) = padicValNat p (fib z) + padicValNat p k
```

And then the specialized form:

```lean
theorem padicValNat_fib_fibEntry_mult
    {p k : ℕ} (hp : Nat.Prime p) (hp2 : p ≠ 2) :
    padicValNat p (fib (k * fibEntry p))
      = padicValNat p (fib (fibEntry p)) + padicValNat p k
```

This theorem should be understood as the Fibonacci analogue of LTE for rank-of-apparition multiples.

#### 4. GCD identity and valuation form
The exact gcd identity is extremely valuable and should be proved if not already present:

```lean
theorem fib_gcd :
    ∀ m n : ℕ, Nat.gcd (fib m) (fib n) = fib (Nat.gcd m n)
```

Then derive the valuation-level version:

```lean
theorem padicValNat_fib_gcd
    {p m n : ℕ} (hp : Nat.Prime p) :
    padicValNat p (Nat.gcd (fib m) (fib n))
      = padicValNat p (fib (Nat.gcd m n))
```

A stronger intermediate theorem worth isolating is:

```lean
theorem prime_dvd_fib_gcd_iff
    {p m n : ℕ} (hp : Nat.Prime p) (hp2 : p ≠ 2) :
    p ∣ Nat.gcd (fib m) (fib n) ↔ p ∣ fib (Nat.gcd m n)
```

Once `fib_gcd` is established, the valuation statement is immediate by rewriting.

#### 5. Valuation on arbitrary indices divisible by the entry point
After the exact multiple theorem, package the general form:

```lean
theorem padicValNat_fib_of_entry_dvd
    {p n z : ℕ} (hp : Nat.Prime p) (hp2 : p ≠ 2)
    (hz : IsFibEntry p z) (hn : z ∣ n) :
    padicValNat p (fib n)
      = padicValNat p (fib z) + padicValNat p (n / z)
```

This is the formulation most useful downstream in arguments comparing valuations from different proper divisors.

#### 6. Composite-index primitive divisor theorem
The final target should be stated in a form that isolates the finite exceptional set. If the exceptional range is already computationally verified elsewhere, parameterize by that result instead of reproving it here.

A useful theorem schema is:

```lean
theorem composite_index_has_primitive_prime
    {n N0 : ℕ}
    (hcomp : Nat.Composite n)
    (hlarge : N0 ≤ n)
    (hexcept :
      ∀ m < N0, Nat.Composite m →
```

If the proof depends on a growth lemma not yet in the library, isolate it explicitly as a hypothesis or a separate theorem. A more concrete downstream-friendly version is:


### Concrete proof strategy

1. **Establish the divisibility sequence structure of Fibonacci numbers.**  
   Prove or import the standard fact
   ```lean
   d ∣ n → fib d ∣ fib n
   ```
   and then derive the stronger gcd identity
   ```lean
   Nat.gcd (fib m) (fib n) = fib (Nat.gcd m n).
   ```
   The cleanest route is Euclidean recursion on indices using the addition formula
   ```lean
   fib (m + n) = fib (m - 1) * fib n + fib m * fib (n + 1)
   ```
   or any Mathlib-available Fibonacci addition theorem. Once the gcd identity is available, the implication
   `p ∣ fib m ∧ p ∣ fib n → p ∣ fib (Nat.gcd m n)` follows immediately.

2. **Derive the entry-point divisibility criterion from gcd minimality.**  
   Assume `hz : IsFibEntry p z` and `p ∣ fib n`. Since also `p ∣ fib z`, use `fib_gcd` to get
   ```lean
   p ∣ fib (Nat.gcd z n).
   ```
   By minimality of `z`, this forces `Nat.gcd z n = z`, hence `z ∣ n`.  
   The converse `z ∣ n → p ∣ fib n` follows from the divisibility-sequence property `fib z ∣ fib n`.

3. **Prove the valuation theorem first on prime-power multiples.**  
   A practical route to
   ```lean
   padicValNat p (fib (k*z)) = padicValNat p (fib z) + padicValNat p k
   ```
   is to reduce to the case `k = p^a * u` with `p ∤ u`. By the divisibility criterion, `p ∤ fib (u*z /? )` unless forced by the `z` factor; thus the whole extra valuation should come from the `p^a` contribution.  
   The key inductive step is
   ```lean
   padicValNat p (fib (p * t * z)) = padicValNat p (fib (t * z)) + 1
   ```
   under the non-exceptional hypotheses. This is the exact Fibonacci-LTE increment.  
   If a full proof requires a known Lucas-sequence theorem not yet formalized, declare a sharply delimited axiom for this increment step and derive all downstream consequences rigorously from it.

4. **Package arbitrary-index valuation formulas using the entry-point criterion.**  
   Given `z ∣ n`, write `n = k*z`; then rewrite with `Nat.exists_eq_mul_left_of_dvd` and apply the multiple theorem. This gives the formula
   ```lean
   padicValNat p (fib n) = padicValNat p (fib z) + padicValNat p (n / z).
   ```
   Use this to prove valuation identities for gcds by reducing both sides to valuations of the corresponding quotient by the entry point.

5. **Use valuations to force a primitive divisor at composite indices.**  
   For composite `n`, suppose every prime factor `p` of `fib n` already divides some `fib d` with `d ∣ n`, `d < n`. Then by the entry-point criterion, the entry point `z(p)` is a proper divisor of `n`. The valuation formula shows every `p`-adic contribution to `fib n` is controlled by
   ```lean
   padicValNat p (fib (z(p))) + padicValNat p (n / z(p)).
   ```
   Summing these controls over all such primes should imply that the entire factorization of `fib n` is accounted for by prime powers coming from proper-divisor indices and from the integer `n` itself. Combine this with the standard product-over-proper-divisors contradiction or an already-verified growth lemma to conclude a residual primitive prime must remain.  
   The right formal shape is often: assume no primitive prime exists, show `fib n` divides a product built from `{fib d | d ∣ n, d < n}` times a controlled factor from `n`, then contradict a previously proved lower bound.

### Lean-specific implementation advice

- Prefer proving theorems first with an explicit parameter `z` and hypothesis `hz : IsFibEntry p z`; this avoids committing too early to a specific construction of `fibEntry`.
- For `padicValNat`, keep hypotheses `hp : Nat.Prime p` explicit everywhere; many simp lemmas need primality.
- When converting `z ∣ n` into `n = k*z`, use:
  ```lean
  rcases hn with ⟨k, rfl⟩
  ```
  and normalize multiplication with `Nat.mul_comm`, `Nat.mul_left_comm`, `Nat.mul_assoc`.
- The gcd valuation theorem should be proved by rewriting via `fib_gcd`, not by a direct valuation argument.
- If a full formal proof of the Fibonacci-LTE step is too deep for the first pass, isolate exactly one axiom/theorem stub in Lucas-sequence language, then derive all divisibility, gcd, and primitive-divisor consequences from it. The research value is in making the dependency graph explicit and minimizing the unformalized core.

### Why this matters

This theorem package is the structural missing link in the Fibonacci/Carmichael program. The entry-point criterion converts prime divisibility of `fib n` into divisibility in the index, the valuation theorem upgrades that to exact multiplicity control, and the gcd identity lets these local statements interact cleanly across different indices. Together they provide the mechanism needed to strip away all prime powers that can be explained by proper divisors of a composite index and force the existence of a genuinely new prime divisor. In other words, this is the backbone that turns isolated divisibility lemmas into a complete primitive-divisor theorem for composite Fibonacci indices.

```lean
/-- Strip all factors of m from r, with bounded fuel -/
def stripAllAux (r : ℕ) (m : ℕ) : ℕ → ℕ
  | 0 => r
  | fuel + 1 =>
    if m ≤ 1 then r
    else
      let g := Nat.gcd r m
      if g ≤ 1 then r
      else stripAllAux (r / g) m fuel

/-- List of proper divisors of n (d with 0 < d < n and d | n) -/
def propDivs (n : ℕ) : List ℕ :=
  (List.range n).filter fun d => 0 < d && d < n && n % d == 0

  induction fuel generalizing r with
  | zero => exact dvd_refl r
  | succ fuel ih =>
    simp only [stripAllAux]
    split_ifs with h1 h2

    · exact dvd_refl r
    · exact dvd_trans (ih (r / Nat.gcd r m)) (Nat.div_dvd_of_dvd (Nat.gcd_dvd_left r m))
```

```lean
import Mathlib
import Shared.CarmichaelHelper
import Shared.CarmichaelProof

/-! # Computational verification of Carmichael's theorem

We verify Carmichael's primitive divisor theorem for composite n
using a combination of computation and mathematical argument.

Key approach:
- For composite n, every prime factor p of F(n) has an entry point α(p) | n
- If α(p) = n, then p is primitive
- The entry point divides n because gcd(F(n), F(k)) = F(gcd(n,k))
- For composite n, we show that the "primitive part" F*(n) = F(n) / gcd(F(n), lcm{F(d) : d|n, d<n}) > 1

We prove key structural lemmas and then apply them.
-/

set_option maxHeartbeats 800000

/-- If p | F(n) and p | F(k), then p | F(gcd(n,k)). -/
lemma fib_dvd_gcd (p n k : ℕ) (hn : p ∣ Nat.fib n) (hk : p ∣ Nat.fib k) :
    p ∣ Nat.fib (Nat.gcd n k) :=
  (Nat.fib_gcd n k) ▸ (Nat.dvd_gcd hn hk)

/-- The entry point of a prime p (smallest positive k with p | F(k)) divides any n with p | F(n).
    This is because gcd(n, α(p)) must equal α(p) by minimality. -/
lemma entry_point_divides (p n : ℕ) (hp : Nat.Prime p) (hn : 0 < n) (hpn : p ∣ Nat.fib n)
    (α : ℕ) (hα_pos : 0 < α) (hα_dvd : p ∣ Nat.fib α)
    (hα_min : ∀ m, 0 < m → m < α → ¬(p ∣ Nat.fib m)) :
    α ∣ n := by
  have h_gcd_le : Nat.gcd n α ≤ α := Nat.gcd_le_right n hα_pos
  have h_gcd_pos : 0 < Nat.gcd n α := Nat.gcd_pos_of_pos_left α hn
  have h_gcd_dvd : p ∣ Nat.fib (Nat.gcd n α) := fib_dvd_gcd p n α hpn hα_dvd
  have h_gcd_eq : Nat.gcd n α = α := by
    by_contra h_ne
    have h_lt : Nat.gcd n α < α := lt_of_le_of_ne h_gcd_le h_ne
    exact hα_min (Nat.gcd n α) h_gcd_pos h_lt h_gcd_dvd
  exact h_gcd_eq ▸ Nat.gcd_dvd_left n α

/-- For composite n, if ALL prime factors of F(n) have entry point < n,
    then each divides F(d) for some proper divisor d of n. -/
lemma all_factors_from_divisors (n : ℕ) (hn : 3 ≤ n) (hn_comp : ¬Nat.Prime n)
```

```lean
composite natural number `n > 10000`, the Fibonacci number `F_n` has a

divide `F_k` for any `0 < k < n`.

* `entry_point_dvd_of_fib_dvd`: The entry point (rank of apparition) of a prime
  in the Fibonacci sequence divides `n` whenever `p ∣ F_n`.
* `fib_dvd_iff_entry_dvd`: A prime `p` divides `F_k` if and only if its entry
  point divides `k`.
* `fib_composite_has_primitive`: The main theorem (composite case of Carmichael's

## Implementation notes

The full proof of Carmichael's theorem requires the theory of cyclotomic Fibonacci
numbers Φ_n (primitive parts), specifically:
1. The multiplicative identity `F_n = ∏_{d|n} Φ_d`
2. The lower bound `Φ_n ≈ φ^{φ(n)}` (Euler's totient function)
3. The intrinsic factor theorem: primes dividing Φ_n and Φ_d (for d | n, d < n)

This infrastructure is not currently available in Mathlib. The entry point theory
and supporting lemmas are fully proved; only the core growth/cyclotomic step
remains as a sorry.

open scoped BigOperators
open Finset Nat

/-! ## Entry point theory for Fibonacci primes -/

/-- If `p ∣ F_m` and `p ∣ F_n`, then `p ∣ F_{gcd m n}`.
This follows from the strong divisibility property `gcd(F_m, F_n) = F_{gcd(m,n)}`. -/
lemma prime_dvd_fib_gcd (p m n : ℕ) (hp : Nat.Prime p)
    (hm : p ∣ Nat.fib m) (hn : p ∣ Nat.fib n) :
    p ∣ Nat.fib (Nat.gcd m n) := by

/-- Every prime divides some positive Fibonacci number.
This follows from the Pisano period: the Fibonacci sequence mod `p` is periodic,
so the pair `(0, 1)` must recur, giving `F_k ≡ 0 (mod p)` for some `k > 0`. -/
lemma prime_dvd_some_fib (p : ℕ) (hp : Nat.Prime p) :
    ∃ k, 0 < k ∧ p ∣ Nat.fib k := by
  have h_pigeonhole : ∃ i j : ℕ, i < j ∧ (fib i % p = fib j % p) ∧
      (fib (i + 1) % p = fib (j + 1) % p) := by
    have h_finite : Set.Finite ((fun k => (fib k % p, fib (k + 1) % p)) '' Set.Ici 0) := by
      exact Set.finite_iff_bddAbove.mpr ⟨⟨p - 1, p - 1⟩, by
        rintro a ⟨k, -, rfl⟩
        exact ⟨Nat.le_sub_one_of_lt (Nat.mod_lt _ hp.pos),
               Nat.le_sub_one_of_lt (Nat.mod_lt _ hp.pos)⟩⟩
    contrapose! h_finite
    exact Set.infinite_of_injective_forall_mem
      (fun i j hij => le_antisymm
        (not_lt.1 fun hi => h_finite _ _ hi (by aesop) (by aesop))
        (not_lt.1 fun hj => h_finite _ _ hj (by aesop) (by aesop)))
      fun i => ⟨i, by norm_num, rfl⟩
  obtain ⟨i, j, hij, hi, hj⟩ := h_pigeonhole
  induction' i with i ih generalizing j
  · induction' j with j ih' <;> simp_all +decide [Nat.fib_add_two, Nat.dvd_iff_mod_eq_zero]
    exact ⟨j + 1, by linarith, by simp +decide [← hi]⟩
  · specialize ih (j - 1) (Nat.lt_pred_iff.mpr hij)
    rcases j <;> simp_all +decide [Nat.fib_add_two, Nat.add_mod]

    (hpn : p ∣ Nat.fib n) :
    ∃ d, 0 < d ∧ d ∣ n ∧ p ∣ Nat.fib d ∧ ∀ k, 0 < k → k < d → ¬(p ∣ Nat.fib k) := by
  obtain ⟨d, hd1, hd2, hd3⟩ : ∃ d, 0 < d ∧ p ∣ fib d ∧ ∀ k, 0 < k → k < d → ¬p ∣ fib k := by
```
