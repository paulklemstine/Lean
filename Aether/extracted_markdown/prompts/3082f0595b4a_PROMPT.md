## Assignment: Direction 2: Non-Abelian Product Covering via Ruzsa Calculus

**Mode:** `prove`

Build a genuinely new non-abelian covering theorem that upgrades the catalog’s abelian/product-cover transfer into a robust theorem for arbitrary groups via Ruzsa calculus. This should not be a cosmetic generalization: the point is to create a reusable non-commutative covering machine that can feed model theory, geometric group theory, and computational group exploration.

The breakthrough target is this: **replace commutativity-dependent product-cover arguments by a structural theorem that only uses approximate subgroup control and left-translate combinatorics.** If successful, this opens a path from pseudofinite/model-theoretic covering principles to the modern non-abelian approximate group toolkit of Tao–Breuillard–Green.

## Why this matters

The catalog theorem `bounded_cover_implies_product_cover` is valuable because it converts a coarse cover of a set by structured pieces into a coarse cover of its product set. But if that mechanism is restricted to abelian or effectively commutative settings, it blocks exactly the phenomena that matter most in modern growth theory: nilpotent progressions, Helfgott-type product growth, and non-abelian stability. Removing commutativity is not an incremental tweak; it upgrades the theorem from an additive-combinatorial lemma to a **group-theoretic infrastructure result**.

A successful formalization here would create:

- a certified non-abelian covering lemma usable in arbitrary groups,
- a bridge from pseudofinite/model-theoretic transfer to approximate groups,
- a computational framework for testing sharpness in finite groups,
- a platform for future work on growth, expansion, and coarse geometry.

**Application keywords:** approximate groups, Ruzsa covering, non-abelian growth, product set estimates, pseudofinite transfer, geometric group theory, finite group computation, additive combinatorics, model theory, small doubling.

## Precise theorem statements

You should aim to prove at least the following three theorems. If exact cardinal packaging forces mild reformulation, preserve the mathematical content.

### Theorem 1: Product cover from non-abelian coset cover
If `A` is covered by `C` left cosets of a `K`-approximate subgroup `H`, then `A * A` is covered by at most `C^2 * K` left translates of `H * H`, and hence by at most `C^2 * K^3` left cosets of `H` once `H^3` is covered by `K^2` left cosets of `H`.

A possible Lean-facing statement:

```lean
theorem product_cover_of_left_coset_cover
    {G : Type*} [Group G]
    (H A : Finset G) (C K : ℕ)
    (hcov : CoveredByLeftCosets A H C)
    (happrox : IsFiniteKApproxSubgroup H K) :
    ∃ T : Finset G,
      T.card ≤ C^2 * K^3 ∧
      ∀ {x}, x ∈ A * A → ∃ t ∈ T, ∃ h ∈ H, x = t * h
```

This is the central theorem. If your formalization naturally yields a sharper bound such as `C^2 * K^2` or `C^2 * K`, prove that and derive the weaker `C^2 * K^3` as a corollary.

### Theorem 2: Triple-product control for approximate subgroups
Formalize the internal engine that turns `H * H ⊆ X * H` with `|X| ≤ K` into a cover of `H^3` by at most `K^2` left cosets of `H`.

```lean
theorem triple_product_cover_of_approx
    {G : Type*} [Group G]
    (H : Finset G) (K : ℕ)
    (happrox : IsFiniteKApproxSubgroup H K) :
    ∃ T : Finset G,
      T.card ≤ K^2 ∧
      ∀ {x}, x ∈ H * H * H → ∃ t ∈ T, ∃ h ∈ H, x = t * h
```

This theorem is mathematically important in its own right: it extracts the combinatorial heart of approximate subgroup structure. It should not be hidden as a helper lemma.

### Theorem 3: Cross-domain theorem — bounded word-metric diameter of covered product sets
Connect additive combinatorics to geometric group theory by proving that if `A` is covered by boundedly many left cosets of `H`, then every element of `A * A` lies in bounded word distance from a bounded set of representatives times `H`. In finite generated groups, phrase this via a finite generating set `S` and a word-ball cover.

A possible formulation:

```lean
theorem product_cover_induces_word_metric_control
    {G : Type*} [Group G]
    (S H A : Finset G) (C K R : ℕ)
    (hgen : Subgroup.closure (↑S : Set G) = ⊤)
    (hHball : ∀ h ∈ H, wordLength S h ≤ R)
    (hcov : CoveredByLeftCosets A H C)
    (happrox : IsFiniteKApproxSubgroup H K) :
    ∃ T : Finset G,
      T.card ≤ C^2 * K^3 ∧
      ∀ x ∈ A * A, ∃ t ∈ T, wordLength S (t⁻¹ * x) ≤ R
```

If `wordLength` is too heavy to instantiate in current Mathlib, replace this by a theorem about containment in a bounded ball generated by `S`, or formulate for the subgroup closure generated by `S`. The point is explicit: **translate covering by approximate algebraic structure into coarse geometric control.**

This theorem is your required cross-domain bridge:
- additive combinatorics ↔ geometric group theory,
- model theory ↔ coarse geometry.

## Proof architecture: 3 viable strategies

You must include multi-step proofs; avoid one-line simplifications. At least 3 substantial theorems should use combinations of `rcases`, induction on finite covers, `by_contra`, `field_simp` where relevant for cardinal inequalities, and explicit `calc` blocks.

### Strategy A: Direct coset-product expansion + approximate subgroup compression
This is the most promising formal route.

1. From `A ⊆ ⋃_{i ∈ I} t_i H` with `|I| ≤ C`, deduce
   ```math
   A·A ⊆ ⋃_{(i,j) ∈ I×I} t_i H H t_j?
   ```
   For left-coset control, be careful with order. A better decomposition is:
   if `a = t_i h_i` and `b = t_j h_j`, then
   `ab = t_i (h_i t_j) h_j`,
   which is awkward unless you rewrite the cover at the set-product level as
   `(T H)(T H) = T (H T H)`.
   This is where non-commutativity bites.

2. Avoid commuting terms by first proving a lemma for a set already contained in `T * H`:
   ```math
   (T H)(T H) ⊆ T T (H H H)
   ```
   using the fact that each middle representative can be absorbed into an enlarged translate set after a second cover step.

3. Use the approximate subgroup witness `H H ⊆ X H`, `|X| ≤ K` to derive
   `H^3 ⊆ X X H`, hence `H^3` is covered by `K^2` left cosets of `H`.

4. Therefore
   ```math
   A^2 ⊆ T T X X H
   ```
   and the cover count is at most `C^2 K^2`; if your bookkeeping only yields `C^2 K^3`, that is acceptable, but try to sharpen.

**Why promising:** this stays closest to finite-set algebra and is likely easiest to formalize in Lean using explicit witnesses and cardinal inequalities on product finsets.

### Strategy B: Ruzsa covering lemma as a reusable intermediate machine
This is conceptually deeper and scientifically more valuable if you can pull it off.

1. Prove a finite non-abelian Ruzsa covering lemma:
   if `|A * B| ≤ K |A|`, then there exists `X ⊆ B` with `|X| ≤ K` and
   `B ⊆ A⁻¹ A X`.

2. Apply this with `A = H` and suitable `B` extracted from the coset-cover decomposition of `A`.
   Use approximate subgroup hypotheses to compress `H⁻¹ H X` into boundedly many left cosets of `H`.

3. Derive the product-cover theorem as a corollary.

**Why promising:** if formalized, this becomes a new library-level combinatorial engine with applications far beyond the present theorem.  
**Why harder:** cardinality inequalities and maximal disjoint family arguments are more delicate in Lean.

### Strategy C: Induction on the cover number `C`
This may be useful for one of the required deep proofs.

1. Prove the base case `C = 0, 1`.
2. Assume `A = A' ∪ tH` with `A'` covered by `C` cosets.
3. Expand `(A' ∪ tH)^2`, bound each piece separately, and merge the translate sets.
4. Compress each product involving `H` using the approximate subgroup witness.

**Why promising:** induction creates structurally rich proofs and may satisfy the depth requirement naturally.  
**Why weaker:** it may produce looser constants and more cumbersome bookkeeping than Strategy A.

**Recommendation:** Use Strategy A for the main theorem, Strategy C for a secondary theorem or strengthened variant, and Strategy B for either a conjectural future direction or a partial formalization if full proof becomes too costly.
