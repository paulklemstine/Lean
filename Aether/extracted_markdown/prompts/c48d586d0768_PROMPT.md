## PROOF STRATEGY REQUIREMENTS

For each major theorem cluster, use varied tactics and explicit intermediate lemmas. Do not rely on `simp` alone.

### Strategy A: Closure-induced Lawvere axioms
Most promising for the core construction.

1. Prove helper rewrite lemmas:
   - `c.idempotent' x`
   - `EMLClosure.toLawvereDist c κ x y = κ (c.toFun x) (c.toFun y)`
   - iterate simplification lemmas.
2. For `dist_self`, unfold and rewrite by idempotence or the provided `hself`.
3. For triangle, unfold and apply the supplied `htri`.
4. For nonexpansiveness of `c.toFun`, rewrite both sides and use idempotence to reduce the left side to the right side.
5. Package the results into an instance only after theorem-level lemmas are stable.

Use `simpa`, `rw`, `calc`, `exact`, `have`.

### Strategy B: Finite stabilization via order chains
Best for computational utility and explicit bounds.

1. Show `x ≤ f x ≤ f^[2] x ≤ ...` by induction using monotonicity/extensivity.
2. On a finite partial order, if all iterates up to `card X` were distinct, extract a strictly increasing chain longer than possible.
3. Use `Fintype.card X`, `Finite`, `injective`, or chain-counting lemmas.
4. Apply `by_contra` to derive contradiction from “no stabilization before card”.
5. Use `omega` for natural number inequalities and `linarith` if numeric bounds are encoded linearly.

This cluster should not be vacuous: prove an explicit `≤ Fintype.card X` stabilization index for `PreClosure`, not just for idempotent closures.

### Strategy C: Product/completion constructions
Good for aesthetic breadth.

1. Define product distance by addition:
   ```lean
   dist (x₁,y₁) (x₂,y₂) := distX x₁ x₂ + distY y₁ y₂
   ```
2. Prove self-distance by `simp` with `dist_self`.
3. Prove triangle by associativity and repeated use of `add_le_add`.
4. Derive componentwise nonexpansiveness from pairwise nonexpansiveness.
5. Interpret this as a semantics of joint information channels / quantum-thermodynamic coupling.

If order-theoretic completion is too large, define a modest notion of “Cauchy-by-stabilization” for closure iterates:
```lean
def EventuallyStable (u : ℕ → X) : Prop := ∃ N, ∀ n ≥ N, u n = u N
```
and show closure iterates are eventually stable for closures, with explicit rate `N = 1`, and for finite preclosures with `N ≤ card X`.

### Strategy D: Residuated/nucleus reconstruction
Use theorem-level abstraction if a full residuated algebra class is too expensive.

1. Define `SemiringNucleus.toClosure`.
2. Prove monotonicity/extensivity/idempotence transfer immediately from the nucleus fields.
3. Introduce a residual cost `ρ` only through the exact axioms needed.
4. Construct the induced Lawvere distance from `ν`.
5. Show the closure map from the nucleus is nonexpansive and fixed points correspond to nucleus-stable elements.

Use `rcases` heavily when unpacking structures; use `constructor` to build instances.

### Strategy E: Contrapositive/fixed-point reflection
Use for reflection theorems.

1. To show zero gap implies fixed point, combine extensivity with antisymmetry.
2. If zero gap is characterized by order, rewrite `κ x (c x) = 0 ↔ x ≤ c x`, then specialize to fixed points.
3. For converse directions, use direct substitution.
4. For stronger “minimality” statements, use `by_contra` and derive nonzero gap contradiction.

/-! ## Semiring Congruence -/

/-- A semiring congruence: an equivalence relation compatible with `+` and `*`. -/
structure SemiringCong (A : Type*) [Semiring A] where
  r : A → A → Prop
  refl' : ∀ a, r a a
  symm' : ∀ {a b}, r a b → r b a
  trans' : ∀ {a b c}, r a b → r b c → r a c
  add' : ∀ {a b c d}, r a b → r c d → r (a + c) (b + d)
  mul' : ∀ {a b c d}, r a b → r c d → r (a * c) (b * d)

namespace SemiringCong

variable {A : Type*} [Semiring A]

instance : LE (SemiringCong A) where
  le C D := ∀ ⦃a b⦄, C.r a b → D.r a b

/-- Scaling on the left: `C.r (f * a) (f * b)` from `C.r a b`. -/
theorem mul_left (C : SemiringCong A) (f : A) {a b : A} (h : C.r a b) :
    C.r (f * a) (f * b) :=
  C.mul' (C.refl' f) h

/-- Scaling on the right: `C.r (a * f) (b * f)` from `C.r a b`. -/
theorem mul_right (C : SemiringCong A) (f : A) {a b : A} (h : C.r a b) :
    C.r (a * f) (b * f) :=
  C.mul' h (C.refl' f)

/-- Adding a common term on the left. -/
theorem add_left (C : SemiringCong A) (f : A) {a b : A} (h : C.r a b) :
    C.r (f + a) (f + b) :=
  C.add' (C.refl' f) h

/-- Adding a common term on the right. -/
theorem add_right (C : SemiringCong A) (f : A) {a b : A} (h : C.r a b) :
    C.r (a + f) (b + f) :=
  C.add' h (C.refl' f)

end SemiringCong
