### PROOF STRATEGIES (Three Independent Paths)

**Strategy A — Direct Matrix Computation (Most Promising)**
The Berggren tree is generated by three matrices $A_1, A_2, A_3$ acting on column vectors $(a, b, c)^T$. The Stern-Brocot tree is generated by two matrices $L = \begin{pmatrix} 1 & 0 \\ 1 & 1 \end{pmatrix}$ and $R = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}$. Prove:
1. `berggren_matrix_fractional_decomposition`: Each $A_i$ decomposes as a product of $L, R$ under $\Phi$
2. `berggren_stern_map_preserves_primitivity`: $\Phi(t) \in \mathbb{Q}$ has denominator $a$ when $\gcd(a, b, c) = 1$
3. `berggren_stern_surjective`: Every reduced fraction $p/q$ with $q > p > 0$ has a preimage—construct it via the Euclidean algorithm on $(p, q)$
4. `berggren_stern_injective`: If $\Phi(t_1) = \Phi(t_2)$ then $t_1 = t_2$—use the uniqueness of Euclidean algorithm remainders

**Strategy B — Structural Induction on Tree Depth**
Prove by induction on the Berggren tree depth that $\Phi$ maps depth-$n$ nodes bijectively onto Stern-Brocot nodes at Stern-depth $n+1$:
1. Base case: depth 0, node $(3, 4, 5)$ maps to $9/3 = 3/1$ ✓ (but we need $(4+5)/3 = 3/1$)
2. Inductive step: Each Berggren child maps to the appropriate Stern-Brocot child via the matrix decomposition from Strategy A
3. Key lemma: `berggren_child_stern_child_correspondence` — the three Berggren children map to three specific Stern-Brocot descendants

**Strategy C — Galois-Theoretic via $\mathbb{Q}(i)$ (Deepest)**
Identify primitive triples with elements of $\mathbb{Z}[i]^*$ modulo units, then use the continued fraction expansion:
1. `pythagorean_gaussian_correspondence`: $(a, b, c) \leftrightarrow a + bi$ with $|a + bi|^2 = c^2$
2. `gaussian_stern_brocot_via_continued_fraction`: The ratio $(c+b)/a$ encodes the continued fraction of the Gaussian integer's argument
3. `continued_fraction_berggren_depth`: The depth equals the length of the continued fraction

**Strategy A is most promising** because it reduces to finite matrix computations at each step and directly produces the constructive witness needed for `∃!`.
