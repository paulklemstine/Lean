Target: deterministic finite automata with output (DFAOs) reading base-k expansions of natural numbers, for arbitrary finite output types.

Requirements:
1. Define a DFAO structure with:
   - a finite state type Q (use [Fintype Q] and [DecidableEq Q]),
   - an initial state q0,
   - a transition function δ : Q → Fin k → Q for fixed base k,
   - an output function out : Q → α with α finite.
2. Define evaluation of a DFAO on a list of digits and then on n : ℕ via a canonical base-k digit expansion. Use a precise convention for digits (for example, most-significant-digit first, with 0 represented by [0], and no leading zeros otherwise). Keep the convention simple and prove the lemmas you actually need.
3. Define when a sequence a : ℕ → α is k-automatic: there exists a DFAO whose value on n equals a n for all n.

Main theorems to fully formalize:
A. Finite-range theorem:
   For every k-automatic sequence a : ℕ → α, the set/range of values of a is finite.
   Preferred proof: show every output is of the form out q for some state q, so the range is contained in Set.range out (or Finset.image out univ).

B. Non-automaticity of identity:
   For every base k ≥ 2, the sequence id : ℕ → ℕ is not k-automatic.
   Preferred proof: combine theorem A with the fact that id has infinite range.
   Make the statement explicit and avoid any computability/halting-problem language.

C. Decidable occurrence / bounded reachability:
   For a fixed DFAO M and z : α, prove that the proposition ∃ n : ℕ, evalNat M n = z is decidable.
   Preferred proof strategy: characterize occurrence by reachability of some state q with out q = z from q0 in the finite directed graph generated by transitions. Then use finite decidable search over states / reflexive-transitive closure / finite path length bounded by card Q or another clean finite argument. It is acceptable to prove an equivalent finite-search theorem instead of using arbitrary graph libraries if that is easier in Lean.

D. Unary eventual periodicity:
   Specialize to the unary case where there is only one input symbol, equivalently a finite state machine with one transition step next : Q → Q and output out : Q → α. Define the generated sequence from iterating next starting at q0. Prove this output sequence is eventually periodic.
   Preferred proof: finite-state orbit => there exist i < j with iterate next i q0 = iterate next j q0; deduce period p = j - i > 0 and eventual periodicity from time i onward.
