## Precise theorem package

Let `S` be a finitely generated commutative idempotent semiring. Let `α := WithTop ℝ` with tropical operations `(inf, +)` or equivalently the standard `MinPlus` incarnation already available / emulable in Lean. Equip semimodules over `S` with a closure operator `cl` satisfying:

1. extensivity,
2. monotonicity,
3. idempotence,
4. compatibility with finite generation,
5. continuity assumptions sufficient to define closure-continuous characters.

Define a **tropical character** to be a semiring morphism
`χ : S →+* α`
satisfying closure continuity.

Let `X(S)` denote the type of closure-continuous tropical characters, endowed with pointwise tropical semimodule structure.

Define the evaluation map
`ev : S → TropFunc (X(S))`
by `ev s χ = χ s`.

Define the tropical Mellin transform of finitely supported functions `f : S →₀ α` by
`M(f)(χ) = inf_s (f s + χ s)`.

Define min-plus convolution on finitely supported functions using semiring multiplication in `S`:
`(f ⋆ g)(t) = inf_{xy=t} (f x + g y)`.

The breakthrough theorem package should be stated as four linked theorems.

## Theorem 1: Separation modulo radical

You should define a canonical congruence radical `radicalCongr : Setoid S` (or a bundled semiring congruence) as the intersection of kernels of closure-continuous tropical characters, and then prove:

> **Separation Theorem.** For all `s t : S`, if `s` and `t` are inequivalent modulo `radicalCongr`, then there exists a closure-continuous tropical character `χ` such that `χ s ≠ χ t`.

This is the semiring analogue of character separation modulo the invisible nilpotent/radical part.

### Lean 4 target
```lean
theorem characters_separate_mod_radical
  (s t : S) :
  ¬ Setoid.r s t radicalCongr ->
  ∃ χ : TropicalCharacter S, χ.toFun s ≠ χ.toFun t
```

A stronger bundled version is even better:
```lean
theorem radicalCongr_eq_iInf_ker :
  radicalCongr =
    sInf {K | ∃ χ : TropicalCharacter S, K = χ.kerSetoid}
```

## Theorem 2: Bidual reconstruction via closure-affine functions

Define the codomain of the evaluation embedding carefully. Do **not** aim at all functions `X(S) → α`; that is too large and false in the strongest form. Instead define the semiring of **finitely generated closure-affine tropical functions** on `X(S)`, generated by evaluation functionals and closed under the EML closure mechanism.

Then prove:

> **Bidual Reconstruction Theorem.** The evaluation map `ev : S → A_cl(X(S))` is a semiring morphism with kernel exactly `radicalCongr`. Hence it is injective when `radicalCongr` is trivial. Moreover, its image is exactly the finitely generated closure-affine tropical functions on `X(S)`.

This is the true Pontryagin-style reconstruction statement: `S` is recoverable from its dual character semimodule up to radical, and exactly recoverable under semisimplicity.

### Lean 4 target
```lean

theorem eval_ker_eq_radical :
  (evalCharacter (S := S) (α := α)).ker = radicalIdealLikeCongr
```

## Theorem 3: Tropical Mellin transform sends convolution to pointwise addition

This is the analytic heart.

For finitely supported `f g : S →₀ α`, define
```lean
def mellinTransform (f : S →₀ α) (χ : TropicalCharacter S) : α := ...
def conv (f g : S →₀ α) : S →₀ α := ...
```

Then prove:

> **Tropical Mellin Convolution Theorem.** For every closure-continuous tropical character `χ`,
> \[
> M(f ⋆ g)(χ) = M(f)(χ) + M(g)(χ),
> \]
> where `+` is tropical pointwise addition in the codomain.

This is the min-plus analogue of the classical statement that multiplicative characters diagonalize convolution. It is the decisive bridge from abstract duality to computation.

### Lean 4 target
```lean
theorem mellin_transform_convolution
  (f g : S →₀ α) (χ : TropicalCharacter S) :
  mellinTransform (conv f g) χ
    = mellinTransform f χ + mellinTransform g χ
```

A stronger extensional form:
```lean
theorem mellin_transform_convolution_funext
  (f g : S →₀ α) :
  mellinTransformFn (conv f g)
    = mellinTransformFn f + mellinTransformFn g
```

You may need assumptions ensuring the infimum over decompositions is attained or can be reduced to finite support. Since `f` and `g` are finitely supported, this is the right formal setting.

## Theorem 4: Certified sparse inversion / decoding theorem

Now specialize to a cryptographically meaningful subclass.

Let `G = {g₁, ..., gₙ}` be a closure-independent generating family of `S`. Define the **character matrix**
\[
A_{ij} := \chi_i(g_j)

for a finite family of characters `χ₁, ..., χ_m`. Assume a tropical nondegeneracy condition strong enough to guarantee uniqueness of min-plus linear recovery for sparse coefficient vectors. > **Certified Sparse Decoding Theorem.** For every `k`-sparse input encoded by semiring convolutional action over the generating family, if the selected character family has nondegenerate tropical measurement matrix, then the input is uniquely recoverable from transform data by a canonical min-plus linear solve. ## Proof strategy architecture

### Strategy A: Radical-first algebraic duality
This is the most promising route.

1. **Define the radical as the intersection of character kernels.**  
   This makes separation tautologically close to true and aligns the formal statement with the actual dual object.
2. **Prove evaluation factors through the quotient by the radical.**  
   Then show the induced map into closure-affine functions is injective by extensionality of characters.
3. **Characterize the image as the closure-affine hull of evaluation functionals.**  
   This avoids impossible surjectivity onto all functions and yields the correct bidual statement.

Why this is strongest: it isolates the semisimple content exactly where Pontryagin-style duality should live. It also avoids overclaiming and gives a reusable quotient API for later representation theory.

---

### Strategy B: Finite generation + polyhedral/tropical linearization
Use finite generation aggressively.

1. Choose a finite generating set `g₁, ..., gₙ` for `S`.
2. Identify each tropical character with a vector in `αⁿ` satisfying a finite family of linear tropical constraints induced by semiring relations and closure continuity.
3. Reduce separation and reconstruction to statements about tropical polyhedra / min-plus affine functions on the character space.

Why this is attractive: it turns abstract semiring duality into finite-dimensional tropical geometry. This is likely the best route for the inversion theorem and for extracting algorithms.

Potential challenge: encoding the finite relation presentation of `S` cleanly in Lean may require more infrastructure than the radical-first approach.

---

### Strategy C: Convolution theorem first, then duality from spectral faithfulness
An analytic-first route.

1. Define convolution and Mellin transform for finitely supported functions.
2. Prove the convolution theorem directly from the multiplicativity of characters.
3. Use the family of transformed delta functions `δ_s` to recover evaluation and derive separation/reconstruction.

Why this is conceptually beautiful: it makes duality emerge from diagonalization, mirroring classical harmonic analysis.

Why it is probably second-best formally: the transform theory depends on careful finite-inf manipulations, and reconstructing the semiring from transformed deltas is elegant but slightly more indirect than Strategy A.

**Recommendation:** Start with **Strategy A** for the reconstruction theorem, then prove **Strategy C** for the transform package, and finally use **Strategy B** to formulate the sparse decoding theorem in finite-dimensional tropical linear algebra.
