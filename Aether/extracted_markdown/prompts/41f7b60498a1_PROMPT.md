### Core Formalization Target

Define a finite toroidal grid first; do not begin on `ℤ × ℤ` unless necessary. The finite case is enough to formalize fixed points, orbit cardinality lower bounds, and gadget simulation.

A promising concrete setup is:

- `Config m n := Matrix (Fin m) (Fin n) ℕ`
- neighborhood sum via a `Finset` of offsets interpreted modulo `m,n`
- tropical local score computed by min-plus expressions
- update rule thresholded into a binary state, or keep a weighted state and define “alive” by a level set

The key design choice is this: **binary visible state, tropical latent score**. This gives you a faithful analogue of Life while preserving min-plus algebra.

For example, define a local tropical score

Then define a visible Boolean occupancy predicate `alive : ℕ → Prop` or `aliveVal : ℕ → Bool` by checking whether the score is below a threshold. This lets you prove circuit-style gadget lemmas using inequalities rather than ad hoc case splits.

### Precise Theorem Targets

#### 1. Tropical still lifes are fixed points

This should strengthen the existing `tropical_block_still_life` from one example to a structural equivalence for a class of patterns.

```lean
def Config (m n : ℕ) := Matrix (Fin m) (Fin n) ℕ

def tropicalLifeStep {m n : ℕ} : Config m n → Config m n := sorry

def IsStillLife {m n : ℕ} (c : Config m n) : Prop :=
  tropicalLifeStep c = c

def Support {m n : ℕ} (c : Config m n) : Finset (Fin m × Fin n) := sorry

def RectBlock {m n : ℕ} (i j h w : ℕ) : Config m n := sorry
```

Target theorem:

```lean
theorem tropical_rect_block_still_life
    {m n i j h w : ℕ}
    (hh : 2 ≤ h) (hw : 2 ≤ w)
    (hm : h < m) (hn : w < n) :
    IsStillLife (RectBlock i j h w : Config m n)
```

If you can characterize a wider class, even better:

```lean
theorem tropical_still_life_iff_local_stability
    {m n : ℕ} (c : Config m n) :
    IsStillLife c ↔
      ∀ x : Fin m × Fin n, localStable tropicalLifeStep c x
```

where `localStable` is your own local inequality predicate. This would be the right theorem: a local certificate for global fixed-point behavior.

**Why this matters:** this turns still lifes from isolated examples into an algebraic fixed-point theory. Combined with `closure_mdl_bound_via_fixed_point` and `still_life_has_bounded_orbit_description`, it gives a direct route to complexity bounds on tropical automaton attractors.

#### 2. Existence of tropical gliders

You need one explicit finite-support pattern whose orbit translates after finitely many steps. On a torus, translation is modulo `m,n`.

```lean
def shiftConfig {m n : ℕ} (dx dy : ℕ) (c : Config m n) : Config m n := sorry

def IsGlider {m n : ℕ} (c : Config m n) : Prop :=
  ∃ T dx dy, 0 < T ∧ (dx ≠ 0 ∨ dy ≠ 0) ∧
    (tropicalLifeStep^[T]) c = shiftConfig dx dy c
```

Target theorem:

```lean
theorem exists_tropical_glider :
  ∃ (m n : ℕ) (_hm : 5 ≤ m) (_hn : 5 ≤ n) (c : Config m n),
    IsGlider c ∧ ¬ IsStillLife c
```

A stronger theorem, if the rule permits it:

```lean
theorem exists_family_of_tropical_gliders :
  ∃ f : ℕ → Σ' m n, Config m n,
    ∀ k, let ⟨m, n, c⟩ := f k
    in IsGlider c ∧ card (Support c) ≥ k
```

Even a weaker parameterized family on growing tori would be a serious result: it shows unbounded mobile complexity.

**Why this matters:** the existence of a glider is the first irreversible sign that the system is not just a dissipative fixed-point machine. It creates the possibility of communication channels, collisions, logic, and universality.

#### 3. Pattern diversity lower bound

You need a theorem that the number of distinct reachable patterns from bounded-support seeds grows nontrivially. Do not settle for a vacuous finite bound. Aim for exponential or at least polynomial lower bounds by constructing independent gadget placement.

Define:

```lean
def boundedSupportConfigs (m n k : ℕ) : Finset (Config m n) := sorry

def orbitSet {m n : ℕ} (T : ℕ) (c : Config m n) : Finset (Config m n) := sorry
```

Target theorem:

```lean
theorem pattern_diversity_lower_bound
    {m n : ℕ} :
    ∃ C > 1, ∀ k : ℕ,
      ∃ S : Finset (Config m n),
        (∀ c ∈ S, card (Support c) ≤ k) ∧
        (∀ c₁ ∈ S, ∀ c₂ ∈ S, c₁ ≠ c₂ →
          orbitSet k c₁ ∩ orbitSet k c₂ = ∅) ∧
        C^k ≤ S.card
```

If this exact form is too heavy, prove a more Lean-manageable combinatorial version:

```lean
theorem exists_exponentially_many_distinct_fixed_orbits
    {m n : ℕ} :
    ∃ C > 1, ∀ k : ℕ,
      ∃ S : Finset (Config m n),
        S.card ≥ C^k ∧
        ∀ c ∈ S, IsStillLife c
```

This can likely be obtained by placing well-separated block gadgets independently. Then use `still_life_has_bounded_orbit_description` and `closure_mdl_bound_via_fixed_point` to interpret the result as a lower bound on **diversity of simple attractors** and a tension between low individual description length and high family cardinality.

**Why this matters:** this is the first theorem tying tropical CA to combinatorial entropy and Kolmogorov-style orbit complexity. It opens a new interface with symbolic dynamics and MDL.

**Why this matters:** this would place tropical algebraic dynamics inside the universality landscape of cellular automata, but with a fundamentally different algebraic substrate than classical Boolean Life. That is field-opening.

### Proof Strategy Architecture

You must pursue at least three proof paths in parallel.

#### Strategy A: Local inequality calculus via min-plus normal forms
Most promising for still lifes and gadget verification.

1. Define the local update rule so that every next-state value is a min of affine expressions in current neighboring values.
2. Use `tropical_plus_distributes_over_min` to normalize local expressions and reduce fixed-point or gadget claims to a finite family of inequalities.
3. Prove separation lemmas: if gadgets are placed farther apart than the neighborhood radius, their interactions decouple. This should yield product constructions for exponentially many still lifes and compositional gadget proofs.

Why promising: Lean handles finite inequality verification and algebraic rewriting far better than global dynamical arguments. This path also interfaces naturally with `tropical_and_bound`.

#### Strategy B: Finite-state symbolic dynamics on a torus
Best for gliders and orbit-diversity statements.

1. Work on `Config m n` with finite `m,n`, so every orbit is eventually periodic.
2. Search for a small explicit seed `c` and period/translation parameters `T,dx,dy`; then formally certify by computation plus extensional equality.
3. Use disjoint unions of separated seeds to generate many distinct periodic or fixed orbits, proving combinatorial lower bounds on orbit diversity.

Why promising: the glider theorem can be made computationally certified. Lean can verify a finite computation exactly once the right seed is found.

#### Strategy C: Circuit semantics and complexity transfer
Best for universality and cross-domain impact.

1. Formalize a small library of gadgets as local spacetime patterns.
2. Prove soundness of each gadget by direct finite evolution.
3. Prove compositionality using spatial separation and timing alignment, then transfer lower bounds from circuit complexity to tropical Life pattern complexity.

Why promising: once one has wire/AND/delay, a whole complexity theory follows. This also gives the strongest cross-domain story.

My recommendation: **A first, then B, then C**. Strategy A gives the reusable local lemmas. Strategy B gives a concrete nontrivial phenomenon early. Strategy C converts the whole project from “interesting CA variant” into “new computational medium in tropical algebra.”
