## Core Vision

The spectral gap only controls variance decay. The modified log-Sobolev constant controls **entropy dissipation**, hypercontractive smoothing, and the correct mixing scale up to the logarithm of the logarithm of state-space size. If you prove even a robust lower bound of order `1 / n^2` for the hybrid walk, you do not merely strengthen an estimate: you install an **information-theoretic engine** for this walk. That would place hybrid permutation dynamics into the same conceptual universe as Glauber dynamics, random transpositions, and dissipative semigroups in statistical mechanics.

This is a field-opening result because the generating set is neither purely local (adjacent transpositions) nor fully global (random transpositions): it is a **structured hybrid**. Establishing entropy dissipation here would create a blueprint for log-Sobolev analysis on other mixed local/global Markov chains, including card-shuffling models, sorting networks, and permutation channels in quantum information.

## Precise Mathematical Target

Let `μ_n` be the uniform probability measure on `Equiv.Perm (Fin n)`. Let `P_n` be the Markov operator for the lazy hybrid walk generated by:
1. adjacent transpositions `(i, i+1)`,
2. the long cycle `c = (0 1 2 ... n-1)` and its inverse.

Let the associated Dirichlet form be
\[
\mathcal E_n(f,g) := \langle f, (I - P_n) g \rangle_{L^2(\mu_n)}.
\]
For positive functions `f : S_n → ℝ_{>0}`, define the modified entropy production ratio
\[
\operatorname{MLS}_n(f) := \frac{\mathcal E_n(f,\log f)}{\operatorname{Ent}_{\mu_n}(f)},
\qquad
\operatorname{Ent}_{\mu_n}(f) := \mathbb E_{\mu_n}[f \log f] - \mathbb E_{\mu_n}[f]\log \mathbb E_{\mu_n}[f].
\]
Define the modified log-Sobolev constant
\[
\rho_n := \inf_{f>0,\; f \not\equiv \text{const}} \operatorname{MLS}_n(f).
\]

### Primary theorem to attack
> **Theorem (Hybrid modified log-Sobolev lower bound).**  
> There exists a universal constant `c : ℝ`, `0 < c`, such that for all `n ≥ 2`,
> \[
> \rho_n \ge \frac{c}{n^2}.
> \]

This would imply entropy decay
\[
\operatorname{Ent}_{\mu_n}(P_n^t f) \le e^{-2\rho_n t}\operatorname{Ent}_{\mu_n}(f),
\]
and hence
\[
t_{\mathrm{mix}}(\varepsilon) \le C n^2 \big(\log n + \log \log(1/\varepsilon)\big)
\]
for a universal `C`, recovering the conjectural `O(n^2 log n)` scale up to constants.

### Theorem 1: Reversibility and entropy production identity
Prove that the hybrid walk is reversible with respect to the uniform measure and derive a symmetrized Dirichlet representation:
\[
\mathcal E(f,\log f)
=
\frac12 \sum_{x,y} \mu(x)P(x,y)(f(x)-f(y))(\log f(x)-\log f(y)).
\]

Lean-style target:
```lean
theorem dirichlet_log_symm
    (n : ℕ) (f : Equiv.Perm (Fin n) → ℝ)
    (hf_pos : ∀ σ, 0 < f σ) :
    dirichlet (hybridAdjCycleChain n) f (fun σ => Real.log (f σ))
      =
      (1/2 : ℝ) * ∑ σ, ∑ τ,
        (hybridAdjCycleChain n).μ σ * (hybridAdjCycleChain n).P σ τ *
        (f σ - f τ) * (Real.log (f σ) - Real.log (f τ))
```

This is the structural theorem that turns entropy dissipation into a nonnegative quadratic-type object.

## Proof Strategy Architecture

You must pursue at least 2–3 proof avenues, not a single hint.

### Strategy A: Canonical-path comparison with random transpositions
**Most promising.**

1. Use the known walk definitions in `HybridWalk.lean` to express the hybrid generators concretely and prove reversibility/uniform stationarity.
2. Build a canonical decomposition of each random transposition into hybrid generators:
   - conjugate by powers of the long cycle to move support,
   - realize base transpositions using adjacent swaps,
   - bound path length and edge congestion.
3. Import or reconstruct the comparison inequality for entropy dissipation, not just spectral gap. The key technical leap is to replace variance transport by **entropy transport**, controlling the logarithmic mean terms.

Why this is most promising: the catalog already contains spectral-gap infrastructure for this walk. The shortest path to a breakthrough is to **upgrade the comparison mechanism**, not reinvent the walk from scratch.

### Strategy B: Bakry–Émery / discrete curvature for the hybrid generator
1. Define the generator `L = P - I` and the carré du champ `Γ`, possibly also `Γ₂`.
2. Compute or estimate `Γ₂ ≥ κ Γ` after averaging local adjacent moves with the global cycle move.
3. Deduce a modified log-Sobolev inequality from a positive curvature surrogate.

Why this is revolutionary: if successful, it would uncover a new curvature mechanism in a noncommutative finite group setting where purely local generators usually fail to exhibit uniform curvature. The cycle may act as a **curvature injector**.

Risk: formalization overhead is much higher, and discrete `Γ₂` technology may not already exist in the catalog.

### Strategy C: Tensorization-by-blocks / factor map to particle systems
1. View permutations via inversion vectors, cyclic positions, or exclusion-process coordinates.
2. Show the cycle move creates a block refresh or coarse-graining that improves entropy dissipation.
3. Prove an approximate tensorization inequality for entropy, then combine with adjacent-transposition local smoothing.

Why this matters: it connects card-shuffling to interacting particle systems and could produce a reusable method for hybrid local/global chains on combinatorial state spaces.

Risk: the state-space encoding is subtle, but even a partial theorem here would be publishable and visionary.

## Cross-Domain Connections You Should Make Explicit

1. **Information theory:**  
   The modified log-Sobolev inequality is an entropy contraction theorem. The hybrid walk becomes a finite noisy channel on permutations. This reframes mixing as **information destruction**.

2. **Statistical mechanics:**  
   Adjacent transpositions are local updates; the cycle is a coherent global mode. The walk is a toy model of systems with both local equilibration and long-range stirring. Proving MLSI here suggests new tools for nonequilibrium relaxation.

3. **Quantum information:**  
   The classical permutation channel has a quantum analogue: averaging over permutation unitaries generated by local swaps and cyclic shifts. A classical MLSI proof could guide a future **quantum log-Sobolev inequality** for permutation channels.

4. **Representation theory:**  
   Spectral analysis of permutation walks lives in irreducible representations of `S_n`, but MLSI is nonlinear. Bridging these could open a new representation-theoretic perspective on entropy dissipation beyond eigenvalues.

5. **Algorithms / MCMC:**  
   A certified `O(n^2 log n)` mixing bound would justify hybrid shuffling algorithms and structured MCMC schemes where one augments local moves by sparse global symmetries.
