## Precise Theorem Target

### Core mathematical statement
Let `x y : Fin n → ℝ`. Suppose there exists `c : ℝ` such that
`y i = x i + c` for all `i`. Then for every pair `i j`, the pairwise order relation is preserved:
`x i ≤ x j ↔ y i ≤ y j`.

This is elementary in statement but foundational in consequence: it says **tropical equivalence by additive translation preserves all ranking information**. From this, derive invariance of argmin sets, gap structure, and any statistic depending only on pairwise differences.

This should then be extended to a network score function or phylogenetic score vector.

### Lean 4 type signature
A minimal formal target:

```lean
theorem tropical_shift_preserves_pairwise_order
    {n : ℕ} (x y : Fin n → ℝ) (c : ℝ)
    (hshift : ∀ i, y i = x i + c) :
    ∀ i j, x i ≤ x j ↔ y i ≤ y j
```

A stronger and more publishable target:

```lean
theorem tropical_shift_preserves_argmin
    {n : ℕ} (hn : 0 < n) (x y : Fin n → ℝ) (c : ℝ)
    (hshift : ∀ i, y i = x i + c) :
    {i | ∀ j, x i ≤ x j} = {i | ∀ j, y i ≤ y j}
```

If set extensionality over predicates is awkward, use explicit membership equivalence:

```lean
theorem tropical_shift_preserves_argmin_mem
    {n : ℕ} (x y : Fin n → ℝ) (c : ℝ)
    (hshift : ∀ i, y i = x i + c) (i : Fin n) :
    (∀ j, x i ≤ x j) ↔ (∀ j, y i ≤ y j)
```

### Breakthrough extension: graph/network observable
Define a finite network score on nodes, e.g. from an adjacency matrix `A : Matrix (Fin n) (Fin n) ℝ`, by tropical row potential
`scoreA i = ∑ j, A i j` or preferably a min-plus score such as `inf`/`Finset.inf'`-style surrogate if convenient.

Then prove:

```lean
theorem tropical_equiv_scores_preserve_ranking
    {n : ℕ} (hn : 0 < n)
    (s t : Fin n → ℝ) (c : ℝ)
    (hshift : ∀ i, t i = s i + c) :
    ∀ i j, s i ≤ s j ↔ t i ≤ t j
```

This theorem becomes the certified core behind a case study where `s` and `t` are empirical node centrality surrogates known to differ only by tropical normalization.

## Proof Strategy Architecture

### Strategy A: Direct order-transport proof via additive cancellation
Most promising for Lean and for immediate publication-quality formalization.

1. Rewrite `y i ≤ y j` using `hshift i` and `hshift j` to get
   `x i + c ≤ x j + c`.
2. Use ordered-ring monotonicity / `add_le_add_iff_right` to cancel `c`.
3. Lift pointwise pairwise-order preservation to argmin-set preservation by quantifying over all `j`.

Why this is best:
- Lean-native,
- no heavy dependencies,
- gives a clean reusable lemma for many downstream applications.

### Strategy B: Factor through pairwise differences
More conceptual and better for future extensions to statistics.

1. Prove `y i - y j = x i - x j` under the shift hypothesis.
2. Deduce preservation of sign of differences, hence order.
3. Define ranking/argmin/gap statistics purely in terms of pairwise differences and show they are invariant.

Why this matters:
- pairwise differences are the real projective tropical invariants;
- this strategy naturally extends to robust statistics and phylogenetic dissimilarity comparisons.

### Strategy C: Tropical projectivization / quotient viewpoint
Most visionary, but may require more definitions.

1. Define tropical equivalence on functions `Fin n → ℝ` by
   `x ~ y ↔ ∃ c, ∀ i, y i = x i + c`.
2. Show ranking statistics descend to the quotient.
3. Interpret the theorem as well-definedness of a map from tropical projective space to finite preorders / argmin subsets.

Why this is revolutionary:
- it turns a concrete lemma into a structural theorem;
- it opens a formal theory of tropical statistical observables as quotient invariants.

Recommended order: **A first, then B, then C if time permits.**

## Concrete Case-Study-Oriented Theorem Ideas

If you want a more data-facing theorem beyond the core invariant, choose one:

### Option 1: Gap-stability theorem
If all pairwise score gaps exceed `2 * ε`, and `‖(t - s) - c‖∞ ≤ ε`, then ranking is unchanged.

Lean-friendly formulation:

```lean
theorem approximate_tropical_shift_preserves_order
    {n : ℕ} (s t : Fin n → ℝ) (c ε : ℝ)
    (hε : 0 ≤ ε)
    (happrox : ∀ i, |(t i - s i) - c| ≤ ε)
    (hgap : ∀ i j, s i < s j → s i + 2 * ε < s j) :
    ∀ i j, s i < s j → t i < t j
```

This would combine beautifully with `tropical_network_lipschitz_bound`.

### Option 2: Tropical normalization preserves minimizers of path scores
Define finite path-score surrogates over a matrix or finite graph and show additive row/column normalization preserving relative path minima under suitable hypotheses.

### Option 3: Tropical equivalence preserves top-k sets
A more combinatorial invariant, useful in network science:

```lean
theorem tropical_shift_preserves_topk_threshold
    {n : ℕ} (x y : Fin n → ℝ) (c τ : ℝ)
    (hshift : ∀ i, y i = x i + c) :
    {i | x i ≤ τ} = {i | y i ≤ τ + c}
```

This is highly interpretable for threshold-based scientific pipelines.
