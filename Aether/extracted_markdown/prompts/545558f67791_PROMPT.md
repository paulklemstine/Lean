## Vision

Grover amplification in Hilbert space rotates amplitude toward marked states. In the min-plus world there is no interference, no unitary geometry, no Born rule. So the breakthrough is **not** to imitate quantum mechanics syntactically. The breakthrough is to identify the tropical replacement for amplitude: a **cost landscape**, and the replacement for amplification: **iterative gap magnification** under a min-plus reflection/update operator.

The field-opening theorem is this:

> For a finite structured search space equipped with a decomposition of state cost into local penalties, there exists a min-plus amplification operator whose iterates increase the separation between marked and unmarked states at a rate exponential in the number of rounds under a gap-squaring recurrence, so that the argmin can be isolated in logarithmically many rounds in the inverse initial gap scale.

This would open a new program:
- tropical analogues of quantum search,
- optimization-as-wave-propagation in idempotent algebra,
- certified fast search in weighted automata / dynamic programming / shortest-path style semirings,
- bridges from quantum algorithms to tropical complexity theory.

## Formalization Target

Work with concrete finite spaces first: `Fin n → ℕ`, `Fin n → ℤ`, or `Fin n → WithTop ℕ`. The cleanest first model is `Fin n → ℕ`.

Define:
- a set of marked states `M : Finset (Fin n)`,
- a cost profile `c : Fin n → ℕ`,
- the marked minimum and unmarked minimum,
- the search gap `Δ(c,M) := min_unmarked - min_marked` when `M` is nonempty and not all of `Fin n)`.

Then define a min-plus amplification operator `A` on cost profiles. The operator should lower marked costs relative to unmarked costs by combining:
1. an oracle-like reward/penalty shift, and
2. a global normalization/reflection based on the current minimum.

A workable first operator is:
- oracle step: subtract a bonus from marked states, leave others unchanged,
- diffusion step: replace `c i` by `min (c i) (μ + (c i - μ) + (c i - μ))`, where `μ = min_j c j`,
or in purely additive/min terms define a recurrence directly on the gap:
- marked min remains `m_t`,
- unmarked min evolves by `u_{t+1} = min(u_t, 2*u_t - m_t - β)` after an oracle bonus `β` on marked states.

But the most Lean-friendly path is to define an operator that acts pointwise by cases on membership in `M`, then prove exact formulas for marked/unmarked minima.

## Precise Core Theorem to Target

### Theorem 1: One-step gap amplification
Define, for `bonus : ℕ`,
```lean
def oracleShift {n : ℕ} (M : Finset (Fin n)) (bonus : ℕ) (c : Fin n → ℕ) : Fin n → ℕ :=
  fun i => if i ∈ M then c i else c i + bonus
```
This is the simplest tropical “phase oracle”: in min-plus, adding cost to unmarked states is the natural analogue of penalizing them.

Define:
```lean
def markedMin {n : ℕ} (M : Finset (Fin n)) (c : Fin n → ℕ) : ℕ :=
  M.inf' (by simp) c

def unmarkedFinset {n : ℕ} (M : Finset (Fin n)) : Finset (Fin n) :=
  Finset.univ \ M

def unmarkedMin {n : ℕ} (M : Finset (Fin n)) (h : (unmarkedFinset M).Nonempty) (c : Fin n → ℕ) : ℕ :=
  (unmarkedFinset M).inf' h c
```

Then prove:

```lean
theorem oracleShift_gap_increases
  {n : ℕ} (M : Finset (Fin n)) (hM : M.Nonempty)
  (hU : (unmarkedFinset M).Nonempty)
  (bonus : ℕ) (c : Fin n → ℕ) :
  unmarkedMin M hU (oracleShift M bonus c)
    = unmarkedMin M hU c + bonus
  ∧
  markedMin M (oracleShift M bonus c)
    = markedMin M c
```

and therefore a corollary:

```lean
theorem oracleShift_separates_marked_from_unmarked
  {n : ℕ} (M : Finset (Fin n)) (hM : M.Nonempty)
  (hU : (unmarkedFinset M).Nonempty)
  (bonus : ℕ) (c : Fin n → ℕ) :
  unmarkedMin M hU (oracleShift M bonus c) - markedMin M (oracleShift M bonus c)
  =
  (unmarkedMin M hU c - markedMin M c) + bonus
```

This is already nontrivial and formalizable. It establishes linear tropical amplification.

## Breakthrough Theorem to Reach

### Theorem 2: Iterated amplification isolates the marked argmin in logarithmic rounds
Define iterates:
```lean
def amplifyIter {n : ℕ} (M : Finset (Fin n)) (bonus : ℕ) : ℕ → (Fin n → ℕ) → (Fin n → ℕ)
| 0, c => c
| t+1, c => oracleShift M bonus (amplifyIter t c)
```
or use `Nat.iterate`.

Let
- `m0 = markedMin M c`,
- `u0 = unmarkedMin M c`,
- `gap0 = u0 - m0`.

Then prove:
```lean
theorem iterated_oracleShift_gap_formula
  {n : ℕ} (M : Finset (Fin n)) (hM : M.Nonempty)
  (hU : (unmarkedFinset M).Nonempty)
  (bonus t : ℕ) (c : Fin n → ℕ) :
  unmarkedMin M hU ((oracleShift M bonus)^[t] c)
    - markedMin M ((oracleShift M bonus)^[t] c)
  =
  (unmarkedMin M hU c - markedMin M c) + t * bonus
```

Then derive the search theorem:

```lean
theorem amplification_finds_marked_argmin
  {n : ℕ} (M : Finset (Fin n)) (hM : M.Nonempty)
  (hU : (unmarkedFinset M).Nonempty)
  (bonus t : ℕ) (c : Fin n → ℕ)
  (hsep :
    unmarkedMin M hU c - markedMin M c + t * bonus > 0) :
  ∀ i, i ∈ M →
    ∀ j, j ∉ M →
      ((oracleShift M bonus)^[t] c) i < ((oracleShift M bonus)^[t] c) j
```

Interpretation: after enough rounds, every marked minimizer beats every unmarked state. If the initial gap is unfavorable, the required number of rounds is `O((m0-u0)/bonus)`; for structured cost decompositions where one round can be implemented in sublinear or local form, this is a true algorithmic speedup over exhaustive comparison.

## More Ambitious Theorem: Gap Squaring

The truly visionary theorem is not linear gap growth but **quadratic/exponential amplification** via a tropical diffusion operator.

Define a normalized profile:
```lean
def globalMin {n : ℕ} (c : Fin n → ℕ) : ℕ := Finset.univ.inf' (Finset.univ_nonempty) c

def diffuse {n : ℕ} (c : Fin n → ℕ) : Fin n → ℕ :=
  let μ := globalMin c
  fun i => μ + 2 * (c i - μ)
```
Then define:
```lean
def tropGroverStep {n : ℕ} (M : Finset (Fin n)) (bonus : ℕ) (c : Fin n → ℕ) : Fin n → ℕ :=
  diffuse (oracleShift M bonus c)
```

Now target a theorem of the form:
```lean
theorem tropGroverStep_gap_doubling
  {n : ℕ} (M : Finset (Fin n)) (hM : M.Nonempty)
  (hU : (unmarkedFinset M).Nonempty)
  (bonus : ℕ) (c : Fin n → ℕ)
  (hmin : markedMin M c = globalMin c) :
  unmarkedMin M hU (tropGroverStep M bonus c) - markedMin M (tropGroverStep M bonus c)
  =
  2 * (unmarkedMin M hU c - markedMin M c + bonus)
```

If you can prove this exact formula, then iteration yields:
```lean
theorem tropGroverIter_exponential_gap
  {n : ℕ} (M : Finset (Fin n)) (hM : M.Nonempty)
  (hU : (unmarkedFinset M).Nonempty)
  (bonus t : ℕ) (c : Fin n → ℕ)
  (hmin : markedMin M c = globalMin c) :
  ∃ K,
    unmarkedMin M hU ((tropGroverStep M bonus)^[t] c)
      - markedMin M ((tropGroverStep M bonus)^[t] c)
    =
    2^t * (unmarkedMin M hU c - markedMin M c) + K
```
with explicit `K`, ideally `K = bonus * (2^t - 1)` or similar.

This would be the first genuine tropical analogue of amplitude amplification: not just monotone improvement, but repeated gap magnification.

## Proof Strategy Architecture

### Strategy A: Finset-inf exact formulas
Most promising for the first two theorems.

1. Define marked and unmarked minima using `Finset.inf'`.
2. Prove pointwise formulas:
   - on marked states, `oracleShift` is identity;
   - on unmarked states, `oracleShift` adds exactly `bonus`.
3. Use `Finset.inf'_congr` or direct `le_antisymm` arguments to show the minima transform exactly.
4. Iterate using `Function.iterate_succ_apply` and induction on `t`.

Why this is promising: it is completely concrete, avoids abstract semiring machinery, and produces robust Lean proofs with minimal sorrys.

### Strategy B: Tropical semiring / order-theoretic abstraction
Best for the breakthrough diffusion theorem.

1. View `Fin n → ℕ` as a tropical module of cost profiles.
2. Express `oracleShift` and `diffuse` as monotone endomorphisms preserving argmin structure.
3. Use distributivity of `+` over `min` from the catalog to push minima through the operator.
4. Derive exact recurrence on the two scalar statistics `markedMin` and `unmarkedMin`.

Why this matters: it transforms the result from an ad hoc finite combinatorics lemma into a reusable tropical search calculus.

### Strategy C: Weighted automata / dynamic programming realization
Best for “structured search” significance.

1. Model a structured instance as a decomposable cost:
   `c x = ∑_{k} φ_k(x)` on `Fin n` or product spaces.
2. Show `oracleShift` and possibly `diffuse` can be computed locally or as a min-plus circuit.
3. Prove that after `t` rounds, only local summaries are needed to certify marked dominance.
4. Connect this to faster inference in weighted automata, Viterbi-style decoding, or shortest-path search.

Why this matters: this is where “speedup” becomes algorithmic rather than merely order-theoretic.

## Cross-Domain Connections You Must Exploit

### 1. Quantum algorithms → tropical optimization
The conceptual bridge is exact:
- quantum amplitude ↔ tropical cost,
- phase oracle ↔ oracle penalty on unmarked states,
- diffusion/reflection ↔ normalization plus cost dilation,
- measurement success ↔ argmin isolation.

The paper should explicitly state where the analogy breaks and where it becomes mathematically stronger: tropical search is deterministic and certificate-bearing.

### 2. Boolean logic / satisfiability
Use `trop_min_is_and` to connect tropical filtering with logical conjunction. Marked-state amplification can be interpreted as iteratively enforcing constraints. This suggests applications to SAT preprocessing, CSP pruning, and branch-and-bound.

### 3. Dynamic programming / shortest paths / control
Min-plus algebra is the native language of Bellman operators. A tropical amplitude amplification theorem becomes a theorem about accelerating winner-state isolation in deterministic optimal control or weighted automata.

### 4. Cellular automata and symbolic dynamics
`min_plus_ca_periodic_definable` suggests a route where amplification is not just an operator on finite vectors but a local dynamical system. This opens the possibility of tropical Grover dynamics implemented as a min-plus CA with definable periodic or convergent behavior.

### 5. Complexity theory
If you can formalize a structured family where each amplification round is local/sublinear and the number of rounds is logarithmic in the inverse gap, you have the beginning of a tropical complexity class separation story: search by gap amplification rather than exhaustive scan.

## What Would Count as a Breakthrough

A theorem merely saying “penalizing unmarked states increases their cost” is too weak. The real breakthrough threshold is one of:

1. **Exact iterate formula** for min-plus amplification over finite search spaces.
2. **Gap-doubling or gap-squaring theorem** under a tropical diffusion operator.
3. **Structured search theorem** showing fewer rounds than naive exhaustive comparison for decomposable costs.
4. **Argmin certification theorem**: after `t` rounds, membership in the marked set is recoverable from a threshold on amplified cost.
5. **CA/automata implementation theorem**: amplification operator realized by a local min-plus rule.

Aim for (1) plus (3), or (2) if the algebra cooperates.
