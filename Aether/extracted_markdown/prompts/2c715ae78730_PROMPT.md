## PROOF STRATEGY

### Strategy A: Prefix factorization + first-divergence separation + arithmetic rearrangement
This is the most promising route.

1. **Factor words at the longest common prefix.**
   Use `exists_prefix_split` to write
   `u = p ++ u'`, `v = p ++ v'`,
   where either one suffix is empty or their first letters differ.
   Then rewrite both evaluations via `evalWord_append`.

2. **Reduce the main theorem to the first-divergence case.**
   The geometry after the common prefix is controlled by the action from the intermediate triple
   `tp := evalWord p rootTriple`.
   Prove a shifted version of the divergence theorem with arbitrary basepoint:
   ```lean
   theorem first_letter_divergence_at
     (t : Triple) (ht : primitiveTriple t)
     {g h : BerggrenGen} {u v : BerggrenWord}
     (hgh : g ≠ h) : ...
   ```
   Then specialize to `tp`.

3. **Exploit monotone height growth.**
   Show that `tripleHeight tp` is at least the prefix length, and ideally comparable to it from below by an exponential or linear function. This converts geometric closeness into a lower bound on prefix length.

4. **Handle degenerate suffix cases separately.**
   If one word is a prefix of the other, then `lcpLength u v = min u.length v.length` exactly; use height monotonicity to prove the bound without separation.

5. **Push to algorithmics.**
   Once `candidate_prefix_concentration` is proved, define a pruning criterion: two candidates matching the same public data must lie in a narrow prefix cone, so subtrees whose lower bound exceeds `ε` can be discarded soundly.

Why this route is strongest: it uses only semigroup freeness/cancellation, growth of height, and a geometric separation lemma already philosophically present in the Berggren spectral-gap/collision-separation infrastructure.

## Summary

This file formalizes the Berggren tree infrastructure and provides a rigorous analysis

## Conclusion: The Conjecture Is False

The central claim — that `tropicalRank(T_p(N)) = ω(N)` — is **false**, for multiple
independent reasons:

### 1. Dimensional Obstruction (Fatal)
The "path matrix" B(N) has dimensions (path_length × 3), since each Pythagorean triple
is a vector in ℤ³. Therefore its tropical rank is at most min(path_length, 3) ≤ 3.
But ω(N) can be arbitrarily large, so the equality fails for any N with ω(N) > 3.

### 2. Concrete Counterexample: N = 169 = 13²
- Path: (3,4,5) → (21,20,29) → (119,120,169), using B₂ twice.
- For p = 13: T₁₃(169) = [[0,0,0],[0,0,0],[0,0,2]]
- Tropical rank of this matrix is ≥ 2 (proof below: it cannot be written as an
  outer sum a[i] + b[j], since all entries are 0 except the (2,2) entry which is 2).
- But ω(169) = ω(13²) = 1.
- So tropical rank ≥ 2 > 1 = ω(N). **Equality fails.**

### 3. Concrete Counterexample: N = 25 = 5²
- Path: (3,4,5) → (5,12,13) → (7,24,25), using B₁ twice.
- For p = 5: T₅(25) = [[0,0,1],[1,0,0],[0,0,2]]

  so the matrix cannot be tropically rank 1.

Not every N > 1 appears as a hypotenuse of a primitive Pythagorean triple.
For a primitive triple (a,b,c), every prime factor of c must be ≡ 1 (mod 4).
So N = 6, 10, 14, 15, 21, ... have no Berggren path at all, making B(N) undefined.
