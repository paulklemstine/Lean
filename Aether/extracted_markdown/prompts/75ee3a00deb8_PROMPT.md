## Precise Theorem Target

### Core mathematical objects

Model a transformer-like symbolic architecture by a finite acyclic directed graph `G` with:
- source nodes = inputs,
- sink node = output,
- each internal node labeled by a primitive operation from a fixed signature `σ`,
- each operation assigned a tropical weight contribution,
- a size parameter `N : ℕ` controlling parameter count / width scaling.

Define a **path cost polynomial**
\[
C_G(N) = \min_{p \in \mathrm{Paths}(G)} \left(a_p \cdot \log N + b_p\right)
\]
or, after de-logarithmization, an equivalent piecewise monomial asymptotic profile
\[
R_G(N) \asymp N^{-\alpha_G} (\log N)^{\beta_G},
\]
where `α_G ∈ ℚ` is extracted from the tropicalized path geometry.

Define tropical equivalence `G ≈ₜ H` by equality of the induced tropical path semiring object, or equivalently by equality of the reduced tropical normal form of their weighted path families.

Then prove:

### Theorem A: Rationality and invariance of the tropical scaling exponent
For every weighted acyclic computation graph `G` in the admissible symbolic architecture class, there exists a rational number `α(G) : ℚ` such that:
1. `α(G)` is computable from the reduced tropical path normal form of `G`,
2. if `G ≈ₜ H`, then `α(G) = α(H)`,
3. for the canonical symbolic resource-loss proxy `L_G(N)`, there exist constants `c₁,c₂>0` and integers `m₁,m₂` such that for all sufficiently large `N`,
   \[
   c_1 N^{-\alpha(G)}(\log N)^{m_1} \le L_G(N) \le c_2 N^{-\alpha(G)}(\log N)^{m_2}.
   \]

This is already a field-opening theorem if done cleanly.

## Suggested Definitions

You will likely need to invent the right surrogate notions.

### 1. Weighted tropical path valuation
For each path `p` in `G`, assign a pair `(u_p, v_p)` where:
- `u_p : ℚ` = leading power contribution,
- `v_p : ℤ` or `ℚ` = lower-order logarithmic contribution.

Then define the tropical normal form as the minimum of these affine functionals:
\[
\Phi_G(x) = \min_{p} (u_p x + v_p).
\]
The leading slope at infinity is the scaling exponent:
\[
\alpha(G) := \min\{u_p : p \text{ eventually attains the minimum}\}.
\]

For finite DAGs, this is automatically rational if all node weights are rational.

### 2. Tropical equivalence
Define:
```lean
def TropicalEquivalent (G H : WeightedDAG σ) : Prop :=
  tropicalNormalForm G = tropicalNormalForm H
```
or a weaker extensional equality:
```lean
∀ x, tropicalPotential G x = tropicalPotential H x
```

### 3. Symbolic complexity proxy
Do not model empirical loss directly. Define a canonical deterministic proxy:
- minimal tropical resource needed to represent all target symbolic patterns up to complexity `K(N)`,
- or a path-based approximation error surrogate.

Even a purely combinatorial proxy is acceptable if it has the right asymptotic structure.

## Proof Strategy A: Tropical normal form and eventual slope extraction
**Most promising.**

1. **Encode every admissible DAG as a finite tropical polynomial.**  
   Show by induction on the DAG that composition of admissible gates produces a finite family of affine forms in `log N`, with rational slopes.

2. **Prove eventual linearity of the lower envelope.**  
   A finite minimum of affine rational functions is piecewise affine, and for sufficiently large `x` its active branch has slope in a finite rational set. This gives existence and rationality of `α(G)`.

3. **Deduce invariance under tropical equivalence.**  
   If two graphs have the same tropical normal form, they have the same eventual slope, hence the same exponent.

4. **Transfer to asymptotic proxy bounds.**  
   Define `symbolicComplexityProxy` directly from the tropical normal form so the asymptotic sandwich is almost tautological.

Why this is strongest: it avoids stochastic training and gives a fully certifiable invariant theorem now.

## Proof Strategy B: Semiring dynamic programming on DAGs
A more algorithmic route.

1. Define a DP recurrence computing the minimal weighted contribution from each node to the sink.
2. Show the recurrence lives in a min-plus semiring with rational edge labels.
3. Prove the resulting value function is eventually affine in `log N`.
4. Show graph rewrites preserving the semiring value induce equal exponents.

Why useful: this can connect directly to certified algorithms and may integrate well with existing complexity theorems like `tropical_sort_complexity_bound`.

## Proof Strategy C: Newton polytope / valuation geometry
Most visionary, but potentially heavier in Lean.

1. Associate to each DAG a finite set of exponent vectors and its Newton polytope.
2. Interpret tropicalization as support-function data of that polytope.
3. Prove the scaling exponent is the outer normal slope of a distinguished face.
4. Tropical equivalence becomes equality of support functions, hence equality of exponents.

Why important: this is the route toward the genuinely “motivic” story. Even if not fully completed this cycle, structure your definitions so this geometric upgrade is possible later.
