## Central Vision

Let `G` be a finite connected graph with edge set `E`, graph Laplacian `L_G`, algebraic connectivity `λ₂(L_G)`, and spanning-tree polynomial
\[
T_G(x) = \sum_{T \text{ spanning tree of } G} \prod_{e\in T} x_e.
\]
The vision is to show that the **Lorentzian stability radius** of `T_G` is not a mysterious algebro-combinatorial quantity, but is controlled by the same spectral gap that governs expansion, mixing, synchronization, and network robustness.

If this succeeds, it opens a new field: **spectral Lorentzian combinatorics**. It would import Cheeger inequalities, Fiedler vectors, expander technology, and effective resistance methods directly into the study of Lorentzian and strongly log-concave polynomials.

Application keywords: **spectral graph theory, Lorentzian polynomials, matroid theory, algebraic connectivity, spanning tree polynomial, Cheeger inequality, effective resistance, network robustness, expander graphs, Hessian spectra, strong log-concavity, perturbation theory**.

## Primary theorem statement

### Theorem A: spectral lower bound on Lorentzian stability radius for graphic matroids

For a connected finite graph `G` with `n = |E(G)|`, rank `r = |V(G)| - 1`, and spanning-tree polynomial `T_G`, prove a theorem of the form:

\[
\exists C_r > 0,\quad
\rho(T_G) \ge C_r \cdot \frac{\lambda_2(L_G)}{n},
\]
or more realistically in first cycle,
\[
\rho(T_G) \ge C_{r,\nu}^{-1}\,\frac{\lambda_2(L_G)}{|E(G)|}
\]
for an explicit constant depending only on rank `r` and nullity `ν = |E|-|V|+1`.

A Lean 4 target signature could look like:

```lean
theorem graphic_lorentzian_stability_radius_lower_bound
    {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V)
    (hconn : G.Connected)
    :
    ∃ C : ℝ,
      0 < C ∧
      lorentzianStabilityRadius (spanningTreePolynomial G)
        ≥ C * algebraicConnectivity G / (Fintype.card (Sym2 V) : ℝ)
```

If `SimpleGraph` edge counting through `Sym2 V` is awkward, define a finite edge type for a fixed graph and state the theorem there. Precision matters more than prettiness.

## Secondary theorem targets

### Theorem B: Hessian of a quadratic leaf is a Laplacian compression

Make precise the heuristic that a codimension-`r-2` directional derivative of the spanning-tree polynomial yields a quadratic form whose Hessian is a principal compression/minor of the graph Laplacian or a weighted Laplacian of a contracted graph.

Suggested statement:

\[
\text{For every quadratic leaf } q \text{ of } T_G,\quad
H(q) = P^\top L_{G'} P
\]
for some graph minor `G'` obtained by deletions/contractions and some coordinate embedding `P`.

Lean target sketch:

```lean
theorem hessian_quadratic_leaf_eq_laplacian_compression
    {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) :
    ∀ q, q ∈ quadraticLeaves (spanningTreePolynomial G) →
      ∃ (V' : Type*) (_ : Fintype V') (_ : DecidableEq V')
        (G' : SimpleGraph V') (P : Matrix _ _ ℝ),
        isGraphMinorOf G' G ∧
        hessianMatrix q = Pᵀ ⬝ graphLaplacianMatrix G' ⬝ P
```

Even a weaker verified theorem is valuable if fully precise: e.g. for leaves obtained from edge-contraction chains, or for a restricted family of graphs.

### Theorem C: interlacing transfers algebraic connectivity to leaf spectral gap

Use Cauchy interlacing / principal submatrix monotonicity to prove that if a quadratic leaf Hessian is a Laplacian compression, then its nontrivial smallest eigenvalue is bounded below by `λ₂(L_G)` up to a normalization factor.

Suggested mathematical form:
\[
\lambda_{\min}^+(H(q)) \ge c(G,q)\,\lambda_2(L_G),
\]
with an explicit `c(G,q)`; first-cycle success could be `c(G,q) = 1` for principal submatrices under a suitable normalization, or a weaker but certified bound.

Lean target sketch:

```lean
theorem quadratic_leaf_spectral_gap_lower_bound
    {n : ℕ} (L H : Matrix (Fin n) (Fin n) ℝ)
    (hL : IsGraphLaplacian L)
    (hH : IsPrincipalCompression H L) :
    algebraicConnectivityMatrix H ≥ algebraicConnectivityMatrix L
      ∨ algebraicConnectivityMatrix H ≥ c * algebraicConnectivityMatrix L
```

You may need to formulate this using ordered eigenvalues of symmetric matrices available in Mathlib, or prove a custom Rayleigh quotient inequality if eigenvalue APIs are insufficient.

### Theorem D: cross-domain theorem via effective resistance or Cheeger constant

Include at least one theorem connecting the Lorentzian radius to another domain. Two strong options:

1. **Cheeger bridge**
   \[
   \rho(T_G) \ge C \frac{h(G)^2}{d_{\max}\,|E|},
   \]
   using `λ₂ ≥ h(G)^2/(2 d_max)`.

2. **Effective resistance bridge**
   Bound the stability radius below using average effective resistance or Kirchhoff index, via the matrix-tree theorem and Laplacian pseudoinverse heuristics.

Lean target sketch for the Cheeger bridge:

```lean
theorem graphic_stability_radius_lower_bound_via_cheeger

    (G : SimpleGraph V) (hconn : G.Connected) :
    ∃ C : ℝ, 0 < C ∧

            / ((maxDegree G : ℝ) * (edgeCardinality G : ℝ))
```

This is the required cross-domain theorem: combinatorial Hodge/Lorentzian theory + spectral geometry/network science.

\textbf{Conjecture (Spectral Stability Law).}\quad
\exists c_1,c_2>0 \text{ depending only on rank/nullity such that for every connected graph } G,

c_1 \frac{\lambda_2(L_G)}{|E(G)|}

For graph families `K_n`, `C_n`, `P_n` with `n ≤ 10`, the ratio
\[
\frac{\rho(T_G)\,|E(G)|}{\lambda_2(L_G)}

should stabilize to a family-dependent constant or remain in a narrow interval.

A stronger prediction worth testing:
- `K_n`: ratio approaches a positive constant near the uniform matroid benchmark.
- `C_n`: ratio remains bounded away from zero.
- `P_n`: ratio decays slowly or stabilizes after degree normalization, revealing whether trees are extremizers.

A computational disproof would consist of an explicit family where the ratio tends to `0` or `∞`.

## Proof Architecture: 3 serious strategy paths

### Strategy A: Hessian-minor route via matrix-tree theorem
Most promising.

1. Express directional derivatives of `T_G` combinatorially using deletion-contraction and the matrix-tree theorem.
2. Show quadratic leaves correspond to weighted spanning-tree polynomials on graph minors; identify their Hessians with Laplacian compressions/principal minors.
3. Use Rayleigh quotient characterizations and interlacing to transfer `λ₂(L_G)` bounds to leaf Hessians.
4. Invoke the perturbation framework from `LorentzianStability.lean` and any sharp constants from `LorentzianSharpStability.lean` to deduce a certified stability radius.

Why this is strongest: it connects directly to already-structured Laplacian algebra and avoids black-box Lorentzian machinery. It should also produce explicit constants.

### Strategy B: Strong log-concavity + spectral certificate route
Potentially cleaner if quadratic leaf APIs are difficult.

1. Reinterpret the Lorentzian stability radius as a uniform quantitative negative-eigenvalue margin over quadratic directional derivatives.
2. Prove that for graphic matroids these derivatives are controlled by strongly log-concave basis-generating polynomials and by the exchange walk/Laplacian of the graph.
3. Derive a lower bound from spectral expansion of the underlying graph or basis-exchange structure.

Why it may work: it uses the conceptual heart of Lorentzian theory. Why it is riskier: formal APIs for quantitative strong log-concavity may be less mature than matrix arguments.

### Strategy C: Restricted-family first, then abstract bootstrap
Best fallback if full generality is blocked.

1. Prove the full theorem for explicit families: complete graphs, cycles, paths, complete bipartite graphs.
2. Isolate the exact graph-theoretic invariant that appears in each proof: usually `λ₂`, degree profile, or effective resistance.
3. Generalize the argument to graphs built by 1-sums / 2-sums / ear decompositions, proving closure theorems for the stability radius under graph composition.

Why useful: even if the universal theorem is out of reach, a family theorem plus composition law can still be field-opening and computationally predictive.
