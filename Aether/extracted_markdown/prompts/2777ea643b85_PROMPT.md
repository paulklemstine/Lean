## Research Task: Berggren semigroup finite-ball bi-order separation and conjugacy-free normal-form rigidity for the SL₂(ℤ) SPB embedding

Research Mode: PROVE

Work in the concrete Berggren/SPB semigroup already embedded in `SL₂(ℤ)` (or in the ambient `Matrix (Fin 2) (Fin 2) ℤ` type if that is the established representation), with the three standard positive generators `A B C`. Use the existing word-length / normal-form infrastructure already proved for Berggren factoring, finite-prefix unique factorization, cancellation, and logarithmic word-metric rigidity.

The goal is to prove a genuinely stronger local rigidity theorem: inside a finite radius ball, an element is determined simultaneously by its bounded right-principal ideal trace and bounded left-principal ideal trace. This should then be sharpened to a bounded collision-resistance statement forbidding nontrivial conjugacy-style collisions.

### Precise theorem package to target

You should define the finite ball and the local principal-ideal traces explicitly. If the semigroup carrier is called `Berggren` or similar, prefer that existing type; otherwise work with a subtype of matrices generated by `A,B,C`.

A good concrete setup is:

```lean
def ball (R : ℕ) : Finset S :=
  (Finset.univ.filter fun x => len x ≤ R)
```

if `S` is finite on bounded length via an existing word encoding; otherwise define the ball on words and push forward to matrices using the already proved injectivity/normal form theorem.

Define bounded right/left traces:

```lean
def rightTrace (R : ℕ) (x : S) : Finset S :=
  (ball R).filter fun z => ∃ t : S, z = x * t

def leftTrace (R : ℕ) (x : S) : Finset S :=
  (ball R).filter fun z => ∃ t : S, z = t * x
```

If a word model is more convenient:

```lean
def rightTraceWord (R : ℕ) (w : Word ABC) : Finset (Word ABC) :=
  (wordsLe R).filter fun z => ∃ t, z = w ++ t

def leftTraceWord (R : ℕ) (w : Word ABC) : Finset (Word ABC) :=
  (wordsLe R).filter fun z => ∃ t, z = t ++ w
```

Then transport the result to the matrix semigroup via the existing embedding and unique factorization theorem.

### Main structural theorem: finite-ball bi-order separation

The central theorem should be stated as a local Green-relation rigidity result. A strong Lean signature to aim for is:

```lean
theorem biOrder_separation_ball
    {R : ℕ} {x y : S}
    (hx : len x ≤ R) (hy : len y ≤ R)
    (hR : rightTrace R x = rightTrace R y)
    (hL : leftTrace R x = leftTrace R y) :
    x = y
```

A word-level version is likely easier and may be the real engine:

```lean
theorem biOrder_separation_words
    {R : ℕ} {w w' : Word ABC}
    (hw : w.length ≤ R) (hw' : w'.length ≤ R)
    (hR : rightTraceWord R w = rightTraceWord R w')
    (hL : leftTraceWord R w = leftTraceWord R w') :
    w = w'
```

If your existing normal-form theorem gives injectivity of evaluation:

```lean
theorem biOrder_separation_matrix
    {R : ℕ} {w w' : Word ABC}
    (hw : w.length ≤ R) (hw' : w'.length ≤ R)
    (hR : rightTraceMat R (eval w) = rightTraceMat R (eval w'))
    (hL : leftTraceMat R (eval w) = leftTraceMat R (eval w')) :
    eval w = eval w' := ...
```

and then derive `w = w'` from injectivity.

A more conceptual corollary, worth proving if the local `L`/`R` relations have been defined, is:

```lean
theorem local_LR_classes_singleton
    {R : ℕ} {x y : S}
    (hx : len x ≤ R) (hy : len y ≤ R)
    (hL : leftTrace R x = leftTrace R y)
    (hR : rightTrace R x = rightTrace R y) :
    x = y
```

This is exactly the “bounded Green relations are trivial” formulation.

### Stronger normal-form rigidity from equal bounded ideals

A sharper theorem should expose the prefix/suffix content directly. The most useful formulation is:

```lean
theorem equal_bounded_principal_ideals_imp_eq
    {R : ℕ} {x y : S}
    (hx : len x ≤ R) (hy : len y ≤ R)
    (hxr : ∀ z, z ∈ ball R → (∃ t, z = x * t) ↔ (∃ t, z = y * t))
    (hxl : ∀ z, z ∈ ball R → (∃ t, z = t * x) ↔ (∃ t, z = t * y)) :
    x = y
```

This pointwise formulation is often easier to use than literal `Finset` equality.

At the word level, there is an even cleaner statement that should be accessible by combinatorics on lists:

```lean
theorem equal_prefix_suffix_languages_ball_imp_eq
    {R : ℕ} {w w' : Word ABC}
    (hw : w.length ≤ R) (hw' : w'.length ≤ R)
    (hpref : ∀ z, z.length ≤ R → (∃ t, z = w ++ t) ↔ (∃ t, z = w' ++ t))
    (hsuf  : ∀ z, z.length ≤ R → (∃ t, z = t ++ w) ↔ (∃ t, z = t ++ w')) :
    w = w'
```

This theorem is mathematically important because it says the bounded two-sided ideal footprint already determines the normal form. It is a local, finite-ball analogue of bi-order embeddability, but in a setting where one only has semigroup structure and positivity/growth rather than a global order.

### Suggested proof strategy

A robust route is to prove the word-level theorem first, then transfer to matrices.

1. **Recover prefix comparability from right-trace equality.**  
   Since `w ∈ rightTraceWord R w` via multiplier `[]`, equality of right traces gives `w ∈ rightTraceWord R w'`, hence there exists `t` with
   ```lean
   w = w' ++ t
   ```
   because `w.length ≤ R`. Symmetrically, from `w' ∈ rightTraceWord R w`, obtain
   ```lean
   w' = w ++ t'
   ```
   This already forces length inequalities in both directions. Taking lengths gives
   ```lean
   w.length = w'.length + t.length
   w'.length = w.length + t'.length
   ```
   so `t.length = 0` and `t'.length = 0`. Therefore `t = []` and `w = w'`.  
   This argument is extremely clean in the free-word model and should be formalized first.

2. **Transfer from words to semigroup elements using existing unique factorization.**  
   If the semigroup elements are matrices, use the established theorem that evaluation on reduced Berggren words is injective / admits unique factorization. Show that the matrix right trace corresponds exactly to the word right trace after restricting to normal forms of length `≤ R`. Then apply the word theorem to the unique normal forms of `x` and `y`.

3. **If direct transport is awkward, use cancellation plus finite-prefix uniqueness.**  
   From `x ∈ rightTrace R y`, get `x = y * t`; from `y ∈ rightTrace R x`, get `y = x * t'`. Substitute:
   ```lean
   x = x * (t' * t)
   ```
   Then use right-cancellation or the no-nontrivial-idempotent/freeness phenomenon already available in the Berggren semigroup to conclude `t' * t = 1`, hence both are trivial. If the semigroup has no identity internally, adjoin the empty word on the word side and transport back.  
   This is where the existing finite-prefix unique factorization and cancellation lemmas should be exploited.

4. **Use positivity and growth to extract first-letter invariants if needed.**  
   If some transfer step requires distinguishing generators from matrix data, use monotonicity of positive entries under multiplication. The first column / row growth under left or right multiplication by `A,B,C` should give a finite invariant of the leading or trailing letter. Combined with bounded-length control, this can recover the first generator from matrix inequalities, after which induction on the remaining suffix applies.

5. **Optional induction on radius `R`.**  
   If the finite-ball theorem is organized inductively, prove the base case `R = 0` separately, then show that equality of traces at radius `R+1` forces equality of first and last letters, and then reduce to radius `R` on the interior suffix. The logarithmic word-metric rigidity theorem is useful here to convert matrix-norm bounds into length bounds when traces are expressed in matrix form rather than word form.

The key insight is that local principal-ideal equality is much stronger than mere existence of a common multiple: because `x` and `y` themselves lie in the ball, each must appear in the other’s bounded ideal trace, forcing mutual prefix and suffix containment. In the free or uniquely factorized Berggren setting, mutual containment collapses to equality.

### Cryptographic corollary: bounded collision-resistance

After the structural theorem, prove a concrete bounded-collision statement. A strong formal target is:

```lean
theorem bounded_two_sided_collision_rigidity
    {R : ℕ} {x y u v u' v' : S}
    (hx : len x ≤ R) (hy : len y ≤ R)
    (hballx : x ∈ ball R) (hbally : y ∈ ball R)
    (heq : u * x * v = u' * y * v')
    (htrace :
      rightTrace R x = rightTrace R y ∧
      leftTrace R x = leftTrace R y) :
    x = y
```

A more refined statement, closer to “conjugacy-style collision extractor does not exist,” is to show that after removing maximal common left and right factors from an equality
```lean
u * x * v = u' * y * v'
```
with `x,y ∈ ball R`, the core equality forces `x = y` and the residual factors are trivial. If maximal common prefix/suffix operations already exist on words, formalize:

```lean
theorem bounded_collision_normal_form_rigid
    {R : ℕ} {ux uy vx vy x y : Word ABC}
    (hx : x.length ≤ R) (hy : y.length ≤ R)
    (hredL : noCommonSuffix ux uy)
    (hredR : noCommonPrefix vx vy)
    (heq : ux ++ x ++ vx = uy ++ y ++ vy)
    (htrace :
      rightTraceWord R x = rightTraceWord R y ∧
      leftTraceWord R x = leftTraceWord R y) :
    x = y ∧ ux = uy ∧ vx = vy
```

If maximal-common-factor infrastructure is unavailable, prove the weaker but still meaningful theorem:

```lean
theorem no_bounded_conjugacy_style_collision
    {R : ℕ} {x y : S}
    (hx : len x ≤ R) (hy : len y ≤ R)
    (htrace :
      rightTrace R x = rightTrace R y ∧
      leftTrace R x = leftTrace R y) :
    ¬ ∃ u v u' v', u * x * v = u' * y * v' ∧ x ≠ y
```

or equivalently conclude `x = y` from such a collision hypothesis plus the trace match.

### Why this matters

This theorem upgrades the current Berggren/SPB theory from cancellation and finite-prefix uniqueness to a true local two-sided rigidity principle. It shows that within any bounded word-metric ball, semigroup elements are completely determined by their left and right ideal behavior. That is stronger than the existing two-sided Ore obstruction: not only do common multiples fail to create a satisfactory localization theory, but even bounded attempts to disguise one element as another through left/right padding are impossible once one records the finite-ball ideal traces.

For the research program, this is the right bridge between semigroup geometry and cryptographic hardness. The SL₂(ℤ) embedding is no longer just injective; it is locally collision-rigid under the exact pattern of two-sided multiplications that adversaries would use to search for non-commutative collisions. Proving this in Lean would give a sharp formal theorem saying that bounded-length “conjugacy-style” extraction attacks collapse to the trivial decomposition. That is a much more operationally meaningful security statement than plain injectivity or one-sided cancellation.
