## YOUR ASSIGNMENT: Functorial Kantorovich–Rubinstein duality for idempotent kernel mean embeddings via maxitive Wasserstein geometry

### Core objects to define precisely

Work on a compact metric space `X` with values in `ℝ`. The intended maxitive measures should be represented by upper-semicontinuous possibility densities when needed, because this gives a concrete Lean handle and avoids premature abstraction barriers. The transport cost should be defined by a max-plus analogue of optimal transport:

- primal side: infimum over maxitive couplings of the worst-case transport cost,
- dual side: supremum of the discrepancy tested against 1-Lipschitz tropical observables.

A robust formalization path is to first define everything for finitely supported possibility profiles on a finite or compact space, prove duality there, and then pass to compact spaces by approximation/regularity.

Use the following concrete Lean-facing structures as targets, even if you need to adjust names to match existing files.

```lean
/-- 1-Lipschitz real-valued functions on `X`. -/
def LipOne (X : Type*) [PseudoMetricSpace X] :=
  {f : X → ℝ // LipschitzWith 1 f}

/-- Maxitive probability profile normalized by `sSup = 0`. 
Think `μ x` as log-density / possibility weight. -/
structure MaxitiveProb (X : Type*) where
  toFun : X → ℝ
  usc : True
  nonpos : ∀ x, toFun x ≤ 0
  normalized : sSup (Set.range toFun) = 0

/-- Coupling of maxitive profiles on `X × Y` with prescribed marginals. -/
structure MaxitiveCoupling
    (μ : MaxitiveProb X) (ν : MaxitiveProb Y)
    [PseudoMetricSpace X] [PseudoMetricSpace Y] where
  toFun : X → Y → ℝ
  nonpos : ∀ x y, toFun x y ≤ 0
  fst_marginal : ∀ x, sSup (Set.range fun y => toFun x y) = μ.toFun x
  snd_marginal : ∀ y, sSup (Set.range fun x => toFun x y) = ν.toFun y

/-- Idempotent Wasserstein-1 cost: inf over couplings of the worst supported cost. -/
def iWasserstein
    (μ ν : MaxitiveProb X) [PseudoMetricSpace X] : ℝ :=
  sInf {r : ℝ | ∃ π : MaxitiveCoupling μ ν, ∀ x y, π.toFun x y > -∞ → dist x y ≤ r}

/-- Dual discrepancy against 1-Lipschitz tests. -/
def iKRDual
    (μ ν : MaxitiveProb X) [PseudoMetricSpace X] : ℝ :=
  sSup {r : ℝ | ∃ f : LipOne X,
    r = (sSup (Set.range fun x => μ.toFun x + f.1 x)) -
        (sSup (Set.range fun x => ν.toFun x + f.1 x)) }
```

If the existing infrastructure already has maxitive integrals/functionals `Λμ`, prefer the cleaner dual formulation

```lean
def iKRDual' (μ ν : MaxitiveProb X) [PseudoMetricSpace X] : ℝ :=
  sSup {r : ℝ | ∃ f : LipOne X, r = Λμ f.1 - Λν f.1}
```

where `Λμ f = sSup (Set.range fun x => μ.toFun x + f x)`.

The best theorem statement is then:

```lean
theorem iWasserstein_eq_iKRDual
    (X : Type*) [CompactSpace X] [PseudoMetricSpace X]
    (μ ν : MaxitiveProb X) :
    iWasserstein μ ν = iKRDual μ ν
```

This is the breakthrough theorem. It creates the metric geometry of maxitive measures, not merely their reconstruction theory.

### Second breakthrough theorem: functorial nonexpansiveness under Lipschitz pushforward

Define pushforward of maxitive profiles along a map `T : X → Y`. In the density model this should be

```lean
def MaxitiveProb.map (T : X → Y) (μ : MaxitiveProb X) : MaxitiveProb Y := ...
```

with
```lean
(map T μ).toFun y = sSup (Set.range fun x => if T x = y then μ.toFun x else -∞)
```

or the existing support-functional pushforward if already present.

Then prove the metric functoriality:

```lean
theorem iWasserstein_map_le
    (X Y : Type*) [PseudoMetricSpace X] [PseudoMetricSpace Y]

    (μ ν : MaxitiveProb X) :
    iWasserstein (μ.map T) (ν.map T) ≤ iWasserstein μ ν
```

This is the correct categorical statement: the assignment `X ↦ MaxitiveProb X` becomes a 1-Lipschitz functor from compact metric spaces to metric spaces of maxitive measures.

### Third breakthrough theorem: kernel mean embedding is nonexpansive, then isometric under a kernel representation hypothesis

Assume you already have a tropical kernel mean embedding
`KME : MaxitiveProb X → H`
or some existing object like `tkme`, and a bound of the shape `kmeDistBound`.

The minimal theorem to prove is:

```lean
theorem kme_nonexpansive_of_lip_kernel
```

But the real target should connect kernel witnesses to KR duality. Introduce a representation hypothesis saying every 1-Lipschitz test is realized, or uniformly approximated, by kernel witness functions:

```lean
def KernelRepresentsLipOne
```

Then prove an isometric or bi-Lipschitz statement:

If exact isometry is too strong, prove the bi-Lipschitz form with explicit constants:

```lean
theorem kme_biLipschitz_of_characteristic_and_lip_representing
```

### Recommended proof architecture

#### Strategy A: finite-space linearization in the max-plus semiring, then compact approximation
This is the most promising route.

1. **Finite support primal formulation**  
   Replace compact `X` by finite `X`. Then couplings are matrices `π : X → X → ℝ` with row/column max constraints.
   Prove that
   ```lean
   iWasserstein μ ν = sInf {r | ∃ π, marginals ∧ ∀ x y, π x y > -∞ → dist x y ≤ r}
   ```
   reduces to a combinatorial feasibility threshold.

2. **Dual feasibility via residuation / c-transform**  
   Define for `f : X → ℝ`
   ```lean
   def cTransform (f : X → ℝ) : X → ℝ := fun y => sInf (Set.range fun x => dist x y - f x)
   ```
   or the max-plus-appropriate residuated version already present in the transport literature.
   Show that `f(x) - f(y) ≤ dist x y` iff `f ≤ cTransform f` or equivalent. This converts 1-Lipschitzness into the correct dual constraint.

3. **Weak duality**  
   For any coupling `π` and any `f : LipOne X`, prove
   ```lean
   (Λμ f) - (Λν f) ≤ transport_cost π
   ```
   by combining:
   - row/column marginal identities,
   - `f x - f y ≤ dist x y`,
   - `sup` monotonicity.

4. **Strong duality on finite spaces**  
   Show that if `r < iWasserstein μ ν`, then there exists a violating 1-Lipschitz witness `f` with
   ```lean
   r < Λμ f - Λν f
   ```
   This is the true core. A minimax/separation argument over the finite max-plus polytope is plausible. If necessary, prove a Hall-type threshold theorem: coupling exists below radius `r` iff every tropical potential satisfies `Λμ f - Λν f ≤ r`.

5. **Compact approximation**  
   Approximate compact maxitive measures by finitely supported profiles using the regularity/support reconstruction infrastructure already built. Then pass:
   - primal costs by monotone approximation or upper/lower semicontinuity,
   - dual values by dense approximation of continuous Lipschitz functions.
   Compactness is what should give attainment or near-attainment of suprema.

#### Strategy B: direct duality through support functionals
If the existing library already packages maxitive measures as functionals `Λ : C(X,ℝ) → ℝ` preserving sup and constants, this route may be shorter.

1. Define
   ```lean
   iKRDual' μ ν = sSup {r | ∃ f : LipOne X, r = Λμ f - Λν f}
   ```
2. Define primal transport in terms of closed relations/cost kernels and pushforward inequalities.
3. Prove weak duality using only the axioms of `Λ`.
4. Recover strong duality by a Hahn–Banach analogue in the idempotent world: a separating Lipschitz potential for the epigraph of feasible couplings.
5. Then derive the density/profile version as a corollary.

This is conceptually cleaner and more functorial, but only if the functional infrastructure is already mature.

#### Strategy C: support-set formulation and Hausdorff collapse
If the current maxitive probability profiles are essentially normalized indicators of supports, then `iWasserstein` may collapse to a Hausdorff-type distance on supports. In that case prove first:

```lean
theorem iWasserstein_support_eq_hausdorff
    (μ ν : MaxitiveProb X) :
    iWasserstein μ ν = hausdorffDist (support μ) (support ν)
```

and then use the known dual formula for Hausdorff distance:
```lean
d_H(A,B) = sup_{f 1-Lipschitz} |sup_A f - sup_B f|
```

This would be a spectacular simplification and likely matches the idempotent philosophy. If true in your model, it is probably the most elegant theorem in the whole program.

### Exact significance to the research program

This theorem changes the role of idempotent measures from static objects of reconstruction to points in a genuine metric geometry. That is the conceptual leap.

- The existing kernel mean embedding theory says maxitive measures can be encoded.
- The support duality theory says they can be reconstructed from functionals.
- This theorem says they can be compared geometrically, transported functorially, and optimized algorithmically.

That opens three major directions immediately:

1. **Idempotent optimal transport as a computational primitive**  
   Once `iWasserstein` satisfies KR duality, witness functions become certificates of discrepancy. This gives a practical algorithmic shadow: search over tropical witnesses instead of couplings.

2. **Metric functoriality and categorical semantics**  
   The map theorem turns `μ ↦ μ.map T` into a contraction on spaces of maxitive measures. This is exactly the structure needed for a category of compact metric spaces enriched by idempotent transport.

3. **Kernel geometry of maxitive data**  
   The KME theorem upgrades kernel embeddings from injective summaries to metric embeddings. This is the bridge from tropical probability to learning theory, robust comparison, and witness extraction.

In short: proving idempotent KR duality would do for maxitive measure theory what classical Wasserstein-1 duality did for probability, but in a tropical/order-theoretic universe. It is a field-defining theorem, not an incremental extension.
