## Research Task: GL3 tropical Satake certified robustness for hierarchical top-m decision trees of Hecke score classifiers

**Research Mode: PROVE**

Develop a compositional robustness theorem for hierarchical classifiers built from binary decision trees whose internal-node decisions are induced by tropicalized GL3 Hecke score aggregates. The goal is to move beyond the already-studied flat decoders by proving that local tropical margin certificates along a root-to-leaf path compose into a global robustness guarantee.

### Precise theorem package to formalize

Work with a finite rooted binary tree encoded concretely enough for Lean. A good minimal model is to index internal nodes and leaves by finite types, together with explicit child maps and a designated prediction path for the clean input. You do **not** need to formalize graph theory in full generality if a path-based formulation captures the theorem cleanly.

A practical path-centric formulation is:

- fix a finite sequence `path : List ι` of internal nodes visited by the clean input,
- for each node `v : ι`, define real-valued score aggregates `SL v : α → ℝ` and `SR v : α → ℝ`,
- define the chosen branch at `v` by a Boolean `goRight v`,
- define the local chosen-vs-other margin by
  ```lean
  def localMargin (goRight : ι → Bool) (SL SR : ι → α → ℝ) (v : ι) (x : α) : ℝ :=
    if goRight v then SR v x - SL v x else SL v x - SR v x
  ```
- assume each score difference is locally controlled by a nodewise Lipschitz constant `K v`.

Use a metric space as the perturbation domain:
```lean
variable {α ι : Type*} [MetricSpace α]
```

A clean core theorem should have essentially the following shape:

```lean
theorem hierarchical_robust_of_path_margins
    {path : List ι}
    (SL SR : ι → α → ℝ)
    (goRight : ι → Bool)
    (K : ι → ℝ)
    (x : α) (r : ℝ)
    (hK : ∀ v ∈ path, 0 ≤ K v)
    (hLip :
      ∀ v ∈ path, ∀ y z : α,
        |((SR v y - SL v y) - (SR v z - SL v z))| ≤ K v * dist y z)
    (hmargin :
      ∀ v ∈ path, 2 * K v * r < localMargin goRight SL SR v x) :
    ∀ y : α, dist y x ≤ r →
      ∀ v ∈ path,
        0 < localMargin goRight SL SR v y
```

This theorem is the key sign-preservation lemma: every local binary decision on the clean path remains unchanged throughout the radius-`r` ball.

Then derive the classifier invariance statement. If the hierarchical classifier is represented by a function
```lean
F : α → γ
```
together with a specification that `F y` is determined by the sequence of branch signs along `path`, prove:

```lean
theorem hierarchical_classifier_constant_on_ball
    {path : List ι}
    (SL SR : ι → α → ℝ)
    (goRight : ι → Bool)
    (K : ι → ℝ)
    (F : α → γ)
    (label : γ)
    (x : α) (r : ℝ)
    (hK : ∀ v ∈ path, 0 ≤ K v)
    (hLip :
      ∀ v ∈ path, ∀ y z : α,
        |((SR v y - SL v y) - (SR v z - SL v z))| ≤ K v * dist y z)
    (hmargin :
      ∀ v ∈ path, 2 * K v * r < localMargin goRight SL SR v x)
    (hclean : F x = label)
    (hspec :
      ∀ y : α,
        (∀ v ∈ path, 0 < localMargin goRight SL SR v y) → F y = label) :
    ∀ y : α, dist y x ≤ r → F y = label
```

This isolates the analytic part from the tree semantics: once all local comparisons preserve their signs, the predicted leaf is fixed.

A more explicit certificate theorem should then state:

```lean
def pathCertificate
    (path : List ι) (SL SR : ι → α → ℝ) (goRight : ι → Bool) (K : ι → ℝ) (x : α) : ℝ :=
  (path.map (fun v => localMargin goRight SL SR v x / (2 * K v))).foldr min 0
```

That literal definition is awkward because of division by zero and the `foldr min 0` artifact. A better Lean-friendly version is to work over a `Finset` and assume positive `K` on the path:

```lean
theorem robustness_of_radius_lt_path_certificate
    {s : Finset ι}
    (hsne : s.Nonempty)
    (SL SR : ι → α → ℝ)
    (goRight : ι → Bool)
    (K : ι → ℝ)
    (F : α → γ)
    (label : γ)
    (x r : ℝ)
    (hx : α)
    (hKpos : ∀ v ∈ s, 0 < K v)
    (hLip :
      ∀ v ∈ s, ∀ y z : α,
        |((SR v y - SL v y) - (SR v z - SL v z))| ≤ K v * dist y z)
    (hclean : F hx = label)
    (hspec :
      ∀ y : α,
        (∀ v ∈ s, 0 < localMargin goRight SL SR v y) → F y = label)
    (hr :
      r < s.inf' hsne (fun v => localMargin goRight SL SR v hx / (2 * K v))) :
    ∀ y : α, dist y hx ≤ r → F y = label
```

You may want to prove first the elementary inequality extracted from `Finset.inf'`:

```lean
have hbound :
  ∀ v ∈ s, r < localMargin goRight SL SR v hx / (2 * K v) := ...
```

and then convert it to
```lean
2 * K v * r < localMargin goRight SL SR v hx
```
using `0 < K v`.

### Stronger additive-budget variant

A genuinely new extension is to allow each node to consume its own perturbation budget and prove robustness under a summed pathwise budget. Formulate nodewise radii `rv : ι → ℝ` and assume
```lean
dist y x ≤ ∑ v in s, rv v
```
together with a per-node Lipschitz loss bound of the form
```lean
|Δv y - Δv x| ≤ K v * dist y x
```
or, more sharply, if your GL3 tropical Satake setup gives decomposed perturbation channels,
```lean
|Δv y - Δv x| ≤ ∑ u in s, A v u * ε u
```
for a nonnegative matrix `A`. The simplest useful theorem is:

```lean
theorem hierarchical_robust_of_summed_losses
    {s : Finset ι}
    (Δ : ι → α → ℝ)
    (K : ι → ℝ)
    (F : α → γ)
    (label : γ)
    (x : α)
    (loss : ι → ℝ)
    (hK : ∀ v ∈ s, 0 ≤ K v)
    (hloss_nonneg : ∀ v ∈ s, 0 ≤ loss v)
    (hLip :
      ∀ v ∈ s, ∀ y : α,
        |Δ v y - Δ v x| ≤ K v * (∑ u in s, loss u))
    (hmargin :
      ∀ v ∈ s, K v * (∑ u in s, loss u) < Δ v x)
    (hspec :
      ∀ y : α, (∀ v ∈ s, 0 < Δ v y) → F y = label)
    (hclean : F x = label) :
    ∀ y : α, F y = label
```

Even if this version is not tied directly to `dist`, it captures the intended “mixed local perturbation budgets” and is likely easier to instantiate later from residual/tropical skip decompositions.

### Suggested concrete proof strategy

1. **Reduce branch preservation to sign preservation of a real-valued margin function.**  
   For each node define
   ```lean
   Δ v z := localMargin goRight SL SR v z
   ```
   and prove from the hypothesis on `SR v - SL v` that
   ```lean
   |Δ v y - Δ v x| ≤ K v * dist y x.
   ```
   The only work is the `if goRight v` case split; in the left-branch case the margin is `SL - SR`, so
   ```lean
   Δ v y - Δ v x = -(((SR v y - SL v y) - (SR v x - SL v x))).
   ```
   Then use `abs_neg`.

2. **Derive a lower bound on perturbed margins.**  
   From
   ```lean
   |Δ v y - Δ v x| ≤ K v * dist y x
   ```
   and `dist y x ≤ r`, obtain
   ```lean
   Δ v y ≥ Δ v x - K v * r.
   ```
   In Lean, this is usually easiest via
   ```lean
   have habs : |Δ v y - Δ v x| ≤ K v * r := ...
   have hneg : -(K v * r) ≤ Δ v y - Δ v x := by
     exact (neg_le.mp ((abs_le.mp habs).1))
   linarith
   ```
   or by using `abs_sub_le_iff`-style lemmas if convenient.

3. **Use the strict margin hypothesis to preserve positivity.**  
   If your local decision is based on comparing two separately `L`-Lipschitz score aggregates, then the margin difference is bounded by `2L * dist`; this explains the factor `2`. If instead the theorem assumes directly that the score difference has Lipschitz constant `K v`, then the hypothesis can be weakened to `K v * r < Δ v x`. Be explicit about which convention you adopt.  
   In the current framing, keep the `2 * K v * r < ...` hypothesis if `K v` is the Lipschitz constant for each aggregate separately, and derive
   ```lean
   Δ v y > 0
   ```
   by
   ```lean
   Δ v y ≥ Δ v x - 2 * K v * r > 0.
   ```

4. **Lift local sign preservation to tree-level invariance.**  
   Avoid formalizing a complicated recursive tree evaluator unless necessary. Instead, define the classifier specification axiomatically:
   if all margins along the clean path remain positive, then the output equals the clean leaf label. This is enough for the main compositional theorem and cleanly separates analytic robustness from combinatorial tree semantics.

5. **Extract the explicit radius certificate via `Finset.inf'`.**  
   For the certificate theorem, let
   ```lean
   c := s.inf' hsne (fun v => localMargin goRight SL SR v x / (2 * K v))
   ```
   and assume `r < c`. Then for every `v ∈ s`,
   ```lean
   c ≤ localMargin ... v x / (2 * K v)
   ```
   by `Finset.inf'_le`. Combine with `r < c` to get the desired nodewise strict inequality. This is the cleanest Lean route to the “minimum normalized internal-node margin” statement.

### Lean-specific implementation advice

- Use a path as a `Finset ι` for the certificate theorem and a `List ι` if you also want order-sensitive semantics. You can prove the analytic sign-preservation theorem over a `Finset`; order is irrelevant there.
- If positivity of `K v` is needed for division, assume
  ```lean
  hKpos : ∀ v ∈ s, 0 < K v
  ```
  not merely nonnegativity.
- If your existing GL3 tropical Satake library gives Lipschitz control for each aggregate separately:
  ```lean
  |SL v y - SL v z| ≤ K v * dist y z
  |SR v y - SR v z| ≤ K v * dist y z
  ```
  then first prove the margin-difference estimate
  ```lean
  |(SR v y - SL v y) - (SR v z - SL v z)| ≤ 2 * K v * dist y z
  ```
  using
  ```lean
  calc
    |(SR v y - SR v z) - (SL v y - SL v z)|
        ≤ |SR v y - SR v z| + |SL v y - SL v z| := by simpa [sub_eq_add_neg, add_comm, add_left_comm, add_assoc] using abs_sub_le (SR v y - SR v z) (SL v y - SL v z)
    _ ≤ K v * dist y z + K v * dist y z := by gcongr
    _ = 2 * K v * dist y z := by ring
  ```
  This lemma is likely the right bridge from the tropical Satake score machinery to the hierarchical theorem.

### Why this matters

This theorem is the correct compositional next step in the GL3 tropical Satake robustness program. Flat decoders such as argmax, top-`k`, ECOC, and one-vs-one can all be seen as shallow decision structures; hierarchical trees introduce genuinely new mathematics because robustness is no longer a one-shot multiclass margin statement but a pathwise composition of local tropical margin certificates. A successful formalization yields:

- a reusable certified-robustness theorem for any hierarchical Hecke-score decoder;
- a canonical path certificate
  ```lean
  r*(x) = min_v Δv(x) / (2 Kv)
  ```
  matching the geometry of local tropical comparisons;
- a foundation for stronger results with residual/skip decompositions and heterogeneous perturbation budgets;
- a bridge from tropical Satake representation-theoretic score constructions to structured, certifiably robust multiclass decision systems.

The key nontrivial content is the composition principle: local GL3 tropical margin control at each internal node suffices to freeze the entire leaf prediction. This is exactly the kind of theorem needed to scale the current flat robustness results to realistic structured decoders.
