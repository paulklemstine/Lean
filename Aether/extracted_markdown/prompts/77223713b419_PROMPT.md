#### 1. Left overlap rigidity inside the free Berggren semigroup
```lean
theorem berggren_left_multiple_rigidity
    {u v x y : List BerggrenGen}
    (hu : Reduced u) (hv : Reduced v)
    (hx : Reduced x) (hy : Reduced y)
    (hxy : evalWord x * evalWord u = evalWord y * evalWord v) :
    ∃ w : List BerggrenGen,
```

#### 3. Finite-ball Green-order incomparability for non-overlapping words
Define the ball by word length:
```lean
def BerggrenBall (R : ℕ) : Finset (List BerggrenGen) :=
  -- reduced words of length ≤ R, assuming decidable Reduced
```
Then prove a finite-ball incomparability theorem. A good precise formulation is:
```lean
theorem berggren_green_incomparable_of_no_overlap
    {R : ℕ} {u v : List BerggrenGen}
    (hu : Reduced u) (hv : Reduced v)
    (hRu : u.length ≤ R) (hRv : v.length ≤ R)
    (hne : u ≠ v)
    (hnot_left : ¬ ∃ w : List BerggrenGen, Reduced w ∧ (u = w ++ v ∨ v = w ++ u))
    (hnot_right : ¬ ∃ w : List BerggrenGen, Reduced w ∧ (u = v ++ w ∨ v = u ++ w)) :
    (¬ ∃ a b : List BerggrenGen, Reduced a ∧ Reduced b ∧
        evalWord a * evalWord u = evalWord b * evalWord v) ∧
    (¬ ∃ a b : List BerggrenGen, Reduced a ∧ Reduced b ∧
        evalWord u * evalWord a = evalWord v * evalWord b)
```
This is the exact “no common left multiple / no common right multiple” conclusion under exclusion of prefix/suffix overlap.

#### 4. Finite-ball extraction of an lcm-free pair
You should then extract an explicit pair from every nontrivial ball. A natural theorem is:
```lean
theorem exists_lcm_free_pair_in_ball
    {R : ℕ} (hR : 1 ≤ R) :
    ∃ u v : List BerggrenGen,
      Reduced u ∧ Reduced v ∧
      u.length ≤ R ∧ v.length ≤ R ∧
      u ≠ v ∧
      (¬ ∃ a b : List BerggrenGen, Reduced a ∧ Reduced b ∧
          evalWord a * evalWord u = evalWord b * evalWord v) ∧
      (¬ ∃ a b : List BerggrenGen, Reduced a ∧ Reduced b ∧
          evalWord u * evalWord a = evalWord v * evalWord b)
```
A very likely explicit witness is two distinct generators, provided the catalog already contains enough to show neither is a left/right extension of the other:
```lean
u = [g₁], v = [g₂], g₁ ≠ g₂
```
If there are exactly three Berggren generators, any two distinct singleton words should work.

### Recommended proof strategy

1. **Reduce matrix equalities to word equalities via normal-form injectivity.**  
   The key move is to rewrite
   `evalWord x * evalWord u = evalWord y * evalWord v`
   as
   `evalWord (x ++ u) = evalWord (y ++ v)`
   using the existing evaluation-on-concatenation lemma. Then invoke the already proved freeness / reduced normal-form uniqueness theorem to deduce
   `x ++ u = y ++ v`.
   At that point, the problem becomes a pure list overlap statement.

2. **Prove a list overlap lemma for concatenation equality.**  
   You will likely need a standalone combinatorial lemma of the form:
   ```lean
   theorem list_eq_append_overlap
       {α : Type _} [DecidableEq α]
       (x y u v : List α)
       (h : x ++ u = y ++ v) :
       ∃ w : List α,
         ((x = y ++ w ∧ v = w ++ u) ∨
          (y = x ++ w ∧ u = w ++ v))
   ```
   This is the free-semigroup heart of the argument. Prove it by induction on `x` and `y`, or by comparing lengths and peeling common prefixes. Once this is available, instantiate it with `α := BerggrenGen`.

3. **Convert overlap data into divisibility comparability.**  
   From the overlap lemma, deduce that any common left multiple forces one of `u,v` to be a suffix-extension of the other; similarly any common right multiple forces one to be a prefix-extension of the other. This is exactly the Green-preorder obstruction. The finite-ball hypotheses are not needed for the rigidity implication itself, but they matter for the “finite-ball incomparability” packaging and for extraction.

4. **Use short explicit witnesses for the extraction theorem.**  
   For `R ≥ 1`, choose two distinct generators `g₁ ≠ g₂`. Show:
   - `[g₁]` and `[g₂]` are reduced,
   - they lie in the radius-`R` ball,
   - neither is of the form `w ++ [g₂]` or `[g₂] ++ w` unless `w = []`, which would force `g₁ = g₂`,
   - hence by the incomparability theorem they have no common left or right multiple.
   This gives a very clean finite-ball lcm-free pair.

5. **If needed, use matrix-entry monotonicity only as a secondary separation tool.**  
   The primary proof should come from normal-form uniqueness plus list overlap. Entry-growth invariants are useful if the current API for reduced words is awkward, or if there is an existing theorem saying distinct reduced words of bounded length evaluate to distinct positive matrices with strictly increasing entries. But this should be support, not the main engine.

### Why this matters

This pushes the Berggren/SPB program beyond freeness and cancellation into a genuinely geometric statement about Green preorders in the positive `SL₂(ℤ)` semigroup. Freeness says words do not collide; the new theorem says much more: bounded-depth words also do not admit hidden two-sided mergers unless there is an actual overlap in normal form. That is the right algebraic strengthening for cryptographic non-compressibility. It formally rules out a whole class of “merge attacks” where two distinct transcripts are forced into a common left or right multiple. In semigroup language, you are showing finite-ball anti-lattice behavior: many pairs have neither a left-lcm nor a right-lcm even locally. This is stronger and more structural than plain bounded-collision statements, and it fits perfectly with the existing residual-finiteness / rigidity arc.
