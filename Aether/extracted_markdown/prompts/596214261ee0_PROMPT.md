## Precise theorem targets

### Theorem 1: Authorized family is an access structure and minimal authorized sets are threshold-crossing closure bases

This is the first anchor theorem and should be proved completely.

**Mathematical statement.**  
Let `α` be finite, `cl` a closure operator on `Set α`, `cap : Set α → K` monotone and closure-invariant, and `t : K`. Then:
1. `Auth(cl, cap, t) := {A | t ≤ cap (cl A)}` is upward closed.
2. If `A` is minimal authorized, then `A` is a basis of its closure `cl A`.
3. Conversely, if `B` is a basis of a closed set `C`, `t ≤ cap C`, and every proper closed subobject generated by a proper subset of `B` has capacity `< t`, then `B` is minimal authorized.

This is the conceptual theorem that turns closure semantics into access structures.

### Theorem 2: Finite closure-capacity systems induce canonical access structures, and representable finite access structures admit closure realizations

This is the representation theorem. Phrase it first as an equivalence between a realizable class of finite access structures and closure-capacity data.

**Mathematical statement.**  
For every finite closure-capacity system `(X, cl, cap, t)` with monotone closure-invariant capacity, the family `Auth(cl, cap, t)` is a finite access structure. Conversely, for every finite access structure `𝒜` in a realizable subclass (for example, one presented by finitely many minimal authorized sets), there exists a closure operator `cl_𝒜`, a closure-invariant monotone capacity `cap_𝒜`, and threshold `t_𝒜` such that
\[
A \in \mathcal{A} \iff t_{\mathcal A} \le cap_{\mathcal A}(cl_{\mathcal A}(A)).
\]

A very plausible canonical construction is:
- `cl_𝒜(A) := ⋂ {B closed-like / authorized-saturated | A ⊆ B}`
or, more concretely in finite settings,
- define `cl_𝒜(A)` by adjoining all participants forced by the minimal authorized hypergraph containing `A`,
- define `cap_𝒜(A)` as a min-plus or boolean threshold from the family of minimal authorized sets.

The boolean-valued first version may be the easiest:
```lean
cap𝒜 A := if ∃ M ∈ MinAuth, M ⊆ cl A then 1 else 0
```
with threshold `t = 1`. Then authorized sets are exactly upward closure of minimal authorized sets.

This is the genuinely new cryptographic synthesis theorem. Do not overpromise a full linear secret-sharing scheme unless Mathlib support is already enough. Instead, prove a **certified reconstruction of a dealer/share incidence object** from finite semimodule presentation data, and phrase linearization as a future direction unless the infrastructure is present.

**Mathematical statement.**  
Given a finite closure-capacity system satisfying:
- finite generation by principal closures,
- separability of distinct minimal authorized closures by capacity profile,
- realizability of the induced access structure,

there exists a canonical finite reconstruction object `R` consisting of:
- a dealer set,

This is the theorem that makes the duality computational.

## Proof architecture: 3 viable strategies

### Strategy A: Direct finite order-theoretic route via closure lattices and threshold ideals
**Most promising for Lean.**

1. Formalize the lattice of closed sets induced by `cl`, and push `cap` down to a well-defined function on closed sets using closure invariance.
2. Define authorized coalitions through thresholding closed sets. Upward closure follows from monotonicity of `cl` and `cap`.
3. Characterize minimal authorized sets by anti-redundancy: if a proper subset has the same closure, minimality fails. This yields the closure-basis theorem.
4. For realizability, construct `cl_𝒜` from the Moore family generated by authorized saturation and define a boolean or natural-valued capacity whose threshold recovers `𝒜`.
5. Extract reconstruction data from the finite set of minimal authorized closures.

Why this is best: it minimizes algebraic overhead and leverages finite-set combinatorics already friendly to Mathlib.

---

### Strategy B: Semimodule-first route via idempotent linearization
**Most conceptually powerful, but heavier.**

1. Define an idempotent semimodule presentation with generators indexed by principal closures and coefficients in an idempotent semiring.
2. Interpret `cap` as a valuation/weight functional on the free idempotent semimodule modulo closure relations.
3. Show minimal authorized coalitions correspond to extremal generators crossing threshold, analogous to tropical basis elements.
4. Reconstruction becomes extracting a minimal generating family with certified threshold behavior.

Why it matters: this turns secret-sharing into tropical/idempotent linear algebra. If successful, it opens the door to tropical information inequalities and algebraic synthesis of access structures.

Risk: substantial library overhead unless existing semiring/semimodule abstractions already align.

---

### Strategy C: Duality-first route via finite spectra and reconstruction invariants
**Best if PadicClosureInformationDuality infrastructure is strong.**

1. Use existing closure-spectrum / information-duality patterns to classify prime or filter-like closed sets associated with threshold cuts of `cap`.
2. Build a reconstruction invariant from the spectrum of threshold-relevant closed sets.
3. Prove that finite separated spectra reconstruct the access structure and then reconstruct the canonical incidence object.
4. Deduce faithfulness/full faithfulness from uniqueness of spectral reconstruction.

Why this is exciting: it reframes cryptographic authorization as a finite duality phenomenon, echoing Stone/Priestley-style reconstruction but in closure-information form.

Risk: category/duality setup may be elegant but longer to formalize.
