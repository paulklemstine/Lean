### PROOF STRATEGY

#### Strategy A: Pointwise thermodynamic soundness + order-theoretic supremum extraction
This is the most promising route if the catalog already contains a theorem relating derivability to evaluation/prime inequalities and another theorem identifying `freeEnergyGap` as an aggregated separator.

1. Prove the pointwise implication
   ```lean
   derivable x y → ∀ β > 0, freeEnergyGap μ β x y ≤ 0
   ```
   by transporting the syntactic inequality through every admissible evaluation and then through the partition/free-energy construction. This should be a monotonicity argument: if `x ⊢ y`, every semantic score for `x` is bounded by that for `y`, so the logarithmic/energy aggregate preserves the order.

2. Prove the converse by contraposition:
   ```lean
   ¬ derivable x y → ∃ β > 0, 0 < freeEnergyGap μ β x y
   ```
   using the existing Stone–Prime completeness theorem to obtain a prime or admissible evaluation witness separating `x` and `y`. Then use the min-energy prime witness extraction/compression theorem to show that this witness survives in the finite-temperature partition semantics with strictly positive gap.

3. Convert the pointwise characterization to the `sSup` characterization using:
   - `show (sSup A ≤ 0 ↔ ∀ z ∈ A, z ≤ 0)` for the specific set
   - or the easier pair of implications:
     - from pointwise nonpositivity to `sSup ≤ 0` via `csSup_le`
     - from `sSup ≤ 0` and membership of each gap in the set to pointwise nonpositivity via `le_csSup`

4. Package the theorem with an auxiliary set:
   ```lean
   def freeEnergyGapSet (μ : Measure (AdmissibleEval S)) (x y : S) : Set ℝ :=
     {g | ∃ β : ℝ, 0 < β ∧ g = freeEnergyGap μ β x y}
   ```
   This often makes the `sSup` proof much cleaner.

#### Strategy B: Zero-temperature first, then derive finite-temperature duality
This is strongest if the catalog already has a theorem identifying `primeSeparationGap` with derivability.

1. Prove the convergence theorem
   ```lean
   Tendsto (fun β => freeEnergyGap μ β x y) atTop (𝓝 (primeSeparationGap x y))
   ```
   using the Laplace principle / low-temperature concentration theorem already encoded in the thermodynamic Stone–Prime infrastructure.

2. Combine it with
   ```lean
   derivable x y ↔ primeSeparationGap x y ≤ 0
   ```
   from prime adequacy.

3. Show:
   - if `derivable x y`, then the limit is `≤ 0`, and use either monotonicity in `β` or an existing upper bound theorem to conclude every finite-temperature gap is `≤ 0`;
   - if `¬ derivable x y`, then the limit is strictly positive, so eventually the finite-temperature gap is positive, hence the `sSup` is positive.

4. This route is conceptually elegant because it interprets proof theory as a phase transition: derivability is exactly the absence of a positive low-temperature separation energy.

#### Strategy C: Sandwich theorem via prime witness lower bound and semantic soundness upper bound
Use this if exact convergence is hard but upper and lower bounds are available.

1. Prove an upper bound:
   ```lean
   derivable x y → freeEnergyGap μ β x y ≤ 0
   ```

2. Prove a lower asymptotic bound from any prime witness `p` separating `x` and `y`:
   ```lean
   witnessGap p x y ≤ liminf atTop (fun β => freeEnergyGap μ β x y)
   ```

3. Use compactness of the prime spectrum to pass from witness-wise lower bounds to the extremal prime separation gap:
   ```lean
   primeSeparationGap x y ≤ liminf ...
   ```

4. If you also have a general thermodynamic upper bound
   ```lean
   limsup ... ≤ primeSeparationGap x y
   ```
   then conclude by squeeze. This is the clean analytic route when exact partition identities are difficult to unfold in Lean.

### WHY THIS MATTERS

This theorem is not an incremental semantic equivalence. It creates a genuine thermodynamic semantics for proof systems in which:

- **Derivability becomes a free-energy law**: proof existence is characterized by the sign of a partition-theoretic gap, not merely by pointwise model checking.
- **Prime completeness acquires a statistical-mechanical limit**: the Stone/prime separator is reinterpreted as the zero-temperature phase of a finite-temperature ensemble over admissible evaluations.
- **Countermodels become compressible energetic witnesses**: non-derivability is not just “some model exists,” but “there is a positive separation energy surviving thermodynamic renormalization.”
- **Algorithmic consequences become available**: finite-temperature free energies suggest annealing-style proof search, spectral relaxation of entailment, and quantitative certificates of near-derivability.
- **Cross-domain synthesis becomes precise**: this is the bridge between logical semantics, tropical/min-plus asymptotics, rate-distortion duality, and large deviations. The `β → ∞` limit is exactly the tropicalization / min-energy collapse of the partition semantics.

If you can formalize this successfully, the research program gains a new organizing principle: proof theory can be studied through phase transitions, variational principles, and low-temperature asymptotics. That opens the door to entropy-sensitive proof complexity, tropical proof invariants, and constructive thermodynamic proof search.
