## Theorem 1: Finite Realization / Tropical Bellman Principle

### Mathematical statement
For every finite Berggren truncation with nonnegative edge weights and distinguished root/source `r`, there exists a canonical tropical potential `dist_r : V → WithTop ℕ` equal to the minimum path cost from `r` to each node, and this potential is the least fixed point (or least post-fixed Bellman solution) of the Berggren tropical transfer operator.

### Lean-style theorem target
A realistic formal signature is:

```lean
theorem exists_shortest_potential
  (V : Type) [Fintype V] [DecidableEq V]
  (root : V)
  (adj : V → V → Prop)
  (w : V → V → WithTop ℕ)
  (h_nonneg : ∀ u v, adj u v → ∃ n : ℕ, w u v = n)
  :
  ∃ φ : V → WithTop ℕ,
    φ root = 0 ∧
    (∀ v, φ v = if v = root then 0 else
      sInf {x | ∃ u, adj u v ∧ x = φ u + w u v}) ∧
    ∀ ψ : V → WithTop ℕ,
      ψ root = 0 →
      (∀ v, ψ v ≤ if v = root then 0 else
        sInf {x | ∃ u, adj u v ∧ x = ψ u + w u v}) →
      φ v ≤ ψ v
```

A more implementation-friendly version using explicit finite predecessor sets is also acceptable.

### Strengthened Berggren specialization
Specialize this to the finite Berggren node type:
```lean
theorem berggren_exists_shortest_potential
  (H : ℕ) :
  ∃ φ : BerggrenNode H → WithTop ℕ, ...
```

### Why this matters
This identifies arithmetic growth in the Berggren tree with a certified tropical harmonic structure. It is the foundational “optical metric” theorem: triple generation is now encoded as min-plus propagation.

## Theorem 2: Lensing Duality / Geodesic Funnel Correspondence

### Mathematical statement
For a suitable arithmetic target predicate `Compatible n v` on nodes—interpreted as “node `v` is congruence-compatible with the integer `n` via a chosen norm form” such as `x^2 + y^2`, `c`, or a derived form—define the terminal penalty
```lean
penalty_n : V → WithTop ℕ
```
to be `0` on compatible nodes and `∞` otherwise. Then the tropical value function obtained by backward propagation from `penalty_n` is exactly the minimum cost of a path from the root to a compatible node. Moreover, minimizers determine a **geodesic funnel**: the set of nodes lying on some optimal compatible path is closed under predecessor minimization and is canonically reconstructible from the potential.

This is the “lensing” theorem: arithmetic compatibility acts as a refractive target condition, and tropical fixed points focus paths into caustics.

### Lean-style theorem target
```lean
def Compatible (n : ℕ) (v : BerggrenNode H) : Prop := ...
def penalty (n : ℕ) : BerggrenNode H → WithTop ℕ :=
  fun v => if Compatible n v then 0 else ⊤

theorem lensing_duality
  (H n : ℕ) :
  ∃ Φ : BerggrenNode H → WithTop ℕ,
    (∀ v, Φ v =
      min (penalty n v)
        (sInf {x | ∃ u, BerggrenEdge H v u ∧ x = Φ u + edgeWeight v u})) ∧
    ∀ v, Φ v = shortestCompatibleCost H n v
```

If fixed-point equality is awkward, prove the equivalent Bellman optimality equation plus uniqueness/minimality.

### Required arithmetic content
You must define at least one nontrivial `Compatible` predicate that connects to factor/divisor information. Examples:
- `Compatible n (a,b,c)` iff `a^2 + b^2 = c^2` and `a^2 + b^2 ≡ 0 [MOD n]` is too weak since always true; do not use this.
- Better: choose a norm-form witness predicate such as
  - `Compatible n (a,b,c) := a ∣ n ∨ b ∣ n`,
  - or `Compatible n (a,b,c) := ∃ d, d ∣ n ∧ d = a ∨ d = b`,
  - or a congruence-filtered version: `a ∣ n ∧ a > 1`, etc.
- Better still: define a form extracted from the triple, e.g. `u := c - b`, `v := c + b`, noting `uv = a^2` in Euclid-style parameterizations under suitable hypotheses; then use divisibility of `u`, `v`, or gcd-structured factors as the arithmetic target.

The theorem need not factor every integer. It must prove a certified implication:
> if the compatibility obstruction vanishes and the tropical funnel is nonempty, then a shortest geodesic reconstructs a divisor certificate.

This is enough to establish the duality.

## Theorem 3: Certified Shortest-Path Reconstruction Gives Divisor Witnesses

### Mathematical statement
Assume a finite Berggren truncation, a target integer `n`, and a compatible node exists. Then from the tropical potential alone one can reconstruct an optimal path from the root to a compatible node. If the terminal node satisfies the arithmetic extraction predicate, the algorithm returns a divisor certificate `d` with `d ∣ n` and `1 < d < n` (or a weaker certified witness, depending on your chosen arithmetic target).

### Lean-style theorem target

  List (BerggrenNode H) := ...

def extractsDivisor (n : ℕ) (v : BerggrenNode H) : Prop := ∃ d, d ∣ n ∧ 1 < d ∧ d < n

theorem reconstruction_certified
  (H n : ℕ)
  (h_exists : ∃ v : BerggrenNode H, Compatible n v)

  ∃ p : List (BerggrenNode H), ∃ v,

## Proof Strategy Paths

### Strategy A: Finite dynamic programming on a DAG induced by height
**Most promising if your edge weight is strictly height-increasing.**

1. Prove Berggren generators strictly increase hypotenuse on non-root descendants, so the bounded-height graph is acyclic.
2. Define distance by recursion/topological order on increasing `c`.
3. Prove Bellman optimality by induction on height.
4. Reconstruct an optimal predecessor chain by choosing a predecessor attaining the finite infimum.
5. Prove arithmetic extraction from the terminal compatible node.

Why promising: finite DAGs make min-plus fixed points elementary and computationally robust in Lean. This is likely the fastest path to a complete theorem with minimal sorry.

### Strategy B: Order-theoretic least fixed point on finite semimodules
**Best if you want conceptual depth and future generalization.**

1. Show `lensOp` is monotone on the finite complete lattice `(V → WithTop ℕ)`.
2. Use finite iteration from `⊤` or from terminal penalties to obtain the least fixed point.
3. Prove that fixed points coincide with shortest-path value functions.
4. Derive path reconstruction from tight predecessor existence on every finite-valued nonterminal node.

Why promising: this turns the result into a reusable theorem about tropical transfer operators on finite arithmetic categories, not just Berggren trees.

### Strategy C: Matrix/min-plus linear algebra formulation
**Most visionary, but only pursue if the infrastructure is ready.**

1. Encode the weighted adjacency as a min-plus matrix `M`.
2. Show the value function is the Kleene star / tropical resolvent applied to the target penalty.
3. Interpret geodesic funnels as supports of tropical eigenvectors or residuated images.
4. Extract shortest witness paths via argmin support.

Why promising: this would connect directly to tropical spectral theory and make the “lensing” terminology mathematically literal. But it may be heavier in Lean unless the catalog already contains suitable semiring linear algebra.

**Recommendation:** complete Strategy A fully, structure definitions so Strategy B becomes a corollary or parallel theorem, and leave Strategy C as an explicit future direction unless the dynamic context already contains tropical matrix infrastructure.
