Produce a single self-contained Lean 4 file formalizing the elementary algebra of the `2 × 2` basic move for two-way contingency tables over `ℤ`. The file must compile with zero sorrys.

Scope:
1. Define `Table (m n : ℕ) := Matrix (Fin m) (Fin n) ℤ`.
2. Define:
   - `rowSum : Table m n → Fin m → ℤ`
   - `colSum : Table m n → Fin n → ℤ`
   - `totalSum : Table m n → ℤ`
   - `sameMargins : Table m n → Table m n → Prop`
3. Define `basicMove (i i' : Fin m) (j j' : Fin n) : Table m n` as the table with values
   `-1` at `(i,j)`, `+1` at `(i,j')`, `+1` at `(i',j)`, `-1` at `(i',j')`, and `0` elsewhere.
   You may define it by nested `if` expressions on index equality.
4. Define `legalBasicStep (T : Table m n) (i i' : Fin m) (j j' : Fin n) : Prop` to mean every entry of `T + basicMove i i' j j'` is nonnegative.

Required theorems:
A. `rowSum_basicMove`:
   assuming `i ≠ i'`, prove `rowSum (basicMove i i' j j') r = 0` for every row `r`.
B. `colSum_basicMove`:
   assuming `j ≠ j'`, prove `colSum (basicMove i i' j j') c = 0` for every column `c`.
C. `totalSum_basicMove_zero`:
   prove the total sum of `basicMove` is `0`. It is acceptable to deduce this from theorem A or B.
D. `basicMove_preserves_rowSum`:
   assuming `i ≠ i'`, prove `rowSum (T + basicMove i i' j j') r = rowSum T r`.
E. `basicMove_preserves_colSum`:
   assuming `j ≠ j'`, prove `colSum (T + basicMove i i' j j') c = colSum T c`.
F. `basicMove_preserves_margins`:
   assuming `i ≠ i'` and `j ≠ j'`, prove `sameMargins T (T + basicMove i i' j j')`.
G. `legalBasicStep_preserves_margins`:
   prove that if `legalBasicStep T i i' j j'` and `i ≠ i'` and `j ≠ j'`, then `sameMargins T (T + basicMove i i' j j')`.
   The proof should explicitly show legality is unused except as an extra hypothesis.
