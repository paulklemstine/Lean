## Precise Theorem Targets

### 1. Tropical Hecke semiring and spherical semimodules

Start with a finite type of generators `D` with a multiplication law encoding double-coset convolution at the combinatorial level. You do **not** need full Coxeter geometry initially; a finite presented convolution semiring with idempotent addition is enough. If possible, package Coxeter-style braid compatibility later as a refinement layer.

A practical Lean design is:

```lean
class TropicalHeckeData (D : Type _) where
  mul : D → D → Finset D
  wt  : D → ℤ
  one : D
  -- optional axioms: associativity up to induced convolution, unit laws, braid compatibility
```

Then define the tropical Hecke semiring as a finitely supported function semiring into an idempotent coefficient semiring `R` (initially `R = WithTop ℤ` or another existing tropical/idempotent semiring in Mathlib-compatible form), with convolution induced by `mul`.

A spherical semimodule should consist of:
- an `H`-semimodule `M`,
- a distinguished vector `η : M`,
- finiteness of the reachable subsemimodule generated by `η` under the finite generator set.

A useful Lean-facing structure:

```lean
structure SphericalTropRep (H M : Type _) [Semiring H] [AddCommMonoid M] [Module H M] where
  eta : M
  finite_reachable :
    (Set.Finite {m : M | ∃ h : H, h • eta = m})
```

If full `Module` over idempotent semirings becomes awkward, weaken to an action structure tailored to the finite generated fragment.

### 2. Tropical character and Hankel kernel

Define the spherical character on generators and then on words/elements by evaluation at the distinguished spherical vector followed by a chosen output functional. The cleanest finite setup is to include an output map to the coefficient semiring.

```lean
structure ObservableSphericalTropRep (H M R : Type _) [Semiring H] [Semiring R] where
  toRep : SphericalTropRep H M
  out   : M →+ R
```

Then define:

```lean
def tropCharacter
  (ρ : ObservableSphericalTropRep H M R) (h : H) : R :=
  ρ.out (h • ρ.toRep.eta)

def tropHankel
  (ρ : ObservableSphericalTropRep H M R) (x y : H) : R :=
  tropCharacter ρ (x * y)
```

If semiring-level multiplication on `H` is not yet available canonically, define `tropHankel` first on words in generators, then descend later.

### 3. Syntactic semimodule and recognition theorem

The decisive theorem is that finite spherical tropical Hecke actions are recognized by their Hankel kernel through a syntactic quotient semimodule. This is the tropical Hecke analogue of both Myhill–Nerode/Hankel minimality and Tannakian “recover the object from matrix coefficients.”

A target theorem statement:

```lean
theorem tropical_hecke_recognition_of_equal_hankel
  {H R M N : Type _}
  [Semiring H] [CanonicallyOrderedAddMonoid R] [Semiring R]
  [AddCommMonoid M] [Module H M]
  [AddCommMonoid N] [Module H N]
  (ρM : ObservableSphericalTropRep H M R)
  (ρN : ObservableSphericalTropRep H N R)
  (hfinM : Finite (SyntacticSemimodule ρM))
  (hfinN : Finite (SyntacticSemimodule ρN))
  (hEq : ∀ x y : H, tropHankel ρM x y = tropHankel ρN x y) :
  Nonempty (SyntacticSemimodule ρM ≃ₗ[H] SyntacticSemimodule ρN)
```

This is the cleanest mathematically: exact equality of Hankel kernels implies isomorphism of syntactic semimodules. If proving equivalence of the original representations is too strong at first, proving it for the syntactic minimal quotients is already a genuine breakthrough.

A stronger form, if reachable:

```lean
theorem spherical_rep_equiv_iff_equal_hankel
  ...
  (hminM : MinimalSpherical ρM)
  (hminN : MinimalSpherical ρN) :
  (Nonempty (M ≃ₗ[H] N)) ↔ (∀ x y : H, tropHankel ρM x y = tropHankel ρN x y)
```

This is the true tropical Satake-recognition slogan: **minimal spherical tropical Hecke representations are determined by spherical Hankel data**.

### 5. Canonical basis reconstruction theorem

This is where the project becomes genuinely visionary. In the tropical/idempotent world, “canonical basis elements” should be represented by extremal generators / join-irreducible / indecomposable reachable states of the syntactic semimodule.

Define an extremality notion suitable for your semimodule:




## 2–3 Proof Strategy Paths

### Strategy A: Syntactic-semimodule/Hankel quotient route
**Most promising.**

1. Define the residual states of a tropical Hankel kernel by left shifts:
   `x ↦ (y ↦ K (x*y))`.
2. Quotient by equality of residual rows to form the syntactic semimodule.
3. Show:
   - the reachable part is finite under finite-rank assumptions,
   - every realization factors through the syntactic semimodule,
   - the syntactic semimodule is minimal and unique up to isomorphism.

Why this is strongest: it directly leverages `finite_separation_semimodule_realization_minimal`, and it turns the whole project into a representation-theoretic upgrade of already certified Hankel minimality technology.

### Strategy B: Tropical Myhill–Nerode for Hecke actions
1. Define an observational equivalence on Hecke words/elements:
   `x ~ y` iff `∀z, K (x*z) = K (y*z)`.
2. Prove this is a right-congruence compatible with tropical Hecke convolution.
3. Build the state semimodule from equivalence classes / principal residuals and show it realizes the kernel minimally.

Why useful: conceptually clean and very close to automata theory. It may yield the easiest finite-state extraction theorem and algorithmic corollaries.

### Strategy C: Extremal-generator / tropical convexity route
1. Realize the syntactic semimodule as a finitely generated idempotent semimodule of residual rows.
2. Use tropical convexity/idempotent linear algebra to identify extremal rays or join-irreducibles.
3. Show these extremals form the canonical basis and are reconstructible from finite samples.

Why important: this is the route that turns minimal realization into “canonical basis reconstruction,” giving the representation-theoretic payload. It is probably secondary after A, but essential for the final statement.

**Recommendation:** Prove the recognition and minimal realization package by **Strategy A**, then derive basis reconstruction via **Strategy C**.
