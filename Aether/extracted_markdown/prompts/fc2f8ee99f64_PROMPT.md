## Core Formal Objects

Let `α` be a commutative idempotent semiring, finitely generated by a finite family `gens : ι → α` with `[Fintype ι]`.

Define a tropical target semiring `𝕋` as a min-plus semiring, ideally represented in Lean by a type with:
- additive structure = `inf` / `min`,
- multiplicative structure = additive combination,
- order-compatible idempotent addition,
- top/bottom conventions chosen consistently.

A **tropical spherical character** should be a normalized semiring morphism from `α` into `𝕋`:
- preserving idempotent addition as `min`,
- preserving multiplication as `+`,
- optionally preserving `0,1`,
- optionally normalized on generators or unit.

You should introduce a structure along the lines of:

```lean
structure TropicalCharacter (α 𝕋 : Type*) [CommSemiring α] [LinearOrder 𝕋]
    [MinPlusSemiring 𝕋] where
  toFun : α → 𝕋
  map_add' : ∀ a b, toFun (a + b) = min (toFun a) (toFun b)
  map_mul' : ∀ a b, toFun (a * b) = toFun a + toFun b
  map_zero' : toFun 0 = ⊤
  map_one' : toFun 1 = 0
```

If a dedicated `MinPlusSemiring` typeclass is too expensive, use a bespoke structure with just enough axioms. Do not let typeclass engineering swallow the mathematics.

Define:
- `SphTrop α` = normalized extremal tropical characters on `α`,
- `tropicalSphericalTransform (h : α) : SphTrop α → 𝕋 := fun χ => χ h`.

You will likely also need:
- a radical congruence `radicalCongr : Setoid α` or equivalent,
- a notion of prime congruence / spectral point,
- an extremality predicate on characters,
- a finite generation / normal form API.

## Precise Target Theorems

### Theorem 1: Tropical Separation by Spherical Characters

Mathematical statement:

Let `H` be a finitely generated commutative idempotent semiring. Assume a semisimplicity/separability hypothesis asserting that the canonical radical congruence equals the intersection of prime congruences detected by normalized tropical spherical characters. Then for any `h₁ h₂ : H`, if `h₁` and `h₂` are inequivalent modulo the radical congruence, there exists a tropical spherical character `χ` such that `χ h₁ ≠ χ h₂`.

This is the exact idempotent analogue of character separation in commutative harmonic analysis.

A Lean target signature could be:

```lean
theorem tropical_character_separation
    {H 𝕋 : Type*}
    [CommSemiring H] [IdempotentAdd H]
    [CanonicallyOrderedCommSemiring H]
    [LinearOrder 𝕋] [MinPlusSemiring 𝕋]
    (rad : Setoid H)
    (S : Set (TropicalCharacter H 𝕋))
    (hsep :
      ∀ {a b : H}, ¬ rad.Rel a b →
        ∃ χ ∈ S, χ.toFun a ≠ χ.toFun b) :
    ∀ {h₁ h₂ : H}, ¬ rad.Rel h₁ h₂ →
      ∃ χ ∈ S, χ.toFun h₁ ≠ χ.toFun h₂ := by
```

This theorem is formally modest if `hsep` is assumed, but the real task is to instantiate `hsep` from prime-congruence/extremal-character classification in your concrete framework.

A more ambitious theorem, if you can define the spectrum:

```lean
theorem separation_of_not_radical_equiv
    {H 𝕋 : Type*}
    [FiniteGeneratedIdemHeckeSemiring H]
    [TropicalCodomain 𝕋]
    [SemisimpleTropicalSpectrum H 𝕋]
    {h₁ h₂ : H} :
    ¬ radicalCongr H h₁ h₂ →
    ∃ χ : SphTrop H 𝕋, tropicalSphericalTransform h₁ χ ≠ tropicalSphericalTransform h₂ χ := by
```

### Theorem 3: Finite Polyhedral Inversion / Lower-Envelope Reconstruction

Mathematical statement:

Assume `H` is finitely generated and semisimple, and every extremal spherical character is determined by generator values satisfying a finite system of tropical polynomial constraints. Then for each `h : H`, there exists a finite family of affine forms on the generator-evaluation space such that the transform of `h` is their lower envelope, and this lower-envelope representation reconstructs the normal form of `h`.

In concrete terms: if `χ` is determined by the vector `(χ(T_i))_i`, then `χ(h)` is a finite minimum of affine linear forms in these coordinates. This is the tropical analogue of reconstructing an element from spectral data via piecewise-linear support functions.

Lean target, likely in a finite-generator presentation layer:

```lean
theorem exists_finite_lowerEnvelope_representation
    {ι H 𝕋 : Type*}
    [Fintype ι]
    [FiniteGeneratedIdemHeckeSemiring H]
    [TropicalCodomain 𝕋]
    (gens : ι → H)
    (hg : Generates H gens)
    (h : H) :
    ∃ (n : ℕ) (A : Fin n → (ι → ℤ)) (c : Fin n → 𝕋),
      ∀ χ : SphTrop H 𝕋,
        tropicalSphericalTransform h χ =
          Finset.univ.inf' _ (fun k => c k + affineEval (A k) (fun i => χ.toFun (gens i))) := by
```

You may need to replace `ℤ` by `ℕ`, or use a custom affine form datatype if subtraction is unavailable. The theorem can be weakened to “piecewise affine over a finite polyhedral stratification” if that is more faithful to the algebra.

A more implementation-friendly variant:

```lean

    {ι H 𝕋 : Type*} ... :
    ∀ h : H, PiecewiseTropicalAffine (generatorSpectrum gens) (fun χ => χ.toFun h) := by
```

## Proof Strategy Architecture

### Strategy A: Congruence-Spectrum First, Characters Second
Most promising if the catalog already contains prime congruence / radical / semiring spectrum machinery.

1. Define prime congruence points on the idempotent Hecke semiring and the radical as their intersection.
2. Prove that each prime congruence gives rise to an extremal normalized tropical character, or at least that every non-radical distinction is witnessed by such a character.
3. Deduce separation, then injectivity of the transform, then finite reconstruction by finite generation and normal-form compactness.

Why this is promising: it mirrors algebraic geometry’s `Spec`-style separation logic and avoids prematurely committing to explicit combinatorics of all characters. It also interfaces naturally with tropical geometry and semiring algebra.

### Strategy B: Finite Presentation + Normal Forms + Support Functions
Most promising if the catalog already has finite-presentation/rewriting/normal-form theorems for idempotent algebraic structures.

1. Present `H` as a quotient of a free idempotent semiring on generators by finitely many relations.
2. Show every element admits a canonical normal form as a finite tropical polynomial in generators.
3. Prove that evaluation on characters sends this normal form to a lower envelope of affine forms, and use equality of all evaluations to recover equality of normal forms.

Why this is promising: it is algorithmic from the start and aligns with the desired certified inversion theorem. It also gives the polyhedral theorem almost for free once normal forms are in place.

### Strategy C: Extremal Semimodule Duality / Tropical Krein–Milman Analogue
Use only if the catalog has strong tropical convexity / extremal decomposition machinery.

1. Regard `H` or its transform image as an idempotent semimodule of tropical functions.
2. Identify extremal spherical characters as “points” generating the dual semimodule.
3. Prove a finite extremal decomposition theorem implying lower-envelope reconstruction.

Why this is exciting: it would make the result look like a true tropical Plancherel theorem rather than just a semiring embedding theorem. But it is higher risk because the supporting convex-analytic API may be missing.

Recommended order: **A → B**, then optionally **C** as a conceptual upgrade.

## Cross-Domain Connections You Should Exploit

1. **Tropical geometry**  
   The transform image should be interpreted as a tropical support function on a polyhedral spectrum. The lower-envelope inversion theorem is a tropical-geometric statement about piecewise-linear functions on a finite fan or polyhedral complex.

2. **Representation theory / Satake philosophy**  
   Classical spherical Hecke algebras are reconstructed through characters on the dual side. Your theorem says that even in the idempotent shadow, the “dual spectral side” retains enough information to reconstruct convolution data. This is a tropical Satake–Plancherel principle.

3. **Automata minimization and weighted computation**  
   Finite fingerprints of semiring elements are analogous to Myhill–Nerode style separation invariants. If catalog theorems already connect tropical semirings with automata minimization, use them: extremal characters act like minimal observers distinguishing convolution operators.

4. **Semiring logic / Gödel semantics**  
   If prior work established semantics via prime congruences or valuation-like maps, exploit that analogy. A tropical character is simultaneously a valuation, a model, and a spectral probe. The separation theorem becomes a completeness theorem in algebraic semantics.

5. **Certified symbolic computation**  
   The inversion theorem is not merely structural; it provides a formal route to verified equality checking and coefficient recovery in finitely presented idempotent convolution algebras.

6. **Convex analysis / idempotent functional analysis**  
   The lower-envelope theorem is the idempotent analogue of representing a function by supporting affine functionals. This is a tropical Legendre/Fenchel flavor and could become the first formally certified bridge between semiring representation theory and idempotent analysis.
