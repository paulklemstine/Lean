## Precise Theorem Statement

Define the kernel lattice of a linear form modulo `q`:
- for `a : Fin n → ℤ` and `q : ℕ`,
- vectors `x : Fin n → ℤ` satisfying `(∑ i, a i * x i) ≡ 0 [ZMOD q]`.

Then prove an explicit bounded-box collision theorem.

### Proposed main theorem (mathematical statement)

For `n ≥ 1`, `q ≥ 1`, `B ≥ 0`, and `a : Fin n → ℤ`, let
\[
\mathcal B(n,B)=\{x \in \mathbb Z^n : \forall i,\ |x_i|\le B\}.
\]
If
\[
(2B+1)^n > q,
\]
then there exist distinct `x,y ∈ 𝔅(n,B)` such that
\[
\sum_i a_i x_i \equiv \sum_i a_i y_i \pmod q.
\]
Therefore `z := x-y` is a nonzero integer vector with
\[
\sum_i a_i z_i \equiv 0 \pmod q,\qquad \forall i,\ |z_i|\le 2B.
\]
Hence the kernel lattice contains a nonzero vector of sup-norm at most `2B`.

This is the cryptanalytic heart: if your attack enumerates more bounded candidates than the modulus can distinguish, a short relation is inevitable.

You will likely need helper definitions, but the theorem should end up close to:


A stronger version, even better, explicitly exhibits `x` and `y`:

```lean
theorem bounded_box_mod_collision
    {n q B : ℕ}
    (hq : 0 < q)
    (a : Fin n → ℤ)
    (hsize : q < (2 * B + 1) ^ n) :
    ∃ x y : Fin n → ℤ,
      x ≠ y ∧
      (∀ i, |x i| ≤ B) ∧
      (∀ i, |y i| ≤ B) ∧
      ((∑ i, a i * x i) : ℤ) ≡ (∑ i, a i * y i) [ZMOD q]
```

Then derive the kernel-vector theorem as a corollary by taking `z := x - y`.

If you can push further, prove a determinant-style corollary connecting with `tropical_lattice_det_bound`:

## Proof Strategy Architecture

You must pursue at least two approaches. The first is likely easiest to formalize; the second is more visionary and may yield stronger corollaries.

### Strategy A: Finite box + pigeonhole on residues
Most promising for Lean.

1. **Enumerate the bounded box**
   - Construct a finite set `box : Finset (Fin n → ℤ)` of all vectors with coordinates in `[-B, B]`.
   - Prove `box.card = (2 * B + 1)^n`.
   - This may require a reusable lemma for the cardinality of product boxes over `Fin n`.

2. **Define the modular linear hash**
   - Define
     ```lean
     f : (Fin n → ℤ) → ZMod q
     | x => ∑ i, (a i : ZMod q) * (x i : ZMod q)
     ```
   - Since `ZMod q` has exactly `q` elements, `box.card > q` forces a collision.

3. **Extract the short kernel vector**
   - From `f x = f y`, derive
     \[
     \sum_i a_i (x_i-y_i) \equiv 0 \pmod q.
     \]
   - Let `z := x - y`; show `z ≠ 0` and `|z_i| ≤ 2B`.
   - This gives the desired short vector in the kernel lattice.

Why this is promising:
- Finite combinatorics over `Finset` and `Fintype.card (ZMod q)` are very compatible with Mathlib.
- The theorem is explicit and computationally meaningful.

### Strategy B: Quotient-lattice / fiber-volume argument
More conceptual, potentially stronger.

1. View the map
   \[
   \phi_a : \mathbb Z^n \to \mathbb Z/q\mathbb Z,\quad x \mapsto \sum_i a_i x_i \bmod q
   \]
   as a group homomorphism.

2. Its kernel is a sublattice (or additive subgroup) of `ℤ^n`.
   - Bounded boxes represent finite sections of the ambient lattice.
   - If the number of sampled points exceeds the index of the kernel, two points lie in the same coset.

3. Deduce a nonzero short kernel element from coset overpopulation.

Why this matters:
- It naturally generalizes to multiple congruences, matrix maps, and SIS/LWE-style structures.
- If successful, it yields a theorem for `A : Matrix (Fin m) (Fin n) ℤ` with codomain `(ZMod q)^m`.

### Strategy C: Matrix generalization to modular SIS
Ambitious and field-opening.

Target a stronger theorem:
```lean
theorem bounded_box_collision_matrix
    {m n q B : ℕ}
    (hq : 0 < q)
    (A : Matrix (Fin m) (Fin n) ℤ)
    (hsize : q ^ m < (2 * B + 1) ^ n) :
    ∃ z : Fin n → ℤ,
      z ≠ 0 ∧
      (∀ i, |z i| ≤ 2 * B) ∧
      (∀ j, ((∑ i, A j i * z i : ℤ) ≡ 0 [ZMOD q]))
```

This is a formal bounded-norm SIS existence theorem by pure counting.
It would be a serious result, because it shows that once the search box outgrows the modular image space, a short modular dependency must exist.

Why this is revolutionary:
- It is the exact conceptual skeleton behind lattice cryptanalysis of hash families and SIS-type constructions.
- It connects cryptographic security thresholds to counting geometry in a theorem prover.
