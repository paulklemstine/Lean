## PROOF STRATEGY

### Strategy A: Contrapositive via prime separation and evaluation elimination
This is the most promising route.

**Step 1: Prove soundness once and for all.**  
Show that every derivation rule used in `derivable` is preserved by admissible evaluations. If `derivable` is closure-generated, the key lemma is that admissible evaluations are monotone and commute with the closure/nucleus structure. The proof should likely be an induction over the derivation system or a direct application of a generic soundness theorem already in the catalog.

Target lemma:
```lean
theorem derivable_sound_for_admissible_evaluations ...
```

**Step 2: Convert non-derivability into spectral separation.**  
Use the prime-spectrum / nucleus comparison theorem to show that if `¬ derivable x y`, then the pair `(x,y)` survives in some Jacobson-prime quotient or prime congruence. This is the exact place where the coherent hypothesis matters: compactness/coherence should guarantee that the failure of derivability is visible in a compact local quotient rather than only in an enormous global object.

Expected imported ingredients:
- a theorem identifying derivability with membership in a proof preorder or proof congruence;
- a prime separation theorem for coherent closure-generated semirings;
- a Jacobson elimination theorem reducing arbitrary prime witnesses to Jacobson ones.

**Step 3: Push the prime witness to an actual evaluation.**  
Use the “Spectral Jacobson–Evaluation Elimination” infrastructure to replace a Jacobson-prime witness by an admissible evaluation `e`. The critical lemma should say that separation in the prime/local model implies semantic inequality in the evaluation target:
```lean
separates P x y → ¬ (e x ≤ e y)
```
This is the bridge from algebraic geometry of the proof spectrum to semantics.

**Step 4: Finish by contrapositive.**  
Assume `∀ e, AdmissibleEvaluation e → e x ≤ e y`. If `¬ derivable x y`, Step 3 yields an admissible `e` with `¬ (e x ≤ e y)`, contradiction.

**Step 5: Package finite witness extraction if available.**  
If the coherence API provides compact local data or finite support certificates, strengthen the countermodel theorem to an algorithmic version:
```lean
theorem not_derivable_exists_finite_counterevaluation_data
    {S : Type*} [CoherentClosureProofSemiring S] {x y : S} :
    ¬ derivable x y →
    ∃ d : Finset S, CounterevaluationData (S := S) x y d
```
This turns semantic completeness into a search procedure.

Why this strategy is best: it aligns exactly with the catalog trajectory from prime congruences to Jacobson elimination to evaluation semantics. It avoids reproving global completeness from scratch and isolates the genuinely new work in the transport lemmas.

This is more algebraic and may yield a stronger theorem.

Prove that the proof preorder/congruence equals the intersection of kernels of all admissible evaluations. In order terms:

5. Conclude equality.

This route is conceptually powerful because it identifies syntax with a radical closure operation. It may also expose a reusable theorem for other logics/semiring semantics.

## SIGNIFICANCE

This theorem is the semantic backbone of the entire closure-generated proof-semiring program. It says that derivability is not an opaque syntactic artifact: it is exactly the intersection of all Jacobson evaluation semantics. That has three major consequences.

1. **Algebraic completeness becomes computationally actionable.**  
   Prime-spectrum completeness alone is geometric and often nonconstructive. Evaluation adequacy converts it into a usable semantic decision principle: to refute `derivable x y`, it suffices to produce a concrete admissible evaluation. This is the bridge from abstract algebra to proof search and model extraction.

2. **The Jacobson radical becomes semantic indistinguishability.**  
   Once the proof preorder/congruence is identified with the intersection of evaluation kernels, radical closure is no longer merely algebraic. It becomes the exact notion of “cannot be distinguished by any admissible model.” That is a deep conceptual unification of algebraic logic, spectral geometry, and semantics.

3. **It opens algorithmic countermodel reconstruction.**  
   Coherence suggests finite witness extraction from compact local data. That means the theorem has an algorithmic shadow: failed derivations should produce finite semantic certificates. This is the semiring analogue of extracting finite countermodels in logic or certificates in optimization. It points toward automated refutation engines, tropical proof analyzers, and complexity bounds on semantic separation.

4. **It connects algebraic logic to tropical and thermodynamic semantics.**  
   Evaluation semantics in idempotent/coherent semirings naturally resemble tropical valuations and free-energy observables. Adequacy therefore says that logical derivability can be read off from valuation-like observables, opening a path from proof theory to tropical optimization, entropy-like separation principles, and even min-plus computational semantics.

This is not an incremental result. It is the theorem that turns a spectral theory into a semantic technology.
