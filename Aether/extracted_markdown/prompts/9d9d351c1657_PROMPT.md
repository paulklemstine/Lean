## Assignment: Arithmetic Monodromy Fingerprints of Gradient Descent

**Mode:** prove

Prove genuinely new theorems at the interface of algebraic geometry, arithmetic dynamics, discrete optimization, and finite-field statistics. The target is not a small extension of known gradient-descent folklore, but the beginning of an invariant-based theory of optimization landscapes: the idea that exact gradient descent on polynomial losses carries an arithmetic shadow, and that this shadow is controlled by monodromy/Galois data of the critical-value covering.

You should formalize a mathematically clean core of this vision in Lean 4, with at least one new definition, at least 3 nontrivial theorems, and one verified computational method. Build from Mathlib’s algebra, polynomial, finite field, group action, and dynamical systems infrastructure wherever possible.

---

## Central Vision

For polynomial losses \( f : K^n \to K \), exact gradient descent with step size \( \eta \in K \),
\[
T_{f,\eta}(x) = x - \eta \nabla f(x),
\]
defines a polynomial self-map. The critical locus of \(f\), the set of critical values, and the permutation action induced by continuation around discriminant loci together define a monodromy/Galois object. The bold claim is that this object is not decorative: it constrains which saddles can feed which minima under exact descent, and it leaves statistically detectable fingerprints after reduction modulo primes.

The revolutionary goal is to isolate the first rigorous theorem showing that **arithmetic data of a polynomial optimization landscape controls observable descent dynamics**.

This would open a new field: **arithmetic optimization theory**. It would connect:
- algebraic geometry of critical loci,
- Galois/monodromy actions on fibers,
- arithmetic dynamics modulo primes,
- trainability and basin statistics in optimization.

If successful, this creates a new language for landscape complexity: not Hessian spectra, not only Morse theory, but **monodromy fingerprints**.

These definitions are mathematically meaningful and can support real theorems.

## Core theorem package to aim for

You must prove at least 3 substantial theorems. Here is the recommended theorem stack.

### Theorem 1: Gradient descent preserves algebraicity and critical-point rationality in explicit families

For an explicit family of low-degree polynomials over \(\mathbb{Q}\) (start with cubic or quartic), prove that the gradient step map sends algebraic points to algebraic points, and that the image of critical points can be expressed by algebraic formulas controlled by the critical-value polynomial.

A good formal statement for the univariate case:

```lean
theorem gradientStep_eval_is_algebraic
  {K L : Type*} [Field K] [Field L] [Algebra K L]
  (f : K[X]) (η x : L) :
  IsAlgebraic K x →
  IsAlgebraic K (aeval x (gradientStep f η)) := ...
```

where `gradientStep` is your new definition, likely:
```lean
def gradientStep (f : K[X]) (η : K) : K[X] :=
  X - C η * derivative f
```

Breakthrough significance: this theorem gives the first formal bridge from optimization dynamics to arithmetic geometry. It says exact descent on polynomial losses stays inside the algebraic world, so monodromy/Galois methods are not merely analogies—they are native.

### Theorem 2: Critical points map through a discriminant-controlled orbit relation

For separable derivatives, prove that the image set of critical points under one gradient step is exactly the set of values
\[
c - \eta f'(c) = c
\]
for critical points \(c\), hence critical points are fixed under one-step descent iff they are stationary. Then go deeper: characterize when a noncritical point can map into the critical locus, or when critical values determine one-step basin partitions.

A more substantial target in Lean is:

```lean
theorem mem_criticalPoints_iff_derivative_eq_zero
  {K : Type*} [Field K] (f : K[X]) (x : K) :
  x ∈ criticalPoints f ↔ aeval x (derivative f) = 0 := ...
```

and then

```lean
theorem gradientStep_fixes_criticalPoints
  {K : Type*} [Field K] (f : K[X]) (η x : K)
  (hx : x ∈ criticalPoints f) :
  aeval x (gradientStep f η) = x := ...
```

Then add a genuinely dynamic theorem, e.g. for a concrete family \(f_a(x)=x^3-ax\):

```lean
theorem cubic_gradient_basin_dichotomy
  {K : Type*} [LinearOrderedField K]
  (a η x : K) (ha : 0 < a) (hη : 0 < η) :
  ... → -- explicit inequalities
  ∃ n : ℕ, ((gradientIterate (cubicLoss a) η n).eval x = realMinimizer a ∨
            (gradientIterate (cubicLoss a) η n).eval x = leftMinimizer a) := ...
```

Even if the final theorem is stated for `ℚ` or `ℝ`, make it mathematically nontrivial: use induction on iterates, interval trapping, and multi-step `calc`.

Breakthrough significance: this is where optimization enters. You are proving that exact descent dynamics can be read from algebraic critical structure, not just from analytic smoothness.

### Theorem 3: Distinct arithmetic/monodromy data force distinct finite-field transition statistics in explicit families

This is the bold theorem. Since full monodromy-group classification may be too large, prove a first explicit separation theorem for two concrete families whose critical-value polynomials have different splitting behavior, and show that the induced descent maps over infinitely many finite fields have provably different fixed-point or basin counts.

A realistic formal target:

```lean
theorem exists_infinitely_many_primes_with_distinct_fixedPointCounts
  (f g : ℚ[X]) (η : ℚ)
  (hsep : arithmeticFingerprintWitness f g η) :
  ∃ᶠ p in Filter.atTop,
    fixedPointCountMod p f η ≠ fixedPointCountMod p g η := ...
```

If proving an “infinitely many primes” theorem is too ambitious in Lean with current libraries, replace it by a family theorem over finite fields with explicit congruence classes:

```lean
theorem quadraticResidue_family_separates_basin_counts
  (p : ℕ) [Fact p.Prime]
  (hp : p % 4 = 1) :
  fixedPointCountMod p f η = A ∧ fixedPointCountMod p g η = B := ...
```

and a complementary theorem for \(p \equiv 3 \pmod 4\). This already gives infinitely many separating primes by classical number theory if you can cite/derive enough infrastructure, or at minimum a computational theorem over explicit prime classes.

Breakthrough significance: this would be the first rigorous statement that two optimization landscapes indistinguishable over \(\mathbb{Q}\) by naive local analysis can be separated by arithmetic descent statistics mod \(p\). That is a new kind of trainability invariant.

## Recommended explicit polynomial families

Do not attack the full generic conjecture first. Use families where the critical structure is symbolically transparent.

### Family A: cubic double-well
\[
f_a(x)=x^3-ax,\quad f_a'(x)=3x^2-a.
\]
Critical points exist iff \(a/3\) is a square. Over finite fields this depends on quadratic residuosity. This is ideal for arithmetic separation.

Gradient step:
\[
T(x)=x-\eta(3x^2-a).
\]

### Family B: quartic double-well
\[
f_a(x)=x^4-2ax^2,\quad f_a'(x)=4x^3-4ax=4x(x^2-a).
\]
Critical points split according to whether \(a\) is a square mod \(p\). Basin combinatorics can differ sharply.

### Family C: shifted cubic/quartic pairs with same degree but different critical-value discriminants
Construct \(f,g\) with same number of critical points over \(\overline{\mathbb{Q}}\) but different splitting fields / discriminants. This is the nearest formal proxy for “different monodromy classes.”

## Proof strategy architecture

You must include at least 2–3 strategy routes and decide which is most promising.

### Strategy A: Explicit algebraic dynamics in low-degree families
1. Define `gradientStep`, `criticalPoints`, `gradientIterate`.
2. Compute derivatives and fixed-point equations for cubic/quartic families.
3. Over finite fields, reduce existence and counts of critical/fixed points to quadratic/cubic residue conditions.
4. Prove prime-class separation results for basin/fixed-point statistics.

**Why promising:** This is the best first theorem package for Lean. It avoids the hardest formalization of étale monodromy while still proving the arithmetic-fingerprint principle in explicit form.

### Strategy B: Galois-theoretic control through splitting fields of derivative and critical-value polynomials
1. Associate to \(f\) the splitting field of \(f'\) and/or the polynomial whose roots are critical values.
2. Prove that gradient-step images of critical points lie in this field.
3. Show that distinct splitting behavior mod \(p\) yields distinct orbit statistics for infinitely many reductions.

**Why promising:** Conceptually closest to the monodromy conjecture. Use if Mathlib’s field theory and polynomial factorization support is sufficient. Even partial success here would be groundbreaking.

### Strategy C: Dynamical systems + arithmetic statistics
1. Study the functional graph of `gradientStep` over `ZMod p`.
2. Define basin-size distributions and prove exact formulas for specific families.
3. Relate graph shape changes to discriminant/residue conditions.

**Why promising:** Strong computational payoff and demo value. It produces a verified algorithm and visible finite-field phenomena, even if the monodromy formalization remains indirect.

**Most promising overall:** Start with Strategy A, augment with C, and import as much of B as the library allows. The first publishable breakthrough is an explicit theorem saying: **critical algebraic data predicts finite-field descent graph statistics**.

## Concrete theorem suggestions with proof texture

You need at least 3 theorems with deep tactics. Here are good candidates.

### Theorem A
```lean
theorem fixedPoints_gradientStep_eq_criticalPoints
  {K : Type*} [Field K] (f : K[X]) (η : K) (hη : η ≠ 0) :
  fixedPoints f η = criticalPoints f := ...
```
Because
\[
x - \eta f'(x) = x \iff \eta f'(x)=0 \iff f'(x)=0.
\]
This is not trivial if you set up the definitions properly and prove via polynomial evaluation identities, `field_simp` where needed, and extensionality on sets.

### Theorem B
For the cubic family over a field of characteristic \(\neq 2,3\):
```lean
theorem cubic_criticalPoints_card_eq
  {K : Type*} [Field K] [DecidableEq K]
  (a : K) (ha : a ≠ 0) :
  Fintype.card {x : K // aeval x (derivative (X^3 - C a * X : K[X])) = 0}
    = if IsSquare (a / 3) then 2 else 0 := ...
```
You may need a field with enough square-root structure or specialize to `ZMod p` with prime conditions. The proof uses derivative computation, algebraic rearrangement, and residue-case splitting.

### Theorem C
```lean
theorem quartic_mod_p_fixedPointCount_depends_on_quadratic_residue
  (p : ℕ) [Fact p.Prime] (hp2 : p ≠ 2)
  (a : ZMod p) :
  fixedPointCountMod p (X^4 - C (2*a) * X^2 : ZMod p[X]) (1 : ZMod p)
    = if IsSquare a then 3 else 1 := ...
```
Since fixed points of gradient step coincide with critical points for nonzero step size, and
\[
f'(x)=4x(x^2-a),
\]
the count is determined by solvability of \(x^2=a\). This is exactly the arithmetic-fingerprint phenomenon in a rigorous finite form.

### Theorem D
```lean

  (p : ℕ) [Fact p.Prime] (hp2 : p ≠ 2) :
  fixedPointCountMod p quarticFamily1 1 ≠ fixedPointCountMod p quarticFamily2 1 := ...
```

under explicit residue assumptions on parameters. This becomes your formal separation theorem.

## Testable conjecture you must state

You must include at least one falsifiable conjecture with a clear computational disproof criterion.

### Recommended conjecture
**Conjecture (Arithmetic fingerprint separation for quartic families).**  
Let
\[
f_a(x)=x^4-2ax^2,\qquad g_b(x)=x^4-2bx^2
\]
with \(a,b \in \mathbb{Z}\setminus\{0\}\), and assume \(a/b\) is not a square in \(\mathbb{Q}\). Then there exist infinitely many odd primes \(p\) for which the exact gradient maps with step size \(\eta=1\) over \(\mathbb{F}_p\) have different basin-size distributions:
\[
\mathrm{BasinStat}_p(f_a,1)\neq \mathrm{BasinStat}_p(g_b,1).
\]

**Computational test:** For increasing prime bounds \(B\), compute basin histograms for all odd primes \(p\le B\) avoiding bad reduction. The conjecture is supported if the empirical separation frequency stabilizes away from 0; it is falsified if monodromy-distinct pairs repeatedly show identical basin distributions for all tested good primes.

A second, bolder conjecture:
**Conjecture (Critical-value splitting predicts descent graph type).**  
For generic low-degree integer polynomials \(f,g\) with distinct critical-value splitting fields, the distributions of cycle lengths of `gradientStep` on `ZMod p` differ for a positive density of good primes.

This is falsifiable by exhaustive computation on many primes.
