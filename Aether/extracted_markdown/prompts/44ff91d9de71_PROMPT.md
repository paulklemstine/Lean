## Precise Target Theorem

Let `X` be a finite directed 2-complex with edge set `E`, composable path type `Path X`, loop type `Loop X`, and a loop closure operator `cl : Finset (Loop X) → Set (Loop X)` satisfying:

1. **Extensive:** `S ⊆ cl S`
2. **Monotone:** `S ⊆ T → cl S ⊆ cl T`
3. **Idempotent:** `cl (cl S ∩ finite_part) = cl S` in the appropriate finitary sense
4. **Basepoint invariant:** conjugate/rebased loops have equal closure status
5. **Tropical subadditivity / capacity law:** closure capacity of concatenations is bounded by tropical product/sup of capacities
6. **Elementary homotopy + gauge-trivial insertion invariance**
7. **Cycle separation:** distinct extremal loop classes are distinguished by some finite test family / incidence functional

From `cl`, define the associated idempotent holonomy semimodule `H_cl`, generated by loop classes modulo closure-identification relations and concatenation submultiplicativity.

Define a finite connection realization `A` as edge weights in an idempotent semiring `R` inducing loop holonomy values `Hol_A : Loop X → R`, and associated closure
`cl_A(S) = {γ | Hol_A γ ≤ ⨆ σ∈S, Hol_A σ}`.

### Main realization/minimality duality theorem
Prove that for finite directed 2-complexes:

> A closure system `cl` is gauge-realizable by some finite idempotent connection iff the associated holonomy semimodule `H_cl` is finitely generated and cycle-separated.  
> Moreover, there exists a finite minimal realization `A_min` such that:
>
> 1. `cl = cl_{A_min}`,
> 2. `A_min` is minimal among all finite realizations in generator rank / state dimension,
> 3. any two minimal realizations are gauge equivalent,
> 4. `A_min` is reconstructible from a finite basis of extremal loops,
> 5. the reconstruction admits a formal certification theorem.

This should be split into Lean-manageable theorems.

## Proof Strategy Architecture

### Strategy A: Hankel-style realization via loop incidence semimodule
This is likely the most promising.

1. **Define the loop incidence/Hankel object.**  
   For test paths or loop contexts `u, v`, define an incidence valuation measuring whether `u * γ * v` lies below the closure capacity generated by a finite family. Package these rows/columns as an idempotent semimodule.

2. **Prove finite generation ↔ finite realizability.**  
   Mimic weighted automata realization: finite generation gives a finite basis of extremal loop responses; from this basis construct edge transport operators and define `Hol_A`.

3. **Prove minimality and uniqueness.**  
   Show any realization factors through the extremal basis semimodule. Then minimality is rank minimality, and uniqueness follows by mutual factorization yielding gauge equivalence.

Why this is strongest: it directly imports the deepest idea from automata/Hankel theory into gauge reconstruction, which is exactly the conceptual leap this project wants.

---

### Strategy B: Closure-to-connection reconstruction via tropical convexity
Potentially cleaner if semimodule APIs are already available.

1. **Form the tropical convex hull of loop valuations.**  
   Treat closure as a tropical convex dependence relation on loops.

2. **Identify extremal loops as primitive curvature witnesses.**  
   Show finite generation implies every loop valuation is a tropical combination of extremal loops.

3. **Reconstruct edge weights from extremal support constraints.**  
   Solve a finite tropical factorization problem assigning edge weights consistent with all extremal loop capacities.

Why useful: this emphasizes geometry and may simplify the certified reconstruction theorem. It also gives a strong conceptual interpretation: **curvature is the tropical support function of the loop closure polytope**.

---

### Strategy C: Categorical / quotient-by-gauge approach
Use if quotienting by gauge equivalence is the main obstacle.

1. Define a category of finite connection presentations and gauge morphisms.
2. Show closure extraction is a functor to finite idempotent holonomy semimodules.
3. Prove a representation theorem: minimal objects in the fiber over `cl` are unique up to isomorphism.
4. Read isomorphism as gauge equivalence.

Why useful: this can make uniqueness-up-to-gauge nearly tautological once the categorical setup is right.  
Why less promising initially: more abstraction, more Lean overhead.
