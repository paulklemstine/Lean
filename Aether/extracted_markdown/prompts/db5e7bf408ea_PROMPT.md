## Assignment: Prove a canonical-form theorem for tropical syntax that upgrades semantic equality into decidable syntactic equality on the commutative-associative fragment

**Mode:** prove

This is not just a normalization exercise. If you succeed, you will have built the first genuine **decision procedure kernel** for a fragment of tropical expression equivalence inside Lean: a certified bridge from semantics (`eval`) to canonical syntax (`normalize_ca`). That is the seed of a tropical proof compiler, a rewriting engine, and eventually a certified tropical Gröbner-style infrastructure. The right theorem here is a foundational breakthrough because it converts the vague slogan “AC-equivalent expressions should have the same normal form” into a formally verified canonicalization theorem strong enough to support automation.

You should define a canonical representation for the **AC tropical fragment** generated by variables/constants under:
- `tmin` as a commutative-associative n-ary minimum,
- `add` as a commutative-associative n-ary sum,
with no distributivity quotienting at this stage.

The key idea is to **separate syntax into operator-homogeneous flattened layers**, sort children using a total order on normalized expressions, and prove that this canonicalization is complete for semantic equality *within the AC fragment*. This gives a true reflection theorem: semantic equality implies syntactic equality after normalization.

The main breakthrough theorem should be stated in one of the following mathematically correct forms.

### Preferred completeness theorem
```lean
theorem normalize_ca_complete
  {e₁ e₂ : TropExpr}
  (h₁ : ACFragment e₁)
  (h₂ : ACFragment e₂)
  (hsame : ∀ σ, eval σ e₁ = eval σ e₂) :
  normalize_ca e₁ = normalize_ca e₂
```

But this may still require a hidden freeness theorem. A stronger and cleaner route is to define the AC congruence relation explicitly:

```lean
inductive ACEquiv : TropExpr → TropExpr → Prop
| refl  : ∀ e, ACEquiv e e
| symm  : ∀ {e₁ e₂}, ACEquiv e₁ e₂ → ACEquiv e₂ e₁
| trans : ∀ {e₁ e₂ e₃}, ACEquiv e₁ e₂ → ACEquiv e₂ e₃ → ACEquiv e₁ e₃
| tmin_comm : ∀ e₁ e₂, ACEquiv (.tmin e₁ e₂) (.tmin e₂ e₁)
| tmin_assoc : ∀ e₁ e₂ e₃, ACEquiv (.tmin (.tmin e₁ e₂) e₃) (.tmin e₁ (.tmin e₂ e₃))
| add_comm : ∀ e₁ e₂, ACEquiv (.add e₁ e₂) (.add e₂ e₁)
| add_assoc : ∀ e₁ e₂ e₃, ACEquiv (.add (.add e₁ e₂) e₃) (.add e₁ (.add e₂ e₃))
| cong_tmin : ∀ {a a' b b'}, ACEquiv a a' → ACEquiv b b' → ACEquiv (.tmin a b) (.tmin a' b')
| cong_add  : ∀ {a a' b b'}, ACEquiv a a' → ACEquiv b b' → ACEquiv (.add a b) (.add a' b')
```

Then prove the canonical theorem:
```lean
theorem normalize_ca_complete_ACEquiv :
  ∀ {e₁ e₂}, ACEquiv e₁ e₂ → normalize_ca e₁ = normalize_ca e₂
```

and, if you can push further, the reflection theorem:
```lean
theorem normalize_ca_reflects_AC_semantics
  {e₁ e₂ : TropExpr}
  (h₁ : ACFragment e₁)
  (h₂ : ACFragment e₂)
  (hsem : ∀ σ, eval σ e₁ = eval σ e₂) :
  normalize_ca e₁ = normalize_ca e₂
```

This last theorem is the genuinely deep one: it says the AC tropical syntax is **free modulo AC over the interpretation into `(ℝ, min, +)`**, at least for the fragment you formalize. ## Recommended proof architecture

## Strategy A: Flatten–sort–rebuild via list semantics
This is likely the most Lean-robust path.

### Step 1: Define operator-specific flatteners
Define:
```lean
def flattenMin : TropExpr → List TropExpr
def flattenAdd : TropExpr → List TropExpr
```
so that:
- `flattenMin (tmin a b)` concatenates `flattenMin a` and `flattenMin b`,
- otherwise it returns `[normalize_ca e]` or `[e]` depending on recursion design,
and similarly for `flattenAdd`.

Then define list evaluators:
```lean
def evalMinList (σ : ℕ → ℝ) : List TropExpr → ℝ
def evalAddList (σ : ℕ → ℝ) : List TropExpr → ℝ
```
probably by folding with `min` and `+`, with careful treatment of singleton/nonempty lists.

### Step 2: Prove permutation invariance
You need lemmas of the form:
```lean
theorem evalAddList_perm (σ) {l₁ l₂} :
  l₁.Perm l₂ → evalAddList σ l₁ = evalAddList σ l₂

theorem evalMinList_perm (σ) {l₁ l₂} :
  l₁.Perm l₂ → evalMinList σ l₁ = evalMinList σ l₂
```
These are the heart of commutativity. Associativity comes from fold/concatenation lemmas:
```lean
theorem evalAddList_append ...
theorem evalMinList_append ...
```

### Step 3: Sort and rebuild canonical nodes
Define a total order on normalized expressions, perhaps lexicographic on a structural encoding:
```lean
def exprCode : TropExpr → ...
instance : LT TropExpr := ...
instance : DecidableRel ((· < ·) : TropExpr → TropExpr → Prop) := ...
```
or better, use a measure-based encoding into a type with an existing `Ord`.

Then:
- recursively normalize children,
- flatten same-head nodes,
- sort children,
- rebuild a right-associated or balanced binary tree.

Prove:
- sorted rebuild is normalized,
- sorting twice is stable,
- flattening a normalized same-head node does nothing.

This yields soundness and idempotence.

### Why Strategy A is most promising
Because Lean handles list induction, permutation lemmas, and sort invariance much more comfortably than abstract rewriting arguments. It also produces executable normalization immediately.

## Strategy B: Rewriting-system / confluence proof
This is more ambitious and more conceptually beautiful.

### Step 1: Define one-step rewrite rules
Orient associativity and commutativity into a canonical direction, e.g.:
- reassociate to right-nested form,
- swap children according to the total order,
- recursively normalize subterms.

### Step 2: Prove termination
Use a lexicographic measure:
- number of “bad” associativity patterns,
- number of local inversions relative to the chosen order,
- total size of unnested same-head chains.

### Step 3: Prove local confluence and invoke Newman-style reasoning
Show critical pairs for associativity/commutativity normalization are joinable. Then derive uniqueness of normal forms and identify `normalize_ca` as the normal-form map.

### Why this matters
This route yields more than your theorem: it gives a bona fide **certified completion system** viewpoint, which is the right language for future extensions with idempotence, absorption, and distributivity fragments.

### Why it is probably less Lean-efficient initially
Critical-pair bookkeeping and termination measures are heavier than list-based flattening. Pursue this only if the list canonicalization is already under control.

---

## Strategy C: Algebraic freeness via multisets / quotient semantics
This is the most mathematically elegant route if you want a conceptual theorem.

### Step 1: Interpret each AC node as a multiset of recursively normalized children
Replace binary trees by an n-ary representation:
- min-nodes as multisets of terms,
- add-nodes as multisets of terms.

### Step 2: Show binary syntax modulo AC is isomorphic to this multiset syntax
This gives a semantic-independent canonicalization theorem.

### Step 3: Push to semantic completeness
Prove that if two AC terms have identical evaluations under all environments, then their multiset normal forms coincide. This is a freeness statement for the interpreted algebra and may require a careful separation argument using valuations/environments that isolate subterms.

### Why this is exciting
It recasts tropical syntax as an initial algebra for two commutative-associative operations, bringing universal algebra directly into the tropical formalization pipeline.

### Risk
The semantic completeness part can fail if constants create accidental equalities or if the fragment is not stratified carefully. This approach demands the clearest mathematical specification.

## Critical mathematical insight: the third theorem needs the right fragment

Do **not** state
```lean
∀ e₁ e₂, (∀ σ, eval σ e₁ = eval σ e₂) → normalize_ca e₁ = normalize_ca e₂
```
for unrestricted syntax. It is false in the presence of additional valid semantic identities not generated by AC, especially once constants are present and certainly once distributive interactions are allowed. The right theorem must be one of:

- completeness for the explicit AC congruence,
- completeness for a restricted AC-only syntax,
- completeness for a typed normal-form grammar where `tmin` and `add` are only identified up to AC and no cross-head equations are admitted.

This correction is not a retreat; it is the mathematically sophisticated move. It makes the theorem true, sharp, and reusable.
