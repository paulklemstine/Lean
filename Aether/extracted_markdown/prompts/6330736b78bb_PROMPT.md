### Core objects to define concretely in Lean
Work with a finite coordinate model of the GL3 tropical test family, so the main theorem is stated over `Fin n → ℝ` and can be proved cleanly with `Finset` sums and sup-norm bounds.

A good concrete setup is:

```lean
abbrev TestVec (n : ℕ) := Fin n → ℝ

def score {n : ℕ} (w φ : TestVec n) : ℝ :=
  ∑ i : Fin n, w i * φ i

def l1Norm {n : ℕ} (w : TestVec n) : ℝ :=
  ∑ i : Fin n, |w i|

def supNormDiff {n : ℕ} (φ ψ : TestVec n) : ℝ :=
  ‖φ - ψ‖

def argmaxInvariant
    {κ n : ℕ} (W : Fin κ → TestVec n) (φ ψ : TestVec n) (a : Fin κ) : Prop :=
  ∀ b : Fin κ, b ≠ a → score (W a) ψ > score (W b) ψ
```

If the norm on `Fin n → ℝ` is inconvenient to control directly, you can instead define the coordinatewise bound as a hypothesis
```lean
∀ i, |φ i - ψ i| ≤ ε
```
and derive all inequalities from that. This is likely the most robust route in Lean.

The representation-theoretic interpretation should remain explicit in naming:
- `w = T h` is the finite tropical Satake test vector attached to Hecke data `h`;
- coordinates of `w` correspond to the GL3 separating test family: two simple-coroot edge valuations and one rank-2 Levi mixed moment, together with any additional finite support coordinates from the partial reconstruction theorem.

You do not need the full abstract semimodule formalism to prove the certificate. The theorem should be stated for finite real vectors, then specialized by setting `w = T h`.

### Theorem 1: Lipschitz transfer lemma for tropical Satake score vectors

Prove the basic score perturbation bound in a coordinatewise form first.

```lean
theorem abs_score_sub_le_l1_mul_eps
    {n : ℕ} (w φ ψ : Fin n → ℝ) (ε : ℝ)
    (hε : ∀ i, |φ i - ψ i| ≤ ε) :
    |score w φ - score w ψ| ≤ l1Norm w * ε
```

A stronger and often cleaner intermediate form is:

```lean
theorem abs_score_sub_le_sum
    {n : ℕ} (w φ ψ : Fin n → ℝ) :
    |score w φ - score w ψ|
      ≤ ∑ i : Fin n, |w i| * |φ i - ψ i|
```

and then derive the previous theorem via
```lean
∑ i, |w i| * |φ i - ψ i| ≤ (∑ i, |w i|) * ε.
```

If you want a norm-based corollary, prove:

```lean
theorem abs_score_sub_le_l1_mul_sup
    {n : ℕ} (w φ ψ : Fin n → ℝ) :
    |score w φ - score w ψ|
      ≤ l1Norm w * (∑' _ : PUnit, ‖φ - ψ‖)
```

but the coordinatewise-ε version is the one that will actually drive the robustness certificate. Do not get stuck forcing a global `‖·‖∞` API if the finite-coordinate estimate is easier.

#### Proof strategy
1. Expand
   ```lean
   score w φ - score w ψ = ∑ i, w i * (φ i - ψ i).
   ```
   This is just linearity of finite sums.
2. Apply `abs_sum_le_sum_abs` to obtain
   ```lean
   |∑ i, w i * (φ i - ψ i)| ≤ ∑ i, |w i * (φ i - ψ i)|.
   ```
3. Rewrite each summand using `abs_mul`:
   ```lean
   |w i * (φ i - ψ i)| = |w i| * |φ i - ψ i|.
   ```
4. Under the hypothesis `hε`, bound each term by `|w i| * ε`, then sum.
5. Factor out `ε` from the sum; if needed, treat separately the sign of `ε`, though in applications you should assume `0 ≤ ε`.

A useful sharpened version assumes `0 ≤ ε`:

```lean
theorem abs_score_sub_le_l1_mul_eps'
    {n : ℕ} (w φ ψ : Fin n → ℝ) {ε : ℝ}
    (hε₀ : 0 ≤ ε)
    (hε : ∀ i, |φ i - ψ i| ≤ ε) :
    |score w φ - score w ψ| ≤ l1Norm w * ε
```

This avoids any pathology if `ε < 0`.

### Theorem 2: Pairwise margin preservation under bounded perturbations

Now prove the binary robustness statement.

```lean
theorem pairwise_margin_preserved
    {n : ℕ} (wa wb φ ψ : Fin n → ℝ) {ε : ℝ}
    (hε₀ : 0 ≤ ε)
    (hcoord : ∀ i, |φ i - ψ i| ≤ ε)
    (hmargin :
      score wa φ - score wb φ >
        (l1Norm wa + l1Norm wb) * ε) :
    score wa ψ > score wb ψ
```

A slightly more flexible equivalent hypothesis is

```lean
hmargin :
  score wa φ > score wb φ + (l1Norm wa + l1Norm wb) * ε
```

which is often easier to manipulate with `linarith`.

#### Proof strategy
1. Apply the Lipschitz transfer lemma separately to `wa` and `wb`:
   ```lean
   |score wa φ - score wa ψ| ≤ l1Norm wa * ε
   |score wb φ - score wb ψ| ≤ l1Norm wb * ε.
   ```
2. Convert absolute-value bounds into one-sided bounds:
   ```lean
   score wa ψ ≥ score wa φ - l1Norm wa * ε
   score wb ψ ≤ score wb φ + l1Norm wb * ε.
   ```
3. Subtract the inequalities to get
   ```lean
   score wa ψ - score wb ψ
     ≥ (score wa φ - score wb φ) - (l1Norm wa + l1Norm wb) * ε.
   ```
4. Use the strict margin hypothesis to conclude the right-hand side is positive.
5. Finish with `linarith`.

A very useful intermediate lemma is:

```lean
theorem score_gap_lower_bound
    {n : ℕ} (wa wb φ ψ : Fin n → ℝ) {ε : ℝ}
    (hε₀ : 0 ≤ ε)
    (hcoord : ∀ i, |φ i - ψ i| ≤ ε) :
    score wa ψ - score wb ψ
      ≥ (score wa φ - score wb φ) - (l1Norm wa + l1Norm wb) * ε
```

This packages the core perturbative estimate and makes the multiclass theorem nearly immediate.

### Theorem 3: Multiclass argmax certificate from minimum transformed margin

Let `W : Fin κ → Fin n → ℝ` be the family of class score vectors, interpreted as `W c = T(h_c)`.

Define the certified margin of class `a` at feature vector `φ` by
```lean
def pairwiseMargin
    {κ n : ℕ} (W : Fin κ → Fin n → ℝ) (φ : Fin n → ℝ) (a b : Fin κ) : ℝ :=
  score (W a) φ - score (W b) φ

def transformedMargin
    {κ n : ℕ} (W : Fin κ → Fin n → ℝ) (φ : Fin n → ℝ) (a : Fin κ) : ℝ :=
  sInf {m : ℝ | ∃ b : Fin κ, b ≠ a ∧
    m = pairwiseMargin W φ a b / (l1Norm (W a) + l1Norm (W b))}
```

However, `sInf` over a set is heavier in Lean than necessary. Since `Fin κ` is finite, a better implementation is via `Finset` minimum over competitors. For the theorem, you can avoid introducing the minimum as a definition and instead assume the pairwise condition for every competitor.

The clean multiclass theorem is:

```lean
theorem multiclass_argmax_invariant
    {κ n : ℕ} (W : Fin κ → Fin n → ℝ) (a : Fin κ) (φ ψ : Fin n → ℝ) {ε : ℝ}
    (hε₀ : 0 ≤ ε)
    (hcoord : ∀ i, |φ i - ψ i| ≤ ε)
    (hmargin : ∀ b : Fin κ, b ≠ a →
      score (W a) φ - score (W b) φ >
        (l1Norm (W a) + l1Norm (W b)) * ε) :
    ∀ b : Fin κ, b ≠ a → score (W a) ψ > score (W b) ψ
```

Equivalently, using the `argmaxInvariant` predicate:

```lean
theorem multiclass_argmax_invariant'
    {κ n : ℕ} (W : Fin κ → Fin n → ℝ) (a : Fin κ) (φ ψ : Fin n → ℝ) {ε : ℝ}
    (hε₀ : 0 ≤ ε)
    (hcoord : ∀ i, |φ i - ψ i| ≤ ε)
    (hmargin : ∀ b : Fin κ, b ≠ a →
      score (W a) φ - score (W b) φ >
        (l1Norm (W a) + l1Norm (W b)) * ε) :
    argmaxInvariant W φ ψ a
```

#### Proof strategy
1. Fix an arbitrary competitor `b ≠ a`.
2. Apply `pairwise_margin_preserved` to `wa = W a` and `wb = W b`.
3. Use the pairwise margin hypothesis `hmargin b hb`.
4. Since the conclusion holds for every competitor, conclude argmax invariance.
5. If desired, separately derive that `a` is the unique argmax at `φ`; this is immediate from taking `ε = 0` or from the strict inequalities already assumed.

### Theorem 4: Representation-theoretic meaningfulness via finite tropical separation

This is the bridge theorem that makes the certificate specifically about GL3 tropical Satake data rather than an arbitrary linear classifier family.

Model the finite tropical test map as
```lean
T : H → Fin n → ℝ
```
for some type `H` of finitely supported dominant GL3 Hecke data. Assume the finite GL3 test-family separation theorem in the form:

```lean
variable {H : Type _}
variable (T : H → Fin n → ℝ)

def Separating (T : H → Fin n → ℝ) : Prop :=
  Function.Injective T
```

Then prove the simple but important corollary:

```lean
theorem separating_implies_nonzero_pairwise_vector
    {H : Type _} {n : ℕ} (T : H → Fin n → ℝ)
    (hsep : Function.Injective T) {ha hb : H} (hne : ha ≠ hb) :
    T ha ≠ T hb
```

and, more substantively, if class data are distinct then the pairwise score-difference functional is not identically zero:

```lean
theorem separating_implies_exists_distinguishing_coordinate
    {H : Type _} {n : ℕ} (T : H → Fin n → ℝ)
    (hsep : Function.Injective T) {ha hb : H} (hne : ha ≠ hb) :
    ∃ i : Fin n, T ha i ≠ T hb i
```

From this derive a non-vacuity statement for margins:

```lean
theorem separating_implies_exists_feature_with_positive_gap
    {H : Type _} {n : ℕ} (T : H → Fin n → ℝ)
    (hsep : Function.Injective T) {ha hb : H} (hne : ha ≠ hb) :
    ∃ φ : Fin n → ℝ, score (T ha) φ ≠ score (T hb) φ
```

A very easy witness is the coordinate basis vector at a distinguishing coordinate. If you want a stronger theorem, choose `φ i = T ha i - T hb i`, giving
```lean
score (T ha - T hb) φ = ∑ i, (T ha i - T hb i)^2 > 0
```
provided you formulate subtraction pointwise. But the basis-vector witness is simpler and sufficient.

#### Proof strategy
1. Use injectivity to deduce `T ha ≠ T hb` from `ha ≠ hb`.
2. Convert inequality of functions on `Fin n` into existence of a coordinate where they differ (`not_forall.mp`).
3. Define a feature vector supported on that coordinate, e.g.
   ```lean
   φ j = if j = i then 1 else 0.
   ```
4. Compute both scores and show they differ exactly by the differing coordinate.
5. Conclude that finite tropical separation gives genuinely distinct score functionals, so the certified margins are attached to actual representation-theoretic distinctions.

This theorem is mathematically modest but conceptually essential: it prevents the robustness certificate from collapsing into a purely generic statement about arbitrary duplicated class vectors.

### Final bridge theorem specialized to tropical Satake classifiers

After the generic finite-vector development, package the representation-theoretic version.

Use parameters:
```lean
variable {H : Type _} {κ n : ℕ}
variable (T : H → Fin n → ℝ)
variable (cls : Fin κ → H)
```

Then state:

```lean
theorem tropical_satake_multiclass_certificate
    (hsep : Function.Injective T)
    (a : Fin κ) (φ ψ : Fin n → ℝ) {ε : ℝ}
    (hε₀ : 0 ≤ ε)
    (hcoord : ∀ i, |φ i - ψ i| ≤ ε)
    (hmargin : ∀ b : Fin κ, b ≠ a →
      score (T (cls a)) φ - score (T (cls b)) φ >
        (l1Norm (T (cls a)) + l1Norm (T (cls b))) * ε) :
    ∀ b : Fin κ, b ≠ a →
      score (T (cls a)) ψ > score (T (cls b)) ψ
```

Optionally add the distinct-class hypothesis
```lean
∀ b ≠ a, cls b ≠ cls a
```
if you want to explicitly invoke separation for semantic uniqueness of class data, though it is not needed for the analytic inequality itself.

A stronger “normalized margin” reformulation is also worth proving:

```lean
theorem tropical_satake_multiclass_certificate_normalized
    (a : Fin κ) (φ ψ : Fin n → ℝ) {ε : ℝ}
    (hε₀ : 0 ≤ ε)
    (hcoord : ∀ i, |φ i - ψ i| ≤ ε)
    (hnorm : ∀ b : Fin κ, b ≠ a →
      ε <
        (score (T (cls a)) φ - score (T (cls b)) φ) /
        (l1Norm (T (cls a)) + l1Norm (T (cls b)))) :
    ∀ b : Fin κ, b ≠ a →
      score (T (cls a)) ψ > score (T (cls b)) ψ
```

This is the explicit “constant times normalized Satake separation margin” formulation. The constant is `1` in the coordinatewise `ℓ∞` perturbation model.

Be careful about zero denominators. To avoid division-by-zero side conditions, either:
- keep the unnormalized theorem as primary, or
- assume
  ```lean
  0 < l1Norm (T (cls a)) + l1Norm (T (cls b))
  ```
  for competitors `b ≠ a`.
This positivity follows automatically if `T (cls a) ≠ T (cls b)` and all coordinates vanish only for the zero vector, but proving that in full generality is an extra lemma.

### Why this matters
This theorem turns partial finite GL3 tropical Satake reconstruction into an actual certified robustness mechanism. The analytic part shows that finite tropical test vectors behave like stable multiclass linear score maps under coordinatewise perturbations. The representation-theoretic part shows that the relevant weight vectors come from a separating GL3 test family, so certified margins are not artifacts of an arbitrary embedding: they witness genuine distinctions between finitely supported dominant Hecke data.

This is the right bridge between the tropical certified robustness program and the GL3 Satake program:
- it upgrades finite test-family injectivity into a usable classifier semantics;
- it yields explicit argmax invariance bounds with constant `1`;
- it provides a clean finite-dimensional API for later generalization to GLn, richer Levi moments, and tropical Hecke architectures.

The ideal outcome is a Lean file proving the generic finite-vector lemmas first, then one final theorem specialized to `w = T h` for GL3 tropical Satake data.
