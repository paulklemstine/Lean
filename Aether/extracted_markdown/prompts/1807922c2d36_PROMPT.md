### Proof strategy hints

1. **Entry-point equivalence from minimality.**  
   For `p ∣ fib a → fibEntryPoint p ∣ a`, use `entry_point_divides`.  
   For the converse `fibEntryPoint p ∣ a → p ∣ fib a`, write `a = k * fibEntryPoint p` and use the standard divisibility property of Fibonacci numbers:
   if `m ∣ n` then `Nat.fib m ∣ Nat.fib n`. The file likely already has this as a theorem such as:
   ```lean
   Nat.fib_dvd_fib : m ∣ n → Nat.fib m ∣ Nat.fib n
   ```
   or a local variant. Then use the defining property that `p ∣ Nat.fib (fibEntryPoint p)`.

2. **Prime divisibility of `gcd(F_a,F_b)` via the entry point.**  
   Convert
   ```lean
   p ∣ Nat.gcd (Nat.fib a) (Nat.fib b)
   ```
   into divisibility of each Fibonacci number using:
   ```lean
   Nat.dvd_gcd_iff
   ```
   or by separately applying `Nat.dvd_gcd`, `Nat.gcd_dvd_left`, `Nat.gcd_dvd_right`.  
   Then invoke `prime_dvd_fib_iff_entryPoint_dvd` on both indices and conclude:
   ```lean
   fibEntryPoint p ∣ a ∧ fibEntryPoint p ∣ b
   ↔ fibEntryPoint p ∣ Nat.gcd a b
   ```
   Finally convert back using the same bridge theorem at `Nat.gcd a b`.  
   This is the cleanest way to avoid a full formal proof of `gcd(F_a,F_b)=F_gcd(a,b)` if that identity is not yet available.

3. **Non-primitivity is equivalent to a smaller multiple of the entry point.**  
   If `p ∣ Nat.fib n` and also `p ∣ Nat.fib m` for some `0 < m < n`, then by the bridge,
   `fibEntryPoint p ∣ m` and `fibEntryPoint p ∣ n`; hence `fibEntryPoint p ≤ m < n`, so `fibEntryPoint p < n`.  
   Conversely, if `fibEntryPoint p ∣ n` and `fibEntryPoint p < n`, then taking `m = fibEntryPoint p` gives an earlier Fibonacci term divisible by `p`.  
   This is the exact mechanism turning “prime divisor of the primitive residual” into “primitive prime divisor”.

4. **Primitive residual > 1 implies existence of a primitive prime.**  
   If the file defines a residual integer `R n` by stripping from `fib n` all prime factors already appearing in `fib d` for proper divisors `d ∣ n`, then prove:
   ```lean
   1 < R n → ∃ p, Nat.Prime p ∧ p ∣ R n
   ```
   using `Nat.exists_prime_and_dvd`.  
   Since `R n ∣ Nat.fib n`, any such prime satisfies `p ∣ Nat.fib n`.  
   If `p` divided some earlier `fib m`, use `entry_point_divides` to show `fibEntryPoint p ∣ m`; then one needs the surrounding divisor-stripping lemma to place this prime among the factors already removed from `fib n`, contradicting `p ∣ R n`.

5. **Composite `n > 12`: proper-divisor stripping cannot exhaust `fib n`.**  
   The intended inequality is that the product of contributions from proper divisors is strictly smaller than `fib n`. The nearby context likely already has monotonicity/growth lemmas for Fibonacci numbers such as:
   ```lean
   Nat.strictMono_fib
   Nat.fib_pos
   Nat.fib_le_fib
   ```
   or custom lower bounds. Use the fact that if `d ∣ n` and `d < n` with `n` composite, then `d ≤ n / 2`. Thus every proper-divisor contribution is bounded in terms of `fib (n / 2)` or smaller. Summing exponents / multiplying bounds over proper divisors should then be enough to show the stripped residual is `> 1`.  
   If the file already contains a “proper divisor product bound” lemma, the missing proof is probably just an application of it together with the composite hypothesis.

