# Theorem Cluster A: Thresholds as Extremizers

## Precise Mathematical Statement

Let a monotone symmetric Boolean function on `n` variables be represented by a monotone profile
`p : Fin (n+1) → Bool`
such that
`Monotone p` in the sense that if `i ≤ j` and `p i = true`, then `p j = true`.

Let
- `trueLayers(p) := {k | p k = true}`,
- `m := |trueLayers(p)|`.

Then monotonicity forces `trueLayers(p)` to be a terminal interval, so there is a unique threshold layer `t = n + 1 - m`, and the corresponding threshold function is `Thresh(n,t)`.

The nontrivial theorem to prove is not just classification of profiles, but the exact extremal witness statement:

> **Theorem A1 (Threshold extremality for symmetric witness count).**  
> For every monotone symmetric Boolean function `f` on `n` variables with exactly `m` true layers,
> \[
> |KWWitness(f)| \le |KWWitness(\mathrm{Thresh}(n,n+1-m))|.
> \]
> Moreover, equality holds iff `f = Thresh(n,n+1-m)`.

Because monotone symmetric profiles are terminal intervals, this theorem may look tautological at first glance. It is not, unless the current formalization has already identified every monotone symmetric function canonically with a threshold. If that equivalence is already in the catalog, then **upgrade the theorem** to the genuinely nontrivial layerwise extremal form below.

## Stronger Upgrade if threshold-classification is already formalized

> **Theorem A1'.**  
> Let `A ⊆ Finset.range (n+1)` be any upward-closed set of true layers, and let `W(A)` be the symmetric KW witness count computed from the layer interaction formula. Then among all upward-closed `A` with fixed cardinality `m`, the terminal interval
> \[
> A^\star = \{n+1-m,\dots,n\}
> \]
> maximizes `W(A)`.

This version becomes a real extremal theorem only if your witness-counting formalism allows more general layer-sets or weighted profiles.

# Theorem Cluster B: Majority Witness Entropy

## Precise Mathematical Statement

> \[

# Theorem Cluster C: KW / W₁ Universality for Thresholds

## Precise Mathematical Statement

Define for threshold `Thresh(n,t)`:
- `KW(n,t) := |KWWitness(Thresh(n,t))|`,
- `W₁(n,t) := ∑_{k ≥ t, l < t} Nat.choose n k * Nat.choose n l * |k-l|`.

The conjectural universality statement is:

> **Theorem C1 (subsequential ratio limit / bounded distortion).**  
> For every fixed `α ∈ (0,1)`, there exist constants `cα, Cα > 0` such that for all sufficiently large `n` and `t = ⌊α n⌋`,
> \[
> c_\alpha \, W₁(n,t) \le KW(n,t) \le C_\alpha \, W₁(n,t).
> \]
> In other words, KW witness count and the naive transport cost are asymptotically equivalent up to bounded multiplicative distortion in the bulk regime.

Ambitious stronger target:

> **Theorem C2 (ratio limit).**  
> For every fixed `α ∈ (0,1)`,
> \[
> \frac{KW(n,\lfloor \alpha n \rfloor)}{W₁(n,\lfloor \alpha n \rfloor)} \to \rho(\alpha)
> \]
> for an explicit continuous function `ρ : (0,1) → (1,\infty)`.

Even proving this at `α = 1/2` would be a meaningful result.
