## Assignment: Tropical Source Coding: Min-Plus Rate-Distortion Theory

Mode: **prove**

Prove a genuinely new bridge theorem in idempotent information theory: for finite tropical sources, the optimal coding cost at distortion budget `D` is exactly the min-plus Legendre-Fenchel transform of the distortion profile, and the tropical achievability/converse bounds coincide without a Shannon-style asymptotic gap.

This is not an incremental variant of classical rate-distortion. The breakthrough is to show that in the min-plus semiring, convex duality and coding optimality collapse into a single exact finite theorem. If successful, this opens a new field: **idempotent information theory as exact optimization geometry**, with direct implications for tropical compression, shortest-path semantics, control, large deviations, and energy-based computation.

Prove new, non-trivial theorems. Build on catalog theorems. Minimize sorry.

### Research Direction

Construct a finite tropical rate-distortion theory in which:

- a source is represented by a finite cost landscape rather than a probability law,
- distortion is a cost kernel `d : α → β → ℝ`,
- the tropical rate-distortion function is defined by a min-plus dual transform,
- tropical source coding achieves this bound exactly,
- the converse matches the achievability bound on the nose.

The conceptual claim is bold:

> In the tropical world, coding is not asymptotically approximating a variational optimum; coding *is* the variational optimum.

That exactness is the field-opening phenomenon.

### Precise Theorem Targets

Work with finite types `α`, `β`. Introduce explicit definitions if absent.

#### Definition 1: Tropical source potential
A tropical source is a function `φ : α → ℝ`, interpreted as a cost/potential.

#### Definition 2: Distortion profile
For `y : β`, define the source-to-reproduction cost profile
`ψφd(y) = max'_{x : α} (φ x - d x y)` or, if the existing library aligns better with min conventions, equivalently formulate the dualized version using `inf`/`sup` consistently. Pick one convention and stick to it globally.

#### Definition 3: Tropical rate-distortion function
For distortion budget `D : ℝ`, define
`R_trop(φ,d,D) = inf_{y : β} (ψφd(y) + D)`
or, more invariantly and more powerfully, define it as a min-plus Legendre-Fenchel transform:
`R_trop(D) = sup_{λ : ℝ} ( - λ * D + inf_{y : β} sup_{x : α} (φ x - λ * d x y))`.

You should formalize whichever version is most Lean-feasible first, then prove equivalence of the primal and dual formulas as a separate theorem if possible.

### Primary Breakthrough Theorem

A sharp finite exactness theorem is the right target.

```lean
theorem tropical_rate_distortion_exact
  {α β : Type*} [Fintype α] [Fintype β] [DecidableEq α] [DecidableEq β]
  (φ : α → ℝ) (d : α → β → ℝ) (D : ℝ) :
  tropical_optimal_code_cost φ d D = tropical_rate_distortion φ d D
```

Here:

- `tropical_optimal_code_cost φ d D` should be defined as the optimal cost of any finite tropical code whose worst-case or source-weighted distortion is bounded by `D`;
- `tropical_rate_distortion φ d D` should be the min-plus Legendre-Fenchel transform object.

This theorem is the heart of the project: **achievability = converse exactly**.

### Stronger Duality Theorem

If you can make the transform precise over finite types, prove a finite Fenchel-Moreau style exact duality statement.

```lean
theorem tropical_rate_distortion_dual
  {α β : Type*} [Fintype α] [Fintype β] [DecidableEq α] [DecidableEq β]
  (φ : α → ℝ) (d : α → β → ℝ) (D : ℝ) :
  tropical_rate_distortion φ d D
    = sInf {r : ℝ | ∃ y : β, (∀ x : α, φ x - r ≤ d x y + D)}
```

This formulation may be Lean-friendlier than a full supremum-infimum dual transform while still capturing the exact tropical convexity content.

```lean
def tropicalOptimalCodeCost
```


Then prove equality between two `sInf` expressions. This is much more Mathlib-native.

## 2–3 Proof Strategy Paths

### Strategy A: Finite max-min duality via explicit witness extraction
Most promising for Lean.

1. Define the primal feasible set
   `S = {r | ∃ y, ∀ x, φ x - r ≤ d x y + D}`.
   Then `tropical_rate_distortion φ d D := sInf S`.

2. Show:
   - any feasible code yields a lower bound `r ∈ S`, hence converse;
   - a minimizer `y*` exists because `β` is finite, so the infimum is attained.

3. Convert the attained minimizer into an explicit tropical code and conclude exactness:
   achievability and converse coincide because finite tropical optimization has no approximation layer.

Why this is promising:
- It avoids heavy convex analysis.
- It uses `Fintype`, `Finset.univ`, `sup'`, `inf'`, and witness extraction.
- It aligns best with existing catalog theorems like `source_coding_lower_bound` and `tropical_source_coding_bound`.

### Strategy B: Tropical Legendre-Fenchel duality first, coding theorem second
Most conceptually powerful.

1. Define a tropical conjugate of the distortion family:
   `f*(λ) = inf_y sup_x (φ x - λ * d x y)`.

2. Define
   `R(D) = sup_λ (-λ * D + f*(λ))`.

3. Prove that over finite spaces, the sup/inf are attained and the dual equals the primal feasible-value characterization. Then derive coding exactness as a corollary.

Why this matters:
- This is the theorem that makes the work paradigm-shifting.
- It connects directly to tropical convex analysis, optimal control, and large deviations.
- It is harder in Lean, but if you can get even a finite restricted-λ version, it is already important.

### Strategy C: Reduce to a shortest-path / morphological optimization theorem
Best cross-domain route.

1. Interpret `d x y` as edge weights in a bipartite graph and `φ` as source potentials.
2. Show the rate-distortion value equals the minimum slack needed so that one reproduction node dominates all source nodes.
3. Reinterpret this as a residuation or erosion/dilation identity in tropical algebra.

Why this is exciting:
- It links source coding to shortest paths, mathematical morphology, and max-plus linear algebra.
- It may provide a simpler proof of exactness than information-theoretic arguments.
- It creates a bridge to algorithm design.

Recommended order: **A first, then C, then B**.  
A will likely formalize fastest; C gives the science-fiction bridge; B upgrades the result into a true duality theory.

### Large deviations / zero-temperature statistical mechanics
Classical rate-distortion involves logarithmic asymptotics; tropicalization is the zero-temperature limit where free energies collapse to ground-state costs. Your theorem would formalize exact coding at zero temperature.
