## Core Theorem Family

Let `G` be a finite abelian group. Consider the left regular action of `G` on functions `G → ℂ`, equivalently the permutation representation induced by left translation. The conceptual claim is:

> Every irreducible complex representation of `G` is one-dimensional, the regular representation contains each character exactly once, and every translation-equivariant linear operator is diagonal in the character basis.

This is the mathematically decisive form of “faithful representations lift to linear representations”: the faithful permutation action canonically lifts to a semisimple linear representation whose complete decomposition is controlled by characters.

### Theorem 1: Existence of enough characters / cardinality theorem

A first precise target is the existence of a full family of distinct characters:

```lean
theorem exists_full_character_family
    (G : Type*) [CommGroup G] [Fintype G] :
    ∃ S : Finset (MonoidHom G ℂˣ),
      S.card = Fintype.card G ∧
      ∀ {g h : G}, (∀ χ ∈ S, χ g = χ h) → g = h
```

This is stronger than merely saying “there are characters”: it says the characters separate points, hence detect the group exactly.

### Theorem 2: Regular representation decomposes with multiplicity one

A decomposition theorem should be stated in a Lean-compatible way, even if the exact representation-theoretic API in Mathlib requires adaptation. The intended mathematical content is:

```lean
theorem regular_representation_multiplicity_one

    ∃ S : Finset (MonoidHom G ℂˣ),
      S.card = Fintype.card G ∧
      ∀ χ : MonoidHom G ℂˣ, χ ∈ S ↔
```

### Theorem 3: Character vectors diagonalize convolution / translation-equivariant operators

This is the cross-domain theorem that turns abstract decomposition into a usable spectral algorithm.

Define convolution on functions `G → ℂ`:

```lean
def convFun
    (G : Type*) [CommGroup G] [Fintype G]
    (f v : G → ℂ) : G → ℂ :=
  fun x => ∑ y, f y * v (y⁻¹ * x)
```

Then target:

```lean
theorem character_is_convolution_eigenvector
    (G : Type*) [CommGroup G] [Fintype G]
    (f : G → ℂ) (χ : MonoidHom G ℂˣ) :
    ∃ λ : ℂ, ∀ x,
      convFun G f (fun t => ((χ t : ℂˣ) : ℂ)) x
        = λ * ((χ x : ℂˣ) : ℂ)
```

And ideally identify the eigenvalue explicitly as the Fourier coefficient:

```lean
theorem convolution_eigenvalue_formula
    (G : Type*) [CommGroup G] [Fintype G]
    (f : G → ℂ) (χ : MonoidHom G ℂˣ) :
    let λ := ∑ y, f y * (((χ y : ℂˣ) : ℂ)⁻¹)
    ∀ x,
      convFun G f (fun t => ((χ t : ℂˣ) : ℂ)) x
        = λ * ((χ x : ℂˣ) : ℂ)
```

This theorem is the real scientific payload: it turns finite abelian representation theory into certified spectral analysis.

## Proof Strategy Architecture

You must provide at least 2–3 proof routes in the file comments or accompanying paper, and pursue the most promising one formally.

### Strategy A: Direct harmonic-analysis construction from character sums
1. Define character vectors `vχ : G → ℂ` by `vχ x = χ x`.
2. Show directly that left translation acts by scalar multiplication:
   `vχ (g * x) = χ g * vχ x`.
3. Prove orthogonality of distinct characters using finite sums and cancellation.
4. Deduce linear independence and cardinality bounds, then conclude the regular representation decomposes into exactly `|G|` one-dimensional eigenspaces.

**Why promising:** This is constructive, algorithmic, and naturally leads to the convolution eigenvalue theorem. It also gives the demo and computational method almost for free.

### Strategy B: Group algebra / semisimple algebra route
1. Work in the group algebra `ℂ[G]`, identified with `G →₀ ℂ` or `G → ℂ` in the finite case.
2. Use commutativity of `G` to show `ℂ[G]` is a finite-dimensional commutative semisimple algebra.
3. Identify primitive idempotents with characters and split the regular module into minimal ideals.
4. Prove multiplicity-one decomposition by dimension count.

**Why promising:** Conceptually strongest and closest to the literature, but may require more Mathlib infrastructure around finite-dimensional algebras and semisimplicity.

### Strategy C: Reduction to cyclic decomposition + explicit tensor/product characters
1. Use the structure theorem for finite abelian groups to decompose `G` into cyclic factors.
2. Construct characters factorwise using roots of unity in `ℂˣ`.
3. Show the full character set is the product of the duals of the cyclic factors.
4. Derive separation, cardinality, and regular decomposition by explicit enumeration.

**Why promising:** Very explicit and computationally testable; especially good for `demo.py`.
**Risk:** Requires formalizing enough of the finite abelian structure theorem and explicit roots of unity machinery.

### Recommended path
Pursue **Strategy A** as the main formal proof, with **Strategy C** as the computational verification route for small groups. Strategy A is most likely to produce the deepest theorems with manageable Lean complexity while also yielding a verified algorithm.
