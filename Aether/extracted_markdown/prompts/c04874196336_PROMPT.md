## Context

## Tasks

### Task 1: Complete the Synthesis
Create a working synthesis that combines:
- The unit-group bridge: `prime_sub_one_dvd_of_forall_units_pow_eq_one` (from KorseltUnitsBridge)
- The converse: for squarefree n, if for every prime p | n we have (p-1) | (n-1), then ∀ u : (ZMod n)ˣ, u^(n-1) = 1
- The existing catalog result: `korselt_iff_absFermatPsp`

Prove the equivalence:
```
theorem unit_pow_iff_isKorselt {n : ℕ} [NeZero n] (hsq : Squarefree n) :
    (∀ u : (ZMod n)ˣ, u ^ (n - 1) = 1) ↔ IsKorselt n
```

### Task 2: Carmichael Lambda ↔ Korselt Equivalence
Define or use Mathlib's `Nat.carmichael` (the Carmichael lambda function, i.e., exponent of (ZMod n)ˣ) and prove:

```
theorem carmichael_lambda_iff_isKorselt {n : ℕ} [NeZero n] (hsq : Squarefree n) (hn : Odd n) :
    Nat.carmichael n ∣ (n - 1) ↔ IsKorselt n
```

The key insight: for squarefree n = p₁ · p₂ · ... · pₖ, the exponent of (ZMod n)ˣ is lcm(p₁-1, p₂-1, ..., pₖ-1). Korselt's condition says each (pᵢ - 1) | (n - 1), which is equivalent to lcm(p₁-1, ..., pₖ-1) | (n - 1).

### Task 3: Computational Corollary
Prove that checking Carmichael-ness reduces to computing the Carmichael lambda function:
```
theorem isCarmichael_iff_carmichael_lambda_dvd {n : ℕ} [NeZero n] (hsq : Squarefree n) (hn : Odd n) :
    IsCarmichael n ↔ Nat.carmichael n ∣ (n - 1)
```
