## Precise theorem targets

### Target A: Admissible tuple obstruction theorem
Define admissibility of a finite set of integer shifts and prove the local obstruction criterion.

**Mathematical statement**
For a finite set `H : Finset ℕ`, define
`Admissible H : Prop := ∀ p : ℕ, Nat.Prime p → ∃ a : ℕ, a < p ∧ ∀ h ∈ H, (a + h) % p ≠ 0`.

Prove:
> If `¬ Admissible H`, then there exists a prime `p` such that every residue class modulo `p` is hit by some `-h mod p` with `h ∈ H`.

This is elementary but foundational: it makes admissibility a finite local condition, the exact combinatorial gateway to Dickson/Hardy–Littlewood/Maynard.

**Lean 4 type signature**
```lean
def Admissible (H : Finset ℕ) : Prop :=
  ∀ p : ℕ, Nat.Prime p →
    ∃ a : ℕ, a < p ∧ ∀ h, h ∈ H → (a + h) % p ≠ 0

theorem not_admissible_iff_full_cover
    (H : Finset ℕ) :
    ¬ Admissible H ↔
      ∃ p : ℕ, Nat.Prime p ∧
        ∀ a : ℕ, a < p →
          ∃ h, h ∈ H ∧ (a + h) % p = 0
```

This theorem is not the twin prime conjecture, but it is the exact local obstruction formalism that all prime tuple conjectures use.

### Target C: Infinite primes imply infinitely many semiprime-bounded pairs
A reachable unconditional theorem inspired by bounded-gap architecture:

> There are infinitely many `n` such that at least two elements of `{n, n+2, ..., n+2k}` are greater than `1` and pairwise not all ruled out by small-prime local obstructions.

A stronger and cleaner version is preferable if you can prove it. For example:

**Lean 4 candidate theorem**
```lean
theorem infinitely_many_coprime_shifts
    (H : Finset ℕ) (h0 : Admissible H) :
    ∀ m : ℕ, ∃ n ≥ m, ∀ p : ℕ, Nat.Prime p → p ≤ H.card →
      ∃ h, h ∈ H ∧ Nat.Coprime (n + h) p
```

This is a CRT-driven theorem: for any admissible tuple, one can find infinitely many translates avoiding all small prime obstructions simultaneously. It is not yet primality, but it formalizes the local-to-global setup of sieve theory.

This would be a substantial and honest theorem.

### Target D: Conditional bounded gaps theorem schema
Formalize the theorem as a **parameterized implication** from a distribution hypothesis to bounded gaps.

You are not expected to formalize the full Bombieri–Vinogradov or Elliott–Halberstam immediately; instead create an abstract hypothesis class.

**Mathematical statement**
> If a suitable level-of-distribution hypothesis `LevelDistrib θ` and a Maynard positivity inequality hold for an admissible `k`-tuple `H`, then there exist infinitely many `n` such that at least two of `n + h` are prime; hence prime gaps are bounded by `max(H) - min(H)` infinitely often.

**Lean 4 schematic signature**
```lean
structure LevelDistribHypothesis : Prop where
  θ : ℝ
  hθ : 0 < θ
  bound : Prop -- replace later by precise discrepancy estimate

structure MaynardPositivity (H : Finset ℕ) : Prop where
  kappa : ℝ
  hk : 0 < kappa
  positivity : Prop -- replace later by explicit weighted inequality

theorem bounded_gaps_of_abstract_maynard
    (H : Finset ℕ)
    (hAdm : Admissible H)
    (hLD : LevelDistribHypothesis)
    (hPos : MaynardPositivity H) :
    ∃ B : ℕ, B ≤ H.max' (by simpa using Finset.card_pos.mpr (by
      exact ⟨0, by sorry⟩)) ∧
      ∃ᶠ n in Filter.atTop,
        ∃ a b : ℕ, a ∈ H ∧ b ∈ H ∧ a ≠ b ∧
          Nat.Prime (n + a) ∧ Nat.Prime (n + b)
```

You may refine the bound statement to use `sup H - inf H` instead of `max'` if cleaner.

This would be a major formalization achievement because it factors modern bounded-gap arguments into reusable components.

## Proof strategies

### Strategy 1: Local obstruction + CRT infrastructure
Most promising for immediate success.

1. Define `Admissible H` via avoided residues modulo each prime.
2. Prove `not_admissible_iff_full_cover` by direct negation unfolding.
3. Use the Chinese Remainder Theorem over finitely many primes to show:
   for any admissible `H` and any finite prime set `P`, there exist infinitely many `n` such that no `n+h` is divisible by any `p ∈ P`.
4. Package this as a “sieve pre-processing theorem.”

Why promising: almost all of this is finitary and should be within Mathlib’s current number-theoretic and modular arithmetic toolkit.

### Strategy 2: Abstract GPY/Maynard positivity layer
Most visionary, medium risk.

1. Introduce abstract structures representing:
   - sieve weights,
   - first and second moment estimates,
   - positivity criterion implying at least two primes in a tuple.
2. Formalize the purely combinatorial deduction:
   if weighted average of prime counts exceeds weighted support count threshold, then some `n` has at least two prime translates.
3. Separate all hard analytic estimates into assumptions.

Why promising: it gives a theorem of genuine conceptual depth without requiring immediate formalization of all deep analytic estimates. It creates the exact API future work needs.

## Cross-domain connections

This project should not live only inside classical number theory. Make at least one bridge theorem or conceptual bridge to another domain.

### 1. Additive combinatorics
Admissible tuples are finite sets avoiding full residue coverage modulo each prime. This is a modular covering problem. Connect admissibility to:
- covering systems,

- density increment heuristics.

Possible theorem direction:
```lean

    (H : Finset ℕ) {p : ℕ} (hp : Nat.Prime p) (hcard : H.card < p) :
    ∃ a : ℕ, a < p ∧ ∀ h, h ∈ H → (a + h) % p ≠ 0
```
Then derive global admissibility under suitable cardinal bounds against all small primes.

### 2. Probability / information theory
Sieve weights behave like probability distributions over integers. Define normalized finite-support weights and prove expectation inequalities abstractly. This recasts Maynard’s method as a constrained optimization problem.

Application keywords:
**sieve optimization, variational methods, entropy heuristics, sparse event amplification**

### 3. Formal complexity theory
Admissibility checking is algorithmic. For finite tuples `H`, one can decide admissibility by checking primes up to `|H|`.

Potential theorem:
```lean
theorem admissible_decidable_by_small_primes
    (H : Finset ℕ) :
    Admissible H ↔
      ∀ p : ℕ, Nat.Prime p → p ≤ H.card →
        ∃ a : ℕ, a < p ∧ ∀ h, h ∈ H → (a + h) % p ≠ 0
```
This is a deep and useful finite reduction, turning an a priori infinite condition into a finite computation. If established, it becomes the computational gateway for exhaustive admissible tuple search.

## Concrete theorem candidates beyond the basics

### Finite-prime reduction for admissibility
This is especially important and realistically provable.

**Mathematical statement**
> A finite set `H` is admissible iff for every prime `p ≤ |H|`, the reductions of `H` modulo `p` do not cover all residue classes.

**Lean target**
```lean
theorem admissible_iff_check_primes_le_card
    (H : Finset ℕ) :
    Admissible H ↔
      ∀ p : ℕ, Nat.Prime p → p ≤ H.card →
        ∃ a : ℕ, a < p ∧ ∀ h, h ∈ H → (a + h) % p ≠ 0
```

Why important: this is standard prime tuple folklore, but formalizing it gives a finite certification algorithm for admissibility.

---

### CRT realization theorem
**Mathematical statement**
Let `H` be admissible and `P` a finite set of primes. Then there exists `n` such that for every `h ∈ H` and `p ∈ P`, `p ∤ n+h`.

**Lean target**
```lean
theorem exists_translate_avoiding_prime_set
    (H P : Finset ℕ)
    (hAdm : Admissible H)
    (hPprime : ∀ p, p ∈ P → Nat.Prime p) :
    ∃ n : ℕ, ∀ h, h ∈ H → ∀ p, p ∈ P → ¬ p ∣ (n + h)
```

This is the exact local sieve setup theorem.

---

### Infinite realization theorem
Strengthen the previous result to infinitely many such `n` using arithmetic progression lifting.

**Lean target**

```lean
theorem infinitely_many_translates_avoiding_prime_set

    (hAdm : Admissible H)
    (hPprime : ∀ p, p ∈ P → Nat.Prime p) :
    Set.Infinite {n : ℕ | ∀ h, h ∈ H → ∀ p, p ∈ P → ¬ p ∣ (n + h)}
```

This is a strong unconditional theorem with real sieve content.
