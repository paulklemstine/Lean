## Assignment: Compositional Witness Synthesis — From Existence to Algorithm

### The Deep Question

The catalog establishes that `typeStateBound(A)` is a *tight* upper bound on `canonicalQuotientSize(d, t)` for any inhabitant `t : A`. But existence is not construction. The profound question is: **can we algorithmically realize the bound-achieving witness, and does the synthesis itself have polynomial complexity?** This is the algorithmic analog of the transition from "every bounded sequence has a convergent subsequence" to "here is the subsequence" — from analysis to constructive mathematics.

### Proof Strategies

**Strategy A: Structural Recursion with Fan-Out Composition.**
Define `synthesizeWitness` by structural recursion on `A`. Base case: the unique inhabitant of `o`. Arrow case: given `synthesizeWitness A = (t_A, d_A)` and `synthesizeWitness B = (t_B, d_B)`, construct `λx. (t_B[x ↦ fan_out(x, d_A, t_A)])` where `fan_out` creates `d_A` parallel copies of `x` fed into `t_A`. This mirrors the proof of `typeStateBound_tight` from Direction 1. The fan-out pattern generates product-sized reduction diamonds — each of the `d_A` copies reduces independently, creating `d_A × d_B` distinct reduction paths.

*Why promising:* Directly mirrors the inductive structure already proven to achieve the bound. The composition is canonical and deterministic.

**Strategy B: Dynamic Programming on Subtypes.**
For type `A₁ ⟶ (A₂ ⟶ ... ⟶ Aₙ ⟶ o)`, compute optimal witnesses for each `Aᵢ` and combine via a "parallel composition" operator `⊗`. The key insight: `canonicalQuotientSize` is *multiplicative* under this composition, so `typeStateBound(A ⟶ B) = typeStateBound(A) × typeStateBound(B)` (up to a correction factor). Cache subproblem solutions and compose.

*Why promising:* Avoids recomputation; naturally yields polynomial time. But requires proving the multiplicative structure of `canonicalQuotientSize` under `⊗`, which is a deep combinatorial fact.

**Strategy C: Reduction to Normal Form Enumeration + Selection.**
Enumerate β-normal forms of type `A` up to size bound, compute `canonicalQuotientSize` for each, and select the maximum. By the finite-generation property of normal forms, this terminates. Polynomial time follows from the bound on the number of normal forms (Statman, 1979).

*Why less promising:* Enumeration is conceptually simple but obscures the compositional structure. The polynomial bound on normal forms of a given type is itself a non-trivial result.

**Recommended path:** Strategy A for the main construction, with Strategy B's multiplicative lemma as a key intermediate result.

### Cross-Domain Connections

1. **Information Theory → Lambda Calculus:** The `witness_entropy_connection` theorem establishes that the size of a bound-achieving witness is bounded below by `2^H`, where `H` is the Shannon entropy of the reduction distribution. This is a *source coding theorem for lambda terms*: the minimal witness size equals the information content of the type's reduction space. This bridges the combinatorics of β-reduction to classical information theory.

2. **Concurrent Computation → Reduction Diamonds:** The fan-out composition creates independent parallel reduction threads. The number of distinct interleavings (reduction sequences) equals the product of the sub-witness complexities — precisely the structure studied in true concurrency semantics (Mazurkiewicz traces, Pratt's pomsets). The `typeStateBound` is thus a *concurrency measure*.

3. **Cryptography → Witness Synthesis:** If synthesizing bound-achieving witnesses is polynomial, then the *gap* between `typeStateBound` and average `canonicalQuotientSize` defines a natural one-way function: finding the bound-achiever is easy, but finding *any other* term with high `canonicalQuotientSize` may be hard. This connects to the complexity of pseudorandom generators in untyped lambda calculus.

### Conjecture with Testable Prediction

**Conjecture (Quadratic Witness Bound):** For all inhabited simple types `A`, the bound-achieving witness `t` satisfies `termSize(t) ≤ C · typeStateBound(A)²` for an absolute constant `C`.

**Computational test:** For all types up to depth 5 (~50 nodes, ~10,000 inhabited types), run `synthesizeWitness` and compute the ratio `termSize(t) / typeStateBound(A)²`. If the conjecture holds, this ratio converges as depth increases. If it diverges, the exponent is > 2.

**Falsification:** Find a type `A` at depth ≤ 6 where `termSize(t) > 10 · typeStateBound(A)²`.
