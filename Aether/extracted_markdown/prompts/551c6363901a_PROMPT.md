### The Vision: Weighted Curvature as Discrete Optimal Transport

The unweighted curvature flow on triangulations converges to constant curvature (proven in catalog). But nature and engineering demand *heterogeneity*: finite element meshes need finer resolution near singularities, network flows prioritize certain nodes, and statistical mechanical systems have non-uniform energy landscapes. The weights $w_i > 0$ are not decoration — they reframe the entire problem as a **discrete Wasserstein gradient flow**.

**The deep insight**: The weighted curvature distribution $\mu_w(i) = w_i / W$ (where $W = \sum w_i$) is a discrete probability measure on the vertex set. The weighted curvature flow is precisely the gradient flow of the functional $V_w = \mathrm{Var}_{\mu_w}(K)$ in the 2-Wasserstein geometry. The condition number $\kappa = w_{\max}/w_{\min}$ controls the *Lojasiewicz constant* of this functional — it is the discrete analog of the Poincaré constant for the weighted graph.

This opens a new field: **discrete optimal transport on curvature spaces**, with applications to adaptive mesh generation, network load balancing, and discrete Ricci flow with conformal factors.

#### Definition 1: Weighted Curvature Structure

```lean
structure WeightedTriangCurv (n : ℕ) (hn : 0 < n) where
  K : Fin n → ℝ          -- combinatorial curvature at each vertex
  w : Fin n → ℝ          -- positive weights
  w_pos : ∀ i, 0 < w i
  K_bounded : ∀ i, K i ∈ Icc (-2) 6  -- curvature bounds for planar triangulations
```

#### Definition 2: Weighted Mean and Variance

```lean
def weightedCurvMean {n : ℕ} {hn : 0 < n} (wt : WeightedTriangCurv n hn) : ℝ :=
  (∑ i : Fin n, wt.w i * wt.K i) / (∑ i : Fin n, wt.w i)

def weightedCurvVar {n : ℕ} {hn : 0 < n} (wt : WeightedTriangCurv n hn) : ℝ :=
  (∑ i : Fin n, wt.w i * (wt.K i - weightedCurvMean wt) ^ 2) / (∑ i : Fin n, wt.w i)

def conditionNumber {n : ℕ} {hn : 0 < n} (wt : WeightedTriangCurv n hn) : ℝ :=
  (Finset.univ.sup' Finset.univ_nonempty wt.w) /
  (Finset.univ.inf' Finset.univ_nonempty (fun i => wt.w i))
```

**Proof Strategy A (Extremal Analysis — Recommended):** A single edge flip changes curvature at exactly 4 vertices (the two vertices gaining/losing an edge and their two common neighbors). The change in $V_w$ is a rational function of the $w_i$ values at these 4 vertices. Minimize this over all valid weight configurations subject to $w_{\max}/w_{\min} = \kappa$. The minimum occurs when the vertex with extreme curvature has minimum weight, giving the $\delta/\kappa$ bound.

**Proof Strategy B (Convexity):** $V_w$ is convex in $K$ for fixed $w$. The flow step is a bounded perturbation of $K$. Use the weighted Poincaré inequality (which has constant $O(\kappa)$) to lower-bound the decrease.

**Proof Strategy C (Direct Computation + Positivity):** Compute $\Delta V_w$ explicitly as a function of the 4 affected vertices' weights and curvatures. Factor as sum of weighted squares times $(1/\kappa)$-bounded coefficients.
