### Theorem A: Width-to-Size Conversion for Tree Resolution

Let `F` be a CNF on `n` variables with initial maximal clause width `w₀`. Let `w*` denote the minimum width of any tree-resolution refutation of `F`. Prove that any tree-resolution refutation of `F` has size at least exponential in `w* - w₀`, via a certified counting bound on the number of width-bounded clauses.

A precise target statement, adapted to what is likely formalizable in Lean, is:

```lean
/-- Number of distinct clauses over `n` variables of width at most `w`. -/
def clauseSpaceBound (n w : ℕ) : ℕ := ∑ k in Finset.range (w + 1), Nat.choose n k * 2^k

/-- Max initial width of clauses in a CNF. -/
def CNF.maxClauseWidth (F : CNF α) : ℕ := Finset.sup F Clause.width

/-- Minimum width among tree-resolution refutations of `F`. -/
def minResWidth (F : CNF α) : ℕ := sInf {w | ∃ T : ResTree α, T.refutes F ∧ T.width ≤ w}

/-- Minimum size among tree-resolution refutations of `F`. -/
def minResSize (F : CNF α) : ℕ := sInf {s | ∃ T : ResTree α, T.refutes F ∧ T.size ≤ s}

theorem width_to_size_tree_lower_bound
  {α : Type} [Fintype α] [DecidableEq α]
  (F : CNF α) :
  minResSize F ≥ clauseSpaceBound (Fintype.card α) (minResWidth F) := by
  ...
```

This exact inequality may need refinement depending on the catalog’s `ResTree.size` and `Clause.width` conventions. If the direct `sInf` formulation is awkward over `ℕ`, replace it with the equivalent universal form:

```lean

  (F : CNF α) (T : ResTree α)
  (hT : T.refutes F) :
  clauseSpaceBound (Fintype.card α) T.width ≤ T.size := by
```

and then derive the min-size corollary separately.

## Proof Strategy Architecture

You must pursue at least 2-3 proof routes in parallel and choose the strongest one after testing in Lean.

### Strategy A: Direct Counting Through `allClauses`  
**Most promising for the first complete Lean proof.**

1. Use `ResTree.card_allClauses_le_size` to show that the number of distinct clauses appearing in a derivation is at most the derivation size.
2. Prove that every clause in `T.allClauses` has width at most `T.width`, using `ResTree.width_le_maxWidth_allClauses` and any needed local lemmas.
3. Inject `T.allClauses` into the finite type of width-`≤ T.width` clause codes, then apply the combinatorial bound
   \[
   |T.allClauses| \le \sum_{k \le T.width}\binom{n}{k}2^k.
   \]
4. Rearrange to obtain a lower bound on `T.size`.

Why this is strongest: it directly leverages the catalog’s existing certified structure, avoids asymptotic reasoning until the final corollary, and isolates the only hard new ingredient into a clean finite combinatorics lemma.

### Strategy B: Support Projection + Signed Set Encoding  
**Best if the clause datatype is awkward to count directly.**

1. Map each clause to a pair `(support, polarity-on-support)`.
2. Show this map is injective for well-formed clauses.
3. Count supports of size `k` by `choose n k`, and count signings by `2^k`.
4. Sum over `k ≤ w`.

Why it is valuable: this route is datatype-agnostic and turns the whole theorem into a finite-set combinatorics problem. It also gives the cleanest cross-domain interpretation as a coding theorem for clauses.

### Strategy C: Entropy Compression / Information-Theoretic Rephrasing  
**Most visionary; may be harder to complete fully, but should shape the exposition and future work.**

1. Interpret a width-`w` clause as a message carrying at most `log₂(∑_{k≤w} choose(n,k)2^k)` bits.
2. Show that any derivation reaching contradiction must realize a family of distinguishable clause states whose cardinality is bounded by the clause-space count.
3. Convert this to a lower bound on derivation size.

Why this matters: it reframes proof complexity as information flow in symbolic systems. Even if the final formal theorem is combinatorial, this perspective could launch a whole program connecting proof complexity with entropy inequalities, coding theory, and statistical mechanics.

## Cross-Domain Connections You Must Make Explicit

This project is not just proof complexity. It is a bridge between multiple fields.

### 1. Combinatorics
The clause-counting lemma is a finite combinatorics theorem about signed subsets. It is structurally analogous to counting Hamming balls and antichains.

### 2. Information Theory
A clause of width `w` over `n` variables carries bounded information: choice of support plus sign pattern. The width-to-size theorem can be read as an entropy barrier: narrow proofs cannot compress contradiction beyond a certain limit.

### 3. Coding Theory
The support/sign encoding of clauses resembles a variable-length codebook. Lower bounds on proof size become lower bounds on codebook cardinality under width constraints.

### 4. Statistical Physics
Resolution derivations can be viewed as trajectories through a constrained state space. Width acts like an energy cap; exponential size lower bounds express an entropic bottleneck. This analogy should appear in `RESEARCH_PAPER.md` and `ARTICLE.md`.

### 5. Complexity Theory
This is a certified impossibility result. A full formalization would be a template for mechanizing lower bounds in circuit complexity, communication complexity, and algebraic proof systems.
