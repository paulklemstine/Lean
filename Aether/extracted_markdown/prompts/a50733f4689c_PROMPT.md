## Precise theorem program

Let `Act := Fin 2`, viewed as actions `{0,1}` corresponding to `{a,b}`. Let infinite traces be streams `Stream Act`. For each `a : Act`, define prefix-cons
\[
\mathrm{cons}_a : Stream\;Act \to Stream\;Act,\qquad s \mapsto Stream.cons\;a\;s.
\]
For predicates `P : Stream Act → Prop`, define pullback
\[
\mathrm{pre}_a(P)(s) := P(\mathrm{cons}_a\, s).
\]

Your task is to define stream-level existential/universal modalities and prove they form adjoints to `pre_a`.

### Theorem 1: Stream prefix adjunction

Define, for `a : Act`,
\[
\Diamond_a P := \{\, t \mid \exists s,\; t = \mathrm{cons}_a(s)\land P(s)\,\},
\qquad
\Box_a P := \{\, t \mid \forall s,\; t = \mathrm{cons}_a(s)\to P(s)\,\}.
\]

Prove the Galois connection / adjunction laws:
\[
\Diamond_a P \subseteq Q \iff P \subseteq \mathrm{pre}_a(Q),
\]
\[
\mathrm{pre}_a(Q) \subseteq P \iff Q \subseteq \Box_a(P).
\]

### Suggested Lean 4 signatures

You may adapt naming, but the mathematical content should match:

```lean
def StreamPred (Act : Type) := Stream Act → Prop

def prefixPull (a : Act) : StreamPred Act → StreamPred Act :=
  fun P s => P (Stream.cons a s)

def diamondStream (a : Act) : StreamPred Act → StreamPred Act :=
  fun P t => ∃ s, t = Stream.cons a s ∧ P s

def boxStream (a : Act) : StreamPred Act → StreamPred Act :=
  fun P t => ∀ s, t = Stream.cons a s → P s

theorem diamondStream_left_adjoint
    {Act : Type} (a : Act) (P Q : StreamPred Act) :
    (∀ t, diamondStream a P t → Q t) ↔
    (∀ s, P s → prefixPull a Q s) := by
  sorry

theorem boxStream_right_adjoint
    {Act : Type} (a : Act) (P Q : StreamPred Act) :
    (∀ s, prefixPull a Q s → P s) ↔
    (∀ t, Q t → boxStream a P t) := by
  sorry
```

These are not enough by themselves; they are the base of the infinite-trace theory.

### Theorem 2: Compatibility with finite-prefix cylinder predicates

Define a predicate on streams determined by a finite trace `w : List Act` and a tail predicate `R` or, more canonically, define **cylinder predicates**:
\[
\mathrm{Cyl}(w,U) := \{ s \mid \text{the prefix of } s \text{ is } w \text{ and the tail after } |w| \text{ lies in } U \}.
\]

Then prove that the stream modalities extend the finite-trace modalities from the catalog along cylinders. Informally:
\[
\Diamond_a(\mathrm{Cyl}(w,U)) = \mathrm{Cyl}(a::w,U),
\]
and similarly for pullback/box in the appropriate direction.

This theorem is where you **build on**:

- `Pythagorean/TemporalAdjunction/Theorems.lean`
  - `diamond_left_adjoint`
  - `box_right_adjoint`

The goal is not to reprove those facts, but to show that the stream-level operators **restrict to / are compatible with** the finite-trace ones on prefix-generated predicates.

### Suggested Lean shape

```lean
-- or an equivalent finite-prefix notion

theorem diamondStream_on_cylinder
    {Act : Type} (a : Act) (w : List Act) (U : StreamPred Act) :
    diamondStream a (cylinderPred w U) =

  sorry
```

```lean
theorem diamondStream_on_cylinder_iff
    {Act : Type} (a : Act) (w : List Act) (U : StreamPred Act) (s : Stream Act) :
    diamondStream a (cylinderPred w U) s ↔
      cylinderPred (a :: w) U s := by
  sorry
```

This is the theorem that realizes the phrase “diamond and box on infinite traces arise as colimit/limit shadows of finite-trace adjunctions.”

### Theorem 3: Recovery of EX / AX on Kripke structures

Define a finite Kripke structure with state type `σ`, transition relation `R : σ → σ → Prop`, and valuation `V`. Define path semantics by streams of states or streams of actions/states. Then prove that your one-step coalgebraic modalities coincide with standard temporal semantics:

\[
s \models EX\,\varphi \iff \exists t,\; R\,s\,t \land t \models \varphi,
\]
\[
s \models AX\,\varphi \iff \forall t,\; R\,s\,t \to t \models \varphi.
\]

The categorical claim is that `EX` and `AX` are exactly the left/right adjoints to relational pullback along the transition map.

### Suggested Lean signatures

```lean
  step : σ → σ → Prop
  lab  : σ → Prop  -- simplify if needed; can generalize later

  fun s => ∃ t, K.step s t ∧ P t

def AX {σ : Type} (K : Kripke σ) (P : σ → Prop) : σ → Prop :=
  fun s => ∀ t, K.step s t → P t

  fun s => ∀ t, K.step s t → P t
-- or use relational inverse image in the form most natural for your setup

theorem EX_left_adjoint_stepPull
    {σ : Type} (K : Kripke σ) (P Q : σ → Prop) :
    (∀ s, EX K P s → Q s) ↔
    (∀ t, P t → AX K Q t) := by
  sorry
```

You may prefer a more standard relational-pullback formulation. What matters is the exact semantic equivalence with temporal operators on finite models.

Then instantiate and **compute nontrivial examples** on Kripke structures with at most 4 states, as demanded by the test. Do not make this purely definitional; prove small but meaningful semantic equivalences.

## Proof strategy architecture

You must pursue 2–3 proof routes and choose the most robust one.

### Strategy A: Direct predicate-level adjunction proof
1. Define `diamondStream` and `boxStream` explicitly via existential/universal quantification over stream decompositions.
2. Prove the adjunctions by unfolding definitions, using `constructor`, `intro`, `rcases`, and careful rewriting with `Stream.cons`.
3. Then prove cylinder compatibility by induction on finite prefixes.

**Why this is promising:** It is the shortest path to nontrivial verified mathematics and will yield the first deep theorems with minimal categorical overhead.

---

### Strategy B: Finite-prefix approximation / inverse-system viewpoint
1. Define stream predicates approximated by all finite prefixes.
2. Show the finite-trace adjunctions commute with prefix extension maps.
3. Deduce that the induced operator on cylinder predicates agrees with the stream operator.

**Why this is deeper:** This realizes the “limit/colimit” intuition from the conjecture, not merely the one-step stream formulas. It gives genuine mathematical evidence that infinite-trace modalities are assembled from finite ones.

**Most promising hybrid:** Use Strategy A to establish the basic adjunction theorems cleanly, then Strategy B for the compatibility theorem that links back to the catalog.

---

### Strategy C: Relational/Kripke semantics first
1. Define `EX` and `AX` relationally on states.
2. Prove the adjunction laws there first.
3. Transport these to stream semantics via path unfolding.

**Why useful:** This gives immediate temporal-logic significance and a concrete test bed on small finite structures. It also creates the cross-domain bridge to model checking.
