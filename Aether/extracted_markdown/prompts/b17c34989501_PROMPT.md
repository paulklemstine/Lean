## Core Mathematical Vision

A Sudoku instance should be represented as a finite CSP over a \(9 \times 9\) grid with values in `Fin 9`. A full assignment has an integer tropical cost equal to the number of violated row/column/box/distinctness constraints plus clue mismatches. The min-plus structure appears because global feasibility is encoded by taking tropical sums of local penalties, and local compatibility updates are naturally expressed using `min`.

The breakthrough target is to prove a hierarchy of results:

1. **Exact tropical encoding theorem**: zero tropical cost is equivalent to Sudoku satisfiability.
2. **Monotone propagation theorem**: adding clues cannot decrease local tropical lower bounds, and propagation computes a canonical lower-bound refinement.
3. **Criticality / hardness surrogate theorem**: instances near the boundary between forced inconsistency and abundant solutions maximize a formally defined residual ambiguity measure.
4. **Polynomial-time solvability of propagation closure**: the propagation operator stabilizes in polynomially many steps because the state space is finite and each step strictly shrinks candidate sets.

Do not overclaim “P=NP for Sudoku.” The boldness must come from proving a rigorous tropical analogue of phase-transition behavior, not from asserting unformalized complexity miracles. The strongest formally reachable version is likely a **finite-size criticality theorem** for a random or parameterized model, or a deterministic theorem identifying a tropical boundary statistic that certifies maximal propagation difficulty.

## Precise Formalization Targets

### 1. Basic Sudoku objects

Use concrete finite types. A clean starting point is:

- `Cell := Fin 9 × Fin 9`
- `Digit := Fin 9`
- `Assignment := Cell → Digit`
- `ClueSet := Finset (Cell × Digit)` or a partial assignment `Cell → Option Digit`

Define row, column, and box compatibility predicates. For boxes, use integer division on `Fin 9` coerced to `Nat`.

### 2. Tropical cost function

Define local penalties in `Nat`, each equal to `0` when a local constraint is satisfied and `1` otherwise. Then define global cost by summing all local penalties. The tropical aspect is not merely “sum penalties”; it is that local inference and lower bounds are computed by min-plus aggregation over candidate digits and neighboring constraints.

A robust target is:

```lean
def SudokuAssignment := (Fin 9 × Fin 9) → Fin 9

def cluePenalty (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (A : SudokuAssignment) : Nat := ...

def rowViolationCount (A : SudokuAssignment) : Nat := ...
def colViolationCount (A : SudokuAssignment) : Nat := ...
def boxViolationCount (A : SudokuAssignment) : Nat := ...

def tropicalSudokuCost
    (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (A : SudokuAssignment) : Nat :=
  cluePenalty clues A + rowViolationCount A + colViolationCount A + boxViolationCount A
```

Then prove the exactness theorem.

### 3. Exact theorem statement

A first flagship theorem should be:

```lean
def SudokuValid
    (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (A : SudokuAssignment) : Prop := ...

theorem tropicalSudokuCost_eq_zero_iff
    (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (A : SudokuAssignment) :
    tropicalSudokuCost clues A = 0 ↔ SudokuValid clues A := ...
```

This is the formal hinge: it identifies satisfiability with zero tropical energy.

To make this theorem nontrivial, ensure each violation count is genuinely combinatorial, e.g. counting repeated digits in units via `Finset`/pairwise distinctness or counting conflicting pairs.

A more structurally elegant alternative is to define penalties over unordered conflicting pairs:

```lean

```

and similarly for columns/boxes, then sum indicator penalties. This often makes the `= 0 ↔ no conflicts` proof cleaner.

### Theorem B: Monotonicity under adding clues

If `clues₁ ⊆ clues₂`, then every assignment has no smaller clue-penalty under `clues₂`, and the minimum tropical cost is monotone.

```lean
theorem tropicalSudokuCost_mono_clues
    {clues₁ clues₂ : Finset ((Fin 9 × Fin 9) × Fin 9)}
    (hsub : clues₁ ⊆ clues₂)
    (A : SudokuAssignment) :
    tropicalSudokuCost clues₁ A ≤ tropicalSudokuCost clues₂ A := ...

def minSudokuCost (clues : Finset ((Fin 9 × Fin 9) × Fin 9)) : Nat :=
  Finset.inf' (Finset.univ.image (fun A => tropicalSudokuCost clues A)) ...

theorem minSudokuCost_mono_clues
    {clues₁ clues₂ : Finset ((Fin 9 × Fin 9) × Fin 9)}
    (hsub : clues₁ ⊆ clues₂) :
    minSudokuCost clues₁ ≤ minSudokuCost clues₂ := ...
```

This is the beginning of a tropical phase diagram: clue density drives the minimum energy upward.

### Theorem C: Propagation as a monotone contracting operator

Represent candidate sets by:

```lean
def Candidates := (Fin 9 × Fin 9) → Finset (Fin 9)
```

Define a one-step propagation operator that removes digits inconsistent with clues and singleton consequences from row/column/box constraints. Then prove:

```lean
def propagateStep (clues : Finset ((Fin 9 × Fin 9) × Fin 9)) :
    Candidates → Candidates := ...

def Candidates.Valid (C : Candidates) : Prop := ∀ c, (C c).Nonempty

theorem propagateStep_antitone_card
    (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (C : Candidates) (c : Fin 9 × Fin 9) :
    ((propagateStep clues C) c).card ≤ (C c).card := ...

theorem propagateStep_sound
    (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (A : SudokuAssignment)
    (hA : SudokuValid clues A)
    (hmem : ∀ c, A c ∈ C c) :
    ∀ c, A c ∈ (propagateStep clues C) c := ...
```

This says propagation never removes a digit used by a true solution.

### Theorem D: Polynomial stabilization of propagation

Because each step only removes candidates and there are at most `81 * 9` candidate memberships, stabilization occurs in at most `729` strict deletions.

```lean
def totalCandidateMass (C : Candidates) : Nat :=
  ∑ c in Finset.univ, (C c).card

theorem propagateStep_mass_mono
    (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (C : Candidates) :
    totalCandidateMass (propagateStep clues C) ≤ totalCandidateMass C := ...

theorem propagation_stabilizes_bounded
    (clues : Finset ((Fin 9 × Fin 9) × Fin 9))
    (C : Candidates) :
    ∃ n ≤ 729, Nat.iterate (propagateStep clues) n C =
                Nat.iterate (propagateStep clues) (n+1) C := ...
```

This is a rigorous polynomial-time theorem for the propagation operator itself.

### Theorem E: Critical ambiguity is maximized on the tropical boundary

This is where you must be creative but precise. Define a **finite-size tropical boundary statistic** instead of an asymptotic complexity claim that is impossible to formalize cleanly in one cycle.

For example, define:
- `minSudokuCost clues`
- `residualMass clues := totalCandidateMass (propagationClosure clues initialCandidates)`
- `critical clues : Prop := minSudokuCost clues = 1 ∨ (minSudokuCost clues = 0 ∧ residualMass clues > baseSolvedMass)`

Then prove a theorem of the form:

```lean
theorem boundary_instances_maximize_residual_ambiguity
    (F : Finset (Finset ((Fin 9 × Fin 9) × Fin 9))) :
    ∃ clues ∈ F, critical clues ∧
      ∀ clues' ∈ F, residualAmbiguity clues' ≤ residualAmbiguity clues := ...
```

provided `F` is a finite family closed under your chosen clue-density parameter and contains both satisfiable and unsatisfiable instances. This is not yet a probabilistic phase transition theorem, but it is a rigorous **extremal tropical boundary theorem**: the most ambiguous instances sit at the edge of feasibility.

If you can push further, define a random model by choosing clue sets of fixed size uniformly from all clue placements, and formalize a weaker threshold monotonicity statement such as:
- expected minimum cost is monotone in clue density,
- probability of satisfiability is antitone after a contradiction-heavy clue model,
- or expected residual ambiguity is unimodal/peaked near a boundary index in finite families.

That would be genuinely new.

## Proof Strategy Architecture

### Strategy A: Conflict-pair exactness via nonnegative sums
Most promising for Theorem A.

1. Define each violation count as a finite sum of `0/1` indicators over clue mismatches and conflicting pairs in rows, columns, and boxes.
2. Prove each summand is nonnegative and equals `0` exactly when the corresponding local constraint holds.
3. Use `Nat.sum_eq_zero_iff_of_nonneg`-style reasoning, or explicit finite induction over the sum, to show the total cost is zero iff every local constraint is satisfied.

Why promising: this avoids difficult algebra and turns the key theorem into a clean decomposition of global validity into local zero-penalty conditions.

### Strategy B: Galois-style propagation via candidate-set shrinking
Best for Theorems C and D.

1. Define `propagateStep` as an intersection of candidate sets with supports allowed by clues and neighbor exclusions.
2. Prove soundness by showing any valid assignment remains pointwise admissible after each local filter.
3. Prove stabilization using the measure `totalCandidateMass`; each non-fixed step strictly decreases mass, so iteration terminates in at most `729` steps.

Why promising: finite descending-chain arguments are Lean-friendly and give an honest polynomial-time result without touching hard search complexity.

### Strategy C: Finite-size phase boundary via extremal families
Best for Theorem E.

1. Parameterize a finite family of clue sets by cardinality or by a controlled random-like generation scheme.
2. Define `residualAmbiguity` from propagation closure, e.g. total candidate mass minus the solved baseline.
3. Prove that satisfiable interior instances have low ambiguity after propagation, deeply inconsistent instances collapse quickly, and maximal ambiguity occurs at a boundary class where propagation neither solves nor refutes immediately.

Why promising: this converts vague “hardest at the threshold” folklore into a rigorous extremal theorem over a finite family. It is bold but still formalizable.

## Cross-Domain Connections You Must Exploit

### 1. Statistical mechanics
Interpret `tropicalSudokuCost` as a zero-temperature Hamiltonian. Satisfying assignments are ground states; clue density is a control parameter; propagation computes local energy minimization. This perspective suggests formal notions of:
- ground-state degeneracy,
- residual entropy (`log` not needed initially; candidate mass suffices),
- critical slowing down surrogate via stabilization depth.

### 2. Error-correcting codes / information theory
Sudoku constraints define a structured code-like object: assignments satisfying row/column/box distinctness form a constrained codebook. Clues are partial observations. Propagation resembles iterative decoding, and residual ambiguity is analogous to list size or posterior support. A future theorem could compare Sudoku propagation with min-sum decoding on factor graphs.

### 3. Tropical geometry / min-plus algebra
The cost landscape is a min-plus energy surface over discrete assignments. Local eliminations are tropical projections onto constraint sets. If you succeed, this points toward a formal theory of **tropical CSPs** far beyond Sudoku: Latin squares, graph coloring, exact cover, and factor-graph inference.

### 4. Complexity theory
You should not promise NP-hardness proofs unless you formalize a reduction. But you can rigorously define and analyze a **hardness surrogate**:
- propagation depth,
- residual ambiguity after closure,
- minimum positive cost,
- number of near-ground states.
This is enough to make a meaningful theorem about criticality.
