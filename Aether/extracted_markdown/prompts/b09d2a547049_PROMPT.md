# Counterpoint as Category Theory: The Voice-Leading Quiver

We formalize first-species counterpoint rules (Fux's *Gradus ad Parnassum*) as a
directed multigraph — the **Counterpoint Quiver** — whose vertices are consonant
intervals mod 12 semitones and whose edges are voice leadings permitted by
counterpoint rules. We prove that this quiver exhibits a fundamental asymmetry
between perfect and imperfect consonances, that permitted voice leadings fail to
compose (hence do not form a subcategory), and that voice-exchange breaks
consonance — formalizing the privileged role of the bass voice.

## Novel Structure: CounterpointSystem

A `CounterpointSystem n` parameterizes counterpoint-like constraints over `ZMod n`:
a set of consonant intervals, a subset of "perfect" (restricted) consonances, and the
rule that parallel motion into perfect consonances is forbidden. This abstraction
captures not just standard 12-TET counterpoint but also microtonal systems (19-TET,
31-TET, etc.) and enables structural theorems about voice-leading constraints in general.

## Main Results

1. **Strong connectivity** (`exists_permitted_voice_leading`): Between any two consonant
   intervals, at least one permitted voice leading exists.

2. **Non-composability** (`non_composability`): The set of permitted one-step voice
   leadings is NOT closed under composition — two individually valid moves can combine
   into a forbidden one. Hence permitted voice leadings do not form a subcategory.

3. **Perfect consonance bottleneck** (`perfect_self_loop_unique`,
   `imperfect_self_loops_all`): A perfect consonance admits exactly 1 self-loop
   (the identity), while an imperfect consonance admits 12. This is the categorical
   manifestation of why parallel fifths and octaves are forbidden.

4. **Voice-swap asymmetry** (`voice_swap_breaks_consonance`): The involution
   `i ↦ -i` on `ZMod 12` does NOT preserve the set of consonant intervals. The
   perfect fifth (7) maps to the perfect fourth (5), which is dissonant. This
   formalizes the asymmetric role of the bass voice in counterpoint.

5. **Hom-set computation** (`total_permitted_to_perfect`, `total_permitted_to_imperfect`):
   Perfect consonances admit exactly 61 incoming voice leadings from all consonant

   the compositional constraint.

/-! ## Section 1: The Counterpoint System — A Novel Mathematical Structure -/

/-- A `CounterpointSystem n` captures the constraint structure of a counterpoint-like
    voice-leading system over `ZMod n`. It consists of:
    - A finite set of consonant intervals
    - A subset of "perfect" consonances subject to stricter voice-leading rules
    - The fundamental rule: parallel motion into perfect consonances is forbidden

    This generalizes beyond 12-TET to any equal temperament, and the key structural
    theorems (connectivity, non-composability, bottleneck) can be stated at this
    level of generality. -/
structure CounterpointSystem (n : ℕ) [NeZero n] where
  /-- The set of consonant intervals in `ZMod n`. -/
  consonant : Finset (ZMod n)
  /-- The subset of perfect consonances (subject to parallel-motion restriction). -/
  perfect : Finset (ZMod n)
  /-- Perfect consonances are consonant. -/
  perfect_sub : perfect ⊆ consonant
  /-- There is at least one consonant interval. -/
  consonant_nonempty : consonant.Nonempty
  /-- There is at least one perfect consonance. -/
  perfect_nonempty : perfect.Nonempty
  /-- There exists a non-perfect consonance. -/
  has_imperfect : ∃ i ∈ consonant, i ∉ perfect

/-- A voice leading is a pair of motions: how much the bass moves and how much the
    soprano moves (both in `ZMod n`). -/
@[ext]
structure VoiceLeading (n : ℕ) [NeZero n] where
  /-- Bass voice motion in semitones mod n. -/
  bass : ZMod n
  /-- Soprano voice motion in semitones mod n. -/
  soprano : ZMod n
  deriving DecidableEq, Repr

instance (n : ℕ) [NeZero n] : Fintype (VoiceLeading n) :=
  Fintype.ofEquiv (ZMod n × ZMod n)
    { toFun := fun ⟨b, s⟩ => ⟨b, s⟩
      invFun := fun ⟨b, s⟩ => ⟨b, s⟩
      left_inv := fun ⟨_, _⟩ => rfl
      right_inv := fun ⟨_, _⟩ => rfl }

/-- The target interval reached by applying a voice leading to a source interval.
    If voices are at interval `source` and bass moves by `vl.bass` while soprano
    moves by `vl.soprano`, the new interval is `source + soprano - bass`. -/
def targetInterval (n : ℕ) [NeZero n] (source : ZMod n) (vl : VoiceLeading n) : ZMod n :=
  source + vl.soprano - vl.bass

/-- A voice leading is *parallel* if both voices move by the same amount (and move at all). -/
def VoiceLeading.isParallel {n : ℕ} [NeZero n] (vl : VoiceLeading n) : Prop :=
  vl.bass = vl.soprano ∧ vl.bass ≠ 0

instance {n : ℕ} [NeZero n] (vl : VoiceLeading n) : Decidable vl.isParallel :=
  instDecidableAnd

/-- A voice leading from `source` to `target` is *permitted* in a counterpoint system if:
    1. Both source and target are consonant
    2. The voice leading actually maps source to target
    3. Parallel motion into a perfect consonance is forbidden -/
def CounterpointSystem.isPermitted {n : ℕ} [NeZero n] (sys : CounterpointSystem n)
    (source target : ZMod n) (vl : VoiceLeading n) : Prop :=
  source ∈ sys.consonant ∧
  target ∈ sys.consonant ∧
  targetInterval n source vl = target ∧
  ¬(target ∈ sys.perfect ∧ vl.isParallel)

instance {n : ℕ} [NeZero n] (sys : CounterpointSystem n)
    (source target : ZMod n) (vl : VoiceLeading n) :
    Decidable (sys.isPermitted source target vl) :=
  instDecidableAnd

/-! ## Section 2: The Standard 12-TET Chromatic Counterpoint System -/

/-- The six consonant intervals in standard first-species counterpoint (mod 12):
    unison (0), minor third (3), major third (4), perfect fifth (7),
    minor sixth (8), major sixth (9). -/
def chromaticConsonant : Finset (ZMod 12) := {0, 3, 4, 7, 8, 9}

/-- The two perfect consonances: unison/octave (0) and perfect fifth (7). -/
def chromaticPerfect : Finset (ZMod 12) := {0, 7}

/-- The standard 12-TET first-species counterpoint system. -/
def standard12 : CounterpointSystem 12 where
  consonant := chromaticConsonant
  perfect := chromaticPerfect
  perfect_sub := by decide
  consonant_nonempty := ⟨0, by decide⟩
  perfect_nonempty := ⟨0, by decide⟩
  has_imperfect := ⟨3, by decide, by decide⟩

/-! ## Section 3: Strong Connectivity -/

/-- The identity voice leading (no motion in either voice). -/
def VoiceLeading.id (n : ℕ) [NeZero n] : VoiceLeading n := ⟨0, 0⟩

/-- The canonical voice leading from interval `i` to interval `j`:
    bass stays, soprano moves by `j - i`. -/
def canonicalVL (n : ℕ) [NeZero n] (i j : ZMod n) : VoiceLeading n := ⟨0, j - i⟩

theorem targetInterval_canonical (n : ℕ) [NeZero n] (i j : ZMod n) :
    targetInterval n i (canonicalVL n i j) = j := by
  simp [targetInterval, canonicalVL, sub_add_cancel]

/-
The canonical voice leading is never parallel when source ≠ target.
-/
theorem canonical_not_parallel (n : ℕ) [NeZero n] (i j : ZMod n) (h : i ≠ j) :
    ¬(canonicalVL n i j).isParallel := by
  unfold canonicalVL VoiceLeading.isParallel; aesop;

/-
**Strong connectivity**: Between any two consonant intervals in the standard
    12-TET system, there exists a permitted voice leading. This means the counterpoint
    quiver is strongly connected as a directed graph.
-/
theorem exists_permitted_voice_leading (i j : ZMod 12)
    (hi : i ∈ chromaticConsonant) (hj : j ∈ chromaticConsonant) :
    ∃ vl : VoiceLeading 12, standard12.isPermitted i j vl := by
  by_cases h : i = j;
  · subst h;
    fin_cases i <;> simp +decide
