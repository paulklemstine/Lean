## Mathematical Framing

Work with a finite type of cells `ι` and finite alphabet `α`. A global update rule
`F : (ι → α) → (ι → α)` is a finite cellular-style dynamical system. Since the configuration space is finite, non-surjectivity is equivalent to the existence of a Garden-of-Eden configuration. But that alone is too easy. The theorem should instead show that if `F` is additionally monotone with respect to a finite partial order on configurations, then **iterating `F` produces bounded descent/stabilization**, and every Garden-of-Eden defect can be witnessed within a finite search radius controlled by finite-height data.

The key conceptual jump: reinterpret “Garden-of-Eden” as a **thermodynamic closure defect**. A non-surjective local dynamics destroys accessible microstates; finite-height descent then certifies that repeated evolution cannot recover them. This creates a rigorous bridge between:
- cellular automata / symbolic dynamics,
- finite lattice dynamics,
- closure operators and entropy-like monotonicity,
- algorithmic countermodel extraction.

## Primary Target Theorem

Prove a theorem of the following form, with a concrete Lean 4 statement.

### Theorem statement (mathematical form)

Let `P` be a finite partial order, and let `F : P → P` be monotone and descending:
- `Monotone F`
- `∀ x, F x ≤ x`

Then:
1. every orbit `x, F x, F (F x), ...` stabilizes in at most `Fintype.card P` steps;
2. if `F` is not surjective, then there exists `y : P` such that `∀ x, F x ≠ y` and moreover `y` lies outside the eventual image `Set.range (F^[Fintype.card P])`.

This is the finite Garden-of-Eden theorem in order-theoretic form: missing states are not only absent now, they are absent from sufficiently evolved dynamics.

### Lean 4 target signature

A strong, realistic target:

```lean
theorem finite_garden_of_eden_descent
  {P : Type*} [Fintype P] [DecidableEq P] [PartialOrder P]
  (F : P → P)
  (hmono : Monotone F)
  (hdesc : ∀ x : P, F x ≤ x) :
  ∀ x : P, ∃ n ≤ Fintype.card P, Function.Iterate F n x = Function.Iterate F (n + 1) x
```

Then prove the corollary:

```lean
theorem finite_garden_of_eden_of_not_surjective
  {P : Type*} [Fintype P] [DecidableEq P] [PartialOrder P]
  (F : P → P)
  (hmono : Monotone F)
  (hdesc : ∀ x : P, F x ≤ x)
  (hnsurj : ¬ Function.Surjective F) :
  ∃ y : P, (∀ x : P, F x ≠ y) ∧ y ∉ Set.range (Function.Iterate F (Fintype.card P))
```

A more configuration-theoretic specialization, if you want the symbolic-dynamics flavor explicit:

```lean
theorem finite_configuration_garden_of_eden
  {ι α : Type*} [Fintype ι] [Fintype α] [DecidableEq α]
  (F : (ι → α) → (ι → α))
  (hnsurj : ¬ Function.Surjective F) :
  ∃ c : (ι → α), ∀ x : (ι → α), F x ≠ c
```

This last theorem is easy; it should appear only as an entry lemma. The real theorem is the descent/stabilization result above.

## Proof Strategy Architecture

### Strategy A — Orbit-as-chain + finite-height bound
**Most promising.**

1. For fixed `x`, consider the orbit sequence `a_n = (F^[n]) x`.
2. Use `hdesc` and monotonicity to prove this is a descending chain:
   `a_(n+1) ≤ a_n`.
3. Invoke `finite_height_descent_bound` or `finite_lattice_bounded_chain` to show no strictly descending chain can continue beyond `Fintype.card P`.
4. Conclude there exists `n ≤ card P` with `a_n = a_(n+1)`.
5. Since `a_(n+1) = F (a_n)`, deduce `a_n` is a fixed point.

Why this is strongest:
- It extracts a quantitative stabilization theorem, not just existence.
- It uses the catalog in the most direct and structurally meaningful way.
- It immediately yields Garden-of-Eden corollaries about eventual image collapse.

### Strategy B — Pigeonhole + antisymmetry + monotone squeezing
1. Since `P` is finite, the orbit `a_n` must repeat.
2. Because the orbit is descending (`a_(n+1) ≤ a_n`), any repetition `a_i = a_j` with `i < j` forces all intermediate inequalities to be equalities by antisymmetry.
3. Therefore stabilization begins at the first repeated state.
4. Bound the first repetition by `Fintype.card P + 1`.

Why this is good:
- More elementary and may avoid dependence on exact shape of `finite_height_descent_bound`.
- Good fallback if catalog theorem interfaces are awkward.

Why it is less visionary:
- It proves the result, but does not visibly leverage the thermodynamic closure machinery.
- Use this only if Strategy A becomes technically blocked.

### Strategy C — Image filtration / entropy defect
1. Consider the descending sequence of images:
   `Set.range F ⊇ Set.range (F^[2]) ⊇ ...`
2. Show this stabilizes on a finite type.
3. If `F` is non-surjective, then `Set.range F` is already proper, and the stable image remains proper.
4. Extract `y` outside the stable image; this is a persistent Garden-of-Eden state.

Why this matters:
- This is the thermodynamic / semantic formulation.
- It upgrades pointwise orbit descent into global loss of accessible state-space volume.
- It is conceptually rich and connects to entropy, automata reachability, and semantics.

Best use:
- As a corollary theorem after Strategy A or B.
