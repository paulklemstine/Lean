## Core objects to define

Start from the standard notion of primitive Pythagorean triple:

- `t = (a,b,c) ∈ ℤ^3`
- `a^2 + b^2 = c^2`
- `gcd a b = 1`, `gcd a c = 1`, `gcd b c = 1`
- parity normalization: exactly one of `a,b` even, `c > 0`, and optionally `0 < a < b < c`

Define a canonical 2D lattice basis attached to `t` by one of the following equivalent models:

1. **Binary Gram model**
   \[
   v_1(t) := (a,b), \qquad v_2(t) := (-b,a),
   \]
   with Gram matrix
   \[
   G_t := \begin{pmatrix}
   a^2+b^2 & 0\\
   0 & a^2+b^2
   \end{pmatrix}
   = c^2 I_2.
   \]
   This is too degenerate for reconstruction by itself, so enrich it.

2. **Asymmetric canonical Gram model** (recommended)
   \[
   v_1(t) := (a,b), \qquad v_2(t) := (a,c),
   \]
   and
   \[
   G_t :=
   \begin{pmatrix}
   a^2+b^2 & a^2+bc\\
   a^2+bc & a^2+c^2
   \end{pmatrix}.
   \]
   Since `a^2+b^2=c^2`, this simplifies but remains nontrivial and remembers arithmetic asymmetry.

3. **Rank-3 embedding model**
   \[
   w_1=(a,b,0),\quad w_2=(a,0,c),\quad w_3=(0,b,c),
   \]
   and let `G_t` be their Gram matrix. This is likely best for reconstruction/separation because it preserves the full quadratic relation in a positive semidefinite but highly structured way.

You should choose one canonical model and then prove all theorems for it. If the rank-2 model is too lossy for uniqueness, prove rank-3 first and derive rank-2 as a corollary or quotient.

## Precise theorem targets

### 1. Functorial Berggren-to-Gram evolution theorem

Let `B₁, B₂, B₃ : Matrix (Fin 3) (Fin 3) ℤ` be the classical Berggren generators acting on primitive triples. Define a map
\[
\mathrm{gramEncode} : \mathrm{PrimTriple} \to \mathrm{GramData}
\]
and for each generator `Bᵢ` define an induced integer matrix/basis update
\[
\Phi_i : \mathrm{GramData} \to \mathrm{GramData}
\]
such that
\[
\mathrm{gramEncode}(B_i \cdot t)=\Phi_i(\mathrm{gramEncode}(t)).
\]

A precise Lean-facing statement should look like:

```lean
theorem gramEncode_functorial_under_Berggren
  (i : Fin 3) (t : PrimTriple) :
  gramEncode (berggrenGen i • t) = gramUpdate i (gramEncode t)
```

If you instead package arbitrary Berggren words:

```lean
theorem gramEncode_functorial
  (w : BerggrenWord) (t : PrimTriple) :
  gramEncode (actWord w t) = actGramWord w (gramEncode t)
```

This is the conceptual entry point: Berggren dynamics is not merely compatible with Gram encoding; it *is* a semigroup action by structured lattice basis evolution.

### 2. Height-to-determinant / successive-minima monotonicity theorem

Define a triple height, preferably `height t := t.c` or a monotone variant equivalent to `max |a| |b| |c|`. For the Gram object define determinant and successive minima:

- `gramDet : GramData → ℤ` or `ℕ`
- `lambda1 lambda2 : GramData → ℝ`

Prove that strict descent in Berggren ancestry corresponds to strict increase in lattice complexity along descendants. A robust formulation:

```lean
theorem descendant_height_strict_mono
  (t u : PrimTriple) :
  BerggrenDescendant t u → height t < height u
```

and then the bridge theorem:

```lean
theorem height_monotone_implies_gram_complexity_mono
  (t u : PrimTriple) :
  BerggrenDescendant t u →
  gramDet (gramEncode t) ≤ gramDet (gramEncode u) ∧
  lambda1 (gramEncode t) ≤ lambda1 (gramEncode u) ∧
  lambda2 (gramEncode t) ≤ lambda2 (gramEncode u)
```

If strict monotonicity for `lambda1` fails on some branches, weaken to:
- monotone nondecrease,
- eventual strictness after one nontrivial descendant step,
- or a lower bound of the form `lambda1 ≥ f(height)` with `f` explicit.

This theorem should explicitly leverage `reduction_terminates_with_height_bound`: termination of reduction is already a certified height argument, so invert it into a statement that ancestry depth controls reduction complexity and vice versa.

### 3. Reconstruction / rigidity theorem from reduced Gram data

This is the hardest and most important theorem. You want a statement saying that reduced Gram data satisfying arithmetic congruence and primitiveness conditions determines a unique Berggren ancestry class.

A model statement:

```lean
theorem reducedGram_reconstructs_unique_ancestry_class
  (G : GramData) :
  isReduced G →
  primitiveParityCompatible G →
  validPythagoreanGram G →
  ∃! t : PrimTriple, gramEncode t = G
```

If literal uniqueness of the triple is too strong because of symmetries `(a,b,c) ~ (b,a,c)` or sign changes, prove uniqueness modulo a canonical equivalence:

```lean
theorem reducedGram_reconstructs_unique_class
  (G : GramData) :
  isReduced G →
  primitiveParityCompatible G →
  validPythagoreanGram G →
  ∃! C : BerggrenClass, ∃ t ∈ C, gramEncode t = G
```

This is where parity constraints matter. Primitive triples are rigidly parameterized by Euclid parameters `m>n`, coprime, opposite parity:
\[
a = m^2-n^2,\quad b = 2mn,\quad c = m^2+n^2.
\]
Use this to derive arithmetic invariants of the Gram entries and invert them. If reconstruction from raw Gram entries is difficult, define a normalized reduced invariant package:
- determinant,
- trace,
- one off-diagonal entry,
- parity/congruence tags mod 2 or mod 4,
- positivity ordering.

Then prove injectivity of the encoding into this reduced package.

This is the theorem that turns lattice reduction output into exact arithmetic provenance.

### 4. Certified short-vector extraction = explicit ancestor recovery theorem

This is the real duality theorem. Local lattice reduction moves should correspond to explicit inverse Berggren moves.

Define a one-step reduction relation on Gram data, e.g.

```lean
def GramReductionStep : GramData → GramData → Prop := ...
```

and define partial inverse Berggren steps on primitive triples:

```lean
def berggrenAncestorStep : PrimTriple → PrimTriple → Prop := ...
```

Then prove:

```lean
theorem reduction_step_corresponds_to_ancestor_step
  (t : PrimTriple) (G' : GramData) :
  GramReductionStep (gramEncode t) G' →
  ∃ t', berggrenAncestorStep t' t ∧ gramEncode t' = G'
```

and conversely:

```lean
theorem ancestor_step_induces_short_vector_extraction
  (t' t : PrimTriple) :
  berggrenAncestorStep t' t →
  ∃ v, isPrimitiveShortestVector v (gramEncode t) ∧
       extractReducedGram v (gramEncode t) = gramEncode t'
```

A stronger packaged theorem:

```lean
theorem certified_short_vector_extraction
  (t : PrimTriple) :
  ∃ ts : List PrimTriple,
    ts.Head? = some t ∧
    ts.getLast? = some rootTriple ∧
    Chain' berggrenAncestorStep ts ∧
    Chain' GramReductionStep (ts.map gramEncode)
```

This should connect directly to `reduction_terminates_with_height_bound`: that theorem already gives a reduction termination certificate. Your task is to identify the terminal reduced object with the Berggren root and each reduction step with a certified ancestry move.

This is where the phrase “lattice hardness proxy” becomes mathematically meaningful: short-vector extraction on this structured family is exactly ancestry recovery.

### 5. Separation / collision-resistance theorem for bounded height

Prove that non-isomorphic ancestry classes remain separated in Gram space up to bounded height. You need an explicit quantitative bound.

A strong finite-height theorem:

```lean
theorem gramEncode_separation_bound
  (N : ℕ) :
  ∃ δ : ℕ, 0 < δ ∧
  ∀ t u : PrimTriple,
    height t ≤ N →
    height u ≤ N →
    ancestryClass t ≠ ancestryClass u →
    gramDistance (gramEncode t) (gramEncode u) ≥ δ
```

Or an injectivity statement with bounded-height collision exclusion:

```lean
theorem bounded_height_no_collision
  (N : ℕ) (t u : PrimTriple) :
  height t ≤ N →
  height u ≤ N →
  gramEncode t = gramEncode u →
  ancestryClass t = ancestryClass u
```

Then refine using catalog theorems:

- `post_quantum_security_residual_collision_bound` should be used as the cryptographic analogue of a finite-state collision barrier.
- `post_quantum_prime_separation_lemma` should likely be used to distinguish Gram invariants by congruence/prime divisibility data.
- If possible, derive a residual bound of the form:
  \[
  \Pr[\text{collision below height }N] \le C/N^\alpha
  \]
  for deterministic enumeration interpreted as a counting statement rather than probability proper.

This gives the “collision resistance” language real content in the structured deterministic setting.

## Proof strategy architecture

### Strategy A: Euclid parameterization → explicit Gram invariants → Berggren rigidity
**Most promising for reconstruction and separation.**

1. Parameterize primitive triples by coprime opposite-parity `m>n>0`.
2. Express Gram entries explicitly as polynomials in `m,n`.
3. Show Berggren generators induce polynomial/rational transforms on `(m,n)` or on invariant tuples.
4. Prove injectivity/reconstruction by solving for `m,n` from reduced Gram invariants plus parity constraints.
5. Derive collision/separation from uniqueness of `(m,n)` and bounded-height counting.

Why this is strongest: it reduces all abstract geometry to exact Diophantine formulas, ideal for Lean and for explicit quantitative bounds.

---

### Strategy B: Semigroup action on bases → reduction relation as inverse word problem
**Most promising for the short-vector extraction theorem.**

1. Define Berggren words and induced basis-update matrices on Gram data.
2. Show each generator strictly increases a well-founded measure tied to height/determinant.
3. Define inverse reduction moves by recognizing local normal forms of the Gram matrix.
4. Prove each reduction step removes the last Berggren generator in the unique normal-form word.
5. Conclude reduction termination, ancestry recovery, and certified extraction.

Why this matters: it identifies lattice reduction with a semigroup normal-form algorithm, a new viewpoint with direct computational meaning.

---

### Strategy C: Quadratic form / Minkowski-style route
**Potentially powerful for minima monotonicity, but probably secondary.**

1. Treat `G_t` as a positive definite binary/ternary quadratic form.
2. Use determinant, trace, and norm inequalities to bound successive minima.
3. Show Berggren expansion increases these invariants via explicit matrix comparison or Loewner-order estimates.
4. Connect reduced forms to primitive vectors and to ancestry descent.

Why it is useful: it ties the result to classical geometry of numbers and makes the cryptographic interpretation legible. But it may be heavier to formalize than Strategy A+B.

**Recommendation:** Use A for rigidity/reconstruction, B for reduction duality, and C only as a conceptual supplement or for cleaner minima bounds.

## How to use the catalog theorems as building blocks

### `reduction_terminates_with_height_bound`
Use this as the backbone of the reduction side. The theorem already certifies termination controlled by height. Your task is to show that:
- the reduction measure coincides with or bounds Berggren ancestry depth,
- terminal reduced data corresponds to the root primitive triple,
- each reduction move has an arithmetic interpretation as an inverse Berggren step.

This converts a termination theorem into a structural equivalence theorem.

### `post_quantum_security_residual_collision_bound`
Use this to motivate and possibly formalize a residual collision estimate for bounded-height Gram encodings. Even if the theorem is stated in automata language, reinterpret Berggren ancestry classes or reduced invariant strings as residual states. Then collisions of encodings become residual-state collisions, and the existing bound becomes a certified separation lemma for the new dictionary.

### `post_quantum_prime_separation_lemma`
Use this to distinguish non-equal triples by prime-sensitive invariants of Gram entries:
- determinant factorization,
- gcd patterns of minors,
- congruence classes mod odd primes or mod 8.
This is especially valuable if direct injectivity of the raw Gram map is too rigid or too false without congruence decoration.

### `quantum_lipschitz_certified_robustness_of_bounded_height`
This looks distant, but conceptually it can be used to prove *stability* of the encoding/reduction pipeline under bounded perturbations of height or local moves. If your `gramDistance` is a discrete metric on reduced forms, bounded-height robustness may yield a “small perturbations cannot change ancestry class below threshold” lemma. That would be a striking cross-arc synthesis: a robustness theorem from one bridge becoming a rigidity theorem here.
