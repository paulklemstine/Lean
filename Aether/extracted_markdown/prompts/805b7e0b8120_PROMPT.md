## Main Theorem Package

### Theorem 1: Closure-with-exchange induces a matroidal rank geometry

Precise mathematical statement:

For any finite type `X` and finitary exchange closure `cl`, there exists a rank function `r : Set X → ℕ` such that for all `A B : Set X`:

1. `r A ≤ A.encard`
2. `A ⊆ B → r A ≤ r B`
3. `r (A ∪ B) + r (A ∩ B) ≤ r A + r B`
4. `cl A = {x | r (A ∪ {x}) = r A}`

and the independent sets are exactly the subsets `I` satisfying `r I = I.encard`.

A Lean-facing theorem signature could be:

```lean
theorem exists_matroid_rank_of_finitary_exchange_closure
  {X : Type _} [Fintype X] [DecidableEq X]
  (C : FinitaryExchangeClosure X) :
  ∃ r : Set X → ℕ,
    (∀ A, r A ≤ A.encard.toNat) ∧
    (∀ {A B : Set X}, A ⊆ B → r A ≤ r B) ∧
    (∀ A B, r (A ∪ B) + r (A ∩ B) ≤ r A + r B) ∧
    (∀ A x, x ∈ C.cl A ↔ r (A ∪ {x}) = r A)
```

If Mathlib matroid APIs are available in your environment, strengthen this to an actual `Matroid X` construction:

```lean
noncomputable def closureMatroid
  {X : Type _} [Fintype X] [DecidableEq X]
  (C : FinitaryExchangeClosure X) : Matroid X := ...
```

with the theorem

```lean
theorem closure_eq_matroid_closure
  {X : Type _} [Fintype X] [DecidableEq X]
  (C : FinitaryExchangeClosure X) :
  ∀ A, (closureMatroid C).cl A = C.cl A
```

This is the foundational bridge theorem.

### Theorem 3: Minimal qualified sets are circuits through the dealer

Fix `d : X`. Define the access structure
`Qualified_d(A) : Prop := d ∈ cl A`.

Define minimal qualified sets:
```lean
def MinimalQualified (C : FinitaryExchangeClosure X) (d : X) (A : Set X) : Prop :=
  d ∈ C.cl A ∧ ∀ B ⊂ A, d ∉ C.cl B
```

Then prove that the minimal qualified sets are exactly the circuits of the induced matroid after adjoining the dealer, or equivalently the minimal dependent sets containing `d`.

Lean target:

```lean
theorem minimalQualified_iff_circuit_with_dealer
  {X : Type _} [Fintype X] [DecidableEq X]
  (C : FinitaryExchangeClosure X) (d : X) (A : Set X) :
  MinimalQualified C d A ↔
    d ∉ A ∧
    IsCircuit (closureMatroid C) (insert d A)
```

If `IsCircuit` is unavailable, define the circuit predicate directly via minimal dependence.

This theorem is cryptographically decisive: **qualified reconstruction is generated by circuit geometry**.

### Theorem 4: Canonical secret-sharing access structure with certified reconstruction/privacy

The cryptographic theorem should be formulated as an *access-structure correctness theorem* rather than a computational implementation of random shares.

Define a semantic secret-sharing scheme over subsets of participants `P := X \ {d}` by:

- a set is reconstructible iff it spans `d`,
- a set is private iff it does not span `d`.

Then prove monotonicity, exactness, and dual certification.

Lean target:

```lean
theorem canonical_access_structure
  {X : Type _} [Fintype X] [DecidableEq X]
  (C : FinitaryExchangeClosure X) (d : X) :
  let Qualified : Set X → Prop := fun A => d ∈ C.cl A
  let Private   : Set X → Prop := fun A => d ∉ C.cl A
  (∀ {A B}, A ⊆ B → Qualified A → Qualified B) ∧
  (∀ A, Qualified A ↔ ¬ Private A) ∧
  (∀ A, Private A → ∀ B ⊆ A, Private B)
```

Then strengthen it to minimal qualified sets / maximal private flats if possible:

```lean
theorem privacy_certified_by_nonspanning
  {X : Type _} [Fintype X] [DecidableEq X]
  (C : FinitaryExchangeClosure X) (d : X) (A : Set X) :
  d ∉ C.cl A →
  ∀ B ⊆ A, d ∉ C.cl B
```

This is the exact certified privacy theorem: non-spanning sets cannot leak the dealer in the closure semantics.

## 2–3 Proof Strategy Paths

### Strategy A: Matroid reconstruction from exchange closure via maximal independent subsets
**Most promising.**

1. Define independence by the standard closure criterion:
   `I` is independent iff for every `x ∈ I`, `x ∉ cl (I \ {x})`.
2. Prove hereditary and augmentation using the exchange axiom.
3. Define `rank A` as the maximum cardinality of an independent finite subset of `A`.
4. Derive closure-from-rank:
   `x ∈ cl A ↔ rank (A ∪ {x}) = rank A`.
5. Package the resulting geometry as a matroid or matroid-like rank structure.
6. Deduce flats/circuits, then reinterpret circuits through the dealer as minimal qualified sets.

Why this is best: it uses only finite combinatorics plus exchange, aligns perfectly with Mathlib-style finite maximization, and makes the cryptographic layer almost automatic once the geometry is built.

---

### Strategy B: Build directly from closure axioms to flats/circuits, then recover rank
1. Define closed sets and minimal dependence directly from `cl`.
2. Show the Steinitz exchange principle yields circuit elimination or enough of it for finite geometry.
3. Construct rank afterward by basis cardinality inside closures.
4. Prove cryptographic statements using circuits/flats first, not rank first.

Why this is attractive: it may avoid some painful maximal-cardinality machinery early on.
Why it is riskier: circuit elimination formalization is often more delicate than rank-submodularity.

---

### Strategy C: Work through existing nucleus / algebraic closure infrastructure
1. Reuse catalog closure/nucleus theorems from the Idempotent Stone Completeness / Noether-correspondence line.
2. Show your `cl` is a nucleus-like operator on the lattice of subsets.
3. Derive the idempotent semilattice of closed sets.
4. Add exchange as the extra axiom forcing matroidality.
5. Push the dealer semantics as a principal filter/cosieve in the closed-set lattice.

Why this matters: it gives the strongest cross-catalog reuse and the most conceptual algebraic statement.
Why it is secondary: it likely still needs Strategy A or B for the actual matroid theorem.

**Recommendation:** Use Strategy A for the core theorem package, with Strategy C to organize the semiring/nucleus layer and to tie into prior catalog results.
