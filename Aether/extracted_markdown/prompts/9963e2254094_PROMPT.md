## Proof architecture: 3 viable strategies

You must include real proof structure. Do not settle for a one-line image-cardinality lemma unless it is embedded inside a deeper theorem package.

### Strategy A: signature restriction + surjectivity + cardinal comparison
**Most promising** if the catalog already realizes `measurementInvariant` as cardinality of a signature image.

1. Use `measurementInvariant_eq_objectwiseTotalCard` to rewrite both invariants as cardinalities of signature spaces / image sets.
2. Construct the restriction map
   `restrictSignatures : SignatureSpace P' → SignatureSpace P`
   induced by forgetting the extra probes.
3. Prove that every `P`-signature is the restriction of some `P'`-signature coming from the same object; hence the induced map on realized signatures is surjective.
4. Deduce
   `measurementInvariant P ≤ measurementInvariant P'`.
5. For equality, show surjective map between finite sets is bijective iff fibers are singletons on realized signatures; translate this to “no new separations.”

Why this is strongest:
- It directly uses the catalog theorem you were given.
- It produces both monotonicity and equality characterization.
- It naturally yields a computable algorithm: compare fibers of the restriction map.

### Strategy B: partition refinement / quotient cardinality
**Most conceptually powerful** and ideal for the cross-domain theorem.

1. Define observational equivalence `ObsEq P`.
2. Prove that `P ≤ P'` implies `ObsEq P' ⊆ ObsEq P` (equivalently: `P'` refines `P`).
3. Show `measurementInvariant P` equals the number of `ObsEq P`-equivalence classes.
4. Use a general theorem: refinement of finite partitions weakly increases the number of blocks.
5. Equality holds iff the two equivalence relations coincide, i.e. iff no new separations are introduced.

Why this matters:
- It reveals the invariant as a partition-counting invariant.
- It generalizes beyond the present category/probe setting.
- It is the cleanest route to the information-theoretic analogy.

### Strategy C: contrapositive rigidity argument
**Useful for the equality characterization**, especially if direct cardinal-bijection machinery is awkward.

1. Assume `measurementInvariant P = measurementInvariant P'`.
2. Suppose by contradiction that `P'` separates some `X,Y` not separated by `P`.
3. Show that the `P`-equivalence class containing `X,Y` must split into at least two `P'`-classes.
4. Therefore the number of observational classes strictly increases, contradiction.
5. Conclude no new separation is possible.

This strategy should use `by_contra`, `rcases`, and multi-step `calc`, satisfying the depth requirements naturally.
