## Core Vision

The central philosophical claim is:

> Higher-order log-concavity is not just a combinatorial regularity of sequences; it is a discrete curvature constraint on the information landscape of the associated probability distribution.

For a positive sequence `a : ℕ → ℝ`, define its normalized probability law
\[
\pi_n = \frac{a_n}{\sum_m a_m}
\]
when the total mass is positive and finite. Since normalization only adds a constant to `log`, the higher finite-difference geometry of `log π_n` is identical to that of `log a_n`. This means the hierarchy of `k`-fold log-concavity should induce a hierarchy of information-curvature sign laws.

This is the theorem family you should formalize and push beyond the obvious first case.

## New Definitions You Must Introduce

At least one genuinely new concept is mandatory. Introduce a small but coherent theory around the following definitions.

### 1. Forward finite difference
Define recursively:
- \(\Delta^0 f(n) = f(n)\)
- \(\Delta^{k+1} f(n) = \Delta^k f(n+1) - \Delta^k f(n)\)

Suggested Lean target:
```lean
def iterForwardDiff (f : ℕ → ℝ) : ℕ → ℕ → ℝ
| 0, n => f n
| k+1, n => iterForwardDiff f k (n+1) - iterForwardDiff f k n
```

### 2. Entropy curvature profile
For a positive sequence `a`, define:
\[
\operatorname{entropyCurvature}(a,k,n) := \Delta^k (\log \circ a)(n).
\]

Suggested Lean target:
```lean
def entropyCurvature (a : ℕ → ℝ) (k n : ℕ) : ℝ :=
  iterForwardDiff (fun m => Real.log (a m)) k n
```

### 3. Information-theoretic depth
Define the depth of a positive sequence to be the largest `d` such that the alternating sign law
\[
(-1)^{j} \Delta^{j+1}(\log \circ a)(n) \ge 0
\quad \text{for all } j < d,\, n
\]
holds. If all orders satisfy it, call the sequence infinitely information-deep.

Suggested Lean-friendly predicates:
```lean
def HasEntropyCurvatureSignUpTo (a : ℕ → ℝ) (d : ℕ) : Prop :=
  ∀ j < d, ∀ n, 0 ≤ ((-1 : ℝ) ^ j) * iterForwardDiff (fun m => Real.log (a m)) (j+1) n

def InfiniteEntropyDepth (a : ℕ → ℝ) : Prop :=
  ∀ j n, 0 ≤ ((-1 : ℝ) ^ j) * iterForwardDiff (fun m => Real.log (a m)) (j+1) n
```

### 4. Pointwise entropy density
To connect to actual information theory, define
\[
I_a(n) := -\pi_n \log \pi_n.
\]
Then prove at least one theorem relating curvature of `log π` to monotonicity/unimodality/shape of `I_a`.

## Precise Theorem Targets

You must prove at least 3 substantial theorems. The following are the minimum breakthrough targets.

### Theorem 1: Second-difference characterization of log-concavity
For positive sequences, ordinary log-concavity is equivalent to nonpositivity of the second finite difference of `log`.

Mathematical statement:
\[
(\forall n,\; a_{n+1}^2 \ge a_n a_{n+2}) \quad \Longleftrightarrow \quad
(\forall n,\; \Delta^2(\log\circ a)(n) \le 0),
\]
assuming \(a_n > 0\) for all \(n\).

Suggested Lean signature:
```lean
theorem logConcave_iff_secondDiff_log_nonpos
  (a : ℕ → ℝ)
  (ha_pos : ∀ n, 0 < a n) :
  LogConcaveN a 1 ↔ ∀ n, iterForwardDiff (fun m => Real.log (a m)) 2 n ≤ 0
```

Why this matters:
This is the exact bridge from multiplicative combinatorics to discrete curvature. It turns a nonlinear inequality on `a` into a linear-looking shape theorem on `log a`.

---

### Theorem 2: Normalization invariance of entropy curvature
If `π` is the normalization of a positive summable sequence `a`, then all finite differences of order at least 1 of `log π` equal those of `log a`.

Mathematical statement:
If
\[
\pi_n = \frac{a_n}{Z}, \qquad Z = \sum_{m=0}^\infty a_m > 0,
\]
then for every \(k \ge 1\),
\[
\Delta^k(\log \pi)(n)=\Delta^k(\log a)(n).
\]

Suggested Lean signature:
```lean
theorem iterForwardDiff_log_normalize_eq
  (a : ℕ → ℝ)
  (ha_pos : ∀ n, 0 < a n)
  (hsum : Summable a)
  (hZ : 0 < ∑' n, a n) :
  ∀ k n, 1 ≤ k →
    iterForwardDiff
      (fun m => Real.log (a m / (∑' n, a n))) k n
    =
    iterForwardDiff (fun m => Real.log (a m)) k n
```

Why this matters:
This theorem says entropy curvature is intrinsic to the shape of the sequence, not an artifact of normalization. That makes it a genuine invariant of the probability law.

### Theorem 3: Geometric distributions have infinite entropy depth
For \(0 < r < 1\), let
\[
a_n = (1-r) r^n.
\]
Then `log a_n` is affine in `n`, so all second and higher finite differences vanish.

Mathematical statement:
\[
\forall k \ge 2,\; \forall n,\; \Delta^k(\log a)(n)=0.
\]

Suggested Lean signature:
```lean
theorem geometric_iterForwardDiff_log_eq_zero
  (r : ℝ)
  (hr0 : 0 < r)
  (hr1 : r < 1) :
  ∀ k n, 2 ≤ k →
    iterForwardDiff (fun m => Real.log ((1 - r) * r^m)) k n = 0
```

Stronger optional corollary:
```lean
theorem geometric_infiniteEntropyDepth
  (r : ℝ)
  (hr0 : 0 < r)
  (hr1 : r < 1) :
  InfiniteEntropyDepth (fun m => (1 - r) * r^m)
```

Why this matters:
Geometric laws are the canonical memoryless distributions. Infinite entropy depth would identify memorylessness with total flattening of higher information curvature.

### Theorem 4: Binomial distributions have negative second log-curvature
For fixed `N` and `0 < p < 1`, define
\[
a_i = \binom{N}{i} p^i (1-p)^{N-i}
\]
for \(i \le N\), and zero outside support if needed via a finite-support version. Then
\[
\Delta^2(\log a)(i) < 0
\]
on the interior support \(0 \le i \le N-2\).

Suggested finite-support Lean signature:
```lean
theorem binomial_secondDiff_log_strict_neg
  (N : ℕ)
  (p : ℝ)
  (hp0 : 0 < p)
  (hp1 : p < 1) :
  ∀ i, i + 2 ≤ N →
    iterForwardDiff
      (fun m => Real.log (((Nat.choose N m : ℝ) * p^m * (1-p)^(N-m))) ) 2 i < 0
```

You may need a support-restricted version to avoid `choose N m = 0` outside range. That is acceptable, and probably cleaner.

Why this matters:
This gives a canonical family where entropy curvature is genuinely nontrivial and computable. It is the discrete Gaussian shadow, and the theorem should become the prototype example for the new theory.

## Proof Strategy Architecture

Do not give one proof hint. Execute one of several routes and record the alternatives in `RESEARCH_PAPER.md`.

### Strategy A: Direct finite-difference / logarithm algebra
Most promising for Theorems 1–3.

1. Expand
   \[
   \Delta^2(\log a)(n)=\log a_{n+2}-2\log a_{n+1}+\log a_n.
   \]
2. Rewrite via log identities as
   \[
   \log\!\left(\frac{a_n a_{n+2}}{a_{n+1}^2}\right).
   \]
3. Use monotonicity of `Real.log` on positive reals to convert sign of the logarithm into multiplicative inequalities.
4. For normalization invariance, use
   \[
   \log(a_n/Z)=\log a_n-\log Z
   \]
   and prove by induction on `k` that finite differences kill constants.

Why promising:
It is elementary, robust in Lean, and directly leverages positivity hypotheses.

Key Lean tactics likely needed:
`induction k with`, `field_simp`, `have`, `calc`, `linarith`, `nlinarith`, `rw [Real.log_mul, Real.log_div]`, positivity side conditions.

---

### Strategy B: Ratio-sequence and score-function route
Most promising for Theorem 5 and for lifting catalog results.

1. Use the catalog equivalence:
   log-concavity of `a` ↔ monotonicity of `a (n+1) / a n`.
2. Apply `Real.log_le_log` or monotonicity of `Real.log` to deduce monotonicity of
   \[
   \log(a_{n+1})-\log(a_n)=\log\!\left(\frac{a_{n+1}}{a_n}\right).
   \]
3. Interpret this as antitonicity of the discrete score function.

Why promising:
It directly exploits existing catalog infrastructure and avoids repeated second-difference expansion.

---

### Strategy C: Closed-form family computation
Most promising for geometric and binomial examples.

1. For geometric laws, prove by induction that all higher forward differences of an affine function vanish from order 2 onward.
2. For binomial laws, derive
   \[
   \frac{a_{i+1}}{a_i} = \frac{N-i}{i+1}\frac{p}{1-p}
   \]
   and then show the log-increment is strictly decreasing in `i`.
3. Deduce strict negativity of second finite differences.

Why promising:
This avoids ugly direct expansions of `choose` inside `log`, replacing them with a ratio formula and monotonicity argument.
