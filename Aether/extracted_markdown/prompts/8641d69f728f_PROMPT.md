```lean
structure FinProb (α : Type*) [Fintype α] where
  weight : α → ℝ

```

Define couplings:

```lean
structure Coupling {α β : Type*} [Fintype α] [Fintype β]
    (μ : FinProb α) (ν : FinProb β) where
  mass : α → β → ℝ
  nonneg : ∀ a b, 0 ≤ mass a b
  left_marginal : ∀ a, ∑ b, mass a b = μ.weight a
  right_marginal : ∀ b, ∑ a, mass a b = ν.weight b
```

Define transport cost:

```lean
def transportCost {α β : Type*} [Fintype α] [Fintype β]
    (c : α → β → ℝ) {μ : FinProb α} {ν : FinProb β}
    (π : Coupling μ ν) : ℝ :=
  ∑ a, ∑ b, c a b * π.mass a b
```

Define optimal cost:

```lean
def kantorovichValue {α β : Type*} [Fintype α] [Fintype β]
    (c : α → β → ℝ) (μ : FinProb α) (ν : FinProb β) : ℝ :=
```

```lean
def admissiblePotential {α β : Type*} [Fintype α] [Fintype β]
```

## Theorem 1: Existence of Optimal Couplings in the Finite Kantorovich Problem

### Statement
For every finite source and target probability distributions and every cost function, there exists a coupling attaining minimal transport cost.

### Lean-style signature
```lean
theorem exists_optimal_coupling
    {α β : Type*} [Fintype α] [Fintype β]
    (c : α → β → ℝ) (μ : FinProb α) (ν : FinProb β) :
    ∃ π : Coupling μ ν, ∀ π' : Coupling μ ν,
      transportCost c π ≤ transportCost c π'
```

### Why this matters
This is the formal cornerstone: without existence, Wasserstein distance is only a symbolic infimum. Once existence is certified, all downstream minimax and duality theorems become algorithmically meaningful.

### Proof strategy options
**Strategy A: Finite-dimensional compactness / Weierstrass**
1. Show the set of couplings is nonempty, e.g. via product coupling `μ ⊗ ν`.
2. Show each coupling entry is bounded: `0 ≤ π a b ≤ μ a` and also `≤ ν b`.
3. Embed couplings into a finite-dimensional cube; prove the feasible set is closed.
4. Use continuity of `transportCost` and finite-dimensional compactness to extract a minimizer.

**Strategy B: Linear programming on a finite polytope**
1. Express couplings as solutions to a finite system of linear equalities/inequalities.
2. Invoke or rebuild finite LP attainment on bounded feasible sets.
3. Show the linear objective attains a minimum at an extreme point.

**Strategy C: Explicit minimization over a finite certificate class**
Less elegant, likely weaker. Only use if you can encode a finite search over rational grids plus exact attainment under extra assumptions. This is less revolutionary.

**Most promising:** Strategy A. It aligns with Mathlib’s topology/analysis toolkit and scales toward weak convergence and Wasserstein compactness later.

## Theorem 2: Finite Kantorovich Duality

### Statement
For finite spaces, the primal optimal transport value equals the supremum over admissible dual potentials.

### Lean-style signature
A direct equality formulation:

```lean
theorem finite_kantorovich_duality
    {α β : Type*} [Fintype α] [Fintype β]
    (c : α → β → ℝ) (μ : FinProb α) (ν : FinProb β) :
    (∃ π : Coupling μ ν, ∀ π' : Coupling μ ν,
      transportCost c π ≤ transportCost c π') ∧
    (∃ φ : α → ℝ, ∃ ψ : β → ℝ, admissiblePotential c φ ψ) ∧
    (sInf {r : ℝ | ∃ π : Coupling μ ν, transportCost c π = r}) =
    sSup {r : ℝ | ∃ φ ψ, admissiblePotential c φ ψ ∧ dualValue c μ ν φ ψ = r}
```

A more Lean-friendly attainment form is better:

```lean
theorem finite_kantorovich_duality_attained
    {α β : Type*} [Fintype α] [Fintype β]
    (c : α → β → ℝ) (μ : FinProb α) (ν : FinProb β) :
    ∃ π : Coupling μ ν, ∃ φ : α → ℝ, ∃ ψ : β → ℝ,
      admissiblePotential c φ ψ ∧
      (∀ π' : Coupling μ ν, transportCost c π ≤ transportCost c π') ∧
      (∀ φ' ψ', admissiblePotential c φ' ψ' →
         dualValue c μ ν φ' ψ' ≤ dualValue c μ ν φ ψ) ∧
      transportCost c π = dualValue c μ ν φ ψ
```

### Why this matters
This is the decisive theorem. It turns transport from a combinatorial optimization problem into a convex-analytic one. In ML terms, it justifies critic-based objectives; in economics, it identifies price systems; in physics, it identifies generalized potentials.

### Proof strategy options
**Strategy A: Weak duality + primal attainment + finite-dimensional separation**
1. Prove weak duality:
   ```lean
   admissiblePotential c φ ψ → dualValue c μ ν φ ψ ≤ transportCost c π
   ```
   for every coupling `π`.
2. Use finite-dimensional convex separation / LP duality to upgrade weak duality to equality.
3. Extract optimal potentials and complementary slackness.

**Strategy B: Farkas lemma / linear programming duality**
1. Encode primal and dual as matrix LPs.
2. Use a verified finite-dimensional LP duality theorem if available, or prove a custom finite version.
3. Decode matrix variables into couplings/potentials.

**Strategy C: c-transform envelope**
1. Define the c-transform of a potential.
2. Reduce dual search to one family of potentials.
3. Show maximal c-convex envelope attains the dual optimum.

**Most promising:** Strategy A or B depending on Mathlib support. If LP duality infrastructure is thin, prove weak duality and then a custom separation theorem for the finite feasible polytope.

## Theorem 3: Complementary Slackness and Cyclical Monotonicity of Optimal Supports

### Statement
If `π` is optimal and `(φ, ψ)` is dual-optimal, then positive transport mass only occurs on pairs saturating the dual constraint; consequently the support is c-cyclically monotone. For quadratic cost, this yields a discrete Brenier-type structure.

### Lean-style signature
Complementary slackness:
```lean
theorem complementary_slackness_optimal_transport
    {α β : Type*} [Fintype α] [Fintype β]
    (c : α → β → ℝ) (μ : FinProb α) (ν : FinProb β)
    (π : Coupling μ ν) (φ : α → ℝ) (ψ : β → ℝ)
    (hoptπ : ∀ π' : Coupling μ ν, transportCost c π ≤ transportCost c π')
    (hdual : admissiblePotential c φ ψ)
    (hEq : transportCost c π = dualValue c μ ν φ ψ) :
    ∀ a b, 0 < π.mass a b → φ a + ψ b = c a b
```

Cyclical monotonicity:
```lean
def cCyclicallyMonotoneSupport {α β : Type*}
    [Fintype α] [Fintype β] (c : α → β → ℝ) (S : Set (α × β)) : Prop :=
  ∀ n : ℕ, ∀ xs : Fin n → α, ∀ ys : Fin n → β,
    (∀ i, (xs i, ys i) ∈ S) →
    ∀ σ : Equiv.Perm (Fin n),
      ∑ i, c (xs i) (ys i) ≤ ∑ i, c (xs i) (ys (σ i))
```

```lean
theorem optimal_support_cyclically_monotone
    {α β : Type*} [Fintype α] [Fintype β]
    (c : α → β → ℝ) (μ : FinProb α) (ν : FinProb β)
    (π : Coupling μ ν)
    (hoptπ : ∀ π' : Coupling μ ν, transportCost c π ≤ transportCost c π') :
    cCyclicallyMonotoneSupport c {p | 0 < π.mass p.1 p.2}
```

### Why this matters
This is where OT becomes geometry rather than bookkeeping. Cyclical monotonicity is the fingerprint of hidden convexity. It is the discrete shadow of Brenier’s theorem and the entry point to transport maps, Monge solutions, and convex potentials.

### Proof strategy options
**Strategy A: Derive from dual potentials**
1. Use complementary slackness to identify support with equality set of `φ a + ψ b = c a b`.
2. Sum equalities along cycles.
3. Compare against admissibility on permuted targets to get monotonicity.

**Strategy B: Exchange argument**
1. Assume non-cyclical monotonicity.
2. Construct an explicit perturbation of the coupling along a cycle.
3. Show cost strictly decreases, contradicting optimality.

**Strategy C: Quadratic-cost specialization**
For `c(x,y) = ‖x-y‖²`, rewrite cyclic inequality into monotonicity of a subgradient relation.

**Most promising:** Strategy A for general costs, then specialize to quadratic cost.

## Theorem 4: Discrete Brenier Theorem for One-Dimensional Quadratic Cost

Do **not** claim full Brenier in arbitrary dimension unless you can really formalize measurable gradients and absolute continuity. Instead prove a finite, sharp theorem that captures the essence.

### Statement
For finitely supported probability measures on `ℝ`, under strict ordering / atom-splitting assumptions, the optimal quadratic-cost coupling is monotone and induced by an order-preserving transport map whenever the source weights can be matched without splitting. Equivalently: among deterministic transport maps preserving mass, the monotone rearrangement minimizes quadratic cost.

### Lean-style signature
A workable finite-map theorem:

```lean
structure TransportMap (α β : Type*) [Fintype α] [Fintype β]
    (μ : FinProb α) (ν : FinProb β) where
  toFun : α → β
  pushes_forward :
    ∀ b, ∑ a in Finset.univ.filter (fun a => toFun a = b), μ.weight a = ν.weight b
```

```lean
theorem monotone_map_optimal_quadratic_on_chain
    {α β : Type*} [Fintype α] [Fintype β]
    [LinearOrder α] [LinearOrder β]
    (x : α → ℝ) (y : β → ℝ)
    (hx : StrictMono x) (hy : StrictMono y)
    (μ : FinProb α) (ν : FinProb β)
    (T : TransportMap α β μ ν)
    (hmono : Monotone T.toFun) :
    ∀ T' : TransportMap α β μ ν,
      (∑ a, (x a - y (T.toFun a))^2 * μ.weight a) ≤
      (∑ a, (x a - y (T'.toFun a))^2 * μ.weight a)
```

Or prove the two-point swap inequality first and then an induction on inversions.

### Why this matters
This is the formalizable heart of Brenier in discrete 1D: optimal transport is not arbitrary matching but **order-respecting convex geometry**. It also gives a verified sorting-based algorithm.

### Proof strategy options
**Strategy A: Swap argument / inversion induction**
1. Prove the key inequality:
   if `x₁ ≤ x₂` and `y₁ ≤ y₂`, then
   ```math
   (x₁-y₁)^2 + (x₂-y₂)^2 ≤ (x₁-y₂)^2 + (x₂-y₁)^2.
   ```
2. Show any non-monotone map has an inversion.
3. Swap the inverted pair to reduce or preserve cost.
4. Induct on inversion count to obtain monotone optimality.

**Strategy B: Convexity / rearrangement inequality**
1. Rewrite the quadratic objective.
2. Reduce to maximizing `∑ x(a) y(T(a)) μ(a)` under mass constraints.
3. Invoke or prove a weighted rearrangement inequality.

**Strategy C: Cyclical monotonicity specialization**
1. Use Theorem 3.
2. Show cyclic monotonicity in 1D implies monotonicity of the support.
3. Deduce map optimality.

**Most promising:** Strategy A. It is robust, elementary, and deeply nontrivial in Lean.

## Theorem 5: Wasserstein-1 as a Metric on Finite Probability Spaces

### Statement
Define a finite Wasserstein-1 distance using a metric cost `d`. Prove nonnegativity, symmetry, identity of indiscernibles, and triangle inequality.

### Lean-style signature
```lean
def Wasserstein1 {α : Type*} [Fintype α] (d : α → α → ℝ)
    (μ ν : FinProb α) : ℝ := 
  -- optimal value with cost d
  kantorovichValue d μ ν
```

```lean
theorem wasserstein1_is_metric
    {α : Type*} [Fintype α]
    (d : α → α → ℝ)
    (hd_nonneg : ∀ a b, 0 ≤ d a b)
    (hd_symm : ∀ a b, d a b = d b a)
    (hd_zero : ∀ a b, d a b = 0 ↔ a = b)
    (hd_triangle : ∀ a b c, d a c ≤ d a b + d b c) :
    (∀ μ ν, 0 ≤ Wasserstein1 d μ ν) ∧
    (∀ μ ν, Wasserstein1 d μ ν = Wasserstein1 d ν μ) ∧
    (∀ μ ν, Wasserstein1 d μ ν = 0 ↔ μ = ν) ∧
    (∀ μ ν ρ, Wasserstein1 d μ ρ ≤ Wasserstein1 d μ ν + Wasserstein1 d ν ρ)
```

### Why this matters
This elevates transport from an optimization problem to a geometry on probability distributions. Once formalized, it becomes a verified substrate for convergence, gradient flows, and learning dynamics.

### Proof strategy options
**Strategy A: Gluing lemma in finite form**
1. Build couplings `π₁₂` and `π₂₃`.
2. Construct a joint triple distribution.
3. Marginalize to obtain a coupling between `μ` and `ρ`.
4. Apply the triangle inequality under the sum.

**Strategy B: Duality-based proof**
1. Use finite Kantorovich duality with 1-Lipschitz potentials.
2. Derive symmetry and triangle from test-function composition.

**Most promising:** Strategy A, because finite gluing is constructive and algorithmic.

## Cross-Domain Theorem: Wasserstein Adversarial Objectives Are Lipschitz-Stable

This is your required cross-domain connection: **optimal transport + machine learning / minimax analysis**.

### Statement
Let `F` be a class of `K`-Lipschitz critics on a finite metric space. Then the discrepancy
```math
Δ_F(μ, ν) = sup_{f ∈ F} \left( \mathbb{E}_μ[f] - \mathbb{E}_ν[f] \right)
```
is bounded by `K * W₁(μ, ν)`. This is the finite certified core of Wasserstein GAN critic stability.

### Lean-style signature
```lean
def criticGap {α : Type*} [Fintype α]
    (μ ν : FinProb α) (F : Set (α → ℝ)) : ℝ :=
  sSup {r : ℝ | ∃ f ∈ F,
    (∑ a, f a * μ.weight a) - (∑ a, f a * ν.weight a) = r}
```

```lean
def isKLipschitzFamily {α : Type*} [Fintype α]
    (d : α → α → ℝ) (K : ℝ) (F : Set (α → ℝ)) : Prop :=
  ∀ f ∈ F, ∀ a b, |f a - f b| ≤ K * d a b
```

```lean
theorem criticGap_le_KWasserstein
    {α : Type*} [Fintype α]
    (d : α → α → ℝ) (K : ℝ) (μ ν : FinProb α) (F : Set (α → ℝ))
    (hK : 0 ≤ K)
    (hF : isKLipschitzFamily d K F) :
    criticGap μ ν F ≤ K * Wasserstein1 d μ ν
```

### Why this is a breakthrough
This theorem is the mathematically clean, formal kernel behind WGANs: the critic objective cannot distinguish distributions more than transport geometry allows. It is a verified **generalization/stability theorem** for adversarial learning. Combined with duality, it becomes a formal bridge between **GAN training, robust optimization, and transport geometry**.

### Proof strategy options
**Strategy A: Coupling bound**
1. Fix any critic `f` and any coupling `π`.
2. Rewrite expectation difference as
   ```math
   ∑_{a,b} (f(a)-f(b)) π(a,b).
   ```
3. Bound by Lipschitzness:
   ```math
   ≤ K ∑_{a,b} d(a,b) π(a,b).
   ```
4. Take inf over couplings, sup over critics.

**Strategy B: Duality**
1. Rescale `f/K` to a 1-Lipschitz dual potential.
2. Apply Kantorovich–Rubinstein-style duality in finite form.

**Most promising:** Strategy A. It is direct and gives a computational certificate.
