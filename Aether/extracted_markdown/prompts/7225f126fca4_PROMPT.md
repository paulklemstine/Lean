## Research Task: finite-ball anti-automorphism rigidity for the Berggren positive semigroup inside `SL(2, ℤ)`

Research Mode: PROVE

Work with the existing Berggren/SPB embedding infrastructure and isolate a theorem that is genuinely stronger than ordinary finite-ball injectivity: positive Berggren words are separated not only from each other, but also from their images under the standard `SL₂(ℤ)` anti-involutions. The core phenomenon to formalize is that the positive semigroup generated by the Berggren matrices has a built-in orientation on boundary data (columns / slopes / action on positive rationals), and transpose or inverse-conjugate reverses that orientation in a way incompatible with positive-word growth.

### Precise target theorem family

You should aim to prove one or both of the following formulations, depending on the exact API already available for Berggren words and their matrix evaluation.

#### Matrix-level rigidity statement
If the library already has:
- concrete generators `A B C : Matrix (Fin 2) (Fin 2) ℤ`,
- a word type such as `List BerggrenGen` or `FreeMonoid BerggrenGen`,
- an evaluation map `eval : Word → Matrix (Fin 2) (Fin 2) ℤ`,
- and a finite-ball set `ball N := {w | w.length ≤ N}`,

then target a theorem of the shape:
```lean
theorem berggren_eval_ne_transpose_of_ne
    (N : ℕ)
    {w v : Word}
    (hw : w.length ≤ N)
    (hv : v.length ≤ N)
    (hposw : w ≠ 1)
    (h : eval w = (eval v)ᵀ) :
    False
```
or, more canonically if equality can only occur in the empty-word case,
```lean
theorem berggren_eval_eq_transpose_iff
    (N : ℕ)
    {w v : Word}
    (hw : w.length ≤ N)
    (hv : v.length ≤ N) :
    eval w = (eval v)ᵀ ↔ w = 1 ∧ v = 1
```

For the second anti-involution, let `J` be the standard symplectic/flip matrix used in the existing `SL₂` development. Prove:
```lean
theorem berggren_eval_eq_J_conjInv_iff
    (N : ℕ)
    {w v : Word}
    (hw : w.length ≤ N)
    (hv : v.length ≤ N) :
    eval w = J ⬝ (eval v)⁻¹ ⬝ J⁻¹ ↔ w = 1 ∧ v = 1
```
If the semigroup is represented in a subtype of determinant-`1` matrices, adapt the statement accordingly, e.g. with `↑(eval w)` in the ambient matrix type.

#### Reversal-collision separation statement
If there is already a theorem identifying matrix evaluation of reversed words with an anti-involution, prove the stronger combinatorial corollary:
```lean
theorem berggren_eval_reverse_ne_self
    (N : ℕ)
    {w : Word}
    (hw : w.length ≤ N)
    (hnonempty : w ≠ 1) :
    eval w.reverse ≠ eval w
```
or, if `reverse` lives on lists,
```lean
theorem berggren_list_eval_reverse_ne_self

```

```lean
theorem berggren_eval_reverse_eq_iff
    (N : ℕ)
    {w : Word}
    (hw : w.length ≤ N) :
    eval w.reverse = eval w ↔ w = 1
```

### Preferred invariant and exact proof strategy

The most promising route is to use a boundary/slope invariant attached to a positive `2×2` matrix. For a matrix
`g = !![a, b; c, d]` with strictly positive entries, define one or both of:
- the ordered column slopes `σ₁(g) := c / a`, `σ₂(g) := d / b` in `ℚ` or `ℝ`,
- the image interval on positive projective line, e.g.
  `I(g) := (g • 0, g • ∞)` or concretely `(b/d, a/c)` depending on the chosen convention,
- a row/column asymmetry invariant such as `a < c` versus `b < d`, if this is already known for all positive Berggren words.

Then prove that every positive Berggren word lands in a rigid cone of matrices where transpose and `J g⁻¹ J⁻¹` move the invariant into a disjoint cone.

Concretely, the proof should be organized around the following steps.

1. **Positivity and strict order of columns for Berggren words.**  
   Prove that every nonempty positive Berggren word evaluates to a matrix with nonnegative, in fact strictly positive, entries and with a strict monotonicity pattern on columns/rows. Typical useful lemmas are:
   ```lean
   theorem berggren_eval_entry_pos
       {w : Word} (hw : w ≠ 1) (i j : Fin 2) :
       0 < (eval w) i j

   theorem berggren_eval_column_slope_strict
       {w : Word} (hw : w ≠ 1) :
       ((eval w) 1 0 : ℚ) / ((eval w) 0 0 : ℚ) <
       ((eval w) 1 1 : ℚ) / ((eval w) 0 1 : ℚ)
   ```
   If division is inconvenient, cross-multiply using positivity:
   ```lean
   theorem berggren_eval_cross_det_pos
       {w : Word} (hw : w ≠ 1) :
       (eval w) 1 0 * (eval w) 0 1 < (eval w) 1 1 * (eval w) 0 0
   ```
   Since `det = 1`, one expects the difference to be exactly `1` up to sign after rearrangement; exploit that.

2. **Anti-involutions reverse the slope interval.**  
   Compute explicitly how transpose and `J g⁻¹ J⁻¹` act on the chosen invariant. For instance, transpose swaps row/column data, while `J g⁻¹ J⁻¹` often exchanges the same two projective endpoints. Prove lemmas of the form:
   ```lean
   theorem slope_interval_transpose
       {g : Matrix (Fin 2) (Fin 2) ℤ}
       (hpos : PositiveMatrix2 g) :
       leftSlope (gᵀ) = rowLeftSlope g ∧
       rightSlope (gᵀ) = rowRightSlope g

   theorem slope_interval_J_conjInv
       {g : Matrix (Fin 2) (Fin 2) ℤ}
       (hg : g ∈ SL2Z) :
       intervalInvariant (J ⬝ g⁻¹ ⬝ J⁻¹) = intervalInvariant g |> reverse
   ```
   The point is not just to compute the formula, but to show the image invariant lies in the “wrong orientation class”.

3. **Disjointness of positive-word region from anti-image region.**  
   Show that for every nonempty Berggren word `w`, the matrix `eval w` satisfies a strict inequality incompatible with being a transpose or `J`-conjugate inverse of another positive Berggren word. Typical contradiction patterns:
   - positive words always satisfy `entry 0 0 < entry 1 1` and `entry 1 0 < entry 0 1`, but transpose flips one of these,
   - positive words always have increasing column slopes, while anti-involutions force decreasing slopes,
   - positive words map the positive projective cone to a positively oriented interval, while anti-involutions reverse orientation.

   The ideal theorem here is a clean matrix lemma independent of words:
   ```lean
   theorem berggren_positive_matrix_ne_transpose_of_orientation
       {g h : Matrix (Fin 2) (Fin 2) ℤ}
       (hg : InBerggrenPositiveCone g)
       (hh : InBerggrenPositiveCone h)
       (hgne : g ≠ 1) :
       g ≠ hᵀ
   ```
   and similarly for `J ⬝ h⁻¹ ⬝ J⁻¹`.

4. **Upgrade matrix separation to finite-ball word separation.**  
   Combine the new anti-rigidity lemma with the existing finite-ball injectivity/cancellation theorem to conclude:
   ```lean
   theorem berggren_ball_anti_collision_free
       (N : ℕ) :
       Set.InjOn eval {w | w.length ≤ N} ∧
       (∀ ⦃w v⦄, w.length ≤ N → v.length ≤ N → eval w ≠ (eval v)ᵀ) ∧
       (∀ ⦃w v⦄, w.length ≤ N → v.length ≤ N → eval w ≠ J ⬝ (eval v)⁻¹ ⬝ J⁻¹)
   ```
   If the empty word is a genuine exception, isolate it explicitly rather than hiding it:
   ```lean
   theorem berggren_ball_anti_collision_free_except_identity
       (N : ℕ) :
       ∀ ⦃w v⦄, w.length ≤ N → v.length ≤ N →
         eval w = (eval v)ᵀ →
         w = 1 ∧ v = 1
   ```

5. **Derive reversal separation as a corollary.**  
   If there is an already-verified theorem connecting `eval (reverse w)` with one of the anti-involutions, use it directly:
   ```lean
   theorem berggren_reverse_collision_free
       (N : ℕ) {w v : Word}
       (hw : w.length ≤ N) (hv : v.length ≤ N)
       (h : eval w = eval v.reverse) :
       w = 1 ∧ v = 1
   ```
   In particular:
   ```lean
   theorem berggren_nonempty_word_ne_reverse
       (N : ℕ) {w : Word}
       (hw : w.length ≤ N) (hnonempty : w ≠ 1) :
       eval w ≠ eval w.reverse
   ```

### Lean-specific implementation advice

Use the most concrete type possible. If the current files work with plain matrices:
```lean
Matrix (Fin 2) (Fin 2) ℤ
```
then keep all algebra there and coerce to `ℚ` or `ℝ` only for slope inequalities. Cross-multiplication is often easier than division because positivity of entries is available. For `2×2` matrices, it is worth introducing entry abbreviations:
```lean
let a := g 0 0
let b := g 0 1
let c := g 1 0
let d := g 1 1
```
and then proving the needed inequalities by reducing to `ad - bc = 1`.

If the Berggren generators are already known to have strictly positive entries and determinant `1`, a useful inductive predicate is:
```lean
def PositiveCone2 (g : Matrix (Fin 2) (Fin 2) ℤ) : Prop :=
  0 < g 0 0 ∧ 0 < g 0 1 ∧ 0 < g 1 0 ∧ 0 < g 1 1 ∧
  g 1 0 * g 0 1 < g 1 1 * g 0 0
```
Then prove:
```lean
theorem berggren_eval_mem_PositiveCone2
    {w : Word} (hw : w ≠ 1) :
    PositiveCone2 (eval w)
```
and separately:
```lean
theorem PositiveCone2.not_transpose
    {g h : Matrix (Fin 2) (Fin 2) ℤ}
    (hg : PositiveCone2 g) (hh : PositiveCone2 h) :
    g ≠ hᵀ
```
The latter should come from comparing the strict cross-inequality for `g` with the corresponding inequality for `hᵀ`, which becomes the opposite inequality after transposition.

Similarly, for the inverse-conjugate involution, exploit the explicit `SL₂` formula
for `g = !![a,b;c,d]` with `ad - bc = 1`:
```text
g⁻¹ = !![d,-b;-c,a]
J g⁻¹ J⁻¹ = !![a,c;b,d]
```
for the appropriate choice of `J` (or a closely related formula depending on conventions). In many conventions this is exactly transpose or column-swap/row-swap composed with transpose. Compute it once and reduce the theorem to the transpose case plus a permutation argument.

### Why this matters

This theorem upgrades ordinary collision-freeness of the SPB/Berggren embedding to a much stronger anti-structural rigidity statement. Existing finite-ball injectivity only rules out direct collisions `M(w)=M(v)`. What is needed for protocol-level robustness is that no hidden collision appears after reversing transcript order, taking adjoints, or normalizing by the natural `SL₂` anti-involutions. Proving that positive Berggren words occupy an orientation-rigid region of `SL₂(ℤ)` gives exactly that: reverse-reading a transcript cannot accidentally land back inside the same positive image. This is the semigroup analogue of a “no palindromic adjoint collision” principle and is the right structural input for later cryptographic arguments about transcript canonicalization, anti-automorphism resistance, and uniqueness of normal forms under adversarial re-encoding.
