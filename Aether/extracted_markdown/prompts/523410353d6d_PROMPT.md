## Assignment: Chaos as a Computable Shadow: The Shadowing Lemma for Real Programs

### Vision

The shadowing lemma is the deepest theorem in computational mathematics that most computer scientists have never heard of. It says: *every approximate orbit of a chaotic system is shadowed by a true orbit*. This means your computer's rounding errors are not bugs — they are tracing out REAL orbits of the chaotic system, just with different initial conditions. Numerical chaos is not error; it is a computable shadow of mathematical truth.

We will formalize this for the first time in a proof assistant: prove the shadowing lemma for expanding maps on metric spaces, specialize it to the logistic map f(x) = 4x(1−x) via topological conjugacy, and establish that floating-point computations of chaotic orbits are shadowed by true orbits with explicitly computable bounds. This opens the field of **certified numerical chaos** — the rigorous study of what your computer is actually computing when it simulates chaos.

### Novel Definitions

```lean
/-- A δ-pseudo-orbit of f: each step deviates from f by at most δ -/
def IsPseudoOrbit {X : Type*} [MetricSpace X] (f : X → X) (δ : ℝ) 
    {n : ℕ} (x : Fin (n+1) → X) : Prop :=
  ∀ i : Fin n, dist (x (i+1)) (f (x i)) < δ

/-- A true orbit y ε-shadows a pseudo-orbit x -/
def ShadowsOrbit {X : Type*} [MetricSpace X] (f : X → X) (ε : ℝ) 
    {n : ℕ} (x : Fin (n+1) → X) (y : Fin (n+1) → X) : Prop :=
  (∀ i : Fin n, y (i+1) = f (y i)) ∧ (∀ i : Fin (n+1), dist (x i) (y i) < ε)

/-- A map f has the shadowing property if every pseudo-orbit is shadowed -/
def HasShadowingProperty {X : Type*} [MetricSpace X] (f : X → X) : Prop :=
  ∀ ε > 0, ∃ δ > 0, ∀ n : ℕ, ∀ x : Fin (n+1) → X,
    IsPseudoOrbit f δ x → ∃ y : Fin (n+1) → X, ShadowsOrbit f ε x y

/-- An expanding map with expansion factor λ > 1 -/
def IsExpanding {X : Type*} [MetricSpace X] (f : X → X) (λ : ℝ) : Prop :=
  λ > 1 ∧ ∀ x y, dist (f x) (f y) ≥ λ * dist x y

/-- The logistic map on [0,1] -/
def logistic (x : ℝ) : ℝ := 4 * x * (1 - x)

/-- The tent map on [0,1] -/
def tentMap (y : ℝ) : ℝ := 2 * min y (1 - y)

/-- The topological conjugacy h : [0,1] → [0,1] with h ∘ tentMap = logistic ∘ h -/
def chaosConj (y : ℝ) : ℝ := (sin (π * y / 2))²
```

### Proof Strategies

**Strategy A: Banach Fixed Point on Sequence Space (Most Direct, Best Bounds)**
1. Define the shadowing operator S on the space of sequences: for a pseudo-orbit x, define S(y)_0 = x_0, S(y)_{i+1} = f(y_i) + (x_{i+1} - f(x_i)). This "corrects" a candidate orbit by adding the pseudo-orbit error.
2. Show S is a contraction on the Banach space ℓ^∞({0,...,N}, X) with contraction ratio 1/λ, using the expanding condition: dist(S(y)_i, S(z)_i) ≤ (1/λ) · max_j dist(y_j, z_j).
3. Apply Banach's fixed point theorem: the unique fixed point of S is a true orbit that ε-shadows x with ε ≤ δ/(λ-1).
4. *Why most promising*: Gives the tightest bound (ε ≈ δ/(λ-1)) and the proof is constructive — the fixed point iteration IS the algorithm for demo.py.
5. *Challenge in Lean*: Need to construct the Banach space of bounded sequences; Mathlib has `MetricSpace` and `CompleteSpace` but the assembly requires careful norm construction.

**Strategy B: Topological Conjugacy to Tent Map (Most Elegant, Best Decomposition)**
1. Prove the tent map T(y) = 2·min(y, 1-y) is expanding with λ = 2 on [0,1] — this is a direct computation on each piece (y ≤ 1/2 and y ≥ 1/2).
2. Prove the conjugacy h(y) = sin²(πy/2) satisfies h(T(y)) = f(h(y)) — this requires the identity sin²(π·min(y,1-y)/2) = 4sin²(πy/2)(1-sin²(πy/2)), which splits into cases.
3. Prove h is bi-Lipschitz with constants (π/2) and 2 — compute h'(y) = π·sin(πy)·cos(πy)/2 = (π/2)·sin(2πy)/2, bounded between 0 and π/2.
4. Apply Theorem 2 to transfer shadowing from tent map to logistic map, getting ε ≤ 4δ (the factor 4 = 2·2 comes from the Lipschitz constants).
5. *Why promising*: Decomposes into clean, independently verifiable sub-goals. The tent map is piecewise linear, so expanding is trivial. The conjugacy is the only analytic work.
6. *Challenge in Lean*: The case split in the tent map (y ≤ 1/2 vs y ≥ 1/2) and the trigonometric identities require careful handling. Mathlib's trig functions should suffice.

**Strategy C: Inductive Correction with Expanding Pullback (Most Constructive, Best for Computation)**
1. Set y_N = x_N (match at the endpoint — this is the "backward" shadowing trick).
2. Inductively define y_{i-1} = f⁻¹(y_i) chosen so that dist(y_{i-1}, x_{i-1}) is minimized, using the expanding condition to ensure uniqueness.
3. Show by backward induction that dist(y_i, x_i) ≤ δ/(λ-1) · (1 - λ^{-(N-i)}) ≤ δ/(λ-1).
4. *Why promising*: Gives an explicit, computable shadowing orbit. The backward construction avoids the need for fixed-point theorems.
5. *Challenge in Lean*: Need surjectivity of f and uniqueness of preimages (expanding maps on compact spaces are covering maps). Requires more topological machinery.

**Recommended path**: Strategy B for the main theorems (cleanest decomposition into sub-lemmas that Mathlib can handle), with Strategy A providing the quantitative bound and the algorithm for demo.py.

### Cross-Domain Connections

1. **Numerical Analysis ↔ Dynamical Systems: Shadowing as Dual Backward Error Analysis**: In ODE theory, *backward error analysis* says "the numerical solution solves a nearby ODE exactly" — it modifies the equation. Shadowing says "the numerical orbit is close to an exact orbit of the original equation" — it modifies the initial condition. These are dual: backward error analysis preserves the solution but perturbs the equation; shadowing preserves the equation but perturbs the solution. Formalizing this duality opens **certified backward error analysis for chaotic systems**: for any numerical integrator of a chaotic ODE, the computed orbit shadows a true orbit with computable distance. This is the chaos-theoretic analogue of Wilkinson's backward stability.

2. **Information Theory ↔ Topological Dynamics: Shadowing Capacity = Metric Entropy**: The shadowing bound ε ≤ δ/(λ-1) implies that a δ-pseudo-orbit carries log₂(1/δ) bits of information about the true orbit, but the chaotic map destroys λ bits per iteration. The *shadowing capacity* — the maximum information recoverable from a noisy orbit — equals the metric entropy h_μ(f) = log(λ). This is not a coincidence: it is a consequence of the variational principle. Formalizing this connects Shannon entropy to topological dynamics, enabling **information-theoretic certification of chaotic simulations**.

3. **Cryptography ↔ Chaos: Shadowing as Post-Quantum Indistinguishability**: Chaotic maps (logistic, tent) are used as PRNGs. Shadowing implies: given any perturbation (side-channel noise, quantum error) of a chaotic PRNG output, there exists a legitimate seed producing a nearby output. This is a form of *computational indistinguishability* — perturbed outputs are indistinguishable from legitimate ones because they ARE legitimate (for different seeds). This bridges shadowing to **differential privacy for chaotic systems**: the "privacy budget" ε corresponds to the shadowing distance.

### Testable Conjecture

**Conjecture (Sharp Shadowing Bound for the Logistic Map)**: For the logistic map f(x) = 4x(1−x) on [0,1], every δ-pseudo-orbit of length N is ε-shadowed by a true orbit with ε = 4δ + O(δ²), and the constant 4 is sharp (achieved by pseudo-orbits near x = 1/2 where the conjugacy has maximum derivative). Furthermore, for any ε > 0, the maximum shadowable orbit length scales as N_max(ε, δ) = Ω(log(1/δ)) — shadowing persists for exponentially many iterations.

**Computational test**: 
1. Implement f(x) = 4x(1−x) in float64 (machine epsilon δ ≈ 2^{-52} ≈ 2.2×10^{-16}).
2. For each of 10⁴ random initial conditions x₀ ∈ [0,1], compute the floating-point orbit x₀, ..., x_N for N = 10⁶.
3. For each such pseudo-orbit, use bisection on initial conditions to find y₀ such that the true orbit (computed in arbitrary precision) y₀, ..., y_N ε-shadows x₀, ..., x_N.
4. Plot shadowing distance ε vs orbit position n. Verify: ε ≤ 4δ ≈ 10^{-15} uniformly in n, with the bound tight near x = 1/2.
5. Plot ε vs δ for fixed N. Verify the linear relationship ε = 4δ + O(δ²).
6. Compare with the naive (non-shadowing) error growth: without shadowing, errors grow as δ · 2^n, reaching O(1) after n ≈ 52 iterations. With shadowing, errors stay bounded at 4δ forever.
