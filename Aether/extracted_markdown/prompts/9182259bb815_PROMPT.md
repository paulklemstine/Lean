## Core Vision

The present catalog controls tropical kernel generators when cycle supports are pairwise disjoint. That is a rigidity theorem in the “non-interacting particle” regime. The real mathematics begins when supports overlap: then generators can no longer be read independently, and one expects interaction terms, fusion phenomena, and possibly new equivalence classes invisible in the disjoint case.

The breakthrough target is:

> **Overlap Rigidity Principle:** the tropical projective equivalence classes of minimal generating families are controlled exactly by the overlap-pattern of cycle supports.

This would connect:
- **tropical linear algebra**: minimal generators of tropical kernels,
- **combinatorial topology**: cycle overlap in induced subgraphs,
- **matroid theory**: circuit intersection graphs and circuit elimination,
- **coding theory**: overlap profiles of supports of minimal codewords,
- **statistical physics/network science**: interacting support complexes rather than isolated excitations.

Application keywords: **tropical kernel rigidity, overlap complexes, cycle-space invariants, matroid circuits, support hypergraphs, graph invariants, coding-theoretic support profiles, network topology, combinatorial Hodge structures, algorithmic graph classification**.

## Recommended Proof Architecture

You must present at least **2–3 proof strategies**, and choose one as primary.

### Strategy A: Induction on overlap degree via peeling
Most faithful to the original conjectural vision.

1. Define `overlapDegree F` as a finite complexity measure that is zero exactly in the pairwise-disjoint case.
2. Prove the base case:
   - `overlapDegree = 0` reduces to the existing rigidity theorem from `TropicalKernelRigidity.lean`.
3. For the inductive step:
   - choose overlapping supports `A, B`,
   - peel off an intersection vertex or split along a minimal overlap separator,
   - compare the original generating family with a modified family whose overlap degree strictly decreases,
   - control the correction term using `support_matching_injective` and induced-cycle-rank arguments from `DefectTheory.lean`.

**Why promising:** this directly extends the current disjoint-support theorem and has a natural finite descent parameter.

### Strategy B: Component factorization through the support interaction graph
Probably the cleanest route to a first major theorem.

1. Define the overlap graph on cycle supports.
2. Show that if the overlap graph is disconnected, then any minimal generating family splits into independent sectors.
3. Prove that `TropProjEquiv` respects this decomposition and acts componentwise.
4. Deduce multiplicativity or additivity of class counts over overlap components.

**Why promising:** this avoids the hardest local-overlap combinatorics and may already reveal the correct invariant. If the full equality conjecture is false, this theorem is likely still true and foundational.

### Strategy C: Matroid-circuit reformulation
Potentially the deepest conceptual route.

1. Interpret cycle supports as circuit supports in the graphic matroid on `G[S]`.
2. Replace graph-specific overlap language by the circuit intersection graph of the matroid.
3. Use circuit elimination to understand how overlap can transform one generating family into another.
4. Translate back to tropical kernels to prove invariance of overlap classes, or identify the extra datum needed beyond overlap classes.

**Why promising:** if successful, this would immediately generalize from graphs to regular matroids or valuated matroids, which is field-opening.

**Suggested priority:** start with **Strategy B**, because it is the highest-probability path to a genuine theorem. Then attempt **Strategy A** for overlap-degree one. Keep **Strategy C** in reserve for conceptual generalization or if the graph-only formulation becomes technically brittle.
