You are not being asked to merely introduce two invariants. You are being asked to build a **bridge theorem** between probabilistic dynamics and tropical/idempotent dynamics on the same finite directed graph, in a form strong enough to seed a new comparison theory.

## Mathematical core

Let `P : Fin n → Fin n → ℝ` be a row-stochastic matrix with strictly positive entries:
\[
(\forall i,j,\; 0 < P_{ij}) \quad\text{and}\quad \sum_j P_{ij} = 1.
\]
Define the associated logarithmic weight matrix
\[
W_{ij} := -\log(P_{ij}).
\]
This places the Markov kernel into tropical additive geometry.

### Proposed definitions

You should formalize at least the following:

1. **Row-stochasticity**
   \[
   \mathrm{RowStochastic}(P) :\!\iff \forall i,\; \sum_j P_{ij} = 1.
   \]

2. **Strict positivity**
   \[
   \mathrm{Positive}(P) :\!\iff \forall i j,\; 0 < P_{ij}.
   \]

3. **Tropical weight transform**
   \[
   W = \mathrm{logWeight}(P), \qquad W_{ij} = -\log(P_{ij}).
   \]

4. **Cycle weight**
   For a cycle `c = [v₀, v₁, …, v_k]` with `v_k = v₀`,
   \[
   \mathrm{cycleWeight}(W,c) = \sum_{t=0}^{k-1} W_{v_t,v_{t+1}}.
   \]

5. **Tropical cycle gap**
   A workable first formal target is not the full “gap between minimum and second minimum cycle mean” unless you can manage cycle enumeration cleanly. A strong and Lean-friendly surrogate is:
   \[
   g(W) := \inf_{\text{nontrivial cycles } c} \frac{\mathrm{cycleWeight}(W,c)}{\mathrm{length}(c)}.
   \]
   On a finite graph with full support this is finite and nonnegative. If needed, define a simpler version first:
   \[
   g_\triangle(W) := \min_{i,j,k} \frac{W_{ij}+W_{jk}+W_{ki}}{3},
   \]
   the minimum triangle mean. This is already nontrivial and computationally tractable in Lean.

6. **Spectral gap surrogate**
   A fully general spectral gap for arbitrary non-reversible stochastic matrices is subtle to formalize. Do not get trapped here. Use one of these precise substitutes:

   - **Symmetric case**: assume `P` is symmetric stochastic, so the top eigenvalue is `1`, and define
     \[
     \gamma(P) := 1 - \max\{|\lambda| : \lambda \in \mathrm{spec}(P),\ \lambda \neq 1\}.
     \]
   - **Entrywise contraction surrogate**:
     \[
     \gamma_{\min}(P) := 1 - \max_{i,j} P_{ij}.
     \]
     This is weaker but Lean-friendly and still meaningful under the log transform.
   - **Diagonal/off-diagonal gap** if you need a first theorem:
     \[
     \gamma_{\mathrm{diag}}(P) := \min_i P_{ii} - \max_{i\neq j} P_{ij}.
     \]

The best route is to define both:
- a genuine spectral-gap notion in the symmetric case,
- a universal elementary surrogate valid without spectral machinery.

Then prove bridge theorems first for the surrogate, and if possible a second theorem for the true symmetric spectral gap.

## Precise theorem targets

### Theorem 1: Log-transform lower bound for tropical cycle mean
This is the first foundational bridge theorem and should be proved completely.

Assume `P` is row-stochastic and strictly positive on `Fin (n+1)`, and let `W i j = - Real.log (P i j)`.

Then for every nontrivial cycle `c` of length `k ≥ 1`,
\[
\frac{\mathrm{cycleWeight}(W,c)}{k}
\;\ge\;
-\log\!\Big(\max_{i,j} P_{ij}\Big).
\]
Hence
\[
g(W)\;\ge\; -\log\!\Big(\max_{i,j} P_{ij}\Big).
\]

This theorem is elementary but not trivial: it says that the tropical minimum cycle mean is controlled by the largest one-step transition probability. It is the first rigorous comparison principle between probabilistic transport and tropical cycle geometry.

### Lean 4 target signature for Theorem 1
A realistic first signature is:

```lean
theorem tropical_cycle_mean_lower_bound_of_entrywise_bound
    {n : ℕ}
    (P : Fin (n+1) → Fin (n+1) → ℝ)
    (hpos : ∀ i j, 0 < P i j)
    (hbound : ∀ i j, P i j ≤ s)
    (hs : 0 < s) :
    ∀ (c : List (Fin (n+1))),
      c.length > 1 →
      List.Chain' (fun a b => True) c →
      let w := fun i j => -Real.log (P i j)
      (-Real.log s) * (c.length - 1 : ℕ) ≤
        ((c.zip c.tail).map (fun e => w e.1 e.2)).sum
```

You may refine the cycle representation. If list-based cycles become annoying, define triangle cycles first and prove the triangle version:

```lean
theorem tropical_triangle_mean_lower_bound
    {n : ℕ}
    (P : Fin (n+1) → Fin (n+1) → ℝ)
    (hpos : ∀ i j, 0 < P i j)
    (hbound : ∀ i j, P i j ≤ s)
    (hs : 0 < s)
    (i j k : Fin (n+1)) :
    -Real.log s ≤
      ((-Real.log (P i j)) + (-Real.log (P j k)) + (-Real.log (P k i))) / 3
```

This triangle theorem is an excellent formal beachhead.

### Theorem 2: Uniform positivity forces positive tropical cycle gap
If `P` is strictly positive and uniformly bounded away from `1`,
\[
\forall i,j,\; P_{ij} \le 1-\varepsilon,\qquad 0<\varepsilon<1,
\]
then
\[
g(W) \ge -\log(1-\varepsilon) > 0.
\]

This is conceptually important: **classical non-determinism implies tropical cycle separation**. In other words, if no transition is too concentrated, then every tropical cycle incurs a definite positive cost per step.

### Theorem 3: Symmetric stochastic case — spectral gap to tropical gap comparison
This is the breakthrough theorem. Even a weaker explicit inequality would be valuable.

Assume `P` is symmetric, row-stochastic, strictly positive, and let `γ(P)` be the spectral gap:
\[
\gamma(P) = 1 - \lambda_2(P)
\]
with eigenvalues ordered in the symmetric case.

Seek an inequality of the form
\[
g(W) \ge -\log(1-\gamma(P)),
\]
or more realistically,
\[
g(W) \ge -\log\!\big(\rho_*(P)\big),
\]
where `ρ_*(P)` is an explicit spectral upper bound on entries or short-cycle transition probabilities derived from the spectral gap.

This will likely require an auxiliary theorem:
if `P` is symmetric stochastic and all entries satisfy
\[
P_{ij} \le 1-\gamma(P),
\]
then apply Theorem 1. This exact premise may not always hold, so a more realistic route is to prove a **two-step version**:
\[
(P^m)_{ij} \le \alpha(\gamma,m,n)
\quad\Longrightarrow\quad
g(W^{(m)}) \ge -\log \alpha(\gamma,m,n),
\]
where `W^{(m)}_{ij} = -\log((P^m)_{ij})`.

This is where the project becomes genuinely new: tropical geometry of multi-step kernels controlled by spectral mixing.

### Lean 4 aspirational signature for a symmetric bridge theorem

```lean

    (P : Matrix (Fin (n+1)) (Fin (n+1)) ℝ)
    (hsymm : P.IsSymm)
    (hrow : ∀ i, ∑ j, P i j = 1)
    (hpos : ∀ i j, 0 < P i j)
    (hpowbound : ∀ i j, (P ^ m) i j ≤ α) 
    (hα : 0 < α) :
    -Real.log α ≤ tropicalCycleGap (fun i j => -Real.log ((P ^ m) i j))
```

## Proof strategy architecture

### Strategy A: Entrywise logarithmic comparison first, cycle aggregation second
This is the most promising route for the first theorem.

1. Prove the scalar monotonicity lemma:
   if `0 < x ≤ s`, then
   \[
   -\log s \le -\log x.
   \]
   In Lean this is a straightforward application of `Real.strictAntiOn_log` or monotonicity of `Real.log`.

2. Sum the inequality over the edges of a cycle:
   each edge weight is at least `-log s`, so a `k`-edge cycle has total weight at least `k * (-log s)`.

3. Divide by `k` to get the mean bound, then infimize over all cycles.

Why this is promising:
- it avoids deep spectral formalization;
- it produces a real theorem immediately;
- it creates reusable infrastructure for every later bridge result.

### Strategy B: Triangle-gap first, then general cycle gap
This is the best fallback if cycle formalization becomes cumbersome.

1. Define `triangleCycleGap`:
   \[
   \min_{i,j,k} \frac{W_{ij}+W_{jk}+W_{ki}}{3}.
   \]

2. Prove the lower bound for each triple directly by three applications of the scalar log inequality.

3. Show that `triangleCycleGap` is a lower bound surrogate for broader tropical cycle behavior, or present it as the first-order comparison invariant.

Why this is promising:
- finite minima over `Fin (n+1)` are much easier than quotienting over all cycles;
- this gives a computationally explicit invariant;
- it is enough to demonstrate the probabilistic–tropical bridge in a formally robust way.

### Strategy C: Multi-step kernel bridge via matrix powers
This is the most visionary route and should be attempted after Strategy A succeeds.

1. Define
   \[
   W^{(m)}_{ij} := -\log((P^m)_{ij})
   \]
   for `m ≥ 1`.

2. Use known spectral/mixing bounds on `P^m` in the symmetric case to produce a uniform entrywise upper bound:
   \[
   (P^m)_{ij} \le \alpha_m.
   \]

3. Apply Strategy A to `P^m` instead of `P`, obtaining
   \[
   g(W^{(m)}) \ge -\log(\alpha_m).
   \]

Why this is most revolutionary:
- it converts asymptotic mixing information into tropical energy separation at scale `m`;
- it suggests a tropicalized theory of heat kernels and diffusion;
- it is the natural doorway to entropy and large deviation interpretations.

## Cross-domain connections to emphasize

Do not leave the result trapped inside matrix inequalities. Explicitly position it across domains.

### 1. Markov chains and mixing theory
The quantity `-log P_ij` is a one-step information cost. Cycle means become average information cost per return loop. Your theorem says: bounded transition concentration implies positive tropical cycle cost.

### 2. Tropical geometry / idempotent analysis
Cycle mean is the tropical analogue of an eigenvalue or Lyapunov exponent in min-plus algebra. Showing it is bounded below by a probabilistic parameter is a new structural comparison.

### 3. Information theory
Because `-log p` is surprisal, a cycle weight is cumulative surprisal along a loop. The tropical cycle gap is thus a loopwise information barrier. This invites future work on tropical entropy rates and data-processing analogues.

### 4. Statistical physics
The weight matrix `W = -log P` is an energy landscape. Cycle means correspond to average loop energies. Spectral gap then resembles relaxation rate, and your theorem becomes a relaxation-energy inequality.

### 5. Algorithms and verification
A triangle-based tropical gap is efficiently computable and can serve as a certified lower bound for stochastic systems, graph diffusion processes, or robust routing.

These are not rhetorical flourishes. They tell you what secondary definitions and lemmas to choose.
