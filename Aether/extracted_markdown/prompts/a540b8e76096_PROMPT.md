## Core theorem targets

### Theorem A: Berggren descendants remain on the rational unit circle

Define a map from a Pythagorean triple `(a,b,c)` with `c ≠ 0` to a rational point on the unit circle:
\[
\Phi(a,b,c) := \left(\frac{a}{c}, \frac{b}{c}\right).
\]
Then every Berggren-generated primitive triple maps exactly to a rational point on the unit circle.

### Precise statement
For every Berggren descendant triple `(a,b,c)` satisfying `a^2 + b^2 = c^2` and `c ≠ 0`,
\[
(a/c)^2 + (b/c)^2 = 1.
\]

### Lean 4 type signature candidate
```lean
theorem berggren_point_on_unit_circle
    (a b c : ℤ)
    (hpy : a ^ 2 + b ^ 2 = c ^ 2)
    (hc : c ≠ 0) :
    ((a : ℚ) / c) ^ 2 + ((b : ℚ) / c) ^ 2 = 1 := by
```

This should be proved first, and then specialized to the root triple and recursively generated descendants.

Build on:

- `berggren_root_pythagorean`
- `unit_circle_from_pythagorean`

The important move is to show that the catalog’s circle theorem is not isolated; it is the geometric shadow of the Berggren recursion.

### Theorem B: Exact tropical distance on Berggren circle points is rational and denominator-controlled

For rational points arising from integer triples, tropical distances should reduce to exact rational expressions with common denominator dividing a product of hypotenuses.

A natural tropical metric on `ℚ × ℚ` is
\[
d_{\mathrm{trop}}((x_1,y_1),(x_2,y_2))
:= \max(|x_1-x_2|, |y_1-y_2|).
\]

For Berggren points
\[
p_1=\left(\frac{a_1}{c_1},\frac{b_1}{c_1}\right),\quad
p_2=\left(\frac{a_2}{c_2},\frac{b_2}{c_2}\right),
\]
prove that `d_trop(p₁,p₂)` is rational and can be computed exactly by integer arithmetic over denominator `c₁*c₂`.

### Precise statement
\[
d_{\mathrm{trop}}(p_1,p_2)
=
\frac{
\max\big(|a_1c_2-a_2c_1|,\ |b_1c_2-b_2c_1|\big)
}{
|c_1c_2|
}.
\]

### Lean 4 type signature candidate
You may first define:
```lean
def tropDistQ (p q : ℚ × ℚ) : ℚ :=
  max (|p.1 - q.1|) (|p.2 - q.2|)
```

Then prove:
```lean
theorem tropDistQ_berggren_exact
    (a₁ b₁ c₁ a₂ b₂ c₂ : ℤ)
    (hc₁ : c₁ ≠ 0)
    (hc₂ : c₂ ≠ 0) :
    tropDistQ
      (((a₁ : ℚ) / c₁), ((b₁ : ℚ) / c₁))
      (((a₂ : ℚ) / c₂), ((b₂ : ℚ) / c₂))
    =
    (max (Int.natAbs (a₁ * c₂ - a₂ * c₁))
         (Int.natAbs (b₁ * c₂ - b₂ * c₁)) : ℚ) / Int.natAbs (c₁ * c₂) := by
```

If the exact `Int.natAbs` formulation becomes cumbersome, prove a cleaner absolute-value version first:
```lean
theorem tropDistQ_berggren_exact'
    (a₁ b₁ c₁ a₂ b₂ c₂ : ℤ)
    (hc₁ : c₁ ≠ 0)
    (hc₂ : c₂ ≠ 0) :
    tropDistQ
      (((a₁ : ℚ) / c₁), ((b₁ : ℚ) / c₁))
      (((a₂ : ℚ) / c₂), ((b₂ : ℚ) / c₂))
    =
    max
      (|((a₁ * c₂ - a₂ * c₁ : ℤ) : ℚ) / (c₁ * c₂)|)
      (|((b₁ * c₂ - b₂ * c₁ : ℤ) : ℚ) / (c₁ * c₂)|) := by
```

This theorem is the exact arithmetic heart of the project. It upgrades `tropical_exact_integer` into a geometric statement about rational shell meshes.

### Theorem C: Depth-bounded Berggren mesh is an exact shell mesh with certified radius

Define the depth-`d` Berggren mesh as the finite set of rational circle points obtained from Berggren descendants up to depth `d`. Then prove every point lies exactly on the unit shell and every pairwise tropical distance is exact rational arithmetic.

This can first be done for the unit circle; the “sphere” language can be introduced by a rational embedding such as
\[
(x,y)\mapsto (x,y,0),
\]
or, more ambitiously, via stereographic lift to `S²`.

### Lean 4 type signature candidate
A first formal version:
```lean
def BerggrenPoint := ℤ × ℤ × ℤ

def toRatPoint (t : BerggrenPoint) : ℚ × ℚ :=
  (((t.1 : ℚ) / t.2.2), ((t.2.1 : ℚ) / t.2.2))

def onUnitCircle (p : ℚ × ℚ) : Prop :=
  p.1 ^ 2 + p.2 ^ 2 = 1

theorem berggren_mesh_on_shell
    (t : BerggrenPoint)
    (hpy : t.1 ^ 2 + t.2.1 ^ 2 = t.2.2 ^ 2)
    (hc : t.2.2 ≠ 0) :
    onUnitCircle (toRatPoint t) := by
```

A stronger finite-mesh theorem:
```lean
theorem berggren_mesh_pairwise_tropical_exact
    (s : Finset BerggrenPoint)
    (hshell : ∀ t ∈ s, t.1 ^ 2 + t.2.1 ^ 2 = t.2.2 ^ 2)
    (hnz : ∀ t ∈ s, t.2.2 ≠ 0) :
    ∀ p ∈ s, ∀ q ∈ s,
      ∃ r : ℚ, tropDistQ (toRatPoint p) (toRatPoint q) = r := by
```

This statement is modest enough to prove now and powerful enough to seed later equidistribution or discrepancy work.

## Proof strategy architecture

### Strategy 1: Algebraic normalization through rational division
Most promising for Theorem A and C.

1. Start from `a^2 + b^2 = c^2`.
2. Cast to `ℚ` and divide both sides by `c^2`.
3. rewrite:
   \[
   \frac{a^2}{c^2} + \frac{b^2}{c^2} = 1
   \]
   as
   \[
   (a/c)^2 + (b/c)^2 = 1.
   \]
4. Package into `onUnitCircle`.

Why this is promising:
- It is elementary and robust in Lean.
- It leverages existing circle infrastructure.
- It avoids dependence on the full Berggren recursion initially.

Key Lean tools:
- `norm_num`
- `field_simp`
- `ring`
- coercion lemmas from `ℤ` to `ℚ`

---

### Strategy 2: Exact tropical denominator clearing
Most promising for Theorem B.

1. Expand
   \[
   \frac{a_1}{c_1} - \frac{a_2}{c_2}
   = \frac{a_1c_2-a_2c_1}{c_1c_2}.
   \]
2. Do the same for the second coordinate.
3. Push absolute value and `max` through the resulting rational expressions.
4. If needed, split on signs of denominators or assume `0 < c₁`, `0 < c₂` for primitive triples.
5. Conclude exactness entirely in `ℚ`.

Why this is promising:
- It converts tropical distance into pure integer arithmetic.
- It directly upgrades `tropical_exact_integer` to a rational shell setting.
- It gives a reusable denominator-control lemma for future certified computations.

A useful intermediate lemma:
```lean
lemma rat_sub_eq_int_cross
    (a₁ a₂ c₁ c₂ : ℤ)
    (hc₁ : c₁ ≠ 0)
    (hc₂ : c₂ ≠ 0) :
    ((a₁ : ℚ) / c₁) - ((a₂ : ℚ) / c₂)
      = ((a₁ * c₂ - a₂ * c₁ : ℤ) : ℚ) / (c₁ * c₂) := by
```

### Strategy 3: Finite mesh theorem via `Finset` closure and pointwise certification
Best for turning local arithmetic lemmas into a global mesh statement.

1. Define a finite collection `s : Finset BerggrenTriple`.
2. Assume each element satisfies `isPythagorean` and nonzero hypotenuse.
3. Prove pointwise shell membership using Theorem A.
4. Prove pairwise tropical exactness using Theorem B.
5. Package this as an exact arithmetic shell mesh theorem.

Why this matters:
- It shifts the project from isolated identities to a usable geometric data structure.
- It prepares the ground for future discrepancy, covering radius, or equidistribution theorems.

## Cross-domain connections you should explicitly exploit

### 1. Tropical geometry
The tropical metric is piecewise-linear and exact on rationals; Berggren meshes provide arithmetic testbeds for tropical Voronoi decompositions, tropical nearest-neighbor search, and exact max-plus geodesic approximations.

### 2. Arithmetic dynamics
The Berggren tree is a discrete dynamical system on primitive triples. Viewing the shell mesh as an orbit-generated rational point cloud suggests a new arithmetic dynamics perspective on geometric discretization.

### 3. Certified numerical geometry
Most mesh generation relies on floating-point approximations. Here the mesh is exact by construction. This is ideal for formal verification, robust optimization, and theorem-certified computational geometry.

### 4. Spherical coding / discrepancy theory
Even before proving asymptotic equidistribution, a finite exact shell mesh from arithmetic recursion is a new object in deterministic sampling. Later one could study angular separation, discrepancy, and covering radius.

### 5. Tropical scientific computing
Exact rational shell meshes could serve as benchmark instances for tropical PDE discretizations, idempotent optimization, and combinatorial wavefront propagation where rounding error is fatal.
