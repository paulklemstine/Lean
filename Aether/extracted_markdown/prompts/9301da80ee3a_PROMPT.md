### Central theorem target (axiomatic version)

> For every finite family `z : Fin n → ℂ`, if `z` is linearly independent over `ℚ`, then the transcendence degree over `ℚ` of the field generated by the coordinates `z i` and `Complex.exp (z i)` is at least `n`.

### Theorem 1: Schanuel implies a finite-tuple Lindemann–Weierstrass principle

This is the most important consequence theorem.

#### Mathematical statement
If `α₁, ..., αₙ` are algebraic over `ℚ` and linearly independent over `ℚ`, then assuming Schanuel’s lower bound, the exponentials `e^{α₁}, ..., e^{αₙ}` are algebraically independent enough to imply in particular that each `e^{αᵢ}` is transcendental, and at minimum that no nontrivial algebraic relation of too low dimension can exist.

A realistic formal consequence is:

> Under the Schanuel axiom, if `z : Fin n → ℂ` is `ℚ`-linearly independent and each `z i` is algebraic over `ℚ`, then the family `fun i => Complex.exp (z i)` is algebraically independent over `ℚ` (or at least satisfies a certified transcendence lower bound).

#### Lean target shape
```lean
theorem schanuel_implies_lindemann_weierstrass
    (hS : HasSchanuelLowerBound ℂ)
    (n : ℕ)
    (z : Fin n → ℂ)
    (hlin : LinearIndependent ℚ z)
    (halg : ∀ i, IsAlgebraic ℚ (z i)) :
    AlgebraicallyIndependent ℚ (fun i => Complex.exp (z i)) := by
  ...
```

If `AlgebraicallyIndependent` over `Fin n → ℂ` is awkward, prove a weaker but still meaningful theorem:

```lean
theorem schanuel_implies_exp_not_algebraic_collapse ...
```

showing that any algebraic dependence among exponentials contradicts the Schanuel lower bound plus algebraicity of the base tuple.

#### Why this is a breakthrough
This turns Schanuel from a slogan into a **formal theorem generator**. The entire ecosystem of transcendence corollaries can then be developed axiomatically in Lean.

### Theorem 2: Rational dependence from algebraicity of logarithms of algebraic numbers

This is the contrapositive geometry of Schanuel and is conceptually powerful.

#### Mathematical statement
Assume Schanuel. If `z₁, ..., zₙ` and `e^{z₁}, ..., e^{zₙ}` are all algebraic, then the tuple must be `ℚ`-linearly dependent.

This is a clean formal theorem and a direct corollary of the conjectural lower bound.

#### Lean target shape
```lean
theorem algebraic_logs_force_q_dependence
    (hS : HasSchanuelLowerBound ℂ)
    (n : ℕ)
    (z : Fin n → ℂ)
    (hz_alg : ∀ i, IsAlgebraic ℚ (z i))
    (hexp_alg : ∀ i, IsAlgebraic ℚ (Complex.exp (z i))) :
    ¬ LinearIndependent ℚ z := by
  ...
```

This theorem should require `by_contra`, extraction of dimension inequalities, and a contradiction with the Schanuel lower bound.

#### Why this matters
This is a rigorous formal obstruction principle for logarithms of algebraic numbers. It links transcendence theory to **symbolic algebra systems** that search for rational relations among logarithms.

### Theorem 3: Minimal-counterexample rigidity for Schanuel-critical tuples

Introduce `IsSchanuelCritical` and prove a rigidity theorem.

#### Mathematical statement
A minimal tuple violating the Schanuel lower bound cannot contain a nontrivial `ℚ`-linearly dependent proper subtuple with the same exponential algebraic defect; equivalently, every proper restriction has strictly better predimension behavior.

#### Lean target shape
```lean
theorem schanuelCritical_restriction_strict
    {n : ℕ} {z : Fin n → ℂ}
    (hcrit : IsSchanuelCritical z) :
    ∀ (m : ℕ) (e : Fin m ↪ Fin n), m < n →
      schanuelPredim (fun i => z (e i)) > schanuelPredim z := by
  ...
```

If strict inequality is too strong for the implemented surrogate, prove a weaker but still deep monotonicity/rigidity theorem.

#### Why this matters
This is not a standard textbook corollary. It opens a **formal minimal-counterexample calculus** for transcendence conjectures, analogous to minimal criminal methods in additive combinatorics and extremal graph theory.

## Proof Strategy Architecture

You must not provide a one-line proof plan. Build the file around 2–3 serious proof pathways.

### Strategy A: Axiomatic transcendence-degree calculus
Most promising.

1. Define a robust abstraction for “lower bound on transcendence complexity” that does not depend on every transcendence-degree API already existing in Mathlib.
2. Prove generic lemmas converting algebraicity assumptions on `z i` into zero contribution from the base tuple, so all lower bound mass must come from the exponentials.
3. Use `by_contra` with a hypothetical algebraic dependence among exponentials, then combine:
   - algebraicity of `z i`,
   - algebraicity of exponentials generated by the dependence,
   - Schanuel lower bound,
   - finite-dimension inequality,
   to derive a contradiction.

Why promising: it isolates the hard open content into a single axiom and allows many rigorous consequences.

### Strategy B: Explicit polynomial-witness route
Good for computational verification.

1. Define `ExpAlgDependenceWitness`.
2. Show that any failure of algebraic independence yields such a witness.
3. Prove that under Schanuel + algebraicity of the base tuple, no witness can exist.
4. Use this to derive certified nonexistence of low-degree relations among exponentials.

Why promising: this produces a verified algorithmic object and a bridge to `demo.py`.

### Strategy C: Minimal-counterexample / predimension descent
Most visionary.

1. Define `IsSchanuelCritical` for a tuple minimizing predimension among bad tuples.
2. Prove proper subtuples are noncritical or have larger predimension.
3. Derive structural rigidity: no repeated coordinates, no rational dependence collapsing dimensions, no algebraic redundancy.
4. Package this as a formal “counterexample anatomy” theorem.

Why promising: even partial success creates a new formal research program around hypothetical Schanuel counterexamples.
