### 3. Ultrametric cover/packing layer

Define closed balls centered in a finite set, and an ultrametric cover number specialized to finite supports.

Suggested signatures:
```lean
def ultraBall {α : Type*} [PseudoMetricSpace α] (c : α) (r : ℝ) : Set α :=
  {x | dist x c ≤ r}

def IsUltraSeparated {α : Type*} [PseudoMetricSpace α] (r : ℝ) (s : Finset α) : Prop :=
  ∀ ⦃x⦄, x ∈ s → ∀ ⦃y⦄, y ∈ s → x ≠ y → r < dist x y

def IsUltraCover {α : Type*} [PseudoMetricSpace α] (r : ℝ) (centers target : Finset α) : Prop :=
  ∀ x, x ∈ target → ∃ c, c ∈ centers ∧ dist x c ≤ r

def ultraCoverNumber {α : Type*} [PseudoMetricSpace α] (r : ℝ) (target : Finset α) : ℕ :=
  sInf {n | ∃ centers : Finset α, centers.card = n ∧ IsUltraCover r centers target}

def ultraPackingNumber {α : Type*} [PseudoMetricSpace α] (r : ℝ) (target : Finset α) : ℕ :=
  sSup {n | ∃ packed : Finset α, packed.card = n ∧ packed ⊆ target ∧ IsUltraSeparated r packed}
```

If `sInf/sSup` over naturals is annoying, use existential/minimization over finite subsets or define via `Nat.find` under nonempty hypotheses. It is acceptable to restrict to nonempty finite targets and nonnegative radii.

The key combinatorial phenomenon to capture:
- in ultrametric spaces, same-radius balls are either nested or disjoint,
- therefore maximal separated subsets induce canonical covers,
- cover and packing numbers coincide at matched scales.

### 4. Compression/divergence layer

Define an ultrametric coding/divergence quantity measuring how deeply the posterior support refines the prior support in the valuation tree. Keep it elementary and finite.

Possible definitions:
```lean
def valuationDepthCost {α : Type*} [PseudoMetricSpace α] (r : ℝ) (μ : FiniteHypDist α) : ℝ :=
  ∑ h in μ.supportFinset, μ.weight h * Real.log (1 + dist h h / (r + 1)) -- placeholder shape
```

Better: define from cover cardinality/support cardinality rather than difficult logs of distances:
```lean
def ValuationCompression {α : Type*} [PseudoMetricSpace α]
    (r : ℝ) (π ρ : FiniteHypDist α) : ℝ :=
  Real.log ((ρ.supportFinset.card : ℝ) / max 1 (ultraCoverNumber r π.supportFinset))
```

Or define a cleaner finite-support KL-like quantity:
```lean
def UltraKL {H : Type*} (ρ π : FiniteHypDist H) : ℝ :=
  ∑ h in ρ.supportFinset, ρ.weight h * Real.log (ρ.weight h / π.weight h)
```
with a convention or positivity hypothesis:
```lean
def HasSupportDomination (ρ π : FiniteHypDist H) : Prop :=
  ∀ h, ρ.weight h ≠ 0 → π.weight h ≠ 0
```

If full KL is cumbersome, define a code-length upper bound:
```lean
def posteriorCodeLength (ρ : FiniteHypDist H) : ℝ := Real.log (ρ.supportFinset.card)

def ValuationCompression (r : ℝ) (ρ : FiniteHypDist H) [PseudoMetricSpace H] : ℝ :=
  Real.log (ultraCoverNumber r ρ.supportFinset)
```

This is mathematically weaker than KL, but far easier to formalize and still supports a PAC-Bayes-style complexity term.

## PROOF STRATEGY REQUIREMENTS

For each main theorem, architect the proof around a clear intermediate lemma chain. Use varied tactics: `induction`, `rcases`, `by_contra`, `linarith`, `omega`, `field_simp`, `nlinarith`, `simpa`, `aesop?` only if controlled.

### For `ultrametric_cover_packing_eq`

Most promising route:
1. Define maximal `r`-separated subsets of a finite target `s` using `Finset` cardinal maximality.
2. Prove by contradiction (`by_contra`) that a maximal separated subset must cover `s`; otherwise one can adjoin an uncovered point and increase cardinality.
3. Use nested/disjoint ball behavior from the ultrametric inequality to show any cover by radius-`r` balls can hit at most one point of an `r`-separated packing.
4. Deduce both inequalities and conclude equality.

Helpful intermediate lemmas:
```lean
theorem separated_point_outside_ball ...
theorem uncovered_can_be_adjoined_to_packing ...
theorem cover_hits_packing_injection ...
```

### For `valuation_compression_code_bound`

Most promising route:
1. First prove `ultraCoverNumber r ρ.supportFinset ≤ ρ.supportFinset.card`.
2. Apply `Real.log_le_log` after establishing positivity.
3. Handle empty/singleton support separately by `rcases h : ρ.supportFinset.card` or by proving positivity lemmas.
4. Package monotonicity in `r` using ball monotonicity.

This is a good place to use `omega` for cardinal arithmetic and `linarith` for positivity side conditions.

### For `ultrametric_pac_bayes_bound_lipschitz_certified_robustness`

Most promising route:
1. Select one center in each radius-`r` cluster of posterior support.
2. Compare loss at each hypothesis to loss at its cluster center using `UltraLipschitzLoss`.
3. Sum over posterior weights to get a `K * r` perturbation term.
4. Bound the residual model complexity by `Real.log (ultraCoverNumber r support + 1) / n`.
5. Use boundedness to keep all expectations nonnegative and controlled.

If exact empirical-vs-true risk comparison is too strong, prove a deterministic compression bound first:
```lean
posteriorTrueRisk ≤ compressedPosteriorTrueRisk + K*r
posteriorRisk compressed ≤ posteriorRisk original + K*r
```
then combine with the coding term.

### For `tropical_to_ultrametric_generalization_transfer`

Most promising route:
1. Define `transportPosterior` by summing weights along fibers.
2. Prove support/image containment and expectation transport inequalities.
3. Use the valuation radius supplied by the bridge to instantiate the ultrametric compression theorem.
4. Conclude a bound where tropical margin or valuation radius appears as the compression scale.
5. If possible, prove a corollary with a theorem name containing both `tropical` and `certified`.
