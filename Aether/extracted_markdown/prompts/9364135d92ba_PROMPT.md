## Assignment: Direction 2: Nonlinear Extraction Obstructions

**Mode:** `prove`

Prove genuinely new theorems that identify the exact boundary where affine Σ-extraction fails and polynomial extraction begins. Build explicitly on:

- `Catalog/Cryptography/AffineSigmaExtraction.lean`
- especially the theorem `no_unique_extract_of_noninj`

The mission is not to produce a small variant of the affine story. The mission is to formalize the first algebraic-geometric obstruction theory for transcript extraction in nonlinear Σ-protocols, and to show that extraction complexity is controlled by the degree and collision geometry of the witness map.

---

## Core Vision

The affine extractor paradigm succeeds because two accepting transcripts determine a unique witness whenever the witness enters linearly and the coefficient difference is invertible. That is a rigid, low-degree miracle. The moment the witness enters through a nonlinear map
\[
g : W \to V,
\]
the extractor is no longer solving a linear system in the witness; it is solving a fiber-membership problem for the morphism \(g\). This changes the nature of extraction completely.

You should make this precise for degree-2 witness dependence over finite fields, beginning with the toy but decisive model
\[
z = t + c \cdot w^2
\quad\text{over } \mathbb{F}_q.
\]

The breakthrough is to prove that transcript extraction is governed not by transcript count alone, but by the algebraic identifiability of the witness map. In other words:

- **two-transcript extraction recovers only the image value \(g(w)\), not the witness \(w\);**
- **unique witness extraction is possible exactly on injective regions/fibers of \(g\);**
- **for quadratic maps over odd fields, global extraction from transcripts alone is impossible in general because the squaring map has fibers of size 2 on nonzero squares;**
- **multi-transcript systems recover polynomial invariants, but not necessarily the witness, unless one augments the protocol or restricts the domain.**

This is the nonlinear boundary of Σ-extraction.

### New Definitions to Introduce

Define a nonlinear Σ transcript model over a field `F`:

```lean
structure NonlinearSigmaInstance (F W T C Z : Type*) [Field F] where
  witnessMap : W → F
  commitTerm : T → F
  challengeTerm : C → F
  responseTerm : Z → F
  accept : T → C → Z → W → Prop :=
    fun t c z w => responseTerm z = commitTerm t + challengeTerm c * witnessMap w
```

For the concrete quadratic case, define:

```lean
def quadWitnessMap {F : Type*} [Field F] (w : F) : F := w^2
```

Define transcript compatibility and extractability notions:

```lean
def TranscriptCompatible {F W T C Z : Type*} [Field F]
    (S : NonlinearSigmaInstance F W T C Z) (t : T) (pairs : List (C × Z)) (w : W) : Prop :=
  ∀ p ∈ pairs, S.accept t p.1 p.2 w

def UniquelyExtractable {F W T C Z : Type*} [Field F]
    (S : NonlinearSigmaInstance F W T C Z) (t : T) (pairs : List (C × Z)) : Prop :=
  ∃! w, TranscriptCompatible S t pairs w
```

Also define a “fiber-collision obstruction”:

```lean
def HasCollision {W F : Type*} (g : W → F) : Prop :=
  ∃ w₁ w₂, w₁ ≠ w₂ ∧ g w₁ = g w₂
```

And, if useful, a restricted-domain notion:

```lean
def InjectiveOn (s : Set W) (g : W → F) : Prop :=
  ∀ ⦃x y⦄, x ∈ s → y ∈ s → g x = g y → x = y
```

This is mathematically essential: the object controlling extraction is the fiber structure of `witnessMap`.

## Theorem 1: Two transcripts determine the nonlinear image, not the witness

### Mathematical statement

Let \(F\) be a field, let
\[
z_i = t + c_i g(w)
\]
for \(i=1,2\), with \(c_1 \neq c_2\). Then two accepting transcripts uniquely determine \(g(w)\), but not necessarily \(w\). Explicitly,
\[
g(w) = \frac{z_1 - z_2}{c_1 - c_2}.
\]
Hence if \(g\) is noninjective, witness extraction from two transcripts is impossible in general.

### Lean-style target

```lean
theorem nonlinear_image_determined_of_two_transcripts
    {F : Type*} [Field F]
    {g : F → F} {t c₁ c₂ z₁ z₂ w : F}
    (hacc₁ : z₁ = t + c₁ * g w)
    (hacc₂ : z₂ = t + c₂ * g w)
    (hneq : c₁ ≠ c₂) :
    g w = (z₁ - z₂) / (c₁ - c₂) := by
```

Then prove the obstruction theorem extending the catalog’s affine result:

```lean
theorem no_unique_extract_of_nonlinear_collision
    {F : Type*} [Field F]
    {g : F → F}
    (hcoll : ∃ w₁ w₂, w₁ ≠ w₂ ∧ g w₁ = g w₂) :
    ∃ t c₁ c₂ z₁ z₂,
      c₁ ≠ c₂ ∧
      ∃ w₁ w₂, w₁ ≠ w₂ ∧
        z₁ = t + c₁ * g w₁ ∧
        z₂ = t + c₂ * g w₁ ∧
        z₁ = t + c₁ * g w₂ ∧
        z₂ = t + c₂ * g w₂ := by
```

### Why this is a breakthrough

This theorem says that the true extracted object from transcript differences is the **algebraic image** \(g(w)\), not the witness. That is the conceptual leap. It reframes Σ-extraction as an inverse problem on algebraic maps. This opens a new field: **algebraic identifiability theory for cryptographic transcripts**.

### Proof strategy options

#### Strategy A: Direct subtraction and division
1. Subtract the two acceptance equations.
2. Rearrange:
   \[
   z_1 - z_2 = (c_1-c_2) g(w).
   \]
3. Use `field_simp` or multiplicative inversion since `hneq : c₁ ≠ c₂`.

This is the cleanest proof and should be the backbone theorem.

#### Strategy B: Reuse affine extraction at the image level
1. Define `u := g w`.
2. Observe the transcript equations are affine in `u`.
3. Apply the affine extraction logic from `AffineSigmaExtraction.lean` to recover `u`.
4. Then show failure of witness extraction whenever `g` has a collision.

This is conceptually stronger because it explicitly factors nonlinear extraction through the affine catalog theorem.

#### Strategy C: Contrapositive obstruction
1. Assume unique witness extraction from every two-transcript instance.
2. Use colliding witnesses \(w_1 \neq w_2\) with \(g(w_1)=g(w_2)\).
3. Build identical transcript pairs for both witnesses.
4. Contradict uniqueness.

This is the right proof style for the impossibility theorem.

**Most promising:** combine A for the constructive formula and C for the impossibility theorem.

## Theorem 2: Quadratic extraction obstruction over odd finite fields

### Mathematical statement

Over a finite field \( \mathbb{F}_q \) of odd characteristic, the squaring map is noninjective:
\[
w^2 = (-w)^2.
\]
Hence global witness extraction from transcript pairs in the quadratic protocol
\[
z = t + c w^2
\]
is impossible whenever there exists \(w \neq 0\).

This is the first exact nonlinear obstruction theorem in the concrete degree-2 model.

### Lean-style target

A general field theorem first:

```lean
theorem sq_noninjective_of_neg_ne_self
    {F : Type*} [Field F]
    (∃ w : F, w ≠ 0) :
    ∃ w₁ w₂ : F, w₁ ≠ w₂ ∧ w₁^2 = w₂^2 := by
```

A stronger finite-field/ZMod version for odd modulus:

```lean
theorem quad_two_transcript_nonunique_ZMod
    {p : ℕ} [Fact p.Prime] (hpodd : p ≠ 2) :
    ∃ t c₁ c₂ z₁ z₂ : ZMod p,
      c₁ ≠ c₂ ∧
      ∃ w₁ w₂ : ZMod p, w₁ ≠ w₂ ∧
        z₁ = t + c₁ * w₁^2 ∧
        z₂ = t + c₂ * w₁^2 ∧
        z₁ = t + c₁ * w₂^2 ∧
        z₂ = t + c₂ * w₂^2 := by
```

If the exact field lemmas for `ZMod p` are awkward, prove a more abstract theorem over any field of characteristic not 2 plus a nonzero element.

### Why this matters

This is not just a toy counterexample. It identifies the first robust nonlinear barrier: **degree-2 witness dependence destroys black-box special soundness unless one tracks branch data beyond the polynomial image**. This is the cryptographic analogue of the fact that algebraic maps are not invertible on fibers.

### Proof strategy options

#### Strategy A: Explicit collision using \(w\) and \(-w\)
1. Pick nonzero `w`.
2. Set `w₁ = w`, `w₂ = -w`.
3. Prove `w₁ ≠ w₂` using `char ≠ 2`.
4. Prove `w₁^2 = w₂^2` by ring manipulation.

This is the most direct and elegant route.

#### Strategy B: Use noninjectivity of polynomial maps
1. Prove `HasCollision (fun w => w^2)` abstractly from odd characteristic.
2. Invoke Theorem 1 obstruction theorem.
3. Specialize to `ZMod p`.

This is modular and best if you want a reusable library for polynomial witness maps.

#### Strategy C: Finite-field counting
1. Show the squaring map on `ZMod p` has image size at most `(p+1)/2`.
2. Since domain size is `p`, it cannot be injective.
3. Extract a collision and instantiate Theorem 1.

This is more sophisticated and links extraction to finite-field combinatorics, but likely heavier in Lean.

**Most promising:** A for the concrete theorem, B for architecture.

## Theorem 3: Multi-transcript systems still do not recover the witness unless the witness map is injective on the candidate set

### Mathematical statement

Suppose a transcript family satisfies
\[
z_i = t + c_i g(w)
\quad (i=1,\dots,m)
\]
with at least two distinct challenges. Then the entire family determines \(g(w)\), but if \(g(w_1)=g(w_2)\), every accepting family for \(w_1\) is also accepting for \(w_2\). Therefore **no number of transcripts can globally recover the witness from this protocol model alone**.

This sharply corrects the naive conjecture that “3 transcripts suffice for quadratics.” They do not, for the equation \(z=t+c\,w^2\) as stated. All transcripts collapse through the single scalar \(w^2\). More transcripts provide redundancy, not branch selection.

### Lean-style target

```lean
theorem transcript_family_depends_only_on_image
    {F : Type*} [Field F]
    {g : F → F} {t : F} {cs zs : List F} {w₁ w₂ : F}
    (himg : g w₁ = g w₂)
    (hcompat : ∀ (c z), (c, z) ∈ List.zip cs zs → z = t + c * g w₁) :
    ∀ (c z), (c, z) ∈ List.zip cs zs → z = t + c * g w₂ := by
```

And the conceptual impossibility theorem:

```lean
theorem no_finite_transcript_unique_extraction_of_collision
    {F : Type*} [Field F] {g : F → F}
    (hcoll : ∃ w₁ w₂, w₁ ≠ w₂ ∧ g w₁ = g w₂) :
    ∀ m : ℕ, ∃ t : F, ∃ cs zs : List F,
      cs.length = m ∧ zs.length = m ∧
      ∃ w₁ w₂, w₁ ≠ w₂ ∧
        TranscriptCompatible
          { witnessMap := g
            commitTerm := fun x => x
            challengeTerm := fun x => x
            responseTerm := fun x => x } t (List.zip cs zs) w₁ ∧
        TranscriptCompatible
          { witnessMap := g
            commitTerm := fun x => x
            challengeTerm := fun x => x
            responseTerm := fun x => x } t (List.zip cs zs) w₂ := by
```

You may simplify the instance encoding if needed; the theorem content is the key.

### Why this is a breakthrough

This result is the real conceptual payload. It says the issue is not “need more transcripts”; the issue is “you are observing the wrong algebraic invariant.” This destroys a common intuition and replaces it with a structural principle: **transcript multiplicity cannot overcome witness-map collisions when acceptance factors through a single hidden image**.

That is a field-opening statement. It suggests a taxonomy of Σ-protocols by identifiability class:
- affine-identifiable,
- image-identifiable,
- fiber-ambiguous,
- branch-recoverable only with auxiliary constraints.

### Proof strategy options

#### Strategy A: Pointwise substitution
1. Assume `g w₁ = g w₂`.
2. Rewrite each transcript equation for `w₁`.
3. Conclude the same equation holds for `w₂`.

This is simple and should be formalized cleanly.

#### Strategy B: Factor through the quotient by fibers
1. Define an equivalence relation \(w_1 \sim w_2\iff g(w_1)=g(w_2)\).
2. Show transcript semantics descend to the quotient.
3. Unique extraction on witnesses would imply a section of the quotient map.
4. Contradict existence of a nontrivial fiber.

This is more abstract and visionary; if feasible, it gives the right language for future work.

#### Strategy C: Matrix viewpoint
1. View transcript vector as
   \[
   \mathbf z = t\mathbf 1 + g(w)\mathbf c.
   \]
2. Show the entire transcript family lies in a 1-dimensional affine line parameterized by `g(w)`.
3. Therefore all witness ambiguity remains exactly the ambiguity of the fiber \(g^{-1}(g(w))\).

This is a nice cross-domain bridge to linear algebra and signal identifiability.

**Most promising:** A for the theorem, C for exposition in the paper.

## Theorem 4: Positive result on restricted-domain extraction

Do not stop at impossibility. Prove the exact recovery condition.

### Mathematical statement

If \(g\) is injective on a domain \(S\), then two transcripts with distinct challenges uniquely extract the witness among witnesses in \(S\).

For the quadratic map over a field, extraction becomes unique on a domain choosing one representative from each \(\{\pm w\}\)-pair, e.g. an abstract “sign slice” or any subset on which squaring is injective.

### Lean-style target

```lean
theorem unique_extraction_on_injective_domain
    {F : Type*} [Field F]
    {g : F → F} {S : Set F}
    (hinj : InjectiveOn S g)
    {t c₁ c₂ z₁ z₂ w : F}
    (hw : w ∈ S)
    (hacc₁ : z₁ = t + c₁ * g w)
    (hacc₂ : z₂ = t + c₂ * g w)
    (hneq : c₁ ≠ c₂) :
    ∀ w' ∈ S,
      z₁ = t + c₁ * g w' →
      z₂ = t + c₂ * g w' →
      w' = w := by
```

### Why this matters

This theorem identifies the exact repair mechanism: **not more transcripts, but injective witness parametrization**. In cryptographic design terms, one must either:
- constrain the witness space,
- add auxiliary transcript data breaking fiber symmetry,
- or redesign the protocol to expose enough algebraic invariants.

This is a principled design doctrine for nonlinear proof systems.

### Proof strategy

1. Use Theorem 1 to show `g w' = g w`.
2. Apply `InjectiveOn S g`.
3. Conclude `w' = w`.

This theorem should use `by_contra`, `rcases`, and multi-step `calc` at some point to satisfy depth requirements.

You should explicitly test and, if necessary, **refute** the statement:

\[

depends only on \(w^2\). Replacing \(w\) by \(-w\) preserves every equation. Thus no finite transcript family can distinguish the two witnesses over odd characteristic unless additional structure is present.

This is scientifically valuable. A decisive counterexample is better than a vague extension. If you can, frame the corrected conjecture:

This is the right conjectural north star.

## Cross-Domain Connections

You must explicitly build at least one theorem/exposition bridge to another domain.

### 1. Cryptography × Algebraic Geometry
The witness map \(g\) defines fibers \(g^{-1}(u)\). Transcript extraction asks whether transcript equations cut out a single point or an entire fiber. This is a question about the geometry of algebraic varieties and finite morphisms.

Key language for the paper:
- fiber cardinality
- identifiability
- branched cover
- quotient by involution \(w \mapsto -w\)
- image variety versus witness variety

### 2. Cryptography × Computational Algebra
For more general degree-\(d\) witness maps, transcript equations generate polynomial ideals. Gröbner bases or elimination can determine whether the witness is uniquely identified, finitely ambiguous, or underdetermined.

Even if full Gröbner formalization is too large, define the algebraic problem precisely and prove low-degree lemmas that motivate it.

### 3. Cryptography × Inverse Problems / Signal Processing
This is mathematically parallel to phase retrieval: measurements often determine a signal only up to a symmetry group. Here transcript equations determine \(w\) only up to the symmetry preserving \(g\), e.g. \(w \sim -w\) for squaring.

This is a superb conceptual bridge:
- affine Σ-extraction corresponds to full identifiability,
- quadratic extraction resembles phase/sign ambiguity,
- auxiliary transcript data acts like symmetry-breaking measurements.

### 4. Cryptography × Physics
The map \(w \mapsto w^2\) creates a two-sheeted cover, analogous to observables that forget sign or phase. Extraction then resembles recovering microscopic state from coarse observables. This can motivate ARTICLE.md beautifully.
