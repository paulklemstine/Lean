## Primary Theorem Statement

### Theorem A: Tropical Hodge = Tropical Cycle under explicit generation hypothesis

Prove an exact equivalence theorem in a finitely generated setting.

Suggested mathematical statement:

> Let `C` be a finite tropical shadow complex. Assume:
> 1. `C` has a graded tropical cohomology ring generated in degree 1 by divisor classes,
> 2. every degree-`p` Hodge class lies in the subalgebra generated by divisor classes,
> 3. every divisor class is represented by a tropical codimension-1 cycle,
> 4. cycle classes are multiplicative under tropical intersection.
>
> Then for every `p` and every cohomology class `x ∈ H^{p,p}_trop(C)`,  
> `x` is a Hodge class iff `x` is represented by a tropical codimension-`p` cycle.

A Lean-style type signature could be:

```lean
theorem tropical_hodge_iff_cycle
    (C : ShadowComplex)
    (hgen : ∀ p, Submodule.span ℤ (Set.range (C.divisorPower p)) = C.hodgeSubmodule p)
    (hdiv : ∀ d : C.cohomology 1, C.IsDivisorClass d → ∃ Z : TropicalCycle C 1, C.cycleClass Z = d)
    (hmul : ∀ {p q} (Zp : TropicalCycle C p) (Zq : TropicalCycle C q),
      ∃ Zpq : TropicalCycle C (p + q), C.cycleClass Zpq = C.mul _ _ (C.cycleClass Zp) (C.cycleClass Zq))
    (x : C.cohomology p) :
    C.IsHodgeClass p x ↔ ∃ Z : TropicalCycle C p, C.cycleClass Z = x
```

This is the theorem to aim for first. It is strong, nontrivial, and formalizable.

## 2–3 Proof Strategy Architectures

### Strategy A: Divisor-generation bootstrap via graded algebra
Most promising.

1. **Define the Hodge submodule** `C.hodgeSubmodule p` as the graded piece generated by degree-1 divisor classes.
2. Use `hdiv` to represent each degree-1 generator by a tropical codimension-1 cycle.
3. Use `hmul` inductively to show every polynomial / monomial in divisor classes is represented by an iterated tropical intersection cycle.
4. Conclude surjectivity onto Hodge classes by `hgen`; the reverse implication is immediate if cycle classes land in the Hodge submodule by construction.

Why this is best:
- It reduces the theorem to algebra in a finitely generated graded ring.
- It is Lean-friendly: induction on degree and finite sums/products.
- It naturally interfaces with `idempotent_hilbert_basis_theorem`.

### Strategy B: Finite-generation + extremal-ray decomposition
Good for Theorem B and stronger computational consequences.

1. Model tropical cycles as a finitely generated semimodule/cone of balanced weights.
2. Apply an idempotent/noetherian finite basis theorem to extract finitely many primitive cycle generators.
3. Show every Hodge class in the image of the cycle map is generated by these primitive classes.
4. Deduce finite generation of the cycle-class image and possibly a normal form theorem.

Why it matters:
- Gives algorithmic content.
- Connects directly to idempotent algebra and semiring methods.
- Opens the door to a decision procedure for representability.

### Strategy C: Transfer-first approach
Best if `tropical_to_classical_transfer` is already strong.

1. Prove tropical representability implies membership in a distinguished transferred algebraic-shadow subring.
2. Pull back the Hodge-class predicate along the transfer map.
3. If the transfer is injective on the relevant graded piece, derive equivalence upstairs from classical constraints downstairs, or vice versa.

Why this may work:
- Exploits existing catalog infrastructure.
- Could produce stronger interoperability theorems.
- Especially good if tropical and classical cohomology are already linked in the library.

But unless the existing transfer theorem is very rich, Strategy A is the main line.

## Concrete Lean 4 design advice

Use concrete types. Avoid overabstracting too early. A workable first implementation is:

- `Cell := Fin n`
- `weight : Fin n → ℤ`
- `cohomology p := (Fin m → ℤ)` or a finitely generated `Module.Free`
- Hodge classes = span of a finite family of generators
- cycle class map = explicit linear map from cycle weights to cohomology vectors

Then prove the abstract theorem in this finite linear-algebra model. Later generalize.

For example:
```lean
structure FiniteTropicalModel where
  nCells : ℕ
  topDim : ℕ
  dim : Fin nCells → ℕ
  Coh : ℕ → Type
  [cohAddCommGroup : ∀ p, AddCommGroup (Coh p)]
  [cohModule : ∀ p, Module ℤ (Coh p)]
  hodgeGens : ∀ p, Finset (Coh p)
  cycleClass : ∀ p, (Fin nCells → ℤ) →ₗ[ℤ] Coh p
  balanced : ∀ p, (Fin nCells → ℤ) → Prop
```

Then define:
```lean
def IsHodgeClass (M : FiniteTropicalModel) (p : ℕ) (x : M.Coh p) : Prop :=
  x ∈ Submodule.span ℤ ((M.hodgeGens p : Finset (M.Coh p)) : Set (M.Coh p))

def IsCycleClass (M : FiniteTropicalModel) (p : ℕ) (x : M.Coh p) : Prop :=
  ∃ w, M.balanced p w ∧ M.cycleClass p w = x
```

A first exact theorem could then be:
```lean
theorem isHodgeClass_iff_isCycleClass
    (M : FiniteTropicalModel)
    (hrep : ∀ p g, g ∈ M.hodgeGens p → ∃ w, M.balanced p w ∧ M.cycleClass p w = g)
    (hspan : ∀ p x, x ∈ Submodule.span ℤ ((M.hodgeGens p : Finset (M.Coh p)) : Set (M.Coh p)) →
      ∃ w, M.balanced p w ∧ M.cycleClass p w = x) :
    ∀ p x, M.IsHodgeClass p x ↔ M.IsCycleClass p x
```

This may look “model-level,” but it is exactly the right formal beachhead.
