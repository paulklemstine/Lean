## Precise Theorem Targets

### 1. Generic common-reduct bisimulation from Church–Rosser

Define a relation saying two terms have a common reduct:
```lean
def HasCommonReduct {α : Type u} (R : α → α → Prop) (a b : α) : Prop :=
  ∃ c, Relation.ReflTransGen R a c ∧ Relation.ReflTransGen R b c
```

Then prove a theorem of the following shape:

```lean
theorem common_reduct_strong_bisimulation_of_church_rosser
  {α : Type u}
  (R : α → α → Prop)
  (hCR :
    ∀ {a b c},
      Relation.ReflTransGen R a b →
      Relation.ReflTransGen R a c →
      ∃ d, Relation.ReflTransGen R b d ∧ Relation.ReflTransGen R c d) :
  StrongBisimulation
    (fun x y => HasCommonReduct R x y)
    R
```

If `StrongBisimulation` is not already available in the exact needed form, define the appropriate notion for a transition relation:
```lean
def StrongBisimulation
  (S : α → α → Prop) (R : α → α → Prop) : Prop :=
  ∀ ⦃x y⦄, S x y →
    (∀ ⦃x'⦄, R x x' → ∃ y', Relation.ReflTransGen R y y' ∧ S x' y') ∧
    (∀ ⦃y'⦄, R y y' → ∃ x', Relation.ReflTransGen R x x' ∧ S x' y')
```

A stronger and cleaner target, if feasible, is to prove matching by **single-step** successors under extra closure lemmas.

**Why this matters:** this is the universal form of the lambda-calculus theorem. Once proved, every confluent rewrite formalism inherits bisimulation machinery for free.

### 2. Rewrite equivalence implies modal invariance on bounded FTS

Define bounded reachability:
```lean
inductive BoundedReachable {α : Type u} (R : α → α → Prop) : Nat → α → α → Prop
| refl  : ∀ a, BoundedReachable 0 a a
| step  : ∀ {n a b c}, R a b → BoundedReachable n b c → BoundedReachable (n+1) a c
```

Define a bounded transition system from `R` up to depth `n`. Then formulate and prove a theorem of the form:

```lean
theorem church_rosser_implies_modal_invariance_bounded
  {α : Type u}
  (R : α → α → Prop)
  (hCR :
    ∀ {a b c},
      Relation.ReflTransGen R a b →
      Relation.ReflTransGen R a c →
      ∃ d, Relation.ReflTransGen R b d ∧ Relation.ReflTransGen R c d) :
  ∀ n x y,
    HasCommonReduct R x y →
    ModalEquivalentUpTo n R x y
```

Here `ModalEquivalentUpTo n R x y` should be your own depth-indexed modal indistinguishability notion for the unlabeled transition system generated by `R`. A simple and formalizable choice is a Hennessy–Milner style recursion:

```lean
def ModalEquivalentUpTo : Nat → (α → α → Prop) → α → α → Prop
| 0,     R, x, y => True
| n + 1, R, x, y =>
    (∀ x', R x x' → ∃ y', Relation.ReflTransGen R y y' ∧ ModalEquivalentUpTo n R x' y') ∧
    (∀ y', R y y' → ∃ x', Relation.ReflTransGen R x x' ∧ ModalEquivalentUpTo n R x' y')
```

If you can strengthen from `ReflTransGen`-matching to direct one-step matching under local confluence + closure assumptions, even better.

**Why this matters:** it converts confluence into a **logic-preservation principle**, not merely a normalization fact.

### 3. Church–Rosser induces weak bisimulation on the reflexive closure / saturation

Define a weak-transition view where a visible move is “one rewrite surrounded by any number of silent rewrites” or simply use `ReflTransGen R` as the weak transition relation. Then prove:

```lean
theorem church_rosser_implies_weak_bisimulation
  {α : Type u}
  (R : α → α → Prop)
  (hCR :
    ∀ {a b c},
      Relation.ReflTransGen R a b →
      Relation.ReflTransGen R a c →
      ∃ d, Relation.ReflTransGen R b d ∧ Relation.ReflTransGen R c d) :
  WeakBisimulation
    (fun x y => HasCommonReduct R x y)
    R
```

with your own precise `WeakBisimulation` definition if necessary.

This theorem should not be a restatement of theorem 1; it should isolate the coalgebraic semantics of confluence through weak transitions.

## Lean 4 Formalization Targets

You should define a reusable structure along the lines of:

```lean
structure ARS (α : Type u) where
  step : α → α → Prop
```

Optionally enrich it:

```lean
structure ARS where
  State : Type u
  step : State → State → Prop
```

Then define:

```lean
namespace ARS

def MultiStep (A : ARS) : A.State → A.State → Prop :=
  Relation.ReflTransGen A.step

def HasCommonReduct (A : ARS) (a b : A.State) : Prop :=
  ∃ c, A.MultiStep a c ∧ A.MultiStep b c

def ChurchRosser (A : ARS) : Prop :=
  ∀ ⦃a b c⦄, A.MultiStep a b → A.MultiStep a c →
    ∃ d, A.MultiStep b d ∧ A.MultiStep c d

def RewriteEquivalent (A : ARS) (a b : A.State) : Prop :=
  ∃ c, A.MultiStep a c ∧ A.MultiStep b c

end ARS
```


At least **3 substantial theorems** must involve real proof structure: induction on `ReflTransGen`, `rcases` on common reduct witnesses, `calc` chains for closure composition, and contradiction arguments where useful.

## Proof Strategy Architecture

### Strategy A: Direct abstraction of the lambda-calculus proof pattern
Most promising.

1. **Isolate the exact lambda-specific lemmas** in `Pythagorean/ChurchRosserBisimulation.lean` that only use:
   - embedding of one-step into multi-step,
   - transitivity of multi-step reduction,
   - Church–Rosser joinability.
2. **Refactor them into ARS-generic lemmas** over an arbitrary relation `R`.
3. Define `HasCommonReduct R` and show it is preserved under successors using the Church–Rosser diamond/join argument.
4. Lift preservation into strong/weak bisimulation and then into modal equivalence.

**Why best:** the catalog theorem already contains the blueprint; the innovation is to identify the true invariant core and remove all syntax-specific baggage.

---

### Strategy B: Coalgebra-first proof via relational closure
Conceptually elegant.

1. Define the transition coalgebra of an ARS as the powerset-valued successor map.
2. Define `HasCommonReduct` as a post-fixed point of the bisimulation operator.
3. Show Church–Rosser implies closure of this relation under the bisimulation transfer condition.
4. Conclude modal invariance from standard coinductive principles or from a depth-indexed approximation.

**Why interesting:** this makes the result look like a theorem in categorical semantics, not just rewriting theory.

**Risk:** Mathlib support for coalgebraic abstractions may be thinner than for raw relations, so this may require extra infrastructure.

---

### Strategy C: Induction on bounded modal depth
Best for the modal theorem.

1. Define `ModalEquivalentUpTo n`.
2. Base case `n = 0` is trivial by definition.
3. Inductive step uses Church–Rosser to match any one-step move from one side by a multi-step move from the other into a shared reduct region.
4. Reapply the induction hypothesis to matched descendants.

**Why useful:** even if full bisimulation abstractions become technically heavy, the bounded modal theorem remains within reach and still delivers a genuine new result.

## Falsifiable Conjecture with Computational Test

State at least one precise conjecture in the code comments and in `FUTURE_DIRECTIONS.md`.

### Conjecture A: bounded common-reduct detection completeness
For every finitely branching confluent ARS with a computable normal-form measure, there exists a function `f : Nat → Nat` such that if two states are modal-equivalent up to depth `n`, then `searchCommonReduct` finds a common reduct within fuel `f n`.

**Computational test:** generate finite confluent rewrite graphs of bounded size, compare:
- depth-`n` modal equivalence,
- existence of common reduct found by bounded search.
A counterexample is any pair modal-equivalent up to `n` but with no common reduct found within the predicted bound.

### Conjecture B: finite quotient minimization
In every finite confluent ARS, quotienting by common-reduct equivalence yields the minimal bounded-modal model up to every finite depth.

**Computational test:** enumerate finite confluent graphs, compute quotient size and compare with brute-force modal partition refinement.

These are falsifiable and algorithmically testable.
