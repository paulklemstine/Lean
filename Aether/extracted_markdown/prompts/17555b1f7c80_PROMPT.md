## Assignment: Triangle inequality for orbit/Wasserstein-type quotient cost

**Mode: prove**

Prove a genuinely new structural theorem: a triangle inequality for a quotient optimal-transport cost obtained by minimizing over a group action. The core idea in the sketch is right, but it must be elevated into a precise, reusable metric-construction theorem that can become infrastructure for an entire formal theory of symmetry-reduced transport, orbit metrics, and equivariant learning.

This is not about proving a one-off inequality. It is about formalizing a **general mechanism**:

> if a cost `Wc` on a space `α` satisfies a triangle inequality and a group `G` acts on `α` by cost-preserving maps, then the induced orbit cost
> `inf_g Wc μ (g • ν)`
> also satisfies a triangle inequality.

That theorem opens a field: quotient OT, symmetry-aware geometry, canonicalization-free comparison of structured objects, and equivariant distances in ML and physics.

## Precise theorem target

Work in maximum generality that is still Lean-manageable:

- `G` a group
- `α` a type with a `MulAction G α`
- `Wc : α → α → ℝ`
- assume:
  1. nonnegativity if useful,
  2. triangle inequality,
  3. invariance under the action in the second slot, or better, diagonal invariance.

Then define the orbit cost:
```lean
def orbitCost (Wc : α → α → ℝ) [Group G] [MulAction G α] (μ ν : α) : ℝ :=
  sInf {r : ℝ | ∃ g : G, r = Wc μ (g • ν)}
```

A more Lean-friendly equivalent if infimum over a set is awkward:
```lean
def orbitCost (Wc : α → α → ℝ) [Group G] [MulAction G α] (μ ν : α) : ℝ :=
  sInf (Set.range fun g : G => Wc μ (g • ν))
```

### Main theorem
```lean
theorem orbitCost_triangle
  {G α : Type*} [Group G] [MulAction G α]
  (Wc : α → α → ℝ)
  (htri : ∀ x y z : α, Wc x z ≤ Wc x y + Wc y z)
  (hinv : ∀ x y : α, ∀ g : G, Wc (g • x) (g • y) = Wc x y) :
  ∀ μ ν ρ : α, orbitCost Wc μ ρ ≤ orbitCost Wc μ ν + orbitCost Wc ν ρ
```

This is the breakthrough-grade version because it isolates the exact categorical mechanism: **triangle inequality descends through isometric group quotienting**.

### Stronger theorem worth targeting if feasible

```lean

  (hinv : ∀ x y : α, ∀ g : G, Wc (g • x) (g • y) = Wc x y) :
  ∀ μ ν ρ : α, ∀ g₁ g₂ : G,
```

The key internal estimate should be:
```lean
have hkey :
  Wc μ ((g₁ * g₂) • ρ) ≤ Wc μ (g₁ • ν) + Wc ν (g₂ • ρ) := ...
```

using
- triangle inequality with midpoint `g₁ • ν`,
- action associativity,
- invariance to rewrite
  `Wc (g₁ • ν) ((g₁ * g₂) • ρ) = Wc ν (g₂ • ρ)`.

This theorem is the engine. The orbit triangle inequality should then follow by ε-approximation or by `sInf` order properties.

## 2–3 proof strategy paths

### Strategy A: ε-near-optimizer proof via group composition
This is the most faithful to the research direction and probably the most intuitive.

1. For fixed `ε > 0`, choose `g₁, g₂ : G` such that
   - `Wc μ (g₁ • ν) ≤ orbitCost Wc μ ν + ε/2`
   - `Wc ν (g₂ • ρ) ≤ orbitCost Wc ν ρ + ε/2`.

2. Show by triangle inequality:
   ```lean
   Wc μ ((g₁ * g₂) • ρ) ≤ Wc μ (g₁ • ν) + Wc (g₁ • ν) ((g₁ * g₂) • ρ)
   ```

3. Rewrite the second term using invariance:
   ```lean
   Wc (g₁ • ν) (g₁ • (g₂ • ρ)) = Wc ν (g₂ • ρ)
   ```

4. Conclude
   ```lean
   orbitCost Wc μ ρ ≤ Wc μ ((g₁ * g₂) • ρ)
   ```
   and hence
   ```lean
   orbitCost Wc μ ρ ≤ orbitCost Wc μ ν + orbitCost Wc ν ρ + ε
   ```
   then let `ε → 0`.

**Why promising:** Conceptually clean, mirrors the mathematical framing exactly, and exposes the algebraic heart: composition of witnesses.

---

### Strategy B: `sInf`/order-theoretic descent proof
This is more abstract and may yield a stronger reusable library lemma.

1. Prove the pointwise bound for every `g₁ g₂`:
   ```lean
   Wc μ ((g₁ * g₂) • ρ) ≤ Wc μ (g₁ • ν) + Wc ν (g₂ • ρ)
   ```

2. Show that every element of the set
   ```lean
   Set.range (fun g : G => Wc μ (g • ρ))
   ```
   is bounded above by some element of the Minkowski-sum-style set generated by the two ranges.

3. Use properties of `sInf`:
   - `sInf_le` to compare the infimum to any candidate,
   - lower-bound arguments to compare with sums of infima.

**Why promising:** More elegant and library-worthy if the set/order lemmas line up. It could produce a generic theorem about infimal convolution under group actions.

---

### Strategy C: descend to quotient/orbit space, then lift back
This is the most visionary route.

1. Define a relation `x ~ y :↔ ∃ g, y = g • x`.
2. Show `Wc` descends to a pseudometric on orbit classes under invariance.
3. Identify `orbitCost` as the quotient distance.

**Why promising:** This creates a whole theory of orbit pseudometrics.  
**Why risky:** Quotients in Lean can be technically heavier than the direct infimum proof.

**Recommendation:** Start with Strategy A, extract the core composition lemma, then generalize with Strategy B. Keep Strategy C as a follow-on theorem in `FUTURE_DIRECTIONS.md`.

## Mathematical framing to sharpen

The current framing repeats the same sentence. Replace it with this:

> Let `Wc` be a base cost on objects `α`, and let `G` act on `α` by `Wc`-isometries. Define the symmetry-reduced cost
> \[
> \widetilde W_c(\mu,\nu) := \inf_{g \in G} W_c(\mu, g\cdot \nu).
> \]
> Then for all `μ ν ρ`,
> \[
> \widetilde W_c(\mu,\rho) \le \widetilde W_c(\mu,\nu) + \widetilde W_c(\nu,\rho).
> \]
> The proof is driven by composability of near-optimal alignments: if `g₁` nearly aligns `ν` to `μ` and `g₂` nearly aligns `ρ` to `ν`, then `g₁ g₂` nearly aligns `ρ` to `μ`.

This should be written explicitly in the source file and documentation comments.
