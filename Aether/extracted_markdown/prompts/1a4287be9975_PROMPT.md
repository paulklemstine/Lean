## Research Task: Tropical Satake support reconstruction for `GL₃` from three rank-1 marginals, and dominant-chamber convolution faithfulness

Research Mode: PROVE

Work in a concrete combinatorial model of dominant `GL₃` coweights where a dominant coweight is encoded by a pair `(a,b) : ℕ × ℕ`, representing the simple-coroot coordinates
`λ = a • α₁∨ + b • α₂∨`.
This is the `A₂` dominant chamber, and it is enough for a first formal theorem because all relevant support data and tropical convolution can be expressed in these coordinates.

Use finitely supported functions
`f : (ℕ × ℕ) → ℝ`
together with an explicit finite support hypothesis, e.g.
`∃ S : Finset (ℕ × ℕ), ∀ x, f x ≠ 0 → x ∈ S`,
or more canonically with `Finsupp` if convenient. The point is to formalize a genuine reconstruction theorem from three one-dimensional marginals:
- the `α₁`-marginal along fibers of fixed `b`,
- the `α₂`-marginal along fibers of fixed `a`,
- the `(α₁+α₂)`-marginal along fibers of fixed `a+b`.

The mathematically meaningful version to target is not arbitrary recovery of a function from arbitrary sums along lines, which is false, but recovery for **downward-closed dominant support indicators / tropical Newton support functions**. So introduce a monotonicity/convexity class strong enough to make the theorem true and weak enough to be interesting.

A robust formal target is to work with finite lower sets in `ℕ × ℕ`:

```lean
def LowerSet2D (S : Set (ℕ × ℕ)) : Prop :=
  ∀ ⦃a b a' b' : ℕ⦄, a' ≤ a → b' ≤ b → (a,b) ∈ S → (a',b') ∈ S
```

and with their indicator functions or weighted versions whose support is a lower set.

Define the three line-profile invariants of a finite lower set `S`:
- row lengths `rowLen S : ℕ → ℕ`, where `rowLen S b = card {a | (a,b) ∈ S}`
- column heights `colLen S : ℕ → ℕ`, where `colLen S a = card {b | (a,b) ∈ S}`
- diagonal lengths `diagLen S : ℕ → ℕ`, where `diagLen S n = card {(a,b) | a+b=n ∧ (a,b) ∈ S}`

These are the three embedded `GL₂` Newton polygon marginals. The key theorem should show that for finite lower sets, the pair `(rowLen, colLen)` already reconstructs the Ferrers profile, and the diagonal data gives the compatibility needed for the tropical convolution step and the intended “highest-root direction” interpretation. If you can prove a stronger theorem using all three marginals simultaneously, even better.

### Precise Lean targets

First formalize the boundary profile of a finite lower set:

```lean
def rowBound (S : Set (ℕ × ℕ)) (b : ℕ) : ℕ :=
  sInf {m : ℕ | ∀ a, m ≤ a → (a,b) ∉ S}
```

or, more Lean-friendly for finite lower sets, define the maximal allowed `a` in row `b` by finite search:

```lean
def rowMax (N : ℕ) (S : Set (ℕ × ℕ)) (b : ℕ) : ℕ :=
  Nat.findGreatest (fun a => a ≤ N ∧ (a,b) ∈ S) N
```

Then prove that for a finite lower set there is a monotone row profile `ρ : ℕ → ℕ` with finite support such that
`(a,b) ∈ S ↔ b < B ∧ a < ρ b`
for some finite `B`, and `Antitone ρ`.

A useful exact theorem statement is:

```lean
theorem lowerSet_ext_of_rowLen
  {S T : Set (ℕ × ℕ)}
  (hSfin : S.Finite) (hTfin : T.Finite)
  (hSdown : LowerSet2D S) (hTdown : LowerSet2D T)
  (hrows : ∀ b : ℕ,
    Nat.card {a // (a,b) ∈ S} = Nat.card {a // (a,b) ∈ T}) :
  S = T
```

If `Nat.card` on subtypes is awkward, replace by explicit finite truncations extracted from finiteness, or package the sets as finite lower-set data from the outset:

```lean
structure FerrersShape where
  carrier : Finset (ℕ × ℕ)
  lower_mem :
    ∀ ⦃a b a' b' : ℕ⦄, a' ≤ a → b' ≤ b → (a,b) ∈ carrier → (a',b') ∈ carrier
```

and then define

```lean
def rowLen (S : FerrersShape) (b : ℕ) : ℕ :=
  ((S.carrier.filter (fun p => p.2 = b)).card)

def colLen (S : FerrersShape) (a : ℕ) : ℕ :=
  ((S.carrier.filter (fun p => p.1 = a)).card)

def diagLen (S : FerrersShape) (n : ℕ) : ℕ :=
  ((S.carrier.filter (fun p => p.1 + p.2 = n)).card)
```

The main reconstruction theorem can then be stated concretely as:

```lean
theorem FerrersShape.ext_of_three_marginals
  {S T : FerrersShape}
  (hrow : ∀ b, rowLen S b = rowLen T b)
  (hcol : ∀ a, colLen S a = colLen T a)
  (hdiag : ∀ n, diagLen S n = diagLen T n) :
  S = T
```

A sharper theorem, likely easier and stronger, is:

```lean
theorem FerrersShape.ext_of_rowLen
  {S T : FerrersShape}
  (hrow : ∀ b, rowLen S b = rowLen T b) :
  S = T
```

Then derive the advertised “three marginals determine the support” theorem as an immediate corollary. This is mathematically legitimate: the three `GL₂` marginals certainly contain the row data.

Next, define tropical/dominant convolution on lower-set indicators by Minkowski sum of supports. For support sets:

```lean
def supportConv (S T : Finset (ℕ × ℕ)) : Finset (ℕ × ℕ) :=
  (S.biUnion fun p =>
    T.image ⟨fun q => (p.1 + q.1, p.2 + q.2), by intro x y h; simpa using h⟩)
```

For lower-set/Ferrers shapes, define the convolution shape by carrier `supportConv S.carrier T.carrier`, and prove it is again lower.

The faithfulness statement should then be formulated at the support level first:

```lean
theorem supportConv_right_cancel
  {S T H : FerrersShape}
  (hHnz : H.carrier.Nonempty)
  (hconv : supportConv S.carrier H.carrier = supportConv T.carrier H.carrier) :
  S = T
```

This is the clean dominant-chamber cancellation/faithfulness theorem. If you prefer to state it as faithfulness of convolution by a nonzero indicator function, define indicator-valued functions and show equality of supports implies equality of functions.

A weighted extension is desirable if feasible: for antitone tropical height functions `φ : ℕ × ℕ → ℝ` with finite lower support, define one-dimensional marginal minima along rows/columns/diagonals and prove extensionality from these data plus lower-set support assumptions. But the support-level theorem above is already substantial and is the right first milestone.

## Proof strategy

1. **Classify finite lower sets in `ℕ²` by antitone row profile.**  
   Prove that if `S` is finite and downward closed, then each row
   `Rb := {a | (a,b) ∈ S}` is an initial segment of `ℕ`, hence of the form `{a | a < ρ b}` for a unique `ρ b : ℕ`.  
   Then prove `ρ` is antitone in `b`:
   if `b₁ ≤ b₂` and `(a,b₂) ∈ S`, downward closure gives `(a,b₁) ∈ S`, so `ρ b₂ ≤ ρ b₁`.  
   This is the fundamental Ferrers-shape lemma.

   A very usable intermediate statement is:

   ```lean
   theorem exists_rowProfile
     (S : FerrersShape) :
     ∃ ρ : ℕ → ℕ, Antitone ρ ∧
       ∀ a b, ((a,b) ∈ S.carrier ↔ a < ρ b)
   ```

   Strictly speaking this needs the convention that `ρ b = 0` for rows outside the finite height; because `carrier` is finite, this is consistent.

2. **Recover the shape from row lengths.**  
   For a lower set, `rowLen S b = ρ b`. This is because row `b` is exactly the initial segment `{0,1,...,ρ b - 1}`.  
   Prove the cardinality lemma for initial segments:

   ```lean
   theorem card_filter_fst_of_initial_segment
     (ρ b : ℕ) :
     ((Finset.range ρ).card = ρ)
   ```

   and then identify each row in `S` with `Finset.range (rowLen S b)`.  
   This yields `FerrersShape.ext_of_rowLen`.  
   The three-marginal theorem is then immediate: use `hrow` and ignore the redundant extra data, or show the row marginal itself is one of the three embedded `GL₂` marginals.

3. **Show convolution of lower sets corresponds to profile addition in a monotone-envelope sense.**  
   For Ferrers shapes `S,T`, define row profiles `ρS, ρT`.  
   The row profile of the Minkowski sum is not simply pointwise sum on the same row index; instead the exact formula is

   ```lean
   ρ_{S⊕T}(n) = sup_{i+j=n} (ρS i + ρT j)
   ```

   in `ℕ`, i.e. maximum over decompositions `n = i + j`.  
   This is the tropical convolution / max-plus convolution of row profiles.  
   Prove both inequalities:
   - if `a < ρS i` and `a' < ρT j`, then `(a+a', i+j)` lies in the sum, giving
     `ρ_{S⊕T}(n) ≥ ρS i + ρT j`;
   - conversely, any point in the sum decomposes this way, so the maximal row length is bounded by the displayed supremum.

   This is the exact place where the “pairwise `GL₂` marginal” philosophy becomes concrete: the `GL₃` support convolution reduces to one-dimensional tropical convolution of row profiles.

4. **Prove right-cancellation for nonempty lower sets using extremal row index.**  
   Let `ηH` be the largest row index with `rowLen H ηH > 0`; existence follows from finiteness and nonemptiness.  
   Then for every `n`,
   the top contribution of `ρH` at `ηH` lets you recover `ρS n` from the convolved profile at row `n + ηH`, because `ρH ηH ≥ 1` and antitonicity forces extremal behavior at the boundary.  
   A more robust argument is to compare maximal row indices and induct downward on `n`:
   from equality
   `ρ_{S⊕H} = ρ_{T⊕H}`
   and knowledge of previously recovered larger rows, isolate the contribution with `j = ηH`.  
   This is a discrete deconvolution on antitone finite-support sequences.

   If this direct cancellation is technically messy, first prove the simpler lemma:
   if `H = {(0,0)}` then cancellation is trivial; then prove cancellation for `H` equal to a rectangle; then extend to general lower sets by induction on `H.carrier.card`, peeling off an extremal corner.  
   The corner-removal induction is natural for Ferrers shapes.

5. **Transfer back from profiles to shapes/functions.**  
   Once row profiles agree, apply `FerrersShape.ext_of_rowLen`.  
   If you define indicator functions
   `1_S : ℕ × ℕ → ℕ` or `→ ℝ`,
   conclude equality of functions from equality of carriers.  
   This gives the desired dominant-chamber convolution faithfulness.

```lean

  Finset.sup (Finset.range (n+1)) (fun i => ρ i + σ (n - i))
```

```lean
  {S T : FerrersShape} :
  ∀ n, rowLen (convShape S T) n = rowProfConv (rowLen S) (rowLen T) n
```

```lean
theorem antitone_right_cancel_rowProf
  {ρ σ τ : ℕ → ℕ}
  (hρanti : Antitone ρ) (hσanti : Antitone σ) (hτanti : Antitone τ)
  (hσfin : ∃ N, ∀ n > N, σ n = 0)
  (hσnz : ∃ n, 0 < σ n)
```

## Significance

This matters because it gives a formal `GL₃` tropical Satake reconstruction theorem without needing the harder `GL₄` hypersimplex machinery. The essential new idea is a cross-rank reduction: encode dominant `GL₃` support by a two-dimensional Ferrers/Newton shape, then recover it from rank-1 `GL₂`-type marginals. This is a concrete tropical analogue of recovering a highest-weight object from its Levi-direction shadows.

The convolution-faithfulness theorem is the structural payoff. In Satake-style settings, faithfulness of convolution by a nonzero dominant object is exactly the kind of rigidity needed to show that tropical transforms preserve information rather than collapsing it. Formally, it provides a cancellation theorem for dominant Newton supports under Minkowski addition, which is a strong and reusable lemma for later work on tropical Hecke algebras and higher-rank support reconstruction.

So the recommended path is:
1. formalize finite lower sets / Ferrers shapes in `ℕ²`,
2. prove extensionality from row profile,
3. package the three marginals as row/column/diagonal projections and derive reconstruction,
4. prove Minkowski-sum row-profile convolution,
5. deduce right-cancellation / convolution faithfulness.

That sequence should produce several substantial theorems in one file, with each stage independently valuable.
