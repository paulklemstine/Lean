## Primary Target: Mod-12 Pareto Rigidity and Cyclic Optimality

The self-contained mod-12 setting is not just a toy model. It is the first finite arena where harmonic preference, tropical optimization, and discrete information geometry can all be made exact in Lean. If you succeed here, you create the canonical finite testbed for the four-part, rate-distortion, and categorical directions. The real breakthrough is to show that mod-12 harmonic motion admits **finite rigidity theorems**: local pairwise improvement constraints force global optimality or canonical normal forms.

### Precise theorem statement

Define a cyclic distance on `ZMod 12`, extend it additively to finite pitch-class configurations, and prove that Pareto-optimal transitions are invariant under transposition.

A concrete first theorem:

```lean
def pc := ZMod 12

def cycDist (a b : pc) : ℕ :=
  min ((a - b).val) (12 - (a - b).val)

def shiftConfig (t : pc) (S : Finset pc) : Finset pc :=
  S.image fun x => x + t

def totalCycCost (A B : Finset pc) : ℕ :=
  ∑ a in A, A.inf fun b => cycDist a b

theorem totalCycCost_transposition_invariant
    (t : pc) (A B : Finset pc) :
    totalCycCost (shiftConfig t A) (shiftConfig t B) = totalCycCost A B
```

But this is only the warm-up. The real theorem should be a rigidity statement for Pareto-minimal motions of 3-note or 4-note pitch-class sets.

A more consequential target:

```lean
def voiceLeadCost (x y : Fin 3 → pc) : ℕ :=
  ∑ i, cycDist (x i) (y i)

def ParetoMinimal (x y : Fin 3 → pc) : Prop :=
  ¬ ∃ z : Fin 3 → pc,
    (∀ i, cycDist (x i) (z i) ≤ cycDist (x i) (y i)) ∧
    (∃ j, cycDist (x j) (z j) < cycDist (x j) (y j))

theorem pareto_minimal_transposition_invariant
    (t : pc) (x y : Fin 3 → pc) :
    ParetoMinimal x y →
    ParetoMinimal (fun i => x i + t) (fun i => y i + t)
```

And the genuinely field-opening theorem to aim for:

```lean
def intervalMultiset3 (x : Fin 3 → pc) : Multiset ℕ := sorry

theorem pareto_minimal_depends_only_on_interval_data
    (x y x' y' : Fin 3 → pc)
    (hx : intervalMultiset3 x = intervalMultiset3 x')
    (hy : intervalMultiset3 y = intervalMultiset3 y')
    (hrel : intervalMultiset3 (fun i => y i - x i) =
            intervalMultiset3 (fun i => y' i - x' i)) :
    ParetoMinimal x y ↔ ParetoMinimal x' y'
```

Even if the final interval-data theorem requires refining the invariant, this is the right ambition: classify Pareto-minimal voice leadings by cyclic orbit data rather than raw representatives.

## Lean 4 formalization guidance

Use concrete types:
- `pc := ZMod 12`
- configurations as `Fin n → pc` for fixed voice count,
- orbit actions via addition by constants,
- costs in `ℕ` first, then possibly `ℝ`.

Prefer function-tuples `Fin n → pc` over unordered `Finset pc` when proving Pareto statements, because voicewise comparison is coordinate-sensitive. Use `Finset` only for set-class invariants and orbit representatives.

If `cycDist` via `.val` becomes awkward, define it first through an integer representative lemma library:
```lean
def rawDist (a b : ZMod 12) : ℕ := (a - b).val
def cycDist (a b : ZMod 12) : ℕ := min (rawDist a b) (12 - rawDist a b)
```
Then prove:
```lean
theorem cycDist_add_right_invariant (a b t : pc) :
    cycDist (a + t) (b + t) = cycDist a b
```
This lemma is the atomic engine for everything else.

## Proof strategy architecture

### Strategy A: Direct group-action rigidity
Most promising for immediate Lean success.

1. Prove the metric invariance lemma:
   - `cycDist (a+t) (b+t) = cycDist a b`
   - then pointwise invariance of `voiceLeadCost`.
2. Transport Pareto witnesses across transposition:
   - if `z` dominates `y` relative to `x`, then `z+t` dominates `y+t` relative to `x+t`.
3. Conclude invariance of `ParetoMinimal` by contradiction.

Why this is promising:
- entirely self-contained,
- avoids quotient types,
- uses only finite sums and elementary `ZMod` algebra,
- gives reusable lemmas for every later direction.

### Strategy B: Quotient-space formulation
More visionary, slightly harder.

1. Define the transposition action of `pc` on `Fin n → pc`.
2. Define the orbit quotient informally first through an invariant predicate, or formally via `Quotient` if manageable.
3. Show `ParetoMinimal` descends to the quotient because the dominance relation is action-invariant.

Why this matters:
- this is the mathematically correct language for harmonic shape space,
- it sets up later categorical and transport results,
- it may allow classification by orbit representatives.

Why it is less immediate:
- quotient reasoning in Lean may slow progress,
- better attempted after the direct invariance theorem is established.

### Strategy C: Interval-coordinate reduction
Best for a stronger theorem after A succeeds.

1. Normalize one voice to `0` by transposition.
2. Encode a 3-voice configuration by interval coordinates `(a,b) : pc × pc`.
3. Rewrite Pareto minimality entirely in terms of interval coordinates and relative motion data.
4. Derive a classification theorem: Pareto minimality depends only on normalized interval data.

Why this is revolutionary:
- it turns harmonic motion into a finite classification problem,
- enables exhaustive computation plus proof,
- gives a canonical database of all mod-12 Pareto classes.
