## Assignment: Direction 4: Shadow Complexity as an Arithmetic Circuit Lower Bound

**Mode:** prove

Prove genuinely new, non-trivial theorems connecting combinatorial shadow growth to arithmetic circuit lower bounds for higher derivatives. Build explicitly on the catalog facts in `Catalog/Speculative/AutoResearch/WeightedSupportShadow.lean`, especially monotonicity lemmas such as `quadShadow_mono` and `computeQuadShadow_mono`, but do not stop at monotonicity: convert shadow cardinality into a certified complexity obstruction.

This direction is promising because it proposes a new kind of lower bound in arithmetic complexity: not degree-based, not rank-based, not purely syntactic, but **support-geometric**. If successful, it opens a program where Newton polytope combinatorics and discrete shadow operators become lower-bound witnesses for symbolic computation.

## Core mathematical vision

Let `S ⊆ ℕ^n` be the exponent support of a polynomial
\[
f(x_1,\dots,x_n)=\sum_{\alpha\in S} c_\alpha x^\alpha
\]
over a semiring or field. For second derivatives, each monomial \(x^\alpha\) contributes to \(\partial_i\partial_j f\) exactly when \(\alpha_i,\alpha_j\) are large enough, and the resulting exponent vector is \(\alpha-e_i-e_j\). Thus the union of all exponent supports appearing in the Hessian is the **2-shadow**
\[
\mathrm{Sh}_2(S):=\{\beta\in \mathbb N^n : \exists i,j,\ \beta+e_i+e_j\in S\}.
\]
The conjectural complexity principle is:

> A circuit computing all nonzero second partial derivatives must somehow account for every exponent in `Sh₂(S)`. Sharing can compress repeated work, but only by a bounded factor corresponding to the number of derivative channels.

The breakthrough would be to make this precise in a formal model and prove lower bounds of the form
\[
\mathrm{size}(C)\ \ge\ \frac{|\mathrm{Sh}_2(S)|}{n^2}
\]
or stronger under suitable non-collision hypotheses. This would be a field-opening bridge between:
- arithmetic circuit complexity,
- combinatorial commutative algebra,
- discrete geometry of supports/Newton polytopes,
- symbolic differentiation algorithms.

## Theorem 1: Shadow coverage theorem for Hessian supports

Formal target:
```lean
theorem secondShadow_subset_hessianUnion
  {n : ℕ} (S : Finset (Fin n → ℕ)) :
  secondShadow S ⊆
    ((hessianSupportFamily S).image (fun p => p.2))
```

Mathematical statement:

For every exponent vector \(\beta \in \mathrm{Sh}_2(S)\), there exist indices \(i,j\) such that \(\beta\) occurs in the support of the Hessian entry \(\partial_i\partial_j f\) for any polynomial \(f\) whose support contains a monomial with exponent \(\beta+e_i+e_j\) and nonzero coefficient.

Why it matters:

This theorem is the support-theoretic bridge from combinatorics to differentiation. It certifies that `secondShadow S` is not an arbitrary combinatorial gadget: it is exactly the ambient pool of exponents that Hessian computation must potentially realize.

Recommended Lean shape if coefficient semantics are cumbersome:
```lean
theorem mem_secondShadow_iff_exists_hessian_channel
  {n : ℕ} {β : Fin n → ℕ} {S : Finset (Fin n → ℕ)} :
  β ∈ secondShadow S ↔
    ∃ i j, ((i,j), β) ∈ hessianSupportFamily S
```

### Proof strategy options
- **Strategy A: direct unpacking of definitions**  
  Define `secondShadow` by existential subtraction of two unit vectors and define `hessianSupportFamily` similarly. Then prove the equivalence by `constructor`, `rcases`, and explicit witness construction.  
  This is the most robust formalization path.
- **Strategy B: reduce to catalog `quadShadow`**  
  If `WeightedSupportShadow.lean` already encodes the relevant two-step shadow operator, prove your `secondShadow` is extensionally equal to the catalog notion and then transport the result.
- **Strategy C: inductive closure viewpoint**  
  Express second shadow as one-step shadow applied twice, prove support occurrence for one derivative, then iterate. This may generalize better to `k`-th derivatives.

Use nontrivial proof steps: `rcases`, `simp` only as local simplifier, and at least one multi-step `calc`.

## Theorem 2: Counting lower bound for support circuits

Formal target:
```lean
theorem supportCircuit_hessian_lower_bound
  {n : ℕ} (S : Finset (Fin n → ℕ)) (C : SupportCircuit n)
  (hC : ComputesHessianSupport S C) :
  secondShadow S.card ≤ n^2 * C.size
```

Equivalent rearranged form:
```lean
theorem supportCircuit_size_ge_div
  {n : ℕ} (hn : 0 < n) (S : Finset (Fin n → ℕ)) (C : SupportCircuit n)
  (hC : ComputesHessianSupport S C) :
  secondShadow S.card / (n^2) ≤ C.size
```

Mathematical statement:

Any support circuit computing all second derivative channels must have size at least the second shadow cardinality divided by the number of Hessian channels. The philosophy is that a single gate/output can only serve boundedly many derivative positions unless exponent information collapses.

Why it is a breakthrough:

This is the first rigorous “shadow-to-complexity” theorem: a combinatorial invariant of support directly yields a lower bound on symbolic differentiation complexity.

### Necessary modeling refinement
To make this true, you likely need a bounded-fiber hypothesis on the circuit output map, e.g. each circuit-produced exponent can feed at most `n^2` Hessian channels. Formalize this honestly as part of the model or theorem assumptions:
```lean
def BoundedChannelReuse (n : ℕ) (C : SupportCircuit n) : Prop := ...
```
Then prove:
```lean
theorem supportCircuit_hessian_lower_bound
  {n : ℕ} (S : Finset (Fin n → ℕ)) (C : SupportCircuit n)
  (hC : ComputesHessianSupport S C) (hreuse : BoundedChannelReuse n C) :
  secondShadow S.card ≤ n^2 * C.size
```

### Proof strategy options
- **Strategy A: finite fiber counting**  
  Construct a surjective map from the set
  \[
  \{((i,j),\beta): \beta\in \mathrm{Sh}_2(S)\text{ realized in channel }(i,j)\}
  \]
  to circuit outputs, with each fiber of size at most `n^2`. Then apply a cardinality bound for finite fibers.  
  This is the most conceptually clean and strongest route.
- **Strategy B: pigeonhole via channel partition**  
  Partition Hessian-support realizations by derivative channel `(i,j)`. Show each output can cover at most one exponent per channel, hence at most `n^2` total. Then use `Finset.card_biUnion` estimates.
- **Strategy C: induction on circuit size**  
  Show adjoining one more support-producing gate increases total Hessian-cover capacity by at most `n^2`. Then conclude by induction on `C.size`.  
  This is more “complexity theoretic” and may be the most revolutionary if you can make it elegant.

Expect to use:
- `rcases`
- finite set cardinality inequalities
- `calc`
- perhaps `by_contra`
- induction if you choose Strategy C.

## Theorem 3: Explicit family with quadratic shadow growth

You need an actual family where the lower bound is nontrivial and asymptotically meaningful.

A strong target is a 2-variable staircase family:
\[
S_m := \{(a,b)\in \mathbb N^2 : a+b=m\}.
\]
Its second shadow is essentially
\[
\mathrm{Sh}_2(S_m)=\{(a,b)\in \mathbb N^2 : a+b=m-2\},
\]
so cardinality is exactly `m-1`. This is only linear, so it is a clean warmup but not enough for “superlinear.” Better is a simplex family in dimension `d`:
\[
T_{d,m}:=\{\alpha\in \mathbb N^d : |\alpha|=m\},
\quad
\mathrm{Sh}_2(T_{d,m})=\{\beta\in \mathbb N^d : |\beta|=m-2\}.
\]
Then
\[
|T_{d,m}|=\binom{m+d-1}{d-1},\qquad
|\mathrm{Sh}_2(T_{d,m})|=\binom{m+d-3}{d-1}.
\]
This is asymptotically comparable, not superlinear relative to support size. So to get a stronger phenomenon, consider product-like supports.

A more interesting family:
\[
R_m := \{(a,b,c,d)\in \mathbb N^4 : a+b=m,\ c+d=m\},
\]
with
\[
|R_m|=(m+1)^2,\qquad |\mathrm{Sh}_2(R_m)| \asymp 4m^2.
\]
Still comparable.

To push toward a sharp theorem, prove an **exact formula** for a family and then derive a lower bound consequence.

Formal target:
```lean
theorem secondShadow_card_simplex
  {d m : ℕ} (hm : 2 ≤ m) :
  (secondShadow (simplexSupport d m)).card =
    Nat.choose (m + d - 3) (d - 1)
```

If the full binomial-count theorem is too heavy, prove a weaker but still nontrivial lower bound:
```lean
theorem secondShadow_card_simplex_lower
  {d m : ℕ} (hd : 1 ≤ d) (hm : 2 ≤ m) :
  Nat.choose (m + d - 3) (d - 1) ≤
    (secondShadow (simplexSupport d m)).card
```

Why it matters:

This gives an explicit infinite family where your lower bound becomes concrete and computable. It transforms the theory from abstract obstruction to a quantitative method.

### Proof strategy options
- **Strategy A: stars-and-bars bijection**  
  Show `β ∈ secondShadow(simplexSupport d m)` iff the coordinate sum of `β` is `m-2`. Then invoke a finite combinatorial counting theorem.
- **Strategy B: explicit equivalence with lower simplex**  
  Prove
  ```lean
  secondShadow (simplexSupport d m) = simplexSupport d (m - 2)
  ```
  under `2 ≤ m`, then cardinality follows from a separate simplex-count theorem.
- **Strategy C: recursive decomposition in the last coordinate**  
  Derive a Pascal-type recurrence for shadow cardinalities and solve it by induction on `d` or `m`.

Strategy B is likely best if you can define simplex supports cleanly.

## Theorem 4: Cross-domain theorem linking support shadows to Newton polytope erosion

You are required to include a cross-domain connection. The natural and ambitious one is:

> The second shadow of a support corresponds to the lattice points in a discrete inward erosion of the Newton polytope by the degree-2 simplex.

Define a discrete erosion operation:
```lean
def polytopeErosion2 (S : Finset (Fin n → ℕ)) : Finset (Fin n → ℕ)
```
intended to model
\[
\{\beta : \beta+\gamma \in S \text{ for some } |\gamma|=2\}.
\]

Then prove an equivalence theorem:
```lean
theorem secondShadow_eq_discreteErosion
  {n : ℕ} (S : Finset (Fin n → ℕ)) :
  secondShadow S = polytopeErosion2 S
```

If you want a more geometric statement:
```lean
theorem secondShadow_convexHull_monotone
  {n : ℕ} {S T : Finset (Fin n → ℕ)}
  (h : convexHull ℚ (↑S : Set (Fin n → ℕ →?)) ⊆ convexHull ℚ (↑T : Set _)) :
  (secondShadow S).card ≤ (secondShadow T).card
```
but this is probably too ambitious unless the convex-geometric infrastructure is already available.

Why it matters:

This connects arithmetic complexity to convex/discrete geometry. The “shadow lower bound” becomes a Newton-polytope erosion invariant, suggesting future links to mixed volumes, toric geometry, and tropical complexity.

### Proof strategy options
- **Strategy A: combinatorial equality of definitions**  
  Define erosion exactly to match two-step subtraction and prove extensional equality by `ext` and `constructor`.
- **Strategy B: iterate one-step erosion**  
  If a first-shadow operator already exists in the catalog, define `polytopeErosion2` as two successive erosions and use catalog monotonicity theorems.
- **Strategy C: Minkowski-difference viewpoint**  
  Formalize the degree-2 simplex as a finite set and show second shadow is the finite-set Minkowski difference with that simplex.

This theorem satisfies the mandatory cross-domain condition: arithmetic circuit complexity + convex/discrete geometry.
