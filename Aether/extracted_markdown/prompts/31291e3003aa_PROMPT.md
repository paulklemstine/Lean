## New Definitions Required

Define at least one genuinely new concept. The strongest option is:

```lean
structure FiniteCharacterBasis (G : Type*) [Finite G] [CommGroup G] where
  ι : Type*
  fintype_ι : Fintype ι
  χ : ι → G → ℂ
  map_one : ∀ i, χ i 1 = 1
  map_mul : ∀ i x y, χ i (x * y) = χ i x * χ i y
  orthogonal :
    ∀ i j, ∑ g : G, χ i g * Complex.conj (χ j g) =
      if i = j then Fintype.card G else 0
  complete : Fintype.card ι = Fintype.card G
```

Then define the Fourier transform attached to such a basis:

```lean
def fourierTransform
  {G : Type*} [Fintype G] [CommGroup G]
  (B : FiniteCharacterBasis G) (f : G → ℂ) : B.ι → ℂ :=
fun i => ∑ g : G, f g * Complex.conj (B.χ i g)
```

Also define support size and spectral support:

```lean
def finSupportCard {α β : Type*} [Fintype α] [DecidableEq α] [Zero β]
  (f : α → β) : ℕ :=
Fintype.card {x : α // f x ≠ 0}

def spectralSupportCard
  {G : Type*} [Fintype G] [CommGroup G]
  (B : FiniteCharacterBasis G) (f : G → ℂ) : ℕ :=
finSupportCard (fourierTransform B f)
```

This abstraction is more powerful than merely hardcoding `ZMod n`, and it makes the uncertainty principle conceptually inevitable.

## Theorem 1: Parseval/Plancherel for finite character bases

### Precise theorem statement
For any finite abelian group with a complete orthogonal character basis, the Fourier transform preserves inner product up to the group cardinality normalization.

A clean Lean target:

```lean
theorem parseval_finiteCharacterBasis
  {G : Type*} [Fintype G] [CommGroup G] [DecidableEq G]
  (B : FiniteCharacterBasis G) (f h : G → ℂ) :
  ∑ i : B.ι, fourierTransform B f i * Complex.conj (fourierTransform B h i)
    = (Fintype.card G : ℂ) * ∑ g : G, f g * Complex.conj (h g)
```

and the norm-square corollary:

```lean
theorem plancherel_finiteCharacterBasis
  {G : Type*} [Fintype G] [CommGroup G] [DecidableEq G]
  (B : FiniteCharacterBasis G) (f : G → ℂ) :
  ∑ i : B.ι, Complex.normSq (fourierTransform B f i)
    = (Fintype.card G : ℝ) * ∑ g : G, Complex.normSq (f g)
```

### Why this is a breakthrough
This theorem upgrades Fourier analysis in Lean from explicit sums on `ZMod n` to a representation-theoretic principle. Once certified, every future formalization of finite spectral methods can reuse it without reproving matrix identities.

### Proof strategies
**Strategy A: direct double-sum orthogonality argument**
1. Expand both Fourier transforms.
2. Rearrange the finite sums using `Finset.sum_comm` / `Finset.sum_sigma'`.
3. Apply the orthogonality axiom of `FiniteCharacterBasis`.
This is likely the most robust Lean path.

**Strategy B: build the Fourier matrix and prove it is scaled unitary**
1. Define matrix entries `U i g = B.χ i g`.
2. Prove `U ⬝ Uᴴ = |G| I`.
3. Deduce Parseval from matrix algebra.
This is conceptually elegant and connects to quantum mechanics, but may require heavier matrix infrastructure.

**Strategy C: prove inner-product preservation abstractly from orthonormal basis expansion**
1. Normalize characters by `(|G|)^{-1/2}`.
2. Show they form an orthonormal basis of the function space `G → ℂ`.
3. Apply a finite-dimensional Hilbert-space identity.
Most beautiful mathematically, but only promising if Mathlib’s basis/inner-product APIs cooperate smoothly.

Most promising: **Strategy A**, because it keeps all dependencies explicit and controllable in Lean.

## Theorem 2: Convolution theorem on finite abelian groups

Define convolution:

```lean
def convolution
  {G : Type*} [Fintype G] [CommGroup G]
  (f h : G → ℂ) : G → ℂ :=
fun x => ∑ y : G, f y * h (y⁻¹ * x)
```

### Precise theorem statement

```lean
theorem fourier_convolution
  {G : Type*} [Fintype G] [CommGroup G] [DecidableEq G]
  (B : FiniteCharacterBasis G) (f h : G → ℂ) :
  fourierTransform B (convolution f h)
    = fun i => fourierTransform B f i * fourierTransform B h i
```

You should also prove the converse spectral multiplication theorem for pointwise products if feasible, with the appropriate normalization.

### Why this matters
This is the theorem that turns Fourier analysis into an algorithmic engine. It is the formal statement that convolutional structure becomes multiplicative in frequency space, which is the heart of:
- fast filtering,
- cyclic code analysis,
- spectral graph methods on Cayley graphs,
- finite quantum propagators,
- future certified FFT-based algorithms.

### Proof strategies
**Strategy A: direct change of variables**
1. Expand the transform of convolution.
2. swap sums,
3. use the multiplicativity of characters:
   `χ(y⁻¹ * x) = χ(y)⁻¹ * χ(x)` or equivalent conjugate identity,
4. factor the sum into a product.
This is the natural proof and should be the default.

**Strategy B: use the regular representation**
1. View convolution by `h` as an endomorphism of `ℂ[G]`.
2. Show characters diagonalize all convolution operators.
3. Read off the eigenvalues as Fourier coefficients.
This is more visionary and representation-theoretic; excellent for the paper even if the Lean proof follows Strategy A.

**Strategy C: matrix-circulant proof in the cyclic case, then transport**
1. Prove for `ZMod n` using circulant matrices,
2. generalize using the structure theorem for finite abelian groups.
This is attractive if cyclic machinery comes first, but less elegant than a direct group proof.

Most promising: **Strategy A** for formal proof, **Strategy B** for exposition in `RESEARCH_PAPER.md`.

## Theorem 3: Finite uncertainty principle

This is the central nontrivial theorem. Do not settle for a weak inequality unless forced by API limitations.

### Precise theorem statement
For a nonzero function on a finite abelian group, the product of the support size of the function and the support size of its Fourier transform is at least the group order.

```lean
theorem uncertainty_principle_finite_abelian
  {G : Type*} [Fintype G] [CommGroup G] [DecidableEq G]
  (B : FiniteCharacterBasis G) (f : G → ℂ)
  (hf : ∃ g : G, f g ≠ 0) :
  (Fintype.card {g : G // f g ≠ 0}) *
    (Fintype.card {i : B.ι // fourierTransform B f i ≠ 0})
      ≥ Fintype.card G
```

A more analytic equivalent is acceptable if support-cardinality lemmas become cumbersome, but the final theorem should explicitly mention support sizes.

### Why this is revolutionary
This theorem is the finite-group avatar of the uncertainty principle: a function cannot be simultaneously localized in physical space and frequency space. Once formalized, it becomes a certified backbone for:
- coding theory bounds,
- sparse recovery over finite groups,
- finite quantum state delocalization,
- additive combinatorics via large spectrum methods.

It is the first theorem in this project that genuinely crosses domains: harmonic analysis becomes an information-theoretic obstruction.

### Proof strategies
**Strategy A: Donoho–Stark style via `L∞` and `L1` bounds**
1. Show `|f̂(χ)| ≤ ∑_{x ∈ supp f} |f x|`.
2. Combine with Parseval/Cauchy–Schwarz to bound the number of nonzero Fourier coefficients below.
3. Derive `|supp f| * |supp f̂| ≥ |G|`.
This route is classical and likely the best Lean target.

**Strategy B: linear-algebraic rank argument**
1. Restrict the Fourier matrix to rows indexed by `supp f̂` and columns indexed by `supp f`.
2. Show a nonzero kernel vector would violate invertibility of an appropriate minor or basis completeness.
3. Conclude the support product bound from rank constraints.
This is powerful and conceptually linked to compressed sensing, but matrix minor formalization may be heavy.

**Strategy C: annihilator/subgroup extremizer approach**
1. First prove sharpness for subgroup indicators:
   `supp(1_H) = |H|`, `supp(̂1_H) = |G/H|`.
2. Then prove the general inequality by comparison to subgroup extremizers.
Beautiful, but likely harder formally unless a lot of subgroup-dual infrastructure already exists.

Most promising: **Strategy A**, because it leverages Parseval plus elementary inequalities and finite sums.
