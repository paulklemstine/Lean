## Core Theorem Target

The mathematically ambitious target is:

> For integers `g d r : ℕ`, a general tropical curve of genus `g` admits a divisor of degree `d` and rank at least `r` if and only if
> \[
> \rho(g,r,d) := g - (r+1)(g-d+r) \ge 0.
> \]

Because “general tropical curve” is not immediately Lean-native, you should formalize this through a **provable canonical generic model**, namely a chain of loops with generic edge lengths. This is both mathematically authentic and formalization-feasible.

### Precise theorem statement to aim for mathematically
Let `Γ_g(ℓ)` be a chain of `g` loops with edge-length data `ℓ` satisfying a genericity condition (e.g. no forbidden ratio relations as in the Cools–Draisma–Payne–Robeva model). Then:
\[
(\exists D,\ \deg D = d \land \operatorname{rank}(D)\ge r)
\iff
\rho(g,r,d)\ge 0.
\]

This is the tropical Brill–Noether theorem in a precise generic family.

## Lean 4 Formalization Targets

You likely need to define a finite combinatorial surrogate first, then extend to metric data.

### Stage 1: Brill–Noether number
```lean
def brillNoetherNumber (g r d : ℕ) : ℤ :=
  (g : ℤ) - ((r + 1 : ℕ) : ℤ) * (((g - d + r : ℕ)) : ℤ)
```

You may prefer a version avoiding truncated subtraction ambiguity:
```lean
def brillNoetherNumber' (g r d : ℕ) : ℤ :=
  (g : ℤ) - ((r + 1 : ℤ) * ((g : ℤ) - (d : ℤ) + (r : ℤ)))
```
This second version is usually the mathematically correct one.

Prove equivalence of the two in the natural range where `d ≤ g + r`.

### Stage 2: Finite graph / chain-of-loops model

Then a metric enhancement:

  topLen : Fin g → ℝ
  botLen : Fin g → ℝ
  hpos_top : ∀ i, 0 < topLen i

Genericity should be explicit:
```lean

  ∀ i j, i ≠ j → Γ.topLen i / Γ.botLen i ≠ Γ.topLen j / Γ.botLen j
```
This exact condition may not be the final right one, but you need a formal genericity predicate that rules out resonance and supports the lingering lattice-path argument.

### Stage 3: Divisors and rank
If Mathlib lacks full Baker–Norine graph divisors in the needed form, define a finite divisor as integer-valued vertex data first:
```lean
def Divisor (V : Type _) [Fintype V] := V → ℤ

def divisorDegree {V} [Fintype V] (D : Divisor V) : ℤ :=
  ∑ v, D v
```

Then define linear equivalence via chip-firing / Laplacian:
```lean
def IsLinearlyEquivalent {V} [Fintype V] (G : SimpleGraph V) (D E : Divisor V) : Prop :=
  ∃ f : V → ℤ, E = D + graphLaplacian G f
```

Define rank in the Baker–Norine style:
```lean
def divisorRank {V} [Fintype V] (G : SimpleGraph V) (D : Divisor V) : ℤ := 
  sSup {r : ℤ | r ≥ -1 ∧ ∀ E : Divisor V, effective E → divisorDegree E = r → ∃ D', IsLinearlyEquivalent G D D' ∧ effective (D' - E)}
```
You may want a nat-valued version with `Option ℕ` or `ℤ` to avoid awkwardness.

## Proof Strategy Paths

## Strategy A: Lingering lattice paths as the main engine
**Most promising.**

1. **Encode divisor classes on a generic chain of loops** by `v0`-reduced divisors or a finite normal form.
2. **Translate rank ≥ r** into existence of a lingering lattice path staying in the Weyl chamber
   \[
   x_0 > x_1 > \cdots > x_r > 0.
   \]
3. **Count existence of such paths** and prove it is equivalent to `ρ ≥ 0`.

Why this is best: the theorem is known in the literature in exactly this form, and the combinatorics is finite, explicit, and Lean-friendly. It avoids trying to formalize all of tropical moduli at once.

Concrete substeps:
- Define a path state as `Fin (r+1) → ℤ`.
- Define Weyl chamber admissibility.
- Define “lingering step” and “forward step”.
- Prove a path exists iff the endpoint constraints admit enough free steps, which simplifies to `ρ ≥ 0`.

## Strategy B: Rank-determining sets + Dhar burning algorithm
1. Develop divisor rank on finite graph models using chip-firing and reduced divisors.
2. Prove a chain-of-loops normal form theorem for reduced divisors.
3. Derive the Brill–Noether criterion by explicit rank computation loop-by-loop.

Why useful: this builds reusable infrastructure for future tropical Riemann–Roch and gonality formalizations. It is more foundational than Strategy A, but likely heavier.

Best use: combine with Strategy A by proving the realization theorem via reduced divisors while proving the numerology via lingering paths.

## Strategy C: Tropicalization/specialization-first route
1. State an abstract specialization inequality:
   \[
   r_X(D) \le r_\Gamma(\tau_*(D)).
   \]
2. Use classical Brill–Noether on algebraic curves plus existence of tropicalizations of general curves.
3. Infer the tropical existence direction from algebraic geometry; separately prove nonexistence for `ρ < 0` combinatorially.

Why this is visionary: it directly formalizes the bridge to classical geometry. Why it is risky: the AG infrastructure in Lean is probably not yet mature enough for a full proof. Use it as a parallel conceptual layer, not the first implementation target.
