## Core Vision

A finitely presented monoidal or symmetric monoidal category can be viewed as a syntax of tensor expressions modulo structural isomorphisms. Coherence says that all canonical structural morphisms between the same source and target are equal. Rewriting theory says that if a presentation is confluent and terminating, then equivalence classes admit unique normal forms and equality reduces to joinability. The revolutionary claim is:

> **Categorical coherence is exactly canonical normalization for structural syntax.**

If formalized cleanly, this opens a new field: **algorithmic coherence theory**, where coherence theorems are proved by critical-pair analysis, completion, and normal-form semantics rather than by ad hoc combinatorial arguments.

## Breakthrough Theorem Statements

You must aim to prove at least 3 substantial theorems. The following are the right scale and flavor.

### Theorem 1: Confluence implies structural coherence

This is the conceptual centerpiece.

**Mathematical statement.**  
Let `R` be the rewrite system on tensor expressions generated by oriented associativity and unit laws:
- `((A ⊗ B) ⊗ C) → (A ⊗ (B ⊗ C))`
- `(I ⊗ A) → A`
- `(A ⊗ I) → A`

Assume `R` is confluent. Then any two tensor expressions equivalent under the congruence generated by these laws are joinable, hence reduce to a common normal form. Therefore canonical structural maps are unique: the presentation is coherent.

**Lean-style target signature:**
```lean
theorem coherence_of_confluent
    {Obj : Type u}
    (R : TensorExpr Obj → TensorExpr Obj → Prop)
    (hconfluent : Confluent R)
    (hstruct : StructuralMonoidalRules R) :
    ∀ {a b : TensorExpr Obj}, EquivGen R a b → Joinable R a b
```

If the catalog theorem already gives an `equiv ↔ joinable` bridge under confluence, instantiate it here with your structural syntax and congruence.

**Why this is a breakthrough.**  
This turns coherence from a category-specific theorem into a reusable rewriting meta-theorem. It gives a computational criterion for coherence: prove confluence once, and all structural diagram equalities follow automatically.

### Theorem 2: Termination and uniqueness of right-associated unit-free normal forms

**Mathematical statement.**  
For the oriented associativity/unit rewrite system on tensor expressions, every expression reduces to a unique right-associated unit-free normal form. Equivalently, the rewrite system is terminating and confluent on pure tensor syntax, and the normal form is given by flattening to a list of variables.

**Lean-style target signature:**
```lean
def flatten {Obj : Type u} : TensorExpr Obj → List Obj
def rightAssoc : List Obj → TensorExpr Obj

theorem reduces_to_rightAssoc_flatten
    {Obj : Type u} :
    ∀ t : TensorExpr Obj, ReflTransGen monoidalStep t (rightAssoc (flatten t))

theorem flatten_invariant_of_equiv
    {Obj : Type u} :
    ∀ {a b : TensorExpr Obj}, EquivGen monoidalStep a b → flatten a = flatten b

theorem normal_form_unique
    {Obj : Type u} :
    ∀ {a b : TensorExpr Obj},
      NormalForm monoidalStep a →
      NormalForm monoidalStep b →
      EquivGen monoidalStep a b →
      a = b
```

You may need to adjust `NormalForm`, `EquivGen`, and `ReflTransGen` names to Mathlib conventions.

**Why this is a breakthrough.**  
This gives an explicit computational semantics of coherence: tensor expressions are not merely equivalent abstractly; they normalize to canonical combinatorial data. This is the algorithmic heart of coherence.

### Theorem 3: Critical-pair joinability yields coherence for the structural subsystem

**Mathematical statement.**  
For the monoidal structural rewrite system, if every critical pair is joinable and the rewrite relation is terminating, then the system is confluent; hence the associated structural theory is coherent.

This is the rewriting-theoretic engine that makes coherence algorithmic.

**Lean-style target signature:**
```lean
theorem coherence_of_critical_pairs
    {Obj : Type u}
    (hterm : WellFounded (fun a b : TensorExpr Obj => monoidalStep b a))
    (hcrit : AllCriticalPairsJoinable monoidalStep) :
    ∀ {a b : TensorExpr Obj}, EquivGen monoidalStep a b → Joinable monoidalStep a b
```

If a full Newman lemma or critical-pair theorem is not already in the catalog, prove a specialized version for your structural rewrite system. That specialization is still mathematically valuable and far from trivial.

**Why this is a breakthrough.**  
This is the first real “completion-theoretic coherence theorem” in the project. It says coherence can be *checked* by local overlap analysis plus termination, exactly as in Knuth–Bendix style reasoning.

## Proof Architecture: 3 Strategy Paths

You must include 2–3 proof strategies in your work and explain which one is most promising.

### Strategy A: Direct normalization by flattening tensor trees
1. Define `flatten : TensorExpr Obj → List Obj` erasing units and reading leaves left-to-right.
2. Define `rightAssoc : List Obj → TensorExpr Obj` rebuilding a canonical right-associated tree.
3. Prove by induction on expressions that every term reduces to `rightAssoc (flatten t)`.
4. Prove `flatten` is invariant under structural equivalence.
5. Deduce uniqueness of normal forms and coherence.

**Why it works:**  
This is the most concrete route. It avoids needing the full generality of higher-order completion for the first major theorem. It should produce robust Lean proofs using induction and calc chains.

**Most promising for initial success.**

---

### Strategy B: Instantiate catalog theorem `equiv_iff_joinable_of_confluent`
1. Define the structural rewrite relation as an instance of the higher-order or first-order rewriting framework used in `Pythagorean/HigherOrderCompletion.lean`.
2. Prove the hypotheses required by `equiv_iff_joinable_of_confluent`.
3. Apply the catalog theorem to obtain `EquivGen R a b ↔ Joinable R a b`.
4. Interpret this equivalence categorically as coherence.

**Why it works:**  
This gives the strongest conceptual payoff: coherence emerges as a direct corollary of a general rewriting theorem.

**Most promising for the headline theorem.**

---

### Strategy C: Local confluence via critical pairs + Newman’s lemma
1. Enumerate overlaps among associativity and unit rules.
2. Prove each critical pair is joinable by explicit multi-step reductions.
3. Prove termination using a well-founded measure, e.g. number of left-nested tensors plus unit occurrences.
4. Apply Newman’s lemma to obtain confluence.
5. Conclude coherence via Strategy B.

**Why it works:**  
This is the true algorithmic coherence pathway. It mirrors how a completion engine would certify coherence in practice.

**Most visionary overall**, even if technically more involved.

## Conjecture with Testable Prediction

You must state at least one falsifiable conjecture and give a computational test.

### Conjecture: Completion-based coherence for finitely presented structural theories
For any finitely presented structural category whose rewrite system is:
1. left-linear,
2. terminating,
3. all critical pairs joinable,

the category is coherent in the sense that any two parallel structural morphisms are equal.

**Testable prediction:**  
Implement a procedure that:
- generates critical pairs for the given structural rules,
- attempts bounded normalization of both branches,
- searches for a common reduct.

A counterexample would be a finitely presented structural theory with all bounded tests passing on small terms but an explicit non-joinable critical pair or non-unique normal form appearing at larger size.

A stronger symmetric conjecture:

### Conjecture: Symmetric coherence = permutation completeness
For the symmetric monoidal structural subsystem, two tensor expressions are structurally equivalent iff their flattened leaf lists are permutation-equivalent.

**Computational test:**  
Enumerate tensor expressions up to size `n`, compute:
- structural equivalence by bounded rewriting,
- `List.Perm` of flattened leaves,

and search for a discrepancy. One counterexample disproves the conjecture.
