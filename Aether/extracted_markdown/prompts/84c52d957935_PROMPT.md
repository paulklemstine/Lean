## Core theorem targets

You should not attempt the full conjecture at once. Instead, prove a chain of strong theorems that together establish a genuine arithmetic Morse-stability principle in tractable but nontrivial regimes.

### New formal objects to define
You must introduce at least one genuinely new concept. I recommend the following trio.

1. **Critical fiber over a ring**
   For a polynomial map `L : MvPolynomial (Fin n) R`, define the critical fiber at value `t`:
   \[
   \operatorname{CritFiber}(L,t;R)
   := \{\theta \in R^n : \forall j,\ \partial_j L(\theta)=0 \ \wedge\  L(\theta)=t\}.
   \]

2. **Prime-modular critical profile**
   For `R = ZMod p`, define a profile statistic
   \[
   \operatorname{critProfile}_p(L,t) := \#\operatorname{CritFiber}(L,t;\mathbb F_p),
   \]
   and for the total profile
   \[
   \operatorname{critProfileTotal}_p(L) := \sum_t \operatorname{critProfile}_p(L,t)^2
   \]
   or another robust aggregate that is easier to formalize than étale Betti data, but still genuinely geometric.

3. **Morse index histogram surrogate**
   Since full smooth Morse index over `ℝ` is hard to formalize in one cycle, define first a discrete surrogate for diagonal quadratic forms:
   \[
   \operatorname{diagMorseHistogram}(Q)(k)
   := \#\{ \text{critical points of index } k\}
   \]
   for losses that decompose as sums of one-variable quadratic or separable polynomial terms. This is enough to prove a first arithmetic-real correspondence theorem with teeth.

These definitions are mathematically meaningful, formalizable, and can support a verified algorithm.

## Precise theorem statements

### Theorem 1: Product decomposition of critical fibers for separable losses
Let
\[
L(\theta_1,\dots,\theta_n)=\sum_{i=1}^n f_i(\theta_i),
\]
with each `f_i : ℤ[X]`. Then the critical fiber decomposes as a dependent product over one-variable critical fibers.

**Mathematical statement**
For any commutative semiring/field `R` and target value `t`, if `L = ∑ i, renameᵢ(f_i)`, then
\[
\theta \in \operatorname{CritFiber}(L,t;R)
\]
is equivalent to the existence of values `t_i` summing to `t` such that each coordinate lies in the one-variable critical fiber of `f_i` at `t_i`.

This is the structural theorem that turns a high-dimensional critical-locus problem into additive convolution.

**Lean 4 type signature sketch**
```lean
def IsSeparableLoss
    {n : ℕ} (L : MvPolynomial (Fin n) ℤ) : Prop := ...

def critFiber
    {n : ℕ} (R : Type*) [CommSemiring R]
    (L : MvPolynomial (Fin n) ℤ) (t : R) : Set (Fin n → R) :=
  {θ | (∀ i, eval θ ((mvPolynomialPartial i) L) = 0) ∧ eval θ (map (Int.castRingHom R) L) = t}

theorem critFiber_separable_equiv_sigma
    {n : ℕ} {R : Type*} [Field R]
    (f : Fin n → Polynomial ℤ) (t : R) :
    let L := separableLoss f
    critFiber R L t =
      {θ | ∃ τ : Fin n → R,
          (∑ i, τ i = t) ∧
          ∀ i, θ i ∈ critFiber1D R (f i) (τ i)} := ...
```

**Why this matters**
This theorem is the engine for everything else. It converts critical-point geometry into additive combinatorics over value partitions. It is already nontrivial, and it creates a formal infrastructure for later arithmetic asymptotics.

### Theorem 2: Prime-stability of nondegenerate one-variable critical points
Let `f ∈ ℤ[X]`. Suppose `a ∈ ℤ` is a simple critical point over `ℚ`, meaning `f'(a)=0` and `f''(a) ≠ 0`. Then for all but finitely many primes `p`, the reduction of `a` modulo `p` remains a nondegenerate critical point of `f mod p`.

**Mathematical statement**
If `a : ℤ` satisfies
\[
f'(a)=0,\qquad f''(a)\neq 0,
\]
then there exists a finite set `S` of primes such that for every prime `p ∉ S`,
\[
(f \bmod p)'(\bar a)=0,\qquad (f \bmod p)''(\bar a)\neq 0.
\]

This is the first rigorous “outside finitely many primes” stability result. It is elementary enough to formalize but conceptually central: **nondegenerate criticality is arithmetic-stable**.

**Lean 4 type signature sketch**
```lean
theorem eventually_prime_nondegenerate_crit_of_integer_point
    (f : Polynomial ℤ) (a : ℤ)
    (hcrit : Polynomial.eval a (Polynomial.derivative f) = 0)
    (hnondeg : Polynomial.eval a (Polynomial.derivative (Polynomial.derivative f)) ≠ 0) :
    ∃ S : Finset ℕ,
      ∀ p : ℕ, Nat.Prime p → p ∉ S →
        Polynomial.eval (a : ZMod p) (Polynomial.map (Int.castRingHom (ZMod p)) (Polynomial.derivative f)) = 0
        ∧
        Polynomial.eval (a : ZMod p)
          (Polynomial.map (Int.castRingHom (ZMod p))
            (Polynomial.derivative (Polynomial.derivative f))) ≠ 0 := ...
```

**Why this is a breakthrough seed**
This theorem is the arithmetic analogue of structural stability. It says that local critical-point type survives almost all prime reductions. It is the first brick in the prime-to-real dictionary.

### Theorem 3: Arithmetic-real count correspondence for separable Morse losses
Assume
\[
L(\theta)=\sum_{i=1}^n f_i(\theta_i),
\]
where each `f_i ∈ ℤ[X]` has only simple critical points in `ℝ`, and all critical points are integral (or rational with a common denominator handled explicitly). Then outside finitely many primes, the number of nondegenerate critical points modulo `p` equals the real critical-point count, and the critical values are preserved modulo `p` away from collisions.

**Mathematical statement**
There exists a finite exceptional set `S` of primes such that for all primes `p ∉ S`:
1. every real/integral nondegenerate coordinatewise critical point reduces to a unique nondegenerate mod-`p` critical point;
2. distinct critical points remain distinct modulo `p`;
3. if critical values are pairwise distinct over `ℤ`, then the multiset of critical-fiber cardinalities over `𝔽_p` matches the real critical-value multiplicity profile.

In the generic separable Morse case this yields:
\[
\#\operatorname{Crit}(L;\mathbb F_p)=\#\operatorname{Crit}(L;\mathbb R),
\]
for all sufficiently large good primes.

**Lean 4 type signature sketch**
```lean
theorem eventually_prime_crit_count_eq_real_count_separable
    {n : ℕ}
    (f : Fin n → Polynomial ℤ)
    (hSimple : ∀ i, simpleCriticals (f i))
    (hIntegral : ∀ i, integralCriticalSet (f i))
    (hDistinct : pairwiseDistinctSeparableCriticalValues f) :
    ∃ S : Finset ℕ,
      ∀ p : ℕ, Nat.Prime p → p ∉ S →
        critPointCountZMod (separableLoss f) p
          = critPointCountRealModel f := ...
```

**Why this matters**
This is the first actual theorem approximating the grand conjecture. It proves that arithmetic critical profiles can recover real critical complexity in a broad, structured family of neural-like polynomial losses. This is not a toy result: separable polynomial losses already model decoupled feature channels, diagonalized Hessian regimes, and local normal forms near many minima/saddles.

### Theorem 4: Morse-index/profile correspondence for diagonal quadratic losses
For diagonal quadratic losses
\[
Q(\theta)=\sum_{i=1}^n \varepsilon_i \theta_i^2 + c_i\theta_i + d
\quad \text{with } \varepsilon_i\in\{\pm 1\},
\]
prove that the real Morse index is exactly the number of negative diagonal coefficients, while the mod-`p` nondegenerate critical count is `1` for every odd prime avoiding denominators, and define an arithmetic signature statistic recovering the index from a Legendre-symbol-weighted Hessian determinant.

A suitable arithmetic statistic:
\[
\operatorname{quadSignature}_p(Q)
:= \sum_{\theta \in \operatorname{Crit}(Q;\mathbb F_p)}
\chi_p(\det \operatorname{Hess}(Q)),
\]
where `χ_p` is the quadratic character. For a unique critical point this becomes
\[
\chi_p\!\left(\prod_i 2\varepsilon_i\right).
\]

Then prove a parity-level dictionary:
\[
\operatorname{quadSignature}_p(Q)
= \chi_p(2)^n \chi_p((-1)^{\operatorname{index}(Q)}),
\]
so for primes in residue classes where `χ_p(2)` is controlled, the arithmetic statistic detects the parity of the real Morse index.

**Lean 4 type signature sketch**
```lean
def diagonalQuadraticLoss {n : ℕ} (ε : Fin n → ℤ) (c : Fin n → ℤ) (d : ℤ) :
    MvPolynomial (Fin n) ℤ := ...

def realMorseIndexDiag {n : ℕ} (ε : Fin n → ℤ) : ℕ :=
  Fintype.card {i : Fin n // ε i < 0}

def quadSignatureModP {n : ℕ} (ε c : Fin n → ℤ) (d : ℤ) (p : ℕ) : ZMod p := ...

theorem diagonal_quadratic_index_formula
    {n : ℕ} (ε : Fin n → ℤ) (c : Fin n → ℤ) (d : ℤ)
    (hpm : ∀ i, ε i = 1 ∨ ε i = -1) :
    realMorseIndexDiag ε =
      Fintype.card {i : Fin n // ε i = -1} := ...

theorem quadSignature_detects_index_parity
    {n : ℕ} (ε : Fin n → ℤ) (c : Fin n → ℤ) (d : ℤ)
    (hp : Nat.Prime p) (hodd : p ≠ 2)
    (hpm : ∀ i, ε i = 1 ∨ ε i = -1) :
    quadSignatureModP ε c d p =
      quadraticChar (ZMod p) (2^n * (-1)^(realMorseIndexDiag ε)) := ...
```

**Why this matters**
This is the sharpest cross-domain theorem in the project: **real Morse index parity becomes visible through arithmetic character sums**. That is exactly the kind of “I never thought of that connection” result this cycle should produce.

## Most promising proof strategies

### Strategy A: Structural decomposition first, arithmetic second
**Best overall route.**

1. **Formalize separable losses** as sums of renamed univariate polynomials inside `MvPolynomial`.
2. Prove derivative and evaluation factorization lemmas coordinatewise.
3. Deduce critical-fiber decomposition and cardinality/product formulas.
4. For one-variable integral critical points, prove finite-exceptional-prime stability by explicitly excluding primes dividing finitely many discriminant-like integers: denominators, second derivatives at critical points, and pairwise differences of critical values/points.
5. Lift the one-variable result to separable `n`-variable losses by product arguments and `Finset` combinatorics.

**Why this is most promising**
It keeps you inside well-supported Mathlib terrain: `Polynomial`, `MvPolynomial`, derivatives, finite sets, `ZMod`, evaluation maps, and explicit arithmetic finiteness. It avoids deep étale cohomology while still delivering a theorem that clearly points toward the full conjecture.

---

### Strategy B: Hessian-signature arithmetic via diagonal normal forms
1. Start from diagonal quadratic losses, where the critical point is explicit.
2. Compute the Hessian determinant exactly.
3. Connect the real Morse index to the sign pattern of coefficients.
4. Define a mod-`p` quadratic-character signature and prove its formula.
5. Show how residue classes of primes encode parity information of the index.

**Why this is powerful**
This yields the strongest conceptual bridge: **Morse-theoretic information visible in finite-field character data**. It is a compelling theorem even if the full profile-determination conjecture remains open.

---

### Strategy C: Counting-profile invariants via generating functions
1. For each one-variable factor `f_i`, define the finite-field critical value count function
   \[
   a_{i,p}(t)=\#\{x : f_i'(x)=0,\ f_i(x)=t\}.
   \]
2. Show the separable loss profile is the additive convolution
   \[
   A_p = a_{1,p} * \cdots * a_{n,p}.
   \]
3. Prove profile moments such as `∑_t A_p(t)^2` factor through Fourier transforms/additive characters over `𝔽_p`.
4. Use these moments as stable arithmetic fingerprints.

**Why it matters**
This route suggests a future bridge to harmonic analysis, coding theory, and statistical mechanics of landscapes. It may be harder to complete fully in Lean this cycle, but even one formal theorem here would be field-opening.

## Required falsifiable conjecture

State this clearly in both the Lean comments and `FUTURE_DIRECTIONS.md`:

### Conjecture: asymptotic modular determination of Morse histograms
For generic separable polynomial losses with integer coefficients and simple integral critical points, there exists a finite exceptional set of primes `S` such that the family of finite-field critical-value profiles
\[
\left\{\operatorname{critProfile}_p(L,\cdot)\right\}_{p\notin S}
\]
determines the real Morse index histogram up to finitely many ambiguities.

### Clear computational refutation test
Search over two distinct separable losses `L₁, L₂` of bounded degree and coefficient size. Compute:
- exact real critical points and Morse indices,
- mod-`p` critical profiles for many increasing good primes.

The conjecture is **refuted** if:
1. `L₁` and `L₂` have different real Morse histograms, but
2. their mod-`p` critical profiles agree for all tested good primes beyond some threshold.

This is sharp, falsifiable, and algorithmically testable.
