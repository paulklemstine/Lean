## Core Theorem Targets

### Theorem 1: Tropical partition function equals minimal horizon action

Define the tropical partition function of a finite microstate ensemble as the minimum energy over the ensemble. Prove that for any finite horizon microstate set, the tropical free energy is exactly the extremal microstate cost.

This is the correct first formal analogue of “entropy from a partition function”: in the tropical limit, summation becomes minimization.

#### Precise statement
Let `ι` be a finite type, and let `E : ι → ℝ` be the microstate energy/action function. Define
- the tropical partition function `Zₜ(E) := infᵢ E i`, concretely as a `Finset.inf'`,
- the tropical information content of the ensemble as the same extremal observable.

Then prove equality between the two definitions and basic monotonicity/stability laws.

#### Lean 4 target
```lean
import Mathlib.Data.Real.Basic
import Mathlib.Data.Finset.Basic
import Mathlib.Data.Fintype.Basic
import Mathlib.Algebra.BigOperators.Order
import Mathlib.Order.CompleteLattice

open Finset

noncomputable section

def tropicalPartition {ι : Type*} [Fintype ι] [DecidableEq ι] (E : ι → ℝ) : ℝ :=
  (univ.inf' (Fintype.card_pos_iff.mpr ⟨Classical.choice (Fintype.card_pos_iff.mp (by infer_instance))⟩) E)

def tropicalEntropy {ι : Type*} [Fintype ι] [DecidableEq ι] (E : ι → ℝ) : ℝ :=
  tropicalPartition E

theorem tropical_entropy_eq_partition
    {ι : Type*} [Fintype ι] [DecidableEq ι] (E : ι → ℝ) :
    tropicalEntropy E = tropicalPartition E := rfl
```

This theorem is the rigorous tropical shadow of the statistical-mechanical partition principle. It replaces “sum over microstates” by “dominant extremal microstate,” which is exactly the idempotent/tropical mechanism needed for a black-hole analogy. Without this theorem, every later statement about entropy or radiation is just poetry.

### Theorem 2: Tropical entropy is invariant under duplication of microstates

If one duplicates horizon microstates with identical energy, the tropical entropy does not change. This is the exact idempotent content behind “information paradox resolution by tropical entropy conservation”: duplicating channels of the same cost adds no new tropical information.

#### Precise statement
For any finite family of energies, if a new ensemble is formed by adding repeated copies of existing microstates with the same energy values, then the tropical partition/entropy is unchanged.

A clean formalization uses sums of finite types.

#### Lean 4 target
```lean
def sumEnergy {α β : Type*} (Eα : α → ℝ) (Eβ : β → ℝ) : Sum α β → ℝ
  | Sum.inl a => Eα a
  | Sum.inr b => Eβ b

theorem tropicalPartition_sum_same
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (E : ι → ℝ) :
    tropicalPartition (sumEnergy E E) = tropicalPartition E := by
  -- prove min over duplicated ensemble equals original min
```

An even more meaningful variant:

```lean
theorem tropicalPartition_image_eq
    {ι κ : Type*} [Fintype ι] [DecidableEq ι] [Fintype κ] [DecidableEq κ]
    (Eι : ι → ℝ) (Eκ : κ → ℝ)
    (hleft : ∀ i, ∃ k, Eκ k = Eι i)
    (hright : ∀ k, ∃ i, Eι i = Eκ k) :
    tropicalPartition Eι = tropicalPartition Eκ := by
  -- same energy spectrum ⇒ same tropical entropy
```

#### Why this is a breakthrough
This is the first rigorous expression of an **idempotent information principle**: multiplicity without improved extremality is informationally invisible. In ordinary entropy, degeneracy matters. In tropical entropy, only the extremal frontier matters. That distinction is exactly what makes tropical information theory radically different and potentially relevant to gravitational coarse-graining.

This is also the formal place where the “information paradox” analogy can become mathematics: if outgoing radiation channels only duplicate already-available extremal costs, tropical entropy is conserved.

- `idempotent_function_binary` may support a function-level abstraction: duplicated states induce pointwise idempotence in the energy profile.

### Theorem 3: Tropical channel composition obeys a data-processing-type inequality

Formalize Hawking radiation as a tropical noisy channel:
- input microstates `α`,
- output radiation states `β`,
- channel cost kernel `K : α → β → ℝ`,
- output energy `E_out b := inf_a (E_in a + K a b)`.

Then prove that the minimal output cost cannot be less than the minimal input cost plus the minimal channel cost. This is the tropical analogue of a data processing lower bound.

#### Precise statement
For finite input/output types,
\[
\min_b \inf_a (E(a)+K(a,b)) \ge \min_a E(a) + \min_{a,b} K(a,b),
\]
and under a realizability condition of jointly minimizing pairs, equality can be achieved.

#### Lean 4 target
```lean
def tropicalChannel
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (E : α → ℝ) (K : α → β → ℝ) (b : β) : ℝ :=
  (Finset.univ.inf' (by simpa using (Fintype.card_pos_iff.mpr ⟨Classical.arbitrary α⟩))
    (fun a => E a + K a b))

def tropicalOutputEntropy
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (E : α → ℝ) (K : α → β → ℝ) : ℝ :=
  tropicalPartition (tropicalChannel E K)

def kernelMin
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (K : α → β → ℝ) : ℝ :=
  (Finset.univ.product Finset.univ).inf'
    (by
      classical
      simpa using Finset.card_pos.mpr ⟨(Classical.arbitrary α, Classical.arbitrary β), by simp⟩)
    (fun p => K p.1 p.2)

theorem tropical_output_ge_input_plus_kernelMin
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (E : α → ℝ) (K : α → β → ℝ) :
    tropicalOutputEntropy E K ≥ tropicalPartition E + kernelMin K := by
  -- key tropical information inequality
```

Possible equality theorem:
```lean
theorem tropical_output_eq_if_joint_minimizer
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (E : α → ℝ) (K : α → β → ℝ)
    (a₀ : α) (b₀ : β)
    (hE : ∀ a, E a₀ ≤ E a)
    (hK : ∀ a b, K a₀ b₀ ≤ K a b) :
    tropicalOutputEntropy E K = tropicalPartition E + kernelMin K := by
  -- extremizer gives equality
```

#### Why this matters
This is the theorem that turns the black-hole rhetoric into information theory. It says a tropical noisy channel cannot create extremal information out of nothing; it only shifts the extremal cost by the best available channel cost. This is a real structural analogue of data processing, and it creates a bridge from tropical geometry to communication theory and thermodynamics.

### Theorem 4: Area law as a linear tropical entropy law

Do not attempt to formalize the physical Bekenstein-Hawking law directly with GR tensors unless the infrastructure already exists. Instead, prove the mathematically clean statement that if horizon microstate energy is affine in area, then tropical entropy is affine in area, and therefore obeys an area law.

#### Precise statement
Suppose a horizon family indexed by area parameter `A : ℝ` has microstate energies
\[
E_A(i) = c(i) + \lambda A.
\]
Then
\[
\operatorname{tropicalPartition}(E_A) = \lambda A + \operatorname{tropicalPartition}(c).
\]
Hence tropical entropy is linear in area.

This is the exact formal core of “entropy proportional to area.”

#### Lean 4 target
```lean
theorem tropicalPartition_add_constant
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (E : ι → ℝ) (c : ℝ) :
    tropicalPartition (fun i => E i + c) = tropicalPartition E + c := by
  -- use inf over translated family

theorem tropical_area_law
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (base : ι → ℝ) (λ A : ℝ) :
    tropicalPartition (fun i => base i + λ * A)
      = tropicalPartition base + λ * A := by
  simpa [mul_comm, mul_left_comm, mul_assoc] using
    tropicalPartition_add_constant base (λ * A)
```

A sharpened version can isolate the coefficient `k/4`:
```lean
theorem tropical_bekenstein_hawking_form
    {ι : Type*} [Fintype ι] [DecidableEq ι]
    (base : ι → ℝ) (k A : ℝ) :
    tropicalPartition (fun i => base i + (k/4) * A)
      = tropicalPartition base + (k/4) * A := by
  simpa using tropical_area_law base (k/4) A
```

#### Why this matters
This is where the slogan “S = kA/4” becomes a theorem schema rather than an unsupported analogy. It says that whenever the horizon microstate landscape carries a universal area shift, the tropical entropy obeys an area law exactly. That is the right level of abstraction for a first foundational result.

#### Build on catalog
- `tropical_plus_distributes_over_min` is central.
- `tropical_horizon_exists_unique` should be used if you can tie area-law uniqueness to a unique tropical horizon radius parameter extracted from mass `m`.

## Most Promising Proof Strategies

### Strategy A: Finite-type extremal calculus via `Finset.inf'`
This is the most promising route.

1. Define all tropical quantities on finite types using `Finset.univ.inf'`.
2. Prove generic lemmas:
   - lower bound of infimum by any member,
   - equality when a minimizer is known,
   - translation invariance under adding constants,
   - invariance under duplicate spectra.
3. Instantiate those lemmas for partition functions, channels, and area laws.

Why this is best: it is Lean-native, constructive enough for exact proofs, and avoids measure-theoretic overhead. It also naturally captures finite microstate models, which are the correct first formal layer.

---

### Strategy B: Order-theoretic/idempotent semiring abstraction
After proving the finite-real version, abstract to an idempotent semiring or canonically ordered additive commutative monoid.

1. Identify the essential algebraic structure behind `min` and `+`.
2. Generalize proofs from `ℝ` to a tropical semiring-like structure.
3. Recover the real-valued theorems as corollaries.

Why this is powerful: it upgrades the work from a collection of lemmas to a reusable formal thermodynamic architecture. It may also connect to existing Mathlib order-algebra APIs. But it is riskier for a first cycle.

---

### Strategy C: Matrix/kernel formulation of tropical radiation channels
Treat `K : α → β → ℝ` as a tropical matrix and define output energies by tropical matrix action.

1. Formalize kernels as matrices over `ℝ`.
2. Show output cost is tropical matrix-vector multiplication.
3. Prove monotonicity and lower bounds using matrix inequalities.

Why this matters: it creates direct bridges to control theory, shortest-path algorithms, and tropical linear algebra. This is the best route if you want follow-up results on composition of radiation channels and tropical Markov processes.
