## Algebra–EML Ruelle Transfer Semantics via Closure Correspondence Operators and Artin–Mazur Rationality

### Core construction target

Work in a fully finite setting first, with explicit matrix semantics, then lift to closure-stable observable submodules. The decisive move is to formalize a **closure correspondence operator** as a finite combinatorial transfer operator whose powers count weighted periodic data, and then prove its zeta series is rational by a matrix determinant identity.

You should build a coherent Lean development around the following finite-dimensional bridge:

- **dynamics/domain side**: a finite state type `α` with an endomap `f : α → α`
- **algebra/observable side**: finitely supported observables or a finite free module indexed by a basis `β`
- **transfer side**: a matrix `L : Matrix β β ℚ` or `Matrix β β ℤ`
- **zeta side**: periodic point counts and trace-power coefficients
- **impact side**: interpret `L` as a discrete Ruelle operator, with theorem names/docstrings explicitly mentioning `quantum`, `entropy`, `lattice_crypto`, `certified_robustness`, `hamiltonian`

The file should not just prove one theorem: it should create a reusable semantics package with at least 10 definitions/structures and 20+ theorems.

## Definitions and structures to introduce

Introduce at least the following definitions with exact or near-exact Lean signatures.

```lean
/-- A finite closure-stable observable basis for a dynamical system. -/
structure ClosureObservableBasis (α β : Type*) [Fintype α] [Fintype β] where
  basisFun : β → α → ℚ
  separates : ∀ x y : α, x ≠ y → ∃ b : β, basisFun b x ≠ basisFun b y
  closureStable :
    ∀ b : β, ∃ coeff : β → ℚ, ∀ x : α,
      basisFun b (f x) = ∑ j, coeff j * basisFun j x
```

### 5. Linear recurrence / Cayley-Hamilton package

Do not stop at rationality folklore. Prove an explicit recurrence for traces of powers.

```lean
theorem trace_power_linear_recurrence_quantum_entropy
  {β : Type*} [Fintype β] [DecidableEq β]
  (L : Matrix β β ℚ) :
  ∃ c : Fin (Fintype.card β + 1) → ℚ,
    c 0 = 1 ∧
    ∀ n : ℕ,
      matrixTracePow L (n + Fintype.card β) =
        - ∑ i : Fin (Fintype.card β), (c i.succ) * matrixTracePow L (n + i)
```

If a direct theorem in this exact form is awkward, prove a slightly weaker but explicit recurrence using the characteristic polynomial coefficients from Mathlib. The important point is:
- the sequence `n ↦ trace (L^n)` satisfies a recurrence of order at most `card β`
- coefficients come from `charpoly L`

Also prove a concrete growth bound:


This explicit bound is essential for utility and gives a certified complexity/robustness flavor.

## Proof architecture: 4 viable routes

### Strategy A: direct finite matrix combinatorics
Most promising for a complete zero-sorry file.

1. Define `correspondenceMatrix` and prove matrix powers enumerate weighted paths.
2. Specialize to deterministic kernels and show each `(x,y)` entry of `M^n` is an indicator for `f^[n] y = x`.
3. Take traces to convert diagonal indicators into periodic point counts.
4. Use finite-dimensional matrix theory / characteristic polynomial to derive a recurrence for `trace (M^n)`.
5. Transfer recurrence to `artinMazurCoeff`.

Key lemmas likely useful:
- `Matrix.mul_apply`
- `Matrix.trace_mul_cycle` or trace cyclicity lemmas if available
- `Matrix.charpoly`
- Cayley-Hamilton theorem in Mathlib
- `Fintype.card`
- `Finset.univ`, `Finset.sum_ite_eq`, `Finset.filter`
- `Function.iterate_succ_apply`

### Strategy B: observable basis first, then deterministic specialization
Best if the catalog already has semimodule/observable infrastructure.

1. Define `pullbackMatrix` from closure-stability coordinates.
2. Prove by induction that powers of the pullback matrix encode iterated pullback on basis observables.
3. If there is already a trace/Lefschetz theorem in the catalog, instantiate it in the finite basis case.
4. Compare the resulting trace sequence to periodic counts and conclude recurrence/rationality.

This route is strongest conceptually because it turns symbolic-dynamics rationality into a theorem about EML semantics, not merely finite adjacency matrices.

### Strategy C: weighted correspondence and determinant identity
Best for originality.

1. Work with `ClosureCorrespondence α`, not just deterministic maps.
2. Show `trace (K^n)` equals weighted loop sums.
3. Derive linear recurrence for weighted loop sums from characteristic polynomial.
4. Deduce rationality for all finite weighted transfer semantics; deterministic Artin–Mazur is a corollary.

This opens the door to thermodynamic/quantum interpretations: weights become energies, amplitudes, or cryptographic transition penalties.

### Strategy D: formal power series after recurrence
Use only after recurrence is done.

1. Define a coefficient sequence from traces.
2. Show any sequence satisfying a finite linear recurrence has a rational generating function.
3. Instantiate with trace powers / periodic coefficients.
4. If needed, derive a logarithmic derivative identity formally.

This route is algebraically elegant, but do not let formal power series machinery block the main theorem.

## Concrete proof steps for the hardest lemmas

### A. `deterministic_matrix_entry_pow`
Use induction on `n`.

- Base case `n = 0`: `M^0 = 1`; entries are `if x = y then 1 else 0`; rewrite with `f^[0]`.
- Step `n+1`:
  ```lean
  simp [Matrix.pow_succ, Matrix.mul_apply, Finset.sum_ite_irrel]
  ```
- Expand the deterministic kernel:
  only the term `z = f^[n] y` or `x = f z` survives.
- Convert existential uniqueness into an `if` statement.
- Finish with:
  ```lean
  by_cases h : f^[n.succ] y = x
  · simp [h]
  · simp [h]
  ```

### B. `pullbackMatrix_iterate_spec`
- Induct on `n`.
- Base case uses `Matrix.one_apply` and basis expansion against Kronecker delta.
- Step:
  - rewrite `f^[n+1] x = f^[n] (f x)` or `f (f^[n] x)` consistently
  - apply `pullbackMatrix_spec`
  - use induction hypothesis
  - swap sums with `Finset.sum_comm`
  - recognize matrix multiplication entry formula

### C. recurrence from Cayley-Hamilton
- Let `p := Matrix.charpoly L`.
- Use `aeval_self_charpoly`/Cayley-Hamilton theorem in the matrix algebra.
- Multiply the matrix identity by `L^n`.
- Take traces.
- Use linearity of trace to get a recurrence.
- Normalize coefficients to isolate the top-order term.
- If indexing is painful, formulate recurrence with `natDegree p` instead of `card β`.

### D. recurrence for divided coefficients `trace/(n+1)`
This is slightly subtler than recurrence for traces.
Two safe options:
1. first prove recurrence for `n ↦ trace(L^(n+1))`; then define zeta data using this sequence instead of dividing by `n+1`;
2. or prove a recurrence for numerator sequence only, and state rationality for the corresponding exponential/log-derivative surrogate.

If division by `n+1` creates avoidable complications, keep the main theorem on the trace sequence and package Artin–Mazur coefficients as a corollary with explicit denominator handling over `ℚ`.
