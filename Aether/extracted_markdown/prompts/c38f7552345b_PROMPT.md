## Primary Theorem Cluster

### Theorem 1: Scalar tropical residuation for translation

Precise mathematical statement:

For all `a c y : ℝ`,
\[
a + y \le c \iff y \le c - a.
\]

This is the atomic residuation law for tropical multiplication as ordinary addition.

Suggested Lean 4 signature:
```lean
theorem tropical_translation_residuation (a y c : ℝ) :
    a + y ≤ c ↔ y ≤ c - a
```

This is simple, but it is the foundational adjunction lemma on which everything else should depend.

### Theorem 2: Finite tropical aggregation as a residuated map

For a finite family of offsets `w : ι → ℝ`, define
\[
T_w(x) := \max_{i \in \iota} (x_i + w_i).
\]
Then for every scalar threshold `c`,
\[
T_w(x) \le c \iff \forall i,\ x_i \le c - w_i.
\]

This says the map `x ↦ sup_i (x_i + w_i)` has right adjoint `c ↦ (i ↦ c - w_i)`.

Use a finite index type `[Fintype ι]`. A good Lean form is:

```lean
theorem tropical_finset_aggregation_residuation
    {ι : Type} [Fintype ι] [DecidableEq ι]
    (x w : ι → ℝ) (c : ℝ) :
    (Finset.univ.sup fun i => x i + w i) ≤ c ↔
      ∀ i, x i ≤ c - w i
```

Depending on available lemmas, you may need `Finset.sup'` with a nonempty witness, or replace `sup` by a `Finset.fold max`. If `CompleteLattice` friction appears, specialize to `Fin n` and use induction on finite sets.

This theorem is the first genuine nontrivial result. It internalizes the passage from a forward tropical layer to a backward certificate.

### Theorem 3: Composition residual / tropical cut-elimination

Suppose `f : α → β` and `g : β → γ` are monotone maps between preorders, each equipped with a residual:
\[
f(x) \le y \iff x \le f^\sharp(y), \qquad
g(y) \le z \iff y \le g^\sharp(z).
\]
Then
\[
(g \circ f)(x) \le z \iff x \le f^\sharp(g^\sharp(z)).
\]

This is the general cut-elimination law for residuated maps. In Lean, prove it abstractly first for preorders, then instantiate it for tropical translation/aggregation maps.

Suggested abstract Lean 4 signature:
```lean
theorem residual_comp
    {α β γ : Type}
    [Preorder α] [Preorder β] [Preorder γ]
    (f : α → β) (fsharp : β → α)
    (g : β → γ) (gsharp : γ → β)
    (hf : ∀ x y, f x ≤ y ↔ x ≤ fsharp y)
    (hg : ∀ y z, g y ≤ z ↔ y ≤ gsharp z) :
    ∀ x z, (g (f x) ≤ z) ↔ x ≤ fsharp (gsharp z)
```

Then instantiate this theorem with tropical maps to obtain a compositional stability result. This is the key theorem that reframes layered tropical computation as proof normalization.

### Theorem 4: Explicit residual for a one-layer tropical operator on vectors

For a matrix `W : m → n → ℝ`, define
\[
F_W(x)_j := \max_i (x_i + W_{i,j}).
\]
Then
\[
F_W(x) \le y \iff \forall i,\ x_i \le \min_j (y_j - W_{i,j}).
\]

This is the matrix-level residuation law, the real prize.

Suggested Lean shape:
```lean
theorem tropical_matrix_residuation
    {m n : Type} [Fintype m] [Fintype n] [DecidableEq m] [DecidableEq n]
    (W : m → n → ℝ) (x : m → ℝ) (y : n → ℝ) :
    (∀ j, (Finset.univ.sup fun i => x i + W i j) ≤ y j) ↔
    (∀ i, x i ≤ Finset.univ.inf fun j => y j - W i j)
```

You may need to reformulate the RHS as `∀ i j, x i ≤ y j - W i j` first, then derive the `inf` form. That intermediate theorem is already strong and likely easier:

```lean
theorem tropical_matrix_residuation_pointwise
    {m n : Type} [Fintype m] [Fintype n] [DecidableEq m] [DecidableEq n]
    (W : m → n → ℝ) (x : m → ℝ) (y : n → ℝ) :
    (∀ j, (Finset.univ.sup fun i => x i + W i j) ≤ y j) ↔
    (∀ i j, x i ≤ y j - W i j)
```

This theorem is a tropical analogue of linear programming dual feasibility and a formal strongest-postcondition/weakest-precondition bridge.

## Proof Strategy Paths

### Strategy A: Direct order-theoretic adjunction proof
Most promising.

1. Prove the scalar lemma `a + y ≤ c ↔ y ≤ c - a` using `linarith` or ordered-ring arithmetic.
2. Lift from scalar translation to finite sup aggregation:
   - show `sup_i (x i + w i) ≤ c` iff each `x i + w i ≤ c`;
   - apply scalar residuation pointwise.
3. Prove abstract composition of residuals (`residual_comp`) once and instantiate it.

Why this is best:

- minimal dependence on exotic Mathlib APIs;
- creates reusable infrastructure for later domains.

### Strategy B: Finset induction and explicit max calculus
Good fallback if `Finset.sup` lemmas are awkward.

1. Define aggregation recursively over a `Finset` using `fold max`.
2. Prove the residuation law by induction on the finite set:
   - base case: singleton;
   - inductive step: `max` inequality splits into conjunction.
3. Derive matrix-level theorem by nesting the finite-set result.

Why useful:
- robust against lattice-instance friction;
- gives computationally explicit proofs.

### Strategy C: Abstract Galois connection formalization

2. Show composition preserves this structure.
3. Instantiate with tropical translation and tropical matrix maps.

Why powerful:
- this creates a reusable category of tropical proof transformers;
- future work on enriched categories becomes immediate.

Risk:
- more setup;
- may require more abstraction than necessary for a first breakthrough.
