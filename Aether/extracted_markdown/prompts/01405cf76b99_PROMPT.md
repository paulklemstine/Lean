**Mode: prove + discover**

The target is a universality principle: that a purely algebraic radius of stability controls, up to universal constants, the largest perturbation scale at which Glauber-type dynamics remain polynomially mixing. If true, this opens a new field: **algorithmic algebraic geometry of mixing thresholds**.

## Primary theorem statement

### Theorem A: one-sided universality lower bound
Prove a rigorous lower bound showing that Lorentzian stability implies algorithmic stability.

**Mathematical statement.**  
There exist universal constants `c > 0`, `k : ℕ` such that for every finite state space and every multiaffine homogeneous strongly log-concave distribution `μ` of degree `d` on `n` variables, if the Lorentzian stability radius of `μ` is at least `ρ`, then every admissible coefficient perturbation of size at most `c * ρ / n^k` has Glauber dynamics spectral gap at least `1 / n^k`.

In symbols, aim for a formal theorem of the form:

```lean
theorem spectralGap_lower_bound_of_lorentzian_radius
    {α : Type} [Fintype α] [DecidableEq α]
    (μ : Finset α → ℝ)
    (n d : ℕ)
    (h_hom : IsHomogeneousOfDegree μ d)
    (h_multiaffine : IsMultiaffineWeight μ)
    (h_slc : StronglyLogConcaveWeight μ)
    {ρ : ℝ} (hρ : 0 < ρ)
    (hLor : ρ ≤ lorentzianStabilityRadius μ) :
    ∃ c : ℝ, ∃ k : ℕ,
      0 < c ∧
      ∀ ε : ℝ, |ε| ≤ c * ρ / (n : ℝ)^k →
        spectralGap (glauberKernel (perturbWeight μ ε)) ≥ 1 / (n : ℝ)^k
```

This is the theorem that turns geometry into algorithmic certification.

### Theorem B: converse upper-bound framework
Prove a converse-type theorem in an abstract perturbation model: if the perturbation exceeds a certified residual-gap threshold, then the spectral gap cannot stay uniformly inverse-polynomial.

**Mathematical statement.**  
For any perturbation family satisfying your admissibility axioms, if residual gap degenerates below a threshold along a sequence of perturbations, then no uniform inverse-polynomial lower bound on the spectral gap survives.

Possible Lean signature:

```lean
theorem no_uniform_poly_gap_of_residual_gap_collapse
    {α β : Type} [Fintype α] [DecidableEq α] [Fintype β]
    (μ : Finset α → ℝ)
    (P : ℝ → Matrix β β ℝ)
    (hAdm : AdmissiblePerturbationFamily μ P)
    (hCollapse :
      ∀ K : ℕ, ∃ ε : ℝ, 0 < |ε| ∧ residualGap μ ε < 1 / (K : ℝ)) :
    ¬ ∃ k : ℕ, ∀ ε : ℝ, IsAdmissible μ ε →
        spectralGap (P ε) ≥ 1 / (Fintype.card α : ℝ)^k
```

This theorem is important because it identifies **residual-gap collapse as an obstruction to universality**.

### Theorem C: cross-domain comparison theorem
Prove a theorem connecting this theory to another domain. The strongest available bridge is to **matroid geometry** or **determinantal processes / linear algebra**.

A particularly promising target:

**For a determinantal measure generated by a positive semidefinite matrix `L`, a lower bound on the minimum nonzero eigenvalue of `L` induces a lower bound on the Lorentzian stability radius, hence on the certified spectral gap radius.**

Possible Lean signature:

```lean
theorem det_process_radius_lower_bound

    {λ : ℝ} (hλ : 0 < λ)
    (heig : λ ≤ minNonzeroEigenvalue L) :

      c * λ ≤ lorentzianStabilityRadius (detWeight L)
```

Combined with Theorem A, this yields an algorithmic consequence for determinantal Glauber dynamics.

This is the required cross-domain theorem:
- algebraic geometry / Lorentzian polynomials,
- spectral linear algebra / random matrix structure,
- Markov-chain mixing.

If the determinantal route is too library-heavy, use **graphic matroids**:
show that a combinatorial edge-connectivity lower bound implies a lower bound on a geometric stability proxy.

```lean
conjecture universality_of_mixing_radius
```

**Prediction:** the ratio remains in a bounded interval and trends toward a family-independent constant band.

A single family where the ratio diverges polynomially would refute universality.

## Proof Strategy Architecture

You must not give a one-line proof sketch. Build a proof program with multiple routes.

### Strategy 1: Certified inequality pipeline from geometry to mixing
This is the most promising route.

1. **Geometry-to-residual step.**  
   Use catalog Lorentzian-gap theorems to show perturbations below `ρ` preserve a quantitative Hessian/eigenvalue signature margin. Convert this to a lower bound on a residual gap or local concavity margin.

2. **Residual-to-spectral step.**  
   Invoke or extend catalog results translating residual gap into a lower bound on the Poincaré constant or spectral gap for Glauber dynamics. Expect to need multi-step `calc` arguments and careful norm inequalities.

3. **Spectral-to-mixing step.**  
   Use standard certified Markov-chain inequalities to obtain polynomial mixing. Even if mixing-time formalization is too long, the spectral-gap theorem itself is already substantial and should be fully formalized.

**Why this is best:** it directly exploits the existing formal pipeline and should yield a clean theorem with minimal new probabilistic infrastructure.

### Strategy 2: Contrapositive obstruction analysis
This is the best route for the converse theorem.

1. Assume inverse-polynomial spectral gap persists under perturbations beyond the geometric threshold.
2. Use `by_contra` and compactness/finite-dimensional continuity of coefficients-to-kernel maps to derive a nondegenerate residual gap.
3. Show this contradicts collapse of the Lorentzian or residual certificate.

**Why this matters:** even a partial converse is scientifically valuable because it identifies exactly where universality could fail.

### Strategy 3: Family-by-family exact computation
This route is ideal for demo and computational validation.

1. For special families (uniform/partition/graphic matroids, small determinantal examples), derive explicit formulas or lower bounds for the geometric radius.
2. Construct the Glauber kernel explicitly and estimate the spectral gap numerically and, where possible, symbolically.
3. Compare exact/empirical thresholds to formulate sharper conjectures.

**Why this matters:** if the full universality theorem is too hard in one cycle, exact solved families can still be paradigm-shifting and will guide the final theorem statement.
