## Core Conjectural Target

Let \(\Gamma\) be a compact connected metric graph, and let \(S \subset \Gamma\) be a finite separated set of points. For each \(s \in S\), define a normalized harmonic kernel generator \(k_s\) to be the unique continuous piecewise-linear function on \(\Gamma\) satisfying:

1. \(k_s\) is harmonic on \(\Gamma \setminus S\),
2. the outgoing slope sum at each \(t \in S\) encodes a unit source at \(s\) and balancing elsewhere,
3. \(k_s(s)=0\) or \(\int_\Gamma k_s = 0\) as normalization.

Then the subgroup generated by the divisor classes of the Laplacians \(\Delta k_s\) should recover the \(S\)-supported Jacobian quotient:
\[
\frac{\operatorname{Div}^0_S(\Gamma)}{\operatorname{Prin}_S(\Gamma)} \;\cong\; J_S(\Gamma),
\]
and, in favorable formulations, this identifies with the image of the tropical Abel–Jacobi map restricted to \(S\)-supported degree-zero divisors.

Your formalization should not merely restate this. It should isolate **provable finite-resolution approximants**, prove stabilization / compatibility theorems, and package a verified computational method.

## Precise theorem statements to aim for

### Theorem 1: Pendant-edge rigidity for metric graphs
This is the metric analogue of leaf rigidity from the catalog.

**Mathematical statement.**
Let \(\Gamma\) be a compact metric graph and \(e\) a pendant edge attached at \(v\) with leaf endpoint \(w\). If \(f\) is continuous, piecewise-linear, and harmonic on the interior of \(e\), then \(f\) is constant on \(e\). More generally, if \(f\) is harmonic on \(\Gamma \setminus S\) and \(e \cap S = \varnothing\), then \(f|_e\) is constant.

This is the continuous maximum-principle manifestation of the discrete theorem `harmonic_at_leaf_eq_neighbor`.

**Lean 4 target signature (suggested).**
```lean
theorem harmonic_on_pendant_edge_constant
  {Γ : MetricGraph} {e : Γ.Edge} {f : Γ.PLFunction} {S : Finset Γ.Point}
  (hpend : Γ.IsPendantEdge e)
  (hdisj : Disjoint (Γ.pointsOnEdge e).toFinset S)
  (hhar : f.IsHarmonicOn (Γ.complSupport S)) :
  ∀ x y, x ∈ Γ.pointsOnEdge e → y ∈ Γ.pointsOnEdge e → f x = f y
```

A vertex-only version may be easier first:
```lean
theorem harmonic_at_leaf_eq_attachment_metric
  {Γ : MetricGraph} {v w : Γ.Vertex} {f : Γ.PLVertexFunction} {S : Finset Γ.Vertex}
  (hleaf : Γ.IsLeaf w)
  (hadj : Γ.Adj w v)
  (hnot : w ∉ S)
  (hhar : f.VertexHarmonicOn Sᶜ) :
  f w = f v
```

### Theorem 2: Canonical kernel uniqueness under normalization
This is the existence/uniqueness theorem that makes the whole theory rigid.

**Mathematical statement.**
Fix a compact connected metric graph \(\Gamma\) and a finite separated set \(S\). For each source divisor \(D\) of degree zero supported on \(S\), there exists a unique normalized PL function \(f\) such that:

- \(f\) is harmonic on \(\Gamma \setminus S\),
- \(\Delta f = D\),
- \(f\) satisfies the chosen normalization.

Equivalently, normalized harmonic representatives are unique modulo constants.

**Lean 4 target signature (suggested).**
```lean
theorem exists_unique_normalized_kernel
  {Γ : MetricGraph} [Fact Γ.Connected] [Fact Γ.Compact]
  {S : Finset Γ.Point} (hsep : Γ.Separated S)
  (D : SSupportedDivisor Γ S)
  (hdeg : D.degree = 0) :
  ∃! f : Γ.PLFunction,
    f.IsNormalized ∧
    f.IsHarmonicOn (Γ.complSupport S) ∧
    f.laplacian = D.toDivisor
```

A weaker finite-vertex skeleton version is also acceptable as an intermediate theorem:
```lean
theorem exists_unique_normalized_kernel_on_model
  {M : MetricGraphModel} [DecidableEq M.V]
  {S : Finset M.V} (hconn : M.Connected)
  (D : VDivisor M.V) (hsupp : D.support ⊆ S) (hdeg : D.degree = 0) :
  ∃! f : M.VertexPotential,
    f.meanZero ∧
    M.laplacian f = D
```

### Theorem 3: Canonical-kernel quotient realizes the \(S\)-supported Jacobian
This is the headline theorem.

**Mathematical statement.**
Let \(\Gamma\) be a compact connected metric graph and \(S\) a finite separated set meeting every essential cycle model. Then the lattice generated by normalized harmonic kernel generators modulo principal relations is canonically isomorphic to the \(S\)-supported Jacobian quotient.

More concretely:
\[
\operatorname{Div}^0_S(\Gamma) / \operatorname{Prin}_S(\Gamma)
\cong
\operatorname{Span}_{\mathbb Z}\{[\Delta k_s - \Delta k_{s_0}] : s \in S \setminus \{s_0\}\}/\mathcal R.
\]

**Lean 4 target signature (suggested).**
```lean
theorem canonical_kernel_quotient_equiv_SJacobian
  {Γ : MetricGraph} [Fact Γ.Connected] [Fact Γ.Compact]
  {S : Finset Γ.Point} (hsep : Γ.Separated S) (hne : S.Nonempty) :
  Nonempty (
    SSupportedJacobian Γ S ≃+
    CanonicalKernelQuotient Γ S
  )
```

If full equivalence is too ambitious in one cycle, prove a two-step version:

1. surjectivity of the canonical-kernel map,
2. characterization of its kernel as principal \(S\)-relations.

### Theorem 4: Resolution compatibility under subdivision
This is the bridge from discrete catalog theorems to metric graphs.

**Mathematical statement.**
Let \(G_n\) be a sequence of subdivisions of a metric graph model for \(\Gamma\) with mesh going to zero. Then the discrete canonical kernel generators on \(G_n\) are compatible under refinement and converge to the metric canonical kernels.

This theorem opens the algorithmic door.

**Lean 4 target signature (suggested).**
```lean
theorem canonical_kernels_refinement_compatible
  {M₁ M₂ : MetricGraphModel}
  (href : M₂.Refines M₁)
  {S : Finset M₁.V} :
  CompatibleKernelFamily href S
```

and a computationally weaker but still meaningful theorem:
```lean
theorem principal_relation_preserved_under_subdivision
  {M₁ M₂ : MetricGraphModel}
  (href : M₂.Refines M₁)
  {D : VDivisor M₁.V} :
  M₁.IsPrincipal D ↔ M₂.IsPrincipal (href.pushDivisor D)
```

### Theorem 5: Cross-domain theorem — Dirichlet energy and tropical Jacobians
This is the required cross-domain connection.

**Mathematical statement.**
For normalized kernel representatives on a compact metric graph, the Dirichlet energy induces a positive semidefinite symmetric bilinear form on \(S\)-supported divisor classes, and this form descends to the tropical polarization on the Jacobian.

This connects tropical geometry to analysis / mathematical physics / electrical networks.

**Lean 4 target signature (suggested).**
```lean
theorem dirichlet_energy_descends_to_jacobian
  {Γ : MetricGraph} [Fact Γ.Connected] [Fact Γ.Compact]
  {S : Finset Γ.Point} (hsep : Γ.Separated S) :
  ∃ Q : SSupportedJacobian Γ S →+ SSupportedJacobian Γ S →+ ℝ,
```

This theorem is not decorative: it identifies the canonical-kernel machinery with the effective resistance / electrical network form and thereby ties tropical Jacobians to statistical mechanics and quantum graph Laplacians.

## Proof architecture: 3 viable strategies

You must include multi-step proofs, not one-line automation. Use induction, `rcases`, `by_contra`, `field_simp`, and long `calc` chains where appropriate.

### Strategy A — Finite model first, then metric completion
**Most promising.**

1. Define a `MetricGraphModel` as a finite graph with positive edge lengths.
2. Prove all key theorems on the finite vertex-edge model:
   - leaf rigidity,
   - Laplacian row-sum-zero,
   - uniqueness of normalized potentials,
   - quotient characterization of \(S\)-supported divisor classes.
3. Show invariance under subdivision/refinement.
4. Package the metric graph as the colimit / geometric realization of all subdivisions and define canonical kernels as refinement-stable PL functions.

**Why this is strongest:** it directly reuses the catalog’s discrete Laplacian theorems and lets you import existing chip-firing reasoning before passing to the continuous limit.

### Strategy B — Variational / energy minimization
1. Define Dirichlet energy for PL functions on a metric graph model:
   \[
   E(f)=\sum_e \frac{(f(v)-f(w))^2}{\ell(e)}.
   \]
2. Show that among functions with prescribed Laplacian source divisor on \(S\), the normalized harmonic representative uniquely minimizes energy.
3. Deduce uniqueness from strict convexity modulo constants.
4. Identify principal relations with zero-energy degeneracies.

**Why this is powerful:** it gives the cleanest conceptual route to uniqueness and positivity, and it naturally produces the cross-domain theorem relating tropical Jacobians to electrical networks and quantum graph Hamiltonians.

### Strategy C — Inductive decomposition by bridges / pendant trees
1. Decompose a metric graph into a 2-core plus attached trees.
2. Use the metric pendant-edge rigidity theorem to collapse tree attachments without changing canonical kernel classes.
3. Reduce the Jacobian computation to the cycle core.
4. Build the canonical quotient from the reduced graph and lift back.

**Why this matters:** it mirrors tropical curve intuition and could yield a highly efficient verified algorithm by pruning irrelevant tree structure before solving the harmonic system.

**Recommendation:** pursue **Strategy A** as the main line, with **Strategy B** supplying the key uniqueness/positivity lemma and **Strategy C** supplying algorithmic simplification and conceptual elegance.

### From `graphLaplacian`
Use `graphLaplacian` as the discrete algebraic prototype for:
- row-sum-zero,
- symmetry,
- principal divisor generation,
- normalization modulo constants.

Then define the metric-graph Laplacian so that on any chosen model it reduces to a weighted Laplacian:
\[
(\Delta f)(v)=\sum_{e \ni v} \frac{f(v)-f(v_e)}{\ell(e)}.
\]
This weighted formula is the exact finite-model shadow of the metric slope-sum Laplacian.

### From `harmonic_at_leaf_eq_neighbor`
Generalize this from a combinatorial leaf to a pendant interval. The metric proof should use:
- harmonicity on the interior implies affine linearity,
- the leaf endpoint has only one outgoing direction,
- zero outgoing slope sum forces slope \(=0\),
- hence constancy along the entire edge.

### From `harmonic_tree_attachment_forces_unique_firing`
Elevate this into:
- tree attachments contribute no independent Jacobian classes,
- attached metric trees carry no nontrivial harmonic kernel freedom once normalization is fixed,
- therefore the Jacobian is determined by the cycle core plus source constraints on \(S\).

This is the structural theorem that makes canonical kernels computationally tractable.
