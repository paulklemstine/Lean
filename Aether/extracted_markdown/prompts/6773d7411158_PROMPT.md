Key tactic: `rcases` on the lattice axioms, `exact` for the idempotent property.

2. **Lemma `tropical_complement_exists`**: For any tropical subrepresentation S of ρ, there exists a tropical complement S' such that T^n = S ⊕ₜ S'. 3. **Lemma `tropical_dim_strictly_decreases`**: If S is a proper subrepresentation of ρ, then dim(S) < dim(ρ) and dim(ker(P_S)) < dim(ρ). Proof: direct computation using the tropical rank. Key tactic: `omega` for the dimension inequality.

4. **Main induction**: By strong induction on n, using `tropical_complement_exists` to split ρ into two strictly smaller representations, then applying the induction hypothesis. Key tactic: `induction'` with the dimension as the measure.

5. **Irreducibility base case**: When n = 1, every representation is irreducible (T^1 has no proper tropical subspaces other than {⊤} and T^1 itself). Key tactic: `decide` or `simp` for the one-dimensional case.

**For tropical_schur_lemma** (the structural theorem):

1. **Lemma `tropical_kernel_subrepresentation`**: The kernel of a G-equivariant tropical linear map is a tropical subrepresentation. Proof: direct verification of invariance. Key tactic: `intro`, `simp`.

2. **Lemma `tropical_image_subrepresentation`**: The image of a G-equivariant tropical linear map is a tropical subrepresentation. Proof: direct verification. Key tactic: `intro`, `simp`.

3. **Lemma `tropical_subspace_trichotomy`**: A tropical subspace of an irreducible representation is either {⊤} (the zero subspace in tropical arithmetic) or the whole space. Proof: by definition of irreducibility. Key tactic: `rcases` on the subspace being in the set of subrepresentations.

4. **Main proof**: Combine kernel-image decomposition with the trichotomy. If ker(φ) = T^m, then φ = 0. If ker(φ) = {⊤}, then φ is injective. Similarly for the image. Key tactic: `rcases` on the four cases, `tauto` for the final disjunction.
