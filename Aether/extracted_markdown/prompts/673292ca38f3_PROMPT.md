## Research Task: Tropical certified robustness for multiclass piecewise-linear networks under monotone weighted-vote score aggregation

Research Mode: PROVE

Prove a compositional robustness theorem for multiclass score aggregators of the form
\[
A_w(s^{(1)},\dots,s^{(m)})_c=\sum_{i=1}^m w_i\, s^{(i)}_c
\]
with nonnegative weights summing to \(1\), followed by prediction by `argmax`. The key point is that the weighted vote is coordinatewise linear and monotone, so pairwise class margins aggregate exactly, and Lipschitz certificates compose with the same weights.

You should aim to formalize the result first in a finite-index setting using `Fin n` for branches and classes, `EuclideanSpace ℝ (Fin d)` or simply `(Fin d → ℝ)` for inputs, and branch score maps
```lean
f : Fin m → (Fin d → ℝ) → Fin C → ℝ
```
with weights
```lean
w : Fin m → ℝ
```
satisfying
```lean
(∀ i, 0 ≤ w i) ∧ (∑ i, w i = 1)
```
although the normalization `∑ i, w i = 1` is not actually needed for the robustness radius formula, only nonnegativity is.

### Precise target theorem statements

Define the weighted aggregated score:
```lean
def aggScore
    {m d C : ℕ} (w : Fin m → ℝ)
    (f : Fin m → (Fin d → ℝ) → Fin C → ℝ)
    (x : Fin d → ℝ) (c : Fin C) : ℝ :=
  ∑ i, w i * f i x c
```

Define the pairwise margin of a score vector:
```lean
def margin
    {d C : ℕ} (g : (Fin d → ℝ) → Fin C → ℝ)
    (y c : Fin C) (x : Fin d → ℝ) : ℝ :=
  g x y - g x c
```

Define the aggregated pairwise margin:
```lean
def aggMargin
    {m d C : ℕ} (w : Fin m → ℝ)
    (f : Fin m → (Fin d → ℝ) → Fin C → ℝ)
    (y c : Fin C) (x : Fin d → ℝ) : ℝ :=
  ∑ i, w i * (f i x y - f i x c)
```

Then prove the weighted Lipschitz composition theorem. A clean statement is:

```lean
theorem aggMargin_lipschitz_of_branch_lipschitz
    {m d C : ℕ} (w K : Fin m → ℝ)
    (f : Fin m → (Fin d → ℝ) → Fin C → ℝ)
    (hw_nonneg : ∀ i, 0 ≤ w i)
    (hK_nonneg : ∀ i, 0 ≤ K i)
    (hLip :
      ∀ i, ∀ x z : Fin d → ℝ, ∀ c : Fin C,
        |f i x c - f i z c| ≤ K i * ‖x - z‖∞) :
    ∀ x z : Fin d → ℝ, ∀ y c : Fin C,
      |aggMargin w f y c x - aggMargin w f y c z|
        ≤ (2 * ∑ i, w i * K i) * ‖x - z‖∞ := by
  ...
```

Here `‖x - z‖∞` should be instantiated using the sup norm on `(Fin d → ℝ)`; if notation becomes awkward in Lean, use the ambient norm and prove the result in the type carrying the `Norm` instance for finite products. The factor `2` comes from
\[
|(a_y-a_c)-(b_y-b_c)| \le |a_y-b_y| + |a_c-b_c|.
\]

After that, prove the branchwise competitor-specific refinement:

```lean
theorem aggMargin_lipschitz_of_competitor_specific_bounds
    {m d C : ℕ} (w : Fin m → ℝ) (Kc : Fin m → Fin C → ℝ)
    (f : Fin m → (Fin d → ℝ) → Fin C → ℝ)
    (hw_nonneg : ∀ i, 0 ≤ w i)
    (hKc_nonneg : ∀ i c, 0 ≤ Kc i c)
    (hLip :
      ∀ i, ∀ x z : Fin d → ℝ, ∀ c : Fin C,
        |(f i x c - f i z c)| ≤ Kc i c * ‖x - z‖∞) :
    ∀ x z : Fin d → ℝ, ∀ y c : Fin C,
      |aggMargin w f y c x - aggMargin w f y c z|
        ≤ ((∑ i, w i * (Kc i y + Kc i c)) * ‖x - z‖∞) := by
  ...
```

This is the sharper competitor-dependent Lipschitz estimate:
\[
|M_w(x;y,c)-M_w(z;y,c)| \le \Big(\sum_i w_i(K_i(y)+K_i(c))\Big)\,\|x-z\|_\infty.
\]

Finally, prove the actual robustness theorem. A good theorem statement avoids needing a formal `argmax` operator by using the stronger margin condition “class `y` strictly beats every competitor”. That is enough to conclude prediction constancy on the ball.

```lean
theorem weighted_vote_certified_radius
    {m d C : ℕ} (w K : Fin m → ℝ)
    (f : Fin m → (Fin d → ℝ) → Fin C → ℝ)
    (x : Fin d → ℝ) (y : Fin C) (r : ℝ)
    (hw_nonneg : ∀ i, 0 ≤ w i)
    (hK_nonneg : ∀ i, 0 ≤ K i)
    (hLip :
      ∀ i, ∀ x z : Fin d → ℝ, ∀ c : Fin C,
        |f i x c - f i z c| ≤ K i * ‖x - z‖∞)
    (hmargin :
      ∀ c, c ≠ y → 0 < aggMargin w f y c x)
    (hr :
      r < (iInf fun c : {c : Fin C // c ≠ y} =>
            aggMargin w f y c.1 x / (2 * ∑ i, w i * K i)))
    :
    ∀ z : Fin d → ℝ, ‖z - x‖∞ ≤ r →
      ∀ c, c ≠ y → aggScore w f z c < aggScore w f z y := by
  ...
```

Because `iInf` over a finite type can be cumbersome, it may be easier in Lean to formulate the hypothesis directly as:
```lean
(hcert :
  ∀ c, c ≠ y →
    r < aggMargin w f y c x / (2 * ∑ i, w i * K i))
```
and conclude
```lean
∀ z, ‖z - x‖∞ ≤ r → ∀ c ≠ y, aggScore w f z c < aggScore w f z y
```
This version is often much easier to prove and is mathematically equivalent to the finite minimum formulation.

### Proof strategy

1. **Algebraic reduction from aggregated scores to aggregated margins.**  
   Prove
   ```lean
   aggMargin w f y c x = aggScore w f x y - aggScore w f x c
   ```
   by expanding both definitions and using `Finset.sum_sub_distrib`, `Finset.mul_sum`, and ring normalization (`ring_nf` / `linarith` after `simp`). This identity is essential because robustness is naturally expressed as positivity of margins rather than direct argmax statements.

2. **Lipschitz transfer from logits to pairwise margins.**  
   For each branch `i`, derive
   ```lean
   |(f i x y - f i x c) - (f i z y - f i z c)| ≤ 2 * K i * ‖x - z‖∞
   ```
   from the coordinatewise Lipschitz bounds using
   \[
   |(a-b)-(a'-b')| \le |a-a'| + |b-b'|.
   \]
   In Lean, this is likely:
   - rewrite with `sub_eq_add_neg`,
   - use `abs_add`,
   - use the branch hypotheses for class `y` and class `c`,
   - conclude by `nlinarith` or `ring_nf` + `linarith`.

3. **Weighted summation with nonnegative coefficients.**  
   For the aggregated margin difference, start from
   ```lean
   |∑ i, w i * Δ_i| ≤ ∑ i, |w i * Δ_i| = ∑ i, w i * |Δ_i|
   ```
   using `abs_sum_le_sum_abs`, `abs_mul`, and `abs_of_nonneg (hw_nonneg i)`. Then substitute the branchwise bounds and factor out `‖x-z‖∞`. You may need a lemma of the form
   ```lean
   ∑ i, w i * (2 * K i * t) = (2 * ∑ i, w i * K i) * t
   ```
   for `0 ≤ t`, proved by distributivity and commutativity of finite sums.

4. **Margin preservation on a ball.**  
   For any competitor `c ≠ y`, show
   \[
   M_w(z;y,c) \ge M_w(x;y,c) - L_c \|z-x\|_\infty
   \]
   by applying the Lipschitz bound to `M_w` and rewriting
   \[
   M_w(z;y,c) = M_w(x;y,c) + (M_w(z;y,c)-M_w(x;y,c)).
   \]
   If the certificate hypothesis gives `L_c * r < M_w(x;y,c)` and `‖z-x‖∞ ≤ r`, conclude `0 < M_w(z;y,c)`. Then use the algebraic identity from step 1 to convert positive margin into
   ```lean
   aggScore w f z c < aggScore w f z y.
   ```

5. **Sharper competitor-specific theorem.**  
   Repeat the previous argument with
   \[
   L_c = \sum_i w_i (K_i(y)+K_i(c))
   \]
   instead of the coarse `2 * ∑ i w_i K_i`. This is the genuinely stronger theorem: it certifies larger radii when the winner class and a given competitor are individually stable, even if other classes in a branch have worse Lipschitz constants.

### Significance

This theorem is the right next step for the certified robustness program because it upgrades robustness from single-branch or max-type multiclass architectures to a genuinely compositional ensemble primitive: monotone weighted voting at the logit level. Unlike max-tree or lexicographic aggregation, weighted vote is linear, ubiquitous in practice, and mathematically compatible with tropical/piecewise-linear score maps. The theorem shows that branchwise certificates do not merely coexist but combine quantitatively, with exact weighted margin addition and a sharp competitor-specific Lipschitz denominator.

Formally, this creates a reusable certification layer: any future theorem producing branchwise pairwise margins and branchwise Lipschitz bounds can be plugged into this aggregation theorem to obtain end-to-end multiclass robustness. It also gives a bridge between tropical score semantics and convex ensemble aggregation, which should be valuable for later extensions to robustness under pruning, sparsification, or certified mixtures of experts.

A strong end product would be:
- one algebra lemma for weighted aggregated margins,
- one coarse robustness theorem with denominator `2 * ∑ i, w i * K i`,
- one sharper theorem with denominator `∑ i, w i * (Kc i y + Kc i c)`,
- and, if convenient, a corollary specialized to normalized weights `∑ i, w i = 1`.

The normalized-weight corollary is conceptually nice, but the mathematically stronger and more reusable statement is the unnormalized nonnegative-weight version.
