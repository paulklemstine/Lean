## Research Task: GL3 tropical Satake to multiclass ResNet robustness via skip-connection Hecke score decompositions

Research Mode: PROVE

Develop a precise certified-robustness theorem for multiclass residual piecewise-linear score maps
\[
f(x) = h(x) + \sum_{i \in I} s_i(x),
\]
where `h` is the base tropical/Hecke score map and each skip branch `s i` has a certified `L∞` Lipschitz bound. The main goal is to convert pairwise tropical Satake separation margins for the base classifier into a robustness certificate for the full residual architecture.

The right formal target is not merely a generic Lipschitz argmax lemma, but a theorem whose hypotheses are phrased in terms of pairwise class-gap lower bounds coming from the GL3 tropical Satake / tropical Hecke score decomposition, and whose conclusion is invariance of the predicted class on an `L∞` ball.

### Core objects and suggested Lean setup

Work with a finite class set `Fin C` and input space `ℝ^d`, represented as functions `Fin d → ℝ`. A concrete setup that should be easy to formalize is:

```lean
open scoped BigOperators
open Finset

variable {C d n : ℕ}

abbrev Input (d : ℕ) := Fin d → ℝ
abbrev ScoreVec (C d : ℕ) := Input d → Fin C → ℝ
```

Use the sup metric on coordinates:

```lean
def linfDist {d : ℕ} (x z : Input d) : ℝ :=
  Finset.sup Finset.univ (fun i : Fin d => |x i - z i|)
```

If `Finset.sup` over `ℝ` becomes inconvenient, it is also acceptable to work with the standard bound
```lean
(∀ i, |z i - x i| ≤ r)
```
as the definition of membership in the `L∞` ball. This is often much easier in Lean than developing a metric API from scratch.

Define the residual score map:

```lean
def totalScore {C d n : ℕ}
    (h : ScoreVec C d) (s : Fin n → ScoreVec C d) : ScoreVec C d :=
  fun x c => h x c + ∑ i : Fin n, s i x c
```

Define pairwise gaps and multiclass margins:

```lean
def pairGap {C d : ℕ} (f : ScoreVec C d) (a b : Fin C) (x : Input d) : ℝ :=
  f x a - f x b

def marginAt {C d : ℕ} (f : ScoreVec C d) (y : Fin C) (x : Input d) : ℝ :=
  Finset.inf' (Finset.univ.erase y) (by
    intro hy; simp at hy) (fun b => pairGap f y b x)
```

For argmax stability, it is cleaner to avoid needing existence/uniqueness of an argmax operator at first. Instead prove the stronger order-theoretic statement:
```lean
∀ b ≠ y, f z y > f z b
```
for all `z` in the ball. This directly implies that `y` is the unique predicted class. If you later want an actual `argmax` statement, define prediction by a tie-free hypothesis.

### Main theorem: residual pairwise robustness from branchwise gap budgets

The most useful exact statement is pairwise and branchwise. Assume:
- the base pairwise gap `h x a - h x b` has a certified lower bound `Δ a b`,
- each branch pairwise gap `(s i · a - s i · b)` is `L∞`-Lipschitz with constant `K i a b`,
- at the center `x`, class `y` has enough total pairwise margin against every competitor `b`.

A precise Lean shape:

```lean
theorem residual_pairwise_robust_of_gap_budget
    {C d n : ℕ}
    (h : ScoreVec C d)
    (s : Fin n → ScoreVec C d)
    (K0 : Fin C → Fin C → ℝ)
    (K : Fin n → Fin C → Fin C → ℝ)
    (x z : Input d)
    (y : Fin C)
    (r : ℝ)
    (hr : 0 ≤ r)
    (hz : ∀ i : Fin d, |z i - x i| ≤ r)
    (hbase_lip :
      ∀ a b : Fin C, ∀ x z,
        (∀ i : Fin d, |z i - x i| ≤ r) →
        |pairGap h a b z - pairGap h a b x| ≤ K0 a b * r)
    (hskip_lip :
      ∀ i : Fin n, ∀ a b : Fin C, ∀ x z,
        (∀ j : Fin d, |z j - x j| ≤ r) →
        |pairGap (s i) a b z - pairGap (s i) a b x| ≤ K i a b * r)
    (hmargin :
      ∀ b : Fin C, b ≠ y →
        pairGap (totalScore h s) y b x >
          (K0 y b + ∑ i : Fin n, K i y b) * r) :
    ∀ b : Fin C, b ≠ y → pairGap (totalScore h s) y b z > 0
```

This theorem is already nontrivial and directly useful: it says that if the center margin beats the total pairwise perturbation budget, then class `y` remains strictly above every competitor on the whole ball.

A slightly sharper and conceptually cleaner form uses a center-certified lower bound `Δ y b` for the base pairwise gap and separates base and skip budgets:

```lean
theorem residual_robust_of_base_gap_and_skip_budget
    {C d n : ℕ}
    (h : ScoreVec C d)
    (s : Fin n → ScoreVec C d)
    (Δ : Fin C → Fin C → Input d → ℝ)
    (K0 : Fin C → Fin C → ℝ)
    (K : Fin n → Fin C → Fin C → ℝ)
    (x z : Input d)
    (y : Fin C)
    (r : ℝ)
    (hr : 0 ≤ r)
    (hz : ∀ i : Fin d, |z i - x i| ≤ r)
    (hΔ :
      ∀ a b : Fin C, Δ a b x ≤ pairGap h a b x)
    (hbase_lip :
      ∀ a b : Fin C, ∀ x z,
        (∀ i : Fin d, |z i - x i| ≤ r) →
        |pairGap h a b z - pairGap h a b x| ≤ K0 a b * r)
    (hskip_lip :
      ∀ i : Fin n, ∀ a b : Fin C, ∀ x z,
        (∀ j : Fin d, |z j - x j| ≤ r) →
        |pairGap (s i) a b z - pairGap (s i) a b x| ≤ K i a b * r)
    (hcenter :
      ∀ b : Fin C, b ≠ y →
        Δ y b x + ∑ i : Fin n, pairGap (s i) y b x >
          (K0 y b + ∑ i : Fin n, K i y b) * r) :
    ∀ b : Fin C, b ≠ y → pairGap (totalScore h s) y b z > 0
```

This is the theorem that best matches the intended “Hecke margin + residual correction” interpretation: `Δ y b x` is the tropical Satake / Hecke separation certificate for the base model, while the skip terms are treated additively.

### Satake-style separation corollary

To align more closely with the stated research direction, introduce an abstract pairwise certificate `Δ` coming from a finite GL3 tropical Satake test family. You do not need to formalize the whole Satake machinery again; it is enough to package the output you need:

```lean
structure PairwiseSatakeCert {C d : ℕ} where
  Δ : Fin C → Fin C → Input d → ℝ
  lower_bound :
    ∀ a b x, Δ a b x ≤ pairGap h a b x
```

or simply keep `Δ` and `hΔ` as hypotheses. Then prove the radius formula:

```lean
theorem certified_radius_branchwise
    {C d n : ℕ}
    (h : ScoreVec C d)
    (s : Fin n → ScoreVec C d)
    (Δ : Fin C → Fin C → Input d → ℝ)
    (K0 : Fin C → Fin C → ℝ)
    (K : Fin n → Fin C → Fin C → ℝ)
    (x : Input d)
    (y : Fin C)
    (hΔ :
      ∀ a b : Fin C, Δ a b x ≤ pairGap h a b x)
    (hcenter :
      ∀ b : Fin C, b ≠ y →
        0 < Δ y b x + ∑ i : Fin n, pairGap (s i) y b x)
    :
    ∀ z,
      (∀ j : Fin d, |z j - x j| ≤
        Finset.inf' (Finset.univ.erase y) (by
          intro hy; simp at hy)
          (fun b =>
            (Δ y b x + ∑ i : Fin n, pairGap (s i) y b x) /
            (K0 y b + ∑ i : Fin n, K i y b))) ) →
      ∀ b : Fin C, b ≠ y → pairGap (totalScore h s) y b z > 0
```

This exact `inf'` radius may be a bit technical if denominator positivity causes side conditions. A cleaner theorem assumes all denominators are positive and then states a user-friendly corollary with any `r` below the minimum certified radius. If division becomes awkward, prove the budget inequality form first and derive the radius corollary later.

### Uniform-budget corollary

The prompt specifically mentions a simpler sufficient condition of the shape
\[
\Delta_{y,b}(x) > 2r(K_h + \sum_i K_i).
\]
This naturally corresponds to using classwise uniform Lipschitz bounds for scores rather than pairwise-gap bounds. A clean theorem is:

```lean
theorem residual_robust_uniform_budget
    {C d n : ℕ}
    (h : ScoreVec C d)
    (s : Fin n → ScoreVec C d)
    (Δ : Fin C → Fin C → Input d → ℝ)
    (Kh : ℝ)
    (Ks : Fin n → ℝ)
    (x z : Input d)
    (y : Fin C)
    (r : ℝ)
    (hr : 0 ≤ r)
    (hz : ∀ i : Fin d, |z i - x i| ≤ r)
    (hΔ : ∀ a b : Fin C, Δ a b x ≤ pairGap h a b x)
    (hbase_lip :
      ∀ c : Fin C, ∀ x z,
        (∀ i : Fin d, |z i - x i| ≤ r) →
        |h z c - h x c| ≤ Kh * r)
    (hskip_lip :
      ∀ i : Fin n, ∀ c : Fin C, ∀ x z,
        (∀ j : Fin d, |z j - x j| ≤ r) →
        |s i z c - s i x c| ≤ Ks i * r)
    (hmargin :
      ∀ b : Fin C, b ≠ y →
        Δ y b x > 2 * r * (Kh + ∑ i : Fin n, Ks i)) :
    ∀ b : Fin C, b ≠ y → pairGap (totalScore h s) y b z > 0
```

The factor `2` appears because each pairwise gap changes by at most the sum of the perturbations of the two logits. This is exactly the theorem to prove if you want the strongest correspondence with earlier “logitwise Lipschitz implies pairwise robustness” results.

### Concrete proof strategy

1. **Expand the pairwise gap of the residual model into base plus branchwise gaps.**  
   Prove a lemma:
   ```lean
   lemma pairGap_totalScore
       {C d n : ℕ}
       (h : ScoreVec C d) (s : Fin n → ScoreVec C d)
       (a b : Fin C) (x : Input d) :
       pairGap (totalScore h s) a b x
         = pairGap h a b x + ∑ i : Fin n, pairGap (s i) a b x
   ```
   This is just algebra, but it is the structural identity everything rests on. Use `sub_eq_add_neg`, `Finset.sum_add_distrib`, and ring normalization (`ring_nf` / `linarith` after rewriting).

2. **Bound perturbation of a pairwise gap by summing branchwise perturbation bounds.**  
   Prove:
   ```lean
   lemma pairGap_totalScore_lipschitz
       ...
       : |pairGap (totalScore h s) a b z - pairGap (totalScore h s) a b x|
         ≤ (K0 a b + ∑ i : Fin n, K i a b) * r
   ```
   Start from `pairGap_totalScore`, rewrite the difference as a sum of one base term plus branch terms, then apply `abs_add` repeatedly and `Finset.abs_sum_le_sum_abs`. Finally use the assumed branchwise inequalities and conclude with `nlinarith` or `linarith`. This lemma is the real engine.

3. **Convert a center margin lower bound into positivity throughout the ball.**  
   For each `b ≠ y`, use
   \[
   \operatorname{gap}_{y,b}(z)
   \ge \operatorname{gap}_{y,b}(x) - |\operatorname{gap}_{y,b}(z)-\operatorname{gap}_{y,b}(x)|.
   \]
   Then insert the Lipschitz bound from step 2. If the center margin exceeds the budget, conclude strict positivity. In Lean, this is a one-line `linarith` once the absolute-value estimate is available.

4. **Upgrade pairwise positivity to prediction invariance.**  
   If desired, define a predicate
   ```lean
   def StrictTopClass (f : ScoreVec C d) (y : Fin C) (x : Input d) : Prop :=
     ∀ b : Fin C, b ≠ y → f x b < f x y
   ```
   Then derive:
   ```lean
   theorem strictTopClass_on_ball ...
     : ∀ z, (∀ i, |z i - x i| ≤ r) → StrictTopClass (totalScore h s) y z
   ```
   This avoids the nuisance of choosing an `argmax`. If you later need an `argmax` theorem, prove it as a corollary under a deterministic tie-breaking definition.

5. **Derive the Hecke/Satake corollary by substituting the certified lower bound `Δ`.**  
   Use `hΔ : Δ a b x ≤ pairGap h a b x` to replace the unknown base gap by a computable tropical Satake certificate. This is exactly where the GL3 finite test-family separation enters: the theorem becomes a robustness certificate computable from Hecke score data rather than from the full network geometry.

### Key helper lemmas worth proving first

These will likely make the main proof much smoother:

```lean
lemma pairGap_add
    {C d : ℕ} (f g : ScoreVec C d) (a b : Fin C) (x : Input d) :
    pairGap (fun x c => f x c + g x c) a b x
      = pairGap f a b x + pairGap g a b x
```

```lean
lemma pairGap_sum
    {C d n : ℕ} (s : Fin n → ScoreVec C d) (a b : Fin C) (x : Input d) :
    pairGap (fun x c => ∑ i : Fin n, s i x c) a b x
      = ∑ i : Fin n, pairGap (s i) a b x
```

```lean
lemma abs_pairGap_le_of_logitwise
    {C d : ℕ} (f : ScoreVec C d) (L : ℝ) (x z : Input d) (a b : Fin C)
    (hf :
      ∀ c : Fin C, |f z c - f x c| ≤ L) :
    |pairGap f a b z - pairGap f a b x| ≤ 2 * L
```

This last lemma is the bridge from classwise logit Lipschitz bounds to the uniform pairwise budget theorem.

### Why this matters

This theorem is the correct next step for the program because it fuses two previously separate ideas:

- **Tropical/Hecke separation** gives finite, representation-theoretic certificates for pairwise class margins.
- **Residual-network decomposition** expresses a modern architecture as a stable additive perturbation of a base classifier.

The resulting theorem is stronger than a generic global Lipschitz certificate: it is **pairwise, branchwise, and certificate-aware**. It shows that tropical Satake margins are not merely static classification witnesses, but remain meaningful under compositional residual corrections. In particular, the theorem yields:
- a certified `L∞` radius for multiclass residual networks,
- a sharper radius when branchwise pairwise constants `K i a b` are available,
- a mathematically clean interface between GL3 tropical Hecke score functionals and neural robustness.

This gives a rigorous bridge from static tropical Hecke score classifiers to compositional multiclass ResNet-style architectures, and it does so in exactly the form needed for later top-`k`, ECOC, or one-vs-one extensions without depending on them now.
