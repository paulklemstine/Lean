## Assignment: Post-Quantum Lattices from Pythagorean Triple Groupoids

Mode: **prove** with a small **formalize** component and a necessary **counterexample-sensitivity check**.

You should not treat the cryptographic headline claim as already plausible. The right breakthrough here is to isolate a mathematically rigid, formally provable hardness-preserving structure arising from Berggren dynamics, and then reduce cryptographic security to that structure. If the full “SVP on Pythagorean lattices is as hard as general SVP” statement is too optimistic in this cycle, produce the strongest formally certified intermediate theorem that makes the conjecture scientifically credible: an explicit embedding/restriction theorem, a hardness-preserving family construction, and an entropy-based key security reduction built from the existing catalog.

The revolutionary point is not “Pythagorean triples in crypto.” It is to show that a classical arithmetic dynamical system — the Berggren generation of primitive triples — can be upgraded into a certified source of structured lattices whose geometry, orbit complexity, and entropy extraction support post-quantum constructions. This would open an unexpected bridge between Diophantine dynamics, lattice cryptography, symbolic dynamics, and certified formal cryptography.

### Core Definitions to Introduce

You likely need a clean formal object for Berggren-generated lattice families. Define these first.

1. A predicate for primitive Pythagorean triples:
```lean
def IsPrimitivePythagoreanTriple (x y z : ℤ) : Prop :=
  x^2 + y^2 = z^2 ∧ Int.gcd x y = 1 ∧ Int.gcd x z = 1 ∧ Int.gcd y z = 1
```

2. Berggren matrices as integer `3 × 3` matrices, and a reachability/orbit relation generated by them:
```lean
def berggrenA : Matrix (Fin 3) (Fin 3) ℤ := ...
def berggrenB : Matrix (Fin 3) (Fin 3) ℤ := ...
def berggrenC : Matrix (Fin 3) (Fin 3) ℤ := ...

inductive BerggrenReachable : (Fin 3 → ℤ) → (Fin 3 → ℤ) → Prop
| refl (v) : BerggrenReachable v v
| stepA {u v} : BerggrenReachable u v → BerggrenReachable u (berggrenA.mulVec v)
| stepB {u v} : BerggrenReachable u v → BerggrenReachable u (berggrenB.mulVec v)
| stepC {u v} : BerggrenReachable u v → BerggrenReachable u (berggrenC.mulVec v)
```

3. A lattice family generated from orbit vectors. For Lean tractability, prefer a finitely generated `Submodule ℤ (Fin n → ℤ)` or a `ZSpan` of a finite set of orbit vectors:
```lean
def berggrenOrbitSet (seed : Fin 3 → ℤ) (S : Finset (Fin 3 → ℤ)) : Prop := ...
def berggrenLattice (gens : Finset (Fin 3 → ℤ)) : Submodule ℤ (Fin 3 → ℤ) := Submodule.span ℤ (↑gens : Set (Fin 3 → ℤ))
```

4. A notion of norm-minimizing nonzero lattice vector:
```lean
def IsShortestVec {n : ℕ} (L : Submodule ℤ (Fin n → ℤ)) (v : Fin n → ℤ) : Prop :=
  v ∈ L ∧ v ≠ 0 ∧ ∀ w ∈ L, w ≠ 0 → ‖v‖ ≤ ‖w‖
```
If Euclidean norm over `ℤ` is awkward, use squared norm in `ℤ` or `ℕ`:
```lean
def sqNorm {n : ℕ} (v : Fin n → ℤ) : ℤ := ∑ i, v i ^ 2
```

### Precise Theorem Targets

Do not attempt the full average-case reduction in one leap. Prove the following sequence.

#### Theorem 1: Berggren action preserves primitiveness and the Pythagorean equation
This is the arithmetic backbone.

**Mathematical statement.**
For each Berggren matrix `M ∈ {A,B,C}`, if `v = (x,y,z)` is a primitive Pythagorean triple, then `Mv` is again a primitive Pythagorean triple.

**Lean target.**
```lean
theorem berggren_preserves_primitive_triple
  (M : Matrix (Fin 3) (Fin 3) ℤ)
  (hM : M = berggrenA ∨ M = berggrenB ∨ M = berggrenC)
  (v : Fin 3 → ℤ)
  (hv : IsPrimitivePythagoreanTriple (v 0) (v 1) (v 2)) :
  IsPrimitivePythagoreanTriple ((M.mulVec v) 0) ((M.mulVec v) 1) ((M.mulVec v) 2) := ...
```

This is not merely warm-up. It certifies that the orbit is not a heuristic sample but a rigid arithmetic dynamical system preserving a quadratic form.

#### Theorem 2: Orbit-generated vectors yield nontrivial full-rank lattice families
This turns arithmetic dynamics into actual lattice objects.

**Mathematical statement.**
Let `v₀ = (3,4,5)`. For any finite set of pairwise distinct Berggren orbit vectors of cardinality at least `n`, there exists an `n`-dimensional coordinate embedding whose integer span has rank `n`. In particular, Berggren orbits generate infinitely many non-isomorphic finitely generated lattices.

A more Lean-friendly version is to prove linear independence for a carefully chosen explicit finite family of orbit vectors.

**Lean target.**
```lean
theorem berggren_explicit_independent_family :
  ∃ (S : Finset (Fin 3 → ℤ)),
    S.card = 3 ∧
    (∀ v ∈ S, BerggrenReachable ![3,4,5] v) ∧
    LinearIndependent ℤ (fun i : Fin 3 => ((S.sort (by intro a b; exact decide)) i)) := ...
```

If sorting/indexing a `Finset` is annoying, replace with an explicit tuple of orbit vectors:
```lean
theorem berggren_three_orbit_vectors_independent :
  ∃ v₁ v₂ v₃ : Fin 3 → ℤ,
    BerggrenReachable ![3,4,5] v₁ ∧
    BerggrenReachable ![3,4,5] v₂ ∧
    BerggrenReachable ![3,4,5] v₃ ∧
    LinearIndependent ℤ ![v₁, v₂, v₃] := ...
```

This theorem is the bridge from groupoid orbit to lattice basis.

#### Theorem 3: Norm growth along Berggren branches gives a certified shortest-vector lower bound
This is the first nontrivial hardness-style geometric fact.

**Mathematical statement.**
Along any nontrivial Berggren orbit from `(3,4,5)`, the hypotenuse coordinate strictly increases; hence in any finite orbit-generated basis set containing the seed, every nonzero lattice vector not equal to a signed seed multiple has squared norm bounded below by a computable positive constant. This yields a certified nontrivial lower bound on shortest vectors in Berggren lattices.

**Lean target.**

```lean
  (hreach : BerggrenReachable v w)

  (w 2).natAbs > 5 := ...
```


#### Theorem 5: Hardness-preserving embedding theorem toward SVP universality
This is the bold theorem. If you can prove it, it is the cycle’s crown jewel.

**Mathematical statement.**
There exists a computable family of integer linear maps `Φ_n : (Fin n → ℤ) → (Fin N n → ℤ)` and Berggren-generated lattices `L_n^B` such that for every rank-`n` lattice basis `B`, `Φ_n` embeds `L(B)` into `L_n^B`, preserving nonzeroness and shortest-vector comparison up to an explicit approximation factor `C_n`. Consequently, an oracle solving exact or `γ_n`-approximate SVP on Berggren lattices yields a solver for general SVP with factor loss `C_n`.

A Lean-friendly first version is the restricted reduction:
```lean
theorem svp_reduction_to_berggren_family
  (n : ℕ) :
  ∃ N : ℕ,
  ∃ Φ : (Fin n → ℤ) →ₗ[ℤ] (Fin N → ℤ),
  ∃ C : ℕ,
    0 < C ∧
    ∀ v : Fin n → ℤ, v ≠ 0 →
      sqNorm (Φ v) ≤ C * sqNorm v := ...
```

Then strengthen to show image lands in a Berggren-generated lattice family:
```lean
theorem berggren_family_universal_embedding
  (n : ℕ) :
  ∃ N : ℕ,
  ∃ L : Submodule ℤ (Fin N → ℤ),
    BerggrenGenerated L ∧
    ∃ Φ : (Fin n → ℤ) →ₗ[ℤ] (Fin N → ℤ),
      Function.Injective Φ ∧
      ∀ v, Φ v ∈ L := ...
```

This theorem would be a genuine field-opening result: a universality principle for arithmetic-dynamical lattices.

### Proof Strategy Architecture

#### Strategy A: Arithmetic dynamics first, then geometry, then crypto
Most promising for this cycle.

1. **Formalize Berggren invariants exactly.**
   Compute `M.mulVec v` for `A,B,C`; verify preservation of `x^2 + y^2 = z^2` by direct ring normalization (`ring_nf`, `linarith` where possible) and prove gcd preservation using explicit matrix formulas and divisibility arguments.

2. **Extract geometric consequences from monotone orbit growth.**
   Show `z` strictly increases along nontrivial branches, then derive pairwise distinctness and norm separation for explicit orbit vectors. Use this to construct linearly independent finite families and nontrivial shortest-vector lower bounds.

3. **Layer entropy reduction on top of orbit combinatorics.**
   Model secrets as Berggren words of length `m`; count them exactly (`3^m`) and invoke `berggren_key_security_from_minEntropy` and `post_quantum_key_security_from_minEntropy` to obtain a clean post-quantum key-security theorem.

Why this is strongest: it aligns tightly with the current catalog, minimizes speculative complexity assumptions, and yields certified mathematics plus a real cryptographic reduction.

#### Strategy B: Quadratic-form and orthogonal-group viewpoint
Potentially deeper, especially if Strategy A stalls on gcd details.

1. View primitive triples as integer points on the isotropic cone of `Q(x,y,z) = x^2 + y^2 - z^2`.
2. Show Berggren matrices lie in an integral automorphism semigroup of `Q`; formalize preservation as `Mᵀ J M = J`.
3. Use quadratic-form machinery to characterize orbit-generated sublattices as structured submodules adapted to `Q`, then derive shortest-vector constraints from form invariance.

Why this is powerful: it reframes Berggren generation as arithmetic dynamics on a Lorentzian lattice, opening connections to automorphic forms and reduction theory. It may also produce the right language for eventual worst-case/average-case reductions.

#### Strategy C: Symbolic dynamics and expander-style hardness heuristics
Best for FUTURE_DIRECTIONS if exact reduction is premature.

1. Treat Berggren words as a regular language over `{A,B,C}` and define a public map from words to orbit vectors/lattice bases.
2. Prove collision resistance properties for bounded-depth truncations or injectivity on reduced words.
3. Use combinatorial growth plus entropy extraction to obtain average-case hardness statements and quantum query lower bounds via `post_quantum_grover_lower_bound`.

Why this matters: it turns Berggren generation into a certified structured random source, connecting to expander graphs, symbolic dynamics, and derandomized cryptography.

### Cross-Domain Connections You Should Exploit

1. **Quadratic forms / arithmetic groups**  
   Berggren matrices preserve the cone `x^2 + y^2 = z^2`; this is really a discrete dynamical system inside an integral orthogonal group. If formalized, this links Pythagorean generation to reduction theory and arithmetic geometry.

2. **Geometry of numbers / lattice cryptography**  
   The central cryptographic insight should be that orbit-generated bases are not ad hoc number-theoretic curiosities but a structured lattice ensemble with certifiable norm growth and entropy.

3. **Symbolic dynamics / automata**

4. **Information theory / extractor-based security**

### Counterexample Sensitivity

Be intellectually ruthless about the strongest claim:
> “SVP on Pythagorean lattices is as hard as general SVP.”

This may be false if the Berggren-generated family is too rigid or too sparse among all lattices. If a full reduction seems structurally impossible, prove one of these instead:

1. **Universality for a broad subclass**  
   e.g. every diagonal or every orthogonally decomposable integer lattice embeds into a Berggren-generated family.

2. **Approximation-preserving hardness for a restricted SVP class**  
   e.g. exact SVP on a natural subclass reduces to approximate SVP on Berggren lattices.

3. **Distributional hardness**  
   average-case shortest-vector search over random Berggren path lattices is at least as hard as recovering the path word.

A well-constructed counterexample or obstruction theorem would itself be valuable:
```lean
theorem not_every_lattice_is_berggren_generated :
  ∃ (n : ℕ) (L : Submodule ℤ (Fin n → ℤ)),
    ¬ BerggrenGenerated L := ...
```
If true, this clarifies the right universality statement and prevents wasted effort.
