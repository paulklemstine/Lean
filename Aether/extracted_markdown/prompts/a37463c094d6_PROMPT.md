# Research Direction
# Tropical Brill–Noether Theory via Crystal Structures on CDPR Paths

The existing conjectural picture is already profound: CDPR paths on chains of loops appear to organize tropical Brill–Noether loci, while Kashiwara/Littelmann crystals organize highest-weight representations of `sl_{r+1}`. If these are the same combinatorial object in disguise, then tropical divisor theory is not merely analogous to representation theory — it *is* a representation-theoretic machine. That would turn tropical Brill–Noether counts into weight multiplicities, Kostka-type numbers, and crystal characters.

Your immediate target should therefore be a theorem that is both formalizable and unmistakably structural: not “there exists some counting coincidence,” but “the CDPR path set admits explicit partial crystal operators satisfying real crystal axioms on a nontrivial regime.”

## Primary Theorem Target: rank-1 crystal structure on CDPR paths

Focus first on the first nontrivial case `r = 1`, where the relevant Lie algebra is `sl₂`. In this regime, a full crystal structure should be accessible and already revolutionary, because it converts tropical Brill–Noether path combinatorics into a certified highest-weight crystal.

### Precise theorem statement

Let `CDPRPath g d` denote the finite set of valid CDPR paths for chains of `g` loops and degree `d` in rank `r = 1`, in the standard lattice-path encoding where a path is a walk of length `g` in `ℕ` with admissible steps determined by the CDPR condition. Define the weight of a path by endpoint displacement, and define crystal operators `e, f` by the usual `sl₂` signature rule on the step word induced by the path.

**Theorem (sl₂ crystal theorem for CDPR paths).**  
For every `g d : ℕ`, the finite type `CDPRPath g d` admits maps
- `e : CDPRPath g d → Option (CDPRPath g d)`
- `f : CDPRPath g d → Option (CDPRPath g d)`
- `wt : CDPRPath g d → ℤ`

such that:

1. `e` and `f` preserve validity of CDPR paths.
2. For all `p q`, `e p = some q ↔ f q = some p`.
3. If `e p = some q`, then `wt q = wt p + 2`.
4. If `f p = some q`, then `wt q = wt p - 2`.
5. Defining
   - `ε(p) = max { n | e^[n] p ≠ none }`
   - `φ(p) = max { n | f^[n] p ≠ none }`,
   one has the `sl₂` crystal identity
   `φ(p) - ε(p) = wt(p)`.
6. Every connected component of the graph generated by `e,f` is a finite `sl₂`-string with a unique highest-weight vertex.

This should be formalized as an explicit combinatorial crystal on the CDPR path set, not merely as an abstract existence statement.

## Secondary theorem target: a rigorous partial `sl_{r+1}` statement

If the full `sl_{r+1}` crystal is too ambitious in one cycle, prove a theorem that certifies the first nontrivial crystal axioms for general `r`.

### Precise theorem statement

For fixed `r ≥ 0`, let `CDPRPath g r d` be the set of valid CDPR paths valued in the Weyl chamber
`{ x : ℤ^r | x₁ > x₂ > ... > x_r > 0 }`
with the standard CDPR admissibility rules. Define candidate operators `e_j, f_j` for `j : Fin r` by local signature cancellation in coordinates `j, j+1`.

**Theorem (partial type-A crystal structure).**  
For every `g r d : ℕ`, the candidate operators `e_j, f_j` preserve the set of valid CDPR paths whenever defined, and satisfy partial inverse and weight-shift axioms:
- `e_j p = some q ↔ f_j q = some p`,
- `wt q = wt p + α_j` under `e_j`,
- `wt q = wt p - α_j` under `f_j`.

Here `wt` lands in the type-A weight lattice and `α_j` is the `j`th simple root.

### Lean 4 type signature target

```lean
def Weight (r : ℕ) := Fin r → ℤ

def crystalE (j : Fin r) : CDPRPath g r d → Option (CDPRPath g r d) := ...
def crystalF (j : Fin r) : CDPRPath g r d → Option (CDPRPath g r d) := ...
def wt : CDPRPath g r d → Weight r := ...
def simpleRoot (j : Fin r) : Weight r := ...

theorem cdpr_partial_typeA_crystal
    (g r d : ℕ) (j : Fin r) :
    (∀ p q, crystalE (g:=g) (r:=r) (d:=d) j p = some q ↔
            crystalF (g:=g) (r:=r) (d:=d) j q = some p) ∧
    (∀ p q, crystalE (g:=g) (r:=r) (d:=d) j p = some q →
            wt q = wt p + simpleRoot j) ∧
    (∀ p q, crystalF (g:=g) (r:=r) (d:=d) j p = some q →
            wt q = wt p - simpleRoot j)
```

This would be a major formal milestone even without the full Kashiwara package.

## Proof strategy architecture

### Strategy A: Direct signature-rule crystal on step words
This is the most promising route.

1. **Encode each CDPR path as a finite word in a step alphabet**  
   Reduce the geometric path validity conditions to combinatorial constraints on a word/list. For `r = 1`, this should collapse to a ballot/Dyck-like path condition or a bounded walk condition.

2. **Define `e,f` via unmatched-signature cancellation**  
   Use the standard `sl₂` crystal recipe: map steps to `+`/`-` symbols, cancel adjacent `-+` pairs, and modify the leftmost/rightmost unmatched symbol. This is robust in Lean because it is finite, list-based, and algorithmic.

3. **Prove preservation of CDPR validity**  
   This is the key new mathematics. Show that the signature modification never violates the CDPR inequalities. The proof should isolate a monotonicity lemma: changing the distinguished unmatched step modifies all future heights in a controlled way and preserves nonnegativity/chamber conditions.

Why this is best: it directly imports crystal technology into the exact combinatorial object already used in tropical Brill–Noether theory. It is constructive, finite, and ideal for Lean.

---

### Strategy B: Transport of structure from a known tableau/Littelmann model
This is conceptually elegant if you can identify an explicit bijection.

1. **Construct a bijection from CDPR paths to a classical `sl₂` crystal model**  
   For `r = 1`, this may be semistandard tableaux of two-row shape, ballot words, or restricted Littelmann paths.

2. **Pull back crystal operators**  
   Define `e,f` on CDPR paths by conjugating the classical operators through the bijection.

3. **Use the certified crystal theorem on the target model**  
   Then only the bijection and transport lemmas need to be formalized.

Why it may work: if catalog theorems already identify CDPR paths with lattice paths counted by a known character formula, this route compresses the hard axioms into the bijection.  
Why it may be harder: Lean formalization of tableaux/Littelmann models may require more infrastructure than a direct word model.

---

### Strategy C: Chip-firing dynamics as root operators
This is the boldest and most original route.

1. **Interpret a CDPR path as a reduced-divisor evolution along the chain of loops**  
   Each path step corresponds to local chip-firing data.

2. **Define `e,f` as local chip transfers preserving linear equivalence class constraints**  
   Show that these local moves correspond to adding/removing one simple root’s worth of combinatorial charge.

3. **Prove the path encoding intertwines chip-firing operators with signature operators**  
   This yields a geometric realization of the crystal.

Why it matters: this is the route that would make experts say “I never thought of that connection.” It ties Kashiwara operators directly to divisor-theoretic dynamics.  
Why it is risky: it demands more original infrastructure and may be better as a follow-on theorem after Strategy A succeeds.

## Cross-domain connections to exploit

### 1. Tropical geometry × quantum groups
The crystal graph viewpoint suggests that tropical Brill–Noether loci are shadows of representation-theoretic moduli. This is the central conceptual bridge.

### 2. Chip-firing × statistical mechanics
Signature cancellation resembles annihilation of particles in one-dimensional solvable models. If the path operators admit local energy statistics, this could connect to box-ball systems and integrable combinatorics.

### 3. Brill–Noether theory × Schubert calculus
Highest-weight multiplicities and Kostka numbers are Schubert-theoretic invariants. A crystal model for CDPR paths would imply that tropical divisor counts are governed by the same combinatorics as intersections in Grassmannians.

### 4. Tropical linear algebra × divisor rank
If the crystal theorem lands, revisit the chip-distance matrix conjecture: weights and crystal strings may control tropical matrix rank bounds, offering a new representation-theoretic certificate for Baker–Norine rank.

### 5. Formalized mathematics × combinatorial representation theory
Lean currently has much stronger infrastructure for finite combinatorics than for tropical geometry. This project uses tropical geometry as the source of a finite combinatorial object that can be completely certified.

## If the full conjecture fails

A counterexample is also valuable science. In particular, test whether:

- the naive signature operators fail to preserve validity for some `(g,r,d)`;
- the path cardinalities fail to match any plausible type-A character;
- only a *subcrystal* of CDPR paths is stable;
- one needs an affine crystal, Demazure crystal, or truncated crystal rather than a full highest-weight crystal.

If failure occurs, isolate the smallest counterexample and prove a replacement theorem identifying the exact obstruction. A theorem of the form “valid CDPR paths form a Demazure truncation but not a full highest-weight crystal” would still be field-opening.
