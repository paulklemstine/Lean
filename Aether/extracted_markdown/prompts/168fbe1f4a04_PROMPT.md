## Research Task: Berggren semigroup cancellation and left-divisibility order for the SL₂(ℤ) SPB embedding

Research Mode: PROVE

Work in the concrete semigroup of integer `2 × 2` matrices generated by the already-formalized Berggren/SPB generators. Let `α` denote the finite generator alphabet already used in the freeness development, let `FreeSemigroup α` be the nonempty free semigroup on `α`, and let
```lean
φ : FreeSemigroup α →* Matrix (Fin 2) (Fin 2) ℤ
```
be the verified semigroup homomorphism into `SL₂(ℤ)`-valued matrices, with image equal to the Berggren semigroup `S`. Use the established facts that `φ` is injective/faithful on words and that elements of `S` admit unique normal forms.

Your goal is to upgrade freeness into an internal divisibility/cancellation theory on the matrix semigroup itself, and then connect the resulting prefix structure to the SPB finite-field cryptographic model.

Prove the following nontrivial results, with exact Lean-style signatures as close as possible to the existing development.

### 1. Left and right cancellation transported from free semigroup normal forms
```lean
theorem berggren_left_cancel
    {A B C : BerggrenSg} :
    A * B = A * C → B = C

theorem berggren_right_cancel
    {A B C : BerggrenSg} :
    B * A = C * A → B = C
```
A matrix-level unbundled variant is also acceptable:
```lean
theorem berggren_left_cancel'
    {a b c : FreeSemigroup α} :
    φ (a * b) = φ (a * c) → b = c

theorem berggren_right_cancel'
    {a b c : FreeSemigroup α} :
    φ (b * a) = φ (c * a) → b = c
```
followed by transport to the image subtype.

### 2. Left-divisibility and right-divisibility are partial orders on the Berggren semigroup
```lean
theorem leftDivides_refl (A : BerggrenSg) : LeftDivides A A
theorem leftDivides_trans {A B C : BerggrenSg} :
    LeftDivides A B → LeftDivides B C → LeftDivides A C
theorem leftDivides_antisymm {A B : BerggrenSg} :
    LeftDivides A B → LeftDivides B A → A = B

instance : PartialOrder BerggrenSg where
  le := LeftDivides
  le_refl := leftDivides_refl
  le_trans := by ...
  le_antisymm := by ...
```
and similarly, if convenient, for right-divisibility:
```lean
theorem rightDivides_antisymm {A B : BerggrenSg} :
    RightDivides A B → RightDivides B A → A = B
```

Because the semigroup is non-unital/nonempty-word based, antisymmetry is the subtle point: if `B = A * X` and `A = B * Y`, then in normal forms one gets `wB = wA ++ x` and `wA = wB ++ y`, forcing `x` and `y` to be empty in the ambient free monoid picture, or equivalently forcing impossible strict length growth in the free semigroup. Formalize this via the existing normal form and a length argument on representatives.

### 3. Exact correspondence between left divisibility and prefix order
Define the normal form map
```lean
def nf : BerggrenSg → FreeSemigroup α
```
using the inverse to the faithful embedding / unique decomposition theorem already established, together with
```lean
theorem nf_spec (A : BerggrenSg) : φ (nf A) = A.1
```
and uniqueness
```lean
theorem nf_unique {A : BerggrenSg} {w : FreeSemigroup α} :
    φ w = A.1 → w = nf A
```

Then define a word-prefix relation on `FreeSemigroup α`. If the library already uses a relation induced from lists, reuse it; otherwise define:
```lean
def IsPrefixFS (u v : FreeSemigroup α) : Prop := ∃ t : FreeSemigroup α, v = u * t
```
or, if you choose to pass through list normal forms, use the corresponding list-prefix notion after converting nonempty words to lists.

Main transport theorem:
```lean
theorem leftDivides_iff_prefix (A B : BerggrenSg) :
    LeftDivides A B ↔ IsPrefixFS (nf A) (nf B)
```
and dually
```lean
theorem rightDivides_iff_suffix (A B : BerggrenSg) :
    RightDivides A B ↔ IsSuffixFS (nf A) (nf B)
```
where `IsSuffixFS u v := ∃ t, v = t * u`.

A stronger and very useful formulation is:
```lean
theorem leftDivides_iff_exists_nf_factor (A B : BerggrenSg) :
    LeftDivides A B ↔ ∃ t : FreeSemigroup α, nf B = nf A * t
```
This should become the workhorse lemma for order-theoretic arguments.

### 4. Greatest lower bound = longest common prefix in normal form
Define a longest common prefix operation on normal forms. If direct recursion on `FreeSemigroup α` is awkward, define it first on nonempty lists and then transport back to `FreeSemigroup α` where appropriate. A practical interface is:
```lean
def lcpWord : FreeSemigroup α → FreeSemigroup α → FreeSemigroup α
```
or, if the common prefix may be empty and the semigroup has no identity, define instead an option-valued/common-prefix-in-list object:
```lean
def lcpList : List α → List α → List α
```
and only state the semigroup meet theorem for pairs with nonempty common prefix, while also proving a more general list-level theorem.

The strongest desirable matrix-level theorem is:
```lean
theorem exists_inf_leftDivides (A B : BerggrenSg) :
    ∃ G : BerggrenSg,
      LeftDivides G A ∧ LeftDivides G B ∧
      ∀ H : BerggrenSg, LeftDivides H A → LeftDivides H B → LeftDivides H G
```
together with identification by normal form:
```lean
theorem nf_inf_eq_lcp (A B : BerggrenSg) (G : BerggrenSg)
    (hG : LeftDivides G A ∧ LeftDivides G B ∧
          ∀ H : BerggrenSg, LeftDivides H A → LeftDivides H B → LeftDivides H G) :
    IsLongestCommonPrefix (nf G) (nf A) (nf B)
```
If the lack of identity makes a global meet awkward when the common prefix is empty, it is acceptable and mathematically cleaner to prove the semigroup-valued meet theorem only on the comparable/nontrivial-common-prefix fragment, and separately prove a list-level longest-common-prefix theorem:
```lean
theorem common_prefixes_of_A_B_form_chain
theorem lcpList_is_greatest_common_prefix
```
Then derive a decidable gcd-like operation:
```lean
def commonPrefix? : BerggrenSg → BerggrenSg → Option BerggrenSg
```
with correctness theorem saying that `some G` is returned exactly when the longest common prefix is nonempty, and in that case `G` is the greatest lower bound for `LeftDivides`.

### 5. Decidability and algorithmic extraction
Use the normal form equivalence to prove the order is decidable:

```lean
instance instDecidableLeftDivides : DecidableRel LeftDivides
```

```lean
theorem decide_leftDivides_via_nf (A B : BerggrenSg) :
    decide (LeftDivides A B) = decide (IsPrefixFS (nf A) (nf B))
```

or an equivalent proposition-level statement.

Also prove uniqueness of left quotient:
```lean
theorem left_quotient_unique
    {A B C D : BerggrenSg} :
    B = A * C → B = A * D → C = D
```
and similarly on the right. This is the algorithmic core behind prefix recovery.

### 6. Prefix-recovery reduction to exponent/discrete-log style recovery in the finite-field image
Assume the already-developed SPB finite-field model provides a homomorphic image
```lean
ψ : BerggrenSg →* G
```
into a finite semigroup/group/subgroup `G`, with the cryptographic public key associated to `ψ A`. Formulate a clean oracle-reduction theorem at the level of abstract algebra first, then specialize to the SPB setting.

A precise abstract reduction theorem could be:
```lean
theorem prefix_recovery_reduces_word_recovery
    (O : G → G → Option (FreeSemigroup α))
    (hO : ∀ A B : BerggrenSg,
      O (ψ A) (ψ B) = some w →
      w = nf A ∨ w = nf B ∨ IsPrefixFS w (nf A) ∧ IsPrefixFS w (nf B)) :
    ...
```
But this is still too weak. Prefer a theorem stating that an oracle returning the exact common prefix in the image model yields exact recovery of exponents/words for comparable instances. For example:
```lean
theorem comparable_prefix_oracle_recovers_suffix_secret
    (O : G → G → Option (FreeSemigroup α))
    (hO : ∀ A B : BerggrenSg,
      O (ψ A) (ψ B) = some (lcpWord (nf A) (nf B))) :
    ∀ A B : BerggrenSg,
      LeftDivides A B →
      ∃ t : FreeSemigroup α, nf B = nf A * t ∧
        O (ψ A) (ψ B) = some (nf A)
```
Then combine this with the unique quotient theorem to show that an oracle for prefix extraction recovers the hidden suffix/exponent word:
```lean
theorem prefix_oracle_yields_secret_suffix
    (O : G → G → Option (FreeSemigroup α))
    (hO : ∀ A B : BerggrenSg,
      O (ψ A) (ψ B) = some (lcpWord (nf A) (nf B))) :
    ∀ A T : BerggrenSg,
      ∃! U : FreeSemigroup α, nf (A * T) = nf A * U
```
and therefore the “secret exponent”/suffix is uniquely determined and extractable from the decomposition.

If the finite-field layer already has a discrete-log-style exponent representation for powers of a distinguished generator, state and prove a sharper specialization:
```lean

    (g : G)
    (encode : ℕ → BerggrenSg)
    (hencode : ∀ m n, encode (m + n) = encode m * encode n)
    (hψ : ∀ n, ψ (encode n) = g ^ n)
    (O : G → Option ℕ)
    (hO : ∀ n, O (g ^ n) = some n) :

```
This toy signature is too weak as written; replace `True` by an actual reduction statement in your concrete model. The point is to prove a mathematically rigorous implication:
- exact recovery of prefixes/common prefixes in the Berggren image
- plus faithfulness/unique decomposition
- implies exact recovery of the hidden suffix word
- and in one-parameter subgroup specializations, exact recovery of the exponent.

The reduction need not be computational-complexity-theoretic; a clean theorem of logical reducibility/functional reconstruction is enough:
```lean

```

## Proof strategy

1. **Transport cancellation from freeness through injectivity.**  
   For words `a b c : FreeSemigroup α`, prove
   ```lean
   φ (a * b) = φ (a * c) → b = c
   ```
   by applying injectivity of `φ` to get `a * b = a * c`, then using left cancellation in the free semigroup. Do the analogous right-cancellation theorem. After that, descend to `BerggrenSg` by choosing normal forms / preimages for subtype elements and rewriting with `Subtype.ext`.

2. **Characterize divisibility by factorization of normal forms.**  
   Prove
   ```lean
   LeftDivides A B ↔ ∃ t, nf B = nf A * t
   ```
   by expanding `LeftDivides`, pulling the factorization back along `nf_spec`, and using `nf_unique` plus homomorphism laws. This lemma is the key bridge from matrices to combinatorics on words.

3. **Prove antisymmetry using word length monotonicity.**  
   From `A ≤ B` and `B ≤ A`, obtain
   ```lean
   nf B = nf A * x
   nf A = nf B * y
   ```
   hence
   ```lean
   length (nf A) < length (nf A) + ...
   ```
   unless both factors are empty. Since `FreeSemigroup α` has no empty word, the only way both divisibilities hold is equality. If your normal forms are represented via nonempty lists, this becomes a straightforward arithmetic contradiction on list lengths. This is the nontrivial heart of the partial-order theorem.

4. **Construct longest common prefix and prove its universal property.**  
   Define LCP recursively on list representatives:
   - if heads match, recurse on tails;
   - otherwise stop.
   Show it is a prefix of each input and that any common prefix is a prefix of it. Then transport back to `FreeSemigroup α`/`BerggrenSg` via the normal form equivalence. This yields the greatest lower bound theorem for `LeftDivides` whenever the common prefix is nonempty, and an `Option`-valued algorithm in general.

5. **Derive decidability and oracle reductions from unique quotients.**  
   Since `LeftDivides A B` is equivalent to a decidable prefix test on `nf A`, `nf B`, decidability is immediate. Then use the exact-prefix characterization plus left quotient uniqueness to show that any oracle revealing the common prefix of two public images determines the hidden suffix uniquely; in comparable instances this is exactly the “secret exponent word”. If your SPB finite-field model has a one-generator encoding, specialize this to an exponent-recovery statement.

## Significance

This result materially strengthens the Berggren/SPB program. Freeness and faithfulness alone show that distinct words give distinct matrices, but they do not yet expose the internal algebraic geometry of the image semigroup. Cancellation and divisibility order do exactly that: they show the Berggren image behaves like a rigid positive monoid with a canonical prefix calculus, not merely as an injective copy of syntax inside `SL₂(ℤ)`.

That matters for three reasons:

1. **Structural algebra:** it identifies the intrinsic order theory of the matrix semigroup and turns unique normal forms into an actual semigroup divisibility theory.
2. **Algorithmics:** it yields a decidable, computable gcd-like common-prefix operation on matrix products, which is the right algebraic primitive for decomposition and parsing problems.
3. **Cryptographic semantics:** it sharpens the SPB Diffie–Hellman embedding story by proving that prefix/common-prefix information in the finite-field image is already enough to reconstruct hidden word/exponent structure. This isolates exactly what algebraic information must remain hidden for security, and it does so in a theorem that is independent of implementation details.

The best outcome is a small cluster of reusable lemmas:
- cancellation on `BerggrenSg`,
- divisibility ↔ prefix/suffix,
- decidable left/right divisibility,
- longest-common-prefix universal property,
- uniqueness of quotients,
- a clean oracle-reduction theorem from prefix recovery to secret-word/exponent recovery.

These will make the Berggren semigroup usable as a serious algebraic object in later SPB and crypto developments, rather than merely as a faithful encoding.
