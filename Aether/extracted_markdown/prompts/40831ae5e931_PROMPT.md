## Theorem 1: Exceptional orbit relation forces finite-prime collision coherence

Work first in a finite dynamical model, then lift the interpretation to reductions mod `p`.

### Mathematical statement
If two marked critical seeds satisfy an algebraic orbit relation over `ℚ`, then for every good prime outside a finite exceptional set, the same iterate relation holds after reduction modulo `p`. Consequently any reduced combinatorial invariant built functorially from equality/collision of these iterates is eventually constant across primes.

For an explicit family like `f_c(x)=x^2+c`, the marked critical seed is `0`, and exceptional relations are preperiodicity relations
`f^[m](0) = f^[n](0)` with `m ≠ n`.

### Lean 4 formal target
A finite-model theorem you can actually prove:

```lean
theorem invariant_of_iterate_relation
    {α β : Type*} [Fintype α] [DecidableEq α] [DecidableEq β]
    (f : α → α) (a : α) (m n : ℕ)
    (hrel : (f^[m]) a = (f^[n]) a)
    (K : α → β)
    (hK : ∀ x y, x = y → K x = K y) :
    K ((f^[m]) a) = K ((f^[n]) a) := by
```

But this alone is too easy; the real theorem should be stronger:

```lean
theorem eventual_periodic_of_iterate_relation
    {α : Type*} [Fintype α] [DecidableEq α]
    (f : α → α) (a : α) (m n : ℕ)
    (h : m < n)
    (hrel : (f^[m]) a = (f^[n]) a) :
    ∀ k : ℕ, (f^[(m + k)]) a = (f^[(n + k)]) a := by
```

This theorem is nontrivial enough to require induction on `k` and gives the mechanism for persistent synchronization: once a collision occurs, all later layers synchronize.

### Why this matters
This is the dynamical skeleton of the adelic conjecture. Exceptional algebraic relations are not isolated coincidences; they propagate through all later orbit layers, so any filtration/barcode built from collision depth must show a rigid synchronized signature.

## Theorem 2: Collision relations induce graph-filtration/barcode surrogate stability

Define a combinatorial filtration from orbit prefixes, collision graph layers, or merging times of marked orbit branches. Then prove that an iterate relation determines equality of the filtration above a threshold. This is your rigorous TDA bridge.

### Suggested definition
For `f : α → α` and marked seeds `a b`, define the level-`N` collision profile as the finite set of pairs `(i,j)` with `i,j ≤ N` and `(f^[i]) a = (f^[j]) b`. Or define a layer function:
`L(N) = true` iff a collision occurs by time `N`.

### Lean 4 target
```lean
def collisionProfile {α : Type*} [DecidableEq α]
    (f : α → α) (a b : α) (N : ℕ) : Finset (ℕ × ℕ) :=
  (Finset.range (N+1)).product (Finset.range (N+1)) |>.filter
    (fun ij => (f^[ij.1]) a = (f^[ij.2]) b)

theorem collisionProfile_monotone
    {α : Type*} [DecidableEq α]
    (f : α → α) (a b : α) :
    Monotone (collisionProfile f a b) := by
```

A stronger and more interesting theorem:

```lean
theorem collisionProfile_stabilizes_after_relation
    {α : Type*} [Fintype α] [DecidableEq α]
    (f : α → α) (a : α) (m n : ℕ)
    (h : m < n)
    (hrel : (f^[m]) a = (f^[n]) a) :
    ∀ N ≥ n, collisionProfile f a a (N + (n - m)) =
             transportProfileShift (n - m) (collisionProfile f a a N) := by
```

You may replace `transportProfileShift` by a simpler explicit statement if needed, for example that all collision data beyond level `n` is periodic with period `n-m`.

Even more feasible and still deep:

```lean
theorem periodic_collision_indicator
    {α : Type*} [Fintype α] [DecidableEq α]
    (f : α → α) (a : α) (m n : ℕ)
    (h : m < n)
    (hrel : (f^[m]) a = (f^[n]) a) :
    ∀ k : ℕ,
      ((∃ i ≤ m + k, ∃ j ≤ m + k, (f^[i]) a = (f^[j + (n - m)]) a) ↔
       (∃ i ≤ m + k, ∃ j ≤ m + k, (f^[i]) a = (f^[j]) a)) := by
```

### Why this matters
This is the point where arithmetic dynamics touches topological data analysis. You are proving that exceptional orbit relations produce **structural stability in a filtration**, not just a one-time equality. That is exactly what a barcode phase transition is supposed to detect.

## Theorem 3: High synchronization implies a repeated invariant value

This theorem is purely combinatorial/information-theoretic and should be proved in full generality over finite prime sets. It supplies the “order parameter” mathematics.

### Mathematical statement
If a finite family of prime-indexed invariants has sufficiently high pairwise agreement score, then some invariant value occurs with large multiplicity. This is a finite Ramsey/pigeonhole synchronization theorem. It turns pairwise alignment into a genuine majority cluster.

### Lean 4 target
```lean
theorem exists_large_fiber_of_high_sync
    {ι β : Type*} [Fintype ι] [DecidableEq ι] [DecidableEq β]
    (x : ι → β) (T : ℕ)
    (hT : T ≤ primeSyncScore x) :
    ∃ b : β, ∃ s : Finset ι,
      (∀ i ∈ s, x i = b) ∧
      T ≤ s.card * s.card := by
```

A sharper version, if manageable:

```lean
theorem syncScore_le_sum_sq_fibers
    {ι β : Type*} [Fintype ι] [DecidableEq ι] [DecidableEq β]
    (x : ι → β) :
    primeSyncScore x ≤ ∑ b in Finset.univ.image x, (Finset.univ.filter (fun i => x i = b)).card ^ 2 := by
```

Then deduce a corollary:

```lean
theorem high_sync_yields_majority_value
    {ι β : Type*} [Fintype ι] [DecidableEq ι] [DecidableEq β]
    (x : ι → β)
    (h : (Fintype.card ι)^2 / 2 ≤ primeSyncScore x) :
    ∃ b : β, (Finset.univ.filter (fun i => x i = b)).card * 2 ≥ Fintype.card ι := by
```

### Why this matters
This theorem converts an empirical “high mutual information across primes” phenomenon into a rigorous finite statement: synchronization means many primes are genuinely seeing the same invariant. It is the information-theoretic backbone of the adelic threshold idea.

### Strategy A: Finite orbit pigeonhole + iterate propagation
1. Prove any orbit in a finite type repeats within `card α + 1` steps.

### Strategy B: Quotient-by-eventual-equivalence and graph dynamics

**Why promising:** This creates a stronger conceptual bridge to persistent homology and graph theory. It is more ambitious, but if executed, it makes the work feel genuinely new rather than merely combinatorial.

3. Deduce existence of a large synchronized cluster from high global score.

**Why promising:** This is the cleanest route for the information-theoretic component. It gives an abstract theorem applicable far beyond dynamics.

Recommended overall plan: **A + C**, with as much of **B** as you can make robust.
