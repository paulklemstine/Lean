## YOUR ASSIGNMENT: Constructive prime witness extraction for non-derivability in closure-generated proof semirings via finite spectral search

### Core formalization target

Work in a **finite decidable closure system** first, and only then lift to any semiring-flavored or proof-theoretic structure already present in the library. The essential theorem is not about syntax but about **constructive spectral separation** in a finite closure lattice.

You should introduce a concrete bundled finite closure operator, so the prime-separation theorem is stated over explicit data and is executable.

A robust Lean 4 starting point is:

```lean
import Mathlib.Data.Finset.Basic
import Mathlib.Data.Set.Lattice
import Mathlib.Order.CompleteLattice
import Mathlib.Order.Zorn
import Mathlib.Data.Fintype.Basic

open Set

structure FiniteClosureSystem (α : Type*) [Fintype α] [DecidableEq α] where
  cl : Set α → Set α
  mono_cl : Monotone cl
  extensive : ∀ s, s ⊆ cl s
  idempotent : ∀ s, cl (cl s) = cl s
  cl_empty : cl ∅ = ∅
  cl_union : ∀ s t, cl (s ∪ t) = cl (cl s ∪ cl t)
```

Then define closed theories and primality at the level of closed sets:

```lean
structure Theory (C : FiniteClosureSystem α) where
  carrier : Set α
  is_closed : C.cl carrier = carrier

instance (C : FiniteClosureSystem α) : SetLike (Theory C) where
  coe T := T.carrier
  coe_injective' := by
    intro A B h; cases A; cases B; cases h; rfl

def Theory.le (K P : Theory C) : Prop := (K : Set α) ⊆ (P : Set α)

instance (C : FiniteClosureSystem α) : LE (Theory C) := ⟨Theory.le⟩

def theoryJoin (C : FiniteClosureSystem α) (K L : Theory C) : Theory C :=
  ⟨C.cl ((K : Set α) ∪ (L : Set α)), C.idempotent _⟩

def IsPrimeTheory (C : FiniteClosureSystem α) (P : Theory C) : Prop :=
  ∀ K L : Theory C, theoryJoin C K L ≤ P → K ≤ P ∨ L ≤ P
```

The semiprime condition should be defined by intersection of prime extensions, or equivalently by the radical-style separation property. In the finite setting, the latter is more useful constructively:

```lean
def SemiprimeTheory (C : FiniteClosureSystem α) (K : Theory C) : Prop :=
  ∀ a : α, a ∉ (K : Set α) →
    ∃ P : Theory C, IsPrimeTheory C P ∧ K ≤ P ∧ a ∉ (P : Set α)
```

This makes the main theorem directly the witness-extraction theorem. After that, prove the representation theorem saying semiprime theories are exactly intersections of prime extensions.

### The real breakthrough statement

Do not stop at mere existence. The mathematically decisive theorem is:

> In a finite decidable closure-generated proof semantics, non-derivability is not only semantically witnessed by a prime theory; it is witnessed by a **computably minimal prime extension** obtained by finite search in the closed-set lattice.

Formalize this as a minimization principle over all prime extensions avoiding `a`. One clean finite statement is:

```lean
def Avoids (a : α) (P : Theory C) : Prop := a ∉ (P : Set α)

def PrimeExtensionsAvoiding (C : FiniteClosureSystem α) (K : Theory C) (a : α) : Finset (Theory C) := ...

def minimalPrimeWitness
    (C : FiniteClosureSystem α) [Fintype α] [DecidableEq α]
    (K : Theory C) (a : α) : Option (Theory C) := ...

theorem minimalPrimeWitness_is_least
    (C : FiniteClosureSystem α) [Fintype α] [DecidableEq α]
    (K : Theory C) (a : α) :
    SemiprimeTheory C K →
    a ∉ (K : Set α) →
    ∃ P, minimalPrimeWitness C K a = some P ∧
      IsPrimeTheory C P ∧ K ≤ P ∧ a ∉ (P : Set α) ∧
      ∀ Q : Theory C, IsPrimeTheory C Q → K ≤ Q → a ∉ (Q : Set α) → P ≤ Q
```

If “least” is too strong for your chosen ordering, weaken to **minimal under inclusion** and implement witness extraction by searching all closed supersets and selecting one with no smaller competitor.

### Concrete proof strategy

#### Strategy A: maximal avoiding extension, then prove maximal implies prime
This is the most promising route in the finite setting because it avoids classical Zorn and turns separation into an explicit finite search.

1. Define the family of closed theories extending `K` and avoiding `a`:
   ```lean
   def AvoidingExtensions (C : FiniteClosureSystem α) (K : Theory C) (a : α) : Set (Theory C) :=
     {P | K ≤ P ∧ a ∉ (P : Set α)}
   ```
   Prove it is finite by `Fintype` on `Theory C` or by embedding theories into `Finset α`.

2. Show that if `a ∉ K`, then `K` itself belongs to `AvoidingExtensions C K a`, so the search space is nonempty.

3. Extract an inclusion-maximal element `P` of `AvoidingExtensions C K a`. In Lean, the easiest route is often:
   - enumerate all theories as a `Finset (Theory C)`,
   - filter by the predicate `K ≤ P ∧ a ∉ P`,
   - choose a maximal element using finite induction or cardinal maximization.
   
   A useful auxiliary theorem:
   ```lean
   theorem exists_maximal_in_finite_poset
       (s : Finset β) (hs : s.Nonempty) :
       ∃ m ∈ s, ∀ x ∈ s, m ≤ x → x ≤ m
   ```
   specialized to reverse inclusion or cardinality-plus-inclusion.

4. Prove the key lemma:
   ```lean
   theorem maximal_avoiding_extension_is_prime
       (P : Theory C) :
       (K ≤ P ∧ a ∉ (P : Set α)) →
       (∀ Q : Theory C, P ≤ Q → K ≤ Q → a ∉ (Q : Set α) → Q = P) →
       IsPrimeTheory C P
   ```
   The proof idea: if `cl(A ∪ B) ⊆ P` and neither `A ≤ P` nor `B ≤ P`, choose witnesses
   `x ∈ A \ P`, `y ∈ B \ P`; then `theoryJoin C P A` and `theoryJoin C P B` are strict closed extensions of `P`. By maximality, each must contain `a`. Use closure distributivity/associativity to show `a ∈ cl(P ∪ A)` and `a ∈ cl(P ∪ B)` together force `a ∈ P`, contradiction. This is the constructive Lindenbaum step and is the real heart of the theorem.

5. Package the maximal element as `primeWitness`, and prove `primeWitness_spec`.

This route mirrors classical prime ideal separation, but in a finite closure lattice it becomes a terminating algorithm.

#### Strategy B: finite distributive lattice / join-irreducible spectrum
This route is conceptually deeper and may produce stronger infrastructure.

1. Show the closed theories form a finite lattice under:
   - meet = set intersection,
   - join = closure of union.

2. Define primality lattice-theoretically:
   ```lean
   def IsPrimeTheory (P : Theory C) : Prop :=
     ∀ K L, K ⊔ L ≤ P → K ≤ P ∨ L ≤ P
   ```

3. Use finite lattice duality: in a finite distributive lattice, prime filters/ideals correspond to join-irreducibles/meet-irreducibles. Prove that a maximal avoiding extension is meet-irreducible, then in the distributive setting conclude prime.

4. Deduce:
   - existence of prime separators,
   - reconstruction as intersection of primes,
   - finite spectral realization.

This route is strongest if your existing catalog already proves distributivity of the theory lattice or identifies theories with congruence kernels. It opens the door to a genuine **Stone/Priestley-style semantics** for proof systems.

#### Strategy C: direct exhaustive search with certified checker
This is the computational route and should be implemented even if Strategy A proves the theorem.

1. Enumerate all subsets `s : Finset α`.
2. Convert each to a closed theory by `C.cl ↑s`.
3. Filter those satisfying:
   - `K ≤ P`,
   - `a ∉ P`,
   - `IsPrimeTheory C P`.
4. Return one if any exist.
5. Prove soundness:
   ```lean
   theorem mem_primeExtensionsAvoiding_iff ...
   theorem primeWitness_sound ...
   ```
6. Prove completeness under `SemiprimeTheory C K`.

This gives an executable theorem-prover object: a witness plus proof certificate. It is slower than Strategy A, but it makes the semantics machine-checkable and computable.

### Significance for the research program

This theorem is the constructive hinge connecting three worlds that have so far only touched abstractly:

1. **Proof semantics**: non-derivability is separated by prime theories.
2. **Finite spectral geometry**: these prime theories are points of a computable finite spectrum.
3. **Algorithms/certificates**: the separation witness is not merely existential but extracted by verified search.

That changes the nature of the semantics. Instead of saying “a failed derivation corresponds to some semantic countermodel,” you will have proved that in finite closure-generated proof semirings there is a **canonical searchable spectral countermodel space**. This is a finite Nullstellensatz-style phenomenon for proof theory: derivability equals vanishing on all prime points, and failure of derivability is witnessed by an explicitly computable prime point.

This also creates a bridge to the tropical and entropy-completion directions already in play. A prime witness is a discrete semantic atom; once extracted algorithmically, it can be:
- scored by entropy or minimax complexity,
- organized into tropical spectra via idempotent valuations,
- used as a certified explanation object in proof search and proof complexity.

In other words, this theorem is not just a separation lemma. It is the first step toward a **computational spectral semantics of reasoning**.
