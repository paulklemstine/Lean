## Theorem 1: Natural Gradient = Mirror Descent in Exponential Families

### Mathematical statement

For a minimal finite exponential family with log-partition `ψ`, Fisher metric `I(θ) = Hess ψ(θ)`, and expectation parameter map `η = ∇ψ(θ)`, the natural gradient update
\[
\theta_{t+1} = \theta_t - \alpha_t I(\theta_t)^{-1}\nabla_\theta L(\theta_t)
\]
is equivalent, to first order / in exact dual coordinates when `L = \tilde L ∘ η`, to a mirror descent step in the Bregman geometry generated by `ψ`.

A precise formal target can be stated as an update identity in dual coordinates:
\[
\eta_{t+1} = \eta_t - \alpha_t \nabla_\eta \tilde L(\eta_t),
\]
whenever the dual-coordinate calculus hypotheses are encoded.

### Lean 4 type signature sketch

```lean

    (ψ : EuclideanSpace ℝ (Fin n) → ℝ)
    (I : EuclideanSpace ℝ (Fin n) → Matrix (Fin n) (Fin n) ℝ)
    (L : EuclideanSpace ℝ (Fin n) → ℝ) where
  step : ℝ → EuclideanSpace ℝ (Fin n) → EuclideanSpace ℝ (Fin n)
  natural_step :
    ∀ α θ, step α θ = θ - α • (I θ)⁻¹.mulVec (fderiv ℝ L θ 1)

theorem naturalGradient_eq_mirrorDescent_dual
    {n : ℕ}
    (ψ L : EuclideanSpace ℝ (Fin n) → ℝ)
    (I η : EuclideanSpace ℝ (Fin n) → EuclideanSpace ℝ (Fin n))
    (hψ : ConvexOn ℝ Set.univ ψ)
    (hI : ∀ θ, I θ = fderiv2 ℝ ψ θ)
    (hη : ∀ θ, η θ = fderiv ℝ ψ θ 1)
    (hmin : MinimalExponentialFamily ψ)
    (hL : ∃ Lη, L = fun θ => Lη (η θ)) :
    ∀ α θ,
      η ((θ - α • ((I θ)⁻¹).mulVec (fderiv ℝ L θ 1))) =
      η θ - α • (fderiv ℝ (Classical.choose hL) (η θ) 1)
```

This signature can and should be adapted to available Mathlib differentiability infrastructure. If full Fréchet machinery is too heavy, specialize first to finite-dimensional coordinate maps on `Fin n → ℝ`.

### Why this matters

This theorem is the conceptual hinge. Once formalized, it shows that **natural gradient is not merely a preconditioned method**; it is a **geometric descent flow in dual affine coordinates**. This opens a certified route from information geometry to mirror descent, online learning, entropy methods, and variational inference.

## Theorem 2: One-Step Bregman Lyapunov Descent

### Mathematical statement

Define the Bregman divergence generated by the log-partition:
\[
D_\psi(\theta^\star,\theta)
= \psi(\theta^\star)-\psi(\theta)-\langle \nabla\psi(\theta),\theta^\star-\theta\rangle.
\]
Assume:
- minimal finite exponential family,
- positive definiteness of Fisher matrix on the relevant domain,
- convex loss in expectation coordinates,
- relative smoothness / cocoercivity condition in Fisher geometry.

Then the natural gradient update satisfies a one-step descent inequality:
\[
D_\psi(\theta^\star,\theta_{t+1})
\le D_\psi(\theta^\star,\theta_t)
- \alpha_t\big(L(\theta_t)-L(\theta^\star)\big)
+ C\alpha_t^2.
\]

This is the real engine behind convergence.

### Lean 4 type signature sketch

```lean
def bregmanDiv
    (ψ : EuclideanSpace ℝ (Fin n) → ℝ)
    (θ⋆ θ : EuclideanSpace ℝ (Fin n)) : ℝ :=
  ψ θ⋆ - ψ θ - inner (fderiv ℝ ψ θ 1) (θ⋆ - θ)

def NaturalStep
    (I : EuclideanSpace ℝ (Fin n) → Matrix (Fin n) (Fin n) ℝ)
    (L : EuclideanSpace ℝ (Fin n) → ℝ)
    (α : ℝ)
    (θ : EuclideanSpace ℝ (Fin n)) :
    EuclideanSpace ℝ (Fin n) :=
  θ - α • ((I θ)⁻¹).mulVec (fderiv ℝ L θ 1)

theorem bregman_descent_natural_step
    {n : ℕ}
    (ψ L : EuclideanSpace ℝ (Fin n) → ℝ)
    (I : EuclideanSpace ℝ (Fin n) → Matrix (Fin n) (Fin n) ℝ)
    (θ⋆ : EuclideanSpace ℝ (Fin n))
    (C : ℝ)
    (hI : ∀ θ, I θ = fderiv2 ℝ ψ θ)
    (hpd : ∀ θ, PositiveDefinite (I θ))
    (hconv : ConvexOn ℝ Set.univ L)
    (hopt : IsLocalMin L θ⋆)
    (hsmooth : RelativeSmoothInFisherMetric ψ I L C) :
    ∀ {α θ}, 0 ≤ α →
      bregmanDiv ψ θ⋆ (NaturalStep I L α θ)
        ≤ bregmanDiv ψ θ⋆ θ - α * (L θ - L θ⋆) + C * α^2
```

### Why this matters

This theorem creates a **formal Lyapunov method for information geometry**. It is the theorem from which rate bounds, stability bounds, and algorithmic corollaries flow. It is also the exact bridge to **thermodynamic free-energy dissipation**, where Bregman divergences act like generalized entropy production.

## Theorem 3: Convergence Rate for Harmonic Step Sizes

### Mathematical statement

Assume the hypotheses of Theorem 2 and `α_t = 1/(t+1)`. Then one can derive at least:
\[
L(\theta_t)-L(\theta^\star) \le \frac{C_1 + C_2\log t}{t}
\]
under relative smoothness and convexity, and potentially sharpen to
\[
L(\theta_t)-L(\theta^\star) \le \frac{C}{t}
\]
under stronger assumptions.

If you can prove an `O(1/t²)` theorem, it must be under **strictly stronger hypotheses**, e.g. geodesic strong convexity plus a Nesterov-type inertial dual update or a special self-concordant/exponential-family structure. Do not oversell a false statement.

### Lean 4 type signature sketch

```lean
def harmonicStep (t : ℕ) : ℝ := 1 / (t + 1)

def ngdSeq
    (I : EuclideanSpace ℝ (Fin n) → Matrix (Fin n) (Fin n) ℝ)
    (L : EuclideanSpace ℝ (Fin n) → ℝ) :
    ℕ → EuclideanSpace ℝ (Fin n) → EuclideanSpace ℝ (Fin n)
  | 0,     θ0 => θ0
  | t + 1, θ0 => NaturalStep I L (harmonicStep t) (ngdSeq I L t θ0)

theorem naturalGradient_rate_O_one_div_t
    {n : ℕ}
    (ψ L : EuclideanSpace ℝ (Fin n) → ℝ)
    (I : EuclideanSpace ℝ (Fin n) → Matrix (Fin n) (Fin n) ℝ)
    (θ⋆ θ0 : EuclideanSpace ℝ (Fin n))
    (A B : ℝ)
    (hA : 0 ≤ A)
    (hB : 0 ≤ B)
    (hdescent :
      ∀ t,
        L (ngdSeq I L (t+1) θ0) - L θ⋆
          ≤ (1 - harmonicStep t) * (L (ngdSeq I L t θ0) - L θ⋆)
            + A * (harmonicStep t)^2)
    (hinit : L θ0 - L θ⋆ ≤ B) :
    ∀ t ≥ 1,
      L (ngdSeq I L t θ0) - L θ⋆ ≤ (B + A * (Real.log t + 1)) / t
```

This theorem should be proved by induction with explicit summation bounds, not by automation. Use harmonic-series inequalities and telescoping arguments.

### Why this matters

A verified non-asymptotic convergence theorem for natural gradient in a mathematically meaningful class of statistical models would be one of the first substantial Lean formalizations of **modern geometric optimization**. Even an `O((log t)/t)` theorem is scientifically important if the assumptions are clean and reusable.

## Theorem 4: Accelerated Natural Gradient on Dually Flat Manifolds

If the plain `1/t` natural gradient does not yield `O(1/t²)`, pivot to a stronger theorem for an accelerated variant.

### Mathematical statement

Define a dual-coordinate inertial scheme:
\[
\eta_{t+1} = y_t - \alpha_t \nabla \tilde L(y_t), \qquad
y_t = \eta_t + \beta_t(\eta_t-\eta_{t-1}),
\]
and map back by Legendre duality to `θ_t`. Under convexity of `\tilde L` and smoothness in dual coordinates, prove
\[
L(\theta_t)-L(\theta^\star)\le \frac{C}{(t+1)^2}.
\]

### Lean 4 type signature sketch

```lean

  η : ℕ → EuclideanSpace ℝ (Fin n)
  θ : ℕ → EuclideanSpace ℝ (Fin n)
  α : ℕ → ℝ
  β : ℕ → ℝ

theorem accelerated_dual_naturalGradient_rate
    {n : ℕ}
    (Lη : EuclideanSpace ℝ (Fin n) → ℝ)
    (S : AcceleratedDualNGD n)
    (θ⋆ : EuclideanSpace ℝ (Fin n))
    (C : ℝ)
    (hconv : ConvexOn ℝ Set.univ Lη)
    (hsmooth : DualCoordinateSmooth Lη)
    (hupdate : IsAcceleratedDualNaturalGradient Lη S)
    :
    ∀ t,
      Lη (S.η t) - Lη (gradCoord θ⋆) ≤ C / (t + 1)^2
```

### Why this matters

This would be a true breakthrough: a certified formal theory of **acceleration in information geometry**. It would connect Amari natural gradient, mirror descent, Nesterov acceleration, and entropy geometry in one framework.

## Proof Strategy Architecture

You must provide at least **2–3 serious proof pathways**, and choose the most promising.

### Strategy A: Bregman Lyapunov + telescoping inequality
1. Define the Bregman divergence associated to the log-partition `ψ`.
2. Use `fisher_eq_sufficientStatCov` and minimality to upgrade PSD Fisher structure toward positive definiteness on the nondegenerate domain.
3. Prove the one-step inequality
   \[
   D_\psi(\theta^\star,\theta_{t+1}) - D_\psi(\theta^\star,\theta_t)
   \le -\alpha_t(L_t-L^\star)+C\alpha_t^2.
   \]
4. Sum over `t` and bound `∑ α_t²`, `∑ α_t`, or use induction for harmonic steps.

**Why promising:** This is the most robust route in Lean. It localizes the geometric difficulty into one descent lemma, after which the rate proof is classical but nontrivial.

### Strategy B: Dual-coordinate reduction to Euclidean gradient descent
1. Use `η = ∇ψ(θ)` and dually flat geometry to rewrite natural gradient as ordinary gradient descent in expectation coordinates.
2. Prove convexity/smoothness of the pulled-back loss `L̃(η)`.
3. Apply Euclidean convergence theorems in dual coordinates and transport bounds back to primal coordinates via Legendre structure.

**Why promising:** Conceptually elegant and ideal for the cross-domain theorem.  
**Risk:** Requires more differential-calculus infrastructure and careful handling of coordinate transformations.

### Strategy C: Continuous-time flow then discretization
1. Study the natural gradient flow
   \[
   \dot\theta = -I(\theta)^{-1}\nabla L(\theta).
   \]
2. Prove energy dissipation for `L` or `D_ψ`.
3. Derive discrete descent by an Euler stability argument.

**Why promising:** Best for future PDE/thermodynamics links.  
**Risk:** Harder to close fully in Lean unless ODE infrastructure is already mature enough for your setup.

**Recommendation:** Start with **Strategy A**, use **Strategy B** for the equivalence theorem, and present **Strategy C** in `FUTURE_DIRECTIONS.md` as the route to geometric gradient-flow formalization.
