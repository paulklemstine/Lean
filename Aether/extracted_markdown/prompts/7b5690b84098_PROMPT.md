## Core Theorem Cluster

You should target the following theorem package, with precise formalization-friendly statements.

### 1. Miller–Rabin witness-density theorem

For odd composite `n`, the set of bases that incorrectly declare `n` “probably prime” has cardinality at most `(n-1)/4`. This is the central soundness theorem behind the `≤ 1/4` one-round error bound.

A Lean-oriented statement should be organized around a predicate `StrongPseudoprimeBase n a`.

#### Suggested definitions
```lean
def DecomposeTwos (m : ℕ) : ℕ × ℕ
-- returns (s, d) with m = 2^s * d and Odd d

def StrongPseudoprimeBase (n a : ℕ) : Prop :=
  Nat.Coprime a n ∧
  let sd := DecomposeTwos (n - 1)
  let s := sd.1
  let d := sd.2
  (a^d ≡ 1 [MOD n]) ∨ ∃ r < s, (a^(d * 2^r) ≡ n - 1 [MOD n])

def MRLiars (n : ℕ) : Finset ℕ :=
  ((Finset.range n).filter fun a => 1 ≤ a ∧ a < n ∧ StrongPseudoprimeBase n a)
```

#### Precise theorem statement
```lean
theorem miller_rabin_liar_card_le_quarter
    (n : ℕ)
    (hn_odd : n % 2 = 1)
    (hn_comp : ¬ Nat.Prime n)
    (hge : 3 ≤ n) :
    4 * (MRLiars n).card ≤ n - 1
```

A probability-form theorem should follow:

```lean

    (n : ℕ)
    (hn_odd : n % 2 = 1)
    (hn_comp : ¬ Nat.Prime n)
    (hge : 3 ≤ n) :
    ((MRLiars n).card : ℚ) / (n - 1) ≤ (1 : ℚ) / 4
```

If the catalog theorem

- explicit odd/composite hypotheses,

- and a reusable decomposition through unit groups modulo `n`.

### 2. Amplification theorem for repeated Miller–Rabin rounds

Once one-round soundness is formalized, prove the standard product bound for independent choices.


### 3. AKS local correctness criterion

Do not begin with full polynomial-time complexity. First isolate the **mathematical heart** of AKS:

If `n ≥ 2`, `n` is not a perfect power, and there exists `r` such that `ord_r(n) > (log₂ n)^2`, and for all small `a` one has
\[
(X+a)^n \equiv X^n + a \pmod{(n, X^r - 1)},
\]
then `n` is prime.

This should be formalized over the quotient ring `(ZMod n)[X] ⧸ (X^r - 1)` or via polynomial congruence modulo the ideal generated by `X^r - 1`.

#### Lean-oriented theorem statement
```lean
theorem aks_criterion
    (n r : ℕ)
    (hn : 2 ≤ n)
    (hpowfree : ¬ ∃ a b : ℕ, 2 ≤ b ∧ n = a^b)
    (hord : (Nat.orderOfMod n r) > (Nat.log2 n)^2)
    (hcong :
      ∀ a : ℕ, a ≤ bound_AKS n r →
        PolynomialCongruenceModXRMinusOne n r a) :
    Nat.Prime n
```

You will likely need to define:
```lean
def PolynomialCongruenceModXRMinusOne (n r a : ℕ) : Prop := ...
def bound_AKS (n r : ℕ) : ℕ := ...
def Nat.orderOfMod (n r : ℕ) : ℕ := ...
```

A weaker but still breakthrough theorem is acceptable if it captures the core algebra:

```lean
theorem aks_congruence_of_prime
    (p r a : ℕ)
    (hp : Nat.Prime p) :
    PolynomialCongruenceModXRMinusOne p r a
```

together with a converse under AKS hypotheses.

### 4. Prime implies AKS congruence via Frobenius in characteristic `p`

This is the algebraic engine of AKS and should be proved abstractly, not by coefficient-bashing alone.

```lean
theorem frobenius_binomial_mod_prime
    (p : ℕ) (hp : Nat.Prime p) (R : Type*) [CommRing R] [CharP R p]
    (x y : R) :
    (x + y)^p = x^p + y^p
```

Then specialize to polynomial rings over `ZMod p`:

```lean
theorem poly_X_add_C_pow_prime
    (p a : ℕ)
    (hp : Nat.Prime p) :
    (Polynomial.X + Polynomial.C (a : ZMod p))^p
      = Polynomial.X^p + Polynomial.C (a : ZMod p)
```

This is likely already close to Mathlib infrastructure; if so, package it into the exact AKS-ready statement.

### 5. Reflection theorem for modular arithmetic normalization

Build a tactic or certified procedure that normalizes expressions in `ZMod n` and polynomial quotients. The theorem should expose semantic correctness of the reifier/evaluator.

```lean
theorem eval_mod_norm_sound
    (n : ℕ) [NeZero n]
    (e : ModExpr)
    (env : Var → ℕ) :
    denoteModExpr n env (normModExpr n e) = denoteModExpr n env e
```

For polynomial quotient normalization:

```lean
theorem eval_poly_mod_xr1_sound
    (n r : ℕ) [NeZero n]
    (e : PolyModExpr)
    (env : Var → ZMod n) :
    denotePolyModExpr n r env (normPolyModExpr n r e)
      = denotePolyModExpr n r env e
```

This is not cosmetic infrastructure. It is what makes AKS feasible in Lean without drowning in ring-syntax bureaucracy.

## Proof Strategy Architecture

You need multiple proof paths. Do not commit prematurely.

### Strategy A: Group-theoretic Miller–Rabin via square roots of unity
Most promising for the witness-density theorem.

1. Work in the unit group `(ZMod n)ˣ` or the subgroup of residues coprime to `n`.
2. Characterize strong liars as elements whose `d`-th power lands in the “2-Sylow preimage” of `{1, -1}` under repeated squaring.
3. Show this subset has size at most one quarter of the unit group for odd composite `n`, using CRT decomposition and nontrivial square roots of unity.

Why this is promising:
- It scales conceptually.
- It interfaces naturally with Carmichael-number structure.
- It produces reusable infrastructure on unit groups modulo composites.

### Strategy B: Chinese remainder decomposition
Especially effective if Mathlib has strong `ZMod`/CRT support.

1. Factor `n` into prime powers or at least two coprime composite factors.
2. Transport `StrongPseudoprimeBase n a` across the CRT isomorphism.
3. Prove the liar set is a product of constrained local sets, one of which has strict density drop, yielding the global `≤ 1/4` bound.

Why this is promising:
- It makes the “quarter” phenomenon transparent.
- It can lead to refined bounds for semiprimes or squarefree composites.
- It sets up future classification results on pseudoprimes.

### Strategy C: Algorithm-first executable formalization
Best for early momentum, not for the deepest theorem.

1. Define executable Miller–Rabin and AKS predicates on `Nat`.
2. Prove soundness/completeness by relating execution traces to modular algebra.
3. Use reflection lemmas to discharge modular equalities automatically.

Why this is promising:
- Rapidly yields certified runnable primality checkers.
- Creates immediate artifacts.
- But by itself it risks becoming engineering-heavy unless tied back to theorems A/B.

Recommended order:
- **Start with C for infrastructure and sanity checks.**
- **Prove Miller–Rabin soundness using A or B.**
- **Then formalize AKS algebraic criterion using Frobenius and quotient-polynomial reflection.**
