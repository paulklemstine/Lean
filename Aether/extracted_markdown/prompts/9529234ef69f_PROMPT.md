# Conjecture 3: Learning-Theoretic Version Space Compression Bound

Aristotle, do not treat this as a routine PAC-bound exercise. The target is to formalize a genuinely new information law for learning: **each labeled example can remove only a bounded amount of semantic uncertainty from the version space**, and this turns sample complexity into an entropy budget. If done correctly, this opens a bridge between finite learning theory, Shannon-style information, compression schemes, and even statistical mechanics of hypothesis elimination.

The breakthrough is not merely a bound on cardinalities. It is a **structural theorem** saying that version-space refinement behaves like an information-dissipation process under observation, with per-sample information capped by the label partition induced by the instance space. This is the kind of theorem that can seed an entire “semantic information theory of learning.”

## Precise formal target

Work in the finite setting first. Let `X` be a finite instance space, `Y` a finite label space, and `H : Finset (X → Y)` a finite hypothesis class. A dataset is a finite set/list of labeled examples, and the version space consists of those `h ∈ H` consistent with the dataset.

You should introduce a new definition capturing **uniform version-space entropy**:
- if `V ⊆ H` is nonempty finite, define `versionSpaceEntropy V := Real.log (V.card) / Real.log 2`.
This is not Shannon entropy over an arbitrary posterior; it is the semantic entropy of the surviving hypothesis class under the uniform posterior. That choice is mathematically sharp and Lean-friendly, and it already yields nontrivial theorems.

Then prove a family of theorems of increasing strength.

## Core theorem package

### Theorem 1: One-sample entropy drop is bounded by label alphabet size

For any version space `V ⊆ H`, any instance `x : X`, and any observed label `y : Y`, let
`V' = {h ∈ V | h x = y}`.
Then:
\[
H(V) - H(V') \le \log_2(|Y|),
\]
provided `V'` is nonempty.

This is the real invariant. The user’s draft uses `log₂(|X|)`, but the mathematically correct per-sample information cap is usually **label-side branching**, not instance-space size. A binary label reveals at most 1 bit, multiclass at most `log₂ |Y|`. This correction is scientifically important: if the original conjecture is false, you should explicitly replace it with the strongest true statement.

### Theorem 2: k-sample entropy drop is bounded linearly

For a sequence of `k` labeled examples, if each update preserves nonemptiness of the version space, then:
\[
H(S_m) - H(S_{m+k}) \le k \log_2(|Y|).
\]

This is the telescoping theorem that turns the one-step law into a sample complexity lower bound.

### Theorem 3: Entropy reduction implies a sample lower bound

If after `k` further samples the version-space entropy decreases by `Δ`, then
\[
k \ge \frac{\Delta}{\log_2(|Y|)}.
\]

This is the actual learning-theoretic compression lower bound.

## 2–3 proof strategy paths

### Strategy A: Fiber partition + cardinality pigeonhole + logarithms
This is the most promising route.

1. For fixed `x`, partition `V` into fibers `V_y = {h ∈ V | h x = y}` over `y : Y`.
2. Since `V = ⨆_y V_y` as a disjoint union, one fiber has size at least `V.card / |Y|`.
3. If the observed label is `y` and `V_y` is nonempty, then `V_y.card ≥ V.card / |Y|` fails for arbitrary `y`, but you can still derive the **worst-case upper bound** on information gained by observing a label through the counting identity plus the fact that there are at most `|Y|` fibers. The sharp path is:
   - entropy drop for a realized label is `log₂(V.card / V_y.card)`;
   - the maximum possible such drop, over nonempty fibers, is at most `log₂ |Y|` if every nonempty fiber is at least `V.card / |Y|`.
   This exact statement is not always true for every fiber, so be careful.
   The robust theorem is instead:
   - **average entropy drop over labels weighted by fiber size** is at most `log₂ |Y|`, or
   - **there exists** a label with drop at most `log₂ |Y|`, or
   - for deterministic labels from a target hypothesis, the drop is bounded by the information content of the partition cell.
4. Therefore, if you want a theorem true for every sample sequence, the correct universal statement is cardinal:
   \[
   |S_{m+k}| \ge |S_m| / |Y|^k,
   \]
   hence
   \[
   H(S_m)-H(S_{m+k}) \le k\log_2|Y|.
   \]
   This version is clean and true because each new example can split each surviving hypothesis into at most `|Y|` label classes, so after `k` examples there are at most `|Y|^k` answer patterns.

This path is the strongest because it avoids false one-step claims about arbitrary realized fibers and instead proves the global sequence theorem directly by **pattern counting**.

### Strategy B: Encoding argument / compression scheme
1. Map each surviving hypothesis `h ∈ S_m` to its label pattern on the next `k` queried instances.
2. There are at most `|Y|^k` such patterns.
3. The refined version space `S_{m+k}` is exactly one fiber of this pattern map.
4. Therefore `S_m` decomposes into at most `|Y|^k` fibers, and the chosen fiber cannot force total entropy loss exceeding `k log₂ |Y|` under the worst-case pattern-count interpretation.

This is conceptually elegant and connects directly to sample compression. It is also likely easier to communicate in `RESEARCH_PAPER.md`.

### Strategy C: Information-theoretic posterior route
1. Put the uniform distribution on `S_m`.
2. Let `Z` be the vector of labels on the next `k` queried instances.
3. Then `H(Hypothesis | data) - H(Hypothesis | data, Z) = I(Hypothesis ; Z | data)`.
4. Since `Z` takes values in `Y^k`, one has `I ≤ H(Z) ≤ k log₂ |Y|`.

This is the most revolutionary mathematically, because it reframes version-space learning as a mutual-information process. But in Lean this is harder unless you already have discrete entropy infrastructure in the catalog. Use this as the conceptual narrative and maybe formalize a combinatorial shadow of it.

## Important correction to the original conjecture

The user statement with `log₂(|X|)` is almost certainly not the right universal cap. A single sample consists of choosing an instance and observing its label; once the instance is fixed by the learner, the uncertainty removed by the label is bounded by the number of possible labels, not by the size of the instance space. Therefore:

- **Refine the conjecture** to `k * log₂(|Y|)` in the fully general finite multiclass setting.
- Optionally prove a secondary bound involving `|X|` only in settings where the learner pays to choose/query the instance, or where one counts the pair `(x,y)` as the observed symbol.
- If possible, include a **counterexample** to the raw `log₂(|X|)` formulation when `|Y| > |X|` or when labels carry more information than instance identity. That would be scientifically valuable and clears a dead end.

## Cross-domain connections you must formalize

You are required to connect this to another domain. Do not do this superficially.

### Connection 1: Statistical mechanics / partition functions
Define the surviving hypothesis count as a zero-temperature partition function:
\[
Z(D) := |S_D|.
\]
Then semantic entropy is `log₂ Z(D)`. Observing data acts like adding hard constraints to a Gibbs ensemble. Prove monotonicity:
\[
D \subseteq D' \implies Z(D') \le Z(D).
\]
This is a real cross-domain theorem: **learning as entropy collapse in a constrained statistical system**.

Possible Lean target:
```lean
theorem versionSpace_card_mono
  {X Y : Type*} [DecidableEq X] [DecidableEq Y]
  (H : Finset (X → Y)) :
  ∀ {D E : List (X × Y)}, D <+ E →
    (versionSpace H E).card ≤ (versionSpace H D).card
```

### Connection 2: Coding theory
The next `k` queried instances define a codeword map from hypotheses to `Y^k`. The refined version space is a code fiber. Prove a theorem phrased as:
- number of distinct equivalence classes induced by `k` queries is at most `|Y|^k`.

Lean target:
```lean
def queryPattern (xs : List X) (h : X → Y) : List Y := xs.map h

theorem num_pattern_classes_le
  {X Y : Type*} [Fintype Y] [DecidableEq Y]
  (H : Finset (X → Y)) (xs : List X) :
  (H.image (queryPattern xs)).card ≤ (Fintype.card Y) ^ xs.length
```

This is a beautiful bridge: sample complexity lower bounds emerge from a coding-capacity bound.

### Connection 3: Order theory / lattice of knowledge states
Datasets induce a partial order on version spaces by reverse inclusion. Prove that adding data moves downward in this lattice. If feasible, define a preorder on datasets modulo equivalent version spaces. This gives a semantic-lattice view of learning.
