## Theorem 1: Surgery strictly decreases tropical separation

### Mathematical statement
Let `W` be a finite weighted graph, `u v s t : Fin n`, and `τ : ℝ`. Suppose every `s`-`t` path in `W` passing through the old ambient region has cost at least `D`, while there exist paths `s → u` and `v → t` of costs `a` and `b`, and the surgery inserts a bridge `u ↔ v` of cost `τ` with `a + τ + b < D`. Then the tropical distance in the surgered graph is at most `a + τ + b`, hence strictly smaller than `D`.

### Lean-style target
```lean
theorem tropicalDistance_wormholeSurgery_le
  {n : Nat} (W : Matrix (Fin n) (Fin n) ℝ)
  (s t u v : Fin n) (a b τ D : ℝ)
  (hsu : tropicalDistance W s u ≤ a)
  (hvt : tropicalDistance W v t ≤ b)
  (hsep : D ≤ tropicalDistance W s t)
  (hbridge : a + τ + b < D) :
  tropicalDistance (wormholeSurgery W u v τ) s t ≤ a + τ + b
```

and corollary
```lean
theorem tropicalDistance_wormholeSurgery_strict
  {n : Nat} (W : Matrix (Fin n) (Fin n) ℝ)
  (s t u v : Fin n) (a b τ D : ℝ)
  (hsu : tropicalDistance W s u ≤ a)
  (hvt : tropicalDistance W v t ≤ b)
  (hsep : D ≤ tropicalDistance W s t)
  (hbridge : a + τ + b < D) :
  tropicalDistance (wormholeSurgery W u v τ) s t < tropicalDistance W s t
```

### Why this is a breakthrough
This is the first theorem-level statement of “wormhole creation” as a certified distance-lowering surgery in a tropicalized spacetime. It translates topology change into a sharp optimization inequality.

```lean
def minPlusRicci {n : Nat} (W : Matrix (Fin n) (Fin n) ℝ) (x : Fin n) : ℝ :=
```


## Theorem 4: Tropical geodesics through wormholes are polynomial-time computable

Do not try to formalize full complexity theory unless the infrastructure is already there. Instead, prove a mathematically precise bounded-iteration theorem: on a graph with `n` vertices, Bellman-Ford-style relaxation stabilizes in at most `n - 1` steps, hence computes tropical geodesics effectively.

### Lean-style target
Define:
```lean
def relax {n : Nat} (W : Matrix (Fin n) (Fin n) ℝ) (d : Fin n → ℝ) : Fin n → ℝ :=
  fun x => Finset.inf' Finset.univ Finset.univ_nonempty (fun y => d y + W y x)

def iterateRelax {n : Nat} (k : Nat) (W : Matrix (Fin n) (Fin n) ℝ) (d0 : Fin n → ℝ) :
    Fin n → ℝ := Nat.iterate (relax W) k d0
```

Then prove eventual correctness:
```lean
theorem iterateRelax_stabilizes_to_tropicalDistance
  {n : Nat} (W : Matrix (Fin n) (Fin n) ℝ) (source : Fin n) :
  ∃ k ≤ n, iterateRelax k W (initialData source) = fun x => tropicalDistance W source x
```

If exact equality to distance is too ambitious, prove:
```lean

theorem iterateRelax_upper_bound
theorem iterateRelax_exact_after_simple_path_bound
```

### Why this matters
This is the algorithmic traversability theorem. It says wormhole geodesics in the tropical shadow are not merely definable; they are computable with explicit finite convergence.

## Proof Strategy Architecture

### Strategy A: Matrix/Bellman dynamic programming route
Most promising.

1. Encode the spacetime graph as a weighted matrix and define `relax`.
2. Show shortest-path distances satisfy the Bellman min-plus fixed-point identity.
3. Show surgery simply changes two matrix entries by `min`, then construct the explicit `s → u → v → t` witness path to obtain the distance drop.

Why promising: this aligns directly with your available min-plus lemmas:
- `tropical_min_comm`
- `tropical_min_idem`
- `tropical_path_idempotent`
- `tropical_plus_distributes_over_min`

These are exactly the algebraic identities needed for min-plus dynamic programming.

### Strategy B: Finite path enumeration route
More elementary, likely easiest for first formal success.

1. Define paths as lists of vertices with bounded length `≤ n`.
2. Define path cost by summing edge weights.
3. Define tropical distance as the minimum over all simple paths.
4. After surgery, explicitly append the bridge edge to compose a new witness path.
5. Derive Bellman inequalities by splitting a path at its final edge.

Why useful: avoids heavy graph infrastructure and keeps everything finitary and computable.

### Strategy C: Semiring/tropical algebra route
Most visionary, but higher risk.

1. Interpret `W` as a min-plus adjacency matrix.
2. Define geodesic propagation as tropical matrix powers / Kleene star.
3. Prove surgery corresponds to a low-rank tropical update.
4. Show the Einstein fixed-point equation is the resolvent equation in the tropical semiring.

Why important: this is the route toward a genuine theory of tropical spacetime operators, but it may be too ambitious for the first cycle.

**Recommendation:** start with Strategy B to get theorem statements landed with minimal sorry, then refactor into Strategy A for elegance, and reserve Strategy C for FUTURE_DIRECTIONS.
