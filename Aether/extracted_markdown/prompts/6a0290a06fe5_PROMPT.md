## Grand Challenge

### Core Vision
For each simple type `A`, define a finitary polynomial endofunctor `F_A : Type u → Type u` determined only by the shape of `A`, and prove that the bisimulation quotient of the finite transition system associated to sufficiently unfolded normal forms of type `A` is canonically an `F_A`-coalgebra. Then identify a canonical finite object built from the type alone that is universal among finite `F_A`-coalgebras generated by λ-terms of type `A`.

The revolutionary point is this: **type structure alone predicts the finite-state semantic universe of its terms.** This would recast typed normalization as a species of coalgebraic behavior theory.

## Exact Theorem Statements to Aim For

### Theorem 1: Quotient inherits coalgebra structure
If `BehavioralEquiv` is the catalog bisimulation equivalence on the FTS of a term/type, then the semantic quotient carries a well-defined coalgebra structure.

**Mathematical statement:**
For every simple type `A` and every finite transition system `C_A` extracted from η-long normal forms of type `A`, if transitions are invariant under `BehavioralEquiv`, then the quotient `SemanticQuotient C_A` admits a coalgebra structure for `F_A`.

**Lean 4 target signature (schematic but precise):**
```lean
theorem quotient_has_type_polynomial_coalgebra
  (A : STLCType)
  (C : Type u)
  [Finite C]
  (step : C → TypePolynomialFunctor A C)
  (hcompat :
    ∀ {x y : C}, BehavioralEquiv x y →
      Quot.sound (hcompat := ?_) ) :
  ∃ qstep : Quotient (BehavioralEquiv : C → C → Prop) →
            TypePolynomialFunctor A (Quotient (BehavioralEquiv : C → C → Prop)),
    True
```

A more practical version, if you have a setoid:
```lean
theorem quotient_coalgebra_well_defined
  (A : STLCType)
  (S : Setoid C)
  (step : C → TypePolynomialFunctor A C)
  (hresp : ∀ a b, a ≈ b → Quotient.map' step ? = ? ) :
  ∃ stepQ : Quotient S → TypePolynomialFunctor A (Quotient S),
    ∀ x, stepQ (Quotient.mk _ x) = mapFunctorQuot A step x
```

**Why this matters:** this is the bridge from operational semantics to categorical semantics. Without it, “coalgebraic semantics” is only metaphorical.

### Theorem 2: Reachable quotient is finite and canonical
The quotient on reachable states does not depend on presentation details of the term graph, only on the type-driven behavior.

**Mathematical statement:**
For each type `A`, the reachable part of the bisimulation quotient of `toFTS d t` stabilizes for sufficiently large `d`, and any two sufficiently large depths yield isomorphic finite `F_A`-coalgebras.

**Lean 4 target signature:**
```lean
theorem quotient_stabilizes_up_to_iso
  (A : STLCType)
  (t : Term A)
  :
  ∃ N : ℕ, ∀ d₁ d₂ : ℕ, N ≤ d₁ → N ≤ d₂ →
    Nonempty (CoalgebraIso
      (reachableQuotCoalgebra A t d₁)
      (reachableQuotCoalgebra A t d₂))
```

If term-indexing is too ambitious, prove a type-level generated version:
```lean
theorem type_generated_quotients_eventually_isomorphic
  (A : STLCType) :
  ∃ N : ℕ, ∀ d₁ d₂ : ℕ, N ≤ d₁ → N ≤ d₂ →
    Nonempty (CoalgebraIso
      (generatedQuotCoalgebra A d₁)
      (generatedQuotCoalgebra A d₂))
```

**Why this matters:** stabilization is the semantic finiteness theorem. It is the coalgebraic analogue of eventual automaton minimization.

### Theorem 3: Universal property among finite generated coalgebras
The canonical quotient coalgebra is terminal/final among finite generated `F_A`-coalgebras arising from terms of type `A`, or dually the corresponding algebra is initial in the generated subcategory.

**Mathematical statement:**
For each type `A`, there exists a finite coalgebra `Can_A` such that every finite generated `F_A`-coalgebra arising from terms of type `A` admits a unique coalgebra morphism into `Can_A`.

**Lean 4 target signature:**
```lean
structure IsFinalAmongGenerated
  (A : STLCType)
  (C : FiniteCoalgebra (TypePolynomialFunctor A)) : Prop where
  lift :
    ∀ D : FiniteCoalgebra (TypePolynomialFunctor A),
      GeneratedByTerms A D →
      ∃! f : CoalgebraHom (TypePolynomialFunctor A) D C, True

theorem canonical_behavior_final_among_generated
  (A : STLCType) :
  ∃ C : FiniteCoalgebra (TypePolynomialFunctor A),
    IsFinalAmongGenerated A C
```

If finality is too hard globally, prove uniqueness up to isomorphism:
```lean
theorem canonical_behavior_unique
  (A : STLCType)
  {C D : FiniteCoalgebra (TypePolynomialFunctor A)}
  (hC : IsFinalAmongGenerated A C)
  (hD : IsFinalAmongGenerated A D) :
  Nonempty (CoalgebraIso C D)
```

**Why this matters:** this is the theorem that would make category theorists pay attention. It upgrades minimization from algorithmic artifact to universal semantics.

## Proof Architecture: 3 Strategic Routes

You must explicitly pursue 2–3 proof pathways in your notes and choose one as primary.

### Strategy A: Quotient-descent via behavioral invariance
**Best first route.**

1. Use `typed_coalgebraic_invariant` from `Pythagorean/StrongNormBisimulation.lean` to show that the observable transition profile of a state is preserved under the catalog’s bisimulation relation.
2. Define `TypePolynomialFunctor A` so that the observation profile lands naturally in `1 + X^k` or a dependent variant thereof.
3. Descend the structure map to the quotient using `Quotient.lift`; prove well-definedness from behavioral invariance.
4. Restrict to reachable states and combine with `SemanticQuotient`/`BehavioralEquiv` machinery from `Pythagorean/BisimMinimization.lean`.
5. Show uniqueness of induced morphisms by extensionality on reachable representatives.

**Why this is most promising:** it leverages existing catalog theorems exactly where they are strongest: invariance and minimization. It turns the hard semantic problem into a quotient-lift problem.

---

### Strategy B: Structural induction on type, then transport through minimization
1. Define `F_A` recursively on the type syntax:
   - base type: nullary observation or terminal behavior
   - arrow type: observation with one constructor per argument position / evaluation branch
2. Prove by induction on `A` that η-long normal forms of type `A` generate only `F_A`-shaped transitions.
3. Use minimization theorems to identify the quotient as the smallest finite realization of that shape.
4. Derive universal property by induction on the type and uniqueness of morphisms into minimized representatives.

**Why it may succeed:** the type syntax is finite and recursively generated, which often makes polynomial functor semantics tractable.  
**Why it is riskier:** the interaction between type recursion and operational reachability may require substantial infrastructure.

---

### Strategy C: Modal logic / observational equivalence route
1. Define a modal observation language whose formulas correspond to one-step `F_A` observations.
2. Show bisimilar states satisfy the same formulas, and on finite reachable systems the converse holds.
3. Build the canonical quotient as the space of complete modal theories.
4. Identify this modal quotient with the bisimulation quotient coalgebra.

**Why this is exciting:** it connects the result to coalgebraic modal logic and Hennessy–Milner style characterization.  
**Why it is harder:** substantial logical infrastructure may be needed unless the catalog already contains observation predicates.

**Disproof criterion:**
