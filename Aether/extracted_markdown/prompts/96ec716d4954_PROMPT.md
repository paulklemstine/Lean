## Assignment: 2. Bellman Duality for Amortized Complexity Certificates

**Mode:** prove

Prove a genuinely new theorem family establishing **strong duality between amortized charge schedules and potential-function certificates** for finite execution traces, then push toward discounted and average-cost infinite-horizon variants. The goal is not merely to restate accounting-method folklore, but to formalize a theorem that turns amortized analysis into a certified dual optimization principle, in the same conceptual class as LP duality, Bellman optimality, and reduced-cost certificates.

This would be a breakthrough because it would convert informal “find a good potential” reasoning into a theorem saying that **optimal amortized bounds are exactly the values of optimal dual certificates**. Once formalized in Lean, this creates a reusable engine for data-structure analysis, online algorithms, and certified resource bounds, and opens a path to tropical / idempotent reinterpretations of complexity.

## Precise theorem target

Let `cost : Fin n → ℝ` be the actual per-step costs of an execution trace of length `n`. A primal amortized schedule is a sequence `a : Fin n → ℝ` such that every prefix of amortized charges dominates the corresponding prefix of actual costs:

\[
\forall k \le n,\quad \sum_{i < k} cost_i \le \sum_{i < k} a_i.
\]

The optimization problem is to minimize total amortized charge
\[
\sum_{i<n} a_i.
\]

A dual certificate is a potential trajectory `φ : Fin (n+1) → ℝ` with `φ 0 = 0`, `φ i ≥ 0`, and
\[
a_i = cost_i + φ(i+1) - φ(i).
\]
Equivalently, the certificate of a global amortized bound `B` is a potential satisfying
\[
\sum_{i<n} cost_i + φ(n) - φ(0) \le B
\]
with nonnegativity constraints making every prefix feasible.

The finite-horizon strong-duality theorem should say that the optimal primal total charge equals the minimal terminal potential surplus / equivalently the maximal dual lower bound, and that an optimizer can be represented by a witnessing potential.

and then derive:

```lean
    {n : ℕ} (cost : Fin n → ℝ) :

      (∀ k : Fin (n+1),

```

This second theorem is mathematically sharp: for pure prefix-feasibility with no terminal-potential constraint, the optimum should collapse to total actual cost. That is not a bug; it is the first duality law. The genuinely interesting strengthening is to impose a **uniform per-step charge cap** or **constant amortized rate** and prove the dual characterization of the least such rate.

That breakthrough theorem is likely the right final target:

```lean
theorem amortized_rate_strong_duality_fin
    {n : ℕ} (cost : Fin n → ℝ) :
    sInf {r : ℝ |
      ∃ φ : Fin (n+1) → ℝ,
        φ 0 = 0 ∧
        (∀ k : Fin (n+1), 0 ≤ φ k) ∧
        ∀ i : Fin n, cost i + φ i.succ - φ i.castSucc ≤ r}

    sInf {r : ℝ |
      ∀ k : Fin (n+1),
        (∑ i in Finset.range k.1, cost ⟨i, by omega⟩) ≤ r * k.1}
```

Interpretation: the least constant amortized charge per operation equals the least dual Bellman certificate bound. This is the exact amortized-analysis analogue of strong duality and is much more field-opening than merely minimizing total charge.

## Why this is the right theorem

The raw “minimize total amortized charge under prefix constraints” problem is degenerate: the optimum is just the total actual cost. The true conceptual object in amortized analysis is the **least uniform amortized rate** `r` such that every prefix cost is bounded by `r * length + initial potential`. The dual variable is the potential function, and the Bellman inequality
\[
cost_i + φ_{i+1} - φ_i \le r
\]
is the one-step reduced-cost condition.

So the theorem to formalize is:

\[
\inf\{r : \forall k,\ \sum_{i<k} cost_i \le rk\}
=
\inf\{r : \exists φ \ge 0,\ φ_0 = 0,\ \forall i,\ cost_i + φ_{i+1}-φ_i \le r\}.
\]

For finite traces this should actually hold with equality by explicit construction:
- primal optimal rate is the maximum prefix average
  \[
  r^\* = \max_{1 \le k \le n} \frac{1}{k}\sum_{i<k} cost_i;
  \]
- dual optimizer can be taken as the slack-to-line potential
  \[
  φ_k = rk - \sum_{i<k} cost_i.
  \]

That is the Bellman duality theorem you should aim to make canonical in Lean.

## Stronger theorem statement

After the equality of infima, prove the closed-form optimizer formula:

```lean
theorem amortized_rate_opt_eq_max_prefix_avg
    {n : ℕ} (hn : 0 < n) (cost : Fin n → ℝ) :
    sInf {r : ℝ |
      ∀ k : Fin (n+1),
        (∑ i in Finset.range k.1, cost ⟨i, by omega⟩) ≤ r * k.1}
    =
    Finset.sup
      (Finset.Icc 1 n)
      (fun k => ((∑ i in Finset.range k, cost ⟨i, by omega⟩) : ℝ) / k)
```

or a `Finset.max'` version if easier.

Then derive existence of an optimal potential:

```lean
theorem exists_optimal_bellman_potential
    {n : ℕ} (hn : 0 < n) (cost : Fin n → ℝ) :
    ∃ r φ,
      r = Finset.sup (Finset.Icc 1 n)
            (fun k => ((∑ i in Finset.range k, cost ⟨i, by omega⟩) : ℝ) / k) ∧
      φ 0 = 0 ∧
      (∀ k : Fin (n+1), 0 ≤ φ k) ∧
      (∀ i : Fin n, cost i + φ i.succ - φ i.castSucc ≤ r)
```

## Proof strategies

### Strategy A: Prefix-slack construction from the primal optimum
Most promising.

1. Define the candidate optimal rate
   \[
   r^\* := \max_{1 \le k \le n} S_k/k
   \]
   where `S_k = ∑_{i<k} cost_i`.
2. Define the potential
   \[
   φ_k := r^\* k - S_k.
   \]
   Prefix maximality gives `φ_k ≥ 0`.
3. Compute
   \[
   cost_k + φ_{k+1} - φ_k = r^\*.
   \]
   This gives a dual witness.
4. Conversely, from any dual witness `(r, φ)`, telescope:
   \[
   \sum_{i<k} cost_i + φ_k - φ_0 \le rk.
   \]
   Since `φ_0 = 0` and `φ_k ≥ 0`, obtain `S_k ≤ rk`.
5. Conclude equality of feasible-rate sets, hence strong duality.

Why this is best: it is constructive, avoids heavy convex-analysis infrastructure, and maps directly to Lean via finite sums and telescoping identities.

### Strategy B: Encode as finite-dimensional LP duality / Farkas certificate
Potentially elegant if existing linear-optimization machinery is available, but likely heavier in Lean.

1. Express prefix constraints as a lower-triangular linear system in variables `r` or `a_i`.
2. Identify dual variables as nonnegative multipliers on prefix inequalities.
3. Show that the potential `φ` is the cumulative sum of dual multipliers.
4. Derive complementary-slackness style relations and the explicit optimizer.

Why this matters: it connects the result to genuine LP duality and opens later formalization of min-cost flow and online primal-dual algorithms. But it may require more infrastructure than Strategy A.

### Strategy C: Dynamic-programming / Bellman operator derivation
Best for the infinite-horizon extension.

1. Define a Bellman operator on potentials:
   \[
   (T_r φ)(i) := \max(0, φ_i + cost_i - r)
   \]
   or an equivalent forward recurrence.
2. Show finite-horizon feasibility is equivalent to existence of a nonnegative fixed point / subsolution.
3. For discounted horizons, replace telescoping by weighted telescoping:
   \[
   cost_i + γ φ_{i+1} - φ_i \le r.
   \]
4. Derive strong duality as a Bellman–Fenchel principle.

This is the bridge to MDPs, optimal control, and certified average-cost complexity.

## Cross-domain connections to emphasize in the formal development

This is where the theorem becomes field-opening rather than local.

### 1. Min-cost flow duality and reduced costs
The Bellman inequality
\[
cost_i + φ_{i+1} - φ_i \le r
\]
is exactly a reduced-cost constraint. The potential is a node price; amortized analysis becomes shortest-path / flow duality on a path graph. Formalizing this opens the door to:
- certified primal-dual online algorithms,
- data-structure potentials as reduced-cost certificates,
- flow-inspired resource analyses.

### 2. Tropical / idempotent linear algebra
Prefix maxima and max-average quantities are naturally tropical objects. The optimal rate as a maximum prefix average is a one-dimensional **max-plus spectral quantity**. This suggests a future theorem that amortized complexity bounds are tropical eigenvalue bounds on transition systems.

### 3. Bellman equations and control theory
Your dual certificate is a discrete Bellman subsolution. This reframes amortized analysis as finite-horizon optimal control:
- `r` is an average stage-cost bound,
- `φ` is a value function / storage function,
- the proof is a dissipativity argument.

This connection is especially powerful for the discounted and infinite-horizon extension.

### 4. Program verification and resource-aware type systems
A formal strong duality theorem would allow extraction of machine-checkable resource certificates from feasible bounds and vice versa. This can influence:
- automatic amortized resource analysis,
- certified cost semantics,
- synthesis of potentials from trace inequalities.

### 5. Information theory and thermodynamics
Potential functions are “stored work”; amortized charges are “free-energy budgets.” There is a real analogy to entropy production inequalities and Lyapunov/storage functions. If developed, this could bridge certified complexity and dissipative systems.
