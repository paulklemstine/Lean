### Research Direction

**Core Conjecture (Treewidth-Certificate Bound):** For any graphic matroid $M(G)$ where $G$ has treewidth $k$, the deletion/contraction certificate compiled along a nice tree decomposition has size at most $|E(G)| \cdot 2^{k^2+k}$.

**Precise Theorem Statement (Lean 4 target):**

```lean
-- New structure: Nice tree decomposition with certificate compilation state
structure NiceTreeDecomp (V : Type*) [Fintype V] [DecidableEq V] where
  bag : Finset V          -- vertices in each bag
  children : List (NiceTreeDecomp V)
  decomp_type : {intro // forget // join // leaf}
  hwidth : ∀ b in bags, bag.card ≤ width + 1
  hcover : ∀ e : G.Edge, ∃ b in bags, e.fst ∈ b ∧ e.snd ∈ b
  hconnected : ∀ v : V, {b ∈ bags | v ∈ b}.IsConnected  -- subtree property

-- New structure: Certificate compiled from decomposition
structure CompiledCert (α : Type*) where
  active_edges : Finset α    -- edges "in play" at current node
  left : Option (CompiledCert α)
  right : Option (CompiledCert α)
  hbranch : left.isSome → right.isSome  -- binary branching invariant

-- The key theorem: certificate size is FPT in treewidth
theorem cert_size_bounded_by_treewidth
    {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) [DecidableRel G.Adj]
    (td : NiceTreeDecomp V G) (k : ℕ) (hk : td.width ≤ k)
    (cert : CompiledCert (Sym2 V))
    (hcomp : cert.IsCompiledFrom td)
    (hG : G.Connected) :
    cert.size ≤ (Fintype.card G.edgeSet) * (2 : ℕ)^(k^2 + k) :=
  sorry
```

**Secondary Theorem (Active-Edge Bound — the inductive crux):**

```lean
theorem active_edges_at_bag_bound
    {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) (td : NiceTreeDecomp V G) (k : ℕ)
    (hk : td.width ≤ k) (b : td.Bags) :
    (activeEdgesAt G td b).card ≤ k * (k + 1) / 2 :=
  sorry
```

**Cross-Domain Theorem (Potts Partition Function ↔ Certificate Size):**

```lean
-- Connects matroid certificate size to statistical mechanics
theorem potts_partition_certificate_equivalence
    {V : Type*} [Fintype V] [DecidableEq V]
    (G : SimpleGraph V) (td : NiceTreeDecomp V G) (k : ℕ)
    (hk : td.width ≤ k) (q : ℕ) (β : ℝ) :
    ∃ (cert : CompiledCert (Sym2 V)) (hcomp : cert.IsCompiledFrom td),
      cert.size ≤ (Fintype.card G.edgeSet) * (2 : ℕ)^(k^2 + k) ∧
      Z_Potts G q β = cert.evaluate * (1 - exp(-β))^cert.leafCount :=
  sorry
```

This states that the q-state Potts model partition function on G at inverse temperature β can be computed by a certificate of FPT-bounded size, with the evaluation factoring through the certificate's leaf count. This bridges **parameterized complexity** (treewidth FPT), **matroid theory** (deletion/contraction), and **statistical mechanics** (Potts model).

### Proof Strategy (Three Paths)

**Strategy A: Direct induction on nice tree decomposition bags.**
- Prove `active_edges_at_bag_bound`: at any bag with ≤ k+1 vertices, there are at most $\binom{k+1}{2}$ active edges.
- Show that the deletion/contraction branching factor at each bag node is at most $2^{k^2+k}$ (each active edge is either deleted or contracted).
- Compose over all $O(|V|)$ bags in the decomposition.
- *Assessment:* Conceptually clean but requires careful bookkeeping of the "active state" across introduce/forget/join transitions.

**Strategy B: State-compression via dynamic programming tables.**
- At each bag, the "state" is a partition of the bag vertices induced by which edges have been contracted. This is a set partition on ≤ k+1 elements, and Bell(k+1) ≤ $2^{k^2}$.
- Show that the certificate compilation visits at most $|E|$ distinct state-partition pairs.
- *Assessment:* Most promising. The Bell number bound is tight and naturally captures the contraction connectivity structure. This connects to the **Whitney embedding** of matroid minors into partition lattices.

**Strategy C: Via branch-width and Seymour-Thomas obstructions.**
- Use the fact that treewidth k implies branch-width ≤ k+1.
- Apply the branch-decomposition to bound the "interaction width" at each split.
- *Assessment:* Elegant but requires formalizing branch-width first, which is substantial overhead. Reserve for future work.

**Recommendation:** Pursue Strategy B. The partition-of-bag-vertices state space is the natural invariant for deletion/contraction recursion on bounded-treewidth graphs. The Bell number bound is the correct exponential dependence on k.

1. **Parameterized Complexity → Quantum Sampling:** The FPT certificate bound directly yields polynomial-time exact quantum sampling from spanning tree distributions on bounded-treewidth graphs. This connects to **#P-completeness barriers**: while counting spanning trees is #P-hard in general, the treewidth parameterization breaks the barrier.

2. **Statistical Mechanics → Matroid Certification:** The Potts model partition function $Z_G(q, \beta)$ equals the Tutte polynomial evaluated at specific algebraic points. The certificate bound implies $Z_G$ is FPT-computable in treewidth, recovering the classical result of *Noble (1998)* but with an explicit, verified certificate rather than just an algorithm.

3. **Phylogenetics → Tropical Geometry:** Maximum-likelihood phylogenetic tree search involves computing likelihood on trees (treewidth 1) and networks (bounded treewidth). The certificate compilation gives verified, efficient likelihood computation, with the tropicalization of the Potts model connecting to **tropical phylogenetic likelihood surfaces**.

4. **VLSI Design → Reliability Polynomials:** Series-parallel graphs (treewidth ≤ 2) dominate VLSI layout. The certificate bound gives $O(|E| \cdot 2^6)$ certificates for network reliability — efficiently verifiable reliability bounds for chip design.

### Conjecture with Testable Prediction

**Conjecture (Tight Certificate Bound):** For every $k \geq 1$, there exists a graph $G_k$ with treewidth $k$ and $|E|$ edges such that the optimal deletion/contraction certificate has size at least $c \cdot |E| \cdot 2^{k^2 - k}$ for a universal constant $c > 0$.

**Computational Test:** Implement `cert_compiler(n, k)` that:
1. Generates a random graph on $n$ vertices with treewidth $k$ (via random tree decomposition with bag size $k+1$).
2. Compiles the deletion/contraction certificate along the nice decomposition.
3. Returns `certificate_size / (|E| * 2^(k^2+k))`.

Plot this ratio for $n \in \{20, 50, 100, 200\}$ and $k \in \{1, 2, 3, 4, 5\}$. If the conjecture is true, the ratio should stay bounded above by 1 and below by a positive constant. If the ratio $\to 0$ as $n \to \infty$, the bound $2^{k^2+k}$ is not tight.

**Falsification:** Find a graph family where `certificate_size / (|E| * 2^(k^2+k))` is unbounded, or prove a lower bound of $\Omega(2^{k^2-k})$.
