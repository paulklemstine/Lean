## Precise Theorem Targets

### Theorem A: Finite exact representation on finite samples by closure-feature networks
Build directly on:

- `finite_function_exact_by_closure_features`
- `finite_domain_is_matmul`

Strengthen the existing exact finite-domain representation theorem into a network-factorization statement.

#### Mathematical statement
Let `K` be a finite set and `Y = ℝ`. Show that every function `f : K → ℝ` can be represented exactly by a finite closure-feature layer followed by a linear readout over `ℝ`, with the feature layer induced by finitely many closure predicates / closure coordinates.

This is the finite combinatorial skeleton of the universal approximation theorem.

#### Lean 4 target shape
```lean
theorem finite_exact_closure_network
  {n : ℕ} (f : Fin n → ℝ) :
  ∃ (m : ℕ) (Φ : Fin n → Fin m → ℝ) (w : Fin m → ℝ) (b : ℝ),
    (∀ i, f i = (∑ j, w j * Φ i j) + b)
```

This theorem should not be a tautological matrix encoding: the point is that `Φ` must arise from closure-generated features. So define a predicate such as:
```lean
def IsClosureFeatureFamily
  {X : Type*} (c : Set X → Set X) (Φ : X → Fin m → ℝ) : Prop := ...
```
and strengthen the theorem to:
```lean
theorem finite_exact_closure_network
  {X : Type*} [Fintype X] [DecidableEq X]
  (c : Set X → Set X)
  (hc : ClosureOperator c)
  (f : X → ℝ) :
  ∃ (m : ℕ) (Φ : X → Fin m → ℝ) (w : Fin m → ℝ) (b : ℝ),
    IsClosureFeatureFamily c Φ ∧
    ∀ x, f x = (∑ j, w j * Φ x j) + b
```

If the fully abstract closure-operator version is too ambitious for the first pass, prove it first for `X = Fin n` with a concrete closure operator generated by a finite family of subsets.

### Theorem B: Uniform approximation on compact intervals
This is the central universal approximation theorem. Do not overstate beyond what can be formalized. A highly plausible first breakthrough is for scalar continuous functions on a compact interval.

#### Mathematical statement
For every continuous `f : ℝ → ℝ` on `[a,b]` and every `ε > 0`, there exists a finite closure-operator network whose realization `g` satisfies
\[
\sup_{x \in [a,b]} |f(x)-g(x)| < \varepsilon.
\]

The closure network should be built from finitely many closure-threshold features on interval domains. The right formal route is probably via piecewise-constant or piecewise-affine approximation from finite partitions, then realization of each cell indicator / ramp by closure features.

#### Lean 4 target shape
A realistic formal signature:
```lean
theorem continuous_on_interval_uniformly_approximable_by_closure_network
  (f : ℝ → ℝ) (a b ε : ℝ)
  (hab : a < b) (hε : 0 < ε)
  (hcont : Continuous fun x : Set.Icc a b => f x) :
  ∃ (m : ℕ) (Φ : ℝ → Fin m → ℝ) (w : Fin m → ℝ) (bias : ℝ),
    IsIntervalClosureFeatureFamily a b Φ ∧
    ∀ x ∈ Set.Icc a b,
      |f x - ((∑ j, w j * Φ x j) + bias)| < ε
```

If dependent-domain continuity is awkward, use:
```lean
theorem continuous_on_interval_uniformly_approximable_by_closure_network
  (f : ℝ → ℝ) (a b ε : ℝ)
  (hab : a < b) (hε : 0 < ε)
  (hcont : Continuous f) :
  ∃ (m : ℕ) (Φ : ℝ → Fin m → ℝ) (w : Fin m → ℝ) (bias : ℝ),
    IsIntervalClosureFeatureFamily a b Φ ∧
    ∀ x, x ∈ Set.Icc a b →
      |f x - ((∑ j, w j * Φ x j) + bias)| < ε
```

This is already a field-opening theorem if the feature family is genuinely closure-theoretic.

### Theorem C: Approximation order comparable to piecewise-linear / ReLU approximation
You should not claim the full strongest known ReLU rates unless you can prove them. Instead, prove a clean asymptotic rate for Lipschitz functions on an interval or box.

#### Mathematical statement
If `f : [a,b] → ℝ` is `L`-Lipschitz, then there exists a closure network with `N` cells/features such that the sup-norm approximation error is at most `L * (b-a) / N` (or a comparable constant multiple). This matches the standard partition-based order of shallow piecewise-linear approximators.

#### Lean 4 target shape
```lean
theorem lipschitz_approx_order_closure_network
  (f : ℝ → ℝ) (a b L : ℝ) (N : ℕ)
  (hab : a < b) (hL : 0 ≤ L) (hN : 0 < N)
  (hlip : LipschitzOnWith L f (Set.Icc a b)) :
  ∃ (m : ℕ) (Φ : ℝ → Fin m → ℝ) (w : Fin m → ℝ) (bias : ℝ),
    IsIntervalClosureFeatureFamily a b Φ ∧
    m ≤ N + 1 ∧
    ∀ x, x ∈ Set.Icc a b →
      |f x - ((∑ j, w j * Φ x j) + bias)| ≤ L * (b - a) / N
```

This theorem is the one that turns the story from “expressive” to “competitive with classical neural approximation.”

Use `relu_idempotent` conceptually here: idempotence is not an obstacle to approximation, but a structural asset.

### Theorem D: Certified robustness from closure radius
This is where the architecture becomes scientifically different from ordinary neural nets.

Build on:
- `same_label_within_radius`
- potentially `ecoc_decoder_robust_of_pairwise_radius_count`

#### Mathematical statement
Suppose a classifier is constant on closure balls / closure neighborhoods of radius `r`. Then any perturbation of size at most `r` preserves the predicted label. Extend this from a single closure feature to a finite closure network with an argmax decoder.

#### Lean 4 target shape
A scalar-label version:
```lean
theorem closure_network_same_label_within_radius
  {X Y : Type*} [PseudoMetricSpace X]
  [DecidableEq Y]
  (f : X → Y) (x : X) (r : ℝ)
  (hr : 0 ≤ r)
  (hstable : ∀ y, dist x y ≤ r → f y = f x) :
  ∀ y, dist x y ≤ r → f y = f x
```
This may look tautological, so the actual theorem should derive `hstable` from closure-network structure:
```lean
theorem closure_network_certified_radius
  {X : Type*} [PseudoMetricSpace X]
  {C : Type*} [Fintype C] [DecidableEq C]
  (net : ClosureClassifier X C)
  (x : X) :
  ∃ r ≥ 0, ∀ y, dist x y ≤ r → net y = net x
```

A stronger and more impactful theorem would combine feature margins with ECOC decoding:
```lean
theorem closure_ecoc_certified_radius
  {X : Type*} [PseudoMetricSpace X]
  (net : ClosureECOCClassifier X)
  (x : X) :
  ∃ r > 0, ∀ y, dist x y ≤ r → net y = net x
```
with proof reducing to `ecoc_decoder_robust_of_pairwise_radius_count`.

This is likely the theorem that transforms the project from approximation theory into certified robust learning.

## Proof Strategy Architecture

### Strategy 1: Finite partition -> exact discrete representation -> uniform approximation
This is the most promising route.

1. **Discretize the compact domain**:
   For `f : ℝ → ℝ` continuous on `[a,b]`, use uniform continuity on compact intervals to choose a partition with mesh small enough that oscillation on each cell is `< ε`.

2. **Construct a step or cellwise-constant approximant**:
   Define `g` by choosing one representative value per partition cell. Then prove
   \[
   \sup_{x \in [a,b]} |f(x)-g(x)| < ε.
   \]

3. **Realize the cellwise approximant by closure features**:
   Encode each interval cell using closure-threshold or closure-membership features. Then express `g` as a finite weighted sum of these features. This is where `finite_function_exact_by_closure_features` should be repurposed: first on the finite partition index set, then pulled back along the partition map `x ↦ cell(x)`.

Why this is best: it isolates all analytic difficulty in standard compactness/uniform continuity, and all representation difficulty in finite exact realization, where you already have catalog support.

---

### Strategy 2: Piecewise-affine approximation via idempotent/ReLU bridge
This is more ambitious and conceptually beautiful.

1. Use standard approximation of continuous functions by piecewise-affine functions on compact intervals.
2. Show piecewise-affine “hinges” can be represented or simulated by compositions of closure operators and idempotent semimodule operations.
3. Use `relu_idempotent` to build a formal equivalence or embedding of ReLU-style units into closure units.

Why this matters: if successful, this proves closure networks are not just universal, but structurally connected to classical deep learning through idempotence. It could become a new algebraic semantics of neural architectures.

Risk: formalizing the exact representation of hinges by closure maps may be technically delicate.

---

### Strategy 3: Order-theoretic Stone–Weierstrass analogue for closure algebras
This is the most revolutionary and the least likely to finish quickly.

1. Define an algebra/lattice of closure-generated functions on a compact ordered space.
2. Prove it separates points and contains constants.
3. Derive density in `C(K, ℝ)` under sup norm by an order-theoretic approximation theorem.

Why this would be paradigm-shifting: it would create a genuine analogue of Stone–Weierstrass for idempotent/closure architectures.

Risk: substantial foundational work and possible mismatch with existing Mathlib topology APIs.
