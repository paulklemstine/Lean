### Precise Mathematical Targets

Work over a finite alphabet `α` with decidable equality. Represent words as `List α`. A tropical weighted language should be a map
`L : List α → WithTop ℕ`
or, if cleaner for algebraic closure, `L : List α → ℕ∞`.
Use the min-plus convention:
- addition in the semiring = `min`,
- multiplication = ordinary addition of costs.

If Mathlib support for `WithTop ℕ` is smoother than for a custom tropical semiring, prefer that. The point is formal rigidity, not notation purity.

Define the **right residual** of `L` by
`residual L u : List α → WithTop ℕ := fun v => L (u ++ v)`.

Define the **tropical Nerode equivalence**
`u ~L v :↔ residual L u = residual L v`.

Then prove the following theorem suite.

### Core theorem 1: canonical tropical Nerode equivalence
```lean
def TropicalResidual {α : Type*} (L : List α → WithTop ℕ) (u : List α) : List α → WithTop ℕ :=
  fun v => L (u ++ v)

def TropicalNerode {α : Type*} (L : List α → WithTop ℕ) (u v : List α) : Prop :=
  TropicalResidual L u = TropicalResidual L v

theorem tropicalNerode_equivalence
  {α : Type*} (L : List α → WithTop ℕ) :
  Equivalence (TropicalNerode L)
```

### Core theorem 2: right congruence
```lean
theorem tropicalNerode_right_invariant
  {α : Type*} (L : List α → WithTop ℕ) (u v w : List α)
  (h : TropicalNerode L u v) :
  TropicalNerode L (u ++ w) (v ++ w)
```

This is the tropical analogue of the classical Nerode right congruence, but now at the level of weighted residuals.

This statement is often more Lean-friendly and mathematically sharper.

### Core theorem 4: construction of the Nerode automaton
Define the canonical automaton whose states are residuals / equivalence classes. Its transition on symbol `a` sends the class of `u` to the class of `u ++ [a]`. Initial state is the class of `[]`. Output / final weight at state `[u]` is `L u`.

Suggested shape:
```lean
structure TropicalAutomaton (α : Type*) where
  State : Type*
  step : State → α → State
  init : State
  output : State → WithTop ℕ

def NerodeAutomaton {α : Type*} (L : List α → WithTop ℕ) : TropicalAutomaton α := ...
```

Then prove correctness:
```lean
theorem NerodeAutomaton_recognizes
  {α : Type*} [DecidableEq α]
  (L : List α → WithTop ℕ) :
  recognizes (NerodeAutomaton L) L
```

where `recognizes` should mean that the automaton’s evaluation on any word equals `L`.

### Core theorem 5: minimality / universal property
This is the real prize. Prove that every tropical automaton recognizing `L` admits a canonical surjective morphism onto the Nerode automaton, or equivalently that the number of reachable states is at least the number of residuals.

A clean theorem:
```lean
theorem nerodeAutomaton_minimal
  {α : Type*} [DecidableEq α]
  (L : List α → WithTop ℕ)
  (A : TropicalAutomaton α)
  (hA : recognizes A L) :
  ∃ f : Reachable A → Quot (setoidOf (TropicalNerode L)),
    Function.Surjective f
```

Or, if you define automaton morphisms:
```lean
theorem nerodeAutomaton_universal
  {α : Type*} [DecidableEq α]
  (L : List α → WithTop ℕ)
  (A : TropicalAutomaton α)
  (hA : recognizes A L) :
  ∃ φ : AutomatonMorphism (reachableSubautomaton A) (NerodeAutomaton L), Surjective φ
```

A cardinality corollary:
```lean
theorem nerode_state_lower_bound
  {α : Type*} [Fintype α] [DecidableEq α]
  (L : List α → WithTop ℕ)
  (A : TropicalAutomaton α)
  (hA : recognizes A L) [Finite (Reachable A)] :
  Fintype.card (Quot (setoidOf (TropicalNerode L))) ≤ Fintype.card (Reachable A)
```

This is the weighted-tropical analogue of DFA minimality and should be treated as the central conceptual contribution.

### Core theorem 6: finite syntactic transformation semigroup
The deepest extension is algebraic: the residuals carry a right action by words; each word induces a transformation on residual states. The image is the tropical syntactic transformation monoid. Prove recognizability iff this action monoid is finite.

A tractable formalization target is not “all weighted syntactic congruences” at once, but the finite transformation monoid generated by symbol actions on residual states.

```lean
def residualAction
  {α : Type*} (L : List α → WithTop ℕ) :
  List α → (Quot (setoidOf (TropicalNerode L)) → Quot (setoidOf (TropicalNerode L))) := ...

def TropicalSyntacticMonoid
  {α : Type*} (L : List α → WithTop ℕ) : Set (Quot (setoidOf (TropicalNerode L)) → Quot (setoidOf (TropicalNerode L))) := ...
```

Then aim for:
```lean
theorem tropical_recognizable_iff_finite_syntactic_action
  {α : Type*} [Fintype α] [DecidableEq α]
  (L : List α → WithTop ℕ) :
  TropicalRecognizable L ↔ Set.Finite (TropicalSyntacticMonoid L)
```

If full monoid structure is cumbersome, prove finiteness of the generated transformation set first. That already captures the essence and is enough for a first breakthrough.

### Idempotence refinement
The phrase “finite idempotent syntactic monoids” is bold but potentially too strong if interpreted as “every element idempotent.” That is generally false for arbitrary finite monoids. Be careful. A more defensible tropical statement is:

- the ambient semiring is idempotent;
- the syntactic algebra acts by monotone / min-plus linear operators;
- in finite dimension, certain closure operators become eventually idempotent.

If the original claim seems false, **pivot to a counterexample theorem**:
```lean
theorem not_every_finite_tropical_syntactic_monoid_is_pointwise_idempotent :
  ∃ (α : Type) (_ : Fintype α) (_ : DecidableEq α) (L : List α → WithTop ℕ),
    TropicalRecognizable L ∧
    ¬ (∀ f ∈ TropicalSyntacticMonoid L, Function.comp f f = f)
```

That would be scientifically valuable: it would prevent the project from ossifying around a false classical-to-tropical transfer. Then replace the false target by a correct one, e.g. eventual idempotence on reachable order ideals, Green-relation finiteness, or J-triviality under extra hypotheses.

## Proof Strategy Architecture

### Strategy A: Residual-function quotient construction
Most promising.

1. Define residuals as actual functions `List α → WithTop ℕ`.
   Then `TropicalNerode L u v` is simply function equality, so equivalence and right invariance become direct by `simp [TropicalResidual, List.append_assoc]`.

2. Construct `NerodeAutomaton L` using residuals themselves as states, avoiding quotient headaches initially:
   ```lean
   State := Set.range (TropicalResidual L)
   ```
   Transition is postcomposition by appending `[a]`. This avoids quotient transport and often makes correctness proofs easier.

3. After correctness and finiteness are established, show equivalence with the quotient-state version. This separates semantic construction from extensional quotient bureaucracy.

Why this is strongest: Lean handles function extensionality and `Set.range` states better than quotient recursion in early stages. You get the theorem package with less definitional friction.

### Strategy B: Reachable-state factorization through residuals
Best for minimality.

1. For any automaton `A` recognizing `L`, define the residual associated to a reachable state `q`:
   `ρ(q)(v) = output (run A q v)`.
   Show that if `q = run A init u`, then `ρ(q) = TropicalResidual L u`.

2. Define the factor map from reachable states to residual states by sending `q` to `ρ(q)`.
   Prove surjectivity because every residual is represented by the state reached after some prefix.

3. Deduce the cardinal lower bound and universal property.

Why this matters: this is the exact weighted analogue of the classical proof, and it makes the theorem feel inevitable rather than ad hoc.

### Strategy C: Syntactic-action finiteness via generated transformations
Best for the algebraic bridge.

1. On residual states, each symbol `a : α` induces a transformation `τ_a`.
   Words induce compositions of these transformations.

2. Show every word action is determined by its effect on finitely many residual states when the residual set is finite. Hence the syntactic action set embeds into the finite function space `Q → Q`.

3. Conversely, if the action monoid is finite, then the orbit of the initial residual under words is finite, yielding finitely many residuals and thus recognizability.

Why this is promising: it replaces abstract semigroup theory with finite-function combinatorics, which Lean formalizes well.

## Cross-Domain Connections to Exploit

1. **Optimization / shortest paths**  
   A min-plus automaton computes dynamic programming costs over words. The residual state after reading a prefix is a cost-to-go function. The Nerode quotient is therefore a compression theorem for dynamic programming state spaces.

2. **Tropical geometry**  
   Residual weighted languages can be viewed as piecewise-linear tropical objects. Finite residuality says the infinite family of prefix-shifted tropical functions collapses to finitely many tropical cells. This suggests a geometric interpretation of recognizability as finite tropical polyhedral complexity.

3. **Control theory / verification**  
   Tropical automata model resource-aware systems, timed costs, and scheduling. Minimality gives canonical compressed models for verification and synthesis.

4. **Cryptography / scattering semantics**  
   Since your catalog includes tropical cryptography and scattering duality bridges, frame the syntactic transformation monoid as a semiring action capturing observable cost profiles. Minimal residual models could become canonical leakage abstractions.

5. **Learning theory**  
   Classical Angluin-style learning relies on Myhill–Nerode finiteness. A tropical version points toward active learning of weighted automata from cost queries and equivalence queries.

## Suggested Lean Definitions

If no existing automaton structure is convenient, define a minimal one:

```lean
structure TropicalAutomaton (α : Type*) where
  State : Type*
  step : State → α → State
  init : State
  output : State → WithTop ℕ

def run {α : Type*} (A : TropicalAutomaton α) : A.State → List α → A.State
  | q, [] => q
  | q, a :: w => run A (A.step q a) w

def eval {α : Type*} (A : TropicalAutomaton α) (w : List α) : WithTop ℕ :=
  A.output (run A A.init w)

def recognizes {α : Type*} (A : TropicalAutomaton α) (L : List α → WithTop ℕ) : Prop :=
  ∀ w, eval A w = L w
```

Then define reachable states:
```lean
def Reachable {α : Type*} (A : TropicalAutomaton α) : Set A.State :=
  { q | ∃ w, run A A.init w = q }
```

You may later refine to weighted transition matrices if needed, but do not let abstraction overhead block the theorem.

## Risk Assessment and Counterexample Discipline

The strongest risk is the statement about “finite idempotent syntactic monoids.” Do not force a false theorem. Test tiny alphabets and tiny weighted languages first. If symbol actions permute residual states nontrivially, elementwise idempotence will fail. If so, convert that into a formal counterexample and replace the theorem by one of these stronger-and-correct alternatives:

- finite tropical syntactic **transformation** monoid,
- eventual idempotence of powers,
- aperiodicity under additional monotonicity hypotheses,
- J-triviality for prefix-closed cost languages,
- idempotence of the semiring-generated closure operators rather than all word actions.

A clean negative result can be as revolutionary as a positive one if it identifies the correct algebraic invariant.
