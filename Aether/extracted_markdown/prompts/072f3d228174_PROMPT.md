## Research Task: GL₃ tropical Satake surjectivity from Levi-compatible adjacent-facet support data

Research Mode: PROVE

Work in a new file
`Tropical/Langlands/GL3/TropicalSatakeSurjectivity.lean`.

The target is to upgrade the existing GL₃ tropical Satake development from injectivity/reconstruction to a genuine image theorem: characterize exactly which dominant-chamber support data arise from compactly supported tropical Hecke functions, and show that tropical convolution is transported to an explicit additive/Minkowski convolution on this support cone.

A good formalization strategy is to make the admissible support data completely concrete on triples of naturals with dominance built in, rather than introducing a large amount of abstract root-datum machinery. The natural base type is:
```lean
def GL3Dom := { μ : Fin 3 → ℕ // μ 0 ≥ μ 1 ∧ μ 1 ≥ μ 2 }
```
or equivalently triples `(a,b,c) : ℕ × ℕ × ℕ` with `a ≥ b ≥ c`. If the existing files already use a dominant-coweight structure for GL₃, reuse it; otherwise keep the above subtype and prove the needed lemmas locally.

A support datum should be a finitely supported tropical weight function
```lean
def SupportDatum := GL3Dom → ℤ
```
or `ℝ` if the current tropical Hecke layer is real-valued. If finite support is encoded by vanishing off a finite set, use:
```lean
def FiniteSupport (h : SupportDatum) : Prop :=
  ∃ s : Finset GL3Dom, ∀ μ, μ ∉ s → h μ = 0
```
If the Hecke side already uses `WithBot ℤ` or `ℤ∞`, adapt the statements accordingly, but keep the admissibility axioms on a concrete chamber function.

The key new predicate should package the image conditions:
```lean
structure AdmissibleSupport (h : SupportDatum) : Prop where
  finite_support : FiniteSupport h
  normalized : h 0 = 0
  concave_dom :
    ∀ μ ν ξ, DomMidpointRelation μ ν ξ → h ξ ≥ min (h μ) (h ν)
  levi_GL2_left :
    ∀ μ, LeftLeviCompatible h μ
  levi_GL2_right :
    ∀ μ, RightLeviCompatible h μ
  adjacent_facet_horn :
    ∀ a b c d, AdjacentFacetConfig a b c d → HornRhombusIneq h a b c d
```
You should not get stuck on the exact names above; the point is to isolate three kinds of hypotheses:
1. finite support/normalization,
2. rank-1 and rank-2 Levi marginal compatibility,
3. adjacent-facet rhombus/Horn inequalities on the dominant chamber.

The second main theorem should identify the image as a semiring and express convolution on support data. Define the induced tropical convolution of support data by maximizing over decompositions:
```lean
def supportConv (h₁ h₂ : SupportDatum) : SupportDatum :=
  fun μ => supᵀ {z | ∃ μ₁ μ₂, DomAdd μ₁ μ₂ μ ∧ z = h₁ μ₁ + h₂ μ₂}
```
For finitely supported integer-valued data, this can be implemented by a `Finset.sup` over the product of supports. Then prove closure:
```lean

    {h₁ h₂ : SupportDatum}
    (hh₁ : AdmissibleSupport h₁)
    (hh₂ : AdmissibleSupport h₂) :
    AdmissibleSupport (supportConv h₁ h₂)
```
and the compatibility with Hecke convolution:
```lean
theorem satakeSupport_mul
    (f g : TropicalHeckeFunction GL3) :
    satakeSupport (f * g) = supportConv (satakeSupport f) (satakeSupport g)
```
From these, derive an image/equivalence theorem:
```lean

    ∃ e : TropicalHeckeFunction GL3 ≃ {h : SupportDatum // AdmissibleSupport h},
```

where `AdmissibleSupportSemiring` is the subtype of admissible support data equipped with `supportConv` and pointwise tropical addition.

### Suggested proof architecture

1. **Define a local reconstruction candidate from Levi marginals.**  
   The hard conceptual step is to turn pairwise GL₂-compatible marginals into a global GL₃ support function. Since injective reconstruction from full Levi data is already available, do not attempt to reconstruct from scratch. Instead:
   - build the candidate `f` using the existing reconstruction theorem applied to the Levi marginals extracted from `h`,
   - prove that the support of this reconstructed `f` agrees with `h` on each adjacent facet,
   - then invoke the existing adjacent-facet faithfulness/injectivity theorem to upgrade facetwise agreement to full equality.

   This should produce the existence part with minimal new machinery. In Lean, the pattern should look like:
   ```lean
   obtain ⟨f, hf_rec⟩ := existing_reconstruction_from_Levi_data ...
   have hfacet : AdjacentFacetSupport (satakeSupport f) = AdjacentFacetSupport h := ...
   have hsupp : satakeSupport f = h := existing_GL3_injectivity_from_adjacent_facets hfacet
   exact ⟨f, hsupp⟩
   ```

2. **Reduce uniqueness entirely to the previously proved injectivity theorem.**  
   Once existence is built, uniqueness should not require new combinatorics. Prove:
   ```lean
   theorem tropicalHecke_ext_of_same_support
       {f g : TropicalHeckeFunction GL3}
       (hfg : satakeSupport f = satakeSupport g) : f = g
   ```
   as a corollary of the established GL₃ injectivity result. Then uniqueness in `∃!` is immediate.

3. **Package the Horn/rhombus inequalities as exactly the missing gluing condition.**  
   The mathematically important lemma is that the adjacent-facet inequalities are not merely necessary, but sufficient to glue the rank-2 Levi data to a global chamber support function. A useful intermediate statement is:
   ```lean
   theorem admissibleSupport_of_facetwise_Levi_gluing
       (h : SupportDatum)
       (hL : LeftLeviCompatible h)
       (hR : RightLeviCompatible h)
       (hH : AdjacentFacetHornCompatible h) :
       ∃ g : SupportDatum,
         GlobalChamberExtension g ∧
         RestrictLeftFacet g = RestrictLeftFacet h ∧
         RestrictRightFacet g = RestrictRightFacet h
   ```
   Then show `g = h` because `h` already satisfies the same chamber axioms. This isolates the genuinely new polyhedral content.

4. **For convolution closure, prove the axioms one by one on the `Finset` formula for `supportConv`.**  
   Finite support should be straightforward by taking the image of `supp h₁ ×ˢ supp h₂` under dominant addition. The Levi compatibility and Horn inequalities should be proved by selecting near-optimal decompositions and using the corresponding inequalities for each summand:
   - for finite support: build an explicit finite support set,
   - for normalization: use the unique decomposition of `0`,
   - for Levi compatibility: push a decomposition of `μ` to decompositions of the Levi projections,
   - for rhombus inequalities: combine maximizing decompositions for opposite vertices and use the summandwise Horn inequalities.

   The key technical lemma should be something like:
   ```lean
   theorem supportConv_rhombus
       {h₁ h₂ : SupportDatum}
       (H₁ : AdjacentFacetHornCompatible h₁)
       (H₂ : AdjacentFacetHornCompatible h₂) :
       AdjacentFacetHornCompatible (supportConv h₁ h₂)
   ```
   The proof should mirror the standard fact that submodular/M-concave functions are closed under max-plus convolution.

5. **Promote to a semiring isomorphism only after proving image characterization and convolution compatibility.**  
   Avoid constructing algebraic instances too early. First prove:
   ```lean
   theorem range_satakeSupport :
     Set.range satakeSupport = {h | AdmissibleSupport h}
   ```
   then define the subtype and transport operations. This will keep typeclass noise under control.

### Lean-specific implementation advice

- Prefer `Finset`-based support definitions over abstract `Finsupp` unless the current Hecke files already use `Finsupp`; finite support lemmas are easier to prove concretely.
- If `supportConv` uses a maximum over a finite set, define the candidate support set explicitly:
  ```lean
  def convSupportSet (s₁ s₂ : Finset GL3Dom) : Finset GL3Dom := ...
  ```
  and prove membership lemmas before any algebraic theorem.
- If the exact dominant-addition operation is awkward on subtypes, define addition on raw triples and then prove closure into the dominant chamber under the hypotheses you actually use.
- For uniqueness proofs, use extensionality on support data first, then invoke the existing Hecke injectivity theorem; do not unfold the Hecke function structure unless absolutely necessary.
- If the full semiring isomorphism is too large for one pass, prove the surjectivity and closure theorems first, then add the algebraic packaging as a second layer.

### Why this matters

This is the missing “image theorem” for the GL₃ tropical Satake program. Injectivity and convolution-faithfulness show that support data remember the Hecke function; surjectivity identifies exactly which tropical polyhedral data come from representation-theoretic objects. The result would turn the GL₃ tropical Satake transform into a concrete equivalence between a Hecke-theoretic algebra and an explicitly axiomatized cone of Levi-compatible, Horn-concave support functions. That is mathematically significant for two reasons:

1. it gives the first genuinely structural classification theorem in the GL₃ tropical direction, not just a reconstruction lemma;
2. it isolates adjacent-facet Horn inequalities as the complete set of tropical constraints, making the Hecke algebra computable in polyhedral terms and setting up the natural next step toward higher-rank tropical Satake and tropical MV/Hive geometry.

A successful formalization here would likely become the backbone for any future GLₙ tropical Satake work, because it shows how local Levi data plus rhombus inequalities glue to a global Hecke object and how convolution is transported to max-plus polyhedral convolution.
