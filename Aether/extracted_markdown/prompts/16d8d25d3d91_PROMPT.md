## Core Vision

Classical Schützenberger/Fliess theory says that finite rank of the Hankel matrix detects rationality/recognizability and controls minimal realizations. The tropical world should admit an equally powerful theorem, but the correct invariant is not ordinary linear rank: it is **finite generation of the Hankel semimodule together with shift stability and observability in the idempotent/residuated sense**.

This would be a breakthrough because it would:

- establish a **spectral realization principle for tropical computation**;
- provide a **certified learning/reconstruction theorem** for weighted automata/transducers from finite windows;
- open a formal bridge between:
  - tropical geometry,
  - automata minimization,
  - idempotent functional analysis,
  - system identification,
  - and algorithmic verification.

This is the tropical analogue of moving from “a behavior exists” to “a behavior has a canonical finite state-space geometry.”

### Theorem 1: Finite tropical Hankel realization duality

Target mathematical statement:

> Let `A` be finite and let `S : List A → Trop`. Suppose the Hankel row semimodule
> `R_S := span { row u | u ∈ A* }`
> is finitely generated and stable under all left residual shifts induced by letters of `A`, and suppose the corresponding observable quotient is separated by evaluation at suffixes. Then there exists a finite tropical weighted automaton `T` such that the behavior of `T` is exactly `S`. Conversely, every finite tropical weighted automaton has finitely generated shift-stable Hankel row semimodule. Moreover, if `R_S` is generated by `n` rows and satisfies reachability/observability, then `S` admits a reachable-observable realization with exactly `n` states, and no realization with fewer states exists.

A Lean-oriented signature skeleton:

```lean
theorem tropical_hankel_realization_duality
  {A : Type _} [Fintype A] [DecidableEq A] :
  ∀ (S : List A → Trop),
    FiniteGeneratedShiftStableHankelRowSemimodule S →
    ObservableHankelSeries S →
    ∃ (n : ℕ) (T : TropicalWeightedAutomaton A n),
      TropicalBehavior T = S ∧
      Reachable T ∧ Observable T ∧
      MinimalStateCount T = hankelGeneratorRank S
```

If `Trop` is awkward, generalize:

```lean
theorem idempotent_hankel_realization_duality
  {K : Type _} [CanonicallyOrderedCommSemiring K] [IsIdempotentAdd K]
  {A : Type _} [Fintype A] [DecidableEq A] :
  ∀ (S : List A → K),
    FiniteGeneratedShiftStableHankelRowSemimodule K S →
    ObservableHankelSeries K S →
    ∃ (n : ℕ) (T : WeightedAutomaton K A n),
      Behavior K T = S ∧
      Reachable K T ∧ Observable K T ∧
      MinimalStateCount K T = hankelGeneratorRank K S
```

This more abstract theorem is actually preferable if it makes the algebra cleaner; instantiate later to tropical semirings.

### Theorem 2: Certified reconstruction from a finite Hankel window

Target mathematical statement:

> If a series `S` has finitely generated shift-stable Hankel semimodule of generator rank `n`, then there exists a finite prefix/suffix window `P × Q` such that from the restricted Hankel data `H_S | P×Q` and a certified generating family of rows, one can algorithmically reconstruct a reachable-observable tropical weighted automaton `T_min` realizing `S`. The output is certified minimal.

Lean signature skeleton:

```lean
theorem certified_tropical_hankel_reconstruction
  {A : Type _} [Fintype A] [DecidableEq A] :
  ∀ (S : List A → Trop),
    FiniteGeneratedShiftStableHankelRowSemimodule S →
    ObservableHankelSeries S →
    ∃ (P Q : Finset (List A)) (n : ℕ)
      (cert : HankelWindowCertifiesGenerators S P Q n)
      (T : TropicalWeightedAutomaton A n),
        ReconstructionFromWindow S P Q cert = some T ∧
        TropicalBehavior T = S ∧
        Reachable T ∧ Observable T ∧
        MinimalStateCount T = n
```

This theorem should explicitly use a finite witness of generation, not just existence in the infinite Hankel object. The phrase “certified reconstruction” matters: the algorithm should return not merely a candidate, but a proof object that the candidate realizes the target series and is minimal.

### Theorem 3: Uniqueness of minimal realization

Target mathematical statement:

> Any two finite reachable-observable tropical weighted automata realizing the same series and having minimal state count are tropically conjugate/isomorphic; equivalently, their state semimodules are isomorphic in a way intertwining transition structure, initial vector, and output vector.

Lean signature skeleton:

```lean
theorem tropical_minimal_realization_unique
  {A : Type _} [Fintype A] [DecidableEq A] :
  ∀ {n m : ℕ} (T₁ : TropicalWeightedAutomaton A n) (T₂ : TropicalWeightedAutomaton A m),
    Reachable T₁ →
    Observable T₁ →
    Reachable T₂ →
    Observable T₂ →
    TropicalBehavior T₁ = TropicalBehavior T₂ →
    MinimalStateCount T₁ = n →
    MinimalStateCount T₂ = m →
```

## Exact Algebraic Conditions You Should Isolate

The theorem becomes powerful only if the hypotheses are exact. Isolate and formalize these conditions carefully:

1. **Finite generation of the row Hankel semimodule**
   - existence of finitely many prefixes `u₁, …, uₙ` whose rows generate all rows under tropical linear combination.

2. **Shift stability**
   - for each letter `a : A`, the left shift of a row generated by `u` corresponds to the row generated by `a :: u` or `u ++ [a]`, depending on your convention;
   - this gives transition operators on generators.

3. **Observability/separation**
   - distinct generator states induce distinct suffix-evaluation functionals;
   - this is the tropical replacement for classical observability rank.

4. **Reachability**
   - every generator state is generated from the initial row by iterated shifts.

5. **Residual compatibility / closure**
   - if you choose a residuation-style formulation, prove the transition action respects the semimodule structure and preserves finite generation.

These conditions should not be decorative; they should be exactly what lets you reconstruct the automaton from semimodule data.

## Most Promising Proof Architecture

### Strategy A: Semimodule basis extraction and direct automaton synthesis
This is likely the strongest path.

1. **Define a finite generating family of rows**
   - pick generators `g₁, …, gₙ` of `R_S`;
   - show every shifted row `row (a ++ u)` decomposes as a tropical linear combination of these generators.

2. **Construct transition matrices**
   - for each `a : A`, define the `n × n` tropical matrix `M_a` sending generator coordinates of `row u` to those of `row (u ++ [a])` or the corresponding convention;
   - define initial vector from `row []`;
   - define output vector by evaluation at `[]`.

3. **Prove realization**
   - induct on words to show the automaton state after reading `u` corresponds exactly to the coordinates of `row u`;
   - conclude the automaton behavior is `S`.

4. **Prove minimality**
   - any `k`-state automaton realizing `S` yields a `k`-generated row semimodule;
   - hence `hankelGeneratorRank S ≤ k`;
   - your constructed automaton uses exactly `hankelGeneratorRank S` states.

Why this is promising: it mirrors the strongest part of classical realization theory while remaining fully constructive and well-suited to Lean.

---

### Strategy B: Factorization of the Hankel kernel through a finite state semimodule
This is conceptually elegant and may give cleaner uniqueness.

1. Prove that a finite automaton realization induces a factorization
   `H_S(u,v) = α · M_u · β_v`
   in tropical matrix language.

2. Show that finite generation of the row semimodule yields a finite semimodule object `X` and morphisms
   - `reach : A* → X`,
   - `obs : X → (A* → Trop)`,
   such that `row u = obs (reach u)`.

3. Reconstruct the automaton from the monoid action of `A*` on `X`.

4. Uniqueness follows from the universal property of the reachable-observable quotient.

Why this is promising: it exposes the theorem as a categorical duality, not just a matrix construction. It could connect directly to your previous closure/Kolmogorov duality work.

---

### Strategy C: Myhill–Nerode-style tropical congruence quotient
This is riskier but potentially revolutionary.

1. Define a tropical behavioral equivalence on prefixes:
   `u ~ v` iff `row u = row v` in the Hankel semimodule or in its observable quotient.

2. Show finite generation + observability implies a finite quotient semimodule/state set.

3. Build the canonical automaton on equivalence classes/generator classes.

4. Prove it is the unique minimal realization.

Why this is powerful: it imports the deepest automata-minimization intuition into idempotent algebra. But in Lean, quotient machinery and semimodule equality may be heavier than Strategy A.

**Recommendation:** Use **Strategy A** for the existence/minimality theorem, then derive uniqueness with a **Strategy B** universal-property argument. Strategy C can be recorded in `FUTURE_DIRECTIONS.md` if it becomes too costly.

## Lean 4 Formalization Guidance

### Suggested definitions
You may need compact, robust definitions like:

```lean
def HankelRow (S : List A → K) (u : List A) : List A → K :=
  fun v => S (u ++ v)

def ShiftRow (a : A) (f : List A → K) : List A → K :=
  fun v => f (a :: v)  -- or adapted to append convention

  init : Fin n → K
  trans : A → Fin n → Fin n → K
  out : Fin n → K
```

Behavior can be defined recursively via tropical matrix products or path semantics. Use whichever is easier to prove against the Hankel construction.

### Prefer finite-index state spaces
To avoid quotient headaches, define automata on `Fin n`. Then prove existential realization with some `n`.

### Separate existential and algorithmic layers
First prove:
- existence of finite realization,
- lower bound/minimality,
- uniqueness.

Then add:
- reconstruction from finite window.

This decomposition keeps the proof graph manageable.

### Avoid premature dependence on advanced tropical rank libraries
If Mathlib lacks the exact tropical rank notion you want, define:

```lean
def hankelGeneratorRank (S : List A → K) : ℕ := sInf {n | ... }
```

or use an existential minimality theorem:
- there exists `n`,
- realization with `n` states,
- every realization has at least `n` states.

This is mathematically stronger than waiting on a polished rank API.

### 3. Idempotent functional analysis × Formal language theory

### 4. Complexity theory × Program semantics

Just as Gibbs boundary data can reconstruct a global phase object, finite Hankel windows reconstruct a global automaton behavior. This is a nontrivial analogy to closure duality and should guide how you formalize certification.
