### Theorem 2: Uniform spectral gap from rank-aware character certificate
This is the central transference theorem.

**Mathematical statement:**
For fixed rank `n`, if there is a rank-`n` Deligne–Lusztig certificate giving
\[
\left|\frac{\chi_\rho(s)}{\chi_\rho(1)}\right| \le \frac{C_n}{q}
\quad\text{for all nontrivial irreducible }\rho,
\]
then for all sufficiently large odd prime powers `q`, the normalized averaging operator attached to a symmetric generating set built from `s,t` has second eigenvalue bounded away from `1`, hence a uniform spectral gap `ε_n > 0`.

Suggested Lean signature:
```lean
theorem uniform_gap_from_rank_certificate
    (n q : ℕ) [Fact q.Prime] (hq_odd : q % 2 = 1)
    (cert : DLRankCharacterBoundCertificate n q) :
    ∃ εn : ℝ, 0 < εn ∧
      spectralGap (cayleyGraphTwoGen cert.s cert.t) ≥ εn
```

A sharper version, closer to the intended mathematics:
```lean
theorem uniform_gap_from_character_ratio_bound
    (n : ℕ) :
    ∃ Cn εn : ℝ, 0 < Cn ∧ 0 < εn ∧
    ∀ q : ℕ, [Fact q.Prime] →
      q % 2 = 1 →
      ∀ s t,
      IsRegularToralSymplectic n q s →
      GeneratesTop s t →
      (∀ ρ : IrreducibleRep (symplecticGroup (Fin (2*n)) (ZMod q)),
        ρ ≠ 1 → ‖characterRatio ρ s‖ ≤ Cn / q) →
      spectralGap (cayleyGraphTwoGen s t) ≥ εn
```

Even if some analytic pieces in the catalog only support a slightly weaker conclusion, you should formulate and prove the strongest theorem that the current machinery genuinely sustains.

## Suggested Proof Strategies

You must present at least **2–3 proof strategy routes** in comments or documentation, and pursue the most promising one in Lean.

### Strategy A: Irreducible-charpoly maximal-subgroup exclusion
Most promising for the generation theorem.

1. Use `eq_bot_or_top_of_charpoly_irreducible` as the seed mechanism: an element with irreducible characteristic polynomial strongly constrains invariant subspaces.
2. Upgrade from linear irreducibility to **symplectic irreducibility**, excluding preservation of proper isotropic or nondegenerate decompositions.
3. Conclude the subgroup cannot lie in the standard geometric maximal subgroups; then deduce it is all of `Sp₂ₙ(𝔽_q)`.

Why promising: it converts existing catalog algebra into a rank-aware subgroup classification argument with minimal dependence on full Deligne–Lusztig formalization.

### Strategy B: Abstract transference from representation bounds
Best for the spectral gap theorem.

1. Formalize the averaging operator associated to `{s, s⁻¹, t, t⁻¹}`.
2. Decompose the regular representation into trivial and nontrivial irreducibles.
3. Use the certificate bound on character ratios to bound operator norms on each nontrivial isotypic component, then combine via a `calc` chain to obtain the gap.

Why promising: this likely aligns best with existing `Sp4SpectralGap` machinery and is conceptually modular. Once done, the theorem becomes reusable for any future family with similar character estimates.

### Strategy C: Torus-type induction on rank
Ambitious, potentially revolutionary if it works.

1. Define a recursive model of regular torus types in type `C_n`.
2. Prove that the relevant regularity/self-reciprocity property persists under rank extension.
3. Transfer character-ratio control from `n` to `n+1` through an explicit torus embedding or combinatorial Weyl-group analysis.

Why promising: if successful, this gives the first genuinely **inductive** route to higher-rank expansion. But it may require more infrastructure than this cycle permits. Pursue as a conjectural scaffold if full proof is out of reach.
