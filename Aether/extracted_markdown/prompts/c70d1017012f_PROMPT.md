## Assignment: Direction 5: Neural Proof Guidance via Cycle Pressure Features

### The Deep Mathematical Insight

Before we can train a neural network on topological features, we must **prove** those features carry genuine information that tree-like features cannot capture. This is not an ML experiment—it is a **structural information-theoretic theorem** about proof spaces, with the ML validation as a downstream corollary. The formal backbone: cycle pressure is a *sufficient statistic* for proof-theoretic branching complexity, and this sufficiency is *strict*—no tree-local feature set can replicate it.

### Novel Definitions (Required by Depth Mandate)

**Definition 1: Proof Search Branching Factor.** For a proposition $x$ in proof graph $G$, define the *branching factor* $\beta(G, x)$ as the maximum, over all complete proof strategies, of the minimum number of distinct tactic applications that must be tried before the strategy can determine whether a proof exists from $x$. This captures the intrinsic difficulty of proof search, independent of heuristic ordering.

**Definition 2: Topological Feature Vector.** For node $x$ in proof graph $G$ with $\varepsilon^*$-neighborhood $G_{\varepsilon^*}(x)$, define:
$$\Phi_{\text{topo}}(G, x) = \big(\text{lcp}(G_{\varepsilon^*}, x),\; \deg(x),\; \text{cr}(G_{\varepsilon^*}),\; \text{Betti}_1(G_{\varepsilon^*})\big)$$
where $\text{cr}$ is the cycle rank and $\text{Betti}_1$ is the first Betti number of the neighborhood.

**Definition 3: Tree-Local Feature Vector.** Define $\Phi_{\text{tree}}(G, x)$ as the vector of all features computable from the tree of radius $\varepsilon^*$ around $x$ *ignoring all cycle structure*—degree sequence, depth distribution, subtree size—any feature that does not distinguish a cycle from a tree with the same degree sequence.

*Statement:* There exist proof graphs $G_1, G_2$ and nodes $x_1 \in V(G_1)$, $x_2 \in V(G_2)$ such that $\Phi_{\text{tree}}(G_1, x_1) = \Phi_{\text{tree}}(G_2, x_2)$ but $\text{lcp}(G_1, x_1) \neq \text{lcp}(G_2, x_2)$ and $\beta(G_1, x_1) \neq \beta(G_2, x_2)$. ### Proof Strategies

**Strategy A (Most Promising): Information-Theoretic via Kolmogorov Complexity.**
1. Define Kolmogorov complexity $K(\pi)$ of a proof $\pi$ as the minimum description length.
2. Show that $\beta(G, x) \geq 2^{K(\text{optimal proof from } x) - O(1)}$—high-complexity proofs force exponential branching.
3. Show that cycle pressure lower-bounds the Kolmogorov complexity of the shortest proof, because each independent cycle forces a choice point that cannot be compressed.
4. Combine to get the logarithmic lower bound. *This is most promising because it directly connects topology to information content via a well-established framework.*

**Strategy B: Combinatorial via Cycle Rank and Decision Trees.**
1. Model proof search as a decision tree over tactic applications.
2. Show that each independent cycle in $G_{\varepsilon^*}(x)$ forces a distinct branch in any complete decision tree (because the cycle represents a genuine choice that cannot be resolved by tree-local information alone).
3. Use the cycle rank lower bound on decision tree depth to establish $\beta(G, x) \geq \text{cr}(G_{\varepsilon^*})$.
4. Refine using the logarithmic amplification from the number of choice points.

**Strategy C: Homological via Betti Numbers.**
1. Interpret the proof graph as a simplicial complex (1-skeleton).
2. Show that $\dim H_1(G_{\varepsilon^*}(x)) = \text{cr}(G_{\varepsilon^*})$ bounds the number of topologically distinct proof paths.
3. Use the universal coefficient theorem to connect Betti numbers to search complexity.
4. *Weaker than Strategy A but provides a bridge to algebraic topology for future work.*
