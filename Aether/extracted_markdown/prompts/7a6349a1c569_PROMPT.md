## Core theorem target

Define a finite tropical incidence structure on `Fin 7` points and `Fin 7` lines, inspired by the Fano plane but interpreted in min-plus geometry:

- each line is represented by a tropical affine functional,
- a point lies on a line when the minimum in the functional is attained at least twice,
- a security margin certifies non-incidence,
- and compatibility conditions encode the 3-points-per-line / 3-lines-through-point combinatorics.

You do **not** need to force classical Fano plane coordinatization over `𝔽₂`. Instead, prove a tropical rigidity theorem: if a candidate incidence structure satisfies the certified tropical line-membership and non-membership constraints, then the incidence relation is uniquely reconstructed from the margins.

### Precise theorem statement

A strong target theorem is:

> For a finite family of tropical lines indexed by `ι` and tropical points indexed by `π`, if:
> 1. incidence is defined by vanishing tropical defect,
> 2. non-incidence has a strictly positive certified security margin,
> 3. every pair of distinct points has a unique compatible line,
> 4. every pair of distinct lines meets in a unique compatible point,
> then the incidence relation is uniquely determined by the defect/margin data; in particular, any two tropical Fano configurations with the same certified defect profile are equal as incidence structures.

This is a tropical rigidity/reconstruction theorem, not merely a definition check.

## Proof strategy architecture

You must pursue at least 2–3 proof routes, not a single linear attempt.

### Strategy A: Direct defect-zero / positive-margin equivalence
Most promising for first success.

1. **Define `tropDefect` so that incidence is literally equivalent to zero defect.**
   The key is to encode “minimum attained at least twice” as vanishing gap between the smallest and second-smallest values of `ℓ i + p i`.

2. **Use `tropical_security_from_norm_bound` to prove positive defect for non-incidence.**
   This converts the vulnerability framework into a geometric separation lemma.

3. **Conclude reconstruction by case split.**
   If defect is zero, incidence holds by definition. If incidence fails, certified positivity excludes zero. Therefore incidence is determined by defect alone.

Why this is promising: it aligns with the “essentially definitional” hint while still producing a theorem with real mathematical content.

### Strategy B: Finite reconstruction from local profiles
More ambitious, higher payoff.

1. **Form the defect matrix** `D : P → L → ℝ`.
2. **Show that Fano-style axioms force incidence to be the zero pattern of `D`.**
3. **Use reconstruction ideas from `reconstruct_from_rank2Levi_profiles_and_edge_moments`** to prove uniqueness of the incidence structure from `D` or from a reduced set of local statistics.

This route is stronger because it upgrades local certificates to global uniqueness. It is the better theorem if the direct route is too easy.

### Strategy C: Min-plus spectral extraction
Most visionary, perhaps second-stage.

1. Build an incidence-weight matrix from defects.
2. Use `tropical_eigenpair_from_diagonal` to extract canonical tropical eigenvectors.
3. Show these eigenvectors encode distinguished points/lines or certify consistency of the incidence geometry.

This could become a theorem saying tropical Fano configurations admit a canonical spectral witness. It is less likely to be the first completed proof, but it could be revolutionary.

**Recommendation:** Complete Strategy A first, then strengthen via Strategy B. Put Strategy C into either a follow-up theorem or `FUTURE_DIRECTIONS.md`.

## Lean engineering guidance

Use concrete choices to reduce friction:

- `Fin 3 → ℝ` for tropical points/lines,
- `Finset` or finite tuples for minima/second minima,
- finite index types `Fin 7` for candidate Fano objects,
- avoid abstract order-statistics if they become painful; define defect by explicit case analysis on three coordinates.

For example, in dimension 3, the defect can be defined by:
- sorting the three values conceptually,
- or taking `min` over pairwise absolute differences under a minimality condition,
- or a simpler equivalent quantity tailored to proofs.

A robust practical option is to define:
```lean
def tropIncident (ℓ : TropLine) (p : TropPoint) : Prop :=
  let a := ℓ 0 + p 0
  let b := ℓ 1 + p 1
  let c := ℓ 2 + p 2
  (a = b ∧ a ≤ c) ∨ (a = c ∧ a ≤ b) ∨ (b = c ∧ b ≤ a)
```
after replacing numerals with `Fin` indices properly.

Then define defect as the minimum of the three “winning gaps.” This may be much easier than a fully generic order-statistic formalization.
