# Primary Breakthrough Target A: Finite rate-distortion as a piecewise-linear/tropical optimization law

You should aim to prove that for a **finite source alphabet** and **finite reproduction alphabet** with a distortion matrix, the rate-distortion function is not merely attained but admits a **piecewise-linear/tropical control structure** on finite distortion intervals. This would bridge classical information theory, min-plus convexity, and certified computability in Lean.

## Precise theorem statement
Let `α`, `β` be finite types, `μ : FinProbDist α`, and `d : α → β → ℝ`. Define the finite rate-distortion function
\[
R_{μ,d}(D) := \inf \{ I(X;\hat X) \mid X \sim μ,\ \mathbb E[d(X,\hat X)] \le D \}.
\]
Prove a finite-dimensional structural theorem of the following shape:

1. **Existence of active channels**: for each feasible `D`, a minimizer exists.
2. **Monotonicity/convexity envelope**: `R_{μ,d}` is monotone nonincreasing and convex on the feasible distortion interval.
3. **Finite tropical support decomposition**: when `α, β` are finite, there exists a finite set of affine functionals `A : Finset (ℝ × ℝ)` such that on the feasible interval,
   \[
   R_{μ,d}(D) = \sup_{(m,b)\in A} (mD+b)
   \]
   or equivalently, after sign change, is representable as a min-plus / tropical envelope.

This is the right theorem because it turns `R(D)` from an existential object into a **computable combinatorial object** in Lean.

## Candidate Lean 4 type signatures
You will likely need to define some supporting notions first, but the target should look like:

```lean
theorem finite_rateDistortion_exists_minimizer
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (μ : FinProbDist α) (d : α → β → ℝ) :
    ∀ D : ℝ, FeasibleDistortion μ d D →
      ∃ K : StochasticKernel α β, IsRateDistortionMinimizer μ d D K
```

```lean
theorem finite_rateDistortion_monotone
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (μ : FinProbDist α) (d : α → β → ℝ) :
    MonotoneOn (rateDistortion μ d) (feasibleDistortionSet μ d)
```

```lean
theorem finite_rateDistortion_convexOn
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (μ : FinProbDist α) (d : α → β → ℝ) :
    ConvexOn ℝ (feasibleDistortionSet μ d) (rateDistortion μ d)
```

```lean
theorem finite_rateDistortion_tropical_envelope
    {α β : Type*} [Fintype α] [DecidableEq α] [Fintype β] [DecidableEq β]
    (μ : FinProbDist α) (d : α → β → ℝ) :
    ∃ A : Finset (ℝ × ℝ),
      ∀ D ∈ feasibleDistortionSet μ d,
        rateDistortion μ d D = sSup ((fun p : ℝ × ℝ => p.1 * D + p.2) '' (A : Set (ℝ × ℝ)))
```

If `sSup` is technically awkward over finite sets, replace with `A.sup` after proving nonemptiness and boundedness, or formulate a min-plus equivalent using `Finset.inf'` / `Finset.sup'`.

## Why this would be a breakthrough
This would formalize, in Lean, a **computable finite-dimensional geometry of lossy compression**. It would open:
- exact certified computation of `R(D)` curves for finite models,
- tropical approximations to classical information-theoretic variational principles,
- a bridge from Shannon theory to idempotent analysis and polyhedral optimization.

This is not “another bound.” It is the beginning of a **formal polyhedral information theory**.

## Proof strategy options

### Strategy A: Convex-analytic route via compactness and finite-dimensional simplex geometry
1. Model stochastic kernels `K : α → FinProbDist β` as a compact subset of a finite-dimensional Euclidean space.
2. Show the feasible set `{K | distortion ≤ D}` is compact and mutual information is lower semicontinuous / continuous on this finite domain.
3. Deduce existence of minimizers and convexity by channel mixing.
4. Derive piecewise-linear/tropical envelope from finite supporting hyperplanes of the epigraph, or from a finite discretization theorem if exact finiteness is only available under rationality hypotheses.

**Most promising** if Mathlib support for convexity and compactness in finite-dimensional `ℝ^n` is sufficient.

### Strategy B: Lagrange-dual / tropical duality route
1. Start from `tropical_rate_distortion_duality_finset`.
2. Use the dual parameter `λ ≥ 0` to express
   \[
   R(D) = \sup_{\lambda \ge 0} (\Phi(\lambda) - \lambda D)
   \]
   for a suitable finite dual functional `Φ`.
3. Prove `R(D)` is a supremum of affine functions in `D`, hence convex and tropical in form.
4. If exact finite support is difficult, first prove a **finitely generated support theorem** under rational distortion matrices or finite active dual set.

This route is conceptually deepest because it uses the catalog’s tropical duality theorem directly and converts it into a geometric theorem.

### Strategy C: Matrix/combinatorial route on concrete finite alphabets
1. Restrict first to `α = Fin n`, `β = Fin m`, with `d` represented by a matrix `Matrix (Fin n) (Fin m) ℝ`.
2. Write channels as row-stochastic matrices.
3. Prove the theorem first in matrix form, then abstract to finite types by equivalence transport.
4. Compute explicit examples (`n=2`, `m=2`, Hamming distortion) to validate the architecture.

This is the best route for getting nontrivial Lean code to compile early.

# Secondary Breakthrough Target B: A categorical voice-leading functor into Lawvere metric spaces

The second mission is to make musical voice-leading into a certified categorical object and connect it to rate-distortion. This is where the project becomes scientifically surprising.

## Precise theorem statement
Define a category whose:
- objects are finite pitch-class multisets / chords / voicings,
- morphisms are admissible voice leadings weighted by total displacement,
- composition is concatenation of voice leadings with additive cost.

Then prove this weighted category defines a functor into a Lawvere metric category, and, if possible, into a category of finite distortion systems.

The philosophical theorem is: **voice-leading is not just a musical heuristic; it is a functorial distortion theory**.

## Why this would be a breakthrough
This would create a formal bridge between:
- music theory,
- enriched category theory,
- optimal transport / distortion geometry,
- information theory.

The point is not the music alone. The point is that **voice-leading becomes an enriched categorical testbed for distortion, compression, and semantics**. Once formalized, one can ask whether musical simplification, harmonic reduction, or motif compression obey rate-distortion principles.

## Proof strategy options

### Strategy A: Enriched-category route
1. Define hom-values as costs in `ℝ≥0∞` rather than bare morphism sets.
2. Use triangle inequality of voice-leading cost as the enriched composition law.
3. Package this as a Lawvere metric space / category.
4. Show a forgetful or embedding functor into a general distortion category.

This is the cleanest mathematically if you can leverage existing order/enrichment patterns.

### Strategy B: Ordinary category first, enrichment second
1. Define morphisms as admissible voice-leading witnesses.
2. Define composition by permutation composition / path concatenation.
3. Prove associativity and identity.
4. Add a cost functional and prove subadditivity separately.
5. Upgrade to a functor into a cost category.

This is likely the most Lean-friendly route.

### Strategy C: Matrix assignment formulation
1. Fix voicings of equal cardinality.
2. Define a morphism by a bipartite matching / assignment matrix.
3. Use sum of absolute pitch displacements as cost.
4. Composition corresponds to matrix/product or matching concatenation bounds.
5. Prove triangle inequality via `abs_add` and summation inequalities.

This route connects strongly to combinatorial optimization and could later interface with transport theory.

# Grand Bridge Theorem C: Voice-leading distortion induces a finite rate-distortion problem

Do not stop at category definitions. Push to a theorem that makes Team E and Team F one program.

## Precise theorem statement
For a finite repertoire `Ω` of voicings with a probability distribution `μ : FinProbDist Ω`, and distortion given by voice-leading cost to a compressed/harmonic prototype space `Π`, define a rate-distortion function `R_voice(D)`. Prove existence of minimizers and derive a tropical/Lawvere lower bound using the catalog theorems.

In symbols: if `dVL : Ω → Π → ℝ` is voice-leading distortion on finite sets, then
\[
\forall D \in \mathbb R,\quad \text{feasible}(D) \Rightarrow \exists K \text{ minimizing } I(X;\hat X)
\]
and
\[
\text{tropical/Lawvere lower bound} \le R_{\text{voice}}(D).
\]

## Candidate Lean 4 type signatures
```lean
theorem voiceLeading_rateDistortion_exists
    {Ω Π : Type*} [Fintype Ω] [DecidableEq Ω] [Fintype Π] [DecidableEq Π]
    (μ : FinProbDist Ω) (dVL : Ω → Π → ℝ) :
    ∀ D : ℝ, FeasibleDistortion μ dVL D →
      ∃ K : StochasticKernel Ω Π, IsRateDistortionMinimizer μ dVL D K
```

theorem voiceLeading_rateDistortion_tropical_bound

## 5. Semantics / representation learning
A categorical distortion theory of voice-leading could become a toy model for structured representation compression in machine learning: objects are semantic states, morphisms are transformations, distortion measures semantic displacement.
