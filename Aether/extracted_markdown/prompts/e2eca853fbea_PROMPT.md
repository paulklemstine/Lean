## Research Task: Max-plus / max-times Stone–Weierstrass bridge for EML classes

Research Mode: PROVE

Prove a genuinely nontrivial universal approximation theorem showing that a point-separating max-plus family of continuous real-valued functions on a compact space is uniformly dense in `C(X, ℝ)`, and then transport it via `Real.log` / `Real.exp` to a max-times statement for positive-valued classes. The key point is not to reprove classical Stone–Weierstrass from scratch, but to show that the max-plus closure hypotheses force the family to be a sublattice (or at least generate one with no loss), so that the existing lattice Stone–Weierstrass machinery applies.

### Positive-valued max-times transport theorem

The bridge theorem to the tropical / EML setting should avoid subtraction at the level of positive functions by transporting along logarithms.

A natural formalization is to work with a family `B : Set C(X, ℝ)` together with a positivity hypothesis on every member:
```lean
hpos : ∀ f ∈ B, ∀ x, 0 < f x
```
and closure under pointwise multiplication and pointwise max:
```lean
hmul : ∀ {f g : C(X, ℝ)}, f ∈ B → g ∈ B → f * g ∈ B
hmax : ∀ {f g : C(X, ℝ)}, f ∈ B → g ∈ B → (f ⊔ g) ∈ B
hconst : ∀ c : ℝ, 0 < c → ContinuousMap.const X c ∈ B
```

Then define the log-image:
```lean
def logFamily (B : Set C(X, ℝ)) : Set C(X, ℝ) :=
  {g | ∃ f ∈ B, g = ContinuousMap.comp (show C(ℝ, ℝ) from ?logMap) f}
```
where `?logMap` is the continuous map `x ↦ Real.log x` on `(0, ∞)`; if global continuity on all of `ℝ` becomes awkward, it may be cleaner to use a subtype of positive continuous functions:
```lean
def PosC (X : Type*) [TopologicalSpace X] := {f : C(X, ℝ) // ∀ x, 0 < f x}
```
and then define `log : PosC X → C(X, ℝ)`.

The intended theorem is:

```lean
theorem exists_mem_approx_uniform_positive_of_closedUnder_max_mul_consts
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
    (B : Set (PosC X))
    (hconst : ∀ c : ℝ, 0 < c → posConst X c ‹0 < c› ∈ B)
    (hmax : ∀ {f g : PosC X}, f ∈ B → g ∈ B → posSup f g ∈ B)
    (hmul : ∀ {f g : PosC X}, f ∈ B → g ∈ B → posMul f g ∈ B)
    (hsep : ∀ x y : X, x ≠ y → ∃ f ∈ B, (f : C(X, ℝ)) x ≠ (f : C(X, ℝ)) y)
    (h : PosC X) {ε : ℝ} (hε : 0 < ε) :
    ∃ b ∈ B, ‖((b : PosC X) : C(X, ℝ)) - (h : C(X, ℝ))‖ < ε := by
  ...
```

This exact statement may need adjustment because uniform approximation of positive functions is delicate if the approximant must remain positive and the error is measured in the original coordinates. A cleaner and more robust theorem is the log-uniform approximation statement:

```lean
theorem exists_mem_approx_uniform_log_of_closedUnder_max_mul_consts
    {X : Type*} [TopologicalSpace X] [CompactSpace X] [T2Space X]
    (B : Set (PosC X))
    (hconst : ∀ c : ℝ, 0 < c → posConst X c ‹0 < c› ∈ B)
    (hmax : ∀ {f g : PosC X}, f ∈ B → g ∈ B → posSup f g ∈ B)
    (hmul : ∀ {f g : PosC X}, f ∈ B → g ∈ B → posMul f g ∈ B)
    (hsep : ∀ x y : X, x ≠ y → ∃ f ∈ B, (f : C(X, ℝ)) x ≠ (f : C(X, ℝ)) y)
    (h : PosC X) {ε : ℝ} (hε : 0 < ε) :
    ∃ b ∈ B, ‖logPosC b - logPosC h‖ < ε := by
  ...
```

Here `logPosC : PosC X → C(X, ℝ)` should satisfy:
- `logPosC (posMul f g) = logPosC f + logPosC g`
- `logPosC (posSup f g) = logPosC f ⊔ logPosC g`
- `logPosC (posConst X c hc) = ContinuousMap.const X (Real.log c)`

Then the real-valued max-plus theorem applies to `logPosC '' B`.

### Proof strategy: concrete steps

1. **Convert max-plus closure into lattice closure.**  
   Prove `inf`-closure using negation:
   ```lean
   f ⊓ g = - ((-f) ⊔ (-g))
   ```
   in `C(X, ℝ)`. This is the decisive bridge from idempotent semiring structure to the lattice structure required by Stone–Weierstrass.

2. **Package the family into the hypothesis format of the existing Stone–Weierstrass theorem.**  
   Depending on the local API, define either:
   - a `Sublattice`/`Submodule`/`Subalgebra` generated by `A`, or
   - a proof that `A` itself is closed under `sup`, `inf`, additive shifts by constants, and separates points.  
   The additive structure matters because the EML approximation results are typically phrased for affine-lattice families, not arbitrary sets.

3. **Use point separation exactly as required by the existing theorem.**  
   If the library theorem wants “for all `x ≠ y`, there exists `f` with `f x ≠ f y`”, use `hsep` directly.  
   If it wants a stronger normalized separation statement, derive it by affine rescaling:
   from `f x ≠ f y`, use constants and scalar/additive operations already available in the existing development to construct a function taking prescribed values at `x` and `y`. If scalar multiplication by real numbers is not available in the max-plus assumptions, use the existing theorem only in the form that needs mere separation; otherwise you may need to add closure under scalar multiplication as an extra hypothesis.

4. **Pass from density/closure to epsilon-approximation in sup norm.**  
   Once you obtain `Dense (A : Set C(X, ℝ))` or `closure A = ⊤`, convert this to:
   ```lean
   ∀ h ε, 0 < ε → ∃ a ∈ A, ‖h - a‖ < ε
   ```
   using the metric/uniform structure on `C(X, ℝ)`. On compact spaces, the norm on continuous maps is the sup norm, so this is exactly the desired universal approximation statement.

5. **For the positive-valued theorem, push closure through `log`.**  
   Show that the log-image of a max-times family is a max-plus family:
   - multiplication becomes addition,
   - max stays max because `Real.log` is strictly monotone on positive reals,
   - positive constants map to arbitrary real constants via `c = Real.exp t`.  
   Separation is preserved because `Real.log` is injective on `(0, ∞)`. Then invoke the real-valued theorem on `logPosC '' B`.

### Important technical choices in Lean

- If working directly with `Set (C(X, ℝ))`, expect to need many helper lemmas of the form
  ```lean
  show _ ∈ A from hmax hf hg
  ```
  and extensionality on `ContinuousMap`:
  ```lean
  ext x <;> simp [sup_eq_max, inf_eq_min]
  ```
- For the `inf` identity, the pointwise proof is likely easiest:
  ```lean
  ext x
  simp [inf_eq_min, sup_eq_max, min_eq_left, max_eq_left]
  ```
  or with `linarith` after rewriting to `max`/`min`.
- If `ContinuousMap` already has lattice instances, use those instead of rebuilding pointwise continuity proofs.
- The positive-valued transport theorem may be much cleaner with a dedicated subtype `PosC X`; otherwise composing with `Real.log` globally on `ℝ` is problematic because continuity at nonpositive points is false.
- If approximation in original coordinates from log-approximation is desired, add a bounded-away-from-zero hypothesis on the target positive function and use uniform continuity of `Real.exp` / `Real.log` on compact ranges.

### Why this matters

This theorem is the cleanest formal bridge between two previously separate themes:

- the EML/Stone–Weierstrass approximation program, which studies expressive power of function classes via lattice closure and point separation;
- tropical/idempotent algebra, where the primitive operations are `max` and `+` (or, after exponentiation, `max` and `*`).

The result shows that max-plus or max-times closure is not merely an algebraic curiosity: on compact spaces, it already implies full classical universal approximation. That gives a rigorous semantic explanation for why tropicalized architectures and positive multiplicative EML classes can approximate arbitrary continuous targets after log-coordinate transport. Formally, it provides a reusable theorem schema for future work on tropical neural networks, certified robustness in idempotent models, and log-domain approximation architectures.
