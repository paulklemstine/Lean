**Title**: Tropical Hecke Operators and Piecewise-Linear Eigenfunction Spaces
**Domain**: Tropical
**Mathematical framing**: Let (ℝ∪{+∞}, ⊕, ⊗) be the tropical semiring with a⊕b = min(a,b) and a⊗b = a+b. Define the tropical projective line TP¹ = (ℝ²\{(−∞,−∞)})/∼ where (a,b)∼(λ⊗a,λ⊗b) for λ∈ℝ\{−∞}. A piecewise-linear function f: TP¹ → ℝ is one locally expressible as a tropical polynomial via AffinePiece from Tropical/Canonical/Basic.lean. The tropical Hecke operator T_p^trop on weight-k tropical modular forms: (T_p^trop f)([x:y]) = min_{j=0}^{p-1} {(k-1)·log(p) + f([x+jy : py])} ⊕ {(k-1)·log(p) + f([px : py])}. Theorem 1 (Preservation): T_p^trop maps PL_k (piecewise-linear functions of tropical weight k) to PL_k. Theorem 2 (Finite-dimensional eigenspaces): For each λ∈ℤ, E_λ = {f ∈ PL_k : T_p^trop f = λ ⊗ f} is a finite-dimensional polyhedral cone. Theorem 3 (Integrality): All eigenvalues of T_p^trop on PL_k are integers. Theorem 4 (Tropical Eisenstein eigenform): E_k^trop(x) = ⊕_{(m,n)≠(0,0)} {k·(mx+ny) + c_{m,n}} is a Hecke eigenform with explicit integer eigenvalue.
