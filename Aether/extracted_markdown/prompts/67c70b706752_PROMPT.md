## Assignment: Direction 1: Topological Restricted Products and Continuous Characters

**Mode:** prove

You are not being asked to add topology as decoration. You are being asked to formalize the analytic birth of the idèle class group. The algebraic restricted product already points toward global class field theory; the missing ingredient is the topology that makes continuous characters, Pontryagin duality, and harmonic analysis possible. If you succeed, you will not merely tidy up existing code — you will create the formal gateway from algebraic idèles to analytic automorphic objects.

Build directly on:

- `LanglandsGL1/RestrictedProduct.lean` — especially the existing `restrictedSubgroup` infrastructure.
- `LanglandsGL1/CharacterDescent.lean` — especially `character_descends_to_idele_class_group`.

Your task is to define the **restricted product topology**, prove its fundamental structural properties, and then prove that **continuous characters descend continuously to the quotient**. This is the exact analytic mechanism behind Hecke characters.

## Core Mathematical Objective

Let `ι` be an index type, and for each `i : ι`, let `G i` be a topological abelian group with a distinguished compact open subgroup `K i ≤ G i`. Define the restricted product
\[
\prod\nolimits_i' (G_i,K_i)
:= \{f : \prod_i G_i \mid \forall^\text{all but finitely many } i,\ f_i \in K_i\}.
\]
Equip it with the topology generated by sets of the form
\[
\prod_i U_i
\]
where for some finite set `S ⊂ ι`, each `U_i` is open in `G_i` for `i ∈ S`, and `U_i = K_i` for `i ∉ S`.

Then prove that this restricted product is a topological abelian group, is locally compact under natural hypotheses, and that continuous characters trivial on the principal subgroup descend continuously to the quotient.

This is the formal analytic skeleton of the idèle class group.

### Theorem 1: Restricted product topology is a group topology

**Mathematical statement.**  
If each `G i` is a topological commutative group and each `K i` is an open subgroup, then the restricted product topology makes the restricted product into a topological commutative group.

A plausible Lean 4 target signature is:

```lean
theorem restrictedProduct_isTopologicalCommGroup

    (K : ∀ i, Subgroup (G i))
    (hK_open : ∀ i, IsOpen (K i : Set (G i))) :
    TopologicalGroup (RestrictedProduct G K)
```

If the exact existing `RestrictedProduct` type in the catalog differs, adapt the statement to the actual structure rather than inventing a parallel universe. But the theorem must certify:

1. multiplication is continuous,
2. inversion is continuous,
3. the topology is compatible with the restricted support condition.

### Theorem 2: Local compactness of the restricted product

**Mathematical statement.**  
If each `G i` is locally compact and each `K i` is compact open, then the restricted product is locally compact.

A plausible Lean target:

```lean
theorem restrictedProduct_locallyCompactSpace
    {ι : Type*} {G : ι → Type*}
    [∀ i, CommGroup (G i)]
    [∀ i, TopologicalSpace (G i)]
    [∀ i, TopologicalGroup (G i)]
    [∀ i, LocallyCompactSpace (G i)]
    (K : ∀ i, Subgroup (G i))
    (hK_open : ∀ i, IsOpen (K i : Set (G i)))
    (hK_compact : ∀ i, IsCompact (K i : Set (G i))) :
    LocallyCompactSpace (RestrictedProduct G K)
```

The deep content here is that the restricted product behaves like a finite product of noncompact pieces times an infinite product of compact pieces. This is exactly the mechanism by which adèles and idèles become locally compact while full infinite products do not.

If Mathlib’s `LocallyCompactSpace` typeclass route is awkward, prove instead a theorem of the form:

```lean
theorem restrictedProduct_hasCompactNeighborhood_one
    ...
    : ∃ U : Set (RestrictedProduct G K),
        IsOpen U ∧ (1 : RestrictedProduct G K) ∈ U ∧ IsCompact (closure U)
```

and derive local compactness from it.

### Theorem 3: Continuous character descent through quotient

**Mathematical statement.**  
Let `A` be a topological abelian group, `H ≤ A` a closed normal subgroup, and `χ : A →* ℂˣ` a continuous homomorphism trivial on `H`. Then the descended homomorphism `A ⧸ H →* ℂˣ` is continuous.

A plausible Lean target:

```lean
theorem continuous_character_descends_to_quotient
    {A : Type*}
    [CommGroup A] [TopologicalSpace A] [TopologicalGroup A]
    (H : Subgroup A) [H.Normal]
    (hH_closed : IsClosed (H : Set A))
    (χ : A →* Units ℂ)
    (hχ_cont : Continuous χ)
    (h_triv : H ≤ χ.ker) :
    Continuous (QuotientGroup.lift H χ h_triv)
```

Depending on the available API, `Subgroup.normal` may be automatic for commutative groups; in that case simplify. If `Units ℂ` creates coercion friction, you may also formulate the codomain as a general topological commutative group `B`:

```lean
theorem continuous_monoidHom_descends_to_quotient
    {A B : Type*}
    [CommGroup A] [TopologicalSpace A] [TopologicalGroup A]
    [CommGroup B] [TopologicalSpace B] [TopologicalGroup B]
    (H : Subgroup A)
    (hH_closed : IsClosed (H : Set A))
    (φ : A →* B)
    (hφ_cont : Continuous φ)
    (hφ : H ≤ φ.ker) :
    Continuous (QuotientGroup.lift H φ hφ)
```

Then instantiate with `B = Units ℂ`.

## New Definitions You Must Introduce

You are required to define at least one genuinely new mathematical object not already present in the catalog. Here are two strong candidates.

### Definition A: Restricted product basic opens

Define the family of basic open sets for the restricted product topology, parameterized by a finite set of exceptional indices.

Something like:

```lean
def restrictedProductBasic
    {ι : Type*} {G : ι → Type*}
    (K : ∀ i, Set (G i))
    (S : Finset ι)
    (U : ∀ i, Set (G i)) : Set (RestrictedProduct G ?K)
```

with the intended semantics:
- if `i ∈ S`, membership is controlled by `U i`,
- if `i ∉ S`, membership is controlled by `K i`.

Then prove this family is a topological basis using `TopologicalSpace.IsTopologicalBasis`.

### Definition B: Principal-compatible continuous character

Define a structure capturing characters that are both continuous and trivial on a designated subgroup:

```lean
structure ContinuousCharacterTrivialOn
    (A B : Type*)
    [CommGroup A] [TopologicalSpace A] [TopologicalGroup A]
    [CommGroup B] [TopologicalSpace B] [TopologicalGroup B]
    (H : Subgroup A) where
  toMonoidHom : A →* B
  continuous_toFun : Continuous toMonoidHom
  trivial_on : H ≤ toMonoidHom.ker
```

This is not cosmetic. It gives you a reusable abstraction for Hecke characters, local characters, and future duality statements.

A more ambitious option is a structure for the restricted product itself that packages the subgroup data and topology:

```lean
structure TopologicalRestrictedProduct
    (ι : Type*) (G : ι → Type*) [∀ i, CommGroup (G i)]
    [∀ i, TopologicalSpace (G i)] where
  K : ∀ i, Subgroup (G i)
  isOpen_K : ∀ i, IsOpen (K i : Set (G i))
  isCompact_K : ∀ i, IsCompact (K i : Set (G i))
```

If you take this route, use it to state theorems cleanly.

## Proof Strategy Architecture

You must not give a one-line proof plan. Develop at least 2–3 serious proof paths and choose one.

### Strategy A: Basis-first topology construction
**Most promising.**

1. Define the restricted product basic opens indexed by a finite exceptional set.
2. Prove they form a basis via finite intersection stability:
   - intersect two basic opens by taking union of finite exceptional sets;
   - use subgroup closure on the integral coordinates.
3. Define the topology generated by this basis and prove:
   - multiplication sends a basic neighborhood of `xy` to preimages of basic neighborhoods of `x` and `y`;
   - inversion sends a basic neighborhood to a basic neighborhood coordinatewise.
4. For local compactness, produce a compact neighborhood of `1`:
   - choose `S = ∅`, giving the product of compact `K i`;
   - or more generally finite perturbations of compact opens.
5. Use the quotient map and `QuotientMap.continuous_iff` or the universal property of quotient topologies to prove continuity of descended characters.

Why this is strongest: it aligns perfectly with Mathlib’s topology APIs and makes continuity proofs reducible to basis calculations rather than wrestling with arbitrary opens.

### Strategy B: Subspace-of-product approach
1. Realize the restricted product as a subtype of the full product `Π i, G i`.
2. Endow it with the subspace topology from the product.
3. Show this subspace topology coincides with the restricted product topology generated by “almost all in `K i`”.
4. Deduce continuity of group operations from continuity on the ambient product.
5. Prove local compactness by identifying neighborhoods with products of finitely many local compact neighborhoods and infinitely many compact opens.

Why this is elegant: it imports continuity from the ambient product almost for free.  
Why it is risky: the topological equality proof may be technically harder than direct basis arguments, especially if the restricted product is not already represented as a subtype in the catalog.

### Strategy C: Categorical/quotient universal-property approach
1. Characterize the restricted product topology as the final/initial topology with respect to finite-coordinate projections and inclusion of compact opens.
2. Prove group continuity using the universal property.
3. For quotient descent, work abstractly with the quotient topology and show the lift is continuous iff its composition with the quotient map is continuous.
4. Reinterpret continuous characters as objects in a functor from topological groups to abelian groups.

Why this matters: it sets up later categorical formalization of adèles and Pontryagin duality.  
Why it is secondary for now: it is conceptually superior but likely more cumbersome in current Mathlib than the basis-first route.

**Recommendation:** Execute Strategy A as the main line, while stealing ambient-product lemmas from Strategy B whenever they reduce friction.

## Cross-Domain Connections You Must Explicitly Surface

This project sits at a three-way junction:

### 1. Number theory ↔ harmonic analysis
Continuous characters of the idèle class group are Hecke characters. Once continuity is formalized, you have the first genuine entry point to:
- Tate’s thesis,
- Fourier analysis on adèles,
- local/global duality,
- eventually L-functions.

### 2. Topology ↔ representation theory
The restricted product topology is the hidden topological infrastructure behind:
- smooth representations of `GL_n(A_f)`,
- Hecke algebras,
- automorphic forms.
Without locally compact topological groups, Haar measure and induced representations cannot even be stated correctly.

### 3. Functional analysis ↔ formal verification
The quotient continuity theorem is a formal version of a ubiquitous analytic maneuver:
“a continuous observable constant on gauge directions descends to the physical quotient.”
This directly resonates with:
- gauge theory,
- symplectic reduction,
- quantum mechanics via character spaces and dual groups.

You should include at least one theorem or discussion point making this bridge explicit. A strong candidate:

> A continuous homomorphism constant on a closed symmetry subgroup defines a continuous observable on the reduced phase space.

In Lean this is just the quotient continuity theorem, but conceptually it links arithmetic quotients and physical quotient spaces.
