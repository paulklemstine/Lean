### Theorem A: Kernel-Quotient Indistinguishability Lift for Module-LWE

**Mathematical statement**  
Let `R` be a finite commutative ring, `M` and `N` finite `R`-modules, and `f : M →ₗ[R] N` a surjective linear map. If an error distribution `χ` on `M` is invariant under translation by `LinearMap.ker f`, then any distinguisher against the pushforward `f_* χ` can be lifted to a distinguisher against `χ` with identical advantage. Equivalently, security in the quotient controls security upstairs whenever the error is kernel-uniform.

This is the algebraic heart of “dimension reduction” and “compression correctness” arguments in module/Ring-LWE systems, and it is the right abstraction for standards-compliant ciphertext compression.

**Lean 4 type signature target**
```lean
theorem advantage_eq_of_ker_invariant
  {R M N : Type*}
  [CommRing R]
  [AddCommGroup M] [Module R M] [Fintype M] [DecidableEq M]
  [AddCommGroup N] [Module R N] [Fintype N] [DecidableEq N]
  (f : M →ₗ[R] N)
  (hsurj : Function.Surjective f)
  (χ : PMF M)
  (hker :
    ∀ m k, k ∈ LinearMap.ker f → χ m = χ (m + k))
  (D : N → Bool) :
  advantage (PMF.map f χ) D =
    advantage χ (fun m => D (f m))
```

If `PMF.map` / `advantage` need adaptation to the catalog’s probability API, define the exact wrapper cleanly and prove the bridge lemmas.

**Why this is a breakthrough**  
This theorem reframes cryptographic hybrid arguments as **functorial statements in module categories**. That opens a path to formal, reusable proofs for Ring-LWE, Module-LWE, compression maps, reconciliation maps, and FO-style decapsulation checks. It is not an incremental variant; it is a new proof language.

### Theorem B: Dual-Hom Hybrid Composition for Search-to-Decision

**Mathematical statement**  
Suppose a secret-recovery game decomposes coordinatewise through a family of linear functionals `ℓ_i : M →ₗ[R] Rq`, and for each coordinate there is a decision oracle whose distinguishing advantage is bounded by `ε_i`. Then the total hybrid gap for recovering the whole secret is bounded by `∑ i, ε_i`.

This should generalize the catalog theorem `search_from_decision_coordinate` from vector-coordinate recovery into an abstract finite module setting. The module-theoretic version is the one that survives transport to Ring-LWE and Module-LWE.

**Lean 4 type signature target**
```lean
theorem search_advantage_le_sum_coordinate_advantages
  {R M S : Type*}
  [CommRing R]
  [AddCommGroup M] [Module R M] [Fintype M] [DecidableEq M]
  [Fintype S] [DecidableEq S]
  (ℓ : S → M →ₗ[R] R)
  (A : SearchAdversary M S)
  (B : S → DecisionAdversary R)
  (ε : S → ℝ)
  (hcoord :
    ∀ s, coordinateAdvantageBound ℓ A (B s) ≤ ε s) :
  totalSearchAdvantage ℓ A ≤ ∑ s, ε s
```

You may need to replace `R` by `ZMod q` or another finite ring to match the existing catalog. That is acceptable, but preserve the conceptual statement.

**Why this is a breakthrough**  
This theorem turns the existing hybrid framework into a **basis-free theorem**. That matters because cryptographic standards increasingly move from plain LWE to module/ring instantiations where “coordinates” are not canonical. Formalizing the theorem basis-free is the mathematically correct move and gives future reductions a stable API.

### Theorem C: Compliance-Safe Compression Bound via Linear Noise Radius

**Mathematical statement**  
Let `f : M →ₗ[R] N` be a linear compression map between finite normed modules/lattices. If the error vector `e` lies in a certified radius `‖e‖ ≤ δ`, and if the decoder is correct on the image ball of radius `L * δ` where `L` is an operator-norm bound for `f`, then compression preserves correctness. This theorem should instantiate to standards-style “decryption failure probability is zero below threshold” statements.

This is the formal bridge between abstract module morphisms and concrete compliance claims (“parameter set X satisfies correctness margin Y”).

**Lean 4 type signature target**
```lean
theorem decode_correct_of_linear_noise_bound
  {𝕜 M N : Type*}
  [NormedField 𝕜]
  [SeminormedAddCommGroup M] [NormedSpace 𝕜 M]
  [SeminormedAddCommGroup N] [NormedSpace 𝕜 N]
  (f : M →L[𝕜] N)
  (decode : N → Message)
  (encode : Message → N)
  (m : Message) (e : M) (δ : ℝ)
  (he : ‖e‖ ≤ δ)
  (hdecode :
    ∀ x, ‖x - encode m‖ ≤ ‖f‖ * δ → decode x = m) :
  decode (encode m + f e) = m
```

If the exact continuous-linear-map infrastructure is too strong for the catalog context, formulate the discrete analogue over Euclidean lattices or `ℤ`-modules with a bespoke norm structure.

**Why this is a breakthrough**  
This theorem connects **cryptographic correctness proofs to functional analysis/operator norms**, giving a mathematically principled route from abstract reductions to standards compliance. This is the kind of bridge post-quantum cryptography badly needs: formal proofs that actually speak the language of parameter documents.

## Cross-Domain Connection Theorem

### Recommended cross-domain theorem: Entropy Monotonicity Under Module Quotients

Interpret a kernel-invariant distribution as a statistical-mechanics-style coarse graining: passing from `M` to `N = M / ker f` should not increase distinguishability complexity, and should reduce or preserve Shannon entropy deficit relative to uniformity.

A formal theorem can be cast in terms of total variation distance if entropy APIs are unavailable:

```lean
theorem tvd_contracts_under_linear_pushforward
  {R M N : Type*}
  [CommRing R]
  [AddCommGroup M] [Module R M] [Fintype M] [DecidableEq M]
  [AddCommGroup N] [Module R N] [Fintype N] [DecidableEq N]
  (f : M →ₗ[R] N)
  (χ ψ : PMF M) :
  tvd (PMF.map f χ) (PMF.map f ψ) ≤ tvd χ ψ
```

**Cross-domain meaning**: this is simultaneously
- a cryptographic data-processing inequality,
- a module-theoretic quotient theorem,
- and an information-theoretic coarse-graining principle.

This is exactly the kind of bridge that opens new territory.

## Proof Strategy Architecture

You must present at least 2–3 proof paths in the code comments or accompanying paper, and choose one as primary.

### Strategy A: Quotient-first categorical route
1. Define `KernelInvariantError` and prove that such a distribution factors through the quotient by `ker f`.
2. Use the first isomorphism theorem / quotient universal property to identify the pushforward game on `N`.
3. Show distinguisher lifting by pullback along `f`, then prove equality of advantages by a `calc` chain over finite sums.

**Why promising**: This is the cleanest conceptual route and yields reusable APIs for future reductions.

### Strategy B: Finite-sum orbit decomposition
1. Partition `M` into fibers of `f`.
2. Use kernel invariance to prove the mass of each fiber is uniformly distributed across its elements.
3. Rewrite both advantages as sums over fibers and compare term-by-term.

**Why useful**: More elementary and may align better with current `Fintype`/`Finset` machinery in Mathlib.

### Strategy C: Hybrid-game abstraction route
1. Define a generic `ModuleHybridGame`.
2. Prove a telescoping inequality for successive replacements of coordinate/functional outputs.
3. Instantiate to `search_from_decision_coordinate` and then generalize to module bases or generating families.

**Why promising**: Best route for Theorem B, especially if the catalog already has hybrid lemmas you can lift.

**Recommendation**:  
Use **Strategy A** for Theorem A, **Strategy C** for Theorem B, and **Strategy B or operator-norm reasoning** for Theorem C depending on available normed APIs.
