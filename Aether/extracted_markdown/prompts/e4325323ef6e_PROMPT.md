## Core objects to define

Let `H` be a finite type of hypotheses.

Define a finite closure operator
- `cl : Finset H → Finset H`
satisfying:
- extensivity
- monotonicity
- idempotence

Then strengthen this to a **consequence-regular closure system** by adding finite proof-theoretic regularity:

1. **Exchange / consequence indistinguishability axiom**  
   If `b ∈ cl (A ∪ {a}) \ cl A`, then `a ∈ cl (A ∪ {b})`.  
   This is the anti-topological heart of the theory: it says derivational novelty is exchangeable, like a proof-front basis exchange law.

2. **Cut-compatible absorption / stability**  
   If `B ⊆ cl A`, then `cl (A ∪ B) = cl A`.

3. **Finite basis / join-irreducible generation**  
   Every closed set is generated by finitely many irredundant primitive proof steps, and in the finite setting this should be extractable as a finite antichain/minimal generator condition.

From this define a consequence semimodule whose elements represent proof states / consequence profiles, with idempotent addition = proof-front union and scalar action = entailment propagation.

You do not need the most general semiring in the first pass. A finite idempotent semiring specialized enough to formalize and prove the duality is acceptable, provided the theorem is nontrivial and reconstruction is explicit. If necessary, begin with the Boolean/idempotent dioid layer and then isolate the axioms needed for generalization.

## Lean 4 theorem target: closure-to-minimal-sequent reconstruction

You should define structures along these lines:

```lean
structure FinClosureSystem (H : Type _) [DecidableEq H] [Fintype H] where
  cl : Finset H → Finset H
  extensive : ∀ A, A ⊆ cl A
  monotone : ∀ {A B : Finset H}, A ⊆ B → cl A ⊆ cl B
  idempotent : ∀ A, cl (cl A) = cl A

structure ConsequenceRegular (H : Type _) [DecidableEq H] [Fintype H]
    extends FinClosureSystem H where
  exchange :
    ∀ {A : Finset H} {a b : H},
      a ∉ cl A →
      b ∉ cl A →
      b ∈ cl (insert a A) →
      a ∈ cl (insert b A)
  absorption :
    ∀ {A B : Finset H}, B ⊆ cl A → cl (A ∪ B) = cl A
```

Then define an entailment equivalence on contexts:

```lean
def ctxEquiv (C : ConsequenceRegular H) (A B : Finset H) : Prop :=
```

## Proof strategy architecture

## Strategy A: Nerode-style quotient on contexts by equal closure
**Most promising for the first formal breakthrough.**

1. Define `A ~ B` iff `cl A = cl B`.  
   Show this is a finite right-congruence for one-step entailment extension:
   `cl A = cl B → cl (insert h A) = cl (insert h B)`.

2. Let states be equivalence classes / canonical representatives of closures.  
   Define transitions by adjoining a hypothesis then reclosing.

3. Prove minimality:
   - reachability is immediate from surjective embedding of contexts,
   - separation follows because distinct states have distinct closures,
   - universality follows by factorization through consequence profiles.

This is the cleanest path because it reuses the conceptual architecture of Myhill–Nerode, but with closure equality replacing language indistinguishability. It should interact well with `quantum_certified_myhill_nerode_proof`.

## Strategy B: Join-irreducible / basis reconstruction from closed sets
**Most promising for extracting irredundant sequents and proof-net incidence.**

1. Define closed sets and the poset of closures under inclusion.  
   Prove finite lattice-style facts from closure axioms.

2. Define join-irreducible closed increments / minimal generators.  
   Show exchange gives a canonical irredundant basis behavior analogous to antimatroids/matroid-style elimination, but oriented toward entailment.

3. Construct sequents as irredundant cover relations
   `Γ ⟶ h`
   where `h ∈ cl Γ` but `h ∉ cl Γ'` for all proper relevant subcontexts `Γ'`.  
   Prove every entailment is generated by these irreducibles and the resulting sequent system is minimal.

This strategy is the right one if you want the theorem to speak explicitly about proof nets rather than just automaton-like states.

## Strategy C: Algebraic semimodule via saturated consequence profiles
**Most ambitious; use once Strategy A is stable.**

1. Let semimodule elements be saturated profiles `cl A`, with idempotent addition induced by closure of unions:
   `X ⊕ Y := cl (X ∪ Y)`.

2. Define scalar/action as admissible propagation operators generated by primitive hypotheses or weighted entailment steps.

3. Prove separation and finite generation, then reconstruct closure from the saturation map.  
   Show quasi-inverse equivalence and identify irreducible module generators with irredundant sequents.

This strategy gives the deepest conceptual theorem and the strongest cross-domain payoff, but it depends on having the quotient/reconstruction layer already certified.

**Recommendation:** Prove Strategy A fully, extract irreducible sequents using Strategy B, and only then package the algebra via Strategy C.
