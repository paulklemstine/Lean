## CORE DEFINITIONS TO FORMALIZE

Use minimal hypotheses first; only strengthen when required for proofs. Favor `ℝ≥0∞` or `ℝ` carefully, but if the catalog infrastructure already has a Lawvere metric codomain, align with it. A practical route is to define costs in `ℝ≥0∞` and observables in `ℝ`, then prove duality under finite-support / path-attained hypotheses.

### 1. Weighted generators

Introduce a weighted one-step derivation interface. If the catalog already has an EML closure step relation, wrap it rather than replacing it.

Suggested shape:

```lean
structure WeightedGenerator (α : Type u) where
  step : α → α → Prop
  cost : α → α → ℝ≥0∞
  cost_top_of_not_step : ∀ {x y}, ¬ step x y → cost x y = ⊤
  cost_zero_on_refl_step : ∀ {x}, step x x → cost x x = 0
```

Also define a more computational finite-support variant for path enumeration:

```lean
structure FinitelyBranchingWeightedGenerator (α : Type u) extends WeightedGenerator α where
  succFinset : α → Finset α
  mem_succFinset_iff : ∀ {x y}, y ∈ succFinset x ↔ step x y
```

If the ambient closure semantics already uses a family of generators indexed by rules, add:

```lean
structure IndexedWeightedGenerator (ι : Type u) (α : Type v) where
  act : ι → α → α
  weight : ι → α → ℝ≥0∞
```

### 2. Path costs / derivation costs

Define finite path cost and derivation cost as an infimum over paths.

```lean
def PathCost {α} (G : WeightedGenerator α) : List α → ℝ≥0∞
def AdmissiblePath {α} (G : WeightedGenerator α) (x y : α) : List α → Prop
def DerivationCost {α} (G : WeightedGenerator α) (x y : α) : ℝ≥0∞
```

The intended meaning:

- `AdmissiblePath G x y p`: path starts at `x`, ends at `y`, and every consecutive pair is a `step`;
- `PathCost G p`: sum of local costs along the path;
- `DerivationCost G x y`: `iInf` over admissible paths.

Also define a path-attained variant / witness structure:

```lean
structure PathAttainsCost {α} (G : WeightedGenerator α) (x y : α) where
  path : List α
  admissible : AdmissiblePath G x y path
  realizes : DerivationCost G x y = PathCost G path
```

### 3. Closure-aware Lawvere metric

Define a closure operator and its defect-sensitive distance. If a closure operator already exists in the catalog, reuse it.

```lean
structure EMLClosureOperator (α : Type u) where
  cl : Set α → Set α
  extensive : ∀ s, s ⊆ cl s
  monotone : ∀ ⦃s t⦄, s ⊆ t → cl s ⊆ cl t
  idempotent : ∀ s, cl (cl s) ⊆ cl s
```

Then define a closure-induced one-point distance, either directly from derivability into the closure of a singleton or via a defect correction term:

```lean
def ClosureLawvereMetric {α} (C : EMLClosureOperator α) (G : WeightedGenerator α) :
    α → α → ℝ≥0∞
```

A strong, useful choice is:
- `ClosureLawvereMetric C G x y := DerivationCost G x y`
when `step` already encodes closure dynamics,
or
- `ClosureLawvereMetric C G x y := iInf {z // z ∈ C.cl ({y} : Set α)}, DerivationCost G x z`
to truly incorporate closure.

Also define a closure defect observable:

```lean
def closureDefect {α} (C : EMLClosureOperator α) (G : WeightedGenerator α) (x : α) : ℝ≥0∞
```

Natural candidate:
```lean
closureDefect C G x := ClosureLawvereMetric C G x x
```
or a more informative asymmetry defect:
```lean
closureDefect C G x := iInf y, ClosureLawvereMetric C G x y + ClosureLawvereMetric C G y x
```

### 4. Lipschitz observables and dual test functions

Define EML observables valued in `ℝ` and their 1-Lipschitz property against the asymmetric metric. Because the metric is asymmetric, use the one-sided condition:
`f x - f y ≤ d x y`.

```lean
def IsLawvereLipschitz {α} (d : α → α → ℝ≥0∞) (f : α → ℝ) : Prop :=
  ∀ x y, f x - f y ≤ (d x y).toReal
```

Then package closure-compatible observables:

```lean
structure LipschitzEMLObservable (α : Type u) where
  toFun : α → ℝ
  lawvere_lipschitz' : IsLawvereLipschitz d toFun
  closure_monotone' : ∀ x y, y ∈ C.cl ({x} : Set α) → toFun y ≤ toFun x
```

If parameters in structures become awkward, use:
```lean
structure LipschitzEMLObservable (α : Type u) (C : EMLClosureOperator α)
    (d : α → α → ℝ≥0∞) where
  toFun : α → ℝ
  lawvere_lipschitz' : IsLawvereLipschitz d toFun
  closure_monotone' : ∀ x y, y ∈ C.cl ({x} : Set α) → toFun y ≤ toFun x
```

Add a bounded / finitely supported variant if needed for the `iSup` theorem:

```lean
structure BoundedLipschitzEMLObservable (α : Type u) (C : EMLClosureOperator α)
    (d : α → α → ℝ≥0∞) extends LipschitzEMLObservable α C d where
  bound : ∃ K : ℝ, ∀ x, |toFun x| ≤ K
```

### D. Kantorovich duality for finitely supported / path-attained systems

This is the main theorem. Use a finite branching / path attained hypothesis so that the supremum is realized or approximated by a Bellman potential.

```lean
theorem d_C_eq_iSup_observable_diff
    {α : Type u}
    [Fintype α] [DecidableEq α]
    (C : EMLClosureOperator α)
    (G : FinitelyBranchingWeightedGenerator α)
    (hattain : ∀ x y, ∃ p, PathAttainsCost G x y)
    (hfinite : ∀ x y, ClosureLawvereMetric C G x y ≠ ⊤) :
    ∀ x y,
      (ClosureLawvereMetric C G x y).toReal =
        sSup {r : ℝ | ∃ f : LipschitzEMLObservable α C (ClosureLawvereMetric C G),
          r = f.toFun x - f.toFun y}
```

If `sSup` over a set of values is awkward, define the supremum over the range of observables using a bounded set or finite-dimensional maximization. A very effective special construction is the **distance-to-target potential**
`f_z(w) := (d w z).toReal`, or in the asymmetric setting `f_y(w) := d w y`.
Show it is 1-Lipschitz by triangle inequality:
`d x y ≤ d x z + d z y`, rearranged to
`d x z - d y z ≤ d x y`.
This often gives the exact dual witness immediately.

So also prove the stronger witness theorem if possible:

```lean
theorem distanceToTarget_is_optimal_observable
    {α : Type u}
    (C : EMLClosureOperator α)
    (G : WeightedGenerator α)
    (x y : α) :
    ∃ f : LipschitzEMLObservable α C (ClosureLawvereMetric C G),
      f.toFun x - f.toFun y = (ClosureLawvereMetric C G x y).toReal
```

This is the cleanest path to the duality theorem. If closure-monotonicity obstructs the raw target-distance function, replace it by a closure-envelope:
```lean
f_y(w) := inf_{z ∈ C.cl({y})} d w z
```
and prove that this is the right witness.

### E. Closure defect duality

Formalize a defect quantity measuring how far iterative dynamics are from closure equilibrium, then identify it via observables.

```lean
def closureDefectDual {α} (C : EMLClosureOperator α)
    (d : α → α → ℝ≥0∞) (x : α) : ℝ :=
  sSup {r : ℝ | ∃ f : LipschitzEMLObservable α C d, r = f.toFun x - f.toFun (Classical.choice ?h)}
```

More concretely, use a designated closed representative or singleton closure target. A cleaner theorem is:

```lean
theorem closure_defect_dual
    {α : Type u}
    [Fintype α] [DecidableEq α]
    (C : EMLClosureOperator α)
    (G : FinitelyBranchingWeightedGenerator α)
    (hattain : ∀ x y, ∃ p, PathAttainsCost G x y)
    (x : α) :
    ∀ ε > 0, ∃ f : LipschitzEMLObservable α C (ClosureLawvereMetric C G),
      closureDefect C G x - ε ≤ ENNReal.ofReal (f.toFun x - f.toFun x) + ε
```

But since `f x - f x = 0`, this version is not informative. Better: define defect relative to closure of a set or fixed-point set. For a singleton target set `T`, define
`closureDefectToSet C G x T := inf_{y ∈ T} d x y`.
Then prove:

```lean
def closureDefectToSet {α} (C : EMLClosureOperator α) (G : WeightedGenerator α)
    (x : α) (T : Set α) : ℝ≥0∞ :=
  iInf (fun y : T => ClosureLawvereMetric C G x y)
```

```lean
theorem closure_defect_dual
    {α : Type u}
    [Fintype α] [DecidableEq α]
    (C : EMLClosureOperator α)
    (G : FinitelyBranchingWeightedGenerator α)
    (T : Set α)
    (hT_closed : C.cl T ⊆ T)
    (hattain : ∀ x y, ∃ p, PathAttainsCost G x y)
    (hfinite : ∀ x y, ClosureLawvereMetric C G x y ≠ ⊤) :
    ∀ x,
      (closureDefectToSet C G x T).toReal =
        sSup {r : ℝ | ∃ f : LipschitzEMLObservable α C (ClosureLawvereMetric C G),
          (∀ y ∈ T, f.toFun y = 0) ∧ r = f.toFun x}
```

This is the dual certificate theorem with direct **certified robustness** meaning: observables vanishing on a safe set certify distance to safety.

## RECOMMENDED PROOF ARCHITECTURE

### Strategy A: Distance-to-target witness (most promising)
This is the cleanest route to the duality theorem.

1. Define
   ```lean
   f_y x := (ClosureLawvereMetric C G x y).toReal
   ```
   or closure-envelope version
   ```lean
   f_y x := inf_{z ∈ C.cl({y})} d x z
   ```

2. Prove one-sided Lipschitzness using triangle:
   ```lean
   d x y ≤ d x z + d z y
   ```
   rearranged by `linarith` on `toReal`-converted finite distances:
   ```lean
   f_y x - f_y z ≤ d x z
   ```

3. Show normalization:
   ```lean
   f_y y = 0
   ```
   from reflexivity.

4. Conclude exactness:
   ```lean
   f_y x - f_y y = d x y
   ```

5. Package into `LipschitzEMLObservable` and take `sSup` upper/lower bounds.

This strategy avoids a heavy Hahn–Banach style argument and is ideal in Lean.

### Strategy B: Dynamic-programming / Bellman potential
Especially useful under finite branching hypotheses.

1. Define a Bellman operator on observables:
   ```lean
   B f x := infᵢ (cost x i + f i)
   ```
   or finite `Finset.inf'`.

2. Prove monotonicity and 1-Lipschitz preservation.

3. Show the target potential is the least fixed point of `B`.

4. Identify `DerivationCost G x y` with the Bellman value by induction on bounded path length, then pass to the limit.

5. Extract dual observables from Bellman fixed points.

This is especially compelling for algorithmic interpretations and **tropical** min-plus semantics.

### Strategy C: Finite-dimensional linear-program duality
Use only if the infrastructure already supports finite sums and suprema over `Fintype`.

1. Encode shortest-path constraints as:
   ```lean
   φ x - φ y ≤ cost x y
   ```
   over edges.

2. Show primal value is shortest path distance.

3. Show dual value is supremum over feasible potentials.

4. Restrict to closure-compatible potentials.

This strategy most directly connects to **cryptographic lattice relaxation** and **certified robustness** as LP certificates.
