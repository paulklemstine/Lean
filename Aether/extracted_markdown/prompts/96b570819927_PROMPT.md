## Assignment: Direction 3 — Directed Cycle Pressure via Strongly Connected Components

**Mode:** `prove`

Aristotle, do not merely port the undirected story to digraphs. Build the first genuinely directed proof-topological complexity theory: one that respects causality, dependency, and feedback. The central insight is that in proof dependency graphs, orientation is not decoration — it is the semantics. A theorem depends on lemmas in one direction; mutual dependence is exceptional and structurally meaningful. The correct directed analogue of local cycle complexity is therefore not “cycles in the symmetrized graph,” but **strongly connected recurrence inside directed neighborhoods**.

Your task is to define a new invariant — **directed cycle pressure** — and prove that it dominates the undirected invariant while being strictly sharper on explicit families. This is not a cosmetic extension. If successful, it opens a route from proof mining to dynamical graph invariants, SCC filtrations, causal complexity measures, and algorithmic theorem recommendation.

The undirected theory in

A vertex should have high directed pressure precisely when its local dependency environment contains large or numerous strongly connected regions, or equivalently many vertices participating in directed cyclic behavior.

### Suggested new definitions

At minimum define:

1. **Directed radius-`r` neighborhood** of a vertex `v`, using reachability by directed paths of length `≤ r`.
2. **Local SCC subgraph** induced on that neighborhood.
3. **Directed cycle pressure** at radius `r`, as a numerical invariant extracted from SCC structure.

A robust first definition is:

- `dirPressure G v r := #{ u in N⁺_r(v) | u lies in a nontrivial SCC of the induced digraph on N⁺_r(v) }`

where “nontrivial SCC” means either cardinality > 1 or a self-loop if your digraph model allows loops.

This is excellent because:
- it is local,
- monotone in information content,
- computable via Tarjan/Kosaraju,
- and comparable to the undirected invariant by symmetrization.

You may also define a stronger weighted version:

- `dirPressureWeighted G v r := ∑ SCC C in N⁺_r(v), (|C| - 1)`

which measures excess recurrent dimension. If both are feasible, prove theorems for the simpler count and expose the weighted version as a refined invariant.

### Theorem 1: Directed pressure dominates undirected pressure under symmetrization

Let `forgetDir G` be the undirected graph on the same vertices where an edge exists if either directed edge exists. Let `undirPressure` be the catalog local cycle pressure, or a local cycle-count surrogate aligned with the catalog definition. Prove that forgetting direction cannot create fewer local cyclic witnesses than the directed SCC-based measure.

A precise mathematical statement to target:

> For every finite directed graph `G`, vertex `v`, and radius `r`,  
> `dirPressure G v r ≤ undirPressure (forgetDir G) v r`.

This inequality direction is the mathematically natural one if directed recurrence is more restrictive than undirected cyclicity. If the catalog’s pressure convention is reversed, adapt the inequality accordingly — but be explicit and prove the comparison in the correct orientation relative to the actual definitions.

#### Lean 4 signature sketch
```lean
theorem dirPressure_le_undirPressure_forgetDir
    {V : Type _} [Fintype V] [DecidableEq V]
    (G : Digraph V) (v : V) (r : ℕ) :
    dirPressure G v r ≤ undirPressure (forgetDir G) v r
```

If the catalog’s invariant uses a normalized real-valued quantity:
```lean
theorem dirPressure_le_undirPressure_forgetDir
    {V : Type _} [Fintype V] [DecidableEq V]
    (G : Digraph V) (v : V) (r : ℕ) :
    (dirPressure G v r : ℝ) ≤ undirPressure (forgetDir G) v r
```

**Why this matters:** this theorem proves your directed invariant is a conservative refinement of the established theory. It makes the new framework backward-compatible with existing results while showing that symmetrization loses information.

### Theorem 2: Strict separation example

Construct an explicit finite digraph family `G_n` and vertex `v_n` such that the directed and undirected pressures differ strictly.

A particularly clean family is:

- vertices `{c, a₁, …, a_n}`
- directed edges `c → a_i` and `a_i → a_{i+1}` for some sparse orientation with **no directed cycles**
- but whose symmetrization creates undirected cycles in the radius-2 or radius-3 neighborhood.

Even better is a family where:
- `dirPressure G_n c r = 0`
- `undirPressure (forgetDir G_n) c r > 0`.

If your chosen undirected pressure requires an actual cycle in the local induced graph, use an oriented triangle-free acyclic digraph whose symmetrization contains triangles or larger cycles in the local ball.

#### Lean 4 signature sketch
```lean
theorem exists_strict_separation :
  ∃ (V : Type) (_ : Fintype V) (_ : DecidableEq V)
    (G : Digraph V) (v : V) (r : ℕ),
      dirPressure G v r < undirPressure (forgetDir G) v r
```

Prefer a fully explicit theorem for a concrete graph:
```lean
theorem strict_separation_on_oriented_diamond :
    dirPressure orientedDiamond center 2
      < undirPressure (forgetDir orientedDiamond) center 2
```

**Why this matters:** this is the field-opening theorem. It proves directed pressure is not a reformulation, but a genuinely finer observable.

### Theorem 3: SCC-characterization of zero pressure

Prove that zero directed pressure exactly means there is no nontrivial SCC in the directed radius-`r` neighborhood.

#### Lean 4 signature sketch
```lean
theorem dirPressure_eq_zero_iff
    {V : Type _} [Fintype V] [DecidableEq V]
    (G : Digraph V) (v : V) (r : ℕ) :
    dirPressure G v r = 0 ↔
      ∀ C, C ∈ localSCCs G v r → sccNontrivial C = False
```

Or equivalently, phrased via vertices:
```lean
theorem dirPressure_eq_zero_iff_no_nontrivial_scc
    {V : Type _} [Fintype V] [DecidableEq V]
    (G : Digraph V) (v : V) (r : ℕ) :
    dirPressure G v r = 0 ↔
      ¬ ∃ u, u ∈ outBall G v r ∧ inNontrivialLocalSCC G v r u
```

**Why this matters:** this gives the invariant semantic content. It says directed pressure is exactly local recurrent complexity.

## Proof strategy architecture

You must not rely on trivial automation. Use induction, `rcases`, `by_contra`, multi-step `calc`, and structural reasoning. Here are three proof routes.

### Strategy A: SCC containment via path symmetrization
**Most promising for Theorem 1.**

1. Define the directed radius-`r` ball and prove every directed path of length `≤ r` becomes an undirected path of length `≤ r` in `forgetDir G`.
2. Show that if a vertex belongs to a nontrivial SCC in the directed induced neighborhood, then it lies on an undirected cycle in the symmetrized induced neighborhood.
3. Convert this witness map into a counting inequality by embedding the directed recurrent set into the undirected cyclic set.

Why promising: it is local, elementary, and does not require a full formalization of Tarjan. It uses only path manipulations and induced-subgraph containment.

### Strategy B: Condensation graph and acyclicity
**Best for Theorem 3 and DAG vanishing.**

1. Define SCC equivalence and local condensation graph.
2. Prove the condensation graph is acyclic.
3. Show `dirPressure = 0` iff every local SCC is trivial, and deduce vanishing on DAGs because all SCCs in a DAG are singleton.

Why promising: mathematically canonical, conceptually clean, and opens the door to stronger later results about hierarchical proof structure.

### Strategy C: Explicit family construction by local neighborhood analysis
**Best for strict separation.**

1. Define a small concrete digraph with 4–6 vertices.
2. Compute its directed radius-`r` neighborhood around a chosen center.
3. Prove no nontrivial SCC exists by contradiction using reachability asymmetry.
4. Prove the symmetrized local graph contains a cycle by explicit witness vertices and edge checks.

Why promising: avoids giant existential constructions and gives a reusable benchmark graph for `demo.py`.

## Cross-domain connections you must exploit

Do not keep this isolated in graph theory. Make at least one theorem or discussion section tie directed pressure to another domain.

### 1. Proof theory × dynamical systems
Interpret nontrivial SCCs as **local recurrence classes**. Directed pressure becomes a discrete analogue of recurrent mass in a finite dynamical system. This invites comparisons with:
- chain recurrence,
- attractor decomposition,
- causal state structure.

A strong framing theorem: DAGs have zero recurrence pressure, analogous to gradient-like dynamical systems.

### 2. Graph theory × topology
Undirected local cycle pressure resembles first Betti complexity of neighborhoods; directed pressure replaces homological looping with **causal recurrence**. This is a bridge from classical local topology to directed topology / concurrency semantics.

### 3. Proof theory × algorithms / complexity
Tarjan’s algorithm computes SCCs in linear time. Therefore your invariant is not only mathematically natural but computationally deployable at scale on theorem dependency corpora. This is the algorithmic hook that makes the theory scientific rather than merely formal.

### 4. Category theory / semantics
SCC condensation produces a DAG of mutually interdependent clusters. This is structurally analogous to:
- quotienting by mutual reachability,
- extracting the causal skeleton of a theory,
- stratifying definitions into recursive components.

If feasible, articulate this as a theorem about local quotient structure.
