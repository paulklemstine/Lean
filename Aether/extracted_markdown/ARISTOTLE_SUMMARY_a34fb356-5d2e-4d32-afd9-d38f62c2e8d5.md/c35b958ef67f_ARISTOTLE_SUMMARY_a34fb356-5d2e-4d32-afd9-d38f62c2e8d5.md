## Overview

I investigated whether SHA-256 can be composed as a single inverted tropical or quantum gate matrix to undo the hash. The answer is **provably impossible** for general inputs, and I formalized this with 22 machine-verified theorems in Lean 4.

### 1. Formal Lean 4 Proofs (`Tropical/SHA256Inversion/HashInversion.lean`)
**22 theorems, all fully proven, zero sorries.** Key results include:

- **`no_matrix_inverts_noninj_function`** — The main impossibility theorem: no function (tropical matrix, quantum gate, or otherwise) can invert a non-injective function
- **`hash_not_injective`** — SHA-256 is non-injective by pigeonhole (2^n > 2^256 inputs map to 2^256 outputs)
- **`mod_add_not_injective`** — Modular addition (SHA-256's core operation) is not injective
- **`tropicalMatMul_assoc`** — Tropical matrix multiplication is associative (with 3 helper lemmas)
- **`tropicalPerm_inverse`** — Tropical permutation matrices are invertible: P(σ) ⊗ P(σ⁻¹) = I
- **`xor_self_inverse`**, **`xor_key_bijective`** — XOR is self-inverse and bijective (the invertible part of SHA-256)
- **`quantum_ancilla_requirement`** — Non-injective functions require ancilla (garbage) bits for quantum reversibility
- **`quantum_sha256_inverse_needs_garbage`** — No hash-only quantum inverse exists
- **`bool_or_as_tropical_min`**, **`bool_and_as_tropical_max`** — Boolean operations as tropical encodings
- **`composition_not_injective_of_component`** — One lossy step makes the entire chain non-invertible

All proofs use only standard axioms (propext, Classical.choice, Quot.sound).

## Key Mathematical Findings

1. **SHA-256 operations split cleanly**: XOR and rotations are invertible (tropical permutation matrices); modular addition is not (proven non-injective)
2. **192+ modular additions** in SHA-256 each destroy information irreversibly
3. **No algebraic object** (tropical matrix, quantum gate, neural network, or anything else) can invert a non-injective function — this is a logical impossibility, not a computational difficulty
4. **Quantum circuits** can implement SHA-256 reversibly but require ancilla bits; without them, inversion is impossible even on a quantum computer
5. **Grover's algorithm** gives quadratic speedup (2^128 vs 2^256) but this is search, not algebraic inversion
