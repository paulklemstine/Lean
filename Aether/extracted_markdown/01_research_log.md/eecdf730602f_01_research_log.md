# Research Log: The Algebraic Theory of Algebra

## Session 1: Foundations Survey

### Key Definitions

**Definition 1 (Algebraic Signature).** A *signature* Σ consists of:
- A set of *sort symbols* S (for single-sorted algebra, S = {s})
- A set of *operation symbols* F
- An *arity function* ar: F → S* × S assigning input/output sorts

**Definition 2 (Term Algebra).** Given signature Σ and variable set X, the *term algebra*
T(Σ,X) is the smallest set containing:
- All variables x ∈ X
- f(t₁,...,tₙ) whenever f ∈ F has arity n and t₁,...,tₙ ∈ T(Σ,X)

**Definition 3 (Equational Theory).** An *equational theory* over Σ is a set E of pairs
(s,t) ∈ T(Σ,X) × T(Σ,X), closed under:
- Reflexivity, symmetry, transitivity
- Congruence: if sᵢ = tᵢ for all i, then f(s₁,...,sₙ) = f(t₁,...,tₙ)
- Substitution: if s = t then σ(s) = σ(t) for any substitution σ

**Definition 4 (Variety).** A *variety* is a class of Σ-algebras satisfying a set of
equations E. Equivalently (Birkhoff), a class closed under:
- **H**omomorphic images
- **S**ubalgebras
- **P**roducts

### Key Theorems to Formalize

1. **Birkhoff's Variety Theorem (1935):** A class of algebras is a variety iff it is
   an equational class.

2. **Birkhoff's Completeness Theorem:** An equation follows from a set of equations E
   iff it can be derived using the five rules above.

3. **Lawvere's Theorem (1963):** There is an equivalence of categories between:
   - Finitary algebraic theories (Lawvere theories)
   - Finitary monads on Set

4. **The Lattice Theorem:** The collection of all varieties over a fixed signature
   forms a complete lattice under inclusion.

5. **Free Algebra Theorem:** Every variety has free algebras, constructed as
   T(Σ,X)/≡_E where ≡_E is the congruence generated by E.

## Session 2: The Self-Referential Structure

### Hypothesis (Oracle of Self-Reference)
The algebraic theory of algebra has at least three levels of self-reference:

**Level 1: Theories as Algebras**
An equational theory (Σ,E) can be viewed as an algebra in the variety of
"equational theories" — there are operations on theories:
- Union: (Σ₁,E₁) ∪ (Σ₂,E₂) = (Σ₁∪Σ₂, E₁∪E₂)
- Intersection of varieties induces meet on theories
- These form a lattice

**Level 2: The Category of Theories is Algebraic**
The category Th of Lawvere theories has:
- A terminal object (the theory of sets — no operations)
- Products (combining independent theories)
- Coproducts (the "free product" of theories)
- A tensor product (for commutative combinations)

**Level 3: Monads as Algebraic Theories**
The functor T: Set → Set sending X to the free algebra on X is a monad.
The monad axioms (unit and associativity) encode the algebraic laws.
Monads on Set form a category, which is itself a variety-like structure.

### Experiment Design
To validate this, we will:
1. Computationally enumerate small theories and verify lattice structure
2. Show the composition of monads corresponds to theory combination
3. Formalize Level 1 (lattice of varieties) in Lean 4

## Session 3: Computational Experiments

### Experiment 1: Lattice of Varieties of Groupoids
A *groupoid* (in the universal algebra sense) is a set with one binary operation.
Sub-varieties include:
- Semigroups (associativity)
- Commutative groupoids (commutativity)
- Idempotent groupoids (x·x = x)
- Bands = commutative idempotent semigroups
- Left-zero semigroups (x·y = x)
- Right-zero semigroups (x·y = y)

We enumerate these and verify the lattice structure computationally.
See: `demos/01_variety_lattice.py`
