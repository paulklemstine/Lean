# AETHER Usage Guide

## Current State

AETHER v0.1.0-alpha is fully operational with one caveat: **Aristotle API integration requires manual dispatch** because the Harmonic API endpoints are not publicly exposed (the dashboard is a Next.js app behind Auth0 authentication).

## Workflow

### Phase 1: Generate Proposals

```bash
cd Catalog/Aether/
PYTHONPATH=/home/raver1975/lean/Catalog/Aether:$PYTHONPATH python3 engine.py --mode generate --arc "speculative_scifi" --count 5
```

This creates `logs/proposals.json` with structured research proposals.

### Phase 2: Review Proposals

```bash
PYTHONPATH=/home/raver1975/lean/Catalog/Aether:$PYTHONPATH python3 manual_dispatch.py --list
```

Output:
```
Found 3 proposals:
  [0] dark_energy_tropical_polynomial_roots (phd) - Speculative/SciFi
  [1] hyperdimensional_data_compression_limit (phd) - Speculative/SciFi
  [2] temporal_causal_loop_diagram_commutes (master) - Speculative/SciFi
```

### Phase 3: Manual Dispatch to Aristotle

Option A: Copy-paste a single prompt

```bash
PYTHONPATH=/home/raver1975/lean/Catalog/Aether:$PYTHONPATH python3 manual_dispatch.py --index 0
```

This prints a formatted prompt you can copy-paste into https://aristotle.harmonic.fun/dashboard

Option B: Generate all job packages

```bash
PYTHONPATH=/home/raver1975/lean/Catalog/Aether:$PYTHONPATH python3 manual_dispatch.py --all --output-dir manual_jobs/
```

Each job package contains:
- `prompt.md` — Copy-paste ready prompt
- `Main.lean` — Standalone Lean 4 file
- `lakefile.toml` — Project config
- `lean-toolchain` — Lean version pin

### Phase 4: Receive Proof from Aristotle

After Aristotle processes the prompt:
1. Copy the returned Lean 4 code
2. Save it to `manual_jobs/job_<id>/result.lean`

### Phase 5: Integrate into Catalog

```bash
# Place the proven file in the catalog
# For example:
cp manual_jobs/job_abc123/result.lean ../Speculative/SciFi/AutoGen/my_theorem.lean

# Rebuild the catalog database
cd ../
python3 Tools/catalog.py rescan --source . --db Tools/output/catalog.json --output-dir ../CatalogBuild --shared-threshold 5

# Verify it builds
lake build
```

## Troubleshooting

**"Module not found: aether"**
```bash
export PYTHONPATH=/home/raver1975/lean/Catalog/Aether:$PYTHONPATH
```

**"No proposals found"**
```bash
# Run generate first
python3 engine.py --mode generate --arc "speculative_scifi"
```

**"Aristotle API 404"**
The API is not publicly accessible. Use `manual_dispatch.py` for copy-paste workflow.

**"lake build fails"**
Ensure you're in `Catalog/` directory and `lake` is installed:
```bash
cd Catalog/
lake build
```
