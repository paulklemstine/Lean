# Summary of changes
I formalized and proved the **Sauer–Shelah lemma** from combinatorics in the file `SauerShelah.lean`. The file compiles with no `sorry` statements and uses only standard axioms (`propext`, `Classical.choice`, `Quot.sound`).

## What's in the file

### Definitions
- **`Shatters F A`**: A family `F` of subsets shatters a set `A` if every subset of `A` arises as `A ∩ S` for some `S ∈ F`.
- **`proj`** / **`embed`**: Projection and embedding maps between `Finset (Fin (n+1))` and `Finset (Fin n)`, used to induct on the ground set size.

### Main theorem
```lean
theorem sauer_shelah : ∀ (n d : ℕ) (F : Finset (Finset (Fin n))),
    (∀ A, Shatters F A → A.card ≤ d) →
    F.card ≤ ∑ i ∈ Finset.range (d + 1), n.choose i
```

This states: if a family `F` of subsets of `Fin n` shatters no set of size greater than `d`, then `|F| ≤ ∑_{i=0}^{d} C(n, i)`.

### Proof structure
The proof proceeds by induction on `n`, splitting by the last coordinate:
- **Base case** (`n = 0`): The only subset of `Fin 0` is `∅`, so `|F| ≤ 1`.
- **Inductive step** (`n → n+1`), case `d = 0`: If no singleton is shattered, the family has at most 1 element.
- **Inductive step**, case `d ≥ 1`: Partition `F` by membership of `Fin.last n`, project both halves to `Fin n`, and apply the inclusion-exclusion identity `|F| = |F₀ ∪ F₁| + |F₀ ∩ F₁|`. The union inherits VC-dimension ≤ d, the intersection inherits VC-dimension ≤ d−1, and the result follows by the inductive hypothesis and Pascal's rule for binomial coefficient sums.
