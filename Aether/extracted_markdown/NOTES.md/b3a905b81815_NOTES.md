## Key Decisions

### What to Formalize

We chose results that are:
1. **Mathematically fundamental** — Bézout, Pythagorean parametrization, Pell
2. **Currently provable** in Lean 4 with Mathlib
3. **Representative** of each pipeline stage
4. **Non-trivial** but not requiring missing deep theory

### What We Excluded

- **Full Berggren surjectivity**: proving every PPT appears in the tree requires
  more machinery than we formalize here.
- **Fermat's two-square theorem** (p ≡ 1 mod 4 → p = a² + b²): requires Gaussian
  integers or Thue's lemma, available but complex to formalize.
- **Tropical geometry**: the full tropical variety theory is not in Mathlib; we
  formalize the bound estimation heuristic in Python only.
- **DPRM theorem** (Diophantine = recursively enumerable): far too deep for this
  formalization, though it provides the theoretical backdrop.

## Mathematical Background

### Why Idempotent Projections?

An idempotent function f satisfies f(f(x)) = f(x). This means:
- **Fixed points are stable**: once you've found a solution, the projection
  doesn't move it.
- **Composition preserves idempotence** (when maps commute): this is formally
  proved as `idempotent_composition`.
- **The pipeline is self-correcting**: applying any stage twice is the same as
  applying it once.

In the context of Diophantine equations:
- The **GCD divisibility check** is idempotent: checking divisibility twice gives
  the same answer.
- **Stereographic projection** is idempotent: projecting a point already on the
  circle back to the circle returns the same point.
- **Berggren descent** is idempotent: the root (3, 4, 5) maps to itself.

### The Brahmagupta–Fibonacci Identity

The Pell composition theorem `pell_composition` is a special case of the
Brahmagupta–Fibonacci identity:

  (x² − Dy²)(a² − Db²) = (xa + Dyb)² − D(xb + ya)²

This shows that solutions to x² − Dy² = 1 form a **group** under the operation
(x, y) ⊗ (a, b) = (xa + Dyb, xb + ya). The identity element is (1, 0), and
every fundamental solution generates an infinite cyclic subgroup.

The formal proof uses `linear_combination h1 * h2` — a single-line proof that
the algebraic identity follows from multiplying the two hypotheses.

### Mod-4 Obstruction

The theorem `not_sum_two_squares_of_three_mod_four` uses a pigeonhole-style
argument: since a² mod 4 ∈ {0, 1} for any integer a, we have
a² + b² mod 4 ∈ {0, 1, 2} — never 3. The formal proof exhaustively checks
all 16 combinations of (a mod 4, b mod 4).
