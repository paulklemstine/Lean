## Phase 1: Foundation — What We Know

### 1.1 The Berggren Tree (Berggren 1934)

Every primitive Pythagorean triple (a, b, c) with a odd, b even, a² + b² = c², gcd(a,b) = 1 can be generated from (3, 4, 5) by repeated application of three matrices:

```
     ┌ 1  -2   2 ┐       ┌ 1   2   2 ┐       ┌-1   2   2 ┐
A =  │ 2  -1   2 │  B =  │ 2   1   2 │  C =  │-2   1   2 │
     └ 2  -2   3 ┘       └ 2   2   3 ┘       └-2   2   3 ┘
```

The resulting tree:
```
                            (3, 4, 5)
                         /      |      \
                   (5,12,13) (21,20,29) (15,8,17)
                  /   |   \    / | \    / | \
            (7,24,25) ...  ...  ...  ...  ...
```

### 1.2 Key Algebraic Facts

1. **Lorentz preservation**: Each B_i preserves Q(x,y,z) = x² + y² - z² (verified in Lean)
2. **Determinants**: det(A) = det(C) = 1, det(B) = -1
3. **2×2 reduction**: Via Euclid parameters (m,n), reduces to matrices M₁, M₂, M₃ in GL(2,ℤ)
4. **Theta group**: ⟨M₁, M₃⟩ generates Γ_θ, an index-3 subgroup of SL(2,ℤ)

### 1.3 Connection to Primes — Fermat's Two-Square Theorem

**Theorem (Fermat, 1640; Euler, 1749):** An odd prime p is the sum of two squares iff p ≡ 1 (mod 4).

**Corollary:** A prime p is the hypotenuse of a primitive Pythagorean triple iff p ≡ 1 (mod 4).

This is because c = m² + n² in Euclid's parametrization.
