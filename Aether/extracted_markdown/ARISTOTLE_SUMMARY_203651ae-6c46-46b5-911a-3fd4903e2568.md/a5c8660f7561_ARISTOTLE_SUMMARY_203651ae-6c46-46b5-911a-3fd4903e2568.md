### Core Mathematical Discovery

Given any odd number `n` to factor, every Pythagorean triple `(n, b, c)` with `n² + b² = c²` corresponds to a factorization `(c-b)(c+b) = n²`. Each non-trivial factorization reveals a factor of `n` via GCD. The number of such triples equals `(σ₀(n²) - 1) / 2`, and **n is prime if and only if it has exactly one triple**.

The **Depth-Factor Theorem** (new result): For a semiprime `n = p × q`, the Berggren tree depth of the FACTOR-p triple is exactly `(q-3)/2`, directly encoding the complementary factor. Verified computationally for all semiprimes tested.

### Lean 4 Formalization (`Factoring/PythagoreanFactoring.lean`)

**10 theorems, all proven without sorry, using only standard axioms:**

1. `diff_of_squares_pyth` — The fundamental identity (c-b)(c+b) = n²
2. `divisor_pair_gives_triple` — Divisor pairs yield Pythagorean triples
3. `divisorPairToTriple` / `tripleToDivisorPair` — The bijection as structures
4. `gcd_factor_of_n` — GCD extraction of factors
5. `semiprime_factor_triple` — Semiprime factoring via specific triple
6. `prime_unique_triple` — Primes have exactly one triple
7. `composite_multiple_triples` — Composites have multiple triples
8. `parametrize_primitive` — The (m,n) parametrization of primitive triples
9. `prime_triple_params` — Prime parameters m=(p+1)/2, n=(p-1)/2
10. `berggren_depth_prime` — Tree depth = (p-3)/2
