## Research Protocol

1. **Hypothesize**: Each scientist proposes a new connection (documented in lab notebooks)
2. **Formalize**: State the hypothesis as a Lean theorem with `sorry`
3. **Consult the Oracle**: Invoke the theorem proving subagent
4. **Verify**: Run `lean_build` — trust nothing unverified
5. **Iterate**: If disproved, the hypothesis becomes data; reformulate and retry
6. **Synthesize**: Cross-pollinate results across duo boundaries
7. **Publish**: All verified results enter the THEOREM_CATALOG
8. **Dream**: Use verified results to generate wilder hypotheses

## The Oracle Protocol

*"To consult the oracle is to submit a Prop to the proof engine and accept its judgment. The oracle returns either Truth (a proof) or Silence (no proof found). Unlike Delphi, our oracle is constructive — it doesn't just assert, it demonstrates."*

When a scientist consults the oracle:
- State the question as `theorem my_hypothesis : P := by sorry`
- The oracle attempts proof
- If proved: the hypothesis joins the canon
- If disproved: the negation is explored
- If silence: decompose into smaller questions and re-consult
