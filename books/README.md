## How to Rebuild

```bash
python3 assemble_books.py
```

The assembly script (`assemble_books.py` in the project root) scans all papers in `lean1/papers2/` (primary) and `lean1/papers/` (fallback for unique files), classifies them by type (Research Paper, Scientific American, Catalog) and category, then generates all four books in all three formats.
