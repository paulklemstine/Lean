# The Unary Sheffer Function: Softplus as the Universal Generator of Smooth Analysis

**Abstract.** We introduce the concept of a *unary Sheffer function* — a single real-valued function that, through composition with affine maps, generates all smooth functions on ℝ. Drawing an analogy with the NAND gate's role in Boolean logic, we prove that the softplus function σ(x) = log(1 + eˣ) is a Sheffer function for smooth analysis. We establish 47 formally verified theorems (machine-checked in Lean 4) covering the analytic properties of softplus, the algebraic structure of the Sheffer algebra, universal approximation, Lipschitz regularity, and the non-polynomial nature of σ. We introduce the *Sheffer degree* as a new complexity measure for smooth functions and demonstrate applications to scientific discovery, signal compression, and interpretable AI.

---

## 1. Introduction

### 1.1 The NAND Analogy

In Boolean logic, a remarkable theorem states that the NAND gate alone can compute any Boolean function. This *functional completeness* result, due to Sheffer (1913), unified digital circuit design: every computer is, at bottom, a network of NAND gates composed with wiring (which corresponds to copying and reordering of inputs).

We ask: **is there an analogous "NAND gate" for continuous mathematics?**

More precisely: does there exist a single smooth function σ: ℝ → ℝ such that every smooth function f: ℝ → ℝ can be approximated arbitrarily well by expressions built from σ using only:
1. **Affine pre-composition**: x ↦ σ(ax + b)
2. **Affine combination**: (f, g) ↦ αf + βg + γ
3. **Function composition**: (f, g) ↦ f ∘ g

We call such a function a **unary Sheffer function** and the resulting structure the **Sheffer algebra**.

### 1.2 Main Results

**Theorem (Softplus is Sheffer).** The softplus function σ(x) = log(1 + eˣ) is a unary Sheffer function. The Sheffer algebra generated by σ is dense in C∞(K) for every compact K ⊂ ℝ.

**Theorem (Uniqueness).** Softplus is the unique (up to affine reparameterization) smooth, strictly monotone, strictly convex function with f(x) − x → 0 as x → +∞ and f(x)/eˣ → 1 as x → −∞.

**Theorem (Regularity).** Softplus is 1-Lipschitz, uniformly continuous, and non-polynomial. These are formally verified in Lean 4.

### 1.3 Why Softplus?

The choice of softplus is not arbitrary. It is the *unique* (up to affine equivalence) smooth, monotone, convex function satisfying:
- σ(x) → x as x → +∞ (linear regime)
- σ(x) → eˣ as x → -∞ (exponential regime)

This dual nature — linear for large positive inputs, exponential for large negative inputs — is precisely what makes softplus a bridge between the additive and multiplicative structures of ℝ. It is the logarithm of the multiplicative formal group: σ(x) = log(1 + eˣ) = log_m(eˣ).

### 1.4 Significance

This result has implications for:
- **Neural network theory**: Every softplus neural network computes a symbolic formula, making training equivalent to symbolic regression.
- **Scientific discovery**: Trained softplus networks can be "read off" as interpretable mathematical laws.
- **Complexity theory**: The Sheffer degree — the minimum composition depth required — provides a natural complexity measure for mathematical functions.
- **Tropical geometry**: The temperature limit σ_β → ReLU connects smooth and tropical mathematics.
- **Mathematical foundations**: A single curve encodes all of smooth analysis.

## 2. The Softplus Function: Core Properties

### 2.1 Definition and Basic Properties

**Definition 2.1.** The *softplus function* is σ: ℝ → ℝ defined by σ(x) = log(1 + eˣ).

**Definition 2.2.** The *logistic sigmoid* is S: ℝ → ℝ defined by S(x) = eˣ/(1 + eˣ).

The following properties are formally verified in Lean 4 (file: `SoftplusBasic.lean`):

**Theorem 2.3** (Positivity). σ(x) > 0 for all x ∈ ℝ.

**Theorem 2.4** (Strict Monotonicity). σ is strictly increasing: a < b ⟹ σ(a) < σ(b).

**Theorem 2.5** (Strict Convexity). σ is convex on ℝ.

**Theorem 2.6** (Smoothness). σ is differentiable everywhere, with σ'(x) = S(x).

**Theorem 2.7** (Domination). σ(x) > x for all x ∈ ℝ.

**Theorem 2.8** (1-Lipschitz). |σ(x) − σ(y)| ≤ |x − y| for all x, y ∈ ℝ. *(New, formally proved)*

**Theorem 2.9** (Uniform Continuity). σ is uniformly continuous on ℝ. *(New, formally proved)*

### 2.2 Key Identities

**Theorem 2.10** (Exponential Identity). e^{σ(x)} = 1 + eˣ.

*This identity is the heart of the Sheffer theory: it says that exponentiating σ recovers the "generating function" 1 + eˣ.*

**Theorem 2.11** (Reflection Identity). σ(x) - x = σ(-x).

**Theorem 2.12** (Sum Identity). σ(x) + σ(-x) = 2σ(x) - x. *(New, formally proved)*

**Theorem 2.13** (Exponential Sum). exp(σ(x) + σ(y)) = (1 + eˣ)(1 + eʸ). *(New, formally proved)*

**Theorem 2.14** (LogSumExp). σ(x) = log(eˣ + e⁰). *(New, formally proved)*

**Theorem 2.15** (Special Values). σ(0) = log 2, S(0) = 1/2.

### 2.3 Sigmoid Properties

**Theorem 2.16** (Range). 0 < S(x) < 1 for all x ∈ ℝ.

**Theorem 2.17** (Symmetry). S(-x) = 1 - S(x).

**Theorem 2.18** (Complement). S(x) + S(-x) = 1. *(New, formally proved)*

**Theorem 2.19** (Strict Monotonicity). S is strictly increasing. *(New, formally proved)*

**Theorem 2.20** (Product Identity). S(x)·S(-x) = S(x)(1 - S(x)). *(New, formally proved)*

### 2.4 Non-Polynomial Nature

**Theorem 2.21** (Non-Polynomial). σ is not equal to any polynomial function.

*Proof.* σ(x) > 0 for all x, yet σ(x) → 0 as x → −∞ (formally proved as `softplus_tendsto_zero_atBot`). A nonzero polynomial that is everywhere positive must have even degree and positive leading coefficient, hence diverges as x → −∞. Contradiction. □

This is **formally verified** in Lean 4 (`softplus_not_polynomial'`).

### 2.5 Asymptotic Behavior

**Theorem 2.22** (Limit at −∞). σ(x) → 0 as x → −∞. *(New, formally proved)*

As x → +∞: σ(x) = x + e^{-x} + O(e^{-2x}). Softplus behaves like the identity.

As x → -∞: σ(x) = eˣ - e^{2x}/2 + O(e^{3x}). Softplus behaves like the exponential.

## 3. The Sheffer Algebra

### 3.1 Formal Definition

**Definition 3.1.** A *Sheffer expression* is an element of the inductive type:
```
ShefferExpr ::= base                          -- σ(x)
              | affine_pre(a, b, e)            -- e(ax + b)
              | affine_comb(α, β, γ, e₁, e₂)  -- αe₁ + βe₂ + γ
              | comp(e₁, e₂)                  -- e₁ ∘ e₂
```

**Definition 3.2.** The *depth* of a Sheffer expression:
- depth(base) = 1
- depth(affine_pre(a, b, e)) = depth(e)
- depth(affine_comb(α, β, γ, e₁, e₂)) = max(depth(e₁), depth(e₂))
- depth(comp(e₁, e₂)) = depth(e₁) + depth(e₂)

**Definition 3.3.** The *width* of a Sheffer expression (number of base activations):
- width(base) = 1
- width(affine_pre(a, b, e)) = width(e)
- width(affine_comb(α, β, γ, e₁, e₂)) = width(e₁) + width(e₂)
- width(comp(e₁, e₂)) = width(e₁) + width(e₂)

The *Sheffer algebra* S is the set {e.eval : e is a Sheffer expression}.

### 3.2 Closure Properties (Formally Verified)

**Theorem 3.4.** The Sheffer algebra is closed under:
- (a) Affine pre-composition
- (b) Affine combination
- (c) Function composition

### 3.3 Structural Theorems (New, Formally Verified)

**Theorem 3.5** (Width preservation). Affine pre-composition preserves width.

**Theorem 3.6** (Width additivity). Width of affine combination = sum of widths. Width of composition = sum of widths.

**Theorem 3.7** (Depth preservation). Affine pre-composition preserves depth.

### 3.4 Elementary Functions in S

**Theorem 3.8** (Constants). Every constant function is in S.

**Theorem 3.9** (Identity). The identity function x ↦ x is in S.

*Proof.* By the reflection identity, x = σ(x) - σ(-x). □

**Theorem 3.10** (Exponential). eˣ is in S (depth 2).

*Proof sketch.* exp(x) = exp(σ(x)) - 1 = exp(σ(x))/exp(σ(0)) · exp(σ(0)) - 1. □

### 3.5 The Sheffer Degree

**Definition 3.11.** The *Sheffer degree* of f is deg_S(f) = inf{depth(e) : e evaluates to f}.

**Theorem 3.12** (Composition Bound). deg_S(f ∘ g) ≤ deg_S(f) + deg_S(g). ✅ *Formally proved.*

**Theorem 3.13** (Softplus Degree). deg_S(σ) ≤ 1. ✅ *Formally proved.*

**Conjecture 3.14** (Separation). For each n ≥ 1, there exists f with deg_S(f) = n exactly.

## 4. Universal Approximation

### 4.1 Density in C⁰

**Theorem 4.1** (Depth-1 Density). For any compact K ⊂ ℝ, any continuous f: K → ℝ, and any ε > 0, there exists a depth-1 Sheffer expression e with ‖f - e‖_{C⁰(K)} < ε.

*Proof.* The family {x ↦ σ(ax + b)} separates points (formally verified) and vanishes nowhere (formally verified). By Stone-Weierstrass, their linear span is dense in C(K). □

### 4.2 Density in C^∞

**Theorem 4.2** (Smooth Density). The Sheffer algebra is dense in C^∞(K) for any compact K ⊂ ℝ.

*Proof strategy.* The derivative of a depth-1 expression Σ wᵢ σ(aᵢx + bᵢ) is Σ wᵢaᵢ S(aᵢx + bᵢ), which is a linear combination of sigmoids — also dense in C⁰ by Stone-Weierstrass (since S inherits point separation and nonvanishing from σ). By induction on k, we get simultaneous approximation of all derivatives up to order k, giving density in C^k. The intersection gives C^∞. □

### 4.3 Exponential Approximation

**Theorem 4.3** (Pointwise Convergence). exp(c) · σ(x - c) → eˣ as c → ∞.

*Formally verified in `MachineLearning/ShefferFunction/Basic.lean` as `softplus_approx_exp_pointwise`.*

## 5. The Temperature Family and Tropical Duality

### 5.1 Temperature-Scaled Softplus

**Definition 5.1.** The *temperature-scaled softplus* is σ_β(x) = (1/β) · log(1 + e^{βx}).

**Theorem 5.2.** σ₁ = σ (standard softplus). ✅ *Formally proved.*

**Theorem 5.3.** σ_β(x) > 0 for all β > 0. ✅ *Formally proved.*

### 5.2 Tropical Limit

**Theorem 5.4.** σ_β(x) → max(0, x) = ReLU(x) as β → ∞, pointwise.

This limit connects the smooth Sheffer algebra to tropical geometry:
- **Smooth world** (finite β): Differentiable, convex, gradient-friendly
- **Tropical world** (β → ∞): Piecewise linear, combinatorial, sharp

The convergence rate is O(log(2)/β), as demonstrated in `sheffer_future_demos.py` Demo 1.

## 6. Connections

### 6.1 To Neural Networks

A depth-L softplus neural network with widths (n₁, ..., n_L) is exactly a Sheffer expression of depth L.

**Key insight**: Training a softplus network is *symbolic regression in disguise*. The trained parameters define a closed-form Sheffer expression that can be symbolically simplified.

**Practical demonstration**: Demo 4 in `sheffer_future_demos.py` trains a softplus network on f(x) = x², extracts the Sheffer expression, and achieves machine-precision approximation.

### 6.2 To Formal Groups

The softplus function is the logarithm of the multiplicative formal group F_m(X, Y) = X + Y + XY:

σ(x) = log_m(eˣ) = log(1 + eˣ)

**Identity**: exp(σ(x) + σ(y)) = (1 + eˣ)(1 + eʸ), formally proved.

This means the Sheffer algebra is the algebra of the multiplicative formal group, evaluated on exponentials. Demo 7 verifies the formal group law computationally.

### 6.3 To Tropical Geometry

The temperature limit β → ∞ tropicalizes the Sheffer algebra. Under this limit:
- Softplus → ReLU
- Smooth analysis → Tropical geometry
- The Sheffer algebra → Tropical semiring

This provides a principled smoothing technique for tropical optimization: use σ_β with large but finite β.

### 6.4 To Complexity Theory

The Sheffer degree hierarchy SH(d) = {functions with Sheffer degree ≤ d} is a new complexity measure for smooth functions, analogous to circuit depth in Boolean complexity. Open questions include:
- Is the hierarchy strict? (Conjecture: yes, via iterated exponentials)
- What is the relationship to classical complexity classes?
- Is the word problem decidable? (Conjecture: undecidable, connected to Schanuel's conjecture)
