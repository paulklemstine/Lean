# Compositional Witness Synthesis for Pythagorean Triples: From Existence to Algorithm

## Abstract

We develop a comprehensive theory of *compositional witness synthesis* for Pythagorean triples, establishing the algorithmic transition from existence proofs to constructive generation. Our main contributions are: (1) a formally verified proof that the classical parametrization (m² − n², 2mn, m² + n²) always yields valid Pythagorean triples, with tight size bounds; (2) a compositionality theorem showing that all three Berggren transformations preserve the Pythagorean property via Lorentz form invariance; (3) a path synthesis correctness theorem proving that every triple generated by any sequence of Berggren matrix applications is Pythagorean; (4) a Gaussian composition theorem showing that two Pythagorean triples can be multiplicatively combined via the Brahmagupta–Fibonacci identity; and (5) a proof that no isosceles Pythagorean triple exists, connecting to the irrationality of √2. All results are machine-verified in Lean 4 with the Mathlib library.

**Keywords:** Pythagorean triples, witness synthesis, Berggren tree, Lorentz group, compositional algorithms, formal verification

## 1. Introduction

### 1.1 Motivation

The study of Pythagorean triples — integer solutions to *a*² + *b*² = *c*² — is among the oldest in mathematics, with examples recorded on the Plimpton 322 tablet (c. 1800 BCE). While the existence of infinitely many solutions has been known since antiquity, the *algorithmic* question of efficiently synthesizing triples with desired properties remains central to computational number theory and its applications.

We address this through the lens of **witness synthesis**: given structural parameters or constraints, construct a concrete triple satisfying the Pythagorean equation, with provable correctness and explicit size bounds. This parallels the constructive turn in modern mathematics, where existence proofs are strengthened to algorithmic constructions.

### 1.2 Prior Work

The parametric family (m² − n², 2mn, m² + n²) has been known since Euclid (c. 300 BCE). Berggren (1934) discovered that three specific 3×3 integer matrices generate all primitive Pythagorean triples as an infinite ternary tree rooted at (3, 4, 5). Barning (1963) independently discovered the same structure. Hall (1970) proved completeness of the Berggren tree. Price (2008) gave an accessible modern treatment.

The connection between Berggren matrices and the Lorentz group O(2,1;ℤ) was developed by Romik (2008) and others, establishing that the Berggren tree is a fundamental domain for the action of a specific subgroup of O(2,1;ℤ) on the positive light cone.

### 1.3 Contributions

Our contributions are organized around five formally verified theorems:

1. **Parametric Witness Correctness** (Theorem 3.1): The parametric family always satisfies a² + b² = c².
2. **Berggren Lorentz Invariance** (Theorem 4.1): All three Berggren matrices preserve the Lorentz form.
3. **Compositional Synthesis** (Theorem 4.2): Berggren transformations preserve the Pythagorean property.
4. **Path Synthesis Correctness** (Theorem 4.3): Every Berggren path from (3,4,5) produces a valid triple.
5. **Gaussian Composition** (Theorem 5.1): Two Pythagorean triples compose into a new one.
6. **No Isosceles Triple** (Theorem 6.1): The equation a² + a² = c² has no positive integer solutions.

Additionally, we establish:
- Tight size bounds (hypotenuse between m² and 2m²)
- Positivity of legs under natural parameter constraints
- Scaling preservation (ka, kb, kc is Pythagorean if a, b, c is)
- The sum-of-odd-numbers identity connecting to square geometry
- Concrete witness computations verified by the kernel

## 2. Definitions and Notation

### 2.1 Pythagorean Triples

**Definition 2.1.** A *Pythagorean triple* is a triple (a, b, c) ∈ ℤ³ satisfying a² + b² = c².

**Definition 2.2.** A Pythagorean triple (a, b, c) is *primitive* if gcd(a, b) = 1.

### 2.2 Parametric Witness

**Definition 2.3.** The *parametric witness* function W : ℤ × ℤ → ℤ³ is defined by:
```
W(m, n) = (m² − n², 2mn, m² + n²)
```

### 2.3 Berggren Matrices

**Definition 2.4.** The three *Berggren matrices* are:

```
        ⎛ 1  -2   2 ⎞         ⎛ 1   2   2 ⎞         ⎛-1   2   2 ⎞
B_A =   ⎜ 2  -1   2 ⎟,  B_B = ⎜ 2   1   2 ⎟,  B_C = ⎜-2   1   2 ⎟
        ⎝ 2  -2   3 ⎠         ⎝ 2   2   3 ⎠         ⎝-2   2   3 ⎠
```

These are implemented as functions on ℤ³:
- B_A(a,b,c) = (a − 2b + 2c, 2a − b + 2c, 2a − 2b + 3c)
- B_B(a,b,c) = (a + 2b + 2c, 2a + b + 2c, 2a + 2b + 3c)
- B_C(a,b,c) = (−a + 2b + 2c, −2a + b + 2c, −2a + 2b + 3c)

### 2.4 Berggren Path

**Definition 2.5.** A *Berggren path* is a finite sequence σ = (i₁, i₂, ..., iₖ) where each iⱼ ∈ {A, B, C}. The *synthesized triple* along path σ starting from root (3, 4, 5) is:

```
T(σ) = B_{i₁} ∘ B_{i₂} ∘ ⋯ ∘ B_{iₖ}(3, 4, 5)
```

### 2.5 Lorentz Form

**Definition 2.6.** The *Lorentz form* on ℤ³ is Q(a, b, c) = a² + b² − c².

## 3. Parametric Witness Synthesis

### 3.1 Correctness

**Theorem 3.1** (Parametric Witness Correctness). *For all m, n ∈ ℤ:*
```
(m² − n²)² + (2mn)² = (m² + n²)²
```

*Proof.* Direct algebraic verification:
```
(m² − n²)² + (2mn)² = m⁴ − 2m²n² + n⁴ + 4m²n² = m⁴ + 2m²n² + n⁴ = (m² + n²)²
```
In our formalization, this is discharged by the `ring` tactic. ∎

### 3.2 Size Bounds

**Theorem 3.2** (Hypotenuse Bounds). *For m > n > 0:*
```
m² ≤ m² + n² ≤ 2m²
```

*Proof.* The lower bound follows from n² ≥ 0. The upper bound follows from n < m, hence n² < m², so m² + n² < 2m². ∎

**Theorem 3.3** (Leg Bounds). *For m > n > 0, both legs are strictly less than the hypotenuse:*
```
m² − n² < m² + n²   and   2mn < m² + n²
```

*Proof.* The first inequality reduces to 0 < 2n², immediate from n > 0. The second reduces to 0 < (m − n)², which holds since m ≠ n. ∎

**Theorem 3.4** (Quadratic Bound). *For m, n ≥ 0:*
```
m² + n² ≤ (m + n)²
```

*Proof.* (m + n)² − (m² + n²) = 2mn ≥ 0. ∎

### 3.3 Positivity

**Theorem 3.5** (Leg Positivity). *For m > n > 0:*
- *m² − n² > 0*
- *2mn > 0*

### 3.4 Concrete Examples

| m | n | First leg | Second leg | Hypotenuse |
|---|---|-----------|------------|------------|
| 2 | 1 | 3         | 4          | 5          |
| 3 | 2 | 5         | 12         | 13         |
| 4 | 1 | 15        | 8          | 17         |
| 4 | 3 | 7         | 24         | 25         |

All verified by kernel-level computation (`native_decide`).

## 4. Compositional Berggren Synthesis

### 4.1 Lorentz Invariance

**Theorem 4.1** (Berggren Lorentz Invariance). *For each i ∈ {A, B, C} and all (a, b, c) ∈ ℤ³:*
```
Q(Bᵢ(a, b, c)) = Q(a, b, c)
```
*where Q(a, b, c) = a² + b² − c² is the Lorentz form.*

*Proof.* Direct algebraic verification for each matrix. For example, for B_B:
```
Q(a + 2b + 2c, 2a + b + 2c, 2a + 2b + 3c)
  = (a + 2b + 2c)² + (2a + b + 2c)² − (2a + 2b + 3c)²
  = a² + b² − c²
  = Q(a, b, c)
```
Each case is verified by `ring` after case-splitting on i. ∎

**Remark.** This theorem encodes the fact that all Berggren matrices lie in the integer Lorentz group O(2,1;ℤ). The Lorentz form is the Minkowski metric with signature (+, +, −), the same structure that appears in special relativity.

### 4.2 Compositional Synthesis

**Theorem 4.2** (Berggren Preserves Pythagorean Property). *If (a, b, c) is a Pythagorean triple, then Bᵢ(a, b, c) is a Pythagorean triple for each i ∈ {A, B, C}.*

*Proof.* If a² + b² = c², then Q(a, b, c) = 0. By Theorem 4.1, Q(Bᵢ(a, b, c)) = 0, so the image satisfies the Pythagorean equation. ∎

This two-line proof, reducing compositional synthesis to Lorentz invariance, is the conceptual core of the paper. It shows why the Berggren tree works: not by accident of specific matrix entries, but by the deep structural reason that the matrices preserve the relevant quadratic form.

### 4.3 Path Synthesis

**Theorem 4.3** (Path Synthesis Correctness). *For any Berggren path σ, the triple T(σ) is Pythagorean.*

*Proof.* By induction on the length of σ:
- **Base case** (σ = ε): T(ε) = (3, 4, 5), which satisfies 9 + 16 = 25.
- **Inductive step** (σ = i :: τ): By induction hypothesis, T(τ) is Pythagorean. By Theorem 4.2, Bᵢ(T(τ)) = T(σ) is also Pythagorean. ∎

### 4.4 Hypotenuse Growth

**Theorem 4.4** (B-Growth). *For a, b, c > 0:*
```
c < 2a + 2b + 3c = hyp(B_B(a, b, c))
```

*Proof.* 2a + 2b + 3c − c = 2a + 2b + 2c > 0 since a, b, c > 0. ∎

### 4.5 Distinctness

**Theorem 4.5** (Root Children Distinct). *The three children of (3, 4, 5) in the Berggren tree are pairwise distinct:*
```
B_A(3,4,5) = (5, 12, 13) ≠ B_B(3,4,5) = (21, 20, 29) ≠ B_C(3,4,5) = (15, 8, 17)
```

*Proof.* Kernel computation. ∎

## 5. Gaussian Composition

### 5.1 The Brahmagupta–Fibonacci Identity

**Theorem 5.1** (Brahmagupta–Fibonacci). *For all a₁, b₁, a₂, b₂ ∈ ℤ:*
```
(a₁² + b₁²)(a₂² + b₂²) = (a₁a₂ − b₁b₂)² + (a₁b₂ + b₁a₂)²
```

This identity encodes the multiplicativity of the norm in the Gaussian integers ℤ[i].

### 5.2 Witness Composition

**Theorem 5.2** (Gaussian Composition of Triples). *If (a₁, b₁, c₁) and (a₂, b₂, c₂) are Pythagorean triples, then so is:*
```
(a₁a₂ − b₁b₂, a₁b₂ + b₁a₂, c₁c₂)
```

*Proof.* We have c₁² = a₁² + b₁² and c₂² = a₂² + b₂². Then:
```
(a₁a₂ − b₁b₂)² + (a₁b₂ + b₁a₂)² = (a₁² + b₁²)(a₂² + b₂²) = c₁²c₂² = (c₁c₂)²
```
The first equality is the Brahmagupta–Fibonacci identity. ∎

### 5.3 Difference of Squares

**Theorem 5.3** (Pythagorean Factoring). *If a² + b² = c², then a² = (c − b)(c + b).*

*Proof.* (c − b)(c + b) = c² − b² = a². ∎

This factoring identity is the basis of several number-theoretic algorithms, including the descent procedure for finding the Berggren tree path of a given primitive triple.

## 6. Non-Existence Results

### 6.1 No Isosceles Pythagorean Triple

**Theorem 6.1** (No Isosceles Triple). *There is no Pythagorean triple of the form (a, a, c) with a > 0.*

*Proof.* If a² + a² = c², then 2a² = c², so (c/a)² = 2, meaning c/a = √2. But √2 is irrational, contradicting c, a ∈ ℤ. ∎

This theorem connects Pythagorean triple theory to the ancient proof of the irrationality of √2, traditionally attributed to Hippasus of Metapontum (5th century BCE).

## 7. Scaling and Algebraic Structure

**Theorem 7.1** (Scaling). *If (a, b, c) is a Pythagorean triple and k ∈ ℤ, then (ka, kb, kc) is a Pythagorean triple.*

*Proof.* (ka)² + (kb)² = k²(a² + b²) = k²c² = (kc)². ∎

**Theorem 7.2** (Sum of Consecutive Odds). *For n ∈ ℕ:*
```
∑_{i=0}^{n-1} (2i + 1) = n²
```

This connects to the geometric interpretation: each odd number 2k+1 is the difference between consecutive perfect squares, (k+1)² − k². A Pythagorean triple a² + b² = c² can be seen as a decomposition of c² into a sum of b² consecutive odds starting from an appropriate point.

## 8. Algorithms

### 8.1 Parametric Synthesis Algorithm

```
PARAMETRIC-SYNTHESIS(m, n):
    Input: integers m > n > 0
    Output: Pythagorean triple (a, b, c)
    
    a ← m² − n²
    b ← 2mn
    c ← m² + n²
    return (a, b, c)
```

**Complexity:** O(M(log m)) where M(n) is the cost of n-bit multiplication. For m, n bounded by N, this is O(M(log N)) ≈ O(log N · log log N) using FFT-based arithmetic.

### 8.2 Berggren Tree Enumeration Algorithm

```
BERGGREN-ENUMERATE(depth):
    Input: maximum tree depth d
    Output: all primitive triples up to depth d
    
    queue ← {(3, 4, 5)}
    result ← ∅
    for level 1 to d:
        new_queue ← ∅
        for each (a, b, c) in queue:
            result ← result ∪ {(a, b, c)}
            new_queue ← new_queue ∪ {B_A(a,b,c), B_B(a,b,c), B_C(a,b,c)}
        queue ← new_queue
    return result
```

**Complexity:** O(3^d) triples generated, each in O(1) arithmetic operations. Space O(3^d) for BFS, or O(d) for DFS.

### 8.3 Gaussian Composition Algorithm

```
GAUSSIAN-COMPOSE((a₁, b₁, c₁), (a₂, b₂, c₂)):
    Input: two Pythagorean triples
    Output: composed Pythagorean triple
    
    a ← a₁a₂ − b₁b₂
    b ← a₁b₂ + b₁a₂
    c ← c₁c₂
    return (a, b, c)
```

**Complexity:** O(1) arithmetic operations.

## 10. Discussion

### 10.1 Implications

The compositional structure of Pythagorean triple synthesis has implications beyond number theory:

1. **Program testing:** The Berggren tree provides a systematic method for generating test cases with controlled complexity growth, applicable to any system that processes integer triples.

2. **Cryptography:** The Lorentz group structure connects Pythagorean triples to lattice-based cryptographic schemes, where integer points on quadric surfaces play a role in key generation.

3. **Parallel computation:** The tree structure enables embarrassingly parallel enumeration — each subtree can be explored independently.

### 10.2 Limitations

Our formalization does not yet include:
- The completeness theorem (every primitive triple appears in the Berggren tree)
- The uniqueness theorem (each primitive triple appears exactly once)
- Asymptotic counting results (the number of primitive triples with hypotenuse ≤ N is ~N/2π)

### 10.3 The Role of Machine Verification

All theorems in this paper are machine-verified, eliminating the possibility of subtle algebraic errors. The most conceptually interesting aspect is the Lorentz-invariance-based proof of Theorem 4.2: the formal proof is only two lines (apply Lorentz invariance, then use `linarith`), matching the mathematical intuition that compositional synthesis works *because of* quadratic form preservation.

## 11. Future Work

1. **Completeness of the Berggren tree:** Formalize the theorem that every primitive Pythagorean triple appears in the Berggren tree.
2. **Higher-dimensional generalization:** Extend to Pythagorean quadruples (a² + b² + c² = d²) using Hurwitz quaternion multiplication.
3. **Asymptotic analysis:** Formalize the counting function π_P(N) ~ N/2π.
4. **Lattice reduction connection:** Formalize the connection between Pythagorean triple synthesis and LLL-based lattice algorithms.
5. **Automated witness optimization:** Given a target hypotenuse, find the Berggren path with minimum depth.
